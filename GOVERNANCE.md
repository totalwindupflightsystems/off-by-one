# Governance

## Project Governance

Off-by-One is a research project developed by Total Windup Flight Systems. It operates as an open-source project under the MIT License.

## Decision Making

Project decisions are made by the maintainers. All changes go through the GitReins quality gate pipeline before merging.

## Roles

- **Maintainer:** Alexis Okuwa (wojonstech@gmail.com)
- **Contributors:** See commit history and CONTRIBUTING.md

## Process

1. Features and bugs are tracked in `.coding-hermes/tasks.md`
2. All code changes require GitReins Tier 1 + Tier 2 (judge) evaluation
3. Commits include co-author attribution per CONTRIBUTING.md
4. The project follows the coding-hermes foreman/worker model for autonomous development
