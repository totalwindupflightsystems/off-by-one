## Variant: 003 — Color Pop

### Design stance
Playful pastel bento — each tile has its own soft color (PostHog/Stripe energy), dark tiles anchor the grid. "This is fun and friendly."

### Key choices
- Layout: 4-col bento, pastel palette per tile (sky/indigo/green/violet/amber/pink), dark pipeline + link band
- Typography: 56px/800 tight wordmark with gradient "By"
- Color: #fafafa bg, per-tile pastels, ink-dark anchors
- Interaction: tile hover lift + shadow, pill CTAs

### Trade-offs
- Strong at: standing out, friendly community feel, approachable for non-engineers
- Weak at: pastel palette risks feeling less "serious" to hardcore devs; more color = more chance of visual noise over time

### Best for
- A community that wants to feel welcoming — visitors who browse answers casually, not just engineers
