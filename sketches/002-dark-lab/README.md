## Variant: 002 — Dark Lab

### Design stance
Linear/Vercel-style dark developer tool: near-black canvas, gradient headline, live-terminal previews, data-forward tiles. "This is for engineers."

### Key choices
- Layout: 4-col bento, terminal tile (2x2), pipeline with colored dots, language coverage bars
- Typography: 60px/800 tight gradient headline, Inter-ish system stack
- Color: #0a0a0f bg, #6366f1/#38bdf8 accents, green/amber/pink status dots
- Interaction: working light/dark theme toggle, tile hover lift

### Trade-offs
- Strong at: instant credibility with developers; matches what successful dev-tool communities (Linear, Vercel, PostHog) look like
- Weak at: less distinct — many dev tools look like this; dark-only needs the light theme to be good too

### Best for
- Maximizing "I want to use this" among technical visitors
