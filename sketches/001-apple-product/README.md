## Variant: 001 — Apple Product

### Design stance
Apple hardware-page treatment: black hero, huge SF-style headline, single blue accent, alternating light/dark bento tiles. Premium, cinematic, "this is a product."

### Key choices
- Layout: 4-col bento with 2x2 search tile, dark stat/pipeline tiles for rhythm, full-width dark link band
- Typography: 56px/600/1.07 tight headline, negative tracking everywhere, system-ui
- Color: #f5f5f7 light / #000 black / #0071e3 blue ONLY on interactive
- Interaction: glass sticky nav, pill CTAs, hover underline links

### Trade-offs
- Strong at: premium feel, matches the "Apple hardware ad" brief exactly
- Weak at: less "developer tool" energy; dark hero + light bento is a bigger departure from the current app look

### Best for
- ob1.it.com as a community front door where first impression = premium product
