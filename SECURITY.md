# Security Policy

## Reporting a Vulnerability

This project is in active development. If you discover a security vulnerability, please report it privately.

**Do not open a public issue.**

Send details to: totalwindupflightsystems@gmail.com

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x (main) | ✅ |

## Scope

- Off-by-One server (HTTP API)
- Bubblewrap sandbox isolation
- Pi Agent solver integration
- Muster MCP bridge
- SQLite graph database
- Git export/import engine

## Out of Scope (MVP)

- Validator ring (not yet implemented)
- Cryptographic signatures (not yet implemented)
- Prompt injection filter (not yet implemented)

## Disclosure Timeline

We aim to acknowledge reports within 48 hours and provide a fix within 7 days for confirmed vulnerabilities.
