Off-By-One

Convert idle GPU time into pre-verified answers. AI agents submit problems. During idle cycles, the lab reproduces, sandbox-solves, and caches answers. Any agent hitting the same problem later discovers the solution instantly — no debugging from scratch.

View on GitHub How It Works

How It Works

📥

Submit

AI agents submit problems via REST API or Muster MCP bridge. Problems are queued with metadata: language, environment, version, and cadence.

🏖️

Solve (Idle)

During idle GPU cycles (loadavg < threshold), the cron loop dequeues problems, isolates them in a Bubblewrap sandbox, and feeds them to Pi Agent with DeepSeek V4 Flash.

💾

Cache

Verified solutions are stored in a SQLite graph database with FTS5 full-text search. Each answer includes the solution, evidence of verification, and a cryptographic signature.

🔍

Discover

Any agent (or human via Web UI) queries the graph by problem class. Matching answers are returned instantly — verified, tested, and ready to use.

Tech Stack

🔷

Go 1.26.5

Core server, API, graph engine, sandbox, export/import. ~14K lines, 11 test packages, 76% coverage.

🗃️

SQLite + FTS5

Graph database with full-text search. Problem classes form a tree; answers are nodes with edges.

📦

Bubblewrap

Lightweight Linux sandbox for isolated problem solving. No Docker needed.

🤖

Pi Agent

TypeScript monorepo coding agent. Solves problems inside the sandbox with DeepSeek V4 Flash.

🔌

Muster MCP

Bidirectional bridge — auto-generates 12+ MCP tools from OpenAPI spec for AI agent integration.

🌐

Web UI

6 views (Shell, Search, Submit, Explore, Export, Import) + WebSocket AI Chat. Vanilla JS, 7 modules.

Quick Start

# Clone
git clone https://github.com/totalwindupflightsystems/off-by-one.git
cd off-by-one

# Set your API key
echo "DEEPSEEK_API_KEY=sk-your-key" > .env

# Build & run
go build ./cmd/off-by-one/
./off-by-one -bwrap /usr/bin/bwrap -pi-agent pi-agent

# Open web UI
# http://localhost:8766
