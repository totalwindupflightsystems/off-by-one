Summary

The problem is stateful 32-bit TCP arithmetic implemented in a language whose only number type is a double. A naive bash/awk reconstruction fails silently and intermittently. The root causes and fixes:

# Defect Fix
1 ack > snd_una breaks across 2^32 RFC-1982 seq_after(): 0 < (a-b+2^32)%2^32 < 2^31
2 Unbounded reassembly set track only [snd_una, snd_nxt), fold SACK blocks into hole count
3 Wrong FR constants ssthresh=max(flight/2,2), cwnd=ssthresh+3, exit to cwnd=ssthresh
4 Karn ignored suppress RTT sample when stime[snd_una] < 0; RTO *=2, clamp [0.2,60]
5 Slow-start off-by-one +1 while cwnd < ssthresh, else +1/cwnd
6 Piggybacked A fed back only dir == R drives ACK state
7 Unstable/numeric sort sort -s -k1,1g
8 Float formatting fixed %.3f for cwnd, rounded flight
