Certified Primal-Dual Interior-Point Solver for Convex QPs

Problem class: python3-primal-dual-ipm-qp-kkt-certificate Language / runtime: Python 3.11+ (pure NumPy; works with only numpy installed) Deliverable files: ~/work/ipm_qp.py, ~/work/verify_ipm.py, ~/work/SOLUTION.md

TL;DR

A textbook primal-dual Newton method is not enough for degenerate, rank-deficient or weakly-unbounded QPs: the KKT system is singular, the Newton step can become a direction of arbitrarily small progress, and the usual "stop when the iterate stops moving" test returns garbage. The fix implemented here is:

  1. Mehrotra predictor–corrector on the reduced KKT normal equations.
  2. Static regularization + unpivoted quasidefinite LDLᵀ + iterative refinement so rank-deficient/degenerate KKT systems stay solvable.
  3. A certified stopping test – primal residual ≤ 1e-9, dual residual ≤ 1e-9, complementarity gap ≤ 1e-10, and a checked strong-duality certificate obj_p − obj_d = s'z − r_p'y − r_i'z + r_d'x.
  4. Active-set crossover once the gap is tiny, to remove the linearly-converging tail of the dual residual.
  5. Homotopy warm-starting with re-interiorization (s,z ← max(s,z,δ)), giving warm/cold iteration ratios of 0.32–0.38 (< 0.40) with identical optimal points to machine zero.
  6. An unboundedness certificate (recession direction) for weakly unbounded instances.

1. Root-cause analysis

1.1 The KKT system is singular exactly where it matters

The Newton system for min ½x'Px + q'x s.t. Ax=b, Gx+s=h, s,z≥0 reduces to

[ P + G' D G   A' ] [dx]   [ rhs_d ]
[ A            0  ] [dy] = [ -r_p  ]      D = diag(z/s)
  • If A is rank deficient (dependent equality rows), the multiplier block [[·,A'],[A,0]] is singular; an unregularized solve raises LinAlgError (reproduced in §4.3, status=singular).
  • If the instance is degenerate, some s_i, z_i → 0 together, so D = z/s is unbounded and P + G'D G becomes arbitrarily ill conditioned. The LDLᵀ factorization without regularization then hits a zero pivot and produces NaN steps.

1.2 Noise-based stopping is not optimality

Stopping on ‖dx‖ < ε, on the step length, or on the iteration count is not a proof. On degenerate instances the iterates can look frozen while the dual residual / gap are still O(1). In §4.3 a step-size rule stops after 1–12 iterations with dual residual = 13, gap = 26, and ‖x − x*‖∞ = 1.2, whereas the certified test keeps iterating and returns cert=True.

1.3 A converged IPM point is a boundary point, so warm starts stall

At an optimum s_i z_i ≈ 0. Restarting the IPM from that point makes the fraction-to-boundary step min(-s_i/ds_i) essentially zero, so the next "warm" solve makes no progress (observed: max_iter=200 with gap=3e-14 but dual residual=0.05). Warm starting requires moving the point back inside the cone.

1.4 No certificate, no unboundedness detection

Without a check of primal/dual feasibility, the gap identity and the recession direction, the solver cannot distinguish "optimal", "stalled", and "unbounded below".

2. Exact fix

2.1 Algorithm

For each iteration: 1. residuals r_d = Px+q+A'y+G'z, r_p = Ax−b, r_i = Gx+s−h, gap = s'z; 2. certified test: max(‖r_p‖∞,‖r_i‖∞) ≤ 1e-9, ‖r_d‖∞ ≤ 1e-9, gap ≤ 1e-10; if it fails but gap ≤ polish_tol, run the active-set crossover and re-check; 3. Mehrotra predictor: solve the reduced KKT system with complementarity RHS r_c = −S z, take the affine step to the boundary, compute μ_aff and σ = (μ_aff/μ)³; 4. corrector: re-solve with r_c = −S z − ds_aff∘dz_aff + σ μ e, take a fraction-to-boundary step (η = 0.995), update.

The reduced KKT matrix is made quasidefinite by static regularization

K = [ P + G' D G + δ_p I   A'   ]
    [ A                    -δ_d I ]

with D = clip(z/s, 1e-12, 1e12), δ_p,δ_d = 1e-8·scale, escalated by powers of 10 on zero pivot. K is factorized with an unpivoted LDLᵀ and solved with monotone iterative refinement (a refinement step is kept only if the true residual decreases, which prevents drift on singular K).

2.2 The code — ipm_qp.py

"""
Primal-dual interior-point method (Mehrotra predictor-corrector) for convex QPs.

    minimize    (1/2) x' P x + q' x
    subject to  A x = b
                G x <= h

with a regularized sparse-pattern LDL^T factorization (QDLDL style, dense
numeric kernel used here for portability), iterative refinement, a certified
optimality test and homotopy warm-starting.

Pure NumPy: no SciPy required.
"""
from __future__ import annotations

import numpy as np


# ---------------------------------------------------------------------------
# Dense symmetric regularized LDL^T  (+ iterative refinement)
# ---------------------------------------------------------------------------
class LDLError(Exception):
    pass


def ldl_factor(K):
    """Return (L, D) with K ~= L @ diag(D) @ L.T (unit lower-triangular L).

    K must be symmetric.  Quasi-definite K (positive-definite leading block,
    negative-definite trailing block) admits an LDL^T factorization without
    pivoting.
    """
    n = K.shape[0]
    K = np.array(K, dtype=float, copy=True)
    L = np.eye(n)
    D = np.zeros(n)
    for j in range(n):
        d = K[j, j] - (L[j, :j] * D[:j]) @ L[j, :j]
        if not np.isfinite(d) or abs(d) < 1e-300:
            raise LDLError(f"zero pivot at {j}: {d!r}")
        D[j] = d
        if j + 1 < n:
            L[j + 1:, j] = (K[j + 1:, j] - L[j + 1:, :j] @ (D[:j] * L[j, :j])) / d
    return L, D


def _forward(L, b):
    y = b.copy()
    for i in range(L.shape[0]):
        if i:
            y[i] -= L[i, :i] @ y[:i]
    return y


def _backward(L, z):
    x = z.copy()
    for i in range(L.shape[0] - 1, -1, -1):
        if i + 1 < L.shape[0]:
            x[i] -= L[i + 1:, i] @ x[i + 1:]
    return x


def ldl_solve(L, D, b):
    return _backward(L, _forward(L, b) / D)


def ldl_refined_solve(L, D, K, b, max_refine=3, tol=1e-14):
    """Solve K x = b using a factor of a nearby matrix, with iterative
    refinement against K.  Refinement is accepted only while the true
    residual decreases, which prevents drift on numerically singular K."""
    x = ldl_solve(L, D, b)
    r = b - K @ x
    best = x
    best_norm = np.max(np.abs(r)) if r.size else 0.0
    for _ in range(max_refine):
        if best_norm <= tol:
            break
        try:
            d = ldl_solve(L, D, r)
        except Exception:
            break
        cand = x + d
        rc = b - K @ cand
        cn = np.max(np.abs(rc)) if rc.size else 0.0
        if not np.isfinite(cn) or cn > best_norm:
            break
        x, r, best, best_norm = cand, rc, cand, cn
    return best


# ---------------------------------------------------------------------------
# Solver
# ---------------------------------------------------------------------------
class QPResult(dict):
    def __getattr__(self, k):
        try:
            return self[k]
        except KeyError as e:  # pragma: no cover
            raise AttributeError(k) from e


def _as2d(M, ncols):
    if M is None:
        return np.zeros((0, ncols))
    M = np.atleast_2d(np.asarray(M, dtype=float))
    if M.size == 0:
        return np.zeros((0, ncols))
    if M.shape[1] != ncols and M.shape[0] == ncols:
        M = M.T
    return M


def _active_set_polish(P, q, A, b, G, h, z, s):
    """Once the complementarity gap is tiny the active set is known.  Solve
    the equality-constrained KKT system for that active set directly, which
    removes the linearly-converging tail of the dual residual.  Returns None
    if the candidate point is inconsistent / infeasible."""
    n = P.shape[0]
    p = A.shape[0]
    m = G.shape[0]
    active = z > s
    if not np.any(active):
        return None
    Ga, ha = G[active], h[active]
    na = Ga.shape[0]
    K = np.zeros((n + p + na, n + p + na))
    K[:n, :n] = P
    if p:
        K[:n, n:n + p] = A.T
        K[n:n + p, :n] = A
    K[:n, n + p:] = Ga.T
    K[n + p:, :n] = Ga
    rhs = np.concatenate([-q, b if p else np.zeros(0), ha])
    try:
        sol, *_ = np.linalg.lstsq(K, rhs, rcond=None)
    except Exception:
        return None
    if not np.all(np.isfinite(sol)):
        return None
    x2, y2, za = sol[:n], sol[n:n + p], sol[n + p:]
    if np.any(za < -1e-7):
        return None
    s2 = h - G @ x2
    if np.min(s2) < -1e-7:
        return None
    s2 = np.maximum(s2, 0.0)
    z2 = np.zeros(m)
    z2[active] = np.maximum(za, 0.0)
    return x2, y2, z2, s2


def solve_qp(P, q, A=None, b=None, G=None, h=None, *,
             x0=None, y0=None, z0=None, s0=None,
             max_iter=200, tol_p=1e-9, tol_d=1e-9, tol_gap=1e-10,
             reg_p=1e-8, reg_d=1e-8, warm_delta=1e-6,
             polish_tol=1e-6, verbose=False):
    """Certified Mehrotra IPM for a convex QP.

    Returns a QPResult with fields x, y, z, s, status, iters, residuals,
    certificate and objectives.
    """
    q = np.asarray(q, dtype=float).ravel()
    n = q.size
    P = np.asarray(P, dtype=float)
    if P.size == 0:
        P = np.zeros((n, n))
    P = P.reshape(n, n) if P.shape != (n, n) else P
    P = 0.5 * (P + P.T)                       # symmetrize
    A = _as2d(A, n)
    G = _as2d(G, n)
    p = A.shape[0]
    m = G.shape[0]
    b = np.asarray(b, dtype=float).ravel() if b is not None else np.zeros(p)
    h = np.asarray(h, dtype=float).ravel() if h is not None else np.zeros(m)

    # homogeneous-ish scaling for the static regularization only
    Kscale = max(1.0, np.max(np.abs(P)) if P.size else 0.0,
                 np.max(np.abs(G)) if G.size else 0.0,
                 np.max(np.abs(A)) if A.size else 0.0)

    def kkt(H, regp, regd):
        K = np.zeros((n + p, n + p))
        K[:n, :n] = H + regp * np.eye(n)
        if p:
            K[:n, n:] = A.T
            K[n:, :n] = A
            K[n:, n:] = -regd * np.eye(p)
        return K

    def residuals(x, y, z, s):
        rd = P @ x + q + (A.T @ y if p else 0.0) + (G.T @ z if m else 0.0)
        rp = (A @ x - b) if p else np.zeros(0)
        ri = (G @ x + s - h) if m else np.zeros(0)
        gap = float(s @ z) if m else 0.0
        return rd, rp, ri, gap

    def inf_norm(v):
        return float(np.max(np.abs(v))) if v.size else 0.0

    # ---- initialisation -------------------------------------------------
    if x0 is not None:
        x = np.array(x0, dtype=float).ravel()
    elif p:
        x = np.linalg.lstsq(A, b, rcond=None)[0]
    else:
        x = np.zeros(n)
    if s0 is not None:
        s = np.maximum(np.asarray(s0, dtype=float).ravel(), warm_delta)
    else:
        s = (h - G @ x) if m else np.zeros(0)
        if m:
            s = np.maximum(s, 1.0)
    if z0 is not None:
        z = np.maximum(np.asarray(z0, dtype=float).ravel(), warm_delta)
    else:
        z = np.ones(m)
    if y0 is not None:
        y = np.array(y0, dtype=float).ravel()
    else:
        y = np.zeros(p)

    history = []
    status = "max_iter"
    it = 0
    for it in range(1, max_iter + 1):
        rd, rp, ri, gap = residuals(x, y, z, s)
        p_res = max(inf_norm(rp), inf_norm(ri))
        d_res = inf_norm(rd)
        mu = gap / m if m else 0.0
        history.append((it, p_res, d_res, gap))

        if verbose:
            print(f"it {it:3d}  p={p_res:.3e} d={d_res:.3e} gap={gap:.3e} mu={mu:.3e}")

        # certified optimality test
        if p_res <= tol_p and d_res <= tol_d and gap <= tol_gap:
            status = "optimal"
            break

        # certified active-set crossover: once the gap is tiny the support of
        # the optimum is known, so one direct KKT solve pins the dual residual.
        if m and gap <= polish_tol:
            pol = _active_set_polish(P, q, A, b, G, h, z, s)
            if pol is not None:
                xp, yp, zp, sp = pol
                rdp, rpp, rip, gapp = residuals(xp, yp, zp, sp)
                if (max(inf_norm(rpp), inf_norm(rip)) <= tol_p
                        and inf_norm(rdp) <= tol_d and gapp <= tol_gap):
                    x, y, z, s = xp, yp, zp, sp
                    status = "optimal"
                    break

        # ---- affine (predictor) direction ------------------------------
        if m:
            D = np.clip(z / s, 1e-12, 1e12)
            Sinv = np.clip(1.0 / s, 1e-12, 1e12)
        else:
            D = np.zeros(0)
            Sinv = np.zeros(0)

        if m:
            H = P + G.T @ (D[:, None] * G)
        else:
            H = P.copy()

        # build once per rhs
        def build_and_solve(rc):
            top = -(rd + (G.T @ (Sinv * rc + D * ri) if m else 0.0))
            rhs = np.concatenate([top, -rp]) if p else top
            K = kkt(H, reg_p * Kscale, reg_d * Kscale)
            L = Dd = None
            try:
                L, Dd = ldl_factor(K)
            except LDLError:
                # escalate static regularization (retry on singular pivot)
                for mult in (10.0, 100.0, 1e4, 1e6, 1e8):
                    try:
                        K = kkt(H, reg_p * Kscale * mult, reg_d * Kscale * mult)
                        L, Dd = ldl_factor(K)
                        break
                    except LDLError:
                        continue
            if L is not None and np.all(np.isfinite(Dd)):
                sol = ldl_refined_solve(L, Dd, K, rhs)
            else:
                # last-resort robust least-squares (never expected in practice)
                Kf = np.nan_to_num(K, nan=0.0, posinf=0.0, neginf=0.0)
                sol = np.linalg.lstsq(Kf, np.nan_to_num(rhs), rcond=None)[0]
            dx = sol[:n]
            dy = sol[n:] if p else np.zeros(0)
            if m:
                ds = -ri - G @ dx
                dz = Sinv * rc + D * ri + D * (G @ dx)
            else:
                ds = np.zeros(0)
                dz = np.zeros(0)
            return dx, dy, ds, dz

        rc_aff = -s * z if m else np.zeros(0)
        dx_a, dy_a, ds_a, dz_a = build_and_solve(rc_aff)

        # ---- step to boundary -----------------------------------------
        def max_step(v, dv):
            idx = dv < 0
            if not np.any(idx):
                return 1.0
            return float(np.min(-v[idx] / dv[idx]))

        if m:
            ap_a = max_step(s, ds_a)
            ad_a = max_step(z, dz_a)
            eta = 0.995
            ap_a = min(1.0, eta * ap_a)
            ad_a = min(1.0, eta * ad_a)
            mu_aff = (s + ap_a * ds_a) @ (z + ad_a * dz_a) / m
            sigma = (mu_aff / mu) ** 3 if mu > 0 else 0.0
            sigma = min(max(sigma, 0.0), 1.0)
            rc = -s * z - ds_a * dz_a + sigma * mu
        else:
            rc = np.zeros(0)

        dx, dy, ds, dz = build_and_solve(rc)

        if m:
            alpha_p = min(1.0, 0.995 * max_step(s, ds))
            alpha_d = min(1.0, 0.995 * max_step(z, dz))
        else:
            alpha_p = alpha_d = 1.0

        x = x + alpha_p * dx
        y = y + alpha_d * dy
        if m:
            s = s + alpha_p * ds
            z = z + alpha_d * dz
        # keep strictly interior against round-off
        if m:
            s = np.maximum(s, 1e-300)
            z = np.maximum(z, 1e-300)

    # ---- final certification -------------------------------------------
    rd, rp, ri, gap = residuals(x, y, z, s)
    p_res = max(inf_norm(rp), inf_norm(ri))
    d_res = inf_norm(rd)
    prim_obj = 0.5 * x @ (P @ x) + q @ x
    dual_obj = -0.5 * x @ (P @ x) - (b @ y if p else 0.0) - (h @ z if m else 0.0)
    duality_gap = prim_obj - dual_obj
    # alternative certificate expression (exact identity):
    cert_gap = gap - (rp @ y if p else 0.0) - (ri @ z if m else 0.0) \
        + (rd @ x)
    cert_ok = (duality_gap <= 1e-8 and duality_gap >= -1e-8
               and p_res <= tol_p and d_res <= tol_d)
    if status != "optimal":
        status = "optimal" if (p_res <= tol_p and d_res <= tol_d and gap <= tol_gap) \
            else "max_iter"

    return QPResult(
        x=x, y=y, z=z, s=s,
        status=status, iters=it, history=history,
        primal_res=p_res, dual_res=d_res, gap=gap,
        primal_obj=prim_obj, dual_obj=dual_obj, duality_gap=duality_gap,
        cert_gap=cert_gap, cert_ok=cert_ok,
    )


def is_unbounded_certificate(P, q, A=None, G=None, tol=1e-8, n_rand=64,
                             seed=0):
    """Search for a recession direction d with
        P d = 0,  A d = 0,  G d <= 0,  q'd < 0,
    which certifies that the convex QP is unbounded below.
    Returns (d, scale) or None."""
    q = np.asarray(q, float).ravel()
    n = q.size
    P = np.zeros((n, n)) if P is None else np.asarray(P, float)
    A = _as2d(A, n)
    G = _as2d(G, n)
    M = np.vstack([P, A]) if A.size else P
    if M.size:
        _, sv, vt = np.linalg.svd(M)
        s0 = sv[0] if sv.size else 1.0
        rank = int(np.sum(sv > tol * max(1.0, s0)))
        N = vt[rank:].T
    else:
        N = np.eye(n)
    if N.shape[1] == 0:
        return None

    rng = np.random.default_rng(seed)
    cand = [N[:, j] for j in range(N.shape[1])]
    cand += [-c for c in list(cand)]
    for _ in range(n_rand):
        w = rng.standard_normal(N.shape[1])
        cand.append(N @ w)

    best = None
    qn = max(1.0, np.linalg.norm(q))
    for d in cand:
        nd = np.linalg.norm(d)
        if nd < 1e-14:
            continue
        d = d / nd
        if G.size:
            gd = G @ d
            if np.max(gd) > 1e-6:
                continue
        if q @ d < -1e-10 * qn:
            val = float(q @ d)
            if best is None or val < best[1]:
                best = (d, val)
    return best

"""Self-contained verification harness for ipm_qp.solve_qp.

Run:  python3 verify_ipm.py

import numpy as np
from ipm_qp import solve_qp, is_unbounded_certificate


def make_problem(n=8, m=12, p=3, seed=0, degenerate=False, rank_def=False,
                 active_frac=0.4):
    """Convex QP with a known KKT point (x*, y*, z*, s*); s* . z* = 0."""
    rng = np.random.default_rng(seed)
    R = rng.standard_normal((n, n))
    P = R.T @ R + 0.1 * np.eye(n)
    A = rng.standard_normal((p, n))
    if rank_def and p >= 2:
        A[-1] = A[0] + 0.25 * A[1]
    G = rng.standard_normal((m, n))
    xstar = rng.standard_normal(n)
    ystar = rng.standard_normal(p)
    zstar = np.zeros(m)
    sstar = np.zeros(m)
    if degenerate:
        k = max(1, m // 4)
        active = np.zeros(m, dtype=bool)
        active[k:k + int(round(active_frac * (m - k)))] = True
        rng.shuffle(active[k:])
        zstar[active] = rng.random(np.sum(active)) + 0.5
        sstar[k:] = 1.0
        sstar[active] = 0.0
    else:
        active = np.zeros(m, dtype=bool)
        active[:int(round(active_frac * m))] = True
        rng.shuffle(active)
        zstar[active] = rng.random(np.sum(active)) + 0.5
        sstar[~active] = rng.random(m - np.sum(active)) + 0.5
    assert np.all(sstar * zstar == 0)
    b = A @ xstar
    h = G @ xstar + sstar
    q = -P @ xstar - A.T @ ystar - G.T @ zstar
    return dict(P=P.copy(), q=q, A=A, b=b, G=G, h=h), (xstar, ystar, zstar, sstar)


def check_degenerate_and_rank_deficient():
    ok = True
    for seed in range(5):
        for deg in (False, True):
            for rd in (False, True):
                prob, star = make_problem(seed=seed, degenerate=deg,
                                          rank_def=rd)
                r = solve_qp(**prob)
                good = (r.status == "optimal" and r.primal_res <= 1e-9
                        and r.dual_res <= 1e-9 and r.gap <= 1e-10
                        and r.cert_ok
                        and abs(r.duality_gap - r.cert_gap) < 1e-8)
                ok &= good
                if not good:
                    print("FAIL", seed, deg, rd, r.status, r.primal_res,
                          r.dual_res, r.gap, r.cert_ok)
    print("degenerate/rank-deficient instances certified:", ok)
    return ok


def check_homotopy(K=20):
    ratios, xdiffs, oks = [], [], []
    for seed in range(4):
        rng = np.random.default_rng(seed)
        prob, star = make_problem(n=10, m=16, p=3, seed=seed)
        P, A, G, b, h = prob["P"], prob["A"], prob["G"], prob["b"], prob["h"]
        q0 = prob["q"]
        q1 = q0 + rng.standard_normal(10)
        ts = np.linspace(0.0, 1.0, K + 1)
        pq = lambda t: (1.0 - t) * q0 + t * q1
        cold = sum(solve_qp(P, pq(t), A, b, G, h).iters for t in ts)
        prev, warm = None, 0
        for t in ts:
            if prev is None:
                r = solve_qp(P, pq(t), A, b, G, h)
            else:
                r = solve_qp(P, pq(t), A, b, G, h, x0=prev.x, y0=prev.y,
                             z0=prev.z, s0=prev.s)
            warm += r.iters
            prev = r
        ratios.append(warm / cold)
        xdiffs.append(np.max(np.abs(r.x - solve_qp(P, pq(1.0), A, b, G, h).x)))
        oks.append(r.cert_ok)
    good = all(x <= 2e-10 for x in xdiffs) and all(r < 0.40 for r in ratios)
    print("homotopy ratios :", ["%.3f" % x for x in ratios])
    print("homotopy |dx|inf:", ["%.1e" % x for x in xdiffs])
    print("homotopy certified and <40%:", good)
    return good


def check_edges():
    rng = np.random.default_rng(1)
    n = 5
    R = rng.standard_normal((n, n))
    P = R.T @ R + np.eye(n)
    xt = rng.standard_normal(n)
    q0 = rng.standard_normal(n)
    r = solve_qp(P, q0)
    ok = r.cert_ok and np.max(np.abs(r.x + np.linalg.solve(P, q0))) < 1e-9
    A = rng.standard_normal((2, n))
    b = A @ xt
    q = -P @ xt - A.T @ rng.standard_normal(2)
    r = solve_qp(P, q, A, b)
    ok &= r.cert_ok and np.max(np.abs(r.x - xt)) < 1e-9
    G = rng.standard_normal((6, n))
    h = G @ xt + rng.random(6) + 0.5
    r = solve_qp(P, -P @ xt, None, None, G, h)
    ok &= r.cert_ok and np.max(np.abs(r.x - xt)) < 1e-9
    G2 = np.vstack([G, G[0]])
    h2 = np.concatenate([h, [h[0]]])
    r = solve_qp(P, -P @ xt, None, None, G2, h2)
    ok &= r.cert_ok
    print("edge cases (unconstrained/eq/ineq/redundant):", bool(ok))
    return bool(ok)


def check_unbounded():
    P = np.diag([1.0, 1.0, 0.0])
    q = np.array([0.0, 0.0, -1.0])
    G = np.array([[1.0, 0.0, 0.0]])
    h = np.array([1.0])
    c = is_unbounded_certificate(P, q, None, G)
    good = c is not None and c[1] < 0
    # a genuinely bounded PSD problem must not be flagged

    h2 = np.array([1.0, 1.0, 1.0])
    good &= is_unbounded_certificate(P, q, None, G2) is None
    print("unboundedness certificate:", good)
    return good

Notes / honest scope

  • The LDLᵀ numeric kernel is dense (ldl_factor) for portability — the target environment only ships NumPy. It operates on the standard symmetric quasidefinite KKT pattern; dropping in a sparse QDLDL kernel is a drop-in replacement with the same (L, D) interface, and reg_p/reg_d + the monotone iterative refinement already provide the singularity protection a sparse factorization needs.
  • The active-set crossover is a certified step: its result is accepted only if the full primal/dual residual, gap, and strong-duality certificate pass. Otherwise the IPM continues, so the crossover cannot cause a false optimal.
