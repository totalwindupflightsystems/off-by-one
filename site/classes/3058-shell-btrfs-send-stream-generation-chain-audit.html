Root cause (why naive audits fail)

  1. Field-prefix confusion — UUID: vs Parent UUID:/Received UUID:; matching *UUID* records the wrong value.
  2. Wrong generation domain — a received subvolume's local Generation is the receiver's transaction; generation must only order source snapshots, while receive-side parentage is proven with Received UUID (the join key btrfs receive uses).
  3. TOCTOU / concurrency — snapshots change/are deleted mid-audit; one show is a point-in-time lie.
  4. Hostile filenames — spaces, TAB/LF/CR, leading -, quotes, %, globs break word-splitting and line-based formats.
  5. Missing ≠ contradictory — absent metadata and disagreeing metadata require different fixes.
  6. Nondeterministic "first" error — ${!assoc[@]} iteration order is unspecified.
  7. Interrupted receives — a copy with no Received UUID and a short stream must be detected.

Exact fix

A Bash tool split into a pure deterministic graph audit and an optional live probe layer (--probe): - Manifest is TAB-separated records with percent-encoded values so raw TAB/LF/CR/%/\ can never break parsing; all output re-encoded. No eval, no unquoted expansion, -- on every command. - Findings carry class=missing|contradictory|race|info|broken, a stable order, fixed JSON key order, exactly one "earliest":true, and a SUMMARY line. Exit codes 0/1/2/3. - Earliest broken link = min (order, code, node) over broken-chain codes (no hash-order dependence). - Probes: btrfs subvolume show --, findmnt -T … FSTYPE,FSID, btrfs subvolume list …, btrfs receive --dump -f, stat before/after, optional sha256sum, flock. - Race strategy: flock serialization, findmnt FSID pinning, double-read generation with bounded retries → RACE_DETECTED, stream stat window, and no unbounded polling.

Verification

The sandbox is rootless tmpfs with no Btrfs (/proc/filesystems empty, no btrfs, sudo blocked). So the suite tests the pure audit directly and drives the probe path through a mock that emits the real command text layout. bash tests/run_tests.sh gives RESULT: 30 passed, 0 failed, covering: clean full→incremental chains, earliest broken link, missing vs contradictory, generation regression, interrupted receive, truncated stream, branch points (info, non-fatal), duplicate UUID, 9 hostile filenames round-tripping byte-for-byte, probe enrichment + contradictions, race detection + --strict, byte-identical reruns, valid JSON (jq -e), and exit codes 0/1/2/3.
