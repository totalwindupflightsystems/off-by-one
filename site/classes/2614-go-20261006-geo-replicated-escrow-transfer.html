Geo-Replicated Escrow Transfer Engine

Problem class: go-20261006-geo-replicated-escrow-transfer · Go 1.26

Working module: ~/escrow · Full write-up: ~/SOLUTION.md · Verified with go vet + go test -race -count=2.

Root-cause analysis

A naive replicated transfer engine that debits and credits a single replicated balance cannot satisfy the requirements at once:

  1. Availability during a partition forces each region to decide with only local knowledge.
  2. Per-account lower bounds are a global invariant: two partitioned regions each seeing 100 and each spending 100 merge to −100.
  3. Rights reallocation and restart from a stale snapshot are the two ways a node acts on a superseded view; both must be fenced.
  4. Duplication and reordering mean a debit/credit pair can be applied many times, in any order, so operations must be idempotent and order-independent.

Root cause: treating spend authority as global and mutable. The fix is to make authority a pre-partitioned, single-owner, fenced resource — an escrow grant — and to make replicated state a grow-only set whose semantics are derived, not mutated. Lower-bound enforcement becomes a local, quorum-free check (remaining(grant) >= amount); convergence is recovered by anti-entropy.

The exact fix: escrow grants with owner-fenced revocation

1. Replicated metadata

Item Meaning Merge rule
Account.Base, Account.Limit genesis balance, lower bound static
Grant{ID,Acct,Owner,Amount,Epoch,State} a slice of capacity owned by exactly one node create-once; Live → Revoking → Revoked
Grant.Accepted owner's final spend set, fixed at revocation union
Transfer{TxID,Src,Dst,Grant,Owner,Amount} a debit from a grant plus a credit grow-only set (Known)

All divergent state is a join-semilattice (grow-only set + monotonic grant states). There is no last-writer-wins field, so duplication and reordering are harmless.

2. Derived state (order-independent)

accepted(t)  = grant(t.Grant) exists AND owner matches
               AND (grant not revoked OR t ∈ grant.Accepted)
Balance(a)   = Base(a) + Σ accepted inbound  − Σ accepted outbound
Escrowed(a)  = Σ over live/revoking grants (Amount − Σ accepted spends)
Free(a)      = Balance(a) − Limit(a) − Escrowed(a)
Invariant:     Balance(a) ≥ Limit(a)   and   Free(a) ≥ 0

accepted(t) is evaluated against current grant state, so a late spend arriving after a revocation is discarded on every replica — no coordination, no lock.

3. Protocols

Transfer (data plane, no quorum). The owner picks a Live grant it owns with enough remaining, records the transfer locally, and gossips it. Replicas union it into Known. Only one node may spend a grant and grants never exceed capacity, so the lower bound holds in every partition.

Allocate (control plane, quorum). free is conservative: live grants lock their full Amount, revoked grants lock only Accepted. A grant is issued only if amount ≤ free. Control metadata commits by quorum, so a stranded minority cannot create money.

Revoke / reallocate (owner-fenced). 1. Fence: mark the grant Revoking (only Live grants are eligible for Spend). 2. Report: the owner returns its exact spend set Accepted. 3. Commit: Amount − ΣAccepted becomes free and is re-issued with a higher Epoch.

If the owner is unreachable the revocation stalls — refusing progress is the correct trade for safety.

Recovery. A restarted node is Recovering and refuses all spends until it replays the committed control log (including Revoked). A snapshot older than a revocation cannot resurrect a revoked grant.

4. Complete implementation

escrow.go — replicated metadata, derived state, invariant checker.

// Package escrow implements a geo-replicated escrow transfer engine.
//
// Safety model
//
//  Capacity(acct) = Base + accepted inbound credits - Limit
//  Locked(acct)   = sum over live grants of Grant.Amount
//                 + sum over revoked grants of accepted spent amount
//  Free(acct)     = Capacity - Locked
//
// A grant is exclusively owned by exactly one node.  Only the owner may
// turn a grant into debits.  A debit is executed against the owner's local
// view and then replicated as an idempotent operation.  Because grants for
// one account are disjoint slices of capacity and because only one node may
// spend a slice, per-account lower bounds hold without any lock that spans
// accounts or regions.
//
// Reallocation (revocation then re-issue) is owner-fenced: the authority
// first asks the owner to stop and to report the exact set of debits it ever
// produced; only then is the remainder declared free.  A restarted node must
// replay the committed control log before it may spend, which is what makes a
// restart from a stale snapshot safe.
package escrow

import (
    "fmt"
    "sort"
)

type AcctID string
type NodeID string
type GrantID string
type TxID string

type GrantState int

const (
    Live GrantState = iota
    Revoking
    Revoked
)

func (s GrantState) String() string {
    switch s {
    case Live:
        return "Live"
    case Revoking:
        return "Revoking"
    case Revoked:
        return "Revoked"
    }
    return "?"
}

// Grant is a slice of an account's spendable capacity that has been handed to
// one owner.  Epoch is a fencing token: an owner may only spend while it holds
// the newest epoch it knows about and while the grant is Live.
type Grant struct {
    ID       GrantID
    Acct     AcctID
    Owner    NodeID
    Amount   int64
    Epoch    uint64
    State    GrantState
    Accepted map[TxID]int64 // spend set fixed at revocation time
}

// Account is the replicated per-account metadata.  Credits is not stored
// directly: it is derived from the set of accepted transfers, which makes
// replay, duplication and reordering harmless.
type Account struct {
    Limit  int64
    Base   int64
    Grants map[GrantID]*Grant
}

// Transfer is the only mutating data-plane operation.  It carries the grant it
// draws from and the owner that produced it, which is enough for any replica to
// independently decide, order-independently, whether the debit/credit pair is
// accepted.
type Transfer struct {
    TxID   TxID
    Src    AcctID
    Dst    AcctID
    Grant  GrantID
    Owner  NodeID
    Amount int64
}

// Replica is one copy of the replicated metadata plus the local grant
// authority of the node that owns it.
type Replica struct {
    ID         NodeID
    Accounts   map[AcctID]*Account
    Known      map[TxID]Transfer // union of every transfer ever seen
    Recovering bool              // true while replaying the control log
}

func NewReplica(id NodeID) *Replica {
    return &Replica{
        ID:       id,
        Accounts: map[AcctID]*Account{},
        Known:    map[TxID]Transfer{},
    }
}

func (r *Replica) InitAccount(acct AcctID, base, limit int64) error {
    if base < limit {
        return fmt.Errorf("base %d below limit %d", base, limit)
    }
    if _, ok := r.Accounts[acct]; ok {
        return nil
    }
    r.Accounts[acct] = &Account{Limit: limit, Base: base, Grants: map[GrantID]*Grant{}}
    return nil
}

func (r *Replica) grant(gid GrantID) *Grant {
    for _, a := range r.Accounts {
        if g, ok := a.Grants[gid]; ok {
            return g
        }
    }
    return nil
}

// ApplyAlloc installs a grant.  It is idempotent: repeated delivery is a no-op.
func (r *Replica) ApplyAlloc(g Grant) {
    a := r.Accounts[g.Acct]
    if a == nil {
        return
    }
    if _, ok := a.Grants[g.ID]; ok {
        return
    }
    cp := g
    cp.Accepted = map[TxID]int64{}
    if cp.State == 0 {
        cp.State = Live
    }
    a.Grants[g.ID] = &cp
}

// ApplyBeginRevoke fences a live grant.  The owner will no longer choose it for
// new debits because only Live grants are eligible.
func (r *Replica) ApplyBeginRevoke(gid GrantID) {
    if g := r.grant(gid); g != nil && g.State == Live {
        g.State = Revoking
    }
}

// ApplyCommitRevoke finalises a revocation with the owner's exact spend set.
// Spends that are not in the set are fenced out for good, on every replica.
func (r *Replica) ApplyCommitRevoke(gid GrantID, accepted map[TxID]int64) {
    g := r.grant(gid)
    if g == nil {
        return
    }
    g.State = Revoked
    if g.Accepted == nil {
        g.Accepted = map[TxID]int64{}
    }
    for tx, amt := range accepted {
        g.Accepted[tx] = amt
    }
}

// ApplyTransfer records a transfer in the grow-only set.  It never fails and is
// independent of arrival order or duplication.  Acceptance is derived later.
func (r *Replica) ApplyTransfer(t Transfer) {
    if _, ok := r.Known[t.TxID]; ok {
        return
    }
    r.Known[t.TxID] = t
}

// isAccepted decides whether a transfer's debit and credit both count.
func (r *Replica) isAccepted(t Transfer) bool {
    g := r.grant(t.Grant)
    if g == nil || g.Owner != t.Owner {
        return false
    }
    if g.State == Revoked {
        _, ok := g.Accepted[t.TxID]
        return ok
    }
    return true
}

// spendSum is the accepted amount drawn from a grant.
func (r *Replica) spendSum(g *Grant) int64 {
    var sum int64
    for _, t := range r.Known {
        if t.Grant != g.ID || t.Owner != g.Owner {
            continue
        }
        if g.State == Revoked {
            if _, ok := g.Accepted[t.TxID]; !ok {
                continue
            }
        }
        sum += t.Amount
    }
    return sum
}

func (r *Replica) credits(acct AcctID) int64 {
    var sum int64
    for _, t := range r.Known {
        if t.Dst == acct && r.isAccepted(t) {
            sum += t.Amount
        }
    }
    return sum
}

func (r *Replica) debits(acct AcctID) int64 {
    var sum int64
    for _, t := range r.Known {
        if t.Src == acct && r.isAccepted(t) {
            sum += t.Amount
        }
    }
    return sum
}

// Balance is derived from the grow-only transfer set.
func (r *Replica) Balance(acct AcctID) int64 {
    a := r.Accounts[acct]
    if a == nil {
        return 0
    }
    return a.Base + r.credits(acct) - r.debits(acct)
}

// Escrowed is the amount still locked in live or revoking grants.
func (r *Replica) Escrowed(acct AcctID) int64 {
    a := r.Accounts[acct]
    if a == nil {
        return 0
    }
    var sum int64
    for _, g := range a.Grants {
        if g.State == Revoked {
            continue
        }
        sum += g.Amount - r.spendSum(g)
    }
    return sum
}

// Remaining is what the owner can still spend from a grant.
func (r *Replica) Remaining(gid GrantID) int64 {
    g := r.grant(gid)
    if g == nil {
        return 0
    }
    return g.Amount - r.spendSum(g)
}

// CheckInvariant verifies the per-account lower bound and that no grant is
// over-spent.  It is the property the whole protocol exists to preserve.
func (r *Replica) CheckInvariant() error {
    for acct, a := range r.Accounts {
        bal := r.Balance(acct)
        esc := r.Escrowed(acct)
        if esc < 0 {
            return fmt.Errorf("account %s: negative escrow %d", acct, esc)
        }
        if bal < a.Limit {
            return fmt.Errorf("account %s: balance %d below limit %d", acct, bal, a.Limit)
        }
        if bal-a.Limit < esc {
            return fmt.Errorf("account %s: capacity %d below escrow %d", acct, bal-a.Limit, esc)
        }
    }
    return nil
}

// AcceptedSpent is what an owner reports when asked to stop spending a grant.
func (r *Replica) AcceptedSpent(gid GrantID) map[TxID]int64 {
    g := r.grant(gid)
    out := map[TxID]int64{}
    if g == nil {
        return out
    }
    for _, t := range r.Known {
        if t.Grant == gid && t.Owner == g.Owner {
            out[t.TxID] = t.Amount
        }
    }
    return out
}

// ChooseGrant picks a live grant owned by this replica that can fund amount.
// Deterministic ordering keeps simulations reproducible.
func (r *Replica) ChooseGrant(acct AcctID, amount int64) *Grant {
    a := r.Accounts[acct]
    if a == nil {
        return nil
    }
    ids := make([]string, 0, len(a.Grants))
    for id := range a.Grants {
        ids = append(ids, string(id))
    }
    sort.Strings(ids)
    for _, id := range ids {
        g := a.Grants[GrantID(id)]
        if g.Owner == r.ID && g.State == Live && r.Remaining(g.ID) >= amount {
            return g
        }
    }
    return nil
}

// Spend is the local, quorum-free debit path.  It only succeeds against a
// live grant owned by this replica; it must refuse while recovering.
func (r *Replica) Spend(src, dst AcctID, amount int64, tx TxID) (Transfer, bool) {
    if r.Recovering || amount <= 0 {
        return Transfer{}, false
    }
    g := r.ChooseGrant(src, amount)
    if g == nil {
        return Transfer{}, false
    }
    t := Transfer{TxID: tx, Src: src, Dst: dst, Grant: g.ID, Owner: r.ID, Amount: amount}
    r.ApplyTransfer(t)
    return t, true
}

// MergeKnown performs anti-entropy: the union of two grow-only transfer sets.
func (r *Replica) MergeKnown(other *Replica) {
    for tx, t := range other.Known {
        if _, ok := r.Known[tx]; !ok {
            r.Known[tx] = t
        }
    }
}

// MergeGrants synchronises control metadata after a partition.  The stricter
// (more advanced) state wins, so a stale snapshot can only be made safer.
func (r *Replica) MergeGrants(other *Replica) {
    for acct, oa := range other.Accounts {
        ra := r.Accounts[acct]
        if ra == nil {
            continue
        }
        for gid, og := range oa.Grants {
            rg, ok := ra.Grants[gid]
            if !ok {
                cp := *og
                cp.Accepted = map[TxID]int64{}
                for k, v := range og.Accepted {
                    cp.Accepted[k] = v
                }
                ra.Grants[gid] = &cp
                continue
            }
            if og.State > rg.State {
                rg.State = og.State
            }
            if rg.Accepted == nil {
                rg.Accepted = map[TxID]int64{}
            }
            for k, v := range og.Accepted {
                rg.Accepted[k] = v
            }
        }
    }
}

cluster.go — authority, quorum/partition/restart model, anti-entropy.

package escrow

import (
    "errors"
    "fmt"
    "math/rand"
    "sort"
)

// Envelope is an undelivered data-plane message.
type Envelope struct {
    To NodeID
    T  Transfer
}

// Cluster glues replicas, a quorum-replicated authority and a lossy,
// duplicating, reordering network together.  It is intentionally small: it
// models exactly the hazards named in the problem statement.
type Cluster struct {
    Replicas  map[NodeID]*Replica
    order     []NodeID
    Leader    NodeID
    rng       *rand.Rand
    inflight  []Envelope
    held      []Envelope
    partition map[NodeID]int
    down      map[NodeID]bool
    // authority metadata
    epoch  map[AcctID]uint64
    grants map[GrantID]*Grant
    quorum int
    txSeq  int
}

func NewCluster(n int, seed int64) *Cluster {
    c := &Cluster{
        Replicas:  map[NodeID]*Replica{},
        rng:       rand.New(rand.NewSource(seed)),
        partition: map[NodeID]int{},
        down:      map[NodeID]bool{},
        epoch:     map[AcctID]uint64{},
        grants:    map[GrantID]*Grant{},
        quorum:    n/2 + 1,
    }
    for i := 0; i < n; i++ {
        id := NodeID(fmt.Sprintf("n%d", i))
        c.Replicas[id] = NewReplica(id)
        c.order = append(c.order, id)
    }
    c.Leader = c.order[0]
    return c
}

func (c *Cluster) Nodes() []NodeID { return c.order }

func (c *Cluster) Replica(id NodeID) *Replica { return c.Replicas[id] }

// InitAccount creates the account on every replica and in the authority base.
func (c *Cluster) InitAccount(acct AcctID, base, limit int64) error {
    for _, id := range c.order {
        if err := c.Replicas[id].InitAccount(acct, base, limit); err != nil {
            return err
        }
    }
    return nil
}

// upInPartition counts live replicas in partition p.
func (c *Cluster) upInPartition(p int) int {
    n := 0
    for _, id := range c.order {
        if !c.down[id] && c.partition[id] == p {
            n++
        }
    }
    return n
}

// actingLeader returns a replica whose partition currently holds a quorum,
// preferring the existing leader.  This models leader election: when the old
// leader is stranded in a minority, the majority elects a new one.
func (c *Cluster) actingLeader() NodeID {
    if c.upInPartition(c.partition[c.Leader]) >= c.quorum {
        return c.Leader
    }
    seen := map[int]bool{}
    ps := []int{}
    for _, id := range c.order {
        p := c.partition[id]
        if !seen[p] {
            seen[p] = true
            ps = append(ps, p)
        }
    }
    sort.Ints(ps)
    for _, p := range ps {
        if c.upInPartition(p) < c.quorum {
            continue
        }
        for _, id := range c.order {
            if c.partition[id] == p && !c.down[id] {
                return id
            }
        }
    }
    return ""
}

// ensureLeader elects a reachable leader and replays committed control state
// into it so Free uses an up-to-date view.
func (c *Cluster) ensureLeader() NodeID {
    l := c.actingLeader()
    if l == "" {
        return ""
    }
    if l != c.Leader {
        c.Leader = l
        // Replay committed control state into the new leader so its derived
        // capacity view is current.
        for gid, g := range c.grants {
            c.Replicas[l].ApplyAlloc(*g)
            if g.State == Revoking || g.State == Revoked {
                c.Replicas[l].ApplyBeginRevoke(gid)
            }
            if g.State == Revoked {
                c.Replicas[l].ApplyCommitRevoke(gid, g.Accepted)
            }
        }
    }
    return l
}

// SetDown simulates a crashed replica.  Crashed replicas neither receive
// messages nor participate in quorum until Restart.
func (c *Cluster) SetDown(id NodeID, down bool) {
    if down {
        c.down[id] = true
        return
    }
    delete(c.down, id)
    // A restarted node is stale until it has replayed the committed control
    // log.  We model that by marking it recovering and replaying grants.
    r := c.Replicas[id]
    r.Recovering = true
    r.MergeGrants(c.Replicas[c.Leader])
    // A recovered node must not trust grants the authority already revoked.
    for gid, g := range c.grants {
        if g.State == Revoked {
            r.ApplyCommitRevoke(gid, g.Accepted)
        } else if g.State == Revoking {
            r.ApplyBeginRevoke(gid)
        } else {
            r.ApplyAlloc(*g)
        }
    }
    r.Recovering = false
}

// Partition assigns a partition id; nodes with different ids cannot exchange
// messages.  Heal restores the default partition 0.
func (c *Cluster) Partition(id NodeID, p int) { c.partition[id] = p }
func (c *Cluster) Heal() {
    c.partition = map[NodeID]int{}
    c.inflight = append(c.inflight, c.held...)
    c.held = nil
}

func (c *Cluster) samePartition(a, b NodeID) bool {
    return c.partition[a] == c.partition[b]
}

// reachable reports whether the authority at Leader can push control state to
// id right now.
func (c *Cluster) reachable(id NodeID) bool {
    return !c.down[id] && c.samePartition(id, c.Leader)
}

// Alloc asks the authority to create a grant.  It is refused when a quorum is
// not reachable: the control plane is available only inside a majority.
func (c *Cluster) Alloc(acct AcctID, owner NodeID, amount int64) (*Grant, error) {
    if c.Replicas[owner] == nil {
        return nil, errors.New("unknown owner")
    }
    if c.ensureLeader() == "" {
        return nil, errors.New("no quorum")
    }
    if amount <= 0 {
        return nil, errors.New("non-positive grant")
    }
    if c.Free(acct) < amount {
        return nil, fmt.Errorf("account %s free %d < %d", acct, c.Free(acct), amount)
    }
    c.epoch[acct]++
    g := &Grant{
        ID:       GrantID(fmt.Sprintf("%s-e%d", acct, c.epoch[acct])),
        Acct:     acct,
        Owner:    owner,
        Amount:   amount,
        Epoch:    c.epoch[acct],
        State:    Live,
        Accepted: map[TxID]int64{},
    }
    c.grants[g.ID] = g
    for _, id := range c.order {
        if c.reachable(id) {
            c.Replicas[id].ApplyAlloc(*g)
        }
    }
    return g, nil
}

// Free implements the conservative authority capacity equation.  Live grants
// lock their full amount; revoked grants lock only the owner's reported spend.
func (c *Cluster) Free(acct AcctID) int64 {
    c.ensureLeader()
    lead := c.Replicas[c.Leader]
    a := lead.Accounts[acct]
    if a == nil {
        return 0
    }
    capacity := a.Base + lead.credits(acct) - a.Limit
    var locked int64
    for _, g := range c.grants {
        if g.Acct != acct {
            continue
        }
        if g.State == Revoked {
            for _, amt := range g.Accepted {
                locked += amt
            }
        } else {
            locked += g.Amount
        }
    }
    return capacity - locked
}

// BeginRevoke fences the grant, collects the owner's final spend set and
// commits the revocation.  A quorum is required to commit control state.
func (c *Cluster) BeginRevoke(gid GrantID) (map[TxID]int64, error) {
    g := c.grants[gid]
    if g == nil {
        return nil, errors.New("unknown grant")
    }
    if c.ensureLeader() == "" {
        return nil, errors.New("no quorum")
    }
    if g.State != Live {
        return nil, fmt.Errorf("grant %s not live", gid)
    }
    // Phase 1: fence every replica that can hear us.
    for _, id := range c.order {
        if c.reachable(id) {
            c.Replicas[id].ApplyBeginRevoke(gid)
        }
    }
    // The owner must itself be fenced before we trust its report.  If it is
    // unreachable the revocation stalls; that is the price of safety.
    owner := c.Replicas[g.Owner]
    if c.down[g.Owner] || !c.samePartition(g.Owner, c.Leader) {
        return nil, fmt.Errorf("owner %s unreachable: revocation stalled", g.Owner)
    }
    accepted := owner.AcceptedSpent(gid)
    // Phase 2: commit the fencing set on the authority and on quorum replicas.
    g.State = Revoked
    g.Accepted = map[TxID]int64{}
    for tx, amt := range accepted {
        g.Accepted[tx] = amt
    }
    for _, id := range c.order {
        if c.reachable(id) {
            c.Replicas[id].ApplyCommitRevoke(gid, accepted)
        }
    }
    return accepted, nil
}

// Deliver randomly delivers, with duplication, one in-flight message, honouring
// partitions.  Duplication is modelled by re-inserting a copy sometimes.
func (c *Cluster) Deliver() bool {
    if len(c.inflight) == 0 {
        return false
    }
    // Reorder: pick a random message, not necessarily the oldest.
    i := c.rng.Intn(len(c.inflight))
    e := c.inflight[i]
    c.inflight = append(c.inflight[:i], c.inflight[i+1:]...)
    if c.down[e.To] {
        return true
    }
    if !c.samePartition(e.To, e.T.Owner) {
        // Crossing a partition: hold it for delivery after healing.
        c.held = append(c.held, e)
        return true
    }
    c.Replicas[e.To].ApplyTransfer(e.T)
    // Duplicate 1/3 of the time.
    if c.rng.Intn(3) == 0 {
        c.inflight = append(c.inflight, e)
    }
    return true
}

// Pending reports how many messages are queued.
func (c *Cluster) Pending() int { return len(c.inflight) }

// Spend performs a local debit and enqueues it to every peer.  It does not
// need a quorum, which is exactly why transfers stay available in a minority.
func (c *Cluster) Spend(owner NodeID, src, dst AcctID, amount int64) (Transfer, bool) {
    c.txSeq++
    tx := TxID(fmt.Sprintf("tx-%d", c.txSeq))
    t, ok := c.Replicas[owner].Spend(src, dst, amount, tx)
    if !ok {
        return Transfer{}, false
    }
    for _, id := range c.order {
        if id == owner {
            continue
        }
        c.inflight = append(c.inflight, Envelope{To: id, T: t})
    }
    return t, true
}

// Drain delivers everything.  Because the network may reorder, we loop until
// no messages remain; duplicates are removed by ApplyTransfer.
func (c *Cluster) Drain() {
    for c.Pending() > 0 {
        c.Deliver()
    }
}

// Gossip is anti-entropy after a partition heals: union the grow-only sets and
// the control metadata until a fixpoint.  It demonstrates convergence.
func (c *Cluster) Gossip() {
    for round := 0; round < len(c.order)+1; round++ {
        for _, a := range c.order {
            for _, b := range c.order {
                if a == b || c.down[a] || c.down[b] {
                    continue
                }
                c.Replicas[a].MergeKnown(c.Replicas[b])
                c.Replicas[a].MergeGrants(c.Replicas[b])
            }
        }
    }
}

// CheckAll returns the first safety violation found on any replica.
func (c *Cluster) CheckAll() error {
    ids := append([]NodeID(nil), c.order...)
    sort.Slice(ids, func(i, j int) bool { return ids[i] < ids[j] })
    for _, id := range ids {
        if c.down[id] {
            continue
        }
        if err := c.Replicas[id].CheckInvariant(); err != nil {
            return fmt.Errorf("replica %s: %w", id, err)
        }
    }
    return nil
}

// Converged reports whether all up replicas agree on derived balances and grant
// states for every account.
func (c *Cluster) Converged(accts []AcctID) bool {
    up := []NodeID{}
    for _, id := range c.order {
        if !c.down[id] {
            up = append(up, id)
        }
    }
    if len(up) == 0 {
        return true
    }
    ref := c.Replicas[up[0]]
    for _, id := range up[1:] {
        r := c.Replicas[id]
        for _, acct := range accts {
            if r.Balance(acct) != ref.Balance(acct) {
                return false
            }
            if len(r.Known) != len(ref.Known) {
                return false
            }
        }
    }
    return true
}

// TotalDebits is the sum of accepted debits over all accounts, used to prove
// conservation (total money never grows).
func (c *Cluster) TotalDebits(accts []AcctID) int64 {
    r := c.Replicas[c.Leader]
    var total int64
    for _, a := range accts {
        total += r.debits(a)
    }
    return total
}

// TotalCredits is the sum of accepted credits over all accounts.
func (c *Cluster) TotalCredits(accts []AcctID) int64 {
    r := c.Replicas[c.Leader]
    var total int64
    for _, a := range accts {
        total += r.credits(a)
    }
    return total
}

// TestBasicTransfersWithDuplicationAndReordering exercises the data plane under
// duplicated, reordered delivery.  Per-account lower bounds must never break and
// all replicas must converge.
func TestBasicTransfersWithDuplicationAndReordering(t *testing.T) {
    c, accts := newBank(t, 5, 1)
    if _, err := c.Alloc("alice", "n1", 900); err != nil {
        t.Fatalf("alloc: %v", err)
    }
    for i := 0; i < 200; i++ {
        if _, ok := c.Spend("n1", "alice", "carol", 7); !ok {
            break
        }
    }
    c.Drain()
    c.Gossip()
    if err := c.CheckAll(); err != nil {
        t.Fatalf("safety: %v", err)
    }
    if !c.Converged(accts) {
        t.Fatal("replicas did not converge")
    }
    // alice spent at most the grant, never dipping below her limit.
    if bal := c.Replica("n1").Balance("alice"); bal < 100 {
        t.Fatalf("alice balance %d below limit", bal)
    }
}

// TestReallocationRace reproduces the transfer/reallocation race directly:
// a grant is spent while it is being revoked, then its remainder is re-issued.
// The total spend can never exceed the original grant.
func TestReallocationRace(t *testing.T) {
    c, _ := newBank(t, 3, 2)
    g, err := c.Alloc("alice", "n1", 900)
    if err != nil {
        t.Fatalf("alloc: %v", err)
    }
    // Spend part of it, then revoke.  The owner's final set includes the spend.
    if _, ok := c.Spend("n1", "alice", "carol", 300); !ok {
        t.Fatal("first spend refused")
    }
    accepted, err := c.BeginRevoke(g.ID)
    if err != nil {
        t.Fatalf("revoke: %v", err)
    }
    if len(accepted) != 1 {
        t.Fatalf("accepted=%v", accepted)
    }
    // Remainder is now available and is re-issued to another node.
    rem := c.Free("alice")
    if rem != 600 {
        t.Fatalf("remaining free = %d, want 600", rem)
    }
    if _, err := c.Alloc("alice", "n2", rem); err != nil {
        t.Fatalf("realloc: %v", err)
    }
    // A late spend on the old grant must be fenced out.
    fenced := Transfer{TxID: "late", Src: "alice", Dst: "bob", Grant: g.ID, Owner: "n1", Amount: 500}
    for _, id := range c.order {
        c.Replicas[id].ApplyTransfer(fenced)
    }
    if _, ok := c.Spend("n2", "alice", "carol", 600); !ok {
        t.Fatal("new owner could not spend its grant")
    }
    c.Drain()
    c.Gossip()
    if err := c.CheckAll(); err != nil {
        t.Fatalf("safety: %v", err)
    }
    // Old owner's fenced spend must not count anywhere.
    if bal := c.Replica("n2").Balance("alice"); bal < 100 {
        t.Fatalf("alice below limit: %d", bal)
    }
}

// TestStaleRestart models a node crashing after it acknowledged a revocation
// and restarting from a snapshot that predates the revocation.  Recovery must
// replay the committed control log so the revoked grant can never be spent.
func TestStaleRestart(t *testing.T) {
    c, _ := newBank(t, 3, 3)
    g, err := c.Alloc("alice", "n1", 900)
    if err != nil {
        t.Fatalf("alloc: %v", err)
    }
    if _, ok := c.Spend("n1", "alice", "carol", 200); !ok {
        t.Fatal("spend refused")
    }
    if _, err := c.BeginRevoke(g.ID); err != nil {
        t.Fatalf("revoke: %v", err)
    }
    // n1 crashes and comes back, replaying the control log on recovery.
    c.SetDown("n1", true)
    c.SetDown("n1", false)
    if _, ok := c.Spend("n1", "alice", "bob", 100); ok {
        t.Fatal("revoked grant was spendable after stale restart")
    }
    // Re-issue the remainder and make sure accounting is right.
    if rem := c.Free("alice"); rem != 700 {
        t.Fatalf("free after restart = %d, want 700", rem)
    }
    if _, err := c.Alloc("alice", "n2", 700); err != nil {
        t.Fatalf("realloc: %v", err)
    }
    c.Drain()
    c.Gossip()
    if err := c.CheckAll(); err != nil {
        t.Fatalf("safety: %v", err)
    }
}

// TestPartialQuorumLoss splits the cluster.  The minority keeps serving
// transfers from grants it owns (availability), while control-plane changes
// stall in the minority but proceed in the majority.
func TestPartialQuorumLoss(t *testing.T) {
    c, accts := newBank(t, 5, 4)
    g, err := c.Alloc("alice", "n0", 800)
    if err != nil {
        t.Fatalf("alloc: %v", err)
    }
    if _, err := c.Alloc("bob", "n4", 800); err != nil {
        t.Fatalf("alloc bob: %v", err)
    }
    // {n0,n1} vs {n2,n3,n4}.
    c.Partition("n0", 1)
    c.Partition("n1", 1)
    for _, id := range []NodeID{"n2", "n3", "n4"} {
        c.Partition(id, 2)
    }
    // Minority keeps spending its own grant without a quorum.
    for i := 0; i < 10; i++ {
        if _, ok := c.Spend("n0", "alice", "carol", 10); !ok {
            t.Fatalf("minority spend %d refused", i)
        }
    }
    // Minority cannot commit a revocation (no quorum).
    if _, err := c.BeginRevoke(g.ID); err == nil {
        t.Fatal("minority revoke unexpectedly succeeded")
    }
    // Majority keeps making progress.
    if _, ok := c.Spend("n4", "bob", "carol", 20); !ok {
        t.Fatal("majority spend refused")
    }
    if _, err := c.Alloc("carol", "n3", 100); err != nil {
        t.Fatalf("majority alloc refused: %v", err)
    }
    if err := c.CheckAll(); err != nil {
        t.Fatalf("safety during partition: %v", err)
    }
    // Heal and converge.
    c.Heal()
    c.Drain()
    c.Gossip()
    if err := c.CheckAll(); err != nil {
        t.Fatalf("safety after heal: %v", err)
    }
    if !c.Converged(accts) {
        t.Fatal("did not converge after heal")
    }
}

// TestConservation checks that accepted debits always equal accepted credits.
func TestConservation(t *testing.T) {
    c, accts := newBank(t, 4, 5)
    if _, err := c.Alloc("alice", "n1", 900); err != nil {
        t.Fatal(err)
    }
    if _, err := c.Alloc("bob", "n2", 900); err != nil {
        t.Fatal(err)
    }
    for i := 0; i < 100; i++ {
        c.Spend("n1", "alice", "carol", 5)
        c.Spend("n2", "bob", "alice", 3)
    }
    c.Drain()
    c.Gossip()
    if d, cr := c.TotalDebits(accts), c.TotalCredits(accts); d != cr {
        t.Fatalf("conservation broken: debits=%d credits=%d", d, cr)
    }
    if err := c.CheckAll(); err != nil {
        t.Fatalf("safety: %v", err)
    }
}

// TestRandomizedFuzz runs many randomized interleavings of allocation,
// spending, revocation, restart and gossip, checking safety after every step.
func TestRandomizedFuzz(t *testing.T) {
    const iters = 300
    for seed := int64(0); seed < iters; seed++ {
        c := NewCluster(5, seed)
        accts := []AcctID{"a", "b", "c"}
        for _, a := range accts {
            if err := c.InitAccount(a, 1000, 0); err != nil {
                t.Fatal(err)
            }
        }
        live := []GrantID{}
        for step := 0; step < 60; step++ {
            switch c.rng.Intn(6) {
            case 0:
                owner := NodeID("n" + string(rune('0'+c.rng.Intn(5))))
                acct := accts[c.rng.Intn(len(accts))]
                if g, err := c.Alloc(acct, owner, int64(1+c.rng.Intn(300))); err == nil {
                    live = append(live, g.ID)
                }
            case 1:
                owner := NodeID("n" + string(rune('0'+c.rng.Intn(5))))
                src := accts[c.rng.Intn(len(accts))]
                dst := accts[c.rng.Intn(len(accts))]
                c.Spend(owner, src, dst, int64(1+c.rng.Intn(50)))
            case 2:
                if len(live) > 0 {
                    i := c.rng.Intn(len(live))
                    c.BeginRevoke(live[i])
                    live = append(live[:i], live[i+1:]...)
                }
            case 3:
                c.Deliver()
            case 4:
                id := NodeID("n" + string(rune('0'+c.rng.Intn(5))))
                c.SetDown(id, true)
                c.SetDown(id, false)
            case 5:
                c.Gossip()
            }
            // A crashed replica is allowed to lag, but no up replica may ever
            // violate a lower bound.
            if err := c.CheckAll(); err != nil {
                t.Fatalf("seed=%d step=%d: %v", seed, step, err)
            }
        }
        c.Drain()
        c.Gossip()
        if err := c.CheckAll(); err != nil {
            t.Fatalf("seed=%d final: %v", seed, err)
        }
        if !c.Converged(accts) {
            t.Fatalf("seed=%d did not converge", seed)
        }
        if d, cr := c.TotalDebits(accts), c.TotalCredits(accts); d != cr {
            t.Fatalf("seed=%d conservation: %d != %d", seed, d, cr)
        }
    }
}
