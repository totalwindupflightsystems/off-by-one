Answer

Solution: TypeError: fake_chain() got an unexpected keyword argument 'lane'

Root cause

The production seam _proxy_chain grew a new keyword argument (lane), and production now calls it as _proxy_chain(requirements, sort_spec=..., lane=lane). The tests replace that seam with a hand-written local stub via monkeypatch.setattr(router_server, "_proxy_chain", fake_chain).

Python binds keyword arguments at call time, against the object currently bound to the module attribute. monkeypatch.setattr swaps in the stub, so the stub's signature — not the production signature — governs the call. Two stubs in the test file declared fixed positional/default signatures (def fake_chain(requirements, sort_spec=None, window_h=None)) and therefore rejected the new lane keyword. Every other stub in the repo was written as lambda reqs, **k: ..., which silently absorbs unknown keywords, so only the fixed-signature outliers broke.

The qualified name in the traceback (_capture_chain.<locals>.fake_chain) is the tell-tale sign of a stub created by a nested factory (_capture_chain()), not a top-level test helper.

Why CI-only: CI ran the full suite, which exercises the seam through paths that pass lane=; the local run covered only a subset of tests that never passed the new kwarg.

Exact fix

Preferred: make seam stubs signature-transparent with **kwargs, so future signature growth stays backward compatible.

def _capture_chain():
    captured = []

    def fake_chain(requirements, **kwargs):          # was: (requirements, sort_spec=None, window_h=None)
        captured.append({"requirements": requirements, **kwargs})
        return "cheap"

    return fake_chain, captured

Acceptable alternative (explicit new kwarg, required if the stub asserts on it):

def fake_chain(requirements, sort_spec=None, window_h=None, lane=None):
    captured.append((requirements, sort_spec, window_h, lane))
    return "cheap"

Apply the same change to every fixed-signature stub (the report says there were two), not just the first one that fails — pytest stops at the first, so fixing one only reveals the other.

Detection command

After extending a seam signature, find fixed-signature stubs that replace it:

# 1) locate all tests that patch the seam
grep -rnE "monkeypatch\.setattr\([^,]*['\"]_proxy_chain['\"]" tests/

# 2) find hand-written stubs and check which lack **kwargs
grep -rnE "def (fake|_fake|stub|_stub)[A-Za-z_]*\(" tests/
grep -rnE "lambda [a-zA-Z_]+(, [a-zA-Z_]+)*:" tests/   # lambdas without **k are also suspects

# 3) run only the affected tests locally before pushing
python -m pytest tests/test_empty_matrix_routing.py -q

Any replacement callable for a seam must either list the new parameter or accept **kwargs.

Prevention

  • Convention: every monkeypatch.setattr seam stub takes (required_positional_args, **kwargs). Treat the stub as an adapter to the production seam, not a re-declaration of it.
  • Keep the capture payload generic ({**kwargs}) so newly added seam kwargs flow through without edits.
  • CI guard (fail when a seam stub has a fixed signature):
! grep -rnE "def (fake|_fake|stub|_stub)[A-Za-z_]*\([^)]*\)" tests/ | grep -v '\*\*'
  • When adding a kwarg to a seam function, grep the test tree for its name and for setattr of that seam in the same commit.

scripts/router_server.py

def _proxy_chain(requirements, sort_spec=None, window_h=None, lane=None):
    return {"requirements": requirements, "sort_spec": sort_spec,
            "window_h": window_h, "lane": lane}

def route(requirements, sort_spec=None, window_h=None, lane=None):
    return _proxy_chain(requirements, sort_spec=sort_spec, window_h=window_h, lane=lane)

tests/test_empty_matrix_routing.py (fixed)

import router_server

def _capture_chain():
    captured = []
    def fake_chain(requirements, **kwargs):
        captured.append({"requirements": requirements, **kwargs})
        return "cheap"
    return fake_chain, captured

def test_a_real_rating_failure_fails_cheap_not_into_the_priciest_profile(monkeypatch):
    fake_chain, captured = _capture_chain()
    monkeypatch.setattr(router_server, "_proxy_chain", fake_chain)
    result = router_server.route({"a": 1}, sort_spec="x", window_h=2, lane="priciest")
    assert result == "cheap"
    assert len(captured) == 1

Takeaway: a monkeypatch.setattr seam stub must mirror production's call contract, not freeze it. **kwargs on every seam stub makes added keyword arguments backward compatible and prevents this class of failure entirely.
