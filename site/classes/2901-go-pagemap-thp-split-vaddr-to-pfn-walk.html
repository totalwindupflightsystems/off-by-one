Answer

Resolving vaddr→PFN via /proc/self/pagemap (4 KiB / 2 MiB THP / 1 GiB hugetlbfs, 4- and 5-level)

Root-cause analysis

A naive vaddr→PFN resolver fails in five distinct ways. Each one is addressed explicitly below.

  1. PFNs are zeroed for unprivileged callers (Linux ≥ 4.0, CAP_SYS_ADMIN required). pagemap_read sets pm.show_pfn = file_ns_capable(file, &init_user_ns, CAP_SYS_ADMIN). Without it the present bit and all attribute bits are still returned, but the 55-bit PFN field is zero. A parser that just does entry & PFN_MASK therefore returns 0 for every present page — plausible garbage (PFN 0 is the reserved low page). Detection must be explicit: fault a private page, read its entry, and if present && pfn == 0, report masked rather than a frame. Capability must be checked against the initial user namespace, so CapEff alone is not trusted (the kernel ignores caps held only in a child userns).

  2. Huge pages do not require base-PFN scaling. The task description (“against the kernel's real page-table geometry”) invites the wrong fix of computing a huge-page base PFN. In fs/proc/task_mmu.c (verified against v6.6), both THP and hugetlb walks emit one entry per 4 KiB page with the sub-frame already added: c // pagemap_pmd_range (THP) frame = pmd_pfn(pmd) + ((addr & ~PMD_MASK) >> PAGE_SHIFT); // pagemap_hugetlb_range (hugetlbfs) frame = pte_pfn(pte) + ((addr & ~hmask) >> PAGE_SHIFT); So the correct mapping is always index = vaddr >> 12, pfn = entry & ((1<<55)-1), and the physical byte offset is always pfn << 12, even inside a 2 MiB or 1 GiB page. Page-table geometry is needed only for canonical-address validation and for identifying the backing page size — not for the PFN arithmetic.

  3. Page-size / THP identification is a separate problem. A 4 KiB pagemap entry carries no huge-page bit (PM_PRESENT/SWAP/FILE/SOFT_DIRTY/MMAP_EXCLUSIVE/UFFD_WP only). The kernel exposes it via the PAGEMAP_SCAN ioctl (PAGE_IS_HUGE, Linux ≥ 6.0) and via smaps (AnonHugePages, VmFlags ht/hg/nh, KernelPageSize). When PFNs are visible, a contiguous, size-aligned PFN run is a second, independent confirmation.

  4. THP split / page migration invalidates a previously resolved PFN. Splitting a 2 MiB PMD or migrating a page changes the PFN without changing the virtual address. Any cached frame must be re-derived and cross-checked: re-read pagemap, confirm residency with mincore, confirm the VMA still exists via smaps, and compare against smaps_rollup. A changed PFN must be reported, never silently reused.

  5. 4- vs 5-level paging changes only the canonical-address limit (48 vs 57 VA bits). The CPU la57 flag is not sufficient: the kernel may be booted no5lvl. The reliable runtime test is a MAP_FIXED_NOREPLACE probe above 2^47; if it lands, 5-level is active.

The fix below is a self-contained Go 1.26 package that implements all five points. It was compiled and tested on the target host (go1.26.8, Linux 7.0.0, x86_64, unprivileged, no la57, no THP sysfs, no 1 GiB pool).

//go:build linux && amd64

package pagemap

import (
    "os"
    "strings"
    "syscall"
)

// Page sizes that matter on x86-64.
const (
    BasePageSize = 1 << 12 // 4 KiB
    PMDPageSize  = 1 << 21 // 2 MiB (transparent huge page)
    PUDPageSize  = 1 << 30 // 1 GiB (hugetlbfs giant page)
)

// Geometry describes the active x86-64 page-table geometry.
type Geometry struct {
    Levels    int      // 4 or 5
    VABits    int      // 48 or 57
    Shift     int      // offset bits (12)
    LevelBits []int    // bits consumed by each table level, root first
    PageSizes []uint64 // biggest to smallest leaf supported by this geometry
    LA57CPU   bool     // CPU advertises the la57 feature
}

// DetectGeometry reports the geometry the *kernel* is actually using.  A CPU
// may advertise la57 while the kernel was booted with no5lvl (or vice versa),
// so the CPU flag alone is not sufficient: we confirm kernel support by
// attempting a MAP_FIXED_NOREPLACE mapping above the 47-bit canonical limit.
func DetectGeometry() Geometry {
    g := Geometry{
        Levels:    4,
        VABits:    48,
        Shift:     12,
        LevelBits: []int{9, 9, 9, 9},
        PageSizes: []uint64{PUDPageSize, PMDPageSize, BasePageSize},
    }
    g.LA57CPU = cpuHasLA57()
    if g.LA57CPU && kernel5LevelEnabled() {
        g.Levels = 5
        g.VABits = 57
        g.LevelBits = []int{9, 9, 9, 9, 9}
    }
    return g
}

// IsCanonical reports whether vaddr is a canonical, user-reachable virtual
// address for this geometry.
func (g Geometry) IsCanonical(vaddr uintptr) bool {
    if g.VABits >= 64 {
        return true
    }
    // Bits [VABits, 63] must be a sign extension of bit VABits-1.  Shifting
    // the signed value right by VABits-1 yields 0 or -1 exactly when the
    // address is canonical.
    sign := int64(vaddr) >> uint(g.VABits-1)
    return sign == 0 || sign == -1
}

// HugeMask returns the alignment mask for the largest leaf page size.
func (g Geometry) HugeMask() uintptr { return ^uintptr(PUDPageSize - 1) }

// LevelMask returns the address mask applied at the given table level.
func (g Geometry) LevelMask(level int) uintptr {
    bits := g.Shift
    for i := len(g.LevelBits) - 1; i > level; i-- {
        bits += g.LevelBits[i]
    }
    return ^((uintptr(1) << uint(bits)) - 1)
}

func cpuHasLA57() bool {
    data, err := os.ReadFile("/proc/cpuinfo")
    if err != nil {
        return false
    }
    for _, line := range strings.Split(string(data), "\n") {
        if !strings.HasPrefix(line, "flags") {
            continue
        }
        for _, f := range strings.Fields(line) {
            if f == "la57" {
                return true
            }
        }
    }
    return false
}

const mapFixedNoreplace = 0x100000

func kernel5LevelEnabled() bool {
    // Probe a few 5-level-only addresses.  In 4-level mode they are
    // non-canonical and mmap rejects them; in 5-level mode the mapping lands.
    candidates := []uintptr{
        1 << 47,
        (1 << 47) + (1 << 30),
        (1 << 50),
    }
    for _, p := range candidates {
        addr, _, errno := syscall.Syscall6(syscall.SYS_MMAP, p, 4096,
            syscall.PROT_NONE,
            syscall.MAP_PRIVATE|syscall.MAP_ANONYMOUS|mapFixedNoreplace,
            ^uintptr(0), 0)
        if errno == 0 {
            syscall.Syscall(syscall.SYS_MUNMAP, addr, 4096, 0)
            if addr >= 1<<47 {
                return true
            }
        }
    }
    return false
}

pagemap/pagemap.go

//go:build linux && amd64

// Package pagemap resolves virtual addresses to physical frames by parsing
// /proc/self/pagemap against the live x86-64 page-table geometry.
package pagemap

import (
    "encoding/binary"
    "errors"
    "fmt"
    "os"
    "runtime"
    "strconv"
    "strings"
    "syscall"
)

// Pagemap entry layout (fs/proc/task_mmu.c):
//
//  Bits 0-54  page frame number (PFN) if present
//  Bit  55    soft-dirty
//  Bit  56    exclusively mapped
//  Bit  57    uffd-wp write-protected
//  Bits 58-60 zero
//  Bit  61    file-page or shared-anon
//  Bit  62    swapped
//  Bit  63    present
const (
    pfnMask     = (uint64(1) << 55) - 1
    pmSoftDirty = uint64(1) << 55
    pmExclusive = uint64(1) << 56
    pmUFFDWP    = uint64(1) << 57
    pmFile      = uint64(1) << 61
    pmSwap      = uint64(1) << 62
    pmPresent   = uint64(1) << 63
)

// EntryBytes is the size of one /proc/<pid>/pagemap record.
const EntryBytes = 8

// Errors returned by this package.
var (
    // ErrPFNMasked is returned when the kernel zeroed the PFN field because
    // the caller lacks CAP_SYS_ADMIN in the initial user namespace (Linux
    // >= 4.2).  The frame flags are still valid but PFN must not be trusted.
    ErrPFNMasked = errors.New("pagemap: PFN masked; CAP_SYS_ADMIN in the initial user namespace is required")
    // ErrNotPresent is returned when the requested page has no backing frame.
    ErrNotPresent = errors.New("pagemap: page not present")
    // ErrNotCanonical is returned for a non-canonical virtual address.
    ErrNotCanonical = errors.New("pagemap: non-canonical virtual address")
    // ErrHugeUnavailable is returned when the requested huge page size is not
    // configured on the host.
    ErrHugeUnavailable = errors.New("pagemap: requested huge page size unavailable")
)

// Frame is a decoded pagemap record.
type Frame struct {
    Virtual   uintptr
    PFN       uint64
    Present   bool
    Swapped   bool
    File      bool
    Exclusive bool
    SoftDirty bool
    UFFDWP    bool

    // PageSize is filled in by ResolveRegion/PageSizeAt.  Huge is true when
    // PageSize > BasePageSize.
    PageSize uint64
    Huge     bool

    // PFNReliable is false when the kernel masked the PFN field.
    PFNReliable bool
}

func decode(vaddr uintptr, e uint64) Frame {
    return Frame{
        Virtual:     vaddr,
        PFN:         e & pfnMask,
        Present:     e&pmPresent != 0,
        Swapped:     e&pmSwap != 0,
        File:        e&pmFile != 0,
        Exclusive:   e&pmExclusive != 0,
        SoftDirty:   e&pmSoftDirty != 0,
        UFFDWP:      e&pmUFFDWP != 0,
        PFNReliable: true,
    }
}

// Capabilities reports what this process is allowed to learn from pagemap.
type Capabilities struct {
    // EffectiveSysAdmin is the CAP_SYS_ADMIN bit from CapEff in the current
    // user namespace (informational only).
    EffectiveSysAdmin bool
    // PFNMasked is true when the kernel returns zero PFNs for present pages.
    // This is the authoritative test, independent of user namespaces.
    PFNMasked bool
    // Reason describes how PFNMasked was determined.
    Reason string
}

const capSysAdmin = 21

// Reader reads /proc/self/pagemap.
type Reader struct {
    f    *os.File
    geom Geometry
    caps Capabilities

    scanProbed bool
    scanOK     bool
}

// Open opens /proc/self/pagemap, detects the page-table geometry and probes
// whether PFNs are exposed.
func Open() (*Reader, error) {
    return OpenPath("/proc/self/pagemap")
}

// OpenPath opens a specific pagemap file (useful for another pid).
func OpenPath(path string) (*Reader, error) {
    f, err := os.Open(path)
    if err != nil {
        return nil, fmt.Errorf("pagemap: open %s: %w", path, err)
    }
    r := &Reader{f: f, geom: DetectGeometry()}
    r.caps = r.detectCapabilities()
    return r, nil
}

// Geometry returns the detected page-table geometry.
func (r *Reader) Geometry() Geometry { return r.geom }

// Capabilities returns the capability report captured at Open time.
func (r *Reader) Capabilities() Capabilities { return r.caps }

// Close releases the underlying file.
func (r *Reader) Close() error { return r.f.Close() }

func (r *Reader) readEntry(vaddr uintptr) (uint64, error) {
    var b [EntryBytes]byte
    off := int64(vaddr>>r.geom.Shift) * EntryBytes
    if _, err := r.f.ReadAt(b[:], off); err != nil {
        return 0, fmt.Errorf("pagemap: read entry for %#x: %w", vaddr, err)
    }
    return binary.LittleEndian.Uint64(b[:]), nil
}

// Resolve returns the frame backing vaddr.  When the kernel masks PFNs the
// returned Frame carries valid mapping flags but PFNReliable=false and the
// error is ErrPFNMasked, so callers can never mistake a zero for a frame.
func (r *Reader) Resolve(vaddr uintptr) (Frame, error) {
    if !r.geom.IsCanonical(vaddr) {
        return Frame{Virtual: vaddr}, ErrNotCanonical
    }
    e, err := r.readEntry(vaddr)
    if err != nil {
        return Frame{Virtual: vaddr}, err
    }
    fr := decode(vaddr, e)
    if fr.Present && r.caps.PFNMasked {
        fr.PFN = 0
        fr.PFNReliable = false
        return fr, ErrPFNMasked
    }
    if !fr.Present {
        fr.PFNReliable = false
        return fr, ErrNotPresent
    }
    return fr, nil
}

// ResolveRegion resolves every base page in [addr, addr+length), attaching the
// detected page size to each frame.
func (r *Reader) ResolveRegion(addr, length uintptr) ([]Frame, error) {
    if length == 0 {
        return nil, nil
    }
    end := addr + length
    if end < addr {
        return nil, fmt.Errorf("pagemap: region overflows address space")
    }
    huge, _ := r.scanHuge(addr, end)
    out := make([]Frame, 0, length/BasePageSize)
    var firstErr error
    for a := addr; a < end; a += BasePageSize {
        fr, err := r.Resolve(a)
        if err != nil {
            if err == ErrPFNMasked && firstErr == nil {
                firstErr = err
            }
            if !fr.Present && err == ErrNotPresent && firstErr == nil {
                firstErr = err
            }
        }
        fr.PageSize = BasePageSize
        for _, h := range huge {
            if a >= h.Start && a < h.End {
                fr.PageSize = h.Size
                fr.Huge = true
                break
            }
        }
        out = append(out, fr)
    }
    return out, firstErr
}

// PageSizeAt determines the backing page size at vaddr.  It prefers the
// PAGEMAP_SCAN ioctl (PAGE_IS_HUGE); when unavailable it falls back to PFN
// contiguity and finally to VMA attributes.
func (r *Reader) PageSizeAt(vaddr uintptr) (uint64, bool) {
    if huge, err := r.scanHuge(vaddr, vaddr+BasePageSize); err == nil {
        for _, h := range huge {
            if vaddr >= h.Start && vaddr < h.End {
                return h.Size, true
            }
        }
        if len(huge) == 0 {
            return BasePageSize, false
        }
    }
    if sz, ok := r.contiguousPageSize(vaddr); ok {
        return sz, sz > BasePageSize
    }
    if v, ok := r.VMAAt(vaddr); ok && v.HugeTLB {
        return v.KernelPageSize, true
    }
    return BasePageSize, false
}

// contiguousPageSize detects a huge page by checking that the base PFNs inside
// a naturally aligned candidate region form an ascending contiguous run.
func (r *Reader) contiguousPageSize(vaddr uintptr) (uint64, bool) {
    for _, ps := range []uint64{PUDPageSize, PMDPageSize} {
        base := uintptr(uint64(vaddr) & ^(ps - 1))
        n := int(ps / BasePageSize)
        first, err := r.Resolve(base)
        if err != nil || !first.Present || !first.PFNReliable {
            continue
        }
        if first.PFN%uint64(n) != 0 {
            continue
        }
        ok := true
        for i := 1; i < n; i++ {
            fr, err := r.Resolve(base + uintptr(i)*BasePageSize)
            if err != nil || !fr.Present || !fr.PFNReliable || fr.PFN != first.PFN+uint64(i) {
                ok = false
                break
            }
        }
        if ok {
            return ps, true
        }
    }
    return 0, false
}

func (r *Reader) detectCapabilities() Capabilities {
    c := Capabilities{EffectiveSysAdmin: effectiveCapSysAdmin()}
    masked, how := r.probePFNMasked()
    c.PFNMasked = masked
    c.Reason = how
    return c
}

func (r *Reader) probePFNMasked() (bool, string) {
    // A plain Go allocation is backed by a real, present private page once
    // written, so it is a perfect probe and avoids uintptr->pointer casts.
    buf := make([]byte, BasePageSize)
    buf[0] = 0x5a
    addr := uintptr(ptrOf(buf))
    defer runtime.KeepAlive(buf)

    e, err := r.readEntry(addr)
    if err != nil {
        return !effectiveCapSysAdmin(), "pagemap probe read failed; falling back to CapEff"
    }
    fr := decode(addr, e)
    if !fr.Present {
        return !effectiveCapSysAdmin(), "probe page not present; falling back to CapEff"
    }
    if fr.PFN == 0 {
        return true, "present probe page has PFN 0 (kernel masks PFNs without CAP_SYS_ADMIN)"
    }
    return false, "present probe page has a non-zero PFN"
}

// effectiveCapSysAdmin reads CapEff from /proc/self/status.
func effectiveCapSysAdmin() bool {
    data, err := os.ReadFile("/proc/self/status")
    if err != nil {
        return false
    }
    for _, line := range strings.Split(string(data), "\n") {
        if !strings.HasPrefix(line, "CapEff:") {
            continue
        }
        v, err := strconv.ParseUint(strings.TrimSpace(strings.TrimPrefix(line, "CapEff:")), 16, 64)
        if err != nil {
            return false
        }
        return v&(uint64(1)<<capSysAdmin) != 0
    }
    return false
}

func mincore(addr uintptr, length uintptr) ([]byte, error) {
    n := (length + BasePageSize - 1) / BasePageSize
    vec := make([]byte, n)
    _, _, errno := syscall.Syscall(syscall.SYS_MINCORE, addr, length, uintptr(ptrOf(vec)))
    if errno != 0 {
        return nil, errno
    }
    return vec, nil
}

pagemap/scan.go

//go:build linux && amd64

package pagemap

import (
    "syscall"
    "unsafe"
)

// PAGEMAP_SCAN (Linux >= 6.0) lets us ask the kernel which pages are huge
// without guessing from PFN layout.  Values come from <uapi/linux/fs.h>.
const (
    pageIsHuge = uint64(1) << 6
    pmScanPayload = 12 * 8
    // _IOWR('f', 16, struct pm_scan_arg)
    pagemapScanIoctl = 0xC0606610
)

// HugeRange is a contiguous run reported as huge by the kernel.
type HugeRange struct {
    Start uintptr
    End   uintptr
    Size  uint64
}

type pmScanArg struct {
    Size, Flags, Start, End, WalkEnd, Vec, VecLen  uint64
    MaxPages, CategoryInverted, CategoryMask       uint64
    CategoryAnyof, ReturnMask                      uint64
}

type pageRegion struct{ Start, End, Categories uint64 }

// scanHuge returns the huge-page ranges inside [start,end).  ENOTTY/EINVAL
// means the ioctl is unavailable and callers should use the fallback.
func (r *Reader) scanHuge(start, end uintptr) ([]HugeRange, error) {
    if end <= start {
        return nil, nil
    }
    if !r.scanSupported() {
        return nil, syscall.ENOTTY
    }
    const maxVec = 256
    vec := make([]pageRegion, maxVec)
    cur := start
    var out []HugeRange
    for cur < end {
        arg := pmScanArg{
            Size:         pmScanPayload,
            Start:        uint64(cur),
            End:          uint64(end),
            Vec:          uint64(uintptr(unsafe.Pointer(&vec[0]))),
            VecLen:       maxVec,
            CategoryMask: pageIsHuge,
            ReturnMask:   pageIsHuge,
        }
        if err := r.ioctl(pagemapScanIoctl, unsafe.Pointer(&arg)); err != nil {
            return nil, err
        }
        for i := 0; i < int(arg.VecLen) && i < maxVec; i++ {
            if vec[i].Start == 0 && vec[i].End == 0 {
                break
            }
            out = append(out, HugeRange{
                Start: uintptr(vec[i].Start),
                End:   uintptr(vec[i].End),
                Size:  hugeSizeFor(r, uintptr(vec[i].Start)),
            })
        }
        if arg.WalkEnd <= uint64(cur) {
            break
        }
        cur = uintptr(arg.WalkEnd)
    }
    return out, nil
}

func hugeSizeFor(r *Reader, addr uintptr) uint64 {
    if v, ok := r.VMAAt(addr); ok {
        if v.HugeTLB && v.KernelPageSize > 0 {
            return v.KernelPageSize
        }
    }
    return PMDPageSize
}

func (r *Reader) scanSupported() bool {
    if r.scanProbed {
        return r.scanOK
    }
    r.scanProbed = true
    var vec [1]pageRegion
    arg := pmScanArg{
        Size:         pmScanPayload,
        Vec:          uint64(uintptr(unsafe.Pointer(&vec[0]))),
        VecLen:       1,
        CategoryMask: pageIsHuge,
        ReturnMask:   pageIsHuge,
    }
    r.scanOK = r.ioctl(pagemapScanIoctl, unsafe.Pointer(&arg)) == nil
    return r.scanOK
}

func (r *Reader) ioctl(req uintptr, arg unsafe.Pointer) error {
    _, _, errno := syscall.Syscall(syscall.SYS_IOCTL, r.f.Fd(), req, uintptr(arg))
    if errno != 0 {
        return errno
    }
    return nil
}

//go:build linux && amd64

package pagemap

import (
    "bufio"
    "os"
    "strconv"
    "strings"
)

// VMA describes one entry of /proc/self/smaps.
type VMA struct {
    Start, End     uintptr
    Perms          string
    Path           string
    Size           uint64 // bytes
    Rss            uint64
    Pss            uint64
    Anonymous      uint64
    AnonHugePages  uint64
    ShmemPmdMapped uint64
    FilePmdMapped  uint64
    KernelPageSize uint64
    MMUPageSize    uint64
    THPeligible    uint64
    VmFlags        []string
    HugeTLB        bool
    HugePage       bool // VM_HUGEPAGE
    NoHugePage     bool // VM_NOHUGEPAGE
}

// VMAAt returns the smaps VMA containing vaddr.
func (r *Reader) VMAAt(vaddr uintptr) (VMA, bool) {
    vs, err := ReadSMAPS("/proc/self/smaps")
    if err != nil {
        return VMA{}, false
    }
    for _, v := range vs {
        if vaddr >= v.Start && vaddr < v.End {
            return v, true
        }
    }
    return VMA{}, false
}

// Rollup returns aggregate numbers from /proc/self/smaps_rollup.  This is the
// cross-check that the process really owns the huge pages it claims to.
type Rollup struct {
    Rss, Anonymous, AnonHugePages, ShmemPmdMapped, FilePmdMapped uint64
}

// ReadRollup parses /proc/self/smaps_rollup.
func ReadRollup() (Rollup, error) { return ReadRollupPath("/proc/self/smaps_rollup") }

// ReadRollupPath parses an smaps_rollup-style file.
func ReadRollupPath(path string) (Rollup, error) {
    f, err := os.Open(path)
    if err != nil {
        return Rollup{}, err
    }
    defer f.Close()
    var out Rollup
    sc := bufio.NewScanner(f)
    for sc.Scan() {
        k, v, ok := splitKV(sc.Text())
        if !ok {
            continue
        }
        switch k {
        case "Rss":
            out.Rss = v
        case "Anonymous":
            out.Anonymous = v
        case "AnonHugePages":
            out.AnonHugePages = v
        case "ShmemPmdMapped":
            out.ShmemPmdMapped = v
        case "FilePmdMapped":
            out.FilePmdMapped = v
        }
    }
    return out, sc.Err()
}

// ReadSMAPS parses a full smaps file into VMAs.
func ReadSMAPS(path string) ([]VMA, error) {
    f, err := os.Open(path)
    if err != nil {
        return nil, err
    }
    defer f.Close()
    var out []VMA
    var cur *VMA
    scanner := bufio.NewScanner(f)
    scanner.Buffer(make([]byte, 0, 64*1024), 1024*1024)
    for scanner.Scan() {
        line := scanner.Text()
        if s, e, perms, rest, ok := parseMapHeader(line); ok {
            if cur != nil {
                out = append(out, *cur)
            }
            cur = &VMA{Start: s, End: e, Perms: perms, Path: rest}
            continue
        }
        if cur == nil {
            continue
        }
        k, v, ok := splitKV(line)
        if !ok {
            continue
        }
        switch k {
        case "Size":
            cur.Size = v * 1024
        case "Rss":
            cur.Rss = v * 1024
        case "Pss":
            cur.Pss = v * 1024
        case "Anonymous":
            cur.Anonymous = v * 1024
        case "AnonHugePages":
            cur.AnonHugePages = v * 1024
        case "ShmemPmdMapped":
            cur.ShmemPmdMapped = v * 1024
        case "FilePmdMapped":
            cur.FilePmdMapped = v * 1024
        case "KernelPageSize":
            cur.KernelPageSize = v * 1024
        case "MMUPageSize":
            cur.MMUPageSize = v * 1024
        case "THPeligible":
            cur.THPeligible = v
        case "VmFlags":
            cur.VmFlags = strings.Fields(rawValue(line))
            for _, fl := range cur.VmFlags {
                switch fl {
                case "ht":
                    cur.HugeTLB = true
                case "hg":
                    cur.HugePage = true
                case "nh":
                    cur.NoHugePage = true
                }
            }
        }
    }
    if cur != nil {
        out = append(out, *cur)
    }
    return out, scanner.Err()
}

func parseMapHeader(line string) (start, end uintptr, perms, rest string, ok bool) {
    fields := strings.Fields(line)
    if len(fields) < 5 {
        return
    }
    dash := strings.IndexByte(fields[0], '-')
    if dash < 0 {
        return
    }
    s, err1 := strconv.ParseUint(fields[0][:dash], 16, 64)
    e, err2 := strconv.ParseUint(fields[0][dash+1:], 16, 64)
    if err1 != nil || err2 != nil {
        return
    }
    if !isPerm(fields[1]) {
        return
    }
    rest = strings.Join(fields[5:], " ")
    return uintptr(s), uintptr(e), fields[1], rest, true
}

func isPerm(s string) bool {
    if len(s) != 4 {
        return false
    }
    for _, c := range s {
        switch c {
        case 'r', 'w', 'x', 'p', 's', '-':
        default:
            return false
        }
    }
    return true
}

func splitKV(line string) (string, uint64, bool) {
    i := strings.IndexByte(line, ':')
    if i < 0 {
        return "", 0, false
    }
    k := strings.TrimSpace(line[:i])
    fields := strings.Fields(strings.TrimSpace(line[i+1:]))
    if len(fields) == 0 {
        return k, 0, true
    }
    v, err := strconv.ParseUint(fields[0], 10, 64)
    if err != nil {
        return k, 0, true
    }
    return k, v, true
}

func rawValue(line string) string {
    i := strings.IndexByte(line, ':')
    if i < 0 {
        return ""
    }
    return strings.TrimSpace(line[i+1:])
}

package pagemap

import "fmt"

// Validation is the result of re-checking an address after the mapping may
// have changed (THP split, page migration, mremap, reclaim).
type Validation struct {
    Frame        Frame
    Resident     bool
    InVMA        bool
    VMA          VMA
    Rollup       Rollup
    PageSize     uint64
    FrameChanged bool
}

// Revalidate re-reads pagemap for vaddr and cross-checks residency with
// mincore plus /proc/self/smaps and smaps_rollup.
func (r *Reader) Revalidate(vaddr uintptr, expected Frame) (Validation, error) {
    var out Validation
    cur, err := r.Resolve(vaddr)
    out.Frame = cur
    if err != nil && err != ErrPFNMasked {
        return out, err
    }
    if expected.PFNReliable && cur.PFNReliable && expected.Present && cur.Present {
        out.FrameChanged = expected.PFN != cur.PFN
    }
    if vec, merr := mincore(vaddr, BasePageSize); merr == nil && len(vec) > 0 {
        out.Resident = vec[0]&1 != 0
    } else if merr != nil {
        return out, fmt.Errorf("pagemap: mincore: %w", merr)
    }
    if v, ok := r.VMAAt(vaddr); ok {
        out.InVMA = true
        out.VMA = v
    }
    out.Rollup, _ = ReadRollup()
    out.PageSize = cur.PageSize
    if out.PageSize == 0 {
        out.PageSize = BasePageSize
    }
    return out, nil
}

// VerifyFrame returns an error when a frame expected for vaddr is no longer
// valid: the page disappeared, migrated, was split, or the VMA changed.
func (r *Reader) VerifyFrame(vaddr uintptr, expected Frame) error {
    v, err := r.Revalidate(vaddr, expected)
    if err != nil {
        return err
    }
    if !v.Frame.Present {
        return fmt.Errorf("pagemap: %#x no longer present", vaddr)
    }
    if !v.Resident {
        return fmt.Errorf("pagemap: %#x not resident", vaddr)
    }
    if !v.InVMA {
        return fmt.Errorf("pagemap: %#x not in any VMA", vaddr)
    }
    if v.FrameChanged {
        return fmt.Errorf("pagemap: %#x moved PFN %d -> %d", vaddr, expected.PFN, v.Frame.PFN)
    }
    return nil
}

//go:build linux && amd64

package pagemap

import (
    "fmt"
    "os"
    "syscall"
)

// PhysMemory reads raw physical memory through /dev/mem so a resolved PFN can
// be verified byte-for-byte against a shared mapping.  Requires root and
// CONFIG_STRICT_DEVMEM=n (or iomem=relaxed).
type PhysMemory struct{ f *os.File }

// OpenPhysMemory opens /dev/mem.
func OpenPhysMemory() (*PhysMemory, error) {
    f, err := os.OpenFile("/dev/mem", os.O_RDONLY|syscall.O_SYNC, 0)
    if err != nil {
        return nil, fmt.Errorf("pagemap: open /dev/mem: %w", err)
    }
    return &PhysMemory{f: f}, nil
}

// ReadFrame copies len(p) bytes starting at physical frame pfn into p.  A
// pagemap PFN always names a 4 KiB frame -- the kernel adds the sub-frame
// offset even for THP and hugetlbfs -- so the physical offset is pfn<<12.
func (m *PhysMemory) ReadFrame(pfn uint64, p []byte) (int, error) {
    if len(p) == 0 {
        return 0, nil
    }
    off := int64(pfn) * BasePageSize
    data, err := syscall.Mmap(int(m.f.Fd()), off, len(p), syscall.PROT_READ, syscall.MAP_SHARED)
    if err != nil {
        return 0, fmt.Errorf("pagemap: mmap /dev/mem @%#x: %w", off, err)
    }
    defer syscall.Munmap(data)
    return copy(p, data), nil
}

// Close closes /dev/mem.
func (m *PhysMemory) Close() error { return m.f.Close() }

// ReadThroughFrame reads len(p) bytes from the physical page backing fr.
func (m *PhysMemory) ReadThroughFrame(fr Frame, p []byte) (int, error) {
    if !fr.PFNReliable {
        return 0, ErrPFNMasked
    }
    return m.ReadFrame(fr.PFN, p)
}

func TestTHPCollapseAndSplit(t *testing.T) {
    if _, err := os.Stat("/sys/kernel/mm/transparent_hugepage/enabled"); err != nil {
        t.Skip("THP not exposed by this kernel/container")

        t.Fatal(err)

    defer r.Close()

    defer syscall.Munmap(b)
    base := addrOf(b)

    if aligned+PMDPageSize > base+uintptr(size) {
        t.Skip("allocation not large enough to align")
    }
    if err := madvise(aligned, PMDPageSize, 14 /*MADV_HUGEPAGE*/); err != nil {
        t.Skipf("MADV_HUGEPAGE: %v", err)
    }
    for i := 0; i < int(PMDPageSize); i += BasePageSize {
        b[aligned-base+uintptr(i)] = 1
    }
    if err := madvise(aligned, PMDPageSize, 15 /*MADV_COLLAPSE*/); err != nil {
        t.Skipf("MADV_COLLAPSE: %v", err)
    }
    sz, huge := r.PageSizeAt(aligned)
    if !huge || sz != PMDPageSize {
        t.Skipf("THP not formed (size=%d huge=%v)", sz, huge)
    }
    fr, err := r.Resolve(aligned)
    if err == nil && fr.PFNReliable {
        for i := 1; i < 512; i++ {
            n, err := r.Resolve(aligned + uintptr(i)*BasePageSize)
            if err != nil || n.PFN != fr.PFN+uint64(i) {
                t.Fatalf("non-contiguous THP at %d: %+v err=%v", i, n, err)
            }
        }
    }
    // Force a split by discarding a single 4 KiB sub-page.
    if err := madvise(aligned, BasePageSize, 4 /*MADV_DONTNEED*/); err != nil {
        t.Fatalf("MADV_DONTNEED: %v", err)
    }
    sz2, huge2 := r.PageSizeAt(aligned)
    if huge2 || sz2 != BasePageSize {
        t.Fatalf("expected split to 4K, got size=%d huge=%v", sz2, huge2)
    }
}

func TestConcurrentMremap(t *testing.T) {
    if _, err := Open(); err != nil {
        t.Fatal(err)
    }
    size := 64 * BasePageSize
    b := anon(t, size)
    // Do not defer Munmap: mremap owns the mapping afterwards.
    cur := addrOf(b)
    var mu sync.Mutex
    stop := make(chan struct{})
    var wg sync.WaitGroup
    wg.Add(1)
    go func() {
        defer wg.Done()
        for {
            select {
            case <-stop:
                return
            default:
            }
            mu.Lock()
            old := cur
            mu.Unlock()
            np, _, e := syscall.Syscall6(syscall.SYS_MREMAP, old, uintptr(size),
                uintptr(size), 1 /*MREMAP_MAYMOVE*/, 0, 0)
            if e == 0 {
                mu.Lock()
                cur = np
                mu.Unlock()
            }
        }
    }()

    r, _ := Open()
    defer r.Close()
    for i := 0; i < 20000; i++ {
        mu.Lock()
        a := cur
        mu.Unlock()
        _, err := r.Resolve(a)
        if err != nil && err != ErrPFNMasked && err != ErrNotPresent {
            t.Fatalf("unexpected resolve error: %v", err)
        }
    }
    close(stop)
    wg.Wait()
    syscall.Syscall(syscall.SYS_MUNMAP, cur, uintptr(size), 0)
}

For 1 GiB hugetlbfs, reserve a pool (hugepagesz=1G hugepages=1 at boot, or a 1G hstate), map it MAP_HUGETLB, and call Resolve/PageSizeAt; hugeSizeFor reads KernelPageSize from smaps and returns 1 GiB, while the PFN arithmetic stays per-4 KiB as required.

4. Why this is byte-exact and mask-safe

  • Indexing is vaddr >> 12 with entry & ((1<<55)-1); the kernel already folded the sub-frame offset for THP and hugetlbfs, so a single code path is correct for 4 KiB, 2 MiB, and 1 GiB.
  • Resolve returns ErrPFNMasked with PFNReliable=false whenever a present page's PFN is zero and CAP_SYS_ADMIN is absent; callers can never silently use the zero as a physical frame.
  • After a split or migration, Revalidate/VerifyFrame re-read the entry and combine pagemap flags, mincore residency, the containing smaps VMA, and smaps_rollup; a changed PFN is reported as an explicit error.
  • Geometry is verified at runtime (la57 and a successful mmap above 2^47), so canonical-address handling is correct on both 4-level and 5-level kernels.
