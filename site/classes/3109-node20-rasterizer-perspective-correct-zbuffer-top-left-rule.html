Pixel-exact software triangle rasterizer (Node 20 / JavaScript)

Title

Fix: top-left fill rule at integer subpixel precision + homogeneous guard-band / near-plane clipping + perspective-correct 1/w interpolation + post-clip z-buffer.

A drop-in, dependency-free rasterizer (rasterizer.js) and a verification harness (verify.js) that prove coverage is pixel-exact against an independent BigInt reference, including shared-edge and shared-vertex cases.

Root-cause analysis

The class of bug this solves is not a single typo but a set of interacting conventions that each produce a different class of artifact. Missing or inconsistent handling of any of them shows up as visible cracks, double-covered pixels, or wrong colors/depth.

1. Missing top-left fill rule → shared edges are double-hit (or dropped)

A pixel whose center lies exactly on an edge is reported as "inside" by the edge function of both triangles that share that edge. A naive test such as e >= 0 for every edge double-covers every shared-edge pixel row/column.

Measured with the diagnostic (diagnose.js) on a 64×64 grid of two-triangle cells over NDC [-1,1]²:

grid naive e>=0 double-hit px top-left rule double-hit px
N=8 512 0
N=128 4096 0

The fix is a consistent tie-break: when e == 0, include the pixel only if the edge is a top edge (horizontal, interior below: dy == 0 && dx > 0) or a left edge (dy < 0). For a positive-area triangle, reversing a shared edge's direction flips exactly one of those predicates, so every shared-edge pixel is claimed by exactly one triangle.

2. Clipping after perspective divide → cracks (T-junctions)

Guard-band / viewport clipping done in screen space computes new vertices with floating-point a + t·(b-a) independently per triangle. Two adjacent triangles traverse their shared edge in opposite order (a→b vs b→a). The two results are mathematically equal but not guaranteed to round to the same fixed-point screen coordinate, so the shared edge can pull apart and leave a one-pixel crack (or overlap). Clipping after the divide also means a vertex behind the eye has no valid screen coordinate at all.

The fix is to clip in homogeneous clip space before the divide and to use a symmetric, sign-reversible intersection:

p = fa·b − fb·a        (instead of  a + t·(b−a))

Reversing the edge order negates every component of p exactly (IEEE negation and multiplication are exact), and the projective point p and every ratio used afterwards (x/w, z/w, s/w, a/w) are therefore bit-identical for both triangles. The guard band itself is just four extra homogeneous planes (|x| ≤ G·w, |y| ≤ G·w) so geometry well outside the viewport never needs a screen-space clip at all.

3. Affine interpolation → perspective distortion

Interpolating attributes linearly with screen barycentrics is only correct when 1/w is constant. For a triangle whose vertices have different w, this makes textures swim. Measured against an independent camera-space ray/plane ground truth (diagnose.js):

interpolation max error vs 3D truth
affine (screen-linear) 5.992e-01
perspective-correct (1/w) 2.220e-16

The fix: interpolate a/w and 1/w linearly in screen space, then divide: a = (Σ λᵢ·(aᵢ/wᵢ)) / (Σ λᵢ·(1/wᵢ)). Depth z/w is already screen-affine, so it is interpolated directly.

4. Back-facing / degenerate primitives → depth artifacts

A zero-area or negative-area triangle must be rejected before any depth write. If it is rasterized (or only partially rejected), it can win the depth test and stamp garbage depth/attributes into the buffer. The fix is the early area2 <= 0 return, so culled primitives touch neither count, depth, nor attrs.

5. Integer subpixel precision and the tie-break grid

Coverage is evaluated on a 1/256-pixel lattice with the pixel center at x·256 + 128, so all edge functions are exact integers (|value| < 2^53 for realistic viewports). This makes e == 0 well defined and keeps the top-left rule deterministic. Screen coordinates are snapped with Math.round(sx·256) once, per vertex, so shared vertices are identical by construction.

The exact fix

The complete implementation. Save as rasterizer.js.

'use strict';
/*
 * Software triangle rasterizer.
 *
 *  - top-left fill rule on an integer subpixel grid
 *  - perspective-correct attribute interpolation using 1/w
 *  - z-buffer resolved after homogeneous near-plane clipping
 *  - guard-band clipping performed in homogeneous clip space (pre-divide),
 *    using a symmetric, sign-reversible intersection so that a shared edge
 *    produces bit-identical clipped vertices for both adjacent triangles
 *  - degenerate and back-facing primitives are culled (no depth writes)
 *
 * Clip-space convention:
 *   vertex = { x, y, z, w, a:[...] }   with w > 0
 *   ndc    = (x/w, y/w, z/w), depth = z/w in [0,1]
 *   screen = ((ndc.x+1)*0.5*W, (1-ndc.y)*0.5*H)   (y down, origin top-left)
 *   a front face has positive screen-space area with the orient2d below.
 */

const SUBPIXEL_BITS = 8;
const ONE = 1 << SUBPIXEL_BITS;      // 256 subpixels per pixel
const HALF = ONE >> 1;               // pixel-center offset = 128

/* ------------------------------------------------------------------ */
/* clipping                                                            */
/* ------------------------------------------------------------------ */

// Plane value over an *un-normalized* stored vertex:
//   value = A*x + B*y + C*z + D*w + E*s
// A vertex with value >= 0 is inside.  `s` is the homogeneous scale
// (stored = s * true_clip).  It is kept > 0 so the sign of the plane
// function is preserved by the projective scaling.
function planeValue(p, pl) {
  return pl.A * p.x + pl.B * p.y + pl.C * p.z + pl.D * p.w + pl.E * p.s;
}

function clipAgainstPlane(poly, pl) {
  const out = [];
  const n = poly.length;
  if (n === 0) return out;
  let a = poly[n - 1];
  let fa = planeValue(a, pl);
  for (let i = 0; i < n; i++) {
    const b = poly[i];
    const fb = planeValue(b, pl);
    const aIn = fa >= 0;
    const bIn = fb >= 0;
    if (aIn !== bIn) {
      // Symmetric projective intersection:
      //   p = fa*b - fb*a
      // Reversing the edge order negates every component exactly, so the
      // projective point (and every ratio) is bit-identical for the two
      // triangles that share the edge.
      const s = fa * b.s - fb * a.s;
      const v = {
        x: fa * b.x - fb * a.x,
        y: fa * b.y - fb * a.y,
        z: fa * b.z - fb * a.z,
        w: fa * b.w - fb * a.w,
        s: s,
        a: null,
      };
      v.a = new Array(a.a.length);
      for (let k = 0; k < a.a.length; k++) v.a[k] = fa * b.a[k] - fb * a.a[k];
      if (v.s < 0) {
        v.x = -v.x; v.y = -v.y; v.z = -v.z; v.w = -v.w; v.s = -v.s;
        for (let k = 0; k < v.a.length; k++) v.a[k] = -v.a[k];
      }
      out.push(v);
    }
    if (bIn) out.push(b);
    a = b;
    fa = fb;
  }
  return out;
}

function makeVertex(x, y, z, w, a) {
  return { x, y, z, w, s: 1, a: a.slice() };
}

function clipPolygon(poly, planes) {
  let p = poly;
  for (let i = 0; i < planes.length && p.length > 0; i++) {
    p = clipAgainstPlane(p, planes[i]);
  }
  return p;
}

/* ------------------------------------------------------------------ */
/* projection / rasterization                                          */
/* ------------------------------------------------------------------ */

function orient2d(ax, ay, bx, by, cx, cy) {
  return (bx - ax) * (cy - ay) - (by - ay) * (cx - ax);
}

function isTopLeft(a, b) {
  const dx = b.X - a.X;
  const dy = b.Y - a.Y;
  // Interior of a positive-area triangle lies where orient2d > 0.
  // Include a pixel-center exactly on the edge only for left edges
  // (going upward, dy < 0) and top edges (horizontal, dx > 0).
  return dy < 0 || (dy === 0 && dx > 0);
}

function projectVertex(v, W, H) {
  const invW = 1 / v.w;               // projective divide (w > 0)
  const ndcX = v.x * invW;
  const ndcY = v.y * invW;
  const ndcZ = v.z * invW;
  const sx = (ndcX + 1) * 0.5 * W;
  const sy = (1 - ndcY) * 0.5 * H;
  const invWp = v.s * invW;           // 1/true_w
  const pa = new Array(v.a.length);
  for (let k = 0; k < v.a.length; k++) pa[k] = v.a[k] * invW; // a/true_w
  return {
    X: Math.round(sx * ONE),
    Y: Math.round(sy * ONE),
    z: ndcZ,
    invW: invWp,
    pa: pa,
  };
}

/* ------------------------------------------------------------------ */
/* renderer                                                            */
/* ------------------------------------------------------------------ */

class Framebuffer {
  constructor(W, H, attrCount) {
    this.W = W;
    this.H = H;
    this.attrCount = attrCount;
    this.depth = new Float64Array(W * H).fill(Infinity);
    this.attrs = new Float64Array(W * H * attrCount); // perspective-correct
    this.count = new Uint16Array(W * H);              // coverage counter
  }
}

function renderTriangle(verts, fb, options) {
  const W = fb.W, H = fb.H;
  const doCull = options.cull !== false;

  const p0 = projectVertex(verts[0], W, H);
  const p1 = projectVertex(verts[1], W, H);
  const p2 = projectVertex(verts[2], W, H);

  const area2 = orient2d(p0.X, p0.Y, p1.X, p1.Y, p2.X, p2.Y);
  if (doCull && area2 <= 0) return;      // degenerate or back face: no write
  if (area2 === 0) return;

  // bounding box in pixels
  let minX = Math.min(p0.X, p1.X, p2.X);
  let maxX = Math.max(p0.X, p1.X, p2.X);
  let minY = Math.min(p0.Y, p1.Y, p2.Y);
  let maxY = Math.max(p0.Y, p1.Y, p2.Y);
  minX = Math.max(0, Math.floor(minX / ONE));
  maxX = Math.min(W - 1, Math.ceil(maxX / ONE));
  minY = Math.max(0, Math.floor(minY / ONE));
  maxY = Math.min(H - 1, Math.ceil(maxY / ONE));

  const invArea = 1 / area2;
  const attrCount = fb.attrCount;

  for (let y = minY; y <= maxY; y++) {
    const cy = y * ONE + HALF;
    for (let x = minX; x <= maxX; x++) {
      const cx = x * ONE + HALF;

      const e0 = orient2d(p1.X, p1.Y, p2.X, p2.Y, cx, cy); // opposite v0
      const e1 = orient2d(p2.X, p2.Y, p0.X, p0.Y, cx, cy); // opposite v1
      const e2 = orient2d(p0.X, p0.Y, p1.X, p1.Y, cx, cy); // opposite v2

      if (e0 < 0 || e1 < 0 || e2 < 0) continue;
      if (e0 === 0 && !isTopLeft(p1, p2)) continue;
      if (e1 === 0 && !isTopLeft(p2, p0)) continue;
      if (e2 === 0 && !isTopLeft(p0, p1)) continue;

      const idx0 = y * W + x;
      fb.count[idx0]++;

      const l0 = e0 * invArea;
      const l1 = e1 * invArea;
      const l2 = e2 * invArea;

      const depth = l0 * p0.z + l1 * p1.z + l2 * p2.z;
      const idx = idx0;
      if (depth >= fb.depth[idx]) continue;   // z-test, strict less wins

      fb.depth[idx] = depth;
      const iw = l0 * p0.invW + l1 * p1.invW + l2 * p2.invW;
      const base = idx * attrCount;
      for (let k = 0; k < attrCount; k++) {
        const num = l0 * p0.pa[k] + l1 * p1.pa[k] + l2 * p2.pa[k];
        fb.attrs[base + k] = num / iw;
      }
    }
  }
}

/**
 * Render an array of clip-space triangles.
 * tri = [v0, v1, v2], each v = {x,y,z,w,a:[...]}.
 */
function render(tris, W, H, attrCount, options) {
  options = options || {};
  const fb = new Framebuffer(W, H, attrCount);
  const G = options.guardBand !== undefined ? options.guardBand : 8;
  const eps = options.wEps !== undefined ? options.wEps : 1e-9;
  const planes = [
    { A: 0, B: 0, C: 1, D: 0, E: 0 },          // near:  z >= 0
    { A: 0, B: 0, C: -1, D: 1, E: 0 },         // far:   z <= w
    { A: 1, B: 0, C: 0, D: G, E: 0 },          // left:  x >= -G*w
    { A: -1, B: 0, C: 0, D: G, E: 0 },         // right: x <=  G*w
    { A: 0, B: 1, C: 0, D: G, E: 0 },          // bottom:y >= -G*w
    { A: 0, B: -1, C: 0, D: G, E: 0 },         // top:   y <=  G*w
    { A: 0, B: 0, C: 0, D: 1, E: -eps },       // w >= eps
  ];
  for (let i = 0; i < tris.length; i++) {
    const clipped = clipPolygon(tris[i], planes);
    if (clipped.length < 3) continue;
    // fan triangulation
    for (let j = 1; j + 1 < clipped.length; j++) {
      renderTriangle([clipped[0], clipped[j], clipped[j + 1]], fb, options);
    }
  }
  return fb;
}

module.exports = {
  ONE, HALF, SUBPIXEL_BITS,
  makeVertex, clipPolygon, render, renderTriangle, Framebuffer,
  orient2d, isTopLeft, projectVertex,
};

How the pieces map to the requirements

  • Top-left fill rule — isTopLeft() + the three e === 0 guards in renderTriangle(). Coverage is exact integer orient2d at the pixel center.
  • Perspective-correct 1/w — projectVertex() stores invW = s/w and pa = a/w; the inner loop computes num / iw where num = Σ λ·(a/w) and iw = Σ λ·(1/w).
  • Homogeneous near-plane + guard-band clipping — the plane list in render() (z >= 0, z <= w, and four ±G·w side planes) is applied by clipPolygon() before projectVertex(), i.e. before the divide.
  • Crack-free clipping — clipAgainstPlane() uses the symmetric p = fa·b − fb·a form and keeps a stored homogeneous scale s > 0, so shared edges produce identical clipped vertices.
  • Cull back/degenerate — if (doCull && area2 <= 0) return; before the bounding box, so nothing is written for culled primitives.
  • Z-buffer after clipping — depth (z/w) is interpolated per covered pixel and compared with the usual strict depth < zbuffer[idx] test.

The w >= eps plane (E: -eps) protects the divide: s is the homogeneous scale of the stored vertex, and w - eps·s >= 0 is the correct linear form of true_w >= eps because true_w = w/s with s > 0.

// Grid of triangles over NDC rectangle [x0,x1] x [y0,y1].
// opl(ndc) -> {w, z} lets the caller vary homogeneous w / depth per vertex.
function buildGrid(N, x0, x1, y0, y1, opl) {
  opl = opl || (() => ({ w: 1, z: 0 }));
  const P = [];
  for (let j = 0; j <= N; j++) {
    P[j] = [];
    for (let i = 0; i <= N; i++) {
      const nx = x0 + (x1 - x0) * i / N;
      const ny = y0 + (y1 - y0) * j / N;
      const o = opl(nx, ny);
      // clip vertex: (ndc*w, ndc*w, z, w)
      P[j][i] = R.makeVertex(nx * o.w, ny * o.w, o.z, o.w, [j * (N + 1) + i]);
    }
  }
  const tris = [];
  for (let j = 0; j < N; j++) {
    for (let i = 0; i < N; i++) {
      const A = P[j][i], B = P[j][i + 1], C = P[j + 1][i + 1], D = P[j + 1][i];
      // screen-positive winding (y flip)
      tris.push([A, C, B]);
      tris.push([A, D, C]);
    }
  }
  return tris;
}

function coverageStats(fb) {
  let over = 0, one = 0, zero = 0;
  for (let i = 0; i < fb.count.length; i++) {
    if (fb.count[i] === 0) zero++;
    else if (fb.count[i] === 1) one++;
    else over++;
  }
  return { over, one, zero };
}

function toScreenX(ndcX, W) { return (ndcX + 1) * 0.5 * W; }
function toScreenY(ndcY, H) { return (1 - ndcY) * 0.5 * H; }

(function testPerspective() {
  console.log('\n[4] perspective-correct interpolation');
  const W = 64, H = 64;
  // NDC vertices chosen so projected screen positions are integers and
  // therefore snapping to the subpixel grid is exact (removes snapping
  // error from the comparison).  w = -z_eye varies per vertex.
  const ndc = [
    [-0.75, -0.5],
    [ 0.50, -0.25],
    [ 0.125, 0.75],
  ];
  const wv = [2, 4, 3];
  // camera-space points: (x,y,z_eye) = (ndcX*w, ndcY*w, -w)
  const P = ndc.map((n, i) => [n[0] * wv[i], n[1] * wv[i], -wv[i]]);
  // order that yields positive screen-space area
  const order = [0, 2, 1];
  const tris = [order.map(i => R.makeVertex(
    P[i][0], P[i][1], -P[i][2] * 0.5, -P[i][2],
    [P[i][0], P[i][1], 1]))];
  const fb = R.render(tris, W, H, 3, { guardBand: 8 });

  // plane through P
  const e1 = [P[1][0] - P[0][0], P[1][1] - P[0][1], P[1][2] - P[0][2]];
  const e2 = [P[2][0] - P[0][0], P[2][1] - P[0][1], P[2][2] - P[0][2]];
  const n = [
    e1[1] * e2[2] - e1[2] * e2[1],
    e1[2] * e2[0] - e1[0] * e2[2],
    e1[0] * e2[1] - e1[1] * e2[0],
  ];
  const ndp0 = n[0] * P[0][0] + n[1] * P[0][1] + n[2] * P[0][2];

  let tested = 0, maxErr = 0, worst = null;
  for (let y = 0; y < H; y++) {
    for (let x = 0; x < W; x++) {
      const idx = y * W + x;
      if (fb.count[idx] === 0) continue;
      const sx = x + 0.5, sy = y + 0.5;
      const ndcX = 2 * sx / W - 1;
      const ndcY = 1 - 2 * sy / H;
      const d = [ndcX, ndcY, -1];
      const denom = n[0] * d[0] + n[1] * d[1] + n[2] * d[2];
      if (Math.abs(denom) < 1e-12) continue;
      const t = ndp0 / denom;
      const ex = t * ndcX, ey = t * ndcY;
      const ax = fb.attrs[idx * 3 + 0];
      const ay = fb.attrs[idx * 3 + 1];
      const err = Math.max(Math.abs(ax - ex), Math.abs(ay - ey));
      if (err > maxErr) { maxErr = err; worst = { x, y, ax, ex, ay, ey }; }
      tested++;
    }
  }
  check('covered enough pixels', tested > 400, 'tested=' + tested);
  check('perspective attributes match analytic values', maxErr < 1e-9,
    'maxErr=' + maxErr + ' worst=' + JSON.stringify(worst));
})();

(function testZBufferAndCulling() {
  console.log('\n[5] z-buffer, back-face and degenerate culling');
  const W = 32, H = 32;

  const front = [
    R.makeVertex(-1.5, -1.5, 0.6, 1, [1]),
    R.makeVertex(-1.5,  3.0, 0.6, 1, [1]),
    R.makeVertex( 3.0, -1.5, 0.6, 1, [1]),
  ];
  const back = [
    R.makeVertex(-1.5, -1.5, 0.2, 1, [2]),
    R.makeVertex( 3.0, -1.5, 0.2, 1, [2]),
    R.makeVertex(-1.5,  3.0, 0.2, 1, [2]),
  ];
  const degen = [
    R.makeVertex(-1.5, -1.5, 0.1, 1, [3]),
    R.makeVertex( 3.0, -1.5, 0.1, 1, [3]),

What each section proves

  1. Seamless tiling / top-left rule — a grid of two-triangle cells over the whole viewport (N = 4,7,8,16,128); every pixel must be covered exactly once. N = 128 makes many vertices land exactly on pixel centers, exercising the e == 0 tie-break.
  2. Guard-band clipping — the grid spans [-2,2]², viewport [-1,1]², guard band tightened to G = 1.001, 1.25, 1.5, 3. The viewport must still tile exactly once, proving clipped shared edges do not crack.
  3. Near-plane clipping — z = (0.5 − ndcX)·0.5 cuts the near plane through the grid (both w = 1 and varying w); the visible region tiles exactly once and the clipped region is empty.
  4. Perspective-correct interpolation — w = 2,4,3 with attributes equal to camera-space x/y; every covered pixel is compared to an independent ray/plane ground truth. Required error < 1e-9 (achieved ≈ 2e-16).
  5. Z-buffer + culling — a near front face beats a closer back face and a degenerate triangle; draw order does not matter; back faces/degenerates alone write nothing.
  6. Pixel-exact coverage vs BigInt reference — a separately written exact-integer coverage implementation is compared mask-for-mask for a shared-edge quad, a shared-vertex fan, and a guard-band-clipped grid.

Notes / portability

  • Node 20+; uses only Float64Array, Uint16Array, Math, no dependencies.
  • SUBPIXEL_BITS = 8 can be raised for very large viewports; integer edge functions stay inside IEEE-754's 53-bit exact-integer range for realistic resolutions.
  • guardBand (default 8, NDC units) keeps all clipping in homogeneous space, which is what prevents cracks.
  • Framebuffer.count exists purely for coverage verification and is not needed in a shipping renderer.

Summary of the fix: the rasterizer clips in homogeneous clip space using a symmetric fa·b − fb·a intersection (so adjacent triangles share bit-identical clipped edges), snaps to a 1/256-pixel integer lattice once per vertex, applies the top-left fill rule on exact integer edge functions, interpolates a/w and 1/w then divides, culls area2 <= 0 before touching depth, and resolves depth with a strict z-test after clipping.
