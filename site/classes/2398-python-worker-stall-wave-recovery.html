Root cause (summary)

The wave runner used process liveness as a proxy for progress: an "alive but stalled" GLM worker blocked on an unterminated socket read or interactive stdin, so it never tripped a timeout. Compounding it: termination killed only the child PID (orphaning grandchildren and wedging worktrees), exit 0 could be treated as success without a branch artifact (risking false closure), and cleanup deleted tasks/worktrees before evidence was persisted. Tier 2 had no defined "no-op" representation.

Fix (summary)

  1. run_worker — own process group/session, stdin=DEVNULL, non-interactive git env, a reader thread that updates a heartbeat on every byte, independent stall_timeout + wall_timeout, SIGTERM→SIGKILL to the whole group, and preserved output_tail as evidence.
  2. recover — persist branch-proof board + GitReins (tier2: "skipped" with reason) before deleting temp tasks and removing/pruning worktrees; then commit and push.
  3. classify — succeeded requires exit 0 and a verified clean branch with commits; reproduced baseline failures become requeued, never closed.

Verification (actual output)

  • Supervisor: ALL 5 TESTS PASSED (silent stall killed at 2.0s idle; partial output extends liveness but stays bounded; grandchild reaped; exit 3 → crashed).
  • Integration: t1–t3 = failed (stall evidence retained), t4 = requeued (baseline), tier2 = skipped, 4 temp tasks deleted, worktrees removed, commit present on main and the bare remote.
