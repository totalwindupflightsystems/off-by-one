What was built

A from-scratch adaptive Dormand–Prince RK5(4) integrator (no SciPy — only NumPy) with:

  • Embedded error estimation — the DP 4/5 pair, err = h·(B5−B4)·K, scaled-RMS norm, accept/reject loop with FSAL (7th stage reused as the next derivative)
  • PI step-size control — Gustavsson/Söderlind controller h_{n+1} = h_n·safety·err_n^{−kP/5}·err_{n−1}^{−kI/5} (kP=0.7, kI=0.4); integral action drives steady-state error to a fixed value and kills step-size oscillation
  • Cubic-Hermite dense output per accepted step, with bisection on g(H(τ)) to locate zero crossings, plus a re-integration/rebisect refinement loop that stops exactly on terminal events (bracket shrinks as width⁴ per cycle → machine precision)

Verification results (all PASS)

  • Scalar y'=y: global relative error tracks rtol (2.1e-9 @ rtol=1e-9)
  • Kepler e=0.7, 20 orbits: max|ΔE| = 1.9e-9, max|ΔL| = 6.9e-10 (< 1e-8); 50 orbits → 5.3e-10
  • van der Pol μ=1000 (stiff): deviation 1.8e-8 @ rtol=1e-6 vs a 1e-12 reference, min step ~5e-5 through the relaxation
  • Bouncing ball: 12 bounces machine-exact vs closed form — worst error 8.2e-14; t[-1] == t_events[0][0] exactly
  • Pendulum θ₀=2.0 rad: θ=0 crossing matches exact elliptic-integral T/4 (AGM) to 2.7e-15
  • Kepler perihelion (non-polynomial event g=y): t=π to 4.5e-13
  • Edge cases: non-terminal events, direction ±1 filtering, h0/hmax, dense output consistency
