Real-time (Wing–Gong/Lowe) Linearizability Checker for Concurrent Read/Write Registers

Problem class: go-linearizability-register-history-wgl-check — Go 1.26

1. Root-cause analysis

A correct checker is hard for four independent reasons, and the usual naive implementation fails on each of them:

  1. Permutation enumeration is factorial. Trying every total order of the operations is O(n!). Concurrent histories routinely have dozens of mutations, so enumeration never terminates in practice.
  2. Reordering is permitted, but only inside the real-time window. Linearizability does not require the file/NDJSON order or a global timestamp order. It requires the linearisation to extend the happens-before relation a → b iff a.Ret < b.Call. Operations that overlap may be reordered. A checker that hard-codes arrival order gives false negatives; one that ignores the relation entirely gives false positives.
  3. Pending operations and the initial value are easy to get wrong. An invoke with no respond is indeterminate: a completion may or may not include it. Its read result is unknown (wildcard), it never precedes another operation, and it may be dropped. The register's initial value is also unknown unless explicitly declared: the first read pins it, and two concurrent reads that disagree on an unwritten register are a genuine violation.
  4. State must stay separable per register. Linearizability is a local property (Herlihy–Wing): a history is linearizable iff its projection onto every object is. Keeping one global state couples independent registers and destroys both correctness and pruning.

The fix is the Wing–Gong / Lowe algorithm: a depth-first search over linearisations that

  • only considers an operation once all of its happens-before predecessors are placed (the wing),
  • tries the operation with the earliest response first (the pivot, which finds counterexamples quickly),
  • memoises each node by (set of placed ops, per-register state) so the factorial space collapses to the set of reachable states,
  • treats responded operations as mandatory and pending operations as optional,
  • and is run per register projection, so the register state stays separable.

Crucially the pivot is only a search order, not a commitment: the counterexample w = write(1)[0,2], r = read()→0[0,5] is linearizable only if r runs first even though w responds first, so every available candidate is still tried before a node is declared failed (completeness).

2. Input / output contract

Input — NDJSON event log

One JSON object per line. event (aliases type/action) selects the kind. invoke/call opens an operation, respond/return closes it, init declares a register's initial value. Field aliases are accepted.

{"event":"init","reg":"x","val":0}
{"event":"invoke","op":1,"proc":"P1","reg":"x","kind":"write","val":1,"ts":0}
{"event":"respond","op":1,"proc":"P1","reg":"x","kind":"write","val":1,"ts":1}
{"event":"invoke","op":2,"proc":"P2","reg":"x","kind":"read","ts":2}
{"event":"respond","op":2,"proc":"P2","reg":"x","kind":"read","val":1,"ts":3}
  • kind is read or write; val is the write payload or the read result.
  • op, proc, reg, ts are optional. Without ts the line order is the clock; without op responses are paired with the latest pending invoke of the same (proc, reg).
  • An invoke without a respond is an indeterminate pending operation.

Output — JSON verdict

{
  "linearizable": false,
  "register": "x",
  "failing_prefix": [2, 3],
  "violated_edge": {
    "from": 2, "to": 3, "kind": "happens-before",
    "detail": "operation 3 (P1) observed 0 but real-time order requires it ..."
  },
  "reason": "..."
}
  • failing_prefix — operation ids of an inclusion-minimal subset of the failing register that is still non-linearizable, sorted by invocation time.
  • violated_edge — a happens-before constraint from → to that cannot be honoured (first choice: an edge whose removal restores linearizability; for an initial-value clash, from = -1 and kind = "initial-value").

Exit status is 0 when linearizable and 1 when not.

package main

import (
    "encoding/json"
    "fmt"
    "sort"
)

// Operation is one invoked operation on a single register.
//
// Real-time order between two operations a and b is defined by
// a.Ret < b.Call, i.e. a returned before b was invoked.  A pending
// operation (no respond event) has Ret == math.MaxInt64 and therefore
// never precedes another operation; it may be omitted from a completion
// or linearised after all of its predecessors.
type Operation struct {
    ID      int    `json:"id"`
    Proc    string `json:"proc"`
    Reg     string `json:"reg"`
    IsWrite bool   `json:"is_write"`
    Val     any    `json:"val"`
    HasVal  bool   `json:"-"`
    Pending bool   `json:"pending"`
    Call    int64  `json:"call"`
    Ret     int64  `json:"ret"`

    seq int // stable tie-break / input order
}

// valueKey canonicalises an arbitrary JSON value so that two values are
// equal iff their keys are equal.
func valueKey(v any) string {
    if v == nil {
        return "null"
    }
    b, err := json.Marshal(v)
    if err != nil {
        return fmt.Sprintf("%#v", v)
    }
    return string(b)
}

func valuesEqual(a, b any) bool { return valueKey(a) == valueKey(b) }

// regState is the separable per-register model state: the register's
// current value plus whether it has been written (or pinned by a read).
type regState struct {
    set   bool
    value any
}

func (s regState) key() string {
    if !s.set {
        return "0"
    }
    return "1|" + valueKey(s.value)
}

// ---------------------------------------------------------------------------
// bitset: compact set of linearised operation indices (indices are local to
// one register's operation slice).
// ---------------------------------------------------------------------------

type bitset []byte

func newBitset(n int) bitset { return make(bitset, (n+7)/8) }

func (b bitset) set(i int)      { b[i>>3] |= 1 << (uint(i) & 7) }
func (b bitset) clear(i int)    { b[i>>3] &^= 1 << (uint(i) & 7) }
func (b bitset) has(i int) bool { return b[i>>3]&(1<<(uint(i)&7)) != 0 }

func (b bitset) clone() bitset {
    c := make(bitset, len(b))
    copy(c, b)
    return c
}

func (b bitset) empty() bool {
    for _, x := range b {
        if x != 0 {
            return false
        }
    }
    return true
}

// subset reports whether every bit set in a is also set in b.
func subset(a, b bitset) bool {
    if len(a) != len(b) {
        return false
    }
    for i := range a {
        if a[i]&^b[i] != 0 {
            return false
        }
    }
    return true
}

// ---------------------------------------------------------------------------
// Result / witness types
// ---------------------------------------------------------------------------

// Edge is a happens-before constraint that could not be reconciled with the
// sequential register semantics.
type Edge struct {
    From   int    `json:"from"`
    To     int    `json:"to"`
    Kind   string `json:"kind"`
    Detail string `json:"detail"`
}

// Result is the JSON verdict emitted by the checker.
type Result struct {
    Linearizable  bool   `json:"linearizable"`
    Register      string `json:"register,omitempty"`
    FailingPrefix []int  `json:"failing_prefix,omitempty"`
    ViolatedEdge  *Edge  `json:"violated_edge,omitempty"`
    Reason        string `json:"reason,omitempty"`
}

// sortByCall orders a subset of operations by invocation time.
func sortByCall(ops []*Operation) {
    sort.SliceStable(ops, func(i, j int) bool {
        if ops[i].Call != ops[j].Call {
            return ops[i].Call < ops[j].Call
        }
        return ops[i].seq < ops[j].seq
    })
}

checker.go — the Wing–Gong/Lowe search

package main

import "sort"

// checker runs the Wing-Gong / Lowe linearizability search for a single
// register.  Operations on other registers never appear here: linearizability
// is a local property, so the register projections may be checked
// independently and the register model state stays separable.
//
// The search is a depth-first enumeration of linearisations.  At every node
// only operations whose happens-before predecessors are all linearised are
// candidates ("wing").  The candidate with the earliest response is tried
// first ("pivot"); this finds witnesses quickly but, because every candidate
// is tried before a node is declared failed, completeness is preserved.
//
// memoisation keys a node by (set of linearised ops, per-register state).
// Repeated (done, state) pairs are answered from the cache, which collapses
// the factorial permutation space.  Operations that have been invoked but not
// responded ("indeterminate pending") are optional: the base case succeeds
// once every responded operation is linearised, so pending operations may
// simply be dropped.
type checker struct {
    ops          []*Operation
    preds        []bitset // preds[i] = operations that must precede i
    completeLeft int
    init         regState // register value before the first operation
    memo         map[string]bool
    steps        int
}

// newChecker builds the happens-before predecessor sets for ops.  If
// (ignoreFrom, ignoreTo) is non-negative the real-time constraint
// ops[ignoreFrom] -> ops[ignoreTo] is dropped (used to isolate a violated
// edge after a negative verdict).
func newChecker(ops []*Operation, ignoreFrom, ignoreTo int, init regState) *checker {
    n := len(ops)
    c := &checker{ops: ops, init: init, memo: make(map[string]bool)}
    c.preds = make([]bitset, n)
    for i := 0; i < n; i++ {
        c.preds[i] = newBitset(n)
        if !ops[i].Pending {
            c.completeLeft++
        }
    }
    for i := 0; i < n; i++ {
        for j := 0; j < n; j++ {
            if i == j {
                continue
            }
            if ops[i].Ret < ops[j].Call {
                if i == ignoreFrom && j == ignoreTo {
                    continue
                }
                c.preds[j].set(i)
            }
        }
    }
    return c
}

// linearizable reports whether the operations admit a linearisation.
func (c *checker) linearizable() bool {
    return c.dfs(newBitset(len(c.ops)), c.init, c.completeLeft)
}

func (c *checker) dfs(done bitset, st regState, completeLeft int) bool {
    c.steps++
    // Every responded operation has been placed; the remaining pending
    // operations may be left incomplete, so we are done.
    if completeLeft == 0 {
        return true
    }

    key := string(done) + "#" + st.key()
    if v, ok := c.memo[key]; ok {
        return v
    }

    type cand struct {
        idx int
        ret int64
    }
    var cands []cand
    for i, op := range c.ops {
        if done.has(i) {
            continue
        }
        if !subset(c.preds[i], done) {
            continue
        }
        cands = append(cands, cand{i, op.Ret})
    }
    // Pivot: earliest response first.  Pending ops (MaxInt64) are tried last.
    sort.Slice(cands, func(i, j int) bool {
        if cands[i].ret != cands[j].ret {
            return cands[i].ret < cands[j].ret
        }
        return c.ops[cands[i].idx].seq < c.ops[cands[j].idx].seq
    })

    for _, cd := range cands {
        op := c.ops[cd.idx]
        ns := st
        valid := false
        switch {
        case op.IsWrite:
            ns.set = true
            ns.value = op.Val
            valid = true
        case op.Pending:
            // Indeterminate read: it can return whatever the state
            // currently holds, so it never constrains the state.
            valid = true
        case !st.set:
            // First read pins the register's initial value.
            ns.set = true
            ns.value = op.Val
            valid = true
        default:
            valid = valuesEqual(st.value, op.Val)
        }
        if !valid {
            continue
        }
        nd := done.clone()
        nd.set(cd.idx)
        ncl := completeLeft
        if !op.Pending {
            ncl--
        }
        if c.dfs(nd, ns, ncl) {
            return true
        }
    }

    c.memo[key] = false
    return false
}

// isLinearizable is a convenience wrapper used by the witness search.
func isLinearizable(ops []*Operation, init regState) bool {
    return newChecker(ops, -1, -1, init).linearizable()
}

func isLinearizableIgnoringEdge(ops []*Operation, from, to int, init regState) bool {
    return newChecker(ops, from, to, init).linearizable()
}

witness.go — verdict, minimal prefix and violated edge

package main

import "sort"

// Check decides linearizability of a whole history.
//
// Linearizability is a local property: a history is linearizable iff its
// projection onto every object (register) is linearizable.  We therefore
// partition the operations by register and run the Wing-Gong/Lowe search on
// each projection independently.  This is what keeps the per-register state
// separable and avoids an unnecessary cross-register state product.
func Check(ops []*Operation, inits map[string]any) Result {
    byReg := make(map[string][]*Operation)
    var order []string
    for _, op := range ops {
        if _, ok := byReg[op.Reg]; !ok {
            order = append(order, op.Reg)
        }
        byReg[op.Reg] = append(byReg[op.Reg], op)
    }
    // deterministic order of registers: by first invocation
    sort.Slice(order, func(i, j int) bool {
        return byReg[order[i]][0].Call < byReg[order[j]][0].Call
    })

    for _, reg := range order {
        projection := byReg[reg]
        initial := regState{}
        if v, ok := inits[reg]; ok {
            initial = regState{set: true, value: v}
        }
        if isLinearizable(projection, initial) {
            continue
        }
        return buildWitness(reg, projection, initial)
    }
    return Result{Linearizable: true}
}

// buildWitness produces a minimal failing prefix and the happens-before edge
// whose reversal is forced by the register semantics.
func buildWitness(reg string, ops []*Operation, initial regState) Result {
    // Greedily shrink to an inclusion-minimal non-linearizable subset.  Each
    // removal is accepted only while the subset stays non-linearizable, so the
    // final set has no redundant operation.
    sel := append([]*Operation(nil), ops...)
    for {
        changed := false
        for i := 0; i < len(sel); i++ {
            trial := make([]*Operation, 0, len(sel)-1)
            trial = append(trial, sel[:i]...)
            trial = append(trial, sel[i+1:]...)
            if len(trial) == 0 {
                continue
            }
            if !isLinearizable(trial, initial) {
                sel = trial
                changed = true
                break
            }
        }
        if !changed {
            break
        }
    }
    sortByCall(sel)

    // A non-linearizable register history must contain a real-time edge
    // a -> b (a.Ret < b.Call) that cannot be honoured.  Find one whose removal
    // makes the failing subset linearizable again.
    edge := findViolatedEdge(sel, initial)
    if edge != nil {
        edge.Kind = "happens-before"
        edge.Detail = edgeDetail(sel, edge)
    } else if initial.set {
        // A read that directly contradicts the declared initial value.
        for _, op := range sel {
            if !op.IsWrite && op.HasVal && !valuesEqual(initial.value, op.Val) {
                edge = &Edge{
                    From: -1,
                    To:   op.ID,
                    Kind: "initial-value",
                    Detail: "operation " + itoa(op.ID) + " observed " +
                        valueKey(op.Val) + " but the register is declared to start at " +
                        valueKey(initial.value),
                }
                break
            }
        }
    }

    prefix := make([]int, len(sel))
    for i, op := range sel {
        prefix[i] = op.ID
    }

    res := Result{
        Linearizable:  false,
        Register:      reg,
        FailingPrefix: prefix,
        ViolatedEdge:  edge,
    }
    if edge == nil {
        res.Reason = "no linearisation of register " + reg +
            " exists; see failing_prefix"
    } else {
        res.Reason = "register " + reg + ": cannot linearise operation " +
            itoa(edge.To) + " after operation " + itoa(edge.From) +
            " although it returned first"
    }
    return res
}

// findViolatedEdge returns a real-time edge inside sel whose removal restores
// linearizability, preferring edges whose target is a read.
func findViolatedEdge(sel []*Operation, initial regState) *Edge {
    type pair struct{ from, to int }
    var pairs []pair
    for i := 0; i < len(sel); i++ {
        for j := 0; j < len(sel); j++ {
            if i == j {
                continue
            }
            if sel[i].Ret < sel[j].Call {
                pairs = append(pairs, pair{i, j})
            }
        }
    }
    // Reads make the most informative witnesses.
    sort.SliceStable(pairs, func(a, b int) bool {
        ra := !sel[pairs[a].to].IsWrite
        rb := !sel[pairs[b].to].IsWrite
        if ra != rb {
            return ra
        }
        return sel[pairs[a].to].Call < sel[pairs[b].to].Call
    })
    for _, p := range pairs {
        if isLinearizableIgnoringEdge(sel, p.from, p.to, initial) {
            return &Edge{From: sel[p.from].ID, To: sel[p.to].ID}
        }
    }
    // No single edge is solely responsible (e.g. two reads that disagree on
    // the register's initial value).  Report the most informative real-time
    // edge: one whose target is a read, tightening any ties by response gap.
    var best *pair
    for i := range pairs {
        p := pairs[i]
        if best == nil {
            best = &p
            continue
        }
        bTgtRead := !sel[p.to].IsWrite
        cTgtRead := !sel[best.to].IsWrite
        if bTgtRead != cTgtRead {
            if bTgtRead {
                best = &p
            }
            continue
        }
        bGap := sel[p.to].Call - sel[p.from].Ret
        cGap := sel[best.to].Call - sel[best.from].Ret
        if bGap < cGap {
            best = &p
        }
    }
    if best != nil {
        return &Edge{From: sel[best.from].ID, To: sel[best.to].ID}
    }
    return nil
}

func edgeDetail(sel []*Operation, e *Edge) string {
    var from, to *Operation
    for _, op := range sel {
        if op.ID == e.From {
            from = op
        }
        if op.ID == e.To {
            to = op
        }
    }
    if from == nil || to == nil {
        return "real-time order conflicts with register semantics"
    }
    if !to.IsWrite && to.HasVal {
        return "operation " + itoa(to.ID) + " (" + to.Proc + ") observed " +
            valueKey(to.Val) + " but real-time order requires it to start only " +
            "after operation " + itoa(from.ID) + " (" + from.Proc + "), whose " +
            "effect cannot be reconciled with that observation"
    }
    return "operation " + itoa(from.ID) + " must precede operation " +
        itoa(to.ID) + " by real-time order, but the register semantics force " +
        "the opposite ordering"
}

func itoa(n int) string {
    if n == 0 {
        return "0"
    }
    neg := n < 0
    if neg {
        n = -n
    }
    var buf [20]byte
    i := len(buf)
    for n > 0 {
        i--
        buf[i] = byte('0' + n%10)
        n /= 10
    }
    if neg {
        i--
        buf[i] = '-'
    }
    return string(buf[i:])
}

type rawEvent map[string]json.RawMessage

func isInvoke(s string) bool {
    switch strings.ToLower(s) {
    case "invoke", "call", "request", "invocation":
        return true
    }
    return false
}

func isRespond(s string) bool {
    switch strings.ToLower(s) {
    case "respond", "response", "return", "reply", "ok":
        return true
    }
    return false
}

// ParseEvents reads an NDJSON event log and returns the operations plus any
// explicit per-register initial values.
//
// Accepted line shapes (field aliases in parentheses):
//
//  {"event":"invoke","op":1,"proc":"P1","reg":"x","kind":"write","val":1,"ts":0}
//  {"event":"respond","op":1,"proc":"P1","reg":"x","kind":"write","val":1,"ts":1}
//  {"event":"init","reg":"x","val":0}
//
// event/type/action selects the line kind.  kind/op_type selects read|write.
// ts/time/timestamp is optional; without it the NDJSON line order is used.
// An invoke without a matching respond is an indeterminate pending operation.
func ParseEvents(r io.Reader) ([]*Operation, map[string]any, error) {
    inits := map[string]any{}
    byID := map[int]*Operation{}
    var all []*Operation
    // For events without an explicit op id, pair a respond with the most
    // recent unmatched invoke having the same proc+reg.
    unmatched := map[string][]*Operation{}

    sc := bufio.NewScanner(r)
    sc.Buffer(make([]byte, 0, 1<<20), 1<<26)
    lineNo := int64(0)
    order := 0

    for sc.Scan() {
        lineNo++
        line := bytes.TrimSpace(sc.Bytes())
        if len(line) == 0 || line[0] == '#' {
            continue
        }
        var ev rawEvent
        if err := json.Unmarshal(line, &ev); err != nil {
            return nil, nil, fmt.Errorf("line %d: invalid JSON: %w", lineNo, err)
        }
        kind, _ := ev.str("event", "type", "action")
        if kind == "" {
            return nil, nil, fmt.Errorf("line %d: missing event/type", lineNo)
        }

        reg, _ := ev.str("reg", "register", "key")
        ts, hasTS := ev.integer("ts", "time", "timestamp")
        if !hasTS {
            ts = lineNo
        }

        switch {
        case strings.EqualFold(kind, "init") || strings.EqualFold(kind, "initial"):
            if reg == "" {
                return nil, nil, fmt.Errorf("line %d: init needs reg", lineNo)
            }
            v, _ := ev.anyValue("val", "value")
            inits[reg] = v

        case isInvoke(kind):
            proc, _ := ev.str("proc", "process", "client", "pid")
            opType, _ := ev.str("kind", "op_type", "optype")
            isWrite := strings.EqualFold(opType, "write")
            if opType == "" {
                // A value on the invoke is a write payload in most logs,
                // but ambiguous; require kind.
                return nil, nil, fmt.Errorf("line %d: invoke needs kind=read|write", lineNo)
            }
            if reg == "" {
                return nil, nil, fmt.Errorf("line %d: invoke needs reg", lineNo)
            }
            op := &Operation{
                Proc:    proc,
                Reg:     reg,
                IsWrite: isWrite,
                Call:    ts,
                Ret:     math.MaxInt64,
                Pending: true,
                seq:     order,
            }
            order++
            if id, ok := ev.integer("op", "op_id", "id", "oper"); ok {
                op.ID = int(id)
            } else {
                op.ID = -1 // resolved later
            }
            if isWrite {
                if v, ok := ev.anyValue("val", "value"); ok {
                    op.Val = v
                    op.HasVal = true
                }
            }
            if op.ID >= 0 {
                if _, dup := byID[op.ID]; dup {
                    return nil, nil, fmt.Errorf("line %d: duplicate op id %d", lineNo, op.ID)
                }
                byID[op.ID] = op
            }
            all = append(all, op)
            key := proc + "\x00" + reg
            unmatched[key] = append(unmatched[key], op)

        case isRespond(kind):
            proc, _ := ev.str("proc", "process", "client", "pid")
            var op *Operation
            if id, ok := ev.integer("op", "op_id", "id", "oper"); ok {
                op = byID[int(id)]
                if op == nil {
                    return nil, nil, fmt.Errorf("line %d: respond for unknown op %d", lineNo, int(id))
                }
            } else {
                key := proc + "\x00" + reg
                q := unmatched[key]
                // pick the latest still-pending invoke
                for len(q) > 0 {
                    candidate := q[len(q)-1]
                    q = q[:len(q)-1]
                    if candidate.Pending {
                        op = candidate
                        break
                    }
                }
                unmatched[key] = q
                if op == nil {
                    return nil, nil, fmt.Errorf("line %d: respond with no matching invoke", lineNo)
                }
            }
            op.Pending = false
            op.Ret = ts
            if !op.IsWrite {
                if v, ok := ev.anyValue("val", "value", "result"); ok {
                    op.Val = v
                    op.HasVal = true
                }
            }

        default:
            return nil, nil, fmt.Errorf("line %d: unknown event %q", lineNo, kind)
        }
    }
    if err := sc.Err(); err != nil {
        return nil, nil, err
    }

    // Resolve synthetic ids for logs that omit the op field.
    next := 1
    for _, op := range byID {
        if op.ID >= next {
            next = op.ID + 1
        }
    }
    for _, op := range all {
        if op.ID < 0 {
            op.ID = next
            next++
        }
    }
    // stable input order
    for i, op := range all {
        op.seq = i
    }
    return all, inits, nil
}

package main

import (
    "math/rand"
    "testing"
)

// bruteLinearizable is an independent, unoptimised reference: it enumerates
// every subset of operations that contains all responded operations, and every
// total order of that subset, checking real-time order and the register spec.
func bruteLinearizable(ops []*Operation, init regState) bool {
    n := len(ops)
    for mask := 0; mask < 1<<n; mask++ {
        var subset []*Operation
        ok := true
        for i, op := range ops {
            if mask&(1<<i) != 0 {
                subset = append(subset, op)
            } else if !op.Pending {
                ok = false // responded operations are mandatory
                break
            }
        }
        if !ok {
            continue
        }
        if brutePermute(subset, make([]bool, len(subset)), nil, init) {
            return true
        }
    }
    return false
}

func brutePermute(ops []*Operation, used []bool, order []*Operation, st regState) bool {
    if len(order) == len(ops) {
        return true
    }
next:
    for i, op := range ops {
        if used[i] {
            continue
        }
        // Real-time: every included predecessor must already be placed.
        for j, other := range ops {
            if j == i || used[j] {
                continue
            }
            if other.Ret < op.Call {
                continue next
            }
        }
        ns := st
        switch {
        case op.IsWrite:
            ns.set = true
            ns.value = op.Val
        case op.Pending:
            // always allowed
        case !st.set:
            ns.set = true
            ns.value = op.Val
        default:
            if !valuesEqual(st.value, op.Val) {
                continue
            }
        }
        used[i] = true
        order = append(order, op)
        if brutePermute(ops, used, order, ns) {
            return true
        }
        order = order[:len(order)-1]
        used[i] = false
    }
    return false
}

func TestRandomAgainstBruteForce(t *testing.T) {
    rng := rand.New(rand.NewSource(20240607))
    for trial := 0; trial < 20000; trial++ {
        n := 1 + rng.Intn(6)
        var ops []*Operation
        for i := 0; i < n; i++ {
            reg := []string{"x", "x", "y"}[rng.Intn(3)]
            proc := []string{"P1", "P2", "P3"}[rng.Intn(3)]
            write := rng.Intn(2) == 0
            call := int64(rng.Intn(8))
            ret := call + 1 + int64(rng.Intn(6))
            pending := rng.Intn(5) == 0
            var val any
            hasVal := true
            if write {
                val = rng.Intn(3)
            } else {
                // Half the time pick a plausible value, half arbitrary.
                if rng.Intn(2) == 0 {
                    val = rng.Intn(3)
                } else {
                    val = 3 + rng.Intn(2)
                }
            }
            op := &Operation{
                ID:      i + 1,
                Proc:    proc,
                Reg:     reg,
                IsWrite: write,
                Val:     val,
                HasVal:  hasVal,
                Call:    call,
                Ret:     ret,
                Pending: pending,
                seq:     i,
            }
            if pending {
                op.Ret = 1 << 62
            }
            ops = append(ops, op)
        }

        // brute: check each register projection independently (locality).
        inits := map[string]any{}
        byReg := map[string][]*Operation{}
        for _, op := range ops {
            byReg[op.Reg] = append(byReg[op.Reg], op)
        }
        want := true
        for _, projection := range byReg {
            init := regState{}
            if v, ok := inits[projection[0].Reg]; ok {
                init = regState{set: true, value: v}
            }
            if !bruteLinearizable(projection, init) {
                want = false
                break
            }
        }

        got := Check(ops, inits).Linearizable
        if got != want {
            t.Fatalf("trial %d: Check=%v brute=%v ops=%+v", trial, got, want, ops)
        }
    }
}
