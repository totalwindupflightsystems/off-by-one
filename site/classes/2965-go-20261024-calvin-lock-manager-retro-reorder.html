Deterministic Calvin-Style Transaction Scheduler in Go

Problem class: go-20261024-calvin-lock-manager-retro-reorder Environment: Go 1.26 · module example.com/calvin

1. Root-cause analysis

Calvin-style determinism requires every replica to produce the same final state without re-running the primary's runtime scheduling. The failure modes a naive implementation hits are:

Symptom Root cause
Replicas diverge The primary's lock-grant order is a function of timing. Replicas cannot reproduce it by re-locking, so the order must be recorded (the retrospection token) and replayed.
Executive replay deadlocks Replaying through the lock manager re-introduces contention and can pick different victims. Replay must be lock-free and follow the recorded order.
Deadlock abort is nondeterministic Victim choice based on "who notices first" differs per replica. Victim choice must be a pure function of the batch (priority, then a stable tie-break).
Aborted txn corrupts state Operations are applied incrementally; an abort must undo partial writes in reverse with before-images.
Read-to-write upgrade reorders An upgrade is a second lock request. If it re-enters the queue at the tail, a later transaction overtakes it and the recorded order no longer matches execution. The transaction needs a stable admission position.
Replay is not byte-identical A write computed from a read (Fn) would be recomputed under a different read interleaving. The token must store the resolved absolute write value.
Partial-batch crash double-applies Replay must be resumable from an offset and the applied writes must be idempotent assignments.

The exact fix is a single-threaded, strict two-phase-locking scheduler that (1) assigns each transaction a monotonic admission position, (2) orders wait queues by that position so upgrades keep their place, (3) builds a wait-for graph from holders and earlier conflicting waiters, (4) deterministically aborts the lowest-priority member of a cycle with full undo, (5) emits a token of resolved operations in commit/grant order, and (6) replays that token lock-free from an arbitrary offset.

Why commit order is the correct token order

Locks are held until commit/abort (strict 2PL), so conflicting operations are ordered by lock acquisition and the commit order is a valid serialization order. Because the token contains resolved write values, applying committed transactions in commit order reproduces the primary's per-key last-writer exactly — byte for byte.

2. Design and exact fix

Op / Txn ──► Scheduler.Run(batch)
                 │  for each pass, advance each txn by one op
                 │    tryAcquire(key, mode)
                 │       └─ queue ordered by admission position (pos)
                 │       └─ grant iff no earlier conflicting waiter
                 │                  and no conflicting holder
                 │    execute ─► state + per-txn undo log
                 │             └─ token write is resolved to absolute value
                 │    pending empty ─► commit, release locks
                 │  after each pass: resolveDeadlocks()
                 │       └─ DFS wait-for graph, abort lowest priority in cycle
                 └─► RetroToken{Order, Aborted, Commits(resolved ops), FinalSum}

RetroToken ──► Replay / ReplayFrom(offset)   (no locks, idempotent)

Key decisions:

  1. Strict 2PL — all granted locks held until commit/abort.
  2. Wait queues sorted by admission pos — canGrant blocks on any earlier conflicting waiter, so an upgrade keeps its original slot and is not overtaken.
  3. Wait-for graph includes fairness edges (A → earlier conflicting waiter) as well as holder edges (A → holder).
  4. Victim = minimum Priority; tie-break = larger TxnID — total order, no map-iteration nondeterminism.
  5. Undo log with (key, prev, existed); abort restores in reverse.
  6. Resolved token ops — Fn is evaluated once, the resulting bytes are stored with Fn == nil.
  7. Absolute-assignment replay — ApplyCommit only writes; ReplayFrom(token, state, k) resumes after a crash.

// Package calvin implements a deterministic, single-threaded Calvin-style
// transaction scheduler.
//
// The scheduler takes a batch of pre-declared transactions, acquires read /
// write locks for them, resolves deadlocks by aborting the lowest-priority
// waiter that participates in a wait-for cycle (rolling back its partial
// writes), and records the resulting serial order as a "retrospection token".
// Replicas can then replay the committed transactions in that order without
// taking any locks; replay is deterministic and byte-identical.
//
// Design notes
//
//   - Locks are strict two-phase: once granted they are held until commit or
//     abort.  Because of this the commit order produced by the primary is a
//     valid serial order, so replaying the committed transactions in that
//     order reproduces the primary's final state exactly.
//
//   - The retrospection token stores *resolved* operations: write values are
//     materialised at execution time (including values derived from reads via
//     Op.Fn).  A replica therefore never has to re-evaluate a read, which is
//     what makes replay byte-identical even when the primary's read/write
//     interleaving differs from the replay's serial order.
//
//   - Every transaction is given a monotonic admission "position" the first
//     time it requests a lock.  Wait queues are ordered by that position, so a
//     read-to-write upgrade keeps the position it originally had and is never
//     overtaken by a transaction that arrived later.
package calvin

import (
    "crypto/sha256"
    "errors"
    "fmt"
    "sort"
)

// TxnID uniquely identifies a transaction within a batch.
type TxnID uint64

// Priority ranks transactions.  Larger values are more important.  The
// deadlock resolver aborts the transaction with the *smallest* priority.
type Priority int

// LockMode is the mode of a granted lock.
type LockMode uint8

const (
    LockNone LockMode = iota
    LockRead
    LockWrite
)

func (m LockMode) String() string {
    switch m {
    case LockRead:
        return "R"
    case LockWrite:
        return "W"
    default:
        return "-"
    }
}

// OpKind distinguishes reads from writes.
type OpKind uint8

const (
    OpRead OpKind = iota
    OpWrite
)

// Op is one pre-declared operation of a transaction.
//
// For OpWrite, the value written is Op.Val unless Op.Fn is non-nil, in which
// case Op.Fn is applied to the prior value of the key.  Op.Fn makes
// transactions read-modify-write while still allowing the scheduler to record
// a fully resolved value in the retrospection token.
type Op struct {
    Kind OpKind
    Key  string
    Val  []byte
    Fn   func(prior []byte) []byte
}

// Txn is a pre-declared transaction.
type Txn struct {
    ID       TxnID
    Priority Priority
    Ops      []Op
}

// AbortReason explains why a transaction was aborted.
type AbortReason string

const (
    // ReasonDeadlock is used when a transaction is the victim of a wait-for
    // cycle.
    ReasonDeadlock AbortReason = "deadlock"
    // ReasonStarvation is a defensive fallback for an unrecoverable stall.
    ReasonStarvation AbortReason = "starvation"
)

// AbortRecord is the aborted transaction plus the reason.
type AbortRecord struct {
    ID     TxnID
    Reason AbortReason
}

// CommittedTxn is a committed transaction in a form that can be replayed.
//
// Position is the admission position assigned when the transaction first
// requested a lock.  It is retained across a read-to-write upgrade.
type CommittedTxn struct {
    ID       TxnID
    Position int
    Ops      []Op
}

// RetroToken is the deterministic schedule produced by a batch: the committed
// transactions in commit (grant) order, the aborted transactions, and a digest
// of the resulting state.
type RetroToken struct {
    Order    []TxnID
    Aborted  []AbortRecord
    Commits  []CommittedTxn
    FinalSum [32]byte
}

// ---------------------------------------------------------------------------
// internal state
// ---------------------------------------------------------------------------

type txnStatus uint8

const (
    stActive txnStatus = iota
    stCommitted
    stAborted
)

type undoEntry struct {
    key     string
    prev    []byte
    existed bool
}

type lockReq struct {
    txn  TxnID
    mode LockMode
    pos  int
}

type keyState struct {
    holders map[TxnID]LockMode
    queue   []*lockReq
}

type txnState struct {
    txn      *Txn
    status   txnStatus
    pending  []Op
    pos      int
    hasPos   bool
    blocked  bool
    held     map[string]LockMode
    undo     []undoEntry
    executed []Op
}

// Scheduler runs one batch at a time.  It is not safe for concurrent use: the
// whole point is that scheduling is deterministic and single-threaded.
type Scheduler struct {
    keys      map[string]*keyState
    state     map[string][]byte
    nextPos   int
    txns      map[TxnID]*txnState
    order     []TxnID
    aborted   []AbortRecord
    commitLog []CommittedTxn
}

// NewScheduler creates a scheduler over a copy of the initial state.
func NewScheduler(initial map[string][]byte) *Scheduler {
    return &Scheduler{state: cloneState(initial)}
}

// State returns a copy of the current materialised state.
func (s *Scheduler) State() map[string][]byte {
    return cloneState(s.state)
}

// Run schedules the batch and returns the retrospection token.  The scheduler
// must be fresh (or Run may be called again after a new NewScheduler) so that
// state does not leak between batches.
func (s *Scheduler) Run(batch []*Txn) *RetroToken {
    s.reset(batch)
    for !s.done() {
        progressed := false
        for _, t := range batch {
            if s.step(s.txns[t.ID]) {
                progressed = true
            }
        }
        if s.done() {
            break
        }
        if s.resolveDeadlocks() {
            progressed = true
        }
        if !progressed {
            // The lock protocol should always either make progress or
            // resolve a cycle, so this is a defensive guard.
            s.abortRemaining()
            break
        }
    }
    return s.buildToken()
}

func (s *Scheduler) reset(batch []*Txn) {
    s.keys = map[string]*keyState{}
    s.nextPos = 0
    s.txns = make(map[TxnID]*txnState, len(batch))
    s.order = nil
    s.aborted = nil
    s.commitLog = nil
    for _, t := range batch {
        s.txns[t.ID] = &txnState{
            txn:     t,
            status:  stActive,
            pending: cloneOps(t.Ops),
            held:    map[string]LockMode{},
        }
    }
}

func (s *Scheduler) done() bool {
    for _, ts := range s.txns {
        if ts.status == stActive {
            return false
        }
    }
    return true
}

// step advances a single transaction by at most one operation.  It returns true
// if the transaction made progress (executed an operation or committed).
func (s *Scheduler) step(ts *txnState) bool {
    if ts == nil || ts.status != stActive {
        return false
    }
    if len(ts.pending) == 0 {
        s.commit(ts)
        return true
    }
    op := ts.pending[0]
    if !s.tryAcquire(ts, op.Key, lockModeFor(op)) {
        return false
    }
    s.execute(ts, op)
    ts.pending = ts.pending[1:]
    if len(ts.pending) == 0 {
        s.commit(ts)
    }
    return true
}

func lockModeFor(op Op) LockMode {
    if op.Kind == OpWrite {
        return LockWrite
    }
    return LockRead
}

// tryAcquire attempts to acquire key in mode for ts.  It records the waiter in
// the key's queue (ordered by admission position) and grants the lock if both
// the holder set and the earlier waiters permit it.
func (s *Scheduler) tryAcquire(ts *txnState, key string, mode LockMode) bool {
    if !ts.hasPos {
        ts.pos = s.nextPos
        s.nextPos++
        ts.hasPos = true
    }
    ks := s.key(key)
    ts.blocked = true
    s.enqueue(ks, ts.txn.ID, mode, ts.pos)
    if !s.canGrant(ks, ts.txn.ID, mode) {
        return false
    }
    s.removeFromQueue(key, ts.txn.ID)
    ks.holders[ts.txn.ID] = mode
    ts.held[key] = mode
    ts.blocked = false
    return true
}

// canGrant reports whether the lock can be granted to txn.  A request is
// blocked by (a) any earlier waiter whose request conflicts with it (this is
// what lets an upgrade keep its position) and (b) any current conflicting
// holder.
func (s *Scheduler) canGrant(ks *keyState, txn TxnID, mode LockMode) bool {
    for _, r := range ks.queue {
        if r.txn == txn {
            break
        }
        if mode == LockWrite || r.mode == LockWrite {
            return false
        }
    }
    for h, hm := range ks.holders {
        if h == txn {
            continue
        }
        if mode == LockWrite || hm == LockWrite {
            return false
        }
    }
    return true
}

func (s *Scheduler) execute(ts *txnState, op Op) {
    switch op.Kind {
    case OpRead:
        ts.executed = append(ts.executed, Op{Kind: OpRead, Key: op.Key})
    case OpWrite:
        prev, existed := s.state[op.Key]
        var next []byte
        if op.Fn != nil {
            next = cloneBytes(op.Fn(cloneBytes(prev)))
        } else {
            next = cloneBytes(op.Val)
        }
        ts.undo = append(ts.undo, undoEntry{
            key:     op.Key,
            prev:    cloneBytes(prev),
            existed: existed,
        })
        s.state[op.Key] = cloneBytes(next)
        // Record the fully resolved write so replay is independent of reads.
        ts.executed = append(ts.executed, Op{Kind: OpWrite, Key: op.Key, Val: cloneBytes(next)})
    }
}

func (s *Scheduler) commit(ts *txnState) {
    if ts.status != stActive {
        return
    }
    s.releaseAll(ts)
    ts.status = stCommitted
    ts.blocked = false
    s.order = append(s.order, ts.txn.ID)
    s.commitLog = append(s.commitLog, CommittedTxn{
        ID:       ts.txn.ID,
        Position: ts.pos,
        Ops:      cloneOps(ts.executed),
    })
}

// abort rolls back a transaction's partial writes in reverse order, releases
// all of its locks and removes it from every wait queue.
func (s *Scheduler) abort(id TxnID, reason AbortReason) {
    ts := s.txns[id]
    if ts == nil || ts.status != stActive {
        return
    }
    for i := len(ts.undo) - 1; i >= 0; i-- {
        e := ts.undo[i]
        if e.existed {
            s.state[e.key] = cloneBytes(e.prev)
        } else {
            delete(s.state, e.key)
        }
    }
    s.releaseAll(ts)
    for key := range s.keys {
        s.removeFromQueue(key, id)
    }
    ts.held = map[string]LockMode{}
    ts.undo = nil
    ts.blocked = false
    ts.status = stAborted
    s.aborted = append(s.aborted, AbortRecord{ID: id, Reason: reason})
}

func (s *Scheduler) releaseAll(ts *txnState) {
    for key := range ts.held {
        if ks := s.keys[key]; ks != nil {
            delete(ks.holders, ts.txn.ID)
        }
        s.removeFromQueue(key, ts.txn.ID)
    }
    ts.held = map[string]LockMode{}
}

func (s *Scheduler) abortRemaining() {
    ids := make([]TxnID, 0)
    for id, ts := range s.txns {
        if ts.status == stActive {
            ids = append(ids, id)
        }
    }
    sort.Slice(ids, func(i, j int) bool { return ids[i] < ids[j] })
    for _, id := range ids {
        s.abort(id, ReasonStarvation)
    }
}

// ---------------------------------------------------------------------------
// wait-for graph and deadlock resolution
// ---------------------------------------------------------------------------

// waitEdges builds the wait-for graph from the current queues and holders.
// An edge A -> B means A is blocked by B, either because B holds a conflicting
// lock or because B is an earlier conflicting waiter on the same key.
func (s *Scheduler) waitEdges() map[TxnID][]TxnID {
    edges := make(map[TxnID][]TxnID)
    for id, ts := range s.txns {
        if ts.status != stActive || !ts.blocked || len(ts.pending) == 0 {
            continue
        }
        op := ts.pending[0]
        for _, b := range s.blockers(op.Key, id, lockModeFor(op)) {
            edges[id] = append(edges[id], b)
        }
    }
    return edges
}

func (s *Scheduler) blockers(key string, txn TxnID, mode LockMode) []TxnID {
    ks := s.keys[key]
    if ks == nil {
        return nil
    }
    seen := map[TxnID]bool{}
    var out []TxnID
    add := func(id TxnID) {
        if id == txn || seen[id] {
            return
        }
        ts := s.txns[id]
        if ts == nil || ts.status != stActive {
            return
        }
        seen[id] = true
        out = append(out, id)
    }
    for h, hm := range ks.holders {
        if mode == LockWrite || hm == LockWrite {
            add(h)
        }
    }
    for _, r := range ks.queue {
        if r.txn == txn {
            break
        }
        if mode == LockWrite || r.mode == LockWrite {
            add(r.txn)
        }
    }
    sort.Slice(out, func(i, j int) bool { return out[i] < out[j] })
    return out
}

// resolveDeadlocks aborts the lowest-priority member of every wait-for cycle
// until the graph is acyclic.  It returns true if it aborted anything.
func (s *Scheduler) resolveDeadlocks() bool {
    didAbort := false
    for {
        cycle := findCycle(s.waitEdges())
        if len(cycle) == 0 {
            return didAbort
        }
        s.abort(s.chooseVictim(cycle), ReasonDeadlock)
        didAbort = true
    }
}

// chooseVictim picks the lowest-priority transaction in the cycle.  Ties are
// broken by the larger transaction ID so the result is deterministic.
func (s *Scheduler) chooseVictim(cycle []TxnID) TxnID {
    victim := cycle[0]
    for _, id := range cycle[1:] {
        cur, best := s.txns[id], s.txns[victim]
        if cur.txn.Priority < best.txn.Priority ||
            (cur.txn.Priority == best.txn.Priority && id > victim) {
            victim = id
        }
    }
    return victim
}

func findCycle(edges map[TxnID][]TxnID) []TxnID {
    const (
        white = 0
        gray  = 1
        black = 2
    )
    color := map[TxnID]int{}
    var path, found []TxnID
    var dfs func(u TxnID) bool
    dfs = func(u TxnID) bool {
        color[u] = gray
        path = append(path, u)
        vs := append([]TxnID(nil), edges[u]...)
        sort.Slice(vs, func(i, j int) bool { return vs[i] < vs[j] })
        for _, v := range vs {
            switch color[v] {
            case gray:
                for i := len(path) - 1; i >= 0; i-- {
                    if path[i] == v {
                        found = append([]TxnID(nil), path[i:]...)
                        break
                    }
                }
                return true
            case white:
                if dfs(v) {
                    return true
                }
            }
        }
        path = path[:len(path)-1]
        color[u] = black
        return false
    }
    nodes := make([]TxnID, 0, len(edges))
    for u := range edges {
        nodes = append(nodes, u)
    }
    sort.Slice(nodes, func(i, j int) bool { return nodes[i] < nodes[j] })
    for _, u := range nodes {
        if color[u] == white {
            if dfs(u) {
                return found
            }
        }
    }
    return nil
}

// ---------------------------------------------------------------------------
// queue helpers
// ---------------------------------------------------------------------------

func (s *Scheduler) key(name string) *keyState {
    ks := s.keys[name]
    if ks == nil {
        ks = &keyState{holders: map[TxnID]LockMode{}}
        s.keys[name] = ks
    }
    return ks
}

// enqueue inserts (or updates) a request, keeping the queue ordered by
// admission position.  Because the position is assigned once, an upgrade keeps
// its original place.
func (s *Scheduler) enqueue(ks *keyState, txn TxnID, mode LockMode, pos int) {
    for _, r := range ks.queue {
        if r.txn == txn {
            r.mode = mode
            return
        }
    }
    req := &lockReq{txn: txn, mode: mode, pos: pos}
    idx := sort.Search(len(ks.queue), func(i int) bool { return ks.queue[i].pos > pos })
    ks.queue = append(ks.queue, nil)
    copy(ks.queue[idx+1:], ks.queue[idx:])
    ks.queue[idx] = req
}

func (s *Scheduler) removeFromQueue(key string, txn TxnID) {
    ks := s.keys[key]
    if ks == nil {
        return
    }
    for i, r := range ks.queue {
        if r.txn == txn {
            ks.queue = append(ks.queue[:i], ks.queue[i+1:]...)
            return
        }
    }
}

// ---------------------------------------------------------------------------
// token and replay
// ---------------------------------------------------------------------------

func (s *Scheduler) buildToken() *RetroToken {
    tok := &RetroToken{
        Order:   append([]TxnID(nil), s.order...),
        Aborted: append([]AbortRecord(nil), s.aborted...),
        Commits: make([]CommittedTxn, len(s.commitLog)),
    }
    for i, c := range s.commitLog {
        tok.Commits[i] = CommittedTxn{ID: c.ID, Position: c.Position, Ops: cloneOps(c.Ops)}
    }
    sort.Slice(tok.Aborted, func(i, j int) bool { return tok.Aborted[i].ID < tok.Aborted[j].ID })
    tok.FinalSum = Digest(s.state)
    return tok
}

// Replay applies every committed transaction of the token to a copy of
// initial, without acquiring any locks.  The resulting state is byte-identical
// to the primary's final state.
func Replay(token *RetroToken, initial map[string][]byte) (map[string][]byte, error) {
    return ReplayFrom(token, initial, 0)
}

// ReplayFrom applies committed transactions starting at index from.  It is
// used to resume a replay after a partial batch failure: a replica that
// crashed after applying commits[0:from] calls ReplayFrom(token, state, from)
// and converges on exactly the same state.
func ReplayFrom(token *RetroToken, initial map[string][]byte, from int) (map[string][]byte, error) {
    if token == nil {
        return nil, errors.New("calvin: nil retrospection token")
    }
    if from < 0 || from > len(token.Commits) {
        return nil, fmt.Errorf("calvin: replay offset %d out of range [0,%d]", from, len(token.Commits))
    }
    state := cloneState(initial)
    for i := from; i < len(token.Commits); i++ {
        ApplyCommit(state, token.Commits[i])
    }
    return state, nil
}

// ApplyCommit applies one committed transaction to state.  Writes are
// absolute assignments, so applying the same commit twice is idempotent.
func ApplyCommit(state map[string][]byte, c CommittedTxn) {
    for _, op := range c.Ops {
        if op.Kind == OpWrite {
            state[op.Key] = cloneBytes(op.Val)
        }
    }
}

// Digest is a deterministic SHA-256 over the sorted contents of state.
func Digest(state map[string][]byte) [32]byte {
    keys := make([]string, 0, len(state))
    for k := range state {
        keys = append(keys, k)
    }
    sort.Strings(keys)
    h := sha256.New()
    for _, k := range keys {
        h.Write([]byte(k))
        h.Write([]byte{0})
        h.Write(state[k])
        h.Write([]byte{0xff})
    }
    var out [32]byte
    copy(out[:], h.Sum(nil))
    return out
}

// ---------------------------------------------------------------------------
// cloning helpers
// ---------------------------------------------------------------------------

func cloneBytes(b []byte) []byte {
    if b == nil {
        return nil
    }
    out := make([]byte, len(b))
    copy(out, b)
    return out
}

func cloneOps(ops []Op) []Op {
    out := make([]Op, len(ops))
    for i, op := range ops {
        out[i] = Op{Kind: op.Kind, Key: op.Key, Val: cloneBytes(op.Val), Fn: op.Fn}
    }
    return out
}

func cloneState(state map[string][]byte) map[string][]byte {
    out := make(map[string][]byte, len(state))
    for k, v := range state {
        out[k] = cloneBytes(v)
    }
    return out
}

package calvin

import (
    "bytes"
    "fmt"
    "reflect"
    "testing"
)

func b(v string) []byte { return []byte(v) }

// ---------------------------------------------------------------------------
// helpers
// ---------------------------------------------------------------------------

func mustReplay(t *testing.T, token *RetroToken, initial map[string][]byte) map[string][]byte {
    t.Helper()
    got, err := Replay(token, initial)
    if err != nil {
        t.Fatalf("Replay: %v", err)
    }
    return got
}

func assertState(t *testing.T, got, want map[string][]byte) {
    t.Helper()
    if len(got) != len(want) {
        t.Fatalf("state size = %d, want %d\ngot=%v\nwant=%v", len(got), len(want), got, want)
    }
    for k, wv := range want {
        gv, ok := got[k]
        if !ok {
            t.Fatalf("missing key %q\ngot=%v", k, got)
        }
        if !bytes.Equal(gv, wv) {
            t.Fatalf("key %q = %q, want %q", k, gv, wv)
        }
    }
}

// ---------------------------------------------------------------------------
// 1. cycle abort: lowest priority waiter is aborted with full rollback

func TestCycleAbortLowestPriority(t *testing.T) {

func TestUpgradeRetainsPosition(t *testing.T) {
    tests := []struct {
        name      string
        initial   map[string][]byte
        batch     []*Txn
        wantOrder []TxnID
        wantAbort []TxnID
        wantState map[string][]byte
        wantPos   map[TxnID]int
    }{
        {
            // A reads K (position 0) and later upgrades.  U (higher priority)
            // requests a conflicting write before the upgrade.  Because A's
            // upgrade keeps position 0 it is granted first; U waits.
            name: "upgrade keeps priority over a later higher-priority writer",
            batch: []*Txn{
                {ID: 1, Priority: 1, Ops: []Op{
                    {Kind: OpRead, Key: "K"},
                    {Kind: OpWrite, Key: "K", Val: b("A")},
                }},
                {ID: 2, Priority: 9, Ops: []Op{
                    {Kind: OpWrite, Key: "K", Val: b("U")},
                }},
            },
            wantOrder: []TxnID{1, 2},
            wantAbort: nil,
            wantState: map[string][]byte{"K": b("U")},
            wantPos:   map[TxnID]int{1: 0, 2: 1},
        },
        {
            // Two readers both try to upgrade.  The earlier admission position
            // is retained and wins the deadlock tie-break (same priority).
            name: "two upgrading readers form a cycle and the later one is aborted",
            batch: []*Txn{
                {ID: 1, Priority: 5, Ops: []Op{
                    {Kind: OpRead, Key: "K"},
                    {Kind: OpWrite, Key: "K", Val: b("A")},
                }},
                {ID: 2, Priority: 5, Ops: []Op{
                    {Kind: OpRead, Key: "K"},
                    {Kind: OpWrite, Key: "K", Val: b("B")},
                }},
            },
            wantOrder: []TxnID{1},
            wantAbort: []TxnID{2},
            wantState: map[string][]byte{"K": b("A")},
            wantPos:   map[TxnID]int{1: 0},
        },
        {
            // Upgrade of a value derived from the read must be recorded as a
            // resolved absolute value in the token.
            name:    "read-modify-write upgrade is resolved in the token",
            initial: map[string][]byte{"n": b("5")},
            batch: []*Txn{
                {ID: 1, Priority: 1, Ops: []Op{
                    {Kind: OpRead, Key: "n"},
                    {Kind: OpWrite, Key: "n", Fn: func(prior []byte) []byte {
                        return append(append([]byte(nil), prior...), []byte("+1")...)
                    }},
                }},
            },
            wantOrder: []TxnID{1},
            wantAbort: nil,
            wantState: map[string][]byte{"n": b("5+1")},
            wantPos:   map[TxnID]int{1: 0},
        },
    }
    for _, tc := range tests {
        t.Run(tc.name, func(t *testing.T) {
            s := NewScheduler(tc.initial)
            token := s.Run(tc.batch)

            if !reflect.DeepEqual(token.Order, tc.wantOrder) {
                t.Fatalf("commit order = %v, want %v", token.Order, tc.wantOrder)
            }
            gotAborts := make([]TxnID, len(token.Aborted))
            for i, a := range token.Aborted {
                gotAborts[i] = a.ID
            }
            if !reflect.DeepEqual(gotAborts, tc.wantAbort) && !(len(gotAborts) == 0 && len(tc.wantAbort) == 0) {
                t.Fatalf("aborted = %v, want %v", gotAborts, tc.wantAbort)
            }
            for id, pos := range tc.wantPos {
                found := false
                for _, c := range token.Commits {
                    if c.ID == id {
                        found = true
                        if c.Position != pos {
                            t.Fatalf("txn %d position = %d, want %d", id, c.Position, pos)
                        }
                    }
                }
                if !found {
                    t.Fatalf("txn %d not found in commits", id)
                }
            }
            assertState(t, s.State(), tc.wantState)

            // The token write for the read-modify-write must be the resolved
            // absolute value, not an Fn closure.
            for _, c := range token.Commits {
                for _, op := range c.Ops {
                    if op.Kind == OpWrite && op.Fn != nil {
                        t.Fatalf("token contains an unresolved Fn write for txn %d", c.ID)
                    }
                }
            }
        })
    }
}

func mixedBatch() []*Txn {
    return []*Txn{
        {ID: 1, Priority: 2, Ops: []Op{

            {Kind: OpWrite, Key: "log", Val: b("t1")},

            {Kind: OpWrite, Key: "counter", Fn: func(p []byte) []byte { return append(cloneBytes(p), []byte("|t2")...) }},
        }},

            {Kind: OpRead, Key: "counter"},

        {ID: 4, Priority: 1, Ops: []Op{

func TestReplayByteIdenticalAcrossReplicas(t *testing.T) {
    initial := map[string][]byte{
        "counter": b("10"),
        "log":     b("init"),
    }
    primary := NewScheduler(initial)
    token := primary.Run(mixedBatch())

    replicaA := mustReplay(t, token, initial)
    replicaB := mustReplay(t, token, map[string][]byte{
        "counter": b("10"),
        "log":     b("init"),
    })

    // Two replicas must agree byte for byte.
    assertState(t, replicaA, replicaB)

    // Both replicas must agree with the primary's materialised state and with
    // the digest embedded in the token.
    assertState(t, replicaA, primary.State())
    if Digest(replicaA) != token.FinalSum {
        t.Fatalf("replica digest %x != token digest %x", Digest(replicaA), token.FinalSum)
    }
    if Digest(replicaB) != token.FinalSum {
        t.Fatalf("replica digest %x != token digest %x", Digest(replicaB), token.FinalSum)
    }
}

func TestIdempotentReplayAfterPartialFailure(t *testing.T) {
    initial := map[string][]byte{"counter": b("10"), "log": b("init")}
    token := NewScheduler(initial).Run(mixedBatch())

    full := mustReplay(t, token, initial)

    for k := 0; k <= len(token.Commits); k++ {
        t.Run(fmt.Sprintf("crash_after_%d_commits", k), func(t *testing.T) {
            // Simulate a replica that applied only the first k commits and then
            // crashed.
            partial := cloneState(initial)
            for i := 0; i < k; i++ {
                ApplyCommit(partial, token.Commits[i])
            }
            // Resume from the crash point.
            resumed, err := ReplayFrom(token, partial, k)
            if err != nil {
                t.Fatalf("ReplayFrom: %v", err)
            }
            assertState(t, resumed, full)

            // Applying the whole token again on top is a no-op (writes are
            // absolute assignments), proving replay is idempotent.
            twice := mustReplay(t, token, resumed)
            assertState(t, twice, full)
        })
    }
}

func TestReplayFromRejectsBadOffset(t *testing.T) {

// Command demo runs the deterministic Calvin scheduler on a small batch and
// replays the resulting retrospection token on two independent replicas.
package main

import (
    "bytes"
    "fmt"
    "sort"

    "example.com/calvin"
)

func b(s string) []byte { return []byte(s) }

func main() {
    initial := map[string][]byte{"A": b("A0"), "B": b("B0"), "C": b("C0")}

    batch := []*calvin.Txn{
        {ID: 1, Priority: 1, Ops: []calvin.Op{ // low priority
            {Kind: calvin.OpWrite, Key: "A", Val: b("A1")},
            {Kind: calvin.OpWrite, Key: "B", Val: b("B1")},
        }},
        {ID: 2, Priority: 9, Ops: []calvin.Op{ // high priority, opposite lock order
            {Kind: calvin.OpWrite, Key: "B", Val: b("B2")},
            {Kind: calvin.OpWrite, Key: "A", Val: b("A2")},
        }},
        {ID: 3, Priority: 5, Ops: []calvin.Op{
            {Kind: calvin.OpRead, Key: "C"},
            {Kind: calvin.OpWrite, Key: "C", Val: b("C3")},
        }},
    }

    primary := calvin.NewScheduler(initial)
    token := primary.Run(batch)

    fmt.Println("commit order (grant order):", token.Order)
    fmt.Print("aborted: ")
    for _, a := range token.Aborted {
        fmt.Printf("[txn %d: %s] ", a.ID, a.Reason)
    }
    fmt.Println()
    fmt.Println("primary digest:", fmt.Sprintf("%x", token.FinalSum))

    replica1, _ := calvin.Replay(token, initial)
    replica2, _ := calvin.Replay(token, initial)

    fmt.Println("replica1 digest:", fmt.Sprintf("%x", calvin.Digest(replica1)))
    fmt.Println("replica2 digest:", fmt.Sprintf("%x", calvin.Digest(replica2)))

    fmt.Println("final state:")
    keys := make([]string, 0, len(replica1))
    for k := range replica1 {
        keys = append(keys, k)
    }
    sort.Strings(keys)
    for _, k := range keys {
        fmt.Printf("  %s = %s\n", k, replica1[k])
    }

    fmt.Println("replica1 == replica2:", equalStates(replica1, replica2))
    fmt.Println("replicas == primary:",
        calvin.Digest(replica1) == token.FinalSum &&
            calvin.Digest(replica2) == token.FinalSum)
}

func equalStates(a, b map[string][]byte) bool {
    if len(a) != len(b) {
        return false
    }
    for k, av := range a {
        if !bytes.Equal(av, b[k]) {
            return false
        }
    }
    return true
}
