Root causes of the hard parts

  1. Snapshot-relative edges — R --rw--> W exists only when W writes something R read and W.commit >= R.begin (invisible writer). This is the boundary most implementations get wrong.
  2. Dangerous structure, not any cycle — only Tin --rw--> Tpivot --rw--> Tout with Tout committing first matters.
  3. First-committer-wins — commit order decides the victim (classic write-skew 2-cycle aborts the second committer).
  4. Read-only far transactions are excluded, otherwise PG would abort transactions it actually keeps.
  5. The pivot is doomed (not the early committer), then aborts at its own commit point.
