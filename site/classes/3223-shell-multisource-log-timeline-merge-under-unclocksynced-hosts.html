Answer

Merging Un-Clocksynced Multi-Source Attack Timelines

Symptom

Journald, an application JSON log, and auth.log come from several hosts whose wall clocks drift up to ±90 s and may step mid-window (NTP correction). A naïve "sort everything by timestamp" merge:

  • silently interleaves events in an order that is not causally possible,
  • cannot tell a real gap from clock skew,
  • hides the fact that some pairs genuinely cannot be ordered.

The requirement is a single causally-consistent ordering plus explicit flags on every ordering that can still flip.

Root-cause analysis

  1. No global clock. t_local on host h differs from true time by an unknown correction o_h, |o_h| ≤ 90 s. Sorting by t_local is therefore wrong by up to 180 s between two hosts.
  2. Offsets are partly observable only through cause→effect. A cross-source anchor (session opened on web1 → DB query on db1, a TCP seq100→seq200 hop, a fork→exec pair) says "A happened at or before B". In local time this is a difference constraint on the offsets: Lmin ≤ (t_B + o_B) − (t_A + o_A) ≤ Lmax.
  3. NTP steps break "one offset per host". A host that gets corrected mid-window has two offsets. If you assume one, the constraint system becomes infeasible (a negative cycle) — that is the detector, not a bug.
  4. Residual uncertainty is real. Even after using anchors, a pair with no causal path between them can have an order that is still achievable both ways. The tool must report it rather than pick one.
  5. Format details that quietly corrupt the merge. Adjacent empty fields in TSV collapse under IFS=<tab> read; syslog dates must be parsed in UTC; and the FNR==NR idiom mis-fires when the first file is empty.

The model

Each host segment (a maximal run with no clock step) gets a variable x_seg = o_seg (seconds to add to local time to reach the reference frame).

  • Anchor edge A→B with latency window [Lmin, Lmax] of duration Δ = t_B − t_A produces two difference constraints:
  • x_B − x_A ≤ Lmax − Δ
  • x_A − x_B ≤ Δ − Lmin
  • Drift bound (translation-invariant): any two host clocks are within 2·MAX_DRIFT.
  • Gauge: pin one reference segment to 0 (absolute epoch is unobservable; only order matters).
  • Solve: Bellman–Ford from a super-source gives each variable's feasible interval and detects clock steps as negative cycles.
  • Ordering: the shortest-path solution is a feasible assignment; sorting by t + x_seg yields one valid interleaving.
  • Flip test: for a shown order A≤B, the reverse is feasible iff ‑sp(seg_A → seg_B) < t_A − t_B (equivalently sp(seg_B → seg_A) > t_B − t_A). All-pairs shortest paths (Floyd–Warshall) make this O(1) per pair.
  • Step recovery: if the system is infeasible, take the nodes on the negative cycle, pick the participating host with the largest internal local-time gap, and cut there; repeat.

Exact fix

Four files. All were run and verified (see below).

timeline-merge.sh

#!/usr/bin/env bash
# timeline-merge.sh
# Merge attack timelines from journald + application JSON logs + auth.log across
# hosts whose wall clocks drift (and step) independently.
set -euo pipefail
LC_ALL=C

MAX_DRIFT=${MAX_DRIFT:-90}   # seconds, bound on |clock correction|
L_SESS=${L_SESS:-5}          # max latency for a session-id causal hop (s)
L_TCP=${L_TCP:-2}            # max one-way latency for a TCP sequence hop (s)
L_PC=${L_PC:-2}              # max latency for a parent->child exec hop (s)

MANIFEST=""; OUT=""; KEEP=0; DUMP=""
usage(){ sed -n '2,20p' "$0" >&2; exit 2; }
while [[ $# -gt 0 ]]; do
  case "$1" in
    --manifest) MANIFEST=$2; shift 2;;
    --out)      OUT=$2; shift 2;;
    --keep)     KEEP=1; shift;;
    --dump)     DUMP=$2; shift 2;;
    -h|--help|*) usage;;
  esac
done
[[ -n "$MANIFEST" && -f "$MANIFEST" ]] || usage

TMP=$(mktemp -d)
cleanup(){ if [[ $KEEP -eq 1 ]]; then echo "[workdir kept: $TMP]" >&2; else rm -rf "$TMP"; fi; }
trap cleanup EXIT

RAW="$TMP/raw.tsv"      # host t src kind sess sseq conn tcps pid ppid msg
EV="$TMP/events.tsv"    # id host t seg src kind sess sseq conn tcps pid ppid msg
CUTS="$TMP/cuts.tsv"    # host t   (segment boundaries)
CONS="$TMP/cons.tsv"    # i j w   meaning  x_j - x_i <= w
SEGMAP="$TMP/segmap.tsv" # idx seg
OFF="$TMP/off.tsv"      # seg lower upper
: > "$RAW"; printf '__no_such_host__\t0\n' > "$CUTS"  # sentinel keeps FNR==NR sane

# ---------------------------------------------------------------------------
# 1. INGEST
# ---------------------------------------------------------------------------
ingest_journald(){ # file
  local file=$1
  jq -r '
    def num(v): (v // -1);
    [ (._HOSTNAME // "unknown"),
      (((.__REALTIME_TIMESTAMP // 0)|tonumber)/1000000),
      "journald",
      (.KIND // "journal"),
      (.SESSION // ""),
      num(.SESSION_SEQ),
      (.CONN // ""),
      num(.TCP_SEQ),
      num(.PID),
      num(.PPID),
      ((.MESSAGE // "") | gsub("[\t\n]"; " "))
    ] | @tsv' "$file" >> "$RAW"
}

ingest_app(){ # file  (one JSON object per line)
  local file=$1
  # epoch conversion is done in jq so that empty fields survive the tab
  # encoding (`IFS=<tab> read` collapses adjacent empty fields).
  jq -r '
    def epoch:
      (.time | capture("(?<s>[0-9-]+T[0-9:]+)\\.(?<f>[0-9]+)Z")) as $m
      | (($m.s + "Z") | fromdateiso8601) + (("0." + $m.f) | tonumber);
    [ (.host // "unknown"), epoch, "appjson", (.kind//"app"), (.session//""),
      (.session_seq//-1), (.conn//""), (.tcp_seq//-1), (.pid//-1), (.ppid//-1),
      ((.message//"")|gsub("[\t\n]";" ")) ] | @tsv' "$file" >> "$RAW"
}

ingest_auth(){ # file  (classic syslog auth.log)
  local file=$1
  local line mon day tm rh rp rmsg kind session conn tcpseq pid
  while IFS= read -r line; do
    [[ -z "${line// }" ]] && continue
    read -r mon day tm rh rp rmsg <<<"$line"
    pid=-1
    [[ $rp =~ \[([0-9]+)\] ]] && pid=${BASH_REMATCH[1]}
    kind=auth
    [[ $rmsg =~ kind=([^[:space:]]+)    ]] && kind=${BASH_REMATCH[1]}
    session=""
    [[ $rmsg =~ session=([^[:space:]]+) ]] && session=${BASH_REMATCH[1]}
    local sseq=-1
    [[ $rmsg =~ session_seq=([0-9]+) ]] && sseq=${BASH_REMATCH[1]}
    conn=""
    [[ $rmsg =~ conn=([^[:space:]]+)    ]] && conn=${BASH_REMATCH[1]}
    tcpseq=-1
    [[ $rmsg =~ tcp_seq=([0-9]+)        ]] && tcpseq=${BASH_REMATCH[1]}
    local ep
    ep=$(TZ=UTC date -d "$mon $day $tm" +%s.%N 2>/dev/null) || continue
    printf '%s\t%s\t%s\t%s\t%s\t%s\t%s\t%s\t%s\t%s\t%s\n' \
      "$rh" "$ep" "authlog" "$kind" "$session" "$sseq" \
      "$conn" "$tcpseq" "$pid" "-1" \
      "${rmsg//$'\t'/ }" >> "$RAW"
  done < "$file"
}

while IFS=$'\t' read -r src path; do
  [[ -z "${src// }" ]] && continue
  [[ -s "$path" ]] || { echo "missing/empty input: $path" >&2; exit 2; }
  case "$src" in
    journald)          ingest_journald "$path";;
    appjson|app)       ingest_app      "$path";;
    authlog|auth)      ingest_auth     "$path";;
    *) echo "unknown source '$src' in manifest" >&2; exit 2;;
  esac
done < "$MANIFEST"

awk -F'\t' 'BEGIN{OFS="\t"}{print ++i,$0}' "$RAW" > "$TMP/numbered.tsv"
[[ $(wc -l < "$TMP/numbered.tsv") -gt 0 ]] || { echo "no events parsed" >&2; exit 2; }

# explicit NTP/clock-step markers become segment cuts
awk -F'\t' '$5 ~ /(ntp|clock|step|timesync|adjust)/ {print $2"\t"$3}' \
  "$TMP/numbered.tsv" >> "$CUTS"

# ---------------------------------------------------------------------------
# 2. SEGMENTATION
# ---------------------------------------------------------------------------
assign_segments(){
  sort -t$'\t' -k2,2 -k3,3g "$TMP/numbered.tsv" > "$TMP/sorted.tsv"
  awk -F'\t' -v OFS='\t' '
    FNR==NR { if($1!="") cut[$1" " $2]=1; next }
    {
      n=0
      for(c in cut){ split(c,p," "); if(p[1]==$2 && p[2]+0 <= $3+0) n++ }
      print $1,$2,$3,($2 "#" n),$4,$5,$6,$7,$8,$9,$10,$11,$12
    }' "$CUTS" "$TMP/sorted.tsv" > "$EV"
}

# ---------------------------------------------------------------------------
# 3. CONSTRAINTS from causal anchors
# ---------------------------------------------------------------------------
build_cons(){ # $1 = reference segment to pin to 0 (gauge fixing)
  awk -F'\t' -v OFS='\t' -v Ls="$L_SESS" -v Lt="$L_TCP" -v Lp="$L_PC" \
      -v D="$MAX_DRIFT" -v segout="$SEGMAP" -v refseg="${1:-}" '
    function getidx(s,  v){ if(s in segidx) return segidx[s];
                            v=++nv; segidx[s]=v; segname[v]=s; return v }
    function krank(k){ if(k ~ /accept|opened|login_success|login/) return 0;
                       if(k ~ /request|query|exec|connect/)       return 2;
                       if(k ~ /ack|response|reply|read/)          return 3;
                       if(k ~ /close|logout|exit|disconnect/)     return 4;
                       return 1 }
    function ord(i){ return (eseq[i]>=0 ? eseq[i] : 1000000+krank(ek[i])) }
    function emit(a,b,Lmin,Lmax,  ta,tb,ia,ib,U,W){
      ia=getidx(eseg[a]); ib=getidx(eseg[b]); ta=et[a]; tb=et[b];
      U = Lmax - (tb - ta);          # x_b - x_a <= U
      W = (tb - ta) - Lmin;          # x_a - x_b <= W
      print ia, ib, U; print ib, ia, W;
    }
    {
      n++
      eid[n]=$1; ehost[n]=$2; et[n]=$3+0; eseg[n]=$4; ek[n]=$6
      esess[n]=$7; eseq[n]=$8+0; econn[n]=$9; etcp[n]=$10+0
      epid[n]=$11+0; eppid[n]=$12+0
      getidx(eseg[n]) > ""
      if(esess[n]!=""){ k="S" SUBSEP esess[n]; c=++sc[k]; sm[k SUBSEP c]=n }
      if(econn[n]!="" && etcp[n]>=0){ k="T" SUBSEP econn[n]; c=++tc[k]; tm[k SUBSEP c]=n }
      if(epid[n]>0){ pk=ehost[n] SUBSEP epid[n]; if(!(pk in pm)) pm[pk]=n }
    }
    END{
      for(k in sc){ m=sc[k]; for(i=1;i<=m;i++) o[i]=sm[k SUBSEP i]
        for(i=2;i<=m;i++){ x=o[i]; v=ord(x); j=i-1
          while(j>=1 && ord(o[j])>v){ o[j+1]=o[j]; j-- } o[j+1]=x }
        for(i=1;i<m;i++) emit(o[i],o[i+1],0,Ls) }
      for(k in tc){ m=tc[k]; for(i=1;i<=m;i++) o[i]=tm[k SUBSEP i]
        for(i=2;i<=m;i++){ x=o[i]; v=etcp[x]; j=i-1
          while(j>=1 && etcp[o[j]]>v){ o[j+1]=o[j]; j-- } o[j+1]=x }
        for(i=1;i<m;i++) emit(o[i],o[i+1],0,Lt) }
      for(i=1;i<=n;i++) if(eppid[i]>0){
        pk=ehost[i] SUBSEP eppid[i]
        if(pk in pm){ p=pm[pk]; if(p!=i) emit(p,i,0,Lp) } }
      # translation-invariant drift bounds: any two host clocks within 2D
      for(u=1;u<=nv;u++) for(v=1;v<=nv;v++) if(u!=v) print u, v, 2*D
      if(refseg!=""){ r=getidx(refseg); print 0, r, 0; print r, 0, 0 }
      for(v=1;v<=nv;v++) print v, segname[v] > segout
    }' "$EV" > "$CONS"
}

# ---------------------------------------------------------------------------
# Bellman-Ford (single source).  mode=reverse gives lower bounds.
# ---------------------------------------------------------------------------
run_bf(){
  local mode=$1 infile=$2
  awk -F'\t' -v n="$NODES" -v mode="$mode" '
    { i=$1+0; j=$2+0; w=$3+0
      if(mode=="reverse"){ t=i; i=j; j=t }
      m++; ei[m]=i; ej[m]=j; ew[m]=w }
    END{
      for(v=0;v<n;v++) d[v]=1e300
      d[0]=0; last=0; pred[0]=0
      for(k=0;k<n;k++){
        upd=0
        for(e=1;e<=m;e++) if(d[ei[e]]<1e299){
          nd=d[ei[e]]+ew[e]
          if(nd < d[ej[e]] - 1e-9){ d[ej[e]]=nd; pred[ej[e]]=ei[e]; upd=1; last=ej[e] } }
        if(!upd) break
        if(k==n-1 && upd){
          x=last; for(t=0;t<n;t++) x=pred[x]
          for(t=0;t<n;t++){ print "NEGCYCLE", x > "/dev/stderr"; x=pred[x] }
          exit 3 }
      }
      for(v=0;v<n;v++) printf "%d\t%.6f\n", v, (d[v]>=1e299?0:d[v])
    }' "$infile"
}

solve(){
  local refseg
  refseg=$(awk -F'\t' '{c[$4]++} END{best="";bn=-1;
            for(k in c){ if(c[k]>bn || (c[k]==bn && (best==""||k<best))){bn=c[k];best=k} }
            print best}' "$EV")
  build_cons "$refseg"
  mapfile -t SEGS < "$SEGMAP"
  NODES=$(( ${#SEGS[@]} + 1 ))
  local fwd rev
  if ! fwd=$(run_bf forward "$CONS" 2>"$TMP/bf.err"); then return 1; fi
  rev=$(run_bf reverse "$CONS" 2>>"$TMP/bf.err")
  : > "$OFF"
  while read -r v seg; do
    local up lo
    up=$(awk -v v="$v" '$1==v{print $2}' <<<"$fwd")
    lo=$(awk -v v="$v" '$1==v{print -$2}' <<<"$rev")
    printf '%s\t%s\t%s\n' "$seg" "$lo" "$up" >> "$OFF"
  done < "$SEGMAP"
}

auto_split(){
  local nodes hosts host gap cut best_host="" best_gap=-1 best_mid=""
  nodes=$(awk '/NEGCYCLE/{print $2}' "$TMP/bf.err" | sort -un)
  [[ -n "$nodes" ]] || return 1
  hosts=$(for n in $nodes; do awk -v v="$n" '$1==v{print $2}' "$SEGMAP"; done \
          | cut -d'#' -f1 | grep -v '^$' | sort -u)
  [[ -n "$hosts" ]] || return 1
  for host in $hosts; do
    read -r gap cut < <(awk -F'\t' -v H="$host" '$2==H{print $3}' "$EV" | sort -g |
        awk 'NR>1{g=$1-p; if(g>mg){mg=g;c=$1}} {p=$1}
             END{print (mg+0), (c==""?0:c)}')
    if awk -v g="$gap" -v b="$best_gap" 'BEGIN{exit !(g>b)}'; then
      best_gap=$gap; best_host=$host; best_mid=$cut
    fi
  done
  [[ -n "$best_host" && -n "$best_mid" ]] || return 1
  grep -qxF "$best_host"$'\t'"$best_mid" "$CUTS" 2>/dev/null && return 1
  printf '%s\t%s\n' "$best_host" "$best_mid" >> "$CUTS"
  echo "[auto-split] host=$best_host at local t=$best_mid (cycle host, gap ${best_gap}s)" >&2
  return 0
}

# ---------------------------------------------------------------------------
# 4. ORDER + FLAG
# ---------------------------------------------------------------------------
floyd(){
  awk -F'\t' -v n="$NODES" '
    BEGIN{ for(i=0;i<n;i++) for(j=0;j<n;j++) d[i,j]=(i==j?0:1e300) }
    { i=$1+0; j=$2+0; w=$3+0; if(w<d[i,j]) d[i,j]=w }
    END{
      for(k=0;k<n;k++) for(i=0;i<n;i++){ if(d[i,k]>=1e299) continue
        for(j=0;j<n;j++){ if(d[k,j]>=1e299) continue
          v=d[i,k]+d[k,j]; if(v<d[i,j]-1e-9) d[i,j]=v } }
      for(i=1;i<n;i++) if(d[i,i]<-1e-9){ print "NEGCYCLE " i > "/dev/stderr"; exit 3 }
      for(i=1;i<n;i++) for(j=1;j<n;j++) printf "%d\t%d\t%.6f\n",i,j,d[i,j]
    }' "$CONS"
}

report(){
  if ! floyd > "$TMP/dist.tsv" 2>"$TMP/fw.err"; then cat "$TMP/fw.err" >&2; exit 3; fi
  declare -A SP SIDX
  while IFS=$'\t' read -r i j d; do SP["$i,$j"]=$d; done < "$TMP/dist.tsv"
  while read -r i s; do SIDX[$s]=$i; done < "$SEGMAP"

  awk -F'\t' -v OFS='\t' '
    FNR==NR { lo[$1]=$2+0; up[$1]=$3+0; next }
    { printf "%s\t%s\t%.6f\t%.6f\t%.6f\t%s\t%s\t%s\t%s\t%.6f\n",
        $1,$2,$3,$3+lo[$4],$3+up[$4],$4,$5,$6,$13,$3+up[$4] }
  ' "$OFF" "$EV" | sort -t$'\t' -k10,10g -k3,3g > "$TMP/intervals.tsv"

  mapfile -t L < "$TMP/intervals.tsv"
  local n=${#L[@]} k idx=0
  local -a EID EHOST ESRC ESEG ET
  echo "==================================================================="
  echo "  CAUSALLY-CONSISTENT MULTI-SOURCE TIMELINE"
  echo "==================================================================="
  printf '%-4s %-14s %-26s %-8s %-9s %-16s %s\n' \
         '#' 'local_time' 'true_time_[lo..hi]' 'host' 'source' 'kind' 'certainty'
  local prev_seg="" prev_t=""
  for ((k=0;k<n;k++)); do
    IFS=$'\t' read -r id host t lo hi seg src kind msg key <<<"${L[$k]}"
    EID[k]=$id; EHOST[k]=$host; ESRC[k]=$src; ESEG[k]=$seg; ET[k]=$t
    idx=$((idx+1)); local mark="FORCED"
    if [[ -n "$prev_seg" && "$seg" != "$prev_seg" ]]; then
      local p=${SIDX[$prev_seg]} q=${SIDX[$seg]}
      if awk -v s="${SP["$q,$p"]}" -v c="$t" -v d="$prev_t" \
           'BEGIN{exit !(s+0 > c-d+1e-9)}'; then mark="AMBIGUOUS(FLIP)"; fi
    fi
    printf '%-4d %-14s [%s .. %s] %-8s %-9s %-16s %s\n' \
      "$idx" "$(date -u -d "@$t" +%H:%M:%S.%3N)" \
      "$(date -u -d "@$lo" +%H:%M:%S.%3N)" "$(date -u -d "@$hi" +%H:%M:%S.%3N)" \
      "$host" "$src" "$kind" "$mark"
    prev_seg=$seg; prev_t=$t
  done
  echo "==================================================================="
  echo
  echo "ORDERINGS THAT FLIP UNDER RESIDUAL UNCERTAINTY (all pairs, not only adjacent):"
  echo "-------------------------------------------------------------------------------"
  local found=0 i j p q
  for ((i=0;i<n;i++)); do
    for ((j=i+1;j<n;j++)); do
      [[ "${ESEG[i]}" == "${ESEG[j]}" ]] && continue
      p=${SIDX[${ESEG[i]}]}; q=${SIDX[${ESEG[j]}]}
      if awk -v s="${SP["$q,$p"]}" -v c="${ET[j]}" -v d="${ET[i]}" \
           'BEGIN{exit !(s+0 > c-d+1e-9)}'; then
        printf '  FLIP: %s[%s/%s] <-> %s[%s/%s]\n' \
          "${EID[i]}" "${EHOST[i]}" "${ESRC[i]}" \
          "${EID[j]}" "${EHOST[j]}" "${ESRC[j]}"
        found=$((found+1))
      fi
    done
  done
  [[ $found -eq 0 ]] && echo "  (none)"
  echo "Total uncertain pairs: $found"
  echo "==================================================================="
}

# ---------------------------------------------------------------------------
# DRIVER
# ---------------------------------------------------------------------------
attempts=0
while :; do
  assign_segments
  if solve; then break; fi
  attempts=$((attempts+1))
  if [[ $attempts -ge 8 ]] || ! auto_split; then
    echo "ERROR: constraint system still infeasible after $attempts splits" >&2
    cat "$TMP/bf.err" >&2; exit 3
  fi
done

echo "Detected host clock segments:"
awk -F'\t' '{s[$4]++} END{for(k in s) print "  "k"  ("s[k]" events)"}' "$EV" | sort
echo
report

if [[ -n "$OUT" ]]; then
  { echo "# merged timeline (see stdout)"; cat "$TMP/intervals.tsv"; } > "$OUT"
fi
if [[ -n "$DUMP" ]]; then
  mkdir -p "$DUMP"
  cp "$EV" "$CONS" "$SEGMAP" "$OFF" "$TMP/intervals.tsv" "$CUTS" "$DUMP"/
fi
exit 0

Run it:

./timeline-merge.sh --manifest manifest.tsv --out merged.tsv

Expected record fields:

source timestamp anchors
journald JSON __REALTIME_TIMESTAMP (µs) SESSION, SESSION_SEQ, CONN, TCP_SEQ, PID, PPID
app JSON .time ISO-8601 .sssZ .session, .session_seq, .conn, .tcp_seq, .pid, .ppid

Verification

A synthetic scenario with known ground truth is generated: 3 hosts (jump +60 s, db1 −75 s, web1 +40 s corrected to +5 s mid-window), session/TCP/parent-child anchors, and two events (EV9/EV10) that are 1 ms apart with no causal path.

generate-fixture.sh

#!/usr/bin/env bash
set -euo pipefail
DIR=${1:-~/tm/fixture}
rm -rf "$DIR"; mkdir -p "$DIR"
J="$DIR/journald.ndjson"; A="$DIR/app.ndjson"; L="$DIR/auth.log"
: > "$J"; : > "$A"; : > "$L"
T=$(date -d "2026-01-02T03:00:00Z" +%s)
plus(){ awk -v T="$T" -v d="$1" 'BEGIN{printf "%.6f", T+d}'; }
emit(){ # SRC HOST TRUE OFFSET KIND SESS SSEQ CONN TCPSEQ PID PPID MSG
  local src=$1 host=$2 true=$3 off=$4 kind=$5 sess=$6 sseq=$7 conn=$8 tcp=$9 pid=${10} ppid=${11} msg=${12}
  local local_t; local_t=$(awk -v t="$true" -v o="$off" 'BEGIN{printf "%.6f", t-o}')
  case "$src" in
    journald)
      local us; us=$(awk -v t="$local_t" 'BEGIN{printf "%d", t*1000000}')
      jq -cn --arg h "$host" --arg us "$us" --arg k "$kind" --arg s "$sess" \
            --argjson sq "$sseq" --arg c "$conn" --argjson tq "$tcp" \
            --argjson p "$pid" --argjson pp "$ppid" --arg m "$msg" \
        '{__REALTIME_TIMESTAMP:$us,_HOSTNAME:$h,MESSAGE:$m,KIND:$k,SESSION:$s,
          SESSION_SEQ:$sq,CONN:$c,TCP_SEQ:$tq,PID:$p,PPID:$pp}' >> "$J";;
    app)
      local iso; iso=$(date -u -d "@$local_t" +"%Y-%m-%dT%H:%M:%S.%3NZ")
      jq -cn --arg t "$iso" --arg h "$host" --arg k "$kind" --arg s "$sess" \
            --argjson sq "$sseq" --arg c "$conn" --argjson tq "$tcp" \
            --argjson p "$pid" --argjson pp "$ppid" --arg m "$msg" \
        '{time:$t,host:$h,kind:$k,session:$s,session_seq:$sq,conn:$c,

Recomputes the shortest-path feasibility from scratch with Floyd–Warshall and checks the tool's answer:

#!/usr/bin/env python3
import sys, re
dump, outfile = sys.argv[1], sys.argv[2]
INF = float("inf")

def load_events(path):
    ev = {}
    for line in open(path):
        f = line.rstrip("\n").split("\t")
        ev[f[0]] = dict(id=f[0], host=f[1], t=float(f[2]), seg=f[3], msg=f[12])
    return ev

def load_segmap(path):
    idx = {}
    for line in open(path):
        i, s = line.rstrip("\n").split("\t"); idx[s] = int(i)
    return idx

def floyd(cons_path, n):
    d = [[INF]*n for _ in range(n)]
    for i in range(n): d[i][i] = 0.0
    for line in open(cons_path):
        i, j, w = line.split("\t"); i, j, w = int(i), int(j), float(w)
        if w < d[i][j]: d[i][j] = w
    for k in range(n):
        for i in range(n):
            if d[i][k] == INF: continue
            for j in range(n):
                if d[k][j] == INF: continue
                v = d[i][k] + d[k][j]
                if v < d[i][j] - 1e-9: d[i][j] = v
    for i in range(n): assert d[i][i] >= -1e-9, "negative cycle"
    return d

ev = load_events(dump + "/events.tsv")
segidx = load_segmap(dump + "/segmap.tsv")
D = floyd(dump + "/cons.tsv", max(segidx.values()) + 1)

def can_flip(a, b):                      # reverse (b before a) feasible?
    p, q = segidx[a["seg"]], segidx[b["seg"]]
    return p != q and (-D[q][p]) < (a["t"] - b["t"]) - 1e-9

text = open(outfile).read()
tool_flips = set(frozenset(p) for p in
    re.findall(r"FLIP:\s*(\S+)\[.*?\]\s*<->\s*(\S+)\[", text))
order = [l.rstrip("\n").split("\t")[0] for l in open(dump + "/intervals.tsv")]
pos = {e: i for i, e in enumerate(order)}

indep = set()
for i in range(len(order)):
    for j in range(i+1, len(order)):
        a, b = ev[order[i]], ev[order[j]]
        if can_flip(a, b): indep.add(frozenset((a["id"], b["id"])))
assert indep == tool_flips, "FLIP mismatch %r" % (indep ^ tool_flips)
print("PASS flip-set: %d uncertain pairs match" % len(indep))

x = {0: 0.0}
for line in open(dump + "/off.tsv"):
    s, lo, up = line.rstrip("\n").split("\t"); x[segidx[s]] = float(up)
for line in open(dump + "/cons.tsv"):
    i, j, w = line.split("\t"); i, j, w = int(i), int(j), float(w)
    assert x[j] - x[i] <= w + 1e-6, "infeasible: %s" % line
print("PASS gauge: point-estimate satisfies all constraints")

true_time = {1:0.0,2:0.5,3:1.0,4:1.4,5:2.0,6:2.5,7:3.0,8:3.5,
             9:4.0,10:4.001,11:1.2,12:2.8}
tid = {e: int(re.search(r"EV(\d+)", v["msg"]).group(1)) for e, v in ev.items()}
for a in ev:
    for b in ev:
        if a != b and frozenset((a,b)) not in indep \
           and true_time[tid[a]] < true_time[tid[b]] and pos[a] > pos[b]:
            raise SystemExit("FORCED order contradicts truth: %s %s" % (a, b))
print("PASS causality: every forced ordering agrees with ground truth")

assert len({v["seg"] for v in ev.values() if v["host"]=="web1"}) >= 2
print("PASS step-detect: web1 split into two clock segments")

p9 = [k for k,v in tid.items() if v == 9][0]
p10 = [k for k,v in tid.items() if v == 10][0]
assert frozenset((p9,p10)) in indep
print("PASS ambiguity: EV9(jump) vs EV10(db1) flagged")
print("ALL CHECKS PASSED")

Hardening notes for production

  • Use journald's __MONOTONIC_TIMESTAMP (or file offset) as the within-host order when a clock steps backwards; the local-time gap heuristic assumes a forward correction.
  • Feed real TCP windows as [0, RTT] rather than a flat L_TCP; tighter windows sharpen every offset bound.
  • For very large event sets, replace the O(n²) all-pairs flip scan with a time-window filter (only test pairs whose intervals overlap), and replace Floyd–Warshall with Johnson's algorithm.
  • Treat Lmin=0 as causal ≤ (a coincidence is allowed). The flip test is deliberately strict (>), so a forced-precedence pair is never reported as a flip merely because it can be simultaneous.
