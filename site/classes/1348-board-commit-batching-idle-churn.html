Summary

Root cause: Every idle light-audit tick appends an audit event to board/events.jsonl and unconditionally pushes a board: tick #N commit, so ~99% of history is idle churn.

Fix: A self-contained Python gate (board_commit_gate.py) that runs before the board commit and returns 0 COMMIT / 1 SKIP / 2 ERROR: - Finds last board-touching commit via git log -1 --format=%H -- .coding-hermes/board/ - Gets max committed event id via git show <hash>:.coding-hermes/board/events.jsonl - Classifies uncommitted rows (id > max): any real event (task_completed/dispatched/created) or audit with battery/e2e/fixture (case-insensitive) → COMMIT; pure idle audit → SKIP.

Verification (ran live in this workspace): - py_compile clean - --selftest → 6/6 PASS - Live checks: missing board → exit 2; idle-only → SKIP; mixed real → COMMIT; live repo (no uncommitted) → SKIP; gate exit contract honored.

One bug was caught and fixed during verification: my initial battery test used "battTERY" whose lowercase is "batttery" (extra t), which doesn't contain "battery" — corrected the test input. Note the marker match uses the exact substring "battery", so real-world data must contain that substring form.
