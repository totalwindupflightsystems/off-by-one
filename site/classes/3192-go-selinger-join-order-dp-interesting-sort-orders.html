Selinger-Style Join Order Optimizer with Interesting Sort Orders (Go 1.26)

Problem class: go-selinger-join-order-dp-interesting-sort-orders Artifacts written: /workspace/SOLUTION.md, ~/joinopt/

1. Problem statement

Given base relations (cardinality + per-column NDV), a set of equi-join predicates, a DP size limit and a max interesting-order length, produce the cheapest physical join plan. For every (subset, interesting output order) pair only the cheapest plan is retained. The result must expose cost, tree shape and per-operator output orders, and it must be provable that no alternative plan over the same join set with the same interesting order is cheaper.

2. Root-cause analysis

The workspace only contained problem.json with empty error_message/stack_trace: there is no implementation to patch — the defect is the absence of a correct optimizer. The hard part is the semantics that make optimality actually hold:

  1. Left-deep only misses bushy plans like (A⋈B)⋈(C⋈D). Partitioning a subset into any two non-empty sub-subsets covers both.
  2. One cheapest plan per subset discards a pricier plan that emits a useful order — exactly what interesting orders exploit. State must be (subset, order).
  3. Orientation-dependent order matching: joined columns A.x/B.x are the same value. Canonicalise predicate columns via union-find so prefix matching works either way.
  4. Tree-dependent cardinality breaks pruning: if Rows varies by tree, a cheap large plan may be pruned though a pricier smaller one completes cheaper. Use the subset-only System-R estimate |J| = (∏|Ri|) / ∏_{p⊆J} max(Vₗ,Vᵣ).
  5. Unbounded enumeration: cap the 2^n lattice with DPMaxRelations and fall back to greedy.
  6. Illegal operators: hash/merge require an equi-key; merge claims the key order only after paying input sorts unless an existing order is a prefix; NL preserves the outer order.

Correctness conditions

  • Rows(mask) = card(mask) is tree-independent, so for a fixed (mask, order) extension cost depends only on (Cost, Rows, OutOrder); keeping the min is safe.
  • Subsets are visited in increasing numeric order, so every proper submask is already final.
  • Orders are canonicalised and bounded by MaxOrderLen; only the claimed prefix is shortened, the full key still drives sort cost.

// Package joinopt implements a Selinger-style cost-based join optimizer.
//
// It enumerates join orders with subset dynamic programming over the subset
// lattice.  For every (subset, interesting sort order) pair it keeps only the
// cheapest plan, i.e. it prunes plans that are dominated under physical
// property equivalence.  Both left-deep and bushy trees are considered.
//
// Three physical operators are supported:
//
//   - hash join   (requires an equi-join key and produces no interesting order)
//   - nested loop (order of the outer input is preserved)
//   - sort/merge  (sorts inputs on the join key when needed and produces an
//     interesting order on that key)
//
// A DP size limit can be configured; once the subset lattice grows past it the
// optimizer falls back to a greedy join-order heuristic.
package joinopt

import (
    "fmt"
    "math"
    "sort"
    "strings"
)

// ---------------------------------------------------------------------------
// Input model
// ---------------------------------------------------------------------------

// ColRef identifies a column by relation index and column index.
type ColRef struct {
    Rel int
    Col int
}

func (c ColRef) less(o ColRef) bool {
    if c.Rel != o.Rel {
        return c.Rel < o.Rel
    }
    return c.Col < o.Col
}

// Relation is a base relation with an estimated cardinality and, for each
// column, the number of distinct values (NDV).
type Relation struct {
    Name string
    Rows float64
    NDV  []float64
}

// Predicate is a single equi-join predicate between two columns.
type Predicate struct {
    Left  ColRef
    Right ColRef
}

// OpKind enumerates the physical operators.
type OpKind int

const (
    OpBase OpKind = iota
    OpHashJoin
    OpNLJoin
    OpMergeJoin
)

func (o OpKind) String() string {
    switch o {
    case OpBase:
        return "Scan"
    case OpHashJoin:
        return "HashJoin"
    case OpNLJoin:
        return "NLJoin"
    case OpMergeJoin:
        return "MergeJoin"
    }
    return "?"
}

// Plan is a physical operator tree. OutOrder holds the canonical interesting
// order with which the operator emits its tuple stream.
type Plan struct {
    Op       OpKind
    Name     string // base relation name (OpBase only)
    Rel      int    // base relation index (OpBase only)
    Left     *Plan
    Right    *Plan
    Preds    []Predicate
    Cost     float64
    Rows     float64
    OutOrder []ColRef
    Mask     uint32 // bitmask of base relations produced by this subtree
}

// Explain renders the plan as an indented tree including the per-operator
// output ordering.
func (p *Plan) Explain() string {
    var b strings.Builder
    var rec func(n *Plan, depth int, label string)
    rec = func(n *Plan, depth int, label string) {
        indent := strings.Repeat("  ", depth)
        switch n.Op {
        case OpBase:
            fmt.Fprintf(&b, "%s%sScan(%s) rows=%.1f cost=%.2f order=%s\n",
                indent, label, n.Name, n.Rows, n.Cost, orderString(n.OutOrder))
        default:
            fmt.Fprintf(&b, "%s%s%s rows=%.1f cost=%.2f order=%s preds=%s\n",
                indent, label, n.Op, n.Rows, n.Cost, orderString(n.OutOrder), predsString(n.Preds))
            rec(n.Left, depth+1, "L: ")
            rec(n.Right, depth+1, "R: ")
        }
    }
    rec(p, 0, "")
    return b.String()
}

func orderString(o []ColRef) string {
    if len(o) == 0 {
        return "[]"
    }
    parts := make([]string, len(o))
    for i, c := range o {
        parts[i] = fmt.Sprintf("r%d.c%d", c.Rel, c.Col)
    }
    return "[" + strings.Join(parts, ",") + "]"
}

func predsString(ps []Predicate) string {
    parts := make([]string, len(ps))
    for i, p := range ps {
        parts[i] = fmt.Sprintf("r%d.c%d=r%d.c%d", p.Left.Rel, p.Left.Col, p.Right.Rel, p.Right.Col)
    }
    return "[" + strings.Join(parts, ",") + "]"
}

// ---------------------------------------------------------------------------
// Utilities
// ---------------------------------------------------------------------------

func cloneOrder(o []ColRef) []ColRef {
    if len(o) == 0 {
        return []ColRef{}
    }
    out := make([]ColRef, len(o))
    copy(out, o)
    return out
}

func orderKey(o []ColRef) string {
    if len(o) == 0 {
        return ""
    }
    var b strings.Builder
    for i, c := range o {
        if i > 0 {
            b.WriteByte(',')
        }
        fmt.Fprintf(&b, "%d:%d", c.Rel, c.Col)
    }
    return b.String()
}

// hasPrefix reports whether req is a prefix of order.  A stream sorted on a
// longer key also satisfies a shorter requirement.
func hasPrefix(order, req []ColRef) bool {
    if len(req) > len(order) {
        return false
    }
    for i := range req {
        if order[i] != req[i] {
            return false
        }
    }
    return true
}

func relInMask(mask uint32, rel int) bool {
    return mask&(uint32(1)<<uint(rel)) != 0
}

func isSingleBit(mask uint32) bool {
    return mask != 0 && mask&(mask-1) == 0
}

func trailingBit(mask uint32) int {
    i := 0
    for mask&1 == 0 {
        mask >>= 1
        i++
    }
    return i
}

// buildRep returns a canonical representative for every column equivalence
// class induced by the join predicates (union-find).  Canonicalising orders
// makes them orientation independent: r0.c0 and r1.c0, joined together, map to
// the same representative.
func buildRep(preds []Predicate) func(ColRef) ColRef {
    parent := map[ColRef]ColRef{}
    var find func(ColRef) ColRef
    find = func(c ColRef) ColRef {
        p, ok := parent[c]
        if !ok || p == c {
            parent[c] = c
            return c
        }
        r := find(p)
        parent[c] = r
        return r
    }
    union := func(a, b ColRef) {
        ra, rb := find(a), find(b)
        if ra == rb {
            return
        }
        if rb.less(ra) {
            ra, rb = rb, ra
        }
        parent[rb] = ra
    }
    for _, p := range preds {
        union(p.Left, p.Right)
    }
    return find
}

func canonOrder(o []ColRef, rep func(ColRef) ColRef) []ColRef {
    out := make([]ColRef, len(o))
    for i, c := range o {
        out[i] = rep(c)
    }
    return out
}

// predicateColumns returns the sorted, de-duplicated canonical columns that
// appear in predicates.  These are the only columns that can carry an
// interesting order produced by a merge join.
func predicateColumns(preds []Predicate, rep func(ColRef) ColRef) []ColRef {
    seen := map[ColRef]bool{}
    var cols []ColRef
    for _, p := range preds {
        for _, c := range []ColRef{p.Left, p.Right} {
            r := rep(c)
            if !seen[r] {
                seen[r] = true
                cols = append(cols, r)
            }
        }
    }
    sort.Slice(cols, func(i, j int) bool { return cols[i].less(cols[j]) })
    return cols
}

// genOrders returns every sequence of distinct columns (length 0..maxLen) over
// cols.  This is the universe of interesting sort orders the optimizer
// reasons about.
func genOrders(cols []ColRef, maxLen int) [][]ColRef {
    res := [][]ColRef{{}}
    used := make([]bool, len(cols))
    var rec func(cur []ColRef)
    rec = func(cur []ColRef) {
        if len(cur) == maxLen {
            return
        }
        for i, c := range cols {
            if used[i] {
                continue
            }
            used[i] = true
            next := append(append([]ColRef{}, cur...), c)
            res = append(res, next)
            rec(next)
            used[i] = false
        }
    }
    rec(nil)
    return res
}

// Cost model
// ---------------------------------------------------------------------------

const (
    hashPerRow  = 1.0
    mergePerRow = 1.0
)

func baseNDV(relns []Relation, c ColRef) float64 {
    if c.Rel >= 0 && c.Rel < len(relns) && c.Col >= 0 && c.Col < len(relns[c.Rel].NDV) {
        if v := relns[c.Rel].NDV[c.Col]; v > 0 {
            return v
        }
    }
    return 1
}

// makeCardFunc returns the estimated cardinality of any subset of relations.
//
// The estimate is the System-R formula
//
//  |R1|*...*|Rk| / prod over predicates (both endpoints in the subset) max(Vl,Vr)
//
// Crucially it depends only on the subset, never on the join tree.  That is
// what makes it sound for the DP to keep a single cheapest plan per
// (subset, interesting order): the extension cost of a plan is a function of
// (Cost, Rows, OutOrder) and Rows is fixed for the subset, so a dominated plan
// can never lead to a cheaper completion.
func makeCardFunc(relns []Relation, preds []Predicate) func(uint32) float64 {
    memo := map[uint32]float64{}
    return func(mask uint32) float64 {
        if v, ok := memo[mask]; ok {
            return v
        }
        rows := 1.0
        for r := range relns {
            if relInMask(mask, r) {
                rows *= relns[r].Rows
            }
        }
        for _, p := range preds {
            if relInMask(mask, p.Left.Rel) && relInMask(mask, p.Right.Rel) {
                if d := math.Max(baseNDV(relns, p.Left), baseNDV(relns, p.Right)); d > 1 {
                    rows /= d
                }
            }
        }
        if rows < 1 {
            rows = 1
        }
        memo[mask] = rows
        return rows
    }
}

func hashJoinCost(a, b *Plan) float64 {
    build := math.Min(a.Rows, b.Rows)
    probe := math.Max(a.Rows, b.Rows)
    return a.Cost + b.Cost + hashPerRow*(build+probe)
}

func sortCost(p *Plan, key []ColRef) float64 {
    if len(key) == 0 || hasPrefix(p.OutOrder, key) || p.Rows <= 1 {
        return 0
    }
    return p.Rows * math.Log(p.Rows) / math.Ln2
}

// joinKeyOrder is the canonical order produced by a sort/merge join on the
// given predicates.
func joinKeyOrder(preds []Predicate, rep func(ColRef) ColRef) []ColRef {
    seen := map[ColRef]bool{}
    var keys []ColRef
    for _, p := range preds {
        r := rep(p.Left)
        if !seen[r] {
            seen[r] = true
            keys = append(keys, r)
        }
    }
    sort.Slice(keys, func(i, j int) bool { return keys[i].less(keys[j]) })
    if keys == nil {
        keys = []ColRef{}
    }
    return keys
}

func connectingPreds(ma, mb uint32, preds []Predicate) []Predicate {
    var out []Predicate
    for _, p := range preds {
        inA := relInMask(ma, p.Left.Rel)
        inB := relInMask(ma, p.Right.Rel)
        inA2 := relInMask(mb, p.Left.Rel)
        inB2 := relInMask(mb, p.Right.Rel)
        if (inA && inB2) || (inB && inA2) {
            out = append(out, p)
        }
    }
    return out
}

// truncateOrder bounds the length of a physical order to maxLen.  Sorting the
// inputs still uses the full join key; only the *claimed* output order is
// shortened, which keeps the number of DP states bounded.
func truncateOrder(o []ColRef, maxLen int) []ColRef {
    if maxLen > 0 && len(o) > maxLen {
        return o[:maxLen]
    }
    return o
}

// allJoins returns every physical way of joining a and b.  The DP and the
// exhaustive verifier both consume this so that they share the cost model.
func allJoins(a, b *Plan, cps []Predicate, card func(uint32) float64, rep func(ColRef) ColRef, maxLen int) []*Plan {
    mask := a.Mask | b.Mask
    // Rows depends only on the subset, never on which operator or tree shape
    // produced it.
    rows := card(mask)
    nlCost := a.Cost + b.Cost + a.Rows*b.Rows
    out := []*Plan{
        // Nested loop with a as outer: preserves a's order.
        {Op: OpNLJoin, Left: a, Right: b, Preds: cps, Cost: nlCost, Rows: rows, OutOrder: cloneOrder(a.OutOrder), Mask: mask},
        // Nested loop with b as outer: preserves b's order.
        {Op: OpNLJoin, Left: b, Right: a, Preds: cps, Cost: nlCost, Rows: rows, OutOrder: cloneOrder(b.OutOrder), Mask: mask},
    }
    if len(cps) > 0 {
        // The inputs are sorted on the full canonical join key, but only a
        // bounded prefix of it is retained as an interesting order.
        fullKey := joinKeyOrder(cps, rep)
        outKey := truncateOrder(fullKey, maxLen)
        out = append(out,
            // Hash join: no interesting order survives.
            &Plan{Op: OpHashJoin, Left: a, Right: b, Preds: cps, Cost: hashJoinCost(a, b), Rows: rows, OutOrder: []ColRef{}, Mask: mask},
            // Sort/merge join: emits the canonical join-key order.
            &Plan{Op: OpMergeJoin, Left: a, Right: b, Preds: cps,
                Cost: a.Cost + b.Cost + sortCost(a, fullKey) + sortCost(b, fullKey) + mergePerRow*(a.Rows+b.Rows),
                Rows: rows, OutOrder: outKey, Mask: mask},
        )
    }
    return out
}

func bestJoin(a, b *Plan, cps []Predicate, card func(uint32) float64, rep func(ColRef) ColRef, maxLen int) *Plan {
    var best *Plan
    for _, p := range allJoins(a, b, cps, card, rep, maxLen) {
        if best == nil || p.Cost < best.Cost {
            best = p
        }
    }
    return best
}

// ---------------------------------------------------------------------------
// Public API
// ---------------------------------------------------------------------------

// Config controls enumeration.
type Config struct {
    // DPMaxRelations is the largest number of relations for which full subset
    // DP is used.  Above it the greedy heuristic is used.  Defaults to 10.
    DPMaxRelations int
    // MaxOrderLen is the maximum length of an interesting sort order.
    // Defaults to 3.
    MaxOrderLen int
}

// Result is the outcome of optimization.
type Result struct {
    Best       *Plan
    Cost       float64
    ByOrder    map[string]float64 // cheapest cost per full-set output order
    UsedGreedy bool
}

// OrderCost returns the cheapest cost known for an exact output order.
func (r *Result) OrderCost(order []ColRef) (float64, bool) {
    c, ok := r.ByOrder[orderKey(order)]
    return c, ok
}

// Optimize plans a join over all supplied relations.
func Optimize(relns []Relation, preds []Predicate, cfg Config) (*Result, error) {
    if len(relns) == 0 {
        return nil, fmt.Errorf("joinopt: no relations")
    }
    if cfg.DPMaxRelations <= 0 {
        cfg.DPMaxRelations = 10
    }
    if cfg.MaxOrderLen <= 0 {
        cfg.MaxOrderLen = 3
    }
    rep := buildRep(preds)
    card := makeCardFunc(relns, preds)

    if len(relns) > cfg.DPMaxRelations {
        p := greedy(relns, preds, card, rep, cfg.MaxOrderLen)
        return &Result{
            Best:       p,
            Cost:       p.Cost,
            ByOrder:    map[string]float64{orderKey(p.OutOrder): p.Cost},
            UsedGreedy: true,
        }, nil
    }

    n := len(relns)
    full := uint32(1)<<uint(n) - 1
    dp := map[uint32]map[string]*Plan{}

    base := func(r int) *Plan {
        m := uint32(1) << uint(r)
        return &Plan{
            Op:       OpBase,
            Name:     relns[r].Name,
            Rel:      r,
            Cost:     relns[r].Rows,
            Rows:     card(m),
            Mask:     m,
            OutOrder: []ColRef{},
        }
    }
    addPlan := func(mask uint32, p *Plan) {
        m := dp[mask]
        if m == nil {
            m = map[string]*Plan{}
            dp[mask] = m
        }
        k := orderKey(p.OutOrder)
        if old, ok := m[k]; !ok || p.Cost < old.Cost {
            m[k] = p
        }
    }
    planList := func(mask uint32) []*Plan {
        m := dp[mask]
        keys := make([]string, 0, len(m))
        for k := range m {
            keys = append(keys, k)
        }
        sort.Strings(keys)
        out := make([]*Plan, 0, len(keys))
        for _, k := range keys {
            out = append(out, m[k])
        }
        return out
    }

    for r := 0; r < n; r++ {
        addPlan(uint32(1)<<uint(r), base(r))
    }

    for mask := uint32(1); mask <= full; mask++ {
        if isSingleBit(mask) {
            continue
        }
        for l := (mask - 1) & mask; l > 0; l = (l - 1) & mask {
            r := mask ^ l
            if r == 0 {
                continue
            }
            cps := connectingPreds(l, r, preds)
            for _, a := range planList(l) {
                for _, b := range planList(r) {
                    for _, p := range allJoins(a, b, cps, card, rep, cfg.MaxOrderLen) {
                        addPlan(mask, p)
                    }
                }
            }
        }
    }

    byOrder := map[string]float64{}
    var best *Plan
    for _, p := range planList(full) {
        if best == nil || p.Cost < best.Cost {
            best = p
        }
        k := orderKey(p.OutOrder)
        if v, ok := byOrder[k]; !ok || p.Cost < v {
            byOrder[k] = p.Cost
        }
    }
    if best == nil {
        // Disconnected inputs with no predicates at all still need a plan.
        best = greedy(relns, preds, card, rep, cfg.MaxOrderLen)
        byOrder[orderKey(best.OutOrder)] = best.Cost
    }
    return &Result{Best: best, Cost: best.Cost, ByOrder: byOrder}, nil
}

// greedy builds a left-deep plan by repeatedly joining the remaining relation
// that yields the cheapest next join.  It is used once the subset lattice
// exceeds the DP size limit.
func greedy(relns []Relation, preds []Predicate, card func(uint32) float64, rep func(ColRef) ColRef, maxLen int) *Plan {
    n := len(relns)
    if n == 0 {
        return nil
    }
    used := make([]bool, n)
    start := 0
    for i := 1; i < n; i++ {
        if relns[i].Rows < relns[start].Rows {
            start = i
        }
    }
    cur := &Plan{
        Op: OpBase, Name: relns[start].Name, Rel: start,
        Cost: relns[start].Rows, Rows: card(uint32(1) << uint(start)),
        Mask: uint32(1) << uint(start), OutOrder: []ColRef{},
    }
    used[start] = true
    for count := 1; count < n; count++ {
        var best *Plan
        for j := 0; j < n; j++ {
            if used[j] {
                continue
            }
            b := &Plan{
                Op: OpBase, Name: relns[j].Name, Rel: j,
                Cost: relns[j].Rows, Rows: card(uint32(1) << uint(j)),
                Mask: uint32(1) << uint(j), OutOrder: []ColRef{},
            }
            cps := connectingPreds(cur.Mask, b.Mask, preds)
            cand := bestJoin(cur, b, cps, card, rep, maxLen)
            if best == nil || cand.Cost < best.Cost {
                best = cand
            }
        }
        cur = best
        for j := 0; j < n; j++ {
            used[j] = relInMask(cur.Mask, j)
        }
    }
    return cur
}

// ExhaustivePlans enumerates every physical plan for the full relation set
// without any pruning.  It is exponential and intended only for verifying the
// DP on small inputs (roughly <= 5 relations).
func ExhaustivePlans(relns []Relation, preds []Predicate, cfg Config) []*Plan {
    if cfg.MaxOrderLen <= 0 {
        cfg.MaxOrderLen = 3
    }
    rep := buildRep(preds)
    card := makeCardFunc(relns, preds)
    memo := map[uint32][]*Plan{}
    var rec func(mask uint32) []*Plan
    rec = func(mask uint32) []*Plan {
        if v, ok := memo[mask]; ok {
            return v
        }
        if isSingleBit(mask) {
            r := trailingBit(mask)
            p := &Plan{
                Op: OpBase, Name: relns[r].Name, Rel: r,
                Cost: relns[r].Rows, Rows: card(mask),
                Mask: mask, OutOrder: []ColRef{},
            }
            memo[mask] = []*Plan{p}
            return memo[mask]
        }
        var out []*Plan
        for l := (mask - 1) & mask; l > 0; l = (l - 1) & mask {
            r := mask ^ l
            if r == 0 {
                continue
            }
            cps := connectingPreds(l, r, preds)
            for _, a := range rec(l) {
                for _, b := range rec(r) {
                    out = append(out, allJoins(a, b, cps, card, rep, cfg.MaxOrderLen)...)
                }
            }
        }
        memo[mask] = out
        return out
    }
    full := uint32(1)<<uint(len(relns)) - 1
    return rec(full)
}

// InterestingOrders returns the universe of interesting sort orders the
// optimizer reasons about: every sequence of distinct predicate columns up to
// MaxOrderLen, using canonical representatives.  This is exposed so callers can
// inspect or assert on the physical properties the optimizer tracks.
func InterestingOrders(preds []Predicate, cfg Config) [][]ColRef {
    if cfg.MaxOrderLen <= 0 {
        cfg.MaxOrderLen = 3
    }
    rep := buildRep(preds)
    return genOrders(predicateColumns(preds, rep), cfg.MaxOrderLen)
}

// VerifyOptimal checks that the DP result cannot be beaten by any alternative
// plan over the same join set, both globally and for each exact output order.
func VerifyOptimal(relns []Relation, preds []Predicate, cfg Config) error {
    res, err := Optimize(relns, preds, cfg)
    if err != nil {
        return err
    }
    if res.UsedGreedy {
        return fmt.Errorf("joinopt: DP was not used, cannot verify optimality")
    }
    plans := ExhaustivePlans(relns, preds, cfg)
    best := math.Inf(1)
    byOrder := map[string]float64{}
    for _, p := range plans {
        if p.Cost < best {
            best = p.Cost
        }
        k := orderKey(p.OutOrder)
        if v, ok := byOrder[k]; !ok || p.Cost < v {
            byOrder[k] = p.Cost
        }
    }
    const eps = 1e-6
    if math.Abs(res.Cost-best) > eps {
        return fmt.Errorf("joinopt: DP cost %.6f != exhaustive optimum %.6f", res.Cost, best)
    }
    for k, v := range byOrder {
        got, ok := res.ByOrder[k]
        if !ok {
            return fmt.Errorf("joinopt: DP missing order %q (exhaustive %.6f)", k, v)
        }
        if math.Abs(got-v) > eps {
            return fmt.Errorf("joinopt: order %q DP %.6f != exhaustive %.6f", k, got, v)
        }
    }
    return nil

// Interesting order prefix semantics: a merge join produces the canonical join
// key order, and a later merge on the same key needs no extra sort.
func TestMergeProducesReusableOrder(t *testing.T) {
    relns := []Relation{
        {Name: "A", Rows: 10000, NDV: []float64{1000}},
        {Name: "B", Rows: 10000, NDV: []float64{1000}},
        {Name: "C", Rows: 10000, NDV: []float64{1000}},
    }
    // A.x = B.x and A.x = C.x, i.e. one equivalence class.
    preds := []Predicate{
        {Left: ColRef{0, 0}, Right: ColRef{1, 0}},
        {Left: ColRef{0, 0}, Right: ColRef{2, 0}},
    }
    rep := buildRep(preds)
    maskA := uint32(1) << 0
    maskB := uint32(1) << 1
    a := &Plan{Op: OpBase, Name: "A", Rel: 0, Cost: 10000, Rows: 10000, Mask: maskA}
    b := &Plan{Op: OpBase, Name: "B", Rel: 1, Cost: 10000, Rows: 10000, Mask: maskB}

    joins := allJoins(a, b, connectingPreds(maskA, maskB, preds), makeCardFunc(relns, preds), rep, 3)
    var merge, hash *Plan
    for _, p := range joins {
        switch p.Op {
        case OpMergeJoin:
            merge = p
        case OpHashJoin:
            hash = p
        }
    }
    if merge == nil || hash == nil {
        t.Fatalf("expected merge and hash joins, got %v", joins)
    }
    if len(merge.OutOrder) == 0 {
        t.Fatalf("merge join should emit a non-empty interesting order")
    }
    if len(hash.OutOrder) != 0 {
        t.Fatalf("hash join should not emit an interesting order")
    }
    key := joinKeyOrder(connectingPreds(maskA, maskB, preds), rep)
    if sc := sortCost(merge, key); sc != 0 {
        t.Fatalf("merge result unexpectedly needs resort: %v", sc)
    }
    if sc := sortCost(hash, key); sc <= 0 {
        t.Fatalf("hash result should need a sort for %v", key)
    }
}

// Every relation appears exactly once, masks are consistent, and each stored
// node cost equals its operator's local cost plus its children's costs.
func TestPlanCoversAllRelationsOnce(t *testing.T) {
    for _, tc := range instances() {
        t.Run(tc.name, func(t *testing.T) {
            res, err := Optimize(tc.relns, tc.preds, Config{MaxOrderLen: 3})
            if err != nil {
                t.Fatal(err)
            }
            rep := buildRep(tc.preds)
            card := makeCardFunc(tc.relns, tc.preds)
            counts := map[int]int{}
            var walk func(*Plan)
            walk = func(p *Plan) {
                if p.Op == OpBase {
                    counts[p.Rel]++
                    if p.Mask != uint32(1)<<uint(p.Rel) {
                        t.Fatalf("base mask %b wrong", p.Mask)
                    }
                    if !approx(p.Cost, tc.relns[p.Rel].Rows) {
                        t.Fatalf("base cost %.3f", p.Cost)
                    }
                    return
                }
                walk(p.Left)
                walk(p.Right)
                l, r := p.Left, p.Right
                if p.Mask != l.Mask|r.Mask {
                    t.Fatalf("mask %b != %b|%b", p.Mask, l.Mask, r.Mask)
                }
                // Predicates must connect exactly the two input sets.
                for _, pr := range p.Preds {
                    if !(relInMask(l.Mask, pr.Left.Rel) != relInMask(l.Mask, pr.Right.Rel)) {
                        t.Fatalf("predicate %v does not connect %b and %b", pr, l.Mask, r.Mask)
                    }
                }
                wantRows := card(p.Mask)
                if !approx(p.Rows, wantRows) {
                    t.Fatalf("rows %.3f want %.3f", p.Rows, wantRows)
                }
                var local float64
                switch p.Op {
                case OpNLJoin:
                    local = l.Rows * r.Rows
                case OpHashJoin:
                    local = hashPerRow * (math.Min(l.Rows, r.Rows) + math.Max(l.Rows, r.Rows))
                case OpMergeJoin:
                    key := joinKeyOrder(p.Preds, rep)
                    local = sortCost(l, key) + sortCost(r, key) + mergePerRow*(l.Rows+r.Rows)
                }
                if !approx(p.Cost, l.Cost+r.Cost+local) {
                    t.Fatalf("%v cost %.3f want %.3f", p.Op, p.Cost, l.Cost+r.Cost+local)
                }
            }
            walk(res.Best)
            for i := range tc.relns {
                if counts[i] != 1 {
                    t.Fatalf("relation %d appears %d times", i, counts[i])
                }
            }
            if !approx(res.Cost, res.Best.Cost) {
                t.Fatalf("Result.Cost %.3f != Best.Cost %.3f", res.Cost, res.Best.Cost)
            }
        })
    }
}

func randInst(rng *rand.Rand, n int) ([]Relation, []Predicate) {
    relns := make([]Relation, n)
    for i := range relns {
        relns[i] = Relation{
            Name: string(rune('A' + i)),
            Rows: float64(100 + rng.Intn(5000)),
            NDV:  []float64{float64(5 + rng.Intn(200)), float64(5 + rng.Intn(200))},
        }
    }
    // A random spanning tree guarantees connectivity.
    var preds []Predicate
    for i := 1; i < n; i++ {
        p := rng.Intn(i)
        preds = append(preds, Predicate{
            Left:  ColRef{i, rng.Intn(2)},
            Right: ColRef{p, rng.Intn(2)},
        })
    }
    // A few extra predicates.
    for k, extra := 0, rng.Intn(n); k < extra; k++ {
        a, b := rng.Intn(n), rng.Intn(n)
        if a == b {
            continue
        }
        preds = append(preds, Predicate{Left: ColRef{a, rng.Intn(2)}, Right: ColRef{b, rng.Intn(2)}})
    }
    return relns, preds
}

5.3 Why optimality is sound

  1. allJoins sets Rows = card(a.Mask | b.Mask) — a subset-only value.
  2. Parent cost depends only on children's Cost, Rows, OutOrder and fixed card; sort cost depends on Rows/OutOrder only.
  3. Hence for fixed (mask, order) a minimum-Cost plan is a best building block; keeping it is safe.
  4. Every partition mask = L ⊎ R is enumerated (bushy), and all operator variants/orientations are generated.
  5. ExhaustivePlans prunes nothing; DP equalling its minimum for every order proves pruning removed no optimum.

5.4 Complexity

  • DP: O(3^n · |orders|), |orders| ≤ Σ_{k≤M} P(p,k).
  • Space: O(2^n · |orders|).
  • DPMaxRelations (default 10) → greedy O(n²) beyond it.
  • MaxOrderLen (default 3); truncation is safe because longer keys satisfy shorter prefixes.
