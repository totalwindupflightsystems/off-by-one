go-foreman stale-worker / duplicate-dispatch — diagnosis and fix

Problem class: go-foreman-stale-worker-duplicate-dispatch Affected ticks: 776 (instant spawn death) and 777 (live-but-inert worker, false "killed" event) Canonical values (the source of truth):

Item Wrong (documented / passed) Correct (canonical / configured)
Workdir ~/&lt;project&gt; ~/Hermes-DAGger/&lt;project&gt;
Provider zai zai-glm-default
Dispatch form stdin heredoc / inline prompt --provider <verified> --query-file <file>
Liveness signal kill -0 / process presence side effect: state.db sessions + git status
Kill method kill (SIGTERM) only SIGTERM by explicit PID, then SIGKILL

1. Symptom timeline

Tick What happened Evidence
776 First dispatch. Worker process exited instantly; no /proc/<pid> entry; zero diff. bash: cd: ~/&lt;project&gt;: No such file or directory, wrapper exit=1
777 Second dispatch (same task id). Process started, then sat at 0% CPU, zero writes, clean worktree. Board event said the worker was killed. Process still alive 23.5 min later, inert

The two failed ticks were not independent: once 776 failed silently, 777 re-dispatched the same task id while the board had no proof the previous worker was gone. The 777 worker then became a second live process for that task — the duplicate-dispatch condition.

2. Root-cause analysis

RC1 — Skill workdir drift (tick 776: instant death)

The project skill documented ~/&lt;project&gt;. The real checkout is ~/Hermes-DAGger/&lt;project&gt; (missing Hermes-DAGger segment + case). The dispatch wrapper runs the worker through bash -lic "cd <documented>; exec ...". cd fails, the wrapper exits 1 before exec, so the spawned PID disappears immediately, leaves no /proc entry, and produces zero diff. Nothing in the foreman diagnosed why; it just saw an empty result and re-queued.

Verified:

bash: cd: ~/&lt;project&gt;: No such file or directory
wrapper exit=1

RC2 — Provider alias not registered (zai vs zai-glm-default) (tick 777: inert worker)

The dispatcher passed --provider zai. The configured provider id is zai-glm-default; zai is not in the allowed set. The resulting agent starts but makes no progress: 0% CPU, no tool calls, no writes. An "inert" agent is indistinguishable from a dead one if you only watch the PID.

RC3 — Liveness inferred from process presence, and board events trusted (duplicate dispatch)

Two compounding control bugs:

  1. The bash -lic wrapper ignores SIGTERM. Interactive bash has SIGTERM ignored, so a plain kill <pid> (TERM) did not stop the wrapper. The tick-777 event claimed "worker killed", but ps would have shown it alive. Verified: the wrapper only died on kill -9.
  2. Liveness was checked with kill -0 / process presence instead of side effects. A live-but-inert worker passes kill -0, so the loop either waited forever or (worse) treated the stale event as truth and re-dispatched — while the old worker still held the worktree.

Contributing bug found during verification: pgrep -f self-match

pgrep -f "worker-<TASK>" matches any process whose command line contains the string — including the guard's own shell/pipeline (sed, grep, an editor). A naive pkill -f guard can kill the foreman that is running the guard. Any automated kill must filter by real executable (/proc/<pid>/exe), verify /proc/<pid>/cmdline, and prefer a written pidfile.

3. Exact fix

3.1 Go patch — hardened dispatch primitives

Drop this into the foreman package and replace the old cwd/provider/liveness logic. It is stdlib-only and was compiled and self-tested (go1.26.8).

// dispatch_guard.go — package foreman
package foreman

import (
    "bufio"
    "fmt"
    "os"
    "os/exec"
    "path/filepath"
    "strconv"
    "strings"
    "syscall"
    "time"
)

// F1 — resolve the canonical workdir; FAIL CLOSED (never trust the skill doc).
func CanonicalWorkdir(candidates ...string) (string, error) {
    for _, c := range candidates {
        c = os.ExpandEnv(c)
        if st, err := os.Stat(c); err == nil && st.IsDir() {
            return filepath.EvalSymlinks(c)
        }
    }
    return "", fmt.Errorf("no canonical workdir among %v", candidates)
}

// F2 — reject an unregistered alias (e.g. "zai") and substitute the
// configured default ("zai-glm-default"); report the substitution.
func ResolveProvider(configPath, requested string) (string, bool, error) {
    allowed := []string{}
    def := ""
    f, err := os.Open(configPath)
    if err != nil {
        return "", false, err
    }
    defer f.Close()
    section := ""
    sc := bufio.NewScanner(f)
    for sc.Scan() {
        line := strings.TrimSpace(sc.Text())
        if line == "" || strings.HasPrefix(line, "#") {
            continue
        }
        if strings.HasSuffix(line, ":") {
            section = strings.TrimSuffix(line, ":")
            continue
        }
        if section == "providers" && strings.HasPrefix(line, "default:") {
            def = strings.TrimSpace(strings.TrimPrefix(line, "default:"))
        }
        if section == "allowed" && strings.HasPrefix(line, "-") {
            allowed = append(allowed, strings.TrimSpace(strings.TrimPrefix(line, "-")))
        }
    }
    if def == "" {
        return "", false, fmt.Errorf("config %s has no providers.default", configPath)
    }
    for _, a := range allowed {
        if a == requested {
            return requested, false, nil
        }
    }
    return def, true, nil
}

// F3 — write the prompt to a file instead of argv/stdin; avoids argv limits
// and the pi "stdin never reaches EOF" hang.
func QueryFileArgs(taskID, provider, prompt string) (args []string, path string, err error) {
    f, err := os.CreateTemp("", "query-"+taskID+"-*.txt")
    if err != nil {
        return nil, "", err
    }
    if _, err := f.WriteString(prompt); err != nil {
        f.Close()
        return nil, "", err
    }
    f.Close()
    return []string{"--provider", provider, "--query-file", f.Name()}, f.Name(), nil
}

// F4 — liveness by SIDE EFFECT. Process presence is deliberately not used.
type Snapshot struct {
    Messages int64
    Tools    int64
    DirtySrc bool
}

func SnapshotState(stateDB, taskID, workdir string) Snapshot {
    var s Snapshot
    out, err := exec.Command("sqlite3", stateDB,
        fmt.Sprintf("select coalesce(sum(message_count),0),coalesce(sum(tool_count),0) "+
            "from sessions where task_id='%s';", taskID)).Output()
    if err == nil {
        if f := strings.Split(strings.TrimSpace(string(out)), "|"); len(f) == 2 {
            s.Messages, _ = strconv.ParseInt(f[0], 10, 64)
            s.Tools, _ = strconv.ParseInt(f[1], 10, 64)
        }
    }
    if st, err := exec.Command("git", "-C", workdir, "status", "--porcelain").Output(); err == nil {
        for _, l := range strings.Split(string(st), "\n") {
            for _, ext := range []string{".go", ".py", ".ts", ".js", ".rs", ".java", ".c", ".cpp", ".h", ".md", ".yaml", ".yml", ".json"} {
                if strings.HasSuffix(strings.TrimSpace(l), ext) {
                    s.DirtySrc = true
                }
            }
        }
    }
    return s
}

func AliveBySideEffect(before, after Snapshot) (bool, string) {
    if after.Messages > before.Messages || after.Tools > before.Tools {
        return true, "telemetry advanced (messages/tools)"
    }
    if !before.DirtySrc && after.DirtySrc {
        return true, "new source file in worktree"
    }
    return false, "no side effect: zero writes, clean worktree"
}

// F5 — find any live worker for this task, then stop it by explicit PID.
// Verify with /proc; never trust a prior board event that says "killed".
func FindWorkerPIDs(taskID, workdir string, self int) []int {
    pf := fmt.Sprintf("/tmp/foreman-workers/%s.pid", taskID)
    if b, err := os.ReadFile(pf); err == nil {
        if pid, err := strconv.Atoi(strings.TrimSpace(string(b))); err == nil {
            if syscall.Kill(pid, 0) == nil {
                return []int{pid}
            }
        }
    }
    out, _ := exec.Command("pgrep", "-f", "worker-"+taskID).Output()
    var pids []int
    for _, l := range strings.Fields(string(out)) {
        pid, err := strconv.Atoi(l)
        if err != nil || pid == self {
            continue
        }
        // pgrep -f matches shell builtins/pipelines too: require a real agent/shell exe.
        exe, err := os.Readlink(fmt.Sprintf("/proc/%d/exe", pid))
        if err != nil {
            continue
        }
        switch filepath.Base(exe) {
        case "bash", "sh", "dash", "pi", "hermes", "node":
        default:
            continue
        }
        cmdline, _ := os.ReadFile(fmt.Sprintf("/proc/%d/cmdline", pid))
        if !strings.Contains(strings.ReplaceAll(string(cmdline), "\x00", " "), "worker-"+taskID) {
            continue
        }
        if cwd, err := os.Readlink(fmt.Sprintf("/proc/%d/cwd", pid)); err == nil && workdir != "" && cwd != workdir {
            continue
        }
        pids = append(pids, pid)
    }
    return pids
}

// SIGTERM, grace, SIGKILL. A `bash -lic` wrapper ignores TERM, so KILL is mandatory.
func Terminate(pid int, grace time.Duration) string {
    if err := syscall.Kill(pid, syscall.SIGTERM); err != nil {
        return "already-gone"
    }
    deadline := time.Now().Add(grace)
    for time.Now().Before(deadline) {
        time.Sleep(200 * time.Millisecond)
        if !processAlive(pid) {
            return "term"
        }
    }
    if err := syscall.Kill(pid, syscall.SIGKILL); err != nil {
        return "term"
    }
    time.Sleep(300 * time.Millisecond)
    if processAlive(pid) {
        return "still-alive"
    }
    return "kill"
}

// A SIGKILLed but not-yet-reaped child is a zombie; treat it as dead.
func processAlive(pid int) bool {
    b, err := os.ReadFile(fmt.Sprintf("/proc/%d/stat", pid))
    if err != nil {
        return false
    }
    i := strings.LastIndex(string(b), ")")
    if i < 0 || i+2 >= len(b) {
        return false
    }
    return string(b)[i+2] != 'Z'
}

3.2 Shell runbook — foreman_dispatch.sh

This is the exact script that was executed end-to-end against the fix. It resolves the workdir, verifies the provider against config.yaml, writes the query file, runs the pre-dispatch duplicate guard, records the PID, and samples liveness by side effect.

#!/usr/bin/env bash
# foreman_dispatch.sh — hardened single-task dispatch.
# Usage: foreman_dispatch.sh <task-id> [requested-provider]
set -uo pipefail

TASK_ID="${1:?usage: foreman_dispatch.sh <task-id> [provider]}"
REQ_PROVIDER="${2:-zai-glm-default}"

REPO="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
CANONICAL_CANDIDATES=(
  "~/Hermes-DAGger/&lt;project&gt;"   # canonical (real)
  "$REPO/Hermes-DAGger/&lt;project&gt;"
)
CONFIG="${HERMES_CONFIG:-$REPO/config.yaml}"
STATE_DB="${HERMES_STATE_DB:-$REPO/state.db}"
BOARDCTL="${BOARDCTL:-boardctl}"
PI_BIN="${PI_BIN:-pi}"
GRACE_SECS="${TERM_GRACE_SECS:-2}"
PIDFILE="/tmp/foreman-workers/${TASK_ID}.pid"

log() { printf '[foreman %s] %s\n' "$TASK_ID" "$*" >&2; }
die() { log "FATAL: $*"; exit 1; }

# --- F1: canonical workdir (never trust the skill doc) ---------------
WORKDIR=""
for d in "${CANONICAL_CANDIDATES[@]}"; do
  [ -d "$d" ] && { WORKDIR="$(realpath "$d")"; break; }
done
[ -n "$WORKDIR" ] || die "no canonical workdir; checked: ${CANONICAL_CANDIDATES[*]}"
log "canonical workdir: $WORKDIR"

# --- F2: config-verified provider ------------------------------------
allowed="$(sed -n '/allowed:/,/^[^ ]/p' "$CONFIG" | sed -n 's/^[[:space:]]*-[[:space:]]*//p' | tr '\n' ' ')"
default="$(sed -n 's/^[[:space:]]*default:[[:space:]]*//p' "$CONFIG" | head -1)"
[ -n "$default" ] || die "config $CONFIG has no providers.default"
if printf ' %s ' "$allowed" | grep -qF " $REQ_PROVIDER "; then
  PROVIDER="$REQ_PROVIDER"
else
  log "provider '$REQ_PROVIDER' not allowed; using configured default '$default'"
  PROVIDER="$default"
fi
log "provider: $PROVIDER"

# --- F3: robust --query-file form ------------------------------------
QUERY_FILE="$(mktemp "/tmp/query-${TASK_ID}-XXXXXX.txt")"
printf 'TASK %s\nWORKDIR %s\nDo the task; leave a source-file diff.\n' \
  "$TASK_ID" "$WORKDIR" > "$QUERY_FILE"
log "query file: $QUERY_FILE"

# --- F5: pre-dispatch duplicate guard (verify, never trust events) ---
worker_pids() {
  local pid exe cmd cwd
  if [ -f "$PIDFILE" ]; then
    pid="$(cat "$PIDFILE" 2>/dev/null)"
    if [ -n "$pid" ] && kill -0 "$pid" 2>/dev/null; then echo "$pid"; return; fi
  fi
  for pid in $(pgrep -f "worker-${TASK_ID}" 2>/dev/null); do
    [ "$pid" = "$$" ] && continue
    exe="$(readlink -f "/proc/$pid/exe" 2>/dev/null)" || continue
    case "${exe##*/}" in
      bash|sh|dash|pi|hermes|node) ;;
      *) continue ;;                       # excludes sed/grep that quote the task
    esac
    cmd="$(tr '\0' ' ' <"/proc/$pid/cmdline" 2>/dev/null)"
    case "$cmd" in *"worker-${TASK_ID}"*) ;; *) continue ;; esac
    cwd="$(readlink -f "/proc/$pid/cwd" 2>/dev/null)"
    [ -n "$cwd" ] && [ "$cwd" != "$WORKDIR" ] && continue
    echo "$pid"
  done
}
[ -n "$(worker_pids)" ] && log "WARNING: prior event claimed termination but ps disagrees"
for pid in $(worker_pids); do
  log "stale worker pid=$pid; SIGTERM then SIGKILL"
  kill -TERM "$pid" 2>/dev/null || true
  i=0
  while kill -0 "$pid" 2>/dev/null && [ "$i" -lt "$GRACE_SECS" ]; do sleep 0.2; i=$((i+1)); done
  kill -0 "$pid" 2>/dev/null && { log "pid=$pid ignored SIGTERM; SIGKILL"; kill -KILL "$pid" 2>/dev/null || true; }
done

# --- dispatch from the canonical workdir -----------------------------
log "spawning worker from $WORKDIR"
( cd "$WORKDIR" || exit 1
  exec "$PI_BIN" --provider "$PROVIDER" --query-file "$QUERY_FILE" ) \
  >/tmp/worker-"${TASK_ID}".log 2>&1 &
WORKER_PID=$!
mkdir -p "$(dirname "$PIDFILE")"; echo "$WORKER_PID" > "$PIDFILE"
log "worker pid=$WORKER_PID (pidfile $PIDFILE)"

# --- board event records ground truth --------------------------------
"$BOARDCTL" -C "$REPO" event --type task_dispatched --task-id "$TASK_ID" \
  --actor foreman \
  --detail-text "provider=$PROVIDER workdir=$WORKDIR pid=$WORKER_PID query_file=$QUERY_FILE" \
  >/dev/null 2>&1 || log "WARNING: could not append board event"

# --- F4: liveness by side effect (sample; do not block forever) ------
sample() {
  local counts src
  counts="$(sqlite3 "$STATE_DB" \
    "select coalesce(sum(message_count),0)||'/'||coalesce(sum(tool_count),0) \
     from sessions where task_id='$TASK_ID';" 2>/dev/null || echo '0/0')"
  src="$(git -C "$WORKDIR" status --porcelain 2>/dev/null \
    | grep -E '\.(go|py|ts|js|rs|java|c|cpp|h|md|ya?ml|json)$' | head -1)"
  printf '%s|%s' "$counts" "${src:-clean}"
}
BEFORE="$(sample)"; sleep 1; AFTER="$(sample)"
log "side-effect before=$BEFORE after=$AFTER"

4.7 Acceptance checklist for the real repo

  1. test -d ~/Hermes-DAGger/&lt;project&gt; returns success.
  2. A dispatch with --provider zai is logged and substituted to zai-glm-default; no --provider zai reaches the agent.
  3. The worker's /proc/<pid>/cwd equals the canonical workdir; a dispatch against a non-existent path exits non-zero and is not retried silently.
  4. Between two consecutive ticks on the same task, ps shows at most one worker; any survivor is killed by explicit PID (SIGTERM→SIGKILL).
  5. Liveness is decided by state.db session counters + git status; a flat counter and clean worktree is treated as dead even if the PID is alive, and a new source file is treated as alive even if kill -0 raced.
  6. No prior task_dispatched/kill event is trusted without a concurrent ps confirmation (the hedge).
  7. pgrep -f based kills are filtered by /proc/<pid>/exe + /proc/<pid>/cmdline (or a pidfile) so the guard cannot kill itself.

5. Prevention / rollout

  • Replace the hard-coded workdir everywhere with CanonicalWorkdir(...) (fail closed; never silently pick a default).
  • Gate every dispatch on ResolveProvider and log substitutions as a warning.
  • Standardize on --query-file; never pass prompts via argv or stdin.
  • Make side-effect sampling the single source of liveness; keep process checks only as a guardrail that is verified against /proc.
  • Make pre-dispatch termination mandatory (pidfile + explicit PID, TERM then KILL) and record pid/workdir/provider in the event.
  • Add the acceptance checklist to CI/board doctor so a path or provider drift fails the tick instead of silently burning it.
