Fixing boardctl wave-dispatch row-key drift (task_keys_uniform=drift) and the LiveBoard-staleness judge abort

TL;DR

Foreman wave dispatch called boardctl update --worktree P --branch B. Those two singular flags were serialized onto the task rows themselves, so every dispatched row gained two keys (worktree, branch) and the board's task_keys_uniform canary flipped from ok to drift (31-key base rows vs 33-key dispatched rows). The wave manifest already records the same dispatch state, so the per-row copy is redundant.

The fix removes the two keys from only the affected rows, folds their values into the row's existing foreman_note as [wave-dispatch] worktree=… branch=…, and re-serializes each touched row with the exact separators/escaping it already used. Non-target lines and the line count are asserted byte-identical. Re-running smoke_check.py board then prints task_keys_uniform=ok.

The same closeout hit a second, independent failure: the gitreins tier-1 lane runs pytest -x, and the ambient LiveBoard staleness test failed because the live board header (board.jsonl: last_commit / last_tick / ticks_total) was still stale. -x aborted the lane on that unrelated check before the real tests ran. The fix is an ordering fix: land the closeout header bump before the judge re-run, then gitreins judge <id> writes a fresh history dir.

1. Root-cause analysis

1.1 Why the rows grew from 31 to 33 keys

boardctl has two dispatch provenance surfaces:

Flag Where it lands
--worktree PATH / --branch NAME (singular) Row keys worktree, branch on that task
--assoc-worktree PATH / --assoc-branch B (repeatable) Array dimensions worktrees, branches that are part of the canonical schema

Foreman's wave dispatch used the singular pair. On each dispatched row that appends two keys, so the row's key set becomes base ∪ {worktree, branch}. smoke_check.py's task_keys_uniform canary compares the exact key sets of all task rows and reports drift when they differ (31 vs 33-key base sets).

Two important subtleties:

  • boardctl validate's census line reports canonical-name uniformity (N/M rows carry only canon keys). Depending on the build, worktree/branch may themselves be treated as canonical names, so boardctl validate --strict-keys can still report 0 drift while the smoke canary (exact-set comparison) reports drift. Do not rely on validate alone; always run smoke_check.py board.
  • The same mistake exists for any extra provenance key (some builds also stamp a per-row detail object). The repair below folds a configurable key list and defaults to the two keys named in this incident.

1.2 Why the fix belongs in foreman_note, not the row keys

The wave manifest (and the task_dispatched event detail) is the authoritative, append-only record of what was dispatched. Duplicating that state inside the mutable row schema is what breaks uniformity. foreman_note is free text and is not part of the key-set contract, so provenance survives there with zero schema drift. The [wave-dispatch] marker keeps it greppable and reversible.

1.3 Why the judge lane failed (LiveBoard staleness + pytest -x)

gitreins' tier-1 tests lane executes pytest -x. -x stops at the first failure, and one of the first tests is an ambient/global LiveBoard staleness check that does not depend on the task under test. When the closeout header bump had not yet landed, the live board header was stale, that ambient check failed, -x aborted the lane, and the judge never produced a fresh history directory. Re-running the judge without first freshening the header simply reproduces the abort, because the ordering was wrong — not because the task regressed.

2. Exact fix — Part 1: fold the wave keys into foreman_note

2.1 The repair script

Save as fix_wave_row_keys.py (also written to /workspace/fix_wave_row_keys.py). It is deterministic, dry-run by default, atomic, refuses to write on any refusal, and round-trip-validates each row's serialization style before touching it.

#!/usr/bin/env python3
"""
fix_wave_row_keys.py -- fold non-canonical wave-dispatch row keys back into
foreman_note, preserving every row's own JSON separator style.

`boardctl update --worktree P --branch B` writes the singular keys
`worktree`/`branch` onto task rows, breaking exact key-set uniformity
(smoke_check.py: task_keys_uniform=drift).  The wave manifest already records
dispatch state, so fold the values into foreman_note and drop the keys.

Guarantees:
  * only rows carrying a fold key are touched;
  * each touched row is re-serialized with the exact separators/escaping that
    reproduce its ORIGINAL bytes (validated per row); un-reproducible styles
    are refused, never mangled;
  * one atomic pass; refuses to write if any target row is refused;
  * asserts line count unchanged and non-target lines byte-identical.

Usage:
  python3 fix_wave_row_keys.py --board <repo-or-board-dir>            # dry run
  python3 fix_wave_row_keys.py --board <repo-or-board-dir> --apply
"""

from __future__ import annotations

import argparse
import json
import os
import re
import shutil
import sys
from collections import Counter

DEFAULT_FOLD_KEYS = ("worktree", "branch")
DEFAULT_NOTE_LABEL = "wave-dispatch"
_STRING_RE = re.compile(r'"(?:\\.|[^"\\])*"')


def resolve_tasks_path(board: str) -> str:
    for root in (board,
                 os.path.join(board, ".coding-hermes"),
                 os.path.join(board, ".coding-hermes", "board")):
        p = os.path.join(root, "tasks.jsonl")
        if os.path.isfile(p):
            return os.path.realpath(p)
    for dirpath, dirnames, filenames in os.walk(board):
        if "tasks.jsonl" in filenames:
            return os.path.realpath(os.path.join(dirpath, "tasks.jsonl"))
        dirnames[:] = [d for d in dirnames if d not in (".git", "node_modules", ".venv")]
    raise SystemExit(f"fix_wave_row_keys: no tasks.jsonl found under {board!r}")


def detect_separators(line: str):
    struct = _STRING_RE.sub('""', line)
    return (", " if '", "' in struct else ",",
            ": " if '": "' in struct else ":")


def style_for(obj, raw_line: str):
    """Return json.dumps kwargs that reproduce raw_line byte-for-byte, else None."""
    for ensure_ascii in (False, True):
        for item in (",", ", "):
            for kv in (":", ": "):
                out = json.dumps(obj, ensure_ascii=ensure_ascii,
                                 separators=(item, kv), sort_keys=False)
                if out == raw_line:
                    return {"ensure_ascii": ensure_ascii,
                            "separators": (item, kv)}
    return None


def strict_load(raw_line: str):
    def hook(pairs):
        keys = [k for k, _ in pairs]
        if len(keys) != len(set(keys)):
            raise ValueError("duplicate object key")
        return dict(pairs)
    return json.loads(raw_line, object_pairs_hook=hook)


def note_with_provenance(existing, folded, order, label):
    bits = [f"{k}={folded[k]}" for k in order
            if k in folded and folded[k] is not None]
    if not bits:
        return existing if isinstance(existing, str) else (existing or "")
    prov = f"[{label}] " + " ".join(bits)
    if existing is None or existing == "":
        return prov
    return f"{existing}\n{prov}"


def key_uniformity(rows):
    sets = [frozenset(r.keys()) for r in rows]
    if not sets:
        return frozenset(), 0, 0, Counter()
    census = Counter(sets)
    base, base_n = census.most_common(1)[0]
    drift = sum(n for s, n in census.items() if s != base)
    return base, base_n, len(sets), census


def main() -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--board", required=True)
    ap.add_argument("--keys", default=",".join(DEFAULT_FOLD_KEYS))
    ap.add_argument("--note-label", default=DEFAULT_NOTE_LABEL)
    ap.add_argument("--apply", action="store_true")
    ap.add_argument("--no-backup", action="store_true")
    args = ap.parse_args()

    order = tuple(k.strip() for k in args.keys.split(",") if k.strip())
    path = resolve_tasks_path(args.board)
    raw = open(path, "rb").read()
    ends_nl = raw.endswith(b"\n")
    body = raw[:-1] if ends_nl else raw
    lines = body.split(b"\n") if body else []
    text = [ln.decode("utf-8") for ln in lines]

    rows, target, parse_fail = [], [], []
    for i, t in enumerate(text):
        if t.strip() == "":
            target.append(False); continue
        try:
            obj = strict_load(t)
        except Exception as exc:  # noqa: BLE001
            parse_fail.append((i + 1, str(exc))); target.append(False); continue
        rows.append(obj)
        target.append(any(k in obj for k in order))

    if parse_fail:
        print("REFUSING: unparseable row(s); run 'boardctl validate --repair':",
              file=sys.stderr)
        for ln, why in parse_fail:
            print(f"  line {ln}: {why}", file=sys.stderr)
        return 2

    base_set, base_n, total, census = key_uniformity(rows)
    print(f"board: {path}")
    print(f"before: {total} rows, base key set size={len(base_set)}, "
          f"uniform={base_n}/{total} ({total - base_n} drift)")
    for s, n in census.most_common():
        tag = "base" if s == base_set else "drift"
        print(f"  [{tag}] {n} row(s): {len(s)} keys"
              + (f" extra={sorted(s - base_set)}" if s - base_set else "")
              + (f" missing={sorted(base_set - s)}" if base_set - s else ""))

    out, changed, refused = list(lines), [], []
    ri = 0
    for i, t in enumerate(text):
        if t.strip() == "":
            continue
        obj = rows[ri]; ri += 1
        if not target[i]:
            continue
        ln_no = i + 1
        folded = {k: obj[k] for k in order if k in obj}
        style = style_for(obj, t)
        if style is None:
            refused.append((ln_no, "cannot round-trip original bytes with any "
                                   "canonical separator style (item=%r kv=%r)"
                                   % detect_separators(t)))
            continue
        new_obj = dict(obj)
        for k in order:
            new_obj.pop(k, None)
        new_obj["foreman_note"] = note_with_provenance(
            new_obj.get("foreman_note"), folded, order, args.note_label)
        new_line = json.dumps(new_obj, sort_keys=False, **style)
        if set(json.loads(new_line)) != set(obj) - set(order):
            refused.append((ln_no, "post-rewrite key set mismatch")); continue
        out[i] = new_line.encode("utf-8")
        changed.append((ln_no, sorted(folded)))

    if refused:
        print("\nREFUSING (no file written):", file=sys.stderr)
        for ln, why in refused:
            print(f"  line {ln}: {why}", file=sys.stderr)
        return 3

    changed_idx = {ln - 1 for ln, _ in changed}
    assert len(out) == len(lines), "line count changed"
    for i in range(len(lines)):
        if i not in changed_idx:
            assert out[i] == lines[i], f"non-target line {i + 1} mutated"

    print(f"\ntargets: {len(changed)} row(s) folded ({', '.join(order)}) "
          f"-> foreman_note[{args.note_label}]")
    for ln, keys in changed:
        print(f"  line {ln}: folded {keys}")
    if not changed:
        print("no target rows; nothing to do"); return 0
    if not args.apply:
        print("\n(dry run) re-run with --apply to write"); return 0

    if not args.no_backup:
        bak = f"{path}.bak-{os.getpid()}"
        shutil.copy2(path, bak)
        print(f"backup: {bak}")

    new_body = b"\n".join(out) + (b"\n" if ends_nl else b"")
    tmp = f"{path}.tmp-{os.getpid()}"
    with open(tmp, "wb") as fh:
        fh.write(new_body); fh.flush(); os.fsync(fh.fileno())
    os.replace(tmp, path)

    after = [json.loads(x.decode()) for x in
             open(path, "rb").read().rstrip(b"\n").split(b"\n") if x.strip()]
    _, a_base_n, a_total, _ = key_uniformity(after)
    print(f"after:  {a_total} rows, uniform={a_base_n}/{a_total} "
          f"({a_total - a_base_n} drift)")
    return 0 if a_total == a_base_n else 1


if __name__ == "__main__":
    sys.exit(main())

2.3 If a row uses a different extra key

Inspect the census that the dry run prints (extra=[...]) and pass the keys explicitly:

python3 fix_wave_row_keys.py --board . --keys worktree,branch,detail --apply

Do not hand-edit rows with sed/jq in place: that silently rewrites separator style and can mutate untouched rows.

3. Exact fix — Part 2: land the header bump before the judge

The judge abort is an ordering bug, not a test bug. Do the closeout in this order and never re-run the judge while board.jsonl is stale.

BOARD=.coding-hermes/board
HEAD_SHA="$(git rev-parse HEAD)"
TICKS="$(python3 -c "import json;print(json.load(open('$BOARD/board.jsonl'))['ticks_total']+1)")"

# 1. finish every closeout edit first (tasks.jsonl, events, notes, this repair)

# 2. bump the LIVE board header so the ambient staleness test is fresh
boardctl -C . header \
  --set-last-commit "$HEAD_SHA" \
  --set-ticks-total "$TICKS" \
  --set-last-tick "$(date -u +%Y-%m-%dT%H:%M:%SZ)"

# 3. commit the bump (the tracked-set/doctor check reads committed state)
git add -A
git commit -m "board: freshen closeout header"

# 4. only now re-run the judge; it gets a fresh header and writes a new history dir
gitreins judge <id>

boardctl event --tick N <type> also rewrites the header tick (unless --no-tick-write), but the explicit boardctl header bump above is the deterministic closeout hook. The wave-closeout recipe is:

boardctl update … (closeout)
python3 fix_wave_row_keys.py --board . --apply      # Part 1
boardctl header --set-last-commit … --set-ticks-total … --set-last-tick …
git add -A && git commit
smoke_check.py board                                 # canary must be ok
gitreins judge <id>                                  # fresh history dir

  2. --apply reports after: … uniform=N/N (0 drift) and exits 0.

5. Idempotency, rollback, and edge cases

  • Idempotent: a second run finds no rows carrying the fold keys and prints no target rows; nothing to do (exit 0).
  • Rollback: cp tasks.jsonl.bak-<pid> tasks.jsonl (or git checkout --). The script never partially writes: it refuses and leaves the file untouched if any target row cannot be faithfully re-serialized (e.g. trailing whitespace), if the file has unparseable lines, or if a post-rewrite key set does not match. Exit codes: 0 ok/uniform, 1 still drifting, 2 unparseable input, 3 refused target row.
  • Mixed serializer styles are handled per row: compact (","/":") and spaced (", "/": ") rows are each reproduced exactly; key order is preserved via sort_keys=False on the parsed (file-order) dict, and both ASCII-escaped and raw-UTF-8 rows round-trip.
  • Never let wave dispatch write the singular --worktree/--branch row keys again. Prefer the manifest/event record; if a row key is truly needed use the canonical array dimensions (--assoc-worktree / --assoc-branch). Keep task_keys_uniform in the closeout gate so this cannot silently recur.
  • For the judge lane, the durable guard is ordering: the LiveBoard header bump must be part of closeout and committed before any gitreins judge re-run. Running the lane without -x would only mask the problem.
