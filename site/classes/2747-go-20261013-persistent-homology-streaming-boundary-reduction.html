Streaming Persistent-Homology Boundary Reduction over F2

Problem class: go-20261013-persistent-homology-streaming-boundary-reduction Environment: Go 1.26, module phstream

All code lives in ~/phstream; every claim is backed by ph/reducer_test.go and the demo in cmd/phdemo.

1. Root-cause analysis

The difficulty is satisfying four constraints simultaneously. Each has a classic failure mode that only appears on non-trivial inputs.

1.1 The textbook implementation blows up memory

Materialising the full n×n boundary matrix D, reducing to R = D·V, is Θ(n²) bits and Θ(n³) work. The reduction only ever re-reads pivot (negative) columns; positive simplices reduce to the zero column and can be discarded immediately.

1.2 Equal-valued batches need a valid, deterministic total order

If equal-valued simplices are processed in arrival order, an edge can precede one of its vertices. Buffer the batch and sort by (dimension, lexicographic vertex tuple): dimension-ascending guarantees faces precede cofaces; the lex tie-break makes output reproducible.

1.3 Checkpoint/resume must capture derived state

Storing only emitted pairs is insufficient. Resuming exactly needs the complex so far, the sparse reduced columns, and the pending batch. The face map, pivot map, and positive/negative flags are all derivable from those.

1.4 Clearing is a trap — reverse/cohomology order changes the barcode under non-uniform filtration

The folklore rule "if low(R[j]) = i then column i is zero and can be cleared" is true, but two tempting exploitations are wrong: - reduce the coboundary matrix in increasing order and clear the pivot row; - reduce the boundary matrix in decreasing order and clear the pivot row.

Both reproduce the correct barcode when filt = dimension (what small hand tests use), but diverge with non-uniform filtration. Measured over 599 random graded complexes: increasing-coboundary mis-barcoded 488, decreasing-boundary mis-barcoded 301. Reversing the order computes persistence of the reversed filtration, which is a different barcode.

The only clearing that provably preserves the canonical boundary pairing is apparent-pair clearing:

A facet σ of a cofacet τ is an apparent pair (σ, τ) when σ is the youngest facet of τ and τ is the oldest cofacet of σ. Apparent pairs are persistence pairs, so σ's column reduces to zero and can be skipped.

Verified over 499 random graded complexes: 0 pairing mismatches, 1765 positive columns skipped.

1.5 Betti numbers do not certify a diagram

[0,2) and [0,1) ∪ [1,2) have identical β_k at every threshold but are different barcodes. The certificate must check the full rank invariant β_k^{s,t} = dim im(H_k(K_s) → H_k(K_t)) for s ≤ t.

2.2 Sparse columns (ph/column.go)

type column []int32            // sorted, duplicate-free row indices; low = last

func (c column) low() int32 { if len(c) == 0 { return -1 }; return c[len(c)-1] }

func xorColumn(a, b column) column { // symmetric difference, stays sorted
    out := make(column, 0, len(a)+len(b))
    i, j := 0, 0
    for i < len(a) && j < len(b) {
        switch {
        case a[i] < b[j]: out = append(out, a[i]); i++
        case a[i] > b[j]: out = append(out, b[j]); j++
        default:          i++; j++
        }
    }
    return append(append(out, a[i:]...), b[j:]...)
}

2.3 Streaming reducer with batching (ph/reducer.go)

func (r *Reducer) Add(verts []int32, filt int64) error {
    v, err := normalizeVerts(verts)              // copy + sort + reject repeats
    if err != nil { return err }
    if r.hasLast && filt < r.lastFilt { return fmt.Errorf("non-monotone filtration") }
    if r.hasLast && filt > r.lastFilt {          // batch boundary -> flush
        if err := r.flushBatch(); err != nil { return err }
    }
    r.hasLast, r.lastFilt = true, filt
    r.pending = append(r.pending, Simplex{Verts: v, Filt: filt})
    return nil
}

func (r *Reducer) flushBatch() error {
    batch := r.pending; r.pending = nil
    sort.SliceStable(batch, func(i, j int) bool {   // valid + deterministic order
        if batch[i].Dim() != batch[j].Dim() { return batch[i].Dim() < batch[j].Dim() }
        return lessVerts(batch[i].Verts, batch[j].Verts)
    })
    for _, s := range batch { if err := r.processSimplex(s); err != nil { return err } }
    return nil
}

The reduction keeps only pivot columns, with a zero-persistence fast path:

    for len(col) > 0 {                            // col = sparse boundary, sorted
        i := col.low()
        c, ok := r.pivot[i]
        if !ok { break }
        if pc := r.columns[c]; len(pc) == 1 {     // XOR with {i} == drop i
            col = col[:len(col)-1]
        } else {
            col = xorColumn(col, pc)
        }
    }
    // empty  -> positive, zero column discarded
    // non-empty -> negative: pivot[low]=idx; columns[idx]=col; record pair (low, idx)

Finalize flushes and emits finite pairs plus every positive simplex never used as a pivot row (essential bars).

for k := 0; k <= cx.maxDim; k++ {

It uses β_k^{s,t} = dim(Z_s + B_t) − dim(B_t), building Z_s = ker ∂_k|K_s and B_t = im ∂_{k+1}|K_t with dense F2 bitsets. It never touches reducer state, and the reducer never materialises the full matrix.

4.3 Memory-boundedness evidence

TestSparseMemoryBound reduces a 400-vertex path (799 simplices) and asserts StoredEntries ≤ 4n. The full matrix would be 799² ≈ 638k entries; the reducer stores 798 entries in 399 pivot columns.

5. Summary of exact fixes

  1. Sparse pivot columns only; discard positive zero columns — bounded memory.
  2. Batch buffer + (dim, lex) tie-break — deterministic, valid face-before-coface order.
  3. Checkpoint complex + reduced columns + pending batch; derive face/pivot maps on resume.
  4. Clear with apparent pairs, never reverse/cohomology order — the latter silently changes the barcode under non-uniform filtration.
  5. Certify with the full rank invariant (s ≤ t), not just Betti numbers (s = t).
