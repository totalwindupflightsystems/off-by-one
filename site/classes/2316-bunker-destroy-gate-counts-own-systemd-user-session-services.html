Answer 1

Done. I diagnosed the failure against the upstream deployBunker/bunker tree (the working dir was empty; I cloned the repo, which is at the exact INT-CI-041 commit 1ce40fd), implemented and verified the fix, and wrote the deliverables.

Root cause

AgentManager.Destroy calls gateDestroyOnLiveProcesses (internal/agent/manager_destroy.go) before userdel -rf. The classifier isAgentSessionProcess (internal/agent/orphan_uid.go) only absorbed systemd --user, (sd-pam), and systemd-executor --deserialize. Under runner contention the agent's own session transient systemctl --user unset-environment SSH_AUTH_SOCK (pid 867701, uid 1008) was classified foreign, so the gate returned StatusLiveProcesses before Step 4, leaving /run/bunker/conctest-4-15075 behind → TestConcurrency_SpawnFiveAgents failed. This is the DF-BUNKER-66(a) class (mind the dbus/pipewire services too), and it's root-gated so it can't reproduce non-root.

Fix delivered

  • Product (a): extended isAgentSessionProcess to absorb the transient systemctl --user environment verbs (unset/set/import/show-environment) with argv validation, plus the session's own bus/media services (dbus-daemon, dbus-broker, pipewire*, wireplumber, mpris-proxy) by argv[0] basename. Operator processes and unrelated systemctl --user status stay foreign; the orphan-uid report still uses all processes.
  • Test (b): cleanupAgent now retries Destroy once on the named StatusLiveProcesses refusal.
  • Regression tests: new internal/agent/intci041_test.go with classifier table, gate absorption test, and operator-still-refused safety control.
  • CI (c): documented as optional.

Verification

  • RED proof: pre-fix classifier returns false on the verbatim CI fingerprint (11 failing cases).
  • GREEN: targeted tests pass (ok ... 0.862s).
  • Full internal/agent failing-test set is byte-identical clean vs patched (17/17 environmental pre-existing failures), so zero new failures.
  • gofmt, go vet ./..., go build ./... all clean.
  • Patch matches the working tree (git apply --check --reverse).
