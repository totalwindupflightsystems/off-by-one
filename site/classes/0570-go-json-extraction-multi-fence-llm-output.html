Layer 1 — multi-fence extraction (extract.go)

func ExtractPlanJSON(raw string) (json.RawMessage, error) {
    var firstValid json.RawMessage
    validSeen := false

    for _, f := range ScanFences(raw) {          // <-- ALL fences, not just the first
        content := strings.TrimSpace(f.Content)
        if !looksLikeJSON(content) || !json.Valid([]byte(content)) {
            continue
        }
        if !validSeen {
            firstValid = cloneJSON([]byte(content))
            validSeen = true
        }
        if JSONLooksLikePlan([]byte(content)) {   // <-- prefer first plan-shaped block
            return cloneJSON([]byte(content)), nil
        }
    }
    if validSeen {
        return firstValid, nil                   // legacy fallback: first valid JSON fence
    }
    if embedded := extractEmbeddedJSON(raw); embedded != nil {
        return embedded, nil                     // last resort: JSON in prose
    }
    return nil, ErrNoJSONFound
}
  • ScanFences walks line-by-line, handles ``` and ~~~ fences, any language tag, blank lines and CRLF.
  • JSONLooksLikePlan unmarshals and checks top-level object keys case-insensitively against {orders, order, plan, steps, actions, tasks, items, ...}; arrays/scalars are never plan-shaped. So an earlier {"analysis":..., "reasoning":...} fence is skipped in favor of the later {"orders":[...], "plan":...} block.
  • extractEmbeddedJSON uses string/escape-aware bracket matching so } inside string literals can't truncate the payload.

Layer 2 — OpenRouter retry semantics (client.go)

func (c *OpenRouterClient) Complete(ctx context.Context, messages []Message) (string, error) {
    for attempt := 0; ; attempt++ {
        content, empty, err := c.doOnce(ctx, messages)
        if err != nil {
            return "", err                      // API/network errors: NEVER retried
        }
        if !empty {
            return content, nil
        }
        if attempt >= c.maxEmptyRetries() {     // default MaxEmptyRetries = 1
            return "", ErrEmptyResponse
        }
    }
}

doOnce classifies: 200 + empty body (or {"choices":[]} / empty choice content) → retryable transient; non-200 status or error payload → *APIError (no retry); transport failure (dropped connection, DNS, etc.) → wrapped network error (no retry). CompletePlan composes both layers end-to-end.
