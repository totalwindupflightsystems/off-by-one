Flash-Attention Backward with Online-Softmax Rescaling — Diagnosis & Fix

Problem class: python3-flash-attention-backward-online-softmax-rescaling-gradient-drift

Symptom: gradcheck at atol=1e-3 fails when the forward stores only the running max m_t and rescale factors α_t instead of the full-row maximum / final log-sum-exp. dV often looks fine while dQ/dK are badly wrong; low-precision recomputation fails even when the algebra is right.

1. Root-cause analysis

Per query row, p_j = exp(s_j − LSE), LSE = log Σ_j exp(s_j), o = Σ_j p_j v_j. The streaming forward never materializes LSE; for key block t it saves m_t and α_t = exp(m_{t−1} − m_t) and accumulates l_t = α_t l_{t−1} + Σ_j exp(s_tj − m_t), so exactly

LSE = m_T + log l_T = m_T + log( Σ_t (Π_{u>t} α_u) Σ_j exp(s_tj − m_t) ).

Three bugs get conflated:

A — per-block renormalization (structural). A naive backward treats P_t = exp(s_t − m_t) as the softmax of block t. It is not normalized — block t's true probabilities are P_t·exp(m_t − LSE), and each block is off by a different global factor. The softmax correction D = Σ_j p_j dP_j = dO·o is a global row sum, not per-block. Result: dQ, dK wrong by O(1), while dV (which never uses D) can look correct.

B — reduced-precision LSE reconstruction. Recomputing LSE in fp16, or from fp16-saved stats, introduces absolute error δ ≈ eps_fp16·|s|. Since P = exp(s − LSE), every probability is multiplied by e^{−δ}. For scores in the tens, δ ≈ 1e-2 → percent-level gradient error, well above 1e-3. The backward must reuse the normalization the forward actually produced.

C — empty key block / all-masked row (m = −inf). Then l_T = 0, LSE = −inf, and exp(s − LSE) → NaN. Unguarded, NaNs contaminate the tile. The gradient of a zero output w.r.t. inputs is 0, so such rows must be skipped.

2. Corrected rescaling formula

Reconstruct LSE once in fp32/fp64 from the saved running stats, then use it for all blocks:

LSE = m_T + log(l_T)                    # l_T already carries the α-chain

or replay exactly: l = 0; for t: l = l·α_t + Σ_j exp(s_tj − m_t); LSE = m_T + log l.

Given dO:

P   = exp(s − LSE)                  # normalized, per key block
dP  = dO · Vᵀ
D   = Σ_all_j P_j dP_j = dO · o     # GLOBAL row sum (softmax correction)
dS  = P · (dP − D)
dV  = Pᵀ dO
dQ  = scale · (dS K)                # accumulated over blocks
dK  = scale · (dSᵀ Q)

This is identical to backpropagating the α chain: the α's only shift the reference max, and their net effect is the global exp(m_t − LSE) factor plus the global D = dO·o correction.

3. Exact fix (drop-in)

Forward saves (m_t, α_t):

rowmax = s.max(axis=1)
m_new  = np.maximum(m, rowmax)
alpha  = np.exp(m - m_new)
alpha  = np.where(np.isnan(alpha), 1.0, alpha)   # m==m_new==-inf case
p      = np.exp(s - m_new[:, None])
l      = l * alpha + p.sum(axis=1)
acc    = acc * alpha[:, None] + p @ V[sl]

Corrected backward:

def online_softmax_backward(Q, K, V, dO, ctx, mask=None):
    Q = Q.astype(np.float64); K = K.astype(np.float64)
    V = V.astype(np.float64); dO = dO.astype(np.float64)
    Nq, d = Q.shape
    scale = ctx["scale"]
    M, L = ctx["M_final"].astype(np.float64), ctx["L_final"].astype(np.float64)

    LSE = np.full(Nq, -np.inf)
    ok = L > 0
    LSE[ok] = M[ok] + np.log(L[ok])              # exact global LSE

    dQ = np.zeros((Nq, d)); dK = np.zeros_like(K); dV = np.zeros_like(V)
    rows = np.isfinite(LSE)                      # EDGE CASE: skip l==0 / m==-inf
    if not rows.any():
        return dQ, dK, dV
    Qr, dOr, LSEr = Q[rows], dO[rows], LSE[rows]

    blocks, D = [], np.zeros(len(Qr))
    for (m_new, alpha, start, stop) in ctx["saved"]:
        sl = slice(start, stop)
        if stop <= start:                        # EDGE CASE: empty block
            continue
        s = scale * (Qr @ K[sl].T)
        if mask is not None:
            s = np.where(mask[rows][:, sl], s, -np.inf)
        P = np.zeros_like(s); good = np.isfinite(s)
        mb = np.broadcast_to(LSEr[:, None], s.shape)
        P[good] = np.exp(s[good] - mb[good])
        dP = dOr @ V[sl].T
        D += np.sum(P * dP, axis=1)              # accumulate GLOBALLY
        blocks.append((sl, P, dP))

    for sl, P, dP in blocks:
        dS = P * (dP - D[:, None])
        dQ[rows] += scale * (dS @ K[sl])
        dK[sl]   += scale * (dS.T @ Qr)
        dV[sl]   += P.T @ dOr
    return dQ, dK, dV

Chain replay if only (m_t, α_t) was saved:

def lse_from_chain(Q, K, mask, ctx):
    l = np.zeros(Q.shape[0], np.float64)
    for (m_new, alpha, start, stop) in ctx["saved"]:
        if stop <= start: continue
        s = ctx["scale"] * (Q.astype(np.float64) @ K[start:stop].astype(np.float64).T)
        if mask is not None:
            s = np.where(mask[:, start:stop], s, -np.inf)
        p = np.zeros_like(s); good = np.isfinite(s)
        p[good] = np.exp(s[good] - np.broadcast_to(m_new[:,None], s.shape)[good])
        l = l * alpha + p.sum(axis=1)
    LSE = np.full(Q.shape[0], -np.inf); ok = l > 0
    LSE[ok] = ctx["M_final"][ok] + np.log(l[ok])
    return LSE

Never recompute the max/sum in fp16; upcast and use one global LSE per row.

5. Checklist for the GPU/torch version

  1. Save m_T/l_T (or per-block (m_t, α_t)) in fp32.
  2. Reconstruct LSE = m_T + log l_T in fp32; never in fp16/bf16.
  3. Compute P = exp(s − LSE) and accumulate D = dO·o globally.
  4. dS = P·(dP − D); accumulate dQ/dK/dV in fp32 accumulators.
  5. Guard l==0/m==−inf rows and zero-size / fully-masked blocks.
  6. torch.autograd.gradcheck(..., atol=1e-3, rtol=1e-3) on multi-block, masked, and empty-row cases.
