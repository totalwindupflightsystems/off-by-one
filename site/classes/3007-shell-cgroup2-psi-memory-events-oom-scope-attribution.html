Done. The solution is written to ~/SOLUTION.md, with the tested script at ~/cgroup_oom_audit.sh and fixture harness at ~/test_cgroup_audit.sh.

Root cause

  • memory.events.oom_kill is hierarchical (events(N) = local(N) + Σ events(children)), while memory.events.local.oom_kill is self-only. Summing memory.events double-counts; summing leaf locals drops kills charged to internal cgroups. Those internal-node locals are the unattributed kills.
  • The exact identity top = Σ leaf local + Σ internal local must hold, so unattributed reconciles rather than double counts.
  • Nonzero PSI full avg10/avg60 is only attributable to a scope if the scope was active during that window → compare against ActiveEnterTimestamp and /proc/<pid>/stat field 22 (via btime/CLK_TCK).
  • KillMode=process double-fork escapes: resolve each candidate PID via /proc/<pid>/cgroup and check containment under the unit's ControlGroup.

Exact fix

cgroup_oom_audit.sh walks every cgroup under a slice, emits deterministic jq -S JSON sorted by path with per-entry {path, oom_kills_local, oom_kills_inherited, unattributed, pressure_full_avg10, pressure_full_avg60, pressure_window_ok, escaped_pids[]} and a totals object. Exit codes: 0 completed (even with findings), 1 hierarchy unreadable, 2 usage. Test hooks CGROUP_ROOT/PROC_ROOT/SYSTEMCTL allow fixture testing.

Verification (all passing)

Against a synthetic hierarchy (top=13, leaf_sum=10, unattributed=3, escaped [2222], PSI mismatch on leaf-b.scope):

  • reconciled == true, top == leaf_sum + unattributed, top == local_sum
  • per-entry unattributed sums to 3; entries sorted; output byte-deterministic across runs
  • findings exit 0; missing slice exits 0; unreadable hierarchy / missing cgroup.controllers exits 1; bash -n clean
  • the script embedded in SOLUTION.md is byte-identical to the tested file (diff clean) and reproduces the same result
