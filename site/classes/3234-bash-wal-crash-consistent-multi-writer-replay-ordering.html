Crash-Consistent Multi-Writer WAL in Bash

Root-cause analysis

A WAL that is merely >>-appended by concurrent processes has several failure modes under SIGKILL:

  1. A killed writer can leave a partial record at EOF. If replay only looks for complete records, it must decide what to do with the fragment. If the next writer simply appends after the fragment, a fully-synced later record becomes unreachable behind an unparseable line. Replay then either loses that later record or keeps a non-prefix of the log.
  2. A newline is not automatically a commit marker. If the record is written in an order where the newline can precede the payload or checksum, a torn record can look complete. The commit marker must be the last byte written.
  3. flock alone is not enough. The lock prevents interleaving, but a killed writer releases the lock while leaving a torn tail. The next writer must repair that tail before appending anything.
  4. Replay must not race appends. Reading or truncating without the exclusive lock can cut a record that another process is still writing.
  5. Durability order matters. The record bytes must be written, the WAL file descriptor fsynced, and only then may the lock be released. For a newly created WAL, the parent directory entry must be fsynced before relying on the file. sync on the whole filesystem is not a precise replacement for fsync(fd).
  6. Torn-record detection needs a checksum plus a length. A missing newline detects the common torn-write case; the length and POSIX cksum CRC detect a complete-looking line whose contents are corrupt.

The fix is to make the WAL a sequence of self-delimiting, checksummed records whose final newline is written last, to repair the tail before every append and replay, and to hold an exclusive flock across repair + append + fsync.

Exact fix

Record format and invariants

Each record is one line:

SET <key> <value> <payload-length> <cksum-crc>\n

The payload is exactly SET <key> <value>. Keys and values use [A-Za-z0-9_.:/@%+-]+, so there are no embedded spaces or newlines. The newline is the commit marker and is written last.

Invariants:

  • Only one process can mutate the WAL at a time (flock -x on the WAL inode).
  • Immediately after taking the lock, a writer repairs any torn tail.
  • A writer never appends after a torn record.
  • A complete record is written before its newline; after the newline the WAL fd is fsynced before the lock is released.
  • Replay takes the same exclusive lock, repairs, reduces the valid prefix, and truncates anything after that prefix.

wal.sh

Save as wal.sh and chmod +x wal.sh.

#!/usr/bin/env bash
# wal.sh - crash-consistent append-only WAL for bash.
#
# WAL record (one line, newline is the commit marker):
#     SET <key> <value> <payload-length> <cksum-crc>
#
# All mutations/reads take an exclusive flock on the WAL inode.  A writer
# repairs a torn tail *before* appending, then writes the record with the
# newline last and fsyncs the WAL fd before releasing the lock.  Replay also
# repairs, then reduces the valid prefix with last-write-wins semantics.

set -u -o pipefail
export LC_ALL=C

: "${WAL:=${WAL_DIR:-.}/wal.log}"
WAL_DIR=$(dirname -- "$WAL")

log() { printf '%s\n' "$*" >&2; }
die() { log "wal: $*"; exit 1; }

# ---- fsync helpers -------------------------------------------------------
# GNU sync(1) might perform syncfs(), not fsync(file).  Prefer an exact
# fsync(2) through Python; keep a functional fallback for minimal systems.
have_python() { command -v python3 >/dev/null 2>&1; }

fsync_fd() {
    local fd=$1
    if have_python; then
        python3 -c 'import os,sys; os.fsync(int(sys.argv[1]))' "$fd"
    else
        # No direct bash fsync.  sync -- FILE is weaker/stronger depending on
        # implementation, but the SIGKILL-correctness argument only requires
        # ordered writes, not power-loss durability.
        sync -- "$WAL" 2>/dev/null || sync
    fi
}

fsync_path() {
    local p=$1
    if have_python; then
        python3 - "$p" <<'PY'
import os, sys
p = sys.argv[1]
flags = os.O_RDONLY
try:
    if os.path.isdir(p):
        flags |= os.O_DIRECTORY
    fd = os.open(p, flags)
except OSError:
    raise SystemExit(1)
try:
    os.fsync(fd)
finally:
    os.close(fd)
PY
    else
        sync -- "$p" 2>/dev/null || sync
    fi
}

truncate_fd() {
    local fd=$1 size=$2
    if have_python; then
        python3 -c 'import os,sys; os.ftruncate(int(sys.argv[1]), int(sys.argv[2]))' "$fd" "$size"
    else
        truncate -s "$size" -- "$WAL"
    fi
    fsync_fd "$fd"
}

# ---- record parsing / construction --------------------------------------
# Restricted, whitespace-free alphabet makes the line framing and the awk
# reference reducer unambiguous.
valid_token() { [[ $1 =~ ^[A-Za-z0-9_.:/@%+-]+$ ]]; }

make_record() {
    local key=$1 val=$2 payload len crc csz
    payload="SET $key $val"
    len=${#payload}
    read -r crc csz <<<"$(printf %s "$payload" | cksum)" || return 1
    [[ $csz == "$len" ]] || return 1
    WAL_RECORD="$payload $len $crc"
}

# Parse one complete line.  Sets REC_KEY/REC_VAL only on success.
parse_record() {
    local line=$1 key val len crc payload out ccrc csz
    [[ $line =~ ^SET[[:space:]]+([A-Za-z0-9_.:/@%+-]+)[[:space:]]+([A-Za-z0-9_.:/@%+-]+)[[:space:]]+([0-9]+)[[:space:]]+([0-9]+)$ ]] || return 1
    key=${BASH_REMATCH[1]}
    val=${BASH_REMATCH[2]}
    len=${BASH_REMATCH[3]}
    crc=${BASH_REMATCH[4]}
    payload="SET $key $val"
    [[ ${#payload} == "$len" ]] || return 1
    out=$(printf %s "$payload" | cksum) || return 1
    read -r ccrc csz <<<"$out"
    [[ $ccrc == "$crc" && $csz == "$len" ]] || return 1
    REC_KEY=$key
    REC_VAL=$val
}

# Byte offset immediately after the last newline in FILE.  If the file ends
# without a newline, this is the offset before the final partial record.
complete_prefix_size() {
    local file=$1 size=$2
    awk -v sz="$size" '
        { total += length($0) + 1 }
        END {
            if (total <= sz) print total
            else             print total - length($0) - 1
        }
    ' < "$file"
}

# Full scan: truncate at the first non-newline-terminated or invalid record.
full_repair() {
    local file=$1 fd=$2 off=0 line bad=0
    while IFS= read -r line; do
        if parse_record "$line"; then
            (( off += ${#line} + 1 ))
        else
            bad=1
            break
        fi
    done < "$file"
    # bad=1: an invalid complete line (including an empty one).
    # non-empty line with bad=0: EOF without a newline (torn tail).
    if (( bad )) || [[ -n $line ]]; then
        truncate_fd "$fd" "$off"
    fi
}

# Repair only the tail.  Fast path: the file ends in '\n' and its last
# complete record validates.  Otherwise remove the partial fragment, then
# validate/recover the preceding record.
repair_tail() {
    local file=$1 fd=$2 size off last
    size=$(stat -c %s -- "$file") || return 1
    (( size == 0 )) && return 0

    # Command substitution removes a final newline, so an empty result means
    # the last byte is '\n' (our records never contain embedded newlines).
    if [[ -z "$(tail -c 1 -- "$file")" ]]; then
        last=$(tail -n 1 -- "$file") || return 1
        if parse_record "$last"; then
            return 0
        fi
        full_repair "$file" "$fd"
        return
    fi

    off=$(complete_prefix_size "$file" "$size") || return 1
    if (( off < size )); then
        truncate_fd "$fd" "$off"
    fi
    (( off == 0 )) && return 0
    last=$(tail -n 1 -- "$file") || return 1
    if parse_record "$last"; then
        return 0
    fi
    full_repair "$file" "$fd"
}

# ---- public operations ---------------------------------------------------
append() {
    local key=$1 val=$2 fd rec
    valid_token "$key" || die "invalid key: $key"
    valid_token "$val" || die "invalid value: $val"
    make_record "$key" "$val" || die "cannot checksum record"

    umask 022
    mkdir -p -- "$WAL_DIR" || die "mkdir $WAL_DIR"
    exec {fd}>>"$WAL" || die "open $WAL"

    flock -x "$fd" || { exec {fd}>&-; die "flock $WAL"; }

    # Once per process: make the directory entry durable before the first
    # record that may refer to it.  (dfd ordering.)
    if [[ ${WAL_DIR_SYNCED:-0} != 1 ]]; then
        fsync_path "$WAL_DIR" || { flock -u "$fd"; exec {fd}>&-; die "fsync dir"; }
        WAL_DIR_SYNCED=1
    fi

    repair_tail "$WAL" "$fd" || { flock -u "$fd"; exec {fd}>&-; die "repair tail"; }

    rec=$WAL_RECORD
    # Newline is written last: a kill at any earlier byte leaves a record
    # that replay cannot mistake for committed.
    printf '%s' "$rec" >&"$fd" || { flock -u "$fd"; exec {fd}>&-; die "write"; }
    if [[ -n ${WAL_TORTURE_PAUSE:-} ]]; then
        # Test hook: widen the window between the record prefix and its
        # newline.  Close the inherited lock fd in the sleeper so that a
        # SIGKILL of this writer releases the flock immediately even if the
        # sleeper is orphaned.
        ( eval "exec ${fd}>&-"; sleep "$WAL_TORTURE_PAUSE" )
    fi
    printf '\n' >&"$fd" || { flock -u "$fd"; exec {fd}>&-; die "write newline"; }

    fsync_fd "$fd" || { flock -u "$fd"; exec {fd}>&-; die "fsync"; }
    flock -u "$fd"
    exec {fd}>&-
}

replay() {
    local out=${1:-} fd line off=0 size k
    declare -A state=()

    mkdir -p -- "$WAL_DIR" || die "mkdir $WAL_DIR"
    exec {fd}>>"$WAL" || die "open $WAL"
    flock -x "$fd" || { exec {fd}>&-; die "flock $WAL"; }

    repair_tail "$WAL" "$fd" || { flock -u "$fd"; exec {fd}>&-; die "repair tail"; }

    while IFS= read -r line; do
        if parse_record "$line"; then
            state[$REC_KEY]=$REC_VAL
            (( off += ${#line} + 1 ))
        else
            break
        fi
    done < "$WAL"

    # Defense in depth: if anything after the valid prefix remains, cut it.
    size=$(stat -c %s -- "$WAL")
    if (( size > off )); then
        truncate_fd "$fd" "$off"
    fi

    flock -u "$fd"
    exec {fd}>&-

    if [[ -n $out ]]; then
        {
            for k in "${!state[@]}"; do
                printf '%s %s\n' "$k" "${state[$k]}"
            done
        } | sort -k1,1 > "$out"
    else
        for k in "${!state[@]}"; do
            printf '%s %s\n' "$k" "${state[$k]}"
        done | sort -k1,1
    fi
}

writer_loop() {
    local id=$1 seq=0 key val ack
    ack="$WAL_DIR/acks.$id"
    : > "$ack"
    while :; do
        key="w${id}_${seq}"
        val="v${seq}"
        append "$key" "$val" || exit 1
        # Ack after fsync: an ack therefore implies a fully-synced record.
        printf '%s %s\n' "$key" "$val" >> "$ack"
        seq=$((seq + 1))
        [[ -n ${WAL_WRITER_SLEEP:-} ]] && sleep "$WAL_WRITER_SLEEP"
    done
}

usage() {
    cat >&2 <<EOF
usage: $0 append KEY VALUE
       $0 replay [OUTFILE]
       $0 writer ID
       $0 repair
EOF
    exit 2
}

cmd=${1:-}
case $cmd in
    append) shift; (( $# == 2 )) || usage; append "$1" "$2" ;;
    replay) shift; replay "${1:-}" ;;
    writer) shift; (( $# == 1 )) || usage; writer_loop "$1" ;;
    repair)
        mkdir -p -- "$WAL_DIR"
        exec {fd}>>"$WAL"
        flock -x "$fd"
        repair_tail "$WAL" "$fd"
        flock -u "$fd"
        exec {fd}>&-
        ;;
    *) usage ;;
esac

Basic use:

export WAL=/var/tmp/myapp/wal.log
./wal.sh append account:1 100

Torture harness (wal_torture.sh)

The harness starts several writers, repeatedly SIGKILLs and respawns them, then verifies the repaired WAL. Each writer writes an ack after append returns (and therefore after the fsync), so every ack is a record that must not be lost.

#!/usr/bin/env bash
# wal_torture.sh - SIGKILL torture + deterministic torn-tail tests.
set -u -o pipefail
export LC_ALL=C

HERE=$(cd -- "$(dirname -- "$0")" && pwd)
WAL_SH=${WAL_SH:-$HERE/wal.sh}
TMP=$(mktemp -d "${TMPDIR:-/tmp}/wal-torture.XXXXXX")
cleanup() { [[ ${KEEP_TMP:-0} == 1 ]] || rm -rf -- "$TMP"; }
trap cleanup EXIT

export WAL=$TMP/wal.log
N=${N:-6}
DURATION=${DURATION:-2}
export WAL_TORTURE_PAUSE=${WAL_TORTURE_PAUSE:-0.01}

fail() { printf 'FAIL: %s\n' "$*" >&2; exit 1; }
pass() { printf 'ok: %s\n' "$*"; }

# ---------------------------------------------------------------- torture
declare -a pid slot_id
next_id=0
start_writer() {
    local slot=$1
    next_id=$((next_id + 1))
    slot_id[$slot]=$next_id
    "$WAL_SH" writer "$next_id" &
    pid[$slot]=$!
}

for ((s=0; s<N; s++)); do start_writer "$s"; done

end=$((SECONDS + DURATION))
while (( SECONDS < end )); do
    sleep 0.05
    s=$((RANDOM % N))
    p=${pid[$s]}
    if kill -0 "$p" 2>/dev/null; then
        kill -9 "$p" 2>/dev/null || true
        wait "$p" 2>/dev/null || true
    fi
    start_writer "$s"
done
for ((s=0; s<N; s++)); do
    kill -9 "${pid[$s]}" 2>/dev/null || true
    wait "${pid[$s]}" 2>/dev/null || true
done

# Replay (this also repairs any torn tail), then compare to an independent
# awk last-write-wins reducer over the repaired WAL.
"$WAL_SH" replay "$TMP/state" || fail "replay exited nonzero"
awk '$1 == "SET" { state[$2] = $3 }
     END { for (k in state) print k, state[k] }' "$WAL" | sort -k1,1 > "$TMP/ref"
diff -u "$TMP/ref" "$TMP/state" || fail "replay != reference reducer"
pass "replay matches awk reducer ($(wc -l < "$TMP/state") keys)"

# Every acknowledged record must still be in the replayed state.  Acks are
# written only after the corresponding append's fsync returned.
acked=0
for ack in "$TMP"/acks.*; do
    [[ -e $ack ]] || continue
    while IFS=' ' read -r k v extra; do
        [[ -n ${k:-} && -n ${v:-} && -z ${extra:-} ]] || continue
        grep -Fqx -- "$k $v" "$TMP/state" || fail "acked record lost: $k $v"
        acked=$((acked + 1))
    done < "$ack"
done
pass "all $acked acknowledged records survived"

# Replay must leave a clean newline-terminated WAL (or an empty file).
if [[ -s $WAL ]]; then
    [[ -z "$(tail -c 1 -- "$WAL")" ]] || fail "WAL tail is not newline-terminated"
fi
"$WAL_SH" replay "$TMP/state2" || fail "second replay"
diff -u "$TMP/state" "$TMP/state2" || fail "replay is not idempotent"
pass "replay is idempotent and WAL tail is clean"

# ------------------------------------------- deterministic torn-tail test
export WAL=$TMP/torn.log
"$WAL_SH" append keep1 v1 || fail "seed append"
base=$(stat -c %s -- "$WAL")
export WAL_TORTURE_PAUSE=10
"$WAL_SH" writer 999 &
p=$!
for _ in {1..200}; do
    if [[ -s $WAL ]] && (( $(stat -c %s -- "$WAL") > base )); then
        # Prefix is on disk but the newline has not been written yet.
        [[ -n "$(tail -c 1 -- "$WAL")" ]] && break
    fi
    sleep 0.01
done
kill -9 "$p" 2>/dev/null || true
wait "$p" 2>/dev/null || true
[[ $(stat -c %s -- "$WAL") -gt $base ]] || fail "could not catch writer mid-append"
[[ -n "$(tail -c 1 -- "$WAL")" ]] || fail "expected a non-newline-terminated torn tail"
pass "killed writer left a torn non-newline-terminated tail"

unset WAL_TORTURE_PAUSE
"$WAL_SH" append keep2 v2 || fail "append after torn tail"
"$WAL_SH" replay "$TMP/torn.state" || fail "replay after torn tail"
grep -Fqx -- 'keep1 v1' "$TMP/torn.state" || fail "lost record before torn tail"
grep -Fqx -- 'keep2 v2' "$TMP/torn.state" || fail "lost record appended after torn tail"
grep -Fqx -- 'w999_0 v0' "$TMP/torn.state" && fail "torn record was accepted"
pass "repair-before-append preserved both good records and discarded the torn one"

printf 'ALL TESTS PASSED (tmp=%s)\n' "$TMP"

The harness proves four separate properties:

  1. Replay equals an independent reducer. After replay repairs/truncates the WAL, awk '$1=="SET" {v[$2]=$3} END {for (k in v) print k, v[k]}' produces exactly the same sorted key-state file.
  2. Acked records are never lost. An ack is written only after append returned, i.e. after the WAL fd was fsynced. Every ack must still appear in replayed state.
  3. Replay is idempotent and leaves no torn tail. A second replay produces the same state, and the WAL either is empty or ends in \n.
  4. The dangerous middle-torn case is covered. A writer is deliberately killed after writing the record prefix but before its newline. The next append must first remove that fragment; both the record before it and the record after it must survive, while the torn record must not be accepted.

Additional manual checks:

# Deterministic torn trailing fragment: replay keeps the valid prefix.
export WAL=/tmp/wal-demo/wal.log
./wal.sh append a 1
./wal.sh append b 2
printf 'SET c 3 9 999' >> "$WAL"       # no newline, bad CRC
./wal.sh replay                         # prints: a 1 / b 2
test -z "$(tail -c 1 -- "$WAL")"        # replay truncated the fragment

# Corruption with a newline: writer repairs before appending.
printf 'SET bad 4 9 123\n' >> "$WAL"
./wal.sh append d 4
./wal.sh replay                         # prints: a 1 / b 2 / d 4
