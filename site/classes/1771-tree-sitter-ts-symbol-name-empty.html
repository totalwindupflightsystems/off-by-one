Summary

Root cause: not missing node kinds — name derivation. The extractor took the last whitespace token of a declaration's first source line and trimmed {/(. For TS/JS that token is {, }, (, or void;, while the identifier is in the middle (function bootstrap(): void {). Rust/Go escaped because they parse fn foo / func foo keyword-prefixed forms.

Fix (hilo-graph/src/signal.rs): - Replace line-scanning with node.child_by_field_name("name") for function_declaration, generator_function_declaration, class_declaration, abstract_class_declaration, method_definition, interface_declaration, type_alias_declaration, enum_declaration. - For lexical_declaration / variable_declaration, use the declarator's name only when its value is function/class-shaped (arrow_function, function_expression, class, generator_function, …), so require/import and constants don't flood the MAP. - Enforce is_identifier (non-empty, first char alphabetic/_/$); emit no symbol when it fails, letting the renderer's (no symbols extracted) path show. - Keep the signature as the trimmed first line (separate contract).

Verification: 11 new targeted tests (231 passed); falsification by restoring the old heuristic makes 8 fail (expected name Middleware, got: ["void;"]); live express MAP 27 empty + 5 real → 0 empty + 33 real; additivity ADDED 0 / REMOVED 0 with 645 edges both sides; determinism 14 pass, clippy/fmt clean.
