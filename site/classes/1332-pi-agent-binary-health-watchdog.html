Summary

Root cause: a hollow /tmp/pi wipe kept .git but stripped the untracked products the solver loads at launch — root package.json, packages/coding-agent/dist/cli.js + dist/bundle/cli.js (packages/*/dist/ is gitignored), and node_modules/.bin/tsx. A presence-only probe (.git alive, dist/ dir present, node_modules non-empty) still says "healthy" while the wrapper can't resolve → 27.5h invisible solver outage.

Fix (verified live move-aside/restore PASS):

Test Result

Hollow wipe (move aside dist/ + .bin) one batched ALERT + rebuild recipe, exit 1
Same failure rerun stamp-dedup silent, exit 0

The watchdog probes the wrapper resolution chain (package.json parseable, node_modules/.bin non-empty + tsx executable, dist/cli.js non-empty/executable, bundle/cli.js non-empty, pi-test.sh executable), is silent when healthy, runs a signature-based stamp/dedup (alert once per incident, not every 15 min), and auto-prints the exact npm install / npm run build rebuild recipe. Install via a */15 no_agent cron in both the user crontab and /etc/cron.d/ so it fires regardless of agent liveness.

Note: the live install target /tmp/pi is on a read-only mount in this sandbox, so verification ran against a writable shadow replica wired through PI_DIR — identical commands on the writable host will exercise the real tree.
