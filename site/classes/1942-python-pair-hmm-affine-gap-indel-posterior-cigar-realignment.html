Pair-HMM Affine-Gap Realignment — Diagnosis and Verified Solution

Summary

The target is a deterministic global affine-gap Pair-HMM that realigns an existing M/I/D/S/N CIGAR, builds the full forward and backward matrices in log space, turns them into per-base posterior probabilities of M, I and D, decodes the maximum-likelihood CIGAR, and reports every changed position with its posterior delta. The implementation is pure Python, has no RNG, and is validated against brute-force enumeration of all alignment paths.

Root-cause analysis

  1. Probability-space underflow — 500 bp has ~10³⁰⁰ paths; float products become 0.0. Fix: log-space recurrences with an -inf-safe lse2/lse (never forms exp(large)).
  2. Linear-space shortcuts break the backward pass — Hirschberg/checkpointing can't yield per-cell posteriors. Fix: retain full (n+1)×(m+1) F_* and B_* matrices.
  3. Linear gap pretending to be affine — use 3 states with explicit open/extend: M→M=log(1-2·open), M→I/M→D=log(open), I→I/D→D=log(extend), I→M/D→M=log(1-extend). Omitting the 1-2·open factor biases every posterior.
  4. Soft clips / reference skips leaking into indels — S and N are segment barriers, not gaps. Fix: emit S/H/N verbatim and realign each maximal M/I/D/=/X run independently.
  5. Posterior off-by-one — F includes the cell emission, B excludes it; γ_s(i,j)=exp(F_s+B_s−Z), Z=B_M(0,0).
  6. Non-reproducibility — fixed DEFAULTS, deterministic loop order and tie-breaking.

The fix (exact code)

Model recurrences:

# forward
F_M(i,j) = E[i][j] + lse( F_M(i-1,j-1)+log_mm,
                          F_I(i-1,j-1)+log_close,
                          F_D(i-1,j-1)+log_close )
F_I(i,j) = lse2( F_M(i-1,j)+log_open, F_I(i-1,j)+log_extend )
F_D(i,j) = lse2( F_M(i,j-1)+log_open, F_D(i,j-1)+log_extend )

# backward
B_M(i,j) = lse2( E[i+1][j+1]+log_mm   + B_M(i+1,j+1),
                 log_open             + B_I(i+1,j),
                 log_open             + B_D(i,j+1) )
B_I(i,j) = lse2( E[i+1][j+1]+log_close + B_M(i+1,j+1),
                 log_extend            + B_I(i+1,j) )
B_D(i,j) = lse2( E[i+1][j+1]+log_close + B_M(i+1,j+1),
                 log_extend            + B_D(i,j+1) )

Parameters (fixed schedule): gap_open=0.05, gap_extend=0.5, epsilon=1e-9, default_q=30, min_err=1e-6, max_err=0.75. Match emission uses Phred q: log(1-p_err) on match, log(p_err) otherwise, p_err=clamp(10^(-q/10), min_err, max_err).
