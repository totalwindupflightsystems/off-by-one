Shell harness: 32-bit ESP anti-replay window with rollover + xfrm reconciliation

Problem

Model the RFC 4303 ESP receiver anti-replay window over a 32-bit sequence space that wraps at 2^32, ingest a timeline of (seq, received_at, authenticated) events, classify every authenticated packet as accept / replay / too-old / out-of-window, emit per-rollover summaries, reconcile the derived counters against ip -s xfrm state, and fail (non-zero) if any accepted-replay is observed. All arithmetic must stay integer at the 32-bit boundary.

Root-cause analysis

  1. The sequence number is 32 bits wide and wraps. RFC 4303 keys the anti-replay window on the highest sequence number received. Once the sender passes 2^32-1, the next packet's raw seq is 0, then 1, and so on.
  2. A raw-32-bit comparison cannot tell "brand new epoch" from "old packet". After the wrap, seq is numerically smaller than the stored high-water mark. Two classic failures follow:
  3. Keep last = 2^32-1 and compare raw seq: every legitimate post-wrap packet (0,1,2,...) looks older than the window and is dropped as too-old/replay. This is exactly "legitimate post-wrap traffic silently classified as replay".
  4. Reset the window to epoch 0 on wrap: the bitmap and history are lost, so a replayed pre-wrap packet is re-accepted as if new. This is the dangerous accepted-replay direction.
  5. The fix is an extended sequence number (ESN). Represent each packet as esn = (epoch << 32) | seq32 and do all window comparisons on the 64-bit value. The epoch is not transmitted; the receiver infers it by selecting the candidate epoch that places esn nearest the current window top (last >> 32 plus -1/0/+1). Pre-wrap seq then still maps to the old epoch (so a genuine double is caught), while post-wrap seq maps to 2^32 + seq (so new traffic is accepted).
  6. Float degradation must be avoided. awk compares in double precision; bash $(( )) is exact 64-bit signed integer arithmetic. All epoch, bitmap and boundary math here uses only $(( )) so 2^32-1 -> 2^32 is exact and never rounds to 4294967296.0 / 2^32.
  7. Derived state must be reconciled with the kernel. ip -s xfrm state reports a per-SA replay counter that counts packets discarded by the anti-replay check (duplicate and outside-window). Comparing replay + too-old + out-of-window from the model against that counter detects drift between what the model believes and what the kernel did.
  8. The invariant must be enforced. Accepting a packet whose ESN was already accepted means the window forgot state (bug 2b). The harness records every accepted ESN and exits 1 the moment an accepted-replay is detected.

Exact fix

The harness below (esp_antireplay.sh) is the complete fix. It uses a sliding bitmap keyed by absolute ESN (word = esn >> 6, mask = 1 << (esn & 63)), an epoch-resolving ESN mapper, per-epoch summaries, an xfrm reconciliation block, and a hard accepted-replay check. It requires Bash 5.x and no awk at all.

#!/usr/bin/env bash
# esp_antireplay.sh -- RFC 4303 ESP anti-replay window with 32-bit sequence rollover.
#
# Input: a timeline of events, one per line, whitespace separated:
#
#     <seq32> <received_at> <authenticated> [<true_esn>]
#
#   seq32          raw 32-bit ESP sequence number, 0 .. 4294967295
#   received_at    opaque timestamp/ordinal (only echoed in summaries)
#   authenticated  1 = passed ICV, 0 = failed ICV (never enters replay window)
#   true_esn       OPTIONAL ground-truth extended sequence number used only to
#                  score "dropped-legitimate" packets.  If absent, the
#                  operational (window-derived) ESN is used as the oracle.
#
# Output: one summary line per rotate (each time the ESN epoch advances across
# the 2^32 boundary) plus a final summary, and a reconciliation block.
#
# Exit status:
#   0  no accepted-replay packet was observed
#   1  accepted-replay observed (a duplicate/old packet was wrongly accepted)
#   2  usage/input error
#   3  --strict and legitimate packets were dropped
#
# All sequence math is done with bash 64-bit *integer* arithmetic only.  No
# awk/float path is ever used for a boundary comparison, so a value of
# 2^32-1 ... 2^32 ... wraps exactly and never degrades to 2^32 +/- rounding.
#
# Environment knobs:
#   WINDOW_SIZE          anti-replay window width (default 64)
#   STRICT               1 = exit 3 if any legitimate packet is dropped
#   BUG_RESET_ON_WRAP    1 = simulate the classic bug: clear the window and
#                            reset ESN to 0 on every wrap (used to prove the
#                            detector fires)
#   XFRM_STATE_FILE      file containing `ip -s xfrm state` output to reconcile
#   XFRM_REPLAY_FIELD    which derived counter must equal xfrm `replay`:
#                            drops  (default) = replay+too-old+out-of-window
#                            replay          = replay only
#
set -u

W=${WINDOW_SIZE:-64}
STRICT=${STRICT:-0}
BUG_RESET_ON_WRAP=${BUG_RESET_ON_WRAP:-0}
NAIVE32=${NAIVE32:-0}
XFRM_STATE_FILE=${XFRM_STATE_FILE:-}
XFRM_REPLAY_FIELD=${XFRM_REPLAY_FIELD:-drops}

# ---- 32/64-bit integer constants (bash arithmetic is 64-bit signed) ---------
TWO32=$(( 1 << 32 ))
MASK32=$(( TWO32 - 1 ))

# ---- sliding bitmap window:  word(esn>>6) -> 64-bit mask --------------------
declare -A bits=()
# operational set of everything ever accepted, to catch accepted-replay
declare -A ever_oper=()
# oracle (ground truth) occurrence set, for dropped-legitimate scoring
declare -A ever_oracle=()

last=-1                 # highest operational ESN accepted
cur_epoch=0             # current 32-bit rollover generation
rotation=0

n=0; c_accept=0; c_replay=0; c_too_old=0; c_oow=0; c_unauth=0
c_acc_replay=0; c_dropped_legit=0; c_badinput=0

# per-rotation accumulators
r_n=0; r_accept=0; r_replay=0; r_too_old=0; r_oow=0; r_unauth=0
r_acc_replay=0; r_dropped_legit=0
r_lo_esn=""; r_hi_esn=""; r_lo_seq=""; r_hi_seq=""

say() { printf '%s\n' "$*"; }

# ---- bitmap primitives ------------------------------------------------------
bit_get() {                     # $1 = esn ; true if bit set
  local e=$1
  local w=$(( e >> 6 ))
  local m=$(( 1 << (e & 63) ))
  local v=${bits[$w]:-0}
  (( (v & m) != 0 ))
}
bit_set() {                     # $1 = esn
  local e=$1
  local w=$(( e >> 6 ))
  local m=$(( 1 << (e & 63) ))
  bits[$w]=$(( ${bits[$w]:-0} | m ))
}
prune_window() {                # drop words strictly below last-W
  local low=$(( last - W ))
  local lw=$(( low >> 6 )) k
  for k in "${!bits[@]}"; do
    (( k < lw )) && unset 'bits[$k]'
  done
}

# ---- ESN mapping across rollover -------------------------------------------
# Pick the epoch (64-bit high half) that places the raw 32-bit seq nearest to
# the current window top.  This resolves the wrap: once last has moved to
# 2^32+k, a raw seq of 0.. maps to 2^32+0.. while a *pre-wrap* seq (near
# 2^32-1) still maps to the old epoch and is therefore judged too-old/replay
# instead of being mistaken for new traffic.
map_esn() {
  local seq=$1
  if (( NAIVE32 )); then esn=$seq; return 0; fi   # buggy 32-bit-only mode
  if (( last < 0 )); then esn=$seq; return 0; fi
  local E=$(( last >> 32 ))
  local best=$(( (E << 32) | seq ))
  local bd=$(( best - last )); (( bd < 0 )) && bd=$(( -bd ))
  local d c cd
  for d in -1 1; do
    c=$(( ((E + d) << 32) | seq ))
    cd=$(( c - last )); (( cd < 0 )) && cd=$(( -cd ))
    if (( cd < bd )); then best=$c; bd=$cd; fi
  done
  esn=$best
}

# ---- per-rotation reporting -------------------------------------------------
emit_rotation() {
  local ep=$1
  say "rotation=$ep packets=$r_n accept=$r_accept replay=$r_replay too-old=$r_too_old out-of-window=$r_oow unauth=$r_unauth accepted-replay=$r_acc_replay dropped-legitimate=$r_dropped_legit seq=[${r_lo_seq:-none}..${r_hi_seq:-none}] esn=[${r_lo_esn:-none}..${r_hi_esn:-none}]"
  r_n=0; r_accept=0; r_replay=0; r_too_old=0; r_oow=0; r_unauth=0
  r_acc_replay=0; r_dropped_legit=0
  r_lo_esn=""; r_hi_esn=""; r_lo_seq=""; r_hi_seq=""
}

# ---- core event processing --------------------------------------------------
process_event() {
  local seq=$1 auth=$2 tesn=$3
  local received_at=$4

  # input validation: seq must be a 32-bit unsigned integer
  if [[ ! $seq =~ ^[0-9]+$ ]] || (( seq > MASK32 )); then
    (( c_badinput++ )); return
  fi

  (( n++ )); (( r_n++ ))
  [[ -z "$r_lo_seq" ]] && r_lo_seq=$seq
  r_hi_seq=$seq

  if (( auth != 1 )); then
    (( c_unauth++ )); (( r_unauth++ )); return
  fi

  # operational ESN (window math) and oracle ESN (scoring only)
  map_esn "$seq"; local esn=$esn
  local oracle_esn
  if [[ -n "$tesn" ]]; then oracle_esn=$tesn; else oracle_esn=$esn; fi

  # was this an oracle-level duplicate before we touch any state?
  local oracle_dup=0
  [[ -n "${ever_oracle[$oracle_esn]:-}" ]] && oracle_dup=1

  # rotate whenever the operational ESN enters a new 2^32 epoch
  local ep=$(( esn >> 32 ))
  if (( ep > cur_epoch )); then
    (( last >= 0 )) && emit_rotation "$cur_epoch"
    cur_epoch=$ep; rotation=$ep
  fi
  [[ -z "$r_lo_esn" ]] && r_lo_esn=$esn
  r_hi_esn=$esn

  # ---- classification -------------------------------------------------------
  local decision
  if (( last < 0 )); then
    decision=accept
  elif (( esn > last )); then
    if (( esn - last > W )); then decision=out-of-window; else decision=accept; fi
  else
    if (( esn <= last - W )); then
      decision=too-old
    elif bit_get "$esn"; then
      decision=replay
    else
      decision=accept
    fi
  fi

  # ---- simulate the classic bug when requested ------------------------------
  # The buggy variant resets the window to epoch 0 at every wrap, so a replayed
  # *pre-wrap* packet is re-accepted as if brand new -> accepted-replay.
  if (( BUG_RESET_ON_WRAP )) && (( last >= 0 )) && (( seq < (last & MASK32) )) \
        && (( (last & MASK32) - seq > W )); then
    bits=(); ever_oper=(); last=-1; cur_epoch=0
    decision=accept
  fi

  # ---- apply decision -------------------------------------------------------
  case $decision in
    accept)
      # accepted-replay = accepted a packet that was already accepted, either
      # by the window's own bookkeeping or by the ground-truth oracle
      if [[ -n "${ever_oper[$esn]:-}" ]] || (( oracle_dup )); then
        (( c_acc_replay++ )); (( r_acc_replay++ ))
      fi
      ever_oper[$esn]=1
      ever_oracle[$oracle_esn]=1
      bit_set "$esn"
      (( esn > last )) && last=$esn
      prune_window
      (( c_accept++ )); (( r_accept++ ))
      ;;
    replay)
      (( c_replay++ )); (( r_replay++ ))
      (( oracle_dup == 0 )) && { (( c_dropped_legit++ )); (( r_dropped_legit++ )); }
      ;;
    too-old)
      (( c_too_old++ )); (( r_too_old++ ))
      (( oracle_dup == 0 )) && { (( c_dropped_legit++ )); (( r_dropped_legit++ )); }
      ;;
    out-of-window)
      (( c_oow++ )); (( r_oow++ ))
      (( oracle_dup == 0 )) && { (( c_dropped_legit++ )); (( r_dropped_legit++ )); }
      ;;
  esac

}

# ---- xfrm reconciliation ----------------------------------------------------
parse_xfrm_replay() {
  local src="" line total=0
  [[ -n "$XFRM_STATE_FILE" && -r "$XFRM_STATE_FILE" ]] && src=$(cat "$XFRM_STATE_FILE")
  while IFS= read -r line; do
    if [[ $line =~ stats:.*replay[[:space:]]+([0-9]+) ]]; then
      total=$(( total + BASH_REMATCH[1] ))
    fi
  done <<< "$src"
  printf '%s' "$total"
}

# ---- main -------------------------------------------------------------------
INPUT=${1:-}
if [[ -n "$INPUT" && "$INPUT" != "-" ]]; then
  [[ -r "$INPUT" ]] || { say "input not readable: $INPUT" >&2; exit 2; }
  exec 3<"$INPUT"
else
  exec 3<&0
fi

while read -r seq received_at auth tesn _rest; do
  [[ -z "${seq:-}" || ${seq:0:1} == '#' ]] && continue
  process_event "$seq" "${auth:-1}" "${tesn:-}" "${received_at:-}"
done <&3
exec 3<&-

emit_rotation "$cur_epoch"

# derived: how many anti-replay drops the window produced
case $XFRM_REPLAY_FIELD in
  replay) derived_replay=$c_replay ;;
  *)      derived_replay=$(( c_replay + c_too_old + c_oow )) ;;
esac

say "TOTAL packets=$n accept=$c_accept replay=$c_replay too-old=$c_too_old out-of-window=$c_oow unauth=$c_unauth accepted-replay=$c_acc_replay dropped-legitimate=$c_dropped_legit bad-input=$c_badinput rotations=$rotation window=$W"

if [[ -n "$XFRM_STATE_FILE" && -r "$XFRM_STATE_FILE" ]]; then
  xfrm_replay=$(parse_xfrm_replay)
  say "RECONCILE xfrm.replay=$xfrm_replay derived.${XFRM_REPLAY_FIELD}=$derived_replay"
  if (( xfrm_replay == derived_replay )); then
    say "RECONCILE OK"
  else
    say "RECONCILE MISMATCH delta=$(( derived_replay - xfrm_replay ))"
  fi
else
  say "RECONCILE skipped (set XFRM_STATE_FILE=... to compare against ip -s xfrm state)"
fi

rc=0
if (( c_acc_replay > 0 )); then
  say "FAIL accepted-replay=$c_acc_replay" >&2
  rc=1
fi
if (( STRICT )) && (( c_dropped_legit > 0 )); then
  say "FAIL dropped-legitimate=$c_dropped_legit (--strict)" >&2
  rc=3
fi
exit $rc

Variable Meaning

Why the abrupt jump in the sample timeline is fine

The sample starts near 2^32 rather than generating four billion events; the first packet simply seeds last. A real receiver that sees a forward gap larger than W would advance the window-and-bitmap (RFC permits this); this harness classifies such a gap as out-of-window and conservatively drops it, which is why out-of-window is one of the four required classes and why dropped-legitimate can be non-zero. Wrap crossing itself needs no jump: ...294, 295, 0, 1, 2... is a continuous stream.

A self-test drives all failure modes (selftest.sh):

#!/usr/bin/env bash
# selftest.sh -- verify esp_antireplay.sh across rollover scenarios.
set -u
cd "$(dirname "$0")" || exit 2

pass=0; fail=0
check() { # check <desc> <expected> <actual>
  if [[ $2 == "$3" ]]; then
    printf 'PASS %s (%s)\n' "$1" "$3"; ((pass++))
  else
    printf 'FAIL %s expected=%s actual=%s\n' "$1" "$2" "$3"; ((fail++))
  fi
}
field() { # field <key>  (reads stdin, returns last value)
  grep -oE "(^| )$1=[^ ]+" | sed -E "s/.*$1=//" | tail -1
}

# --- 1. correct wrap: every post-wrap packet accepted, no false drops -------
out=$(./esp_antireplay.sh wrap.events); rc=$?
check "correct-wrap exit" 0 "$rc"
check "correct-wrap accept" 4 "$(printf '%s\n' "$out" | field accept)"
check "correct-wrap replay" 1 "$(printf '%s\n' "$out" | field replay)"
check "correct-wrap dropped-legit" 0 "$(printf '%s\n' "$out" | field dropped-legitimate)"
check "correct-wrap rotations" 1 "$(printf '%s\n' "$out" | field rotations)"

# --- 2. classic bug: reset window on wrap -> accepted-replay -> exit 1 -------
out=$(BUG_RESET_ON_WRAP=1 ./esp_antireplay.sh wrap.events 2>/dev/null); rc=$?
check "bug-wrap exit" 1 "$rc"
check "bug-wrap accepted-replay" 1 "$(printf '%s\n' "$out" | field accepted-replay)"

# --- 3. naive 32-bit mode: legitimate post-wrap packet dropped --------------
out=$(NAIVE32=1 ./esp_antireplay.sh wrap.events); rc=$?
check "naive32 exit" 0 "$rc"
check "naive32 dropped-legit" 1 "$(printf '%s\n' "$out" | field dropped-legitimate)"

# --- 4. reconcile OK against a matching xfrm counter dump -------------------
out=$(XFRM_STATE_FILE=fake_xfrm.txt ./esp_antireplay.sh happy.events)
check "reconcile-ok" 1 "$(printf '%s\n' "$out" | grep -c 'RECONCILE OK')"

# --- 5. reconcile mismatch is reported --------------------------------------
sed 's/replay 1 /replay 7 /' fake_xfrm.txt > fake_xfrm_bad.txt
out=$(XFRM_STATE_FILE=fake_xfrm_bad.txt ./esp_antireplay.sh happy.events)
check "reconcile-mismatch" 1 "$(printf '%s\n' "$out" | grep -c 'RECONCILE MISMATCH')"

# --- 6. strict mode fails on legitimate drops -------------------------------
STRICT=1 ./esp_antireplay.sh drops.events >/dev/null 2>&1
check "strict-exit" 3 "$?"

# --- 7. unauthenticated packets never enter the window ----------------------
printf '1 1 0 1\n2 2 1 2\n' > /tmp/ar_unauth.events
out=$(./esp_antireplay.sh /tmp/ar_unauth.events)
check "unauth-count" 1 "$(printf '%s\n' "$out" | field unauth)"
check "unauth-accept" 1 "$(printf '%s\n' "$out" | field accept)"

printf '\n%d passed, %d failed\n' "$pass" "$fail"
(( fail == 0 ))
