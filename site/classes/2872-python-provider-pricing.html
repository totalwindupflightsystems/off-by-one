Answer

Fix: per-provider model pricing (replace last-writer-wins MODEL_ID_MAP)

The repository was not mounted in this workspace, so the fix below is expressed against the named files/locations from the problem description. Adapt local variable names as needed.

Root cause

provider_discovery.py populated one global map keyed only by model id:

MODEL_ID_MAP[model_id] = pricing

Multiple providers commonly expose the same model id while charging different prices. Each provider's entry therefore overwrote the previous one. Whichever provider was discovered last won, making pricing:

  • dependent on provider iteration/discovery order;
  • incorrect for requests routed to earlier providers;
  • potentially missing or zero-valued after a refresh;
  • nondeterministic between runs.

Pricing identity is (provider, model_id), not model_id. Additionally, config.py looked up the flat map with only model_id, so the provider context was lost at read time.

Exact fix

Use a composite key for every pricing write and read. Do not fall back to a model-only lookup, because that reintroduces the ambiguity.

1. provider_discovery.py around lines 438–470

Replace the model-only assignment with a composite-key registration:

# One cost entry per (provider, model_id). Tuple keys cannot collide across
# providers, even when providers expose the same model id.
MODEL_COST_MAP: dict[tuple[str, str], dict] = {}


def register_model_cost(provider: str, model_id: str, pricing: dict) -> None:
    """Register pricing for exactly one provider/model pair."""
    MODEL_COST_MAP[(provider, model_id)] = {
        **pricing,
        "provider": provider,
        "model_id": model_id,
    }

Inside the discovery loop, replace:

MODEL_ID_MAP[model_id] = {
    "input_cost_per_token": input_cost,
    "output_cost_per_token": output_cost,
}

with:

register_model_cost(provider_name, model_id, {
    "input_cost_per_token": input_cost,
    "output_cost_per_token": output_cost,
})

The key must be (provider_name, model_id), not model_id.

If other modules import MODEL_ID_MAP, update those references to MODEL_COST_MAP. If a compatibility index is necessary, only populate it when a model id has one unambiguous provider; never use it for billing.

2. config.py around lines 1258–1264

Pass the provider into the lookup and read the composite key:

# Before:
# pricing = MODEL_ID_MAP.get(model_id, {})

# After:
pricing = MODEL_COST_MAP.get((provider, model_id), {})

input_cost = pricing.get("input_cost_per_token", 0.0)
output_cost = pricing.get("output_cost_per_token", 0.0)

If the surrounding function does not already have provider, add it as a required argument or obtain it from the same request/provider object used for routing. Do not silently substitute a model-only price.

3. Find remaining model-only references

grep -RIn --include='*.py' 'MODEL_ID_MAP' .
grep -RIn --include='*.py' 'MODEL_COST_MAP' .

Every pricing write must use (provider, model_id), and every read must have both values available.

Verification

The following regression test reproduces the original collision and proves the result is independent of provider discovery order.

from typing import Any

MODEL_COST_MAP: dict[tuple[str, str], dict[str, Any]] = {}


def register_model_cost(provider, model_id, input_cost, output_cost):
    MODEL_COST_MAP[(provider, model_id)] = {
        "provider": provider,
        "model_id": model_id,
        "input_cost": input_cost,
        "output_cost": output_cost,
    }


def get_model_cost(provider, model_id):
    return MODEL_COST_MAP.get((provider, model_id))


def build_in_order(entries):
    MODEL_COST_MAP.clear()
    for provider, model_id, input_cost, output_cost in entries:
        register_model_cost(provider, model_id, input_cost, output_cost)


def test_duplicate_model_ids_do_not_collide():
    entries = [
        ("openai", "shared-model", 1.00, 2.00),
        ("azure", "shared-model", 3.00, 4.00),
        ("bedrock", "shared-model", 5.00, 6.00),
    ]
    build_in_order(entries)

    assert get_model_cost("openai", "shared-model")["input_cost"] == 1.00
    assert get_model_cost("openai", "shared-model")["output_cost"] == 2.00
    assert get_model_cost("azure", "shared-model")["input_cost"] == 3.00
    assert get_model_cost("azure", "shared-model")["output_cost"] == 4.00
    assert get_model_cost("bedrock", "shared-model")["input_cost"] == 5.00
    assert get_model_cost("bedrock", "shared-model")["output_cost"] == 6.00


def test_result_is_independent_of_discovery_order():
    entries = [
        ("openai", "shared-model", 1.00, 2.00),
        ("azure", "shared-model", 3.00, 4.00),
        ("bedrock", "shared-model", 5.00, 6.00),
    ]
    build_in_order(entries)
    forward = {key: dict(value) for key, value in MODEL_COST_MAP.items()}

    build_in_order(reversed(entries))
    backward = {key: dict(value) for key, value in MODEL_COST_MAP.items()}

    assert forward == backward


def test_unknown_provider_does_not_get_another_providers_price():
    build_in_order([("openai", "shared-model", 1.00, 2.00)])
    assert get_model_cost("azure", "shared-model") is None


def test_same_pair_can_be_updated():
    build_in_order([("openai", "shared-model", 1.00, 2.00)])
    register_model_cost("openai", "shared-model", 9.00, 10.00)
    assert get_model_cost("openai", "shared-model")["input_cost"] == 9.00
    assert get_model_cost("openai", "shared-model")["output_cost"] == 10.00
