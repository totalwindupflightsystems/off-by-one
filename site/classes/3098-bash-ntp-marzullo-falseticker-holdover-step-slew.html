Chrony-Style Clock Discipline in Bash: Root Cause, Exact Fix, Verification

1. Summary

The failure class is stateless last-sample-wins discipline: each update sets correction = offset_of_last_sample. This trusts a single sample, has no memory of the previously applied correction, applies every jump instantaneously, and therefore silently absorbs the second half of an injected double step.

The fix is a Bash evaluator (numeric core in POSIX awk) that per poll epoch:

  • runs Marzullo interval intersection and requires ≥ 3 survivors;
  • uses a 0.128 s step threshold with a two-step lockout window (at most one step per window; a refused second step is reported as an anomaly);
  • slews at ≤ 500 ppm;
  • enters holdover after 3 consecutive epochs without consensus;
  • prints the disciplined offset timeline plus ANOMALY lines.

2. Root-cause analysis

The naive baseline is literally:

correction = offset_of_last_sample      # every epoch

Four independent structural flaws, all triggered by the double step:

  1. No quorum / interval intersection — one bad server is trusted as much as a healthy majority.
  2. No cross-update memory — a genuine discontinuity is indistinguishable from a transient outlier because the new value is never compared to the applied correction.
  3. No step threshold + lockout — a double step (two large jumps on consecutive epochs) is applied twice, leaving the clock over-corrected by the second jump, with no warning.
  4. No bounded slew — corrections are instantaneous discontinuities rather than a monotone ≤ 500 ppm ramp.

The double step is the canonical witness: last-sample-wins ends at +2Δ and reports nothing. Correct discipline must validate with a quorum, compare to the applied correction, refuse and flag a second step inside the lockout, bound the slew, and hold over when consensus is lost.

3. Exact fix

3.1 Log and output model

Input line: <local_ts> <offset> <root_delay> <stratum> <leap> Samples sharing a timestamp form one poll epoch. Interval = offset ± root_delay/2; stratum > 15 and leap == 3 are discarded.

Output: epoch event applied_delta correction residual survivors flags, with event ∈ {STEP, SLEW, REJECT, HOLDOVER}. A refused step also prints ANOMALY <epoch> DOUBLE_STEP_LOCKOUT delta=<d> residual=<r>.

3.2 chrony_eval.sh

#!/usr/bin/env bash
#
# chrony_eval.sh - chrony-style clock discipline evaluator.
#
# Consumes an NTP sample log.  Lines:
#
#     <local_ts> <offset> <root_delay> <stratum> <leap>
#
#   local_ts    local timestamp in seconds (float).  Samples that share the
#               same local_ts belong to the same poll epoch / same batch of
#               servers.
#   offset      measured offset (remote - local) in seconds.
#   root_delay  root distance / root delay in seconds (uncertainty).
#   stratum     server stratum.
#   leap        leap indicator (0 = none, 1 = insert, 2 = delete,
#               3 = unsynchronised -> sample discarded).
#
# For every epoch it:
#   1. builds the Marzullo interval [offset - root_delay/2, offset + root_delay/2]
#      for every usable sample,
#   2. runs Marzullo's interval-intersection algorithm and requires at least
#      MIN_SURV survivors to declare consensus,
#   3. disciplines the local clock with a step when |delta| > STEP_THRESH
#      (subject to a LOCKOUT window that permits only one step per window),
#      otherwise slews at most SLEW_PPM ppm,
#   4. enters HOLDOVER after three consecutive epochs without consensus,
#      and reports every anomalous (locked-out) large jump.
#
# Output columns:
#
#     epoch event applied_delta correction residual survivors flags
#
# `applied_delta` is the change of the applied correction during the epoch,
# `correction` is the total applied correction, `residual` is the remaining
# error (agreed offset - correction).  When a step is refused because of the
# lockout window an extra line is emitted:
#
#     ANOMALY <epoch> DOUBLE_STEP_LOCKOUT delta=<d> residual=<r>
#
set -euo pipefail

STEP_THRESH=0.128
SLEW_PPM=500
LOCKOUT=2.0
MIN_SURV=3
MAX_STRATUM=15
ANOMALY_FILE=""
INPUT=""

usage() {
    cat <<'EOF'
Usage: chrony_eval.sh [options] SAMPLE_LOG

Options:
  --step-threshold S   step threshold in seconds        (default 0.128)
  --slew-ppm P         maximum slew rate in ppm         (default 500)
  --lockout S          two-step lockout window seconds  (default 2.0)
  --min-survivors N    Marzullo survivors required      (default 3)
  --max-stratum N      discard samples above this       (default 15)
  --anomaly-file F     also append ANOMALY lines to F
  -h, --help           print this help
EOF
}

while [ $# -gt 0 ]; do
    case "$1" in
        --step-threshold) STEP_THRESH=$2; shift 2 ;;
        --slew-ppm)       SLEW_PPM=$2; shift 2 ;;
        --lockout)        LOCKOUT=$2; shift 2 ;;
        --min-survivors)  MIN_SURV=$2; shift 2 ;;
        --max-stratum)    MAX_STRATUM=$2; shift 2 ;;
        --anomaly-file)   ANOMALY_FILE=$2; shift 2 ;;
        -h|--help)        usage; exit 0 ;;
        -*)               echo "unknown option: $1" >&2; usage >&2; exit 2 ;;
        *)                INPUT=$1; shift ;;
    esac
done

if [ -z "$INPUT" ]; then
    usage >&2
    exit 2
fi
if [ ! -r "$INPUT" ]; then
    echo "cannot read sample log: $INPUT" >&2
    exit 2
fi

awk \
    -v step_thresh="$STEP_THRESH" \
    -v slew_ppm="$SLEW_PPM" \
    -v lockout="$LOCKOUT" \
    -v min_surv="$MIN_SURV" \
    -v max_stratum="$MAX_STRATUM" \
    -v anomaly_file="$ANOMALY_FILE" '
BEGIN {
    FS = "[ \t]+"
    if (anomaly_file != "") printf "" > anomaly_file
    corr = 0.0
    oldcorr = 0.0
    prev_t = 0.0
    have_prev = 0
    first_done = 0
    last_step_t = -1e300
    consec_reject = 0
    holdover = 0
    nsamp = 0
}

function fabs(x) { return x < 0 ? -x : x }

function emit_anomaly(t, detail) {
    line = sprintf("ANOMALY %.3f DOUBLE_STEP_LOCKOUT %s", t, detail)
    print line
    if (anomaly_file != "") print line >> anomaly_file
}

function flush_epoch(   i, j, k, t, tmp, ne, best, best_lo, best_hi, cnt,
                        agreed, delta, dt, maxd, event, anom, fals, usable,
                        applied, residual) {
    if (nsamp == 0) return

    # ---- build Marzullo endpoint events -------------------------------
    ne = 0
    usable = 0
    for (i = 1; i <= nsamp; i++) {
        if (stratum[i] > max_stratum || leap[i] == 3) continue
        usable++
        ne++; ev_pos[ne] = lo[i]; ev_typ[ne] = 1
        ne++; ev_pos[ne] = hi[i]; ev_typ[ne] = -1
    }

    # ---- sort: position ascending, starts (+1) before ends (-1) --------
    for (i = 1; i < ne; i++) {
        for (j = i + 1; j <= ne; j++) {
            if (ev_pos[j] < ev_pos[i] ||
                (ev_pos[j] == ev_pos[i] && ev_typ[j] > ev_typ[i])) {
                tmp = ev_pos[i]; ev_pos[i] = ev_pos[j]; ev_pos[j] = tmp
                tmp = ev_typ[i]; ev_typ[i] = ev_typ[j]; ev_typ[j] = tmp
            }
        }
    }

    # ---- sweep to find the largest intersection -----------------------
    cnt = 0; best = 0; best_lo = 0; best_hi = 0
    for (k = 1; k <= ne; k++) {
        if (ev_typ[k] == 1) {
            cnt++
            if (cnt > best) { best = cnt; best_lo = ev_pos[k]; best_hi = ev_pos[k] }
        } else {
            if (best > 0 && cnt == best) best_hi = ev_pos[k]
            cnt--
        }
    }

    t = epoch_t

    # ---- no consensus -> falseticker rejection / holdover --------------
    if (best < min_surv) {
        consec_reject++
        if (consec_reject >= 3) holdover = 1
        event = holdover ? "HOLDOVER" : "REJECT"
        printf "%.3f %s %.6f %.6f %s %d no_consensus\n",
               t, event, 0.0, corr, "nan", best
        prev_t = t; have_prev = 1
        nsamp = 0
        return
    }

    # ---- consensus established ----------------------------------------
    consec_reject = 0
    holdover = 0
    agreed = (best_lo + best_hi) / 2.0
    oldcorr = corr
    delta = agreed - corr
    anom = ""

    if (!first_done) {
        # initial acquisition: lock on to the agreed offset immediately
        corr = agreed
        first_done = 1
        if (fabs(delta) > step_thresh) {
            event = "STEP"
            last_step_t = t
        } else {
            event = "SLEW"
        }
    } else if (fabs(delta) > step_thresh) {
        if (t - last_step_t >= lockout) {
            corr = agreed
            last_step_t = t
            event = "STEP"
        } else {
            # second large jump inside the lockout window: refuse the step
            anom = "DOUBLE_STEP_LOCKOUT"
            dt = have_prev ? (t - prev_t) : 0
            if (dt < 0) dt = 0
            maxd = slew_ppm * 1e-6 * dt
            if (fabs(delta) <= maxd) corr = agreed
            else corr += (delta < 0 ? -1 : 1) * maxd
            event = "SLEW"
        }
    } else {
        dt = have_prev ? (t - prev_t) : 0
        if (dt < 0) dt = 0
        maxd = slew_ppm * 1e-6 * dt
        if (fabs(delta) <= maxd) corr = agreed
        else corr += (delta < 0 ? -1 : 1) * maxd
        event = "SLEW"
    }

    applied = corr - oldcorr
    residual = agreed - corr
    fals = usable - best
    printf "%.3f %s %.6f %.6f %.6f %d falsetickers=%d\n",
           t, event, applied, corr, residual, best, fals

    if (anom != "") {
        emit_anomaly(t, sprintf("delta=%.6f residual=%.6f", delta, residual))
    }

    prev_t = t; have_prev = 1
    nsamp = 0
}

/^[ \t]*#/ { next }
/^[ \t]*$/ { next }
{
    t = $1 + 0
    if (nsamp > 0 && t != epoch_t) flush_epoch()
    if (nsamp == 0) epoch_t = t
    nsamp++
    off = $2 + 0
    d = $3 + 0
    stratum[nsamp] = $4 + 0
    leap[nsamp] = $5 + 0
    lo[nsamp] = off - d / 2.0
    hi[nsamp] = off + d / 2.0
}

END { flush_epoch() }
' "$INPUT"

Implementation note: t must be declared a local parameter of flush_epoch. If it is left global, the function overwrites the current line's timestamp and the epoch grouping collapses (one epoch per sample). This was the one real bug found during development; the differential fuzzer caught nothing else.

3.3 sample_gen.sh (deterministic generator)

#!/usr/bin/env bash
#
# sample_gen.sh - deterministic NTP sample-log generator for chrony_eval.sh.
#
# Emits lines:  <local_ts> <offset> <root_delay> <stratum> <leap>
#
# Scenarios:
#   clean        steady servers; one deliberate falseticker per epoch
#   step         single large step at epoch STEP_AT
#   double_step  two large jumps on consecutive epochs
#   falseticker  three consecutive epochs in which no 3 servers agree
#
set -euo pipefail

SCENARIO=clean
EPOCHS=6
SERVERS=4
START=0
PERIOD=1.0
BASE=0.0
DRIFT=0.0
STEP_AT=3
ROOT_DELAY=0.001
STRATUM=2
LEAP=0

usage() {
    cat <<'EOF'
Usage: sample_gen.sh [options]

Options:
  --scenario NAME   clean | step | double_step | falseticker (default clean)
  --epochs N        number of epochs                        (default 6)
  --servers M       servers per epoch                       (default 4)
  --start S         first timestamp                         (default 0)
  --period S        seconds between epochs                  (default 1.0)
  --base O          base offset in seconds                  (default 0.0)
  --drift O         per-epoch offset drift                  (default 0.0)
  --step-at N       epoch index of the injected event       (default 3)
  --root-delay S    root delay / uncertainty                (default 0.001)
  --stratum N       server stratum                          (default 2)
  --leap N          leap indicator                          (default 0)
EOF
}

while [ $# -gt 0 ]; do
    case "$1" in
        --scenario)   SCENARIO=$2; shift 2 ;;
        --epochs)     EPOCHS=$2; shift 2 ;;
        --servers)    SERVERS=$2; shift 2 ;;
        --start)      START=$2; shift 2 ;;
        --period)     PERIOD=$2; shift 2 ;;
        --base)       BASE=$2; shift 2 ;;
        --drift)      DRIFT=$2; shift 2 ;;
        --step-at)    STEP_AT=$2; shift 2 ;;
        --root-delay) ROOT_DELAY=$2; shift 2 ;;
        --stratum)    STRATUM=$2; shift 2 ;;
        --leap)       LEAP=$2; shift 2 ;;
        -h|--help)    usage; exit 0 ;;
        *) echo "unknown option: $1" >&2; usage >&2; exit 2 ;;
    esac
done

awk \
    -v scenario="$SCENARIO" \
    -v epochs="$EPOCHS" \
    -v servers="$SERVERS" \
    -v start="$START" \
    -v period="$PERIOD" \
    -v base="$BASE" \
    -v drift="$DRIFT" \
    -v step_at="$STEP_AT" \
    -v root_delay="$ROOT_DELAY" \
    -v stratum="$STRATUM" \
    -v leap="$LEAP" '
BEGIN {
    for (i = 0; i < epochs; i++) {
        t = start + i * period
        off = base + i * drift
        total = off

        if (scenario == "step" && i >= step_at) {
            total += 0.5
        } else if (scenario == "double_step") {
            if (i == step_at)     total += 0.5
            else if (i > step_at) total += 1.0
        }

        for (s = 1; s <= servers; s++) {
            o = total
            if (scenario == "falseticker" && i >= step_at && i < step_at + 3) {
                o = total + (s - 1) * 10.0
            } else if (scenario == "clean" && s == servers) {
                o = total + 5.0
            }
            printf "%.3f %.6f %.6f %d %d\n",
                   t, o, root_delay, stratum, leap
        }
    }
}
'

3.5 selftest.sh (three known-answer tests)

#!/usr/bin/env bash
#
# selftest.sh - three known-answer tests for chrony_eval.sh.
#
set -euo pipefail

HERE=$(cd "$(dirname "$0")" && pwd)
EVAL="$HERE/chrony_eval.sh"
GEN="$HERE/sample_gen.sh"
TMP=$(mktemp -d)
trap 'rm -rf "$TMP"' EXIT

pass=0
fail=0

check() {
    local name=$1 expected_file=$2 actual_file=$3
    if diff -u "$expected_file" "$actual_file" > "$TMP/diff.txt"; then
        echo "PASS: $name"; pass=$((pass + 1))
    else
        echo "FAIL: $name"; cat "$TMP/diff.txt"; fail=$((fail + 1))
    fi
}

# KAT 1 - clean quorum with one permanent falseticker; 500 ppm slew ramp.
"$GEN" --scenario clean --epochs 6 --servers 4 \
       --base 0.0 --drift 0.010 > "$TMP/kat1.log"
"$EVAL" "$TMP/kat1.log" > "$TMP/kat1.out"
cat > "$TMP/kat1.exp" <<'EOF'
0.000 SLEW 0.000000 0.000000 0.000000 3 falsetickers=1
1.000 SLEW 0.000500 0.000500 0.009500 3 falsetickers=1
2.000 SLEW 0.000500 0.001000 0.019000 3 falsetickers=1
3.000 SLEW 0.000500 0.001500 0.028500 3 falsetickers=1
4.000 SLEW 0.000500 0.002000 0.038000 3 falsetickers=1
5.000 SLEW 0.000500 0.002500 0.047500 3 falsetickers=1
EOF
check "KAT1 clean quorum + 500ppm slew" "$TMP/kat1.exp" "$TMP/kat1.out"

# KAT 2 - injected double step.  Epoch 3 steps +0.5 (allowed).  Epoch 4 steps
# again inside the 2 s lockout: refused, reported, slewed.  Epoch 5 applies.
"$GEN" --scenario double_step --epochs 6 --servers 3 --step-at 3 \
       > "$TMP/kat2.log"
"$EVAL" "$TMP/kat2.log" > "$TMP/kat2.out"
cat > "$TMP/kat2.exp" <<'EOF'
0.000 SLEW 0.000000 0.000000 0.000000 3 falsetickers=0
1.000 SLEW 0.000000 0.000000 0.000000 3 falsetickers=0
2.000 SLEW 0.000000 0.000000 0.000000 3 falsetickers=0
3.000 STEP 0.500000 0.500000 0.000000 3 falsetickers=0
4.000 SLEW 0.000500 0.500500 0.499500 3 falsetickers=0
ANOMALY 4.000 DOUBLE_STEP_LOCKOUT delta=0.500000 residual=0.499500
5.000 STEP 0.499500 1.000000 0.000000 3 falsetickers=0
EOF
check "KAT2 double-step lockout anomaly" "$TMP/kat2.exp" "$TMP/kat2.out"

# KAT 3 - three consecutive no-consensus epochs drive the clock into HOLDOVER.
"$GEN" --scenario falseticker --epochs 6 --servers 3 --step-at 2 \
       --base 0.0 --drift 0.010 > "$TMP/kat3.log"
"$EVAL" "$TMP/kat3.log" > "$TMP/kat3.out"
cat > "$TMP/kat3.exp" <<'EOF'
0.000 SLEW 0.000000 0.000000 0.000000 3 falsetickers=0
1.000 SLEW 0.000500 0.000500 0.009500 3 falsetickers=0
2.000 REJECT 0.000000 0.000500 nan 1 no_consensus
3.000 REJECT 0.000000 0.000500 nan 1 no_consensus
4.000 HOLDOVER 0.000000 0.000500 nan 1 no_consensus
5.000 SLEW 0.000500 0.001000 0.049000 3 falsetickers=0
EOF
check "KAT3 holdover after 3 rejections" "$TMP/kat3.exp" "$TMP/kat3.out"

echo
echo "self-test: $pass passed, $fail failed"
[ "$fail" -eq 0 ]

4.2 Naive vs. fixed on the double-step log

$ ./naive_lastsample.sh /tmp/kat2.log

4.000 STEP 0.500000 1.000000 0.000000 last-sample   <-- silently absorbed
5.000 STEP 0.000000 1.000000 0.000000 last-sample

The evaluator instead refuses and reports the second jump. This is the exact anomaly the problem requires.

4.3 Edge cases

  • empty input → no output, exit 0;
  • comments/blanks ignored;
  • all samples unusable (stratum>15, leap==3) → REJECT ... 0 no_consensus;
  • one falseticker among four → survivors=3 falsetickers=1;
  • negative offsets and mixed epoch spacing share one code path.
