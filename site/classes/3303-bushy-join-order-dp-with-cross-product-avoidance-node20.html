Bushy Join-Order DP with Cross-Product Avoidance (Node 20)

1. What the task actually asks for

Given a query hypergraph (relations + base cardinalities + predicate selectivities), find the cheapest bushy join tree and report two numbers:

  1. the optimal plan / cost, and
  2. the number of explored subplans, so a greedy planner's cost regression against the DP is measurable.

The specification pins down three non-obvious requirements:

  • Bushy, not left-deep: any two subplans may be joined.
  • Branch & bound: a connected subplan is discarded only when its estimated cost already exceeds the best complete plan found.
  • Cross-product avoidance (DPsize vs DPccp): predicate joins are tried first; joins with no crossing predicate (cartesian products) are deferred until all predicate pairs are exhausted. The dangerous part is memoization: once a set of relations has been solved by joining two disconnected components, the solution must be stored and reused, never re-derived through a different join order.

2. Root-cause analysis (the two traps)

Trap A — greedy cost regressions

A greedy "always join the next smallest relation" planner collapses to a left-deep tree and can pick a large intermediate before a very selective predicate is applied. Example used below:

R0 --(0.9)-- R1 --(0.001)-- R2 --(0.9)-- R3,  all base cards = 1000

The selective R1--R2 edge (selectivity 0.001) must be applied before R0/R3 are pulled in. This is only expressible as a bushy tree; left-deep enumeration misses it. Hence the DP must enumerate arbitrary bipartitions of every relation subset, not a fixed join order.

Trap B — naive DPsize re-derives cross-product subplans

The textbook DPsize recurrence for a subset S is

best[S] = min over all A subset of S, A != 0, A != S:
              cost(best[A]) + cost(best[S \ A]) + card(S)

For a disconnected S this enumerates every bipartition, including the same connected components in many different orders. Without a memo keyed by the subproblem, those cartesian subplans are rebuilt exponentially many times, the explored-subplan counter explodes, and the search can even report different costs depending on evaluation order (float summation).

The root cause is treating a disconnected subset as an unstructured set. The induced join graph of a subset has a unique partition into connected components, so the correct memo key is a connected-component bitset. In the implementation the relation mask already is that key: two partial plans with the same mask have the same components, so best[mask] is solved exactly once.

The correct DPccp ordering

Classic DPccp never considers cartesian products at all for connected graphs. Here cross products are still needed for genuinely disconnected queries, but they are deferred:

  • Phase A (per mask): only bipartitions spanned by a predicate (crossingEdge(A,B)). These are the connected pairs.
  • Phase B (per mask): only for masks whose induced graph is disconnected, enumerate the cartesian bipartitions. A connected mask never needs one: applying the crossing predicate at its top level can only make the intermediate smaller (selectivity ≤ 1), so any cartesian top-level join is dominated.

Each mask is visited once in increasing popcount order, so every subplan — connected or cartesian — is built and memoized exactly once.

3. Exact fix

/workspace/join_order.js:

'use strict';

/*
 * Bushy join-order DP with cross-product avoidance (DPccp) + branch & bound.
 *
 * Model
 * -----
 * A query hypergraph is given as:
 *   {
 *     relations:     [ "R0", "R1", ... ],          // names, index = relation id
 *     cardinalities: [ 1000, 200, ... ],           // base row counts
 *     predicates:    [ { relations:[0,1], selectivity: 0.1 }, ... ]  // hyper-edges
 *   }
 *
 * Cardinality of a *set* of relations S:
 *   card(S) = PROD_{i in S} base[i] * PROD_{e subset of S} e.selectivity
 * A predicate may only be applied once every relation it references is present.
 *
 * Cost model (hash joins): a join costs its output cardinality, and the cost of
 * a plan is the sum of the output cardinalities of every internal join (classic
 * "sum of intermediate results").  Leaves cost 0.  With selectivities <= 1 a
 * connected (predicate) join never produces more rows than the corresponding
 * cross product, so connected joins are preferred and cross products are only
 * used when a set is genuinely disconnected.
 *
 * Algorithm
 * ---------
 * 1. Greedy plan -> initial upper bound `bound`.
 * 2. DPsize over every relation subset, bottom up by popcount.  For each mask:
 *      phase A -- predicate joins  (an edge crosses the cut)
 *      phase B -- cross products   (deferred until all predicate pairs are done)
 *    Each candidate is memoized under its relation bitset, so a subplan produced
 *    by joining two disconnected components is built exactly once and never
 *    re-derived through a different join order.
 * 3. Branch & bound: a *connected* (predicate) candidate whose cost is >= the
 *    best full plan found so far is pruned.  Cross products are never pruned
 *    (they may be required to reconnect a disconnected graph).
 */

function popcount(x) {
  let c = 0;
  while (x) { x &= x - 1; c++; }
  return c;
}
function lowbit(x) { return x & -x; }
function bitIndex(b) { return 31 - Math.clz32(b); }

function normalizeInput(input) {
  const relations = input.relations || input.rels || input.tables;
  if (!Array.isArray(relations)) throw new Error('input.relations (array of names) is required');
  const n = relations.length;
  const cardinalities = input.cardinalities || input.cards;
  if (!Array.isArray(cardinalities) || cardinalities.length !== n) {
    throw new Error('input.cardinalities must be an array with one entry per relation');
  }
  const rawEdges = input.predicates || input.edges || input.hyperedges || [];
  const edges = [];
  for (const e of rawEdges) {
    const rels = e.relations || e.rels || (e.left !== undefined ? [e.left, e.right] : null);
    if (!rels || rels.length < 2) continue;
    let mask = 0;
    for (const r of rels) mask |= (1 << r);
    if (popcount(mask) < 2) continue;
    const sel = e.selectivity !== undefined ? e.selectivity
      : e.sel !== undefined ? e.sel : 1;
    edges.push({ mask, sel });
  }
  return { n, names: relations.slice(), base: cardinalities.slice(), edges, full: (1 << n) - 1 };
}

function makeJoinOrder(input) {
  const { n, names, base, edges, full } = normalizeInput(input);
  if (n > 30) throw new Error('this implementation supports at most 30 relations (32-bit masks)');

  // ---- cardinality of a relation set (all its internally contained predicates) ----
  const cardOfArr = new Float64Array(full + 1);
  const cardKnown = new Uint8Array(full + 1);
  function cardOf(mask) {
    if (mask === 0) return 1;
    if (cardKnown[mask]) return cardOfArr[mask];
    let p = 1;
    for (let i = 0; i < n; i++) if (mask & (1 << i)) p *= base[i];
    for (const e of edges) if ((e.mask & mask) === e.mask) p *= e.sel;
    cardOfArr[mask] = p;
    cardKnown[mask] = 1;
    return p;
  }

  // ---- connectivity of a relation set (union-find over fully contained edges) ----
  function componentsOf(mask) {
    const parent = new Int32Array(n);
    for (let i = 0; i < n; i++) parent[i] = i;
    const find = (x) => { while (parent[x] !== x) { parent[x] = parent[parent[x]]; x = parent[x]; } return x; };
    const union = (a, b) => { a = find(a); b = find(b); if (a !== b) parent[a] = b; };
    for (const e of edges) {
      if ((e.mask & mask) === e.mask) {
        let first = -1, m = e.mask;
        while (m) { const b = lowbit(m); m ^= b; const i = bitIndex(b); if (first < 0) first = i; else union(first, i); }
      }
    }
    const groups = new Map();
    let m = mask;
    while (m) {
      const b = lowbit(m); m ^= b;
      const i = bitIndex(b);
      const r = find(i);
      groups.set(r, (groups.get(r) || 0) | b);
    }
    return [...groups.values()];
  }
  const connCache = new Int8Array(full + 1).fill(-1);
  function isConnected(mask) {
    if (mask === 0) return false;
    const c = connCache[mask];
    if (c !== -1) return c === 1;
    const ok = componentsOf(mask).length <= 1 ? 1 : 0;
    connCache[mask] = ok;
    return ok === 1;
  }

  // does some predicate fully contained in A|B cross the cut A | B ?
  function crossingEdge(A, B) {
    const both = A | B;
    for (const e of edges) {
      if ((e.mask & both) === e.mask && (e.mask & A) !== 0 && (e.mask & B) !== 0) return true;
    }
    return false;
  }

  // canonical unordered bi-partitions of `mask`: A always contains the lowest bit.
  function forEachSplit(mask, cb) {
    const low = lowbit(mask);
    const rest = mask ^ low;
    let sub = rest;
    for (;;) {
      const A = low | sub;
      const B = mask ^ A;
      if (B !== 0) cb(A, B);
      if (sub === 0) break;
      sub = (sub - 1) & rest;
    }
  }

  function leaf(i) {
    return { type: 'rel', rel: i, name: names[i], mask: 1 << i, card: cardOf(1 << i), cost: 0 };
  }
  function recomputeCost(node) {
    if (!node || node.type === 'rel') return 0;
    return recomputeCost(node.left) + recomputeCost(node.right) + node.card;
  }

  // ---- greedy upper bound --------------------------------------------------
  function greedyPlan() {
    const items = [];
    for (let i = 0; i < n; i++) items.push(leaf(i));
    while (items.length > 1) {
      let pick = -1, pickJ = -1, pickCross = true, bestKey = Infinity;
      for (let pass = 0; pass < 2 && pick < 0; pass++) {
        const wantCross = pass === 1;
        for (let i = 0; i < items.length; i++) {
          for (let j = i + 1; j < items.length; j++) {
            const A = items[i], B = items[j];
            const cross = !crossingEdge(A.mask, B.mask);
            if (cross !== wantCross) continue;
            const card = cross ? A.card * B.card : cardOf(A.mask | B.mask);
            if (card < bestKey) { bestKey = card; pick = i; pickJ = j; pickCross = cross; }
          }
        }
      }
      const A = items[pick], B = items[pickJ];
      const mask = A.mask | B.mask;
      const card = pickCross ? A.card * B.card : cardOf(mask);
      const node = {
        type: 'join', cross: pickCross, mask, card,
        cost: A.cost + B.cost + card, left: A, right: B,
      };
      items.splice(pickJ, 1);
      items.splice(pick, 1);
      items.push(node);
    }
    return items[0] || null;
  }

  const greedy = greedyPlan();
  const bound = greedy ? greedy.cost : Infinity;
  if (n === 0) return { plan: null, cost: 0, explored: 0, pruned: 0, memoized: 0, bound, greedyCost: 0, connected: false, components: 0 };

  // ---- DPsize over all masks, predicate joins before cross products --------
  const best = new Array(full + 1).fill(null);
  const groups = Array.from({ length: n + 1 }, () => []);
  for (let mask = 1; mask <= full; mask++) groups[popcount(mask)].push(mask);

  let explored = 0;
  let pruned = 0;
  let crossUpdates = 0;      // times a cross-product candidate improved a mask
  let connectedUpdates = 0;  // times a predicate candidate improved a mask
  let memoized = 0;

  for (let size = 1; size <= n; size++) {
    for (const mask of groups[size]) {
      if (size === 1) { best[mask] = leaf(bitIndex(mask)); memoized++; continue; }

      // phase A: predicate joins (connected pairs)
      forEachSplit(mask, (A, B) => {
        const pa = best[A], pb = best[B];
        if (!pa || !pb) return;
        if (!crossingEdge(A, B)) return;
        explored++;
        const card = cardOf(mask);
        const cost = pa.cost + pb.cost + card;
        if (mask !== full && cost >= bound) { pruned++; return; }
        if (!best[mask] || cost < best[mask].cost) {
          best[mask] = { type: 'join', cross: false, mask, card, cost, left: pa, right: pb };
          connectedUpdates++;
        }
      });

      // phase B: cross products, deferred until all predicate pairs are done.
      // DPccp distinction: a connected mask never needs a cross product at its
      // top level (applying a crossing predicate first can only reduce rows), so
      // cross products are generated only for genuinely disconnected masks.
      if (!isConnected(mask)) forEachSplit(mask, (A, B) => {
        const pa = best[A], pb = best[B];
        if (!pa || !pb) return;
        if (crossingEdge(A, B)) return;          // already handled in phase A
        explored++;
        const card = pa.card * pb.card;          // no predicate across the cut
        const cost = pa.cost + pb.cost + card;
        if (!best[mask] || cost < best[mask].cost) {
          best[mask] = { type: 'join', cross: true, mask, card, cost, left: pa, right: pb };
          crossUpdates++;
        }
      });

      if (best[mask]) memoized++;
    }
  }

  const root = best[full];
  const verifiedCost = recomputeCost(root);

  return {
    plan: root,
    cost: root ? root.cost : 0,
    verifiedCost,
    explored,
    pruned,
    memoized,
    connectedUpdates,
    crossUpdates,
    bound,
    greedyCost: greedy ? greedy.cost : 0,
    connected: isConnected(full),
    components: componentsOf(full).length,
  };
}

/* ------------------------------------------------------------------ */
/* Reference brute force: full DPsize, every split, no pruning.        */
/* Used only to verify optimality of the main search.                  */
/* ------------------------------------------------------------------ */
function bruteForce(input) {
  const { n, base, edges, full } = normalizeInput(input);
  function cardOf(mask) {
    if (mask === 0) return 1;
    let p = 1;
    for (let i = 0; i < n; i++) if (mask & (1 << i)) p *= base[i];
    for (const e of edges) if ((e.mask & mask) === e.mask) p *= e.sel;
    return p;
  }
  function crossingEdge(A, B) {
    const both = A | B;
    for (const e of edges) if ((e.mask & both) === e.mask && (e.mask & A) !== 0 && (e.mask & B) !== 0) return true;
    return false;
  }
  const best = new Array(full + 1).fill(null);
  for (let mask = 1; mask <= full; mask++) {
    if (popcount(mask) === 1) {
      const i = bitIndex(mask);
      best[mask] = { type: 'rel', rel: i, mask, card: cardOf(mask), cost: 0 };
      continue;
    }
    const low = lowbit(mask), rest = mask ^ low;
    let sub = rest;
    for (;;) {
      const A = low | sub, B = mask ^ A;
      if (B !== 0 && best[A] && best[B]) {
        const cross = !crossingEdge(A, B);
        const card = cross ? best[A].card * best[B].card : cardOf(mask);
        const cost = best[A].cost + best[B].cost + card;
        if (!best[mask] || cost < best[mask].cost) {
          best[mask] = { type: 'join', cross, mask, card, cost, left: best[A], right: best[B] };
        }
      }
      if (sub === 0) break;
      sub = (sub - 1) & rest;
    }
  }
  return best[full];
}

function planToString(node, indent = '') {
  if (!node) return '<empty>';
  if (node.type === 'rel') return `${node.name}`;
  const tag = node.cross ? ' CROSS' : '';
  const l = planToString(node.left, indent + '  ');
  const r = planToString(node.right, indent + '  ');
  return `JOIN${tag} (card=${fmt(node.card)}, cost=${fmt(node.cost)}) [\n${indent}  ${l}\n${indent}  ${r}\n${indent}]`;
}
function fmt(x) {
  if (!isFinite(x)) return String(x);
  return Math.round(x * 1e6) / 1e6;
}

function mulberry32(a) {
  return function () {
    a |= 0; a = (a + 0x6D2B79F5) | 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

Why this verifies the hard edge

  • memoized === 2^n - 1 on the disconnected 4-relation example means every subset (including every cartesian subplan) was stored exactly once — no subplan was re-derived.
  • The randomized differential test shows the DP finds a plan with cost equal to the exhaustive search on all 1000 graphs, so deferring cross products did not lose optimality.
  • The disconnected plan contains exactly one CROSS node and two predicate joins, confirming cartesian products appear only between finished connected components.
  • pruned > 0 on the deterministic example confirms branch & bound is actually discarding connected subplans whose cost already exceeds the best complete plan.
  • verifiedCost === cost confirms the memoized cost matches a fresh tree traversal.

5. Complexity / notes

  • Masks are 32-bit, so up to 30 relations. Subset DP is O(3^n) bipartition enumeration; the DPccp csg-cmp enumeration is the standard next optimization, but the correctness-critical part — the connected-component memoization and the phase-A/phase-B deferral — is identical.
  • Cardinality of a relation set is plan-independent: card(S) = prod(base_i) * prod(sel_e for e subset of S), which is what makes the overlapping-subproblem DP valid.
  • Cost is the classic sum of intermediate result sizes (hash-join model): a join costs its output cardinality, leaves cost 0.
