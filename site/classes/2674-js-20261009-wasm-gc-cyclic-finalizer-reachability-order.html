Wasm-GC Cyclic Heap with Weak Refs, Ephemerons, Finalizers, and Incremental Slices

1. Diagnosis / root cause

This problem class looks like a simple mark-and-sweep, but four independent mechanics interact, and each one is a classic source of wrong answers:

  1. Cycles vs. reachability. The collector must be a reachability analysis from roots, not a reference count. A cycle with no root is garbage; a cycle reachable from a root is fully live.*
  2. Weak references are not roots, but they must be cleared deterministically when their target dies. The trap is clearing too early: if you clear during marking and then a mutation/finalizer makes the target reachable, you produce a dangling/incorrectly-cleared weak cell. Weak clearing must happen against the final live set, after finalizers run.
  3. Ephemerons are not ordinary edges. {key, value} keeps the value alive iff the key is alive, and this is a fixed point: marking a value can mark another ephemeron's key, etc. A single pass leaks or over-collects. Chains/cycles require iteration to a fixed point.
  4. Finalizers and resurrection. An unreachable finalizable object must be retained one collection so its finalizer can run, and its reachable closure retained too (else the finalizer sees freed memory). Finalizers run at most once and may resurrect. The bug is "incorrect resurrection": reviving a finalized/swept object, or restoring an already-cleared weak ref.
  5. Incremental slices break naive marking. Between slices the mutator can create a BLACK → WHITE edge; the white target is never scanned and a live object is collected. The fix is a write barrier (shade the target grey), plus the same treatment for ephemeron updates and allocate-grey.

Observable output = survivors + finalization order. Determinism requires a fixed order (here: allocation registration order).

2. Normative semantics + invariants

  • R1 root keeps target live. R2 strong edges transitive. R3 weak never retains, cleared against final live set. R4 ephemeron {key,value} retains value iff cell live and key live, iterated to fixed point. R5 unreachable unfinalized finalizable object + closure retained one cycle; finalizer exactly once; reclaimed if not resurrected. R6 unreachable non-finalizable / already-finalized swept. R7 no post-sweep resurrection (stale handles throw).

  • INV-1 no BLACK → WHITE edge (Dijkstra insertion barrier).

  • INV-2 ephemeron added/changed on a BLACK cell with live key shades the value.
  • INV-3 weak edges never shade; cleared only after finalizers + final live set.
  • INV-4 finalized flag set before callback (at-most-once).
  • INV-5 a queued finalizable object is shaded with full strong closure + ephemeron fixpoint.

3. The fix — complete simulator (gc.js)

'use strict';

/*
 * Deterministic simulator for a Wasm-GC-style managed heap with:
 *   - strong references and reference cycles
 *   - weak references
 *   - ephemerons (key is weak, value is strong iff key is strongly live)
 *   - finalizers with at-most-once semantics and documented ordering
 *   - incremental (slice-based) marking with a mutation write barrier
 *
 * Reachability rules implemented (the normative spec of this module):
 *   R1. A root keeps its target strongly live.
 *   R2. A strong edge from a live object keeps its target live (transitive).
 *   R3. A weak edge never keeps its target live. A weak reference whose target
 *       is not live at the end of a collection is cleared (permanently).
 *   R4. An ephemeron E is a cell {key, value}. If E is live and E.key is live,
 *       then E.value is live. This is iterated to a fixed point (handles
 *       transitive/cyclic ephemeron chains).
 *   R5. An unreachable object with an unfired finalizer is retained (together
 *       with its strong closure) for one collection. Its finalizer runs at the
 *       end of that collection, exactly once. After it fires it may be
 *       resurrected by the finalizer; otherwise it is collected next cycle.
 *   R6. Unreachable objects without finalizers (or whose finalizer already
 *       fired) are swept.
 *   R7. No object is ever resurrected after it has been swept: handles to
 *       swept objects become invalid and mutation attempts throw.
 *
 * Incremental correctness (tri-color invariant):
 *   INV-1 (no black -> white edge). During incremental marking, mutating a
 *         BLACK object to point at a WHITE object shades the WHITE object
 *         GREY (Dijkstra insertion barrier). This guarantees every object
 *         live at the end of the increment is marked.
 *   INV-2 (ephemeron consistency). Setting/altering an ephemeron on a BLACK
 *         cell whose key is already live shades the value.
 *   INV-3 (weak safety). Weak edges never shade; they are cleared only after
 *         finalizers have run and the final live set is fixed, so a finalizer
 *         resurrection cannot leave a dangling/restored weak reference.
 *
 * Determinism:
 *   - Traversal/graph iteration is ordered by object registration index (the
 *     order objects were allocated).
 *   - Finalizers fire in registration-index order.
 */

const WHITE = 0;
const GREY = 1;
const BLACK = 2;

class HeapObject {
  constructor(id, reg) {
    this.id = id;
    this.reg = reg;
    this.strong = new Set(); // ids of strong targets
    this.weak = new Set();   // ids of weak targets
    this.ephemeron = null;   // { key: id, value: id }
    this.finalizer = null;   // { label, fn }
    this.color = WHITE;
    this.alive = true;
    this.finalized = false;
    this.pending = false;    // retained for finalization this cycle
  }
}

class GC {
  constructor() {
    this.objects = new Map();
    this.roots = new Set();
    this.finalizationLog = [];
    this.weakClearLog = [];
    this.barrierActivations = 0;
    this._counter = 0;
    this._reg = 0;
    this._grey = [];
    this.inc = null;
  }

  // ------------------------------------------------------------------ heap
  newObject(id) {
    if (id === undefined) id = `o${this._counter++}`;
    id = String(id);
    if (this.objects.has(id)) throw new Error(`duplicate object id: ${id}`);
    const o = new HeapObject(id, this._reg++);
    this.objects.set(id, o);
    if (this.inc && this.inc.active) this._shade(o); // allocate-grey: never lost
    return o;
  }

  obj(id) { return this.objects.get(String(id)); }

  _must(id) {
    const o = this.objects.get(String(id));
    if (!o) throw new Error(`no such object (collected or never allocated): ${id}`);
    return o;
  }

  addRoot(id) {
    const o = this._must(id);
    this.roots.add(o);
    if (this.inc && this.inc.active) this._shade(o);
    return o;
  }

  removeRoot(id) { this.roots.delete(this._must(id)); }

  setStrong(fromId, toId) {
    const from = this._must(fromId);
    this._must(toId).alive = true;
    from.strong.add(String(toId));
    if (this.inc && this.inc.active) this._writeBarrier(from, String(toId));
  }

  deleteStrong(fromId, toId) { this._must(fromId).strong.delete(String(toId)); }

  setWeak(fromId, toId) {
    this._must(fromId).weak.add(String(toId));
  }

  deleteWeak(fromId, toId) { this._must(fromId).weak.delete(String(toId)); }

  setEphemeron(ephId, keyId, valueId) {
    const eph = this._must(ephId);
    eph.ephemeron = { key: String(keyId), value: String(valueId) };
    this._must(keyId);
    this._must(valueId);
    if (this.inc && this.inc.active) this._ephemeronBarrier(eph);
  }

  clearEphemeron(ephId) { this._must(ephId).ephemeron = null; }

  setFinalizer(id, label, fn) {
    this._must(id).finalizer = { label, fn: fn || null };
  }

  // -------------------------------------------------------- marking engine
  _resetMarks() {
    for (const o of this.objects.values()) {
      o.color = WHITE;
      o.pending = false;
    }
    this._grey.length = 0;
  }

  _shade(o) {
    if (o && o.alive && o.color === WHITE) {
      o.color = GREY;
      this._grey.push(o);
    }
  }

  _processGrey(limit = Infinity) {
    let n = 0;
    while (this._grey.length > 0 && n < limit) {
      const o = this._grey.pop();
      if (o.color !== GREY) continue;
      for (const tid of o.strong) this._shade(this.objects.get(tid));
      o.color = BLACK;
      n++;
    }
    return this._grey.length === 0;
  }

  _markRoots() { for (const o of this.roots) this._shade(o); }

  _sortedObjects() {
    return [...this.objects.values()].sort((a, b) => a.reg - b.reg);
  }

  _ephemeronFixpoint() {
    let changed = true;
    while (changed) {
      changed = false;
      for (const o of this._sortedObjects()) {
        if (o.color === WHITE || !o.ephemeron) continue;
        const key = this.objects.get(o.ephemeron.key);
        if (!key || key.color === WHITE) continue;
        const val = this.objects.get(o.ephemeron.value);
        if (!val || val.color !== WHITE) continue;
        this._shade(val);
        this._processGrey();
        changed = true;
      }
    }
  }

  // Retain every unreachable, unfinalized, finalizable object plus its strong
  // closure. Iterated with ephemerons to a joint fixed point. Returns newly
  // queued objects (in registration order).
  _retainUnreachableFinalizable() {
    const queued = [];
    let changed = true;
    while (changed) {
      changed = false;
      this._ephemeronFixpoint();
      for (const o of this._sortedObjects()) {
        if (o.color === WHITE && o.finalizer && !o.finalized && !o.pending) {
          o.pending = true;
          queued.push(o);
          this._shade(o);
          this._processGrey();
          changed = true;
        }
      }
    }
    this._ephemeronFixpoint();
    return queued;
  }

  _runFinalizers(queued) {
    queued.sort((a, b) => a.reg - b.reg); // deterministic, documented order
    for (const o of queued) {
      if (o.finalized) continue;
      o.finalized = true;            // at-most-once, before the callback runs
      this.finalizationLog.push(o.finalizer.label);
      if (o.finalizer.fn) o.finalizer.fn(o, this);
    }
    for (const o of queued) o.pending = false;
  }

  _clearWeak() {
    for (const o of this._sortedObjects()) {
      if (o.color === WHITE) continue; // owner is dying; its weak cells vanish
      for (const tid of [...o.weak]) {
        const t = this.objects.get(tid);
        if (!t || t.color === WHITE) {
          o.weak.delete(tid);
          this.weakClearLog.push({ from: o.id, to: tid });
        }
      }
    }
    return this.weakClearLog;
  }

  _sweep() {
    for (const o of [...this.objects.values()]) {
      if (o.color === WHITE) {
        o.alive = false;
        this.objects.delete(o.id);
      }
    }
  }

  _finalMark() {
    this._resetMarks();
    this._markRoots();
    this._processGrey();
    this._ephemeronFixpoint();
  }

  _report() {
    return {
      alive: [...this.objects.values()].map((o) => o.id).sort(),
      finalized: [...this.finalizationLog],
      clearedWeak: [...this.weakClearLog],
      barrierActivations: this.barrierActivations,
    };
  }

  // ------------------------------------------------------- full collection
  collectFull() {
    // Phase A: mark roots + strong closure + ephemerons.
    this._finalMark();
    // Phase B: retain unreachable finalizable objects and run their finalizers.
    const queued = this._retainUnreachableFinalizable();
    this._runFinalizers(queued);
    // Phase C: final live set from current roots. Any object that became
    // unreachable as a side effect of finalization and still needs a finalizer
    // is retained but deferred to the NEXT collection (no cascade this cycle),
    // matching a single-generation finalization queue.
    this._finalMark();
    const deferred = this._retainUnreachableFinalizable();
    for (const o of deferred) o.pending = false;
    // Phase D: clear weak refs against the fixed live set, then sweep.
    this._clearWeak();
    this._sweep();
    return this._report();
  }

  // -------------------------------------------------- incremental collection
  startIncremental() {
    if (this.inc && this.inc.active) throw new Error('incremental collection already active');
    this._resetMarks();
    this.inc = { active: true };
    this._markRoots();
    return this;
  }

  // Process at most `budget` grey objects. Returns true when no grey work and
  // the ephemeron fixed point is stable.
  step(budget = 1) {
    if (!this.inc || !this.inc.active) throw new Error('no active incremental collection');
    this._processGrey(budget);
    if (this._grey.length === 0) {
      this._ephemeronFixpoint();
      return this._grey.length === 0;
    }
    return false;
  }

  isMarkingComplete() {
    if (!this.inc || !this.inc.active) return false;
    return this._grey.length === 0 && this._ephemeronsStable();
  }

  _ephemeronsStable() {
    for (const o of this.objects.values()) {
      if (o.color === WHITE || !o.ephemeron) continue;
      const key = this.objects.get(o.ephemeron.key);
      const val = this.objects.get(o.ephemeron.value);
      if (key && key.color !== WHITE && val && val.color === WHITE) return false;
    }
    return true;
  }

  // Dijkstra insertion barrier: BLACK -> WHITE becomes BLACK -> GREY.
  _writeBarrier(from, toId) {
    if (from.color === BLACK) {
      const t = this.objects.get(toId);
      if (t && t.color === WHITE) {
        this._shade(t);
        this.barrierActivations++;
      }
    }
  }

  _ephemeronBarrier(eph) {
    if (eph.color !== BLACK || !eph.ephemeron) return;
    const key = this.objects.get(eph.ephemeron.key);
    const val = this.objects.get(eph.ephemeron.value);
    if (key && key.color !== WHITE && val && val.color === WHITE) {
      this._shade(val);
      this.barrierActivations++;
    }
  }

  finishIncremental() {
    if (!this.inc || !this.inc.active) throw new Error('no active incremental collection');
    while (!this._processGrey(4096)) { /* drain */ }
    this._ephemeronFixpoint();
    const queued = this._retainUnreachableFinalizable();
    this._runFinalizers(queued);
    this.inc.active = false;
    // Final live set with deferred finalizable retention (no cascade).
    this._finalMark();
    const deferred = this._retainUnreachableFinalizable();
    for (const o of deferred) o.pending = false;
    this._clearWeak();
    this._sweep();
    this.inc = null;
    return this._report();
  }
}

module.exports = { GC, WHITE, GREY, BLACK };

5. Implementation notes

  • Fixed-point ordering by allocation registration index → deterministic finalization order.
  • Ephemeron barrier on black cells prevents losing a value in incremental mode.
  • Allocate-grey mid-cycle prevents newly allocated objects from being lost.
  • Newly-unreachable finalizable objects found in the final pass are retained but deferred to the next collection (no unbounded same-cycle cascade).
  • _must throws on collected handles → no post-sweep resurrection.
