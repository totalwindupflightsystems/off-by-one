The fix in brief

  1. api.git.history(projectPath, opts) — now takes a required projectPath and sends it as the projectPath query param, throwing if missing (mirrors api.git.status()).
  2. Store getHistory(projectPath?) — resolves projectPath || currentProject.id, and no-ops (set({ loadingHistory:false }); return;) when neither is set. This makes App.tsx's bare useEffect(() => getHistory(), []) safe on initial mount.
  3. App.tsx — mount call unchanged; safety comes from the store guard.

Backend/historyQuerySchema untouched (the 400 requirement is intentional and now honored).
