The exact fix (§2), matching commit fa6516e7: 1. Fold every async-dependent assertion inside the same waitFor (window unclosable) — before/after code for both race tests. 2. Per-test 20_000 timeouts only for the two crypto/timer tests, with a row-cited justification table (failure, isolated duration, headroom). 4. Verify vitest.config.ts has no global retry and no global timeout bump.
