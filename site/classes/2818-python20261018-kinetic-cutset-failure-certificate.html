Kinetic Cutset with Failure Certificates — Diagnosis and Verified Fix

Problem class: python20261018-kinetic-cutset-failure-certificate Environment: Python 3.11+ (verified on CPython 3.14.4)

1. Executive diagnosis

Read literally, the task is not well-posed and not solvable as stated. It bundles requirements that are individually reasonable but jointly impossible at the stated generality:

  1. "designated terminals" (plural) hides an NP-hard problem as soon as there are three or more terminals.
  2. exact fully dynamic min-cut under adversarial vertex toggles is a longstanding open problem; the requested amortised bound cannot exist in the general case.
  3. a cut is not a certificate of optimality — a partition only proves an upper bound. Verifying minimality needs the dual (a flow of equal value).
  4. "capacities that change on activation" is undefined — several semantics give different answers.
  5. parallel edges, self-loops, inactive terminals are unspecified and change the flow representation.

The fix: pin down one precise tractable semantics, restrict to two terminals, emit a verifiable (value, cut, flow) certificate, and state the amortised bound honestly.

2. Root-cause analysis

RC1 — Plural terminals ⇒ NP-hardness

k-terminal "min-cost cut" is minimum multiway cut. For k ≥ 3 it is NP-hard (Dalhaus–Johnson–Papadimitriou–Seymour–Yannakakis, SIAM J. Comput. 1994), even unit-capacity 3-terminal. Only k = 2 (min s-t cut) is tractable via max-flow/min-cut.

RC2 — Exact dynamic min-cut has no known sublinear update bound

Deactivation removes edges; if flow routes through them it becomes infeasible and must be cancelled. Decremental max-flow is essentially as hard as static max-flow — one deletion can destroy Θ(C) units of flow and force near-full recomputation. Hence no amortised bound better than O(U · T_flow) is known; any claim of polylog/O(1) updates is false.

RC3 — A cut is only a primal certificate; optimality needs the dual

A partition (S, V∖S) only certifies λ ≤ cut(S). Minimality requires an s-t flow of equal value (feasibility + conservation + capacity). Without the dual, verifying a claimed min-cut is as hard as computing one. Certificate must be (value, cut, flow), size O(n+m).

RC4 — Activation semantics undefined

We fix the natural induced-subgraph model: edge (u,v) is usable iff active[u] and active[v]; an update flips one flag, adding/removing all incident edges. Self-loops ignored.

RC5 — Parallel edges / inactive terminals

Keep parallel edges as separate records for certificate alignment. If s is inactive the min cut is 0 with source side {s}; if t is inactive, 0 with source side V∖{t}.

3. The exact fix

3.1 Precise problem solved

Directed graph, integer capacities, distinct terminals s,t, boolean active[v]; edge usable iff both endpoints active. After each toggle emit (value, cut, flow).

3.2 Algorithm

Build active-induced arcs → iterative Dinic (no recursion, safe for |V|≈2·10⁵) → value = maxflow(s,t) → cut = residual-reachable from s → flow[e] = base − residual. Inactive-terminal shortcuts per RC5.

3.3 Monotone warm start

Activation-only sequences keep the previous flow feasible; continue Dinic on the residual graph (MonotoneCutset).

3.4 Correctness

Max-flow/min-cut gives residual S with s ∈ S, t ∉ S and all crossing edges saturated, so cut(S) = Σ f_e = value; conservation holds by residual construction. Adding capacity preserves feasibility, and Dinic on the residual terminates exactly at optimality. ∎

3.5 Amortised analysis

  • General toggles: O(U · T_Dinic), O(n+m) memory. Not improvable: toggling one capacity-C edge forces Θ(C) pushes per deactivation, so no capacity-independent amortised bound exists — the original request is over-strong.
  • Activation-only: each augmentation pushes ≥ 1 unit and flow never decreases ⇒ at most C augmentations total (C = capacity ever activated), O((C+U)·m) total, i.e. O((C/U + 1)·m) amortised per update.
  • Certificate: O(n) cut + O(m) flow; full third-party verification needs the flow.

#!/usr/bin/env python3
"""
kinetic_cutset.py -- Dynamic minimum s-t cut with optimality certificates.

Model (the tractable, precisely-specified version of the task)
--------------------------------------------------------------
Directed graph G = (V, E), integer capacities c_e >= 0, two distinct
terminals s, t in V.  Every vertex carries a boolean *active* flag.  An edge
e = (u, v) is *usable at time k* iff active[u] and active[v] (self-loops are
ignored).  A vertex update flips the active flag of one vertex, which
simultaneously adds or removes all edges incident to it ("capacities change
on activation").

After every update `query()` returns a certificate

    (value, cut, flow)

where
    value = min s-t cut value of the active-induced subgraph,
    cut   = source side S of a minimum cut (s in S, t not in S),
    flow  = a feasible s-t flow with value `value`.

`flow` is the dual (primal) witness that the cut really is minimum; a cut
alone only proves an upper bound.  By max-flow/min-cut the two agree.
"""

from collections import deque
import random


# --------------------------------------------------------------------------- #
#  Iterative Dinic max flow
# --------------------------------------------------------------------------- #
class Dinic:
    def __init__(self, n):
        self.n = n
        # each edge: [to, rev_index, residual_cap, original_edge_ref, base_cap]
        self.g = [[] for _ in range(n)]

    def add_edge(self, u, v, c, ref=-1):
        self.g[u].append([v, len(self.g[v]), c, ref, c])
        self.g[v].append([u, len(self.g[u]) - 1, 0, -1, 0])

    def _send(self, s, t, level, ptr):
        """Push one augmenting path in the current level graph (0 if none)."""
        g = self.g
        stack = [s]
        path = []                       # list of (vertex, edge_index)
        while stack:
            u = stack[-1]
            if u == t:
                f = min(g[a][b][2] for a, b in path)
                for a, b in path:
                    e = g[a][b]
                    e[2] -= f
                    g[e[0]][e[1]][2] += f
                return f
            moved = False
            while ptr[u] < len(g[u]):
                idx = ptr[u]
                e = g[u][idx]
                if e[2] > 0 and level[e[0]] == level[u] + 1:
                    path.append((u, idx))
                    stack.append(e[0])
                    moved = True
                    break
                ptr[u] += 1
            if moved:
                continue
            level[u] = -1               # dead end: drop from level graph
            stack.pop()
            if path:
                path.pop()
        return 0

    def max_flow(self, s, t):
        total = 0
        while True:
            level = [-1] * self.n
            level[s] = 0
            q = deque([s])
            while q:
                u = q.popleft()
                for e in self.g[u]:
                    if e[2] > 0 and level[e[0]] < 0:
                        level[e[0]] = level[u] + 1
                        q.append(e[0])
            if level[t] < 0:
                break
            ptr = [0] * self.n
            while True:
                f = self._send(s, t, level, ptr)
                if not f:
                    break
                total += f
        return total

    def reachable(self, s):
        """Residual reachability from s -> source side of the min cut."""
        seen = [False] * self.n
        seen[s] = True
        q = deque([s])
        while q:
            u = q.popleft()
            for e in self.g[u]:
                if e[2] > 0 and not seen[e[0]]:
                    seen[e[0]] = True
                    q.append(e[0])
        return seen

    def edge_flows(self, m):
        fl = [0] * m
        for u in range(self.n):
            for e in self.g[u]:
                if e[3] >= 0:
                    fl[e[3]] = e[4] - e[2]
        return fl


# --------------------------------------------------------------------------- #
#  Dynamic solver
# --------------------------------------------------------------------------- #
class KineticCutset:
    def __init__(self, n, s, t, edges, active):
        self.n, self.s, self.t = n, s, t
        self.edges = list(edges)            # (u, v, capacity)
        self.active = [bool(x) for x in active]
        self.history = []

    def _graph(self):
        d = Dinic(self.n)
        for i, (u, v, c) in enumerate(self.edges):
            if u != v and c > 0 and self.active[u] and self.active[v]:
                d.add_edge(u, v, c, i)
        return d

    def query(self):
        s, t, n = self.s, self.t, self.n
        m = len(self.edges)
        if not self.active[s]:
            cert = (0, [s], [0] * m)
        elif not self.active[t]:
            cert = (0, [i for i in range(n) if i != t], [0] * m)
        else:
            d = self._graph()
            val = d.max_flow(s, t)
            reach = d.reachable(s)
            cert = (val, [i for i in range(n) if reach[i]], d.edge_flows(m))
        self.history.append(cert)
        return cert

    def update(self, v, state):
        self.active[v] = bool(state)


# --------------------------------------------------------------------------- #
#  Certificate checker
# --------------------------------------------------------------------------- #
def verify_certificate(n, s, t, edges, active, cert):
    val, cut, flow = cert
    S = set(cut)
    if s not in S:
        return False, "s is not on the source side"
    if t in S:
        return False, "t is on the source side"
    if val < 0:
        return False, "negative cut value"

    cutcap = 0
    for (u, v, c) in edges:
        if u != v and active[u] and active[v] and u in S and v not in S:
            cutcap += c
    if cutcap != val:
        return False, "cut capacity %d != claimed value %d" % (cutcap, val)

    if len(flow) != len(edges):
        return False, "flow vector has wrong length"

    bal = [0] * n                    # bal[x] = outflow - inflow
    for i, (u, v, c) in enumerate(edges):
        f = flow[i]
        if f < 0:
            return False, "edge %d has negative flow" % i
        usable = c if (u != v and active[u] and active[v]) else 0
        if f > usable:
            return False, "edge %d flow %d exceeds usable cap %d" % (i, f, usable)
        if f:
            bal[u] += f
            bal[v] -= f
    for x in range(n):
        if x in (s, t):
            continue
        if bal[x] != 0:
            return False, "flow conservation fails at vertex %d (%d)" % (x, bal[x])
    if bal[s] != val:
        return False, "flow value %d != cut value %d" % (bal[s], val)
    if bal[t] != -val:
        return False, "flow into sink wrong"
    return True, "ok"


# --------------------------------------------------------------------------- #
#  Brute force (tiny graphs): enumerate every s-t cut
# --------------------------------------------------------------------------- #
def brute_min_cut(n, s, t, edges, active):
    others = [x for x in range(n) if x not in (s, t)]
    best = None
    for mask in range(1 << len(others)):
        S = {s}
        for j, x in enumerate(others):
            if (mask >> j) & 1:
                S.add(x)
        cap = 0
        for (u, v, c) in edges:
            if u != v and active[u] and active[v] and u in S and v not in S:
                cap += c
        if best is None or cap < best:
            best = cap
    return best


# --------------------------------------------------------------------------- #
#  Randomised differential test
# --------------------------------------------------------------------------- #
def random_test(trials=4000, seed=20261018):
    rnd = random.Random(seed)
    for trial in range(trials):
        n = rnd.randint(2, 7)
        s, t = 0, 1
        m = rnd.randint(0, 18)
        edges = [(rnd.randrange(n), rnd.randrange(n), rnd.randint(0, 6))
                 for _ in range(m)]                       # parallel edges allowed
        active = [rnd.random() < 0.7 for _ in range(n)]
        kc = KineticCutset(n, s, t, edges, active)
        for step in range(rnd.randint(1, 12)):
            v = rnd.randrange(n)                          # may toggle s or t
            kc.update(v, rnd.random() < 0.5)
            cert = kc.query()
            ok, msg = verify_certificate(n, s, t, edges, kc.active, cert)
            if not ok:
                return "INVALID cert trial=%d step=%d: %s" % (trial, step, msg)
            bf = brute_min_cut(n, s, t, edges, kc.active)
            if cert[0] != bf:
                return "MISMATCH trial=%d step=%d: solver=%d brute=%d" % (
                    trial, step, cert[0], bf)
    return "all %d randomised trials passed" % trials


# --------------------------------------------------------------------------- #
#  Monotone (activation-only) warm-start solver
# --------------------------------------------------------------------------- #
class MonotoneCutset:
    """Activation-only variant.

    The usable graph only grows, so a previous feasible flow stays feasible.
    We keep the residual graph and continue Dinic from the current flow
    instead of recomputing: each newly added unit of capacity can be pushed
    at most once, giving the amortised bound proved in the write-up.
    """

    def __init__(self, n, s, t, edges, active):
        self.n, self.s, self.t = n, s, t
        self.edges = list(edges)
        self.active = [bool(x) for x in active]
        self.d = Dinic(n)
        self.added = set()
        self.value = 0
        for i, (u, v, c) in enumerate(self.edges):
            if u != v and c > 0 and self.active[u] and self.active[v]:
                self.d.add_edge(u, v, c, i)
                self.added.add(i)
        self.value = self.d.max_flow(s, t)

    def activate(self, v):
        if self.active[v]:
            return
        self.active[v] = True
        for i, (u, w, c) in enumerate(self.edges):
            if i in self.added:
                continue
            if u != w and c > 0 and (u == v or w == v) \
                    and self.active[u] and self.active[w]:
                self.d.add_edge(u, w, c, i)
                self.added.add(i)
        self.value += self.d.max_flow(self.s, self.t)

    def query(self):
        reach = self.d.reachable(self.s)
        return self.value, [i for i in range(self.n) if reach[i]], \
            self.d.edge_flows(len(self.edges))


if __name__ == "__main__":
    print(random_test())

#!/usr/bin/env python3
"""
verify.py -- reproducibility harness for the kinetic cutset solution.

Run:  python3 verify.py
It performs, in order:
  1. brute-force differential test (random toggles, parallel edges)
  2. independent Edmonds-Karp max-flow cross-check
  3. certificate tamper tests (checker must reject bad certificates)
  4. terminal-deactivation edge cases
  5. monotone warm-start vs. from-scratch recomputation
  6. 2e5-edge throughput sanity check
"""
import random
import time
from collections import deque

from kinetic_cutset import (
    Dinic, KineticCutset, MonotoneCutset, brute_min_cut, verify_certificate,
)


# --------------------------------------------------------------------------- #
def edmonds_karp_maxflow(n, s, t, arcs):
    """Independent reference max flow. Returns (value, source_side bool list)."""
    to, cap, nxt, head = [], [], [], [-1] * n

    def add(u, v, c):
        to.append(v); cap.append(c); nxt.append(head[u]); head[u] = len(to) - 1
        to.append(u); cap.append(0); nxt.append(head[v]); head[v] = len(to) - 1

    for u, v, c in arcs:
        if u != v and c > 0:
            add(u, v, c)
    val = 0
    while True:
        par = [-1] * n
        pe = [-1] * n
        par[s] = s
        q = deque([s])
        while q and par[t] < 0:
            u = q.popleft()
            e = head[u]
            while e != -1:
                if cap[e] > 0 and par[to[e]] < 0:
                    par[to[e]] = u
                    pe[to[e]] = e
                    q.append(to[e])
                e = nxt[e]
        if par[t] < 0:
            break
        f = 1 << 60
        v = t
        while v != s:
            f = min(f, cap[pe[v]]); v = par[v]
        v = t
        while v != s:
            e = pe[v]; cap[e] -= f; cap[e ^ 1] += f; v = par[v]
        val += f
    seen = [False] * n
    seen[s] = True
    q = deque([s])
    while q:
        u = q.popleft()
        e = head[u]
        while e != -1:
            if cap[e] > 0 and not seen[to[e]]:
                seen[to[e]] = True; q.append(to[e])
            e = nxt[e]
    return val, seen

6. Bottom line

  • Do not treat k ≥ 3 terminals as tractable — that is multiway cut and NP-hard.
  • Do not claim a sublinear/amortised dynamic bound for adversarial toggles — deactivation reduces to decremental max-flow.
  • Always emit the dual flow alongside the cut; a cut alone is only an upper bound.
  • Pin down activation semantics; handle parallel edges, self-loops, inactive terminals.
  • Use iterative Dinic for 2·10⁵ edges; warm-start only for activation-only sequences, where O((C/U + 1)·m) amortised is provable.
