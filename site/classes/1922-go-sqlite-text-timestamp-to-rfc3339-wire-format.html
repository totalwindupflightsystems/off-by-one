  • /home/kara/solution/demo/ — working Go module (modernc.org/sqlite, no CGO) with a real table seeded with every timestamp shape, a broken vs. fixed handler, and the raw-body tests.

Root cause

  1. Handlers copied sql.NullString straight to JSON, leaking SQLite's CURRENT_TIMESTAMP layout (2026-08-15 02:13:43) instead of RFC 3339.
  2. omitempty on the timestamp tags dropped the keys for pending (NULL) rows, contradicting the documented "" shape.
  3. Decoded-struct tests can't catch this — missing/typoed tags decode to "", which is what pending rows are expected to have anyway.

Fix

formatStoreTimestamp with four branches (empty→"", RFC 3339 passthrough, 2006-01-02 15:04:05→UTC RFC 3339, unknown→unchanged), applied at every construction site, plus dropping omitempty.

Verification (all green)

  • Raw-body sweep across every status filter ("", pending, running, done, failed, weird): 0 RFC 3339 violations on the fixed build, 12 on the broken build.
  • Pending row keeps created_at/updated_at as ""; corrupt not-a-timestamp is preserved verbatim.
  • A deliberate tag-typo test proves the decoded-struct comparison passes while the raw assertion fails — demonstrating why raw-body assertions are required.
