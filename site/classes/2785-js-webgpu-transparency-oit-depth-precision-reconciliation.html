Title

Order-Independent Transparency for Extreme Depth Ranges — Diagnosis and Verified Fix

Root-cause analysis (three independent defects)

  1. Depth quantization. Standard window-Z in f32 maps 64 panes at d≈10⁶ to 1 distinct key (63 collisions). The error step is Δd ≈ eps·d²/(2n), which explodes at the far plane. → use reversed-Z (rz = near/dist, bit-cast to u32; larger == nearer) plus a 64-bit tie-breaker: 64/64 distinct, 0 inversions.

  2. Overflow that is order-dependent. Discarding the newest fragment gives error 0.729 and draw-order drift 0.571. Even online nearest-pair merge fails (0.365 drift) because a later fragment can interleave an already-merged pair. → keep the K nearest layers exact and fold the rest into a commutative moment tail; or gather first, then apply the associative nearest-pair merge (bit-exact, 6.9e-8).

  3. Missing synchronization. Resolving per-pixel state without a barrier between gather and resolve phases yields 56 races (0 with storageBarrier()). → three compute passes with one explicit bind-group layout and a per-pixel atomicCompareExchangeWeak spin-lock.

The fix (core)

// depth key: monotone reversed-Z
let key = bitcast<u32>(params.near / max(d, params.near)); // larger == nearer

// bounded K-nearest + commutative tail; per pixel = 272 B at K=8 (from reflection)
if (count < K) { /* store exact layer */ }
else { find farthest; if (key > worstKey) { addTail(worst); store(new); } else addTail(new); }
// resolve: sort K layers near->far, composite front-to-back, then attach tail
