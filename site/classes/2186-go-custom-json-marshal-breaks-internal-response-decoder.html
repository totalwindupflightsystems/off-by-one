Answer

Fix: json: cannot unmarshal object into Go struct field NodeDetail.node.metadata of type []uint8

Root cause

The node response DTOs store metadata as []byte. Go's default codec encodes []byte as a base64 string and only accepts a base64 string when decoding. A custom MarshalJSON was later added so public responses emit metadata as native JSON (object/array/scalar):

raw := []byte(`{"region":"us"}`)   // stored internally
// BEFORE: {"metadata":"eyJyZWdpb24iOiJ1cyJ9"}   (base64 string)
// AFTER : {"metadata":{"region":"us"}}            (native JSON)

The encoder moved forward, but the decoder did not. Integration tests reuse the same DTO to decode the live API response, so the client still used Go's default []byte decoder, which expects a base64 string. On an object it failed at the field:

json: cannot unmarshal object into Go struct field NodeDetail.node.metadata of type []uint8

The fix

Add one normalization helper plus narrow, symmetric UnmarshalJSON methods on the node DTOs. They accept native JSON and the legacy base64-string form, keep null/omitted as nil, and reject malformed base64 or base64 that isn't valid JSON.

internal/db/models.go

import (
    "bytes"
    "encoding/base64"
    "encoding/json"
    "fmt"
)

// metadataFromRaw normalizes every wire form of a metadata value into the
// canonical raw-JSON []byte representation used internally.
//
// Accepted:
//   - nil / empty / JSON null      -> nil
//   - JSON object / array / scalar -> the raw JSON bytes
//   - JSON string                  -> legacy base64-encoded JSON bytes
//
// Rejected:
//   - a string that is not valid base64
//   - a base64 string whose payload is not valid JSON
func metadataFromRaw(raw json.RawMessage) ([]byte, error) {
    trimmed := bytes.TrimSpace(raw)
    if len(trimmed) == 0 || bytes.Equal(trimmed, []byte("null")) {
        return nil, nil
    }

    if trimmed[0] == '"' {
        var s string
        if err := json.Unmarshal(trimmed, &s); err != nil {
            return nil, fmt.Errorf("metadata: invalid string: %w", err)
        }
        decoded, err := base64.StdEncoding.DecodeString(s)
        if err != nil {
            return nil, fmt.Errorf("metadata: invalid legacy base64: %w", err)
        }
        if !json.Valid(decoded) {
            return nil, fmt.Errorf("metadata: legacy base64 did not decode to valid JSON")
        }
        return decoded, nil
    }

    if !json.Valid(trimmed) {
        return nil, fmt.Errorf("metadata: invalid JSON")
    }
    out := make([]byte, len(trimmed))
    copy(out, trimmed)
    return out, nil
}

Add the symmetric decoder to the type that owns Metadata []byte:

type Node struct {
    ID       int64  `json:"id"`
    Name     string `json:"name"`
    Metadata []byte `json:"metadata"`
}

// MarshalJSON emits metadata as native JSON instead of base64.
func (n Node) MarshalJSON() ([]byte, error) {
    type Alias Node // drops methods, prevents recursion
    aux := struct {
        Metadata json.RawMessage `json:"metadata"`
        Alias
    }{
        Alias: Alias(n),
    }
    if len(n.Metadata) == 0 {
        aux.Metadata = json.RawMessage("null")
    } else {
        aux.Metadata = json.RawMessage(n.Metadata)
    }
    return json.Marshal(aux)
}

// UnmarshalJSON restores symmetry: it accepts the native-JSON form emitted by
// MarshalJSON as well as the legacy base64 string form.
func (n *Node) UnmarshalJSON(data []byte) error {
    type Alias Node
    aux := &struct {
        Metadata json.RawMessage `json:"metadata"`
        *Alias
    }{
        Alias: (*Alias)(n),
    }
    if err := json.Unmarshal(data, &aux); err != nil {
        return err
    }
    md, err := metadataFromRaw(aux.Metadata)
    if err != nil {
        return err
    }
    n.Metadata = md
    return nil
}

internal/service/node_service.go

NodeDetail is the type the integration client decodes, so give it the same self-contained handling:

import (
    "bytes"
    "encoding/json"
)

type NodeDetail struct {
    Node *Node  `json:"node"`
    Note string `json:"note,omitempty"`
}

func (d NodeDetail) MarshalJSON() ([]byte, error) {
    type Alias NodeDetail
    return json.Marshal(struct{ Alias }{Alias(d)})
}

func (d *NodeDetail) UnmarshalJSON(data []byte) error {
    type Alias NodeDetail
    aux := &struct {
        Node json.RawMessage `json:"node"`
        *Alias
    }{
        Alias: (*Alias)(d),
    }
    if err := json.Unmarshal(data, &aux); err != nil {
        return err
    }
    if len(bytes.TrimSpace(aux.Node)) == 0 || bytes.Equal(bytes.TrimSpace(aux.Node), []byte("null")) {
        d.Node = nil
        return nil
    }
    var n Node
    if err := json.Unmarshal(aux.Node, &n); err != nil {
        return err
    }
    d.Node = &n
    return nil
}

Why this shape works:

  • Native JSON ({...}, [...], numbers, bools) is passed through as raw JSON bytes — exactly what MarshalJSON emits.
  • Legacy base64 strings still decode, preserving persisted data and older clients.
  • null / omitted stay nil, not an empty slice.
  • Malformed base64 and base64 that is not JSON return an error instead of silent garbage.
  • The type Alias T trick prevents recursion and avoids copying every field by hand, so the methods stay narrow and survive future field additions.
