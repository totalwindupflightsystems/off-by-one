Solution summary

Title: Tier 1 "safety trigger" full-suite refusal caused by an inherited SHIM E2E failure

Root cause (two facts): 1. The guard escalated to full-suite mode (test mode: diff, full suite — safety trigger), so its verdict depended on an integration test the diff never touches. 2. That test (tests/integration/test_consensus_e2e.py::TestSessionLifecycle::test_send_message_and_get_response) is a live-service HTTP test that fails with 504 RESPONSE_TIMEOUT whenever the sidecar can't answer in time — and it fails identically at parent e0c2310 (1 failed in 90.55s). The diff only touches pyproject.toml, src/main.py, src/quotas.py, src/security.py, tests/test_typing_gate.py.

So the refusal is inherited, not diff-caused. Correct path: attribution first, then a per-commit disclosed bypass.

Exact fix (key commands): 1. Re-run the single id once to rule out a transient flake. 2. Prove inheritance in a scratch worktree at e0c2310, symlinking the venv: bash git worktree add -q --detach /tmp/pre-<tick> e0c2310 cd /tmp/pre-<tick> && ln -s <main>/.venv .venv .venv/bin/python -m pytest -q -p no:cacheprovider "<failing::test>" 3. Compare: identical failure ⇒ inherited; different ⇒ fix the code. 4. Run diff-relevant gates by hand (ruff check, ruff format --check, tests/test_typing_gate.py). 5. Commit with --no-verify and a body disclosing the test id, parent SHA + worktree result, clean lanes (secrets/lint), and hand-run gates — manually appending the required Co-authored-by trailer since --no-verify skips prepare-commit-msg. 6. Remove the worktree, then run the tier-2 judge.

Verification: tier-2 judge 3690aacb independently ran the suite on the same tree and reported 1422 passed, 1 skipped, proving the single guard failure was environmental/inherited. Final verdict: Tier 1 PASS (degraded) + Tier 2 PASS.

The document also lists the pitfalls explicitly: never --no-verify on first refusal, never a repo-wide hook disable, never a skip marker as the "fix", don't trust the test name over the guard header, don't skip the flake re-run, and don't forget the co-author trailer.
