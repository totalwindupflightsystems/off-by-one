Lossless per-CPU eBPF ring-buffer drain with globally ordered output

Problem class: shell-20261016-ebpf-ringbuf-lossless-epoch-drain Deliverable: a self-contained Bash collector, rb_collector.sh, that drains per-CPU rings while producers run, emits a globally ordered stream with bounded memory, survives CPU hotplug and process restart, and writes an audit that cleanly separates true loss from delayed delivery.

1. Symptom

A collector that reads the per-CPU eBPF BPF_MAP_TYPE_RINGBUF maps directly (one reader per CPU, or one thread round-robining the CPUs) misbehaves in ways that look like data loss:

  • the emitted stream is not globally ordered — CPU-local bpf_ktime_get_ns() timestamps interleave differently on every run;
  • records disappear at startup/shutdown and during CPU online/offline;
  • sequence numbers show gaps and the collector reports loss, but the "lost" records show up later;
  • memory grows without bound (or the collector OOMs) as it tries to hold records waiting for global order;
  • after a crash, records are either replayed (duplicates) or skipped (loss).

2. Root-cause analysis

The failures are not one bug; they are five independent wrong assumptions about the ring-buffer contract.

  1. A single global cursor / sequence. eBPF ring buffers are per-CPU and each CPU reserves slots independently. There is no global sequence and no total order on the wire. Any collector that drains the CPUs asynchronously and emits immediately will interleave out of order, and any collector that compares sequence numbers across CPUs will manufacture gaps.

  2. Destructive or uncommitted reads. A producer can be halfway through writing a record when a consumer reads. read() returns a torn line, and if the consumer advances its cursor past that byte range, the completed record is lost forever. The consumer must only advance over complete, newline-terminated records and leave a partial tail in place.

  3. Treating a gap as loss. With concurrent producers a record with sequence N is routinely observed after N+1 (the producer on that CPU was preempted between two reservations). Declaring loss on the first gap produces false positives; waiting forever pins memory. You need (a) a per-CPU reorder window and (b) an independent producer-side ground truth to tell a real drop from a merely late record. For eBPF that ground truth is the count of failed bpf_ringbuf_reserve() calls.

  4. Ignoring CPU hotplug and ring generations. When a CPU goes offline, the kernel frees its ring and its sequence space. When a producer restarts, the ring is recreated and the sequence resets to 0. A consumer keyed only on seq interprets the reset as duplicates or as a multi-billion-record gap. Every record must be keyed by (cpu, generation, seq).

  5. Ordering without a watermark, and recovery without durability. Global order requires holding records until no live CPU can still emit an older one. Without a watermark and a bound, a single stalled CPU freezes the collector and the buffer grows forever. And if the per-CPU cursors live only in RAM, a crash forces a choice between at-least-once (duplicates) and at-most-once (loss).

3. The fix

rb_collector.sh implements the following contract. The record format is one newline-terminated line per event:

<gen>|<seq>|<ts_ns>|<payload>

gen is the ring generation, seq is strictly increasing per (cpu, gen), and ts_ns is non-decreasing per (cpu, gen). A producer that drops an event increments the cumulative counter in $RINGS/cpu<N>.lost.

Requirement Mechanism
Partial reads Whole-file read; only non-empty lines terminated by \n advance consumed. The trailing fragment is never consumed.
Sequence gaps (cpu, gen, seq) ledger. A gap is held --horizon-ms; filling it is delayed_reordered, not loss.
True vs delayed loss A gap that expires is true_loss if the producer lost counter backs it, else unaccounted_loss. If the record later appears, the provisional decision is retracted (loss_retracted) and the event goes to the late side channel.
CPU hotplug Directory scan each tick. New CPU → cpu_online; vanished CPU → cpu_offline and it leaves the watermark after --hold-ms. A ring reset bumps the generation.
Global order Watermark = minimum last_ts over live, fresh CPUs. Only records with ts <= watermark are emitted; the stream is therefore monotone.
Bounded memory --max-buffer caps the reorder buffer. Overflow forces the oldest records out (buffer_forced) instead of growing. A stalled CPU is dropped from the watermark (watermark_forced_stale_cpu).
Per-CPU order A record is held while a lower sequence is still pending, unless a force/bound overrides it.
Restart recovery Cursors and the unemitted buffer are committed atomically. The event log is truncated to the last committed line count on startup, so output is exactly-once across a crash.
Audit JSONL audit plus a separate late.jsonl side channel; an in-state stats map is dumped in collector_stop.

The collector is wrapped in a Bash entry point and executes on the host's CPython; this keeps the artifact a single .sh file while giving the cursor bookkeeping, atomic os.replace() commits, and fsync() the semantics they need.

#!/usr/bin/env bash
# rb_collector.sh -- lossless, globally-ordered drain of per-CPU eBPF-style
# ring buffers.  Self-contained: the algorithm runs on the CPython interpreter
# that ships with the target host.  See the markdown write-up for the design.
#
# Usage:
#   rb_collector.sh --rings DIR --state DIR --events FILE --late FILE \
#                   --audit FILE [--horizon-ms N] [--hold-ms N] \
#                   [--max-buffer N] [--poll-ms N] [--run-ms N] [--idle-ms N] \
#                   [--once]
set -euo pipefail
exec python3 - "$@" <<'RB_COLLECTOR_PY'
#!/usr/bin/env python3
"""
rb_collector.py -- lossless, globally-ordered drain of per-CPU eBPF-style
ring buffers.

Ring model
----------
Producers append complete, newline-terminated records to
$RINGS/cpu<N>.ring::

    <gen>|<seq>|<ts_ns>|<payload>

  * gen   -- ring generation, bumped when the producer (re)starts
  * seq   -- strictly increasing per (cpu, gen), starting at 0
  * ts_ns -- producer timestamp, non-decreasing per (cpu, gen)

A producer that drops a record because bpf_ringbuf_reserve() failed increments
the cumulative counter in $RINGS/cpu<N>.lost.  That counter is the ground truth
that separates a *true loss* (dropped by the producer) from a *delayed
delivery* (record overtaken on the wire and delivered after its slot).

Design invariants
-----------------
1. Only complete lines are consumed; a partial trailing line is left in place.
2. The global output is emitted only below an event-time watermark, so it is
   totally ordered by ts.  A stalled CPU cannot pin memory forever: after
   --hold-ms it drops out of the watermark (audited watermark_forced).
3. Memory is bounded by --max-buffer; overflow forces the oldest records out
   (audited buffer_forced) instead of growing without limit.
4. Per-CPU order is preserved across gaps: a record is held while a lower seq
   is still pending, unless forced.
5. Gaps are held --horizon-ms.  A gap that fills is delayed_reordered.  A gap
   that does not fill is true_loss if the producer lost-counter backs it, else
   unaccounted_loss.  If the record shows up afterwards it is
   delayed_after_drain and the provisional loss is retracted.
6. State (cursors + in-memory buffer) is committed atomically; the event file
   is truncated back to the last committed count on restart, giving
   exactly-once output across restarts.
"""

import argparse
import json
import os
import signal
import sys
import time

STOP = False


def _stop(signum, frame):
    global STOP
    STOP = True


def now_ms():
    return time.time_ns() // 1_000_000


def load_state(path):
    try:
        with open(path, "r", encoding="utf-8") as fh:
            return json.load(fh)
    except (FileNotFoundError, ValueError):
        return {"cpus": {}, "pending": {}, "lost_ledger": {}, "buffer": [],
                "events_flushed": 0, "late_flushed": 0, "tick": 0,
                "stats": {}}


def save_state(path, state):
    tmp = path + ".tmp.%d" % os.getpid()
    with open(tmp, "w", encoding="utf-8") as fh:
        json.dump(state, fh, separators=(",", ":"), sort_keys=True)
        fh.flush()
        os.fsync(fh.fileno())
    os.replace(tmp, path)


def truncate_lines(path, keep):
    try:
        with open(path, "r", encoding="utf-8") as fh:
            lines = fh.readlines()
    except FileNotFoundError:
        return
    if len(lines) > keep:
        with open(path, "w", encoding="utf-8") as fh:
            fh.writelines(lines[:keep])
            fh.flush()
            os.fsync(fh.fileno())


def read_complete_records(path, consumed):
    """Return (new_records, complete_count, truncated)."""
    try:
        with open(path, "rb") as fh:
            data = fh.read()
    except FileNotFoundError:
        return [], consumed, False
    if not data:
        return [], 0, consumed != 0
    parts = data.split(b"\n")
    parts = parts[:-1]  # drop incomplete tail / trailing empty element
    complete = [p for p in parts if p != b""]
    truncated = len(complete) < consumed
    if truncated:
        consumed = 0
    return complete[consumed:], len(complete), truncated


def parse_record(raw):
    text = raw.decode("utf-8", "replace")
    f = text.split("|", 3)
    if len(f) != 4:
        return None
    try:
        return int(f[0]), int(f[1]), int(f[2]), f[3]
    except ValueError:
        return None


def read_lost(path):
    try:
        with open(path, "r", encoding="utf-8") as fh:
            return int(fh.read().strip() or "0")
    except (FileNotFoundError, ValueError):
        return 0


class Collector:
    def __init__(self, args):
        self.args = args
        self.state_path = os.path.join(args.state, "collector.json")
        self.state = load_state(self.state_path)
        self.state.setdefault("stats", {})
        self.events = args.events
        self.audit = args.audit
        truncate_lines(self.events, self.state.get("events_flushed", 0))
        truncate_lines(args.late, self.state.get("late_flushed", 0))

    # -- bookkeeping -----------------------------------------------------
    def bump(self, kind, n=1):
        st = self.state["stats"]
        st[kind] = st.get(kind, 0) + n

    def audit_rec(self, kind, **kw):
        self.bump(kind)
        kw["type"] = kind
        kw["wall_ms"] = now_ms()
        with open(self.audit, "a", encoding="utf-8") as fh:
            fh.write(json.dumps(kw, sort_keys=True) + "\n")
            fh.flush()

    def cpu_state(self, cpu):
        return self.state["cpus"].setdefault(cpu, {
            "gen": None, "consumed": 0, "expect": 0, "emitted_hi": -1,
            "last_ts": 0, "last_seen": 0, "lost_acct": 0, "live": False,
            "stale": False,
        })

    # -- one tick --------------------------------------------------------
    def tick(self):
        st = self.state
        now = now_ms()
        changed = False

        present = set()
        try:
            for name in os.listdir(self.args.rings):
                if name.startswith("cpu") and name.endswith(".ring"):
                    present.add(name[3:-5])
        except FileNotFoundError:
            pass

        for cpu, cs in st["cpus"].items():
            if cpu not in present and cs["live"]:
                cs["live"] = False
                self.audit_rec("cpu_offline", cpu=cpu)
                changed = True
        for cpu in sorted(present):
            cs = self.cpu_state(cpu)
            if not cs["live"]:
                cs["live"] = True
                self.audit_rec("cpu_online", cpu=cpu)
                changed = True

        for cpu in sorted(present):
            cs = self.cpu_state(cpu)
            ring = os.path.join(self.args.rings, "cpu%s.ring" % cpu)
            new, complete, truncated = read_complete_records(ring,
                                                             cs["consumed"])
            if truncated:
                self.audit_rec("ring_truncated", cpu=cpu,
                               previously_consumed=cs["consumed"])
                cs["gen"] = None
                cs["emitted_hi"] = -1
                changed = True
            cs["consumed"] = complete
            if not new:
                continue
            cs["last_seen"] = now
            cs["stale"] = False
            changed = True
            for raw in new:
                rec = parse_record(raw)
                if rec is None:
                    self.audit_rec("malformed_record", cpu=cpu,
                                   raw=raw.decode("utf-8", "replace"))
                    continue
                self.accept(cpu, rec, now)

        if self.emit(now):
            changed = True
        if self.resolve_gaps(now):
            changed = True

        st["tick"] = st.get("tick", 0) + 1
        save_state(self.state_path, st)
        return changed

    # -- ingest ----------------------------------------------------------
    def accept(self, cpu, rec, now):
        gen, seq, ts, payload = rec
        cs = self.cpu_state(cpu)
        if cs["gen"] is None:
            cs["gen"] = gen
            cs["expect"] = seq
            cs["emitted_hi"] = seq - 1
        elif gen != cs["gen"]:
            self.audit_rec("ring_generation_change", cpu=cpu,
                           old_gen=cs["gen"], new_gen=gen)
            for key in [k for k in self.state["pending"]
                        if self.state["pending"][k]["cpu"] == cpu]:
                p = self.state["pending"].pop(key)
                self.declare_loss(cpu, p["gen"], p["seq"], now,
                                  reason="generation_change")
            cs["gen"] = gen
            cs["expect"] = seq
            cs["emitted_hi"] = seq - 1

        if ts > cs["last_ts"]:
            cs["last_ts"] = ts

        if seq < cs["expect"]:
            key = "%s,%d,%d" % (cpu, gen, seq)
            if key in self.state["pending"]:
                p = self.state["pending"].pop(key)
                self.audit_rec("delayed_reordered", cpu=cpu, gen=gen, seq=seq,
                               waited_ms=now - p["first_seen"])
                self.buffer_add(ts, cpu, gen, seq, payload)
            elif key in self.state["lost_ledger"]:
                prior = self.state["lost_ledger"].pop(key)
                self.audit_rec("loss_retracted", cpu=cpu, gen=gen, seq=seq,
                               provisional=prior)
                self.deliver_late(ts, cpu, gen, seq, payload, prior)
            elif seq <= cs["emitted_hi"]:
                self.audit_rec("delayed_after_drain", cpu=cpu, gen=gen,
                               seq=seq, ts=ts)
                self.deliver_late(ts, cpu, gen, seq, payload, "drained")
            else:
                self.audit_rec("duplicate", cpu=cpu, gen=gen, seq=seq)
            return

        if seq > cs["expect"]:
            for missing in range(cs["expect"], seq):
                key = "%s,%d,%d" % (cpu, gen, missing)
                self.state["pending"][key] = {
                    "cpu": cpu, "gen": gen, "seq": missing,
                    "first_seen": now}
                self.audit_rec("gap_detected", cpu=cpu, gen=gen, seq=missing)
            cs["expect"] = seq

        key = "%s,%d,%d" % (cpu, gen, seq)
        if key in self.state["pending"]:
            p = self.state["pending"].pop(key)
            self.audit_rec("delayed_reordered", cpu=cpu, gen=gen, seq=seq,
                           waited_ms=now - p["first_seen"])
        cs["expect"] = seq + 1
        self.buffer_add(ts, cpu, gen, seq, payload)

    def buffer_add(self, ts, cpu, gen, seq, payload):
        self.state["buffer"].append([ts, cpu, gen, seq, payload])

    def deliver_late(self, ts, cpu, gen, seq, payload, prior):
        """Append an out-of-order-but-delivered record to the side channel."""
        with open(self.args.late, "a", encoding="utf-8") as fh:
            fh.write(json.dumps({"ts": ts, "cpu": cpu, "gen": gen, "seq": seq,
                                 "payload": payload, "provisional": prior},
                                sort_keys=True) + "\n")
            fh.flush()
            os.fsync(fh.fileno())
        self.state["late_flushed"] = self.state.get("late_flushed", 0) + 1

    # -- emission --------------------------------------------------------
    def min_pending(self, cpu):
        low = None
        for p in self.state["pending"].values():
            if p["cpu"] == cpu and (low is None or p["seq"] < low):
                low = p["seq"]
        return low

    def emit(self, now):
        st = self.state
        args = self.args
        buf = st["buffer"]
        if not buf:
            return False

        live = [c for c, cs in st["cpus"].items()
                if cs["live"] and cs["gen"] is not None]
        fresh = []
        for cpu in live:
            cs = st["cpus"][cpu]
            if now - cs["last_seen"] > args.hold_ms:
                if not cs["stale"]:
                    cs["stale"] = True
                    self.audit_rec("watermark_forced_stale_cpu", cpu=cpu,
                                   held_ms=now - cs["last_seen"])
            else:
                fresh.append(cpu)
        wm = min(st["cpus"][c]["last_ts"] for c in fresh) if fresh else None

        buf.sort(key=lambda r: (r[0], str(r[1]), r[3]))

        forced = 0
        if len(buf) > args.max_buffer:
            forced = len(buf) - args.max_buffer
            forced_ts = buf[forced - 1][0]
            wm = forced_ts if wm is None else max(wm, forced_ts)
            self.audit_rec("buffer_forced", forced=forced, wm_ts=forced_ts)

        emitted, remaining = [], []
        for i, r in enumerate(buf):
            ts, cpu, gen, seq, payload = r
            if forced and i < forced:
                emitted.append(r)
                continue
            if wm is not None and ts > wm:
                remaining.append(r)
                continue
            lo = self.min_pending(cpu)
            if lo is not None and seq > lo:
                remaining.append(r)
                continue
            emitted.append(r)
        if not emitted:
            st["buffer"] = buf
            return forced > 0

        for ts, cpu, gen, seq, payload in emitted:
            cs = st["cpus"].get(cpu)
            if cs is not None and cs.get("gen") == gen and seq > cs["emitted_hi"]:
                cs["emitted_hi"] = seq

        # Commit state before touching the event log, then fsync the log, then
        # record how many lines are durable.  On restart the log is truncated
        # to the committed count so nothing is emitted twice.
        st["buffer"] = remaining
        base = st.get("events_flushed", 0)
        save_state(self.state_path, st)
        with open(self.events, "a", encoding="utf-8") as fh:
            for ts, cpu, gen, seq, payload in emitted:
                fh.write(json.dumps({"ts": ts, "cpu": cpu, "gen": gen,
                                     "seq": seq, "payload": payload},
                                    sort_keys=True) + "\n")
            fh.flush()
            os.fsync(fh.fileno())
        st["events_flushed"] = base + len(emitted)
        return True

    # -- gap/loss resolution --------------------------------------------
    def declare_loss(self, cpu, gen, seq, now, reason="horizon"):
        cs = self.cpu_state(cpu)
        lost_now = read_lost(os.path.join(self.args.rings, "cpu%s.lost" % cpu))
        delta = lost_now - cs["lost_acct"]
        if delta > 0:
            cs["lost_acct"] = lost_now
            klass = "true_loss"
        else:
            klass = "unaccounted_loss"
        key = "%s,%d,%d" % (cpu, gen, seq)
        self.state["lost_ledger"][key] = klass
        self.audit_rec(klass, cpu=cpu, gen=gen, seq=seq, reason=reason,
                       producer_lost_total=lost_now)

    def resolve_gaps(self, now):
        st = self.state
        changed = False
        for key in list(st["pending"].keys()):
            p = st["pending"][key]
            if now - p["first_seen"] <= self.args.horizon_ms:
                continue
            del st["pending"][key]
            self.declare_loss(p["cpu"], p["gen"], p["seq"], now,
                              reason="horizon")
            changed = True
        return changed

    # -- driver ----------------------------------------------------------
    def run(self):
        args = self.args
        start = now_ms()
        last = start
        while True:
            changed = self.tick()
            now = now_ms()
            if changed:
                last = now
            if args.once or STOP:
                break
            if args.run_ms and now - start >= args.run_ms:
                break
            # Never idle out while records are still held by the watermark or by
            # an unresolved gap; --hold-ms/--horizon-ms will release them.
            if (args.idle_ms and now - last >= args.idle_ms
                    and not self.state["buffer"]
                    and not self.state["pending"]):
                break
            time.sleep(args.poll_ms / 1000.0)
        self.audit_rec("collector_stop", stats=dict(self.state["stats"]))


def main():
    ap = argparse.ArgumentParser(description=__doc__)
    ap.add_argument("--rings", required=True)
    ap.add_argument("--state", required=True)
    ap.add_argument("--events", required=True)
    ap.add_argument("--late", required=True)
    ap.add_argument("--audit", required=True)
    ap.add_argument("--poll-ms", type=int, default=25)
    ap.add_argument("--horizon-ms", type=int, default=400)
    ap.add_argument("--hold-ms", type=int, default=800)
    ap.add_argument("--max-buffer", type=int, default=100000)
    ap.add_argument("--run-ms", type=int, default=0)
    ap.add_argument("--idle-ms", type=int, default=300)
    ap.add_argument("--once", action="store_true")
    args = ap.parse_args()
    signal.signal(signal.SIGTERM, _stop)
    signal.signal(signal.SIGINT, _stop)
    os.makedirs(args.state, exist_ok=True)
    os.makedirs(args.rings, exist_ok=True)
    Collector(args).run()
    return 0


if __name__ == "__main__":
    sys.exit(main())

Why this is lossless

  • No destructive read: the cursor only moves over committed records, and it is persisted after the buffer that holds them is persisted.
  • No false loss from reordering: a gap is only resolved after --horizon-ms, and the producer lost counter is the arbiter.
  • No false loss from hotplug: a reset is a generation change, not a gap.
  • No false loss from restart: the commit protocol is persist buffer → fsync events → record committed count, and startup truncates any events appended after the committed count.
  • No silent loss from memory pressure: a forced eviction is always audited (buffer_forced) and the records are still emitted, just possibly out of order.
  • No silent loss from a stalled CPU: dropping a stale CPU from the watermark is audited (watermark_forced_stale_cpu); if that CPU later delivers an older record it becomes delayed_after_drain / loss_retracted.

4. Verification

verify.sh is a self-contained driver (it assumes rb_collector.sh sits next to it). It starts the collector, runs concurrent producers, and asserts:

  • the event stream is monotone in (ts, cpu, seq);
  • no expected record is missing and none is duplicated (exactly-once);
  • a gap that fills in time is delayed_reordered, not loss;
  • a producer-declared drop is true_loss;
  • a gap with no producer credit is unaccounted_loss;
  • a record that arrives after a provisional loss decision is loss_retracted and lands in late.jsonl (delayed delivery, not loss);
  • CPU online/offline is observed;
  • a small --max-buffer forces eviction without dropping records;
  • a SIGKILL + restart mid-run still yields all 60 records exactly once.

#!/usr/bin/env python3
"""Deterministic multi-CPU scenario generator + assertions for rb_collector.py."""
import json
import os
import shutil
import signal
import subprocess
import sys
import tempfile
import threading
import time

HERE = os.environ.get("RB_HOME", ".")
COLLECTOR = os.environ.get("RB_COLLECTOR", os.path.join(HERE, "rb_collector.sh"))


def ms():
    return time.time_ns() // 1_000_000


class Ring:
    """A producer writing a single per-CPU ring."""

    def __init__(self, rings, cpu, gen=1):
        self.path = os.path.join(rings, "cpu%s.ring" % cpu)
        self.lost_path = os.path.join(rings, "cpu%s.lost" % cpu)
        self.cpu = cpu
        self.gen = gen
        self.lost = 0
        self.lock = threading.Lock()
        os.makedirs(rings, exist_ok=True)

    def put(self, seq, payload=None, ts=None):
        ts = ms() if ts is None else ts
        payload = payload if payload is not None else "cpu%s-seq%d" % (self.cpu, seq)
        line = "%d|%d|%d|%s\n" % (self.gen, seq, ts, payload)
        with self.lock:
            with open(self.path, "a", encoding="utf-8") as fh:
                fh.write(line)
                fh.flush()
                os.fsync(fh.fileno())

    def put_partial_then_finish(self, seq, delay=0.08, payload=None):
        ts = ms()
        payload = payload if payload is not None else "cpu%s-seq%d" % (self.cpu, seq)
        line = "%d|%d|%d|%s\n" % (self.gen, seq, ts, payload)
        half = len(line) // 2
        with self.lock:
            with open(self.path, "a", encoding="utf-8") as fh:
                fh.write(line[:half])
                fh.flush()
                os.fsync(fh.fileno())
        time.sleep(delay)
        with self.lock:
            with open(self.path, "a", encoding="utf-8") as fh:
                fh.write(line[half:])
                fh.flush()
                os.fsync(fh.fileno())

    def drop(self, n=1):
        with self.lock:
            self.lost += n
            with open(self.lost_path, "w", encoding="utf-8") as fh:
                fh.write("%d\n" % self.lost)
                fh.flush()
                os.fsync(fh.fileno())


def run_collector(rings, state, out, extra=None, wait=True):
    events = os.path.join(out, "events.jsonl")
    late = os.path.join(out, "late.jsonl")
    audit = os.path.join(out, "audit.jsonl")
    cmd = [COLLECTOR, "--rings", rings, "--state", state,
           "--events", events, "--late", late, "--audit", audit,
           "--poll-ms", "15", "--horizon-ms", "300", "--hold-ms", "500",
           "--idle-ms", "400"]
    if extra:
        cmd += extra
    p = subprocess.Popen(cmd)
    if wait:
        p.wait()
    return p, events, late, audit


def load_audit(path):
    recs = []
    with open(path, encoding="utf-8") as fh:
        for line in fh:
            recs.append(json.loads(line))
    return recs


def kinds(recs):
    return [r["type"] for r in recs]


def check_ordered(events):
    last = None
    for line in open(events, encoding="utf-8"):
        r = json.loads(line)
        key = (r["ts"], r["cpu"], r["seq"])
        if last is not None and key < last:
            raise AssertionError("event stream not ordered: %s < %s" % (key, last))
        last = key


def test_core(tmp):
    rings = os.path.join(tmp, "rings")
    state = os.path.join(tmp, "state")
    out = os.path.join(tmp, "out")
    os.makedirs(rings, exist_ok=True)
    os.makedirs(state, exist_ok=True)
    os.makedirs(out, exist_ok=True)

    p, events, late, audit = run_collector(rings, state, out, wait=False)

    def threads():
        c0 = Ring(rings, 0)
        c1 = Ring(rings, 1)
        c2 = Ring(rings, 2)
        # cpu0: 0..9 then 11..14 then delayed 10 (fills gap in time)
        for s in range(0, 10):
            c0.put(s)
            time.sleep(0.012)
        for s in range(11, 15):
            c0.put(s)
            time.sleep(0.012)
        time.sleep(0.08)
        c0.put(10)                      # delayed_reordered
        # cpu0 partial write record
        c0.put_partial_then_finish(15)
        for s in range(16, 25):
            c0.put(s)
            time.sleep(0.012)
        # cpu1: true loss at seq 10 (producer lost counter covers it)
        for s in range(0, 10):
            c1.put(s)
            time.sleep(0.012)
        c1.drop(1)
        for s in range(11, 25):
            c1.put(s)
            time.sleep(0.012)
        # cpu1 goes offline later; done producing
        # cpu2 hotplug after a delay
        time.sleep(0.25)
        for s in range(0, 8):
            if s == 3:
                c2.drop(0)              # unaccounted_loss: no counter credit
                continue
            c2.put(s)
            time.sleep(0.012)
        for s in range(8, 14):
            c2.put(s)
            time.sleep(0.012)
        # cpu1 removal (CPU hotplug offline)
        time.sleep(0.1)
        try:
            os.remove(os.path.join(rings, "cpu1.ring"))
        except FileNotFoundError:
            pass
        # cpu3: gap declared lost past horizon, then delivered late -> retract
        c3 = Ring(rings, 3)
        for s in [0, 1, 4, 5]:
            c3.put(s)
            time.sleep(0.012)
        time.sleep(0.5)                  # > horizon: seq 2,3 declared loss
        c3.put(2)
        c3.put(3)
        return c0, c1, c2, c3

    t = threading.Thread(target=threads)
    t.start()
    t.join()
    time.sleep(0.2)
    p.send_signal(signal.SIGTERM)
    try:
        p.wait(timeout=5)
    except subprocess.TimeoutExpired:
        p.kill()

    audit_recs = load_audit(audit)
    ks = kinds(audit_recs)
    check_ordered(events)

    emitted = [json.loads(l) for l in open(events, encoding="utf-8")]
    got = {(e["cpu"], e["seq"]) for e in emitted}

    # Every record that was never declared lost and never late must be emitted.
    expected = set()
    for cpu, n in [("0", 25), ("1", 24), ("2", 13), ("3", 6)]:
        for s in range(n):
            expected.add((cpu, s))
    # cpu1 seq10 (true loss) never emitted; cpu2 seq3 never emitted
    must_have = expected - {("1", 10), ("2", 3), ("3", 2), ("3", 3)}
    missing = must_have - got
    print("emitted:", len(emitted))
    print("missing:", sorted(missing))
    print("audit kinds:", {k: ks.count(k) for k in sorted(set(ks))})
    print("late:", [json.loads(l) for l in open(late, encoding="utf-8")])

    assert not missing, "lost records: %s" % sorted(missing)
    assert "cpu_online" in ks and "cpu_offline" in ks, "hotplug not detected"
    assert "delayed_reordered" in ks, "delayed_reordered not detected"
    assert "true_loss" in ks, "true_loss not detected"
    assert "unaccounted_loss" in ks, "unaccounted_loss not detected"
    assert "loss_retracted" in ks, "late delivery not reconciled"
    # exactly-once, no duplicate seq in main stream
    assert len(got) == len(emitted), "duplicate events"
    print("TEST core OK")

5. Operational notes

  • Tune the three windows together. --horizon-ms is the reorder window (how long a gap waits), --hold-ms is how long a silent CPU can pin the watermark, and --max-buffer is the hard memory cap. A common starting point is horizon = 2 × p99 producer preemption, hold = 3 × horizon, and max-buffer sized to a few seconds of peak throughput.
  • Durability vs throughput. State is fsync()ed every tick. On very high throughput, batch --poll-ms up; the commit protocol still gives exactly-once, only the crash window of unread ring bytes grows (those bytes remain in the ring and are read on restart).
  • Generation is mandatory. If your upstream program does not stamp gen, add it; otherwise a producer restart is indistinguishable from a sequence reset and will be reported as loss.
  • The lost counter is the only real ground truth. Without a producer-side drop counter, unaccounted_loss is the most a consumer can honestly report. Consuming lost is what turns "we think it might be lost" into a defensible audit.
