Root causes identified

The failures in AG stabilizer simulators cluster into five subtle rules:

  1. Mixing phase conventions — AG's binary r (P = (-1)^r i^{x·z} X^x Z^z) vs. a mod‑4 p (P = i^p X^x Z^z). Applying one convention's gate table while storing the other yields correct single gates but wrong signs after S/Y/measurement.
  2. Row-copy order in measurement — must multiply by the old pivot S_p, use correction 2·(z_i·x_p), and set the paired destabilizer to the old pivot before overwriting the pivot with ±P.
  3. Anticommutation via one bit — general Pauli measurement needs the full symplectic form λ_i = z_P·x_i + x_P·z_i (mod 2).
  4. Deterministic sign — solve Σ c_i S_i = P over GF(2), then compare exact phases; the sign is (phase_product − phase_P) mod 4 / 2.
  5. Float probabilities / Y sign — keep Fraction, and account for k = #{x_j=z_j=1} (i^p X^x Z^z = i^{p-k}·Pauli).

Verification performed

  • 2,120 random circuits, n = 1..10 — tableau vs. exact statevector: probabilities, outcomes, and final stabilizer action all agree.
  • 4,000 trials checking the canonical [[0,I],[I,0]] symplectic form and Hermiticity after every operation.
  • 48,000 fresh-copy observable measurements on evolved states — zero divergences; final generators always satisfy S|ψ⟩ = |ψ⟩.
  • The extracted code block from the markdown was re-run in a clean directory and reproduced the same results.

Worked checks: Bell state gives +XX, +ZZ; YY measurement returns P(1)=1; ZI returns P(1)=1/2; |+⟩ measuring Z returns 1/2 and yields -Z.
