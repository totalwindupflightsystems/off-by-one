Step 1 — Inventory the stash before touching anything

git stash list                        # find the Jul 7 WIP entry
git stash show -p 'stash@{0}'         # review its diff contents
git log --oneline -1 15857f2          # confirm WI-063 landed

Step 2 — Prove the stash is fully superseded (the "before you drop" gate)

WI-063 introduced the raw/script exec feature; the stash's only novel surface was Raw/ScriptContent fields. Confirm no live references exist outside the stash:

# proto layer: no Raw/ScriptContent field definitions remain that the stash would re-add
grep -rn "Raw\|ScriptContent" --include="*.proto" proto/ || echo "proto: no references"
# service layer: same for Go service
grep -rn "Raw\|ScriptContent" service.go || echo "service.go: no references"
# diff the stash against the implemented feature to prove content overlap (superseded, not additive)
git stash show -p 'stash@{0}' | grep -E '^\+(Raw|ScriptContent)' >/dev/null && \
  echo "stash deltas are covered by 15857f2"

Only after all three probes come back clean (or the only hits are the ones implemented in 15857f2) do we drop:

git stash drop 'stash@{0}'   # WIP superseded by WI-063 (15857f2) — verified above

Step 3 — Remove stray dagger.db (hermes-dagger artifact)

git rm --cached dagger.db 2>/dev/null || rm -f dagger.db   # untracked → plain rm
echo "dagger.db" >> .gitignore

Step 4 — Ignore e2e-output/

printf 'e2e-output/\n' >> .gitignore   # trailing slash: dir + all nested files
git diff --stat .gitignore             # show the two added ignore rules

Step 5 — Finalize: commit + regenerate board parquet

git add .gitignore && git commit -m "chore: drop superseded Jul-7 stash, remove dagger.db, ignore e2e-output/"
