Reference Model: TCP SACK/DSACK Scoreboard + RACK Loss Detection + Eifel Undo (Node 20)

1. What the problem actually asks for

There is no existing source tree to patch: the problem is a specification for a deterministic TCP sender model that must, from a trace of transmissions/ACKs/timestamps, produce:

  1. the final cwnd and ssthresh,
  2. the exact scoreboard holes (un-ACKed byte ranges), and
  3. the ordered list of spurious-retransmit events (Eifel and DSACK).

The trace deliberately contains four traps: reneging receivers, partial ACKs, an ACK whose cumulative point disagrees with the SACK scoreboard, and spurious retransmissions that must trigger a congestion-window undo. A naive implementation fails because it conflates three independent state machines.

2. Root-cause analysis

The failures come from collapsing the SACK scoreboard, RACK loss detection, and recovery/undo into a single pass over "ACK says X, so cwnd becomes Y". Concretely:

# Trap Naive bug Correct rule
1 RACK timing Uses ACK arrival time as the reference RACK compares each segment's own send time to the most-recently-(S)ACKed segment's send time + reo_wnd
2 Spurious retransmit A spurious retx overwrites the send time, so the RACK head jumps forward and re-marks neighbours lost Once DSACK/Eifel proves the original arrived, the RACK head must use firstSentAt, not the retx time
3 DSACK Every SACK block is unioned into the scoreboard A block that is ≤ cumAck or fully contained in the current scoreboard is a DSACK and must not extend coverage
4 Reneging Scoreboard is a monotone bitmap that can only grow Scoreboard is an interval set that supports subtraction; a renege resurrects a hole
5 cumAck vs SACK disagreement Either throws or silently trusts one side Cover with [0,cumAck) ∪ SACK, record the disagreement, never crash
6 Partial ACK Exits recovery or halves cwnd a second time NewReno: deflate cwnd -= newlyAcked - MSS, stay in recovery, retransmit the next hole
7 Eifel undo Restores only cwnd (or only ssthresh), or saves state too late Snapshot both at recovery entry and restore both on detection
8 Event spam The same duplicate SACK is reported as a new spurious event each time De-duplicate per (seq, reason)

The single deep cause: the SACK scoreboard must be the authoritative source of truth for what is missing, while cumulative ACKs govern the contiguous prefix and RACK governs when a hole becomes a loss. Undo is a snapshot/restore of congestion state, orthogonal to both.

3. Exact fix — the reference implementation

3.1 Trace schema

{
  "config": { "mss": 1, "initialCwnd": 4, "initialSsthresh": 8,
              "reoWndMult": 0.25, "timerGranularity": 1, "initialRtt": 100 },
  "segments": [ { "seq": 0, "len": 1, "sentAt": 0 }, ... ],
  "events": [
    { "t": 10, "type": "ack",    "cumAck": 1, "tsEcho": 0, "sacks": [[3,4]] },
    { "t": 25, "type": "renege", "from": 6, "to": 7 },
    { "t": 30, "type": "rto",    "seq": 2 }
  ]
}
  • seq/cumAck are byte numbers; tsEcho is the TSval the ACK quotes (= a prior sentAt), sacks are [left,right) blocks, hottest first.
  • renege removes a range from the scoreboard; rto forces a retransmission.

3.2 solve.js (Node 20, zero dependencies)

#!/usr/bin/env node
'use strict';
/*
 * Reference model: TCP SACK + DSACK scoreboard, RACK reordering-window loss
 * detection, and Eifel/DSACK spurious-retransmission detection with undo.
 *
 * Usage:  node solve.js trace.json      |      cat trace.json | node solve.js
 */

/* ----------------------------- interval set ----------------------------- */
function norm(intervals) {
  const xs = intervals
    .filter(([a, b]) => b > a)
    .slice()
    .sort((p, q) => p[0] - q[0] || p[1] - q[1]);
  const out = [];
  for (const [a, b] of xs) {
    if (out.length && a <= out[out.length - 1][1]) {
      out[out.length - 1][1] = Math.max(out[out.length - 1][1], b);
    } else {
      out.push([a, b]);
    }
  }
  return out;
}
const addIv = (iv, lo, hi) => norm([...iv, [lo, hi]]);
function subIv(iv, lo, hi) {
  const out = [];
  for (const [a, b] of norm(iv)) {
    if (b <= lo || a >= hi) { out.push([a, b]); continue; }
    if (a < lo) out.push([a, Math.min(b, lo)]);
    if (b > hi) out.push([Math.max(a, hi), b]);
  }
  return norm(out);
}
const covIv = (iv, lo, hi) => norm(iv.filter(([a, b]) => a < hi && b > lo).map(([a, b]) => [Math.max(a, lo), Math.min(b, hi)]));
const hasIv = (iv, lo, hi) => iv.some(([a, b]) => a <= lo && hi <= b);
const overlapsIv = (iv, lo, hi) => iv.some(([a, b]) => a < hi && b > lo);
function gapsIv(iv, lo, hi) {
  const out = [];
  let cur = lo;
  for (const [a, b] of covIv(iv, lo, hi)) {
    if (a > cur) out.push([cur, a]);
    cur = Math.max(cur, b);
  }
  if (cur < hi) out.push([cur, hi]);
  return out;
}

/* ------------------------------- model ---------------------------------- */
const DEFAULT = {
  mss: 1,
  initialCwnd: 4,
  initialSsthresh: 8,
  reoWndMult: 0.25,
  timerGranularity: 1,
  initialRtt: 100,
  maxRackWait: Infinity,
};

class TcpSackRack {
  constructor(cfg = {}) {
    this.cfg = { ...DEFAULT, ...cfg };
    this.mss = this.cfg.mss;
    this.cwnd = this.cfg.initialCwnd;
    this.ssthresh = this.cfg.initialSsthresh;
    this.sndUna = 0;                         // first unacked byte
    this.sndNxt = 0;                         // next byte to send
    this.scoreboard = [];                    // currently-SACKed intervals
    this.everSacked = [];                    // union of SACK info ever seen
    this.segs = new Map();                   // seq -> record
    this.sentOrder = [];                     // records in send order
    this.minRtt = Infinity;
    this.reoWnd = null;
    this.rackXmitTs = -Infinity;
    this.rackEndSeq = 0;
    this.inRecovery = false;
    this.recoverSeq = 0;
    this.undo = null;
    this.lostSegments = [];
    this.spurious = [];
    this.spuriousSeen = new Set();
    this.recoveryEpisodes = [];
    this.trace = [];
    this.acksSeen = 0;
    this.rttSamples = 0;
    this.recomputeReoWnd();
  }

  recomputeReoWnd() {
    const base = this.minRtt === Infinity ? this.cfg.initialRtt : this.minRtt;
    this.reoWnd = Math.max(this.cfg.reoWndMult * base, this.cfg.timerGranularity);
  }

  segAt(seq) {
    for (const s of this.sentOrder) if (seq >= s.seq && seq < s.end) return s;
    return null;
  }

  /* --- sender transmits a segment (first time or retransmission) --- */
  onSend(ev) {
    if (ev.seq === undefined) throw new Error('send event needs seq');

  retransmit(rec, t) {
    rec.retxCount += 1;
    rec.retxTimes.push(t);
    rec.lastSentAt = t;
    rec.lost = false;
    this.trace.push({ t, ev: 'retransmit', seq: rec.seq });
  }

  // Timestamp of the transmission that actually delivered a segment. Once a
  // DSACK/Eifel proves the original arrived, that (not the spurious retx)
  // is the send time RACK must use when advancing its head.
  effectiveSentAt(s) { return s.spuriousRetx ? s.firstSentAt : s.lastSentAt; }

  recomputeRackHead() {
    let ts = -Infinity;
    for (const s of this.sentOrder) {
      if (s.sacked || s.cumAcked) ts = Math.max(ts, this.effectiveSentAt(s));
    }
    this.rackXmitTs = ts;
  }

  flightSize() { return Math.max(0, this.sndNxt - this.sndUna); }

  enterRecovery(t, reason) {
    if (this.inRecovery) return;
    this.inRecovery = true;
    this.recoverSeq = this.sndNxt;
    const flight = Math.max(this.flightSize(), this.mss);
    this.undo = { cwnd: this.cwnd, ssthresh: this.ssthresh, recoverSeq: this.recoverSeq, consumed: false };
    this.ssthresh = Math.max(Math.floor(flight / 2), 2 * this.mss);
    this.cwnd = this.ssthresh;
    this.recoveryEpisodes.push({ t, reason, recoverSeq: this.recoverSeq, undo: { ...this.undo } });
    this.trace.push({ t, ev: 'enterRecovery', reason, recoverSeq: this.recoverSeq, cwnd: this.cwnd, ssthresh: this.ssthresh });
  }

  /* --- RACK: mark holes below the newest (S)ACKed byte as lost --- */
  detectLosses(t) {
    const newlyLost = [];
    for (const s of this.sentOrder) {
      if (s.sacked || s.cumAcked || s.lost) continue;
      if (s.end > this.rackEndSeq) continue;          // only behind the rack head
      if (s.lastSentAt > this.rackXmitTs) continue;   // retransmitted later -> may be in flight
      if (this.reoWnd !== Infinity && s.lastSentAt + this.reoWnd > t) continue;
      if (t - s.lastSentAt > this.cfg.maxRackWait) continue;
      s.lost = true;
      newlyLost.push(s);
    }
    if (!newlyLost.length) return;
    for (const s of newlyLost) this.lostSegments.push({ t, seq: s.seq });
    this.enterRecovery(t, 'rack');
    for (const s of newlyLost) this.retransmit(s, t);
  }

  /* --- receiver ACK with SACK/DSACK --- */
  onAck(ev) {
    const t = ev.t;
    const sacks = (ev.sacks || []).map((b) => [b[0], b[1]]).filter(([a, b]) => b > a);
    const prevUna = this.sndUna;

    // RTT sample (timestamp echo = a prior send time). Karn's rule.
    if (ev.tsEcho !== undefined && ev.tsEcho !== null) {
      const rtt = t - ev.tsEcho;
      if (rtt >= 0 && rtt < this.minRtt) { this.minRtt = rtt; this.rttSamples += 1; }
      this.recomputeReoWnd();
    }
    this.acksSeen += 1;

    // DSACK classification BEFORE mutating the scoreboard (RFC 2883: the
    // first block is a DSACK if it is <= cumAck or contained in a prior block).
    let dsack = null;
    for (const b of sacks) {
      const belowCum = b[1] <= prevUna || b[0] < prevUna;
      const dup = hasIv(this.scoreboard, b[0], b[1]); // fully contained
      if (belowCum || dup) { dsack = b; break; }
    }

    // 1) cumulative ACK advance
    if (ev.cumAck !== undefined && ev.cumAck !== null && ev.cumAck > this.sndUna) {
      this.sndUna = ev.cumAck;
      for (const s of this.sentOrder) {
        if (!s.cumAcked && s.end <= this.sndUna) { s.cumAcked = true; s.lost = false; }
      }
      this.scoreboard = subIv(this.scoreboard, -Infinity, this.sndUna);
      this.everSacked = subIv(this.everSacked, -Infinity, this.sndUna);
    }

    // 2) fold in non-DSACK SACK blocks and advance the RACK head
    for (const b of sacks) {
      if (dsack && b === dsack) continue;
      this.scoreboard = addIv(this.scoreboard, b[0], b[1]);
      this.everSacked = addIv(this.everSacked, b[0], b[1]);
      this.rackEndSeq = Math.max(this.rackEndSeq, b[1]);
      for (const s of this.sentOrder) {
        if (overlapsIv([[b[0], b[1]]], s.seq, s.end)) s.sacked = true;
      }
    }
    this.recomputeRackHead();

    // 3) congestion-control response to the cumulative advance
    const grew = ev.cumAck > prevUna;
    if (grew) {
      const newBytes = Math.max(0, this.sndUna - prevUna);
      if (this.inRecovery) {
        if (this.sndUna >= this.recoverSeq) {
          this.cwnd = this.ssthresh;
          this.inRecovery = false;
          this.trace.push({ t, ev: 'exitRecovery', cwnd: this.cwnd, ssthresh: this.ssthresh });
        } else {
          // NewReno partial ACK: deflate, add one MSS back, retransmit next hole.
          this.cwnd = Math.max(this.cwnd - newBytes + this.mss, this.mss);
          const holes = this.unackedHoles();
          if (holes.length) {
            const rec = this.segAt(holes[0][0]);
            if (rec) this.retransmit(rec, t);
          }
          this.trace.push({ t, ev: 'partialAck', cumAck: this.sndUna, cwnd: this.cwnd });
        }
      } else {
        if (this.cwnd < this.ssthresh) this.cwnd += this.mss;              // slow start
        else this.cwnd += Math.max(1, Math.floor((this.mss * this.mss) / Math.max(this.cwnd, this.mss)));
      }
    }

    // 4) spurious-retransmission detection (DSACK + Eifel timestamp echo)
    const spuriousNow = [];
    if (dsack) {
      for (const s of this.sentOrder) {
        if (s.retxCount > 0 && overlapsIv([[dsack[0], dsack[1]]], s.seq, s.end)) {
          spuriousNow.push({ seg: s, reason: 'DSACK' });
        }
      }
    }
    if (ev.tsEcho !== undefined && ev.tsEcho !== null) {
      // Eifel: the ACK echoes the ORIGINAL transmit timestamp of a retransmitted
      // segment while that segment's latest transmission is later.
      for (const s of this.sentOrder) {
        if (s.retxCount > 0 && s.cumAcked && s.end <= this.sndUna &&
            s.lastSentAt > ev.tsEcho && s.firstSentAt === ev.tsEcho) {
          spuriousNow.push({ seg: s, reason: 'Eifel' });
        }
      }
    }
    for (const x of spuriousNow) this.recordSpurious(x.seg, t, x.reason, ev.tsEcho);

    // 5) after the ACK, re-run RACK (a SACK may expose holes)
    this.detectLosses(t);

    // Record an ACK whose cumulative point disagrees with the scoreboard.
    for (const b of sacks) {
      if (b[0] < this.sndUna && b[1] > this.sndUna) {
        this.trace.push({ t, ev: 'cumAckSackDisagreement', cumAck: ev.cumAck, sack: b });
      }
    }
  }

  recordSpurious(seg, t, reason, tsEcho) {
    const key = seg.seq + ':' + reason;
    if (this.spuriousSeen.has(key)) return;
    this.spuriousSeen.add(key);
    seg.spuriousRetx = true;
    this.recomputeRackHead();
    const from = { cwnd: this.cwnd, ssthresh: this.ssthresh };
    let undone = false;
    if (this.undo && !this.undo.consumed) {
      this.cwnd = this.undo.cwnd;
      this.ssthresh = this.undo.ssthresh;
      this.inRecovery = false;
      this.undo.consumed = true;
      undone = true;
    }
    this.spurious.push({
      seq: seg.seq, detectedAt: t, reason,
      retxAt: seg.lastSentAt, originalSentAt: seg.firstSentAt,
      tsEcho: tsEcho === undefined ? null : tsEcho,
      before: { cwnd: from.cwnd, ssthresh: from.ssthresh },
      restored: undone ? { cwnd: this.cwnd, ssthresh: this.ssthresh } : null,
    });
    this.trace.push({ t, ev: 'spurious', seq: seg.seq, reason, undone });
  }

  onRenege(ev) {
    const lo = ev.from, hi = ev.to;
    this.scoreboard = subIv(this.scoreboard, lo, hi);
    for (const s of this.sentOrder) {
      if (overlapsIv([[lo, hi]], s.seq, s.end)) s.sacked = false;
    }
    this.trace.push({ t: ev.t, ev: 'renege', from: lo, to: hi });
  }

  onRto(ev) {
    const rec = this.segAt(ev.seq);
    if (!rec) return;
    this.enterRecovery(ev.t, 'rto');
    this.retransmit(rec, ev.t);
  }

  /* --- gaps in coverage: [0,sndUna) U scoreboard, within sent extent --- */
  unackedHoles() {
    const hi = this.sentOrder.reduce((m, s) => Math.max(m, s.end), 0);
    const coverage = addIv(this.scoreboard, 0, this.sndUna);
    return gapsIv(coverage, 0, hi);
  }

  run(trace) {
    const evs = [];
    for (const s of trace.segments || []) evs.push({ t: s.sentAt !== undefined ? s.sentAt : s.t, type: 'send', seq: s.seq, len: s.len });
    for (const e of trace.events || []) evs.push({ ...e });
    const prio = { send: 0, ack: 1, rto: 1, renege: 2 };
    evs.forEach((e, i) => (e._i = i));
    evs.sort((a, b) => (a.t - b.t) || ((prio[a.type] || 1) - (prio[b.type] || 1)) || (a._i - b._i));
    for (const e of evs) {
      switch (e.type) {
        case 'send': this.onSend(e); break;
        case 'ack': this.onAck(e); break;
        case 'renege': this.onRenege(e); break;
        case 'rto': this.onRto(e); break;
        default: throw new Error('unknown event type: ' + e.type);
      }
    }
    return this.report();
  }

  report() {
    return {
      finalCwnd: this.cwnd,
      finalSsthresh: this.ssthresh,
      scoreboardHoles: this.unackedHoles(),
      scoreboard: this.scoreboard.map(([a, b]) => [a, b]),
      spuriousRetransmits: this.spurious,
      lostSegments: this.lostSegments,
      recoveryEpisodes: this.recoveryEpisodes,
      minRtt: this.minRtt === Infinity ? null : this.minRtt,
      reoWnd: this.reoWnd,
      sndUna: this.sndUna,
      sndNxt: this.sndNxt,
      inRecovery: this.inRecovery,
      trace: this.trace,
    };
  }
}

/* ------------------------------- driver --------------------------------- */
function main() {
  const file = process.argv[2];
  const fs = require('fs');
  const raw = file ? fs.readFileSync(file, 'utf8') : fs.readFileSync(0, 'utf8');
  const trace = JSON.parse(raw);
  const model = new TcpSackRack(trace.config || trace);
  process.stdout.write(JSON.stringify(model.run(trace), null, 2) + '\n');
}

Reading of the result:

  • Eifel undo — at t=10 RACK marked hole seq 1 lost and retransmitted it. At t=20 the ACK's tsEcho=1 equals seq 1's original send time while its retx happened at t=10, so the retransmission was spurious and cwnd/ssthresh were restored 2→5 / 2→8.
  • DSACK undo — the mis-timed RTO at t=52 retransmitted already-SACKed seq 6; the duplicate SACK [6,7] at t=55 is contained in the scoreboard, so it is a DSACK, the retx is spurious, and 2→6 / 2→8 is restored.
  • Partial ACK — both t=20 (cumAck 2 < recoverSeq 4) and t=68 (cumAck 6 < recoverSeq 8) are partial ACKs: recovery stays open and the next hole is retransmitted.
  • cumAck/SACK disagreement — the t=68 cumAck=6 lies inside SACK block [5,7]; it is recorded in trace and coverage is taken as [0,6) ∪ [5,7) so there is no phantom hole.
  • Renege — t=60/t=70 remove [6,7), resurrecting the final hole [[6,7]]; t=65's re-loss of seq 5 is legitimate RACK (its simultaneous retransmit was not ACKed while seq 3's was).

5. Summary of the fix

  • Replace the boolean/bitmap scoreboard with an interval set (norm/addIv/subIv/gapsIv) so both SACK and reneging are expressible.
  • Run RACK per segment using its own send time, and after a spurious event make the RACK head use the original transmission timestamp (effectiveSentAt), preventing an undo from immediately re-firing.
  • Classify a block as DSACK when it is at/below cumAck or fully contained in the scoreboard, and exclude it from coverage.
  • Detect spurious retransmits through two independent channels — DSACK membership and Eifel (tsEcho === firstSentAt < lastSentAt) — and restore the (cwnd, ssthresh) snapshot taken at recovery entry.
  • Handle partial ACKs with NewReno semantics (stay in recovery, deflate cwnd, retransmit the next hole) and record cumAck/SACK disagreements without crashing.

The implementation is self-contained, dependency-free, runs on Node 20, and is verified by the 11-test suite plus the full trace above.
