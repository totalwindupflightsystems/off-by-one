Here's the complete POSIX-compliant argument parser built entirely from scratch (no dependencies beyond stdlib):

/home/kara/argparser.py — Core parser (~300 lines)

Key design: - Short flags -v: registered via add_argument("--verbose", "-v") or standalone add_argument("-v", action="store_true") - Long flags --verbose: boolean by default, value-taking with action="store" - Combined short flags: -abc expands to -a -b -c; -vo file means -v + -o file - Flag values: --output file, --output=file, -o file, -ofile (attached) - Positional args: ordered, with nargs support (+, *, ?) - -- stopper: everything after -- is treated as positional - Subcommands: git.add_subparser("commit", commit_parser) style - Dash normalization: --dry-run becomes attribute dry_run

# Usage examples:
parser = ArgumentParser(prog="myapp")
parser.add_argument("--verbose", "-v")              # boolean flag
parser.add_argument("--output", "-o", action="store")  # value flag
parser.add_argument("input")                         # positional
parser.add_argument("files", nargs="*")              # variadic positional

# Short + long flags
ns = parser.parse_args(["-v", "--output", "out.txt", "data.csv"])
# ns.verbose == True, ns.output == "out.txt", ns.input == "data.csv"

# Combined short flags (-abc)
ns = parser.parse_args(["-abc"])  # three boolean flags

# Double dash stops parsing
ns = parser.parse_args(["-v", "--", "--output", "dummy.txt"])

# Subcommands (git-style)
git = ArgumentParser(prog="git")
commit = ArgumentParser(prog="git commit")
commit.add_argument("--message", "-m", action="store")
git.add_subparser("commit", commit)
ns = git.parse_args(["commit", "-m", "fix bug"])
# ns._subcommand == "commit", ns.message == "fix bug"

# Dash normalization
ns = parser.parse_args(["--dry-run"])  # accessible as ns.dry_run
