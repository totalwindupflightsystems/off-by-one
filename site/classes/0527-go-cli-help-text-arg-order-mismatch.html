SOLUTION

Root cause (SPEC-GAP-001): contract diff parsed the first positional argument as the NEW contract (matching the library signature DetectChanges(new, old) — the deepest contract in the codebase), but every user-facing text site documented the arguments as <old> <new>. Specs were silent on the order, so the library signature was the only authority: it defines the direction of the diff, and inverting it would silently flip every "added"/"removed" pair. Changing the parser would break existing scripts (contract diff new.txt old.txt), so the correct fix is to align the text to the code — never the code to the text.
