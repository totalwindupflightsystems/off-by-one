CF-412 — Git porcelain directory residue classification

Problem class: git-porcelain-directory-residue-classification Project: code-factory · Source: scripts/ownership.py · Test: tests/test_ownership_residue.py Reference commit: ac3028115920ae11a99e4f56f70356d790270218 (six hermetic CLI regressions green)

1. Root cause

git status porcelain v1 reports an untracked directory as one record, not as its leaves. With default --untracked-files=normal, the rescue tree collapses:

$ git status --porcelain=v1
?? .gitreins/

$ git status --porcelain=v1 --untracked-files=all
?? .gitreins/rescue.patch

The classifier never sees .gitreins/rescue.patch, only .gitreins/. Two failure modes follow:

  1. Collapse (baseline). No -z/--untracked-files=all, so rescue-only and expanded-only repos produce the wrong residue set.
  2. Over-matching (substring control). A naive --untracked-files=all fix using prefix in path wrongly owns nested unrelated paths like vendor/.gitreins/rescue.patch. Ownership must be an anchored repository-root prefix test.

Tracked modifications (M, M, R, …) are not residue; only ?? records are eligible.

2. Exact fix

a) Enumerate every untracked leaf with NUL-safe porcelain:

subprocess.run(
    ["git", "-C", str(repo), "status", "--porcelain=v1",
     "-z", "--untracked-files=all"],
    check=True, stdout=subprocess.PIPE, stderr=subprocess.PIPE,
)

Parse XY<space>path NUL records; keep only ??; consume the extra origin record for R/C renames.

b) Anchor ownership at the repository-root prefix (porcelain paths are already root-relative, even from a subdir):

OWNED_PREFIXES = (".gitreins",)

def _normalize(path: str) -> str:
    path = path.replace("\\", "/")
    while path.startswith("./"):
        path = path[2:]
    return path

def is_owned_residue(path: str, prefixes=OWNED_PREFIXES) -> bool:
    normalized = _normalize(path)
    if normalized in ("", "."):
        return False
    for prefix in prefixes:
        root = _normalize(prefix).rstrip("/")
        if root and (normalized == root or normalized.startswith(root + "/")):
            return True
    return False

def classify_residue(repo, prefixes=OWNED_PREFIXES) -> list[str]:
    return [p for p in git_untracked_entries(repo)
            if is_owned_residue(p, prefixes)]

Minimal command-level patch that kills the collapse:

- ["git", "-C", repo, "status", "--porcelain=v1"]
+ ["git", "-C", repo, "status", "--porcelain=v1", "-z", "--untracked-files=all"]

…plus replacing substring matching with the anchored form above.
