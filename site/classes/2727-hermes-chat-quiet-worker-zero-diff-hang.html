Fixing hermes-chat-quiet-worker-zero-diff-hang

Problem class: a hermes chat -Q worker launched in the background with a brief that references a non-existent Go test helper (runCorsaTypeCheck) produced zero diff and zero log output for 6+ minutes, showed no liveness, and survived SIGTERM (needed kill -9). Related incidents: 0941 (approval-abort) and 1178 (empty-query).

Environment: Linux, Bash Deliverable: a drop-in supervised dispatcher (hermes-worker-run.sh) plus fail-fast preflight rules. Verified end-to-end in this sandbox (6/6 checks pass).

1. Root-cause analysis

The hang is not one bug; it is a chain of missing safety nets. Any one of them would have converted a 6-minute hang into a fast, diagnosable failure.

RC-1 — -Q (quiet) is an output policy, not a liveness signal

In quiet mode the worker emits no progress, so the dispatcher has nothing to observe. The "6 minutes of zero log output" is partly by design of -Q, and once stdout/stderr is a pipe or file (background dispatch), many runtimes switch to block buffering, so even non-quiet progress can sit in a buffer. A supervisor that uses "is there new log output?" as its only liveness probe cannot tell a busy worker from a dead one.

RC-2 — No wall-clock timeout and no idle watchdog

The worker was backgrounded (&) and then awaited indefinitely. There is no timeout, no deadline, and no "no progress for N seconds" rule. A blocked worker therefore runs forever by default; the operator, not the system, decides when to intervene.

RC-3 — Indefinite block on input (covers 1178 empty-query and 0941 approval-abort)

A backgrounded job inherits the parent's stdin. If the query is empty, the agent falls back to reading stdin; with an open pipe and no writer, read(2) blocks forever. Likewise, a tool call that needs approval can block forever when the approval channel is gone or aborted — quiet mode offers no way to surface or auto-answer the prompt. Both are blocking reads with no timeout.

RC-4 — Missing helper symbol drives an unbounded agent loop (runCorsaTypeCheck)

The brief named runCorsaTypeCheck, which does not exist. Two bad outcomes: * the tool/harness dispatcher waits for a result for a tool/helper it never resolved (no per-tool timeout), or * the agent retries the same phantom symbol in a loop. With no step budget and no output (RC-1), it burns the full 6 minutes without ever touching a file — hence zero diff.

RC-5 — Not a process group, so SIGTERM could not clean it up

The worker was backgrounded without setsid, so the agent and its subprocesses (e.g. go test) live in the same process group as the dispatcher. A supervisor that signals only the direct PID, or that signals a group that isn't isolated, leaves children alive. A stuck/TERM-ignoring child is exactly why kill -9 was required, and why leftovers can leak (the same leftovers that wedge the user manager per /usr/local/sbin/hermes-user-manager-heal.sh).

Why the diff was empty

Not a code-generation failure — the worker never got far enough. Blocked before/while invoking a non-existent helper, it never reached editing, so git diff was empty. Fix the hang and the diff appears (or the worker fails fast and tells you why).

2. The fix

Two layers: 1. Durable: replace bare hermes chat -Q ... & with a supervising dispatcher that validates first, isolates the worker in its own process group, never blocks on stdin, enforces a hard deadline + idle watchdog, and kills the whole group (TERM then KILL). 2. Agent-level hardening (recommended): a per-tool timeout + explicit "unknown tool/helper" error, and approval auto-deny in unattended mode.

2.1 Drop-in dispatcher: hermes-worker-run.sh

Save as /usr/local/bin/hermes-worker-run.sh and chmod +x.

#!/usr/bin/env bash
# hermes-worker-run.sh
# Supervised, non-interactive dispatch of a `hermes chat -Q` worker.
#
# Fixes the "quiet worker, zero diff, zero log, 6+ min hang" class:
#   * fail-fast preflight (empty brief / unknown helper symbol / build)
#   * worker gets its own session + process group (setsid)
#   * stdin is /dev/null so a missing/empty query can never block on read()
#   * hard wall-clock timeout AND idle (no-log-growth) watchdog
#   * SIGTERM the whole process group, then SIGKILL after a grace period
#   * single-flight lock per run name
#   * structured summary written even when the worker is killed
#
# Usage:
#   hermes-worker-run.sh [options] -- <worker command...>
#
# Example:
#   hermes-worker-run.sh --name corsa-1178 --repo /srv/corsa \
#       --brief /srv/briefs/corsa.md \
#       --require-symbol runCorsaTypeCheck \
#       --preflight 'go build ./...' \
#       --timeout 600 --idle 120 \
#       -- hermes chat --verbose --no-approval -p "$(cat /srv/briefs/corsa.md)"
set -Eeuo pipefail

log() { printf '%s [supervisor] %s\n' "$(date -Is)" "$*" >&2; }
die() { log "FATAL: $*"; exit 2; }

WORK_ROOT="${HERMES_WORK_ROOT:-${TMPDIR:-/tmp}/hermes-workers}"
HARD_TIMEOUT="${HERMES_WORKER_TIMEOUT:-900}"
IDLE_TIMEOUT="${HERMES_WORKER_IDLE_TIMEOUT:-180}"
KILL_AFTER="${HERMES_WORKER_KILL_AFTER:-30}"
POLL="${HERMES_WORKER_POLL:-5}"
APPROVAL_MODE="${HERMES_APPROVAL_MODE:-never}"
NAME=""
REPO="$PWD"
BRIEF=""
PREFLIGHT_CMD=""
REQUIRE_SYMBOLS=()
WORKER_CMD=()

usage() {
  sed -n '2,30p' "$0" >&2
  exit 2
}

while [[ $# -gt 0 ]]; do
  case "$1" in
    --name)           NAME="${2:?}"; shift 2 ;;
    --repo)           REPO="${2:?}"; shift 2 ;;
    --brief)          BRIEF="${2:?}"; shift 2 ;;
    --require-symbol) REQUIRE_SYMBOLS+=("${2:?}"); shift 2 ;;
    --preflight)      PREFLIGHT_CMD="${2:?}"; shift 2 ;;
    --timeout)        HARD_TIMEOUT="${2:?}"; shift 2 ;;
    --idle)           IDLE_TIMEOUT="${2:?}"; shift 2 ;;
    --kill-after)     KILL_AFTER="${2:?}"; shift 2 ;;
    --poll)           POLL="${2:?}"; shift 2 ;;
    --)               shift; WORKER_CMD=("$@"); break ;;
    -h|--help)        usage ;;
    *)                die "unknown option: $1 (put -- before the worker command)" ;;
  esac
done

[[ ${#WORKER_CMD[@]} -gt 0 ]] || die "no worker command given"
[[ -d "$REPO" ]] || die "repo directory not found: $REPO"

# ---- fail-fast preflight ---------------------------------------------------
# incident 1178: empty query -> agent blocks forever waiting for input.
if [[ -n "$BRIEF" ]]; then
  [[ -f "$BRIEF" ]] || die "brief not found: $BRIEF"
  grep -q '[^[:space:]]' "$BRIEF" || die "brief is empty/whitespace (empty-query guard)"
fi

# unknown Go helper referenced by the brief (e.g. runCorsaTypeCheck) must fail
# in milliseconds, not after six minutes of an agent retry loop.
for sym in "${REQUIRE_SYMBOLS[@]}"; do
  if git -C "$REPO" rev-parse --git-dir >/dev/null 2>&1; then
    git -C "$REPO" grep -qw -- "$sym" -- '*.go' \
      || die "brief references unknown Go helper '$sym' (no such symbol in tracked files)"
  else
    grep -Rqw --include='*.go' -- "$sym" "$REPO" \
      || die "brief references unknown Go helper '$sym'"
  fi
done

if [[ -n "$PREFLIGHT_CMD" ]]; then
  log "preflight: $PREFLIGHT_CMD"
  ( cd "$REPO" && timeout "$HARD_TIMEOUT" bash -o pipefail -c "$PREFLIGHT_CMD" ) \
    || die "preflight failed"
fi

# ---- run directory + single-flight lock ------------------------------------
NAME="${NAME:-$(date +%Y%m%dT%H%M%S)-$$}"
mkdir -p "$WORK_ROOT"
RUN_DIR="$WORK_ROOT/$NAME"
mkdir -p "$RUN_DIR"
LOG_FILE="$RUN_DIR/worker.log"
SUMMARY="$RUN_DIR/summary.env"
: > "$LOG_FILE"

exec 9>"$RUN_DIR/.lock"
flock -n 9 || die "another worker already holds lock for '$NAME'"

# ---- launch worker in its own session / process group ----------------------
# stdin </dev/null: never block on read().  setsid: own pgid so we can signal
# the whole tree (agent + go test subprocesses) with one negative-pid kill.
cmd_str=""
for a in "${WORKER_CMD[@]}"; do printf -v q '%q' "$a"; cmd_str+="$q "; done

log "launching '$NAME' repo=$REPO timeout=${HARD_TIMEOUT}s idle=${IDLE_TIMEOUT}s"
(
  cd "$REPO"
  export PYTHONUNBUFFERED=1
  export HERMES_APPROVAL_MODE="$APPROVAL_MODE"
  exec </dev/null
  exec setsid bash -c 'exec '"$cmd_str" >"$LOG_FILE" 2>&1
) &
child=$!

# resolve the process-group id (setsid makes child a group/session leader)
PGID=""
for _ in $(seq 20); do
  PGID="$(ps -o pgid= -p "$child" 2>/dev/null | tr -d ' ' || true)"
  [[ -n "$PGID" ]] && break
  sleep 0.1
done
[[ -n "$PGID" ]] || PGID="$child"
log "worker pid=$child pgid=$PGID"

# ---- watchdog: hard wall-clock + no-log-growth idle timer ------------------
start=$(date +%s)
last_size=-1
last_change=$start
reason=""

group_alive() { kill -0 -- "-$PGID" 2>/dev/null; }

while group_alive; do
  now=$(date +%s)
  size=$(stat -c%s "$LOG_FILE" 2>/dev/null || echo 0)
  if [[ "$size" != "$last_size" ]]; then
    last_size="$size"; last_change="$now"
  fi
  if (( now - start >= HARD_TIMEOUT )); then
    reason="hard-timeout ${HARD_TIMEOUT}s"; break
  fi
  if (( now - last_change >= IDLE_TIMEOUT )); then
    reason="idle ${IDLE_TIMEOUT}s (no log growth)"; break
  fi
  sleep "$POLL"
done

# ---- deterministic teardown: TERM the group, then KILL ---------------------
killed=0
if [[ -n "$reason" ]]; then
  killed=1
  log "watchdog fired: $reason -- SIGTERM pgid $PGID"
  kill -TERM -- "-$PGID" 2>/dev/null || kill -TERM "$child" 2>/dev/null || true
  for _ in $(seq "$KILL_AFTER"); do
    group_alive || break
    sleep 1
  done
  if group_alive; then
    log "pgid $PGID ignored SIGTERM -- SIGKILL"
    kill -KILL -- "-$PGID" 2>/dev/null || kill -KILL "$child" 2>/dev/null || true
  fi
fi

rc=0
wait "$child" 2>/dev/null || rc=$?
end=$(date +%s)

# ---- summary always emitted (even on kill) ---------------------------------
changed="?"
if git -C "$REPO" rev-parse --git-dir >/dev/null 2>&1; then
  changed="$(git -C "$REPO" status --porcelain | wc -l | tr -d ' ')"
fi
{
  printf 'name=%s\n'        "$NAME"
  printf 'repo=%s\n'        "$REPO"
  printf 'pid=%s\n'         "$child"
  printf 'pgid=%s\n'        "$PGID"
  printf 'rc=%s\n'          "$rc"
  printf 'duration_s=%s\n'  "$((end - start))"
  printf 'killed=%s\n'      "$killed"
  printf 'reason=%s\n'      "$reason"
  printf 'changed_paths=%s\n' "$changed"
  printf 'log=%s\n'         "$LOG_FILE"
} > "$SUMMARY"

log "finished rc=$rc duration=$((end - start))s killed=$killed changed=$changed"
log "summary: $SUMMARY"

if (( killed )); then
  exit 124           # conventional timeout exit status
fi
exit "$rc"

2.2 Change the dispatch call-site

Before (hang-prone):

# inherits stdin; no deadline; no group isolation; -Q hides all progress
hermes chat -Q -p "$brief_text" >/tmp/worker.log 2>&1 &
wait $!

After (supervised, fail-fast):

hermes-worker-run.sh \
  --name "corsa-$(date +%s)" \
  --repo /srv/corsa \
  --brief /srv/briefs/corsa.md \
  --require-symbol runCorsaTypeCheck \
  --preflight 'go build ./... && go vet ./...' \
  --timeout 600 \
  --idle 120 \
  --kill-after 30 \
  -- hermes chat --verbose --no-approval -p "$(cat /srv/briefs/corsa.md)"

Notes: * Drop -Q for background work; use the verbose/log flag so the idle watchdog has a liveness signal. If you must keep -Q, keep the hard --timeout (it always applies) and lower --idle. * --require-symbol is the specific guard for the runCorsaTypeCheck failure: the run never starts if the brief names a Go identifier absent from tracked *.go files. * --preflight 'go build ./...' catches a compile-level phantom helper even when referenced from a non-.go file.

2.3 One-line mitigation if you cannot deploy the wrapper yet

# hard deadline + own session + closed stdin + whole-group TERM then KILL
timeout --signal=TERM --kill-after=30s 600s \
  setsid bash -c 'exec </dev/null; exec hermes chat --verbose --no-approval -p "$1"' _ "$brief_text" \
  >/tmp/worker.log 2>&1

2.4 Agent-level hardening (durable, recommended)

dispatch(tool_call):
    handler = registry.lookup(tool_call.name)
    if handler is None:
        return ToolError("unknown tool '%s' (helper does not exist)" % name)  # never block
    return run_with_timeout(handler, tool_call, timeout=per_tool_timeout)

approval_request(prompt):
    if mode == "never" or not sys.stdin.isatty():
        return ApprovalDenied("unattended: approvals disabled")  # no deadlock

And add a per-turn step budget so a retry loop on a missing symbol terminates with a clear error instead of silently burning the deadline.

3.1 Verification harness (verify.sh) and mock

#!/usr/bin/env bash
# mock/mock-worker.sh — worst-case worker: no output, ignores SIGTERM, spawns a child.
set -u
mode="${1:-ok}"; shift || true
case "$mode" in
  ok)          echo "worker: starting"; sleep 1; echo "worker: finished"; exit 0 ;;
  hang)        trap '' TERM; ( trap '' TERM; while :; do sleep 1; done ) & while :; do sleep 1; done ;;
  child)       trap '' TERM; bash -c 'trap "" TERM; while :; do sleep 1; done' & while :; do sleep 1; done ;;
  empty-query) if IFS= read -r line; then echo "got: $line"; exit 0; fi
               echo "empty query detected -> fast fail" >&2; exit 3 ;;
  *)           echo "unknown mode" >&2; exit 64 ;;
esac

#!/usr/bin/env bash
# verify.sh
set -u
HERE="$(cd "$(dirname "$0")" && pwd)"
SUP="$HERE/hermes-worker-run.sh"; MOCK="$HERE/mock/mock-worker.sh"
WORK="$(mktemp -d)"; trap 'rm -rf "$WORK"' EXIT
export HERMES_WORK_ROOT="$WORK/runs"
pass=0; fail=0
ok()  { printf 'PASS: %s\n' "$1"; pass=$((pass+1)); }
bad() { printf 'FAIL: %s\n' "$1"; fail=$((fail+1)); }

mkdir -p "$WORK/repo"
printf 'package corsa\n\nfunc runCorsaTypeCheck() {}\n' > "$WORK/repo/x.go"
printf 'hello brief\n' > "$WORK/repo/brief.md"; : > "$WORK/repo/empty.md"

# T1: unknown helper symbol fails fast, no worker started
t0=$(date +%s)
if timeout 5 "$SUP" --name t1 --repo "$WORK/repo" --require-symbol runCorsaTypeCheck \
      --require-symbol functionThatDoesNotExist -- "$MOCK" ok >/dev/null 2>&1; then
  bad "expected failure for missing symbol"
else
  t1=$(date +%s); (( t1-t0 <= 2 )) && [[ ! -d "$HERMES_WORK_ROOT/t1" ]] \
    && ok "missing symbol rejected in $((t1-t0))s before dispatch" \
    || bad "missing symbol took $((t1-t0))s or a run dir was created"
fi

# T2: empty brief fails fast
timeout 5 "$SUP" --name t2 --repo "$WORK/repo" --brief "$WORK/repo/empty.md" -- "$MOCK" empty-query \
  >/dev/null 2>&1 && bad "expected empty-brief rejection" || ok "empty brief rejected before dispatch"

# T3: happy path logs captured, rc=0, no kill
"$SUP" --name t3 --repo "$WORK/repo" --brief "$WORK/repo/brief.md" \
  --timeout 30 --idle 10 -- "$MOCK" ok >/dev/null 2>&1
[[ $? -eq 0 ]] && grep -q 'worker: finished' "$HERMES_WORK_ROOT/t3/worker.log" \
  && grep -q 'killed=0' "$HERMES_WORK_ROOT/t3/summary.env" \
  && ok "worker output captured and clean exit" || bad "happy path"

# T4: TERM-ignoring hang is killed as a process group
"$SUP" --name t4 --repo "$WORK/repo" --brief "$WORK/repo/brief.md" \
  --timeout 2 --idle 1 --kill-after 2 --poll 1 -- "$MOCK" child >/dev/null 2>&1
rc=$?; pgid="$(awk -F= '/^pgid=/{print $2}' "$HERMES_WORK_ROOT/t4/summary.env")"
leftover=0; [[ -n "$pgid" ]] && kill -0 -- "-$pgid" 2>/dev/null && leftover=1
[[ $rc -eq 124 && $leftover -eq 0 ]] \
  && ok "hang terminated (rc=124), process group $pgid fully reaped" \
  || bad "rc=$rc leftover=$leftover pgid=$pgid"

# T5a: reproduce the stdin deadlock with an inherited open pipe
mkfifo "$WORK/f"; exec 8<>"$WORK/f"
"$MOCK" empty-query <"$WORK/f" >/dev/null 2>&1 & old=$!; sleep 2
kill -0 "$old" 2>/dev/null && { ok "reproduced: inherited-open-stdin worker blocks on read()"; kill -KILL "$old" 2>/dev/null; } \
  || bad "could not reproduce stdin block"
exec 8>&-; rm -f "$WORK/f"; wait "$old" 2>/dev/null || true

# T5b: supervisor closes stdin -> fast fail
t0=$(date +%s)
timeout 5 "$SUP" --name t5 --repo "$WORK/repo" --brief "$WORK/repo/brief.md" \
  --timeout 3 --idle 1 -- "$MOCK" empty-query >/dev/null 2>&1; rc=$?; t1=$(date +%s)
[[ $rc -eq 3 ]] && (( t1-t0 <= 3 )) \
  && ok "empty query fails fast (rc=3 in $((t1-t0))s), no read() deadlock" \
  || bad "expected rc=3, got rc=$rc in $((t1-t0))s"

echo; echo "RESULT: $pass passed, $fail failed"; exit $(( fail > 0 ))

4. Prevention checklist

  1. Never dispatch an unattended worker with a quiet flag and no deadline.
  2. Always give workers their own process group (setsid) and kill with kill -- -PGID, TERM then KILL.
  3. Always redirect backgrounded worker stdin from /dev/null; pass the query explicitly.
  4. Validate the brief before dispatch: non-empty, and every referenced helper/tool exists.
  5. Add a per-tool timeout and an explicit "unknown tool" error.
  6. Auto-deny/auto-abort approvals in non-TTY mode.
  7. Emit a structured summary (rc, duration_s, killed, reason, changed_paths) on every run, including kills.
