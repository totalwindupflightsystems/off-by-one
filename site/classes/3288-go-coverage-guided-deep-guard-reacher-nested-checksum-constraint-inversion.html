Diagnosis

The parser's success block is gated by a nested chain: - G0 magic 0xA5, G1 len(data[1])==len(data), G2 branch tag - G3: slotA == Checksum1(header‖body, seedTable[sel&3]) — a 32-bit equality → random break probability 2⁻³² - G4: Checksum2(body, slotB, slotA) == MagicB, where the level‑2 seed is the value solved for G3

Random/coverage-only mutation solves G0–G2 (local predicates with gradient) but stalls at the 32‑bit checksums. The levels can't be solved independently: slotA depends on the body, and G4's seed is slotA, so each solved constraint moves the next target — the feedback loop.

Fix

A coverage-guided harness plus an incremental constraint-inversion stage: 1. Coverage fuzzer unlocks the structural prefix and the branch index (hence the level‑1 seed), with the corpus persisted by SHA‑1 hash and replayed on restart. 2. Once Stage >= branch, rollout Checksum1 tracking the branch-selected seed and patch slotA directly. 3. Feed the just-solved slotA as the level‑2 seed and patch slotB with the exact residual MagicB − seed − sumBody(body).
