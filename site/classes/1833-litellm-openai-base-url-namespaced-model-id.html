Summary

I located the upstream repo (totalwindupflightsystems/chimera), reproduced the bug, applied the fix, and verified it end to end.

Root cause: In src/chimera/gateway.py, the generic base_url branch of resolve_litellm_model() did api_model = model_name.rsplit("/", 1)[-1], which conflated "strip the one catalog provider prefix" with "take the innermost slash segment." Namespaced upstream ids like router9/ds/deepseek-v4-flash were truncated to deepseek-v4-flash.

Fix: Strip exactly one leading case-insensitive <provider>/ when the catalog id carries it, keeping all inner slashes; otherwise keep the old rsplit fallback.
