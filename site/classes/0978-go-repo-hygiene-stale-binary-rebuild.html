Diagnosis (premise correction): PM's report "tracked binary bin/consensus STALE, users git pull get old binary" is based on a wrong premise. bin/ is gitignored (.gitignore has /bin/) and no binary was ever committed — git pull can never serve a stale binary that isn't in the repo. The real issue is only a stale local artifact from an old build. The correct fix is a rebuild from HEAD plus a live functional verify; no code commit is needed, and the build step is already documented in README/quickstart/deployment runbooks.

The fix (applied from pinned HEAD, e.g. bea9648):

# 1. Rebuild the artifact from HEAD (not from a stale local checkout)
git -C /path/to/consensus checkout bea9648          # pin to reported HEAD
go -C /path/to/consensus build -o bin/consensus ./cmd/consensus

# 2. Prove the rebuild actually refreshed the artifact
stat -c '%y %s %n' bin/consensus                     # mtime must be "now"

# 3. Live functional verify from a fresh scratch dir (no repo state leaks in)
mkdir -p /tmp/scratch && cd /tmp/scratch
/path/to/consensus/bin/consensus init                # expect: Memory bank: ready
find .memory-bank                                    # expect: skeleton files present

# 4. Idempotency: re-run must be clean and leave files untouched
/path/to/consensus/bin/consensus init                # expect: exit 0, "already initialized"

# 5. Confirm git state is clean (bin/ stays untracked by design)
git -C /path/to/consensus status --porcelain         # expect: empty

The init subcommand is written to be idempotent — it only writes the .memory-bank skeleton (C-GAP-013 bootstrap) when absent:

func initCmd() int {
    const dir = ".memory-bank"
    if err := os.MkdirAll(dir, 0o755); err != nil {
        fmt.Fprintf(os.Stderr, "init: %v\n", err)
        return 1
    }
    readme := filepath.Join(dir, "README.md")
    if _, err := os.Stat(readme); os.IsNotExist(err) {
        os.WriteFile(readme, []byte("# Memory bank\n"), 0o644)
        fmt.Println("Memory bank: ready (.memory-bank skeleton created)")
    } else {
        fmt.Println("Memory bank: ready (already initialized)") // idempotent
    }
    return 0
}
