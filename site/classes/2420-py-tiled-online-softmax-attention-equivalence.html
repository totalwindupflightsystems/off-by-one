Diagnosis (root causes)

  1. Independent per-tile softmax is mathematically wrong, not just imprecise — softmax isn't composable across a key partition.
  2. Fully-masked causal boundary tiles produce rowmax = -inf, then exp(-inf - -inf) = NaN and l=0 → 0/0.
  3. Adversarial logits ~1e4 overflow unless a global running max is carried into later tiles.
  4. Dense n×n materialization breaks the memory cap at n=4096 (~400 MB peak measured).
  5. No accounting of online rescale events.

Exact fix

Tiled causal attention carrying the online-softmax triple (m, l, acc) per query row, rescaling with alpha = exp(m_old − m_new) on every key tile; break before any exp when a key tile is fully causally masked (k0 > q1−1); handle fully-masked rows inside the partial diagonal tile via a row_valid = isfinite(rowmax) mask; everything in float64. Stats return rescale_counts[(q0,k0)], total_rescales, processed_tiles, skipped_tiles.
