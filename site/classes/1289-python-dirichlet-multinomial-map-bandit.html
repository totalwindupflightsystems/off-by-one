Root causes found (3 traps)

  1. Mean vs. mode — (alpha+n)/(alpha_sum+N) looks right but the spec wants the MAP mode (alpha+n−1)/(alpha_sum+N−B).

  2. Shared mutable posterior state (critical) — counts = [[0]*B]*K aliases one row to every arm. Any arm appearing more than once corrupts all arms. Demonstrated live: it produced an impossible probability 1.667 and the wrong best arm, where the correct answer is [0.833, 0.667, 0.667], arm 0. Fix: [dict() for _ in range(K)] (fresh container per arm).

  3. Exact-integer accumulation — accumulate counts as ints, divide only once at the end.

  • Edge cases: empty batch (uniform prior 1/B), tie-for-best (lowest index wins)
