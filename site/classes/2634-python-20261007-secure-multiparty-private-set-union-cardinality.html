The technical defect is the "blind locally, then union" PSU-CA shortcut: because g^(H(x)·k_i) ≠ g^(H(x)·k_j), each shared element is counted once per holder, inflating the cardinality by m−1 for every element held by m parties (and it leaks if plaintext is unioned).
