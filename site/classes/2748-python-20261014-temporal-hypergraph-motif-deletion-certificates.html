Temporal Hypergraph Motif Counting with Deletion Certificates

Verified solution written to ~/work/SOLUTION.md (and runnable files temporal_motifs.py, test_temporal_motifs.py). The fenced code below was extracted and executed independently — all 300 differential seeds + adversarial suites pass.

Problem

Maintain exact counts of induced motifs of size ≤ 6 in a temporal hypergraph under online edge insertions/deletions. Hyperedges carry interval lifetimes, counts obey a bounded temporal-span rule, overlap patterns are adversarial, and every count change must come with a compact, independently checkable certificate — without rescanning the whole incidence structure.

Root-cause analysis

A naive implementation fails for four independent reasons; all must be fixed together.

  1. Temporal validity is a continuum, but intervals are tractable. "Active at a common time within a window W" looks like it needs sampling. For intervals it is closed-form: a set F has a common active instant iff max_e l_e < min_e r_e (Helly for intervals), and bounded span is max_e r_e − min_e l_e ≤ W. Witness t = max_e l_e. No sampling.

  2. "Induced" + deletions is the hard part. F(S) = {e : verts(e) ⊆ S} is not additive: deleting one edge changes F(S) for every S ⊇ verts(e). Correct invariant: an update of e can only change occurrences whose S contains verts(e); recompute only those supersets.

  3. Occurrences must be canonical, or counts drift. Allowing uncovered vertices in S lets unrelated supersets appear/disappear. Enforce closure S = ⋃_{e∈F(S)} verts(e), making occurrences bijective with closed edge sets and the affected set exactly the supersets of verts(e).

  4. A count delta is not a proof. Emit signed certificates carrying the full edge descriptions, witness, and span; a verifier re-derives validity and induction-completeness from them.

A fifth trap in the reference code: probing the "rarest vertex" to compute F(S) is wrong — an edge inside S need not touch the rarest vertex. The fix unions incidence lists of all vertices of S.

Exact fix

Semantics (fixed, unambiguous)

  • Edge e = (S_e, l_e, r_e), non-empty S_e, integer lifetime [l_e, r_e).
  • F(S) = { e active : S_e ⊆ S } for |S| ≤ KMAX = 6.
  • Occurrence (S, F(S)): F(S) ≠ ∅, closure S = ⋃ verts(e), and validity max l_e < min r_e and max r_e − min l_e ≤ W.
  • V_active = ⋃ of active-edge vertex sets; S ⊆ V_active.
  • Count is the number of occurrences; patterns() groups by exact isomorphism class (min incidence signature over ≤ 720 relabelings).

Algorithm and data structures

  • active, by_vertex, vertex_deg, occ : (S, frozenset(F)) → certificate.
  • _induced(S) unions by_vertex[v] for v ∈ S and filters verts ⊆ S.
  • _supersets(base) enumerates S ⊇ base, |S| ≤ 6, from V_active (O(|V|^5), KMAX fixed).
  • Insert: update indexes; diff every superset of verts(e); emit −/+ certs.
  • Delete: build − certs while e is still active, remove it, then + certs over post-state.
  • Per-update complexity O(|V|^5 · D) vs O(|V|^6·|E|) full recomputation. The index removes the full-incidence rescan.

"""
Exact online induced-motif counting over temporal hypergraphs, with
independently checkable change certificates.
"""
from __future__ import annotations

from collections import Counter
from itertools import combinations, permutations
from typing import Dict, FrozenSet, List, Optional, Set, Tuple

KMAX = 6


class Edge:
    __slots__ = ("eid", "verts", "l", "r")

    def __init__(self, eid, verts, l, r):
        self.eid = eid
        self.verts = frozenset(verts)
        self.l = int(l)
        self.r = int(r)
        if not self.verts:
            raise ValueError("edge %r has empty vertex set" % (eid,))
        if self.l >= self.r:
            raise ValueError("edge %r has empty lifetime" % (eid,))


def span_ok(edges, W: int) -> Tuple[bool, Optional[int]]:
    """(valid, witness) for a non-empty edge set under the bounded-span rule."""
    if not edges:
        return False, None
    max_l = max(e.l for e in edges)
    min_r = min(e.r for e in edges)
    if max_l >= min_r:                       # no common active instant
        return False, None
    if max(e.r for e in edges) - min(e.l for e in edges) > W:
        return False, None
    return True, max_l


# ----------------------------- certificates --------------------------------

def make_certificate(sign: str, S: FrozenSet[int], F: Tuple[str, ...],
                     state: Dict[str, Edge], W: int) -> dict:
    edges = [state[e] for e in F]
    valid, witness = span_ok(edges, W)
    assert valid and edges
    return {
        "sign": sign,
        "vertices": sorted(S),
        "edge_ids": list(F),
        "edges": [
            {"eid": e.eid, "verts": sorted(e.verts), "l": e.l, "r": e.r}
            for e in edges
        ],
        "witness": witness,
        "span": max(e.r for e in edges) - min(e.l for e in edges),
        "W": W,
    }


def verify_certificate(cert: dict, state: Dict[str, Edge],
                       KMAX: int = KMAX) -> bool:
    """Check one certificate against the state in which it was emitted."""
    S = set(cert["vertices"])
    if not S or len(S) > KMAX:
        return False
    F = list(cert["edge_ids"])
    if not F:
        return False
    embedded = {e["eid"]: e for e in cert["edges"]}
    if set(embedded) != set(F):
        return False
    union = set()
    for eid in F:
        if eid not in state:
            return False
        live = state[eid]
        d = embedded[eid]
        if sorted(live.verts) != d["verts"] or live.l != d["l"] or live.r != d["r"]:
            return False
        if not live.verts <= S:
            return False
        union |= set(live.verts)
    if union != S:                                 # closure: no isolated vertex
        return False
    induced = frozenset(eid for eid, e in state.items() if e.verts <= S)
    if induced != frozenset(F):                    # completeness of induction
        return False
    edges = [Edge(d["eid"], d["verts"], d["l"], d["r"]) for d in cert["edges"]]
    valid, witness = span_ok(edges, cert["W"])
    if not valid or witness != cert["witness"]:
        return False
    if cert["span"] != max(e.r for e in edges) - min(e.l for e in edges):
        return False
    return True


def verify_transcript(transcript: List[dict], pre: Dict[str, Edge],
                      post: Dict[str, Edge]) -> Tuple[bool, int]:
    """Audit an update: '-' against pre-state, '+' against post-state."""
    net = 0
    for c in transcript:
        state = pre if c["sign"] == "-" else post
        if not verify_certificate(c, state):
            return False, net
        net += 1 if c["sign"] == "+" else -1
    return True, net


# ----------------------------- incremental engine --------------------------

class TemporalHypergraph:
    def __init__(self, W: int, KMAX: int = KMAX):
        self.W = int(W)
        self.KMAX = int(KMAX)
        self.active: Dict[str, Edge] = {}
        self.by_vertex: Dict[int, Set[str]] = {}
        self.vertex_deg: Dict[int, int] = {}
        self.occ: Dict[Tuple[FrozenSet[int], FrozenSet[str]], dict] = {}

    def _induced(self, S: FrozenSet[int]) -> Tuple[str, ...]:
        if not S:
            return ()
        cand: Set[str] = set()
        for v in S:                       # union incidence: NOT the rarest vertex
            cand |= self.by_vertex.get(v, set())
        return tuple(sorted(eid for eid in cand if self.active[eid].verts <= S))

    def _valid(self, S: FrozenSet[int]) -> Optional[Tuple[str, ...]]:
        F = self._induced(S)
        if not F:
            return None
        union = set()
        for eid in F:
            union |= self.active[eid].verts
        if frozenset(union) != S:         # closure / no isolated vertices
            return None
        ok, _ = span_ok([self.active[e] for e in F], self.W)
        return F if ok else None

    def _supersets(self, base: FrozenSet[int]):
        extra = sorted(set(self.vertex_deg) - set(base))
        max_extra = self.KMAX - len(base)
        if max_extra < 0:
            return
        bs = set(base)
        for k in range(max_extra + 1):
            for combo in combinations(extra, k):
                yield frozenset(bs | set(combo))

    def _occ_keys(self, S: FrozenSet[int]):
        return [k for k in self.occ if k[0] == S]

    def add_edge(self, eid, verts, l, r) -> List[dict]:
        if eid in self.active:
            raise KeyError("edge %r already active" % (eid,))
        e = Edge(eid, verts, l, r)
        self.active[eid] = e
        for v in e.verts:
            self.by_vertex.setdefault(v, set()).add(eid)
            self.vertex_deg[v] = self.vertex_deg.get(v, 0) + 1

        certs: List[dict] = []
        for S in self._supersets(e.verts):
            old = self._occ_keys(S)
            Fnew = self._valid(S)
            newF = frozenset(Fnew) if Fnew else None
            if old:
                if old[0][1] != newF:
                    for k in old:
                        certs.append(make_certificate("-", S, k[1], self.active, self.W))
                        del self.occ[k]
                    if newF is not None:
                        c = make_certificate("+", S, Fnew, self.active, self.W)
                        self.occ[(S, newF)] = c
                        certs.append(c)
            elif newF is not None:
                c = make_certificate("+", S, Fnew, self.active, self.W)
                self.occ[(S, newF)] = c
                certs.append(c)
        return certs

    def remove_edge(self, eid) -> List[dict]:
        e = self.active[eid]
        stale = []
        for S in set(self._supersets(e.verts)):
            for k in self._occ_keys(S):
                stale.append((S, k))
        # removal certificates built while the edge is still active
        certs = [make_certificate("-", S, k[1], self.active, self.W)
                 for S, k in stale]

        del self.active[eid]
        for v in e.verts:
            self.by_vertex[v].discard(eid)
            if not self.by_vertex[v]:
                del self.by_vertex[v]
            self.vertex_deg[v] -= 1
            if self.vertex_deg[v] == 0:
                del self.vertex_deg[v]
        for _, k in stale:
            del self.occ[k]

        for S in self._supersets(e.verts):      # additions over post-state
            Fnew = self._valid(S)
            if Fnew:
                key = (S, frozenset(Fnew))
                if key not in self.occ:
                    c = make_certificate("+", S, Fnew, self.active, self.W)
                    self.occ[key] = c
                    certs.append(c)
        return certs

    def count(self) -> int:
        return len(self.occ)

    def patterns(self) -> Dict[tuple, int]:
        c = Counter()
        for (S, F) in self.occ:
            c[self._canon(S, F)] += 1
        return dict(c)

    def _canon(self, S: FrozenSet[int], F: FrozenSet[str]) -> tuple:
        Sv = sorted(S)
        idx = {v: i for i, v in enumerate(Sv)}
        sigs = [tuple(sorted(idx[x] for x in self.active[e].verts)) for e in F]
        best = None
        for p in permutations(range(len(Sv))):
            sig = tuple(sorted(tuple(sorted(p[i] for i in es)) for es in sigs))
            if best is None or sig < best:
                best = sig
        return best


# ----------------------------- brute-force oracle --------------------------

def brute_force(active: Dict[str, Edge], W: int, KMAX: int = KMAX):
    V = sorted({v for e in active.values() for v in e.verts})
    occ = {}
    for k in range(1, KMAX + 1):
        for combo in combinations(V, k):
            S = frozenset(combo)
            F = tuple(sorted(eid for eid, e in active.items() if e.verts <= S))
            if not F:
                continue
            union = set()
            for eid in F:
                union |= active[eid].verts
            if frozenset(union) != S:
                continue
            valid, witness = span_ok([active[e] for e in F], W)
            if valid:
                occ[(S, frozenset(F))] = witness
    return occ

"""Differential + adversarial verification for temporal_motifs.py."""
import random
import sys

from temporal_motifs import (
    Edge, TemporalHypergraph, brute_force, span_ok,
    verify_transcript, verify_certificate,
)


def diff_test(seed, n_vertices=6, n_ops=40, W=None, max_edges=5):
    rng = random.Random(seed)
    if W is None:
        W = rng.randint(1, 6)
    g = TemporalHypergraph(W)
    edges, live, counter = {}, set(), 0
    for step in range(n_ops):
        can_add = len(live) < max_edges
        do_add = can_add and (not live or rng.random() < 0.6)
        if do_add:
            verts = rng.sample(range(n_vertices), rng.randint(1, 3))
            l = rng.randint(0, 4); r = l + rng.randint(1, 5)
            eid = "e%d" % counter; counter += 1
            pre = dict(g.active); before = g.count()
            certs = g.add_edge(eid, verts, l, r)
            edges[eid] = Edge(eid, verts, l, r); live.add(eid)
            changed = eid
        else:
            eid = rng.choice(sorted(live))
            pre = dict(g.active); before = g.count()
            certs = g.remove_edge(eid)
            live.discard(eid); changed = eid
        post = dict(g.active)

        oracle = brute_force(g.active, W)
        if set(g.occ.keys()) != set(oracle.keys()):
            return "seed %d step %d: occurrence set mismatch" % (seed, step)
        ok, net = verify_transcript(certs, pre, post)
        if not ok:
            return "seed %d step %d: certificate verification failed" % (seed, step)
        if net != g.count() - before:
            return "seed %d step %d: net delta != count delta" % (seed, step)
        for c in certs:
            if do_add and c["sign"] == "+" and changed not in c["edge_ids"]:
                return "seed %d step %d: add cert not tied to edge" % (seed, step)
            if (not do_add) and c["sign"] == "-" and changed not in c["edge_ids"]:
                return "seed %d step %d: del cert not tied to edge" % (seed, step)
    return None


def adversarial_tests():
    failures = []
    for W in (1, 2, 4, 8):                          # heavy common-core overlap
        g = TemporalHypergraph(W)
        for i in range(6):
            g.add_edge("a%d" % i, [0, 1 + (i % 3)], 0, 3)
        if set(g.occ) != set(brute_force(g.active, W)):
            failures.append("overlap add W=%d" % W)
        for i in range(6):
            g.remove_edge("a%d" % i)
            if set(g.occ) != set(brute_force(g.active, W)):
                failures.append("overlap del %d W=%d" % (i, W))
    for W in (2, 3, 10):                            # chained overlaps
        g = TemporalHypergraph(W)
        for i in range(5):
            g.add_edge("c%d" % i, [i, i + 1], i, i + 3)
        if set(g.occ) != set(brute_force(g.active, W)):
            failures.append("chain add W=%d" % W)
        for i in range(4, -1, -1):
            g.remove_edge("c%d" % i)
            if set(g.occ) != set(brute_force(g.active, W)):
                failures.append("chain del %d W=%d" % (i, W))
    g = TemporalHypergraph(3)                       # span-splitting insertion
    g.add_edge("x", [1, 2], 0, 2); g.add_edge("y", [1, 3], 0, 2)
    before = g.count()
    certs = g.add_edge("z", [1, 2, 3], 4, 5)
    if set(g.occ) != set(brute_force(g.active, 3)):
        failures.append("span-split state")
    pre = {k: v for k, v in g.active.items() if k != "z"}
    ok, net = verify_transcript(certs, pre, g.active)
    if not ok or net != g.count() - before:
        failures.append("span-split transcript")
    return failures


def main():
    g = TemporalHypergraph(3)
    c1 = g.add_edge("p", [0, 1], 0, 2)
    c2 = g.add_edge("q", [1, 2], 0, 2)
    assert g.count() == len(brute_force(g.active, 3))
    assert all(verify_certificate(c, g.active) for c in c1 + c2)
    g2 = TemporalHypergraph(1)
    g2.add_edge("m", [0], 0, 5); g2.add_edge("n", [0], 4, 5)
    assert g2.count() == 0
    assert span_ok([g2.active["m"], g2.active["n"]], 1)[0] is False

    bad = [r for r in (diff_test(s) for s in range(300)) if r]
    print("differential seeds passed: %d/%d" % (300 - len(bad), 300))
    for b in bad[:10]:
        print("  FAIL", b)
    adv = adversarial_tests()
    print("adversarial checks passed:", not adv)
    for a in adv:
        print("  FAIL", a)
    if bad or adv:
        sys.exit(1)
    print("ALL VERIFIED")


if __name__ == "__main__":
    main()

  • certificate verification failed — each − cert replays against pre-state, each + against post-state: embedded edge data matches live incidence, S_e ⊆ S, closure, induction completeness, and the common-instant + span predicate at the stated witness.
  • net delta != count delta — signed certs sum to the real count change.
  • causal tie — on insert every + cert contains the inserted edge; on delete every − cert contains the deleted edge.
  • adversarial suites — 6 fully overlapping equal-lifetime edges and a 5-edge overlap chain inserted then deleted one-by-one, re-checked at every intermediate state, plus the span-splitting case.

add h3 shows the non-additive case: inserting a 3-vertex edge lowers the count because two induced 2-vertex occurrences are replaced by one closed 3-vertex occurrence, emitted as a combined −/−/+ certificate set.

Why the certificates are independently checkable

A verifier needs only (W, KMAX), the certificate, and the incidence state in which it was emitted; it never trusts the engine or re-runs the count. It checks length bound, embedded-vs-live edge equality, S_e ⊆ S, closure, induction completeness, and the interval predicate at the witness. A whole update is audited by replaying − against pre-state and + against post-state and confirming the signed sum equals the observed count() change.

Notes and extensions

  • Raising KMAX stays correct but superset enumeration grows as O(|V|^(KMAX-1)).
  • patterns() is a separate observation call so the hot mutation path stays cheap.
  • For very large V, shard by a covering hash of verts(e); the closure invariant keeps disconnected S components reachable only through induced edge sets, so bucketing must keep edges whose vertex sets lie in the same bucket.
