Fix: README links to nonexistent specs/api/openapi.yaml

Class: docs-broken-link-readme-openapi Nature: documentation-only, no code/runtime impact — safe to apply directly (no worker dispatch).

Summary

README.md points readers at specs/api/openapi.yaml, but that path does not exist. The OpenAPI document actually lives at docs/api/openapi.yaml. The link 404s for every reader and fails any link-checking job. The fix is a one-token path correction from the stale specs/ location to the real docs/ location.

Root-cause analysis

The README's link target and the file's real location disagree:

Referenced in README Actual file on disk Result
specs/api/openapi.yaml absent broken link
(docs/api/openapi.yaml never referenced) present valid, but undiscoverable

Cause: the spec was moved/created under docs/api/ (the canonical docs tree), but the README reference was never updated — stale-relative-path drift after a doc relocation. The path is repo-root-relative because the README sits at the repo root, so no anchor or symlink is involved; the literal specs/ segment is simply wrong. Impact is documentation-only: nothing imports the path in code, so this is a pure link repair.

Diagnosis

# 1. Show what the README claims
grep -n 'openapi\.yaml' README.md

# 2. Show what actually exists
find . -name 'openapi.yaml' -not -path './.git/*'

# 3. Confirm the referenced path is absent (non-zero exit = broken)
test -e specs/api/openapi.yaml && echo present || echo MISSING

Expected:

3:See the [OpenAPI spec](specs/api/openapi.yaml) for details.
./docs/api/openapi.yaml
MISSING

Exact fix

sed -i 's#specs/api/openapi\.yaml#docs/api/openapi.yaml#g' README.md

-See the [OpenAPI spec](specs/api/openapi.yaml) for details.
+See the [OpenAPI spec](docs/api/openapi.yaml) for details.

Sweep the whole tree in case the stale path appears in more than one doc:

grep -rIl 'specs/api/openapi\.yaml' --exclude-dir=.git . \
  | xargs -r sed -i 's#specs/api/openapi\.yaml#docs/api/openapi.yaml#g'

Note: subdirectory READMEs need a path relative to themselves (e.g. ../docs/api/openapi.yaml).

# 3. Portable link check over every local README link (inline + reference style)
check_links() {
  grep -oE '\]\([^)]+\)|^\[[^]]+\]:[[:space:]]*[^[:space:]]+' "$1" \
  | sed -E 's/^\]\(//; s/\)$//; s/^\[[^]]+\]:[[:space:]]*//' \
  | while read -r link; do
      case "$link" in http://*|https://*|mailto:*|tel:*|"#") continue ;; esac
      target="${link%%#*}"; [ -z "$target" ] && continue
      if [ -e "$target" ]; then echo "OK      $target"; else echo "MISSING $target"; fi
    done
}
check_links README.md
