go-cobra-flag-shorthand-collision

Answer

Root cause. Cobra auto-registers -h, --help on every command via InitDefaultHelpFlag at execute time. Any BoolP/StringP/IntP/etc. that claims the h shorthand on a subcommand collides with it and panics at flag-setup:

panic: unable to redefine 'h' shorthand in "du" flagset: it's already used for "human" flag

(pflag raises this when the second flag — the auto help flag — tries to take a taken shorthand.) The same class covers persistent flags claimed at a parent level: a child redeclaring -o (already persistent on the root) panics identically.

Fix. Two legal patterns, per the task: drop the shorthand (keep long flag) or pick a non-colliding letter. In newDuCmd:

// BEFORE — panics when du executes:
cmd.Flags().BoolP("human", "h", false, "print sizes in human readable format")

// AFTER — pattern 1: long-only flag, 'h' left free for help:
cmd.Flags().Bool("human", false, "print sizes in human readable format")

// AFTER — pattern 2: free shorthand 'd' is safe (check nothing else claims it):
cmd.Flags().IntP("depth", "d", 0, "descend at most N levels of directories")

The parent-level -o/--output claim stays on the root via PersistentFlags() and is inherited — children must not redeclare o.

Catch it in CI. A --help (and -h) smoke test per subcommand, walking the command tree:

func TestHelpSmokePerSubcommand(t *testing.T) {
    root := newRootCmd()
    var walk func(cmd *cobra.Command, path []string)
    walk = func(cmd *cobra.Command, path []string) {
        for _, c := range cmd.Commands() {
            p := append(append([]string{}, path...), c.Name())
            walk(c, p)
            runHelpSmoke(t, c.Name(), p) // executes "<path> --help" and "-h"
        }
    }
    walk(root, nil)
    runHelpSmoke(t, root.Name(), nil)
}

runHelpSmoke executes the args from the root (a subcommand's ExecuteC() delegates to c.Root(), so Find-ing a child and executing it directly is a harness bug) and asserts no error, output contains Usage:, and no panic text. The buggy code fails this instantly with the panic; a companion expected-panic test (TestShorthandCollisionPanicsDocumentsTheHazard) documents that reintroducing h or child-side o still panics, guarding the class.
