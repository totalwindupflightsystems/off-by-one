Title

Verified Fix: DAG-Size-Optimized SMT Bit-Blasting for QF_BV

Root-cause analysis

Naive bit-blasting emits a fresh gate for every operator occurrence with no sharing or rewriting. Tseitin CNF size is linear in live gates, so equivalences like a+b vs b+a, x<<3 vs x*8, and a*(b+c) vs a*b+a*c are encoded as disjoint cones and the SAT solver re-refutes the same facts repeatedly. Additionally, ite identities are not applied and AND/OR-built XORs are never recognized.

Exact fix (implemented, src/)

  • circuit.js — hash-consed Boolean DAG over AND/OR/XOR/ITE; NOT is free via literal polarity. Constant folding, idempotence, complementation, absorption, distributivity/Shannon factoring, XOR factoring, and full ITE rewriting at construction.
  • bitblast.js — QF_BV lowering: ripple add/sub, shift-add mul, unsigned (ult/ule) and signed (slt/sle) compares, constant + variable barrel shifts, concat/extract, ite.
  • resynth.js — cuts-based local resynthesis: k-feasible cuts (k≤4), exact per-cut truth tables, optimal BFS-synthesized per-arity 1/2/3-input libraries over {AND,OR,XOR,NOT}, strictly-cheaper replacement + replay + ITE lowering. Pipeline keeps the smaller of hashed vs. resynthesized.
  • cnf.js / sat.js — Tseitin conversion + in-process CDCL solver (watched literals, 1UIP learning, VSIDS, phase saving).

Verification

  • 14/14 test groups pass, including: CDCL vs. exhaustive brute force (400 random 3-CNFs), pigeonhole UNSAT, every BV operator vs. a BigInt reference, exhaustive evalCone truth-table exactness for every cut, exhaustive resynthesis soundness, and an 80-case naive-vs-optimized differential (circuit eval + SAT result).
  • Benchmark: ~70% fewer live gates/CNF clauses and ~24× geometric-mean SAT speedup. xor-resynth-8 isolates resynthesis: 47 gates → 0 (AND/OR XOR recognized as native XOR, then hash-collapsed).
  • Differential testing caught and fixed two subtle soundness bugs (wrong all-ones truth-table mask; cross-arity library lookup), both now covered by regression tests.
