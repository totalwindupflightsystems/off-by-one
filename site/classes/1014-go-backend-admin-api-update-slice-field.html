U-GAP-032 — Handlers *[]HandlerDef on the update struct

Before: AppConfigUpdate had only Name; the admin PUT could not touch handlers, forcing callers to delete+recreate the whole app config.

After — model.go: every field is a pointer so "absent" (nil) is distinguishable from "explicitly set" (non-nil):

type AppConfigUpdate struct {
    Name     *string       `json:"name,omitempty"`
    Handlers *[]HandlerDef `json:"handlers,omitempty"` // pointer-to-slice: the fix
}

After — service.go: nil-preserving partial update; deep-copy exactly via append([]HandlerDef(nil), ...):

func (s *Service) Update(id string, req AppConfigUpdate) (AppConfig, error) {
    s.mu.Lock()
    defer s.mu.Unlock()
    cfg, ok := s.configs[id]
    if !ok {
        return AppConfig{}, ErrNotFound
    }
    if req.Name != nil {
        cfg.Name = *req.Name
    }
    if req.Handlers != nil { // nil pointer -> preserve; non-nil -> replace (even empty)
        cfg.Handlers = copyHandlers(*req.Handlers) // append([]HandlerDef(nil), hs...) + nested Args copies
    }
    cfg.UpdatedAt = time.Now().UTC()
    s.configs[id] = cfg
    return cloneConfig(cfg), nil // returned value must not alias the store
}

func copyHandlers(hs []HandlerDef) []HandlerDef {
    out := append([]HandlerDef(nil), hs...) // the prescribed pattern
    for i := range out {
        if out[i].Args != nil {
            out[i].Args = append([]string(nil), out[i].Args...)
        }
    }
    return out
}

Contract (verified empirically against encoding/json): JSON null and absent both decode to a nil pointer → preserve; {"handlers":[]} decodes to a non-nil pointer to an empty slice → clear; {"handlers":[...]} → replace. Wire demo:

PUT {"handlers":[{"name":"worker",...}]}   -> replaces web handler in place
PUT {"name":"demo-v2"}                     -> worker preserved, name updated
PUT {"handlers":null}                      -> worker preserved (nil pointer)
PUT {"handlers":[]}                        -> handlers cleared
