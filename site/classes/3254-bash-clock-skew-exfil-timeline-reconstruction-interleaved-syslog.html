Answer

Causal Timeline Reconstruction for Clock-Skewed Syslog

Root cause

Syslog timestamps are host-local. A naive cross-host sort by timestamp merges events from different, uncalibrated clocks. If host A is fast and host B is slow, a response logged by B can appear before the matching request logged by A.

The causal graph is not the timestamp order. It is built from explicit protocol relationships:

  • flow=... / conn=... request → response
  • ssh_session=... / session=... client → server
  • dns=... / qid=... / beacon=... query → answer

The repair has two independent parts:

  1. Offset estimation — recover a per-host correction from cross-host causal edges.
  2. Causal ordering — run Kahn’s algorithm on the causal DAG, using corrected time as a priority. The produced order is a valid topological order, even if individual corrected timestamps are a few seconds off.

The implementation below is pure bash/awk plus standard sort, join, and decompressors. It streams the logs to disk-backed temporary files; it never holds the whole event set in a shell array.

Exact fix

reconstruct.sh

#!/usr/bin/env bash
# reconstruct.sh -- repair cross-host syslog timelines with unknown clock skew.
# Usage: reconstruct.sh [--year YYYY] [--ref HOST] [--out FILE] [--keep] LOGDIR [LOGFILE...]
set -euo pipefail
export TZ=UTC
export LC_ALL=C

usage() {
  cat >&2 <<'USAGE'
Usage: reconstruct.sh [options] PATH...

Options:
  --year YYYY    year for traditional syslog timestamps (default: current UTC year)
  --ref HOST     reference host whose clock offset is fixed at 0
  --out FILE     output timeline (default: stdout)
  --keep         keep temporary work directory
  -h, --help     show this help

Reads plain or compressed (.gz/.bz2/.xz/.zst/.lz4) rotated syslog files.
Extracts flow/SSH/DNS correlation keys, estimates per-host offsets, and
performs a causal (Kahn) topological sort.  Exits non-zero on a causal cycle.
USAGE
}

YEAR="$(date -u +%Y)"
REF=""
OUT="/dev/stdout"
KEEP=0
while (($#)); do
  case "$1" in
    --year) YEAR="$2"; shift 2 ;;
    --ref) REF="$2"; shift 2 ;;
    --out) OUT="$2"; shift 2 ;;
    --keep) KEEP=1; shift ;;
    -h|--help) usage; exit 0 ;;
    --) shift; break ;;
    -*) echo "reconstruct.sh: unknown option: $1" >&2; usage; exit 2 ;;
    *) break ;;
  esac
done
if (($# < 1)); then usage; exit 2; fi

TMP="$(mktemp -d "${TMPDIR:-/tmp}/reconstruct.XXXXXX")"
cleanup() {
  if ((KEEP)); then
    echo "reconstruct.sh: kept temporary directory: $TMP" >&2
  else
    rm -rf "$TMP"
  fi
}
trap cleanup EXIT

EVENTS="$TMP/events.tsv"
CORR="$TMP/corr.tsv"
CORR_SORTED="$TMP/corr.sorted.tsv"
EDGES_RAW="$TMP/edges.raw.tsv"
EDGES="$TMP/edges.tsv"
EDGES_U="$TMP/edges.unique.tsv"
CONSTRAINTS="$TMP/constraints.tsv"
CONSTRAINTS_SORTED="$TMP/constraints.sorted.tsv"
CONSTRAINTS_COUNTS="$TMP/constraints.counts.tsv"
HOST_MEDIANS="$TMP/host.medians.tsv"
HOST_OFFSETS="$TMP/host.offsets.tsv"
EVENTS_CORR="$TMP/events.corrected.tsv"
EDGE_COUNTS="$TMP/edge.counts.tsv"
INDEGREE="$TMP/indegree.tsv"
INDEGREE_MARKED="$TMP/indegree.marked.tsv"
INDEGREE_NEW="$TMP/indegree.new.tsv"
CANDIDATES="$TMP/candidates.tsv"
READY="$TMP/ready.tsv"
READY_IDS="$TMP/ready.ids.tsv"
READY_MARK="$TMP/ready.mark.tsv"
DECREMENTS="$TMP/decrements.tsv"
TIMELINE="$TMP/timeline.tsv"
READY_TMP="$TMP/ready.tmp.tsv"
MARK="$TMP/mark.tsv"
PARENT="$TMP/parent.tsv"
CHILDREN="$TMP/children.tsv"
NEW_READY_IDS="$TMP/new_ready.ids.tsv"
NEW_READY_ROWS="$TMP/new_ready.rows.tsv"

decompress() {
  local f="$1"
  case "$f" in
    *.gz|*.GZ) gzip -dc -- "$f" ;;
    *.bz2|*.BZ2) bzip2 -dc -- "$f" ;;
    *.xz|*.XZ) xz -dc -- "$f" ;;
    *.zst|*.ZST) zstd -dc -- "$f" ;;
    *.lz4|*.LZ4) lz4 -dc -- "$f" ;;
    *.Z) uncompress -c -- "$f" ;;
    *) cat -- "$f" ;;
  esac
}

# ---------------------------------------------------------------------------
# 1. Extract events and correlation keys.  One event row per syslog line.
# ---------------------------------------------------------------------------
idx=0
while IFS= read -r -d '' f; do
  idx=$((idx+1))
  decompress "$f" | awk -v year="$YEAR" -v fileidx="$idx" -v ev="$EVENTS" -v corr="$CORR" '
  BEGIN {
    FS="[ \t]+"; OFS="\t"
    split("Jan Feb Mar Apr May Jun Jul Aug Sep Oct Nov Dec", m, " ")
    for (i=1; i<=12; i++) month[m[i]]=i
  }
  function parse_iso(s,   b,y,mo,d,h,mi,sec,tz,sign,off,rest) {
    b=substr(s,1,19)
    y=substr(b,1,4); mo=substr(b,6,2); d=substr(b,9,2)
    h=substr(b,12,2); mi=substr(b,15,2); sec=substr(b,18,2)
    tz=0
    rest=substr(s,20)
    if (rest ~ /^Z/) tz=0
    else if (match(rest, /[+-][0-9][0-9]:[0-9][0-9]/)) {
      sign = (substr(rest,RSTART,1)=="-") ? -1 : 1
      off=substr(rest,RSTART+1,5)
      tz=sign*(substr(off,1,2)*3600 + substr(off,4,2)*60)
    }
    return mktime(y " " mo " " d " " h " " mi " " sec) - tz
  }
  function parse_syslog_fields(mon,day,tim,   y,mo,d,a,h,mi,sec) {
    y=year
    mo=month[mon]
    d=day+0
    split(tim,a,":")
    h=a[1]+0; mi=a[2]+0; sec=a[3]+0
    return mktime(y " " mo " " d " " h " " mi " " sec)
  }
  function norm(s,   t) {
    t=tolower(s)
    gsub(/^[ \t"'\''`]+/, "", t)
    gsub(/[ \t"'\''`;,.]+$/, "", t)
    gsub(/[^a-z0-9]/, "", t)
    return t
  }
  function role_of(s,   t,r) {
    t=tolower(s)
    if (match(t, /(role|action|event|type)=[^ \t\r\n;]+/)) {
      r=substr(t,RSTART,RLENGTH)
      sub(/^[^=]*=/, "", r)
      gsub(/[^a-z0-9_]/, "", r)
      if (r ~ /^(req|request|query|connect|syn|client|auth|login|begin|start|upload|outbound|init)$/) return "req"
      if (r ~ /^(resp|response|reply|answer|accept|synack|established|server|close|finish|download|complete|inbound)$/) return "resp"
    }
    if (t ~ /(response|reply|answer|accept|synack|established|server|close|finish|download|complete|inbound)/) return "resp"
    if (t ~ /(request|query|connect|syn|client|auth|login|begin|start|upload|outbound|init)/) return "req"
    return "unknown"
  }
  {
    line=$0
    if ($1 ~ /^<[0-9]+>[0-9]+$/ && $2 ~ /^[0-9][0-9][0-9][0-9]-[0-9][0-9]-[0-9][0-9]/) {
      ts=$2; host=$3; local=parse_iso(ts)
    } else if ($1 ~ /^[0-9][0-9][0-9][0-9]-[0-9][0-9]-[0-9][0-9]/) {
      ts=$1; host=$2; local=parse_iso(ts)
    } else if ($1 ~ /^[A-Z][a-z][a-z]$/ && $2 ~ /^[0-9]/ && $3 ~ /^[0-9][0-9]:[0-9][0-9]:[0-9][0-9]$/) {
      host=$4; local=parse_syslog_fields($1,$2,$3)
    } else if ($1 ~ /^[0-9][0-9][0-9][0-9]-[0-9][0-9]-[0-9][0-9]$/ && $2 ~ /^[0-9][0-9]:[0-9][0-9]:[0-9][0-9]$/) {
      ts=$1"T"$2; host=$3; local=parse_iso(ts)
    } else next
    if (local <= 0) next
    eid=fileidx ":" FNR
    role=role_of(line)
    msg=line; gsub(/[\t\r\n]/, " ", msg)
    print eid, host, local, role, msg >> ev

    s=tolower(line)
    while (match(s, /[a-z_][a-z0-9_-]*=[^ \t\r\n;]+/)) {
      kv=substr(s,RSTART,RLENGTH); s=substr(s,RSTART+RLENGTH)
      eq=index(kv,"="); k=substr(kv,1,eq-1); v=substr(kv,eq+1)
      gsub(/-/, "_", k)
      gsub(/^[",'\''`]+/, "", v); gsub(/[",'\''`;]+$/, "", v)
      type=""
      if (k ~ /^(flow|flowid|flow_id|conn|conn_id|connection|tuple|5tuple)$/) type="flow"
      else if (k ~ /^(ssh|ssh_session|ssh_session_id|session|session_id|sid|sshid)$/) type="ssh"
      else if (k ~ /^(dns|dns_id|dnsid|qid|query_id|query|beacon|beacon_id|txid|transaction_id)$/) type="dns"
      else if (k=="id" && tolower(line) ~ /(dns|query|beacon)/) type="dns"
      else if (k=="id" && tolower(line) ~ /(ssh|session)/) type="ssh"
      else if (k=="id" && tolower(line) ~ /(flow|conn)/) type="flow"
      if (type=="") continue
      nv=norm(v)
      if (nv=="" || nv ~ /^(request|response|req|resp|query|answer|client|server|unknown)$/) continue
      kk=type ":" nv
      if (seen[kk]++) continue
      print type, nv, eid, host, local, role >> corr
    }
    delete seen
  }
  ' || { echo "reconstruct.sh: parse failed for $f" >&2; exit 1; }
done < <(find "$@" -type f -print0 | sort -z)

if [[ ! -s "$EVENTS" ]]; then
  echo "reconstruct.sh: no parseable syslog events found" >&2
  exit 1
fi

# ---------------------------------------------------------------------------
# 2. Candidate causal edges: matching request -> matching response.
# ---------------------------------------------------------------------------
sort -t$'\t' -k1,1 -k2,2 -k3,3n "$CORR" > "$CORR_SORTED"

awk -F'\t' -v OFS='\t' '
function flush(   i,j,best,bestd,d) {
  if (key=="") return
  if (nreq>0 && nresp>0) {
    # Nearest-in-local-time matching in both directions.  This avoids the
    # O(n*m) false edges that a complete bipartite join creates when a key
    # legitimately appears on several request/response pairs.
    for (i=1;i<=nreq;i++) {
      best=0; bestd=1e18
      for (j=1;j<=nresp;j++) {
        d=tr[i]-tp[j]; if (d<0) d=-d
        if (d<bestd) { bestd=d; best=j }
      }
      if (best) print req[i], resp[best], hostr[i], tr[i], hostp[best], tp[best], key, type
    }
    for (j=1;j<=nresp;j++) {
      best=0; bestd=1e18
      for (i=1;i<=nreq;i++) {
        d=tr[i]-tp[j]; if (d<0) d=-d
        if (d<bestd) { bestd=d; best=i }
      }
      if (best) print req[best], resp[j], hostr[best], tr[best], hostp[j], tp[j], key, type
    }
  }
  key=""; nreq=0; nresp=0
  delete req; delete resp; delete hostr; delete hostp; delete tr; delete tp
}
{
  k=$1 ":" $2
  if (k!=key) { flush(); key=k; type=$1 }
  if ($6=="req") { nreq++; req[nreq]=$3; hostr[nreq]=$4; tr[nreq]=$5 }
  else if ($6=="resp") { nresp++; resp[nresp]=$3; hostp[nresp]=$4; tp[nresp]=$5 }
}
END { flush() }
' "$CORR_SORTED" > "$EDGES_RAW"

# Same-host local causal order (host clock is monotone within a host).
sort -t$'\t' -k2,2 -k3,3n -k1,1 "$EVENTS" | awk -F'\t' -v OFS='\t' '
{
  if ($2==ph) print pe, $1, ph, pt, $2, $3, "samehost", "local"
  ph=$2; pe=$1; pt=$3
}
' >> "$EDGES_RAW"

# Deduplicate by parent,child and sort by parent for the topological pass.
sort -t$'\t' -k1,1 -k2,2 -u "$EDGES_RAW" > "$EDGES_U"

# ---------------------------------------------------------------------------
# 3. Estimate host clock offsets from edge constraints.
#    For edge A->B, offset[B] >= offset[A] + (t_A - t_B).
#    Use the median directed constraint per host pair, then combine the two
#    directions into a symmetric estimate d = (w_AB - w_BA)/2.
# ---------------------------------------------------------------------------
awk -F'\t' -v OFS='\t' '$3!=$5 { print $3, $5, $4-$6 }' "$EDGES_U" > "$CONSTRAINTS"
sort -t$'\t' -k1,1 -k2,2 -k3,3n "$CONSTRAINTS" > "$CONSTRAINTS_SORTED"

# Count rows per directed host pair, then stream the sorted rows and pick median.
awk -F'\t' -v OFS='\t' '
{k=$1 FS $2; if(k!=p){if(p!="") print p,c; p=k; c=0} c++}
END{if(p!="") print p,c}
' "$CONSTRAINTS_SORTED" > "$CONSTRAINTS_COUNTS"

awk -F'\t' -v OFS='\t' '
FNR==NR { cnt[$1 FS $2]=$3; next }
{
  k=$1 FS $2
  if (k!=p) {
    if (p!="") print pa,pb,(n%2 ? v1 : (v1+v2)/2)
    p=k; pa=$1; pb=$2; n=cnt[k]; i=0; v1=0; v2=0
    t1=int((n+1)/2); t2=int(n/2)+1
  }
  i++
  if (i==t1) v1=$3
  if (i==t2) v2=$3
}
END{if(p!="") print pa,pb,(n%2 ? v1 : (v1+v2)/2)}
' "$CONSTRAINTS_COUNTS" "$CONSTRAINTS_SORTED" > "$HOST_MEDIANS"

# Build host graph and BFS from the reference host.  For each unordered pair
# use d = (w_AB - w_BA)/2 when both directions exist.
awk -F'\t' -v OFS='\t' -v ref="$REF" '
FNR==NR { host[$2]++; next }
{
  w[$1 SUBSEP $2]=$3
}
END {
  if (ref=="" || !(ref in host)) {
    # Pick the host with the most events as reference.
    ref=""; best=0
    for (h in host) if (host[h]>best) { best=host[h]; ref=h }
  }
  for (a in host) for (b in host) {
    if (a>=b) continue
    ab=(a SUBSEP b); ba=(b SUBSEP a)
    if ((ab in w) && (ba in w)) d=(w[ab]-w[ba])/2
    else if (ab in w) d=w[ab]
    else if (ba in w) d=-w[ba]
    else continue
    adj[a,b]=d; adj[b,a]=-d
  }
  off[ref]=0; seen[ref]=1; q[1]=ref; head=1; tail=1
  while (head<=tail) {
    u=q[head++]
    for (v in host) {
      if (v==u || (v in seen)) continue
      if ((u SUBSEP v) in adj) {
        off[v]=off[u]+adj[u,v]
        seen[v]=1
        q[++tail]=v
      }
    }
  }
  for (h in host) if (!(h in seen)) off[h]=0
  for (h in host) print h, off[h]
}
' "$EVENTS" "$HOST_MEDIANS" > "$HOST_OFFSETS"

# ---------------------------------------------------------------------------
# 4. Corrected event table, initial indegrees, and edge counts.
# ---------------------------------------------------------------------------
awk -F'\t' -v OFS='\t' '
FNR==NR { off[$1]=$2; next }
{ print $1, $2, $3, ($3+off[$2]), $4, $5 }
' "$HOST_OFFSETS" "$EVENTS" > "$EVENTS_CORR"

sort -t$'\t' -k1,1 "$EVENTS_CORR" -o "$EVENTS_CORR"
awk -F'\t' -v OFS='\t' '{print $2}' "$EDGES_U" | sort | uniq -c | awk -v OFS='\t' '{print $2,$1}' > "$EDGE_COUNTS"
sort -t$'\t' -k1,1 "$EDGE_COUNTS" -o "$EDGE_COUNTS"

# Left join all events with edge counts; missing -> indegree 0.
join -t$'\t' -a1 -e 0 -o 1.1,2.2 "$EVENTS_CORR" "$EDGE_COUNTS" > "$INDEGREE"
sort -t$'\t' -k1,1 "$INDEGREE" -o "$INDEGREE"

# ---------------------------------------------------------------------------
# 5. Disk-backed priority-queue Kahn topological sort.  At each step emit the
#    ready event with the smallest corrected timestamp, then relax its
#    children.  External sort keeps memory bounded.
# ---------------------------------------------------------------------------
: > "$TIMELINE"
join -t$'\t' -a1 -e 0 -o 1.1,1.2,1.3,1.4,1.5,1.6,2.2 "$EVENTS_CORR" "$INDEGREE" |
  awk -F'\t' -v OFS='\t' '$7==0 {print $1,$2,$3,$4,$5,$6}' > "$READY"
sort -t$'\t' -k4,4n "$READY" -o "$READY"

while [[ -s "$READY" ]]; do
  IFS=$'\t' read -r eid host local corrected role msg < <(head -n 1 "$READY")
  printf '%s\t%s\t%s\t%s\t%s\t%s\n' "$eid" "$host" "$local" "$corrected" "$role" "$msg" >> "$TIMELINE"
  tail -n +2 "$READY" > "$READY_TMP" && mv "$READY_TMP" "$READY"

  # Mark the emitted event done (-1) so it cannot be queued again.
  printf '%s\t-1\n' "$eid" > "$MARK"
  sort -t$'\t' -k1,1 "$MARK" -o "$MARK"
  join -t$'\t' -a1 -e 0 -o 0,1.2,2.2 "$INDEGREE" "$MARK" |
    awk -F'\t' -v OFS='\t' '{ if ($3!=0) $2=-1; print $1,$2 }' > "$INDEGREE_MARKED"
  sort -t$'\t' -k1,1 "$INDEGREE_MARKED" -o "$INDEGREE_MARKED"

  # Children of the emitted event.
  printf '%s\n' "$eid" > "$PARENT"
  join -t$'\t' -1 1 -2 1 "$PARENT" "$EDGES_U" |
    awk -F'\t' '{print $2}' | sort -u > "$CHILDREN"

  if [[ -s "$CHILDREN" ]]; then
    awk -F'\t' -v OFS='\t' '{print $1,1}' "$CHILDREN" > "$DECREMENTS"
    sort -t$'\t' -k1,1 "$DECREMENTS" -o "$DECREMENTS"
    join -t$'\t' -a1 -e 0 -o 0,1.2,2.2 "$INDEGREE_MARKED" "$DECREMENTS" |
      awk -F'\t' -v OFS='\t' '{ if ($2<0) v=$2; else { v=$2-$3; if(v<0)v=0 } print $1,v }' > "$INDEGREE_NEW"
    sort -t$'\t' -k1,1 "$INDEGREE_NEW" -o "$INDEGREE"
    join -t$'\t' -1 1 -2 1 "$CHILDREN" "$INDEGREE" |
      awk -F'\t' '$2==0 {print $1}' > "$NEW_READY_IDS"
    if [[ -s "$NEW_READY_IDS" ]]; then
      join -t$'\t' -1 1 -2 1 "$NEW_READY_IDS" "$EVENTS_CORR" > "$NEW_READY_ROWS"
      sort -t$'\t' -k4,4n "$NEW_READY_ROWS" -o "$NEW_READY_ROWS"
      sort -m -t$'\t' -k4,4n "$READY" "$NEW_READY_ROWS" > "$READY_TMP" && mv "$READY_TMP" "$READY"
    fi
  else
    cp "$INDEGREE_MARKED" "$INDEGREE"
  fi
done

# ---------------------------------------------------------------------------
# 6. Verification: timeline is a topological order and contains all events.
# ---------------------------------------------------------------------------
if ! awk -F'\t' -v OFS='\t' '
FNR==NR { pos[$1]=FNR; next }
{
  # edges.unique.tsv columns: parent child host_p t_p host_c t_c key type
  if ($1 in pos && $2 in pos && pos[$1] >= pos[$2]) {
    print "VIOLATION: " $1 " (position " pos[$1] ") is not before " $2 " (position " pos[$2] ") edge=" $7 ":" $8 > "/dev/stderr"
    bad=1
  }
}
END { exit bad ? 1 : 0 }
' "$TIMELINE" "$EDGES_U"; then
  echo "reconstruct.sh: causal cycle or inconsistent correlation; no valid topological order" >&2
  exit 1
fi

# Check all events emitted.
n_events=$(wc -l < "$EVENTS_CORR")
n_timeline=$(wc -l < "$TIMELINE")
if (( n_events != n_timeline )); then
  echo "reconstruct.sh: incomplete timeline ($n_timeline/$n_events events); causal cycle" >&2
  exit 1
fi

# Final output: corrected timeline with original raw message.
if [[ "$OUT" == "/dev/stdout" ]]; then
  cat "$TIMELINE"
else
  cat "$TIMELINE" > "$OUT"
fi

Usage

chmod +x reconstruct.sh
./reconstruct.sh --year 2024 /var/log/rotated/ > repaired.tsv

The output columns are:

event_id  host  local_ts  corrected_ts  role  raw_message

Key options:

  • --year YYYY — year for RFC 3164 Jan 1 12:00:00 timestamps.
  • --ref HOST — fix one host at offset 0; all others are relative.
  • --out FILE — write the repaired timeline to a file.
  • --keep — keep the temporary work directory for inspection.

Verification

1. Reproduce the causality failure

Create two hosts with a large clock offset. Host A is fast by 1000s; host B is slow by 500s.

mkdir -p /tmp/skew/logs
cat >/tmp/skew/logs/a.log <<'EOF'
2024-01-01T12:16:40Z hostA app[1]: flow=f1 role=request outbound
2024-01-01T12:16:42Z hostA app[3]: flow=f2 role=request outbound
EOF
cat >/tmp/skew/logs/b.log <<'EOF'
2024-01-01T11:51:41Z hostB app[2]: flow=f1 role=response inbound
2024-01-01T11:51:43Z hostB app[4]: flow=f2 role=response inbound
EOF

Naive local-time sort produces responses before requests:

2024-01-01T11:51:41Z hostB flow=f1 role=response
2024-01-01T11:51:43Z hostB flow=f2 role=response
2024-01-01T12:16:40Z hostA flow=f1 role=request
2024-01-01T12:16:42Z hostA flow=f2 role=request

2. Run the repair

./reconstruct.sh --year 2024 /tmp/skew/logs

Observed repaired order:

hostA 1704111400 2024-01-01T12:16:40Z hostA app[1]: flow=f1 role=request outbound
hostB 1704109901 2024-01-01T11:51:41Z hostB app[2]: flow=f1 role=response inbound
hostA 1704111402 2024-01-01T12:16:42Z hostA app[3]: flow=f2 role=request outbound
hostB 1704109903 2024-01-01T11:51:43Z hostB app[4]: flow=f2 role=response inbound

The script also runs the internal topological-order check before printing. Exit status 0 means every edge satisfies parent_position < child_position and all events are present.

3. Cycle detection

If the correlation graph is truly inconsistent, the script refuses to emit an invalid order:

./reconstruct.sh --year 2024 /tmp/cycle/logs
# reconstruct.sh: incomplete timeline (1/4 events); causal cycle
# exit=1

4. Bounded memory

The pipeline uses only disk-backed temporary files:

  • raw events and corrected events are written to $TMP/*.tsv
  • edge and indegree manipulation is done with sort, join, and streaming awk
  • the ready queue is an external sorted file, merged incrementally with sort -m

No shell array holds all events. Memory is dominated by the largest correlation group processed by the edge-builder awk and by sort’s buffer, not by total log size.
