Answer

The Mythos CLI had three related defects in the batch path, all reproduced and fixed in /home/kara/mythos-cli (commits abb91ab → 9f667cb):

Before — mythos batch outside a project:

[provider:fs] version=1.0.0 module=/tmp/mythos-repro/outside-project/providers/fs.js   ← absolute path leak
Fatal error: No project loaded: cannot find mythos.json in /tmp/... or any parent.      ← bare, no guidance
EXIT=2                                                                                   ← wrong exit code

1. Gate ProviderRegistry diagnostics behind verbosity — the registry's diagnostics include absolute on-disk module paths, so they're only emitted when the user opted in (--verbose or MYTHOS_VERBOSE=1):

// src/provider.ts
private logDiagnostics(verbose: boolean): void {
  if (!verbose) return;                    // gate: default runs never leak paths
  for (const p of this.providers.values()) {
    console.error(`[provider:${p.name}] version=${p.version} module=${p.modulePath}`);
  }
}
initialize(verbose: boolean): void { this.logDiagnostics(verbose); }

2. Propagate MYTHOS_VERBOSE to backend services — spawned children get an explicit normalized env var (never stale/missing), from the CLI's resolved verbosity (--verbose wins over env fallback via src/config.ts):

// src/backend.ts
export function spawnBackend(command: string, args: string[], opts: BackendOptions): Promise<number> {
  const env: NodeJS.ProcessEnv = { ...process.env, MYTHOS_VERBOSE: opts.verbose ? '1' : '0' };
  return new Promise((resolve, reject) => {
    const child = spawn(command, args, { env, stdio: 'inherit' });
    child.on('error', reject);
    child.on('exit', (code) => resolve(code ?? 1));
  });
}

3. Remap StorageError in the CLI catch-all + exit 1 — instead of a bare Fatal error: line, the catch-all detects the storage failure and gives actionable guidance, always exiting 1:

// src/cli.ts — main().catch(...)
if (e instanceof StorageError || e.name === 'StorageError') {
  console.error(
    `mythos: ${e.message}\n` +
    'No project is loaded in this directory.\n' +
    'Run `mythos init` to create a project here, then try again.',
  );
} else {
  console.error(`Fatal error: ${e.message}`);   // unrelated errors keep the prefix
}
process.exitCode = 1;

After — mythos batch outside a project:

mythos: No project loaded: cannot find mythos.json in /tmp/... or any parent directory.
No project is loaded in this directory.
Run `mythos init` to create a project here, then try again.
EXIT=1
