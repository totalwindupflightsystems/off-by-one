Root cause

boardctl (TR-251) requires --status complete to carry an --evidence-run-id whose run resolves under .gitreins/history/, and a verdict is bound to both a task_id and a commit. The evidence-tracking row has neither its own product commit nor a verdict bound to its id, so reusing one of the four named rows' run ids would record a foreign verdict — fabrication. The honest closure is a new aggregate evidence run whose recorded criterion re-runs the four bindings.

Two mechanics that cost time, now pinned in the doc: 1. The verdict artifact directory is not the CLI's printed Verdict saved <hex>; resolve by task_id AND commit. Also, boardctl stores the passed --evidence-fingerprint as evidence[].tree_fp (64-hex GitReins tree digest) — that is the binding to re-derive. 2. DuckBrain DELETE /api/namespaces/<ns> ignores ?confirm=true (400 VALIDATION_ERROR, namespace leaks); it needs the JSON body {"confirm":true}.

Fix shape

  1. Judge locates verdicts by task_id+commit, recomputes the tree digest from git rev-parse <commit>^{tree}, recomputes verdict_hash, and (with --rerun) re-executes recorded checks.
  2. Mint an aggregate run for the tracking row: binds[] = the four rows, tree = sha256(canonical_json(sorted(child tree_fp))), checks[] = the judge itself.
  3. boardctl update <META> --status complete --evidence-run-id <agg-run> --evidence-fingerprint <agg>.

Verification (all reproduced against a real boardctl v0.4.0 board + git repo)

  • python3 -m unittest scripts/test_audit_board_evidence.py → Ran 17 tests ... OK
  • pre-closure grep -cE '^BOUND .*\(pass\)' → 4
  • post-closure --json → bound=5, missing=0, unresolvable=0, rc=0
  • jq id/status/run_id selection over .coding-hermes/board/tasks.jsonl
  • three refusal classes fire: dangling-run-id, foreign-verdict, fabricated-label (whole-board rc=1)
  • DuckBrain mock: query-confirm → 400 + leaked; body-confirm → 200 + 404 on re-GET

I also executed the document's exact §3.2/§3.3 shell blocks end-to-end on a fresh pre-closure copy, which closed the row and produced the clean audit.
