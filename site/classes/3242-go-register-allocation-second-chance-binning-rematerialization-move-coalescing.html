Fixing the Second-Chance Binning Spill / Rematerialization / Coalescing Cost Model

Root-Cause Analysis

The naive local cost model is:

remat_cost(r) = RematCost[r]

This is wrong for three reasons.

  1. It ignores live-range extension of inputs. Rematerializing r at each use forces r's inputs to stay available at every use site. Their live ranges grow. If an input itself is rematerializable, its inputs also grow, and so on. The cost of r must therefore include the effective cost of every input:

effective(r) = min(SpillCost[r], RematCost[r] + Σ effective(input))

Without this, a cheap constant remat looks free while it silently creates new spills elsewhere.

  1. A greedy decision loop oscillates. If you update costs while making decisions, you can get:

remat r -> input becomes expensive spill r -> input becomes cheap remat r -> ...

The system never settles because decisions and costs are recomputed from each other. The fix is to compute the least fixed point of a monotone cost system before making any decision. The recurrence above is monotone: each effective(r) is nondecreasing in every effective(input). With finite spill costs a unique least fixed point exists.

  1. Different-width copies cannot be coalesced. If src.Width != dst.Width, the two operands cannot legally share one register class. The copy must remain explicit and must carry a width-mismatch/conversion cost. Treating the move as coalescible produces illegal register assignments.

Exact Fix

The cost equation

For each live range r:

effective(r) =
    SpillCost[r]                                      if !Rematerializable
    min(SpillCost[r],
        RematCost[r] + Σ effective(i) for i in Inputs[r])   otherwise

The solver computes this equation to a fixed point using a shortest-hyperpath walk:

  • Spill is a base rule with cost SpillCost[r].
  • Rematerialization is a hyperedge with cost RematCost[r] + Σ cost(inputs), and it is only eligible once all inputs are finalized.
  • Nodes are finalized in increasing cost, so a later candidate can never lower an already-finalized node. This is the Dijkstra-style argument, and it is why the result cannot oscillate.

After costs are final, decisions are pure functions of those costs:

if cost[r] < SpillCost[r] - ε:
    Action[r] = Rematerialize
else:
    Action[r] = Spill          // deterministic tie-break

Copy decision:

if src.Width != dst.Width:
    CopyAction = KeepCopy
    CopyCost   = CopyCost + WidthMismatchCost
else if CoalescePenalty < CopyCost:
    CopyAction = Coalesce
    CopyCost   = CoalescePenalty
else:
    CopyAction = KeepCopy
    CopyCost   = CopyCost

// Solve computes a stable cost for every live range and then makes the
// spill/rematerialization and copy-coalescing decisions.
func (m *Model) Solve() (Plan, error) {
    // ... validation and dependency construction ...

    // Base derivations: a spill, or a rematerialization with no inputs.
    for i := range m.Ranges {
        r := &m.Ranges[i]
        if r.Rematerializable && len(deps[i]) == 0 {
            push(i, r.RematCost)
        }
        if !math.IsInf(r.SpillCost, 1) {
            push(i, r.SpillCost)
        }
    }

    finalized := 0
    for h.Len() > 0 {
        it := heap.Pop(h).(heapItem)
        i := it.id
        if done[i] || it.cost != best[i] {
            continue
        }

        cost[i] = it.cost
        done[i] = true
        finalized++

        for _, j := range dependents[i] {
            if done[j] {
                continue
            }
            pending[j]--
            sum[j] += cost[i]
            if pending[j] == 0 && m.Ranges[j].Rematerializable {
                candidate := m.Ranges[j].RematCost + sum[j]
                if candidate < best[j]-epsilon {
                    push(j, candidate)
                }
            }
        }
    }

    // ... finalize actions ...

    for ci := range m.Copies {
        c := &m.Copies[ci]
        src, dst := idx[c.Src], idx[c.Dst]

        // Width mismatch: cannot coalesce.
        if m.Ranges[src].Width != m.Ranges[dst].Width {
            p.CopyAction[ci] = KeepCopy
            p.CopyCost[ci] = c.CopyCost + c.WidthMismatchCost
            continue
        }

        // Same width: coalesce only if the risk is cheaper than the copy.
        if c.CoalescePenalty < c.CopyCost {
            p.CopyAction[ci] = Coalesce
            p.CopyCost[ci] = c.CoalescePenalty
        } else {
            p.CopyAction[ci] = KeepCopy
            p.CopyCost[ci] = c.CopyCost
        }
    }

    return p, nil
}
