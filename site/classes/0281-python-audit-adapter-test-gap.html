Answer

The audit gap: native.py defines NativeH3Harness, a documented adapter with a locked contract (endpoint=None, async run() raising NotImplementedError with a Hermes Core handoff message), but had zero direct tests. The fix is mechanical contract-lock scaffolding — assert the documented surface, never spawn workers for an adapter that is documented not to spawn them.

The adapter contract (native.py):

class NativeH3Harness:
    """Contract: endpoint=None; async run() raises NotImplementedError
    mentioning 'Hermes Core' (runtime handoff not yet wired)."""
    endpoint = None

    async def run(self, *args, **kwargs):
        raise NotImplementedError(
            "Hermes Core: native execution requires the Hermes Core runtime; "
            "no worker is spawned from the native harness."
        )

The 3-test lock (test_native.py) — run() is async, so it is driven with asyncio.run():

import asyncio
import pytest
from native import NativeH3Harness

def test_endpoint_contract_is_locked_to_none():
    assert NativeH3Harness.endpoint is None

def test_run_is_async_and_raises_not_implemented():
    with pytest.raises(NotImplementedError):
        asyncio.run(NativeH3Harness().run())

def test_run_error_mentions_hermes_core_handoff():
    try:
        asyncio.run(NativeH3Harness().run())
    except NotImplementedError as exc:
        assert "Hermes Core" in str(exc)
    else:
        pytest.fail("NativeH3Harness.run() must raise NotImplementedError")

Tests are contract-lock (one per documented surface item: endpoint, async+exception, message), not worker spawns — matching the audit's own pattern.
