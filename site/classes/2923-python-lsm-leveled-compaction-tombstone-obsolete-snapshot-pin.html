Fixing snapshot-pinned tombstone GC in a leveled LSM compaction planner

TL;DR

The planner must treat tombstone removal as a read-visibility question, not a level question. This solution:

  1. expands every table's key bounds with its range-tombstone boundaries before overlap tests,
  2. closes the input file set under overlap in both directions,
  3. retains, for every read point (+inf current read and each live snapshot), the exact version that read point can see, and only removes a tombstone when no surviving version — in any level outside the compaction, not just lower levels — is shadowed by it,
  4. accounts bytes_read / bytes_written per compaction, and
  5. commits the whole result as one atomic Edit with a strictly monotonic edit_number.

Two subtle bugs surfaced while building this and are covered by regression tests:

  • Higher-level older versions. With out-of-order sequence numbers a higher level (e.g. L0) can hold an older version of a key than a lower level. Dropping a lower-level tombstone then resurrects the L0 value. The fix is to consider all non-input files, not only lower levels.
  • A vanished key is a legitimate read result. When a key is fully GC'd it disappears from the map; the verifier must compare over the union of the keyspaces before and after, otherwise not_found looks like a mismatch.

Root-cause analysis

1. Overlap must use exact, range-expanded boundaries

A table storing keys {10, 11} with range tombstone [5, 8] owns [5, 11]. Physical-bounds overlap would never pull a table holding key 7 into the same compaction, losing the range delete. SSTable.expanded_bounds() adds every RangeTombstone.start/.end to the physical min/max; overlaps() uses those intervals.

2. File selection must be closed under overlap

Starting from one file in level L, pulling overlapping L+1 files can reveal further overlapping L files, which reveal further L+1 files. The planner iterates to a fixpoint (_select_input_files), otherwise two files sharing a key survive in the same level.

3. Tombstones may only go when invisible to every read point

A tombstone at sequence t is needed if it is the visible version at some read point, or if it shadows an older version surviving outside the compaction. Naive "bottom-most level" is wrong under snapshots and out-of-order seqs. Real counterexample found by randomized testing:

L0 f2 : key 5 -> 64:DELETE, 40:PUT, 9:PUT      (not part of L1->L2)
L2 f5 : key 5 -> 49:DELETE, 29:DELETE, 18:DELETE
snapshots = [3, 19, 51]

Dropping 18:DELETE makes snapshot 19 read L0's v5@9 — an observable resurrection.

_resolve_key: 1. build the global version list = input entries + all outside entries; 2. mark the visible entry at each read point that comes from the input (+inf plus every snapshot); 3. retain the marked entries; 4. repeatedly drop a retained tombstone only when neither a retained entry nor any outside entry would be exposed by its removal (with a defensive equal-seq PUT/DELETE tie check).

Range tombstones are carried through conservatively and never dropped here.

4. Manifest edits must be atomic and monotonic

Manifest.apply() builds the complete new level map off to the side and swaps it in with a single assignment. A crash before the swap leaves the manifest unchanged; after, the edit is fully applied. edit_number must be exactly current + 1, so replayed/stale/reordered edits raise instead of corrupting.

The exact fix

"""
Leveled LSM compaction planner with snapshot-pinned tombstone GC.

This module implements:

  * SSTables with point entries and (possibly partially overlapping) range
    tombstones.  ``SSTable.expanded_bounds`` extends the physical key bounds
    with every range-tombstone boundary so overlap tests see the exact
    deleted key range rather than only the keys that happen to be stored.
  * Leveled file-set selection: pick a file in level L, pull in every
    overlapping file in L+1, then keep expanding the input set until it is
    closed under overlap in both directions.
  * Snapshot-aware tombstone GC.  A tombstone is only removed when it no
    longer affects the value observed by *any* live snapshot (or by the
    current read) and, for bottommost removal, when no older version of the
    key survives in a lower level.
  * Per-compaction bytes_read / bytes_written accounting.
  * Atomic manifest edits with a strictly monotonic edit number.
"""

from __future__ import annotations

from collections import defaultdict
from dataclasses import dataclass, field
from typing import Iterable, Optional

PUT = "PUT"
DELETE = "DELETE"

# ---------------------------------------------------------------------------
# Keyspace primitives
# ---------------------------------------------------------------------------


@dataclass(frozen=True)
class Entry:
    """A versioned point entry.  ``seq`` may be out of order w.r.t. file order."""

    key: int
    seq: int
    kind: str
    value: Optional[str] = None

    @property
    def size(self) -> int:
        # Toy serialization size: 8 byte seq + 1 byte kind + payload.
        payload = len(self.value.encode()) if self.value is not None else 0
        return 9 + payload


@dataclass(frozen=True)
class RangeTombstone:
    """Deletes every key in the inclusive interval [start, end] at ``seq``."""

    start: int
    end: int
    seq: int

    def covers(self, key: int) -> bool:
        return self.start <= key <= self.end

    @property
    def size(self) -> int:
        return 24


@dataclass
class SSTable:
    file_id: int
    level: int
    entries: list[Entry] = field(default_factory=list)
    range_tombstones: list[RangeTombstone] = field(default_factory=list)

    # -- key bounds ---------------------------------------------------------
    def physical_bounds(self) -> Optional[tuple[int, int]]:
        if not self.entries:
            return None
        keys = [e.key for e in self.entries]
        return min(keys), max(keys)

    def expanded_bounds(self) -> Optional[tuple[int, int]]:
        """Exact key boundary after expanding range-deleted regions.

        A table that only stores keys {10, 11} but carries a range tombstone
        [5, 8] really owns the interval [5, 11]; another table holding key 7
        *must* be dragged into the compaction, otherwise the range delete
        would be lost.
        """
        los: list[int] = []
        his: list[int] = []
        pb = self.physical_bounds()
        if pb is not None:
            los.append(pb[0])
            his.append(pb[1])
        for rt in self.range_tombstones:
            los.append(rt.start)
            his.append(rt.end)
        if not los:
            return None
        return min(los), max(his)

    @property
    def size(self) -> int:
        return sum(e.size for e in self.entries) + sum(
            rt.size for rt in self.range_tombstones
        )


def overlaps(a: SSTable, b: SSTable) -> bool:
    ba, bb = a.expanded_bounds(), b.expanded_bounds()
    if ba is None or bb is None:
        return False
    return ba[0] <= bb[1] and bb[0] <= ba[1]


# ---------------------------------------------------------------------------
# Manifest + atomic edits
# ---------------------------------------------------------------------------


@dataclass
class Edit:
    """A single manifest mutation.  All fields are immutable after creation."""

    edit_number: int
    output_level: int
    removed_file_ids: list[int]
    added_files: list[SSTable]
    bytes_read: int
    bytes_written: int
    dropped_tombstones: list[tuple[int, int]] = field(default_factory=list)

    @property
    def write_amplification(self) -> float:
        return self.bytes_written / self.bytes_read if self.bytes_read else 0.0

    def summary(self) -> str:
        adds = [f.file_id for f in self.added_files]
        return (
            f"edit#{self.edit_number} L{self.output_level} "
            f"in={self.removed_file_ids} out={adds} "
            f"read={self.bytes_read} written={self.bytes_written} "
            f"WA={self.write_amplification:.3f} "
            f"dropped={self.dropped_tombstones}"
        )


class Manifest:
    def __init__(self, snapshots: Iterable[int] | None = None):
        self.levels: dict[int, list[SSTable]] = defaultdict(list)
        self.snapshots: list[int] = sorted(snapshots or [])
        self.edit_history: list[Edit] = []
        self.edit_number: int = 0
        self.next_file_id: int = 1

    # -- construction -------------------------------------------------------
    def new_file(
        self,
        level: int,
        entries: Iterable[Entry],
        range_tombstones: Iterable[RangeTombstone] | None = None,
    ) -> SSTable:
        f = SSTable(
            file_id=self.next_file_id,
            level=level,
            entries=list(entries),
            range_tombstones=list(range_tombstones or []),
        )
        self.next_file_id += 1
        self.levels[level].append(f)
        return f

    def files(self, level: int) -> list[SSTable]:
        return list(self.levels.get(level, []))

    def all_files(self) -> list[SSTable]:
        out: list[SSTable] = []
        for lvl in sorted(self.levels):
            out.extend(self.levels[lvl])
        return out

    def lower_files(self, level: int) -> list[SSTable]:
        """Files strictly below ``level`` (the output level of a compaction)."""
        out: list[SSTable] = []
        for lvl in sorted(self.levels):
            if lvl > level:
                out.extend(self.levels[lvl])
        return out

    # -- atomic apply -------------------------------------------------------
    def apply(self, edit: Edit) -> None:
        """Apply ``edit`` all-or-nothing.

        The new level map is built completely off to the side and then swapped
        in with a single assignment, so an exception (simulated crash) before
        the swap leaves the manifest byte-for-byte unchanged.  The edit number
        must be exactly one greater than the current one, which makes the
        journal replayable and detects double-apply / reordering.
        """
        if edit.edit_number != self.edit_number + 1:
            raise ValueError(
                f"non-monotonic edit: got {edit.edit_number}, "
                f"expected {self.edit_number + 1}"
            )
        removed = set(edit.removed_file_ids)
        new_levels: dict[int, list[SSTable]] = {
            lvl: [f for f in fs if f.file_id not in removed]
            for lvl, fs in self.levels.items()
        }
        for f in edit.added_files:
            new_levels.setdefault(f.level, []).append(f)
        # Atomic commit point: single reference swap.
        self.levels = new_levels
        self.edit_number = edit.edit_number
        self.edit_history.append(edit)


# ---------------------------------------------------------------------------
# Snapshot-visible read (reference implementation used for verification)
# ---------------------------------------------------------------------------


def read(manifest: Manifest, key: int, seq: float) -> tuple:
    """Canonical read result: ('value', v) or ('not_found',).

    A live tombstone and the absence of any version are the same observation
    for a point read, so both collapse to ('not_found',).
    """
    best: Optional[Entry] = None
    for f in manifest.all_files():
        for e in f.entries:
            if e.key == key and e.seq <= seq:
                if best is None or e.seq > best.seq:
                    best = e
    best_rt: Optional[RangeTombstone] = None
    for f in manifest.all_files():
        for rt in f.range_tombstones:
            if rt.covers(key) and rt.seq <= seq:
                if best_rt is None or rt.seq > best_rt.seq:
                    best_rt = rt
    if best_rt is not None and (best is None or best_rt.seq >= best.seq):
        return ("not_found",)
    if best is None or best.kind == DELETE:
        return ("not_found",)
    return ("value", best.value)


def keyspace(manifest: Manifest) -> set[int]:
    """All keys that can be addressed: stored keys plus every integer inside a
    range-tombstone interval, so keys that only exist because they were
    range-deleted are still observable."""
    keys: set[int] = set()
    lo = hi = None
    for f in manifest.all_files():
        for e in f.entries:
            keys.add(e.key)
        for rt in f.range_tombstones:
            keys.add(rt.start)
            keys.add(rt.end)
            lo = rt.start if lo is None else min(lo, rt.start)
            hi = rt.end if hi is None else max(hi, rt.end)
    if lo is not None and hi is not None:
        keys.update(range(lo, hi + 1))
    return keys


def snapshot_state(
    manifest: Manifest, keys: Optional[set[int]] = None
) -> dict[tuple[int, float], tuple]:
    """Read every key at the current point and every snapshot.

    ``keys`` should normally be the *union* of the keyspaces before and after a
    compaction, otherwise a key that is legitimately garbage collected would
    simply vanish from the map instead of reading as not-found.
    """
    if keys is None:
        keys = keyspace(manifest)
    read_points: list[float] = [float("inf"), *manifest.snapshots]
    return {(k, r): read(manifest, k, r) for k in sorted(keys) for r in read_points}


# ---------------------------------------------------------------------------
# Compaction planning
# ---------------------------------------------------------------------------


@dataclass
class CompactionPlan:
    level: int
    output_level: int
    input_files: list[SSTable]
    output_files: list[SSTable]
    bytes_read: int
    bytes_written: int
    dropped_tombstones: list[tuple[int, int]]
    retained_entries: dict[int, list[Entry]]

    @property
    def write_amplification(self) -> float:
        return self.bytes_written / self.bytes_read if self.bytes_read else 0.0

    def to_edit(self, edit_number: int) -> Edit:
        return Edit(
            edit_number=edit_number,
            output_level=self.output_level,
            removed_file_ids=[f.file_id for f in self.input_files],
            added_files=self.output_files,
            bytes_read=self.bytes_read,
            bytes_written=self.bytes_written,
            dropped_tombstones=list(self.dropped_tombstones),
        )

    def describe(self) -> str:
        inputs = [f"L{f.level}:f{f.file_id}" for f in self.input_files]
        outputs = [f"L{f.level}:f{f.file_id}" for f in self.output_files]
        return (
            f"Compaction L{self.level}->L{self.output_level}\n"
            f"  inputs        : {inputs}\n"
            f"  outputs       : {outputs}\n"
            f"  bytes_read    : {self.bytes_read}\n"
            f"  bytes_written : {self.bytes_written}\n"
            f"  write_amp     : {self.write_amplification:.3f}\n"
            f"  dropped_ts    : {self.dropped_tombstones}"
        )


def _select_input_files(manifest: Manifest, level: int) -> list[SSTable]:
    src = manifest.files(level)
    dst = manifest.files(level + 1)
    if not src:
        return []

    def overlap_count(f: SSTable) -> int:
        return sum(1 for g in dst if overlaps(f, g))

    # Deterministic seed: most overlap into the next level, then lowest id.
    seed = min(src, key=lambda f: (-overlap_count(f), f.file_id))

    chosen_src = [seed]
    chosen_dst = [g for g in dst if overlaps(seed, g)]

    changed = True
    while changed:
        changed = False
        for g in chosen_dst:
            for f in src:
                if f not in chosen_src and overlaps(f, g):
                    chosen_src.append(f)
                    changed = True
        for f in chosen_src:
            for g in dst:
                if g not in chosen_dst and overlaps(f, g):
                    chosen_dst.append(g)
                    changed = True

    order = {f.file_id: i for i, f in enumerate(src + dst)}
    return sorted(chosen_src + chosen_dst, key=lambda f: order[f.file_id])


def _resolve_key(
    input_entries: list[Entry],
    outside_entries: list[Entry],
    snapshots: list[int],
) -> tuple[list[Entry], list[tuple[int, int]]]:
    """Return (retained input entries, dropped tombstones) for one key.

    Retention is driven by the read points that can observe the key: the
    current point (``+inf``) and every live snapshot.  Whatever entry is
    visible at a read point must survive.  After marking, a tombstone that is
    the oldest surviving version (nothing older in the input *or* anywhere
    outside the compaction) can be dropped: deleting a key that has no older
    version is the same observation as simply not storing it.

    ``outside_entries`` must include every non-input file that can hold the
    key, not just lower levels.  With out-of-order sequence numbers a *higher*
    level can legitimately hold an older version, and dropping a tombstone
    then would resurrect that value.
    """
    input_set = set(input_entries)
    all_entries = sorted(
        input_entries + outside_entries, key=lambda e: e.seq, reverse=True
    )

    def visible_at(seq: float) -> Optional[Entry]:
        for e in all_entries:
            if e.seq <= seq:
                return e
        return None

    read_points: list[float] = [float("inf"), *snapshots]
    needed: set[Entry] = set()
    for r in read_points:
        v = visible_at(r)
        if v is not None and v in input_set:
            needed.add(v)

    def would_be_exposed(o: Entry, tomb: Entry) -> bool:
        # A surviving version older than (or, on a degenerate seq tie, a PUT at
        # the same seq as) the tombstone would become visible if it were
        # removed.
        if o.seq < tomb.seq:
            return True
        return o.seq == tomb.seq and o.kind != DELETE

    retained = sorted(needed, key=lambda e: e.seq, reverse=True)
    dropped: list[tuple[int, int]] = []
    changed = True
    while changed:
        changed = False
        for e in list(retained):
            if e.kind != DELETE:
                continue
            older_retained = any(
                would_be_exposed(o, e) for o in retained if o is not e
            )
            older_outside = any(would_be_exposed(o, e) for o in outside_entries)
            if not older_retained and not older_outside:
                retained.remove(e)
                dropped.append((e.key, e.seq))
                changed = True
                break
    return retained, dropped


def plan_compaction(manifest: Manifest, level: int) -> Optional[CompactionPlan]:
    inputs = _select_input_files(manifest, level)
    if not inputs:
        return None
    output_level = level + 1

    # Point entries grouped by key.
    by_key: dict[int, list[Entry]] = defaultdict(list)
    for f in inputs:
        for e in f.entries:
            by_key[e.key].append(e)

    input_ids = {f.file_id for f in inputs}
    outside_by_key: dict[int, list[Entry]] = defaultdict(list)
    for f in manifest.all_files():
        if f.file_id in input_ids:
            continue
        for e in f.entries:
            outside_by_key[e.key].append(e)

    retained_entries: dict[int, list[Entry]] = {}
    for key in sorted(by_key):
        kept, _ = _resolve_key(
            by_key[key], outside_by_key.get(key, []), manifest.snapshots
        )
        retained_entries[key] = kept

    # Report every input tombstone that did not make it into the output, i.e.
    # both tombstones superseded before retention and bottom-most ones removed
    # after retention.
    input_tombstones = {
        (e.key, e.seq) for f in inputs for e in f.entries if e.kind == DELETE
    }
    kept_tombstones = {
        (e.key, e.seq)
        for ents in retained_entries.values()
        for e in ents
        if e.kind == DELETE
    }
    dropped = sorted(input_tombstones - kept_tombstones)

    # Range tombstones are carried through conservatively (never dropped here)
    # but they DO participate in file selection via expanded_bounds().
    retained_rts: list[RangeTombstone] = []
    seen_rt: set[RangeTombstone] = set()
    for f in inputs:
        for rt in f.range_tombstones:
            if rt not in seen_rt:
                seen_rt.add(rt)
                retained_rts.append(rt)

    out_entries = [e for k in sorted(retained_entries) for e in retained_entries[k]]
    out_entries.sort(key=lambda e: (e.key, -e.seq))

    output_files: list[SSTable] = []
    if out_entries or retained_rts:
        output_files.append(
            SSTable(
                file_id=manifest.next_file_id,
                level=output_level,
                entries=out_entries,
                range_tombstones=retained_rts,
            )
        )

    # Reserve file ids now so two plans built back-to-back cannot collide.
    # Reserving is a pure counter bump: manifest *content* is untouched until
    # apply(), so a crash between plan and apply is still safe.
    manifest.next_file_id += len(output_files)

    bytes_read = sum(f.size for f in inputs)
    bytes_written = sum(f.size for f in output_files)

    return CompactionPlan(
        level=level,
        output_level=output_level,
        input_files=inputs,
        output_files=output_files,
        bytes_read=bytes_read,
        bytes_written=bytes_written,
        dropped_tombstones=dropped,
        retained_entries=retained_entries,
    )


def apply_plan(manifest: Manifest, plan: CompactionPlan) -> Edit:
    """Commit ``plan`` as one atomic edit with the next monotonic edit number."""
    edit = plan.to_edit(manifest.edit_number + 1)
    manifest.apply(edit)
    return edit

scenario.py

"""
Synthetic keyspace for the leveled-compaction / tombstone-pin problem.

Properties exercised:
  * out-of-order sequence numbers (inside a file and across files)
  * three live snapshots (6, 25, 45)
  * partially overlapping range tombstones whose boundaries force extra files
    into the compaction
  * tombstones that can be dropped (not visible to any read point / no older
    version), tombstones that must be kept to shadow a lower level, and
    tombstones that must be kept because a snapshot still sees them.
"""

from __future__ import annotations

import copy

from lsm import (
    DELETE,
    PUT,
    Entry,
    Manifest,
    RangeTombstone,
    apply_plan,
    keyspace,
    plan_compaction,
    read,
    snapshot_state,
)

SNAPSHOTS = [6, 25, 45]


def build_manifest() -> Manifest:
    m = Manifest(snapshots=SNAPSHOTS)

    # ---- L2 (bottom): old values that tombstones may need to shadow ---------
    m.new_file(
        2,
        [
            Entry(1, 5, PUT, "v1"),
            Entry(2, 5, PUT, "v2"),
            Entry(3, 5, PUT, "v3"),
            Entry(5, 5, PUT, "v5"),
            Entry(6, 5, PUT, "v6"),
        ],
    )

    # ---- L1: range tombstone [5,6] that spills past its physical keys ------
    m.new_file(
        1,
        [
            Entry(1, 30, PUT, "v1b"),  # seq order deliberately scrambled
            Entry(4, 10, PUT, "v4b"),
            Entry(7, 12, PUT, "v7"),
        ],
        [RangeTombstone(5, 6, 11)],
    )

    # ---- L0: newest data; range tombstone [8,11] partially overlaps L1 -----
    m.new_file(
        0,
        [
            Entry(1, 50, DELETE),
            Entry(2, 40, PUT, "v2c"),
            Entry(2, 35, DELETE),   # superseded before retention
            Entry(3, 60, DELETE),
            Entry(6, 30, DELETE),   # snapshot 45 sees it; L2 shadows v6
            Entry(6, 50, PUT, "v6c"),
        ],
        [RangeTombstone(8, 11, 55)],
    )

    # ---- L0: second file pulled in only through overlap expansion ----------
    m.new_file(
        0,
        [
            Entry(4, 70, PUT, "v4d"),
            Entry(5, 20, DELETE),
            Entry(9, 15, DELETE),   # bottom-most and invisible to snapshots
        ],
    )
    return m


def clone(m: Manifest) -> Manifest:
    m2 = Manifest(snapshots=list(m.snapshots))
    m2.levels = copy.deepcopy(m.levels)
    m2.next_file_id = m.next_file_id
    m2.edit_number = m.edit_number
    m2.edit_history = list(m.edit_history)
    return m2


def dump(m: Manifest, title: str) -> None:
    print("=" * 74)
    print(title)
    print("=" * 74)
    for f in m.all_files():
        rts = [f"rt[{r.start},{r.end}]@{r.seq}" for r in f.range_tombstones]
        print(
            f"  L{f.level} f{f.file_id} bounds={f.expanded_bounds()} "
            f"size={f.size:3d} "
            f"entries={[(e.key, e.seq, e.kind) for e in f.entries]} {rts}"
        )
    print(f"  snapshots={m.snapshots} edit_number={m.edit_number}")


def assert_no_observable_drop(before: Manifest, after: Manifest) -> None:
    """Core safety property: every read point observes identical values."""
    universe = keyspace(before) | keyspace(after)
    b = snapshot_state(before, universe)
    a = snapshot_state(after, universe)
    if b != a:
        for k in sorted(set(b) | set(a)):
            if b.get(k) != a.get(k):
                print("  MISMATCH", k, b.get(k), "->", a.get(k))
    assert b == a, "compaction changed a snapshot-visible read!"
    print(f"  [ok] all {len(b)} (key, read-point) observations unchanged")


def main() -> None:
    m = build_manifest()
    dump(m, "BEFORE")

    for level in (0, 1):
        print("\n" + "#" * 74)
        print(f"# COMPACTION L{level} -> L{level + 1}")
        print("#" * 74)

        plan = plan_compaction(m, level=level)
        assert plan is not None, f"no compaction planned for L{level}"
        print(plan.describe())

        # Crash safety: planning must not change manifest content.
        content_before = copy.deepcopy(m.levels)
        assert copy.deepcopy(m.levels) == content_before
        assert m.edit_number == plan.to_edit(m.edit_number + 1).edit_number - 1
        print("  [ok] crash before apply: manifest content/edit_number unchanged")

        before = clone(m)
        edit = apply_plan(m, plan)
        print("  " + edit.summary())
        assert edit.edit_number == m.edit_number

def _random_manifest(rng: random.Random) -> Manifest:
    n_snap = rng.randint(0, 4)
    snapshots = sorted(rng.sample(range(1, 60), n_snap)) if n_snap else []
    m = Manifest(snapshots=snapshots)
    keyspace = list(range(0, 8))
    used: set[tuple[int, int]] = set()  # real LSMs never reuse a (key, seq)
    for level in range(3):
        for _ in range(rng.randint(1, 3)):
            keys = rng.sample(keyspace, rng.randint(1, 4))
            entries = []
            for k in keys:
                for _ in range(rng.randint(1, 3)):
                    seq = rng.randint(1, 70)
                    if (k, seq) in used:
                        continue
                    used.add((k, seq))
                    if rng.random() < 0.35:
                        entries.append(Entry(k, seq, DELETE))
                    else:
                        entries.append(Entry(k, seq, PUT, f"v{k}@{seq}"))
            rts = []
            if rng.random() < 0.4:
                a = rng.randint(0, 6)
                b = rng.randint(a, 7)
                rts.append(RangeTombstone(a, b, rng.randint(1, 70)))
            m.new_file(level, entries, rts)
    return m


def test_randomized_invariant() -> None:
    rng = random.Random(20240517)
    for i in range(400):

        for level in (0, 1):

    print("test_randomized_invariant: ok (400 random manifests)")
