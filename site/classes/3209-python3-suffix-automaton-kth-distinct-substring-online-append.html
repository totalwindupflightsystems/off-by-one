Online Suffix Automaton: k-th Distinct Substring with Clone-Safe Counts

Problem class: python3-suffix-automaton-kth-distinct-substring-online-append

Implement a suffix automaton that supports online character appends and, after any prefix, answers "what is the k-th lexicographically smallest distinct substring?" in O(|answer| · log σ) per query, while maintaining occurrence counts (endpos sizes) through clone-state propagation, with explicit hardening against counts that overflow the parent link tree when states are cloned mid-stream.

1. Root-cause analysis

The naive "build a suffix automaton, compute counts once, then answer queries" approach has four distinct failure modes in the online regime.

1.1 Stale caches after an online append

extend(c) can add a new state, add several transitions, and redirect existing transitions to a freshly created clone. Every append therefore changes the transition DAG, so any cached answer to "how many distinct substrings start at state v" is invalidated. A cached query result that is reused after an append silently returns answers for an older prefix.

Reproduction (string was "ab", then two appends make it "abab"):

cached at 'ab': paths[0] = 3
string is now 'abab', true distinct = 7, cached paths[0] = 3
stale kth(7) = None
after rebuild kth(7) = ('bab', 1)

Root cause: the count array is not marked dirty when the DAG changes.

1.2 Cloning duplicates end positions → parent link-tree counts overflow

A clone is created as a copy of an existing state q (same transitions). It is not a new end position. The occurrence count of a state is the size of its endpos set, computed as a subtree sum over the suffix-link tree starting from a pristine marker ones[v] = 1 for primary states and ones[clone] = 0 for clones. If a clone inherits ones[q] (or occ[q]), the endpos set is counted twice and every ancestor in the link tree is inflated.

Reproduction on "abb" (the shortest binary string that produces a clone):

quantity correct clone copies ones[q]
occ("b") 2 3

The parent-link-tree count overflowed.

1.3 Propagating an already-cumulative count

After one propagation pass, occ[v] is the subtree sum, not the marker. Running the "sum children into parent" loop again on the same array re-adds whole subtrees. Correct code must always start from the pristine ones array (or reset it), never from the previous cumulative occ.

Reproduction on "ababa":

quantity correct re-propagating cumulative occ
occ("a") 3 6

1.4 Using occurrence counts (or a sum of path counts) for distinct substrings

Two different quantities are easily confused:

  • occ[v] = number of end positions of the strings in state v (≤ n).
  • paths[v] = number of distinct substrings that can be read starting at v = Σ (1 + paths[u]) over transitions v --c--> u (up to n(n+1)/2).

The k-th distinct substring must use paths, not occ. Moreover the total number of distinct substrings is paths[root]; summing paths over all states double counts:

string 'abb':  true distinct = 5
               paths[0]      = 5   (correct)
               SUM(paths)    = 9   (wrong, double counts shared suffixes)

This is precisely "substring counts overflowing": path counts grow much faster than endpos counts and must be kept in their own array.

2. The fix

2.1 Suffix automaton with clone-safe append

Keep a pristine marker per state:

  • ones[cur] = 1 when cur is created as a primary state (new end position),
  • ones[clone] = 0 when a clone is created.

Transitions of a clone are copied (dict(self.next[q])) because the clone has exactly the same right-extension behavior as q; only its length interval and link position differ.

2.2 Counts: one topological pass each, from pristine data

Because transitions always go to a state with strictly larger length, both recurrences are evaluated in decreasing length order:

occ   = ones[:]                       # fresh copy every rebuild
paths = [0]*n
for v in states_descending_by_length:
    if link[v] != -1:
        occ[link[v]] += occ[v]        # endpos over the link tree
    paths[v] = Σ (1 + paths[u])        # distinct substrings over the DAG

paths[0] is the total number of distinct non-empty substrings. The independent identity Σ (length[v] − length[link[v]]) equals paths[0] and is used as a cross-check in the tests.

2.3 Lexicographic walk in O(|answer| · log σ)

At state v, the answers whose next character is c form a contiguous block of size 1 + paths[u]. Each state stores its transitions sorted by character with a prefix-sum array cum. A bisect_left(cum, k) locates the block; the leading 1 is the literal string current + c and the rest descend into u.

The rebuild is lazy: extend only sets dirty = True, and kth_distinct / occurrences rebuild once before use. Appends are O(1) amortized; a rebuild is O(S · log σ) for S states (equal to O(n) for a fixed alphabet); a query is O(|answer| · log σ). Batching appends between queries makes rebuilds amortize away (e.g. building a final static string and then querying costs one rebuild).

3. Complete solution

from bisect import bisect_left
"""
Online Suffix Automaton:
  - online character appends (extend)
  - occurrence counts (endpos sizes) via clone-state propagation
  - k-th lexicographically smallest DISTINCT substring

The k-th query walks the automaton's transition DAG.  For a state v, let

    paths(v) = number of non-empty strings spelled by paths starting at v
             = sum over transitions (v --c--> u) of (1 + paths(u))

Each distinct substring corresponds to exactly one path from the root
(the automaton is deterministic), so paths(root) is the number of distinct
substrings.  To spell the k-th distinct substring, walk the transitions in
lexicographic character order; the block of answers whose next character is c
has size 1 + paths(u).  Consume that literal string (the "1") before
descending, which is what makes the count of *distinct* strings exact.
"""


class SuffixAutomaton:
    def __init__(self):
        self.length = [0]      # len of longest string of the state
        self.link = [-1]       # suffix link (parent in the link tree)
        self.next = [dict()]   # transitions
        self.ones = [0]        # 1 iff state was created as a "primary" state
        self.last = 0
        # caches, rebuilt lazily
        self.occ = None        # endpos size
        self.paths = None      # distinct substrings starting at state
        self.ordered = None    # per-state (chars, prefix-sums) for O(log sigma)
        self.dirty = True

    # ---------------------------------------------------------------- append
    def extend(self, c):
        length, link, nxt, ones = self.length, self.link, self.next, self.ones
        cur = len(length)
        length.append(length[self.last] + 1)
        link.append(-1)
        nxt.append({})
        ones.append(1)                     # new end position
        p = self.last
        while p != -1 and c not in nxt[p]:
            nxt[p][c] = cur
            p = link[p]
        if p == -1:
            link[cur] = 0
        else:
            q = nxt[p][c]
            if length[p] + 1 == length[q]:
                link[cur] = q
            else:
                clone = len(length)
                length.append(length[p] + 1)
                link.append(link[q])
                nxt.append(dict(nxt[q]))   # inherit transitions
                ones.append(0)             # HARDENING: clone adds no end position
                while p != -1 and nxt[p].get(c) == q:
                    nxt[p][c] = clone
                    p = link[p]
                link[q] = clone
                link[cur] = clone
        self.last = cur
        self.dirty = True
        return cur

    def build(self, s):
        for ch in s:
            self.extend(ch)
        return self

    # ------------------------------------------------------------- rebuild
    def _rebuild(self):
        n = len(self.length)
        # Counting sort by length (lengths are in 0..n).  Bucket order gives
        # ascending length; iterate reversed for descending (topological) order.
        bucket = [0] * (n + 1)
        for v in range(n):
            bucket[self.length[v]] += 1
        for i in range(1, n + 1):
            bucket[i] += bucket[i - 1]
        order = [0] * n
        for v in range(n - 1, -1, -1):
            lv = self.length[v]
            bucket[lv] -= 1
            order[bucket[lv]] = v
        # order is ascending by length; walk it backwards.

        occ = self.ones[:]                 # fresh copy: never re-propagate
        paths = [0] * n
        for idx in range(n - 1, -1, -1):
            v = order[idx]
            # occurrence propagation up the suffix-link tree
            p = self.link[v]
            if p != -1:
                occ[p] += occ[v]
            # path counting over the transition DAG (len[u] > len[v])
            acc = 0
            for u in self.next[v].values():
                acc += 1 + paths[u]
            paths[v] = acc

        # Lexicographically ordered transitions with cumulative block sizes,
        # so each query step is a binary search (O(log sigma)).
        ordered = [None] * n
        for v in range(n):
            chars = []
            cum = []
            acc = 0
            for c in sorted(self.next[v]):
                u = self.next[v][c]
                acc += 1 + paths[u]
                chars.append(c)
                cum.append(acc)
            ordered[v] = (chars, cum)

        self.occ = occ
        self.paths = paths
        self.ordered = ordered
        self.dirty = False

    def _ensure(self):
        if self.dirty:
            self._rebuild()

    # -------------------------------------------------------------- queries
    def distinct_count(self):
        self._ensure()
        return self.paths[0]

    def kth_distinct(self, k):
        """1-indexed k-th lexicographically smallest non-empty distinct
        substring.  Returns (substring, occurrence_count) or None if out of
        range."""
        self._ensure()
        if k < 1 or k > self.paths[0]:
            return None
        v = 0
        out = []
        while True:
            chars, cum = self.ordered[v]
            idx = bisect_left(cum, k)          # first block whose cum >= k
            base = cum[idx - 1] if idx else 0
            c = chars[idx]
            u = self.next[v][c]
            out.append(c)
            if k - base == 1:                  # the literal string current+c
                return "".join(out), self.occ[u]
            k -= base + 1                      # descend into state u
            v = u

    def occurrences(self, s):
        """Number of occurrences of s (None if s is not a substring)."""
        self._ensure()
        v = 0
        for c in s:
            if c not in self.next[v]:
                return None
            v = self.next[v][c]
        return self.occ[v]

    def total_via_lengths(self):
        """Cross-check: sum(len[v] - len[link[v]]) == distinct substrings."""
        return sum(self.length[v] - (self.length[self.link[v]] if self.link[v] != -1 else 0)
                   for v in range(len(self.length)))

Usage

sa = SuffixAutomaton()
sa.extend('a'); sa.extend('b'); sa.extend('b')     # online appends
print(sa.distinct_count())        # 5
print(sa.kth_distinct(1))         # ('a', 1)
print(sa.kth_distinct(5))         # ('bb', 1)
print(sa.occurrences('b'))        # 2   (clone-safe endpos count)
print(sa.kth_distinct(99))        # None (out of range)

4. Verification

The solution was checked against brute force on python3 (3.14.4). The brute force enumerates all substrings into a sorted set and counts occurrences with str.find.

Covered by the test harness:

  • all binary strings of length 0..8;
  • all ternary strings of length 0..5;
  • unary, alternating, and periodic strings up to length 60;
  • 3000 random strings over alphabets of size 2/3/4/8;
  • online interleaving: append one character, then query, comparing with brute force at every prefix (including unary and alternating families);
  • arbitrary/Unicode alphabets (40-, 30-, and 62-symbol alphabets), verifying O(log σ) ordering;
  • for every prefix: distinct_count(), every rank k = 1..D, occurrence counts of every substring, out-of-range k ∈ {0, D+1}, and the Σ(len − len[link]) identity.
