Tiled Attention: Boundary Ownership & Bitwise-Stable Online Softmax

Problem class: tiled-attention-kernel-online-softmax-boundary-ownership Runtime: Node 20 (verified on Node 22, ES2020 only) Artifact: flash_tile.js — one command runs the whole proof: node flash_tile.js

1. Symptom

A flash-attention-style kernel over a ragged batch (per-sample Lq[b], Lk[b], head dim D not a multiple of the tile size BD) produces results that are:

  • slightly wrong at the sequence tail (a few rows/columns off), or
  • non-reproducible run-to-run (same inputs, different low bits), or
  • correct on the first launch and progressively wrong on later KV tiles.

These are three faces of the same defect: ownership of tile boundaries is not a partition, and/or online-softmax state is recomputed per KV tile instead of carried forward.

2. Root-cause analysis

2.1 Boundary ownership is not a partition

The kernel must assign every logical element to exactly one executor. The two classic off-by-one mistakes:

Defect Mechanism Observable
Double-accumulate adjacent KV tiles share a column, e.g. tile nt starts at nt*BN - 1, or the mask is j <= j1 on both neighbours a key column j is folded into the online sum twice → wrong denominator/vector
Drop ragged tail is truncated with j < floor(Lk/BN)*BN, or a ceil is missing columns j ∈ [floor(Lk/BN)*BN, Lk) never counted → wrong at the tail

Both survive a single-tile unit test and only appear when Lk % BN != 0 or D % BD != 0. The D dimension has the same hazard: the last d-tile is short, and if lanes are assigned as lane = floor(d / (D/LANES)) with a rounding shortcut, the union of lanes is neither exhaustive nor disjoint.

2.2 Online-softmax state is recomputed instead of carried

Correct online softmax carries three pieces of state per query row across KV tiles:

m    : running max  (monotone non-decreasing)
l    : running sum  of exp(s - m)
acc[]: running weighted sum of V

For each KV tile the update is applied exactly once:

mNew = max(m, max_j s_j)          // monotone: m only grows
corr = exp(m - mNew)              // rescale the *previous* state
l   *= corr ;  acc[d] *= corr
p_j  = exp(s_j - mNew)            // current tile
l   += Σ p_j ;  acc[d] += Σ p_j * V[j][d]
m    = mNew

Failure modes:

  • rescaling by the tile max rather than the running max (exp(s_j - mTile) every tile) — this is not the same function and drifts;
  • recomputing m/l from all previous tiles each step — different rounding, breaks bitwise stability, and is O(T²);
  • splitting the KV loop across warps and merging (m,l,acc) with atomicAdd — floating-point addition is non-associative, so the result depends on scheduling and changes between launches.

2.3 The interaction that makes it subtle

In a warp-specialized kernel, producer warps issue async copies for KV tiles into a double buffer while consumer warps compute. Because the producer may pre-fetch ahead, a consumer can observe tiles in a different arrival order. The fix is not to serialize the copies but to make the consumption order and the ownership deterministic:

The warp that owns a query row-tile owns its entire (m, l, acc) state and consumes KV tiles in strictly ascending tile index. Async copies only move bytes; they never change the mathematical reduction tree.

3. Exact fix

3.1 One tiling primitive: balanced partition

Replace every floor/ceil tile-range computation with a single balanced, exhaustive, disjoint partition. No other range arithmetic is permitted in the schedule.

// exhaustive + disjoint partition of [0,n) into `parts` parts.
function balanced(n, parts, idx) {
  const base = Math.floor(n / parts);
  const rem  = n % parts;
  const start = idx * base + Math.min(idx, rem); // first `rem` parts get +1
  const len   = base + (idx < rem ? 1 : 0);
  return [start, start + len];
}
  • KV tile nt: [j0,j1) = balanced(Lk[b], ceilDiv(Lk[b], BN), nt) — the short tail tile is produced automatically, with no special case and no overlap.
  • Query rows of tile mt: balanced(Lq[b], numRowTiles, mt).
  • Head dim of tile dt: balanced(D, ceilDiv(D, BD), dt).

3.2 Ownership functions (the "one warp" guarantee)

rowTile(i)  = floor(i / BM)   // one compute warp owns this row-tile
dTile(d)    = floor(d / BD)   // one lane owns this d-tile: lane = dTile % LANES
kvTile(j)   = floor(j / BN)   // consumed in ascending order by the row owner
  • The warp owning rowTile(i) is the sole owner of (m, l, acc) for every row i in that tile, so it is the sole contributor to every output element of those rows.
  • Lanes partition D via dTile % LANES; each lane writes a disjoint set of d indices.
  • Therefore the map (b,h,i,d) → (warp, lane) is a function, not a relation. writeCount[b,h,i,d] == 1 by construction.

3.3 Boundary masks

Validity is a predicate, never a range mutation:

rowValid  = i < Lq[b]
colValid  = j < Lk[b]
causalOk  = !causal || j <= i + (Lk[b] - Lq[b])   // offset = Lk - Lq
valid(i,j) = rowValid && colValid && causalOk

A masked score becomes -Infinity and contributes p_j = 0. A tile whose mTile === -Infinity is skipped entirely — it must not touch m, l, or acc (this also avoids the exp(-Inf - -Inf) = NaN trap on the first KV tile).

3.4 Canonical update order (bitwise stability)

For each owned query row:

  1. loop nt from 0 to ceilDiv(Lk[b],BN)-1 ascending, exactly once;
  2. mNew = max(m, mTile); corr = exp(m - mNew); scale l and acc only if corr !== 1;
  3. accumulate p_j and p_j * V for j ascending;
  4. finalize O = acc / l.

No atomics, no cross-warp reduction, no state recomputation. Because the reduction tree (tile order, j order, d order) is statically fixed, two runs produce bit-identical output.

3.5 Async-copy contract

  • Producer copies [j0, j1) bytes; j1 follows from balanced, so no over-read and no duplicate column is ever staged.
  • The consumer's loop index nt is the ordering token; barriers are attached to that token, not to buffer arrival.
  • Double-buffer slots are indexed nt % STAGES; the barrier guarantees slot nt % STAGES is free only after the consumer for nt - STAGES has retired.

'use strict';
const assert = require('assert');

function mulberry32(a) {
  return function () {
    a |= 0; a = (a + 0x6d2b79f5) | 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
const ceilDiv = (a, b) => Math.floor((a + b - 1) / b);

// exhaustive + disjoint partition of [0,n) into `parts` parts
function balanced(n, parts, idx) {
  const base = Math.floor(n / parts), rem = n % parts;
  const start = idx * base + Math.min(idx, rem);
  return [start, start + base + (idx < rem ? 1 : 0)];
}

function makeBatch({ B, H, D, Lq, Lk, causal = true, seed = 0xC0FFEE }) {
  const rnd = mulberry32(seed), rand = () => rnd() * 2 - 1;
  const totalQ = Lq.reduce((a, b) => a + b, 0);
  const totalK = Lk.reduce((a, b) => a + b, 0);
  const Q = new Float64Array(totalQ * H * D);
  const K = new Float64Array(totalK * H * D);
  const V = new Float64Array(totalK * H * D);
  const qOff = new Array(B + 1).fill(0), kOff = new Array(B + 1).fill(0);
  for (let b = 0; b < B; b++) { qOff[b + 1] = qOff[b] + Lq[b]; kOff[b + 1] = kOff[b] + Lk[b]; }
  for (let i = 0; i < Q.length; i++) Q[i] = rand();
  for (let i = 0; i < K.length; i++) { K[i] = rand(); V[i] = rand(); }
  return { B, H, D, Lq, Lk, causal, Q, K, V, qOff, kOff, totalQ };
}
const qIndex = (bt, b, h, i, d) => (((bt.qOff[b] + i) * bt.H + h) * bt.D + d);
const kIndex = (bt, b, h, j, d) => (((bt.kOff[b] + j) * bt.H + h) * bt.D + d);

function referenceAttention(bt) {
  const { B, H, D, Lq, Lk, Q, K, V, causal } = bt;
  const O = new Float64Array(bt.totalQ * H * D), scale = 1 / Math.sqrt(D);
  for (let b = 0; b < B; b++) {
    const offset = Lk[b] - Lq[b];
    for (let h = 0; h < H; h++) for (let i = 0; i < Lq[b]; i++) {
      const s = new Float64Array(Lk[b]); let m = -Infinity;
      for (let j = 0; j < Lk[b]; j++) {
        if (causal && j > i + offset) { s[j] = -Infinity; continue; }
        let dot = 0;
        for (let d = 0; d < D; d++) dot += Q[qIndex(bt, b, h, i, d)] * K[kIndex(bt, b, h, j, d)];
        s[j] = dot * scale; if (s[j] > m) m = s[j];
      }
      let l = 0;
      for (let j = 0; j < Lk[b]; j++) { if (s[j] === -Infinity) { s[j] = 0; continue; } s[j] = Math.exp(s[j] - m); l += s[j]; }
      for (let d = 0; d < D; d++) {
        let acc = 0;
        for (let j = 0; j < Lk[b]; j++) acc += s[j] * V[kIndex(bt, b, h, j, d)];
        O[qIndex(bt, b, h, i, d)] = l === 0 ? 0 : acc / l;
      }
    }
  }
  return O;
}

// cfg = { BM, BN, BD, LANES, bugOverlapKV?, bugDropLast? }
function tiledAttention(bt, cfg) {
  const { B, H, D, Lq, Lk, Q, K, V, causal } = bt;
  const { BM, BN, BD, LANES } = cfg;
  const O = new Float64Array(bt.totalQ * H * D);
  const writeCount = new Int32Array(bt.totalQ * H * D);
  const scale = 1 / Math.sqrt(D);
  const rowsPerBH = new Array(B * H);
  for (let b = 0; b < B; b++) for (let h = 0; h < H; h++) rowsPerBH[b * H + h] = ceilDiv(Lq[b], BM);

  for (let b = 0; b < B; b++) {
    const offset = Lk[b] - Lq[b];
    const numKVtiles = ceilDiv(Lk[b], BN);
    for (let h = 0; h < H; h++) for (let i = 0; i < Lq[b]; i++) {
      const mt = Math.floor(i / BM);
      let wid = mt;
      for (let k = 0; k < b * H + h; k++) wid += rowsPerBH[k];   // one warp owns this row-tile
      let m = -Infinity, l = 0;
      const acc = new Float64Array(D);

      let nLast = cfg.bugDropLast ? numKVtiles - 2 : numKVtiles - 1;
      for (let nt = 0; nt <= nLast; nt++) {
        let [j0, j1] = balanced(Lk[b], numKVtiles, nt);          // clamp, never overlap
        if (cfg.bugOverlapKV && nt > 0) { j0 -= 1; j1 = Math.min(j0 + BN, Lk[b]); } // defect only
        if (j0 >= j1) continue;

        const s = new Float64Array(j1 - j0); let mTile = -Infinity;
        for (let j = j0; j < j1; j++) {
          if (causal && j > i + offset) { s[j - j0] = -Infinity; continue; }
          let dot = 0;
          for (let d = 0; d < D; d++) dot += Q[qIndex(bt, b, h, i, d)] * K[kIndex(bt, b, h, j, d)];
          dot *= scale; s[j - j0] = dot; if (dot > mTile) mTile = dot;
        }
        if (mTile === -Infinity) continue;                        // never touch state

        const mNew = Math.max(m, mTile), corr = Math.exp(m - mNew);
        if (corr !== 1) { l *= corr; for (let d = 0; d < D; d++) acc[d] *= corr; }
        m = mNew;
        for (let j = j0; j < j1; j++) {                            // ascending j
          const p = s[j - j0] === -Infinity ? 0 : Math.exp(s[j - j0] - mNew);
          l += p;
          if (p !== 0) { const kb = kIndex(bt, b, h, j, 0); for (let d = 0; d < D; d++) acc[d] += p * V[kb + d]; }
        }
      }
      for (let d = 0; d < D; d++) {                                // one writer per element
        const e = qIndex(bt, b, h, i, d);
        writeCount[e] += 1;
        O[e] = l === 0 ? 0 : acc[d] / l;
      }
    }
  }
  for (let b = 0; b < B; b++) for (let h = 0; h < H; h++) for (let i = 0; i < Lq[b]; i++)
    for (let d = 0; d < D; d++)
      assert.strictEqual(writeCount[qIndex(bt, b, h, i, d)], 1, 'exactly-once violated');
  return { O, writeCount };
}

/* --------------------------- verification --------------------------- */
function proveDPartition(D, BD) {
  const seen = new Int32Array(D), nDT = ceilDiv(D, BD);
  for (let dt = 0; dt < nDT; dt++) { const [d0, d1] = balanced(D, nDT, dt); for (let d = d0; d < d1; d++) seen[d]++; }
  for (let d = 0; d < D; d++) assert.strictEqual(seen[d], 1, `D=${D} BD=${BD} d=${d}`);
}
function proveKVTiling(Lk, BN, bugOverlap) {
  const seen = new Int32Array(Lk), nT = ceilDiv(Lk, BN);
  for (let nt = 0; nt < nT; nt++) {
    let [j0, j1] = balanced(Lk, nT, nt);
    if (bugOverlap && nt > 0) { j0 -= 1; j1 = Math.min(j0 + BN, Lk); }
    for (let j = j0; j < j1; j++) seen[j]++;
  }
  return seen;
}
const sameBits = (a, b) => Buffer.from(a.buffer, a.byteOffset, a.byteLength)
  .equals(Buffer.from(b.buffer, b.byteOffset, b.byteLength));
const maxAbsDiff = (a, b) => { let m = 0; for (let i = 0; i < a.length; i++) m = Math.max(m, Math.abs(a[i] - b[i])); return m; };

for (const D of [1, 2, 5, 7, 16, 17, 31, 32, 33, 64, 65]) for (const BD of [1, 3, 4, 5, 8, 16]) proveDPartition(D, BD);
for (const Lk of [1, 3, 4, 5, 7, 8, 9, 15, 16, 17]) for (const BN of [1, 2, 3, 4, 8]) {
  const seen = proveKVTiling(Lk, BN, false);
  for (let j = 0; j < Lk; j++) assert.strictEqual(seen[j], 1, `KV partition Lk=${Lk} BN=${BN} j=${j}`);
}

const bt = makeBatch({ B: 4, H: 3, D: 17, Lq: [15, 7, 1, 23], Lk: [15, 10, 1, 30], causal: true, seed: 0xBADC0DE });
const cfg = { BM: 4, BN: 3, BD: 5, LANES: 4 };
const ref = referenceAttention(bt);
const r1 = tiledAttention(bt, cfg), r2 = tiledAttention(bt, cfg);
assert.ok(maxAbsDiff(r1.O, ref) < 1e-9, 'matches reference');
assert.ok(sameBits(r1.O, r2.O), 'bitwise deterministic');
assert.ok(maxAbsDiff(tiledAttention(bt, { ...cfg, bugOverlapKV: true }).O, ref) > 1e-9, 'overlap detected');
assert.ok(maxAbsDiff(tiledAttention(bt, { ...cfg, bugDropLast: true }).O, ref) > 1e-9, 'drop detected');

5.2 No-drop / no-double-accumulate argument

  1. balanced(n, parts, i) returns [start_i, end_i) with start_0 = 0, end_{parts-1} = n, and end_i = start_{i+1}. Therefore ∪ [start_i,end_i) = [0,n) (no drop) and the intervals are pairwise disjoint (no double count). This holds for any n, parts, including n < parts and n % parts != 0.
  2. Applying it independently to Lk[b], Lq[b], and D gives disjoint exhaustive tilings along KV, rows, and head dim.
  3. Ownership is a total function (b,h,i,d) → (warp(rowTile(i)), lane(dTile(d))); since warp and lane are keyed by the unique tile containing i and d, exactly one executor finalizes each element.
  4. The online recurrence is applied once per KV tile with the running (monotone) max; m, l, acc are never rebuilt, so no contribution is re-added and no state is recomputed.
  5. The reduction order is a compile-time constant (ascending nt, ascending j, ascending d), so the floating-point result is a deterministic function of the inputs — verified bit-for-bit across repeated runs.

5.3 What to enforce when porting to CUDA/Triton

  • Never write j1 = j0 + BN without min(..., Lk). Use balanced.
  • Never split the KV loop across warps without also splitting query rows; if shared rows are unavoidable, merge (m,l,acc) with the closed-form log-sum-exp merge in a fixed warp order, never atomicAdd.
  • Keep m monotone; rescale with exp(m_old - m_new).
  • -Infinity rows/cols must contribute p=0; skip all-masked tiles before touching state.
  • Bind producer double-buffer slots to the same nt token the consumer uses, so async prefetch cannot reorder the reduction.
