Diagnosis

A peephole phase-ordering pass picks the next rewrite from local profitability only and never re-validates the global value-dependency DAG. Two rewrites can therefore become mutually dependent (A→B→C→A), producing a real loop-carried value recurrence. Reordering cannot fix it; the downstream topological scheduler either aborts or emits uses before defs, so definitions stop dominating uses.

Greedy "cut the back-edge you notice" is the trap: it is provably suboptimal when cycles overlap (the figure-eight case needs 2 bridges; a shared-node cut needs 3).

Root cause + exact fix

Because every node is retained (the task says renumber, not delete), ΣL(v) is constant, so the objective collapses to a minimum feedback arc set (fewest COPY bridges). The fix:

  1. SCC-decompose with iterative Tarjan (cycles are confined to SCCs; cross-SCC edges are never bridged, min-FAS(G)=Σ_SCC min-FAS).
  2. Per SCC, run an exact O(2^k·k) subset DP over the Linear Ordering identity min-FAS = min over orders of #backward edges; reconstruct the optimal order and read off bridges (self-loops always bridged).
  3. Order the condensation topologically, concatenate each SCC's internal optimum, renumber 0…n-1 so every non-bridge edge points forward.
  4. Emit one COPY prev_iter(u) per bridge; it carries the loop-carried value and does not re-close the current-iteration cycle.

Optimality proof: any order's backward edges form a valid FAS; a minimum FAS leaves a DAG whose topological order makes exactly the removed edges backward — so the two minima coincide. The DP induction then attains that minimum.

Verification (all passing)

  • DP optimum vs. brute-force edge-subset search on 720 random graphs
  • Weighted DP vs. all k! permutations on 400 random graphs
  • 200 random graphs: retained graph acyclic, every def index < every use index, every non-trivial SCC bridged, total_cost = ΣL + |B|
  • Structural: disjoint 2-cycles, forced self-loop bridge, figure-eight SCC (optimum 2)

Worked example 0→1→2→0 + tail 2→3, latencies [3,1,2,4]: one bridge, total cost 10+1=11, verified OK. Exact DP is exponential only in SCC size (real recurrences are tiny); §7 documents the ILP/approx fallback for k ≳ 22.
