TLS 1.3 0-RTT Anti-Replay: Quorum-Fenced, Bounded, Single-Use Admission

Root-cause analysis

The failure is the composition of five defects:

  1. Stateless acceptance — the ticket is decrypted and early data admitted without ever recording consumption. A PSK ticket is a bearer token, so every presenter wins.
  2. No global serialization point — a per-node cache only rejects same-node replays. Under partition, {A,B} and {C,D} each believe the ticket is fresh and both admit it.
  3. Epoch rotation without a fence — no monotonic boundary is enforced, so pre-rotation tickets stay valid forever and the replay window is unbounded in time.
  4. Unbounded replay state — storing every seen ID forever is an OOM/eviction attack; there is no fail-closed policy when the window fills.
  5. Non-linearizable epoch advance — partitions can sit at different epochs, so neither side knows which is authoritative.

Core insight: no local cache can give a global at-most-once guarantee under partition. Single-use must be anchored at a quorum; the epoch must be a majority-backed monotonic fence; and the backing state must be bounded. The only safe default without a quorum is fail closed.

Fix design

Ticket identity: (epoch, 128-bit random id) encoded inside the encrypted ticket (tls.SessionState.Extra).

Quorum-anchored single use: each node keeps a bounded key -> immutable owner map. Admission commits iff quorum = N/2+1 nodes accept this proposal. acquire never overwrites.

Safety proof. Two winning proposals P,Q for one key have majority sets that intersect at node x. The stored owner at x is written once and never changes, so it cannot equal both P and Q. Two quorums cannot both exist ⇒ at most one admission. Disjoint partition groups can't both hold a majority, so only one side admits and the minority fails closed; after heal the winner's immutable owner rejects replays.

Monotonic epoch fence: committed epoch = value held by a majority. AdvanceEpoch only current -> current+1 with a quorum ack and never rolls back. acquire rejects ticket.Epoch < node.epoch (ErrFenced) and > node.epoch (ErrFutureEpoch). The epoch check and the claim are one atomic step, closing the rotation TOCTOU.

Bounded state: hard per-node capacity; full window fails closed (ErrExhausted), never silently evicts. Entries are reclaimed only on epoch advance, and the fence makes those tickets unusable first.

cluster.go (the core admission path):

// Package zerortt implements a fail-closed, quorum-anchored single-use
// admission gate for TLS 1.3 0-RTT (early-data) session tickets in a
// partitioned server cluster.
package zerortt

import (
    "errors"
    "fmt"
    "strconv"
    "sync"
    "sync/atomic"
)

var (
    ErrNoQuorum    = errors.New("zerortt: no reachable quorum")
    ErrFenced      = errors.New("zerortt: ticket fenced (minted before current epoch)")
    ErrFutureEpoch = errors.New("zerortt: ticket epoch is ahead of committed epoch")
    ErrReplay      = errors.New("zerortt: ticket already admitted (replay)")
    ErrExhausted   = errors.New("zerortt: replay window exhausted")
    ErrEpochGap    = errors.New("zerortt: epoch advance must be exactly current+1")
    ErrDead        = errors.New("zerortt: node is crashed")
)

// Ticket is the security-relevant identity of a PSK/0-RTT ticket.
type Ticket struct {
    ID    string
    Epoch uint64
}

// Key returns the bounded replay-cache key for the ticket.
func (t Ticket) Key() string {
    return strconv.FormatUint(t.Epoch, 10) + "/" + t.ID
}

type acquireStatus int

const (
    statusGranted acquireStatus = iota // claim inserted
    statusOwned                        // already claimed by this proposal
    statusReplay                       // already claimed by another proposal
    statusFull                         // window full and ticket absent
    statusFenced                       // node epoch > ticket epoch
    statusFuture                       // node epoch < ticket epoch
)

type entry struct {
    owner string
    epoch uint64
}

type nodeStore struct {
    mu      sync.Mutex
    epoch   uint64
    entries map[string]*entry
    limit   int
}

func newNode(epoch uint64, limit int) *nodeStore {
    return &nodeStore{epoch: epoch, entries: make(map[string]*entry), limit: limit}
}

// acquire is the atomic single-use claim. Once a key is present its owner is
// never overwritten, which is what makes the quorum protocol safe.
func (s *nodeStore) acquire(t Ticket, owner string) acquireStatus {
    s.mu.Lock()
    defer s.mu.Unlock()
    if t.Epoch < s.epoch {
        return statusFenced
    }
    if t.Epoch > s.epoch {
        return statusFuture
    }
    key := t.Key()
    if e, ok := s.entries[key]; ok {
        if e.owner == owner {
            return statusOwned
        }
        return statusReplay
    }
    if len(s.entries) >= s.limit {
        return statusFull
    }
    s.entries[key] = &entry{owner: owner, epoch: t.Epoch}
    return statusGranted
}

// setEpoch moves the node's epoch forward and GCs entries from older epochs.
// The fence makes those tickets unusable, so dropping them is safe.
func (s *nodeStore) setEpoch(e uint64) {
    s.mu.Lock()
    defer s.mu.Unlock()
    if e <= s.epoch {
        return
    }
    s.epoch = e
    for k, v := range s.entries {
        if v.epoch < e {
            delete(s.entries, k)
        }
    }
}

func (s *nodeStore) currentEpoch() uint64 {
    s.mu.Lock()
    defer s.mu.Unlock()
    return s.epoch
}

func (s *nodeStore) size() int {
    s.mu.Lock()
    defer s.mu.Unlock()
    return len(s.entries)
}

// Cluster is an in-memory model of an N-node TLS terminator fleet.
type Cluster struct {
    mu    sync.RWMutex
    nodes []*nodeStore
    alive []bool
    group []int
    next  atomic.Uint64
    limit int
}

func NewCluster(n, limit int) *Cluster {
    if n <= 0 {
        panic("zerortt: cluster needs at least one node")
    }
    if limit <= 0 {
        panic("zerortt: replay window limit must be positive")
    }
    c := &Cluster{limit: limit}
    for i := 0; i < n; i++ {
        c.nodes = append(c.nodes, newNode(1, limit))
        c.alive = append(c.alive, true)
        c.group = append(c.group, 0)
    }
    return c
}

func (c *Cluster) N() int        { return len(c.nodes) }
func (c *Cluster) Quorum() int   { return len(c.nodes)/2 + 1 }
func (c *Cluster) Limit() int    { return c.limit }

func (c *Cluster) reachable(from, to int) bool {
    if from < 0 || from >= len(c.nodes) || to < 0 || to >= len(c.nodes) {
        return false
    }
    if !c.alive[from] || !c.alive[to] {
        return false
    }
    return c.group[from] == c.group[to]
}

// Partition splits the cluster into the supplied groups; unnamed nodes become
// isolated singletons.
func (c *Cluster) Partition(groups ...[]int) {
    c.mu.Lock()
    defer c.mu.Unlock()
    gid := 1
    seen := make([]bool, len(c.nodes))
    for _, g := range groups {
        for _, i := range g {
            if i >= 0 && i < len(c.nodes) && !seen[i] {
                c.group[i] = gid
                seen[i] = true
            }
        }
        gid++
    }
    for i := range c.nodes {
        if !seen[i] {
            c.group[i] = gid
            gid++
        }
    }
}

func (c *Cluster) Heal() {
    c.mu.Lock()
    defer c.mu.Unlock()
    for i := range c.group {
        c.group[i] = 0
    }
}

func (c *Cluster) Crash(i int) {
    c.mu.Lock()
    defer c.mu.Unlock()
    if i >= 0 && i < len(c.nodes) {
        c.alive[i] = false
    }
}

func (c *Cluster) Restart(i int) {
    c.mu.Lock()
    defer c.mu.Unlock()
    if i >= 0 && i < len(c.nodes) {
        c.alive[i] = true
    }
}

// committedEpochLocked returns the unique epoch held by a majority of
// reachable nodes and converges lagging nodes onto it.
func (c *Cluster) committedEpochLocked(from int) (uint64, bool) {
    if !c.reachable(from, from) {
        return 0, false
    }
    counts := make(map[uint64]int)
    for j := range c.nodes {
        if c.reachable(from, j) {
            counts[c.nodes[j].currentEpoch()]++
        }
    }
    var best uint64
    found := false
    for e, n := range counts {
        if n >= c.Quorum() && (!found || e > best) {
            best, found = e, true
        }
    }
    if !found {
        return 0, false
    }
    for j := range c.nodes {
        if c.reachable(from, j) {
            c.nodes[j].setEpoch(best)
        }
    }
    return best, true
}

func (c *Cluster) CommittedEpoch(from int) (uint64, bool) {
    c.mu.RLock()
    defer c.mu.RUnlock()
    return c.committedEpochLocked(from)
}

// Admit consumes a ticket exactly once. nil means committed by a quorum;
// every error means reject the early data (fail closed).
func (c *Cluster) Admit(from int, t Ticket) error {
    c.mu.RLock()
    defer c.mu.RUnlock()

    if !c.reachable(from, from) {
        return ErrDead
    }
    cur, ok := c.committedEpochLocked(from)
    if !ok {
        return ErrNoQuorum
    }
    if t.Epoch < cur {
        return fmt.Errorf("%w: ticket=%d current=%d", ErrFenced, t.Epoch, cur)
    }
    if t.Epoch > cur {
        return fmt.Errorf("%w: ticket=%d current=%d", ErrFutureEpoch, t.Epoch, cur)
    }

    owner := strconv.Itoa(from) + "#" + strconv.FormatUint(c.next.Add(1), 10)
    granted := 0
    sawReplay, sawFull, sawFenced := false, false, false
    for j := range c.nodes {
        if !c.reachable(from, j) {
            continue
        }
        switch c.nodes[j].acquire(t, owner) {
        case statusGranted, statusOwned:
            granted++
        case statusReplay:
            sawReplay = true
        case statusFull:
            sawFull = true
        case statusFenced:
            sawFenced = true
        }
    }
    if granted >= c.Quorum() {
        return nil
    }
    if sawReplay {
        return fmt.Errorf("%w: %s", ErrReplay, t.Key())
    }
    if sawFull {
        return fmt.Errorf("%w: limit=%d", ErrExhausted, c.limit)
    }
    if sawFenced {
        return fmt.Errorf("%w: ticket=%d current=%d", ErrFenced, t.Epoch, cur)
    }
    return ErrNoQuorum
}

// AdvanceEpoch rotates the ticket-key epoch: quorum-backed and monotonic.
func (c *Cluster) AdvanceEpoch(from int, newEpoch uint64) error {
    c.mu.RLock()
    defer c.mu.RUnlock()

    if !c.reachable(from, from) {
        return ErrDead
    }
    cur, ok := c.committedEpochLocked(from)
    if !ok {
        return ErrNoQuorum
    }
    if newEpoch != cur+1 {
        return fmt.Errorf("%w: current=%d requested=%d", ErrEpochGap, cur, newEpoch)
    }
    acks := 0
    for j := range c.nodes {
        if !c.reachable(from, j) {
            continue
        }
        c.nodes[j].setEpoch(newEpoch)
        if c.nodes[j].currentEpoch() >= newEpoch {
            acks++
        }
    }
    if acks < c.Quorum() {
        return ErrNoQuorum
    }
    return nil
}

func (c *Cluster) State(i int) (epoch uint64, used int, capacity int) {
    c.mu.RLock()
    defer c.mu.RUnlock()
    if i < 0 || i >= len(c.nodes) {
        return 0, 0, c.limit
    }
    return c.nodes[i].currentEpoch(), c.nodes[i].size(), c.limit
}

tlsgate.go (real crypto/tls wiring):

package zerortt

import (
    "crypto/rand"
    "crypto/tls"
    "encoding/binary"
    "fmt"
)

const ticketMetaPrefix = "\x00zerortt/1\x00"

const (
    ticketIDLen  = 16
    ticketRecLen = len(ticketMetaPrefix) + 8 + ticketIDLen
)

// EncodeTicketMetadata appends (epoch, id) to ss.Extra as a self-identifying
// record inside the encrypted ticket.
func EncodeTicketMetadata(ss *tls.SessionState, epoch uint64, id []byte) error {
    if len(id) != ticketIDLen {
        return fmt.Errorf("zerortt: ticket id must be %d bytes, got %d", ticketIDLen, len(id))
    }
    rec := make([]byte, 0, ticketRecLen)
    rec = append(rec, ticketMetaPrefix...)
    var b [8]byte
    binary.BigEndian.PutUint64(b[:], epoch)
    rec = append(rec, b[:]...)
    rec = append(rec, id...)
    ss.Extra = append(ss.Extra, rec)
    return nil
}

func ExtractTicketMetadata(ss *tls.SessionState) (Ticket, bool) {
    if ss == nil {
        return Ticket{}, false
    }
    for _, rec := range ss.Extra {
        if len(rec) == ticketRecLen && string(rec[:len(ticketMetaPrefix)]) == ticketMetaPrefix {
            epoch := binary.BigEndian.Uint64(rec[len(ticketMetaPrefix) : len(ticketMetaPrefix)+8])
            id := rec[len(ticketMetaPrefix)+8:]
            return Ticket{ID: string(id), Epoch: epoch}, true
        }
    }
    return Ticket{}, false
}

// Gate binds one TLS terminator node to the cluster admission protocol.
type Gate struct {
    Cluster *Cluster
    Node    int
    Config  *tls.Config
}

// NewGate wires g's callbacks into cfg.
func NewGate(cfg *tls.Config, c *Cluster, node int) *Gate {
    g := &Gate{Cluster: c, Node: node, Config: cfg}
    cfg.WrapSession = g.WrapSession
    cfg.UnwrapSession = g.UnwrapSession
    return g
}

func (g *Gate) WrapSession(cs tls.ConnectionState, ss *tls.SessionState) ([]byte, error) {
    id := make([]byte, ticketIDLen)
    if _, err := rand.Read(id); err != nil {
        return nil, err
    }
    epoch, ok := g.Cluster.CommittedEpoch(g.Node)
    if !ok {
        return nil, ErrNoQuorum
    }
    if err := EncodeTicketMetadata(ss, epoch, id); err != nil {
        return nil, err
    }
    return g.Config.EncryptTicket(cs, ss)
}

// UnwrapSession consumes a ticket exactly once. Any rejection returns
// (nil, nil) so crypto/tls declines the resumption/0-RTT.
func (g *Gate) UnwrapSession(identity []byte, cs tls.ConnectionState) (*tls.SessionState, error) {
    ss, err := g.Config.DecryptTicket(identity, cs)
    if err != nil || ss == nil {
        return nil, nil
    }
    t, ok := ExtractTicketMetadata(ss)
    if !ok {
        return nil, nil
    }
    if err := g.Cluster.Admit(g.Node, t); err != nil {
        return nil, nil // fail closed
    }
    return ss, nil
}

// OnQUICResumeSession is called on tls.QUICResumeSession: the hook crypto/tls
// provides to accept or decline 0-RTT. Clearing EarlyData declines 0-RTT while
// still allowing a normal handshake.
func (g *Gate) OnQUICResumeSession(ev *tls.QUICEvent) error {
    if ev == nil || ev.Kind != tls.QUICResumeSession || ev.SessionState == nil {
        return nil
    }
    t, ok := ExtractTicketMetadata(ev.SessionState)
    if !ok {
        ev.SessionState.EarlyData = false
        return nil
    }
    if err := g.Cluster.Admit(g.Node, t); err != nil {
        ev.SessionState.EarlyData = false
        return err
    }
    return nil
}

Limitations: during a partition the minority cannot admit 0-RTT (deliberate; CAP forbids both strict single-use and availability). Go emits QUICResumeSession before binder verification, so a forged ClientHello can burn a ticket (availability DoS, not a safety break). For production, make nodeStore durable (WAL/replicated log + fsync before ack). No wall-clock is used, so clock skew cannot widen the window.
