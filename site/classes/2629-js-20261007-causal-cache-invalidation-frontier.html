Causal Cache Invalidation Frontier — diagnosis and verified fix

Problem class: js-20261007-causal-cache-invalidation-frontier (node20)

A distributed cache tracker receives out-of-order causal context vectors ("version vectors") for writes and invalidations. It must evict an entry only when an observed dependency frontier provably dominates the entry's context, keep working across replica resets and bounded metadata compaction, and guarantee that delayed or concurrent writes cannot resurrect a value that has already been invalidated.

This document contains the root-cause analysis, the exact fix (a complete, dependency-free Node.js module), and a verification suite with real output.

1. Root-cause analysis

The task looks like "add a version-vector comparison", but four independent failure modes make a naive implementation incorrect. Each one is a distinct root cause; all four must be addressed.

1.1 Out-of-order delivery breaks naive application

Events arrive in arbitrary order. Applying a later write before its causal predecessor violates causality and can materialise a value that was never visible. The fix is causal buffering: an event is only applied when its dependency context (the vector before the write, deps) is already observed; otherwise it is parked and retried after every successful delivery.

Root cause: the tracker compared only the event's dot, not the context it depends on.

1.2 Eviction must be gated on proof of dominance

A cache may only release an entry when it can prove that every replica that could still reference the entry has advanced past it. "Newer timestamp" is not enough. The correct predicate is component-wise dominance of the merged invalidation frontier over the entry's context:

evict(entry)  ⇔  frontier[key].dominates(entry.clock)

A concurrent frontier (neither side dominates) must not evict, otherwise a live value is lost.

Root cause: treating a delete as "latest write wins" instead of "dominates the dependency frontier".

1.3 Concurrent branches and the lost-candidate bug

The obvious register optimisation — keep one value per key and let the highest Lamport timestamp win — is not convergent when combined with causal invalidation. Counter-example:

  • p_a = {Z:1} and p_b = {X:1} are concurrent; ts(p_a) < ts(p_b).
  • A delete d = {X:1} dominates p_b but not p_a.

With single-value LWW, p_b replaces p_a, then d evicts p_b, and p_a is gone. Yet p_a was never dominated, so it must survive. Different delivery orders then produce different final states.

Root cause: collapsing the concurrent version set too early. The fix is to keep the set of concurrent versions per key (an MV-register), prune versions only when one causally dominates another or when the frontier/floor dominates them, and read the maximum (ts, replica) survivor. This is a join-semilattice and is therefore order-independent and convergent.

1.4 Replica resets and vector compaction resurrect stale values

Two related problems:

  • Resets. A restarted replica may emit dots with smaller counters (epoch 0, seq 1) than its pre-reset history. A delayed pre-reset message can then look "newer" or re-create a deleted value. Fix: per-replica incarnations (epochs). Dominance compares (epoch, seq) lexicographically, so a post-reset write dominates all earlier incarnations; maxEpoch[replica] rejects delayed pre-reset messages; and the reset marker is durably recorded.
  • Compaction. Frontiers cannot grow forever with the key count. Introduce a globally acknowledged stable floor. Components at or below the floor are pruned from every frontier ("exceptions only"), and the floor becomes a permanent anti-resurrection watermark: any write whose dot is at or below the floor is dropped. This bounds metadata by the number of live exceptions rather than by the number of keys.

Root cause: unbounded tombstones / no incarnation, which lets garbage-collected history be replayed.

2. The fix

The complete implementation. It is dependency-free CommonJS and runs on Node.js 20+. Save it as causal-cache.js.

2.1 causal-cache.js

'use strict';

/*
 * CausalCache — distributed cache invalidation tracker.
 *
 * A cache entry carries a causal context (version vector) describing the
 * writes it depends on.  Invalidation messages also carry a context
 * ("frontier").  An entry may be evicted only when a frontier we have
 * observed *provably dominates* the entry's context.  Out-of-order messages
 * (including messages from before a replica reset) must not resurrect a
 * value that has been invalidated.
 *
 * Contexts are sparse version vectors with per-replica incarnations:
 *
 *     Clock = { replica -> [epoch, seq] }
 *
 * Epoch is bumped on a replica reset ("incarnation").  Dominance compares
 * (epoch, seq) lexicographically per replica.  This makes a post-reset write
 * dominate every write from the previous incarnation of the same replica,
 * while letting us *reject* delayed pre-reset messages via the maxEpoch and
 * floor watermarks.
 */

const ZERO = [0, 0];

function cmpComp(a, b) {
  if (a[0] !== b[0]) return a[0] < b[0] ? -1 : 1;
  if (a[1] !== b[1]) return a[1] < b[1] ? -1 : 1;
  return 0;
}

function maxComp(a, b) {
  return cmpComp(a, b) >= 0 ? a : b;
}

class Clock {
  constructor(map) {
    this.map = map instanceof Map ? map : new Map();
  }

  static fromJSON(obj) {
    const c = new Clock();
    if (!obj) return c;
    const keys = Array.isArray(obj) ? null : Object.keys(obj);
    if (keys) {
      for (const r of keys) {
        const v = obj[r];
        if (Array.isArray(v) && (v[0] !== 0 || v[1] !== 0)) c.map.set(r, [v[0], v[1]]);
      }
    } else {
      // [[replica,[epoch,seq]], ...]
      for (const [r, v] of obj) {
        if (v && (v[0] !== 0 || v[1] !== 0)) c.map.set(r, [v[0], v[1]]);
      }
    }
    return c;
  }

  get(r) {
    return this.map.get(r) || ZERO;
  }

  set(r, comp) {
    if (!comp) return;
    if (comp[0] === 0 && comp[1] === 0) this.map.delete(r);
    else this.map.set(r, [comp[0], comp[1]]);
  }

  observe(r, comp) {
    if (cmpComp(comp, this.get(r)) > 0) this.set(r, comp);
  }

  clone() {
    const c = new Clock();
    for (const [r, v] of this.map) c.map.set(r, [v[0], v[1]]);
    return c;
  }

  size() {
    return this.map.size;
  }

  isEmpty() {
    return this.map.size === 0;
  }

  /** this := max(this, other) pointwise. Returns this. */
  merge(other) {
    for (const [r, v] of other.map) {
      if (cmpComp(v, this.get(r)) > 0) this.map.set(r, [v[0], v[1]]);
    }
    return this;
  }

  /** True iff this dominates other (this >= other component-wise). */
  dominates(other) {
    for (const [r, v] of other.map) {
      if (cmpComp(this.get(r), v) < 0) return false;
    }
    return true;
  }

  equals(other) {
    return this.dominates(other) && other.dominates(this);
  }

  /**
   * Remove every component that is <= floor (i.e. globally acknowledged).
   * Returns the number of removed components.  This is the bounded-metadata
   * compaction primitive: only "exceptions" above the stable floor survive.
   */
  pruneBelow(floor) {
    let removed = 0;
    for (const [r, v] of [...this.map]) {
      if (cmpComp(floor.get(r), v) >= 0) {
        this.map.delete(r);
        removed++;
      }
    }
    return removed;
  }

  toJSON() {
    const out = {};
    for (const [r, v] of this.map) out[r] = [v[0], v[1]];
    return out;
  }
}

function keyOf(dot) {
  return `${dot.replica}@${dot.epoch}:${dot.seq}`;
}

class CausalCache {
  /**
   * @param {object} opts
   * @param {string} opts.replica  replica id of this tracker
   * @param {number} [opts.epoch]  initial incarnation / epoch
   */
  constructor(opts = {}) {
    this.replica = opts.replica || 'r0';
    this.epoch = opts.epoch || 0;
    this.local = new Clock();
    this.local.set(this.replica, [this.epoch, 0]);

    this.maxEpoch = new Map();          // replica -> highest incarnation observed
    this.maxEpoch.set(this.replica, this.epoch);

    this.entries = new Map();           // key -> { value, clock, dot, ts }
    this.frontier = new Map();          // key -> Clock of invalidations (tombstones)
    this.floor = new Clock();           // stable/GC watermark (anti-resurrection)
    this.pending = [];                  // out-of-order events (causal buffer)
    this.pendingKeys = new Set();
    this.lamport = opts.lamport || 0;   // causality-respecting LWW timestamp

    this.stats = {
      applied: 0,
      buffered: 0,
      deliveredFromBuffer: 0,
      droppedStaleEpoch: 0,
      droppedFloor: 0,
      droppedInvalidated: 0,
      evicted: 0,
      resurrectBlocked: 0,
      pruned: 0,
    };
  }

  // ---- local writes ------------------------------------------------------

  _nextDot() {
    const cur = this.local.get(this.replica);
    const seq = cur[1] + 1;
    this.local.set(this.replica, [this.epoch, seq]);
    this.lamport += 1;
    return { replica: this.replica, epoch: this.epoch, seq };
  }

  /**
   * A reset is an explicit new incarnation.  It durably bumps the epoch so
   * that every later write dominates all earlier writes of this replica and
   * every delayed pre-reset message is rejected.
   */
  reset() {
    this.epoch += 1;
    this.local.set(this.replica, [this.epoch, 0]);
    this.maxEpoch.set(this.replica, this.epoch);
    return this.epoch;
  }

  /** Produce a put event (also applied locally). */
  write(key, value) {
    const dot = this._nextDot();
    const clock = this.local.clone();
    const deps = clock.clone();
    deps.set(this.replica, dot.seq > 1 ? [this.epoch, dot.seq - 1] : [0, 0]);
    const ev = { type: 'put', key, value, dot, clock, deps, ts: this.lamport };
    this.receive(ev);
    return ev;
  }

  /** Produce a delete event (also applied locally). */
  remove(key) {
    const dot = this._nextDot();
    const clock = this.local.clone();
    const deps = clock.clone();
    deps.set(this.replica, dot.seq > 1 ? [this.epoch, dot.seq - 1] : [0, 0]);
    const ev = { type: 'del', key, dot, clock, deps, ts: this.lamport };
    this.receive(ev);
    return ev;
  }

  // ---- delivery ----------------------------------------------------------

  deliverable(ev) {
    // Every causal dependency (context before the write) must be observed.
    for (const [r, comp] of ev.deps.map) {
      if (cmpComp(this.local.get(r), comp) < 0) return false;
    }
    return true;
  }

  /** Is this exact dot already known to be superseded (pre-reset) ? */
  staleEpoch(dot) {
    const seen = this.maxEpoch.get(dot.replica);
    return seen !== undefined && dot.epoch < seen;
  }

  /** Reject a write whose dot is at or below the GC floor. */
  belowFloor(dot) {
    return cmpComp(this.floor.get(dot.replica), [dot.epoch, dot.seq]) >= 0;
  }

  /**
   * Deliver one event.  Returns one of:
   *   'applied' | 'buffered' | 'dropped-stale' | 'dropped-floor' |
   *   'dropped-invalidated'
   */
  receive(ev) {
    ev = normalizeEvent(ev);
    if (this.staleEpoch(ev.dot) || this.belowFloor(ev.dot)) {
      if (this.staleEpoch(ev.dot)) this.stats.droppedStaleEpoch++;
      else this.stats.droppedFloor++;
      return this.staleEpoch(ev.dot) ? 'dropped-stale' : 'dropped-floor';
    }
    if (!this.deliverable(ev)) {
      this.pending.push(ev);
      this.pendingKeys.add(ev.key);
      this.stats.buffered++;
      return 'buffered';
    }
    const res = this._commit(ev);
    this._drain();
    return res;
  }

  _commit(ev) {
    const r = ev.dot.replica;
    const seen = this.maxEpoch.get(r) || 0;
    if (ev.dot.epoch > seen) this.maxEpoch.set(r, ev.dot.epoch);

    // Observe the write in our own vector clock.
    this.local.merge(ev.clock);
    if (typeof ev.ts === 'number' && ev.ts > this.lamport) this.lamport = ev.ts;

    const applied = this._apply(ev);
    return applied;
  }

  _apply(ev) {
    const key = ev.key;
    if (ev.type === 'del') {
      let f = this.frontier.get(key);
      if (!f) {
        f = new Clock();
        this.frontier.set(key, f);
      }
      f.merge(ev.clock);
      this._evict(key);
      this.stats.applied++;
      return 'applied';
    }

    // PUT: reject only if the observed frontier (or the GC floor) provably
    // dominates it.  Otherwise add the version to the key's concurrent version
    // set, dropping any versions it causally supersedes.  Keeping concurrent
    // versions is what makes invalidation safe: a delete can remove one branch
    // without losing another branch that it does not dominate.
    const f = this.frontier.get(key);
    if (f && f.dominates(ev.clock)) {
      this.stats.droppedInvalidated++;
      this.stats.resurrectBlocked++;
      return 'dropped-invalidated';
    }

    let bucket = this.entries.get(key);
    if (!bucket) {
      bucket = new Map();
      this.entries.set(key, bucket);
    }
    const vid = keyOf(ev.dot);

    // Redundant if some retained version already causally dominates it.
    for (const v of bucket.values()) {
      if (v.clock.dominates(ev.clock)) {
        this.stats.applied++;
        return 'applied';
      }
    }

    bucket.set(vid, {
      value: ev.value,
      clock: ev.clock.clone(),
      dot: ev.dot,
      ts: ev.ts || 0,
      vid,
    });
    // Drop versions that this put supersedes (causally older).
    for (const [id, v] of [...bucket]) {
      if (id !== vid && ev.clock.dominates(v.clock)) bucket.delete(id);
    }
    this.stats.applied++;
    return 'applied';
  }

  /** Evict every version the frontier (or global floor) provably dominates. */
  _evict(key) {
    const bucket = this.entries.get(key);
    if (!bucket || bucket.size === 0) return false;
    const f = this.frontier.get(key);
    let removed = 0;
    for (const [id, v] of [...bucket]) {
      const dominated =
        (f && f.dominates(v.clock)) || this.floor.dominates(v.clock);
      if (dominated) {
        bucket.delete(id);
        removed++;
      }
    }
    if (removed && bucket.size === 0) this.entries.delete(key);
    this.stats.evicted += removed;
    return removed > 0;
  }

  _drain() {
    let progressed = true;
    while (progressed && this.pending.length) {
      progressed = false;
      const rest = [];
      for (const ev of this.pending) {
        if (this.staleEpoch(ev.dot) || this.belowFloor(ev.dot)) {
          this.stats.droppedStaleEpoch++;
          progressed = true;
          continue;
        }
        if (this.deliverable(ev)) {
          this._commit(ev);
          this.stats.deliveredFromBuffer++;
          progressed = true;
        } else {
          rest.push(ev);
        }
      }
      this.pending = rest;
    }
    if (!this.pending.length) this.pendingKeys.clear();
  }

  // ---- reads / external invalidation ------------------------------------

  get(key) {
    const bucket = this.entries.get(key);
    if (!bucket || bucket.size === 0) return undefined;
    let best = null;
    for (const v of bucket.values()) {
      if (!best) best = v;
      else if (v.ts !== best.ts ? v.ts > best.ts : cmpDot(v.dot, best.dot) > 0) best = v;
    }
    return best.value;
  }

  has(key) {
    const bucket = this.entries.get(key);
    return !!bucket && bucket.size > 0;
  }

  /**
   * Register an externally generated invalidation frontier for a key.  The
   * entry is evicted only if/when the merged frontier dominates its context.
   */
  invalidate(key, clock) {
    let f = this.frontier.get(key);
    if (!f) {
      f = new Clock();
      this.frontier.set(key, f);
    }
    f.merge(clock);
    this._evict(key);
  }

  // ---- stable watermark / bounded metadata compaction -------------------

  /**
   * Advance the globally acknowledged (stable) watermark.  Everything at or
   * below it may be forgotten: per-key frontiers are compacted to
   * "exceptions" above the floor, and the floor itself blocks delayed puts.
   */
  advanceStable(stableClock) {
    this.floor.merge(stableClock);
    let pruned = 0;
    for (const [key, f] of [...this.frontier]) {
      pruned += f.pruneBelow(this.floor);
      if (f.isEmpty()) this.frontier.delete(key);
    }
    // Evict anything the stable watermark already dominates.
    for (const key of [...this.entries.keys()]) this._evict(key);
    this.stats.pruned += pruned;
    return pruned;
  }

  /** Number of live per-replica components kept in metadata. */
  metadataSize() {
    let n = this.entries.size + this.floor.size() + this.maxEpoch.size;
    for (const bucket of this.entries.values()) n += bucket.size;
    for (const f of this.frontier.values()) n += f.size();
    return n;
  }

  // ---- snapshot / recovery ----------------------------------------------

  snapshot() {
    const entries = [];
    for (const [k, bucket] of this.entries) {
      for (const v of bucket.values()) {
        entries.push({ key: k, value: v.value, clock: v.clock.toJSON(), dot: v.dot, ts: v.ts });
      }
    }
    const frontier = [];
    for (const [k, f] of this.frontier) frontier.push({ key: k, clock: f.toJSON() });
    const pending = this.pending.map((ev) => ({
      type: ev.type,
      key: ev.key,
      value: ev.value,
      dot: ev.dot,
      ts: ev.ts,
      clock: ev.clock.toJSON(),
      deps: ev.deps.toJSON(),
    }));
    return {
      replica: this.replica,
      epoch: this.epoch,
      local: this.local.toJSON(),
      maxEpoch: [...this.maxEpoch.entries()],
      floor: this.floor.toJSON(),
      entries,
      frontier,
      pending,
      lamport: this.lamport,
    };
  }

  static restore(snap) {
    const c = new CausalCache({ replica: snap.replica, epoch: snap.epoch });
    c.local = Clock.fromJSON(snap.local);
    c.maxEpoch = new Map(snap.maxEpoch || []);
    c.floor = Clock.fromJSON(snap.floor);
    c.lamport = snap.lamport || 0;
    for (const e of snap.entries || []) {
      let bucket = c.entries.get(e.key);
      if (!bucket) {
        bucket = new Map();
        c.entries.set(e.key, bucket);
      }
      const vid = keyOf(e.dot);
      bucket.set(vid, { value: e.value, clock: Clock.fromJSON(e.clock), dot: e.dot, ts: e.ts || 0, vid });
    }
    for (const f of snap.frontier || []) {
      c.frontier.set(f.key, Clock.fromJSON(f.clock));
    }
    c.pending = (snap.pending || []).map((ev) => ({
      type: ev.type,
      key: ev.key,
      value: ev.value,
      dot: ev.dot,
      ts: ev.ts,
      clock: Clock.fromJSON(ev.clock),
      deps: Clock.fromJSON(ev.deps),
    }));
    return c;
  }
}

function cmpDot(a, b) {
  if (a.epoch !== b.epoch) return a.epoch < b.epoch ? -1 : 1;
  if (a.seq !== b.seq) return a.seq < b.seq ? -1 : 1;
  if (a.replica === b.replica) return 0;
  return a.replica < b.replica ? -1 : 1;
}

function normalizeEvent(ev) {
  if (ev.clock instanceof Clock && ev.deps instanceof Clock) return ev;
  return {
    type: ev.type,
    key: ev.key,
    value: ev.value,
    dot: ev.dot,
    ts: ev.ts,
    clock: ev.clock instanceof Clock ? ev.clock : Clock.fromJSON(ev.clock),
    deps: ev.deps instanceof Clock ? ev.deps : Clock.fromJSON(ev.deps),
  };
}

function cmpClock(a, b) {
  if (a.dominates(b)) return b.dominates(a) ? 0 : 1;
  if (b.dominates(a)) return -1;
  return null; // concurrent
}

module.exports = { CausalCache, Clock, cmpComp, cmpClock, cmpDot, ZERO };

const assert = require('assert');
const { CausalCache, Clock, cmpComp, cmpClock } = require('./causal-cache');

let passed = 0;
function test(name, fn) {

    fn();
    passed++;

  }

// Round-trip an event over a "wire" so caches never share mutable clocks.
function wire(ev) {
  return {
    type: ev.type,
    key: ev.key,
    value: ev.value,
    dot: ev.dot,
    ts: ev.ts,
    clock: ev.clock.toJSON(),
    deps: ev.deps.toJSON(),
  };
}

console.log('clock algebra');
test('dominance is component-wise', () => {
  const a = Clock.fromJSON({ x: [0, 3], y: [0, 1] });
  const b = Clock.fromJSON({ x: [0, 2], y: [0, 1] });
  assert.strictEqual(a.dominates(b), true);
  assert.strictEqual(b.dominates(a), false);
  const c = Clock.fromJSON({ x: [0, 5] });
  assert.strictEqual(a.dominates(c), false);
  assert.strictEqual(c.dominates(a), false);
});

test('epoch dominates older incarnation regardless of seq', () => {
  const old = Clock.fromJSON({ r: [0, 999] });
  const neu = Clock.fromJSON({ r: [1, 1] });
  assert.strictEqual(neu.dominates(old), true);
  assert.strictEqual(old.dominates(neu), false);
});

test('merge is pointwise max and commutative', () => {
  const a = Clock.fromJSON({ x: [0, 3], y: [0, 1] });
  const b = Clock.fromJSON({ x: [0, 2], y: [0, 4], z: [0, 1] });
  const m1 = a.clone().merge(b);
  const m2 = b.clone().merge(a);
  assert.deepStrictEqual(m1.toJSON(), m2.toJSON());
  assert.deepStrictEqual(m1.toJSON(), { x: [0, 3], y: [0, 4], z: [0, 1] });

test('put/get/remove on a single replica', () => {

  assert.strictEqual(c.get('k'), 1);
  c.write('k', 2);
  assert.strictEqual(c.get('k'), 2);

  const c = new CausalCache({ replica: 'a' });

console.log('out-of-order delivery');
test('causally later put is buffered until its dependency arrives', () => {
  const a = new CausalCache({ replica: 'a' });

  const e2 = a.write('k', 2);

2.3 fuzz.js (adversarial differential test vs. an independent oracle)

'use strict';

/*
 * Adversarial randomized verification for CausalCache.
 *
 * Independently computes the intended final state (an oracle) and checks that
 * many trackers -- fed every event in a different random order, with duplicate
 * deliveries, a mid-stream snapshot/restore, and sparse replica participation
 * -- all converge to exactly that state.
 *
 * Oracle for a key:
 *   frontier = join of every delete's context
 *   survivors = puts whose context is NOT dominated by frontier
 *   value = survivor with the greatest (ts, replica)  [LWW]
 */

const assert = require('assert');
const { CausalCache, Clock, cmpDot } = require('./causal-cache');

function mulberry32(seed) {
  return function () {
    seed |= 0;
    seed = (seed + 0x6d2b79f5) | 0;
    let t = Math.imul(seed ^ (seed >>> 15), 1 | seed);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

function wire(ev) {
  return {
    type: ev.type,
    key: ev.key,
    value: ev.value,
    dot: ev.dot,
    ts: ev.ts,
    clock: ev.clock.toJSON(),
    deps: ev.deps.toJSON(),
  };
}

function shuffle(arr, rand) {
  const a = arr.slice();
  for (let i = a.length - 1; i > 0; i--) {
    const j = Math.floor(rand() * (i + 1));
    [a[i], a[j]] = [a[j], a[i]];
  }
  return a;
}

function oracle(events, floorClock) {
  const frontier = new Map(); // key -> Clock
  const best = new Map(); // key -> {value, clock, dot, ts}
  for (const ev of events) {
    let f = frontier.get(ev.key);
    if (!f) {
      f = new Clock();
      frontier.set(ev.key, f);
    }
    if (ev.type === 'del') f.merge(ev.clock);
  }
  for (const ev of events) {
    if (ev.type !== 'put') continue;
    const f = frontier.get(ev.key);
    if (f && f.dominates(ev.clock)) continue; // stale / invalidated
    if (floorClock && floorClock.dominates(ev.clock)) continue; // GC'd
    const cur = best.get(ev.key);
    if (!cur) {
      best.set(ev.key, { value: ev.value, clock: ev.clock, dot: ev.dot, ts: ev.ts });
    } else if (ev.ts !== cur.ts ? ev.ts > cur.ts : cmpDot(ev.dot, cur.dot) > 0) {
      best.set(ev.key, { value: ev.value, clock: ev.clock, dot: ev.dot, ts: ev.ts });
    }
  }
  const out = new Map();
  for (const [k, v] of best) out.set(k, v.value);
  return out;
}

function run(seed) {
  const rand = mulberry32(seed);
  const R = 8;
  const K = 60;
  const M = 4000;
  const replicas = [];
  for (let i = 0; i < R; i++) replicas.push(new CausalCache({ replica: 'r' + i }));

  // Sparse, skewed participation: most writes come from a few hot replicas.
  const hot = [0, 1, 2];
  const events = [];
  for (let i = 0; i < M; i++) {
    const r = rand() < 0.8 ? hot[Math.floor(rand() * hot.length)] : Math.floor(rand() * R);
    const key = 'k' + Math.floor(rand() * K);
    if (rand() < 0.25) events.push(replicas[r].remove(key));
    else events.push(replicas[r].write(key, `${r}:${i}`));
  }

  const expected = oracle(events);

  // Feed every tracker a different permutation, with duplicates.
  for (let t = 0; t < 5; t++) {
    const tracker = new CausalCache({ replica: 'tracker' + t });
    const order = shuffle(events, rand);
    // Inject duplicates of a random subset (idempotence / no resurrection).
    const feed = order.concat(shuffle(order, rand).slice(0, Math.floor(order.length / 5)));
    for (let i = 0; i < feed.length; i++) {
      tracker.receive(wire(feed[i]));
      if (t === 0 && i === Math.floor(feed.length / 2)) {
        // Mid-stream recovery must not perturb the result.
        const restored = CausalCache.restore(JSON.parse(JSON.stringify(tracker.snapshot())));
        tracker.entries = restored.entries;
        tracker.frontier = restored.frontier;
        tracker.floor = restored.floor;
        tracker.local = restored.local;
        tracker.maxEpoch = restored.maxEpoch;
        tracker.pending = restored.pending;
      }
    }
    assert.strictEqual(tracker.pending.length, 0, `seed ${seed} t=${t}: undelivered events`);

    for (let k = 0; k < K; k++) {
      const key = 'k' + k;
      const got = tracker.get(key);
      const want = expected.get(key);
      assert.strictEqual(
        got,
        want,
        `seed ${seed} tracker ${t} key ${key}: got ${got} want ${want}`
      );
    }
  }
  return { events: events.length, keys: K };
}

let total = 0;
for (let seed = 1; seed <= 25; seed++) {
  const r = run(seed);
  total += r.events;
}
console.log(`fuzz: 25 seeds OK, ${total} events compared against independent oracle`);

// ---------------------------------------------------------------------------
// Compaction + replay scenario: after full delivery, advance a stable floor,
// let the tracker prune metadata and evict dominated versions, then replay
// every event.  The floor must block stale replays and all trackers must still
// agree with the floor-aware oracle.  Metadata must shrink back to a bound.
// ---------------------------------------------------------------------------
function runCompaction(seed) {
  const rand = mulberry32(seed ^ 0x9e3779b9);
  const R = 8;
  const K = 40;
  const M = 3000;
  const replicas = [];
  for (let i = 0; i < R; i++) replicas.push(new CausalCache({ replica: 'r' + i }));
  const events = [];
  for (let i = 0; i < M; i++) {
    const r = Math.floor(rand() * R);
    const key = 'k' + Math.floor(rand() * K);
    if (rand() < 0.2) events.push(replicas[r].remove(key));
    else events.push(replicas[r].write(key, `${r}:${i}`));
  }

  // A legitimate global stable frontier: merge of the first half of events.
  const floor = new Clock();
  for (let i = 0; i < Math.floor(M / 2); i++) floor.merge(events[i].clock);
  const expected = oracle(events, floor);

  const trackers = [];
  for (let t = 0; t < 4; t++) {
    const tracker = new CausalCache({ replica: 'tracker' + t });
    for (const ev of shuffle(events, rand)) tracker.receive(wire(ev));
    trackers.push(tracker);
  }

  // Compact, then replay every event (including stale pre-floor ones).
  for (const tracker of trackers) {
    tracker.advanceStable(floor);
    for (const ev of shuffle(events, rand)) tracker.receive(wire(ev));
    assert.strictEqual(tracker.pending.length, 0);
    for (let k = 0; k < K; k++) {
      const key = 'k' + k;
      assert.strictEqual(
        tracker.get(key),
        expected.get(key),
        `seed ${seed} compaction key ${key}: ${tracker.get(key)} != ${expected.get(key)}`
      );
    }
  }

  // Metadata must be bounded by the live exceptions above the floor.
  for (const tracker of trackers) {
    assert.ok(
      tracker.metadataSize() <= 3 * R * K + 128,
      `metadata too large: ${tracker.metadataSize()}`
    );
  }
  return { events: M, keys: K };
}

let ctotal = 0;
for (let seed = 1; seed <= 10; seed++) ctotal += runCompaction(seed).events;
console.log(`compaction+replay: 10 seeds OK, ${ctotal} events checked`);

4. What was fixed, in one paragraph

Causal delivery is buffered until deps are observed; invalidation evicts a version only when the merged frontier (or the GC floor) dominates its context; concurrent versions are retained as an MV-register and reduced by (Lamport ts, replica) so delivery order cannot change the result; per-replica epochs make resets monotonic and reject delayed pre-reset messages; and a globally stable floor compacts frontiers to exceptions and blocks replay of garbage-collected writes. Snapshots carry the floor, frontier and pending buffer, so recovery cannot resurrect stale values.

5. Complexity

  • receive: O(V) to test dominance / merge, V = live replicas, plus amortised drain of the causal buffer.
  • Storage per key: O(number of concurrent versions), bounded by V and collapsed to O(live exceptions) by advanceStable.
  • Global metadata after compaction: O(V · live keys with exceptions), not O(total keys) and not O(total history).
