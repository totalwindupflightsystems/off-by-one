Crash-Safe Lease-Read Fence for a Sharded Go Service

Problem class: go-lease-read-fence-recovery-20261102 Environment: Go 1.26 (go1.26.8 linux/amd64)

1. Symptom

A sharded service uses one Raft-style group per shard. To avoid a network round trip per read, the leader serves linearizable reads locally while it believes it holds a lease. Under lease expiry, renewal, clock jumps, quorum loss, leader transfer, and process restart, stale replicas nonetheless acknowledge reads. The observed failures are:

  • a read answered by an old leader after a new leader was elected;
  • two leaders answering reads in the same interval;
  • a restarted replica resuming reads from before its crash;
  • a lease that never expires (or expires instantly) after an NTP step.

2. Root-cause analysis

A time-based read lease is sound only if it is fenced against all of the following. Each is an independent, independently-exploitable root cause.

RC1 — Wall-clock lease arithmetic

Computing the deadline with time.Now().UnixNano() (or comparing wall-clock timestamps) makes the lease vulnerable to NTP steps, suspend/resume, VM migration, and manual clock changes. A backwards jump makes a lease live forever and permits overlapping leaders; a forwards jump expires a valid lease and causes spurious quorum stalls. Fix: all lease arithmetic uses a monotonic clock. The code exposes Mono int64 and never reads a wall clock, so a wall jump is unobservable.

RC2 — Missing vote fence (the classic two-leaders bug)

If followers grant votes based only on "log is at least as up to date" and "have not voted this term", a candidate that timed out in a partition can be elected by a quorum that is still receiving heartbeats from the old leader: the old leader still holds a valid lease, yet a second leader exists. Fix: a follower records the last heartbeat it accepted from a legitimate leader and refuses to grant a vote for ElectionTimeout. Combined with LeaseDuration + MaxClockDrift < ElectionTimeout, no election can succeed while any previously issued lease can still be valid. Quorum intersection then guarantees at most one valid lease.

RC3 — Out-of-order / delayed lease acknowledgements

A heartbeat ack delayed beyond its round can be counted toward a later round and wrongly re-arm the lease; a stale ack can also complete a quorum the current round never obtained. Fix: every heartbeat round carries a fresh, strictly monotonic fencing epoch (epoch = term << 20 | round). A follower persists its highest observed epoch (fsync) before acknowledging. The leader counts only acks whose epoch equals the current round and grants at most once per round.

RC4 — Lease not tied to leadership and the term barrier

Serving as soon as a leader is elected can return state that has not applied entries committed before its term; and after a step-down or voluntary transfer the old leader's in-memory lease must die immediately. Fix: a read additionally requires the per-term leadership barrier to be committed and applied by a quorum; stepDownLocked clears the lease; TransferTo steps down before sending TimeoutNow.

RC5 — Lease / epoch state surviving a restart

If lease validity were persisted, a restarted node could resume serving. If the fencing epoch were not durable, a restart could replay an already-seen epoch. Fix: lease validity is volatile and always re-acquired after restart; only term, votedFor, highestEpoch are persisted, written with write-temp → fsync → rename → fsync(dir) before any vote or ack is emitted.

Why the naive "just check the clock" version fails

Fixing only RC1 still leaves the two-leaders window (RC2). Fixing RC2 still lets a delayed ack extend a lease across rounds (RC3). Fixing RC3 still serves un-applied state after a transfer (RC4). Fixing RC4 still lets a restarted node resume (RC5). The fix must address all five, each with a test that fails when only that one is reverted.

3. Safety model

Let quorum = floor((N+1)/2) + 1. A node serves a read only if all hold:

  1. role == Leader;
  2. it has applied its term's leadership barrier, confirmed by a quorum (ready and applied >= commit);
  3. it holds a lease whose epoch was acknowledged by a quorum in the current round;
  4. clock.Now() < leaseExpiry on the monotonic timeline.

Claim (single read leader). At any instant, at most one node satisfies the read gate.

Proof sketch. Suppose leaders L1 (lease e1, expiring at t1) and L2 (e2 > e1) both satisfy the gate at time t. L2's lease was completed by a quorum Q2 of acks; let F ∈ Q2 be the follower whose ack completed it. F persisted e2 and set lastHeartbeat = tF at or before the ack, so F refuses votes until tF + ElectionTimeout. L1's lease is valid only while t < t1, and by RC2 t1 < tF + ElectionTimeout (with clock drift), so F refuses to help elect L2 until after t1. But L2 needed a quorum intersecting Q2, hence F's refusal makes L2's election impossible before t1. Contradiction. ∎

A read mints ReadFence{Shard, Term, Epoch}. Downstream shards validate with FenceValidator.Accept, which rejects any epoch <= the highest accepted, so a stale replica can never overwrite a newer fence.

Module example.com/leasefence, no third-party dependencies.

// Package leasefence implements a crash-safe, lease-based read fence for a
// sharded Raft-style replicated service.
//
// The package models the minimum of a Raft group needed to make the
// lease-read optimization safe: election terms, votes, heartbeats and a
// per-term leadership barrier. The safety of a local read is carried by three
// invariants:
//
//  1. Read gate. A read is served only by a node that is currently leader,
//     has applied its term's leadership barrier, and holds a lease that was
//     granted by a quorum and has not expired on a *monotonic* clock.
//
//  2. Vote fence. A follower refuses to grant a vote within ElectionTimeout
//     of the last heartbeat it accepted from a legitimate leader. Because
//     LeaseDuration+MaxClockDrift < ElectionTimeout, no new leader can be
//     elected while any previously issued lease can still be valid. This is
//     what makes it impossible for two nodes to serve reads in the same
//     window.
//
//  3. Fencing epoch. Every lease carries a strictly monotonic epoch that a
//     follower must persist (fsync) *before* it acknowledges the lease.
//     Out-of-order, duplicated or replayed lease messages carry an epoch that
//     is <= the highest persisted epoch and are rejected. A restarted node
//     therefore can never acknowledge an epoch it has already superseded.
//
// Wall-clock jumps are irrelevant by construction: the package never reads a
// wall clock. All time arithmetic flows through Clock, whose contract is a
// monotonic nanosecond timeline.
package leasefence

import (
    "errors"
    "fmt"
    "sync"
)

// Term is a monotonically increasing election term (a Raft term).
type Term uint64

// Epoch is a fencing epoch. Epochs are globally monotonically increasing:
// leaseEpochFor encodes the term in the high bits so that a lease from a
// later term always dominates any lease from an earlier term, and the round
// in the low bits so that a late acknowledgement of an earlier heartbeat
// cannot extend the current lease.
type Epoch uint64

const roundBits = 20
const roundMask = (uint64(1) << roundBits) - 1

func leaseEpochFor(term Term, round uint64) Epoch {
    if round > roundMask {
        panic("leasefence: heartbeat round overflow")
    }
    return Epoch(uint64(term)<<roundBits | round)
}

// Mono is a point on a monotonic timeline. It is deliberately not a
// time.Time: nothing in this package may consult a wall clock.
type Mono int64

// Clock is the only time source used by the lease logic. Implementations MUST
// be monotonic and MUST NOT jump because of NTP, suspend/resume or operator
// changes to the system clock.
type Clock interface {
    Now() Mono
}

// Config holds the lease/election tunables.
type Config struct {
    // LeaseDuration is how long a quorum-granted lease is valid.
    LeaseDuration Mono
    // ElectionTimeout is the minimum time a follower that heard from a
    // leader will refuse to grant a vote.
    ElectionTimeout Mono
    // MaxClockDrift is the assumed upper bound on relative clock drift
    // between any two nodes over one lease interval.
    MaxClockDrift Mono
}

func (c Config) validate() error {
    if c.LeaseDuration <= 0 {
        return errors.New("leasefence: LeaseDuration must be > 0")
    }
    if c.ElectionTimeout <= 0 {
        return errors.New("leasefence: ElectionTimeout must be > 0")
    }
    if c.LeaseDuration+c.MaxClockDrift >= c.ElectionTimeout {
        return fmt.Errorf(
            "leasefence: unsafe lease: LeaseDuration(%d)+MaxClockDrift(%d) must be < ElectionTimeout(%d)",
            c.LeaseDuration, c.MaxClockDrift, c.ElectionTimeout)
    }
    return nil
}

// Role is a replica role.
type Role uint8

const (
    Follower Role = iota
    Candidate
    Leader
)

func (r Role) String() string {
    switch r {
    case Follower:
        return "follower"
    case Candidate:
        return "candidate"
    case Leader:
        return "leader"
    default:
        return "unknown"
    }
}

// MsgType enumerates the wire messages.
type MsgType uint8

const (
    MsgVoteReq MsgType = iota
    MsgVoteResp
    MsgHeartbeat
    MsgHeartbeatResp
    MsgTimeoutNow
)

func (t MsgType) String() string {
    switch t {
    case MsgVoteReq:
        return "VoteReq"
    case MsgVoteResp:
        return "VoteResp"
    case MsgHeartbeat:
        return "Heartbeat"
    case MsgHeartbeatResp:
        return "HeartbeatResp"
    case MsgTimeoutNow:
        return "TimeoutNow"
    default:
        return "?"
    }
}

// Message is a single RPC. It is a value type so that the deterministic
// simulator used by the tests can hold, delay and reorder messages freely.
type Message struct {
    From    string
    To      string
    Type    MsgType
    Term    Term
    Epoch   Epoch
    Success bool

    // VoteReq / VoteResp
    Candidate string
    Granted   bool

    // Heartbeat / HeartbeatResp
    Barrier uint64 // leadership barrier index carried by the leader
    Match   uint64 // highest barrier index the follower has observed
}

// DurableState is the small amount of state that must survive a crash before
// the node acts on it. Save must be durable (fsync/rename) before returning.
type DurableState struct {
    Term         Term
    VotedFor     string
    HighestEpoch Epoch
}

// Store persists DurableState crash-safely.
type Store interface {
    Load() (DurableState, error)
    Save(DurableState) error
}

// ReadFence is the token minted for a linearizable read. Shard plus the
// monotonic epoch let a downstream shard or client reject anything minted by a
// stale replica.
type ReadFence struct {
    Shard string
    Term  Term
    Epoch Epoch
}

// Replica is one member of a single shard's Raft group.
type Replica struct {
    id    string
    shard string
    peers []string
    cfg   Config
    clock Clock
    store Store

    mu sync.Mutex

    // Durable state (mirrored in the Store).
    term         Term
    votedFor     string
    highestEpoch Epoch

    // Volatile state.
    role          Role
    leader        string
    votes         map[string]bool
    heardLeader   bool
    lastHeartbeat Mono

    // Leader-only lease acquisition for the current round.
    round        uint64
    pendingEpoch Epoch
    pendingAcks  map[string]Epoch
    pendingDone  bool
    leaseEpoch   Epoch
    leaseExpiry  Mono

    // Per-term leadership barrier.
    barrier     uint64
    barrierTerm Term
    match       map[string]uint64
    commit      uint64
    applied     uint64
    ready       bool
}

// New constructs a replica. All time flows through clock and all durable
// state through store.
func New(id, shard string, peers []string, cfg Config, clock Clock, store Store) (*Replica, error) {
    if err := cfg.validate(); err != nil {
        return nil, err
    }
    if clock == nil {
        return nil, errors.New("leasefence: nil clock")
    }
    if store == nil {
        return nil, errors.New("leasefence: nil store")
    }
    st, err := store.Load()
    if err != nil {
        return nil, err
    }
    return &Replica{
        id: id, shard: shard, peers: append([]string(nil), peers...),
        cfg: cfg, clock: clock, store: store,
        term:         st.Term,
        votedFor:     st.VotedFor,
        highestEpoch: st.HighestEpoch,
        role:         Follower,
        votes:        map[string]bool{},
        pendingAcks:  map[string]Epoch{},
        match:        map[string]uint64{},
    }, nil
}

func (r *Replica) ID() string      { return r.id }
func (r *Replica) Shard() string   { return r.shard }
func (r *Replica) quorumSize() int { return (len(r.peers)+1)/2 + 1 }

// persistLocked writes durable state while r.mu is held.
func (r *Replica) persistLocked() error {
    return r.store.Save(DurableState{
        Term:         r.term,
        VotedFor:     r.votedFor,
        HighestEpoch: r.highestEpoch,
    })
}

// stepDownLocked abandons leadership. It is deliberately conservative: any
// lease the node held is invalidated immediately, before it can answer
// another read. The higher term (if any) is durable as soon as the caller
// persists.
func (r *Replica) stepDownLocked(newTerm Term) {
    if newTerm > r.term {
        r.term = newTerm
        r.votedFor = ""
    }
    r.role = Follower
    r.leader = ""
    r.ready = false
    r.leaseEpoch = 0
    r.leaseExpiry = 0
    r.pendingEpoch = 0
    r.pendingDone = false
    r.pendingAcks = map[string]Epoch{}
}

// campaignLocked transitions to candidate and returns vote requests. The
// candidate votes for itself; self is counted in r.votes.
func (r *Replica) campaignLocked() ([]Message, error) {
    r.term++
    r.votedFor = r.id
    r.role = Candidate
    r.leader = ""
    r.ready = false
    r.leaseEpoch = 0
    r.leaseExpiry = 0
    r.votes = map[string]bool{r.id: true}
    if err := r.persistLocked(); err != nil {
        return nil, err
    }
    out := make([]Message, 0, len(r.peers))
    for _, p := range r.peers {
        out = append(out, Message{
            From: r.id, To: p, Type: MsgVoteReq, Term: r.term, Candidate: r.id,
        })
    }
    return out, nil
}

// Campaign starts an election (used by tests and by an election timer).
func (r *Replica) Campaign() ([]Message, error) {
    r.mu.Lock()
    defer r.mu.Unlock()
    return r.campaignLocked()
}

func (r *Replica) becomeLeaderLocked() {
    r.role = Leader
    r.leader = r.id
    r.ready = false
    r.round = 0
    r.match = map[string]uint64{}
    r.barrier = r.applied + 1
    r.barrierTerm = r.term
}

// beginHeartbeatLocked opens a new lease-granting round. A new epoch is used
// for every round so that a delayed acknowledgement from an earlier round
// cannot be mistaken for an acknowledgement of the current round.
func (r *Replica) beginHeartbeatLocked() ([]Message, error) {
    r.round++
    r.pendingEpoch = leaseEpochFor(r.term, r.round)
    r.pendingAcks = map[string]Epoch{}
    r.pendingDone = false
    out := make([]Message, 0, len(r.peers))
    for _, p := range r.peers {
        out = append(out, Message{
            From: r.id, To: p, Type: MsgHeartbeat,
            Term: r.term, Epoch: r.pendingEpoch, Barrier: r.barrier,
        })
    }
    return out, nil
}

// Heartbeat opens a fresh lease-granting round. The caller delivers the
// returned messages and feeds the responses back through Step.
func (r *Replica) Heartbeat() ([]Message, error) {
    r.mu.Lock()
    defer r.mu.Unlock()
    if r.role != Leader {
        return nil, nil
    }
    return r.beginHeartbeatLocked()
}

// Step applies one inbound message and returns the outbound messages it
// produces. Persistence failures are returned so the caller can stop.
func (r *Replica) Step(m Message) ([]Message, error) {
    r.mu.Lock()
    defer r.mu.Unlock()

    switch m.Type {
    case MsgVoteReq:
        return r.handleVoteReq(m)
    case MsgVoteResp:
        return r.handleVoteResp(m)
    case MsgHeartbeat:
        return r.handleHeartbeat(m)
    case MsgHeartbeatResp:
        return r.handleHeartbeatResp(m)
    case MsgTimeoutNow:
        return r.handleTimeoutNow(m)
    default:
        return nil, nil
    }
}

func (r *Replica) handleVoteReq(m Message) ([]Message, error) {
    resp := Message{From: r.id, To: m.From, Type: MsgVoteResp}
    if m.Term < r.term {
        resp.Term = r.term
        return []Message{resp}, nil
    }
    if m.Term > r.term {
        r.stepDownLocked(m.Term)
        if err := r.persistLocked(); err != nil {
            return nil, err
        }
    }
    resp.Term = r.term

    canGrant := m.Candidate != "" && (r.votedFor == "" || r.votedFor == m.Candidate)

    // Invariant 2: the vote fence. While the follower is inside the leader's
    // election window it refuses to help elect anyone, even at a higher
    // term. Without this, a candidate could be elected while the old
    // leader's lease is still valid, and two leaders could both answer
    // reads.
    if canGrant && r.heardLeader {
        if r.clock.Now()-r.lastHeartbeat < r.cfg.ElectionTimeout {
            canGrant = false
        }
    }

    if canGrant {
        r.votedFor = m.Candidate
        resp.Granted = true
        if err := r.persistLocked(); err != nil {
            return nil, err
        }
    }
    return []Message{resp}, nil
}

func (r *Replica) handleVoteResp(m Message) ([]Message, error) {
    if r.role != Candidate || m.Term != r.term {
        return nil, nil
    }
    if m.Term > r.term {
        r.stepDownLocked(m.Term)
        if err := r.persistLocked(); err != nil {
            return nil, err
        }
        return nil, nil
    }
    if !m.Granted {
        return nil, nil
    }
    r.votes[m.From] = true
    if len(r.votes) < r.quorumSize() {
        return nil, nil
    }
    r.becomeLeaderLocked()
    return r.beginHeartbeatLocked()
}

func (r *Replica) handleHeartbeat(m Message) ([]Message, error) {
    resp := Message{From: r.id, To: m.From, Type: MsgHeartbeatResp}
    if m.Term < r.term {
        resp.Term = r.term
        return []Message{resp}, nil
    }
    if m.Term > r.term {
        r.stepDownLocked(m.Term)
        if err := r.persistLocked(); err != nil {
            return nil, err
        }
    }
    // Accept the leader for this term.
    r.role = Follower
    r.leader = m.From
    r.heardLeader = true
    r.lastHeartbeat = r.clock.Now()

    // Invariant 3: persist a higher epoch before acknowledging it. If the
    // save fails we must not emit an ack, otherwise a crash could forget the
    // epoch and later replay it.
    if m.Epoch > r.highestEpoch {
        r.highestEpoch = m.Epoch
        if err := r.persistLocked(); err != nil {
            return nil, err
        }
    }
    resp.Term = r.term
    resp.Epoch = r.highestEpoch // echo the highest epoch we have fenced
    resp.Success = true
    resp.Match = m.Barrier
    return []Message{resp}, nil
}

func (r *Replica) handleHeartbeatResp(m Message) ([]Message, error) {
    if r.role != Leader || m.Term != r.term || !m.Success {
        return nil, nil
    }

    // Leadership barrier: quorum of followers have observed this term's
    // barrier, so it is safe to serve reads from applied state.
    if m.Match > r.match[m.From] {
        r.match[m.From] = m.Match
    }
    if !r.ready && r.barrier != 0 && r.quorumMatchLocked() >= r.quorumSize() {
        r.commit = r.barrier
        if r.applied < r.commit {
            r.applied = r.commit
        }
        r.ready = true
    }

    // Lease grant: only acknowledgements carrying the *current* round's
    // epoch count, and only until the round is granted. A later duplicate or
    // a response delayed across rounds must not extend the lease.
    if !r.pendingDone && r.pendingEpoch != 0 && m.Epoch == r.pendingEpoch {
        r.pendingAcks[m.From] = m.Epoch
        if len(r.pendingAcks)+1 >= r.quorumSize() {
            r.leaseEpoch = r.pendingEpoch
            r.leaseExpiry = r.clock.Now() + r.cfg.LeaseDuration
            r.pendingDone = true
        }
    }
    return nil, nil
}

func (r *Replica) quorumMatchLocked() int {
    n := 1 // the leader itself has the barrier
    for _, idx := range r.match {
        if idx >= r.barrier {
            n++
        }
    }
    return n
}

func (r *Replica) handleTimeoutNow(m Message) ([]Message, error) {
    if m.Term < r.term {
        return nil, nil
    }
    if m.Term > r.term {
        r.stepDownLocked(m.Term)
        if err := r.persistLocked(); err != nil {
            return nil, err
        }
    }
    return r.campaignLocked()
}

// readAllowedLocked is the read gate (invariant 1).
func (r *Replica) readAllowedLocked() bool {
    if r.role != Leader {
        return false
    }
    if !r.ready {
        return false
    }
    if r.applied < r.commit {
        return false
    }
    if r.leaseEpoch == 0 {
        return false
    }
    if r.clock.Now() >= r.leaseExpiry {
        return false
    }
    return true
}

// Read mints a fence for a linearizable read, or reports that the local
// replica is not allowed to answer.
func (r *Replica) Read() (ReadFence, bool) {
    r.mu.Lock()
    defer r.mu.Unlock()
    if !r.readAllowedLocked() {
        return ReadFence{}, false
    }
    return ReadFence{Shard: r.shard, Term: r.term, Epoch: r.leaseEpoch}, true
}

// LeaseStatus exposes the current lease for tests and introspection.
func (r *Replica) LeaseStatus() (epoch Epoch, expiry Mono, ok bool) {
    r.mu.Lock()
    defer r.mu.Unlock()
    return r.leaseEpoch, r.leaseExpiry, r.readAllowedLocked()
}

// Role returns the current role.
func (r *Replica) Role() Role {
    r.mu.Lock()
    defer r.mu.Unlock()
    return r.role
}

// HighestEpoch returns the persisted fencing epoch.
func (r *Replica) HighestEpoch() Epoch {
    r.mu.Lock()
    defer r.mu.Unlock()
    return r.highestEpoch
}

// TransferTo initiates a leadership transfer. The old leader steps down
// *before* the message is sent, so it can never answer another read even if
// its wall-clock lease would otherwise still be running.
func (r *Replica) TransferTo(target string) ([]Message, error) {
    r.mu.Lock()
    defer r.mu.Unlock()
    if r.role != Leader {
        return nil, nil
    }
    term := r.term
    r.stepDownLocked(term) // same term, conservative immediate invalidation
    return []Message{{
        From: r.id, To: target, Type: MsgTimeoutNow, Term: term,
    }}, nil
}

// FenceValidator rejects read fences minted by stale replicas. A downstream
// shard keeps one per (client, shard) or globally per shard.
type FenceValidator struct {
    mu      sync.Mutex
    highest Epoch
    term    Term
    shard   string
}

// NewFenceValidator returns a validator for a shard.
func NewFenceValidator(shard string) *FenceValidator {
    return &FenceValidator{shard: shard}
}

// Accept records a fence and reports whether it is fresh. A fence is fresh
// only if it is for the right shard and its epoch is strictly greater than
// every epoch accepted before. This is what stops a stale replica from
// acknowledging a read after a newer lease exists.
func (v *FenceValidator) Accept(f ReadFence) bool {
    v.mu.Lock()
    defer v.mu.Unlock()
    if v.shard != "" && f.Shard != v.shard {
        return false
    }
    if f.Term < v.term {
        return false
    }
    if f.Epoch <= v.highest {
        return false
    }
    v.highest = f.Epoch
    v.term = f.Term
    return true
}

// Highest returns the highest accepted epoch.
func (v *FenceValidator) Highest() Epoch {
    v.mu.Lock()
    defer v.mu.Unlock()
    return v.highest
}

package leasefence

import (
    "encoding/json"
    "errors"
    "os"
)

// FileStore is a crash-safe file-backed Store. Save writes a temporary file,
// fsyncs it, then atomically renames it over the target and fsyncs the
// directory, so a crash either leaves the old state or the new state, never a
// torn write.
type FileStore struct {
    path string
}

// NewFileStore returns a store backed by path.
func NewFileStore(path string) *FileStore { return &FileStore{path: path} }

// Load reads durable state, returning a zero state when the file is absent.
func (f *FileStore) Load() (DurableState, error) {
    b, err := os.ReadFile(f.path)
    if errors.Is(err, os.ErrNotExist) {
        return DurableState{}, nil
    }
    if err != nil {
        return DurableState{}, err
    }
    var s DurableState
    if err := json.Unmarshal(b, &s); err != nil {
        return DurableState{}, err
    }
    return s, nil
}

// Save durably writes state.
func (f *FileStore) Save(s DurableState) error {
    b, err := json.Marshal(s)
    if err != nil {
        return err
    }
    tmp := f.path + ".tmp"
    fd, err := os.OpenFile(tmp, os.O_CREATE|os.O_WRONLY|os.O_TRUNC, 0o600)
    if err != nil {
        return err
    }
    if _, err := fd.Write(b); err != nil {
        _ = fd.Close()
        return err
    }
    if err := fd.Sync(); err != nil {
        _ = fd.Close()
        return err
    }
    if err := fd.Close(); err != nil {
        return err
    }
    if err := os.Rename(tmp, f.path); err != nil {
        return err
    }
    // fsync the directory so the rename itself is durable.
    dir, err := os.Open(dirOf(f.path))
    if err != nil {
        return err
    }
    defer dir.Close()
    return dir.Sync()
}

func dirOf(p string) string {
    for i := len(p) - 1; i >= 0; i-- {
        if p[i] == '/' {
            if i == 0 {
                return "/"
            }
            return p[:i]
        }
    }
    return "."
}

6. Applying it to a real service

  1. Replace wall-clock deadlines with a monotonic clock (time.Since on a process-start time.Time is monotonic in Go; or use a Mono type as here).
  2. Persist (term, votedFor, highestEpoch) through an fsync+rename Store before sending a vote or a lease ack.
  3. Gate the read handler on Read() and attach the returned ReadFence to the response; validate it on downstream shards with FenceValidator.
  4. Enforce LeaseDuration + MaxClockDrift < ElectionTimeout at startup.
  5. On restart, always start as Follower with no lease and re-acquire.
  6. On stepDown/transfer, clear the lease before returning.
