Answer

Effective memory.high in a nested cgroup v2 subtree (with PSI)

TL;DR

memory.high is not a per-cgroup absolute value. The value that actually throttles a leaf is the minimum of the memory.high values on every ancestor that has the memory controller online, and a controller is online only if the chain of cgroup.subtree_control delegated it. A non-root cgroup with processes attached (pids.current > 0) cannot newly publish memory in its own cgroup.subtree_control ("no internal process" constraint). When that chain is broken, every memory.high below the break is silently unenforced no matter what value is recorded.

The verified solution lives in ~/solution/:

file purpose
effective_memory_high.sh parse dump, compute effective limits, classify unenforced policies, emit a safe ordered write plan
apply_writes.sh replay that plan against /sys/fs/cgroup (dry-run by default)
verify.py independent simulator proving configured(child) ≤ configured(parent) after every write
fixtures/, fixtures/expected/, run_tests.sh regression + property tests (15/15 pass)
SOLUTION.md the full written-up version of this document

Output is byte-identical for any permutation of the input lines (keyed storage + explicit LC_ALL=C sort order).

Root-cause analysis

A naive implementation ("read memory.high, print it") fails for four independent conceptual reasons:

1. memory.high is hierarchical, and max is infinity

effective(root) = own_high(root)                       if online
effective(n)    = min(own_high(n), effective(parent))  if online
effective(n)    = effective(parent)                    if offline

A child may configure a value above its parent (the kernel accepts it); the parent wins. And max must be infinity — never parsed as a number.

2. Presence of a value ≠ enforcement

memory is online at n iff memory ∈ parent.cgroup.subtree_control. A non-root cgroup with pids.current > 0 that has not already delegated can no longer publish the controller, so descendants have no memory files at all. Their memory.high entries are unenforced and cannot be fixed by writing memory.high — the fix requires moving the processes out first. Missing this is how a tool reports "limits applied" while pressure still climbs.

3. A single pass cannot safely reach the target

If a child is currently above its parent (a pre-existing inversion) and both targets are lower, lowering the parent first strands the child. The robust construction is: temporarily widen the parent to its subtree's current maximum, raise/widen top-down, then lower bottom-up. The widening is undone by the final lower pass, so the net result is exactly the target.

4. Order-dependent output

Associative-array iteration and raw input order are unspecified. The fix is to key every fact by path|field and materialize one explicit sorted order before emitting anything.

Model and algorithm

For each node n: online(n) as above; own(n) = numeric memory.high; eff(n) = min(own(n), eff(parent)) when online else +inf; binding(n) = deepest online ancestor attaining the minimum.

Policy classification: inactive (offline, with fixable/blocked break detail), shadowed_by_max (v ≥ memory.max), shadowed (v > eff(parent)), redundant (v == eff(parent)).

Write plan (parents-first for raising/widening, child-first for lowering): 1. activate +memory into cgroup.subtree_control, top-down, only where the parent has no processes (or is root); 2. temp — temporarily widen to the subtree current maximum, top-down; 3. raise/set toward target, top-down; 4. lower to target, bottom-up.

Input format

Flat, order-independent; blank lines and # comments ignored; each line is path field value:

field value
cgroup.controllers / cgroup.subtree_control space-separated names, or -
memory.max / memory.high / memory.swap.max bytes or max
pids.current integer
psi.memory / .some / .full avg10=.. avg60=.. avg300=.. total=..
intended.memory.high optional target to restore

The fix — effective_memory_high.sh

#!/usr/bin/env bash
# effective_memory_high.sh
# Diagnose a cgroup v2 subtree dump deterministically and emit a safe write plan.
set -uo pipefail
export LC_ALL=C

PROG=${0##*/}
INF=9223372036854775807
PSI_WARN=${PSI_WARN_AVG10:-10.00}

err()  { printf '%s: error: %s\n' "$PROG" "$*" >&2; exit 2; }
warn() { printf '%s: warning: %s\n' "$PROG" "$*" >&2; }

norm_path() {
    local p=${1:-/}
    p=${p%$'\r'}
    while [[ $p == *//* ]]; do p=${p//\/\//\/}; done
    [[ $p == /* ]] || p=/$p
    while [[ $p != / && $p == */ ]]; do p=${p%/}; done
    [[ -z $p ]] && p=/
    printf '%s' "$p"
}
node_depth() {
    local p=${1:-/} d=0 part
    local IFS=/
    for part in $p; do [[ -n $part ]] && d=$((d + 1)); done
    printf '%s' "$d"
}
is_uint() { [[ $1 =~ ^[0-9]+$ ]]; }
to_num()  { case $1 in max|'') printf '%s' "$INF" ;; *) printf '%s' "$1" ;; esac; }
val_str() { (( $1 == INF )) && printf 'max' || printf '%s' "$1"; }
list_has() { [[ " $1 " == *" $2 "* ]]; }

declare -A SEEN DUPSCALAR CTL_SET SUB_SET
declare -A MAXV HIGHV SWAPV PIDV PSIS PSIF INTV
declare -A HIGH_PRESENT INT_PRESENT
declare -a NODES=()

ADD_NODE_OUT=
add_node() {
    local q; q=$(norm_path "$1")
    if [[ -z ${SEEN[$q]:-} ]]; then SEEN[$q]=1; NODES+=("$q"); fi
    ADD_NODE_OUT=$q
}
set_scalar() {
    local arr=$1 p=$2 f=$3 v=$4 key
    local -n A="$arr"
    key="$p|$f"
    if [[ -n ${DUPSCALAR[$key]:-} && ${A[$p]:-} != "$v" ]]; then
        err "conflicting values for '$f' at '$p': '${A[$p]}' vs '$v'"
    fi
    A[$p]=$v
    DUPSCALAR[$key]=1
}
parse_stream() {
    local input=${1:-/dev/stdin} line p f rest tok
    while IFS= read -r line || [[ -n $line ]]; do
        line=${line%$'\r'}
        [[ -z $line || $line == \#* ]] && continue
        read -r p f rest <<<"$line"
        [[ -z ${p:-} || -z ${f:-} ]] && { warn "ignoring malformed line: $line"; continue; }
        add_node "$p"; p=$ADD_NODE_OUT
        case $f in
            cgroup.controllers)
                for tok in $rest; do [[ $tok == - || -z $tok ]] && continue; CTL_SET["$p|$tok"]=1; done ;;
            cgroup.subtree_control)
                for tok in $rest; do [[ $tok == - || -z $tok ]] && continue; SUB_SET["$p|$tok"]=1; done ;;
            memory.max)
                { is_uint "$rest" || [[ $rest == max ]]; } || err "bad memory.max at $p: $rest"
                set_scalar MAXV "$p" memory.max "$rest" ;;
            memory.high)
                { is_uint "$rest" || [[ $rest == max ]]; } || err "bad memory.high at $p: $rest"
                set_scalar HIGHV "$p" memory.high "$rest"; HIGH_PRESENT["$p"]=1 ;;
            memory.swap.max)
                { is_uint "$rest" || [[ $rest == max ]]; } || err "bad memory.swap.max at $p: $rest"
                set_scalar SWAPV "$p" memory.swap.max "$rest" ;;
            pids.current)
                is_uint "$rest" || err "bad pids.current at $p: $rest"; set_scalar PIDV "$p" pids.current "$rest" ;;
            psi.memory|psi.memory.some) PSIS["$p"]=$rest ;;
            psi.memory.full) PSIF["$p"]=$rest ;;
            intended.memory.high)
                { is_uint "$rest" || [[ $rest == max ]]; } || err "bad intended.memory.high at $p: $rest"
                set_scalar INTV "$p" intended.memory.high "$rest"; INT_PRESENT["$p"]=1 ;;
            *) warn "unknown field '$f' at '$p' (ignored)" ;;
        esac
    done <"$input"
}

declare -A CTL SUB PARENT CHILDREN SYNTH
declare -a ORDER=() RORDER=()
build_lists() {
    local key p c toks
    for key in "${!CTL_SET[@]}"; do p=${key%%|*}; c=${key#*|}; CTL["$p"]="${CTL[$p]:-} $c"; done
    for key in "${!SUB_SET[@]}"; do p=${key%%|*}; c=${key#*|}; SUB["$p"]="${SUB[$p]:-} $c"; done
    for p in "${NODES[@]}"; do
        toks="${CTL[$p]:-}"
        if [[ -n $toks ]]; then CTL["$p"]=$(printf '%s\n' $toks | LC_ALL=C sort -u | paste -sd' ' -); else CTL["$p"]=""; fi
        toks="${SUB[$p]:-}"
        if [[ -n $toks ]]; then SUB["$p"]=$(printf '%s\n' $toks | LC_ALL=C sort -u | paste -sd' ' -); else SUB["$p"]=""; fi
    done
}
add_ancestors() {
    local p par changed=1
    local -a snap
    while (( changed )); do
        changed=0; snap=("${NODES[@]}")
        for p in "${snap[@]}"; do
            [[ $p == / ]] && continue
            par=${p%/*}; [[ -z $par ]] && par=/
            if [[ -z ${SEEN[$par]:-} ]]; then SEEN[$par]=1; SYNTH[$par]=1; NODES+=("$par"); changed=1; fi
        done
    done
    if [[ -z ${SEEN[/]:-} ]]; then SEEN[/]=1; SYNTH[/]=1; NODES+=(/); fi
    for p in "${NODES[@]}"; do
        if [[ -n ${SYNTH[$p]:-} ]]; then
            list_has "${CTL[$p]:-}" memory || CTL["$p"]="memory"
            list_has "${SUB[$p]:-}" memory || SUB["$p"]="memory ${SUB[$p]:-}"
            SUB["$p"]=$(printf '%s\n' ${SUB[$p]:-} | LC_ALL=C sort -u | paste -sd' ' -)
        fi
    done
}
build_tree() {
    local p par
    for p in "${NODES[@]}"; do
        [[ $p == / ]] && continue
        par=${p%/*}; [[ -z $par ]] && par=/
        PARENT["$p"]=$par
        CHILDREN["$par"]="${CHILDREN[$par]:-} $p"
    done
}
compute_order() {
    local p
    mapfile -t ORDER < <(
        for p in "${NODES[@]}"; do printf '%d\t%s\n' "$(node_depth "$p")" "$p"; done \
        | LC_ALL=C sort -t$'\t' -k1,1n -k2,2 | cut -f2-
    )
    mapfile -t RORDER < <(printf '%s\n' "${ORDER[@]}" | tac)
}

declare -A ACTIVE EFF BIND
compute_active_effective() {
    local p par own cand
    for p in "${ORDER[@]}"; do
        if [[ $p == / ]]; then
            if list_has "${CTL[/]:-}" memory || [[ -n ${SYNTH[/]:-} ]]; then ACTIVE[/]=1; else ACTIVE[/]=0; fi
        else
            par=${PARENT[$p]}
            if [[ ${ACTIVE[$par]:-0} == 1 ]] && list_has "${SUB[$par]:-}" memory; then ACTIVE[$p]=1; else ACTIVE[$p]=0; fi
        fi
        if [[ $p == / ]]; then cand=$INF; else cand=${EFF[${PARENT[$p]}]:-$INF}; fi
        if [[ ${ACTIVE[$p]:-0} == 1 ]]; then
            own=$(to_num "${HIGHV[$p]:-max}"); (( own < cand )) && cand=$own
        fi
        EFF[$p]=$cand
        if [[ ${ACTIVE[$p]:-0} == 1 && $(to_num "${HIGHV[$p]:-max}") -le $cand ]]; then BIND[$p]=$p
        elif [[ $p != / ]]; then BIND[$p]=${BIND[${PARENT[$p]}]:--}; else BIND[$p]=-; fi
    done
}

declare -a UNENF=()
collect_unenforced() {
    local p par int num maxv peff kind detail a brk
    for p in "${ORDER[@]}"; do
        if [[ -n ${INT_PRESENT[$p]:-} ]]; then int=${INTV[$p]}
        elif [[ -n ${HIGH_PRESENT[$p]:-} ]]; then int=${HIGHV[$p]}
        else continue; fi
        num=$(to_num "$int"); (( num == INF )) && continue
        kind=""; detail=""
        if [[ ${ACTIVE[$p]:-0} != 1 ]]; then
            kind=inactive; a=$p; brk=""
            while [[ $a != / ]]; do
                par=${PARENT[$a]}
                if [[ ${ACTIVE[$par]:-0} == 1 ]] && ! list_has "${SUB[$par]:-}" memory; then brk=$par; fi
                a=$par
            done
            if [[ -n $brk ]]; then
                if [[ $brk == / || ${PIDV[$brk]:-0} == 0 ]]; then detail="delegation_missing_at:$brk(fixable)"
                else detail="internal_process_at:$brk(pids=${PIDV[$brk]:-0},blocked)"; fi
            else detail="controller_unavailable"; fi
        else
            maxv=$(to_num "${MAXV[$p]:-max}")
            if (( num >= maxv )); then
                kind=shadowed_by_max
                [[ $maxv == INF ]] && detail="memory.max=unset" || detail="memory.max=$maxv"
            else
                [[ $p == / ]] && peff=$INF || peff=${EFF[${PARENT[$p]}]:-$INF}
                if (( num > peff )); then kind=shadowed; detail="clamped_by:${BIND[${PARENT[$p]}]:--}"
                elif (( num == peff )); then kind=redundant; detail="same_as:${BIND[${PARENT[$p]}]:--}"; fi
            fi
        fi
        [[ -n $kind ]] && UNENF+=("$p|$int|$kind|$detail")
    done
}

declare -A NEEDS SUB_ADDED SIMACT
declare -a WRITES=()
emit_write() { WRITES+=("$1|$2|$3|$4|$5"); }
compute_needs() {
    local p
    for p in "${ORDER[@]}"; do NEEDS[$p]=0; done
    for p in "${ORDER[@]}"; do
        if [[ -n ${INT_PRESENT[$p]:-} || -n ${HIGH_PRESENT[$p]:-} ]]; then
            if [[ $(to_num "${INTV[$p]:-${HIGHV[$p]:-max}}") != $INF ]]; then NEEDS[$p]=1; fi
        fi
    done
    for p in "${RORDER[@]}"; do
        [[ $p == / ]] && continue
        [[ ${NEEDS[$p]:-0} == 1 ]] && NEEDS[${PARENT[$p]}]=1
    done
}
generate_activations() {
    local p par
    for p in "${ORDER[@]}"; do
        if [[ $p == / ]]; then
            if list_has "${CTL[/]:-}" memory || [[ -n ${SYNTH[/]:-} ]]; then SIMACT[/]=1; else SIMACT[/]=0; fi
            continue
        fi
        par=${PARENT[$p]}
        if [[ ${SIMACT[$par]:-0} == 1 && ${SUB_ADDED[$par]:-0} == 0 ]] \
           && ! list_has "${SUB[$par]:-}" memory && [[ ${NEEDS[$p]:-0} == 1 ]]; then
            if list_has "${CTL[$par]:-}" memory && { [[ $par == / ]] || [[ ${PIDV[$par]:-0} == 0 ]]; }; then
                emit_write activate "$par" cgroup.subtree_control "+memory" "delegate memory to children of $par"
                SUB_ADDED[$par]=1
            fi
        fi
        if [[ ${SIMACT[$par]:-0} == 1 ]] && { list_has "${SUB[$par]:-}" memory || [[ ${SUB_ADDED[$par]:-0} == 1 ]]; }; then
            SIMACT[$p]=1
        else SIMACT[$p]=0; fi
    done
}
declare -A TGT CURV CUR_SET CUR_UNSET SUBMAX
plan_limits() {
    local p par
    for p in "${ORDER[@]}"; do
        [[ ${SIMACT[$p]:-0} == 1 ]] || continue
        if [[ -n ${INT_PRESENT[$p]:-} ]]; then TGT[$p]=$(to_num "${INTV[$p]}")
        elif [[ -n ${HIGH_PRESENT[$p]:-} ]]; then TGT[$p]=$(to_num "${HIGHV[$p]}")
        else TGT[$p]=$INF; fi
        if [[ ${ACTIVE[$p]:-0} == 1 ]]; then CUR_SET[$p]=1; CUR_UNSET[$p]=0; CURV[$p]=$(to_num "${HIGHV[$p]:-max}")
        else CUR_SET[$p]=0; CUR_UNSET[$p]=1; CURV[$p]=$INF; fi
    done
    for p in "${ORDER[@]}"; do
        [[ ${SIMACT[$p]:-0} == 1 ]] || continue
        [[ $p == / ]] && continue
        par=${PARENT[$p]}
        if (( ${TGT[$p]} > ${TGT[$par]} )); then
            warn "target for $p exceeds parent $par; clamped for safety"; TGT[$p]=${TGT[$par]}
        fi
    done
}
plan_temps() {
    local p c m
    for p in "${RORDER[@]}"; do
        [[ ${SIMACT[$p]:-0} == 1 ]] || continue
        m=0
        if [[ ${CUR_SET[$p]:-0} == 1 && ${CUR_UNSET[$p]:-0} == 0 ]]; then m=${CURV[$p]}; fi
        for c in ${CHILDREN[$p]:-}; do
            [[ ${SIMACT[$c]:-0} == 1 ]] || continue
            (( ${SUBMAX[$c]:-0} > m )) && m=${SUBMAX[$c]}
        done
        SUBMAX[$p]=$m
    done
    for p in "${ORDER[@]}"; do
        [[ ${SIMACT[$p]:-0} == 1 ]] || continue
        [[ ${CUR_SET[$p]:-0} == 1 && ${CUR_UNSET[$p]:-0} == 0 ]] || continue
        if (( ${SUBMAX[$p]} > ${CURV[$p]} )); then
            emit_write temp "$p" memory.high "$(val_str "${SUBMAX[$p]}")" "temporary widening above subtree current max"
            CURV[$p]=${SUBMAX[$p]}
        fi
    done
}
write_raises() {
    local p
    for p in "${ORDER[@]}"; do
        [[ ${SIMACT[$p]:-0} == 1 ]] || continue
        if [[ ${CUR_UNSET[$p]:-0} == 1 ]]; then
            emit_write set "$p" memory.high "$(val_str "${TGT[$p]}")" "first write after delegation"
            CURV[$p]=${TGT[$p]}; CUR_UNSET[$p]=0
        elif (( ${TGT[$p]} > ${CURV[$p]} )); then
            emit_write raise "$p" memory.high "$(val_str "${TGT[$p]}")" "raise to target"; CURV[$p]=${TGT[$p]}
        fi
    done
}
write_lowers() {
    local p
    for p in "${RORDER[@]}"; do
        [[ ${SIMACT[$p]:-0} == 1 ]] || continue
        [[ ${CUR_UNSET[$p]:-0} == 1 ]] && continue
        if (( ${TGT[$p]} < ${CURV[$p]} )); then
            emit_write lower "$p" memory.high "$(val_str "${TGT[$p]}")" "lower to target"; CURV[$p]=${TGT[$p]}
        fi
    done
}

psi_avg10() { local s=${1:-}; if [[ $s =~ avg10=([0-9.]+) ]]; then printf '%s' "${BASH_REMATCH[1]}"; else printf -- '-'; fi; }
pct_ge() { [[ $1 == - ]] && return 1; awk -v a="$1" -v b="$2" 'BEGIN{exit !(a+0>=b+0)}'; }

print_report() {
    local p child isleaf e b sa fa press line n w
    printf '# effective-memory-high report\n'
    printf 'SECTION EFFECTIVE_HIGH\n'
    for p in "${ORDER[@]}"; do
        isleaf=1; for child in ${CHILDREN[$p]:-}; do isleaf=0; break; done
        [[ $isleaf == 1 ]] || continue
        e=$(val_str "${EFF[$p]:-$INF}"); b=${BIND[$p]:--}; [[ $e == max ]] && b=-
        sa=$(psi_avg10 "${PSIS[$p]:-}"); fa=$(psi_avg10 "${PSIF[$p]:-}"); press=OK
        if pct_ge "$sa" "$PSI_WARN" || pct_ge "$fa" "$PSI_WARN"; then press=WARN; fi
        printf 'EFFECTIVE_HIGH path=%s effective=%s binding=%s memory_max=%s psi_some_avg10=%s psi_full_avg10=%s pressure=%s\n' \
            "$p" "$e" "$b" "$(val_str "$(to_num "${MAXV[$p]:-max}")")" "$sa" "$fa" "$press"
    done
    printf 'SECTION UNENFORCED\n'
    if [[ ${#UNENF[@]} -eq 0 ]]; then printf 'UNENFORCED none\n'
    else
        while IFS= read -r line; do
            printf 'UNENFORCED path=%s intended=%s kind=%s detail=%s\n' \
                "${line%%|*}" "$(echo "$line" | cut -d'|' -f2)" "$(echo "$line" | cut -d'|' -f3)" "$(echo "$line" | cut -d'|' -f4-)"
        done < <(printf '%s\n' "${UNENF[@]}" | LC_ALL=C sort)
    fi
    printf 'SECTION WRITES\n'
    n=0
    if [[ ${#WRITES[@]} -eq 0 ]]; then printf 'WRITE none\n'
    else
        for w in "${WRITES[@]}"; do
            n=$((n + 1))
            printf 'WRITE seq=%d phase=%s path=%s file=%s value=%s note=%s\n' \
                "$n" "$(echo "$w" | cut -d'|' -f1)" "$(echo "$w" | cut -d'|' -f2)" \
                "$(echo "$w" | cut -d'|' -f3)" "$(echo "$w" | cut -d'|' -f4)" "$(echo "$w" | cut -d'|' -f5- | tr '|' ' ')"
        done
    fi
}

INPUT=${1:-/dev/stdin}
[[ $INPUT == - ]] && INPUT=/dev/stdin
[[ -r $INPUT ]] || err "cannot read input: $INPUT"
parse_stream "$INPUT"
if [[ ${#NODES[@]} -eq 0 ]]; then err "no cgroup nodes found in input"; fi
add_ancestors
build_lists
build_tree
compute_order
compute_active_effective
collect_unenforced
compute_needs
HAVE_TRIGGER=0
for p in "${ORDER[@]}"; do
    if [[ -n ${INT_PRESENT[$p]:-} && ${INTV[$p]:-} != "${HIGHV[$p]:-}" ]]; then HAVE_TRIGGER=1; fi
    if [[ -n ${HIGH_PRESENT[$p]:-} && ${ACTIVE[$p]:-0} != 1 ]]; then HAVE_TRIGGER=1; fi
done
if [[ $HAVE_TRIGGER == 1 ]]; then
    generate_activations; plan_limits; plan_temps; write_raises; write_lowers
fi
print_report
