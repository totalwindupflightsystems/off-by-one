Answer

Reclaiming WAL from PostgreSQL logical replication slots without breaking live subscribers

Problem class: shell-pglogical-slot-wal-retention-lag-reconcile Target: Bash 5.2 operator script, PostgreSQL 10+ (tested on 18) Artifact: pg_slot_reconcile.sh — dry-run planner + guarded applier (also saved at ~/SOLUTION.md and ~/pg_slot_reconcile.sh)

1. Root-cause analysis

A logical replication slot is a WAL retention pin. PostgreSQL keeps every WAL segment from the slot's restart_lsn forward, because the decoder may still have to read it. The pin is bounded by max_slot_wal_keep_size:

  • if the pin exceeds the limit, pg_replication_slots.safe_wal_size goes negative and wal_status becomes 'unreserved';
  • the next checkpoint (CheckPointReplicationSlots / InvalidateObsoleteReplicationSlots) removes those segments and flips the slot to 'lost' with restart_lsn = NULL — the subscriber can never resume without a full resync.

Operational failures cluster around a small set of mistakes:

  1. Dropping a slot that a live subscriber still needs. If active = true, a walsender is attached and WAL from confirmed_flush_lsn onward is still required. A naive SELECT pg_drop_replication_slot(slot_name) FROM pg_replication_slots WHERE safe_wal_size < 0 will happily destroy it.
  2. A subscriber reconnects between "plan" and "apply". The slot was inactive when the plan was computed, so the plan says drop; a subscriber attaches a moment later. Without a re-check, the operator drops a live slot.
  3. A checkpoint is in flight. restart_lsn/wal_status can change (to lost) between reading the state and acting on it.
  4. wal_status = 'unreserved' is misread as "already lost" (and skipped) or as "safe" (and ignored). It means not guaranteed anymore; act now.
  5. Non-idempotent plans. An "advance" that does not move restart_lsn gets proposed again on every run, so the operator can never tell whether the system converged.

The core insight for the fix: active is the safety boundary. A slot may only be mutated when it has no live walsender, and the only reliable way to free restart_lsn-pinned WAL on a logical slot is to drop it (or have a subscriber actually decode). pg_replication_slot_advance() moves confirmed_flush_lsn and is offered here for environments where it also moves restart_lsn; the reclaim proof measures the actual before/after effect so it never overstates.

The retention accounting that the plan must prove

PostgreSQL counts a slot's retention from the end of the segment containing restart_lsn to the current WAL insert position (verified empirically on PG 18; the difference between safe_wal_size and the exact pg_current_wal_lsn()-based value was 0 bytes):

counted_retained(slot) = pg_current_wal_lsn - (floor(restart_lsn / wal_segment_size) + 1) * wal_segment_size
safe_wal_size(slot)    = max_slot_wal_keep_size - counted_retained(slot)

For a freshly created slot counted_retained is negative, so safe_wal_size can legitimately exceed max_slot_wal_keep_size. The script reproduces this formula exactly (including the negative case) to project the post-plan retention of the oldest surviving slot.

2. The fix (design)

A single JSON plan is produced from one database snapshot; mutation requires --apply.

Decision table per logical slot

Condition Action Why
active = true hold live subscriber; WAL from confirmed_flush_lsn still required. Never dropped.
restart_lsn IS NULL or wal_status = 'lost' and inactive drop unusable; cannot pin WAL, no live subscriber.
inactive, past --grace drop (--orphan-action=drop) / advance (--orphan-action=advance) / hold orphaned
inactive, within grace hold avoid reaping a subscriber that just disconnected
wal_status = 'unreserved' treated like any active/inactive slot, but surfaced as status = at_risk/over_limit act before the checkpoint makes it lost

Guards that close the race windows

  • The plan is advisory; each drop/advance is re-validated inside the database in a PL/pgSQL DO block that re-reads active.
  • pg_drop_replication_slot() / pg_replication_slot_advance() themselves call ReplicationSlotAcquire(..., nowait) and raise replication slot "x" is active for PID n if a subscriber reconnected — this is the final, atomic backstop.
  • A checkpoint that turns the slot lost simply makes the drop a no-op or makes the advance log "lost; advancing confirmed position only".
  • An advisory lock (pg_try_advisory_lock) serializes concurrent operator runs.
  • A per-target state file records the first-seen-inactive timestamp (grace clock) and the last advance target (idempotency high-water mark).

Idempotency is verified inside the same run: after applying, the script re-reads the database, re-plans with the updated state, and reports idempotent_after_apply plus remaining_actions_after_apply.

3. Exact fix — pg_slot_reconcile.sh

#!/usr/bin/env bash
#
# pg_slot_reconcile.sh -- PostgreSQL logical replication slot / WAL-retention
# reconciler.
#
# Reads pg_replication_slots + pg_stat_replication, and produces a JSON plan
# that ADVANCEs, HOLDs, or DROPs every logical slot so that WAL retained by
# abandoned slots is reclaimed, while WAL still required by a live subscriber
# is never discarded.
#
# Safe by construction:
#   * dry-run is the default; mutation requires --apply
#   * a live subscriber (slot.active = true) is always HOLD
#   * drop/advance are re-validated inside the database, and
#     pg_drop_replication_slot()/pg_replication_slot_advance() themselves
#     refuse to touch an active slot -- this closes the "subscriber reconnects
#     between plan and apply" race
#   * a checkpoint that invalidates the slot (restart_lsn -> NULL,
#     wal_status='lost') or a newly visible wal_status='unreserved' is handled
#     at apply time
#   * re-planning after apply yields only HOLDs (idempotent), enforced with a
#     small on-disk bookkeeping file for the orphan grace clock / advance mark
#
# Requires: bash >= 5.0, psql, jq.  Tested with bash 5.2/5.3, PostgreSQL 18.
#
set -Eeuo pipefail

PROG="${0##*/}"
VERSION="1.0.0"

APPLY=0
GRACE=600
ORPHAN_ACTION="drop"        # drop | advance | hold
ADVANCE_TO_CURRENT=1        # for --orphan-action advance
DROP_LOST=1
SLOT_FILTER=""
STATE_DIR="${XDG_STATE_HOME:-$HOME/.local/state}/pg-slot-reconcile"
DSN=""
QUIET=0
LOCK_KEY=7234070312345678901
APPLY_RC=0

usage() {
  cat <<EOF
Usage: $PROG [options]

Reconcile PostgreSQL logical replication slots against WAL retention.
Dry-run by default; pass --apply to execute the plan.

Options:
  --apply                     Execute the plan (default: dry-run).
  --grace N                   Seconds an inactive slot must stay inactive before
                              it is considered an orphan (default $GRACE).
  --orphan-action ACTION      drop | advance | hold      (default $ORPHAN_ACTION)
  --advance-to-confirmed      With 'advance': advance only to confirmed_flush_lsn.
  --no-drop-lost              Do not drop slots with wal_status='lost'.
  --slot-filter REGEX         Only consider slots whose name matches REGEX.
  --state-dir DIR             Orphan-grace / advance state dir (default $STATE_DIR).
  --dsn DSN                   libpq connection string / URI (else use PG* env).
  --quiet                     Suppress progress messages on stderr.
  -h, --help                  This help.
  --version                   Print version.

Exit status: 0 success, 1 usage/runtime error, 2 an apply guard refused.
EOF
}

log() { [[ $QUIET -eq 0 ]] && printf '%s\n' "$*" >&2 || true; }
die() { printf '%s: error: %s\n' "$PROG" "$*" >&2; exit 1; }

while (($#)); do
  case "$1" in
    --apply)                APPLY=1 ;;
    --dry-run)              APPLY=0 ;;
    --grace)                GRACE="${2:?--grace needs a value}"; shift ;;
    --grace=*)              GRACE="${1#*=}" ;;
    --orphan-action)        ORPHAN_ACTION="${2:?--orphan-action needs a value}"; shift ;;
    --orphan-action=*)      ORPHAN_ACTION="${1#*=}" ;;
    --advance-to-confirmed) ADVANCE_TO_CURRENT=0 ;;
    --no-drop-lost)         DROP_LOST=0 ;;
    --slot-filter)          SLOT_FILTER="${2:?--slot-filter needs a value}"; shift ;;
    --slot-filter=*)        SLOT_FILTER="${1#*=}" ;;
    --state-dir)            STATE_DIR="${2:?--state-dir needs a value}"; shift ;;
    --state-dir=*)          STATE_DIR="${1#*=}" ;;
    --dsn)                  DSN="${2:?--dsn needs a value}"; shift ;;
    --dsn=*)                DSN="${1#*=}" ;;
    --quiet)                QUIET=1 ;;
    -h|--help)              usage; exit 0 ;;
    --version)              printf '%s %s\n' "$PROG" "$VERSION"; exit 0 ;;
    *) die "unknown option: $1 (try --help)" ;;
  esac
  shift
done

[[ "$GRACE" =~ ^[0-9]+$ ]] || die "--grace must be a non-negative integer"
case "$ORPHAN_ACTION" in drop|advance|hold) ;; *) die "--orphan-action must be drop|advance|hold" ;; esac
command -v psql >/dev/null || die "psql not found"
command -v jq   >/dev/null || die "jq not found"

PSQL=(psql -X -q -A -t -v ON_ERROR_STOP=1)
[[ -n "$DSN" ]] && PSQL+=(-d "$DSN")

# --------------------------------------------------------------------------
# 1. Read one consistent snapshot.
# --------------------------------------------------------------------------
read -r -d '' SQL_STATE <<'SQL' || true
SELECT json_build_object(
  'server_version', current_setting('server_version'),
  'now_epoch', extract(epoch FROM clock_timestamp())::bigint,
  'current_wal_lsn', pg_current_wal_lsn()::text,
  'wal_offset', pg_wal_lsn_diff(pg_current_wal_lsn(), '0/0'::pg_lsn),
  'wal_segment_size', pg_size_bytes(current_setting('wal_segment_size')),
  'max_slot_wal_keep_size_setting', current_setting('max_slot_wal_keep_size'),
  'max_slot_wal_keep_size_bytes',
      CASE WHEN current_setting('max_slot_wal_keep_size') = '-1' THEN -1
           ELSE pg_size_bytes(current_setting('max_slot_wal_keep_size')) END,
  'slots', COALESCE((
    SELECT json_agg(x ORDER BY (x->>'slot_name'))
    FROM (
      SELECT json_build_object(
        'slot_name', s.slot_name,
        'slot_type', s.slot_type,
        'database', s.database,
        'active', s.active,
        'active_pid', s.active_pid,
        'restart_lsn', s.restart_lsn::text,
        'restart_offset',
            CASE WHEN s.restart_lsn IS NULL THEN NULL
                 ELSE pg_wal_lsn_diff(s.restart_lsn, '0/0'::pg_lsn) END,
        'confirmed_flush_lsn', s.confirmed_flush_lsn::text,
        'confirmed_offset',
            CASE WHEN s.confirmed_flush_lsn IS NULL THEN NULL
                 ELSE pg_wal_lsn_diff(s.confirmed_flush_lsn, '0/0'::pg_lsn) END,
        'wal_status', s.wal_status,
        'safe_wal_size', s.safe_wal_size,
        'retained_bytes',
            CASE WHEN s.restart_lsn IS NULL THEN NULL
                 ELSE pg_wal_lsn_diff(pg_current_wal_lsn(), s.restart_lsn) END,
        'pinned_confirmed_bytes',
            CASE WHEN s.restart_lsn IS NULL OR s.confirmed_flush_lsn IS NULL THEN NULL
                 ELSE pg_wal_lsn_diff(s.confirmed_flush_lsn, s.restart_lsn) END,
        'live_subscriber', (s.active AND r.pid IS NOT NULL),
        'subscriber',
            CASE WHEN r.pid IS NULL THEN NULL ELSE json_build_object(
              'pid', r.pid,
              'application_name', r.application_name,
              'client_addr', host(r.client_addr),
              'state', r.state,
              'sync_state', r.sync_state,
              'write_lsn', r.write_lsn::text,
              'flush_lsn', r.flush_lsn::text,
              'replay_lsn', r.replay_lsn::text,
              'replay_lag_seconds', extract(epoch FROM r.replay_lag),
              'replay_lag_bytes',
                  CASE WHEN r.replay_lsn IS NULL THEN NULL
                       ELSE pg_wal_lsn_diff(pg_current_wal_lsn(), r.replay_lsn) END
            ) END
      ) AS x
      FROM pg_replication_slots s
      LEFT JOIN pg_stat_replication r ON r.pid = s.active_pid
      WHERE s.slot_type = 'logical'
    ) sub
  ), '[]'::json)
)::text;
SQL

db_state() { "${PSQL[@]}" -c "$SQL_STATE"; }

# --------------------------------------------------------------------------
# 2. Plan builder.
# --------------------------------------------------------------------------
read -r -d '' JQ_PLAN <<'JQ' || true
def seg: $db.wal_segment_size;
def seg_end($off): if $off == null then null else (((($off / seg) | floor) + 1) * seg) end;

# effective inactive_since: first sighting starts the clock at "now" for this
# run.  Only --apply persists it, so a dry-run never silently ages a slot.
def inactive_since($s):
  if $s.active then null
  else ($state.slots[$s.slot_name].inactive_since // $db.now_epoch) end;

def past_grace($s):
  (inactive_since($s)) as $t
  | ($t != null) and (($db.now_epoch - $t) >= $opts.grace);

def status_for($s):
  if ($s.safe_wal_size != null and $s.safe_wal_size < 0) then "over_limit"
  elif $s.wal_status == "lost" then "lost"
  elif $s.wal_status == "unreserved" then "at_risk"
  else "ok" end;

def action_for($s):
  if $s.active then
    { action: "hold",
      reason: (if $s.restart_lsn == null or $s.wal_status == "lost"
               then "live subscriber attached but slot is lost; resync required"
               else "live subscriber attached; WAL from confirmed_flush_lsn still required" end),
      required_by_live_subscriber: true }
  elif ($s.restart_lsn == null or $s.wal_status == "lost") then
    (if $opts.drop_lost
     then { action: "drop", reason: "slot is lost and has no live subscriber",
            required_by_live_subscriber: false }
     else { action: "hold", reason: "slot is lost; --no-drop-lost set",
            required_by_live_subscriber: false } end)
  elif past_grace($s) then
    (if $opts.orphan_action == "drop" then
       { action: "drop",
         reason: "orphan: inactive for >= \($opts.grace)s and not referenced by a live subscriber",
         required_by_live_subscriber: false }
     elif $opts.orphan_action == "advance" then
       (if $opts.advance_to_current
        then {off: $db.wal_offset, lsn: $db.current_wal_lsn}
        else {off: $s.confirmed_offset, lsn: $s.confirmed_flush_lsn} end) as $t
       | if $t.off == null then
           { action: "hold", reason: "orphan but no safe advance target",
             required_by_live_subscriber: false }
         elif (($state.slots[$s.slot_name].last_advance_target // -1) >= $t.off) then
           { action: "hold", reason: "orphan already advanced to target",
             required_by_live_subscriber: false }
         else
           { action: "advance", advance_to_offset: $t.off, advance_to_lsn: $t.lsn,
             discards_unconfirmed: ($opts.advance_to_current == 1),
             reason: (if $opts.advance_to_current == 1
                      then "orphan: fast-forward past unconfirmed WAL (subscriber presumed gone)"
                      else "orphan: release already-confirmed range" end),
             required_by_live_subscriber: false }
         end
     else
       { action: "hold", reason: "orphan held by policy", required_by_live_subscriber: false }
     end)
  else
    { action: "hold",
      reason: (if $s.wal_status == "unreserved"
               then "inactive but within grace period (wal_status=unreserved)"
               else "inactive but within grace period" end),
      required_by_live_subscriber: false }
  end;

def projected_offset($s; $a):
  if $a.action == "drop" then null
  elif $a.action == "advance" then $a.advance_to_offset
  else $s.restart_offset end;

([ $db.slots[]
   | select(($opts.slot_filter == "") or (.slot_name | test($opts.slot_filter)))
   | . as $s
   | (action_for($s)) as $a
   | $s + $a
   | . + {
       status: status_for($s),
       inactive_since_epoch: inactive_since($s),
       worker_replay_lag_bytes: (if $s.subscriber == null then null else $s.subscriber.replay_lag_bytes end),
       projected_restart_offset: projected_offset($s; $a),
       reclaimable_bytes:
         (if $a.action == "drop" then ($s.retained_bytes // 0)
          elif $a.action == "advance" and $s.restart_offset != null
            then ([($s.restart_offset - $a.advance_to_offset), 0] | max)
          else 0 end)
     }
 ]) as $slots
| ([ $slots[] | .projected_restart_offset | select(. != null) ] | min) as $projected_oldest
| ($db.max_slot_wal_keep_size_bytes) as $max_keep
| (if $projected_oldest == null then 0
   else ($db.wal_offset - seg_end($projected_oldest)) end) as $projected_counted
| {
    version: "1.0",
    generated_at: (now | todate),
    dry_run: ($opts.apply == 0),
    server_version: $db.server_version,
    current_wal_lsn: $db.current_wal_lsn,
    current_wal_offset: $db.wal_offset,
    max_slot_wal_keep_size: $db.max_slot_wal_keep_size_setting,
    max_slot_wal_keep_size_bytes: $max_keep,
    grace_seconds: $opts.grace,
    orphan_action: $opts.orphan_action,
    summary: {
      total: ($slots | length),
      advance: ([$slots[] | select(.action == "advance")] | length),
      hold:    ([$slots[] | select(.action == "hold")]    | length),
      drop:    ([$slots[] | select(.action == "drop")]    | length),
      reclaimable_bytes: ([$slots[] | .reclaimable_bytes] | add // 0),
      over_limit_before: ([$slots[] | select(.status == "over_limit")] | length),
      at_risk_before:    ([$slots[] | select(.status == "at_risk")]    | length),
      lost_before:       ([$slots[] | select(.status == "lost")]       | length)
    },
    retention_proof: {
      method: "counted_retained = pg_current_wal_lsn - next_segment_start(oldest_restart_lsn); safe_wal_size = max_slot_wal_keep_size - counted_retained",
      projected_oldest_restart_offset: $projected_oldest,
      projected_counted_retained_bytes: $projected_counted,
      projected_safe_wal_size: (if $max_keep < 0 then null else $max_keep - $projected_counted end),
      within_limit_after: (if $max_keep < 0 then true else ($max_keep - $projected_counted) >= 0 end)
    },
    slots: $slots
  }
JQ

# --------------------------------------------------------------------------
# 3. State bookkeeping (orphan clock + advance high-water mark).
# --------------------------------------------------------------------------
state_file() {
  local key
  key="$(printf '%s' "${DSN:-${PGHOST:-local}:${PGPORT:-5432}:${PGDATABASE:-${PGUSER:-}}}" \
          | tr -c 'A-Za-z0-9._-' '_')"
  mkdir -p "$STATE_DIR"
  printf '%s/%s.json' "$STATE_DIR" "$key"
}

load_state() {
  local f; f="$(state_file)"
  if [[ -s "$f" ]]; then jq -c '.' "$f" 2>/dev/null || printf '{"version":1,"slots":{}}'
  else printf '{"version":1,"slots":{}}'; fi
}

next_state() {
  local state="$1" db="$2" plan="$3"
  jq -nc --argjson st "$state" --argjson db "$db" --argjson plan "$plan" '
    ($db.now_epoch) as $now
    | { version: 1,
        slots:
          (reduce $plan.slots[] as $s
             ({};
              ($s.slot_name) as $n
              | .[$n] =
                  (if $s.active then {}
                   else {inactive_since: ($st.slots[$n].inactive_since // $now)} end)
              | if ($st.slots[$n].last_advance_target // null) != null
                then .[$n].last_advance_target = $st.slots[$n].last_advance_target else . end
              | if $s.action == "advance"
                then .[$n].last_advance_target = $s.advance_to_offset else . end
             )
          )
      }'
}

plan() {
  # $1 state, $2 db
  jq -nc --argjson state "$1" --argjson db "$2" --argjson opts "$OPTS" "$JQ_PLAN"
}

# --------------------------------------------------------------------------
# 4. Apply, with in-database re-validation.
# --------------------------------------------------------------------------
sql_lit() { printf '%s' "$1" | sed "s/'/''/g"; }

release_lock() { "${PSQL[@]}" -c "SELECT pg_advisory_unlock($LOCK_KEY)" >/dev/null 2>&1 || true; }

apply_actions() {
  local plan="$1" results='[]' row action name target nlit tlit out status
  while IFS= read -r row; do
    [[ -z "$row" ]] && continue
    action="$(jq -r '.action' <<<"$row")"
    name="$(jq -r '.slot_name' <<<"$row")"
    nlit="$(sql_lit "$name")"
    status=0
    if [[ "$action" == "drop" ]]; then
      out="$("${PSQL[@]}" -c "
DO \$do\$
DECLARE v record;
BEGIN
  SELECT active INTO v FROM pg_replication_slots WHERE slot_name = '$nlit';
  IF NOT FOUND THEN RAISE NOTICE 'slot % already absent', '$nlit'; RETURN; END IF;
  IF v.active THEN RAISE EXCEPTION 'guard refused: slot % became active', '$nlit'; END IF;
  PERFORM pg_drop_replication_slot('$nlit');
  RAISE NOTICE 'dropped slot %', '$nlit';
END
\$do\$;" 2>&1)" || status=$?
    elif [[ "$action" == "advance" ]]; then
      target="$(jq -r '.advance_to_lsn' <<<"$row")"
      tlit="$(sql_lit "$target")"
      discards="$(jq -r '.discards_unconfirmed // false' <<<"$row")"
      out="$("${PSQL[@]}" -c "
DO \$do\$
DECLARE v record; target pg_lsn := '$tlit'; discards boolean := $discards;
BEGIN
  SELECT active, restart_lsn, confirmed_flush_lsn INTO v
    FROM pg_replication_slots WHERE slot_name = '$nlit';
  IF NOT FOUND THEN RAISE NOTICE 'slot % already absent', '$nlit'; RETURN; END IF;
  IF v.active THEN RAISE EXCEPTION 'guard refused: slot % became active', '$nlit'; END IF;
  IF NOT discards AND (v.confirmed_flush_lsn IS NULL OR v.confirmed_flush_lsn < target) THEN
    RAISE EXCEPTION 'guard refused: advance target % beyond confirmed_flush_lsn % for %',
      target, v.confirmed_flush_lsn, '$nlit';
  END IF;
  IF v.restart_lsn IS NOT NULL AND v.restart_lsn >= target THEN
    RAISE NOTICE 'slot % already at/after target', '$nlit'; RETURN;
  END IF;
  IF v.restart_lsn IS NULL THEN
    RAISE NOTICE 'slot % is lost; advancing only confirmed position', '$nlit';
  END IF;
  IF discards THEN
    RAISE WARNING 'slot %: advancing to % discards unconfirmed WAL', '$nlit', target;
  END IF;
  PERFORM pg_replication_slot_advance('$nlit', target);
  RAISE NOTICE 'advanced slot % to %', '$nlit', target;
END
\$do\$;" 2>&1)" || status=$?
    else
      continue
    fi
    (( status == 0 )) && log "apply ok: $action $name" || { APPLY_RC=2; log "apply FAILED: $action $name"; }
    results="$(jq -c --arg a "$action" --arg n "$name" --arg out "$out" --argjson st "$status" \
      '. + [{action:$a, slot_name:$n, exit_code:$st,
             detail:($out|gsub("\n";" ")|gsub("^\\s+|\\s+$";""))}]' <<<"$results")"
  done < <(jq -c '.slots[] | select(.action == "drop" or .action == "advance")' <<<"$plan")
  printf '%s' "$results"
}

# --------------------------------------------------------------------------
# 5. Main.
# --------------------------------------------------------------------------
STATE="$(load_state)"
DB="$(db_state)" || die "failed to read slot state (connection/privileges)"
jq -e . >/dev/null 2>&1 <<<"$DB" || die "database did not return valid JSON"

OPTS="$(jq -nc \
  --argjson grace "$GRACE" \
  --arg orphan_action "$ORPHAN_ACTION" \
  --argjson advance_to_current "$ADVANCE_TO_CURRENT" \
  --argjson drop_lost "$DROP_LOST" \
  --argjson apply "$APPLY" \
  --arg slot_filter "$SLOT_FILTER" \
  '{grace:$grace, orphan_action:$orphan_action, advance_to_current:$advance_to_current,
    drop_lost:$drop_lost, apply:$apply, slot_filter:$slot_filter}')"

PLAN="$(plan "$STATE" "$DB")"

if [[ $APPLY -eq 0 ]]; then
  printf '%s\n' "$PLAN"
  exit 0
fi

LOCKED="$("${PSQL[@]}" -c "SELECT pg_try_advisory_lock($LOCK_KEY)")"
[[ "$LOCKED" == "t" ]] || die "another $PROG run holds the advisory lock"
RESULTS_FILE="$(mktemp "${TMPDIR:-/tmp}/pg-slot-reconcile.XXXXXX")"
cleanup() { rm -f "$RESULTS_FILE"; release_lock; }
trap cleanup EXIT

log "applying plan (grace=${GRACE}s, orphan-action=${ORPHAN_ACTION})"
apply_actions "$PLAN" >"$RESULTS_FILE"
RESULTS="$(cat "$RESULTS_FILE")"

NEW_STATE="$(next_state "$STATE" "$DB" "$PLAN")"
printf '%s\n' "$NEW_STATE" >"$(state_file)"

DB2="$(db_state)"
PLAN2="$(plan "$NEW_STATE" "$DB2")"

jq -nc --argjson plan "$PLAN2" --argjson results "$RESULTS" --argjson rc "$APPLY_RC" '
  $plan
  | .dry_run = false
  | .apply_exit_code = $rc
  | .apply_results = $results
  | .idempotent_after_apply = ([.slots[] | select(.action != "hold")] | length) == 0
  | .remaining_actions_after_apply = [.slots[] | select(.action != "hold") | {slot_name, action}]'

exit "$APPLY_RC"

4. Usage

# dry-run (default) -- emits the JSON plan, changes nothing
PGHOST=/var/run/postgresql PGDATABASE=postgres ./pg_slot_reconcile.sh --grace 600

# apply the plan
./pg_slot_reconcile.sh --apply --grace 600

# keep orphans instead of dropping them, fast-forward their confirmed position
./pg_slot_reconcile.sh --apply --grace 600 --orphan-action=advance

# human-readable one-liner
./pg_slot_reconcile.sh --grace 600 | jq '.summary, (.slots[]|{slot_name,action,reason})'

6. Operational notes

  • Run it from cron in dry-run, alert on summary.over_limit > 0 or summary.at_risk > 0, and run --apply only after the grace window makes orphans obvious.
  • wal_status='lost' on an active slot is an incident: the subscriber has already lost WAL; the plan holds the slot and the alert should trigger a resync. The script never drops it.
  • Advance vs drop. On current PostgreSQL a logical slot's restart_lsn is advanced by decoding, not by pg_replication_slot_advance() alone; the script therefore measures the real effect and defaults to drop for orphans. Use --orphan-action=advance --advance-to-confirmed to keep the slot identity and release only the already-confirmed range.
  • State directory. ${XDG_STATE_HOME:-$HOME/.local/state}/pg-slot-reconcile/, keyed by connection target. Delete it to reset grace clocks after a failover.
  • Privileges. Reader needs SELECT on pg_replication_slots/pg_stat_replication; apply needs the replication privilege (or superuser) for pg_drop_replication_slot/pg_replication_slot_advance.

7. Why this is correct under the three named hazards

Hazard Mechanism in the fix
checkpoint in flight apply re-reads active/restart_lsn/confirmed_flush_lsn in the DO block; a lost drop is absent-safe and an advance on lost is guarded
wal_status='unreserved' surfaced as at_risk/over_limit; inactive → drop/advance, active → hold + required_by_live_subscriber:true
subscriber reconnects between plan and apply in-DO active check → guard refused; plus pg_drop_replication_slot/pg_replication_slot_advance's own ReplicationSlotAcquire(nowait) raises replication slot is active
idempotency per-slot inactive_since + last_advance_target state, and an in-run post-apply re-plan asserting idempotent_after_apply=true
