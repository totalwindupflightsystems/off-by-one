Root cause

The probe needs both RBAC legs provable on the same fixture row: - student leg: assignment not in enrollments → expect 404 - teacher leg: classes.teacher_id IS NOT NULL (teacher owns the class) → expect 200

The old candidate select only guaranteed "unenrolled":

SELECT a.id FROM assignments a
WHERE a.id NOT IN (SELECT assignment_id FROM enrollments WHERE student_id=:student_id)
LIMIT 1;

After the reseed, the only unenrolled assignments sat in teacherless classes (teacher_id IS NULL). The endpoint correctly 404s a non-owning teacher, so the 200 was unprovable by fixture, not broken by product — a false FAIL.

Fix

Join classes and require an owning teacher, and treat zero candidates as a named SKIP rather than a FAIL:

SELECT a.id
  FROM assignments a
  JOIN classes c ON c.id = a.class_id
 WHERE a.id NOT IN (SELECT assignment_id FROM enrollments WHERE student_id = :student_id)
   AND c.teacher_id IS NOT NULL
 LIMIT 1;

if candidate is None:
    return TestResult(status="SKIP",
        reason="fixture-gap: no unenrolled assignment in a teacher-owned class "
               "(classes.teacher_id IS NOT NULL); student=404/teacher=200 unprovable")
