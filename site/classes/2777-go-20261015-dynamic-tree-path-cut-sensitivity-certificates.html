Dynamic Weighted Tree — Path-Cut Sensitivity Certificates (Go 1.26)

Problem class: go-20261015-dynamic-tree-path-cut-sensitivity-certificates

Deliverable: a self-contained, verified Go 1.26 solution for maintaining a weighted tree under edge-weight updates and answering threshold connectivity queries with the lexicographically canonical separating-failure certificate (up to two adversarial edge failures).

0. Executive summary

The problem asks for polylogarithmic updates/queries on a weighted tree, a decision about connectivity below a threshold after up to two adversarial edge failures, and a compact, lexicographically canonical certificate of the separating failures (or a proof that no such certificate exists), while handling equal weights and repeated updates exactly.

The key diagnosis is that on a tree the two-failure budget collapses to at most one failure. The subgraph induced by active edges (weight < threshold) is a forest. In a forest:

  • if u and v are already in different components, the empty set separates them (zero failures), which is cardinality-optimal;
  • if they are in the same component, their path is unique and any single edge of it is a cut, so the minimum separating family has size exactly one.

A size-two family can never beat this, so the canonical answer is:

  • NONE when u == v (no non-empty edge set can separate a vertex from itself),
  • EMPTY when the active path is broken (already separated with 0 failures),
  • otherwise the minimum-id edge on the active u–v path (1 failure).

The implementation is a Heavy-Light Decomposition (HLD) with a segment tree that stores (maximum edge weight, minimum edge id) per position. It answers each query in O(log² n) and each point update in O(log n) using exact integer comparisons, so equal weights and repeated updates are handled exactly.

1. Precise model and interface

Input

n                        # 1 <= n
u v w                    # n-1 lines, edge index i = 1..n-1, 1-based vertices
...
q                        # number of operations
U i x                    # set weight of edge i to x
Q u v theta              # query pair (u,v) at threshold theta

Semantics

  • active(e, theta) := (w[e] < theta) — strictly below the threshold. The strictness makes the equal-weight boundary case exact rather than approximate.
  • Let F(theta) be the forest (V, {e : active(e, theta)}). Since the full graph is a tree, F(theta) is a forest.
  • A separating family for (u,v,theta) is a set S of edges such that deleting S from F(theta) disconnects u from v. The query returns the family that is minimum by cardinality first, then lexicographically smallest by sorted edge-id sequence, subject to |S| <= 2.
  • NONE means no such family exists (only u == v), EMPTY means the empty family is the optimum (already separated), and an integer is the canonical single-edge family.

Complexity target: O(log² n) per query, O(log n) per update, O(n) memory. HLD gives O(log n) path segments; each segment query is O(log n), so O(log² n) total.

2. Root-cause analysis

Subtle points a naive solution gets wrong, and how this solution addresses them:

2.1 The "up to two failures" budget is a red herring on a tree. A common failure mode is to enumerate pairs of edge failures and treat the second failure as meaningful. On a forest it is not: separating u from v requires cutting the unique path, and one edge of that path already does it. The cardinality-first rule therefore always selects the empty set or a singleton. TestTwoFailureCollapse exhaustively checks that no genuine two-edge cut ever appears on a tree.

2.2 Strict vs. non-strict threshold. "Below a threshold" must be w < theta. If a solution uses w <= theta, an edge of weight exactly theta is incorrectly treated as active. Tests pin this down (q(1,2,5) with w=5 yields EMPTY, while q(1,2,6) yields the edge).

2.3 Equal weights and the canonical tie-break. When several path edges share a weight, the certificate must still be unique. The canonical order is on edge ids, not weights, so the segment tree stores the minimum edge id on the path (in addition to the maximum weight used for the threshold decision).

2.4 Repeated updates. Setting an edge to the value it already has, or applying the same update many times, is idempotent: the segment tree's point update overwrites the leaf and recomputes ancestors.

2.5 LCA / path-edge bookkeeping. With the "edge stored at its child vertex" convention, a path query must exclude the LCA's own parent edge. Forgetting the +1 in the final same-chain range is the classic off-by-one. Exercised by chain/star/caterpillar shape tests and randomized differential tests.

2.6 Why HLD and not a heavier dynamic structure. The topology is fixed (only edge-weight updates are required), so Link-Cut Trees are unnecessary. HLD with a segment tree is simpler, iterative (no recursion-depth risk for large n), and meets the polylogarithmic bound. If the problem were extended to link/cut and genuine 2-edge connectivity, it becomes the fully dynamic 2-edge-connectivity problem, a different and much harder class than the stated model.

// Package main implements a solution to the "dynamic weighted tree, path-cut
// sensitivity certificates" problem class.
//
// Model (see the accompanying report for the full derivation):
//
//   - We maintain a weighted tree T = (V, E, w) on n vertices.  The topology is
//     fixed; the only mutations are point updates of edge weights.
//   - An edge e is *active at threshold theta* iff w(e) < theta.  "Below a
//     threshold" is taken strictly; the equality case is therefore decided by
//     the exact integer comparison and never by a tolerance.
//   - A query (u, v, theta) asks for the lexicographically smallest set S of
//     edges with |S| <= 2 whose removal from the active forest separates u and
//     v, minimising |S| first and then the sorted edge-id sequence.
//
// Because the active subgraph of a tree is a forest, the minimum separating set
// is either empty (u and v are already separated in the active forest) or a
// single edge (when an active u-v path exists, any edge of it is a cut).  Hence
// the "at most two" budget is never exhausted: the optimum is always achieved
// with at most one edge, and the canonical answer is the minimum-id edge on the
// active path.  The data structure below answers this in O(log^2 n) per query
// and O(log n) per update with a Heavy-Light Decomposition plus a segment tree
// that stores (maximum edge weight, minimum edge id) on each path.
package main

import (
    "bufio"
    "fmt"
    "io"
    "os"
    "strconv"
)

const (
    inf int64 = 1 << 60
    neg int64 = -inf
)

// ---------- segment tree over the HLD base array ----------
//
// Leaf at position p (1-indexed) stores the edge that connects the vertex with
// position p to its parent (or (neg, +inf) for the root / a vertex with no
// parent edge).  Internal nodes store the component-wise maximum weight and
// minimum edge id.

type segTree struct {
    size  int
    maxW  []int64
    minID []int
}

func newSegTree(n int, baseW []int64, baseID []int) *segTree {
    size := 1
    for size < n {
        size <<= 1
    }
    s := &segTree{
        size:  size,
        maxW:  make([]int64, 2*size),
        minID: make([]int, 2*size),
    }
    for i := 0; i < 2*size; i++ {
        s.maxW[i] = neg
        s.minID[i] = int(^uint(0) >> 1) // max int
    }
    for p := 1; p <= n; p++ {
        s.maxW[size+p-1] = baseW[p]
        s.minID[size+p-1] = baseID[p]
    }
    for i := size - 1; i >= 1; i-- {
        s.pull(i)
    }
    return s
}

func (s *segTree) pull(i int) {
    l, r := 2*i, 2*i+1
    if s.maxW[l] >= s.maxW[r] {
        s.maxW[i] = s.maxW[l]
    } else {
        s.maxW[i] = s.maxW[r]
    }
    if s.minID[l] <= s.minID[r] {
        s.minID[i] = s.minID[l]
    } else {
        s.minID[i] = s.minID[r]
    }
}

func (s *segTree) update(pos int, w int64, id int) {
    i := s.size + pos - 1
    s.maxW[i] = w
    s.minID[i] = id
    for i >>= 1; i >= 1; i >>= 1 {
        s.pull(i)
    }
}

// query returns the aggregate (max weight, min id) on the inclusive 1-indexed
// range [l, r].  Returns (neg, maxInt) for an empty range.
func (s *segTree) query(l, r int) (int64, int) {
    if l > r {
        return neg, int(^uint(0) >> 1)
    }
    l = l - 1 + s.size
    r = r - 1 + s.size
    mx := neg
    mi := int(^uint(0) >> 1)
    for l <= r {
        if l&1 == 1 {
            if s.maxW[l] > mx {
                mx = s.maxW[l]
            }
            if s.minID[l] < mi {
                mi = s.minID[l]
            }
            l++
        }
        if r&1 == 0 {
            if s.maxW[r] > mx {
                mx = s.maxW[r]
            }
            if s.minID[r] < mi {
                mi = s.minID[r]
            }
            r--
        }
        l >>= 1
        r >>= 1
    }
    return mx, mi
}

// ---------- dynamic weighted tree ----------

type edgeRef struct {
    to int
    id int
}

// Tree is a static-topology weighted tree with point edge-weight updates and
// O(log^2 n) path queries.
type Tree struct {
    n      int
    eu, ev []int
    ew     []int64

    adj        [][]edgeRef
    parent     []int
    depth      []int
    heavy      []int
    head       []int
    pos        []int
    parentEdge []int
    childEdge  []int // childEdge[e]  = deeper endpoint of edge e

    seg *segTree
}

// NewTree builds the HLD for an n-vertex tree.  Edges are 1-indexed: edge i
// connects eu[i] and ev[i] and initially has weight ew[i].
func NewTree(n int, eu, ev []int, ew []int64) *Tree {
    t := &Tree{
        n:          n,
        eu:         eu,
        ev:         ev,
        ew:         ew,
        adj:        make([][]edgeRef, n+1),
        parent:     make([]int, n+1),
        depth:      make([]int, n+1),
        heavy:      make([]int, n+1),
        head:       make([]int, n+1),
        pos:        make([]int, n+1),
        parentEdge: make([]int, n+1),
        childEdge:  make([]int, n),
    }
    for i := 1; i < n; i++ {
        u, v := eu[i], ev[i]
        t.adj[u] = append(t.adj[u], edgeRef{v, i})
        t.adj[v] = append(t.adj[v], edgeRef{u, i})
    }

    // Iterative preorder (parents before children).
    order := make([]int, 0, n)
    stack := []int{1}
    seen := make([]bool, n+1)
    seen[1] = true
    for len(stack) > 0 {
        x := stack[len(stack)-1]
        stack = stack[:len(stack)-1]
        order = append(order, x)
        for _, e := range t.adj[x] {
            if !seen[e.to] {
                seen[e.to] = true
                t.parent[e.to] = x
                t.depth[e.to] = t.depth[x] + 1
                t.parentEdge[e.to] = e.id
                t.childEdge[e.id] = e.to
                stack = append(stack, e.to)
            }
        }
    }

    // Subtree sizes and heavy child (reverse preorder).
    size := make([]int, n+1)
    for i := len(order) - 1; i >= 0; i-- {
        x := order[i]
        size[x] = 1
        best := 0
        for _, e := range t.adj[x] {
            if e.to == t.parent[x] {
                continue
            }
            size[x] += size[e.to]
            if size[e.to] > best {
                best = size[e.to]
                t.heavy[x] = e.to
            }
        }
    }

    // Heavy-light positions.  Each chain occupies a contiguous range.
    cur := 1
    type item struct{ v, h int }
    dstack := []item{{1, 1}}
    for len(dstack) > 0 {
        it := dstack[len(dstack)-1]
        dstack = dstack[:len(dstack)-1]
        v, h := it.v, it.h
        for v != 0 {
            t.head[v] = h
            t.pos[v] = cur
            cur++
            for _, e := range t.adj[v] {
                if e.to != t.parent[v] && e.to != t.heavy[v] {
                    dstack = append(dstack, item{e.to, e.to})
                }
            }
            v = t.heavy[v]
        }
    }

    baseW := make([]int64, n+1)
    baseID := make([]int, n+1)
    maxInt := int(^uint(0) >> 1)
    for v := 1; v <= n; v++ {
        if v == 1 {
            baseW[t.pos[v]] = neg
            baseID[t.pos[v]] = maxInt
        } else {
            baseW[t.pos[v]] = t.ew[t.parentEdge[v]]
            baseID[t.pos[v]] = t.parentEdge[v]
        }
    }
    t.seg = newSegTree(n, baseW, baseID)
    return t
}

// UpdateWeight sets the weight of edge id to w.
func (t *Tree) UpdateWeight(id int, w int64) {
    t.ew[id] = w
    child := t.childEdge[id]
    t.seg.update(t.pos[child], w, id)
}

// PathAggregate returns (max edge weight, min edge id) on the u-v path.
// For u == v it returns (neg, maxInt).
func (t *Tree) PathAggregate(u, v int) (int64, int) {
    maxInt := int(^uint(0) >> 1)
    mx, mi := neg, maxInt
    for t.head[u] != t.head[v] {
        if t.depth[t.head[u]] < t.depth[t.head[v]] {
            u, v = v, u
        }
        w, id := t.seg.query(t.pos[t.head[u]], t.pos[u])
        if w > mx {
            mx = w
        }
        if id < mi {
            mi = id
        }
        u = t.parent[t.head[u]]
    }
    if u != v {
        if t.depth[u] > t.depth[v] {
            u, v = v, u
        }
        // u is now the LCA; exclude its own parent edge.
        w, id := t.seg.query(t.pos[u]+1, t.pos[v])
        if w > mx {
            mx = w
        }
        if id < mi {
            mi = id
        }
    }
    return mx, mi
}

// Certificate describes the canonical separating answer.
type Certificate struct {
    // Kind is one of CertNone, CertEmpty, CertSingle.
    Kind int
    // Edge is valid when Kind == CertSingle.
    Edge int
}

const (
    // CertNone: no set of edge failures can separate the pair (u == v).
    CertNone = iota
    // CertEmpty: the pair is already separated in the active forest, so the
    // empty set is the canonical (0-edge) certificate.
    CertEmpty
    // CertSingle: a single edge separates the pair; Edge is its id.
    CertSingle
    // CertDouble is used only by the brute-force oracle when a genuine
    // two-edge cut is required.  It never occurs on a tree.
    CertDouble
)

// Query returns the lexicographically canonical minimum-cardinality edge set
// of size at most two that separates u and v in the forest of edges with
// weight strictly below theta.
func (t *Tree) Query(u, v int, theta int64) Certificate {
    if u == v {
        return Certificate{Kind: CertNone}
    }
    mx, mn := t.PathAggregate(u, v)
    if mx < theta {
        // The whole path is active: connected, and any path edge is a cut.
        // The minimum-id path edge is the canonical one-edge certificate.
        return Certificate{Kind: CertSingle, Edge: mn}
    }
    // Some path edge is inactive, so u and v are already separated with zero
    // failures.  The empty set is canonical and beats any non-empty set by
    // cardinality.
    return Certificate{Kind: CertEmpty}
}

// ---------- brute force reference (used by tests and by -brute mode) ----------

// BruteQuery enumerates all edge subsets of size at most two and returns the
// cardinality-minimal, lexicographically-smallest separating set in the active
// forest.  It runs in O(n^3) and is intended only for validation.
func BruteQuery(n int, eu, ev []int, ew []int64, u, v int, theta int64) Certificate {
    if u == v {
        return Certificate{Kind: CertNone}
    }
    m := n - 1
    // helper: are u and v connected after deleting the given edges?
    connected := func(del []int) bool {
        removed := make([]bool, m+1)
        for _, id := range del {
            removed[id] = true
        }
        adj := make([][]int, n+1)
        for i := 1; i <= m; i++ {
            if removed[i] {
                continue
            }
            if ew[i] < theta {
                adj[eu[i]] = append(adj[eu[i]], ev[i])
                adj[ev[i]] = append(adj[ev[i]], eu[i])
            }
        }
        seen := make([]bool, n+1)
        stack := []int{u}
        seen[u] = true
        for len(stack) > 0 {
            x := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            if x == v {
                return true
            }
            for _, y := range adj[x] {
                if !seen[y] {
                    seen[y] = true
                    stack = append(stack, y)
                }
            }
        }
        return false
    }
    // size 0
    if !connected(nil) {
        return Certificate{Kind: CertEmpty}
    }
    // size 1
    for i := 1; i <= m; i++ {
        if !connected([]int{i}) {
            return Certificate{Kind: CertSingle, Edge: i}
        }
    }
    // size 2, lexicographic (i increasing, then j increasing)
    for i := 1; i <= m; i++ {
        for j := i + 1; j <= m; j++ {
            if !connected([]int{i, j}) {
                // We only encode the single-edge case in Certificate; the
                // brute force returning a two-edge cut is surfaced by tests
                // that need it.  For a tree it never happens.
                return Certificate{Kind: CertDouble, Edge: i*(m+1) + j}
            }
        }
    }
    return Certificate{Kind: CertNone}
}

// ---------- CLI ----------

func mustInt(s string) int {
    x, err := strconv.Atoi(s)
    if err != nil {
        panic(err)
    }
    return x
}

func mustI64(s string) int64 {
    x, err := strconv.ParseInt(s, 10, 64)
    if err != nil {
        panic(err)
    }
    return x
}

func main() {
    if len(os.Args) > 1 && os.Args[1] == "-brute" {
        runBrute(os.Stdin, os.Stdout)
        return
    }
    runFast(os.Stdin, os.Stdout)
}

func runFast(in io.Reader, out io.Writer) {
    r := bufio.NewReaderSize(in, 1<<20)
    w := bufio.NewWriterSize(out, 1<<20)
    defer w.Flush()
    readInt := func() int {
        s := readToken(r)
        return mustInt(s)
    }
    readI64 := func() int64 {
        s := readToken(r)
        return mustI64(s)
    }
    n := readInt()
    eu := make([]int, n)
    ev := make([]int, n)
    ew := make([]int64, n)
    for i := 1; i < n; i++ {
        eu[i] = readInt()
        ev[i] = readInt()
        ew[i] = readI64()
    }
    t := NewTree(n, eu, ev, ew)
    q := readInt()
    for ; q > 0; q-- {
        op := readToken(r)
        switch op {
        case "U":
            id := readInt()
            x := readI64()
            t.UpdateWeight(id, x)
        case "Q":
            u := readInt()
            v := readInt()
            theta := readI64()
            c := t.Query(u, v, theta)
            switch c.Kind {
            case CertNone:
                fmt.Fprintln(w, "NONE")
            case CertEmpty:
                fmt.Fprintln(w, "EMPTY")
            case CertSingle:
                fmt.Fprintln(w, c.Edge)
            default:
                fmt.Fprintln(w, "NONE")
            }
        default:
            // tolerate EOF / blank
        }
    }
}

// readToken reads the next whitespace-separated token.
func readToken(r *bufio.Reader) string {
    for {
        b, err := r.ReadByte()
        if err != nil {
            return ""
        }
        if b == ' ' || b == '\n' || b == '\r' || b == '\t' {
            continue
        }
        buf := []byte{b}
        for {
            c, err := r.ReadByte()
            if err != nil {
                return string(buf)
            }
            if c == ' ' || c == '\n' || c == '\r' || c == '\t' {
                return string(buf)
            }
            buf = append(buf, c)
        }
    }
}

func TestUpdateAndRepeatedUpdates(t *testing.T) {
    n := 5

        tr.UpdateWeight(i, 9)
    }
    if c := tr.Query(1, 5, 9); c.Kind != CertEmpty {
        t.Fatalf("all weight 9, theta 9 should be empty, got %+v", c)

}

func randTree(rng *rand.Rand, n int, maxW int64) ([]int, []int, []int64) {
    eu := make([]int, n)
    ev := make([]int, n)
    ew := make([]int64, n)
    for v := 2; v <= n; v++ {
        p := rng.Intn(v-1) + 1
        eu[v-1] = p
        ev[v-1] = v
        ew[v-1] = int64(rng.Intn(int(maxW)) + 1)
    }
    return eu, ev, ew
}

4.4 Correctness argument (proof sketch)

  1. F(theta) is a subgraph of a tree, hence a forest.
  2. If u and v lie in different components of F(theta), the empty set is a separating family; by cardinality minimality it is optimal, so the canonical answer is EMPTY.
  3. Otherwise the unique F(theta)-path P exists. Removing any e ∈ P disconnects u and v, so {e} separates and the minimum cardinality is 1. Among singletons the lexicographic minimum is the minimum edge id in P; a two-element family has larger cardinality and cannot win.
  4. The segment tree stores (max weight, min id); P's maximum weight < theta is exactly the test for P ⊆ E_active, and P's minimum id is exactly the canonical singleton. HLD decomposes P into O(log n) contiguous ranges combined in O(log n) each, giving O(log² n) per query.

5. Notes on alternative readings

  • "The adversary must place exactly two failures" — on a tree the minimum cut is still one edge; any pair containing a path edge is also separating but is not cardinality-optimal, so the canonical minimum remains a singleton or the empty set.
  • "Remain connected for every possible pair of failures" (2-edge robustness) — in a tree every distinct pair is separated by a single path edge, so robustness holds only for u == v; the certificate of failure of robustness is exactly the singleton produced here.

If the intended graph had non-tree edges (cycles), the problem would become dynamic 2-edge-connectivity and the two-failure budget would be essential. The statement specifies a tree and only edge-weight updates, so the collapse above is the correct diagnosis.
