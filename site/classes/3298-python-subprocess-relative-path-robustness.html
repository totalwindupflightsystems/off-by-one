What was diagnosed

When PATH has a relative entry (PATH=".venv/bin:$PATH"), CPython sets sys.executable to the relative string .venv/bin/python. subprocess.run([sys.executable, ...], cwd=scratch) passes a slash-containing program path, which POSIX execve resolves against the child's cwd → FileNotFoundError. The repo-root spawn passes only by accident.

Three mediator shapes are affected: direct argv, argv = [sys.executable, ...] variables, and command strings handed to shell=True/custom executors.

Exact fix

os.path.abspath(sys.executable) at every spawn with a non-root cwd, captured at import time (before any chdir); do not use realpath — the uv venv bin/python is a symlink, so realpath resolves to /usr/bin/python3.14 and drops the venv.
