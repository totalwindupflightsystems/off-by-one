Stratified Datalog with Semiring Provenance and Exact Incremental Maintenance

Problem class: python-20261017-datalog-provenance-semiring-negation-fixpoint Language: Python 3.12+ (verified on CPython 3.14) Verified artifacts: datalog_provenance.py, test_datalog_provenance.py, demo.py, SOLUTION.md in ~/solution/.

1. Root-cause analysis

The spec asks for four things that interact badly when implemented naively: an arbitrary commutative semiring, provenance polynomials, stratified negation and aggregation, and exact incremental insert/delete (the over-deletion problem).

1.1 Naive fixpoint evaluation double-counts derivations

The obvious loop

repeat:
    for each ground rule r:
        prov[head(r)] += product(prov[body(r)])
until no change

re-applies every rule every round. For idempotent semirings (Bool with or, Tropical with min) re-adding is harmless. For Nat (bag multiplicities) and provenance polynomials ℕ[X] the same derivation is added again and again: x_q, then 2·x_q, then 3·x_q, … and never stabilises. Fix: iterate the Kleene sequence D₀ = ⊥, D_{n+1} = F(D_n) where F is recomputed from scratch each round rather than accumulated. F(D_n) contains exactly the derivation trees of height ≤ n+1, each once. Stop at the first D_{n+1} = D_n.

1.2 Deletion over-deletes

"Delete f and everything derived from f" kills facts that have an alternative derivation not using f. Subtraction is impossible: Nat, Bool and Tropical have no additive inverse. Fix (DRed / delete-and-rederive): over-delete the affected region (predicates forward-reachable from the changed predicate in the body→head dependency graph), then recompute only that region from the surviving base facts plus unaffected derived facts. Anything outside the region is provably independent of f. Negation must follow edges regardless of polarity, because deleting a fact can flip not f to true and create new derivations.

1.3 Negation and aggregation are non-monotone — they need strata

p(x) :- not q(x) with q(x) :- p(x) has no stratified model, and aggregation changes the derived tuple identity when inputs change. Fix: contract SCCs of the dependency graph and topologically order them. A negative or aggregation edge inside an SCC raises StratificationError. Strata are evaluated in order, so a negated atom is always read after its relation is complete.

1.4 Non-idempotent provenance over cyclic data is infinite

With ℕ[X] and recursion over a cyclic graph there are infinitely many derivation trees; no finite least fixpoint exists. Fix: bounded Kleene iteration raises ProvenanceConvergenceError instead of looping. Recursive strata work fully for idempotent semirings (Bool, Tropical) or when derivations are finite (e.g. transitive closure on a DAG).

1.5 Byte-identical comparison needs a canonical total order

Facts can contain mixed constant types (int and str), which Python cannot order with <. A repr-based total order on variables/monomials makes canonical_snapshot() deterministic.

2. The fix — architecture and exactness

  • Semiring (zero, one, add, mult) with BoolSemiring, NatSemiring, TropicalSemiring, PolynomialSemiring(K).
  • Polynomial implements K[X]; evaluate_polynomial is the homomorphism K[X] → S that turns one polynomial into why-provenance, bag multiplicity and min-cost.
  • DatalogEngine(semiring): evaluate() full stratified evaluation; insert_batch / delete_batch region-incremental maintenance.
  • _fixpoint: Kleene iteration of §1.1. _stratify: Tarjan SCC + topological condensation. _forward_reachable: DRed region. canonical_snapshot: sorted JSON for byte comparison.

Exactness. For F(P)(h) = Σ_{r: head(r)=h} Π_{positive bodies} P(b) · [negated bodies absent], D_n = Fⁿ(⊥) is exactly the semiring sum over all derivation trees of height ≤ n; the first fixpoint is the sum over all derivations (Green–Karvounarakis–Tannen semantics). For maintenance, a base fact of predicate p can only change predicates forward-reachable from p, so replacing that region with its least fixpoint equals full recomputation; hence incremental and full states are byte-identical after every batch. Negated literals contribute the multiplicative identity when absent and kill the rule otherwise; an aggregate fact's provenance is the product of its whole input group's annotations.

3. datalog_provenance.py

"""
Stratified Datalog with provenance over an arbitrary commutative semiring,
plus exact incremental maintenance on base-fact insert / delete.

Design
------
* A fact is a pair ``(pred, args)`` with ``args`` a tuple of constants.
* The engine is parameterised by a commutative semiring ``K``.  Each fact is
  annotated with a value in ``K``.  A base fact ``f`` gets the annotation the
  caller supplies (default ``K.one()``); the annotation of a derived fact is

      prov(head) = K.add over all grounding derivations of
                       K.mult over the annotations of the positive body atoms

  which is exactly the "semiring sum over all rule derivations" required by the
  task.  Choosing ``K`` = Bool / Nat / Tropical / a polynomial semiring gives
  why-provenance, bag multiplicities, min-cost, or full provenance polynomials.

* Stratification: predicates are grouped into SCCs of the dependency graph
  (edge body -> head).  Negated and aggregation edges must cross SCC boundaries
  (strictly increasing stratum), otherwise ``StratificationError`` is raised.
  Strata are evaluated in topological order, so a negated atom is always read
  after the predicate it negates is fully computed.

* Incremental maintenance: changing a base predicate ``p`` can only influence
  predicates forward-reachable from ``p`` in the dependency graph.  The engine
  resets exactly those derived predicates (a DRed-style over-deletion) and
  re-runs the fixpoint on the affected region only, leaving everything else
  untouched.  Alternatives that do not use the deleted fact are re-derived, so
  the over-deletion problem is solved without subtraction and without
  recomputing the whole program.

This module is self-contained; tests live in ``test_datalog_provenance.py``.
"""

from __future__ import annotations

from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import Any, Callable, Dict, Iterable, Iterator, List, Optional, Sequence, Tuple


# --------------------------------------------------------------------------- #
# Semirings
# --------------------------------------------------------------------------- #
class Semiring(ABC):
    """A commutative semiring ``(K, +, *, 0, 1)``."""

    name = "Semiring"
    idempotent = False  # True when a + a == a for every a

    @abstractmethod
    def zero(self) -> Any: ...

    @abstractmethod
    def one(self) -> Any: ...

    @abstractmethod
    def add(self, a: Any, b: Any) -> Any: ...

    @abstractmethod
    def mult(self, a: Any, b: Any) -> Any: ...

    def is_zero(self, a: Any) -> bool:
        return a == self.zero()

    def is_one(self, a: Any) -> bool:
        return a == self.one()

    def value_repr(self, a: Any) -> Any:
        """Deterministic, JSON-friendly representation used for byte comparisons."""
        return a


class BoolSemiring(Semiring):
    """``({False, True}, or, and, False, True)`` -- set / why existence."""

    name = "Bool"
    idempotent = True

    def zero(self) -> bool:
        return False

    def one(self) -> bool:
        return True

    def add(self, a: bool, b: bool) -> bool:
        return bool(a) or bool(b)

    def mult(self, a: bool, b: bool) -> bool:
        return bool(a) and bool(b)


class NatSemiring(Semiring):
    """``(N, +, *, 0, 1)`` -- bag multiplicities / derivation counts."""

    name = "Nat"

    def zero(self) -> int:
        return 0

    def one(self) -> int:
        return 1

    def add(self, a: int, b: int) -> int:
        return a + b

    def mult(self, a: int, b: int) -> int:
        return a * b


class TropicalSemiring(Semiring):
    """Min-plus ``(R u {+inf}, min, +, +inf, 0)`` -- least-cost derivations."""

    name = "Tropical"
    idempotent = True

    def zero(self) -> float:
        return float("inf")

    def one(self) -> float:
        return 0.0

    def add(self, a: float, b: float) -> float:
        return a if a <= b else b

    def mult(self, a: float, b: float) -> float:
        return a + b


# --------------------------------------------------------------------------- #
# Polynomials K[X] over a coefficient semiring K
# --------------------------------------------------------------------------- #
def _key(x: Any) -> Tuple[str, str]:
    """Total order on arbitrary constants/variables for canonical forms."""
    return (type(x).__name__, repr(x))


def _mono_key(mono: Tuple[Any, ...]) -> Tuple[int, Tuple[Tuple[str, str], ...]]:
    return (len(mono), tuple(_key(v) for v in mono))


class Polynomial:
    """A commutative polynomial with coefficients in ``coeff``.

    A monomial is a canonical (sorted) tuple of variable identifiers; the empty
    tuple is the constant monomial.
    """

    __slots__ = ("coeff", "terms")

    def __init__(self, coeff: Semiring, terms: Optional[Dict[Tuple[Any, ...], Any]] = None):
        self.coeff = coeff
        out: Dict[Tuple[Any, ...], Any] = {}
        for mono, c in (terms or {}).items():
            mono = tuple(sorted(mono, key=_key))
            if coeff.is_zero(c):
                continue
            if mono in out:
                out[mono] = coeff.add(out[mono], c)
                if coeff.is_zero(out[mono]):
                    del out[mono]
            else:
                out[mono] = c
        self.terms = out

    # -- constructors ------------------------------------------------------- #
    @classmethod
    def const(cls, coeff: Semiring, value: Any) -> "Polynomial":
        return cls(coeff, {(): value})

    @classmethod
    def var(cls, coeff: Semiring, name: Any) -> "Polynomial":
        return cls(coeff, {(name,): coeff.one()})

    # -- semiring ops ------------------------------------------------------- #
    def add(self, other: "Polynomial") -> "Polynomial":
        out = dict(self.terms)
        for mono, c in other.terms.items():
            if mono in out:
                out[mono] = self.coeff.add(out[mono], c)
                if self.coeff.is_zero(out[mono]):
                    del out[mono]
            else:
                out[mono] = c
        return Polynomial(self.coeff, out)

    def mult(self, other: "Polynomial") -> "Polynomial":
        out: Dict[Tuple[Any, ...], Any] = {}
        for m1, c1 in self.terms.items():
            for m2, c2 in other.terms.items():
                mono = tuple(sorted(m1 + m2, key=_key))
                c = self.coeff.mult(c1, c2)
                if self.coeff.is_zero(c):
                    continue
                if mono in out:
                    out[mono] = self.coeff.add(out[mono], c)
                    if self.coeff.is_zero(out[mono]):
                        del out[mono]
                else:
                    out[mono] = c
        return Polynomial(self.coeff, out)

    def is_zero(self) -> bool:
        return not self.terms

    # -- comparison / serialisation ---------------------------------------- #
    def __eq__(self, other: object) -> bool:
        return isinstance(other, Polynomial) and self.terms == other.terms

    def __hash__(self) -> int:
        return hash(tuple(sorted(
            ((_mono_key(m), self.coeff.value_repr(c)) for m, c in self.terms.items()),
            key=lambda x: (x[0], repr(x[1])))))

    def canonical(self) -> Any:
        def rep(c: Any) -> Any:
            return self.coeff.value_repr(c)
        return tuple(sorted(((_mono_key(mono), rep(c)) for mono, c in self.terms.items()),
                            key=lambda x: (x[0], repr(x[1]))))

    def __repr__(self) -> str:
        if not self.terms:
            return "0"
        parts = []
        for mono, c in sorted(self.terms.items(), key=lambda kv: _mono_key(kv[0])):
            var = "*".join(str(v) for v in mono) if mono else "1"
            parts.append(f"{c}*{var}")
        return " + ".join(parts)


class PolynomialSemiring(Semiring):
    """``K[X]`` -- the free commutative semiring on a set of variables.

    Variables are arbitrary hashable identifiers (here: base-fact keys).  The
    coefficient semiring is ``coeff``.
    """

    name = "Polynomial"

    def __init__(self, coeff: Optional[Semiring] = None):
        self.coeff = coeff or NatSemiring()
        self.idempotent = self.coeff.idempotent

    def zero(self) -> Polynomial:
        return Polynomial(self.coeff, {})

    def one(self) -> Polynomial:
        return Polynomial(self.coeff, {(): self.coeff.one()})

    def add(self, a: Polynomial, b: Polynomial) -> Polynomial:
        return a.add(b)

    def mult(self, a: Polynomial, b: Polynomial) -> Polynomial:
        return a.mult(b)

    def is_zero(self, a: Polynomial) -> bool:
        return a.is_zero()

    def var(self, name: Any) -> Polynomial:
        return Polynomial.var(self.coeff, name)

    def value_repr(self, a: Polynomial) -> Any:
        return a.canonical()

def is_var(term: Any) -> bool:
    return isinstance(term, str) and term.startswith("?")


@dataclass(frozen=True)
class Atom:
    pred: str
    args: Tuple[Any, ...]

    def __post_init__(self):
        object.__setattr__(self, "args", tuple(self.args))


@dataclass(frozen=True)
class Literal:
    atom: Atom
    negated: bool = False


@dataclass
class Rule:
    head: Atom
    body: Tuple[Literal, ...]

    def __init__(self, head: Atom, body: Sequence[Literal]):
        self.head = head
        self.body = tuple(body)


@dataclass(frozen=True)
class AggSpec:
    """A stratified aggregation.

    ``head_pred`` is populated with ``key_vars + (aggregate_value,)`` for every
    group of ``src``.  The annotation of the aggregate fact is the semiring
    product of the annotations of the contributing ``src`` facts (an aggregate
    depends on its *whole* input group).

    ``agg`` is one of ``count``, ``sum``, ``min``, ``max``, ``avg``.
    ``value_var`` names the argument of ``src`` holding the numeric value
    (ignored for ``count``).
    """

    head_pred: str
    src: Atom
    key_vars: Tuple[str, ...]
    agg: str
    value_var: Optional[str] = None

    def __post_init__(self):
        if self.agg not in ("count", "sum", "min", "max", "avg"):
            raise ValueError(f"unknown aggregate {self.agg!r}")
        src_vars = {a for a in self.src.args if is_var(a)}
        for v in self.key_vars:
            if v not in src_vars:
                raise ValueError(f"group variable {v!r} is not bound by {self.src}")
        if self.value_var is not None and self.value_var not in src_vars:
            raise ValueError(f"value variable {self.value_var!r} is not bound by {self.src}")
        if self.agg != "count" and self.value_var is None:
            raise ValueError(f"aggregate {self.agg!r} requires a value variable")

# --------------------------------------------------------------------------- #
# Helpers
# --------------------------------------------------------------------------- #
def _instantiate(atom: Atom, binding: Dict[str, Any]) -> Tuple[str, Tuple[Any, ...]]:
    args = []
    for a in atom.args:
        if is_var(a):
            if a not in binding:
                raise RuleSafetyError(f"unbound variable {a} in head {atom}")
            args.append(binding[a])
        else:
            args.append(a)
    return (atom.pred, tuple(args))


def _match(pattern: Tuple[Any, ...], facts: Iterable[Tuple[Any, ...]],
           binding: Dict[str, Any]) -> Iterator[Tuple[Dict[str, Any], Tuple[Any, ...]]]:
    for gargs in facts:
        b = dict(binding)
        ok = True
        for p, g in zip(pattern, gargs):
            if is_var(p):
                if p in b:
                    if b[p] != g:
                        ok = False
                        break
                else:
                    b[p] = g
            elif p != g:
                ok = False
                break
        if ok:
            yield b, gargs


def _solve_body(body: Tuple[Literal, ...], i: int, binding: Dict[str, Any],
                index: Dict[str, Dict[Tuple[Any, ...], Any]],
                K: Semiring) -> Iterator[Tuple[Dict[str, Any], Any]]:
    """Yield ``(binding, provenance)`` for every grounding of ``body[i:]``."""
    if i == len(body):
        yield binding, K.one()
        return
    lit = body[i]
    table = index.get(lit.atom.pred, {})
    if lit.negated:
        for _b, _g in _match(lit.atom.args, list(table.keys()), binding):
            return  # negated atom is true; rule does not fire
        yield from _solve_body(body, i + 1, binding, index, K)
    else:
        for b, gargs in _match(lit.atom.args, list(table.keys()), binding):
            bodyval = table[gargs]
            if K.is_zero(bodyval):
                continue
            for b2, rest in _solve_body(body, i + 1, b, index, K):
                yield b2, K.mult(bodyval, rest)


# --------------------------------------------------------------------------- #
# Engine
# --------------------------------------------------------------------------- #
class DatalogEngine:
    def __init__(self, semiring: Optional[Semiring] = None, max_iterations: int = 100000):
        self.K: Semiring = semiring or BoolSemiring()
        self.rules: List[Rule] = []
        self.agg_specs: List[AggSpec] = []
        self.base: Dict[Tuple[str, Tuple[Any, ...]], Any] = {}
        self.prov: Dict[Tuple[str, Tuple[Any, ...]], Any] = {}
        self.max_iterations = max_iterations
        self._strata: Optional[List[set]] = None
        self._deps: Dict[str, List[Tuple[str, bool]]] = {}
        self._preds: set = set()
        self._derived_preds: set = set()
        self._rule_head_preds: set = set()
        self._agg_head_preds: set = set()

    # -- program construction ---------------------------------------------- #
    def add_rule(self, head: Atom, body: Sequence[Literal]) -> "DatalogEngine":
        self.rules.append(Rule(head, body))
        self._strata = None
        return self

    def add_aggregate(self, spec: AggSpec) -> "DatalogEngine":
        self.agg_specs.append(spec)
        self._strata = None
        return self

    # -- base facts --------------------------------------------------------- #
    def add_base_fact(self, pred: str, args: Sequence[Any], ann: Any = None) -> None:
        fact = (pred, tuple(args))
        a = self.K.one() if ann is None else ann
        self.base[fact] = self.K.add(self.base.get(fact, self.K.zero()), a)
        self.prov[fact] = self.base[fact]

    def delete_base_fact(self, pred: str, args: Sequence[Any]) -> None:
        fact = (pred, tuple(args))
        self.base.pop(fact, None)
        self.prov.pop(fact, None)

    # -- validation / stratification --------------------------------------- #
    def _rebuild(self) -> None:
        deps: Dict[str, List[Tuple[str, bool]]] = {}
        preds: set = set()
        head_preds: set = set()
        for r in self.rules:
            head_preds.add(r.head.pred)
            preds.add(r.head.pred)
            for lit in r.body:
                preds.add(lit.atom.pred)
                deps.setdefault(r.head.pred, []).append((lit.atom.pred, lit.negated))
        for s in self.agg_specs:
            head_preds.add(s.head_pred)
            preds.add(s.head_pred)
            preds.add(s.src.pred)
            # aggregation is non-monotone: treat as a strict (negative-like) edge
            deps.setdefault(s.head_pred, []).append((s.src.pred, True))
        if self.base and (head_preds & set(p for p, _ in self.base)):
            clash = head_preds & set(p for p, _ in self.base)
            raise DatalogError(f"predicates used as both base and derived: {sorted(clash)}")

        self._check_safety()
        self._preds = preds
        self._deps = deps
        self._rule_head_preds = {r.head.pred for r in self.rules}
        self._agg_head_preds = {s.head_pred for s in self.agg_specs}
        self._derived_preds = self._rule_head_preds | self._agg_head_preds
        self._strata = self._stratify(preds, deps)

    def _check_safety(self) -> None:
        for r in self.rules:
            positive_vars: set = set()
            for lit in r.body:
                if not lit.negated:
                    for a in lit.atom.args:
                        if is_var(a):
                            positive_vars.add(a)
            for lit in r.body:
                if lit.negated:
                    for a in lit.atom.args:
                        if is_var(a) and a not in positive_vars:
                            raise RuleSafetyError(
                                f"unsafe negation in rule {r.head}: {a} not bound positively")
            for a in r.head.args:
                if is_var(a) and a not in positive_vars:
                    raise RuleSafetyError(
                        f"unsafe rule {r.head}: head variable {a} not bound in body")

    def _stratify(self, preds: set, deps: Dict[str, List[Tuple[str, bool]]]) -> List[set]:
        # Tarjan SCC over edges body -> head.
        index: Dict[str, int] = {}
        low: Dict[str, int] = {}
        on_stack: set = set()
        stack: List[str] = []
        comps: List[set] = []
        counter = [0]

        adj: Dict[str, List[str]] = {p: [] for p in preds}
        for head, bodydeps in deps.items():
            for body, _neg in bodydeps:
                adj.setdefault(body, []).append(head)

        def strongconnect(v: str) -> None:
            index[v] = low[v] = counter[0]
            counter[0] += 1
            stack.append(v)
            on_stack.add(v)
            for w in adj.get(v, []):
                if w not in index:
                    strongconnect(w)
                    low[v] = min(low[v], low[w])
                elif w in on_stack:
                    low[v] = min(low[v], index[w])
            if low[v] == index[v]:
                comp: set = set()
                while True:
                    w = stack.pop()
                    on_stack.discard(w)
                    comp.add(w)
                    if w == v:
                        break
                comps.append(comp)

        for p in sorted(preds):
            if p not in index:
                strongconnect(p)

        comp_of: Dict[str, int] = {}
        for i, comp in enumerate(comps):
            for p in comp:
                comp_of[p] = i

        # strict edges (negation / aggregation) must not be inside an SCC
        for head, bodydeps in deps.items():
            for body, strict in bodydeps:
                if strict and comp_of[body] == comp_of[head]:
                    raise StratificationError(
                        "program is not stratified: strict edge "
                        f"{body} -> {head} lies inside a recursive component")

        # condensation DAG body_comp -> head_comp, topological order
        cadj: Dict[int, set] = {i: set() for i in range(len(comps))}
        indeg: Dict[int, int] = {i: 0 for i in range(len(comps))}
        for head, bodydeps in deps.items():
            for body, _strict in bodydeps:
                a, b = comp_of[body], comp_of[head]
                if a != b and b not in cadj[a]:
                    cadj[a].add(b)
                    indeg[b] += 1
        from collections import deque
        q = deque(sorted(i for i in range(len(comps)) if indeg[i] == 0))
        order: List[int] = []
        while q:
            i = q.popleft()
            order.append(i)
            for j in sorted(cadj[i]):
                indeg[j] -= 1
                if indeg[j] == 0:
                    q.append(j)
        if len(order) != len(comps):
            raise StratificationError("unexpected cycle in condensation")

        strata: List[set] = []
        for i in order:
            strata.append(set(comps[i]))
        return strata

    # -- full evaluation ---------------------------------------------------- #
    def evaluate(self) -> None:
        self._rebuild()
        self.prov = dict(self.base)
        for stratum in self._strata:
            self._compute_preds(stratum)
            for spec in self.agg_specs:
                if spec.head_pred in stratum:
                    self._compute_aggregate(spec)

    def _ordered_aggregates(self) -> List[AggSpec]:
        # Kept for API compatibility; strata ordering already places aggregate
        # heads after their sources.  Returns specs in topological order.
        remaining = list(self.agg_specs)
        ordered: List[AggSpec] = []
        produced = self._rule_head_preds | set(p for p, _ in self.base)
        while remaining:
            progressed = False
            for s in list(remaining):
                if s.src.pred in produced or s.src.pred not in {x.head_pred for x in remaining}:
                    ordered.append(s)
                    produced.add(s.head_pred)
                    remaining.remove(s)
                    progressed = True
            if not progressed:
                raise StratificationError("aggregate dependency cycle")
        return ordered

    # -- core fixpoint ------------------------------------------------------ #
    def _compute_preds(self, preds: set) -> None:
        owned = preds & self._rule_head_preds
        if not owned:
            return
        for fact in [f for f in self.prov if f[0] in owned]:
            del self.prov[fact]
        rules = [r for r in self.rules if r.head.pred in owned]
        self._fixpoint(rules, owned)

    def _fixpoint(self, rules: List[Rule], owned_preds: set) -> None:
        """Kleene iteration ``D_{n+1} = F(D_n)`` over ``owned_preds``.

        ``F`` is *recomputed from scratch* each round (not accumulated), so
        every derivation tree is counted exactly once even when the semiring
        addition is not idempotent (e.g. bag multiplicities).  Predicates
        outside ``owned_preds`` are fixed inputs.
        """
        K = self.K
        fixed: Dict[str, Dict[Tuple[Any, ...], Any]] = {}
        for (pred, args), ann in self.prov.items():
            if pred not in owned_preds:
                fixed.setdefault(pred, {})[args] = ann
        derived: Dict[str, Dict[Tuple[Any, ...], Any]] = {}
        for _ in range(self.max_iterations):
            index: Dict[str, Dict[Tuple[Any, ...], Any]] = {p: dict(d) for p, d in fixed.items()}
            for p, d in derived.items():
                index.setdefault(p, {}).update(d)
            new_derived: Dict[str, Dict[Tuple[Any, ...], Any]] = {}
            for r in rules:
                for binding, bodyval in _solve_body(r.body, 0, {}, index, K):
                    if K.is_zero(bodyval):
                        continue
                    head = _instantiate(r.head, binding)
                    p, args = head
                    table = new_derived.setdefault(p, {})
                    table[args] = K.add(table.get(args, K.zero()), bodyval)
            if new_derived == derived:
                break
            derived = new_derived
        else:
            raise ProvenanceConvergenceError(
                "provenance fixpoint did not converge; recursive rules with a "
                "non-idempotent coefficient semiring can produce infinite provenance")
        for p, d in derived.items():
            for args, ann in d.items():
                if not K.is_zero(ann):
                    self.prov[(p, args)] = ann

    def _index(self) -> Dict[str, Dict[Tuple[Any, ...], Any]]:
        idx: Dict[str, Dict[Tuple[Any, ...], Any]] = {}
        for (pred, args), ann in self.prov.items():
            idx.setdefault(pred, {})[args] = ann
        return idx

    # -- aggregation -------------------------------------------------------- #
    def _compute_aggregate(self, spec: AggSpec) -> None:
        K = self.K
        for fact in [f for f in self.prov if f[0] == spec.head_pred]:
            del self.prov[fact]
        src_table = self._index().get(spec.src.pred, {})
        groups: Dict[Tuple[Any, ...], List[Any]] = {}
        for gargs, ann in src_table.items():
            b: Dict[str, Any] = {}
            for pat, g in zip(spec.src.args, gargs):
                if is_var(pat):
                    b[pat] = g
            key = tuple(b[v] for v in spec.key_vars)
            val = b.get(spec.value_var) if spec.value_var else None
            groups.setdefault(key, []).append((val, ann))
        for key in sorted(groups, key=lambda k: tuple(map(repr, k))):
            rows = groups[key]
            vals = [v for v, _ in rows if v is not None]
            if spec.agg == "count":
                agg_val: Any = len(rows)
            elif spec.agg == "sum":
                agg_val = sum(vals)
            elif spec.agg == "min":
                agg_val = min(vals)
            elif spec.agg == "max":
                agg_val = max(vals)
            elif spec.agg == "avg":
                agg_val = sum(vals) / len(vals)
            else:  # pragma: no cover
                raise ValueError(spec.agg)
            ann = K.one()
            for _, a in rows:
                ann = K.mult(ann, a)
            if K.is_zero(ann):
                continue
            self.prov[(spec.head_pred, tuple(key) + (agg_val,))] = ann

    # -- incremental maintenance ------------------------------------------- #
    def _forward_reachable(self, seeds: Iterable[str]) -> set:
        rev: Dict[str, set] = {}
        for head, bodydeps in self._deps.items():
            for body, _ in bodydeps:
                rev.setdefault(body, set()).add(head)
        seen = set(seeds)
        stack = list(seeds)
        while stack:
            u = stack.pop()
            for v in rev.get(u, ()):
                if v not in seen:
                    seen.add(v)
                    stack.append(v)
        return seen

    def insert_batch(self, facts: Iterable[Tuple[str, Sequence[Any], Any]]) -> None:
        changed = set()
        for pred, args, ann in facts:
            self.add_base_fact(pred, args, ann)
            changed.add(pred)
        self._maintain(changed)

    def delete_batch(self, facts: Iterable[Tuple[str, Sequence[Any]]]) -> None:
        changed = set()
        for pred, args in facts:
            self.delete_base_fact(pred, args)
            changed.add(pred)
        self._maintain(changed)

    def _maintain(self, changed_preds: set) -> None:
        if self._strata is None:
            self._rebuild()
        if not changed_preds:
            return
        affected = self._forward_reachable(changed_preds)
        for stratum in self._strata:
            todo = stratum & affected
            if todo:
                self._compute_preds(todo)
                for spec in self.agg_specs:
                    if spec.head_pred in todo:
                        self._compute_aggregate(spec)
        # drop zero-annotated facts to keep a canonical state
        for fact in [f for f, v in self.prov.items() if self.K.is_zero(v)]:
            del self.prov[fact]

    # -- queries / serialisation ------------------------------------------- #
    def query(self, pred: str) -> Dict[Tuple[Any, ...], Any]:
        return {args: v for (p, args), v in self.prov.items() if p == pred}

    def canonical_snapshot(self) -> str:
        import json
        items = []
        for (pred, args), val in self.prov.items():
            items.append((pred, list(args), self.K.value_repr(val)))
        items.sort(key=lambda x: (x[0], repr(x[1])))
        return json.dumps(items, sort_keys=True, default=repr)

    def explain(self, pred: str, args: Sequence[Any]) -> Any:
        return self.prov.get((pred, tuple(args)), self.K.zero())

# Convenience semiring homomorphism: evaluate polynomials in a target semiring
# --------------------------------------------------------------------------- #
def evaluate_polynomial(poly: Polynomial, target: Semiring,
                        var_value: Callable[[Any], Any],
                        coeff_map: Optional[Callable[[Any], Any]] = None) -> Any:
    """Apply the semiring homomorphism ``K0[X] -> S`` given by ``var_value``.

    By default coefficients from ``NatSemiring``/``BoolSemiring`` are mapped by
    the canonical unit map; other coefficient semirings are mapped by identity.
    """
    src = poly.coeff
    if coeff_map is None:
        if isinstance(src, NatSemiring):
            def coeff_map(n: int):  # type: ignore
                if n == 0:
                    return target.zero()
                acc = target.zero()
                for _ in range(n):
                    acc = target.add(acc, target.one())
                return acc
        elif isinstance(src, BoolSemiring):
            def coeff_map(b: bool):  # type: ignore
                return target.one() if b else target.zero()
        else:
            coeff_map = lambda c: c  # type: ignore
    result = target.zero()
    for mono, c in poly.terms.items():
        term = coeff_map(c)
        for v in mono:
            term = target.mult(term, var_value(v))
        result = target.add(result, term)
    return result

class BruteForce:
    """Independent reference: enumerate every proof tree of a (non-recursive) program."""
    def __init__(self, rules, base, K):
        self.rules, self.base, self.K = rules, base, K
        self.true = set(base)
        changed = True
        while changed:
            changed = False
            for r in rules:
                for binding in self._ground(r):
                    if all(self._body_truth(lit, binding) for lit in r.body):
                        f = _instantiate(r.head, binding)
                        if f not in self.true:
                            self.true.add(f); changed = True

    def prov(self, fact, stack=()):
        if fact in stack: return self.K.zero()
        if fact in self.base: return self.base[fact]
        total = self.K.zero()
        for r in self.rules:
            if r.head.pred != fact[0]: continue
            for binding in self._ground(r):
                b = dict(binding)
                if not self._unify(r.head, fact, b): continue
                if not all(self._body_truth(lit, b) for lit in r.body): continue
                prod, ok = self.K.one(), True
                for lit in r.body:
                    if lit.negated: continue
                    bf = _instantiate(lit.atom, b)
                    if bf not in self.true: ok = False; break
                    prod = self.K.mult(prod, self.prov(bf, stack + (fact,)))
                if ok: total = self.K.add(total, prod)
        return total

def test_incremental_matches_full_recompute_random(self):
    random.seed(20261017)
    e_inc = self._build()                       # rules + negation + aggregation
    facts = [("edge", ("a","b")), ("blue", ("a","b")), ("blocked", ("a","b")), ...]
    live = []
    for step in range(120):
        if facts and (not live or random.random() < 0.55):
            f = random.choice(facts)
            if f not in live:
                live.append(f)
                e_inc.insert_batch([(f[0], f[1], e_inc.K.var(f))])
        else:
            f = random.choice(live); live.remove(f)
            e_inc.delete_batch([(f[0], f[1])])

        # full recompute from the same base facts
        e_full = self._build()
        for pred, args in live:

        e_full.evaluate()
