Root causes found

The kernel is a logical→physical gather, and every failure came from confusing the two coordinate systems or iterating the allocated region instead of the valid region:

Bug Fix Measured error when present
A ignored block-table indirection phys = blockTable[lb] 1.345
B read unused tail of final block bound loops by n = min(seqLen, pos+1) 0.754
C wrong GQA mapping floor(h/groupSize) (contiguous groups) 1.826
D no causal prefix mask bound by absolute pos = startPos+i 1.305
E missing 1/sqrt(d) scale logits 1.279

Key insight: A and B are silent for aligned, identity-ordered lengths — they only show up with a permuted table and/or seqLen % blockSize ≠ 0. D is invisible for single-token decode and only appears with qLen > 1.

Verification (actually executed)

  • 58/58 cases pass, max abs error 6.661e-16 (tolerance 1e-6).
  • Covers short / exactly-block-aligned / partial-final-block lengths for blockSize ∈ {4,8,16}, identity and permuted tables, multi-token chunks, GQA ratios 1/1…32/8, and an invalid-config throw.
  • Ground truth is an independent plain-JS GQA kernel over dense K,V; paged cache slots outside [0,seqLen) are filled with ±9 garbage to catch out-of-range reads.
  • demonstrate_bugs.js proves each mutated kernel diverges while the fixed one matches.
