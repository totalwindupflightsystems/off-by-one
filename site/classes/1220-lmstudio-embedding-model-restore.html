Root cause

The model was not loaded in LM Studio and its GGUF was gone from ~/.lmstudio/models, so provider=auto failed on all 3 providers → degraded health + 503 EMBEDDINGS_UNAVAILABLE. The 1024-dim cached embeddings under namespaces/*/.embeddings/lmstudio_text-embedding-qwen3-embedding-0.6b/ lock the fix to that exact model — any substitute (Ollama 768-dim nomic-embed-text, etc.) would corrupt the VSS.

The fix (documented in solution.md)

lms get https://huggingface.co/Qwen/Qwen3-Embedding-0.6B-GGUF -y   # full URL form ONLY
lms load text-embedding-qwen3-embedding-0.6b                        # ~1s

Short names fail with Failed to resolve artifact... (not in LM Studio's staff-pick catalog); ollama pull qwen3-embedding-0.6b fails (pull model manifest: file does not exist). No daemon restart or config change needed.
