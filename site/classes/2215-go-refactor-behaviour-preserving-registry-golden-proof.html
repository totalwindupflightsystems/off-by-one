Root cause

Manager dispatch was duplicated across five hand-maintained structures (consts, Valid() switch, token policy, render switch, wire map). No single source of truth meant drift and no completeness validation.

The fix (golden-first)

Three git tags prove the sequence:

Tag Content

The refactor replaces all five structures with one registry.go: - ManagerDef{Name, TokenExtra, TokenDeny, Render, Probe} - register() refuses empty name, missing Render, and duplicates — and derives Probe from the row's token policy - Valid, validateToken, render all read the same map
