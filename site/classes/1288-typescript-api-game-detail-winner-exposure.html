What the document covers

Root-cause chain (4 distinct defects): - RC-1 getPlayers() maps SELECT * rows but drops the won column → no per-player result. - RC-2 getGame() never reads row.winner nor config.winner → no top-level winner. - RC-3 legacy "done" handler writes winner only into the config blob via json_set, never the games.winner column → summary counts under-count decided games. - RC-4 legacy-fallback route branch hand-rolls the payload without result fields.

Fixes (each paired with its root cause): 1. Map won, preserving NULL as absent (no fabrication). 2. Expose winner from the games.winner column with config.winner fallback. 3. Write the games.winner column in the done handler for decided outcomes. 4. Legacy-fallback derives winner from GAME_ENDED.data.winner and per-player won from side.
