Certified KV-Cache Quantizer for Grouped-Query Attention

Problem class: python-20261014-quantized-attention-kv-cache-error-budget

1. Root-cause analysis

The task is a constrained sizing problem, not "round a tensor". Six coupled effects break naive quantizers:

  1. Softmax is nonlinear. Key rounding perturbs scores before softmax amplifies them; an MSE budget on K gives no valid logit bound.
  2. Key/value errors are correlated. A change in K changes attention weights that are then multiplied by V; independent budgets miss the cross term ‖Δp‖·‖v̂‖.
  3. Outlier channels dominate. A few channels carry most of the range; uniform precision either blows the budget or wastes bits.
  4. Mixed precision is discrete resource allocation, not a rounding choice.
  5. GQA shares KV heads, so a KV channel's sensitivity is the max over its query group.
  6. Certificates must not replay inference — the proof must reduce to arithmetic over committed sufficient statistics.

2. Exact fix

2.1 The certified bound

Work in ℓ₁. Per-channel affine quantization with round-to-nearest has half-step u_c = (hi_c−lo_c)/(2(2^{b_c}−1)). With U_K=Σu^K_c, U_V=Σu^V_c, q_inf=max‖q‖_∞, v1_max=max_i‖v_i‖₁, and L the ℓ₁ Lipschitz constant of attention-output → logits:

  • |ε_i| = |q·Δk_i|/√d ≤ q_inf/√d · U_K.
  • Softmax is ½-Lipschitz from ℓ_∞ logits to ℓ₁ probabilities (max_j 2p_j(1−p_j) ≤ ½), so ‖p̂−p‖₁ ≤ q_inf/(2√d)·U_K.
  • ‖ô−o‖₁ ≤ U_V + ‖p̂−p‖₁·max_i‖v̂_i‖₁ ≤ U_V + q_inf/(2√d)·U_K·(v1_max+U_V).

$$\boxed{\,E = L\Big[U_V + \tfrac{q_{\infty}}{2\sqrt d}\,U_K\,(v_{1,\max}+U_V)\Big]\,}$$

The product U_K·U_V is the correlated key/value term; q_inf/(2√d) is the softmax gain.

2.2 Allocation algorithm

  1. Calibrate per-channel (lo,hi) for K/V plus q_inf, v1_max, L.
  2. Separable planning bound by freezing U_V at its worst case: w^K_c = L·q_inf/(2√d)·(v1_max+Ū_V), w^V_c = L.
  3. Minimum-bit DP over {2,3,4,5,6,8}: dp[m]= min separable error using exactly m bits; pick the smallest m ≤ cap with dp[m] ≤ budget. Provably no worse than the best uniform width.
  4. Refinement lowering channels one at a time against the tight bilinear bound.
  5. Certificate with flat bits/lo/hi arrays (ranges rounded outward to 6 sig-figs), committed by SHA-256; checker recomputes scale, zero, u, U_K, U_V, and E — no model replay.

2.3 Core implementation (kv_quant.py)

ALLOWED_BITS = (2, 3, 4, 5, 6, 8)

def half_step(lo, hi, bits):
    return (float(hi) - float(lo)) / (2.0 * ((1 << bits) - 1))

def _layer_error_from_us(lip, q_inf, d, v1_max, U_K, U_V):
    return lip * (U_V + q_inf / (2.0 * math.sqrt(d)) * U_K * (v1_max + U_V))

def allocate_bits(ranges, weights, budget, cap):
    """Min total bits s.t. Σ w_c·halfstep(range_c,b_c) <= budget and Σ b_c <= cap."""
    INF = float("inf")
    opts = [[(b, w * half_step(0.0, r, b)) for b in ALLOWED_BITS]
            for r, w in zip(ranges, weights)]
    dp = [INF] * (cap + 1); dp[0] = 0.0; choices = []
    for i, o in enumerate(opts):
        ndp = [INF] * (cap + 1); ch = [-1] * (cap + 1)
        for used in range(cap + 1):
            if dp[used] == INF: continue
            for b, e in o:
                if used + b <= cap and dp[used] + e < ndp[used + b]:
                    ndp[used + b] = dp[used] + e; ch[used + b] = b
        dp = ndp; choices.append(ch)
    best = next((m for m in range(cap + 1) if dp[m] <= budget), None)
    if best is None: return None, None
    bits, used = [0] * len(ranges), best
    for i in range(len(ranges) - 1, -1, -1):
        bits[i] = choices[i][used]; used -= bits[i]
    return bits, float(dp[best])

def _refine_allocation(st, r_k, r_v, bits_k, bits_v, budget):
    """Greedily lower bits while the tight bilinear bound still holds."""
    bits_k, bits_v = list(bits_k), list(bits_v)
    U_K = sum(half_step(0, r, b) for r, b in zip(r_k, bits_k))
    U_V = sum(half_step(0, r, b) for r, b in zip(r_v, bits_v))
    improved = True
    while improved:
        improved = False; best = None
        for kind, r, bits in (("k", r_k, bits_k), ("v", r_v, bits_v)):
            for i, b in enumerate(bits):
                nb = max((x for x in ALLOWED_BITS if x < b), default=None)
                if nb is None: continue
                dU = half_step(0, r[i], nb) - half_step(0, r[i], b)
                e = _layer_error_from_us(st.lip, st.q_inf, st.head_dim, st.v1_max,
                                         U_K + dU, U_V) if kind == "k" else \
                    _layer_error_from_us(st.lip, st.q_inf, st.head_dim, st.v1_max,
                                         U_K, U_V + dU)
                if e <= budget + 1e-12 and (best is None or e < best[0]):
                    best = (e, kind, i, nb, dU)
        if best:
            _, kind, i, nb, dU = best
            (bits_k if kind == "k" else bits_v)[i] = nb
            if kind == "k": U_K += dU
            else: U_V += dU
            improved = True
    return bits_k, bits_v

build_certificate emits, per layer, {"bits":[...], "lo":[...], "hi":[...]} for K and V, plus U_K, U_V, storage_bits, certified_logit_distortion, and the commitments calibration_sha256, stats_sha256, certificate_sha256. verify_certificate(cert, layer_caps, calibration_sha256, stats_sha256, total_budget) recomputes every quantity and the bilinear bound, checks caps/budget/commitments, and returns a per-check report.

Trust model: the checker needs only the certificate + external spec + trusted calibration/stats commitments. An auditor with the raw traces can recompute the statistics to confirm the commitments (the audit block in demo.py), but that is not required for checking.
