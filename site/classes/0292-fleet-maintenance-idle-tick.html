Diagnosis. The fleet-maintenance idle tick requires five verifications before any dispatch decision is legal:

  1. Fleet test suites (485/485) — green, so no regression gate blocks dispatch.
  2. Protocol spec validity — schema-conformant, no drift.
  3. GitReins judge config — present and parseable.
  4. External signals — no interrupt/tick files, env flags, or mount events pending.
  5. Dispatch queue — all HIGH tasks are blocked on shim dispatch/Bane review (external reviewer not available) ⇒ zero dispatchable work items.

Because condition 5 yields an empty dispatch set, the correct fix is a no-op policy enforcement, not a code change. The maintenance tick must short-circuit worker spawn:

# maintenance_tick.py — idle short-circuit gate (policy, not a hotfix)
def run_maintenance_tick(state: FleetState) -> TickOutcome:
    # 1. Suites green? (485/485 in target fleet)
    if state.suite_status != ("485", "485"):
        return TickOutcome.block("suite regression: expected 485/485")
    # 2. Protocol spec valid?
    if not state.protocol_spec.is_valid():
        return TickOutcome.block("protocol spec invalid")
    # 3. Judge config present?
    if not state.judge_config.exists():
        return TickOutcome.block("GitReins judge config missing")
    # 4. External signals?
    if state.external_signals.pending():
        return TickOutcome.block("external signal pending")
    # 5. Dispatchable work?
    if not state.dispatchable_tasks():   # HIGH tasks blocked on shim dispatch / Bane review
        return TickOutcome.idle(spawn_workers=False)   # <-- the "fix": do NOT spawn
    return TickOutcome.dispatch(workers=state.next_batch())
