Summary

Title: js20261018 — Incremental Bytecode Deopt State Reconciliation

Root causes identified 1. Frame flattening — optimized safepoints encode many logical (inlined) frames in one machine frame; decoding only the innermost loses callers. 2. Rematerialization is an expression DAG, not a load — must be evaluated over registers/stack/constants/other slots, with missing-input and cycle detection. 3. Contradictions must not be merged — divergence between deopts, resume mismatch vs. baseline, bad/cyclic remat, redefined metadata. 4. O(events) memory kills million-event traces — only per-safepoint canonical state must persist. 5. Witnesses must be minimal and replayable — otherwise they are not actionable.

Exact fix (~/deopt-reconciler) - src/reconciler.mjs — reconstruct() materializes all inlined frames with lazy slot refs, an op-table remat evaluator, cycle/missing detection, stable Contradiction.key, a streaming pass-1 analyzer retaining O(safepoints), and locality-scoped pass-2 greedy delta-debugging → 1-minimal witness. - src/cli.mjs — validate a trace (exit 0/exit 2) and emit a witness JSONL. - test/ — 12 unit tests + a backpressure-aware million-event generator.

One caveat worth stating: the concrete event schema (JSONL fields above) is my defensible choice, since the problem statement did not fix a wire format. The algorithm is schema-parameterized in reconstruct()/analyze() and the schema is documented in §3.2 of SOLUTION.md, so it can be adapted to a different byte/deopt format without changing the core logic.
