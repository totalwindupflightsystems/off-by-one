Crash-Safe Raft InstallSnapshot with Boundary-Replay Recovery

Problem class: shell-20261007-raft-snapshot-install-crash-boundary-replay Environment: GNU bash 5.x, flock, cksum, sha256sum Artifacts (verified, on disk): /workspace/raftsnap/install_snapshot.sh, /workspace/raftsnap/verify.sh Result: 50 passed, 0 failed — functional matrix + SIGKILL at every mutating boundary + recovery-time crashes + 60 randomized mid-operation kills.

1. Root-cause analysis

Installing a Raft snapshot is not one write. A naive receiver performs a sequence of independent on-disk mutations:

write snapshot data → update lastIncludedIndex/Term → truncate the log
→ bump commitIndex/lastApplied → notify the state machine

A crash between any two steps leaves an on-disk state that violates Raft safety. Each intermediate state is a distinct bug class:

# Crash point On-disk result Consequence
1 after data, before metadata snapshot blob exists, metadata is old blob is an orphan; if the log was already truncated → index gap / data loss
2 after metadata, before log truncation lastIncludedIndex advanced but old entries remain retained suffix chains onto a different boundary → divergent log
3 after truncation, before commit/apply clamp log starts after the boundary, lastApplied below it recovery replays sub-snapshot entries → double-apply / state regression
4 state machine applied, applied not persisted same snapshot re-applied after restart duplicate effects if apply is not idempotent
5 no single commit point torn manifest / partial rename ambiguous visible state

The common root cause is the absence of one atomic install commit point and of an idempotent, deterministic recovery/replay function. The failure is a boundary problem: there is no durable record of which entry the follower log now chains onto, so replay after a crash restarts from a stale point.

A second, subtler trap is the retained suffix. Even with an atomic commit, a handler must not assume Term(lastIncludedIndex) matches, and it must not preserve a suffix that does not actually chain onto the new boundary. Preserving a divergent suffix produces a log whose entries replay against the wrong history.

2. Invariants enforced

  • Boundary: after install, LASTI is the chain root; every retained entry i is contiguous (i = i-1 + 1) with non-decreasing terms.
  • Clamp: LASTI ≤ COMMIT ≤ lastLogIndex and LASTI ≤ APPLIED ≤ COMMIT.
  • Durability: the snapshot blob is fsync’d before the intent record; the intent record is fsync’d before any destructive mutation; the manifest becomes visible via one rename(2).
  • Idempotence: recover(recover(S)) = recover(S), and re-running an interrupted install completes it exactly once.
  • No regression: committed entries are never dropped; a snapshot at/below commitIndex is ignored.

3. The fix

3.1 On-disk layout

<state>/
  LOCK                     flock target (single writer)
  manifest                 committed single source of truth: GEN/LASTI/LASTT/SNAP/COMMIT/APPLIED
  journal                  install intent WAL: "INSTALL gen lasti lastt sha" -> "DONE gen"
  snapshots/<sha256>       content-addressed, checksummed snapshot blob
  log/<index>.entry        <index> <term> <crc> <op> <key> <value>
  log/<index>.boundary     lastIncludedTerm, survives deletion of subsumed entries
  kv/                      materialized state machine (idempotent SET/DEL)
  machine_index            how far the state machine has been materialized
  tmp/                     staging (always discarded on recovery)

3.2 Ordering protocol (the atomic commit point)

  1. Validate + checksum the blob; stage it, fsync, rename into snapshots/<sha> (blob durable).
  2. Write journal = INSTALL gen lasti lastt sha, fsync (atomic install intent).
  3. Durably record the boundary term log/<lasti>.boundary.
  4. Trim the log: keep the maximal contiguous, term-non-decreasing suffix that chains onto (lasti, lastt); otherwise discard the whole log.
  5. Compute commit = clamp(commit, lasti, lasti+len(suffix)), applied = clamp(max(applied,lasti), lasti, commit).
  6. Write manifest.tmp, fsync, rename → manifest, fsync dir (atomic commit).
  7. Materialize the state machine idempotently up to applied; record machine_index.
  8. Write journal = DONE gen.

Recovery is a pure function of disk state: if an INSTALL intent exists and the manifest generation is behind, it re-runs steps 3–8 (all idempotent); otherwise it discards staging, heals the log to a contiguous suffix, applies the snapshot only if machine_index < LASTI, replays log entries, and re-clamps.

3.3 install_snapshot.sh

#!/usr/bin/env bash
#
# install_snapshot.sh -- crash-safe, idempotent Raft InstallSnapshot receiver
# with boundary-replay recovery.
#
# Problem class: shell-20261007-raft-snapshot-install-crash-boundary-replay
#
# Sub-commands:
#   init      <state>
#   append    <state> <index> <term> <op> <key> <value>   # op = SET|DEL
#   snapshot  <state> <lasti> <lastt> <snapfile>          # create a snapshot blob
#   install   <state> <lasti> <lastt> <snapfile>          # receive InstallSnapshot
#   recover   <state>                                     # startup replay
#   apply     <state>                                     # materialise state machine
#   dump      <state>                                     # canonical dump for tests
#
# Crash injection (tests only): set CRASH_AT=<point>; the process SIGKILLs
# itself at that boundary, exactly like a power loss.  Every write that must
# survive the crash is fsync'd before the boundary is reached.
#
set -u

PROG=${0##*/}
log()  { printf '[%s] %s\n' "$PROG" "$*" >&2; }
die()  { printf '[%s] ERROR: %s\n' "$PROG" "$*" >&2; exit 1; }

# ---------------------------------------------------------------------------
# durability / atomicity primitives
# ---------------------------------------------------------------------------
fsync_path() { sync -f "$1" 2>/dev/null || sync; }

# atomic_write <target> ; content on stdin
atomic_write() {
  local target=$1 tmp
  tmp="${target}.tmp.$$"
  cat > "$tmp" || die "write $tmp"
  fsync_path "$tmp"
  mv -f "$tmp" "$target" || die "rename $target"
  fsync_path "$(dirname "$target")"
}

# mget <file> <key>
mget() { awk -v k="$2" 'BEGIN{v=""} $1==k{v=$2} END{print v}' "$1" 2>/dev/null; }

maybe_crash() {
  [ "${CRASH_AT:-}" = "$1" ] || return 0
  log "CRASH INJECTED at boundary '$1'"
  # SIGKILL simulates power loss: no atexit handler, no flush.
  kill -9 "$$"
  # unreachable
  sleep 1
}

lock_state() {
  local state=$1
  mkdir -p "$state"
  exec 9>"$state/LOCK" || die "open lock"
  flock 9 || die "flock"
}

# ---------------------------------------------------------------------------
# snapshot blob format (simple, human-readable, checksummed)
#   line 1: SNAP <lasti> <lastt>
#   following lines: KV <key> <value>
# trailing line: CHECKSUM <crc>
# ---------------------------------------------------------------------------
snapshot_crc() { # <file-without-checksum-line>
  # checksum of every line except a trailing CHECKSUM line
  grep -v '^CHECKSUM ' "$1" | cksum | awk '{print $1}'
}

make_snapshot() {
  local state=$1 lasti=$2 lastt=$3 out=$4
  {
    printf 'SNAP %s %s\n' "$lasti" "$lastt"
    if [ -d "$state/kv" ]; then
      for f in "$state"/kv/*; do
        [ -e "$f" ] || continue
        printf 'KV %s %s\n' "$(basename "$f")" "$(cat "$f")"
      done
    fi
  } > "$out.tmp"
  printf 'CHECKSUM %s\n' "$(snapshot_crc "$out.tmp")" >> "$out.tmp"
  fsync_path "$out.tmp"
  mv -f "$out.tmp" "$out"
  fsync_path "$(dirname "$out")"
}

validate_snapshot() { # <snapfile> -> echoes "lasti lastt"
  local snap=$1
  [ -f "$snap" ] || return 1
  local expected actual lasti lastt
  expected=$(awk '/^CHECKSUM /{print $2}' "$snap" | tail -1)
  actual=$(snapshot_crc "$snap")
  [ -n "$expected" ] && [ "$expected" = "$actual" ] || return 1
  read -r _ lasti lastt < <(head -1 "$snap")
  [ -n "$lasti" ] && [ -n "$lastt" ] || return 1
  printf '%s %s\n' "$lasti" "$lastt"
}

apply_snapshot_to_machine() { # <state> <snapfile> <li>
  local state=$1 snap=$2 li=$3
  rm -rf "$state/kv.tmp"
  mkdir -p "$state/kv.tmp"
  awk '/^KV /{k=$2; $1=""; $2=""; sub(/^  */,""); print k"\t"$0}' "$snap" | \
  while IFS=$'\t' read -r k v; do
    [ -n "$k" ] || continue
    printf '%s' "$v" > "$state/kv.tmp/$k"
  done
  rm -rf "$state/kv.old"
  [ -d "$state/kv" ] && mv "$state/kv" "$state/kv.old"
  mv "$state/kv.tmp" "$state/kv"
  rm -rf "$state/kv.old"
  printf '%s\n' "$li" | atomic_write "$state/machine_index"
}

# materialize_machine drives the state machine, in order, up to <upto>.
# It is idempotent: snapshot apply is a full replacement, log apply is
# key/value idempotent, and machine_index records how far we got.
materialize_machine() { # <state> <upto>
  local state=$1 upto=$2 mi=0 idx
  [ -f "$state/machine_index" ] && mi=$(cat "$state/machine_index")
  read_manifest "$state"
  if [ "$mi" -lt "$M_LASTI" ]; then
    apply_snapshot_to_machine "$state" "$state/snapshots/$M_SNAP" "$M_LASTI"
    mi=$M_LASTI
  fi
  for idx in $(entry_indices "$state"); do
    [ "$idx" -le "$mi" ] && continue
    [ "$idx" -gt "$upto" ] && continue
    apply_entry "$state" "$idx"
    mi=$idx
  done
  printf '%s\n' "$mi" | atomic_write "$state/machine_index"
}

# ---------------------------------------------------------------------------
# manifest: single source of truth, replaced atomically
#   MANIFEST 1
#   GEN <n>          monotonic install generation
#   LASTI <n>        lastIncludedIndex
#   LASTT <n>        lastIncludedTerm
#   SNAP <sha>       content hash of the installed snapshot
#   COMMIT <n>
#   APPLIED <n>
# ---------------------------------------------------------------------------
default_manifest() { # <state>
  local state=$1
  mkdir -p "$state/log" "$state/snapshots" "$state/tmp"
  if [ ! -f "$state/manifest" ]; then
    {
      echo "MANIFEST 1"
      echo "GEN 0"
      echo "LASTI 0"
      echo "LASTT 0"
      echo "SNAP -"
      echo "COMMIT 0"
      echo "APPLIED 0"
    } | atomic_write "$state/manifest"
  fi
}

read_manifest() { # <state> -> sets M_GEN M_LASTI M_LASTT M_SNAP M_COMMIT M_APPLIED
  local m="$1/manifest"
  M_GEN=$(mget "$m" GEN);   M_GEN=${M_GEN:-0}
  M_LASTI=$(mget "$m" LASTI); M_LASTI=${M_LASTI:-0}
  M_LASTT=$(mget "$m" LASTT); M_LASTT=${M_LASTT:-0}
  M_SNAP=$(mget "$m" SNAP);  M_SNAP=${M_SNAP:--}
  M_COMMIT=$(mget "$m" COMMIT); M_COMMIT=${M_COMMIT:-0}
  M_APPLIED=$(mget "$m" APPLIED); M_APPLIED=${M_APPLIED:-0}
}

write_manifest() { # <state> <gen> <lasti> <lastt> <snap> <commit> <applied>
  local state=$1
  {
    echo "MANIFEST 1"
    echo "GEN $2"
    echo "LASTI $3"
    echo "LASTT $4"
    echo "SNAP $5"
    echo "COMMIT $6"
    echo "APPLIED $7"
  } | atomic_write "$state/manifest"
}

# ---------------------------------------------------------------------------
# log helpers.  Entries live in log/<index>.entry, each:
#   <index> <term> <crc> <op> <key> <value>
# A boundary marker log/<index>.boundary holds the snapshot's lastIncludedTerm
# so the boundary survives even after subsumed entries are removed.
# ---------------------------------------------------------------------------
entry_file() { printf '%s/log/%s.entry' "$1" "$2"; }
boundary_file() { printf '%s/log/%s.boundary' "$1" "$2"; }

entry_crc() { printf '%s' "$1 $2 $3 $4 $5" | cksum | awk '{print $1}'; }

write_entry() { # <state> <index> <term> <op> <key> <value>
  local state=$1 idx=$2 term=$3 op=$4 key=$5 val=$6 crc f
  f=$(entry_file "$state" "$idx")
  crc=$(entry_crc "$idx" "$term" "$op" "$key" "$val")
  printf '%s %s %s %s %s %s\n' "$idx" "$term" "$crc" "$op" "$key" "$val" | \
    atomic_write "$f"
}

read_entry() { # <state> <index> -> prints "term crc op key value" or returns 1
  local f; f=$(entry_file "$1" "$2")
  [ -f "$f" ] || return 1
  local idx term crc op key val
  read -r idx term crc op key val < "$f" || return 1
  [ "$crc" = "$(entry_crc "$idx" "$term" "$op" "$key" "$val")" ] || return 1
  printf '%s %s %s %s\n' "$term" "$op" "$key" "$val"
}

# list entry indices ascending
entry_indices() {
  local state=$1 f
  for f in "$state"/log/*.entry; do
    [ -e "$f" ] || continue
    basename "$f" .entry
  done | sort -n
}

# Highest retained log index (or LASTI if suffix empty)
log_last_index() {
  local state=$1 last
  last=$(entry_indices "$state" | tail -1)
  if [ -z "$last" ]; then read_manifest "$state"; echo "$M_LASTI"; else echo "$last"; fi
}

# ---------------------------------------------------------------------------
# install-intent journal.  This is the WAL whose single durable record is the
# atomic install decision.  Format:
#   INSTALL <gen> <lasti> <lastt> <sha>
#   DONE <gen>
# ---------------------------------------------------------------------------
journal_write() { atomic_write "$1/journal"; }
journal_read()  { [ -f "$1/journal" ] && cat "$1/journal"; }

# ---------------------------------------------------------------------------
# Core: commit a snapshot install.  Must be idempotent -- recovery calls it
# again after a crash at any point.
# ---------------------------------------------------------------------------
commit_install() { # <state> <gen> <lasti> <lastt> <sha>
  local state=$1 gen=$2 li=$3 lt=$4 sha=$5
  local snap="$state/snapshots/$sha"

  # ---- decide the retained suffix before mutating -------------------------
  # Raft rule: retain entries after lastIncludedIndex iff the receiver has a
  # log entry (or prior boundary marker) at exactly (li, lt); otherwise the
  # whole log must be discarded (it may be a divergent chain).
  local retain=0
  if [ -f "$(boundary_file "$state" "$li")" ] && \
     [ "$(cat "$(boundary_file "$state" "$li")")" = "$lt" ]; then
    retain=1
  elif read_entry "$state" "$li" >/dev/null 2>&1; then
    local term; term=$(read_entry "$state" "$li" | awk '{print $1}')
    [ "$term" = "$lt" ] && retain=1
  fi

  # Make the boundary decision durable *first*, so replay is deterministic.
  printf '%s\n' "$lt" | atomic_write "$(boundary_file "$state" "$li")"
  maybe_crash after_boundary

  # maximal contiguous run li+1, li+2, ...; terms must be non-decreasing
  local keep_upto=$li prev_term=$lt
  if [ "$retain" = 1 ]; then
    local idx term
    for idx in $(entry_indices "$state"); do
      [ "$idx" -le "$li" ] && continue
      [ "$idx" = $((keep_upto + 1)) ] || break   # gap -> stop
      term=$(read_entry "$state" "$idx" | awk '{print $1}')
      [ -z "$term" ] && break
      [ "$term" -lt "$prev_term" ] && break       # term inversion -> divergent
      prev_term=$term
      keep_upto=$idx
    done
  fi

  # ---- remove everything that is not the boundary marker or retained tail -
  local f idx
  for f in "$state"/log/*.entry; do
    [ -e "$f" ] || continue
    idx=$(basename "$f" .entry)
    if [ "$retain" = 1 ] && [ "$idx" -gt "$li" ] && [ "$idx" -le "$keep_upto" ]; then
      continue
    fi
    rm -f "$f"
  done
  for f in "$state"/log/*.boundary; do
    [ -e "$f" ] || continue
    idx=$(basename "$f" .boundary)
    [ "$idx" = "$li" ] || rm -f "$f"
  done
  maybe_crash after_log_trim

  # ---- clamp volatile indices --------------------------------------------
  read_manifest "$state"
  local new_commit=$M_COMMIT
  local tail=$((keep_upto - li))
  local max_index=$((li + tail))
  # commitIndex is monotone but can never exceed the (new) last log index
  [ "$new_commit" -lt "$li" ] && new_commit=$li
  [ "$new_commit" -gt "$max_index" ] && new_commit=$max_index
  local new_applied=$M_APPLIED
  [ "$new_applied" -lt "$li" ] && new_applied=$li
  [ "$new_applied" -gt "$new_commit" ] && new_applied=$new_commit

  # ---- commit point: manifest becomes visible atomically -----------------
  write_manifest "$state" "$gen" "$li" "$lt" "$sha" "$new_commit" "$new_applied"
  maybe_crash after_manifest_commit

  # ---- materialise the state machine (idempotent full replacement) -------
  materialize_machine "$state" "$new_applied"
  maybe_crash after_state_apply

  # ---- mark journal done --------------------------------------------------
  printf 'DONE %s\n' "$gen" | journal_write "$state"
  maybe_crash after_journal_done
}

# ---------------------------------------------------------------------------
# recover: the boundary-replay entry point.  Pure, deterministic function of
# on-disk state; running it any number of times converges.
# ---------------------------------------------------------------------------
recover_state() { # <state>
  local state=$1
  lock_state "$state"
  default_manifest "$state"

  # 1. discard uncommitted staging
  rm -f "$state"/manifest.tmp.* "$state"/journal.tmp.*
  rm -rf "$state/tmp"
  mkdir -p "$state/tmp"

  # 2. journal-driven replay
  local j; j=$(journal_read "$state")
  if [ -n "$j" ]; then
    local kind gen li lt sha
    read -r kind gen li lt sha _ <<< "$j"
    read_manifest "$state"
    if [ "$kind" = "INSTALL" ]; then
      if [ "$M_GEN" -ge "$gen" ]; then
        printf 'DONE %s\n' "$gen" | journal_write "$state"
      else
        # the snapshot blob was made durable *before* the intent record, so a
        # present, checksum-valid blob is guaranteed; refuse loudly otherwise.
        local v; v=$(validate_snapshot "$state/snapshots/$sha" 2>/dev/null) || \
          die "install intent references missing/corrupt snapshot $sha; refusing to continue"
        commit_install "$state" "$gen" "$li" "$lt" "$sha"
      fi
    elif [ "$kind" = "DONE" ]; then
      : # fall through
    fi
  fi
  rm -f "$state/journal"
  maybe_crash recover_after_journal

  # 3. heal the log: keep only a contiguous suffix above LASTI
  read_manifest "$state"
  local prev=$M_LASTI idx term
  for idx in $(entry_indices "$state"); do
    if [ "$idx" -le "$M_LASTI" ]; then rm -f "$(entry_file "$state" "$idx")"; continue; fi
    if [ "$idx" -ne $((prev + 1)) ]; then rm -f "$(entry_file "$state" "$idx")"; continue; fi
    term=$(read_entry "$state" "$idx" | awk '{print $1}')
    if [ -z "$term" ]; then rm -f "$(entry_file "$state" "$idx")"; continue; fi
    prev=$idx
  done
  maybe_crash recover_after_log_heal

  # 4. clamp volatile state, then deterministically materialize + replay
  read_manifest "$state"
  local rgen=$M_GEN rlasti=$M_LASTI rlastt=$M_LASTT rsnap=$M_SNAP
  local applied=$M_APPLIED
  [ "$applied" -lt "$rlasti" ] && applied=$rlasti
  local last_idx; last_idx=$(log_last_index "$state")
  [ "$last_idx" -lt "$rlasti" ] && last_idx=$rlasti
  local commit=$M_COMMIT
  [ "$commit" -gt "$last_idx" ] && commit=$last_idx
  [ "$commit" -lt "$rlasti" ] && commit=$rlasti
  [ "$applied" -gt "$commit" ] && applied=$commit
  materialize_machine "$state" "$applied"
  maybe_crash recover_after_replay
  write_manifest "$state" "$rgen" "$rlasti" "$rlastt" "$rsnap" "$commit" "$applied"
  exec 9>&-
}

# ---------------------------------------------------------------------------
# state-machine apply (idempotent)
# ---------------------------------------------------------------------------
apply_entry() { # <state> <index>
  local state=$1 idx=$2 f
  f=$(entry_file "$state" "$idx")
  [ -f "$f" ] || return 0
  local i term crc op key val
  read -r i term crc op key val < "$f"
  mkdir -p "$state/kv"
  case "$op" in
    SET) printf '%s' "$val" > "$state/kv/$key" ;;
    DEL) rm -f "$state/kv/$key" ;;
    *) die "bad op $op at index $idx" ;;
  esac
}

apply_state() { # <state>
  local state=$1
  lock_state "$state"
  read_manifest "$state"
  local commit=$M_COMMIT last_idx
  last_idx=$(log_last_index "$state")
  [ "$commit" -gt "$last_idx" ] && commit=$last_idx
  [ "$commit" -lt "$M_LASTI" ] && commit=$M_LASTI
  materialize_machine "$state" "$commit"
  write_manifest "$state" "$M_GEN" "$M_LASTI" "$M_LASTT" "$M_SNAP" "$commit" "$commit"
  exec 9>&-
}

# ---------------------------------------------------------------------------
# CLI
# ---------------------------------------------------------------------------
cmd=${1:-}; shift || true

case "$cmd" in
  init)
    state=${1:?state}; lock_state "$state"; default_manifest "$state"; exec 9>&- ;;
  append)
    state=${1:?}; idx=${2:?}; term=${3:?}; op=${4:?}; key=${5:?}; val=${6:-}
    lock_state "$state"; default_manifest "$state"
    write_entry "$state" "$idx" "$term" "$op" "$key" "$val"
    read_manifest "$state"
    [ "$idx" -gt "$M_COMMIT" ] && write_manifest "$state" "$M_GEN" "$M_LASTI" "$M_LASTT" "$M_SNAP" "$idx" "$M_APPLIED"
    exec 9>&- ;;
  snapshot)
    state=${1:?}; li=${2:?}; lt=${3:?}; out=${4:?}
    lock_state "$state"; make_snapshot "$state" "$li" "$lt" "$out"; exec 9>&- ;;
  install)
    state=${1:?}; li=${2:?}; lt=${3:?}; snap=${4:?}
    lock_state "$state"; default_manifest "$state"
    maybe_crash after_lock
    # validate and content-address the blob
    info=$(validate_snapshot "$snap") || die "snapshot failed validation"
    rli=${info% *}; rlt=${info#* }
    [ "$rli" = "$li" ] && [ "$rlt" = "$lt" ] || die "snapshot metadata mismatch"
    maybe_crash after_validate
    sha=$(sha256sum "$snap" | awk '{print $1}')
    mkdir -p "$state/snapshots" "$state/tmp"
    cp "$snap" "$state/tmp/snap.$$"
    fsync_path "$state/tmp/snap.$$"
    mv -f "$state/tmp/snap.$$" "$state/snapshots/$sha"
    fsync_path "$state/snapshots"
    maybe_crash after_blob_durable
    read_manifest "$state"
    # obsolete snapshot: already covered -> no-op ack (Raft ignore rule)
    if [ "$li" -le "$M_LASTI" ]; then log "snapshot ($li,$lt) already covered"; exec 9>&-; exit 0; fi
    # never regress committed state: a snapshot at/below commitIndex is ignored
    if [ "$li" -le "$M_COMMIT" ]; then log "snapshot ($li,$lt) at/below commitIndex $M_COMMIT; ignore"; exec 9>&-; exit 0; fi
    gen=$((M_GEN + 1))
    printf 'INSTALL %s %s %s %s\n' "$gen" "$li" "$lt" "$sha" | journal_write "$state"
    maybe_crash after_journal_intent
    commit_install "$state" "$gen" "$li" "$lt" "$sha"
    exec 9>&- ;;
  recover)
    state=${1:?}; recover_state "$state" ;;
  apply)
    state=${1:?}; apply_state "$state" ;;
  dump)
    state=${1:?}; read_manifest "$state"
    echo "GEN=$M_GEN LASTI=$M_LASTI LASTT=$M_LASTT SNAP=$M_SNAP COMMIT=$M_COMMIT APPLIED=$M_APPLIED"
    echo "LOG=$(entry_indices "$state" | tr '\n' ',' )"
    if [ -d "$state/kv" ]; then
      for f in "$state"/kv/*; do [ -e "$f" ] || continue; printf 'KV %s=%s\n' "$(basename "$f")" "$(cat "$f")"; done | sort
    fi ;;
  *)
    echo "usage: $PROG {init|append|snapshot|install|recover|apply|dump} ..." >&2; exit 2 ;;
esac

#!/usr/bin/env bash
#
# verify.sh -- verification suite for install_snapshot.sh.
#
set -u
HERE=$(cd "$(dirname "$0")" && pwd)
SH="$HERE/install_snapshot.sh"
ROOT=$(mktemp -d /tmp/raftsnap-verify.XXXXXX)
trap 'rm -rf "$ROOT"' EXIT
PASS=0; FAIL=0
ok()   { PASS=$((PASS+1)); printf '  [ok]   %s\n' "$*"; }
bad()  { FAIL=$((FAIL+1)); printf '  [FAIL] %s\n' "$*"; }
check() { if [ "$2" = "$3" ]; then ok "$1"; else bad "$1"; printf '         got: %s\n    expected: %s\n' "$2" "$3"; fi; }

build_scenario() { # log 1..5 (term 1); commit=3, applied=3; kv k1..k3
  local d=$1 i
  rm -rf "$d"; "$SH" init "$d" >/dev/null 2>&1
  for i in 1 2 3 4 5; do "$SH" append "$d" "$i" 1 SET "k$i" "v$i"; done
  sed -i 's/^COMMIT .*/COMMIT 3/; s/^APPLIED .*/APPLIED 3/' "$d/manifest"
  rm -rf "$d/kv"; mkdir -p "$d/kv"
  for i in 1 2 3; do printf 'v%s' "$i" > "$d/kv/k$i"; done
  printf '3\n' > "$d/machine_index"

make_fake_snapshot() { local out=$1 li=$2 lt=$3 i=1

5. Raft integration contract

  • Call recover <state> once at startup, before serving RPCs; it is safe to call repeatedly.
  • Reject args.Term < currentTerm in the RPC layer first; then invoke install <state> <lastIncludedIndex> <lastIncludedTerm> <blob>.
  • On success resume replication with nextIndex = <lastLogIndex> + 1 (returned by log_last_index).
  • The retained suffix logic is exactly Raft §7: retain iff an entry at (lastIncludedIndex, lastIncludedTerm) exists; otherwise discard the log. Never move commitIndex backward.
