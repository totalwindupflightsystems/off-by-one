Answer

Root cause (GAP-008): the list-known-friends subcommand hardcoded a deployment-specific default, /opt/hermes-demo/helix/known-friends.json. Every host that is not that one deployment reported FILE_NOT_FOUND, and the error gave no hint about how to point at the right file. Two secondary defects: an empty registry file was fed to json.Unmarshal and surfaced as unexpected end of JSON input (a parse error) instead of "no agents", and the missing-file error gave users no actionable hint.

The fix, in three parts (full working code in /home/kara/gap008/):

1. os.Stat-based default resolution — prod path if present, else ~/.helix/<file>:

var ProdDefault = "/opt/hermes-demo/helix/known-friends.json" // var, so tests can probe a fake deployment

func ResolveDefault(explicit string) string {
    if explicit != "" { // --registry wins; no stat probing needed
        return explicit
    }
    if _, err := os.Stat(ProdDefault); err == nil { // host IS the prod deployment
        return ProdDefault
    }
    home, err := os.UserHomeDir()
    if err != nil || home == "" {
        return "known-friends.json" // last resort, still better than a foreign path
    }
    return filepath.Join(home, ".helix", "known-friends.json") // every other host
}

2. Empty registry file ⇒ NO_AGENTS, exit 0 (not a parse error):

reg := &Registry{}
if len(bytes.TrimSpace(data)) == 0 { // zero bytes OR whitespace-only
    // Valid empty registry: "no entries", exit 0. Never feed this to
    // json.Unmarshal, which would error "unexpected end of JSON input".
    return reg, nil
}
if err := json.Unmarshal(data, reg); err != nil {
    return nil, fmt.Errorf("parse %s: %w", path, err) // real corruption still errors
}

3. FILE_NOT_FOUND error with a pass --flag or set ENV hint:

var ErrFileNotFound = errors.New("FILE_NOT_FOUND")

func Load(path string) (*Registry, error) {
    data, err := os.ReadFile(path)
    if err != nil {
        if errors.Is(err, os.ErrNotExist) {
            return nil, fmt.Errorf("%w: %s (pass --registry or set HELIX_REGISTRY)",
                ErrFileNotFound, path)
        }
        return nil, fmt.Errorf("read %s: %w", path, err)
    }
    // ...empty check, json.Unmarshal as above
}

Exit codes: 0 OK/NO_AGENTS, 1 FILE_NOT_FOUND, 2 parse error. Callers use errors.Is(err, ErrFileNotFound) to route to the right code, so the hint survives wrapping.
