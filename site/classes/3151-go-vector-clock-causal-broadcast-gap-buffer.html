Causally Ordered Broadcast with a Bounded Gap Buffer

TL;DR

A vector-clock causal layer is not enough on its own: a single permanently dropped broadcast makes every later message fail the causal predicate, so the holdback ("gap") queue grows without bound and the node deadlocks. Because a vector clock only proves that a predecessor was sent, it cannot prove that it is permanently lost. The fix is to add a deterministic liveness rule: once a known-sent predecessor is absent for K further live messages, declare it permanently lost, record it in a gap report, and compact the buffer by advancing the delivered clock over it. K is counted in distinct live messages, never in wall-clock time, so the run is bit-for-bit reproducible.

The complete, runnable module is in ~/causalbc. go test ./... passes all six tests, including a golden delivery order, a 200-run determinism check, a bounded-memory proof, and a causal-order invariant checker.

1. Problem restated

Implement a causal broadcast layer over an unreliable transport:

  • each node keeps a vector clock and a holdback (gap) buffer;
  • a message is delivered only after all of its causal predecessors are delivered;
  • a node that stalls on K messages must not grow memory without bound or deadlock;
  • given a captured trace with duplicates, reordering, late arrivals, two joins and one leave, emit the exact per-node delivery order and a gap report naming the unreachable predecessors;
  • the layer must be deterministic, and must classify a predecessor as permanently lost within a bounded number of live messages so the buffer can be compacted.

2. Root-cause analysis

2.1 Symptom

Node C receives A:2's successor, A:3. A:3's clock says A:2 existed. A:2 never arrives. A:3 is therefore undeliverable forever, and every later message that transitively depends on A:2 piles up behind it. The holdback queue becomes an unbounded leak and C makes no further progress.

2.2 Why the obvious design fails

A vector clock is a proof of causality, not of liveness. From A:3's clock you can prove A:2 was sent; nothing in the clock tells you whether A:2 is in flight, sitting in a reorder buffer, or gone forever. The standard causal predicate

deliverable(m)  <=>  m.clock[from] == delivered[from] + 1
                     and for all j != from: m.clock[j] <= delivered[j]

is a safety predicate. It has no liveness escape hatch, so a single loss is a permanent stall. That is the root cause: the wait is unbounded because the condition to stop waiting was never defined.

2.3 Why wall-clock timeouts are the wrong escape hatch

Introducing "wait N seconds, then give up" makes the output depend on machine speed and scheduling. The exact delivery order and the gap set would change between runs, violating the determinism requirement. Time must be measured in something intrinsic to the trace: live messages.

2.4 The classification rule and its trade-off

When a received message's clock references j:k and j:k is absent, record the current live-message counter. If K more distinct live messages arrive and j:k still has not, classify it as permanently lost. This is a conservative liveness heuristic: it trades the possibility of misclassifying a very-late message for guaranteed bounded memory and termination. If a message declared lost later surfaces, it is absorbed as a tombstone (the delivery order already reported cannot be changed). K should exceed the transport's worst-case reordering window in live messages.

2.5 Joins and leaves

  • A joining node starts with an empty clock; its first broadcast is <id>:00000001. Nothing special is required because other nodes only ever wait on predecessors that some clock names.
  • A leaving node simply stops extending its component of the horizon. Outstanding gaps that name it are resolved by the ordinary K-live-message rule; no special case, no extra deadlock surface.

3. The fix

3.1 Data kept per node

field purpose
delivered vector clock of delivered messages
holdback received-but-blocked messages (the gap buffer)
horizon component-wise max of every clock seen = frontier of known-sent messages
missingSince gap id -> live counter when first noticed
lost / gapOrder permanently lost predecessors + the gap report
recvSeq arrival rank, used only as a deterministic tie-break

3.2 Delivery predicate

canDeliver(m):
  m.clock[from] == delivered[from] + 1      # next in this sender's stream
  AND for every other j: m.clock[j] <= delivered[j]

3.3 Gap detection + compaction

classifyGaps():
  for each node j in sorted order:
    while delivered[j] < horizon[j]:
      k = delivered[j] + 1
      id = "j:k"
      if id in holdback:            break   # present, just blocked
      if id never noticed:          missingSince[id] = live; break
      if live - missingSince[id] < K: break # still inside reorder window
      lost[id] = true; gapOrder += id
      delivered[j] = k              # compact over the predecessor

3.4 Determinism

  • classifyGaps iterates sender ids in sorted order.
  • pickReady delivers the deliverable buffer entry with the smallest arrival rank, giving a deterministic total order over concurrent messages.
  • All String/report output sorts keys. No wall clock, no goroutine timing, no map-iteration order leaks into the result.

3.5 Termination bound

Every settle iteration either delivers a message (strictly reduces holdback) or declares a gap lost (strictly advances delivered). Both are bounded by the number of messages ever sent, so settle is a terminating fixed-point loop. Memory is bounded by O(K * senders): at most K+1 messages can accumulate behind a head gap before it is reclassified, after which the buffer flushes.

package causal

import "fmt"

// Message is a broadcast message enriched with the sender's vector clock at
// send time. Clock[From] equals Seq; for every other node j, Clock[j] is the
// number of messages from j that the sender had delivered when it sent this.
type Message struct {
    ID    string      `json:"id"`
    From  string      `json:"from"`
    Seq   int         `json:"seq"`
    Clock VectorClock `json:"clock"`
    Body  string      `json:"body,omitempty"`
}

// MakeID builds a stable, lexicographically ordered id: "<node>:<8-digit seq>".
func MakeID(from string, seq int) string {
    return fmt.Sprintf("%s:%08d", from, seq)
}

causal/clock.go

package causal

import (
    "sort"
    "strconv"
    "strings"
)

// VectorClock maps a node ID to the number of messages from that node that
// have been delivered (the classic vector-clock component).
type VectorClock map[string]int

func NewClock() VectorClock { return VectorClock{} }

func (vc VectorClock) Clone() VectorClock {
    c := make(VectorClock, len(vc))
    for k, v := range vc {
        c[k] = v
    }
    return c
}

func (vc VectorClock) Get(node string) int { return vc[node] }

func (vc VectorClock) Set(node string, v int) { vc[node] = v }

// Inc increments the component for node and returns the new value.
func (vc VectorClock) Inc(node string) int {
    vc[node]++
    return vc[node]
}

// Merge folds other into vc using a component-wise maximum.
func (vc VectorClock) Merge(other VectorClock) {
    for k, v := range other {
        if v > vc[k] {
            vc[k] = v
        }
    }
}

// Max returns the component-wise maximum of a and b.
func Max(a, b VectorClock) VectorClock {
    c := a.Clone()
    c.Merge(b)
    return c
}

// LessEq reports whether a <= b component-wise (a is "dominated by" b).
func (a VectorClock) LessEq(b VectorClock) bool {
    for k, av := range a {
        if av > b[k] {
            return false
        }
    }
    return true
}

// Equal reports component-wise equality.
func (a VectorClock) Equal(b VectorClock) bool {
    return a.LessEq(b) && b.LessEq(a)
}

// Compare returns:
//
//  -1 if a < b  (a happens-before b)
//   1 if b < a  (b happens-before a)
//   0 if a == b
//   2 if a and b are concurrent
func (a VectorClock) Compare(b VectorClock) int {
    ab := a.LessEq(b)
    ba := b.LessEq(a)
    switch {
    case ab && ba:
        return 0
    case ab:
        return -1
    case ba:
        return 1
    default:
        return 2
    }
}

// String renders the clock with sorted keys so output is byte-for-byte stable
// across runs (Go map iteration order is randomized).
func (vc VectorClock) String() string {
    keys := make([]string, 0, len(vc))
    for k := range vc {
        keys = append(keys, k)
    }
    sort.Strings(keys)
    parts := make([]string, 0, len(keys))
    for _, k := range keys {
        parts = append(parts, k+":"+strconv.Itoa(vc[k]))
    }
    return "{" + strings.Join(parts, ",") + "}"
}

causal/node.go

package causal

import "sort"

// DefaultLossThreshold is the number K of live messages after which a
// predecessor that is known to exist but has not arrived is declared
// permanently lost. It is measured in distinct live messages, never in wall
// clock, so results are deterministic across runs and machines.
const DefaultLossThreshold = 5

// Node is one participant in the causally ordered broadcast layer.
type Node struct {
    ID        string
    Threshold int // K; <=0 means DefaultLossThreshold

    // delivered is the vector clock of delivered messages.
    delivered VectorClock
    // deliveryOrder is the exact per-node order messages were delivered in.
    deliveryOrder []string
    deliveredSet  map[string]bool

    // seen de-duplicates the unreliable transport.
    seen map[string]bool
    // live counts distinct messages that actually arrived (self-sends included).
    live int

    // holdback is the gap buffer: received but not yet causally deliverable.
    holdback map[string]Message
    // recvSeq gives a total arrival order used as the deterministic tie-break.
    recvSeq  map[string]int
    nextRecv int

    // horizon is the component-wise max of every clock seen. It is the
    // frontier of messages we know were *sent* to somebody.
    horizon VectorClock

    // missingSince[id] is the live-counter value when the gap id was first
    // noticed as missing.
    missingSince map[string]int
    lost         map[string]bool
    gapOrder     []string

    joined bool
    left   bool
}

// NewNode creates a node with the default loss threshold.
func NewNode(id string) *Node { return NewNodeK(id, DefaultLossThreshold) }

// NewNodeK creates a node with an explicit loss threshold K.
func NewNodeK(id string, k int) *Node {
    if k <= 0 {
        k = DefaultLossThreshold
    }
    return &Node{
        ID:           id,
        Threshold:    k,
        delivered:    NewClock(),
        deliveredSet: map[string]bool{},
        seen:         map[string]bool{},
        holdback:     map[string]Message{},
        recvSeq:      map[string]int{},
        horizon:      NewClock(),
        missingSince: map[string]int{},
        lost:         map[string]bool{},
    }
}

// Joined reports whether the node has been marked live.
func (n *Node) Joined() bool { return n.joined }

// Left reports whether the node has left the group.
func (n *Node) Left() bool { return n.left }

// Join marks the node live. A joining node starts with an empty clock, so its
// first broadcast is "<id>:00000001".
func (n *Node) Join() {
    n.joined = true
    n.left = false
}

// Leave marks the node as having departed. The node sends nothing further, so
// any outstanding gap that references it simply stops growing its horizon and
// is resolved by the ordinary K-live-message rule.
func (n *Node) Leave() { n.left = true }

// Broadcast increments the local clock, emits a message and self-delivers it
// immediately (a process always delivers its own broadcasts).
func (n *Node) Broadcast(body string) Message {
    seq := n.delivered.Inc(n.ID)
    msg := Message{
        ID:    MakeID(n.ID, seq),
        From:  n.ID,
        Seq:   seq,
        Clock: n.delivered.Clone(),
        Body:  body,
    }
    n.seen[msg.ID] = true
    n.live++
    n.horizon.Merge(msg.Clock)
    n.deliverLocked(msg)
    n.settle()
    return msg
}

// Receive feeds one transport delivery into the causal layer. Duplicates are
// ignored. Out-of-order messages are buffered until deliverable.
func (n *Node) Receive(msg Message) {
    if n.seen[msg.ID] {
        return // duplicate
    }
    if n.lost[msg.ID] {
        // The message surfaced after we already compacted over it and advanced
        // the delivered clock. Re-delivering it would violate the order we
        // already reported, so it is absorbed as a tombstone.
        return
    }
    n.seen[msg.ID] = true
    n.live++
    n.horizon.Merge(msg.Clock)
    n.recvSeq[msg.ID] = n.nextRecv
    n.nextRecv++

    if n.canDeliver(msg) {
        n.deliverLocked(msg)
    } else {
        n.holdback[msg.ID] = msg
    }
    n.settle()
}

// canDeliver is the causal delivery predicate:
//
//  Clock[From]      == delivered[From] + 1   (next in this sender's FIFO order)
//  Clock[j != From] <= delivered[j]          (all cross-node predecessors done)
func (n *Node) canDeliver(msg Message) bool {
    for node, c := range msg.Clock {
        if node == msg.From {
            if c != n.delivered.Get(node)+1 {
                return false
            }
        } else if c > n.delivered.Get(node) {
            return false
        }
    }
    return true
}

func (n *Node) deliverLocked(msg Message) {
    for node, c := range msg.Clock {
        if c > n.delivered.Get(node) {
            n.delivered.Set(node, c)
        }
    }
    n.deliveredSet[msg.ID] = true
    n.deliveryOrder = append(n.deliveryOrder, msg.ID)
    delete(n.holdback, msg.ID)
}

// pickReady returns the identifier of the deliverable holdback message with
// the smallest arrival sequence, giving a deterministic total order over
// concurrent messages. It returns ok=false when the buffer is blocked.
func (n *Node) pickReady() (string, bool) {
    best := ""
    bestSeq := -1
    for id, msg := range n.holdback {
        if !n.canDeliver(msg) {
            continue
        }
        s := n.recvSeq[id]
        if bestSeq == -1 || s < bestSeq {
            best, bestSeq = id, s
        }
    }
    return best, bestSeq != -1
}

// settle delivers everything that is currently enabled, then reclassifies
// gaps (which may enable more), until a fixed point is reached. It terminates
// because every iteration either delivers a message or marks a gap lost,
// both strictly monotone and bounded by the number of messages.
func (n *Node) settle() {
    for {
        changed := false
        for {
            id, ok := n.pickReady()
            if !ok {
                break
            }
            msg := n.holdback[id]
            delete(n.holdback, id)
            n.deliverLocked(msg)
            changed = true
        }
        if n.classifyGaps() {
            changed = true
        }
        if !changed {
            break
        }
    }
}

// classifyGaps decides which known-but-missing predecessors are permanently
// lost, then compacts the buffer by advancing the delivered clock over them.
// This is what bounds memory and prevents deadlock when the transport has
// permanently dropped a message.
//
// A gap "j:k" is noticed the first time some received message proves it was
// sent (its clock has component j >= k) while it is absent. Once the node has
// observed Threshold further live messages without receiving it, it is
// declared lost and recorded in the gap report.
func (n *Node) classifyGaps() bool {
    changed := false
    nodes := make([]string, 0, len(n.horizon))
    for j := range n.horizon {
        nodes = append(nodes, j)
    }
    sort.Strings(nodes)

    for _, j := range nodes {
        exp := n.horizon.Get(j)
        for n.delivered.Get(j) < exp {
            k := n.delivered.Get(j) + 1
            id := MakeID(j, k)
            if n.deliveredSet[id] {
                break // bookkeeping safety
            }
            if _, buffered := n.holdback[id]; buffered {
                break // the message exists; it is merely not deliverable yet
            }
            since, noticed := n.missingSince[id]
            if !noticed {
                n.missingSince[id] = n.live
                break // start the bounded wait for this head gap
            }
            if n.live-since < n.Threshold {
                break // still within the reordering window
            }
            // Permanent loss: compact the buffer over this predecessor.
            n.lost[id] = true
            n.gapOrder = append(n.gapOrder, id)
            n.delivered.Set(j, k)
            changed = true
        }
    }
    return changed
}

// DeliveryOrder returns a copy of the exact per-node delivery order.
func (n *Node) DeliveryOrder() []string {
    out := make([]string, len(n.deliveryOrder))
    copy(out, n.deliveryOrder)
    return out
}

// Gaps returns a copy of the unreachable predecessors declared lost at this
// node, in the order they were reclassified.
func (n *Node) Gaps() []string {
    out := make([]string, len(n.gapOrder))
    copy(out, n.gapOrder)
    return out
}

// HoldbackLen is the live size of the gap buffer (should stay bounded).
func (n *Node) HoldbackLen() int { return len(n.holdback) }

// DeliveredClone returns a copy of the delivered vector clock.
func (n *Node) DeliveredClone() VectorClock { return n.delivered.Clone() }

// HorizonClone returns a copy of the horizon vector clock.
func (n *Node) HorizonClone() VectorClock { return n.horizon.Clone() }

causal/runner.go

package causal

import (
    "fmt"
    "sort"
    "strings"
)

// Command is one entry of the captured send/receive trace. The transport's
// unreliability is expressed purely by which "deliver" commands exist and in
// what order they appear: dropping is an omitted deliver, reordering is a
// later position, duplication is a repeated deliver.
type Command struct {
    Op   string `json:"op"`             // join | leave | send | deliver
    Node string `json:"node"`           // actor (join/leave/send) or source
    To   string `json:"to,omitempty"`   // destination of a deliver
    Tag  string `json:"tag,omitempty"`  // logical message name for deliver
    Body string `json:"body,omitempty"` // payload for send
}

// Report is the deterministic result of running a trace.
type Report struct {
    Nodes      []string            `json:"nodes"`
    Deliveries map[string][]string `json:"deliveries"`
    Gaps       map[string][]string `json:"gaps"`
    Holdback   map[string]int      `json:"holdback"`
    Messages   map[string]Message  `json:"messages"`
}

// Runner replays a captured trace through the causal layer.
type Runner struct {
    K    int
    msgs map[string]Message
}

// NewRunner creates a runner with loss threshold k (0 => default).
func NewRunner(k int) *Runner {
    if k <= 0 {
        k = DefaultLossThreshold
    }
    return &Runner{K: k, msgs: map[string]Message{}}
}

// Run executes the trace and returns the report. Nodes referenced before a
// "join" command are auto-created joined, so a partial trace still runs.
func (r *Runner) Run(script []Command) *Report {
    nodes := map[string]*Node{}
    get := func(id string) *Node {
        n, ok := nodes[id]
        if !ok {
            n = NewNodeK(id, r.K)
            nodes[id] = n
        }
        return n
    }

    for _, c := range script {
        switch c.Op {
        case "join":
            get(c.Node).Join()
        case "leave":
            get(c.Node).Leave()
        case "send":
            msg := get(c.Node).Broadcast(c.Body)
            r.msgs[c.Tag] = msg
        case "deliver":
            msg, ok := r.msgs[c.Tag]
            if !ok {
                panic(fmt.Sprintf("deliver references unknown tag %q", c.Tag))
            }
            get(c.To).Receive(msg)
        default:
            panic("unknown op " + c.Op)
        }
    }

    rep := &Report{
        Deliveries: map[string][]string{},
        Gaps:       map[string][]string{},
        Holdback:   map[string]int{},
        Messages:   r.msgs,
    }
    for id, n := range nodes {
        rep.Nodes = append(rep.Nodes, id)
        rep.Deliveries[id] = n.DeliveryOrder()
        rep.Gaps[id] = n.Gaps()
        rep.Holdback[id] = n.HoldbackLen()
    }
    sort.Strings(rep.Nodes)
    return rep
}

// Format renders the report as stable, human-readable text.
func (rep *Report) Format() string {
    var b strings.Builder
    for _, id := range rep.Nodes {
        fmt.Fprintf(&b, "node %s\n", id)
        fmt.Fprintf(&b, "  delivery order: %s\n", strings.Join(rep.Deliveries[id], ", "))
        gaps := rep.Gaps[id]
        if len(gaps) == 0 {
            fmt.Fprintf(&b, "  gap report:     <none>\n")
        } else {
            fmt.Fprintf(&b, "  gap report:     %s\n", strings.Join(gaps, ", "))
        }
        fmt.Fprintf(&b, "  holdback size:  %d\n", rep.Holdback[id])
    }
    return b.String()
}

// Equal reports whether two reports are identical (used by the determinism
// check in tests): same delivery order, gaps, holdback sizes and messages.
func (rep *Report) Equal(other *Report) bool {
    if strings.Join(rep.Nodes, ",") != strings.Join(other.Nodes, ",") {
        return false
    }
    for _, id := range rep.Nodes {
        if strings.Join(rep.Deliveries[id], ",") != strings.Join(other.Deliveries[id], ",") {
            return false
        }
        if strings.Join(rep.Gaps[id], ",") != strings.Join(other.Gaps[id], ",") {
            return false
        }
        if rep.Holdback[id] != other.Holdback[id] {
            return false
        }
    }
    if len(rep.Messages) != len(other.Messages) {
        return false
    }
    for k, v := range rep.Messages {
        ov, ok := other.Messages[k]
        if !ok || !v.Clock.Equal(ov.Clock) || v.ID != ov.ID {
            return false
        }
    }
    return true
}

package causal

// DemoTrace is a captured send/receive trace that exercises every feature the
// problem names: two node joins (C and D), one node leave (B), reordering,
// duplicates, late arrivals, and one permanently lost pair of predecessors
// (A:2 and B:2) that node C must classify and compact over.
//
// The order of "deliver" commands *is* the observed transport order. Omitted
// delivers are drops; repeated delivers are duplicates; later positions are
// reorderings/late arrivals.
func DemoTrace() []Command {
    return []Command{
        // --- initial membership: A, B ---
        {Op: "join", Node: "A"},
        {Op: "join", Node: "B"},

        // concurrent broadcasts A1 and B1
        {Op: "send", Node: "A", Tag: "a1", Body: "a1"},
        {Op: "send", Node: "B", Tag: "b1", Body: "b1"},
        {Op: "deliver", To: "B", Tag: "a1"},
        {Op: "deliver", To: "A", Tag: "b1"},
        {Op: "deliver", To: "B", Tag: "a1"}, // duplicate -> ignored

        // causal second round: B2 depends on A1, A2 depends on B1
        {Op: "send", Node: "B", Tag: "b2", Body: "b2"},
        {Op: "send", Node: "A", Tag: "a2", Body: "a2"},
        {Op: "deliver", To: "A", Tag: "b2"},
        {Op: "deliver", To: "B", Tag: "a2"},

        // --- first join: C ---
        {Op: "join", Node: "C"},
        {Op: "send", Node: "C", Tag: "c1", Body: "c1"},
        {Op: "deliver", To: "A", Tag: "c1"},
        {Op: "deliver", To: "B", Tag: "c1"},

        // third round
        {Op: "send", Node: "A", Tag: "a3", Body: "a3"},
        {Op: "deliver", To: "B", Tag: "a3"},
        {Op: "send", Node: "B", Tag: "b3", Body: "b3"},

        // --- second join: D, with late/reordered delivery ---
        {Op: "join", Node: "D"},
        {Op: "send", Node: "D", Tag: "d1", Body: "d1"},

        // D sees A's stream completely out of order: 3, 2, 1 -- all within K.
        {Op: "deliver", To: "D", Tag: "a3"},
        {Op: "deliver", To: "D", Tag: "a2"},
        {Op: "deliver", To: "D", Tag: "a1"},
        {Op: "deliver", To: "D", Tag: "a2"}, // duplicate -> ignored
        {Op: "deliver", To: "D", Tag: "b1"}, // late arrival, still within K
        {Op: "deliver", To: "D", Tag: "b2"}, // late arrival, still within K
        {Op: "deliver", To: "D", Tag: "c1"},

        // C receives A1, B1, then the two messages that prove A2 and B2 exist.
        // A2 and B2 themselves are *never* delivered to C: permanent loss.
        {Op: "deliver", To: "C", Tag: "a1"},
        {Op: "deliver", To: "C", Tag: "b1"},
        {Op: "deliver", To: "C", Tag: "a3"},
        {Op: "deliver", To: "C", Tag: "b3"},

        // Pump enough distinctly-live traffic into C to exceed the loss
        // threshold so A2 and B2 are declared permanently lost and compacted.
        {Op: "send", Node: "A", Tag: "a4", Body: "a4"},
        {Op: "deliver", To: "C", Tag: "a4"},
        {Op: "send", Node: "D", Tag: "d2", Body: "d2"},
        {Op: "deliver", To: "C", Tag: "d2"},
        {Op: "send", Node: "C", Tag: "c2", Body: "c2"},
        {Op: "send", Node: "B", Tag: "b4", Body: "b4"},
        {Op: "deliver", To: "C", Tag: "b4"},
        {Op: "deliver", To: "C", Tag: "d1"},

package causal

import (
    "strings"
    "testing"
)

// idToMessage builds an ID -> Message index from a report.
func idToMessage(rep *Report) map[string]Message {
    m := map[string]Message{}
    for _, msg := range rep.Messages {
        m[msg.ID] = msg
    }
    return m
}

// assertCausalOrder is the central correctness invariant: a message may only
// be delivered once every causal predecessor is either already delivered or
// has been declared permanently lost. It also checks that no message is
// delivered twice and that lost predecessors are never delivered.
func assertCausalOrder(t *testing.T, rep *Report) {
    t.Helper()
    byID := idToMessage(rep)
    for _, node := range rep.Nodes {
        order := rep.Deliveries[node]
        pos := map[string]int{}
        for i, id := range order {
            if _, dup := pos[id]; dup {
                t.Fatalf("node %s delivered %s twice", node, id)
            }
            pos[id] = i
        }
        lost := map[string]bool{}
        for _, id := range rep.Gaps[node] {
            lost[id] = true
            if _, delivered := pos[id]; delivered {
                t.Fatalf("node %s both delivered and declared lost %s", node, id)
            }
        }
        for i, id := range order {
            msg, ok := byID[id]
            if !ok {
                t.Fatalf("node %s delivered unknown message %s", node, id)
            }
            for j := range msg.Clock {
                upto := msg.Clock[j]
                if j == msg.From {
                    upto = msg.Seq - 1 // own predecessors, excluding self
                }
                for k := 1; k <= upto; k++ {
                    p := MakeID(j, k)
                    pp, delivered := pos[p]
                    if delivered {
                        if pp > i {
                            t.Fatalf("node %s delivered %s before predecessor %s", node, id, p)
                        }
                        continue
                    }
                    if !lost[p] {
                        t.Fatalf("node %s delivered %s with unsatisfied, unclassified predecessor %s", node, id, p)
                    }
                }
            }
        }
    }
}

// TestDemoGolden pins the exact, deterministic result of the captured trace.
func TestDemoGolden(t *testing.T) {
    rep := NewRunner(0).Run(DemoTrace())

    wantDeliveries := map[string][]string{
        "A": {"A:00000001", "B:00000001", "A:00000002", "B:00000002", "C:00000001", "A:00000003", "A:00000004"},
        "B": {"B:00000001", "A:00000001", "B:00000002", "A:00000002", "C:00000001", "A:00000003", "B:00000003", "B:00000004"},
        "C": {"C:00000001", "A:00000001", "B:00000001", "C:00000002", "A:00000003", "B:00000003", "A:00000004", "B:00000004", "D:00000001", "D:00000002", "D:00000003"},
        "D": {"D:00000001", "A:00000001", "B:00000001", "A:00000002", "B:00000002", "C:00000001", "A:00000003", "D:00000002", "D:00000003"},
    }
    for node, want := range wantDeliveries {
        got := strings.Join(rep.Deliveries[node], ",")
        if got != strings.Join(want, ",") {
            t.Errorf("node %s delivery order\n got: %s\nwant: %s", node, got, strings.Join(want, ","))
        }
    }
    // Exactly node C permanently loses the dropped A:2 and B:2.
    if got := strings.Join(rep.Gaps["C"], ","); got != "A:00000002,B:00000002" {
        t.Errorf("C gap report = %q", got)
    }
    for _, node := range []string{"A", "B", "D"} {
        if len(rep.Gaps[node]) != 0 {
            t.Errorf("node %s unexpectedly reported gaps %v", node, rep.Gaps[node])
        }
    }

    for _, node := range rep.Nodes {
        if rep.Holdback[node] != 0 {
            t.Errorf("node %s left %d messages in holdback", node, rep.Holdback[node])
        }
    }

}

// TestLateArrivalNotClassifiedLost shows the K rule does not fire early: a
// predecessor delayed by fewer than K live messages is still delivered, not
// reported as a gap.
func TestLateArrivalNotClassifiedLost(t *testing.T) {
    const k = 4
    a, b := NewNodeK("A", k), NewNodeK("B", k)
    a.Join()
    b.Join()

    var msgs []Message
    for i := 1; i <= 6; i++ {
        msgs = append(msgs, a.Broadcast("m"))
    }
    // B sees 1, then 3,4,5 (fewer than K after the gap), then finally 2.
    b.Receive(msgs[0])
    b.Receive(msgs[2])
    b.Receive(msgs[3])
    b.Receive(msgs[4])
    if len(b.Gaps()) != 0 {
        t.Fatalf("premature loss classification: %v", b.Gaps())
    }
    b.Receive(msgs[1]) // late but in time
    for i := 5; i < 6; i++ {
        b.Receive(msgs[i])
    }
    if len(b.Gaps()) != 0 {
        t.Fatalf("late arrival misclassified: %v", b.Gaps())
    }
    if b.HoldbackLen() != 0 {
        t.Fatalf("holdback not drained: %d", b.HoldbackLen())
    }
    want := []string{"A:00000001", "A:00000002", "A:00000003", "A:00000004", "A:00000005", "A:00000006"}
    if strings.Join(b.DeliveryOrder(), ",") != strings.Join(want, ",") {
        t.Fatalf("delivery order = %v", b.DeliveryOrder())
    }
}

// TestPermanentLossBoundedBuffer proves the memory bound: after a predecessor
// is permanently dropped, at most K further live messages can pile up before
// the gap is classified and the buffer is compacted.
func TestPermanentLossBoundedBuffer(t *testing.T) {
    const k = 5
    a := NewNodeK("A", k)
    b := NewNodeK("B", k)
    a.Join()
    b.Join()

    // A broadcasts 1, 2, 3, ...; sequence 2 is *dropped* and never delivered.
    m1 := a.Broadcast("m1") // A:1
    b.Receive(m1)
    dropped := a.Broadcast("dropped") // A:2 -- dropped for B
    _ = dropped

    maxHoldback := 0
    var pending []Message
    for i := 3; i <= 40; i++ {
        pending = append(pending, a.Broadcast("m"))
    }
    for _, m := range pending {
        b.Receive(m)
        if n := b.HoldbackLen(); n > maxHoldback {
            maxHoldback = n
        }
    }
    if maxHoldback > k+1 {
        t.Fatalf("holdback grew to %d, bound is %d", maxHoldback, k+1)
    }
    if got := strings.Join(b.Gaps(), ","); got != "A:00000002" {
        t.Fatalf("gaps = %q", got)
    }
    if b.HoldbackLen() != 0 {
        t.Fatalf("holdback not compacted: %d", b.HoldbackLen())
    }
    if got := len(b.DeliveryOrder()); got != 39 {
        t.Fatalf("delivered %d messages, want 39", got)
    }
}

// TestNoClassificationGrowsUnbounded demonstrates the pre-fix failure mode:
// with the live-message classification effectively disabled (huge K) the gap
// buffer grows without bound and the node can never make progress.
func TestNoClassificationGrowsUnbounded(t *testing.T) {
    const n = 1000
    a := NewNodeK("A", 1<<30) // K effectively infinite: no reclassification
    b := NewNodeK("B", 1<<30)
    b.Receive(a.Broadcast("m1")) // A:1 arrives
    a.Broadcast("dropped")       // A:2 is dropped
    for i := 0; i < n; i++ {
        b.Receive(a.Broadcast("m")) // A:3.. blocked forever
    }
    if b.HoldbackLen() < n {
        t.Fatalf("expected unbounded holdback growth, got %d", b.HoldbackLen())
    }
    if len(b.Gaps()) != 0 {
        t.Fatalf("huge K should never classify a gap")
    }
}

// TestCrossNodeCausalDelivery exercises a delayed dependency that must be
// ordered across nodes even though it arrives out of order.
func TestCrossNodeCausalDelivery(t *testing.T) {
    a, b, x := NewNode("A"), NewNode("B"), NewNode("X")
    a.Join()
    b.Join()
    x.Join()

    a1 := a.Broadcast("a1")
    b.Receive(a1)
    b1 := b.Broadcast("b1")
    a2 := a.Broadcast("a2") // concurrent with b1

    // X receives them in an adversarial order.
    x.Receive(a2)
    x.Receive(b1)
    x.Receive(a1)
    if x.HoldbackLen() != 0 {
        t.Fatalf("holdback = %d, want 0", x.HoldbackLen())
    }
    // a1 must precede both a2 and b1; a2/b1 are concurrent.
    idx := map[string]int{}
    for i, id := range x.DeliveryOrder() {
        idx[id] = i
    }
    if idx[a1.ID] > idx[a2.ID] || idx[a1.ID] > idx[b1.ID] {
        t.Fatalf("causal violation in %v", x.DeliveryOrder())
    }
}

6. Guarantees, complexity and tuning

  • Safety. canDeliver never lets a message pass an unsatisfied predecessor. The only way past a predecessor is an explicit, reported loss classification.
  • Liveness. Once a predecessor is known-sent and absent for K distinct live messages, it is declared lost and the node continues. With K finite, no drop can stall a node forever.
  • Bounded memory. Peak holdback behind a head gap is K+1 messages; worst case O(K * number_of_senders). settle is a fixed-point loop that strictly decreases the buffer or advances the delivered clock each iteration.
  • Determinism. All iteration and tie-breaking is key-sorted; K is counted in live messages, never wall time. The 200-run test enforces this.
  • Tuning K. Set K to the transport's worst-case reordering/late window measured in live messages. Too small ⇒ false loss classification (the late message is absorbed as a tombstone). Too large ⇒ buffer lingers longer, but memory is still bounded by K. The default is DefaultLossThreshold = 5.
