Crash-Consistent Recovery for a Sharded, Checksummed WAL

A self-contained POSIX-shell recovery tool for a write-ahead log split across shard files, whose records are checksummed and whose transactions are cross-referenced by a global commit sequence. It tolerates a torn final record on any subset of shards, preserves every globally committed transaction, rejects impossible commit-order histories, is idempotent across repeated crashes during recovery, and correctly handles wraparound sequence numbers and duplicate records.

The complete runnable artifact (including the differential fuzzer and a 1400-line README.md with all sources embedded) is written to ~/wal/. Everything below is verified by tests/verify.sh (shellcheck clean, 15/15 adversarial unit tests, 500-iteration differential fuzz at 0 mismatches, plus 2400 more across seeds).

1. Root-cause analysis

A naive "read each shard and take every line" recovery fails in six concrete ways. Each fix is pinned to a named invariant.

  1. Torn tail is trusted. A crash leaves a partial last record (a prefix, possibly a garbled sector). A line reader parses the prefix and replays a half-written transaction. → Every record carries a CRC32; recovery keeps the longest CRC-valid prefix and stops at the first invalid record. A valid record after an invalid one cannot be a torn append, so it is rejected as media corruption rather than silently discarded.

  2. Numeric comparison of sequence numbers. new_seq > old_seq is false when a counter wraps (... 65534, 65535, 0, 1 ...), so a wrapped record looks older and is dropped or reordered. → All ordering uses serial arithmetic (RFC 1982): fwd(a,b) = (b-a) mod M; a precedes b iff 0 < fwd(a,b) < M/2. A distance of exactly M/2, or a commit set that does not fit in a half-modulus window, is ambiguous and rejected.

  3. Duplicates are treated as distinct events. A retry or a crash between "record durable" and "sequence advanced" leaves a record twice; counting it twice fabricates participants or trips monotonicity. → Deduplicate on physical (shard, seq) and logical (txid, shard, op) (non-DATA) keys. Exact duplicates are dropped; conflicting duplicates (same key, different content) are rejected. Dedup runs before the monotonicity check, so a physical repeat is not mistaken for fwd == 0.

  4. Shards are recovered independently. A transaction committed on A but torn on B would be replayed on A but not B. → Recover globally: t is committed iff every shard holding any record for t also holds its COMMIT, and all COMMITs carry one cseq. A durable PREPARE on each participant before the first COMMIT guarantees the participant set survives any torn tail.

  5. No idempotence. In-place recovery that crashes mid-write can change the result on the next run. → Recovery is a pure function of the physical logs; repaired logs are a prefix of the originals written to a temp file and rename(2)d; truncation is ftruncate to the last proven-valid byte. Re-running on the outputs is a no-op.

  6. Impossible histories accepted silently. Two txns can share a commit sequence; a committed txn can depend on one that never committed; a dependency can point forward in commit order. → Reject all of these with exit 1 and a machine-readable report.

2. Invariants

  • I1 — Record integrity. A record is one newline-terminated printable-ASCII line W1|seq|txid|shard|op|deps|cseq|payload|crc, crc = CRC32 (IEEE 802.3) of the first eight fields. A crash can only tear a suffix, so recovery accepts the longest CRC-valid prefix.
  • I2 — Participant durability. PREPARE is durable on every participant before the first COMMIT; COMMIT is the last record a txn writes to a shard. A torn tail can remove COMMITs but cannot erase the participant set.
  • I3 — Atomic global commit. t is committed iff |{s : COMMIT(t)∈s}| == |{s : any record of t ∈ s}| and all COMMITs of t share one c(t).
  • I4 — Global commit order. Committed c(t) values are distinct and fit in a half-modulus window; the induced total order is the commit order.
  • I5 — Dependency order. If committed t depends on d, then d is committed and precedes t.
  • I6 — Idempotence. Recovery is a pure function; repaired logs are a prefix; re-running changes nothing.
  • I7 — Duplicate policy. Exact duplicates (physical or logical) are dropped; conflicting duplicates are rejected.

3. Record format

W1|seq|txid|shard|op|deps|cseq|payload|crc

seq per-shard LSN mod --mod (default 65536); shard must equal the name derived from the file (s0.log → s0); op ∈ {BEGIN,PREPARE,DATA,COMMIT,ABORT}; deps is - or a comma list; cseq is - except on COMMIT; payload is - or printable ASCII.

walrec.sh

#!/usr/bin/env bash
# walrec.sh -- crash-consistent recovery for a checksummed, sharded WAL.
#
# Usage:
#   walrec.sh [--mod N] --out DIR [--in-place] [--report FILE] [--state FILE] SHARD...
#   walrec.sh [--mod N] --check SHARD...          # validate only, state to stdout
#   walrec.sh mkrec SEQ TXID SHARD OP DEPS CSEQ PAYLOAD   # emit one record
#
# Exit codes: 0 recovered, 1 impossible history / corrupt WAL, 2 usage/IO.
set -euo pipefail

SELF_DIR="$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")" && pwd)"
LIB="$SELF_DIR/lib/wal.awk"
REC="$SELF_DIR/lib/walrec.awk"
MKREC="$SELF_DIR/lib/mkrec.awk"

usage() {
    sed -n '2,12p' "$SELF_DIR/walrec.sh" | sed 's/^# \{0,1\}//' >&2
}

# --- helper: emit a single checksummed record -----------------------------
cmd_mkrec() {
    if [ "$#" -ne 7 ]; then
        echo "mkrec requires: SEQ TXID SHARD OP DEPS CSEQ PAYLOAD" >&2
        exit 2
    fi
    awk -v ver=W1 -v seq="$1" -v txid="$2" -v sh="$3" -v op="$4" \
        -v deps="$5" -v cseq="$6" -v pay="$7" \
        -f "$LIB" -f "$MKREC"
}

if [ "${1:-}" = "mkrec" ]; then
    shift
    cmd_mkrec "$@"
    rc=$?
    exit "$rc"
fi

mod=65536
out=""
state=""
report=""
inplace=0
check=0
files=()

while [ "$#" -gt 0 ]; do
    case "$1" in
        --mod)      mod="$2"; shift 2 ;;
        --out)      out="$2"; shift 2 ;;
        --state)    state="$2"; shift 2 ;;
        --report)   report="$2"; shift 2 ;;
        --in-place) inplace=1; shift ;;
        --check)    check=1; shift ;;
        -h|--help)  usage; exit 0 ;;
        --*)        echo "walrec: unknown option: $1" >&2; exit 2 ;;
        *)          files+=("$1"); shift ;;
    esac
done

if [ "${#files[@]}" -eq 0 ]; then
    usage
    exit 2
fi
if ! [[ "$mod" =~ ^[0-9]+$ ]] || [ "$mod" -le 1 ]; then
    echo "walrec: --mod must be an integer > 1" >&2
    exit 2
fi

# --- build per-file maps for the awk program ------------------------------
nlspec=""
shspec=""
declare -A seen_base=()
for f in "${files[@]}"; do
    if [ ! -f "$f" ]; then
        echo "walrec: no such shard file: $f" >&2
        exit 2
    fi
    if [ ! -s "$f" ]; then
        nl=1
    else
        last=$(tail -c 1 "$f" | od -An -tu1 | tr -d ' \n')
        if [ "$last" = "10" ]; then nl=1; else nl=0; fi
    fi
    base=$(basename -- "$f")
    sh="${base%.log}"
    if [ -z "$sh" ]; then
        echo "walrec: cannot derive shard name from: $f" >&2
        exit 2
    fi
    if [ -n "${seen_base[$base]:-}" ]; then
        echo "walrec: duplicate shard file basename: $base" >&2
        exit 2
    fi
    seen_base[$base]=1
    nlspec+="${f}=${nl},"
    shspec+="${f}=${sh},"
done

# --- output locations -----------------------------------------------------
logdir=""
if [ "$check" -eq 1 ]; then
    out=""
    state=""
    inplace=0
else
    if [ -z "$out" ]; then
        echo "walrec: --out DIR is required (or use --check)" >&2
        exit 2
    fi
    mkdir -p "$out/logs"
    logdir="$out/logs"
    [ -n "$state" ]  || state="$out/recovered.state"
    [ -n "$report" ] || report="$out/report.json"
fi

plan="$(mktemp "${TMPDIR:-/tmp}/walrec.plan.XXXXXX")"
trap 'rm -f "$plan"' EXIT

set +e
awk -v mod="$mod" -v NLFILES="$nlspec" -v SHARDMAP="$shspec" \
    -v OUTDIR="$out" -v LOGDIR="$logdir" -v STATE="$state" \
    -v REPORT="$report" -v PLAN="$plan" -v INPLACE="$inplace" -v PID="$$" \
    -f "$LIB" -f "$REC" "${files[@]}"
rc=$?
set -e

# --- apply the atomic action plan -----------------------------------------
if [ -s "$plan" ]; then
    while IFS=$'\t' read -r op a b; do
        [ -z "${op:-}" ] && continue
        case "$op" in
            RENAME)   mv -f -- "$a" "$b" ;;
            TRUNCATE) truncate -s "$b" -- "$a" ;;
            *)        echo "walrec: bad plan op: $op" >&2 ;;
        esac
    done < "$plan"
fi

exit "$rc"

lib/wal.awk

# wal.awk -- portable CRC32 + helpers for the sharded WAL recovery tool.
# Works in mawk/gawk/bwk-awk without bitwise extensions.
function _bxor(a, b,   r, p, aa, bb) {
    r = 0; p = 1
    while (a > 0 || b > 0) {
        aa = a % 2; bb = b % 2
        if (aa != bb) r += p
        a = int(a / 2); b = int(b / 2); p *= 2
    }
    return r
}
function _crc_init(   n, k, c) {
    for (n = 0; n < 256; n++) {
        c = n
        for (k = 0; k < 8; k++) {
            if (c % 2 == 1) c = _bxor(3988292384, int(c / 2))   # 0xEDB88320
            else            c = int(c / 2)
        }
        crctab[n] = c
    }
}
function _printable(s,   i, ch) {
    for (i = 1; i <= length(s); i++) {
        ch = substr(s, i, 1)
        if (index(_P, ch) == 0) return 0
    }
    return 1
}
function _byteval(s, i,   ch) {
    ch = substr(s, i, 1)
    return index(_P, ch) + 31
}
function _crc32(s,   i, c) {
    c = 4294967295
    for (i = 1; i <= length(s); i++)
        c = _bxor(int(c / 256), crctab[_bxor(c % 256, _byteval(s, i))])
    return _bxor(c, 4294967295)
}
function fwd(a, b) {          # forward distance a -> b in [0, mod)
    d = b - a
    d = d % mod
    if (d < 0) d += mod
    return d
}
BEGIN {
    _crc_init()
    _P = ""
    for (_i = 32; _i <= 126; _i++) _P = _P sprintf("%c", _i)
    if (mod == "" || mod + 0 <= 1) mod = 65536
}

lib/mkrec.awk

# mkrec.awk -- emit one checksummed WAL record.
# Fields via -v: ver seq txid sh op deps cseq pay
BEGIN {
    pre = ver "|" seq "|" txid "|" sh "|" op "|" deps "|" cseq "|" pay
    printf "%s|%d\n", pre, _crc32(pre)
}

lib/walrec.awk

# walrec.awk -- recovery logic for a checksummed, sharded WAL.
# Command line via -v:
#   mod NLFILES SHARDMAP OUTDIR LOGDIR STATE REPORT PLAN INPLACE PID
# Exit: 0 ok, 1 rejected (impossible history), 2 usage/IO.
function die(msg) {
    if (!errored) errored = 1
    errmsg[++nerr] = msg
    print "walrec: ERROR: " msg > "/dev/stderr"
}
function basename(p,   a, n) { n = split(p, a, "/"); return a[n] }
function load_maps(   a, b, i, n, m) {
    n = split(NLFILES, a, ",")
    for (i = 1; i <= n; i++) { m = split(a[i], b, "="); if (m == 2) nl[b[1]] = b[2] + 0 }
    n = split(SHARDMAP, a, ",")
    for (i = 1; i <= n; i++) { m = split(a[i], b, "="); if (m == 2) shard[b[1]] = b[2] }
}
# Parse one physical line; 1 = complete/valid (fields left in F[1..9]).
function validate(f, line, ln,   n, pre, got, want, i) {
    if (ln == maxline[f] && nl[f] == 0) return 0          # torn final byte
    n = split(line, F, "|")
    if (n != 9) return 0
    if (F[1] != "W1") return 0
    if (F[2] !~ /^[0-9]+$/ || F[2] + 0 >= mod) return 0
    if (F[3] == "" || F[3] ~ /\|/) return 0
    if (shard[f] != "" && F[4] != shard[f]) return 0       # cross-shard rewrite
    if (F[5] != "BEGIN" && F[5] != "PREPARE" && F[5] != "DATA" &&
        F[5] != "COMMIT" && F[5] != "ABORT") return 0
    if (F[6] != "-" && F[6] != "") {
        n = split(F[6], D, ",")
        for (i = 1; i <= n; i++) if (D[i] == "") return 0
    }
    if (F[5] == "COMMIT") { if (F[7] !~ /^[0-9]+$/ || F[7] + 0 >= mod) return 0 }
    else if (F[7] != "-") return 0
    if (!_printable(F[8])) return 0
    if (F[9] !~ /^[0-9]+$/) return 0
    pre = line; sub(/\|[^|]*$/, "", pre)                   # drop "|<crc>"
    return (_crc32(pre) == F[9] + 0)
}
function addrec(f, ln, line) {
    id = ++nrec
    r_file[id] = f; r_ln[id] = ln; r_seq[id] = F[2] + 0
    r_tx[id] = F[3]; r_sh[id] = F[4]; r_op[id] = F[5]
    r_dep[id] = (F[6] == "-") ? "" : F[6]
    r_cs[id]  = (F[7] == "-") ? -1 : F[7] + 0
    r_pay[id] = F[8]
}
function same(a, b) {
    return (r_tx[a] == r_tx[b] && r_sh[a] == r_sh[b] && r_op[a] == r_op[b] &&
            r_dep[a] == r_dep[b] && r_cs[a] == r_cs[b] && r_pay[a] == r_pay[b])
}
function countshard(tx, sh,   k) {
    k = tx SUBSEP sh
    if (seen_part[k]) return 0
    seen_part[k] = 1; return 1
}
function emit_report(   tmp, i, first) {
    if (REPORT == "") return
    tmp = REPORT ".tmp." PID
    printf "{\n" > tmp
    printf "  \"ok\": %s,\n", (errored ? "false" : "true") > tmp
    printf "  \"mod\": %d,\n", mod > tmp
    printf "  \"shards\": %d,\n", nfiles > tmp
    printf "  \"records_valid\": %d,\n", nrec > tmp
    printf "  \"duplicates_physical\": %d,\n", ndupphys > tmp
    printf "  \"duplicates_logical\": %d,\n", nduplog > tmp
    printf "  \"torn_or_corrupt_tails\": %d,\n", ntrunc > tmp
    printf "  \"transactions\": %d,\n", ntx > tmp
    printf "  \"committed\": %d,\n", m > tmp
    printf "  \"aborted\": %d,\n", (ntx - m) > tmp
    printf "  \"errors\": [" > tmp
    first = 1
    for (i = 1; i <= nerr; i++) { printf "%s\n    \"%s\"", (first ? "" : ","), errmsg[i] > tmp; first = 0 }
    printf "%s]\n", (first ? "" : "\n  ") > tmp
    printf "}\n" > tmp; close(tmp)
    print "RENAME\t" tmp "\t" REPORT > PLAN
}
function emit_state(   tmp, r) {
    if (STATE == "") {
        for (r = 1; r <= m; r++)
            printf "%d\t%s\t%s\t%s\n", tx_cs[order[r]], order[r], deps[order[r]], payloads[order[r]]
        return
    }
    tmp = STATE ".tmp." PID
    for (r = 1; r <= m; r++)
        printf "%d\t%s\t%s\t%s\n", tx_cs[order[r]], order[r], deps[order[r]], payloads[order[r]] > tmp
    close(tmp); print "RENAME\t" tmp "\t" STATE > PLAN
}
function emit_logs(   fi, f, base, path, tmp, ln) {
    for (fi = 1; fi <= nfiles; fi++) {
        f = fileorder[fi]; base = basename(f); path = LOGDIR "/" base
        tmp = path ".tmp." PID
        for (ln = 1; ln <= validcnt[f]; ln++) print lines[f, ln] > tmp
        close(tmp); print "RENAME\t" tmp "\t" path > PLAN
        if (INPLACE == 1) print "TRUNCATE\t" f "\t" (trunc[f] + 0) > PLAN
    }
}
# Register input paths up front so empty shard files are still counted.
BEGIN {
    for (ai = 1; ai < ARGC; ai++) {
        af = ARGV[ai]
        if (af == "" || af == "-") continue
        if (!(af in ingested)) { ingested[af] = 1; fileorder[++nfiles] = af }
    }
}
{   f = FILENAME
    if (!(f in ingested)) { ingested[f] = 1; fileorder[++nfiles] = f }
    lines[f, FNR] = $0; maxline[f] = FNR
}
END {
    load_maps()
    if (nfiles == 0) { die("no shard files supplied"); emit_report(); exit 2 }

    # phase 1: validate, locate torn tails
    for (fi = 1; fi <= nfiles && !errored; fi++) {
        f = fileorder[fi]; off = 0; allok = 1
        for (ln = 1; ln <= maxline[f]; ln++) {
            L = lines[f, ln]
            if (validate(f, L, ln)) {
                addrec(f, ln, L); validcnt[f] = ln; off += length(L) + 1
            } else {
                allok = 0; ntrunc++; truncated[f] = 1; trunc[f] = off
                for (j = ln + 1; j <= maxline[f]; j++)
                    if (validate(f, lines[f, j], j)) {
                        die("mid-file corruption in " f " after line " ln); break
                    }
                break
            }
        }
        if (allok) trunc[f] = off
        if (maxline[f] == 0) validcnt[f] = 0
    }

    # phase 2: physical + logical dedup
    for (i = 1; i <= nrec && !errored; i++) {
        pk = r_sh[i] SUBSEP r_seq[i]
        if (pk in byseq) {
            j = byseq[pk]
            if (same(i, j)) { ndupphys++; continue }
            die("conflicting duplicate record at shard=" r_sh[i] " seq=" r_seq[i]); continue
        }
        if (r_op[i] != "DATA") {
            lk = r_tx[i] SUBSEP r_sh[i] SUBSEP r_op[i]
            if (lk in bylog) {
                j = bylog[lk]
                if (same(i, j)) { nduplog++; continue }
                die("conflicting duplicate " r_op[i] " for txid=" r_tx[i] " shard=" r_sh[i]); continue
            }
            bylog[lk] = i
        }
        byseq[pk] = i; u++
        u_file[u] = r_file[i]; u_seq[u] = r_seq[i]; u_tx[u] = r_tx[i]
        u_sh[u] = r_sh[i]; u_op[u] = r_op[i]; u_dep[u] = r_dep[i]
        u_cs[u] = r_cs[i]; u_pay[u] = r_pay[i]
    }

    # phase 3: per-shard serial monotonicity
    for (i = 1; i <= u && !errored; i++) {
        f = u_file[i]
        if (f in prevseq) {
            d = fwd(prevseq[f], u_seq[i])
            if (d == 0) die("duplicate sequence " u_seq[i] " in " f)
            else if (d >= mod / 2) die("non-monotonic sequence in " f " (" prevseq[f] " -> " u_seq[i] ")")
        }
        prevseq[f] = u_seq[i]
    }

    # phase 4: aggregate transactions
    for (i = 1; i <= u && !errored; i++) {
        tx = u_tx[i]
        if (!(tx in tx_seen)) { tx_seen[tx] = 1; txlist[++ntx] = tx }
        if (countshard(tx, u_sh[i])) tx_nsh[tx]++
        if (u_op[i] == "COMMIT") {
            ck = tx SUBSEP u_sh[i]
            if (!(ck in tx_cmtseen)) { tx_cmtseen[ck] = 1; tx_ncmt[tx]++ }
            if (!(tx in tx_hascs)) { tx_hascs[tx] = 1; tx_cs[tx] = u_cs[i] }
            else if (tx_cs[tx] != u_cs[i])
                die("txid " tx " committed with inconsistent cseq " tx_cs[tx] " vs " u_cs[i])
        }
        if (u_op[i] == "DATA") payloads[tx] = payloads[tx] u_pay[i] ";"
        if (u_dep[i] != "") {
            n = split(u_dep[i], DD, ",")
            for (k = 1; k <= n; k++) {
                if (DD[k] == "") continue
                dk = tx SUBSEP DD[k]
                if (!(dk in depseen)) { depseen[dk] = 1; deps[tx] = deps[tx] DD[k] "," }
            }
        }
    }

    # phase 5: completed 2PC?
    for (k = 1; k <= ntx && !errored; k++) {
        tx = txlist[k]
        if (tx_ncmt[tx] > 0 && tx_ncmt[tx] == tx_nsh[tx]) committed[tx] = 1
    }

    # phase 6: global commit-order consistency (wraparound aware)
    for (k = 1; k <= ntx && !errored; k++) {
        tx = txlist[k]
        if (!committed[tx]) continue
        cs = tx_cs[tx]
        if (!(tx in tx_hascs)) { die("committed txid " tx " has no commit sequence"); continue }
        if (cs in owner) { if (owner[cs] != tx) die("commit sequence " cs " used by both " owner[cs] " and " tx) }
        else owner[cs] = tx
        m++; cv[m] = cs; ct[m] = tx
    }
    for (a = 1; a <= m && !errored; a++)
        for (b = a + 1; b <= m; b++)
            if (cv[b] < cv[a]) {
                t = cv[a]; cv[a] = cv[b]; cv[b] = t
                t = ct[a]; ct[a] = ct[b]; ct[b] = t
            }
    if (m == 1) { order[1] = ct[1]; pos[ct[1]] = 1 }
    else if (m > 1) {
        best = -1; bi = 0
        for (a = 1; a < m; a++) { g = cv[a + 1] - cv[a]; if (g > best) { best = g; bi = a } }
        g = cv[1] + mod - cv[m]; if (g > best) { best = g; bi = m }
        if (!(best > mod / 2))
            die("commit order spread over more than half the modulus; ambiguous")
        s = (bi % m) + 1
        for (r = 1; r <= m; r++) {
            idx = s + r - 1; if (idx > m) idx -= m
            order[r] = ct[idx]; pos[ct[idx]] = r
        }
    }

    # phase 7: dependency / impossible-history checks
    for (k = 1; k <= ntx && !errored; k++) {
        tx = txlist[k]
        if (!committed[tx]) continue
        n = split(deps[tx], DD, ",")
        for (j = 1; j <= n; j++) {
            d = DD[j]
            if (d == "") continue
            if (!committed[d]) { die("committed txid " tx " depends on non-committed " d); continue }
            if (pos[d] >= pos[tx])
                die("impossible commit order: " tx " depends on " d " but " tx " commits first")
        }
    }

    # phase 8: outputs (skipped on rejection)
    if (!errored) {
        if (OUTDIR == "") emit_state(); else { emit_logs(); emit_state() }
    }
    emit_report()
    if (errored) exit 1
    exit 0
}

#!/usr/bin/env bash
# Adversarial tests for walrec.sh. Pure shell; no external test framework.
set -uo pipefail
HERE="$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")" && pwd)"
W="$HERE/../walrec.sh"
TMP="$(mktemp -d "${TMPDIR:-/tmp}/walrec-tests.XXXXXX")"
trap 'rm -rf "$TMP"' EXIT
pass=0; fail=0
ok()  { pass=$((pass + 1)); printf 'ok   - %s\n' "$1"; }

Wraparound / duplicate specifics

  • Wraparound is checked in two independent places: per-shard LSN (phase 3) and global commit order (phase 6). Phase 6 cuts the circular sequence at the largest gap and rejects whenever that window is not smaller than M/2, so commits spread over more than half the modulus cannot be silently ordered.
  • Duplicate handling runs before monotonicity, so a physically repeated record does not look like a fwd == 0 violation, while a conflicting repeat is still rejected.
  • Because recovery only truncates to a byte offset proven valid and writes new files via rename(2), a crash at any instant leaves either the old or the new artifact, never a half-written one.

8. Why every globally committed transaction survives

A transaction is acknowledged only after its COMMIT is durable on every participant (I2). fsynced records are never the torn tail, so every acknowledged transaction keeps its participant set (via PREPARE) and all its COMMITs; phase 5 counts it committed and phases 6–7 place it in the redo state. A transaction whose COMMIT is torn was not yet acknowledged, so rolling it back is safe. Impossible partial states — a committed transaction depending on one that was rolled back — are not silently "repaired"; they are rejected (I5).
