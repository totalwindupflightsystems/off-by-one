Artifacts (all in ~/mpmc-ring/): - ring.go — bounded lock-free MPMC ring with 64-bit packed epoch:index cursors - ring_test.go — ABA, wrap-mid-drain, FIFO, stress, and torn-publish tests - SOLUTION.md — self-contained write-up (title, root-cause analysis, full fix, verification)

Verified: gofmt clean, go vet clean, go test -race -count=3 pass, 10× race stress pass, correct under GOMAXPROCS=1 and 16.

Root causes addressed (with the exact fix):

  1. ABA on the cursor after wraparound — a stale snapshot must not match after capacity steps. Fix: put epoch+index in one 64-bit word and CAS the whole word. At capacity 4, position 0 and 4 share index 0 but differ in epoch, so the stale CAS fails.
  2. Skipping an unpublished slot at wrap mid-drain — publication is claim-then-publish, so a producer can be preempted. Fix: consume only on exact slot.seq == head+1; on slot.seq < head+1 stop, never skip to a later published slot. TestWrapMidDrainNoSkip reserves position 6, publishes position 7, and asserts Dequeue returns empty until 6 is published.
  3. Naive two-counter split breaks liveness under preemption — (index, epoch) in two atomics has no single linearization point. An index-only CAS wins on stale state (TestNaiveSplitCounterABA shows two owners of one slot); failing retries can also starve a preempted thread. The single packed CAS restores lock-freedom: a failed CAS implies another thread succeeded.
  4. Memory ordering — producer must Store the token after the payload write, consumer must Store the recycle token after the payload read, with acquire loads on the matching reads. Go's sync/atomic is SC (stronger than release/acquire); comments mark where a weaker model needs explicit store(Release)/load(Acquire).

Epoch reclamation is embedded per slot: a producer may reclaim a slot only when slot.seq == tail, which happens only after a consumer has quiesced and stored head + capacity.

The full SOLUTION.md contains the complete ring.go + ring_test.go, the reasoning for each failure mode, and the exact commands/outputs.
