Crash-Consistent Snapshot & Recovery for Pinned eBPF Map Sets

Problem class: shell-20261011-bpf-map-freeze-crash-consistency

TL;DR

A "torn generation" is a set of files that mixes two writer generations. It happens because a filesystem guarantees atomicity per file, while a map set is many files plus metadata. The fix is to give the whole set one atomic commit point: write every member into a private staging directory, build a manifest that binds every member by size + SHA-256, seal the manifest, then publish the directory with a single rename(2). Recovery only considers sealed, fully verified generations and picks the greatest explicit generation integer — never mtime, never readdir order.

All 14 verification checks pass, including SIGKILL after every filesystem operation (commit: 5 windows, snapshot: 3, recover: 2).

1. Root-cause analysis

1.1 The real defect is cross-file atomicity

Updating N pinned maps plus M pin-metadata files is a multi-syscall operation. The kernel makes each write/rename atomic, but there is no kernel object representing "the map set". At any instant a crashed/frozen writer can leave a mix:

map/conn   = generation 8   <- updated
map/rules  = generation 7   <- not yet updated
meta/conn  = generation 8
meta/rules = generation 7

Every file is valid; the set is torn. A recovery tool that accepts it runs the application on incompatible generations.

1.2 Why the usual shortcuts fail

Shortcut Why it fails
"Newest mtime wins" Coarse granularity, equal mtimes, arbitrary touch, clock skew; the half-written file looks newest.
"Read readdir order" POSIX leaves directory order unspecified and it changes with dir_index/tmpfs hashing.
"Copy in place" A crash between copies leaves an indistinguishable mixed destination.
"Checksum each file" Validates files, not the set; a mixed set of valid files passes.
"Write the marker first" A reader trusting an early marker accepts a payload that was never written.
"BPF_MAP_FREEZE alone" Freezing one map does not freeze the set; map B can still be mid-update. Freeze is irreversible, so it must be the last mutating step of a global commit.
"Overwrite on resume" Not idempotent; a partial generation is indistinguishable from an empty one.

1.3 Invariants

  • I1 Every committed generation has a canonical manifest binding each member by type/name/size/SHA-256 plus a set hash over the generation integer.
  • I2 A generation becomes visible only via one rename(2); no intermediate visible state.
  • I3 "Latest" = greatest integer among verified generations. Timestamps and directory order are never read.
  • I4 An unverified generation is inert: ignored, never selected, never required.
  • I5 Re-running any command after a crash is idempotent.

2. Design

2.1 Layout

live/
  CURRENT                # cached pointer; NEVER authoritative
  .lock .staging/
  gens/<n>/
    MANIFEST             # canonical, content-hashed member list
    MANIFEST.sha256      # seal over MANIFEST
    map/<name>           # pin payload (map dump)
    meta/<name>          # pin metadata (bpftool show JSON + gen token)
store/
  by-gen/<n>-<sethash16>/  # immutable snapshot
  LATEST .lock .staging/

2.2 Manifest format

format 1
gen <integer>
member map <name> <size> <sha256>
member meta <name> <size> <sha256>
set <sha256("gen <n>\n" + sorted member lines, LC_ALL=C)>

Verification is three independent layers, all required: (1) seal matches MANIFEST; (2) set recomputes; (3) every member exists with the recorded size and hash. Sorting with LC_ALL=C removes locale/dir-order dependence.

2.3 Commit protocol

  1. flock the directory; remove orphaned staging dirs (safe under lock).
  2. Copy all members into .staging/<unique>/.
  3. Build + seal MANIFEST; fsync members, manifest, directory.
  4. mv -T .staging/<unique> gens/<n> — the single atomic commit.
  5. fsync parent; update cached pointer atomically.

A crash yields either a complete sealed generation or nothing visible.

2.4 Uncooperative writers (raw capture)

If there is no gens/, use read-verify-read: hash source, copy, hash copy, hash source again; commit only if all three agree, retrying up to BPFSNAP_RAW_ATTEMPTS then refusing. This catches per-file tearing but not a cross-map mix where a writer paused between two in-place updates. For that, BPFSNAP_REQUIRE_GEN=1 requires every meta/<name> to contain one gen=<token> line with all tokens equal. Since the writer updates payload then token, a uniform token set implies every payload of that generation is present.

2.5 Real eBPF mapping

Abstract Real object Command
map/<name> map contents bpftool map dump pinned <pin> --json
meta/<name> pin metadata bpftool map show pinned <pin> --json
commit freeze + publish bpftool map freeze pinned <pin> then seal one generation

3. Exact fix: bpfsnap.sh

#!/usr/bin/env bash
# bpfsnap - crash-consistent snapshot/recovery for a set of pinned eBPF maps
# plus their pin metadata.
#
# Invariants (see solution.md):
#   I1  Every committed generation is self-describing, content-hashed and
#       sealed.  Verification is a pure function of the bytes on disk.
#   I2  Publication is a single atomic rename(2); a generation directory
#       that is visible under gens/ (or by-gen/) always verifies.
#   I3  Selection of "latest" uses the explicit generation integer only.
#       Never mtime, never readdir order.
#   I4  A generation that does not verify is torn and is ignored, never
#       deleted, never selected.
#   I5  Re-running any command after a crash is idempotent.

set -euo pipefail

BPFSNAP_FORMAT=1

log() { printf 'bpfsnap: %s\n' "$*" >&2; }
die() { printf 'bpfsnap: error: %s\n' "$*" >&2; exit 1; }

# Fault injection used by the test suite.  BPFSNAP_CRASH_AT=<n> makes the
# process commit suicide right after the n-th filesystem-ish operation.
_ops=0
crashpoint() {
  _ops=$((_ops + 1))
  if [ -n "${BPFSNAP_CRASH_AT:-}" ] && [ "$_ops" -eq "$BPFSNAP_CRASH_AT" ]; then
    printf 'bpfsnap: injected crash after op %d (%s)\n' "$_ops" "$1" >&2
    kill -9 "$$"
  fi
}

sha256_file() { sha256sum -- "$1" | awk '{print $1}'; }
size_of()     { stat -c %s -- "$1"; }
valid_name()  { [[ "$1" =~ ^[A-Za-z0-9_.-]+$ ]]; }

fsync_path() {
  [ -e "$1" ] || return 0
  sync -d -- "$1" 2>/dev/null || sync 2>/dev/null || true
}
fsync_dir() {
  [ -d "$1" ] || return 0
  sync -d -- "$1" 2>/dev/null || sync 2>/dev/null || true
}

# Deterministic, locale-independent member enumeration.
collect_members() {
  local root="$1" type f base
  for type in map meta; do
    [ -d "$root/$type" ] || continue
    for f in "$root/$type"/*; do
      [ -f "$f" ] || continue
      base="${f##*/}"
      valid_name "$base" || { log "ignoring member with invalid name: $base"; continue; }
      printf '%s\t%s\n' "$type" "$base"
    done
  done | LC_ALL=C sort
}

# build_manifest <gen> <root> <body-out> <manifest-out>  (sets SET_HASH)
SET_HASH=""
build_manifest() {
  local gen="$1" root="$2" body="$3" manifest="$4"
  local type name f size hash
  : > "$body"
  while IFS=$'\t' read -r type name; do
    f="$root/$type/$name"
    size="$(size_of "$f")"
    hash="$(sha256_file "$f")"
    printf 'member %s %s %s %s\n' "$type" "$name" "$size" "$hash" >> "$body"
    crashpoint "hash $type/$name"
  done < <(collect_members "$root")

  SET_HASH="$( { printf 'gen %s\n' "$gen"; cat "$body"; } | sha256sum | awk '{print $1}' )"
  {
    printf 'format %s\n' "$BPFSNAP_FORMAT"
    printf 'gen %s\n' "$gen"
    cat "$body"
    printf 'set %s\n' "$SET_HASH"
  } > "$manifest"
}

# verify_gen <dir> ; all three layers must agree
verify_gen() {
  local dir="$1"
  [ -f "$dir/MANIFEST" ] || return 1
  [ -f "$dir/MANIFEST.sha256" ] || return 1

  local seal expected
  seal="$(awk 'NR==1{print $1}' "$dir/MANIFEST.sha256")"
  expected="$(sha256_file "$dir/MANIFEST")"
  [ -n "$seal" ] && [ "$seal" = "$expected" ] || return 1

  local format="" gen="" set="" tag=""
  local body; body="$(mktemp)"
  while IFS= read -r line; do
    case "$line" in
      "format "*) format="${line#format }" ;;
      "gen "*)    gen="${line#gen }" ;;
      "set "*)    set="${line#set }" ;;
      "member "*) printf '%s\n' "$line" >> "$body" ;;
      *) return 1 ;;
    esac
  done < "$dir/MANIFEST"

  [ "$format" = "$BPFSNAP_FORMAT" ] || { rm -f "$body"; return 1; }
  [ -n "$gen" ] && [ -n "$set" ] || { rm -f "$body"; return 1; }

  local recomputed
  recomputed="$( { printf 'gen %s\n' "$gen"; cat "$body"; } | sha256sum | awk '{print $1}' )"
  rm -f "$body"
  [ "$recomputed" = "$set" ] || return 1

  local type name size hash f
  while IFS=' ' read -r tag type name size hash; do
    [ "$tag" = "member" ] || return 1
    f="$dir/$type/$name"
    [ -f "$f" ] || return 1
    [ "$(size_of "$f")" = "$size" ] || return 1
    [ "$(sha256_file "$f")" = "$hash" ] || return 1
  done < <(grep '^member ' "$dir/MANIFEST" || true)
  return 0
}

# commit_gen <live> <workdir> <gen>
commit_gen() {
  local live="$1" work="$2" gen="$3"
  case "$gen" in ''|*[!0-9]*) die "generation must be a non-negative integer" ;; esac
  mkdir -p "$live/gens" "$live/.staging"

  exec 8>"$live/.lock"
  flock 8
  local stage="$live/.staging/commit-$gen-$$"
  rm -rf "$stage"; mkdir -p "$stage/map" "$stage/meta"
  cp -a "$work/map/." "$stage/map/" 2>/dev/null || true
  cp -a "$work/meta/." "$stage/meta/" 2>/dev/null || true
  crashpoint "copy work -> commit stage"

  build_manifest "$gen" "$stage" "$stage/.body" "$stage/MANIFEST"
  rm -f "$stage/.body"
  ( cd "$stage" && sha256sum MANIFEST > MANIFEST.sha256 )
  fsync_path "$stage/MANIFEST"
  fsync_path "$stage/MANIFEST.sha256"
  fsync_dir "$stage"

  rm -rf "$live/gens/$gen"
  mv -T "$stage" "$live/gens/$gen"
  crashpoint "publish live generation"
  fsync_dir "$live/gens"

  printf '%s\n' "$gen" > "$live/.current.tmp.$$"
  mv -T "$live/.current.tmp.$$" "$live/CURRENT"
  crashpoint "publish CURRENT pointer"
  fsync_dir "$live"
  flock -u 8
  log "committed live generation $gen"
}

list_verified_gens() {
  local live="$1" d name
  for d in "$live/gens"/*; do
    [ -d "$d" ] || continue
    name="${d##*/}"
    case "$name" in ''|*[!0-9]*) continue ;; esac
    if verify_gen "$d"; then printf '%s\n' "$name"; fi
  done
}

pick_latest_live() { list_verified_gens "$1" | sort -n | tail -n1; }

# ---- raw (uncooperative writer) capture --------------------------------
hash_members() {
  local root="$1" type name f
  while IFS=$'\t' read -r type name; do
    f="$root/$type/$name"
    if [ ! -f "$f" ]; then printf 'MISSING %s %s\n' "$type" "$name"; continue; fi
    printf '%s %s %s %s\n' "$type" "$name" "$(size_of "$f")" "$(sha256_file "$f")"
  done < <(collect_members "$root")
}

copy_raw() {
  local src="$1" dst="$2"
  mkdir -p "$dst/map" "$dst/meta"
  cp -a "$src/map/." "$dst/map/" 2>/dev/null || true
  cp -a "$src/meta/." "$dst/meta/" 2>/dev/null || true
}

raw_gen_tokens() {
  local root="$1" type name f token
  while IFS=$'\t' read -r type name; do
    [ "$type" = meta ] || continue
    f="$root/meta/$name"
    [ -f "$f" ] || { printf '<missing>\n'; continue; }
    token="$(sed -n 's/^gen[=:][[:space:]]*\([A-Za-z0-9_.-]\{1,\}\).*/\1/p' "$f" | head -n1)"
    printf '%s\n' "${token:-<none>}"
  done < <(collect_members "$root")
}

raw_gen_uniform() {
  local root="$1" tokens distinct
  [ "${BPFSNAP_REQUIRE_GEN:-0}" = "1" ] || return 0
  tokens="$(raw_gen_tokens "$root")"
  printf '%s' "$tokens" | grep -q '<none>\|<missing>' && return 1
  distinct="$(printf '%s\n' "$tokens" | LC_ALL=C sort -u | wc -l)"
  [ "$distinct" -eq 1 ]
}

next_seq_for() {
  local store="$1" d n max=0
  for d in "$store/by-gen"/*; do
    [ -d "$d" ] || continue
    n="${d##*/}"; n="${n%%-*}"
    case "$n" in ''|*[!0-9]*) continue ;; esac
    [ "$n" -gt "$max" ] && max="$n"
  done
  printf '%s\n' "$((max + 1))"
}

snapshot_raw() {
  local src="$1" store="$2" max_attempts="${BPFSNAP_RAW_ATTEMPTS:-8}"
  local attempt=0 h0 h1 hs stage seq id final set

  exec 9>"$store/.lock"
  flock 9
  rm -rf "$store/.staging"/*

  collect_members "$src" | grep -q . || die "live source $src has no members"

  while [ "$attempt" -lt "$max_attempts" ]; do
    attempt=$((attempt + 1))
    h0="$(hash_members "$src")"
    stage="$store/.staging/raw-$$"
    rm -rf "$stage"; mkdir -p "$stage"
    copy_raw "$src" "$stage"
    crashpoint "raw copy live -> store stage"
    hs="$(hash_members "$stage")"
    h1="$(hash_members "$src")"
    if [ "$h0" = "$h1" ] && [ "$h0" = "$hs" ] && raw_gen_uniform "$src"; then
      set="$(printf '%s\n' "$hs" | sha256sum | awk '{print $1}')"
      local suf="${set:0:16}" existing=""
      for d in "$store/by-gen"/*-raw"$suf"; do
        [ -d "$d" ] || continue
        if verify_gen "$d"; then existing="${d##*/}"; break; fi
      done
      if [ -n "$existing" ]; then
        rm -rf "$stage"
        log "raw snapshot content $suf already present as $existing (idempotent)"
        update_latest "$store" "$existing"; flock -u 9; return 0
      fi
      seq="$(next_seq_for "$store")"
      id="$seq-raw$suf"
      final="$store/by-gen/$id"
      build_manifest "$seq" "$stage" "$stage/.body" "$stage/MANIFEST"
      rm -f "$stage/.body"
      ( cd "$stage" && sha256sum MANIFEST > MANIFEST.sha256 )
      verify_gen "$stage" || { rm -rf "$stage"; die "raw staged copy failed verification"; }
      fsync_dir "$stage"
      rm -rf "$final"
      mv -T "$stage" "$final"
      crashpoint "publish raw store generation"
      fsync_dir "$store/by-gen"
      update_latest "$store" "$final"
      flock -u 9
      log "raw snapshotted seq $seq as $id (attempt $attempt)"
      return 0
    fi
    rm -rf "$stage"
    log "live source changed during capture (attempt $attempt); retrying"
  done
  flock -u 9
  die "live source $src did not stabilise after $max_attempts attempts; refusing to publish a torn set"
}

# ---- snapshot ----------------------------------------------------------
update_latest() {
  local store="$1" id="$2"
  printf '%s\n' "$id" > "$store/.latest.tmp.$$"
  mv -T "$store/.latest.tmp.$$" "$store/LATEST"
  crashpoint "publish store LATEST"
  fsync_dir "$store"
}

copy_payload() {
  local src="$1" dst="$2"
  mkdir -p "$dst/map" "$dst/meta"
  cp -a "$src/map/." "$dst/map/" 2>/dev/null || true
  cp -a "$src/meta/." "$dst/meta/" 2>/dev/null || true
  cp -a "$src/MANIFEST" "$src/MANIFEST.sha256" "$dst/"
}

snapshot() {
  local live="$1" store="$2"
  mkdir -p "$store/by-gen" "$store/.staging"

  if [ ! -d "$live/gens" ]; then
    snapshot_raw "$live" "$store"
    return 0
  fi

  exec 9>"$store/.lock"
  flock 9
  rm -rf "$store/.staging"/*

  local lgen; lgen="$(pick_latest_live "$live")"
  [ -n "$lgen" ] || die "no verified live generation under $live/gens"
  local srcdir="$live/gens/$lgen"
  local set; set="$(awk '/^set /{print $2; exit}' "$srcdir/MANIFEST")"
  local id="$lgen-${set:0:16}"
  local final="$store/by-gen/$id"

  if [ -d "$final" ] && verify_gen "$final"; then
    log "store already has $id (idempotent)"
    update_latest "$store" "$id"; flock -u 9; return 0
  fi

  local stage="$store/.staging/$id.$$"
  rm -rf "$stage"; mkdir -p "$stage"
  copy_payload "$srcdir" "$stage"
  crashpoint "copy live -> store stage"

  if ! verify_gen "$stage"; then
    rm -rf "$stage"; die "staged copy of live generation $lgen failed verification"
  fi
  fsync_dir "$stage"
  rm -rf "$final"
  mv -T "$stage" "$final"
  crashpoint "publish store generation"
  fsync_dir "$store/by-gen"
  update_latest "$store" "$id"
  flock -u 9
  log "snapshotted live generation $lgen as $id"
}

list_verified_store() {
  local store="$1" d name g
  for d in "$store/by-gen"/*; do
    [ -d "$d" ] || continue
    name="${d##*/}"; g="${name%%-*}"
    case "$g" in ''|*[!0-9]*) continue ;; esac
    if verify_gen "$d"; then printf '%s\n' "$name"; fi
  done
}

pick_latest_store() {
  list_verified_store "$1" | LC_ALL=C sort -t- -k1,1n -k2,2 | tail -n1
}

# ---- recover -----------------------------------------------------------
recover() {
  local store="$1" dest="$2"
  mkdir -p "$store/by-gen"
  mkdir -p "$(dirname "$dest")"
  local dest_abs
  dest_abs="$(cd "$(dirname "$dest")" && pwd)/$(basename "$dest")"

  exec 9>"$store/.lock"
  flock 9
  rm -rf "$store/.staging"/*

  local id; id="$(pick_latest_store "$store")"
  [ -n "$id" ] || die "no verified snapshot under $store/by-gen"
  local src="$store/by-gen/$id"
  local versions="$dest_abs.versions"
  mkdir -p "$versions"
  rm -rf "$versions"/.stage.*
  local target="$versions/$id"

  if [ ! -d "$target" ] || ! verify_gen "$target" 2>/dev/null; then
    local stage="$versions/.stage.$$"
    rm -rf "$stage"; mkdir -p "$stage"
    copy_payload "$src" "$stage"
    if ! verify_gen "$stage"; then rm -rf "$stage"; die "recover copy failed verification"; fi
    fsync_dir "$stage"
    rm -rf "$target"
    mv -T "$stage" "$target"
    crashpoint "materialise recovery"
    fsync_dir "$versions"
  fi

  if [ -e "$dest_abs" ] && [ ! -L "$dest_abs" ]; then
    mv -T "$dest_abs" "$dest_abs.pre-recover.$$"
  fi
  ln -sfn "$target" "$dest_abs.tmp.$$"
  mv -T "$dest_abs.tmp.$$" "$dest_abs"
  crashpoint "publish recovery symlink"
  fsync_dir "$(dirname "$dest_abs")"
  flock -u 9
  log "recovered $id -> $dest_abs"
}

usage() {
  cat >&2 <<'EOF'
usage: bpfsnap <command> [args]
  commit <live> <workdir> <gen>   seal+atomically publish a live generation
  snapshot <live> <store>         copy newest verified live gen into store
  recover <store> <dest>          atomically expose newest verified snapshot
  verify <dir>                    verify any generation directory
  latest <live|store>             print newest verified generation id
EOF
  exit 2
}

main() {
  local cmd="${1:-}"
  case "$cmd" in
    commit)   [ $# -eq 4 ] || usage; shift; commit_gen "$@" ;;
    snapshot) [ $# -eq 3 ] || usage; shift; snapshot "$@" ;;
    recover)  [ $# -eq 3 ] || usage; shift; recover "$@" ;;
    verify)   [ $# -eq 2 ] || usage; verify_gen "$2" && echo "OK $2" ;;
    latest)   [ $# -eq 2 ] || usage
              if [ -d "$2/gens" ]; then pick_latest_live "$2"; else pick_latest_store "$2"; fi ;;
    *) usage ;;
  esac
}

main "$@"

4. Production adapter (bpfsnap-bpftool.sh, full source in /workspace)

Walks the bpffs tree in LC_ALL=C order, writes one gen=<n> token into each metadata file, and dumps each map:

bpftool map show pinned "$pin" --json   > meta-run   # metadata
bpftool map dump pinned "$pin" --json   > map-run     # payload
# then: bpfsnap.sh commit "$(dirname "$WORK")/live" "$WORK" "$GEN"

Example:

sudo mount -t bpf bpffs /sys/fs/bpf
sudo bpfsnap-bpftool.sh /sys/fs/bpf /var/lib/bpfsnap/work 42
sudo bpfsnap.sh snapshot /var/lib/bpfsnap/live  /var/lib/bpfsnap/store
sudo bpfsnap.sh recover  /var/lib/bpfsnap/store /run/bpf/active

6. Operational notes

  • Same filesystem required for staging and destination so rename(2) is atomic.
  • Durability: sync -d is applied to members, manifests and parent directories around the commit rename; a surviving directory entry is re-verified next run.
  • Concurrency: writers and the utility share flock on .lock; sealed capture only reads immutable published dirs, so it never blocks on a frozen writer.
  • GC: generations are immutable; oldest deletion never harms newest recovery, so GC is kept out of the hot path.
  • Limitation: raw capture guarantees per-file integrity and (with BPFSNAP_REQUIRE_GEN=1) cross-map consistency; a writer that publishes no generation token requires the sealed generation protocol.
