Root cause

The cache released inFlight only in .finally() and wrote the TTL cache only in .then(). A probe whose awaited fetch never settled reached neither: inFlight stayed set forever and the cache was never populated, so the TTL branch was never satisfied and the fresh path was never taken. Every later caller received the same dead promise. This explains both the permanent poison and the 0% CPU / 0-socket signature (parked await, not a loop).

Fix highlights

  • withDeadline guarantees every probe settles → cleanup always runs.
  • Cache: inner deadline, cache only settled values, watchdog force-releases the slot, generation counter blocks stale writes, reset() for no-restart recovery.
  • Handler: one absolute deadline, each sub-probe gets only the remaining budget (two hung probes can't stack budgets), always answers 503 + deadline_exceeded:[...] with the reason in each section's note.
  • Watchdog: HUNG → exit 3 so escalation can't restart-loop a healthy daemon.
