What the diagnosis found

The failure class has five independent root causes; four are standard, one is the subtle killer:

  1. Global-gensym renaming is neither hygienic (a macro temp can capture a user argument) nor stable (a global counter renumbers everything after an unrelated edit, invalidating caches).
  2. Caching by spelling instead of resolved binding identity lets an unrelated edit capture a reused expansion.
  3. Over-broad invalidation (re-expanding the whole module) defeats incrementality and perturbs generated scopes.
  4. Lost source locations because templates are built without loc.
  5. Lexical scopes applied after macro expansion — the bug that survives fixes 1–4. If you expand first and then assign lexical scopes, a macro-introduced free identifier receives the use-site scope, so subset resolution lets a local binder capture it: scheme (define-syntax use-helper (syntax-rules () ((_ x) (helper x)))) (let ((helper 42)) (use-helper 5)) ; naive post-pass: helper binds to the local!

The exact fix

A scope-set model (Flatt's Binding as Sets of Scopes) with strict ordering:

  • Binding forms (lambda/let) add a fresh lexical scope to binder + body.
  • Each macro expansion adds a fresh macro scope only to template-origin syntax; arguments are cloned untouched.
  • A reference binds to the largest scope set that is a subset of the reference's scopes.
  • Scopes come from a counter reset per top-level form, making expansion reproducible and cache-stable.
  • Expansion and resolution run in one pass (process), so lexical scopes are applied to the raw use before the macro fires. This is what makes use-helper stay free.
  • Cache validity = source hash + hashes of every macro/top-level value actually used; reverse dependency edges give the smallest sound recomputation region.
  • Introduced nodes inherit the macro-use loc; arguments keep theirs.

function process(node, env, macroEnv, ctx) {
  if (node.type === 'symbol') { /* resolve by largest subset */ }
  const head = node.items[0];
  if (head && head.type === 'symbol') {
    if (macroEnv.has(head.name)) {
      const macro = macroEnv.get(head.name);
      for (const rule of macro.rules) {
        const binds = match(rule.pattern, node, macro.literals, {});
        if (binds) {
          ctx.usedMacros.add(macro.name);
          const scope = ctx.freshScope();
          // template gets `scope`; substituted args do not
          const inst = instantiate(rule.template, binds, scope, node.loc);
          return process(inst, env, macroEnv, ctx);   // reassign result!
        }
      }
    }
    if (head.name === 'let') {
