Conservative Nonzero-Winding Scanline Rasterizer with Exact Viewport Clipping

Problem class: js-nonzero-winding-conservative-rasterizer-clip Runtime: Node.js 20+ (verified on v22) · Language: JavaScript (CommonJS)

1. Problem statement

Implement a scanline polygon rasterizer that:

  1. fills self-intersecting paths under the nonzero winding rule;
  2. is conservative — no pixel whose unit square intersects the filled region may be omitted;
  3. clips exactly to an integer viewport without flipping winding at the boundary;
  4. flattens quadratic Béziers within a stated tolerance;
  5. supports sub-pixel vertices;
  6. supports holes created by opposite-winding subpaths;
  7. emits a deterministic 8-bit-per-pixel coverage mask that is invariant to direction reversal for hole-free shapes.

2. Root-cause analysis

The failures this class of task exhibits come from six independent mistakes:

# Symptom Root cause Fix
1 Holes filled, or self-overlaps vanish Uses even-odd/XOR, or sums signed area. Nonzero needs winding != 0; same-winding overlaps must stay filled. Accumulate a directed winding number per crossing and keep spans where W != 0.
2 Reversing a shape changes the mask Edge orientation leaks into the intersection math; x = x1 + (y-y1)·dx/dy is not bit-identical to the reversed formula. Store edges canonicalised (lower-y endpoint first + explicit sign). The formula then depends only on undirected geometry.
3 Winding flips at the clip boundary Clipping the polygon (Sutherland–Hodgman) creates/discards/reorders boundary edges, changing the winding reaching the interior. Never clip the polygon. Gather crossings from all edges, accumulate winding globally, then clip the resulting filled x-spans to [x0,x1).
4 Thin slivers / tangencies omitted Pixel-centre or single-scanline sampling misses geometry thinner than the sample grid. Coverage analytic in x, supersampled in y, plus a conservative pass forcing any edge-touched pixel to >= 1.
5 Flattened curves exceed tolerance Fixed subdivision count / flatness test ignoring the control point. Adaptive de Casteljau using the perpendicular distance of the control point to the chord; subdivision is reversal-symmetric.
6 Non-deterministic output Unstable sorts, Map/Set iteration order, random jitter. Total order on crossings (x, then sign), typed arrays only, no ambient state.

A subtle point on (2): nonzero winding is already sign-insensitive, so a correct implementation survives reversal in exact arithmetic. The bitwise guarantee comes from canonical edges, which make floating-point rounding identical as well.

3. Exact fix — complete implementation

'use strict';

/**
 * Conservative nonzero-winding scanline polygon rasterizer.
 *
 * Public API
 * ----------
 *   rasterize(path, options) -> Uint8Array
 *
 *   path    : Array of SVG-like commands:
 *               ['M', x, y]
 *               ['L', x, y]
 *               ['Q', cx, cy, x, y]   // quadratic Bezier
 *               ['Z']                 // close current subpath
 *             Subpaths that are left open are closed implicitly for filling,
 *             exactly as SVG `fill` does.
 *
 *   options :
 *     width, height      output mask size (required)
 *     viewport          {x0,y0,x1,y1} integer half-open pixel rect to rasterize
 *                       (default: the whole image).  Pixels outside stay 0.
 *     bezierTolerance   max chord deviation for Q flattening (default 0.1)
 *     verticalSamples   sub-scanlines per pixel row (default 16)
 *
 *   returns : Uint8Array length width*height, row-major (y*width + x),
 *             value 0..255 = quantized coverage fraction.
 *
 * Guarantees
 * ----------
 *  - Nonzero winding rule, so opposite-winding subpaths punch holes and
 *    self-overlap that raises |W| above 1 stays filled.
 *  - Conservative: every pixel whose square intersects the filled region
 *    (including mere tangency) receives a value >= 1.
 *  - Direction-reversal invariant for hole-free shapes: coverage is computed
 *    from a direction-canonical edge representation so the bit pattern is
 *    identical when every subpath is reversed.
 *  - Deterministic: only IEEE-754 double arithmetic and a total order on
 *    crossings; no Map/Set iteration or random state is involved.
 */

// ---------------------------------------------------------------------------
// small geometry helpers
// ---------------------------------------------------------------------------

function cross2(ax, ay, bx, by) {
  return ax * by - ay * bx;
}

/**
 * Upper bound on the deviation of the quadratic (p0,p1,p2) from its chord.
 * Used to decide when to stop recursive de Casteljau flattening.
 */
function quadFlatness(x0, y0, x1, y1, x2, y2) {
  const dx = x2 - x0;
  const dy = y2 - y0;
  const len2 = dx * dx + dy * dy;
  if (len2 < 1e-24) {
    // Chord is degenerate: fall back to the length of the control leg.
    return Math.hypot(x1 - x0, y1 - y0);
  }
  // Perpendicular distance from the control point to the chord line.
  // The curve's maximum distance to the chord is exactly half of this,
  // so using the full value is a safe (stricter) flatness test.
  return Math.abs(cross2(dx, dy, x1 - x0, y1 - y0)) / Math.sqrt(len2);
}

/** Recursively flatten a quadratic Bezier, appending points (x,y) to `out`. */
function flattenQuad(x0, y0, x1, y1, x2, y2, tol, out, depth) {
  if (depth >= 24 || quadFlatness(x0, y0, x1, y1, x2, y2) <= tol) {
    out.push(x2, y2);
    return;
  }
  const x01 = (x0 + x1) * 0.5;
  const y01 = (y0 + y1) * 0.5;
  const x12 = (x1 + x2) * 0.5;
  const y12 = (y1 + y2) * 0.5;
  const x012 = (x01 + x12) * 0.5;
  const y012 = (y01 + y12) * 0.5;
  flattenQuad(x0, y0, x01, y01, x012, y012, tol, out, depth + 1);
  flattenQuad(x012, y012, x12, y12, x2, y2, tol, out, depth + 1);
}

/**
 * Convert the command list into flat vertex arrays [x0,y0,x1,y1,...] per
 * subpath.
 */
function buildSubpaths(path, tol) {
  const subpaths = [];
  let cur = null;
  let cx = 0, cy = 0, sx = 0, sy = 0;

  const ensureSubpath = () => {
    if (!cur) {
      cur = [cx, cy];
      subpaths.push(cur);
      sx = cx;
      sy = cy;
    }
    return cur;
  };

  for (const cmd of path) {
    const type = String(cmd[0]).toUpperCase();
    if (type === 'M') {
      cx = cmd[1];
      cy = cmd[2];
      sx = cx;
      sy = cy;
      cur = [cx, cy];
      subpaths.push(cur);
    } else if (type === 'L') {
      ensureSubpath().push(cmd[1], cmd[2]);
      cx = cmd[1];
      cy = cmd[2];
    } else if (type === 'Q') {
      flattenQuad(cx, cy, cmd[1], cmd[2], cmd[3], cmd[4], tol, ensureSubpath(), 0);
      cx = cmd[3];
      cy = cmd[4];
    } else if (type === 'Z') {
      // Filling always closes implicitly; just return to the subpath start.
      cx = sx;
      cy = sy;
      cur = null;
    } else {
      throw new Error('rasterize: unsupported command ' + JSON.stringify(cmd));
    }
  }
  return subpaths;
}

/**
 * Build a direction-canonical, non-horizontal edge list.
 *
 * For every edge the representation is stored with the lower-y endpoint first
 * and an explicit winding `sign` (+1 if the original edge pointed downward in
 * y, i.e. y1 < y2, else -1).  The x-intersection formula therefore depends
 * only on the undirected geometry, which is what makes the rasterizer
 * bit-for-bit invariant under path reversal.
 */
function buildEdges(subpaths) {
  const edges = [];
  for (const verts of subpaths) {
    const n = verts.length >> 1;
    if (n < 2) continue;
    for (let i = 0; i < n; i++) {
      const j = (i + 1) % n; // implicit closing edge
      const x1 = verts[2 * i], y1 = verts[2 * i + 1];
      const x2 = verts[2 * j], y2 = verts[2 * j + 1];
      let sign, xlo, ylo, xhi, yhi;
      if (y1 < y2) {
        sign = 1; xlo = x1; ylo = y1; xhi = x2; yhi = y2;
      } else if (y1 > y2) {
        sign = -1; xlo = x2; ylo = y2; xhi = x1; yhi = y1;
      } else {
        continue; // horizontal edges never cross a scanline
      }
      edges.push({ xlo, ylo, xhi, yhi, sign, x1, y1, x2, y2 });
    }
  }
  return edges;
}

/** Liang-Barsky: does segment (x1,y1)-(x2,y2) touch the closed rect? */
function segIntersectsRect(x1, y1, x2, y2, rx0, ry0, rx1, ry1) {
  const dx = x2 - x1;
  const dy = y2 - y1;
  const p = [-dx, dx, -dy, dy];
  const q = [x1 - rx0, rx1 - x1, y1 - ry0, ry1 - y1];
  let t0 = 0, t1 = 1;
  for (let i = 0; i < 4; i++) {
    if (p[i] === 0) {
      if (q[i] < 0) return false;
    } else {
      const r = q[i] / p[i];
      if (p[i] < 0) {
        if (r > t1) return false;
        if (r > t0) t0 = r;
      } else {
        if (r < t0) return false;
        if (r < t1) t1 = r;
      }
    }
  }
  return true;
}

// main entry point
// ---------------------------------------------------------------------------

function rasterize(path, options) {
  const opts = options || {};
  const width = opts.width | 0;
  const height = opts.height | 0;
  if (width < 0 || height < 0) {
    throw new Error('rasterize: width/height must be non-negative');
  }

  const tol = opts.bezierTolerance == null ? 0.1 : opts.bezierTolerance;
  const S = Math.max(1, opts.verticalSamples == null ? 16 : opts.verticalSamples | 0);
  const vp = opts.viewport || { x0: 0, y0: 0, x1: width, y1: height };

  // Exact integer clipping of the raster window to the image.
  const x0 = Math.max(0, vp.x0 | 0);
  const y0 = Math.max(0, vp.y0 | 0);
  const x1 = Math.min(width, vp.x1 | 0);
  const y1 = Math.min(height, vp.y1 | 0);

  const mask = new Uint8Array(width * height);
  if (x0 >= x1 || y0 >= y1) return mask;

  const subpaths = buildSubpaths(path, tol);
  const edges = buildEdges(subpaths);

  const vw = x1 - x0;
  const cov = new Float64Array(vw * (y1 - y0));
  const invS = 1 / S;

  const crossX = new Float64Array(edges.length);
  const crossSign = new Int8Array(edges.length);
  const order = new Int32Array(edges.length);

  for (let py = y0; py < y1; py++) {
    const rowBase = (py - y0) * vw;
    for (let j = 0; j < S; j++) {
      const y = py + (j + 0.5) * invS;

      // Gather crossings of every edge with this sub-scanline.
      let m = 0;
      for (let e = 0; e < edges.length; e++) {
        const ed = edges[e];
        if (y >= ed.ylo && y < ed.yhi) {
          crossX[m] =
            ed.xlo + (y - ed.ylo) * (ed.xhi - ed.xlo) / (ed.yhi - ed.ylo);
          crossSign[m] = ed.sign;
          m++;
        }
      }
      if (m === 0) continue;

      for (let i = 0; i < m; i++) order[i] = i;
      // Deterministic total order: by x, then by winding sign.
      const ord = order.subarray(0, m);
      ord.sort((a, b) => (crossX[a] - crossX[b]) || (crossSign[a] - crossSign[b]));

      // Walk crossings left->right accumulating winding; emit nonzero spans.
      let winding = 0;
      let prevX = 0;
      let havePrev = false;
      for (let k = 0; k < m; k++) {
        const idx = ord[k];
        const x = crossX[idx];
        if (winding !== 0 && havePrev) {
          // Span [prevX, x) is inside. Clip it exactly to [x0, x1).
          let a = prevX > x0 ? prevX : x0;
          let b = x < x1 ? x : x1;
          if (b > a) {
            let colA = Math.floor(a);
            if (colA < x0) colA = x0;
            let colB = Math.ceil(b);
            if (colB > x1) colB = x1;
            for (let cx = colA; cx < colB; cx++) {
              const l = a > cx ? a : cx;
              const r = b < cx + 1 ? b : cx + 1;
              if (r > l) cov[rowBase + (cx - x0)] += (r - l) * invS;
            }
          }
        }
        winding += crossSign[idx];
        prevX = x;
        havePrev = true;
      }
    }
  }

  // Quantize to 8 bits.
  for (let i = 0; i < cov.length; i++) {
    let v = Math.round(cov[i] * 255);
    if (v > 255) v = 255;
    else if (v < 0) v = 0;
    mask[(y0 + (i / vw | 0)) * width + (x0 + (i % vw))] = v;
  }

  // Conservative pass: any pixel touched by the boundary must be non-zero.
  for (let e = 0; e < edges.length; e++) {
    const ed = edges[e];
    const minx = Math.min(ed.x1, ed.x2);
    const maxx = Math.max(ed.x1, ed.x2);
    const miny = Math.min(ed.y1, ed.y2);
    const maxy = Math.max(ed.y1, ed.y2);

    let px0 = Math.floor(minx);
    if (px0 < x0) px0 = x0;
    let px1 = Math.floor(maxx);
    if (px1 > x1 - 1) px1 = x1 - 1;
    let pyc0 = Math.floor(miny);
    if (pyc0 < y0) pyc0 = y0;
    let pyc1 = Math.floor(maxy);
    if (pyc1 > y1 - 1) pyc1 = y1 - 1;

    for (let py = pyc0; py <= pyc1; py++) {
      for (let px = px0; px <= px1; px++) {
        const idx = py * width + px;
        if (
          mask[idx] === 0 &&
          segIntersectsRect(ed.x1, ed.y1, ed.x2, ed.y2, px, py, px + 1, py + 1)
        ) {
          mask[idx] = 1;
        }
      }
    }
  }

  return mask;
}

/** Nonzero winding number of the (implicitly closed) path at point (px,py). */
function windingNumberAt(path, px, py, tol) {
  const subpaths = buildSubpaths(path, tol == null ? 0.1 : tol);
  const edges = buildEdges(subpaths);
  let w = 0;
  for (const ed of edges) {
    if (py >= ed.ylo && py < ed.yhi) {
      const x = ed.xlo + (py - ed.ylo) * (ed.xhi - ed.xlo) / (ed.yhi - ed.ylo);
      if (x > px) w += ed.sign;
    }
  }
  return w;
}

/**
 * Reverse every subpath of a command list.
 *
 * A closed subpath v0 -> v1 -> ... -> v(n-1) -> v0 becomes
 * v0 -> v(n-1) -> ... -> v1 -> v0.  A quadratic segment is reversed by
 * swapping its endpoints and keeping its control point.
 */
function reversePath(path) {
  // Parse into subpaths.  After parsing, `v` has n+1 vertices and `c` has n
  // controls.  Explicit edge i (0..n-1) runs v[i] -> v[i+1] with control
  // c[i] (null = line).  Filling always adds an implicit closing edge
  // v[n] -> v[0] (a straight line), so we reverse that cycle too.
  const subs = [];
  let sp = null;
  for (const cmd of path) {
    const type = String(cmd[0]).toUpperCase();
    if (type === 'M') {
      sp = { v: [[cmd[1], cmd[2]]], c: [] };
      subs.push(sp);
    } else if (type === 'L' || type === 'Q') {
      if (!sp) {
        sp = { v: [[0, 0]], c: [] };
        subs.push(sp);
      }
      if (type === 'L') {
        sp.v.push([cmd[1], cmd[2]]);
        sp.c.push(null);
      } else {
        sp.c.push([cmd[1], cmd[2]]);
        sp.v.push([cmd[3], cmd[4]]);
      }
    }
  }

  const emitRev = (out, ctrl, target) => {
    if (ctrl) out.push(['Q', ctrl[0], ctrl[1], target[0], target[1]]);
    else out.push(['L', target[0], target[1]]);
  };

  const out = [];
  for (const s of subs) {
    const n = s.c.length; // number of explicit segments
    if (n === 0) continue;
    out.push(['M', s.v[0][0], s.v[0][1]]);
    // Reverse of the implicit closing edge v[n] -> v[0].
    out.push(['L', s.v[n][0], s.v[n][1]]);
    // Reverse of explicit edges n-1 .. 1.
    for (let i = n - 1; i >= 1; i--) emitRev(out, s.c[i], s.v[i]);
    // Reverse of explicit edge 0 returns to the start.
    emitRev(out, s.c[0], s.v[0]);
    out.push(['Z']);
  }
  return out;
}

Algorithm walkthrough

  1. Parse & flatten (buildSubpaths): M/L/Q/Z; each quadratic is recursively subdivided until |cross(chord, p1-p0)| / |chord| <= bezierTolerance. Every subpath is implicitly closed for filling.
  2. Canonical edges (buildEdges): each non-horizontal edge becomes (xlo,ylo,xhi,yhi,sign) with ylo < yhi; sign = +1 if it originally went downward in y, else -1. Horizontal edges are skipped.
  3. Scan & cover: per pixel row and per sub-scanline, collect x-crossings, sort deterministically, walk left→right accumulating winding, and emit each span with winding != 0, clipped exactly to [x0,x1) and weighted by overlap / verticalSamples. Coverage is exact in x, quantized only in y.
  4. Quantise: round(coverage * 255), clamped.
  5. Conservative repair: for every edge, visit bbox pixels and force any still-zero pixel touched by the segment to 1 via a Liang–Barsky test. Any partially covered pixel must have an edge passing through it, so this closes the only gap sub-scanline sampling could leave.

What each check proves

  • Nonzero rule / holes — outer CCW square + inner CW square leaves the interior 0; the same inner square as CCW leaves it 255. This separates nonzero from even-odd.
  • Reversal invariance — a concave polygon and a quadratic outline are rasterised and compared byte-for-byte after reversePath; fuzzing extends this to 300 random single-subpath shapes containing quadratics.
  • Conservative coverage — a triangle only 0.02 units tall is placed between sub-scanlines so supersampling alone yields zero, yet every column is marked. Fuzzing samples a 32×32 grid per pixel and asserts every filled sample lands in a non-zero pixel.
  • Exact clipping — viewport rasterisation equals cropping the full canvas; an edge lying exactly on the viewport border keeps its winding; self-intersecting stars crossing the border repeatedly are handled.
  • Sub-pixel vertices — square (0.5,0.5)–(9.5,9.5) gives 64 on corners, 128 on half-covered edges, 255 inside.
  • Winding correctness — windingNumberAt is cross-checked against an independent signed-angle winding computation at 400 points.
  • Determinism — repeated runs produce identical bytes.

Properties guaranteed

For any hole-free path P and its reversal reverse(P):

rasterize(P) === rasterize(reverse(P))          // byte-identical
pixel touched by any edge  =>  mask[pixel] >= 1 // conservative
|winding| > 0              =>  mask[pixel] > 0  // nonzero rule
