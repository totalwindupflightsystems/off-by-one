WORKTREE-001 — Fix TestWorkdirDetection::test_get_workdir_in_git_repo for linked Git worktrees

Summary

The focused test asserted os.path.isdir(<workdir>/.git). That invariant only holds in a main checkout, where .git is a directory. In a linked Git worktree (git worktree add), .git is a regular file containing gitdir: <common>/.git/worktrees/<name>, so the assertion fails even though get_workdir() is correct. The test, not the production code, encoded a main-checkout-only assumption.

Root cause

get_workdir() resolves the checkout root with git rev-parse --show-toplevel, which is worktree-aware and returns the invoking worktree's root in both layouts.

  • Main checkout: /repo/.git → directory
  • Linked worktree: /worktrees/x/.git → file with contents gitdir: /repo/.git/worktrees/x

The original assertion (os.path.isdir(...)) therefore tested an implementation detail of main checkouts rather than the actual contract (a Git-recognized checkout root). This is invisible under a plain main-checkout run and only surfaces when the staged patch is verified from a real linked worktree.

# Failing assertion
assert os.path.isdir(os.path.join(workdir, ".git"))

Resulting method (what is in the tree now):

def test_get_workdir_in_git_repo(self):
    """Inside git repo → returns a Git-recognized checkout root."""
    from gitreins.cli import get_workdir

    workdir = get_workdir()
    expected_root = subprocess.run(
        ["git", "rev-parse", "--show-toplevel"],
        check=True,
        capture_output=True,
        text=True,
    ).stdout.strip()
    recognized_root = subprocess.run(
        ["git", "-C", workdir, "rev-parse", "--show-toplevel"],
        check=True,
        capture_output=True,
        text=True,
    ).stdout.strip()

    assert os.path.isdir(workdir)
    assert os.path.exists(os.path.join(workdir, ".git"))
    assert os.path.samefile(workdir, expected_root)
    assert os.path.samefile(workdir, recognized_root)

Why this is correct: - os.path.exists(<workdir>/.git) accepts a directory or a file, covering both layouts. - samefile(workdir, expected_root) pins the return value to Git's own --show-toplevel for the current CWD. - samefile(workdir, recognized_root) proves the returned path is independently recognized by Git (worktree-safe round-trip).

No production change is required for this assertion; get_workdir() is already correct. (The same commit also landed the canonical board resolution in engine/repo_paths.py and gitreins worktree doctor, but the WORKTREE-001 test regression itself is test-only.)
