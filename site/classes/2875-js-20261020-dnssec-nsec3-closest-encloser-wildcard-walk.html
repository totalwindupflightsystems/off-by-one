DNSSEC NSEC3 Denial-of-Existence Validator — Diagnosis & Fix

Problem class: js-20261020-dnssec-nsec3-closest-encloser-wildcard-walk Environment: Node 20 (verified on Node 22 LTS runtime), SHA-1 NSEC3 (RFC 5155) Scale target: 1,000,000 NSEC3 records, 100,000 queries, ≤ 5 s total

1. Root-cause analysis

NSEC3 denial proofs are interval arithmetic over a hash-ordered ring, not set membership. Almost every failure mode comes from treating the NSEC3 chain as an ordinary lookup table. The concrete defects this solution eliminates:

# Defect in a naive implementation Why it breaks Fix
1 Builds a Map from owner → record but never checks the next links A forged or truncated chain still "answers" Verify the chain is one cycle where record.next === sortedSuccessor.owner; reject unsorted/sub-cyclic/self-looping chains
2 Searches for the closest encloser by taking the longest suffix present, then stops Must be the longest existing ancestor; a shorter match silently mislabels NXDOMAIN Walk suffixes from longest to shortest, first exact owner match wins
3 Assumes one global iteration count and ignores the record's iterations Attacker supplies a low-iteration record to make hashes collide, or a huge value to burn CPU Read iterations from the records, require consistent salt/iterations, and reject any value above the declared policy ceiling (maxIterations)
4 Treats an opt-out NSEC3 covering the next closer as proof of NXDOMAIN Opt-out exists precisely to skip unsigned delegations; asserting NXDOMAIN denies a possibly insecure delegation Return INSECURE, never NXDOMAIN, when the next-closer cover has the opt-out bit
5 Accepts any NSEC3 whose owner name "looks like" *.<something> as a wildcard match A record for *.other.example would wrongly validate *.example The wildcard match is valid iff ownerKey === hash('*.' + closestEncloser); otherwise reject
6 Returns the whole proof list including duplicates / unrelated RRs Not minimal; leaks extra data and can hide forged records De-duplicate cover owners; verifyProof enforces exact set equality with the derived minimal set
7 Re-decodes/re-encodes the whole 1M chain on every load (hex ↔ base32hex) Blows the 5 s budget Keep the native input representation (hex or base32hex) as the internal key; both preserve 20-byte hash order, so no transcoding is needed on the hot path

Key invariant used throughout: for fixed-width encodings, the lexicographic order of the 40-char hex string and of the 32-char base32hex string is exactly the byte order of the 20-byte SHA-1 hash. Therefore a sorted array of key strings supports binary search for NSEC3 coverage without materialising the hash bytes.

2. The fix

Two self-contained files. nsec3.js is the validator; test.js is the verification harness (RFC hash definition, all verdict paths, all rejection paths, representation equivalence, and the 1M/100k performance gate).

nsec3.js

'use strict';

/**
 * nsec3.js — DNSSEC NSEC3 denial-of-existence validator (Node 20+).
 *
 * Implements RFC 5155 closest-encloser / next-closer / wildcard walking with
 * opt-out handling, per-record hash iteration counting and forged/incomplete
 * proof rejection. Built for large zones (1e6 NSEC3 records) and large query
 * batches (1e5) under a tight time budget.
 *
 * Public API
 * ----------
 *   nsec3HashRaw(wireName, saltBuf, iterations) -> Buffer(20)
 *   hashName(name, salt, iterations)            -> Buffer(20)
 *   base32hexEncode(buf) / base32hexDecode(str)
 *   new Nsec3Chain(records, options)
 *   chain.validate(qname)          -> { ok, verdict, cover, reason }
 *   chain.verifyProof(qname, list) -> { ok, verdict, cover, reason }
 *
 * Record fields: { owner|ownerName, next|nextOwner, flags, iterations, salt,
 *                  algorithm?, types? }.  owner/next may be 20-byte Buffers,
 * 40-char hex strings, or 32-char base32hex strings.  Mixed representations
 * are accepted; the dominant representation is used as the internal key so
 * the hot path never transcodes the whole chain.
 *
 * Verdicts
 * --------
 *   NAME_MATCH   qname itself exists (positive answer / ENT)
 *   WILDCARD     wildcard-expanded NOERROR proven
 *   NXDOMAIN     NXDOMAIN proven
 *   INSECURE     closest-encloser proof + opt-out next-closer cover: the
 *                NXDOMAIN cannot be asserted; treat as insecure delegation
 *   BOGUS        proof missing / forged / inconsistent (reject)
 */

const crypto = require('crypto');

/* ------------------------------------------------------------------ *
 * base32hex (RFC 4648 §7, NSEC3 owner-name encoding)                  *
 * ------------------------------------------------------------------ */

const B32HEX_ALPHABET = '0123456789ABCDEFGHIJKLMNOPQRSTUV';
const B32HEX_LOOKUP = (() => {
  const m = new Map();
  for (let i = 0; i < B32HEX_ALPHABET.length; i++) m.set(B32HEX_ALPHABET[i], i);
  return m;
})();

/** Fast encode; groups of 5 bytes -> 8 base32hex chars. */
function base32hexEncode(buf) {
  const A = B32HEX_ALPHABET;
  const n = buf.length;
  let out = '';
  let i = 0;
  for (; i + 5 <= n; i += 5) {
    const b0 = buf[i];
    const b1 = buf[i + 1];
    const b2 = buf[i + 2];
    const b3 = buf[i + 3];
    const b4 = buf[i + 4];
    out +=
      A[(b0 >>> 3) & 31] +
      A[((b0 << 2) | (b1 >>> 6)) & 31] +
      A[(b1 >>> 1) & 31] +
      A[((b1 << 4) | (b2 >>> 4)) & 31] +
      A[((b2 << 1) | (b3 >>> 7)) & 31] +
      A[(b3 >>> 2) & 31] +
      A[((b3 << 3) | (b4 >>> 5)) & 31] +
      A[b4 & 31];
  }
  if (i < n) {
    let bits = 0;
    let value = 0;
    for (; i < n; i++) {
      value = ((value << 8) | buf[i]) & 0xffff;
      bits += 8;
      while (bits >= 5) {
        out += A[(value >>> (bits - 5)) & 31];
        bits -= 5;
      }
    }
    if (bits > 0) out += A[(value << (5 - bits)) & 31];
  }
  return out;
}

function base32hexDecode(str) {
  if (typeof str !== 'string') throw new Error('base32hexDecode: expected string');
  const clean = str.replace(/[=\s]/g, '').toUpperCase();
  const out = [];
  let bits = 0;
  let value = 0;
  for (let i = 0; i < clean.length; i++) {
    const v = B32HEX_LOOKUP.get(clean[i]);
    if (v === undefined) throw new Error('invalid base32hex character: ' + clean[i]);
    value = ((value << 5) | v) & 0xffff;
    bits += 5;
    if (bits >= 8) {
      out.push((value >>> (bits - 8)) & 0xff);
      bits -= 8;
    }
  }
  return Buffer.from(out);
}

/** Normalise an NSEC3 owner label to upper-case, un-padded base32hex. */
function normalizeOwner(label) {
  if (label instanceof Buffer || label instanceof Uint8Array) {
    return base32hexEncode(Buffer.from(label));
  }
  return String(label).replace(/[=\s]/g, '').replace(/\.$/, '').toUpperCase();
}

/* ------------------------------------------------------------------ *
 * Name canonicalisation + NSEC3 hash                                  *
 * ------------------------------------------------------------------ */

/** Canonical wire form of a DNS name (RFC 4034 §6.2, lower-cased). */
function nameToWire(name) {
  let n = String(name).toLowerCase();
  if (n.endsWith('.')) n = n.slice(0, -1);
  if (n === '') return Buffer.from([0]);
  const labels = n.split('.');
  const out = [];
  for (const label of labels) {
    if (label.length === 0) throw new Error('empty label in name: ' + name);
    if (label.length > 63) throw new Error('label too long: ' + label);
    out.push(label.length);
    for (let i = 0; i < label.length; i++) out.push(label.charCodeAt(i) & 0xff);
  }
  out.push(0);
  return Buffer.from(out);
}

/** RFC 5155 §5.1.1 iterated hash. `iterations` extra iterations. */
function nsec3HashRaw(wireName, saltBuf, iterations) {
  let h = crypto.createHash('sha1').update(wireName).update(saltBuf).digest();
  for (let i = 0; i < iterations; i++) {
    h = crypto.createHash('sha1').update(h).update(saltBuf).digest();
  }
  return h;
}

function parseSalt(salt) {
  if (salt === undefined || salt === null || salt === '' || salt === '-') return Buffer.alloc(0);
  if (Buffer.isBuffer(salt)) return salt;
  if (typeof salt !== 'string' || salt.length % 2 !== 0 || !/^[0-9a-fA-F]*$/.test(salt)) {
    throw new Error('invalid NSEC3 salt: ' + salt);
  }
  return Buffer.from(salt, 'hex');
}

function hashName(name, salt, iterations) {
  return nsec3HashRaw(nameToWire(name), parseSalt(salt), iterations);
}

/* ------------------------------------------------------------------ *
 * Sorted lookup                                                       *
 * ------------------------------------------------------------------ */

/** First index i such that arr[i] > target (fixed-length hex/b32 strings). */
function upperBound(arr, target) {
  let lo = 0;
  let hi = arr.length;
  while (lo < hi) {
    const mid = (lo + hi) >>> 1;
    if (arr[mid] > target) hi = mid;
    else lo = mid + 1;
  }
  return lo;
}

/* ------------------------------------------------------------------ *
 * NSEC3 chain                                                        *
 * ------------------------------------------------------------------ */

const HASH_ALG_SHA1 = 1;
const FLAG_OPT_OUT = 1;
const HEX40 = /^[0-9a-fA-F]{40}$/;
const B32_32 = /^[0-9A-V]{32}$/;

/** Allocation-free 40-char hex check. */
function isHex40(s) {
  if (s.length !== 40) return false;
  for (let i = 0; i < 40; i++) {
    const c = s.charCodeAt(i);
    if (!((c >= 48 && c <= 57) || (c >= 97 && c <= 102) || (c >= 65 && c <= 70))) return false;
  }
  return true;
}

class Nsec3Chain {
  /**
   * @param {Array<object>} records
   * @param {object} [options]
   *   maxIterations  policy ceiling for the iteration field (default 2500)
   *   allowMixedParameters  permit differing salt/iterations (default false)
   */
  constructor(records, options = {}) {
    if (!Array.isArray(records) || records.length === 0) {
      throw new Error('Nsec3Chain: at least one NSEC3 record is required');
    }
    this.maxIterations = options.maxIterations == null ? 2500 : options.maxIterations;
    this.allowMixedParameters = !!options.allowMixedParameters;
    this._hashCache = new Map();
    this._labelCache = new Map();

    // Choose the internal key representation from the first record.  Both
    // 40-char hex and 32-char base32hex preserve 20-byte hash order, so the
    // hot path can avoid transcoding the chain when it is already uniform.
    const firstOwner = records[0].owner !== undefined ? records[0].owner : records[0].ownerName;
    this.keyMode = (typeof firstOwner === 'string' && !HEX40.test(firstOwner.trim()))
      ? 'b32'
      : 'hex';

    const byOwner = new Map();
    const norm = [];
    let params = null;

    for (const r of records) {
      const algorithm = r.algorithm == null ? HASH_ALG_SHA1 : r.algorithm;
      if (algorithm !== HASH_ALG_SHA1) {
        throw new Error('unsupported NSEC3 hash algorithm: ' + algorithm);
      }
      const iterations = r.iterations == null ? 0 : r.iterations;
      if (!Number.isInteger(iterations) || iterations < 0) {
        throw new Error('invalid NSEC3 iterations: ' + iterations);
      }
      if (iterations > this.maxIterations) {
        throw new Error(
          'NSEC3 iterations ' + iterations + ' exceeds declared limit ' + this.maxIterations
        );
      }
      const saltBuf = parseSalt(r.salt);
      const flags = r.flags == null ? 0 : r.flags;
      if (!Number.isInteger(flags) || flags < 0 || flags > 255) {
        throw new Error('invalid NSEC3 flags: ' + flags);
      }

      const p = saltBuf.toString('hex') + ':' + iterations;
      if (params === null) params = p;
      else if (params !== p && !this.allowMixedParameters) {
        throw new Error('inconsistent NSEC3 salt/iterations across chain');
      }

      const ownerKey = this._toKey(r.owner !== undefined ? r.owner : r.ownerName, 'owner');
      const nextKey = this._toKey(r.next !== undefined ? r.next : r.nextOwner, 'next');
      if (byOwner.has(ownerKey)) {
        throw new Error('duplicate NSEC3 owner: ' + this.ownerLabel(ownerKey));
      }
      const rec = {
        ownerKey,
        nextKey,
        flags,
        iterations,
        salt: saltBuf,
        saltHex: saltBuf.toString('hex'),
        optOut: (flags & FLAG_OPT_OUT) !== 0,
        types: r.types,
      };
      byOwner.set(ownerKey, rec);
      norm.push(rec);
    }

    this.records = norm;
    this.byOwner = byOwner;
    this.params = params;

    // Canonical (hash) order.  Fixed-width keys sort exactly like the hashes.
    this.sortedOwners = norm.map((r) => r.ownerKey).sort();
    this.sortedRecords = this.sortedOwners.map((h) => byOwner.get(h));

    // A valid chain is a single cycle: each record's `next` is the owner of
    // the following record in sorted order, wrapping at the end.  This
    // rejects unsorted, sub-cyclic and looping chains.
    const n = this.sortedRecords.length;
    for (let i = 0; i < n; i++) {
      const rec = this.sortedRecords[i];
      const expected = this.sortedRecords[(i + 1) % n].ownerKey;
      if (rec.nextKey !== expected) {
        throw new Error(
          'broken/looping NSEC3 chain at ' + this.ownerLabel(rec.ownerKey) +
          ': next is ' + this.ownerLabel(rec.nextKey) +
          ' expected ' + this.ownerLabel(expected)
        );
      }
    }

    // Zone-level hash parameters, taken from the records themselves.
    const parts = this.params.split(':');
    this.salt = parseSalt(parts[0]);
    this.iterations = Number(parts[1]);
  }

  /** Convert an accepted owner representation to the internal key. */
  _toKey(v, what) {
    if (Buffer.isBuffer(v) || v instanceof Uint8Array) {
      const b = Buffer.from(v);
      if (b.length !== 20) throw new Error('NSEC3 ' + what + ' must be 20 bytes, got ' + b.length);
      return this.keyMode === 'hex' ? b.toString('hex') : base32hexEncode(b);
    }
    const s = typeof v === 'string' ? v : String(v);

    // Fast path: input already in the internal representation.
    if (this.keyMode === 'hex' && s.length === 40 && isHex40(s)) {
      return s.toLowerCase();
    }
    if (this.keyMode === 'b32' && s.length === 32 && B32_32.test(s)) {
      return s.toUpperCase();
    }

    // Slow path: tolerate trailing dots, whitespace, padding and the other
    // representation.
    const t = s.replace(/[=\s]/g, '').replace(/\.$/, '');
    if (HEX40.test(t)) {
      const hex = t.toLowerCase();
      return this.keyMode === 'hex' ? hex : base32hexEncode(Buffer.from(hex, 'hex'));
    }
    const b32 = t.toUpperCase();
    if (this.keyMode === 'b32') {
      const b = base32hexDecode(b32);
      if (b.length !== 20) throw new Error('NSEC3 ' + what + ' must hash to 20 bytes');
      return b32;
    }
    const b = base32hexDecode(b32);
    if (b.length !== 20) throw new Error('NSEC3 ' + what + ' must hash to 20 bytes, got ' + b.length);
    return b.toString('hex');
  }

  /** Normalised (base32hex) label for an internal key. */
  ownerLabel(key) {
    if (this.keyMode === 'b32') return key;
    let l = this._labelCache.get(key);
    if (l === undefined) {
      l = base32hexEncode(Buffer.from(key, 'hex'));
      this._labelCache.set(key, l);
    }
    return l;
  }

  /** Memoised NSEC3 hash -> internal key for a canonical name. */
  hashNameKey(name) {
    let h = this._hashCache.get(name);
    if (h !== undefined) return h;
    const buf = nsec3HashRaw(nameToWire(name), this.salt, this.iterations);
    h = this.keyMode === 'hex' ? buf.toString('hex') : base32hexEncode(buf);
    this._hashCache.set(name, h);
    return h;
  }

  /** Backwards-compatible alias. */
  hashNameHex(name) {
    return this.hashNameKey(name);
  }

  /** Exact owner lookup. Returns the record or null. */
  findMatch(hashKey) {
    return this.byOwner.get(hashKey) || null;
  }

  /**
   * Find the record whose [owner, next) interval contains hashKey in hash
   * order (circular). Returns { match } on an exact owner hit, else
   * { cover } with the covering record, else null.
   */
  findCover(hashKey) {
    const match = this.byOwner.get(hashKey);
    if (match) return { match, cover: null };
    const owners = this.sortedOwners;
    if (owners.length === 0) return null;
    const idx = upperBound(owners, hashKey) - 1; // greatest owner < hash
    const rec = idx >= 0
      ? this.byOwner.get(owners[idx])
      : this.byOwner.get(owners[owners.length - 1]); // wrap-around
    return { match: null, cover: rec };
  }

  /**
   * Validate a query name against the chain.
   * @returns {{ok:boolean, verdict:string, cover:string[], reason?:string}}
   *   cover = minimal, de-duplicated, normalised (base32hex) owner labels.
   */
  validate(qname) {
    const name = String(qname).toLowerCase().replace(/\.$/, '');
    if (name === '') return bogus('empty query name');

    const labels = name.split('.');
    if (labels.some((l) => l.length === 0)) return bogus('ill-formed query name');

    // 1) closest-encloser search, longest suffix first.
    let ce = null;
    let ceRec = null;
    let ceIdx = -1;
    for (let i = 0; i < labels.length; i++) {
      const cand = labels.slice(i).join('.');
      const rec = this.findMatch(this.hashNameKey(cand));
      if (rec) {
        ce = cand;
        ceRec = rec;
        ceIdx = i;
        break;
      }
    }
    if (!ceRec && labels.length > 0) {
      // Root "." as a last resort (only meaningful for a root zone).
      const rec = this.findMatch(this.hashNameKey(''));
      if (rec) {
        ce = '';
        ceRec = rec;
        ceIdx = labels.length;
      }
    }
    if (!ceRec) return bogus('no closest-encloser proof in chain');

    // Exact match: the queried name exists (or is an empty non-terminal).
    if (ceIdx === 0) {
      return {
        ok: true,
        verdict: 'NAME_MATCH',
        cover: [this.ownerLabel(ceRec.ownerKey)],
        reason: 'qname matches an NSEC3 owner (' + ce + ')',
      };
    }
    if (ceIdx < 0) return bogus('closest encloser not on query path');

    // 2) next-closer proof.
    const ncName = labels.slice(ceIdx - 1).join('.');
    const ncKey = this.hashNameKey(ncName);
    const ncRes = this.findCover(ncKey);
    if (!ncRes) return bogus('no NSEC3 covers the next-closer name');
    if (ncRes.match) {
      // The next-closer exists as an owner: the chosen CE was not closest.
      return bogus('next-closer name unexpectedly matched an NSEC3 owner');
    }
    const ncRec = ncRes.cover;
    if (ncRec.optOut) {
      // Opt-out: the name may be an unsigned delegation. NXDOMAIN is not
      // provable; report an insecure delegation instead.  Do NOT emit an
      // NXDOMAIN verdict here.
      return {
        ok: true,
        verdict: 'INSECURE',
        cover: dedupe([this.ownerLabel(ceRec.ownerKey), this.ownerLabel(ncRec.ownerKey)]),
        reason: 'next-closer covered by an opt-out NSEC3; cannot assert NXDOMAIN',
      };
    }

    // 3) wildcard proof: match *.CE (wildcard-expanded NOERROR) or cover it
    //    (proves no wildcard => NXDOMAIN).
    const wildcardName = ce === '' ? '*' : '*.' + ce;
    const wKey = this.hashNameKey(wildcardName);
    const wRes = this.findCover(wKey);

    if (wRes && wRes.match) {
      const wRec = wRes.match;
      // Hard guard: the matched owner must be exactly the hash of the
      // closest-encloser wildcard, never some other "*." label.
      if (wRec.ownerKey !== wKey) {
        return bogus('wildcard match owner is not the closest-encloser wildcard');
      }
      return {
        ok: true,
        verdict: 'WILDCARD',
        cover: dedupe([
          this.ownerLabel(ceRec.ownerKey),
          this.ownerLabel(ncRec.ownerKey),
          this.ownerLabel(wRec.ownerKey),
        ]),
        reason: 'wildcard ' + wildcardName + ' exists; wildcard-expanded NOERROR',
      };
    }

    if (!wRes || !wRes.cover) return bogus('no NSEC3 covering the wildcard');

    return {
      ok: true,
      verdict: 'NXDOMAIN',
      cover: dedupe([
        this.ownerLabel(ceRec.ownerKey),
        this.ownerLabel(ncRec.ownerKey),
        this.ownerLabel(wRes.cover.ownerKey),
      ]),
      reason: 'closest encloser + next closer + wildcard cover proven',
    };
  }

  /**
   * Verify an explicitly supplied proof set (list of NSEC3 owner labels).
   * Rejects missing, extra, out-of-chain or wrong-owner records, and any
   * proof that would accept a forged wildcard / opt-out denial.
   */
  verifyProof(qname, proofOwners) {
    if (!Array.isArray(proofOwners) || proofOwners.length === 0) {
      return bogus('empty proof set');
    }
    const provided = new Set();
    for (const raw of proofOwners) {
      let key;
      try {
        key = this._toKey(raw, 'proof owner');
      } catch (e) {
        return bogus('unparseable proof owner: ' + raw);
      }
      if (!this.byOwner.has(key)) {
        return bogus('proof contains owner not present in chain: ' + this.ownerLabel(key));
      }
      provided.add(key);
    }

    const res = this.validate(qname);
    if (!res.ok) return res;

    const expected = new Set(res.cover.map((l) => this._toKey(l, 'expected owner')));
    if (provided.size !== expected.size) {
      return bogus(
        'proof set is not minimal/complete (got ' + provided.size +
        ', expected ' + expected.size + ')'
      );
    }
    for (const key of provided) {
      if (!expected.has(key)) {
        return bogus('proof contains unexpected owner: ' + this.ownerLabel(key));
      }
    }
    return res;
  }
}

function dedupe(arr) {
  return Array.from(new Set(arr));
}

function bogus(reason) {
  return { ok: false, verdict: 'BOGUS', cover: [], reason };
}

let passed = 0;
let failed = 0;
function test(name, fn) {
  try {
    fn();
    passed++;

  } catch (e) {
    failed++;
    console.log('FAIL  ' + name + '\n      ' + (e && e.stack ? e.stack.split('\n')[0] : e));

const SALT = 'aabbccdd';
const ITER = 0;

/** Build a syntactically valid NSEC3 ring from a list of {name, flags}. */
function buildRecords(entries, saltHex = SALT, iterations = ITER) {
  const recs = entries.map((e) => ({
    owner: base32hexEncode(hashName(e.name, saltHex, iterations)),
    flags: e.flags || 0,
    iterations,
    salt: saltHex,
  }));
  recs.sort((a, b) => (a.owner < b.owner ? -1 : a.owner > b.owner ? 1 : 0));
  for (let i = 0; i < recs.length; i++) recs[i].next = recs[(i + 1) % recs.length].owner;
  return recs;
}

function makeChain(entries, opts) {
  return new Nsec3Chain(buildRecords(entries), opts);
}

  // it is done before the timed window.
  const pool = crypto.randomBytes(20 * N);
  const owners = new Array(N);

    owners[i] = i < known.length
      ? known[i]
      : pool.toString('hex', i * 20, (i + 1) * 20);
  }
  owners.sort();
  // Deduplicate (random collisions are astronomically unlikely, but be safe).
  const recs = [];
  for (let i = 0; i < owners.length; i++) {
    if (i > 0 && owners[i] === owners[i - 1]) continue;
    recs.push({ owner: owners[i], next: '', flags: 0, salt: saltHex, iterations });
  }
  for (let i = 0; i < recs.length; i++) recs[i].next = recs[(i + 1) % recs.length].owner;

3. API in one paragraph

new Nsec3Chain(records, { maxIterations = 2500 }) accepts records with owner/ownerName and next/nextOwner as 20-byte Buffer, 40-char hex, or 32-char base32hex (mixed is tolerated). chain.validate(qname) returns { ok, verdict, cover, reason } where verdict ∈ {NAME_MATCH, WILDCARD, NXDOMAIN, INSECURE, BOGUS} and cover is the minimal, de-duplicated, normalized (upper-case, un-padded base32hex) owner-label set. chain.verifyProof(qname, owners) re-checks a caller-supplied proof and rejects missing, extra, out-of-chain, foreign-wildcard, or non-minimal sets.

Assumptions: SHA-1 (algorithm 1), a zone-consistent salt/iteration pair (mixing is rejected unless allowMixedParameters is set), and empty non-terminals present as NSEC3 owners in the chain.
