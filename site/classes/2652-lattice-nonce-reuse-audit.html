What was actually wrong

In an ML‑DSA/Dilithium‑style scheme (t = A·s + e2, z = y + c·s), a faulty RNG that reuses the ephemeral mask y gives z_i − z_j = (c_i−c_j)·s, so s falls out by one ring division — total key compromise. Correlated masks y_i − y_j = δ give s = (z_i−z_j−δ)(c_i−c_j)^{-1}. A naive “hash every nonce” auditor fails because (1) memory is unbounded, (2) birthday collisions in short tags are expected and harmless, (3) the commitment w is scrambled by A, so only exact reuse is metric‑detectable, (4) hash buckets are adversarially stuffable, and (5) a sketch hit is not proof.

The fix (two stages, exact decision)

Reconstruct the public commitment w' = A·z − c·t = A·y − c·e2. Salted, fixed‑memory bucketed hash tables + LSH + Count‑Min Sketch only nominate candidates (this is where collisions/birthday/truncation happen). The algebraic verifier is the only path that can alert:

verify(a, b) {
  const dc = vecSub(a.c, b.c);
  if (linf(dc) === 0) return null;                       // no equation
  let delta = (a.nonce && b.nonce) ? vecSub(a.nonce, b.nonce) : zeros(N);
  if (!(a.nonce && b.nonce) && linf(vecSub(a.w, b.w)) > LSH_W_THRESH) return null; // cheap filter
  const s_est = ringMul(vecSub(vecSub(a.z, b.z), delta), ringInv(dc));
  if (linf(s_est) > ETA) return null;                    // decisive: short secret
  const residual = vecSub(ringMul(a.A, s_est), a.t);
  if (linf(residual) > ETA2) return null;                // decisive: reproduces pubkey
  return { kind, ids, recovered_s: s_est, residual_linf: linf(residual), ... };
}

Because the verifier accepts only genuine reuse, sketch collisions cannot cause a false positive; salted SHA‑256 denies the adversary bucket targeting.

False‑positive guarantee

Under i.i.d. uniform nonces, s_est = s + (y_i−y_j−δ)(c_i−c_j)^{-1} is uniform over R_q ≅ Z_q^n, so per tested pair

p_fp = ((2η+1)/q)^n = (5/8380417)^8 ≈ 1.606e-50
P(any FP) ≤ m·S·p_fp ≤ 10^6·8·1.6e-50 ≈ 1.28e-43
