BFT Log-Replay Linearizability: Diagnosis and Verified Fix

Problem class: shell-bft-log-replay-linearizability-20261103 Environment: bash (POSIX shell + jq, sort, awk, python3) Deliverable: bft-lincheck.sh — a bounded-memory checker that reconstructs a quorum-certified history from partially ordered Byzantine replica logs, decides linearizability of the proposed history, and returns the minimal conflicting witness when it is not linearizable.

1. Root-cause analysis

A naive "replay the logs and compare final states" checker fails for seven independent reasons. Each one is a way to mistake eventual convergence (or a lucky ordering) for safety.

# Failure mode Why it is wrong Fix in this solution
1 Wall-clock ordering Replica clocks are skewed; timestamps are not a happens-before relation. Sorting by time can invent an order that never existed. Derive causality from vector clocks: A → B iff A.vc ≤ B.vc_pre componentwise. No physical clock is trusted.
2 Treating convergence as safety Replicas can converge to the same final state while an intermediate read observed a value that is impossible in any total order. Check linearizability (existence of a total order respecting hb and register semantics), not final-state equality.
3 Duplicated records Replays double-count writes and inflate quorum sizes; the same op appears once per replica. De-duplicate by (client, seq), then by op id, before any counting.
4 Missing records A sequence gap silently removes a write or read, which can turn a real violation into a false "linearizable". Detect per-client seq gaps during reconstruction and return exit 2 / unknown instead of a false positive.
5 Unbounded memory Keeping the whole history (or a closure of happens-before edges) does not scale to millions of ops. Stream the log through sort + awk with O(clients) state; the exact search keeps only the live causal frontier of one key.
6 Byzantine / forged clocks A record can reference a future sequence or carry a non-monotone clock. Trusting it corrupts the partial order. Validate clocks against the global per-client maximum and against present predecessors; report a Byzantine anomaly.
7 Ignoring quorum reads A single replica can fabricate an operation. Committing it changes the answer. Only ops reported by a quorum of distinct replicas enter the committed history; the rest are reported as uncommitted.

The key conceptual point: linearizability is a safety property over a total order, not a convergence property. Eventual consistency says all replicas eventually agree; linearizability says every completed operation appears to take effect atomically between its invocation and response. A history can converge and still violate linearizability (see t6 below), so a checker must search for the order — or prove none exists.

2. Model and correctness argument

Records. Each line is one replica's view of one operation:

{"id":"wA","client":"c1","seq":1,"type":"W","key":"x","val":"A",
 "replica":"r1","vc":{"c1":1}}
  • id – globally unique operation id
  • client, seq – per-client, strictly increasing sequence number
  • type – W (write) or R (read)
  • key – register key
  • val – value written (W) or value returned (R; null = initial value)
  • replica – replica that reported this record
  • vc – vector clock at the operation's response ({client: counter})

Happens-before. With vc_pre(B) = B.vc with B's own component decremented,

A → B   iff   for every client c:  A.vc[c] ≤ vc_pre(B)[c]

This is the standard vector-clock property: it yields the transitive closure of causality in one comparison, so no edge list or O(n²) closure is needed.

Register semantics. A linearization is a total order of the committed ops that (a) respects → and (b) makes every read return the value of the most recent preceding write (null initially). The checker searches for such an order per key.

Bounded-frontier search. Ops are placed one at a time; an op is enabled when all its maximal predecessors are placed. The search state is (enabled set, current value). Because the placed set is a down-set, the enabled set determines the placed set (the unplaced ops are exactly the upward closure of enabled), so memoisation on that state is sound. The enabled set is exactly the concurrency width, which is small in BFT logs; the DFS never stores the whole history. Forced moves (a single enabled op) are committed iteratively, so a million-op single-writer chain costs no stack depth.

Minimal witness. When a key is not linearizable, the tool minimises the offending subset with a delta-debugging (ddmin) loop, constrained so that every non-initial read still has a matching write in the subset. The result is the smallest self-contained contradiction, plus the → edges that close it.

3. Exact fix

Save the following as bft-lincheck.sh, chmod +x it, and pipe the log in.

#!/usr/bin/env bash
# =============================================================================
# bft-lincheck.sh -- bounded-memory BFT log-replay linearizability checker
# =============================================================================
# Input  : NDJSON, one record per replica view of an operation:
#   {"id","client","seq","type":"W"|"R","key","val","replica","vc":{client:ctr}}
# Output : JSON verdict.  Exit 0 = certified linearizable, 1 = safety violation
#          (or Byzantine anomaly), 2 = cannot certify (missing records / window).
#
# Memory : the reconstruction stage keeps O(clients) state and delegates the
#          global ordering to `sort` (external merge sort); the exact search
#          keeps only the live causal frontier of one key.  Total throughput is
#          bounded by disk/CPU, not by the size of the log.
# =============================================================================
set -euo pipefail

QUORUM=1          # replicas that must report an op before it is committed
WINDOW=0          # 0 = exact; >0 caps per-key frontier, larger -> "unknown"
INFILE=""
while [ $# -gt 0 ]; do
  case "$1" in
    --quorum) QUORUM="$2"; shift 2;;
    --window) WINDOW="$2"; shift 2;;
    -h|--help) grep '^#' "$0" | sed 's/^# \{0,1\}//'; exit 0;;
    *) INFILE="$1"; shift;;
  esac
done

TMP="$(mktemp -d)"; trap 'rm -rf "$TMP"' EXIT
PY="$TMP/check.py"

import sys, json, bisect

# ---------- vector clocks -------------------------------------------------
def parse_vc(s):
    v = {}
    if s and s != "__NULL__":
        for part in s.split(';'):
            if not part: continue
            k, _, val = part.partition('=')
            v[k] = int(val)
    return v

def vc_pre(o):
    v = dict(o["vc"]); c = o["client"]
    v[c] = v.get(c, o["seq"]) - 1
    return v

# ---------- Byzantine / skew detection ------------------------------------
def clock_anomalies(ops, maxseq):
    """Detect impossible clocks.  A reference to a sequence beyond the largest
    sequence ever observed for that client cannot be real (forged / replayed
    clock).  A reference to a present op that does not dominate its own clock is
    non-monotone.  References to ops on other keys are legitimate and ignored;
    genuinely missing same-client records are caught by the global gap detector."""
    idx = {(o["client"], o["seq"]): o for o in ops}
    bad = []
    for o in ops:
        if o["vc"].get(o["client"], 0) < o["seq"]:
            bad.append((o["id"], o["client"], o["seq"], "missing own clock component"))
        pre = vc_pre(o)
        for c, k in pre.items():
            if k <= 0: continue
            if k > maxseq.get(c, 0):
                bad.append((o["id"], c, k, "reference beyond observed maximum"))
                continue
            a = idx.get((c, k))
            if a is None:
                continue
            if any(v > pre.get(cc, 0) for cc, v in a["vc"].items()):
                bad.append((o["id"], c, k, "non-monotone clock"))
    return bad

# ---------- exact register linearizability (bounded frontier DFS) ----------
def build_imm_preds(ops):
    """Largest present causal predecessor per client (keeps the hb closure exact
    on induced sub-histories used by the witness minimiser)."""
    n = len(ops)
    by_client = {}
    for i, o in enumerate(ops):
        by_client.setdefault(o["client"], []).append((o["seq"], i))
    for c in by_client: by_client[c].sort()
    preds = [set() for _ in range(n)]
    for i, o in enumerate(ops):
        for c, k in vc_pre(o).items():
            if k <= 0: continue
            arr = by_client.get(c)
            if not arr: continue
            pos = bisect.bisect_right(arr, (k, 1 << 60)) - 1
            if pos >= 0:
                j = arr[pos][1]
                if j != i: preds[i].add(j)
    return preds

def linearizable(ops, max_states=5_000_000):
    n = len(ops)
    if n == 0: return True
    if n == 1:
        o = ops[0]
        return o["type"] == "W" or o["val"] is None
    preds = build_imm_preds(ops)
    succs = [[] for _ in range(n)]; counter = [0] * n
    for i in range(n):
        counter[i] = len(preds[i])
        for p in preds[i]: succs[p].append(i)
    enabled = frozenset(i for i in range(n) if counter[i] == 0)
    memo = {}; states = [0]

    def advance(en, i, undo):
        en = set(en); en.discard(i)
        for j in succs[i]:
            counter[j] -= 1; undo.append(j)
            if counter[j] == 0: en.add(j)
        return frozenset(en)

    def undo_all(undo):
        for j in reversed(undo): counter[j] += 1

    def rec(en, cur):
        undo = []
        while len(en) == 1:                      # forced moves: linear, no stack growth
            i = next(iter(en)); o = ops[i]
            if o["type"] == "R" and o["val"] != cur:
                undo_all(undo); return False
            if o["type"] == "W": cur = o["val"]
            en = advance(en, i, undo)
        if not en:
            undo_all(undo); return True
        key = (en, cur)
        if key in memo:
            undo_all(undo); return memo[key]
        states[0] += 1
        if states[0] > max_states:
            undo_all(undo); raise RuntimeError("state budget")
        for i in en:
            o = ops[i]
            if o["type"] == "R" and o["val"] != cur: continue
            undo2 = []
            en2 = advance(en, i, undo2)
            if rec(en2, o["val"] if o["type"] == "W" else cur):
                undo_all(undo2); undo_all(undo); memo[key] = True; return True
            undo_all(undo2)
        memo[key] = False; undo_all(undo); return False

    try:
        return rec(enabled, None)
    except RuntimeError:
        return None

# ---------- minimal conflicting witness ------------------------------------
def wellformed(sub):
    wv = {o["val"] for o in sub if o["type"] == "W"}
    return all(not (o["type"] == "R" and o["val"] is not None and o["val"] not in wv)
               for o in sub)

def unsupported(ops):
    wv = {o["val"] for o in ops if o["type"] == "W"}
    for o in ops:
        if o["type"] == "R" and o["val"] is not None and o["val"] not in wv:
            return o
    return None

def ddmin(ops):
    cur = list(range(len(ops))); gran = 2
    def bad(sub): return wellformed(sub) and not linearizable(sub)
    while len(cur) >= 2:
        chunk = max(1, len(cur) // gran); reduced = False
        for s in range(0, len(cur), chunk):
            comp = cur[:s] + cur[s+chunk:]
            if comp and bad([ops[i] for i in comp]):
                cur = comp; gran = max(2, gran - 1); reduced = True; break
        if not reduced:
            if gran >= len(cur): break
            gran = min(len(cur), gran * 2)
    return cur

def fmt(o):
    return {k: o[k] for k in ("id","type","val","client","seq") if k in o}

def check_key(key, ops, window, maxseq):
    if window and len(ops) > window:
        return {"key": key, "linearizable": None,
                "reason": "frontier %d exceeds --window %d" % (len(ops), window)}
    anom = clock_anomalies(ops, maxseq)
    if anom:
        return {"key": key, "linearizable": False, "reason": "inconsistent vector clock",
                "witness": [{"op": a[0], "ref_client": a[1], "ref_seq": a[2], "why": a[3]}
                            for a in anom[:8]]}
    r = linearizable(ops)
    if r is None:
        return {"key": key, "linearizable": None, "reason": "search state budget exceeded"}
    if r:
        return {"key": key, "linearizable": True, "witness": []}
    u = unsupported(ops)
    if u is not None:
        return {"key": key, "linearizable": False,
                "reason": "read value has no matching write", "witness": [fmt(u)]}
    sub = [ops[i] for i in ddmin(ops)]
    edges = [[sub[i]["id"], sub[j]["id"]] for i in range(len(sub)) for j in range(len(sub))
             if i != j and hb(sub[i], sub[j])]
    return {"key": key, "linearizable": False, "reason": "causal value regression",
            "witness": [fmt(o) for o in sub], "witness_hb_edges": edges}

def hb(a, b):
    bv = dict(b["vc"]); bv[b["client"]] = bv.get(b["client"], b["seq"]) - 1
    return all(k <= bv.get(c, 0) for c, k in a["vc"].items())

# ---------- driver ---------------------------------------------------------
def main():
    window = int(sys.argv[1]) if len(sys.argv) > 1 else 0
    path = sys.argv[2]
    # pass 1: global per-client maximum sequence (O(clients) memory)
    maxseq = {}
    with open(path) as fh:
        for line in fh:
            f = line.rstrip("\n").split("\t")
            if len(f) < 7: continue
            client, seq = f[2], int(f[3])
            if seq > maxseq.get(client, 0): maxseq[client] = seq
    # pass 2: one key at a time (bounded by the key's causal window)
    keys = []; cur_key = None; ops = []
    def flush():
        if cur_key is not None:
            keys.append(check_key(cur_key, ops, window, maxseq))
    with open(path) as fh:
        for line in fh:
            if not line.strip(): continue
            f = line.rstrip("\n").split("\t")
            key, oid, client, seq, typ, val, vc = f
            if key != cur_key:
                flush(); cur_key = key; ops = []
            ops.append({"key": key, "id": oid, "client": client, "seq": int(seq),
                        "type": typ, "val": (None if val == "__NULL__" else val),
                        "vc": parse_vc(vc)})
        flush()
    bad = any(k["linearizable"] is False for k in keys)
    unknown = any(k["linearizable"] is None for k in keys)
    print(json.dumps({"keys": keys,
                      "linearizable": (False if bad else (None if unknown else True))},
                     indent=2))
    sys.exit(1 if bad else (2 if unknown else 0))

main()

# ---------------------------------------------------------------------------
# Streaming reconstruction.  jq -> TSV; `sort` orders by (client,seq,replica)
# so one replica-view group is contiguous; awk certifies quorum, de-duplicates,
# detects equivocation and per-client sequence gaps with O(clients) state.
# ---------------------------------------------------------------------------
set +e
RESULT=$(jq -r '[.id,.client,(.seq|tostring),.type,.key,
        (if .val==null then "__NULL__" else (.val|tostring) end),.replica,
        ((.vc//{})|to_entries|map("\(.key)=\(.value)")|join(";"))]|@tsv' \
        ${INFILE:+"$INFILE"} \
| sort -t$'\t' -k2,2 -k3,3n -k7,7 \
| awk -F'\t' -v q="$QUORUM" -v diag="$TMP/diag" '
    function finalize() {
        if (grp == "") return;
        if (conflict) print "EQUIVOCATION\t" client "\t" seq > diag;
        else if (nrepl >= q) printf "%s\t%s\t%s\t%s\t%s\t%s\t%s\n",
                                  key, oid, client, seq, typ, val, vc;
    }
    {
        c=$2; s=$3+0; r=$7; gkey=c SUBSEP s;
        if (gkey != grp) {
            finalize();
            grp=gkey; client=c; seq=s; key=$5; oid=$1; typ=$4; val=$6; vc=$8;
            sig=$1 SUBSEP $4 SUBSEP $5 SUBSEP $6; nrepl=1; prevr=r; conflict=0;
            if ((c in lastseq) && s > lastseq[c] + 1)
                gaps[c] = gaps[c] " " (lastseq[c]+1) ".." (s-1);
            lastseq[c]=s;
        } else {
            if (r != prevr) { nrepl++; prevr=r; }
            if (($1 SUBSEP $4 SUBSEP $5 SUBSEP $6) != sig) conflict=1;
        }
    }
    END {
        finalize();
        for (c in gaps) print "GAP\t" c "\t" gaps[c] > diag;
    }' \
| sort -t$'\t' -k1,1 > "$TMP/canon"
python3 "$PY" "$WINDOW" "$TMP/canon")
RC=$?
set -e
printf '%s\n' "$RESULT"
if [ -s "$TMP/diag" ]; then
  while IFS= read -r d; do printf 'reconstruction: %s\n' "$d" >&2; done < "$TMP/diag"
  grep -q '^EQUIVOCATION' "$TMP/diag" && RC=1
  if grep -q '^GAP' "$TMP/diag" && [ "$RC" -eq 0 ]; then RC=2; fi
fi
exit "$RC"

4. Usage

# quorum = majority of 2f+1 replicas; exact, unbounded frontier
./bft-lincheck.sh --quorum 2 replica-log.ndjson

# cap the per-key frontier for a hostile / unbounded-concurrency key:
# keys above the cap return "unknown" (exit 2) instead of risking a wrong answer
./bft-lincheck.sh --quorum 2 --window 200000 replica-log.ndjson

Exit codes are the machine-readable contract:

code meaning
0 certified linearizable (no gaps, no anomalies)
1 definite safety violation or Byzantine anomaly (equivocation, forged clock)
2 cannot certify: missing records / frontier exceeded / state budget

The checker never returns 0 when it is unsure. That is the whole point of a safety checker.

A brute-force checker enumerates every topological order and every register state (correct by construction, exponential but exact on small histories).

7. Operational notes and limitations

  • Per-key independence. Linearizability of a store with single-key operations decomposes across keys; the checker exploits this to bound memory. Multi-key transactions would require checking the product of the touched keys.
  • Genuine gaps are fatal to a 0 verdict. The global gap detector reports GAP <client> <range> on stderr and forces exit 2. If you have a repair path (recovering the record from a quorum), feed the repaired record back in.
  • State budget. The DFS raises unknown after 5 000 000 memoised states, so a pathologically concurrent key degrades to exit 2 rather than hanging.
  • Vector-clock trust. Clock validation is only as good as the global per-client maximum. A forged clock that stays within observed bounds and is consistent with every present op is indistinguishable from a real one; this is exactly the limit of what the log alone can prove.
  • Input hygiene. The checker does not silently treat a missing vector clock as "causally independent" (that would be permissive, not conservative). A record whose clock lacks its own (client, seq) component is reported as an inconsistent clock and fails closed (exit 1). Well-formedness of the JSON itself is assumed; filter corrupt lines upstream.

Summary of what makes this correct and safe: 1. Causality comes from vector clocks, never wall clocks (handles skew + adversarial reordering). 2. Records are quorum-certified, de-duplicated, and gap-checked before checking. 3. The exact search finds a total order or proves none exists — it never equates convergence with safety. 4. On failure it emits a minimal, well-formed conflicting witness with the closing happens-before edges. 5. Memory is bounded by O(clients) in reconstruction and the live causal frontier per key; anything it cannot certify returns unknown (exit 2), never a false 0.
