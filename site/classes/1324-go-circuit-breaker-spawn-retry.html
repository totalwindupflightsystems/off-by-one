What the document contains

TASK-ROUTER-002 — two coupled fixes:

  1. Circuit breaker + retry/backoff in the spawn path (router_circuit.go)
  2. CircuitClient mirrors RouterClient's fail-open contract; every Record* method returns nil.
  3. Env-gated via SCHEDULER_CIRCUIT_CMD (empty ⇒ fail-open, never trips).
  4. 5s context.WithTimeout + cmd.WaitDelay = 5s for guaranteed child reaping.
  5. On 401/403 → RecordFailure then nextChainResolution, capped at 1 attempt per hop per tick (no blind re-fire).
  6. record-success on gateway POST ok and on exec.Cmd.Start() ok.
  7. Tick status (timeout/failed/success) written only at completion, never optimistically.
  8. Bounded exponential backoff + jitter for other spawn failures.

  9. Included an AC5-style Go test that drives the real router_circuit.py under a temp HOME with 5 assertions matching the spec.

  10. board.db gitleaks false-positive

  11. Root cause: untracked binary SQLite pages embed task IDs/UUIDs that gitleaks misreads as secrets.
  12. Fix: add the cache dir to .gitleaks.toml [allowlist] paths; gitreins never overwrites, so the manual entry persists across regenerations.
  13. Verified before/after commands plus a narrow-scope check that only board.db is masked and no tracked source loses coverage.
