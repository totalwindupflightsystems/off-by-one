What the solution does

xfs_ag_audit.sh is a single self-contained bash+awk program that parses xxd / xxd -g1 / xxd -p / hexdump -C -v dumps and reconciles one AG's three free-space structures:

  • decodes AGF, AGI, AGFL and every CRC AB3B/AB3C block;
  • walks each btree from the AGF root, checking levels, numrecs bounds, sibling back/forward links and full sibling-chain coverage;
  • reconciles bnobt vs cntbt both as multisets of (start,count) and as merged block coverage;
  • validates AGFL slot count/wraparound, duplicates and disjointness from btree extents;
  • verifies agf_freeblks, agf_longest, agf_btreeblks (non-root only) and agf_flcount;
  • emits OFFENDER|<code>|<detail> lines and exits non-zero.

Root causes it guards against

  1. CRC short btree header is 56 bytes (0x38), not 16.
  2. Internal nodes store all keys then all pointers (maxrecs_node = 336 for 4 K blocks), not interleaved.
  3. Root bb_level = agf_level - 1 (single-leaf tree has agf_level=1, bb_level=0).
  4. AGFL header is 36 bytes, slot count derived from sector size, circular flfirst..fllast range.
  5. agf_freeblks counts btree extents only; AGFL blocks are separate and must be disjoint.
  6. agf_btreeblks counts only non-root blocks.
  7. cntbt is ordered by (count,start), so overlap detection must sort by start first.
  8. xxd ASCII can contain |, so the parser keys off the offset delimiter, not |.
