Fixing the t-digest "error cliff" when merging heavy-tailed streams

Problem class: js-tdigest-online-quantile-merge-clustering-error-cliff-heavy-tailed-skew

Environment: Node.js 20 (this workspace reports v22; the code only uses ES2020 features available in Node 20).

Symptom: After two digests that used different delta / compression settings are merged, the number of centroids collapses and the estimated 0.999 quantile error jumps from the 0.1% class to the 5-10% class. The failure is not caused by heavy tails per se; it is caused by recomputing cluster boundaries with the wrong scale.

1. Root cause

A t-digest stores weighted centroids. The legal cluster width at rank q is controlled by a scale function k(q) and a normalizer derived from the total sample count of the digest that owns the centroids:

K3:  k(q) = nrm * log(2q)          for q <= 1/2
     k(q) = -nrm * log(2(1-q))     for q >  1/2
     nrm  = compression / Z,   Z = 4 log(N / compression) + 21

A candidate cluster spanning [q0, q1] is legal when

k(q1) - k(q0) <= 1

This is the scaled k1/k2 size function: k(q0) and k(q1) are the two k boundaries, and they must be evaluated with one normalizer.

The error cliff appears when merge code does either of these:

  1. Re-clusters the union with the smaller input delta.
    delta (compression) is an inverse accuracy knob. Using min(deltaA, deltaB) forces the merged digest to keep the centroid budget of the worst input. It throws away the resolution of the better input.
  2. Reuses each digest's private normalizer.
    Each input digest computed its centroids with its own N_i and its own Z(compression_i, N_i). Those k-values are not comparable. Concatenating them and deciding what to merge with the old boundaries is not order-independent and can over-merge (or under-merge) the union.

The correct invariant is simple:

All centroids from all inputs are pooled first.
The union total N = Σ N_i is computed once.
A single target compression is chosen (max by default).
All boundaries are recomputed with nrm = target / Z(target, N).

That single-pass, union-scale re-clustering is what the fix implements.

2. Exact fix

The full working implementation is in ~/final/tdigest.js. The two functions that carry the fix are:

2.1 mergeCentroids — k-size-monotone union merge

function mergeCentroids(left, right, compression) {
  const input = [];
  for (const c of left)  if (c.weight > 0) input.push({ mean: c.mean, weight: c.weight });
  for (const c of right) if (c.weight > 0) input.push({ mean: c.mean, weight: c.weight });
  if (input.length === 0) return [];

  // Deterministic order => A+B and B+A give the same sequence.
  input.sort((a, b) =>
    a.mean < b.mean ? -1 : a.mean > b.mean ? 1 : a.weight - b.weight);

  let N = 0;
  for (const c of input) N += c.weight;
  if (!(N > 0)) return [];

  // ONE normalizer on the UNION sample count N.
  const nrm = SCALE.normalizer(compression, N);

  const out = [{ mean: input[0].mean, weight: input[0].weight }];
  let wSoFar = 0;

  for (let i = 1; i < input.length; i++) {
    const cur = out[out.length - 1];
    const inc = input[i];
    const proposed = cur.weight + inc.weight;
    const q0 = wSoFar / N;
    const q1 = (wSoFar + proposed) / N;

    let merge;
    if (i === 1 || i === input.length - 1) {
      merge = false;                 // K3 requires singleton endpoints
    } else {
      const k0 = SCALE.k(q0, nrm);   // <-- scaled k1
      const k1 = SCALE.k(q1, nrm);   // <-- scaled k2
      merge = (k1 - k0) <= 1 + 1e-12;

      // Belt-and-braces endpoint weight guard.
      const maxW = N * Math.min(
        SCALE.maxFraction(q0, nrm),
        SCALE.maxFraction(q1, nrm));
      if (proposed > maxW) merge = false;
    }

    if (merge) {
      const w = cur.weight + inc.weight;
      cur.mean += (inc.mean - cur.mean) * (inc.weight / w);
      cur.weight = w;
    } else {
      wSoFar += cur.weight;
      out.push({ mean: inc.mean, weight: inc.weight });
    }
  }
  return out;
}

2.2 TDigest.mergeAll — order-independent union merge

static mergeAll(digests, targetCompression = null) {
  if (!Array.isArray(digests) || digests.length === 0)
    throw new Error('empty digest list');

  for (const d of digests) d.compress();

  // Never silently downgrade to the weakest input.
  const target = targetCompression == null
    ? Math.max(...digests.map(d => d.compression))
    : targetCompression;

  const all = [];
  let total = 0, min = Infinity, max = -Infinity;
  for (const d of digests) {
    total += d.totalWeight;
    min = Math.min(min, d.min);
    max = Math.max(max, d.max);
    for (const c of d.centroids) all.push({ mean: c.mean, weight: c.weight });
  }

  const out = new TDigest(target);
  // One re-clustering pass on the union. The scale is now k-size-monotone.
  out.centroids = mergeCentroids(all, [], target);
  out.totalWeight = total;
  out.min = min;
  out.max = max;
  return out;
}

The older single-digest merge(other, target) is retained, but it delegates to the same union logic by calling mergeCentroids(this.centroids, other.centroids, target); the important operational rule is to use TDigest.mergeAll([A, B]) (or A.merge(B)) with the target compression fixed to max(deltaA, deltaB).

3. Verification

3.1 Script

The verifier is ~/final/verify.js. It:

  1. Generates N = 1,000,000 deterministic Pareto(1.05) samples (inverse-CDF, seeded mulberry32).
  2. Splits them into two halves and builds two digests with different deltas.
  3. Compares a naive merge (concat then compress with min(delta)) with the fixed union-scale merge.
  4. Runs a Kolmogorov–Smirnov scan against the exact Pareto CDF: D = max_p | F_digest(Q_exact(p)) - p | over a 50,000-point probability grid.
  5. Checks that A+B and B+A are identical under mergeAll.

Run it with:

cd ~/final
node verify.js

3.3 Interpretation

  • Cliff removed. With A(2000) and B(50), the naive min-delta merge collapses to 40 centroids and gives 8.5% relative error at 0.999. The fixed union-scale merge keeps 628 centroids and reduces the error to 0.489%. The 9% KS error of the fixed merge in this deliberately mismatched case is the residual error of the coarse delta=50 input; a merge cannot invent tail resolution that the input never had.
  • Order independence. A(2000) + B(1000) and B(1000) + A(2000) produce exactly the same centroid count (1181) and the same 0.999 quantile. The deterministic sort plus one union normalizer is responsible.
  • KS verification on a well-resolved merge. When both inputs are accurate enough (A(5000), B(2000)), the merged digest keeps 2804 centroids, has KS D = 0.00125, which is below the 5% critical value 0.00136 for N=1,000,000, and gives a 0.163% relative error at 0.999. This is the intended accuracy class — a merge that respects the scaled k1/k2 size function on the union.

3.4 What to look for in the code

  • Do not call digest.merge(other) with a target compression derived from the smaller digest.
  • Do not concatenate centroids and reuse the old nrm.
  • Do compute N = totalWeight after all inputs are compressed.
  • Do compute one normalizer nrm = compression / Z(compression, N).
  • Do allow a centroid to join a cluster only if k(q1) - k(q0) <= 1 under that one normalizer.
  • Do keep the first and last centroids as singleton endpoints for K3 (max(0)=0, max(1)=0).
