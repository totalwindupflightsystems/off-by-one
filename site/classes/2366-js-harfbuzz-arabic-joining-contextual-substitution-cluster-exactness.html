HarfBuzz-equivalent Arabic / Devanagari shaping — diagnosis & fix

Root cause

A naive left‑to‑right substitution fails this corpus for five independent reasons; fixing any subset still leaves visibly wrong output.

  1. Joining is contextual, not per‑character. Form = f(previous, next) using Joining_Type R/D/C/L/U. Marks are Transparent and must be skipped, but Transparency is the default for all Mn/Me/Mc codepoints and is not listed in ArabicShaping.txt — a table returning U for missing codepoints makes every fatha a joining barrier. ZWJ (C) forces joining, ZWNJ (U) blocks it, tatweel (C) behaves like a visible ZWJ. Each form feature must be enabled only on the glyphs whose form was derived.

  2. Lookup flags make matching skippy. GDEF class bits coincide with the flag bits, so HarfBuzz tests glyph_props & flag & 0x000E; IgnoreMarks lets the lam+alef ligature match across a fatha (لَا), and MarkAttachmentType/UseMarkFilteringSet skip marks by attachment type / mark set. A pairwise comparator never matches these.

  3. Features are staged and glyph masks carry the staging. ccmp/locl must run before joining, mark/mkmk/kern after GSUB. HarfBuzz sorts enabled lookups by lookup index and gates each glyph with a feature mask (glyph.mask & lookup.mask). Without masks, a ccmp SingleSubst can consume the form fina just produced.

  4. Clusters must survive ligatures and mark reordering. Ligature merges use the minimum cluster over the consumed range; canonical combining‑class reordering must keep a mark on its base's cluster; a ZWJ's cluster merges with the preceding glyph (ZWNJ does not); and the merge must run after substitution because the base may just have become a ligature.

  5. Default ignorables are hidden, not shaped. ZWJ/ZWNJ become hidden space glyphs with zero advance and mask 0; mark attachment searches past them (with ZWJ as a barrier).

The fix

shape.mjs parses SFNT/cmap/GDEF/GSUB/GPOS itself, then runs the pipeline. The critical pieces:

Joining (marks are transparent):

function joiningType(cp) {
  const t = lookupRanges(JOINING_RANGES, cp); if (t) return t;
  if (inRanges(MARK_RANGES, cp)) return 'T';   // the fix naive tables miss
  return 'U';
}
// form = isol|init|medi|fina from joinPrev/joinNext, skipping T

Lookup‑flag skipper (class bits == flag bits):

function skipGlyph(font, flag, mfs, g) {
  const k = font.klass(g);                       // 1 base 2 lig 3 mark
  const props = k === 1 ? 0x0002 : k === 2 ? 0x0004 : k === 3 ? 0x0008 : 0;
  if (props & flag & 0x000e) return true;        // IgnoreBase/Lig/Marks
  if (k === 3) {
    const mt = (flag >> 8) & 0xff;               // MarkAttachmentType
    if (mt && (font.gdef.markAttach.get(g) || 0) !== mt) return true;
    if (mfs != null && !font.gdef.markSets[mfs]?.has(g)) return true;
  }
  return false;
}

Ligature matching + monotonic clusters + masks:

// match components with skippy iteration, then:
let cluster = infos[i].cluster;
for (let k = i + 1; k <= j; k++) cluster = Math.min(cluster, infos[k].cluster);
for (let k = i; k <= j; k++) infos[k].cluster = cluster;
infos[i].gid = lig.lig;
// per-glyph feature mask: lookup applies iff (infos[pos].mask & lookupMask) !== 0n

Mark ordering / cluster fixup (runs after GSUB):

reorderMarks(infos);                       // stable ccc sort, ccc==0 is a barrier
mergeMarkClusters(infos); mergeZwjClusters(infos);
for (let n = 0; n < 8; n++) {              // fixpoint, handles ZWJ runs
  let ch = mergeMarkClusters(infos);
  ch = mergeZwjClusters(infos) || ch;
  if (!ch) break;
}

Mark attachment reads the proper MarkBasePosFormat1 layout (markCoverage, baseCoverage, markClassCount, markArray, baseArray), searches backwards past marks and hidden ignorables, sets mark.offset = baseAnchor − markAnchor and zeroes the mark advance.
