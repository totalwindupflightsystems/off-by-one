Answer

Root cause (corrected diagnosis): chimera-v2 has cooldown_s = 900 pinned in both /home/kara/coding-hermes-scheduler/coding-herms-scheduler/fleet.toml and ~/.hermes/fleet.toml. On daemon restart, the scheduler reconciles state from fleet.toml and overwrites the runtime value (43200 set via API PUT) back to 900. Detection must be grep, not assumption.

Fix — edit the TOML files (this is the permanent fix), not just the API:

# 1. Detect (not assume) — confirm the pinned values in BOTH files
grep -n "cooldown_s" /home/kara/coding-hermes-scheduler/coding-herms-scheduler/fleet.toml ~/.hermes/fleet.toml
# expect: both show  cooldown_s = 900  under the chimera-v2 [[agents]] block

# 2. Fix both files (they must agree — one stale file is enough to regress)
sed -i '/chimera-v2/,/^\[\[/ s/cooldown_s = 900/cooldown_s = 43200/' \
  /home/kara/coding-hermes-scheduler/coding-herms-scheduler/fleet.toml
sed -i '/chimera-v2/,/^\[\[/ s/cooldown_s = 900/cooldown_s = 43200/' ~/.hermes/fleet.toml

# 3. Re-verify the edit landed in both
grep -n "cooldown_s" /home/kara/coding-hermes-scheduler/coding-herms-scheduler/fleet.toml ~/.hermes/fleet.toml

Equivalent TOML fragment after the fix:

[[agents]]
id = "chimera-v2"
# ...
cooldown_s = 43200   # was 900 — file is now the source of truth

Runtime API PUT — correct form on this scheduler version:

# CORRECT: CooldownS-only PUT (accepted, 200)
curl -X PUT http://localhost:<port>/api/v1/scheduler/agents/chimera-v2 \
  -H 'Content-Type: application/json' \
  -d '{"CooldownS": 43200}'

# WRONG: DecayRate=0 is rejected with "decay_rate must be > 0" validation error
# curl -X PUT ... -d '{"DecayRate": 0, "CooldownS": 43200}'   # -> 400, do not use

Note the API uses camelCase CooldownS; the file uses snake_case cooldown_s. The API PUT is a runtime tweak only — durability comes from the file.

Regression guard: add a startup/CI smoke check so a 900 can never silently return:

# CI / pre-start assertion — fails loudly instead of reverting silently
if grep -Eq 'cooldown_s = 900' ~/.hermes/fleet.toml \
   /home/kara/coding-hermes-scheduler/coding-herms-scheduler/fleet.toml; then
  echo "FATAL: pinned cooldown_s=900 found in fleet.toml (chimera-v2)" >&2; exit 1
fi
