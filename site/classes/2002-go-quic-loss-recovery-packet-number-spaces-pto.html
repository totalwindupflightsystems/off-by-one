QUIC Loss Recovery over Per-Packet-Number-Space State

Summary

The task is to implement RFC 9002-style loss recovery where Initial, Handshake, and Application are three independent packet number spaces. The failure mode named by the problem class is a single shared "packet number space": one largest_acked, one in-flight set, one loss/PTO timer. Such an implementation silently corrupts state whenever two spaces are active at once (the handshake/application overlap), fires PTOs it should not, and produces the wrong retransmit counts under reordering and tail loss.

This document contains the root-cause analysis, the exact fix (a complete Go package), and a regression test that passes on the correct engine and fails on the naive single-space engine. The package lives in /home/kara/quicrecovery.

Root-cause analysis

RFC 9002 §5.1 is explicit: packet numbers are independent for each packet number space. That independence is load-bearing for four separate mechanisms. The naive implementation breaks each one:

  1. ACK processing (largest_acked). An ACK frame carries range sets meaningful only within the space it was received on. A shared largest_acked lets ACK(Application, largest=5) set the Handshake largest-acked to 5. Loss detection in Handshake then thinks packet numbers ≤ 2 are old, and RTT/ECN counters are polluted. Rule: an ACK for one space must never advance another space's largest-acked.
  2. In-flight accounting and loss detection. Each space has its own sent-but-unacked set and its own 9/8 * max(srtt, latest_rtt) loss timer. Sharing them declares a Handshake packet lost because an unrelated Application packet was acknowledged, and corrupts bytes_in_flight.
  3. PTO arming. Per RFC 9002 §6.2.1:
  4. A PTO is armed only when the first ack-eliciting packet in a space goes in flight.
  5. It is not reset while other ack-eliciting packets are already in flight.
  6. It is re-anchored to time_of_last_ack_eliciting_packet only after a newly acknowledged ack-eliciting packet, and pto_count resets to 0.
  7. An ACK-only packet must never arm or reset a PTO. Merged state lets an ACK-only flight in one space postpone/cancel the PTO another space needs, and applies backoff to the wrong counter.
  8. PTO backoff / probes. On expiry the period doubles (base * 2^pto_count) in the space whose timer expired, and probes are sent there. Merged state makes the doubling global.

Two extra traps the correct engine must avoid:

  • Loss timer must not spin. RFC 9002 applies the time threshold only to packets with packet_number <= largest_acked (§6.1.2, Appendix A). If the loss timer is set for packets above largest_acked, AdvanceTo recomputes the same past deadline forever. We set the loss timer only when an ACK exists and only over packets at or below largest_acked; otherwise PTO is the recovery mechanism.
  • PTO deadline must not be in the past after an ACK. Anchoring to the oldest in-flight packet makes the deadline fall behind now as acks trickle in, producing an immediate spurious probe. RFC anchors to time_of_last_ack_eliciting_packet.

The fix

A small Go package:

  • range.go — RangeSet (sorted, coalesced inclusive ranges), QUIC varints, ACK-frame encode/decode, PendingACKs.
  • recovery.go — Space, Config, per-space spaceState, Manager (independent largest_acked, in-flight sets, RTT, loss timers, PTO per space). NewNaive maps all spaces onto one state, used only by the regression.
  • congestion.go — pluggable CongestionController + NewReno and DeliveryRate (BBR-style); ECN-CE via OnECNCongestion, once per RTT in NewReno.
  • sim.go — deterministic trace runner + invariant checks.

The regression test ships five traces:

heavy-reordering 2 0 non-contiguous ACK ranges, packet-threshold loss
tail-loss 0 4 un-acked tail recovered by PTO, exponential backoff
cross-space-overlap 0 0 Initial/Handshake/Application ACKs must not cross
persistent-ce 0 0 repeated ECN-CE marks, once-per-RTT reaction

package recovery

import (
    "errors"
    "sort"
)

// Range is an inclusive range of packet numbers [Low, High].
type Range struct {
    Low  uint64
    High uint64
}

// RangeSet is a set of packet numbers represented as sorted, disjoint,
// non-adjacent inclusive ranges (stored ascending internally). It is used for
// both sides of an ACK frame: to accumulate the packet numbers an endpoint has
// received (so it can emit an ACK frame), and to parse the ranges carried by an
// incoming ACK frame.
type RangeSet struct {
    ranges []Range // ascending by Low, disjoint and non-adjacent
}

// Add inserts n into the set, coalescing with any touching/overlapping ranges.
func (s *RangeSet) Add(n uint64) {
    for i := 0; i < len(s.ranges); i++ {
        r := s.ranges[i]
        switch {
        case r.High+1 < n && r.High != ^uint64(0):
            // r ends strictly before n-1: keep scanning.
            continue
        case r.Low > n+1 && n != ^uint64(0):
            // r starts strictly after n+1: insert a fresh range here.
            s.ranges = append(s.ranges, Range{})
            copy(s.ranges[i+1:], s.ranges[i:])
            s.ranges[i] = Range{n, n}
            return
        default:
            // Touch/overlap: extend r, then coalesce forward.
            if r.Low < n {
            } else {
                r.Low = n
            }
            if r.High > n {
            } else {
                r.High = n
            }
            // merge with the following ranges while they touch.
            j := i + 1
            for j < len(s.ranges) && s.ranges[j].Low <= r.High+1 {
                if s.ranges[j].High > r.High {
                    r.High = s.ranges[j].High
                }
                j++
            }
            s.ranges[i] = r
            s.ranges = append(s.ranges[:i+1], s.ranges[j:]...)
            return
        }
    }
    s.ranges = append(s.ranges, Range{n, n})
}

// Contains reports whether n is in the set.
func (s *RangeSet) Contains(n uint64) bool {
    i := sort.Search(len(s.ranges), func(i int) bool { return s.ranges[i].High >= n })
    return i < len(s.ranges) && s.ranges[i].Low <= n
}

// Len returns the number of packet numbers in the set.
func (s *RangeSet) Len() uint64 {
    var n uint64
    for _, r := range s.ranges {
        n += r.High - r.Low + 1
    }
    return n
}

// Min returns the smallest element and whether the set is non-empty.
func (s *RangeSet) Min() (uint64, bool) {
    if len(s.ranges) == 0 {
        return 0, false
    }
    return s.ranges[0].Low, true
}

// Max returns the largest element and whether the set is non-empty.
func (s *RangeSet) Max() (uint64, bool) {
    if len(s.ranges) == 0 {
        return 0, false
    }
    return s.ranges[len(s.ranges)-1].High, true
}

// Ascending returns the ranges in ascending order.
func (s *RangeSet) Ascending() []Range {
    out := make([]Range, len(s.ranges))
    copy(out, s.ranges)
    return out
}

// Descending returns the ranges in descending order, which is the order used by
// a QUIC ACK frame.
func (s *RangeSet) Descending() []Range {
    out := make([]Range, len(s.ranges))
    for i, r := range s.ranges {
        out[len(out)-1-i] = r
    }
    return out
}

// Clone returns a deep copy.
func (s *RangeSet) Clone() *RangeSet {
    out := &RangeSet{}
    out.ranges = make([]Range, len(s.ranges))
    copy(out.ranges, s.ranges)
    return out
}

// Subtract removes n if present, splitting a range if needed.
func (s *RangeSet) Subtract(n uint64) {
    i := sort.Search(len(s.ranges), func(i int) bool { return s.ranges[i].High >= n })
    if i >= len(s.ranges) || s.ranges[i].Low > n {
        return
    }
    r := s.ranges[i]
    switch {
    case r.Low == n && r.High == n:
        s.ranges = append(s.ranges[:i], s.ranges[i+1:]...)
    case r.Low == n:
        s.ranges[i].Low = n + 1
    case r.High == n:
        s.ranges[i].High = n - 1
    default:
        s.ranges[i].High = n - 1
        s.ranges = append(s.ranges, Range{})
        copy(s.ranges[i+2:], s.ranges[i+1:])
        s.ranges[i+1] = Range{n + 1, r.High}
    }
}

// ---- QUIC variable-length integers ----

func appendVarint(b []byte, v uint64) []byte {
    switch {
    case v < 1<<6:
        return append(b, byte(v))
    case v < 1<<14:
        return append(b, byte(v>>8)|0x40, byte(v))
    case v < 1<<30:
        return append(b, byte(v>>24)|0x80, byte(v>>16), byte(v>>8), byte(v))
    default:
        return append(b,
            byte(v>>56)|0xc0, byte(v>>48), byte(v>>40), byte(v>>32),
            byte(v>>24), byte(v>>16), byte(v>>8), byte(v))
    }
}

func readVarint(b []byte) (uint64, int, error) {
    if len(b) == 0 {
        return 0, 0, errors.New("short varint")
    }
    prefix := b[0] >> 6
    size := 1 << prefix
    if len(b) < size {
        return 0, 0, errors.New("short varint")
    }
    var v uint64
    switch prefix {
    case 0:
        v = uint64(b[0] & 0x3f)
    case 1:
        v = uint64(b[0]&0x3f)<<8 | uint64(b[1])
    case 2:
        v = uint64(b[0]&0x3f)<<24 | uint64(b[1])<<16 | uint64(b[2])<<8 | uint64(b[3])
    default:
        v = uint64(b[0]&0x3f)<<56 | uint64(b[1])<<48 | uint64(b[2])<<40 | uint64(b[3])<<32 |
            uint64(b[4])<<24 | uint64(b[5])<<16 | uint64(b[6])<<8 | uint64(b[7])
    }
    return v, size, nil
}

// AckFrame is a decoded QUIC ACK frame. Ranges is descending by High and
// includes LargestAcked in Ranges[0].High.
type AckFrame struct {
    LargestAcked uint64
    AckDelay     uint64
    Ranges       []Range
    ECN          bool
    ECT0         uint64
    ECT1         uint64
    ECNCE        uint64
}

// NewAckFrame builds an ACK frame from the received packet numbers.
func NewAckFrame(rs *RangeSet, ackDelay uint64) (AckFrame, bool) {
    max, ok := rs.Max()
    if !ok {
        return AckFrame{}, false
    }
    return AckFrame{
        LargestAcked: max,
        AckDelay:     ackDelay,
        Ranges:       rs.Descending(),
    }, true
}

// Encode serialises the ACK frame using QUIC variable-length integer encoding.
func (f AckFrame) Encode() []byte {
    if len(f.Ranges) == 0 {
        return nil
    }
    typ := byte(0x02)
    if f.ECN {
        typ = 0x03
    }
    b := []byte{typ}
    b = appendVarint(b, f.LargestAcked)
    b = appendVarint(b, f.AckDelay)
    b = appendVarint(b, uint64(len(f.Ranges)-1))
    b = appendVarint(b, f.Ranges[0].High-f.Ranges[0].Low) // first ACK range length
    for i := 1; i < len(f.Ranges); i++ {
        // Gap is the number of unacknowledged packets between the previous
        // (higher) range Low and this range High.
        gap := f.Ranges[i-1].Low - f.Ranges[i].High - 2
        b = appendVarint(b, gap)
        b = appendVarint(b, f.Ranges[i].High-f.Ranges[i].Low)
    }
    if f.ECN {
        b = appendVarint(b, f.ECT0)
        b = appendVarint(b, f.ECT1)
        b = appendVarint(b, f.ECNCE)
    }
    return b
}

// DecodeAckFrame parses an ACK frame produced by Encode (or by a peer).
func DecodeAckFrame(b []byte) (AckFrame, int, error) {
    if len(b) == 0 {
        return AckFrame{}, 0, errors.New("empty frame")
    }
    if b[0] != 0x02 && b[0] != 0x03 {
        return AckFrame{}, 0, errors.New("not an ACK frame")
    }
    f := AckFrame{ECN: b[0] == 0x03}
    pos := 1
    var err error
    if f.LargestAcked, pos, err = decodeAt(b, pos); err != nil {
        return AckFrame{}, 0, err
    }
    if f.AckDelay, pos, err = decodeAt(b, pos); err != nil {
        return AckFrame{}, 0, err
    }
    var count uint64
    if count, pos, err = decodeAt(b, pos); err != nil {
        return AckFrame{}, 0, err
    }
    var first uint64
    if first, pos, err = decodeAt(b, pos); err != nil {
        return AckFrame{}, 0, err
    }
    if first > f.LargestAcked {
        return AckFrame{}, 0, errors.New("first ACK range underflows")
    }
    f.Ranges = []Range{{Low: f.LargestAcked - first, High: f.LargestAcked}}
    for i := uint64(0); i < count; i++ {
        var gap, length uint64
        if gap, pos, err = decodeAt(b, pos); err != nil {
            return AckFrame{}, 0, err
        }
        if length, pos, err = decodeAt(b, pos); err != nil {
            return AckFrame{}, 0, err
        }
        prev := f.Ranges[len(f.Ranges)-1]
        high := prev.Low - gap - 2
        if gap+2 > prev.Low {
            return AckFrame{}, 0, errors.New("ACK range underflows")
        }
        if length > high {
            return AckFrame{}, 0, errors.New("ACK range length underflows")
        }
        f.Ranges = append(f.Ranges, Range{Low: high - length, High: high})
    }
    if f.ECN {
        if f.ECT0, pos, err = decodeAt(b, pos); err != nil {
            return AckFrame{}, 0, err
        }
        if f.ECT1, pos, err = decodeAt(b, pos); err != nil {
            return AckFrame{}, 0, err
        }
        if f.ECNCE, pos, err = decodeAt(b, pos); err != nil {
            return AckFrame{}, 0, err
        }
    }
    return f, pos, nil
}

func decodeAt(b []byte, pos int) (uint64, int, error) {
    v, n, err := readVarint(b[pos:])
    if err != nil {
        return 0, 0, err
    }
    return v, pos + n, nil
}

// SetFromAck descends the ACK ranges into a RangeSet (ascending).
func (f AckFrame) SetFromAck() *RangeSet {
    rs := &RangeSet{}
    for i := len(f.Ranges) - 1; i >= 0; i-- {
        rs.ranges = append(rs.ranges, f.Ranges[i])
    }
    return rs
}

package recovery

import "sort"

// Space identifies a QUIC packet number space.
type Space uint8

const (
    Initial Space = iota
    Handshake
    Application
)

// NumSpaces is the number of QUIC packet number spaces.
const NumSpaces = int(Application) + 1

func (s Space) String() string {
    switch s {
    case Initial:
        return "Initial"
    case Handshake:
        return "Handshake"
    case Application:
        return "Application"
    }
    return "Unknown"
}

// Config controls loss recovery.
type Config struct {
    // InitialRTT is the assumed RTT before a sample exists, in microseconds.
    InitialRTT int64
    // MaxAckDelay is the peer's max_ack_delay, in microseconds.
    MaxAckDelay int64
    // TimerGranularity is the timer granularity, in microseconds.
    TimerGranularity int64
    // PacketThreshold is the reordering threshold kPacketThreshold.
    PacketThreshold uint64
    // MaxDatagramSize is the probe/retransmit size.
    MaxDatagramSize int
    // CC is the congestion controller. Defaults to NewReno.
    CC CongestionController
    // AutoRetransmit re-sends a fresh ack-eliciting packet whenever an
    // in-flight packet is declared lost.
    AutoRetransmit bool
}

// DefaultConfig returns the RFC 9002 defaults.
func DefaultConfig() Config {
    return Config{
        InitialRTT:       100_000,
        MaxAckDelay:      25_000,
        TimerGranularity: 1_000,
        PacketThreshold:  3,
        MaxDatagramSize:  1200,
        CC:               NewNewReno(1200),
        AutoRetransmit:   true,
    }
}

type rttState struct {
    hasSample bool
    latest    int64
    min       int64
    smoothed  int64
    variance  int64
}

func (r *rttState) update(sample int64) {
    if sample < 1 {
        sample = 1
    }
    r.latest = sample
    if !r.hasSample {
        r.hasSample = true
        r.min = sample
        r.smoothed = sample
        r.variance = sample / 2
        return
    }
    if sample < r.min {
        r.min = sample
    }
    delta := r.smoothed - sample
    if delta < 0 {
        delta = -delta
    }
    r.variance = (3*r.variance + delta) / 4
    r.smoothed = (7*r.smoothed + sample) / 8
}

type sentPacket struct {
    number       uint64
    space        Space
    timeSent     int64
    ackEliciting bool
    inFlight     bool
    size         int
}

type spaceState struct {
    space            Space
    nextPacketNumber uint64
    largestAcked     uint64
    hasLargestAcked  bool

    sent                 map[uint64]*sentPacket
    ackElicitingInFlight int

    lossTime    int64
    hasLossTime bool
    ptoTime     int64
    hasPTO      bool
    ptoCount    int

    // lastAckElicitingSent is time_of_last_ack_eliciting_packet for the space.
    lastAckElicitingSent int64

    // Largest ECN counts observed in ACK frames for this space.
    ecnECT0 uint64
    ecnECT1 uint64
    ecnCE   uint64
}

func newSpaceState(s Space) *spaceState {
    return &spaceState{space: s, sent: make(map[uint64]*sentPacket)}
}

// Engine is the surface shared by the correct and naive implementations.
type Engine interface {
    SendPacket(space Space, ackEliciting bool, size int) uint64
    OnACK(space Space, frame AckFrame, now int64)
    AdvanceTo(now int64)
    LargestAcked(space Space) (uint64, bool)
    PTOTime(space Space) (int64, bool)
    Lost() int
    Probes() int
    BytesInFlight() int
    Window() int
    AckElicitingInFlight(space Space) int
}

// Manager is the multi-space loss-recovery engine.
type Manager struct {
    cfg    Config
    rtt    rttState
    states []*spaceState
    spaces [NumSpaces]*spaceState
    merged bool

    bytesInFlight int
    lost          int
    probes        int
    now           int64
    autoRetx      bool
}

// NewManager builds a correct, multi-space recovery manager.
func NewManager(cfg Config) *Manager {
    if cfg.CC == nil {
        cfg.CC = NewNewReno(cfg.MaxDatagramSize)
    }
    m := &Manager{cfg: cfg, autoRetx: cfg.AutoRetransmit}
    for i := 0; i < NumSpaces; i++ {
        ss := newSpaceState(Space(i))
        m.spaces[i] = ss
        m.states = append(m.states, ss)
    }
    return m
}

// NewNaive builds the buggy single-packet-number-space implementation used by
// the regression test. All three logical spaces map onto one shared state, so
// an ACK in one space advances the largest-acked of every space and the
// per-space loss/PTO timers are conflated.
func NewNaive(cfg Config) *Manager {
    if cfg.CC == nil {
        cfg.CC = NewNewReno(cfg.MaxDatagramSize)
    }
    m := &Manager{cfg: cfg, merged: true, autoRetx: cfg.AutoRetransmit}
    ss := newSpaceState(Application)
    m.states = []*spaceState{ss}
    for i := 0; i < NumSpaces; i++ {
        m.spaces[i] = ss
    }
    return m
}

func (m *Manager) stateFor(space Space) *spaceState {
    if m.merged {
        return m.states[0]
    }
    if int(space) < 0 || int(space) >= NumSpaces {
        return m.states[Application]
    }
    return m.spaces[space]
}

// Now returns the current simulated time.
func (m *Manager) Now() int64 { return m.now }

// SendPacket allocates a packet number in the requested space and records it.
func (m *Manager) SendPacket(space Space, ackEliciting bool, size int) uint64 {
    ss := m.stateFor(space)
    if size <= 0 {
        size = m.cfg.MaxDatagramSize
    }
    n := ss.nextPacketNumber
    ss.nextPacketNumber++
    if !ackEliciting {
        // ACK-only packets are not in flight, are not retransmitted, and MUST
        // NOT arm a PTO.
        return n
    }
    p := &sentPacket{
        number:       n,
        space:        space,
        timeSent:     m.now,
        ackEliciting: true,
        inFlight:     true,
        size:         size,
    }
    ss.sent[n] = p
    ss.ackElicitingInFlight++
    ss.lastAckElicitingSent = m.now
    m.bytesInFlight += size
    if m.cfg.CC != nil {
        m.cfg.CC.OnPacketSent(m.now, m.now, size)
    }
    // Arm the PTO only when this is the first ack-eliciting packet in flight
    // for the space. If ack-eliciting packets are already in flight, the PTO
    // deadline MUST NOT be reset (RFC 9002 6.2.1).
    if ss.ackElicitingInFlight == 1 {
        ss.ptoTime = m.now + m.ptoDuration(ss)
        ss.hasPTO = true
    }
    m.setLossTime(ss)
    return n
}

// ptoDuration is srtt + max(4*rttvar, granularity) [+ max_ack_delay].
func (m *Manager) ptoDuration(ss *spaceState) int64 {
    var d int64
    if m.rtt.hasSample {
        d = m.rtt.smoothed + max64(4*m.rtt.variance, m.cfg.TimerGranularity)
    } else {
        // srtt = initial_rtt, rttvar = initial_rtt/2.
        d = 3 * m.cfg.InitialRTT
    }
    if ss.space == Application {
        d += m.cfg.MaxAckDelay
    }
    return d
}

func (m *Manager) lossDelay() int64 {
    var base int64
    if m.rtt.hasSample {
        base = m.rtt.smoothed
        if m.rtt.latest > base {
            base = m.rtt.latest
        }
    } else {
        base = m.cfg.InitialRTT
    }
    return base + base/8 // 9/8 * max(srtt, latest_rtt)
}

func (m *Manager) setLossTime(ss *spaceState) {
    // Loss detection is only meaningful once a packet has been acknowledged;
    // time-threshold loss in RFC 9002 is applied only to packets at or below
    // largest_acked. Without an ACK the PTO is the recovery mechanism.
    if !ss.hasLargestAcked {
        ss.hasLossTime = false
        return
    }
    var oldest int64
    found := false
    for _, p := range ss.sent {
        if !p.inFlight {
            continue
        }
        if p.number > ss.largestAcked {
            continue
        }
        if !found || p.timeSent < oldest {
            oldest = p.timeSent
            found = true
        }
    }
    if !found {
        ss.hasLossTime = false
        return
    }
    ss.lossTime = oldest + m.lossDelay()
    ss.hasLossTime = true
}

// OnACK processes an inbound ACK frame for one packet number space.
func (m *Manager) OnACK(space Space, frame AckFrame, now int64) {
    m.now = now
    ss := m.stateFor(space)
    if len(frame.Ranges) == 0 && !frame.ECN {
        return
    }
    if frame.LargestAcked > ss.largestAcked || !ss.hasLargestAcked {
        ss.largestAcked = frame.LargestAcked
        ss.hasLargestAcked = true
    }

    acked := frame.SetFromAck()
    var newly []*sentPacket
    for n, p := range ss.sent {
        if acked.Contains(n) {
            newly = append(newly, p)
        }
    }
    sort.Slice(newly, func(i, j int) bool { return newly[i].number < newly[j].number })

    var largestNewly *sentPacket
    for _, p := range newly {
        if largestNewly == nil || p.number > largestNewly.number {
            largestNewly = p
        }
    }

    var rtt int64
    if largestNewly != nil && largestNewly.ackEliciting {
        rtt = now - largestNewly.timeSent
        if space == Application {
            delay := int64(frame.AckDelay)
            if delay > m.cfg.MaxAckDelay {
                delay = m.cfg.MaxAckDelay
            }
            rtt -= delay
        }
        if rtt < 1 {
            rtt = 1
        }
        m.rtt.update(rtt)
    }

    newlyAckEliciting := false
    for _, p := range newly {
        delete(ss.sent, p.number)
        crtt := int64(0)
        if p == largestNewly {
            crtt = rtt
        }
        if p.inFlight {
            m.bytesInFlight -= p.size
            if m.cfg.CC != nil {
                m.cfg.CC.OnPacketAcked(now, p.timeSent, p.size, crtt)
            }
        }
        if p.ackEliciting {
            ss.ackElicitingInFlight--
            newlyAckEliciting = true
        }
    }

    if frame.ECN {
        if frame.ECT0 > ss.ecnECT0 {
            ss.ecnECT0 = frame.ECT0
        }
        if frame.ECT1 > ss.ecnECT1 {
            ss.ecnECT1 = frame.ECT1
        }
        if frame.ECNCE > ss.ecnCE {
            ss.ecnCE = frame.ECNCE
            if m.cfg.CC != nil {
                m.cfg.CC.OnECNCongestion(now, m.rtt.smoothed)
            }
        }
    }

    if newlyAckEliciting {
        ss.ptoCount = 0
        if ss.ackElicitingInFlight == 0 {
            ss.hasPTO = false
        } else {
            // Re-anchor to time_of_last_ack_eliciting_packet (RFC 9002 6.2.1).
            ss.ptoTime = ss.lastAckElicitingSent + m.ptoDuration(ss)
            ss.hasPTO = true
        }
    }

    m.detectLost(ss, now)
    m.setLossTime(ss)
}

func (m *Manager) detectLost(ss *spaceState, now int64) {
    if !ss.hasLargestAcked {
        return
    }
    lossDelay := m.lossDelay()
    var lost []*sentPacket
    for _, p := range ss.sent {
        if !p.inFlight {
            continue
        }
        if p.number > ss.largestAcked {
            continue
        }
        if p.timeSent+lossDelay <= now {
            lost = append(lost, p)
        } else if p.number+m.cfg.PacketThreshold <= ss.largestAcked {
            lost = append(lost, p)
        }
    }
    if len(lost) == 0 {
        return
    }
    sort.Slice(lost, func(i, j int) bool { return lost[i].number < lost[j].number })
    for _, p := range lost {
        delete(ss.sent, p.number)
        m.bytesInFlight -= p.size
        ss.ackElicitingInFlight--
        m.lost++
        if m.cfg.CC != nil {
            m.cfg.CC.OnPacketLost(now, p.timeSent, p.size)
        }
        if m.autoRetx {
            m.SendPacket(p.space, true, p.size)
        }
    }
}

func (m *Manager) onPTO(ss *spaceState, now int64) {
    if ss.ackElicitingInFlight == 0 {
        ss.hasPTO = false
        return
    }
    ss.ptoCount++
    // RFC 9002 recommends two probes in Initial/Handshake, one elsewhere.
    count := 1
    if ss.space != Application {
        count = 2
    }
    for i := 0; i < count; i++ {
        m.probes++
        m.SendPacket(ss.space, true, m.cfg.MaxDatagramSize)
    }
    d := m.ptoDuration(ss)
    for i := 0; i < ss.ptoCount; i++ {
        if d > 1<<62 {
            d = 1 << 62
            break
        }
        d *= 2
    }
    ss.ptoTime = now + d
    ss.hasPTO = true
}

func (m *Manager) nextTimeout() (int64, bool) {
    var t int64
    found := false
    for _, ss := range m.states {
        if ss.hasPTO && ss.ackElicitingInFlight > 0 {
            if !found || ss.ptoTime < t {
                t, found = ss.ptoTime, true
            }
        }
        if ss.hasLossTime {
            if !found || ss.lossTime < t {
                t, found = ss.lossTime, true
            }
        }
    }
    return t, found
}

func (m *Manager) fire(t int64) {
    m.now = t
    // Loss detection first: it may resolve packets before probes are needed.
    for _, ss := range m.states {
        if ss.hasLossTime && ss.lossTime <= t {
            ss.hasLossTime = false
            m.detectLost(ss, t)
            m.setLossTime(ss)
        }
    }
    for _, ss := range m.states {
        if !ss.hasPTO {
            continue
        }
        if ss.ackElicitingInFlight == 0 {
            ss.hasPTO = false
            continue
        }
        if ss.ptoTime <= t {
            m.onPTO(ss, t)
        }
    }
}

// AdvanceTo fires every loss/PTO timer due at or before now.
func (m *Manager) AdvanceTo(now int64) {
    for {
        t, ok := m.nextTimeout()
        if !ok || t > now {
            break
        }
        m.fire(t)
    }
    m.now = now
}

// LargestAcked returns the largest acknowledged packet number for the space.

package recovery

// CongestionController is the pluggable congestion-control interface. The
// Manager owns bytes-in-flight accounting and calls into the controller as
// packets are sent, acknowledged, declared lost, or ECN-CE marked.
type CongestionController interface {
    // OnPacketSent is called when a congestion-controlled packet is sent.
    OnPacketSent(now, sentTime int64, bytes int)
    // OnPacketAcked is called when a previously sent packet is acknowledged.
    OnPacketAcked(now, sentTime int64, bytes int, rtt int64)
    // OnPacketLost is called when a packet is declared lost.
    OnPacketLost(now, sentTime int64, bytes int)
    // OnPacketsDiscarded is called when packets leave flight without being
    // acknowledged (e.g. the connection is closing).
    OnPacketsDiscarded(bytes int)
    // OnECNCongestion is called when the peer reports newly received ECN-CE
    // marked packets. Multiple CE marks inside one RTT count once.
    OnECNCongestion(now, rtt int64)
    // CanSend reports whether another packet of size bytes fits in the window.
    CanSend(bytesInFlight, bytes int) bool
    // Window returns the current congestion window in bytes.
    Window() int
    // Name identifies the controller.
    Name() string
}

func maxInt(a, b int) int {
    if a > b {
        return a
    }
    return b
}

func minInt(a, b int) int {
    if a < b {
        return a
    }
    return b
}

// NewReno is an RFC 9002 NewReno congestion controller.
type NewReno struct {
    mss           int
    cwnd          int
    ssthresh      int
    recoveryStart int64
    inRecovery    bool
    rtt           int64
    // ECN reaction pacing: do not react to CE marks more than once per RTT.
    lastECN int64
}

// NewNewReno returns a NewReno controller with the RFC 9002 initial window.
func NewNewReno(mss int) *NewReno {
    if mss <= 0 {
        mss = 1200
    }
    init := minInt(10*mss, maxInt(2*mss, 14720))
    return &NewReno{
        mss:      mss,
        cwnd:     init,
        ssthresh: 1 << 30,
    }
}

func (c *NewReno) Name() string { return "newreno" }

func (c *NewReno) OnPacketSent(now, sentTime int64, bytes int) {}

func (c *NewReno) OnPacketAcked(now, sentTime int64, bytes int, rtt int64) {
    if rtt > 0 {
        c.rtt = rtt
    }
    if c.inRecovery && sentTime > c.recoveryStart {
        c.inRecovery = false
    }
    if c.inRecovery {
        // Packets sent before recovery began do not grow the window.
        return
    }
    if c.cwnd < c.ssthresh {
        c.cwnd += bytes
    } else {
        // Congestion avoidance: one MSS per RTT.
        c.cwnd += maxInt(1, c.mss*bytes/c.cwnd)
    }
}

func (c *NewReno) OnPacketLost(now, sentTime int64, bytes int) {
    if c.inRecovery {
        return
    }
    c.cwnd = maxInt(c.cwnd/2, 2*c.mss)
    c.ssthresh = c.cwnd
    c.inRecovery = true
    c.recoveryStart = now
}

func (c *NewReno) OnPacketsDiscarded(bytes int) {}

func (c *NewReno) OnECNCongestion(now, rtt int64) {
    if c.inRecovery {
        return
    }
    // RFC 9002 7.2.1: react to at most one CE event per RTT.
    if c.lastECN != 0 && now-c.lastECN < max64(rtt, 1) {
        return
    }
    c.lastECN = now
    c.cwnd = maxInt(c.cwnd/2, 2*c.mss)
    c.ssthresh = c.cwnd
    c.inRecovery = true
    c.recoveryStart = now
}

func (c *NewReno) CanSend(bytesInFlight, bytes int) bool {
    return bytesInFlight+bytes <= c.cwnd
}

func (c *NewReno) Window() int { return c.cwnd }

// DeliveryRate is a BBR-style controller that tracks the maximum recent
// delivery rate and the minimum RTT, and sizes the window from their product.
// It does not halve on loss the way NewReno does; loss and ECN-CE instead cut
// the bandwidth estimate.
type DeliveryRate struct {
    mss           int
    // windowed max bandwidth (bytes per microsecond) and min RTT (us).
    maxBw         float64
    minRTT        int64
    cwnd          int
    startup       bool
    lastAckTime   int64
    lastAckSize   int
    roundStart    int64
    lastECN       int64
    lossReduction float64
    ecnReduction  float64
}

// NewDeliveryRate returns a delivery-rate controller.
func NewDeliveryRate(mss int) *DeliveryRate {
    if mss <= 0 {
        mss = 1200
    }
    return &DeliveryRate{
        mss:           mss,
        minRTT:        1 << 62,
        startup:       true,
        lossReduction: 0.7,
        ecnReduction:  0.7,
        cwnd:          10 * mss,
    }
}

func (c *DeliveryRate) Name() string { return "delivery-rate" }

func (c *DeliveryRate) OnPacketSent(now, sentTime int64, bytes int) {
    if c.roundStart == 0 {
        c.roundStart = now
    }
}

func (c *DeliveryRate) OnPacketAcked(now, sentTime int64, bytes int, rtt int64) {
    if rtt > 0 && rtt < c.minRTT {
        c.minRTT = rtt
    }
    if c.lastAckTime != 0 {
        dt := now - c.lastAckTime
        if dt > 0 {
            bw := float64(bytes) / float64(dt)
            if bw > c.maxBw {
                c.maxBw = bw
            }
        }
    }
    c.lastAckTime = now
    // Startup leaves BBR when the bandwidth has stopped growing for a round;
    // simplified: leave startup after a fixed number of samples.
    if c.startup && now-c.roundStart > 4*max64(c.minRTT, 1) {
        c.startup = false
    }
    c.recompute()
}

func (c *DeliveryRate) OnPacketLost(now, sentTime int64, bytes int) {
    c.maxBw *= c.lossReduction
    c.recompute()
}

func (c *DeliveryRate) OnPacketsDiscarded(bytes int) {}

func (c *DeliveryRate) OnECNCongestion(now, rtt int64) {
    if c.lastECN != 0 && now-c.lastECN < max64(rtt, 1) {
        return
    }
    c.lastECN = now
    c.maxBw *= c.ecnReduction
    c.recompute()
}

func (c *DeliveryRate) recompute() {
    if c.minRTT == 1<<62 || c.maxBw <= 0 {
        return
    }
    gain := 1.25
    if c.startup {
        gain = 2.885
    }
    target := int(gain * c.maxBw * float64(c.minRTT))
    c.cwnd = maxInt(2*c.mss, target)
}

func (c *DeliveryRate) CanSend(bytesInFlight, bytes int) bool {
    return bytesInFlight+bytes <= c.cwnd
}

func (c *DeliveryRate) Window() int { return c.cwnd }

func max64(a, b int64) int64 {
    if a > b {
        return a
    }
    return b
}

package recovery

import "fmt"

// EventKind enumerates deterministic trace events.
type EventKind int

const (
    // Send is an application-originated packet.
    Send EventKind = iota
    // Ack is an inbound ACK frame.
    Ack
    // Tick advances the clock and fires due timers.
    Tick
)

// Event is one entry in a deterministic recovery trace.
type Event struct {
    Kind         EventKind
    Time         int64 // microseconds
    Space        Space
    Name         string // Send: symbolic name used by later Ack events
    AckEliciting bool   // Send: whether the packet is ack-eliciting
    Size         int    // Send: packet size in bytes

    AckNames []string // Ack: symbolic names of sent packets to acknowledge
    AckDelay uint64   // Ack: ACK delay in microseconds
    ECT0     uint64   // Ack: cumulative ECT(0) count
    ECT1     uint64   // Ack: cumulative ECT(1) count
    ECNCE    uint64   // Ack: cumulative ECN-CE count
}

// Trace is a named deterministic event sequence with shipped expectations.
type Trace struct {
    Name           string
    ExpectedLost   int
    ExpectedProbes int
    Events         []Event
}

// Result is the outcome of running a trace.
type Result struct {
    Lost               int
    Probes             int
    Violations         []string
    LargestAcked       [NumSpaces]uint64
    HasLargestAcked    [NumSpaces]bool
    FinalWindow        int
    FinalBytesInFlight int
}

func (r Result) OK() bool { return len(r.Violations) == 0 }

// RunTrace drives e through tr, checking the space-isolation and PTO invariants
// after every event.
func RunTrace(tr Trace, e Engine) Result {
    var res Result
    sent := map[string]uint64{}
    maxAck := [NumSpaces]uint64{}
    hasMaxAck := [NumSpaces]bool{}

    violate := func(format string, args ...any) {
        res.Violations = append(res.Violations, fmt.Sprintf(format, args...))
    }

    check := func() {
        for s := 0; s < NumSpaces; s++ {
            space := Space(s)
            la, ok := e.LargestAcked(space)
            if ok {
                if !hasMaxAck[s] {
                    violate("space %s largest-acked is %d but no ACK ever arrived for that space", space, la)
                } else if la > maxAck[s] {
                    violate("space %s largest-acked %d advanced past ACKed maximum %d", space, la, maxAck[s])
                }
            }
            if _, armed := e.PTOTime(space); armed && e.AckElicitingInFlight(space) == 0 {
                violate("PTO armed for space %s with no ack-eliciting packet in flight", space)
            }
        }
    }

    for i, ev := range tr.Events {
        e.AdvanceTo(ev.Time)
        switch ev.Kind {
        case Send:
            beforePTO := [NumSpaces]struct {
                t     int64
                armed bool
            }{}
            beforeAEIF := [NumSpaces]int{}
            for s := 0; s < NumSpaces; s++ {
                t, armed := e.PTOTime(Space(s))
                beforePTO[s] = struct {
                    t     int64
                    armed bool
                }{t, armed}
                beforeAEIF[s] = e.AckElicitingInFlight(Space(s))
            }
            n := e.SendPacket(ev.Space, ev.AckEliciting, ev.Size)
            if ev.Name != "" {
                if _, dup := sent[ev.Name]; dup {
                    violate("duplicate send name %q", ev.Name)
                }
                sent[ev.Name] = n
            }
            if ev.AckEliciting {
                if beforeAEIF[ev.Space] > 0 && beforePTO[ev.Space].armed {
                    t, armed := e.PTOTime(ev.Space)
                    if !armed || t != beforePTO[ev.Space].t {
                        violate("event %d: PTO reset while ack-eliciting packets were already in flight in %s", i, ev.Space)
                    }
                }
            } else {
                if !beforePTO[ev.Space].armed {
                    if _, armed := e.PTOTime(ev.Space); armed {
                        violate("event %d: ACK-only send armed a PTO in %s", i, ev.Space)
                    }
                }
            }
        case Ack:
            rs := &RangeSet{}
            for _, name := range ev.AckNames {
                n, ok := sent[name]
                if !ok {
                    violate("event %d: ack references unknown send %q", i, name)
                    continue
                }
                rs.Add(n)
            }
            frame, ok := NewAckFrame(rs, ev.AckDelay)
            if !ok {
                violate("event %d: empty ACK frame", i)
                break
            }
            frame.ECN = ev.ECT0 > 0 || ev.ECT1 > 0 || ev.ECNCE > 0
            frame.ECT0, frame.ECT1, frame.ECNCE = ev.ECT0, ev.ECT1, ev.ECNCE
            e.OnACK(ev.Space, frame, ev.Time)
            s := int(ev.Space)
            if !hasMaxAck[s] || frame.LargestAcked > maxAck[s] {
                maxAck[s] = frame.LargestAcked
                hasMaxAck[s] = true
            }
        case Tick:
            // AdvanceTo above already handled it.
        }
        check()
    }
    res.Lost = e.Lost()
    res.Probes = e.Probes()
    for s := 0; s < NumSpaces; s++ {
        res.LargestAcked[s], res.HasLargestAcked[s] = e.LargestAcked(Space(s))
    }
    res.FinalWindow = e.Window()
    res.FinalBytesInFlight = e.BytesInFlight()
    return res
}

// TestTraceExpectations verifies that the correct multi-space engine reproduces

func TestTraceExpectations(t *testing.T) {
    for _, tr := range allTraces() {
        t.Run(tr.Name, func(t *testing.T) {
            if tr.ExpectedLost < 0 || tr.ExpectedProbes < 0 {
                t.Fatalf("trace %s has uncalibrated expectations", tr.Name)
            }
            r := RunTrace(tr, NewManager(DefaultConfig()))
            if !r.OK() {
                t.Fatalf("invariant violations: %v", r.Violations)
            }
            if r.Lost != tr.ExpectedLost {
                t.Fatalf("lost=%d want %d", r.Lost, tr.ExpectedLost)
            }
            if r.Probes != tr.ExpectedProbes {
                t.Fatalf("probes=%d want %d", r.Probes, tr.ExpectedProbes)
            }
        })
    }
}

// TestNaiveSingleSpaceFails is the regression: a naive implementation that
// merges all packet number spaces must fail the shipped traces, while the
// correct engine passes.
func TestNaiveSingleSpaceFails(t *testing.T) {
    for _, tr := range allTraces() {
        t.Run(tr.Name, func(t *testing.T) {
            good := RunTrace(tr, NewManager(DefaultConfig()))
            if !good.OK() {

            bad := RunTrace(tr, NewNaive(DefaultConfig()))

// TestCrossSpaceACKDoesNotAdvanceOtherSpace is the focused acceptance check:
// an ACK in one space must never move another space's largest-acked.
func TestCrossSpaceACKDoesNotAdvanceOtherSpace(t *testing.T) {
    m := NewManager(DefaultConfig())
    tr := traceCrossSpace()
    for _, ev := range tr.Events {
        m.AdvanceTo(ev.Time)
        switch ev.Kind {
        case Send:
            m.SendPacket(ev.Space, ev.AckEliciting, ev.Size)
        case Ack:
            if ev.Space == Handshake {
                // Check isolation before the Handshake ACK that legitimately
                // advances Handshake largest-acked.
                if _, ok := m.LargestAcked(Handshake); ok {
                    t.Fatal("Handshake largest-acked advanced before any Handshake ACK arrived")
                }
                return
            }
            rs := &RangeSet{}
            // Packet numbers are independent per space, so the i-th name is
            // packet number i in that space.
            for i := range ev.AckNames {
                rs.Add(uint64(i))
            }
            f, _ := NewAckFrame(rs, 0)
            m.OnACK(ev.Space, f, ev.Time)
        }
    }
    t.Fatal("trace never delivered a Handshake ACK")
}
