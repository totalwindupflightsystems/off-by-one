FM-index over a 200 MB byte string: half-open SA intervals, sampled-SA locate(), and sentinel-boundary correctness

Deliverables (self-contained): - fmindex.py — corrected index (build, backward_search, count, locate, sampled SA, bidirectional wrapper) - test_fmindex.py — brute-force verification suite - Run: python3 -m pytest test_fmindex.py -q

1. Root-cause analysis

RC1 — Empty pattern must be [0, N), not empty

Backward search is

lo, hi = 0, N
for c in reversed(pattern):
    lo = C[c] + Occ(c, lo)
    hi = C[c] + Occ(c, hi)

Bugs come from initialising [0,0) / [0,n) instead of [0,N), short-circuiting if not pattern: return (0,0), or mixing closed [lo,hi] with hi-lo. With [lo,hi) and initial [0,N), the empty pattern runs zero iterations and returns the full range [0,N); hi-lo == N, never 0.

RC2 — Off-by-one at the sentinel boundary

A raw-T FM-index has no unique smallest character, so SA[0] is arbitrary, S[SA[i]-1] underflows for SA[i]==0 (Python hides it by returning T[-1]), and the suffix ending at n-1 can locate at n.

Fix: index S = T + sentinel; byte b -> b+1 (1..256), sentinel 0, N=n+1. Then SA[0]=n, BWT[i]=S[(SA[i]-1) mod N] is a true permutation, a text pattern never matches the sentinel, and a suffix ending at n-1 locates at exactly n-k.

RC3 — locate() wraparound

LF obeys SA[LF(i)] = (SA[i]-1) mod N. At SA[i]==0, LF jumps to the sentinel row with value N-1 (i.e. -1 mod N). Storing SA[sample]+steps without the modulo overflows past N-1. Sampling row i iff SA[i] % period == sample_offset (default period=32, offset 0) guarantees the walk reaches a sample in ≤ period-1 steps, and

position = (SA[sampled_row] + steps) mod N

With offset 0, value 0 is sampled so no wrap is normally needed; the modulo keeps it general (tested with offset 1, which forces a genuine 0 -> N-1 wrap).

RC4 — Bidirectional pairing

A bidirectional FM-index is the pair (FM(T), FM(reverse(T))) sharing one half-open convention: left-extension is a backward step on the forward index, right-extension a backward step on the reverse index after reversing the pattern.

fmindex.py (full, verified):

"""
fmindex.py -- A correct FM-index with half-open suffix-array intervals and a
sampled suffix array (period 32 by default) for locate().
"""

from __future__ import annotations

from typing import List, Tuple

import numpy as np

SENTINEL = 0          # virtual sentinel; real bytes are shifted to 1..256
ALPHABET_SIZE = 257


def _numpy_suffix_array(s: np.ndarray) -> np.ndarray:
    """Prefix-doubling suffix array for an integer sequence with unique 0."""
    N = int(s.shape[0])
    if N == 0:
        return np.empty(0, dtype=np.int64)
    if N == 1:
        return np.zeros(1, dtype=np.int64)

    rank = s.astype(np.int64).copy()
    k = 1
    order = np.arange(N, dtype=np.int64)

    while True:
        r2 = np.full(N, -1, dtype=np.int64)
        idx = np.arange(N, dtype=np.int64) + k
        in_range = idx < N
        r2[in_range] = rank[idx[in_range]]
        order = np.lexsort((r2, rank))          # primary rank, secondary r2

        a = rank[order]
        b = r2[order]
        changed = np.empty(N, dtype=np.int64)
        changed[0] = 0
        changed[1:] = (a[1:] != a[:-1]) | (b[1:] != b[:-1])
        new_rank = np.empty(N, dtype=np.int64)
        new_rank[order] = np.cumsum(changed)
        rank = new_rank
        if int(rank[order[-1]]) == N - 1:
            break
        k <<= 1
    return order.astype(np.int64)


def build_suffix_array(text: bytes, prefer_external: bool = True) -> np.ndarray:
    """SA of T + sentinel.  For a real 200 MB text use a linear-time builder
    (pydivsufsort / libdivsufsort); the NumPy doubling is for tests."""
    n = len(text)
    augmented = np.empty(n + 1, dtype=np.int64)
    if n:
        augmented[:n] = np.frombuffer(text, dtype=np.uint8).astype(np.int64) + 1
    augmented[n] = SENTINEL

    if prefer_external:
        try:  # pragma: no cover
            import pydivsufsort  # type: ignore
            sa_text = np.asarray(pydivsufsort.divsufsort(bytes(text)), dtype=np.int64)
            sa = np.empty(n + 1, dtype=np.int64)
            sa[0] = n              # sentinel suffix ranks first
            sa[1:] = sa_text       # relative order of T suffixes is preserved
            return sa
        except Exception:
            pass
    return _numpy_suffix_array(augmented)


class _Rank:
    """Occ(c, i) = #occurrences of c in bwt[0:i) using block checkpoints."""

    def __init__(self, bwt: np.ndarray, block: int = 512):
        self.bwt = bwt
        self.block = block
        N = int(bwt.shape[0])
        self.nblocks = N // block + 1
        tab = np.zeros((self.nblocks, ALPHABET_SIZE), dtype=np.int32)
        run = np.zeros(ALPHABET_SIZE, dtype=np.int64)
        for b in range(1, self.nblocks):
            start = (b - 1) * block
            run = run + np.bincount(bwt[start:min(start + block, N)],
                                    minlength=ALPHABET_SIZE)
            tab[b] = run
        self.tab = tab

    def occ(self, c: int, i: int) -> int:
        if i <= 0:
            return 0
        b = i // self.block
        start = b * self.block
        base = int(self.tab[b, c])
        if start >= i:
            return base
        return base + int(np.count_nonzero(self.bwt[start:i] == c))


class FMIndex:
    def __init__(self, text: bytes, period: int = 32, sample_offset: int = 0,
                 prefer_external: bool = True):
        if period <= 0:
            raise ValueError("period must be positive")
        if not (0 <= sample_offset < period):
            raise ValueError("sample_offset must satisfy 0 <= offset < period")

        self.text = text
        self.n = len(text)
        self.N = self.n + 1
        self.period = period
        self.sample_offset = sample_offset

        self.sa = build_suffix_array(text, prefer_external=prefer_external)
        if self.N < 2**31:
            self.sa = self.sa.astype(np.int32)

        # BWT[i] = S[(SA[i]-1) mod N]; S[-1] is the sentinel.
        shifted = np.empty(self.N, dtype=np.int16)
        if self.n:
            shifted[:self.n] = np.frombuffer(text, dtype=np.uint8).astype(np.int16) + 1
        shifted[self.n] = SENTINEL
        prev = (self.sa.astype(np.int64) - 1) % self.N
        self.bwt = shifted[prev]
        del shifted, prev

        self.rank = _Rank(self.bwt)
        counts = np.bincount(self.bwt, minlength=ALPHABET_SIZE)
        self.C = np.zeros(ALPHABET_SIZE, dtype=np.int64)
        self.C[1:] = np.cumsum(counts[:-1])           # chars strictly smaller

        self.sampled = (self.sa % period == sample_offset)
        self._locate_cache: dict[int, int] = {}

    def lf(self, i: int) -> int:
        c = int(self.bwt[i])
        return int(self.C[c] + self.rank.occ(c, i))

    def backward_search(self, pattern: bytes) -> Tuple[int, int]:
        """Half-open SA interval [lo, hi).  Empty pattern -> [0, N)."""
        lo, hi = 0, self.N
        for byte in reversed(pattern):
            c = int(byte) + 1
            lo = int(self.C[c] + self.rank.occ(c, lo))
            hi = int(self.C[c] + self.rank.occ(c, hi))
            if lo >= hi:
                return lo, hi
        return lo, hi

    def count(self, pattern: bytes) -> int:
        lo, hi = self.backward_search(pattern)
        return hi - lo

    def _locate_row(self, row: int) -> int:
        cached = self._locate_cache.get(row)
        if cached is not None:
            return cached
        steps = 0
        j = row
        while not self.sampled[j]:
            j = self.lf(j)
            steps += 1
            if steps > self.N:                        # LF is a permutation
                raise RuntimeError("LF walk did not reach a sampled row")
        value = (int(self.sa[j]) + steps) % self.N     # sentinel wraparound
        self._locate_cache[row] = value
        return value

    def locate(self, lo: int, hi: int) -> List[int]:
        if not (0 <= lo <= hi <= self.N):
            raise ValueError("invalid interval")
        return [self._locate_row(r) for r in range(lo, hi)]

    def locate_pattern(self, pattern: bytes, drop_sentinel: bool = True) -> List[int]:
        lo, hi = self.backward_search(pattern)
        pos = self.locate(lo, hi)
        if drop_sentinel:
            pos = [p for p in pos if p != self.n]
        return sorted(pos)

    def bwt_char(self, i: int) -> int:
        return int(self.bwt[i])

    def sa_value(self, i: int) -> int:
        return int(self.sa[i])


class BidirectionalFMIndex:
    """Pair (FM(T), FM(reverse(T))) sharing the half-open convention."""

    def __init__(self, text: bytes, period: int = 32, sample_offset: int = 0):
        self.text = text
        self.forward = FMIndex(text, period=period, sample_offset=sample_offset)
        self.reverse = FMIndex(text[::-1], period=period, sample_offset=sample_offset)

    def backward_search(self, pattern: bytes) -> Tuple[int, int]:
        return self.forward.backward_search(pattern)

    def forward_search(self, pattern: bytes) -> Tuple[int, int]:
        return self.reverse.backward_search(pattern[::-1])

    def count(self, pattern: bytes) -> int:
        return self.forward.count(pattern)

    def locate_pattern(self, pattern: bytes, drop_sentinel: bool = True) -> List[int]:
        return self.forward.locate_pattern(pattern, drop_sentinel=drop_sentinel)

3. Requirement → implementation map

Requirement Where enforced
Half-open [lo, hi) backward_search, count = hi-lo, locate(lo,hi) iterates range(lo,hi)
Sampled SA, period 32 self.sampled = (self.sa % period == sample_offset), default 32
LF wraparound at sentinel (int(self.sa[j]) + steps) % self.N
Steps modulo sample period walk stops within period-1 steps (tested)
Empty pattern = full range initial [0, N), zero iterations → [0, N)
Suffix at sentinel boundary augmented S = T + sentinel, SA[0]=n (tested)

4.4 Suffix at the sentinel boundary (no off-by-one)

T="mississippi", n=11, last byte index 10:

suffix b'i'   -> [1,5) locate=[1,4,7,10]
suffix b'pi'  -> [6,7) locate=[9]
suffix b'ppi' -> [7,8) locate=[8]

The occurrence ending at n-1 = 10 is found at 10; the sentinel 11 is never returned. The whole text locates at 0.

4.5 Wraparound handled with % N

With period=32, sample_offset=1 value 0 is deliberately unsampled, forcing 0 -> N-1:

offset=1 forced-wrap 'si' -> [3, 6]     # matches brute force

For every row the test asserts steps < period and (SA[sampled]+steps) % N == SA[row].

5. One-line summary

Index an augmented text with a unique sentinel, keep intervals half-open and initialise to [0, N) so the empty pattern is the full range, and reconstruct sampled positions with (SA[sampled_row] + steps) % N; this lands the sentinel-boundary suffix exactly on n-1 and handles the 0 -> N-1 LF wraparound.
