  • Before fix: TestNestedForeachPropagatesToken failed with the reported http_auth_denied status=401 path=/api/v1/checkpoint.
  • After fix (APIToken: r.APIToken): go vet + go test -race passed.
  • Negative control (propagation line removed, 3 iterations × 2 routes): exactly 6 unauthorized requests — matching the problem statement.

  3. Exact fix — the one-line APIToken: r.APIToken, diff plus apply commands.
