ECDSA Nonce-Leak Recovery (Hidden Number Problem) in Node.js

Pure-BigInt, exact-arithmetic recovery of a secp256k1 private key from signatures whose nonces leak their top bits, using an in-process LLL reduction and rigorous candidate validation.

1. Symptom / problem statement

Given batches of ECDSA signatures (r_i, s_i) over secp256k1 for which the high bits of each nonce k_i are known, recover the signing key d:

  • no native crypto / lattice library may be used — only Node's BigInt;
  • the lattice must be built from the per-signature leak bounds;
  • LLL must use exact rational Gram–Schmidt coefficients (no float drift);
  • candidate keys must be extracted from the reduced rows and re-derived before being reported;
  • genuinely underdetermined batches must return insufficient-leakage instead of a wrong key.

A naive implementation exhibits some combination of:

  1. Float LLL drift — double Gram–Schmidt coefficients silently lose the Lovász decisions once the basis entries exceed ~2⁵³, producing a non-reduced basis and no key.
  2. Rational blow-up — storing mu/c as normalized fractions and running gcd on every operation makes a 15–20 dimensional lattice take tens of seconds.
  3. Bad lattice scaling — if the unknown-low-bit coordinate is not scaled against the key coordinate, the target vector is not short and LLL never returns it.
  4. Unvalidated candidates — on underdetermined input the lattice still contains short vectors whose "key" ratio is garbage; emitting it is wrong.
  5. No feasibility gate — a 256-bit secret cannot be pinned by < 256 known bits, so such input must be refused up front.

2. Root-cause analysis

2.1 The Hidden Number Problem

For each signature

s_i k_i ≡ z_i + r_i d   (mod n)

so

k_i ≡ t_i d + u_i   (mod n),   t_i = r_i s_i⁻¹,  u_i = z_i s_i⁻¹.

Knowing the top bits of k_i means k_i = a_i + b_i with a_i = h_i · 2^{l_i} (h_i = known high part) and 0 ≤ b_i < B_i = 2^{l_i}. Substituting and centring the unknown interval around zero:

b_i' ≡ t_i d + c_i   (mod n),
b_i' = b_i − B_i/2 ∈ [−B_i/2, B_i/2),
c_i  = (u_i − a_i − B_i/2)  mod n.

The b_i' are small, so the vector (b_i'/B_i, d/n, 1) is short.

2.2 The lattice

With L = n · 2^{l_max} (a common denominator that clears every fraction), the (m+2)×(m+2) integer basis is

row i   (i<m) :  n·L/B_i                      at column i
row m         :  t_0·L/B_0, …, t_{m-1}·L/B_{m-1},   L/n,  0
row m+1       :  c_0·L/B_0, …, c_{m-1}·L/B_{m-1},    0,   L

The integer combination d·row_m + row_{m+1} reduced modulo the first rows yields

L · [ b_0'/B_0, …, b_{m-1}'/B_{m-1}, d/n, 1 ],

whose first m coordinates lie in [−1/2, 1/2] and whose last coordinate is exactly 1. It is short iff enough high bits are known. The number of known bits is Σ(256 − l_i); when it exceeds 256 the target separates from the generic lattice vectors and LLL finds it.

2.3 Exact arithmetic

Fractions represented as BigInt numerator/denominator are exact but cost a gcd per operation and grow large. The standard remedy is the de Weger integer form of the same rational Gram–Schmidt: keep

λ_{i,j} = d_j · μ_{i,j},     d_j = det Gram(b_0 … b_{j-1})

so that μ_{i,j} = λ_{i,j} / d_{j+1}. All LLL decisions become integer comparisons and exact divisions — mathematically identical to rational Gram–Schmidt, with no rounding and no fraction growth. This is what the solver uses (lllInt); a slower fraction version (lllRational) is retained in the file for cross-checking.

2.4 Candidate extraction & why validation is mandatory

For any lattice vector, coordinate m equals a_m·(L/n) and coordinate m+1 equals a_{m+1}·L. For the target a_m = d, a_{m+1} = 1, hence

d = a_m / a_{m+1} = (coord_m · n / L) / (coord_{m+1} / L).

A wrong short vector can also have a small last coordinate, so every candidate is re-derived: recompute k_i = s_i⁻¹(z_i + r_i d) mod n, check the leaked high bits and that x(k_i·G) mod n == r_i. Only then is a key reported. If nothing validates, the batch is declared underdetermined.

2.5 Underdetermined detection

Two layers:

  1. Information gate — Σ(256 − l_i) < 256 cannot determine a 256-bit key, so return insufficient-leakage immediately.
  2. Validation gate — even at ≥ 256 known bits the lattice margin can be too small (e.g. many signatures each leaking only a few bits). If no candidate passes re-derivation, return insufficient-leakage. A wrong key is never emitted.

3. Exact fix

Complete self-contained module (hnp.js). Copy it verbatim and run with node hnp.js.

'use strict';
// ECDSA nonce-leak (Hidden Number Problem) lattice key recovery.
// Pure BigInt. Exact-rational LLL.

/* ------------------------------------------------------------------ *
 * Exact rational numbers (BigInt numerator / BigInt denominator > 0)
 * ------------------------------------------------------------------ */
function bigGcd(a, b) {
  if (a < 0n) a = -a;
  if (b < 0n) b = -b;
  while (b) { const t = a % b; a = b; b = t; }
  return a;
}

class Frac {
  constructor(n, d = 1n) {
    if (d === 0n) throw new Error('Frac: divide by zero');
    if (d < 0n) { n = -n; d = -d; }
    if (n === 0n) { this.n = 0n; this.d = 1n; return; }
    const g = bigGcd(n, d);
    this.n = n / g;
    this.d = d / g;
  }
  add(o) { return new Frac(this.n * o.d + o.n * this.d, this.d * o.d); }
  sub(o) { return new Frac(this.n * o.d - o.n * this.d, this.d * o.d); }
  mul(o) { return new Frac(this.n * o.n, this.d * o.d); }
  div(o) { return new Frac(this.n * o.d, this.d * o.n); }
  neg() { return new Frac(-this.n, this.d); }
  abs() { return this.n < 0n ? this.neg() : this; }
  isZero() { return this.n === 0n; }
  cmp(o) {
    const l = this.n * o.d, r = o.n * this.d;
    return l < r ? -1 : (l > r ? 1 : 0);
  }
}
const F0 = new Frac(0n);
const F1 = new Frac(1n);
const FHALF = new Frac(1n, 2n);

// floor(a/b) for b > 0
function floorDivBig(a, b) {
  let q = a / b;
  if (a % b !== 0n && a < 0n) q -= 1n;
  return q;
}
// nearest integer to fraction (ties -> away from zero to keep |mu|<=1/2 safe)
function roundFrac(f) {
  return floorDivBig(2n * f.n + f.d, 2n * f.d);
}

/* ------------------------------------------------------------------ *
 * LLL, exact rational Gram-Schmidt, incremental updates
 * ------------------------------------------------------------------ */
function computeGS(basis) {
  const n = basis.length;
  const dim = basis[0].length;
  const mu = Array.from({ length: n }, () => new Array(n).fill(F0));
  const c = new Array(n).fill(F0);
  const bstar = basis.map(v => v.map(x => new Frac(x)));
  for (let i = 0; i < n; i++) {
    for (let j = 0; j < i; j++) {
      if (c[j].isZero()) { mu[i][j] = F0; continue; }
      let dot = F0;
      const bi = basis[i];
      const bj = bstar[j];
      for (let t = 0; t < dim; t++) dot = dot.add(new Frac(bi[t]).mul(bj[t]));
      mu[i][j] = dot.div(c[j]);
      const m = mu[i][j];
      const row = bstar[i];
      for (let t = 0; t < dim; t++) row[t] = row[t].sub(m.mul(bj[t]));
    }
    let norm = F0;
    for (const x of bstar[i]) norm = norm.add(x.mul(x));
    c[i] = norm;
  }
  return { mu, c };
}

/* ------------------------------------------------------------------ *
 * Exact integer LLL (de Weger form of exact rational Gram-Schmidt).
 * Keeps lambda[i][j] and d[i] so that mu[i][j] = lambda[i][j]/d[j+1]
 * and d[i] = det Gram(b[0..i-1]).  All arithmetic is exact BigInt.
 * ------------------------------------------------------------------ */
function lllInt(b) {
  const n = b.length;
  const dim = b[0].length;
  const d = new Array(n + 1).fill(1n);
  const lam = Array.from({ length: n }, () => new Array(n).fill(0n));
  const dot = (u, v) => { let s = 0n; for (let t = 0; t < dim; t++) s += u[t] * v[t]; return s; };

  // full Gram-Schmidt (integer, fraction-free recurrences)
  for (let i = 0; i < n; i++) {
    for (let j = 0; j < i; j++) {
      let u = dot(b[i], b[j]);
      for (let l = 0; l < j; l++) u = (d[l + 1] * u - lam[i][l] * lam[j][l]) / d[l];
      lam[i][j] = u;
    }
    let V = dot(b[i], b[i]);
    for (let j = 0; j < i; j++) V = (d[j + 1] * V - lam[i][j] * lam[i][j]) / d[j];
    d[i + 1] = V;
  }

  let k = 1;
  while (k < n) {
    // size-reduce b[k] against b[k-1..0]
    for (let j = k - 1; j >= 0; j--) {
      const dj = d[j + 1];
      if (2n * (lam[k][j] < 0n ? -lam[k][j] : lam[k][j]) > dj) {
        const q = floorDivBig(2n * lam[k][j] + dj, 2n * dj);
        const bk = b[k], bj = b[j];
        for (let t = 0; t < dim; t++) bk[t] -= q * bj[t];
        lam[k][j] -= q * dj;
        for (let l = 0; l < j; l++) lam[k][l] -= q * lam[j][l];
      }
    }
    // Lovasz: 4*(d[k+1]*d[k-1] + lam^2) >= 3*d[k]^2
    const lk = lam[k][k - 1];
    if (4n * (d[k + 1] * d[k - 1] + lk * lk) >= 3n * d[k] * d[k]) {
      k += 1;
    } else {
      // swap b[k-1] and b[k]
      const tmp = b[k]; b[k] = b[k - 1]; b[k - 1] = tmp;
      const u = lam[k][k - 1];
      const nd = (d[k - 1] * d[k + 1] + u * u) / d[k];
      for (let i = k + 1; i < n; i++) {
        const t = lam[i][k];
        const newIK = (d[k + 1] * lam[i][k - 1] - u * t) / d[k];
        lam[i][k - 1] = (nd * t + u * newIK) / d[k + 1];
        lam[i][k] = newIK;
      }
      for (let j = 0; j < k - 1; j++) {
        const s = lam[k - 1][j]; lam[k - 1][j] = lam[k][j]; lam[k][j] = s;
      }
      lam[k][k - 1] = u;
      d[k] = nd;
      k = Math.max(1, k - 1);
    }
  }
  return b;
}

// Default solver uses the exact integer LLL.
function lll(basis) { return lllInt(basis); }

function lllRational(basis, delta = new Frac(3n, 4n)) {
  const n = basis.length;
  const dim = basis[0].length;
  const { mu, c } = computeGS(basis);
  let k = 1;
  let guard = 0;
  while (k < n) {
    if (++guard > 10000000) throw new Error('LLL: iteration guard tripped');
    // size-reduce b[k] against b[k-1..0]
    for (let j = k - 1; j >= 0; j--) {
      const m = mu[k][j];
      if (m.abs().cmp(FHALF) > 0) {
        const q = roundFrac(m);
        const qF = new Frac(q);
        const bk = basis[k], bj = basis[j];
        for (let t = 0; t < dim; t++) bk[t] -= q * bj[t];
        mu[k][j] = m.sub(qF);
        for (let i = 0; i < j; i++) mu[k][i] = mu[k][i].sub(qF.mul(mu[j][i]));
      }
    }
    // Lovasz condition
    const lhs = c[k];
    const mu2 = mu[k][k - 1].mul(mu[k][k - 1]);
    const rhs = delta.sub(mu2).mul(c[k - 1]);
    if (lhs.cmp(rhs) >= 0) {
      k += 1;
    } else {
      // swap b[k-1] and b[k]
      const tmp = basis[k]; basis[k] = basis[k - 1]; basis[k - 1] = tmp;
      const u = mu[k][k - 1];
      const oldCk = c[k], oldCk1 = c[k - 1];
      const B = oldCk.add(u.mul(u).mul(oldCk1));
      const newMu = u.mul(oldCk1).div(B);
      for (let i = k + 1; i < n; i++) {
        const t = mu[i][k];
        mu[i][k] = mu[i][k - 1].sub(u.mul(t));
        mu[i][k - 1] = t.add(newMu.mul(mu[i][k]));
      }
      for (let j = 0; j < k - 1; j++) {
        const s = mu[k - 1][j]; mu[k - 1][j] = mu[k][j]; mu[k][j] = s;
      }
      mu[k][k - 1] = newMu;
      c[k - 1] = B;
      c[k] = oldCk1.mul(oldCk).div(B);
      k = Math.max(1, k - 1);
    }
  }
  return basis;
}

/* ------------------------------------------------------------------ *
 * secp256k1 minimal arithmetic (pure BigInt)
 * ------------------------------------------------------------------ */
const P = 0xFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFEFFFFFC2Fn;
const N = 0xFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFEBAAEDCE6AF48A03BBFD25E8CD0364141n;
const Gx = 0x79BE667EF9DCBBAC55A06295CE870B07029BFCDB2DCE28D959F2815B16F81798n;
const Gy = 0x483ADA7726A3C4655DA4FBFC0E1108A8FD17B448A68554199C47D08FFB10D4B8n;

function mod(a, m = P) { const r = a % m; return r < 0n ? r + m : r; }
function modInv(a, m = P) {
  a = mod(a, m);
  if (a === 0n) throw new Error('inverse of 0');
  // extended euclid
  let [old_r, r] = [a, m];
  let [old_s, s] = [1n, 0n];
  while (r !== 0n) {
    const q = old_r / r;
    [old_r, r] = [r, old_r - q * r];
    [old_s, s] = [s, old_s - q * s];
  }
  return mod(old_s, m);
}
function isInf(p) { return p === null; }
function ptAdd(a, b) {
  if (isInf(a)) return b;
  if (isInf(b)) return a;
  const [x1, y1] = a, [x2, y2] = b;
  if (x1 === x2) {
    if (mod(y1 + y2) === 0n) return null;
    // double
    const l = mod((3n * x1 * x1) * modInv(2n * y1), P);
    const x3 = mod(l * l - 2n * x1);
    return [x3, mod(l * (x1 - x3) - y1)];
  }
  const l = mod((y2 - y1) * modInv(x2 - x1), P);
  const x3 = mod(l * l - x1 - x2);
  return [x3, mod(l * (x1 - x3) - y1)];
}
function ptMul(k, p) {
  let r = null, q = p;
  k = mod(k, N);
  while (k > 0n) {
    if (k & 1n) r = ptAdd(r, q);
    q = ptAdd(q, q);
    k >>= 1n;
  }
  return r;
}

/* ------------------------------------------------------------------ *
 * Test-data generation: ECDSA signatures with known MSBs of nonce
 * ------------------------------------------------------------------ */
function sha256ToZ(msg) {
  const { createHash } = require('crypto');
  const h = createHash('sha256').update(msg).digest('hex');
  return mod(BigInt('0x' + h), N);
}

function randomScalar() {
  const { randomBytes } = require('crypto');
  for (;;) {
    const b = randomBytes(32);
    let v = 0n; for (const x of b) v = (v << 8n) | BigInt(x);
    v = mod(v, N);
    if (v > 0n) return v;
  }
}

// leakBits: number of low bits of the nonce that stay UNKNOWN.
// The top (256-leakBits) bits are exposed as nonceHigh.
function makeSignature(d, z, leakBits) {
  if (leakBits < 0 || leakBits > 256) throw new Error('bad leakBits');
  const k = randomScalar();
  const R = ptMul(k, [Gx, Gy]);
  const r = mod(R[0], N);
  if (r === 0n) return makeSignature(d, z, leakBits);
  const s = mod(modInv(k, N) * mod(z + r * d, N), N);
  if (s === 0n) return makeSignature(d, z, leakBits);
  return { r, s, z, leakBits, nonceHigh: k >> BigInt(leakBits) };
}

/* ------------------------------------------------------------------ *
 * HNP lattice construction + recovery
 *
 * For each signature:  b_i = t_i*d + c_i  (mod n),  0 <= b_i < B_i
 * with t_i = r_i*s_i^-1, c_i = z_i*s_i^-1 - a_i, a_i = nonceHigh_i*B_i
 * and B_i = 2^leakBits_i.
 *
 * Basis (integer, cleared by L = n * lcm(B_i)):
 *   row i            : n*L/B_i at column i
 *   row m            : t_i*L/B_i ,  L/n at column m, 0
 *   row m+1          : c_i*L/B_i ,  0 , L
 * The lattice contains L*[b_i/B_i, d/n, 1].
 * ------------------------------------------------------------------ */
function buildLattice(sigs) {
  const m = sigs.length;
  if (m === 0) throw new Error('no signatures');
  const lmax = Math.max(...sigs.map(s => s.leakBits));
  const TWOlmax = 1n << BigInt(lmax);
  const L = N * TWOlmax; // common denominator

  const Bs = sigs.map(s => 1n << BigInt(s.leakBits));
  const ts = [], cs = [];
  for (let i = 0; i < m; i++) {
    const sig = sigs[i];
    const sinv = modInv(sig.s, N);
    const t = mod(sig.r * sinv, N);
    const a = sig.nonceHigh << BigInt(sig.leakBits);
    // center the unknown interval around 0 by subtracting B/2
    const c = mod(sig.z * sinv - a - (Bs[i] >> 1n), N);
    ts.push(t);
    cs.push(c);
  }
  const dim = m + 2;
  const basis = Array.from({ length: dim }, () => new Array(dim).fill(0n));
  for (let i = 0; i < m; i++) basis[i][i] = (N * L) / Bs[i];
  for (let i = 0; i < m; i++) {
    basis[m][i] = (ts[i] * L) / Bs[i];
    basis[m + 1][i] = (cs[i] * L) / Bs[i];
  }
  basis[m][m] = L / N;        // = TWOlmax
  basis[m + 1][m + 1] = L;    // = N*TWOlmax
  return { basis, L, TWOlmax, m };
}

// Validate candidate private key by re-deriving each nonce/signature.
function validateKey(d, sigs) {
  if (d <= 0n || d >= N) return false;
  for (const sig of sigs) {
    const k = mod(modInv(sig.s, N) * mod(sig.z + sig.r * d, N), N);
    if (k === 0n) return false;
    const B = 1n << BigInt(sig.leakBits);
    if ((k >> BigInt(sig.leakBits)) !== sig.nonceHigh) return false;
    const R = ptMul(k, [Gx, Gy]);
    if (R === null || mod(R[0], N) !== sig.r) return false;
  }
  return true;
}

function candidateFromPair(aM, aM1) {
  if (aM1 === 0n) return null;
  if (aM % aM1 !== 0n) return null;
  const d = ((aM / aM1) % N + N) % N;
  return d === 0n ? null : d;
}

function recoverPrivateKey(sigs) {
  if (!sigs || sigs.length === 0) return { status: 'insufficient-leakage', candidates: 0 };
  // Information-theoretic gate: fewer than 256 known bits cannot pin a 256-bit key.
  const totalKnown = sigs.reduce((a, s) => a + (256 - s.leakBits), 0);
  if (totalKnown < 256) return { status: 'insufficient-leakage', candidates: 0 };
  // A fully known nonce (leakBits==0) reveals the key directly from one signature.
  for (const sig of sigs) {
    if (sig.leakBits === 0) {
      const k = sig.nonceHigh;
      const d = mod((sig.s * k - sig.z) * modInv(sig.r, N), N);
      if (validateKey(d, sigs)) return { status: 'recovered', privateKey: d, candidates: 1 };
    }
  }

  const { basis, TWOlmax, m } = buildLattice(sigs);
  lll(basis);
  const NLmax = N * TWOlmax;
  const candidates = new Set();
  const tried = new Set();

  const consider = (aM, aM1) => {
    const d = candidateFromPair(aM, aM1);
    if (d === null || tried.has(d)) return null;
    tried.add(d);
    candidates.add(d);
    return validateKey(d, sigs) ? d : null;
  };

  // 1) single reduced basis rows
  for (const row of basis) {
    const hit = consider(row[m] / TWOlmax, row[m + 1] / NLmax);
    if (hit !== null) return { status: 'recovered', privateKey: hit, candidates: candidates.size };
  }

  // 2) small integer combinations of the shortest reduced rows
  const T = Math.min(basis.length, 7);
  const RANGE = 3;
  const coeffs = [];
  for (let c = -RANGE; c <= RANGE; c++) coeffs.push(BigInt(c));
  const Am = [], Am1 = [];
  for (let i = 0; i < T; i++) {
    Am.push(basis[i][m] / TWOlmax);
    Am1.push(basis[i][m + 1] / NLmax);
  }
  let found = null;
  const rec = (idx, aM, aM1) => {
    if (found !== null) return;
    if (idx === T) {
      const hit = consider(aM, aM1);
      if (hit !== null) found = hit;
      return;
    }
    for (const c of coeffs) rec(idx + 1, aM + c * Am[idx], aM1 + c * Am1[idx]);
  };
  rec(0, 0n, 0n);
  if (found !== null) return { status: 'recovered', privateKey: found, candidates: candidates.size };

  return { status: 'insufficient-leakage', candidates: candidates.size };
}

module.exports = { Frac, lll, buildLattice, recoverPrivateKey, validateKey, makeSignature, sha256ToZ, ptMul, N, P, Gx, Gy };

  run('no info', [256], 'insufficient');
}

4.2 What was tested

  • Recovery, uniform leaks: 4×60, 5×30, 6×50–100, 8×50, 12×200 unknown bits — all recovered the exact key.
  • Recovery, mixed leaks: e.g. [40,55,70,90,110,130] — per-signature bounds B_i = 2^{l_i} handled correctly.
  • Fully known nonce (leakBits = 0) — recovered directly.
  • Underdetermined: known < 256 (e.g. 3×180, 7×220, 1×8, 1×256) — all returned insufficient-leakage with no key.
  • Margin cases: cases where known ≥ 256 but the lattice margin is too small (e.g. 40 signatures each leaking 249 bits) also return insufficient-leakage rather than a wrong key.
  • LLL correctness: on 20 random 6-D integer lattices the output basis was verified to satisfy both the size-reduction (|μ_ij| ≤ 1/2) and Lovász conditions computed with independent exact rational Gram–Schmidt — 0 failures.
  • Robustness: 400 independently generated 10×220-bit HNP instances all recovered the key directly from a reduced basis row.

4.4 Notes on tuning

  • L = n · 2^{l_max} clears all denominators; mixed leak widths are handled by the per-row factors L/B_i.
  • Centring (−B_i/2) keeps target coordinates in [−1/2, 1/2], which improves the LLL reduction quality.
  • The combination search (step 2 of recoverPrivateKey) is a cheap safety net; in practice the target is already a reduced basis row.
  • The totalKnown < 256 gate is exact for uniqueness; at equality (leakBits = 0) the direct-nonce shortcut handles the degenerate case.
