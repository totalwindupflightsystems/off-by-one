NUTS core: recursive trees, U-turn checks, dual averaging, divergences

Root-cause analysis

A "looks correct" NUTS kernel fails these requirements in predictable ways:

Failure Root cause Effect
Poor mixing Fixed path length or one-sided U-turn test Biased / truncated exploration
Never terminates Missing U-turn short-circuit or max_tree_depth Unbounded work
Explodes on cond=1e4 Hard-coded step size; no isfinite guard NaN poisons the chain
Missed divergences Wrong sign (H0-H vs H-H0); divergent states leak in Silent bias
Adaptation targets wrong value Acceptance stat includes initial state, or per-tree instead of per-step Settles at ~0.9 for delta=0.8
Not bitwise reproducible Global RNG, extra draws, order dependence Two seeded runs differ

Key insight: the mean acceptance statistic fed to dual averaging must average leapfrog steps only. Including the initial state biases small trees upward, so the schedule converges to the wrong rate.

The fix (essence)

nuts_core.py implements Hoffman & Gelman's efficient NUTS (Algorithms 5–6), NumPy-only, float64:

  • _build_tree — exact BUILD_TREE recursion; each leaf does one leapfrog, returns slice count n', stop flag s', acceptance α', leapfrog count.
  • U-turn — (q₊-q₋)·p₋ ≥ 0 and (q₊-q₋)·p₊ ≥ 0; s = s' if uturn else 0.
  • Divergence — leaf returns n'=0, s'=0, divergent=True when not isfinite(H) or H-H0 > delta_max (default 1000). The zero s' short-circuits the tree.
  • Dual averaging — H̄ ← (1-η)H̄ + η(δ-α), log ε ← μ - √t/γ·H̄, log ε̄ ← t^{-κ}log ε + (1-t^{-κ})log ε̄; μ=log(10ε0), γ=.05, t0=10, κ=.75. Sampling uses ε̄=exp(log ε̄).
  • Determinism — one seeded numpy.random.Generator (PCG64) with fixed draw order: momentum → slice → direction → merge choice. record_trajectory=True captures every gradient.
  • Bounded work — max_tree_depth=10 plus the s criterion cap leapfrogs at 2¹⁰.

API: NUTSSampler(log_prob, grad_log_prob, dim, ...).sample(n, warmup=...) or nuts_sample(...). Returns samples, depths, accept_stats, n_leapfrog, divergences, step_size, warmup_accept, warmup_step_size, eps0.

from nuts_core import nuts_sample
out = nuts_sample(lambda q: float(-0.5*q@q), lambda q: -q, 2,
                  num_samples=2000, warmup=1000, seed=0, delta=0.8)
