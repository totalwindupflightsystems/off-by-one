Snapshot-Safe MVCC Compaction of Range Tombstones and Point Versions

Root-cause analysis

A naive compactor treats a version chain as "keep the newest version, drop the rest" and treats tombstones as "delete if old enough." Both rules are wrong once snapshots exist, and they fail in five distinct ways:

  1. Newest point version is not the same as the visible version. A newer Put can itself be shadowed by a range tombstone, so the truly visible value at the watermark may be an older Put. Dropping all but the newest point op resurrects values that were deleted (or deletes values that should be visible).
  2. A tombstone cannot be dropped just because it is older than the oldest live snapshot. Dropping it re-exposes every point version it shadowed unless those versions are also removed. Tombstone removal and version removal must be done together.
  3. A moving snapshot watermark is unsound. If the compactor recomputes oldest_live_snapshot while it runs, a snapshot that begins or ends during compaction changes what gets retained. The safe rule is to pin the protected set at the start of the compaction. Snapshots created later get a sequence ≥ the current maximum, so they are automatically covered.
  4. Overlapping range tombstones only dominate where no snapshot lies between them. A newer tombstone T2 shadows an older T1 for a snapshot s only if T1.seq ≤ s implies T2.seq ≤ s. If a protected snapshot exists in [T1.seq, T2.seq), that snapshot sees T1 but not T2, so the overlap must be kept. Trimming without this guard loses history.
  5. In-place log rewrite is not crash-safe. A crash in the middle of rewriting the log leaves a torn file and loses committed state. Records need checksums and length framing, and compaction must be temp-file + fsync + atomic rename + directory fsync.

The fix below makes the invariant explicit: at every protected sequence, replaying the compacted log yields exactly the same state as replaying the original log. The compactor does not approximate the watermarked state; it replays it.

mvcc.go — versioned op log + exact read semantics

// Package mvcc implements a small, crash-safe MVCC engine with point versions
// and range tombstones, plus a snapshot-safe compactor.
//
// Semantics (matching an LSM/LevelDB-style engine):
//
//   - Every mutation is assigned a strictly increasing sequence number.
//   - A point Put/Delete with sequence p is visible to a snapshot s iff p <= s.
//   - A range tombstone [start,end) with sequence t shadows a point version
//     with sequence p iff p < t <= s and start <= key < end.
//   - A snapshot at sequence s sees, for each key, the newest point version
//     with sequence <= s, unless a range tombstone shadows it.
//
// The whole state is a sorted log of operations; replaying the log up to s in
// sequence order reproduces exactly the snapshot-s state.  The compactor
// rewrites that log while preserving every protected snapshot.
package mvcc

import (
    "sort"
)

// Kind identifies the operation type.
type Kind uint8

const (
    // Put writes Value at Key.
    Put Kind = iota
    // Delete removes Key.
    Delete
    // DeleteRange installs a tombstone over [Key, End).
    DeleteRange
)

// Op is a single versioned mutation. Ops are ordered by Seq.
type Op struct {
    Seq   uint64
    Kind  Kind
    Key   string
    Value []byte
    End   string // exclusive end for DeleteRange
}

// clone returns a deep copy so callers cannot mutate stored state.
func (o Op) clone() Op {
    c := o
    if o.Value != nil {
        c.Value = append([]byte(nil), o.Value...)
    }
    return c
}

// Engine holds the op log and issues snapshots.
type Engine struct {
    ops []Op
    seq uint64
}

// New returns an empty engine.
func New() *Engine { return &Engine{} }

// NewFromOps rebuilds an engine from a persisted op log.
func NewFromOps(ops []Op) *Engine {
    e := &Engine{}
    e.LoadOps(ops)
    return e
}

// LoadOps replaces the log. It sorts by Seq and sets the sequence counter.
func (e *Engine) LoadOps(ops []Op) {
    e.ops = e.ops[:0]
    for _, o := range ops {
        e.ops = append(e.ops, o.clone())
    }
    sort.SliceStable(e.ops, func(i, j int) bool { return e.ops[i].Seq < e.ops[j].Seq })
    e.seq = 0
    for _, o := range e.ops {
        if o.Seq > e.seq {
            e.seq = o.Seq
        }
    }
}

// Seq returns the latest assigned sequence number.
func (e *Engine) Seq() uint64 { return e.seq }

// Ops returns a copy of the current log (for persistence / tests).
func (e *Engine) Ops() []Op {
    out := make([]Op, len(e.ops))
    for i, o := range e.ops {
        out[i] = o.clone()
    }
    return out
}

// nextSeq assigns the next sequence number.
func (e *Engine) nextSeq() uint64 {
    e.seq++
    return e.seq
}

// Put inserts/replaces Key.
func (e *Engine) Put(key string, val []byte) uint64 {
    s := e.nextSeq()
    e.ops = append(e.ops, Op{Seq: s, Kind: Put, Key: key, Value: append([]byte(nil), val...)})
    return s
}

// Delete removes Key.
func (e *Engine) Delete(key string) uint64 {
    s := e.nextSeq()
    e.ops = append(e.ops, Op{Seq: s, Kind: Delete, Key: key})
    return s
}

// DeleteRange installs a tombstone over [start,end).
func (e *Engine) DeleteRange(start, end string) uint64 {
    if start >= end {
        panic("mvcc: DeleteRange requires start < end")
    }
    s := e.nextSeq()
    e.ops = append(e.ops, Op{Seq: s, Kind: DeleteRange, Key: start, End: end})
    return s
}

// Apply inserts a pre-built op, assigning it the next sequence. Useful for
// replaying a WAL where the seq is already present via ApplyWithSeq.
func (e *Engine) Apply(op Op) uint64 {
    op.Seq = e.nextSeq()
    if op.Kind == DeleteRange {
        if op.Key >= op.End {
            panic("mvcc: DeleteRange requires start < end")
        }
    }
    op = op.clone()
    e.ops = append(e.ops, op)
    return op.Seq
}

// ApplyWithSeq inserts an op preserving its sequence number. It panics if the
// seq is not strictly greater than the current maximum.
func (e *Engine) ApplyWithSeq(op Op) {
    if op.Seq <= e.seq {
        panic("mvcc: non-monotonic sequence")
    }
    e.ops = append(e.ops, op.clone())
    e.seq = op.Seq
}

// Snapshot returns an immutable read view at the current sequence.
func (e *Engine) Snapshot() *Snapshot { return &Snapshot{e: e, seq: e.seq} }

// SnapshotAt returns a read view at an explicit sequence (<= current).
func (e *Engine) SnapshotAt(seq uint64) *Snapshot {
    if seq > e.seq {
        seq = e.seq
    }
    return &Snapshot{e: e, seq: seq}
}

// Snapshot is a read view.
type Snapshot struct {
    e   *Engine
    seq uint64
}

// Seq returns the snapshot sequence.
func (s *Snapshot) Seq() uint64 { return s.seq }

// Get returns the value of key as of the snapshot.
func (s *Snapshot) Get(key string) ([]byte, bool) {
    return getAt(s.e.ops, key, s.seq)
}

// Scan returns all live key/value pairs with start <= key < end, sorted.
func (s *Snapshot) Scan(start, end string) []KV {
    return scanAt(s.e.ops, start, end, s.seq)
}

// KV is a key/value pair.
type KV struct {
    Key   string
    Value []byte
}

// getAt implements point-read semantics directly over the ordered log.
func getAt(ops []Op, key string, snap uint64) ([]byte, bool) {
    // Newest point op for key with seq <= snap.
    var ptSeq uint64
    var kind Kind
    var val []byte
    found := false
    for i := len(ops) - 1; i >= 0; i-- {
        o := ops[i]
        if o.Seq > snap {
            continue
        }
        if o.Kind == DeleteRange || o.Key != key {
            continue
        }
        ptSeq = o.Seq
        kind = o.Kind
        val = o.Value
        found = true
        break
    }
    if !found || kind == Delete {
        return nil, false
    }
    // Any tombstone strictly newer than the point version and <= snap shadows it.
    for i := len(ops) - 1; i >= 0; i-- {
        o := ops[i]
        if o.Seq > snap {
            continue
        }
        if o.Seq <= ptSeq {
            break // log is ascending; older tombstones cannot shadow
        }
        if o.Kind == DeleteRange && o.Key <= key && key < o.End {
            return nil, false
        }
    }
    return append([]byte(nil), val...), true
}

// scanAt collects candidate keys and point-reads each.
func scanAt(ops []Op, start, end string, snap uint64) []KV {
    keys := make(map[string]struct{})
    for _, o := range ops {
        if o.Seq > snap {
            continue
        }
        if o.Kind != DeleteRange && o.Key >= start && o.Key < end {
            keys[o.Key] = struct{}{}
        }
    }
    sorted := make([]string, 0, len(keys))
    for k := range keys {
        sorted = append(sorted, k)
    }
    sort.Strings(sorted)
    out := make([]KV, 0, len(sorted))
    for _, k := range sorted {
        if v, ok := getAt(ops, k, snap); ok {
            out = append(out, KV{Key: k, Value: v})
        }
    }
    return out
}

// Replay rebuilds the exact snapshot state by applying ops in sequence order.
// It is the reference semantics against which direct reads are validated.
func Replay(ops []Op, snap uint64) map[string][]byte {
    m := make(map[string][]byte)
    ordered := append([]Op(nil), ops...)
    sort.SliceStable(ordered, func(i, j int) bool { return ordered[i].Seq < ordered[j].Seq })
    for _, o := range ordered {
        if o.Seq > snap {
            continue
        }
        switch o.Kind {
        case Put:
            m[o.Key] = append([]byte(nil), o.Value...)
        case Delete:
            delete(m, o.Key)
        case DeleteRange:
            for k := range m {
                if o.Key <= k && k < o.End {
                    delete(m, k)
                }
            }
        }
    }
    return m
}

compaction.go — the snapshot-safe compactor

package mvcc

import "sort"

// Compact rewrites the op log so that every snapshot sequence in `protected`
// observes exactly the same state as before.  It is the core of snapshot-safe
// tombstone/version compaction.
//
// Algorithm
//
//  1. Let w = min(protected) be the "watermark".  Every protected snapshot is
//     >= w, so the state at w is a common ancestor state for all of them.
//  2. Replay the log up to w to obtain that ancestor state exactly.
//  3. Replace every op with seq <= w by a single Put at seq w (one per live
//     key).  All old point versions, point deletes and range tombstones with
//     seq <= w can be dropped, because replaying the new puts reproduces the
//     state at w and every protected snapshot then applies only ops with
//     seq > w.
//  4. Range tombstones with seq > w are kept, but trimmed against strictly
//     newer tombstones whenever no protected snapshot lies between the two
//     sequences.  In that case the newer tombstone shadows the older one at
//     every protected snapshot, so the overlap is redundant.
//
// Because the state at w is replayed rather than approximated, the result is
// exact for all s >= w (not merely for the listed snapshots).  New snapshots
// created after compaction get a sequence >= the current maximum >= w, so they
// are always covered.
func Compact(ops []Op, protected []uint64) []Op {
    w := watermark(ops, protected)
    state := Replay(ops, w)

    tombs := make([]Op, 0)
    for _, o := range ops {
        if o.Seq > w && o.Kind == DeleteRange {
            tombs = append(tombs, o.clone())
        }
    }
    tombs = compactTombstones(tombs, protected)
    frags := make(map[uint64][]Op, len(tombs))
    for _, t := range tombs {
        frags[t.Seq] = append(frags[t.Seq], t)
    }

    out := make([]Op, 0, len(state)+len(ops))
    keys := make([]string, 0, len(state))
    for k := range state {
        keys = append(keys, k)
    }
    sort.Strings(keys)
    for _, k := range keys {
        out = append(out, Op{Seq: w, Kind: Put, Key: k, Value: state[k]})
    }
    for _, o := range ops {
        if o.Seq <= w {
            continue
        }
        if o.Kind == DeleteRange {
            for _, t := range frags[o.Seq] {
                out = append(out, t)
            }
            continue
        }
        out = append(out, o.clone())
    }
    sort.SliceStable(out, func(i, j int) bool { return out[i].Seq < out[j].Seq })
    return out
}

// watermark returns the oldest sequence that must be preserved.  When
// `protected` is empty the latest state is still preserved by using the
// current maximum sequence.
func watermark(ops []Op, protected []uint64) uint64 {
    if len(protected) > 0 {
        w := protected[0]
        for _, p := range protected[1:] {
            if p < w {
                w = p
            }
        }
        return w
    }
    var m uint64
    for _, o := range ops {
        if o.Seq > m {
            m = o.Seq
        }
    }
    return m
}

type interval struct{ start, end string }

// subtract removes cut from the set of intervals.
func subtract(in []interval, cut interval) []interval {
    var out []interval
    for _, iv := range in {
        if cut.end <= iv.start || cut.start >= iv.end {
            out = append(out, iv) // no overlap
            continue
        }
        if iv.start < cut.start {
            out = append(out, interval{iv.start, cut.start})
        }
        if cut.end < iv.end {
            out = append(out, interval{cut.end, iv.end})
        }
    }
    return out
}

// compactTombstones removes tombstone shadow that is provably redundant for all
// protected snapshots.
func compactTombstones(tombs []Op, protected []uint64) []Op {
    // Sort newest first so that when trimming an older tombstone we can use the
    // already-final intervals of newer ones.
    ordered := append([]Op(nil), tombs...)
    sort.SliceStable(ordered, func(i, j int) bool { return ordered[i].Seq > ordered[j].Seq })

    var final []Op
    for _, older := range ordered {
        ivs := []interval{{older.Key, older.End}}
        for _, newer := range final {
            if newer.Key >= older.End || newer.End <= older.Key {
                continue
            }
            if !dominates(older.Seq, newer.Seq, protected) {
                continue
            }
            ivs = subtract(ivs, interval{newer.Key, newer.End})
            if len(ivs) == 0 {
                break
            }
        }
        for _, iv := range ivs {
            t := older.clone()
            t.Key, t.End = iv.start, iv.end
            final = append(final, t)
        }
    }
    sort.SliceStable(final, func(i, j int) bool {
        if final[i].Seq != final[j].Seq {
            return final[i].Seq < final[j].Seq
        }
        return final[i].Key < final[j].Key
    })
    return final
}

// dominates reports whether every protected snapshot that has the older
// tombstone active also has the newer one active, i.e. there is no protected
// sequence in [olderSeq, newerSeq).
func dominates(olderSeq, newerSeq uint64, protected []uint64) bool {
    for _, p := range protected {
        if p >= olderSeq && p < newerSeq {
            return false
        }
    }
    return true
}

wal.go — crash-safe append log + atomic compaction

package mvcc

import (
    "bytes"
    "encoding/binary"
    "encoding/gob"
    "errors"
    "fmt"
    "hash/crc32"
    "os"
    "path/filepath"
)

// WAL is a crash-safe append-only log of Ops.
//
// Layout:
//
//  magic   = "MVCC1\n"
//  record* = uint32le length | uint32le crc32(payload) | payload (gob Op)
//
// A record is only considered valid if the full length and payload are present
// and the CRC matches.  Reads stop at the first invalid/torn record, which is
// exactly what a crash mid-append leaves behind.  Compaction writes a complete
// replacement log to a temp file, fsyncs it, and atomically renames it over the
// live file, so a crash can never expose a half-written log.
const walMagic = "MVCC1\n"

var (
    // ErrBadMagic indicates the file is not a WAL.
    ErrBadMagic = errors.New("mvcc: bad wal magic")
)

// Store couples an Engine with a durable WAL.
type Store struct {
    path string
    eng  *Engine
    f    *os.File
}

// Open opens or creates the WAL at path, recovering the valid prefix.
func Open(path string) (*Store, error) {
    _ = os.Remove(path + ".tmp") // leftover from a crashed compaction
    ops, err := readWAL(path)
    if err != nil {
        return nil, err
    }
    e := NewFromOps(ops)
    f, err := os.OpenFile(path, os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0o644)
    if err != nil {
        return nil, err
    }
    // Ensure a freshly created file has the magic.
    fi, err := f.Stat()
    if err != nil {
        f.Close()
        return nil, err
    }
    if fi.Size() == 0 {
        if _, err := f.WriteString(walMagic); err != nil {
            f.Close()
            return nil, err
        }
        if err := f.Sync(); err != nil {
            f.Close()
            return nil, err
        }
    }
    return &Store{path: path, eng: e, f: f}, nil
}

// Engine exposes the in-memory engine.
func (s *Store) Engine() *Engine { return s.eng }

// Close closes the WAL.
func (s *Store) Close() error {
    if s.f == nil {
        return nil
    }
    err := s.f.Close()
    s.f = nil
    return err
}

// appendRecord durably appends one op.
func (s *Store) appendRecord(op Op) error {
    var payload bytes.Buffer
    if err := gob.NewEncoder(&payload).Encode(op); err != nil {
        return err
    }
    buf := make([]byte, 8+payload.Len())
    binary.LittleEndian.PutUint32(buf[0:4], uint32(payload.Len()))
    binary.LittleEndian.PutUint32(buf[4:8], crc32.ChecksumIEEE(payload.Bytes()))
    copy(buf[8:], payload.Bytes())
    if _, err := s.f.Write(buf); err != nil {
        return err
    }
    return s.f.Sync()
}

// Put durably writes a key.
func (s *Store) Put(key string, val []byte) (uint64, error) {
    op := Op{Kind: Put, Key: key, Value: append([]byte(nil), val...)}
    seq, err := s.append(op)
    return seq, err
}

// Delete durably deletes a key.
func (s *Store) Delete(key string) (uint64, error) {
    return s.append(Op{Kind: Delete, Key: key})
}

// DeleteRange durably installs a range tombstone.
func (s *Store) DeleteRange(start, end string) (uint64, error) {
    if start >= end {
        return 0, fmt.Errorf("mvcc: DeleteRange requires start < end")
    }
    return s.append(Op{Kind: DeleteRange, Key: start, End: end})
}

func (s *Store) append(op Op) (uint64, error) {
    op.Seq = s.eng.seq + 1
    if err := s.appendRecord(op); err != nil {
        return 0, err
    }
    s.eng.ApplyWithSeq(op)
    return op.Seq, nil
}

// Compact atomically replaces the WAL with a compacted version that preserves
// all protected snapshots.
func (s *Store) Compact(protected []uint64) error {
    ops := Compact(s.eng.Ops(), protected)
    tmp := s.path + ".tmp"
    if err := writeWAL(tmp, ops); err != nil {
        return err
    }
    if err := s.f.Close(); err != nil {
        return err
    }
    s.f = nil
    if err := os.Rename(tmp, s.path); err != nil {
        return err
    }
    if err := syncDir(filepath.Dir(s.path)); err != nil {
        return err
    }
    f, err := os.OpenFile(s.path, os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0o644)
    if err != nil {
        return err
    }
    s.f = f
    s.eng.LoadOps(ops)
    return nil
}

func writeWAL(path string, ops []Op) error {
    f, err := os.OpenFile(path, os.O_CREATE|os.O_TRUNC|os.O_WRONLY, 0o644)
    if err != nil {
        return err
    }
    defer f.Close()
    if _, err := f.WriteString(walMagic); err != nil {
        return err
    }
    for _, op := range ops {
        var payload bytes.Buffer
        if err := gob.NewEncoder(&payload).Encode(op); err != nil {
            return err
        }
        buf := make([]byte, 8+payload.Len())
        binary.LittleEndian.PutUint32(buf[0:4], uint32(payload.Len()))
        binary.LittleEndian.PutUint32(buf[4:8], crc32.ChecksumIEEE(payload.Bytes()))
        copy(buf[8:], payload.Bytes())
        if _, err := f.Write(buf); err != nil {
            return err
        }
    }
    if err := f.Sync(); err != nil {
        return err
    }
    return nil
}

func syncDir(dir string) error {
    d, err := os.Open(dir)
    if err != nil {
        return err
    }
    defer d.Close()
    return d.Sync()
}

// readWAL decodes the valid prefix of a WAL.  A missing file yields no ops.
// Torn or corrupted trailing records are silently dropped, which recovers the
// state as of the last complete record.
func readWAL(path string) ([]Op, error) {
    data, err := os.ReadFile(path)
    if err != nil {
        if os.IsNotExist(err) {
            return nil, nil
        }
        return nil, err
    }
    if len(data) < len(walMagic) {
        if len(data) == 0 {
            return nil, nil
        }
        return nil, ErrBadMagic
    }
    if string(data[:len(walMagic)]) != walMagic {
        return nil, ErrBadMagic
    }
    var ops []Op
    p := data[len(walMagic):]
    for {
        if len(p) < 8 {
            break // torn length/crc
        }
        n := int(binary.LittleEndian.Uint32(p[0:4]))
        crc := binary.LittleEndian.Uint32(p[4:8])
        if len(p) < 8+n {
            break // torn payload
        }
        payload := p[8 : 8+n]
        if crc32.ChecksumIEEE(payload) != crc {
            break // corrupted record: stop at last good one
        }
        var op Op
        if err := gob.NewDecoder(bytes.NewReader(payload)).Decode(&op); err != nil {
            break
        }
        ops = append(ops, op)
        p = p[8+n:]
        if len(p) == 0 {
            break
        }
    }
    return ops, nil
}

engine_test.go — verification harness

package mvcc

import (
    "bytes"
    "encoding/binary"
    "fmt"
    "math/rand"
    "os"
    "path/filepath"
    "testing"
)

func mustPut(t *testing.T, e *Engine, k, v string) {
    t.Helper()
    e.Put(k, []byte(v))
}

func checkSnapshot(t *testing.T, e *Engine, ops []Op, snap uint64) {
    t.Helper()
    s := e.SnapshotAt(snap)
    ref := Replay(ops, s.Seq())
    for _, k := range allKeys(ops) {
        gotV, gotOK := s.Get(k)
        refV, refOK := ref[k]
        if gotOK != refOK || (gotOK && !bytes.Equal(gotV, refV)) {
            t.Fatalf("snapshot %d key %q: engine=(%q,%v) reference=(%q,%v)",
                snap, k, gotV, gotOK, refV, refOK)
        }
    }
    got := s.Scan("", "\xff")
    want := map[string][]byte{}
    for k, v := range ref {
        want[k] = v
    }
    if len(got) != len(want) {
        t.Fatalf("snapshot %d scan size: engine=%d reference=%d", snap, len(got), len(want))
    }
    for _, kv := range got {
        rv, ok := want[kv.Key]
        if !ok || !bytes.Equal(kv.Value, rv) {
            t.Fatalf("snapshot %d scan key %q: engine=%q reference=(%q,%v)", snap, kv.Key, kv.Value, rv, ok)
        }
    }
}

func allKeys(ops []Op) []string {
    set := map[string]struct{}{}
    for _, o := range ops {
        if o.Kind != DeleteRange {
            set[o.Key] = struct{}{}
        }
    }
    out := make([]string, 0, len(set))
    for k := range set {
        out = append(out, k)
    }
    return out
}

func TestRangeTombstoneBasics(t *testing.T) {
    e := New()
    mustPut(t, e, "b", "v1")
    e.DeleteRange("a", "c")
    mustPut(t, e, "b", "v3")
    e.DeleteRange("b", "d")
    mustPut(t, e, "c", "v5")
    e.Delete("c")
    mustPut(t, e, "c", "v7")

    for snap := uint64(0); snap <= 7; snap++ {
        checkSnapshot(t, e, e.Ops(), snap)
    }
    if v, ok := e.SnapshotAt(3).Get("b"); !ok || string(v) != "v3" {

func TestTombstoneTrimProtected(t *testing.T) {
    build := func() []Op {

        e.DeleteRange("a", "m")  // 4 older
        mustPut(t, e, "k", "v5") // 5
        e.DeleteRange("a", "k")  // 6 newer, dominates 4 on [a,k)
        mustPut(t, e, "k", "v7") // 7
        return e.Ops()
    }
    ops := build()

    out := Compact(ops, []uint64{3, 5, 7})
    for _, snap := range []uint64{3, 5, 7} {
        got := Replay(out, snap)
        want := Replay(ops, snap)
        if len(got) != len(want) {
            t.Fatalf("snap %d size mismatch got=%v want=%v", snap, got, want)
        }
        for k, v := range want {
            if !bytes.Equal(got[k], v) {
                t.Fatalf("snap %d key %q got=%q want=%q", snap, k, got[k], v)
            }
        }
    }
    kept := false
    for _, o := range out {
        if o.Kind == DeleteRange && o.Seq == 4 && o.Key == "a" && o.End == "m" {
            kept = true
        }
    }
    if !kept {
        t.Fatalf("tombstone 4 was trimmed although snapshot 5 protects it")
    }

    out2 := Compact(ops, []uint64{3, 7})
    n4 := 0
    for _, o := range out2 {
        if o.Kind == DeleteRange && o.Seq == 4 {
            n4++
            if o.Key != "k" || o.End != "m" {
                t.Fatalf("expected trimmed tombstone [k,m), got [%s,%s)", o.Key, o.End)
            }
        }
    }
    if n4 != 1 {
        t.Fatalf("expected one fragment of tombstone 4, got %d", n4)
    }
    for _, snap := range []uint64{3, 7} {
        got := Replay(out2, snap)
        want := Replay(ops, snap)
        if len(got) != len(want) {
            t.Fatalf("snap %d size mismatch got=%v want=%v", snap, got, want)
        }
        for k, v := range want {

                t.Fatalf("snap %d key %q got=%q want=%q", snap, k, got[k], v)
            }
        }
    }

func TestRandomizedCompactionDifferential(t *testing.T) {
    keys := []string{"a", "b", "c", "d", "e"}
    for seed := int64(0); seed < 200; seed++ {
        r := rand.New(rand.NewSource(seed))
        e := New()
        var protected []uint64
        n := 60 + r.Intn(60)
        for i := 0; i < n; i++ {
            switch r.Intn(10) {
            case 0, 1, 2, 3:
                k := keys[r.Intn(len(keys))]
                e.Put(k, []byte(fmt.Sprintf("v%d_%d", seed, i)))
            case 4, 5:
                k := keys[r.Intn(len(keys))]
                e.Delete(k)
            default:
                i0 := r.Intn(len(keys))
                i1 := r.Intn(len(keys))
                if i0 > i1 {
                    i0, i1 = i1, i0
                }
                start, end := keys[i0], keys[i1]
                if start == end {
                    end = string(start[0] + 1)
                }
                e.DeleteRange(start, end)
            }
            if r.Intn(4) == 0 {
                protected = append(protected, e.Seq())
            }
        }
        original := e.Ops()

        for _, p := range protected {
            checkSnapshot(t, e, original, p)
        }
        checkSnapshot(t, e, original, e.Seq())

        prot := append([]uint64(nil), protected...)
        prot = append(prot, e.Seq())
        compacted := Compact(original, prot)
        ce := NewFromOps(compacted)
        for _, p := range prot {
            checkSnapshot(t, ce, original, p)
        }
        if len(compacted) > len(original) {
            t.Fatalf("seed %d: compaction grew %d -> %d", seed, len(original), len(compacted))
        }

        compacted2 := Compact(compacted, []uint64{e.Seq()})
        ce2 := NewFromOps(compacted2)
        checkSnapshot(t, ce2, original, e.Seq())
        for _, k := range keys {
            v1, ok1 := ce2.SnapshotAt(e.Seq()).Get(k)
            v2, ok2 := ce.SnapshotAt(e.Seq()).Get(k)
            if ok1 != ok2 || !bytes.Equal(v1, v2) {
                t.Fatalf("seed %d: second compaction diverged for %q", seed, k)
            }
        }
    }
}

func TestSnapshotsBeginEndDuringCompaction(t *testing.T) {

func TestCrashSafeCompaction(t *testing.T) {

    }
    if v, ok := s2.Engine().SnapshotAt(4).Get("c"); !ok || string(v) != "3" {

The compactor folds the entire version/tombstone history into the live state, so memory during compaction is bounded by O(distinct live keys + ops newer than watermark) rather than by the number of historical versions.

Why it is correct (summary proof)

Let w = min(protected). Replay(ops, w) reconstructs the exact state at w. Compact emits one Put per live key at sequence w and keeps every op with seq > w. For any protected snapshot s ≥ w, Replay(new, s) first reaches the state at w and then applies the identical ops in (w, s], so it equals Replay(old, s). The synthetic w-puts sit strictly below every retained op, so ordering is preserved. Tombstone overlap trimming is applied only when dominates(T1.seq, T2.seq) holds, i.e. no protected snapshot exists in [T1.seq, T2.seq); then T2 is active for every protected snapshot where T1 is, so removing the overlap changes nothing. Snapshots opened after compaction get sequence numbers greater than the current maximum, hence ≥ w, and are covered.
