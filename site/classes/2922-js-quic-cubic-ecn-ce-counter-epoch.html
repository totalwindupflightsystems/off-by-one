RFC 9438 CUBIC + DCTCP ECN epoch accounting for a QUIC sender

TL;DR

The failure is a state-machine and determinism bug, not a formula bug. A correct simulate(trace) must (1) compute the DCTCP alpha from the CE fraction of a completed observation window and apply the window reduction once per window/RTT, (2) start every CUBIC congestion-avoidance stage after the multiplicative decrease so K is derived from the post-reduction cwnd, (3) implement RFC 9438 fast convergence before the decrease, (4) restore the exact saved CUBIC state on a spurious loss without letting the recovered bytes drive a second increase, and (5) do all range arithmetic on sorted, merged, canonical half-open intervals so output is bit-identical regardless of Map/Set insertion order.

1. Root-cause analysis

A naïve implementation typically fails in six distinct places. Each changes the numbers, and some make them non-reproducible.

1.1 alpha updated (and applied) per ACK instead of per completed epoch

DCTCP (RFC 8257 §3.3) accumulates BytesAcked/BytesMarked over an observation window and only at window end computes

M     = BytesMarked / BytesAcked
alpha = (1 - g) * alpha + g * M      // g = 1/16
cwnd  = cwnd * (1 - alpha / 2)       // at most once per window

Updating per ACK runs the EWMA at ACK rate, uses the wrong denominator, and reduces cwnd many times per RTT. The boundary is the RFC's WindowEnd (set to SND.NXT at close), not every ACK.

1.2 K derived from the pre-reduction cwnd

RFC 9438 Figure 2 anchors the cubic at the start of the CA stage: K = cbrt((W_max - cwnd_epoch) / C). If cwnd_epoch is captured before the decrease (or stale K is kept), the plateau lands at the wrong window. The epoch must be restarted after every reduction.

1.3 Fast convergence applied to the wrong value / at the wrong time

RFC 9438 §4.7 updates W_max before the decrease:

if (cwnd < W_max && fast_convergence) W_max = cwnd * (1 + beta) / 2;  // beta=0.7 -> 0.85*cwnd
else                                  W_max = cwnd;

Common bugs: using beta instead of (1+beta)/2, testing against the post-reduction cwnd, or forgetting cwnd_prior is the window before the decrease (needed by the undo).

1.4 Spurious loss double-counted recovered bytes

RFC 9438 §4.9.2 restores cwnd, cwnd_prior, ssthresh, W_max, K, t_epoch, W_est exactly when cwnd < cwnd_prior. The recovered ACK's bytes are genuinely newly acked and belong in the DCTCP counters once, but must not also feed congestion-avoidance growth — the undo already restored cwnd, so growing again makes the spurious path end above the no-loss path.

1.5 Set/Map iteration order leaks into float sums

Deduping with a Set<number> / Map makes the byte-count summation order depend on insertion order. Floating-point addition is not associative, so runs can differ in low-order bits. Fix: sort ranges, merge overlaps, sum in canonical order — never iterate Set/Map for arithmetic.

1.6 ECN reacted to with no CE marks

A window with BytesMarked == 0 must only decay alpha, not reduce cwnd (Linux tcp_dctcp.c drives the reduction through the ECE/CWR path). Reacting unconditionally collapses the window on a clean link.

2. The exact fix

Complete, dependency-free implementation. Exports simulate(trace, options?) -> { cwnd: number[], alpha: number[], epochs: object[] }.

'use strict';
/*
 * RFC 9438 CUBIC + RFC 8257 (DCTCP) ECN accounting for a simulated QUIC sender.
 *
 * Public API:
 *   simulate(trace, options) -> { cwnd: number[], alpha: number[], epochs: object[] }
 *
 * Trace (flexible, normalized by normalizeTrace):
 *   - an array of ack events, or { events | acks | trace: [...] }
 *   - an event is:
 *       {
 *         time | now | timestamp | ackElicitingTimestamp : number,
 *         acked  | ackedRanges | ranges : [[lo,hi), ...]  // half-open byte ranges
 *         lost   | lostRanges            : [[lo,hi), ...]
 *         ce     : boolean | [[lo,hi), ...] | number      // CE marks on acked bytes
 *         ecn    : { ect0, ect1, ce }                     // cumulative counters (QUIC)
 *         rtt    : number,                                // measured RTT (optional)
 *         sent   : number                                 // bytes sent so far (optional)
 *       }
 *
 * All byte ranges are half-open [lo, hi) and are sorted+merged before use so the
 * result is bit-identical regardless of input ordering and free of double
 * counting of retransmitted/recovered bytes.
 */

const DEFAULTS = {
  mss: 1200,            // bytes per segment
  initialCwndSegs: 10,  // initial cwnd in segments
  initialRtt: 100,      // same time unit as the trace (default 100ms -> ms traces)
  beta: 0.7,            // CUBIC multiplicative decrease
  cubicC: 0.4,          // CUBIC scaling constant (per RFC 9438)
  g: 1 / 16,            // DCTCP EWMA gain
  alphaInit: 1,         // DCTCP.Alpha initial value
  fastConvergence: true,
  enableEcn: true,
};

/* ------------------------------------------------------------------ */
/* deterministic interval algebra                                      */
/* ------------------------------------------------------------------ */

function isNum(x) { return typeof x === 'number' && Number.isFinite(x); }

// Sort + merge a batch of ranges into a canonical ascending, disjoint list.
function normalizeRanges(ranges) {
  if (ranges == null) return [];
  const out = [];
  if (isNum(ranges) || typeof ranges === 'boolean') return [];
  for (const r of ranges) {
    if (Array.isArray(r) && r.length >= 2 && isNum(r[0]) && isNum(r[1])) {
      const lo = Math.floor(r[0]);
      const hi = Math.floor(r[1]);
      if (hi > lo) out.push([lo, hi]);
    } else if (isNum(r)) {
      const lo = Math.floor(r);
      out.push([lo, lo + 1]);
    }
  }
  out.sort((a, b) => (a[0] - b[0]) || (a[1] - b[1]));
  const merged = [];
  for (const [lo, hi] of out) {
    const last = merged[merged.length - 1];
    if (last && lo <= last[1]) {
      if (hi > last[1]) last[1] = hi;
    } else {
      merged.push([lo, hi]);
    }
  }
  return merged;
}

// Merge two already-canonical interval lists.
function mergeTwo(a, b) {
  const res = [];
  let i = 0, j = 0;
  while (i < a.length || j < b.length) {
    let lo, hi;
    if (j >= b.length || (i < a.length && a[i][0] <= b[j][0])) {
      lo = a[i][0]; hi = a[i][1]; i++;
    } else {
      lo = b[j][0]; hi = b[j][1]; j++;
    }
    const last = res[res.length - 1];
    if (last && lo <= last[1]) {
      if (hi > last[1]) last[1] = hi;
    } else {
      res.push([lo, hi]);
    }
  }
  return res;
}

function sizeOf(list) {
  let s = 0;
  for (const [lo, hi] of list) s += hi - lo;
  return s;
}

// Parts of batch `b` not covered by canonical list `a` (canonical, ascending).
function subtractRanges(b, a) {
  const out = [];
  let i = 0;
  for (const [blo, bhi] of b) {
    let cur = blo;
    while (i < a.length && a[i][1] <= cur) i++;
    let k = i;
    while (k < a.length && a[k][0] < bhi) {
      if (a[k][0] > cur) out.push([cur, Math.min(a[k][0], bhi)]);
      if (a[k][1] > cur) cur = a[k][1];
      if (cur >= bhi) break;
      k++;
    }
    if (cur < bhi) out.push([cur, bhi]);
  }
  return out;
}

// Size of intersection of two canonical lists.
function intersectSize(a, b) {
  let i = 0, j = 0, s = 0;
  while (i < a.length && j < b.length) {
    const lo = Math.max(a[i][0], b[j][0]);
    const hi = Math.min(a[i][1], b[j][1]);
    if (hi > lo) s += hi - lo;
    if (a[i][1] < b[j][1]) i++; else j++;
  }
  return s;
}

/* ------------------------------------------------------------------ */
/* trace normalization                                                 */
/* ------------------------------------------------------------------ */

function pickFirst(obj, keys) {
  for (const k of keys) if (obj[k] !== undefined) return obj[k];
  return undefined;
}

function normalizeTrace(trace) {
  let events;
  if (Array.isArray(trace)) events = trace;
  else if (trace && Array.isArray(trace.events)) events = trace.events;
  else if (trace && Array.isArray(trace.acks)) events = trace.acks;
  else if (trace && Array.isArray(trace.trace)) events = trace.trace;
  else events = [];

  return events.map((ev, i) => {
    const time = pickFirst(ev, ['time', 'now', 'timestamp', 'ts', 'ackTime']);
    const ackElicitingTs = pickFirst(ev, ['ackElicitingTimestamp', 'ackElicitingTs', 'sentTime']);
    const ackedRaw = pickFirst(ev, ['acked', 'ackedRanges', 'ranges', 'ack']);
    const lostRaw = pickFirst(ev, ['lost', 'lostRanges', 'losses']);
    const ceRaw = pickFirst(ev, ['ce', 'ceRanges', 'marked']);
    return {
      index: i,
      time: isNum(time) ? time : (isNum(ackElicitingTs) ? ackElicitingTs : i),
      ackElicitingTs: isNum(ackElicitingTs) ? ackElicitingTs : undefined,
      rtt: isNum(ev.rtt) ? ev.rtt : undefined,
      sent: isNum(ev.sent) ? ev.sent : undefined,
      acked: normalizeRanges(ackedRaw),
      lost: normalizeRanges(lostRaw),
      ceRanges: normalizeRanges(ceRaw),
      ceAll: ceRaw === true || ev.ceMarked === true || ev.ece === true,
      ecn: (ev.ecn && typeof ev.ecn === 'object') ? ev.ecn : undefined,
    };
  });
}

/* ------------------------------------------------------------------ */
/* core simulator                                                      */
/* ------------------------------------------------------------------ */

function simulate(trace, options) {
  const opts = Object.assign({}, DEFAULTS, options || {});
  const MSS = opts.mss;
  const events = normalizeTrace(trace);

  // --- CUBIC state (bytes / seconds) ---
  let cwnd = opts.initialCwndSegs * MSS;
  let ssthresh = Infinity;
  let Wmax = 0;              // window just before last reduction
  let cwndPrior = 0;         // cwnd before last reduction (RFC 9438)
  let cwndEpoch = cwnd;      // cwnd at start of current CA stage (post reduction)
  let tEpoch = 0;            // time CA stage started
  let K = 0;                 // seconds to reach Wmax
  let West = cwnd;           // Reno-friendly window estimate
  let alphaCubic = 3 * (1 - opts.beta) / (1 + opts.beta);
  let inCongestionAvoidance = false;

  // --- DCTCP state ---
  let alpha = opts.alphaInit;
  let epochBytesAcked = 0;
  let epochBytesMarked = 0;
  let windowEnd = cwnd;      // end of current observation window (byte seq)
  let lastEcn = null;

  // --- accounting unions (canonical, sorted, disjoint) ---
  let ackedUnion = [];       // bytes ever acked (dedupe)
  let lostUnion = [];        // bytes currently declared lost, not yet recovered
  const pendingUndo = [];    // loss events that may turn out to be spurious

  // --- RTT estimate ---
  let srtt = opts.initialRtt;
  let haveSrtt = false;

  const cwndOut = [];
  const alphaOut = [];
  const epochsOut = [];
  const stateOut = opts.debug ? [] : null;

  function startEpoch(now) {
    cwndEpoch = cwnd;
    tEpoch = now;
    West = cwnd;
    // K is anchored on the POST-reduction window:
    K = Math.cbrt(Math.max(0, Wmax - cwndEpoch) / (opts.cubicC * MSS));
    alphaCubic = 3 * (1 - opts.beta) / (1 + opts.beta);
  }

  function reduce(now, factor, kind, ranges) {
    const undo = {
      cwnd, ssthresh, Wmax, cwndPrior, cwndEpoch, tEpoch, K, West, alphaCubic,
      inCongestionAvoidance, kind, ranges: ranges ? ranges.slice() : [],
      eventIndex: -1,
    };
    // RFC 9438 fast convergence (before the reduction).
    if (opts.fastConvergence && cwnd < Wmax) {
      Wmax = cwnd * (1 + opts.beta) / 2;
    } else {
      Wmax = cwnd;
    }
    cwndPrior = cwnd;
    const reduced = cwnd * factor;
    cwnd = Math.max(reduced, (kind === 'loss' ? 2 : 1) * MSS);
    ssthresh = Math.max(cwnd, 2 * MSS);
    inCongestionAvoidance = true;
    startEpoch(now);
    return undo;
  }

  function cubicGrow(ackedBytes, now, rtt) {
    if (ackedBytes <= 0) return;
    if (!inCongestionAvoidance && cwnd < ssthresh) {
      cwnd += ackedBytes;                       // slow start
      if (cwnd >= ssthresh) { inCongestionAvoidance = true; startEpoch(now); }
      return;
    }
    const dt = Math.max(0, now - tEpoch);
    const WcubicT = opts.cubicC * MSS * Math.pow(dt - K, 3) + Wmax;
    const WcubicTrtt = opts.cubicC * MSS * Math.pow(dt + rtt - K, 3) + Wmax;
    // Reno-friendly estimate (RFC 9438 Fig. 4, converted to bytes).
    West += alphaCubic * (ackedBytes / cwnd) * MSS;
    if (West >= cwndPrior) alphaCubic = 1;

    if (WcubicT < West) {
      if (West > cwnd) cwnd = West;             // Reno-friendly region
      return;
    }
    let target = WcubicTrtt;
    if (target < cwnd) target = cwnd;
    else if (target > 1.5 * cwnd) target = 1.5 * cwnd;
    cwnd += (target - cwnd) * (ackedBytes / cwnd);
  }

  for (let i = 0; i < events.length; i++) {
    const ev = events[i];
    const now = ev.time;

    // 0. RTT estimate from ack-eliciting timestamps.
    if (isNum(ev.rtt)) {
      srtt = haveSrtt ? (7 * srtt + ev.rtt) / 8 : ev.rtt;
      haveSrtt = true;
    } else if (isNum(ev.ackElicitingTs) && now >= ev.ackElicitingTs) {
      const sample = now - ev.ackElicitingTs;
      srtt = haveSrtt ? (7 * srtt + sample) / 8 : sample;
      haveSrtt = true;
    }
    const rtt = Math.max(1e-9, srtt);

    /* --- 1. ACK accounting (deterministic, deduped) --- */
    const ackedBatch = ev.acked;
    const mergedAck = mergeTwo(ackedUnion, ackedBatch);
    const newlyAcked = subtractRanges(ackedBatch, ackedUnion);
    const newlyAckedBytes = sizeOf(newlyAcked);
    ackedUnion = mergedAck;
    const cumAck = ackedUnion.length ? ackedUnion[ackedUnion.length - 1][1] : 0;

    // Bytes that were previously declared lost and are now acked = spurious.
    const spuriousBytes = intersectSize(newlyAcked, lostUnion);

    // CE bytes for this event: ranges, "all", or cumulative QUIC counters.
    let ceBytes = 0;
    if (ev.ceAll) {
      ceBytes = newlyAckedBytes;
    } else if (ev.ceRanges.length) {
      ceBytes = intersectSize(newlyAcked, ev.ceRanges);
    } else if (ev.ecn) {
      const e = ev.ecn;
      if (lastEcn) {
        const dEct0 = Math.max(0, (e.ect0 || 0) - (lastEcn.ect0 || 0));
        const dEct1 = Math.max(0, (e.ect1 || 0) - (lastEcn.ect1 || 0));
        const dCe = Math.max(0, (e.ce || 0) - (lastEcn.ce || 0));
        // ECN counters are in packets; scale to bytes using MSS.
        ceBytes = dCe * MSS;
        if (newlyAckedBytes === 0) ceBytes = Math.min(ceBytes, 0);
        void dEct0; void dEct1;
      }
      lastEcn = { ect0: e.ect0 || 0, ect1: e.ect1 || 0, ce: e.ce || 0 };
    }
    ceBytes = Math.min(ceBytes, newlyAckedBytes);

    epochBytesAcked += newlyAckedBytes;
    epochBytesMarked += ceBytes;

    /* --- 2. Loss detection -> CUBIC reduction --- */
    let reducedThisEvent = false;
    let restoredThisEvent = false;
    if (newlyAckedBytes > 0 && spuriousBytes > 0) {
      // Spurious loss: undo the most recent matching reduction exactly, and do
      // NOT let the recovered bytes drive a second window increase.
      for (let p = pendingUndo.length - 1; p >= 0; p--) {
        const u = pendingUndo[p];
        if (intersectSize(newlyAcked, u.ranges) <= 0) continue;
        if (cwnd < u.cwnd) {
          cwnd = u.cwnd;
          ssthresh = u.ssthresh;
          Wmax = u.Wmax;
          cwndPrior = u.cwnd;   // cwnd just before the undone reduction
          cwndEpoch = u.cwndEpoch;
          tEpoch = u.tEpoch;
          K = u.K;
          West = u.West;
          alphaCubic = u.alphaCubic;
          inCongestionAvoidance = u.inCongestionAvoidance;
        }
        pendingUndo.splice(p, 1);
        restoredThisEvent = true;
        break;
      }
    }

    const newLost = subtractRanges(ev.lost, lostUnion);
    const newLostBytes = sizeOf(newLost);
    if (newLostBytes > 0) {
      lostUnion = mergeTwo(lostUnion, newLost);
      const u = reduce(now, opts.beta, 'loss', newLost);
      u.eventIndex = i;
      pendingUndo.push(u);
      reducedThisEvent = true;
    }

    // Acknowledged bytes that were lost are no longer pending lost.
    const stillLost = subtractRanges(lostUnion, newlyAcked);
    lostUnion = stillLost;

    /* --- 3. DCTCP epoch completion: alpha update + one reduction per epoch --- */
    let alphaApplied = false;
    if (cumAck > windowEnd && epochBytesAcked > 0) {
      const M = epochBytesMarked / epochBytesAcked;
      const alphaBefore = alpha;
      alpha = alpha * (1 - opts.g) + opts.g * M;
      const cwndBefore = cwnd;
      let cwndAfter = cwnd;
      // React to ECN only when this window actually carried CE marks; like
      // RFC 8257 / Linux DCTCP this reacts at most once per observation window.
      if (opts.enableEcn && epochBytesMarked > 0 && alpha > 0) {
        // Treat the ECN decrease as a CUBIC congestion event so growth anchors
        // on the post-reduction window (fast convergence applied here too).
        // Not pushed to pendingUndo: ECN reductions are never "spurious loss".
        reduce(now, 1 - alpha / 2, 'ecn', []).eventIndex = i;
        cwndAfter = cwnd;
        alphaApplied = true;
      }
      epochsOut.push({
        eventIndex: i,
        bytesAcked: epochBytesAcked,
        bytesMarked: epochBytesMarked,
        fraction: M,
        alphaBefore,
        alphaAfter: alpha,
        cwndBefore,
        cwndAfter: cwnd,
        Wmax,
        K,
        cwndEpoch,
        ssthresh,
      });
      epochBytesAcked = 0;
      epochBytesMarked = 0;
      // RFC 8257 sets WindowEnd = SND.NXT at the close.  Use the trace's `sent`
      // pointer when supplied; otherwise approximate SND.NXT as ACK + cwnd.
      windowEnd = isNum(ev.sent) ? ev.sent : cumAck + cwnd;
    }

    /* --- 4. CUBIC growth for newly acked data --- */
    // Skip growth if a reduction happened this event, or if the bytes were
    // recovered from a spurious loss (avoids double counting).
    let growBytes = newlyAckedBytes;
    if (restoredThisEvent) growBytes = Math.max(0, growBytes - spuriousBytes);
    if (!reducedThisEvent && !alphaApplied && growBytes > 0) {
      cubicGrow(growBytes, now, rtt);
    }

    cwndOut.push(cwnd);
    alphaOut.push(alpha);
    if (stateOut) {
      stateOut.push({
        cwnd, ssthresh, Wmax, K, cwndEpoch, tEpoch, West,
        alpha, alphaCubic, epochBytesAcked, epochBytesMarked, windowEnd,
        inCongestionAvoidance,
      });
    }
  }

  const out = { cwnd: cwndOut, alpha: alphaOut, epochs: epochsOut };
  if (stateOut) out.state = stateOut;
  return out;
}

module.exports = { simulate, normalizeRanges, mergeTwo, sizeOf, subtractRanges, intersectSize };
