Root-cause analysis

A correct per-process THP report cannot be derived from the global enabled knob alone. The failure modes a naive awk-over-smaps script hits are:

  1. Global policy is not the effective policy. MADV_HUGEPAGE/MADV_NOHUGEPAGE are recorded per VMA as the hg/nh bits in VmFlags. A VMA can be eligible even when enabled=never is impossible, and a nh VMA must never show hugepage accounting. Shmem has its own shmem_enabled knob; file THP is yet another path.
  2. AnonHugePages is PMD-granular and bounded by PMD alignment. A huge page occupies a PMD-sized window that must lie entirely inside the VMA. A 512 KiB VMA can therefore never legitimately report 2 MiB of AnonHugePages, and the total can never exceed the sum of fully contained PMD windows. Most scripts only compare against Size, which hides real contradictions.
  3. smaps VMAs may have an empty pathname. Parsing the 16 fields with IFS=$'\t' silently collapses the empty path (tab is IFS whitespace), shifting every following field — producing garbage like FilePmdMapped=1 and bogus totals. A non-whitespace delimiter (0x1f) is required.
  4. Anon vs shmem vs file must be separated. AnonHugePages, ShmemPmdMapped and FilePmdMapped are different pools. tmpfs-backed paths (including /tmp in containers) are shmem, which requires consulting /proc/<pid>/mounts and taking the longest matching mount point.
  5. THPeligible is authoritative but scoped. It describes anon/shmem eligibility; it is not authoritative for page-cache/file THP.
  6. smaps and smaps_rollup are two reads. On a live process they can disagree purely because memory changed between reads. Only a stable before/after rollup pair turns a mismatch into a real inconsistency.
  7. Silent failure. A parser bug that drops VMAs yields plausible per-VMA checks; only the rollup reconciliation and the "impossible counter" check catch it. The tool must exit non-zero rather than print a wrong total.

The fix

Save as thp-report.sh (also written to ~/thp-report.sh), chmod +x it.

#!/usr/bin/env bash
#
# thp-report.sh -- derive the effective transparent-hugepage (THP) policy and
# hugepage accounting for every VMA of a live process.
#
# Data sources
#   /proc/<pid>/smaps
#   /proc/<pid>/smaps_rollup
#   /proc/<pid>/mounts            (tell tmpfs/shmem from regular files)
#   /proc/vmstat                  (THP fault/collapse/split counters)
#   /sys/kernel/mm/transparent_hugepage/{enabled,defrag,shmem_enabled,hpage_pmd_size}
#   /sys/kernel/mm/transparent_hugepage/khugepaged/*
#
# Exit codes
#   0  success, no contradiction found
#   1  usage / I/O error
#   2  contradiction between observed hugepage accounting and declared policy
#   3  required policy data missing (only with --strict)
#
# Requires bash >= 4.3 (associative arrays) and GNU coreutils.

set -uo pipefail
export LC_ALL=C

PROG=${0##*/}

# ---------------------------------------------------------------------------
# usage / argument parsing
# ---------------------------------------------------------------------------
usage() {
  cat <<'EOF'
Usage: thp-report.sh [OPTIONS] [PID]

Derive per-VMA effective THP policy and hugepage accounting for PID
(default: the current shell) and flag contradictions.

Options:
  -p, --pid PID       target PID (may also be given positionally)
  -s, --smaps FILE    read smaps from FILE instead of /proc/PID/smaps
  -r, --rollup FILE   read smaps_rollup from FILE
      --sysfs DIR     transparent_hugepage sysfs dir
                      (default /sys/kernel/mm/transparent_hugepage)
      --vmstat FILE   vmstat file (default /proc/vmstat)
      --mounts FILE   mounts file (default /proc/PID/mounts)
  -j, --json          emit JSON instead of the human report
  -q, --quiet         suppress the per-VMA table
      --strict        missing sysfs knobs are fatal (exit 3)
  -h, --help          this help

Exit codes: 0 ok, 1 usage/IO, 2 contradiction, 3 missing required data.
EOF
}

pid=""
smaps_file=""
rollup_file=""
sysfs_dir="/sys/kernel/mm/transparent_hugepage"
vmstat_file="/proc/vmstat"
mounts_file=""
json=0
quiet=0
strict=0

while (( $# )); do
  case "$1" in
    -p|--pid)    [[ $# -ge 2 ]] || { echo "$PROG: --pid needs an argument" >&2; exit 1; }; pid=$2; shift 2;;
    -s|--smaps)  [[ $# -ge 2 ]] || { echo "$PROG: --smaps needs an argument" >&2; exit 1; }; smaps_file=$2; shift 2;;
    -r|--rollup) [[ $# -ge 2 ]] || { echo "$PROG: --rollup needs an argument" >&2; exit 1; }; rollup_file=$2; shift 2;;
    --sysfs)     [[ $# -ge 2 ]] || { echo "$PROG: --sysfs needs an argument" >&2; exit 1; }; sysfs_dir=$2; shift 2;;
    --vmstat)    [[ $# -ge 2 ]] || { echo "$PROG: --vmstat needs an argument" >&2; exit 1; }; vmstat_file=$2; shift 2;;
    --mounts)    [[ $# -ge 2 ]] || { echo "$PROG: --mounts needs an argument" >&2; exit 1; }; mounts_file=$2; shift 2;;
    -j|--json)   json=1; shift;;
    -q|--quiet)  quiet=1; shift;;
    --strict)    strict=1; shift;;
    -h|--help)   usage; exit 0;;
    --)          shift; break;;
    -*)          echo "$PROG: unknown option: $1" >&2; usage >&2; exit 1;;
    *)           pid=$1; shift;;
  esac
done
if (( $# )); then
  [[ -z "$pid" ]] || { echo "$PROG: too many arguments" >&2; exit 1; }
  pid=$1; shift
fi

if [[ -z "$pid" ]]; then pid=$$; fi
case "$pid" in self) pid=$$;; esac
[[ "$pid" =~ ^[0-9]+$ ]] || { echo "$PROG: invalid pid '$pid'" >&2; exit 1; }
[[ -d "/proc/$pid" ]] || { echo "$PROG: no such process: $pid" >&2; exit 1; }

[[ -n "$smaps_file"  ]] || smaps_file="/proc/$pid/smaps"
[[ -n "$rollup_file" ]] || rollup_file="/proc/$pid/smaps_rollup"
[[ -n "$mounts_file" ]] || mounts_file="/proc/$pid/mounts"

[[ -r "$smaps_file" ]] || { echo "$PROG: cannot read $smaps_file" >&2; exit 1; }

# ---------------------------------------------------------------------------
# errors / warnings
# ---------------------------------------------------------------------------
ERRORS=()
WARNINGS=()
MISSING=()
DATA_MISSING=0
err()     { ERRORS+=("$1");  printf 'ERROR: %s\n'   "$1" >&2; }
warn()    { WARNINGS+=("$1"); printf 'WARNING: %s\n' "$1" >&2; }

# ---------------------------------------------------------------------------
# small numeric helpers (smaps reports kB; keep everything in bytes)
# ---------------------------------------------------------------------------
kb_to_bytes() {
  local v=${1%%[[:space:]]*}
  [[ "$v" =~ ^[0-9]+$ ]] || { echo 0; return; }
  echo $(( v * 1024 ))
}
to_num() {
  local v=${1%%[[:space:]]*}
  [[ "$v" =~ ^-?[0-9]+$ ]] || { echo 0; return; }
  echo "$v"
}
is_pow2() { local n=$1; (( n > 0 )) && (( (n & (n-1)) == 0 )); }

# ---------------------------------------------------------------------------
# sysfs / vmstat
# ---------------------------------------------------------------------------
read_knob() { # $1 = file; prints the selected (bracketed) token or ""
  local f=$1 v
  [[ -r "$f" ]] || { printf ''; return; }
  v=$(cat -- "$f" 2>/dev/null) || { printf ''; return; }
  if [[ "$v" =~ \[([^]]+)\] ]]; then
    printf '%s' "${BASH_REMATCH[1]}"
  else
    printf '%s' "${v%%[[:space:]]*}"
  fi
}

read_vmstat() { # $1 = key, $2 = file -> value or ""
  local key=$1 file=$2 line
  [[ -r "$file" ]] || { printf ''; return; }
  while read -r line; do
    case "$line" in
      "$key "[0-9]*) printf '%s' "${line#* }"; return;;
    esac
  done < "$file"
  printf ''
}

THP_ENABLED=$(read_knob "$sysfs_dir/enabled")
THP_DEFRAG=$(read_knob  "$sysfs_dir/defrag")
THP_SHMEM=$(read_knob   "$sysfs_dir/shmem_enabled")

PMD=""
if [[ -r "$sysfs_dir/hpage_pmd_size" ]]; then
  PMD=$(to_num "$(cat -- "$sysfs_dir/hpage_pmd_size" 2>/dev/null)")
fi
if [[ -z "$PMD" || "$PMD" == 0 ]]; then
  PMD=2097152
  warn "hpage_pmd_size unavailable under $sysfs_dir; assuming ${PMD} bytes"
fi
if ! is_pow2 "$PMD"; then
  err "hpage_pmd_size=$PMD is not a power of two"
  PMD=2097152
fi

# khugepaged tunables (best effort)
KH_PAGES_COLLAPSED=$(to_num "$(cat -- "$sysfs_dir/khugepaged/pages_collapsed" 2>/dev/null)")
KH_PAGES_SCANNED=$(to_num   "$(cat -- "$sysfs_dir/khugepaged/pages_scanned"   2>/dev/null)")
KH_FULL_SCANS=$(to_num      "$(cat -- "$sysfs_dir/khugepaged/full_scans"      2>/dev/null)")

VM_FAULT_ALLOC=$(read_vmstat thp_fault_alloc       "$vmstat_file")
VM_COLLAPSE_ALLOC=$(read_vmstat thp_collapse_alloc "$vmstat_file")
VM_FILE_ALLOC=$(read_vmstat thp_file_alloc         "$vmstat_file")
VM_SPLIT_PAGE=$(read_vmstat thp_split_page         "$vmstat_file")
VM_SPLIT_PMD=$(read_vmstat thp_split_pmd           "$vmstat_file")
VM_DEFERRED_SPLIT=$(read_vmstat thp_deferred_split_page "$vmstat_file")

# Missing sysfs knobs make the *effective policy* text less precise, but the
# kernel-provided THPeligible bit in smaps remains authoritative.  Fail loudly
# only when the caller asked for strict mode.
if (( strict )); then
  [[ -n "$THP_ENABLED" ]] || missing "missing $sysfs_dir/enabled"
  [[ -n "$THP_SHMEM"   ]] || missing "missing $sysfs_dir/shmem_enabled"
  [[ -n "$THP_DEFRAG"  ]] || missing "missing $sysfs_dir/defrag"
fi
if [[ -z "$THP_ENABLED" ]]; then warn "THP enabled knob unavailable; using THPeligible only"; fi
if [[ -z "$THP_SHMEM"   ]]; then warn "THP shmem_enabled knob unavailable"; fi

# ---------------------------------------------------------------------------
# mounts: build a table so we can tell tmpfs (shmem) from real files
# ---------------------------------------------------------------------------
declare -a MOUNT_PT=()
declare -a MOUNT_FS=()
load_mounts() {
  local file=$1 line mp fs
  [[ -r "$file" ]] || return 0
  while IFS= read -r line; do
    set -- $line
    mp=${2:-}; fs=${3:-}
    [[ -n "$mp" ]] || continue
    # unescape \040 \011 \012 \134 that the kernel uses in mount paths
    mp=${mp//\\040/ }
    mp=${mp//\\011/$'\t'}
    mp=${mp//\\012/$'\n'}
    mp=${mp//\\134/\\}
    MOUNT_PT+=("$mp")
    MOUNT_FS+=("$fs")
  done < "$file"
}
load_mounts "$mounts_file"

mount_fstype() { # longest matching mount point wins
  local p=$1 best_len=-1 best_fs=unknown i mp
  for i in "${!MOUNT_PT[@]}"; do
    mp=${MOUNT_PT[$i]}
    if [[ "$mp" == "/" ]]; then
      [[ "$p" == /* ]] || continue
      if (( ${#mp} > best_len )); then best_len=${#mp}; best_fs=${MOUNT_FS[$i]}; fi
    elif [[ "$p" == "$mp" || "$p" == "$mp"/* ]]; then
      if (( ${#mp} > best_len )); then best_len=${#mp}; best_fs=${MOUNT_FS[$i]}; fi
    fi
  done
  printf '%s' "$best_fs"
}

# ---------------------------------------------------------------------------
# smaps parser
#   Emits one US(0x1f)-separated record per VMA:
#   start end perms offset dev inode path size rss anon anonhuge shmempmd
#   filepmd thpelig swap vmflags
# ---------------------------------------------------------------------------
parse_smaps() {
  local file=$1
  local hdr_re='^([0-9a-fA-F]+)-([0-9a-fA-F]+)[[:space:]]+([-rwxps]{4})[[:space:]]+([0-9a-fA-F]+)[[:space:]]+([0-9a-fA-F]+:[0-9a-fA-F]+)[[:space:]]+([0-9]+)[[:space:]]*(.*)$'
  local fld_re='^([A-Za-z_]+):[[:space:]]+(.*)$'
  local -A f=()
  local -a order=(start end perms offset dev inode path size rss anon \
                  anonhuge shmempmd filepmd thpelig swap vmflags)
  local started=0 line key val k

  emit() {
    local -a out=()
    for k in "${order[@]}"; do out+=("${f[$k]:-}"); done
    # Use US (0x1f), a non-whitespace delimiter, so that an empty pathname does
    # not collapse and shift every following field.
    local IFS=$'\x1f'
    printf '%s\n' "${out[*]}"
  }

  while IFS= read -r line || [[ -n "$line" ]]; do
    if [[ "$line" =~ $hdr_re ]]; then
      (( started )) && emit
      started=1
      f=()
      f[start]=$((16#${BASH_REMATCH[1]}))
      f[end]=$((16#${BASH_REMATCH[2]}))
      f[perms]=${BASH_REMATCH[3]}
      f[offset]=${BASH_REMATCH[4]}
      f[dev]=${BASH_REMATCH[5]}
      f[inode]=${BASH_REMATCH[6]}
      f[path]=${BASH_REMATCH[7]//$'\t'/ }
      f[path]=${f[path]//$'\x1f'/ }
      f[size]=-1          # smaps_rollup has no Size: field
      f[rss]=0; f[anon]=0; f[anonhuge]=0; f[shmempmd]=0
      f[filepmd]=0; f[thpelig]=-1; f[swap]=0; f[vmflags]=""
      continue
    fi
    (( started )) || continue
    if [[ "$line" =~ $fld_re ]]; then
      key=${BASH_REMATCH[1]}; val=${BASH_REMATCH[2]}
      case "$key" in
        Size)            f[size]=$(kb_to_bytes "$val");;
        Rss)             f[rss]=$(kb_to_bytes "$val");;
        Anonymous)       f[anon]=$(kb_to_bytes "$val");;
        AnonHugePages)   f[anonhuge]=$(kb_to_bytes "$val");;
        ShmemPmdMapped)  f[shmempmd]=$(kb_to_bytes "$val");;
        FilePmdMapped)   f[filepmd]=$(kb_to_bytes "$val");;
        THPeligible)     f[thpelig]=$(to_num "$val");;
        Swap)            f[swap]=$(kb_to_bytes "$val");;
        VmFlags)         f[vmflags]=$val;;
      esac
    fi
  done < "$file"
  (( started )) && emit
}

# ---------------------------------------------------------------------------
# classification / policy
# ---------------------------------------------------------------------------
classify_vma() { # $1 path
  local p=$1
  case "$p" in
    "") echo anon; return;;
    "[heap]"|"[stack]") echo anon; return;;
    "[vdso]"|"[vvar]"|"[vvar_vclock]"|"[vsyscall]") echo special; return;;
    "[anon:"*"]") echo anon; return;;
    "/dev/zero"*|"memfd:"*|"/memfd:"*|"/SYSV"*|"/dev/shm/"*|"/run/shm/"*) echo shmem; return;;
  esac
  if [[ "$p" == /* ]]; then
    case "$(mount_fstype "$p")" in
      tmpfs|ramfs) echo shmem; return;;
    esac
  fi
  echo file
}

effective_policy() { # kind hg nh
  local kind=$1 hg=$2 nh=$3
  (( nh )) && { echo "never(nh)"; return; }
  case "$kind" in
    anon|file)
      case "$THP_ENABLED" in
        always)  (( hg )) && echo "always(hg)"  || echo "always";;
        madvise) (( hg )) && echo "madvise(hg)" || echo "madvise(ineligible)";;
        never)   echo "never(global)";;
        "")      (( hg )) && echo "eligible(hg,global-unknown)" || echo "global-unknown";;
        *)       (( hg )) && echo "$THP_ENABLED(hg)" || echo "$THP_ENABLED";;
      esac;;
    shmem)
      case "$THP_SHMEM" in
        always)      (( hg )) && echo "shmem-always(hg)" || echo "shmem-always";;
        within_size) (( hg )) && echo "shmem-within_size(hg)" || echo "shmem-within_size";;
        advise)      (( hg )) && echo "shmem-advise(hg)" || echo "shmem-advise(ineligible)";;
        never|deny)  echo "never(shmem)";;
        force)       echo "shmem-force";;
        "")          (( hg )) && echo "shmem-eligible(hg,global-unknown)" || echo "shmem-global-unknown";;
        *)           echo "shmem-$THP_SHMEM";;
      esac;;
    *) echo "n/a";;
  esac
}

predicted_eligible() { # kind hg nh
  local kind=$1 hg=$2 nh=$3
  (( nh )) && { echo 0; return; }
  case "$kind" in
    anon|file) (( hg )) && { echo 1; return; }
               [[ "$THP_ENABLED" == always ]] && { echo 1; return; }
               echo 0;;
    shmem) case "$THP_SHMEM" in
             always|within_size|force) echo 1;;
             advise) (( hg )) && echo 1 || echo 0;;
             *) echo 0;;
           esac;;
    *) echo 0;;
  esac
}

# PMD-aligned footprint fully contained in [start,end)
aligned_footprint() { # start end
  local start=$1 end=$2 first slots
  first=$(( (start + PMD - 1) / PMD * PMD ))
  if (( end > first )); then slots=$(( (end - first) / PMD )); else slots=0; fi
  echo $(( slots * PMD ))
}

# ---------------------------------------------------------------------------
# load smaps
# ---------------------------------------------------------------------------
declare -a V_START V_END V_PERMS V_OFFSET V_DEV V_INODE V_PATH V_KIND \
           V_POLICY V_HG V_NH V_ELIG V_SIZE V_RSS V_ANON V_AHUGE V_SHMEM \
           V_FILE V_SWAP V_ALIGN V_FLAGS

# Snapshot the rollup before reading smaps, so a stable before/after pair proves
# the process did not move while smaps was being collected.
ROLLUP_PRE=""
if [[ -r "$rollup_file" ]]; then
  ROLLUP_PRE=$(parse_smaps "$rollup_file" | head -n1)
fi

n=0
while IFS= read -r rec; do
  IFS=$'\x1f' read -r start end perms offset dev inode path size rss anon \
      anonhuge shmempmd filepmd thpelig swap vmflags <<<"$rec"

  kind=$(classify_vma "$path")
  # smaps always carries Size:; fall back to the address range if it does not.
  (( size < 0 )) && size=$(( end - start ))
  hg=0; nh=0
  [[ " $vmflags " == *" hg "* ]] && hg=1
  [[ " $vmflags " == *" nh "* ]] && nh=1
  [[ "$thpelig" == -1 ]] && thpelig=$(predicted_eligible "$kind" "$hg" "$nh")
  policy=$(effective_policy "$kind" "$hg" "$nh")
  align=$(aligned_footprint "$start" "$end")

  V_START[$n]=$start; V_END[$n]=$end; V_PERMS[$n]=$perms; V_OFFSET[$n]=$offset
  V_DEV[$n]=$dev; V_INODE[$n]=$inode; V_PATH[$n]=$path; V_KIND[$n]=$kind
  V_POLICY[$n]=$policy; V_HG[$n]=$hg; V_NH[$n]=$nh; V_ELIG[$n]=$thpelig
  V_SIZE[$n]=$size; V_RSS[$n]=$rss; V_ANON[$n]=$anon; V_AHUGE[$n]=$anonhuge
  V_SHMEM[$n]=$shmempmd; V_FILE[$n]=$filepmd; V_SWAP[$n]=$swap
  V_ALIGN[$n]=$align; V_FLAGS[$n]=$vmflags

  # ---- per-VMA contradiction checks -------------------------------------
  if (( nh )) && (( anonhuge + shmempmd + filepmd > 0 )); then
    err "VMA $(printf '%x-%x' "$start" "$end") has MADV_NOHUGEPAGE (nh) but hugepage accounting anon=$((anonhuge/1024))k shmem=$((shmempmd/1024))k file=$((filepmd/1024))k"
  fi
  if (( anonhuge > 0 )); then
    (( anonhuge % PMD == 0 )) || err "VMA $(printf '%x-%x' "$start" "$end") AnonHugePages=$((anonhuge/1024))k is not a multiple of PMD=$((PMD/1024))k"
    (( anonhuge <= align ))  || err "VMA $(printf '%x-%x' "$start" "$end") AnonHugePages=$((anonhuge/1024))k exceeds PMD-aligned anon footprint=$((align/1024))k"
    (( anonhuge <= anon ))   || err "VMA $(printf '%x-%x' "$start" "$end") AnonHugePages=$((anonhuge/1024))k exceeds Anonymous=$((anon/1024))k"
  fi
  if (( shmempmd > 0 )); then
    (( shmempmd % PMD == 0 )) || err "VMA $(printf '%x-%x' "$start" "$end") ShmemPmdMapped=$((shmempmd/1024))k is not a multiple of PMD"
    (( shmempmd <= align ))   || err "VMA $(printf '%x-%x' "$start" "$end") ShmemPmdMapped=$((shmempmd/1024))k exceeds PMD-aligned footprint=$((align/1024))k"
    [[ "$kind" == shmem ]]    || err "VMA $(printf '%x-%x' "$start" "$end") has ShmemPmdMapped but is classified '$kind' (path '$path')"
  fi
  if (( filepmd > 0 )); then
    (( filepmd % PMD == 0 )) || warn "VMA $(printf '%x-%x' "$start" "$end") FilePmdMapped=$((filepmd/1024))k is not a multiple of PMD=$((PMD/1024))k"
    (( filepmd <= align ))   || warn "VMA $(printf '%x-%x' "$start" "$end") FilePmdMapped=$((filepmd/1024))k exceeds PMD-aligned footprint=$((align/1024))k"
  fi
  # THPeligible only describes anonymous and shmem VMAs; it is not authoritative
  # for page-cache/file THP (FilePmdMapped).
  if (( thpelig == 0 )) && (( nh == 0 )); then
    if [[ "$kind" == anon && "$anonhuge" -gt 0 ]] || [[ "$kind" == shmem && "$shmempmd" -gt 0 ]]; then
      err "VMA $(printf '%x-%x' "$start" "$end") THPeligible=0 but hugepage accounting anon=$((anonhuge/1024))k shmem=$((shmempmd/1024))k"
    fi
  fi

  n=$((n+1))
done < <(parse_smaps "$smaps_file")

(( n > 0 )) || { echo "$PROG: no VMAs parsed from $smaps_file" >&2; exit 1; }

# ---------------------------------------------------------------------------
# totals
# ---------------------------------------------------------------------------
t_size=0 t_rss=0 t_anon=0 t_ahuge=0 t_shmem=0 t_file=0 t_swap=0
anon_aligned=0 anon_huge=0
for ((i=0; i<n; i++)); do
  t_size=$((t_size + V_SIZE[i]))
  t_rss=$((t_rss + V_RSS[i]))
  t_anon=$((t_anon + V_ANON[i]))
  t_ahuge=$((t_ahuge + V_AHUGE[i]))
  t_shmem=$((t_shmem + V_SHMEM[i]))
  t_file=$((t_file + V_FILE[i]))
  t_swap=$((t_swap + V_SWAP[i]))
  if [[ ${V_KIND[i]} == anon || ${V_ANON[i]} -gt 0 ]]; then
    anon_aligned=$((anon_aligned + V_ALIGN[i]))
  fi
  anon_huge=$((anon_huge + V_AHUGE[i]))
done

# aggregate: total AnonHugePages cannot exceed the total PMD-aligned anon footprint
if (( t_ahuge > anon_aligned )); then
  err "total AnonHugePages=$((t_ahuge/1024))k exceeds total PMD-aligned anon footprint=$((anon_aligned/1024))k"
fi
# aggregate: AnonHugePages is huge-page granular
(( t_ahuge % PMD == 0 )) || err "total AnonHugePages is not a multiple of PMD"

# reconcile against global khugepaged fault/collapse counters
alloc_total=0
for v in "$VM_FAULT_ALLOC" "$VM_COLLAPSE_ALLOC" "$VM_FILE_ALLOC"; do
  [[ -n "$v" ]] && alloc_total=$((alloc_total + v))
done
if [[ -r "$vmstat_file" ]]; then
  if [[ -z "$VM_FAULT_ALLOC$VM_COLLAPSE_ALLOC$VM_FILE_ALLOC" ]]; then
    warn "$vmstat_file has no thp_* counters; AnonHugePages cannot be reconciled against khugepaged"
  elif (( t_ahuge > 0 )) && (( alloc_total == 0 )); then
    err "process has AnonHugePages=$((t_ahuge/1024))k but vmstat reports no thp_fault_alloc/thp_collapse_alloc/thp_file_alloc"
  fi
else
  warn "vmstat unavailable at $vmstat_file; AnonHugePages not reconciled against khugepaged"
fi

# ---------------------------------------------------------------------------
# reconcile with smaps_rollup
# ---------------------------------------------------------------------------
rollup_present=0
rollup_stable=0
r_size=-1 r_rss=-1 r_anon=-1 r_ahuge=-1 r_shmem=-1 r_file=-1 r_swap=-1
if [[ -r "$rollup_file" ]]; then
  rec=$(parse_smaps "$rollup_file" | head -n1)
  if [[ -n "$rec" ]]; then
    rollup_present=1
    IFS=$'\x1f' read -r _ _ _ _ _ _ _ r_size r_rss r_anon r_ahuge r_shmem r_file _ r_swap _ <<<"$rec"
    # The pre-smaps and post-smaps rollups must agree for a mismatch with smaps

Offline/testing overrides: --smaps FILE --rollup FILE --sysfs DIR --vmstat FILE --mounts FILE.

Definitions used

  • PMD-aligned anon footprint of a VMA: floor((end - ceil(start/PMD)*PMD) / PMD) * PMD — the number of whole PMD windows that fit inside the VMA. Huge-page-backed bytes for a VMA can never exceed this.
  • alignment-aware fragmentation ratio: (anon_aligned_footprint - AnonHugePages) / anon_aligned_footprint. anon THP coverage is the same numerator over the raw Anonymous total, so sub-PMD anonymous bytes are not counted as fragmentation.
  • effective policy: nh ⇒ never; else for anon/file use enabled, for shmem use shmem_enabled, with hg marking madvise eligibility. THPeligible from smaps is preferred when present.
  • shmem classification: path under the longest-matching tmpfs/ramfs mount from /proc/<pid>/mounts, or a known shmem path (/dev/zero, memfd:, /SYSV, /dev/shm).

Exit codes

code meaning
0 no contradiction
1 usage / unreadable input
2 contradiction (policy vs accounting, alignment overflow, impossible counter, stable rollup mismatch)
3 --strict and a required sysfs knob is missing

4. The parser bug that motivated the non-whitespace delimiter

With IFS=$'\t', the empty-pathname 64 MiB VMA shifted fields and produced FilePmdMapped=1 plus a spurious THPeligible=0 error. The current parser round-trips the same VMA as:

6  000079e5dfe00000-000079e5e3e00000 anon rw-p madvise(hg) 1 64.00M 64.00M 64.00M 0B 0B rd wr mr mw me ac sd hg

This is verified by the real-process run in step 1 (RESULT: OK), where every empty-path anon VMA now reports anonhuge, shmempmd, filepmd and thpelig in the correct columns.
