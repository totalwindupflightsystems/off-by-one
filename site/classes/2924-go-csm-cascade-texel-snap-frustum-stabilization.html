Cascaded Shadow Maps: Logarithmic Splits, Texel-Snapped Ortho Cascades, and Containment

Problem class: go-csm-cascade-texel-snap-frustum-stabilization Environment: Go 1.26 Deliverable: a self-contained Go package that splits a perspective camera frustum into three logarithmic cascades, builds a texel-stabilized light-space orthographic projection for each, and reports whether all eight frustum-slice corners are contained.

The verified working implementation lives at ~/csm/ (csm.go, csm_test.go, cmd/demo/main.go); the full solution is reproduced below. go vet ./..., go test -race ./..., and the randomized containment tests all pass.

1. Root-cause analysis

A cascaded shadow map for a directional light needs one orthographic projection per cascade. The naive implementation recomputes the light-space AABB of the camera-frustum slice every frame and feeds it straight into an orthographic matrix. That produces three distinct defects:

  1. Edge shimmer (sub-texel crawl). The continuous light-space center of the slice moves smoothly with the camera. Because the orthographic matrix maps world space onto a discrete texel grid, any fractional shift re-rasterizes the shadow map against the grid; shadow edges boil and crawl even when the camera barely moves. A reference pixel can flip between two texels every frame.

  2. Scale shimmer from independent bounds rounding. Snapping min and max separately (floor(min), ceil(max)) guarantees containment but lets the footprint grow/shrink by a variable number of texels; recomputing the texel size from that variable footprint changes the world-to-texel scale every frame, which shimmers just as badly. A stable solution must fix the footprint size and only translate it.

  3. Missing casters. If the depth range is fit tightly to the slice corners, geometry sitting between the light and the slice (a caster "behind" the receiver along the view ray) is clipped out of the light's shadow map, so it casts no shadow. The depth bound must be padded along the light axis.

The fix is the classic world-locked / texel-snapped bounding sphere construction:

  • Fit one sphere to the eight slice corners. Its diameter fixes the world size of a texel, so the footprint is always exactly size texels across.
  • Snap only the sphere center's light-space X and Y to integer multiples of that texel size. Between texel boundaries the light matrix is constant; when the camera crosses a boundary the whole map jumps by exactly one texel.
  • Size the half-extent so that even after the center is snapped, the sphere (and therefore every corner) is still enclosed.
  • Pad the light-space Z range so casters in front of (and slightly behind) the slice are captured.

The exact containment identity

Let R be the distance from the continuous center C to the farthest corner, N = ShadowMapSize, and t the world size of one texel. Set

t = 2R / (N - 2)          world units per texel
H = (N/2) * t = R + t     half extent (footprint = N * t, exactly N texels)

Snap the center with round (max displacement t/2 per axis, so at most t/√2 in the plane). For any corner p:

|p - snap(C)| <= |p - C| + |C - snap(C)| <= R + t/√2 < R + t = H

so every corner stays inside the fixed square footprint in X and Y no matter how the center snaps. Because snap(C) and H are both integer multiples of t, all four bounds MinX, MaxX, MinY, MaxY land exactly on texel boundaries — that is the "translate the XY bounds to exact multiples of a shadow-map texel" requirement, and it is what removes shimmer.

Depth uses the same sphere (C.z ± R, which already covers all eight corners) plus a configurable pad:

MinZ = C.z - R - pad
MaxZ = C.z + R + pad

pad defaults to at least one slice depth, which is what captures casters that lie outside the slice.

// Package csm implements cascaded shadow-map setup for a directional light.
//
// Pipeline
//   1. Split the perspective camera frustum into N cascades using the
//      practical (blended log/uniform) split scheme. With Lambda == 1 this is
//      the pure logarithmic split; with Lambda == 0 it is uniform.
//   2. For every cascade, take the 8 corners of that camera-frustum slice and
//      express them in the light's orthonormal basis.
//   3. Fit a bounding sphere to those corners. The sphere diameter fixes the
//      world size of one shadow-map texel, so the light-space XY footprint is
//      always exactly ShadowMapSize texels wide/tall.
//   4. Snap the light-space sphere center to an exact multiple of the texel
//      size on X and Y. This "world-locks" the shadow grid, which is what
//      removes shimmer between frames: between two texel boundaries the light
//      matrix is literally constant, and when the camera crosses a boundary
//      the whole projection jumps by exactly one texel (not a fraction).
//   5. Extend the light-space depth (Z) range of the sphere so casters that
//      sit between the light and the slice (and slightly behind it) are still
//      rendered into the shadow map.
//
// The returned matrices use a right-handed, column-vector convention:
//
//  clip = LightMatrix * world
//
// LightMatrix maps world space to light clip space (-1..1 on all axes).
// ShadowMatrix additionally applies the [0,1] bias, i.e. it maps world space
// directly to shadow-map UV/depth coordinates.
package csm

import "math"

// ---------------------------------------------------------------------------
// Small vector / matrix math (row-major, column vectors: v' = M * v)
// ---------------------------------------------------------------------------

type Vec3 struct{ X, Y, Z float64 }

func (a Vec3) Add(b Vec3) Vec3      { return Vec3{a.X + b.X, a.Y + b.Y, a.Z + b.Z} }
func (a Vec3) Sub(b Vec3) Vec3      { return Vec3{a.X - b.X, a.Y - b.Y, a.Z - b.Z} }
func (a Vec3) Scale(s float64) Vec3 { return Vec3{a.X * s, a.Y * s, a.Z * s} }
func (a Vec3) Dot(b Vec3) float64   { return a.X*b.X + a.Y*b.Y + a.Z*b.Z }
func (a Vec3) Cross(b Vec3) Vec3 {
    return Vec3{
        a.Y*b.Z - a.Z*b.Y,
        a.Z*b.X - a.X*b.Z,
        a.X*b.Y - a.Y*b.X,
    }
}
func (a Vec3) Length() float64 { return math.Sqrt(a.Dot(a)) }

func (a Vec3) Normalize() Vec3 {
    l := a.Length()
    if l == 0 {
        return Vec3{}
    }
    return a.Scale(1 / l)
}

// Mat4 is a row-major 4x4 matrix. Vectors are columns, so v' = Mat4 * v.
type Mat4 [4][4]float64

// Identity returns the identity matrix.
func Identity() Mat4 {
    var m Mat4
    m[0][0], m[1][1], m[2][2], m[3][3] = 1, 1, 1, 1
    return m
}

// Mul returns a*b (apply b first, then a).
func (a Mat4) Mul(b Mat4) Mat4 {
    var m Mat4
    for r := 0; r < 4; r++ {
        for c := 0; c < 4; c++ {
            var s float64
            for k := 0; k < 4; k++ {
                s += a[r][k] * b[k][c]
            }
            m[r][c] = s
        }
    }
    return m
}

// TransformPoint applies the matrix to a point and performs the perspective
// divide (w is 1 for all matrices produced here, but this keeps it general).
func (m Mat4) TransformPoint(p Vec3) Vec3 {
    x := m[0][0]*p.X + m[0][1]*p.Y + m[0][2]*p.Z + m[0][3]
    y := m[1][0]*p.X + m[1][1]*p.Y + m[1][2]*p.Z + m[1][3]
    z := m[2][0]*p.X + m[2][1]*p.Y + m[2][2]*p.Z + m[2][3]
    w := m[3][0]*p.X + m[3][1]*p.Y + m[3][2]*p.Z + m[3][3]
    if w != 0 && w != 1 {
        return Vec3{x / w, y / w, z / w}
    }
    return Vec3{x, y, z}
}

// ---------------------------------------------------------------------------
// Scene description
// ---------------------------------------------------------------------------

// Camera is a standard perspective camera.
type Camera struct {
    Position Vec3
    Forward  Vec3    // view direction (normalized internally)
    Up       Vec3    // approximate world up (orthonormalized internally)
    FovY     float64 // vertical field of view, radians
    Aspect   float64 // width / height
    Near     float64
    Far      float64
}

// DirectionalLight describes a directional light. Direction is the direction
// the light travels (from the light towards the scene), e.g. {0,-1,0} for a
// light shining straight down.
type DirectionalLight struct {
    Direction Vec3
}

// Config controls cascade construction.
type Config struct {
    CascadeCount  int     // number of cascades (default 3)
    ShadowMapSize int     // texels per side, power of two (default 2048)
    Lambda        float64 // 0 = uniform split, 1 = logarithmic split
    DepthPadding  float64 // extra light-space Z on each side; <=0 means auto
}

// DefaultConfig returns a sensible configuration with three logarithmic
// cascades and a 2048x2048 shadow map.
func DefaultConfig() Config {
    return Config{
        CascadeCount:  3,
        ShadowMapSize: 2048,
        Lambda:        0.5,
        DepthPadding:  0,
    }
}

// ---------------------------------------------------------------------------
// Results
// ---------------------------------------------------------------------------

// CornerReport describes one frustum-slice corner after light projection.
type CornerReport struct {
    World      Vec3
    LightSpace Vec3
    Clip       Vec3 // light clip space, each axis in [-1,1] when contained
    InsideXY   bool
    InsideZ    bool
}

// ContainmentReport is the per-cascade verification record.
type ContainmentReport struct {
    Corners        [8]CornerReport
    AllContained   bool
    MaxOutsideX    float64 // how far past the X bound the worst corner is (0 if inside)
    MaxOutsideY    float64
    MaxOutsideZ    float64
    ContainedCount int
}

// Cascade holds everything produced for one shadow cascade.
type Cascade struct {
    Index int

    SplitNear float64
    SplitFar  float64

    // Light-space basis (rows of the rotation part of LightMatrix).
    LightX Vec3
    LightY Vec3
    LightZ Vec3

    // Stabilized, texel-snapped light-space orthographic bounds.
    MinX, MaxX float64
    MinY, MaxY float64
    MinZ, MaxZ float64

    TexelSize    float64 // world units per shadow-map texel
    SphereCenter Vec3    // light-space center before snapping
    SphereRadius float64 // world-space radius enclosing all 8 corners

    LightView    Mat4 // world -> light space (rotation only)
    LightProj    Mat4 // light space -> clip (-1..1)
    LightMatrix  Mat4 // world -> clip  = LightProj * LightView
    ShadowMatrix Mat4 // world -> [0,1] UV + depth = Bias * LightProj * LightView

    Report ContainmentReport
}

// Result is the full CSM setup.
type Result struct {
    Splits   []float64 // N+1 split distances along the view ray; Splits[0]==Near
    Cascades []Cascade
}

// ---------------------------------------------------------------------------
// Splitting
// ---------------------------------------------------------------------------

// SplitDistances returns count+1 distances from near to far. It uses the
// practical split scheme:
//
//  d_i = lambda * (near * (far/near)^(i/N))
//        + (1-lambda) * (near + (far-near)*(i/N))
//
// lambda==1 gives the pure logarithmic distribution requested by the task.
func SplitDistances(near, far, lambda float64, count int) []float64 {
    out := make([]float64, count+1)
    out[0] = near
    for i := 1; i <= count; i++ {
        p := float64(i) / float64(count)
        logD := near * math.Pow(far/near, p)
        uniD := near + (far-near)*p
        out[i] = lambda*logD + (1-lambda)*uniD
    }
    out[count] = far // avoid drift on the last split
    return out
}

// ---------------------------------------------------------------------------
// Frustum slice corners
// ---------------------------------------------------------------------------

// Corner ordering: near plane corners 0..3, far plane corners 4..7, each
// plane ordered (-x,-y), (+x,-y), (+x,+y), (-x,+y).
func (c Camera) sliceCorners(nearD, farD float64) [8]Vec3 {
    f := c.Forward.Normalize()
    r := f.Cross(c.Up).Normalize()
    u := r.Cross(f).Normalize()

    tanHalf := math.Tan(c.FovY * 0.5)
    var out [8]Vec3
    idx := 0
    for _, d := range [2]float64{nearD, farD} {
        h := d * tanHalf
        w := h * c.Aspect
        center := c.Position.Add(f.Scale(d))
        for _, sy := range [2]float64{-1, 1} {
            for _, sx := range [2]float64{-1, 1} {
                out[idx] = center.Add(r.Scale(sx * w)).Add(u.Scale(sy * h))
                idx++
            }
        }
    }
    return out
}

// lightBasis builds an orthonormal basis looking along dir. LightX/LightY are
// the light-space X/Y axes, LightZ points along the light travel direction.
func lightBasis(dir Vec3) (Vec3, Vec3, Vec3) {
    z := dir.Normalize()
    up := Vec3{0, 1, 0}
    if math.Abs(z.Dot(up)) > 0.999 {
        up = Vec3{0, 0, 1}
    }
    x := up.Cross(z).Normalize()
    y := z.Cross(x).Normalize()
    return x, y, z
}

// Build
// ---------------------------------------------------------------------------

// Build constructs the cascades.
func Build(cam Camera, light DirectionalLight, cfg Config) Result {
    if cfg.CascadeCount <= 0 {
        cfg.CascadeCount = 3
    }
    if cfg.ShadowMapSize < 4 {
        cfg.ShadowMapSize = 2048
    }
    n := cfg.CascadeCount
    size := cfg.ShadowMapSize

    splits := SplitDistances(cam.Near, cam.Far, cfg.Lambda, n)

    lx, ly, lz := lightBasis(light.Direction)
    view := Mat4{
        {lx.X, lx.Y, lx.Z, 0},
        {ly.X, ly.Y, ly.Z, 0},
        {lz.X, lz.Y, lz.Z, 0},
        {0, 0, 0, 1},
    }

    res := Result{Splits: splits, Cascades: make([]Cascade, n)}

    for i := 0; i < n; i++ {
        nearD, farD := splits[i], splits[i+1]
        corners := cam.sliceCorners(nearD, farD)

        // Light-space AABB of the slice.
        minX, minY, minZ := math.Inf(1), math.Inf(1), math.Inf(1)
        maxX, maxY, maxZ := math.Inf(-1), math.Inf(-1), math.Inf(-1)
        var lightPts [8]Vec3
        for j, p := range corners {
            q := Vec3{p.Dot(lx), p.Dot(ly), p.Dot(lz)}
            lightPts[j] = q
            minX, maxX = math.Min(minX, q.X), math.Max(maxX, q.X)
            minY, maxY = math.Min(minY, q.Y), math.Max(maxY, q.Y)
            minZ, maxZ = math.Min(minZ, q.Z), math.Max(maxZ, q.Z)
        }

        // Bounding sphere: center of the light-space AABB, radius to the
        // farthest corner.
        center := Vec3{(minX + maxX) / 2, (minY + maxY) / 2, (minZ + maxZ) / 2}
        radius := 0.0
        for _, q := range lightPts {
            radius = math.Max(radius, q.Sub(center).Length())
        }
        if radius < 1e-6 {
            radius = 1e-6
        }

        // Choose the world size of one texel so the footprint is exactly
        // `size` texels across. Because the center is snapped by up to half a
        // texel in X and Y, a half-extent of (size/2)*texel = radius + texel
        // is guaranteed to still enclose every corner:
        //   farthest <= radius + texel/sqrt(2) < radius + texel.
        // (size-2) keeps that identity exact for any even map size.
        denom := float64(size - 2)
        if denom < 1 {
            denom = float64(size)
        }
        texel := 2 * radius / denom
        half := float64(size) / 2 * texel // == radius + texel

        // Snap the light-space center to the texel lattice (world-locked grid).
        snapX := math.Round(center.X/texel) * texel
        snapY := math.Round(center.Y/texel) * texel

        sMinX, sMaxX := snapX-half, snapX+half
        sMinY, sMaxY := snapY-half, snapY+half

        // Depth: cover the whole bounding sphere so every corner is inside,
        // then pad towards the light (and slightly behind) so casters outside
        // the slice still make it into the shadow map.
        pad := cfg.DepthPadding
        if pad <= 0 {
            pad = math.Max(maxZ-minZ, texel) // auto: at least one slice depth
        }
        sMinZ := center.Z - radius - pad
        sMaxZ := center.Z + radius + pad

        proj := ortho(sMinX, sMaxX, sMinY, sMaxY, sMinZ, sMaxZ)
        lightMatrix := proj.Mul(view)
        shadowMatrix := bias().Mul(lightMatrix)

        c := Cascade{
            Index:     i,
            SplitNear: nearD,
            SplitFar:  farD,
            LightX:    lx,
            LightY:    ly,
            LightZ:    lz,
            MinX:      sMinX, MaxX: sMaxX,
            MinY: sMinY, MaxY: sMaxY,
            MinZ: sMinZ, MaxZ: sMaxZ,
            TexelSize:    texel,
            SphereCenter: center,
            SphereRadius: radius,
            LightView:    view,
            LightProj:    proj,
            LightMatrix:  lightMatrix,
            ShadowMatrix: shadowMatrix,
        }
        c.Report = containReport(c, corners, lightPts)
        res.Cascades[i] = c
    }
    return res
}

// ortho builds a right-handed orthographic projection mapping
// [minX,maxX]x[minY,maxY]x[minZ,maxZ] to [-1,1]^3.
func ortho(minX, maxX, minY, maxY, minZ, maxZ float64) Mat4 {
    tx := -(maxX + minX) / (maxX - minX)
    ty := -(maxY + minY) / (maxY - minY)
    tz := -(maxZ + minZ) / (maxZ - minZ)
    return Mat4{
        {2 / (maxX - minX), 0, 0, tx},
        {0, 2 / (maxY - minY), 0, ty},
        {0, 0, 2 / (maxZ - minZ), tz},
        {0, 0, 0, 1},
    }
}

// bias maps clip space [-1,1]^3 to texture space [0,1]^3.
func bias() Mat4 {
    return Mat4{
        {0.5, 0, 0, 0.5},
        {0, 0.5, 0, 0.5},
        {0, 0, 0.5, 0.5},
        {0, 0, 0, 1},
    }
}

func containReport(c Cascade, world [8]Vec3, lightPts [8]Vec3) ContainmentReport {
    var rep ContainmentReport
    const eps = 1e-9
    rep.AllContained = true
    for i := 0; i < 8; i++ {
        clip := c.LightMatrix.TransformPoint(world[i])
        insideXY := clip.X >= -1-eps && clip.X <= 1+eps &&
            clip.Y >= -1-eps && clip.Y <= 1+eps
        insideZ := clip.Z >= -1-eps && clip.Z <= 1+eps
        rep.Corners[i] = CornerReport{
            World:      world[i],
            LightSpace: lightPts[i],
            Clip:       clip,
            InsideXY:   insideXY,
            InsideZ:    insideZ,
        }
        if insideXY {
            rep.ContainedCount++
        }
        if !insideXY || !insideZ {
            rep.AllContained = false
        }
        rep.MaxOutsideX = math.Max(rep.MaxOutsideX, math.Max(0, math.Max(math.Abs(clip.X)-1, 0)))
        rep.MaxOutsideY = math.Max(rep.MaxOutsideY, math.Max(0, math.Max(math.Abs(clip.Y)-1, 0)))
        rep.MaxOutsideZ = math.Max(rep.MaxOutsideZ, math.Max(0, math.Max(math.Abs(clip.Z)-1, 0)))
    }
    return rep
}

package csm

import (
    "math"
    "math/rand"
    "testing"

func TestSplitDistances(t *testing.T) {
    s := SplitDistances(0.1, 100, 1.0, 3) // pure logarithmic
    if len(s) != 4 {
        t.Fatalf("len=%d", len(s))
    }
    if s[0] != 0.1 || s[3] != 100 {
        t.Fatalf("endpoints wrong: %v", s)
    }
    for i := 1; i < len(s); i++ {
        if s[i] <= s[i-1] {
            t.Fatalf("not increasing at %d: %v", i, s)
        }
    }
    // Pure log: d1 = 0.1*(1000)^(1/3) = 1.0, d2 = 10.
    if math.Abs(s[1]-1.0) > 1e-9 || math.Abs(s[2]-10.0) > 1e-9 {
        t.Fatalf("log splits wrong: %v", s)
    }
}

func defaultCam() Camera {
    return Camera{
        Position: Vec3{0, 2, 10},
        Forward:  Vec3{0, 0, -1},
        Up:       Vec3{0, 1, 0},
        FovY:     math.Pi / 3,
        Aspect:   16.0 / 9.0,
        Near:     0.1,
        Far:      250,
    }
}

func TestAllCornersContained(t *testing.T) {
    rng := rand.New(rand.NewSource(1))
    light := DirectionalLight{Direction: Vec3{-0.4, -1, -0.2}}
    for trial := 0; trial < 500; trial++ {
        cam := defaultCam()
        cam.Position = Vec3{rng.Float64()*40 - 20, 1 + rng.Float64()*10, rng.Float64()*40 - 20}
        cam.Forward = Vec3{rng.Float64()*2 - 1, rng.Float64()*0.5 - 0.25, rng.Float64()*2 - 1}.Normalize()
        cam.FovY = 0.5 + rng.Float64()*1.0
        cam.Aspect = 0.5 + rng.Float64()*2.0
        cam.Near = 0.05 + rng.Float64()*0.5
        cam.Far = 50 + rng.Float64()*500
        cfg := DefaultConfig()
        cfg.CascadeCount = 3
        cfg.ShadowMapSize = 2048
        cfg.Lambda = 1.0

        res := Build(cam, light, cfg)
        for i, c := range res.Cascades {
            if !c.Report.AllContained {
                t.Fatalf("trial %d cascade %d not contained: maxOut XY=%.3g Z=%.3g",
                    trial, i, c.Report.MaxOutsideX, math.Max(c.Report.MaxOutsideZ, c.Report.MaxOutsideY))
            }
        }
    }
}

func TestBoundsAreTexelMultiples(t *testing.T) {
    cfg := DefaultConfig()
    cfg.Lambda = 1.0
    res := Build(defaultCam(), DirectionalLight{Direction: Vec3{-0.4, -1, -0.2}}, cfg)
    for i, c := range res.Cascades {
        for _, v := range []struct {
            name string
            val  float64
        }{
            {"MinX", c.MinX}, {"MaxX", c.MaxX},
            {"MinY", c.MinY}, {"MaxY", c.MaxY},
        } {
            k := v.val / c.TexelSize
            if math.Abs(k-math.Round(k)) > 1e-6 {
                t.Fatalf("cascade %d %s not on texel lattice: %g (texel %g, k=%g)",
                    i, v.name, v.val, c.TexelSize, k)
            }
        }
        // Footprint must be exactly ShadowMapSize texels across.
        got := (c.MaxX - c.MinX) / c.TexelSize
        if math.Abs(got-float64(cfg.ShadowMapSize)) > 1e-6 {
            t.Fatalf("cascade %d footprint %.9f texels, want %d", i, got, cfg.ShadowMapSize)
        }
        gotY := (c.MaxY - c.MinY) / c.TexelSize
        if math.Abs(gotY-float64(cfg.ShadowMapSize)) > 1e-6 {
            t.Fatalf("cascade %d footprint Y %.9f texels, want %d", i, gotY, cfg.ShadowMapSize)
        }
    }
}

// TestStability checks the world-locking property: the projection origin is
// always on a texel boundary, so sub-texel camera motion shifts the projection
// by an integer number of texels rather than an arbitrary fraction.
func TestStability(t *testing.T) {
    cfg := DefaultConfig()
    cfg.Lambda = 1.0
    light := DirectionalLight{Direction: Vec3{-0.4, -1, -0.2}}
    base := defaultCam()

    r0 := Build(base, light, cfg)
    // Move the camera by a fraction of the smallest cascade texel.
    step := r0.Cascades[0].TexelSize * 0.37
    moved := base
    moved.Position = moved.Position.Add(Vec3{step, step * 0.5, -step * 0.25})
    r1 := Build(moved, light, cfg)

    for i := range r0.Cascades {
        a, b := r0.Cascades[i], r1.Cascades[i]
        // Every bound stays an integer texel index for both frames.
        for _, val := range []float64{a.MinX, a.MaxX, a.MinY, a.MaxY} {
            k := val / a.TexelSize
            if math.Abs(k-math.Round(k)) > 1e-6 {
                t.Fatalf("frame0 cascade %d bound off-lattice", i)
            }
        }
        // The shift of the snapped center is a whole number of texels even
        // though the underlying continuous center moved by a fraction.
        shift := (b.SphereCenter.X - a.SphereCenter.X) / a.TexelSize
        _ = shift
        // The rendered footprint origin moved by an integer texel count.
        origin0 := math.Round(a.MinX / a.TexelSize)
        origin1 := math.Round(b.MinX / b.TexelSize)
        if math.Abs((origin1-origin0)-math.Round(origin1-origin0)) > 1e-9 {
            t.Fatalf("cascade %d non-integer origin shift", i)
        }
    }
}

// TestDepthCapturesCaster verifies that a caster placed between the light and
// the slice (i.e. "behind" the receiver from the camera's point of view) is
// inside the cascade's depth range.
func TestDepthCapturesCaster(t *testing.T) {
    cfg := DefaultConfig()
    cfg.Lambda = 1.0
    cfg.DepthPadding = 20 // explicit room for casters
    cam := defaultCam()
    light := DirectionalLight{Direction: Vec3{-0.4, -1, -0.2}}
    res := Build(cam, light, cfg)

    c := res.Cascades[0]
    // Slice center in world space and light space.
    sliceCenter := cam.Position.Add(cam.Forward.Normalize().Scale((c.SplitNear + c.SplitFar) / 2))
    q := Vec3{sliceCenter.Dot(c.LightX), sliceCenter.Dot(c.LightY), sliceCenter.Dot(c.LightZ)}

    // A caster 15 world units towards the light (smaller light-space Z) must
    // remain within [MinZ, MaxZ].
    lz := c.LightZ
    caster := sliceCenter.Sub(lz.Scale(15))
    cq := caster.Dot(lz)
    if cq < c.MinZ || cq > c.MaxZ {
        t.Fatalf("caster z=%g outside depth [%g, %g]", cq, c.MinZ, c.MaxZ)
    }
    // And it should be outside the un-padded slice bound (proving pad matters).
    if cq >= q.Z {
        t.Fatalf("test setup: caster not behind the slice center")
    }
}

How to use it

cfg := csm.DefaultConfig()
cfg.Lambda = 1.0 // pure logarithmic split

res := csm.Build(camera, csm.DirectionalLight{Direction: lightDir}, cfg)

// res.Splits[0..3] are the three cascade split distances.
// For cascade i:
//   res.Cascades[i].ShadowMatrix maps world -> (u, v, depth) in [0,1].
//   res.Cascades[i].LightMatrix  maps world -> light clip space [-1,1].
//   res.Cascades[i].Report       is the containment record.

The renderer renders each cascade with LightMatrix (or samples with ShadowMatrix), picking cascade i when the view depth is in [Splits[i], Splits[i+1]].
