Answer 1

Done. I diagnosed the flake against the actual repo (cloned to /tmp/grrepo) and implemented + verified a fix. The deliverable is at /workspace/solution.md (also copied to ~/solution.md and /tmp/grrepo/SOLUTION-POC-61.md).

Root cause

tests/test_resolution.py::test_live_smoke_jev_resolution makes a real OpenRouter call and is placed in the suite that judge tier-1 runs:

  • engine/pipeline.py::tier1_plan() uses guards.test_command verbatim and ignores test_mode: diff, so every judge runs the full suite. The env has GITREINS_OPENROUTER_KEY (tier-2 needs it), so the live test executes.
  • Each gitreins task complete is its own process; addopts = "-n 4" only serializes within one pytest process. N concurrent judges → N simultaneous live calls → rate-limit/5xx → pytest -x exits non-zero.
  • A tier-1 failure short-circuits tier-2. That's the FAIL/re-run cost.

The defect is a category error: a non-deterministic, host-global egress smoke inside the deterministic gate.

Fix (5 files)

  1. tests/test_resolution.py — add @pytest.mark.live.
  2. pyproject.toml — register the live marker.
  3. engine/pipeline.py:
  4. _run_script_step now merges per-step env over the sanitized env;
  5. tier1_plan() stamps the tests step with env={"GITREINS_TIER1": "1"}.
  6. tests/conftest.py — when GITREINS_TIER1=1, skip live-marked tests (pytest_collection_modifyitems); for any live test that does run, take a per-repo flock and skip if another process holds it (pytest_runtest_setup/teardown).
  7. tests/test_v081_fixes.py — regression assertion on the tier-1 tests step env (no new test functions, so the docs-drift count stays green).

Rejected retry-only fix (c): it doubles cost, can mask real regressions, and adds more state than the deterministic exclusion.

Verification performed

  • pytest::test_live_smoke collected normally without the env var; skipped with reason live/egress test excluded from judge tier-1 (DF-GITREINS-POC-61) when GITREINS_TIER1=1, even with a key present.
  • Whole tests/test_resolution.py under tier-1: 127 passed, 1 skipped.
  • tier1_plan() emits env={'GITREINS_TIER1': '1'} and the runner injects it into the child (TIER1=1).
  • Two concurrent live processes: first passes, second SKIPs on the lock.
  • tests/test_v081_fixes.py + tests/test_pipeline.py: 122 passed; docs-drift check green (2436 tests / 68 files); ruff format --check and ruff check clean.
