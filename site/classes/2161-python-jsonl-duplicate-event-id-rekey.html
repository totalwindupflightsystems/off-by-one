Root cause

Two defects combined: 1. Writer race: max(existing_ids) + 1 was computed outside the lock; the private lock only covered the write, so concurrent writers minted identical ids. 2. Two corruption shapes requiring different repairs: byte-identical re-appends (same id + same bytes → drop later copies) vs. distinct-content collisions (same id, different bytes → re-key later copies).

Verified results

{"dropped_identical": 3, "rekeyed": 5, "lines_in": 23, "lines_out": 20,
 "global_max_id": 15, "next_id": 21, "unique_ids_in": 15}
$ python3 audit_jsonl.py audit events.jsonl        -> exit 0, 0 duplicates
$ python3 audit_jsonl.py reconcile *.bak events.jsonl -> exit 0, all logical events preserved

The raw diff shows exactly 3 whole-line deletions and 5 lines changed on the id field only, confirming byte preservation and order. All 5 regression tests pass.
