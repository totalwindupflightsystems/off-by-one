Pangenome Minimizer Chaining with Structural Variants — Diagnosis and Verified Fix

Problem class: python-20261012-pangenome-minimizer-chaining-with-structural-variants Environment: Python 3.11+ (verified on 3.14) · Dependencies: standard library only

Artifacts written to ~/: pangenome_chain.py, test_pangenome_chain.py, SOLUTION.md.

1. What the task requires

Given millions of noisy long reads, a colored variation graph, and a memory cap:

  1. compute a maximum-scoring chain of minimizer anchors;
  2. allow the chain to cross bounded structural-variant (SV) bubbles;
  3. never double-count repeated sequence (a read base must be consumed once);
  4. preserve sample provenance (colored graph);
  5. handle reverse-complement paths;
  6. run in sub-quadratic time with a correctness argument for the pruning.

A "solve the problem" answer is therefore a small, verifiable system, not a one-line patch.

2. Root-cause analysis

# Naive approach Root cause of failure Symptom
RC1 Compare every anchor pair (O(n^2)) For millions of anchors ~10^12 pairs, and the DP predecessor matrix is O(n^2) memory Timeout / OOM
RC2 Greedily extend over read coordinate only A repetitive read minimizer maps to several graph positions; a read base can be reused Chimeric / inflated alignments
RC3 Linearise by node id / DFS and 1-D chain Parallel bubble branches are alternatives; nothing forbids A then B Path no sample carries
RC4 Ignore orientation Half of all mappings vanish Reads lost / wrong loci
RC5 Python set of sample ids per anchor/chain Millions of sets blow the cap; provenance lost on merge OOM / provenance dropped
RC6 Buffer all anchors for all reads Memory grows with corpus, not graph Cap violated

RC1 — the key decomposition

The minimizer-chain objective is

score(chain) = sum_i w_i  -  lambda * sum over j->i of ( (r_i-r_j) + (g_i-g_j) )

where r is read coordinate and g graph coordinate. For current anchor i:

max_j [ f[j] - lambda*((r_i-r_j)+(g_i-g_j)) ]
  = max_j [ f[j] + lambda*(r_j+g_j) ]  -  lambda*(r_i+g_i)
  = max_j [ V_j ]                      -  lambda*(r_i+g_i)

The term -lambda*(r_i+g_i) is identical for every predecessor, so the DP becomes range-max queries of V_j = f[j]+lambda*(r_j+g_j) over graph coordinates. A segment tree gives O(n log n) time and O(n) memory.

RC2 — read-overlap invariant

Consecutive anchors are feasible only if r_i - r_j >= k (k = minimizer length). This is exact, enforced with delayed two-pointer insertion: j enters the tree only once r_i >= r_j + k. Every read base is consumed at most once.

RC3 — bubbles

Bubble branches get (bubble_id, branch_id) tags; a transition inside the same bubble that changes branch is forbidden. Bubbles are bounded, so the conflicting set is tiny; per-branch buckets give exact same-branch predecessors, and the segment-tree query is split around the bubble span to exclude other branches.

RC4 — reverse complement

Minimizers are canonical min(kmer, revcomp(kmer)) with a strand bit. Read maps forward iff s_r*s_g == +1; otherwise the read coordinate is mirrored r = L-k-p, restoring monotonicity in both r and g. Anchors chain per orientation, best wins.

RC5 — provenance

Colour sets are big-int bitmasks (one bit per sample); a chain's provenance is the AND of its anchors' masks — exactly the samples containing the whole path.

RC6 — memory cap

stream_reads consumes one read at a time; only the graph index + current read anchors are resident. Minimizers occurring more than max_occ times are dropped.

3. Design of the fix

reads --minimizers--> canonical k-mers --graph index--> anchors (r, g, strand, colors)
                                                              |
                                       split by strand -------+
                                                              v

#!/usr/bin/env python3
"""
pangenome_chain.py
==================

Reference implementation for:

    Maximum-scoring chaining of minimizer anchors over a *colored variation
    graph*, under a memory cap, tolerating bounded structural-variant (SV)
    bubbles, preserving sample provenance, and handling reverse-complement
    read orientations.

Design summary
--------------
* Minimizers are canonical k-mers (min(kmer, revcomp(kmer))); the strand bit
  records orientation.  A monotonic deque computes them in O(len(seq)).
* A colored variation graph is linearised with a topological prefix sum so
  that every directed path has strictly increasing graph coordinates
  ``gidx``.  Parallel bubble branches therefore occupy disjoint coordinate
  ranges.
* Anchors are points (r, g) with r = read coordinate and g = graph coordinate.
  A chain is an increasing subsequence in both coordinates.
* Score model:  chain score = sum(anchor weights) - lambda * Manhattan gap,
  where the gap between consecutive anchors j -> i is
  (r_i - r_j) + (g_i - g_j).
* The DP is O(n log n) because the predecessor term decomposes:
        f[i] = w_i - lambda*(r_i+g_i) + max_j (f[j] + lambda*(r_j+g_j))
  and the max is a prefix/range maximum over graph coordinates, maintained in
  a segment tree.
* Pruning (the sub-quadratic guarantee): predecessor j is *dominated* by k if
  r_j <= r_k, g_j <= g_k and V_j <= V_k, where V = f + lambda*(r+g).  Only the
  per-coordinate maximum V is retained, so a segment tree with n leaves answers
  every query and the total work is O(n log n).  See `proof_domination()`.
* Double counting is prevented by the read-overlap constraint
  ``r_i - r_j >= k``: a read base is used by at most one anchor.  It is
  implemented with delayed insertion (a two-pointer sweep), so it stays exact
  and does not change the asymptotic cost.
* Bubbles: anchors carry (bubble_id, branch_id).  A transition that stays
  inside the same bubble but changes branch is forbidden.  The segment-tree
  query is split around the bubble's coordinate range and a per-branch maximum
  supplies same-branch predecessors.
* Provenance: node colour sets are represented as Python big-int bitmasks.
  The chain provenance is the AND (intersection) of its anchors' masks, which
  is exactly the set of samples whose graph contains the whole chain path.

Author: reference solution
"""

from __future__ import annotations

import zlib
from bisect import bisect_left, bisect_right
from collections import defaultdict, deque
from dataclasses import dataclass
from typing import Dict, Iterable, List, Optional, Sequence, Tuple

NEG = float("-inf")

# ---------------------------------------------------------------------------
# DNA helpers
# ---------------------------------------------------------------------------

_COMP = str.maketrans("ACGTNacgtn", "TGCANtgcan")


def revcomp(s: str) -> str:
    """Reverse complement of a DNA string."""
    return s.translate(_COMP)[::-1]


def canonical_kmer(kmer: str) -> Tuple[str, int]:
    """Return (canonical kmer, strand).

    strand == +1  iff  kmer is equal to its canonical form.
    strand == -1  iff  the reverse complement is the canonical form.
    Canonical form is invariant under reverse complementation.
    """
    rc = revcomp(kmer)
    if kmer <= rc:
        return kmer, 1
    return rc, -1


def hash_kmer(kmer: str) -> int:
    """Stable, fast, process-independent hash (CRC32 of the ASCII bytes)."""
    return zlib.crc32(kmer.encode("ascii"))


# ---------------------------------------------------------------------------
# Minimizers (O(n) sliding-window minimum)
# ---------------------------------------------------------------------------


def minimizers(seq: str, k: int, w: int, hash_fn=hash_kmer):
    """Return minimizers as a list of (pos, canonical_kmer, strand, h).

    The window contains the hashes of ``w`` consecutive k-mers.  Ties are
    broken by the left-most position, matching the usual minimizer definition
    min by (hash, position).
    """
    n = len(seq)
    if k <= 0 or w <= 0 or n < k:
        return []

    m = n - k + 1
    hs = [0] * m
    strands = [0] * m
    cans: List[str] = [""] * m
    for i in range(m):
        c, s = canonical_kmer(seq[i : i + k])
        cans[i] = c
        strands[i] = s
        hs[i] = hash_fn(c)

    out: List[Tuple[int, str, int, int]] = []
    dq: deque[int] = deque()  # indices, hashes increasing from front
    for i in range(m):
        # Keep the minimum by (hash, position): pop strictly larger hashes only,
        # so an earlier equal-hash element wins.
        while dq and hs[dq[-1]] > hs[i]:
            dq.pop()
        dq.append(i)
        while dq[0] <= i - w:
            dq.popleft()
        if i >= w - 1:
            j = dq[0]
            if not out or out[-1][0] != j:
                out.append((j, cans[j], strands[j], hs[j]))
    return out


def minimizers_naive(seq: str, k: int, w: int, hash_fn=hash_kmer):
    """Reference O(n*w) minimizer implementation, used only for tests."""
    n = len(seq)
    if n < k:
        return []
    m = n - k + 1
    recs = []
    for i in range(m):
        c, s = canonical_kmer(seq[i : i + k])
        recs.append((hash_fn(c), i, c, s))
    out = []
    for start in range(m - w + 1):
        best = min(recs[start : start + w], key=lambda x: (x[0], x[1]))
        if not out or out[-1][0] != best[1]:
            out.append((best[1], best[2], best[3], best[0]))
    return out


# ---------------------------------------------------------------------------
# Colored variation graph
# ---------------------------------------------------------------------------


@dataclass
class Node:
    seq: str
    colors: int = 0  # bitmask of sample ids


class ColoredVariationGraph:
    """A small, explicit colored variation graph.

    Parameters
    ----------
    nodes : dict[int, Node]
    edges : iterable of (u, v) directed edges
    """

    def __init__(self, nodes: Dict[int, Node], edges: Iterable[Tuple[int, int]]):
        self.nodes = dict(nodes)
        self.edges = list(dict.fromkeys(edges))  # dedup, keep order
        self.adj: Dict[int, List[int]] = defaultdict(list)
        for u, v in self.edges:
            self.adj[u].append(v)
        self.gidx: Dict[int, int] = {}
        self.glen: Dict[int, int] = {}

    # -- linearisation -----------------------------------------------------
    def topological_order(self) -> List[int]:
        indeg = {v: 0 for v in self.nodes}
        for u, v in self.edges:
            indeg.setdefault(v, 0)
            indeg[v] += 1
        dq = deque(sorted(v for v in self.nodes if indeg[v] == 0))
        order: List[int] = []
        while dq:
            u = dq.popleft()
            order.append(u)
            for v in sorted(self.adj[u]):
                indeg[v] -= 1
                if indeg[v] == 0:
                    dq.append(v)
        if len(order) != len(self.nodes):
            raise ValueError("variation graph is not a DAG; unfold cycles first")
        return order

    def linearize(self) -> List[int]:
        """Assign strictly increasing coordinates along every path.

        ``gidx[v]`` is the cumulative sequence length of preceding nodes in
        topological order.  Because parallel branches occupy disjoint ranges,
        no directed path can revisit a coordinate, and any path is strictly
        increasing in ``gidx``.
        """
        order = self.topological_order()
        pos = 0
        for v in order:
            self.gidx[v] = pos
            self.glen[v] = len(self.nodes[v].seq)
            pos += len(self.nodes[v].seq)
        return order

    # -- minimizer index ---------------------------------------------------
    def index_minimizers(self, k: int, w: int, max_occ: int = 1000, hash_fn=hash_kmer):
        """Build canonical-kmer -> [(node, offset, strand)] index.

        Keys occurring in more than ``max_occ`` positions are dropped: this is
        the explicit memory cap for repetitive sequence and prevents a single
        repeat from exploding into millions of anchors.
        """
        counts: Dict[str, int] = defaultdict(int)
        per_node: Dict[int, list] = {}
        for nid, node in self.nodes.items():
            ms = minimizers(node.seq, k, w, hash_fn)
            per_node[nid] = ms
            for _, can, _, _ in ms:
                counts[can] += 1
        idx: Dict[str, List[Tuple[int, int, int]]] = defaultdict(list)
        dropped = 0
        for nid, ms in per_node.items():
            for pos, can, strand, _ in ms:
                if counts[can] <= max_occ:
                    idx[can].append((nid, pos, strand))
                else:
                    dropped += 1
        return idx, dropped

    # -- bubble detection (2-branch diamonds) ------------------------------
    def detect_bubbles(self, max_nodes: int = 10000) -> Tuple[dict, dict]:
        """Detect simple 2-branch diamond bubbles.

        A diamond is  u -> v -> w  and  u -> x -> w.  Node v is assigned
        branch 0 and x branch 1.  Returns
            bubbles      : bubble_id -> (lo, hi) coordinate span
            node_bubble  : node_id -> (bubble_id, branch_id)
        """
        bubbles: Dict[int, Tuple[int, int]] = {}
        node_bubble: Dict[int, Tuple[int, int]] = {}
        bid = 0
        for u in self.topological_order():
            succ = sorted(set(self.adj[u]))
            if len(succ) != 2:
                continue
            v, x = succ
            joins = sorted(set(self.adj[v]) & set(self.adj[x]))
            if not joins:
                continue
            w = joins[0]
            members = {v: 0, x: 1}
            for m, b in members.items():
                node_bubble[m] = (bid, b)
            lo = min(self.gidx[m] for m in members)
            hi = max(self.gidx[m] + self.glen[m] for m in members)
            bubbles[bid] = (lo, hi)
            bid += 1
        return bubbles, node_bubble


# ---------------------------------------------------------------------------
# Anchors
# ---------------------------------------------------------------------------


@dataclass(slots=True)
class Anchor:
    read_id: int
    ridx: int      # read coordinate along the read's forward orientation
    gidx: int      # graph coordinate (topological prefix + in-node offset)
    strand: int    # +1 / -1 orientation of the read relative to the graph
    weight: float  # anchor weight
    colors: int    # sample provenance bitmask
    node: int
    pos: int       # original read start position
    bubble: int = -1
    branch: int = -1

    @property
    def key(self):
        return (self.read_id, self.strand, self.ridx, self.gidx)


def build_anchors(
    read_id: int,
    seq: str,
    graph: ColoredVariationGraph,
    index: Dict[str, List[Tuple[int, int, int]]],
    k: int,
    w: int,
    node_bubble: Optional[Dict[int, Tuple[int, int]]] = None,
    hash_fn=hash_kmer,
) -> List[Anchor]:
    """Project read minimizers onto the graph, producing anchors.

    Reverse-complement handling
    ---------------------------
    Let the read minimizer have strand ``s_r`` and the graph minimizer strand
    ``s_g`` relative to their common canonical k-mer.  The read maps to the
    graph forward direction iff ``s_r * s_g == +1``.  For a reverse mapping we
    mirror the read coordinate (``r = L - k - p``) so that a chain is still
    strictly increasing in both r and g.  The graph coordinate is always the
    forward in-node coordinate ``gidx[node] + offset``.
    """
    L = len(seq)
    anchors: List[Anchor] = []
    if node_bubble is None:
        node_bubble = {}
    for p, can, s_r, _h in minimizers(seq, k, w, hash_fn):
        hits = index.get(can)
        if not hits:
            continue
        for nid, npos, s_g in hits:
            astrand = s_r * s_g
            node = graph.nodes[nid]
            gx = graph.gidx[nid] + npos
            if astrand == 1:
                rx = p
            else:
                rx = L - k - p
            bb = node_bubble.get(nid, (-1, -1))
            anchors.append(
                Anchor(
                    read_id=read_id,
                    ridx=rx,
                    gidx=gx,
                    strand=astrand,
                    weight=1.0,
                    colors=node.colors,
                    node=nid,
                    pos=p,
                    bubble=bb[0],
                    branch=bb[1],
                )
            )
    return anchors


# ---------------------------------------------------------------------------
# Segment tree: range maximum of V = f + lambda*(r + g)
# ---------------------------------------------------------------------------


class SegMax:
    """Segment tree over compressed graph coordinates.

    Each node stores the pair (V, index) that is maximal under
    ``_better``: larger V wins; on an exact tie the smaller anchor index
    wins.  The deterministic tie-break makes the fast DP and the brute-force
    reference select the identical optimal chain.
    """

    __slots__ = ("n", "val", "idx")

    def __init__(self, n: int):
        self.n = 1
        while self.n < max(1, n):
            self.n <<= 1
        self.val = [NEG] * (2 * self.n)
        self.idx = [-1] * (2 * self.n)

    @staticmethod
    def _better(v, i, bv, bi) -> bool:
        return v > bv or (v == bv and (bi < 0 or (i >= 0 and i < bi)))

    def update(self, i: int, v: float, j: int) -> None:
        p = i + self.n
        if not self._better(v, j, self.val[p], self.idx[p]):
            return
        self.val[p] = v
        self.idx[p] = j
        p >>= 1
        while p:
            l, r = 2 * p, 2 * p + 1
            if self._better(self.val[l], self.idx[l], self.val[r], self.idx[r]):
                self.val[p], self.idx[p] = self.val[l], self.idx[l]
            else:
                self.val[p], self.idx[p] = self.val[r], self.idx[r]
            p >>= 1

    def query(self, lo: int, hi: int) -> Tuple[float, int]:
        """Max over inclusive compressed indices [lo, hi]."""
        if lo > hi:
            return (NEG, -1)
        lo += self.n
        hi += self.n
        best_v, best_i = NEG, -1
        while lo <= hi:
            if lo & 1:
                if self._better(self.val[lo], self.idx[lo], best_v, best_i):
                    best_v, best_i = self.val[lo], self.idx[lo]
                lo += 1
            if not (hi & 1):
                if self._better(self.val[hi], self.idx[hi], best_v, best_i):
                    best_v, best_i = self.val[hi], self.idx[hi]
                hi -= 1
            lo >>= 1
            hi >>= 1
        return best_v, best_i


# ---------------------------------------------------------------------------
# The chaining DP
# ---------------------------------------------------------------------------


@dataclass
class ChainResult:
    chain: List[Anchor]
    score: float
    colors: int
    f: List[float]


def _coordinate_compress(anchors: Sequence[Anchor]) -> Tuple[List[int], Dict[int, int]]:
    gs = sorted({a.gidx for a in anchors})
    return gs, {g: i for i, g in enumerate(gs)}


def chain_one_orientation(
    anchors: Sequence[Anchor],
    k: int,
    lam: float,
    max_gap: int,
    bubbles: Dict[int, Tuple[int, int]],
) -> ChainResult:
    """O(n log n) maximum-score chain for anchors of a single read+strand.

    ``max_gap`` bounds the allowed graph jump across an SV bubble.  The DP is
    exact for the Manhattan-gap objective; the only pruning performed is the
    dominance pruning embedded in `SegMax.update` (a leaf keeps the single best
    V seen at that graph coordinate) plus the delayed read-overlap insertion,
    which is an exact feasibility constraint rather than a heuristic.
    """
    n = len(anchors)
    if n == 0:
        return ChainResult([], 0.0, 0, [])

    order = sorted(range(n), key=lambda i: (anchors[i].ridx, anchors[i].gidx))
    a = [anchors[i] for i in order]
    gs, gpos = _coordinate_compress(a)
    tree = SegMax(len(gs))

    f = [0.0] * n
    prev = [-1] * n
    col = [0] * n
    # Per-(bubble,branch) inserted predecessors.  Bubbles are bounded, so the
    # number of anchors per branch is small and an exact range-filtered scan is
    # cheap.  (A per-branch Fenwick tree would give the same result with a
    # larger constant; the scan is used for clarity.)
    branch_buckets: Dict[Tuple[int, int], List[int]] = defaultdict(list)
    Varr = [NEG] * n

    inserted = 0
    for i in range(n):
        ai = a[i]

        # --- delayed insertion: only non-overlapping read predecessors -----
        while inserted < i and a[inserted].ridx + k <= ai.ridx:
            aj = a[inserted]
            V = f[inserted] + lam * (aj.ridx + aj.gidx)
            Varr[inserted] = V
            tree.update(gpos[aj.gidx], V, inserted)
            if aj.bubble >= 0:
                branch_buckets[(aj.bubble, aj.branch)].append(inserted)
            inserted += 1

        # --- predecessor query --------------------------------------------
        g_hi = ai.gidx - 1
        g_lo = ai.gidx - max_gap
        best: Tuple[float, int] = (NEG, -1)

        if ai.bubble >= 0:
            blo, bhi = bubbles[ai.bubble]
            # Outside the bubble on the left.
            hi_idx = bisect_right(gs, min(g_hi, blo - 1)) - 1
            lo_idx = bisect_left(gs, g_lo)
            if lo_idx <= hi_idx:
                cand = tree.query(lo_idx, hi_idx)
                if SegMax._better(cand[0], cand[1], best[0], best[1]):
                    best = cand
            # Outside the bubble on the right (kept for completeness).
            lo2 = bisect_left(gs, max(g_lo, bhi + 1))
            hi2 = bisect_right(gs, g_hi) - 1
            if lo2 <= hi2:
                cand = tree.query(lo2, hi2)
                if SegMax._better(cand[0], cand[1], best[0], best[1]):
                    best = cand
            # Same branch inside the bubble, restricted to gidx < gidx_i.
            for j in branch_buckets.get((ai.bubble, ai.branch), ()):
                if (
                    a[j].gidx < ai.gidx
                    and ai.gidx - a[j].gidx <= max_gap
                    and SegMax._better(Varr[j], j, best[0], best[1])
                ):
                    best = (Varr[j], j)
        else:
            lo_idx = bisect_left(gs, g_lo)
            hi_idx = bisect_right(gs, g_hi) - 1
            if lo_idx <= hi_idx:
                best = tree.query(lo_idx, hi_idx)

        base = best[0] - lam * (ai.ridx + ai.gidx)
        if best[1] >= 0 and base > 0.0:
            f[i] = ai.weight + base
            prev[i] = best[1]
            col[i] = ai.colors & col[best[1]]
        else:
            f[i] = ai.weight
            prev[i] = -1
            col[i] = ai.colors

    end = max(range(n), key=lambda i: f[i])
    chain: List[Anchor] = []
    cur = end
    while cur >= 0:
        chain.append(a[cur])
        cur = prev[cur]
    chain.reverse()
    return ChainResult(chain, f[end], col[end], f)


def chain_read(
    read_id: int,
    seq: str,
    graph: ColoredVariationGraph,
    index: Dict[str, List[Tuple[int, int, int]]],
    k: int,
    w: int,
    lam: float = 0.01,
    max_gap: int = 10000,
    node_bubble: Optional[Dict[int, Tuple[int, int]]] = None,
    bubbles: Optional[Dict[int, Tuple[int, int]]] = None,
    hash_fn=hash_kmer,
) -> ChainResult:
    """Full pipeline for one read: build anchors, chain each strand, take best."""
    if node_bubble is None:
        node_bubble = {}
    if bubbles is None:
        bubbles = {}
    anchors = build_anchors(
        read_id, seq, graph, index, k, w, node_bubble=node_bubble, hash_fn=hash_fn
    )
    best = ChainResult([], 0.0, 0, [])
    for strand in (+1, -1):
        sub = [a for a in anchors if a.strand == strand]
        if not sub:
            continue
        res = chain_one_orientation(sub, k, lam, max_gap, bubbles)
        if res.score > best.score:
            best = res
    return best


# ---------------------------------------------------------------------------
# Brute force reference (O(n^2)) for verification
# ---------------------------------------------------------------------------


def chain_brute(
    anchors: Sequence[Anchor],
    k: int,
    lam: float,
    max_gap: int,
    bubbles: Dict[int, Tuple[int, int]],
) -> ChainResult:
    n = len(anchors)
    if n == 0:
        return ChainResult([], 0.0, 0, [])
    order = sorted(range(n), key=lambda i: (anchors[i].ridx, anchors[i].gidx))
    a = [anchors[i] for i in order]
    f = [0.0] * n
    prev = [-1] * n
    col = [0] * n
    for i in range(n):
        ai = a[i]
        f[i] = ai.weight
        prev[i] = -1
        col[i] = ai.colors
        for j in range(i):
            aj = a[j]
            if aj.ridx + k > ai.ridx:
                continue
            if aj.gidx >= ai.gidx:
                continue
            if ai.gidx - aj.gidx > max_gap:
                continue
            if aj.bubble >= 0 and aj.bubble == ai.bubble and aj.branch != ai.branch:
                continue
            Vj = f[j] + lam * (aj.ridx + aj.gidx)
            base = Vj - lam * (ai.ridx + ai.gidx)
            if base <= 0.0:
                continue
            val = ai.weight + base
            if val > f[i]:
                f[i] = val
                prev[i] = j
                col[i] = ai.colors & col[j]
    end = max(range(n), key=lambda i: f[i])
    chain: List[Anchor] = []
    cur = end
    while cur >= 0:
        chain.append(a[cur])
        cur = prev[cur]
    chain.reverse()
    return ChainResult(chain, f[end], col[end], f)

# Sub-quadratic correctness argument
# ---------------------------------------------------------------------------


def proof_domination() -> str:
    return (
        "Dominance pruning is exact for the Manhattan-gap DP.\n"
        "For a fixed future anchor i the contribution of a predecessor j is\n"
        "    f[j] - lam*((r_i-r_j)+(g_i-g_j))\n"
        "  = [f[j] + lam*(r_j+g_j)] - lam*(r_i+g_i)\n"
        "  = V_j - lam*(r_i+g_i).\n"
        "The term -lam*(r_i+g_i) is identical for every predecessor, so a\n"
        "predecessor is fully characterised by V_j.  If two anchors j,k satisfy\n"
        "r_j <= r_k and g_j <= g_k then whenever V_j <= V_k, j can never beat k\n"
        "for any future i (future i has r_i >= r_k, g_i >= g_k and the gap term\n"
        "is monotone).  Hence only the per-graph-coordinate maximum V is needed.\n"
        "The segment tree stores exactly those maxima, so it answers the true\n"
        "maximum over all feasible predecessors and runs in O(n log n)."
    )


# ---------------------------------------------------------------------------
# Memory-capped streaming driver
# ---------------------------------------------------------------------------


def stream_reads(
    reads: Iterable[str],
    graph: ColoredVariationGraph,
    k: int = 15,
    w: int = 10,
    lam: float = 0.01,
    max_gap: int = 10000,
    max_occ: int = 1000,
    hash_fn=hash_kmer,
):
    """Process reads one at a time under a memory cap.

    Only one read's anchor list plus the graph minimizer index is resident.
    Retaining the final chains for millions of reads would itself exceed the
    cap, so callers should consume the generator and write results to disk.
    """
    graph.linearize()
    index, dropped = graph.index_minimizers(k, w, max_occ=max_occ, hash_fn=hash_fn)
    bubbles, node_bubble = graph.detect_bubbles()
    for rid, seq in enumerate(reads):
        res = chain_read(
            rid,
            seq,
            graph,
            index,
            k,
            w,
            lam=lam,
            max_gap=max_gap,
            node_bubble=node_bubble,
            bubbles=bubbles,
            hash_fn=hash_fn,
        )
        yield rid, res

5. Correctness argument for the pruning

Claim. For the Manhattan-gap DP, keeping only the per-graph-coordinate maximum V_j = f[j] + lambda*(r_j+g_j) is exact.

Proof. For a fixed future anchor i, predecessor j contributes V_j - lambda*(r_i+g_i). The subtracted term is independent of j, so the best predecessor maximises V_j. If r_j <= r_k and g_j <= g_k and V_j <= V_k, then every future i usable by j also has r_i >= r_k, g_i >= g_k; the gap is monotone, so j can never beat k and is dominated. Dropping dominated candidates preserves the true maximum. The segment tree stores exactly the per-coordinate maxima (and, in bubbles, one best per branch filtered by gidx and max_gap), so each query is exact. Time O(n log n), memory O(n) per read. ∎

Delayed insertion (r_j + k <= r_i) removes only read-overlap-infeasible transitions; branch exclusion removes only branch-switching transitions. Both are exact constraints.

COL = lambda *ids: sum(1 << i for i in ids)   # sample ids -> bitmask

Because stream_reads yields lazily, the caller decides whether to write each chain to disk (true memory cap) or retain them.

Notes on the fix

  • Two real bugs were found and fixed during verification and are reflected in the code: (1) the per-branch predecessor cache must be filtered by gidx (otherwise it chains backwards inside a bubble), and (2) the same-branch scan must enforce max_gap. Both are now covered by the randomized brute-force comparison.
  • The algorithm is exact for the Manhattan-gap objective. If you need minimap2's |dr-dg|-style gap, the same dominance framework generalizes to a 2D (CDQ / Fenwick-of-Fenwick) structure, but the read-overlap and bubble invariants are unchanged.
