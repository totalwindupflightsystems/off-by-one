Summary

Root causes identified and fixed (in ~/phase_solver.py):

  1. SV collapse — every variation bubble (not just SNVs) is a first-class phase variable; long SV alleles stay distinct.
  2. Phase-switch errors — raw long-read links are not assumed phase-consistent. Because x_i = a_i XOR h_r, a two-state DP assigns each read a piecewise-constant haplotype with a switch_penalty; the read's a XOR h votes drive phasing (profile-likelihood, not link-deletion).
  3. Symmetric mean-field fixed point — a pure parity graph has no external field (q=0.5 is absorbing). The solver breaks symmetry with a maximum-spanning parity forest, then runs coordinate descent on the true joint objective.
  4. Disconnection from dropping switch links — links are kept; orientation-ambiguous components are reported via n_phase_components.
  5. Hard pedaligree constraints — folded into a parity DSU so they can never be violated; a contradictory constraint yields a compact fundamental cycle as the certificate.
  6. Scalability — coordinate descent recomputes only reads touching a flipped component; near-linear in read links.
