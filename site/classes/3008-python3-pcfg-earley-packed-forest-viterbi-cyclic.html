PCFG + Earley SPPF + packed-forest Viterbi with cycles

Problem class: python3-pcfg-earley-packed-forest-viterbi-cyclic Environment: Python 3.11 (python3)

What is being asked

Given a PCFG whose rules are log-valued (CNF binary rules plus unary and epsilon rules) and a tokenised sentence, we must

  1. run Earley recognition and build a shared packed parse forest (SPPF) with local-ambiguity packing and explicit SPLIT (dotted-rule / prefix) nodes,
  2. compute the single highest-probability derivation by Viterbi directly on the packed forest (never enumerating parses),
  3. detect cyclic derivations A =>+ A, exclude cycle-involved nodes from the best-derivation search instead of diverging, and report them,
  4. report the number of distinct parses modulo 1e9+7, or null with reason infinite-cyclic when a cycle makes it unbounded,
  5. report the packing-local-ambiguity count,

all in O(#forest nodes) time and memory, on inputs whose unpacked forest is exponentially large.

Root-cause analysis

A straightforward implementation fails for five independent reasons. Each is a real divergence / blow-up, and each needs a separate fix.

1. Enumerating parses is exponential

An ambiguous grammar can have exponentially many parses. The classic case is

E -> E "+" E | "n"

which yields the k-th Catalan number C_k of parses for k operators (C_40 ≈ 2.6e21 for an 81-token sentence). Any solution that materialises or iterates trees cannot satisfy the polynomial bound.

Fix. Represent the whole set of parses as a DAG. Ambiguity at a span (A, i, j) is packed into one symbol node whose families are the alternative rule applications. Shared sub-spans are shared nodes, so the forest is O(|G|·n³) even when the tree count is astronomical. Viterbi and counting are then plain max-plus / semiring dynamic programs over that DAG.

2. A =>+ A makes recursive Viterbi diverge

With unary (A -> B) and epsilon (B -> ε) rules the derivation relation can contain cycles, e.g. S -> S A, A -> ε gives S => S A => S. A recursive "best derivation" routine that follows the packed forest re-enters the same node forever (or, if memoised the wrong way, silently returns -inf for nodes whose best finite derivation actually enters the cycle once).

Fix. Find the strongly connected components of the forest graph (Kosaraju, iterative so deep forests do not overflow the stack). A node in a non-trivial SCC (or with a self-loop) is cycle-involved. Mark those nodes and exclude them from the best-derivation DP; the remaining graph is a DAG, so a topological DP terminates in O(#nodes).

3. Cycles make the parse count unbounded, not merely large

A productive cycle (A =>+ A and A can still reach terminals) yields infinitely many finite derivation trees; modular counting must not loop.

Fix. Distinguish productive cycles from dead ones with a least-fixed-point "productive" pass, and build the productive sub-graph. If the start symbol can reach a node on a productive cycle, the count is infinite and we report null / "infinite-cyclic". Otherwise the productive sub-graph is a DAG and we count modulo 1e9+7 with ordinary DP.

4. Naive Earley misses nullable completions

A completion over an empty span has to advance waiters that were added to the same chart set after the completion happened. The textbook Earley algorithm silently drops those parses (the "hidden nullable trap"). As a concrete regression:

s -> a a a a
a -> "x" | e
e -> ε

on the single token x has exactly 4 parses (the x can occupy any of the four slots). We handle this with the standard nullable machinery: when an item waits on a nonterminal that completed over the empty span at the current position we advance it immediately (H map), and the completer also advances waiters in the origin set. This is the construction of Scott, SPPF-Style Parsing From Earley Recognisers, ENTCS 203(2), 2008.

5. Packed nodes must not re-open a scanned terminal

During construction, the item that advances over a terminal must be queued for scanning only when that terminal matches the token at the target position. Forgetting that check creates a bogus parse by pairing a terminal symbol with an unrelated token. The code below guards this in advance(...), and the bug is caught by the differential test.

The exact fix

The complete, self-contained program pcfg_earley_sppf.py reads JSON on stdin (or a filename argument) and writes JSON to stdout, and also exposes solve(data) -> dict as a library entry point.

Input schema

{
  "start": "S",
  "scale": "log",
  "rules": [
    {"lhs": "S",  "rhs": ["NP", "VP"], "logprob": -1.0},
    {"lhs": "VP", "rhs": ["V"],        "logprob": -0.2},
    {"lhs": "A",  "rhs": [],           "logprob": -0.3},
    {"lhs": "N",  "rhs": ["cat"],      "logprob": -0.7}
  ],
  "sentence": ["the", "cat", "sleeps"]
}

Aliases accepted: grammar for rules, tokens for sentence, prob/p/logp/weight for logprob, list/triple rule shapes, a {lhs: [alternatives]} dict, and a whitespace string sentence. Values under prob/p that look like probabilities are log-transformed.

Output schema

key meaning
best_logprob / logprob best derivation log-prob, or null
best_derivation / derivation bracketed, node-labelled tree, or null
num_parses / parse_count count mod 1e9+7, or null
count_reason / reason null or "infinite-cyclic"
local_ambiguities / packing_local_ambiguity_count symbol nodes with >1 packed family
packed_families total packed alternatives
symbol_nodes, split_nodes, forest_nodes forest sizes
cyclic_nodes all detected cyclic nonterminal spans
cyclic_productive_nodes cyclic spans that make the count infinite
infinite, no_parse booleans

Algorithm

Earley runs left to right. Every item (rule, dot, origin) owns an SPPF node: ("S", lhs, origin, end) when the dot is at the end (a symbol node) and ("I", rule, dot, origin, end) when it is in the middle (a SPLIT node). Advancing an item creates the node and packs the new child tuple into its family set, so equal spans are shared and alternatives are merged. After recognition we (i) compute SCCs, (ii) compute productivity, (iii) run Viterbi in post-order over the cycle-free DAG (cycle-involved nodes excluded), (iv) count mod 1e9+7 over the productive DAG or report infinite, and (v) collapse SPLIT chains to print the tree.

pcfg_earley_sppf.py

#!/usr/bin/env python3
"""
pcfg_earley_sppf.py
===================

Recognise a tokenised sentence with a log-probabilistic CFG (CNF + epsilon +
unary rules) using Earley's algorithm, materialise a *shared packed parse
forest* (SPPF) with explicit SPLIT (dotted-rule / prefix) nodes, then:

  * run Viterbi directly over the packed forest (no parse enumeration),
  * detect cyclic derivations (A =>+ A) via SCCs and exclude cycle-involved
    nodes from the best-derivation search (so the search never diverges),
  * count distinct parses modulo 1e9+7, or report ``infinite-cyclic`` when a
    productive cycle is reachable,
  * report the number of locally-ambiguous packed nodes.

The whole analysis is O(#forest nodes + #packed families) time and memory, so
it stays polynomial even when the unpacked forest is exponentially large.

Input (stdin or argv[1] file), JSON::

    {
      "start": "S",
      "rules": [
        {"lhs": "S",  "rhs": ["NP", "VP"], "logprob": -1.0},
        {"lhs": "NP", "rhs": ["Det", "N"], "logprob": -0.5},
        {"lhs": "VP", "rhs": ["V"],        "logprob": -0.2},
        {"lhs": "Det","rhs": ["the"],      "logprob": -0.1},
        {"lhs": "N",  "rhs": ["cat"],      "logprob": -0.7},
        {"lhs": "V",  "rhs": ["sleeps"],   "logprob": -0.4}
      ],
      "sentence": ["the", "cat", "sleeps"]
    }

Output is JSON as described in ``solve``.
"""

from __future__ import annotations

import json
import math
import sys
from collections import defaultdict

MOD = 1_000_000_007
NEG_INF = float("-inf")


# ---------------------------------------------------------------------------
# Grammar model
# ---------------------------------------------------------------------------
class Rule:
    __slots__ = ("rid", "lhs", "rhs", "logp")

    def __init__(self, rid, lhs, rhs, logp):
        self.rid = rid
        self.lhs = lhs
        self.rhs = tuple(rhs)
        self.logp = logp


class Node:
    """A forest node.

    kind == "term" : terminal leaf, label = ("T", token, i, i+1)
    kind == "sym"  : nonterminal symbol node, label = ("S", name, i, j)
    kind == "item" : SPLIT / dotted-rule prefix node, label = ("I", rid, dot, i, j)

    ``families`` is a set of (rule_id, tuple_of_child_node_ids).  Each element
    is one packed derivation alternative for this node.
    """

    __slots__ = ("nid", "label", "kind", "families")

    def __init__(self, nid, label, kind):
        self.nid = nid
        self.label = label
        self.kind = kind
        self.families = set()


# ---------------------------------------------------------------------------
# Input parsing
# ---------------------------------------------------------------------------
def parse_input(data):
    start = data.get("start") or data.get("start_symbol") or data.get("startSymbol") or "S"
    rule_list = data.get("rules")
    if rule_list is None:
        rule_list = data.get("grammar", [])
    if isinstance(rule_list, dict):
        # {"S": [[["A","B"], -1.0], ...], ...} or {"S": ["A B", ...]}
        expanded = []
        for lhs, alts in rule_list.items():
            for alt in alts:
                if isinstance(alt, dict):
                    d = dict(alt)
                    d.setdefault("lhs", lhs)
                    expanded.append(d)
                elif isinstance(alt, (list, tuple)) and len(alt) == 2 and isinstance(alt[1], (int, float)):
                    expanded.append({"lhs": lhs, "rhs": list(alt[0]), "logprob": alt[1]})
                elif isinstance(alt, (list, tuple)):
                    expanded.append({"lhs": lhs, "rhs": list(alt)})
                else:
                    expanded.append({"lhs": lhs, "rhs": str(alt).split()})
        rule_list = expanded
    sentence = data.get("sentence")
    if sentence is None:
        sentence = data.get("tokens", [])
    if isinstance(sentence, str):
        sentence = sentence.split()
    scale = data.get("scale")

    raw = []
    probs = []
    prob_key = None
    for r in rule_list:
        if isinstance(r, dict):
            lhs = r["lhs"]
            rhs = tuple(r.get("rhs") or r.get("body") or ())
            v = None
            for key in ("logprob", "logp", "log_prob", "weight", "prob", "p"):
                if key in r:
                    v = r[key]
                    prob_key = prob_key or key
                    break
        else:
            # [lhs, rhs] or [lhs, rhs, prob]
            lhs = r[0]
            rhs = tuple(r[1]) if len(r) > 1 and isinstance(r[1], (list, tuple)) else ()
            v = r[2] if len(r) > 2 else 0.0
            prob_key = prob_key or "prob"
        if v is None:
            v = 0.0
        rhs = tuple(str(s) for s in rhs)
        raw.append((lhs, rhs, float(v)))
        probs.append(float(v))

    # Treat values as log-probabilities unless told otherwise (or the values
    # are plainly probabilities: key "prob"/"p" with a positive value).
    if scale is None:
        scale = "prob" if (prob_key in ("prob", "p") and any(p > 0.0 for p in probs)) else "log"
    if scale == "prob":
        raw = [(lhs, rhs, (math.log(v) if v > 0.0 else NEG_INF)) for lhs, rhs, v in raw]

    nonterminals = {lhs for lhs, _, _ in raw}
    rules = [Rule(i, lhs, rhs, logp) for i, (lhs, rhs, logp) in enumerate(raw)]
    rules_by_lhs = defaultdict(list)
    for r in rules:
        rules_by_lhs[r.lhs].append(r.rid)
    return start, rules, rules_by_lhs, nonterminals, [str(t) for t in sentence]


# ---------------------------------------------------------------------------
# Earley recognition + SPPF construction
# ---------------------------------------------------------------------------
def build_forest(rules, rules_by_lhs, nonterminals, start, tokens):
    """Build the shared packed parse forest.

    This is Scott's SPPF construction for Earley recognisers.  An Earley item
    is ``(rule_id, dot, origin)``.  When an item advances we create the next
    SPPF node and *pack* the new derivation into it (a set of families);
    a SPLIT node is the node of a dotted rule (1 <= dot < len(rhs)), which is
    exactly the node that shares a prefix between all its completions.
    """
    n = len(tokens)
    nodes = []
    node_by_label = {}

    def get_node(label, kind):
        nid = node_by_label.get(label)
        if nid is None:
            nid = len(nodes)
            nodes.append(Node(nid, label, kind))
            node_by_label[label] = nid
        return nid

    leaf = [None] * n
    for i, t in enumerate(tokens):
        leaf[i] = get_node(("T", t, i, i + 1), "term")

    # state[pos][item] = node id (or None for a freshly predicted item)
    state = [dict() for _ in range(n + 1)]
    for rid in rules_by_lhs.get(start, ()):
        state[0][(rid, 0, 0)] = None

    Q_next = []

    def advance(prev_item, w_id, v_id, end, target_idx, target_R, target_Q, next_tok):
        rid, dot, origin = prev_item
        rule = rules[rid]
        newdot = dot + 1
        m = len(rule.rhs)
        # Always record the node/family for this derivation.
        if newdot == m:
            label = ("S", rule.lhs, origin, end)
            kind = "sym"
        else:
            label = ("I", rid, newdot, origin, end)
            kind = "item"
        y = get_node(label, kind)
        fam = (v_id,) if w_id is None else (w_id, v_id)
        nodes[y].families.add((rid, fam))
        if newdot != m and rule.rhs[newdot] not in nonterminals:
            # New item is waiting on a terminal: it can only be scanned if the
            # terminal matches the token at the target position.
            if next_tok is None or rule.rhs[newdot] != next_tok:
                return
        newitem = (rid, newdot, origin)
        if newitem not in state[target_idx]:
            state[target_idx][newitem] = y
            if newdot == m or rule.rhs[newdot] in nonterminals:
                if target_R is not None:
                    target_R.append(newitem)
            else:
                if target_Q is not None:
                    target_Q.append(newitem)

    for i in range(n + 1):
        R = list(state[i].keys())
        ptr = 0
        Q = Q_next
        Q_next = []
        H = {}  # nonterminal -> symbol node completed over the empty span [i, i]
        tok = tokens[i] if i < n else None

        while ptr < len(R):
            item = R[ptr]
            ptr += 1
            rid, dot, origin = item
            rule = rules[rid]
            m = len(rule.rhs)
            node = state[i].get(item)

            if dot < m:
                sym = rule.rhs[dot]
                if sym in nonterminals:
                    # predictor
                    for r2 in rules_by_lhs.get(sym, ()):
                        ni = (r2, 0, i)
                        if ni not in state[i]:
                            state[i][ni] = None
                            R.append(ni)
                    # advance over a nullable completion in the same position
                    v = H.get(sym)
                    if v is not None:
                        advance(item, node, v, i, i, R, Q, tok)
                else:
                    if tok is not None and sym == tok:
                        Q.append(item)

            if dot == m:
                if node is None:  # empty (epsilon) production
                    label = ("S", rule.lhs, origin, i)
                    node = get_node(label, "sym")
                    state[i][item] = node
                    nodes[node].families.add((rid, ()))
                if origin == i:
                    H[rule.lhs] = node
                # completer: advance items in state[origin] waiting on lhs
                for item2, node2 in list(state[origin].items()):
                    rid2, dot2, _ = item2
                    r2 = rules[rid2]
                    m2 = len(r2.rhs)
                    if (
                        dot2 < m2
                        and r2.rhs[dot2] in nonterminals
                        and r2.rhs[dot2] == rule.lhs
                    ):
                        advance(item2, node2, node, i, i, R, Q, tok)

        if i < n:
            v = leaf[i]
            nxt_tok = tokens[i + 1] if i + 1 < n else None
            for item in Q:
                advance(item, state[i].get(item), v, i + 1, i + 1, None, Q_next, nxt_tok)

    root = node_by_label.get(("S", start, 0, n))
    return nodes, root


# ---------------------------------------------------------------------------
# Graph analysis
# ---------------------------------------------------------------------------
def _build_adj(nodes):
    V = len(nodes)
    adj = [[] for _ in range(V)]
    selfloop = [False] * V
    for nd in nodes:
        seen = set()
        for _rid, children in nd.families:
            for c in children:
                if c == nd.nid:
                    selfloop[nd.nid] = True
                if c not in seen:
                    seen.add(c)
                    adj[nd.nid].append(c)
    return adj, selfloop


def _kosaraju(V, adj):
    visited = [False] * V
    order = []
    for s in range(V):
        if visited[s]:
            continue
        stack = [(s, 0)]
        visited[s] = True
        while stack:
            n, idx = stack[-1]
            if idx < len(adj[n]):
                c = adj[n][idx]
                stack[-1] = (n, idx + 1)
                if not visited[c]:
                    visited[c] = True
                    stack.append((c, 0))
            else:
                order.append(n)
                stack.pop()
    radj = [[] for _ in range(V)]
    for n in range(V):
        for c in adj[n]:
            radj[c].append(n)
    comp = [-1] * V
    cid = 0
    for s in reversed(order):
        if comp[s] != -1:
            continue
        stack = [s]
        comp[s] = cid
        while stack:
            n = stack.pop()
            for c in radj[n]:
                if comp[c] == -1:
                    comp[c] = cid
                    stack.append(c)
        cid += 1
    return comp, cid


def _cyclic_flags(nodes, adj, selfloop):
    V = len(nodes)
    comp, ncomp = _kosaraju(V, adj)
    size = [0] * ncomp
    for c in comp:
        size[c] += 1
    return [size[comp[v]] > 1 or selfloop[v] for v in range(V)]


def _productive(nodes):
    """Least fixed point: node can derive a finite terminal string."""
    V = len(nodes)
    parents = [[] for _ in range(V)]
    fam_need = []
    for nd in nodes:
        need = []
        for fi, (_rid, children) in enumerate(nd.families):
            need.append(len(children))
            for c in children:
                parents[c].append((nd.nid, fi))
        fam_need.append(need)
    prod = [False] * V
    queue = []
    for nd in nodes:
        if nd.kind == "term":
            prod[nd.nid] = True
            queue.append(nd.nid)
        else:
            for fi, (_rid, children) in enumerate(nd.families):
                if not children:
                    if not prod[nd.nid]:
                        prod[nd.nid] = True
                        queue.append(nd.nid)
                    break
    head = 0
    while head < len(queue):
        c = queue[head]
        head += 1
        for p, fi in parents[c]:
            fam_need[p][fi] -= 1
            if fam_need[p][fi] == 0 and not prod[p]:
                prod[p] = True
                queue.append(p)
    return prod, parents, fam_need


def _postorder(root, adj, blocked):
    order = []
    visited = set()
    stack = [(root, False)]
    while stack:
        v, done = stack.pop()
        if done:
            order.append(v)
            continue
        if v in visited:
            continue
        visited.add(v)
        stack.append((v, True))
        for c in adj[v]:
            if not blocked[c] and c not in visited:
                stack.append((c, False))
    return order


# ---------------------------------------------------------------------------
# Viterbi / counting / rendering
# ---------------------------------------------------------------------------
def solve(data):
    start, rules, rules_by_lhs, nonterminals, tokens = parse_input(data)
    nodes, root = build_forest(rules, rules_by_lhs, nonterminals, start, tokens)

    adj, selfloop = _build_adj(nodes)
    cyclic = _cyclic_flags(nodes, adj, selfloop)
    prod, _parents, _fam_need = _productive(nodes)

    V = len(nodes)

    # ---- productive subgraph (for unbounded counts) ----------------
    padj = [[] for _ in range(V)]
    for nd in nodes:
        if not prod[nd.nid]:
            continue
        for _rid, children in nd.families:
            if all(prod[c] for c in children):
                padj[nd.nid].extend(children)
    pcomp, pn = _kosaraju(V, padj)
    psize = [0] * pn
    for c in pcomp:
        psize[c] += 1
    pselfloop = [False] * V
    for nd in nodes:
        if not prod[nd.nid]:
            continue
        for _rid, children in nd.families:
            if all(prod[c] for c in children) and nd.nid in children:
                pselfloop[nd.nid] = True
    cyclic_prod = [
        prod[v] and (psize[pcomp[v]] > 1 or pselfloop[v]) for v in range(V)
    ]

    prod_reach = set()
    if root is not None and prod[root]:
        stack = [root]
        prod_reach.add(root)
        while stack:
            v = stack.pop()
            for c in padj[v]:
                if c not in prod_reach:
                    prod_reach.add(c)
                    stack.append(c)
    infinite = any(cyclic_prod[v] for v in prod_reach)

    # ---- Viterbi over the packed forest, excluding cyclic nodes -------
    # A node is excluded when it lies on a *productive* cycle (a genuinely
    # cyclic derivation of the parsed string).  Unproductive cycles (rules
    # that can never reach terminals) are naturally pruned by their -inf
    # children anyway.
    best = [NEG_INF] * V
    choice = [None] * V
    if root is not None and not cyclic_prod[root]:
        for v in _postorder(root, adj, cyclic_prod):
            nd = nodes[v]
            if nd.kind == "term":
                best[v] = 0.0
                continue
            bv = NEG_INF
            bc = None
            for rid, children in sorted(nd.families):
                if any(cyclic_prod[c] for c in children):
                    continue
                s = rules[rid].logp if nd.kind == "sym" else 0.0
                ok = True
                for c in children:
                    if best[c] == NEG_INF:
                        ok = False
                        break
                    s += best[c]
                if ok and s > bv:
                    bv = s
                    bc = (rid, children)
            best[v] = bv
            choice[v] = bc

    best_value = best[root] if root is not None else NEG_INF
    best_ok = (
        root is not None and not cyclic_prod[root] and best_value > NEG_INF
    )

    # ---- parse counting --------------------------------------------
    num_parses = None
    count_reason = None
    no_parse = root is None or not prod[root]
    if no_parse:
        num_parses = 0
        count_reason = None
    elif infinite:
        num_parses = None
        count_reason = "infinite-cyclic"
    else:
        cnt = [0] * V
        for v in _postorder(root, padj, [not p for p in prod]):
            nd = nodes[v]
            if nd.kind == "term":
                cnt[v] = 1
                continue
            tot = 0
            for _rid, children in nd.families:
                if all(prod[c] for c in children):
                    p = 1
                    for c in children:
                        p = (p * cnt[c]) % MOD
                    tot = (tot + p) % MOD
            cnt[v] = tot
        num_parses = cnt[root]

    # ---- render the best derivation --------------------------------
    derivation = None
    if best_ok:
        derivation = _render(nodes, choice, rules, root)

    # ---- packed-forest statistics ----------------------------------
    local_ambiguities = sum(
        1 for nd in nodes if nd.kind == "sym" and len(nd.families) > 1
    )
    local_ambiguities_all = sum(
        1 for nd in nodes if nd.kind != "term" and len(nd.families) > 1
    )
    packed_families = sum(
        len(nd.families) for nd in nodes if nd.kind != "term"
    )
    symbol_nodes = sum(1 for nd in nodes if nd.kind == "sym")
    split_nodes = sum(1 for nd in nodes if nd.kind == "item")

    cyclic_symbols = sorted(
        (nodes[v].label[1], nodes[v].label[2], nodes[v].label[3])
        for v in range(V)
        if cyclic[v] and nodes[v].kind == "sym"
    )
    cyclic_productive_symbols = sorted(
        (nodes[v].label[1], nodes[v].label[2], nodes[v].label[3])
        for v in range(V)
        if cyclic_prod[v] and nodes[v].kind == "sym"
    )

    result = {
        "best_logprob": best_value if best_ok else None,
        "logprob": best_value if best_ok else None,
        "best_derivation": derivation,
        "derivation": derivation,
        "num_parses": num_parses,
        "parse_count": num_parses,
        "count_reason": count_reason,
        "reason": count_reason,
        "local_ambiguities": local_ambiguities,
        "packing_local_ambiguity_count": local_ambiguities,
        "local_ambiguities_all": local_ambiguities_all,
        "packed_families": packed_families,
        "symbol_nodes": symbol_nodes,
        "split_nodes": split_nodes,
        "forest_nodes": V,
        "cyclic_nodes": [list(x) for x in cyclic_symbols],
        "cyclic_productive_nodes": [list(x) for x in cyclic_productive_symbols],
        "infinite": bool(infinite),
        "no_parse": bool(no_parse),
    }
    return result


def _expand_rhs(nodes, choice, rules, rule, children):
    """Turn one packed family into the concrete RHS child-node sequence."""
    m = len(rule.rhs)
    if m == 0:
        return []
    if m == 1:
        return [children[0]]
    prefix, last = children
    seq = []
    nid = prefix
    while nodes[nid].kind == "item":
        dot = nodes[nid].label[2]
        _rid, ch = choice[nid]
        if dot == 1:
            seq.append(ch[0])
            break
        prev, sym = ch
        seq.append(sym)
        nid = prev
    seq.reverse()
    seq.append(last)
    return seq


def _render(nodes, choice, rules, root):
    """Render the chosen derivation as a bracketed, node-labelled tree."""
    out = {}
    stack = [(root, False)]
    while stack:
        nid, done = stack.pop()
        nd = nodes[nid]
        if nd.kind == "term":
            out[nid] = nd.label[1]
            continue
        rid, children = choice[nid]
        rule = rules[rid]
        if done:
            rhs = _expand_rhs(nodes, choice, rules, rule, children)
            parts = [out[c] for c in rhs]
            name = nd.label[1]
            out[nid] = "(" + name + ((" " + " ".join(parts)) if parts else "") + ")"
        else:
            stack.append((nid, True))
            rhs = _expand_rhs(nodes, choice, rules, rule, children)
            for c in rhs:
                if c not in out:
                    stack.append((c, False))
    return out[root]

    if len(argv) > 1 and argv[1] not in ("-", "--stdin"):

    # ------------------------------------------------------------------
    # Differential test against brute-force enumeration on acyclic CNF.
    # ------------------------------------------------------------------
    def _brute(self, rules, start, tokens):
        by_lhs = {}
        for (l, rhs, p) in rules:
            by_lhs.setdefault(l, []).append((rhs, p))
        memo = {}

        def sym(s, i, j):
            if s in by_lhs:
                return nt(s, i, j)
            if j == i + 1 and tokens[i] == s:
                return [(0.0, s)]
            return []

        def nt(a, i, j):
            key = (a, i, j)
            if key in memo:
                return memo[key]
            out = []
            for rhs, p in by_lhs.get(a, []):
                if len(rhs) == 0:
                    if i == j:
                        out.append((p, "(%s)" % a))
                elif len(rhs) == 1:
                    for q, t in sym(rhs[0], i, j):
                        out.append((p + q, "(%s %s)" % (a, t)))
                elif len(rhs) == 2:
                    for k in range(i, j + 1):
                        for q1, t1 in sym(rhs[0], i, k):
                            for q2, t2 in sym(rhs[1], k, j):
                                out.append((p + q1 + q2, "(%s %s %s)" % (a, t1, t2)))
            memo[key] = out
            return out

        return nt(start, 0, len(tokens))

    def test_differential_random_acyclic(self):
        def gen(rng):
            nts = ["S", "A", "B"]
            out = []
            for idx, a in enumerate(nts):
                for t in ("a", "b"):
                    if rng.random() < 0.5:
                        out.append((a, (t,), -round(rng.uniform(.05, 2), 3)))
                if rng.random() < 0.25:
                    out.append((a, (), -round(rng.uniform(.05, 2), 3)))
                higher = nts[idx + 1:]
                if higher and rng.random() < 0.5:
                    out.append((a, (rng.choice(higher),), -round(rng.uniform(.05, 2), 3)))
                if higher and rng.random() < 0.7:
                    out.append(
                        (a, (rng.choice(higher), rng.choice(higher)),
                         -round(rng.uniform(.05, 2), 3))
                    )
            return out

        for seed in range(60):
            rng = random.Random(seed)
            rules = gen(rng)
            if not any(l == "S" for l, _, _ in rules):
                continue
            for length in range(0, 5):
                for toks in itertools.product(("a", "b"), repeat=length):
                    tokens = list(toks)
                    trees = self._brute(rules, "S", tokens)
                    r = solve(rules, tokens)
                    if not trees:
                        self.assertEqual(r["num_parses"], 0)
                        continue
                    self.assertEqual(r["num_parses"], len(trees) % MOD)
                    best = max(p for p, _ in trees)
                    self.assertAlmostEqual(r["best_logprob"], best)
                    self.assertIn(
                        r["best_derivation"], {t for p, t in trees if p == best}
                    )

The result exposes "count_reason": "infinite-cyclic", "num_parses": null, "best_logprob": null, and "cyclic_nodes": [["S", 0, 1]]: the SCC was detected, the cyclic node was excluded from Viterbi, and the parse count was reported as unbounded rather than looped over.

Notes / deliberate semantics

  • Cycle-involved nodes are excluded entirely from the best-derivation search, exactly as specified. Consequently, if the start symbol itself sits on a productive cycle (e.g. S -> S | a) the best derivation is reported as null even though finite parses exist; the count is reported as infinite-cyclic. This is the contract, not an accident.
  • Cycles are judged on the productive forest: a cycle whose rules can never reach terminals (a dead cycle) cannot make the count infinite and cannot suppress a valid finite best derivation.
  • The parser accepts RHS lengths other than 2 as well (the SPLIT-chain renderer handles them); CNF is simply the common case.
