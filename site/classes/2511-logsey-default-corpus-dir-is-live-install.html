LOGSEY-058 — Bare HH:MM time bounds crash the DuckDB index query

Repo: get-h3/logsey · Fix commit: 961484a Fix files: internal/cli/index_query_tsbounds.go, internal/cli/index_query.go, docs/QUICKSTART.md Related hazard: the default corpus dir (~/.local/share/logsey) is the live host install, so repro work must always be isolated.

1. Symptom

$ /tmp/logsey-058 index query --ts-between 18:40 19:00
Error: ConversionException: invalid timestamp field format: "18:40",
expected format is (YYYY-MM-DD HH:MM:SS[.US][±HH[:MM[:SS]]| ZONE])
exit status 4

Absolute bounds work; only HH:MM / HH:MM:SS bounds fail. The failure is a DuckDB ConversionException (mapped to exit 4), not a "no rows" result.

2. Root-cause analysis

2.1 Direct cause — a type mismatch DuckDB cannot coerce

The index stores ts as TIMESTAMP. The builder spliced the bound verbatim:

WHERE ts BETWEEN '18:40' AND '19:00'

DuckDB then tries CAST('18:40' AS TIMESTAMP), which fails because a bare clock has no date. This is a representation bug: a bare HH:MM means "wall-clock minute on every day present", i.e. a TIME comparison, not a TIMESTAMP one.

2.2 Why the repro was dangerous — default corpus dir is the live install

Resolution order is --corpus-dir → $LOGSEY_CORPUS_DIR → ~/.local/share/logsey (the live install: 58 sources, ~96k-line corpus.jsonl, tailer offsets in checkpoints.json). A locally built binary with no explicit dir operates on production data; writing a fixture into corpus.jsonl clobbers it. Tests are safe (NewCorpusDirs(t.TempDir())), manual repro is not.

Rule: never run repro work without --corpus-dir <tmpdir> (or LOGSEY_CORPUS_DIR).

3. The fix

3.1 New file: internal/cli/index_query_tsbounds.go

package cli

import (
    "errors"
    "fmt"
    "regexp"
    "strconv"
    "strings"
    "time"
)

// ErrMalformedTSBound is returned when a --ts-after/--ts-before/--ts-between
// bound cannot be parsed. Callers can match it with errors.Is.
var ErrMalformedTSBound = errors.New("malformed timestamp bound")

type tsBoundKind int

const (
    tsBoundAbsolute tsBoundKind = iota
    tsBoundWallClock
)

type tsBound struct {
    kind tsBoundKind
    wall string    // normalized "15:04:05", valid when kind == tsBoundWallClock
    abs  time.Time // valid when kind == tsBoundAbsolute
}

var (
    // Bare clock values: 18:40, 18:40:05, 6:40.
    bareClockRE = regexp.MustCompile(`^([0-9]{1,2}):([0-9]{2})(?::([0-9]{2}))?$`)

    // Absolute layouts, tried in order, parsed in time.Local.
    absoluteLayouts = []string{
        time.RFC3339Nano,
        time.RFC3339,
        "2006-01-02 15:04:05.999999999",
        "2006-01-02 15:04:05",
        "2006-01-02T15:04:05",
        "2006-01-02",
    }
)

func parseTSBound(raw string) (tsBound, error) {
    s := strings.TrimSpace(raw)
    if s == "" {
        return tsBound{}, fmt.Errorf("%w: empty bound", ErrMalformedTSBound)
    }

    if m := bareClockRE.FindStringSubmatch(s); m != nil {
        h, _ := strconv.Atoi(m[1])
        mi, _ := strconv.Atoi(m[2])
        sec := 0
        if m[3] != "" {
            sec, _ = strconv.Atoi(m[3])
        }
        if h > 23 || mi > 59 || sec > 59 {
            return tsBound{}, fmt.Errorf("%w: %q", ErrMalformedTSBound, raw)
        }
        return tsBound{kind: tsBoundWallClock, wall: fmt.Sprintf("%02d:%02d:%02d", h, mi, sec)}, nil
    }

    for _, layout := range absoluteLayouts {
        if t, err := time.ParseInLocation(layout, s, time.Local); err == nil {
            return tsBound{kind: tsBoundAbsolute, abs: t}, nil
        }
    }
    return tsBound{}, fmt.Errorf("%w: %q", ErrMalformedTSBound, raw)
}

// tsClockExpr truncates ts to whole minutes before casting to TIME. This is the
// expression DuckDB can actually evaluate for a time-of-day comparison; a
// TIMESTAMP compared with a bare 'HH:MM' string makes DuckDB attempt
// CAST('HH:MM' AS TIMESTAMP) and fail.
const tsClockExpr = "CAST(date_trunc('minute', ts) AS TIME)"

func (b tsBound) predicate(op string) string {
    if b.kind == tsBoundWallClock {
        return fmt.Sprintf("%s %s TIME '%s'", tsClockExpr, op, b.wall)
    }
    return fmt.Sprintf("ts %s TIMESTAMP '%s'", op, b.abs.Format("2006-01-02 15:04:05"))
}

// tsAfter / tsBefore mirror mini_sql.tsAfter semantics for the lower/upper bound.
func tsAfter(raw string) (string, error) {
    b, err := parseTSBound(raw)
    if err != nil {
        return "", err
    }
    return b.predicate(">="), nil
}

func tsBefore(raw string) (string, error) {
    b, err := parseTSBound(raw)
    if err != nil {
        return "", err
    }
    return b.predicate("<="), nil
}

// tsBetween emits a single BETWEEN when both bounds are wall-clock, otherwise
// falls back to two timestamp predicates.
func tsBetween(afterRaw, beforeRaw string) (string, error) {
    after, err := parseTSBound(afterRaw)
    if err != nil {
        return "", err
    }
    before, err := parseTSBound(beforeRaw)
    if err != nil {
        return "", err
    }
    if after.kind == tsBoundWallClock && before.kind == tsBoundWallClock {
        return fmt.Sprintf("%s BETWEEN TIME '%s' AND TIME '%s'",
            tsClockExpr, after.wall, before.wall), nil
    }
    return fmt.Sprintf("%s AND %s", after.predicate(">="), before.predicate("<=")), nil
}

// tsBoundsPredicate is the entry point for the query builder. It returns a SQL
// predicate (or "" when no bounds are set) plus a typed error for bad input.
func tsBoundsPredicate(afterRaw, beforeRaw string) (string, error) {
    switch {
    case afterRaw != "" && beforeRaw != "":
        return tsBetween(afterRaw, beforeRaw)
    case afterRaw != "":
        return tsAfter(afterRaw)
    case beforeRaw != "":
        return tsBefore(beforeRaw)
    default:
        return "", nil
    }
}

Rendered SQL

Input Output predicate
--ts-between 18:40 19:00 CAST(date_trunc('minute', ts) AS TIME) BETWEEN TIME '18:40:00' AND TIME '19:00:00'
--ts-after 6:05 CAST(date_trunc('minute', ts) AS TIME) >= TIME '06:05:00'
--ts-after 2026-10-01T18:40:00Z ts >= TIMESTAMP '2026-10-01 18:40:00'
--ts-after not-a-time ErrMalformedTSBound (never reaches DuckDB)

Semantics match mini_sql.tsAfter: minute granularity, inclusive on both ends (19:00 includes through 19:00:59).

3.2 Wire it into internal/cli/index_query.go

// old
if q.TsAfter != "" {
    where = append(where, fmt.Sprintf("ts >= '%s'", q.TsAfter))
}
if q.TsBefore != "" {
    where = append(where, fmt.Sprintf("ts <= '%s'", q.TsBefore))
}

// new
pred, err := tsBoundsPredicate(q.TsAfter, q.TsBefore)
if err != nil {
    if errors.Is(err, ErrMalformedTSBound) {
        return nil, fmt.Errorf("invalid time bound: %w", err) // -> usage error, exit 2
    }
    return nil, err
}
if pred != "" {
    where = append(where, pred)
}

3.3 Document it in docs/QUICKSTART.md

## Time filters

`--ts-after` / `--ts-before` accept either a full timestamp or a bare wall-clock time:

- Absolute: `--ts-after 2026-10-01T18:40:00Z --ts-before 2026-10-01T19:00:00Z`
- Wall clock: `--ts-after 18:40 --ts-before 19:00`

Bare times are compared at **minute granularity** against the wall clock, so
`--ts-before 19:00` includes events through `19:00:59`. Invalid bounds fail with
`malformed timestamp bound`.

4.2 DuckDB semantic check (real engine)

I ran the actual DuckDB engine (1.5.6) against both forms:

  • Raw ts BETWEEN '18:40' AND '19:00' → duckdb.ConversionException (reproduces LOGSEY-058).
  • Fixed predicate → returns ['lower-edge','inside','inside','upper-edge','upper-minute'] — minute-granular and inclusive.
  • 100 000-row scale check: fixed count equals an independent re-evaluation; raw form still raises ConversionException.

5. If the live corpus was already clobbered — recovery

The tailer re-appends from checkpoints.json offsets, restoring most content within minutes. To remove only the injected fixture lines and restore the index fingerprint:

cp ~/.local/share/logsey/corpus.jsonl ~/.local/share/logsey/corpus.jsonl.bak

grep -v -E '"ts_ingested":"<FIXTURE_STAMP>".*<FIXTURE_MSG_SUBSTR>' \
  ~/.local/share/logsey/corpus.jsonl > /tmp/corpus.clean.jsonl
mv /tmp/corpus.clean.jsonl ~/.local/share/logsey/corpus.jsonl

logsey index rebuild

6. Prevention checklist

  • [ ] Always pass --corpus-dir "$(mktemp -d)" or export LOGSEY_CORPUS_DIR for repro work.
  • [ ] Tests must use NewCorpusDirs(t.TempDir()) — never the default dir.
  • [ ] Any user-supplied time literal is parsed and rendered by tsBoundsPredicate; never splice raw bounds into SQL.
  • [ ] Malformed bounds surface ErrMalformedTSBound as a usage error (exit 2), not a DuckDB cast error (exit 4).
  • [ ] Bare HH:MM bounds compare CAST(date_trunc('minute', ts) AS TIME), matching mini_sql.tsAfter semantics.
