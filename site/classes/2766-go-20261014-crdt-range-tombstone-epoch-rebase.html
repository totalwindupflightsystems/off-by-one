Fixing wrap-unsafe epoch ordering in an observed-remove range-tombstone map

Problem

A replicated ordered-map merge engine accepts:

  • out-of-order range tombstones [lo, hi),
  • concurrent inserts, and
  • node reincarnations whose compacted per-replica epochs may wrap.

It must preserve observed-remove (OR) semantics, must not retain all historical events, and must return the minimal safe compaction frontier from bounded per-replica summaries — or prove that no bounded frontier exists. The result is validated, under adversarial delivery schedules, against a reference event interpreter that keeps the full history.

Root cause

The engine stored a per-op stamp as an Epoch counter that is compacted (reduced to a small window) and compared with plain numeric </<=.

That comparison is only valid while the counter is strictly monotone. Two things break monotonicity:

  1. Reincarnation. After a node restarts it resets the local counter, so new ops get numerically smaller epochs than old ops.
  2. Epoch wrap. Even inside one incarnation the retained epoch is stored modulo a window. After EpochMod operations the counter rolls back to 0.

Because the wrap/incarnation qualification was discarded during compaction, an old range tombstone's causal context {Epoch: k} was treated as if it covered a brand-new insert with Epoch: 0..k. The tombstone then removed an insert it never observed — a direct observed-remove violation and permanent divergence from the reference interpreter.

Concretely, with EpochMod = 4:

put k=v0        Epoch=1
del [a,z)       Epoch=2   context {r1: Epoch 2}
put k=v1        Epoch=3
put k=v2        Epoch=0   wrap=1   <-- numerically below the tombstone context

A raw Epoch <= check folds the wrap=1, Epoch=0 insert under the tombstone and wrongly deletes v2. The same failure appears on reincarnation.

The loss of qualification also makes the frontier unsound: the componentwise minimum of per-replica epochs can advance past live inserts, and once the wrap counter has been truncated there is no way to recover the ordering, so no bounded frontier can be certified.

The fix

Qualify every stamp with (Incarnation, Wrap, Epoch) and compare causally:

  • Incarnation is bumped on restart and never wraps.
  • Wrap counts epoch wraps inside an incarnation.
  • Epoch remains the small, compacted counter.
  • Causal comparison is lexicographic on (Incarnation, Wrap, Epoch); raw Epoch is never compared alone.
  • A range tombstone carries its observed causal context Ctx (a version vector) and removes put P iff P.Key ∈ [lo,hi) and Ctx covers P.ID. Concurrent inserts the tombstone did not observe survive.
  • The compaction frontier is the componentwise minimum of the per-replica version vectors. A tombstone is forgotten only when the frontier covers both the tombstone ID and its whole context Ctx; that is precisely when every replica has applied it and no future insert can be mistaken for an observed one.
  • If any summary has lost its Wrap qualification (Truncated), the engine returns ErrNoBoundedFrontier instead of silently compacting.

// Command solution is a self-contained replication engine for an ordered map
// with out-of-order range tombstones, concurrent inserts and reincarnating
// nodes whose compacted epochs may wrap.
//
//  go run solution.go
//
// It runs a deterministic observed-remove check, a wrap/reincarnation
// regression, a randomized differential check against a history-retaining
// reference interpreter, and frontier certification.
package main

import (
    "errors"
    "fmt"
    "math/rand"
    "os"
    "reflect"
)

// ---------------------------------------------------------------------------
// Identifiers, causal versions and version vectors
// ---------------------------------------------------------------------------

var ErrNoBoundedFrontier = errors.New("no bounded compaction frontier exists")

type OpID struct {
    Replica     uint64
    Incarnation uint64 // bumped on reincarnation; never wraps
    Wrap        uint64 // number of epoch wraps inside an incarnation
    Epoch       uint64 // per-replica counter, stored modulo EpochMod
}

func (a OpID) Less(b OpID) bool {
    if a.Incarnation != b.Incarnation {
        return a.Incarnation < b.Incarnation
    }
    if a.Wrap != b.Wrap {
        return a.Wrap < b.Wrap
    }
    if a.Epoch != b.Epoch {
        return a.Epoch < b.Epoch
    }
    return a.Replica < b.Replica
}

type Version struct {
    Incarnation uint64
    Wrap        uint64
    Epoch       uint64
}

func (v Version) CoversID(id OpID) bool {
    if id.Incarnation != v.Incarnation {
        return id.Incarnation < v.Incarnation
    }
    if id.Wrap != v.Wrap {
        return id.Wrap < v.Wrap
    }
    return id.Epoch <= v.Epoch
}

func (v Version) CoversVersion(o Version) bool {
    if o.Incarnation != v.Incarnation {
        return o.Incarnation < v.Incarnation
    }
    if o.Wrap != v.Wrap {
        return o.Wrap < v.Wrap
    }
    return o.Epoch <= v.Epoch
}

func (v Version) Less(o Version) bool {
    if v.Incarnation != o.Incarnation {
        return v.Incarnation < o.Incarnation
    }
    if v.Wrap != o.Wrap {
        return v.Wrap < o.Wrap
    }
    return v.Epoch < o.Epoch
}

type VV map[uint64]Version

func (vv VV) Clone() VV {
    out := make(VV, len(vv))
    for k, v := range vv {
        out[k] = v
    }
    return out
}

func (vv VV) Join(o VV) {
    for r, v := range o {
        if cur, ok := vv[r]; !ok || cur.Less(v) {
            vv[r] = v
        }
    }
}

func (vv VV) CoversID(id OpID) bool {
    v, ok := vv[id.Replica]
    return ok && v.CoversID(id)
}

func (vv VV) CoversVV(o VV) bool {
    for r, ov := range o {
        v, ok := vv[r]
        if !ok || !v.CoversVersion(ov) {
            return false
        }
    }
    return true
}

func inRange(key, lo, hi string) bool { return key >= lo && key < hi }

// ---------------------------------------------------------------------------
// Operations
// ---------------------------------------------------------------------------

type Put struct {
    ID  OpID
    Key string
    Val string
}

type Del struct {
    ID  OpID
    Lo  string
    Hi  string
    Ctx VV // causal context observed when the tombstone was created
}

type Op struct {
    Put *Put
    Del *Del
}

// ---------------------------------------------------------------------------
// Bounded replica
// ---------------------------------------------------------------------------

type Config struct {
    ReplicaID uint64
    EpochMod  uint64
    WrapLimit uint64
}

type Replica struct {
    cfg       Config
    clock     Version
    truncated bool
    vv        VV
    live      map[string]map[OpID]Put
    dels      []Del
    delSeen   map[OpID]bool
}

func NewReplica(cfg Config) *Replica {
    if cfg.EpochMod == 0 {
        cfg.EpochMod = 1 << 32
    }
    if cfg.WrapLimit == 0 {
        cfg.WrapLimit = 1 << 32
    }
    return &Replica{
        cfg:     cfg,
        vv:      VV{},
        live:    map[string]map[OpID]Put{},
        delSeen: map[OpID]bool{},
    }
}

func (r *Replica) Reincarnate() {
    r.clock = Version{Incarnation: r.clock.Incarnation + 1}
}

func (r *Replica) nextID() OpID {
    r.clock.Epoch++
    if r.clock.Epoch >= r.cfg.EpochMod {
        r.clock.Epoch = 0
        r.clock.Wrap++
        if r.clock.Wrap >= r.cfg.WrapLimit {
            r.truncated = true
        }
    }
    return OpID{
        Replica:     r.cfg.ReplicaID,
        Incarnation: r.clock.Incarnation,
        Wrap:        r.clock.Wrap,
        Epoch:       r.clock.Epoch,
    }
}

func (r *Replica) Put(key, val string) Put {
    id := r.nextID()
    p := Put{ID: id, Key: key, Val: val}
    r.applyPut(p)
    r.observe(id)
    return p
}

func (r *Replica) DeleteRange(lo, hi string) Del {
    id := r.nextID()
    d := Del{ID: id, Lo: lo, Hi: hi, Ctx: r.vv.Clone()}
    r.applyDel(d)
    r.observe(id)
    return d
}

func (r *Replica) Apply(op Op) {
    switch {
    case op.Put != nil:
        r.applyPut(*op.Put)
        r.observe(op.Put.ID)
    case op.Del != nil:
        r.applyDel(*op.Del)
        r.observe(op.Del.ID)
    }
}

func (r *Replica) applyPut(p Put) {
    for i := range r.dels {
        d := &r.dels[i]
        if inRange(p.Key, d.Lo, d.Hi) && d.Ctx.CoversID(p.ID) {
            return
        }
    }
    m := r.live[p.Key]
    if m == nil {
        m = map[OpID]Put{}
        r.live[p.Key] = m
    }
    m[p.ID] = p
}

func (r *Replica) applyDel(d Del) {
    if r.delSeen[d.ID] {
        return
    }
    r.delSeen[d.ID] = true
    for key, m := range r.live {
        if !inRange(key, d.Lo, d.Hi) {
            continue
        }
        for id := range m {
            if d.Ctx.CoversID(id) {
                delete(m, id)
            }
        }
        if len(m) == 0 {
            delete(r.live, key)
        }
    }
    r.dels = append(r.dels, d)
}

func (r *Replica) observe(id OpID) {
    nv := Version{Incarnation: id.Incarnation, Wrap: id.Wrap, Epoch: id.Epoch}
    if cur, ok := r.vv[id.Replica]; !ok || cur.Less(nv) {
        r.vv[id.Replica] = nv
    }
}

func (r *Replica) Merge(o *Replica) {
    for _, m := range o.live {
        for _, p := range m {
            r.applyPut(p)
            r.observe(p.ID)
        }
    }
    for i := range o.dels {
        r.applyDel(o.dels[i])
        r.observe(o.dels[i].ID)
    }
    r.vv.Join(o.vv)
    if o.truncated {
        r.truncated = true
    }
}

func (r *Replica) Snapshot() map[string]string {
    out := make(map[string]string, len(r.live))
    for k, m := range r.live {
        var best *Put
        for _, p := range m {
            pp := p
            if best == nil || best.ID.Less(pp.ID) {
                best = &pp
            }
        }
        if best != nil {
            out[k] = best.Val
        }
    }
    return out
}

func (r *Replica) Compact(f VV) int {
    kept := r.dels[:0]
    dropped := 0
    for i := range r.dels {
        d := r.dels[i]
        if f.CoversID(d.ID) && f.CoversVV(d.Ctx) {
            dropped++
            delete(r.delSeen, d.ID)
            continue
        }
        kept = append(kept, d)
    }
    r.dels = kept
    return dropped
}

// ---------------------------------------------------------------------------
// Reference history-retaining interpreter
// ---------------------------------------------------------------------------

type Ref struct {
    puts map[OpID]Put
    dels []Del
}

func NewRef() *Ref { return &Ref{puts: map[OpID]Put{}} }

func (r *Ref) Apply(op Op) {
    switch {
    case op.Put != nil:
        r.puts[op.Put.ID] = *op.Put
    case op.Del != nil:
        r.dels = append(r.dels, *op.Del)
    }
}

func (r *Ref) live(id OpID) bool {
    p := r.puts[id]
    for i := range r.dels {
        d := &r.dels[i]
        if inRange(p.Key, d.Lo, d.Hi) && d.Ctx.CoversID(id) {
            return false
        }
    }
    return true
}

func (r *Ref) Snapshot() map[string]string {
    out := map[string]string{}
    best := map[string]OpID{}
    for id := range r.puts {
        if !r.live(id) {
            continue
        }
        p := r.puts[id]
        if cur, ok := best[p.Key]; !ok || cur.Less(id) {
            best[p.Key] = id
            out[p.Key] = p.Val
        }
    }
    return out
}

// ---------------------------------------------------------------------------
// Bounded frontier
// ---------------------------------------------------------------------------

type Summary struct {
    ReplicaID uint64
    Vers      VV
    Truncated bool
}

func (r *Replica) Summary() Summary {
    return Summary{ReplicaID: r.cfg.ReplicaID, Vers: r.vv.Clone(), Truncated: r.truncated}
}

func MaxSafeFrontier(summaries []Summary) (VV, error) {
    if len(summaries) == 0 {
        return VV{}, nil
    }
    for _, s := range summaries {
        if s.Truncated {
            return nil, ErrNoBoundedFrontier
        }
    }
    replicas := map[uint64]bool{}
    for _, s := range summaries {
        for r := range s.Vers {
            replicas[r] = true
        }
    }
    f := VV{}
    for r := range replicas {
        var min Version
        found := false
        complete := true
        for _, s := range summaries {
            v, ok := s.Vers[r]
            if !ok {
                complete = false
                break
            }
            if !found || v.Less(min) {
                min = v
                found = true
            }
        }
        if complete && found {
            f[r] = min
        }
    }
    return f, nil
}

// ---------------------------------------------------------------------------
// Demonstration + differential verification
// ---------------------------------------------------------------------------

func generateHistory(rng *rand.Rand, n, steps int) []Op {
    gens := make([]*Replica, n)
    for i := range gens {
        gens[i] = NewReplica(Config{ReplicaID: uint64(i), EpochMod: 6})
    }
    keys := []string{"a", "b", "c", "d", "e", "f", "g"}
    var events []Op
    for s := 0; s < steps; s++ {
        g := gens[rng.Intn(n)]
        if rng.Intn(8) == 0 {
            g.Reincarnate()
        }
        if rng.Intn(3) == 0 {
            i := rng.Intn(len(keys) - 1)
            j := i + 1 + rng.Intn(len(keys)-1-i)
            d := g.DeleteRange(keys[i], keys[j]+"\x00")
            events = append(events, Op{Del: &d})
        } else {
            k := keys[rng.Intn(len(keys))]
            v := fmt.Sprintf("r%d-s%d", g.cfg.ReplicaID, s)
            p := g.Put(k, v)
            events = append(events, Op{Put: &p})
        }
        for d := 0; d < rng.Intn(4) && len(events) > 0; d++ {
            g.Apply(events[rng.Intn(len(events))])
        }
    }
    return events
}

func fail(format string, args ...any) {
    fmt.Fprintf(os.Stderr, "FAIL: "+format+"\n", args...)
    os.Exit(1)
}

func equal(a, b map[string]string) bool { return reflect.DeepEqual(a, b) }

func main() {
    // 1. Wrap regression: a pre-wrap tombstone must not remove a post-wrap put.
    w := NewReplica(Config{ReplicaID: 1, EpochMod: 4})
    w.Put("k", "v0")
    w.DeleteRange("a", "z")
    w.Put("k", "v1")
    p3 := w.Put("k", "v2") // wraps to Wrap=1, Epoch=0
    if p3.ID.Wrap != 1 || p3.ID.Epoch != 0 {
        fail("expected an epoch wrap, got %+v", p3.ID)
    }
    if !equal(w.Snapshot(), map[string]string{"k": "v2"}) {
        fail("post-wrap insert removed by pre-wrap tombstone: %v", w.Snapshot())
    }

    // 2. Reincarnation: new-incarnation ops survive old tombstones.
    ri := NewReplica(Config{ReplicaID: 1, EpochMod: 4})
    ri.Put("k", "old")
    ri.DeleteRange("a", "z")
    ri.Reincarnate()
    ri.Put("k", "new")
    if !equal(ri.Snapshot(), map[string]string{"k": "new"}) {
        fail("reincarnated insert removed: %v", ri.Snapshot())
    }

    // 3. Randomized differential convergence + frontier compaction.
    for seed := int64(1); seed <= 500; seed++ {
        rng := rand.New(rand.NewSource(seed))
        events := generateHistory(rng, 3, 120)
        ref := NewRef()
        for _, op := range events {
            ref.Apply(op)
        }
        want := ref.Snapshot()
        for c := 0; c < 4; c++ {
            consumer := NewReplica(Config{ReplicaID: uint64(100 + c), EpochMod: 8})
            for _, i := range rng.Perm(len(events)) {
                consumer.Apply(events[i])
            }
            if !equal(consumer.Snapshot(), want) {
                fail("seed %d consumer %d diverged: got %v want %v",
                    seed, c, consumer.Snapshot(), want)
            }
            f, err := MaxSafeFrontier([]Summary{consumer.Summary()})
            if err != nil {
                fail("seed %d unexpected no-frontier: %v", seed, err)
            }
            consumer.Compact(f)
            if !equal(consumer.Snapshot(), want) {
                fail("seed %d compaction changed snapshot", seed)
            }
        }
    }

    // 4. No-bounded-frontier detection.
    tr := NewReplica(Config{ReplicaID: 1, EpochMod: 2, WrapLimit: 2})
    for i := 0; i < 10; i++ {
        tr.Put("k", "v")
    }
    if _, err := MaxSafeFrontier([]Summary{tr.Summary()}); err != ErrNoBoundedFrontier {
        fail("expected ErrNoBoundedFrontier, got %v", err)
    }

    fmt.Println("OK: observed-remove, wrap/reincarnation, 500x differential schedules, frontier certification")
}

The assertions that make this a proof rather than a smoke test:

  • TestObservedRemoveBasic — an observed insert is removed, a concurrent insert survives.
  • TestEpochWrapReincarnation — a pre-wrap tombstone must not remove a post-wrap insert; a post-wrap tombstone must. It also demonstrates that the raw-epoch comparison is wrong on the same input.

  • TestConvergenceRandomSchedules / TestExhaustiveInterleavings — every delivery order (including duplicates) converges to the reference event interpreter.
  • TestConvergenceViaMerge — pairwise Merge reaches the same fixpoint and compaction at the certified frontier preserves the snapshot.
  • TestFrontierMinimal / TestUnsafeCompactionBeyondFrontier — the componentwise minimum is the maximal safe frontier; compacting past it leaves a ghost tombstone and diverges from the reference.
  • TestNoBoundedFrontier — a truncated (wrap-qualification-lost) summary yields ErrNoBoundedFrontier.

Complexity / bounds

Per replica the engine retains only live puts plus tombstones that are not yet causally stable, so memory is bounded by concurrency, not history length. Merge and Apply are idempotent and order independent; Compact is monotone and never revisits a forgotten tombstone. The frontier is computed in one pass over the summaries in O(replicas²) versions.
