Fix: live-substrate gate reds on teardown 409 while an unrelated hourly sync holds the namespace lock

Problem class: python-gate-substrate-window

Symptom

A repo gate that runs live-substrate integration tests turns red. The red is a teardown failure (delete returns 409 Conflict), so the report points at the test teardown fixture, not at the code under review. It happens intermittently, roughly once an hour, and always correlates with an unrelated periodic sync service being mid-run.

The trap: the diff is blamed, reviewers burn time on a "flaky teardown", and the real cause (namespace-lock contention from the sync service) is invisible because the gate launched inside the sync window.

Root-cause analysis

  1. Shared resource, transient lock. The integration suite creates a namespace (POST → 201) and tears it down (DELETE → 200). An unrelated hourly sync service acquires the same namespace lock while it runs. During that window, teardown gets 409 Conflict.

  2. The failure names the wrong layer. The 409 surfaces on the teardown call, so the gate's assertion/report says "teardown failed". Nothing in the failure message mentions the sync service or the lock.

  3. The window guard was reading the wrong property. The gate tried to avoid the sync window by inspecting the timer, but on the affected hosts:

  4. systemctl --user show <timer>.timer -p NextElapseUSecRealtime --value prints empty, and
  5. -p NextElapseUSecMonotonic --value prints infinity.

infinity (or an empty realtime) means "the gate can't see an upcoming fire", but the old logic effectively treated it as a safe/infinite window and launched anyway — straight into the lock. The real next-fire time is still present in systemctl --user list-timers.

  1. No preflight, no attribution. The gate never proved the substrate was actually lock-free before launching, and had no way to classify a red as environment evidence versus a regression.

Decision logic that fixes it

real next-fire  = list-timers NEXT column   (fallback: show realtime, then monotonic)
clear window    = next-fire - now
if sync service ActiveState == active: block
if window unknown:                     block (fail closed)
if window < 1500s:                     defer (do not launch)
probe create=201 then delete=200:      else block as environment
run suite
  green                          -> pass (0)
  red matching teardown 409      -> environment (2), attributed
  any other red                  -> regression (1)

1500 s (25 min) is intentionally larger than the sync's worst-case run so teardown cannot land in the lock window.

The fix

1. Resolve the real next-fire time (the crux)

With --timestamp=unix, the first whitespace token of a list-timers line is NEXT, and UNIT / ACTIVATES are the last two tokens. Anchoring on the last two tokens sidesteps the fact that the human LAST / PASSED columns contain spaces:

systemctl --user list-timers --all --no-pager --no-legend --timestamp=unix
# <NEXT_unix|n/a> <LEFT> <LAST_unix|n/a> <PASSED> <UNIT> <ACTIVATES>

Manual one-liner to check the window before pushing:

unit=sync-hourly.timer
next=$(systemctl --user list-timers --all --no-pager --no-legend --timestamp=unix \
       | awk -v u="$unit" '$0 ~ u {print $1; exit}')
now=$(date +%s)
echo "clear window: $(( next - now ))s"

2. Drop in the gate wrapper

Save as scripts/substrate_window_gate.py, chmod +x, and have CI call it instead of the raw suite. Exit codes: 0 pass, 1 regression, 2 environment (defer/retry, do not blame the diff). The full, verified script is saved at /workspace/verify/substrate_window_gate.py and embedded below:

#!/usr/bin/env python3
"""substrate_window_gate.py -- guard a live-substrate repo gate against an
unrelated periodic sync service that transiently holds the namespace lock.

The script:
  1. finds the REAL next-fire time of the sync timer (systemctl --user),
  2. requires a clear window of >= --min-window seconds before launching,
  3. probes the substrate with create (expect 201) then delete (expect 200),
  4. runs the suite, and
  5. classifies a teardown 409 as ENVIRONMENT evidence bound to the sync
     service's active window -- never as a code regression.

Exit codes: 0 = pass, 1 = code regression, 2 = environment (blocked/blocked-red).

No third-party dependencies (stdlib only).
"""
from __future__ import annotations

import argparse
import json
import os
import re
import shutil
import subprocess
import sys
import time
import urllib.error
import urllib.request
import uuid
from datetime import datetime, timezone

def _run(cmd: list[str], timeout: float = 15.0) -> subprocess.CompletedProcess:
    return subprocess.run(
        cmd, capture_output=True, text=True, timeout=timeout, check=False
    )


def _show(unit: str, prop: str) -> str:
    """`systemctl --user show <unit> -p <prop> --value` (empty on failure)."""
    if not shutil.which("systemctl"):
        return ""
    cp = _run(["systemctl", "--user", "show", unit, "-p", prop, "--value"])
    return cp.stdout.strip()


_SYSTEMD_UNITS = {
    "us": 1e-6,
    "ms": 1e-3,
    "s": 1.0,
    "sec": 1.0,
    "second": 1.0,
    "seconds": 1.0,
    "m": 60.0,
    "min": 60.0,
    "minute": 60.0,
    "minutes": 60.0,
    "h": 3600.0,
    "hr": 3600.0,
    "hour": 3600.0,
    "hours": 3600.0,
    "d": 86400.0,
    "day": 86400.0,
    "days": 86400.0,
    "w": 604800.0,
    "week": 604800.0,
    "weeks": 604800.0,
    "month": 2629800.0,
    "year": 31557600.0,
}


def parse_systemd_span(text: str) -> float | None:
    """Parse '1h 30min 5s' -> seconds. 'infinity'/'' -> None."""
    text = (text or "").strip()
    if not text or text.lower() in {"infinity", "inf", "n/a", "-"}:
        return None
    total = 0.0
    found = False
    for value, unit in re.findall(
        r"([0-9]+(?:\.[0-9]+)?)\s*([a-zA-Z]+)", text
    ):
        factor = _SYSTEMD_UNITS.get(unit.lower())
        if factor is not None:
            total += float(value) * factor
            found = True
    return total if found else None


def parse_realtime(text: str) -> float | None:
    """Parse the many shapes `NextElapseUSecRealtime` can take -> epoch."""
    text = (text or "").strip()
    if not text or text.lower() in {"infinity", "n/a", "0", "-"}:
        return None
    # Pure epoch (systemctl --timestamp=unix or -p ...USecRealtime can render secs)
    if re.fullmatch(r"[0-9]+(?:\.[0-9]+)?", text):
        v = float(text)
        return v / 1_000_000.0 if v > 1e12 else v
    # ISO-8601
    try:
        return datetime.fromisoformat(text.replace("Z", "+00:00")).timestamp()
    except ValueError:
        pass
    # "Sun 2026-11-15 06:00:00 UTC"
    for fmt in ("%a %Y-%m-%d %H:%M:%S %Z", "%a %Y-%m-%d %H:%M:%S"):
        try:
            dt = datetime.strptime(text, fmt)
            return dt.replace(tzinfo=timezone.utc).timestamp()
        except ValueError:
            continue
    return None


def next_fire_epoch(unit: str, now: float) -> tuple[float | None, str]:
    """Return (epoch, source). Order: precise realtime -> list-timers -> monotonic.

    This is the crux of the bug: on the affected host `NextElapseUSecRealtime`
    is empty and `NextElapseUSecMonotonic` reads `infinity`, so neither `show`
    property works. `list-timers` still prints the real NEXT column.
    """
    # 1. Precise realtime property.
    real = parse_realtime(_show(unit, "NextElapseUSecRealtime"))
    if real is not None:
        return real, "show:NextElapseUSecRealtime"

    # 2. Parse `list-timers --timestamp=unix`. With unix timestamps the first
    #    token is NEXT; UNIT/ACTIVATES are the last two whitespace tokens, so
    #    the human "LAST"/"PASSED" columns (which contain spaces) are harmless.
    if shutil.which("systemctl"):
        cp = _run([
            "systemctl", "--user", "list-timers", "--all",
            "--no-pager", "--no-legend", "--timestamp=unix",
        ])
        for line in cp.stdout.splitlines():
            tok = line.split()
            if len(tok) < 2:
                continue
            if tok[-2] != unit:  # unit is second-to-last token
                continue
            first = tok[0]
            if re.fullmatch(r"[0-9]+", first):
                return float(first), "list-timers:Next(unix)"
        # 2b. Fallback for systemd without --timestamp=unix: parse the pretty
        #     NEXT from the same last-two-token anchored line.
        for line in cp.stdout.splitlines():
            tok = line.split()
            if len(tok) < 2 or tok[-2] != unit:
                continue
            m = re.match(
                r"(\w{3}\s+\d{4}-\d{2}-\d{2}\s+\d{2}:\d{2}:\d{2}\s+\w+)", line
            )
            if m:
                return parse_realtime(m.group(1) + " UTC"), "list-timers:Next(pretty)"

    # 3. Monotonic span rendered relative to now.
    span = parse_systemd_span(_show(unit, "NextElapseUSecMonotonic"))
    if span is not None:
        return now + span, "show:NextElapseUSecMonotonic"

    return None, "unavailable"


def service_active_state(service: str) -> tuple[bool, float | None]:
    """Return (is_active_now, epoch_when_activated_or_None).

    A missing ActiveEnterTimestamp must NOT be read as 'not active': the
    service can be up with an unparseable timestamp, and that is still a held
    lock.  Only ActiveState decides busy-vs-not.
    """
    active = _show(service, "ActiveState") == "active"
    ts = parse_realtime(_show(service, "ActiveEnterTimestamp")) if active else None
    return active, ts


# --------------------------------------------------------------------------
# substrate probe
# --------------------------------------------------------------------------
class ProbeError(Exception):
    pass


def http_request(method: str, url: str, body: dict | None, timeout: float = 10.0):
    data = json.dumps(body).encode() if body is not None else None
    req = urllib.request.Request(url, data=data, method=method)
    if data is not None:
        req.add_header("Content-Type", "application/json")
    try:
        with urllib.request.urlopen(req, timeout=timeout) as resp:
            raw = resp.read().decode(errors="replace")
            return resp.status, raw
    except urllib.error.HTTPError as e:
        return e.code, e.read().decode(errors="replace")
    except (urllib.error.URLError, TimeoutError, OSError) as e:
        raise ProbeError(f"{method} {url}: transport error: {e}") from e


def probe_namespace(args) -> dict:
    """create=201 then delete=200. 409 anywhere == lock held (environment)."""
    name = f"{args.ns_prefix}-{os.getpid()}-{uuid.uuid4().hex[:8]}"
    base = args.base_url.rstrip("/")
    create_url = base + args.create_path
    delete_url = base + args.delete_path.format(name=name)
    out = {"namespace": name, "create": None, "delete": None}

    code, raw = http_request("POST", create_url, {"name": name}, args.probe_timeout)
    out["create"] = code
    if code == 409:
        out["verdict"] = "locked"
        out["detail"] = "create returned 409 Conflict (namespace lock held)"
        return out
    if code != 201:
        out["verdict"] = "error"
        out["detail"] = f"create returned {code}, expected 201: {raw[:200]}"
        return out

    code, raw = http_request("DELETE", delete_url, None, args.probe_timeout)
    out["delete"] = code
    if code == 409:
        out["verdict"] = "locked"
        out["detail"] = "delete returned 409 Conflict (namespace lock held)"
        return out
    if code != 200:
        out["verdict"] = "error"
        out["detail"] = f"delete returned {code}, expected 200: {raw[:200]}"
        return out

    out["verdict"] = "clear"
    out["detail"] = "create=201 delete=200"
    return out


# --------------------------------------------------------------------------
# reporting
# --------------------------------------------------------------------------
def emit(report: dict, path: str | None) -> None:
    report.setdefault("ts", datetime.now(timezone.utc).isoformat())
    payload = json.dumps(report, indent=2, sort_keys=True)
    print(payload)
    if path:
        with open(path, "w") as fh:
            fh.write(payload + "\n")


def env_report(reason: str, **extra) -> dict:
    r = {"decision": "environment", "reason": reason}
    r.update(extra)
    return r


# --------------------------------------------------------------------------
# main
# --------------------------------------------------------------------------
def main(argv=None) -> int:
    p = argparse.ArgumentParser(description=__doc__)
    p.add_argument("--timer", default="sync-hourly.timer",
                   help="systemd --user timer for the sync service")
    p.add_argument("--service", default=None,
                   help="sync service unit (default: timer with .service)")
    p.add_argument("--min-window", type=float, default=1500.0,
                   help="required clear seconds before launch (default 1500)")
    p.add_argument("--post-sync-buffer", type=float, default=120.0,
                   help="seconds to wait past next-fire before re-checking")
    p.add_argument("--max-wait", type=float, default=0.0,
                   help="if >0, sleep and retry instead of exiting 2")
    p.add_argument("--base-url", default="http://<ip-address>:8766")
    p.add_argument("--create-path", default="/api/namespaces")
    p.add_argument("--delete-path", default="/api/namespaces/{name}")
    p.add_argument("--ns-prefix", default="gate-probe")
    p.add_argument("--probe-timeout", type=float, default=10.0)
    p.add_argument("--skip-probe", action="store_true")
    p.add_argument("--suite-cmd", default=None,
                   help="shell command for the live-substrate suite")
    p.add_argument("--teardown-409-regex",
                   default=r"(?is)teardown.*\b409\b|\b409\b.*teardown")
    p.add_argument("--report", default=None)
    p.add_argument("--now-epoch", type=float, default=None,
                   help="override wall clock (testing only)")
    args = p.parse_args(argv)
    if args.service is None:
        args.service = args.timer.replace(".timer", ".service") \
            if args.timer.endswith(".timer") else args.timer

    report: dict = {"timer": args.timer, "service": args.service,
                    "min_window": args.min_window}

    # --- establish a clear window -----------------------------------------
    deadline = time.monotonic() + max(0.0, args.max_wait)
    while True:
        now = args.now_epoch if args.now_epoch is not None else time.time()
        nf, source = next_fire_epoch(args.timer, now)
        active, active_since = service_active_state(args.service)
        report.update({"now": now, "next_fire": nf, "next_fire_source": source,
                       "service_active": active,
                       "service_active_since": active_since})

        if active:
            report["clear_window"] = 0.0
            report["window_reason"] = "sync service is active right now"
            blocked = True
        elif nf is None:
            report["clear_window"] = None
            report["window_reason"] = (
                "next fire could not be determined from show properties or "
                "list-timers; refusing to launch blind"
            )
            blocked = True
        else:
            window = nf - now
            report["clear_window"] = window
            report["window_reason"] = f"{window:.0f}s until next fire"
            blocked = window < args.min_window

        if not blocked:
            break
        if args.max_wait <= 0 or time.monotonic() >= deadline:
            return _finish(env_report(
                "insufficient-clear-window",
                detail=report["window_reason"],
            ) | {"window": report}, args.report)
        # sleep past this fire (or a short poll when no fire is known)
        if nf is not None:
            sleep_for = max(5.0, (nf - now) + args.post_sync_buffer)
        else:
            sleep_for = 60.0
        sleep_for = min(sleep_for, max(1.0, deadline - time.monotonic()))
        time.sleep(sleep_for)

    # --- probe: create=201 / delete=200 -----------------------------------
    if args.skip_probe:
        report["probe"] = {"verdict": "skipped"}
    else:
        try:
            probe = probe_namespace(args)
        except ProbeError as e:
            return _finish(env_report("probe-transport-error", detail=str(e))
                           | {"window": report}, args.report)
        report["probe"] = probe
        if probe["verdict"] == "locked":
            # Lock is held mid-window (sync overran): re-check the window, do
            # not blame the diff.
            return _finish(env_report("namespace-lock-held", detail=probe["detail"])
                           | {"window": report}, args.report)
        if probe["verdict"] != "clear":
            return _finish(env_report("probe-failed", detail=probe["detail"])
                           | {"window": report}, args.report)

    # --- run the suite ----------------------------------------------------
    if not args.suite_cmd:
        return _finish({"decision": "pass", "reason": "preflight-only",
                        "probe": report.get("probe"), "window": report},
                       args.report)

    t0 = time.time()
    cp = subprocess.run(args.suite_cmd, shell=True, capture_output=True, text=True)
    output = (cp.stdout or "") + (cp.stderr or "")
    report["suite"] = {"exit_code": cp.returncode, "started": t0,
                       "finished": time.time()}
    report["suite_tail"] = output[-4000:]

    if cp.returncode == 0:
        return _finish({"decision": "pass", "reason": "suite-green",
                        "window": report}, args.report)

    teardown_409 = re.search(args.teardown_409_regex, output) is not None
    report["teardown_409"] = teardown_409
    if teardown_409:
        # Attribute to the sync service window: red occurred while a namespace
        # lock could be held, and the probe proved the substrate clean moments
        # earlier -- this is environment, not the diff.
        report["attribution"] = {
            "service": args.service,
            "service_active_since": report.get("service_active_since"),
            "next_fire": report.get("next_fire"),
            "probe": report.get("probe"),
            "note": ("probe was clear (create=201/delete=200) immediately "
                     "before the run; teardown 409 is lock contention from "
                     "the periodic sync, not a code regression"),
        }
        return _finish(env_report("teardown-409-lock-contention",
                                  detail="suite red matches teardown 409")
                       | {"window": report}, args.report)

    return _finish({"decision": "regression", "reason": "suite-red",
                    "window": report}, args.report)


def _finish(report: dict, path: str | None) -> int:
    emit(report, path)
    return {"pass": 0, "regression": 1, "environment": 2}[report["decision"]]


if __name__ == "__main__":
    sys.exit(main())

# Treat 2 as "environment, retry later" -- NOT as a code failure.
set +e
scripts/substrate_window_gate.py \
  --timer sync-hourly.timer \
  --service sync-hourly.service \
  --min-window 1500 \
  --max-wait 0 \
  --base-url http://<ip-address>:8766 \
  --suite-cmd "make integration-live" \
  --report gate-window.json
rc=$?
set -e
case "$rc" in
  0) echo "gate green" ;;
  1) echo "::error::code regression"; exit 1 ;;
  2) echo "::warning::environment (sync lock); report attached"; exit 0 ;;
esac

If you prefer to block-and-wait instead of deferring, set --max-wait 3600; the wrapper sleeps past the next fire plus --post-sync-buffer, then re-checks.

Why E is environment, not regression

The wrapper captured that the probe was create=201 / delete=200 immediately before the run. A red whose only signature is a teardown 409 seconds later, inside the sync service's active window, is lock contention — not a behavioral change from the diff. The attribution block in gate-window.json records the service, its ActiveState/ActiveEnterTimestamp, the next-fire time, and the clean probe, so the classification is auditable rather than a silent retry.

Operational guardrails

  • Fail closed. If next-fire can't be determined, do not launch. A blind launch is how the original red was produced.
  • Probe, don't assume. A clean window is necessary but not sufficient; the create=201/delete=200 probe proves the lock is free now.
  • Never retry a 1. Only exit 2 is eligible for automatic retry/defer.
  • Attach gate-window.json to the CI run so a teardown red carries its window evidence.
  • Watch for the sync overrunning. If namespace-lock-held fires often, the sync is taking longer than expected and --min-window/the service timeout need raising.
  • Alert on recurring 2s. Repeated environment exits can hide a genuinely broken sync service; track the rate rather than ignoring them.
