Delta-State CRDT Counter Gossip: Delta-Window Starvation, Stale-Ack Merge, and Interval-Overlap Anti-Entropy

Problem class: go-crdt-delta-state-antientropy-delta-window-starvation-stale-ack-merge · Environment: Go 1.26

TL;DR

Three coupled defects break convergence and liveness:

  1. A vector clock is blind to holes. A per-origin frontier (max seq) cannot distinguish {1,2,3,5} from {1..5}. Two replicas with equal frontiers can stay divergent forever.
  2. Stale acks are unioned, not replaced. Once a peer acks an interval, a union-style ack keeps the shipping window closed even after the peer loses/compacts that data, so it is never resent.
  3. Per-delta draining starves. If the 1 s tick ships individual increments under a fixed budget, a hot shard outruns the drain and the pending window grows unbounded.

Fix: represent applied state and delta windows as coalesced interval sets (join = union), reconcile with an interval-overlap check instead of a vector clock, make peer acks authoritative replacements, trigger state-based full sync when windows are disjoint, and make the gossip budget count coalesced intervals, not increments.

1. Root-cause analysis

2.1 Frontier ≠ set (holes invisible). G-Counter with join = max is only correct under in-order, lossless delivery. Under lossy gossip a replica can apply seq 5 without seq 4; storing max = 5 then silently counts 1..5.

local  A: [1..5]        frontier 5
remote A: [1..3],[5]    frontier 5   <- hole at 4
vector clock: 5 >= 5 -> "synced"      (WRONG)
intervals:    local \ remote = [4..4] -> resend

2.2 Stale ack closes a compacted window permanently.

A owns [1..5]; B applies+acks -> A.peerAck[B] = [1..5]
B rolls back to [1..3],[5]
A.peerAck[B] UNION [1..3],[5] = [1..5] -> window empty (WRONG, never repairs)

2.3 Disjoint windows after partition heal are miscalled "synced".

old side A:[1..5]   new side A:[10..15]
vector clock: 15 >= 5 -> send nothing (WRONG)
interval overlap: no common seq -> full state sync required

2.4 Hot-shard starvation. Pending FIFO of per-deltas + fixed drain N ⇒ queue (r-N)·t grows without bound. The representation, not the tick rate, is at fault: N sequential increments are one contiguous interval.

2. The exact fix

State per origin is a normalized set of inclusive intervals; the CRDT join is per-origin union (commutative, associative, idempotent). Counter value = total interval length. The critical decision function is interval-based, never frontier-based:

// Reconcile is the CORRECT anti-entropy decision: compare actual interval sets
// and their overlap, never vector clocks. A frontier cannot see holes, and two
// replicas with equal frontiers can still disagree about which deltas they have.
func Reconcile(local, remote Digest) ReconcileResult {
    res := ReconcileResult{Send: Digest{}, Want: Digest{}}
    for _, o := range unionOrigins(local, remote) {
        l := NewSet(local[o]...)
        r := NewSet(remote[o]...)
        if need := l.Difference(r); !need.Empty() {
            res.Send[o] = need.Intervals()
        }
        if want := r.Difference(l); !want.Empty() {
            res.Want[o] = want.Intervals()
        }
        // Delta-interval overlap check: no shared sequence number means the
        // windows were produced either side of a partition and per-delta repair
        // is insufficient -> escalate to a state-based full sync (always safe,
        // because the join is idempotent union).
        if !l.Empty() && !r.Empty() && !l.Overlaps(r) {
            res.FullSync = true
            res.Reason = "disjoint delta windows for origin " + o
        }
    }
    return res
}

Peer acks must be authoritative replacements, not unions:

// Ack records a peer's full applied digest. It REPLACES the old value so a peer
// that lost/compacted data re-opens the window. Unioning here is the stale-ack
// bug: it permanently hides deltas the peer no longer has.
func (n *Node) Ack(peer string, applied Digest) { n.peerAck[peer] = applied }

Gossip budget counts coalesced intervals, with a fragmentation fallback:

// PlanGossip: unit of work is a coalesced interval, not a single delta, so a hot
// shard producing a contiguous run costs ONE interval. Severely fragmented
// windows escalate to a full coalesced snapshot so bounded repair cannot be
// outrun by the producer.
func PlanGossip(local, peerAcked Digest, maxIntervals, fragHighWater int) GossipPlan {
    window, total := Digest{}, 0
    for o, ivs := range local {
        need := NewSet(ivs...).Difference(NewSet(peerAcked[o]...))
        if need.Empty() { continue }
        window[o] = need.Intervals()
        total += len(need.Intervals())
    }
    if fragHighWater > 0 && total > fragHighWater {
        return GossipPlan{Delta: local, FullSync: true, ...}
    }
    // ...ship up to maxIntervals *intervals* (not increments)...
}

Why merge is commutative even when one peer acked a range the other already compacted: per-origin state is a set and merge is ∪, which is commutative (A∪B=B∪A), associative, and idempotent (A∪A=A). A delta window and a compacted snapshot are both set fragments; an ack only changes the shipping decision, never the state. So any interleaving yields the same ∪ Sᵢ and identical value Σ|Sᵢ|.

4. Applying this to an existing codebase

  1. Replace map[origin]uint64 counter state with map[origin]IntervalSet; Merge = set union.
  2. Replace remote.frontier >= local.frontier gates with Reconcile(...) acting on Send/Want/FullSync.
  3. Change peerAck[peer] = union(old, reported) → peerAck[peer] = reported.
  4. Drain in units of coalesced intervals, coalescing on produce and again before ship.
  5. Add a fragmentation high-water mark that escalates to full-state sync.
  6. Keep the union-property tests in CI — they are the proof obligation for the compacted-range merge.
