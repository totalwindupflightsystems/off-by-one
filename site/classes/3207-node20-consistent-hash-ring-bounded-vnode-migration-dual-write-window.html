Bounded-Migration Consistent Hash Ring with a Dual-Write Cutover Window

Root-cause analysis

A naive consistent-hash implementation fails this problem in five distinct ways:

  1. Nondeterministic collision handling. Two virtual nodes can hash to the same token. If the ring stores only token -> node or relies on insertion order, different processes can disagree about the owner of keys in the colliding interval, causing split-brain writes and data loss on failover.
  2. Unbounded ownership movement. Rebalancing by rebuilding the whole ring, or by remapping several successor positions at once, can move a key through many owners during a join. There is no per-key migration budget and no atomic rejection when the budget would be exceeded.
  3. A hard cutover. The directory is switched to the new owner before the old copy is drained. Reads routed to the new owner then return not found, while the only valid copy is still on the old owner.
  4. Last-writer confusion during dual writes. If reads simply prefer the new owner, or pick the first copy they see, a stale old copy can mask a newer in-flight write. Writes must be versioned and reads must choose max(version, writeId) across all live copies.
  5. Lost in-flight writes. If a write is acknowledged after reaching only one side, or if the outbox entry is removed before every destination acknowledges it, a crash or join between phases loses the write. The fix requires a durable write intent, dynamic destination resolution, idempotent apply, retries, and a drain/close fence.

Invariants and the fix

  • Vnodes are sorted by (token, nodeId, replica). A key token is mapped to the first vnode whose token is >= keyToken; on an exact collision, the first vnode in the same deterministic order owns the key.
  • One join changes a key's primary owner by at most one hop. Existing vnode order is unchanged when a node is added. Therefore the successor of any key either stays the same or becomes the newly added node. The join is validated for every existing key before the live ring is mutated; if hops > K, the whole join is rejected atomically. K=0 is supported and rejects any join that would move an existing key.
  • During the window, a key may have several holders. Writes are written to all current candidates; reads inspect all candidates and return the record with the highest (version, writeId).
  • A write intent is inserted into the outbox before delivery. Destinations are resolved at delivery time, so a write in flight across a join automatically includes the new candidates. Delivery is idempotent by writeId + version; an entry leaves the outbox only after every current candidate has acknowledged it.
  • Drain copies the maximum record from every holder to the migration target. The window can close only when the outbox is empty, every key is drained, and the target dominates every source copy. Only then are old copies deleted.

At-least-once proof for in-flight writes

Let write w be accepted while the window is open.

  1. put(w) stores the intent in the outbox before attempting any delivery. If the process stops at any point, the intent is still replayable.
  2. The destination set is recomputed from the current ring, holders, and active migration at every delivery attempt. Thus a write that starts before a join but is delivered after it is sent to both sides; a write that reaches only the old side before the join is still in the old holder set and is copied by drain.
  3. _apply is monotone and idempotent: an older or equal (version, writeId) cannot overwrite a newer record, and replaying the same (version, writeId) with the same value is a no-op. Duplicate delivery therefore cannot corrupt state.
  4. The outbox entry is deleted only when every current candidate is in acked. If any destination fails, finishWindow() refuses to close because the outbox is non-empty. Retrying replays the same intent until at least one successful delivery exists at every required holder.
  5. Drain copies the maximum source record to the target. A write acknowledged before the join is present on an old holder and is therefore copied; a write acknowledged during the join is dual-written or drained. At window close, the target is the only remaining copy and is at least as new as every source.

Therefore every accepted in-flight write is delivered to at least one holder and, by drain/close, to the final owner; retries may deliver it more than once, but idempotence makes that safe. This is at-least-once delivery, not loss.

Exact implementation (consistent-ring.js)

'use strict';

/**
 * Deterministic consistent-hash ring + bounded-migration dual-write store.
 * Node 20 compatible (CommonJS, no dependencies).
 */

function fnv1a32(value) {
  const bytes = Buffer.from(String(value), 'utf8');
  let h = 0x811c9dc5;
  for (const b of bytes) {
    h ^= b;
    h = Math.imul(h, 0x01000193) >>> 0;
  }
  return h >>> 0;
}

function compareVnode(a, b) {
  if (a.token !== b.token) return a.token - b.token;
  if (a.nodeId !== b.nodeId) return a.nodeId < b.nodeId ? -1 : 1;
  return a.replica - b.replica;
}

function firstTokenGE(vnodes, token) {
  let lo = 0;
  let hi = vnodes.length;
  while (lo < hi) {
    const mid = (lo + hi) >>> 1;
    if (vnodes[mid].token < token) lo = mid + 1;
    else hi = mid;
  }
  return lo;
}

class ConsistentHashRing {
  constructor({ replicas = 128, hash = fnv1a32 } = {}) {
    if (!Number.isInteger(replicas) || replicas < 1) {
      throw new RangeError('replicas must be a positive integer');
    }
    if (typeof hash !== 'function') throw new TypeError('hash must be a function');
    this.replicas = replicas;
    this.hash = hash;
    this.nodes = new Set();
    this.vnodes = [];
  }

  tokenFor(nodeId, replica) {
    return this.hash(`${nodeId}#${replica}`) >>> 0;
  }

  addNode(nodeId, replicas = this.replicas) {
    if (typeof nodeId !== 'string' || nodeId.length === 0) {
      throw new TypeError('nodeId must be a non-empty string');
    }
    if (!Number.isInteger(replicas) || replicas < 1) {
      throw new RangeError('replicas must be a positive integer');
    }
    if (this.nodes.has(nodeId)) return [];

    const inserted = [];
    for (let replica = 0; replica < replicas; replica += 1) {
      inserted.push({
        token: this.tokenFor(nodeId, replica),
        nodeId,
        replica,
      });
    }
    this.nodes.add(nodeId);
    this.vnodes.push(...inserted);
    this.vnodes.sort(compareVnode);
    return inserted;
  }

  removeNode(nodeId) {
    if (!this.nodes.has(nodeId)) return false;
    this.nodes.delete(nodeId);
    this.vnodes = this.vnodes.filter((v) => v.nodeId !== nodeId);
    return true;
  }

  hasNode(nodeId) {
    return this.nodes.has(nodeId);
  }

  clone() {
    const copy = new ConsistentHashRing({
      replicas: this.replicas,
      hash: this.hash,
    });
    copy.nodes = new Set(this.nodes);
    copy.vnodes = this.vnodes.map((v) => ({ ...v }));
    return copy;
  }

  _startIndex(key) {
    if (this.vnodes.length === 0) throw new Error('ring is empty');
    const keyToken = this.hash(String(key)) >>> 0;
    const idx = firstTokenGE(this.vnodes, keyToken);
    return idx === this.vnodes.length ? 0 : idx;
  }

  primary(key) {
    return this.vnodes[this._startIndex(key)].nodeId;
  }

  ownersOf(key, count = 1) {
    if (!Number.isInteger(count) || count < 1) {
      throw new RangeError('count must be a positive integer');
    }
    const start = this._startIndex(key);
    const owners = [];
    const seen = new Set();
    for (let i = 0; i < this.vnodes.length && owners.length < count; i += 1) {
      const nodeId = this.vnodes[(start + i) % this.vnodes.length].nodeId;
      if (!seen.has(nodeId)) {
        seen.add(nodeId);
        owners.push(nodeId);
      }
    }
    return owners;
  }
}

class MigrationBudgetExceededError extends Error {
  constructor(message, details) {
    super(message);
    this.name = 'MigrationBudgetExceededError';
    this.details = details;
  }
}

function compareRecord(a, b) {
  if (!a && !b) return 0;
  if (!a) return -1;
  if (!b) return 1;
  if (a.version !== b.version) return a.version - b.version;
  if (a.writeId === b.writeId) return 0;
  return a.writeId < b.writeId ? -1 : 1;
}

/**
 * A primary-copy store (replicationFactor defaults to 1) implementing a
 * draining window. The ring keeps replica lookup support; migration below is
 * deliberately per-primary-copy so the K-hop proof is exact.
 */
class MigratingStore {
  constructor({
    ring = new ConsistentHashRing(),
    maxHopsPerJoin = 1,
    replicationFactor = 1,
    hash,
    replicas,
  } = {}) {
    if (ring && !(ring instanceof ConsistentHashRing)) {
      throw new TypeError('ring must be a ConsistentHashRing');
    }
    this.ring = ring || new ConsistentHashRing({ hash, replicas });
    this.maxHopsPerJoin = maxHopsPerJoin;
    this.replicationFactor = replicationFactor;
    this.data = new Map();          // ownerId -> Map(key -> record)
    this.holders = new Map();       // key -> Set(ownerId)
    this.migrations = new Map();    // key -> migration
    this.outbox = new Map();        // writeId -> write intent
    this.completed = new Map();     // writeId -> completed metadata
    this.versions = new Map();      // key -> highest observed version
    this.failOwners = new Set();    // deterministic fault injection
    this.deliveries = new Map();    // writeId -> Map(ownerId -> successful deliveries)
    this.writeSeq = 0;
  }

  _ownerData(ownerId) {
    let map = this.data.get(ownerId);
    if (!map) {
      map = new Map();
      this.data.set(ownerId, map);
    }
    return map;
  }

  _record(ownerId, key) {
    const map = this.data.get(ownerId);
    return map ? map.get(key) : undefined;
  }

  _rememberHolder(key, ownerId) {
    let set = this.holders.get(key);
    if (!set) {
      set = new Set();
      this.holders.set(key, set);
    }
    set.add(ownerId);
  }

  _maxRecordVersion(key) {
    let max = 0;
    for (const map of this.data.values()) {
      const rec = map.get(key);
      if (rec && rec.version > max) max = rec.version;
    }
    return max;
  }

  _nextVersion(key) {
    const current = Math.max(this.versions.get(key) || 0, this._maxRecordVersion(key));
    const version = current + 1;
    this.versions.set(key, version);
    return version;
  }

  _allKeys() {
    const keys = new Set(this.holders.keys());
    for (const key of this.migrations.keys()) keys.add(key);
    for (const map of this.data.values()) {
      for (const key of map.keys()) keys.add(key);
    }
    return keys;
  }

  candidateOwners(key) {
    const candidates = new Set(this.ring.ownersOf(key, this.replicationFactor));
    const held = this.holders.get(key);
    if (held) for (const ownerId of held) candidates.add(ownerId);
    const migration = this.migrations.get(key);
    if (migration) {
      candidates.add(migration.to);
      for (const ownerId of migration.from) candidates.add(ownerId);
    }
    return [...candidates].sort();
  }

  _apply(ownerId, key, record) {
    const map = this._ownerData(ownerId);
    const current = map.get(key);
    const cmp = compareRecord(record, current);
    if (cmp === 0 && current && current.value !== record.value) {
      throw new Error(`writeId ${record.writeId} was reused with a different value`);
    }
    if (cmp > 0) map.set(key, { ...record });
    this._rememberHolder(key, ownerId);
    const highest = this.versions.get(key) || 0;
    if (record.version > highest) this.versions.set(key, record.version);
    return cmp > 0;
  }

  _noteDelivery(writeId, ownerId) {
    let byOwner = this.deliveries.get(writeId);
    if (!byOwner) {
      byOwner = new Map();
      this.deliveries.set(writeId, byOwner);
    }
    byOwner.set(ownerId, (byOwner.get(ownerId) || 0) + 1);
  }

  deliveryCount(writeId, ownerId) {
    const byOwner = this.deliveries.get(writeId);
    return byOwner ? byOwner.get(ownerId) || 0 : 0;
  }

  _flushEntry(entry, failOwners = this.failOwners) {
    const owners = this.candidateOwners(entry.key);
    for (const ownerId of owners) {
      if (entry.acked.has(ownerId)) continue;
      if (failOwners.has(ownerId)) continue;
      this._apply(ownerId, entry.key, entry);
      entry.acked.add(ownerId);
      this._noteDelivery(entry.writeId, ownerId);
    }

    const remaining = this.candidateOwners(entry.key)
      .filter((ownerId) => !entry.acked.has(ownerId));
    if (remaining.length === 0) {
      this.outbox.delete(entry.writeId);
      this.completed.set(entry.writeId, {
        key: entry.key,
        value: entry.value,
        version: entry.version,
      });
      return { ok: true, writeId: entry.writeId, version: entry.version, pending: [] };
    }
    return {
      ok: false,
      writeId: entry.writeId,
      version: entry.version,
      pending: remaining,
    };
  }

  put(key, value, { writeId, version, failOwners } = {}) {
    const id = writeId || `w${++this.writeSeq}`;

    if (this.completed.has(id)) {
      const done = this.completed.get(id);
      if (done.key !== key || done.value !== value) {
        throw new Error(`completed writeId ${id} cannot be reused for another value`);
      }
      return { ok: true, writeId: id, version: done.version, duplicate: true, pending: [] };
    }

    let entry = this.outbox.get(id);
    if (entry) {
      if (entry.key !== key || entry.value !== value) {
        throw new Error(`in-flight writeId ${id} cannot be reused for another value`);
      }
    } else {
      const v = version === undefined ? this._nextVersion(key) : version;
      if (!Number.isSafeInteger(v) || v < 1) {
        throw new RangeError('version must be a positive safe integer');
      }
      this.versions.set(key, Math.max(this.versions.get(key) || 0, v));
      entry = {
        writeId: id,
        key,
        value,
        version: v,
        acked: new Set(),
      };
      this.outbox.set(id, entry);
    }
    return this._flushEntry(entry, failOwners || this.failOwners);
  }

  flushPending(failOwners = this.failOwners) {
    const entries = [...this.outbox.values()];
    const results = entries.map((entry) => this._flushEntry(entry, failOwners));
    return { pending: this.outbox.size, results };
  }

  get(key) {
    const owners = this.candidateOwners(key);
    let best = null;
    for (const ownerId of owners) {
      const rec = this._record(ownerId, key);
      if (rec && compareRecord(rec, best) > 0) best = rec;
    }
    return best
      ? { value: best.value, version: best.version, writeId: best.writeId, owners }
      : null;
  }

  join(nodeId, { maxHops = this.maxHopsPerJoin, replicas } = {}) {
    if (!Number.isInteger(maxHops) || maxHops < 0) {
      throw new RangeError('maxHops must be a non-negative integer');
    }
    if (this.ring.hasNode(nodeId)) {
      return { added: false, moved: 0, maxHopsObserved: 0, plans: [] };
    }

    const nextRing = this.ring.clone();
    nextRing.addNode(nodeId, replicas);

    // Validate the whole join before mutating the live ring. This makes a
    // budget rejection atomic: no partial vnode insertion is visible.
    const plans = [];
    let maxHopsObserved = 0;
    for (const key of this._allKeys()) {
      const oldPrimary = this.ring.primary(key);
      const newPrimary = nextRing.primary(key);
      let hops = 0;
      if (oldPrimary !== newPrimary) {
        // Adding one node can only change the successor to that new node.
        if (newPrimary !== nodeId) {
          throw new Error('internal invariant broken: a join changed owner to an existing node');
        }
        hops = 1;
      }
      if (hops > maxHopsObserved) maxHopsObserved = hops;
      if (hops > maxHops) {
        throw new MigrationBudgetExceededError(
          `join ${nodeId} would move key ${key} ${hops} hop(s), budget is ${maxHops}`,
          { key, oldPrimary, newPrimary, hops, maxHops },
        );
      }
      plans.push({ key, oldPrimary, newPrimary, hops });
    }

    this.ring = nextRing;
    let moved = 0;
    for (const plan of plans) {
      if (plan.hops === 0) continue;
      moved += 1;
      const key = plan.key;
      const previous = this.migrations.get(key);
      const from = new Set();

      // Every copy that may contain this key is a drain source.
      const held = this.holders.get(key);
      if (held) for (const ownerId of held) from.add(ownerId);
      if (previous) {
        from.add(previous.to);
        for (const ownerId of previous.from) from.add(ownerId);
      }
      from.add(plan.oldPrimary);
      from.delete(plan.newPrimary);

      this.migrations.set(key, {
        key,
        from,
        to: plan.newPrimary,
        status: 'draining',
        epoch: (previous ? previous.epoch : 0) + 1,
      });
      this._rememberHolder(key, plan.newPrimary);
      for (const ownerId of from) this._rememberHolder(key, ownerId);
    }

    return { added: true, moved, maxHopsObserved, plans };
  }

  addNode(nodeId, options) {
    return this.join(nodeId, options);
  }

  drain() {
    let copied = 0;
    for (const migration of this.migrations.values()) {
      const key = migration.key;
      const target = migration.to;
      const sources = new Set([
        ...(this.holders.get(key) || []),
        ...migration.from,
        this.ring.primary(key),
      ]);
      sources.delete(target);

      let best = this._record(target, key);
      for (const ownerId of sources) {
        const rec = this._record(ownerId, key);
        if (rec && compareRecord(rec, best) > 0) best = rec;
      }
      if (best) {
        const current = this._record(target, key);
        if (compareRecord(best, current) > 0) {
          this._apply(target, key, best);
          copied += 1;
        }
      }

      const targetRecord = this._record(target, key);
      let targetIsAtLeastAllSources = true;
      for (const ownerId of sources) {
        const rec = this._record(ownerId, key);
        if (rec && compareRecord(rec, targetRecord) > 0) {
          targetIsAtLeastAllSources = false;
          break;
        }
      }
      const pendingForThisKey = [...this.outbox.values()].some((e) => e.key === key);
      migration.status = targetIsAtLeastAllSources && !pendingForThisKey
        ? 'drained'
        : 'draining';
    }
    return {
      copied,
      open: this.migrations.size,
      undrained: [...this.migrations.values()].filter((m) => m.status !== 'drained').length,
    };
  }

  finishWindow() {
    if (this.outbox.size > 0) {
      throw new Error(`cannot close dual-write window: ${this.outbox.size} write(s) still in flight`);
    }
    this.drain();
    const undrained = [...this.migrations.values()].filter((m) => m.status !== 'drained');
    if (undrained.length > 0) {
      throw new Error(`cannot close dual-write window: ${undrained.length} key(s) not drained`);
    }

    // Final fence: target must dominate every remaining source before old
    // copies are removed. A read can therefore never fall back to stale data.
    for (const migration of this.migrations.values()) {
      const target = migration.to;
      const currentPrimary = this.ring.primary(migration.key);
      if (currentPrimary !== target) {
        throw new Error(`internal invariant broken: migration target ${target} != primary ${currentPrimary}`);
      }
      const targetRecord = this._record(target, migration.key);
      const allSources = new Set([
        ...(this.holders.get(migration.key) || []),
        ...migration.from,
      ]);
      for (const ownerId of allSources) {
        if (ownerId === target) continue;
        const rec = this._record(ownerId, migration.key);
        if (rec && compareRecord(rec, targetRecord) > 0) {
          throw new Error(`cannot close window: ${ownerId} is newer than target ${target}`);
        }
      }
    }

    let deleted = 0;
    for (const migration of this.migrations.values()) {
      const key = migration.key;
      const keep = migration.to;
      const allHolders = new Set([
        ...(this.holders.get(key) || []),
        ...migration.from,
        keep,
      ]);
      for (const ownerId of allHolders) {
        if (ownerId === keep) continue;
        const map = this.data.get(ownerId);
        if (map && map.delete(key)) deleted += 1;
        if (map && map.size === 0) this.data.delete(ownerId);
      }
      this.holders.set(key, new Set([keep]));
    }

    const closed = this.migrations.size;
    this.migrations.clear();
    return { closed, deletedStaleCopies: deleted };
  }

  isWindowOpen() {
    return this.migrations.size > 0;
  }
}

'use strict';

const assert = require('node:assert/strict');
const {
  fnv1a32,
  ConsistentHashRing,
  MigratingStore,
  MigrationBudgetExceededError,
} = require('./consistent-ring');

function test(name, fn) {
  try {
    fn();
    console.log(`ok - ${name}`);
  } catch (err) {
    console.error(`not ok - ${name}`);
    throw err;
  }
}

function collisionRing() {
  const hash = (s) => {
    if (s === 'node-a#0' || s === 'node-b#0' || s === 'K') return 42;
    return fnv1a32(s);
  };
  return new ConsistentHashRing({ replicas: 1, hash });
}

function twoNodeMigrationHash(s) {
  if (s === 'old#0') return 200;
  if (s === 'new#0') return 100;
  if (s === 'k') return 50;
  return fnv1a32(s);
}

function threeNodeMigrationHash(s) {
  if (s === 'old#0') return 300;
  if (s === 'mid#0') return 200;
  if (s === 'new#0') return 100;
  if (s === 'k') return 50;
  return fnv1a32(s);
}

test('vnode collisions use a deterministic (token,nodeId,replica) tie-break', () => {
  const r1 = collisionRing();
  r1.addNode('node-b');
  r1.addNode('node-a');

  const r2 = collisionRing();
  r2.addNode('node-a');
  r2.addNode('node-b');

  assert.equal(r1.primary('K'), 'node-a');
  assert.equal(r2.primary('K'), 'node-a');
  assert.deepEqual(r1.ownersOf('K', 2), ['node-a', 'node-b']);
  assert.deepEqual(r2.ownersOf('K', 2), ['node-a', 'node-b']);
});

test('one join moves every existing key at most one hop (K=1)', () => {
  const store = new MigratingStore({ ring: new ConsistentHashRing({ replicas: 32 }) });
  for (const node of ['n0', 'n1', 'n2']) store.join(node);

  const keys = Array.from({ length: 250 }, (_, i) => `key:${i}`);
  for (const key of keys) store.put(key, `value:${key}`);

  const before = new Map(keys.map((key) => [key, store.ring.primary(key)]));
  const result = store.join('n3', { maxHops: 1 });

  assert.ok(result.moved > 0, 'test should actually exercise a migration');
  assert.ok(result.maxHopsObserved <= 1);
  for (const plan of result.plans) {
    assert.ok(plan.hops <= 1, `key ${plan.key} moved ${plan.hops} hops`);
    if (plan.hops === 1) {
      assert.equal(plan.newPrimary, 'n3');
      assert.notEqual(plan.oldPrimary, 'n3');
    }
    assert.equal(plan.oldPrimary, before.get(plan.key));
  }

  store.drain();
  store.finishWindow();
  for (const key of keys) {
    assert.equal(store.get(key).value, `value:${key}`);
    assert.equal(store.ring.primary(key), store.get(key).owners[0]);
  }
});

test('K=0 rejects an ownership-moving join atomically, then K=1 succeeds', () => {
  const ring = new ConsistentHashRing({ replicas: 1, hash: twoNodeMigrationHash });
  ring.addNode('old');
  const store = new MigratingStore({ ring });
  store.put('k', 'v1', { writeId: 'w-budget' });
  assert.equal(ring.primary('k'), 'old');

  assert.throws(
    () => store.join('new', { maxHops: 0 }),
    (err) => err instanceof MigrationBudgetExceededError
      && err.details.key === 'k'
      && err.details.hops === 1,
  );
  assert.equal(store.ring.hasNode('new'), false, 'rejected join must not partially mutate ring');
  assert.equal(store.ring.primary('k'), 'old');
  assert.equal(store.get('k').value, 'v1');

  const joined = store.join('new', { maxHops: 1 });
  assert.equal(joined.moved, 1);
  assert.equal(joined.maxHopsObserved, 1);
  assert.equal(store.ring.primary('k'), 'new');
});

test('dual-write window: newer source beats stale target and drain copies it forward', () => {
  const ring = new ConsistentHashRing({ replicas: 1, hash: twoNodeMigrationHash });
  ring.addNode('old');
  const store = new MigratingStore({ ring });

  assert.deepEqual(store.put('k', 'v1', { writeId: 'before-join' }), {
    ok: true,
    writeId: 'before-join',
    version: 1,
    pending: [],
  });
  store.join('new');
  assert.equal(store.isWindowOpen(), true);
  assert.equal(store.get('k').value, 'v1');

  const partial = store.put('k', 'v2', {
    writeId: 'during-window',
    failOwners: new Set(['new']),
  });
  assert.equal(partial.ok, false);
  assert.deepEqual(partial.pending, ['new']);
  assert.equal(store.get('k').value, 'v2', 'read must select max(version,writeId), not stale target');

  const drained = store.drain();
  assert.ok(drained.copied >= 1);
  assert.equal(store.data.get('new').get('k').value, 'v2');

  assert.throws(() => store.finishWindow(), /still in flight/);
  const retry = store.flushPending(new Set());
  assert.equal(retry.pending, 0);

  // At-least-once: the in-flight write reached both old and new at least once.
  assert.ok(store.deliveryCount('during-window', 'old') >= 1);
  assert.ok(store.deliveryCount('during-window', 'new') >= 1);

  store.finishWindow();
  assert.equal(store.isWindowOpen(), false);
  assert.equal(store.get('k').value, 'v2');
  assert.equal(store.data.has('old'), false, 'old stale copy should be removed after drain');

  const duplicate = store.put('k', 'v2', { writeId: 'during-window' });
  assert.equal(duplicate.duplicate, true);
  assert.equal(duplicate.version, 2, 'duplicate delivery must not create a new version');
});

test('a second join during the window drains all previous holders to the final target', () => {
  const ring = new ConsistentHashRing({ replicas: 1, hash: threeNodeMigrationHash });
  ring.addNode('old');
  const store = new MigratingStore({ ring });
  store.put('k', 'v1', { writeId: 'multi-join' });

  assert.equal(store.join('mid').moved, 1);
  assert.equal(store.join('new').moved, 1);
  assert.equal(store.ring.primary('k'), 'new');

  store.drain();
  store.finishWindow();
  assert.equal(store.get('k').value, 'v1');
  assert.equal(store.data.has('old'), false);
  assert.equal(store.data.has('mid'), false);
  assert.deepEqual([...store.holders.get('k')], ['new']);
});
