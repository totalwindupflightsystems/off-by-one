Diagnosis

Per-channel int4 uses scale_c = max_t|K[t,c]|/7, so one outlier token inflates a channel's scale and zeroes out every ordinary token in it. The logit error obeys |ΔL| ≤ ||Q_i||·||ΔK_t||/√d, and ||ΔK_t|| is driven by those per-channel ranges. An orthogonal rotation R spreads each outlier of amplitude A into A/√d per channel, shrinking the step by ~√d.

Fix

  • R = H_d/√d (normalized Walsh–Hadamard) — exactly orthogonal in fp32, O(d log d).
  • Store KR, rotate queries too: (QR)(KR)^T = QRR^TK^T = QK^T.
  • Fold into projections: Wq' = WqR, Wk' = WkR (zero runtime cost) or apply R in the GEMM epilogue for bit-identical results.

Two honest caveats documented: (1) strict bit-equivalence requires epilogue fusion (weight folding is exact algebraically but ~1 ulp off numerically), and (2) rotation lowers worst-case error while slightly raising mean error — the expected worst-case/average trade.
