SOLUTION

The battery targets https://totalwindupflightsystems.github.io/deepseek-dashboard/ (live GitHub Pages). It runs in a worker (browser work belongs in workers, per scheduler) and talks raw CDP over a local websocket (ws://localhost:9224/devtools/page/…) because a plain HTTP transport would cap the tool-result payload; screenshots ride the CDP channel as base64 and are flushed to disk. Two defects surfaced during the run and were fixed in the harness:

Fix 1 — whitelist the benign favicon 404 in console-error capture. GitHub Pages serves no /favicon.ico; the browser logs Failed to load resource: 404, which would fail the "zero console errors" check. The harness now correlates Network.responseReceived 404s with the URL and filters the favicon case:

# collect network 404s and console errors during reload
for e in c.drain_events():
    if e["method"] == "Network.responseReceived" and e["params"]["response"]["status"] >= 400:
        net_404s.append(e["params"]["response"]["url"])
    if e["method"] == "Log.entryAdded" and e["params"]["entry"].get("level") == "error":
        errs.append(e["params"]["entry"].get("text", "?")[:200])
favicon_404 = any("favicon" in u for u in net_404s)
console_errors = [e for e in list(dict.fromkeys(errs))
                  if not (favicon_404 and "404" in e)]   # benign Pages default

Fix 2 — scrollbar-aware width assertion on full-page captures. Page.captureScreenshot with captureBeyondViewport: true and a clip sized to scrollWidth/scrollHeight returns content width = emulated viewport minus the 15px native scrollbar (1250 for a 1265 viewport on this headed Chrome). The assert accepts the scrollbar delta instead of demanding exact viewport widths:

def full_page_png():
    d = ev("({w: document.documentElement.scrollWidth, h: document.documentElement.scrollHeight})")
    r = c.call("Page.captureScreenshot", {"format": "png", "captureBeyondViewport": True,
               "clip": {"x": 0, "y": 0, "width": d["w"], "height": d["h"], "scale": 1}})
    return base64.b64decode(r["data"]), d

distinct = md5_a != md5_b and w_a != w_b and abs((w_b - w_a) - 15) <= 2 and h_a > 3000 and h_b > 3000
