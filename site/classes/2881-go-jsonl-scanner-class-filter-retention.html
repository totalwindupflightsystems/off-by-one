Go JSONL class-filter retention: streaming scanner + ordered parallel merge

Problem class: stream a large JSONL retention window, keep only lines whose top-level class matches a wanted marker, and report a bad-line count that is identical to a full scan — using bufio.Scanner (never os.ReadFile + strings.Split) and parallel per-file reads merged back in file order.

This document diagnoses the four failure modes found while building that pipeline and gives a verified, runnable fix. All numbers in the verification section were produced by the code in this repository on a 16-core Ryzen 7 7840HS.

1. Root-cause analysis

Pitfall 1 — the fixture was "escaped JSON", not JSONL

encoding/json.Marshal returns bytes. If a fixture writer marshals an already-serialized line a second time, every record becomes a JSON string:

"{\"ts\":1700000000,\"class\":\"io\",...}"   <- broken: a quoted, escaped string
{"ts":1700000000,"class":"io",...}           <- correct: a JSON object

The filter then decodes a string, not an object, so every line is silently invalid and nothing is retained. This is the worst kind of bug: exit status 0, zero output.

Fix: write the marshalled bytes directly. Never re-marshal a serialized line.

Pitfall 2 — hand-rolled class extraction stops at " but not \

A daily file can itself be an escaped JSON string ("{\"class\":\"io\"}"). A naive extractor that scans from "class":" until the next " walks straight through the \" and reports a bogus class. The scan must stop at both " and \.

Fix (best): do not hand-parse at all. json.Unmarshal into a map handles escaping correctly by construction. If a hand-rolled extractor is kept as a performance shortcut, it must stop at both bytes (see classFromLine in the tests) and must never be used to accept a line.

Pitfall 3 — LastIndex does not fix a foreign class key

A payload can contain its own class key. bytes.LastIndex(line, []byte("class")) then finds the payload's key, not the record's:

{"class":"net","meta":{"class":"io"}}

LastIndex says io, but the real class is net. There is no manual positional parse that is safe in general. The safe design is:

  1. whole-line containment of the wanted fragment ("class":"io") as a cheap prefilter, and
  2. an authoritative json.Unmarshal into a map that reads the top-level class, and
  3. a ground-truth census that measures how often a foreign marker exists, so you know whether the prefilter can be trusted to skip work.

On the real 208k-line window the census found 0 lines with a foreign class marker; the synthetic fixture below deliberately injects 199 such lines to prove the confirming decode rejects them.

Pitfall 4 — "parallel" must be ordered and bounded

Reading files concurrently is only correct if output is merged in file order, and only fast if workers do not collectively hold the whole dataset. Merge results by file index and emit each file only once all earlier files have been emitted; buffer only out-of-order completions.

2.2 Streaming scanner with containment prefilter and exact confirmation

func scanReader(f *os.File, class string, emit func([]byte) error) (Stats, error) {
    st := Stats{Files: 1}
    sc := bufio.NewScanner(f)
    // Default 64 KiB max token is too small for fat log lines; allow 8 MiB.
    sc.Buffer(make([]byte, 64*1024), 8*1024*1024)

    needle := ClassNeedle(class) // []byte(`"class":"` + class + `"`)
    for sc.Scan() {
        raw := sc.Bytes()
        line := make([]byte, len(raw)) // Scanner reuses its buffer
        copy(line, raw)
        st.Total++

        trimmed := bytes.TrimSpace(line)
        if len(trimmed) == 0 {
            st.Bad++
            continue
        }

        // Fast path: marker absent => cannot be retained. Still validate into
        // a map so the bad-line count matches a full scan line for line.
        if !bytes.Contains(trimmed, needle) {
            var probe map[string]json.RawMessage
            if err := json.Unmarshal(trimmed, &probe); err != nil {
                st.Bad++
            }
            continue
        }

        // Candidate: decode and confirm the TOP-LEVEL class. Containment alone
        // is not evidence because a payload may carry a foreign class marker.
        var obj map[string]json.RawMessage
        if err := json.Unmarshal(trimmed, &obj); err != nil {
            st.Bad++
            continue
        }
        rawClass, ok := obj["class"]
        if !ok {
            continue
        }
        var cls string
        if err := json.Unmarshal(rawClass, &cls); err != nil {
            continue
        }
        if cls != class {
            continue
        }
        st.Kept++
        if emit != nil {
            if err := emit(trimmed); err != nil {
                return st, err
            }
        }
    }
    if err := sc.Err(); err != nil {
        return st, err
    }
    return st, nil
}

func ClassNeedle(class string) []byte { return []byte(`"class":"` + class + `"`) }

Assumption: the upstream writer emits compact JSON (the default of json.Marshal), so "class":"io" appears verbatim. If pretty-printed input is possible, either normalize the marker or drop the containment prefilter and always decode; retention is still correct either way because the final class is always read by json.Unmarshal.

2.3 Ordered, bounded parallel merge

func ScanFilesParallel(paths []string, class string, emit func([]byte) error, workers int) (Stats, error) {
    sorted := append([]string(nil), paths...)
    sort.Strings(sorted)
    if workers < 1 { workers = 1 }
    if workers > len(sorted) { workers = len(sorted) }

    type job struct { idx int; path string }
    type result struct { idx int; stats Stats; buf bytes.Buffer; err error }

    jobs := make(chan job)
    results := make(chan result)
    var wg sync.WaitGroup

    for w := 0; w < workers; w++ {
        wg.Add(1)
        go func() {
            defer wg.Done()
            for j := range jobs {
                var buf bytes.Buffer
                st, err := ScanFile(j.path, class, func(line []byte) error {
                    buf.Write(line); buf.WriteByte('\n'); return nil
                })
                results <- result{idx: j.idx, stats: st, buf: buf, err: err}
            }
        }()
    }

    go func() {
        for i, p := range sorted { jobs <- job{idx: i, path: p} }
        close(jobs)
        wg.Wait()
        close(results)
    }()

    // Emit in file order; hold only out-of-order completions.
    pending := make(map[int]result)
    var total Stats
    for next := 0; next < len(sorted); {
        if r, ok := pending[next]; ok {
            delete(pending, next)
            total = total.Add(r.stats)
            if err := emit(r.buf.Bytes()); err != nil { return total, err }
            next++
            continue
        }
        r, open := <-results
        if !open { break }
        if r.err != nil { return total, fmt.Errorf("%s: %w", sorted[r.idx], r.err) }
        if r.idx != next { pending[r.idx] = r; continue }
        total = total.Add(r.stats)
        if err := emit(r.buf.Bytes()); err != nil { return total, err }
        next++
    }
    return total, nil
}

4. One-paragraph summary of the fix

Write fixtures as plain JSON by emitting the marshalled bytes directly. Stream with bufio.Scanner and a generous Buffer. Use whole-line containment of the compact "class":"<wanted>" fragment as a cheap prefilter, but never trust it: confirm the top-level class with json.Unmarshal into a map so a foreign class key inside a payload cannot leak through, and never use LastIndex. Validate turned-away lines too, so bad is identical to a full scan. Read files in parallel but merge by file index, buffering only out-of-order completions; the output is byte-identical to a sequential scan, several times faster, and peak RSS stays below the whole-dataset baseline. Prove it with a ground-truth census, a hash comparison, and a table of wall time and RSS.
