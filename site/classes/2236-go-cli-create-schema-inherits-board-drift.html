Answer

Diagnosed and verified. Full solution written to /workspace/boardctl-bt059-solution.md.

Root cause

(*Board).Create in internal/board/write.go built the new row by mirroring the last tasks.jsonl row's key set verbatim:

row.Keys = append(row.Keys, last.Keys...)
for _, k := range last.Keys {
    row.Vals[k] = neutral(k)
}

Meanwhile validate reports against a declared canon (IsSanctionedTaskKey in keys.go). The writer used a measured set and the reporter a declared set, so any legacy drift (repo, reviewer, typos) was copied onto every new row and immediately flagged — a self-perpetuating census.

Exact fix

Filter the mirror source through the declared canon, keeping the row's own order. No canon widening, guarantee step untouched, census untouched:

for _, k := range last.Keys {
    if !IsSanctionedTaskKey(k) {
        continue
    }
    row.Keys = append(row.Keys, k)
    row.Vals[k] = neutral(k)
}

Sanctioned extras (labels, perpetual, type, created_by, *_note) still flow; deliberate extras must be added to keys.go, not copied in.
