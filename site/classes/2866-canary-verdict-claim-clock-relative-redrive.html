Fix: make canary verdict claims clock-relative to the tick, not the reader

Problem class: canary-verdict-claim-clock-relative-redrive

Symptom

A commit message quotes a board verdict line such as last_tick_staleness=FAIL. Days later, reconstructing the same board header and re-driving it with the current clock still prints FAIL, so the claim looks true. But measured at the tick's own instant the identical header yields WARN. The verdict is therefore not re-derivable: it silently depends on when the reader runs.

Root cause

Two separate defects compound:

  1. The verdict is a function of the reader clock. Staleness is computed as now - last_tick, and the ladder thresholds live in whichever call site happens to evaluate them. A probe and an auditor that each keep their own copy of the multipliers (or re-read now) can disagree, and a re-drive always disagrees because now has moved forward. The quoted line records age but not the instant that age was measured at, so nobody can recover the original arithmetic.

  2. The claim auditor ages against now. Given only last_tick and a commit message, the naive re-drive computes datetime.now() - last_tick, which is guaranteed to be larger than the age at commit time. A WARN at commit time can only grow into FAIL; the claim becomes unfalsifiable.

Concretely: with cooldown = 21600 s, the ladder thresholds are WARN = 1.5 × 21600 = 32400 s and FAIL = 3 × 21600 = 64800 s. At commit fbaf148 the board was 48211 s old → WARN (32400 ≤ 48211 < 64800). The commit claimed FAIL. Re-driven today the same header is 380981 s old → FAIL, masking the error.

The fix

Three changes, all required together.

1. One shared ladder — scripts/staleness.py

# scripts/staleness.py
"""Canary cadence ladder -- the single source of truth."""
from __future__ import annotations

WARN_MULT = 1.5
FAIL_MULT = 3.0

OK, WARN, FAIL = "OK", "WARN", "FAIL"


def staleness_verdict(age_s, cooldown_s):
    """age <  WARN_MULT*cooldown -> OK
       age <  FAIL_MULT*cooldown -> WARN
       else                      -> FAIL
    """
    if age_s is None or age_s < 0:
        return OK
    if age_s < WARN_MULT * cooldown_s:
        return OK
    if age_s < FAIL_MULT * cooldown_s:
        return WARN
    return FAIL


def warn_threshold_s(cooldown_s):
    return WARN_MULT * cooldown_s


def fail_threshold_s(cooldown_s):
    return FAIL_MULT * cooldown_s

2. Probe records the measurement instant

Emit last_tick_age_at=<ISO-8601 with explicit UTC offset> immediately after last_tick_age_s, so any quoted line is arithmetically re-derivable: age == at - last_tick.

# scripts/canary_probe.py  (relevant part)
def iso_utc(dt):
    return dt.astimezone(timezone.utc).isoformat(timespec="seconds")


def header_line(last_tick, measured_at, cooldown_s=21600):
    age_s = int((measured_at - last_tick).total_seconds())
    header = {
        "last_tick": iso_utc(last_tick),
        "last_tick_age_s": age_s,
        "last_tick_age_at": iso_utc(measured_at),   # <-- new, adjacent
        "cooldown_s": cooldown_s,
        "last_tick_staleness": staleness_verdict(age_s, cooldown_s),
    }
    return json.dumps(header, separators=(", ", ": "))

3. Claim auditor pins the clock — scripts/check_tick_claim.py

It reads the parent commit's board.jsonl header, ages last_tick against the commit timestamp (never now), verdicts via the shared ladder, and exits 1 on MISMATCH.

#!/usr/bin/env python3
"""Re-drive a commit-message canary severity claim against the commit instant."""
from __future__ import annotations

import argparse, json, re, subprocess, sys
from datetime import datetime, timezone

from canary_probe import DEFAULT_COOLDOWN_S, header_line, iso_utc, parse_iso
from staleness import fail_threshold_s, staleness_verdict, warn_threshold_s

CLAIM_RE = re.compile(r"last_tick_staleness\s*=\s*(OK|WARN|FAIL)")


def git(*args):
    return subprocess.run(["git", *args], capture_output=True,
                          text=True, check=True).stdout


def audit(commit, board_path, cooldown_override, now_override):
    parent = f"{commit}^"
    message = git("show", "-s", "--format=%B", commit)
    tick_time = parse_iso(git("show", "-s", "--format=%cI", commit).strip())

    # Board header as it existed at the PARENT commit (the state the tick saw).
    header = json.loads(git("show", f"{parent}:{board_path}").splitlines()[0])
    header_last_tick = parse_iso(header["last_tick"])
    cooldown_s = (cooldown_override if cooldown_override is not None
                  else int(header.get("cooldown_s", DEFAULT_COOLDOWN_S)))

    age_at_tick_s = int((tick_time - header_last_tick).total_seconds())
    verdict_at_tick = staleness_verdict(age_at_tick_s, cooldown_s)

    quote = next((ln.strip() for ln in message.splitlines()
                  if CLAIM_RE.search(ln)), "")
    m = CLAIM_RE.search(quote)
    claim_severity = m.group(1) if m else "NONE"

    probe_line = header_line(header_last_tick, tick_time, cooldown_s)
    claim_audit = "OK" if claim_severity == verdict_at_tick else "MISMATCH"

    now = parse_iso(now_override) if now_override else datetime.now(timezone.utc)
    live_age_s = int((now - header_last_tick).total_seconds())
    live_verdict = staleness_verdict(live_age_s, cooldown_s)

    return {
        "commit": commit, "claim_quote": quote, "claim_severity": claim_severity,
        "tick_time": iso_utc(tick_time), "header_last_tick": iso_utc(header_last_tick),
        "age_at_tick_s": age_at_tick_s, "cooldown_s": cooldown_s,
        "verdict_at_tick": verdict_at_tick, "probe_line": probe_line,
        "claim_audit": claim_audit, "warn_at_s": warn_threshold_s(cooldown_s),
        "fail_at_s": fail_threshold_s(cooldown_s), "now": iso_utc(now),
        "live_age_s": live_age_s, "live_verdict": live_verdict,
    }


def main(argv=None):
    ap = argparse.ArgumentParser()
    ap.add_argument("commit", nargs="?", default="HEAD")
    ap.add_argument("--board", default="board.jsonl")
    ap.add_argument("--cooldown", type=int, default=None)
    ap.add_argument("--now", default=None)
    args = ap.parse_args(argv)
    result = audit(args.commit, args.board, args.cooldown, args.now)
    for k, v in result.items():
        print(f"{k}={v}")
    return 1 if result["claim_audit"] == "MISMATCH" else 0


if __name__ == "__main__":
    sys.exit(main())

Why the two verdicts differ (the proof)

Instant age_s Ladder Verdict
tick's own instant (tick_time) 48211 32400 ≤ 48211 < 64800 WARN
reader clock "today" 380981 380981 ≥ 64800 FAIL

The header is identical; only the clock changed. A re-drive must pin the tick's own instant — recorded as last_tick_age_at — and verdict through the one shared ladder. That is what scripts/check_tick_claim.py does, and why it now fails the false FAIL claim while the honest WARN claim passes.
