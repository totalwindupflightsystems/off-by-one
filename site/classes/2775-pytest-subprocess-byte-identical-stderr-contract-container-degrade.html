Fix: explicit-backend-no-downgrade byte-identical stderr contract

Problem class: pytest-subprocess-byte-identical-stderr-contract-container-degrade Repo: terminal-jail · Fix commit: 455ab4a Environment: docker python:3.11-slim + host pytest

1. Symptom

The composed-mode live test asserts the explicit-backend-no-downgrade arm emits exactly the refusal bytes and rc=2:

terminal-jail: namespace creation failed (unshare exit 1); command not run — on unprivileged hosts try --user

Under pytest the child prepends a Landlock fs-tier degrade warning, breaking byte-identity:

terminal-jail: WARNING: no filesystem isolation — Landlock enforcement probe found no caller-writable
ungranted path (XDG_RUNTIME_DIR unset or not writable, HOME is a granted read root, /tmp granted);
fs tier degrades to loud warning
terminal-jail: namespace creation failed (unshare exit 1); command not run — on unprivileged hosts try --user

The bare battery passes; the failure is host-dependent, so CI sometimes went green. Two layers, both fixed at the test/spawn site — the production wrapper is correct.

2. Root-cause analysis

Layer 1 — inherited-environment leak (latent reproducibility bug)

Tests spawn with env=os.environ.copy(), so under pytest PYTEST_*, GIT_*, COVERAGE_*, BUILD_* leak into the child and its decisions depend on how the test was invoked. Fix is a hermetic env base at the spawn site — not relaxed assertions.

Layer 2 — host-dependent Landlock fs-tier probe (the actual red arm)

The Landlock tier (TJ-GAP-082) needs a caller-writable path outside the granted roots to prove enforcement.

Host situation Probe stderr
XDG_RUNTIME_DIR set + writable green refusal only
python:3.11-slim: XDG_RUNTIME_DIR unset, HOME granted read, /tmp granted no candidate loud WARNING + refusal

The wrapper is right to warn; that path has its own tests. The byte-identical refusal test must pin the tier env vars like the unit suite already does.

3. Exact fix

3.1 Hermetic env base (tests/conftest.py)

from __future__ import annotations
import os

_FORBIDDEN_PREFIXES: tuple[str, ...] = ("PYTEST_", "GIT_", "COVERAGE_", "BUILD_")

def hermetic_env(**overrides: str) -> dict[str, str]:
    """Build a child env from scratch — never os.environ.copy()."""
    env: dict[str, str] = {
        "PATH": os.environ.get("PATH", "/usr/local/bin:/usr/bin:/bin"),
        "LANG": "C.UTF-8", "LC_ALL": "C.UTF-8",
        "HOME": os.environ.get("HOME", "/nonexistent"),
        "TMPDIR": os.environ.get("TMPDIR", "/tmp"),
    }
    for key, value in overrides.items():
        if key.startswith(_FORBIDDEN_PREFIXES):
            raise ValueError(f"refusing to inject forbidden namespace {key!r}")
        env[key] = value
    return env

Route every spawn helper through this.

3.2 Pin the tier in the byte-identical arm

def test_explicit_backend_no_downgrade_is_byte_identical() -> None:
    env = hermetic_env(
        TERMINAL_JAIL_JAIL_BACKEND="unshare",   # explicit: never downgrade
        TERMINAL_JAIL_COMPOSED="off",           # plain-host fail-closed
        TERMINAL_JAIL_LANDLOCK="off",           # pin fs tier — probe not this test's subject
        TERMINAL_JAIL_FS_ISOLATION="degraded",
        TERMINAL_JAIL_UID_MAP="0",
    )
    proc = subprocess.run([TERMINAL_JAIL, "--no-interruptor", "true"],
                          env=env, stdout=subprocess.PIPE, stderr=subprocess.PIPE)
    assert proc.returncode == 2
    assert proc.stderr == (
        b"terminal-jail: namespace creation failed (unshare exit 1); "
        b"command not run \xe2\x80\x94 on unprivileged hosts try --user\n"
    )

TERMINAL_JAIL_LANDLOCK=off is the wrapper's documented gate and makes the test independent of XDG_RUNTIME_DIR/HOME//tmp. If you instead want the tier-on path, pin XDG_RUNTIME_DIR to a writable dir not under HOME or /tmp (e.g. tmp_path/"xdg").

3.3 Keep loud-degrade covered

def test_landlock_no_probe_host_degrades_loudly() -> None:
    env = hermetic_env(TERMINAL_JAIL_JAIL_BACKEND="unshare",
                       TERMINAL_JAIL_LANDLOCK="on", HOME="/nonexistent")
    env.pop("XDG_RUNTIME_DIR", None)  # slim-container shape
    proc = subprocess.run(..., env=env, stderr=subprocess.PIPE)
    assert proc.returncode == 2
    assert b"WARNING: no filesystem isolation" in proc.stderr

3.4 Never relax the assertion

assert refusal in stderr would hide any future stray warning and untest the security contract.
