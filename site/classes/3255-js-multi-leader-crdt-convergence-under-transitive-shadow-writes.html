Convergence failure in multi-leader CRDT log compaction under transitive "shadow" writes

Deliverable: ~/crdt-compaction/crdt.js — reproduces the divergence and verifies the retention rule in one command:

cd ~/crdt-compaction && node crdt.js

1. Root-cause analysis

An op-based CRDT replicates ops carrying a causal context (deps, a version vector), with a delivery rule "apply only when every dependency is present," and an anti-entropy log used to fill partition gaps.

Causally complete is a local, per-op property: the chunk (plus applied state) contains the dependency closure needed to apply it locally. It says nothing about what other replicas have seen.

With r1,r3 connected and r2 partitioned:

r1.generate('a')        // a=r1:1, deps {}
sync(r1 -> r3)
r3.generate('b')        // b=r3:1, deps {r1:1}   <-- transitively needs a
sync(r3 -> r1)
r1.generate('c')        // c=r1:2, deps {r1:1, r3:1}
sync(r1 -> r3)

r1/r3 compact a (applied + locally complete), keeping b,c. After heal, r2 receives b,c but a is gone from every log, so causal delivery buffers them forever. r1/r3 = {a,b,c}, r2 = {} — permanent divergence.

That is the transitive shadow write: a is no longer directly needed by its creators, only reachable through the dependency set of b, which is still being gossiped.

Cause: compaction was gated on causal completeness (local closure) instead of causal stability (acknowledged by every live replica).

2. Exact fix: causal-stability GC

Let Ack[i] be replica i's version vector of durably applied ops. Define the stable frontier S = componentwise-min over all live replicas of Ack[i]. Remove op o from the log iff o.deps ≤ S and S[o.origin] ≥ o.ctr.

// A missing/unknown ack is 0: a lagging replica must pin the frontier, never advance it.
function vvMin(ids, acks) {
  const out = {};
  for (const r of ids) out[r] = Math.min(...ids.map((id) => get(acks[id] || {}, r)));
  return out;
}

stable() { return vvMin(this.membership, this.acks); }

compactStable() {
  const s = this.stable();
  for (const [id, op] of [...this.log]) {
    const included = dominates(s, op.deps) && get(s, op.rid) >= op.ctr;
    if (included) { this.log.delete(id); this.compacted++; }
  }
}

Acks ride along on every anti-entropy exchange so they propagate while connected replicas keep compacting:

receiveBatch(fromId, ops, fromVV, fromAcks) {
  this.acks[fromId] = vvMax(this.acks[fromId] || {}, fromVV);
  for (const rid in fromAcks) this.acks[rid] = vvMax(this.acks[rid] || {}, fromAcks[rid]);
  // ... buffer + causal delivery unchanged ...
}

Metadata is bounded: one version vector per replica — no per-op tombstones. A replica behind S (or new) is caught up via snapshot transfer of the compacted prefix + retained suffix; a replica that acked S has no outstanding dependency on removed deltas. Membership churn must be handled with explicit stable-membership epochs.

final logs   : [ 2, 2, 2 ] compacted ops: [ 1, 0, 1 ]

=== FIXED: causal-stability (ack-vector) compaction ===
before heal  : { r1: 'a,b,c', r2: '', r3: 'a,b,c', logs: [ 3, 0, 3 ] }
after  heal  : [ 'a,b,c', 'a,b,c', 'a,b,c' ] converged= true
after settle : [ 'a,b,c', 'a,b,c', 'a,b,c' ] converged= true
final logs   : [ 0, 0, 0 ] compacted ops: [ 3, 3, 3 ]

All assertions passed.

Assertions prove: the buggy policy genuinely diverges (r2 stuck empty), the stable policy converges after heal and survives a full post-heal GC pass, and stability GC actually reclaims all three deltas (final logs: [0,0,0]) once every replica acks. Before heal, S is pinned to 0 because r2's ack is unknown — retention is driven by the global minimum of knowledge, exactly the condition under which a removed dependency can no longer be requested.
