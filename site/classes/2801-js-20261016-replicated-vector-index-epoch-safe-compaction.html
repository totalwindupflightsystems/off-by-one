Root-cause analysis

The failure class comes from five coupled mistakes:

# Root cause Effect
RC1 Conflict resolution keyed on wall-clock time / arrival order Non-deterministic repair; late old upsert overwrites a newer tombstone → resurrection
RC2 Tombstones GC'd before globally stable Offline replica replays a stale upsert after the delete is gone → resurrection
RC3 Epoch-blind compaction/query Vectors from different embedding models get merged/scored together → garbage distances
RC4 No stable watermark / eviction Either unbounded history, or premature tombstone deletion
RC5 Gap/duplicate-intolerant anti-entropy Reordering/loss double-applies or leaves permanent holes

The fix

  1. Deterministic total order on every update: (epoch, lamport_ts, origin, seq). Higher epoch always dominates (incl. over a larger Lamport ts), then LWW by ts, then replica id. maxUpdate is the merge — idempotent, commutative, associative (join-semilattice) → repair order-independent.
  2. Version vectors + gap buffer per origin → duplicates ignored, out-of-order updates buffered until contiguous.
  3. Stable floor GC: stableFloor[o] = min over non-evicted replicas of vv[o]. Only tombstones/history at or below it are dropped; live winners are always kept.
  4. Eviction + authoritative snapshot bootstrap: replicas lagging past retention are evicted, then syncFrom installs a snapshot with reset:true, so a GC'd delete can never be replayed.
  5. Epoch fencing: writes tagged with active epoch, receiving a higher epoch advances it, and query hard-filters by a single epoch.
  6. ANN layer: exact or seeded deterministic IVF (nlist/nprobe), applied only to live, epoch-matching records.

Core ordering and safe GC:

function compareUpdates(a, b) {
  if (a.epoch !== b.epoch) return a.epoch - b.epoch; // newer model wins
  if (a.ts !== b.ts) return a.ts - b.ts;
  if (a.origin !== b.origin) return a.origin < b.origin ? -1 : 1;
  return a.seq - b.seq;
}

compact(stable) {                       // only self-stable data is removed
  for (const [o, s] of stable) if (s > (this.floor.get(o)||0)) this.floor.set(o, s);
  for (const [k, u] of this.records)
    if (u.deleted && u.seq <= (this.floor.get(u.origin)||0)) this.records.delete(k);
  for (const o of [...this.log.keys()]) this._trimLogFor(o);
}

syncFrom(source) {
  if (this._isBehind(source.floor))
    return this.installSnapshot(source.snapshot(), { reset: true }); // authoritative
  return this.applyOps(source.getOpsSince(this.vv));                // idempotent
}
