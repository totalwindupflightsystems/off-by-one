/home/kara/gitreins-poc/append_board_event.py (mode 644, deliberately no exec bit — direct invocation is meant to fail with Permission denied; the only supported path is via the venv interpreter):

#!/usr/bin/env python3
"""append_board_event.py -- canonical JSONL board appender for gitreins-poc.

REPO is the ABSOLUTE path to the gitreins-poc checkout, e.g.
/home/kara/gitreins-poc.  NOTE: ops-ref's "run from /home/kara with relative
gitreins-poc arg" note is stale -- the canonical invocation always passes an
absolute REPO path and runs this script with the repo virtualenv interpreter:

    /home/kara/gitreins-poc/.venv/bin/python3 \
        /home/kara/gitreins-poc/append_board_event.py \
        /home/kara/gitreins-poc EVENT_ID DETAIL_JSON \
        --ts 'YYYY-MM-DD HH:MM:SS.000000' \
        --set ticks_total=N --set ticks_idle=M

The --ts timestamp is MANDATORY and must be UTC: the events stream is UTC, and
local-time events get re-appended downstream ... """

Key mechanics:

  • CLI: repo event_id detail_json --ts TS --set KEY=VALUE... (repeatable --set). --ts is required; ticks_total/ticks_idle must parse as ints.
  • UTC enforcement: strict regex ^\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}\.\d{6}$ — naive strings are accepted as UTC; anything with a tz offset (+02:00) or Z is rejected (exit 2). This is the guard against the "local-time events get re-appended" failure mode.
  • Absolute REPO required: relative paths (the stale ops-ref style) are rejected with exit 2.
  • Append flow: loads board.jsonl (line 1 = header, rest = events), appends {"id", "ts", ...--set fields, "detail": <detail.json contents>}, updates header (event_count, last_event_id, ticks_total, ticks_idle, updated_at), writes atomically via os.replace.
  • Idempotency: exact (id, ts) already present → no-op (exit 0). Same id with a different (corrected UTC) ts re-appends — matching the re-append design note.
  • Duckdb cache (best-effort): CREATE TABLE IF NOT EXISTS events(id BIGINT, ts VARCHAR, ticks_total BIGINT, ticks_idle BIGINT, detail JSON, PRIMARY KEY (id, ts)) + a header(key, value) mirror; INSERT OR IGNORE. Any failure prints WARN: to stderr and returns "cache insert SKIPPED" — the JSONL append never blocks.

Supporting files: detail.json (tick-143 payload), README.md (canonical invocation), _seed.py (regenerates board history), and seeded board.jsonl (header + events 1–85, incl. verified id=85) + board.db cache.
