Fixing gitreins-verdict-fail-on-pre-existing-residual

A verification-only close for a correct fix that was blocked by an unrelated, pre-existing test failure.

TL;DR

A gitreins task complete run returned tier2 FAIL for a fix that was correct. The acceptance criterion was recorded as a whole-package command (cargo test -p <crate>), so one pre-existing failure in a file the fix never touched (tests/bare-symbol impact) was charged to the fix. The durable fix is to judge the acceptance-named target, not the whole package, and to keep residuals on their own board rows so they can never contaminate a close. The immediate fix is a verification-only close bound to a fresh PASS evidence run.

Result of applying this runbook: close with fresh PASS verdict 7d8e650a, residual tracked on its own row, environment flake quarantined.

1. Symptoms / incident shape

Signal Observation
Harness verdict tier2 FAIL from gitreins task complete
Worker confidence Fix is correct; all change-target tests pass
Verdict criterion cargo test -p <crate> — whole package, "0 failures"
Failure count exactly 1
Failing test bare-symbol impact, in a file the fix does not modify
Board the residual is (or becomes) its own row, fixed later
Flake (optional) FUSE mount wait_ready 30s timeout at a shared TMPDIR, GREEN under a clean TMPDIR

The verdict is a false negative: the criterion's scope is wider than the change under review.

2. Root-cause analysis

2.1 Proximate cause — over-broad acceptance scope

The task's acceptance criterion was cargo test -p <crate> (all targets in the package). A package-wide "0 failures" gate couples the fix to the entire pre-existing health of the crate. Any unrelated red test — known or not — flips the verdict to FAIL. The correct scope is the acceptance-named target that the change is actually accountable for, e.g.:

cargo test -p <crate> --test <target>

2.2 Contributing cause — residual not separated from the fix

The pre-existing defect and the fix were both present at HEAD. The verdict did not record/enforce a baseline subtraction (known failures at the merge-base) or an attribution to an existing board row. So a known residual was indistinguishable from a regression introduced by the fix.

2.3 Contributing cause — environment flake indistinguishable from residual

The FUSE wait_ready 30s timeout only reproduces on the shared ambient TMPDIR. Without a private TMPDIR the flake looks like a deterministic failure and gets folded into the same FAIL, misleading the close.

2.4 Why FAIL is wrong here

A criterion may only fail a fix for failures within the criterion's named target and causally reachable by the fix. A failure in an untouched file, already tracked on its own board row, is disjoint and belongs to that row — not to this close.

3. Diagnosis loop (do it in this order)

Read the artifacts, never the commit message. The commit message is authored by the worker; verdict.json and summary.md are authored by the judge.

  1. Read verdict.json + summary.md for the failing run.
  2. Diff the failing test file against the fix commit. If it is untouched by the fix, the failure is pre-existing / disjoint.
  3. Check the board for an existing row for that residual (title/acceptance match). If none, file one; do not close the fix on an unfiled residual.
  4. Re-run acceptance at current HEAD, scoped to the acceptance-named target (cargo test -p <crate> --test <target>) — not the whole package.
  5. Classify environment flakes (FUSE wait_ready timeout at a shared TMPDIR) and re-run under a private TMPDIR; never let a flake contaminate the close.

Evidence run layout (this is what boardctl's completion gate resolves):

<repo>/.gitreins/history/<YYYY-MM-DD>/<run-id>/
├── verdict.json      # machine verdict: verdict/status, tier, commit, base_commit, criteria[]
└── summary.md        # human narrative of the criteria

4. Exact fix

4.1 Immediate: verification-only close (fresh PASS run)

After the residual is fixed (or attributed) and the scoped target proves green at HEAD, re-issue a fresh PASS run and bind the board row to it. boardctl's completion gate (TR-251) requires --evidence-run-id:

REPO=.                       # repo root (contains .coding-hermes/ and .gitreins/)
FIX_ROW=TASK-FIX
NEW_PASS_RUN=7d8e650a        # the fresh verdict run under .gitreins/history/<date>/7d8e650a/

# 1) bank the scoped re-judge evidence (this is what gitreins writes for you)
ls "$REPO/.gitreins/history"/*/"$NEW_PASS_RUN"/verdict.json

# 2) close the fix row against the fresh PASS run
boardctl -C "$REPO" update "$FIX_ROW" \
  --status complete \
  --evidence-run-id "$NEW_PASS_RUN" \
  --guard PASS --ci GREEN \
  --commit-hash "$(git -C "$REPO" rev-parse HEAD)" \
  --summary "re-judge scoped to acceptance target; residual bare-symbol is pre-existing and tracked on TASK-RESIDUAL"

boardctl resolves the run id against .gitreins/history/<date>/<run-id>/verdict.json; a completion without an evidence run id is refused:

boardctl: evidence run required: completion REFUSED for "TASK-FIX":
--evidence-run-id is REQUIRED when setting status "complete" (TR-251)

4.2 Re-judge with the correct scope

Replace the package-wide gate in the criterion with the acceptance-named target, and always give FUSE tests a private TMPDIR so mount waits are not starved by a shared one:

# scope to the acceptance-named target (not `cargo test -p <crate>`)
TMPDIR="$(mktemp -d /tmp/gitreins.XXXXXX)" cargo test -p <crate> --test <target>

Carry the scope into the record so future re-judges cannot silently widen it:

// .gitreins/history/<date>/<run-id>/verdict.json
{
  "run_id": "7d8e650a",
  "tier": "tier2",
  "verdict": "PASS",
  "commit": "<HEAD>",
  "base_commit": "<merge-base>",
  "files_changed": ["src/lib.rs"],
  "pass_criteria": "cargo test -p <crate> --test <target>",
  "criteria": [
    { "name": "acceptance", "command": "cargo test -p <crate> --test <target>", "status": "PASS" }
  ]
}

4.3 Put the residual on its own row (once, deferred)

The residual must have an owner row so it is never charged to another close. --deferred marks it as accepted-not-now:

boardctl -C "$REPO" create \
  --id TASK-RESIDUAL \
  --title "bare-symbol impact test fails" \
  --priority P2 --deferred

Re-detection is refused by normalised title/reasoning; evidence the existing row instead of refiling, or pass --force to file a variant.

4.4 Quarantine environment flakes

Treat FUSE/mount/timeout names as flake-suspect and re-run in isolation before concluding anything:

# ambient shared TMPDIR -> red; private TMPDIR -> green
TMPDIR="$(mktemp -d /tmp/gitreins.XXXXXX)" cargo test -p <crate> --test fuse_mount

Record the classification in the row note, but do not gate the fix on it.

4.5 Triage helper (tested)

verdict_triage.py reads the failing evidence run, cross-references the fix diff and the board, and prints the classification plus the exact close-out.

#!/usr/bin/env python3
"""verdict_triage.py - classify a gitreins tier2 FAIL and print the close-out.

Reads an evidence run (verdict.json / summary.md) and decides whether a failing
acceptance criterion is a *pre-existing residual* (disjoint from the fix, with
its own board row), a *regression* (touched by the fix), or an *environment
flake* (e.g. FUSE wait_ready timeout under a shared TMPDIR).

Exit codes:
  0  PRE-EXISTING RESIDUAL confirmed (disjoint + own board row present)
  1  REGRESSION (a failing artifact was modified by the fix commit)
  3  ENV-FLAKE suspected (FUSE/mount/timeout signature)
  2  UNKNOWN / inputs missing

Usage:
  verdict_triage.py --repo . --run-id 1a2b3c4d [--target 'cargo test -p demo --test feature_target']
  verdict_triage.py --repo . --run-dir .gitreins/history/2026-10-22/1a2b3c4d
"""
from __future__ import annotations

import argparse
import glob
import json
import os
import re
import subprocess
import sys
from typing import Any, Iterator

FAIL_WORDS = ("fail", "failed", "error", "red", "broken")
PATH_RE = re.compile(
    r"(?<![\w/\\])((?:[\w.@+-]+/)*[\w.@+-]+\.(?:rs|py|go|ts|tsx|js|jsx|java|kt|rb|c|cc|cpp|h|hpp|swift|m|cs))(?![\w])"
)
TEST_RE = re.compile(r"\btest\s+([A-Za-z0-9_:.:/\-]+)", re.I)
RUST_TEST_RE = re.compile(r"\b([a-z][a-z0-9_]*::[a-z][a-z0-9_]*)\b")
FLAKE_RE = re.compile(
    r"(fuse|wait_ready|mount|timed?\s*out|timeout|device\s+busy|resource\s+temporarily\s+unavailable|stale\s+file\s+handle)",
    re.I,
)


def run(cmd: list[str], cwd: str | None = None) -> tuple[int, str]:
    try:
        p = subprocess.run(cmd, cwd=cwd, capture_output=True, text=True, timeout=120)
        return p.returncode, (p.stdout or "") + (p.stderr or "")
    except FileNotFoundError:
        return 127, f"not found: {cmd[0]}"
    except subprocess.TimeoutExpired as e:
        return 124, f"timeout: {e}"


def iter_dicts(obj: Any) -> Iterator[dict]:
    if isinstance(obj, dict):
        yield obj
        for v in obj.values():
            yield from iter_dicts(v)
    elif isinstance(obj, list):
        for v in obj:
            yield from iter_dicts(v)


def status_of(d: dict) -> str | None:
    for k in ("status", "verdict", "result", "outcome", "state", "guard", "ci"):
        v = d.get(k)
        if isinstance(v, str) and v.strip():
            return v.strip()
    return None


def is_failing(d: dict) -> bool:
    st = (status_of(d) or "").lower()
    if any(w in st for w in FAIL_WORDS):
        return True
    for k in ("failures", "failed", "failed_tests", "errors"):
        if d.get(k):
            return True
    return False


def looks_like_criterion(d: dict) -> bool:
    return any(k in d for k in ("command", "cmd", "pass_criteria", "acceptance", "acceptance_criteria", "failures", "failed", "failed_tests"))


def collect_criteria(v: dict) -> list[dict]:
    for key in ("criteria", "criterion", "checks", "gates"):
        crit = v.get(key)
        if isinstance(crit, list):
            return [d for d in crit if isinstance(d, dict)]
    return [d for d in iter_dicts(v) if looks_like_criterion(d)]


def command_of(d: dict) -> str | None:
    for k in ("command", "cmd", "pass_criteria", "acceptance", "acceptance_criteria", "test_command"):
        v = d.get(k)
        if isinstance(v, str) and v.strip():
            return v.strip()
    return None


def find_run_dir(repo: str, run_id: str | None, run_dir: str | None, history: str | None) -> str | None:
    if run_dir:
        return run_dir
    hist = history or os.path.join(repo, ".gitreins", "history")
    if run_id:
        hits = [p for p in glob.glob(os.path.join(hist, "*", run_id)) if os.path.isdir(p)]
        if hits:
            return sorted(hits)[-1]
    return None


def load_verdict(run_dir: str) -> dict:
    for name in ("verdict.json", "verdict.yaml", "verdict.yml"):
        p = os.path.join(run_dir, name)
        if os.path.isfile(p):
            with open(p) as f:
                return json.load(f)
    return {}


def read_summary(run_dir: str) -> str:
    p = os.path.join(run_dir, "summary.md")
    if os.path.isfile(p):
        with open(p) as f:
            return f.read()
    return ""


def extract_candidates(blob: str) -> tuple[set[str], set[str]]:
    files = {m.group(1) for m in PATH_RE.finditer(blob)}
    tests = set()
    for m in TEST_RE.finditer(blob):
        t = m.group(1).strip("'\".,:;")
        if not t.startswith("-") and len(t) > 1:
            tests.add(t)
    for m in RUST_TEST_RE.finditer(blob):
        tests.add(m.group(1))
    return files, tests


def residual_symbols(files: set[str], tests: set[str]) -> set[str]:
    toks: set[str] = set()
    for t in tests:
        toks.add(t.split("::")[-1])
        toks.add(os.path.basename(t))
    for f in files:
        toks.add(os.path.basename(f).rsplit(".", 1)[0])
    extra: set[str] = set()
    for t in list(toks):
        parts = re.split(r"[_\-]", t)
        for n in range(len(parts), 1, -1):
            for i in range(0, len(parts) - n + 1):
                extra.add("_".join(parts[i:i + n]))
    return {t for t in toks | extra if len(t) >= 4}


def changed_files(repo: str, base: str | None, head: str) -> set[str]:
    if not base:
        rc, mb = run(["git", "-C", repo, "merge-base", "HEAD", "origin/HEAD"])
        if rc != 0:
            rc, mb = run(["git", "-C", repo, "merge-base", "HEAD", "main"])
        if rc != 0:
            rc, mb = run(["git", "-C", repo, "rev-list", "--max-parents=0", head])
        base = mb.strip().splitlines()[-1] if rc == 0 and mb.strip() else ""
    if not base:
        return set()
    rc, out = run(["git", "-C", repo, "diff", "--name-only", f"{base}..{head}"])
    return {l.strip() for l in out.splitlines() if l.strip()} if rc == 0 else set()


def board_rows(repo: str) -> list[dict]:
    rc, out = run(["boardctl", "-C", repo, "list", "--json", "--all"])
    if rc != 0:
        return []
    try:
        data = json.loads(out)
        return data if isinstance(data, list) else data.get("tasks", [])
    except json.JSONDecodeError:
        return []


def row_text(row: dict) -> str:
    parts = [str(row.get(k, "")) for k in ("id", "title", "worker_summary", "reasoning")]
    det = row.get("detail") or {}
    if isinstance(det, dict):
        parts += [json.dumps(det)]
    return " ".join(parts)


def main() -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--repo", default=".")
    ap.add_argument("--run-id")
    ap.add_argument("--run-dir")
    ap.add_argument("--history")
    ap.add_argument("--base")
    ap.add_argument("--head", default="HEAD")
    ap.add_argument("--target", help="acceptance-named target, e.g. 'cargo test -p demo --test feature_target'")
    a = ap.parse_args()

    repo = os.path.abspath(a.repo)
    run_dir = find_run_dir(repo, a.run_id, a.run_dir, a.history)
    if not run_dir:
        print(f"UNKNOWN: no evidence run found for run-id={a.run_id!r} under {a.history or repo + '/.gitreins/history'}", file=sys.stderr)
        return 2

    v = load_verdict(run_dir)
    summary = read_summary(run_dir)
    print(f"run dir : {run_dir}")
    print(f"verdict : {v.get('verdict') or v.get('status')}  tier={v.get('tier')}  commit={v.get('commit')}")

    base = a.base or v.get("base_commit")
    head = v.get("commit") or a.head

    fail_blobs: list[str] = []
    commands: list[str] = []
    for d in collect_criteria(v):
        if is_failing(d):
            fail_blobs.append(json.dumps(d))
            c = command_of(d)
            if c:
                commands.append(c)
    fail_blobs.append(summary)

    blob = "\n".join(fail_blobs)
    files, tests = extract_candidates(blob)
    files = {f for f in files if not f.startswith(("http://", "https://"))}

    changed = changed_files(repo, base, head)
    touched = sorted(f for f in files if f in changed or any(f.endswith(c) or c.endswith(f) for c in changed))
    untouched = sorted(files - set(touched))

    rows = board_rows(repo)
    syms = residual_symbols(files, tests)
    residual_rows = [r for r in rows if any(s in row_text(r).replace("-", "_") for s in syms)]

    print("\nfailing commands:")
    for c in dict.fromkeys(commands):
        print(f"  - {c}")
    print(f"\nsuspect files : {sorted(files) or '(none parsed; inspect the criterion output above)'}")
    print(f"tests/names   : {sorted(tests) or '(none parsed)'}")
    print(f"fix touches   : {sorted(changed) or '(none)'}")
    print(f"touched by fix: {touched or '(none)'}")
    print(f"untouched     : {untouched or '(none)'}")

    print("\nboard rows referencing the residual:")
    for r in residual_rows or []:
        print(f"  - {r.get('id')}  status={r.get('status')}  deferred={r.get('deferred')}  {r.get('title')}")
    if not residual_rows:
        print("  (none found)")

    flaky = bool(FLAKE_RE.search(blob))
    print("\nclassification:")
    if touched:
        print("  REGRESSION: a failing artifact was modified by the fix commit -> fix the code, do NOT close.")
        verdict = "regression"
    elif flaky:
        print("  ENV-FLAKE: FUSE/mount/timeout signature present -> re-run with a private TMPDIR before any close.")
        verdict = "env-flake"
    elif files and residual_rows:
        print("  PRE-EXISTING RESIDUAL: failing file(s) untouched by the fix AND tracked on their own board row.")
        verdict = "residual"
    elif files and untouched:
        print("  PRE-EXISTING (unfiled): failing file(s) untouched but no board row -> file a residual row first.")
        verdict = "residual-unfiled"
    else:
        print("  UNKNOWN: could not parse failing artifacts; inspect verdict.json + summary.md manually.")
        verdict = "unknown"

    target = a.target or next((c for c in commands if "--test" in c or " -t " in c), None)
    if not target:
        target = "cargo test -p <crate> --test <target>   # acceptance-named target"
    print("\nre-judge at HEAD (scoped, private TMPDIR):")
    print(f"  TMPDIR=\"$(mktemp -d /tmp/gitreins.XXXXXX)\" {target}")
    print("\nclose-out (verification-only, fresh PASS run id):")
    print(f"  git -C {repo} rev-parse HEAD")
    print(f"  boardctl -C {repo} update TASK-FIX --status complete \\")
    print(f"      --evidence-run-id <NEW-PASS-RUN-ID> --guard PASS --ci GREEN \\")
    print(f"      --summary 're-judge scoped to acceptance target; residual <name> is pre-existing and tracked on <RESIDUAL-ID>'")

    return {"regression": 1, "env-flake": 3, "residual": 0, "residual-unfiled": 2, "unknown": 2}[verdict]


if __name__ == "__main__":
    sys.exit(main())

6. Prevention / hardening

  1. Scope every acceptance criterion to a named target. Store pass_criteria: cargo test -p <crate> --test <target> (or the language equivalent) in the criterion and in the board row. Never judge a fix on cargo test -p <crate>.
  2. Baseline subtraction at judge time. Run the criterion at base_commit, record the known-red set, and subtract it before deciding PASS/FAIL. A residual present at the base can never fail the fix.
  3. One residual = one owner row. File detector findings once (boardctl create ... --deferred); re-detection is refused, so evidence the existing row instead of refiling.
  4. Record files_changed + base_commit in verdict.json. This is exactly what makes step 2 a mechanical diff instead of an argument.
  5. Flake-aware close. Give FUSE/mount tests a private TMPDIR in CI and treat wait_ready/timeout signatures as flake-suspect; require a clean-TMPDIR re-run before any close.
  6. Trust artifacts, not prose. Re-judge decisions must read verdict.json / summary.md; the commit message has no evidentiary weight.

7. One-screen checklist

  • [ ] Read the failing run's verdict.json + summary.md (not the commit message).
  • [ ] git diff --name-only <base>..<HEAD>: is the failing file untouched?
  • [ ] boardctl list / show: does the residual have its own row? If not, file one.
  • [ ] Re-run the acceptance-named target (... --test <target>) at HEAD under a private TMPDIR.
  • [ ] If FUSE/mount/timeout: classify as flake, re-run clean; don't gate the fix.
  • [ ] If touched by the fix: it is a regression — fix it; do not close.
  • [ ] Else: verification-only close with a fresh PASS --evidence-run-id.
