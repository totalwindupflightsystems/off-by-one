Reconciler for stale-generation descriptor reuse under systemd socket activation

Problem class: shell-20261014-systemd-socket-activation-fd-generation-race Language: bash 5 / POSIX tooling (awk, sort, grep, ss, gdb)

1. Symptom

Across a fleet, after .service restarts / .socket recreations, processes keep listening sockets alive that no longer belong to the current generation:

  • an old service instance survives a restart and keeps the port bound, racing the new instance;
  • a socket unit is recreated (new inode) but a worker still holds the previous generation's listener;
  • a listening fd number is later reused for another object, so (pid, fd)-keyed tooling closes the wrong thing — sometimes a live listener.

Events arrive interleaved, out of order, and duplicated. The reconciler must still emit one deterministic plan and never close the last reference to a live listener.

2. Root-cause analysis

Two independent things advance after activation:

Object Identity Changes when
listening socket inode socket:[N] + gen .socket restart / re-exec (new inode)
service instance pid + process starttime .service start / restart (new pid)
process fd (pid, fd) → inode fork/dup2/restart/fd-number recycle

A descriptor is stale when its generation was superseded, which a raw (pid, fd) view cannot see:

  1. Old socket inode — dead listener; any holder is a leak; safe to close (not the active listener).
  2. Superseded process + current inode — a duplicate of the live listener. Safe to close only if the current owner also holds the same inode. If it is the sole holder, it is the live listener → report, never remediate blindly.
  3. Foreign process + current inode — report, do not touch.
  4. Current owner holding an old inode — close that one fd surgically; never kill the owner.

Naive tools fail by keying only on (pid,fd) (fd-number reuse), ignoring /proc/<pid>/stat field 22 (recycled PID), ignoring duplicate-vs-last-reference, or using last-writer-wins on an unordered feed. The fix makes all four explicit.

3. Exact fix

3.1 Feed schema

Whitespace-separated records; # starts a comment; the feed may be shuffled and duplicated arbitrarily.

<seq> <eid> <KIND> key=value...
SOCK <seq> <eid> sock=<socket.unit> gen=<n> inode=<n> fd=<n> svc=<svc.unit> pid=<pid> pstart=<n>
SVC  <seq> <eid> svc=<svc.unit>  gen=<n> pid=<pid> pstart=<n> [reason=...]
FD   <seq> <eid> pid=<pid> pstart=<n> fd=<n> inode=<n> listen=<0|1> [svc=<svc.unit>] [ppid=<pid>]

eid = dedupe key, seq = latest-wins order, pstart = /proc/<pid>/stat field 22.

3.2 reconciler.sh

#!/usr/bin/env bash
# reconciler.sh
# Detect stale-generation descriptor reuse in systemd socket-activated fleets
# and emit a deterministic, minimal remediation plan.
set -u
LC_ALL=C

INPUT=/dev/stdin
MODE=plan
PROC_ROOT=/proc

die() { printf 'reconciler: %s\n' "$*" >&2; exit 2; }
warn() { printf 'WARN: %s\n' "$*" >&2; }

usage() {
  cat <<'EOF'
Usage: reconciler.sh [--apply|--verify] [--proc-root DIR] [FEED]
  FEED            incident feed (default: stdin, '-' = stdin)
  --verify        dry-run the plan against the live process table
  --apply         execute the plan (default: print plan only)
  --proc-root DIR use DIR instead of /proc for live identity checks
EOF
}

while (( $# )); do
  case $1 in
    --apply)     MODE=apply ;;
    --verify)    MODE=verify ;;
    --plan)      MODE=plan ;;
    --proc-root) shift; PROC_ROOT=${1:?--proc-root needs DIR} ;;
    -h|--help)   usage; exit 0 ;;
    -)           INPUT=/dev/stdin ;;
    --)          shift; [[ $# -gt 0 ]] && INPUT=$1; break ;;
    -*)          die "unknown option: $1" ;;
    *)           INPUT=$1 ;;
  esac
  shift
done

# 1. Ingest + dedupe. Identical duplicates dropped; conflicting eid resolved
#    deterministically (smallest canonical form wins) and reported.
declare -A CANON
WARNINGS=()
while IFS= read -r raw || [[ -n $raw ]]; do
  line=${raw%%#*}
  read -r -a tok <<< "$line"
  (( ${#tok[@]} < 3 )) && continue
  seq=${tok[0]} eid=${tok[1]} kind=${tok[2]}
  [[ $seq =~ ^[0-9]+$ ]] || { warn "bad seq in: $raw"; continue; }
  [[ $eid =~ ^[A-Za-z0-9_.:-]+$ ]] || { warn "bad eid in: $raw"; continue; }
  rest=""
  for ((i=3; i<${#tok[@]}; i++)); do rest+="${tok[i]} "; done
  canon="$seq|$eid|$kind|$rest"
  if [[ -n ${CANON[$eid]+x} ]]; then
    [[ ${CANON[$eid]} == "$canon" ]] && continue
    WARNINGS+=("conflicting eid=$eid")
    [[ "$canon" < "${CANON[$eid]}" ]] && CANON[$eid]=$canon
  else
    CANON[$eid]=$canon
  fi
done < "$INPUT"

# 2. Fold events into order-independent state.
declare -A SOCK_GEN SOCK_INODE SOCK_SVC
declare -A INODE_UNIT INODE_GEN INODE_SEQ
declare -A SVC_GEN SVC_PID
declare -A PID_SVC PID_GEN PID_PSTART
declare -A FD_INODE FD_LISTEN FD_PSTART FD_SEQ
declare -A PROC_PPID
declare -A F
for eid in "${!CANON[@]}"; do
  IFS='|' read -r seq _ kind rest <<< "${CANON[$eid]}"
  F=(); read -r -a kv <<< "$rest"
  for t in "${kv[@]}"; do [[ $t == *=* ]] && F[${t%%=*}]=${t#*=}; done
  case $kind in
    SOCK)
      u=${F[sock]:-} g=${F[gen]:-0} ino=${F[inode]:-}
      [[ -z $u || -z $ino ]] && { warn "SOCK missing sock/inode eid=$eid"; continue; }
      if [[ -z ${SOCK_GEN[$u]+x} ]]; then
        SOCK_GEN[$u]=$g; SOCK_INODE[$u]=$ino
      elif (( g > SOCK_GEN[$u] )) || { (( g == SOCK_GEN[$u] )) && [[ $ino < ${SOCK_INODE[$u]} ]]; }; then
        SOCK_GEN[$u]=$g; SOCK_INODE[$u]=$ino
      fi
      if [[ -z ${INODE_SEQ[$ino]+x} ]] || (( seq > INODE_SEQ[$ino] )) \
         || { (( seq == INODE_SEQ[$ino] )) && [[ $u < ${INODE_UNIT[$ino]} ]]; }; then
        INODE_SEQ[$ino]=$seq; INODE_UNIT[$ino]=$u; INODE_GEN[$ino]=$g
      fi
      [[ -n ${F[svc]:-} ]] && SOCK_SVC[$u]=${F[svc]}
      if [[ -n ${F[pid]:-} ]]; then
        PID_SVC[${F[pid]}]=${F[svc]:-${PID_SVC[${F[pid]}]:-}}
        PID_PSTART[${F[pid]}]=${F[pstart]:-${PID_PSTART[${F[pid]}]:-}}
      fi ;;
    SVC)
      svc=${F[svc]:-} g=${F[gen]:-0} pid=${F[pid]:-}
      [[ -z $svc || -z $pid ]] && { warn "SVC missing svc/pid eid=$eid"; continue; }
      if [[ -z ${SVC_GEN[$svc]+x} ]] || (( g > SVC_GEN[$svc] )); then
        SVC_GEN[$svc]=$g; SVC_PID[$svc]=$pid
      fi
      PID_SVC[$pid]=$svc; PID_GEN[$pid]=$g; PID_PSTART[$pid]=${F[pstart]:-${PID_PSTART[$pid]:-}} ;;
    FD)
      pid=${F[pid]:-} fd=${F[fd]:-} ino=${F[inode]:-}
      [[ -z $pid || -z $fd || -z $ino ]] && { warn "FD missing pid/fd/inode eid=$eid"; continue; }
      k="$pid|$fd"
      if [[ -z ${FD_SEQ[$k]+x} ]] || (( seq > FD_SEQ[$k] )); then
        FD_SEQ[$k]=$seq; FD_INODE[$k]=$ino; FD_LISTEN[$k]=${F[listen]:-0}; FD_PSTART[$k]=${F[pstart]:-}
      fi
      [[ -n ${F[ppid]:-} ]] && PROC_PPID[$pid]=${F[ppid]} ;;
    *) warn "unknown record kind '$kind' eid=$eid" ;;
  esac
done

CUR_PID=()
for s in "${!SVC_PID[@]}"; do CUR_PID[${SVC_PID[$s]}]=$s; done
declare -A LIVE_INODE
for u in "${!SOCK_INODE[@]}"; do LIVE_INODE[${SOCK_INODE[$u]}]=1; done

is_descendant_of_current() {
  local p=$1 parent depth=0
  while [[ -n ${PROC_PPID[$p]+x} ]] && (( depth++ < 64 )); do
    parent=${PROC_PPID[$p]}
    [[ -z $parent || $parent == 0 ]] && return 1
    [[ -n ${CUR_PID[$parent]+x} ]] && return 0
    p=$parent
  done
  return 1
}
declare -A OWNER_HOLDS_INODE
for k in "${!FD_INODE[@]}"; do
  pid=${k%%|*}; ino=${FD_INODE[$k]}
  [[ ${FD_LISTEN[$k]:-0} == 1 && -n ${CUR_PID[$pid]+x} ]] && OWNER_HOLDS_INODE[$ino]=1
done

# 3. Classify every observed listener fd.
declare -A VERDICT
declare -A PID_DANGEROUS PID_CURRENT PID_SUPERSEDED
for k in "${!FD_INODE[@]}"; do
  pid=${k%%|*}; fd=${k##*|}; ino=${FD_INODE[$k]}
  if [[ ${FD_LISTEN[$k]:-0} != 1 || -z ${INODE_UNIT[$ino]+x} ]]; then VERDICT[$k]=OTHER; continue; fi
  (( pid == 1 )) && { VERDICT[$k]=SYSTEMD; continue; }
  unit=${INODE_UNIT[$ino]}
  is_cur=0; [[ ${SOCK_INODE[$unit]:-} == "$ino" ]] && is_cur=1
  role=foreign
  if [[ -n ${CUR_PID[$pid]+x} ]] || is_descendant_of_current "$pid"; then
    role=current; PID_CURRENT[$pid]=1
  elif [[ -n ${PID_SVC[$pid]+x} && -n ${SVC_GEN[${PID_SVC[$pid]}]+x} ]] \
       && (( ${PID_GEN[$pid]:-0} < ${SVC_GEN[${PID_SVC[$pid]}]} )); then
    role=superseded; PID_SUPERSEDED[$pid]=1
  fi
  if [[ $role == current ]]; then
    if (( is_cur )); then VERDICT[$k]=LEGIT; else VERDICT[$k]=STALE; fi
  elif [[ $role == superseded ]]; then
    if (( is_cur )); then
      if [[ -n ${OWNER_HOLDS_INODE[$ino]+x} ]]; then VERDICT[$k]=LEAKED_DUP
      else VERDICT[$k]=DANGEROUS; PID_DANGEROUS[$pid]=1; fi
    else VERDICT[$k]=STALE; fi
  else
    if (( is_cur )); then VERDICT[$k]=FOREIGN_LIVE; else VERDICT[$k]=STALE_FOREIGN; fi
  fi
done

# 4. Minimal plan: one TERM covers all fds of a fully-superseded process;
#    otherwise surgical CLOSE per closable fd. Never plans a live listener.
STATE_LINES=() CLASS_LINES=() ACTION_LINES=()
for u in "${!SOCK_GEN[@]}"; do
  svc=${SOCK_SVC[$u]:-}
  STATE_LINES+=("$u|STATE socket $u gen=${SOCK_GEN[$u]} inode=${SOCK_INODE[$u]} service=${svc:-?} owner_pid=${SVC_PID[$svc]:-?}")
done
for k in "${!VERDICT[@]}"; do
  pid=${k%%|*}; fd=${k##*|}; ino=${FD_INODE[$k]}; unit=${INODE_UNIT[$ino]:-?}; g=${INODE_GEN[$ino]:-?}
  CLASS_LINES+=("$(printf '%010d|%010d' "$pid" "$fd")|CLASS pid=$pid fd=$fd inode=$ino socket=$unit gen=$g current=${SOCK_GEN[$unit]:-?} verdict=${VERDICT[$k]}")
done
declare -A PID_CLOSABLE_FDS
for k in "${!VERDICT[@]}"; do
  v=${VERDICT[$k]}
  [[ $v == STALE || $v == STALE_FOREIGN || $v == LEAKED_DUP ]] || continue
  pid=${k%%|*}; fd=${k##*|}; PID_CLOSABLE_FDS[$pid]+="$fd "
done
for pid in "${!PID_CLOSABLE_FDS[@]}"; do
  if [[ -n ${PID_SUPERSEDED[$pid]+x} && -z ${PID_DANGEROUS[$pid]+x} && -z ${PID_CURRENT[$pid]+x} ]]; then
    ps=${PID_PSTART[$pid]:-}
    ACTION_LINES+=("$(printf '%010d|1|%010d' "$pid" 0)|ACTION TERM pid=$pid pstart=$ps reason=superseded-generation-all-listeners-dead-or-duplicated")
  else
    for fd in ${PID_CLOSABLE_FDS[$pid]}; do
      k="$pid|$fd"; ino=${FD_INODE[$k]}; unit=${INODE_UNIT[$ino]:-?}; ps=${FD_PSTART[$k]:-}
      ACTION_LINES+=("$(printf '%010d|2|%010d' "$pid" "$fd")|ACTION CLOSE pid=$pid fd=$fd inode=$ino pstart=$ps socket=$unit reason=${VERDICT[$k]}")
    done
  fi
done

# 5. Deterministic report.
printf '# RECONCILER v5  records=%d  warnings=%d\n' "${#CANON[@]}" "${#WARNINGS[@]}"
for w in "${WARNINGS[@]:-}"; do [[ -n $w ]] && printf '# WARN %s\n' "$w"; done
[[ ${#WARNINGS[@]} -gt 0 ]] && printf '#\n'
printf '# --- current listener state ---\n'
if (( ${#STATE_LINES[@]} )); then printf '%s\n' "${STATE_LINES[@]}" | sort -t'|' -k1,1 | cut -d'|' -f2-; else printf '# (none)\n'; fi
printf '# --- fd classification ---\n'
if (( ${#CLASS_LINES[@]} )); then printf '%s\n' "${CLASS_LINES[@]}" | sort -t'|' -k1,1 -k2,2 | cut -d'|' -f3-; else printf '# (none)\n'; fi
printf '# --- minimal remediation plan ---\n'
if (( ${#ACTION_LINES[@]} )); then printf '%s\n' "${ACTION_LINES[@]}" | sort -t'|' -k1,1 -k2,2 -k3,3 | cut -d'|' -f4-; else printf '# (no action required)\n'; fi

# 6. Live identity guard + optional verify/apply.
proc_starttime() { awk '{ n=split($0,a,")"); rest=a[n]; sub(/^ /,"",rest); split(rest,b," "); print b[20] }' "$1" 2>/dev/null; }
plan_entries() { [[ ${#ACTION_LINES[@]} -gt 0 ]] || return 0; printf '%s\n' "${ACTION_LINES[@]}" | sort -t'|' -k1,1 -k2,2 -k3,3 | cut -d'|' -f4-; }
if [[ $MODE == apply || $MODE == verify ]]; then
  [[ $MODE == verify || $EUID -eq 0 ]] || die "--apply requires root (or CAP_SYS_PTRACE/CAP_KILL)"
  printf '\n# --- %s ---\n' "$([[ $MODE == apply ]] && echo applying || echo verifying) plan"
  while IFS= read -r line; do
    [[ $line == ACTION* ]] || continue
    read -r _ verb kv <<< "$line"
    pid=${kv#pid=}; pid=${pid%% *}
    pstart=${kv#*pstart=}; pstart=${pstart%% *}
    fd=${kv#*fd=}; [[ $fd == "$kv" ]] && fd=""; fd=${fd%% *}
    if [[ $pid == 1 || $pid == "$$" ]]; then printf '# SKIP pid=%s (protected)\n' "$pid"; continue; fi
    statf=$PROC_ROOT/$pid/stat
    if [[ ! -r $statf ]]; then printf '# SKIP pid=%s (gone)\n' "$pid"; continue; fi
    live=$(proc_starttime "$statf")
    if [[ -n $pstart && -n $live && $pstart != "$live" ]]; then
      printf '# SKIP pid=%s (pid recycled: live starttime=%s recorded=%s)\n' "$pid" "$live" "$pstart"; continue
    fi
    if [[ $verb == TERM ]]; then
      if [[ -z $pstart ]]; then printf '# SKIP pid=%s (no recorded starttime; cannot prove identity)\n' "$pid"; continue; fi
      holds_live=0
      for l in "$PROC_ROOT/$pid"/fd/*; do
        [[ -e $l || -L $l ]] || continue
        t=$(readlink "$l" 2>/dev/null) || continue
        case $t in
          socket:\[*\]) i=${t#socket:[}; i=${i%]}; [[ -n ${LIVE_INODE[$i]+x} ]] && { holds_live=1; break; } ;;
        esac
      done
      if (( holds_live )); then printf '# SKIP pid=%s (still holds a live listener)\n' "$pid"; continue; fi
      [[ $MODE == apply ]] || { printf '# OK   TERM pid=%s pstart=%s (no live listener held)\n' "$pid" "$pstart"; continue; }
      printf '# TERM pid=%s\n' "$pid"; kill -TERM "$pid" 2>/dev/null || printf '#   failed\n'
    else
      local_ino=${kv#*inode=}; local_ino=${local_ino%% *}
      target=$(readlink "$PROC_ROOT/$pid/fd/$fd" 2>/dev/null || true)
      case $target in *socket*) : ;; *) printf '# SKIP pid=%s fd=%s (not a socket: %s)\n' "$pid" "$fd" "$target"; continue ;; esac
      live_ino=${target##*[}; live_ino=${live_ino%]}
      if [[ -n $local_ino && -n $live_ino && $local_ino != "$live_ino" ]]; then
        printf '# SKIP pid=%s fd=%s (fd retargeted: live inode=%s recorded=%s)\n' "$pid" "$fd" "$live_ino" "$local_ino"; continue
      fi
      [[ $MODE == apply ]] || { printf '# OK   CLOSE pid=%s fd=%s inode=%s pstart=%s\n' "$pid" "$fd" "$local_ino" "$pstart"; continue; }
      printf '# CLOSE pid=%s fd=%s (gdb)\n' "$pid" "$fd"
      gdb -q -n -batch -p "$pid" -ex "call (int)close($fd)" >/dev/null 2>&1 || printf '#   gdb close failed (ptrace blocked?)\n'
    fi
  done < <(plan_entries)
fi

3.3 capture.sh — live process-fd snapshot

#!/usr/bin/env bash
# capture.sh — take a live process-fd snapshot in reconciler FD-record format.
#   listen=1 is derived from the kernel's listening-socket inode set (ss), so it
#   is accurate even when unprivileged /proc hides the socket owner.
set -u
PROC_ROOT=${1:-/proc}; seq=${2:-0}; LC_ALL=C
declare -A LISTEN
while read -r ino; do [[ -n $ino ]] && LISTEN[$ino]=1; done < <(
  ss -tlnpe 2>/dev/null | grep -oE 'ino:[0-9]+' | cut -d: -f2 | sort -u
)
for fdlink in "$PROC_ROOT"/[0-9]*/fd/*; do
  [[ -e $fdlink || -L $fdlink ]] || continue
  pid=${fdlink#"$PROC_ROOT"/}; pid=${pid%%/*}; fd=${fdlink##*/}
  target=$(readlink "$fdlink" 2>/dev/null) || continue
  case $target in
    socket:\[*\]) ino=${target#socket:[}; ino=${ino%]} ;;
    *) continue ;;
  esac
  listen=0; [[ -n ${LISTEN[$ino]+x} ]] && listen=1
  pstart=""
  [[ -r $PROC_ROOT/$pid/stat ]] && pstart=$(awk '{ n=split($0,a,")"); rest=a[n]; sub(/^ /,"",rest); split(rest,b," "); print b[20] }' "$PROC_ROOT/$pid/stat" 2>/dev/null)
  seq=$((seq+1))
  printf '%d c%08d FD pid=%s pstart=%s fd=%s inode=%s listen=%s\n' "$seq" "$seq" "$pid" "$pstart" "$fd" "$ino" "$listen"
done

3.4 selftest.sh

The 23-check harness is in /workspace/recon/selftest.sh (embedded verbatim inside /workspace/SOLUTION.md), covering classification, minimality, reorder/duplicate invariance, conflict handling, live guards, pid-1 protection, and malformed input.

4. Algorithm

  1. Ingest/dedupe by eid; identical dups dropped, conflicts reported and resolved by smallest canonical form.
  2. Fold order-independently: current socket gen = max gen; current service pid = max gen; fd observation = highest seq per (pid,fd).
  3. Classify by (process role, inode currency): LEGIT, STALE, LEAKED_DUP, DANGEROUS, FOREIGN_LIVE, STALE_FOREIGN, SYSTEMD, OTHER.
  4. Minimal plan: one TERM for a fully-superseded process (covers all its fds); otherwise surgical CLOSE. DANGEROUS/FOREIGN_LIVE/LEGIT/SYSTEMD are never planned.
  5. Deterministic emit (state by unit; class by pid,fd; actions by pid,rank,fd).

Invariant: a CLOSE is only emitted for a dead inode or for a duplicate of a current inode that the current owner also holds; the sole-reference case is DANGEROUS and yields no action.

CLASS pid=6100 fd=3 inode=9101 socket=metrics.socket gen=1 current=1 verdict=LEGIT
CLASS pid=6200 fd=3 inode=9101 socket=metrics.socket gen=1 current=1 verdict=FOREIGN_LIVE
CLASS pid=7100 fd=3 inode=9201 socket=worker.socket gen=1 current=1 verdict=DANGEROUS

  • pid=4100 (superseded api gen-1) holds two dead inodes and one live duplicate → one TERM replaces 3 closes.
  • pid=5200 is the current owner; only its dead fd 9 is closed. Its live fd 3 is untouched.
  • pid=6200 holds a live listener but is unrelated → FOREIGN_LIVE, no action.
  • pid=7100 is the sole holder of its live listener → DANGEROUS, no action (killing it would drop the service).

5.3 Apply-time guards

$ ./reconciler.sh --verify --proc-root fakeproc incident.feed
# --- verifying plan ---
# OK   TERM pid=4100 pstart=1000 (no live listener held)
# OK   CLOSE pid=5200 fd=9 inode=9001 pstart=2000

# after the pid is recycled and fd 9 is retargeted to a live listener:
# --- verifying plan ---
# SKIP pid=4100 (pid recycled: live starttime=9999 recorded=1000)
# SKIP pid=5200 fd=9 (fd retargeted: live inode=9002 recorded=9001)
Guard Trigger Result
starttime mismatch pid recycled SKIP ... (pid recycled: ...)
fd retargeted fd now points at another inode SKIP ... (fd retargeted: ...)
live listener re-check target pid acquired a current listener SKIP ... (still holds a live listener)
protected pid == 1 or reconciler itself SKIP ... (protected)
vanished /proc/<pid> gone SKIP ... (gone)

--apply is opt-in, root-only, and issues the close(2) via gdb; if ptrace is blocked it reports failure rather than guessing.

6. Operational use

{
  journalctl -o cat -b --no-hostname | awk '/Activated|Startup finished|Stopped|Started|socket/ { ... }'  # SVC/SOCK
  ./capture.sh                                                                                            # FD
} > incident.feed
./reconciler.sh incident.feed > plan.txt
./reconciler.sh --verify incident.feed
sudo ./reconciler.sh --apply incident.feed      # only after review

FOREIGN_LIVE/DANGEROUS rows are the escalation queue (lost or unauthorized listener reference) and are never auto-remediated. Run --verify as late as possible; a plan is only valid against the process table it was computed from.
