SSA Register Allocation Across Normal and Exceptional Edges

Problem class: python-20261014-ssa-exceptional-edge-register-allocation

Deliverable: a compiler pass that allocates registers for SSA values over normal and exceptional control-flow edges, respects per-call clobber masks, preserves phi-edge parallel-copy semantics, minimizes spill cost under a register budget, and emits an allocation certificate that a checker validates independently of the allocation heuristic.

1. Root-cause analysis

A textbook SSA register allocator rests on three assumptions. Each is false for this problem, and each failure is silent (miscompiled code, not a crash):

  1. The CFG has only normal edges. A throwing call has an exception edge to its landing pad. A liveness pass that follows only fallthrough/branch successors never marks a value used only in the landing pad as live at the call. The allocator then parks it in a caller-clobbered register and the handler reads garbage after the throw. This is the "values live only in landing pads" failure.

  2. Physical registers are interchangeable. Targets clobber a specific, per-call-site set of registers. Any value whose live range crosses the call must avoid every register in that call's clobber mask. A value that is only an argument and is dead afterwards may legally use a clobbered register.

  3. Phi operands can be copied sequentially. On an edge all (destination, source) pairs assigned by phis are simultaneous. Executing them one at a time corrupts values whenever the pairs form a cycle (the classic x <- y; y <- x swap). Sequentialisation needs a scratch location and a cycle-breaking order.

Two further requirements shape the fix:

  1. Spill minimisation under a budget. Greedy simplify/select colouring is fast but not always optimal, so an exact branch-and-bound upgrade is used with the heuristic as an initial upper bound and a node budget.

  2. Independent verifiability. Because an allocator bug is a miscompile, the certificate must let a checker re-derive liveness, interference and clobber constraints from the IR, then validate the assignment, every edge copy and the reported spill cost without trusting allocator state.

2. The fix

The pass is one self-contained module, ssa_regalloc.py.

Stage Role Why it fixes the root cause
IR model blocks, phis, call(clobbers=..., exc_succ=...) exception edges are first-class CFG edges
compute_liveness backward dataflow over normal and exception successors landing-pad-only values become live on the throwing edge
build_interference live-range interference plus edges to pre-coloured @Rr nodes v -- @Rr encodes exactly "v may not use Rr"
allocate_heuristic Chaitin–Briggs, spill victim ranked by weight/degree fast deterministic baseline
allocate_exact branch & bound, heuristic as upper bound minimum spill cost (bounded by node_limit)
schedule_parallel simultaneous copy schedule, cycles broken with TMP preserves phi-edge semantics
verify_certificate re-derives everything and checks it verification independent of the heuristic

Design points that matter:

  • Up-exposed uses. In SSA a value defined in a block cannot be live-in through a later use. The block use set is uses - defs. Without this, a phi-defined value used later in the same block leaks backwards onto the entry edge and spuriously interferes with its own operands.
  • Clobbers as pre-coloured nodes. Whenever a value is live after a call that clobbers r, add the edge v -- @Rr. Graph colouring with fixed colours then enforces the clobber mask automatically. A call argument that is dead after the call is not live-after, so it may use a clobbered register.
  • All phi destinations interfere, guaranteeing distinct copy destinations and making the parallel-copy scheduler total.
  • Exact spills. allocate(mode="exact") returns a provably minimum-cost allocation for the model; if node_limit is exceeded it falls back to the heuristic.

#!/usr/bin/env python3
"""
ssa_regalloc.py -- Register allocation for SSA values across normal and
exceptional control-flow edges, with a verifiable allocation certificate.

Pipeline
--------
1. IR model (blocks, phis, calls with target-specific clobber masks, exception
   successors / landing pads).
2. Edge-aware liveness (normal edges + exception edges from throwing calls).
3. Interference graph, including pre-coloured physical-register nodes that
   encode "value is live across a call that clobbers register r".
4. Chaitin-style simplify/select colouring under a register budget, choosing
   spill victims by a spill-cost / degree heuristic.
5. Phi-edge parallel-copy scheduling (cycles broken with a scratch location).
6. Certificate emission + an independent checker that re-derives every fact
   from the IR (it never trusts the allocator's intermediate state).

The checker also supports brute-force optimal spill cost for small functions,
so the heuristic's output can be compared against a ground truth.
"""
from __future__ import annotations

import json
from collections import defaultdict
from dataclasses import dataclass, field
from typing import Any, Optional

# --------------------------------------------------------------------------
# IR
# --------------------------------------------------------------------------

@dataclass
class Instr:
    """A single IR instruction.

    kind:
      'assign' -- dst = srcs[0]
      'phi'    -- dst = phi over predecessors; srcs is a tuple of
                  (predecessor_block, value) pairs
      'call'   -- optional dst = call(srcs...); may clobber physical regs and
                  may transfer to `exc_succ` (a landing pad)
      'use'    -- pure use of srcs (e.g. return/observable effect)
    """
    kind: str
    dst: Optional[str] = None
    srcs: tuple = ()
    clobbers: tuple = ()
    exc_succ: Optional[str] = None


@dataclass
class Block:
    name: str
    instrs: list = field(default_factory=list)
    succs: tuple = ()          # normal successors


@dataclass
class Function:
    name: str
    blocks: dict               # name -> Block
    entry: str
    regs: tuple                # physical registers, e.g. ("R0","R1","R2")
    weights: dict = field(default_factory=dict)   # value -> relative spill weight


# --------------------------------------------------------------------------
# CFG helpers
# --------------------------------------------------------------------------

def _isval(x) -> bool:
    """SSA values are strings; ints are literals and are not allocated."""
    return isinstance(x, str)


def all_successors(fn: Function) -> dict:
    """Return {block_name: set(successor_names)} incl. exception edges."""
    succ = {name: set(b.succs) for name, b in fn.blocks.items()}
    for name, b in fn.blocks.items():
        for ins in b.instrs:
            if ins.exc_succ is not None:
                succ[name].add(ins.exc_succ)
    return succ


def phi_operands(fn: Function, pred: str, succ: str) -> list:
    """All (dst, value) pairs selected by `succ`'s phis on the pred->succ edge."""
    out = []
    for ins in fn.blocks[succ].instrs:
        if ins.kind == "phi":
            for (pb, v) in ins.srcs:
                if pb == pred and _isval(v):
                    out.append((ins.dst, v))
    return out


def all_phis(fn: Function) -> list:
    out = []
    for b in fn.blocks.values():
        for ins in b.instrs:
            if ins.kind == "phi":
                out.append((b.name, ins))
    return out


def all_values(fn: Function) -> set:
    vals = set()
    for b in fn.blocks.values():
        for ins in b.instrs:
            if ins.dst is not None:
                vals.add(ins.dst)
            for s in ins.srcs:
                if ins.kind == "phi":
                    if _isval(s[1]):
                        vals.add(s[1])
                elif _isval(s):
                    vals.add(s)
    return vals


# --------------------------------------------------------------------------
# Liveness (normal + exceptional edges)
# --------------------------------------------------------------------------

@dataclass
class Liveness:
    live_in: dict
    live_out: dict
    defs: dict
    uses: dict
    edge_uses: dict            # (pred,succ) -> set of phi operand values


def compute_liveness(fn: Function) -> Liveness:
    succ = all_successors(fn)
    names = list(fn.blocks)
    defs, uses = {}, {}
    for name, b in fn.blocks.items():
        d, u = set(), set()
        for ins in b.instrs:
            if ins.kind == "phi":
                d.add(ins.dst)                     # defined at block entry
                # operands live on incoming edges, not inside the block
            else:
                if ins.dst is not None:
                    d.add(ins.dst)
                u.update(x for x in ins.srcs if _isval(x))
        # Up-exposed uses only: in SSA a value defined in the block cannot be
        # live-in through a later use, so remove block defs from the use set.
        uses[name] = u - d
        defs[name] = d

    # phi operand uses per incoming edge
    edge_uses = {}
    for p in names:
        for s in succ[p]:
            edge_uses[(p, s)] = {v for (_d, v) in phi_operands(fn, p, s)}

    live_in = {n: set() for n in names}
    live_out = {n: set() for n in names}
    changed = True
    while changed:
        changed = False
        for n in names:
            out = set()
            for s in succ[n]:
                # live_in[s] already excludes s's phi defs (they are in defs[s]);
                # phi operands are added on the edge itself.
                out |= live_in[s] | edge_uses[(n, s)]
            new_in = uses[n] | (out - defs[n])
            if out != live_out[n] or new_in != live_in[n]:
                live_out[n] = out
                live_in[n] = new_in
                changed = True
    return Liveness(live_in, live_out, defs, uses, edge_uses)


# --------------------------------------------------------------------------
# Interference graph + clobber constraints
# --------------------------------------------------------------------------

@dataclass
class Interference:
    adj: dict                  # node -> set(node); nodes are values and @Rr
    live_after: dict           # (block, instr_index) -> frozenset (for debug)
    clobber_edges: list        # (value, register_node)


def build_interference(fn: Function, live: Liveness) -> Interference:
    adj = defaultdict(set)
    clobber_edges = []
    live_after = {}

    def add(a, b):
        if a == b:
            return
        adj[a].add(b)
        adj[b].add(a)

    live_after = {}
    for name, b in fn.blocks.items():
        cur = set(live.live_out[name])
        # walk backwards, recording the live set *after* each instruction
        after = [None] * len(b.instrs)
        for i in range(len(b.instrs) - 1, -1, -1):
            ins = b.instrs[i]
            after[i] = set(cur)
            # clobber constraint: anything live after a call cannot sit in a
            # register the call clobbers.
            if ins.kind == "call":
                for v in after[i]:
                    for r in ins.clobbers:
                        rn = "@" + r
                        add(v, rn)
                        clobber_edges.append((v, rn))
            if ins.dst is not None:
                cur.discard(ins.dst)
            if ins.kind != "phi":
                cur.update(x for x in ins.srcs if _isval(x))

        # defs interfere with everything live after them
        for i, ins in enumerate(b.instrs):
            if ins.dst is None:
                continue
            for v in after[i]:
                add(ins.dst, v)

        # all phi destinations are defined at the same point: force them to be
        # pairwise distinct so that edge parallel copies have distinct targets.
        phi_dsts = [ins.dst for ins in b.instrs if ins.kind == "phi"]
        for i, d1 in enumerate(phi_dsts):
            for d2 in phi_dsts[i + 1:]:
                add(d1, d2)

        for i, ins in enumerate(b.instrs):
            live_after[(name, i)] = frozenset(after[i])

    # ensure every node is present
    for v in all_values(fn):
        adj.setdefault(v, set())
    for r in fn.regs:
        adj.setdefault("@" + r, set())
    return Interference(dict(adj), live_after, clobber_edges)


# --------------------------------------------------------------------------
# Allocation
# --------------------------------------------------------------------------

@dataclass
class Allocation:
    location: dict             # value -> register name or spill slot name
    color: dict                # value -> int register index (only if in reg)
    spilled: set
    registers: tuple
    spill_cost: float


def _access_counts(fn: Function) -> dict:
    counts = defaultdict(int)
    for b in fn.blocks.values():
        for ins in b.instrs:
            if ins.dst is not None:
                counts[ins.dst] += 1
            if ins.kind == "phi":
                for (_p, v) in ins.srcs:
                    if _isval(v):
                        counts[v] += 1
            else:
                for s in ins.srcs:
                    if _isval(s):
                        counts[s] += 1
    return counts


def allocate_heuristic(fn: Function, live: Liveness, budget: Optional[int] = None) -> Allocation:
    """Chaitin-Briggs simplify/select colouring.

    Physical registers are pre-coloured nodes (colour == register index).
    Clobber constraints are interference edges to those physical nodes.
    Spill victim selection minimises weight*(uses+defs)/degree.
    """
    K = len(fn.regs) if budget is None else budget
    regs = fn.regs[:K]
    inter = build_interference(fn, live)
    adj = {n: set(ns) for n, ns in inter.adj.items()}
    values = all_values(fn)
    counts = _access_counts(fn)
    weight = {v: float(fn.weights.get(v, 1.0)) * max(1, counts.get(v, 1))
              for v in values}

    color = {"@" + r: i for i, r in enumerate(regs)}
    removed = set()

    def degree(v):
        return sum(1 for n in adj[v] if n not in removed)

    stack = []
    work = set(values)
    while work:
        # Chaitin: prefer a node that can definitely be coloured.
        ready = [v for v in work if degree(v) < K]
        if ready:
            # deterministic tie-break: lowest id, then lowest degree
            ready.sort(key=lambda v: (degree(v), v))
            v = ready[0]
            tag = "ok"
        else:
            # optimistic spill: lowest cost/degree first
            def rank(v):
                d = max(1, degree(v))
                return (weight[v] / d, weight[v], v)
            v = min(work, key=rank)
            tag = "spill"
        stack.append((v, tag))
        work.discard(v)
        removed.add(v)

    spilled = set()
    for v, tag in reversed(stack):
        used = {color[n] for n in adj[v] if n in color}
        avail = [c for c in range(K) if c not in used]
        if avail:
            color[v] = avail[0]
        else:
            spilled.add(v)

    location = {v: regs[color[v]] for v in values if v not in spilled}
    slots = {v: "S%d" % i for i, v in enumerate(sorted(spilled))}
    location.update(slots)
    total = sum(weight[v] for v in spilled)
    return Allocation(location, color, spilled, regs, total)


def allocate_exact(fn: Function, live: Liveness, budget: int,
                   node_limit: int = 2_000_000,
                   upper: Optional[Allocation] = None) -> Allocation:
    """Exact minimum-spill-cost colouring via branch and bound.

    `upper` is an optional heuristic allocation used as an initial upper bound.
    If the search exceeds `node_limit` nodes the best incumbent (the heuristic
    upper bound) is returned, so this never runs unbounded.
    """
    K = budget
    regs = fn.regs[:K]
    inter = build_interference(fn, live)
    adj = {n: set(ns) for n, ns in inter.adj.items()}
    values = sorted(all_values(fn))
    counts = _access_counts(fn)
    weight = {v: float(fn.weights.get(v, 1.0)) * max(1, counts.get(v, 1))
              for v in values}

    forbidden = defaultdict(set)
    reg_index = {r: i for i, r in enumerate(fn.regs)}
    for (v, rn) in inter.clobber_edges:
        forbidden[v].add(reg_index[rn[1:]])
    vset = set(values)
    vadj = {v: {n for n in adj.get(v, ()) if n in vset} for v in values}
    degree = {v: len(vadj[v]) for v in values}

    # incumbent
    if upper is None:
        upper = allocate_heuristic(fn, live, K)
    best_cost = [float(upper.spill_cost)]
    best_assign = [dict(upper.color)]

    order = sorted(values, key=lambda v: (-degree[v], -weight[v], v))
    color = {}
    nodes = [0]
    aborted = [False]

    def rec(i, cost):
        nodes[0] += 1
        if nodes[0] > node_limit:
            aborted[0] = True
            return
        if cost >= best_cost[0]:
            return
        if i == len(order):
            best_cost[0] = cost
            best_assign[0] = dict(color)
            return
        v = order[i]
        used = {color[n] for n in vadj[v] if n in color and color[n] is not None}
        for c in range(K):
            if c in used or c in forbidden[v]:
                continue
            color[v] = c
            rec(i + 1, cost)
            if aborted[0]:
                del color[v]
                return
            del color[v]
        color[v] = None                    # spill v
        rec(i + 1, cost + weight[v])
        del color[v]

    rec(0, 0.0)

    assignment = best_assign[0]
    spilled = {v for v in values if assignment.get(v) is None}
    color_out = {v: assignment[v] for v in values if v not in spilled}
    location = {v: regs[color_out[v]] for v in color_out}
    for i, v in enumerate(sorted(spilled)):
        location[v] = "S%d" % i
    return Allocation(location, color_out, spilled, regs,
                      sum(weight[v] for v in spilled))


def allocate(fn: Function, live: Liveness, budget: Optional[int] = None,
             mode: str = "auto", node_limit: int = 2_000_000) -> Allocation:
    """Allocate registers.

    mode:
      'heuristic' -- Chaitin-Briggs only
      'exact'     -- exact branch and bound (bounded by node_limit)
      'auto'      -- exact for small functions, heuristic otherwise
    """
    K = len(fn.regs) if budget is None else budget
    h = allocate_heuristic(fn, live, K)
    if mode == "heuristic":
        return h
    if mode == "exact" or (mode == "auto" and len(all_values(fn)) <= 24):
        return allocate_exact(fn, live, K, node_limit=node_limit, upper=h)
    return h


# --------------------------------------------------------------------------
# Phi-edge parallel copies
# --------------------------------------------------------------------------

def required_copies(fn: Function, alloc: Allocation) -> dict:
    succ = all_successors(fn)
    copies = {}
    for p in fn.blocks:
        for s in sorted(succ[p]):
            pairs = []
            for (dst, src) in phi_operands(fn, p, s):
                pairs.append((alloc.location[dst], alloc.location[src]))
            copies[(p, s)] = pairs
    return copies


def schedule_parallel(pairs: list, temp: str) -> list:
    """Sequentialise a parallel copy with distinct destinations.

    Returns a list of ("move", dst, src) / ("save", temp, src) operations that
    implement all pairs simultaneously.  Cycles are broken through `temp`.
    """
    remaining = [(d, s) for (d, s) in pairs if d != s]
    moves = []
    guard = 0
    while remaining:
        guard += 1
        if guard > 10000:
            raise RuntimeError("parallel copy scheduling failed to converge")
        srcs = {s for _d, s in remaining}
        ready = [(d, s) for (d, s) in remaining if d not in srcs]
        if ready:
            d, s = ready[0]
            moves.append(("move", d, s))
            remaining.remove((d, s))
        else:
            # every destination is still a source -> a cycle; break one via temp
            d, s = remaining[0]
            moves.append(("save", temp, s))
            remaining = [(dd, temp if ss == s else ss) for (dd, ss) in remaining]
    return moves


def build_schedules(fn: Function, alloc: Allocation) -> dict:
    copies = required_copies(fn, alloc)
    temp = "TMP"
    return {key: schedule_parallel(pairs, temp) for key, pairs in copies.items()}, temp


# --------------------------------------------------------------------------
# Certificate
# --------------------------------------------------------------------------

def emit_certificate(fn: Function, alloc: Allocation) -> dict:
    schedules, temp = build_schedules(fn, alloc)
    copies = required_copies(fn, alloc)
    return {
        "function": fn.name,
        "register_budget": len(alloc.registers),
        "registers": list(alloc.registers),
        "assignment": {v: alloc.location[v] for v in sorted(alloc.location)},
        "spilled": sorted(alloc.spilled),
        "spill_cost": alloc.spill_cost,
        "edge_parallel_copies": {
            "%s->%s" % k: [[d, s] for (d, s) in v] for k, v in sorted(copies.items())
        },
        "edge_schedule": {
            "%s->%s" % k: [list(op) for op in v] for k, v in sorted(schedules.items())
        },
        "scratch": temp,
    }


# --------------------------------------------------------------------------
# Independent checker
# --------------------------------------------------------------------------

class CertificateError(Exception):
    pass


def verify_certificate(fn: Function, cert: dict) -> dict:
    """Re-derive all facts from the IR and validate the certificate.

    Returns a report dict; raises CertificateError on the first violation.
    """
    report = {}

    # ---- structural sanity -------------------------------------------------
    if cert.get("function") != fn.name:
        raise CertificateError("certificate is for a different function")
    regs = tuple(cert.get("registers", []))
    K = cert.get("register_budget")
    if K != len(regs):
        raise CertificateError("register_budget does not match register list")
    if K > len(fn.regs):
        raise CertificateError("certificate uses more registers than the target has")
    for r in regs:
        if r not in fn.regs:
            raise CertificateError("unknown register %r" % r)

    assignment = dict(cert.get("assignment", {}))
    expected_vals = all_values(fn)
    if set(assignment) != expected_vals:
        missing = expected_vals - set(assignment)
        extra = set(assignment) - expected_vals
        raise CertificateError(
            "assignment/value mismatch missing=%s extra=%s" % (sorted(missing), sorted(extra)))

    # ---- assignment legality ----------------------------------------------
    for v, loc in assignment.items():
        if loc in fn.regs:
            if loc not in regs:
                raise CertificateError("value %s assigned to unbudgeted register %s" % (v, loc))
        elif loc.startswith("S"):
            pass
        else:
            raise CertificateError("value %s has invalid location %r" % (v, loc))

    live = compute_liveness(fn)
    inter = build_interference(fn, live)

    # spilled list must agree with the locations actually chosen
    slot_values = {v for v, loc in assignment.items() if loc not in fn.regs}
    if set(cert.get("spilled", [])) != slot_values:
        raise CertificateError(
            "spilled list %s does not match slot assignments %s"
            % (sorted(cert.get("spilled", [])), sorted(slot_values)))

    # no interfering pair may share the same physical location
    for a in expected_vals:
        for b in inter.adj.get(a, ()):
            if b in expected_vals and a < b:
                if assignment[a] == assignment[b]:
                    raise CertificateError(
                        "interfering values %s and %s share location %s"
                        % (a, b, assignment[a]))

    # clobber constraints independently re-derived
    for (v, rn) in inter.clobber_edges:
        if assignment[v] == rn[1:]:
            raise CertificateError(
                "value %s is live across a call clobbering %s but is assigned there"
                % (v, rn[1:]))
    report["clobber_constraints"] = len(inter.clobber_edges)

    # ---- phi edge parallel copies -----------------------------------------
    cert_copies = cert.get("edge_parallel_copies", {})
    schedules = cert.get("edge_schedule", {})
    temp = cert.get("scratch")
    if temp is None:
        raise CertificateError("certificate has no scratch location")

    succ = all_successors(fn)
    checked_edges = 0
    checked_phis = 0
    for p in fn.blocks:
        for s in sorted(succ[p]):
            key = "%s->%s" % (p, s)
            required = [(assignment[dst], assignment[src])
                        for (dst, src) in phi_operands(fn, p, s)]
            got = [tuple(x) for x in cert_copies.get(key, [])]
            if sorted(required) != sorted(got):
                raise CertificateError(
                    "edge %s parallel copies mismatch required=%s got=%s"
                    % (key, sorted(required), sorted(got)))
            # destinations must be distinct
            dsts = [d for d, _ in got]
            if len(dsts) != len(set(dsts)):
                raise CertificateError("edge %s has duplicate copy destinations" % key)
            # validate the schedule
            op = schedules.get(key, [])
            _simulate_schedule(key, required, op, temp, assignment)
            checked_edges += 1
            checked_phis += len(required)
    report["edges_checked"] = checked_edges
    report["phi_copies_checked"] = checked_phis

    # ---- spill cost --------------------------------------------------------
    counts = _access_counts(fn)
    weight = {v: float(fn.weights.get(v, 1.0)) * max(1, counts.get(v, 1))
              for v in expected_vals}
    spilled = set(cert.get("spilled", []))
    recomputed = sum(weight[v] for v in spilled)
    if abs(recomputed - float(cert.get("spill_cost", -1))) > 1e-9:
        raise CertificateError(
            "spill_cost mismatch: cert=%s recomputed=%s"
            % (cert.get("spill_cost"), recomputed))
    report["spill_cost"] = recomputed
    report["spilled"] = sorted(spilled)
    report["valid"] = True
    return report


def _simulate_schedule(key, required, ops, temp, assignment):
    """Symbolically execute the parallel-copy schedule.

    content[loc] tracks which pre-edge location's value currently sits in loc.
    After execution, content[dst] must equal src for every required pair.
    """
    locations = set()
    for d, s in required:
        locations.add(d)
        locations.add(s)
    locations.add(temp)
    content = {loc: loc for loc in locations}
    dests = {d for d, _ in required}

    for op in ops:
        if op[0] == "move":
            _, d, s = op
            if d not in dests and d != temp:
                raise CertificateError(
                    "edge %s schedule writes non-destination %s" % (key, d))
            if s not in content:
                content[s] = s
            content[d] = content[s]
        elif op[0] == "save":
            _, t, s = op
            if t != temp:
                raise CertificateError(
                    "edge %s schedule saves to non-scratch %s" % (key, t))
            if s not in content:
                content[s] = s
            content[t] = content[s]
        else:
            raise CertificateError("edge %s has unknown op %r" % (key, op))

    pre = {loc: loc for loc in locations}
    for d, s in required:
        if content[d] != pre[s]:
            raise CertificateError(
                "edge %s: after schedule location %s holds %s, expected %s"
                % (key, d, content[d], pre[s]))
    return True

# Brute-force optimal spill cost (ground truth for small functions)
# --------------------------------------------------------------------------

def brute_force_optimal(fn: Function, budget: int):
    """Exhaustively find the minimum spill weight allocation.

    Uses unique spill slots. Returns (best_cost, best_spilled_set) or
    (inf, None) if no legal assignment exists. Exponential; use for tests.
    """
    live = compute_liveness(fn)
    inter = build_interference(fn, live)
    adj = {n: set(ns) for n, ns in inter.adj.items()}
    values = sorted(all_values(fn))
    counts = _access_counts(fn)
    weight = {v: float(fn.weights.get(v, 1.0)) * max(1, counts.get(v, 1))
              for v in values}
    K = budget
    best = [None, float("inf")]

    reg_index = {r: i for i, r in enumerate(fn.regs)}
    forbidden = {v: set() for v in values}
    for (v, rn) in inter.clobber_edges:
        forbidden[v].add(reg_index[rn[1:]])
    # value-value interference
    vadj = {v: {n for n in adj[v] if n in set(values)} for v in values}

    order = sorted(values, key=lambda v: -weight[v])

    color = {}

    def rec(i, cost):
        if cost >= best[1]:
            return
        if i == len(order):
            if cost < best[1]:
                best[0] = set(color[v] for v in values if color[v] is None)
                best[1] = cost
            return
        v = order[i]
        used = {color[n] for n in vadj[v] if n in color and color[n] is not None}
        for c in range(K):
            if c in used or c in forbidden[v]:
                continue
            color[v] = c
            rec(i + 1, cost)
            color[v] = "unset"
        # spill
        color[v] = None
        rec(i + 1, cost + weight[v])
        del color[v]

    # deterministic order, but we must track colors for all values
    rec(0, 0.0)
    return best[1], best[0]

def _demo_swap_loop() -> Function:

                Instr("use", srcs=("%x", "%y")),
            ], succs=("loop", "exit")),
            "exit": Block("exit", [Instr("use", srcs=("%x",))], succs=()),
        })


def _demo_exc_clobber() -> Function:
    return Function(
        name="exc_clobber", entry="entry", regs=("R0", "R1", "R2", "R3"),
        blocks={
            "entry": Block("entry", [
                Instr("assign", dst="%p", srcs=(1,)),
                Instr("assign", dst="%q", srcs=(2,)),
                Instr("call", dst="%r", srcs=("%p",), clobbers=("R0",),
                      exc_succ="handler"),
            ], succs=("normal",)),
            "normal": Block("normal", [Instr("use", srcs=("%p", "%r"))], succs=()),
            "handler": Block("handler", [Instr("use", srcs=("%q",))], succs=()),

def _random_ssa(rng, idx) -> Function:
    K = rng.randint(1, 3)
    n = rng.randint(2, 6)
    vals = ["%%v%d" % i for i in range(n)]
    entry_vals = [v for v in vals if rng.random() < 0.6]
    rest = [v for v in vals if v not in entry_vals]
    defined = list(entry_vals)
    phis, assigns = [], []
    for v in rest:
        if defined and rng.random() < 0.5:
            phis.append(Instr("phi", dst=v, srcs=(("entry", rng.choice(defined)),)))
        elif defined:
            assigns.append(Instr("assign", dst=v, srcs=(rng.choice(defined),)))
        else:
            assigns.append(Instr("assign", dst=v, srcs=(rng.randint(0, 3),)))
        defined.append(v)
    used = [v for v in vals if rng.random() < 0.7]
    body = phis + assigns + ([Instr("use", srcs=tuple(used))] if used else [])
    regs = tuple("R%d" % i for i in range(K))
    return Function("rnd%d" % idx, {
        "entry": Block("entry", [Instr("assign", dst=v, srcs=(rng.randint(0, 3),))
                                 for v in entry_vals], succs=("body",)),
        "body": Block("body", body, succs=()),
    }, "entry", regs)

  • swap_loop exercises the phi swap: TMP holds R0, then R0 <- R1, then R1 <- TMP. A sequential R0 <- R1; R1 <- R0 would be caught.
  • exc_clobber has %q used only in the landing pad and %p live across a call clobbering R0; neither is assigned R0.

3.2 What the independent checker validates

verify_certificate(fn, cert) uses only the IR and the certificate and re-derives liveness, interference and clobber edges. It checks:

  1. the assignment covers exactly the SSA values and uses only budgeted registers or spill slots S*;
  2. no two interfering values share a location;
  3. no value live across a clobbering call is placed in a clobbered register;
  4. the spilled list exactly matches the values assigned to spill slots;
  5. every edge's parallel copies equal the copies implied by its phis;
  6. each edge schedule, symbolically executed, leaves every destination holding the required pre-edge source value and writes only destinations or scratch;
  7. spill_cost equals the recomputed weight of spilled values.

Four deliberate corruptions are injected in the self-test — a clobbered register, a wrong phi copy, a bogus schedule order, and a falsified spill cost — and all are rejected with a CertificateError.

3.3 Optimality ground truth

brute_force_optimal(fn, budget) exhaustively searches every register/spill choice for small functions. allocate(mode="exact") matches it on 300 random functions inside the self-test, 800 random functions in the unit tests, and a structured fuzzer generated 2000 random CFGs containing phis, loops, calls with random clobber masks and exception edges, verifying 4000 certificates and 2000 optimality comparisons:
