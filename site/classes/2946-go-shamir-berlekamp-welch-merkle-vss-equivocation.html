Shamir / Berlekamp–Welch / Merkle VSS with equivocation detection

Problem class: go-shamir-berlekamp-welch-merkle-vss-equivocation Environment: Go 1.26 (verified with go1.26.8 linux/amd64) Deliverable: a self-contained Go module that shares a single secret byte over GF(2⁸), decodes the sharing polynomial with Berlekamp–Welch, cross-checks the dealer's SHA-256 Merkle commitment, and classifies the outcome as VALID, CORRUPT_SHARES, DEALER_EQUIVOCATION, or AMBIGUOUS.

1. Root-cause analysis: why naive implementations fail

1.1 The AES field is irreducible but not primitive

x⁸ + x⁴ + x³ + x + 1 (0x11b) is irreducible, so it is a valid field, but x = 0x02 has order 51, not 255. Building exp/log tables from 0x02 (as one does for a primitive polynomial) silently produces an incomplete group, and every multiplication after the first wrap is wrong.

Fix: build the tables from the generator 0x03 (x+1) and assert all 255 non-zero elements are visited before returning to 1. The implementation cross-checks every one of the 65,536 products against an independent shift-and-reduce routine.

1.2 Berlekamp–Welch unknown layout

The error-locator polynomial is monic: E(x) = x^e + e_{e-1}x^{e-1} + … + e_0. Treating all e+1 coefficients as unknown over-parameterises the system and destroys the solvability condition. With E monic there are k+e unknowns for Q and e for E', i.e. k+2e unknowns for n equations → the exact bound 2e < n-k+1 (equivalently 2e ≤ n-k).

Fix: substitute the monic term into the RHS: Q(xᵢ) − yᵢ·E'(xᵢ) = yᵢ·xᵢᵉ, then solve that affine system.

1.3 Non-canonical share encodings must be rejected, not normalised

encoding/hex accepts uppercase, strconv accepts leading zeros, generic parsers accept 0x prefixes. The statement requires rejection.

Fix: parseCanonicalByte accepts exactly two characters from [0-9a-f]; anything else (0A, 0X0a, a, 000a, whitespace, …) is an error. The Merkle root must likewise be 64 lowercase hex characters.

1.4 Boundary cases that break assumption-laden code

Case Trap Fix
k = 1 degree-0 polynomial; E division looks degenerate interpolate the constant / majority value
n = k no redundancy, e_max = 0 interpolate the n points directly
secret 0x00 zero polynomial has degree -1, not k-1 Poly.Deg() returns -1 for the zero polynomial; recovered for every n,k
2e ≥ n-k+1 BW system has a non-trivial solution space enumerate the affine solution space and report two distinct quotients

1.5 Classification: corruption vs dealer equivocation

Re-evaluating the decoded polynomial reveals which received shares were wrong, but not who is at fault. The dealer's Merkle root resolves this:

  • If the root rebuilt over the corrected values H(index ‖ P(index)) equals the published root, the dealer committed to consistent shares → CORRUPT_SHARES.
  • If instead the root rebuilt over the received values equals the published root, the dealer committed to the bad values still in participants' hands → DEALER_EQUIVOCATION.

Both the provided leaf order and the index-sorted order are tried, so the result does not depend on an undocumented tree ordering convention.

package vss

import "errors"

// GF(2^8) with the AES reduction polynomial x^8 + x^4 + x^3 + x + 1 (0x11b).
// The AES polynomial is irreducible but x (0x02) is not a generator; the
// element x+1 (0x03) is a generator of the multiplicative group, so the
// exp/log tables are built from 0x03.

type gfTables struct {
    exp [512]byte
    log [256]byte
}

var gf = newGF()

func newGF() *gfTables {
    var t gfTables
    seen := [256]bool{}
    x := byte(1)
    for i := 0; i < 255; i++ {
        if seen[x] {
            panic("GF(256): generator is not primitive")
        }
        seen[x] = true
        t.exp[i] = x
        t.log[x] = byte(i)
        x = mulNoTable(x, 0x03)
    }
    if x != 1 {
        panic("GF(256): generator order is not 255")
    }
    for i := 255; i < 512; i++ {
        t.exp[i] = t.exp[i-255]
    }
    t.log[0] = 0 // never used; guarded below
    return &t
}

// mulNoTable multiplies in GF(2^8) without using the exp/log tables.
func mulNoTable(a, b byte) byte {
    var r byte
    for b > 0 {
        if b&1 == 1 {
            r ^= a
        }
        hi := a & 0x80
        a <<= 1
        if hi != 0 {
            a ^= 0x1b
        }
        b >>= 1
    }
    return r
}

// xtime multiplies by x modulo 0x11b.
func xtime(a byte) byte {
    if a&0x80 != 0 {
        return (a << 1) ^ 0x1b
    }
    return a << 1
}

// Add is XOR in characteristic 2.
func gfAdd(a, b byte) byte { return a ^ b }

// Mul multiplies two field elements.
func gfMul(a, b byte) byte {
    if a == 0 || b == 0 {
        return 0
    }
    return gf.exp[int(gf.log[a])+int(gf.log[b])]
}

// Inv returns the multiplicative inverse; zero has no inverse.
func gfInv(a byte) (byte, error) {
    if a == 0 {
        return 0, errors.New("GF(256): division by zero")
    }
    return gf.exp[255-int(gf.log[a])], nil
}

// Div returns a/b; it fails on b == 0.
func gfDiv(a, b byte) (byte, error) {
    if b == 0 {
        return 0, errors.New("GF(256): division by zero")
    }
    if a == 0 {
        return 0, nil
    }
    return gf.exp[(int(gf.log[a])-int(gf.log[b])+255)%255], nil
}

// Pow returns a^e for e >= 0.
func gfPow(a byte, e int) byte {
    r := byte(1)
    for e > 0 {
        if e&1 == 1 {
            r = gfMul(r, a)
        }
        a = gfMul(a, a)
        e >>= 1
    }
    return r
}

package vss

import "errors"

// Poly is a polynomial over GF(2^8) with little-endian coefficients:
// p[0] + p[1]*x + p[2]*x^2 + ...
type Poly []byte

func (p Poly) clone() Poly {
    q := make(Poly, len(p))
    copy(q, p)
    return q
}

// normalize trims trailing zero coefficients.
func (p Poly) normalize() Poly {
    n := len(p)
    for n > 0 && p[n-1] == 0 {
        n--
    }
    return p[:n]
}

// Deg returns the degree, or -1 for the zero polynomial.
func (p Poly) Deg() int { return len(p.normalize()) - 1 }

// Eval evaluates p at x using Horner's rule.
func (p Poly) Eval(x byte) byte {
    var r byte
    for i := len(p) - 1; i >= 0; i-- {
        r = gfMul(r, x) ^ p[i]
    }
    return r
}

// Add returns p+q.
func (p Poly) Add(q Poly) Poly {
    n := len(p)
    if len(q) > n {
        n = len(q)
    }
    r := make(Poly, n)
    for i := 0; i < n; i++ {
        var a, b byte
        if i < len(p) {
            a = p[i]
        }
        if i < len(q) {
            b = q[i]
        }
        r[i] = a ^ b
    }
    return r.normalize()
}

// Scale returns c*p.
func (p Poly) Scale(c byte) Poly {
    r := make(Poly, len(p))
    for i, v := range p {
        r[i] = gfMul(c, v)
    }
    return r.normalize()
}

// Mul returns p*q.
func (p Poly) Mul(q Poly) Poly {
    if len(p) == 0 || len(q) == 0 {
        return Poly{}
    }
    r := make(Poly, len(p)+len(q)-1)
    for i, a := range p {
        if a == 0 {
            continue
        }
        for j, b := range q {
            r[i+j] ^= gfMul(a, b)
        }
    }
    return r.normalize()
}

// DivMod returns the quotient and remainder of p divided by d.
func (p Poly) DivMod(d Poly) (Poly, Poly, error) {
    d = d.normalize()
    if len(d) == 0 {
        return nil, nil, errors.New("polynomial division by zero")
    }
    rem := p.clone().normalize()
    if len(rem) < len(d) {
        return Poly{}, rem.clone(), nil
    }
    quot := make(Poly, len(rem)-len(d)+1)
    invLead, _ := gfInv(d[len(d)-1])
    for len(rem) >= len(d) {
        shift := len(rem) - len(d)
        coef := gfMul(rem[len(rem)-1], invLead)
        quot[shift] = coef
        for i := 0; i < len(d); i++ {
            rem[shift+i] ^= gfMul(coef, d[i])
        }
        rem = rem[:len(rem)-1].normalize()
    }
    return quot.normalize(), rem.clone().normalize(), nil
}

// interpolate returns the unique polynomial of degree < len(xs) through the
// given points. xs must be pairwise distinct.
func interpolate(xs, ys []byte) Poly {
    n := len(xs)
    if n == 0 {
        return Poly{}
    }
    res := make(Poly, n)
    for i := 0; i < n; i++ {
        num := Poly{1}
        den := byte(1)
        for j := 0; j < n; j++ {
            if j == i {
                continue
            }
            num = num.Mul(Poly{xs[j], 1})
            den = gfMul(den, xs[i]^xs[j])
        }
        scale, _ := gfDiv(ys[i], den)
        term := num.Scale(scale)
        res = res.Add(term)
    }
    return res.normalize()
}

linalg.go

package vss

// solveLinear solves A x = b over GF(2^8).
// It returns one particular solution and a basis for the null space of A.
func solveLinear(a [][]byte, b []byte) (particular []byte, nullBasis [][]byte, ok bool) {
    rows := len(a)
    if rows == 0 {
        return nil, nil, false
    }
    ncols := len(a[0])

    m := make([][]byte, rows)
    for i := range m {
        m[i] = make([]byte, ncols+1)
        copy(m[i], a[i])
        m[i][ncols] = b[i]
    }

    pivots := make([]int, 0, ncols)
    row := 0
    for col := 0; col < ncols && row < rows; col++ {
        pr := -1
        for r := row; r < rows; r++ {
            if m[r][col] != 0 {
                pr = r
                break
            }
        }
        if pr < 0 {
            continue
        }
        m[row], m[pr] = m[pr], m[row]
        inv, err := gfInv(m[row][col])
        if err != nil {
            return nil, nil, false
        }
        for c := col; c <= ncols; c++ {
            m[row][c] = gfMul(m[row][c], inv)
        }
        for r := 0; r < rows; r++ {
            if r == row || m[r][col] == 0 {
                continue
            }
            f := m[r][col]
            for c := col; c <= ncols; c++ {
                m[r][c] ^= gfMul(f, m[row][c])
            }
        }
        pivots = append(pivots, col)
        row++
    }

    // consistency: any non-pivot row must have zero right-hand side
    for r := row; r < rows; r++ {
        if m[r][ncols] != 0 {
            return nil, nil, false
        }
    }

    isPivot := make([]bool, ncols)
    for _, c := range pivots {
        isPivot[c] = true
    }

    particular = make([]byte, ncols)
    for i, c := range pivots {
        particular[c] = m[i][ncols]
    }

    for free := 0; free < ncols; free++ {
        if isPivot[free] {
            continue
        }
        vec := make([]byte, ncols)
        vec[free] = 1
        for i, c := range pivots {
            vec[c] = m[i][free]
        }
        nullBasis = append(nullBasis, vec)
    }
    return particular, nullBasis, true
}

bw.go

package vss

import "sort"

func (p Poly) key() string {
    k := make([]byte, len(p))
    copy(k, p)
    return string(k)
}

// findAllPolys searches for every degree-(k-1) polynomial that agrees with at
// least n-radius of the points, using Berlekamp-Welch interpolation for each
// candidate error-locator degree t <= radius. The returned slice is de-duped.
func findAllPolys(xs, ys []byte, k, radius int) []Poly {
    maxT := radius
    if maxT > len(xs) {
        maxT = len(xs)
    }
    found := map[string]Poly{}
    for t := 0; t <= maxT; t++ {
        for _, f := range bwAtDegree(xs, ys, k, t) {
            if f.Deg() >= k {
                continue
            }
            if mismatchCount(f, xs, ys) <= radius {
                found[f.key()] = f.clone().normalize()
            }
        }
    }
    out := make([]Poly, 0, len(found))
    for _, p := range found {
        out = append(out, p)
    }
    sort.Slice(out, func(i, j int) bool { return lessPoly(out[i], out[j]) })
    return out
}

func lessPoly(a, b Poly) bool {
    n := len(a)
    if len(b) < n {
        n = len(b)
    }
    for i := 0; i < n; i++ {
        if a[i] != b[i] {
            return a[i] < b[i]
        }
    }
    return len(a) < len(b)
}

func mismatchCount(f Poly, xs, ys []byte) int {
    c := 0
    for i := range xs {
        if f.Eval(xs[i]) != ys[i] {
            c++
        }
    }
    return c
}

// bwAtDegree solves the Berlekamp-Welch linear system for error-locator degree
// exactly t and returns every valid quotient polynomial of degree < k.
func bwAtDegree(xs, ys []byte, k, t int) []Poly {
    n := len(xs)
    nQ := k + t // Q has degree <= k+t-1
    nE := t     // E is monic: E = x^t + e_{t-1}x^{t-1} + ... + e_0
    m := nQ + nE

    pows := make([][]byte, n)
    for i := 0; i < n; i++ {
        p := make([]byte, nQ)
        xp := byte(1)
        for j := 0; j < nQ; j++ {
            p[j] = xp
            xp = gfMul(xp, xs[i])
        }
        pows[i] = p
    }

    A := make([][]byte, n)
    b := make([]byte, n)
    for i := 0; i < n; i++ {
        row := make([]byte, m)
        copy(row[:nQ], pows[i][:nQ])
        for j := 0; j < nE; j++ {
            row[nQ+j] = gfMul(ys[i], pows[i][j])
        }
        A[i] = row
        b[i] = gfMul(ys[i], pows[i][t])
    }

    particular, nullBasis, ok := solveLinear(A, b)
    if !ok {
        return nil
    }

    u := make([]byte, m)
    var out []Poly
    seen := map[string]bool{}
    total := 1
    for range nullBasis {
        total *= 256
        if total > 1<<20 {
            total = -1
            break
        }
    }
    consider := func(u []byte) {
        Q := make(Poly, nQ)
        copy(Q, u[:nQ])
        E := make(Poly, t+1)
        copy(E, u[nQ:])
        E[t] = 1
        q, r, err := Q.DivMod(E)
        if err != nil || len(r) != 0 {
            return
        }
        if q.Deg() >= k {
            return
        }
        key := q.key()
        if seen[key] {
            return
        }
        seen[key] = true
        out = append(out, q.clone().normalize())
    }

    if total > 0 {
        idx := make([]int, len(nullBasis))
        for {
            copy(u, particular)
            for l, c := range idx {
                if c == 0 {
                    continue
                }
                nb := nullBasis[l]
                for j := 0; j < m; j++ {
                    u[j] ^= gfMul(byte(c), nb[j])
                }
            }
            consider(u)
            p := 0
            for p < len(idx) {
                idx[p]++
                if idx[p] < 256 {
                    break
                }
                idx[p] = 0
                p++
            }
            if p == len(idx) {
                break
            }
        }
    } else {
        consider(particular)
        for trial := 0; trial < 64; trial++ {
            copy(u, particular)
            for l := range nullBasis {
                c := byte(trial*31 + l*7 + 1)
                nb := nullBasis[l]
                for j := 0; j < m; j++ {
                    u[j] ^= gfMul(c, nb[j])
                }
            }
            consider(u)
        }
    }
    return out
}

merkle.go

package vss

import (
    "crypto/sha256"
    "encoding/hex"
)

// leafHash computes H(index || share) where both are single bytes.
func leafHash(index, share byte) [32]byte {
    var buf [2]byte
    buf[0] = index
    buf[1] = share
    return sha256.Sum256(buf[:])
}

// merkleRoot builds a binary Merkle tree over the supplied leaves. When a
// level has an odd number of nodes the final node is duplicated.
func merkleRoot(leaves [][32]byte) [32]byte {
    if len(leaves) == 0 {
        return [32]byte{}
    }
    level := make([][32]byte, len(leaves))
    copy(level, leaves)
    for len(level) > 1 {
        if len(level)%2 == 1 {
            level = append(level, level[len(level)-1])
        }
        next := make([][32]byte, len(level)/2)
        for i := 0; i < len(level); i += 2 {
            h := sha256.New()
            h.Write(level[i][:])
            h.Write(level[i+1][:])
            var out [32]byte
            copy(out[:], h.Sum(nil))
            next[i/2] = out
        }
        level = next
    }
    return level[0]
}

func rootHex(root [32]byte) string { return hex.EncodeToString(root[:]) }

// rootOverShares computes the Merkle root over leaves (index, value).
func rootOverShares(indices []int, values []byte, sorted bool) [32]byte {
    type pair struct {
        idx int
        val byte
    }
    ps := make([]pair, len(indices))
    for i := range indices {
        ps[i] = pair{indices[i], values[i]}
    }
    if sorted {
        for i := 1; i < len(ps); i++ {
            for j := i; j > 0 && ps[j].idx < ps[j-1].idx; j-- {
                ps[j], ps[j-1] = ps[j-1], ps[j]
            }
        }
    }
    leaves := make([][32]byte, len(ps))
    for i, p := range ps {
        leaves[i] = leafHash(byte(p.idx), p.val)
    }
    return merkleRoot(leaves)
}

vss.go

package vss

import (
    "crypto/rand"
    "encoding/hex"
    "errors"
    "fmt"
    "sort"
)

const (
    ClassValid       = "VALID"
    ClassCorrupt     = "CORRUPT_SHARES"
    ClassEquivocate  = "DEALER_EQUIVOCATION"
    ClassAmbiguous   = "AMBIGUOUS"
    ClassUndecodable = "UNDECODABLE"
)

type Share struct {
    Index int
    Value byte
}

type Result struct {
    SecretHex      string
    Corrupt        []int
    Classification string
    MaxUniqueE     int
    Ambiguous      []Poly
}

// MaxUniqueErrors returns the largest e for which unique decoding is
// guaranteed: 2e < n-k+1  <=>  e <= floor((n-k)/2).
func MaxUniqueErrors(n, k int) int {
    d := n - k
    if d < 0 {
        return 0
    }
    return d / 2
}

// MerkleRootHex returns the lowercase-hex Merkle root over H(index||share).
func MerkleRootHex(indices []int, values []byte) string {
    return rootHex(rootOverShares(indices, values, true))
}

// Generate builds an honest sharing of a single-byte secret.
func Generate(secret byte, n, k int, rng func([]byte) error) ([]Share, Poly, error) {
    if n < 1 || n > 255 || k < 1 || k > n {
        return nil, nil, fmt.Errorf("bad n/k: n=%d k=%d", n, k)
    }
    poly := make(Poly, k)
    poly[0] = secret
    for i := 1; i < k; i++ {
        var b [1]byte
        if rng != nil {
            if err := rng(b[:]); err != nil {
                return nil, nil, err
            }
        } else {
            if _, err := rand.Read(b[:]); err != nil {
                return nil, nil, err
            }
        }
        poly[i] = b[0]
    }
    shares := make([]Share, n)
    for i := 0; i < n; i++ {
        idx := i + 1
        shares[i] = Share{Index: idx, Value: poly.Eval(byte(idx))}
    }
    return shares, poly.normalize(), nil
}

func Decode(indices []int, values []byte, k, eBudget int, publishedRoot string) (*Result, error) {
    n := len(indices)
    if n == 0 {
        return nil, errors.New("no shares")
    }
    if k < 1 || k > n {
        return nil, fmt.Errorf("invalid threshold k=%d for n=%d", k, n)
    }
    xs := make([]byte, n)
    seen := map[int]bool{}
    for i, idx := range indices {
        if idx < 1 || idx > 255 {
            return nil, fmt.Errorf("share index %d out of range 1..255", idx)
        }
        if seen[idx] {
            return nil, fmt.Errorf("duplicate share index %d", idx)
        }
        seen[idx] = true
        xs[i] = byte(idx)
    }

    eMax := MaxUniqueErrors(n, k)
    radius := eBudget
    if radius < eMax {
        radius = eMax
    }
    if radius > n {
        radius = n
    }

    polys := findAllPolys(xs, values, k, radius)
    res := &Result{MaxUniqueE: eMax}
    switch len(polys) {
    case 0:
        res.Classification = ClassUndecodable
        return res, nil
    case 1:
    default:
        if 2*radius >= n-k+1 {
            res.Classification = ClassAmbiguous
            res.Ambiguous = pickTwo(polys)
            return res, nil
        }
        sort.Slice(polys, func(i, j int) bool {
            return mismatchCount(polys[i], xs, values) < mismatchCount(polys[j], xs, values)
        })
    }

    p := polys[0]
    res.SecretHex = hex.EncodeToString([]byte{p.Eval(0)})
    var corrupt []int
    for i := range xs {
        if p.Eval(xs[i]) != values[i] {
            corrupt = append(corrupt, indices[i])
        }
    }
    sort.Ints(corrupt)
    res.Corrupt = corrupt

    if len(corrupt) == 0 {
        res.Classification = ClassValid
        return res, nil
    }
    corrected := make([]byte, n)
    for i := range xs {
        corrected[i] = p.Eval(xs[i])
    }
    if publishedRoot != "" {
        matchesCorrected := false
        matchesReceived := false
        for _, sorted := range []bool{true, false} {
            if rootHex(rootOverShares(indices, corrected, sorted)) == publishedRoot {
                matchesCorrected = true
            }
            if rootHex(rootOverShares(indices, values, sorted)) == publishedRoot {
                matchesReceived = true
            }
        }
        switch {
        case matchesCorrected:
            res.Classification = ClassCorrupt
        case matchesReceived:
            res.Classification = ClassEquivocate
        default:
            res.Classification = ClassUndecodable
        }
        return res, nil
    }
    res.Classification = ClassCorrupt
    return res, nil
}

func pickTwo(polys []Poly) []Poly {
    if len(polys) < 2 {
        return polys
    }
    return []Poly{polys[0], polys[1]}
}

type output struct {
    Secret         string   `json:"secret,omitempty"`
    Corrupt        []int    `json:"corrupt_indices,omitempty"`
    Classification string   `json:"classification"`
    MaxUniqueE     int      `json:"max_unique_e"`
    Ambiguous      []string `json:"ambiguous_polynomials,omitempty"`
    Error          string   `json:"error,omitempty"`
}

func parseCanonicalByte(s string) (byte, error) {
    if len(s) != 2 {
        return 0, fmt.Errorf("non-canonical share %q: want exactly 2 lowercase hex digits", s)
    }
    for _, c := range s {
        if !((c >= '0' && c <= '9') || (c >= 'a' && c <= 'f')) {
            return 0, fmt.Errorf("non-canonical share %q: must be lowercase hex", s)
        }
    }
    b, err := hex.DecodeString(s)
    if err != nil {
        return 0, fmt.Errorf("non-canonical share %q: %v", s, err)
    }
    return b[0], nil
}

func polyString(p vss.Poly) string {
    b := make([]byte, len(p))
    copy(b, p)
    return hex.EncodeToString(b)
}

func validRoot(s string) bool {
    if len(s) != 64 {
        return false
    }
    for _, c := range s {
        if !((c >= '0' && c <= '9') || (c >= 'a' && c <= 'f')) {
            return false
        }
    }
    return true
}

func run(r io.Reader) (*output, error) {
    var in input
    dec := json.NewDecoder(r)
    dec.DisallowUnknownFields()
    if err := dec.Decode(&in); err != nil {
        return nil, fmt.Errorf("invalid input JSON: %w", err)
    }
    n := len(in.Shares)
    if in.N != 0 && in.N != n {
        return nil, errors.New("n does not match number of shares")
    }
    if in.K < 1 {
        return nil, errors.New("k must be >= 1")
    }

    indices := make([]int, n)
    values := make([]byte, n)
    for i, s := range in.Shares {
        v, err := parseCanonicalByte(s.Value)
        if err != nil {
            return nil, err
        }
        indices[i] = s.Index
        values[i] = v
    }

    eBudget := -1
    if in.E != nil {
        eBudget = *in.E
        if eBudget < 0 {
            return nil, errors.New("e must be >= 0")
        }
    }
    if in.MerkleRoot != "" && !validRoot(in.MerkleRoot) {
        return nil, errors.New("merkle_root must be 64 lowercase hex characters")
    }
    res, err := vss.Decode(indices, values, in.K, eBudget, in.MerkleRoot)
    if err != nil {
        return nil, err
    }
    out := &output{
        Secret:         res.SecretHex,
        Corrupt:        res.Corrupt,
        Classification: res.Classification,
        MaxUniqueE:     res.MaxUniqueE,
    }
    for _, p := range res.Ambiguous {
        out.Ambiguous = append(out.Ambiguous, polyString(p))
    }
    return out, nil
}

func main() {
    out, err := run(os.Stdin)
    if err != nil {
        json.NewEncoder(os.Stdout).Encode(output{Classification: "ERROR", Error: err.Error()})
        os.Exit(1)
    }
    json.NewEncoder(os.Stdout).Encode(out)
}

3.3 Scale

Gaussian elimination is O(n·(k+2t)²) per error-locator degree, sweeping t up to the radius. Worst-case n = 255 on this machine:

n k e_max decode time
255 128 63 0.42 s
255 200 27 0.21 s
255 50 102 0.45 s
255 2 126 0.40 s

At the minimal error-locator degree the affine solution space has dimension at most 2 (k+2t−n ≤ 2), so the exhaustive 256^d ≤ 65,536 enumeration for ambiguity is cheap.
