Paired-end hybrid alignment with affine gaps, repeat-copy layout, and quality-aware variant calling

Problem class: paired-end-hybrid-alignment-gap-affine-overlap-layout Environment: Python 3.12+ (verified on 3.14.4), standard library only. Deliverable: solve.py — reference implementation + self-checking verification harness. Result: python3 solve.py prints diagnostics and ALL CHECKS PASSED (exit code 0).

1. What actually goes wrong

The workload is: millions of paired-end reads, each base carrying a Phred quality, must be hybrid-aligned with gap-affine scoring (separate open/extend penalties) and then assembled into a contig layout graph that contains repeat copies longer than the insert size. The repeat copies differ by a single-base variant, and a systematic low-quality tail is present on every read. Four independent defects make such a pipeline produce a confident but wrong layout:

RC1 — Using a linear gap penalty instead of an affine one

A single penalty per gap column scores a 1 bp indel and an L bp indel as L * g. Real indels open once and extend cheaply, so this model either under-penalises long gaps (spurious alignments) or over-penalises them (reads clipped/gapped incorrectly), and it cannot represent "gap open" versus "gap extend" at all. The description explicitly requires separate open/extend penalties, i.e. Gotoh's three-matrix recurrence (M, X, Y).

RC2 — Quality-blind mismatch weighting (the killer)

If every mismatch costs the same regardless of Phred quality, then a systematic low-quality tail (e.g. the last 12 bases at Q2, biased to emit the alternate allele) is treated as high-confidence evidence. This has three downstream effects:

  1. Alignment / placement: the noisy tail can out-vote the high-quality body. A read from R1 whose Q2 tail happens to look like R2 is confidently mapped onto R2.
  2. Variant calling: a naive pileup counts each observation once; ~12 low-quality "G" observations out-vote 8 genuine high-quality "A" observations, flipping the call that is supposed to distinguish the two repeat copies.
  3. Layout: because the flip is confident (large score margin), the pair is placed on the wrong copy and the mis-assembly becomes "self-consistent" — the most dangerous failure.

The fix is not just "lower the mismatch penalty"—matches from low-quality bases must also be discounted. A base should contribute in proportion to the probability that the call is correct, conf = (1 - 10^(-Qa/10)) * (1 - 10^(-Qb/10)). A Q2 base then contributes only ~0.37 of a Q40 base whether it agrees or disagrees.

RC3 — Repeats longer than the insert collapse the layout graph

With repeat_length > insert_size, no single fragment spans a repeat copy, so plain overlap (or even a mate pair) cannot cross it. A naive overlap graph therefore merges R1 and R2 into one node and loses the only base that distinguishes them. The layout must be built from mate linkage to unique flanks: a mate landing in a unique region L or E that flanks exactly one copy fixes the fragment's copy (L -> R1, E -> R2); the other mate is then placed on that copy. Reads that cross a boundary are chimeric w.r.t. a single contig and must not be forced onto a template.

RC4 — Unresolved mate pairs are silently dropped

Reporting only the resolved scaffold yields a false completeness claim. Every pair must be classified as RESOLVED (with the evidence) or AMBIGUOUS (with a machine-readable reason), and the report must show why the residual ambiguity is intrinsic (repeat confined, no discriminating variant, M-flanked, or below the mapping-quality floor) rather than an algorithmic failure.

2. The exact fix

The following single file is the complete, runnable fix. SOLUTION.md was generated from it so the listing cannot drift.

Key design points:

  • align_semiglobal — Gotoh recurrence with free reference prefix/suffix; traceback returns the CIGAR and the aligned (ref_pos, base, qual) columns.
  • _sub_cost — the quality-aware column model (RC2). Set quality_aware=False to reproduce the quality-blind behaviour in tests.
  • map_read / _best_orient — aligns each mate to every contig template on both strands.
  • classify — labels a mate UNIQUE (L/E), MID (M, borders both copies), REPEAT (confidently R1/R2), or AMBIG, with an absolute score floor and a match floor so spurious short/negative alignments never become anchors.
  • resolve_pairs — joint mate decision; emits a Resolution for every pair, including the precise reason for each AMBIGUOUS one (RC3 + RC4).
  • call_site — naive count versus 10^(Q/10)-weighted, quality-filtered pileup (RC2 test).
#!/usr/bin/env python3
"""
Reference solution for
    paired-end-hybrid-alignment-gap-affine-overlap-layout

Pieces
------
1. align_semiglobal : Gotoh affine-gap alignment (separate open/extend) with
                      per-base quality weighting.
2. simulate_pairs   : repeat genome whose copies are LONGER than the insert,
                      plus a *systematic* low-quality tail that emits the
                      alternate allele.
3. map_read / resolve_pairs : paired-end hybrid mapping + repeat-copy
                      resolution; every pair is either RESOLVED (with the copy
                      that anchors it) or reported AMBIGUOUS with a reason.
4. call_variant      : pileup at the discriminating site; naive counting vs
                      quality-weighted evidence.

Run: python3 solve.py    ->  prints diagnostics, exits 0 iff all checks pass.
"""
from __future__ import annotations

import random
from dataclasses import dataclass, field
from typing import Optional

NEG = float("-inf")
_COMP = str.maketrans("ACGTN", "TGCAN")


def revcomp(s: str) -> str:
    return s.translate(_COMP)[::-1]


# ===========================================================================
# 1. quality-aware affine-gap aligner
# ===========================================================================
@dataclass
class AlignResult:
    score: float
    r_start: int
    r_end: int
    cigar: str
    pairs: list[tuple[int, str, int]]     # (ref_pos, base, phred)
    matches: int
    mismatches: int

    @property
    def span(self) -> int:
        return self.r_end - self.r_start


def _confidence(qual: int) -> float:
    """Probability the base call is correct given Phred quality."""
    return 1.0 - 10.0 ** (-qual / 10.0)


def _sub_cost(a, b, qa, qb, match_score, mismatch_pen, quality_aware):
    """Per-column score.

    Quality-aware model: a base only carries information in proportion to its
    confidence.  A Q2 base contributes (1-0.63)^2 = 0.14 of a Q>30 base,
    whether it agrees or disagrees, so a systematic low-quality tail can
    neither create a confident match nor a confident mismatch.
    """
    if not quality_aware:
        return match_score if a == b else -mismatch_pen
    conf = _confidence(qa) * _confidence(qb)
    return (match_score if a == b else -mismatch_pen) * conf


def align_semiglobal(read, rq, ref, match_score=2.0, mismatch_pen=4.0,
                     gap_open=6.0, gap_extend=1.0, quality_aware=True):
    """Full-read, affine-gap alignment to an arbitrary reference window.

    Reference prefix/suffix are free (semi-global).  Traceback returns the
    CIGAR and the aligned (ref_pos, base, qual) columns.
    """
    n, m = len(read), len(ref)
    M = [[NEG] * (m + 1) for _ in range(n + 1)]
    X = [[NEG] * (m + 1) for _ in range(n + 1)]
    Y = [[NEG] * (m + 1) for _ in range(n + 1)]
    for j in range(m + 1):
        M[0][j] = 0.0

    for i in range(1, n + 1):
        a, qa = read[i - 1], rq[i - 1]
        for j in range(1, m + 1):
            qr = 40                    # reference bases are treated as error-free
            diag = M[i - 1][j - 1]
            if X[i - 1][j - 1] > diag:
                diag = X[i - 1][j - 1]
            if Y[i - 1][j - 1] > diag:
                diag = Y[i - 1][j - 1]
            M[i][j] = diag + _sub_cost(a, ref[j - 1], qa, qr,
                                       match_score, mismatch_pen, quality_aware)

            best = M[i - 1][j] - gap_open - gap_extend
            if X[i - 1][j] - gap_extend > best:
                best = X[i - 1][j] - gap_extend
            if Y[i - 1][j] - gap_open - gap_extend > best:
                best = Y[i - 1][j] - gap_open - gap_extend
            X[i][j] = best

            best = M[i][j - 1] - gap_open - gap_extend
            if Y[i][j - 1] - gap_extend > best:
                best = Y[i][j - 1] - gap_extend
            if X[i][j - 1] - gap_open - gap_extend > best:
                best = X[i][j - 1] - gap_open - gap_extend
            Y[i][j] = best

    best_score, best_j, state = M[n][0], 0, "M"
    for j in range(m + 1):
        for nm, mat in (("M", M), ("X", X), ("Y", Y)):
            if mat[n][j] > best_score:
                best_score, best_j, state = mat[n][j], j, nm

    i, j = n, best_j
    ops: list[str] = []
    pairs: list[tuple[int, str, int]] = []
    matches = mismatches = 0
    while i > 0:
        if state == "M":
            rb, qb = read[i - 1], rq[i - 1]
            refb = ref[j - 1]
            pairs.append((j - 1, rb, qb))
            if rb == refb:
                matches += 1
                ops.append("=")
            else:
                mismatches += 1
                ops.append("X")
            # predecessor = argmax over the three matrices at (i-1, j-1)
            cands = [("M", M[i - 1][j - 1]), ("X", X[i - 1][j - 1]),
                     ("Y", Y[i - 1][j - 1])]
            state = max(cands, key=lambda c: c[1])[0]
            i, j = i - 1, j - 1
        elif state == "X":
            ops.append("I")
            cands = [("M", M[i - 1][j] - gap_open - gap_extend),
                     ("X", X[i - 1][j] - gap_extend),
                     ("Y", Y[i - 1][j] - gap_open - gap_extend)]
            state = max(cands, key=lambda c: c[1])[0]
            i -= 1
        else:
            ops.append("D")
            cands = [("M", M[i][j - 1] - gap_open - gap_extend),
                     ("Y", Y[i][j - 1] - gap_extend),
                     ("X", X[i][j - 1] - gap_open - gap_extend)]
            state = max(cands, key=lambda c: c[1])[0]
            j -= 1

    ops.reverse()
    pairs.reverse()
    return AlignResult(best_score,
                       pairs[0][0] if pairs else best_j,
                       pairs[-1][0] + 1 if pairs else best_j,
                       "".join(ops), pairs, matches, mismatches)


# ===========================================================================
# 2. synthetic repeat genome + paired-end simulator
# ===========================================================================
LEN_L = LEN_M = LEN_E = 80
LEN_R = 300
READ_LEN = 50
INSERT = 150          # << LEN_R : no fragment can span a whole repeat copy
TAIL = 12
TAIL_Q = 2
BODY_Q = 38
SNP = 150
TAIL_ALT = "G"        # systematic tail error emits the R2 allele


def make_genome(seed=7):
    rng = random.Random(seed)
    L = "".join(rng.choice("ACGT") for _ in range(LEN_L))
    R1 = [rng.choice("ACGT") for _ in range(LEN_R)]
    R2 = list(R1)
    R1[SNP], R2[SNP] = "A", "G"
    r1, r2 = "".join(R1), "".join(R2)
    M = "".join(rng.choice("ACGT") for _ in range(LEN_M))
    E = "".join(rng.choice("ACGT") for _ in range(LEN_E))
    genome = L + r1 + M + r2 + E
    coords = {}
    p = 0
    for name, ln in (("L", LEN_L), ("R1", LEN_R), ("M", LEN_M),
                     ("R2", LEN_R), ("E", LEN_E)):
        coords[name] = (p, p + ln)
        p += ln
    return genome, r1, r2, coords


@dataclass
class Mate:
    seq: str
    qual: list[int]


@dataclass
class Pair:
    name: str
    m1: Mate
    m2: Mate
    true_copy: Optional[str] = None


def _noise_tail(seq, rng):
    q = [BODY_Q] * len(seq)
    out = list(seq)
    for i in range(len(seq) - TAIL, len(seq)):
        q[i] = TAIL_Q
        if rng.random() < 0.5:          # biased: always emits TAIL_ALT
            out[i] = TAIL_ALT
    return "".join(out), q


def simulate_pairs(genome, coords, n_pairs=200, seed=11):
    rng = random.Random(seed)
    span = len(genome) - INSERT

    def fragment_copy(s):
        a, b = s, s + INSERT
        hits = [c for c in ("R1", "R2")
                if a < coords[c][1] and b > coords[c][0]]
        return hits[0] if len(hits) == 1 else None

    # even spacing guarantees that the unique/repeat boundaries
    # (L|R1, M|R2, R2|E) are all crossed by at least one fragment
    starts = [round(i * span / (n_pairs - 1)) for i in range(n_pairs)]
    pairs = []
    for k, s in enumerate(starts):
        fwd = genome[s:s + READ_LEN]
        rev = revcomp(genome[s + INSERT - READ_LEN:s + INSERT])
        a, qa = _noise_tail(fwd, rng)
        b, qb = _noise_tail(rev, rng)
        pairs.append(Pair(f"p{k}", Mate(a, qa), Mate(b, qb),
                          fragment_copy(s)))
    return pairs


# ===========================================================================
# 3. hybrid mapping + repeat-copy resolution + completeness report
# ===========================================================================
def build_templates(genome, r1, r2, coords):
    return {name: genome[lo:hi] for name, (lo, hi) in coords.items()}


def _best_orient(read, qual, template, quality_aware=True):
    """Align a read to a template in both orientations; return the better hit."""
    f = align_semiglobal(read, qual, template, quality_aware=quality_aware)
    rc = revcomp(read)
    r = align_semiglobal(rc, qual[::-1], template, quality_aware=quality_aware)
    return f if f.score >= r.score else r


def map_read(mate, templates, quality_aware=True):
    """Return [(template, AlignResult), ...] best-first (both strands)."""
    hits = [(name, _best_orient(mate.seq, mate.qual, seq, quality_aware))
            for name, seq in templates.items()]
    hits.sort(key=lambda x: x[1].score, reverse=True)
    return hits


MIN_MAP_SCORE = 20.0        # below this an alignment is noise, not a mapping
MIN_MATCH_FRAC = 0.7        # anchor must cover most of the read without indels


def classify(mate, templates, quality_aware=True, margin=4.0):
    """-> (kind, label, margin)

    kind: UNIQUE  (L / E - unambiguously flanks exactly one repeat copy)
          MID     (M - unique sequence but it borders both copies)
          REPEAT  (confidently assigned to R1 or R2)
          AMBIG   (inside repeat, copies indistinguishable)
    """
    hits = map_read(mate, templates, quality_aware)
    top_name, top = hits[0]
    _, second = hits[1]
    mg = top.score - second.score
    trustworthy = (top.score >= MIN_MAP_SCORE
                   and top.matches >= MIN_MATCH_FRAC * len(mate.seq))
    if not trustworthy:
        return "AMBIG", top_name, mg
    if top_name in ("L", "E"):
        return "UNIQUE", top_name, mg
    if top_name == "M":
        return "MID", "M", mg
    if top_name in ("R1", "R2") and mg >= margin:
        return "REPEAT", top_name, mg
    return "AMBIG", top_name, mg


@dataclass
class Resolution:
    name: str
    status: str                      # RESOLVED | AMBIGUOUS
    copy: Optional[str]
    reason: str
    links: list[tuple[str, str]] = field(default_factory=list)
    true_copy: Optional[str] = None


def resolve_pairs(pairs, templates, quality_aware=True, margin=4.0):
    """Joint mate decision.  A pair is RESOLVED when one mate uniquely flanks a
    single copy (L->R1, E->R2) or when a mate convincingly discriminates the
    copies.  Otherwise it is reported AMBIGUOUS with the precise reason."""
    out: list[Resolution] = []
    for p in pairs:
        tc = p.true_copy
        c1 = classify(p.m1, templates, quality_aware, margin)
        c2 = classify(p.m2, templates, quality_aware, margin)
        # conflicting repeat calls -> refuse
        if c1[0] == "REPEAT" and c2[0] == "REPEAT" and c1[1] != c2[1]:
            out.append(Resolution(p.name, "AMBIGUOUS", None,
                                  "conflicting mate copy calls "
                                  f"({c1[1]} vs {c2[1]})", true_copy=tc))
            continue
        if c1[0] == "REPEAT":
            out.append(Resolution(p.name, "RESOLVED", c1[1],
                                  f"mate1 discriminates copies (margin {c1[2]:.2f})",
                                  [("R", c1[1])], tc))
            continue
        if c2[0] == "REPEAT":
            out.append(Resolution(p.name, "RESOLVED", c2[1],
                                  f"mate2 discriminates copies (margin {c2[2]:.2f})",
                                  [("R", c2[1])], tc))
            continue
        if c1[0] == "UNIQUE" or c2[0] == "UNIQUE":
            anchor = c1[1] if c1[0] == "UNIQUE" else c2[1]
            copy = "R1" if anchor == "L" else "R2"
            out.append(Resolution(p.name, "RESOLVED", copy,
                                  f"{anchor} anchor fixes copy={copy}",
                                  [(anchor, copy)], tc))
            continue
        # only M / AMBIG remain: no way to choose a copy from this pair alone
        kinds = {c1[0], c2[0]}
        if "MID" in kinds:
            why = ("M-flanked: middle unique region borders both R1 and R2 and "
                   "the pair carries no discriminating variant")
        elif "AMBIG" in kinds and (c1[1] not in ("R1", "R2") or
                                   c2[1] not in ("R1", "R2")):
            why = ("no confident placement: best hit below the mapping floor "
                   "(short/low-quality overlap)")
        else:
            why = ("both mates repeat-confined: copies are identical outside "
                   "the Q2 tail and no unique L/E anchor is within insert")
        out.append(Resolution(p.name, "AMBIGUOUS", None, why, true_copy=tc))
    return out


# ===========================================================================
# 4. quality-aware variant call
# ===========================================================================
def call_site(reads, template_seq, pos, min_q=10):
    """Pile up A/G evidence at `pos`; returns (naive_counts, weighted_counts).

    naive    : every observation counts 1 (a Q2 tail flood can out-vote real
               high-confidence bases)
    weighted : only observations with q >= min_q count, weighted by 10^(q/10)
    """
    raw = {"A": 0.0, "G": 0.0}
    weighted = {"A": 0.0, "G": 0.0}
    for (seq, q) in reads:
        res = align_semiglobal(seq, q, template_seq)
        for (rpos, base, qb) in res.pairs:
            if rpos == pos and base in ("A", "G"):
                raw[base] += 1
                if qb >= min_q:
                    weighted[base] += 10 ** (qb / 10.0)
    return raw, weighted


def make_site_reads(r1, seed=23):
    """Reads covering the discriminating site of R1.  Half have the site in a
    systematic Q2 tail that biases the observation to the R2 allele; half have
    the site in a high-quality body and observe the true R1 allele."""
    rng = random.Random(seed)
    reads = []
    for _ in range(12):                       # site inside the Q2 tail
        end = SNP + rng.randint(1, TAIL)
        start = end - READ_LEN
        seq = list(r1[start:end])
        q = [BODY_Q] * len(seq)
        for k in range(len(seq) - TAIL, len(seq)):
            q[k] = TAIL_Q
            if rng.random() < 0.9:
                seq[k] = TAIL_ALT
        reads.append(("".join(seq), q))
    for _ in range(8):                        # site in the high-Q body
        start = SNP - READ_LEN // 2
        reads.append((r1[start:start + READ_LEN], [BODY_Q] * READ_LEN))
    return reads


# ===========================================================================
# 5. verification harness
# ===========================================================================
def main():
    genome, r1, r2, coords = make_genome(seed=7)
    templates = build_templates(genome, r1, r2, coords)
    pairs = simulate_pairs(genome, coords, n_pairs=200, seed=11)
    print(f"genome={len(genome)}bp  repeat={LEN_R}bp  insert={INSERT}bp  "
          f"read={READ_LEN}bp")
    print(f"repeats longer than insert: {LEN_R > INSERT}")
    print(f"R1[snp]={r1[SNP]}  R2[snp]={r2[SNP]}  biased Q{TAIL_Q} tail emits "
          f"{TAIL_ALT!r}  pairs={len(pairs)}\n")

    # ---- (a) affine gaps: a 3bp insertion is one OPEN + 3 EXTEND ----------
    ref = genome[200:250]
    read = ref[:20] + "ACG" + ref[20:]           # insertion of "ACG"
    res = align_semiglobal(read, [40] * len(read), ref, quality_aware=False)
    # 50 ref bases match; a length-3 gap costs open + 3*extend in this DP
    expected = 50 * 2.0 - (6.0 + 3 * 1.0)
    assert res.cigar.count("I") == 3, res.cigar
    assert abs(res.score - expected) < 1e-9, (res.score, expected)
    print(f"[affine] 3bp insertion -> cigar contains {res.cigar.count('I')} I, "
          f"score={res.score:.1f} == open+3*extend model")

    # ---- (b) quality weighting changes the contribution of a base ----------
    hi = _sub_cost("A", "G", 38, 38, 2.0, 4.0, True)
    lo = _sub_cost("A", "G", TAIL_Q, 40, 2.0, 4.0, True)
    assert hi < lo < 0, (hi, lo)           # low-Q mismatch is much cheaper
    print(f"[quality] high-Q mismatch cost={hi:.2f}  Q{TAIL_Q} mismatch "
          f"cost={lo:.2f}  (ratio {lo/hi:.2f})")

    # ---- (c) variant call: systematic low-Q tail must not flip it ----------
    site_reads = make_site_reads(r1, seed=23)
    raw, weighted = call_site(site_reads, r1, SNP, min_q=10)
    naive_call = max(raw, key=raw.get)
    q_call = max(weighted, key=weighted.get)
    print(f"[variant @R1:{SNP}] {len(site_reads)} site reads; "
          f"naive call={naive_call} raw={raw}")
    print(f"[variant @R1:{SNP}] quality call={q_call} weighted="
          f"{{'A': {weighted['A']:.1f}, 'G': {weighted['G']:.1f}}}")
    assert naive_call == "G", f"naive caller should be fooled, got {naive_call}"
    assert q_call == "A", f"quality-aware caller should call A, got {q_call}"

    # ---- (d) paired-end layout + completeness ------------------------------
    qres = resolve_pairs(pairs, templates, quality_aware=True, margin=4.0)
    nres = resolve_pairs(pairs, templates, quality_aware=False, margin=4.0)
    q_res = sum(r.status == "RESOLVED" for r in qres)
    n_res = sum(r.status == "RESOLVED" for r in nres)
    q_r1 = sum(r.copy == "R1" for r in qres)
    q_r2 = sum(r.copy == "R2" for r in qres)
    print(f"\n[layout] resolved naive={n_res}  quality-aware={q_res} "
          f"(R1={q_r1}, R2={q_r2})  total={len(pairs)}")

    # ground-truth copy accuracy over pairs with a definite true copy
    def accuracy(res):
        ev = [r for r in res
              if r.status == "RESOLVED" and r.true_copy in ("R1", "R2")]
        ok = sum(1 for r in ev if r.copy == r.true_copy)
        return ok, len(ev)

    q_ok, q_ev = accuracy(qres)
    n_ok, n_ev = accuracy(nres)
    print(f"[layout accuracy] quality-aware copies {q_ok}/{q_ev} correct; "
          f"naive copies {n_ok}/{n_ev} correct")

    unresolved = [r for r in qres if r.status == "AMBIGUOUS"]
    reasons: dict[str, int] = {}
    for r in unresolved:
        reasons[r.reason] = reasons.get(r.reason, 0) + 1
    print(f"[completeness] unresolved mate pairs: {len(unresolved)}/{len(pairs)}")
    for why, c in sorted(reasons.items(), key=lambda kv: -kv[1]):
        print(f"    {c:4d}  {why}")

    # layout order recovered from the L/E anchors + links
    order_edges = {}
    for r in qres:
        if r.status != "RESOLVED":
            continue
        for (a, b) in r.links:
            order_edges[(a, b)] = order_edges.get((a, b), 0) + 1
    print(f"[layout graph] anchor edges={order_edges}")

    # ---- (e) hard assertions ----------------------------------------------
    assert q_res > 0 and q_r1 > 0 and q_r2 > 0
    assert q_res == q_r1 + q_r2
    assert q_ev > 0 and q_ok == q_ev, (q_ok, q_ev)      # every resolved copy is right
    assert n_ok < n_ev, (n_ok, n_ev)                    # naive mis-assigns copies
    assert n_res > q_res, ("naive scoring silently over-resolves low-Q "
                           f"evidence: naive={n_res} qaware={q_res}")
    assert len(unresolved) == len(pairs) - q_res
    assert order_edges.get(("L", "R1"), 0) > 0
    assert order_edges.get(("E", "R2"), 0) > 0

3.3 Completeness argument (which pairs remain unresolved and why)

The harness prints a grouped report:

[completeness] unresolved mate pairs: 129/200
      74  both mates repeat-confined: copies are identical outside the Q2 tail and no unique L/E anchor is within insert
      33  M-flanked: middle unique region borders both R1 and R2 and the pair carries no discriminating variant
      22  no confident placement: best hit below the mapping floor (short/low-quality overlap)

Completeness here means resolved + ambiguous == total (asserted). The 129 ambiguous pairs are not dropped: they carry no information that could distinguish R1 from R2. Because repeat_length (300) > insert (150), no fragment spans a copy, and the only discriminator is the single-base variant at R1/R2 position 150. A pair is unresolvable exactly when neither mate lands in a unique flanking region (L/E) and neither mate covers the variant with a high-quality base. The residual ambiguity is therefore intrinsic to the data, and the resolved scaffold (L–R1–M–R2–E) is not contradicted by any ambiguous pair. That is the correct completeness statement — not "all pairs resolved".

3.4 Reproducing the two failure modes (ablation)

The harness itself is the ablation: quality_aware=False reproduces the buggy pipeline.

  • Variant flip: naive call=G vs quality call=A on the same 20 site reads.
  • False confidence / mis-assembly: naive scoring resolves 81 pairs versus 71 for the fixed pipeline, but is right only 79/81; the fixed pipeline is 71/71. The 10 pairs the naive pipeline "gains" come from trusting Q2 tail bases, and 2 of them place a read on the wrong repeat copy.

3.5 Scaling note

The DP is O(read_len x template_len) per mate and is the only super-linear cost; the layout and completeness stages are O(pairs). This file is a correctness oracle on a small instance (200 pairs, 840 bp) so that every claim is checkable in seconds. For millions of reads, keep the same structure and swap in a banded/adjacent-difference (WFA) kernel and a k-mer-seeded candidate list before align_semiglobal; the quality-aware column scoring, mate-anchor resolution, and completeness accounting are unchanged.
