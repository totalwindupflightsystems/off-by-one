Quorum Log Prefix Repair Under Epoch Wrap

Problem class: go-20261014-quorum-log-prefix-repair-under-epoch-wrap Stack: Go 1.26 Deliverable: a complete, tested package quorumlog that (a) authenticates signed quorum certificates over a weighted, jointly-reconfiguring replicated log whose epochs may wrap, (b) rejects non-linearizable histories with a minimal counterexample, and (c) returns the minimum safe repair suffix plus a verifiable safety witness.

0. The model, stated precisely

Everything below depends on these definitions, so they are stated up front rather than inferred.

Concept Definition
Log entry (Index uint64, Epoch uint32, Value string). Index is dense and starts at the snapshot point start.
Epoch A uint32 term/ballot counter that wraps. Ordering is RFC-1982 serial arithmetic, defined only for distances < 2^31; a distance of exactly 2^31 is ambiguous.
Configuration A weighted voter set. A quorum is a subset with weight strictly greater than half the total.
Joint consensus Membership{Joint:true, Old, New}. A certificate is valid iff its signers are a quorum of both Old and New.
Configuration timeline Membership is keyed by log index (monotonic, wrap-free), not by epoch. Index i is governed by the latest change with Change.Index <= i.
Quorum certificate (QC) A bag of votes for one (Index, Epoch, Value). A vote is (Voter, Index, Epoch, Value, ed25519.Sig) and the signature covers every one of those fields.
Certificate as contract A QC is treated as proof that a quorum certified this value in this epoch. A later epoch may legitimately overwrite an earlier epoch's value (Raft/Paxos log evolution); therefore cross-epoch value differences are not violations. Two values certified in the same epoch are a violation, because two quorums intersect and the intersecting honest voter would have to double-sign.
Linearizable history One that can be assigned a single value per index such that no epoch certifies two values at the same index, no epoch pair is half-range-ambiguous, and the surviving value at each index is the one with the greatest wrap-aware epoch.
Minimum safe repair suffix The shortest suffix [r, logEnd] that must be re-replicated so that [start, r) is a contiguous, locally-consistent, certificate-backed prefix. r is the first index without an authenticated certificate (or that diverges from one).

Inputs to the analysis: qcs []QC, the local []LogEntry copy, start uint64, a *Timeline, and a *Verifier. Outputs: Linearizable bool; Conflicts []Conflict (minimal counterexamples); Rejected []Rejected; the witness Committed []Committed; and RepairStart, RepairEnd, Unsafe, LogEnd.

1. Root-cause analysis

The task asks to diagnose the failure mode. There is no single typo here; the "minimum safe repair suffix" is corrupted by six independent semantic defects. Each is stated with the concrete wrong behavior it produces.

RC-1 — Epoch wrap breaks "latest wins"

A uint32 epoch wraps. Comparing with numeric </> makes 0xFFFFFFF0 look newer than 3, so the analyser keeps a stale entry, reports the wrong surviving value, and names the wrong epoch in the witness. Fix: RFC-1982 serial ordering.

RC-2 — Joint consensus quorum checked with only one half

During joint consensus, a certificate is valid iff its signers are a quorum of the old and the new configuration. Accepting old OR new (or validating against whichever half "looks current") lets a minority of one half certify a value. The resulting "committed" prefix is fiction and the repair suffix is computed from it. Fix: Membership.HasQuorum requires the old quorum and, when joint, the new quorum.

RC-3 — Configuration chosen by current membership instead of membership-at-index

A certificate made under the old configuration must be judged by the old configuration even after the new one is active, and a certificate at a new-config index must not be judged by the old config. Using the current config either rejects valid history (spurious repair) or accepts invalid history (unsafe prefix). Fix: Timeline.At(index).

RC-4 — Naive quorum arithmetic

Four distinct holes, each sufficient to fabricate a quorum: 1. duplicate votes from one voter are double-counted; 2. voters outside the configuration contribute weight; 3. the signature does not cover index/epoch/value, so a vote can be replayed elsewhere; 4. 2*sum > total overflows for large weights.

Fix: dedupe voters, filter to the membership, bind the signature to all fields, and test sum > total-sum.

RC-5 — Wrong notion of conflict

Two different values at the same index in different epochs are legal — a later epoch overwrites an earlier, uncertified proposal. The provable violation is two values certified in the same epoch: quorum intersection forces an honest voter to have double-signed. Treating all cross-epoch value differences as conflicts rejects valid histories; treating none as conflicts (only noticing byte-identical duplicate QCs) accepts equivocation. Fix: bucket by (index, epoch); reject same-epoch multi-value certificates and half-range-ambiguous epoch orderings; otherwise let the wrap-aware maximum epoch win.

RC-6 — Repair suffix computed from the wrong end

The safe prefix ends at the first index without an authenticated certificate (or that diverges from one), not at the highest index seen. Everything from that first hole through logEnd is the minimum suffix that must be re-replicated, because committing index i always requires a contiguous [start, i]. Fix: scan start..logEnd and stop at the first unsafe index.

epoch.go

package quorumlog

// Epoch is a wrap-around term/ballot counter (e.g. a uint32 term number).
//
// Plain numeric comparison is wrong once the counter wraps: after
// 0xFFFFFFFF the next epoch is 0, which is numerically smaller but
// causally newer. Epoch provides RFC 1982 style serial-number ordering
// over the half-open range [1, 1<<31).
type Epoch uint32

const epochHalf = uint32(1) << 31

// Less reports whether a causally precedes b.
func (a Epoch) Less(b Epoch) bool {
    d := uint32(b - a)
    return d != 0 && d < epochHalf
}

// Greater reports whether a causally follows b.
func (a Epoch) Greater(b Epoch) bool {
    return b.Less(a)
}

// Equal reports exact equality.
func (a Epoch) Equal(b Epoch) bool { return a == b }

// Ambiguous reports the half-range case where serial ordering is undefined.
func (a Epoch) Ambiguous(b Epoch) bool {
    return uint32(b-a) == epochHalf
}

config.go

package quorumlog

import "sort"

// VoterID identifies a voter.
type VoterID string

// Config is a weighted voter set. A quorum is a subset whose weight is a
// strict majority of the total weight.
type Config struct {
    Name    string
    Weights map[VoterID]uint64
}

// TotalWeight returns the sum of all voter weights.
func (c Config) TotalWeight() uint64 {
    var total uint64
    for _, w := range c.Weights {
        total += w
    }
    return total
}

// HasQuorum reports whether signers hold a strict weighted majority.
// Using sum > total-sum avoids the 2*sum overflow of the naive check.
func (c Config) HasQuorum(signers map[VoterID]bool) bool {
    var sum uint64
    for v := range signers {
        if w, ok := c.Weights[v]; ok {
            sum += w
        }
    }
    total := c.TotalWeight()
    return sum > total-sum
}

// Membership is either a single configuration or a joint-consensus pair.
// During joint consensus a certificate is valid only if it is a quorum of
// BOTH the old and the new configuration. Check the old config first so a
// failure keeps HasQuorum cheap.
type Membership struct {
    Name  string
    Joint bool
    Old   Config
    New   Config
}

// HasQuorum reports whether signers form a valid quorum for this membership.
func (m Membership) HasQuorum(signers map[VoterID]bool) bool {
    if !m.Old.HasQuorum(signers) {
        return false
    }
    if m.Joint && !m.New.HasQuorum(signers) {
        return false
    }
    return true
}

// ConfigChange installs a membership starting at a log index. Configuration
// is keyed by log index (monotonic, wrap-free) rather than by epoch.
type ConfigChange struct {
    Index      uint64
    Membership Membership
}

// Timeline maps a log index to the membership that governs that index.
type Timeline struct {
    changes []ConfigChange
}

// NewTimeline builds a timeline, sorting changes by log index.
func NewTimeline(changes ...ConfigChange) *Timeline {
    cp := append([]ConfigChange(nil), changes...)
    sort.SliceStable(cp, func(i, j int) bool { return cp[i].Index < cp[j].Index })
    return &Timeline{changes: cp}
}

// At returns the membership active at the given log index. Indices before
// the first known change use the first (genesis) configuration.
func (t *Timeline) At(index uint64) (Membership, bool) {
    if len(t.changes) == 0 {
        return Membership{}, false
    }
    best := t.changes[0].Membership
    found := false
    for _, ch := range t.changes {
        if ch.Index <= index {
            best = ch.Membership
            found = true
        }
    }
    if !found {
        return t.changes[0].Membership, true
    }
    return best, true
}

cert.go

package quorumlog

import (
    "crypto/ed25519"
    "errors"
    "fmt"
    "sort"
)

// ErrNoQuorum is returned when a certificate's valid, unique, known voters
// do not add up to a quorum of the governing membership.
var ErrNoQuorum = errors.New("certificate does not reach quorum")

// Vote is one voter's signed attestation to (Index, Epoch, Value).
type Vote struct {
    Voter VoterID
    Index uint64
    Epoch uint32
    Value string
    Sig   []byte
}

// voteMessage is the canonical byte string that gets signed. Every field
// that the verifier relies on must be covered, otherwise a signature can be
// replayed against a different index/epoch/value.
func voteMessage(v VoterID, index uint64, epoch uint32, value string) []byte {
    return []byte(fmt.Sprintf("ql-vote|%s|%d|%d|%s", v, index, epoch, value))
}

// SignVote produces a signed vote.
func SignVote(priv ed25519.PrivateKey, voter VoterID, index uint64, epoch uint32, value string) Vote {
    return Vote{
        Voter: voter,
        Index: index,
        Epoch: epoch,
        Value: value,
        Sig:   ed25519.Sign(priv, voteMessage(voter, index, epoch, value)),
    }
}

// QC is a quorum certificate: a bag of votes for one (Index, Epoch, Value).
type QC struct {
    Index uint64
    Epoch uint32
    Value string
    Votes []Vote
}

// Verifier holds the trusted public key of every voter.
type Verifier struct {
    Keys map[VoterID]ed25519.PublicKey
}

// NewVerifier builds a Verifier over a trusted key set.
func NewVerifier(keys map[VoterID]ed25519.PublicKey) *Verifier {
    return &Verifier{Keys: keys}
}

// VerifyQC authenticates a certificate against a membership.
//
// Security-relevant rules, each of which is a distinct bug class when
// omitted:
//   - a vote must match the certificate's (Index, Epoch, Value);
//   - a voter is counted at most once (no double-voting);
//   - only voters present in the membership contribute weight;
//   - the signature must cover all of the above.
//
// It returns the sorted set of counted voters even on failure, which the
// caller uses to build minimal counterexamples.
func (vr *Verifier) VerifyQC(qc QC, m Membership) ([]VoterID, error) {
    seen := make(map[VoterID]bool, len(qc.Votes))
    for _, vote := range qc.Votes {
        if vote.Index != qc.Index || vote.Epoch != qc.Epoch || vote.Value != qc.Value {
            continue
        }
        if seen[vote.Voter] {
            continue
        }
        pub, ok := vr.Keys[vote.Voter]
        if !ok {
            continue
        }
        if len(vote.Sig) != ed25519.SignatureSize {
            continue
        }
        if !ed25519.Verify(pub, voteMessage(vote.Voter, vote.Index, vote.Epoch, vote.Value), vote.Sig) {
            continue
        }
        seen[vote.Voter] = true
    }

    signers := make([]VoterID, 0, len(seen))
    for v := range seen {
        signers = append(signers, v)
    }
    sort.Slice(signers, func(i, j int) bool { return signers[i] < signers[j] })

    if !m.HasQuorum(seen) {
        return signers, ErrNoQuorum
    }
    return signers, nil
}

history.go

package quorumlog

import "sort"

// LogEntry is one locally stored entry.
type LogEntry struct {
    Index uint64
    Epoch uint32
    Value string
}

// Rejected records a certificate that failed authentication or quorum.
type Rejected struct {
    QC     QC
    Reason string
}

// Conflict is a minimal counterexample: two authenticated certificates that
// cannot coexist in one linearizable log. Their minimized quorums must
// intersect; every voter in Common double-certified conflicting values.
type Conflict struct {
    Index      uint64
    Epoch      uint32
    Reason     string
    A, B       QC
    SignersA   []VoterID
    SignersB   []VoterID
    Common     []VoterID
    Membership Membership
}

// Committed is one element of the safety witness: a value at an index
// together with the certificate and membership that justify it.
type Committed struct {
    Index      uint64
    Epoch      uint32
    Value      string
    Signers    []VoterID
    Membership Membership
}

// Analysis is the result of diagnosing a history.
type Analysis struct {
    Linearizable bool
    Conflicts    []Conflict
    Rejected     []Rejected

    // Safety witness: the longest contiguous, locally-consistent committed
    // prefix starting at the requested start index.
    Committed []Committed
    HasCommit bool
    CommitEnd uint64

    // Minimum safe repair suffix: the log must be replaced on
    // [RepairStart, RepairEnd]. RepairStart is the first index that is not
    // backed by an authenticated certificate (or that diverges from one).
    // Unsafe lists the indices inside the suffix that are actually missing
    // or divergent; the intermediate indices are known but are still
    // re-replicated because commit requires a contiguous prefix.
    RepairStart uint64
    RepairEnd   uint64
    Unsafe      []uint64
    LogEnd      uint64
}

type verified struct {
    qc      QC
    m       Membership
    signers []VoterID
}

// Analyze authenticates every certificate, rejects non-linearizable
// histories with a minimal counterexample, and otherwise produces a safety
// witness plus the minimum repair suffix.
func Analyze(qcs []QC, local []LogEntry, start uint64, tl *Timeline, vr *Verifier) Analysis {
    var res Analysis
    res.Linearizable = true

    groups := make(map[uint64][]verified)
    for _, qc := range qcs {
        m, ok := tl.At(qc.Index)
        if !ok {
            res.Rejected = append(res.Rejected, Rejected{QC: qc, Reason: "no configuration for index"})
            continue
        }
        signers, err := vr.VerifyQC(qc, m)
        if err != nil {
            res.Rejected = append(res.Rejected, Rejected{QC: qc, Reason: err.Error()})
            continue
        }
        groups[qc.Index] = append(groups[qc.Index], verified{qc: qc, m: m, signers: signers})
    }

    // A single epoch may certify at most one value per index: any two
    // quorums in one epoch intersect, so two different values would force an
    // intersecting voter to equivocate. Different epochs may legitimately
    // name different values -- the greater (wrap-aware) epoch overwrites the
    // earlier one -- so cross-epoch differences are not conflicts. A pair of
    // epochs exactly half a range apart has no defined order and is
    // likewise rejected.
    for index, group := range groups {
        byEpoch := make(map[uint32][]verified)
        for _, g := range group {
            byEpoch[g.qc.Epoch] = append(byEpoch[g.qc.Epoch], g)
        }
        for epoch, eg := range byEpoch {
            var first *verified
            for i := range eg {
                if first == nil {
                    first = &eg[i]
                    continue
                }
                if eg[i].qc.Value != first.qc.Value {
                    res.recordConflict(index, epoch, "two values certified in one epoch", first, &eg[i])
                    break
                }
            }
        }
        for i := range group {
            for j := i + 1; j < len(group); j++ {
                a, b := &group[i], &group[j]
                if a.qc.Value == b.qc.Value {
                    continue
                }
                if Epoch(a.qc.Epoch).Ambiguous(Epoch(b.qc.Epoch)) {
                    res.recordConflict(index, a.qc.Epoch, "ambiguous epoch ordering", a, b)
                }
            }
        }
    }
    if !res.Linearizable {
        sort.Slice(res.Conflicts, func(i, j int) bool {
            if res.Conflicts[i].Index != res.Conflicts[j].Index {
                return res.Conflicts[i].Index < res.Conflicts[j].Index
            }
            return res.Conflicts[i].Epoch < res.Conflicts[j].Epoch
        })
        return res
    }

    localAt := make(map[uint64]LogEntry, len(local))
    var maxLocal uint64
    haveLocal := false
    for _, e := range local {
        localAt[e.Index] = e
        if !haveLocal || e.Index > maxLocal {
            maxLocal = e.Index
            haveLocal = true
        }
    }
    var maxQC uint64
    haveQC := false
    for index := range groups {
        if !haveQC || index > maxQC {
            maxQC = index
            haveQC = true
        }
    }
    logEnd := start
    if haveLocal && maxLocal > logEnd {
        logEnd = maxLocal
    }
    if haveQC && maxQC > logEnd {
        logEnd = maxQC
    }
    res.LogEnd = logEnd

    // Pick the winning certificate per index. The winner is the maximum
    // epoch under wrap-aware ordering; certificates at the same epoch and
    // value are merged (each is a subset that may add fresh signers).
    winners := make(map[uint64]Committed, len(groups))
    for index, group := range groups {
        best := group[0]
        for _, g := range group[1:] {
            if Epoch(g.qc.Epoch).Greater(Epoch(best.qc.Epoch)) {
                best = g
            }
        }
        merged := map[VoterID]bool{}
        for _, g := range group {
            if g.qc.Epoch == best.qc.Epoch && g.qc.Value == best.qc.Value {
                for _, s := range g.signers {
                    merged[s] = true
                }
            }
        }
        signers := make([]VoterID, 0, len(merged))
        for v := range merged {
            signers = append(signers, v)
        }
        sort.Slice(signers, func(i, j int) bool { return signers[i] < signers[j] })
        winners[index] = Committed{
            Index:      index,
            Epoch:      best.qc.Epoch,
            Value:      best.qc.Value,
            Signers:    signers,
            Membership: best.m,
        }
    }

    // Longest contiguous committed prefix that does not diverge locally.
    i := start
    for {
        w, ok := winners[i]
        if !ok {
            break
        }
        if e, present := localAt[i]; present && e.Value != w.Value {
            break
        }
        res.Committed = append(res.Committed, w)
        i++
    }
    if len(res.Committed) > 0 {
        res.HasCommit = true
        res.CommitEnd = res.Committed[len(res.Committed)-1].Index
        res.RepairStart = res.CommitEnd + 1
    } else {
        res.RepairStart = start
    }

    if res.RepairStart <= res.LogEnd {
        res.RepairEnd = res.LogEnd
        for j := res.RepairStart; j <= res.LogEnd; j++ {
            w, ok := winners[j]
            if ok {
                if e, present := localAt[j]; !present || e.Value == w.Value {
                    continue
                }
            }
            res.Unsafe = append(res.Unsafe, j)
        }
    } else {
        res.RepairEnd = res.RepairStart - 1
    }
    return res
}

// recordConflict stores a minimized counterexample.
func (res *Analysis) recordConflict(index uint64, epoch uint32, reason string, a, b *verified) {
    sa := minimalSigners(a.signers, a.m)
    sb := minimalSigners(b.signers, b.m)
    res.Linearizable = false
    res.Conflicts = append(res.Conflicts, Conflict{
        Index:      index,
        Epoch:      epoch,
        Reason:     reason,
        A:          a.qc,
        B:          b.qc,
        SignersA:   sa,
        SignersB:   sb,
        Common:     intersect(sa, sb),
        Membership: a.m,
    })
}

func setOf(vs []VoterID) map[VoterID]bool {
    s := make(map[VoterID]bool, len(vs))
    for _, v := range vs {
        s[v] = true
    }
    return s
}

// minimalSigners greedily removes voters while a quorum remains, yielding a
// minimal quorum subset of the supplied signers.
func minimalSigners(signers []VoterID, m Membership) []VoterID {
    cur := append([]VoterID(nil), signers...)
    sort.Slice(cur, func(i, j int) bool { return cur[i] < cur[j] })
    for i := 0; i < len(cur); {
        trial := make([]VoterID, 0, len(cur)-1)
        trial = append(trial, cur[:i]...)
        trial = append(trial, cur[i+1:]...)
        if m.HasQuorum(setOf(trial)) {
            cur = trial
        } else {
            i++
        }
    }
    return cur
}

func intersect(a, b []VoterID) []VoterID {
    sb := setOf(b)
    var out []VoterID
    for _, v := range a {
        if sb[v] {
            out = append(out, v)
        }
    }
    sort.Slice(out, func(i, j int) bool { return out[i] < out[j] })
    return out
}

package quorumlog

import (
    "crypto/ed25519"
    "fmt"
    "math/rand"
    "testing"
)

func testKeys(n int) (map[VoterID]ed25519.PrivateKey, map[VoterID]ed25519.PublicKey) {
    priv := make(map[VoterID]ed25519.PrivateKey, n)
    pub := make(map[VoterID]ed25519.PublicKey, n)
    for i := 0; i < n; i++ {
        seed := make([]byte, ed25519.SeedSize)
        seed[0] = byte(i + 1)
        seed[1] = 0x5a
        k := ed25519.NewKeyFromSeed(seed)
        id := VoterID(string(rune('A' + i)))
        priv[id] = k
        pub[id] = k.Public().(ed25519.PublicKey)
    }
    return priv, pub
}

func mkQC(t *testing.T, priv map[VoterID]ed25519.PrivateKey, index uint64, epoch uint32, value string, voters ...VoterID) QC {
    t.Helper()
    qc := QC{Index: index, Epoch: epoch, Value: value}
    for _, v := range voters {
        qc.Votes = append(qc.Votes, SignVote(priv[v], v, index, epoch, value))
    }
    return qc
}

func single(voters ...VoterID) Membership {
    w := map[VoterID]uint64{}
    for _, v := range voters {
        w[v] = 1
    }
    return Membership{Name: "single", Old: Config{Name: "single", Weights: w}}
}

func TestJointConsensusRequiresBothConfigs(t *testing.T) {
    priv, pub := testKeys(5)
    old := Config{Name: "old", Weights: map[VoterID]uint64{"A": 1, "B": 1, "C": 1}}
    newc := Config{Name: "new", Weights: map[VoterID]uint64{"C": 1, "D": 1, "E": 1}}
    jm := Membership{Name: "joint", Joint: true, Old: old, New: newc}
    vr := NewVerifier(pub)

    // A+B is an old-config majority but not a new-config majority.
    if _, err := vr.VerifyQC(mkQC(t, priv, 0, 1, "v", "A", "B"), jm); err == nil {
        t.Fatal("A+B accepted without a new-config quorum")
    }
    // D+E is a new-config majority but not an old-config majority.
    if _, err := vr.VerifyQC(mkQC(t, priv, 0, 1, "v", "D", "E"), jm); err == nil {
        t.Fatal("D+E accepted without an old-config quorum")
    }
    // A+B+C+D is a majority of both.
    if _, err := vr.VerifyQC(mkQC(t, priv, 0, 1, "v", "A", "B", "C", "D"), jm); err != nil {
        t.Fatalf("A+B+C+D should be a joint quorum: %v", err)
    }
}

func TestDuplicateAndUnknownVotersDontCount(t *testing.T) {
    priv, pub := testKeys(4) // A,B,C plus an outsider D
    m := single("A", "B", "C")
    vr := NewVerifier(pub)

    // A votes twice; without a second voter this must NOT be a quorum.
    qc := QC{Index: 0, Epoch: 1, Value: "v"}
    qc.Votes = append(qc.Votes, SignVote(priv["A"], "A", 0, 1, "v"))
    qc.Votes = append(qc.Votes, SignVote(priv["A"], "A", 0, 1, "v"))
    if _, err := vr.VerifyQC(qc, m); err == nil {
        t.Fatal("duplicate voter was double-counted")
    }

    // An unknown voter D is not in the membership, so contributes no weight.
    if _, err := vr.VerifyQC(mkQC(t, priv, 0, 1, "v", "A", "D"), m); err == nil {
        t.Fatal("unknown voter contributed weight")
    }

    // A genuine quorum is accepted.
    if _, err := vr.VerifyQC(mkQC(t, priv, 0, 1, "v", "A", "B"), m); err != nil {
        t.Fatalf("A+B should be a quorum: %v", err)
    }
}

func TestEpochWrapWinnerSelection(t *testing.T) {
    priv, pub := testKeys(3)
    m := single("A", "B", "C")
    tl := NewTimeline(ConfigChange{Index: 0, Membership: m})
    vr := NewVerifier(pub)

    // After the counter wraps, epoch 3 is causally newer than 0xFFFFFFF0
    // even though it is numerically smaller. The later epoch overwrites the
    // earlier value, so this is a legal history, not a conflict.
    older := mkQC(t, priv, 7, 0xFFFFFFF0, "old", "A", "B")
    newer := mkQC(t, priv, 7, 3, "new", "A", "B")

    a := Analyze([]QC{older, newer}, nil, 7, tl, vr)
    if !a.Linearizable {
        t.Fatal("cross-epoch overwrite must not be a conflict")
    }
    if len(a.Committed) != 1 {

3.4 A concrete minimal counterexample

Config {A:1, B:1, C:1} (quorum = 2). The history contains, at index 2, epoch 1:

  • QC₁ = value A, signed by A, B
  • QC₂ = value B, signed by B, C

Both are valid certificates (2 of 3). Both minimized quorums have size 2 and intersect at B, so B certifies two different values in one epoch. Analyze returns Linearizable=false, one Conflict{Index:2, Epoch:1, Reason:"two values certified in one epoch", SignersA:[A B], SignersB:[B C], Common:[B]}. This is minimal: dropping any signer from either quorum breaks that quorum, and B is the single intersecting voter. That is enough to reject the history — no repairing can linearize it.

3.5 A concrete repair witness

Certificates exist for indices 0,1,3 in epoch 1; the node locally stores 0..3; index 2's certificate was lost. Analyze returns:

  • witness Committed = [{0,"v0",[A B]},{1,"v1",[A B]}], CommitEnd=1;
  • RepairStart=2, RepairEnd=3, Unsafe=[2], LogEnd=3.

Index 3 is certificate-backed, but it is inside the repair suffix because index 2 blocks contiguous commit; Unsafe (the truly unknown set) is only [2].

4. Why the fix is correct

  1. Only authenticated weight counts. VerifyQC counts a voter once, only if the signature over (voter,index,epoch,value) verifies, and only if the voter is in the governing membership. HasQuorum uses sum > total-sum, so no overflow can manufacture a majority.
  2. The governing membership is the one at the index. Timeline.At makes historical certificates independently checkable, so RC-2 and RC-3 cannot mis-validate.
  3. Same-epoch uniqueness. With a majority (or joint-majority) rule, any two quorums intersect. A single epoch that certified two values at one index therefore contains an intersecting voter that signed both; recordConflict exhibits exactly that intersection.
  4. Wrap-aware survival. For each index the winner is the certificate with the greatest epoch under Epoch.Greater; a half-range pair is rejected as ambiguous rather than silently mis-ordered. This is why 0xFFFFFFF0 loses to 3.
  5. Contiguity. The witness is built only while certificates exist and agree with the local copy, so it is hole-free by construction.
  6. Suffix minimality. The first index failing that test is RepairStart; every earlier prefix is certificate-backed and locally consistent, so no smaller suffix can be necessary, and no larger suffix re-fetches anything that is already provably safe. Unsafe reports the subset that is genuinely missing or divergent.
