  1. Board evidence gate — the PENDING P0 row T-1042 held evidence in reasoning and a detail list; the guard's _is_blank() returns True for any non-string, and created_by was "".   3. Torn events.jsonl (latent) — two records concatenated mid-file. "Parse the last line" passes and masks it; whole-file iteration catches Extra data at col 91. Repaired by inserting exactly one \n at the json.JSONDecoder().raw_decode boundary, then proving that deleting the inserted byte reproduces the original file byte-for-byte.
