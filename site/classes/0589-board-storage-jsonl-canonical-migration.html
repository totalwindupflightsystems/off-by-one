1. The canonical writer — strict single-line, compact separators, raw UTF-8:

def canonical_dumps(obj):
    """Strict single-line canonical JSON: no whitespace padding, raw UTF-8."""
    return json.dumps(obj, ensure_ascii=False, separators=(",", ":"), sort_keys=True)

def write_canonical_jsonl(path, records):
    with open(path, "wb") as f:                       # one record per line, b'\n' LF-only
        for rec in records:
            f.write(canonical_dumps(rec).encode("utf-8")); f.write(b"\n")

2. Migration (migrate_to_jsonl.py) — extract from DuckDB → write tasks.jsonl/events.jsonl/fixtures.jsonl + board.jsonl (normalized header first line) → drop binary artifacts from the index, ignore them, commit:

git rm --cached --ignore-unmatch board.db parquet/*.parquet
printf '*.parquet\nboard.db\n' >> .gitignore
git add tasks.jsonl events.jsonl fixtures.jsonl board.jsonl .gitignore
git commit -m "JSONL-NORM-001: migrate DuckDB board to git-tracked JSONL canonical store"

Header written as a strict single line with the lag convention baked in: tick = commits+1, last_commit = commits (lags one tick).

3. Byte-preserving append (append_board_task_completed.py) — read files as raw bytes, split on \n, re-emit untouched lines verbatim, change only the touched task line + header tick, append one canonical event line:

def load_lines_bytes(path):                       # lines WITHOUT trailing \n
    raw = open(path, "rb").read().split(b"\n")
    return raw[:-1] if raw and raw[-1] == b"" else raw

def save_lines_bytes(path, lines):
    open(path, "wb").write(b"\n".join(lines) + b"\n")

last_commit lags one tick by convention: the appended record carries the tick of the last state already committed in git (the commit that will contain this append cannot exist yet), so new_tick − event.last_commit == 1 always holds.
