SSA Exception-Edge Register Spill Minimization — Diagnosis and Verified Fix

Problem class: python-20261016-ssa-exception-edge-register-spill-minimization Environment: Python 3.11+ (tested on 3.12/3.14) Deliverable: a self-contained allocator that emits an allocation plus a machine-checkable certificate, and an independent verifier.

Note on the input: problem.json has an empty error_message/stack_trace/context, so this is not a crash to localize. The "defect" is the absence of a legal, cost-optimal, verifiable allocator for this problem class. The analysis below names the specific modeling traps that make naive allocators wrong; the fix is a complete implementation that avoids all of them and ships its own verifier.

1. Formal model

An instance is an SSA CFG with weighted edges (normal / exception). Lowered to the data the allocator needs:

field meaning legality constraint
reg_classes[cls] = {count, caller_saved} physical registers per class each class has a fixed budget
values[{id, cls, spill_cost}] SSA live ranges exactly one home each
interference simultaneously-live pairs same-class interfering values must get different registers
phi_edges[{from, to, weight}] phi operand → result on an incoming edge locations must match or a copy is placed on that edge
live_across_calls[{value, call, weight}] values live across a call (incl. exception edges) must be callee-saved, spilled, or have an explicit save/reload

Objective (weighted dynamic cost):

cost = Σ spill_cost[v]                       (v spilled)
     + Σ save_restore_cost · weight          (caller-saved & live across call)
     + Σ phi_edge_cost(loc[a], loc[b], w)    (locations differ)

phi_edge_cost is w·move_cost between two registers, w·spill_move_cost if exactly one side is spilled, and w·2·spill_move_cost if both sides are spilled.

2. Root-cause analysis

  1. Collapsing all spill slots into one token. The single most damaging bug (I hit it in the first draft): if loc[a] == loc[b] == "SPILL" is treated as "same place", the solver returns 0 for a phi edge between two spilled live ranges and the certificate omits the copy. Two live ranges live in distinct stack slots, so a phi edge still needs a store/load. Fix: same_place(a,b) := (a == b and a != SPILL). Only the same physical register is a shared location.

  2. Ignoring exceptional edges / call clobbers. A value live across a call while in a caller-saved register is destroyed. Allocators that reason only over normal CFG edges drop handler live-ins. Exception edges must feed the same liveness/call-clobber analysis as fallthrough edges.

  3. Register classes. Interference and capacity are per class; cross-class values must not be forced apart, and same-class interference must be strictly honored. Register names are class-prefixed (int0, flt1) so the two spaces never alias.

  4. Loop weights. Cost must be dynamic. A def/use in a 100× block is 100× more expensive to spill than one in a cold block; phi copies and call saves carry their edge/block execution weights. Static counts spill hot values and lose money.

  5. Phi-edge legality vs. coalescing. A phi operand and result must share a location or get a copy on the incoming edge. Coalescing removes copies but raises interference pressure. That trade-off — not register assignment alone — is the optimization.

  6. NP-hardness + the need to verify. Interference-aware allocation with coalescing/spilling is graph-coloring-hard. The solver therefore uses a greedy incumbent plus branch-and-bound with an admissible lower bound, with a node/time budget. Because a minimizer's own cost is not evidence, an independent verifier re-derives every constraint and recomputes the objective from the allocation alone.

3. The fix

Save as ssa_alloc.py.

#!/usr/bin/env python3
"""
ssa_alloc.py -- legal phi-edge splits and spills for SSA CFGs with
exceptional edges, register classes, call clobbers and loop weights.

Commands
    python3 ssa_alloc.py solve  INSTANCE.json [-o CERT.json]
    python3 ssa_alloc.py verify INSTANCE.json CERT.json
    python3 ssa_alloc.py selftest

Normalized instance
    reg_classes      : { cls: {count, caller_saved:[reg indices]} }
    values           : [ {id, cls, spill_cost} ]
    interference     : [ [id, id], ... ]            (must differ if same class)
    phi_edges        : [ {from, to, weight} ]       (copy if locations differ)
    live_across_calls: [ {value, call, weight} ]    (must survive the call)

CFG instance (front-end): has "blocks" and "instructions" instead of the
lowered fields; see from_cfg() for the exact schema.

Certificate: allocation + phi_copies + call_saves + spilled + cost.
verify() independently re-derives every legality condition and the objective.
"""
from __future__ import annotations

import json
import sys
import time
from collections import defaultdict

SPILL = "SPILL"


class Instance:
    def __init__(self, d):
        self.move_cost = d.get("move_cost", 1)
        self.spill_move_cost = d.get("spill_move_cost", 2)
        self.save_restore_cost = d.get("save_restore_cost", 2)
        self.regs, self.caller_saved = {}, {}
        for c, s in d["reg_classes"].items():
            n = s["count"]
            self.regs[c] = ["%s%d" % (c, i) for i in range(n)]
            self.caller_saved[c] = {"%s%d" % (c, i) for i in s.get("caller_saved", [])}
        self.values, self.cls, self.spill_cost = [], {}, {}
        for v in d["values"]:
            self.values.append(v["id"])
            self.cls[v["id"]] = v["cls"]
            self.spill_cost[v["id"]] = v.get("spill_cost", 1)
        self.adj = {v: set() for v in self.values}
        for a, b in d.get("interference", []):
            self.adj[a].add(b)
            self.adj[b].add(a)
        self.phi, self.phi_adj = [], defaultdict(list)
        for e in d.get("phi_edges", []):
            a, b, w = e["from"], e["to"], e["weight"]
            self.phi.append((a, b, w))
            self.phi_adj[a].append((b, w))
            if b != a:
                self.phi_adj[b].append((a, w))
        self.live_calls = {v: [] for v in self.values}
        for e in d.get("live_across_calls", []):
            self.live_calls[e["value"]].append((e.get("call", "?"), e["weight"]))

    @staticmethod
    def same_place(a, b):
        # Each live range owns a distinct spill slot, so SPILL == SPILL still
        # needs a copy; only the same physical register is a shared location.
        return a == b and a != SPILL

    def fixed_cost(self, v, loc):
        if loc == SPILL:
            return float(self.spill_cost[v])
        if loc in self.caller_saved[self.cls[v]] and self.live_calls[v]:
            return float(self.save_restore_cost) * sum(w for _, w in self.live_calls[v])
        return 0.0

    def phi_cost(self, a, b, w):
        if self.same_place(a, b):
            return 0.0
        if a == SPILL and b == SPILL:
            return float(w) * 2 * self.spill_move_cost
        if a == SPILL or b == SPILL:
            return float(w) * self.spill_move_cost
        return float(w) * self.move_cost

    def options(self, v):
        return list(self.regs[self.cls[v]]) + [SPILL]

    def conflicts(self, v, loc, assigned):
        return loc != SPILL and any(assigned.get(u) == loc for u in self.adj[v])


def eval_cost(inst, loc):
    total = sum(inst.fixed_cost(v, loc[v]) for v in inst.values)
    return total + sum(inst.phi_cost(loc[a], loc[b], w) for a, b, w in inst.phi)


def _greedy(inst, order):
    assigned = {}
    for v in order:
        best = None
        for loc in inst.options(v):
            if inst.conflicts(v, loc, assigned):
                continue
            c = inst.fixed_cost(v, loc)
            for u, w in inst.phi_adj[v]:
                if u in assigned:
                    c += inst.phi_cost(loc, assigned[u], w)
            if best is None or c < best[0]:
                best = (c, loc)
        assigned[v] = best[1] if best else SPILL
    return assigned


class _Stop(Exception):
    pass


def solve(inst, max_nodes=2_000_000, time_limit=20.0):
    """Branch and bound.  Returns (allocation, proven_optimal)."""
    order = sorted(inst.values, key=lambda v: (-len(inst.adj[v]),
                                               -len(inst.phi_adj[v]),
                                               -inst.spill_cost[v]))
    n = len(order)
    if n + 50 > sys.getrecursionlimit():
        sys.setrecursionlimit(n + 100)
    seed = _greedy(inst, order)
    best = {"loc": seed, "cost": eval_cost(inst, seed)}
    state, t0 = {"nodes": 0}, time.time()

    def lower_bound(idx, assigned, cur):
        lb = cur
        for i in range(idx, n):
            v = order[i]
            mn = inst.spill_cost[v]
            for loc in inst.regs[inst.cls[v]]:
                if not inst.conflicts(v, loc, assigned):
                    mn = min(mn, inst.fixed_cost(v, loc))
            lb += mn
        return lb

    def rec(idx, assigned, cur):
        state["nodes"] += 1
        if state["nodes"] > max_nodes or time.time() - t0 > time_limit:
            raise _Stop
        if idx == n:
            if cur < best["cost"] - 1e-12:
                best["cost"], best["loc"] = cur, dict(assigned)
            return
        if lower_bound(idx, assigned, cur) >= best["cost"] - 1e-12:
            return
        v = order[idx]
        choices = []
        for loc in inst.options(v):
            if inst.conflicts(v, loc, assigned):
                continue
            add = inst.fixed_cost(v, loc)
            for u, w in inst.phi_adj[v]:
                if u in assigned:
                    add += inst.phi_cost(loc, assigned[u], w)
            choices.append((add, loc))
        for add, loc in sorted(choices):
            assigned[v] = loc
            rec(idx + 1, assigned, cur + add)
            del assigned[v]

    try:
        rec(0, {}, 0.0)
        return dict(best["loc"]), True
    except _Stop:
        return dict(best["loc"]), False


def make_certificate(inst, loc, optimal):
    phi_copies = [
        {"from": a, "to": b, "weight": w, "cost": inst.phi_cost(loc[a], loc[b], w)}
        for a, b, w in inst.phi if not inst.same_place(loc[a], loc[b])
    ]
    call_saves = []
    for v in inst.values:
        l = loc[v]
        if l != SPILL and l in inst.caller_saved[inst.cls[v]] and inst.live_calls[v]:
            for call, w in inst.live_calls[v]:
                call_saves.append({"value": v, "call": call, "weight": w,
                                   "register": l,
                                   "cost": inst.save_restore_cost * w})
    spilled = [v for v in inst.values if loc[v] == SPILL]
    s = sum(inst.spill_cost[v] for v in spilled)
    p = sum(e["cost"] for e in phi_copies)
    r = sum(e["cost"] for e in call_saves)
    return {"allocation": dict(loc), "spilled": spilled, "phi_copies": phi_copies,
            "call_saves": call_saves,
            "cost": {"spill": s, "phi": p, "save_restore": r, "total": s + p + r},
            "proven_optimal": bool(optimal)}


def verify(inst, cert):
    """Return (ok, errors, recomputed_total).  Trusts only the allocation."""
    errors = []
    alloc = cert.get("allocation")
    if not isinstance(alloc, dict):
        return False, ["certificate has no 'allocation' object"], None

    # 1. totality and register-class legality
    for v in inst.values:
        if v not in alloc:
            errors.append("missing allocation for value %r" % v)
    for v in alloc:
        if v not in inst.cls:
            errors.append("allocation mentions unknown value %r" % v)
        elif alloc[v] != SPILL and alloc[v] not in inst.regs[inst.cls[v]]:
            errors.append("value %r assigned %r which is not a %r register"
                          % (v, alloc[v], inst.cls[v]))
    if errors:
        return False, errors, None

    # 2. interference / register capacity
    for a in inst.values:
        for b in inst.adj[a]:
            if a < b and alloc[a] != SPILL and alloc[a] == alloc[b]:
                errors.append("interference violation: %r and %r both in %r"
                              % (a, b, alloc[a]))

    # 3. phi-edge splits: present iff locations differ, no extras/duplicates
    known = {(a, b) for a, b, _ in inst.phi}
    provided = defaultdict(list)
    for e in cert.get("phi_copies", []):
        key = (e["from"], e["to"])
        if key not in known:
            errors.append("phi copy for unknown edge %r -> %r" % key)
        provided[key].append(e)
    for key, entries in provided.items():
        if len(entries) > 1:
            errors.append("duplicate phi copies for edge %r -> %r" % key)
    for a, b, w in inst.phi:
        need = not inst.same_place(alloc[a], alloc[b])
        entries = provided.get((a, b), [])
        if need and not entries:
            errors.append("missing phi-edge copy for %r -> %r" % (a, b))
        if not need and entries:
            errors.append("spurious phi-edge copy for %r -> %r" % (a, b))
        if need and entries:
            want = inst.phi_cost(alloc[a], alloc[b], w)
            if abs(entries[0].get("cost", -1e18) - want) > 1e-6:
                errors.append("phi copy %r -> %r cost %r != %r"
                              % (a, b, entries[0].get("cost"), want))

    # 4. exception-handler / live-across-call preservation
    for v in inst.values:
        l = alloc[v]
        if l != SPILL and l in inst.caller_saved[inst.cls[v]] and inst.live_calls[v]:
            for call, _ in inst.live_calls[v]:
                if not any(s.get("value") == v and s.get("call") == call
                           for s in cert.get("call_saves", [])):
                    errors.append("live-across-call value %r in caller-saved %r "
                                  "has no save/reload on call %r" % (v, l, call))
    needed = {(v, call) for v in inst.values for call, _ in inst.live_calls[v]}
    for s in cert.get("call_saves", []):
        v, call = s.get("value"), s.get("call")
        if (v, call) not in needed:
            errors.append("spurious call save for %r on %r" % (v, call))
        elif alloc.get(v) not in inst.caller_saved.get(inst.cls.get(v, ""), set()):
            errors.append("call save for %r but %r is not caller-saved"
                          % (v, alloc.get(v)))
        elif s.get("register") != alloc.get(v):
            errors.append("call save register %r != allocation %r for %r"
                          % (s.get("register"), alloc.get(v), v))

    # 5. recompute objective and compare to the claim
    total = eval_cost(inst, alloc)
    claimed = cert.get("cost", {}).get("total")
    if claimed is not None and abs(float(claimed) - total) > 1e-6:
        errors.append("claimed cost %r != recomputed %r" % (claimed, total))

    # 6. spilled list must match
    if "spilled" in cert and set(cert["spilled"]) != {
            v for v in inst.values if alloc[v] == SPILL}:
        errors.append("'spilled' list does not match the allocation")
    return (not errors), errors, total

def from_cfg(cfg):
    """Lower an SSA CFG to a normalized instance.

    CFG schema:
      reg_classes   : same as normalized
      value_classes : {value_id: class}
      blocks        : {bid: {weight, succ: [[succ, kind, weight], ...]}}
      instructions  : [{block, def, uses, is_call, is_phi, phi_operands}]
                      phi_operands is [[pred_block, value], ...]

    Interference = def vs live-out, plus each phi result vs values live at
    block entry.  Spill cost is the sum of dynamic weights of the value's
    def/uses; phi operands are charged the edge weight.  live_across_calls
    records every value live immediately after a call.
    """
    blocks, instrs = cfg["blocks"], cfg["instructions"]
    succ = defaultdict(list)
    for b, spec in blocks.items():
        for s, kind, w in spec.get("succ", []):
            succ[b].append((s, kind, w))
    by_block = defaultdict(list)
    for i, ins in enumerate(instrs):
        ins = dict(ins)
        ins.setdefault("id", "%s#%d" % (ins["block"], i))
        by_block[ins["block"]].append(ins)

    def phidefs(b):
        return {i["def"] for i in by_block[b] if i.get("is_phi") and i.get("def")}

    def upward(b):
        defined, out = set(phidefs(b)), set()
        for i in by_block[b]:
            if i.get("is_phi"):
                continue
            out.update(u for u in i.get("uses", []) if u not in defined)
            if i.get("def"):
                defined.add(i["def"])
        return out

    phi_use = defaultdict(set)
    for b in blocks:
        for i in by_block[b]:
            if i.get("is_phi"):
                for p, val in i.get("phi_operands", []):
                    phi_use[p].add(val)

    live_in = {b: set() for b in blocks}
    live_out = {b: set() for b in blocks}
    changed = True
    while changed:
        changed = False
        for b in blocks:
            out = set(phi_use[b])
            for s, _, _ in succ[b]:
                out |= live_in[s]
            inn = upward(b) | (out - {i["def"] for i in by_block[b] if i.get("def")})
            if out != live_out[b] or inn != live_in[b]:
                live_out[b], live_in[b] = out, inn
                changed = True

    adj, spill, live_calls = defaultdict(set), defaultdict(float), []
    for b in blocks:
        w_b = blocks[b].get("weight", 1)
        for i in by_block[b]:
            if i.get("def"):
                spill[i["def"]] += w_b
            for u in i.get("uses", []):
                spill[u] += w_b
            if i.get("is_phi"):
                for p, val in i.get("phi_operands", []):
                    spill[val] += sum(x[2] for x in succ[p] if x[0] == b) or 1
        live = set(live_out[b])
        for i in reversed(by_block[b]):
            if i.get("is_phi"):
                continue
            if i.get("is_call"):
                for v in live:
                    if v != i.get("def"):
                        live_calls.append({"value": v, "call": i["id"], "weight": w_b})
            d = i.get("def")
            if d is not None:
                for x in live:
                    if x != d:
                        adj[d].add(x)
                        adj[x].add(d)
                live.discard(d)
            live.update(i.get("uses", []))
        entry = set(live_in[b]) | phidefs(b)
        for d in phidefs(b):
            for x in entry:
                if x != d:
                    adj[d].add(x)
                    adj[x].add(d)

    classes = dict(cfg.get("value_classes", {}))
    values = sorted(set(spill) | set(classes))
    phi_edges = []
    for b in blocks:
        for i in by_block[b]:
            if i.get("is_phi") and i.get("def"):
                for p, val in i.get("phi_operands", []):
                    w = sum(x[2] for x in succ[p] if x[0] == b) or 1
                    phi_edges.append({"from": val, "to": i["def"], "weight": w})
    return Instance({
        "reg_classes": cfg["reg_classes"],
        "move_cost": cfg.get("move_cost", 1),
        "spill_move_cost": cfg.get("spill_move_cost", 2),
        "save_restore_cost": cfg.get("save_restore_cost", 2),
        "values": [{"id": v, "cls": classes.get(v, cfg.get("default_class", "int")),
                    "spill_cost": max(spill.get(v, 0.0), 1.0)} for v in values],
        "interference": sorted({tuple(sorted((a, b)))
                                for a in adj for b in adj[a] if a < b}),
        "phi_edges": phi_edges,
        "live_across_calls": live_calls,
    })

def _load(path):
    with open(path) as fh:
        return json.load(fh)


def _instance(raw):
    return from_cfg(raw) if "blocks" in raw else Instance(raw)


def main(argv):
    if len(argv) < 2:
        print(__doc__)
        return 2
    cmd = argv[1]
    if cmd == "solve":
        rest = argv[2:]
        out_path = None
        if "-o" in rest:
            i = rest.index("-o")
            out_path = rest[i + 1]
            rest = rest[:i] + rest[i + 2:]
        inst = _instance(_load(rest[0]))
        loc, opt = solve(inst)
        cert = make_certificate(inst, loc, opt)
        ok, errors, total = verify(inst, cert)
        if not ok:
            print("internal error: %s" % "; ".join(errors), file=sys.stderr)
            return 2
        text = json.dumps(cert, indent=2, sort_keys=True)
        if out_path:
            with open(out_path, "w") as fh:
                fh.write(text + "\n")
        print(text)
        print("VERIFIED total_cost=%s proven_optimal=%s" % (total, opt),
              file=sys.stderr)
        return 0
    if cmd == "verify":
        inst = _instance(_load(argv[2]))
        ok, errors, total = verify(inst, _load(argv[3]))
        if ok:
            print("PASS: certificate valid; recomputed weighted cost = %s" % total)
            return 0
        print("FAIL: %d problem(s)" % len(errors))
        for e in errors:
            print("  - " + e)
        return 1
    if cmd == "selftest":
        import itertools
        import random
        random.seed(0)
        for _ in range(200):
            ids = ["v%d" % i for i in range(random.randint(2, 6))]
            nregs = random.randint(1, 3)
            d = {"reg_classes": {"int": {"count": nregs,
                                         "caller_saved": [nregs - 1]}},
                 "move_cost": 1, "spill_move_cost": 2, "save_restore_cost": 2,
                 "values": [{"id": v, "cls": "int",
                             "spill_cost": random.randint(1, 20)} for v in ids],
                 "interference": [[a, b] for a, b in itertools.combinations(ids, 2)
                                  if random.random() < .35],
                 "phi_edges": [{"from": a, "to": b, "weight": random.choice([1, 5, 20])}
                               for a, b in itertools.combinations(ids, 2)
                               if random.random() < .25],
                 "live_across_calls": [{"value": v, "call": "c", "weight": 3}
                                       for v in ids if random.random() < .3]}
            inst = Instance(d)
            loc, opt = solve(inst)
            brute = min(eval_cost(inst, dict(zip(inst.values, c)))
                        for c in itertools.product(*[inst.options(v) for v in inst.values])
                        if not any(inst.conflicts(v, dict(zip(inst.values, c))[v],
                                                  dict(zip(inst.values, c)))
                                   for v in inst.values))
            assert opt and abs(eval_cost(inst, loc) - brute) < 1e-9
            ok, errs, _ = verify(inst, make_certificate(inst, loc, opt))
            assert ok, errs
        print("selftest OK: 200 random instances, solver == exhaustive optimum")
        return 0
    print("unknown command %r" % cmd, file=sys.stderr)
    return 2


if __name__ == "__main__":
    sys.exit(main(sys.argv))

5. Usage summary

# normalized or CFG input
python3 ssa_alloc.py solve  INSTANCE.json -o CERT.json
python3 ssa_alloc.py verify INSTANCE.json CERT.json
python3 ssa_alloc.py selftest

The certificate contains allocation, spilled, phi_copies, call_saves, the cost breakdown, and proven_optimal. verify returns non-zero and lists every violation for any certificate that shares a register across an interfering pair, uses a register from the wrong class, omits/duplicates/forges a phi copy, leaves a handler value clobberable, or reports a cost that does not match the independently recomputed weighted dynamic cost.
