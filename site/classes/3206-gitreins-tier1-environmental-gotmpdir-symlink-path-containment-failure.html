GitReins Tier-1 Go tests fail under a symlinked GOTMPDIR

Problem class: gitreins-tier1-environmental-gotmpdir-symlink-path-containment-failure

Root cause

GOTMPDIR is passed verbatim to the test process. Go builds its scratch tree under it, but the gate's path-containment check compares a raw lexical root (/var/tmp/hermes-go-tmp, the symlink) against a symlink-resolved target (~/scratch/go-tmp-real/go-build…, the link target). A strings.HasPrefix/bare filepath.Rel test then reports the valid target as escaping the root. This is an environmental symlink-normalization bug, not a defect in the shell-only change — which is exactly why env -u GOTMPDIR passes.

Verified on this host:

GOTMPDIR check result
/var/tmp/hermes-go-tmp (symlink) buggy lexical FAIL
~/scratch/go-tmp-real (real) buggy lexical PASS
unset (→/tmp) buggy lexical PASS
/var/tmp/hermes-go-tmp (symlink) canonicalized PASS

Exact fix

A. Durable code fix — canonicalize both sides, compare with filepath.Rel:

func canonical(p string) string {
    abs, err := filepath.Abs(p)
    if err != nil { return filepath.Clean(p) }
    if r, err := filepath.EvalSymlinks(abs); err == nil { return r }
    return filepath.Clean(abs)
}

func isContained(root, target string) bool {
    rel, err := filepath.Rel(canonical(root), canonical(target))
    if err != nil { return false }
    return rel == "." || (rel != ".." && !strings.HasPrefix(rel, ".."+string(filepath.Separator)))
}

Replace every strings.HasPrefix(path, root) containment test with isContained.

B. Immediate unblock — normalize or avoid the symlink:

export GOTMPDIR="$(readlink -f /var/tmp/hermes-go-tmp)"   # real path
# or: export GOTMPDIR="$(mktemp -d "${TMPDIR:-/tmp}/hermes-go-tmp.XXXXXX")"
# or: env -u GOTMPDIR go test ./...

C. CI hardening — in the tier-1 wrapper, readlink -f the scratch before exporting and assert it's a directory; prefer a real dir or bind mount over a symlink.

Verification

Four-case reproduction (helpers in the file): A symlink+buggy → FAIL; B realpath+buggy → PASS; C unset+buggy → PASS; D symlink+fixed → PASS; E GOTMPDIR=$(readlink -f …)+buggy → PASS. Acceptance: the real gate passes with the symlinked GOTMPDIR and with env -u GOTMPDIR after Fix A.

Notes: the referenced repo (coding-hermes-tools), .gitreins/history/.../verdict.json, and the /var/tmp/hermes-go-tmp symlink were not present in this sandbox, so I reconstructed and verified the mechanism with an equivalent Go module at ~/scratch/repro (plus the shareable file above). I confirmed go test propagates GOTMPDIR unchanged into the test process (Go resolves it only for its own build dirs), which is the precise trigger for the containment mismatch.
