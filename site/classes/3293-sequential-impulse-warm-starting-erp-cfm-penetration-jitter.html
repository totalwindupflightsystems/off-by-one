Sequential Impulse + Warm Starting + ERP/CFM: Penetration/Jitter Fix

Root-cause analysis

The instability comes from three compounding mistakes:

  1. SAT axis selection is wrong.
    A box-box routine that only tests faces pointing toward the other box and keeps the smallest positive overlap can choose a non-minimum axis. Two boxes that merely touch can report a large overlap on a perpendicular axis. Fix: test all 15 axes (3 A faces, 3 B faces, 9 edge cross-products). For every axis compute
    depth = hA(n) + hB(n) - |n·(cB-cA)|.
    If any axis has depth <= 0, the pair is separated and there is no contact.

  2. No persistent manifold / no warm starting.
    Recreating contacts every frame and starting each contact with lambda = 0 makes a stack pump energy. Fix: cache manifold points and carry accumulated normal/friction impulses forward. Match by feature key first, then by nearest point with dot(n_old, n_new) > 0.9.

  3. Baumgarte inside the velocity solver injects kinetic energy.
    A velocity bias v_n += -erp * penetration / dt turns position error into real velocity, so deep penetration “pops” and adds energy. Fix: use split impulse. The real velocity solver uses bias = 0; a separate pseudo-velocity pass applies erp * max(pen - slop, 0) / dt and only the pseudo-velocities move positions. Real velocities and kinetic energy are untouched.

The complete verified solver is in ~/solver.js (Node 20, no dependencies). Run it with:

node ~/solver.js

Exact fix

1. Correct 15-axis SAT + clipping

// 3 A faces
for (let i = 0; i < 3; i++) {
  const axis = A.R[i];
  const dd = V.dot(axis, d);
  const depth = hProjection(A, axis) + hProjection(B, axis) - Math.abs(dd);
  if (depth <= 0) return null; // separated
  if (depth < minDepth - 1e-12) {
    minDepth = depth;
    const contactNormal = dd >= 0 ? axis : V.mul(axis, -1);
    const signRef = dd >= 0 ? 1 : -1;
    best = { type: 'face', depth, contactNormal, refBody: A,
             refFace: { i, sign: signRef } };
  }
}
// 3 B faces
for (let i = 0; i < 3; i++) {
  const axis = B.R[i];
  const dd = V.dot(axis, d);
  const depth = hProjection(A, axis) + hProjection(B, axis) - Math.abs(dd);
  if (depth <= 0) return null;
  if (depth < minDepth - 1e-12) {
    minDepth = depth;
    const contactNormal = dd >= 0 ? axis : V.mul(axis, -1);
    const signRef = dd >= 0 ? -1 : 1;
    best = { type: 'face', depth, contactNormal, refBody: B,
             refFace: { i, sign: signRef } };
  }
}
// 9 edge-edge axes
for (const eA of edgesA) {
  for (const eB of edgesB) {
    const cross = V.cross(eA.dir, eB.dir);
    if (V.len(cross) < 1e-6) continue;
    const n = V.norm(cross);
    const dd = V.dot(n, d);
    const depth = hProjection(A, n) + hProjection(B, n) - Math.abs(dd);
    if (depth <= 0) return null;
    // ... choose min depth, then clip face or use closest edge points
  }
}

Face contacts are generated by clipping the incident face polygon against the reference face side planes. Edge contacts use the closest points of the two supporting edges.

2. Persistent warm-started impulses

// cache key for a body pair, e.g. "12:15"
const oldList = this.cache.get(pair.key) || [];
for (const c of pair.contacts) {
  let old = null, bestScore = -Infinity;
  for (const o of oldList) {
    if (V.dot(c.n, o.n) < 0.9) continue;
    let score = -V.len(V.sub(c.p, o.p));
    if (c.key === o.key) score += 1e6;
    if (score > bestScore) { bestScore = score; old = o; }
  }
  if (old && (c.key === old.key || V.len(V.sub(c.p, old.p)) < 0.05)) {
    c.lambdaN = old.lambdaN || 0;
    // rotate old friction impulse into the new tangent basis
    const P = V.add(V.mul(old.t1, old.lambdaT1 || 0),
                    V.mul(old.t2, old.lambdaT2 || 0));
    const [t1, t2] = tangentBasis(c.n);
    c.t1 = t1; c.t2 = t2;
    c.lambdaT1 = V.dot(P, t1);
    c.lambdaT2 = V.dot(P, t2);
  } else {
    const [t1, t2] = tangentBasis(c.n);
    c.t1 = t1; c.t2 = t2;
    c.lambdaN = c.lambdaT1 = c.lambdaT2 = 0;
  }
}

3. Split-impulse Baumgarte/CFM

Real velocity solver has no penetration bias:

c.bias = 0; // no Baumgarte in the real velocity solver
c.invKn = 1 / (c.Kn + this.cfm);

Separate position pass:

solvePositions() {
  for (const b of this.bodies) { b.pv = [0,0,0]; b.pw = [0,0,0]; }
  for (const pl of this.planes) { pl.pv = [0,0,0]; pl.pw = [0,0,0]; }

  for (let iter = 0; iter < 4; iter++) {
    for (const c of this.contacts) {
      const v = relativePseudoVelocity(c.a, c.b, c.rA, c.rB);
      const vn = V.dot(v, c.n);
      const dLambda = (c.posBias - vn) / (c.Kn + this.cfm);
      const old = c.lambdaP;
      const nl = Math.max(old + dLambda, 0);
      c.lambdaP = nl;
      if (nl !== old)
        applyContactImpulsePseudo(c.a, c.b, c.rA, c.rB,
                                  V.mul(c.n, nl - old));
    }
  }
  // only pseudo-velocities move the bodies
  for (const b of this.bodies) {
    b.c = V.add(b.c, V.mul(b.pv, this.dt));
    b.q = qIntegrate(b.q, b.pw, this.dt);
    b.updateR();
  }
}

posBias is set during contact preparation:

c.bias = 0;
c.posBias = this.erp * Math.max(c.pen - this.slop, 0) / this.dt;
c.lambdaP = 0;

Tuning notes

  • erp = 0.5 for the split-impulse position pass.
  • cfm = 1e-4 regularises the normal and friction solves.
  • iterations = 64 for the sequential velocity solver makes the pyramid settle to max |dKE| ≈ 3.4e-7 J.
  • slop = 0.005 m allows a small penetration band; the stack settles at maxPen ≈ 0.001 m.
  • Friction uses a 2×2 tangent effective-mass solve and a circular cone clamp |lambda_t| <= mu * lambda_n.
