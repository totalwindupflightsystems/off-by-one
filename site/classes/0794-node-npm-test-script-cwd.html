Answer

Root cause: The root package.json had no test script (npm test → "Missing script"). Running npx vitest run directly from the repo root produced a false-red 249-fail suite: vitest resolves the @/ alias relative to the config/root setting, so with cwd at the repo root the alias points outside tests/ and every import using it fails.

Fix: Make npm test run vitest with tests/ as the working directory, where the alias resolves correctly.

1. Root package.json — add the test script:

{
  "name": "fed-019",
  "private": true,
  "scripts": {
    "test": "cd tests && npx vitest run"
  }
}
