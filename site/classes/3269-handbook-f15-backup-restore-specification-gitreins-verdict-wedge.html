Summary of the diagnosis

Incident (real board row P5G-07 in coding-hermes/code-factory, F15 backup/restore spec): gitreins task complete P5G-07 flipped the task to complete, then Tier‑2 wedged with no verdict.json, forcing a stop/preserve/push/defer recovery.

Root cause (two compounding defects):

  1. Self-referential poll with no aggregate deadline. The Tier‑2 judge model runs sleep 29; grep 'EXIT=' /tmp/selftest.log, but tests/selftest.sh never emitted EXIT=. Each poll fits inside the 30 s command_timeout in engine/command_hygiene.py:run_bounded (invoked from engine/evaluator.py:2253), so it is never refused and the loop is bounded only by max_iterations — the judge burns its whole budget (30 m 28 s observed, ~2 s CPU, killed).
  2. Complete-before-verdict ordering. gitreins/cli.py:2461 calls tm.complete() before judge.evaluate_task() (:2471) and _persist_result() (:2489), so a wedge leaves a permanently complete task with no artifact. engine/persist.py:1037-1059 stamps commit = rev-parse HEAD, so the missing verdict is exactly the “no commit-matching verdict.json” condition.

Exact fix - Landed durable fix 956b684: tests/selftest.sh routes exits through finish()/selftest_exit_trap to always print EXIT=0|1 (diff included). Executed and confirmed: EXIT=1 is now emitted (the single selftest failure is an unrelated disk-floor check: 5.5 GB < 5.9 GB). - Recommended GitReins hardening: aggregate wall-clock deadline on the tool loop; persist verdict before flipping complete; enforce verdict.commit == HEAD. - Recovery runbook (copy‑paste, all boardctl commands tested live): back up .gitreins/history + refs/gitreins/history + board → stop only the exact evaluator by lease/PID/SHA (never broad pkill) → tag/push 48c0d66 → defer the row with an explicit verdict=none:… trace → rejudge detached at the exact SHA → close only when verdict.commit == 48c0d66.

Verification included in the doc: sentinel emission proof, 956b684 ancestry at HEAD, the recorded 751 s self-terminating P5G-34 run that wrote .gitreins/history/2026-11-12/ef3553a3/verdict.json, commit-match assertion, and boardctl doctor/validate deferred-state checks.
