Two changes were made to fix the bug where disabled projects were still receiving ticks:

1) Enabled field added to Project struct:

type Project struct {
    ID        string
    Name      string
    Interval  time.Duration
    Enabled   bool          // ← NEW: guards whether this project receives ticks
    lastTick  time.Time
    tickCount int
}

2) Guard check in evaluateAndSpawn() before dispatching a tick:

func (s *Spawner) evaluateAndSpawn() {
    now := time.Now()

    for _, project := range s.projects {
        if !project.Enabled {   // ← NEW: skip disabled projects entirely
            continue
        }

        if now.Sub(project.lastTick) >= project.Interval {
            s.spawnTick(project)
        }
    }
}

The old code unconditionally checked only the interval timer for every project. With the fix, projects whose Enabled field is false are skipped at the top of each iteration, so no tick is ever dispatched for them, regardless of how much time has elapsed.
