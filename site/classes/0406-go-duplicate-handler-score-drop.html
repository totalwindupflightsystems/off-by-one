Answer

Root cause: two handlers existed — the Retrieve handler in memories_search.go:148 (which had DOGFOOD-004 relevance_score plumbing) and the live MemoryHandler.Search wired in main.go:1191 to POST /v1/memories/search. The live handler never copied RelevanceScore from the internal RetrieveResult into the SearchResponse, so every agent hit the wire with relevance_score: 0 — while judge PASS came from unit tests that exercised the unwired handler/Retrieve directly.

The fix — one line in the live handler (main.go):

func (h *MemoryHandler) Search(w http.ResponseWriter, r *http.Request) {
    results := Retrieve(r.URL.Query().Get("q"))
    out := make([]SearchResponse, 0, len(results))
    for _, res := range results {
        out = append(out, SearchResponse{
            ID:             res.ID,
            Text:           res.Text,
            RelevanceScore: res.RelevanceScore, // THE FIX: 1-line field copy
        })
    }
    writeJSON(w, out)
}

Regression test (main_test.go) — the key change is that it hits the actual route registration agents call, not the unwired handler. It builds the server through the same newMux() used in production (the thing to grep for in main.go):

func newTestServer() *httptest.Server {
    return httptest.NewServer(newMux(&MemoryHandler{})) // same wiring as main.go:1191
}

// TestSearchRouteCarriesRelevanceScore is the DOGFOOD-004 regression test:
// it would have failed on day one of the incident because the live route
// returned 0.0 for every relevance_score.
func TestSearchRouteCarriesRelevanceScore(t *testing.T) {
    srv := newTestServer()
    defer srv.Close()

    resp, err := http.Post(srv.URL+"/v1/memories/search?q=dexdat", "application/json", nil)
    if err != nil {
        t.Fatalf("POST route: %v", err)
    }
    defer resp.Body.Close()

    var out []SearchResponse
    if err := json.NewDecoder(resp.Body).Decode(&out); err != nil {
        t.Fatalf("decode: %v", err)
    }
    for i, m := range out {
        if m.RelevanceScore == 0 {
            t.Errorf("result %d: relevance_score = 0 on live route (DOGFOOD-004 regression), want > 0", i)
        }
    }
}

Also added edge-case coverage: empty query returns [] (not null), the wire payload contains the relevance_score JSON key, and scores are preserved per result (0.92, 0.61) rather than clobbered. Repo: /home/kara/dexdat-fix.
