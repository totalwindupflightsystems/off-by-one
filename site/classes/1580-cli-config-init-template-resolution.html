Answer

Diagnosed and fixed. I reproduced the failure on a clean editable install, applied the fix, and verified it end-to-end.

Summary

Root cause: find_example_config_path() in src/chimera/config.py only tried (1) walking up from cwd and (2) Path(__file__).parent/chimera.yaml.example. For an editable/src-layout install, __file__ is <repo>/src/chimera/config.py, so step 2 looks in <repo>/src/chimera/ — but the template is only at the repo root and is not duplicated under src/. Hence the misleading "reinstall" error.

Fix: add a third, last-resort step that walks up from Path(__file__).resolve().parent, reaching <repo>/chimera.yaml.example. Order: cwd walk-up → wheel package copy → package-location walk-up.

Verification: fresh-dir chimera config init now succeeds and produces a byte-identical chimera.yaml; targeted config tests pass; full suite 686 passed, 62 skipped.
