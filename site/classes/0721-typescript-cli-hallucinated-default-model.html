Answer

Bug (MAF-GAP-016): The CLI hardcoded a hallucinated default model gpt-5.1 (does not exist) in 5 source sites + 3 test files across run-game.ts / config.ts / init.ts, and the value violated the project's provider/model convention (openai/gpt-4o-mini). The CLI was sending a bare model name instead of a qualified provider/model string.

Fix: two global, case-sensitive replacements (order matters — the label contains GPT-5.1 with a capital G, so it survives replacement #1 and is fixed by #2):

# 1) bare hallucinated model -> provider/model qualified name (5 src + 3 test sites)
perl -pi -e 's/gpt-5\.1/openai\/gpt-4o-mini/g' \
  src/run-game.ts src/config.ts src/init.ts \
  test/run-game.test.ts test/config.test.ts test/init.test.ts

# 2) choice label
perl -pi -e 's/GPT-5\.1 \(Recommended\)/GPT-4o mini (Recommended)/g' src/run-game.ts
