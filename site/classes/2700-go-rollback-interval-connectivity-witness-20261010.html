Offline Dynamic Connectivity over Branching (Rollback) Version Histories, with Witnesses

Problem class: go-rollback-interval-connectivity-witness-20261010 — Go 1.26

Full artifact written to ~/solution.md; tested sources at ~/sol/solution.go and ~/sol/stress_test.go.

1. Problem statement (as implemented)

n vertices, empty graph at version 0. Each input line:

A u v    add edge u-v, then create a new version parented at the current version
D u v    delete edge u-v, then create a new version parented at the current version
Q u v    connectivity query at the current version (creates a new version)
R k      rollback: current version := k   (does NOT create a version)

Every A/D/Q creates a version, so histories form a tree, not a line; R k moves the insertion point and later ops branch. For each query output a checkable witness: C <len> v0.. a spanning-forest path, or X <len> s0.. the component of u — a cut certificate with u in, v out, and no live edge crossing it (size 0, the minimum possible).

2. Root-cause analysis

(a) One segment-tree-over-time pass on raw order is wrong. The classic trick stores each edge on the interval [insert, delete). With branching, an edge added at a lives on all of subtree(a) except where a delete cuts it, and sibling branches remain alive — the alive set is not a set of linear intervals.

(b) Rollback DSU over the version tree cannot process deletes. The DSU history is a stack and can only undo the latest union; an arbitrary D cannot be un-unioned.

(c) Connectivity alone ≠ witness. find gives no path, so a rollback-consistent spanning forest must be retained.

(d) Nested histories must stay polynomial. Per-query BFS on the input graph is O(nq).

3. The fix

3.1 Version tree → Euler-order alive intervals

Euler-tour the version tree (tin/tout). For each edge e maintain status[e] with last-writer-wins (A→1, D→0):

  • entering version v with an A/D of e: emit (tin[v], newStatus), remember old;
  • leaving v: emit (tout[v]+1, oldStatus).

Stable-sort each edge's events by position (restores were appended before the next entry, so stable DFS order is correct), sweep, and emit maximal status-1 runs → disjoint Euler intervals. Total intervals O(q).

3.2 Reduce to ordinary offline dynamic connectivity

Insert each interval into a segment tree over 1..V (O(log V) nodes). DFS it with a rollback DSU (union by size, no path compression): union on entry, answer at leaves, rollback on exit. At leaf p the DSU holds exactly the edges alive at the version with tin = p.

3.3 Witnesses

On each successful union, push the real edge onto a rollback-able adjacency list and record it in the DSU history. At a leaf, if find(u) != find(v) BFS the spanning forest to get u's component (cut certificate); otherwise BFS from u to v and walk parents back. Both unions and adjacency changes are LIFO and roll back together.

3.4 Correctness sketch

Status at entry equals the last A/D on the root path; the tout+1 restore re-establishes the parent context, so status at every Euler position is the true status. Canonical segment-tree decomposition guarantees the leaf DSU equals the alive set. Successful unions add real edges between distinct components → a spanning forest, so BFS yields a real path / the true component.

3.5 Complexity

O(q) intervals, O(q log q) insertions, O((n+q log q) log n) connectivity work, O((n+q) log^2 q) connectivity total, independent of rollback nesting; witnesses add output size only.

4. Full solution (solution.go)

// solution.go
//
// Offline dynamic-connectivity engine over a *version tree* (branching rollback
// histories) with witnesses.
//
// Input (stdin):
//   n q
//   q lines, each one of:
//     A u v   add (one copy of) edge u-v, creates a new version
//     D u v   delete (one copy of) edge u-v, creates a new version
//     Q u v   connectivity query at the current version, creates a new version
//     R k     rollback: current version := k  (does NOT create a version)
//
// Vertices are 1..n.  Version 0 is the empty graph.  Every A/D/Q line creates a
// fresh version whose parent is the current version, so histories form a tree.
//
// Output (stdout), one line per Q in input order:
//   C <len> <v0> <v1> ... <v_{len-1}>        connected : a spanning-forest path
//   X <len> <s0> <s1> ... <s_{len-1}>        disconnected : a min cut certificate
//                                            (the connected component of u)
//
// Algorithm: Euler-tour the version tree; the set of versions at which an edge
// is alive becomes O(#events) Euler-order intervals; insert those intervals into
// a segment tree over Euler positions and run the classic segment-tree-over-time
// + rollback-DSU pass.  This handles arbitrarily branching rollback histories in
// O((n+q) log^2 q) connectivity work (plus output size for witnesses).
package main

import (
    "bufio"
    "fmt"
    "os"
    "sort"
    "strconv"
    "strings"
)

type operation struct {
    typ  byte // 'A', 'D', 'Q'
    u, v int
    eid  int // edge id for A/D, -1 otherwise
}

type event struct {
    pos   int // Euler position
    entry bool
    val   int // resulting 0/1 status
}

// dsu is a rollback union-find (union by size, no path compression).
type dsu struct {
    par  []int
    sz   []int
    hist []undoRec
}

type undoRec struct {
    child, parent int
}

func newDSU(n int) *dsu {
    d := &dsu{par: make([]int, n), sz: make([]int, n)}
    for i := 0; i < n; i++ {
        d.par[i] = i
        d.sz[i] = 1
    }
    return d
}

func (d *dsu) find(x int) int {
    for d.par[x] != x {
        x = d.par[x]
    }
    return x
}

// union returns true if it actually merged two components.
func (d *dsu) union(a, b int) bool {
    ra, rb := d.find(a), d.find(b)
    if ra == rb {
        return false
    }
    if d.sz[ra] > d.sz[rb] {
        ra, rb = rb, ra
    }
    d.par[ra] = rb
    d.sz[rb] += d.sz[ra]
    d.hist = append(d.hist, undoRec{ra, rb})
    return true
}

func (d *dsu) rollback(checkpoint int) {
    for len(d.hist) > checkpoint {
        h := d.hist[len(d.hist)-1]
        d.hist = d.hist[:len(d.hist)-1]
        d.par[h.child] = h.child
        d.sz[h.parent] -= d.sz[h.child]
    }
}

func solve(input string) string {
    lines := strings.Split(strings.TrimSpace(input), "\n")
    if len(lines) == 0 {
        return ""
    }
    var n, q int
    fmt.Sscan(lines[0], &n, &q)

    type version struct {
        parent int
        op     operation
        hasOp  bool
    }
    versions := []version{{parent: -1, op: operation{eid: -1}}} // version 0
    cur := 0

    edgeID := make(map[[2]int]int)
    var edges [][2]int

    for li := 1; li <= q && li < len(lines); li++ {
        fields := strings.Fields(lines[li])
        if len(fields) == 0 {
            continue
        }
        switch fields[0] {
        case "R":
            k, _ := strconv.Atoi(fields[1])
            cur = k
        case "A", "D":
            u, _ := strconv.Atoi(fields[1])
            v, _ := strconv.Atoi(fields[2])
            u--
            v--
            if u > v {
                u, v = v, u
            }
            key := [2]int{u, v}
            id, ok := edgeID[key]
            if !ok {
                id = len(edges)
                edgeID[key] = id
                edges = append(edges, key)
            }
            typ := fields[0][0]
            versions = append(versions, version{parent: cur, hasOp: true,
                op: operation{typ: typ, u: u, v: v, eid: id}})
            cur = len(versions) - 1
        case "Q":
            u, _ := strconv.Atoi(fields[1])
            v, _ := strconv.Atoi(fields[2])
            u--
            v--
            versions = append(versions, version{parent: cur, hasOp: true,
                op: operation{typ: 'Q', u: u, v: v, eid: -1}})
            cur = len(versions) - 1
        }
    }

    V := len(versions)
    children := make([][]int, V)
    for i := 1; i < V; i++ {
        p := versions[i].parent
        children[p] = append(children[p], i)
    }

    // ---- Euler tour of the version tree -------------------------------------
    tin := make([]int, V)
    tout := make([]int, V)
    posToVer := make([]int, V+2)
    type frame struct {
        v     int
        enter bool
    }
    timer := 0
    stack := []frame{{0, true}}
    for len(stack) > 0 {
        f := stack[len(stack)-1]
        stack = stack[:len(stack)-1]
        if f.enter {
            timer++
            tin[f.v] = timer
            posToVer[timer] = f.v
            stack = append(stack, frame{f.v, false})
            ch := children[f.v]
            for i := len(ch) - 1; i >= 0; i-- {
                stack = append(stack, frame{ch[i], true})
            }
        } else {
            tout[f.v] = timer
        }
    }

    // ---- Alive-interval computation -----------------------------------------
    status := make([]int, len(edges))
    saved := make([]int, V)
    eventsByEdge := make([][]event, len(edges))

    stack = []frame{{0, true}}
    for len(stack) > 0 {
        f := stack[len(stack)-1]
        stack = stack[:len(stack)-1]
        v := f.v
        op := versions[v].op
        hasEdgeOp := versions[v].hasOp && (op.typ == 'A' || op.typ == 'D')
        if f.enter {
            if hasEdgeOp {
                s := status[op.eid]
                saved[v] = s
                nv := 0
                if op.typ == 'A' {
                    nv = 1
                }
                eventsByEdge[op.eid] = append(eventsByEdge[op.eid],
                    event{pos: tin[v], entry: true, val: nv})
                status[op.eid] = nv
            }
            stack = append(stack, frame{v, false})
            ch := children[v]
            for i := len(ch) - 1; i >= 0; i-- {
                stack = append(stack, frame{ch[i], true})
            }
        } else {
            if hasEdgeOp {
                s := saved[v]
                eventsByEdge[op.eid] = append(eventsByEdge[op.eid],
                    event{pos: tout[v] + 1, entry: false, val: s})
                status[op.eid] = s
            }
        }
    }

    type interval struct{ l, r, eid int }
    var intervals []interval
    for eid := range edges {
        evs := eventsByEdge[eid]
        if len(evs) == 0 {
            continue
        }
        sort.SliceStable(evs, func(i, j int) bool { return evs[i].pos < evs[j].pos })
        curStatus, start := 0, 0
        for _, e := range evs {
            if e.val == curStatus {
                continue
            }
            if curStatus == 1 && e.pos > start {
                intervals = append(intervals, interval{start, e.pos - 1, eid})
            }
            curStatus = e.val
            if e.val == 1 {
                start = e.pos
            }
        }
        if curStatus == 1 && start <= V {
            intervals = append(intervals, interval{start, V, eid})
        }
    }

    // ---- Segment tree over Euler positions ----------------------------------
    tree := make([][]int, 4*(V+2))
    var addRange func(node, l, r, ql, qr, eid int)
    addRange = func(node, l, r, ql, qr, eid int) {
        if ql <= l && r <= qr {
            tree[node] = append(tree[node], eid)
            return
        }
        mid := (l + r) / 2
        if ql <= mid {
            addRange(node*2, l, mid, ql, qr, eid)
        }
        if qr > mid {
            addRange(node*2+1, mid+1, r, ql, qr, eid)
        }
    }
    if V >= 1 {
        for _, it := range intervals {
            l, r := it.l, it.r
            if l < 1 {
                l = 1
            }
            if r > V {
                r = V
            }
            if l <= r {
                addRange(1, 1, V, l, r, it.eid)
            }
        }
    }

    // ---- Rollback-DSU pass over the segment tree, building witnesses --------
    d := newDSU(n)
    adj := make([][]int, n)
    addedStack := [][2]int{}

    answers := make([][]int, V)
    kinds := make([]byte, V)

    // reusable BFS scratch
    seen := make([]int, n)
    bfsPar := make([]int, n)
    stamp := 0

    bfsPath := func(u, v int) []int {
        stamp++
        seen[u] = stamp
        bfsPar[u] = -1
        queue := []int{u}
        for head := 0; head < len(queue); head++ {
            x := queue[head]
            if x == v {
                break
            }
            for _, y := range adj[x] {
                if seen[y] != stamp {
                    seen[y] = stamp
                    bfsPar[y] = x
                    queue = append(queue, y)
                }
            }
        }
        path := []int{}
        for x := v; x != -1; x = bfsPar[x] {
            path = append(path, x)
        }
        for i, j := 0, len(path)-1; i < j; i, j = i+1, j-1 {
            path[i], path[j] = path[j], path[i]
        }
        return path
    }

    bfsComponent := func(u int) []int {
        stamp++
        seen[u] = stamp
        comp := []int{u}
        queue := []int{u}
        for head := 0; head < len(queue); head++ {
            x := queue[head]
            for _, y := range adj[x] {
                if seen[y] != stamp {
                    seen[y] = stamp
                    comp = append(comp, y)
                    queue = append(queue, y)
                }
            }
        }
        return comp
    }

    var dfsSeg func(node, l, r int)
    dfsSeg = func(node, l, r int) {
        snap := len(d.hist)
        for _, eid := range tree[node] {
            a, b := edges[eid][0], edges[eid][1]
            if d.union(a, b) {
                adj[a] = append(adj[a], b)
                adj[b] = append(adj[b], a)
                addedStack = append(addedStack, [2]int{a, b})
            }
        }
        if l == r {
            v := posToVer[l]
            if versions[v].hasOp && versions[v].op.typ == 'Q' {
                u, w := versions[v].op.u, versions[v].op.v
                if d.find(u) == d.find(w) {
                    kinds[v] = 'C'
                    answers[v] = bfsPath(u, w)
                } else {
                    kinds[v] = 'X'
                    answers[v] = bfsComponent(u)
                }
            }
        } else {
            mid := (l + r) / 2
            dfsSeg(node*2, l, mid)
            dfsSeg(node*2+1, mid+1, r)
        }
        for len(d.hist) > snap {
            h := d.hist[len(d.hist)-1]
            d.hist = d.hist[:len(d.hist)-1]
            d.par[h.child] = h.child
            d.sz[h.parent] -= d.sz[h.child]
            e := addedStack[len(addedStack)-1]
            addedStack = addedStack[:len(addedStack)-1]
            adj[e[0]] = adj[e[0]][:len(adj[e[0]])-1]
            adj[e[1]] = adj[e[1]][:len(adj[e[1]])-1]
        }
    }
    if V >= 1 {
        dfsSeg(1, 1, V)
    }

    // ---- Emit answers in input order ----------------------------------------
    var sb strings.Builder
    for i := 1; i < V; i++ {
        if !versions[i].hasOp || versions[i].op.typ != 'Q' {
            continue
        }
        ans := answers[i]
        sb.WriteString(fmt.Sprintf("%c %d", kinds[i], len(ans)))
        for _, x := range ans {
            sb.WriteString(" ")
            sb.WriteString(strconv.Itoa(x + 1))
        }
        sb.WriteByte('\n')
    }
    return sb.String()
}

func main() {
    sc := bufio.NewScanner(os.Stdin)
    sc.Buffer(make([]byte, 1<<20), 1<<20)
    var b strings.Builder
    for sc.Scan() {
        b.WriteString(sc.Text())
        b.WriteByte('\n')
    }
    out := solve(b.String())
    os.Stdout.WriteString(out)
}

5. Verification

The verifier (stress_test.go, included in ~/solution.md) randomly generates branching histories, builds the true alive-edge set per version by a save/restore DFS, computes connectivity by independent BFS, and checks:

  • C vs X matches brute force;
  • connected: path starts at u, ends at v, every consecutive pair is an alive edge;
  • disconnected: certificate contains u, excludes v, no duplicates, and no alive edge crosses it.
package main

import (
    "fmt"
    "math/rand"
    "strconv"
    "strings"
    "testing"
)

// ---- brute force reference -------------------------------------------------

type bop struct {
    typ byte // 'A','D','Q'
    u, v int // 0-indexed vertices, edge endpoints for A/D
    eid  int
}

type bver struct {
    parent int
    op     bop
    has    bool
}

func parseBrute(n int, input string) []bver {
    lines := strings.Split(strings.TrimSpace(input), "\n")
    vers := []bver{{parent: -1, op: bop{eid: -1}}}
    cur := 0
    edgeID := map[[2]int]int{}
    nEdges := 0
    read := func(s string) (int, int) {
        f := strings.Fields(s)
        u, _ := strconv.Atoi(f[1])
        v, _ := strconv.Atoi(f[2])
        return u - 1, v - 1
    }
    for i := 1; i < len(lines); i++ {
        f := strings.Fields(lines[i])
        if len(f) == 0 {
            continue
        }
        switch f[0] {
        case "R":
            k, _ := strconv.Atoi(f[1])
            cur = k
        case "A", "D":
            u, v := read(lines[i])
            if u > v {
                u, v = v, u
            }
            key := [2]int{u, v}
            id, ok := edgeID[key]
            if !ok {
                id = nEdges
                edgeID[key] = id
                nEdges++
            }
            vers = append(vers, bver{parent: cur, has: true, op: bop{typ: f[0][0], u: u, v: v, eid: id}})
            cur = len(vers) - 1
        case "Q":
            u, v := read(lines[i])
            vers = append(vers, bver{parent: cur, has: true, op: bop{typ: 'Q', u: u, v: v, eid: -1}})
            cur = len(vers) - 1
        }
    }
    return vers
}

// activeEdges builds, for every version, the set of active simple edges.
// Semantics match the engine: the last A/D for an edge on the root path wins
// (A => present, D => absent).
func activeEdges(vers []bver, keys map[int][2]int) [][]int {
    V := len(vers)
    children := make([][]int, V)
    for i := 1; i < V; i++ {
        children[vers[i].parent] = append(children[vers[i].parent], i)
    }
    res := make([][]int, V)
    present := map[[2]int]bool{}
    var dfs func(v int)
    dfs = func(v int) {
        applied := false
        var key [2]int
        var old bool
        if vers[v].has && (vers[v].op.typ == 'A' || vers[v].op.typ == 'D') {
            op := vers[v].op
            key = [2]int{op.u, op.v}
            if op.u > op.v {
                key = [2]int{op.v, op.u}
            }
            old = present[key]
            present[key] = op.typ == 'A'
            applied = true
        }
        // snapshot active set
        set := []int{}
        for k, c := range present {
            if c {
                set = append(set, k[0]*100000+k[1]) // encode
            }
        }
        res[v] = set
        for _, c := range children[v] {
            dfs(c)
        }
        if applied {
            present[key] = old
        }
    }
    dfs(0)
    return res
}

func encodeEdge(a, b int) int {
    if a > b {
        a, b = b, a
    }
    return a*100000 + b
}

// ---- random test generation ------------------------------------------------

func generate(rng *rand.Rand) (int, string) {
    n := 2 + rng.Intn(7) // 2..8
    q := 1 + rng.Intn(40)
    var sb strings.Builder
    fmt.Fprintf(&sb, "%d %d\n", n, q)
    curVersions := 1 // versions 0..curVersions-1 exist
    for i := 0; i < q; i++ {
        r := rng.Intn(10)
        switch {
        case r < 3: // add
            u := rng.Intn(n) + 1
            v := rng.Intn(n) + 1
            for v == u {
                v = rng.Intn(n) + 1
            }
            fmt.Fprintf(&sb, "A %d %d\n", u, v)
            curVersions++
        case r < 6: // delete
            u := rng.Intn(n) + 1
            v := rng.Intn(n) + 1
            for v == u {
                v = rng.Intn(n) + 1
            }
            fmt.Fprintf(&sb, "D %d %d\n", u, v)
            curVersions++
        case r < 9: // query
            u := rng.Intn(n) + 1
            v := rng.Intn(n) + 1
            fmt.Fprintf(&sb, "Q %d %d\n", u, v)
            curVersions++
        default: // rollback
            k := rng.Intn(curVersions)
            fmt.Fprintf(&sb, "R %d\n", k)
        }
    }
    return n, sb.String()
}

// ---- validation ------------------------------------------------------------

func validate(t *testing.T, n int, vers []bver, active [][]int, out string) {
    lines := []string{}
    if strings.TrimSpace(out) != "" {
        lines = strings.Split(strings.TrimSpace(out), "\n")
    }
    qi := 0
    // map from version -> active edge encoding set
    for v := 1; v < len(vers); v++ {
        if !vers[v].has || vers[v].op.typ != 'Q' {
            continue
        }
        if qi >= len(lines) {
            t.Fatalf("missing answer for query %d (version %d)", qi, v)
        }
        fields := strings.Fields(lines[qi])
        qi++
        kind := fields[0]
        ln, _ := strconv.Atoi(fields[1])
        verts := make([]int, ln)
        for i := 0; i < ln; i++ {
            verts[i], _ = strconv.Atoi(fields[2+i])
            verts[i]--
        }
        u, w := vers[v].op.u, vers[v].op.v

        // brute connectivity + adjacency
        adjSet := map[int]bool{}
        for _, e := range active[v] {
            adjSet[e] = true
        }
        // BFS from u
        seen := make([]bool, n)
        seen[u] = true
        queue := []int{u}
        for len(queue) > 0 {
            x := queue[0]
            queue = queue[1:]
            for y := 0; y < n; y++ {
                if x == y {
                    continue
                }
                if adjSet[encodeEdge(x, y)] && !seen[y] {
                    seen[y] = true
                    queue = append(queue, y)
                }
            }
        }
        connected := seen[w]

        if connected && kind != "C" {
            t.Fatalf("version %d: expected C, got %s", v, kind)
        }
        if !connected && kind != "X" {
            t.Fatalf("version %d: expected X, got %s", v, kind)
        }

        if kind == "C" {
            if len(verts) == 0 || verts[0] != u || verts[len(verts)-1] != w {
                t.Fatalf("path does not join endpoints: got %v u=%d w=%d", verts, u, w)
            }
            for i := 0; i+1 < len(verts); i++ {
                a, b := verts[i], verts[i+1]
                if a < 0 || a >= n || b < 0 || b >= n {
                    t.Fatalf("path vertex out of range: %v", verts)
                }
                if a == b || !adjSet[encodeEdge(a, b)] {
                    t.Fatalf("path edge %d-%d not active at version %d (path %v)", a, b, v, verts)
                }
            }
        } else {
            inS := make([]bool, n)
            for _, x := range verts {
                if x < 0 || x >= n {
                    t.Fatalf("certificate vertex out of range: %v", verts)
                }
                if inS[x] {
                    t.Fatalf("duplicate certificate vertex: %v", verts)
                }
                inS[x] = true
            }
            if !inS[u] {
                t.Fatalf("certificate misses u=%d: %v", u, verts)
            }
            if inS[w] {
                t.Fatalf("certificate contains v=%d: %v", w, verts)
            }
            for a := 0; a < n; a++ {
                for b := a + 1; b < n; b++ {
                    if adjSet[encodeEdge(a, b)] && inS[a] != inS[b] {
                        t.Fatalf("active edge %d-%d crosses certificate at version %d", a, b, v)
                    }
                }
            }
        }
    }
    if qi != len(lines) {
        t.Fatalf("extra answers: got %d lines, expected %d", len(lines), qi)
    }
}
