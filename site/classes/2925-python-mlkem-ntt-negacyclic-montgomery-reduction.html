Fixing the ML-KEM (Kyber) NTT over Z_q[x]/(x^256+1), q = 3329

TL;DR

A correct, self-contained Python implementation lives in mlkem_ntt.py. It implements the forward/inverse NTT, on-the-fly zeta tables, Montgomery and Barrett reduction, and base-case multiplication. It enforces canonical coefficients in [0, q), rejects anything else with CoefficientRangeError (a ValueError subclass), round-trips the inverse NTT exactly, and guarantees

inv_ntt(pointwise_mul(ntt(a), ntt(b))) == negacyclic_convolution(a, b)

for random a, b. Verification is in verify_mlkem_ntt.py and test_mlkem_ntt.py.

Root-cause analysis

The reported symptoms (pointwise products that disagree with schoolbook negacyclic convolution, inverse transforms that do not round-trip, non-canonical twiddle factors, and out-of-range coefficients being silently reduced) come from a small set of well-known mistakes in Kyber NTT code:

  1. Assuming x^256 + 1 splits into 256 linear factors. q - 1 = 3328 = 2^8 * 13, so there is no primitive 512-th root of unity mod q. x^256 + 1 splits into 128 irreducible quadratics, and the "pointwise" stage must be 128 base-case multiplications in Z_q[y]/(y^2 - zeta_i), not 256 scalar multiplications. Forcing a 512-point transform (or a full 256-point cyclic NTT) silently yields a cyclic convolution instead of a negacyclic one.

  2. Wrong zeta ordering. Kyber stores the 128 twiddle factors in bit-reversed order: zeta_k = 17 ** bitrev7(k) mod q. A table in natural order, or with the wrong bit width, breaks both the butterfly network and the inverse.

  3. Non-canonical twiddles. Reproducing the reference C table verbatim keeps it in signed Montgomery form (e.g. -1044, -758, …), whose values lie outside [0, q). The required fix is to derive the table on the fly as pow(17, bitrev7(k), q) and store its Montgomery form as (zeta * 2^16) % q — both canonical.

  4. Inconsistent Montgomery scaling. fqmul(a, b) = a*b*2^-16 mod q. Mixing Montgomery and non-Montgomery operands, or forgetting to undo the 2^-16 factor in the base-case product, leaves a global R factor so the pointwise result is off by a constant. The forward NTT is a true NTT when the twiddles are in Montgomery form (because zeta_M * 2^-16 = zeta); the base multiply and inverse normalisation must be handled consistently.

  5. Wrong inverse normalisation. The unnormalised inverse network computes 128 * (true inverse), so the final scaling must be exactly 128^-1 mod q. Kyber's invntt_tomont scales by R/128 because it deliberately targets the Montgomery domain; copying that constant into a non-Montgomery path breaks the round-trip.

  6. Silently reducing out-of-range inputs. Wrapping every incoming coefficient with x % q hides caller bugs. The contract here is to validate first and raise CoefficientRangeError.

  7. Wrong reduction constants. q^-1 mod 2^16 = 62209, 2^16 mod q = 2285, 2^-16 mod q = 169, 128^-1 mod q = 3303. One wrong constant corrupts every layer.

Exact fix

mlkem_ntt.py

"""ML-KEM (CRYSTALS-Kyber) NTT over Z_q[x]/(x^256 + 1), q = 3329.

This module implements, from scratch and in pure Python:

  * on-the-fly zeta (twiddle) tables,
  * Montgomery reduction and Barrett reduction,
  * the forward and inverse number-theoretic transform,
  * base-case multiplication in Z_q[y]/(y^2 - zeta),

with the following contract:

  * Every public function accepts and returns coefficients that are *canonical*
    residues in [0, q); inputs outside that range are rejected with a
    ``CoefficientRangeError`` (a ``ValueError`` subclass) instead of being
    silently reduced.
  * ``inv_ntt(ntt(a)) == a`` exactly, coefficient for coefficient.
  * ``inv_ntt(pointwise_mul(ntt(a), ntt(b)))`` equals the schoolbook
    negacyclic convolution of ``a`` and ``b`` modulo q.
  * Every twiddle factor is a canonical residue in [0, q).

The transform is the usual 7-layer Cooley-Tukey / Gentle-Sande network used by
Kyber.  Because q - 1 = 3328 = 2**8 * 13, there is no primitive 512-th root of
unity; instead ``x^256 + 1`` splits into 128 irreducible quadratics and the
"pointwise" stage is 128 base-case multiplications in Z_q[y]/(y^2 - zeta_i).
"""

from __future__ import annotations

from typing import List, Sequence, Tuple

# ---------------------------------------------------------------------------
# Constants
# ---------------------------------------------------------------------------

Q: int = 3329                 # Kyber modulus
N: int = 256                  # polynomial degree
ZETA_ROOT: int = 17           # primitive 256-th root of unity mod q
R: int = 1 << 16              # Montgomery radix
R_MOD_Q: int = R % Q          # 2285  = 2^16 mod q
R_INV_MOD_Q: int = pow(R, -1, Q)     # 169   = 2^-16 mod q
Q_INV_MOD_2_16: int = pow(Q, -1, R)  # 62209 = q^-1 mod 2^16

# Barrett constant: v = floor(2^26 / q) rounded to nearest.
_BARRETT_V: int = ((1 << 26) + Q // 2) // Q  # 20159


class CoefficientRangeError(ValueError):
    """Raised when a coefficient is not a canonical residue in [0, q)."""


# ---------------------------------------------------------------------------
# On-the-fly twiddle tables
# ---------------------------------------------------------------------------

def _bit_reverse(value: int, width: int) -> int:
    """Reverse the low ``width`` bits of ``value``."""
    result = 0
    for _ in range(width):
        result = (result << 1) | (value & 1)
        value >>= 1
    return result


def compute_zetas() -> List[int]:
    """Return the 128 true (non-Montgomery) twiddles in Kyber's NTT order.

    ``ZETAS[k] = 17 ** bitrev7(k) mod q``.  All entries are canonical in
    [0, q).  Entry 0 is the unused placeholder (equals 1).
    """
    return [pow(ZETA_ROOT, _bit_reverse(k, 7), Q) for k in range(N // 2)]


def compute_montgomery_zetas() -> List[int]:
    """Return the 128 twiddles in Montgomery form (``zeta * 2^16 mod q``).

    All entries are canonical in [0, q).  These are the values used directly
    by the NTT butterflies, exactly as in the Kyber reference implementation.
    """
    return [(z * R_MOD_Q) % Q for z in compute_zetas()]


# Computed once at import time (no hard-coded table).
ZETAS: Tuple[int, ...] = tuple(compute_zetas())
ZETAS_MONT: Tuple[int, ...] = tuple(compute_montgomery_zetas())

# Sanity: every twiddle factor is a canonical residue.
assert all(0 <= z < Q for z in ZETAS), "non-canonical zeta in true table"
assert all(0 <= z < Q for z in ZETAS_MONT), "non-canonical zeta in Montgomery table"
assert ZETAS[0] == 1 and ZETAS_MONT[0] == R_MOD_Q
assert pow(ZETA_ROOT, 128, Q) == Q - 1, "17 must be a primitive 256-th root"
assert pow(ZETA_ROOT, 256, Q) == 1


# ---------------------------------------------------------------------------
# Modular reductions
# ---------------------------------------------------------------------------

def montgomery_reduce(a: int) -> int:
    """Return ``a * 2^-16 mod q`` as a signed representative.

    Uses the standard Montgomery trick: choose ``m`` in [0, 2^16) with
    ``m == a * q^-1 (mod 2^16)``; then ``a - m*q`` is divisible by 2^16 and
    ``(a - m*q) / 2^16 == a * 2^-16 (mod q)``.
    """
    m = (a * Q_INV_MOD_2_16) & 0xFFFF
    return (a - m * Q) >> 16


def barrett_reduce(a: int) -> int:
    """Return ``a mod q`` as a signed representative near zero.

    Correct for inputs with |a| < 2^25 (all values produced by this module).
    """
    t = (_BARRETT_V * a + (1 << 25)) >> 26
    return a - t * Q


def fqmul(a: int, b: int) -> int:
    """Montgomery multiplication: ``montgomery_reduce(a * b)``."""
    return montgomery_reduce(a * b)


def to_canonical(a: int) -> int:
    """Map any integer to its unique representative in [0, q)."""
    return a % Q


# ---------------------------------------------------------------------------
# Canonical input validation
# ---------------------------------------------------------------------------

def _check_poly(poly: Sequence[int], name: str = "poly") -> None:
    """Reject anything that is not 256 canonical residues in [0, q)."""
    if len(poly) != N:
        raise CoefficientRangeError(
            f"{name}: expected {N} coefficients, got {len(poly)}"
        )
    for i, c in enumerate(poly):
        if not isinstance(c, int) or isinstance(c, bool):
            raise CoefficientRangeError(
                f"{name}[{i}]: expected int coefficient, got {type(c).__name__}"
            )
        if not (0 <= c < Q):
            raise CoefficientRangeError(
                f"{name}[{i}] = {c} is outside the canonical range [0, {Q})"
            )


# ---------------------------------------------------------------------------
# Forward / inverse NTT
# ---------------------------------------------------------------------------

def ntt(poly: Sequence[int]) -> List[int]:
    """Forward NTT of a polynomial with canonical coefficients.

    Returns a new list of 256 canonical residues in [0, q).
    """
    _check_poly(poly, "ntt input")
    r = list(poly)

    k = 1
    length = N // 2
    while length >= 2:
        start = 0
        while start < N:
            zeta_m = ZETAS_MONT[k]
            k += 1
            for j in range(start, start + length):
                t = fqmul(zeta_m, r[j + length])   # == zeta * r[j+length] mod q
                r[j + length] = to_canonical(r[j] - t)
                # Barrett keeps the sum bounded; canonicalise afterwards.
                r[j] = to_canonical(barrett_reduce(r[j] + t))
            start += 2 * length
        length //= 2
    return r


def inv_ntt(poly: Sequence[int]) -> List[int]:
    """Inverse NTT with the exact normalisation factor 1/128.

    Returns a new list of 256 canonical residues in [0, q) and is the exact
    inverse of :func:`ntt`.
    """
    _check_poly(poly, "inv_ntt input")
    r = list(poly)

    k = N // 2 - 1  # 127
    length = 2
    while length <= N // 2:
        start = 0
        while start < N:
            zeta_m = ZETAS_MONT[k]
            k -= 1
            for j in range(start, start + length):
                t = r[j]
                r[j] = to_canonical(t + r[j + length])
                r[j + length] = fqmul(zeta_m, r[j + length] - t)
            start += 2 * length
        length *= 2

    # The unnormalised network yields 128 * inverse; scale by 128^-1.
    # fqmul(x, (128^-1)*R) == x * 128^-1 mod q.
    inv128_mont = (pow(128, -1, Q) * R_MOD_Q) % Q
    return [to_canonical(fqmul(x, inv128_mont)) for x in r]


# Common aliases used by different ML-KEM code bases.
invntt = inv_ntt
forward_ntt = ntt
inverse_ntt = inv_ntt


# ---------------------------------------------------------------------------
# Base-case multiplication and pointwise product
# ---------------------------------------------------------------------------

def basemul(a: Sequence[int], b: Sequence[int], zeta: int) -> List[int]:
    """Base-case multiplication in Z_q[y]/(y^2 - zeta).

    ``a`` and ``b`` are length-2 canonical coefficient pairs and ``zeta`` is
    the canonical true (non-Montgomery) root.  Returns a length-2 canonical
    pair.  This is the primitive that the 128-way pointwise stage uses.
    """
    if len(a) != 2 or len(b) != 2:
        raise CoefficientRangeError("basemul expects length-2 coefficient pairs")
    if not (0 <= zeta < Q):
        raise CoefficientRangeError(
            f"basemul zeta {zeta} is outside the canonical range [0, {Q})"
        )
    for name, pair in (("a", a), ("b", b)):
        for i, c in enumerate(pair):
            if not isinstance(c, int) or isinstance(c, bool) or not (0 <= c < Q):
                raise CoefficientRangeError(
                    f"basemul {name}[{i}] = {c!r} is not a canonical residue"
                )
    a0, a1 = a
    b0, b1 = b
    r0 = (a0 * b0 + a1 * b1 * zeta) % Q
    r1 = (a0 * b1 + a1 * b0) % Q
    return [r0, r1]


def basemul_montgomery(
    a: Sequence[int], b: Sequence[int], zeta_mont: int
) -> List[int]:
    """Reference-style base multiplication using Montgomery arithmetic.

    ``zeta_mont`` is the Montgomery-form root (canonical in [0, q)).  The
    accumulated factor 2^-16 is removed before returning, so the result is
    identical to :func:`basemul` and canonical.
    """
    if len(a) != 2 or len(b) != 2:
        raise CoefficientRangeError("basemul_montgomery expects length-2 pairs")
    a0, a1 = a
    b0, b1 = b
    r0 = to_canonical(fqmul(fqmul(a1, b1), zeta_mont) + fqmul(a0, b0))
    r1 = to_canonical(fqmul(a0, b1) + fqmul(a1, b0))
    # Undo the 2^-16 factor introduced by fqmul.
    return [to_canonical(r0 * R_MOD_Q), to_canonical(r1 * R_MOD_Q)]


def pointwise_mul(a_hat: Sequence[int], b_hat: Sequence[int]) -> List[int]:
    """Pointwise (base-case) product of two NTT-domain polynomials.

    Consumes and produces 256 canonical residues.  The 128 pairs use roots
    ``ZETAS[64 + i]`` and its negation, matching Kyber's layout.
    """
    _check_poly(a_hat, "pointwise a_hat")
    _check_poly(b_hat, "pointwise b_hat")
    out = [0] * N
    for i in range(0, N, 4):
        z_true = ZETAS[64 + i // 4]
        out[i], out[i + 1] = basemul(
            (a_hat[i], a_hat[i + 1]), (b_hat[i], b_hat[i + 1]), z_true
        )
        out[i + 2], out[i + 3] = basemul(
            (a_hat[i + 2], a_hat[i + 3]),
            (b_hat[i + 2], b_hat[i + 3]),
            (Q - z_true) % Q,
        )
    return out


# Aliases.
poly_basemul = pointwise_mul
pointwise = pointwise_mul


# ---------------------------------------------------------------------------
# Reference (schoolbook) negacyclic convolution
# ---------------------------------------------------------------------------

def negacyclic_convolution(a: Sequence[int], b: Sequence[int]) -> List[int]:
    """Schoolbook product in Z_q[x]/(x^256 + 1).

    This is the slow ground truth: ``c[k] = sum_{i+j=k} a_i b_j -
    sum_{i+j=k+256} a_i b_j (mod q)``.
    """
    _check_poly(a, "negacyclic a")
    _check_poly(b, "negacyclic b")
    res = [0] * N
    for i in range(N):
        ai = a[i]
        if ai == 0:
            continue
        for j in range(N):
            bj = b[j]
            if bj == 0:
                continue
            d = i + j
            if d < N:
                res[d] += ai * bj
            else:
                res[d - N] -= ai * bj
    return [x % Q for x in res]


# Convenience: multiply two polynomials using the NTT.
def ntt_multiply(a: Sequence[int], b: Sequence[int]) -> List[int]:
    """Return a*b in Z_q[x]/(x^256+1) via NTT + pointwise + inverse NTT."""
    _check_poly(a, "ntt_multiply a")
    _check_poly(b, "ntt_multiply b")
    return inv_ntt(pointwise_mul(ntt(a), ntt(b)))


# ---------------------------------------------------------------------------
# Self-test
# ---------------------------------------------------------------------------

def _self_test(trials: int = 200, seed: int = 0x5EED) -> None:
    import random

    rng = random.Random(seed)

    # 1. reductions agree with their definitions.
    for _ in range(2000):
        x = rng.randrange(-Q * Q, Q * Q)
        assert (montgomery_reduce(x) - x * R_INV_MOD_Q) % Q == 0
        assert (barrett_reduce(x) - x) % Q == 0
        assert (fqmul(x, 1) - x * R_INV_MOD_Q) % Q == 0

    # 2. twiddles canonical.
    assert all(0 <= z < Q for z in ZETAS)
    assert all(0 <= z < Q for z in ZETAS_MONT)

    for _ in range(trials):
        a = [rng.randrange(Q) for _ in range(N)]
        b = [rng.randrange(Q) for _ in range(N)]

        # 3. forward output canonical.
        a_hat = ntt(a)
        assert all(0 <= c < Q for c in a_hat)

        # 4. exact round-trip.
        assert inv_ntt(a_hat) == a

        # 5. pointwise == negacyclic convolution.
        c_hat = pointwise_mul(a_hat, ntt(b))
        assert inv_ntt(c_hat) == negacyclic_convolution(a, b)

        # 6. Montgomery base multiply matches the canonical primitive.
        for i in range(0, N, 4):
            zt = ZETAS[64 + i // 4]
            zm = ZETAS_MONT[64 + i // 4]
            assert basemul(
                (a_hat[i], a_hat[i + 1]), (a_hat[i + 1], a_hat[i]), zt
            ) == basemul_montgomery(
                (a_hat[i], a_hat[i + 1]), (a_hat[i + 1], a_hat[i]), zm
            )

    # 7. strict rejection of non-canonical coefficients.
    for bad in (-1, Q, Q + 5, 1 << 40):
        try:
            ntt([bad] + [0] * (N - 1))
        except CoefficientRangeError:
            pass
        else:
            raise AssertionError(f"ntt accepted out-of-range coefficient {bad}")
    try:
        ntt([0] * (N - 1))
    except CoefficientRangeError:
        pass
    else:
        raise AssertionError("ntt accepted a wrong-length polynomial")

    print("mlkem_ntt self-test: all checks passed")


if __name__ == "__main__":
    _self_test()

"""Compact standalone verifier for mlkem_ntt.

Checks the properties required by the problem statement:

  1. every twiddle factor is canonical in [0, q);
  2. coefficients outside [0, q) are rejected;
  3. inverse NTT round-trips exactly;
  4. pointwise product (NTT domain) == schoolbook negacyclic convolution.

Run:  python3 verify_mlkem_ntt.py
"""

import random

import mlkem_ntt as m

Q, N = m.Q, m.N
rng = random.Random(123456789)


def main() -> None:
    # 1. canonical twiddles
    assert len(m.ZETAS) == 128 and len(m.ZETAS_MONT) == 128
    assert all(0 <= z < Q for z in m.ZETAS)
    assert all(0 <= z < Q for z in m.ZETAS_MONT)
    print("[1] all 256 twiddle factors are canonical in [0, q)")

    # 2. strict rejection
    for bad in (-1, Q, Q + 1, 1 << 40):
        for fn in (m.ntt, m.inv_ntt):
            try:
                fn([bad] + [0] * (N - 1))
            except m.CoefficientRangeError:
                pass
            else:
                raise AssertionError(f"{fn.__name__} accepted {bad}")
    print("[2] out-of-range coefficients are rejected (CoefficientRangeError)")

    trials = 300
    for _ in range(trials):
        a = [rng.randrange(Q) for _ in range(N)]
        b = [rng.randrange(Q) for _ in range(N)]

        a_hat = m.ntt(a)
        # 3. exact round trip
        assert m.inv_ntt(a_hat) == a
        # 4. pointwise == negacyclic convolution
        assert m.inv_ntt(m.pointwise_mul(a_hat, m.ntt(b))) == m.negacyclic_convolution(a, b)

    print(f"[3] inverse NTT round-trips exactly over {trials} random polynomials")
    print(f"[4] pointwise product == schoolbook negacyclic convolution over {trials} pairs")
    print("ALL VERIFICATION CHECKS PASSED")


if __name__ == "__main__":
    main()

Why it is correct

  • Twiddle generation. 17 is a primitive 256-th root of unity mod 3329 (17^128 = -1, 17^256 = 1). The table is computed, not hard-coded, and every value is reduced mod q, so it is canonical by construction.
  • Forward NTT. Each butterfly computes t = fqmul(zeta_M, r[j+len]). Since zeta_M = zeta * 2^16 mod q, fqmul returns zeta * r[j+len] mod q, i.e. the forward map is the genuine NTT with no stray R factor. Barrett reduction keeps running sums bounded; the result is re-canonicalised.
  • Inverse NTT. The mirrored (Gentle-Sande) network with the same twiddles is the adjoint of the forward network; on its own it produces 128 * f. Multiplying by 128^-1 (carried through fqmul as 128^-1 * 2^16 mod q) yields the exact inverse.
  • Pointwise stage. The pair at index 2p is f mod (x^2 - r_p) with r_p = (-1)^(p mod 2) * 17^(2*bitrev6(p//2)+1). Multiplying the two CRT images componentwise is exactly multiplication in Z_q[x]/(x^256+1), hence it matches the schoolbook negacyclic convolution.
  • Validation. _check_poly verifies length, integer type, and the range 0 <= c < q before any reduction is attempted.
