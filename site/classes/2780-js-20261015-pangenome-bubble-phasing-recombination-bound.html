Pangenome Bubble Phasing under a Recombination Bound — Exact Decomposition, Certificate, and Infeasibility Witness

Problem class: js-20261015-pangenome-bubble-phasing-recombination-bound · Runtime: Node.js 20+ (zero external dependencies)

1. What the problem actually is

Given a bidirected variation graph, allele-support counts, phased-read constraints (links asserting two alleles are on the same or opposite haplotype), and a recombination budget K, produce a globally consistent diploid haplotype decomposition that maximises supported sequence and, among all optimal-support solutions, minimises phase switches subject to switches <= K. Handle nested snarls, ambiguous orientation, cycles; return a verifiable optimality certificate or a minimal infeasibility witness.

A snarl (bubble) is a subgraph with exactly two boundary sides and no path between them leaving the subgraph. Snarls decompose a bidirected graph into a tree of nested bubbles plus chains. The structural fact that makes this tractable:

Once decomposed into its snarl tree, phasing is a tree-structured binary optimisation (weighted Max-2SAT / Ising on a tree) with a cardinality constraint on "switched" tree edges.

The difficulty is not the objective — it is (a) building the snarl tree and (b) handling non-tree read links with the budget exactly.

2. Root-cause analysis — why the obvious approaches fail

# Naive approach Failure
2.1 Enumerate all source→sink paths, pick two Path count is exponential; nested snarls multiply and cycles give infinitely many walks.
2.2 Greedy / per-site read majority Read links span bubbles, so local choices are globally inconsistent and can violate the budget by an unbounded amount; not optimal.
2.3 Ignore orientation / wrong strand de-dup A bidirected graph encodes each locus twice; without canonicalising by underlying node set, sites are double-counted and same/opposite parity is wrong.
2.4 Assume a DAG Inversions/repeats form cycles; a DAG-only method loops or silently drops them.
2.5 Treat budget as a soft penalty The budget is a hard cardinality constraint; a penalty can exceed K and cannot distinguish infeasible from expensive.
2.6 Return a solution with no proof No certificate ⇒ cannot know it is optimal; no witness ⇒ cannot explain infeasibility.

Root cause: forcing the solver to reason over paths explodes the state space. The fix is to reason over the snarl tree — one boolean per snarl — and solve the budgeted weighted Max-2SAT exactly by tree DP (tree edges) + branch-and-bound (cross edges). This never enumerates paths.

3. The fix — algorithm

3.1 Decomposition

  1. Bidirected → handle graph: replace node v by handles v+,v-; edge (a,oa)-(b,ob) yields arcs a_oa → b_ob and b_~ob → a_~oa.
  2. Cycles: Tarjan SCC + condensation; each non-trivial SCC becomes one complex snarl, never expanded.
  3. Bubbles: find all simple single-entry/single-exit superbubbles (internal in/out degree = 1) on the condensation DAG; they are laminar.
  4. Canonicalise strands: collapse reverse-complement duplicates by underlying node-name set.
  5. Reads: map each endpoint to its innermost snarl; emit soft (weighted) or hard parity links.

3.2 Model

One phase bit x_u ∈ {0,1} per snarl. Maximise

Σ_u support[u][x_u] + Σ_tree coupling[x_u][x_v] + Σ_soft w·[x_a XOR x_b = rel]
subject to  Σ_(u,parent) [x_u ≠ x_parent] ≤ K

coupling matrices absorb ambiguous orientation (diagonal = same, off-diagonal = opposite). Among optimal-support assignments, minimise switches (lexicographic).

3.3 Exact tree DP with budget

f_u[x][k] = best value in subtree u with phase x and exactly k switches, merging children by knapsack convolution; a switch x≠x_c costs 1. Answer = max_{x,k≤K} f_root[x][k]. Polynomial in n·K; iterative post-order avoids stack overflow. Never sees the path count.

3.4 Cross links: exact branch-and-bound

Fix the endpoints of every non-tree read link; the rest is solved optimally by the tree DP. Prune only when treeDP + Σ un-negotiated soft weights < incumbent — a valid upper bound, so the final incumbent is a global optimum.

3.5 Certificate & witness

Optimality: value = exact lower bound + search statistics. Infeasibility: deletion-minimal unsatisfiable core of the hard links (covers contradictory constraints and budget-induced infeasibility).

3.6 Complexity

O(V+E) handle/SCC · O(V²) simple superbubbles (snarl-scale) · O(n·K)–O(n·K²) tree DP · O(2^c) cross-link B&B (c = cross endpoints, usually 0). The path count never appears.

4.1 phasing-solver.js

'use strict';
const NEG = -Infinity;

function buildTree(inst) {
  const nodes = inst.nodes;
  const children = {};
  const parent = {};
  for (const id of Object.keys(nodes)) children[id] = [];
  for (const e of inst.edges || []) {
    if (!(e.parent in children)) throw new Error('unknown tree parent: ' + e.parent);
    if (!(e.child in nodes)) throw new Error('unknown tree child: ' + e.child);
    children[e.parent].push({ child: e.child, coupling: e.coupling || null });
    parent[e.child] = e.parent;
  }
  return { nodes, children, parent, root: inst.root };
}

function treeDP(inst, fixed, K) {
  fixed = fixed || {};
  const T = buildTree(inst);
  const store = new Map();
  const supportOf = (id) => (T.nodes[id].support || [0, 0]);

  // Iterative post-order: arbitrarily deep chains cannot overflow the stack.
  const order = [];
  const stack = [{ u: T.root, phase: 0 }];
  while (stack.length) {
    const top = stack[stack.length - 1];
    if (top.phase === 0) {
      top.phase = 1;
      for (const { child } of T.children[top.u]) stack.push({ u: child, phase: 0 });
    } else { order.push(top.u); stack.pop(); }
  }

  for (const u of order) {
    const su = supportOf(u);
    let f = [[], []];
    let choices = [[], []];
    for (let x = 0; x < 2; x++) {
      if (fixed[u] !== undefined && fixed[u] !== x) continue;
      f[x][0] = su[x]; choices[x][0] = null;
    }
    for (const { child, coupling } of T.children[u]) {
      const g = store.get(child);
      const nf = [[], []], nc = [[], []];
      for (let x = 0; x < 2; x++) {
        if (fixed[u] !== undefined && fixed[u] !== x) continue;
        const fx = f[x]; if (!fx) continue;
        for (let k = 0; k < fx.length; k++) {
          if (fx[k] === undefined) continue;
          for (let xc = 0; xc < 2; xc++) {
            if (fixed[child] !== undefined && fixed[child] !== xc) continue;
            const gc = g.f[xc]; if (!gc) continue;
            const flip = x === xc ? 0 : 1;
            for (let kc = 0; kc < gc.length; kc++) {
              if (gc[kc] === undefined) continue;
              const kk = k + kc + flip;
              if (kk > K) continue;
              const v = fx[k] + (coupling ? coupling[x][xc] : 0) + gc[kc];
              if (nf[x][kk] === undefined || v > nf[x][kk]) {
                nf[x][kk] = v;
                nc[x][kk] = { child, x: xc, k: kc, rest: choices[x][k] };
              }
            }
          }
        }
      }
      f = nf; choices = nc;
    }
    store.set(u, { f, choices });
  }

  const rootRes = store.get(T.root);
  let best = NEG, bx = -1, bk = -1;
  for (let x = 0; x < 2; x++) {
    const fx = rootRes.f[x]; if (!fx) continue;
    for (let k = 0; k < fx.length; k++) {
      if (fx[k] === undefined) continue;
      if (fx[k] > best || (fx[k] === best && (bk < 0 || k < bk))) { best = fx[k]; bx = x; bk = k; }
    }
  }
  if (bx < 0) return { best: NEG, flips: Infinity, assign: null };

  const assign = {};
  const work = [{ u: T.root, x: bx, k: bk }];
  while (work.length) {
    const { u, x, k } = work.pop();
    assign[u] = x;
    let p = store.get(u).choices[x] && store.get(u).choices[x][k];
    while (p) { work.push({ u: p.child, x: p.x, k: p.k }); p = p.rest; }
  }
  return { best, flips: bk, assign };
}

function crosses(inst) {
  const vars = new Set();
  for (const c of inst.hard || []) { vars.add(c.a); vars.add(c.b); }
  for (const c of inst.soft || []) { vars.add(c.a); vars.add(c.b); }
  return [...vars];
}
function diffOf(a, b) { return a !== b ? 1 : 0; }

function softUpperBound(inst, partial) {
  let ub = 0;
  for (const c of inst.soft || []) {
    const w = c.weight === undefined ? 1 : c.weight;
    if (partial[c.a] !== undefined && partial[c.b] !== undefined) ub += diffOf(partial[c.a], partial[c.b]) === c.rel ? w : 0;
    else if (c.a === c.b) ub += c.rel === 0 ? w : 0;
    else ub += w;
  }
  return ub;
}
function softValue(inst, assign) {
  let v = 0;
  for (const c of inst.soft || []) {
    const w = c.weight === undefined ? 1 : c.weight;
    if (diffOf(assign[c.a], assign[c.b]) === c.rel) v += w;
  }
  return v;
}
function hardSatisfied(inst, assign) {
  for (const c of inst.hard || []) if (diffOf(assign[c.a], assign[c.b]) !== c.rel) return false;
  return true;
}
function feasible(inst, hardSubset, K) {
  const sub = Object.assign({}, inst, { hard: hardSubset, soft: [] });
  const vars = crosses(sub);
  let found = false; const partial = {};
  (function rec(i) {
    if (found) return;
    if (i === vars.length) {
      if (!hardSatisfied(sub, partial)) return;
      if (treeDP(sub, partial, K).best !== NEG) found = true;
      return;
    }
    for (const v of [0, 1]) { partial[vars[i]] = v; rec(i + 1); delete partial[vars[i]]; if (found) return; }
  })(0);
  return found;
}
function minimalWitness(inst, K) {
  let core = (inst.hard || []).slice();
  if (feasible(inst, core, K)) return { infeasible: false, core: [] };
  let changed = true;
  while (changed) {
    changed = false;
    for (let i = 0; i < core.length; i++) {
      const trial = core.slice(0, i).concat(core.slice(i + 1));
      if (!feasible(inst, trial, K)) { core = trial; changed = true; break; }
    }
  }
  return { infeasible: true, core,
    reason: 'No assignment satisfies these ' + core.length + ' read constraint(s) with at most ' + K + ' recombination(s).' };
}

function solve(inst) {
  const K = inst.budget === undefined ? Infinity : inst.budget;
  const vars = crosses(inst);
  let best = null, nodesExplored = 0, rootUpper = null;

  function evaluate(partial) {
    const td = treeDP(inst, partial, K);
    if (td.best === NEG) return null;
    if (!hardSatisfied(inst, partial)) return null;
    return { value: td.best + softValue(inst, partial), flips: td.flips, assign: td.assign };
  }
  function upper(partial) {
    const td = treeDP(inst, partial, K);
    if (td.best === NEG) return NEG;
    for (const c of inst.hard || [])
      if (partial[c.a] !== undefined && partial[c.b] !== undefined && diffOf(partial[c.a], partial[c.b]) !== c.rel) return NEG;
    return td.best + softUpperBound(inst, partial);
  }
  function rec(i, partial) {
    nodesExplored++;
    if (i === vars.length) {
      const r = evaluate(partial);
      if (r && (best === null || r.value > best.value || (r.value === best.value && r.flips < best.flips))) best = r;
      return;
    }
    const ub = upper(partial);
    if (i === 0) rootUpper = ub;
    if (ub === NEG) return;
    if (best !== null && ub < best.value) return;
    for (const v of [0, 1]) { partial[vars[i]] = v; rec(i + 1, partial); delete partial[vars[i]]; }
  }

  if (vars.length === 0) {
    const r = evaluate({});
    if (r) { best = r; rootUpper = r.value; } else rootUpper = NEG;
  } else rec(0, {});

  if (best === null) {
    const witness = minimalWitness(inst, K);
    return { feasible: false, witness,
      certificate: { method: 'tree-DP + branch-and-bound', searchNodes: nodesExplored,
        note: 'infeasible: no phase decomposition within the budget' } };
  }
  return { feasible: true, value: best.value, recombinations: best.flips, budget: K, assignment: best.assign,
    certificate: { method: 'tree-DP + branch-and-bound', searchNodes: nodesExplored,
      upperBoundAtRoot: rootUpper, lowerBound: best.value, provenOptimal: true,
      note: 'The tree DP is exact and branch-and-bound prunes only subtrees whose upper bound is strictly below the incumbent, so the incumbent is a global optimum; among maximum-support decompositions it has the fewest recombinations.' } };
}

function bruteForce(inst) {
  const ids = Object.keys(inst.nodes), T = buildTree(inst);
  const K = inst.budget === undefined ? Infinity : inst.budget, parent = T.parent;
  let best = null;
  for (let mask = 0; mask < (1 << ids.length); mask++) {
    const assign = {};
    for (let i = 0; i < ids.length; i++) assign[ids[i]] = (mask >> i) & 1;
    let flips = 0;
    for (const id of ids) if (parent[id] !== undefined && assign[id] !== assign[parent[id]]) flips++;
    if (flips > K || !hardSatisfied(inst, assign)) continue;
    let val = 0;
    for (const id of ids) val += (inst.nodes[id].support || [0, 0])[assign[id]];
    for (const e of inst.edges || []) if (e.coupling) val += e.coupling[assign[e.parent]][assign[e.child]];
    val += softValue(inst, assign);
    if (best === null || val > best.value || (val === best.value && flips < best.flips)) best = { value: val, flips, assign };
  }
  return best;
}

module.exports = { solve, treeDP, bruteForce, minimalWitness, feasible, buildTree };

4.2 graph.js (bidirected front-end)

'use strict';
const { solve } = require('./phasing-solver');
function flip(o) { return o === '+' ? '-' : '+'; }
function hkey(node, o) { return node + o; }
function parseHkey(k) { return { node: k.slice(0, -1), orient: k.slice(-1) }; }

function handleGraph(graph) {
  const adj = new Map(), radj = new Map();
  const add = (m, a, b) => { if (!m.has(a)) m.set(a, []); m.get(a).push(b); };
  const touch = (k) => { if (!adj.has(k)) adj.set(k, []); if (!radj.has(k)) radj.set(k, []); };
  for (const id of Object.keys(graph.nodes)) { touch(hkey(id, '+')); touch(hkey(id, '-')); }
  for (const e of graph.edges || []) {
    const a = hkey(e.a.node, e.a.orient), b = hkey(e.b.node, e.b.orient);
    touch(a); touch(b); add(adj, a, b); add(radj, b, a);
    const ar = hkey(e.b.node, flip(e.b.orient)), br = hkey(e.a.node, flip(e.a.orient));
    touch(ar); touch(br); add(adj, ar, br); add(radj, br, ar);
  }
  return { verts: [...adj.keys()], adj, radj };
}
function scc(verts, adj) {
  let index = 0; const idx = new Map(), low = new Map(), on = new Set(), stack = [], comps = [];
  (function strong(v) {
    idx.set(v, index); low.set(v, index); index++; stack.push(v); on.add(v);
    for (const w of adj.get(v) || []) {
      if (!idx.has(w)) { strong(w); low.set(v, Math.min(low.get(v), low.get(w))); }
      else if (on.has(w)) low.set(v, Math.min(low.get(v), idx.get(w)));
    }
    if (low.get(v) === idx.get(v)) { const c = []; let w; do { w = stack.pop(); on.delete(w); c.push(w); } while (w !== v); comps.push(c); }
  })(verts[0]);
  for (const v of verts) if (!idx.has(v)) strong(v);
  return comps;
}
function reachSets(verts, adj, topo) {
  const desc = new Map();
  for (let i = topo.length - 1; i >= 0; i--) {
    const v = topo[i], s = new Set([v]);
    for (const w of adj.get(v) || []) { const dw = desc.get(w); if (dw) for (const x of dw) s.add(x); }
    desc.set(v, s);
  }
  return desc;
}
function topoSort(verts, adj) {
  const indeg = new Map(); for (const v of verts) indeg.set(v, 0);
  for (const v of verts) for (const w of adj.get(v) || []) if (indeg.has(w)) indeg.set(w, indeg.get(w) + 1);
  const q = verts.filter((v) => indeg.get(v) === 0), order = [];
  while (q.length) { const v = q.shift(); order.push(v);
    for (const w of adj.get(v) || []) { if (!indeg.has(w)) continue; indeg.set(w, indeg.get(w) - 1); if (indeg.get(w) === 0) q.push(w); } }
  return order.length === verts.length ? order : null;
}
function findSuperbubbles(verts, adj, radj) {
  const topo = topoSort(verts, adj); if (!topo) return { topo: null, bubbles: [] };
  const desc = reachSets(verts, adj, topo), bubbles = [];
  for (const s of topo) for (const t of desc.get(s)) {
    if (t === s) continue;
    const B = new Set();
    for (const v of desc.get(s)) if (v === t || (desc.get(v) && desc.get(v).has(t))) B.add(v);
    if (B.size < 2) continue;
    let ok = true, sOut = 0, tIn = 0;
    for (const v of B) {
      let iIn = 0, iOut = 0, eIn = 0, eOut = 0;
      for (const u of radj.get(v) || []) { if (B.has(u)) iIn++; else eIn++; }
      for (const w of adj.get(v) || []) { if (B.has(w)) iOut++; else eOut++; }
      if (v === s && iIn !== 0) { ok = false; break; }
      if (v !== s && eIn !== 0) { ok = false; break; }
      if (v === t && iOut !== 0) { ok = false; break; }
      if (v !== t && eOut !== 0) { ok = false; break; }
      if (v !== s && v !== t && (iIn !== 1 || iOut !== 1)) { ok = false; break; }
      if (v === s) sOut = iOut; if (v === t) tIn = iIn;
    }
    if (ok && sOut >= 2 && tIn >= 2) bubbles.push({ s, t, set: B });
  }
  return { topo, bubbles };
}

function buildInstance(graph) {
  const { verts, adj } = handleGraph(graph);
  const comps = scc(verts, adj);
  const compOf = new Map(); comps.forEach((c, i) => c.forEach((v) => compOf.set(v, i)));
  const cverts = comps.map((_, i) => 'C' + i), cid = (v) => 'C' + compOf.get(v);
  const cadj = new Map(cverts.map((c) => [c, []])); const carcs = new Set();
  for (const v of verts) for (const w of adj.get(v) || []) {
    const a = cid(v), b = cid(w); if (a === b) continue;
    const k = a + '>' + b; if (carcs.has(k)) continue; carcs.add(k); cadj.get(a).push(b);
  }
  const cradj = new Map(cverts.map((c) => [c, []]));
  for (const [a, bs] of cadj) for (const b of bs) cradj.get(b).push(a);
  const { topo, bubbles } = findSuperbubbles(cverts, cadj, cradj);
  const compNodes = new Map();
  comps.forEach((c, i) => compNodes.set('C' + i, new Set(c.map((h) => parseHkey(h).node))));
  const bubbleNodes = (b) => { const ns = new Set(); for (const comp of b.set) for (const n of compNodes.get(comp) || []) ns.add(n); return ns; };

  if (topo && bubbles.length) {
    const canon = new Map();
    for (const b of bubbles) { const ns = bubbleNodes(b); const key = [...ns].sort().join('\u0000'); if (!canon.has(key)) canon.set(key, { set: b.set, nodeSet: ns }); }
    const items = [...canon.values()];
    items.sort((x, y) => x.nodeSet.size - y.nodeSet.size);
    const parent = items.map(() => -1);
    for (let i = 0; i < items.length; i++) for (let j = i + 1; j < items.length; j++) {
      let inside = true; for (const v of items[i].nodeSet) if (!items[j].nodeSet.has(v)) { inside = false; break; }
      if (inside) { parent[i] = j; break; }
    }
    const nodes = {}, edges = [], idOf = (i) => 'B' + i;
    items.forEach((_, i) => { nodes[idOf(i)] = { support: [0, 0] }; });
    for (let i = 0; i < items.length; i++) if (parent[i] !== -1) edges.push({ parent: idOf(parent[i]), child: idOf(i), coupling: null });
    function innermost(ns) {
      let best = -1;
      for (let i = 0; i < items.length; i++) { let inside = true; for (const v of ns) if (!items[i].nodeSet.has(v)) { inside = false; break; }
        if (inside && (best === -1 || items[i].nodeSet.size < items[best].nodeSet.size)) best = i; }
      return best;
    }
    const soft = [], hard = [];
    for (const r of graph.reads || []) {
      const ca = cid(hkey(r.a, r.aOrient || '+')), cb = cid(hkey(r.b, r.bOrient || '+'));
      if (ca === undefined || cb === undefined) continue;
      const ba = innermost(compNodes.get(ca) || new Set([r.a])), bb = innermost(compNodes.get(cb) || new Set([r.b]));
      if (ba === -1 || bb === -1 || idOf(ba) === idOf(bb)) continue;
      const link = { a: idOf(ba), b: idOf(bb), rel: r.rel, weight: r.weight === undefined ? 1 : r.weight };
      if (r.hard) hard.push(link); else soft.push(link);
    }
    for (const gid of Object.keys(graph.nodes)) {
      const ps = graph.nodes[gid].phaseSupport; if (!ps) continue;
      const ci = innermost(new Set([gid])); if (ci === -1) continue;
      nodes[idOf(ci)].support[0] += ps[0]; nodes[idOf(ci)].support[1] += ps[1];
    }
    const rootId = 'ROOT'; nodes[rootId] = { support: [0, 0] };
    for (let i = 0; i < items.length; i++) if (parent[i] === -1) edges.push({ parent: rootId, child: idOf(i), coupling: null });
    const insideComp = new Set(); for (const b of bubbles) for (const v of b.set) insideComp.add(v);
    for (const c of cverts) if (!insideComp.has(c)) { nodes['T' + c] = { support: [0, 0] }; edges.push({ parent: rootId, child: 'T' + c, coupling: null }); }
    return { root: rootId, nodes, edges, soft, hard, budget: graph.budget === undefined ? Infinity : graph.budget };
  }
  const rootId = 'ROOT', nodes = { [rootId]: { support: [0, 0] } }, edges = [];
  for (const v of cverts) { nodes['T' + v] = { support: [0, 0] }; edges.push({ parent: rootId, child: 'T' + v, coupling: null }); }
  return { root: rootId, nodes, edges, soft: [], hard: [], budget: graph.budget === undefined ? Infinity : graph.budget };
}

6. Correctness argument

  1. Tree DP exact — f_u[x][k] enumerates every child phase and every switch-budget split, so the root max is the true optimum.
