The solution is complete and verified. It lives at ~/bandalign/SOLUTION.md, with the runnable library align.go, tests align_test.go, and go.mod alongside.

What was wrong (root causes found by experiment)

  1. Fixed-diagonal banding silently loses the optimum. A band [i-W, i+W] cannot represent a path whose diagonal offset exceeds W; the DP still reaches (n,m), so the wrong score looks valid.
  2. Recentring on the running maximum alone is unstable. Per-row arg-max drifts through repeats and over-extends on a single large indel, so it can still exclude the true path.
  3. Traceback used the wrong tie-break for gaps. Re-deriving the predecessor with one global M>D>I priority does not reproduce D/I's own extend > open rule; the reconstructed CIGAR no longer summed to the stored score.
  4. -inf + score created fake reachable cells (-536870910 > -536870912), manufacturing bogus tracebacks.
  5. Band clamp order bug: when i-W > m, lo could exceed m and the hi<lo repair pushed hi past m → index-out-of-range panic.
  6. X-drop was presented as an optimum even though a truncated best prefix (empty prefix = 0) can exceed the true global optimum.

The fix

  • Union band: band(i) = [i-W, i+W] ∪ [c-W, c+W], where c is the arg-max column of the previous row. The diagonal window makes optimality provable for any path with offset ≤ W; the recentred window follows larger shifts. Drift is capped at ±3W.
  • Documented deterministic tie-break: match/mismatch > gap-extend > gap-open, with D beating I; the traceback carries the current DP state.
  • Exact -inf guards; correct [0,m] clamping before lo≤hi repair.
  • Honest flags: XDrop, BandLimited, and ProvenOptimal (only full band + no X-drop).

Verification

Full-matrix control: Align(...,0,0) reproduces FullDP exactly (score and CIGAR) over 3000 random pairs. The adversarial gradual-shift case has maxOff=30; AlignFixed(W=12) loses it (15 vs 170) while Align(W=12) recovers the exact optimum. Homopolymers, tandem repeats, long indels, and a 3.26 kb target all match full O(nm) DP; X-drop triggers are flagged non-optimal.
