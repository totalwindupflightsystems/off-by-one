Answer 1

I've written and empirically verified the solution at:

~/SOLUTION-git-worktree-guard-missing-untracked-fixture.md

Summary

Root cause: The gitreins guard runs the whole repo suite (allow_skips=false, test_mode=full). TestROMHandling::test_rom_path_with_spaces needs data/rom/pokemon_red.gb, which is gitignored and untracked — it exists only in the main checkout. git worktree add builds from the committed tree, so fresh wave worktrees never get it. The guard cannot whitelist the failure by design, so the worker stalls with an otherwise complete, verified patch.

Immediate recovery (foreman-direct):

MAIN="$(git -C "$WT" worktree list --porcelain | awk '/^worktree /{print substr($0,10); exit}')"
mkdir -p "$WT/data/rom"
cp -p "$MAIN/data/rom/pokemon_red.gb" "$WT/data/rom/pokemon_red.gb"
git -C "$WT" check-ignore -v -- data/rom/pokemon_red.gb   # stays clean
git -C "$WT" commit -F "$MSGFILE"                         # Tier1 green

Do not re-dispatch the worker — the staged patch was already verified.

Prevention: a tracked .worktree-fixtures manifest plus scripts/provision_worktree_fixtures.sh, invoked from worktree.sh new right after git worktree add. The provisioner copies only gitignored/untracked fixtures, refuses tracked or non-ignored paths, is idempotent, and preserves spaces in paths.

Verification performed

I built a synthetic reproduction of the exact scenario (main checkout + fresh detached worktree) and ran the provisioner extracted directly from the document: - ✅ Reproduced FileNotFoundError in the un-provisioned worktree - ✅ Provisioner copies the fixture; test passes - ✅ Second run is a no-op (0 copied, N already present) - ✅ git status --porcelain stays empty; git ls-files data/rom shows only README - ✅ Tracked manifest entry refused (WARN ... is tracked) - ✅ Non-ignored untracked entry refused with exit 1 - ✅ Paths containing spaces (data/rom dir with spaces/rom two.gb) handled correctly

The final file is self-contained: symptom, root cause, exact commands, drop-in scripts, worktree.sh integration, and a full verification/acceptance checklist.
