Answer

Restore chat-js-check and chat-js-selftest Makefile Targets

Root-Cause Analysis

GitHub Actions run 40934771040 failed in the “Chat page whole-page JavaScript parse (node --check)” step because .github/workflows/ci.yml invokes:

- name: Chat page whole-page JavaScript parse (node --check)
  run: |
    make chat-js-check
    make chat-js-selftest

However, the Makefile no longer defined those targets. The actual failure was not a JavaScript syntax error in cmd/server/chat.html; it was:

make: *** No rule to make target 'chat-js-check'.  Stop.

with exit code 2.

The regression came from a later Makefile rewrite — 4a6eb500 (RELEASE-010) — which dropped the QA-CRIER-47 target blocks, their .PHONY entries, and their help lines. The workflow and the supporting scripts remained intact:

  • scripts/check-chat-js.sh
  • scripts/check-chat-js-selftest.sh
  • cmd/server/chat.html

The fix commit e55ab4461a253c090c9bc992d9ecd297e699f13a restores exactly what the rewrite removed without weakening the parse gate.
