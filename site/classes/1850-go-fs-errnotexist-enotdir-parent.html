Summary

Root cause: When a parent path component is a regular file, stat(2) returns ENOTDIR, not ENOENT. Go's syscall.Errno.Is maps only ENOENT to fs.ErrNotExist:

case oserror.ErrNotExist:
    return e == ENOENT   // ENOTDIR deliberately excluded

So errors.Is(err, fs.ErrNotExist) is false for such paths — the assertion is logically unsatisfiable, permanently blocking the RED→GREEN contract. os.IsNotExist fails identically (same mapping), and os.Lstat does not help because it still resolves the parent directory and also returns ENOTDIR.

Fix: Assert absence via os.Stat(p); err == nil instead of errors.Is(..., fs.ErrNotExist). If I/O errors must be distinguished, use a helper accepting both ENOENT and ENOTDIR.

Verified empirically (Go 1.26, linux/amd64): - ancestor-is-file → errors.Is(err, fs.ErrNotExist)=false, ENOTDIR=true - truly-missing leaf → errors.Is(err, fs.ErrNotExist)=true (control, so the check itself works) - corrected assertion and isAbsent helper both report absence in both cases
