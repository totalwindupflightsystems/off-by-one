Quorum Clock-Skew Reconciliation — Verified Fix

A Node.js coordinator for a quorum-replicated store whose replicas have bounded but unknown clock skew, suffer partial network partitions and delayed acknowledgements, and must survive retries and coordinator failover. The fix replaces untrusted wall-clock last-write-wins with a causality-tracking, conflict-preserving CRDT plus a quorum protocol and a fault-injection test suite.

1. Root-cause analysis

The unsafe behaviour comes from using physical (wall) time to order writes:

  1. Wall clocks are not comparable across replicas. With bounded but unknown skew |offset_i - offset_j| <= E, two updates a and b with timestamps t_a < t_b may still be concurrent, and a causally-later update can carry a smaller timestamp than its cause if the causing replica's clock lags. Any if (t_a < t_b) keep b rule can therefore discard the causally-later write (data loss) or order concurrent writes arbitrarily (a silent, non-deterministic merge). That is the unsafe LWW.
  2. Wall time cannot express causality. Skew only widens the ambiguity. Even with perfect clocks, timestamps do not tell us whether b observed a. There is no evidence to justify overwriting.
  3. Concurrency must not be silently collapsed. When two writers are truly concurrent, choosing one by any fixed rule hides a real conflict. The safe behaviour is to retain both and require application-level reconciliation.
  4. Retries and delayed acks duplicate delivery. Any protocol that is not idempotent double-applies updates, so an accepted update must be safe to deliver any number of times, in any order.
  5. Coordinator-local state breaks failover. If the coordinator caches the "winner" or an ordering, a crash and replacement can disagree, or lose an acknowledged write unless state is reconstructible from the replicas.
  6. Quorums must fail closed. Under a partition that leaves fewer than a quorum reachable, the coordinator must refuse the write rather than ack it unsafely on a minority.

Design consequences

  • Track causality with version vectors (vector clocks) — no wall clock.
  • Store each key as a Multi-Value Register (MV-Register) CRDT that keeps exactly the non-dominated values, so causal evidence is honoured and concurrency is preserved.
  • Pick a preferred value for display with a deterministic total order based on the Lamport logical clock + replica id, never on wall time.
  • Make every mutation an idempotent join so retries and duplicate acks are harmless.
  • Keep the coordinator stateless; all authority lives in the replica CRDTs, and quorums intersect so any replacement coordinator reconstructs the same answer.
  • Add read-repair / anti-entropy so replicas converge after a partition.

2. Exact fix — protocol

Update at origin replica i: entry = { id: "i:seq", origin, key, value, vv: vv_i ++ [i]++, lamport: ++L_i, wall: now() }

Join / apply at any replica: register := prune(register ∪ {entry}), where prune removes any entry whose version vector is causally dominated by another. join is commutative, associative and idempotent — a bounded join-semilattice, so replicas converge regardless of message order, duplication or coordinator crashes.

Read: query a quorum, join all returned registers, resolve with the deterministic order (lamport DESC, origin DESC, id DESC). Report conflict = candidates.length > 1. Read-repair the responders with the merged state.

Write: generate the update at a replica (so its causal context is durable), broadcast it, and only report committed = true after >= quorum acks. Retries reuse the same update id and are idempotent.

Resolution rule (the core of "safe, not LWW"):

Evidence about A vs B Action
A.vv dominates B.vv Keep A (B is causally superseded)
B.vv dominates A.vv Keep B
A.vv == B.vv Same causal past; dedupe by update id
concurrent (neither dominates) Keep both, flag conflict, pick preferred by Lamport/replica-id, never by wall clock

wall is retained only for auditing and is never read by any ordering logic.

src/versionVector.js

'use strict';

/**
 * Version vectors (a.k.a. vector clocks) capture causality without any
 * dependence on wall-clock time. They are the only ordering evidence the
 * coordinator trusts.
 *
 * A vector is a plain object: { [replicaId]: counter }.
 */

function get(vv, id) {
  return vv[id] || 0;
}

function clone(vv) {
  return Object.assign({}, vv);
}

/** Component-wise maximum (the join/lub of the vector-clock lattice). */
function mergeMax(a, b) {
  const out = clone(a);
  for (const k of Object.keys(b)) {
    out[k] = Math.max(out[k] || 0, b[k] || 0);
  }
  return out;
}

function increment(vv, id, by = 1) {
  const out = clone(vv);
  out[id] = (out[id] || 0) + by;
  return out;
}

/**
 * Compare two vectors.
 * Returns:
 *   'equal'      -> same causal past
 *   'dominates'  -> a causally follows b (a >= b component-wise, and strictly in one)
 *   'dominated'  -> b causally follows a
 *   'concurrent' -> neither follows the other; there is NO causal evidence
 */
function compare(a, b) {
  let aGreater = false;
  let bGreater = false;
  const keys = new Set(Object.keys(a).concat(Object.keys(b)));
  for (const k of keys) {
    const av = a[k] || 0;
    const bv = b[k] || 0;
    if (av > bv) aGreater = true;
    else if (bv > av) bGreater = true;
  }
  if (aGreater && bGreater) return 'concurrent';
  if (aGreater) return 'dominates';
  if (bGreater) return 'dominated';
  return 'equal';
}

function dominates(a, b) {
  return compare(a, b) === 'dominates';
}

function concurrent(a, b) {
  return compare(a, b) === 'concurrent';
}

module.exports = { get, clone, mergeMax, increment, compare, dominates, concurrent };

src/mvRegister.js

'use strict';

/**
 * Multi-Value Register (MV-Register), a state-based CRDT.
 *
 * The register keeps every update that is NOT causally dominated by another
 * update. This gives us exactly the required behaviour:
 *
 *   - When causal evidence exists (one write's version vector dominates the
 *     other's), the causally-later value supersedes the earlier one.
 *   - When two writes are concurrent (no evidence), BOTH values are retained
 *     and the read is flagged as a conflict. We never silently drop one using
 *     an untrusted wall clock (no unsafe last-write-wins).
 *
 * `join` is commutative, associative and idempotent, so replicas can exchange
 * state in any order, any number of times, and still converge.
 */

const vv = require('./versionVector');

function prune(entries) {
  const result = [];
  for (let i = 0; i < entries.length; i++) {
    const e = entries[i];
    let dominated = false;
    for (let j = 0; j < entries.length; j++) {
      if (i === j) continue;
      const f = entries[j];
      const cmp = vv.compare(f.vv, e.vv);
      if (cmp === 'dominates') {
        dominated = true;
        break;
      }
      if (cmp === 'equal' && f.id !== e.id && f.id < e.id) {
        // deterministic tie-break for pathological id/vector collision
        dominated = true;
        break;
      }
    }
    if (!dominated) result.push(e);
  }
  return result;
}

function union(entries) {
  const byId = new Map();
  for (const e of entries) byId.set(e.id, e);
  return prune(Array.from(byId.values()));
}

/** Join two register states (each an array of entries). */
function join(a, b) {
  return union(a.concat(b));
}

/** Apply a single entry to a register state. Idempotent. */
function apply(entries, entry) {
  return union(entries.concat([entry]));
}

/**
 * Deterministic total order used only to pick a *preferred* value for display
 * when a conflict exists. It is deliberately based on the Lamport logical
 * clock and replica id -- never on wall time.
 */
function compareEntriesDesc(a, b) {
  if (b.lamport !== a.lamport) return b.lamport - a.lamport;
  if (a.origin !== b.origin) return a.origin < b.origin ? 1 : -1;
  if (a.id !== b.id) return a.id < b.id ? 1 : -1;
  return 0;
}

/**
 * Resolve a register state for a reader.
 * Returns { value, conflict, candidates, winner }.
 */
function resolve(entries) {
  if (!entries || entries.length === 0) {
    return { value: undefined, conflict: false, candidates: [], winner: null };
  }
  const sorted = entries.slice().sort(compareEntriesDesc);
  const winner = sorted[0];
  return {
    value: winner.value,
    conflict: entries.length > 1,
    candidates: sorted.map((e) => ({
      id: e.id,
      origin: e.origin,
      value: e.value,
      lamport: e.lamport,
      wall: e.wall,
      vv: e.vv,
    })),
    winner,
  };
}

module.exports = { prune, union, join, apply, resolve, compareEntriesDesc };

src/replica.js

'use strict';

const vv = require('./versionVector');
const mv = require('./mvRegister');

/**
 * A single replica of the quorum store.
 *
 * State is a map of key -> MV-Register (array of non-dominated entries).
 * Every mutation is a CRDT join, therefore idempotent: replaying an update,
 * or receiving it from two different coordinators, is harmless.
 */
class Replica {
  constructor(id, options = {}) {
    this.id = id;
    this.wallOffset = options.wallOffset || 0; // simulated physical clock error
    this.lamport = 0; // logical clock, used for deterministic display order
    this.vv = {}; // causal context of everything this replica has observed
    this.seq = 0; // local update counter -> globally unique update ids
    this.store = new Map(); // key -> entry[]
    this.applied = new Set(); // idempotency guard
  }

  /** Wall clock, intentionally untrusted. Kept only for auditing. */
  now() {
    return Date.now() + this.wallOffset;
  }

  /** Create (and locally apply) a brand new update at this replica. */
  generate(key, value) {
    this.seq += 1;
    this.lamport += 1;
    const entry = {
      id: `${this.id}:${this.seq}`,
      origin: this.id,
      key,
      value,
      vv: vv.increment(this.vv, this.id),
      lamport: this.lamport,
      wall: this.now(),
    };
    this.apply(entry);
    return entry;
  }

  /**
   * Join an entry into local state. Returns true if the entry was not seen
   * before, false for a duplicate. Either way the join is idempotent.
   */
  apply(entry) {
    const firstTime = !this.applied.has(entry.id);
    this.applied.add(entry.id);
    this.lamport = Math.max(this.lamport, entry.lamport);
    this.vv = vv.mergeMax(this.vv, entry.vv);
    const current = this.store.get(entry.key) || [];
    this.store.set(entry.key, mv.apply(current, entry));
    return firstTime;
  }

  entries(key) {
    return (this.store.get(key) || []).slice();
  }

  /** Full replica snapshot for a key, used for read-repair / anti-entropy. */
  snapshot(key) {
    return {
      id: this.id,
      key,
      entries: this.entries(key),
      vv: vv.clone(this.vv),
      lamport: this.lamport,
    };
  }

  /** Handle an inbound message (sync, in-process). */
  handle(msg) {
    if (msg.type === 'get') {
      return { ok: true, id: this.id, entries: this.entries(msg.key) };
    }
    if (msg.type === 'apply') {
      let changed = false;
      for (const entry of msg.entries) {
        if (this.apply(entry)) changed = true;
      }
      return { ok: true, id: this.id, changed };
    }
    throw new Error(`unknown message type: ${msg.type}`);
  }
}

module.exports = { Replica };

src/network.js — fault injection (partitions, drops, latency/timeouts)

'use strict';

/** Deterministic PRNG so fault-injection runs are reproducible. */
function mulberry32(seed) {
  let a = seed >>> 0;
  return function () {
    a |= 0;
    a = (a + 0x6d2b79f5) | 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

const delay = (ms) => new Promise((r) => setTimeout(r, ms));

/**
 * In-process network with fault injection:
 *   - partial partitions (nodes grouped; cross-group traffic fails)
 *   - probabilistic message drops
 *   - added latency (models delayed acknowledgements)
 *   - a request timeout: a delayed ack that arrives after the timeout is
 *     effectively lost to the caller (retries handle it)
 */
class Network {
  constructor(replicas, options = {}) {
    this.replicas = replicas; // Map id -> Replica
    this.seed = options.seed != null ? options.seed : 1;
    this.rng = mulberry32(this.seed);
    this.dropRate = options.dropRate || 0;
    this.latencyMs = options.latencyMs || 1;
    this.jitterMs = options.jitterMs || 0;
    this.timeoutMs = options.timeoutMs || 25;
    this.groups = new Map(); // node id -> partition group index
    this.stats = { attempted: 0, dropped: 0, blocked: 0, delivered: 0, timedOut: 0 };
  }

  /** Partition the listed groups. Nodes absent from all groups stay isolated. */
  partition(groups) {
    this.groups = new Map();
    groups.forEach((group, idx) => group.forEach((node) => this.groups.set(node, idx)));
  }

  heal() {
    this.groups = new Map();
  }

  isBlocked(from, to) {
    if (from === to) return false;
    const a = this.groups.get(from);
    const b = this.groups.get(to);
    if (a === undefined || b === undefined) return false; // unknown nodes reachable
    return a !== b;
  }

  /** Send one request; resolves with the handler response or rejects on loss/timeout. */
  async request(from, to, msg) {
    this.stats.attempted += 1;
    if (this.isBlocked(from, to)) {
      this.stats.blocked += 1;
      throw new Error(`partitioned: ${from}->${to}`);
    }
    if (this.rng() < this.dropRate) {
      this.stats.dropped += 1;
      throw new Error(`dropped: ${from}->${to}`);
    }
    const latency = this.latencyMs + Math.floor(this.rng() * (this.jitterMs + 1));
    let timer;
    try {
      const result = await Promise.race([
        (async () => {
          await delay(latency);
          const target = this.replicas.get(to);
          if (!target) throw new Error(`no such replica: ${to}`);
          return target.handle(msg);
        })(),
        new Promise((_, reject) => {
          timer = setTimeout(() => {
            this.stats.timedOut += 1;
            reject(new Error(`timeout: ${from}->${to}`));
          }, this.timeoutMs);
        }),
      ]);
      this.stats.delivered += 1;
      return result;
    } finally {
      clearTimeout(timer);
    }
  }

  async broadcast(nodeIds, from, msg) {
    const results = await Promise.allSettled(nodeIds.map((to) => this.request(from, to, msg)));
    return results;
  }
}

module.exports = { Network, mulberry32, delay };

src/antiEntropy.js — convergence / repair

'use strict';

/**
 * Anti-entropy: pairwise exchange of full register state until a fixpoint.
 * Because the MV-Register join is a join-semilattice, this always converges
 * to the same state on every reachable replica regardless of exchange order.
 */
function antiEntropy(replicas, key, rounds = 10) {
  const list = Array.from(replicas.values());
  for (let round = 0; round < rounds; round++) {
    let changed = false;
    for (let i = 0; i < list.length; i++) {
      for (let j = 0; j < list.length; j++) {
        if (i === j) continue;
        const target = list[i];
        const source = list[j];
        const before = JSON.stringify(target.entries(key).map(entryFingerprint));
        for (const entry of source.entries(key)) target.apply(entry);
        const after = JSON.stringify(target.entries(key).map(entryFingerprint));
        if (before !== after) changed = true;
      }
    }
    if (!changed) break;
  }
  return list;
}

function entryFingerprint(e) {
  return [e.id, e.origin, e.key, JSON.stringify(e.value), e.lamport, JSON.stringify(e.vv)];
}

/** Fingerprint of a replica's register state, for convergence assertions. */
function stateFingerprint(replica, key) {
  return JSON.stringify(
    replica
      .entries(key)
      .map(entryFingerprint)
      .sort((a, b) => (JSON.stringify(a) < JSON.stringify(b) ? -1 : 1))
  );
}

module.exports = { antiEntropy, stateFingerprint, entryFingerprint };

src/coordinator.js — stateless quorum coordinator

'use strict';

const mv = require('./mvRegister');
const { delay } = require('./network');

/**
 * Stateless coordinator. It holds NO authoritative state. All state lives in
 * the replicas as a CRDT, so a coordinator can crash at any point and a
 * replacement can reconstruct an identical view by reading a quorum.
 * Quorums intersect, so a committed write is seen by any subsequent quorum
 * read, either directly or via read-repair.
 */
class Coordinator {
  constructor(network, replicaIds, options = {}) {
    this.net = network;
    this.ids = replicaIds.slice();
    this.quorum =
      options.quorum != null ? options.quorum : Math.floor(this.ids.length / 2) + 1;
    this.readRetries = options.readRetries != null ? options.readRetries : 3;
    this.writeRetries = options.writeRetries != null ? options.writeRetries : 5;
  }

  async read(key, options = {}) {
    const repair = options.repair !== false;
    let replies = [];
    for (let attempt = 0; attempt <= this.readRetries; attempt++) {
      const results = await this.net.broadcast(this.ids, 'coordinator', { type: 'get', key });
      replies = results.filter((r) => r.status === 'fulfilled').map((r) => r.value);
      if (replies.length >= this.quorum) break;
      if (attempt < this.readRetries) await delay(1);
    }
    if (replies.length < this.quorum) {
      const err = new Error(
        `quorum read failed for "${key}": ${replies.length}/${this.quorum} replies`
      );
      err.code = 'QUORUM_UNAVAILABLE';
      throw err;
    }

    let entries = [];
    for (const reply of replies) entries = mv.join(entries, reply.entries);
    const resolved = mv.resolve(entries);

    if (repair && entries.length > 0) {
      await this.net.broadcast(replies.map((r) => r.id), 'coordinator', {
        type: 'apply',
        entries,
      });
    }

    return {
      key,
      value: resolved.value,
      conflict: resolved.conflict,
      candidates: resolved.candidates,
      winner: resolved.winner,
      responses: replies.length,
      quorum: this.quorum,
    };
  }

  async write(key, value, options = {}) {
    const originId = options.originId || this.ids[0];
    const origin = this.net.replicas.get(originId);
    if (!origin) throw new Error(`unknown origin replica: ${originId}`);

    const entry = origin.generate(key, value);

    let acks = 0;
    let attempts = 0;
    for (let attempt = 0; attempt <= this.writeRetries; attempt++) {
      attempts += 1;
      const results = await this.net.broadcast(this.ids, 'coordinator', {
        type: 'apply',
        entries: [entry],
      });
      acks = results.filter((r) => r.status === 'fulfilled').length;
      if (acks >= this.quorum) {
        return { committed: true, entry, acks, attempts, quorum: this.quorum };
      }
      if (attempt < this.writeRetries) await delay(1);
    }
    return { committed: false, entry, acks, attempts, quorum: this.quorum };
  }
}

module.exports = { Coordinator };

src/cluster.js — cluster factory

'use strict';

const { Replica } = require('./replica');
const { Network } = require('./network');
const { Coordinator } = require('./coordinator');

function makeCluster(n, opts = {}) {
  const ids = opts.ids || Array.from({ length: n }, (_, i) => `r${i + 1}`);
  const replicas = new Map();
  ids.forEach((id, i) => {
    replicas.set(
      id,
      new Replica(id, { wallOffset: (opts.wallOffsets && opts.wallOffsets[i]) || 0 })
    );
  });

  const network = new Network(replicas, opts);
  const coordinators = [];
  const newCoordinator = (cOpts = {}) => {
    const c = new Coordinator(network, ids, { quorum: opts.quorum, ...cOpts });
    coordinators.push(c);
    return c;
  };

  return { ids, replicas, network, newCoordinator, coordinators };
}

module.exports = { makeCluster };

src/index.js — runnable demonstration (npm run demo)

'use strict';

const { makeCluster } = require('./cluster');
const { antiEntropy, stateFingerprint } = require('./antiEntropy');

async function main() {
  const cluster = makeCluster(5, { seed: 42, latencyMs: 1, jitterMs: 1 });
  const { replicas, network, newCoordinator, ids } = cluster;
  const coord = newCoordinator();
  const KEY = 'account:42';

  console.log('== Scenario 1: causal overwrite ==');
  await coord.write(KEY, { balance: 100 }, { originId: 'r1' });
  await coord.write(KEY, { balance: 150 }, { originId: 'r1' });
  let r = await coord.read(KEY);
  console.log('value =', r.value, 'conflict =', r.conflict);

  console.log('\n== Scenario 2: concurrent committed writes ==');
  const KEY2 = 'config:mode';
  const a = replicas.get('r1').generate(KEY2, 'A');
  for (const id of ['r1', 'r2', 'r3']) replicas.get(id).apply(a);
  const b = replicas.get('r4').generate(KEY2, 'B');
  for (const id of ['r3', 'r4', 'r5']) replicas.get(id).apply(b);
  network.heal();
  antiEntropy(replicas, KEY2);
  const coordC = newCoordinator();
  r = await coordC.read(KEY2);
  console.log('value =', r.value, 'conflict =', r.conflict);
  console.log('candidates =', r.candidates.map((c) => `${c.origin}:${JSON.stringify(c.value)}`));

  console.log('\n== Scenario 3: quorum unavailable is refused ==');
  network.partition([
    ['coordinater', 'r1', 'r2'],
    ['r3', 'r4', 'r5'],
  ]);
  const w = await coord.write('danger:key', 'unsafe', { originId: 'r1' });
  console.log('committed =', w.committed, 'acks =', w.acks, 'quorum =', w.quorum);

  console.log('\n== Scenario 4: heal, converge, failover ==');
  network.heal();
  antiEntropy(replicas, KEY);
  antiEntropy(replicas, KEY2);
  antiEntropy(replicas, 'danger:key');
  const fingerprints = ids.map((id) => stateFingerprint(replicas.get(id), KEY2));
  console.log('all replicas converged =', new Set(fingerprints).size === 1);
  const coordD = newCoordinator();
  const r2 = await coordD.read(KEY2);
  console.log('replacement coordinator value =', r2.value, 'conflict =', r2.conflict);
  console.log('same answer as previous coordinator =', JSON.stringify(r) === JSON.stringify(r2));

  console.log('\n== Scenario 5: causal reconciliation wins ==');
  await coordD.write(KEY2, 'C', { originId: 'r3' });
  antiEntropy(replicas, KEY2);
  r = await coord.read(KEY2);
  console.log('value =', r.value, 'conflict =', r.conflict);
}

main().catch((e) => {
  console.error(e);
  process.exit(1);
});

'use strict';

const test = require('node:test');
const assert = require('node:assert');
const vv = require('../src/versionVector');
const mv = require('../src/mvRegister');

test('version vector: causal comparisons', () => {
  assert.equal(vv.compare({ a: 1 }, { a: 1 }), 'equal');
  assert.equal(vv.compare({ a: 2 }, { a: 1 }), 'dominates');
  assert.equal(vv.compare({ a: 1 }, { a: 2 }), 'dominated');
  assert.equal(vv.compare({ a: 1 }, { b: 1 }), 'concurrent');
  assert.equal(vv.compare({ a: 2, b: 1 }, { a: 1, b: 2 }), 'concurrent');
  assert.equal(vv.compare({ a: 2, b: 2 }, { a: 1, b: 2 }), 'dominates');

test('mv-register: join is commutative, associative, idempotent', () => {
  const e1 = { id: 'a:1', origin: 'a', key: 'k', value: 1, vv: { a: 1 }, lamport: 1 };
  const e2 = { id: 'b:1', origin: 'b', key: 'k', value: 2, vv: { b: 1 }, lamport: 1 };
  const e3 = { id: 'c:1', origin: 'c', key: 'k', value: 3, vv: { c: 1 }, lamport: 2 };

  const ab = mv.join([e1], [e2]);
  const ba = mv.join([e2], [e1]);
  assert.deepEqual(ab.map((e) => e.id).sort(), ba.map((e) => e.id).sort());

  const left = mv.join(mv.join([e1], [e2]), [e3]);
  const right = mv.join([e1], mv.join([e2], [e3]));
  assert.deepEqual(left.map((e) => e.id).sort(), right.map((e) => e.id).sort());

  assert.equal(mv.join(ab, ab).length, ab.length); // idempotent
});

  const e1 = { id: 'a:1', origin: 'a', key: 'k', value: 'old', vv: { a: 1 }, lamport: 1 };
  const e2 = { id: 'a:2', origin: 'a', key: 'k', value: 'new', vv: { a: 2 }, lamport: 2 };

test('mv-register: concurrent writes kept and flagged; resolution ignores wall clock', () => {
  const early = { id: 'a:1', origin: 'a', key: 'k', value: 'A', vv: { a: 1 }, lamport: 1, wall: 1 };
  const late = { id: 'b:1', origin: 'b', key: 'k', value: 'B', vv: { b: 1 }, lamport: 1, wall: 9e15 };
  const joined = mv.join([early], [late]);
  assert.equal(joined.length, 2);
  const r1 = mv.resolve(joined);
  assert.equal(r1.conflict, true);
  assert.equal(r1.candidates.length, 2);

  assert.equal(swapped.value, r1.value);
  assert.deepEqual(swapped.candidates.map((c) => c.id), r1.candidates.map((c) => c.id));
});

test('mv-register: causally-later write wins even with a smaller wall clock', () => {

  const next = { id: 'a:2', origin: 'a', key: 'k', value: 'B', vv: { a: 2 }, lamport: 6, wall: 1 };

  assert.equal(r.value, 'B');
  assert.equal(r.conflict, false);

5. Safety argument

  • Causal order preserved. If B observed A, then A.vv < B.vv, so A is pruned; the causally-later value is the only candidate. This holds regardless of wall-clock skew.
  • No unsafe LWW. Concurrent values are never discarded by a clock-based rule; both remain as candidates and the read is marked conflict.
  • Determinism. resolve is a pure function of the candidate set; wall time is not an input. Any coordinator, before or after failover, returns the same value and candidate ordering.
  • Idempotent under retries. All mutations are joins; duplicate entries are identical and re-joining changes nothing.
  • Failover safe. Coordinators keep no authoritative state. A write commits only after a quorum acks, and any later read quorum intersects the write quorum, so the committed entry is observed (or read-repaired) by the new coordinator.
  • Convergence. The MV-Register with prune is a join-semilattice; pairwise anti-entropy reaches a fixpoint identical on every reachable replica.
  • Fail-closed quorums. If fewer than quorum replicas respond, the coordinator raises QUORUM_UNAVAILABLE / returns committed: false instead of acknowledging an unsafe write.
