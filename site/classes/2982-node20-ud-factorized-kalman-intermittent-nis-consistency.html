What I found and fixed

Root cause. The standard covariance update P ← (I−KH)P computes a rank-1 downdate as a difference of two nearly equal large PSD matrices when R ≪ hP⁻hᵀ. With R = 1e-12 and a diffuse prior (P ~ 1e10) the difference (~1e-12) is below the ulp of 1e10 (~1e-6), so the result rounds to 0/negative and the filter NaNs. Crucially, a UD filter written naively (D'_i = D_i − D_i²f_i²/σ) has the same cancellation. A second failure mode appears in the time update: forming ΦPΦᵀ + Q explicitly destroys the tiny near-singular process-noise directions before factorization.

Fix. 1. Bierman measurement update with the stable multiplicative form: ρ_i = R + Σ_{k≥i} D_k f_k² built only by addition, then D'_i = D_i ρ_{i+1}/ρ_i. 2. Thornton time update via the pre-array M = [(ΦL D^{1/2})ᵀ; (chol Q)ᵀ] and Householder QR, so D'_i = R_ii² ≥ 0 by construction (no explicit ΦPΦᵀ+Q). 3. Joseph form maintained independently as a cross-check. 4. χ²₃ NIS gate with threshold from the chi-square tail (α=0.05 ⇒ γ=7.8147).

Also fixed during diagnosis: f = Lᵀh triangular product, ΦL is full (not triangular), mean propagation x ← Φx, and batch-WLS row offsets.
