Landlock Layered-Ruleset Rights Intersection — Root-Cause Analysis and Fix

Problem class: shell-landlock-layered-ruleset-rights-intersection Environment: bash 5.3.9 / jq 1.8.1 / Linux

1. What is asked

Given nested Landlock domains where each layer declares a handled right set and per-path allow grants, compute the matrix a process retains after all domains stack. A right is allowed only if every domain on the root→leaf chain both handles and grants it; anything unhandled stays denied; a child may only narrow. Exit non-zero if a child handles a right its parent never handled.

2. Root-cause analysis

The core invariant that naive implementations get wrong is intersection, not union:

effective(p, r) = ⋀ over L in root..leaf [ r ∈ handled(L) ∧ r ∈ allow(L, p) ]
widening guard:  ∀ child C with parent P : handled(C) ⊆ handled(P)
Bug Consequence Correct rule
Union allow lists across layers A child restores a right an ancestor removed (widening) Intersect; all layers must grant
Treat unhandled right as inherited/unrestricted Silently re-enables a right the parent never handled granted = (r ∈ handled) ∧ (r ∈ allow), so unhandled ⇒ denied
Attribute denial to the deepest layer Reports a redundant denier, not the root cause Report the topmost denying layer (the minimal cause set on a linear stack)
Only compare per-path grants for widening Misses the real widening signal — the handled set Reject handled(child) ⊄ handled(parent)
Ignore parent topology Cycles/missing parents/multiple roots hang or drop layers Validate: unique names, known parents, acyclic, exactly one root

3. The fix

landlock_intersect.sh validates the layer forest, enforces handled(child) ⊆ handled(parent), and computes one effective matrix per leaf domain, tracking denied_by plus minimal_deniers (the topmost denier(s)). Rights outside the handled union are reported unhandled: true with no responsible layer.

./landlock_intersect.sh -i rules.json            # human-readable matrix
./landlock_intersect.sh -i rules.json -o json    # machine-readable
cat rules.json | ./landlock_intersect.sh -o json # stdin
