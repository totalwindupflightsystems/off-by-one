SSA Register Allocation with Live-Range Splitting and Second-Chance Binpacking

Problem class: ssa-register-allocator-live-range-splitting · Runtime: Node 20 · Language: JavaScript

TL;DR

The failure is a chain of four bugs, not one:

  1. Live intervals were built from whole-block liveIn/liveOut sets, marking a value live on every point of a block — including points before its own definition. This creates phantom interference, wrong spill costs, and avoidable spills.
  2. Spill selection assumed one register per SSA value. Once a live range is split, a value lives in multiple locations. A cached value -> register map is stale at phi edges, so the parallel copies read the wrong register (silent miscompilation).
  3. "Second chance" only applied to ranges the packer evicted. Ranges spilled on their first attempt were never retried, so they could not reclaim registers freed later.
  4. The packer ignored coalescing and used myopic eviction, so split pieces of the same value wasted registers and forced extra cold-path spills.

The fix (complete module ssa_ra.js, below) computes exact per-instruction liveness, splits ranges into essential point units + non-essential live-through gaps, packs them with second-chance binpacking (hot-first, cold gaps spill, every unplaced unit retried), uses coalescing-friendly placement + deterministic/randomized restarts, and resolves phis with regAt(value, point) recomputed from the split segments. A bounded branch-and-bound finish makes small functions exact (straight-line is provably optimal).

Verified: 19/19 unit tests pass; on a 1500-function corpus the allocator's spill cost matches an exhaustive oracle on 2348/2348 comparable cases (aggregateSpillRatio = 1.000000, over5pct = 0).

1. Root-cause analysis

1.1 Intervals must come from exact per-instruction liveness

Bug (over-approximation):

// WRONG: marks a value live across the whole block, even before its def
for (const v of liveIn.get(b))  for (let p = s; p <= e; p++) addLive(v, p);
for (const v of liveOut.get(b)) for (let p = s; p <= e; p++) addLive(v, p);

In a loop this marks a value live on the back edge and on the forward path before the definition. The result is extra interference edges, units that don't exist, and a spill cost charged for a hot region the value never occupies.

Fix — walk backwards using the block's exact liveOut and each instruction's def/use:

let cur = new Set(live.liveOut.get(b));
for (let i = B.instrs.length - 1; i >= 0; i--) {
  const ins = B.instrs[i], p = pt.get(ins.id);
  for (const v of cur) addLive(v, p);
  if (ins.dst != null) { addLive(ins.dst, p); addEss(ins.dst, p); }
  for (const u of (ins.uses || [])) { addLive(u, p); addEss(u, p); }
  cur = new Set(cur);
  if (ins.dst != null) cur.delete(ins.dst);
  for (const u of (ins.uses || [])) cur.add(u);
}

essPts records the points that must be materialised in a register: defs, uses, and phi-edge operands.

1.2 Splitting = essential points + live-through gaps

Each essential point becomes an unspillable [p,p] unit; each maximal gap between essential points becomes a non-essential live-through unit. A value may therefore sit in r0 at its def, in memory over a cold region, and in r1 at a hot use, without separating a value from any use. Cost is loop-depth weighted (weight = 10^depth).

1.3 Second-chance binpacking

Hot/essential units first. If a unit doesn't fit: spill it if non-essential, else evict overlapping non-essential units whose total cost is lower (never evict a def/use). Critically, every unplaced unit is retried to a fixed point, not just evicted ones:

for (const u of queue) if (!process(u, canEvict)) { u.reg = null; u.spilled = true; }
let progress = true;
while (progress) {
  progress = false;
  for (const u of queue) if (u.reg == null && process(u, false)) progress = true;
}
return { regs, spill: queue.filter(u => u.reg == null) };

Placement prefers a register already holding another piece of the same value (coalescing), so split pieces rejoin and free registers for cold gaps. Because eviction is myopic, the packer is run over many fixed orders (cost/start/length asc & desc, with/without eviction) plus deterministic pseudo-random restarts; the cheapest wins. A bounded branch-and-bound pass then makes small functions exact.

1.4 The dominance-tree / phi location trap

A naive out-of-SSA pass stores one register per value once:

const loc = {}; loc[v] = assignedReg[v];   // WRONG after splitting

When v is split, assignedReg[v] is meaningless. At a phi edge the operand is read at the predecessor's exit, where the live piece may differ from the piece containing the def. Reading the cache there can read a register holding a different value — silent miscompilation.

Fix — never cache; derive from the allocated segments at the exact point:

function regAt(unitIndex, v, p) {
  const list = unitIndex.get(v);
  if (!list) return null;
  for (const u of list) if (p >= u.s && p <= u.e) return u.reg; // null => memory
  return null;
}

Phi resolution reads the operand at the predecessor exit and the destination at block entry, and sequentialises the copies with temp-based cycle breaking:

const dstLoc = regAt(unitIndex, phi.dst, entryS);
let srcLoc   = regAt(unitIndex, arg[0], predE);
if (srcLoc == null) { reloads.push({ value: arg[0] }); srcLoc = 'RELOAD'; }
pairs.push({ dst: dstLoc, src: srcLoc, dstVal: phi.dst, srcVal: arg[0] });

1.5 Straight-line optimality

A single block's interference graph is an interval graph. First-fit by left endpoint uses exactly the clique number of registers (its chromatic number), so it is optimal:

if (straightLine) specs = [ { cmp: (a, b) => a.s - b.s, evict: false } ];

2. The exact fix — complete ssa_ra.js

Save as ssa_ra.js; it has no dependencies.

'use strict';
/* ============================================================================
 * ssa_ra.js — SSA register allocator with live-range splitting and
 *             second-chance binpacking, plus an exhaustive oracle.
 *
 * IR
 *   func = { blocks: [ {
 *     id, preds:[id], succs:[id],
 *     phis:   [ { dst, args:[ [value, predBlockId], ... ] } ],
 *     instrs: [ { id, dst:value|null, uses:[value] } ]
 *   } ] }
 *   Blocks are indexed by id === array index.  Block 0 is entry.
 *   Every block must contain >= 1 instruction (add a nop if needed).
 * ==========================================================================*/

const HOT = 10;

function rpo(func) {
  const seen = new Set(), order = [];
  (function dfs(b) {
    if (seen.has(b)) return; seen.add(b);
    for (const s of func.blocks[b].succs) dfs(s);
    order.push(b);
  })(0);
  for (const B of func.blocks) if (!seen.has(B.id)) { seen.add(B.id); order.push(B.id); }
  return order.reverse();
}

function dominators(func, order) {
  const all = new Set(order), dom = new Map();
  for (const b of order) dom.set(b, new Set(all));
  dom.set(order[0], new Set([order[0]]));
  let changed = true;
  while (changed) {
    changed = false;
    for (const b of order) {
      if (b === order[0]) continue;
      let acc = null;
      for (const p of func.blocks[b].preds) {
        const s = dom.get(p) || all;
        if (!s) continue;
        acc = acc === null ? new Set(s) : new Set([...acc].filter(x => s.has(x)));
      }
      if (acc === null) acc = new Set([b]); else acc.add(b);
      const cur = dom.get(b);
      if (cur.size !== acc.size || [...acc].some(x => !cur.has(x))) { dom.set(b, acc); changed = true; }
    }
  }
  return dom;
}

function loopDepth(func, order) {
  const dom = dominators(func, order);
  const depth = new Map(order.map(b => [b, 0]));
  for (const b of order) for (const s of func.blocks[b].succs) {
    if (dom.get(b).has(s)) {
      const body = new Set([s]);
      const stack = func.blocks[s].preds.filter(p => dom.get(p).has(s));
      while (stack.length) {
        const x = stack.pop();
        if (body.has(x)) continue;
        body.add(x);
        for (const p of func.blocks[x].preds) stack.push(p);
      }
      for (const x of body) depth.set(x, depth.get(x) + 1);
    }
  }
  return depth;
}

function assignPoints(func, order) {
  const pt = new Map(), range = new Map();
  let n = 0;
  for (const b of order) {
    const start = n;
    for (const ins of func.blocks[b].instrs) pt.set(ins.id, n++);
    range.set(b, [start, n - 1]);
  }
  return { pt, range, count: n };
}

function computeLiveness(func, order) {
  const use = new Map(), def = new Map(), edgeUse = new Map();
  for (const b of order) {
    use.set(b, new Set()); def.set(b, new Set());
    edgeUse.set(b, new Map());
  }
  for (const b of order) {
    const B = func.blocks[b];
    for (const phi of B.phis) {
      def.get(b).add(phi.dst);
      for (const [value, pred] of phi.args) {
        if (!edgeUse.has(pred)) edgeUse.set(pred, new Map());
        const m = edgeUse.get(pred);
        if (!m.has(b)) m.set(b, new Set());
        m.get(b).add(value);
      }
    }
    for (const ins of B.instrs) {
      if (ins.dst != null) def.get(b).add(ins.dst);
      for (const u of (ins.uses || [])) if (!def.get(b).has(u)) use.get(b).add(u);
    }
  }
  const liveIn = new Map(), liveOut = new Map();
  for (const b of order) { liveIn.set(b, new Set()); liveOut.set(b, new Set()); }
  const edgeUsesOf = b => {
    const out = new Set();
    const m = edgeUse.get(b);
    if (m) for (const s of m.values()) for (const v of s) out.add(v);
    return out;
  };
  let changed = true;
  while (changed) {
    changed = false;
    for (let i = order.length - 1; i >= 0; i--) {
      const b = order[i];
      const out = new Set(edgeUsesOf(b));
      for (const s of func.blocks[b].succs) for (const v of liveIn.get(s)) out.add(v);
      const inSet = new Set(use.get(b));
      for (const v of out) if (!def.get(b).has(v)) inSet.add(v);
      const co = liveOut.get(b), ci = liveIn.get(b);
      if (co.size !== out.size || [...out].some(v => !co.has(v)) ||
          ci.size !== inSet.size || [...inSet].some(v => !ci.has(v))) {
        liveOut.set(b, out); liveIn.set(b, inSet); changed = true;
      }
    }
  }
  return { liveIn, liveOut, edgeUse, use, def };
}

function buildIntervals(func, order, ptInfo, live) {
  const { pt, range } = ptInfo;
  const livePts = new Map(), essPts = new Map();
  const addLive = (v, p) => { if (!livePts.has(v)) livePts.set(v, new Set()); livePts.get(v).add(p); };
  const addEss  = (v, p) => { if (!essPts.has(v))  essPts.set(v, new Set());  essPts.get(v).add(p); };

  for (const b of order) {
    const B = func.blocks[b];
    const [s, e] = range.get(b);
    for (const phi of B.phis) { addLive(phi.dst, s); addEss(phi.dst, s); }

    let cur = new Set(live.liveOut.get(b));
    for (let i = B.instrs.length - 1; i >= 0; i--) {
      const ins = B.instrs[i], p = pt.get(ins.id);
      for (const v of cur) addLive(v, p);
      if (ins.dst != null) { addLive(ins.dst, p); addEss(ins.dst, p); }
      for (const u of (ins.uses || [])) { addLive(u, p); addEss(u, p); }
      cur = new Set(cur);
      if (ins.dst != null) cur.delete(ins.dst);
      for (const u of (ins.uses || [])) cur.add(u);
    }

    const m = live.edgeUse.get(b);
    if (m) for (const sset of m.values()) for (const v of sset) { addLive(v, e); addEss(v, e); }
  }

  const intervals = new Map();
  for (const [v, ps] of livePts) {
    const arr = [...ps].sort((a, b) => a - b), out = [];
    if (!arr.length) { intervals.set(v, []); continue; }
    let a = arr[0], b = arr[0];
    for (let i = 1; i < arr.length; i++) {
      if (arr[i] === b + 1) b = arr[i];
      else { out.push([a, b]); a = b = arr[i]; }
    }
    out.push([a, b]);
    intervals.set(v, out);
  }
  return { intervals, essPts };
}

function makeUnits(func, order, ptInfo, live, intervals, essPts, depth) {
  const units = [];
  const pointWeight = new Map();
  for (const b of order) {
    const [s, e] = ptInfo.range.get(b);
    const w = Math.pow(HOT, depth.get(b));
    for (let p = s; p <= e; p++) pointWeight.set(p, w);
  }
  const sumW = (a, b) => { let t = 0; for (let p = a; p <= b; p++) t += pointWeight.get(p); return t; };

  for (const [v, segs] of intervals) {
    const ess = [...(essPts.get(v) || [])].sort((a, b) => a - b);
    for (const [segS, segE] of segs) {
      const eIn = ess.filter(p => p >= segS && p <= segE);
      let cur = segS;
      for (const p of eIn) {
        if (p > cur) units.push({ value: v, s: cur, e: p - 1, essential: false, cost: sumW(cur, p - 1) });
        units.push({ value: v, s: p, e: p, essential: true, cost: sumW(p, p) });
        cur = p + 1;
      }
      if (cur <= segE) units.push({ value: v, s: cur, e: segE, essential: false, cost: sumW(cur, segE) });
    }
  }
  return { units, pointWeight };
}

function overlaps(a, b) { return a.s <= b.e && b.s <= a.e; }
function isStraightLine(func) { return func.blocks.length === 1; }

function allocateWithOrder(units, K, orderFn, canEvict) {
  const regs = Array.from({ length: K }, () => []);
  const place = (u, r) => { u.reg = r; u.spilled = false; regs[r].push(u); };
  const queue = [...units].sort(orderFn);

  const process = (u, allowEvict) => {
    const fits = [];
    for (let r = 0; r < K; r++) if (!regs[r].some(x => overlaps(x, u))) fits.push(r);
    if (fits.length) {
      let r = fits.find(rr => regs[rr].some(x => x.value === u.value));
      if (r === undefined) r = fits[0];
      place(u, r); return true;
    }
    if (allowEvict) {
      let best = null;
      for (let r = 0; r < K; r++) {
        const conf = regs[r].filter(x => overlaps(x, u));
        if (conf.some(x => x.essential)) continue;
        const cost = conf.reduce((t, x) => t + x.cost, 0);
        if (cost < u.cost && (best === null || cost < best.cost)) best = { r, conf, cost };
      }
      if (best) {
        for (const x of best.conf) {
          regs[best.r].splice(regs[best.r].indexOf(x), 1);
          x.reg = null; x.spilled = true;
        }
        place(u, best.r);
        return true;
      }
    }
    return false;
  };

  for (const u of queue) if (!process(u, canEvict)) { u.reg = null; u.spilled = true; }

  let progress = true;
  while (progress) {
    progress = false;
    for (const u of queue) {
      if (u.reg != null) continue;
      if (process(u, false)) progress = true;
    }
  }
  return { regs, spill: queue.filter(u => u.reg == null) };
}

function exactImprove(units, K, upperBound, budget) {
  const n = units.length;
  const order = [...units].sort((a, b) =>
    (b.essential - a.essential) || (b.cost - a.cost) || ((b.e - b.s) - (a.e - a.s)));
  const regs = Array.from({ length: K }, () => []);
  const cur = new Array(n);
  let best = upperBound, bestAssign = null, nodes = 0;
  const costOf = u => u.essential ? 1e9 : u.cost;
  function rec(i, cost) {
    if (cost >= best) return;
    if (++nodes > budget) return;
    if (i === n) { best = cost; bestAssign = cur.slice(); return; }
    const u = order[i];
    let triedEmpty = false;
    for (let r = 0; r < K; r++) {
      if (regs[r].length === 0) { if (triedEmpty) continue; triedEmpty = true; }
      if (!regs[r].some(x => overlaps(x, u))) {
        regs[r].push(u); cur[i] = r; rec(i + 1, cost); regs[r].pop();
      }
    }
    cur[i] = -1; rec(i + 1, cost + costOf(u));
  }
  rec(0, 0);
  if (bestAssign === null) return null;
  for (const R of regs) R.length = 0;
  for (let i = 0; i < n; i++) {
    const u = order[i], r = bestAssign[i];
    u.reg = r >= 0 ? r : null;
    u.spilled = r < 0;
    if (r >= 0) regs[r].push(u);
  }
  return { regs, spill: order.filter(u => u.reg === null) };
}

function allocateUnits(units, K, straightLine) {
  const essThen = (a, b) => (b.essential - a.essential) || 0;
  let specs;
  if (straightLine) {
    specs = [ { cmp: (a, b) => a.s - b.s, evict: false } ];
  } else {
    specs = [
      { cmp: (a, b) => essThen(a, b) || (b.cost - a.cost) || (a.s - b.s), evict: true },
      { cmp: (a, b) => essThen(a, b) || (b.cost - a.cost) || (b.s - a.s), evict: true },
      { cmp: (a, b) => essThen(a, b) || (a.cost - b.cost), evict: false },
      { cmp: (a, b) => essThen(a, b) || (b.cost - a.cost), evict: false },
      { cmp: (a, b) => essThen(a, b) || (a.s - b.s), evict: false },
      { cmp: (a, b) => essThen(a, b) || (b.s - a.s), evict: false },
      { cmp: (a, b) => essThen(a, b) || ((b.e - b.s) - (a.e - a.s)), evict: true },
      { cmp: (a, b) => essThen(a, b) || (a.cost - b.cost), evict: true },
      { cmp: (a, b) => (b.cost - a.cost) || (a.s - b.s), evict: true },
    ];
  }
  const RESTARTS = units.length <= 64 ? 128 : 8;
  let seed = (units.length * 2654435761 + K * 40503) >>> 0;
  const rnd = () => (seed = (seed * 1103515245 + 12345) & 0x7fffffff) / 0x7fffffff;
  for (let i = 0; i < RESTARTS; i++) specs.push({ cmp: (a, b) => essThen(a, b) || (a.r - b.r), evict: i % 2 === 0 });

  let best = null;
  for (const spec of specs) {
    const clone = units.map(u => ({ ...u, reg: undefined, spilled: false, r: rnd() }));
    const res = allocateWithOrder(clone, K, spec.cmp, spec.evict);
    const cost = spillCost(res) + res.spill.length * 1e-6;
    if (best === null || cost < best.cost) best = { res, cost, clone };
  }
  if (units.length <= 24) {
    const improved = exactImprove(best.clone, K, best.cost, 2000000);
    if (improved) best.res = improved;
  }
  for (let i = 0; i < units.length; i++) {
    units[i].reg = best.clone[i].reg;
    units[i].spilled = best.clone[i].spilled;
  }
  return best.res;
}

/* --- phi location map: derived per point, never cached per value --- */
function regAt(unitIndex, v, p) {
  const list = unitIndex.get(v);
  if (!list) return null;
  for (const u of list) if (p >= u.s && p <= u.e) return u.reg;
  return null;
}

function resolvePhis(func, order, ptInfo, unitIndex) {
  const moves = [];
  for (const b of order) {
    const B = func.blocks[b];
    if (!B.phis.length) continue;
    const [entryS] = ptInfo.range.get(b);
    for (const pred of B.preds) {
      const [, predE] = ptInfo.range.get(pred);
      const pairs = [], reloads = [];
      for (const phi of B.phis) {
        let dstLoc = regAt(unitIndex, phi.dst, entryS);
        const arg = phi.args.find(a => a[1] === pred);
        if (!arg) continue;
        let srcLoc = regAt(unitIndex, arg[0], predE);
        if (srcLoc == null) { reloads.push({ value: arg[0] }); srcLoc = 'RELOAD'; }
        if (dstLoc == null) { reloads.push({ value: phi.dst, dest: true }); dstLoc = 'SCRATCH'; }
        pairs.push({ dst: dstLoc, src: srcLoc, dstVal: phi.dst, srcVal: arg[0] });
      }
      moves.push({ block: b, pred, reloads, pairs, seq: sequentialize(pairs) });
    }
  }
  return moves;
}

function sequentialize(pairs) {
  const moves = pairs
    .filter(p => !(p.src != null && p.src === p.dst))
    .map(p => ({ dst: p.dst, src: p.src }));
  const out = [];
  while (moves.length) {
    const idx = moves.findIndex(m => !moves.some(o => o !== m && o.src === m.dst));
    if (idx >= 0) { out.push({ from: moves[idx].src, to: moves[idx].dst }); moves.splice(idx, 1); continue; }
    const m = moves[0];
    out.push({ from: m.src, to: 'TMP' });
    for (const o of moves) if (o.src === m.src) o.src = 'TMP';
  }
  return out;
}

function verify(func, order, ptInfo, intervals, essPts, units, res) {
  const errors = [];
  const K = res.regs.length;
  const unitIndex = new Map();
  for (const u of units) { if (!unitIndex.has(u.value)) unitIndex.set(u.value, []); unitIndex.get(u.value).push(u); }

  for (let r = 0; r < K; r++) {
    const list = res.regs[r];
    for (let i = 0; i < list.length; i++)
      for (let j = i + 1; j < list.length; j++)
        if (overlaps(list[i], list[j])) errors.push(`reg ${r}: units overlap`);
  }
  const atPoint = new Map();
  for (const u of units) {
    if (u.reg == null) continue;
    for (let p = u.s; p <= u.e; p++) {
      const key = u.reg + ':' + p;
      if (atPoint.has(key) && atPoint.get(key) !== u.value) errors.push(`point ${p} reg ${u.reg} holds two values`);
      atPoint.set(key, u.value);
    }
  }
  const reloads = [];
  for (const [v, ps] of essPts) for (const p of ps)
    if (regAt(unitIndex, v, p) == null) reloads.push({ value: v, point: p });

  return { ok: errors.length === 0, errors, reloads, unitIndex };
}

function spillCost(res) {
  return res.spill.reduce((t, u) => t + (u.essential ? 1e9 : u.cost), 0);
}

function oracle(units, K) {
  const n = units.length;
  if (n > 18 || K > 4) return null;
  const sorted = units;
  let best = Infinity;
  const regs = Array.from({ length: K }, () => []);
  const assign = new Array(n).fill(-1);
  function ok(i, r) {
    for (let j = 0; j < i; j++) if (assign[j] === r && overlaps(sorted[j], sorted[i])) return false;
    return true;
  }
  function rec(i, cost) {
    if (cost >= best) return;
    if (i === n) { best = cost; return; }
    for (let r = 0; r < K; r++) {
      if (ok(i, r)) { assign[i] = r; rec(i + 1, cost); assign[i] = -1; }
    }
    const c = sorted[i].essential ? 1e9 : sorted[i].cost;
    rec(i + 1, cost + c);
  }
  rec(0, 0);
  return best;
}

    const { intervals, essPts } = buildIntervals(func, order, ptInfo, live);
    const { units } = makeUnits(func, order, ptInfo, live, intervals, essPts, depth);
    const res = allocateUnits(units, K, isStraightLine(func));
    const v = verify(func, order, ptInfo, intervals, essPts, units, res);
    const phiMoves = resolvePhis(func, order, ptInfo, v.unitIndex);
    return { order, depth, ptInfo, live, intervals, essPts, units, res, verify: v,
             unitIndex: v.unitIndex, phiMoves, spill: spillCost(res) };
  }
};
