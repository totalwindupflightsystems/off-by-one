Diagnosis (root cause)

The guarantee "exactly one shared prime pairwise" means gcd(n_i, n_j) is prime for every pair. Since the Paillier moduli are public, one Euclidean algorithm recovers the shared prime, and then every n_i = p·q_i factors, yielding the private (λ_i, μ_i) — so the broadcast aggregate is recoverable with no server handing over a key. The distinct-prime structure {p, q_0…q_{N−1}} is exactly what makes CRT recombination possible, and it also makes the threshold/dropout barrier cosmetic.

Exact fix implemented

  1. pairwise_gcd_graph / factor_moduli — detect the shared-prime graph, validate each edge is prime, fully factor all moduli (star and triangle topologies both verified).
  2. orchestrate — collects honest witnesses m mod n_i or re-derives them locally, then rebuilds the aggregate over the distinct primes with CRT/Lagrange weights; dropouts are filled via the exploit and the CRT path is re-derived.
  3. threshold_check / prove — Lagrange/CRT-weighted certificate: Σ c_i·(x mod m_i) ≡ x (mod M), residue check, witness consistency, exactness, and threshold count.
  4. Hardening snippet — reject any keyring with a non-trivial pairwise GCD and sample independent primes.
