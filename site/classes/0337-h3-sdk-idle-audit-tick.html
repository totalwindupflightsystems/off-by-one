The described tick state is not reproducible on this host: the audited artifact does not exist here. There is no h3_harness package, no fleet.toml, no repo with _run_echo*.py, and no venv with fastapi/uvicorn anywhere on the filesystem. Running a "canonical EchoHarness battery" would therefore be a fabrication — so the correct action is a blocked audit: no battery, no PUT, no state mutation, cooldown preserved. (This is the honest inverse of the pitfall note: the note's port/venv constraints are real here — 8000 is taken, system python lacks fastapi — but the SDK itself is missing.)

Fix 1 — readiness gate that must pass before any battery launch (this is the code I actually ran; it is the first thing the runbook executes):

# /tmp/h3_audit_gate.py (excerpt of the real, executed gate)
import importlib.util, shutil, socket, subprocess, sys

def _spec_ok(m):                                  # find_spec without raising
    try: return importlib.util.find_spec(m) is not None
    except (ImportError, ModuleNotFoundError, AttributeError, ValueError): return False

def _port_free(p):
    with socket.socket() as s:
        try: s.bind(("127.0.0.1", p)); return True
        except OSError: return False

def _uvicorn_py():                                # venv python that *actually* has uvicorn
    for py in ("venv/bin/python", "venv/bin/python3"):
        if shutil.which(py) and subprocess.run([py, "-c", "import uvicorn, fastapi"],
                                               capture_output=True).returncode == 0: return py
    return ""

GATES = [
    ("h3_harness importable",               lambda: _spec_ok("h3_harness")),
    ("canonical h3_harness.examples.echo",  lambda: _spec_ok("h3_harness.examples.echo")),
    ("venv fastapi+uvicorn (not system py)",lambda: _spec_ok("fastapi") and shutil.which("uvicorn")),
    ("free canonical port 8777",            lambda: _port_free(8777)),
]
ok = all(g() for _, g in GATES) and bool(_uvicorn_py())
print("VERDICT:", "BATTERY-RUNNABLE" if ok else "BATTERY-BLOCKED (no PUT, no state change)")

The one thing to get right is the target: the canonical acceptance surface is h3_harness.examples.echo.EchoHarness on :8777 (43/43). The repo-root _run_echo*.py scratch helpers are stale (they fail 40–41/43) and must never be used as a target — this environment confirms that: the leftover /home/kara/.local/bin/h3-test shim imports h3_shim, which is not installed, i.e. it is exactly such a stale scratch artifact.

The "fix" is therefore a guarded no-op that encodes the audit contract:

# audit_tick_44.py — idle-audit no-op (never invoked against stale scratch helpers)
CANONICAL_HARNESS = "h3_harness.examples.echo.EchoHarness"
CANONICAL_PORT = 8777
COOLDOWN_S = 7200

def audit_tick(state: dict) -> dict:
    # fleet.toml-pinned cooldown forbids PUT on this tick
    assert state["cooldown_s"] == COOLDOWN_S, "cooldown must stay pinned"
    assert state["put_allowed"] is False, "no PUT permitted on idle audit"
    assert state["issues"] == 0, "0 issues required for no-op tick"
    # harness target selection is the only thing that must not drift
    assert state["harness"] == CANONICAL_HARNESS and state["port"] == CANONICAL_PORT
    return state  # unchanged: no diff, no PUT
