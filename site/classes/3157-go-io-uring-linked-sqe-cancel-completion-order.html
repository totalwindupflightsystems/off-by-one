Modeling the Linux io_uring Completion Engine: linked SQEs, drain barriers, timeouts, ASYNC and CQE-skip

Problem class: go-io-uring-linked-sqe-cancel-completion-order Environment: go1.26 (linux/amd64) Deliverable: a runnable, tested Go model that folds a trace of SQEs + raw completion events into the exact CQE stream, and rejects malformed traces at the first kernel-order protocol violation.

1. Symptom / problem statement

A naive completion model treats the CQE stream as a permutation of the SQEs: it maps the n-th completion to the n-th submit and copies the result through. On real io_uring that is wrong in several independent ways, and the errors compound:

  • linked chains must be cancelled with -ECANCELED the moment an earlier member fails, even for members that were never started;
  • IOSQE_IO_DRAIN re-orders both issue and completion across a barrier;
  • IORING_OP_LINK_TIMEOUT and IORING_OP_TIMEOUT settle differently (one disarms, one fires);
  • IOSQE_CQE_SKIP_SUCCESS removes a CQE for a successful op but never for a failed one;
  • IOSQE_ASYNC defers a completion out of the synchronous submit pass, changing arrival order;
  • and malformed traces (reused user_data, references to never-issued op ids) must be rejected rather than silently mis-modelled.

2. Root-cause analysis

The single root cause behind all of these is that the CQE stream is not a function of SQE array order — it is a function of the issue order (the SQ array), the link/drain state machine, and the completion arrival order. Any implementation that keys on array position, submit index, or assumes "one SQE ⇒ one synchronous CQE" will diverge. Concretely, the hazards are:

  1. Issue order is the SQ array, not the SQE array. IOSQE_IO_LINK links an SQE to the next entry in the SQ array, so the chain structure cannot be derived from the sqes[] array. A model that links sqes[i] → sqes[i+1] is wrong whenever the two orders differ.

  2. A failed link poisons the rest of the chain. When a member completes with res < 0 (or is failed before running), every remaining member — started or not — settles as -ECANCELED. IOSQE_IO_HARDLINK behaves the same way for this purpose. Members are sequential: the next member only starts after the previous completes.

  3. Drain is a full barrier. A IOSQE_IO_DRAIN request does not start until all earlier-submitted requests complete, and no request submitted after it starts until it completes. This makes drain both an issue and a completion-ordering constraint, so later completions that arrive early must be buffered behind it.

  4. LINK_TIMEOUT vs TIMEOUT.

  5. IORING_OP_TIMEOUT is an ordinary independent request. On expiry it posts res = -ETIME.

  6. IORING_OP_LINK_TIMEOUT must be the immediate successor (in issue order) of the request it times out, and that predecessor must carry IOSQE_IO_LINK; otherwise the kernel fails the link timeout with -EINVAL. If the timer fires first it cancels the target (-ECANCELED) and posts its own -ETIME; if the target completes first the timer is disarmed and the link timeout posts -ECANCELED. (io_uring/timeout.c: io_req_task_link_timeout, io_disarm_next.)

  7. CQE_SKIP_SUCCESS is result-sensitive. It suppresses the CQE only when the terminal res >= 0. A cancelled or failed op (-ECANCELED, -ETIME, …) always posts. The kernel also couples it to drain: once IOSQE_CQE_SKIP_SUCCESS has been used, IO_RING_F_DRAIN_DISABLED is set and a subsequent IOSQE_IO_DRAIN request fails with -EOPNOTSUPP (io_uring/io_uring.c, io_init_req).

  8. ASYNC cannot complete during the submit pass. IOSQE_ASYNC punts the request to io-wq (REQ_F_FORCE_ASYNC), so its CQE can never be emitted in the middle of the synchronous batch.

  9. Exactly one terminal result per op. A raw completion that references a never-issued op id is a protocol violation. Two issued SQEs sharing a user_data is a protocol violation, detected at submission. The first violation in kernel order (submissions before completions; SQ-array order within submissions; event-arrival order within completions) must be reported.

3. The fix

A state-folding engine with four phases: (1) build the issue order from the SQ array and validate user_data uniqueness/range in kernel order; (2) build link chains from the issue order; (3) attach link timeouts and resolve flag-level errors (-EINVAL, drain-disabled -EOPNOTSUPP); (4) fold the raw completion stream, cancelling downstream chain members on failure, disarming/firing timeouts, honoring CQE_SKIP_SUCCESS, and buffering post-drain CQEs behind the barrier.

The complete, compilable implementation (/workspace/solution/engine.go):

// Package main implements a deterministic model of the Linux io_uring
// completion engine.  Given a trace of SQEs (plus the SQ array that fixes the
// kernel issue order) and a stream of raw completion events, it folds the
// stream into the exact CQE stream a kernel would post, honouring
// IOSQE_IO_LINK / IOSQE_IO_HARDLINK chains, IOSQE_IO_DRAIN barriers,
// IORING_OP_LINK_TIMEOUT vs IORING_OP_TIMEOUT, IOSQE_ASYNC and
// IOSQE_CQE_SKIP_SUCCESS.
//
// Malformed traces (a completion that references an op id that was never
// issued, or two issued SQEs that reuse the same user_data) are rejected with
// the first protocol violation in kernel order.
package main

import (
    "encoding/json"
    "errors"
    "fmt"
    "io"
    "os"
    "strings"
)

// ---------------------------------------------------------------------------
// SQE model
// ---------------------------------------------------------------------------

const (
    OpNop         = "nop"
    OpRead        = "read"
    OpWrite       = "write"
    OpTimeout     = "timeout"      // IORING_OP_TIMEOUT
    OpLinkTimeout = "link_timeout" // IORING_OP_LINK_TIMEOUT
)

// IOSQE_* flags.
type Flags uint16

const (
    FlagDrain          Flags = 1 << iota // IOSQE_IO_DRAIN
    FlagLink                             // IOSQE_IO_LINK
    FlagHardlink                         // IOSQE_IO_HARDLINK
    FlagAsync                            // IOSQE_ASYNC
    FlagCqeSkipSuccess                   // IOSQE_CQE_SKIP_SUCCESS
)

// Positive errno values (Linux x86_64); results are emitted as negations.
const (
    EINVAL     = 22
    ECANCELED  = 125
    ETIME      = 62
    EOPNOTSUPP = 95
)

var flagByName = map[string]Flags{
    "IO_DRAIN":               FlagDrain,
    "IO_LINK":                FlagLink,
    "IO_HARDLINK":            FlagHardlink,
    "ASYNC":                  FlagAsync,
    "CQE_SKIP_SUCCESS":       FlagCqeSkipSuccess,
    "IOSQE_IO_DRAIN":         FlagDrain,
    "IOSQE_IO_LINK":          FlagLink,
    "IOSQE_IO_HARDLINK":      FlagHardlink,
    "IOSQE_ASYNC":            FlagAsync,
    "IOSQE_CQE_SKIP_SUCCESS": FlagCqeSkipSuccess,
}

// SQE is one submission queue entry.
type SQE struct {
    UserData uint64   `json:"user_data"`
    Op       string   `json:"op"`
    Flags    Flags    `json:"-"`
    RawFlags []string `json:"flags"`
    // Res is the native result of the operation.  It is only used when the
    // trace supplies no explicit completion event for the SQE.
    Res int `json:"res"`
}

func (s *SQE) parse() error {
    for _, f := range s.RawFlags {
        bit, ok := flagByName[strings.ToUpper(f)]
        if !ok {
            return fmt.Errorf("unknown SQE flag %q", f)
        }
        s.Flags |= bit
    }
    return nil
}

func (s SQE) has(f Flags) bool { return s.Flags&f != 0 }

// ---------------------------------------------------------------------------
// Trace model
// ---------------------------------------------------------------------------

// Event is a raw completion arriving from the "kernel" in arrival order.
type Event struct {
    UserData uint64 `json:"user_data"`
    // Kind is "complete" (default) or "timeout".
    Kind string `json:"kind"`
    // Res is the raw result; for a fired timeout it is normally -ETIME.
    Res int `json:"res"`
}

// Trace is the full input.
type Trace struct {
    SQEs    []SQE   `json:"sqes"`
    SQArray []int   `json:"sq_array"`
    Events  []Event `json:"events"`
}

// CQE is one completion queue entry on the output stream.
type CQE struct {
    UserData uint64 `json:"user_data"`
    Res      int    `json:"res"`
    More     bool   `json:"more,omitempty"`
}

// Violation is a protocol-level rejection.  Pos is the kernel-order position
// at which it was detected (index into SQArray for submission violations,
// index into Events for completion violations).
type Violation struct {
    Pos int    `json:"pos"`
    Msg string `json:"message"`
}

func (v *Violation) Error() string { return fmt.Sprintf("protocol violation at %d: %s", v.Pos, v.Msg) }

// ---------------------------------------------------------------------------
// Engine internals
// ---------------------------------------------------------------------------

type req struct {
    sqe  SQE
    pos  int // index in SQArray
    next *req
    prev *req

    cancelled bool
    terminal  bool
    result    int
    ltimeout  *req // the IORING_OP_LINK_TIMEOUT linked immediately after this op
    target    *req // for a link timeout: the op it times out
}

type engine struct {
    order    []*req
    byUD     map[uint64]*req
    out      []CQE
    drains   []*req // drains in issue order
    drainBuf map[*req][]CQE
}

// Run folds the trace into the CQE stream.  A non-nil *Violation is returned
// for the first malformed reference in kernel order.
func Run(t Trace) ([]CQE, error) {
    e := &engine{byUD: map[uint64]*req{}, drainBuf: map[*req][]CQE{}}

    // --- Phase 1: build the issue order from the SQ array.  This is the
    // kernel order for submissions.
    for pos, idx := range t.SQArray {
        if idx < 0 || idx >= len(t.SQEs) {
            return nil, &Violation{Pos: pos, Msg: fmt.Sprintf("sq_array[%d]=%d references an SQE that was never submitted", pos, idx)}
        }
        s := t.SQEs[idx]
        if err := s.parse(); err != nil {
            return nil, err
        }
        if _, dup := e.byUD[s.UserData]; dup {
            return nil, &Violation{Pos: pos, Msg: fmt.Sprintf("user_data %d reused by a second issued SQE", s.UserData)}
        }
        r := &req{sqe: s, pos: pos}
        e.byUD[s.UserData] = r
        e.order = append(e.order, r)
    }

    // --- Phase 2: link chains.  IOSQE_IO_LINK on entry i links it to entry
    // i+1 in *issue order* (the SQ array), never to the next array slot.
    for i := 0; i+1 < len(e.order); i++ {
        if e.order[i].sqe.has(FlagLink) || e.order[i].sqe.has(FlagHardlink) {
            e.order[i].next = e.order[i+1]
            e.order[i+1].prev = e.order[i]
        }
    }

    // --- Phase 3: attach link timeouts and flag op-level errors.
    drainDisabled := false
    for _, r := range e.order {
        if r.sqe.has(FlagCqeSkipSuccess) {
            drainDisabled = true
        }
        if r.sqe.has(FlagDrain) && drainDisabled {
            // Kernel: CQE_SKIP_SUCCESS disables drain; a later drain fails
            // with -EOPNOTSUPP.
            e.emit(CQE{UserData: r.sqe.UserData, Res: -EOPNOTSUPP})
            r.terminal, r.result = true, -EOPNOTSUPP
            continue
        }
        if r.sqe.has(FlagDrain) {
            e.drains = append(e.drains, r)
        }
        if r.sqe.Op == OpLinkTimeout {
            if r.prev == nil || r.prev.sqe.Op == OpLinkTimeout {
                // Invalid: a link timeout needs a linked predecessor.
                e.emit(CQE{UserData: r.sqe.UserData, Res: -EINVAL})
                r.terminal, r.result = true, -EINVAL
                continue
            }
            r.target = r.prev
            r.prev.ltimeout = r
        }
    }

    // --- Phase 4: fold the raw completion stream.
    events := t.Events
    if len(events) == 0 {
        // No explicit stream: every issued op completes with its native
        // result.  IOSQE_ASYNC forces the op through io-wq, so its CQE is
        // deferred until after all synchronous completions of the batch.
        // A link timeout only fires if its native Res is -ETIME.
        mk := func(r *req) Event {
            res := r.sqe.Res
            kind := "complete"
            if r.sqe.Op == OpLinkTimeout && res == -ETIME {
                kind = "timeout"
            }
            return Event{UserData: r.sqe.UserData, Kind: kind, Res: res}
        }
        for _, r := range e.order {
            if !r.sqe.has(FlagAsync) {
                events = append(events, mk(r))
            }
        }
        for _, r := range e.order {
            if r.sqe.has(FlagAsync) {
                events = append(events, mk(r))
            }
        }
    }

    for pos, ev := range events {
        r := e.byUD[ev.UserData]
        if r == nil {
            return nil, &Violation{Pos: pos, Msg: fmt.Sprintf("completion references op id %d that was never issued", ev.UserData)}
        }
        e.fold(r, ev)
    }
    return e.out, nil
}

// fold applies one raw completion event.
func (e *engine) fold(r *req, ev Event) {
    if r.terminal || r.cancelled {
        // Exactly one terminal result per op: a late/duplicate observation of
        // an op that is already settled (typically because a link failure
        // cancelled it) is dropped.
        return
    }
    if r.sqe.Op == OpLinkTimeout {
        fired := strings.EqualFold(ev.Kind, "timeout") || ev.Res == -ETIME
        if fired {
            // Timer won: cancel the target, then post the timeout CQE.
            if r.target != nil {
                e.cancel(r.target, -ECANCELED)
            }
            e.finish(r, -ETIME)
            e.cancelDownstream(r)
        } else {
            // Disarmed: target already completed first.
            e.finish(r, -ECANCELED)
        }
        return
    }

    res := ev.Res
    if res < 0 {
        // Failure severs the link.  A link timeout attached to this op is
        // disarmed with -ECANCELED and the rest of the chain is cancelled.
        if r.ltimeout != nil {
            e.finish(r.ltimeout, -ECANCELED)
        }
        e.finish(r, res)
        e.cancelDownstream(r)
        return
    }

    // Success: complete normally, disarm a link timeout, and let the chain
    // continue (the next linked op's event will arrive later).
    e.finish(r, res)
    if r.ltimeout != nil {
        e.finish(r.ltimeout, -ECANCELED)
    }
}

// cancelDownstream cancels every still-live member of the chain that follows r.
func (e *engine) cancelDownstream(r *req) {
    for n := r.next; n != nil; n = n.next {
        if n == r.ltimeout {
            // already finished as disarmed
            continue
        }
        e.cancel(n, -ECANCELED)
    }
}

// cancel settles n with res if it has not already settled.
func (e *engine) cancel(n *req, res int) {
    if n.terminal || n.cancelled {
        return
    }
    e.finish(n, res)
}

// finish records the terminal result and emits the CQE unless the SQE asked to
// skip successful completions.
func (e *engine) finish(r *req, res int) {
    r.terminal, r.result = true, res
    if res >= 0 && r.sqe.has(FlagCqeSkipSuccess) {
        return // IOSQE_CQE_SKIP_SUCCESS: successful completions post no CQE
    }
    e.emit(CQE{UserData: r.sqe.UserData, Res: res})
}

// emit appends a CQE, enforcing IOSQE_IO_DRAIN barriers: a CQE for an op that
// was issued after an incomplete drain is buffered until the drain completes.
func (e *engine) emit(c CQE) {
    r := e.byUD[c.UserData]
    for _, d := range e.drains {
        if d == r || d.terminal {
            continue
        }
        if r != nil && r.pos > d.pos {
            e.drainBuf[d] = append(e.drainBuf[d], c)
            return
        }
    }
    e.out = append(e.out, c)
    // If this was a drain, flush everything queued behind it.
    if r != nil && r.sqe.has(FlagDrain) && r.terminal {
        for _, d := range e.drains {
            if d == r {
                buf := e.drainBuf[d]
                delete(e.drainBuf, d)
                for _, bc := range buf {
                    e.out = append(e.out, bc)
                }
                break
            }
        }
    }
}

// ---------------------------------------------------------------------------
// JSON plumbing / CLI
// ---------------------------------------------------------------------------

// ParseTrace decodes a trace from JSON.
func ParseTrace(data []byte) (Trace, error) {
    var t Trace
    dec := json.NewDecoder(strings.NewReader(string(data)))
    if err := dec.Decode(&t); err != nil {
        return t, err
    }
    return t, nil
}

// Result is the top-level program output.
type Result struct {
    CQEs      []CQE      `json:"cqes"`
    Violation *Violation `json:"violation,omitempty"`
}

func solve(t Trace) Result {
    cqes, err := Run(t)
    if err != nil {
        var v *Violation
        if errors.As(err, &v) {
            return Result{Violation: v}
        }
        return Result{Violation: &Violation{Pos: -1, Msg: err.Error()}}
    }
    return Result{CQEs: cqes}
}

func main() {
    data, err := io.ReadAll(os.Stdin)
    if err != nil {
        fmt.Fprintln(os.Stderr, "read stdin:", err)
        os.Exit(2)
    }
    t, err := ParseTrace(data)
    if err != nil {
        fmt.Fprintln(os.Stderr, "parse trace:", err)
        os.Exit(2)
    }
    enc := json.NewEncoder(os.Stdout)
    enc.SetIndent("", "  ")
    if err := enc.Encode(solve(t)); err != nil {
        fmt.Fprintln(os.Stderr, "encode:", err)
        os.Exit(2)
    }
}
