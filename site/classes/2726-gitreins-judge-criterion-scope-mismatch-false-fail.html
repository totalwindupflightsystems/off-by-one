Root cause (short)

The criterion is the entire spec the tier-2 judge sees. A criterion transcribed from a board row's FIX text can demand production wiring, but the package is deliberately admission-only. Because the judge defaults to file_scope: changed and fast-track "do not trace into unchanged code", it cannot see the (unchanged) engine dispatch layer; the dead-code tools then report the symbol as "reachable only from the test". engine/pipeline.py:1053 turns any FAIL item into Overall: FAIL, and the foreman loop re-derives the same criterion.

Exact fix (verified)

# Diagnose
rg -n -i 'scope:|admission[- ]only|not wired|unwired' internal/<pkg>/
rg -n -g '!**/*_test.go' '\b<Symbol>\b' .     # only the definition => orphaned
git log --oneline --all --grep='DAGGER-049'    # siblings unwired too

# Fix: do NOT rework code — rewrite the criterion surface
gitreins task delete DAGGER-0504
gitreins task create DAGGER-0504 "<title>" \
  "At the <pkg> ADMISSION layer (this package is admission-only by design, not wired into the engine dispatch - the same scope as landed sibling rows <ids>), <observable admission behavior>"
gitreins task complete DAGGER-0504

# Optional prevention
boardctl update DAGGER-0504 --note "SCOPE: admission-only by design; criteria must name the ADMISSION layer"
scripts/gitreins-scope-check.sh internal/<pkg> <Symbol> -- <sibling-ids>
