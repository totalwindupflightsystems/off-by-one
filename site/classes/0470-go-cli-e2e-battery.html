Answer

Verdict: zero app gaps. All 3 battery FAILs were script bugs. The fix is to correct the battery assertions, not the CLI. The canonical contract is byte-exact — compare bytes, never grep.

Reconstructed repro at /home/kara/foreman-direct/ (main.go, battery_test.go 26-case Go battery, battery.sh, artifact-demo.sh).

1. Coarse grep on JSON → parse fields exactly. Compact JSON {"tick":48,"status":"ok",...} defeats grep '"status": "ok"'. Fixed with jq (or encoding/json):

# BUGGY: echo "$rep" | grep -o '"status": "ok"'
# FIXED: parse, don't pattern-match
echo "$rep" | jq -e '.status == "ok" and .tick == 48' >/dev/null   # exit 0 = PASS
[ "$(echo "$rep" | jq 'keys | length')" = "3" ]                   # schema lock
[ "$rep" = "$("$BIN" report --tick 48)" ]                         # deterministic bytes

2. Wrong DB filename pattern → glob the real contract. The CLI writes foreman-<tick>-run.db; scripts looked for foreman.db / *.sqlite. Fixed:

"$BIN" init --dir "$TMP" --tick 48
db=$(find "$TMP" -maxdepth 1 -name 'foreman-*-run.db' -printf '%f\n')
printf '%s' "$db" | grep -Eq '^foreman-[0-9]+-run\.db$'   # exact pattern
[ "$(find "$TMP" -maxdepth 1 -type f -name '*.db' | wc -l)" -eq 1 ]  # no stray artifacts

3. Empty-body MCP expectation → the contract body is non-empty. [ -z "$mcp" ] failed against a correct app. Fixed:

mcp=$("$BIN" mcp)
[ -n "$mcp" ]                                                   # non-empty by contract
echo "$mcp" | jq -e '.resource == "flow" and .content == "42\ntrigger=none" and .ok == true'

Canonical flow — byte-exact, verified with cmp (never grep):

"$BIN" source > out.txt; printf '42\ntrigger=none\n' > exp.txt
cmp -s out.txt exp.txt && [ "$(wc -c < out.txt)" -eq 16 ]
