The slice is F841/S110/S112 (+ E722 interplay), 67 sites. The fix is a per-site triage, not a blind autofix. Five buckets, each with code examples:

1. F841 — keep the RHS call, drop the assignment (pure deletion)

# before  →  F841: local variable `compose` assigned to but never used
def on_compose(friend):
    compose = generate_compose(friend)
    notify_ticker()

# after  →  clean (call is side-effectful, result deliberately discarded)
def on_compose(friend):
    generate_compose(friend)
    notify_ticker()

Do not delete the whole line and do not rename with _ unless the call's only purpose is the return value — here the call has a side effect and must survive.

2. S110/S112 — silence ONLY two ways, verified empirically

Ruff ignores explanatory comments. The # noqa must sit on the except line (on the pass/continue line it is dead weight — confirmed, see EVIDENCE):

# ✗ NOT silenced — plain comment on except line
try:
    send_best_effort(payload)
except Exception:
    # best effort: drop on failure
    pass

# ✓ SILENCED — noqa on the except line
try:
    send_best_effort(payload)
except Exception:  # noqa: S110
    pass

# ✓ SILENCED — narrowing to concrete type(s)
try:
    send_best_effort(payload)
except (TimeoutError, ConnectionError):
    pass

3. Best-effort / must-never-propagate contracts → broad catch + comment + # noqa: S110 (keep the safety)

Background workers, cleanup/teardown, notification, and telemetry must swallow anything — narrowing would let a stray TypeError kill the worker thread:

# keep broad catch (must never propagate), comment explains WHY, noqa silences lint
def flush_best_effort(rows):
    try:
        sink.flush(rows)
    except Exception:  # noqa: S110 — best-effort flush; failure must never propagate to caller
        log.warning("flush failed", exc_info=True)
        # intentional swallow: contract is fire-and-forget
        pass

4. E722 bare-except → do NOT mechanically convert to except Exception (net-zero trap)

# before → E722
try:
    parse(raw)
except:
    data = {}

# ⚠ converting to broad Exception does NOT reduce the count:
# E722 disappears but BLE001 fires → net zero on total
try:
    parse(raw)
except Exception:
    data = {}

# ✓ the only count-reducing move is a concrete exception
try:
    parse(raw)
except ValueError:
    data = {}

So E722 sites are only fixed when a concrete type is knowable; otherwise they stay or get noqa — never an "autofix to Exception".

5. doctor.py — protected (Bane live-work rule), all 14 sites stay as intentional drift. Zero edits, zero autofix, git diff doctor.py must be empty at the end.

6. Narrowing must respect test fakes — complete the tuple, never touch tests

test_matrix.py fakes raise TypeError; narrowing except Exception: to just except ValueError: makes the real code re-raise the fake's TypeError and fails the test. Fix the source, not the test:

# before (broad, S110)
try:
    matrix = build_matrix(raw)
except Exception:
    matrix = None

# ✗ breaks test_matrix.py — fake raises TypeError
try:
    matrix = build_matrix(raw)
except ValueError:
    matrix = None

# ✓ complete the tuple: ValueError (real) + TypeError (fake contract)
try:
    matrix = build_matrix(raw)
except (ValueError, TypeError):  # noqa: S110 — build is best-effort; both real and fake raise paths swallowed
    matrix = None
