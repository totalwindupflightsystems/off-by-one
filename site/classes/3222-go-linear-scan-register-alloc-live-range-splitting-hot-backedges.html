Answer

go-linear-scan-register-alloc-live-range-splitting-hot-backedges

Diagnosis

A naive linear-scan allocator falls back to spilling the whole live range whenever the register file is full, which is why hot loops lose all their values to the stack. Adding live-range splitting on top of linear scan exposes several independent correctness traps. I reproduced and fixed all of them in a working Go implementation under ~/regalloc.

Root causes (each reproduced by the randomized harness)

# Symptom Root cause Fix
1 Whole-range spills; only remainder never reappears Evicting a range always spilled it entire On pressure, evict the furthest-ending interval and split it at the gap around cur (last use < cur, first use > cur); prefix keeps the register, tail is requeued
2 Missed expirations / wrong registers under insertion Split remainders were appended to the end of the scan list, destroying start-order Work list is a min-heap keyed by Start (container/heap)
3 Allocator hangs / unbounded pieces A root could be split forever Per-root Splits budget (MaxSplits); once exhausted the incoming piece is spilled wholesale
4 Wrong loop value on the 2nd iteration Splitting a loop-carried value inside the loop lets its register be reused before the back edge re-executes the prefix Refuse a split whose retained prefix overlaps a carried loop (computeCarried), and proactively split loop-spanning holes at the back edge
5 Wrong value at a phi-free join A split tail starts at a use and relies on a reload at that position, but a branch can reach a later use while skipping that block Home slot is canonical; every split tail is memory-resident; only pieces that start at a definition are register-resident
6 Wrong value in v = v op x A self-referential def both reads and writes v, but the reload was suppressed because the position was a def Reload at the first position of every register piece before the instruction, even if it also defines v
7 Malformed loop test passed vacuously The header's false branch fell through into the body, so both interpreters looped forever and compared equal Fixed layout; harness now requires the reference to terminate

The most instructive failure was #5. In seed 21 the allocator produced:

v2 [2,2]  reg=1
v2 [13,19] reg=2      <- tail starts at the use at pos 13

The control flow is:

block 0: pos 0..9 (defs) ; pos 10 Br -> block 2
block 1: pos 11..13                       (reached only on the false path)
block 2: pos 14..17  <-- pos 14 uses v2

The Br jumps straight to block 2, so pos 13 is never executed, the tail's reload never happens, and pos 14 reads r2 left over from v1 = -5 instead of v2 = -2. A linear range is not a path; a reload must not be placed at a position that joins can skip. Making the home slot authoritative and keeping split tails in memory removes the dependency on where the reload lands.

The fix

Design

  • Home slot per virtual register. Every definition writes the home slot (in addition to its register). Every use of a memory-resident piece reads the slot. The slot is therefore always the last value written along any path.
  • Register pieces are only created at definitions. Allocate marks any interval whose Start is not a definition as memory-resident, and every split tail/suffix is memory-resident. A register piece starts at a def and owns its register for its whole range, so that def dominates every use (checked statically).
  • Splitting on pressure. When no register is free, choose the active interval with the furthest End that has a legal split gap u1 < cur < u2. The prefix [Start,u1] keeps the register; [u2,End] is requeued (memory-resident). The register is handed to the incoming interval — legal because the prefix ended strictly before cur.
  • Back-edge handling. A pre-pass splits loop-spanning values that are not used inside the loop at the loop boundary. Under pressure, a split is refused if the retained prefix overlaps a back edge the value is carried across.
  • Termination. Every tail has Start = u2 > cur, so the scan strictly advances; plus a per-root split budget.

Core allocator (alloc.go)

package main

import (
    "container/heap"
    "fmt"
)

type Edge struct{ Src, Tgt int } // back edge in flat positions

type carriedEdge struct {
    VReg     int
    Tgt, Src int
}

type RegAlloc struct {
    K, MaxSplits int
    Pieces       []*Interval
    slots        []int // vreg -> home slot
    prog         *Program
    backedges    []Edge
    carried      []carriedEdge
    Trace        []string
}

// work list: min-heap by Start (keeps the scan sorted under split insertions)
type workHeap []*Interval

func (w workHeap) Len() int { return len(w) }
func (w workHeap) Less(i, j int) bool {
    if w[i].Start != w[j].Start {
        return w[i].Start < w[j].Start
    }
    return w[i].End < w[j].End
}
func (w workHeap) Swap(i, j int) { w[i], w[j] = w[j], w[i] }
func (w *workHeap) Push(x any)   { *w = append(*w, x.(*Interval)) }
func (w *workHeap) Pop() any {
    old := *w
    n := len(old)
    x := old[n-1]
    *w = old[:n-1]
    return x
}

// active set sorted by End (expiry is a prefix scan)
type activeSet []*Interval

func (a *activeSet) insert(it *Interval) {
    *a = append(*a, it)
    for i := len(*a) - 1; i > 0 && (*a)[i].End < (*a)[i-1].End; i-- {
        (*a)[i], (*a)[i-1] = (*a)[i-1], (*a)[i]
    }
}
func (a *activeSet) removeAt(i int) { *a = append((*a)[:i], (*a)[i+1:]...) }
func (a *activeSet) removeItem(it *Interval) {
    for i, x := range *a {
        if x == it {
            a.removeAt(i)
            return
        }
    }
}

// computeCarried finds (vreg, back edge) pairs where the value is live at both
// the loop header and the latch.
func computeCarried(p *Program) []carriedEdge {
    _, liveOut := computeLiveness(p)
    liveAfter := make([]map[int]bool, len(p.Flat))
    liveBefore := make([]map[int]bool, len(p.Flat))
    for bi, b := range p.Blocks {
        cur := copySet(liveOut[bi])
        for k := len(b.Instrs) - 1; k >= 0; k-- {
            in := b.Instrs[k]
            liveAfter[in.Pos] = copySet(cur)
            for _, d := range in.defs() {
                delete(cur, d)
            }
            for _, u := range in.usesList() {
                cur[u] = true
            }
            liveBefore[in.Pos] = copySet(cur)
        }
    }
    var out []carriedEdge
    for _, e := range findBackedges(p) {
        for v := 0; v < p.NV; v++ {
            if liveBefore[e.Tgt][v] && liveAfter[e.Src][v] {
                out = append(out, carriedEdge{VReg: v, Tgt: e.Tgt, Src: e.Src})
            }
        }
    }
    return out
}

func findBackedges(p *Program) []Edge {
    var out []Edge
    for bi, b := range p.Blocks {
        for _, s := range b.Succ {
            if s <= bi {
                out = append(out, Edge{Src: p.End[bi], Tgt: p.Start[s]})
            }
        }
    }
    return out
}

func Allocate(p *Program, ivs []*Interval, K, maxSplits int) *RegAlloc {
    ra := &RegAlloc{
        K: K, MaxSplits: maxSplits, prog: p,
        backedges: findBackedges(p), carried: computeCarried(p),
        slots: make([]int, p.NV),
    }
    for i := range ra.slots {
        ra.slots[i] = i
    }
    for i, iv := range ivs {
        iv.Root = i
        iv.Reg = -1
    }
    ra.Pieces = append(ra.Pieces, ivs...)

    // Only def-started pieces may hold a register. Anything starting at a use
    // would need a reload that a join could skip.
    for _, iv := range ra.Pieces {
        if !ra.isDefAt(iv.VReg, iv.Start) {
            iv.Spill = true
        }
    }

    // hot-back-edge pre-pass
    var pre []*Interval
    for _, iv := range ra.Pieces {
        pre = append(pre, ra.splitAtLoops(iv)...)
    }
    ra.Pieces = pre

    w := &workHeap{}
    for _, it := range ra.Pieces {
        *w = append(*w, it)
    }
    heap.Init(w)

    active := activeSet{}
    free := make([]int, K)
    for i := 0; i < K; i++ {
        free[i] = i
    }

    for w.Len() > 0 {
        it := heap.Pop(w).(*Interval)
        if it.Spill { // home-slot piece: no register, no pressure
            ra.Trace = append(ra.Trace,
                fmt.Sprintf("home-slot v%d [%d,%d]", it.VReg, it.Start, it.End))
            continue
        }
        for len(active) > 0 && active[0].End < it.Start { // expire
            free = append(free, active[0].Reg)
            active.removeAt(0)
        }
        if len(free) > 0 {
            it.Reg = free[len(free)-1]
            free = free[:len(free)-1]
            active.insert(it)
            ra.Trace = append(ra.Trace,
                fmt.Sprintf("assign v%d [%d,%d] -> r%d", it.VReg, it.Start, it.End, it.Reg))
            continue
        }

        // pressure: evict + split the furthest-ending splittable range
        victim := ra.pickVictim(active, it.Start)
        if victim != nil && victim.Splits < maxSplits {
            if tail, ok := ra.splitVictim(victim, it.Start); ok {
                reg := victim.Reg
                active.removeItem(victim)
                ra.Pieces = append(ra.Pieces, tail)
                heap.Push(w, tail) // requeue remainder in sorted position
                ra.Trace = append(ra.Trace,
                    fmt.Sprintf("split v%d [%d,%d] at %d -> prefix [%d,%d] tail [%d,%d]; hand r%d to v%d",
                        victim.VReg, victim.Start, victim.End, it.Start,
                        victim.Start, victim.End, tail.Start, tail.End, reg, it.VReg))
                it.Reg = reg
                active.insert(it)
                continue
            }
        }

        it.Spill = true // bounded-split fallback
        it.Reg = -1
        ra.Trace = append(ra.Trace,
            fmt.Sprintf("spill v%d [%d,%d]", it.VReg, it.Start, it.End))
    }
    return ra
}

func (ra *RegAlloc) pickVictim(active activeSet, cur int) *Interval {
    var best *Interval
    for _, a := range active {
        if a.Reg < 0 {
            continue
        }
        if _, _, ok := ra.splitPoint(a, cur); !ok {
            continue
        }
        if best == nil || a.End > best.End {
            best = a
        }
    }
    return best
}

// splitPoint finds the gap u1 < cur < u2 bracketing cur.
func (ra *RegAlloc) splitPoint(v *Interval, cur int) (end1, u2 int, ok bool) {
    u1, u2 := -1, -1
    for _, u := range v.Uses {
        if u < cur {
            u1 = u
        } else {
            u2 = u
            break
        }
    }
    if u2 < 0 || u2 <= cur {
        return 0, 0, false
    }
    end1 = u1
    if end1 < 0 {
        end1 = v.Start
    }
    if end1 >= cur {
        return 0, 0, false
    }
    // reject if the retained prefix overlaps a loop the value is carried across
    for _, c := range ra.carried {
        if c.VReg == v.VReg && v.Start <= c.Src && end1 >= c.Tgt {
            return 0, 0, false
        }
    }
    return end1, u2, true
}

func (ra *RegAlloc) splitVictim(v *Interval, cur int) (*Interval, bool) {
    end1, u2, ok := ra.splitPoint(v, cur)
    if !ok {
        return nil, false
    }
    var tailUses, kept []int
    for _, u := range v.Uses {
        if u >= u2 {
            tailUses = append(tailUses, u)
        } else {
            kept = append(kept, u)
        }
    }
    tail := &Interval{
        VReg: v.VReg, Start: u2, End: v.End, Uses: tailUses,
        Reg: -1, Root: v.Root, Splits: v.Splits + 1, FromSplit: true,
    }
    tail.Spill = true // memory-resident hand-off; slot is always current
    v.End = end1
    v.Uses = kept
    return tail, true
}

// splitAtLoops splits a loop-spanning interval that is not used inside the
// loop at the loop boundary (hot-back-edge split).
func (ra *RegAlloc) splitAtLoops(iv *Interval) []*Interval {
    if iv.Splits >= ra.MaxSplits {
        return []*Interval{iv}
    }
    for _, e := range ra.backedges {
        if iv.Start > e.Tgt || iv.End < e.Src {
            continue
        }
        usedIn := false
        for _, u := range iv.Uses {
            if u >= e.Tgt && u <= e.Src {
                usedIn = true
                break
            }
        }
        if usedIn {
            continue
        }
        prefixEnd := iv.Start
        for _, u := range iv.Uses {
            if u < e.Tgt {
                prefixEnd = u
            }
        }
        suffixStart := -1
        for _, u := range iv.Uses {
            if u > e.Src {
                suffixStart = u
                break
            }
        }
        if suffixStart < 0 || prefixEnd >= suffixStart {
            continue
        }
        prefix := &Interval{VReg: iv.VReg, Start: iv.Start, End: prefixEnd,
            Reg: -1, Root: iv.Root, Splits: iv.Splits}
        for _, u := range iv.Uses {
            if u <= prefixEnd {
                prefix.Uses = append(prefix.Uses, u)
            }
        }
        suffix := &Interval{VReg: iv.VReg, Start: suffixStart, End: iv.End,
            Reg: -1, Root: iv.Root, Splits: iv.Splits + 1, FromSplit: true, Spill: true}
        for _, u := range iv.Uses {
            if u >= suffixStart {
                suffix.Uses = append(suffix.Uses, u)
            }
        }
        return append([]*Interval{prefix}, ra.splitAtLoops(suffix)...)
    }
    return []*Interval{iv}
}

func (ra *RegAlloc) isDefAt(v, pos int) bool {
    return pos >= 0 && pos < len(ra.prog.Flat) && ra.prog.Flat[pos].Dst == v
}

Interval construction (ir.go)

The interval end must follow liveness, not just the last textual use, so a value live across a back edge has its range extended to the latch:

func buildIntervals(p *Program, liveIn, liveOut []map[int]bool) []*Interval {
    liveAfter := make([]map[int]bool, len(p.Flat))
    liveBefore := make([]map[int]bool, len(p.Flat))
    for bi, b := range p.Blocks {
        cur := copySet(liveOut[bi])
        for k := len(b.Instrs) - 1; k >= 0; k-- {
            in := b.Instrs[k]
            liveAfter[in.Pos] = copySet(cur)
            for _, d := range in.defs() {
                delete(cur, d)
            }
            for _, u := range in.usesList() {
                cur[u] = true
            }
            liveBefore[in.Pos] = copySet(cur)
        }
    }
    var out []*Interval
    for v := 0; v < p.NV; v++ {
        start, end := -1, -1
        var uses []int
        for pos, in := range p.Flat {
            isDef, isUse := in.Dst == v, false
            for _, u := range in.usesList() {
                if u == v {
                    isUse = true
                    break
                }
            }
            if isDef || isUse {
                if start < 0 {
                    start = pos
                }
                end = pos
            }
            if liveAfter[pos][v] { // extends across back edges
                if start < 0 {
                    start = pos
                }
                if pos > end {
                    end = pos
                }
            }
            if isUse {
                uses = append(uses, pos)
            }
        }
        if liveBefore[0][v] && (start < 0 || start > 0) {
            start = 0
        }
        if start < 0 {
            continue
        }
        out = append(out, &Interval{VReg: v, Start: start, End: end, Uses: uses, Reg: -1})
    }
    return out
}

Execution model (interp.go)

The two rules that make split hand-off correct on every path:

// read: at the first position of a register piece reload from the home slot,
// even if the instruction also defines v (self-referential v = v op x reads
// the source before the write).
func (ra *RegAlloc) read(v, pos int, regs, slots []int64) int64 {
    p := ra.pieceAt(v, pos)
    if p == nil || p.Spill {
        return slots[v]
    }
    if pos == p.Start {
        regs[p.Reg] = slots[v]
    }
    return regs[p.Reg]
}

// write: always keep the home slot current so any later reload or spilled use
// sees the last value written along the current path.
func (ra *RegAlloc) write(v, pos int, val int64, regs, slots []int64) {
    p := ra.pieceAt(v, pos)
    if p == nil || p.Spill {
        slots[v] = val
        return
    }
    regs[p.Reg] = val
    slots[v] = val
}

Verification

What is checked

For every program the harness verifies all of the following, then executes:

  1. CheckConflicts — no two register-resident pieces share a physical register over an overlapping range.
  2. CheckSplitBound — no root interval exceeds MaxSplits (termination).
  3. CheckRegisterValidity — every register piece starts at a definition and that definition dominates every use in the piece (the all-paths condition, computed with a full dominator analysis).
  4. CheckDenseCoverage — every use is covered by a piece.
  5. Differential execution — the reference interpreter over virtual registers and the allocated interpreter over physical registers + home slots are run on many random inputs; results and termination must match. The loop test additionally requires the reference to terminate.

Coverage summary

  • 400 random acyclic CFGs × 2–4 registers × 40 random inputs each = 16 000 differential executions, plus the back-edge loop at every pressure level K = 1..6.
  • 0 register conflicts, 0 split-bound violations, 0 domination failures, 0 value/termination mismatches.
  • TestSplittingHappens guards against a regression where the allocator would spill everything and never split.

Termination argument. Each split of interval v produces a tail whose Start = u2 > cur (strictly after the scan position) and increments the root's Splits; the work list is a min-heap over a finite position set, and Splits ≤ MaxSplits, so the number of pieces per root is bounded by MaxSplits + 1 and the scan strictly advances. The back-edge pre-pass is likewise bounded by MaxSplits. Hence allocation always terminates.
