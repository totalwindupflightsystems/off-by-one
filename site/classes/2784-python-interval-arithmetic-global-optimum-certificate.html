Certified Global Optimization over Interval Constraints

Root-cause analysis

The failure modes of a naive interval branch-and-bound for this problem class are:

  1. Dependency overestimation. Expanding a polynomial into monomials and summing the natural interval extension of each monomial discards correlations between terms that share subexpressions. For the demo objective f = (x-1)^2 + (y-1)^4 + (x-1)(y-1)^2 on [-2,2]^2, the expanded-monomial natural extension gives f ∈ [-53, 95], while evaluating the shared expression DAG gives the much tighter [-27, 99]. Because the lower bound is the search driver, a loose bound makes branch-and-bound refine forever.

  2. First-order forms built from loose gradients are worse than useless. A mean-value / Taylor form uses the interval gradient. Over a wide box the gradient enclosure of a quartic is huge (e.g. ∂f/∂y ∈ [-114, 22]), so the mean-value lower bound can drop below the natural bound and never prune. It must be intersected with the natural bound, and a second-order Taylor form must be used to handle the curvature.

  3. Near-singular stationary points. At the true minimizer (1,1) the Hessian is singular (diag(2,0) in the (u,v) coordinates), and the objective is flat to fourth order. Derivative-only reasoning never excludes boxes around it. The second-order Taylor term plus monotonicity-based face reduction plus deterministic midpoint subdivision are what drive the bound to zero.

  4. Rounding / endpoint errors. If any bound is produced with floating-point directed rounding in the wrong direction, or a box split drops/duplicates an endpoint, the certificate is unsound. A checker must recompute with exact arithmetic and reject a claimed lower bound that exceeds the rigorous one, and must verify that the split children exactly partition the parent.

The fix

  • Exact rational interval arithmetic (fractions.Fraction) — there is no rounding at all, so lo/hi are true enclosures by construction.
  • Expression DAG (stored as RPN for transport) so shared subexpressions are evaluated once; this removes most dependency overestimation.
  • Forward-mode interval automatic differentiation carrying value, gradient, and Hessian, computed with exact interval arithmetic.
  • rigorous_lower(box) = max(natural, mean-value, 2nd-order Taylor) after monotonicity face reduction. Each candidate is itself a valid lower bound, so the max is valid.
  • Best-first branch and bound splitting the smallest-lower-bound leaf along the Hansen smear axis at the exact rational midpoint.
  • Flat, signed certificate: a node list with parent links; leaves form an exact tiling of the root; each node carries a rational lower bound; the incumbent is an exact feasible point. SHA-256 over canonical JSON makes it reproducible and tamper-evident.
  • Checker re-derives the same rigorous lower bound in exact arithmetic and rejects: an upward-rounded lower bound, a non-partitioning split / shifted endpoint, overlapping or volumetric-gap covers, a wrong rounding mode, and a tampered incumbent.

certopt.py

"""
certopt.py -- Certified global optimization of rational multivariate polynomials
over interval (box) constraints, using exact rational interval arithmetic and
forward-mode interval automatic differentiation (value, gradient, Hessian).

All arithmetic is done with fractions.Fraction, so every enclosure is exact:
there is no floating-point rounding anywhere.  This makes the certificate fully
reproducible and lets the checker reject any certificate whose claimed lower
bound exceeds a rigorous lower bound (a rounding / endpoint mistake).

Standard library only.  Python >= 3.11.
"""

from __future__ import annotations

from fractions import Fraction
import heapq
import hashlib
import json

# ===========================================================================
# Rational helpers
# ===========================================================================

def F(x) -> Fraction:
    if isinstance(x, Fraction):
        return x
    if isinstance(x, bool):
        return Fraction(int(x))
    if isinstance(x, int):
        return Fraction(x)
    if isinstance(x, str):
        return Fraction(x)
    if isinstance(x, float):
        return Fraction(x)            # exact binary value
    raise TypeError(f"cannot convert {x!r} to Fraction")


def fstr(x) -> str:
    x = F(x)
    return f"{x.numerator}/{x.denominator}"


# ===========================================================================
# Exact interval arithmetic
# ===========================================================================

class Interval:
    __slots__ = ("lo", "hi")

    def __init__(self, lo, hi=None):
        if hi is None:
            lo = F(lo)
            hi = lo
        else:
            lo, hi = F(lo), F(hi)
        if lo > hi:
            raise ValueError(f"empty interval [{lo}, {hi}]")
        self.lo, self.hi = lo, hi

    def __repr__(self):
        return f"[{self.lo},{self.hi}]"

    @property
    def is_point(self) -> bool:
        return self.lo == self.hi

    @property
    def width(self) -> Fraction:
        return self.hi - self.lo

    @property
    def mid(self) -> Fraction:
        return (self.lo + self.hi) / 2

    def contains(self, v) -> bool:
        v = F(v)
        return self.lo <= v <= self.hi

    def __neg__(self):
        return Interval(-self.hi, -self.lo)

    def __add__(self, other):
        other = _iv(other)
        return Interval(self.lo + other.lo, self.hi + other.hi)

    __radd__ = __add__

    def __sub__(self, other):
        other = _iv(other)
        return Interval(self.lo - other.hi, self.hi - other.lo)

    def __rsub__(self, other):
        return _iv(other) - self

    def __mul__(self, other):
        other = _iv(other)
        p = (self.lo * other.lo, self.lo * other.hi,
             self.hi * other.lo, self.hi * other.hi)
        return Interval(min(p), max(p))

    __rmul__ = __mul__

    def __truediv__(self, other):
        other = _iv(other)
        if other.lo <= 0 <= other.hi:
            raise ZeroDivisionError("interval divisor straddles zero")
        return self * Interval(1 / other.hi, 1 / other.lo)

    def __rtruediv__(self, other):
        return _iv(other) / self

    def __pow__(self, k: int):
        if not isinstance(k, int) or k < 0:
            raise ValueError("only non-negative integer powers are supported")
        return ipow(self, k)


def _iv(x) -> Interval:
    return x if isinstance(x, Interval) else Interval(x)


def ipow(x: Interval, k: int) -> Interval:
    """Tight integer power of an interval (handles even powers across 0)."""
    if k == 0:
        return Interval(1)
    if k % 2 == 1:
        return Interval(x.lo ** k, x.hi ** k)
    if x.lo >= 0:
        return Interval(x.lo ** k, x.hi ** k)
    if x.hi <= 0:
        return Interval(x.hi ** k, x.lo ** k)
    return Interval(0, max(x.lo ** k, x.hi ** k))


# ===========================================================================
# Expression DAG  (constructor side)
# ===========================================================================

class Expr:
    """Immutable expression node.

    ops: 'const' (c), 'var' (i), 'add'/'sub'/'mul' (a,b), 'pow' (a,k), 'neg' (a)
    """

    __slots__ = ("op", "a", "b", "c", "i", "k", "_rpn")

    def __init__(self, op, a=None, b=None, c=None, i=None, k=None):
        self.op = op
        self.a = a
        self.b = b
        self.c = c
        self.i = i
        self.k = k
        self._rpn = None

    # -- constructors -------------------------------------------------------
    @staticmethod
    def const(c):
        return Expr("const", c=F(c))

    @staticmethod
    def var(i):
        return Expr("var", i=i)

    # -- algebra ------------------------------------------------------------
    def __add__(self, other):
        return Expr("add", self, _expr(other))

    __radd__ = __add__

    def __sub__(self, other):
        return Expr("sub", self, _expr(other))

    def __rsub__(self, other):
        return Expr("sub", _expr(other), self)

    def __neg__(self):
        return Expr("neg", self)

    def __mul__(self, other):
        return Expr("mul", self, _expr(other))

    __rmul__ = __mul__

    def __pow__(self, k):
        if not isinstance(k, int) or k < 0:
            raise ValueError("only non-negative integer powers supported")
        return Expr("pow", self, k=k)

    # -- evaluation ---------------------------------------------------------
    @property
    def rpn(self):
        if self._rpn is None:
            self._rpn = self._to_rpn()
        return self._rpn

    def _to_rpn(self):
        out = []
        stack = [(self, False)]
        while stack:
            node, done = stack.pop()
            if node.op == "const":
                out.append(["c", fstr(node.c)])
            elif node.op == "var":
                out.append(["x", node.i])
            elif done:
                if node.op == "pow":
                    out.append(["^", node.k])
                elif node.op == "neg":
                    out.append(["neg"])
                elif node.op == "add":
                    out.append(["+"])
                elif node.op == "sub":
                    out.append(["-"])
                elif node.op == "mul":
                    out.append(["*"])
                else:
                    raise ValueError(f"bad op {node.op!r}")
            else:
                stack.append((node, True))
                if node.b is not None:
                    stack.append((node.b, False))
                stack.append((node.a, False))
        return out

    def eval_point(self, xs):
        j = jet_eval(self.rpn, [Interval(x) for x in xs], len(xs))
        return j.v.lo

    def value(self, box) -> Interval:
        return jet_eval(self.rpn, box, len(box)).v

    # -- serialization ------------------------------------------------------
    def to_json(self):
        return {"vars": None, "rpn": self.rpn}

    @staticmethod
    def from_rpn(rpn):
        return _from_rpn(rpn)


def _expr(x) -> Expr:
    if isinstance(x, Expr):
        return x
    return Expr.const(x)


def _from_rpn(rpn):
    """Rebuild an Expr tree from RPN (used by the checker for serialization)."""
    stack = []
    for tok in rpn:
        t = tok[0]
        if t == "c":
            stack.append(Expr.const(F(tok[1])))
        elif t == "x":
            stack.append(Expr.var(int(tok[1])))
        elif t == "+":
            b, a = stack.pop(), stack.pop()
            stack.append(Expr("add", a, b))
        elif t == "-":
            b, a = stack.pop(), stack.pop()
            stack.append(Expr("sub", a, b))
        elif t == "*":
            b, a = stack.pop(), stack.pop()
            stack.append(Expr("mul", a, b))
        elif t == "^":
            a = stack.pop()
            stack.append(Expr("pow", a, k=int(tok[1])))
        elif t == "neg":
            a = stack.pop()
            stack.append(Expr("neg", a))
        else:
            raise ValueError(f"bad rpn token {tok!r}")
    if len(stack) != 1:
        raise ValueError("malformed rpn")
    return stack[0]


# ===========================================================================
# Forward-mode interval automatic differentiation  (value, grad, Hessian)
# ===========================================================================

class Jet:
    __slots__ = ("v", "g", "h")

    def __init__(self, v, g, h):
        self.v = v          # Interval
        self.g = g          # list[Interval], length n
        self.h = h          # list[Interval], length n*n (row major)

    @staticmethod
    def const(c, n):
        z = Interval(0)
        return Jet(Interval(c), [z] * n, [z] * (n * n))

    @staticmethod
    def var(i, x, n):
        z = Interval(0)
        o = Interval(1)
        g = [z] * n
        g[i] = o
        return Jet(x, g, [z] * (n * n))

    def __add__(self, other):
        return Jet(self.v + other.v,
                   [self.g[i] + other.g[i] for i in range(len(self.g))],
                   [self.h[i] + other.h[i] for i in range(len(self.h))])

    def __sub__(self, other):
        return Jet(self.v - other.v,
                   [self.g[i] - other.g[i] for i in range(len(self.g))],
                   [self.h[i] - other.h[i] for i in range(len(self.h))])

    def __neg__(self):
        return Jet(-self.v, [-x for x in self.g], [-x for x in self.h])

    def __mul__(self, other):
        n = len(self.g)
        v = self.v * other.v
        g = [self.g[i] * other.v + self.v * other.g[i] for i in range(n)]
        h = [None] * (n * n)
        for i in range(n):
            for j in range(n):
                k = i * n + j
                h[k] = (self.h[k] * other.v
                        + self.g[i] * other.g[j]
                        + self.g[j] * other.g[i]
                        + self.v * other.h[k])
        return Jet(v, g, h)

    def __pow__(self, k):
        if k == 0:
            return Jet.const(1, len(self.g))
        if k == 1:
            return self
        n = len(self.g)
        v = ipow(self.v, k)
        vm1 = ipow(self.v, k - 1)
        vm2 = ipow(self.v, k - 2)
        g = [k * vm1 * self.g[i] for i in range(n)]
        h = [None] * (n * n)
        for i in range(n):
            for j in range(n):
                idx = i * n + j
                h[idx] = (k * (k - 1) * vm2 * self.g[i] * self.g[j]
                          + k * vm1 * self.h[idx])
        return Jet(v, g, h)


def jet_eval(rpn, box, n):
    stack = []
    for tok in rpn:
        t = tok[0]
        if t == "c":
            stack.append(Jet.const(F(tok[1]), n))
        elif t == "x":
            i = int(tok[1])
            if not (0 <= i < n):
                raise ValueError("variable index out of range")
            stack.append(Jet.var(i, box[i], n))
        elif t == "+":
            b = stack.pop()
            a = stack.pop()
            stack.append(a + b)
        elif t == "-":
            b = stack.pop()
            a = stack.pop()
            stack.append(a - b)
        elif t == "*":
            b = stack.pop()
            a = stack.pop()
            stack.append(a * b)
        elif t == "^":
            a = stack.pop()
            stack.append(a ** int(tok[1]))
        elif t == "neg":
            stack.append(-stack.pop())
        else:
            raise ValueError(f"bad rpn token {tok!r}")
    if len(stack) != 1:
        raise ValueError("malformed rpn")
    return stack[0]


# ===========================================================================
# Rigorous lower bound: monotonicity tightening + mean value + 2nd-order Taylor
# ===========================================================================

def rigorous_lower(expr_or_rpn, box):
    """A rigorous rational lower bound for the expression on ``box``.

    Combines the natural interval extension, a mean-value form and a second
    order Taylor form after monotonicity tightening.  All arithmetic is exact.
    """
    rpn = expr_or_rpn.rpn if isinstance(expr_or_rpn, Expr) else expr_or_rpn
    n = len(box)
    X = list(box)

    # 1) Monotonicity tightening for a *lower* bound: if the partial derivative
    #    has a strict sign, f is monotone on the box and the minimum lies on a
    #    face.
    for _ in range(n):
        J = jet_eval(rpn, X, n)
        changed = False
        for i in range(n):
            if X[i].is_point:
                continue
            gi = J.g[i]
            if gi.lo > 0:
                X[i] = Interval(X[i].lo)
                changed = True
            elif gi.hi < 0:
                X[i] = Interval(X[i].hi)
                changed = True
        if not changed:
            break

    J = jet_eval(rpn, X, n)
    best = J.v.lo
    if all(X[i].is_point for i in range(n)):
        return best

    center = [X[i].mid for i in range(n)]
    Jc = jet_eval(rpn, [Interval(c) for c in center], n)
    fc = Jc.v.lo
    delta = [Interval(X[i].lo - center[i], X[i].hi - center[i]) for i in range(n)]

    # 2) Mean value form:  f(c) + grad(X) . (X - c)
    mv = fc
    for i in range(n):
        mv += (J.g[i] * delta[i]).lo
    if mv > best:
        best = mv

    # 3) Second order Taylor:  f(c) + g(c).d + 1/2 d^T H(X) d
    so = fc
    for i in range(n):
        so += (Jc.g[i] * delta[i]).lo
    q = Fraction(0)
    for i in range(n):
        for j in range(n):
            q += (J.h[i * n + j] * (delta[i] * delta[j])).lo
    so += q / 2
    if so > best:
        best = so
    return best

# Box utilities

def box_center(box):
    return [b.mid for b in box]


def split_axis(expr, box):
    """Hansen smear rule, with width fallback."""
    n = len(box)
    J = jet_eval(expr.rpn, box, n)
    best, best_score = None, Fraction(-1)
    for i in range(n):
        w = box[i].width
        if w == 0:
            continue
        m = max(abs(J.g[i].lo), abs(J.g[i].hi))
        score = w * m
        if score > best_score or (score == best_score
                                  and (best is None or w > box[best].width)):
            best, best_score = i, score
    if best is None:
        for i in range(n):
            if box[i].width > 0:
                return i
    return best


def split_box(box, axis):
    b = box[axis]
    m = b.mid
    if m == b.lo or m == b.hi:
        return None
    left = list(box)
    right = list(box)
    left[axis] = Interval(b.lo, m)
    right[axis] = Interval(m, b.hi)
    return left, right

def _lcg_points(box, count, seed=0x9E3779B97F4A7C15):
    n = len(box)
    state = seed & ((1 << 64) - 1)
    pts = []
    for _ in range(count):
        coords = []
        for i in range(n):
            state = (state * 6364136223846793005
                     + 1442695040888963407) & ((1 << 64) - 1)
            t = Fraction(state >> 11, 1 << 53)      # exact dyadic in [0,1)
            coords.append(box[i].lo + t * box[i].width)
        pts.append(coords)
    return pts


def initial_candidates(box):
    n = len(box)
    pts = [box_center(box)]
    if (1 << n) <= 256:
        for mask in range(1 << n):
            pts.append([box[i].hi if (mask >> i) & 1 else box[i].lo
                        for i in range(n)])
    for i in range(n):
        for side in (0, 1):
            p = box_center(box)
            p[i] = box[i].lo if side == 0 else box[i].hi
            pts.append(p)
    pts.extend(_lcg_points(box, 32))
    return pts


def pattern_search(expr, box, start, iters=220):
    x = [F(v) for v in start]
    fx = expr.eval_point(x)
    step = [max(b.width / 4, Fraction(1, 1 << 24)) for b in box]
    for _ in range(iters):
        improved = False
        for i in range(len(box)):
            if box[i].width == 0:
                continue
            for s in (step[i], -step[i]):
                cand = list(x)
                cand[i] = min(max(x[i] + s, box[i].lo), box[i].hi)
                if cand[i] == x[i]:
                    continue
                fc = expr.eval_point(cand)
                if fc < fx:
                    x, fx = cand, fc
                    improved = True
        if not improved:
            step = [s / 2 for s in step]
            if all(s == 0 for s in step):
                break
    return x, fx


def find_incumbent(expr, box):
    cands = initial_candidates(box)
    scored = sorted(cands, key=expr.eval_point)
    best_x, best_v = scored[0], expr.eval_point(scored[0])
    for p in scored[:4]:
        x, v = pattern_search(expr, box, p)
        if v < best_v:
            best_x, best_v = x, v
    return best_x, best_v

# Branch and bound + flat certificate nodes

def branch_and_bound(expr: Expr, root_box, gap, max_iters=200_000,
                     max_leaves=100_000, verbose=False):
    """Best-first branch and bound.

    Returns a certificate dict.  The cover is stored as a flat list of nodes:
    every node has a parent index; a parent has either 0 or 2 children and the
    two children exactly partition the parent along one axis.
    """
    n = len(root_box)
    gap = F(gap)
    root_box = [Interval(b.lo, b.hi) for b in root_box]

    best_x, best_v = find_incumbent(expr, root_box)

    nodes = []

    def make_node(box, lower, parent, axis):
        nodes.append({"box": [[b.lo, b.hi] for b in box], "lower": F(lower),
                      "parent": parent, "axis": axis})
        return len(nodes) - 1

    lo0 = rigorous_lower(expr, root_box)
    root_id = make_node(root_box, lo0, -1, None)

    counter = 0
    heap = [(lo0, counter, root_id)]
    counter += 1

    it = 0
    while heap and it < max_iters:
        it += 1
        lb, _, nid = heap[0]
        if best_v - lb <= gap:
            break
        heapq.heappop(heap)

        node = nodes[nid]
        box = [Interval(lo, hi) for lo, hi in node["box"]]
        axis = split_axis(expr, box)
        if axis is None:
            continue
        pieces = split_box(box, axis)
        if pieces is None:
            continue
        for cb in pieces:
            c = box_center(cb)
            v = expr.eval_point(c)
            if v < best_v:
                best_x, best_v = c, v
        for cb in pieces:
            clo = rigorous_lower(expr, cb)
            cid = make_node(cb, clo, nid, axis)
            heapq.heappush(heap, (clo, counter, cid))
            counter += 1
        if len(nodes) > max_leaves:
            break
        if verbose and it % 1000 == 0:
            print(f"  iter {it:6d}  nodes {len(nodes):6d}  "
                  f"lb {float(lb): .8f}  ub {float(best_v): .8f}")

    global_lb = min(entry[0] for entry in heap)
    proven = (best_v - global_lb) <= gap
    cert = {
        "schema": "certopt/1",
        "objective": expr.to_json(),
        "nvars": n,
        "root": [[b.lo, b.hi] for b in root_box],
        "gap": gap,
        "rounding": "exact-rational",
        "incumbent": {"point": best_x, "value": best_v},
        "nodes": nodes,
        "global_lower": global_lb,
        "proven": bool(proven),
        "stats": {"iterations": it, "nodes": len(nodes)},
    }
    cert["signature"] = certificate_signature(cert)
    return cert

# Serialization

def _jsonable(obj):
    if isinstance(obj, Fraction):
        return fstr(obj)
    if isinstance(obj, Interval):
        return [fstr(obj.lo), fstr(obj.hi)]
    if isinstance(obj, (list, tuple)):
        return [_jsonable(v) for v in obj]
    if isinstance(obj, dict):
        return {k: _jsonable(v) for k, v in obj.items()}
    return obj


def canonical_json(cert) -> str:
    return json.dumps(_jsonable(cert), sort_keys=True, separators=(",", ":"))


def certificate_signature(cert) -> str:
    body = {k: v for k, v in cert.items() if k != "signature"}
    return hashlib.sha256(canonical_json(body).encode("utf-8")).hexdigest()


def cert_to_text(cert) -> str:
    return json.dumps(_jsonable(cert), indent=2, sort_keys=True)

class CheckError(Exception):
    pass


def _parse_box(raw):
    if not isinstance(raw, list) or not raw:
        raise CheckError("box must be a non-empty list")
    out = []
    for pair in raw:
        if isinstance(pair, Interval):
            out.append(pair)
            continue
        if not isinstance(pair, list) or len(pair) != 2:
            raise CheckError(f"bad interval {pair!r}")
        lo, hi = F(pair[0]), F(pair[1])
        if lo > hi:
            raise CheckError(f"reversed interval [{lo},{hi}]")
        out.append(Interval(lo, hi))
    return out


def _same_box(a, b):
    return all(a[i].lo == b[i].lo and a[i].hi == b[i].hi for i in range(len(a)))


def check_certificate(cert, expected_signature=None):
    """Verify a certificate.  Returns (ok, errors, report)."""
    errors = []
    try:
        n = int(cert["nvars"])
        expr = Expr.from_rpn(cert["objective"]["rpn"])
        root = _parse_box(cert["root"])
        if len(root) != n:
            errors.append("root dimension mismatch")
        gap = F(cert["gap"])
        if gap < 0:
            errors.append("negative gap")
        if cert.get("rounding") != "exact-rational":
            errors.append(f"unsupported rounding mode: {cert.get('rounding')!r}")

        sig = certificate_signature(cert)
        if cert.get("signature") != sig:
            errors.append("signature mismatch (certificate was modified)")
        if expected_signature is not None and sig != expected_signature:
            errors.append("signature does not match expected value")

        # ---- structural / partition check on the flat node list -----------
        raw_nodes = cert["nodes"]
        nodes = []
        for idx, nd in enumerate(raw_nodes):
            box = _parse_box(nd["box"])
            if len(box) != n:
                errors.append(f"node {idx} dimension mismatch")
            lo = F(nd["lower"])
            parent = int(nd["parent"])
            axis = nd["axis"]
            if idx == 0:
                if parent != -1:
                    errors.append("root node must have parent -1")
                if not _same_box(box, root):
                    errors.append("root node box != declared root")
            else:
                if not (0 <= parent < idx):
                    errors.append(f"node {idx} has invalid parent")
            nodes.append({"box": box, "lower": lo, "parent": parent,
                          "axis": axis})

        children = {}
        for idx, nd in enumerate(nodes):
            children.setdefault(nd["parent"], []).append(idx)

        for idx, nd in enumerate(nodes):
            kids = children.get(idx, [])
            if len(kids) not in (0, 2):
                continue  # reported below via parent accounting
            if len(kids) == 2:
                c0, c1 = nodes[kids[0]], nodes[kids[1]]
                box = nd["box"]
                diff = [i for i in range(n)
                        if not (c0["box"][i].lo == box[i].lo
                                and c0["box"][i].hi == box[i].hi
                                and c1["box"][i].lo == box[i].lo
                                and c1["box"][i].hi == box[i].hi)]
                if len(diff) != 1:
                    errors.append(f"node {idx}: children do not split exactly "
                                  "one axis")
                else:
                    ax = diff[0]
                    if not (c0["box"][ax].lo == box[ax].lo
                            and c0["box"][ax].hi == c1["box"][ax].lo
                            and c1["box"][ax].hi == box[ax].hi):
                        errors.append(f"node {idx}: children do not exactly "
                                      f"partition parent on axis {ax} "
                                      "(endpoint mistake)")

        # every non-root node must be referenced as a child
        for idx in range(1, len(nodes)):
            p = nodes[idx]["parent"]
            if p < 0 or p >= len(nodes):
                errors.append(f"node {idx} dangling parent")

        # ---- bound check ---------------------------------------------------
        leaves = []
        for idx, nd in enumerate(nodes):
            kids = children.get(idx, [])
            rig = rigorous_lower(expr, nd["box"])
            if nd["lower"] > rig:
                errors.append(
                    f"node {idx}: lower bound {fstr(nd['lower'])} exceeds "
                    f"rigorous lower bound {fstr(rig)} "
                    "(rounding or endpoint mistake)")
            if not kids:
                leaves.append(nd)
            elif len(kids) != 2:
                errors.append(f"node {idx} has {len(kids)} children")

        # The set of leaves must exactly cover the root: volume + disjointness.
        if leaves:
            for nd in leaves:
                for i in range(n):
                    if nd["box"][i].lo < root[i].lo or nd["box"][i].hi > root[i].hi:
                        errors.append("a leaf escapes the root box")
                        break
            for a in range(len(leaves)):
                for b in range(a + 1, len(leaves)):
                    ba, bb = leaves[a]["box"], leaves[b]["box"]
                    disjoint = any(ba[i].hi <= bb[i].lo or bb[i].hi <= ba[i].lo
                                   for i in range(n))
                    if not disjoint:
                        errors.append("leaf boxes overlap (cover is not a tiling)")
            vol = Fraction(1)
            for i in range(n):
                vol *= root[i].width
            lvol = Fraction(0)
            for nd in leaves:
                v = Fraction(1)
                for i in range(n):
                    v *= nd["box"][i].width
                lvol += v
            if lvol != vol:
                errors.append(f"leaf volume {fstr(lvol)} != root volume "
                              f"{fstr(vol)} (gap or overlap in cover)")

        # ---- incumbent -----------------------------------------------------
        inc = cert["incumbent"]
        x = [F(v) for v in inc["point"]]
        if len(x) != n:
            errors.append("incumbent wrong dimension")
        else:
            for i, xi in enumerate(x):
                if not root[i].contains(xi):
                    errors.append(f"incumbent leaves root on axis {i}")
            true_val = expr.eval_point(x)
            claimed = F(inc["value"])
            if true_val != claimed:
                errors.append(f"incumbent value {fstr(claimed)} != "
                              f"f(x)={fstr(true_val)}")

        # ---- gap proof -----------------------------------------------------
        if not leaves:
            errors.append("certificate has no leaf nodes")
            global_lb = None
        else:
            global_lb = min(nd["lower"] for nd in leaves)
            claimed_glb = F(cert["global_lower"])
            if claimed_glb != global_lb:
                errors.append(f"global_lower {fstr(claimed_glb)} != min leaf "
                              f"bound {fstr(global_lb)}")
            ub = F(inc["value"])
            if ub - global_lb > gap:
                errors.append(f"gap not proven: UB-LB = {float(ub-global_lb):.6g}"
                              f" > gap {float(gap):.6g}")

        report = {
            "ok": not errors,
            "errors": errors,
            "leaves": len(leaves),
            "nodes": len(nodes),
            "global_lower": global_lb,
            "incumbent_value": F(cert["incumbent"]["value"]),
            "gap": gap,
            "signature": sig,
        }
        return (not errors), errors, report
    except (KeyError, ValueError, CheckError, TypeError, IndexError) as exc:
        errors.append(f"malformed certificate: {exc!r}")
        return False, errors, {"ok": False, "errors": errors}

def _self_test():
    import json, random
    from fractions import Fraction

    x = Expr.var(0)
    y = Expr.var(1)
    u, v = x - 1, y - 1
    expr = u ** 2 + v ** 4 + u * (v ** 2)        # min 0 at (1,1), singular Hessian
    box = [Interval(-2, 2), Interval(-2, 2)]

    cert = branch_and_bound(expr, box, gap=Fraction(1, 1000))
    ok, errs, rep = check_certificate(cert)
    assert ok, errs
    assert cert["proven"]
    assert F(cert["global_lower"]) <= 0          # true min is 0

    # JSON round-trip is the certificate transport path.
    loaded = json.loads(cert_to_text(cert))
    ok2, errs2, rep2 = check_certificate(loaded, expected_signature=cert["signature"])
    assert ok2, errs2

    # reproducibility
    cert_b = branch_and_bound(expr, box, gap=Fraction(1, 1000))
    assert cert["signature"] == cert_b["signature"]

    def resign(c):
        c["signature"] = certificate_signature(c)
        return c

    # (a) upward-rounded lower bound must be rejected
    bad = resign(__import__("copy").deepcopy(cert))
    for nd in bad["nodes"]:
        nd["lower"] = F(nd["lower"]) + Fraction(1, 10 ** 9)
    resign(bad)
    assert not check_certificate(bad)[0]

    # (b) endpoint mistake must be rejected
    bad = resign(__import__("copy").deepcopy(cert))
    kids_by_parent = {}
    for i, nd in enumerate(bad["nodes"]):
        kids_by_parent.setdefault(nd["parent"], []).append(i)
    idx = next(i for i, nd in enumerate(bad["nodes"])
               if len(kids_by_parent.get(i, [])) == 2)
    c0 = bad["nodes"][kids_by_parent[idx][0]]
    ax = c0["axis"]
    c0["box"][ax][1] = F(c0["box"][ax][1]) + Fraction(1, 1000)
    resign(bad)
    assert not check_certificate(bad)[0]

    # (c) wrong rounding mode must be rejected
    bad = resign(__import__("copy").deepcopy(cert))
    bad["rounding"] = "round-up"
    resign(bad)
    assert not check_certificate(bad)[0]

    # (d) fuzz: certified lower bound never exceeds sampled values
    rng = random.Random(0)
    def rand_expr(n, depth):
        if depth == 0:
            return (Expr.const(Fraction(rng.randint(-4, 4), rng.randint(1, 4)))
                    if rng.random() < 0.35 else Expr.var(rng.randrange(n)))
        op = rng.choice(["+", "-", "*", "pow"])
        if op == "pow":
            return rand_expr(n, depth - 1) ** rng.randint(1, 4)
        a, b = rand_expr(n, depth - 1), rand_expr(n, depth - 1)
        return a + b if op == "+" else (a - b if op == "-" else a * b)
    for _ in range(200):
        n = rng.randint(1, 3)
        e = rand_expr(n, 3)
        bx = [Interval(Fraction(rng.randint(-5, 1), 2),
                       Fraction(rng.randint(2, 6), 2)) for _ in range(n)]
        lb = rigorous_lower(e, bx)
        for p in _lcg_points(bx, 50) + initial_candidates(bx):
            assert lb <= e.eval_point(p)

    print(f"PASS: leaves={rep['leaves']} LB={float(rep['global_lower']):.3e} "
          f"UB={float(rep['incumbent_value']):.3e} "
          f"signature={cert['signature'][:16]}...")
    print("PASS: JSON round-trip, reproducibility, tamper rejection, fuzz rigor")

Key points to reuse
