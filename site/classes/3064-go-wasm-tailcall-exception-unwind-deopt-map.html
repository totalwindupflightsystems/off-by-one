Lowering WebAssembly return_call while preserving exception unwind, stack traces and deopt maps

Problem class: go-wasm-tailcall-exception-unwind-deopt-map Environment: go1.26 (module wasmlower, standalone Go 1.26 program + wabt 1.0.36) Artifacts: ~/wasmlower (source, tests, verification scripts)

1. Summary

return_call / return_call_indirect must be replaced with ordinary call + return code for engines that do not implement the tail-call proposal. The naive rewrite

return_call $f       ->  call $f ; return
return_call_indirect ->  call_indirect ; return

is almost correct but silently changes exception semantics: a real return_call replaces the current frame before the callee runs, so the current frame's catch / delegate handlers are already gone and cannot observe the callee's exception. A call inside a try leaves the handler installed, so the callee's exception is caught. This is observable and asserted by the official spec test-suite.

The fix is a per-function lowering that

  1. keeps argument evaluation inside the original try scopes (so exceptions raised while computing arguments are still caught),
  2. leaves the original try/delegate scopes with a normal br (which does not fire any handler), and
  3. performs the real call / call_indirect at function scope, outside every handler in the replaced frame, so the callee's exception/trap propagates past the frame exactly like return_call.

Along the way the pass recomputes branch depths for the inserted control flow and rewrites the byte offsets referenced by the module's go.deopt source-location map.

Verified against wabt's reference interpreter/V8 and against the official try_catch.wast (42/42) and try_delegate.wast (26/26) spec suites, with the tail-call modules substituted by the lowered versions.

2. Ground truth: what return_call means with exceptions

The spec is unambiguous. In WebAssembly/exception-handling/test/legacy/exceptions/core/try_catch.wast:

(func (export "return-call-in-try-catch")
  (try
    (do (return_call $throw-void))
    (catch $e0)))

(assert_exception (invoke "return-call-in-try-catch"))

The same pattern exists for try/delegate:

(func (export "return-call-in-try-delegate")
  (try $l
    (do (try
          (do (return_call $throw-void))
          (delegate $l)))
    (catch $e0)))

(assert_exception (invoke "return-call-in-try-delegate"))

assert_exception means the callee's exception is not caught by the enclosing catch. wabt and V8 agree:

$ wasm-interp --enable-all eh4.wasm --run-all-exports
h() => error: uncaught exception
$ node run.mjs eh4.wasm
h threw: Exception wasm exception tag=...

whereas the naive rewrite is caught and returns normally:

$ wasm-interp --enable-all eh5.wasm --run-all-exports
h() => i32:49
$ node run.mjs eh5.wasm
h returned: 49

So return_call is not definitionally equal to call; return in the presence of exception handlers. Any lowerer that emits call; return inside the original try scope is wrong.

3. Root-cause analysis

3.1 Semantic bug of the naive lowering

return_call performs a frame replacement: the current activation and all of its handlers are discarded, then the callee is entered. Consequently a thrown exception unwinds past the current function. delegate makes this worse: an inner try … delegate $outer normally forwards the exception to $outer, but if the throw comes out of a return_call, the whole frame (including $outer's handler) is already gone.

With call; return, the current frame and its handler stack remain live for the duration of the call, so catch/delegate fire. The difference is observable for every tail call that sits lexically inside a try, or inside a catch, of a frame that would handle the callee's exception.

3.2 Branch depth

try, catch, delegate and all structured control instructions define labels that are addressed by relative depth. Any lowering that routes the call through a shared epilogue (instead of a literal return) inserts new labels and must (a) compute the depth of the branch that leaves the handlers from the site's current nesting level, and (b) compute the depth of the epilogue branch. delegate N in particular is depth-sensitive.

3.3 Deopt maps

The module carries a go.deopt custom section that maps instruction byte offsets to source lines and to the local slots live at that point (used to build stack traces / debugger frames). Because the transform inserts wrapper blocks, a stash sequence and a dispatch thunk, all byte offsets after an insertion shift. Every deopt point must be re-keyed to its new offset.

3.4 Multi-value results

A function may return several values. The epilogue block that receives the normal path must have the function's full result list, and a WebAssembly block with more than one result must be encoded as a type index of a new [] -> results function type appended to the type section.

4. Exact fix

4.1 Rewritten shape of a function

For any function that contains at least one tail call we emit

block $normal (result R)          ;; R = function result list
  block $escape                   ;; common landing pad, outside all handlers
    <original body>               ;; tail calls replaced (see 4.2)
    br $normal                    ;; normal fall-through, carrying R
  end
  <dispatch>                      ;; one arm per tail-call site (see 4.3)
  unreachable
end
end                               ;; function end

Why this is correct:

  • The original body is emitted unchanged except for the tail-call sites. Therefore every argument-producing instruction stays exactly where it was, inside the same try/catch/delegate scopes. Exceptions during argument evaluation are still caught by the frame's handlers.
  • br $escape is a normal branch out of all the enclosing try blocks, so it does not fire catch, catch_all or delegate.
  • The actual call/call_indirect is emitted after $escape has closed, at function scope, where no handler of the replaced frame is active. A throw or trap from the callee therefore leaves the current frame, exactly matching return_call.
  • The normal (non-tail) path still produces the function results and exits through $normal.

4.2 Lowering one tail-call site

Given a tail call at nesting depth d (number of enclosing labels, i.e. the original block/loop/if/try/try_table labels) with argument types A* and, for the indirect form, a table-index operand:

;; value stack on entry: A0 A1 ... An-1 [tableidx]
local.set $idx                     ;; only for return_call_indirect
local.set $t_{n-1}
...
local.set $t_0
i32.const <site-id>
local.set $sel
br d                               ;; = branch to $escape

The temps are fresh locals appended to the local declaration list, so no existing local index changes. The depth is exactly the original nesting depth d: from the site, the labels outward are the d original labels, then $escape, then $normal.

4.3 Dispatch

After $escape has ended, each site has a small thunk. The thunks are outside all handlers:

local.get $sel
i32.const <site-id>
i32.eq
if
  local.get $t_0
  ...
  local.get $t_{n-1}
  [local.get $idx]                 ;; indirect only
  call $f / call_indirect T Tab
  br 1                             ;; to $normal, carrying R
end
...                                ;; repeat per site
unreachable

This preserves the value order required by call/call_indirect (args first, table index last).

4.4 Branch-depth bookkeeping

  • The two wrapper blocks are the outermost labels of the function. A branch inside the original body that targets another label inside the body keeps the same relative depth, because both the branch and the target are inside both wrappers. Existing depths therefore need no fix-up.
  • The inserted br $escape uses depth d = the site's original nesting depth.
  • The inserted br $normal uses depth 1 (one if level below $normal in the dispatch; directly below $escape on the normal fall-through path).
  • delegate N immediates are never rewritten for the same reason: their target remains inside the body, closer than the wrappers.

This is the design point that makes correct depth handling cheap: add the new labels only outside the region whose internal depths must stay stable.

4.5 Multi-value block types

$normal's block type is encoded as

  • 0x40 when R = [],
  • the single valtype byte when R = [t],
  • a signed-Leb type-index when |R| > 1, after appending a fresh funcType{params: nil, results: R} to the type section.

Appending a type never shifts existing type indices.

4.6 Deopt-map remapping

While re-emitting a body, record old instruction start -> new byte offset. A deopt point is remapped to the new offset of the instruction that contained it (largest old start <= point, plus the in-instruction delta). For a point on a return_call, this lands on the first emitted stash instruction of that site. Functions with no tail call are emitted byte-for-byte, so their points are untouched.

4.7 Implementation

The pass is a standalone Go 1.26 program (module wasmlower) that parses the binary, rewrites function bodies, rebuilds the type/code sections and patches go.deopt. The core is:

// lowerBody rewrites a single defined function body, lowering tail calls.
func (lc *loweringCtx) lowerBody(funcIdx uint32, body []byte) (newBody []byte, changed bool, err error) {
    m := lc.m
    locals, instrs, err := decodeBody(body)
    if err != nil { return nil, false, err }
    fti, ok := m.funcTypeIndex(funcIdx)
    if !ok { return nil, false, fmt.Errorf("func %d has no type", funcIdx) }
    ft := m.types[fti]

    hasTail := false
    for i := range instrs { if instrs[i].tail != 0 { hasTail = true; break } }
    if !hasTail { return body, false, nil } // unchanged: deopt offsets stable

    // Fresh locals: selector + one temp per argument (+ table index).
    var nlocals uint32
    for _, l := range locals { nlocals += l.count }
    selLocal := uint32(len(ft.params)) + nlocals
    nextLocal := selLocal + 1

    type site struct {
        instrIdx int
        instr    *instr
        params   []byte
        temps    []uint32
        tidx     uint32
        hasTidx  bool
    }
    var sites []site
    for i := range instrs {
        in := &instrs[i]
        if in.tail == 0 { continue }
        var params []byte
        switch in.tail {
        case 1: // return_call
            ti, ok := m.funcTypeIndex(in.funcIdx)
            if !ok { return nil, false, fmt.Errorf("return_call target %d unknown", in.funcIdx) }
            params = m.types[ti].params
        case 2: // return_call_indirect
            if int(in.typeIdx) >= len(m.types) {
                return nil, false, fmt.Errorf("return_call_indirect type %d unknown", in.typeIdx)
            }
            params = m.types[in.typeIdx].params
        default:
            return nil, false, fmt.Errorf("return_call_ref lowering is not supported")
        }
        s := site{instrIdx: i, instr: in, params: params}
        for range params { s.temps = append(s.temps, nextLocal); nextLocal++ }
        if in.tail == 2 { s.tidx, s.hasTidx = nextLocal, true; nextLocal++ }
        sites = append(sites, s)
    }

    // Local declarations: originals + i32 selector + temps.
    newLocals := append([]localDecl(nil), locals...)
    newLocals = append(newLocals, localDecl{count: 1, typ: vtI32}) // $sel
    for _, s := range sites {
        for _, p := range s.params { newLocals = append(newLocals, localDecl{count: 1, typ: p}) }
        if s.hasTidx { newLocals = append(newLocals, localDecl{count: 1, typ: vtI32}) }
    }
    var out []byte
    out = appendU32(out, uint32(len(newLocals)))
    for _, l := range newLocals { out = appendU32(out, l.count); out = append(out, l.typ) }

    lc.offsetMap = map[int]int{}

    // block $normal (result R); block $escape
    out = append(out, opBlock); out = append(out, lc.blockTypeFor(ft.results)...)
    out = append(out, opBlock, 0x40)

    siteByInstr := map[int]int{}
    for si, s := range sites { siteByInstr[s.instrIdx] = si }

    for i := range instrs {
        in := &instrs[i]
        if in.op == opEnd && i == len(instrs)-1 { continue } // function end handled below
        if si, ok := siteByInstr[i]; ok {
            s := sites[si]
            lc.offsetMap[in.start] = len(out)
            if s.hasTidx { out = append(out, opLocalSet); out = appendU32(out, s.tidx) }
            for j := len(s.temps) - 1; j >= 0; j-- {     // args are pushed left-to-right
                out = append(out, opLocalSet); out = appendU32(out, s.temps[j])
            }
            out = append(out, opI32Const); out = appendU32(out, uint32(si))
            out = append(out, opLocalSet); out = appendU32(out, selLocal)
            out = append(out, opBr); out = appendU32(out, uint32(in.depth)) // -> $escape
            continue
        }
        lc.offsetMap[in.start] = len(out)
        out = append(out, in.op); out = append(out, in.imm...)
    }

    out = append(out, opBr, 0x01) // normal path -> $normal
    out = append(out, opEnd)      // end $escape

    for si, s := range sites {
        out = append(out, opLocalGet); out = appendU32(out, selLocal)
        out = append(out, opI32Const); out = appendU32(out, uint32(si))
        out = append(out, 0x46) // i32.eq
        out = append(out, opIf, 0x40)
        for _, t := range s.temps { out = append(out, opLocalGet); out = appendU32(out, t) }
        switch s.instr.tail {
        case 1:
            out = append(out, opCall); out = appendU32(out, s.instr.funcIdx)
        case 2:
            if s.hasTidx { out = append(out, opLocalGet); out = appendU32(out, s.tidx) }
            out = append(out, opCallIndirect); out = appendU32(out, s.instr.typeIdx); out = appendU32(out, s.instr.tableIdx)
        }
        out = append(out, opBr, 0x01) // -> $normal
        out = append(out, opEnd)
    }
    out = append(out, opUnreachable)
    out = append(out, opEnd) // end $normal
    out = append(out, opEnd) // function end
    return out, true, nil
}

blockTypeFor appends the multi-value type on demand:

func (lc *loweringCtx) blockTypeFor(results []byte) []byte {
    switch len(results) {
    case 0:  return []byte{0x40}
    case 1:  return []byte{results[0]}
    default:
        idx := uint32(len(lc.m.types) + len(lc.newTypes))
        lc.newTypes = append(lc.newTypes, funcType{results: append([]byte(nil), results...)})
        return appendS(nil, int64(idx), 33)
    }
}

Deopt remapping (encode.go):

func remapDeopt(pts []deoptPoint, offsetMap map[int]int) []deoptPoint {
    var starts []int
    for k := range offsetMap { starts = append(starts, k) }
    sortInt(starts)
    mapOffset := func(old int) int {
        if no, ok := offsetMap[old]; ok { return no }
        lo, hi := 0, len(starts)
        for lo < hi { // greatest instruction start <= old
            mid := (lo + hi) / 2
            if starts[mid] <= old { lo = mid + 1 } else { hi = mid }
        }
        if lo == 0 { return old }
        s := starts[lo-1]
        return offsetMap[s] + (old - s)
    }
    out := make([]deoptPoint, len(pts))
    for i, p := range pts { np := p; np.offset = mapOffset(p.offset); out[i] = np }
    return out
}

The decoder tracks a label stack while scanning the body (pushing for block/loop/if/try/try_table, popping for end and for delegate) so that instr.depth is known at every tail call. Instruction immediates are decoded with full LEB128 handling for the control, call, local/global, memory, constant, table, reference and 0xfc-prefixed instruction families; SIMD/threads/GC are rejected rather than mis-decoded.

4.8 What the output looks like

Reference:

(func (export "simple") (param i32) (result i32)
  local.get 0
  return_call $inc)

Lowered (from wasm2wat):

(func (;1;) (type $ii) (param i32) (result i32)
  (local i32 i32)
  block (result i32)      ;; $normal
    block                 ;; $escape
      local.get 0
      local.set 2         ;; stash arg
      i32.const 0         ;; site id
      local.set 1         ;; $sel
      br 0                ;; leave $escape (no handlers fire)
      br 1                ;; normal fall-through -> $normal
    end
    local.get 1
    i32.const 0
    i32.eq
    if
      local.get 2
      call $inc           ;; real call is outside every handler
      br 1                ;; -> $normal
    end
    unreachable
  end)

6.4 Notes and limitations

  • return_call_ref is rejected with a diagnostic (the reference-typed local needed to stash the function reference is engine/type-system specific); return_call and return_call_indirect are fully supported.
  • SIMD/threads/GC opcodes are rejected rather than parsed incorrectly; the decoder covers the MVP, bulk-memory/bulk-table, reference types and the legacy and try_table exception instructions.
  • The transform keeps the caller frame physically present while the callee runs (that is what makes the handler-bypass emulation possible with plain wasm). Runtime stack unwinding therefore still has a frame to inspect; the source-location/deopt metadata is corrected so debuggers and traps map to the right source positions. True frame elision requires engine support and is orthogonal to this bytecode pass.
  • Functions with no tail call are copied byte-for-byte, so their deopt maps and branch structure are untouched.
