CF-274 — hermes-worker-stall-after-first-edit: bounded first-edit checkpoint, exact-PID stop, and a single changed-brief retry

Problem class: hermes-worker-stall-after-first-edit Environment: Hermes api_server, unattended coding-herms scheduler tick Repo/row: code-factory / CF-274 Observed: two attempts, zero product diff; exact process trees stopped by PID.

1. Symptom and impact

In the unattended shared checkout a worker would:

  1. start under a scheduler tick,
  2. write a first evidence edit — a transcript / narrate / run artifact,
  3. stay alive for minutes with no source diff and no commit,
  4. get reaped only when the tick budget expired (7m32s on attempt 1, 6m2s on attempt 2), or by hand.

Attempt 2 produced only another transcript artifact and timed out again. So the retry burned a second full tick and still produced no product change.

Two properties make this worse than "a slow worker":

  • It is not a crash. The process is S/D-state alive the whole time, so any supervisor that equates "process alive" with "work in progress" waits out the entire timeout.
  • It is repeatable at the tick level. Re-dispatching the same brief reloads the same oversized context and reproduces the same stall. Left alone it will occupy --max-concurrent slots (4 in the hardened unit) and can leave D/Z leftovers that block <email>, which the hermes-user-manager-heal.sh cron exists to clean up.

2. Root-cause analysis

The stall is the symptom; the defect is that the tick has no bounded first-edit checkpoint, no exact process identity, and an unbounded, brief-identical retry policy.

2.1 There is no product-diff checkpoint — evidence counts as progress

The foreman dispatches a worker and waits for the tick (schedulerd --tick-timeout, 600s in the hardened unit). Nothing in that wait requires a product change. A worker that only calls toolsd narrate, toolsd write --root on an artifact path, or writes .hermes/.../artifacts/... has "done something" but has not changed the product. The scheduler cannot tell the difference, so it waits out the deadline. This is why both attempts produced "zero source diff" yet ran to timeout.

2.2 The stall is a transport stall, not a crash

The mechanism named in the report is that the transport worker consumed a large context and stalled before implementation. A model/transport stall leaves the process parked in a read rather than exiting: the agent loaded the brief plus a large repo/transcript context, exhausted or wedged the model request, and never got to the implementation step. Because the process is alive and emits no error, the only signal available is "no product diff after N seconds" — which is exactly what the current tick does not measure.

2.3 No exact process identity at spawn

Nothing records the worker's pid, start time, process group, session, or cgroup at spawn. Cleanup therefore falls back to pattern kills (pkill -f, or fuser -k on a port), which either miss the real tree or hit an unrelated process, and which cannot tell a recycled PID from the original. The report is explicit that the exact PID tree had to be polled and stopped. That is a missing primitive, not a tuning problem.

2.4 The retry is unbounded and brief-identical

The second dispatch used effectively the same brief. That reloads the same large context, so it stalls the same way. There is no attempt counter and no "the brief must materially change" gate, so the scheduler can keep paying the same cost. The report's own prevention line is the correct policy: bounded first-edit checkpoint + retry once with a materially changed brief.

2.5 Why leftovers wedge the user manager

If the worker holds an sshfs/FUSE mount in the shared checkout, a kill can leave a task in D state. D/Z tasks cannot be reaped by the user manager's cgroup teardown, so <email> fails to restart ("Processes still around after final SIGKILL") and every user service goes down. Stopping the tree before it accumulates blocked descendants, and migrating any survivor out of the unit cgroup, are both part of the fix.

3. The fix

Three pieces, all drop-in:

  1. hermes_first_edit_guard.py — runs beside the worker from spawn. It records exact process identity, snapshots the checkout, waits a bounded --deadline for a product change, and on expiry preserves evidence then stops the exact PID tree (leaves-first, TERM → grace → KILL, polled to zero).
  2. hermes_retry_gate.py — a persistent attempt ledger. It denies a re-dispatch whose brief is byte-identical and denies anything beyond one retry, so a stall can never loop.
  3. Wiring + hardening — the guard runs at spawn, the tick timeout is set above the checkpoint but below the old value, and the worker gets its own session/process group so the stop is exact.

3.1 hermes_first_edit_guard.py

#!/usr/bin/env python3
"""
hermes_first_edit_guard.py — bounded first-edit checkpoint for unattended
Hermes worker ticks.

Problem class: hermes-worker-stall-after-first-edit (CF-274)

A worker can write an "evidence"/transcript artifact, then sit alive for
minutes with no *product* diff or commit. The tick budget is spent waiting and
the process tree is never reaped, so a plain re-dispatch repeats the stall and
can wedge the user manager with D/Z leftovers.

This guard closes the loop:

  1. records the exact process identity (pid, starttime, pgid, sid, cgroup)
     at spawn time, so a later kill cannot hit a recycled PID;
  2. snapshots the checkout baseline, then polls for a *product* change
     (tracked-file edit, or a new file matching the product extension set)
     within a bounded deadline;
  3. if the deadline expires with only evidence artifacts, it preserves the
     evidence (run record + transcript + process tree + git diff) BEFORE
     stopping anything;
  4. stops the exact PID tree, leaves-first, TERM -> grace -> KILL, and polls
     until no live member remains (D/Z members are reported, not ignored);
  5. exits with a machine-readable code the foreman can act on.

Exit codes:
  0  product diff observed within the deadline (worker is progressing)
  2  stalled: deadline expired with no product diff; tree stopped
  4  worker already gone with no product diff (stalled, nothing to stop)
  3  operational error

Pure stdlib. Tested against a synthetic child tree (see verification.md).
"""

from __future__ import annotations

import argparse
import json
import os
import re
import signal
import subprocess
import sys
import time
from dataclasses import dataclass, field
from typing import Optional

# --------------------------------------------------------------------------- #
# defaults
# --------------------------------------------------------------------------- #

PRODUCT_EXTS = (
    "go", "py", "rs", "ts", "tsx", "js", "jsx", "mjs", "cjs", "java", "kt",
    "rb", "php", "c", "h", "cc", "cpp", "hpp", "cs", "swift", "scala", "sh",
    "bash", "zsh", "sql", "proto", "toml", "yaml", "yml", "json", "md", "html",
    "htm", "css", "scss", "tf", "hcl", "gradle", "xml", "txt", "cfg", "ini",
    "env", "mod", "sum", "lock", "gitignore",
)
PRODUCT_NAMES = re.compile(
    r"(^|/)(Dockerfile|Makefile|Rakefile|Gemfile|Procfile|Vagrantfile|"
    r"BUILD|WORKSPACE|CMakeLists\.txt)$"
)
PRODUCT_EXT_RE = re.compile(r"\.(" + "|".join(PRODUCT_EXTS) + r")$", re.I)

# Paths that are never "product". Transcripts, run records, evidence blocks and
# the agent's own state all live under these prefixes / suffixes.
DEFAULT_EVIDENCE_RE = re.compile(
    r"(^|/)\.hermes/|(^|/)\.coding-hermes/|"
    r"(^|/)(artifacts?|evidence|transcripts?|runs?|logs?|reports?)/|"
    r"\.(evidence|transcript|narrat\w*|guard)\.(json|jsonl|md|txt)$|"
    r"(^|/)(EVIDENCE|RUN|TRANSCRIPT|NOTES?|HANDOFF)[^/]*$",
    re.I,
)


# --------------------------------------------------------------------------- #
# process identity
# --------------------------------------------------------------------------- #

def proc_starttime(pid: int) -> Optional[int]:
    try:
        with open(f"/proc/{pid}/stat", "rb") as fh:
            data = fh.read().decode("utf-8", "replace")
    except OSError:
        return None
    # comm may contain spaces/parens; everything after ") " is fixed-position.
    try:
        rest = data.rsplit(") ", 1)[1].split()
    except IndexError:
        return None
    # rest[0] == state (field 3); starttime is field 22 -> index 19.
    try:
        return int(rest[19])
    except (IndexError, ValueError):
        return None


def proc_cgroup(pid: int) -> str:
    try:
        with open(f"/proc/{pid}/cgroup") as fh:
            for line in fh:
                parts = line.strip().split("::", 1)
                if len(parts) == 2:
                    return parts[1]
    except OSError:
        pass
    return ""


def proc_children_map() -> dict[int, list[int]]:
    children: dict[int, list[int]] = {}
    for name in os.listdir("/proc"):
        if not name.isdigit():
            continue
        pid = int(name)
        try:
            with open(f"/proc/{pid}/stat", "rb") as fh:
                data = fh.read().decode("utf-8", "replace")
            ppid = int(data.rsplit(") ", 1)[1].split()[1])  # field 4 -> idx 1
        except (OSError, IndexError, ValueError):
            continue
        children.setdefault(ppid, []).append(pid)
    return children


def descendant_tree(root: int) -> list[int]:
    """All live descendants of root (including root), BFS, leaves last."""
    children = proc_children_map()
    seen: set[int] = set()
    order: list[int] = []
    stack = [root]
    while stack:
        pid = stack.pop()
        if pid in seen or pid <= 1:
            continue
        seen.add(pid)
        order.append(pid)
        stack.extend(children.get(pid, []))
    return order


def proc_state(pid: int) -> str:
    try:
        with open(f"/proc/{pid}/stat", "rb") as fh:
            return fh.read().decode("utf-8", "replace").rsplit(") ", 1)[1][0]
    except (OSError, IndexError):
        return "?"


def pstree_text(root: int) -> str:
    try:
        out = subprocess.run(
            ["ps", "-o", "pid,ppid,pgid,sid,stat,etime,args", "--ppid",
             str(root), "--forest"],
            capture_output=True, text=True, timeout=10,
        ).stdout
    except Exception:
        out = ""
    try:
        head = subprocess.run(
            ["ps", "-o", "pid,ppid,pgid,sid,stat,etime,args", "-p", str(root)],
            capture_output=True, text=True, timeout=10,
        ).stdout
    except Exception:
        head = ""
    return head + out


@dataclass
class WorkerIdentity:
    pid: int
    starttime: Optional[int]
    pgid: Optional[int]
    sid: Optional[int]
    cgroup: str
    verified: bool = True


def capture_identity(pid: int) -> WorkerIdentity:
    st = proc_starttime(pid)
    try:
        pgid = os.getpgid(pid)
    except OSError:
        pgid = None
    try:
        sid = os.getsid(pid)
    except OSError:
        sid = None
    return WorkerIdentity(pid, st, pgid, sid, proc_cgroup(pid), st is not None)


def alive_and_same(idn: WorkerIdentity) -> bool:
    st = proc_starttime(idn.pid)
    if st is None:
        return False
    if idn.starttime is not None and st != idn.starttime:
        return False  # PID recycled; do NOT touch it
    return True


# --------------------------------------------------------------------------- #
# checkout snapshot
# --------------------------------------------------------------------------- #

@dataclass
class Snapshot:
    entries: dict[str, str] = field(default_factory=dict)  # path -> "XY:sha"


def _hash_file(root: str, rel: str) -> str:
    import hashlib
    p = os.path.join(root, rel)
    try:
        h = hashlib.sha1()
        with open(p, "rb") as fh:
            for chunk in iter(lambda: fh.read(65536), b""):
                h.update(chunk)
        return h.hexdigest()[:16]
    except OSError:
        return "absent"


def snapshot(root: str) -> Snapshot:
    """git status --porcelain=v1 -z, hashing each changed path's content."""
    try:
        out = subprocess.run(
            ["git", "-C", root, "status", "--porcelain=v1", "-z",
             "--untracked-files=all"],
            capture_output=True, text=True, timeout=30,
        )
    except Exception as exc:  # pragma: no cover
        raise RuntimeError(f"git status failed: {exc}") from exc
    if out.returncode != 0:
        raise RuntimeError(f"git status rc={out.returncode}: {out.stderr.strip()}")

    snap = Snapshot()
    fields = out.stdout.split("\0")
    i = 0
    while i < len(fields):
        entry = fields[i]
        i += 1
        if not entry:
            continue
        xy, path = entry[:2], entry[3:]
        # rename/copy carry an extra NUL-terminated source path
        if ("R" in xy or "C" in xy) and i < len(fields) and fields[i]:
            i += 1
        snap.entries[path] = f"{xy}:{_hash_file(root, path)}"
    return snap


def classify(root: str, snap: Snapshot, evidence_re: re.Pattern,
             product_re: Optional[re.Pattern]) -> tuple[list[str], list[str]]:
    product, evidence = [], []
    for path, meta in snap.entries.items():
        xy = meta.split(":", 1)[0]
        tracked = xy != "??"
        if evidence_re.search(path):
            evidence.append(path)
        elif product_re is not None:
            if product_re.search(path):
                product.append(path)
        elif tracked or PRODUCT_EXT_RE.search(path) or PRODUCT_NAMES.search(path):
            product.append(path)
    return product, evidence


def new_changes(base: Snapshot, cur: Snapshot) -> dict[str, str]:
    out: dict[str, str] = {}
    for path, meta in cur.entries.items():
        if base.entries.get(path) != meta:
            out[path] = meta
    # deletions also count
    for path in base.entries:
        if path not in cur.entries:
            out[path] = "deleted"
    return out


# --------------------------------------------------------------------------- #
# evidence preservation
# --------------------------------------------------------------------------- #

def preserve_evidence(state_dir: str, run_id: str, root: str, idn: WorkerIdentity,
                      elapsed: float, deadline: float, product: list[str],
                      evidence: list[str], changes: dict[str, str],
                      baseline: Snapshot, current: Snapshot) -> str:
    run_dir = os.path.join(state_dir, run_id)
    os.makedirs(run_dir, exist_ok=True)
    evidence_copy_dir = os.path.join(run_dir, "evidence")
    os.makedirs(evidence_copy_dir, exist_ok=True)

    def dump(name: str, text: str) -> None:
        with open(os.path.join(run_dir, name), "w") as fh:
            fh.write(text)

    # 1. process tree + identity, captured while processes still exist
    dump("processes.txt",
         f"=== identity ===\n{json.dumps(idn.__dict__, default=str, indent=2)}\n"
         f"=== ps forest ===\n{pstree_text(idn.pid) if alive_and_same(idn) else '(root already gone)'}\n")
    dump("git-status.txt", subprocess.run(
        ["git", "-C", root, "status", "--porcelain=v1"], capture_output=True,
        text=True).stdout)
    dump("git-diff.patch", subprocess.run(
        ["git", "-C", root, "diff", "--binary"], capture_output=True,
        text=True).stdout)

    # 2. copy every evidence artifact this worker produced
    copied = []
    for rel in sorted(set(evidence)):
        src = os.path.join(root, rel)
        if os.path.isfile(src):
            dst = os.path.join(evidence_copy_dir, rel.replace("/", "__"))
            try:
                with open(src, "rb") as sf, open(dst, "wb") as df:
                    df.write(sf.read())
                copied.append(rel)
            except OSError:
                pass

    record = {
        "run_id": run_id,
        "root": root,
        "ts": time.time(),
        "elapsed_s": round(elapsed, 1),
        "deadline_s": deadline,
        "outcome": "stalled_no_product_diff",
        "identity": {**idn.__dict__, "verified_at_kill": idn.verified},
        "product_changes": sorted(product),
        "evidence_changes": sorted(evidence),
        "all_changes": changes,
        "evidence_copied": copied,
        "state": {p: proc_state(idn.pid) for p in descendant_tree(idn.pid)},
    }
    with open(os.path.join(run_dir, "run.json"), "w") as fh:
        json.dump(record, fh, indent=2, default=str)
    try:
        os.chmod(os.path.join(run_dir, "run.json"), 0o444)
    except OSError:
        pass
    return run_dir


# --------------------------------------------------------------------------- #
# stop the exact tree
# --------------------------------------------------------------------------- #

def stop_tree(idn: WorkerIdentity, grace: float, stop_timeout: float,
              log, run_id: str = "") -> dict:
    result = {"root": idn.pid, "killed": [], "lingering": [], "recycled": False}
    if not alive_and_same(idn):
        result["recycled"] = idn.starttime is not None and proc_starttime(idn.pid) is not None
        result["note"] = "root gone or PID recycled; nothing stopped"
        return result

    tree = descendant_tree(idn.pid)
    leaves_first = list(reversed(tree))

    # 1. cgroup kill is the only thing that reliably stops a whole scope,
    #    including children that re-parent to init. Use it only when the scope
    #    looks worker-owned (named after the run) to avoid collateral.
    cg = idn.cgroup
    cg_leaf = os.path.basename(cg.rstrip("/")) if cg else ""
    # Never touch the root/cgroup-of-everything. Only kill a scope that is
    # unambiguously this worker's (named after the run or an explicit worker
    # scope). Exact-PID tree kill below is the primary mechanism.
    cg_owned = bool(cg) and cg.strip("/") != "" and (
        "worker" in cg_leaf or "run-" in cg_leaf or
        (run_id and run_id in cg_leaf))
    cg_kill = os.path.join("/sys/fs/cgroup", cg.lstrip("/"), "cgroup.kill") if cg else ""
    if cg_owned and os.path.exists(cg_kill) and idn.pgid == idn.pid:
        try:
            with open(cg_kill, "w") as fh:
                fh.write("1")
            log(f"cgroup.kill written for {cg}")
        except OSError as exc:
            log(f"cgroup.kill failed ({exc}); falling back to signals")

    # 2. TERM the process group when the worker owns its own group/session.
    if idn.pgid == idn.pid:
        try:
            os.killpg(idn.pgid, signal.SIGTERM)
            result["killed"].append(f"pgid:{idn.pgid}=TERM")
        except OSError:
            pass
    # 3. TERM every exact descendant, leaves first.
    for pid in leaves_first:
        try:
            os.kill(pid, signal.SIGTERM)
            result["killed"].append(f"pid:{pid}=TERM")
        except OSError:
            pass

    # 4. grace, then KILL survivors.
    deadline = time.monotonic() + grace
    while time.monotonic() < deadline:
        if not any(os.path.exists(f"/proc/{p}") for p in tree):
            break
        time.sleep(0.2)
    for pid in leaves_first:
        if os.path.exists(f"/proc/{pid}"):
            try:
                os.kill(pid, signal.SIGKILL)
                result["killed"].append(f"pid:{pid}=KILL")
            except OSError:
                pass
    if idn.pgid == idn.pid:
        try:
            os.killpg(idn.pgid, signal.SIGKILL)
        except OSError:
            pass

    # 5. poll until nobody in the tree is alive.
    deadline = time.monotonic() + stop_timeout
    while time.monotonic() < deadline:
        live = [p for p in tree if os.path.exists(f"/proc/{p}")]
        if not live:
            break
        time.sleep(0.5)
    for pid in tree:
        if os.path.exists(f"/proc/{pid}"):
            result["lingering"].append({"pid": pid, "state": proc_state(pid)})
    return result

# main
# --------------------------------------------------------------------------- #

def main(argv: Optional[list[str]] = None) -> int:
    ap = argparse.ArgumentParser(description=__doc__,
                                 formatter_class=argparse.RawDescriptionHelpFormatter)
    sub = ap.add_subparsers(dest="cmd", required=True)

    w = sub.add_parser("watch", help="bounded first-edit checkpoint + stop")
    w.add_argument("--root", required=True)
    w.add_argument("--run-id", required=True)
    w.add_argument("--worker-pid", type=int, required=True)
    w.add_argument("--deadline", type=float, default=180.0,
                   help="seconds to wait for a product diff (default 180)")
    w.add_argument("--poll", type=float, default=5.0)
    w.add_argument("--state-dir", default=os.path.expanduser(
        "~/.hermes/foreman/guard"))
    w.add_argument("--evidence-re", action="append", default=[])
    w.add_argument("--product-re", default=None)
    w.add_argument("--grace", type=float, default=5.0)
    w.add_argument("--stop-timeout", type=float, default=30.0)
    w.add_argument("--json", action="store_true")

    sub.add_parser("identity", help="print a worker's identity")
    ip = sub.choices["identity"]
    ip.add_argument("--pid", type=int, required=True)

    args = ap.parse_args(argv)
    os.makedirs(args.state_dir, exist_ok=True) if hasattr(args, "state_dir") else None

    if args.cmd == "identity":
        print(json.dumps(capture_identity(args.pid).__dict__, indent=2, default=str))
        return 0

    def log(msg: str) -> None:
        line = f"[guard {time.strftime('%H:%M:%S')}] {msg}"
        print(line, file=sys.stderr, flush=True)

    evidence_re = DEFAULT_EVIDENCE_RE
    for pat in args.evidence_re:
        evidence_re = re.compile(evidence_re.pattern + "|" + pat, re.I)
    product_re = re.compile(args.product_re, re.I) if args.product_re else None

    idn = capture_identity(args.worker_pid)
    if not idn.verified:
        log(f"worker pid {args.worker_pid} not alive at guard start")
        return 4

    try:
        baseline = snapshot(args.root)
    except RuntimeError as exc:
        log(f"ERROR {exc}")
        return 3
    log(f"run={args.run_id} pid={idn.pid} pgid={idn.pgid} sid={idn.sid} "
        f"start={idn.starttime} cgroup={idn.cgroup!r} deadline={args.deadline}s")

    started = time.monotonic()
    while True:
        elapsed = time.monotonic() - started
        if not alive_and_same(idn):
            log(f"worker tree root gone after {elapsed:.1f}s")
            try:
                current = snapshot(args.root)
            except RuntimeError:
                current = baseline
            changes = new_changes(baseline, current)
            product, evidence = classify(args.root, Snapshot(
                {k: current.entries[k] for k in changes if k in current.entries}),
                evidence_re, product_re)
            if product:
                log(f"product diff after worker exit: {product}")
                return 0
            if evidence:
                run_dir = preserve_evidence(args.state_dir, args.run_id, args.root,
                                            idn, elapsed, args.deadline, product,
                                            evidence, changes, baseline, current)
                log(f"evidence preserved at {run_dir}")
            return 4

        try:
            current = snapshot(args.root)
        except RuntimeError as exc:
            log(f"snapshot error: {exc}")
            return 3
        changes = new_changes(baseline, current)
        changed_snap = Snapshot({k: current.entries[k] for k in changes
                                 if k in current.entries})
        product, evidence = classify(args.root, changed_snap, evidence_re, product_re)
        product = [p for p in product if p in changes]

        if product:
            log(f"first product edit after {elapsed:.1f}s: {sorted(product)}")
            if args.json:
                print(json.dumps({"outcome": "product_diff", "elapsed_s": elapsed,
                                  "product": sorted(product),
                                  "evidence": sorted(evidence)}, indent=2))
            return 0

        if elapsed >= args.deadline:
            log(f"deadline {args.deadline}s expired; product=0 evidence={sorted(evidence)}")
            run_dir = preserve_evidence(args.state_dir, args.run_id, args.root, idn,
                                        elapsed, args.deadline, product, evidence,
                                        changes, baseline, current)
            log(f"evidence preserved at {run_dir}")
            stop = stop_tree(idn, args.grace, args.stop_timeout, log, args.run_id)
            log(f"stop result: {json.dumps(stop, default=str)}")
            if stop["lingering"]:
                log("WARNING lingering processes (D/Z -> migrate out of cgroup "
                    "before the user manager can restart): "
                    + json.dumps(stop["lingering"]))
            if args.json:
                print(json.dumps({"outcome": "stalled", "elapsed_s": elapsed,
                                  "state_dir": run_dir, "stop": stop}, indent=2))
            return 2

        time.sleep(min(args.poll, max(0.1, args.deadline - elapsed)))


if __name__ == "__main__":
    sys.exit(main())

3.2 hermes_retry_gate.py

#!/usr/bin/env python3
"""
hermes_retry_gate.py — dispatch gate for the CF-274 retry rule.

Rule (from the prevention): after a stall, retry EXACTLY ONCE and only with a
materially changed brief. Never re-dispatch the same brief repeatedly.

Usage:
  # before spawning a worker
  hermes_retry_gate.py check  --state attempts.json --row CF-274 --brief brief.md
  # after the guard reports an outcome
  hermes_retry_gate.py record --state attempts.json --row CF-274 --brief brief.md \
        --outcome stalled        # or: product

Exit: check -> 0 ALLOW, 1 DENY.   record -> 0.
State file is JSON, safe to keep beside the scheduler DB.

Material change = the brief's sha256 differs from the last FAILED brief AND the
brief still carries a description. We refuse an identical brief; we also warn
when the retry brief is not shorter, because the observed mechanism is context
over-consumption, so a materially changed brief should usually be smaller.
"""

from __future__ import annotations

import argparse
import hashlib
import json
import os
import sys
import time
from typing import Optional


def sha256_file(path: str) -> str:
    h = hashlib.sha256()
    with open(path, "rb") as fh:
        for chunk in iter(lambda: fh.read(65536), b""):
            h.update(chunk)
    return h.hexdigest()


def load(path: str) -> dict:
    if not os.path.exists(path):
        return {}
    try:
        with open(path) as fh:
            return json.load(fh)
    except (OSError, json.JSONDecodeError):
        return {}


def save(path: str, state: dict) -> None:
    os.makedirs(os.path.dirname(os.path.abspath(path)), exist_ok=True)
    tmp = path + ".tmp"
    with open(tmp, "w") as fh:
        json.dump(state, fh, indent=2, sort_keys=True)
    os.replace(tmp, path)


def main(argv: Optional[list[str]] = None) -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("cmd", choices=["check", "record"])
    ap.add_argument("--state", required=True)
    ap.add_argument("--row", required=True)
    ap.add_argument("--brief", required=True)
    ap.add_argument("--outcome", choices=["stalled", "product", "error"])
    ap.add_argument("--max-retries", type=int, default=1)
    args = ap.parse_args(argv)

    digest = sha256_file(args.brief)
    size = os.path.getsize(args.brief)
    state = load(args.state)
    attempts = state.setdefault(args.row, [])

    if args.cmd == "record":
        attempts.append({
            "attempt": len(attempts) + 1,
            "brief_sha256": digest,
            "brief_bytes": size,
            "outcome": args.outcome or "error",
            "ts": time.time(),
        })
        save(args.state, state)
        print(json.dumps({"recorded": args.row, "attempts": len(attempts),
                          "outcome": args.outcome}))
        return 0

    # check
    failed = [a for a in attempts if a.get("outcome") in ("stalled", "error")]
    if not attempts:
        decision, reason = "ALLOW", "first attempt for this row"
    elif len(failed) >= 1 + args.max_retries:
        decision = "DENY"
        reason = (f"attempt budget exhausted ({len(failed)} failed of "
                  f"{1 + args.max_retries}): stop auto re-dispatch; a human or "
                  f"the foreman must change the approach")
    elif digest == attempts[-1].get("brief_sha256"):
        decision = "DENY"
        reason = ("brief is byte-identical to the failed attempt; re-dispatching "
                  "would repeat the stall")
    else:
        last = attempts[-1]
        delta = size - int(last.get("brief_bytes", 0))
        decision = "ALLOW"
        reason = (f"brief materially changed (sha256 differs, "
                  f"{delta:+d} bytes vs failed attempt); retry "
                  f"{len(failed) + 1}/{1 + args.max_retries}")
        if delta >= 0:
            reason += (" — WARNING: retry brief is not smaller; CF-274's mechanism "
                       "is context over-consumption, prefer a narrower brief")

    print(json.dumps({"row": args.row, "decision": decision, "reason": reason,
                      "brief_sha256": digest, "failed_attempts": len(failed)},
                     indent=2))
    return 0 if decision == "ALLOW" else 1


if __name__ == "__main__":
    sys.exit(main())

3.3 Wire the checkpoint into the foreman tick

The guard only works if it starts at spawn (so its baseline is clean) and if the worker is launched in its own session (so the stop is exact). Wrap the worker spawn like this — this is the core production change:

# ~/.hermes/foreman/run_worker_with_checkpoint.sh
# Sourced/called by the foreman instead of spawning a bare worker.
set -u
ROW="${ROW:?CF row id required}"                 # e.g. CF-274
RUN_ID="$(date +%s)-${ROW}-$$"
ROOT="${WORKER_ROOT:?checkout root required}"
BRIEF="${BRIEF_FILE:?brief path required}"
STATE="${FOREMAN_STATE:-~/.hermes/foreman/guard}"
FIRST_EDIT_DEADLINE="${FIRST_EDIT_DEADLINE:-180}"   # seconds
TICK_BUDGET="${TICK_BUDGET:-300}"                   # must exceed deadline

mkdir -p "$STATE"
ATTEMPTS="$STATE/attempts.json"

# 1. Retry gate: refuse an unchanged brief and refuse more than one retry.
if ! python3 ~/.hermes/foreman/guard/hermes_retry_gate.py check \
        --state "$ATTEMPTS" --row "$ROW" --brief "$BRIEF"; then
  echo "dispatch refused for $ROW (gate), not spawning a worker" >&2
  exit 75
fi

# 2. Spawn the worker in its OWN session/process group, then immediately guard.
#    `setsid` makes pgid == pid so the guard can signal the whole group.
setsid "$@" &
WORKER=$!

python3 ~/.hermes/foreman/guard/hermes_first_edit_guard.py watch \
    --root "$ROOT" \
    --run-id "$RUN_ID" \
    --worker-pid "$WORKER" \
    --deadline "$FIRST_EDIT_DEADLINE" \
    --poll 5 \
    --grace 5 \
    --stop-timeout 30 \
    --state-dir "$STATE" \
    --json
GUARD_RC=$?

case "$GUARD_RC" in
  0)  # product diff seen inside the bound
      python3 ~/.hermes/foreman/guard/hermes_retry_gate.py record \
          --state "$ATTEMPTS" --row "$ROW" --brief "$BRIEF" --outcome product
      wait "$WORKER"; exit $? ;;
  2)  # stalled: evidence preserved and tree stopped by the guard
      python3 ~/.hermes/foreman/guard/hermes_retry_gate.py record \
          --state "$ATTEMPTS" --row "$ROW" --brief "$BRIEF" --outcome stalled
      echo "CF-274 stall for $ROW; evidence under $STATE/$RUN_ID" >&2
      exit 2 ;;
  4)  # worker died with only evidence: same handling as a stall
      python3 ~/.hermes/foreman/guard/hermes_retry_gate.py record \
          --state "$ATTEMPTS" --row "$ROW" --brief "$BRIEF" --outcome stalled
      exit 2 ;;
  *)  echo "guard operational error rc=$GUARD_RC; NOT stopping worker" >&2
      exit 3 ;;
esac

The foreman must then generate the materially changed brief before the one allowed retry. A brief that satisfies the gate and the mechanism is:

  • drop the repo dump / prior transcripts / full history (the context that wedged the transport),
  • narrow to the single row and the single file/function,
  • add an explicit first instruction: "your first tool call MUST write the product diff; do not write an evidence artifact first",
  • name the checkpoint: "a product diff is required within $FIRST_EDIT_DEADLINEs or the tick is stopped."

Do not re-dispatch a third time automatically. After the ledger shows two failed attempts the gate returns DENY and the row must be handled by a human or a different strategy.

3.5 Stop the transport stall at the source

The checkpoint contains the blast radius; these reduce the chance of stalling at all, and belong with the worker model configuration:

  • Cap worker context below the model's hard limit and drop repo dumps / prior transcripts from the brief. The observed mechanism is context over-consumption, so this is the actual fix; the guard is the safety net.
  • Per-request transport timeout on the model client, shorter than FIRST_EDIT_DEADLINE, so a wedged request aborts and surfaces an error instead of parking the process.
  • First-call contract: make the worker's first tool call a product edit. An evidence/narrate block must be emitted after the diff, never instead of it.
  • Serialize the shared checkout: toolsd lease acquire --holder "$RUN_ID" --ttl 30m --root "$ROOT" <paths> before editing, so a stalled tick cannot hold paths another tick needs; use toolsd session start for worktrees when concurrency is expected.

4.3 Manual stop / poll commands (operational fallback)

If the guard is unavailable and a tree must be stopped now, these are the exact PID-tree primitives the guard uses:

PID=<worker-root-pid>

# identity that survives PID reuse
cat /proc/$PID/stat | awk '{print "starttime=" $22}'
PGID=$(ps -o pgid= -p $PID | tr -d ' ')
SID=$(ps -o sid=  -p $PID | tr -d ' ')
cat /proc/$PID/cgroup

# the exact tree, leaves included
pstree -ap $PID
ps -o pid,ppid,pgid,sid,stat,etime,args --forest -g "$PGID"

# stop: TERM the group, grace, then KILL, then poll to zero
kill -TERM -"$PGID"; sleep 5; kill -KILL -"$PGID"
for i in $(seq 1 60); do pgrep -g "$PGID" >/dev/null || break; sleep 0.5; done
pgrep -g "$PGID" && echo "STILL ALIVE — inspect state" || echo "tree stopped"

# survivors in D/Z cannot be reaped by the user manager; migrate them out of
# the unit cgroup (same technique as hermes-user-manager-heal.sh)
mkdir -p /sys/fs/cgroup/hermes-leftover.scope
while read -r p s; do
  case "$s" in D|Z) echo "$p" > /sys/fs/cgroup/hermes-leftover.scope/cgroup.procs \
     && echo "migrated $p ($s)";;
  esac
done < <(ps -o pid,stat -g "$PGID" --no-headers 2>/dev/null)

4.4 Retry-policy acceptance

The ledger produces exactly the policy CF-274 asks for:

record attempt 1 (stalled)
check same brief    -> DENY  "brief is byte-identical to the failed attempt"
check changed brief -> ALLOW "retry 2/2 (prefer a narrower brief)"
record attempt 2 (stalled)
check any brief     -> DENY  "attempt budget exhausted (2 failed of 2)"

check exits 0 on ALLOW and 1 on DENY, so the foreman can branch on it directly.

4.5 Residual risk / out of scope

  • The guard stops a live tree. A worker that has already entered uninterruptible D state on a FUSE mount cannot be killed by signal; §4.3's cgroup migration is the escape hatch, not a guarantee.
  • The transport-side trigger (context over-consumption, missing model-request timeout) lives in the worker/model config (§3.5); the guard bounds the damage but does not itself shrink the context.
  • attempts.json is per-row state next to the scheduler DB. If it is lost, the gate degrades to "first attempt allowed once more" — acceptable, because the byte-identical-brief rule still blocks the exact loop from §2.4.
