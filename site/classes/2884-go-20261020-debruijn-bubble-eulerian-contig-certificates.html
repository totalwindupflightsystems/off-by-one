Diagnosing and Fixing the de Bruijn Bubble/Eulerian-Contig Certificate Problem

TL;DR

The problem class is not a single bug — it is a set of failure modes that appear when an assembler is built naively: map-iteration non-determinism, branch/tip decisions made without an explicit policy, and no machine-checkable proof that the emitted contigs partition the retained k-mers. The fix is a deterministic compacted de Bruijn graph (cDBG) builder with (1) total ordering at every choice point, (2) an explicit coverage/length policy for tips and bubbles, and (3) an exactly-once certificate over retained k-mers whose correctness is checked at build time and hashed for reproducibility.

A complete, tested Go implementation lives in ~/dbg (go.mod, dbg.go, main.go, dbg_test.go). All tests pass and the CLI is deterministic under input permutation.

1. Interface contract

  • Input: directed k-mer arcs (from reads or an edge list). A k-mer e is an arc prefix(e) → suffix(e) with prefix = e[:k-1], suffix = e[1:]; its weight is coverage.
  • Caller-chosen k (≥2), plus an explicit policy:
  • min-cov — edges below this are discarded as low_coverage.
  • max-tip-len (bp) and tip-cov-frac — a dead-ending branch is trimmed when len ≤ max-tip-len and cov < tip-cov-frac × best_branch_cov.
  • min-branch-len (bp) and het-lo — a bubble branch is eligible if len ≥ min-branch-len; a bubble is undecidable iff ≥2 eligible branches have cov ≥ max_cov × het-lo. Such branches are all retained and reported.
  • Output: contig paths, removed k-mers with reasons, the minimal set of undecidable bubbles, and a certificate proving every retained k-mer occurs in exactly one contig at exactly one offset.
  • Determinism: byte-identical output (including a SHA-256 digest) for any permutation of input edges.

2. Root-cause analysis (why naive attempts fail)

# Failure mode Root cause Symptom
R1 Different runs produce different contigs Iterating Go maps to pick "the next edge" or the next branch Non-reproducible assemblies; certificates that verify on one run and fail on the next
R2 k-mers silently lost Compaction only emits unitigs reachable from branch nodes; pure cycles are never emitted Missing cyclic contigs; certificate count mismatch
R3 k-mers duplicated Merging unitigs after branch collapse without re-partitioning A k-mer assigned to two contigs
R4 Heterozygous alleles wrongly collapsed No explicit policy; "pick highest coverage" loses real diploid sequence Reference allele-only assembly; reported as "complete"
R5 Error branches kept forever Tips/gaps not trimmed by length+coverage Bloated graph, fragmented contigs
R6 Cycle output not canonical A cycle has no start; whichever edge is encountered first wins Permutation-sensitive output
R7 Truncated/wrong contigs Emitting k-mers instead of overlap-merging, or assuming edges are contiguous Contig sequence is not the assembly of its arcs
R8 Ambiguity hidden No distinction between "resolved" and "undecidable" bubbles User cannot tell which alternatives the data cannot decide
R9 Non-ACGT kmers Reads containing N poison nodes Spurious branches and tips

The fix addresses each: sort every adjacency list and every choice set (R1, R6); emit leftover simple cycles explicitly with canonical rotation (R2, R6); build contigs by overlap assembly and prove partition (R3, R7); define the policy above (R4, R5, R8); skip non-ACGT k-mers (R9).

3. Design of the fix

3.1 Deterministic ordering rules (total order at every choice)

  1. Node/arc keys are plain strings; comparisons are byte-wise strings.
  2. Every in/out adjacency list is sort.Strings-ed after construction.
  3. Unitig start arcs are sorted; final unitigs are sorted by (sequence, start_node).
  4. Pure cycles are rotated so the lexicographically smallest arc is first.
  5. Bubble branches are ordered by (length-eligible desc, coverage desc, length desc, lexicographic path).
  6. removed_kmers and undecidable_bubbles are sorted.
  7. The SHA-256 digest is computed over a canonical JSON rendering.

3.2 Compaction

Walk from every arc whose prefix node is non-simple (in≠1 or out≠1) through simple (in=1 and out=1) nodes. After that pass, any unvisited arcs form pure cycles; emit each as one cyclic unitig, rotated canonically. This partitions the edge set exactly once.

3.3 Bubble and tip detection

From each branching node, follow each outgoing arc through simple nodes until a non-simple node is reached. That is one branch. Group branches by their terminal node:

  • group size 1 ending at a dead-end → tip (trim if short + low coverage);
  • group size ≥2 → bubble (apply eligibility/coverage policy).

Because internal bubble nodes are simple by construction, branches never share internal edges, and the merge node is necessarily non-simple, so this finds every simple bubble.

3.4 Certificate (the "Eulerian" part)

The certificate asserts an edge-disjoint trail decomposition of the retained graph: for each retained k-mer it records (contig, offset), verifies no duplicate, verifies no omitted retained k-mer, verifies each contig's consecutive arcs overlap by k-1, and verifies the contig sequence equals the overlap assembly of its arcs. It is backed by a SHA-256 digest of the sorted assignment table.

package main

import (
    "crypto/sha256"
    "encoding/hex"
    "encoding/json"
    "fmt"
    "sort"
    "strings"

// ---------------------------------------------------------------------------
// Policy
// ---------------------------------------------------------------------------

// Params is the caller's explicit coverage/length policy. Every value is part
// of the assembly contract; nothing is inferred implicitly from map order.
type Params struct {
    K            int     `json:"k"`
    MinCov       int     `json:"min_cov"`
    MaxTipLen    int     `json:"max_tip_len_bp"`
    MinBranchLen int     `json:"min_branch_len_bp"`
    HetLo        float64 `json:"het_ratio_low"`
    TipCovFrac   float64 `json:"tip_cov_frac"`
}

// ---------------------------------------------------------------------------
// Graph primitives
// ---------------------------------------------------------------------------

// index is a deterministic adjacency view of an edge (k-mer) set. A k-mer e
// is an arc prefix(e) -> suffix(e) where prefix = e[:k-1], suffix = e[1:].
type index struct {
    k     int
    edges map[string]int // k-mer -> coverage
    in    map[string][]string
    out   map[string][]string
}

func buildIndex(edges map[string]int, k int) *index {
    ix := &index{k: k, edges: edges, in: map[string][]string{}, out: map[string][]string{}}
    for e := range edges {
        u := e[:k-1]
        v := e[1:]
        ix.out[u] = append(ix.out[u], e)
        ix.in[v] = append(ix.in[v], e)
    }
    for _, l := range ix.in {
        sort.Strings(l)
    }
    for _, l := range ix.out {
        sort.Strings(l)
    }
    return ix
}

// simple reports whether a node is an internal (non-branching) node.
func (ix *index) simple(n string) bool {
    return len(ix.in[n]) == 1 && len(ix.out[n]) == 1
}

func medianCoverage(path []string, edges map[string]int) float64 {
    vals := make([]int, len(path))
    for i, e := range path {
        vals[i] = edges[e]
    }
    sort.Ints(vals)
    n := len(vals)
    if n == 0 {
        return 0
    }
    if n%2 == 1 {
        return float64(vals[n/2])
    }
    return float64(vals[n/2-1]+vals[n/2]) / 2
}

// ---------------------------------------------------------------------------
// Compaction into unitigs
// ---------------------------------------------------------------------------

type Unitig struct {
    Edges     []string `json:"edges"`
    Sequence  string   `json:"sequence"`
    Cov       float64  `json:"coverage"`
    Cycle     bool     `json:"cycle"`
    StartNode string   `json:"start_node"`
    EndNode   string   `json:"end_node"`
}

func seqFromEdges(edges []string, k int) string {
    var sb strings.Builder
    sb.WriteString(edges[0])
    for _, e := range edges[1:] {
        sb.WriteByte(e[k-1])
    }
    return sb.String()
}

func makeUnitig(path []string, edges map[string]int, k int, cycle bool) Unitig {
    return Unitig{
        Edges:     append([]string(nil), path...),
        Sequence:  seqFromEdges(path, k),
        Cov:       medianCoverage(path, edges),
        Cycle:     cycle,
        StartNode: path[0][:k-1],
        EndNode:   path[len(path)-1][1:],
    }
}

// rotateMin rotates a cyclic unitig so the lexicographically smallest arc is
// first. This makes pure-cycle output canonical under input permutation.
func rotateMin(cyc []string) []string {
    if len(cyc) == 0 {
        return cyc
    }
    mi := 0
    for i, e := range cyc {
        if e < cyc[mi] {
            mi = i
        }
    }
    if mi == 0 {
        return cyc
    }
    out := make([]string, 0, len(cyc))
    out = append(out, cyc[mi:]...)
    out = append(out, cyc[:mi]...)
    return out
}

// compact builds the compacted de Bruijn graph: maximal paths through
// in-degree==1, out-degree==1 nodes. Pure cycles are emitted separately and
// rotated canonically. Output order is sorted by sequence.
func compact(edges map[string]int, k int) []Unitig {
    ix := buildIndex(edges, k)
    visited := map[string]bool{}
    var unitigs []Unitig

    starts := make([]string, 0, len(edges))
    for e := range edges {
        if !ix.simple(e[:k-1]) {
            starts = append(starts, e)
        }
    }
    sort.Strings(starts)

    for _, e := range starts {
        if visited[e] {
            continue
        }
        path := []string{}
        cur := e
        for !visited[cur] {
            visited[cur] = true
            path = append(path, cur)
            to := cur[1:]
            if ix.simple(to) {
                cur = ix.out[to][0]
            } else {
                break
            }
        }
        unitigs = append(unitigs, makeUnitig(path, edges, k, false))
    }

    // Leftover arcs can only belong to cycles whose every node is simple.
    rem := make([]string, 0)
    for e := range edges {
        if !visited[e] {
            rem = append(rem, e)
        }
    }
    sort.Strings(rem)
    for _, e := range rem {
        if visited[e] {
            continue
        }
        cyc := []string{}
        cur := e
        for !visited[cur] {
            visited[cur] = true
            cyc = append(cyc, cur)
            to := cur[1:]
            if len(ix.out[to]) != 1 {
                break
            }
            cur = ix.out[to][0]
        }
        if len(cyc) == 0 {
            continue
        }
        cyc = rotateMin(cyc)
        unitigs = append(unitigs, makeUnitig(cyc, edges, k, true))
    }
    return unitigs
}

// ---------------------------------------------------------------------------
// Bubble / tip analysis
// ---------------------------------------------------------------------------

type Branch struct {
    Path  []string `json:"path"`
    Seq   string   `json:"sequence"`
    Cov   float64  `json:"coverage"`
    LenBP int      `json:"length_bp"`
    End   string   `json:"end_node"`
}

type Bubble struct {
    Start    string   `json:"start_node"`
    End      string   `json:"end_node"`
    Branches []Branch `json:"branches"`
}

func branchKey(b Branch) string { return strings.Join(b.Path, ",") }

func makeBranch(path []string, end string, ix *index, k int) Branch {
    return Branch{
        Path:  append([]string(nil), path...),
        Seq:   seqFromEdges(path, k),
        Cov:   medianCoverage(path, ix.edges),
        LenBP: len(path) + k - 1,
        End:   end,
    }
}

// walk follows a single arc through simple nodes until it hits a non-simple
// node (branch point or dead end). This is exactly one bubble/tip branch.
func walk(ix *index, e string) ([]string, string) {
    path := []string{e}
    cur := e
    limit := len(ix.edges) + 1
    for i := 0; i < limit; i++ {
        to := cur[1:]
        if ix.simple(to) {
            cur = ix.out[to][0]
            path = append(path, cur)
        } else {
            return path, to
        }
    }
    return path, path[len(path)-1][1:]
}

func markRemoved(m map[string]string, path []string, reason string) {
    for _, e := range path {
        if _, ok := m[e]; !ok {
            m[e] = reason
        }
    }
}

// analyze detects simple bubbles and tips in the compacted graph and applies
// the coverage/length policy. It returns removed k-mers (with reasons) and the
// bubbles that are genuinely undecidable: >=2 length-eligible branches whose
// coverages are within HetLo of the dominant branch.
func analyze(ix *index, p Params) (map[string]string, []Bubble) {
    removed := map[string]string{}
    var undecidable []Bubble

    starts := []string{}
    for n, outs := range ix.out {
        if len(outs) >= 2 {
            starts = append(starts, n)
        }
    }
    sort.Strings(starts)

    for _, s := range starts {
        groups := map[string][]Branch{}
        ends := []string{}
        for _, e := range ix.out[s] { // ix.out is sorted
            path, end := walk(ix, e)
            br := makeBranch(path, end, ix, p.K)
            if _, ok := groups[end]; !ok {
                ends = append(ends, end)
            }
            groups[end] = append(groups[end], br)
        }
        sort.Strings(ends)

        best := 0.0
        for _, brs := range groups {
            for _, b := range brs {
                if b.Cov > best {
                    best = b.Cov
                }
            }
        }

        for _, end := range ends {
            brs := groups[end]

            if len(brs) == 1 {
                br := brs[0]
                // A lone branch that dead-ends is a tip when short + low cov.
                if len(ix.out[end]) == 0 &&
                    br.LenBP <= p.MaxTipLen &&
                    br.Cov < p.TipCovFrac*best {
                    markRemoved(removed, br.Path, "tip")
                }
                continue
            }

            // Deterministic branch order: length-eligible first, then
            // coverage desc, then length desc, then lexicographic.
            sort.Slice(brs, func(i, j int) bool {
                ei := brs[i].LenBP >= p.MinBranchLen
                ej := brs[j].LenBP >= p.MinBranchLen
                if ei != ej {
                    return ei
                }
                if brs[i].Cov != brs[j].Cov {
                    return brs[i].Cov > brs[j].Cov
                }
                if brs[i].LenBP != brs[j].LenBP {
                    return brs[i].LenBP > brs[j].LenBP
                }
                return branchKey(brs[i]) < branchKey(brs[j])
            })

            maxCov := 0.0
            for _, b := range brs {
                if b.Cov > maxCov {
                    maxCov = b.Cov
                }
            }
            balanced := 0
            for _, b := range brs {
                if b.LenBP >= p.MinBranchLen && maxCov > 0 && b.Cov >= maxCov*p.HetLo {
                    balanced++
                }
            }

            if balanced >= 2 {
                // Both (or several) alleles are well supported and of similar
                // coverage: the data alone cannot choose. Keep them all.
                undecidable = append(undecidable, Bubble{Start: s, End: end, Branches: brs})
                continue
            }

            // Otherwise collapse to the single best branch. This covers
            // homozygous bubbles (minor branch absent) and sequencing-error
            // bubbles (minor branch short/low-coverage).
            for i := 1; i < len(brs); i++ {
                markRemoved(removed, brs[i].Path, "bubble_minor")
            }
        }
    }

    sort.Slice(undecidable, func(i, j int) bool {
        if undecidable[i].Start != undecidable[j].Start {
            return undecidable[i].Start < undecidable[j].Start
        }
        return undecidable[i].End < undecidable[j].End
    })
    return removed, undecidable
}

type Certificate struct {

type Output struct {
    K           int           `json:"k"`
    Params      Params        `json:"params"`
    Contigs     []ContigOut   `json:"contigs"`
    Removed     []RemovedKmer `json:"removed_kmers"`

// ---------------------------------------------------------------------------
// Certificate
// ---------------------------------------------------------------------------

// buildCertificate proves that the union of contig paths partitions the
// retained k-mer set: every retained k-mer appears in exactly one contig at
// exactly one offset, every arc is contiguous with the next, and each contig
// sequence is exactly the overlap-assembly of its arcs.
func buildCertificate(unitigs []Unitig, retained map[string]int, k int) (Certificate, error) {
    assign := map[string]Assign{}
    var dupes []string
    for ci, u := range unitigs {
        for off, e := range u.Edges {
            if _, ok := assign[e]; ok {
                dupes = append(dupes, e)
                continue
            }
            assign[e] = Assign{Kmer: e, Contig: ci, Offset: off}
        }
    }
    if len(dupes) > 0 {
        sort.Strings(dupes)
        return Certificate{}, fmt.Errorf("certificate violation: k-mer %q covered more than once (%d duplicates)", dupes[0], len(dupes))
    }

    var missing []string
    for e := range retained {
        if _, ok := assign[e]; !ok {
            missing = append(missing, e)
        }
    }
    if len(missing) > 0 {
        sort.Strings(missing)
        return Certificate{}, fmt.Errorf("certificate violation: retained k-mer %q not covered (%d missing)", missing[0], len(missing))
    }

    for _, u := range unitigs {
        if len(u.Edges) == 0 {
            continue
        }
        if u.Sequence != seqFromEdges(u.Edges, k) {
            return Certificate{}, fmt.Errorf("certificate violation: contig sequence inconsistent with its k-mers")
        }
        for i := 1; i < len(u.Edges); i++ {
            if u.Edges[i-1][1:] != u.Edges[i][:k-1] {
                return Certificate{}, fmt.Errorf("certificate violation: non-contiguous k-mers %q -> %q", u.Edges[i-1], u.Edges[i])
            }
        }
    }

    list := make([]Assign, 0, len(assign))
    for _, a := range assign {
        list = append(list, a)
    }
    sort.Slice(list, func(i, j int) bool { return list[i].Kmer < list[j].Kmer })

    h := sha256.New()
    for _, a := range list {
        fmt.Fprintf(h, "%s\t%d\t%d\n", a.Kmer, a.Contig, a.Offset)
    }
    return Certificate{
        RetainedKmers: len(retained),
        AssignedKmers: len(list),
        ExactlyOnce:   len(list) == len(retained),
        Digest:        hex.EncodeToString(h.Sum(nil)),
        Assignments:   list,
    }, nil
}

func Build(raw map[string]int, p Params) (Output, error) {
    if p.K < 2 {
        return Output{}, fmt.Errorf("k must be >= 2 (got %d)", p.K)
    }
    if p.MinCov < 1 {
        p.MinCov = 1
    }
    if p.MaxTipLen <= 0 {
        p.MaxTipLen = 2 * p.K
    }
    if p.MinBranchLen <= 0 {
        p.MinBranchLen = 2 * p.K
    }
    if p.HetLo <= 0 || p.HetLo > 1 {
        p.HetLo = 0.4
    }
    if p.TipCovFrac <= 0 || p.TipCovFrac > 1 {
        p.TipCovFrac = 0.3
    }

    removed := map[string]string{}
    filtered := map[string]int{}
    for e, c := range raw {
        if len(e) != p.K {
            return Output{}, fmt.Errorf("input k-mer %q has length %d, want k=%d", e, len(e), p.K)
        }
        if c >= p.MinCov {
            filtered[e] = c
        } else {
            removed[e] = "low_coverage"
        }
    }

    ix := buildIndex(filtered, p.K)
    extra, undec := analyze(ix, p)
    for e, r := range extra {
        if _, ok := removed[e]; !ok {
            removed[e] = r
        }
    }

    retained := map[string]int{}
    for e, c := range filtered {
        if _, gone := removed[e]; !gone {
            retained[e] = c
        }
    }

    unitigs := compact(retained, p.K)
    sort.Slice(unitigs, func(i, j int) bool {
        if unitigs[i].Sequence != unitigs[j].Sequence {
            return unitigs[i].Sequence < unitigs[j].Sequence
        }
        return unitigs[i].StartNode < unitigs[j].StartNode
    })

    contigs := make([]ContigOut, len(unitigs))
    for i, u := range unitigs {
        contigs[i] = ContigOut{
            ID:        i,
            Sequence:  u.Sequence,
            Coverage:  u.Cov,
            Edges:     u.Edges,
            StartNode: u.StartNode,
            EndNode:   u.EndNode,
            Cycle:     u.Cycle,
            LengthBP:  len(u.Sequence),
        }
    }

    cert, err := buildCertificate(unitigs, retained, p.K)
    if err != nil {
        return Output{}, err
    }

    rm := make([]RemovedKmer, 0, len(removed))
    for e, r := range removed {
        rm = append(rm, RemovedKmer{Kmer: e, Reason: r})
    }
    sort.Slice(rm, func(i, j int) bool { return rm[i].Kmer < rm[j].Kmer })

    ubs := make([]BubbleOut, len(undec))
    for i, b := range undec {
        ubs[i] = BubbleOut{
            Start:    b.Start,
            End:      b.End,
            Reason:   "heterozygous_or_multiallelic_undecidable",
            Branches: b.Branches,
        }
    }

    out := Output{K: p.K, Params: p, Contigs: contigs, Removed: rm, Undecidable: ubs, Certificate: cert}
    dig, err := digestOutput(out)
    if err != nil {
        return Output{}, err
    }
    out.Digest = dig
    return out, nil
}

// digestOutput hashes a canonical JSON rendering of the result (with the
// self-referential digest field blanked). Because all slices are pre-sorted
// and Go's encoding/json sorts map keys, this is stable under input
// permutation.
func digestOutput(out Output) (string, error) {
    out.Digest = ""
    b, err := json.Marshal(out)
    if err != nil {
        return "", err
    }
    sum := sha256.Sum256(b)
    return hex.EncodeToString(sum[:]), nil
}

package main

import (
    "bufio"
    "encoding/json"
    "flag"
    "fmt"
    "os"
    "strings"
)

func main() {
    var (
        k         int
        readsPath string
        edgesPath string
        minCov    int
        maxTip    int
        minBranch int
        hetLo     float64
        tipFrac   float64
        outPath   string
        showAll   bool
    )
    flag.IntVar(&k, "k", 0, "k-mer size (required, >=2)")
    flag.StringVar(&readsPath, "reads", "", "FASTA/FASTQ reads to k-merize")
    flag.StringVar(&edgesPath, "edges", "", "edge list: '<kmer>[<whitespace>count]' per line")
    flag.IntVar(&minCov, "min-cov", 2, "minimum edge coverage to retain")
    flag.IntVar(&maxTip, "max-tip-len", 0, "max tip length in bp (default 2k)")
    flag.IntVar(&minBranch, "min-branch-len", 0, "min branch length in bp for a real allele (default 2k)")
    flag.Float64Var(&hetLo, "het-lo", 0.4, "coverage ratio below which a minor branch is collapsed")
    flag.Float64Var(&tipFrac, "tip-cov-frac", 0.3, "tip coverage fraction of the best branch below which it is trimmed")
    flag.StringVar(&outPath, "out", "", "write JSON result to file (default stdout)")
    flag.BoolVar(&showAll, "show-assignments", true, "include per-k-mer certificate assignments")
    flag.Parse()

    if k < 2 {
        fmt.Fprintln(os.Stderr, "dbg: -k must be >= 2")
        os.Exit(2)
    }
    if readsPath == "" && edgesPath == "" {
        fmt.Fprintln(os.Stderr, "dbg: provide -reads and/or -edges")
        os.Exit(2)
    }

    raw := map[string]int{}
    if edgesPath != "" {
        m, err := loadEdges(edgesPath)
        if err != nil {
            fatal(err)
        }
        mergeCounts(raw, m)
    }
    if readsPath != "" {
        m, err := loadReads(readsPath, k)
        if err != nil {
            fatal(err)
        }
        mergeCounts(raw, m)
    }

    out, err := Build(raw, Params{
        K:            k,
        MinCov:       minCov,
        MaxTipLen:    maxTip,
        MinBranchLen: minBranch,
        HetLo:        hetLo,
        TipCovFrac:   tipFrac,
    })
    if err != nil {
        fatal(err)
    }
    if !showAll {
        out.Certificate.Assignments = nil
    }
    data, err := json.MarshalIndent(out, "", "  ")
    if err != nil {
        fatal(err)
    }
    data = append(data, '\n')
    if outPath == "" {
        _, _ = os.Stdout.Write(data)
        return
    }
    if err := os.WriteFile(outPath, data, 0o644); err != nil {
        fatal(err)
    }
}

    fmt.Fprintln(os.Stderr, "dbg:", err)
    os.Exit(1)
}

func mergeCounts(dst, src map[string]int) {
    for k, v := range src {
        dst[k] += v
    }
}

func isACGT(s string) bool {
    for i := 0; i < len(s); i++ {
        switch s[i] {
        case 'A', 'C', 'G', 'T':
        default:
            return false
        }
    }
    return true
}

// loadEdges reads a k-mer/edge list. Each non-empty, non-comment line begins
// with the k-mer and may be followed by an integer coverage/count. Duplicate
// k-mers are summed, so line order is irrelevant.
func loadEdges(path string) (map[string]int, error) {
    f, err := os.Open(path)
    if err != nil {
        return nil, err
    }
    defer f.Close()

    m := map[string]int{}
    sc := bufio.NewScanner(f)
    sc.Buffer(make([]byte, 0, 1<<20), 1<<24)
    for sc.Scan() {
        line := strings.TrimSpace(sc.Text())
        if line == "" || strings.HasPrefix(line, "#") {
            continue
        }
        fields := strings.Fields(line)
        kmer := strings.ToUpper(fields[0])
        c := 1
        if len(fields) >= 2 {
            var v int
            if _, err := fmt.Sscanf(fields[1], "%d", &v); err != nil {
                return nil, fmt.Errorf("edges: line %q: bad count: %w", line, err)
            }
            c = v
        }
        m[kmer] += c
    }
    return m, sc.Err()
}

// loadReads k-merizes FASTA, FASTQ or plain sequence input. Only k-mers over
// {A,C,G,T} are counted; k-mers containing N/ambiguity are skipped, matching
// standard assembler behavior.
func loadReads(path string, k int) (map[string]int, error) {
    data, err := os.ReadFile(path)
    if err != nil {
        return nil, err
    }
    lines := strings.Split(string(data), "\n")

    format := "fasta"
    for _, l := range lines {
        l = strings.TrimSpace(l)
        if l == "" {
            continue
        }
        if l[0] == '@' {
            format = "fastq"
        }
        break
    }

    m := map[string]int{}
    addSeq := func(s string) {
        s = strings.ToUpper(s)
        for i := 0; i+k <= len(s); i++ {
            km := s[i : i+k]
            if isACGT(km) {
                m[km]++
            }
        }
    }

    if format == "fastq" {
        // Header, sequence, plus, quality on consecutive lines.
        for i := 1; i < len(lines); i += 4 {
            if i < len(lines) {
                addSeq(strings.TrimSpace(lines[i]))
            }
        }
        return m, nil
    }

    var cur strings.Builder
    flush := func() {
        if cur.Len() > 0 {
            addSeq(cur.String())
            cur.Reset()
        }
    }
    for _, l := range lines {
        l = strings.TrimSpace(l)
        if strings.HasPrefix(l, ">") {
            flush()
            continue
        }
        if l == "" || strings.HasPrefix(l, "#") {
            continue
        }
        cur.WriteString(l)
    }
    flush()
    return m, nil
}

5.4 Certificate is enforced, not just reported

Build calls buildCertificate and returns an error (aborting the CLI) if any retained k-mer is missing, any k-mer is doubly assigned, any pair of consecutive arcs fails the k-1 overlap, or the contig sequence disagrees with its arcs. TestCertificateDetectsDuplicates exercises the failure path directly, and TestCertificatePartitionsRetainedExactlyOnce independently re-checks the partition on a mixed graph.

6. Complexity and scope

  • Let E = number of distinct k-mers, V ≤ 2E nodes, L = total output length.
  • Index construction and all adjacency sorts: O(E log E).
  • Compaction: O(E) after sorting.
  • Bubble/tip walk: each arc is traversed O(1) times from a branch start, O(E) total.
  • Certificate: O(E log E) for the final sort; digest O(E).
  • Memory: O(E).
  • Detected bubbles are simple bubbles (internally non-branching). Nested/complex regions decompose into multiple reported simple bubbles, so the reported undecidable set is minimal with respect to the simple-bubble decomposition. Branch decision uses median coverage per branch, which is robust to per-k-mer coverage noise.

Determinism rule of thumb: never let a Go map decide anything. Every choice is made from a sorted slice or a documented total order.
