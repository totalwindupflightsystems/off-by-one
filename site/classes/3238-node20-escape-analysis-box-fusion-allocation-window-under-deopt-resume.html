Deopt-Resume Cursor Ordering in Fused Allocation Windows

Answer

Under the fully specified reference model below (4096 synthetic frames, one resume cursor / one box slot per frame, 64-slot fused allocation windows), the index of the first frame whose materialised slot differs between pre- and post-increment cursor semantics is 65.

Scope note. The problem does not ship the cursor stream, boxes-per-frame, or fusion/window policy, so the raw index is a function of those inputs and is not unique as literally worded. 65 is the canonical value for the explicit model below; the general closed form is the first frame whose cumulative box count exceeds the window size (WINDOW + 1 when each frame contributes one box).

Root-cause analysis

Escape analysis coalesces per-frame heap boxes into one shared allocation window; a lazy deopt point records a resume cursor relative to the window base:

materialised slot = windowBase + cursor

The bug is the order of the store and the advance:

// BUGGY: pre-increment store
base[i] = winBase;      // cursor written first ...
used += 1;              // ... then advanced
if (used > WINDOW) {    // overflow discovered afterwards
  winBase += WINDOW;
  used = 0;
}

The first frame that overflows the window has already recorded the old winBase before the overflow is noticed. The box actually belongs to the next window, so it is materialised at oldBase + cursor instead of newBase + 0 — off by a whole window of slots.

With one box per frame and WINDOW = 64:

frames (1-based) window pre base post base
1 … 64 0 0 0
65 1 0 (stale) 64 (correct)

Frames 1–64 agree; frame 65 is the first overflow, hence the first divergence.

Exact fix

Store the cursor after the advance/roll (post-increment), or normalise against the current window base at materialisation:

// FIXED: post-increment store
if (used + 1 > WINDOW) {   // roll first
  winBase += WINDOW;
  used = 0;
}
base[i] = winBase;         // then store the owning window base
used += 1;

General form for size[i] boxes per frame:

function firstDivergentFrame(size, WINDOW) {
  let acc = 0;
  for (let i = 0; i < size.length; i++) {
    acc += size[i];
    if (acc > WINDOW) return i + 1;   // 1-based
  }
  return -1;
}

Reference implementation

/workspace/reference_model.js:

'use strict';
const N = 4096, WINDOW = 64;

function fusePre(frames = N, window = WINDOW) {   // buggy
  const base = new Uint32Array(frames);
  let winBase = 0, used = 0;
  for (let i = 0; i < frames; i++) {
    base[i] = winBase;                 // store cursor first
    used += 1;                         // then advance
    if (used > window) { winBase += window; used = 0; }
  }
  return base;
}

function fusePost(frames = N, window = WINDOW) {  // fixed
  const base = new Uint32Array(frames);
  let winBase = 0, used = 0;
  for (let i = 0; i < frames; i++) {
    if (used + 1 > window) { winBase += window; used = 0; }
    base[i] = winBase;                 // store after the roll
    used += 1;
  }
  return base;
}

function firstDivergentFrame(pre, post) {
  for (let i = 0; i < pre.length; i++) if (pre[i] !== post[i]) return i + 1;
  return -1;
}

console.log(firstDivergentFrame(fusePre(), fusePost())); // 65
