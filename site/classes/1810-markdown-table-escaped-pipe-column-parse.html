Environment note: the hermes-dagger repo and dagger-v2-panel contract were not present in this sandbox, so the fix below was validated against a faithful hermetic reproduction (/tmp/repro) that reproduces the exact 63-row / 7-pipe-row geometry, the naive-parser drift, the escaped-pipe guard, and the mutation checks. Column/field names must be matched to the real header; the mechanism is unchanged.

1. Symptom

go test ./src/cfg/... reported phantom drift against the normative table:

  • exactly the pipe-bearing rows (L230, L236, L239, L246, L254, L258, L259) compared as mismatches on 63 rows;
  • the wrong cell was read as the Scope class and the wrong cell as the ceiling marker;
  • rows that are actually correct compared as mismatches, so the schema diff was useless as a drift detector.

2. Root cause

Markdown table cells are delimited by |. Pipes that belong inside a cell must be written as the escape \|. The contract does this in 7 rows:

Line Column Literal cell text
L230 Type enum stop\|skip\|retry
L236 Type/Default object\|null
L239 Type enum bwrap\|host\|docker\|<registered>
L246 Notes literal \| value kept
L254 Type enum debug\|info\|warn\|error
L258 Type string\|null
L259 Type array\|null

Two failure modes combine:

  1. strings.Split(line, "|") is escape-blind. It breaks on the pipe inside \|, so a row that should have 6 cells yields 7–9. Every positional index after the embedded pipe shifts → wrong Scope / wrong ceiling marker.
  2. Right-anchoring alone also breaks on L246. The trailing Notes column is free-form and may itself contain \|. On L246 the escaped pipes inflate the cell count on the right side, so even cells[len-2]/cells[len-1] reads the wrong value.

The escape \| is a literal two-character sequence in the cell, not a separator.

3. The exact fix

3.1 src/cfg/schema.go — escape-aware splitter

Add a splitter that copies \| verbatim and only breaks on an unescaped |:

// splitMarkdownRow splits a markdown table row on unescaped '|' characters.
// A backslash-pipe "\|" is preserved in the cell as the literal two-byte
// sequence "\|" and is NOT treated as a column separator.
func splitMarkdownRow(line string) []string {
    var cells []string
    var b strings.Builder
    for i := 0; i < len(line); i++ {
        c := line[i]
        if c == '\\' && i+1 < len(line) && line[i+1] == '|' {
            b.WriteByte('\\')
            b.WriteByte('|')
            i++ // consume the pipe as part of the escape
            continue
        }
        if c == '|' {
            cells = append(cells, b.String())
            b.Reset()
            continue
        }
        b.WriteByte(c)
    }
    cells = append(cells, b.String())
    return cells
}

// trimRowCells removes the empty cells produced by the leading/trailing '|'.
func trimRowCells(cells []string) []string {
    if len(cells) > 0 && strings.TrimSpace(cells[0]) == "" {
        cells = cells[1:]
    }
    if len(cells) > 0 && strings.TrimSpace(cells[len(cells)-1]) == "" {
        cells = cells[:len(cells)-1]
    }
    return cells
}

3.2 src/cfg/schema_test.go — assert cell count, then anchor from the RIGHT

const (
    wantRows = 63
    wantCols = 6

    // If the contract changes its escaping convention this guard fails loudly
    // instead of silently mis-parsing.
    wantEscapedPipeRows = 7
)

// parseContractTable parses the L224–286 table. Every data row MUST yield
// exactly the header's cell count, otherwise the test fails hard.
func parseContractTable(t *testing.T, body []string) [][]string {
    t.Helper()
    var rows [][]string
    for _, line := range body {
        cells := trimRowCells(splitMarkdownRow(line))
        if len(cells) != wantCols {
            t.Fatalf("SC-02 table row yields %d cells, want %d: %q",
                len(cells), wantCols, line)
        }
        for i := range cells {
            cells[i] = strings.TrimSpace(cells[i])
        }
        rows = append(rows, cells)
    }
    if len(rows) != wantRows {
        t.Fatalf("SC-02 table row count = %d, want %d", len(rows), wantRows)
    }
    return rows
}

Get the free-form trailing column and the ceiling marker from the right, so the Notes escapes can never shift them:
