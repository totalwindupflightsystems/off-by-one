Fix: arms_plan=67 arms_tree=68 — section-mapping gate drift

Gate: docs/audits/cf198-section-mapping.sh Consumers: tests/selftest.sh section 39, docs/ACCEPTANCE-PLAN.md Base: a8112ae (gate reports arms_plan=67 arms_tree=67 RESULT: OK) Working tree: gate reports arms_plan=67 arms_tree=68 RESULT: FAIL

1. Root-cause analysis

The gate is a derived-count / cross-artifact consistency check:

Quantity Derived from Working tree
arms_tree ^say "N\. numbered section markers in tests/selftest.sh 68
arms_plan | §N | mapping rows in docs/ACCEPTANCE-PLAN.md 67

The diff under test adds a new numbered selftest section (arm §65) but does not add its | §65 | row to the plan. The artifacts are out of sync by one row. The fix is to make the plan describe the new arm — never to weaken the gate.

Trap 1 — "pre-existing" is wrong. There is a genuinely pre-existing failure nearby (section 56, unrelated port/auth battery). The discriminator is to rebuild the audit at base in a detached worktree: base a8112ae → 67/67 OK; working tree → 67/68 FAIL. Green-at-base / red-in-tree means the diff introduced it.

Trap 2 — over-broad hermeticity arm. The audit's "tracked files untouched" arm must be scoped to the paths the fixtures write, not git status of the whole tree, or it fails on the very diff being gated.

2. Exact fix

2a. Derive the missing id (don't hard-code blindly):

cd "$(git rev-parse --show-toplevel)"
comm -23 \
  <(grep -oE '^say "[0-9]+\.' tests/selftest.sh | grep -oE '[0-9]+' | LC_ALL=C sort -u) \
  <(grep -oE '^\| *§[0-9]+ *\|' docs/ACCEPTANCE-PLAN.md | grep -oE '[0-9]+' | LC_ALL=C sort -u)
# expected: 65
grep -nE '^say "65\.' tests/selftest.sh   # title source for the new row

2b. Add the §65 row to docs/ACCEPTANCE-PLAN.md, matching neighbouring §64/§66 columns:

| §65 | <title from tests/selftest.sh> | <status, matching neighbours> |

2c. Bump the prose arm count 67 → 68 in docs/ACCEPTANCE-PLAN.md:

grep -nE '\b(67|sixty-seven)\b' docs/ACCEPTANCE-PLAN.md

2d. Scope the hermeticity arm in docs/audits/cf198-section-mapping.sh. Replace whole-tree git status with a fixture-path snapshot:

FIXTURE_PATHS=(  # the exact paths the audit fixtures write
  # "docs/ACCEPTANCE-PLAN.md.fixture"  ...
)
snapshot() { git status --porcelain -- "${FIXTURE_PATHS[@]}"; }
before="$(snapshot)"
# ... run fixtures ...
after="$(snapshot)"
if [ "$before" != "$after" ]; then
  echo "FAIL: fixtures touched tracked files:" >&2; printf '%s\n' "$after" >&2; exit 1
fi
