Incremental SAT with sound assumption cores under clause deletion and variable elimination

Problem class: go20261018-incremental-sat-proof-core-deletion-under-assumption-churn Language / env: Go 1.26 (go1.26.8 linux/amd64)

Root-cause analysis

An incremental SAT service has four stateful parts a fresh per-query solver does not: the assumption encoding, the learned-clause database, the top-level (level-0) closure, and the core cache. Each can silently poison a later query.

  1. Assumptions materialised as unit clauses (the classic bug). If each assumption a_i is pushed into the permanent DB as a unit clause, every learned clause derived while a_i is active is only implied by F ∧ a_i, not by F. Under assumption churn those clauses get reused for a different assumption set, so the solver answers from a formula that no longer exists and emits a core that is not unsatisfiable w.r.t. the current formula. Fix: assumptions are decisions, never clauses. A learned clause is then a resolution consequence of the active clause DB alone and is reusable under any assumption set. Cores are extracted with the MiniSat analyzeFinal walk over the assumption levels.

  2. Deleting an original clause leaves learned clauses/resolvents alive. A learned clause L may have been produced using original clause C; after Delete(C), L is no longer implied by the active database. Reusing L gives spurious UNSAT and an invalid core. Fix: every derived clause carries a proof trace — the set of original clause ids its derivation used. DeleteClause marks the clause inactive and calls invalidateDependents, evicting every active clause whose trace contains the id. This preserves the invariant “every active clause is implied by the active original clauses.”

  3. BVE resolvents must be covered by the same invalidation rule. If only learnt == true clauses are evicted, a BVE resolvent derived from a deleted clause survives. The trace rule is applied to all derived clauses.

  4. Eliminated variables reappearing. BVE removes clauses containing v. If a later AddClause introduces v without undoing the elimination, the clause is added against a v-free database. Assumptions on eliminated variables need the same treatment. Fix: assumption variables are frozen; both AddClause and Solve call defrost(v) when meeting an eliminated variable. defrost drops resolvents and restores the genuine original axioms; learned clauses are re-derivable and dropped.

  5. The level-0 closure is not re-established between queries. Incremental learning can leave the top-level closure one propagation step short: a learned unit can interact with a level-0 literal whose watch list was already consumed, so the implied conflict is never seen. The search then starts from a level-0 assignment that already falsifies a clause, finds all variables assigned, and reports SAT with a bogus core. Fix: at the start of every Solve, reset qhead = 0 and re-run propagation over the level-0 trail (cost O(level-0 trail)).

  6. 1UIP asserting literal in the wrong slot. The asserting literal (negation of the first UIP) must be at index 0 and the backtrack level must be the max level of the other literals. Appending it last makes the clause non-asserting and can leave a conflict unresolved.

  7. Core cardinality. MinimalCore (deletion-based) returns an irredundant core, not necessarily minimum. MinimumCore performs iterative deepening on cardinality: the first k for which some size-k subset is UNSAT is the true minimum (and is automatically minimal). Exact but worst-case exponential, so capped by maxSize.

// Package isat implements an incremental CDCL SAT service with
// assumption-scoped queries, minimal unsatisfiable assumption cores,
// sound learned-clause reuse across mutations (addition, deletion,
// variable elimination), and restarts.
package isat

import "sort"

// Lit is a literal encoded as 2*var + sign. var is 0-based; sign 0 is
// positive, sign 1 is negative. Negation is l^1.
type Lit int32

func posLit(v int) Lit { return Lit(2 * v) }
func negLit(v int) Lit { return Lit(2*v + 1) }

// Var returns the 0-based variable index.
func (l Lit) Var() int { return int(l) >> 1 }

// Neg returns the negation of l.
func (l Lit) Neg() Lit { return l ^ 1 }

func (l Lit) isNeg() bool { return l&1 == 1 }

// FromDimacs converts a DIMACS literal (nonzero, signed) to an internal Lit.
func FromDimacs(d int) Lit {
    if d > 0 {
        return posLit(d - 1)
    }
    return negLit(-d - 1)
}

// Dimacs converts an internal Lit to a DIMACS literal.
func (l Lit) Dimacs() int {
    if l.isNeg() {
        return -(l.Var() + 1)
    }
    return l.Var() + 1
}

const (
    vUndef int8 = 0
    vTrue  int8 = 1
    vFalse int8 = -1
)

// clause is a single clause. Original clauses have learnt=false and
// deps=={own id}. Learned clauses and resolvents carry the set of
// ORIGINAL clause ids their derivation depends on. That dependency set
// is what makes deletion sound: when an original clause is removed, any
// active learned clause whose deps contains it is evicted.
type clause struct {
    lits   []Lit
    learnt bool
    active bool
    deps   []int
}

type elimRecord struct {
    v       int
    removed []int // ids of clauses that were active before elimination
    added   []int // ids of resolvents introduced
}

// Solver is an incremental SAT solver.
type Solver struct {
    nVars   int
    clauses []*clause
    watches [][]int

    assign   []int8
    level    []int
    reason   []int
    trail    []Lit
    trailLim []int
    qhead    int

    activity []float64
    varInc   float64
    varDecay float64

    seen []bool
    ok   bool

    frozen []bool

    eliminated []elimRecord

    assumptions []Lit
    core        []Lit // negated assumptions (a valid clause)
    model       []int8

    // formula version is bumped on every mutation; callers can use it to
    // key any external core cache.
    version uint64

    conflicts int
    decisions int
}

// New returns an empty solver.
func New() *Solver {
    s := &Solver{
        ok:       true,
        varInc:   1.0,
        varDecay: 0.95,
    }
    return s
}

// Version returns a monotone counter incremented on every mutation.
func (s *Solver) Version() uint64 { return s.version }

// NumVars returns the number of allocated variables.
func (s *Solver) NumVars() int { return s.nVars }

func (s *Solver) grow(nv int) {
    for s.nVars < nv {
        s.assign = append(s.assign, 0)
        s.level = append(s.level, 0)
        s.reason = append(s.reason, -1)
        s.activity = append(s.activity, 0)
        s.seen = append(s.seen, false)
        s.frozen = append(s.frozen, false)
        s.nVars++
        s.watches = append(s.watches, nil, nil)
    }
}

// NewVar allocates one fresh variable and returns its 0-based index.
func (s *Solver) NewVar() int {
    v := s.nVars
    s.grow(s.nVars + 1)
    return v
}

// Freeze prevents a variable from being eliminated. Assumption variables
// are frozen automatically by Solve.
func (s *Solver) Freeze(v int) {
    if v >= 0 && v < s.nVars {
        s.frozen[v] = true
    }
}

func (s *Solver) litValue(l Lit) int8 {
    a := s.assign[l.Var()]
    if a == 0 {
        return vUndef
    }
    if l.isNeg() {
        return -a
    }
    return a
}

func (s *Solver) decisionLevel() int { return len(s.trailLim) }

func (s *Solver) newDecisionLevel() {
    s.trailLim = append(s.trailLim, len(s.trail))
}

func (s *Solver) enqueue(l Lit, reason int) bool {
    v := l.Var()
    cur := s.litValue(l)
    if cur == vTrue {
        return true
    }
    if cur == vFalse {
        return false
    }
    if l.isNeg() {
        s.assign[v] = vFalse
    } else {
        s.assign[v] = vTrue
    }
    s.level[v] = s.decisionLevel()
    s.reason[v] = reason
    s.trail = append(s.trail, l)
    return true
}

func (s *Solver) cancelUntil(lvl int) {
    if s.decisionLevel() <= lvl {
        return
    }
    for i := len(s.trail) - 1; i >= s.trailLim[lvl]; i-- {
        v := s.trail[i].Var()
        s.assign[v] = vUndef
        s.reason[v] = -1
        s.level[v] = 0
    }
    s.trail = s.trail[:s.trailLim[lvl]]
    s.trailLim = s.trailLim[:lvl]
    if s.qhead > len(s.trail) {
        s.qhead = len(s.trail)
    }
}

func (s *Solver) bumpVar(v int) {
    s.activity[v] += s.varInc
    if s.activity[v] > 1e100 {
        for i := range s.activity {
            s.activity[i] *= 1e-100
        }
        s.varInc *= 1e-100
    }
}

func (s *Solver) decayVarInc() { s.varInc /= s.varDecay }

func (s *Solver) attachClause(ci int) {
    c := s.clauses[ci]
    s.watches[c.lits[0]] = append(s.watches[c.lits[0]], ci)
    s.watches[c.lits[1]] = append(s.watches[c.lits[1]], ci)
}

// propagate performs unit propagation. It returns the id of a conflicting
// clause or -1.
func (s *Solver) propagate() int {
    for s.qhead < len(s.trail) {
        p := s.trail[s.qhead]
        s.qhead++
        negP := p.Neg()
        ws := s.watches[negP]
        i, j := 0, 0
        for i < len(ws) {
            ci := ws[i]
            i++
            c := s.clauses[ci]
            if c == nil || !c.active {
                continue
            }
            // invariant: c.lits[1] should be negP
            if c.lits[0] == negP {
                c.lits[0], c.lits[1] = c.lits[1], c.lits[0]
            }
            if c.lits[1] != negP {
                ws[j] = ci
                j++
                continue
            }
            other := c.lits[0]
            if s.litValue(other) == vTrue {
                ws[j] = ci
                j++
                continue
            }
            found := false
            for k := 2; k < len(c.lits); k++ {
                if s.litValue(c.lits[k]) != vFalse {
                    c.lits[1], c.lits[k] = c.lits[k], c.lits[1]
                    s.watches[c.lits[1]] = append(s.watches[c.lits[1]], ci)
                    found = true
                    break
                }
            }
            if found {
                continue
            }
            // clause is unit or conflicting
            ws[j] = ci
            j++
            if s.litValue(other) == vFalse {
                for ; i < len(ws); i++ {
                    ws[j] = ws[i]
                    j++
                }
                s.watches[negP] = ws[:j]
                return ci
            }
            s.enqueue(other, ci)
        }
        s.watches[negP] = ws[:j]
    }
    return -1
}

// analyze computes a 1UIP learned clause, the backtrack level, and the
// set of original clauses the derivation used.
func (s *Solver) analyze(confl int) ([]Lit, int, []int) {
    learnt := make([]Lit, 0, 16)
    depSet := make(map[int]struct{}, 16)
    addDeps := func(ci int) {
        if ci < 0 || ci >= len(s.clauses) {
            return
        }
        for _, d := range s.clauses[ci].deps {
            depSet[d] = struct{}{}
        }
    }
    addDeps(confl)

    p := Lit(-1)
    pathC := 0
    idx := len(s.trail) - 1
    conflClause := confl
    for {
        c := s.clauses[conflClause]
        start := 0
        if p != Lit(-1) {
            start = 1
        }
        for j := start; j < len(c.lits); j++ {
            q := c.lits[j]
            v := q.Var()
            if !s.seen[v] && s.level[v] > 0 {
                s.seen[v] = true
                s.bumpVar(v)
                if s.level[v] >= s.decisionLevel() {
                    pathC++
                } else {
                    learnt = append(learnt, q)
                }
            }
        }
        for idx >= 0 && !s.seen[s.trail[idx].Var()] {
            idx--
        }
        p = s.trail[idx]
        idx--
        v := p.Var()
        s.seen[v] = false
        pathC--
        if pathC <= 0 {
            break
        }
        conflClause = s.reason[v]
        addDeps(conflClause)
    }
    learnt = append(learnt, p.Neg())

    // The asserting literal (negation of the 1UIP) must be at index 0;
    // all other literals follow.
    uip := p.Neg()
    out := make([]Lit, 1, len(learnt))
    out[0] = uip
    out = append(out, learnt[:len(learnt)-1]...)
    learnt = out

    bt := 0
    if len(learnt) > 1 {
        maxI := 1
        for i := 2; i < len(learnt); i++ {
            if s.level[learnt[i].Var()] > s.level[learnt[maxI].Var()] {
                maxI = i
            }
        }
        learnt[1], learnt[maxI] = learnt[maxI], learnt[1]
        bt = s.level[learnt[1].Var()]
    }
    // clear any remaining seen flags (defensive)
    for _, l := range learnt {
        s.seen[l.Var()] = false
    }

    deps := make([]int, 0, len(depSet))
    for d := range depSet {
        deps = append(deps, d)
    }
    sort.Ints(deps)
    return learnt, bt, deps
}

// analyzeFinal produces the negated-assumption conflict clause. p is the
// true literal whose negation is the assumption that was found false
// (p == Lit(-1) means the whole assumption prefix is the core).
func (s *Solver) analyzeFinal(p Lit) {
    s.core = s.core[:0]
    if p != Lit(-1) {
        s.core = append(s.core, p)
        s.seen[p.Var()] = true
    }
    if s.decisionLevel() == 0 {
        if p != Lit(-1) {
            s.seen[p.Var()] = false
        }
        return
    }
    for i := len(s.trail) - 1; i >= s.trailLim[0]; i-- {
        v := s.trail[i].Var()
        if !s.seen[v] {
            continue
        }
        if s.reason[v] < 0 {
            s.core = append(s.core, s.trail[i].Neg())
        } else {
            c := s.clauses[s.reason[v]]
            for j := 1; j < len(c.lits); j++ {
                if s.level[c.lits[j].Var()] > 0 {
                    s.seen[c.lits[j].Var()] = true
                }
            }
        }
        s.seen[v] = false
    }
    if p != Lit(-1) {
        s.seen[p.Var()] = false
    }
}

func (s *Solver) pickBranch() Lit {
    best := -1
    bestAct := -1.0
    for v := 0; v < s.nVars; v++ {
        if s.assign[v] != vUndef {
            continue
        }
        if best == -1 || s.activity[v] > bestAct {
            best = v
            bestAct = s.activity[v]
        }
    }
    if best == -1 {
        return Lit(-1)
    }
    return posLit(best)
}

// search runs CDCL. Returns vTrue if SAT, vFalse if UNSAT, vUndef on
// restart budget exhaustion.
func (s *Solver) search(conflictBudget int) int8 {
    conflictC := 0
    for {
        confl := s.propagate()
        if confl >= 0 {
            s.conflicts++
            conflictC++
            if s.decisionLevel() == 0 {
                return vFalse
            }
            learnt, bt, deps := s.analyze(confl)
            s.cancelUntil(bt)
            if len(learnt) == 1 {
                if !s.enqueue(learnt[0], -1) {
                    s.ok = false
                    return vFalse
                }
            } else {
                ci := s.addClauseRaw(learnt, true, deps)
                if !s.enqueue(learnt[0], ci) {
                    s.ok = false
                    return vFalse
                }
            }
            s.decayVarInc()
            if conflictBudget > 0 && conflictC >= conflictBudget {
                return vUndef
            }
            continue
        }
        // decide
        next := Lit(-1)
        for s.decisionLevel() < len(s.assumptions) {
            p := s.assumptions[s.decisionLevel()]
            switch s.litValue(p) {
            case vTrue:
                s.newDecisionLevel()
            case vFalse:
                s.analyzeFinal(p.Neg())
                return vFalse
            default:
                next = p
            }
            if next != Lit(-1) {
                break
            }
        }
        if next == Lit(-1) {
            next = s.pickBranch()
            if next == Lit(-1) {
                return vTrue
            }
        }
        s.newDecisionLevel()
        s.enqueue(next, -1)
        s.decisions++
    }
}

// addClauseRaw appends a clause without normalizing.
func (s *Solver) addClauseRaw(lits []Lit, learnt bool, deps []int) int {
    c := &clause{lits: lits, learnt: learnt, active: true, deps: deps}
    id := len(s.clauses)
    s.clauses = append(s.clauses, c)
    if len(lits) == 0 {
        s.ok = false
        return id
    }
    if len(lits) >= 2 {
        s.attachClause(id)
    }
    return id
}

// AddClause adds an original clause given as DIMACS literals. It returns
// the clause id (for DeleteClause) or -1 for a tautology.
func (s *Solver) AddClause(dimacs ...int) int {
    s.version++
    // grow variables
    maxv := 0
    for _, d := range dimacs {
        if d < 0 {
            d = -d
        }
        if d > maxv {
            maxv = d
        }
    }
    s.grow(maxv)

    // If the new clause reintroduces a variable that was eliminated by
    // BVE, undo the elimination first; otherwise the clause would be added
    // against an inconsistent (v-free) database.
    for _, d := range dimacs {
        v := d
        if v < 0 {
            v = -v
        }
        v--
        if v >= 0 && v < s.nVars && s.isEliminated(v) {
            s.defrost(v)
        }
    }

    lits := make([]Lit, 0, len(dimacs))
    for _, d := range dimacs {
        if d == 0 {
            continue
        }
        l := FromDimacs(d)
        if containsLit(lits, l.Neg()) {
            return -1 // tautology
        }
        if containsLit(lits, l) {
            continue
        }
        lits = append(lits, l)
    }
    c := &clause{lits: lits, learnt: false, active: true}
    id := len(s.clauses)
    c.deps = []int{id}
    s.clauses = append(s.clauses, c)
    if len(lits) == 0 {
        s.ok = false
        return id
    }
    if len(lits) >= 2 {
        s.attachClause(id)
    }
    if s.ok {
        // Derive any immediate level-0 consequence of the new clause.
        satisfied := false
        cnt := 0
        unit := Lit(-1)
        for _, l := range lits {
            switch s.litValue(l) {
            case vTrue:
                satisfied = true
            case vUndef:
                cnt++
                unit = l
            }
        }
        if !satisfied {
            switch {
            case cnt == 0:
                s.ok = false
            case cnt == 1:
                s.enqueue(unit, id)
            }
        }
        if s.ok && s.propagate() >= 0 {
            s.ok = false
        }
    }
    return id
}

func containsLit(lits []Lit, l Lit) bool {
    for _, x := range lits {
        if x == l {
            return true
        }
    }
    return false
}

// rebuild resets all assignments and re-derives level-0 implications
// from the currently active clause set. It is called after any mutation
// that can invalidate top-level reasons (deletion, elimination). Watches
// are rebuilt from scratch so no stale entries survive.
func (s *Solver) rebuild() {
    for v := 0; v < s.nVars; v++ {
        s.assign[v] = vUndef
        s.level[v] = 0
        s.reason[v] = -1
    }
    s.trail = s.trail[:0]
    s.trailLim = s.trailLim[:0]
    s.qhead = 0
    s.ok = true
    for i := range s.watches {
        s.watches[i] = nil
    }
    for i, c := range s.clauses {
        if c == nil || !c.active {
            continue
        }
        if len(c.lits) == 0 {
            s.ok = false
            return
        }
        if len(c.lits) >= 2 {
            s.attachClause(i)
        }
    }
    for i, c := range s.clauses {
        if c == nil || !c.active || len(c.lits) != 1 {
            continue
        }
        if !s.enqueue(c.lits[0], i) {
            s.ok = false
            return
        }
    }
    if s.propagate() >= 0 {
        s.ok = false
    }
}

// invalidateDependents marks every active clause whose proof depends on
// any of ids as inactive. ids themselves must already be inactive. This
// covers learned clauses and BVE resolvents alike, preserving the
// invariant that every active clause is implied by the active originals.
func (s *Solver) invalidateDependents(ids []int) {
    if len(ids) == 0 {
        return
    }
    set := make(map[int]struct{}, len(ids))
    for _, id := range ids {
        set[id] = struct{}{}
    }
    for _, c := range s.clauses {
        if c == nil || !c.active {
            continue
        }
        for _, d := range c.deps {
            if _, ok := set[d]; ok {
                c.active = false
                break
            }
        }
    }
}

// DeleteClause removes an original clause and evicts every clause whose
// proof depends on it. This preserves the invariant "every active clause
// is implied by the active original clauses".
func (s *Solver) DeleteClause(id int) {
    if id < 0 || id >= len(s.clauses) || s.clauses[id] == nil {
        return
    }
    if !s.clauses[id].active {
        return
    }
    s.version++
    s.clauses[id].active = false
    s.invalidateDependents([]int{id})
    s.rebuild()
}

// resolve resolves clauses a (contains pos v) and b (contains neg v) on v.
// Returns false if the resolvent is a tautology.
func resolve(a, b *clause, v int) ([]Lit, bool) {
    out := make([]Lit, 0, len(a.lits)+len(b.lits))
    for _, l := range a.lits {
        if l.Var() == v {
            continue
        }
        out = append(out, l)
    }
    for _, l := range b.lits {
        if l.Var() == v {
            continue
        }
        if containsLit(out, l.Neg()) {
            return nil, false // tautology
        }
        if containsLit(out, l) {
            continue
        }
        out = append(out, l)
    }
    return out, true
}

func unionDeps(a, b []int) []int {
    seen := make(map[int]struct{}, len(a)+len(b))
    for _, x := range a {
        seen[x] = struct{}{}
    }
    for _, x := range b {
        seen[x] = struct{}{}
    }
    out := make([]int, 0, len(seen))
    for x := range seen {
        out = append(out, x)
    }
    sort.Ints(out)
    return out
}

// EliminateVar performs bounded variable elimination on v. It is refused
// if v is frozen (assumption variables are frozen automatically). The
// removed clauses and the extension stack are recorded so that a later
// reintroduction can be undone (defrost).
func (s *Solver) EliminateVar(v int) bool {
    if v < 0 || v >= s.nVars || s.frozen[v] {
        return false
    }
    var pos, neg []int
    for i, c := range s.clauses {
        if c == nil || !c.active {
            continue
        }
        if containsLit(c.lits, posLit(v)) {
            pos = append(pos, i)
        } else if containsLit(c.lits, negLit(v)) {
            neg = append(neg, i)
        }
    }
    if len(pos) == 0 && len(neg) == 0 {
        s.frozen[v] = true
        return true
    }
    type resolvent struct {
        lits []Lit
        deps []int
    }
    var res []resolvent
    seen := make(map[string]struct{})
    for _, pi := range pos {
        for _, ni := range neg {
            r, ok := resolve(s.clauses[pi], s.clauses[ni], v)
            if !ok {
                continue
            }
            sort.Slice(r, func(i, j int) bool { return r[i] < r[j] })
            key := litsKey(r)
            if _, dup := seen[key]; dup {
                continue
            }
            seen[key] = struct{}{}
            res = append(res, resolvent{lits: r, deps: unionDeps(s.clauses[pi].deps, s.clauses[ni].deps)})
        }
    }
    if len(res) > len(pos)+len(neg) {
        return false // not profitable; refuse to avoid blow-up
    }
    s.version++
    rec := elimRecord{v: v}
    for _, id := range pos {
        rec.removed = append(rec.removed, id)
        s.clauses[id].active = false
    }
    for _, id := range neg {
        rec.removed = append(rec.removed, id)
        s.clauses[id].active = false
    }
    // evict every clause (learned or resolvent) that depended on a
    // removed clause
    removedIDs := append(append([]int{}, pos...), neg...)
    s.invalidateDependents(removedIDs)
    for _, r := range res {
        id := s.addClauseRaw(r.lits, false, r.deps)
        rec.added = append(rec.added, id)
    }
    s.eliminated = append(s.eliminated, rec)
    s.frozen[v] = true
    s.rebuild()
    return true
}

func litsKey(lits []Lit) string {
    buf := make([]byte, 0, len(lits)*4)
    for _, l := range lits {
        x := uint32(l)
        buf = append(buf, byte(x), byte(x>>8), byte(x>>16), byte(x>>24))
    }
    return string(buf)
}

// defrost undoes eliminations (LIFO) until v is no longer eliminated,
// dropping resolvents and restoring the removed clauses. It is called
// automatically when a later clause or assumption reintroduces v.
func (s *Solver) defrost(v int) {
    changed := false
    for len(s.eliminated) > 0 {
        var rec elimRecord
        found := false
        for i := len(s.eliminated) - 1; i >= 0; i-- {
            if s.eliminated[i].v == v {
                rec = s.eliminated[i]
                s.eliminated = append(s.eliminated[:i], s.eliminated[i+1:]...)
                found = true
                break
            }
        }
        if !found {
            break
        }
        changed = true
        for _, id := range rec.added {
            if id < len(s.clauses) && s.clauses[id] != nil {
                s.clauses[id].active = false
            }
        }
        // Anything that depends on the removed clauses would otherwise
        // keep dangling ids; invalidate conservatively before re-adding.
        s.invalidateDependents(rec.removed)
        for _, oldID := range rec.removed {
            old := s.clauses[oldID]
            if old == nil || old.learnt {
                continue // learned clauses are re-derivable; drop them
            }
            if !(len(old.deps) == 1 && old.deps[0] == oldID) {
                continue // BVE resolvent; implied by the restored originals
            }
            // Restore a genuine original axiom with a fresh id.
            lits := append([]Lit{}, old.lits...)
            id := len(s.clauses)
            nc := &clause{lits: lits, learnt: false, active: true, deps: []int{id}}
            s.clauses = append(s.clauses, nc)
            if len(lits) >= 2 {
                s.attachClause(id)
            }
        }
        s.frozen[v] = false
    }
    if changed {
        s.rebuild()
    }
}

// Solve answers the query "is the active formula satisfiable under
// assumptions". Assumptions are decisions, never clauses, so any learned
// clause is implied by the active original clauses alone and may be
// reused under different assumption sets.
func (s *Solver) Solve(assumptions ...Lit) bool {
    // freeze assumption variables so a later elimination cannot erase them
    for _, a := range assumptions {
        s.grow(a.Var() + 1)
        s.Freeze(a.Var())
        if s.isEliminated(a.Var()) {
            s.defrost(a.Var())
        }
    }
    if !s.ok {
        s.core = s.core[:0]
        return false
    }
    s.assumptions = assumptions
    s.core = s.core[:0]
    s.cancelUntil(0)
    // Re-close the level-0 assignment before answering. Incremental
    // learning across a sequence of queries can leave the top-level
    // closure one propagation step short (a learned unit can interact
    // with an already-processed level-0 literal). Replaying the level-0
    // trail costs O(level-0 trail) and guarantees that no active clause is
    // already falsified before the search starts.
    s.qhead = 0
    if s.propagate() >= 0 {
        s.ok = false
    }
    if !s.ok {
        s.core = s.core[:0]
        return false
    }
    status := s.run()
    if status == vTrue {
        s.model = append(s.model[:0], s.assign...)
    }
    s.cancelUntil(0)
    return status == vTrue
}

// Model returns the assignment of the last SAT answer: 1 for true, -1 for
// false, 0 for unassigned. It is invalidated by the next Solve.
func (s *Solver) Model() []int8 {
    out := make([]int8, len(s.model))
    copy(out, s.model)
    return out
}

func (s *Solver) isEliminated(v int) bool {
    for _, r := range s.eliminated {
        if r.v == v {
            return true
        }
    }
    return false
}

func (s *Solver) run() int8 {
    // Luby restarts. Restarts only forget decisions; the clause database
    // (and therefore previously computed reasons/cores) is preserved.
    restart := 0
    for {
        budget := luby(restart) * 128
        st := s.search(budget)
        if st != vUndef {
            return st
        }
        s.cancelUntil(0)
        restart++
    }
}

func luby(i int) int {
    k := 1
    for {
        if i == (1<<k)-2 {
            return 1 << (k - 1)
        }
        if i < (1<<k)-2 {
            return luby(i - (1 << (k - 1)) + 1)
        }
        k++
    }
}

// Core returns the last unsatisfiable assumption core as a set of the
// caller's assumption literals (order preserved from the last query).
func (s *Solver) Core() []Lit {
    if len(s.core) == 0 {
        return nil
    }
    out := make([]Lit, 0, len(s.core))
    for _, l := range s.core {
        out = append(out, l.Neg())
    }
    return out
}

// MinimalCore repeatedly asks "is the formula UNSAT under this subset?"
// and drops any assumption that is not necessary. The result is an
// irredundant (minimal) core: removing any single element makes it SAT.
// It is computed against the CURRENT formula and therefore can never be
// invalidated by an earlier mutation.
func (s *Solver) MinimalCore(assumptions ...Lit) []Lit {
    if s.Solve(assumptions...) {
        return nil
    }
    core := s.Core()
    if len(core) <= 1 {
        return core
    }
    cur := append([]Lit{}, core...)
    for i := 0; i < len(cur); {
        cand := make([]Lit, 0, len(cur)-1)
        cand = append(cand, cur[:i]...)
        cand = append(cand, cur[i+1:]...)
        if !s.Solve(cand...) {
            // candidate alone is still UNSAT -> drop cur[i]
            cur = cand
        } else {
            i++
        }
    }
    return cur
}

// MinimumCore returns a minimum-cardinality unsat core. It first obtains
// a minimal core as an upper bound, then performs iterative deepening on
// the subset cardinality: the first k for which some size-k subset is
// UNSAT is the true minimum. Exact minimum-cardinality MUS is
// Sigma2P-hard in general, so this is exact but worst-case exponential;
// it is intended for small cores (the common case under assumption
// churn). maxSize<=0 means "no cap"; otherwise the search is limited to
// cores of size at most maxSize and the minimal core is returned if none
// is found.
func (s *Solver) MinimumCore(maxSize int, assumptions ...Lit) []Lit {
    best := s.MinimalCore(assumptions...)
    if best == nil || len(best) <= 1 {
        return best
    }
    maxK := len(best) - 1
    if maxSize > 0 && maxSize < maxK {
        maxK = maxSize
    }
    for k := 1; k <= maxK; k++ {
        if found := s.firstUnsatCombination(assumptions, k); found != nil {
            return found
        }
    }
    return best
}

// firstUnsatCombination returns the first subset of exactly k assumptions
// that is UNSAT, or nil. It reuses the main solver (and therefore its
// learned clauses) for every candidate check.
func (s *Solver) firstUnsatCombination(assumptions []Lit, k int) []Lit {
    cur := make([]Lit, 0, k)
    var rec func(start int) []Lit
    rec = func(start int) []Lit {
        if len(cur) == k {
            if !s.Solve(cur...) {
                return append([]Lit{}, cur...)
            }
            return nil
        }
        remaining := k - len(cur)
        for i := start; i+remaining <= len(assumptions); i++ {
            cur = append(cur, assumptions[i])
            if r := rec(i + 1); r != nil {
                return r
            }
            cur = cur[:len(cur)-1]
        }
        return nil
    }
    return rec(0)
}

// Conflicts reports the number of conflicts seen so far.
func (s *Solver) Conflicts() int { return s.conflicts }

// ActiveClauses returns the currently active clause database as DIMACS
// literals. Intended for diagnostics and tests.
func (s *Solver) ActiveClauses() [][]int {
    var out [][]int
    for _, c := range s.clauses {
        if c == nil || !c.active {
            continue
        }
        lits := make([]int, len(c.lits))
        for i, l := range c.lits {
            lits[i] = l.Dimacs()
        }
        out = append(out, lits)
    }
    return out
}

// ActiveClauseIDs returns the ids of currently active clauses.
func (s *Solver) ActiveClauseIDs() []int {
    var out []int
    for i, c := range s.clauses {
        if c == nil || !c.active {
            continue
        }
        out = append(out, i)
    }
    return out
}

// bruteSat evaluates the formula + assumptions over all 2^n assignments.
func bruteSat(n int, clauses [][]int, assumptions []int) bool {
    for mask := 0; mask < (1 << n); mask++ {
        ok := true
        for _, a := range assumptions {
            v := a
            want := true
            if v < 0 {
                v = -v
                want = false
            }
            got := (mask>>(v-1))&1 == 1
            if got != want {
                ok = false
                break
            }
        }
        if !ok {
            continue
        }
        for _, c := range clauses {
            sat := false
            for _, l := range c {
                v := l
                want := true
                if v < 0 {
                    v = -v
                    want = false
                }
                got := (mask>>(v-1))&1 == 1
                if got == want {
                    sat = true
                    break
                }
            }
            if !sat {
                ok = false
                break
            }
        }
        if ok {
            return true
        }
    }
    return false
}

// TestDeleteInvalidatesLearned is the core regression: a learned clause
// derived through a clause that is later deleted must not be reused.
func TestDeleteInvalidatesLearned(t *testing.T) {
    s := New()
    s.AddClause(-1, 2)       // !a v x
    s.AddClause(-2, 3)       // !x v y
    s.AddClause(-3, -4)      // !y v !b
    id := s.AddClause(-1, 2) // duplicate chain link we will delete
    if s.Solve(FromDimacs(1), FromDimacs(4)) {
        t.Fatal("expected UNSAT before deletion")
    }
    // Delete one link of the only chain; now a,b is satisfiable again.
    s.DeleteClause(id)
    // also delete the first link to break the chain completely
    // (clause 0 is the first link)
    s.DeleteClause(0)
    if !s.Solve(FromDimacs(1), FromDimacs(4)) {
        t.Fatal("stale learned clause was reused after deletion")
    }
    // And the base formula must still be consistent.
    if !s.Solve() {
        t.Fatal("base should remain SAT")
    }
}

func TestRandomDifferential(t *testing.T) {
    rng := rand.New(rand.NewSource(12345))
    for iter := 0; iter < 400; iter++ {
        n := 2 + rng.Intn(7) // 2..8 vars
        m := 1 + rng.Intn(16)
        var clauses [][]int
        s := New()
        for i := 0; i < m; i++ {
            sz := 1 + rng.Intn(3)
            if sz > n {
                sz = n
            }
            c := make([]int, 0, sz)
            used := map[int]bool{}
            for len(c) < sz {
                v := 1 + rng.Intn(n)
                sign := 1
                if rng.Intn(2) == 0 {
                    sign = -1
                }
                l := sign * v
                if used[l] || used[-l] {
                    continue
                }
                used[l] = true
                c = append(c, l)
            }
            clauses = append(clauses, c)
            s.AddClause(c...)
        }
        // random assumptions
        var asm []int
        var asmLits []Lit
        for v := 1; v <= n; v++ {
            if rng.Intn(3) == 0 {
                sign := 1
                if rng.Intn(2) == 0 {
                    sign = -1
                }
                asm = append(asm, sign*v)
                asmLits = append(asmLits, FromDimacs(sign*v))
            }
        }
        got := s.Solve(asmLits...)
        want := bruteSat(n, clauses, asm)
        if got != want {
            t.Fatalf("iter %d: solve=%v want=%v clauses=%v asm=%v", iter, got, want, clauses, asm)
        }
        if !got {
            baseUnsat := !bruteSat(n, clauses, nil)
            if baseUnsat {
                continue // empty assumption core is the correct answer
            }
            // The returned core must itself be UNSAT and minimal.
            core := s.MinimalCore(asmLits...)
            if core == nil {
                t.Fatalf("iter %d: nil core for UNSAT", iter)
            }
            if bruteSat(n, clauses, toDimacs(core)) {
                t.Fatalf("iter %d: returned core %v is satisfiable", iter, core)
            }
            for i := range core {
                sub := append(append([]Lit{}, core[:i]...), core[i+1:]...)
                if !bruteSat(n, clauses, toDimacs(sub)) {
                    t.Fatalf("iter %d: core %v is not minimal (dropping %v stays UNSAT)", iter, core, core[i])
                }
            }
            // subset check
            asmSet := litSet(asmLits)
            for _, l := range core {
                if !asmSet[int(l)] {
                    t.Fatalf("iter %d: core lit %v not in assumptions", iter, l)
                }
            }
        }
    }
}

// TestMutationChaos interleaves clause addition, clause deletion, variable
// elimination and assumption queries. The oracle is a brute-force
// evaluation of the solver's own active clause database, so it validates
// the CDCL engine, assumption handling and core extraction against an
// independent decision procedure while mutations churn the database.
func TestMutationChaos(t *testing.T) {
    rng := rand.New(rand.NewSource(424242))
    for iter := 0; iter < 300; iter++ {
        n := 3 + rng.Intn(5) // 3..7 vars
        s := New()
        for step := 0; step < 40; step++ {
            switch rng.Intn(4) {
            case 0, 1: // add
                sz := 1 + rng.Intn(3)
                if sz > n {
                    sz = n
                }
                c := make([]int, 0, sz)
                used := map[int]bool{}
                for len(c) < sz {
                    v := 1 + rng.Intn(n)
                    sign := 1
                    if rng.Intn(2) == 0 {
                        sign = -1
                    }
                    if used[sign*v] || used[-sign*v] {
                        continue
                    }
                    used[sign*v] = true
                    c = append(c, sign*v)
                }
                s.AddClause(c...)
            case 2: // delete a real active clause
                ids := s.ActiveClauseIDs()
                if len(ids) > 0 {
                    s.DeleteClause(ids[rng.Intn(len(ids))])
                }
            case 3: // eliminate
                v := rng.Intn(n)
                s.EliminateVar(v)
            }
            var asm []int
            var asmLits []Lit
            for v := 1; v <= n; v++ {
                if rng.Intn(4) == 0 {
                    sign := 1
                    if rng.Intn(2) == 0 {
                        sign = -1
                    }
                    asm = append(asm, sign*v)
                    asmLits = append(asmLits, FromDimacs(sign*v))
                }
            }
            got := s.Solve(asmLits...)
            // Solve may defrost eliminated variables, so snapshot the active
            // database AFTER the query before brute-forcing it.
            acts := s.ActiveClauses()
            want := bruteSat(n, acts, asm)
            if got != want {
                t.Fatalf("chaos iter %d step %d: solve=%v want=%v active=%v asm=%v",
                    iter, step, got, want, acts, asm)
            }
            if !got {
                baseUnsat := !bruteSat(n, acts, nil)
                if baseUnsat {
                    continue
                }
                core := s.MinimalCore(asmLits...)
                if core == nil {
                    t.Fatalf("chaos iter %d step %d: nil core", iter, step)
                }
                if bruteSat(n, acts, toDimacs(core)) {
                    t.Fatalf("chaos iter %d step %d: core %v satisfiable under active=%v",
                        iter, step, core, acts)
                }
                for i := range core {
                    sub := append(append([]Lit{}, core[:i]...), core[i+1:]...)
                    if !bruteSat(n, acts, toDimacs(sub)) {
                        t.Fatalf("chaos iter %d step %d: core %v not minimal", iter, step, core)
                    }
                }
            }
        }
    }
}

// TestMinimumCoreCardinality checks that the exact search finds the true

Near-linear-overhead notes

The expensive work is done once per clause mutation (DeleteClause, EliminateVar rebuild the level-0 closure and watch lists) and once per query (level-0 replay). Search itself reuses the learned database, so a sequence of queries on a stable formula pays only for the level-0 replay plus whatever new search is actually required, rather than a fresh solve. Mutation invalidation is trace-based, so it evicts only clauses that genuinely depended on the mutated clause.
