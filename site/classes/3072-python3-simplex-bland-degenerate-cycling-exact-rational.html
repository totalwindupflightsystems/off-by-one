Exact Two-Phase Simplex with Bland's Rule and Machine-Checkable Certificates

Root-cause analysis

The spec is a set of coupled constraints; naive solvers fail each one for a distinct reason:

Requirement Root cause of naive failure
Exact optimum Float pivots/ratio tests pick wrong leaving variables and lose feasibility.
Klee–Minty n=8 termination Dantzig's rule revisits bases exponentially on the cube.
Beale cycling cube Dantzig deterministically loops on a degenerate vertex.
Degenerate vertices Ratio test must use only >0 entries and break ties by smallest basic index.
Unbounded rays Absence of a positive ratio must yield the escaping direction r[enter]=1, r[basis[i]]=-T[i][enter].
Redundant rows 0=0 rows make the basis singular unless deliberately removed; a user-supplied singular basis must raise a typed error.
Infeasibility Phase-I optimum < 0 proves infeasibility; its dual prices are the Farkas vector.
Dual certificate The optimal dual is π^T = c_B^T B^{-1}, not c_B — a subtle bug I hit and fixed.
Malformed input NaN comparisons are always false, so naive filters silently drop constraints.

The exact fix

Three files (full code in SOLUTION.md):

  • exact_simplex.py — Fraction-only two-phase simplex.
  • Bland's rule mandatory: entering = smallest index with r_j > 0; leaving = min ratio, ties by smallest basic index.
  • Artificials only for rows with b_i < 0 (preserves the slack basis, which is what makes Beale cycle under Dantzig and terminate under Bland).
  • Phase-I cleanup drives out artificials; all-zero rows are dropped as redundant.
  • Multipliers recovered by exact solve of B^T π = c_B on the original basis, then mapped through row signs: phase II y_i = sign_i π_i (dual), phase I failure y_i = sign_i π_i (Farkas).
  • Typed errors: NonFiniteInputError, DimensionMismatchError, RankDeficientBasisError, InvalidBasisError, InfeasibleStartingBasisError, EmptyBoundsError.
  • Supports max/min, finite upper bounds and non-trivial lower bounds (shifting), emitting an expanded dual over the explicit bound rows.
  • certificate_checkers.py — imports nothing from the solver; re-verifies check_primal, check_dual, check_farkas, check_unbounded_ray from raw data.
  • verify_solution.py — independent brute-force vertex enumeration + all property tests.

Run:

cd ~/simplex_solution
python3 verify_solution.py

Verification (actual output)

  • Klee–Minty n=8: optimal, objective matches brute force, 68 phase-II iterations (phase1=1).
  • Beale degenerate cube: Dantzig variant hits the iteration cap (cycles); Bland terminates in 7 phase-II iterations with a valid primal+dual certificate and correct objective 1/20.
  • 200 seeded random LPs: all objectives exactly equal brute-force vertex enumeration; all primal/dual certificates valid.
  • Extra stress (300 mixed LPs, negative RHS): 108 infeasible with valid Farkas certificates, 64 optimal, 116 unbounded with valid rays — 0 failures.
  • Malformed input: NaN, ±inf (in c, A, b, and bounds), dimension mismatch, singular basis, duplicate basis index — all raise the correct typed errors.
  • Redundant rows: duplicate/scaled constraints dropped, dual still valid.
  • Finite bounds: correct optimum and expanded dual certificate.
