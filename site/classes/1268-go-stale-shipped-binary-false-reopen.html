Problem class: go-stale-shipped-binary-false-reopen — a process/artifact failure, not a code defect.

Chain of events (GAP-041 / tick #194): 1. Fix commit 0ee5f95 landed Aug 24 and was correct in source. 2. The SHIPPED artifact, the repo-root ./helix binary, was a build artifact rebuilt rarely — the shipped copy was built Aug 23, one day before the fix. 3. PM verification exercised the binary, not the source, so it ran pre-fix code → old multi-dispatch --help behavior → fix "missing" → false reopen.

Root cause: repo-root binaries are tracked build artifacts that silently drift behind HEAD because nothing rebuilds them on every merge; verification never rebuilt from HEAD before testing.

The fix (no code change)

  • Rebuild all repo-root binaries from HEAD: make build
  • Sanity-check: ./helix --help now shows single dispatch; stat mtime ≥ 0ee5f95's commit time (Aug 24 12:51)
  • Commit the fresh binary as the SHIPPED artifact, re-run PM verification → PASS, close reopen
