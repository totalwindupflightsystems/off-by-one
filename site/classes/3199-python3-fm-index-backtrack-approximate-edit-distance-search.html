FM-index Approximate Edit-Distance Search — Diagnosis and Verified Solution

Problem class: python3-fm-index-backtrack-approximate-edit-distance-search Environment: Python 3.11+ (verified on CPython 3.14)

1. Problem statement

Implement approximate string matching over an FM-index: build the BWT and C table (plus Occ rank tables), run a backtracking search with up to k edits (mismatches, insertions, deletions), prune branches whose lower-bound edit distance exceeds k, and report all matching intervals + reconstruct positions from the suffix array without scanning the text. An occurrence is any T[start:end] with levenshtein(pattern, T[start:end]) <= k.

2. Root-cause analysis

The problem couples three components that are each easy to get subtly wrong:

2.1 Broken BWT / sentinel handling

  • BWT entry is T[SA[i]-1] and must use the sentinel when SA[i] == 0. Using T[-1] corrupts LF mapping.
  • Sentinel must be strictly smaller than every real symbol and appear once (map alphabet to 1..σ, sentinel 0).
  • C[c] = sum_{d<c} count(d), including the sentinel.

2.2 Wrong LF mapping / backward search

  • Correct extension: [C[c] + Occ(c, lo), C[c] + Occ(c, hi)). Off-by-one lo-1/hi-1 breaks everything.
  • Occ must be a prefix count over the BWT with Occ(c,0)=0.
  • A character absent from the text must return the empty interval (0,0), not raise.

2.3 Incomplete edit-distance backtracking

All three operations must be symmetric or matches are silently dropped:

Operation Consumes pattern Consumes text Cost
match / mismatch yes yes 0 / 1
insertion (pattern extra char) yes no 1
deletion (text extra char) no yes 1
  • Indels at the ends matter: trailing text chars via deletion before the first pattern char; leading text chars via deletion after i < 0. Stopping dead at i < 0 is a classic false-negative.
  • Deletions at i < 0 must respect the budget, else the recursion is unbounded.
  • Empty matched substring (tlen == 0) is not a valid occurrence.

2.4 Bad pruning

  • e (edits spent so far) is a valid lower bound on final edit distance, so prune as soon as e > k.
  • When e == k, no further edit is affordable → the remaining prefix must match exactly (single backward extension).

2.5 Wrong / duplicated reporting

  • Positions come from SA[lo:hi], never by scanning text.
  • Different strings can share one interval (e.g. "mis" and "miss" both [5,6) in "mississippi"), so the state carries tlen and records are keyed on (lo, hi, tlen).
  • Filter out the sentinel suffix.

2.6 Suffix-array construction

Prefix doubling must break ties with the second key and terminate only when all ranks are distinct.

3. Exact fix

Complete dependency-free implementation (fm_approx.py):

"""Approximate string matching over an FM-index."""
from __future__ import annotations
import sys
from typing import Dict, List, Optional, Sequence, Set, Tuple

__all__ = ["build_suffix_array", "FMIndex", "approximate_search",
           "approximate_intervals", "approximate_positions", "edit_distance"]
SENTINEL = 0


def build_suffix_array(seq: Sequence[int]) -> List[int]:
    n = len(seq)
    if n == 0:
        return []
    sa = list(range(n)); rank = list(seq); tmp = [0] * n; k = 1
    while True:
        sa.sort(key=lambda x: (rank[x], rank[x + k] if x + k < n else -1))
        tmp[sa[0]] = 0
        for i in range(1, n):
            a, b = sa[i - 1], sa[i]
            ra = (rank[a], rank[a + k] if a + k < n else -1)
            rb = (rank[b], rank[b + k] if b + k < n else -1)
            tmp[b] = tmp[a] + (ra != rb)
        rank = tmp[:]
        if rank[sa[-1]] == n - 1:
            break
        k <<= 1
    return sa


class FMIndex:
    def __init__(self, text: str):
        self.text = text
        self.chars = sorted(set(text))
        self._char_to_sym = {c: i + 1 for i, c in enumerate(self.chars)}
        self._sym_to_char = {i + 1: c for i, c in enumerate(self.chars)}
        self.num_symbols = len(self.chars) + 1
        self.seq = [self._char_to_sym[c] for c in text] + [SENTINEL]
        self.n = len(self.seq)
        self.sa = build_suffix_array(self.seq)
        self.bwt = [self.seq[self.sa[i] - 1] if self.sa[i] > 0 else SENTINEL
                    for i in range(self.n)]
        counts = [0] * self.num_symbols
        for s in self.seq:
            counts[s] += 1
        self.C = [0] * self.num_symbols
        running = 0
        for s in range(self.num_symbols):
            self.C[s] = running; running += counts[s]
        self.occ = [[0] * (self.n + 1) for _ in range(self.num_symbols)]
        for i, s in enumerate(self.bwt):
            for sym in range(self.num_symbols):
                self.occ[sym][i + 1] = self.occ[sym][i]
            self.occ[s][i + 1] += 1

    def backward_extend(self, lo: int, hi: int, ch: str) -> Tuple[int, int]:
        s = self._char_to_sym.get(ch)
        if s is None:
            return 0, 0
        c = self.C[s]
        return c + self.occ[s][lo], c + self.occ[s][hi]

    def locate(self, lo: int, hi: int) -> List[int]:
        return sorted(p for p in self.sa[lo:hi] if p < len(self.text))

    def exact_interval(self, pattern: str) -> Tuple[int, int]:
        lo, hi = 0, self.n
        for ch in reversed(pattern):
            lo, hi = self.backward_extend(lo, hi, ch)
            if lo >= hi:
                break
        return lo, hi

    def exact_positions(self, pattern: str) -> List[int]:
        lo, hi = self.exact_interval(pattern)
        return self.locate(lo, hi)


def approximate_search(text, pattern, k, index=None) -> List[Tuple[int, int]]:
    if k < 0:
        return []
    if index is None:
        index = FMIndex(text)
    alphabet = index.chars; text_len = len(text); m = len(pattern)
    results: Set[Tuple[int, int]] = set()
    seen: Set[Tuple[int, int, int, int, int]] = set()

    def rec(i, lo, hi, e, tlen):
        state = (i, lo, hi, e, tlen)
        if state in seen:
            return
        seen.add(state)
        if i < 0:
            if tlen > 0:
                for p in index.locate(lo, hi):
                    if p < text_len:
                        results.add((p, p + tlen))
            if e < k:                       # leading deletions
                for a in alphabet:
                    nlo, nhi = index.backward_extend(lo, hi, a)
                    if nlo < nhi:
                        rec(-1, nlo, nhi, e + 1, tlen + 1)
            return
        if e == k:                          # must match exactly
            nlo, nhi = index.backward_extend(lo, hi, pattern[i])
            if nlo < nhi:
                rec(i - 1, nlo, nhi, e, tlen + 1)
            return
        c = pattern[i]
        for a in alphabet:                  # match / substitution
            nlo, nhi = index.backward_extend(lo, hi, a)
            if nlo < nhi:
                ne = e + (0 if a == c else 1)
                if ne <= k:
                    rec(i - 1, nlo, nhi, ne, tlen + 1)
        if e < k:                           # deletion (text extra)
            for a in alphabet:
                nlo, nhi = index.backward_extend(lo, hi, a)
                if nlo < nhi:
                    rec(i, nlo, nhi, e + 1, tlen + 1)
            rec(i - 1, lo, hi, e + 1, tlen)  # insertion (pattern extra)

    rec(m - 1, 0, index.n, 0, 0)
    return sorted(results)


def approximate_intervals(text, pattern, k, index=None):
    if k < 0:
        return []
    if index is None:
        index = FMIndex(text)
    alphabet = index.chars; text_len = len(text); m = len(pattern)
    found: Set[Tuple[int, int, int]] = set()
    seen: Set[Tuple[int, int, int, int, int]] = set()

    def rec(i, lo, hi, e, tlen):
        state = (i, lo, hi, e, tlen)
        if state in seen:
            return
        seen.add(state)
        if i < 0:
            if tlen > 0 and any(p < text_len for p in index.sa[lo:hi]):
                found.add((lo, hi, tlen))
            if e < k:
                for a in alphabet:
                    nlo, nhi = index.backward_extend(lo, hi, a)
                    if nlo < nhi:
                        rec(-1, nlo, nhi, e + 1, tlen + 1)
            return
        if e == k:
            nlo, nhi = index.backward_extend(lo, hi, pattern[i])
            if nlo < nhi:
                rec(i - 1, nlo, nhi, e, tlen + 1)
            return
        c = pattern[i]
        for a in alphabet:
            nlo, nhi = index.backward_extend(lo, hi, a)
            if nlo < nhi:
                ne = e + (0 if a == c else 1)
                if ne <= k:
                    rec(i - 1, nlo, nhi, ne, tlen + 1)
        if e < k:
            for a in alphabet:
                nlo, nhi = index.backward_extend(lo, hi, a)
                if nlo < nhi:
                    rec(i, nlo, nhi, e + 1, tlen + 1)
            rec(i - 1, lo, hi, e + 1, tlen)

    rec(m - 1, 0, index.n, 0, 0)
    out = []
    for lo, hi, tlen in sorted(found, key=lambda r: (r[2], r[0])):
        positions = [p for p in index.sa[lo:hi] if p < text_len]
        out.append((lo, hi, tlen, sorted(positions)))
    return out


def approximate_positions(text, pattern, k, index=None) -> List[int]:
    return sorted({s for s, _ in approximate_search(text, pattern, k, index)})


def edit_distance(a: str, b: str) -> int:
    la, lb = len(a), len(b)
    prev = list(range(lb + 1))
    for i in range(1, la + 1):
        cur = [i] + [0] * lb
        ai = a[i - 1]
        for j in range(1, lb + 1):
            cost = 0 if ai == b[j - 1] else 1
            cur[j] = min(prev[j] + 1, cur[j - 1] + 1, prev[j - 1] + cost)
        prev = cur
    return prev[lb]


def brute_force_matches(text: str, pattern: str, k: int) -> List[Tuple[int, int]]:
    m = len(pattern); out: Set[Tuple[int, int]] = set(); n = len(text)
    for p in range(n):
        max_len = min(n - p, m + k)
        for length in range(1, max_len + 1):
            if edit_distance(pattern, text[p:p + length]) <= k:
                out.add((p, p + length))
    return sorted(out)

    import argparse

5. Fix summary

Root cause Fix
Sentinel / BWT wrong symbol 0 sentinel, BWT[i]=seq[SA[i]-1], SA[i]==0 → 0
C / Occ wrong C[s]=#{d<s}, Occ[s][i]=#{s in bwt[:i]}
LF mapping wrong (C[c]+Occ(c,lo), C[c]+Occ(c,hi))
Missing indels explicit insertion + deletion branches incl. both ends
Bad pruning prune e>k; exact-only shortcut at e==k
Duplicate/lost matches (i,lo,hi,e,tlen) state + seen memo + (lo,hi,tlen) records
Text scanning positions from SA[lo:hi], sentinel filtered
Infinite recursion every edge increases e or decreases i; e ≤ k
