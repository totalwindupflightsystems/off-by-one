Pattern gate — only NEVER-DONE fixture pending ⇒ audit tick (no worker):

def audit_tick_required(con):
    pending = pending_fixtures(con)                 # status NOT IN ('DONE','SKIPPED')
    if not pending: return False
    if any(f["status"] != "NEVER-DONE" for f in pending): return False
    if any(f.get("worker") for f in pending): return False
    return True

Board write — explicit event id MAX+1, naive UTC, display-name project match:

def next_event_id(con):
    return int(con.execute("SELECT COALESCE(MAX(event_id), 0) FROM events").fetchone()[0]) + 1

def naive_utc_now():                                # timezone-naive, Z-suffixed
    return datetime.now(timezone.utc).replace(tzinfo=None).strftime("%Y-%m-%dT%H:%M:%SZ")

def board_write(con, fixture):
    eid, now = next_event_id(con), naive_utc_now()
    if fixture["display_name"] != fixture["project_display_name"]:
        raise AuditTickError("display-name project match violated: ...")
    con.execute("INSERT INTO events (event_id, event_type, display_name, timestamp, payload) "
                "VALUES (?, 'fixture.audit', ?, ?, ?)", (eid, fixture["display_name"], now, payload))
    con.execute("UPDATE board SET status='AUDITED', updated_at=? WHERE display_name=?", (now, ...))
    con.commit(); return eid, now

JSONL mirror via COPY — not parquet (INFRA-013), stray parquet removed: copy_to_jsonl() does a row-for-row COPY of board/events into board.jsonl/events.jsonl (one JSON per line); remove_stray_parquet() deletes every *.parquet; the pipeline asserts zero parquet files afterward, and .gitignore pins *.parquet + board.db.

git stages: gitreins_guard() runs git fsck --no-dangling, rejects tracked parquet and any dirty path outside {board.jsonl, events.jsonl, .gitignore} (pre- and post-commit); commit_board() stages only those three explicit paths; update_phase2_last_commit() writes git HEAD into board.db meta; push() falls back to push -u origin HEAD when no upstream exists.

Scheduler — never PUT: scheduler_pin_check() reads fleet.toml [scheduler] and requires cooldown == 7200 and decay_rate == 1 exactly; scheduler_never_put() raises on any PUT verb (the pin in fleet.toml is the source of truth; the tick only GETs).
