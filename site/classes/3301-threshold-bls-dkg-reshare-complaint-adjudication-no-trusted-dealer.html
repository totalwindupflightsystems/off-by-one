Threshold BLS DKG / Reshare: Complaint Adjudication Without a Trusted Dealer

Environment: Go 1.26, github.com/cloudflare/circl v1.6.5 (BLS12-381 pairings)

Working module: ~/reshare Verification: go vet ./... clean; go test -race ./... passes all 11 scenario tests.

1. Root-cause analysis

The problem class is not “write a VSS”; it is the set of failure modes that appear when naive GJKR/Pedersen DKG is extended to proactive resharing. Each is a distinct root cause:

# Symptom in a naive implementation Root cause
1 Reshare asks an old committee member to “reconstruct then re-deal”, or uses a trusted dealer The secret is materialized. Fix: each old member deals a degree-t_new−1 polynomial whose constant term is its old share, never f(0).
2 New shares sum old shares: g(0)=Σ f(i), so PK changes Missing Lagrange weights. f(0)=Σ λ_i f(i) only for λ_i over a qualified set. Weights must be applied after the qualified set is known.
3 Byzantine dealer shows different commitment vectors/boxes to different receivers No transcript binding. Fix: a broadcast digest over (dealer, commitments, boxes); every receiver and every complaint is checked against it.
4 Complaints contain the disputed share in cleartext (classic GJKR dispute rule) A share is itself secret material; enough leaked shares reconstruct a dealer polynomial or the epoch secret.
5 Malicious receiver files a false complaint and gets an honest dealer disqualified Complaint is unfalsifiable if it is just “I got a bad value”. Fix: the dealer must commit to the exact transmitted value with a Pedersen box; a complaint must prove knowledge of an opening of that box. Pedersen binding makes framing impossible.
6 Reshare aborts or breaks when old/new overlap is only t Confusing overlap with dealer participation. Every active old member deals to every new member; overlap only affects which nodes already hold an old share. As long as #active_old ≥ t_old, interpolation works.
7 One delinquent receiver/old member stalls the epoch Finalization must be QUAL-set based. Exclude missing/non-qualified dealers and require only ≥ t qualified contributions.
8 “Proof” that the resharing preserved the secret is missing or can be forged Recompute the Lagrange combination of public commitments and check C'_0 == PK_old; bind each member's public share with a pairing attestation.

The key cryptographic insight for #4/#5

Give every (dealer i, receiver j) a public Pedersen box

Box_{i,j} = y_{i,j}·G + r_{i,j}·H        (H = hash-to-curve, dlog_G H unknown)

and send (y_{i,j}, r_{i,j}) privately. A complaint publishes only:

Y = y·G,   π_y : knowledge of y with Y = yG,   π_r : knowledge of r with Box−Y = rH
  • Sound: the two proofs prove knowledge of an opening (y,r) of the dealer's fixed box. Pedersen binding forces y to be the unique value the dealer committed to.
  • No framing: a false complainant cannot produce π_r for Box−Y unless it can solve dlog_G H.
  • No leak: no scalar share appears in the evidence; Y is a group element and both Schnorr proofs are zero-knowledge.

Adjudication is then public and deterministic: if Y == p_i(j)·G the complaint is rejected; otherwise the dealer is disqualified.

// Package reshare implements a non-interactive (no trusted dealer)
// Pedersen/GJKR-style distributed key generation and proactive resharing
// protocol over BLS12-381.
package reshare

import (
    "crypto/rand"
    "crypto/sha256"
    "encoding/binary"
    "errors"
    "fmt"
    "sort"

    "github.com/cloudflare/circl/ecc/bls12381"
)

type (
    Scalar = bls12381.Scalar
    G1     = bls12381.G1
    G2     = bls12381.G2
)

type ID int

var ErrThreshold = errors.New("reshare: threshold must satisfy 1 <= t <= n")

func scalarOf(i ID) *Scalar {
    if i < 1 {
        panic("reshare: ID must be >= 1")
    }
    s := new(Scalar)
    s.SetUint64(uint64(i))
    return s
}

func randomScalar() (*Scalar, error) {
    s := new(Scalar)
    if err := s.Random(rand.Reader); err != nil {
        return nil, err
    }
    return s, nil
}

func hashToScalar(domain string, parts ...[]byte) *Scalar {
    for ctr := uint32(0); ; ctr++ {
        h := sha256.New()
        writeLP(h, []byte(domain))
        for _, p := range parts {
            writeLP(h, p)
        }
        var cb [4]byte
        binary.BigEndian.PutUint32(cb[:], ctr)
        h.Write(cb[:])
        s := new(Scalar)
        s.SetBytes(h.Sum(nil))
        if s.IsZero() == 0 {
            return s
        }
    }
}

func writeLP(h interface{ Write([]byte) (int, error) }, b []byte) {
    var l [4]byte
    binary.BigEndian.PutUint32(l[:], uint32(len(b)))
    h.Write(l[:])
    h.Write(b)
}

func mulG1(s *Scalar) *G1 {
    p := new(G1)
    p.ScalarMult(s, bls12381.G1Generator())
    return p
}

// hGenerator is a second G1 generator with unknown discrete log w.r.t. the
// standard generator, obtained by hash-to-curve. Pedersen binding relies on
// nobody knowing dlog_G(H).
var hGenerator = func() *G1 {
    h := new(G1)
    h.Hash([]byte("reshare/independent-pedersen-generator"), []byte("reshare-pedersen-v1"))
    return h
}()

func pedersenCommit(y, r *Scalar) *G1 {
    return add(mulG1(y), mul(hGenerator, r))
}

func mul(p *G1, s *Scalar) *G1 {
    r := new(G1)
    r.ScalarMult(s, p)
    return r
}

func add(a, b *G1) *G1 {
    r := new(G1)
    r.Add(a, b)
    return r
}

func neg(a *G1) *G1 {
    r := new(G1)
    *r = *a
    r.Neg()
    return r
}

type Polynomial struct {
    coeffs []*Scalar
}

func NewPolynomial(t int, constant *Scalar) (*Polynomial, error) {
    if t < 1 {
        return nil, ErrThreshold
    }
    cs := make([]*Scalar, t)
    cs[0] = new(Scalar)
    if constant != nil {
        cs[0].Set(constant)
    } else {
        c, err := randomScalar()
        if err != nil {
            return nil, err
        }
        cs[0].Set(c)
    }
    for k := 1; k < t; k++ {
        c, err := randomScalar()
        if err != nil {
            return nil, err
        }
        cs[k] = c
    }
    return &Polynomial{coeffs: cs}, nil
}

func (p *Polynomial) Degree() int { return len(p.coeffs) - 1 }

func (p *Polynomial) Eval(x *Scalar) *Scalar {
    res := new(Scalar)
    res.Set(p.coeffs[len(p.coeffs)-1])
    for k := len(p.coeffs) - 2; k >= 0; k-- {
        res.Mul(res, x)
        res.Add(res, p.coeffs[k])
    }
    return res
}

func (p *Polynomial) Constant() *Scalar {
    c := new(Scalar)
    c.Set(p.coeffs[0])
    return c
}

func (p *Polynomial) Commitments() []*G1 {
    comms := make([]*G1, len(p.coeffs))
    for k, c := range p.coeffs {
        comms[k] = mulG1(c)
    }
    return comms
}

// EvalCommitments returns sum_k C_k * x^k = p(x)*G1 without the coefficients.
func EvalCommitments(comms []*G1, x *Scalar) *G1 {
    res := new(G1)
    res.SetIdentity()
    for k := len(comms) - 1; k >= 0; k-- {
        res = add(mul(res, x), comms[k])
    }
    return res
}

func VerifyShare(comms []*G1, x *Scalar, share *Scalar) bool {
    return mulG1(share).IsEqual(EvalCommitments(comms, x))
}

// commitmentDigest binds a dealer to one commitment vector and one set of
// per-receiver Pedersen boxes, so it cannot equivocate.
func commitmentDigest(dealer ID, comms []*G1, boxes map[ID]*G1) [32]byte {
    h := sha256.New()
    writeLP(h, []byte("reshare/commit/v2"))
    var b [8]byte
    binary.BigEndian.PutUint64(b[:], uint64(dealer))
    h.Write(b[:])
    var tb [4]byte
    binary.BigEndian.PutUint32(tb[:], uint32(len(comms)))
    h.Write(tb[:])
    for _, c := range comms {
        h.Write(c.BytesCompressed())
    }
    keys := make([]ID, 0, len(boxes))
    for id := range boxes {
        keys = append(keys, id)
    }
    sort.Slice(keys, func(i, j int) bool { return keys[i] < keys[j] })
    binary.BigEndian.PutUint32(tb[:], uint32(len(keys)))
    h.Write(tb[:])
    for _, id := range keys {
        binary.BigEndian.PutUint64(b[:], uint64(id))
        h.Write(b[:])
        h.Write(boxes[id].BytesCompressed())
    }
    var out [32]byte
    copy(out[:], h.Sum(nil))
    return out
}

type DLogProof struct {
    R *G1
    Z *Scalar
}

func ProveDLog(secret *Scalar, base *G1, ctx []byte) (*DLogProof, error) {
    r, err := randomScalar()
    if err != nil {
        return nil, err
    }
    Y := mul(base, secret)
    R := mul(base, r)
    c := hashToScalar("reshare/dlog", ctx, Y.BytesCompressed(), R.BytesCompressed())
    z := new(Scalar)
    z.Mul(c, secret)
    z.Add(z, r)
    return &DLogProof{R: R, Z: z}, nil
}

func VerifyDLog(p *DLogProof, Y *G1, base *G1, ctx []byte) bool {
    if p == nil || p.R == nil || p.Z == nil {
        return false
    }
    c := hashToScalar("reshare/dlog", ctx, Y.BytesCompressed(), p.R.BytesCompressed())
    lhs := mul(base, p.Z)
    rhs := add(p.R, mul(Y, c))
    return lhs.IsEqual(rhs)
}

func LagrangeAtZero(ids []ID) (map[ID]*Scalar, error) {
    if len(ids) == 0 {
        return nil, errors.New("reshare: empty interpolation set")
    }
    seen := map[ID]bool{}
    out := make(map[ID]*Scalar, len(ids))
    for _, i := range ids {
        if i < 1 || seen[i] {
            return nil, fmt.Errorf("reshare: invalid/duplicate id %d", i)
        }
        seen[i] = true
        xi := scalarOf(i)
        num := new(Scalar)
        num.SetOne()
        den := new(Scalar)
        den.SetOne()
        for _, m := range ids {
            if m == i {
                continue
            }
            xm := scalarOf(m)
            t := new(Scalar)
            t.Set(xm)
            t.Neg()
            num.Mul(num, t)
            t = new(Scalar)
            t.Sub(xi, xm)
            den.Mul(den, t)
        }
        den.Inv(den)
        lam := new(Scalar)
        lam.Mul(num, den)
        out[i] = lam
    }
    return out, nil
}

func SignBLS(secret *Scalar, msg []byte) *G1 {
    h := new(G1)
    h.Hash(msg, []byte("BLS_SIG_BLS12381G1_XMD:SHA-256_SSWU_RO_NUL_"))
    return mul(h, secret)
}

func VerifyBLS(pk *G1, pkG2 *G2, msg []byte, sigma *G1) bool {
    if pk == nil || pkG2 == nil || sigma == nil {
        return false
    }
    h := new(G1)
    h.Hash(msg, []byte("BLS_SIG_BLS12381G1_XMD:SHA-256_SSWU_RO_NUL_"))
    g2 := bls12381.G2Generator()
    if !bls12381.Pair(pk, g2).IsEqual(bls12381.Pair(bls12381.G1Generator(), pkG2)) {
        return false
    }
    return bls12381.Pair(sigma, g2).IsEqual(bls12381.Pair(h, pkG2))
}

dkg.go

package reshare

import (
    "errors"
    "fmt"
    "sort"

    "github.com/cloudflare/circl/ecc/bls12381"
)

type Roster struct {
    IDs       []ID
    Threshold int
    Epoch     uint64
}

func (r Roster) Validate() error {
    if r.Threshold < 1 || r.Threshold > len(r.IDs) {
        return ErrThreshold
    }
    seen := map[ID]bool{}
    for _, id := range r.IDs {
        if id < 1 {
            return fmt.Errorf("reshare: invalid id %d", id)
        }
        if seen[id] {
            return fmt.Errorf("reshare: duplicate id %d", id)
        }
        seen[id] = true
    }
    return nil
}

func (r Roster) SortedIDs() []ID {
    out := append([]ID(nil), r.IDs...)
    sort.Slice(out, func(i, j int) bool { return out[i] < out[j] })
    return out
}

func (r Roster) has(id ID) bool {
    for _, x := range r.IDs {
        if x == id {
            return true
        }
    }
    return false
}

// DealerShare is the private opening of a dealer's Pedersen box for one
// receiver.
type DealerShare struct {
    Value    *Scalar
    Blinding *Scalar
}

func (s *DealerShare) valid() bool {
    return s != nil && s.Value != nil && s.Blinding != nil
}

func copyShare(s *DealerShare) *DealerShare {
    if s == nil {
        return nil
    }
    out := &DealerShare{}
    if s.Value != nil {
        out.Value = new(Scalar)
        out.Value.Set(s.Value)
    }
    if s.Blinding != nil {
        out.Blinding = new(Scalar)
        out.Blinding.Set(s.Blinding)
    }
    return out
}

type Announcement struct {
    Dealer      ID
    Threshold   int
    Commitments []*G1
    Boxes       map[ID]*G1
    Digest      [32]byte
}

func NewAnnouncement(dealer ID, threshold int, comms []*G1, boxes map[ID]*G1) *Announcement {
    if boxes == nil {
        boxes = map[ID]*G1{}
    }
    return &Announcement{
        Dealer:      dealer,
        Threshold:   threshold,
        Commitments: comms,
        Boxes:       boxes,
        Digest:      commitmentDigest(dealer, comms, boxes),
    }
}

func (a *Announcement) Validate(expectedThreshold int) error {
    if a == nil || a.Dealer < 1 {
        return errors.New("reshare: nil/invalid announcement")
    }
    if a.Threshold != expectedThreshold {
        return fmt.Errorf("reshare: dealer %d threshold %d != %d", a.Dealer, a.Threshold, expectedThreshold)
    }
    if len(a.Commitments) != a.Threshold {
        return fmt.Errorf("reshare: dealer %d has %d commitments for t=%d", a.Dealer, len(a.Commitments), a.Threshold)
    }
    if commitmentDigest(a.Dealer, a.Commitments, a.Boxes) != a.Digest {
        return fmt.Errorf("reshare: dealer %d transcript digest mismatch", a.Dealer)
    }
    for k, c := range a.Commitments {
        if c == nil || !c.IsOnG1() {
            return fmt.Errorf("reshare: dealer %d commitment %d is not in G1", a.Dealer, k)
        }
    }
    for id, box := range a.Boxes {
        if id < 1 || box == nil || !box.IsOnG1() {
            return fmt.Errorf("reshare: dealer %d has an invalid box for %d", a.Dealer, id)
        }
    }
    return nil
}

func (a *Announcement) BoxFor(receiver ID) *G1 {
    if a == nil {
        return nil
    }
    return a.Boxes[receiver]
}

// Complaint reveals only a G1 point and two Schnorr proofs, never a scalar.
type Complaint struct {
    Dealer          ID
    Receiver        ID
    Digest          [32]byte
    ShareCommitment *G1
    ValueProof      *DLogProof
    BlindingProof   *DLogProof
}

func complaintContext(domain string, epoch uint64, dealer, receiver ID, digest [32]byte) []byte {
    ctx := make([]byte, 0, len(domain)+8+8+8+32+8)
    ctx = append(ctx, []byte(domain)...)
    ctx = appendU64(ctx, epoch)
    ctx = appendU64(ctx, uint64(dealer))
    ctx = appendU64(ctx, uint64(receiver))
    ctx = append(ctx, digest[:]...)
    return ctx
}

func appendU64(b []byte, v uint64) []byte {
    return append(b, byte(v>>56), byte(v>>48), byte(v>>40), byte(v>>32),
        byte(v>>24), byte(v>>16), byte(v>>8), byte(v))
}

func NewComplaint(epoch uint64, ann *Announcement, receiver ID, s *DealerShare) (*Complaint, error) {
    if ann == nil {
        return nil, errors.New("reshare: nil announcement")
    }
    box := ann.BoxFor(receiver)
    if box == nil {
        return nil, fmt.Errorf("reshare: dealer %d has no box for %d", ann.Dealer, receiver)
    }
    if !s.valid() {
        return nil, errors.New("reshare: incomplete share opening")
    }
    ctxV := complaintContext("reshare/complaint/value", epoch, ann.Dealer, receiver, ann.Digest)
    vp, err := ProveDLog(s.Value, bls12381.G1Generator(), ctxV)
    if err != nil {
        return nil, err
    }
    ctxB := complaintContext("reshare/complaint/blinding", epoch, ann.Dealer, receiver, ann.Digest)
    bp, err := ProveDLog(s.Blinding, hGenerator, ctxB)
    if err != nil {
        return nil, err
    }
    return &Complaint{
        Dealer:          ann.Dealer,
        Receiver:        receiver,
        Digest:          ann.Digest,
        ShareCommitment: mulG1(s.Value),
        ValueProof:      vp,
        BlindingProof:   bp,
    }, nil
}

type Verdict struct {
    Qualified    []ID
    Disqualified []ID
    Upheld       []Complaint
    Rejected     []Complaint
}

func VerifyDealerShare(ann *Announcement, receiver ID, s *DealerShare) bool {
    if ann == nil || !s.valid() {
        return false
    }
    box := ann.BoxFor(receiver)
    if box == nil {
        return false
    }
    if !VerifyShare(ann.Commitments, scalarOf(receiver), s.Value) {
        return false
    }
    return box.IsEqual(pedersenCommit(s.Value, s.Blinding))
}

func Adjudicate(roster Roster, anns map[ID]*Announcement, complaints []Complaint) Verdict {
    receivers := map[ID]bool{}
    for _, id := range roster.IDs {
        receivers[id] = true
    }
    return adjudicate(roster.Epoch, roster.Threshold, roster.SortedIDs(), receivers, anns, complaints)
}

func adjudicate(epoch uint64, threshold int, dealerIDs []ID, receivers map[ID]bool, anns map[ID]*Announcement, complaints []Complaint) Verdict {
    eligible := map[ID]bool{}
    for _, id := range dealerIDs {
        a := anns[id]
        if a == nil {
            continue
        }
        if a.Validate(threshold) != nil {
            continue
        }
        eligible[id] = true
    }

    bad := map[ID]bool{}
    var v Verdict
    for _, c := range complaints {
        a := anns[c.Dealer]
        if a == nil || !eligible[c.Dealer] || !receivers[c.Receiver] {
            v.Rejected = append(v.Rejected, c)
            continue
        }
        if c.Digest != a.Digest {
            v.Rejected = append(v.Rejected, c)
            continue
        }
        box := a.BoxFor(c.Receiver)
        if box == nil || c.ShareCommitment == nil || !c.ShareCommitment.IsOnG1() {
            v.Rejected = append(v.Rejected, c)
            continue
        }
        ctxV := complaintContext("reshare/complaint/value", epoch, c.Dealer, c.Receiver, c.Digest)
        if !VerifyDLog(c.ValueProof, c.ShareCommitment, bls12381.G1Generator(), ctxV) {
            v.Rejected = append(v.Rejected, c)
            continue
        }
        ctxB := complaintContext("reshare/complaint/blinding", epoch, c.Dealer, c.Receiver, c.Digest)
        boxMinusY := add(box, neg(c.ShareCommitment))
        if !VerifyDLog(c.BlindingProof, boxMinusY, hGenerator, ctxB) {
            v.Rejected = append(v.Rejected, c)
            continue
        }
        want := EvalCommitments(a.Commitments, scalarOf(c.Receiver))
        if c.ShareCommitment.IsEqual(want) {
            v.Rejected = append(v.Rejected, c)
            continue
        }
        bad[c.Dealer] = true
        v.Upheld = append(v.Upheld, c)
    }

    sorted := append([]ID(nil), dealerIDs...)
    sort.Slice(sorted, func(i, j int) bool { return sorted[i] < sorted[j] })
    for _, id := range sorted {
        if eligible[id] && !bad[id] {
            v.Qualified = append(v.Qualified, id)
        } else {
            v.Disqualified = append(v.Disqualified, id)
        }
    }
    return v
}

type Dealer struct {
    ID   ID
    Poly *Polynomial
}

func NewDealer(id ID, threshold int) (*Dealer, error) {
    p, err := NewPolynomial(threshold, nil)
    if err != nil {
        return nil, err
    }
    return &Dealer{ID: id, Poly: p}, nil
}

// NewReshareDealer fixes the constant term to the dealer's old share. This is
// the no-trusted-dealer, no-reconstruction reshare primitive.
func NewReshareDealer(id ID, oldShare *Scalar, threshold int) (*Dealer, error) {
    p, err := NewPolynomial(threshold, oldShare)
    if err != nil {
        return nil, err
    }
    return &Dealer{ID: id, Poly: p}, nil
}

func (d *Dealer) Deal(receivers []ID, threshold int) (*Announcement, map[ID]*DealerShare, error) {
    comms := d.Poly.Commitments()
    boxes := make(map[ID]*G1, len(receivers))
    shares := make(map[ID]*DealerShare, len(receivers))
    for _, j := range receivers {
        y := d.Poly.Eval(scalarOf(j))
        r, err := randomScalar()
        if err != nil {
            return nil, nil, err
        }
        boxes[j] = pedersenCommit(y, r)
        shares[j] = &DealerShare{Value: y, Blinding: r}
    }
    return NewAnnouncement(d.ID, threshold, comms, boxes), shares, nil
}

func (d *Dealer) ShareFor(receiver ID) *Scalar {
    return d.Poly.Eval(scalarOf(receiver))
}

type DKGResult struct {
    Roster        Roster
    Verdict       Verdict
    Commitments   []*G1
    PublicKey     *G1
    Shares        map[ID]*Scalar
    PublicShares  map[ID]*G1
    Announcements map[ID]*Announcement
}

func FinalizeFresh(roster Roster, anns map[ID]*Announcement, dealerShares map[ID]map[ID]*DealerShare, qualified []ID) (*DKGResult, error) {
    if len(qualified) < roster.Threshold {
        return nil, fmt.Errorf("reshare: only %d qualified dealers, need %d", len(qualified), roster.Threshold)
    }
    t := roster.Threshold
    comms := make([]*G1, t)
    for k := 0; k < t; k++ {
        comms[k] = new(G1)
        comms[k].SetIdentity()
    }
    for _, d := range qualified {
        a := anns[d]
        if a == nil || len(a.Commitments) != t {
            return nil, fmt.Errorf("reshare: missing commitments for dealer %d", d)
        }
        for k := 0; k < t; k++ {
            comms[k] = add(comms[k], a.Commitments[k])
        }
    }
    shares := map[ID]*Scalar{}
    public := map[ID]*G1{}
    for _, j := range roster.IDs {
        s := new(Scalar)
        s.SetUint64(0)
        for _, d := range qualified {
            ds := dealerShares[d][j]
            if !ds.valid() {
                return nil, fmt.Errorf("reshare: dealer %d missing share for %d", d, j)
            }
            s.Add(s, ds.Value)
        }
        shares[j] = s
        public[j] = mulG1(s)
        if !VerifyShare(comms, scalarOf(j), s) {
            return nil, fmt.Errorf("reshare: final share of %d fails Feldman check", j)
        }
    }
    return &DKGResult{
        Roster:        roster,
        Commitments:   comms,
        PublicKey:     comms[0],
        Shares:        shares,
        PublicShares:  public,
        Announcements: anns,
    }, nil
}

func RunDKG(roster Roster) (*DKGResult, error) {
    if err := roster.Validate(); err != nil {
        return nil, err
    }
    dealerShares := map[ID]map[ID]*DealerShare{}
    anns := map[ID]*Announcement{}
    for _, d := range roster.IDs {
        dealer, err := NewDealer(d, roster.Threshold)
        if err != nil {
            return nil, err
        }
        ann, shares, err := dealer.Deal(roster.IDs, roster.Threshold)
        if err != nil {
            return nil, err
        }
        anns[d] = ann
        dealerShares[d] = shares
    }
    res, err := FinalizeFresh(roster, anns, dealerShares, roster.SortedIDs())
    if err != nil {
        return nil, err
    }
    res.Verdict = Verdict{Qualified: roster.SortedIDs()}
    return res, nil
}

// ConsistencyProof is the public proof that the new sharing is the
// Lagrange-weighted combination of the qualified old dealers and commits to
// the same epoch secret.
type ConsistencyProof struct {
    Epoch           uint64
    OldThreshold    int
    NewThreshold    int
    OldPublicKey    *G1
    NewPublicKey    *G1
    QualifiedOld    []ID
    Announced       map[ID]*Announcement
    NewCommitments  []*G1
    NewPublicShares map[ID]*G1
}

func (p *ConsistencyProof) Verify() error {
    if p == nil {
        return errors.New("reshare: nil consistency proof")
    }
    if p.OldPublicKey == nil || p.NewPublicKey == nil {
        return errors.New("reshare: missing public key in proof")
    }
    if len(p.QualifiedOld) < p.OldThreshold {
        return fmt.Errorf("reshare: proof has %d qualified old dealers, need %d", len(p.QualifiedOld), p.OldThreshold)
    }
    if p.NewThreshold != len(p.NewCommitments) {
        return errors.New("reshare: proof commitment length != new threshold")
    }
    lam, err := LagrangeAtZero(p.QualifiedOld)
    if err != nil {
        return err
    }

    recomputed := make([]*G1, p.NewThreshold)
    for k := 0; k < p.NewThreshold; k++ {
        recomputed[k] = new(G1)
        recomputed[k].SetIdentity()
    }
    for _, i := range p.QualifiedOld {
        a := p.Announced[i]
        if a == nil {
            return fmt.Errorf("reshare: proof missing announcement for %d", i)
        }
        if err := a.Validate(p.NewThreshold); err != nil {
            return err
        }
        for k := 0; k < p.NewThreshold; k++ {
            recomputed[k] = add(recomputed[k], mul(a.Commitments[k], lam[i]))
        }
    }
    for k := 0; k < p.NewThreshold; k++ {
        if !recomputed[k].IsEqual(p.NewCommitments[k]) {
            return fmt.Errorf("reshare: recomputed commitment %d differs", k)
        }
    }
    if !recomputed[0].IsEqual(p.NewPublicKey) {
        return errors.New("reshare: new public key != new commitment constant")
    }
    if !p.OldPublicKey.IsEqual(p.NewPublicKey) {
        return errors.New("reshare: epoch public key changed (secret not preserved)")
    }
    for id, Y := range p.NewPublicShares {
        if Y == nil || !Y.IsOnG1() {
            return fmt.Errorf("reshare: bad public share for %d", id)
        }
        want := EvalCommitments(p.NewCommitments, scalarOf(id))
        if !Y.IsEqual(want) {
            return fmt.Errorf("reshare: public share of %d inconsistent with new commitments", id)
        }
    }
    return nil
}

type ReshareResult struct {
    OldRoster    Roster
    NewRoster    Roster
    Verdict      Verdict
    QualifiedOld []ID
    Lagrange     map[ID]*Scalar
    Commitments  []*G1
    PublicKey    *G1
    Shares       map[ID]*Scalar
    PublicShares map[ID]*G1
    Proof        *ConsistencyProof
}

type ReshareOptions struct {
    ActiveOld      []ID
    Complaints     []Complaint
    FileComplaints bool
    Tamper         func(dealer, receiver ID, share *DealerShare) *DealerShare
}

func RunReshare(old *DKGResult, newRoster Roster, opts ReshareOptions) (*ReshareResult, error) {
    if old == nil {
        return nil, errors.New("reshare: nil old epoch")
    }
    if err := newRoster.Validate(); err != nil {
        return nil, err
    }
    active := opts.ActiveOld
    if active == nil {
        active = old.Roster.SortedIDs()
    }
    active = append([]ID(nil), active...)
    sort.Slice(active, func(i, j int) bool { return active[i] < active[j] })
    for _, id := range active {
        if !old.Roster.has(id) {
            return nil, fmt.Errorf("reshare: active old member %d not in old roster", id)
        }
    }

    // 1. Each active old member deals a polynomial whose constant is its old
    //    share. The secret is never reconstructed.
    dealerShares := map[ID]map[ID]*DealerShare{}
    anns := map[ID]*Announcement{}
    for _, i := range active {
        share := old.Shares[i]
        if share == nil {
            return nil, fmt.Errorf("reshare: old member %d has no share", i)
        }
        d, err := NewReshareDealer(i, share, newRoster.Threshold)
        if err != nil {
            return nil, err
        }
        ann, shares, err := d.Deal(newRoster.IDs, newRoster.Threshold)
        if err != nil {
            return nil, err
        }
        if opts.Tamper != nil {
            for _, j := range newRoster.IDs {
                tampered := opts.Tamper(i, j, shares[j])
                if tampered != nil && tampered.valid() {
                    shares[j] = tampered
                    ann.Boxes[j] = pedersenCommit(tampered.Value, tampered.Blinding)
                }
            }
            ann.Digest = commitmentDigest(ann.Dealer, ann.Commitments, ann.Boxes)
        }
        anns[i] = ann
        dealerShares[i] = shares
    }

    // 2. Pairwise Feldman + box verification by every new member.
    complaints := append([]Complaint(nil), opts.Complaints...)
    if opts.FileComplaints {
        for _, i := range active {
            a := anns[i]
            for _, j := range newRoster.SortedIDs() {
                s := dealerShares[i][j]
                if !VerifyDealerShare(a, j, s) {
                    c, err := NewComplaint(newRoster.Epoch, a, j, s)
                    if err != nil {
                        return nil, err
                    }
                    complaints = append(complaints, *c)
                }
            }
        }
    }

    // 3. Public adjudication.
    receivers := map[ID]bool{}
    for _, j := range newRoster.IDs {
        receivers[j] = true
    }
    verdict := adjudicate(newRoster.Epoch, newRoster.Threshold, active, receivers, anns, complaints)
    if len(verdict.Qualified) < old.Roster.Threshold {
        return nil, fmt.Errorf("reshare: %d qualified old dealers, need %d", len(verdict.Qualified), old.Roster.Threshold)
    }

    // 4. Lagrange combination over the qualified old dealers.
    lam, err := LagrangeAtZero(verdict.Qualified)
    if err != nil {
        return nil, err
    }
    tNew := newRoster.Threshold
    comms := make([]*G1, tNew)
    for k := 0; k < tNew; k++ {
        comms[k] = new(G1)
        comms[k].SetIdentity()
    }
    for _, i := range verdict.Qualified {
        for k := 0; k < tNew; k++ {
            comms[k] = add(comms[k], mul(anns[i].Commitments[k], lam[i]))
        }
    }
    if !comms[0].IsEqual(old.PublicKey) {
        return nil, errors.New("reshare: new public key does not match old public key")
    }

    shares := map[ID]*Scalar{}
    public := map[ID]*G1{}
    for _, j := range newRoster.IDs {
        s := new(Scalar)
        s.SetUint64(0)
        for _, i := range verdict.Qualified {
            ds := dealerShares[i][j]
            if !ds.valid() {
                return nil, fmt.Errorf("reshare: dealer %d missing share for %d", i, j)
            }
            s.Add(s, mulScalar(lam[i], ds.Value))
        }
        if !VerifyShare(comms, scalarOf(j), s) {
            return nil, fmt.Errorf("reshare: new share of %d fails Feldman check", j)
        }
        shares[j] = s
        public[j] = mulG1(s)
    }

    proof := &ConsistencyProof{
        Epoch:           newRoster.Epoch,
        OldThreshold:    old.Roster.Threshold,
        NewThreshold:    tNew,
        OldPublicKey:    old.PublicKey,
        NewPublicKey:    comms[0],
        QualifiedOld:    append([]ID(nil), verdict.Qualified...),
        Announced:       anns,
        NewCommitments:  comms,
        NewPublicShares: public,
    }
    if err := proof.Verify(); err != nil {
        return nil, err
    }
    return &ReshareResult{
        OldRoster:    old.Roster,
        NewRoster:    newRoster,
        Verdict:      verdict,
        QualifiedOld: verdict.Qualified,
        Lagrange:     lam,
        Commitments:  comms,
        PublicKey:    comms[0],
        Shares:       shares,
        PublicShares: public,
        Proof:        proof,
    }, nil
}

func mulScalar(a, b *Scalar) *Scalar {
    r := new(Scalar)
    r.Mul(a, b)
    return r
}

// Attestation lets a member prove, with pairings, that it holds the share
// committed to by the transcript.
type Attestation struct {
    Member        ID
    Signature     *G1
    PublicShareG2 *G2
}

func AttestationMessage(epoch uint64, pk *G1) []byte {
    h := sha256.New()
    h.Write([]byte("reshare/attest"))
    var b [8]byte
    b[0] = byte(epoch >> 56)
    b[1] = byte(epoch >> 48)
    b[2] = byte(epoch >> 40)
    b[3] = byte(epoch >> 32)
    b[4] = byte(epoch >> 24)
    b[5] = byte(epoch >> 16)
    b[6] = byte(epoch >> 8)
    b[7] = byte(epoch)
    h.Write(b[:])
    h.Write(pk.BytesCompressed())
    return h.Sum(nil)
}

func BuildAttestation(member ID, share *Scalar, epoch uint64, pk *G1) *Attestation {
    msg := AttestationMessage(epoch, pk)
    sig := SignBLS(share, msg)
    g2 := new(G2)
    g2.ScalarMult(share, bls12381.G2Generator())
    return &Attestation{Member: member, Signature: sig, PublicShareG2: g2}
}

func VerifyAttestation(a *Attestation, Y *G1, epoch uint64, pk *G1) bool {
    if a == nil || a.Signature == nil || a.PublicShareG2 == nil {
        return false
    }
    msg := AttestationMessage(epoch, pk)
    h := new(G1)
    h.Hash(msg, []byte("BLS_SIG_BLS12381G1_XMD:SHA-256_SSWU_RO_NUL_"))

    g2 := bls12381.G2Generator()
    if !bls12381.Pair(Y, g2).IsEqual(bls12381.Pair(bls12381.G1Generator(), a.PublicShareG2)) {
        return false
    }
    return bls12381.Pair(a.Signature, g2).IsEqual(bls12381.Pair(h, a.PublicShareG2))
}

5. Security notes / assumptions

  • No trusted dealer, no reconstruction. Old-member dealers use NewReshareDealer with p_i(0)=s_i; finalization applies λ_i to both shares and commitments. The library never computes f(0).
  • Leak-free complaints. Evidence is Y=yG plus two Fiat–Shamir Schnorr proofs over a Pedersen box. No scalar share appears. A recorded complaint transcript is zero-knowledge.
  • Sound adjudication. Pedersen binding (with H from hash-to-curve, dlog_G H unknown) means a complainant can only prove an opening of the dealer's actual box; a fabricated Y fails the blinding relation Box−Y=rH. Thus honest dealers cannot be framed, and a dealer that commits to a value inconsistent with its Feldman commitments is provably disqualified.
  • Equivocation. The broadcast digest covers both commitments and all per-receiver boxes; Announcement.Validate rejects any mismatch. Receivers must verify against the broadcast announcement (model assumes reliable broadcast for the transcript).
  • Overlap = t. Correct because every active old dealer sends to every new member; only #active_old ≥ t_old is required. Interpolation is over any qualified old subset of size ≥ t_old.
  • Delinquency. Missing/non-qualified dealers are excluded from the Lagrange set; finalization aborts if fewer than t_old remain. Delinquent new receivers do not block the epoch; t_new honest new members are sufficient to use the key.
  • Pairing verifiability. VerifyBLS and VerifyAttestation use e(·,·) equations binding G1 public shares, G2 images, and BLS signatures. The consistency proof additionally checks C'_0 = PK_old and Y_j = EvalCommitments(C',j).
  • Delivery fault vs. committed fault. If a malicious dealer sends an opening that does not open its broadcast box, the receiver treats it as non-delivery (it cannot produce a sound complaint without leaking); the epoch still succeeds as long as t_new honest receivers got valid openings. A dealer that commits to an inconsistent value is provably disqualified by the complaint above.
