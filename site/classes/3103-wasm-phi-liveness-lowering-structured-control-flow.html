Fixing SSA Phi Lowering for WebAssembly Structured Control Flow

Problem class: wasm-phi-liveness-lowering-structured-control-flow Environment: Python 3.14, WABT 1.0.36 (wat2wasm, wasm-validate), Node 22 Artifact: a self-contained lowering + a differential verifier (files also in ~/wasm_phi/).

TL;DR

A front end that lowers SSA to WebAssembly fails in four distinct ways when handling phi nodes, critical edges, irreducible loops and multi-value results:

  1. Phi copies are edge properties, but they are placed at blocks. A copy appended at the end of a predecessor runs on every outgoing edge, so on a critical edge it clobbers a sibling successor's value.
  2. Phi copies are simultaneous, but they are emitted sequentially. A dependence cycle (p := q, q := p, or any loop-carried swap) needs a temporary or the update is lost.
  3. Liveness under-approximates. Edge-move operands, terminator uses (return values / branch conditions) and parameters live on entry are not counted. Because liveness drives spill-slot colouring and copy coalescing, two simultaneously-live values can share a local and the second write destroys the first. This is the "loop accumulator silently reverts" / "returned tuple is [x, x]" failure.
  4. Irreducible loops are not lexically nestable. WebAssembly only has block/loop/if and branches to enclosing labels; a multi-entry cycle cannot be expressed by naive nesting without duplication. A dispatch-state (loop + br_table) lowering is the general, always-valid structured form.

The fix is a five-stage pipeline: critical-edge splitting → out-of-SSA parallel copies → correct liveness/interference colouring → structured dispatch lowering → multi-value-aware WAT emission. It executes blocks in exactly the source order, so observable traps and evaluation order are preserved.

1. Symptom

Symptom Failing shape Wrong Correct
Lost loop accumulator loop_sum after 1 iteration 0 1
Loop-carried value reverted irreducible 0 expected
Returned tuple is [x, x] two values defined in a Return block [-2, -2] [-1, -2]
Phi merge corrupted diamond whose arms share a local [0, 0] [2, 0]
Validation failure irreducible / multi-entry loop invalid wasm valid module
Spurious trap division after a lost spill no trap integer divide by zero

2. Root-cause analysis

2.1 A phi is an edge function, not a block function

An edge P → V is critical when outdegree(P) > 1 and indegree(V) > 1. Copying a phi input at the end of P also runs when P branches elsewhere; sinking it into V cannot tell P from other predecessors. Fix: split every critical edge with a fresh empty block S: P → S → V. Rewrite V.phi.incoming[P] to S and append all copies to S.

2.2 Phi copies are simultaneous

All phis of V on edge P → V execute in parallel. Emitting them one-by-one is wrong whenever a destination is another move's source (swap / rotation). Fix: the classic parallel-move schedule — emit any move whose destination no pending move still reads; if none exists, break the cycle by stashing the destination's old value in a fresh temp and rewriting readers. This is sequentialize().

2.3 Liveness drives coalescing, so under-approximating it is a miscompile

The allocator builds an interference graph: whenever a variable is defined while another is live, they interfere and may not share a slot. Missing edges allow two live values to share a local. Three easy-to-miss classes:

  • (a) Edge-move operands — a value used only by an edge's copies is live at the end of the predecessor but is not in live_in(successor). The scan must be seeded with move_sources ∪ (live_in(succ) \ move_defs).
  • (b) Terminator uses — a Return block has empty live-out; two values defined and both returned never interfere unless the returned values are seeded. Branch conditions likewise.
  • (c) Parameters — no defining instruction, so the "edge at definition" rule never fires. Make every pair in live_in(entry) interfere.

2.4 Irreducible loops cannot be lexically nested

A multi-entry cycle has no unique header, so no single lexical loop dominates its blocks. Fix: lower to a structured dispatch state machine — number blocks, keep a pc local, wrap each block in a nested block whose end is its entry, and jump with br_table; each body sets the next pc and brs to the dispatch loop. Every br targets an enclosing label, so it validates for any CFG. Block execution order is preserved exactly.

2.5 Multi-value

Every phi is an independent scalar channel; copies are scalar; a Return(v0…vk) becomes (result i32)*k with (return …). Values travel through locals/returns, so dispatcher blocks have arity [] → [].

2.6 Why traps/order are preserved

Instructions stay in order; edge moves run only on their edge, after the condition is read (if pops the condition before an arm runs); dispatch happens at block end, so no trapping instruction is reordered; i32.div_s/i32.rem_s trap at the identical point. Unreachable blocks are still emitted well-typed.

3. The fix: pipeline

SSA IR
  |  split_critical_edges()   # unique edge per phi input
  |  collect_edge_moves()     # parallel copies, cycle-safe
  |  build_lowered()          # non-SSA instructions
  |  compute_liveness()       # use/def incl. edge moves + terminators
  |  build_interference()     # + entry clique for parameters
  |  color_variables()        # min locals + coalescing
  |  emit WAT                 # dispatch + multi-value returns

wasm-phi-liveness-lowering-structured-control-flow
==================================================

A self-contained reference implementation that lowers an SSA IR with
phi nodes, critical edges, irreducible loops and multi-value blocks into
*valid* WebAssembly structured control flow while preserving the exact
evaluation order and trap behaviour of the source program.
"""

# 1.  SSA IR
# =============================================================================


@dataclass
class Phi:
    """`dest = phi(pred_0: v_0, pred_1: v_1, ...)`."""
    dest: str
    incoming: Dict[str, Any]  # predecessor block name -> value (str name or int)


@dataclass
class Inst:
    """`dest = op(args...)` (pure, total except for the trapping div/rem ops)."""
    dest: str
    op: str
    args: List[Any]


@dataclass
class Jump:
    target: str


@dataclass
class CondBr:
    cond: str
    then_bb: str
    else_bb: str


@dataclass
class Return:
    values: List[Any]


@dataclass
class Block:
    name: str
    phis: List[Phi] = field(default_factory=list)
    insts: List[Inst] = field(default_factory=list)
    term: Any = None


@dataclass
class Function:
    name: str
    params: List[str]
    blocks: List[Block]
    entry: str


# =============================================================================
# 2.  Reference semantics (used both as oracle and to define traps)
# =============================================================================


class WasmTrap(Exception):
    """A WebAssembly trap (divide-by-zero, integer overflow)."""


def wrap32(x: int) -> int:
    x &= 0xFFFFFFFF
    return x - 0x100000000 if x >= 0x80000000 else x


def _trunc_div(x: int, y: int) -> int:
    q = abs(x) // abs(y)
    return q if (x < 0) == (y < 0) else -q


def eval_op(op: str, a: List[int]) -> int:
    if op == "const":
        return wrap32(a[0])
    if op == "add":
        return wrap32(a[0] + a[1])
    if op == "sub":
        return wrap32(a[0] - a[1])
    if op == "mul":
        return wrap32(a[0] * a[1])
    if op == "div_s":
        if a[1] == 0:
            raise WasmTrap("integer divide by zero")
        if a[0] == -(2 ** 31) and a[1] == -1:
            raise WasmTrap("integer overflow")
        return wrap32(_trunc_div(a[0], a[1]))
    if op == "div_u":
        if a[1] == 0:
            raise WasmTrap("integer divide by zero")
        return wrap32((a[0] & 0xFFFFFFFF) // (a[1] & 0xFFFFFFFF))
    if op == "rem_s":
        if a[1] == 0:
            raise WasmTrap("integer divide by zero")
        if a[0] == -(2 ** 31) and a[1] == -1:
            return 0
        return wrap32(a[0] - _trunc_div(a[0], a[1]) * a[1])
    if op == "rem_u":
        if a[1] == 0:
            raise WasmTrap("integer divide by zero")
        return wrap32((a[0] & 0xFFFFFFFF) % (a[1] & 0xFFFFFFFF))
    if op in ("and", "or", "xor"):
        x, y = a[0] & 0xFFFFFFFF, a[1] & 0xFFFFFFFF
        return wrap32({"and": x & y, "or": x | y, "xor": x ^ y}[op])
    if op == "shl":
        return wrap32((a[0] & 0xFFFFFFFF) << (a[1] & 31))
    if op == "shr_s":
        return wrap32(a[0] >> (a[1] & 31))
    if op == "shr_u":
        return wrap32((a[0] & 0xFFFFFFFF) >> (a[1] & 31))
    if op == "eqz":
        return 1 if a[0] == 0 else 0
    if op in ("eq", "ne", "lt_s", "gt_s", "le_s", "ge_s",
              "lt_u", "gt_u", "le_u", "ge_u"):
        x, y = a[0], a[1]
        if op in ("lt_u", "gt_u", "le_u", "ge_u"):
            x, y = x & 0xFFFFFFFF, y & 0xFFFFFFFF
        return 1 if {
            "eq": x == y, "ne": x != y,
            "lt_s": x < y, "gt_s": x > y, "le_s": x <= y, "ge_s": x >= y,
            "lt_u": x < y, "gt_u": x > y, "le_u": x <= y, "ge_u": x >= y,
        }[op] else 0
    raise ValueError(f"unknown op {op!r}")


def _val(v: Any, env: Dict[str, int]) -> int:
    return v if isinstance(v, int) else env[v]


def interpret(fn: Function, args: List[int], step_limit: int = 1_000_000):
    """Direct execution of the SSA IR; the oracle for differential testing."""
    if len(args) != len(fn.params):
        raise ValueError("arity mismatch")
    env: Dict[str, int] = dict(zip(fn.params, args))
    blocks = {b.name: b for b in fn.blocks}
    cur, pred, steps = fn.entry, None, 0
    while True:
        steps += 1
        if steps > step_limit:
            raise TimeoutError("reference interpreter step limit")
        b = blocks[cur]
        for phi in b.phis:
            env[phi.dest] = _val(phi.incoming[pred], env)
        for ins in b.insts:
            env[ins.dest] = eval_op(ins.op, [_val(a, env) for a in ins.args])
        t = b.term
        if isinstance(t, Return):
            return [_val(v, env) for v in t.values]
        if isinstance(t, Jump):
            nxt = t.target
        else:  # CondBr
            nxt = t.then_bb if env[t.cond] != 0 else t.else_bb
        pred, cur = b.name, nxt


# =============================================================================
# 3.  Critical-edge splitting
# =============================================================================


def succ_names(term: Any) -> List[str]:
    if isinstance(term, Jump):
        return [term.target]
    if isinstance(term, CondBr):
        return [term.then_bb, term.else_bb]
    return []


def _redirect(term: Any, old: str, new: str) -> None:
    if isinstance(term, Jump):
        if term.target == old:
            term.target = new
    elif isinstance(term, CondBr):
        if term.then_bb == old:
            term.then_bb = new
        if term.else_bb == old:
            term.else_bb = new


def split_critical_edges(fn: Function) -> None:
    """
    A *critical edge* is `u -> v` where u has several successors and v has
    several predecessors.  Splitting every critical edge gives every phi input
    a dedicated predecessor block, which is what makes the simple "append
    copies to the predecessor" lowering correct.
    """
    blocks = {b.name: b for b in fn.blocks}
    while True:
        succs = {n: {s for s in succ_names(b.term)} for n, b in blocks.items()}
        preds: Dict[str, set] = {n: set() for n in blocks}
        for n, ss in succs.items():
            for s in ss:
                preds[s].add(n)
        progress = False
        for name, b in list(blocks.items()):
            if len(succs[name]) <= 1:
                continue
            for s in list(succs[name]):
                if len(preds[s]) <= 1:
                    continue
                new = f"{name}__{s}"
                k = 0
                while new in blocks:
                    k += 1
                    new = f"{name}__{s}_{k}"
                blocks[new] = Block(new, [], [], Jump(s))
                _redirect(b.term, s, new)
                for phi in blocks[s].phis:
                    if name in phi.incoming:
                        phi.incoming[new] = phi.incoming.pop(name)
                progress = True
                break
            if progress:
                break
        if not progress:
            break
    fn.blocks = list(blocks.values())


# =============================================================================
# 4.  Out-of-SSA: parallel copy sequentialisation
# =============================================================================


class _Fresh:
    def __init__(self) -> None:
        self.n = 0

    def __call__(self) -> str:
        self.n += 1
        return f"%tmp{self.n}"


def sequentialize(moves: List[Tuple[str, Any]], fresh) -> List[Tuple[str, Any]]:
    """
    Turn a *parallel* copy `(d0 := s0, d1 := s1, ...)` into an ordered sequence
    of scalar moves with identical simultaneous semantics, using temporaries to
    break cycles (e.g. the swap `a,b := b,a`).
    """
    moves = [(d, s) for (d, s) in moves if not (d == s)]
    out: List[Tuple[str, Any]] = []
    while moves:
        readers = {s for _, s in moves}
        ready = next((i for i, m in enumerate(moves) if m[0] not in readers), None)
        if ready is not None:
            out.append(moves.pop(ready))
        else:
            d, _ = moves[0]
            tmp = fresh()
            out.append((tmp, d))                     # tmp := old d
            moves = [(dd, (tmp if ss == d else ss)) for dd, ss in moves]
    return out


# =============================================================================
# 5.  Lowered (non-SSA) program
# =============================================================================


@dataclass
class LBlock:
    name: str
    insts: List[Inst]
    term: Any
    moves: Dict[str, List[Tuple[str, Any]]]  # successor name -> ordered edge moves


def collect_edge_moves(fn: Function, fresh) -> Dict[Tuple[str, str], list]:
    raw: Dict[Tuple[str, str], list] = {}
    for b in fn.blocks:
        for s in set(succ_names(b.term)):
            raw[(b.name, s)] = []
    for b in fn.blocks:
        for phi in b.phis:
            for pred, val in phi.incoming.items():
                raw[(pred, b.name)].append((phi.dest, val))
    return {k: sequentialize(v, fresh) for k, v in raw.items()}


def build_lowered(fn: Function, edge_moves) -> List[LBlock]:
    prog = []
    for b in fn.blocks:
        mv = {s: edge_moves.get((b.name, s), []) for s in set(succ_names(b.term))}
        prog.append(LBlock(b.name, list(b.insts), b.term, mv))
    return prog


# =============================================================================
# 6.  Liveness, interference and spill-slot colouring
# =============================================================================


def _all_vars(fn: Function, prog: List[LBlock]) -> set:
    vs = set(fn.params)
    for b in prog:
        for i in b.insts:
            vs.add(i.dest)
            for a in i.args:
                if isinstance(a, str):
                    vs.add(a)
        if isinstance(b.term, CondBr):
            vs.add(b.term.cond)
        if isinstance(b.term, Return):
            for v in b.term.values:
                if isinstance(v, str):
                    vs.add(v)
        for mv in b.moves.values():
            for d, s in mv:
                vs.add(d)
                if isinstance(s, str):
                    vs.add(s)
    return vs


def compute_liveness(prog: List[LBlock]):
    use: Dict[str, set] = {}
    define: Dict[str, set] = {}
    succ: Dict[str, List[str]] = {}
    for b in prog:
        ss = []
        if isinstance(b.term, Jump):
            ss = [b.term.target]
        elif isinstance(b.term, CondBr):
            ss = [b.term.then_bb, b.term.else_bb]
        succ[b.name] = ss
        reads, writes = set(), set()
        for i in b.insts:
            for a in i.args:
                if isinstance(a, str) and a not in writes:
                    reads.add(a)
            writes.add(i.dest)
        if isinstance(b.term, CondBr):
            if b.term.cond not in writes:
                reads.add(b.term.cond)
        if isinstance(b.term, Return):
            for v in b.term.values:
                if isinstance(v, str) and v not in writes:
                    reads.add(v)
        # Edge moves are alternatives; treat them simultaneously (conservative).
        for mv in b.moves.values():
            for d, s in mv:
                if isinstance(s, str) and s not in writes:
                    reads.add(s)
                writes.add(d)
        use[b.name], define[b.name] = reads, writes

    live_in = {b.name: set() for b in prog}
    live_out = {b.name: set() for b in prog}
    changed = True
    while changed:
        changed = False
        for b in prog:
            out = set()
            for s in succ[b.name]:
                out |= live_in[s]
            inn = use[b.name] | (out - define[b.name])
            if out != live_out[b.name] or inn != live_in[b.name]:
                live_out[b.name], live_in[b.name] = out, inn
                changed = True
    return use, define, succ, live_in, live_out


def build_interference(prog, live_in, live_out):
    edges: Dict[str, set] = {}
    for b in prog:
        # Seed with variables live *just before* the edge moves: move sources
        # plus successor live-in minus move destinations.  Seeding with
        # live_out alone misses loop-carried values.
        live = set()
        if isinstance(b.term, CondBr):
            live.add(b.term.cond)
        if isinstance(b.term, Return):
            live |= {v for v in b.term.values if isinstance(v, str)}
        for tgt, mv in b.moves.items():
            defs_m = {d for d, _ in mv}
            live |= {s for _, s in mv if isinstance(s, str)}
            live |= (live_in[tgt] - defs_m)
        for i in reversed(b.insts):
            for v in live:
                if v != i.dest:
                    edges.setdefault(i.dest, set()).add(v)
                    edges.setdefault(v, set()).add(i.dest)
            live.discard(i.dest)
            for a in i.args:
                if isinstance(a, str):
                    live.add(a)
        # per-edge move interference (precise, so coalescing is possible)
        for tgt, mv in b.moves.items():
            lv = set(live_in[tgt])
            for d, s in reversed(mv):
                for v in lv:
                    if v != d:
                        edges.setdefault(d, set()).add(v)
                        edges.setdefault(v, set()).add(d)
                lv.discard(d)
                if isinstance(s, str):
                    lv.add(s)

    # Parameters live on entry have no defining instruction: clique them.
    entry_live = sorted(live_in.get(prog[0].name, set()))
    for i in range(len(entry_live)):
        for j in range(i + 1, len(entry_live)):
            a, c = entry_live[i], entry_live[j]
            edges.setdefault(a, set()).add(c)
            edges.setdefault(c, set()).add(a)
    return edges


def color_variables(all_vars: set, edges) -> Dict[str, int]:
    """Greedy graph colouring: colour number == physical wasm local index."""
    colors: Dict[str, int] = {}
    order = sorted(all_vars, key=lambda v: -len(edges.get(v, ())))
    for v in order:
        forbidden = {colors[n] for n in edges.get(v, ()) if n in colors}
        c = 0
        while c in forbidden:
            c += 1
        colors[v] = c
    return colors

# 7.  WAT emission
# =============================================================================


BINARY_OPS = {
    "add": "i32.add", "sub": "i32.sub", "mul": "i32.mul",
    "div_s": "i32.div_s", "div_u": "i32.div_u",
    "rem_s": "i32.rem_s", "rem_u": "i32.rem_u",
    "and": "i32.and", "or": "i32.or", "xor": "i32.xor",
    "shl": "i32.shl", "shr_s": "i32.shr_s", "shr_u": "i32.shr_u",
    "eq": "i32.eq", "ne": "i32.ne",
    "lt_s": "i32.lt_s", "lt_u": "i32.lt_u", "gt_s": "i32.gt_s", "gt_u": "i32.gt_u",
    "le_s": "i32.le_s", "le_u": "i32.le_u", "ge_s": "i32.ge_s", "ge_u": "i32.ge_u",
}
UNARY_OPS = {"eqz": "i32.eqz", "clz": "i32.clz", "ctz": "i32.ctz", "popcnt": "i32.popcnt"}


def _operand(v: Any, colors) -> str:
    return (f"(i32.const {wrap32(v)})" if isinstance(v, int)
            else f"(local.get $l{colors[v]})")


def emit_inst(i: Inst, colors) -> str:
    if i.op == "const":
        return f"(local.set $l{colors[i.dest]} (i32.const {wrap32(i.args[0])}))"
    if i.op in UNARY_OPS:
        return (f"(local.set $l{colors[i.dest]} "
                f"({UNARY_OPS[i.op]} {_operand(i.args[0], colors)}))")
    if i.op in BINARY_OPS:
        return (f"(local.set $l{colors[i.dest]} "
                f"({BINARY_OPS[i.op]} {_operand(i.args[0], colors)} "
                f"{_operand(i.args[1], colors)}))")
    raise ValueError(f"cannot emit op {i.op!r}")


def emit_moves(dst: str, moves, colors, indent: str, out: List[str]) -> None:
    for d, s in moves:
        if isinstance(s, str) and colors[d] == colors[s]:
            continue  # coalesced: the move is a no-op
        out.append(f"{indent}(local.set $l{colors[d]} {_operand(s, colors)})")


def lower_to_wat(fn: Function):
    """Return (wat_text, metadata). Does not mutate `fn`."""
    fn = copy.deepcopy(fn)
    split_critical_edges(fn)

    fresh = _Fresh()
    edge_moves = collect_edge_moves(fn, fresh)
    prog = build_lowered(fn, edge_moves)

    all_vars = _all_vars(fn, prog)
    use, define, succ, live_in, live_out = compute_liveness(prog)
    edges = build_interference(prog, live_in, live_out)
    colors = color_variables(all_vars, edges)
    nlocals = (max(colors.values()) + 1) if colors else 0
    n_moves = sum(len(mv) for b in prog for mv in b.moves.values())
    n_elided = sum(
        1 for b in prog for mv in b.moves.values() for d, s in mv
        if isinstance(s, str) and colors[d] == colors[s]
    )

    idx = {b.name: i for i, b in enumerate(prog)}
    n = len(prog)

    rets = [b.term.values for b in prog if isinstance(b.term, Return)]
    arity = len(rets[0]) if rets else 0
    for r in rets:
        assert len(r) == arity, "inconsistent return arity"
    results = " ".join("(result i32)" for _ in range(arity))
    params = " ".join(f"(param $p{i} i32)" for i in range(len(fn.params)))

    o: List[str] = []
    o.append("(module")
    o.append(f"  (func $f (export \"f\") {params} {results}".rstrip())
    for c in range(nlocals):
        o.append(f"    (local $l{c} i32)")
    o.append("    (local $pc i32)")
    for i, pvar in enumerate(fn.params):
        o.append(f"    (local.set $l{colors[pvar]} (local.get $p{i}))")
    o.append(f"    (local.set $pc (i32.const {idx[fn.entry]}))")
    o.append("    (loop $dispatch")

    # nested dispatch blocks: $b{n} (default) encloses $b{n-1} ... $b0
    for k in range(n, -1, -1):
        o.append(f"      (block $b{k}")
    o.append("        (br_table " + " ".join(f"$b{k}" for k in range(n))
             + f" $b{n} (local.get $pc))")
    for k in range(n):
        o.append("      )")  # close $b{k}
        b = prog[k]
        body: List[str] = []
        for i in b.insts:
            body.append(emit_inst(i, colors))
        t = b.term
        if isinstance(t, Jump):
            emit_moves("", b.moves[t.target], colors, " " * 8, body)
            body.append(f"(local.set $pc (i32.const {idx[t.target]}))")
            body.append("(br $dispatch)")
        elif isinstance(t, CondBr):
            body.append(f"(if (local.get $l{colors[t.cond]})")
            body.append("  (then")
            emit_moves("", b.moves[t.then_bb], colors, " " * 12, body)
            body.append(f"    (local.set $pc (i32.const {idx[t.then_bb]}))")
            body.append("    (br $dispatch)")
            body.append("  )")
            body.append("  (else")
            emit_moves("", b.moves[t.else_bb], colors, " " * 12, body)
            body.append(f"    (local.set $pc (i32.const {idx[t.else_bb]}))")
            body.append("    (br $dispatch)")
            body.append("  )")
            body.append(")")
        elif isinstance(t, Return):
            ops = " ".join(_operand(v, colors) for v in t.values)
            body.append(f"(return {ops})".replace("  ", " ").rstrip())
        else:
            raise ValueError("bad terminator")
        o.extend("        " + line for line in body)
    o.append("      )")                 # close $b{n} (default)
    o.append("      (unreachable)")     # invalid pc is semantically impossible
    o.append("    )")                   # end loop
    o.append("    (unreachable)")       # make the function end type-check
    o.append("  )")
    o.append(")")
    return "\n".join(o) + "\n", {
        "colors": colors, "nlocals": nlocals, "index": idx,
        "n_values": len(all_vars), "n_moves": n_moves, "n_moves_elided": n_elided,
    }

def wat_to_wasm(wat: str, workdir: str) -> str:
    os.makedirs(workdir, exist_ok=True)
    wat_path = os.path.join(workdir, "m.wat")
    wasm_path = os.path.join(workdir, "m.wasm")
    with open(wat_path, "w") as f:
        f.write(wat)
    subprocess.run(["wat2wasm", wat_path, "-o", wasm_path],
                   check=True, capture_output=True)
    subprocess.run(["wasm-validate", wasm_path], check=True, capture_output=True)
    return wasm_path


_NODE_DRIVER = r"""
const fs = require('fs');
const bytes = fs.readFileSync(process.argv[2]);
const args = JSON.parse(process.argv[3]);
WebAssembly.instantiate(bytes, {}).then(({instance}) => {
  try {
    const r = instance.exports.f(...args);
    console.log(JSON.stringify({ok: true, result: r}));
  } catch (e) {
    console.log(JSON.stringify({ok: false, trap: String(e)}));
  }
}).catch(e => { console.log(JSON.stringify({ok: false, error: String(e)})); });
"""


def run_wasm(wasm_path: str, args: List[int], workdir: str):
    driver = os.path.join(workdir, "run.js")
    with open(driver, "w") as f:
        f.write(_NODE_DRIVER)
    proc = subprocess.run(["node", driver, wasm_path, json.dumps(args)],
                          capture_output=True, text=True, timeout=30)
    return json.loads(proc.stdout.strip())

def check_function(fn: Function, arg_sets: List[List[int]], verbose: bool = False):
    wat, meta = lower_to_wat(fn)
    workdir = tempfile.mkdtemp(prefix="wasmphione")
    try:
        wasm = wat_to_wasm(wat, workdir)
        for args in arg_sets:
            expected_exc = None
            try:
                expected = interpret(fn, args)
            except WasmTrap as e:
                expected_exc = str(e)
            except TimeoutError:
                continue
            got = run_wasm(wasm, args, workdir)
            if expected_exc is not None:
                ok = (not got["ok"]) and "unreachable" not in got.get("trap", "")
                if not ok:
                    raise AssertionError(
                        f"{fn.name}{args}: expected trap {expected_exc!r}, got {got}")
            else:
                if not got["ok"]:
                    raise AssertionError(
                        f"{fn.name}{args}: expected {expected}, got trap {got}")
                exp = expected[0] if len(expected) == 1 else expected
                if got["result"] != exp:
                    raise AssertionError(
                        f"{fn.name}{args}: expected {expected}, got {got['result']}")
        return wat, meta
    finally:
        shutil.rmtree(workdir, ignore_errors=True)

def const(d, n): return Inst(d, "const", [n])
def add(d, a, b): return Inst(d, "add", [a, b])
def sub(d, a, b): return Inst(d, "sub", [a, b])
def mul(d, a, b): return Inst(d, "mul", [a, b])
def div_s(d, a, b): return Inst(d, "div_s", [a, b])
def phi(d, **inc): return Phi(d, dict(inc))


def diamond():
    fn = Function("diamond", ["%x"], [
        Block("%entry", [], [const("%z", 0), Inst("%c", "ne", ["%x", "%z"])],
              CondBr("%c", "%t", "%f")),
        Block("%t", [], [const("%two", 2), mul("%y", "%x", "%two")], Jump("%j")),
        Block("%f", [], [const("%h", 100), add("%y", "%x", "%h")], Jump("%j")),
        Block("%j", [phi("%r", **{"%t": "%y", "%f": "%y"})], [], Return(["%r"])),
    ], "%entry")
    return fn, [[0], [1], [7], [-9]]


def loop_sum():
    fn = Function("loop_sum", ["%n"], [
        Block("%entry", [], [const("%zero", 0)], Jump("%h")),
        Block("%h", [phi("%sum", **{"%entry": "%zero", "%b": "%sum2"}),
                     phi("%i", **{"%entry": "%n", "%b": "%i2"})],
              [Inst("%c", "ne", ["%i", "%zero"])], CondBr("%c", "%b", "%e")),
        Block("%b", [], [add("%sum2", "%sum", "%i"), const("%one", 1),
                         sub("%i2", "%i", "%one")], Jump("%h")),
        Block("%e", [], [], Return(["%sum"])),
    ], "%entry")
    return fn, [[0], [1], [5], [10]]


def loop_swap():
    # phi swap cycle on the back edge
    fn = Function("loop_swap", ["%x"], [
        Block("%entry", [], [const("%one", 1), const("%ten", 10)], Jump("%h")),
        Block("%h", [phi("%p", **{"%entry": "%x", "%b": "%q"}),
                     phi("%q", **{"%entry": "%one", "%b": "%p"}),
                     phi("%i", **{"%entry": "%ten", "%b": "%i2"})],
              [Inst("%c", "ne", ["%i", "%one"])], CondBr("%c", "%b", "%e")),
        Block("%b", [], [sub("%i2", "%i", "%one")], Jump("%h")),
        Block("%e", [], [], Return(["%p"])),
    ], "%entry")
    return fn, [[1], [2], [7], [-3]]


def irreducible():
    # multi-entry cycle: entry -> b|c ; b->d, c->d, d->b|c
    fn = Function("irreducible", ["%x"], [
        Block("%entry", [], [const("%z", 0), Inst("%c0", "ne", ["%x", "%z"])],
              CondBr("%c0", "%b", "%c")),
        Block("%b", [phi("%vb", **{"%entry": "%x", "%d": "%vd"})],
              [const("%one", 1), sub("%vb2", "%vb", "%one")],
              CondBr("%vb2", "%d", "%e")),
        Block("%c", [phi("%vc", **{"%entry": "%x", "%d": "%vd2"})],
              [const("%two", 2), add("%vc2", "%vc", "%two")],
              CondBr("%vc2", "%d", "%e")),
        Block("%d", [phi("%vd", **{"%b": "%vb2", "%c": "%vc2"})],
              [const("%thr", 3), add("%vd2", "%vd", "%thr")],
              CondBr("%vd2", "%b", "%c")),
        Block("%e", [], [], Return(["%x"])),
    ], "%entry")
    return fn, [[0], [1], [5], [-3]]


def trap():
    fn = Function("trap", ["%x", "%n"], [
        Block("%entry", [], [], Jump("%h")),
        Block("%h", [phi("%y", **{"%entry": "%x", "%b": "%y2"})],
              [Inst("%c", "ne", ["%y", "%n"])], CondBr("%c", "%b", "%e")),
        Block("%b", [], [div_s("%y2", "%y", "%n")], Jump("%h")),
        Block("%e", [], [], Return(["%y"])),
    ], "%entry")
    return fn, [[8, 2], [8, 0], [-8, 2]]


def multivalue():
    fn = Function("multivalue", ["%x"], [
        Block("%entry", [], [const("%z", 0), Inst("%c", "gt_s", ["%x", "%z"])],
              CondBr("%c", "%t", "%f")),
        Block("%t", [], [const("%one", 1), add("%a", "%x", "%one"),
                         sub("%b", "%x", "%one")], Jump("%j")),
        Block("%f", [], [const("%two", 2), const("%three", 3),
                         mul("%a", "%x", "%two"), mul("%b", "%x", "%three")], Jump("%j")),
        Block("%j", [phi("%pa", **{"%t": "%a", "%f": "%a"}),
                     phi("%pb", **{"%t": "%b", "%f": "%b"})], [],
              Return(["%pa", "%pb"])),
    ], "%entry")
    return fn, [[0], [1], [2], [-5]]


def multiret():
    # two values defined in one Return block: catches missing terminator-use edges
    fn = Function("multiret", ["%x"], [
        Block("%entry", [], [const("%z", 0), Inst("%c", "gt_s", ["%x", "%z"])],
              CondBr("%c", "%t", "%f")),
        Block("%t", [], [const("%one", 1), const("%two", 2)], Return(["%one", "%two"])),
        Block("%f", [], [const("%m", -1), const("%n", -2)], Return(["%m", "%n"])),
    ], "%entry")
    return fn, [[0], [1], [-5]]
