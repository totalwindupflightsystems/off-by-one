Byzantine-Tolerant Checkpoint Repair Coordinator

Problem class: go-bft-checkpoint-equivocation-repair-20261013
Language / toolchain: Go 1.26 (standard library only)

TL;DR

A checkpoint repair coordinator is safe only if a repair certificate is a quorum of 2f+1 signatures over the entire (shard, height, stateRoot, configEpoch) tuple, and if it accepts at most one tuple per replica per height. Binding the config epoch into both the signed bytes and the candidate key stops "same root, different epoch" votes from being merged into a bogus quorum. Accepting only the first tuple per replica bounds buffering at N votes and N candidate tuples per height regardless of how many conflicting tuples a Byzantine replica emits. Selection then resumes from the highest height whose quorum is admissible, and refuses (does not guess) if two conflicting quorums are ever seen.

The implementation below passes a randomized safety suite (N=4, f=1, 120 trials × 40 heights), an epoch-splitting attack test, out-of-order/replay tests, a 20,000-message bounded-buffering test, race detection, and 88.6% statement coverage.

Root-Cause Analysis

The problem statement hides three independent failure modes. Each has a naive implementation that looks correct and fails.

1. Root-only keying loses the configuration epoch (safety bug)

A replica votes on a checkpoint. The obvious struct is (shard, height, root), and the obvious candidate map is keyed by (height, root). But a checkpoint root is only meaningful relative to the configuration epoch that produced it. If a Byzantine replica signs (H, R, epoch=1) and (H, R, epoch=2), a root-only coordinator merges both into a single quorum. It then resumes from root R while different nodes disagree about which configuration that root belongs to. Two honest nodes can apply the same root under different configs, which is a safety violation (divergent state, wrong validator set / shard assignment).

Root cause: the signed message and the buffering key do not commit to the full checkpoint tuple. The fix is to sign and key on (shard, height, stateRoot, configEpoch) together. The test TestEpochBindingPreventsMerge demonstrates the attack: five voters that a root-only coordinator would count as a quorum (size 5) stay split into candidates of size 3/1/1, below the quorum of 4.

2. The signed message omits the view (replay across view changes)

Votes are collected across view changes. If the view is not part of the signed payload, a signature captured in view v can be replayed in view v+k. Even though replaying a vote for the same checkpoint is harmless (the replica really did endorse that checkpoint), an attacker can also replay old votes to keep a stale candidate alive and to force unbounded duplicate processing. Domain-separating and including the view in SigningBytes makes signatures non-transferable between views, and a per-replica dedup map makes replays within a view a no-op.

3. Buffering every distinct tuple is unbounded (liveness / DoS)

A Byzantine replica is not limited to one vote. For a single height it can emit an unlimited number of distinct (root, epoch) pairs. A coordinator that stores every tuple it sees grows without bound, and a delayed/reordered stream makes it worse. The number of heights must also be bounded: a vote for committed + 10^9 must not allocate.

Root cause: no "one vote per replica per height" rule and no height window. The fix:

  • the first accepted vote from a replica at a height is that replica's vote;
  • any later, different tuple for the same height is kept only as a bounded equivocation proof (de-duplicated per (replica, height)), not as a new candidate;
  • heights are buffered only in (committed, committed+Lookahead] and at most Window distinct heights are retained at once, evicting the lowest.

This yields hard, provable bounds: at most N accepted votes per height, at most N candidate tuples per height, at most Window*N votes total. The test TestBoundedBuffering hammers the coordinator with 20,000 out-of-order messages spanning 5,000 heights and asserts these bounds on every iteration.

Safety argument

Let N = 3f+1 and quorum Q = N-f = 2f+1. A certificate is Q distinct replica signatures over one tuple. Two distinct certificates at the same height would need two quorums whose intersection has size at least Q + Q - N = f+1. At least one member of that intersection is honest (there are only f Byzantine replicas) and would have signed two different tuples, which an honest replica never does. Contradiction. Hence conflicting quorums at one height are impossible under the fault assumption. The coordinator detects the impossible case anyway and returns ErrConflictingQuorum rather than picking an arbitrary root.

The Fix

Design invariants

  1. SigningBytes commits to domain || shard || height || stateRoot || configEpoch || view.
  2. Candidate key is (stateRoot, configEpoch) inside a height bucket (shard and height are fixed by the bucket).
  3. Per height, signed[replica] records exactly one accepted vote. Subsequent conflicting tuples produce equivocation evidence only.
  4. Heights outside (committed, committed+Lookahead] are dropped, and at most Window heights are retained, lowest evicted first.
  5. VerifyCertificate requires Q distinct signers, all on the same tuple, valid signatures, and an admissible checkpoint. It caps input at N votes.
  6. SelectRepair scans retained heights and returns the highest admissible complete candidate; two complete candidates at one height is fatal.
  7. Commit is monotonic, idempotent for the same checkpoint, and prunes all heights at or below the new base.

// Package checkpoint implements a Byzantine fault tolerant checkpoint repair
// coordinator for a sharded replicated log.
//
// # Threat model
//
// Up to f of the N = 3f+1 replicas are Byzantine. A Byzantine replica may
// equivocate: it may sign two different checkpoints for the same height,
// including two checkpoints that share a state root but disagree on the
// configuration epoch under which that root is to be interpreted. Messages
// may be delayed, duplicated, or replayed across view changes.
//
// # Why the obvious implementation is unsafe
//
// A repair certificate is a quorum of Q = N-f = 2f+1 signed votes. The two
// mistakes that break safety are:
//
//  1. Keying candidates by state root alone. If the coordinator treats votes
//     as "root R at height H", then votes for (H, R, epoch=1) and
//     (H, R, epoch=2) are merged into a single quorum. The repair then resumes
//     from a root whose configuration epoch is ambiguous, and two different
//     nodes can interpret the same root under different configurations. The
//     fix is to bind the signed message and the candidate key to the entire
//     tuple (shard, height, stateRoot, configEpoch).
//
//  2. Buffering every distinct tuple that arrives. A Byzantine replica can
//     emit an unbounded number of distinct (root, epoch) pairs for one height,
//     so a naive per-tuple buffer grows without bound. The fix is to accept at
//     most one tuple per replica per height: the first accepted vote from a
//     replica is its vote, and any later, different tuple is recorded only as
//     an equivocation proof. This gives a hard bound of N votes per height and
//     N candidate tuples per height.
//
// # Safety argument
//
// Because the signed message commits to the whole tuple, a vote harvested for
// one checkpoint cannot be replayed as a vote for another. Two distinct
// certificates at the same height would require two quorums of size Q whose
// intersection has size at least Q+Q-N = f+1. At least one member of the
// intersection is honest and would have signed two different tuples, which is
// impossible. Therefore the coordinator never observes two conflicting
// quorums when at most f replicas are Byzantine; if it ever does (which proves
// the fault assumption was violated) it refuses to choose and reports the
// conflict instead of silently resuming from an arbitrary root.
package checkpoint

import (
    "crypto/ed25519"
    "encoding/binary"
    "errors"
    "fmt"
    "sort"
    "sync"
)

const voteDomain = "BFTCHECKPOINT/v1"

// ---------------------------------------------------------------------------
// Identifiers and checkpoint tuple
// ---------------------------------------------------------------------------

// ShardID identifies one shard of the replicated log.
type ShardID uint32

// ReplicaID identifies a replica within a shard's consensus group.
type ReplicaID uint32

// Checkpoint is the unit replicas vote on. Height is the log position that the
// state root commits to. StateRoot and ConfigEpoch are bound together so that a
// root cannot be reinterpreted under a different configuration later.
type Checkpoint struct {
    Shard       ShardID
    Height      uint64
    StateRoot   [32]byte
    ConfigEpoch uint64
}

// Equal reports whether two checkpoints are the exact same tuple.
func (c Checkpoint) Equal(o Checkpoint) bool {
    return c.Shard == o.Shard &&
        c.Height == o.Height &&
        c.StateRoot == o.StateRoot &&
        c.ConfigEpoch == o.ConfigEpoch
}

// String renders a checkpoint for logs and error messages.
func (c Checkpoint) String() string {
    return fmt.Sprintf("shard=%d height=%d root=%x epoch=%d",
        c.Shard, c.Height, c.StateRoot[:4], c.ConfigEpoch)
}

// SigningBytes returns the canonical, domain-separated byte string that a
// replica signs for a vote. It binds the shard, height, state root,
// configuration epoch, and the view. Binding the view prevents a signature
// produced for one view from being replayed under a different view.
func SigningBytes(c Checkpoint, view uint64) []byte {
    b := make([]byte, 0, len(voteDomain)+4+8+32+8+8)
    b = append(b, voteDomain...)
    b = binary.BigEndian.AppendUint32(b, uint32(c.Shard))
    b = binary.BigEndian.AppendUint64(b, c.Height)
    b = append(b, c.StateRoot[:]...)
    b = binary.BigEndian.AppendUint64(b, c.ConfigEpoch)
    b = binary.BigEndian.AppendUint64(b, view)
    return b
}

// Vote is a signed statement by one replica endorsing one checkpoint in one
// view. A repair certificate is a quorum of votes with identical checkpoints.
type Vote struct {
    Checkpoint Checkpoint
    View       uint64
    Replica    ReplicaID
    Sig        []byte
}

// ---------------------------------------------------------------------------
// Verification
// ---------------------------------------------------------------------------

// Verifier checks a replica's signature. Implementations must return false for
// unknown replicas and for malformed signatures.
type Verifier interface {
    Verify(id ReplicaID, msg, sig []byte) bool
}

// VerifierFunc adapts a function to the Verifier interface.
type VerifierFunc func(id ReplicaID, msg, sig []byte) bool

// Verify implements Verifier.
func (f VerifierFunc) Verify(id ReplicaID, msg, sig []byte) bool {
    return f(id, msg, sig)
}

// Keyring is an ed25519 Verifier backed by a static public-key map.
type Keyring struct {
    mu  sync.RWMutex
    pub map[ReplicaID]ed25519.PublicKey
}

// NewKeyring returns an empty keyring.
func NewKeyring() *Keyring {
    return &Keyring{pub: make(map[ReplicaID]ed25519.PublicKey)}
}

// Add registers the public key for a replica.
func (k *Keyring) Add(id ReplicaID, pub ed25519.PublicKey) {
    k.mu.Lock()
    defer k.mu.Unlock()
    k.pub[id] = append(ed25519.PublicKey(nil), pub...)
}

// Verify implements Verifier.
func (k *Keyring) Verify(id ReplicaID, msg, sig []byte) bool {
    k.mu.RLock()
    pub, ok := k.pub[id]
    k.mu.RUnlock()
    if !ok || len(pub) != ed25519.PublicKeySize {
        return false
    }
    if len(sig) != ed25519.SignatureSize {
        return false
    }
    return ed25519.Verify(pub, msg, sig)
}

// ---------------------------------------------------------------------------
// Errors
// ---------------------------------------------------------------------------

var (
    // ErrWrongShard is returned for a vote or certificate belonging to a shard
    // this coordinator does not manage.
    ErrWrongShard = errors.New("checkpoint: foreign shard")
    // ErrBadSignature is returned when signature verification fails.
    ErrBadSignature = errors.New("checkpoint: invalid vote signature")
    // ErrFutureView is returned for a vote whose view is too far ahead.
    ErrFutureView = errors.New("checkpoint: vote from a view too far ahead")
    // ErrFutureHeight is returned for a vote beyond the bounded look-ahead.
    ErrFutureHeight = errors.New("checkpoint: vote beyond the bounded look-ahead window")
    // ErrOutOfWindow is returned when the bounded repair window is full of
    // newer heights and this vote would evict a more useful one.
    ErrOutOfWindow = errors.New("checkpoint: vote outside the bounded repair window")
    // ErrStaleCertificate is returned when committing a certificate older than
    // the already committed checkpoint.
    ErrStaleCertificate = errors.New("checkpoint: certificate older than committed checkpoint")
    // ErrConflictingQuorum indicates two conflicting quorums at one height were
    // observed. Under the f-fault assumption this is impossible; observing it
    // proves the assumption was violated, so the coordinator refuses to choose.
    ErrConflictingQuorum = errors.New("checkpoint: conflicting quorum certificates")
    // ErrBadCertificate is returned for a structurally invalid certificate.
    ErrBadCertificate = errors.New("checkpoint: malformed certificate")
    // ErrInadmissible is returned for a well-formed certificate whose checkpoint
    // fails the admissibility predicate.
    ErrInadmissible = errors.New("checkpoint: checkpoint is not admissible")
    // ErrBadConfig is returned by New for an inconsistent configuration.
    ErrBadConfig = errors.New("checkpoint: invalid coordinator configuration")
)

// Equivocation is cryptographic evidence that one replica signed two different
// checkpoints for the same height. It is not itself a safety failure, but it is
// slashable and is retained (bounded by the number of replicas) for reporting.
type Equivocation struct {
    Replica ReplicaID
    Height  uint64
    First   Vote
    Second  Vote
}

func (e Equivocation) String() string {
    return fmt.Sprintf("equivocation: replica=%d height=%d first={%s view=%d} second={%s view=%d}",
        e.Replica, e.Height,
        e.First.Checkpoint, e.First.View,
        e.Second.Checkpoint, e.Second.View)
}

// ---------------------------------------------------------------------------
// Coordinator configuration
// ---------------------------------------------------------------------------

// Config configures a Coordinator.
type Config struct {
    // Shard is the shard this coordinator repairs. Votes for other shards are
    // rejected.
    Shard ShardID
    // N is the total number of replicas and F the assumed fault bound. New
    // requires N >= 3F+1. The quorum size is N-F.
    N int
    F int
    // Verifier authenticates votes. Required.
    Verifier Verifier
    // Admissible optionally vetoes a checkpoint that has a valid quorum but
    // must not be resumed from (for example, an unknown or unratified
    // configuration epoch). A nil predicate admits every checkpoint.
    Admissible func(Checkpoint) bool
    // Window is the maximum number of distinct heights buffered at once. This
    // is the primary bound on out-of-order memory. Defaults to 64.
    Window int
    // Lookahead is the maximum distance above the committed height for which
    // votes are buffered. Votes beyond it are dropped rather than queued.
    // Defaults to 4096.
    Lookahead uint64
    // MaxViewLag is the maximum number of views a buffered vote may lead the
    // coordinator's current view by. Defaults to 2.
    MaxViewLag uint64
    // MaxEvidence bounds the retained equivocation evidence. Evidence is
    // de-duplicated per (replica, height) and capped so a Byzantine replica
    // cannot grow the evidence buffer without bound. Defaults to 4096.
    MaxEvidence int
}

// Quorum returns the number of distinct replicas required for a certificate.
func (c Config) Quorum() int { return c.N - c.F }

func (c *Config) withDefaults() {
    if c.Window <= 0 {
        c.Window = 64
    }
    if c.Lookahead == 0 {
        c.Lookahead = 4096
    }
    if c.MaxViewLag == 0 {
        c.MaxViewLag = 2
    }
    if c.MaxEvidence <= 0 {
        c.MaxEvidence = 4096
    }
}

// ---------------------------------------------------------------------------
// Certificate
// ---------------------------------------------------------------------------

// Certificate is a repair certificate: a quorum of signed votes that all bind
// the same checkpoint tuple. It is self-contained (one signature per distinct
// replica) so it can be persisted and gossiped.
type Certificate struct {
    Checkpoint Checkpoint
    Votes      []Vote
}

// Signers returns the distinct replica IDs in ascending order.
func (c Certificate) Signers() []ReplicaID {
    seen := make(map[ReplicaID]struct{}, len(c.Votes))
    out := make([]ReplicaID, 0, len(c.Votes))
    for _, v := range c.Votes {
        if _, ok := seen[v.Replica]; ok {
            continue
        }
        seen[v.Replica] = struct{}{}
        out = append(out, v.Replica)
    }
    sort.Slice(out, func(i, j int) bool { return out[i] < out[j] })
    return out
}

// VerifyCertificate checks that cert is a structurally valid quorum for cfg's
// shard. It rejects duplicate replicas, mixed checkpoints, bad signatures, a
// short quorum, and checkpoints vetoed by cfg.Admissible. It does not consult
// any coordinator state, so it can be used by a verifier that is catching up.
func VerifyCertificate(cfg Config, cert Certificate) error {
    quorum := cfg.Quorum()
    if quorum <= 0 {
        return fmt.Errorf("%w: non-positive quorum", ErrBadConfig)
    }
    if cert.Checkpoint.Shard != cfg.Shard {
        return fmt.Errorf("%w: certificate %s", ErrWrongShard, cert.Checkpoint)
    }
    if len(cert.Votes) < quorum {
        return fmt.Errorf("%w: have %d votes, need %d", ErrBadCertificate, len(cert.Votes), quorum)
    }
    // A certificate can never contain more than one vote per replica; cap the
    // input so a malicious peer cannot make a verifier allocate unboundedly.
    if len(cert.Votes) > cfg.N {
        return fmt.Errorf("%w: %d votes exceeds N=%d", ErrBadCertificate, len(cert.Votes), cfg.N)
    }
    seen := make(map[ReplicaID]struct{}, len(cert.Votes))
    for _, v := range cert.Votes {
        if !v.Checkpoint.Equal(cert.Checkpoint) {
            return fmt.Errorf("%w: vote %s does not match certificate %s",
                ErrBadCertificate, v.Checkpoint, cert.Checkpoint)
        }
        if _, dup := seen[v.Replica]; dup {
            return fmt.Errorf("%w: duplicate replica %d", ErrBadCertificate, v.Replica)
        }
        seen[v.Replica] = struct{}{}
        msg := SigningBytes(v.Checkpoint, v.View)
        if cfg.Verifier == nil || !cfg.Verifier.Verify(v.Replica, msg, v.Sig) {
            return fmt.Errorf("%w: replica %d", ErrBadSignature, v.Replica)
        }
    }
    if cfg.Admissible != nil && !cfg.Admissible(cert.Checkpoint) {
        return fmt.Errorf("%w: %s", ErrInadmissible, cert.Checkpoint)
    }
    return nil
}

// ---------------------------------------------------------------------------
// Buffered state (bounded)
// ---------------------------------------------------------------------------

// candidateKey identifies a candidate checkpoint within one height. Shard and
// height are fixed by the enclosing heightState, so only the root and the
// configuration epoch remain. Including the epoch is exactly what prevents
// "same root, different epoch" quorum merging.
type candidateKey struct {
    root  [32]byte
    epoch uint64
}

// candidate accumulates the distinct replicas that voted for one tuple.
type candidate struct {
    ckpt     Checkpoint
    votes    map[ReplicaID]Vote
    complete bool
}

func (c *candidate) certificate() Certificate {
    votes := make([]Vote, 0, len(c.votes))
    for _, v := range c.votes {
        votes = append(votes, v)
    }
    sort.Slice(votes, func(i, j int) bool { return votes[i].Replica < votes[j].Replica })
    return Certificate{Checkpoint: c.ckpt, Votes: votes}
}

// heightState buffers the votes seen for one height. Memory is bounded: at most
// one accepted tuple per replica (signed), which in turn bounds the number of
// candidates and the total number of votes by N.
type heightState struct {
    height     uint64
    signed     map[ReplicaID]Vote
    candidates map[candidateKey]*candidate
}

func newHeightState(height uint64) *heightState {
    return &heightState{
        height:     height,
        signed:     make(map[ReplicaID]Vote),
        candidates: make(map[candidateKey]*candidate),
    }
}

// add records a vote. It returns whether the vote was newly accepted and, if
// this replica already signed a different tuple for the same height, an
// equivocation proof. A replica is never counted toward more than one
// candidate, which is what bounds memory under a Byzantine flood.
func (hs *heightState) add(v Vote, quorum int) (bool, *Equivocation) {
    if prev, ok := hs.signed[v.Replica]; ok {
        if !prev.Checkpoint.Equal(v.Checkpoint) {
            proof := &Equivocation{
                Replica: v.Replica,
                Height:  hs.height,
                First:   prev,
                Second:  v,
            }
            return false, proof
        }
        // Exact replay (possibly a different view of the same tuple): already
        // counted, no additional buffering.
        return false, nil
    }
    hs.signed[v.Replica] = v
    key := candidateKey{root: v.Checkpoint.StateRoot, epoch: v.Checkpoint.ConfigEpoch}
    cand := hs.candidates[key]
    if cand == nil {
        cand = &candidate{ckpt: v.Checkpoint, votes: make(map[ReplicaID]Vote)}
        hs.candidates[key] = cand
    }
    cand.votes[v.Replica] = v
    if len(cand.votes) >= quorum {
        cand.complete = true
    }
    return true, nil
}

// completeCandidates returns the candidates that reached quorum.
func (hs *heightState) completeCandidates() []*candidate {
    var out []*candidate
    for _, c := range hs.candidates {
        if c.complete {
            out = append(out, c)
        }
    }
    sort.Slice(out, func(i, j int) bool {
        if out[i].ckpt.StateRoot != out[j].ckpt.StateRoot {
            return bytesLess(out[i].ckpt.StateRoot[:], out[j].ckpt.StateRoot[:])
        }
        return out[i].ckpt.ConfigEpoch < out[j].ckpt.ConfigEpoch
    })
    return out
}

func bytesLess(a, b []byte) bool {
    for i := range a {
        if a[i] != b[i] {
            return a[i] < b[i]
        }
    }
    return false
}

// ---------------------------------------------------------------------------
// Coordinator
// ---------------------------------------------------------------------------

// Stats is a snapshot of the coordinator's buffered state.
type Stats struct {
    Heights    int // distinct heights buffered
    Candidates int // candidate tuples buffered across all heights
    Votes      int // accepted votes buffered (one per replica per height)
    Dropped    uint64
}

// Coordinator collects votes and selects a repair certificate. All methods are
// safe for concurrent use.
type Coordinator struct {
    cfg    Config
    verify Verifier

    mu      sync.Mutex
    view    uint64
    base    bool
    height  uint64
    root    [32]byte
    epoch   uint64
    pending map[uint64]*heightState
    order   []uint64 // ascending heights present in pending

    equivocations []Equivocation
    evidenceKeys  map[evidenceKey]struct{}
    dropped       uint64
}

// evidenceKey de-duplicates equivocation evidence: at most one proof is kept
// per (replica, height), no matter how many conflicting tuples it emits.
type evidenceKey struct {
    replica ReplicaID
    height  uint64
}

// New validates cfg and returns a coordinator with no committed base. Use
// Commit (or the optional seeding helper) before selecting certificates that
// must extend an existing checkpoint.
func New(cfg Config) (*Coordinator, error) {
    if cfg.N <= 0 || cfg.F < 0 || cfg.N < 3*cfg.F+1 {
        return nil, fmt.Errorf("%w: need N >= 3F+1, got N=%d F=%d", ErrBadConfig, cfg.N, cfg.F)
    }
    if cfg.Verifier == nil {
        return nil, fmt.Errorf("%w: nil verifier", ErrBadConfig)
    }
    cfg.withDefaults()
    return &Coordinator{
        cfg:          cfg,
        verify:       cfg.Verifier,
        pending:      make(map[uint64]*heightState),
        evidenceKeys: make(map[evidenceKey]struct{}),
    }, nil
}

// Config returns the effective configuration.
func (c *Coordinator) Config() Config { return c.cfg }

// SetView advances the coordinator's current view. It never moves backwards.
func (c *Coordinator) SetView(view uint64) {
    c.mu.Lock()
    defer c.mu.Unlock()
    if view > c.view {
        c.view = view
    }
}

// View returns the current view.
func (c *Coordinator) View() uint64 {
    c.mu.Lock()
    defer c.mu.Unlock()
    return c.view
}

// AddVote validates and buffers a vote. The returned bool reports whether the
// vote was newly accepted into a candidate. Errors are advisory: a vote can be
// safely dropped. Duplicate and stale votes return (false, nil).
func (c *Coordinator) AddVote(v Vote) (bool, error) {
    c.mu.Lock()
    defer c.mu.Unlock()

    if v.Checkpoint.Shard != c.cfg.Shard {
        c.dropped++
        return false, fmt.Errorf("%w: %d", ErrWrongShard, v.Checkpoint.Shard)
    }
    if v.View > c.view+c.cfg.MaxViewLag {
        c.dropped++
        return false, ErrFutureView
    }
    msg := SigningBytes(v.Checkpoint, v.View)
    if !c.verify.Verify(v.Replica, msg, v.Sig) {
        c.dropped++
        return false, ErrBadSignature
    }

    // Heights at or below the committed base are already resolved; a delayed or
    // replayed vote for them must not be buffered.
    if c.base && v.Checkpoint.Height <= c.height {
        return false, nil
    }
    // Heights too far in the future are dropped rather than queued, which keeps
    // the out-of-order buffer bounded.
    if v.Checkpoint.Height > c.height+c.cfg.Lookahead {
        c.dropped++
        return false, ErrFutureHeight
    }

    hs := c.pending[v.Checkpoint.Height]
    if hs == nil {
        if !c.makeRoomLocked(v.Checkpoint.Height) {
            c.dropped++
            return false, ErrOutOfWindow
        }
        hs = newHeightState(v.Checkpoint.Height)
        c.pending[v.Checkpoint.Height] = hs
        c.insertOrderLocked(v.Checkpoint.Height)
    }

    added, proof := hs.add(v, c.cfg.Quorum())
    if proof != nil {
        c.recordEvidenceLocked(*proof)
    }
    return added, nil
}

// recordEvidenceLocked stores equivocation evidence with a per-(replica,height)
// de-duplication key and a hard capacity, so evidence collection cannot grow
// without bound under a conflicting-tuple flood.
func (c *Coordinator) recordEvidenceLocked(e Equivocation) {
    key := evidenceKey{replica: e.Replica, height: e.Height}
    if _, ok := c.evidenceKeys[key]; ok {
        return
    }
    c.evidenceKeys[key] = struct{}{}
    c.equivocations = append(c.equivocations, e)
    if len(c.equivocations) > c.cfg.MaxEvidence {
        old := c.equivocations[0]
        c.equivocations = c.equivocations[1:]
        delete(c.evidenceKeys, evidenceKey{replica: old.Replica, height: old.Height})
    }
}

// makeRoomLocked enforces the height window. It evicts the lowest buffered
// height when the new height is newer; otherwise the new height is rejected so
// that newer heights are retained.
func (c *Coordinator) makeRoomLocked(h uint64) bool {
    if len(c.order) < c.cfg.Window {
        return true
    }
    low := c.order[0]
    if low >= h {
        return false
    }
    delete(c.pending, low)
    c.order = c.order[1:]
    return true
}

func (c *Coordinator) insertOrderLocked(h uint64) {
    i := sort.Search(len(c.order), func(i int) bool { return c.order[i] >= h })
    c.order = append(c.order, 0)
    copy(c.order[i+1:], c.order[i:])
    c.order[i] = h
}

// admissibleLocked applies the monotonicity and user-supplied admissibility
// rules to a candidate checkpoint.
func (c *Coordinator) admissibleLocked(ck Checkpoint) bool {
    if c.base {
        if ck.Height <= c.height {
            return false
        }
        // A configuration epoch must never move backwards: replaying an old
        // epoch's checkpoint would reinterpret newer state under an older
        // configuration.
        if ck.ConfigEpoch < c.epoch {
            return false
        }
    }
    if c.cfg.Admissible != nil && !c.cfg.Admissible(ck) {
        return false
    }
    return true
}

// SelectRepair returns the certificate for the newest admissible checkpoint
// currently buffered. It returns ok=false when no admissible quorum has formed.
//
// If two conflicting quorums are buffered at the same height the coordinator
// refuses to pick one and returns ErrConflictingQuorum. Under the f-fault
// assumption this branch is unreachable.
func (c *Coordinator) SelectRepair() (Certificate, bool, error) {
    c.mu.Lock()
    defer c.mu.Unlock()

    var (
        best     Certificate
        bestH    uint64
        found    bool
        conflict *Checkpoint
    )
    for _, h := range c.order {
        hs := c.pending[h]
        complete := hs.completeCandidates()
        switch {
        case len(complete) == 0:
            continue
        case len(complete) > 1:
            // Two quorums at one height contradict the fault assumption.
            dup := complete[0].ckpt
            conflict = &dup
            continue
        }
        ck := complete[0].ckpt
        if !c.admissibleLocked(ck) {
            continue
        }
        if !found || h > bestH {
            best = complete[0].certificate()
            bestH = h
            found = true
        }
    }
    if conflict != nil {
        return Certificate{}, false, fmt.Errorf("%w at height %d (%s)", ErrConflictingQuorum, conflict.Height, *conflict)
    }
    if !found {
        return Certificate{}, false, nil
    }
    return best, true, nil
}

// Commit installs a certificate as the coordinator's committed base and prunes
// everything at or below its height. Committing the same checkpoint twice is
// idempotent; committing a conflicting checkpoint at an equal or lower height
// is rejected.
func (c *Coordinator) Commit(cert Certificate) error {
    if err := VerifyCertificate(c.cfg, cert); err != nil {
        return err
    }
    c.mu.Lock()
    defer c.mu.Unlock()

    ck := cert.Checkpoint
    if c.base {
        if ck.Height < c.height {
            return fmt.Errorf("%w: %s < %d", ErrStaleCertificate, ck, c.height)
        }
        if ck.Height == c.height {
            if ck.StateRoot != c.root || ck.ConfigEpoch != c.epoch {
                return fmt.Errorf("%w: %s conflicts with committed root=%x epoch=%d",
                    ErrConflictingQuorum, ck, c.root[:4], c.epoch)
            }
            return nil
        }
        if ck.ConfigEpoch < c.epoch {
            return fmt.Errorf("%w: epoch regression %d < %d", ErrInadmissible, ck.ConfigEpoch, c.epoch)
        }
    }
    c.base = true
    c.height = ck.Height
    c.root = ck.StateRoot
    c.epoch = ck.ConfigEpoch
    c.pruneLocked()
    return nil
}

func (c *Coordinator) pruneLocked() {
    kept := c.order[:0]
    for _, h := range c.order {
        if h <= c.height {
            delete(c.pending, h)
            continue
        }
        kept = append(kept, h)
    }
    c.order = kept
}

// Committed returns the committed height, root, and epoch, and whether a base
// has been installed.
func (c *Coordinator) Committed() (height uint64, root [32]byte, epoch uint64, ok bool) {
    c.mu.Lock()
    defer c.mu.Unlock()
    return c.height, c.root, c.epoch, c.base
}

// Stats returns a snapshot of buffered state.
func (c *Coordinator) Stats() Stats {
    c.mu.Lock()
    defer c.mu.Unlock()
    s := Stats{Heights: len(c.pending), Dropped: c.dropped}
    for _, hs := range c.pending {
        s.Candidates += len(hs.candidates)
        s.Votes += len(hs.signed)
    }
    return s
}

// Equivocations returns a copy of the equivocation evidence collected so far.
// The list is de-duplicated per (replica, height) and capped at MaxEvidence.
func (c *Coordinator) Equivocations() []Equivocation {
    c.mu.Lock()
    defer c.mu.Unlock()
    return append([]Equivocation(nil), c.equivocations...)
}

// The honest root for a height is a deterministic function so tests can
// recompute it independently of the coordinator.
func honestRoot(h uint64) [32]byte {
    var r [32]byte
    r[0] = 0xA5
    r[1] = byte(h >> 8)
    r[2] = byte(h)
    return r
}

// TestSelectsNewestAdmissible verifies that selection resumes from the highest
// height, not merely the highest buffered height, and that a higher height with
// an unratified configuration epoch does not win over a lower admissible one.
func TestSelectsNewestAdmissible(t *testing.T) {
    var allowNewEpoch atomic.Bool
    admissible := func(ck Checkpoint) bool { return ck.ConfigEpoch <= 2 || allowNewEpoch.Load() }
    tn := newTestNet(t, 4, 1, admissible)
    c := mustNew(t, tn.cfg)

    specs := []struct {
        h     uint64
        epoch uint64
    }{{3, 1}, {6, 2}, {9, 3}}
    for _, s := range specs {
        for id := 0; id < 3; id++ { // 3 distinct replicas = quorum for N=4,F=1
            if _, err := c.AddVote(tn.sign(id, tn.ckpt(s.h, byte(s.h), s.epoch), 0)); err != nil {
                t.Fatalf("AddVote: %v", err)
            }
        }
    }

    cert, ok, err := c.SelectRepair()
    if err != nil {
        t.Fatalf("SelectRepair: %v", err)
    }
    if !ok || cert.Checkpoint.Height != 6 {
        t.Fatalf("expected newest admissible height 6, got ok=%v cert=%+v", ok, cert.Checkpoint)
    }

    // Ratify epoch 3: now height 9 becomes admissible and must win.
    allowNewEpoch.Store(true)
    cert, ok, err = c.SelectRepair()
    if err != nil {
        t.Fatalf("SelectRepair after ratify: %v", err)
    }
    if !ok || cert.Checkpoint.Height != 9 || cert.Checkpoint.ConfigEpoch != 3 {
        t.Fatalf("expected height 9 epoch 3, got ok=%v cert=%+v", ok, cert.Checkpoint)
    }
}

// TestEpochBindingPreventsMerge is the core equivocation test. All votes share
// the same state root and height but disagree on the configuration epoch. A
// root-only coordinator would merge them into a quorum; binding the epoch must
// leave every candidate below quorum.
func TestEpochBindingPreventsMerge(t *testing.T) {
    tn := newTestNet(t, 5, 1, nil) // quorum = 4
    c := mustNew(t, tn.cfg)

    const h = 10
    var root [32]byte
    root[0] = 0x77
    // Root-only accounting would see 5 distinct voters. Epoch-keyed
    // accounting sees candidates of size 3, 1, 1.
    c.AddVote(tn.sign(0, Checkpoint{Shard: tn.cfg.Shard, Height: h, StateRoot: root, ConfigEpoch: 1}, 0))
    c.AddVote(tn.sign(1, Checkpoint{Shard: tn.cfg.Shard, Height: h, StateRoot: root, ConfigEpoch: 1}, 0))
    c.AddVote(tn.sign(2, Checkpoint{Shard: tn.cfg.Shard, Height: h, StateRoot: root, ConfigEpoch: 1}, 0))
    c.AddVote(tn.sign(3, Checkpoint{Shard: tn.cfg.Shard, Height: h, StateRoot: root, ConfigEpoch: 2}, 0))
    c.AddVote(tn.sign(4, Checkpoint{Shard: tn.cfg.Shard, Height: h, StateRoot: root, ConfigEpoch: 3}, 0))

    if _, ok, err := c.SelectRepair(); err != nil || ok {
        t.Fatalf("epoch splitting must not form a quorum: ok=%v err=%v", ok, err)
    }

    // A genuine quorum on one epoch still forms in a fresh coordinator.
    c2 := mustNew(t, tn.cfg)
    for id := 0; id < 4; id++ {
        c2.AddVote(tn.sign(id, Checkpoint{Shard: tn.cfg.Shard, Height: h, StateRoot: root, ConfigEpoch: 1}, 0))
    }
    cert, ok, err := c2.SelectRepair()
    if err != nil || !ok {
        t.Fatalf("genuine quorum should form: ok=%v err=%v", ok, err)
    }
    if cert.Checkpoint.ConfigEpoch != 1 {
        t.Fatalf("wrong epoch selected: %d", cert.Checkpoint.ConfigEpoch)
    }
}

// TestEquivocationProof checks that a replica signing two different tuples at
// one height is detected, and that the duplicate is not counted toward the
// second candidate.
func TestEquivocationProof(t *testing.T) {
    tn := newTestNet(t, 4, 1, nil)
    c := mustNew(t, tn.cfg)

    if _, err := c.AddVote(tn.sign(0, tn.ckpt(h, 0x01, 1), 0)); err != nil {

        t.Fatalf("bad proof: %+v", eq[0])
    }
}

// TestCertificateVerification covers duplicate signers, mismatched tuples, bad
// signatures, short quorums, and valid certificates.
func TestCertificateVerification(t *testing.T) {
    tn := newTestNet(t, 4, 1, nil)
    ck := tn.ckpt(5, 0x11, 1)

    valid := Certificate{Checkpoint: ck, Votes: []Vote{
        tn.sign(0, ck, 0), tn.sign(1, ck, 0), tn.sign(2, ck, 0),
    }}
    if err := VerifyCertificate(tn.cfg, valid); err != nil {
        t.Fatalf("valid certificate rejected: %v", err)
    }

    dup := valid
    dup.Votes = []Vote{tn.sign(0, ck, 0), tn.sign(0, ck, 0), tn.sign(1, ck, 0)}
    if err := VerifyCertificate(tn.cfg, dup); !errors.Is(err, ErrBadCertificate) {
        t.Fatalf("duplicate signer not rejected: %v", err)
    }

    mixed := valid
    mixed.Votes = []Vote{tn.sign(0, ck, 0), tn.sign(1, ck, 0), tn.sign(2, tn.ckpt(5, 0x11, 2), 0)}
    if err := VerifyCertificate(tn.cfg, mixed); !errors.Is(err, ErrBadCertificate) {
        t.Fatalf("mixed tuple not rejected: %v", err)
    }

    bad := valid
    bad.Votes = []Vote{tn.sign(0, ck, 0), tn.sign(1, ck, 0), {Checkpoint: ck, Replica: 2, Sig: make([]byte, ed25519.SignatureSize)}}
    if err := VerifyCertificate(tn.cfg, bad); !errors.Is(err, ErrBadSignature) {
        t.Fatalf("bad signature not rejected: %v", err)
    }

    short := Certificate{Checkpoint: ck, Votes: []Vote{tn.sign(0, ck, 0), tn.sign(1, ck, 0)}}
    if err := VerifyCertificate(tn.cfg, short); !errors.Is(err, ErrBadCertificate) {
        t.Fatalf("short quorum not rejected: %v", err)
    }

    wrongShard := valid
    wrongShard.Checkpoint.Shard = 99
    if err := VerifyCertificate(tn.cfg, wrongShard); !errors.Is(err, ErrWrongShard) {
        t.Fatalf("wrong shard not rejected: %v", err)
    }
}

// TestCommitIdempotentAndStale checks commit pruning and stale/conflicting
// commit handling.
func TestCommitIdempotentAndStale(t *testing.T) {
    tn := newTestNet(t, 4, 1, nil)
    c := mustNew(t, tn.cfg)
    makeCert := func(h uint64, rb byte) Certificate {
        ck := tn.ckpt(h, rb, 1)
        return Certificate{Checkpoint: ck, Votes: []Vote{tn.sign(0, ck, 0), tn.sign(1, ck, 0), tn.sign(2, ck, 0)}}
    }
    cert5 := makeCert(5, 0x05)
    if err := c.Commit(cert5); err != nil {
        t.Fatalf("commit: %v", err)
    }
    if err := c.Commit(cert5); err != nil {
        t.Fatalf("idempotent commit: %v", err)
    }
    cert3 := makeCert(3, 0x03)
    if err := c.Commit(cert3); !errors.Is(err, ErrStaleCertificate) {
        t.Fatalf("stale commit not rejected: %v", err)
    }
    // Replaying height <= committed must not be buffered.
    added, err := c.AddVote(tn.sign(0, cert5.Checkpoint, 0))
    if err != nil || added {
        t.Fatalf("replay of committed height must be ignored: added=%v err=%v", added, err)
    }
    if s := c.Stats(); s.Heights != 0 {
        t.Fatalf("expected empty buffer after commit, got %+v", s)
    }
}

// TestBoundedBuffering feeds a large, adversarial, out-of-order stream and
// asserts the buffer never exceeds Window heights or Window*N accepted votes.
func TestBoundedBuffering(t *testing.T) {
    tn := newTestNet(t, 4, 1, nil)
    tn.cfg.Window = 8
    tn.cfg.Lookahead = 32
    c := mustNew(t, tn.cfg)

    rng := mrand.New(mrand.NewSource(20261013))
    const iterations = 20000
    maxVotes := tn.cfg.Window * tn.n
    for i := 0; i < iterations; i++ {
        h := uint64(1 + rng.Intn(5000)) // far outside the look-ahead often
        id := rng.Intn(tn.n)
        ck := Checkpoint{
            Shard:       tn.cfg.Shard,
            Height:      h,
            StateRoot:   [32]byte{byte(rng.Intn(256))},
            ConfigEpoch: uint64(1 + rng.Intn(3)),
        }
        v := tn.sign(id, ck, uint64(rng.Intn(3)))
        _, _ = c.AddVote(v)

        s := c.Stats()
        if s.Heights > tn.cfg.Window {
            t.Fatalf("iter %d: buffered %d heights > window %d", i, s.Heights, tn.cfg.Window)
        }
        if s.Votes > maxVotes {
            t.Fatalf("iter %d: buffered %d votes > bound %d", i, s.Votes, maxVotes)
        }
        if s.Candidates > tn.cfg.Window*tn.n {
            t.Fatalf("iter %d: buffered %d candidates > bound", i, s.Candidates)
        }
    }
}

// TestOutOfOrderAndReplay confirms that votes arriving out of order still form
// a certificate, that replays are ignored, and that old-view votes combine for
// the same tuple.
func TestOutOfOrderAndReplay(t *testing.T) {
    tn := newTestNet(t, 4, 1, nil)
    c := mustNew(t, tn.cfg)
    ck := tn.ckpt(12, 0x3C, 1)

    // Reverse order, all from different views, plus replays.
    votes := []Vote{
        tn.sign(2, ck, 1),
        tn.sign(1, ck, 0),
        tn.sign(0, ck, 0),
        tn.sign(2, ck, 2), // same tuple, newer view: not equivocation
    }
    for _, v := range votes {
        if _, err := c.AddVote(v); err != nil {
            t.Fatalf("AddVote: %v", err)
        }
    }
    if eq := c.Equivocations(); len(eq) != 0 {
        t.Fatalf("same tuple across views is not equivocation: %v", eq)
    }
    before := c.Stats()
    if _, err := c.AddVote(tn.sign(0, ck, 0)); err != nil { // replay
        t.Fatal(err)
    }
    if after := c.Stats(); after.Votes != before.Votes {
        t.Fatalf("replay changed buffer: before=%+v after=%+v", before, after)
    }

    cert, ok, err := c.SelectRepair()
    if err != nil || !ok {
        t.Fatalf("out-of-order quorum did not form: ok=%v err=%v", ok, err)
    }
    if !cert.Checkpoint.Equal(ck) {
        t.Fatalf("wrong checkpoint: %v", cert.Checkpoint)
    }
    if err := c.Commit(cert); err != nil {
        t.Fatal(err)
    }
    if _, ok, _ := c.SelectRepair(); ok {
        t.Fatal("no repair expected after commit")
    }
}

// TestSafetyRandomized runs many trials in which f Byzantine replicas
// equivocate arbitrarily and the honest quorum must always win. Every height's
// selected root must equal the honest root, and no conflicting quorum may be
// observed.
func TestSafetyRandomized(t *testing.T) {
    const (
        n     = 4
        f     = 1
        maxH  = 40
        trial = 120
    )
    for tr := 0; tr < trial; tr++ {
        tn := newTestNet(t, n, f, nil)
        c := mustNew(t, tn.cfg)
        rng := mrand.New(mrand.NewSource(int64(tr)))

        for h := uint64(1); h <= maxH; h++ {
            var votes []Vote
            // N-f = 3 honest replicas sign the honest tuple.
            for id := 0; id < n-f; id++ {
                ck := Checkpoint{Shard: tn.cfg.Shard, Height: h, StateRoot: honestRoot(h), ConfigEpoch: 1}
                votes = append(votes, tn.sign(id, ck, uint64(rng.Intn(3))))
                votes = append(votes, tn.sign(id, ck, uint64(rng.Intn(3)))) // replay
            }
            // The single Byzantine replica sprays distinct tuples.
            for k := 0; k < 4; k++ {
                ck := Checkpoint{
                    Shard:       tn.cfg.Shard,
                    Height:      h,
                    StateRoot:   [32]byte{byte(0xE0 + rng.Intn(16))},
                    ConfigEpoch: uint64(1 + rng.Intn(3)),
                }
                votes = append(votes, tn.sign(n-1, ck, uint64(rng.Intn(3))))
            }
            mrand.Shuffle(len(votes), func(i, j int) { votes[i], votes[j] = votes[j], votes[i] })
            addAll(t, c, votes)

            cert, ok, err := c.SelectRepair()
            if err != nil {
                t.Fatalf("trial %d height %d: SelectRepair: %v", tr, h, err)
            }
            if !ok {
                t.Fatalf("trial %d height %d: honest quorum did not form", tr, h)
            }
            if cert.Checkpoint.Height != h {
                t.Fatalf("trial %d: selected height %d, want %d", tr, cert.Checkpoint.Height, h)
            }
            if cert.Checkpoint.StateRoot != honestRoot(h) {
                t.Fatalf("trial %d height %d: selected Byzantine root %x", tr, h, cert.Checkpoint.StateRoot[:4])
            }
            if err := c.Commit(cert); err != nil {
                t.Fatalf("trial %d height %d: Commit: %v", tr, h, err)
            }
        }
    }
}

// TestEvidenceBounded checks that a flood of conflicting tuples cannot grow the
// evidence buffer without bound, and that evidence is de-duplicated per
// (replica, height).
func TestEvidenceBounded(t *testing.T) {
    tn := newTestNet(t, 4, 1, nil)
    tn.cfg.MaxEvidence = 4
    c := mustNew(t, tn.cfg)

    // Many conflicting tuples for one (replica, height): one proof only.
    h := uint64(1)
    for k := 0; k < 1000; k++ {
        c.AddVote(tn.sign(0, tn.ckpt(h, byte(k), uint64(k)), 0))
    }
    if got := len(c.Equivocations()); got != 1 {
        t.Fatalf("same (replica,height) flood produced %d proofs, want 1", got)
    }

    // Many heights: total evidence never exceeds MaxEvidence.
    for hh := uint64(2); hh < 1000; hh++ {
        c.AddVote(tn.sign(0, tn.ckpt(hh, 0x01, 1), 0))
        c.AddVote(tn.sign(0, tn.ckpt(hh, 0x02, 1), 1))
        if got := len(c.Equivocations()); got > tn.cfg.MaxEvidence {
            t.Fatalf("evidence buffer grew to %d > cap %d", got, tn.cfg.MaxEvidence)
        }
    }
}

What each test proves

Test Property verified
TestSelectsNewestAdmissible Picks the highest height whose config epoch is ratified, falling back below an unratified higher checkpoint; ratifying it promotes it.
TestEpochBindingPreventsMerge Same root + different epochs never merge into a quorum; a genuine same-epoch quorum still forms.
TestEquivocationProof A replica signing two tuples at one height is detected and the second is not counted.
TestCertificateVerification Duplicate signers, mixed tuples, bad signatures, short quorums, and wrong shards are rejected.
TestCommitIdempotentAndStale Re-commit is a no-op; stale commit is rejected; committed heights are pruned and not re-buffered.
TestBoundedBuffering 20,000 adversarial out-of-order messages never exceed Window heights / Window*N votes / Window*N candidates.
TestOutOfOrderAndReplay Out-of-order and cross-view votes form a certificate; exact replays do not change buffered state.
TestFutureWindowRejected Far-future heights and far-future views are dropped (ErrFutureHeight, ErrFutureView).
TestConflictingQuorumRefused Two disjoint complete candidates at one height produce ErrConflictingQuorum.
TestSafetyRandomized 120 trials × 40 heights with an arbitrary equivocating Byzantine replica: the honest root always wins and every height is committed correctly.
TestEvidenceBounded Equivocation evidence is de-duplicated per (replica, height) and capped at MaxEvidence.
TestOversizedCertificateRejected A certificate with more than N votes is rejected before heavy work.
TestSignersAndSorting Certificates expose distinct, sorted signer IDs.

Known non-goals / extension points

  • Networking, persistence, and gossip are out of scope; Certificate is self-contained so it can be serialized and shipped as-is.
  • The Admissible hook is where a deployment wires in "is this configuration epoch ratified by the reconfiguration certificate" checks.
  • Liveness across views is handled by allowing votes from any view to combine for the same tuple (the coordinator's own view only gates how far ahead a vote may be). A production layer would drive SetView from the consensus loop.
