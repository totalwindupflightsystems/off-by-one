SC-21 c.1 deterministic digest — import-cycle-safe canonical emitter

Root cause

SC-21 c.1 L300 requires a deterministic digest over the declared struct members. "Deterministic" has three independent requirements:

  1. Fixed member set — only the members enumerated by the spec may influence the digest.
  2. Canonical serialization — the preimage must be byte-stable across runs, Go versions, and map iteration order (sorted object keys, one escaping rule, no insignificant whitespace).
  3. Stable hashing — the final digest is sha256(canonicalPreimage).

The repository already has the canonical JSON encoder, but it lives in package wire, and wire imports target (it exposes the target-aware wire.EncodeRecord). Go forbids import cycles, so the obvious implementation:

// target/digest.go — DOES NOT COMPILE
import "example.com/sc21/wire"

func (r Record) Digest() string {
    b, _ := wire.EncodeRecord(r) // import cycle: target -> wire -> target
    ...
}

fails with:

package example.com/sc21/target
    imports example.com/sc21/wire from canon.go
    imports example.com/sc21/target: import cycle not allowed

Tempting shortcuts are also wrong:

  • json.Marshal(r) over the struct emits fields in struct declaration order, includes every field (so adding Extra silently moves the digest), and does not necessarily match the wire canonical rules.
  • Reflection with a skip-list skips fields but still does not guarantee canonical key ordering and silently picks up any future field unless the skip-list is maintained in lock-step.

So the cycle must be broken inside target, without losing byte-compatibility with the canonical encoder.

The fix

Put a local canonical emitter in target that hard-codes the declared members in canonical (sorted) order and applies the same ordering and escaping rules as wire. Because the member set is literal code, a future field cannot leak in. The deliberate copy is defended by tests, not by trust.

Two invariants make this safe:

  • Invariant A (canonical rules): wire.CanonicalJSON is pinned to encoding/json by a known-answer test.
  • Invariant B (equivalence): target's local emitter is pinned byte-for-byte to wire.EncodeRecord for arbitrary records.

target/record.go

package target

// Record is the persisted entity. Only the members enumerated in
// DeclaredMembers participate in the SC-21 c.1 digest.
type Record struct {
    ID      string
    Version int
    Name    string
    Tags    []string

    // Extra is deliberately NOT a declared digest member. Adding or
    // changing it must not move the digest.
    Extra string
}

// DeclaredMembers is the authoritative, ordered list of Record members
// covered by the SC-21 c.1 digest. It is sorted by canonical key order.
var DeclaredMembers = []string{"id", "name", "tags", "version"}

target/digest.go

package target

import (
    "crypto/sha256"
    "encoding/hex"
    "strconv"
    "unicode/utf8"
)

// canonical returns the canonical JSON preimage for the digest.
//
// This is a local copy of the wire canonical encoder's ordering and
// escaping rules. It cannot call wire.CanonicalJSON because package wire
// imports package target (import cycle). The copy is safe only because
// equivalence_test.go proves it byte-identical to wire for arbitrary records.
//
// The declared members are written by name in canonical (sorted) order.
// Because the member set is hard-coded, a field added to Record later
// can never silently enter the digest.
func (r Record) canonical() []byte {
    b := make([]byte, 0, 128)
    b = append(b, '{')

    b = appendString(b, "id")
    b = append(b, ':')
    b = appendString(b, r.ID)
    b = append(b, ',')

    b = appendString(b, "name")
    b = append(b, ':')
    b = appendString(b, r.Name)
    b = append(b, ',')

    b = appendString(b, "tags")
    b = append(b, ':')
    b = append(b, '[')
    for i, t := range r.Tags {
        if i > 0 {
            b = append(b, ',')
        }
        b = appendString(b, t)
    }
    b = append(b, ']')
    b = append(b, ',')

    b = appendString(b, "version")
    b = append(b, ':')
    b = strconv.AppendInt(b, int64(r.Version), 10)

    b = append(b, '}')
    return b
}

// CanonicalBytes returns the exact digest preimage. It is exported so the
// cross-package equivalence test can compare it with wire.EncodeRecord.
func (r Record) CanonicalBytes() []byte { return r.canonical() }

// Digest returns the lowercase hex SHA-256 of the canonical encoding of
// the declared members.
func (r Record) Digest() string {
    sum := sha256.Sum256(r.canonical())
    return hex.EncodeToString(sum[:])
}

// appendString mirrors encoding/json's string escaping, matching package
// wire's appendString byte-for-byte. (Full body in target/digest.go.)
func appendString(b []byte, s string) []byte { /* see file */ }

The appendString body is the one function that must stay identical in both packages. It handles ", \, the short escapes \n \r \t, control bytes as \u00XX, HTML escaping of < > & as \u003c \u003e \u0026, U+2028/U+2029 as \u2028/\u2029, and invalid UTF-8 as \ufffd — exactly encoding/json's rules. It is copied verbatim into wire/canon.go and target/digest.go.

Why not just call encoding/json from target?

That is a valid simplification iff the canonical rules are known to be encoding/json's defaults. It is not used as the primary fix because the wire canonical rules are allowed to differ from the standard library defaults (e.g. a future JCS/RFC-8785 profile that disables HTML escaping). Keeping the explicit local emitter makes that contract visible and testable. If the team pins the canonical rules to stdlib, replacing the local emitter with json.Marshal(map[string]any{...}) is equivalent and the same tests still pass.

Verification

1. Canonical encoder vs. the standard library (known-answer test)

wire/canon_test.go feeds objects exercising key ordering, string escapes, HTML escapes, line separators, UTF-8, slices and nesting, and requires wire.CanonicalJSON to equal json.Marshal byte-for-byte. It also asserts unsupported types are rejected instead of encoded non-deterministically.

2. Local emitter vs. the canonical encoder (the cycle guard)

target/equivalence_test.go lives in the external test package target_test, so it is allowed to import wire even though wire imports target. It checks target.Record.CanonicalBytes() against wire.EncodeRecord for empty, quoted/escaped, HTML, line-separator and invalid-UTF-8 records.

package target_test

import (
    "testing"

    "example.com/sc21/target"
    "example.com/sc21/wire"
)

func TestLocalEmitterMatchesWire(t *testing.T) {
    records := []target.Record{
        {},
        {ID: "r-1", Version: 1, Name: "alpha", Tags: []string{"x", "y"}},
        {ID: "q\"uote", Version: 42, Name: "<html>&\n\t", Tags: []string{"\u2028", "ok"}},
        {ID: "héllo → 世界", Version: -7, Name: "\x00\x1f", Tags: nil},
    }
    for i, r := range records {
        want, err := wire.EncodeRecord(r)
        if err != nil {
            t.Fatalf("record %d: wire.EncodeRecord: %v", i, err)
        }
        if got := r.CanonicalBytes(); string(got) != string(want) {
            t.Fatalf("record %d: local emitter != wire\n got: %s\nwant: %s", i, got, want)
        }
    }
}

3. Change-propagation table

target/digest_test.go proves every enumerated member moves the digest and the non-enumerated member does not:

Mutation Declared? Digest must move
ID yes yes
Version yes yes
Name yes yes
Tags yes yes
Extra no no

A third test walks DeclaredMembers and asserts each entry is actually covered by the emitter, so the list cannot drift from the code.

Guardrails for future changes

  • Add every new spec-mandated member to both DeclaredMembers and the literal emitter; TestDeclaredMembersMatchEncoder fails if you add only one.
  • Adding a non-spec field to Record requires no change and must not move the digest; TestDigestIgnoresNonDeclaredMembers fails if it does.
  • Any change to the wire canonical rules must be mirrored in target; the cross-package equivalence test fails on the first divergence.
  • Keep target's local appendString byte-identical to wire's. Do not "simplify" it to fmt.Sprintf("%q", s) — Go's verb escapes differently.
