go-mcp-jsonrpc-param-shape

Answer

The root cause: the tools/call params struct was decoded with encoding/json tags only for tool/input, so standard MCP clients sending {name, arguments} decoded to an empty tool name → 400 tool name is required.

The fix is a dual-shape ToolCallParams with a custom UnmarshalJSON that decodes both shapes in one pass, prefers name/arguments whenever either is present, falls back to tool/input, and returns ErrToolNameRequired only when both pairs are absent (including null/missing params):

// mcp/params.go
var ErrToolNameRequired = errors.New("tool name is required")

type ToolCallParams struct {
    Name      string          `json:"name"`
    Arguments json.RawMessage `json:"arguments,omitempty"`
}

// UnmarshalJSON accepts both shapes; standard (name, arguments) wins,
// legacy (tool, input) is the fallback, error only when both are absent.
func (p *ToolCallParams) UnmarshalJSON(data []byte) error {
    var wire struct {
        Name      string          `json:"name"`
        Arguments json.RawMessage `json:"arguments"`
        Tool      string          `json:"tool"`
        Input     json.RawMessage `json:"input"`
    }
    if err := json.Unmarshal(data, &wire); err != nil {
        return fmt.Errorf("decode tools/call params: %w", err)
    }
    if bytes.Equal(bytes.TrimSpace(data), []byte("null")) {
        return ErrToolNameRequired
    }
    *p = ToolCallParams{}
    switch {
    case wire.Name != "" || wire.Arguments != nil:
        p.Name, p.Arguments = wire.Name, wire.Arguments // standard — preferred
    case wire.Tool != "" || wire.Input != nil:
        p.Name, p.Arguments = wire.Tool, wire.Input     // legacy — fallback
    default:
        return ErrToolNameRequired
    }
    return nil
}

The handler surfaces it as a JSON-RPC invalid-params error (-32602, message "tool name is required"), and the HTTP layer maps that to HTTP 400:

// mcp/handler.go — Handle() excerpt
if err := json.Unmarshal(body, &req); err != nil {
    code := CodeParseError
    var syn *json.SyntaxError
    if !errors.As(err, &syn) {
        code = CodeInvalidParams
    }
    if errors.Is(err, ErrToolNameRequired) {
        code = CodeInvalidParams
        msg = ErrToolNameRequired.Error() // "tool name is required"
    }
    return Response{JSONRPC: "2.0", Error: &RPCError{Code: code, Message: msg}}
}
// HandleCall rejects an empty resolved name as defense-in-depth:
if params.Name == "" { return nil, ErrToolNameRequired }
