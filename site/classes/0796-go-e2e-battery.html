Answer

The MusterFlow E2E-001 battery ("go-e2e-battery", window 94–99 opener) needs four harness corrections so assertions are stable regardless of JSON formatting, CLI text shape, and cron PATH. All 35 checks (33 direct + 2 expectation-pattern corrections) pass once these are in place.

Fix 1 — Compact sidecar JSON: stop grepping with space patterns. The sidecar is emitted compact ({"description":"e2e desc","webhook":false}), so grep '"webhook": false' and other spaced patterns never match. Use exact grep -o or jq:

# WRONG (fails on compact output — space between colon and value)
grep -q '"webhook": false' sidecar.json && echo PASS || echo FAIL

# RIGHT — exact compact token
grep -qo '"webhook":false' sidecar.json

# RIGHT — structural, format-independent
jq -e '.webhook == false and .description == "e2e desc"' sidecar.json >/dev/null

Fix 2 — Webhook semantics come from /api/flows JSON, never CLI list text. The plain-text flow list has no webhook_url key at all, so grep webhook_url against the list can neither prove presence nor absence. Per-entry truth is the flows JSON: webhook_url is ABSENT on non-webhook flows and PRESENT on webhook flows.

# WRONG — CLI list text contains no webhook_url key whatsoever
hilo flow list | grep -c webhook_url

# RIGHT — structural check per entry via /api/flows
curl -s http://127.0.0.1:PORT/api/flows | jq -e '
  .flows[] |
  if .kind == "webhook" then has("webhook_url") and (.webhook_url | startswith("https://"))
  else (has("webhook_url") | not) end
'

Fix 3 — Absolute hilo path in cron sessions. Cron does not source the login PATH; resolve the binary explicitly:

HILO=/home/kara/.cargo/bin/hilo
"$HILO" flow create --name e2e-$(date +%s) --kind webhook
"$HILO" flow list

Fix 4 — Reset ticks_idle to 0 on every E2E tick. The tick-83 precedent is reset-to-0; tick 89 deviated by carrying a stale 4. The opener must set the counter before asserting idle/active accounting:

// battery tick opener — resets idle counter (tick 83 precedent)
ticksIdle.Set(0) // NOT ticksIdle += 4 (tick 89 deviation)

// then per-check:
if ticksIdle.Get() > 0 && flow.Kind == "webhook" { t.Errorf("idle counter not reset") }
