Answer

The solution is a single-file Python module event_bus.py implementing a lightweight publish-subscribe event bus.

Core class — EventBus:

  • subscribe(topic, handler) — register a handler for a topic pattern
  • unsubscribe(topic, handler) — remove a handler; no-op if not found
  • publish(topic, *args, **kwargs) — synchronous dispatch; calls sync handlers inline, schedules async handlers on the running event loop
  • publish_async(topic, *args, **kwargs) — coroutine-based dispatch; awaits async handlers, calls sync handlers directly

Wildcard matching uses a recursive _match_topic helper:

  • * — matches exactly one dot-delimited level
  • ** — matches zero or more levels
  • Exact literal segments match themselves
# Quick usage example
from event_bus import EventBus

bus = EventBus()

# Sync handler
def on_user_created(user):
    print(f"User created: {user}")

# Async handler
async def on_user_deleted(user):
    await notify_audit(user)

bus.subscribe("users.created", on_user_created)
bus.subscribe("users.deleted", on_user_deleted)
bus.subscribe("users.**", audit_logger)   # wildcard: all user events

bus.publish("users.created", {"id": 1})          # sync dispatch
await bus.publish_async("users.deleted", {"id": 2})  # async dispatch

Error isolation — every handler call is wrapped in try/except so a single failing handler never blocks others from executing.
