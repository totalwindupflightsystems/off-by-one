Answer

Everything is verified: go vet, go test, go test -race all pass. The complete solution has been written to ~/btree/SOLUTION.md. Here is the deliverable:

Fixing the go-btree-slotted-page-split-varlen-underflow fault

An on-disk B+tree with a slotted-page layout, variable-length keys, slot-array compaction, prefix-compressed interior keys, atomic splits with a minimum fill factor, exact sibling redistribution on delete, and an idempotent redo log. Verified against a sorted-map oracle with byte-level page invariants over a randomized insert/delete/scan workload.

1. Root-cause analysis

Every page is a fixed 1024-byte image (PageSize). Each page has a 24-byte header, a slot array growing up from the header, and a cell region growing down from the end. serializePage always rewrites cells contiguously and rebuilds the slot array, so compaction is a property of every write. Interior cells are prefix-compressed against the previous cell on the same page: cell i stores commonPrefixLen(prevKey, key) plus the suffix.

The fault class has two interacting causes:

Cause A — prefix compression makes cell size non-monotonic across a split

A naive interior split takes the median cell, pushes its key into the parent, and puts everything to its right on a new page. But interior page size is not the sum of independent cell sizes: a cell's size depends on the key before it. The first cell of the right-hand page previously shared a long prefix with the cell that stayed on the left. After the split it starts a new prefix chain, so it can become larger. A fixed median can therefore produce a right page that no longer fits (page image exceeds page size), while "move the split point to make it fit" can instead leave a page below the minimum fill. That is the split-varlen-underflow fault.

Cause B — in-place value growth bypassed the overflow check

Because values are variable length, Put on an existing key can replace a short value with a long one and push a leaf past PageSize. The update branch returned early after writing the value without checking fits, so the overflow was only discovered on the next write (or would corrupt the page in a different layout).

Related invariants

  • Splits and reapportionment must measure serialized size, because only that accounts for prefix compression.
  • Delete must not create underflow: merge when the concatenation fits, else redistribute exactly until the child reaches the fill threshold, never overfilling either side.
  • Redo must be idempotent: replaying a committed group twice must not change the store.

2. Exact fix

  1. splitInterior evaluates every candidate pivot, computes the actual standalone serialized size of each side (via the same cellBytes logic the writer uses), and picks the most balanced pivot for which both sides fit. If no balanced pivot fits, it falls back to any fitting pivot (degenerate but safe).
  2. put on an existing key updates the value and then falls through to the normal fits/splitLeaf path instead of returning early.

Delete already used fits-based decisions; it is included for completeness and to satisfy minimum-fill and exact-redistribution.

package btree

import (
    "encoding/binary"
    "fmt"
)

// Page geometry. A page is a fixed-size byte array on disk. It is a slotted
// page: a fixed header, then a slot array growing upward from headerSize, and a
// cell region growing downward from PageSize. The gap between freeStart
// (header+2*numSlots) and freeEnd (lowest cell byte) is free space. Serializing
// a page always rewrites cells contiguously from the top, i.e. it compacts the
// slot array and the cell region.
const (
    PageSize         = 1024
    headerSize       = 24
    pageTypeMeta     = 0
    pageTypeLeaf     = 1
    pageTypeInterior = 2
)

// Minimum number of used bytes (header + slots + cells) for any non-root page.
// Splits and sibling redistribution must keep both sides at or above this,
// otherwise the tree degenerates into a linked list of near-empty pages. This
// is the "minimum fill factor": PageSize/4.
const minFill = PageSize / 4

var le = binary.LittleEndian

// cell is the decoded form of one slotted-page entry.
//
// Leaf:     key + val
// Interior: key + child, where child is the sub-page immediately to the RIGHT
//           of key. The leftmost child lives in the page header. Prefix
//           compression is applied between consecutive interior keys.
type cell struct {
    key   []byte
    val   []byte
    child uint32
}

// page is the decoded representation. It is the canonical logical state; the
// byte layout is produced only by serializePage.
type page struct {
    id       uint32
    typ      byte
    lsn      uint32
    leftmost uint32 // interior only
    next     uint32 // leaf only
    cells    []cell
}

func commonPrefixLen(a, b []byte) int {
    n := len(a)
    if len(b) < n {
        n = len(b)
    }
    i := 0
    for i < n && a[i] == b[i] {
        i++
    }
    return i
}

func cellBytes(c cell, typ byte, prev []byte) []byte {
    if typ == pageTypeLeaf {
        b := make([]byte, 4+len(c.key)+len(c.val))
        le.PutUint16(b[0:], uint16(len(c.key)))
        le.PutUint16(b[2:], uint16(len(c.val)))
        copy(b[4:], c.key)
        copy(b[4+len(c.key):], c.val)
        return b
    }
    pre := commonPrefixLen(prev, c.key)
    suf := c.key[pre:]
    b := make([]byte, 8+len(suf))
    le.PutUint16(b[0:], uint16(pre))
    le.PutUint16(b[2:], uint16(len(suf)))
    le.PutUint32(b[4:], c.child)
    copy(b[8:], suf)
    return b
}

// usedBytes returns the exact on-disk footprint of the page.
func usedBytes(p *page) int {
    u := headerSize + 2*len(p.cells)
    var prev []byte
    for _, c := range p.cells {
        u += len(cellBytes(c, p.typ, prev))
        if p.typ == pageTypeInterior {
            prev = c.key
        }
    }
    return u
}

func fits(p *page) bool { return usedBytes(p) <= PageSize }

// serializePage produces the canonical byte image. It returns false if the
// logical page does not fit, without mutating the input.
func serializePage(p *page) ([]byte, bool) {
    buf := make([]byte, PageSize)
    buf[0] = p.typ
    le.PutUint16(buf[2:], uint16(len(p.cells)))
    le.PutUint32(buf[8:], p.lsn)
    le.PutUint32(buf[14:], p.leftmost)
    le.PutUint32(buf[18:], p.next)

    frame := headerSize + 2*len(p.cells) // first free byte (end of slot array)
    freeEnd := PageSize
    var prev []byte
    for i, c := range p.cells {
        cb := cellBytes(c, p.typ, prev)
        freeEnd -= len(cb)
        if freeEnd < frame {
            return nil, false
        }
        copy(buf[freeEnd:], cb)
        le.PutUint16(buf[headerSize+2*i:], uint16(freeEnd))
        if p.typ == pageTypeInterior {
            prev = c.key
        }
    }
    le.PutUint16(buf[4:], uint16(frame))
    le.PutUint16(buf[6:], uint16(freeEnd))
    return buf, true
}

func deserializePage(id uint32, buf []byte) *page {
    p := &page{id: id}
    p.typ = buf[0]
    n := int(le.Uint16(buf[2:]))
    p.lsn = le.Uint32(buf[8:])
    p.leftmost = le.Uint32(buf[14:])
    p.next = le.Uint32(buf[18:])
    var prev []byte
    for i := 0; i < n; i++ {
        off := int(le.Uint16(buf[headerSize+2*i:]))
        if p.typ == pageTypeLeaf {
            kl := int(le.Uint16(buf[off:]))
            vl := int(le.Uint16(buf[off+2:]))
            key := append([]byte(nil), buf[off+4:off+4+kl]...)
            val := append([]byte(nil), buf[off+4+kl:off+4+kl+vl]...)
            p.cells = append(p.cells, cell{key: key, val: val})
        } else {
            pre := int(le.Uint16(buf[off:]))
            sl := int(le.Uint16(buf[off+2:]))
            ch := le.Uint32(buf[off+4:])
            key := append(append([]byte(nil), prev[:pre]...), buf[off+8:off+8+sl]...)
            p.cells = append(p.cells, cell{key: key, child: ch})
            prev = key
        }
    }
    return p
}

// rawCellBounds returns the [start,end) byte range of slot i in a raw image.
func rawCellBounds(buf []byte, typ byte, i int) (int, int, error) {
    off := int(le.Uint16(buf[headerSize+2*i:]))
    if off < 0 || off >= PageSize {
        return 0, 0, fmt.Errorf("slot %d offset %d out of range", i, off)
    }
    if typ == pageTypeLeaf {
        kl := int(le.Uint16(buf[off:]))
        vl := int(le.Uint16(buf[off+2:]))
        end := off + 4 + kl + vl
        if end > PageSize {
            return 0, 0, fmt.Errorf("leaf cell %d overruns page", i)
        }
        return off, end, nil
    }
    sl := int(le.Uint16(buf[off+2:]))
    end := off + 8 + sl
    if end > PageSize {
        return 0, 0, fmt.Errorf("interior cell %d overruns page", i)
    }
    return off, end, nil
}

package btree

import (
    "fmt"
    "os"
)

// Pager is the durable page store. Page 0 is the metadata page; it stores the
// root page id.
type Pager interface {
    Read(id uint32) ([]byte, error)
    Write(id uint32, buf []byte) error
    Alloc() (uint32, error)
    Sync() error
}

// MemPager is an in-memory pager used by the tests. It models durable storage:
// a "crash" is simply stopping the application of page images.
type MemPager struct {
    pages map[uint32][]byte
    next  uint32
}

func NewMemPager() *MemPager {
    m := &MemPager{pages: map[uint32][]byte{}, next: 1}
    m.pages[0] = make([]byte, PageSize) // metadata page
    return m
}

func (m *MemPager) Read(id uint32) ([]byte, error) {
    b, ok := m.pages[id]
    if !ok {
        return nil, fmt.Errorf("page %d not allocated", id)
    }
    return append([]byte(nil), b...), nil
}

func (m *MemPager) Write(id uint32, buf []byte) error {
    if len(buf) != PageSize {
        return fmt.Errorf("bad page size %d", len(buf))
    }
    m.pages[id] = append([]byte(nil), buf...)
    return nil
}

func (m *MemPager) Alloc() (uint32, error) {
    id := m.next
    m.next++
    m.pages[id] = make([]byte, PageSize)
    return id, nil
}

func (m *MemPager) Sync() error { return nil }

// FilePager is a simple real on-disk pager. The file grows in PageSize units.
type FilePager struct {
    f    *os.File
    next uint32
}

func OpenFilePager(path string) (*FilePager, error) {
    f, err := os.OpenFile(path, os.O_RDWR|os.O_CREATE, 0o644)
    if err != nil {
        return nil, err
    }
    st, _ := f.Stat()
    n := uint32(st.Size() / PageSize)
    if n == 0 {
        n = 1
        if _, err := f.WriteAt(make([]byte, PageSize), 0); err != nil {
            return nil, err
        }
    }
    return &FilePager{f: f, next: n}, nil
}

func (fp *FilePager) Read(id uint32) ([]byte, error) {
    buf := make([]byte, PageSize)
    if _, err := fp.f.ReadAt(buf, int64(id)*PageSize); err != nil {
        return nil, err
    }
    return buf, nil
}

func (fp *FilePager) Write(id uint32, buf []byte) error {
    _, err := fp.f.WriteAt(buf, int64(id)*PageSize)
    return err
}

func (fp *FilePager) Alloc() (uint32, error) {
    id := fp.next
    fp.next++
    if _, err := fp.f.WriteAt(make([]byte, PageSize), int64(id)*PageSize); err != nil {
        return 0, err
    }
    return id, nil
}

func (fp *FilePager) Sync() error { return fp.f.Sync() }

func (fp *FilePager) Close() error { return fp.f.Close() }

wal.go

package btree

import (
    "encoding/binary"
    "sync"
)

// redoRec is a full-page after-image. Full images (rather than physical byte
// deltas) make replay trivially idempotent: applying the same image twice has
// the same effect as applying it once, and the per-page LSN guard lets a
// recovery pass skip pages that are already at or beyond the record.
type redoRec struct {
    LSN    uint32
    PageID uint32
    Image  []byte
}

type walGroup struct {
    txnID uint32
    recs  []redoRec
}

// WAL is a write-ahead log. A transaction is durable once Commit has been
// recorded. Replay only ever applies committed groups.
type WAL struct {
    mu        sync.Mutex
    groups    []walGroup
    nextTxn   uint32
    committed map[uint32]bool
}

func NewWAL() *WAL {
    return &WAL{nextTxn: 1, committed: map[uint32]bool{}}
}

func (w *WAL) NextTxnID() uint32 {
    w.mu.Lock()
    defer w.mu.Unlock()
    id := w.nextTxn
    w.nextTxn++
    return id
}

func (w *WAL) Append(t *txn) {
    w.mu.Lock()
    defer w.mu.Unlock()
    g := walGroup{txnID: t.id}
    for _, id := range t.order {
        g.recs = append(g.recs, t.recs[id])
    }
    w.groups = append(w.groups, g)
}

func (w *WAL) Commit(txnID uint32) {
    w.mu.Lock()
    defer w.mu.Unlock()
    w.committed[txnID] = true
}

// Recover replays all committed groups. It is idempotent: a page image is only
// written when the on-disk page LSN is strictly older. Running Recover twice
// leaves the store unchanged.
func (w *WAL) Recover(p Pager) error {
    w.mu.Lock()
    defer w.mu.Unlock()
    for _, g := range w.groups {
        if !w.committed[g.txnID] {
            continue
        }
        for _, r := range g.recs {
            cur, err := p.Read(r.PageID)
            if err != nil {
                cur = make([]byte, PageSize)
            }
            curLSN := binary.LittleEndian.Uint32(cur[8:])
            if curLSN < r.LSN {
                if err := p.Write(r.PageID, r.Image); err != nil {
                    return err
                }
            }
        }
    }
    return nil
}

// MaxLSN reports the highest LSN present in the log for a given page, used to
// resume LSN allocation after recovery.
func (w *WAL) MaxLSN() uint32 {
    w.mu.Lock()
    defer w.mu.Unlock()
    var m uint32
    for _, g := range w.groups {
        for _, r := range g.recs {
            if r.LSN > m {
                m = r.LSN
            }
        }
    }
    return m
}

btree.go

package btree

import (
    "bytes"
    "errors"
    "sort"
)

var (
    errPageOverflow = errors.New("btree: page image exceeds page size")
    errKeyTooLarge  = errors.New("btree: key/value too large to split")
)

type txn struct {
    id    uint32
    recs  map[uint32]redoRec
    order []uint32
}

func (t *txn) set(id uint32, r redoRec) {
    if _, ok := t.recs[id]; !ok {
        t.order = append(t.order, id)
    }
    t.recs[id] = r
}

// BTree is an on-disk B+tree. All logical durability goes through the WAL: a
// Put/Delete stages full-page images, appends them to the WAL, records the
// commit, and only then applies them to the pager. A crash at any point is
// repaired by replaying the committed images.
type BTree struct {
    pager   Pager
    wal     *WAL
    root    uint32
    nextLSN uint32
    txn     *txn

    // applyHook, when non-nil, decides whether commit is allowed to write a
    // page to the pager. Tests use it to simulate a crash mid-apply.
    applyHook func(pageID uint32) bool
}

func New(p Pager, w *WAL) (*BTree, error) {
    t := &BTree{pager: p, wal: w, nextLSN: w.MaxLSN() + 1}
    meta, _ := t.pager.Read(0)
    t.root = le.Uint32(meta[4:])
    if t.root == 0 {
        if err := t.begin(); err != nil {
            return nil, err
        }
        id, err := t.pager.Alloc()
        if err != nil {
            return nil, err
        }
        leaf := &page{id: id, typ: pageTypeLeaf}
        if err := t.stage(leaf); err != nil {
            return nil, err
        }
        if err := t.stageMeta(id); err != nil {
            return nil, err
        }
        t.root = id
        if err := t.commit(); err != nil {
            return nil, err
        }
    }
    return t, nil
}

func (t *BTree) Root() uint32 { return t.root }

func (t *BTree) nextID() uint32 {
    t.nextLSN++
    return t.nextLSN
}

func (t *BTree) begin() error {
    t.txn = &txn{id: t.wal.NextTxnID(), recs: map[uint32]redoRec{}}
    return nil
}

func (t *BTree) abort() { t.txn = nil }

func (t *BTree) commit() error {
    cur := t.txn
    t.wal.Append(cur)
    t.wal.Commit(cur.id)
    for _, id := range cur.order {
        if t.applyHook != nil && !t.applyHook(id) {
            continue // simulated crash: leave page un-applied
        }
        if err := t.pager.Write(id, cur.recs[id].Image); err != nil {
            return err
        }
    }
    t.txn = nil
    return nil
}

func (t *BTree) stage(p *page) error {
    lsn := t.nextID()
    p.lsn = lsn
    img, ok := serializePage(p)
    if !ok {
        return errPageOverflow
    }
    t.txn.set(p.id, redoRec{LSN: lsn, PageID: p.id, Image: img})
    return nil
}

func (t *BTree) stageMeta(root uint32) error {
    lsn := t.nextID()
    buf := make([]byte, PageSize)
    buf[0] = pageTypeMeta
    le.PutUint32(buf[4:], root)
    le.PutUint32(buf[8:], lsn)
    t.txn.set(0, redoRec{LSN: lsn, PageID: 0, Image: buf})
    return nil
}

// load returns the current logical state of a page, honoring not-yet-applied
// images staged in the active transaction.
func (t *BTree) load(id uint32) *page {
    if t.txn != nil {
        if r, ok := t.txn.recs[id]; ok {
            return deserializePage(id, r.Image)
        }
    }
    buf, _ := t.pager.Read(id)
    return deserializePage(id, buf)
}

func childIndexOf(p *page, key []byte) int {
    return sort.Search(len(p.cells), func(i int) bool {
        return bytes.Compare(p.cells[i].key, key) > 0
    })
}

func childAt(p *page, ci int) uint32 {
    if ci == 0 {
        return p.leftmost
    }
    return p.cells[ci-1].child
}

func abs(x int) int {
    if x < 0 {
        return -x
    }
    return x
}

// ---------------- Insert ----------------

func (t *BTree) Put(key, val []byte) error {
    if len(key) == 0 {
        return errors.New("btree: empty key not supported")
    }
    if err := t.begin(); err != nil {
        return err
    }
    push, right, split, err := t.put(t.root, key, val)
    if err != nil {
        t.abort()
        return err
    }
    if split {
        nid, err := t.pager.Alloc()
        if err != nil {
            t.abort()
            return err
        }
        np := &page{id: nid, typ: pageTypeInterior, leftmost: t.root,
            cells: []cell{{key: push, child: right}}}
        if err := t.stage(np); err != nil {
            t.abort()
            return err
        }
        if err := t.stageMeta(nid); err != nil {
            t.abort()
            return err
        }
        t.root = nid
    }
    return t.commit()
}

func (t *BTree) put(pid uint32, key, val []byte) ([]byte, uint32, bool, error) {
    p := t.load(pid)
    if p.typ == pageTypeLeaf {
        i := sort.Search(len(p.cells), func(i int) bool {
            return bytes.Compare(p.cells[i].key, key) >= 0
        })
        if i < len(p.cells) && bytes.Equal(p.cells[i].key, key) {
            // An in-place value update can enlarge a variable-length slab past
            // the page size; it must go through the same split path.
            p.cells[i].val = append([]byte(nil), val...)
        } else {
            p.cells = append(p.cells, cell{})
            copy(p.cells[i+1:], p.cells[i:])
            p.cells[i] = cell{key: append([]byte(nil), key...), val: append([]byte(nil), val...)}
        }
        if fits(p) {
            return nil, 0, false, t.stage(p)
        }
        _, right, err := t.splitLeaf(p)
        if err != nil {
            return nil, 0, false, err
        }
        return right.cells[0].key, right.id, true, nil
    }

    ci := childIndexOf(p, key)
    push, right, split, err := t.put(childAt(p, ci), key, val)
    if err != nil {
        return nil, 0, false, err
    }
    if !split {
        return nil, 0, false, nil
    }
    p.cells = append(p.cells, cell{})
    copy(p.cells[ci+1:], p.cells[ci:])
    p.cells[ci] = cell{key: push, child: right}
    if fits(p) {
        return nil, 0, false, t.stage(p)
    }
    return t.splitInterior(p)
}

// splitLeaf splits an overflowing leaf into two leaves and links them. The two
// writes belong to the same transaction as the parent update, so the split is
// atomic from the point of view of recovery.
func (t *BTree) splitLeaf(p *page) (*page, *page, error) {
    n := len(p.cells)
    if n < 2 {
        return nil, nil, errKeyTooLarge
    }
    sizes := make([]int, n)
    total := 0
    for i, c := range p.cells {
        sizes[i] = len(cellBytes(c, pageTypeLeaf, nil))
        total += sizes[i]
    }
    best, bestDiff := 1, 1<<62
    lsum := 0
    for i := 1; i < n; i++ {
        lsum += sizes[i-1]
        if d := abs(2*lsum - total); d < bestDiff {
            bestDiff, best = d, i
        }
    }
    oldNext := p.next
    nid, err := t.pager.Alloc()
    if err != nil {
        return nil, nil, err
    }
    left := &page{id: p.id, typ: pageTypeLeaf, next: nid,
        cells: append([]cell(nil), p.cells[:best]...)}
    right := &page{id: nid, typ: pageTypeLeaf, next: oldNext,
        cells: append([]cell(nil), p.cells[best:]...)}
    if err := t.stage(left); err != nil {
        return nil, nil, err
    }
    if err := t.stage(right); err != nil {
        return nil, nil, err
    }
    return left, right, nil
}

// splitInterior pushes a separator up to the parent. Prefix compression makes
// the byte size of a cell depend on its predecessor, so removing the boundary
// cell can make the right-hand page LARGER than it was. The pivot is therefore
// chosen by measuring the actual serialized size of each candidate partition,
// not by a fixed median. This is the core fix for the varlen split underflow /
// overflow fault.
func (t *BTree) splitInterior(p *page) ([]byte, uint32, bool, error) {
    n := len(p.cells)
    if n < 2 {
        return nil, 0, false, errKeyTooLarge
    }

    // Prefix-compressed size of a run of interior cells standing alone.
    runSize := func(cells []cell) int {
        u := headerSize + 2*len(cells)
        var prev []byte
        for _, c := range cells {
            u += len(cellBytes(c, pageTypeInterior, prev))
            prev = c.key
        }
        return u
    }

    bestMid := -1
    bestDiff := 1 << 62
    for mid := 1; mid <= n-2; mid++ { // keep both sides non-empty
        ls := runSize(p.cells[:mid])
        rs := runSize(p.cells[mid+1:])
        if ls > PageSize || rs > PageSize {
            continue
        }
        if d := abs(ls - rs); d < bestDiff {
            bestDiff, bestMid = d, mid
        }
    }
    if bestMid < 0 {
        // No balanced pivot fits (pathologically large keys): pick any pivot
        // whose two sides each fit, even if one side is empty.
        for mid := 0; mid <= n-1; mid++ {
            if runSize(p.cells[:mid]) <= PageSize && runSize(p.cells[mid+1:]) <= PageSize {
                bestMid = mid
                break
            }
        }
    }
    if bestMid < 0 {
        return nil, 0, false, errKeyTooLarge
    }
    mid := bestMid

    push := append([]byte(nil), p.cells[mid].key...)
    nid, err := t.pager.Alloc()
    if err != nil {
        return nil, 0, false, err
    }
    right := &page{id: nid, typ: pageTypeInterior, leftmost: p.cells[mid].child,
        cells: append([]cell(nil), p.cells[mid+1:]...)}
    p.cells = p.cells[:mid]
    // p keeps its original leftmost.
    if !fits(p) || !fits(right) {
        return nil, 0, false, errKeyTooLarge
    }
    if err := t.stage(p); err != nil {
        return nil, 0, false, err
    }
    if err := t.stage(right); err != nil {
        return nil, 0, false, err
    }
    return push, nid, true, nil
}

// ---------------- Delete ----------------

func (t *BTree) Delete(key []byte) error {
    if err := t.begin(); err != nil {
        return err
    }
    deleted, err := t.del(t.root, key)
    if err != nil {
        t.abort()
        return err
    }
    if deleted {
        root := t.load(t.root)
        if root.typ == pageTypeInterior && len(root.cells) == 0 {
            if err := t.stageMeta(root.leftmost); err != nil {
                t.abort()
                return err
            }
            t.root = root.leftmost
        }
    }
    return t.commit()
}

func (t *BTree) del(pid uint32, key []byte) (bool, error) {
    p := t.load(pid)
    if p.typ == pageTypeLeaf {
        i := sort.Search(len(p.cells), func(i int) bool {
            return bytes.Compare(p.cells[i].key, key) >= 0
        })
        if i >= len(p.cells) || !bytes.Equal(p.cells[i].key, key) {
            return false, nil
        }
        p.cells = append(p.cells[:i], p.cells[i+1:]...)
        return true, t.stage(p)
    }
    ci := childIndexOf(p, key)
    deleted, err := t.del(childAt(p, ci), key)
    if err != nil || !deleted {
        return deleted, err
    }
    child := t.load(childAt(p, ci))
    if usedBytes(child) < minFill {
        if err := t.fixChild(p, ci); err != nil {
            return false, err
        }
    }
    return true, t.stage(p)
}

// fixChild repairs an underflowing child by (in order of preference) merging
// with a sibling when the combined cells fit, or exactly redistributing cells
// with a sibling. All page edits stay in the transaction, so the repair is
// atomic with the delete that triggered it.
func (t *BTree) fixChild(p *page, ci int) error {
    n := len(p.cells)
    rightOK := ci < n
    leftOK := ci > 0

    child := t.load(childAt(p, ci))

    // Merge if the concatenation fits on one page.
    if rightOK {
        r := t.load(p.cells[ci].child)
        if merged, ok := mergePages(child, r, p.cells[ci]); ok {
            if err := t.doMerge(child, merged); err != nil {
                return err
            }
            p.cells = append(p.cells[:ci], p.cells[ci+1:]...)
            return nil
        }
    }
    if leftOK {
        l := t.load(p.cells[ci-1].child)
        if merged, ok := mergePages(l, child, p.cells[ci-1]); ok {
            if err := t.doMerge(l, merged); err != nil {
                return err
            }
            // remove separator ci-1
            p.cells = append(p.cells[:ci-1], p.cells[ci:]...)
            return nil
        }
    }

    // Otherwise redistribute. Because merging did not fit, the two pages hold
    // more than one page of cells, so a split point with both sides above the
    // minimum fill exists; the loop below finds it exactly.
    if rightOK {
        r := t.load(p.cells[ci].child)
        t.redistributeRight(p, ci, child, r)
        return nil
    }
    if leftOK {
        l := t.load(p.cells[ci-1].child)
        t.redistributeLeft(p, ci, l, child)
        return nil
    }
    return nil
}

func mergePages(a, b *page, sep cell) (*page, bool) {
    m := &page{typ: a.typ, cells: append(append([]cell(nil), a.cells...), b.cells...)}
    if a.typ == pageTypeLeaf {
        m.next = b.next
    } else {
        m.leftmost = a.leftmost
        // Insert the separator between the two cell runs.
        mid := append([]cell(nil), a.cells...)
        mid = append(mid, cell{key: append([]byte(nil), sep.key...), child: b.leftmost})
        mid = append(mid, b.cells...)
        m.cells = mid
    }
    if !fits(m) {
        return nil, false
    }
    return m, true
}

func (t *BTree) doMerge(into, merged *page) error {
    into.cells = merged.cells
    into.next = merged.next
    into.leftmost = merged.leftmost
    return t.stage(into)
}

func (t *BTree) redistributeRight(p *page, ci int, child, r *page) {
    if child.typ == pageTypeLeaf {
        for usedBytes(child) < minFill && len(r.cells) > 1 {
            c := r.cells[0]
            r.cells = r.cells[1:]
            child.cells = append(child.cells, c)
        }
        if len(r.cells) > 0 {
            p.cells[ci].key = append([]byte(nil), r.cells[0].key...)
        }
        _ = t.stage(child)
        _ = t.stage(r)
        return
    }
    // Interior rotation: parent separator moves down, right's first key moves up.
    for usedBytes(child) < minFill && len(r.cells) > 0 {
        sep := p.cells[ci]
        rFirst := r.cells[0]
        oldChild, oldRCells, oldRLeft, oldPCell := clonePage(child), append([]cell(nil), r.cells...), r.leftmost, p.cells[ci]

        child.cells = append(child.cells, cell{key: append([]byte(nil), sep.key...), child: r.leftmost})
        p.cells[ci] = cell{key: append([]byte(nil), rFirst.key...), child: rFirst.child}
        r.leftmost = rFirst.child
        r.cells = r.cells[1:]
        if !fits(child) || !fits(r) {
            // revert
            child.cells, child.leftmost = oldChild.cells, oldChild.leftmost
            r.cells, r.leftmost = oldRCells, oldRLeft
            p.cells[ci] = oldPCell
            break
        }
    }
    _ = t.stage(child)
    _ = t.stage(r)
}

func (t *BTree) redistributeLeft(p *page, ci int, l, child *page) {
    if child.typ == pageTypeLeaf {
        for usedBytes(child) < minFill && len(l.cells) > 1 {
            c := l.cells[len(l.cells)-1]
            l.cells = l.cells[:len(l.cells)-1]
            child.cells = append([]cell{c}, child.cells...)
        }
        if len(child.cells) > 0 {
            p.cells[ci-1].key = append([]byte(nil), child.cells[0].key...)
        }
        _ = t.stage(child)
        _ = t.stage(l)
        return
    }
    for usedBytes(child) < minFill && len(l.cells) > 0 {
        sep := p.cells[ci-1]
        last := l.cells[len(l.cells)-1]
        oldChild, oldLCells, oldLLeft, oldPCell := clonePage(child), append([]cell(nil), l.cells...), l.leftmost, p.cells[ci-1]

        child.cells = append([]cell{{key: append([]byte(nil), sep.key...), child: child.leftmost}}, child.cells...)
        child.leftmost = last.child
        p.cells[ci-1] = cell{key: append([]byte(nil), last.key...), child: sep.child}
        l.cells = l.cells[:len(l.cells)-1]
        if !fits(child) || !fits(l) {
            child.cells, child.leftmost = oldChild.cells, oldChild.leftmost
            l.cells, l.leftmost = oldLCells, oldLLeft
            p.cells[ci-1] = oldPCell
            break
        }
    }
    _ = t.stage(child)
    _ = t.stage(l)
}

func clonePage(p *page) *page {
    q := *p
    q.cells = append([]cell(nil), p.cells...)
    return &q
}

// ---------------- Scan / Get ----------------

func (t *BTree) Get(key []byte) ([]byte, bool) {
    id := t.root
    for {
        p := t.load(id)
        if p.typ == pageTypeLeaf {
            i := sort.Search(len(p.cells), func(i int) bool {
                return bytes.Compare(p.cells[i].key, key) >= 0
            })
            if i < len(p.cells) && bytes.Equal(p.cells[i].key, key) {
                return append([]byte(nil), p.cells[i].val...), true
            }
            return nil, false
        }
        id = childAt(p, childIndexOf(p, key))
    }
}

func (t *BTree) Scan(fn func(k, v []byte) bool) {
    id := t.root
    for {
        p := t.load(id)
        if p.typ == pageTypeLeaf {
            break
        }
        id = p.leftmost
    }
    for id != 0 {
        p := t.load(id)
        for _, c := range p.cells {
            if !fn(c.key, c.val) {
                return
            }
        }
        id = p.next
    }
}

func TestRandomWorkload(t *testing.T) {

        t.Fatal(err)

        n := 1 + rng.Intn(16)
        buf := make([]byte, n)

        }
        return string(buf)

        for i := range buf {

        }
        return string(buf)

func TestCrashRecoveryIdempotent(t *testing.T) {
    pager := NewMemPager()
    wal := NewWAL()
    b, err := New(pager, wal)
    if err != nil {
        t.Fatal(err)
    }
    oracle := map[string]string{}
    for i := 0; i < 400; i++ {
        k := fmt.Sprintf("k%04d", i)
        v := fmt.Sprintf("v%04d", i*7)
        if err := b.Put([]byte(k), []byte(v)); err != nil {
            t.Fatal(err)
        }
        oracle[k] = v
    }
    // Simulate a crash: commit the next transaction to the WAL but apply only
    // every other page image.
    b.applyHook = func(id uint32) bool { return id%2 == 0 }
    if err := b.Put([]byte("crash-key"), []byte("crash-val")); err != nil {
        t.Fatal(err)
    }
    oracle["crash-key"] = "crash-val"
    b.applyHook = nil

    if err := wal.Recover(pager); err != nil {
        t.Fatal(err)
    }
    snap1 := dumpPager(pager)
    // Replay again: must be a no-op.
    if err := wal.Recover(pager); err != nil {
        t.Fatal(err)
    }
    snap2 := dumpPager(pager)
    if !bytes.Equal(snap1, snap2) {
        t.Fatal("recovery is not idempotent")
    }

    // Reopen and verify logical state against the oracle.
    b2, err := New(pager, wal)
    if err != nil {
        t.Fatal(err)
    }
    checkAll(t, b2, oracle)
}

// ---- verification helpers ----

func reachable(b *BTree) map[uint32]bool {
    seen := map[uint32]bool{}
    var walk func(id uint32)
    walk = func(id uint32) {
        if seen[id] {
            return
        }
        seen[id] = true
        p := b.load(id)
        if p.typ == pageTypeInterior {
            walk(p.leftmost)
            for _, c := range p.cells {
                walk(c.child)
            }
        }
    }
    walk(b.root)
    return seen
}

func dumpPager(p *MemPager) []byte {
    ids := make([]int, 0, len(p.pages))
    for id := range p.pages {
        ids = append(ids, int(id))
    }
    sort.Ints(ids)
    var out bytes.Buffer
    for _, id := range ids {
        out.Write(p.pages[uint32(id)])
    }
    return out.Bytes()
}

func checkAll(t *testing.T, b *BTree, oracle map[string]string) {
    t.Helper()
    checkRawPages(t, b)
    leaves := checkOrderAndFill(t, b)
    // Oracle comparison over the leaf chain.
    got := map[string]string{}
    for _, kv := range leaves {
        got[string(kv[0])] = string(kv[1])
    }
    if len(got) != len(oracle) {
        t.Fatalf("size mismatch: tree=%d oracle=%d", len(got), len(oracle))
    }
    for k, v := range oracle {
        if g, ok := got[k]; !ok || g != v {
            t.Fatalf("oracle mismatch for %q: got %q ok=%v want %q", k, g, ok, v)
        }
    }
    // Scan must agree with the oracle and be ordered.
    var prev []byte
    count := 0
    b.Scan(func(k, v []byte) bool {
        if prev != nil && bytes.Compare(prev, k) >= 0 {
            t.Fatalf("scan out of order: %q >= %q", prev, k)
        }
        prev = append([]byte(nil), k...)
        count++
        return true
    })
    if count != len(oracle) {
        t.Fatalf("scan count %d != oracle %d", count, len(oracle))
    }
}

// checkRawPages verifies byte-level slotted-page invariants on every reachable
// page: header consistency, slot bounds, no cell overlap, compaction and a
// byte-exact serialize/deserialize round trip.
func checkRawPages(t *testing.T, b *BTree) {
    t.Helper()
    for id := range reachable(b) {
        buf, err := b.pager.Read(id)
        if err != nil {
            t.Fatalf("read page %d: %v", id, err)
        }
        typ := buf[0]
        n := int(le.Uint16(buf[2:]))
        freeStart := int(le.Uint16(buf[4:]))
        freeEnd := int(le.Uint16(buf[6:]))
        if freeStart != headerSize+2*n {
            t.Fatalf("page %d: freeStart %d != header+2n %d", id, freeStart, headerSize+2*n)
        }
        if freeEnd > PageSize || freeStart > freeEnd {
            t.Fatalf("page %d: bad free region [%d,%d)", id, freeStart, freeEnd)
        }
        type rng struct{ s, e int }
        var rs []rng
        minOff := PageSize
        for i := 0; i < n; i++ {
            off := int(le.Uint16(buf[headerSize+2*i:]))
            if off < freeEnd || off >= PageSize {
                t.Fatalf("page %d slot %d offset %d outside cell region [%d,%d)", id, i, off, freeEnd, PageSize)
            }
            if off < minOff {
                minOff = off
            }
            s, e, err := rawCellBounds(buf, typ, i)
            if err != nil {
                t.Fatalf("page %d: %v", id, err)
            }
            rs = append(rs, rng{s, e})
        }
        if n > 0 && freeEnd != minOff {
            t.Fatalf("page %d not compacted: freeEnd %d minOffset %d", id, freeEnd, minOff)
        }
        if n == 0 && freeEnd != PageSize {
            t.Fatalf("page %d empty but freeEnd %d", id, freeEnd)
        }
        sort.Slice(rs, func(i, j int) bool { return rs[i].s < rs[j].s })
        for i := 1; i < len(rs); i++ {
            if rs[i-1].e > rs[i].s {
                t.Fatalf("page %d cells overlap: [%d,%d) and [%d,%d)", id, rs[i-1].s, rs[i-1].e, rs[i].s, rs[i].e)
            }
        }
        p := deserializePage(id, buf)
        img, ok := serializePage(p)
        if !ok {
            t.Fatalf("page %d does not re-serialize", id)
        }
        if !bytes.Equal(buf, img) {
            t.Fatalf("page %d round-trip mismatch", id)
        }
    }
}

// checkOrderAndFill recursively verifies key ordering and the minimum fill
// invariant, and returns the leaf cells in order.
func checkOrderAndFill(t *testing.T, b *BTree) [][2][]byte {
    t.Helper()
    var leaves [][2][]byte
    var walk func(id uint32, lo, hi []byte)
    walk = func(id uint32, lo, hi []byte) {
        p := b.load(id)
        if id != b.root && usedBytes(p) < minFill {
            t.Fatalf("page %d underflows: used=%d < minFill=%d", id, usedBytes(p), minFill)
        }
        if p.typ == pageTypeLeaf {
            for i, c := range p.cells {
                if i > 0 && bytes.Compare(p.cells[i-1].key, c.key) >= 0 {
                    t.Fatalf("leaf %d keys not increasing", id)
                }
                if lo != nil && bytes.Compare(c.key, lo) < 0 {
                    t.Fatalf("leaf %d key %q below lower bound %q", id, c.key, lo)
                }
                if hi != nil && bytes.Compare(c.key, hi) >= 0 {
                    t.Fatalf("leaf %d key %q above upper bound %q", id, c.key, hi)
                }
                leaves = append(leaves, [2][]byte{c.key, c.val})
            }
            return
        }
        n := len(p.cells)
        for j := 0; j <= n; j++ {
            l, h := lo, hi
            if j > 0 {
                l = maxKey(lo, p.cells[j-1].key)
            }
            if j < n {
                h = minKey(hi, p.cells[j].key)
            }
            walk(childAt(p, j), l, h)
        }
    }
    walk(b.root, nil, nil)
    return leaves
}

func maxKey(a, b []byte) []byte {
    if a == nil {
        return b
    }
    if bytes.Compare(a, b) >= 0 {
        return a
    }
    return b
}

func minKey(a, b []byte) []byte {
    if a == nil {
        return b
    }
    if bytes.Compare(a, b) <= 0 {
        return a
    }
    return b
}

3. Verification

Build and run:

cd btree
go vet ./...
go test -count=1 -v ./...
go test -race -count=1 ./...

The suite proves:

  1. Oracle equivalence. TestRandomWorkload (6000 ops, seed 42) and TestManySeeds (25 seeds × 4000 ops) apply random Put/Delete to the tree and a map[string]string, then compare every key/value and a full Scan.
  2. Byte-level page invariants. checkRawPages walks every reachable page and asserts: freeStart == headerSize + 2*numSlots; freeStart <= freeEnd <= PageSize; every slot offset lies in the cell region; no two cells overlap; freeEnd equals the minimum cell offset (slot-array compaction); and a byte-exact deserialize→serialize round trip. checkOrderAndFill additionally asserts sorted keys, correct separator bounds on every subtree, and usedBytes >= minFill for every non-root page.
  3. Minimum fill factor. The fill assertion runs after every checked operation, so every split and every delete-induced merge/redistribution keeps non-root pages above PageSize/4.
  4. Crash recovery is idempotent. TestCrashRecoveryIdempotent commits a transaction to the WAL but applies only every other page image (simulated crash mid-apply). It runs WAL.Recover, snapshots the pager, runs Recover again, and asserts byte-identical snapshots, then reopens the tree and re-checks oracle + invariants. Idempotency comes from full-page after-images plus the per-page LSN guard: an image is written only when the on-disk page LSN is strictly older.
  5. Real on-disk storage. TestFilePagerRoundTrip writes 500 entries through FilePager, closes and reopens the file, and re-verifies all invariants.
