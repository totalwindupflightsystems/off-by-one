Verified Solution: go-wasm-tailcall-stack-map-verifier

A deterministic, linear-time type verifier for a compact Wasm-like bytecode with indirect calls, tail calls, exception edges, multi-value returns, and bounded linear memory.

1. Root-cause analysis

The problem class is not one bug — it is a family of soundness and complexity traps that appear when you validate a typed stack machine with structured control flow:

Trap Why it breaks
Naive CFG path enumeration Enumerating every path through nested block/if/loop is exponential in nesting depth. An adversarial program with N nested blocks has 2^N paths, so the verifier hangs.
Coarse join ("any type") If a join point accepts Bot/any, a value of one type can flow into a slot that expects another, so ill-typed programs are accepted. Joins must be exact.
Ad-hoc safepoints Stack maps at calls must contain the precise live type of every operand slot. Reading them from a partially-popped stack yields wrong GC metadata.
Missing tail-call frame check return_call replaces the current frame. If callee results ≠ caller results (or params don't match the operand stack), the machine returns the wrong arity/types.
Exceptions treated as plain blocks A catch handler begins with the tag payload on the stack. Forgetting to type the payload lets a throw i64 reach a handler expecting i32.
Recursive descent A verifier that recurses on block nesting overflows the Go stack on deep programs.

Key insight. Wasm control flow is structured. You do not need path enumeration: a single forward pass driven by an explicit control-frame stack validates every join at block boundaries (end, else, catch). Each instruction is visited once → O(n) time and O(depth) space, regardless of path count. Unreachable code is handled with stack polymorphism (Bot), and dead safepoints are pruned by a reachability bit.

2. The algorithm

Per function, keep:

  • opds []ValType — the abstract operand stack.
  • ctrls []ctrlFrame — one frame per open block/loop/if/try (plus one implicit frame for the function body). A frame records {opcode, startTypes, endTypes, height, unreachable}.

Core operations (standard Wasm validation algorithm, adapted):

  • popVal: if the current frame is unreachable and the stack is at height, return Bot (polymorphic). Otherwise pop; popping at/below height is underflow.
  • pushCtrl(op,in,out): record height=len(opds), push in.
  • popCtrl: popVals(endTypes), require len(opds)==height, unwind.
  • unreachable: truncate opds to height, set the frame flag.
  • labelTypes(frame): startTypes for loop (branch target = header), endTypes otherwise.
  • br l: pop labelTypes(ctrls[l]), then unreachable.
  • end: popCtrl, push endTypes; an if with no else requires params == results.
  • else: popCtrl (must be if), push a new frame with the same types.
  • catch tag: popCtrl (must be try/catch), push a catch frame whose inputs are the tag payload tag.Params, endTypes unchanged. A try without catch is rejected.
  • throw tag: pop the tag payload, then unreachable (handler bodies are validated independently with the payload on top).
  • return_call f: pop callee params; require callee.Results == currentFunc.Results; unreachable.
  • load/store: require a declared memory, offset + size <= maxPages*65536, and align <= naturalAlign.

Joins are exact because both the fall-through path (end) and every branch path (br) must produce precisely endTypes. There is no path enumeration, so deep nesting stays linear.

Safepoints. At each reachable call, call_indirect, return_call, return_call_indirect, throw, and return, record a StackMap{Func, PC, Op, Stack, Locals} taken before popping arguments. Bot cannot occur in a reachable map.

// Package wasmverify implements a deterministic, linear-time type checker for a
// compact WebAssembly-like bytecode. It supports indirect calls, tail calls,
// exception edges, multi-value returns and bounded linear memory.
//
// The verifier is a single forward pass over each function body driven by an
// explicit control-frame stack (no recursion).  Because the control flow is
// structured, joins are enforced by the block/catch/loop frames and every
// instruction is visited exactly once.  This makes verification O(n) and immune
// to exponential path enumeration on adversarially nested programs.
package wasmverify

import (
    "fmt"
)

// ---------------------------------------------------------------------------
// Types
// ---------------------------------------------------------------------------

// ValType is an abstract value type.
type ValType uint8

const (
    I32 ValType = iota
    I64
    F32
    F64
    FuncRef
    // Bot is the bottom type that inhabits polymorphic stack slots in dead
    // (unreachable) code.  It is compatible with every type.
    Bot
)

func (t ValType) String() string {
    switch t {
    case I32:
        return "i32"
    case I64:
        return "i64"
    case F32:
        return "f32"
    case F64:
        return "f64"
    case FuncRef:
        return "funcref"
    case Bot:
        return "bot"
    default:
        return fmt.Sprintf("type(%d)", t)
    }
}

// FuncType is a function signature.
type FuncType struct {
    Params  []ValType
    Results []ValType
}

func (ft FuncType) String() string {
    return fmt.Sprintf("(%s)->(%s)", joinTypes(ft.Params), joinTypes(ft.Results))
}

func joinTypes(ts []ValType) string {
    s := ""
    for i, t := range ts {
        if i > 0 {
            s += " "
        }
        s += t.String()
    }
    return s
}

func equalTypes(a, b []ValType) bool {
    if len(a) != len(b) {
        return false
    }
    for i := range a {
        if a[i] != b[i] {
            return false
        }
    }
    return true
}

func cloneTypes(ts []ValType) []ValType {
    if ts == nil {
        return nil
    }
    return append([]ValType(nil), ts...)
}

// BlockType describes the parameters and results of a structured block.
type BlockType struct {
    Params  []ValType
    Results []ValType
}

// MemArg describes a memory access immediate.
type MemArg struct {
    Align  uint32 // log2 of the alignment in bytes
    Offset uint32 // static byte offset
}

// Memory is a bounded linear memory, measured in 64 KiB pages.
type Memory struct {
    MinPages uint32
    MaxPages uint32
}

func (m *Memory) byteLen() uint64 {
    return uint64(m.MaxPages) * 65536
}

// TagType describes an exception tag (its payload is the parameter list).
type TagType struct {
    Params []ValType
}

func (o Op) String() string {
    names := []string{
        "i32.const", "i64.const", "f32.const", "f64.const",
        "local.get", "local.set", "local.tee", "global.get", "global.set",
        "drop", "select", "i32.add", "i32.sub", "i32.mul", "i64.add",
        "i32.eqz", "i32.eq", "i32.lt_s",
        "call", "call_indirect", "return_call", "return_call_indirect",
        "return", "block", "loop", "if", "else", "end",
        "br", "br_if", "br_table", "throw", "try", "catch", "load", "store",
    }
    if int(o) < len(names) {
        return names[o]
    }
    return fmt.Sprintf("op(%d)", o)
}

// Instr is a decoded instruction.
type Instr struct {
    Op    Op
    Imm   int64 // constant value / local, global, func, type or tag index / branch depth

    Block BlockType

// Module

// Func is a function definition. Locals excludes the parameters declared in
// the signature (params come first, followed by Locals).
type Func struct {
    Type   int
    Locals []ValType

}

type Global struct {
    Type    ValType
    Mutable bool
}

type Module struct {

    Globals []Global
    Tags    []TagType
    Memory  *Memory
}

// ---------------------------------------------------------------------------
// Reports
// ---------------------------------------------------------------------------

// StackMap is the precise set of live operand types recorded at a safepoint
// (a call or a throw).
type StackMap struct {
    Func   int
    PC     int
    Op     Op
    Stack  []ValType
    Locals []ValType
}

// Report is the result of verifying a module.
type Report struct {
    StackMaps []StackMap
}

// ValidationError reports an ill-typed program.
type ValidationError struct {
    Func int
    PC   int
    Op   Op
    Msg  string
}

func (e *ValidationError) Error() string {
    return fmt.Sprintf("func %d pc %d (%s): %s", e.Func, e.PC, e.Op, e.Msg)
}

// ---------------------------------------------------------------------------
// Verifier
// ---------------------------------------------------------------------------

type ctrlFrame struct {
    opcode      Op
    startTypes  []ValType
    endTypes    []ValType
    height      int
    unreachable bool

    // Reachability bookkeeping (only used to prune dead safepoints).
    entryReach bool
    altReach   bool // a sibling branch (then / earlier catch) could fall through
    brTargeted bool // a reachable branch targets this frame's end
}

type verifier struct {
    mod    *Module
    fnIdx  int
    ft     FuncType
    locals []ValType
    opds   []ValType
    ctrls  []ctrlFrame
    maps   []StackMap
    reach  bool
}

func (v *verifier) fail(pc int, op Op, format string, args ...any) error {
    return &ValidationError{Func: v.fnIdx, PC: pc, Op: op, Msg: fmt.Sprintf(format, args...)}
}

func (v *verifier) top() *ctrlFrame { return &v.ctrls[len(v.ctrls)-1] }

func (v *verifier) pushVal(t ValType) { v.opds = append(v.opds, t) }

func (v *verifier) pushVals(ts []ValType) {
    for _, t := range ts {
        v.opds = append(v.opds, t)
    }
}

// popVal implements WebAssembly stack polymorphism: while the current control
// frame is unreachable and the operand stack has been reset to the frame
// height, popping yields Bot.
func (v *verifier) popVal() (ValType, error) {
    if len(v.ctrls) == 0 {
        if len(v.opds) == 0 {
            return Bot, fmt.Errorf("operand stack underflow")
        }
        t := v.opds[len(v.opds)-1]
        v.opds = v.opds[:len(v.opds)-1]
        return t, nil
    }
    f := v.top()
    if f.unreachable && len(v.opds) == f.height {
        return Bot, nil
    }
    if len(v.opds) <= f.height {
        return Bot, fmt.Errorf("operand stack underflow")
    }
    t := v.opds[len(v.opds)-1]
    v.opds = v.opds[:len(v.opds)-1]
    return t, nil
}

func (v *verifier) popVals(ts []ValType) error {
    for i := len(ts) - 1; i >= 0; i-- {
        got, err := v.popVal()
        if err != nil {
            return err
        }
        if got != Bot && got != ts[i] {
            return fmt.Errorf("type mismatch: expected %s, got %s", ts[i], got)
        }
    }
    return nil
}

func (v *verifier) pushCtrl(op Op, in, out []ValType) {
    f := ctrlFrame{
        opcode:     op,
        startTypes: in,
        endTypes:   out,
        height:     len(v.opds),
        entryReach: v.reach,
    }
    v.ctrls = append(v.ctrls, f)
    v.pushVals(in)
}

// popCtrl validates that the current frame produced its declared result types
// and unwinds it.
func (v *verifier) popCtrl() (ctrlFrame, error) {
    if len(v.ctrls) == 0 {
        return ctrlFrame{}, fmt.Errorf("control stack underflow")
    }
    f := *v.top()
    if err := v.popVals(f.endTypes); err != nil {
        return ctrlFrame{}, fmt.Errorf("at end of %s: %w", f.opcode, err)
    }
    if len(v.opds) != f.height {
        return ctrlFrame{}, fmt.Errorf("at end of %s: operand stack height %d, want %d", f.opcode, len(v.opds), f.height)
    }
    v.ctrls = v.ctrls[:len(v.ctrls)-1]
    return f, nil
}

func (v *verifier) unreachable() {
    v.opds = v.opds[:v.top().height]
    v.top().unreachable = true
    v.reach = false
}

func labelTypes(f *ctrlFrame) []ValType {
    if f.opcode == OpLoop {
        return f.startTypes
    }
    return f.endTypes
}

func (v *verifier) recordSafepoint(pc int, op Op) {
    if !v.reach {
        return
    }
    v.maps = append(v.maps, StackMap{
        Func:   v.fnIdx,
        PC:     pc,
        Op:     op,
        Stack:  cloneTypes(v.opds),
        Locals: cloneTypes(v.locals),
    })
}

// ---------------------------------------------------------------------------
// Instruction helpers
// ---------------------------------------------------------------------------

func (v *verifier) funcType(idx int) (FuncType, error) {
    if idx < 0 || idx >= len(v.mod.Types) {
        return FuncType{}, fmt.Errorf("type index %d out of range", idx)
    }
    return v.mod.Types[idx], nil
}

func sizeOf(t ValType) uint32 {
    switch t {
    case I32, F32:
        return 4
    case I64, F64:
        return 8
    default:
        return 0
    }
}

func naturalAlignLog2(t ValType) uint32 {
    switch t {
    case I32, F32:
        return 2
    case I64, F64:
        return 3
    default:
        return 0
    }
}

func (v *verifier) checkMem(in Instr, pc int) error {
    if v.mod.Memory == nil {
        return v.fail(pc, in.Op, "memory instruction without a declared memory")
    }
    sz := uint64(sizeOf(in.Type))
    a := uint64(in.Mem.Offset)
    end := a + sz
    if end < a || end > v.mod.Memory.byteLen() {
        return v.fail(pc, in.Op, "static memory access [%d,%d) exceeds memory bound %d",
            a, end, v.mod.Memory.byteLen())
    }
    if in.Mem.Align > naturalAlignLog2(in.Type) {
        return v.fail(pc, in.Op, "alignment %d exceeds natural alignment %d for %s",
            in.Mem.Align, naturalAlignLog2(in.Type), in.Type)
    }
    return nil
}

func unify(a, b ValType) (ValType, bool) {
    switch {
    case a == Bot:
        return b, true
    case b == Bot:
        return a, true
    case a == b:
        return a, true
    default:
        return Bot, false
    }
}

// Function verification
// ---------------------------------------------------------------------------

// VerifyFunc verifies a single function of mod and returns the safepoint stack
// maps discovered in it.
func VerifyFunc(mod *Module, fnIdx int) ([]StackMap, error) {
    if fnIdx < 0 || fnIdx >= len(mod.Funcs) {
        return nil, fmt.Errorf("function index %d out of range", fnIdx)
    }
    fn := &mod.Funcs[fnIdx]
    if fn.Type < 0 || fn.Type >= len(mod.Types) {
        return nil, fmt.Errorf("func %d: type index %d out of range", fnIdx, fn.Type)
    }
    ft := mod.Types[fn.Type]
    locals := append(cloneTypes(ft.Params), fn.Locals...)

    v := &verifier{mod: mod, fnIdx: fnIdx, ft: ft, locals: locals, reach: true}
    // Implicit outermost frame: the function body must produce the result types
    // and must not fall off the end with extra values.
    v.ctrls = append(v.ctrls, ctrlFrame{
        opcode:     OpBlock,
        startTypes: nil,
        endTypes:   ft.Results,
        height:     0,
        entryReach: true,
    })

    for pc := 0; pc < len(fn.Body); pc++ {
        in := fn.Body[pc]
        if err := v.step(pc, in); err != nil {
            if ve, ok := err.(*ValidationError); ok {
                return nil, ve
            }
            return nil, v.fail(pc, in.Op, "%v", err)
        }
    }

    // Close the implicit function frame.
    if _, err := v.popCtrl(); err != nil {
        return nil, v.fail(len(fn.Body), OpEnd, "%v", err)
    }
    if len(v.ctrls) != 0 {
        return nil, v.fail(len(fn.Body), OpEnd, "%d unterminated control frame(s)", len(v.ctrls))
    }
    // A reachable reach at the end is allowed only because the implicit frame
    // accepted the results; v.reach is intentionally not used further.
    return v.maps, nil
}

// Verify verifies every function in mod.
func Verify(mod *Module) (*Report, error) {
    rep := &Report{}
    for i := range mod.Funcs {
        maps, err := VerifyFunc(mod, i)
        if err != nil {
            return nil, err
        }
        rep.StackMaps = append(rep.StackMaps, maps...)
    }
    return rep, nil
}

func (v *verifier) step(pc int, in Instr) error {
    switch in.Op {
    // -- constants ------------------------------------------------------
    case OpI32Const:
        v.pushVal(I32)
    case OpI64Const:
        v.pushVal(I64)
    case OpF32Const:
        v.pushVal(F32)
    case OpF64Const:
        v.pushVal(F64)

    // -- locals ---------------------------------------------------------
    case OpLocalGet:
        if in.Imm < 0 || int(in.Imm) >= len(v.locals) {
            return v.fail(pc, in.Op, "local index %d out of range", in.Imm)
        }
        v.pushVal(v.locals[in.Imm])
    case OpLocalSet:
        if in.Imm < 0 || int(in.Imm) >= len(v.locals) {
            return v.fail(pc, in.Op, "local index %d out of range", in.Imm)
        }
        if err := v.popVals([]ValType{v.locals[in.Imm]}); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
    case OpLocalTee:
        if in.Imm < 0 || int(in.Imm) >= len(v.locals) {
            return v.fail(pc, in.Op, "local index %d out of range", in.Imm)
        }
        t := v.locals[in.Imm]
        if err := v.popVals([]ValType{t}); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        v.pushVal(t)

    // -- globals --------------------------------------------------------
    case OpGlobalGet:
        if in.Imm < 0 || int(in.Imm) >= len(v.mod.Globals) {
            return v.fail(pc, in.Op, "global index %d out of range", in.Imm)
        }
        v.pushVal(v.mod.Globals[in.Imm].Type)
    case OpGlobalSet:
        if in.Imm < 0 || int(in.Imm) >= len(v.mod.Globals) {
            return v.fail(pc, in.Op, "global index %d out of range", in.Imm)
        }
        g := v.mod.Globals[in.Imm]
        if !g.Mutable {
            return v.fail(pc, in.Op, "global %d is immutable", in.Imm)
        }
        if err := v.popVals([]ValType{g.Type}); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }

    // -- stack manipulation --------------------------------------------
    case OpDrop:
        if _, err := v.popVal(); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
    case OpSelect:
        if _, err := v.popVal(); err != nil { // condition
            return v.fail(pc, in.Op, "%v", err)
        }
        a, err := v.popVal()
        if err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        b, err := v.popVal()
        if err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        t, ok := unify(a, b)
        if !ok {
            return v.fail(pc, in.Op, "select operands have incompatible types %s and %s", a, b)
        }
        v.pushVal(t)

    // -- numeric --------------------------------------------------------
    case OpI32Add, OpI32Sub, OpI32Mul:
        if err := v.popVals([]ValType{I32, I32}); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        v.pushVal(I32)
    case OpI64Add:
        if err := v.popVals([]ValType{I64, I64}); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        v.pushVal(I64)
    case OpI32Eqz:
        if err := v.popVals([]ValType{I32}); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        v.pushVal(I32)
    case OpI32Eq, OpI32LtS:
        if err := v.popVals([]ValType{I32, I32}); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        v.pushVal(I32)

    // -- calls ----------------------------------------------------------
    case OpCall:
        ft, err := v.funcType(int(in.Imm))
        if err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        v.recordSafepoint(pc, in.Op)
        if err := v.popVals(ft.Params); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        v.pushVals(ft.Results)
    case OpCallIndirect:
        ft, err := v.funcType(int(in.Imm))
        if err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        v.recordSafepoint(pc, in.Op)
        if err := v.popVals([]ValType{I32}); err != nil { // element index
            return v.fail(pc, in.Op, "%v", err)
        }
        if err := v.popVals(ft.Params); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        v.pushVals(ft.Results)
    case OpReturnCall:
        ft, err := v.funcType(int(in.Imm))
        if err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        v.recordSafepoint(pc, in.Op)
        if err := v.popVals(ft.Params); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        if !equalTypes(ft.Results, v.ft.Results) {
            return v.fail(pc, in.Op,
                "tail-call frame incompatible: callee results (%s) != caller results (%s)",
                joinTypes(ft.Results), joinTypes(v.ft.Results))
        }
        v.unreachable()
    case OpReturnCallIndirect:
        ft, err := v.funcType(int(in.Imm))
        if err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        v.recordSafepoint(pc, in.Op)
        if err := v.popVals([]ValType{I32}); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        if err := v.popVals(ft.Params); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        if !equalTypes(ft.Results, v.ft.Results) {
            return v.fail(pc, in.Op,
                "tail-call frame incompatible: callee results (%s) != caller results (%s)",
                joinTypes(ft.Results), joinTypes(v.ft.Results))
        }
        v.unreachable()
    case OpReturn:
        v.recordSafepoint(pc, in.Op)
        if err := v.popVals(v.ft.Results); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        v.unreachable()

    // -- structured control flow ---------------------------------------
    case OpBlock:
        if err := v.popVals(in.Block.Params); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        v.pushCtrl(OpBlock, in.Block.Params, in.Block.Results)
    case OpLoop:
        if err := v.popVals(in.Block.Params); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        v.pushCtrl(OpLoop, in.Block.Params, in.Block.Results)
    case OpIf:
        if err := v.popVals([]ValType{I32}); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        if err := v.popVals(in.Block.Params); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        v.pushCtrl(OpIf, in.Block.Params, in.Block.Results)
    case OpElse:
        f, err := v.popCtrl()
        if err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        if f.opcode != OpIf {
            return v.fail(pc, in.Op, "else without matching if")
        }
        thenReach := v.reach
        v.pushCtrl(OpElse, f.startTypes, f.endTypes)
        t := v.top()
        t.brTargeted = f.brTargeted
        t.altReach = f.altReach || thenReach
        v.reach = f.entryReach

    case OpCatch:
        f, err := v.popCtrl()
        if err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        if f.opcode != OpTry && f.opcode != OpCatch {
            return v.fail(pc, in.Op, "catch without matching try")
        }
        if in.Imm < 0 || int(in.Imm) >= len(v.mod.Tags) {
            return v.fail(pc, in.Op, "tag index %d out of range", in.Imm)
        }
        tag := v.mod.Tags[in.Imm]
        prevReach := v.reach
        // A catch handler starts with the tag payload on the operand stack.
        v.pushCtrl(OpCatch, tag.Params, f.endTypes)
        t := v.top()
        t.brTargeted = f.brTargeted
        t.altReach = f.altReach || prevReach
        v.reach = f.entryReach

    case OpEnd:
        f, err := v.popCtrl()
        if err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        if f.opcode == OpIf {
            // No else (an else branch would make the frame OpElse): the implicit
            // empty else must map params to results.
            if !equalTypes(f.startTypes, f.endTypes) {
                return v.fail(pc, in.Op,
                    "if without else requires params (%s) == results (%s)",
                    joinTypes(f.startTypes), joinTypes(f.endTypes))
            }
        }
        if f.opcode == OpTry {
            return v.fail(pc, in.Op, "try without catch")
        }
        reachAfter := v.reach || f.brTargeted || f.altReach
        if f.opcode == OpIf {
            reachAfter = reachAfter || f.entryReach
        }
        v.reach = reachAfter
        v.pushVals(f.endTypes)

    // -- branches -------------------------------------------------------
    case OpBr:
        if int(in.Imm) < 0 || int(in.Imm) >= len(v.ctrls) {
            return v.fail(pc, in.Op, "branch depth %d out of range", in.Imm)
        }
        target := &v.ctrls[len(v.ctrls)-1-int(in.Imm)]
        if err := v.popVals(labelTypes(target)); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        if v.reach && target.opcode != OpLoop {
            target.brTargeted = true
        }
        v.unreachable()
    case OpBrIf:
        if int(in.Imm) < 0 || int(in.Imm) >= len(v.ctrls) {
            return v.fail(pc, in.Op, "branch depth %d out of range", in.Imm)
        }
        if err := v.popVals([]ValType{I32}); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        target := &v.ctrls[len(v.ctrls)-1-int(in.Imm)]
        if err := v.popVals(labelTypes(target)); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        v.pushVals(labelTypes(target))
        if v.reach && target.opcode != OpLoop {
            target.brTargeted = true
        }
    case OpBrTable:
        if err := v.popVals([]ValType{I32}); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        targets := append(append([]int(nil), in.Targets...), in.Default)
        snapshot := cloneTypes(v.opds)
        for _, d := range targets {
            if d < 0 || d >= len(v.ctrls) {
                return v.fail(pc, in.Op, "branch depth %d out of range", d)
            }
            v.opds = cloneTypes(snapshot)
            target := &v.ctrls[len(v.ctrls)-1-d]
            if err := v.popVals(labelTypes(target)); err != nil {
                return v.fail(pc, in.Op, "%v", err)
            }
            if v.reach && target.opcode != OpLoop {
                target.brTargeted = true
            }
        }
        v.opds = snapshot
        v.unreachable()

    // -- exceptions -----------------------------------------------------
    case OpThrow:
        if in.Imm < 0 || int(in.Imm) >= len(v.mod.Tags) {
            return v.fail(pc, in.Op, "tag index %d out of range", in.Imm)
        }
        tag := v.mod.Tags[in.Imm]
        v.recordSafepoint(pc, in.Op)
        if err := v.popVals(tag.Params); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        v.unreachable()
    case OpTry:
        if err := v.popVals(in.Block.Params); err != nil {
            return v.fail(pc, in.Op, "%v", err)
        }
        v.pushCtrl(OpTry, in.Block.Params, in.Block.Results)

    // -- memory ---------------------------------------------------------
    case OpLoad:
        if err := v.checkMem(in, pc); err != nil {
            return err
        }
        if err := v.popVals([]ValType{I32}); err != nil { // address
            return v.fail(pc, in.Op, "%v", err)
        }
        v.pushVal(in.Type)
    case OpStore:
        if err := v.checkMem(in, pc); err != nil {
            return err
        }
        if err := v.popVals([]ValType{in.Type}); err != nil { // value
            return v.fail(pc, in.Op, "%v", err)
        }
        if err := v.popVals([]ValType{I32}); err != nil { // address
            return v.fail(pc, in.Op, "%v", err)
        }

    default:
        return v.fail(pc, in.Op, "unknown opcode")
    }
    return nil
}

// Command wasmverify validates a JSON-encoded module and prints the safepoint
// stack maps it discovers.
//
// Usage:
//
//  wasmverify module.json
//  cat module.json | wasmverify
//
// Exit code 0 means the module passed verification; 1 means it was rejected.
package main

import (
    "encoding/json"
    "fmt"
    "io"
    "os"

    "wasmverify"
)

func main() {
    var data []byte
    var err error
    if len(os.Args) > 1 {
        data, err = os.ReadFile(os.Args[1])
    } else {
        data, err = io.ReadAll(os.Stdin)
    }
    if err != nil {
        fmt.Fprintln(os.Stderr, "read:", err)
        os.Exit(2)
    }

    var m wasmverify.Module
    if err := json.Unmarshal(data, &m); err != nil {
        fmt.Fprintln(os.Stderr, "decode:", err)
        os.Exit(2)
    }

    rep, err := wasmverify.Verify(&m)
    if err != nil {
        fmt.Fprintln(os.Stderr, "REJECTED:", err)
        os.Exit(1)
    }
    fmt.Println("ACCEPTED")
    for _, sm := range rep.StackMaps {
        fmt.Printf("  stackmap func=%d pc=%d op=%s stack=%v locals=%v\n",
            sm.Func, sm.PC, sm.Op, sm.Stack, sm.Locals)
    }
}

5. Why this is sound and complete for the class

  • Sound joins: every path into a join must satisfy popCtrl/br against exactly the same endTypes; there is no "any type" widening. Bot is only produced in unreachable frames.
  • Tail-call frame compatibility: return_call[_indirect] requires callee.Results to be structurally equal to the enclosing function's results and the callee params to be on the stack.
  • Precise stack maps: safepoint maps are snapshots of the abstract operand stack before argument popping, emitted only when the reach bit is set.
  • Exception edges: throw type-checks against the tag payload; catch seeds the handler stack with the same payload; try without catch is rejected.
  • Bounded memory: static offset + size ≤ maxPages·65536 and align ≤ naturalAlign are enforced.
  • No blowup / no recursion: explicit slices for both stacks; every instruction visited once.
