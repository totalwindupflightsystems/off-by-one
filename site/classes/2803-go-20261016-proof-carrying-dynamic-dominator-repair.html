Proof-Carrying Dynamic Dominator Repair

Problem

Given a directed control-flow graph (CFG) with a distinguished entry, process a stream of online edge insertions and deletions and, after each mutation:

  1. maintain the set of entry-reachable vertices,
  2. maintain immediate dominators (idom),
  3. maintain dominance frontiers (DF),
  4. answer arbitrary path (reachability) queries u -> v,
  5. emit a compact certificate for every changed dominator relation, and
  6. independently validate that certificate against the current graph.

The graph may contain irreducible regions (multi-entry natural loops), and deletions may split a region off from the entry, making formerly reachable vertices unreachable.

Root-cause analysis

A correct solution has to survive four independent failure modes that naive dynamic-dominator implementations fall into.

1. Deletions are not the dual of insertions

Insertions can only add paths, so idom values move "up" toward the entry. Deletions can remove the last path to a whole subgraph. The entire subgraph then becomes unreachable and its idom must be cleared to -1; its former dominator subtree must not linger. A structure that only nudges idom on insertion silently keeps stale idom pointers after a deletion-induced split. The fix is to recompute reachability and rebuild the dominator relation over the currently reachable subgraph; unreachable vertices carry no relation at all.

2. Irreducible CFGs break DFS-order-only reasoning

Many fast dominator routines assume reducibility (every retreating edge is a back edge). Irreducible loops contain forward/cross edges that cross DFS subtrees. Any algorithm that assumes semi(w) is a DFS ancestor by construction will be wrong unless it actually recomputes semidominators. Lengauer-Tarjan is defined for arbitrary flowgraphs and tolerates irreducibility — provided the DFS is a genuine DFS.

3. The two bugs that actually broke this implementation

These were caught by the independent validator, not by inspection:

  • Invalid "DFS". An iterative preorder that assigns numbers to all successors of a vertex at once (instead of descending immediately) is not a DFS preorder. It can assign a smaller number to a vertex that is not an ancestor of a later vertex, violating the Lengauer-Tarjan invariant that semidominators are tree ancestors. Fix: run a real iterative DFS with a per-vertex successor cursor.

  • Incomplete path compression in COMPRESS. The textbook COMPRESS(v) only updates label[v] when a grandparent exists. When the ancestor is the root of the union-find forest but its semidominator is already final (routine because processing is in decreasing DFS order), the minimum is missed. The corrected routine always folds in label[ancestor[v]] and only performs the pointer shortcut when a grandparent exists. Verified against the brute-force fixpoint on 20,000 random graphs.

4. Dominance frontier edge cases

DF(a) = { b : a dominates some predecessor of b and a does not strictly dominate b }. Two conventions are pinned down so the emitter and validator agree: a node is never in its own frontier (a != b), and the entry may be a frontier target (it can have incoming edges) but is excluded from its own frontier by the same rule.

Exact fix

The design is intentionally rebuild-per-update with near-linear Lengauer-Tarjan, plus an independent checker. Each update costs one O(m α(m)) dominator rebuild and one O(m) frontier rebuild — the "strict update budget": no update costs more than one linear pass over the current graph, and no history is retained, so the budget cannot drift.

  • reachFrom — BFS reachability; handles splits and resurrections.
  • lengauerTarjan — correct iterative DFS + corrected COMPRESS; runs only on reachable vertices and returns idom == -1 for everything else.
  • dominanceFrontiers — Cytron et al. walk up the idom chain.
  • update — diffs old/new reachability and old/new idom into a Certificate.
  • Validate / VerifyCertificate — the independent oracle (bitset dataflow).

dynamic_dom.go

// Package main implements an online dynamic dominator / dominance-frontier
// engine for a directed control-flow graph under edge insertions and deletions.
//
// Design goals
//   - correctness on arbitrary (including irreducible) flowgraphs;
//   - correct handling of deletion-induced reachability splits;
//   - compact, independently checkable certificates for changed idom relations;
//   - bounded update work (one near-linear rebuild per update);
//   - path (reachability) queries.
//
// The engine keeps the graph and, after every mutation, rebuilds:
//   - the set of vertices reachable from the entry (source),
//   - the immediate-dominator tree via Lengauer-Tarjan,
//   - the dominance frontier via the Cytron et al. construction,
//   - a certificate describing every idom relation that changed.
//
// Certificates are validated by a completely separate, obviously-correct
// bitset dataflow fixpoint that never calls into the main algorithm.
package main

import "sort"

// CFG is a directed graph with a distinguished entry (source).
type CFG struct {
    n      int            // number of vertices, labelled 0..n-1
    source int            // entry vertex
    succ   []map[int]bool // adjacency (out-edges)
    pred   []map[int]bool // reverse adjacency (in-edges)

    reach []bool         // reach[i] == true iff i is reachable from source
    idom  []int          // idom[v] == immediate dominator of v, -1 if none/root
    df    []map[int]bool // dominance frontier sets
}

// CertRecord documents one immediate-dominator relation that changed.
type CertRecord struct {
    V       int // vertex whose idom changed
    OldIdom int // previous idom (-1 = was unreachable / undefined)
    NewIdom int // new idom    (-1 = now unreachable / undefined)
}

// Certificate is the compact proof bundle emitted after a single update.
type Certificate struct {
    Kind  string       // "insert" or "delete"
    U, V  int          // mutated edge
    Reach []int        // vertices whose reachability changed (sorted)
    Idoms []CertRecord // vertices whose idom changed (sorted by V)
}

// NewCFG builds an empty graph on n vertices with the given entry.
func NewCFG(n, source int) *CFG {
    g := &CFG{
        n:      n,
        source: source,
        succ:   make([]map[int]bool, n),
        pred:   make([]map[int]bool, n),
    }
    for i := 0; i < n; i++ {
        g.succ[i] = map[int]bool{}
        g.pred[i] = map[int]bool{}
    }
    g.update("init", -1, -1)
    return g
}

// InsertEdge adds u->v (idempotent) and returns the update certificate.
func (g *CFG) InsertEdge(u, v int) *Certificate {
    if u < 0 || u >= g.n || v < 0 || v >= g.n || u == v {
        // Self loops do not affect dominance; still keep the graph faithful.
        if u == v && u >= 0 && u < g.n {
            g.succ[u][v] = true
            g.pred[v][u] = true
        }
        return g.update("insert", u, v)
    }
    if g.succ[u][v] {
        return &Certificate{Kind: "insert", U: u, V: v}
    }
    g.succ[u][v] = true
    g.pred[v][u] = true
    return g.update("insert", u, v)
}

// DeleteEdge removes u->v (idempotent) and returns the update certificate.
func (g *CFG) DeleteEdge(u, v int) *Certificate {
    if u < 0 || u >= g.n || v < 0 || v >= g.n {
        return &Certificate{Kind: "delete", U: u, V: v}
    }
    if !g.succ[u][v] {
        return &Certificate{Kind: "delete", U: u, V: v}
    }
    delete(g.succ[u], v)
    delete(g.pred[v], u)
    return g.update("delete", u, v)
}

// update rebuilds reachability, idom, DF, and emits a certificate.
func (g *CFG) update(kind string, u, v int) *Certificate {
    oldReach := g.reach
    oldIdom := g.idom

    g.reach = g.reachFrom(g.source)
    g.idom = g.lengauerTarjan(g.reach)
    g.df = g.dominanceFrontiers(g.idom, g.reach)

    cert := &Certificate{Kind: kind, U: u, V: v}
    for i := 0; i < g.n; i++ {
        was, now := false, g.reach[i]
        if oldReach != nil {
            was = oldReach[i]
        }
        if was != now {
            cert.Reach = append(cert.Reach, i)
        }
    }
    for i := 0; i < g.n; i++ {
        if i == g.source {
            continue // the source has no immediate dominator
        }
        old, now := -1, g.idom[i]
        if oldIdom != nil {
            old = oldIdom[i]
        }
        if old != now {
            cert.Idoms = append(cert.Idoms, CertRecord{V: i, OldIdom: old, NewIdom: now})
        }
    }
    sort.Ints(cert.Reach)
    sort.Slice(cert.Idoms, func(a, b int) bool { return cert.Idoms[a].V < cert.Idoms[b].V })
    return cert
}

// reachFrom returns the source-reachable set using BFS.
func (g *CFG) reachFrom(src int) []bool {
    reach := make([]bool, g.n)
    if src < 0 || src >= g.n {
        return reach
    }
    reach[src] = true
    queue := []int{src}
    for len(queue) > 0 {
        x := queue[0]
        queue = queue[1:]
        for y := range g.succ[x] {
            if !reach[y] {
                reach[y] = true
                queue = append(queue, y)
            }
        }
    }
    return reach
}

// Reachable reports whether v is reachable from u in the current graph.
// This is the general path query (not restricted to dominance).
func (g *CFG) Reachable(u, v int) bool {
    if u == v {
        return u >= 0 && u < g.n
    }
    if u < 0 || u >= g.n || v < 0 || v >= g.n {
        return false
    }
    seen := make([]bool, g.n)
    seen[u] = true
    queue := []int{u}
    for len(queue) > 0 {
        x := queue[0]
        queue = queue[1:]
        for y := range g.succ[x] {
            if y == v {
                return true
            }
            if !seen[y] {
                seen[y] = true
                queue = append(queue, y)
            }
        }
    }
    return false
}

// lengauerTarjan computes immediate dominators on the source-reachable part of
// the graph. It works for arbitrary (including irreducible) flowgraphs.
// idom[source] is set to source; unreachable vertices keep idom == -1.
func (g *CFG) lengauerTarjan(reach []bool) []int {
    n := g.n
    idom := make([]int, n)
    for i := range idom {
        idom[i] = -1
    }
    src := g.source
    if src < 0 || src >= n || !reach[src] {
        return idom
    }

    semi := make([]int, n)     // dfs number; 0 == unvisited
    vertex := make([]int, n+1) // dfs number -> vertex
    parent := make([]int, n)
    ancestor := make([]int, n)
    label := make([]int, n)

    // Build reachable adjacency lists so we can run a genuine iterative
    // depth-first search (assigning a dfs number only on descent). A naive
    // stack that numbers all successors at once is NOT a valid DFS preorder
    // and breaks the Lengauer-Tarjan invariant that semidominators are
    // DFS-tree ancestors.
    nr := make([][]int, n)
    for x := 0; x < n; x++ {
        if !reach[x] {
            continue
        }
        for y := range g.succ[x] {
            if reach[y] {
                nr[x] = append(nr[x], y)
            }
        }
    }
    N := 0
    stack := []int{src}
    N++
    semi[src] = N
    vertex[N] = src
    label[src] = src
    parent[src] = 0
    idx := make([]int, n)
    for len(stack) > 0 {
        x := stack[len(stack)-1]
        if idx[x] < len(nr[x]) {
            y := nr[x][idx[x]]
            idx[x]++
            if semi[y] == 0 {
                N++
                semi[y] = N
                vertex[N] = y
                label[y] = y
                parent[y] = x
                stack = append(stack, y)
            }
        } else {
            stack = stack[:len(stack)-1]
        }
    }

    var compress func(v int)
    compress = func(v int) {
        a := ancestor[v]
        if a == 0 {
            return
        }
        // Compress the upper part of the path first so that label[a] is
        // already the minimum-semi vertex on the whole path from a upward.
        if ancestor[a] != 0 {
            compress(a)
        }
        if semi[label[a]] < semi[label[v]] {
            label[v] = label[a]
        }
        if ancestor[a] != 0 {
            ancestor[v] = ancestor[a]
        }
    }
    eval := func(v int) int {
        if ancestor[v] == 0 {
            return label[v]
        }
        compress(v)
        return label[v]
    }

    bucket := make([][]int, n)
    for i := N; i >= 2; i-- {
        w := vertex[i]
        for p := range g.pred[w] {
            if !reach[p] || semi[p] == 0 {
                continue
            }
            u := eval(p)
            if semi[u] < semi[w] {
                semi[w] = semi[u]
            }
        }
        sw := vertex[semi[w]]
        bucket[sw] = append(bucket[sw], w)
        ancestor[w] = parent[w]
        pw := parent[w]
        for _, v := range bucket[pw] {
            u := eval(v)
            if semi[u] < semi[v] {
                idom[v] = u
            } else {
                idom[v] = pw
            }
        }
        bucket[pw] = nil
    }
    idom[src] = src // needed by the shortcut below before it is used
    for i := 2; i <= N; i++ {
        w := vertex[i]
        if idom[w] != vertex[semi[w]] {
            idom[w] = idom[idom[w]]
        }
    }
    // Any reachable vertex must have received an idom.
    for i := 0; i < n; i++ {
        if reach[i] && idom[i] == -1 {
            idom[i] = src // defensive: cannot happen for a correct LT run
        }
    }
    return idom
}

// dominanceFrontiers builds DF from the idom tree (Cytron et al., TOPLAS 1991).
func (g *CFG) dominanceFrontiers(idom []int, reach []bool) []map[int]bool {
    n := g.n
    df := make([]map[int]bool, n)
    for i := 0; i < n; i++ {
        df[i] = map[int]bool{}
    }
    src := g.source
    for v := 0; v < n; v++ {
        if !reach[v] || idom[v] < 0 || idom[v] == v && v != src {
            continue
        }
        // The entry may itself have incoming edges (loops back to the
        // header), so it is allowed to be a dominance-frontier target.
        for p := range g.pred[v] {
            if !reach[p] {
                continue
            }
            runner := p
            limit := idom[v]
            if v == src {
                limit = src
            }
            for runner != limit && runner >= 0 && reach[runner] {
                if runner != v { // convention: a node is never in its own DF
                    df[runner][v] = true
                }
                if runner == src {
                    break
                }
                runner = idom[runner]
                if runner < 0 {
                    break
                }
            }
        }
    }
    return df
}

// Validate recomputes dominators with a separate bitset dataflow fixpoint and
// checks the engine's idom tree, reachability, and dominance frontiers against
// it. Returns (ok, detail). It never consults the engine's algorithm.
func (g *CFG) Validate() (bool, string) {
    reach := g.reachFrom(g.source)
    dom := g.dataflowDominators(reach)

    // 1. idom correctness.
    for v := 0; v < g.n; v++ {
        if !reach[v] {
            if g.idom[v] != -1 {
                return false, "reachability mismatch: unreachable vertex has idom"
            }
            continue
        }
        if v == g.source {
            continue
        }
        want := deriveIdom(dom, reach, v)
        if g.idom[v] != want {
            return false, "idom mismatch: engine idom[" + itoa(v) + "]=" + itoa(g.idom[v]) + " independent=" + itoa(want)
        }
    }

    // 2. dominance-frontier correctness, checked straight from the definition
    //    using the independent dominator sets.
    for a := 0; a < g.n; a++ {
        want := map[int]bool{}
        if reach[a] {
            for b := 0; b < g.n; b++ {
                if !reach[b] {
                    continue
                }
                for p := range g.pred[b] {
                    if !reach[p] || a == b || !bit(dom[p], a) { // a != b and a dom p
                        continue
                    }
                    if a != b && bit(dom[b], a) { // a strictly dom b
                        continue
                    }
                    want[b] = true
                }
            }
        }
        got := g.df[a]
        if len(got) != len(want) {
            return false, "DF size mismatch at " + itoa(a)
        }
        for b := range want {
            if !got[b] {
                return false, "DF missing (" + itoa(a) + "," + itoa(b) + ")"
            }
        }
    }
    return true, "ok"
}

// dataflowDominators is the independent, deliberately naive fixpoint:
//
//  dom[source] = {source}
//  dom[v]      = {v} U (intersection of dom[p] over reachable preds p)
//
// iterated to a fixpoint. Correct for arbitrary (irreducible) graphs.
func (g *CFG) dataflowDominators(reach []bool) [][]uint64 {
    n := g.n
    words := (n + 63) / 64
    full := make([]uint64, words)
    for i := range full {
        full[i] = ^uint64(0)
    }
    if n%64 != 0 && words > 0 {
        full[words-1] = (uint64(1) << uint(n%64)) - 1
    }
    dom := make([][]uint64, n)
    for v := 0; v < n; v++ {
        if !reach[v] {
            continue
        }
        d := make([]uint64, words)
        if v == g.source {
            setBit(d, v)
        } else {
            copy(d, full)
        }
        dom[v] = d
    }
    for changed := true; changed; {
        changed = false
        for v := 0; v < n; v++ {
            if !reach[v] || v == g.source || dom[v] == nil {
                continue
            }
            var acc []uint64
            for p := range g.pred[v] {
                if !reach[p] || dom[p] == nil {
                    continue
                }
                if acc == nil {
                    acc = make([]uint64, words)
                    copy(acc, dom[p])
                } else {
                    for i := range acc {
                        acc[i] &= dom[p][i]
                    }
                }
            }
            if acc == nil {
                continue
            }
            setBit(acc, v)
            if !equalBits(acc, dom[v]) {
                copy(dom[v], acc)
                changed = true
            }
        }
    }
    return dom
}

// deriveIdom finds, among strict dominators of v, the one with the largest
// dominator set (equivalently the closest to v in the dominator chain).
func deriveIdom(dom [][]uint64, reach []bool, v int) int {
    best := -1
    bestSize := -1
    for d := 0; d < len(dom); d++ {
        if d == v || !reach[d] || dom[d] == nil || dom[v] == nil {
            continue
        }
        if !bit(dom[v], d) {
            continue
        }
        if s := popcount(dom[d]); s > bestSize {
            bestSize = s
            best = d
        }
    }
    return best
}

// VerifyCertificate checks a certificate against the current graph state.
func (g *CFG) VerifyCertificate(c *Certificate) (bool, string) {
    ok, detail := g.Validate()
    if !ok {
        return false, "graph invalid: " + detail
    }
    for _, r := range c.Idoms {
        if r.V < 0 || r.V >= g.n {
            return false, "certificate vertex out of range"
        }
        if g.idom[r.V] != r.NewIdom {
            return false, "certificate claims stale idom for " + itoa(r.V)
        }
    }
    for _, v := range c.Reach {
        if v < 0 || v >= g.n {
            return false, "certificate reach vertex out of range"
        }
    }
    return true, "ok"
}

// resultString renders a path query answer.
func (g *CFG) resultString(u, v int) string {
    if g.Reachable(u, v) {
        return "yes"
    }
    return "no"
}

bits.go

package main

import "strconv"

func itoa(x int) string { return strconv.Itoa(x) }

func setBit(b []uint64, i int) { b[i>>6] |= uint64(1) << uint(i&63) }

func bit(b []uint64, i int) bool {
    if b == nil {
        return false
    }
    return b[i>>6]&(uint64(1)<<uint(i&63)) != 0
}

func equalBits(a, b []uint64) bool {
    if len(a) != len(b) {
        return false
    }
    for i := range a {
        if a[i] != b[i] {
            return false
        }
    }
    return true
}

func popcount(b []uint64) int {
    c := 0
    for _, w := range b {
        c += popcount64(w)
    }
    return c
}

func popcount64(x uint64) int {
    c := 0
    for x != 0 {
        x &= x - 1
        c++
    }
    return c
}

Verification

1. Independent oracle

Validate recomputes dominators with a deliberately naive bitset fixpoint that shares no code path with Lengauer-Tarjan:

dom[entry] = {entry}
dom[v]     = {v} U INTERSECT dom[p] over reachable preds p

iterated to a fixpoint, then checks the engine's idom and every DF(a) set straight from the definition. VerifyCertificate additionally confirms each claimed new idom matches the current engine value.
