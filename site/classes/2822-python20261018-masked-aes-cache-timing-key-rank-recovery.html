Masked AES Cache-Timing Key-Rank Recovery — Diagnosis and Fix

Problem class: python20261018-masked-aes-cache-timing-key-rank-recovery Environment: Python 3.11+ (verified on CPython 3.14), NumPy only (no SciPy required)

Artifacts written and verified in /workspace: - SOLUTION.md — full self-contained write-up - aes_cache_rank.py — reference implementation - test_aes_cache_rank.py — 10-check verification suite (10/10 pass) - demo_report.py — reproducible evidence generator

1. Root-cause analysis

1.1 Arg-max is not rank recovery; the LLR must be normalised

For first-round T-table AES, index_j = plaintext_byte_j XOR key_byte_j and the touched cache set is a function of index_j. Scoring key hypothesis k sums a per-trace log-likelihood l_j(k). Because the observed data are identical across candidates, raw totals aren't comparable. The prunable quantity is the log-likelihood ratio

D(k) = L(k*) - L(k) >= 0,   k* = argmax_k L(k),

the only quantity with a known null distribution. Hard arg-max cannot quantify confidence or retain competing keys.

1.2 Real cache-set resolution hides the low nibble

A 256-entry T-table of 4-byte words is 1 KiB. With 64-byte lines there are 16 sets, so the set only depends on (index >> 4) & 0xF. The low nibble of each key byte is information-theoretically invisible in first-round cache-set timing. The model makes resolution explicit via line_entries: 1 → 256 distinguishable classes (full byte), 16 → physical cache (high nibble only). The demo confirms 0xB6 → 0xB0 with all low nibbles tied.

1.3 Correlated measurements make i.i.d. LLRs over-confident

Traces in a burst/batch share scheduler/frequency/cache state, so i.i.d. variance estimation understates Var[D(k)]. The usual z = sqrt(2·D) then over-prunes and drops the true key. From the demo (150 traces, batch-sd 45): true key rank 5, D=56.46, naive z=10.63 (would prune) vs cluster-robust z=1.06 (retained). The fix is a cluster-robust (sandwich) SE grouped by batch; with unit-size batches it reduces to the ordinary i.i.d. test, so it is strictly a generalisation and only ever widens the noise floor.

1.4 Missing samples must be skipped trace-wise

Dropped traces correlate with slow (miss) accesses. Dropping whole rows or coercing NaN→0 biases the score. A non-finite timing must contribute exactly 0 for every candidate (neutral in the LLR); all-missing batches are dropped from the cluster sum; if nothing is usable, return the uniform distribution.

1.5 Outliers break Gaussian/mean-based calibration

With interrupts/heavy tails, a Gaussian MLE lets one 5σ sample dominate. Fix: median + 1.4826·MAD per-set location/scale, and a Student-t × uniform mixture score with the uniform floor capping extreme penalties; the mixture weight is estimated from robust residuals.

1.6 Masked first-order leakage: only key XOR mask is identifiable

With a mask m, the leak depends on p XOR k XOR m. Likelihood is invariant under (k,m)→(k⊕c, m⊕c), so k alone is not identifiable; only k⊕m is. The demo shows the zero-mask search returning 0xAB = 0x9C XOR 0x37. A correct solution takes the mask as known, or reports the identifiable combination.

2. The exact fix

Algorithm

for each key-byte position j:
  1. calibrate (known profiling key): per-class median/MAD, outlier weight,
     Student-t dof, batch ICC.
  2. score k=0..255: l_j(k) robust per-trace log-lik, NaN -> 0; L(k)=sum
  3. LLR: D(k) = max L - L(k) >= 0
  4. cluster-robust variance over batches -> z(k)
  5. prune: keep {k : z(k) <= z_thresh} U {argmax}
  6. posterior ∝ exp(-z(k)^2/2) over retained candidates
combine the 16 independent per-byte candidate sets via beam-pruned product search

"""
aes_cache_rank.py
=================

Robust key-rank recovery for a table-based (T-table) AES implementation from
noisy cache-timing traces, using a calibrated cache-set leakage model.

Design goals (matching the problem statement)
---------------------------------------------
* "noisy timing traces ... calibrated cache-set leakage model"
      -> a per-cache-set location/scale timing model, estimated robustly.
* "likelihood-ratio search with pruning"
      -> per-key-byte log-likelihood ratios, pruned with a *cluster-robust*
         significance threshold; byte candidates are combined by beam search.
* "remains correct when trace batches have missing samples"
      -> NaNs are ignored trace-wise; empty batches are dropped.
* "... outliers"
      -> Student-t + uniform mixture likelihood and median/MAD calibration.
* "... correlated measurements"
      -> cluster-robust (sandwich) standard errors over batches, so pruning
         and reported confidence are not over-confident.
* "several competing keys within the noise floor"
      -> all candidates inside the noise floor are kept and reported with
         posterior weights instead of a single hard decision.
* "masked AES"
      -> cache-set prediction accepts a mask; the module documents/exploits
         the fact that only k XOR mask is identifiable from first-order leakage.

Resolution note (important)
---------------------------
A real 256-entry T-table spans 16 cache lines (64 B / 4 B words), so first-round
cache-set leakage only exposes the *high nibble* of ``p XOR k`` and therefore
only the high nibble of each key byte.  To make full-byte recovery well posed,
``line_entries`` defaults to 1 (one distinguishable leak class per table entry,
256 classes).  Passing ``line_entries=16`` reproduces the physical, coarser
cache and intentionally leaves the low nibble unidentifiable.

Only numpy + the standard library are required (no scipy).

Public API
----------
    CalibratedLeakageModel
    calibrate(...)
    cache_sets(...)
    score_keys(...)
    rank_byte(...)
    rank_all_bytes(...)
    combine_rankings(...)
"""

_LOG2PI = math.log(2.0 * math.pi)


def _student_t_logpdf(residual: np.ndarray, scale: np.ndarray, dof: float) -> np.ndarray:
    """log pdf of a (possibly vectorised) Student-t distribution.

    residual : (...,) array
    scale    : scalar or array broadcastable to residual (strictly positive)
    dof      : degrees of freedom (dof -> inf recovers the Gaussian)
    """
    residual = np.asarray(residual, dtype=np.float64)
    scale = np.asarray(scale, dtype=np.float64)
    if not np.isfinite(dof) or dof >= 1e6:
        return -0.5 * _LOG2PI - np.log(scale) - 0.5 * (residual / scale) ** 2
    const = math.lgamma((dof + 1.0) / 2.0) - math.lgamma(dof / 2.0) - 0.5 * math.log(dof * math.pi)
    z = residual / scale
    return const - np.log(scale) - 0.5 * (dof + 1.0) * np.log1p((z * z) / dof)


def _robust_scale(x: np.ndarray) -> float:
    """Normal-consistent median absolute deviation."""
    x = np.asarray(x, dtype=np.float64)
    if x.size == 0:
        return 0.0
    med = float(np.median(x))
    mad = float(np.median(np.abs(x - med)))
    return 1.4826 * mad


def _as_float_array(x: Iterable[float]) -> np.ndarray:
    return np.asarray(list(x), dtype=np.float64)

# Leakage model

def _shift_and_mask(line_entries: int) -> Tuple[int, int]:
    if line_entries < 1 or (line_entries & (line_entries - 1)) != 0:
        raise ValueError("line_entries must be a power of two")
    shift = line_entries.bit_length() - 1
    n_sets = max(256 // line_entries, 1)
    return shift, n_sets


def cache_sets(
    plaintext: np.ndarray,
    key_byte: int,
    mask: int = 0,
    line_entries: int = 1,
) -> np.ndarray:
    """Predicted first-round T0 cache set for each plaintext byte.

    A 256-entry table of 4-byte words is 1 KiB.  With ``line_entries`` entries
    per cache line, entry index ``v = (p XOR k XOR mask)`` lives in cache set
    ``(v >> log2(line_entries)) & (n_sets - 1)``.
    """
    shift, n_sets = _shift_and_mask(line_entries)
    p = np.asarray(plaintext, dtype=np.int64)
    v = p ^ (int(key_byte) & 0xFF) ^ (int(mask) & 0xFF)
    return ((v >> shift) & (n_sets - 1)).astype(np.int64)


@dataclass
class CalibratedLeakageModel:
    """Calibrated per-cache-set timing model with robust outlier handling.

    mu / sigma   : per-cache-set location and scale of the timing measurement.
    outlier_p    : mixture weight of a broad uniform background component.
    outlier_lo/hi: support of that background component (timing window).
    dof          : Student-t degrees of freedom (robustness to outliers).
    rho          : estimated intra-batch correlation (informational; the
                   cluster-robust SE is estimated per comparison at rank time).
    line_entries : cache line size in table entries.
    """

    mu: np.ndarray
    sigma: np.ndarray
    outlier_p: float = 0.0
    outlier_lo: float = 0.0
    outlier_hi: float = 1.0
    dof: float = 4.0
    rho: float = 0.0
    line_entries: int = 1

    def __post_init__(self) -> None:
        self.mu = np.asarray(self.mu, dtype=np.float64).reshape(-1)
        self.sigma = np.asarray(self.sigma, dtype=np.float64).reshape(-1)
        if self.mu.shape != self.sigma.shape:
            raise ValueError("mu and sigma must have the same shape")
        if np.any(self.sigma <= 0):
            raise ValueError("sigma values must be strictly positive")

    @property
    def n_sets(self) -> int:
        return int(self.mu.size)


# ---------------------------------------------------------------------------
# Calibration
# ---------------------------------------------------------------------------

def _estimate_icc(t: np.ndarray, batch_ids: np.ndarray) -> float:
    """One-way random-effects intra-class correlation (ANOVA estimator)."""
    groups = np.unique(batch_ids)
    m = groups.size
    n = t.size
    if m < 2 or n <= m:
        return 0.0
    grand = float(np.mean(t))
    ss_between = 0.0
    ss_within = 0.0
    sum_nb2 = 0.0
    for g in groups:
        vals = t[batch_ids == g]
        nb = vals.size
        if nb < 1:
            continue
        mb = float(np.mean(vals))
        ss_between += nb * (mb - grand) ** 2
        ss_within += float(np.sum((vals - mb) ** 2))
        sum_nb2 += nb * nb
    df_b = m - 1
    df_w = n - m
    if df_b <= 0 or df_w <= 0:
        return 0.0
    msb = ss_between / df_b
    msw = ss_within / df_w
    n0 = (n - sum_nb2 / n) / df_b if df_b > 0 else 1.0
    denom = msb + (n0 - 1.0) * msw
    if denom <= 0:
        return 0.0
    return float(min(max((msb - msw) / denom, 0.0), 1.0))


def calibrate(
    plaintext: Sequence[int],
    timings: Sequence[float],
    key_byte: int,
    mask: int = 0,
    batch_ids: Optional[Sequence[int]] = None,
    line_entries: int = 1,
    dof: float = 4.0,
    outlier_q: float = 3.5,
) -> CalibratedLeakageModel:
    """Estimate a robust cache-set timing model from *labelled* profiling traces.

    ``key_byte`` is known during profiling.  NaNs are ignored.  Per cache set
    the location is the median and the scale the MAD; sets with too few or
    degenerate samples borrow the pooled scale.  The outlier mixture weight is
    the fraction of robust residuals beyond ``outlier_q`` MADs.
    """
    p = np.asarray(plaintext, dtype=np.int64)
    t = np.asarray(timings, dtype=np.float64)
    if p.shape != t.shape:
        raise ValueError("plaintext and timings must have the same shape")
    _, n_sets = _shift_and_mask(line_entries)
    sets = cache_sets(p, key_byte, mask=mask, line_entries=line_entries)
    valid = np.isfinite(t)
    if valid.sum() == 0:
        raise ValueError("calibration set contains no finite timings")

    mu = np.zeros(n_sets, dtype=np.float64)
    sigma = np.zeros(n_sets, dtype=np.float64)
    pooled = _robust_scale(t[valid])
    if pooled <= 0:
        pooled = float(np.std(t[valid])) or 1.0
    for s in range(n_sets):
        vals = t[valid & (sets == s)]
        if vals.size >= 8:
            mu[s] = float(np.median(vals))
            sc = _robust_scale(vals)
            sigma[s] = sc if sc > 0 else pooled
        else:
            # Pool across all sets (offset removed) for sparse sets.
            mu[s] = float(np.median(vals)) if vals.size else float(np.median(t[valid]))
            sigma[s] = pooled

    # Outlier weight from robust standardised residuals.
    z = np.abs((t[valid] - mu[sets[valid]]) / sigma[sets[valid]])
    outlier_p = float(np.mean(z > outlier_q)) if z.size else 0.0
    outlier_p = float(min(max(outlier_p, 0.0), 0.5))
    loose = float(np.percentile(t[valid], 99.9))
    tight = float(np.percentile(t[valid], 0.1))
    span = max(loose - tight, 1e-9)
    # Slight widening keeps the uniform density from being zero outside the
    # observed range (important for held-out traces).
    outlier_lo = tight - 0.1 * span
    outlier_hi = loose + 0.1 * span

    rho = 0.0
    if batch_ids is not None:
        b = np.asarray(batch_ids)
        if b.shape != t.shape:
            raise ValueError("batch_ids must match timings")
        # Remove the per-set location first; otherwise the set-to-set spread
        # dominates and masks the within-batch correlation.
        resid = t - mu[sets]
        rho = _estimate_icc(resid[valid], b[valid])

    return CalibratedLeakageModel(
        mu=mu,
        sigma=sigma,
        outlier_p=outlier_p,
        outlier_lo=outlier_lo,
        outlier_hi=outlier_hi,
        dof=dof,
        rho=rho,
        line_entries=line_entries,
    )


# ---------------------------------------------------------------------------
# Scoring
# ---------------------------------------------------------------------------

def _per_trace_loglik(
    model: CalibratedLeakageModel,
    timings: np.ndarray,
    sets_row: np.ndarray,
) -> np.ndarray:
    """Per-trace log-likelihood for one key hypothesis (NaNs -> 0 contribution)."""
    t = timings
    valid = np.isfinite(t)
    out = np.zeros(t.shape, dtype=np.float64)
    if not valid.any():
        return out
    sv = sets_row[valid]
    mu = model.mu[sv]
    lk = _student_t_logpdf(t[valid] - mu, model.sigma[sv], model.dof)
    if model.outlier_p > 0.0:
        span = max(model.outlier_hi - model.outlier_lo, 1e-300)
        uni = math.log(model.outlier_p) - math.log(span)
        lk = np.logaddexp(math.log1p(-model.outlier_p) + lk, uni)
    out[valid] = lk
    return out


def score_keys(
    model: CalibratedLeakageModel,
    plaintext: Sequence[int],
    timings: Sequence[float],
    mask: int = 0,
    keys: Optional[Sequence[int]] = None,
) -> Tuple[np.ndarray, np.ndarray]:
    """Total log-likelihood of every candidate key for a single byte position.

    Returns ``(keys, totals)`` with ``totals[i]`` the summed log-likelihood of
    ``keys[i]`` (missing timings contribute zero).
    """
    p = np.asarray(plaintext, dtype=np.int64)
    t = np.asarray(timings, dtype=np.float64)
    if p.shape != t.shape:
        raise ValueError("plaintext and timings must have the same shape")
    if keys is None:
        ks = np.arange(256, dtype=np.int64)
    else:
        ks = np.asarray(list(keys), dtype=np.int64)

    totals = np.empty(ks.size, dtype=np.float64)
    for i, k in enumerate(ks):
        s = cache_sets(p, int(k), mask=mask, line_entries=model.line_entries)
        totals[i] = float(np.sum(_per_trace_loglik(model, t, s)))
    return ks, totals


def _score_by_batch(
    model: CalibratedLeakageModel,
    plaintext: np.ndarray,
    timings: np.ndarray,
    batch_ids: np.ndarray,
    mask: int,
    keys: np.ndarray,
) -> Tuple[np.ndarray, np.ndarray]:
    """Per-key, per-batch summed log-likelihood, shape ``(len(keys), n_batches)``.

    Empty (all-NaN) batches are dropped.  Returns ``(keys, batched, used_batches)``.
    """
    groups = np.unique(batch_ids)
    used: List[int] = []
    cols: List[np.ndarray] = []
    for g in groups:
        sel = batch_ids == g
        if not np.isfinite(timings[sel]).any():
            continue
        _, totals = score_keys(model, plaintext[sel], timings[sel], mask=mask, keys=keys)
        cols.append(totals)
        used.append(int(g))
    if not cols:
        return keys, np.zeros((keys.size, 0), dtype=np.float64), np.zeros(0, dtype=np.int64)
    return keys, np.column_stack(cols), np.asarray(used, dtype=np.int64)

@dataclass
class ByteRanking:
    byte_index: int = -1
    order: np.ndarray = field(default_factory=lambda: np.zeros(0, dtype=np.int64))
    scores: np.ndarray = field(default_factory=lambda: np.zeros(0, dtype=np.float64))
    llr: np.ndarray = field(default_factory=lambda: np.zeros(0, dtype=np.float64))
    z: np.ndarray = field(default_factory=lambda: np.zeros(0, dtype=np.float64))
    se: np.ndarray = field(default_factory=lambda: np.zeros(0, dtype=np.float64))
    posterior: np.ndarray = field(default_factory=lambda: np.zeros(0, dtype=np.float64))
    best: int = -1
    mask: int = 0
    candidates: np.ndarray = field(default_factory=lambda: np.zeros(0, dtype=np.int64))
    candidate_posterior: np.ndarray = field(default_factory=lambda: np.zeros(0, dtype=np.float64))
    true_key: Optional[int] = None
    true_rank: Optional[int] = None

    def rank_of(self, key: int) -> Optional[int]:
        hit = np.nonzero(self.order == (int(key) & 0xFF))[0]
        return int(hit[0]) if hit.size else None

    def confidence(self, key: int) -> float:
        hit = np.nonzero(self.order == (int(key) & 0xFF))[0]
        return float(self.posterior[hit[0]]) if hit.size else 0.0


def rank_byte(
    model: CalibratedLeakageModel,
    plaintext: Sequence[int],
    timings: Sequence[float],
    batch_ids: Optional[Sequence[int]] = None,
    mask: int = 0,
    byte_index: int = -1,
    true_key: Optional[int] = None,
    z_thresh: float = 3.0,
    keys: Optional[Sequence[int]] = None,
) -> ByteRanking:
    """Likelihood-ratio search with cluster-robust pruning for one key byte.

    For every candidate key the total log-likelihood and the log-likelihood
    ratio ``D(k) = L(best) - L(k) >= 0`` are computed.  ``D(k)`` is a sum over
    traces; because traces inside a batch are correlated, its sampling
    variance is estimated with a cluster-robust (sandwich) estimator grouped
    by ``batch_ids``.  A candidate is retained when its robust z-score is
    within ``z_thresh``; retained candidates receive Gaussian-profile
    posterior weights.  Never prunes the best candidate.
    """
    p = np.asarray(plaintext, dtype=np.int64)
    t = np.asarray(timings, dtype=np.float64)
    if p.shape != t.shape:
        raise ValueError("plaintext and timings must have the same shape")
    if keys is None:
        ks = np.arange(256, dtype=np.int64)
    else:
        ks = np.asarray(list(keys), dtype=np.int64)
    if ks.size == 0:
        raise ValueError("empty key candidate set")

    if batch_ids is None:
        b = np.zeros(t.shape, dtype=np.int64)
    else:
        b = np.asarray(batch_ids, dtype=np.int64)
        if b.shape != t.shape:
            raise ValueError("batch_ids must match timings")

    _, LB, _ = _score_by_batch(model, p, t, b, mask, ks)
    if LB.shape[1] == 0:
        # No usable trace at all: uniform, zero confidence.
        order = ks.copy()
        posterior = np.full(ks.size, 1.0 / ks.size)
        return ByteRanking(
            byte_index=byte_index, order=order, scores=np.zeros(ks.size),
            llr=np.zeros(ks.size), z=np.zeros(ks.size), se=np.zeros(ks.size),
            posterior=posterior, best=int(order[0]), mask=mask,
            candidates=order.copy(), candidate_posterior=posterior.copy(),
            true_key=true_key, true_rank=None,
        )

    totals = LB.sum(axis=1)
    best_i = int(np.argmax(totals))
    best = int(ks[best_i])
    D = totals[best_i] - totals  # >= 0
    D[D < 0] = 0.0

    m = LB.shape[1]
    if m > 1:
        Diff = LB[best_i][None, :] - LB            # (K, m)
        Dbar = D / m
        var = (m / (m - 1.0)) * np.sum((Diff - Dbar[:, None]) ** 2, axis=1)
    else:
        # Single batch: no independent replication; fall back to the naive
        # Poisson/chi-square scale (conservative lower bound on variance).
        var = 2.0 * np.maximum(D, 0.0) + 1.0
    var = np.maximum(var, 1e-12)
    se = np.sqrt(var)
    z = np.where(D <= 0.0, 0.0, D / se)

    # Retain everything inside the noise floor (plus the best).
    keep = (z <= z_thresh) | (D <= 0.0)
    keep[best_i] = True
    cand_idx = np.nonzero(keep)[0]

    # Gaussian profile posterior over retained candidates.
    zc = z[cand_idx]
    logw = -0.5 * zc * zc
    logw -= np.max(logw)
    w = np.exp(logw)
    w /= w.sum()

    order = np.argsort(-totals, kind="stable")
    posterior = np.zeros(ks.size, dtype=np.float64)
    posterior[cand_idx] = w

    res = ByteRanking(
        byte_index=byte_index,
        order=ks[order],
        scores=totals[order],
        llr=D[order],
        z=z[order],
        se=se[order],
        posterior=posterior[order],
        best=best,
        mask=mask,
        candidates=ks[cand_idx],
        candidate_posterior=w,
        true_key=true_key,
    )
    if true_key is not None:
        res.true_rank = res.rank_of(int(true_key))
    return res


def rank_all_bytes(
    model: CalibratedLeakageModel,
    plaintext: np.ndarray,
    timings: np.ndarray,
    batch_ids: Optional[Sequence[int]] = None,
    mask: int = 0,
    true_key: Optional[Sequence[int]] = None,
    z_thresh: float = 3.0,
) -> List[ByteRanking]:
    """Rank every key byte independently.

    ``plaintext``/``timings`` are ``(n_traces, 16)`` arrays (timings may hold
    NaNs).  First-round table lookups make the 16 bytes conditionally
    independent given the leakage model, so per-byte ranking is exact and
    massively prunes the joint search.
    """
    P = np.asarray(plaintext)
    T = np.asarray(timings, dtype=np.float64)
    if P.ndim != 2 or P.shape[1] != 16:
        raise ValueError("plaintext must be (n_traces, 16)")
    if T.shape != P.shape:
        raise ValueError("timings must match plaintext shape")
    out: List[ByteRanking] = []
    for j in range(16):
        tk = int(true_key[j]) if true_key is not None else None
        out.append(
            rank_byte(
                model, P[:, j], T[:, j], batch_ids=batch_ids, mask=mask,
                byte_index=j, true_key=tk, z_thresh=z_thresh,
            )
        )
    return out

@dataclass
class FullKeyRanking:
    keys: np.ndarray                      # (K, 16) best full keys
    scores: np.ndarray                    # summed log-likelihood
    posterior: np.ndarray                 # normalised over the returned set
    per_byte_candidates: List[np.ndarray]


def combine_rankings(
    rankings: Sequence[ByteRanking],
    beam: int = 64,
    top_k: int = 16,
) -> FullKeyRanking:
    """Combine independent per-byte rankings with a beam-pruned product search.

    Because the per-byte byte-likelihoods add, the best full keys are found by
    a beam search over bytes that keeps only the ``beam`` highest-scoring
    partial assignments at each step.  This is the likelihood-ratio search with
    pruning at the key level (the per-byte candidate sets were already pruned).
    """
    if len(rankings) != 16:
        raise ValueError("expected 16 per-byte rankings")
    # State: (score, tuple_of_bytes, tuple_of_loglik_per_byte)
    beam_states: List[Tuple[float, Tuple[int, ...], Tuple[float, ...]]] = [
        (0.0, (), ())
    ]
    for r in rankings:
        if r.candidates.size == 0:
            raise ValueError("a byte ranking has no candidates")
        new_states: List[Tuple[float, Tuple[int, ...], Tuple[float, ...]]] = []
        for score, keytuple, lltuple in beam_states:
            for k in r.candidates:
                ki = int(k) & 0xFF
                # score for this byte from the ranking's own score table
                hit = np.nonzero(r.order == ki)[0]
                sc = float(r.scores[hit[0]]) if hit.size else -np.inf
                new_states.append(
                    (score + sc, keytuple + (ki,), lltuple + (sc,))
                )
        new_states.sort(key=lambda s: s[0], reverse=True)
        beam_states = new_states[:beam]

    beam_states.sort(key=lambda s: s[0], reverse=True)
    chosen = beam_states[:top_k]
    keys = np.asarray([c[1] for c in chosen], dtype=np.int64)
    scores = np.asarray([c[0] for c in chosen], dtype=np.float64)
    logw = scores - scores.max()
    w = np.exp(logw)
    w /= w.sum()
    return FullKeyRanking(
        keys=keys,
        scores=scores,
        posterior=w,
        per_byte_candidates=[r.candidates.copy() for r in rankings],
    )
