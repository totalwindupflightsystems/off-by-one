Fused (Flash-Attention) Online-Softmax Attention with LSE-Based Backward

Root-cause analysis

  1. 0/0 and -inf - -inf on fully-masked rows. A row with every key masked gives rowmax=-inf, l=0, L=-inf. exp(S-m), exp(S-L) and acc/l all produce NaN, which then contaminates gradients. Fix: guard divisions (where(l>0,...,1), zero result) and use masked ufuncs (np.subtract(..., out=..., where=...) then np.exp(..., out=..., where=...)). np.where alone still evaluates the NaN branch.
  2. Dropping the online-softmax correction. When a tile raises m_old → m_new, both l and acc must be rescaled by alpha = exp(m_old - m_new) before adding the tile. Otherwise output is just the last tile's softmax.
  3. Storing probabilities in backward. Requirement is to save only L (shape (B,H,N)) and recompute P = exp(S-L) per tile, keeping O(N) rather than O(N·M) memory.
  4. Finite negative masking constant. -1e9 leaks softmax mass when logits are very negative. Use true -inf.
  5. Ragged final tiles. Clamp i1=min(i0+bq,N) and build masks on the actual slice; never assume divisibility.
  6. fp16 accumulation. Inputs are fp16, but m, l, acc, rescale, and P@V must accumulate in fp32.
  7. Wrong dS correction. It is dS = P*(dP - D) with D_i = Σ_j dO_ij·O_ij, not a mismatched-broadcast surrogate.

Exact fix

The implementation (key parts):

# forward: online softmax, fp32 accumulation, masked ufuncs
m_new = np.maximum(m, np.max(S, axis=-1))
row_ok = np.isfinite(m_new)
alpha = np.zeros_like(m)
rescale = row_ok & np.isfinite(m)
np.subtract(m, m_new, out=alpha, where=rescale)
np.exp(alpha, out=alpha, where=rescale)

P = np.zeros_like(S)
p_mask = keep & row_ok[..., None]
np.subtract(S, m_new[..., None], out=P, where=p_mask)
np.exp(P, out=P, where=p_mask)

l = l * alpha + P.sum(axis=-1)
acc = acc * alpha[..., None] + np.einsum("bhnm,bhmd->bhnd", P, Vj)
m = m_new
# ...
O[:, :, qi, :] = np.where(l[..., None] > 0, acc / np.where(l[..., None] > 0, l[..., None], 1), 0)
L[:, :, qi] = np.where(l > 0, m + np.log(np.where(l > 0, l, 1)), neg_inf)

# backward: recompute P from saved L, never store P
D = np.einsum("bhnd,bhnd->bhn", dO, O)
row_ok = np.isfinite(Li)
P = np.zeros_like(S)
p_mask = keep & row_ok[..., None]
np.subtract(S, Li[..., None], out=P, where=p_mask)
np.exp(P, out=P, where=p_mask)
dV[:, :, kj, :] += np.einsum("bhnm,bhnd->bhmd", P, dOi)
dP = np.einsum("bhnd,bhmd->bhnm", dOi, Vj)
dS = np.where(keep, P * (dP - Di[..., None]), 0)
dQ[:, :, qi, :] += np.einsum("bhnm,bhmd->bhnd", dS, Kj) * scale
dK[:, :, kj, :] += np.einsum("bhnm,bhnd->bhmd", dS, Qi) * scale
