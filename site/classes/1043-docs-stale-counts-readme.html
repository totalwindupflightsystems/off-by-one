Answer

Root cause: the README's counts (14 autoloads / 395 files / 160 test files) were human/PM-supplied claims that drifted from disk truth (21 / 394 / 183). Fix: never trust PM claims — regenerate every count from the repo itself, then patch the README and guard with an independent recompute.

Fix script (fix_readme_counts.sh, run at repo root):

#!/usr/bin/env bash
set -euo pipefail
README="${1:-README.md}"

ROOT="$(git rev-parse --show-toplevel 2>/dev/null)" || { echo "not a git repo" >&2; exit 1; }
cd "$ROOT"
[ -f project.godot ] || { echo "no project.godot" >&2; exit 1; }

# 1) autoloads: active (non-commented) entries in [autoload]; ';'/'#' lines are decoys
AUTOLOADS="$(awk '
  /^\[/   { if (in_autoload) exit }           # next section -> stop
  /^\[autoload\]/ { in_autoload = 1; next }
  in_autoload && /^[A-Za-z_][A-Za-z0-9_]*[[:space:]]*=/ { count++ }
  END { print count + 0 }
' project.godot)"

# 2) total tracked files (untracked/junk excluded via git ls-files)
TOTAL_FILES="$(git ls-files | wc -l | tr -d ' ')"

# 3) test files: under tests/ OR matching test naming conventions
TEST_RE='(^|/)tests/|_test\.gd$|^test_[^/]+\.gd$'
TEST_FILES="$(git ls-files | grep -E "$TEST_RE" | wc -l | tr -d ' ' || true)"
# `|| true`: grep exits 1 on zero matches -> would trip set -e/pipefail

echo "disk truth -> autoloads=$AUTOLOADS total_files=$TOTAL_FILES test_files=$TEST_FILES"

# 4) patch README: replace the number guarding each count keyword (tests before files)
python3 - "$README" "$AUTOLOADS" "$TOTAL_FILES" "$TEST_FILES" <<'PY'
import re, sys
path, autoloads, total, tests = sys.argv[1], *map(int, sys.argv[2:5])
s = open(path, encoding="utf-8").read()
subs = (
    (re.compile(r'(?<!\d)(\d+)(?=\s*autoloads?\b)', re.I), str(autoloads)),
    (re.compile(r'(?<!\d)(\d+)(?=\s*(?:test|spec)[^.\n]*files?\b)', re.I), str(tests)),
    (re.compile(r'(?<!\d)(\d+)(?=\s*files?\b)', re.I), str(total)),
)
for rx, repl in subs: s = rx.sub(repl, s)
open(path, "w", encoding="utf-8").write(s)
PY

# 5) guard: assert README now agrees with disk (doc-only close-out gate)
grep -qiE "$AUTOLOADS autoloads\b"  "$README" || exit 1
grep -qiE "$TOTAL_FILES files\b"    "$README" || exit 1
grep -qiE "$TEST_FILES test files\b" "$README" || exit 1
echo "guard PASS: README counts match disk truth"

This fixed the drift in the fixture README: - **14 autoloads** → **21**, **395 files** → **394**, **160 test files** → **183**.
