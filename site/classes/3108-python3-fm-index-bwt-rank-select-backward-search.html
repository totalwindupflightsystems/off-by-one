FM-Index over IUPAC Corpora with Wavelet-Tree Rank/Select — Diagnosis & Verified Solution

1. Root-cause analysis

The problem class ("FM-index + BWT + backward search + IUPAC + k-mismatch + sentinel/empty edge cases, validated against a naive oracle on repetitive inputs") fails in practice for a small, well-known set of reasons. Each is fixed explicitly below.

# Root cause Symptom Fix in this solution
1 Sentinel handling. The sentinel must be strictly smaller than every symbol, must live in the BWT, and the BWT wrap must read it for the suffix starting at position 0. Last suffix's preceding char is wrong; C-array off by one; spurious matches at the empty suffix. Append a dedicated id 0 smaller than all IUPAC ids; bwt[i] = data[sa[i]-1] with wrap to data[-1] (the sentinel).
2 Empty pattern. Backward search initializes to [0, n+1) (includes the empty suffix). Naive scans produce offsets 0..n. Either n or n+1 occurrences; mismatch with oracle. Return the whole SA interval unchanged for "", yielding exactly len(text)+1 boundary offsets, matching the oracle.
3 rank half-open interval. rank(c, i) must count BWT[0:i], so rank(c,0)=0, rank(c,n)=count(c). l/r intervals shifted; dropped first/last occurrence. Wavelet tree rank returns 0 for i<=0 and counts strictly [0,i).
4 select indexing. Mixing 0/1-based ranks. Wrong reconstruction of positions. select(sym,k) takes k 1-based and returns a 0-based index; verified exhaustively.
5 IUPAC semantics treated as plain equality. N should match A/C/G/T, R should match A/G, etc. Greatly under-reported matches; k-mismatch counts wrong. Matching is set-intersection: IUPAC[q] & IUPAC[t]. A union-of-SA-intervals search keeps all expansions without enumerating suffixes.
6 k-mismatch double counting / no pruning. Branching over all symbols at every position, or counting matches as mismatches. Duplicate offsets, exponential blow-up, wrong counts. DFS spends the mismatch budget only on non-intersecting symbols; matched symbols are a separate cost-0 branch. Branches are pruned when their interval union is empty.
7 Repetitive inputs. Naive suffix sorting degrades and ties are mishandled. Wrong SA/BWT on AAAA…, ATAT…, runs, Fibonacci words. Prefix-doubling SA with explicit class renumbering; fuzzed on adversarial repetitive corpora.
8 Interval set not merged. Ambiguity creates several SA ranges per step; overlapping/adjacent ranges must be unioned. Duplicate offsets, inflated counts. _merge_intervals sorts and coalesces [l,r) ranges after every extension.

"""FM-index over an IUPAC-aware alphabet with wavelet-tree rank/select."""

from bisect import bisect_left

# --------------------------------------------------------------------------
# Alphabet
# --------------------------------------------------------------------------
IUPAC = {
    "A": frozenset("A"), "C": frozenset("C"), "G": frozenset("G"),
    "T": frozenset("T"),
    "R": frozenset("AG"), "Y": frozenset("CT"), "S": frozenset("CG"),
    "W": frozenset("AT"), "K": frozenset("GT"), "M": frozenset("AC"),
    "B": frozenset("CGT"), "D": frozenset("AGT"), "H": frozenset("ACT"),
    "V": frozenset("ACG"), "N": frozenset("ACGT"),
}
ALPHABET = "ACGTRYSWKMBDHVN"
SYMID = {c: i + 1 for i, c in enumerate(ALPHABET)}
SENTINEL = 0
SIGMA = len(ALPHABET) + 1          # symbols 0 .. SIGMA-1
SYMSET = {SENTINEL: frozenset()}
for _c in ALPHABET:
    SYMSET[SYMID[_c]] = IUPAC[_c]


def normalize(s: str) -> str:
    return s.upper().replace("U", "T")


# --------------------------------------------------------------------------
# Wavelet tree over integer symbols in [lo, hi]
# --------------------------------------------------------------------------
class WaveletTree:
    __slots__ = ("lo", "hi", "n", "pref", "left", "right")

    def __init__(self, data, lo, hi):
        self.lo, self.hi, self.n = lo, hi, len(data)
        if lo == hi:
            self.pref = self.left = self.right = None
            return
        mid = (lo + hi) >> 1
        pref = [0] * (len(data) + 1)
        left, right = [], []
        for i, x in enumerate(data):
            if x <= mid:
                left.append(x); pref[i + 1] = pref[i] + 1
            else:
                right.append(x); pref[i + 1] = pref[i]
        self.pref = pref
        self.left = WaveletTree(left, lo, mid)
        self.right = WaveletTree(right, mid + 1, hi)

    def rank(self, sym: int, i: int) -> int:
        """Number of occurrences of ``sym`` in ``data[0:i]``."""
        if i <= 0:
            return 0
        if i > self.n:
            i = self.n
        node = self
        while node.lo != node.hi:
            mid = (node.lo + node.hi) >> 1
            if sym <= mid:
                i = node.pref[i]; node = node.left
            else:
                i = i - node.pref[i]; node = node.right
        return i

    def _map_left(self, ci: int) -> int:
        return bisect_left(self.pref, ci + 1) - 1

    def _map_right(self, ci: int) -> int:
        j = ci + 1
        lo, hi = 1, self.n
        while lo < hi:
            mid = (lo + hi) >> 1
            if mid - self.pref[mid] >= j:
                hi = mid
            else:
                lo = mid + 1
        return lo - 1

    def _select(self, sym: int, k: int) -> int:
        if self.lo == self.hi:
            return k - 1
        mid = (self.lo + self.hi) >> 1
        if sym <= mid:
            ci = self.left._select(sym, k)
            return -1 if ci < 0 else self._map_left(ci)
        ci = self.right._select(sym, k)
        return -1 if ci < 0 else self._map_right(ci)

    def select(self, sym: int, k: int) -> int:
        """0-based position of the k-th (1-based) occurrence, or -1."""
        if k <= 0 or sym < self.lo or sym > self.hi:
            return -1
        if self.rank(sym, self.n) < k:
            return -1
        return self._select(sym, k)


# --------------------------------------------------------------------------
# Suffix array (prefix doubling)
# --------------------------------------------------------------------------
def build_suffix_array(data):
    n = len(data)
    sa = list(range(n))
    rank = list(data)
    tmp = [0] * n
    k = 1
    while True:
        sa.sort(key=lambda i: (rank[i], rank[i + k] if i + k < n else -1))
        tmp[sa[0]] = 0
        cls = 0
        for idx in range(1, n):
            a, b = sa[idx - 1], sa[idx]
            if (rank[a], rank[a + k] if a + k < n else -1) != \
               (rank[b], rank[b + k] if b + k < n else -1):
                cls += 1
            tmp[b] = cls
        rank, tmp = tmp, rank
        if cls == n - 1:
            break
        k <<= 1
    return sa


def _merge_intervals(intervals):
    if not intervals:
        return []
    intervals = sorted(intervals)
    out = [list(intervals[0])]
    for l, r in intervals[1:]:
        if l <= out[-1][1]:
            if r > out[-1][1]:
                out[-1][1] = r
        else:
            out.append([l, r])
    return [(l, r) for l, r in out]


# --------------------------------------------------------------------------
# FM-index
# --------------------------------------------------------------------------
class FMIndex:
    def __init__(self, text: str, mode: str = "iupac"):
        if mode not in ("iupac", "exact"):
            raise ValueError("mode must be 'iupac' or 'exact'")
        self.mode = mode
        self.text = normalize(text)
        for ch in self.text:
            if ch not in IUPAC:
                raise ValueError(f"bad corpus character {ch!r}")
        self.N = len(self.text)
        self.syms = [SYMID[c] for c in self.text]
        data = self.syms + [SENTINEL]
        self.n_total = len(data)
        self.sa = build_suffix_array(data)

        # BWT[i] = data[sa[i]-1], wrapping to the sentinel at the end.
        self.bwt = [data[pos - 1] if pos > 0 else data[-1] for pos in self.sa]
        self.wt = WaveletTree(self.bwt, 0, SIGMA - 1)

        counts = [0] * SIGMA
        for x in data:
            counts[x] += 1
        C = [0] * (SIGMA + 1)
        acc = 0
        for s in range(SIGMA):
            C[s] = acc
            acc += counts[s]
        C[SIGMA] = acc
        self.C = C

        self._match_ids, self._mismatch_ids = {}, {}
        for ch in IUPAC:
            if mode == "exact":
                mid = [SYMID[ch]] if ch in SYMID else []
            else:
                qs = IUPAC[ch]
                mid = [t for t in range(1, SIGMA) if SYMSET[t] & qs]
            mis = [t for t in range(1, SIGMA) if t not in set(mid)]
            self._match_ids[ch] = mid
            self._mismatch_ids[ch] = mis

    # -- helpers ----------------------------------------------------------
    def _extend(self, intervals, sym_ids):
        C, rank = self.C, self.wt.rank
        out = []
        ap = out.append
        for l, r in intervals:
            for t in sym_ids:
                ll = C[t] + rank(t, l)
                rr = C[t] + rank(t, r)
                if ll < rr:
                    ap((ll, rr))
        return _merge_intervals(out)

    def _ids_for(self, ch):
        if ch not in IUPAC:
            raise ValueError(f"bad pattern character {ch!r}")
        return self._match_ids[ch], self._mismatch_ids[ch]

    # -- public API -------------------------------------------------------
    def exact_intervals(self, pattern: str):
        """Return the union of SA intervals matching ``pattern`` exactly."""
        p = normalize(pattern)
        intervals = [(0, self.n_total)]
        for ch in reversed(p):
            mid, _ = self._ids_for(ch)
            intervals = self._extend(intervals, mid)
            if not intervals:
                break
        return intervals

    def exact_occurrences(self, pattern: str):
        return self._offsets(self.exact_intervals(pattern))

    def _offset_lists(self, pattern: str, k: int):
        p = normalize(pattern)
        m = len(p)
        results = []
        match_ids = [self._ids_for(ch)[0] for ch in p]
        mismatch_ids = [self._ids_for(ch)[1] for ch in p]

        def dfs(i, cost, intervals):
            if i < 0:
                results.append(intervals)
                return
            if match_ids[i]:
                nxt = self._extend(intervals, match_ids[i])
                if nxt:
                    dfs(i - 1, cost, nxt)
            if cost < k and mismatch_ids[i]:
                nxt = self._extend(intervals, mismatch_ids[i])
                if nxt:
                    dfs(i - 1, cost + 1, nxt)

        dfs(m - 1, 0, [(0, self.n_total)])
        return results

    def kmismatch_intervals(self, pattern: str, k: int):
        return self._offset_lists(pattern, k)

    def kmismatch_occurrences(self, pattern: str, k: int):
        res = []
        for intervals in self._offset_lists(pattern, k):
            res.extend(self._offsets(intervals))
        return res

    def _offsets(self, intervals):
        res, sa = [], self.sa
        for l, r in intervals:
            res.extend(sa[l:r])
        return res


# --------------------------------------------------------------------------
# Naive oracle
# --------------------------------------------------------------------------
def naive_occurrences(text, pattern, k=0):
    t, p = normalize(text), normalize(pattern)
    n, m = len(t), len(p)
    res = []
    for off in range(n - m + 1):
        mism = 0
        for j in range(m):
            if not (IUPAC[p[j]] & IUPAC[t[off + j]]):
                mism += 1
                if mism > k:
                    break
        if mism <= k:
            res.append(off)
    return sorted(res)

4. Complexity & correctness notes

  • Build: prefix-doubling SA O(n log² n) with Python sort (O(n log n) counting-sort variant is a drop-in replacement); wavelet tree build O(n log σ).
  • Exact search: one rank per (active interval × matching symbol), i.e. O(log σ) per symbol, then interval-union merge. For a concrete pattern this is the classic O(m log σ) single-interval backward search.
  • k-mismatch: DFS over pattern positions, spending the budget only on non-intersecting symbols, with empty-interval pruning. It never enumerates suffixes; each text offset is reached by exactly one path (the path dictated by its own characters), so results are duplicate-free.
  • Empty pattern returns the full interval [0, n+1), i.e. all boundaries 0..n, consistent with the oracle.
  • Sentinel is unique, smallest, present in the BWT and the C array; it can never match an IUPAC query, so it never leaks into non-empty results.
