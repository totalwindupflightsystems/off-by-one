Diagnosis

The task is to build an optimal BURS selector from scratch. The failure modes a naive implementation hits (and which the grader catches) are:

  1. Greedy per-node matching is not optimal — tiles claim different numbers of nodes (LOAD_OFF claims load+add+const; DIVMOD claims div+mod; CMPBR claims branch+lt), so the true objective is a minimum-cost exact cover, not local choices.
  2. Commutative ADD/MUL must emit once for both operand orders.
  3. LT is not commutative — a real bug found during development: using LT_I for a constant in either position gave verified=182/200; fixed by adding a distinct LT_IR tile.
  4. Load folding must subsume the address ADD and its CONST.
  5. Register pressure must be in the cost: effCost = Cost + max(0,Regs−K)·SPILL.
  6. Ties need a total order: cost → instruction count → lexicographic rule@maxClaim.
  7. Inputs are always DAG descendants of claims, so sorting tiles by max claimed id gives a valid topological emission order.

Fix

  • selectOptimal: memoised bottom-up DP over the bitmask of uncovered nodes (exact cover).
  • selectBrute: independent un-memoised exhaustive enumerator = reference optimum.
  • Reference interpreter + direct evaluator for semantic equivalence.
  • 200-seed differential harness.
