Below is the deliverable.

Fix: untracked deployed cron copy drifting from its tracked canonical

Root cause

The cron entrypoint (~/.hermes/scripts/x.sh) is a hand-deployed copy of the tracked script (<repo>/scripts/x.sh). Deployment was a manual cp scripts/x.sh ~/.hermes/scripts/, so two independent mutable files existed with nothing enforcing parity. When the canonical script gained a pipeline leg, the deployed copy was never updated. The cron job kept exiting 0 (a missing leg is not an error), so the drift was invisible for ~6 days.

The failure is structural, not a one-off typo: * no single source of truth at run time — the thing cron executes is untracked; * no check at the execution path (the script itself) or outside it (CI/make); * no deployment path that cannot silently no-op.

The fix makes drift loud in three places (at run time, at deploy time, and in a deterministic selftest) while keeping the existing cron harness green.

Exact fix

Layout (~/parity-demo/repo assumed; adjust REPO/paths):

repo/
├── Makefile
└── scripts/
    ├── x.sh                      # tracked canonical (single source of truth)
    ├── check-deployed-parity.sh  # read-only checker (missing/non-exec/drift)
    ├── selftest-parity.sh        # deterministic parity selftest
    └── harness.sh                # the EXISTING cron harness (slice trap)

1. Canonical script with a run-time parity guard (ABOVE the marker)

scripts/x.sh:

#!/usr/bin/env bash
# x.sh - tracked canonical pipeline (single source of truth).
# ---------------------------------------------------------------------------
# PARITY GUARD - MUST STAY ABOVE the "set -euo pipefail" marker below.
#
# A cron harness slices this file starting at the marker and runs the slice
# from /tmp.  If this guard sat below the marker, the sliced copy's own path
# (/tmp/slice.sh) would never equal the canonical path and every harness case
# would fail with a false drift.  Keep the guard above the marker.
# ---------------------------------------------------------------------------
__self="${BASH_SOURCE[0]:-$0}"
__repo="${REPO:-$HOME/parity-demo/repo}"
__canon="${__repo}/scripts/$(basename "$__self")"
__self_hash="$(sha256sum -- "$__self" 2>/dev/null | awk '{print $1}')"
__canon_hash="$(sha256sum -- "$__canon" 2>/dev/null | awk '{print $1}')"
if [ -z "$__canon_hash" ] || [ "$__self_hash" != "$__canon_hash" ]; then
  {
    printf '%s\n' "FATAL: deployed copy has drifted from the tracked canonical script."
    printf '  running file : %s\n' "$__self"
    printf '  canonical    : %s\n' "$__canon"
    printf '  running hash : %s\n' "${__self_hash:-<unreadable>}"
    printf '  canonical    : %s\n' "${__canon_hash:-<missing or unreadable>}"
    printf '  remedy       : run "make install" in %s to redeploy, then re-run.\n' "$__repo"
  } >&2
  exit 1
fi
# ---------------------------------------------------------------------------
# === pipeline body is sliced from the marker line below by the cron harness ===
set -euo pipefail

leg1() { printf '%s\n' "x: leg1 (extract)"; }
leg2() { printf '%s\n' "x: leg2 (transform)"; }

main() {
  leg1
  leg2
}
main "$@"

Notes: * $0/BASH_SOURCE[0] is the running file; the canonical is ${REPO}/scripts/<basename>. If the canonical cannot be hashed, that is treated as drift (not as "skip the check"). * The message names both paths, both hashes, and the remedy. * REPO can be exported by crontab; the default is a pinned absolute path so the deployed copy never has to guess.

2. Read-only checker with distinct failure modes

scripts/check-deployed-parity.sh:

#!/usr/bin/env bash
# check-deployed-parity.sh - read-only parity check for a deployed copy.
set -euo pipefail

name="${1:-x.sh}"
repo="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
canon="${repo}/scripts/${name}"
deploy_dir="${HERMES_SCRIPTS:-$HOME/.hermes/scripts}"
deployed="${deploy_dir}/${name}"

hash_of() { sha256sum -- "$1" 2>/dev/null | awk '{print $1}'; }

if [ ! -e "$canon" ]; then
  printf 'PARITY FAIL: tracked canonical is missing: %s\n' "$canon" >&2
  exit 2
fi

if [ ! -e "$deployed" ]; then
  {
    printf 'PARITY FAIL: deployed copy is missing: %s\n' "$deployed"
    printf '  canonical : %s\n' "$canon"
    printf '  remedy    : run "make install" in %s\n' "$repo"
  } >&2
  exit 1
fi

if [ ! -f "$deployed" ]; then
  printf 'PARITY FAIL: deployed copy is not a regular file: %s\n' "$deployed" >&2
  exit 1
fi

if [ ! -x "$deployed" ]; then
  {
    printf 'PARITY FAIL: deployed copy is not executable: %s\n' "$deployed"
    printf '  remedy    : run "make install" in %s (or chmod 0755 %s)\n' "$repo" "$deployed"
  } >&2
  exit 1
fi

canon_hash="$(hash_of "$canon")"
deployed_hash="$(hash_of "$deployed")"
if [ "$canon_hash" != "$deployed_hash" ]; then
  {
    printf 'PARITY FAIL: deployed copy has drifted: %s\n' "$deployed"
    printf '  canonical     : %s\n' "$canon"
    printf '  deployed hash : %s\n' "$deployed_hash"
    printf '  canonical hash: %s\n' "$canon_hash"
    printf '  remedy        : run "make install" in %s\n' "$repo"
  } >&2
  exit 1
fi

printf 'PARITY OK: %s matches %s (%s)\n' "$deployed" "$canon" "$canon_hash"

3. Make target replaces the hand cp, checker gates the success line

Makefile:

SHELL := /bin/bash
REPO  := $(CURDIR)
DEPLOY_DIR := $(HOME)/.hermes/scripts

.PHONY: install check selftest clean

install: check-src
    @mkdir -p "$(DEPLOY_DIR)"
    @cp "scripts/x.sh" "$(DEPLOY_DIR)/x.sh"
    @chmod 0755 "$(DEPLOY_DIR)/x.sh"
    @REPO="$(REPO)" scripts/check-deployed-parity.sh x.sh \
      && printf 'installed %s/x.sh (sha256 %s)\n' "$(DEPLOY_DIR)" "$$(sha256sum scripts/x.sh | cut -d' ' -f1)"

check:
    @REPO="$(REPO)" scripts/check-deployed-parity.sh x.sh

selftest:
    @REPO="$(REPO)" scripts/selftest-parity.sh

check-src:
    @test -x scripts/x.sh || { echo "scripts/x.sh missing or not executable" >&2; exit 1; }

clean:
    @rm -f "$(DEPLOY_DIR)/x.sh"

The && means the installed … line prints only if the checker passed. Any missing/non-executable/drifted copy makes make install fail loudly.

4. Deterministic selftest

scripts/selftest-parity.sh:

#!/usr/bin/env bash
# selftest-parity.sh - deterministic selftest for the deployed-parity guard.
set -euo pipefail

repo="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
name="x.sh"
real_deploy_dir="${HERMES_SCRIPTS:-$HOME/.hermes/scripts}"
real_deployed="${real_deploy_dir}/${name}"

sandbox="$(mktemp -d "${TMPDIR:-/tmp}/parity-selftest.XXXXXX")"
trap 'rm -rf "$sandbox"' EXIT

real_before="none"
if [ -e "$real_deployed" ]; then
  real_before="$(sha256sum -- "$real_deployed" | awk '{print $1}')"
fi

pass=0; fail=0
ok() { printf 'PASS: %s\n' "$1"; pass=$((pass + 1)); }
no() { printf 'FAIL: %s\n' "$1"; fail=$((fail + 1)); }

# 1. in-sync
cp "$repo/scripts/$name" "$sandbox/$name"; chmod 0755 "$sandbox/$name"
if HERMES_SCRIPTS="$sandbox" REPO="$repo" "$sandbox/$name" >/dev/null 2>&1; then
  ok "in-sync: guard lets the deployed copy run"
else no "in-sync: guard rejected a matching copy"; fi
if HERMES_SCRIPTS="$sandbox" "$repo/scripts/check-deployed-parity.sh" "$name" >/dev/null 2>&1; then
  ok "in-sync: checker reports PARITY OK"
else no "in-sync: checker rejected a matching copy"; fi

# 2. drifted
printf '\n# drifted pipeline leg accidentally missing on the deployed copy\n' >>"$sandbox/$name"
drift_out="$(HERMES_SCRIPTS="$sandbox" REPO="$repo" "$sandbox/$name" 2>&1)" && drift_rc=0 || drift_rc=$?
if [ "$drift_rc" -ne 0 ] && printf '%s' "$drift_out" | grep -q 'drifted'; then
  ok "drifted: guard refuses and names the drift"
else no "drifted: guard did not refuse (rc=$drift_rc)"; fi
if HERMES_SCRIPTS="$sandbox" "$repo/scripts/check-deployed-parity.sh" "$name" >/dev/null 2>&1; then
  no "drifted: checker reported OK on a drifted copy"
else ok "drifted: checker fails on a drifted copy"; fi
if printf '%s' "$drift_out" | grep -q 'leg1'; then
  no "guard-refuse: pipeline body executed despite drift"
else ok "guard-refuse: pipeline body never ran on a drifted copy"; fi

# 3. missing
rm -f "$sandbox/$name"
miss_dir="$(mktemp -d "$sandbox/empty.XXXXXX")"
miss_out="$(HERMES_SCRIPTS="$miss_dir" "$repo/scripts/check-deployed-parity.sh" "$name" 2>&1)" && miss_rc=0 || miss_rc=$?
if [ "$miss_rc" -ne 0 ] && printf '%s' "$miss_out" | grep -q 'deployed copy is missing'; then
  ok "missing: checker reports a distinct missing-copy error"
else no "missing: checker did not report missing copy (rc=$miss_rc)"; fi

# 4. non-executable
cp "$repo/scripts/$name" "$sandbox/$name"; chmod 0644 "$sandbox/$name"
noexec_out="$(HERMES_SCRIPTS="$sandbox" "$repo/scripts/check-deployed-parity.sh" "$name" 2>&1)" && noexec_rc=0 || noexec_rc=$?
if [ "$noexec_rc" -ne 0 ] && printf '%s' "$noexec_out" | grep -q 'not executable'; then
  ok "non-executable: checker reports a distinct not-executable error"
else no "non-executable: checker did not report non-executable copy (rc=$noexec_rc)"; fi

# invariant: real deployed copy never touched
real_after="none"
if [ -e "$real_deployed" ]; then
  real_after="$(sha256sum -- "$real_deployed" | awk '{print $1}')"
fi
if [ "$real_before" = "$real_after" ]; then
  ok "invariant: real deployed copy hash unchanged ($real_before)"
else no "invariant: real deployed copy changed"; fi

printf -- '---\nselftest: %d passed, %d failed\n' "$pass" "$fail"
[ "$fail" -eq 0 ]

5. Placement trap — keep the guard above the marker

scripts/harness.sh:

#!/usr/bin/env bash
set -euo pipefail
repo="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
slice="$(mktemp "${TMPDIR:-/tmp}/x-slice.XXXXXX.sh")"
trap 'rm -f "$slice"' EXIT
awk '/^set -euo pipefail/{f=1} f' "$repo/scripts/x.sh" >"$slice"
chmod 0755 "$slice"
bash "$slice"

If the guard lived below set -euo pipefail, every harness run would slice it into /tmp/x-slice.*.sh, where $__self != $__canon, producing a false drifted failure. Placing the guard above the marker means the slice does not contain it and the harness stays green. Re-run the existing harness after adding the guard.

Deploy/install:

chmod 0755 repo/scripts/*.sh
cd repo && make install      # copy -> chmod -> checker gates "installed ..."

E. Make gating

With a drifted deployed copy, make check fails and prints no success line (make: *** [Makefile:22: check] Error 1); after make install it prints PARITY OK followed by installed …. The success line is gated on the checker by &&.
