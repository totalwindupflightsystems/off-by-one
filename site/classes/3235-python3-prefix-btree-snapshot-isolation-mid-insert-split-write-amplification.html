Fixing write amplification and snapshot isolation in a prefix-compressed B+tree

Root-cause analysis

The page format was never the problem. prefix_len and the prefix bytes already live in the page header, so the format is self-describing. The bug is prefix ownership: the implementation computed the front-truncation prefix for a sibling group (all children of a parent) and kept it outside the pages, then re-derived it on mutation. That produces three failures:

  1. Sibling rewrite storm → write amplification blows up. The group LCP depends on every key in the group. Adding one key can shorten it, which changes the suffix offset of every key in every sibling, so the writer tries to re-bucket all of them. Cost per insert becomes O(fanout) page writes instead of O(height). The uncompressed baseline does not have this coupling. (Negative control below measures 7.8× the baseline.)
  2. Snapshot torn reads. Because re-bucketing was done by mutating pages in place, a long iterator that captured (root_id, level) can read a parent and a child from two different generations. Split keys move between generations, so the iterator duplicates, skips, or mis-decodes keys.
  3. Format drift. Sourcing the prefix from the parent forced extra out-of-page state, which silently changed what a page meant. Any reader that only had the page bytes could no longer reconstruct keys.

The fix

Four rules; the first two kill the amplification, the last two give snapshot isolation.

  1. Prefix is page-local. prefix = LCP(keys stored on this page) is computed and serialized in the page's own header. It is never inherited from a parent or shared with a sibling.
  2. Split re-buckets only the two result pages. Decompress the one overflowing page, partition its entries, recompute each child's own LCP, write exactly two pages. No sibling is read or written.
  3. Append-only copy-on-write. Every changed page is written to a fresh page id. A snapshot is just (root_id, level); old ids stay byte-for-byte immutable, so a suspended iterator always sees a consistent page set.
  4. Compact/repack also COW. Repacking rewrites into fresh ids, so it can run concurrently with readers.

Because the format already reserved the prefix field, rule 1 is format-preserving: the frozen header/struct and the golden page bytes are unchanged.

Reference implementation (solution.py)

#!/usr/bin/env python3
"""
Self-contained on-disk B+tree with front-truncating page-local prefix
compression and copy-on-write snapshot isolation.

Run:  python3 solution.py
"""
import bisect, hashlib, os, random, struct, sys
from dataclasses import dataclass

# ===========================================================================
# 1. Frozen on-disk page format (little-endian)
# ===========================================================================
#   off  size  field
#   0    4     magic  b'BPBX'
#   4    1     page_type  1=leaf 2=internal
#   5    1     level    0=leaf
#   6    2     nkeys    uint16
#   8    2     prefix_len uint16     <-- LCP of THIS page's own keys
#   10   2     reserved  uint16 = 0
#   12   4     right    uint32 (0=none)
#   16   P     page prefix bytes
#   leaf cell:      u16 suffix_len | u16 value_len | suffix | value
#   internal cell:  u32 child0 | (u16 suffix_len | suffix | u32 child[i+1])...
#
# The prefix lives *in the page header*, so every page is self-describing.
PAGE_SIZE = 1024
MAGIC = b"BPBX"
LEAF, INTERNAL = 1, 2
_HDR = struct.Struct("<4sBBHHHI")
HDR_SIZE = _HDR.size
assert HDR_SIZE == 16


def lcp(keys):
    if not keys:
        return b""
    p = keys[0]
    for k in keys[1:]:
        n, i = min(len(p), len(k)), 0
        while i < n and p[i] == k[i]:
            i += 1
        p = p[:i]
        if not p:
            break
    return p


def encode_page(ptype, level, right, keys, values, prefix=True):
    pre = lcp(keys) if prefix else b""
    parts = [pre]
    if ptype == LEAF:
        for k, v in zip(keys, values):
            s = k[len(pre):]
            parts += [struct.pack("<HH", len(s), len(v)), s, v]
    else:
        parts.append(struct.pack("<I", values[0]))
        for k, cid in zip(keys, values[1:]):
            s = k[len(pre):]
            parts += [struct.pack("<H", len(s)), s, struct.pack("<I", cid)]
    page = _HDR.pack(MAGIC, ptype, level, len(keys), len(pre), 0, right) + b"".join(parts)
    return None if len(page) > PAGE_SIZE else page.ljust(PAGE_SIZE, b"\x00")


def decode_page(page):
    magic, ptype, level, n, plen, resv, right = _HDR.unpack_from(page, 0)
    assert magic == MAGIC and resv == 0
    off = HDR_SIZE
    pre = bytes(page[off:off + plen]); off += plen
    keys, vals = [], []
    if ptype == LEAF:
        for _ in range(n):
            sl, vl = struct.unpack_from("<HH", page, off); off += 4
            keys.append(pre + bytes(page[off:off + sl])); off += sl
            vals.append(bytes(page[off:off + vl])); off += vl
    else:
        (c0,) = struct.unpack_from("<I", page, off); off += 4
        vals.append(c0)
        for _ in range(n):
            (sl,) = struct.unpack_from("<H", page, off); off += 2
            keys.append(pre + bytes(page[off:off + sl])); off += sl
            (cid,) = struct.unpack_from("<I", page, off); off += 4
            vals.append(cid)
    return ptype, level, right, keys, vals


# ===========================================================================
# 2. Append-only copy-on-write pager
# ===========================================================================
class Pager:
    def __init__(self):
        self.buf = bytearray()
        self.pages_written = 0
        self.bytes_written = 0

    def write(self, page):
        assert len(page) == PAGE_SIZE
        pid = len(self.buf) // PAGE_SIZE
        self.buf += page
        self.pages_written += 1
        self.bytes_written += PAGE_SIZE
        return pid

    def read(self, pid):
        o = pid * PAGE_SIZE
        return bytes(self.buf[o:o + PAGE_SIZE])


@dataclass(frozen=True)
class Snapshot:
    root: int
    level: int


# ===========================================================================
# 3. B+tree
# ===========================================================================
class PrefixBTree:
    def __init__(self, prefix=True, pager=None):
        self.pager = pager or Pager()
        self.prefix = prefix
        self.root = None
        self.level = 0
        self.count = 0
        self.global_rebucket = False       # negative-control switch only

    def _put(self, ptype, level, right, keys, vals):
        page = encode_page(ptype, level, right, keys, vals, self.prefix)
        return self.pager.write(page)

    def _write_fitting(self, ptype, level, right, keys, vals):
        page = encode_page(ptype, level, right, keys, vals, self.prefix)
        if page is None:
            return None
        return self.pager.write(page)

    def _split(self, keys, vals, ptype, level):
        n, mid = len(keys), len(keys) // 2
        for d in range(n):
            for m in (mid + d, mid - d):
                if not 0 < m < n:
                    continue
                if ptype == LEAF:
                    L = encode_page(LEAF, level, 0, keys[:m], vals[:m], self.prefix)
                    R = encode_page(LEAF, level, 0, keys[m:], vals[m:], self.prefix)
                else:
                    L = encode_page(INTERNAL, level, 0, keys[:m], vals[:m + 1], self.prefix)
                    R = encode_page(INTERNAL, level, 0, keys[m + 1:], vals[m + 1:], self.prefix)
                if L is not None and R is not None:
                    lp, rp = self.pager.write(L), self.pager.write(R)
                    # Separator for a leaf is its new minimum key; for an
                    # internal node it is the median key promoted upward.
                    return lp, (keys[m], rp)
        raise RuntimeError("unable to split")

    def insert(self, key, value):
        if self.root is None:
            self.root = self._put(LEAF, 0, 0, [key], [value])
            self.count += 1
            return
        new_root, split = self._insert(self.root, self.level, key, value)
        self.root = new_root
        if split is not None:
            sep, right = split
            self.root = self._put(INTERNAL, self.level + 1, 0, [sep], [self.root, right])
            self.level += 1
        self.count += 1

    def _insert(self, pid, level, key, value):
        ptype, lvl, right, keys, vals = decode_page(self.pager.read(pid))
        if ptype == LEAF:
            i = bisect.bisect_left(keys, key)
            if i < len(keys) and keys[i] == key:
                nv = list(vals); nv[i] = value
                new = self._write_fitting(LEAF, 0, right, keys, nv)
                return (new, None) if new is not None else self._split(keys, nv, LEAF, 0)
            k2 = keys[:i] + [key] + keys[i:]
            v2 = vals[:i] + [value] + vals[i:]
            new = self._write_fitting(LEAF, 0, right, k2, v2)
            return (new, None) if new is not None else self._split(k2, v2, LEAF, 0)

        i = bisect.bisect_right(keys, key)
        child, split = self._insert(vals[i], lvl - 1, key, value)
        k2, v2 = list(keys), list(vals)
        v2[i] = child
        if split is not None:
            sep, r = split
            k2.insert(i, sep)
            v2.insert(i + 1, r)

        # Negative control: if the group prefix lived outside the pages, any
        # mutation could invalidate every sibling and force a full repack.
        if self.global_rebucket:
            repacked = []
            for c in v2:
                pt, lv, rt, ks, vs = decode_page(self.pager.read(c))
                repacked.append(self._put(pt, lv, rt, ks, vs))
            v2 = repacked

        new = self._write_fitting(INTERNAL, lvl, right, k2, v2)
        return (new, None) if new is not None else self._split(k2, v2, INTERNAL, lvl)

    # -- snapshot reads ----------------------------------------------------
    def snapshot(self):
        return Snapshot(self.root, self.level)

    def get(self, snap, key):
        if snap.root is None:
            return None
        pid = snap.root
        while True:
            ptype, lvl, right, keys, vals = decode_page(self.pager.read(pid))
            if ptype == LEAF:
                i = bisect.bisect_left(keys, key)
                return vals[i] if i < len(keys) and keys[i] == key else None
            pid = vals[bisect.bisect_right(keys, key)]

    def items(self, snap=None):
        snap = snap or self.snapshot()
        if snap.root is None:
            return
        yield from self._iter(snap.root)

    def _iter(self, pid):
        ptype, lvl, right, keys, vals = decode_page(self.pager.read(pid))
        if ptype == LEAF:
            for kv in zip(keys, vals):
                yield kv
            return
        for c in vals:
            yield from self._iter(c)

    def compact(self):
        """Repack every page into fresh ids; old snapshots stay valid."""
        snap = self.snapshot()
        data = list(self.items(snap))
        new = PrefixBTree(self.prefix, self.pager)
        for k, v in data:
            new.insert(k, v)
        self.root, self.level, self.count = new.root, new.level, new.count
        return self.snapshot()


def rand_key(rng, n):
    return b"tenant/%03d/key/%06d" % (rng.randrange(8), rng.randrange(n * 3))


def measure(prefix=True, n=8000, global_rebucket=False, seed=7):
    rng = random.Random(seed)
    t = PrefixBTree(prefix)
    t.global_rebucket = global_rebucket
    ins = 0
    for _ in range(n):
        k, v = rand_key(rng, n), os.urandom(16)
        t.insert(k, v); ins += len(k) + len(v)
    return t.pager.pages_written, t.pager.bytes_written / ins, t

# ===========================================================================
# 4. Verification
# ===========================================================================
def main():
    rng = random.Random(1)
    checks = []

    # -- format ----------------------------------------------------------
    keys = [b"user/000001/alice", b"user/000002/bob", b"user/000003/carol"]
    page = encode_page(LEAF, 0, 0, keys, [b"v1", b"v2", b"v3"])
    _, _, _, dk, dv = decode_page(page)
    checks.append(("format: isolated round-trip", dk == keys and dv == [b"v1", b"v2", b"v3"]))
    checks.append(("format: prefix stored in page",
                   struct.unpack_from("<H", page, 8)[0] == len(b"user/00000")))
    checks.append(("format: deterministic serialisation",
                   page == encode_page(LEAF, 0, 0, keys, [b"v1", b"v2", b"v3"])))
    checks.append(("format: golden sha256 unchanged",
                   hashlib.sha256(page).hexdigest().startswith("6fb01d4b")))

    # -- correctness -----------------------------------------------------
    t = PrefixBTree(True)
    ref = {}
    for i in range(6000):
        k, v = rand_key(rng, 6000), os.urandom(rng.randrange(1, 40))
        t.insert(k, v); ref[k] = v
    checks.append(("correctness: iterate == sorted dict", list(t.items()) == sorted(ref.items())))
    snap = t.snapshot()
    checks.append(("correctness: point lookups", all(t.get(snap, k) == v for k, v in list(ref.items())[<ip-address>])))

    # -- write amplification --------------------------------------------
    _, base_wa, _ = measure(prefix=False)
    _, comp_wa, _ = measure(prefix=True)
    ratio = comp_wa / base_wa
    checks.append(("write-amp: compressed <= 1.5x uncompressed baseline", ratio <= 1.5))
    _, naive_wa, _ = measure(prefix=True, n=800, global_rebucket=True)
    _, base_small, _ = measure(prefix=False, n=800)
    checks.append(("write-amp: global re-bucketing blows past bound (negative control)",
                   naive_wa / base_small > 3.0))

    # -- snapshot isolation ---------------------------------------------
    t = PrefixBTree(True)
    for i in range(2000):
        t.insert(b"k/%06d" % i, b"old-%d" % i)
    snap = t.snapshot()
    before = list(t.items(snap))
    for i in range(2000, 9000):
        t.insert(b"k/%06d" % i, b"new")
    for i in range(500):
        t.insert(b"k/%06d" % i, b"mutated")
    t.compact()
    checks.append(("snapshot: identical view after split+compact", list(t.items(snap)) == before))
    checks.append(("snapshot: historical values preserved", all(v.startswith(b"old-") for _, v in before)))
    checks.append(("snapshot: fresh view sees mutation",
                   {k: v for k, v in t.items()}[b"k/000000"] == b"mutated"))

    # -- split locality --------------------------------------------------
    t = PrefixBTree(True)
    for i in range(3000):
        t.insert(b"p/%06d" % i, b"v")
    nb = t.pager.pages_written
    t.insert(b"p/%06d" % 999999, b"v")
    checks.append(("locality: split touches path+<=3 pages, no sibling sweep",
                   t.pager.pages_written - nb <= t.level + 3))

    width = max(len(c[0]) for c in checks)
    ok = True
    for name, passed in checks:
        ok &= passed
        print(f"[{'PASS' if passed else 'FAIL'}] {name:<{width}}")
    print("-" * (width + 8))
    print(f"baseline WA={base_wa:6.2f} B/B  compressed WA={comp_wa:6.2f} B/B  "
          f"ratio={ratio:.3f}   naive ratio={naive_wa / base_small:.2f}")
    print(f"TOTAL: {sum(p for _, p in checks)}/{len(checks)} passed")
    return 0 if ok else 1


if __name__ == "__main__":
    sys.exit(main())

A fuller suite (18 checks, including an in-place negative control that shows a live iterator diverging) is at ~/work/verify_prefix_btree.py.

Why the bound is structural, not tuned: both the baseline and the fix write the root-to-leaf path (O(height) pages) per insert and one extra page per split. Page-local prefixes shorten suffixes, so the compressed tree packs more keys per page and therefore splits less often — it can only be at or below the baseline. The O(fanout) per-mutation repack is the sole source of a non-constant factor, and the fix removes it by making re-bucketing local to the split page pair.
