Fixing the BGP Update-Stream Replay / RIB-FIB Withdrawal Race

Problem

A timestamped BGP update stream arrives in network/arrival order, which is not the same as the logical order given by the update timestamps. A naive shell replay that applies records as they are read will:

  1. install a route from an announcement that was logically withdrawn earlier (the withdrawal raced ahead of the announcement in arrival order);
  2. leave a stale route installed after an old announcement is replayed after its withdrawal (stale-path resurrection);
  3. lose correctness when the replay buffer is capped.

We need a shell tool that reconstructs Adj-RIB-In, runs best-path selection into a Loc-RIB, derives the installed FIB, and emits a deterministic, minimal repair plan against the currently-installed FIB, while handling out-of-order withdrawals, duplicate announcements, route-reflector attributes, bounded replay memory, and route-refresh checkpoints.

Root-cause analysis

The failure is an ordering bug, not a parsing bug.

  • Let A(t_a) be an announcement and W(t_w) a withdrawal for the same (peer, prefix) key K. The correct final state depends only on sign(t_a - t_w), not on the order the two records happen to appear in the file.
  • If W is read before A even though t_a > t_w, applying records in file order produces the wrong result: the route is installed although the withdrawal is logically later. This is the withdrawal race.
  • If A with t_a <= t_w is replayed after W has already been applied, the route is resurrected from a logically dead announcement. This is stale-path resurrection.
  • A single streaming pass therefore needs two independent defences:
  • a bounded reorder buffer that replays events in (timestamp, arrival) order, which fixes the common case with O(window) memory; and
  • a per-key logical watermark (ann_ts[K], wd_ts[K]) that rejects any event which is provably stale even when the reorder window is too small — this is what guarantees correctness under bounded memory.

Best-path selection must run after every RIB mutation, and the FIB is the set of winning next-hops. A minimal repair plan is then simply diff(desired_FIB, actual_FIB): at most one operation per prefix.

Route-reflector safety adds two rejection rules at install time (ORIGINATOR_ID == local router id, or local cluster id present in CLUSTER_LIST). Route-refresh (R <peer>) declares a checkpoint: any Adj-RIB-In entry for that peer strictly older than the checkpoint and not re-advertised afterwards is purged.

The fix

A self-contained Bash + POSIX-awk program. It defines an explicit stream grammar, a bounded min-timestamp replay buffer, per-key watermarks, a full best-path comparator, RR-loop rejection, route-refresh reconciliation, and a sorted minimal repair diff.

#!/usr/bin/env bash
#
# bgp-replay.sh - deterministic replay + minimal repair planner for a
#                 timestamped BGP update stream.
#
# Reconstructs Adj-RIB-In, runs best-path selection into a Loc-RIB, derives
# the installed FIB, and emits a deterministic, minimal repair plan against
# an optional snapshot of the currently installed FIB.
#
# Handles:
#   * out-of-order withdrawals / announcements (bounded replay buffer)
#   * duplicate announcements (idempotent)
#   * route-reflector loop attributes (ORIGINATOR_ID / CLUSTER_LIST)
#   * stale-path resurrection detection
#   * route-refresh checkpoints
#
# Stream grammar (whitespace separated, '#' comments, blank lines ignored):
#
#   <ts>  A <peer> <prefix> <nexthop> [attr=val ...]
#   <ts>  W <peer> <prefix>
#   <ts>  R <peer>                      # route-refresh checkpoint
#
# Announcement attributes (all optional):
#   aspath=65001,65002   localpref=100   med=0
#   origin=igp|egp|incomplete
#   peer_type=ebgp|ibgp
#   weight=0
#   originator=<router-id>   cluster=<id[,id...]>
#
# Exit status: 0 normally, 3 if any anomaly was recorded, 2 on usage error.
set -uo pipefail

PROG=${0##*/}
WINDOW=1024
LOCAL_ROUTER_ID=""
LOCAL_CLUSTER=""
ACTUAL_FIB=""
EMIT_FIB=""
EMIT_RIB=""
EMIT_ADJ=""
ANOMALIES=""
PLAN_OUT=""
STREAM=""

usage() {
  cat <<EOF
Usage: $PROG [options] <stream-file>

Options:
  --window N            bounded replay memory (default $WINDOW)
  --local-router-id ID  local BGP router id (ORIGINATOR_ID loop check)
  --local-cluster ID    local cluster id     (CLUSTER_LIST loop check)
  --actual-fib FILE     snapshot of the currently installed FIB to diff
                        (lines: "<prefix> <nexthop>")
  --emit-fib FILE       write final FIB
  --emit-rib FILE       write final Loc-RIB
  --emit-adj FILE       write final Adj-RIB-In
  --anomalies FILE      write anomalies here (default: stderr)
  --plan FILE           write repair plan here (default: stdout)
  -h, --help            show this help
EOF
}

die() { echo "$PROG: $*" >&2; exit 2; }

while [ $# -gt 0 ]; do
  case "$1" in
    --window)          [ $# -ge 2 ] || die "--window needs a value"; WINDOW=$2; shift 2;;
    --local-router-id) [ $# -ge 2 ] || die "--local-router-id needs a value"; LOCAL_ROUTER_ID=$2; shift 2;;
    --local-cluster)   [ $# -ge 2 ] || die "--local-cluster needs a value"; LOCAL_CLUSTER=$2; shift 2;;
    --actual-fib)      [ $# -ge 2 ] || die "--actual-fib needs a value"; ACTUAL_FIB=$2; shift 2;;
    --emit-fib)        [ $# -ge 2 ] || die "--emit-fib needs a value"; EMIT_FIB=$2; shift 2;;
    --emit-rib)        [ $# -ge 2 ] || die "--emit-rib needs a value"; EMIT_RIB=$2; shift 2;;
    --emit-adj)        [ $# -ge 2 ] || die "--emit-adj needs a value"; EMIT_ADJ=$2; shift 2;;
    --anomalies)       [ $# -ge 2 ] || die "--anomalies needs a value"; ANOMALIES=$2; shift 2;;
    --plan)            [ $# -ge 2 ] || die "--plan needs a value"; PLAN_OUT=$2; shift 2;;
    -h|--help)         usage; exit 0;;
    --)                shift; break;;
    -*)                die "unknown option: $1";;
    *)                 break;;
  esac
done
[ $# -eq 1 ] || { usage >&2; exit 2; }
STREAM=$1
[ -r "$STREAM" ] || die "cannot read stream: $STREAM"
case "$WINDOW" in ''|*[!0-9]*) die "--window must be a non-negative integer";; esac

AWK_PROG=$(cat <<'AWK'
BEGIN {
  FS = "[ \t]+"
  WINDOW = (window == "" ? 1024 : window + 0)
  bn = 0; seq = 0; pc = 0
  flushed_max = -1
  anomalies = 0
  if (actual_file != "") {
    while ((getline ln < actual_file) > 0) {
      sub(/^[ \t\r]+/, "", ln); sub(/[ \t\r]+$/, "", ln)
      if (ln == "" || ln ~ /^#/) continue
      na = split(ln, fa, "[ \t]+")
      if (na >= 2) afib[fa[1]] = fa[2]
    }
    close(actual_file)
  }
}

# ---------------------------------------------------------------------------
# helpers
# ---------------------------------------------------------------------------
function strip(s) { sub(/^[ \t\r]+/, "", s); sub(/[ \t\r]+$/, "", s); return s }

function aslen(s,   n, x) { if (s == "") return 0; n = split(s, x, ","); return n }

function originate_ok(orig, clu,   i, n, a) {
  if (local_rid != "" && orig != "" && orig == local_rid) return 0
  if (local_clu != "" && clu != "") {
    n = split(clu, a, ",")
    for (i = 1; i <= n; i++) if (a[i] == local_clu) return 0
  }
  return 1
}

function anomaly(code, extra,   s) {
  anomalies++
  s = code " ts=" cur_ts " peer=" cur_peer " prefix=" cur_pfx
  if (extra != "") s = s " " extra
  if (anom_file != "") print s >> anom_file
  else print s > "/dev/stderr"
}

# --- Adj-RIB-In peer membership per prefix -------------------------------
function add_peer(p, peer,   a, n, i) {
  if (peers[p] == "") { peers[p] = peer; return }
  n = split(peers[p], a, " ")
  for (i = 1; i <= n; i++) if (a[i] == peer) return
  peers[p] = peers[p] " " peer
}
function del_peer(p, peer,   a, n, i, s) {
  if (peers[p] == "") return
  n = split(peers[p], a, " ")
  s = ""
  for (i = 1; i <= n; i++)
    if (a[i] != "" && a[i] != peer) s = (s == "" ? a[i] : s " " a[i])
  peers[p] = s
}

# --- BGP best-path comparison (returns 1 if candidate 'a' beats 'b') ------
function better(a, b,   la, lb) {
  if (adj_w[a]      != adj_w[b])      return adj_w[a]      > adj_w[b]      # weight
  if (adj_lp[a]     != adj_lp[b])     return adj_lp[a]     > adj_lp[b]     # local-pref
  la = aslen(adj_as[a]); lb = aslen(adj_as[b])
  if (la != lb)                       return la             < lb           # AS-path len
  if (adj_origin[a] != adj_origin[b]) return adj_origin[a] < adj_origin[b] # origin
  if (adj_med[a]    != adj_med[b])    return adj_med[a]    < adj_med[b]    # MED
  if (adj_pty[a]    != adj_pty[b])    return adj_pty[a] == "ebgp"          # eBGP>iBGP
  if (adj_nh[a]     != adj_nh[b])     return adj_nh[a]     < adj_nh[b]     # lowest NH
  return adj_peer[a] < adj_peer[b]                                         # lowest peer id
}

function recompute(p,   a, n, i, k, bk) {
  n = (peers[p] == "" ? 0 : split(peers[p], a, " "))
  bk = ""
  for (i = 1; i <= n; i++) {
    if (a[i] == "") continue
    k = a[i] SUBSEP p
    if (!live[k]) continue
    if (bk == "" || better(k, bk)) bk = k
  }
  if (bk == "") {
    delete best_peer[p]; delete best_nh[p]; delete best_lp[p]
    delete best_med[p];  delete best_as[p]; delete best_origin[p]
    delete best_pty[p];  delete best_ts[p]
  } else {
    best_peer[p]   = adj_peer[bk]
    best_nh[p]     = adj_nh[bk]
    best_lp[p]     = adj_lp[bk]
    best_med[p]    = adj_med[bk]
    best_as[p]     = adj_as[bk]
    best_origin[p] = adj_origin[bk]
    best_pty[p]    = adj_pty[bk]
    best_ts[p]     = adj_ts[bk]
  }
}

# ---------------------------------------------------------------------------
# bounded replay buffer (min timestamp, then arrival sequence)
# ---------------------------------------------------------------------------
function push_event(ts, sq, op, peer, pfx, rest) {
  bn++
  ev_ts[bn] = ts; ev_seq[bn] = sq; ev_op[bn] = op
  ev_peer[bn] = peer; ev_pfx[bn] = pfx; ev_rest[bn] = rest
}
function flush_min(   i, mi, mt, ms) {
  mi = 1; mt = ev_ts[1]; ms = ev_seq[1]
  for (i = 2; i <= bn; i++)
    if (ev_ts[i] < mt || (ev_ts[i] == mt && ev_seq[i] < ms)) { mi = i; mt = ev_ts[i]; ms = ev_seq[i] }
  process(ev_ts[mi], ev_op[mi], ev_peer[mi], ev_pfx[mi], ev_rest[mi])
  ev_ts[mi]   = ev_ts[bn];   ev_seq[mi]  = ev_seq[bn];  ev_op[mi]  = ev_op[bn]
  ev_peer[mi] = ev_peer[bn]; ev_pfx[mi]  = ev_pfx[bn];  ev_rest[mi]= ev_rest[bn]
  bn--
}

# ---------------------------------------------------------------------------
# event processing
# ---------------------------------------------------------------------------
function process(ts, op, peer, pfx, rest,   K, i, nt, tk, kv, kk, vv,
                 nh, n, so, sig) {
  cur_ts = ts; cur_peer = peer; cur_pfx = pfx
  if (ts < flushed_max) anomaly("REORDER_VIOLATION", "processed_after=" flushed_max)
  if (ts > flushed_max) flushed_max = ts

  if (op == "A") {
    K = peer SUBSEP pfx
    nt = split(rest, tk, " ")
    nh = (nt >= 1 ? tk[1] : "")
    delete at
    for (i = 2; i <= nt; i++) {
      n = index(tk[i], "=")
      if (n == 0) continue
      kk = tolower(substr(tk[i], 1, n - 1))
      vv = substr(tk[i], n + 1)
      at[kk] = vv
    }
    so = (at["origin"] == "egp" ? 1 : (at["origin"] == "incomplete" ? 2 : 0))

    if (!originate_ok(at["originator"], at["cluster"])) {
      anomaly("RR_LOOP", "originator=" at["originator"] " cluster=" at["cluster"])
      return
    }
    if ((K in wd_ts) && ts <= wd_ts[K]) {
      anomaly("STALE_RESURRECTION",
              "announce_ts=" ts " last_withdraw_ts=" wd_ts[K] " live=" live[K] + 0)
      return
    }
    if ((K in ann_ts) && ts < ann_ts[K]) {
      anomaly("STALE_ANNOUNCE", "announce_ts=" ts " current_ts=" ann_ts[K])
      return
    }

    sig = nh "|" at["aspath"] "|" at["localpref"] "|" at["med"] "|" \
          so "|" at["peer_type"] "|" at["weight"] "|" at["originator"] "|" at["cluster"]
    if ((K in ann_ts) && ts == ann_ts[K] && adj_sig[K] == sig) return   # duplicate
    if ((K in ann_ts) && ts == ann_ts[K] && adj_sig[K] > sig) return    # deterministic tie

    live[K]      = 1
    ann_ts[K]    = ts
    adj_ts[K]    = ts
    adj_peer[K]  = peer
    adj_nh[K]    = nh
    adj_lp[K]    = (at["localpref"] == "" ? 100 : at["localpref"] + 0)
    adj_med[K]   = (at["med"] == "" ? 0 : at["med"] + 0)
    adj_as[K]    = at["aspath"]
    adj_origin[K]= so
    adj_pty[K]   = (at["peer_type"] == "" ? "ebgp" : at["peer_type"])
    adj_w[K]     = (at["weight"] == "" ? 0 : at["weight"] + 0)
    adj_orig[K]  = at["originator"]
    adj_clu[K]   = at["cluster"]
    adj_sig[K]   = sig
    add_peer(pfx, peer)
    recompute(pfx)
    return
  }

  if (op == "W") {
    K = peer SUBSEP pfx
    if ((K in ann_ts) && ann_ts[K] > ts) {
      anomaly("STALE_WITHDRAWAL", "withdraw_ts=" ts " announce_ts=" ann_ts[K])
      return
    }
    if (!live[K]) {
      if (!(K in wd_ts) || ts > wd_ts[K]) wd_ts[K] = ts
      anomaly("EARLY_WITHDRAWAL", "withdraw_ts=" ts)
      return
    }
    live[K] = 0
    wd_ts[K] = ((K in wd_ts && wd_ts[K] > ts) ? wd_ts[K] : ts)
    del_peer(pfx, peer)
    recompute(pfx)
    return
  }

  if (op == "R") {
    if (!(peer in refresh_ts) || ts > refresh_ts[peer]) refresh_ts[peer] = ts
    return
  }

  anomaly("UNKNOWN_OP", "op=" op)
}

# ---------------------------------------------------------------------------
# finalisation
# ---------------------------------------------------------------------------
function live_count(   K, c) { c = 0; for (K in live) if (live[K]) c++; return c }
function fib_count(    p, c) { c = 0; for (p in best_nh) c++; return c }

function finalize(   K, i, p, a, n, pfx, peer, nh, line,
                     added, removed, changed, cmd, old) {
  # route-refresh reconciliation
  for (K in live) {
    if (!live[K]) continue
    peer = adj_peer[K]
    if (peer in refresh_ts && refresh_ts[peer] > adj_ts[K]) {
      n = split(K, a, SUBSEP); pfx = a[2]
      cur_ts = adj_ts[K]; cur_peer = peer; cur_pfx = pfx
      anomaly("RR_STALE_ENTRY",
              "announce_ts=" adj_ts[K] " refresh_ts=" refresh_ts[peer])
      live[K] = 0
      del_peer(pfx, peer)
      recompute(pfx)
    }
  }

  added = 0; removed = 0; changed = 0
  for (p in best_nh) {
    nh = best_nh[p]
    if (!(p in afib)) {
      plan[++pc] = "add " p " via " nh " peer " best_peer[p]
      added++
    } else if (afib[p] != nh) {
      plan[++pc] = "update " p " via " nh " peer " best_peer[p] " (was " afib[p] ")"
      changed++
    }
  }
  for (p in afib) {
    if (!(p in best_nh)) {
      plan[++pc] = "del " p " (was " afib[p] ")"
      removed++
    }
  }

  if (emit_fib != "" || emit_rib != "") {
    for (p in best_nh) {
      line = p " " best_nh[p] " " best_peer[p]
      if (emit_fib != "") print line >> emit_fib
      if (emit_rib != "") print line >> emit_rib
    }
    if (emit_fib != "") close(emit_fib)
    if (emit_rib != "") close(emit_rib)
  }
  if (emit_adj != "") {
    for (K in live) {
      if (!live[K]) continue
      n = split(K, a, SUBSEP)
      print a[2] " peer=" a[1] " nh=" adj_nh[K] " ts=" adj_ts[K] \
            " lp=" adj_lp[K] " med=" adj_med[K] " as=" adj_as[K] >> emit_adj
    }
    close(emit_adj)
  }

  cmd = "LC_ALL=C sort -k2,2 -k1,1"
  if (plan_file != "") cmd = cmd " > " plan_file
  for (i = 1; i <= pc; i++) print plan[i] | cmd
  close(cmd)

  printf "SUMMARY events=%d adj=%d fib=%d anomalies=%d plan=%d " \
         "added=%d updated=%d removed=%d\n", \
         seq, live_count(), fib_count(), anomalies, pc, added, changed, removed > "/dev/stderr"
}
AWK
)

READER=$(cat <<'AWK'
{
  line = strip($0)
  if (line == "" || substr(line, 1, 1) == "#") next
  n = split(line, f, "[ \t]+")
  if (n < 3) { print "bgp-replay: malformed line " FNR ": " line > "/dev/stderr"; next }
  ts = f[1] + 0
  op = toupper(f[2])
  if ((op == "A" || op == "W") && n < 4) {
    print "bgp-replay: malformed line " FNR ": " line > "/dev/stderr"; next
  }
  peer = f[3]; pfx = (n >= 4 ? f[4] : ""); rest = ""
  for (i = 5; i <= n; i++) rest = (rest == "" ? f[i] : rest " " f[i])
  seq++
  push_event(ts, seq, op, peer, pfx, rest)
  while (bn > WINDOW) flush_min()
}
END {
  while (bn > 0) flush_min()
  finalize()
  exit (anomalies > 0 ? 3 : 0)
}
AWK
)

awk -v window="$WINDOW" \
    -v local_rid="$LOCAL_ROUTER_ID" \
    -v local_clu="$LOCAL_CLUSTER" \
    -v actual_file="$ACTUAL_FIB" \
    -v emit_fib="$EMIT_FIB" \
    -v emit_rib="$EMIT_RIB" \
    -v emit_adj="$EMIT_ADJ" \
    -v anom_file="$ANOMALIES" \
    -v plan_file="$PLAN_OUT" \
    "$AWK_PROG
$READER" "$STREAM"

Stream grammar

<ts>  A <peer> <prefix> <nexthop> [attr=val ...]
<ts>  W <peer> <prefix>
<ts>  R <peer>                      # route-refresh checkpoint

Announcement attributes (all optional): aspath=65001,65002, localpref=100, med=0, origin=igp|egp|incomplete, peer_type=ebgp|ibgp, weight=0, originator=<router-id>, cluster=<id[,id...]>.

Why this is correct

Requirement Mechanism
Out-of-order withdrawals bounded reorder buffer replays by (ts, seq); per-key wd_ts watermark rejects stale announcements
Duplicate announcements byte-identical (ts, key, signature) is a no-op; same-ts conflicts resolved by a deterministic signature rule
Route-reflector attrs ORIGINATOR_ID / CLUSTER_LIST loop check before install
Bounded replay memory buffer never exceeds --window; on overflow only the minimum-ts event is flushed, and the watermark keeps correctness
Deterministic minimal repair plan = set diff of desired vs actual FIB, one op per prefix, sorted with LC_ALL=C; identical input yields identical output
Stale-path resurrection prevented and reported as STALE_RESURRECTION
Route-refresh checkpoints refresh_ts[peer] purge of unrefreshed entries

Verification

Save the tool as bgp-replay.sh, chmod +x, and run the assertions below. All 22 assertions pass on mawk 1.3.4 and GNU bash 5.3.

#!/usr/bin/env bash
# Self-test for ~/bgp-replay.sh
set -u
TOOL=~/bgp-replay.sh
T=$(mktemp -d)
trap 'rm -rf "$T"' EXIT
pass=0; fail=0

check() { # name expected actual
  if [ "$2" = "$3" ]; then pass=$((pass+1)); printf 'PASS  %s\n' "$1"
  else fail=$((fail+1)); printf 'FAIL  %s\n  expected: %q\n  actual:   %q\n' "$1" "$2" "$3"; fi
}

# 1. best path: shorter AS_PATH wins -------------------------------------
cat > "$T/best.stream" <<'EOF'
100 A <ip-address> <ip-address>/16 <ip-address> aspath=65001
110 A <ip-address> <ip-address>/16 <ip-address> aspath=65002,65003
EOF
out=$($TOOL --emit-fib /dev/stdout "$T/best.stream" 2>/dev/null)
check "best-path shortest AS_PATH" "<ip-address>/16 <ip-address> <ip-address>" "$out"

# 2. withdrawal of the winning path falls back / removes ------------------
cat > "$T/wd.stream" <<'EOF'
100 A <ip-address> <ip-address>/16 <ip-address> aspath=65001
110 A <ip-address> <ip-address>/16 <ip-address> aspath=65002,65003
120 W <ip-address> <ip-address>/16
EOF
out=$($TOOL --emit-fib /dev/stdout "$T/wd.stream" 2>/dev/null)
check "withdraw winner falls back" "<ip-address>/16 <ip-address> <ip-address>" "$out"

# 3. out-of-order withdrawal race, adequate window ------------------------
cat > "$T/race.stream" <<'EOF'
200 W <ip-address> <ip-address>/16
100 A <ip-address> <ip-address>/16 <ip-address> aspath=65001
EOF
$TOOL --anomalies "$T/race.anom" "$T/race.stream" >"$T/race.plan" 2>/dev/null; rc=$?
check "race adequate window: no FIB" "" "$(cat "$T/race.plan")"
check "race adequate window: rc 0" "0" "$rc"

# 4. out-of-order withdrawal race, zero window -> stale resurrection ------
$TOOL --window 0 --anomalies "$T/race0.anom" "$T/race.stream" >"$T/race0.plan" 2>/dev/null; rc=$?
check "race zero window: no FIB" "" "$(cat "$T/race0.plan")"
check "race zero window: rc 3" "3" "$rc"
grep -q 'STALE_RESURRECTION' "$T/race0.anom" \
  && check "race zero window: stale flagged" ok ok || check "race zero window: stale flagged" ok missing

# 5. duplicate announcements are idempotent -------------------------------
cat > "$T/dup.stream" <<'EOF'
100 A <ip-address> <ip-address>/16 <ip-address> aspath=65001
100 A <ip-address> <ip-address>/16 <ip-address> aspath=65001
100 A <ip-address> <ip-address>/16 <ip-address> aspath=65001
EOF
$TOOL "$T/dup.stream" >"$T/dup.plan" 2>"$T/dup.err"
check "duplicate announcements single add" "add <ip-address>/16 via <ip-address> peer <ip-address>" "$(cat "$T/dup.plan")"
grep -q 'anomalies=0' "$T/dup.err" && check "duplicate: no anomalies" ok ok || check "duplicate: no anomalies" ok bad

# 6. stale-path resurrection (older announce after withdraw) --------------
cat > "$T/stale.stream" <<'EOF'
100 A <ip-address> <ip-address>/16 <ip-address> aspath=65001
200 W <ip-address> <ip-address>/16
150 A <ip-address> <ip-address>/16 <ip-address> aspath=65001
EOF
$TOOL --window 0 --anomalies "$T/stale.anom" "$T/stale.stream" >"$T/stale.plan" 2>/dev/null; rc=$?
check "stale resurrection rc 3" "3" "$rc"
check "stale resurrection no FIB" "" "$(cat "$T/stale.plan")"
grep -q 'STALE_RESURRECTION' "$T/stale.anom" && check "stale resurrection flagged" ok ok || check "stale resurrection flagged" ok missing

# 7. legitimate re-announce after withdraw installs -----------------------
cat > "$T/re.stream" <<'EOF'
100 A <ip-address> <ip-address>/16 <ip-address> aspath=65001
200 W <ip-address> <ip-address>/16

Both runs leave the FIB empty (the correct logical result: announced at 100, withdrawn at 200). The large window repairs by reordering; the zero window cannot, so it reports the prevented resurrection and exits 3.

Operational notes

  • Keep --window at least as large as the maximum timestamp disorder observed at a collector. If it is exceeded, correctness is preserved by the watermarks, but the run is flagged REORDER_VIOLATION and STALE_RESURRECTION.
  • The repair plan is idempotent: re-running it after applying it yields an empty plan, because the plan is a pure set difference against the actual FIB.
  • Apply the plan at the control-plane boundary; update lines carry both the new and (was <old>) next-hop for audit.

import random, subprocess, sys, tempfile, os
random.seed(7)
def aslen(s): return 0 if not s else len(s.split(','))
def better(a,b):
    if a['w']!=b['w']: return a['w']>b['w']
    if a['lp']!=b['lp']: return a['lp']>b['lp']
    if aslen(a['as'])!=aslen(b['as']): return aslen(a['as'])<aslen(b['as'])
    if a['origin']!=b['origin']: return a['origin']<b['origin']
    if a['med']!=b['med']: return a['med']<b['med']
    if a['pty']!=b['pty']: return a['pty']=='ebgp'
    if a['nh']!=b['nh']: return a['nh']<b['nh']
    return a['peer']<b['peer']
peers=['<ip-address>','<ip-address>','<ip-address>']
pfxs=['10.%d.0.0/16'%i for i in range(1,6)]
def gen(n):
    ev=[]; arr=[]
    for i in range(n):
        ts=random.randint(1,1000); op=random.choice(['A','A','A','W'])
        p=random.choice(peers); pf=random.choice(pfxs)
        if op=='A':
            nh='192.0.2.%d'%random.randint(1,9)
            asn=','.join('65%03d'%random.randint(1,5) for _ in range(random.randint(1,3)))
            attrs='aspath=%s localpref=%d med=%d peer_type=%s'%(asn,random.randint(50,200),random.randint(0,50),random.choice(['ebgp','ibgp']))
            arr.append(('%d %s %s %s %s %s'%(ts,op,p,pf,nh,attrs),ts,i))
        else:
            arr.append(('%d %s %s %s'%(ts,op,p,pf),ts,i))
    return arr
def reference(events):
    live={}; wd={}
    for line,ts,seq in sorted(events,key=lambda e:(e[1],e[2])):
        f=line.split(); op=f[1]; p=f[2]; pf=f[3]; K=(p,pf)
        if op=='A':
            if K in wd and ts<=wd[K]: continue
            if K in live and ts<live[K]['ts']: continue
            if K in live and ts==live[K]['ts'] and live[K]['sig']>=line: continue
            nh=f[4]; at={}
            for tok in f[5:]:
                k,v=tok.split('=',1); at[k]=v
            live[K]=dict(peer=p,nh=nh,ts=ts,lp=int(at.get('localpref',100)),med=int(at.get('med',0)),
                         as_=at.get('aspath',''),origin={'egp':1,'incomplete':2}.get(at.get('origin','igp'),0),
                         pty=at.get('peer_type','ebgp'),w=int(at.get('weight',0)),sig=line)
        else:
            if K in live and live[K]['ts']>ts: continue
            if K in live: del live[K]
            wd[K]=ts
    best={}
    for (p,pf),a in live.items():
        cand=dict(a); cand['pfx']=pf; cand['as']=a['as_']
        if pf not in best or better(cand,best[pf]): best[pf]=cand
    return {pf:b['nh'] for pf,b in best.items()}
