BLAST-style Karlin-Altschul statistics for gapless local alignments

Problem class: python3-karlin-altschul-effective-length-bit-score-evalue Deliverable: karlin_altschul.py (self-contained, standard library only) plus a verification harness verify_solution.py.

1. Root-cause analysis

Naive implementations of ungapped Karlin-Altschul statistics fail in five distinct, reproducible ways. Each one has a precise fix, listed below.

1.1 Solving sum_ij p_i p_j exp(lambda s_ij) = 1 directly

The natural formulation works on phi(lambda) = sum_s P(s) exp(lambda s) - 1. phi(0) = 0, phi'(0) = E[s] < 0, and phi(lambda) -> +inf, so a unique positive root exists. But iterating on exp(lambda s) overflows for large scores and Newton's method easily walks to lambda = 0 (the spurious root at x = 1) or overshoots into the overflow region.

Fix. Substitute x = exp(-lambda). The equation becomes a polynomial in x with a root in [0, 1]; the two mathematical roots are x = 1 and the root we want. NCBI's NlmKarlinLambdaNR keeps an uncertainty bracket [a, b] with f(a) > 0 > f(b), takes a Newton step only if it stays inside the bracket and decreases |f| and f'(x) < 0, and bisects otherwise. This is what _lambda_newton / _calc_lambda implement. Splitting out the greatest common divisor d of the attainable scores before calling prevents near-degenerate lattices.

1.2 Silent NaN / -1 on matrices that admit no solution

When E[s] >= 0 or no positive score occurs, lambda does not exist. Returning -1, NaN, or inf propagates into bit scores and E-values.

Fix. Raise typed exceptions with a machine-readable reason:

condition exception reason
E[s] >= 0 NegativeExpectedScoreError nonnegative_expected_score
no positive score NoPositiveScoreError no_positive_score
Newton/bisection cannot bracket a root LambdaNoSolutionError lambda_underflow
H <= 0 or K non-convergent KParameterError k_parameter_undefined

All derive from KarlinAltschulError.

1.3 A wrong (or approximate) K

K is not H/lambda and it is not exp(-2*outerSum) * something that can be guessed. NCBI computes it with a dynamic program over the probability of each cumulative score for each alignment length (P(i, j)), followed by Horner evaluation, a truncated series in outerSum, and two closed forms for the special {+1, -1} and {+1, x} / {x, -1} systems. H itself is the relative entropy lambda * sum_s s P(s) exp(lambda s).

Fix. Port BlastKarlinLHtoK and BlastKarlinLtoH verbatim (_LH_to_K, _calc_H). The divisor (gcd) scaling, the expm1 form of the denominator and the sumlimit = 1e-4 / iterlimit = 100 truncation are all load-bearing.

1.4 Effective length without the composition / edge-effect term

The effective search space is (m - A)(n - N*A), where the length adjustment A is the fixed point of

A = (alpha/lambda) * (ln K + ln((m - A)(n - N A))) + beta

For ungapped alignments alpha/lambda = 1/H and beta is the tabulated edge-effect decay term (e.g. -3.2 for BLOSUM62). Dropping beta, or using the raw sequence lengths, changes E-values by orders of magnitude on short sequences. A must be the floor of the fixed point, with the ceil(A) re-check that NCBI performs.

Fix. Port BLAST_ComputeLengthAdjustment (compute_length_adjustment) and expose effective_lengths(...).

1.5 Rounding and multiple-HSP statistics

Bit scores are printed as half-up integers (floor(x + 0.5)), and multiple linked HSPs use the Karlin-Altschul 1993 sum statistics: the normalised total

xsum = sum_i (lambda*S_i - ln K)

is corrected for the pair search space and the number of starting points, then fed to the sum P-value (closed-form/interpolated for r <= 4, the double integral of K&A 1993 otherwise). A plain Poisson or a sum of rounded bit scores is wrong.

Fix. round_bit_score, sum_pvalue and sum_statistics.

2. Exact fix

The complete, dependency-free implementation is below. It is also saved as ~/karlin_altschul.py.

"""
BLAST-style Karlin-Altschul statistics for gapless (ungapped) local alignments.

This module derives the ungapped parameters (lambda, K, H) for an arbitrary
integer substitution matrix and background residue frequencies by solving

        sum_{i,j} p_i q_j exp(lambda * s_ij) = 1

with a safeguarded, bracketed Newton iteration on the polynomial in x = exp(-lambda).
It then provides the composition-based effective-length adjustment
(edge-effect decay term beta included), bit scores, expectation values and
multiple-HSP sum statistics.

The numerical algorithms are a faithful port of the NCBI BLAST implementation
(blast_stat.c: NlmKarlinLambdaNR / BlastKarlinLtoH / BlastKarlinLHtoK /
BLAST_ComputeLengthAdjustment / s_BlastSumP) so results reproduce the
reference tabulations.

All failure modes raise a typed KarlinAltschulError subclass instead of
returning NaN/-1 silently.
"""

# --------------------------------------------------------------------------- #
# Typed failures
# --------------------------------------------------------------------------- #
class KarlinAltschulError(Exception):
    """Base class for all Karlin-Altschul calculation failures."""

    reason = "karlin_altschul_error"


class NegativeExpectedScoreError(KarlinAltschulError):
    """The background expected score is >= 0, so lambda does not exist."""

    reason = "nonnegative_expected_score"


class NoPositiveScoreError(KarlinAltschulError):
    """No strictly positive score occurs with non-zero probability."""

    reason = "no_positive_score"


class LambdaNoSolutionError(KarlinAltschulError):
    """Newton/bisection failed to bracket a positive root (e.g. underflow)."""

    reason = "lambda_underflow"


class KParameterError(KarlinAltschulError):
    """K (or H) could not be computed for the scoring system."""

    reason = "k_parameter_undefined"

# Core: build the score probability distribution
# --------------------------------------------------------------------------- #
def score_probabilities(
    matrix,
    query_freq: Dict[str, float],
    db_freq: Optional[Dict[str, float]] = None,
) -> Dict[int, float]:
    """Return P(score = s) for all integer scores s.

    Parameters
    ----------
    matrix:
        Either a mapping ``(a, b) -> int score`` or a pair
        ``(alphabet, rows)`` where ``rows`` is a square list-of-lists of ints.
    query_freq, db_freq:
        Background residue frequencies keyed by residue letter.  If ``db_freq``
        is omitted the query frequencies are used for both sequences
        (standard BLAST behaviour).
    """
    if db_freq is None:
        db_freq = query_freq

    if isinstance(matrix, tuple):
        alphabet, rows = matrix
        mat = {(a, b): rows[i][j] for i, a in enumerate(alphabet)
               for j, b in enumerate(alphabet)}
    else:
        mat = matrix

    # normalise frequencies defensively
    q_tot = sum(query_freq.values())
    d_tot = sum(db_freq.values())
    if q_tot <= 0 or d_tot <= 0:
        raise ValueError("residue frequencies must be positive")

    sprob: Dict[int, float] = {}
    for (a, b), s in mat.items():
        pa = query_freq.get(a, 0.0) / q_tot
        pb = db_freq.get(b, 0.0) / d_tot
        if pa == 0.0 or pb == 0.0:
            continue
        sprob[s] = sprob.get(s, 0.0) + pa * pb
    return sprob


# --------------------------------------------------------------------------- #
# Core: lambda
# --------------------------------------------------------------------------- #
def _gcd(a: int, b: int) -> int:
    a, b = abs(a), abs(b)
    while b:
        a, b = b, a % b
    return a


def _lambda_newton(
    sprob: Dict[int, float],
    d: int,
    low: int,
    high: int,
    lambda0: float,
    tolx: float,
    itmax: int,
    max_newton: int,
) -> Tuple[float, int]:
    """Safeguarded Newton iteration on f(x) = sum p_s x**(s/d) - 1.

    A root is bracketed in [a, b] subset [0, 1] with f(a) > 0 and f(b) < 0.
    Newton steps are only accepted when they stay inside the bracket and
    decrease |f|; otherwise the algorithm bisects.  This cannot converge to
    x = 1 (lambda = 0) nor overflow, because it iterates on the polynomial in
    x = exp(-lambda) rather than on the exponential directly.
    """
    x0 = math.exp(-lambda0)
    x = x0 if 0.0 < x0 < 1.0 else 0.5
    a, b = 0.0, 1.0
    f = 4.0  # larger than any possible value of the polynomial on [0, 1]
    is_newton = 0
    k = 0
    for k in range(itmax):
        fold = f
        was_newton = is_newton
        is_newton = 0

        # Horner evaluation of f and f'
        g = 0.0
        f = sprob.get(low, 0.0)
        i = low + d
        while i < 0:
            g = x * g + f
            f = f * x + sprob.get(i, 0.0)
            i += d
        g = x * g + f
        f = f * x + sprob.get(0, 0.0) - 1.0
        i = d
        while i <= high:
            g = x * g + f
            f = f * x + sprob.get(i, 0.0)
            i += d

        if f > 0.0:
            a = x
        elif f < 0.0:
            b = x
        else:
            break  # exact root

        if b - a < 2.0 * a * (1.0 - b) * tolx:
            x = (a + b) / 2.0
            break

        if (
            k >= max_newton
            or (was_newton and abs(f) > 0.9 * abs(fold))
            or g >= 0.0
        ):
            x = (a + b) / 2.0
        else:
            p = -f / g
            y = x + p
            if y <= a or y >= b:
                x = (a + b) / 2.0
            else:
                is_newton = 1
                x = y
                if abs(p) < tolx * x * (1.0 - x):
                    break

    return -math.log(x) / d, k


def _calc_lambda(sprob: Dict[int, float], low: int, high: int,
                 lambda0: float = 0.5) -> float:
    score_avg = sum(s * p for s, p in sprob.items())
    if high <= 0:
        raise NoPositiveScoreError(
            "the scoring system has no positive score: lambda does not exist"
        )
    if score_avg >= 0.0:
        raise NegativeExpectedScoreError(
            f"expected score {score_avg:.6g} is not negative: lambda does not exist"
        )

    # greatest common divisor of the lattice of attainable scores
    d = -low
    for i in range(1, high - low + 1):
        if d <= 1:
            break
        if sprob.get(low + i, 0.0) != 0.0:
            d = _gcd(d, i)

    lam, _ = _lambda_newton(sprob, d, low, high, lambda0,
                            tolx=1e-6, itmax=20, max_newton=20)
    if not math.isfinite(lam) or lam <= 0.0:
        raise LambdaNoSolutionError(
            "failed to bracket a positive root for lambda (numerical underflow)"
        )
    return lam


# --------------------------------------------------------------------------- #
# Core: H and K
# --------------------------------------------------------------------------- #
def _calc_H(sprob: Dict[int, float], low: int, high: int, lam: float) -> float:
    etonlam = math.exp(-lam)
    s = low * sprob.get(low, 0.0)
    for score in range(low + 1, high + 1):
        s = score * sprob.get(score, 0.0) + etonlam * s
    scale = etonlam ** high
    if scale > 0.0:
        return lam * s / scale
    # underflow of exp(-lambda*high)
    if s <= 0.0:
        raise KParameterError("relative entropy H is not positive")
    return lam * math.exp(lam * high + math.log(s))


def _LH_to_K(sprob: Dict[int, float], low0: int, high0: int,
             score_avg: float, lam: float, H: float) -> float:
    """Port of NCBI BlastKarlinLHtoK (PNAS 87, 2264-2268, appendix)."""
    if lam <= 0.0 or H <= 0.0:
        raise KParameterError("lambda and H must be positive to compute K")
    if score_avg >= 0.0:
        raise NegativeExpectedScoreError("expected score must be negative")

    low, high = low0, high0
    rng = high - low

    divisor = -low
    for i in range(1, rng + 1):
        if divisor <= 1:
            break
        if sprob.get(low + i, 0.0) != 0.0:
            divisor = _gcd(divisor, i)

    high //= divisor
    low //= divisor
    lam *= divisor
    rng = high - low

    first_term = H / lam
    exp_minus_lam = math.exp(-lam)

    # closed forms for the special two- and three-point systems
    if low == -1 and high == 1:
        p_low = sprob[low0]
        p_high = sprob[high0]
        if p_low <= 0.0:
            raise KParameterError("degenerate score distribution")
        return (p_low - p_high) ** 2 / p_low

    if low == -1 or high == 1:
        if high != 1:
            score_avg = score_avg / divisor
            first_term = (score_avg * score_avg) / first_term
        return first_term * (1.0 - exp_minus_lam)

    sumlimit = 1e-4
    iterlimit = 100
    asp = [0.0] * (iterlimit * rng + 1)  # P(total score i in j letters)

    outer_sum = 0.0
    low_as = high_as = 0
    asp[0] = inner = oldsum = oldsum2 = 1.0
    iter_counter = 0

    while iter_counter < iterlimit and inner > sumlimit:
        first = last = rng
        low_as += low
        high_as += high

        # dynamic program: convolution over one more alignment position
        idx = high_as - low_as
        while idx >= 0:
            ptr1 = idx - first
            ptr1e = idx - last
            ptr2 = first
            inner = 0.0
            while ptr1 >= ptr1e:
                inner += asp[ptr1] * sprob.get(low + ptr2, 0.0)
                ptr1 -= 1
                ptr2 += 1
            if first:
                first -= 1
            if idx <= rng:
                last -= 1
            asp[idx] = inner
            idx -= 1

        # Horner's rule over score classes (negative scores weighted by
        # exp(-lambda), non-negative ones added directly)
        ptrp = 0
        inner = asp[ptrp]
        i = low_as + 1
        while i < 0:
            ptrp += 1
            inner = asp[ptrp] + inner * exp_minus_lam
            i += 1
        inner *= exp_minus_lam
        while i <= high_as:
            ptrp += 1
            inner += asp[ptrp]
            i += 1

        oldsum2 = oldsum
        oldsum = inner

        iter_counter += 1
        inner /= iter_counter
        outer_sum += inner

    K = -math.exp(-2.0 * outer_sum) / (first_term * math.expm1(-lam))
    if not math.isfinite(K) or K <= 0.0:
        raise KParameterError("K computation did not converge to a positive value")
    return K


# --------------------------------------------------------------------------- #
# Public: full ungapped calibration
# --------------------------------------------------------------------------- #
def ungapped_karlin_from_scores(
    sprob: Dict[int, float],
    lambda0: float = 0.5,
) -> KarlinStats:
    """Compute (lambda, K, H) from a score probability distribution."""
    if not sprob:
        raise NoPositiveScoreError("empty score distribution")
    low = min(sprob)
    high = max(sprob)
    score_avg = sum(s * p for s, p in sprob.items())

    lam = _calc_lambda(sprob, low, high, lambda0)
    H = _calc_H(sprob, low, high, lam)
    if not math.isfinite(H) or H <= 0.0:
        raise KParameterError("relative entropy H is not positive")
    K = _LH_to_K(sprob, low, high, score_avg, lam, H)
    return KarlinStats(Lambda=lam, K=K, H=H, logK=math.log(K),
                       score_avg=score_avg, obs_min=low, obs_max=high)


def ungapped_karlin(
    matrix,
    query_freq: Dict[str, float],
    db_freq: Optional[Dict[str, float]] = None,
    lambda0: float = 0.5,
) -> KarlinStats:
    """Compute the ungapped Karlin-Altschul parameters for a matrix/frequencies."""
    sprob = score_probabilities(matrix, query_freq, db_freq)
    return ungapped_karlin_from_scores(sprob, lambda0)


# --------------------------------------------------------------------------- #
# Composition-based effective length adjustment
# --------------------------------------------------------------------------- #
def compute_length_adjustment(
    K: float,
    logK: float,
    alpha_over_lambda: float,
    beta: float,
    query_length: int,
    db_length: int,
    db_num_seqs: int,
) -> Tuple[int, bool]:
    """Port of NCBI ``BLAST_ComputeLengthAdjustment``.

    Returns ``(length_adjustment, converged)``.  ``alpha_over_lambda`` is
    ``1/H`` for ungapped alignments and ``beta`` is the edge-effect decay
    term (0 when unknown, negative values for the standard matrices).
    """
    m = float(query_length)
    n = float(db_length)
    N = float(db_num_seqs)
    max_iterations = 20

    # Largest ell satisfying K (m - ell)(n - N ell) > max(m, n)
    a = N
    mb = m * N + n
    c = n * m - max(m, n) / K
    if c < 0.0:
        return 0, True
    disc = mb * mb - 4.0 * a * c
    if disc < 0.0:
        return 0, False
    ell_max = 2.0 * c / (mb + math.sqrt(disc))

    ell_min = 0.0
    ell_next = 0.0
    converged = False
    for i in range(1, max_iterations + 1):
        ell = ell_next
        ss = (m - ell) * (n - N * ell)
        if ss <= 0.0:
            break
        ell_bar = alpha_over_lambda * (logK + math.log(ss)) + beta
        if ell_bar >= ell:
            ell_min = ell
            if ell_bar - ell_min <= 1.0:
                converged = True
                break
            if ell_min == ell_max:
                break
        else:
            ell_max = ell
        if ell_min <= ell_bar <= ell_max:
            ell_next = ell_bar
        else:
            ell_next = ell_max if i == 1 else (ell_min + ell_max) / 2.0

    if converged:
        length_adjustment = int(math.floor(ell_min))
        # verify ceil(ell_min) does not share the floor of the true fixed point
        ell = math.ceil(ell_min)
        if ell <= ell_max:
            ss = (m - ell) * (n - N * ell)
            if ss > 0.0 and alpha_over_lambda * (logK + math.log(ss)) + beta >= ell:
                length_adjustment = int(ell)
    else:
        length_adjustment = int(math.floor(ell_min))
    return length_adjustment, converged


def effective_lengths(
    stats: KarlinStats,
    query_length: int,
    db_length: int,
    db_num_seqs: int = 1,
    beta: float = 0.0,
    alpha_over_lambda: Optional[float] = None,
) -> EffectiveLengths:
    """Composition-based effective lengths and search space.

    ``alpha_over_lambda`` defaults to ``1/H`` (the ungapped value).  ``beta`` is
    the edge-effect decay term; pass the tabulated value (e.g. -3.2 for
    BLOSUM62) to reproduce BLAST exactly.
    """
    if alpha_over_lambda is None:
        if stats.H <= 0.0:
            raise KParameterError("H must be positive to derive alpha/lambda")
        alpha_over_lambda = 1.0 / stats.H

    A, converged = compute_length_adjustment(
        stats.K, stats.logK, alpha_over_lambda, beta,
        query_length, db_length, db_num_seqs,
    )
    q_eff = max(query_length - A, 1)
    db_eff = max(db_length - db_num_seqs * A, 1)
    return EffectiveLengths(
        length_adjustment=A,
        query_effective_length=q_eff,
        database_effective_length=db_eff,
        search_space=float(q_eff) * float(db_eff),
        converged=converged,
    )


# --------------------------------------------------------------------------- #
# Bit scores and E-values
# --------------------------------------------------------------------------- #
def bit_score(score: float, stats: KarlinStats) -> float:
    """Unrounded BLAST bit score: (lambda*S - ln K)/ln 2."""
    return (score * stats.Lambda - stats.logK) / math.log(2.0)


def round_bit_score(score: float, stats: KarlinStats) -> int:
    """Bit score rounded half-up, matching BLAST tabular output."""
    bs = bit_score(score, stats)
    return int(math.floor(bs + 0.5))


def evalue(score: float, stats: KarlinStats, search_space: float) -> float:
    """Expectation value E = searchspace * exp(-lambda*S + ln K)."""
    return search_space * math.exp(-stats.Lambda * score + stats.logK)

def _ln_gamma_int(n: int) -> float:
    return math.lgamma(float(n))

_MAX_DIAGS = 20


def _romberg(
    f: Callable[[float], float],
    p: float,
    q: float,
    eps: float,
    epsit: int,
    itmin: int,
) -> float:
    """Port of NCBI BLAST_RombergIntegrate."""
    itmin = max(1, min(itmin, _MAX_DIAGS - 1))
    epsit = max(1, min(epsit, 3))
    epsck = itmin - epsit

    npts = 1
    h = q - p
    x = f(p)
    if abs(x) == math.inf:
        return x
    y = f(q)
    if abs(y) == math.inf:
        return y
    romb = [0.0] * _MAX_DIAGS
    romb[0] = 0.5 * h * (x + y)
    epsit_cnt = 0
    for i in range(1, _MAX_DIAGS):
        s = 0.0
        x = p + 0.5 * h
        for _ in range(npts):
            y = f(x)
            if abs(y) == math.inf:
                return y
            s += y
            x += h
        romb[i] = 0.5 * (romb[i - 1] + h * s)
        n = 4
        for j in range(i - 1, -1, -1):
            romb[j] = (n * romb[j + 1] - romb[j]) / (n - 1)
            n *= 4
        if i > epsck:
            if abs(romb[1] - romb[0]) > eps * abs(romb[0]):
                epsit_cnt = 0
            else:
                epsit_cnt += 1
                if i >= itmin and epsit_cnt >= epsit:
                    return romb[0]
        npts *= 2
        h *= 0.5
    return math.inf


def _sump_calc(r: int, s: float) -> float:
    """Port of NCBI s_BlastSumPCalc (double integral of K&A 1993, eqn 4)."""
    if r == 1:
        if s > 8.0:
            return math.exp(-s)
        return -math.expm1(-math.exp(-s))
    if r < 1:
        return 0.0

    if r < 8:
        if s <= -2.3 * r:
            return 1.0
    elif r < 15:
        if s <= -2.5 * r:
            return 1.0
    elif r < 27:
        if s <= -3.0 * r:
            return 1.0
    elif r < 51:
        if s <= -3.4 * r:
            return 1.0
    elif r < 101:
        if s <= -4.0 * r:
            return 1.0

    stddev = math.sqrt(r)
    stddev4 = 4.0 * stddev
    r1 = r - 1

    if r > 100:
        est_mean = -r * r1
        if s <= est_mean - stddev4:
            return 1.0

    logr = math.log(r)
    mean = r * (1.0 - logr) - 0.5
    if s <= mean - stddev4:
        return 1.0

    if s >= mean:
        t = s + 6.0 * stddev
        itmin = 1
    else:
        t = mean + 6.0 * stddev
        itmin = 2

    num = r
    num_minus_2 = r - 2
    adj1 = num_minus_2 * logr - _ln_gamma_int(r1) - _ln_gamma_int(r)
    epsilon = 0.002

    def make_outer(inner_s: float):
        sdvir = inner_s / num
        adj2 = adj1 - inner_s

        def outer(x: float) -> float:
            y = math.exp(x - sdvir)
            if y == math.inf:
                return 0.0
            if num_minus_2 == 0:
                return math.exp(adj2 - y)
            if x == 0.0:
                return 0.0
            return math.exp(num_minus_2 * math.log(x) + adj2 - y)

        return outer

    def inner_cb(inner_s: float) -> float:
        mx = (inner_s / num + 3.0) if inner_s > 0.0 else 3.0
        return _romberg(make_outer(inner_s), 0.0, mx, epsilon, 0, 1)

    d = 0.0
    while True:
        d = _romberg(inner_cb, s, t, epsilon, 0, itmin)
        if d == math.inf:
            return d
        if not (s < mean and d < 0.4 and itmin < 4):
            break
        itmin += 1
    return d if d < 1.0 else 1.0


def sum_pvalue(r: int, s: float) -> float:
    """P-value for r distinct alignments with adjusted total score ``s`` nats.

    Exact port of NCBI ``s_BlastSumP`` (interpolated tables for r <= 4,
    numerical integration otherwise).
    """
    tables = {2: (_K_TAB2, len(_K_TAB2) - 1),
              3: (_K_TAB3, len(_K_TAB3) - 1),
              4: (_K_TAB4, len(_K_TAB4) - 1)}
    if r == 1:
        return -math.expm1(-math.exp(-s))
    if r <= 4:
        if r < 1:
            return 0.0
        r1 = r - 1
        if s >= r * r + r1:
            a = _ln_gamma_int(r + 1)
            return r * math.exp(r1 * math.log(s) - s - a - a)
        if s > -2 * r:
            tab, size = tables[r]
            a = s + s + 4 * r
            i = int(a)
            a -= i
            i = size - i
            return a * tab[i - 1] + (1.0 - a) * tab[i]
        return 1.0
    return _sump_calc(r, s)


def sum_statistics(
    scores: Sequence[float],
    stats: KarlinStats,
    query_effective_length: int,
    database_effective_length: int,
    search_space: float,
    starting_points: int,
    round_scores: bool = False,
) -> Dict[str, float]:
    """Multiple-HSP sum statistics for a linked set of HSPs.

    Returns a dict with

    * ``S_prime``        -- sum of the (optionally rounded) raw scores
    * ``sum_bit_score``  -- S' expressed on the bit-scale
    * ``xsum``           -- sum_i (lambda*S_i - ln K), the normalised total
    * ``p_value``        -- small-gap sum p-value
    * ``evalue``         -- small-gap sum expectation value
    * ``num_hsps``       -- number of HSPs in the set
    """
    if not scores:
        raise ValueError("at least one HSP score is required")
    if starting_points < 1:
        raise ValueError("starting_points must be >= 1")

    used = [float(round(s)) if round_scores else float(s) for s in scores]
    num = len(used)
    s_prime = sum(used)
    xsum = sum(stats.Lambda * s - stats.logK for s in used)

    pair_search_space = float(database_effective_length) * float(query_effective_length)
    if num == 1:
        p = -math.expm1(-math.exp(-xsum))
    else:
        adj = xsum - (math.log(pair_search_space)
                      + 2.0 * (num - 1) * math.log(starting_points))
        adj -= _ln_gamma_int(num)
        p = sum_pvalue(num, adj)
    if p <= 0.0:
        e = 0.0
    elif p >= 1.0:
        e = math.inf
    else:
        e = -math.log1p(-p) * (search_space / pair_search_space)

    return {
        "S_prime": s_prime,
        "sum_bit_score": (stats.Lambda * s_prime - stats.logK) / math.log(2.0),
        "xsum": xsum,
        "num_hsps": num,
        "p_value": p,
        "evalue": e,
    }
