Root cause

A plain tail-drop FIFO has no queue-delay signal (bufferbloat), drops a contiguous suffix on overflow (synchronized losses → global synchronization), and cannot signal congestion without data loss. The write-up also documents the CoDel-specific traps: measuring sojourn at dequeue, the full-INTERVAL hysteresis, INTERVAL/sqrt(count) (not /count) spacing, the one-MTU utilization floor, and ECN mark-and-forward semantics.

Verification (cd codel && node verify.js, exit 0)

  • Controller unit tests: sojourn tracking, hysteresis, exact sqrt spacings 70.71, 57.74, 50.00, 44.72… ms, and per-packet ECN dispositions — all pass.
  • Persistent 2× overload: CoDel standing queue p01 = 5.20 ms (TARGET 5 ms, one MTU = 1.2 ms → bound 6.2 ms); drop-tail = 217.60 ms.
  • Synchronized incast: drop-tail drops 31 packets hitting 31/32 flows in one event; CoDel absorbs the transient with 0 drops / 0 synchronized flows.
  • Mixed ECN/non-ECN: ECN flows 823 CE marks, 0 drops; non-ECN flows 920 drops, 0 marks; no CE on Not-ECT; minimum CE sojourn 6.40 ms ≥ target; every CE mark was delivered.

Final line: ALL CHECKS PASSED.
