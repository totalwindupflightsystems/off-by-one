Answer

Goal: split backend/api/routes/import.ts (465L) into an import/ module directory where the router's only export is export default router, with zero changes to importers (app.ts default import, tests via original path).

Why this variant is special (LF-039 precedent): export * never re-exports a default. When the barrel's only public export is the default, the shim must be export { default } from "./import/index.js" — the export * form silently drops the default (verified: TS1192 "Module has no default export").

Final structure:

backend/api/routes/import.ts          ← shim (replaces original, same path)
backend/api/routes/import/
  ├── index.ts                        ← barrel: assembles router, `export default router;` (only ^export line)
  ├── types.ts                        ← ImportStatus/ImportRecord/ImportRow/ImportSummary
  ├── schemas.ts                      ← zod schemas (recordSchema, idParamSchema, commitBodySchema)
  ├── helpers.ts                      ← parseCsv, summarize, createRecord, asyncHandler, notFound, constants
  ├── upload.ts                       ← multer instance (memoryStorage, size/mime limits)
  └── events.ts                       ← EventEmitter + emit()

Shim (import.ts, 1 line):

export { default } from "./import/index.js";

Barrel (import/index.ts) — submodule imports, then export default router; as its sole export:

import { Router } from "express";
import type { Request, Response, NextFunction } from "express";
import { upload, uploadFieldName } from "./upload.js";
import { idParamSchema, commitBodySchema } from "./schemas.js";
import { createRecord, parseCsv, summarize, asyncHandler, notFound } from "./helpers.js";
import { emit } from "./events.js";
import type { ImportRecord } from "./types.js";

const memoryStore: Map<string, ImportRecord> = new Map();
const router = Router();
// ... POST /, GET /:id, POST /:id/commit, DELETE /:id, GET /, error handler ...

export default router;

Untouched importers resolve through the shim automatically: app.ts keeps import importRouter from "./api/routes/import.js" and the test keeps importing via the original path. Resolution order (file import.ts beats directory import/index.ts for ./import imports, while the shim's explicit ./import/index.js targets the barrel) makes the swap invisible.
