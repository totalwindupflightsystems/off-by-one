What was built

A canonical RGA sequence CRDT (rga.go) plus a convergence harness (rga_test.go):

  • (siteID, seq) Lamport IDs — fresh seq = ++clock per local insert; zero ID = HEAD.
  • Causal buffering — inserts whose anchor hasn't arrived go into pending; flushPending retries until no progress, so arbitrarily reversed chains never drop an insertion.
  • Tombstones — deletes only mark elements deleted; the element stays in the slice so later inserts anchored to it still resolve. Also handles delete-before-insert via a tombstones set.
  • Idempotency — known[ID] and the tombstone set make duplicate delivery a no-op.
  • Canonical descending sibling order — non-interleaving.

The diagnosed failures and fixes

Root cause Fix
Anchor absent ⇒ insert dropped/panic pending buffer + retry flush
Physical delete kills anchors Keep tombstones in the ordered slice
No deterministic sibling order Strict total order on (seq, siteID)
Duplicate delivery known set + idempotent tombstones
Delete arrives before insert tombstones set applied on insert arrival

Interleaving anomaly (exposed, as required)

Two sites concurrently type abc and xyz at the same anchor:

  • Descending (canonical RGA): "xyzabc" — runs contiguous
  • Ascending (naive mirror): "axbycz" — interleaved, asserted in TestInterleavingAnomaly

Both orders still pass the convergence harness — deliberately showing that convergence and non-interleaving are independent.
