root-suite FAIL-CLOSED after SEC-001 moved rest_addr: client/daemon address parity repair

Problem class: bunker-root-suite-classification-daemon-unavailable-rest-addr-parity Environment: scripts/root-suite.sh (root-gated suite) on the self-hosted runner bunker-mvp Language: bash / Go (bunker CLI + bunkerd) Verdict: deterministic, not transient. The classifier was working correctly; its input was broken — the client dialed <ip-address>:18080, the daemon had moved to <ip-address>:18080.

1. Symptom

Cleanup classification fails closed for every candidate, so the sweep preserves every leaked test user and the suite's "zero leftover bunker-* state" invariant breaks on the follow-up runs:

root-suite: FAIL-CLOSED: /usr/local/bin/bunker list --status all unavailable while classifying user bunker-conctest-0; bunker: list agents: unavailable: dial tcp <ip-address>:18080: connect: connection refused

CI runs 38590365280 / 38590390418 / 38590627192 / 38597655288 logged 19 FAIL-CLOSED lines and 0 removals for TestConcurrency_SpawnFiveAgents (bunker-conctest-0/1/3/4, bunker-8c9d57ea). Because the failure is connection refused (a transport error), scripts/root-suite.sh daemon_has_agent returns rc=2 → preserve candidate.

2. Root cause

scripts/root-suite.sh classifies each removal candidate with a live membership query:

daemon_has_agent() { ... out="$("$BUNKER_BIN" list --status all 2>/dev/null)" ... }
# rc 0 = registered (keep) · rc 1 = not registered (safe to remove) · rc 2 = query unavailable (FAIL CLOSED)

The query shells out to the client /usr/local/bin/bunker, which reads its server URL from the resolved CLI config — ${XDG_CONFIG_HOME:-~/.config}/bunker/config.yaml (GAP-181), i.e. /root/.config/bunker/config.yaml for root, not /root/.bunker/config.yaml (that legacy path is only a read alias).

  1. SEC-001 (2026-10-10 18:26) hardened bunkerd on bunker-mvp by changing /etc/bunkerd/config.yaml:

yaml server: name: bunker-mvp rest_addr: "<ip-address>:18080" # was ":18080" (all interfaces, loopback included) grpc_addr: "<ip-address>:19090"

The daemon now binds only the Tailscale interface. Nothing listens on <ip-address>:18080.

  1. The root client config was never swept. /root/.config/bunker/config.yaml still said:

yaml servers: bunker-mvp: name: bunker-mvp url: http://<ip-address>:18080

→ dial tcp <ip-address>:18080: connect: connection refused, every time, for every candidate.

  1. Fail-closed logic amplifies a config error into a full-suite block. A deterministic address mismatch is indistinguishable, from inside daemon_has_agent, from a real daemon outage. Preserving is the safe default for production agents (DF-BUNKER-78), but it means a stale URL reddens CI forever.

  2. The bounded retry (merged 17486d92, worker f1b4425) does not fix this. It recovers transient hiccups (4 attempts, backoff 1 2 4, plus a sweep sleep cap). A deterministic refusal still fails closed after the budget — correct behavior, wrong input. That is precisely why CI stayed red after that hardening.

Why the wrong file was investigated first: the failure transcript and an early note pointed at ~/.bunker/config.yaml. bunker paths reports the authoritative file. On this host it is ~/.config/bunker/config.yaml; the legacy ~/.bunker file, when present, is stale and is not what the CLI reads. Always resolve, never guess.

Lesson: after moving a daemon bind address, sweep all client configs on the host. A deterministic failure looks exactly like an outage to fail-closed logic.

3. Fix

3A. Immediate — repoint the client config to the daemon's actual rest_addr

Run as root on bunker-mvp (the daemon config is 0600, owned by nobody):

# 0) discover the truth from the daemon and the resolver — do not guess paths
DAEMON_CONFIG=/etc/bunkerd/config.yaml
bunker paths --cli-only            # authoritative client config path (GAP-181)
grep -n 'rest_addr' "$DAEMON_CONFIG"

# 1) back up, then repoint every loopback URL in the resolved client config
CLI_CONFIG="$(bunker paths --cli-only | awk '$1=="cli" && $2=="config.yaml" {print $3; exit}')"
cp -a "$CLI_CONFIG" "$CLI_CONFIG.bak-restaddr-$(date +%Y%m%d-%H%M%S)"
sed -i -E 's#http://(127\.0\.0\.1|localhost):18080#http://<ip-address>:18080#g' "$CLI_CONFIG"

# 2) prove the CLI now answers as root
bunker list --status all

This is the fix that was applied live on the runner (sed /root/.config/bunker/config.yaml URLs to http://<ip-address>:18080; root bunker list answered).

Robust alternative (registers via the CLI instead of editing YAML):

# token: auth.token from the daemon config, or $BUNKER_TOKEN
bunker connect http://<ip-address>:18080 --name bunker-mvp --token "$BUNKER_TOKEN"
bunker use bunker-mvp
bunker list --status all

Do not "fix" this by re-binding the daemon to :18080. SEC-001 deliberately moved the bind off all-interfaces; the client is what is stale.

3B. Defense in depth — bounded retry in the classifier (already merged 17486d92)

Keep scripts/root-suite.sh's bounded retry, which is correct hardening for genuine saturation (five concurrent spawns churning dockerd). It runs before the rc=2 fail-closed decision, and only a successful, non-empty query can authorize removal:

ROOT_SUITE_QUERY_ATTEMPTS="${ROOT_SUITE_QUERY_ATTEMPTS:-4}"     # attempts
ROOT_SUITE_QUERY_BACKOFF="${ROOT_SUITE_QUERY_BACKOFF:-1 2 4}"   # seconds, per retry
ROOT_SUITE_QUERY_SWEEP_SLEEP="${ROOT_SUITE_QUERY_SWEEP_SLEEP:-60}" # whole-sweep sleep cap

daemon_has_agent() {
    local id="$1" out attempt=0 delay t0=$SECONDS att_word=attempts ret_word=retries
    DHA_BUDGET_TEXT=""; DHA_ELAPSED=0
    while :; do
        attempt=$((attempt + 1))
        if out="$("$BUNKER_BIN" list --status all 2>/dev/null)" && [ -n "$out" ]; then
            [ "$attempt" -gt 1 ] && echo "root-suite: note: '$BUNKER_BIN list --status all' recovered on attempt $attempt for '$id' after $((SECONDS - t0))s — classification proceeded (INT-CI-071)" >&2
            echo "$out" | awk '/^  [a-z0-9]/{print $1}' | grep -qx "$id" && return 0
            return 1
        fi
        [ "$attempt" -ge "$ROOT_SUITE_QUERY_ATTEMPTS" ] && break
        delay="$(query_retry_delay "$attempt")"
        if [ "$delay" -gt 0 ] && [ "$QUERY_SWEEP_SLEPT" -lt "$ROOT_SUITE_QUERY_SWEEP_SLEEP" ]; then
            sleep "$delay"; QUERY_SWEEP_SLEPT=$((QUERY_SWEEP_SLEPT + delay))
        elif [ "$QUERY_SWEEP_NOTE_EMITTED" -eq 0 ] && [ "$delay" -gt 0 ]; then
            QUERY_SWEEP_NOTE_EMITTED=1
            echo "root-suite: note: retry sleep budget ${ROOT_SUITE_QUERY_SWEEP_SLEEP}s is exhausted — remaining checks retry back-to-back" >&2
        fi
    done
    [ "$attempt" -eq 1 ] && att_word=attempt
    [ "$((attempt - 1))" -eq 1 ] && ret_word=retry
    DHA_BUDGET_TEXT="$attempt $att_word / $((attempt - 1)) $ret_word"
    DHA_ELAPSED=$((SECONDS - t0))
    return 2   # FAIL CLOSED: ambiguous on every attempt
}

The canonical version (comments, query_retry_delay, the full cleanup() wiring) is in scripts/root-suite.sh; the change is commit f1b4425e, merged as 17486d92.

3C. Fleet-wide — restaddr-parity-sweep.sh (closes QA-BUNKER-74)

The same class exists on any host whose rest_addr moved. This sweep reads the daemon's real rest_addr, finds every resolved client config (root + all operator homes), repoints loopback URLs with a timestamped backup, and verifies each config reaches the daemon. Run it on every fleet host (critical on bunker-mvp). Save as scripts/restaddr-parity-sweep.sh, chmod +x.

#!/usr/bin/env bash
# restaddr-parity-sweep.sh — reconcile local bunker client configs with the
# daemon's ACTUAL rest_addr (QA-BUNKER-74, follow-up to INT-CI-071).
#
# SEC-001 moved server.rest_addr from a loopback bind (":18080") to a Tailscale
# IP. Client configs written before that still dial http://<ip-address>:18080, so
# every `bunker list` fails DETERMINISTICALLY with
#     list agents: unavailable: dial tcp <ip-address>:18080: connect: connection refused
# A FAIL-CLOSED consumer (scripts/root-suite.sh classification) reads that as an
# outage and preserves every candidate, so a config typo reddens CI forever.
#
# Usage: restaddr-parity-sweep.sh [--dry-run] [--daemon-config PATH] [FILES...]
# Exit:  0 = every swept config is (now) in parity; 1 = a mismatch remains.
set -uo pipefail

PROG=restaddr-parity-sweep.sh
DRY_RUN=0
DAEMON_CONFIG="${BUNKERD_CONFIG:-/etc/bunkerd/config.yaml}"
EXPLICIT=()

while [ $# -gt 0 ]; do
    case "$1" in
        --dry-run)        DRY_RUN=1; shift ;;
        --daemon-config)  DAEMON_CONFIG="$2"; shift 2 ;;
        -h|--help)        sed -n '2,40p' "$0"; exit 0 ;;
        --*) echo "$PROG: unknown flag: $1" >&2; exit 2 ;;
        *) EXPLICIT+=("$1"); shift ;;
    esac
done
log()  { printf '%s: %s\n' "$PROG" "$*"; }
warn() { printf '%s: warning: %s\n' "$PROG" "$*" >&2; }

# ── 1. where the daemon actually listens ────────────────────────────────────
rest_addr=""
if [ -r "$DAEMON_CONFIG" ]; then
    rest_addr="$(awk '
        /^[[:space:]]*rest_addr:[[:space:]]*/ {
            v=$0; sub(/^[^:]*:[[:space:]]*/, "", v)
            gsub(/["'"'"']/,"",v); gsub(/[[:space:]]/,"",v); print v; exit
        }' "$DAEMON_CONFIG")"
else
    warn "daemon config not readable: $DAEMON_CONFIG (use --daemon-config)"
fi
[ -n "$rest_addr" ] || { echo "$PROG: no rest_addr found in $DAEMON_CONFIG — pass --daemon-config" >&2; exit 2; }

bind_host="${rest_addr%:*}"; bind_port="${rest_addr##*:}"
bind_host="${bind_host#[}"; bind_host="${bind_host%]}"
case "$bind_host" in
    ""|"<ip-address>"|"::"|"*"|"<ip-address>"|"<ip-address>"|"localhost")
        log "rest_addr=$rest_addr binds all/loopback — loopback clients still served; informational"
        target_url="" ;;
    *)  target_url="http://$bind_host:$bind_port" ;;
esac
log "daemon rest_addr=$rest_addr (bind_host=$bind_host bind_port=$bind_port)"
[ -n "$target_url" ] && log "loopback client URLs will be repointed to $target_url"

# ── 2. enumerate client configs (root + every operator home) ────────────────
declare -a CONFIGS=()
if [ "${#EXPLICIT[@]}" -gt 0 ]; then
    CONFIGS=("${EXPLICIT[@]}")
else
    candidates=()
    if command -v bunker >/dev/null 2>&1; then
        p="$(bunker paths --cli-only 2>/dev/null | awk '$1=="cli" && $2=="config.yaml" {print $3; exit}')"
        [ -n "$p" ] && candidates+=("$p")
    fi
    while IFS=: read -r _ _ _ _ _ home _; do
        [ -n "$home" ] || continue
        candidates+=("$home/.config/bunker/config.yaml")
        candidates+=("$home/.bunker/config.yaml")
    done < /etc/passwd
    for f in "${candidates[@]}"; do
        [ -f "$f" ] || continue
        found=0
        for seen in "${CONFIGS[@]:-}"; do [ "$seen" = "$f" ] && found=1 && break; done
        [ "$found" -eq 0 ] && CONFIGS+=("$f")
    done
fi
[ "${#CONFIGS[@]}" -eq 0 ] && { log "no client config files found — nothing to sweep"; exit 0; }
log "sweeping ${#CONFIGS[@]} client config file(s)"

# ── 3. sweep each file ──────────────────────────────────────────────────────
REMAINING=0
for cfg in "${CONFIGS[@]}"; do
    [ -r "$cfg" ] || { warn "unreadable, skipped: $cfg"; continue; }
    stale="$(grep -cE "^[[:space:]]*url:[[:space:]]*http://(127\.0\.0\.1|localhost|\[<ip-address>\]):[0-9]+" "$cfg" 2>/dev/null || true)"
    if [ "${stale:-0}" -eq 0 ]; then log "OK      $cfg (no loopback url)"; continue; fi
    if [ -z "$target_url" ]; then
        log "NOTE    $cfg has $stale loopback url(s) but the daemon still serves loopback — leaving as-is"; continue
    fi
    if [ "$DRY_RUN" -eq 1 ]; then
        log "DRIFT   $cfg has $stale loopback url(s); would repoint to $target_url"
        grep -nE "^[[:space:]]*url:[[:space:]]*http://(127\.0\.0\.1|localhost|\[<ip-address>\]):[0-9]+" "$cfg" | sed 's/^/          /'
        REMAINING=1; continue
    fi
    backup="$cfg.bak-restaddr-$(date +%Y%m%d-%H%M%S)"
    cp -a "$cfg" "$backup" || { warn "backup failed for $cfg"; REMAINING=1; continue; }
    sed -i -E "s#^([[:space:]]*url:[[:space:]]*http://)(127\.0\.0\.1|localhost)(:[0-9]+)?#\1${bind_host}:${bind_port}#" "$cfg"
    if grep -qE "^[[:space:]]*url:[[:space:]]*http://(127\.0\.0\.1|localhost|\[<ip-address>\]):[0-9]+" "$cfg"; then
        warn "some loopback url(s) remain in $cfg (IPv6 form?) — inspect manually"; REMAINING=1
    else
        log "FIXED   $cfg ($stale url(s) -> $target_url; backup $backup)"
    fi
done

# ── 4. verify a live answer per config (best effort; needs a valid token) ───
if [ "$DRY_RUN" -eq 0 ] && command -v bunker >/dev/null 2>&1; then
    for cfg in "${CONFIGS[@]}"; do
        [ -r "$cfg" ] || continue
        if out="$(bunker --config "$cfg" list --status all 2>&1)"; then
            log "VERIFY  $cfg: bunker list answered"
        else
            case "$out" in
                *"connection refused"*|*"i/o timeout"*|*"no route to host"*|*"network is unreachable"*|*"unavailable: dial tcp"*)
                    warn "VERIFY  $cfg transport still failing (${out##*$'\n'}); URL: $(grep -m1 -E '^[[:space:]]*url:' "$cfg")"
                    REMAINING=1 ;;
                *) log "VERIFY  $cfg reached the daemon (non-transport answer: ${out##*$'\n'})" ;;
            esac
        fi
    done
fi
exit "$REMAINING"

Operator runbook:

5. Prevention / rollout

  • Treat client/daemon address parity as a deploy step. Whenever server.rest_addr/grpc_addr changes, run restaddr-parity-sweep.sh (or bunker connect/bunker use) on every host before relying on any bunker query. The committed contract is internal/fleet/inventory.yaml; bunker status --all exits nonzero on NOT_REGISTERED / PORT_MISMATCH / UNREACHABLE / BELOW_FLOOR.
  • Run the sweep in CI as a preflight gate and fail the job on --dry-run drift, so a stale URL is a clear, early error instead of a late FAIL-CLOSED storm.
  • Keep fail-closed + bounded retry. Preserve-when-ambiguous stays; retry handles saturation. The missing piece was never the classifier — it was reconciling the address it was told to trust.
  • Resolve, don't guess, config paths. ${XDG_CONFIG_HOME:-~/.config}/bunker/config.yaml is authoritative; ~/.bunker/config.yaml is a legacy read alias and may be stale (GAP-181).
