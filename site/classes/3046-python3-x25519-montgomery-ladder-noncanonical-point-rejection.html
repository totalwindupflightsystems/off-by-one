X25519 Montgomery Ladder — Non-Canonical & Low-Order Point Rejection

Root-cause analysis

The problem is a from-scratch RFC 7748 X25519 implementation. The failures that make the adversarial harness fail are almost always one of these:

  1. Off-by-one in the ladder loop. RFC 7748 uses a 255-bit scalar/field, so the ladder must iterate bits 254 … 0. Writing for t in reversed(range(254)) gives 253 … 0, silently drops bit 254, and produces a wrong-but-plausible result. The RFC's section 5.2 vectors immediately fail even though decoding and clamping look right.
  2. Not masking the top bit of u. The input u-coordinate is 32 bytes = 256 bits, but the field is only 255 bits. Bit 255 must be cleared (u[31] &= 0x7f). Forgetting this makes the field element depend on garbage and changes results / raises.
  3. Encoding/decoding endianness. X25519 serializes little-endian. Decoding with big-endian or encoding the shared secret big-endian breaks every vector.
  4. Scalar clamping. RFC 7748 requires k[0] &= 248, k[31] &= 127, k[31] |= 64 (forces a multiple of the cofactor 8 and sets bit 254). Missing the |= 64 or &= 248 yields wrong results and defeats cofactor clearing.
  5. All-zero secret handling / non-canonical points. Inputs equal to (or congruent mod p to) a low-order point make the ladder output the identity, which serializes to 32 zero bytes. A naive implementation returns that all-zero secret. The correct behavior is to reject it explicitly. Non-canonical encodings are the same field element (p ≡ 0, p+1 ≡ 1, and the high-bit variants), so the check must be done after decoding and reduction mod p, not by raw byte comparison.
  6. Mutating a bytes object. u[31] &= 0x7f on bytes raises TypeError; you must copy into a bytearray/list first. This is the "handle u=0/high-bit input without raising" trap.
  7. Ladder formula errors (e.g. wrong a24 = 121665, wrong z2 = E*(AA + a24*E), wrong cswap). These pass the first vector by luck only rarely; they fail iterated vectors.

Facts established for the rejection logic (computed over F_p, p = 2^255-19): the only distinct low-order u-coordinates reachable by X25519 are {0, 1, p-1, e0…, 5f…}. Because clamping forces the scalar to be a multiple of 8, any low-order input maps to the identity and serializes to all zeros. Therefore checking for the all-zero output is both necessary and sufficient, and a decoded-value blacklist is a fast pre-check.

Exact fix (complete, self-contained module)

Save as x25519_solution.py:

"""
X25519 (RFC 7748) implemented from scratch in pure Python 3.

x25519(k, u)          -> 32-byte shared secret, or None on a low-order point.
x25519_base(k)        -> same against u = 9.
x25519_strict(k, u)   -> raises LowOrderPointError on a low-order point.
"""

from typing import Optional

P = 2**255 - 19          # field prime
A24 = 121665             # (486662 - 2) / 4
BITS = 255               # loop over bits 254..0

# Canonical u-coordinates of every low-order point reachable by X25519.
_LOW_ORDER = {
    0,
    1,
    325606250916557431795983626356110631294008115727848805560023387167927233504,
    39382357235489614581723060781553021112529911719440698176882885853963445705823,
    P - 1,   # 2^255 - 20
}


class LowOrderPointError(ValueError):
    """Raised by x25519_strict for a low-order (all-zero-output) input."""


# ---- little-endian codecs -------------------------------------------------
def _decode_le(b: bytes, bits: int) -> int:
    return sum(b[i] << (8 * i) for i in range((bits + 7) // 8))


def _encode_le(n: int, bits: int) -> bytes:
    n %= (1 << bits)
    return bytes((n >> (8 * i)) & 0xFF for i in range((bits + 7) // 8))


def _decode_u(u: bytes) -> int:
    """Decode u; mask bit 255 (RFC 7748 requires this)."""
    if len(u) != 32:
        raise ValueError("X25519 u-coordinate must be 32 bytes")
    b = bytearray(u)
    b[31] &= 0x7F                       # clear the high bit
    return _decode_le(bytes(b), BITS)


def _decode_scalar(k: bytes) -> int:
    """Decode and clamp the scalar (RFC 7748 decodeScalar25519)."""
    if len(k) != 32:
        raise ValueError("X25519 scalar must be 32 bytes")
    b = bytearray(k)
    b[0] &= 248                         # clear the 3 low bits
    b[31] &= 127                        # clear the top bit
    b[31] |= 64                         # set bit 254
    return _decode_le(bytes(b), BITS)


# ---- Montgomery ladder ----------------------------------------------------
def _cswap(swap: int, a: int, b: int):
    """Conditional swap of two field elements."""
    dummy = swap * ((a - b) % P)
    return (a - dummy) % P, (b + dummy) % P


def _ladder(k: int, x1: int) -> int:
    """Return x([k]P) for Montgomery x-coordinate x1, iterating 254..0."""
    x2, z2 = 1, 0
    x3, z3 = x1 % P, 1
    swap = 0
    for t in reversed(range(BITS)):          # t = 254, 253, ..., 0
        kt = (k >> t) & 1
        swap ^= kt
        x2, x3 = _cswap(swap, x2, x3)
        z2, z3 = _cswap(swap, z2, z3)
        swap = kt

        a  = (x2 + z2) % P
        aa = (a * a) % P
        b  = (x2 - z2) % P
        bb = (b * b) % P
        e  = (aa - bb) % P
        c  = (x3 + z3) % P
        d  = (x3 - z3) % P
        da = (d * a) % P
        cb = (c * b) % P
        x3 = (da + cb) % P
        x3 = (x3 * x3) % P
        z3 = (da - cb) % P
        z3 = (x1 * z3 * z3) % P
        x2 = (aa * bb) % P
        z2 = (e * (aa + A24 * e)) % P

    x2, x3 = _cswap(swap, x2, x3)
    z2, z3 = _cswap(swap, z2, z3)
    return (x2 * pow(z2, P - 2, P)) % P      # z2 == 0 -> 0 (identity)


# ---- public API -----------------------------------------------------------
def _is_low_order(x1: int) -> bool:
    # Reduce mod P so p, p+1, ... (non-canonical encodings of low-order
    # elements) are folded onto the canonical blacklist.
    return (x1 % P) in _LOW_ORDER


def x25519(k: bytes, u: bytes) -> Optional[bytes]:
    """X25519(k, u); returns None for a low-order input (no uncaught raise)."""
    x1 = _decode_u(u)
    if _is_low_order(x1):
        return None
    kk = _decode_scalar(k)
    out = _ladder(kk, x1)
    res = _encode_le(out, BITS)
    if res == b"\x00" * 32:                  # defence in depth
        return None
    return res


def x25519_base(k: bytes) -> Optional[bytes]:
    """X25519 against the RFC 7748 base point u = 9."""
    return x25519(k, (9).to_bytes(32, "little"))


def x25519_strict(k: bytes, u: bytes) -> bytes:
    """Like x25519 but raises LowOrderPointError instead of returning None."""
    res = x25519(k, u)
    if res is None:
        raise LowOrderPointError("X25519 input is a low-order point")
    return res

Key points of the fix, mapped to the root causes:

  • Ladder uses for t in reversed(range(255)) → bits 254…0 (fixes #1).
  • _decode_u copies to bytearray and does b[31] &= 0x7F → high-bit masked, never raises (fixes #2, #6).
  • Little-endian encode/decode throughout (fixes #3).
  • _decode_scalar performs the exact RFC clamp (fixes #4).
  • _is_low_order reduces mod p so non-canonical p, p+1, and high-bit variants are rejected; the all-zero output check is a complete backstop (fixes #5).
  • a24 = 121665, z2 = E*(AA + a24*E), and the standard cswap (fixes #7).

If a caller prefers exceptions, x25519_strict wraps the same logic. If the harness expects float('nan')/sentinel instead of None, replace the two return None sites accordingly — the cryptographic logic is unchanged.
