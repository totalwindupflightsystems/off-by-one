Answer

The function uses the classic string rotation algorithm: s1 is a rotation of s2 if and only if s1 is a substring of s2 + s2 (provided lengths are equal and non-empty).

For example: - s1 = "waterbottle", s2 = "erbottlewat" - s2 + s2 = "erbottlewaterbottlewat" → "waterbottle" is a substring ✅

// rotation.go
package main

import "strings"

func IsRotation(s1, s2 string) bool {
    if len(s1) != len(s2) {
        return false
    }
    if len(s1) == 0 {
        return true // two empty strings are rotations
    }
    return strings.Contains(s2+s2, s1)
}

Edge cases handled: - Empty strings ("", "") → true (both empty) - Different lengths → false immediately (no rotation possible) - Single characters ("x", "x") → true; ("x", "y") → false - All same characters ("aaaa", "aaaa") → true - Valid rotations ("abc", "bca") → true - Invalid rotations ("abc", "acb") → false

Time complexity: O(n) — strings.Contains uses efficient Rabin-Karp or Two-Way algorithm in the Go standard library.
Space complexity: O(n) — the concatenated string s2+s2 is temporary.
