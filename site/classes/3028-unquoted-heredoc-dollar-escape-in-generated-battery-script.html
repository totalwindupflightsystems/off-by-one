Fix: unquoted-heredoc dollar escaping in a bash generator script

Symptom

A generator script emits an agent-side script through an unquoted heredoc:

cat > "$out" <<EOF
...
EOF

A newly injected line that contains a shell variable (e.g. DISCONNECT_SUITE_SUMMARY=..., echo "STATUS=$STATUS") is wrong in the rendered file: the runtime variable is expanded/consumed by the generator instead of surviving as $VAR into the generated script. A base64-staged . file workaround also fails because the decoded blob is data, not a shell command stream.

Root cause

An unquoted heredoc body is still shell input to the generating shell. Before the text is written to $out, bash performs parameter expansion ($X, ${X:-d}), command substitution ($(...), backticks), and backslash processing (\$, \\, \`, \<newline>). Therefore:

  • Render-time values ($HOME) must stay unescaped: they should expand now.
  • Agent-runtime values ($STATUS, ${DISCONNECT_SUITE_SUMMARY:-none}) must be escaped exactly once in the template (\$STATUS, \${DISCONNECT_SUITE_SUMMARY:-none}) so the unquoted heredoc renders the literal text $STATUS / ${DISCONNECT_SUITE_SUMMARY:-none} into the file.
  • The patch/edit fuzzy matcher re-applies on failure and can escalate \$ to \\\$; that renders an extra backslash into the generated script, changing runtime semantics even though the line still "contains $STATUS".
  • Base64 staging does not help: base64 protects bytes in transit, but . file / eval still interprets the decoded text as commands, so variables expand at render time. A heredoc-body fragment is data and must not be sourced/evaled.

Escaping contract (write this in the template)

Desired text in generated script Template source (on disk)
$X \$X
${X:-default} \${X:-default}
$(cmd) \$(cmd)
`cmd` \`cmd\`
\ \\
value of render-time $HOME $HOME (unescaped)
literal \$X in output (rare) \\\$X

Exact fix

1. Escape runtime vars once in the template

cat > "$out" <<EOF
#!/usr/bin/env bash
set -euo pipefail
BUNKER_HOME="$HOME/.bunker"
DISCONNECT_SUITE_SUMMARY="\${DISCONNECT_SUITE_SUMMARY:-none}"
echo "STATUS=\$STATUS"
EOF

2. Inject escape-dense lines with a line-scoped, anchored, idempotent patcher

Do not use a fuzzy patch/edit tool for these lines. Stage a Python script that matches the full stripped line exactly and writes the desired line once. This cannot re-escalate backslashes on retries.

#!/usr/bin/env python3
"""Line-scoped, anchored rewrite of escape-dense generator lines.

Edits only lines whose stripped form EXACTLY equals an anchor. No fuzzy
matching, no whole-file regex, idempotent on retry.
Usage: patch_gen.py GENERATOR
"""
import sys

# exact stripped old line -> exact stripped desired line
RULES = [
    ('DISCONNECT_SUITE_SUMMARY="$DISCONNECT_SUITE_SUMMARY"',
     'DISCONNECT_SUITE_SUMMARY="\\${DISCONNECT_SUITE_SUMMARY:-none}"'),
    ('echo "STATUS=$STATUS"',
     'echo "STATUS=\\$STATUS"'),
]

def main(path):
    with open(path, encoding="utf-8") as fh:
        lines = fh.readlines()
    changed = 0
    out = []
    for line in lines:
        newline = "\n" if line.endswith("\n") else ""
        bare = line[:-1] if newline else line
        stripped = bare.strip()
        indent = bare[: len(bare) - len(bare.lstrip())]
        for old, new in RULES:
            if stripped == old:
                desired = indent + new + newline
                if line != desired:
                    line = desired
                    changed += 1
                break
        out.append(line)
    if changed:
        with open(path, "w", encoding="utf-8") as fh:
            fh.writelines(out)
    print(f"{path}: {changed} line(s) rewritten")
    return 0

if __name__ == "__main__":
    raise SystemExit(main(sys.argv[1]))

Rules of thumb

  1. Render-time variable → leave $X unescaped.
  2. Agent-runtime variable → write \$X (single backslash) in the template.
  3. Never use base64 + . file / eval to "preserve" heredoc-body text; the blob is data, not a command stream.
  4. Never use a fuzzy patch tool on escape-dense lines; use exact, line-scoped, idempotent replacement.
  5. Always bash -n and grep the rendered file, never the template.
