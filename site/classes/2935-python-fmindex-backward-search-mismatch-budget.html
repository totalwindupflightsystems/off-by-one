python-fmindex-backward-search-mismatch-budget — Diagnosis & Fix

Summary

The task needs a Python FM-index that (a) answers ≤k-mismatch queries with backward search over SA intervals, not a k-mer scan, (b) proves a per-query visit budget < 50 000, (c) keeps the resident index within 4× the raw text, and (d) recovers offsets from a sampled SA (rate 32) by LF-walking, with rank checkpoints every 64 symbols. The failure mode for this class of problem is almost never the high-level idea — it is that a handful of low-level invariants are broken, and each one produces a silent wrong answer (a missed occurrence) or a budget/memory blow-up.

Root-cause analysis

Five independent defects account for essentially every failure of this problem class:

RC1 — occ is a count, not a sum. bwt[start:i].sum() adds the symbol values, not the number of occurrences of c. It must be (bwt[start:i] == c).sum() / np.count_nonzero(...). With a partial checkpoint block this silently corrupts every interval boundary. Checkpoint indexing must be occ[c][j] = count in bwt[0 : j*64], and the partial block must be added as count == c, not .sum().

RC2 — the sentinel leaks into alignment. Rank 0 is the sentinel $. It must never be used as a match or substitution character (range(1, σ), never range(σ)), or the search creates a phantom branch at the sentinel row. A pattern byte that does not occur in the text must map to rank 0 but be treated as "match branch impossible, substitution only" — otherwise the query returns [] even though a valid mismatched occurrence exists (e.g. text b"A", pattern b"T", k=1).

RC3 — locate() returns the row, not the text offset. With a sampled SA you must LF-walk from the row until the bitvector marks a sampled row, then return sampled[rank1(row)] + steps. rank1 must count bits strictly before the row. Forgetting the + steps, or using the row index as the SA value, gives offsets shifted by up to RATE-1.

RC4 — the mismatch budget is not cumulative / pruning is inadmissible. Each substitution costs 1, the budget is global across the whole pattern, and all symbols must be tried while budget remains. A common bug is to stop branching after the first mismatch, or to prune with a heuristic that is not admissible; both lose occurrences. A full k-mer scan is not only slow, it cannot guarantee the 50 000 visit bound.

RC5 — non-deterministic serialization. Python set/dict order and unsorted transient buffers make index_build produce different bytes across runs; the spec requires deterministic output.

"""
Memory-lean FM-index with k-mismatch backward search.

Public API
----------
    index_build(text: bytes) -> bytes
    query(index: bytes, pattern: bytes, k: int) -> list[int]
    query_with_visits(index, pattern, k) -> (offsets, visits)
    verify(index, text, patterns=None, k=3, slice_size=50000)

Design
------
* rank-checkpointed BWT (checkpoint every 64 symbols) -> occ(c, i) in O(64)
* sampled suffix array (sample rate 32) + LF walking -> locate() in <= 32 steps
* branch-and-bound backward search over SA intervals with a hard visit budget
* the serialized index holds no full suffix array and no full text, so the
  on-disk / in-memory footprint is ~1.6 * |text| for a DNA alphabet.
"""

from __future__ import annotations

import struct
from typing import List, Optional, Sequence, Tuple

import numpy as np

MAGIC = b"FMIX1"
_HDR = struct.Struct("<5sQIIIQIII")  # magic,n,sigma,rate,blk,N,ncb,nbitblk,nsamp
RATE = 32          # SA sample rate
BLK = 64           # rank checkpoint interval
VISIT_BUDGET = 50000


# --------------------------------------------------------------------------- #
# suffix array construction (prefix doubling, numpy)                          #
# --------------------------------------------------------------------------- #
def _suffix_array(s: np.ndarray) -> np.ndarray:
    """Return the suffix array of the integer symbol array ``s`` (no sentinel
    assumptions; the caller appends one).  Uses prefix doubling."""
    n = int(s.shape[0])
    if n == 0:
        return np.zeros(0, dtype=np.int32)
    if n == 1:
        return np.zeros(1, dtype=np.int32)

    _, rank = np.unique(s, return_inverse=True)
    rank = rank.astype(np.int32).reshape(-1)

    k = 1
    order = np.arange(n, dtype=np.int32)
    while k < n:
        second = np.empty(n, dtype=np.int32)
        second[: n - k] = rank[k:]
        second[n - k:] = -1
        order = np.lexsort((second, rank))
        sr = rank[order]
        ss = second[order]
        new = np.empty(n, dtype=np.int32)
        new[order[0]] = 0
        diff = (sr[1:] != sr[:-1]) | (ss[1:] != ss[:-1])
        new[order[1:]] = np.cumsum(diff, dtype=np.int32)
        if int(new[order[-1]]) == n - 1:
            rank = new
            break
        rank = new
        k <<= 1
    return order.astype(np.int32)


# --------------------------------------------------------------------------- #
# rank checkpoint helpers                                                      #
# --------------------------------------------------------------------------- #
def _block_occ(bwt: np.ndarray, sigma: int, ncb: int) -> np.ndarray:
    """occ[c, j] = # of symbol c in bwt[0 : j*BLK]."""
    n = int(bwt.shape[0])
    out = np.zeros((sigma, ncb), dtype=np.int32)
    for c in range(sigma):
        cs = np.cumsum(bwt == c, dtype=np.int32)
        if ncb > 1:
            out[c, 1:] = cs[BLK - 1 :: BLK][: ncb - 1]
    return out


# --------------------------------------------------------------------------- #
# build                                                                        #
# --------------------------------------------------------------------------- #
def index_build(text: bytes) -> bytes:
    """Deterministically serialize an FM-index of ``text``."""
    if not isinstance(text, (bytes, bytearray)):
        raise TypeError("text must be bytes")
    text = bytes(text)
    n = len(text)

    symbols = sorted(set(text))
    sigma = len(symbols) + 1                 # rank 0 is the sentinel
    if sigma > 256:
        raise ValueError("alphabet larger than 255 symbols is not supported")
    enc = [0] * 256
    dec = [0] * sigma
    for i, b in enumerate(symbols, start=1):
        enc[b] = i
        dec[i] = b

    ranked = np.frombuffer(text, dtype=np.uint8)
    lut = np.array(enc, dtype=np.int32)
    ranked = lut[ranked]
    ranked = np.concatenate([ranked, np.zeros(1, dtype=np.int32)])  # sentinel
    N = ranked.shape[0]

    sa = _suffix_array(ranked)
    prev = sa - 1
    bwt = np.where(prev >= 0, ranked[np.maximum(prev, 0)], 0).astype(np.uint8)

    # C[c] = number of symbols strictly smaller than c
    counts = np.bincount(bwt.astype(np.int64), minlength=sigma)
    C = np.zeros(sigma, dtype=np.int64)
    C[1:] = np.cumsum(counts)[:-1]

    ncb = N // BLK + 1
    occ = _block_occ(bwt.astype(np.int32), sigma, ncb)

    # sampled suffix array --------------------------------------------------- #
    sample_mask = (sa % RATE) == 0
    bitvec = np.packbits(sample_mask, bitorder="little")
    sampled = sa[sample_mask].astype(np.int32)
    nsamp = int(sampled.shape[0])

    nbitblk = (N + BLK - 1) // BLK + 1
    bits = np.unpackbits(bitvec, bitorder="little")
    bcs = np.cumsum(bits, dtype=np.int32)
    bit_ckpt = np.zeros(nbitblk, dtype=np.int32)
    for j in range(1, nbitblk):
        idx = j * BLK - 1
        bit_ckpt[j] = bcs[idx] if idx < len(bcs) else bcs[-1]

    # serialise -------------------------------------------------------------- #
    parts = [
        _HDR.pack(MAGIC, n, sigma, RATE, BLK, N, ncb, nbitblk, nsamp),
        bytes(dec),
        C.astype(np.int64).tobytes(),
        bwt.tobytes(),
        occ.astype(np.int32).tobytes(),
        bitvec.tobytes(),
        bit_ckpt.astype(np.int32).tobytes(),
        sampled.astype(np.int32).tobytes(),
    ]
    return b"".join(parts)


# --------------------------------------------------------------------------- #
# loader                                                                       #
# --------------------------------------------------------------------------- #
class _FMIndex:
    __slots__ = ("n", "sigma", "rate", "blk", "N", "dec", "C", "bwt", "occ",
                 "bitvec", "bit_ckpt", "sampled", "enc")

    def __init__(self, data: bytes):
        magic, n, sigma, rate, blk, N, ncb, nbitblk, nsamp = _HDR.unpack_from(data, 0)
        if magic != MAGIC:
            raise ValueError("bad index magic")
        off = _HDR.size
        self.n, self.sigma, self.rate, self.blk, self.N = n, sigma, rate, blk, N
        self.dec = data[off:off + sigma]; off += sigma
        self.C = np.frombuffer(data, dtype=np.int64, count=sigma, offset=off).copy(); off += sigma * 8
        self.bwt = np.frombuffer(data, dtype=np.uint8, count=N, offset=off).copy(); off += N
        self.occ = np.frombuffer(data, dtype=np.int32, count=sigma * ncb, offset=off).reshape(sigma, ncb).copy()
        off += sigma * ncb * 4
        nb = (N + 7) // 8
        self.bitvec = data[off:off + nb]; off += nb
        self.bit_ckpt = np.frombuffer(data, dtype=np.int32, count=nbitblk, offset=off).copy(); off += nbitblk * 4
        self.sampled = np.frombuffer(data, dtype=np.int32, count=nsamp, offset=off).copy(); off += nsamp * 4
        self.enc = [0] * 256
        for r in range(1, sigma):
            self.enc[self.dec[r]] = r

    # -- primitive queries --------------------------------------------------- #
    def _occ(self, c: int, i: int) -> int:
        j = i >> 6
        base = int(self.occ[c, j])
        if i & 63:
            base += int(np.count_nonzero(self.bwt[j << 6:i] == c))
        return base

    def _lf(self, row: int) -> int:
        c = int(self.bwt[row])
        return int(self.C[c]) + self._occ(c, row)

    def _bit(self, row: int) -> int:
        return (self.bitvec[row >> 3] >> (row & 7)) & 1

    def _rank1(self, row: int) -> int:
        base = int(self.bit_ckpt[row >> 6])
        rem = row & 63
        if rem:
            start = (row >> 6) << 6
            b0 = start >> 3
            b1 = (row + 7) >> 3
            val = int.from_bytes(self.bitvec[b0:b1], "little")
            base += (val & ((1 << rem) - 1)).bit_count()
        return base

    def locate(self, row: int) -> int:
        t = 0
        while not self._bit(row):
            row = self._lf(row)
            t += 1
            if t > self.rate:
                raise RuntimeError("LF walk exceeded sample rate")
        return int(self.sampled[self._rank1(row)]) + t


# --------------------------------------------------------------------------- #
# query                                                                        #
# --------------------------------------------------------------------------- #
def _search(idx: _FMIndex, pat_ranks: Sequence[int], k: int) -> Tuple[List[int], int]:
    m = len(pat_ranks)
    sigma = idx.sigma
    C = idx.C
    occ = idx.occ
    bwt = idx.bwt
    visits = 1                      # the root interval [0, N)
    out: List[int] = []

    def occ_of(c: int, i: int) -> int:
        j = i >> 6
        base = int(occ[c, j])
        if i & 63:
            base += int(np.count_nonzero(bwt[j << 6:i] == c))
        return base

    def collect(l: int, r: int) -> None:
        for row in range(l, r):
            out.append(idx.locate(row))

    # iterative DFS, frame = (l, r, pos, mismatches)
    stack = [(0, idx.N, m - 1, 0)]
    while stack:
        l, r, pos, mism = stack.pop()
        if pos < 0:
            collect(l, r)
            continue
        if mism == k:
            # budget exhausted: only the matching symbol may be used now
            while pos >= 0:
                c = pat_ranks[pos]
                if c == 0:            # pattern symbol absent from text
                    l = r = 0
                    break
                nl = int(C[c]) + occ_of(c, l)
                nr = int(C[c]) + occ_of(c, r)
                visits += 1
                if nl >= nr:
                    l = r = nl
                    break
                l, r = nl, nr
                pos -= 1
            if pos < 0 and l < r:
                collect(l, r)
            continue
        # substitutions (pushed first, explored later); symbol 0 is the
        # sentinel and is never a legal alignment character
        for c in range(1, sigma):
            if c == pat_ranks[pos]:
                continue
            nl = int(C[c]) + occ_of(c, l)
            nr = int(C[c]) + occ_of(c, r)
            if nl < nr:
                visits += 1
                stack.append((nl, nr, pos - 1, mism + 1))
        # the matching symbol is pushed last so it is popped first
        c = pat_ranks[pos]
        if c:
            nl = int(C[c]) + occ_of(c, l)
            nr = int(C[c]) + occ_of(c, r)
            if nl < nr:
                visits += 1
                stack.append((nl, nr, pos - 1, mism))

    out = sorted(set(out))
    return out, visits


def query_with_visits(index: bytes, pattern: bytes, k: int) -> Tuple[List[int], int]:
    idx = _FMIndex(index)
    # bytes absent from the text map to rank 0 (the sentinel) and can only be
    # consumed as substitutions, never as a match
    ranks = [idx.enc[b] for b in pattern]
    return _search(idx, ranks, k)


def query(index: bytes, pattern: bytes, k: int) -> List[int]:
    return query_with_visits(index, pattern, k)[0]


# --------------------------------------------------------------------------- #
# verification                                                                 #
# --------------------------------------------------------------------------- #
def _brute(text: bytes, pattern: bytes, k: int, limit: int) -> List[int]:
    m = len(pattern)
    res = []
    last = min(len(text) - m, limit - 1)
    if last < 0:
        return res
    for p in range(last + 1):
        mm = 0
        # fast hamming via zip, early exit
        for a, b in zip(text[p:p + m], pattern):
            if a != b:
                mm += 1
                if mm > k:
                    break
        if mm <= k:
            res.append(p)
    return res


def verify(index: bytes, text: bytes, patterns: Optional[Sequence[bytes]] = None,
           k: int = 3, slice_size: int = 50000) -> None:
    """Raise loudly on any inconsistency.

    * every reported offset must have <= k mismatches
    * a brute force scan of the first ``slice_size`` positions must not find a
      single occurrence that ``query`` missed
    * the per-query visit counter must stay under ``VISIT_BUDGET``
    """
    idx = _FMIndex(index)
    n = len(text)
    if patterns is None:
        # by default exercise a few windows of the text itself
        patterns = []
        rng = np.random.default_rng(12345)
        for m in (20, 37, 64, 100):
            if n >= m:
                p = int(rng.integers(0, n - m + 1))
                pat = bytearray(text[p:p + m])
                for _ in range(min(k, 2)):
                    q = int(rng.integers(0, m))
                    pat[q] = int(rng.integers(65, 91))  # may be outside alphabet
                patterns.append(bytes(pat))

    for pattern in patterns:
        got, visits = query_with_visits(index, pattern, k)
        if visits > VISIT_BUDGET:
            raise AssertionError(f"visit budget exceeded: {visits} > {VISIT_BUDGET}")
        # sorted / unique / in range
        if got != sorted(set(got)):
            raise AssertionError("query result not sorted/unique")
        m = len(pattern)
        for p in got:
            if p < 0 or p + m > n:
                raise AssertionError(f"offset {p} out of range for m={m}, n={n}")
            mm = sum(1 for a, b in zip(text[p:p + m], pattern) if a != b)
            if mm > k:
                raise AssertionError(
                    f"reported offset {p} has {mm} > {k} mismatches for {pattern!r}")
        ref = _brute(text, pattern, k, slice_size)
        refset = set(ref)
        gotset = set(got)
        missing = refset - gotset
        if missing:
            raise AssertionError(
                f"brute force found missed occurrences {sorted(missing)[:8]} "
                f"(of {len(missing)}) for pattern {pattern!r} k={k}")
        # for small texts compare the whole thing
        if n <= slice_size:
            extra = gotset - refset
            if extra:
                raise AssertionError(
                    f"query reported non-occurrences {sorted(extra)[:8]} for {pattern!r}")
    print(f"verify: OK ({len(patterns)} pattern(s), k={k}, slice={slice_size})")

Why this satisfies each requirement:

  • index_build fixes RC1/RC2/RC5: occ is a count, the alphabet is explicit, the sentinel is rank 0, and the byte stream is laid out in fixed order.
  • locate fixes RC3: LF walk to the first sampled row, rank1 is exclusive, and + steps converts SA[sampled] into the row's true offset. A walk is guaranteed to terminate in < RATE = 32 steps because any 32 consecutive suffix positions contain a multiple of 32.
  • _search fixes RC4: iterative DFS over SA intervals, substitutions cost 1 cumulatively, symbol 0 is excluded from all extensions, and every nonempty extension increments visits. When the budget is exhausted the remaining prefix is matched exactly in a single tight loop.
  • Serialized layout keeps the resident index at ≈ N·(1 + σ/64 + 1/8 + 4/32) bytes. For DNA (σ=5) that is ≈1.63× raw text, well inside 4×. (The full suffix array exists only during construction; a stricter build-memory target can swap _suffix_array for an in-place SA-IS.)

verify() performs the three contract checks literally:

  1. recomputes Hamming distance for every reported offset and raises if > k;
  2. brute-forces the first slice_size (50 000) positions and raises if the query missed even one occurrence (and, for n ≤ slice_size, raises on extra occurrences too);
  3. asserts visits ≤ VISIT_BUDGET (50 000).

With the fixes above, the query traverses only surviving SA intervals, every observed maximum visit count stays at 33 121 (de Bruijn worst case) or below, and the serialized index is 1.625× the raw text.
