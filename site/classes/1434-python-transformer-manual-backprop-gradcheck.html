Key fixes worth noting (from root-cause analysis)

  1. The "copy" task must be a true copy — predicting the next random character is unlearnable (entropy floor ln V); shifting by one gives a learnable target.
  2. Positional-embedding scatter shape bug — original pos_idx was (T,) while the gradient is (B,T,D); fixed by tiling indices to (B,T) so np.add.at broadcasts correctly.
  3. Masked-softmax denominator must exclude masked entries in forward, and the backward formula then yields exactly-zero masked gradients automatically (verified bit-exact).
