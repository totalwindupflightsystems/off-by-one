Exact-Rational LLL: Lovász Condition, Tie-Safe Size Reduction, and Knapsack Short-Vector Recovery

Problem class: lll-lattice-basis-reduction-lovasz-exact-rational-embedding-recovery-python

Deliverable: a self-contained, bit-reproducible LLL implementation in pure Python (fractions.Fraction, no floating point), plus an embedding-recovery driver and an exact invariant verifier.

1. Root-cause analysis

For dimension up to 60 with entries exceeding 128 bits, the usual failures are not cosmetic — they change the returned lattice basis.

  1. Floating-point Gram–Schmidt. The textbook algorithm keeps mu[i][j] and B[i]=||b_i*||² as float. With 128-bit entries, B[i] is far beyond 53 bits of mantissa; the Lovász comparison and round(mu) are computed from meaningless values, so the loop makes wrong swaps and can return a basis that no longer spans the input lattice. Fix: carry every GSO value as an exact Fraction; never call float.

  2. The classic round-half bug at the quotient. Size reduction needs q = round(mu). The naive int(mu + 1/2) is wrong for negative mu because int truncates toward zero: mu = -3/5 → int(-1/10) = 0, but the nearest integer is -1. With floats, an exact 1/2 can be a hair above or below, sending q one off. Python's round is also a trap (banker's: round(Fraction(1,2))==0, round(Fraction(5,2))==2). Fix: exact q = floor(mu + 1/2) = (2*num + den) // (2*den); Python // floors, so it is correct for negatives and huge numerators.

  3. Stale / incomplete GSO after a row operation. For b_k -= q b_l, only mu[k][l] and mu[k][i] (i<l) change; after a swap of b_{k-1},b_k, mu[k][k-1], the swapped lower coefficients, and mu[i][k-1],mu[i][k] (i>k) must all be updated with the exact swap formulas. Missing an update yields a "reduced" basis whose fresh GSO violates the invariants. Fix: exact incremental updates, verified against a from-scratch recomputation.

  4. Pivot order. Canonical algorithm (Cohen Algo. 2.6.3 / Wikipedia): reduce b_k against b_{k-1}, test Lovász, and only if no swap finish reducing against b_{k-2}…b_0 top-down. Since the predicate depends only on mu[k][k-1],||b_k*||²,||b_{k-1}*||², which smaller-index reductions never touch, this equals "reduce all j, then test".

  5. Inexact invariant checking. Use fresh exact Fraction GSO and assert |mu[i][j]| <= 1/2 and B[i] >= (delta - mu[i][i-1]²) B[i-1] with zero slack.

  6. Determinism / tie rule. Reduced bases are not unique, so bit-exactness requires the same pivot sequence, the same trigger (> 1/2), and the same half-way rule. Canonical floor formula ⇒ half-way rounds toward +∞.

"""
Exact-rational LLL lattice basis reduction (no floating point).
...
"""

from fractions import Fraction
from math import gcd

__all__ = [
    "lll_reduce", "lll", "gram_schmidt", "check_lll", "is_lll_reduced",
    "round_nearest", "build_subset_sum_lattice", "recover_subset",
]


def round_nearest(x: Fraction) -> int:
    """Exact nearest integer; ties round toward +infinity."""
    num, den = x.numerator, x.denominator
    return (2 * num + den) // (2 * den)


def _dot_frac(u, v):
    s = Fraction(0)
    for a, b in zip(u, v):
        s += a * b
    return s


def gram_schmidt(basis):
    """Exact GSO: mu[i][j]=<b_i,b_j*>/||b_j*||^2, Bnorm[i]=||b_i*||^2."""
    n = len(basis)
    m = len(basis[0]) if n else 0
    mu = [[Fraction(0)] * n for _ in range(n)]
    Bnorm = [Fraction(0)] * n
    bstar = []
    for i in range(n):
        v = [Fraction(x) for x in basis[i]]
        for j in range(i):
            coef = _dot_frac(basis[i], bstar[j]) / Bnorm[j]
            mu[i][j] = coef
            for t in range(m):
                v[t] -= coef * bstar[j][t]
        bstar.append(v)
        Bnorm[i] = _dot_frac(v, v)
    return mu, Bnorm


def lll_reduce(basis, delta=Fraction(3, 4)):
    """Return an exact LLL-reduced basis of the row lattice."""
    delta = Fraction(delta)
    if not (Fraction(1, 4) < delta <= 1):
        raise ValueError("delta must satisfy 1/4 < delta <= 1")

    B = [list(row) for row in basis]
    n = len(B)
    if n == 0:
        return B
    m = len(B[0])

    mu = [[Fraction(0)] * n for _ in range(n)]
    Bnorm = [Fraction(0)] * n
    bstar = []
    for i in range(n):
        v = [Fraction(x) for x in B[i]]
        for j in range(i):
            coef = _dot_frac(B[i], bstar[j]) / Bnorm[j]
            mu[i][j] = coef
            for t in range(m):
                v[t] -= coef * bstar[j][t]
        bstar.append(v)
        Bnorm[i] = _dot_frac(v, v)
    del bstar

    half = Fraction(1, 2)

    def size_reduce(k, l):
        if abs(mu[k][l]) <= half:
            return
        q = round_nearest(mu[k][l])
        if q == 0:
            return
        bk, bl = B[k], B[l]
        for t in range(m):
            bk[t] -= q * bl[t]
        mu[k][l] -= q
        mul, muk = mu[l], mu[k]
        for i in range(l):
            muk[i] -= q * mul[i]

    k = 1
    while k < n:
        size_reduce(k, k - 1)
        if Bnorm[k] < (delta - mu[k][k - 1] * mu[k][k - 1]) * Bnorm[k - 1]:
            mu_kk1 = mu[k][k - 1]
            B_k = Bnorm[k]
            B_km1 = Bnorm[k - 1]
            B_new = B_k + mu_kk1 * mu_kk1 * B_km1
            mu_new = mu_kk1 * B_km1 / B_new

            B[k], B[k - 1] = B[k - 1], B[k]

            for j in range(k - 1):
                mu[k][j], mu[k - 1][j] = mu[k - 1][j], mu[k][j]

            for i in range(k + 1, n):
                t = mu[i][k]
                mu[i][k] = mu[i][k - 1] - mu_kk1 * t
                mu[i][k - 1] = t + mu_new * mu[i][k]

            Bnorm[k] = B_km1 * B_k / B_new
            Bnorm[k - 1] = B_new
            mu[k][k - 1] = mu_new

            k = max(1, k - 1)
        else:
            for l in range(k - 2, -1, -1):
                size_reduce(k, l)
            k += 1

    return B


lll = lll_reduce


def check_lll(basis, delta=Fraction(3, 4), tol=0):
    """Raise AssertionError unless exact size-reduced + delta-Lovasz hold."""
    delta = Fraction(delta)
    tol = Fraction(tol)
    mu, Bnorm = gram_schmidt(basis)
    n = len(basis)
    for i in range(n):
        if Bnorm[i] <= 0:
            raise AssertionError(f"b*_{i} is not positive definite")
        for j in range(i):
            if abs(mu[i][j]) > Fraction(1, 2) + tol:
                raise AssertionError(
                    f"size reduction violated: mu[{i}][{j}] = {mu[i][j]}"
                )
    for i in range(1, n):
        lhs = Bnorm[i]
        rhs = (delta - mu[i][i - 1] * mu[i][i - 1]) * Bnorm[i - 1]
        if lhs < rhs - tol:
            raise AssertionError(f"Lovasz violated at i={i}: {lhs} < {rhs}")


def is_lll_reduced(basis, delta=Fraction(3, 4), tol=0):
    try:
        check_lll(basis, delta, tol)
        return True
    except AssertionError:
        return False


def build_subset_sum_lattice(a, target, scale=None):
    """Coster-et-al. embedding: b_i = 2 e_i + scale*a_i e_n, last = 1...1, scale*target."""
    n = len(a)
    if scale is None:
        scale = n + 1
    B = []
    for i in range(n):
        row = [0] * (n + 1)
        row[i] = 2
        row[n] = scale * a[i]
        B.append(row)
    B.append([1] * n + [scale * target])
    return B


def recover_subset(reduced, a, target=None):
    """Recover the planted subset from a reduced subset-sum lattice."""
    n = len(a)
    best = None
    best_norm = None
    for row in reduced:
        if row[n] != 0:
            continue
        norm = sum(x * x for x in row)
        if best_norm is None or norm < best_norm:
            best_norm = norm
            best = row
    if best is None:
        return None
    cand = set(i for i in range(n) if best[i] > 0)
    if target is None:
        return cand
    if sum(a[i] for i in cand) == target:
        return cand
    comp = set(range(n)) - cand
    if sum(a[i] for i in comp) == target:
        return comp
    cand2 = set(i for i in range(n) if best[i] < 0)
    if sum(a[i] for i in cand2) == target:
        return cand2
    return None
