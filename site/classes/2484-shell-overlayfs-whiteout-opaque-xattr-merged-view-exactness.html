Root causes identified

The task cannot be solved by resolving each path in the union of layer paths. The actual failure modes:

  1. Redirects synthesize paths present in no layer (/redir/child from redirect=/target) — a tree walk is required, not union resolution.
  2. Redirect override applied at the wrong level — P→R must replace the whole child path for lower layers, not be concatenated as R/name.
  3. Lower non-directory stealing the win from a higher directory — only the first (topmost) match may set the winner.
  4. Whiteout below a surviving directory cuts layers but must not delete the directory.
  5. Opaque hides descendants, which still must be reported hidden; the opaque layer's own entries stay visible, and a lower entry whose logical path is won by a higher layer must not be double-reported.
  6. Redirect chains + whiteouts require carrying a per-layer real path and updating it on each redirect.
  7. Root opacity/redirect off-by-ones, relative redirects, and 0:0 whiteout spelling.

Approach

For each logical directory, carry an effective stack (layer, realpath) and a shadow/cut stack (layer, realpath, cause). descend() resolves one component top-down; walk() recurses the merged tree, hiding shadow subtrees and filtering visible paths out of the hidden set.
