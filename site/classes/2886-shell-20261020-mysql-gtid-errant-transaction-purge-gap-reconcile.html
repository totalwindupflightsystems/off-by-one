GTID errant-transaction / purge-gap reconciliation after a failover

Problem class: shell-20261020-mysql-gtid-errant-transaction-purge-gap-reconcile

Reconstruct each server's executed GTID set, classify transactions as missing, errant or unknown, and produce a replay plan that can never re-apply an errant transaction. The procedure is idempotent, derives ground truth from mysqlbinlog plus SHOW GTID_EXECUTED, and exits non-zero rather than guess when a gap cannot be proven empty.

1. Root-cause analysis

1.1 The GTID identity is the thing that breaks

For a MySQL server with GTIDs enabled:

gtid_executed = gtid_purged  ∪  {GTIDs present in the surviving binary logs}

gtid_purged is supposed to advance whenever transactions leave the binary logs. During a failover this invariant is routinely violated:

  • binlogs are deleted by hand / by a backup agent / by OS cleanup, so gtid_purged never learns about it;
  • the old primary's tail was never flushed, so the promoted replica is missing transactions the primary had already reported as executed;
  • the promoted replica owns transactions (manual writes, another replication stream) the source never executed — errant transactions.

When the identity is broken, gtid_executed contains ranges whose events are gone. You can still know a transaction was executed, but you cannot know what it did.

1.2 Three mistakes the naive fix makes

  1. Skipping the gap. SET GLOBAL gtid_purged = <source gtid_executed> on the replica makes it pretend the missing transactions are applied. That silently drops data.
  2. Replaying too much. Building the replay from a coarse range (or from gtid_executed) can pull in errant transactions, duplicating changes that already exist on the replica.
  3. Trusting one source of truth. gtid_executed alone cannot tell you if events still exist to replay; mysqlbinlog alone cannot tell you what was executed (relay logs, purges, log_slave_updates=OFF). You need both.

1.3 What must be computed independently

Symbol Meaning Source
E_s, E_r executed sets @@GLOBAL.gtid_executed
P_s, P_r purged sets @@GLOBAL.gtid_purged
B_s, B_r GTIDs with surviving events mysqlbinlog on the surviving files
V = P ∪ B evidence (everything we can account for locally) derived
missing = E_s \ E_r must be replayed derived
errant = E_r \ E_s must never be replayed derived

The safety argument is a set argument: errant = E_r \ E_s, and the replay set is missing = E_s \ E_r, therefore missing ∩ errant = ∅. The plan passes only --include-gtids=<missing> (a positive allow-list) to mysqlbinlog, so even a set-arithmetic bug cannot admit an errant transaction; a second --exclude-gtids=<errant> guard is added when errant is non-empty.

1.4 Where the "gap that cannot be proven empty" lives

missing \ B_s is the set of transactions the replica needs but for which the source has no surviving event evidence. They may still be in gtid_purged (i.e. already discarded), in a backup, or in a replica relay log. Until evidence is supplied, the script refuses and exits 2; it never silently skips them.

2. The fix

Save the following as gtid_reconcile.sh and chmod +x it. It is one self-contained file (the GTID set-algebra engine is embedded).

#!/usr/bin/env bash
# =============================================================================
# gtid_reconcile.sh
#
# Reconcile two MySQL servers after binary logs were purged during a failover.
#
#   * reconstructs each server's executed GTID set from SHOW GTID_EXECUTED
#     (gtid_executed / gtid_purged) *plus* mysqlbinlog evidence of the
#     surviving binary logs,
#   * classifies every transaction as MISSING, ERRANT, COMMON or UNKNOWN,
#   * emits a replay plan whose allow-list is built only from the proven
#     MISSING set, so it can never contain an errant transaction,
#   * is idempotent: every run re-derives state from the live servers, so an
#     interrupted or repeated apply only ever sees what is still missing,
#   * exits non-zero instead of guessing whenever a gap cannot be proven
#     empty (i.e. a transaction is needed for replay but has no surviving
#     event evidence anywhere we can prove).
#
# Exit codes
#   0  success: plan produced (possibly empty) or apply completed
#   2  UNKNOWN: a required gap cannot be proven empty / cannot be replayed
#   3  evidence collection failure (mysql/mysqlbinlog/awk failure, bad binlog)
#   4  inconsistent evidence (physically present but not executed, partition
#      broken, errant leaked into the replay set)
#   5  usage / configuration error
#
# Requires: bash >= 4.3, mysql client, mysqlbinlog, awk, sed, find/sort.
# =============================================================================

set -o pipefail
# NOTE: not `set -e`; we inspect return codes explicitly so we can report.

readonly PROG=${0##*/}

# ---------------------------------------------------------------------------
# Defaults / global state
# ---------------------------------------------------------------------------
SRC_HOST="" ; SRC_PORT="" ; SRC_USER="" ; SRC_PASS="" ; SRC_SOCKET=""
SRC_DEFAULTS_FILE="" ; SRC_DEFAULTS_GROUP=""
REP_HOST=""  ; REP_PORT=""  ; REP_USER="" ; REP_PASS="" ; REP_SOCKET=""
REP_DEFAULTS_FILE="" ; REP_DEFAULTS_GROUP=""

SRC_BINLOG_DIR="" ; REP_BINLOG_DIR=""
EXTRA_EVIDENCE=""          # optional GTID set file that may satisfy missing
APPLY=0
STRICT_UNACCOUNTED=1

AWK_CMD=${GTID_AWK_CMD:-awk}
declare -a SRC_MYSQL=() SRC_BINLOG=()
declare -a REP_MYSQL=() REP_BINLOG=()

AWK_FILE=""

# ---------------------------------------------------------------------------
# helpers
# ---------------------------------------------------------------------------
die()  { local code=$1; shift; printf '%s: %s\n' "$PROG" "$*" >&2; exit "$code"; }
warn() { printf '%s: warning: %s\n' "$PROG" "$*" >&2; }
info() { printf '%s: %s\n' "$PROG" "$*" >&2; }

usage() {
    cat <<EOF
Usage: $PROG --source-* ... --replica-* ... [options]

Connection options are per side (source = replay from, replica = replay to):
  --source-host HOST        --replica-host HOST
  --source-port PORT        --replica-port PORT
  --source-user USER        --replica-user USER
  --source-password PASS    --replica-password PASS
  --source-socket PATH      --replica-socket PATH
  --source-defaults-file F  --replica-defaults-file F
  --source-defaults-group G --replica-defaults-group G

Binlog evidence:
  --source-binlog-dir DIR   read local copies of source binlogs from DIR
  --replica-binlog-dir DIR  read local copies of replica binlogs from DIR
  --extra-evidence FILE     file containing a GTID set that is known to be
                            replayable from an external archive/backup

Behaviour:
  --apply                   actually run the replay command (default: print)
  --tolerate-unaccounted    do not hard-fail on unaccounted source GTIDs
  -h, --help
EOF
}

parse_args() {
    # option name -> shell variable it sets
    declare -A OPTVAR=(
        [--source-host]=SRC_HOST [--source-port]=SRC_PORT
        [--source-user]=SRC_USER [--source-password]=SRC_PASS
        [--source-socket]=SRC_SOCKET
        [--source-defaults-file]=SRC_DEFAULTS_FILE
        [--source-defaults-group]=SRC_DEFAULTS_GROUP
        [--replica-host]=REP_HOST [--replica-port]=REP_PORT
        [--replica-user]=REP_USER [--replica-password]=REP_PASS
        [--replica-socket]=REP_SOCKET
        [--replica-defaults-file]=REP_DEFAULTS_FILE
        [--replica-defaults-group]=REP_DEFAULTS_GROUP
        [--source-binlog-dir]=SRC_BINLOG_DIR
        [--replica-binlog-dir]=REP_BINLOG_DIR
        [--extra-evidence]=EXTRA_EVIDENCE
    )
    while (( $# )); do
        local opt=$1 val="" hasval=0
        if [[ $opt == --*=* ]]; then
            val=${opt#*=}; opt=${opt%%=*}; hasval=1
        fi
        case $opt in
            --apply) APPLY=1; (( hasval )) || : ; shift ;;
            --tolerate-unaccounted) STRICT_UNACCOUNTED=0; shift ;;
            -h|--help) usage; exit 0 ;;
            *)
                if [[ -n ${OPTVAR[$opt]+x} ]]; then
                    if (( hasval == 0 )); then
                        val=${2:-}
                        shift
                    fi
                    shift
                    printf -v "${OPTVAR[$opt]}" '%s' "$val"
                else
                    die 5 "unknown option: $1 (try --help)"
                fi ;;
        esac
    done
}

build_conns() {
    # mysql clients: --defaults-file must be the first option
    _login_src=(); _login_rep=()
    if [[ -n $SRC_DEFAULTS_FILE ]]; then
        _login_src+=( "--defaults-file=$SRC_DEFAULTS_FILE" )
        [[ -n $SRC_DEFAULTS_GROUP ]] && _login_src+=( "--defaults-group-suffix=$SRC_DEFAULTS_GROUP" )
    fi
    [[ -n $SRC_HOST   ]] && _login_src+=( "--host=$SRC_HOST" )
    [[ -n $SRC_PORT   ]] && _login_src+=( "--port=$SRC_PORT" )
    [[ -n $SRC_USER   ]] && _login_src+=( "--user=$SRC_USER" )
    [[ -n $SRC_PASS   ]] && _login_src+=( "--password=$SRC_PASS" )
    [[ -n $SRC_SOCKET ]] && _login_src+=( "--socket=$SRC_SOCKET" )

    if [[ -n $REP_DEFAULTS_FILE ]]; then
        _login_rep+=( "--defaults-file=$REP_DEFAULTS_FILE" )
        [[ -n $REP_DEFAULTS_GROUP ]] && _login_rep+=( "--defaults-group-suffix=$REP_DEFAULTS_GROUP" )
    fi
    [[ -n $REP_HOST   ]] && _login_rep+=( "--host=$REP_HOST" )
    [[ -n $REP_PORT   ]] && _login_rep+=( "--port=$REP_PORT" )
    [[ -n $REP_USER   ]] && _login_rep+=( "--user=$REP_USER" )
    [[ -n $REP_PASS   ]] && _login_rep+=( "--password=$REP_PASS" )
    [[ -n $REP_SOCKET ]] && _login_rep+=( "--socket=$REP_SOCKET" )

    # mysql = batch query client
    SRC_MYSQL=( mysql --batch --skip-column-names --raw --connect-timeout=15 "${_login_src[@]}" )
    REP_MYSQL=( mysql --batch --skip-column-names --raw --connect-timeout=15 "${_login_rep[@]}" )
    # mysqlbinlog = evidence reader
    if [[ -n $SRC_BINLOG_DIR ]]; then
        SRC_BINLOG=( mysqlbinlog )
    else
        SRC_BINLOG=( mysqlbinlog --read-from-remote-server "${_login_src[@]}" )
    fi
    if [[ -n $REP_BINLOG_DIR ]]; then
        REP_BINLOG=( mysqlbinlog )
    else
        REP_BINLOG=( mysqlbinlog --read-from-remote-server "${_login_rep[@]}" )
    fi
}

# GTID set algebra via the embedded awk engine
gtid_op() {
    local mode=$1 a=${2-} b=${3-}
    "$AWK_CMD" -v mode="$mode" -v A="$a" -v B="$b" -f "$AWK_FILE"
}

# Run a query, return single scalar.
q_side() { # side=source|replica  sql=...
    local side=$1 sql=$2
    if [[ $side == source ]]; then
        "${SRC_MYSQL[@]}" -e "$sql"
    else
        "${REP_MYSQL[@]}" -e "$sql"
    fi
}

# Fetch a GTID variable from a side. Returns empty string if NULL/absent.
gtid_var() { # side  varname
    q_side "$1" "SELECT COALESCE(@@GLOBAL.$2,'')" 2>/dev/null
}

# ---------------------------------------------------------------------------
# Evidence collection
# ---------------------------------------------------------------------------
list_binlogs() { # side -> filenames on stdout, ordered
    local side=$1
    local rows
    rows=$(q_side "$side" "SHOW BINARY LOGS" 2>/dev/null) || \
        die 3 "cannot list binary logs on $side"
    printf '%s\n' "$rows" | awk 'NF {print $1}'
}

# Print an ordered list (one per line) of the binlog files for a side.
#   remote : the base names returned by SHOW BINARY LOGS (mysqlbinlog
#            --read-from-remote-server fetches them).
#   local  : every *.0* file in the directory (so archived copies are used),
#            except .index and relay logs -- relay logs hold not-yet-executed
#            transactions and must never be counted as executed evidence.
binlog_paths() { # side
    local side=$1 dir
    if [[ $side == source ]]; then dir=$SRC_BINLOG_DIR; else dir=$REP_BINLOG_DIR; fi
    if [[ -z $dir ]]; then
        list_binlogs "$side"
        return
    fi
    find "$dir" -maxdepth 1 -type f -name '*.0*' \
        ! -name '*.index' ! -name '*relay*' -print 2>/dev/null \
        | LC_ALL=C sort
}

# Extract every GTID that actually occurs as a transaction event in the
# surviving binary logs and return the normalized union.  Fails loudly if
# mysqlbinlog cannot read a file (corruption/truncation) -- we refuse to
# guess what a damaged file contained.
scan_binlogs() { # side
    local side=$1
    local -a files=() reader=()
    local path

    while IFS= read -r path; do
        [[ -n $path ]] && files+=( "$path" )
    done < <(binlog_paths "$side")

    if (( ${#files[@]} == 0 )); then
        printf ''
        return 0
    fi

    if [[ $side == source ]]; then
        reader=( "${SRC_BINLOG[@]}" )
    else
        reader=( "${REP_BINLOG[@]}" )
    fi

    # Capture stderr so a parse failure is reported, not silently swallowed.
    local errfile; errfile=$(mktemp)
    local gtids rc
    # shellcheck disable=SC2016
    gtids=$(
        "${reader[@]}" "${files[@]}" 2>"$errfile" \
        | sed -n \
          "s/.*SET @@SESSION.GTID_NEXT= '\([0-9A-Fa-f]\{8\}-[0-9A-Fa-f]\{4\}-[0-9A-Fa-f]\{4\}-[0-9A-Fa-f]\{4\}-[0-9A-Fa-f]\{12\}:[0-9]\+\)'.*/\1/p" \
        | "$AWK_CMD" -v mode=collect -f "$AWK_FILE"
    )
    rc=$?
    if (( rc != 0 )); then
        warn "mysqlbinlog failed while scanning $side binary logs:"
        sed 's/^/    /' "$errfile" >&2
        rm -f "$errfile"
        die 3 "could not derive ground truth from $side binary logs"
    fi
    # mysqlbinlog may exit 0 yet print errors about a truncated tail; treat
    # any 'error'/'corrupt' diagnostic as fatal.
    if grep -qiE '(error|corrupt|truncat|failed)' "$errfile"; then
        warn "mysqlbinlog reported problems scanning $side binary logs:"
        grep -iE '(error|corrupt|truncat|failed)' "$errfile" | sed 's/^/    /' >&2
        rm -f "$errfile"
        die 3 "refusing to guess contents of damaged $side binary logs"
    fi
    rm -f "$errfile"
    printf '%s' "$gtids"
}

# ---------------------------------------------------------------------------
# main
# ---------------------------------------------------------------------------
main() {
    parse_args "$@"

    if [[ -z $SRC_DEFAULTS_FILE && -z $SRC_HOST && -z $SRC_SOCKET ]]; then
        die 5 "source connection is not configured (use --source-* options)"
    fi
    if [[ -z $REP_DEFAULTS_FILE && -z $REP_HOST && -z $REP_SOCKET ]]; then
        die 5 "replica connection is not configured (use --replica-* options)"
    fi

    build_conns

    # --- embedded awk engine -------------------------------------------------
    AWK_FILE=$(mktemp) || die 3 "cannot create temporary file"
    trap 'rm -f "$AWK_FILE"' EXIT
    cat > "$AWK_FILE" <<'GTID_AWK_EOF'
# gtid.awk -- GTID set algebra for MySQL GTID sets.
#
# Input (awk -v):  mode = normalize|union|sub|inter|subset|equal|card
#                  A    = first GTID set string
#                  B    = second GTID set string (where used)
# Output: canonical GTID set string, or "1"/"0" for subset/equal,
#         or a count for card.
#
# GTID set grammar (GNO):
#   set      = uuidset ("," uuidset)*
#   uuidset  = uuid ":" interval (":" interval)*
#   interval = n ["-" m]
# Endpoints are unsigned 64-bit.  We carry them as doubles; up to 2^53
# (9.0e15) transactions are represented exactly, which is far beyond any
# real MySQL server.  Values are printed with "%.0f" so no exponent form.

function reset_set(which) {
    if (which == 1) na = 0
    else nb = 0
}

function push(which, uuid, lo, hi,   n) {
    if (lo > hi) return
    if (which == 1) { na++; au[na] = uuid; al[na] = lo; ah[na] = hi }
    else            { nb++; bu[nb] = uuid; bl[nb] = lo; bh[nb] = hi }
}

function parse(s, which) {
    reset_set(which)
    parse_add(s, which)
}

# Add components of s to an existing set without resetting it.
function parse_add(s, which,   ncomp, comps, i, comp, parts, k, j, iv, ab, a, b) {
    if (s == "") return
    ncomp = split(s, comps, ",")
    for (i = 1; i <= ncomp; i++) {
        comp = comps[i]
        gsub(/^[ \t\r\n]+/, "", comp)
        gsub(/[ \t\r\n]+$/, "", comp)
        if (comp == "") continue
        k = split(comp, parts, ":")
        if (k < 2) continue
        for (j = 2; j <= k; j++) {
            iv = parts[j]
            if (index(iv, "-") > 0) {
                split(iv, ab, "-")
                a = ab[1] + 0
                b = (ab[2] == "") ? a : ab[2] + 0
            } else {
                a = iv + 0
                b = a
            }
            # UUIDs are case-insensitive; canonicalise so server output and
            # mysqlbinlog output always compare equal.
            push(which, tolower(parts[1]), a, b)
        }
    }
}

# copy the result arrays res* into a private copy s* and sort/merge them
function norm_res(   i, j, tu, tl, th, cnt, n) {
    cnt = nr
    for (i = 1; i <= cnt; i++) { su[i] = resu[i]; sl[i] = resl[i]; sh[i] = resh[i] }
    for (i = 2; i <= cnt; i++) {
        tu = su[i]; tl = sl[i]; th = sh[i]
        j = i - 1
        while (j >= 1 && (su[j] > tu || (su[j] == tu && sl[j] > tl))) {
            su[j+1] = su[j]; sl[j+1] = sl[j]; sh[j+1] = sh[j]
            j--
        }
        su[j+1] = tu; sl[j+1] = tl; sh[j+1] = th
    }
    m = 0
    for (i = 1; i <= cnt; i++) {
        if (m > 0 && mu[m] == su[i] && sl[i] <= mh[m] + 1) {
            if (sh[i] > mh[m]) mh[m] = sh[i]
        } else {
            m++
            mu[m] = su[i]; ml[m] = sl[i]; mh[m] = sh[i]
        }
    }
}

function print_res(   i, s) {
    s = ""
    for (i = 1; i <= m; i++) {
        if (i > 1) s = s ","
        s = s mu[i] ":"
        if (ml[i] == mh[i]) s = s sprintf("%.0f", ml[i])
        else s = s sprintf("%.0f", ml[i]) "-" sprintf("%.0f", mh[i])
    }
    print s
}

# subtract B from A -> res arrays
function subtract(   i, j, k, pl, ph, ql, qh, np, newn) {
    nr = 0
    for (i = 1; i <= na; i++) {
        np = 1
        pl_l[1] = al[i]; pl_h[1] = ah[i]
        for (j = 1; j <= nb && np > 0; j++) {
            if (bu[j] != au[i]) continue
            ql = bl[j]; qh = bh[j]
            newn = 0
            for (k = 1; k <= np; k++) {
                pl = pl_l[k]; ph = pl_h[k]
                if (qh < pl || ql > ph) {
                    newn++; nl[newn] = pl; nh[newn] = ph
                } else {
                    if (ql > pl) { newn++; nl[newn] = pl;       nh[newn] = ql - 1 }
                    if (qh < ph) { newn++; nl[newn] = qh + 1;   nh[newn] = ph     }
                }
            }
            np = newn
            for (k = 1; k <= newn; k++) { pl_l[k] = nl[k]; pl_h[k] = nh[k] }
        }
        for (k = 1; k <= np; k++) {
            nr++; resu[nr] = au[i]; resl[nr] = pl_l[k]; resh[nr] = pl_h[k]
        }
    }
}

function intersect(   i, j, lo, hi) {
    nr = 0
    for (i = 1; i <= na; i++) {
        for (j = 1; j <= nb; j++) {
            if (bu[j] != au[i]) continue
            lo = (al[i] > bl[j]) ? al[i] : bl[j]
            hi = (ah[i] < bh[j]) ? ah[i] : bh[j]
            if (lo <= hi) { nr++; resu[nr] = au[i]; resl[nr] = lo; resh[nr] = hi }
        }
    }
}

function union_res(   i) {
    nr = 0
    for (i = 1; i <= na; i++) { nr++; resu[nr] = au[i]; resl[nr] = al[i]; resh[nr] = ah[i] }
    for (i = 1; i <= nb; i++) { nr++; resu[nr] = bu[i]; resl[nr] = bl[i]; resh[nr] = bh[i] }
}

function count_res(   i, total) {
    total = 0
    for (i = 1; i <= m; i++) total += mh[i] - ml[i] + 1
    return total
}

BEGIN {
    if (mode == "normalize") {
        parse(A, 1)
        nr = 0
        for (i = 1; i <= na; i++) { nr++; resu[nr] = au[i]; resl[nr] = al[i]; resh[nr] = ah[i] }
        norm_res(); print_res()
    } else if (mode == "union") {
        parse(A, 1); parse(B, 2); union_res(); norm_res(); print_res()
    } else if (mode == "sub") {
        parse(A, 1); parse(B, 2); subtract(); norm_res(); print_res()
    } else if (mode == "inter") {
        parse(A, 1); parse(B, 2); intersect(); norm_res(); print_res()
    } else if (mode == "subset") {
        parse(A, 1); parse(B, 2); subtract()
        print (nr == 0) ? "1" : "0"
    } else if (mode == "equal") {
        parse(A, 1); parse(B, 2); subtract()
        if (nr != 0) { print "0"; exit }
        parse(B, 1); parse(A, 2); subtract()
        print (nr == 0) ? "1" : "0"
    } else if (mode == "collect") {
        reset_set(1)
        while ((getline line) > 0) {
            gsub(/[ \t\r\n]/, "", line)
            parse_add(line, 1)
        }
        nr = 0
        for (i = 1; i <= na; i++) { nr++; resu[nr] = au[i]; resl[nr] = al[i]; resh[nr] = ah[i] }
        norm_res(); print_res()
    } else if (mode == "card") {
        parse(A, 1)
        nr = 0
        for (i = 1; i <= na; i++) { nr++; resu[nr] = au[i]; resl[nr] = al[i]; resh[nr] = ah[i] }
        norm_res()
        printf "%.0f\n", count_res()
    } else {
        print "unknown mode: " mode > "/dev/stderr"
        exit 2
    }
}
GTID_AWK_EOF

    gtid_op normalize "aaaaaaaa-aaaa-aaaa-aaaa-aaaaaaaaaaaa:1-2" >/dev/null \
        || die 3 "GTID algebra engine is not working (awk failure)"

    # --- collect reported sets ----------------------------------------------
    local E_s P_s E_r P_r B_s B_r
    E_s=$(gtid_var source gtid_executed)  || die 3 "cannot read source gtid_executed"
    P_s=$(gtid_var source gtid_purged)    || die 3 "cannot read source gtid_purged"
    E_r=$(gtid_var replica gtid_executed) || die 3 "cannot read replica gtid_executed"
    P_r=$(gtid_var replica gtid_purged)   || die 3 "cannot read replica gtid_purged"

    [[ -n $E_s ]] || die 3 "source gtid_executed is empty or GTID mode is disabled"
    [[ -n $E_r ]] || die 3 "replica gtid_executed is empty or GTID mode is disabled"

    E_s=$(gtid_op normalize "$E_s")
    P_s=$(gtid_op normalize "$P_s")
    E_r=$(gtid_op normalize "$E_r")
    P_r=$(gtid_op normalize "$P_r")

    info "scanning surviving source binary logs ..."
    B_s=$(scan_binlogs source) || exit 3
    info "scanning surviving replica binary logs ..."
    B_r=$(scan_binlogs replica) || exit 3
    B_s=$(gtid_op normalize "$B_s")
    B_r=$(gtid_op normalize "$B_r")

    # --- per-side ground-truth reconstruction --------------------------------
    local V_s V_r src_extra src_unacc rep_extra rep_unacc rep_unacc_bad
    V_s=$(gtid_op union "$P_s" "$B_s")          # source evidence (purged + binlog)
    V_r=$(gtid_op union "$P_r" "$B_r")          # replica evidence
    src_extra=$(gtid_op sub "$V_s" "$E_s")      # present, not claimed executed
    src_unacc=$(gtid_op sub "$E_s" "$V_s")      # claimed executed, no evidence
    rep_extra=$(gtid_op sub "$V_r" "$E_r")
    rep_unacc=$(gtid_op sub "$E_r" "$V_r")
    # A replica without log_slave_updates legitimately has replicated GTIDs
    # absent from its own binlog; they are explained if the source has them.
    rep_unacc_bad=$(gtid_op sub "$rep_unacc" "$V_s")

    # --- reconciliation ------------------------------------------------------
    local missing errant common
    missing=$(gtid_op sub "$E_s" "$E_r")
    errant=$(gtid_op sub "$E_r" "$E_s")
    common=$(gtid_op inter "$E_s" "$E_r")

    # --- safety invariants (defence in depth) --------------------------------
    local tmp1 tmp2
    tmp1=$(gtid_op union "$missing" "$common"); [[ $tmp1 == "$E_s" ]] || bad_set "missing ∪ common != source executed"
    tmp2=$(gtid_op union "$errant"  "$common"); [[ $tmp2 == "$E_r" ]] || bad_set "errant ∪ common != replica executed"
    tmp1=$(gtid_op inter "$missing" "$errant"); [[ -z $tmp1 ]] || bad_set "missing ∩ errant is not empty"

    # --- unknowns / unprovable gaps -----------------------------------------
    # Transactions we still need that have no surviving event evidence on the
    # source (they were purged).  These cannot be replayed from available
    # binlogs; we must not silently skip them.
    local unknown_missing
    unknown_missing=$(gtid_op sub "$missing" "$B_s")

    # Optional external evidence can clear an otherwise-unprovable missing set.
    if [[ -n $EXTRA_EVIDENCE ]]; then
        [[ -f $EXTRA_EVIDENCE ]] || die 5 "extra evidence file not found: $EXTRA_EVIDENCE"
        local extra
        extra=$(gtid_op normalize "$(tr -d ' \t\r\n' < "$EXTRA_EVIDENCE")")
        unknown_missing=$(gtid_op sub "$unknown_missing" "$extra")
    fi

    # Combined UNKNOWN bucket for the report: every transaction we cannot
    # prove is either absent or safely replayable.
    local unknown_all
    unknown_all=$(gtid_op union "$(gtid_op union "$src_unacc" "$rep_unacc_bad")" "$unknown_missing")

    # --- report --------------------------------------------------------------
    cat <<EOF

================ GTID reconciliation report ================
source  executed : $E_s
source  purged   : $P_s
source  binlog   : $B_s
source  evidence : $V_s   (purged ∪ binlog)
replica executed : $E_r
replica purged   : $P_r
replica binlog   : $B_r
replica evidence : $V_r

MISSING (source has, replica lacks) : $missing
ERRANT  (replica has, source lacks) : $errant
COMMON                              : $common

source unaccounted (in executed, no evidence)          : $src_unacc
replica unaccounted, unexplained by source             : $rep_unacc_bad
MISSING without surviving source binlog evidence       : $unknown_missing
source evidence not in executed (inconsistent)         : $src_extra
replica evidence not in executed (inconsistent)        : $rep_extra

UNKNOWN (cannot prove absent / cannot prove replayable): $unknown_all
============================================================

EOF

    # Hard inconsistencies: evidence claims a transaction was persisted but
    # the server says it was never executed.  Never guess here.
    if [[ -n $src_extra || -n $rep_extra ]]; then
        die 4 "binary log evidence contradicts gtid_executed (extra: ${src_extra:-none} / ${rep_extra:-none})"
    fi

    # Unaccounted source transactions: the executed set is not fully
    # reconstructible.  That is exactly a gap that cannot be proven empty.
    if [[ -n $src_unacc ]]; then
        if (( STRICT_UNACCOUNTED == 1 )); then
            die 2 "source executed GTIDs lack any evidence (gap cannot be proven empty): $src_unacc"
        fi
        warn "source executed GTIDs lack local evidence (tolerated): $src_unacc"
    fi
    if [[ -n $rep_unacc_bad ]]; then
        if (( STRICT_UNACCOUNTED == 1 )); then
            die 2 "replica executed GTIDs lack any evidence and are not explained by source: $rep_unacc_bad"
        fi
        warn "replica executed GTIDs lack any evidence (tolerated): $rep_unacc_bad"
    fi

    # Required transactions that cannot be replayed from anything we can prove.
    if [[ -n $unknown_missing ]]; then
        die 2 "MISSING transactions have no surviving replay evidence (gap cannot be proven empty): $unknown_missing"
    fi

    # --- replay plan ---------------------------------------------------------
    local replay="$missing"

    # Final errant-exclusion proof.  By construction replay ⊆ E_s and
    # errant = E_r \ E_s, so this must always hold; assert it anyway.
    local errant_in_replay
    errant_in_replay=$(gtid_op inter "$replay" "$errant")
    if [[ -n $errant_in_replay ]]; then
        die 4 "refusing to plan: errant transactions leaked into replay set: $errant_in_replay"
    fi
    # Nothing already applied may be replayed (idempotency proof).
    local already
    already=$(gtid_op inter "$replay" "$E_r")
    [[ -z $already ]] || die 4 "refusing to plan: replay set overlaps replica executed set: $already"

    if [[ -z $replay ]]; then
        info "no missing transactions: replica already has every source transaction"
        info "errant transactions (left in place, never replayed): ${errant:-none}"
        exit 0
    fi

    local n_replay
    n_replay=$(gtid_op card "$replay")

    # Build the mysqlbinlog command that reads ONLY the proven-missing GTIDs.
    # A positive allow-list (--include-gtids) is used deliberately: even if the
    # set arithmetic were wrong, the filter cannot emit an errant transaction,
    # because errant ∉ replay.
    local -a src_files=() reader=( "${SRC_BINLOG[@]}" )
    local p
    while IFS= read -r p; do [[ -n $p ]] && src_files+=( "$p" ); done < <(binlog_paths source)

    # Quoted commands + files for the printed plan.  The arrays already
    # contain the executable name, so they are used verbatim.
    local reader_str="" f
    for f in "${reader[@]}"; do reader_str+=" ${f@Q}"; done; reader_str=${reader_str# }
    local files_str=""
    for f in "${src_files[@]}"; do files_str+=" ${f@Q}"; done
    local rep_mysql_str="" x
    for x in "${REP_MYSQL[@]}"; do rep_mysql_str+=" ${x@Q}"; done; rep_mysql_str=${rep_mysql_str# }

    # Defensive second guard: the positive allow-list already excludes errant
    # GTIDs; also exclude them explicitly when there are any.
    local exclude_flag=""
    [[ -n $errant ]] && exclude_flag=" --exclude-gtids=${errant@Q}"

    local plan_cmd="$reader_str --include-gtids=${replay@Q}${exclude_flag}${files_str} | $rep_mysql_str"

    cat <<EOF
================ SAFE REPLAY PLAN ================
transactions to append : $n_replay
replay set             : $replay
errant transactions    : ${errant:-none}   <-- never in the replay set

Invariants verified:
  replay ∩ errant              = ∅
  replay ∩ replica.gtid_executed = ∅
  replay ⊆ source.gtid_executed
  every replay GTID has surviving source binlog evidence

Apply command (review before running):
  $plan_cmd

NOTE: errant transactions are intentionally left in place.  If this replica is
later promoted and used as a source, run this tool with the roles swapped and
the errant set will be reported again; never feed it into a replay allow-list.
==================================================
EOF

    if (( APPLY == 1 )); then
        info "applying replay plan ..."
        # Re-read replica executed set immediately before applying so a
        # concurrent or repeated run only appends what is still missing.
        local E_r2 still
        E_r2=$(gtid_var replica gtid_executed)
        E_r2=$(gtid_op normalize "$E_r2")
        still=$(gtid_op sub "$replay" "$E_r2")
        if [[ -z $still ]]; then
            info "nothing left to apply (replica advanced concurrently)"
            exit 0
        fi
        local -a apply_args=( "${reader[@]}" --include-gtids="$still" )
        [[ -n $errant ]] && apply_args+=( --exclude-gtids="$errant" )
        apply_args+=( "${src_files[@]}" )
        "${apply_args[@]}" | "${REP_MYSQL[@]}" 2>&1 || die 3 "apply failed"
        # Recompute and prove the replica now covers the source.
        local E_r3
        E_r3=$(gtid_var replica gtid_executed); E_r3=$(gtid_op normalize "$E_r3")
        local remaining; remaining=$(gtid_op sub "$E_s" "$E_r3")
        if [[ -n $remaining ]]; then
            die 2 "apply finished but transactions are still missing: $remaining"
        fi
        info "apply complete; replica now contains all source transactions"
    else
        info "dry run: plan printed, nothing executed (pass --apply to run)"
    fi
}

bad_set() { die 4 "$*"; }

main "$@"

2.1 Typical invocation (remote, live servers)

./gtid_reconcile.sh \
  --source-host=old-primary  --source-user=repl --source-password=... \
  --replica-host=new-primary --replica-user=repl --replica-password=...

2.2 Offline copies / archived binlogs

When the surviving files live on disk, point the tool at the directories. All *.0* files are scanned so archived copies that MySQL already purged still count as evidence; relay logs are deliberately excluded because they hold not-yet-executed transactions:

./gtid_reconcile.sh \
  --source-defaults-file=/etc/my.src.cnf \
  --replica-defaults-file=/etc/my.rep.cnf \
  --source-binlog-dir=/backup/old-primary/binlogs \
  --replica-binlog-dir=/backup/new-primary/binlogs

2.3 Supplying external evidence for an otherwise-unprovable gap

./gtid_reconcile.sh ... --extra-evidence=/backup/gtid-from-archive.txt

2.4 Applying

Without --apply the plan is printed only (dry run). With --apply the script re-reads gtid_executed first and replays only what is still missing, which is what makes it idempotent.

./gtid_reconcile.sh ... --apply

Exit codes: 0 success, 2 unprovable/unknown gap, 3 evidence collection failure, 4 inconsistent evidence, 5 usage error.

2.5 Why the plan cannot re-apply an errant transaction

  • replay = missing = E_s \ E_r, and errant = E_r \ E_s, disjoint by construction; the script re-asserts replay ∩ errant = ∅.
  • The replay uses --include-gtids=<replay> (allow-list), never a negative filter alone, and adds --exclude-gtids=<errant> when errant is non-empty.
  • Before planning it also proves replay ∩ E_r = ∅ and replay ⊆ E_s.
  • Errant transactions are left in place and reported; if the replica is later promoted, re-run the tool with the roles swapped.

3.4 Verifying against a real MySQL pair

On a disposable copy, plant the broken state on purpose and confirm the tool's classification before trusting it:

-- source (S)
SET GLOBAL gtid_purged = '<S executed minus tail>';   -- pretend tail was purged
-- replica (R): apply a local transaction that S never saw (errant)
SET @@SESSION.GTID_NEXT = 'aaaaaaaa-aaaa-aaaa-aaaa-aaaaaaaaaaaa:<future>';
INSERT INTO t VALUES (...);   -- errant

Then run the tool and check:

  1. the ERRANT line contains the local transaction's UUID/range;
  2. the replay set and the printed --include-gtids= value contain neither that UUID nor anything already in E_r;
  3. a purged-and-needed range makes the tool exit 2 and name the range;
  4. mysqlbinlog --include-gtids=<replay> on the source emits only the missing transactions.

Because the replay is expressed with explicit GTIDs, re-running it is a no-op on a server that already applied them, and the script's pre-apply re-read guarantees it never re-sends a transaction that has since been applied.
