RFC 9002 QUIC loss recovery: diagnosis and verified fix

Root-cause analysis

The bug class is caused by mixing per-space recovery state and by letting packet status change implicitly. The important failure modes are:

  1. Shared packet-number-space state. Initial, Handshake, and Application need independent sent, history, ackRanges, largestAcked, lossTime, and ptoCount. Sharing them makes ACK ranges and PTOs cross spaces.

  2. Double-counting packets that are both in-flight and lost. Loss detection must remove bytes from bytes_in_flight exactly once. PTO arming must then use only packets still marked inflight; it must not use a stale “last ack-eliciting” timestamp that includes a packet just declared lost or ACKed.

  3. Incorrect ACK-range decoding. RFC 9000 gaps are relative:

  4. new_hi = previous_lo - gap - 2
  5. new_lo = new_hi - length

ECN counters are cumulative and must never decrease on reordered/duplicate ACKs.

  1. Incorrect delay rules. max_ack_delay is zero for Initial/Handshake and for Application before handshake confirmation. PTO is: smoothed_rtt + max(4*rttvar, granularity) + max_ack_delay, multiplied by 2^pto_count.

  2. Persistent congestion vs. spurious loss. Persistent congestion requires a contiguous all-lost run whose send-time span exceeds three unbacked-off PTOs. A late ACK of a “lost” packet is a spurious loss: restore the pre-loss cwnd, and mark the whole loss event reverted so it cannot re-enter persistent congestion.

The critical invariants are:

// Packets are explicitly inflight, lost, or acked.
// Lost packets are removed from sent, so PTO only scans what remains.
_lastAckElicitingInFlight(space) {
  let last = null;
  for (const rec of space.sent.values()) {
    if (rec.status === 'inflight' && rec.ackEliciting) {
      if (last == null || rec.timeSent > last) last = rec.timeSent;
    }
  }
  return last;
}

// Persistent congestion: contiguous all-lost run, no spurious-reverted event.
if (candidate.some((r) => r.lossEvent && r.lossEvent.reverted)) continue;
if (last.timeSent - first.timeSent <= duration) continue;

this.cwnd = 2 * this.maxDatagramSize;
this.ssthresh = this.cwnd;
this.congestionAvoidanceEpoch = now;
this.recoveryStartTime = now;

// A late ACK restores the loss-event snapshot and prevents re-entry.
this.cwnd = Math.max(this.cwnd, event.previousCwnd);
this.ssthresh = event.previousSsthresh;
this.recoveryStartTime = event.previousRecoveryStartTime;
this.congestionAvoidanceEpoch = event.previousCongestionAvoidanceEpoch;
this.persistentCongestion = false;
event.reverted = true;
