Diagnosis

The failure class is the lower-bound half of triangle-inequality smoothing. The correct metric rules are asymmetric:

U_ij = min(U_ij, U_ik + U_kj)                  # shortest paths
L_ij = max(L_ij, L_ik - U_kj, L_kj - U_ik)     # subtract the UPPER bound

The bugs that reproduce this class:

  1. Wrong operand — using L_kj/U_kj on the right side instead of the upper bound; under-tightens and hides infeasibilities.
  2. Wrong order — relaxing L before U has converged.
  3. Vectorised broadcasting bug (the one actually caught by the verifier): writing Us[:, None, :] instead of Us[:, :, None], which drops the k index and relaxes against U_ij.
  4. Non-determinism — unsorted/duplicate restraints, eigenvector sign ambiguity, single-embedding local minima.

The fix:

# upper bounds: all-pairs shortest paths (do this FIRST)
for k in range(n):
    np.minimum(Us, Us[:, k, None] + Us[None, k, :], out=Us)

# lower bounds against the FINALISED upper bounds
for _ in range(n + 1):
    cand1 = Ls[:, :, None] - Us[None, :, :]   # L_ik - U_kj -> [i,k,j]
    best  = cand1.max(axis=1)
    cand2 = Ls[None, :, :] - Us[:, :, None]   # L_kj - U_ik -> [i,k,j]
    best  = np.maximum(best, cand2.max(axis=1))
    new = np.maximum(Ls, best)
    if np.allclose(new, Ls, atol=1e-12): break
    Ls = new

Inconsistency is then simply L_ij > U_ij; determinism comes from sorting/deduping restraints, canonicalising MDS eigenvector signs, and trying a fixed ordered list of trial-distance fractions.
