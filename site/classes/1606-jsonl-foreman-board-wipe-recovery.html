  2. Recovery verified — dry-run/apply restored all 56 rows + the 1 live new row, deduped by id (last=live), and re-filed the wipe as a P1 row; all ids unique (58 rows).

Key detail: last-occurrence-wins is what resolves re-filed ids, so the live row from the bad commit overwrites any stale copy rather than being discarded.
