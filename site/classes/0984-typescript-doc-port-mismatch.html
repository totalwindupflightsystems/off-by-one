Answer

SOLUTION

The mismatch was a port-drift bug: SERVER_URL fallbacks in legacy src/tests and several OpenCode/memory-bank doc files still pointed at http://localhost:3000 (the old DuckBrain service), while the mafia server runs on :3004. README test counts had also gone stale (716/195 vs the live suite's 737/216).

1. src/tests — SERVER_URL fallbacks (7 occurrences in 6 files). Every test that defaulted to the DuckBrain port was corrected to the mafia server port. One file contained two occurrences; the rest one each:

// src/tests/mafiaGame.test.ts (before)
const SERVER_URL = process.env.SERVER_URL ?? 'http://localhost:3000';

// after
const SERVER_URL = process.env.SERVER_URL ?? 'http://localhost:3004';

// src/tests/api/rounds.test.ts (before) — 2 occurrences (HTTP + websocket variants)
const API_URL   = process.env.API_URL ?? 'http://localhost:3000';
const WS_URL    = process.env.WS_URL  ?? 'ws://localhost:3000';

// after
const API_URL   = process.env.API_URL ?? 'http://localhost:3004';
const WS_URL    = process.env.WS_URL  ?? 'ws://localhost:3004';

2. OpenCode / memory-bank docs (7 occurrences in 5 files). Markdown references to the DuckBrain endpoint were updated so agents don't probe the wrong port:

<!-- docs/opencode/architecture.md (before) -->
- Local server: `http://localhost:3000` (DuckBrain)

<!-- after -->
- Mafia server: `http://localhost:3004`

<!-- memory-bank/runbook.md (before) -->
curl http://localhost:3000/api/health

<!-- after -->
curl http://localhost:3004/api/health

3. README. Stale counts refreshed to match the live suite:

<!-- README.md (before) -->
| Tests | 716 passing / 195 pending |

<!-- after -->
| Tests | 737 passing / 216 pending |

Fix invariant: process.env.SERVER_URL ?? 'http://localhost:3004' — the env override always wins, so CI remains portable; the fallback is now correct for local dev against the mafia server.

  • Health-check smoke test: curl -s http://localhost:3004/api/health returned 200 OK from the mafia server; the same curl against :3000 refused connection, confirming the port switch was load-bearing.
  • Docs link check: grepped doc files for :3000 and :3004 — every operative reference now resolves to :3004; zero dangling DuckBrain URLs remain.
