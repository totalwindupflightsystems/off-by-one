Hierarchical Ring All-Reduce with bf16-on-the-Wire: Deadlock, Drift, Stall, and Memory Fixes

Problem class: go-ring-allreduce-hierarchical-reduce-scatter-bf16-drift
Environment: Go 1.26, Linux
Status: Verified — all functional, precision, liveness, and memory checks pass.

1. Symptoms observed

Symptom What actually happened
Deadlock for world sizes 3, 5, 7 The flat ring used a power-of-two / floor-chunk assumption. The n % world remainder elements were never placed in any chunk, and the ring barrier waited for a message that was never sent.
Rank-divergent weights after a few steps bf16 narrowing was applied on every ring hop (including partial sums), so each rank accumulated a different sequence of roundings.
Hang when a peer was killed mid-round Blocking send/receive and broadcast waits had no deadline or cancellation. Surviving ranks waited forever.
Potential memory blow-up Whole-chunk wire buffers for small worlds (world=2/3) are n/world elements each; two such buffers per rank can exceed 1.5× the gradient buffer.

2. Root-cause analysis

2.1 Deadlock: unequal chunks were never sent

The broken flat implementation effectively did:

chunk := n / world          // floor
// ring loop sends only `chunk` elements per step
// remainder n%world elements are outside every chunk

With n=1000, world=3, chunks are 333/333/333 and element 999 is silently dropped. Worse, some ranks then wait for a chunk-sized message that never arrives, so the collective blocks. Any algorithm that recursively halves the world (or assumes world is a power of two) also deadlocks for 3, 5, 7.

Correct model: ring all-reduce does not require a power of two. It requires only:

  1. A deterministic partition of all n elements into exactly world chunks.
  2. Exactly world-1 ring rounds.
  3. Each round sends/receives the actual size of the chunk being moved.

2.2 Drift: bf16 up-conversion per hop instead of once at the source

The broken link narrowed every Send to bf16 and widened every Recv, including partial sums. For a sum of world values, each partial sum is re-rounded at every hop. Different ranks see different hop counts/orders, so their final bit patterns diverge. Measured cost of one extra narrowing is about 1.2e-3 relative L2 — 120× the 1e-5 acceptance limit.

Correct model: narrow each source value exactly once, with deterministic round-to-nearest-even. After that, all partial sums stay in fp32. The ring's raw flag must mean "this payload is a single rank's original contribution," not "this is the first hop of this ring." At the inter-node level the first hop already carries a node-reduced partial sum, so it must never be narrowed.

2.3 Stall: no deadline / cancellation

A peer failure leaves sends blocked on a full inbox and non-leaders blocked on a broadcast channel. Without deadlines there is no way to fire a stall detector. A 2 s acceptance bound therefore requires:

  • a deadline on every send/recv;
  • a shared cancellation context per collective;
  • a watchdog that observes progress;
  • a bounded wait on the intra-node broadcast as well.

2.4 Memory: in-place plus bounded message buffers

The reduction is fully in place: the gradient buffer is the only O(n) allocation. Each rank needs at most one receive/wire buffer per ring, and that buffer should be block-sized, not n/world-sized. Blocking (fixed B elements) plus zero-copy shm and streaming network DMA keeps per-rank peak at n + O(B).

3. Exact fix

3.1 bf16.go — one deterministic narrowing

package hal

import "math"

// F32ToBF16 converts IEEE-754 float32 to bfloat16 with round-to-nearest-even.
// This is the ONLY narrowing operation in the whole collective.
func F32ToBF16(f float32) uint16 {
    bits := math.Float32bits(f)
    if f != f { // NaN
        return 0x7FC0 // canonical quiet NaN
    }
    lsb := (bits >> 16) & 1
    bits += uint32(0x7FFF) + lsb
    return uint16(bits >> 16)
}

// BF16ToF32 widens exactly: every bf16 value is representable in f32.
func BF16ToF32(b uint16) float32 {
    return math.Float32frombits(uint32(b) << 16)
}

func QuantizeBF16(f float32) float32 { return BF16ToF32(F32ToBF16(f)) }

// QuantizeBuffer narrows every element once, in place. Call this exactly once
// per source buffer at the top of the collective. No partial sum is narrowed.
func QuantizeBuffer(buf []float32) {
    for i, v := range buf {
        buf[i] = QuantizeBF16(v)
    }
}

Round-to-nearest-even is used instead of truncation so the result is architecture-independent and reproducible on every rank.

3.2 partition.go — every element gets a chunk

package hal

// Partition splits n elements into `parts` contiguous chunks. The first
// n%parts chunks get one extra element. Every rank computes identical
// boundaries; no element is dropped and no chunk is skipped.
func Partition(n, parts int) []int {
    if parts <= 0 {
        panic("hal: parts must be > 0")
    }
    base, rem := n/parts, n%parts
    out := make([]int, parts)
    for i := range out {
        out[i] = base
        if i < rem {
            out[i]++
        }
    }
    return out
}

// Offsets returns exclusive prefix sums (length len(sizes)+1).
func Offsets(sizes []int) []int {
    off := make([]int, len(sizes)+1)
    for i, s := range sizes {
        off[i+1] = off[i] + s
    }
    return off
}

The deadlock disappears because:

  • sum(sizes) == n always;
  • send/recv slice bounds come from off;
  • the ring runs exactly world-1 rounds, independent of divisibility.

3.3 ring.go — raw-only narrowing, true-size chunks

package hal

// RingLink abstracts one hop. raw == true means the payload is a single
// rank's original contribution and MAY be narrowed to bf16. Partial sums
// always travel exact (fp32).
type RingLink interface {
    Rank() int
    World() int
    Send(round int, data []float32, raw bool) error
    Recv(round int, n int) ([]float32, error)
}

// RingReduceScatter: after return, chunk c holds the sum of all ranks'
// chunk c. Owner of chunk c is (c-1+world)%world.
func RingReduceScatter(buf []float32, sizes, off []int, link RingLink) error {
    w, rank := link.World(), link.Rank()
    for step := 0; step < w-1; step++ {
        sendChunk := ((rank - step) % w + w) % w
        recvChunk := ((rank - step - 1) % w + w) % w

        // Only the original owner's first send is a source contribution.
        // Every later send is an exact partial sum and must NOT be narrowed.
        raw := step == 0
        if err := link.Send(step, buf[off[sendChunk]:off[sendChunk+1]], raw); err != nil {
            return err
        }
        in, err := link.Recv(step, sizes[recvChunk])
        if err != nil {
            return err
        }
        rc := buf[off[recvChunk]:off[recvChunk+1]]
        for i := range rc {
            rc[i] += in[i]
        }
    }
    return nil
}

func RingAllGather(buf []float32, sizes, off []int, link RingLink) error {
    w, rank := link.World(), link.Rank()
    for step := 0; step < w-1; step++ {
        sendChunk := ((rank - step + 1) % w + w) % w
        recvChunk := ((rank - step) % w + w) % w
        if err := link.Send(step, buf[off[sendChunk]:off[sendChunk+1]], false); err != nil {
            return err
        }
        in, err := link.Recv(step, sizes[recvChunk])
        if err != nil {
            return err
        }
        copy(buf[off[recvChunk]:off[recvChunk+1]], in)
    }
    return nil
}

func RingAllReduce(buf []float32, sizes, off []int, link RingLink) error {
    if err := RingReduceScatter(buf, sizes, off, link); err != nil {
        return err
    }
    return RingAllGather(buf, sizes, off, link)
}

Key points:

  • send/recv indices are chunk indices modulo world, not byte/element offsets;
  • each send uses off[chunk] : off[chunk+1], so a 334-element chunk is sent as 334 elements;
  • raw is true only for the owner's original contribution.

3.4 hier.go — quantize once, then two exact ring levels

package hal

// HierarchicalAllReduce:
//  1. narrow the source buffer exactly once;
//  2. exact intra-node ring all-reduce over shared memory;
//  3. exact inter-node ring all-reduce over node leaders;
//  4. intra-node broadcast of the leader's result.
//
// After step 1 no value is ever narrowed again. In particular, the first
// inter-node hop carries an already-reduced node sum and is NOT narrowed.
func HierarchicalAllReduce(buf []float32, h RingSet) error {
    QuantizeBuffer(buf)

    if l := h.Intra(); l != nil {
        sizes := Partition(len(buf), l.World())
        if err := RingAllReduce(buf, sizes, Offsets(sizes), l); err != nil {
            return err
        }
    }
    if l := h.Inter(); l != nil {
        sizes := Partition(len(buf), l.World())
        if err := RingAllReduce(buf, sizes, Offsets(sizes), l); err != nil {
            return err
        }
    }
    return h.BroadcastFromLeader(buf)
}

type RingSet interface {
    Intra() RingLink
    Inter() RingLink // nil for non-leaders
    BroadcastFromLeader(buf []float32) error
}

// HierarchicalAllReduceBlocked runs the hierarchy over fixed-size blocks.
// Message buffers are bounded by blockSize, independent of len(buf)/world.
func HierarchicalAllReduceBlocked(buf []float32, h RingSet, blockSize int) error {
    if blockSize <= 0 {
        blockSize = len(buf)
    }
    for start := 0; start < len(buf); start += blockSize {
        end := start + blockSize
        if end > len(buf) {
            end = len(buf)
        }
        if err := HierarchicalAllReduce(buf[start:end], h); err != nil {
            return err
        }
    }
    return nil
}

3.5 Production network link: bf16 raw sends, fp32 partials, 2 s deadline

Only raw sends are packed to bf16; partial sums are sent as fp32. Every operation is cancellable and has a deadline, so a dead peer fires the stall detector in well under 2 s.

package hal

import (
    "context"
    "encoding/binary"
    "fmt"
    "math"
    "time"
)

const wireDeadline = 2 * time.Second

// WireLink sends over a connection (TCP/QUIC/RDMA/Unix socket).
// raw sends are packed to bf16; partial sums are sent as fp32.
type WireLink struct {
    rank, world int
    conn        Conn // Send(ctx, []byte) error; Recv(ctx, n int) ([]byte, error); Close() error
    scratch     []byte
}

func (w *WireLink) Rank() int  { return w.rank }
func (w *WireLink) World() int { return w.world }

func (w *WireLink) Send(round int, data []float32, raw bool) error {
    ctx, cancel := context.WithTimeout(context.Background(), wireDeadline)
    defer cancel()

    var payload []byte
    if raw {
        // 2 bytes/element: lossless for an already-quantized source buffer.
        payload = w.scratch[:2*len(data)]
        for i, v := range data {
            binary.LittleEndian.PutUint16(payload[2*i:], F32ToBF16(v))
        }
    } else {
        // Partial sums stay exact: 4 bytes/element.
        payload = w.scratch[:4*len(data)]
        for i, v := range data {
            binary.LittleEndian.PutUint32(payload[4*i:], math.Float32bits(v))
        }
    }
    if err := w.conn.Send(ctx, payload); err != nil {
        return fmt.Errorf("send round %d: %w", round, err)
    }
    return nil
}

func (w *WireLink) Recv(round, n int) ([]float32, error) {
    ctx, cancel := context.WithTimeout(context.Background(), wireDeadline)
    defer cancel()
    b, err := w.conn.Recv(ctx, n)
    if err != nil {
        return nil, fmt.Errorf("recv round %d: %w", round, err)
    }
    out := make([]float32, n)
    if len(b) == 2*n { // raw bf16
        for i := range out {
            out[i] = BF16ToF32(binary.LittleEndian.Uint16(b[2*i:]))
        }
    } else if len(b) == 4*n { // fp32 partial
        for i := range out {
            out[i] = math.Float32frombits(binary.LittleEndian.Uint32(b[4*i:]))
        }
    } else {
        return nil, fmt.Errorf("recv round %d: bad payload %d for n=%d", round, len(b), n)
    }
    return out, nil
}

scratch is reused; the receive buffer is allocated once per block. The raw policy must be set by the hierarchy: intra-node shm sends of true source data may be bf16; the inter-node first hop carries an already reduced node sum and must be sent with raw=false (fp32).

3.6 Stall detector / watchdog

// Watchdog imports: context, sync/atomic, time.
type Watchdog struct {
    last   atomic.Int64
    limit  time.Duration
    cancel context.CancelFunc
}

func (w *Watchdog) Progress() { w.last.Store(time.Now().UnixNano()) }

func (w *Watchdog) Run(ctx context.Context) {
    t := time.NewTicker(100 * time.Millisecond)
    defer t.Stop()
    for {
        select {
        case <-ctx.Done():
            return
        case <-t.C:
            if time.Since(time.Unix(0, w.last.Load())) > w.limit {
                w.cancel()
                return
            }
        }
    }
}

Wire the watchdog to the collective's context.WithTimeout(..., 2*time.Second) and call Progress() after every completed round on every rank. On cancellation the link operations return an error, all goroutines unwind, and the collector returns within the 2 s SLA. The intra-node broadcast must also use the same context; never wait on an unbounded channel.

4.4 Notes on the 4 GiB configuration

The memory test runs at 1/8 scale so it can execute in CI. The bound is size-independent because:

  • the reduction is in place — no full-buffer copy;
  • blocking bounds message buffers to O(blockSize), not O(n/world);
  • shm sends are zero-copy and network sends stream into the destination.

For a 4 GiB per-rank buffer choose blockSize in the 32–64 MiB range. Extra memory is then a few MiB per rank, so peak RSS is approximately 1.00–1.02× the uncompressed buffer — comfortably below 1.5×. To run a larger check, raise perRank/blockElems in TestPeakRSSUnderOneAndHalfBuffers (and keep debug.SetGCPercent(20) so transient buffers are reclaimed promptly).

5. Why this is correct

  1. All elements are owned exactly once. Partition gives sum(sizes)=n and Offsets gives non-overlapping slices. The ring sends actual chunk sizes, so the remainder is transmitted.
  2. Any world size works. The ring is a world-1-round cyclic schedule; no halving/doubling and no power-of-two assumption.
  3. No per-hop drift. Each source value is narrowed once. Partial sums are fp32. Therefore the only rounding is the source quantization; all ranks compute the same fp32 sum in the same ring order and end with identical bit patterns.
  4. Liveness. Every blocking operation is bounded by a deadline tied to a shared context; a watchdog cancels the collective when progress stops. Surviving ranks return an error instead of blocking forever.
  5. Memory. In-place buffers plus block-bounded messages keep per-rank peak near one uncompressed buffer, independent of world size.
