SCCP: Phi-Safe Unreachable-Edge Lattice Fixpoint

Verified, self-contained solution: ~/solution.md (full code + tests embedded), with runnable sources in ~/sccp/.

Root-cause analysis

SCCP fails in two coupled ways at the phi/edge boundary:

  1. Phi poisoning. A phi is a meet over executable predecessors only. If you meet over all syntactic operands, a constant reaching the merge only through a never-taken branch gets counted and turns a constant merge into overdefined.

  2. Oscillation when the predecessor set shrinks. A tempting fix is to optimistically mark both edges while the branch condition is undefined, then retract the untaken edge when the condition resolves. Retraction lets a lattice cell move down; if the condition later widens to overdefined (typical with loop-carried operands) the edge returns and the cell moves back up. The worklist can cycle shrink→fall→refold→rise forever.

  3. Unsound loop folding. A loop-carried value can look constant before the back edge is explored. With a runtime trip count it must be overdefined.

One-sentence cause: the executable-edge set and every lattice cell must be monotone. Don't emit edges early and later retract them — defer branch propagation while the condition is undefined.

The fix

Branch rule (the heart of it):

condition cell edges emitted
undefined none — defer
const c only the taken edge
overdefined both edges

Phi meets only operands whose incoming edge is in exec; edges are only ever added; set asserts every cell only moves up (lattice height 3 ⇒ termination, no oscillation). Replacements/rewiring happen only after the fixpoint, so runtime loops can't be prematurely folded.

Core code (full file at ~/sccp/sccp.go, lines shown from the verified source):

func (s *solver) meetPhi(phi *Value) cell {
    res := cell{tag: Undefined}
    have := false
    for i, arg := range phi.Args {
        if !s.exec[phi.Block.Preds[i]] {   // only executable predecessors
            continue
        }
        c := s.get(arg)
        if c.tag == Undefined {
            continue
        }
        if !have {
            res, have = c, true
        } else {
            res = meet(res, c)
        }
    }
    return res
}

func (s *solver) propagate(b *Block) {
    switch b.Kind {
    case BlockExit:
        return
    case BlockEntry, BlockPlain:
        if len(b.Succs) > 0 {
            s.pushEdge(Edge{From: b, Idx: 0})
        }
    case BlockIf:
        c := s.get(b.Cond)
        switch c.tag {
        case Undefined:
            return // defer: do NOT optimistically mark both edges
        case Const:
            idx := 1
            if c.val != 0 {
                idx = 0
            }
            s.pushEdge(Edge{From: b, Idx: idx})
        default: // Overdefined
            s.pushEdge(Edge{From: b, Idx: 0})
            s.pushEdge(Edge{From: b, Idx: 1})
        }
    default:
        panic("sccp: unknown block kind")
    }
}

func (s *solver) set(v *Value, nc cell) {
    if !possibleConst(v) {
        return
    }
    oldp := s.lat[v]
    if oldp == nil {
        oldp = &cell{tag: Undefined}
        s.lat[v] = oldp
    }
    old := *oldp
    if old.tag == nc.tag && (old.tag != Const || old.val == nc.val) {
        return
    }
    if old.tag > nc.tag { // the invariant that forbids oscillation
        panic(fmt.Sprintf("sccp: lattice decreased %v -> %v", old, nc))
    }
    if old.tag == Const && nc.tag == Const && old.val != nc.val {
        panic("sccp: constant changed its value")
    }
    *oldp = nc
    for _, u := range s.uses[v] {
        s.addValWL(u)
    }
    for _, b := range s.ctrl[v] {
        s.propagate(b)
    }
}

Loop soundness comes from overdefined conditions emitting both edges (so the back edge widens the phi) plus post-fixpoint replacement.
