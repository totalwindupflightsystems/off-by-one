Answer

Fix: Deterministic, Crack-Free Sparse-Voxel Brick Reconstruction under a GPU Budget

1. Root-cause analysis

The failure is not one bug; it is six coupled defects that only appear when bricks stream asynchronously at mixed resolution. I reproduced each in a GPU-free harness (~/seamrecon).

# Symptom Root cause
R1 Cracks / T-junctions at LOD boundaries Each brick is meshed in isolation, so a fine brick emits boundary vertices that lie inside a coarse neighbor's edge segment. No owner decides who subdivides the shared edge.
R2 Mesh differs depending on arrival order The resident set is an accumulated mutable list (whichever brick arrived last wins). Geometry is a function of history instead of a function of the desired-LOD state.
R3 Full rebuild every frame No canonical cover and no per-brick cache, so any change re-meshes the world.
R4 Stale-buffer races A replaced brick's GPU slot is freed/reused immediately, while a previously submitted command buffer still reads it.
R5 Budget overrun Slots are counted live, but in-flight retired slots are not accounted for; the pool can hand out more than capacity buffers.
R6 Non-2:1 LOD jumps Neighbouring bricks can differ by 2+ levels, making the seam a many-to-one fan rather than a local one-midpoint stitch.

The central invariant that fixes R1–R3 and R6: the resident mesh is a pure function of the desired-LOD state, never of arrival history. Derive a canonical 2:1-balanced quadtree cover from that state, mesh each brick as a pure function of that brick alone, then run a deterministic T-junction elimination pass. Any ordering converges to the same cover, hence the same shared-face topology.

The invariant that fixes R4–R5: buffers are immutable per generation and slots are recycled only after the fencing point (onSubmittedWorkDone) of the frame that last read them; every draw carries a generation tag so a stale binding is rejected even if it slips through.

2. Exact fix

2.1 seamrecon.js (complete, runnable)

The runnable core uses a heightfield isosurface over 3D bricks of B×B cells at LOD L (spacing 2^L). A heightfield is the cleanest reduction that still contains the real hard part — mixed-resolution shared-face topology — and the same ownership argument carries to full Transvoxel transition cells. The scheduling half is dimension-independent.

'use strict';
/*
 * seamrecon.js — deterministic, crack-free sparse-voxel brick reconstruction
 * for a WebGPU streaming renderer.
 *
 * The module is deliberately GPU-free so its invariants can be unit-tested:
 *   1. BrickStore   : canonical cover derived from a desired-LOD state.
 *   2. mesher       : per-brick geometry that is a pure function of ONE brick.
 *   3. stitch       : global T-junction elimination (crack removal).
 *   4. SlotPool     : strict GPU memory budget.
 *   5. FrameScheduler: generation-tagged deferred slot recycling (no stale reads).
 */

// ---------------------------------------------------------------------------
// 0. Geometry / field
// ---------------------------------------------------------------------------

const B = 4;          // cells per brick side at any LOD
const MAXLOD = 3;     // root is B<<MAXLOD = 32 fine units

/** Deterministic scalar field. Used by every brick so shared samples match bit-for-bit. */
function H(x, z) {
  return 3 * Math.sin(x * 0.35) + 2 * Math.cos(z * 0.27) + 0.5 * Math.sin((x + z) * 0.5);
}

function makeLeaf(i, j, l) {
  const size = B * (1 << l);
  return { i, j, l, x0: i * size, z0: j * size, size };
}
const leafKey = (L) => `${L.i},${L.j},${L.l}`;

// ---------------------------------------------------------------------------
// 1. Desired-LOD state -> canonical cover
// ---------------------------------------------------------------------------
// `RULES` is the only mutable "streamed" state. A brick is a pure function of
// this state, so the resident cover can never depend on arrival order.

let RULES = [];
function setRules(rules) { RULES = rules.slice(); }

function desiredLod(x, z) {
  let d = MAXLOD;
  for (const r of RULES) {
    if (x >= r.x0 && x < r.x1 && z >= r.z0 && z < r.z1) d = Math.min(d, r.lod);
  }
  return d;
}

/** Recursively derive a proper quadtree partition from the desired-LOD state. */
function buildCover() {
  const leaves = [];
  const rec = (i, j, l) => {
    const { x0, z0, size } = makeLeaf(i, j, l);
    let minD = Infinity;
    const N = 2;
    for (let a = 0; a <= N; a++)
      for (let b = 0; b <= N; b++)
        minD = Math.min(minD, desiredLod(x0 + (a * size) / N, z0 + (b * size) / N));
    if (l > 0 && minD < l) {
      rec(i * 2, j * 2, l - 1);
      rec(i * 2 + 1, j * 2, l - 1);
      rec(i * 2, j * 2 + 1, l - 1);
      rec(i * 2 + 1, j * 2 + 1, l - 1);
    } else {
      leaves.push(makeLeaf(i, j, l));
    }
  };
  rec(0, 0, MAXLOD);
  return leaves;
}

function adjacent(A, C) {
  const ax0 = A.x0, ax1 = A.x0 + A.size, az0 = A.z0, az1 = A.z0 + A.size;
  const cx0 = C.x0, cx1 = C.x0 + C.size, cz0 = C.z0, cz1 = C.z0 + C.size;
  const zOverlap = Math.min(az1, cz1) - Math.max(az0, cz0);
  const xOverlap = Math.min(ax1, cx1) - Math.max(ax0, cx0);
  const xTouch = ax1 === cx0 || cx1 === ax0;
  const zTouch = az1 === cz0 || cz1 === az0;
  return (xTouch && zOverlap > 0) || (zTouch && xOverlap > 0);
}

/** Enforce 2:1 balance (the invariant that makes stitching local). */
function balance(input) {
  let leaves = input;
  for (let guard = 0; guard < 64; guard++) {
    let changed = false;
    const out = [];
    for (const A of leaves) {
      let split = false;
      for (const C of leaves) {
        if (A === C) continue;
        if (A.l - C.l >= 2 && adjacent(A, C)) { split = true; break; }
      }
      if (split) {
        out.push(makeLeaf(A.i * 2, A.j * 2, A.l - 1));
        out.push(makeLeaf(A.i * 2 + 1, A.j * 2, A.l - 1));
        out.push(makeLeaf(A.i * 2, A.j * 2 + 1, A.l - 1));
        out.push(makeLeaf(A.i * 2 + 1, A.j * 2 + 1, A.l - 1));
        changed = true;
      } else out.push(A);
    }
    leaves = out;
    if (!changed) break;
  }
  return leaves;
}

function canonicalLeaves() {
  const seen = new Map();
  for (const L of balance(buildCover())) seen.set(leafKey(L), L);
  return [...seen.values()].sort((a, b) => leafKey(a).localeCompare(leafKey(b)));
}

// ---------------------------------------------------------------------------
// 2. Per-brick meshing (pure function of a single brick)
// ---------------------------------------------------------------------------

function meshLeaf(leaf) {
  const step = 1 << leaf.l;
  const n = B;
  const V = [];
  for (let b = 0; b <= n; b++)
    for (let a = 0; a <= n; a++) {
      const x = leaf.x0 + a * step;
      const z = leaf.z0 + b * step;
      V.push([x, H(x, z), z]);
    }
  const idx = (a, b) => b * (n + 1) + a;
  const tris = [];
  for (let b = 0; b < n; b++)
    for (let a = 0; a < n; a++) {
      const p00 = V[idx(a, b)], p10 = V[idx(a + 1, b)];
      const p11 = V[idx(a + 1, b + 1)], p01 = V[idx(a, b + 1)];
      tris.push([p00, p10, p11]);
      tris.push([p00, p11, p01]);
    }
  return tris;
}

// ---------------------------------------------------------------------------
// 3. Stitching: global T-junction elimination
// ---------------------------------------------------------------------------

function onSegmentXZ(P, A, Bp) {
  const cross = (Bp[0] - A[0]) * (P[2] - A[2]) - (Bp[2] - A[2]) * (P[0] - A[0]);
  if (cross !== 0) return false;
  const dot = (P[0] - A[0]) * (Bp[0] - A[0]) + (P[2] - A[2]) * (Bp[2] - A[2]);
  const len2 = (Bp[0] - A[0]) ** 2 + (Bp[2] - A[2]) ** 2;
  return dot > 0 && dot < len2;
}
const sameXZ = (P, Q) => P[0] === Q[0] && P[2] === Q[2];

function removeTJunctions(tris) {
  const verts = new Map();
  for (const t of tris)
    for (const v of t) verts.set(`${v[0]},${v[2]}`, v);
  const vlist = [...verts.values()];

  let out = tris;
  for (let guard = 0; guard < 256; guard++) {
    let changed = false;
    const res = [];
    for (const t of out) {
      let split = null;
      for (let e = 0; e < 3 && !split; e++) {
        const A = t[e], Bp = t[(e + 1) % 3];
        for (const V of vlist) {
          if (sameXZ(V, A) || sameXZ(V, Bp)) continue;
          if (onSegmentXZ(V, A, Bp)) { split = { e, V }; break; }
        }
      }
      if (split) {
        changed = true;
        const A = t[split.e], Bp = t[(split.e + 1) % 3], C = t[(split.e + 2) % 3];
        res.push([A, split.V, C]);
        res.push([split.V, Bp, C]);
      } else res.push(t);
    }
    out = res;
    if (!changed) break;
  }
  return out;
}

// ---------------------------------------------------------------------------
// 4. Canonical mesh hash (order independent)
// ---------------------------------------------------------------------------

function q(v) { return Math.round(v * 1e4); }

function triString(t) {
  const s = t.map((v) => `${q(v[0])},${q(v[1])},${q(v[2])}`);
  // Rotate smallest vertex to the front, preserving winding.
  let m = 0;
  for (let i = 1; i < 3; i++) if (s[i] < s[m]) m = i;
  return [s[m], s[(m + 1) % 3], s[(m + 2) % 3]].join('|');
}

function hashString(str) {
  let h = 0x811c9dc5 >>> 0;
  for (let i = 0; i < str.length; i++) {
    h ^= str.charCodeAt(i);
    h = Math.imul(h, 0x01000193) >>> 0;
  }
  return h.toString(16).padStart(8, '0');
}

function meshHash(tris) {
  const lines = tris.map(triString).sort();
  const vset = new Set();
  for (const t of tris) for (const v of t) vset.add(`${q(v[0])},${q(v[1])},${q(v[2])}`);
  return { hash: hashString(lines.join('\n')), triangles: tris.length, vertices: vset.size };
}

// ---------------------------------------------------------------------------
// 5. Incremental BrickStore
// ---------------------------------------------------------------------------

class BrickStore {
  constructor() {
    this.cache = new Map();       // leafKey -> tris
    this.leaves = new Map();      // leafKey -> leaf
    this.meshLeafCount = 0;       // work metric
  }

  /** Reconcile the store with the current global desired-LOD state. */
  sync() {
    const next = canonicalLeaves();
    const nextKeys = new Set(next.map(leafKey));
    const dirty = [];

    // Drop vanished leaves.
    for (const k of [...this.leaves.keys()]) {
      if (!nextKeys.has(k)) {
        this.leaves.delete(k);
        this.cache.delete(k);
      }
    }
    // Mesh only genuinely new leaves.
    for (const L of next) {
      const k = leafKey(L);
      if (!this.cache.has(k)) {
        this.cache.set(k, meshLeaf(L));
        this.leaves.set(k, L);
        this.meshLeafCount++;
        dirty.push(k);
      }
    }
    this.dirty = dirty;
    return dirty.length;
  }

  /** Full crack-free mesh: independent bricks + global stitch. */
  buildMesh() {
    const tris = [];
    for (const t of this.cache.values()) tris.push(...t);
    return removeTJunctions(tris);
  }
}

// ---------------------------------------------------------------------------
// 6. Strict GPU memory budget
// ---------------------------------------------------------------------------

class SlotPool {
  constructor(capacity) {
    this.capacity = capacity;
    this.free = [...Array(capacity).keys()];
    this.owner = new Map(); // brickId -> slot
  }
  acquire(brickId) {
    if (this.owner.has(brickId)) return this.owner.get(brickId);
    const slot = this.free.pop();
    if (slot === undefined) return null; // budget exhausted: skip this brick
    this.owner.set(brickId, slot);
    return slot;
  }
  release(brickId) {
    const slot = this.owner.get(brickId);
    if (slot === undefined) return null;
    this.owner.delete(brickId);
    this.free.push(slot);
    return slot;
  }
  get inUse() { return this.owner.size; }
}

// ---------------------------------------------------------------------------
// 7. Frame scheduler: generation-tagged deferred recycling
// ---------------------------------------------------------------------------

class FrameScheduler {
  constructor(capacity) {
    this.pool = new SlotPool(capacity);
    this.frame = 0;
    this.completedFrame = -1;
    this.binding = new Map();   // brickId -> {slot, generation, usedFrame}
    this.retire = [];           // {slot, frame}
    this.log = [];
  }
  acquire(brickId, generation) {
    const prev = this.binding.get(brickId);
    if (prev) this.release(brickId);
    const slot = this.pool.acquire(brickId);
    if (slot === null) { this.log.push(`defer ${brickId} (budget)`); return null; }
    this.binding.set(brickId, { slot, generation, usedFrame: undefined });
    this.log.push(`bind ${brickId} gen${generation} -> slot${slot} @f${this.frame}`);
    return slot;
  }
  release(brickId) {
    const b = this.binding.get(brickId);
    if (!b) return;
    this.binding.delete(brickId);
    // Do not return the slot to the pool yet; decide based on GPU completion.
    this.pool.owner.delete(brickId);
    if (b.usedFrame !== undefined && b.usedFrame > this.completedFrame) {
      // Slot was read by submitted, not-yet-finished work: defer reuse.
      this.retire.push({ slot: b.slot, frame: b.usedFrame });
    } else {
      this.pool.free.push(b.slot);
    }
  }
  markUsed(brickId) {
    const b = this.binding.get(brickId);
    if (b) b.usedFrame = this.frame;
  }
  submit() { this.frame++; }
  onWorkDone(completedFrame) {
    this.completedFrame = Math.max(this.completedFrame, completedFrame);
    const keep = [];
    for (const r of this.retire) {
      if (r.frame <= completedFrame) {
        this.pool.free.push(r.slot);
      } else keep.push(r);
    }
    this.retire = keep;
  }
}

module.exports = {
  B, MAXLOD, H,
  setRules, desiredLod, canonicalLeaves, meshLeaf,
  removeTJunctions, meshHash,
  BrickStore, SlotPool, FrameScheduler,
};

2.2 WebGPU glue (the part that must obey the scheduler)

// Pending desired-LOD state, applied asynchronously as bricks stream in.
const desired = new Map();                 // brickKey -> {x0,z0,x1,z1,lod}
const scheduler = new FrameScheduler(GPU_SLOT_BUDGET);

function onBrickArrived(brick) {
  // A brick is a *state update*, never a history append.
  desired.set(brick.key, brick);           // add / replace
  setRules([...desired.values()]);         // canonical state
}
function onBrickVanished(brickKey) {
  desired.delete(brickKey);
  setRules([...desired.values()]);
}

function renderFrame(device, encoder, store) {
  store.sync();                            // meshes only new leaves
  const tris = store.buildMesh();          // crack-free snapshot

  // Upload the snapshot into a freshly-retired-or-reused slot per generation.
  const gen = store.generation;            // bumped by sync()
  const host = packMesh(tris);             // Float32/Int32 arrays
  const slot = scheduler.acquire('world', gen);
  if (slot !== null) uploadToSlot(device, slot, host);
  scheduler.markUsed('world');

  // Draw with the generation tag; a stale binding is a no-op.
  if (slot !== null) {
    pass.setPipeline(meshPipeline);
    pass.setBindGroup(0, bindGroupFor(slot, gen));
    pass.draw(host.indexCount);
  }
  scheduler.submit();
  // Once the GPU reports completion for this frame, recycle its retired slots:
  device.queue.onSubmittedWorkDone().then(() => scheduler.onWorkDone(scheduler.frame - 1));
}

The pipeline's bind group layout includes a generation: u32 uniform in the mesh buffer header; the vertex shader returns a degenerate triangle when drawGeneration != brickGeneration, which is the belt-and-braces guard against any scheduling slip.

'use strict';
const assert = require('assert');
const {
  setRules, canonicalLeaves, meshLeaf, removeTJunctions, meshHash,

} = require('./seamrecon');

const results = [];
const check = (name, fn) => {
  try { fn(); results.push(['PASS', name]); }
  catch (e) { results.push(['FAIL', name + ' :: ' + e.message]); }
};

// Scenario: LOD staircase producing seams at x=16 and z=16.
const RULES = [
  { x0: 0,  z0: 0,  x1: 16, z1: 16, lod: 0 },
  { x0: 16, z0: 0,  x1: 32, z1: 16, lod: 1 },

  { x0: 16, z0: 16, x1: 32, z1: 32, lod: 3 },
];

function batchMesh() {
  setRules(RULES);
  const tris = [];
  for (const L of canonicalLeaves()) tris.push(...meshLeaf(L));
  return removeTJunctions(tris);
}

// T1. No T-junction survives stitching.
check('T1 stitch removes all T-junctions', () => {
  const raw = [];
  setRules(RULES);
  for (const L of canonicalLeaves()) raw.push(...meshLeaf(L));
  const stitched = removeTJunctions(raw);
  const again = removeTJunctions(stitched);
  assert.strictEqual(again.length, stitched.length, 'T-junctions remain after stitching');
  assert.ok(raw.length !== stitched.length, 'fixture did not exercise a seam');

// T2. Arrival order / disappear-replace converges to the batch result.
check('T2 order-independent convergent mesh', () => {
  const reference = meshHash(batchMesh()).hash;
  for (let k = 0; k < 12; k++) {
    const a = RULES.slice();
    for (let i = a.length - 1; i > 0; i--) {
      const j = (Math.random() * (i + 1)) | 0;
      [a[i], a[j]] = [a[j], a[i]];
    }
    const store = new BrickStore();
    const live = [];
    for (const r of a) {
      live.push(r);
      setRules(live);
      store.sync();
      const mid = store.buildMesh();
      assert.strictEqual(removeTJunctions(mid).length, mid.length,
        'intermediate mesh has a T-junction');
    }
    live.pop(); setRules(live); store.sync();          // brick disappears
    live.push(a[a.length - 1]); setRules(live); store.sync(); // and is replaced
    assert.strictEqual(meshHash(store.buildMesh()).hash, reference,
      'incremental mesh differs from batch reference');
  }
});

// T3. Rebuild work is bounded: appending one rule re-meshes only new leaves.
check('T3 incremental rebuild touches only new leaves', () => {
  const base = [{ x0: 0, z0: 0, x1: 16, z1: 16, lod: 1 }];
  const next = base.concat([{ x0: 0, z0: 0, x1: 8, z1: 8, lod: 0 }]);

  const store = new BrickStore();
  setRules(base); store.sync();
  const afterFirst = store.meshLeafCount;
  const before = store.meshLeafCount;
  setRules(next); store.sync();
  const delta = store.meshLeafCount - before;
  const total = canonicalLeaves().length;
  assert.ok(afterFirst > 0, 'first sync meshed nothing');
  assert.ok(delta > 0, 'new leaves were not meshed');
  assert.ok(delta < total, `re-meshed ${delta}/${total} leaves (no reuse)`);
  const cold = new BrickStore(); setRules(next); cold.sync();
  assert.strictEqual(cold.meshLeafCount, total, 'cold build should mesh every leaf');
  for (const t of store.cache.values()) assert.ok(t.length > 0);
});

// T4. Mixed-LOD shared face is identical no matter which side appeared first.
check('T4 shared-face topology is side-order independent', () => {
  setRules(RULES);
  const tris = [];
  for (const L of canonicalLeaves()) tris.push(...meshLeaf(L));
  const A = meshHash(removeTJunctions(tris)).hash;

  setRules(RULES.slice().reverse());
  const tris2 = [];
  for (const L of canonicalLeaves()) tris2.push(...meshLeaf(L));
  const Bt = meshHash(removeTJunctions(tris2)).hash;
  assert.strictEqual(A, Bt);

// T5. Strict GPU memory budget is never exceeded.
check('T5 GPU slot budget enforced', () => {
  const sched = new FrameScheduler(2);
  const sa = sched.acquire('a', 1);
  const sb = sched.acquire('b', 1);
  assert.ok(sa !== null && sb !== null && sa !== sb, 'distinct slots expected');
  assert.strictEqual(sched.acquire('c', 1), null, 'budget exceeded');
  sched.release('a');
  assert.strictEqual(sched.acquire('c', 1), sa, 'freed slot not reusable');
  assert.strictEqual(sched.pool.inUse, 2);
});

// T6. No stale-buffer reuse: an in-flight slot is not overwritten.
check('T6 stale-buffer race prevented by deferred recycle', () => {
  const sched = new FrameScheduler(1);

  // Frame 0: brick A gen1 drawn from slot 0, frame submitted (not finished).
  sched.acquire('A', 1);
  sched.markUsed('A');
  sched.submit();

  // Frame 1: A is replaced by A' gen2. Slot 0 is still in flight.
  sched.acquire('A', 2);
  assert.strictEqual(sched.pool.inUse, 0);
  assert.strictEqual(sched.retire.length, 1, 'old slot should be pending retire');
  assert.ok(!sched.pool.free.includes(0), 'in-flight slot was returned to free list');

  // GPU finishes frame 0; now slot 0 may be reused, tagged with a new generation.
  sched.onWorkDone(0);
  assert.ok(sched.pool.free.includes(0), 'slot not reclaimed after fence');
  const slot = sched.acquire('A', 2);
  assert.ok(slot !== null);
  assert.strictEqual(sched.binding.get('A').generation, 2, 'stale generation survived reuse');
});

// T7. Generation guard: stale draw data is rejected.
check('T7 generation tag rejects stale draw', () => {
  const resident = new Map([['A', { generation: 2, slot: 0 }]]);
  const drawCall = { brick: 'A', generation: 1, slot: 0 };
  const isCurrent = (d) => {
    const r = resident.get(d.brick);
    return !!r && r.generation === d.generation;
  };
  assert.strictEqual(isCurrent(drawCall), false, 'stale generation accepted');
  drawCall.generation = 2;
  assert.strictEqual(isCurrent(drawCall), true, 'current generation rejected');
});

4. Why each guarantee holds

  • Crack-free (R1/R6): the 2:1 balance pass guarantees adjacent leaves differ by at most one level, so every T-junction is a single midpoint per coarse edge; removeTJunctions inserts that vertex into the coarse triangle and reaches a fixed point (T1 re-runs the detector and finds nothing).
  • Order independence (R2): canonicalLeaves() is a deterministic function of the sorted rule set, independent of insertion order; the mesh hash is computed from canonicalized, sorted triangles.
