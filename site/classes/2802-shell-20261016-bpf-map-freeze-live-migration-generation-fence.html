Summary

Problem: migrate a heavily-written pinned eBPF hash map between schemas with live readers/writers, no lost updates, no duplicate ownership, no stale-generation reads, bounded memory, crash-safe at any instruction boundary.

Root causes (all independent): 1. Lost updates — copy-then-swap has no snapshot; writes after the copier's visit vanish. Needs a write-ahead record + post-drain reconciliation. 2. Duplicate ownership — owner published in >1 word tears. Needs one atomic cutover word. 3. Stale-generation reads — load gen → read entry → decode races the cutover. Needs a seqlock and a post-read generation recheck. 4. Unbounded memory — logging operations grows with write volume. A WAL keyed by user key holding the latest absolute value is bounded by map capacity and idempotent. 5. Crash atomicity — multi-map updates aren't transactions; in-flight lease counters deadlock barriers after a crash. Needs commit-before-apply + idempotent recovery + lease invalidation.

Fix: two schema maps + bounded absolute-value WAL + map-in-map root[0] indirection; dual-write during migration; a seqlock/epoch fence (A → DUAL → FENCE → B) with an in-flight-writer barrier; atomic cutover of root[0]+owner+gen; idempotent restart from ctl.phase.

Verification (executed in this sandbox): - Real BPF is impossible here (CapEff=0, unprivileged_bpf_disabled=2, no bpffs), so the proof is a crash-injection model checker: happy-path : verify=COMPLETE steps=417 maxWAL=2 stale-retries=0 interrupted : verify=INCOMPLETE pending_keys=23 negative-ctl : caught by checker -> I1 LOST UPDATE ... migration : 150 atomic boundaries in first pass crash-inject : PASS across 150 atomic boundaries (I1-I4 hold after recovery) - The live verifier's decision logic was tested against a mocked bpftool: COMPLETE (rc 0), INCOMPLETE for B-lag and non-empty WAL (rc 1), IN_PROGRESS for odd epoch (rc 2). - Negative control proves the checker isn't vacuous.

Key protocol insight: the WAL is the commit point, so correctness no longer depends on atomicity of the dual-write; the epoch barrier gives liveness, and recovery invalidating dead writer leases prevents the barrier deadlock that the crash injection exposed.
