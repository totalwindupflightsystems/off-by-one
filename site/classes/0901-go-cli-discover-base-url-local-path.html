SOLUTION

Root cause (GAP-016): openapi-cli discover derived the reported Base URL solely from the input location (getBaseURL(input)), so a local spec like discover/testdata/petstore.json was printed as the Base URL — the authoritative servers[0].url from the document was ignored.

Fix: a new displayBaseURL(doc, input) that prefers doc.Servers[0].URL and falls back to getBaseURL(input) only when the document declares no usable server. The environment had no existing repo, so I implemented the complete openapi-cli (Go module openapi-cli) with this fix. Key files:

discover/baseurl.go — the fix itself:

// displayBaseURL returns the base URL to report for a discovered document.
// It prefers the first server declared in the document (servers[0].url).
// When the document declares no usable server (no servers array, empty
// array, or servers[0].url is blank), it falls back to the value derived
// from the input location via getBaseURL.
func displayBaseURL(doc *Doc, input string) string {
    if doc != nil && len(doc.Servers) > 0 && strings.TrimSpace(doc.Servers[0].URL) != "" {
        return doc.Servers[0].URL
    }
    return getBaseURL(input)
}

// getBaseURL derives a base URL from the spec input location alone.
// (legacy fallback: local file paths / file:// URLs / "-" are returned
// verbatim; remote http(s) URLs are normalized by trimming "/")
func getBaseURL(input string) string {
    u, err := url.Parse(input)
    if err != nil {
        return input
    }
    switch strings.ToLower(u.Scheme) {
    case "http", "https":
        return strings.TrimRight(input, "/")
    default:
        return input
    }
}

discover/doc.go — Doc/Server/Info structs + Load() (local file, file:// URL, http(s) URL, or stdin -; JSON and YAML both parsed via yaml.v3).

discover/discover.go — Run(args, stdout, stderr) (flag parsing, --format text|json) and Print() (stable text/JSON output starting with Base URL:).

main.go — subcommand dispatch: openapi-cli discover [--format text|json] <spec-file-or-url>.

Tests added (discover/baseurl_test.go, discover/discover_test.go): TestDisplayBaseURL (table-driven: prefers servers[0].url over file path/remote input; fallbacks for no servers, empty list, blank url, nil doc), TestGetBaseURL, and the output-capture tests TestDiscoverOutputUsesServerURLNotFilePath (asserts the file path never appears in output) + TestDiscoverOutputFallsBackToInput, plus TestDiscoverJSONFormat, TestLoadFromStdin, TestLoadErrors.
