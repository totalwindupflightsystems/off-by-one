TRBL-117 — Compaction must declare exact consumed seqs, and verify must read them per day

Symptom

A successful ledger compact (exit 0, delta -99126 bytes, 103 aggregates) immediately caused the product’s own ledger verify to report corruption:

FINDINGS exit 1
seq_holes=25
tombstone_mismatches=101

The holes matched folded event-line ranges, e.g. 88..99, 650..658.

Root cause

There are two defects; both must be fixed.

1. agg_seqs declared a bounding range, but folded seqs are sparse

Compaction folds one group’s event lines into one aggregate, but groups interleave in the writer. A fixture can produce:

group A: 2, 5, 8, 11
group B: 3, 6, 9, 12
group C: 4, 7, 10, 13

Group A’s [first=2,last=11] range includes other groups’ seqs and omits its own later folds. The aggregate must record the explicit, deduplicated, ascending consumed seq list in agg_seqs.seqs.

2. Neither verifier consulted agg_seqs

Both Ledger.Verify (recover.go) and ReadVerify (readonly.go) required contiguous line seqs and counted only surviving event lines. Folded lines are gone, so healthy compaction looked like holes plus short tombstones.

Fix contract:

accounted seq = a surviving line
              OR an aggregate-declared consumed range

tombstone denominator = declared aggregate seqs
                      + surviving lines whose seq falls inside a declared range

3. Continuity is per-day, not per-walk

Accumulating all walked days into one seq set lets one day mask another day’s real hole, and the old global prev walk invents holes at day boundaries. Seq state must be flushed at every day boundary.

Exact fix

1. internal/ledger/compact.go — write exact consumed seqs

Add sort to imports and add:

func sortedSeqs(in []uint64) []any {
    if len(in) == 0 {
        return []any{}
    }
    cp := make([]uint64, len(in))
    copy(cp, in)
    sort.Slice(cp, func(i, j int) bool { return cp[i] < cp[j] })
    out := make([]any, 0, len(cp))
    var prev uint64
    for i, s := range cp {
        if i > 0 && s == prev {
            continue
        }
        out = append(out, s)
        prev = s
    }
    return out
}

Extend aggregate state with seqs []uint64, append each folded line’s seq:

a.count++
a.seqs = append(a.seqs, rec.Seq)

When re-compacting a prior aggregate, carry its list forward and include the prior aggregate line’s own seq:

if prior, ok := rec.Payload["agg_seqs"].(map[string]any); ok {
    if list, ok := prior["seqs"].([]any); ok {
        for _, v := range list {
            a.seqs = append(a.seqs, uint64(numOf(v)))
        }
    }
}
a.seqs = append(a.seqs, rec.Seq)

Emit the exact list:

"agg_seqs": map[string]any{

    "last":       a.lastSeq,
    "count":      a.count,
    "seqs":       sortedSeqs(a.seqs),
    "exceptions": []any{},

2. internal/ledger/recover.go — shared reader, continuity, denominator

Add:

type seqSpan struct{ from, to uint64 }

func aggSeqSpans(rec *types.Record) (spans []seqSpan, declared uint64) {
    if rec == nil || rec.Payload == nil {
        return nil, 0
    }
    raw, ok := rec.Payload["agg_seqs"]
    if !ok {
        return nil, 0
    }
    block, ok := raw.(map[string]any)
    if !ok {
        return nil, 0
    }
    first := uint64(numOf(block["first"]))
    last := uint64(numOf(block["last"]))

    // Prefer the explicit consumed-seq list; folded seqs are sparse because
    // groups interleave in the writer.
    if list, ok := block["seqs"].([]any); ok && len(list) > 0 {
        numeric := make([]uint64, 0, len(list))
        for _, v := range list {
            if n := uint64(numOf(v)); n != 0 {
                numeric = append(numeric, n)
            }
        }
        if len(numeric) > 0 {
            sort.Slice(numeric, func(i, j int) bool { return numeric[i] < numeric[j] })
            start := numeric[0]
            prev := numeric[0]
            for _, n := range numeric[1:] {
                if n == prev {
                    continue
                }
                if n == prev+1 {
                    prev = n
                    continue
                }
                spans = append(spans, seqSpan{start, prev})
                start, prev = n, n
            }
            spans = append(spans, seqSpan{start, prev})

            declared = uint64(len(numeric))
            if c, ok := rec.Payload["counters"].(map[string]any); ok {
                if n := uint64(numOf(c["events"])); n != 0 {
                    declared = n
                }
            } else if n := uint64(numOf(block["count"])); n != 0 {
                declared = n
            }
            if n := uint64(numOf(rec.Payload["events_aggregated"])); n != 0 && declared == 0 {
                declared = n
            }
            return spans, declared
        }
    }

    // Legacy fallback: [first..last] minus exceptions.
    if first == 0 || last < first {
        return nil, 0
    }
    var except []seqSpan
    if list, ok := block["exceptions"].([]any); ok {
        for _, e := range list {
            switch v := e.(type) {
            case map[string]any:
                ef, el := uint64(numOf(v["from"])), uint64(numOf(v["to"]))
                if ef == 0 {
                    ef = uint64(numOf(v["first"]))
                }
                if el == 0 {
                    el = uint64(numOf(v["last"]))
                }
                if ef != 0 && el >= ef {
                    except = append(except, seqSpan{ef, el})
                }
            case []any:
                if len(v) == 2 {
                    ef, el := uint64(numOf(v[0])), uint64(numOf(v[1]))
                    if ef != 0 && el >= ef {
                        except = append(except, seqSpan{ef, el})
                    }
                }
            case float64, int, int64, json.Number:
                if n := uint64(numOf(v)); n >= first && n <= last {
                    except = append(except, seqSpan{n, n})
                }
            }
        }
    }
    sort.Slice(except, func(i, j int) bool { return except[i].from < except[j].from })
    cur := first
    for _, ex := range except {
        if ex.to < cur {
            continue
        }
        if ex.from > last {
            break
        }
        if ex.from > cur {
            spans = append(spans, seqSpan{cur, ex.from - 1})
        }
        if ex.to+1 > cur {
            cur = ex.to + 1
        }
    }
    if cur <= last {
        spans = append(spans, seqSpan{cur, last})
    }

    counted := uint64(0)
    for _, s := range spans {
        counted += s.to - s.from + 1
    }
    declared = uint64(numOf(rec.Payload["events_aggregated"]))
    if c, ok := rec.Payload["counters"].(map[string]any); ok {
        if n := uint64(numOf(c["events"])); n != 0 {
            declared = n
        }
    }
    if declared == 0 {
        declared = counted
    }
    return spans, declared
}

Continuity:

func verifyContinuity(seen map[uint64]struct{}, consumed []seqSpan) []SeqHole {
    if len(seen) == 0 {
        return nil
    }
    max := uint64(0)
    for s := range seen {
        if s > max {
            max = s
        }
    }
    for _, sp := range consumed {
        if sp.to > max {
            max = sp.to
        }
    }
    spans := make([]seqSpan, 0, len(consumed))
    for _, sp := range consumed {
        if sp.to >= sp.from {
            spans = append(spans, sp)
        }
    }
    sort.Slice(spans, func(i, j int) bool { return spans[i].from < spans[j].from })

    var holes []SeqHole
    var start, end uint64
    record := func(s, e uint64) {
        if start == 0 {
            start, end = s, e
            return
        }
        if s == end+1 {
            end = e
            return
        }
        holes = append(holes, SeqHole{From: start, To: end})
        start, end = s, e
    }
    idx := 0
    for s := uint64(1); s <= max; s++ {
        if _, ok := seen[s]; ok {
            continue
        }
        for idx < len(spans) && spans[idx].to < s {
            idx++
        }
        if idx < len(spans) && spans[idx].from <= s {
            continue
        }
        record(s, s)
    }
    if start != 0 {
        holes = append(holes, SeqHole{From: start, To: end})
    }
    return holes
}

Tombstone denominator:

func eventSeqSet(lines map[uint64]struct{}, consumed []seqSpan) uint64 {
    set := make(map[uint64]struct{}, len(lines))
    for _, sp := range consumed {
        if sp.to < sp.from {
            continue
        }
        for s := sp.from; s <= sp.to; s++ {
            set[s] = struct{}{}
        }
    }
    for s := range lines {
        for _, sp := range consumed {
            if s >= sp.from && s <= sp.to {
                set[s] = struct{}{}
                break
            }
        }
    }
    return uint64(len(set))
}

3. Wire both verifiers per day

Both Ledger.Verify and ReadVerify replace the old prev/counted logic with:

type aggInfo struct {
    declared uint64
    seqs     map[uint64]struct{}
    spans    []seqSpan
}

aggs := map[string]*aggInfo{}
seen := map[uint64]struct{}{}
var consumed []seqSpan

curDay := ""
flushDay := func() {
    if curDay == "" {
        return
    }
    rep.SeqHoles = append(rep.SeqHoles, verifyContinuity(seen, consumed)...)
    seen = map[uint64]struct{}{}
    consumed = nil
}

At each file:

if p.Day != curDay {
    flushDay()
    curDay = p.Day
}

For each line:

seen[rec.Seq] = struct{}{}

For surviving lines belonging to an aggregate:

if ai.seqs == nil {
    ai.seqs = map[uint64]struct{}{}
}
ai.seqs[rec.Seq] = struct{}{}

For a real compression aggregate:

spans, declared := aggSeqSpans(rec)
consumed = append(consumed, spans...)
ai.spans = append(ai.spans, spans...)
ai.declared += declared

After the walk:

flushDay()

for _, ai := range aggs {
    counted := eventSeqSet(ai.seqs, ai.spans)
    if ai.declared != 0 && counted != 0 && ai.declared != counted {
        rep.TombstoneMismatches++
    }
}

General rule

When a reduction replaces N records with one summary record, the summary must state the exact set it consumed, not merely a bounding range. Every consumer that validates completeness must consult that exact set. Interleaved sources make bounding ranges overlap and lie. Validate the reduction round trip in a test, and make continuity checks per-partition (per day/segment), never across the whole walk.
