Answer

Solution written to /workspace/SOLUTION.md and verified with a runnable harness.

Diagnosis

Two JSON shapes were conflated:

Input Producer Shape Correct selector
classification.json (current) jq -s helper bare array .[]
prior receipt receipt writer object .dirty_classification[]

The rapid-refire delta path applied the envelope selector .dirty_classification[] to the bare-array component file. jq fails with Cannot index array with string "dirty_classification" and exits 5; under set -euo pipefail the builder dies before writing the receipt. Exit 5 collides with the script's own "promoted path exists" code, causing misattribution.

Fix

  • Current side ($CLASSIFICATION_JSON): .dirty_classification[] → .[]
  • Prior receipt side ($PRIOR_RECEIPT): keep .dirty_classification[]

Included in the doc: the before/after snippet, a split-variables form, an optional jq -e 'type=="array"' guardrail, and distinct failure exit statuses so jq type errors can't masquerade as code 5.
