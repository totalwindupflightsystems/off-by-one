Root-cause analysis

The naive approach fails in four independent ways:

  1. Floating-point overflow (unsound if swallowed). The Poisson-subsampled Gaussian RDP is a sum of terms containing exp(k(k−1)/(2σ²)). With σ=0.5, k=20 the exponent is 760 > log(DBL_MAX)≈709, so a direct sum(exp(...)) overflows to inf for ordinary parameters. If the overflow is clamped, the reported δ is too small.
  2. Invalid amplification (the big one). Fixed-size sampling (without replacement) is not Poisson. For the same q=m/n the without-replacement RDP is strictly larger. Substituting Poisson under-states δ by 36×–239× on a concrete replace-one run — a guarantee that claims far more privacy than exists.
  3. Unsound interpolation. Interpolating ε(α) itself need not upper-bound the truth. One must interpolate the convex log-moment g(α) = (α−1)ε(α) = log E[L^α], whose chord lies above the curve.
  4. Adjacency / independence. The without-replacement bound is a replace-one result; the Poisson bound is add/remove. Order-wise RDP addition also requires independent subsampling across steps.

The exact fix

  • Integer-order RDP computed entirely in log space with a stable log_sum_exp — no overflow.
  • Separate formula per sampler: Poisson binomial sum vs. Wang–Balle–Kasiviswanathan forward-difference formula (log-domain) for fixed-size/WOR.
  • Accumulate g(α) = (α−1)ε(α) across steps (valid for adaptive composition).
  • Interpolate g (convex) between queried Rényi orders, then convert δ = min_α exp((α−1)(ε_α−ε))·(α−1)^(α−1)/α^α.
  • Refuse to certify on σ≤0, bad ranges, invalid amplification/adjacency, dependent batching, non-finite RDP.

def poisson_subsampled_gaussian_rdp(alpha, q, sigma):      # log-space
    log_terms = [ (lgamma(a+1)-lgamma(k+1)-lgamma(a-k+1))
                  + (a-k)*log1p(-q) + k*log(q)
                  + k*(k-1)/(2*sigma**2) for k in range(a+1) ]
    return log_sum_exp(log_terms) / (alpha - 1)

def fixed_size_subsampled_gaussian_rdp(alpha, q, sigma):   # WOR, alpha int
    return fixed_size_subsampled_gaussian_rdp_int(q, sigma, int(alpha)) / (alpha-1)
    # ... forward differences of exp(cgf) in log space (W-B-K Theorem 27)

def renyi_to_delta(alpha, rdp_alpha, epsilon):             # log-space closed form
    log_delta = (alpha-1)*(rdp_alpha-epsilon) + (alpha-1)*log(alpha-1) - alpha*log(alpha)
    return min(1.0, exp(log_delta)) if log_delta < 0 else 1.0
