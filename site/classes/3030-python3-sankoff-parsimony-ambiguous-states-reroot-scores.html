Sankoff Parsimony with IUPAC Ambiguity, Multifurcations, and Rerooted Edge Deltas

1. Problem restated precisely

Given a Newick tree (possibly with a trifurcating/unrooted root and arbitrarily high-degree internal nodes) whose leaf labels are IUPAC nucleotide ambiguity codes, compute:

  1. the optimal Sankoff parsimony root cost (minimum number of substitutions over all state assignments, with ambiguity sets treated as sets of possible states), and
  2. for every edge, a rerooted per-edge cost delta that measures how much that edge contributes to the total cost.

Working definition used and implemented (it is the only non‑trivial one, because the unrooted parsimony total is root‑invariant for symmetric costs):

Deleting edge e = (u,c) splits the tree into the c‑side (subtree c) and the u‑side. Their independent optimal scores are min(down[c]) and min(S[u] − g[c]). Then delta(e) = total − (min(down[c]) + min(S[u] − g[c])) ≥ 0. These two side scores are exactly the scores obtained by rerooting each component at the cut endpoints; the delta is the edge's contribution to the total.

C(s,t) = 0 if s == t else 1; states are A,C,G,T in lexicographic order.

2. Root‑cause analysis (why naive solutions fail)

# Failure mode Symptom Root cause Fix
1 Recursion depth RecursionError on a 10^5‑node caterpillar Recursive Newick parse / DFS Explicit stack, iterative pre/post-order
2 Ambiguity collapsed too early R={A,G} next to G reports cost 1 instead of 0 Mapping each IUPAC code to one base before the DP Keep the set in the DP (0 for allowed states, INF otherwise); collapse only when emitting a reconstruction

4 Meaningless "reroot delta" delta is always 0 Symmetric Sankoff total is root‑invariant, so "rerooted total − original total = 0" Define delta via the forest score after deleting the edge, computed with the two‑pass down/up rerooting DP

#!/usr/bin/env python3
"""
Sankoff parsimony with IUPAC ambiguity, multifurcations, iterative rerooting,
and per-edge contribution deltas.

States are fixed as 0..3 == A,C,G,T (lexicographic order A < C < G < T).
Unit substitution cost: 0 on the diagonal, 1 on every off-diagonal.
All arithmetic is exact Python integers; a large int sentinel replaces +inf.
"""

from __future__ import annotations

import json
import sys

# --------------------------------------------------------------------------
# States and IUPAC ambiguity sets
# --------------------------------------------------------------------------
STATES = "ACGT"
NSTATES = 4
INF = 1 << 60

IUPAC = {
    "A": frozenset((0,)), "C": frozenset((1,)),
    "G": frozenset((2,)), "T": frozenset((3,)), "U": frozenset((3,)),
    "R": frozenset((0, 2)), "Y": frozenset((1, 3)),
    "S": frozenset((1, 2)), "W": frozenset((0, 3)),
    "K": frozenset((2, 3)), "M": frozenset((0, 1)),
    "B": frozenset((1, 2, 3)), "D": frozenset((0, 2, 3)),
    "H": frozenset((0, 1, 3)), "V": frozenset((0, 1, 2)),
    "N": frozenset((0, 1, 2, 3)),
    "?": frozenset((0, 1, 2, 3)),
    "-": frozenset((0, 1, 2, 3)),
}


class ParseError(ValueError):
    """Raised for malformed, ambiguous, or cycle-forming Newick input."""


# --------------------------------------------------------------------------
# Tokenizer
# --------------------------------------------------------------------------
_PUNCT = {"(": "LPAREN", ")": "RPAREN", ",": "COMMA", ";": "SEMI", ":": "COLON"}


def tokenize(text: str):
    tokens = []
    i, n = 0, len(text)
    while i < n:
        c = text[i]
        if c.isspace():
            i += 1
            continue
        if c == "[":  # Newick comment, nesting allowed
            start = i
            depth = 0
            while i < n:
                if text[i] == "[":
                    depth += 1
                elif text[i] == "]":
                    depth -= 1
                    if depth == 0:
                        i += 1
                        break
                i += 1
            else:
                raise ParseError(f"unterminated comment starting at offset {start}")
            continue
        if c in ("'", '"'):
            quote = c
            start = i
            i += 1
            buf = []
            while i < n:
                if text[i] == quote:
                    if quote == "'" and i + 1 < n and text[i + 1] == "'":
                        buf.append("'")
                        i += 2
                        continue
                    i += 1
                    break
                buf.append(text[i])
                i += 1
            else:
                raise ParseError(f"unterminated quoted name at offset {start}")
            tokens.append(("NAME", "".join(buf), start))
            continue
        if c in _PUNCT:
            tokens.append((_PUNCT[c], c, i))
            i += 1
            continue
        start = i
        while i < n and not text[i].isspace() and text[i] not in "(),;:'\"[]":
            i += 1
        tokens.append(("NAME", text[start:i], start))
    return tokens


# --------------------------------------------------------------------------
# Iterative Newick parser -> rooted tree
# --------------------------------------------------------------------------
class Tree:
    __slots__ = ("n", "children", "parent", "labels", "leaf_states", "root", "edges")

    def __init__(self):
        self.n = 0
        self.children = []      # children[u] = list[int]
        self.parent = []        # parent[u] = int or -1
        self.labels = []        # label per node (str or None)
        self.leaf_states = []   # frozenset for leaves, None for internal
        self.root = 0
        self.edges = []         # (parent, child) in rooted orientation


def parse_newick(text: str) -> Tree:
    tokens = tokenize(text)
    tree = Tree()
    defined_internal: dict[str, int] = {}
    # Stack of frames: [children, need_child].  index 0 is the top level.
    stack = [[[], True]]
    i = 0
    n = len(tokens)

    def new_node(label, kids, leaf_set):
        idx = tree.n
        tree.n += 1
        tree.children.append(kids)
        tree.parent.append(-1)
        tree.labels.append(label)
        tree.leaf_states.append(leaf_set)
        return idx

    def skip_branch_length(pos):
        nonlocal i
        if i + 1 >= n or tokens[i + 1][0] != "NAME":
            raise ParseError(f"branch length missing after ':' at offset {pos}")
        i += 2

    while i < n:
        typ, val, pos = tokens[i]
        if typ == "LPAREN":
            stack[-1][1] = False
            stack.append([[], True])
            i += 1
        elif typ == "COMMA":
            frame = stack[-1]
            if frame[1]:
                raise ParseError(f"empty child before ',' at offset {pos}")
            frame[1] = True
            i += 1
        elif typ == "RPAREN":
            if len(stack) < 2:
                raise ParseError(f"unbalanced ')' at offset {pos}")
            frame = stack.pop()
            if frame[1] or not frame[0]:
                raise ParseError(f"empty child before ')' at offset {pos}")
            kids = frame[0]
            i += 1
            label = None
            if i < n and tokens[i][0] == "NAME":
                label = tokens[i][1]
                i += 1
            if label is not None and label in defined_internal:
                raise ParseError(
                    f"cycle-forming input: internal node label {label!r} reused "
                    f"at offset {pos} (would create a node with two parents)"
                )
            node = new_node(label, kids, None)
            if label is not None:
                defined_internal[label] = node
            if i < n and tokens[i][0] == "COLON":
                skip_branch_length(tokens[i][2])
            stack[-1][0].append(node)
            stack[-1][1] = False
        elif typ == "NAME":
            name = val
            if name in defined_internal:
                raise ParseError(
                    f"cycle-forming input: reference to internal node {name!r} "
                    f"at offset {pos} (back-edge)"
                )
            code = name.upper()
            if code not in IUPAC:
                raise ParseError(f"unknown state symbol {name!r} at offset {pos}")
            node = new_node(name, [], IUPAC[code])
            i += 1
            if i < n and tokens[i][0] == "COLON":
                skip_branch_length(tokens[i][2])
            stack[-1][0].append(node)
            stack[-1][1] = False
        elif typ == "SEMI":
            i += 1
            break
        elif typ == "COLON":
            raise ParseError(f"unexpected ':' at offset {pos}")
        else:  # pragma: no cover
            raise ParseError(f"unexpected token {typ!r} at offset {pos}")

    if i != n:
        raise ParseError(f"trailing input after ';' at offset {tokens[i][2]}")
    if len(stack) != 1:
        raise ParseError("unbalanced parentheses (unclosed '(')")
    top_frame = stack[0]
    top = top_frame[0]
    if top_frame[1] or len(top) == 0:
        raise ParseError("empty Newick input")
    if len(top) > 1:
        raise ParseError(
            "cycle-forming/forest input: expected exactly one top-level tree, "
            f"found {len(top)}"
        )

    tree.root = top[0]
    for u in range(tree.n):
        for c in tree.children[u]:
            tree.parent[c] = u
            tree.edges.append((u, c))
    return tree


# --------------------------------------------------------------------------
# Sankoff DP
# --------------------------------------------------------------------------
def _transform(vec):
    """min-plus message: g[t] = min_x C(t,x) + vec[x], C = 0 diag / 1 off."""
    m = min(vec)
    return [vec[t] if vec[t] <= m + 1 else m + 1 for t in range(NSTATES)]


class SankoffResult:
    __slots__ = ("total", "root_vector", "down", "up", "S", "g", "order")

    def __init__(self):
        self.total = 0
        self.root_vector = None
        self.down = None
        self.up = None
        self.S = None
        self.g = None
        self.order = None


def sankoff(tree: Tree) -> SankoffResult:
    n = tree.n
    down = [[INF] * NSTATES for _ in range(n)]
    g = [[INF] * NSTATES for _ in range(n)]

    # Iterative pre-order; parents precede descendants, children left-to-right.
    order = []
    stack = [tree.root]
    while stack:
        u = stack.pop()
        order.append(u)
        stack.extend(reversed(tree.children[u]))

    # Post-order: descendants before ancestors.
    for u in reversed(order):
        leaf_set = tree.leaf_states[u]
        if leaf_set is not None:
            row = down[u]
            for s in leaf_set:
                row[s] = 0
        else:
            row = [0] * NSTATES
            for c in tree.children[u]:
                mc = g[c]
                for s in range(NSTATES):
                    row[s] += mc[s]
            down[u] = row
        g[u] = _transform(down[u])

    # up[root] = 0, S[root] = down[root].
    up = [[0] * NSTATES for _ in range(n)]
    S = [[0] * NSTATES for _ in range(n)]
    S[tree.root] = down[tree.root][:]

    # Pre-order rerooting pass.
    for u in order:
        Su = S[u]
        for c in tree.children[u]:
            gc = g[c]
            X = [Su[t] - gc[t] for t in range(NSTATES)]  # u-side minus edge
            upc = _transform(X)
            up[c] = upc
            dc = down[c]
            S[c] = [upc[s] + dc[s] for s in range(NSTATES)]

    res = SankoffResult()
    res.down, res.up, res.S, res.g, res.order = down, up, S, g, order
    res.root_vector = S[tree.root]
    res.total = min(res.root_vector)
    return res


def edge_deltas(tree: Tree, res: SankoffResult):
    """total - (forest score after deleting each edge)."""
    out = []
    for (u, c) in tree.edges:
        Su = res.S[u]
        gc = res.g[c]
        forest = min(res.down[c]) + min(Su[t] - gc[t] for t in range(NSTATES))
        out.append((u, c, res.total - forest))
    return out


def reconstruct(tree: Tree, res: SankoffResult):
    """Lexicographically smallest optimal assignment (left-to-right pre-order).

    Ambiguity is only resolved here; the DP never collapses a set.
    """
    assign = [None] * tree.n
    assign[tree.root] = min(range(NSTATES), key=lambda s: (res.S[tree.root][s], s))
    for u in res.order:
        su = assign[u]
        for c in tree.children[u]:
            dc = res.down[c]
            best = min(range(NSTATES), key=lambda s: (dc[s] + (0 if s == su else 1), s))
            assign[c] = best
    return assign


# --------------------------------------------------------------------------
# Convenience API + CLI
# --------------------------------------------------------------------------
def solve(newick: str) -> dict:
    tree = parse_newick(newick)
    res = sankoff(tree)
    assign = reconstruct(tree, res)
    deltas = edge_deltas(tree, res)
    return {
        "root_cost": res.total,
        "root_state_costs": {STATES[s]: res.root_vector[s] for s in range(NSTATES)},
        "edge_deltas": [{"parent": u, "child": c, "delta": d} for (u, c, d) in deltas],
        "node_labels": [tree.labels[u] for u in range(tree.n)],
        "reconstruction": {str(u): STATES[assign[u]] for u in range(tree.n)},
    }


def main(argv):
    text = " ".join(argv[1:]) if len(argv) > 1 else sys.stdin.read()
    try:
        print(json.dumps(solve(text), indent=2))
    except ParseError as e:
        print(f"ParseError: {e}", file=sys.stderr)
        return 2
    return 0


if __name__ == "__main__":
    raise SystemExit(main(sys.argv))

Why the rerooting pass is correct

With down[u][s] = subtree cost given u=s and g[c] the child→parent message, define S[u][s] = up[u][s] + down[u][s] = whole-tree cost given u=s. For a child c, X[t] = S[u][t] − g[c][t] is the cost of the u‑side (edge removed) given u=t, and up[c] = transform(X). Consequently:

  • total = min(S[root]) (and by induction min(S[u]) == total for every node — the invariance that makes the naive reroot delta useless),
  • forest(e) = min(down[c]) + min(X),
  • delta(e) = total − forest(e) ≥ 0.

Complexity: O(n · |Σ|²) = O(16n) time, O(n · |Σ|) = O(4n) memory, no recursion.
