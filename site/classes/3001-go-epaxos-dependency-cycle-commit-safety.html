EPaxos Dependency-Cycle Commit Safety — Verified Solution

Root-cause analysis

EPaxos assigns each command (replica, slot), a seq, and a set of conflicting-instance deps. Execution order = SCC order of the committed dependency graph, tie-broken inside each SCC by (seq, replica, slot). That is what makes replicas agree.

The unsafe step is the slow path. When fast-quorum PreAccept replies disagree, the leader merges a majority's deps:

merged = union(leader.deps, replies...)

Because it is computed against a local view, the merge can add X -> Y where the target Y is already committed and already reaches X transitively. That closes X <-> Y:

  • Y is committed (frozen) but can never satisfy its dependency on the uncommitted X, so it is stranded;
  • the SCC {X, Y} cannot be legally ordered.

Root cause: no guard against adding an edge from an uncommitted instance to an already-committed instance that reaches back to it. Naive merge can also keep an unnecessary edge that makes a transient cycle permanent.

The exact fix

  1. Commit-safety guard — before recording X with deps D, build the graph over committed ∪ {X}. For each committed d ∈ D, test pathExists(d, X). If so, X -> d strands d. Drop the minimal such edge (smallest target by (replica, slot)) and nominate X for recovery.
  2. SCC execution order — Tarjan over committed instances, condense, emit dependencies before dependents; inside an SCC sort by (seq, replica, slot). If a committed instance transitively depends on an uncommitted one, refuse to order and report the blocker.
  3. Total, deterministic tie-breaking at every decision point.
// Try to commit cand with deps against the committed set.
func CommitSafely(committed map[ID]*Instance, cand *Instance, deps map[ID]bool) SafetyResult {
    res := SafetyResult{Instance: cand.ID}

    tmp := map[ID]*Instance{}
    for id, in := range committed { tmp[id] = in }
    probe := newInstance(cand.ID, cand.Cmd)
    probe.Seq = cand.Seq
    for d := range deps { probe.Deps[d] = true }
    probe.State = Committed
    tmp[cand.ID] = probe
    g := buildGraph(tmp, nil)

    var illegal []Edge
    for d := range deps {
        y, isCommitted := committed[d]
        if !isCommitted || y.State != Committed { continue }
        if pathExists(g, d, cand.ID) {           // d -> ... -> cand
            illegal = append(illegal, Edge{From: cand.ID, To: d})
        }
    }
    if len(illegal) == 0 {
        res.Committed = true
        res.FinalDeps = sortedKeys(deps)
        return res
    }
    // Pick the minimal edge to drop (deterministic).
    sort.Slice(illegal, func(i, j int) bool { return illegal[i].To.Less(illegal[j].To) })
    drop := illegal[0]
    res.Dropped = &drop
    rec := cand.ID
    res.Recover = &rec

    safe := map[ID]bool{}
    for d := range deps { if d != drop.To { safe[d] = true } }
    res.FinalDeps = sortedKeys(safe)
    res.Committed = true
    return res
}

func ExecutionOrder(insts map[ID]*Instance) ([]ID, ID, error) {
    committed := map[ID]bool{}
    for id, in := range insts {
        if in.State == Committed || in.State == Executed { committed[id] = true }
    }
    // Stranded check: committed whose transitive closure hits an uncommitted one.
    // (full body in epaxos.go)
    g := buildGraph(insts, committed)
    comps := tarjan(g)
    order, err := topoOrderComponents(g, comps, insts) // deps first; intra-SCC by (seq,replica,slot)
    return order, ID{}, err
}
