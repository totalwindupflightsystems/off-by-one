Answer

Root cause: the fork inherited upstream LocalStack's README, which documents a localstack CLI daemon (localstack start -d, localstack stop). The fork's real entry point is the in-memory runtime python3 -m localstack.runtime.main (exposed via make start), and [project.scripts] only ships localstack-supervisor. A dev following the README verbatim runs a binary that was never installed → localstack: No such file or directory (exit 127).

Fix has three layers:

1. Documentation (primary) — README documents only live-verified commands
