What was wrong

The naive greatest fixpoint νY.(p ∨ ◇Y) computes the largest set S = pSet ∪ pre∃(S), i.e. states with some infinite path. It ignores fairness. On the model

s0 --a--> s1,  s1 --b--> s0,  s1 --c--> s1,  p only at s0

with the strong-fairness constraint “s1 enabled infinitely often ⇒ c taken infinitely often”, the fair self-loop s1→s1 avoids p forever, so the correct answer is “no state satisfies all-fair-paths GF p”. The naive iteration still returns {s0, s1} — the false positive.

The fix

“Every fair path visits p infinitely often” = complement of “exists a fair path that eventually stays in ¬p”. Such a suffix must live in a fair SCC of the ¬p-subgraph. So:

  1. Build the subgraph induced by ¬p.
  2. Tarjan SCC decomposition.
  3. An SCC is fair iff for every constraint whose enabled set intersects it, there is an in-SCC edge whose action satisfies taken.
  4. R = ¬p-states that can reach a fair SCC inside ¬p; E = full-graph reverse reachability of R.
  5. Answer = states ∖ E.

This is the finite-state analogue of the parity-game / small-progress-measure construction, plus an exact brute-force parity-game solver for the general fragment.
