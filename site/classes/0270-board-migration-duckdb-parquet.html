FIX #1 — namespace basename bug (home → duckbrain): legacy code did Path.home().name (e.g. kara/root), scattering parquet under the wrong tree. Now the namespace is the explicit fleet constant:

NAMESPACE = "duckbrain"          # never Path.home().name
...
ns_dir = out_root / NAMESPACE / "boards" / board   # out/duckbrain/boards/fleet/...

FIX #2 — Active-only parser dropped DB-001 (Blocked): parser now takes all sections, and rows lost to the legacy parser are backfilled from dropped_snapshot:

def parse_board(con, sections=SECTIONS):          # SECTIONS = Active|Blocked|Done
    q = ("SELECT key,title,section,status,gate,cooldown_secs FROM items "
         f"WHERE section IN ({','.join('?'*len(sections))})")
    return [tuple(r) for r in con.execute(q, sections)]

def backfill_dropped(rows, con):
    seen = {r[0] for r in rows}
    snap = con.execute("SELECT key,title,section,status,gate,cooldown_secs FROM dropped_snapshot").fetchall()
    return rows + [tuple(r) for r in snap if r["key"] not in seen]   # restores DB-001

FIX #3 — fixtures trio auto-inserted (and mirrored into items so the Active parquet carries them): ensure_fixtures_trio runs before parsing:

con.executemany("INSERT OR IGNORE INTO items (key,title,section,status,gate,cooldown_secs) "
                "VALUES (:key,:key,:section,'fixture','auto',0)", FIXTURE_TRIO)  # FX-001..003

FIX #4 — two-commit hash backfill: source_commit (sibling mid-tick 1049c6a) and target_commit (delta c4ebfcc) land in both migration_meta and manifest.parquet.

FIX #5 — audit gate placeholders filled by independent gates; cooldown stays 900: placeholders are never trusted from in-flight siblings — every PENDING_PLACEHOLDER is re-run independently. DB-001 is human-gated, so it becomes pending-human (real pending), not auto-passed, and its cooldown is preserved:

def run_gate_independently(key, event):
    if key in HUMAN_GATED_KEYS:          # {"DB-001"}
        return "pending-human", "independent"
    return "passed", "independent"

FIX #6 — gitignore: board.db appended idempotently to .gitignore.

Double-fire reconciliation (reconcile cmd): ① verify sibling parquet == db row-for-row per section (abort on mismatch), ② snapshot the sibling audit before writing, ③ re-run migration with independent gates, ④ write delta.parquet containing only rows that changed vs the sibling — exactly the 3 filled gates → commit c4ebfcc.
