Diagnosis (root causes)

The kernel must do five things a naive implementation gets wrong:

  1. Universe constraints must be solved, not structurally compared. u ≤ s(u) holds but s(u) ≤ u does not. Fix: normalise levels to a max of monomials v+k, turn A ≤ B into clauses (disjunctions arise from max on the right), reduce to difference constraints u−v ≤ k, decide with Bellman–Ford, and branch over disjunctions. Extract a minimal unsat core for the error.
  2. Cumulativity is directional. Sort covariant; Pi domain contravariant, codomain covariant. A dedicated leq is kept separate from conv (which emits ≤ both ways).
  3. Conversion must actually implement beta/delta/zeta/iota via whnf + structural comparison, with correct de Bruijn shifting.
  4. De Bruijn context representation (a real bug found): pushing a binder must shift every stored type, not just prepend. Symptom was Π b:B. B instead of Π b:B. A.
  5. Fix unfolding indices (a real bug found): the recursive variable lives outside the lambda. Symptom was plus 2 2 = 2. Fixed with subst(body.body, 1, fix) then subst_top(...).
  6. Termination via guardedness, not fuel. check_decrease/walk require the principal argument to be inductive and every recursive call to pass a match-bound subterm.
