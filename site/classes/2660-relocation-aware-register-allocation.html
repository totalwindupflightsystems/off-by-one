Relocation-Aware Register Allocation: Diagnosis and Verified Fix

Problem class: relocation-aware-register-allocation Environment: Python 3 Artifacts produced: solution.py (allocator library + self-test), test_solution.py (test suite)

1. Root-cause analysis

A register allocator that only "picks a register per virtual register" fails on this problem class for a small set of independent reasons. Each one produces a different class of wrong code, and each needs an explicit mechanism:

  1. CFG- and loop-blind liveness. Liveness must be a fixed point over the whole CFG, not a linear scan of each block. A value defined in one block and used in another (or carried around a back edge) is live at the boundary. Without whole-CFG dataflow, loop-carried values are missed and two values simultaneously live at a loop header silently share a register. Fix: iterative backward dataflow (compute_liveness) plus boundary cliques at every block entry/exit in build_interference.

  2. Spill cost that ignores execution frequency. Spilling a value used inside a hot loop is far more expensive than spilling one used once in the entry block. A flat cost model spills the wrong value. Fix: loop_depths finds natural loops from DFS back-edges; spill_costs weights each def/use by 8 ** loop_depth and charges uses more than defs.

  3. Ignoring rematerialization. Constants, copies and address computations can be recomputed at the use instead of occupying a register or stack slot. Fix: remat_candidates marks values defined exactly once by a pure remat instruction; spill_costs multiplies their cost by 0.05, and spill_transform clones the definition before each dominated use instead of emitting a store/reload.

  4. Instruction-specific constraints. Some operands must live in a fixed physical register, some are two-address (destination aliases a source), some instructions clobber registers, and calls clobber the caller-saved set. Fix: fixed operands become pre-colored nodes; two-address pairs are coalesced in coalesce_two_address (rejected if they genuinely interfere); clobbers/calls add interference edges against the clobbered physical registers.

  5. Physical registers not treated as pre-colored during coloring. If physical registers have no color of their own, the selector never sees clobber/fixed edges as forbidden and assigns a live value to a caller-saved register across a call. Fix: allocate_class seeds color with {r: r for r in regs}. (This exact bug was caught by the verifier during development.)

  6. Splitting live ranges incorrectly across blocks. Once a value is spilled, its definition and uses may be in different blocks or loop iterations. Fix: spill-everywhere-at-def/use — reload before every use, store after every definition. The value travels through one memory slot, so the transform is correct for any CFG shape. Reload temporaries inherit class and fixed-register requirements.

  7. No independent verifier. Fix: verify recomputes liveness/interference from scratch and checks classes, fixed constraints, two-address co-location, interference, call clobbers, allocation coverage, and spill-pseudo integrity.

  8. A greedy colorer can pick the wrong spill victim. Chaitin/Briggs can color a live value and then fail on a short-lived reload temporary. Fix: when only temporaries fail, allocate_function spills an original value interfering with the failed temporary and retries.

2.1 solution.py — allocator, spiller, rematerializer, verifier

"""Relocation-aware register allocator.

A self-contained register allocator for a small machine-level IR with:

* a control-flow graph (basic blocks + successors), including loops;
* an explicit machine description with register classes and caller/callee
  saved registers;
* instruction-specific operand constraints (fixed registers, two-address
  operands, explicit clobbers, calls);
* liveness / interference analysis over the whole CFG;
* spill-cost estimation weighted by loop nesting (execution frequency) and by
  rematerialization opportunities;
* Chaitin/Briggs style graph coloring with spilling and coalescing of
  two-address operands;
* spill/reload insertion (spill-everywhere-at-def/use, which keeps every
  split live range correct across block and loop boundaries) plus a
  dominance-aware rematerialization pass;
* an independent verifier that reports invalid assignments and missed
  instruction constraints.

Run ``python3 solution.py`` to execute the built-in self test.
"""

from __future__ import annotations

from collections import defaultdict
from dataclasses import dataclass, field
from typing import Dict, Iterable, List, Optional, Set, Tuple


class AllocError(Exception):
    """Raised when an allocation is structurally impossible or inconsistent."""


# --------------------------------------------------------------------------
# Machine description
# --------------------------------------------------------------------------
@dataclass(frozen=True)
class RegClass:
    name: str
    regs: Tuple[str, ...]


@dataclass
class Machine:
    classes: Dict[str, RegClass] = field(default_factory=dict)
    caller_saved: Set[str] = field(default_factory=set)
    callee_saved: Set[str] = field(default_factory=set)
    reg_class_of: Dict[str, str] = field(default_factory=dict)

    def __post_init__(self) -> None:
        if not self.reg_class_of:
            for rc in self.classes.values():
                for r in rc.regs:
                    self.reg_class_of[r] = rc.name

    def add_class(self, name: str, regs: Iterable[str]) -> "Machine":
        regs = tuple(regs)
        self.classes[name] = RegClass(name, regs)
        for r in regs:
            self.reg_class_of[r] = name
        return self

    def class_of_reg(self, reg: str) -> str:
        if reg not in self.reg_class_of:
            raise AllocError(f"unknown physical register {reg!r}")
        return self.reg_class_of[reg]


# --------------------------------------------------------------------------
# IR
# --------------------------------------------------------------------------
@dataclass
class Instr:
    op: str
    defs: List[str] = field(default_factory=list)
    uses: List[str] = field(default_factory=list)
    # vreg -> required physical register
    fixed_defs: Dict[str, str] = field(default_factory=dict)
    fixed_uses: Dict[str, str] = field(default_factory=dict)
    # (def, use) pairs whose operands must share a physical register
    two_address: List[Tuple[str, str]] = field(default_factory=list)
    clobbers: Set[str] = field(default_factory=set)
    is_call: bool = False
    is_branch: bool = False
    remat: bool = False
    # immediate operand for constant-producing instructions
    imm: Optional[int] = None
    # pseudo-ops ("__reload"/"__store") carry the memory slot here
    slot: Optional[str] = None

    def clone(self, **kw) -> "Instr":
        base = dict(
            op=self.op,
            defs=list(self.defs),
            uses=list(self.uses),
            fixed_defs=dict(self.fixed_defs),
            fixed_uses=dict(self.fixed_uses),
            two_address=list(self.two_address),
            clobbers=set(self.clobbers),
            is_call=self.is_call,
            is_branch=self.is_branch,
            remat=self.remat,
            imm=self.imm,
            slot=self.slot,
        )
        base.update(kw)
        return Instr(**base)

    def __str__(self) -> str:  # pragma: no cover - cosmetic
        if self.op == "__reload":
            return f"{self.defs[0]} = reload [{self.slot}]"
        if self.op == "__store":
            return f"store [{self.slot}], {self.uses[0]}"
        lhs = ", ".join(self.defs)
        rhs = ", ".join(self.uses)
        c = " (call)" if self.is_call else ""
        return f"{lhs} = {self.op} {rhs}{c}".strip()


@dataclass
class Block:
    name: str
    instrs: List[Instr] = field(default_factory=list)
    succs: List[str] = field(default_factory=list)


@dataclass
class Function:
    name: str
    blocks: List[Block]
    machine: Machine
    vreg_class: Dict[str, str] = field(default_factory=dict)
    entry: Optional[str] = None

    def __post_init__(self) -> None:
        if self.entry is None and self.blocks:
            self.entry = self.blocks[0].name

    def block(self, name: str) -> Block:
        for b in self.blocks:
            if b.name == name:
                return b
        raise KeyError(name)

    def all_vregs(self) -> Set[str]:
        out: Set[str] = set()
        for b in self.blocks:
            for ins in b.instrs:
                out.update(ins.defs)
                out.update(ins.uses)
        return out

    def use_locations(self, vreg: str) -> List[Tuple[str, int]]:
        locs: List[Tuple[str, int]] = []
        for b in self.blocks:
            for i, ins in enumerate(b.instrs):
                if vreg in ins.uses:
                    locs.append((b.name, i))
        return locs

    def fixed_reg(self) -> Dict[str, str]:
        out: Dict[str, str] = {}
        for b in self.blocks:
            for ins in b.instrs:
                pairs = list(ins.fixed_defs.items()) + list(ins.fixed_uses.items())
                for v, r in pairs:
                    if v in out and out[v] != r:
                        raise AllocError(
                            f"inconsistent fixed constraints for {v}: "
                            f"{out[v]} vs {r}"
                        )
                    out[v] = r
        return out


# --------------------------------------------------------------------------
# Liveness
# --------------------------------------------------------------------------
@dataclass
class Liveness:
    live_in: Dict[str, Set[str]]
    live_out: Dict[str, Set[str]]
    before: Dict[Tuple[str, int], Set[str]]
    after: Dict[Tuple[str, int], Set[str]]


def _block_use_def(instrs: List[Instr]) -> Tuple[Set[str], Set[str]]:
    used: Set[str] = set()
    defined: Set[str] = set()
    for ins in instrs:
        for v in ins.uses:
            if v not in defined:
                used.add(v)
        defined.update(ins.defs)
    return used, defined


def compute_liveness(func: Function) -> Liveness:
    """Backward dataflow liveness over the whole CFG."""
    names = [b.name for b in func.blocks]
    ud = {b.name: _block_use_def(b.instrs) for b in func.blocks}
    succ = {b.name: list(b.succs) for b in func.blocks}
    live_in: Dict[str, Set[str]] = {n: set() for n in names}
    live_out: Dict[str, Set[str]] = {n: set() for n in names}

    changed = True
    while changed:
        changed = False
        for n in names:
            out: Set[str] = set()
            for s in succ[n]:
                out |= live_in[s]
            used, defined = ud[n]
            inn = used | (out - defined)
            if out != live_out[n] or inn != live_in[n]:
                live_in[n] = inn
                live_out[n] = out
                changed = True

    before: Dict[Tuple[str, int], Set[str]] = {}
    after: Dict[Tuple[str, int], Set[str]] = {}
    for b in func.blocks:
        cur = set(live_out[b.name])
        for i in range(len(b.instrs) - 1, -1, -1):
            ins = b.instrs[i]
            after[(b.name, i)] = set(cur)
            cur = (cur - set(ins.defs)) | set(ins.uses)
            before[(b.name, i)] = set(cur)
    return Liveness(live_in, live_out, before, after)


# --------------------------------------------------------------------------
# Interference graph
# --------------------------------------------------------------------------
def build_interference(
    func: Function, live: Optional[Liveness] = None
) -> Tuple[Dict[str, Set[str]], Liveness]:
    """Build a co-liveness interference graph (vregs plus physical registers)."""
    live = live or compute_liveness(func)
    adj: Dict[str, Set[str]] = defaultdict(set)

    def clique(vs: Iterable[str]) -> None:
        vs = list(vs)
        for i in range(len(vs)):
            for j in range(i + 1, len(vs)):
                a, b = vs[i], vs[j]
                if a == b:
                    continue
                adj[a].add(b)
                adj[b].add(a)

    for b in func.blocks:
        clique(live.live_in[b.name])
        clique(live.live_out[b.name])
        for i, ins in enumerate(b.instrs):
            clique(live.before[(b.name, i)])
            clique(live.after[(b.name, i)])
            # Values live across a clobbering instruction cannot use a
            # clobbered physical register.
            clob = set(ins.clobbers)
            if ins.is_call:
                clob |= func.machine.caller_saved
            if clob:
                across = live.after[(b.name, i)] - set(ins.defs)
                for v in across:
                    for r in clob:
                        adj[v].add(r)
                        adj[r].add(v)
    return adj, live


# --------------------------------------------------------------------------
# Frequency / spill costs
# --------------------------------------------------------------------------
def loop_depths(func: Function) -> Dict[str, int]:
    """Nesting depth of each block, from natural loops of DFS back-edges."""
    color: Dict[str, int] = {}
    depth: Dict[str, int] = defaultdict(int)
    loops: List[Set[str]] = []
    succ = {b.name: list(b.succs) for b in func.blocks}

    def dfs(u: str, stack: List[str]) -> None:
        color[u] = 1
        stack.append(u)
        for v in succ.get(u, ()):
            c = color.get(v, 0)
            if c == 1:
                idx = stack.index(v)
                loops.append(set(stack[idx:]))
            elif c == 0:
                dfs(v, stack)
        color[u] = 2
        stack.pop()

    if func.entry is not None and func.entry not in color:
        dfs(func.entry, [])
    for b in func.blocks:
        for loop in loops:
            if b.name in loop:
                depth[b.name] += 1
    return depth


def remat_candidates(func: Function) -> Set[str]:
    """vregs defined exactly once by a side-effect-free rematerializable op."""
    defs: Dict[str, List[Instr]] = defaultdict(list)
    for b in func.blocks:
        for ins in b.instrs:
            for d in ins.defs:
                defs[d].append(ins)
    out: Set[str] = set()
    for v, instrs in defs.items():
        if len(instrs) != 1:
            continue
        ins = instrs[0]
        if not ins.remat or ins.op in ("__reload", "__store") or ins.is_call:
            continue
        if v in ins.uses:
            continue
        if any(v in pair for pair in ins.two_address):
            continue
        out.add(v)
    return out


def spill_costs(func: Function) -> Dict[str, float]:
    """Frequency-weighted spill cost; rematerializable values are cheap to spill."""
    depth = loop_depths(func)
    cost: Dict[str, float] = defaultdict(float)
    for b in func.blocks:
        freq = 8.0 ** depth[b.name]
        for ins in b.instrs:
            for u in ins.uses:
                cost[u] += 1.5 * freq
            for d in ins.defs:
                cost[d] += 1.0 * freq
    for v in remat_candidates(func):
        cost[v] *= 0.05
    for v in func.all_vregs():
        cost.setdefault(v, 1.0)
    return cost


# --------------------------------------------------------------------------
# Coloring
# --------------------------------------------------------------------------
def allocate_class(
    nodes: List[str],
    regs: Tuple[str, ...],
    adj: Dict[str, Set[str]],
    cost: Dict[str, float],
    fixed: Dict[str, str],
) -> Tuple[Dict[str, str], List[str]]:
    """Chaitin/Briggs simplify+select for one register class."""
    regset = set(regs)
    # Physical registers are precolored with themselves so that interference
    # edges against them (calls/clobbers) actually forbid those colors.
    color: Dict[str, str] = {r: r for r in regs}

    for v, r in fixed.items():
        if r not in regset:
            raise AllocError(
                f"fixed register {r} for {v} is not in class {regs}"
            )
        color[v] = r

    for v in fixed:
        for w in adj.get(v, ()):
            if w in fixed and w != v and fixed[w] == fixed[v]:
                raise AllocError(
                    f"fixed-register conflict: {v} and {w} both require {fixed[v]}"
                )

    simplify = [v for v in nodes if v not in fixed]
    simplify_set = set(simplify)
    adj_s: Dict[str, Set[str]] = {
        v: {w for w in adj.get(v, ()) if w in simplify_set} for v in simplify
    }

    removed: Set[str] = set()
    order: List[str] = []
    remaining = set(simplify)
    while remaining:
        pick: Optional[str] = None
        for v in remaining:
            deg = len(adj_s[v] - removed)
            precolored = {
                w for w in adj.get(v, ()) if w in regset and w in color
            }
            if deg < len(regs) - len(precolored):
                pick = v
                break
        if pick is None:
            # Potential spill: lowest cost per covered neighbor.
            pick = min(
                remaining, key=lambda v: cost.get(v, 1.0) / (len(adj_s[v]) + 1)
            )
        order.append(pick)
        removed.add(pick)
        remaining.discard(pick)

    spilled: List[str] = []
    for v in reversed(order):
        forbidden: Set[str] = set()
        for w in adj.get(v, ()):
            c = color.get(w)
            if c is not None:
                forbidden.add(c)
        chosen: Optional[str] = None
        for r in regs:
            if r not in forbidden:
                chosen = r
                break
        if chosen is None:
            spilled.append(v)
        else:
            color[v] = chosen
    return {v: color[v] for v in nodes if v in color}, spilled


@dataclass
class AllocationResult:
    func: Function            # the final, spill-rewritten function
    alloc: Dict[str, str]
    spilled: Set[str]         # original vregs that live in memory
    slots: Dict[str, str]     # original vreg -> memory slot name
    adj: Dict[str, Set[str]]
    live: Liveness


# --------------------------------------------------------------------------
# Two-address coalescing
# --------------------------------------------------------------------------
def coalesce_two_address(func: Function) -> Function:
    """Union vregs that a two-address constraint forces into one register.

    If two such vregs interfere the constraint is contradictory and we report
    it rather than silently producing a wrong allocation.
    """
    adj, _ = build_interference(func)

    parent: Dict[str, str] = {}

    def find(x: str) -> str:
        parent.setdefault(x, x)
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    def union(a: str, b: str) -> None:
        ra, rb = find(a), find(b)
        if ra != rb:
            parent[rb] = ra

    for b in func.blocks:
        for ins in b.instrs:
            for d, u in ins.two_address:
                if d == u:
                    continue
                if u in adj.get(d, ()):
                    raise AllocError(
                        f"two-address operands {d}={u} in {ins.op!r} interfere; "
                        "cannot share a register"
                    )
                union(d, u)

    def ren(v: str) -> str:
        return find(v)

    new_class: Dict[str, str] = {}
    for v, c in func.vreg_class.items():
        r = ren(v)
        if r in new_class and new_class[r] != c:
            raise AllocError(f"coalesced vregs {v} have inconsistent classes")
        new_class[r] = c

    new_blocks: List[Block] = []
    for b in func.blocks:
        out: List[Instr] = []
        for ins in b.instrs:
            nd: List[str] = []
            for d in ins.defs:
                rd = ren(d)
                if rd not in nd:
                    nd.append(rd)
            nu: List[str] = []
            for u in ins.uses:
                ru = ren(u)
                if ru not in nu:
                    nu.append(ru)
            fd = {ren(k): v for k, v in ins.fixed_defs.items()}
            fu = {ren(k): v for k, v in ins.fixed_uses.items()}
            ta = [(ren(d), ren(u)) for d, u in ins.two_address]
            out.append(
                ins.clone(defs=nd, uses=nu, fixed_defs=fd, fixed_uses=fu,
                          two_address=ta,
                          clobbers=set(ins.clobbers))
            )
        new_blocks.append(Block(b.name, out, list(b.succs)))
    result = Function(func.name, new_blocks, func.machine, new_class, func.entry)
    return result


# --------------------------------------------------------------------------
# Domination helpers for rematerialization
# --------------------------------------------------------------------------
def compute_dominators(func: Function) -> Dict[str, Set[str]]:
    names = [b.name for b in func.blocks]
    preds: Dict[str, List[str]] = defaultdict(list)
    for b in func.blocks:
        for s in b.succs:
            preds[s].append(b.name)
    dom: Dict[str, Set[str]] = {n: set(names) for n in names}
    dom[func.entry] = {func.entry}  # type: ignore[index]
    changed = True
    while changed:
        changed = False
        for n in names:
            if n == func.entry:
                continue
            if not preds[n]:
                new = {n}
            else:
                new = set(names)
                for p in preds[n]:
                    new &= dom[p]
                new.add(n)
            if new != dom[n]:
                dom[n] = new
                changed = True
    return dom


def _dominates_use(
    dom: Dict[str, Set[str]], dblock: str, didx: int, ublock: str, uidx: int
) -> bool:
    if dblock == ublock:
        return didx < uidx
    return dblock in dom.get(ublock, set())


# --------------------------------------------------------------------------
# Spill / reload / rematerialization rewriting
# --------------------------------------------------------------------------
class _Counter:
    def __init__(self) -> None:
        self.n = 0

    def fresh(self, tag: str) -> str:
        self.n += 1
        return f"__t{self.n}_{tag}"


def _remat_usable(
    func: Function, spilled: Set[str], dom: Dict[str, Set[str]]
) -> Dict[str, Tuple[str, int, Instr]]:
    defs: Dict[str, List[Tuple[str, int, Instr]]] = defaultdict(list)
    for b in func.blocks:
        for i, ins in enumerate(b.instrs):
            for d in ins.defs:
                defs[d].append((b.name, i, ins))

    usable: Dict[str, Tuple[str, int, Instr]] = {}
    for v in spilled:
        locations = defs.get(v, [])
        if len(locations) != 1:
            continue
        b, i, ins = locations[0]
        if not ins.remat or ins.op in ("__reload", "__store") or ins.is_call:
            continue
        if v in ins.uses or any(v in pair for pair in ins.two_address):
            continue
        if any(u in spilled for u in ins.uses):
            continue
        uses = func.use_locations(v)
        if not uses:
            usable[v] = (b, i, ins)
            continue
        if all(_dominates_use(dom, b, i, ub, ui) for ub, ui in uses):
            usable[v] = (b, i, ins)
    return usable


def spill_transform(
    func: Function,
    spilled: Set[str],
    counter: _Counter,
    dom: Dict[str, Set[str]],
) -> Function:
    """Rewrite ``func`` so that every vreg in ``spilled`` is loaded/stored.

    Because a reload is inserted before *every* use and a store after *every*
    definition, the transform is correct even when a live range crosses block
    or loop boundaries: the value simply travels through its memory slot.
    """
    remat = _remat_usable(func, spilled, dom)
    new_class = dict(func.vreg_class)
    new_blocks: List[Block] = []

    for b in func.blocks:
        out: List[Instr] = []
        for i, ins in enumerate(b.instrs):
            use_map: Dict[str, str] = {}
            def_map: Dict[str, Optional[str]] = {}

            # 1. Materialize spilled uses (reload or rematerialize).
            for u in ins.uses:
                if u not in spilled or u in use_map:
                    continue
                if u in remat:
                    rb, ri, rins = remat[u]
                    t = counter.fresh("rm")
                    new_class[t] = func.vreg_class[u]
                    clone = rins.clone(
                        defs=[t],
                        slot=None,
                        two_address=[],
                        fixed_defs={},
                    )
                    if u in rins.fixed_defs:
                        clone.fixed_defs[t] = rins.fixed_defs[u]
                    out.append(clone)
                    use_map[u] = t
                    continue
                t = counter.fresh("rl")
                new_class[t] = func.vreg_class[u]
                reload = Instr(op="__reload", defs=[t], slot=u)
                if u in ins.fixed_uses:
                    reload.fixed_defs[t] = ins.fixed_uses[u]
                out.append(reload)
                use_map[u] = t

            # 2. Introduce definition temporaries for spilled defs.
            for d in ins.defs:
                if d not in spilled:
                    continue
                if d in remat:
                    def_map[d] = None  # value recomputed at uses; no store
                else:
                    t = counter.fresh("df")
                    new_class[t] = func.vreg_class[d]
                    def_map[d] = t

            # 3. Rebuild the instruction with remapped operands.
            new_uses = [use_map.get(u, u) for u in ins.uses]
            new_defs: List[str] = []
            new_fixed_defs = dict(ins.fixed_defs)
            for d in ins.defs:
                if d in def_map:
                    if def_map[d] is None:
                        new_fixed_defs.pop(d, None)
                        continue
                    t = def_map[d]
                    assert t is not None
                    new_defs.append(t)
                    if d in ins.fixed_defs:
                        new_fixed_defs[t] = ins.fixed_defs[d]
                        new_fixed_defs.pop(d, None)
                else:
                    new_defs.append(d)

            new_fixed_uses = dict(ins.fixed_uses)
            for u in ins.uses:
                if u in use_map and u in new_fixed_uses:
                    new_fixed_uses[use_map[u]] = new_fixed_uses.pop(u)

            new_ta: List[Tuple[str, str]] = []
            for d, u in ins.two_address:
                nd = def_map.get(d, d) if d in def_map else d
                nu = use_map.get(u, u)
                if nd is None or nu is None:
                    continue
                new_ta.append((nd, nu))

            new_instr = ins.clone(
                defs=new_defs,
                uses=new_uses,
                fixed_defs=new_fixed_defs,
                fixed_uses=new_fixed_uses,
                two_address=new_ta,
                clobbers=set(ins.clobbers),
            )
            dead_pure = (
                not new_instr.defs
                and new_instr.op
                in ("const", "cstf", "copy", "add", "sub", "fadd", "mul", "div")
            )
            if not dead_pure:
                out.append(new_instr)

            # 4. Store spilled definitions (non-rematerialized ones).
            for d in ins.defs:
                if d in spilled and d not in remat:
                    t = def_map.get(d)
                    if t is not None:
                        out.append(Instr(op="__store", uses=[t], slot=d))
        new_blocks.append(Block(b.name, out, list(b.succs)))

    return Function(func.name, new_blocks, func.machine, new_class, func.entry)

# Allocation driver
# --------------------------------------------------------------------------
def try_allocate(
    func: Function,
) -> Tuple[Dict[str, str], Set[str], Dict[str, Set[str]], Liveness]:
    adj, live = build_interference(func)
    cost = spill_costs(func)
    fixed = func.fixed_reg()
    vregs = func.all_vregs()

    for v in vregs:
        if v not in func.vreg_class:
            raise AllocError(f"vreg {v} has no register class")

    alloc: Dict[str, str] = {}
    spilled: Set[str] = set()
    for cname, rc in func.machine.classes.items():
        nodes = [v for v in vregs if func.vreg_class.get(v) == cname]
        if not nodes:
            continue
        fixed_for_class = {v: fixed[v] for v in nodes if v in fixed}
        color, sp = allocate_class(nodes, rc.regs, adj, cost, fixed_for_class)
        for v, r in color.items():
            if r is not None:
                alloc[v] = r
        spilled.update(sp)
    return alloc, spilled, adj, live


def allocate_function(func: Function) -> AllocationResult:
    """Allocate registers, spilling / rematerializing as needed.

    The transform is always applied to the *original* function with the
    accumulated set of spilled vregs, so spill code is never duplicated.
    """
    func = coalesce_two_address(func)
    dom = compute_dominators(func)
    orig_vregs = set(func.all_vregs())
    spilled_orig: Set[str] = set()
    slots: Dict[str, str] = {}
    counter = _Counter()

    for _ in range(64):
        work = (
            spill_transform(func, spilled_orig, counter, dom)
            if spilled_orig
            else func
        )
        alloc, sp, adj, live = try_allocate(work)
        if not sp:
            return AllocationResult(work, alloc, spilled_orig, slots, adj, live)

        new_orig = {v for v in sp if v in orig_vregs}
        if not new_orig:
            # A temporary could not be colored.  Greedy coloring may simply
            # have made the wrong choice; spill an original value that
            # interferes with the failed temporary and retry.
            cost = spill_costs(work)
            candidates: Dict[str, int] = {}
            for t in sp:
                for w in adj.get(t, ()):
                    if (
                        w in orig_vregs
                        and w not in spilled_orig
                        and w in work.all_vregs()
                    ):
                        candidates[w] = candidates.get(w, 0) + 1
            if not candidates:
                raise AllocError(
                    "cannot color reload temporaries; an instruction needs more "
                    f"simultaneously live registers than the register class "
                    f"provides ({sorted(sp)[:6]})"
                )
            victim = max(
                candidates,
                key=lambda w: (candidates[w], -cost.get(w, 1.0)),
            )
            new_orig = {victim}

        for v in new_orig:
            spilled_orig.add(v)
            slots.setdefault(v, f"spill_{v}")

    raise AllocError("register allocation did not converge")


# --------------------------------------------------------------------------
# Verifier
# --------------------------------------------------------------------------
def verify(
    func: Function,
    machine: Machine,
    alloc: Dict[str, str],
    spilled: Iterable[str] = (),
    slots: Optional[Dict[str, str]] = None,
    live: Optional[Liveness] = None,
    adj: Optional[Dict[str, Set[str]]] = None,
) -> List[str]:
    """Return a list of violations (empty means the allocation is valid).

    The verifier recomputes liveness/interference and independently checks:
      * every vreg is allocated or spilled;
      * assigned physical registers exist and are in the right class;
      * fixed-register operand constraints;
      * two-address same-register constraints;
      * no two interfering vregs share a register;
      * no value live across a call/clobber sits in a clobbered register;
      * spill pseudo-ops refer to known slots.
    """
    spilled = set(spilled)
    live = live or compute_liveness(func)
    if adj is None:
        adj, _ = build_interference(func, live)
    fixed = func.fixed_reg()
    vregs = func.all_vregs()
    violations: List[str] = []

    # 1. Class correctness.
    for v, r in alloc.items():
        if v not in vregs:
            violations.append(f"allocation mentions unknown vreg {v}")
            continue
        cls = func.vreg_class.get(v)
        if cls is None:
            violations.append(f"vreg {v} has no register class")
            continue
        try:
            rcls = machine.class_of_reg(r)
        except AllocError:
            violations.append(f"vreg {v} assigned unknown register {r}")
            continue
        if rcls != cls:
            violations.append(
                f"vreg {v} (class {cls}) assigned {r} of class {rcls}"
            )

    # 2. Every vreg is either allocated or spilled.
    for v in vregs:
        if v not in alloc and v not in spilled:
            violations.append(f"vreg {v} neither allocated nor spilled")

    # 3. Fixed constraints.
    for v, r in fixed.items():
        if v in alloc and alloc[v] != r:
            violations.append(
                f"fixed constraint violated: {v} must be {r}, got {alloc[v]}"
            )

    # 4. Two-address constraints.
    for b in func.blocks:
        for i, ins in enumerate(b.instrs):
            for d, u in ins.two_address:
                if d in alloc and u in alloc and alloc[d] != alloc[u]:
                    violations.append(
                        f"two-address {d}={u} not co-located at "
                        f"{b.name}:{i} ({alloc[d]} vs {alloc[u]})"
                    )

    # 5. Interference.
    for v, ws in adj.items():
        if v not in alloc:
            continue
        for w in ws:
            if w in alloc and alloc[v] == alloc[w]:
                violations.append(
                    f"interference: {v} and {w} both assigned {alloc[v]}"
                )

    # 6. Calls and clobbers.
    for b in func.blocks:
        for i, ins in enumerate(b.instrs):
            across = live.after[(b.name, i)] - set(ins.defs)
            clob = set(ins.clobbers)
            if ins.is_call:
                clob |= machine.caller_saved
            for v in across:
                if v in alloc and alloc[v] in clob:
                    violations.append(
                        f"{v}={alloc[v]} live across clobbering "
                        f"{ins.op!r} at {b.name}:{i}"
                    )

    # 7. Spill pseudo-op sanity.
    if slots is not None:
        for b in func.blocks:
            for i, ins in enumerate(b.instrs):
                if ins.op == "__reload":
                    if ins.slot not in slots:
                        violations.append(f"reload of unknown slot {ins.slot}")
                    for d in ins.defs:
                        if d not in alloc:
                            violations.append(f"reload def {d} not allocated")
                elif ins.op == "__store":
                    if ins.slot not in slots:
                        violations.append(f"store to unknown slot {ins.slot}")
                    for u in ins.uses:
                        if u not in alloc:
                            violations.append(f"store source {u} not allocated")

    return violations


def dump(func: Function, alloc: Optional[Dict[str, str]] = None,
         spilled: Iterable[str] = ()) -> str:
    alloc = alloc or {}
    spilled = set(spilled)
    lines: List[str] = []
    for b in func.blocks:
        lines.append(f"{b.name}:  -> {', '.join(b.succs) or '(exit)'}")
        for ins in b.instrs:
            marks: List[str] = []
            for v in ins.defs + ins.uses:
                if v in alloc:
                    marks.append(f"{v}={alloc[v]}")
                elif v in spilled:
                    marks.append(f"{v}=mem")
            lines.append(f"    {ins}    # {' '.join(marks)}")
    return "\n".join(lines)


# --------------------------------------------------------------------------
# Reference interpreter (semantic verification)
# --------------------------------------------------------------------------
def execute(
    func: Function,
    call_fn=None,
    max_steps: int = 100000,
    model_call_clobber: bool = True,
):
    """Execute a function over the concrete IR and return the `ret` value.

    Only used for testing: it lets us run the *original* virtual-register
    program and the *allocated/spilled* physical-register program and compare
    their results.  When running the allocated program, caller-saved physical
    registers are actually clobbered across a call, so a wrong caller-saved
    assignment produces a wrong result.
    """
    state: Dict[str, int] = {}
    mem: Dict[str, int] = {}
    pc: Optional[str] = func.entry
    steps = 0
    while pc is not None:
        steps += 1
        if steps > max_steps:
            raise RuntimeError("execution step limit exceeded")
        block = func.block(pc)
        nxt: Optional[str] = None
        for ins in block.instrs:
            op = ins.op
            if op == "__reload":
                state[ins.defs[0]] = mem.get(ins.slot, 0)
            elif op == "__store":
                mem[ins.slot] = state.get(ins.uses[0], 0)
            elif op in ("const", "cstf"):
                if ins.defs:
                    state[ins.defs[0]] = ins.imm if ins.imm is not None else 0
            elif op == "copy":
                if ins.defs:
                    state[ins.defs[0]] = state.get(ins.uses[0], 0)
            elif op == "add":
                if ins.defs:
                    state[ins.defs[0]] = (
                        state.get(ins.uses[0], 0) + state.get(ins.uses[1], 0)
                    )
            elif op == "sub":
                if ins.defs:
                    state[ins.defs[0]] = (
                        state.get(ins.uses[0], 0) - state.get(ins.uses[1], 0)
                    )
            elif op == "fadd":
                if ins.defs:
                    state[ins.defs[0]] = (
                        state.get(ins.uses[0], 0) + state.get(ins.uses[1], 0)
                    )
            elif op == "call":
                args = [state.get(u, 0) for u in ins.uses]
                result = call_fn(args) if call_fn else sum(args) * 3 + 7
                if ins.defs:
                    state[ins.defs[0]] = result
                if model_call_clobber:
                    for reg in func.machine.caller_saved:
                        state.pop(reg, None)
            elif op == "ret":
                return state.get(ins.uses[0]) if ins.uses else None
            elif op in ("jmp", "br"):
                if op == "br":
                    cond = state.get(ins.uses[0], 0) if ins.uses else 0
                    nxt = block.succs[0] if cond else (
                        block.succs[1] if len(block.succs) > 1
                        else (block.succs[0] if block.succs else None)
                    )
                else:
                    nxt = block.succs[0] if block.succs else None
            else:
                for d in ins.defs:
                    state[d] = sum(state.get(u, 0) for u in ins.uses)
        pc = nxt
    return None

def _build_loop_function() -> Function:
    """Loop + call + rematerializable constants + a constrained return reg."""
    m = Machine()
    m.add_class("gp", ["r0", "r1", "r2"])
    m.add_class("fp", ["f0", "f1"])
    m.caller_saved = {"r0", "r1", "f0"}
    m.callee_saved = {"r2", "f1"}

    cls = {f"v{i}": "gp" for i in range(13)}

    entry = Block(
        "entry",
        [
            Instr("const", defs=["v0"], imm=1, remat=True),
            Instr("const", defs=["v1"], imm=2, remat=True),
            Instr("const", defs=["v2"], imm=3, remat=True),
            Instr("const", defs=["v3"], imm=4, remat=True),
            Instr("const", defs=["v11"], imm=5),
            Instr("jmp", is_branch=True),
        ],
        ["loop"],
    )
    loop = Block(
        "loop",
        [
            Instr("add", defs=["v4"], uses=["v0", "v1"]),
            Instr("add", defs=["v5"], uses=["v4", "v2"]),
            Instr("add", defs=["v6"], uses=["v5", "v3"]),
            Instr(
                "call",
                defs=["v7"],
                uses=["v6"],
                fixed_defs={"v7": "r0"},
                is_call=True,
            ),
            Instr("add", defs=["v8"], uses=["v7", "v4"]),
            Instr("add", defs=["v9"], uses=["v8", "v6"]),
            Instr("sub", defs=["v12"], uses=["v11", "v0"]),
            Instr("copy", defs=["v11"], uses=["v12"]),
            Instr("br", uses=["v11"], is_branch=True),
        ],
        ["loop", "exit"],
    )
    exit_ = Block(
        "exit",
        [
            Instr("add", defs=["v10"], uses=["v1", "v3"]),
            Instr("ret", uses=["v10"]),
        ],
        [],
    )
    return Function("loopy", [entry, loop, exit_], m, cls, "entry")


def _build_constraint_function() -> Function:
    """Two-address, fixed-use and fixed-def operand constraints."""
    m = Machine()
    m.add_class("gp", ["r0", "r1", "r2"])
    m.caller_saved = {"r0", "r1"}
    m.callee_saved = {"r2"}
    m.add_class("fp", ["f0", "f1"])
    m.caller_saved |= {"f0"}

    cls = {v: "gp" for v in ("a0", "b0", "x", "y", "r")}
    cls.update({v: "fp" for v in ("fa", "fb", "fc")})

    blocks = [
        Block(
            "entry",
            [
                Instr("const", defs=["a0"], imm=10, remat=True),
                Instr("const", defs=["b0"], imm=20, remat=True),
                Instr("cstf", defs=["fa"], imm=1, remat=True),
                Instr("cstf", defs=["fb"], imm=2, remat=True),
                Instr("fadd", defs=["fc"], uses=["fa", "fb"]),
                Instr("add", defs=["x"], uses=["a0", "b0"],
                      fixed_uses={"a0": "r1"}),
                Instr("add", defs=["y"], uses=["x", "a0"],
                      two_address=[("y", "x")]),
                Instr("copy", defs=["r"], uses=["y"], fixed_defs={"r": "r2"}),
                Instr("ret", uses=["r", "fc"]),
            ],
            [],
        )
    ]
    return Function("constrained", blocks, m, cls, "entry")


def _first_interfering_pair(result: AllocationResult):
    for a, ws in result.adj.items():
        if a not in result.alloc:
            continue
        for b in ws:
            if b in result.alloc and b != a:
                return a, b
    return None

3. Verification

3.1 Design-level checks

  • Class compatibility — every assigned register belongs to the vreg's class.
  • Coverage — every vreg is either allocated or spilled to a known slot.
  • Fixed constraints — fixed_defs / fixed_uses are honored exactly.
  • Two-address — coalesced def/use pairs land in the same register.
  • Interference — no two interfering vregs share a register.
  • Calls/clobbers — no value live across a call or clobber sits in a clobbered (caller-saved) register.
  • Split live ranges — every reload/store references a real slot and every temporary is allocated.

3.2 Semantic (execution) check

execute() runs the concrete IR. The suite runs the original virtual-register program and the allocated + spilled physical-register program with the same inputs and requires identical return values. When running the allocated program, caller-saved physical registers are actually clobbered across a call, so a wrong caller-saved assignment changes the result.
