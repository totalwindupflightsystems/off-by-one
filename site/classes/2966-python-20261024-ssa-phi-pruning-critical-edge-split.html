SSA Phi Pruning with Critical-Edge Splitting — Verified Solution

Problem class: python-20261024-ssa-phi-pruning-critical-edge-split · Language: Python 3.11+ · Files: ssa_phi_pruning.py, test_ssa_phi_pruning.py, fuzz_ssa.py

1. Root-cause analysis

Naive dominance-frontier SSA construction inserts a phi at every join where a name is live, regardless of whether incoming values actually differ. Two redundant patterns dominate the result:

  1. All operands identical — x = phi(A: v, B: v) (not a real merge).
  2. All-but-one operand is the phi itself — x = phi(entry: v, latch: x) (loop-carried identity).

Three traps make naive pruning wrong or slow:

  • Trap 1 — chains. Removing x rewrites uses and can make another phi trivial (y = phi(A: x, B: v)), so a single unordered pass misses simplifications.
  • Trap 2 — irreducibility. Rule 2 is only sound when each self edge is a proper back edge, i.e. block(x) dominates every predecessor supplying the self operand. In an irreducible region (A → B → A with entry → A and entry → B) the self-edge value can be undefined on an entry path; deleting there is unsound.
  • Trap 3 — order. Critical edges (outdeg(src)>1 and indeg(dst)>1) must be split only for edges feeding a surviving phi.

No liveness fixpoint is needed: a use-def worklist with in-place substitution touches each phi O(1) times.

2. The fix

Pruning rules (with soundness certificate). For x = phi((p_i,v_i)), resolve operands through the current substitution map:

  • (R1) all resolved operands equal w ≠ x → substitute x := w (always safe).
  • (R2) exactly one distinct non-self operand w exists and block(x) dom p_i for every predecessor p_i whose operand resolves to x → substitute x := w.
  • otherwise keep the phi.

Rule 2's dominance test is the local reducibility certificate. Substitution is applied eagerly to all phi operands and pushed on a use-def worklist, so transitive simplifications are found without a liveness fixpoint.

Irreducible degradation. A self-referential phi failing the dominance test is kept, and t = copy(v) is materialised on the incoming edge (splitting it first when critical) — conservative, never unsound.

Critical-edge splitting. After pruning, iterate surviving phis only; for each critical incoming pred → block, insert a single-successor block on the edge and relabel the phi operand. Splitting replaces pred → block with pred → new → block; neither new edge is critical.

3. Exact fix — ssa_phi_pruning.py

#!/usr/bin/env python3
"""
ssa_phi_pruning.py
==================

A self-contained toolkit for pruning redundant SSA phi nodes and splitting
only the critical edges that surviving phis actually need.

Pipeline
--------
  1. parse(text)          -> Function   (textual CFG/SSA reader)
  2. emit(fn)             -> str        (round-trip writer)
  3. optimize(fn)         -> Stats      (phi pruning + critical-edge split)
  4. execute(fn, inputs)  -> tuple      (reference interpreter)

Design notes
------------
* Phi pruning uses the two classic local rules:
    (R1) all operands identical            -> replace phi by that value
    (R2) exactly one non-self operand      -> replace phi by that value,
         but *only* when every self-referencing predecessor is dominated by
         the phi's block.  This is the local reducibility certificate and it
         is what makes the pass safe on loops with many backedges.
* The two rules are propagated with a use-def worklist, so a phi that becomes
  trivial only after its operand was rewritten is still deleted.  No liveness
  is ever recomputed; each phi is visited O(1) times (plus once per operand
  rewrite) and the worklist is bounded by the use-def edges.
* Irreducible regions degrade conservatively: a self-referential phi whose
  self edge is not dominated by the phi block is *kept*, and an explicit
  `t = copy(v)` is materialised on the incoming edge (splitting it first when
  it is critical).  Semantics are preserved, no unsound deletion happens.
* Critical-edge splitting happens *after* pruning, only for edges feeding a
  surviving phi.  A critical edge is `src -> dst` with `outdeg(src) > 1` and
  `indeg(dst) > 1`.
"""

from __future__ import annotations

import random
import re
import sys
from collections import OrderedDict, defaultdict, deque
from dataclasses import dataclass, field
from typing import Optional

sys.setrecursionlimit(100000)


# ---------------------------------------------------------------------------
# Undefined value sentinel (used by the interpreter)
# ---------------------------------------------------------------------------
class _Undef:
    __slots__ = ()

    def __repr__(self) -> str:  # pragma: no cover - debugging aid
        return "undef"


UNDEF = _Undef()


# ---------------------------------------------------------------------------
# IR data model
# ---------------------------------------------------------------------------
@dataclass
class Phi:
    dst: str
    operands: list  # list of [pred_block, value]

    def copy(self) -> "Phi":
        return Phi(self.dst, [list(o) for o in self.operands])


@dataclass
class Instr:
    dst: str
    op: str
    args: list

    def copy(self) -> "Instr":
        return Instr(self.dst, self.op, list(self.args))


@dataclass
class Term:
    kind: str  # 'jmp' | 'br' | 'ret'
    args: list

    def copy(self) -> "Term":
        return Term(self.kind, list(self.args))


@dataclass
class Block:
    name: str
    phis: list = field(default_factory=list)   # list[Phi]
    instrs: list = field(default_factory=list)  # list[Instr]
    term: Optional[Term] = None

    def copy(self) -> "Block":
        return Block(self.name,
                     [p.copy() for p in self.phis],
                     [i.copy() for i in self.instrs],
                     self.term.copy() if self.term else None)


@dataclass
class Function:
    name: str
    params: list
    blocks: "OrderedDict[str, Block]"
    entry: str
    preds: dict = field(default_factory=dict)   # name -> list[name]
    succs: dict = field(default_factory=dict)   # name -> list[name]

    # -- derived CFG ------------------------------------------------------
    def recompute_edges(self) -> None:
        self.preds = {b: [] for b in self.blocks}
        self.succs = {b: [] for b in self.blocks}
        for b, blk in self.blocks.items():
            for s in successors(blk):
                if s not in self.succs[b]:
                    self.succs[b].append(s)
                if b not in self.preds.setdefault(s, []):
                    self.preds[s].append(b)

    def copy(self) -> "Function":
        blocks = OrderedDict((n, b.copy()) for n, b in self.blocks.items())
        fn = Function(self.name, list(self.params), blocks, self.entry)
        fn.recompute_edges()
        return fn

    # -- convenience ------------------------------------------------------
    def all_value_names(self) -> set:
        names = set(self.params)
        for blk in self.blocks.values():
            for p in blk.phis:
                names.add(p.dst)
            for ins in blk.instrs:
                names.add(ins.dst)
        for blk in self.blocks.values():
            if blk.term:
                if blk.term.kind == "ret":
                    names.update(blk.term.args)
                elif blk.term.kind == "br":
                    names.add(blk.term.args[0])
        return names


def successors(blk: Block) -> list:
    t = blk.term
    if t is None:
        return []
    if t.kind == "jmp":
        return [t.args[0]]
    if t.kind == "br":
        return [t.args[1], t.args[2]]
    return []


# ---------------------------------------------------------------------------
# Textual parser
# ---------------------------------------------------------------------------
_FN_RE = re.compile(r"^fn\s+([A-Za-z_]\w*)\s*\((.*?)\)\s*\{?\s*$")
_HEADER_RE = re.compile(r"^([A-Za-z_]\w*)\s*:\s*$")
_ASSIGN_RE = re.compile(r"^([A-Za-z_]\w*)\s*=\s*(.*)$")
_PHI_RE = re.compile(r"^phi\s*\((.*)\)\s*$")

_BINOPS = {
    "add", "sub", "mul", "div", "rem",
    "lt", "le", "gt", "ge", "eq", "ne",
    "and", "or", "xor", "shl", "shr",
}


def parse(text: str) -> Function:
    """Parse a textual SSA/CFG program into a Function."""
    lines = []
    for raw in text.splitlines():
        line = raw.split("#", 1)[0]
        line = line.split(";", 1)[0].strip()
        if line:
            lines.append(line)

    fn_name = None
    params: list = []
    blocks: "OrderedDict[str, Block]" = OrderedDict()
    cur: Optional[Block] = None

    for line in lines:
        if line.startswith("fn ") or line.startswith("fn\t"):
            m = _FN_RE.match(line)
            if not m:
                raise SyntaxError(f"bad function header: {line!r}")
            fn_name = m.group(1)
            params = [p.strip() for p in m.group(2).split(",") if p.strip()]
            continue
        if line == "}":
            break
        m = _HEADER_RE.match(line)
        if m:
            name = m.group(1)
            cur = Block(name)
            blocks[name] = cur
            continue
        if cur is None:
            raise SyntaxError(f"instruction outside a block: {line!r}")

        if line.startswith("jmp "):
            cur.term = Term("jmp", [line[4:].strip()])
            continue
        if line.startswith("br "):
            parts = [p.strip() for p in line[3:].split(",")]
            if len(parts) != 3:
                raise SyntaxError(f"bad br: {line!r}")
            cur.term = Term("br", parts)
            continue
        if line == "ret" or line.startswith("ret "):
            rest = line[3:].strip()
            cur.term = Term("ret", [p.strip() for p in rest.split(",") if p.strip()])
            continue

        m = _ASSIGN_RE.match(line)
        if not m:
            raise SyntaxError(f"cannot parse line: {line!r}")
        dst, rhs = m.group(1), m.group(2).strip()

        pm = _PHI_RE.match(rhs)
        if pm:
            inner = pm.group(1)
            ops = []
            for pair in inner.split(","):
                pair = pair.strip()
                if not pair:
                    continue
                if ":" not in pair:
                    raise SyntaxError(f"bad phi operand: {pair!r}")
                pred, val = pair.split(":", 1)
                ops.append([pred.strip(), val.strip()])
            cur.phis.append(Phi(dst, ops))
            continue

        toks = rhs.split(None, 1)
        op = toks[0]
        rest = toks[1].strip() if len(toks) > 1 else ""
        if op == "const":
            args = [rest]
        elif op in ("copy", "neg"):
            args = [rest]
        elif op in _BINOPS:
            args = [a.strip() for a in rest.split(",")]
        else:
            raise SyntaxError(f"unknown op {op!r} in {line!r}")
        cur.instrs.append(Instr(dst, op, args))

    if fn_name is None or not blocks:
        raise SyntaxError("empty / malformed program")
    entry = next(iter(blocks))
    fn = Function(fn_name, params, blocks, entry)
    fn.recompute_edges()
    return fn


# ---------------------------------------------------------------------------
# Textual emitter (round-trip)
# ---------------------------------------------------------------------------
def emit(fn: Function) -> str:
    out = [f"fn {fn.name}({', '.join(fn.params)}) {{"]
    for name, blk in fn.blocks.items():
        out.append(f"{name}:")
        for p in blk.phis:
            ops = ", ".join(f"{pr}: {v}" for pr, v in p.operands)
            out.append(f"  {p.dst} = phi({ops})")
        for ins in blk.instrs:
            if ins.op == "const":
                out.append(f"  {ins.dst} = const {ins.args[0]}")
            elif ins.op in ("copy", "neg"):
                out.append(f"  {ins.dst} = {ins.op} {ins.args[0]}")
            else:
                out.append(f"  {ins.dst} = {ins.op} {', '.join(ins.args)}")
        if blk.term is not None:
            if blk.term.kind == "jmp":
                out.append(f"  jmp {blk.term.args[0]}")
            elif blk.term.kind == "br":
                out.append(f"  br {', '.join(blk.term.args)}")
            elif blk.term.kind == "ret":
                out.append(f"  ret {', '.join(blk.term.args)}")
        out.append("")
    out.append("}")
    return "\n".join(out)


def same_program(a: Function, b: Function) -> bool:
    if a.name != b.name or a.params != b.params or a.entry != b.entry:
        return False
    if list(a.blocks) != list(b.blocks):
        return False
    for n in a.blocks:
        ba, bb = a.blocks[n], b.blocks[n]
        if len(ba.phis) != len(bb.phis) or len(ba.instrs) != len(bb.instrs):
            return False
        for pa, pb in zip(ba.phis, bb.phis):
            if pa.dst != pb.dst or [list(o) for o in pa.operands] != [list(o) for o in pb.operands]:
                return False
        for ia, ib in zip(ba.instrs, bb.instrs):
            if (ia.dst, ia.op, ia.args) != (ib.dst, ib.op, ib.args):
                return False
        ta, tb = ba.term, bb.term
        if (ta is None) != (tb is None):
            return False
        if ta is not None and (ta.kind, ta.args) != (tb.kind, tb.args):
            return False
    return True


# ---------------------------------------------------------------------------
# Dominance
# ---------------------------------------------------------------------------
def reverse_postorder(fn: Function) -> list:
    seen = set()
    order = []

    def dfs(b: str) -> None:
        seen.add(b)
        for s in fn.succs.get(b, []):
            if s not in seen:
                dfs(s)
        order.append(b)

    if fn.entry in fn.blocks:
        dfs(fn.entry)
    order.reverse()
    return order


def compute_dominators(fn: Function) -> dict:
    """Cooper-Harvey-Kennedy iterative dominators. Returns idom map."""
    order = reverse_postorder(fn)
    index = {b: i for i, b in enumerate(order)}
    idom = {fn.entry: fn.entry}
    if not order:
        return idom

    def intersect(a: str, b: str) -> str:
        while a != b:
            while index[a] > index[b]:
                a = idom[a]
            while index[b] > index[a]:
                b = idom[b]
        return a

    changed = True
    while changed:
        changed = False
        for b in order:
            if b == fn.entry:
                continue
            new = None
            for p in fn.preds.get(b, []):
                if p in idom:
                    new = p if new is None else intersect(p, new)
            if new is not None and idom.get(b) != new:
                idom[b] = new
                changed = True
    return idom


def dominates(idom: dict, a: str, b: str) -> bool:
    cur = b
    while True:
        if cur == a:
            return True
        if cur not in idom:
            return False
        nxt = idom[cur]
        if nxt == cur:
            return False
        cur = nxt


def is_reducible(fn: Function, idom: dict) -> bool:
    """A flow graph is reducible iff every retreating edge u->v has v dom u."""
    color = {}  # truthy once visited
    in_progress = set()
    retreating = []

    def dfs(u: str) -> None:
        color[u] = True
        in_progress.add(u)
        for v in fn.succs.get(u, []):
            if v not in color:
                dfs(v)
            elif v in in_progress:
                retreating.append((u, v))
        in_progress.discard(u)

    if fn.entry in fn.blocks:
        dfs(fn.entry)
    for u, v in retreating:
        if not dominates(idom, v, u):
            return False
    return True


# ---------------------------------------------------------------------------
# Phi pruning
# ---------------------------------------------------------------------------
def _resolve(subst: dict, v: str) -> str:
    seen = set()
    while v in subst and v not in seen:
        seen.add(v)
        v = subst[v]
    return v


@dataclass
class Stats:
    phis_before: int = 0
    phis_after: int = 0
    phis_removed: list = field(default_factory=list)
    conservative_phis: list = field(default_factory=list)
    split_edges: list = field(default_factory=list)
    copies_inserted: list = field(default_factory=list)
    reducible: bool = True


def optimize(fn: Function, *, split_edges: bool = True) -> Stats:
    """Prune trivial phis and split critical edges feeding surviving phis.

    Mutates ``fn`` in place and returns :class:`Stats`.
    """
    fn.recompute_edges()
    idom = compute_dominators(fn)
    stats = Stats(reducible=is_reducible(fn, idom))

    phis = [(b, p) for b, blk in fn.blocks.items() for p in blk.phis]
    stats.phis_before = len(phis)
    if not phis:
        if split_edges:
            _split_critical_edges(fn, set(), stats)
        stats.phis_after = 0
        return stats

    use_map: dict = defaultdict(set)
    for i, (_, p) in enumerate(phis):
        for _, v in p.operands:
            use_map[v].add(i)

    order = reverse_postorder(fn)
    rank = {b: k for k, b in enumerate(order)}
    worklist = deque(sorted(range(len(phis)),
                            key=lambda i: rank.get(phis[i][0], 1 << 30)))
    in_wl = set(worklist)
    subst: dict = {}
    conservative_ids = set()

    def push(i: int) -> None:
        if i not in in_wl:
            in_wl.add(i)
            worklist.append(i)

    def apply_subst(i: int, w: str) -> None:
        _, p = phis[i]
        d = p.dst
        w2 = _resolve(subst, w)
        subst[d] = w2
        for j in list(use_map.get(d, set())):
            if j == i:
                continue
            _, up = phis[j]
            changed = False
            for op in up.operands:
                if op[1] == d:
                    op[1] = w2
                    use_map[w2].add(j)
                    changed = True
            if changed:
                push(j)
        use_map[d] = set()

    while worklist:
        i = worklist.popleft()
        in_wl.discard(i)
        b, p = phis[i]
        if p.dst in subst:
            continue

        ops = [[pr, _resolve(subst, v)] for pr, v in p.operands]
        vals = [v for _, v in ops]

        # (R1) all operands identical
        if len(set(vals)) == 1:
            w = vals[0]
            if w != p.dst:
                apply_subst(i, w)
            else:
                # pure self cycle: keep, but flag if not a proper loop header
                self_edges = [pr for pr, v in ops if v == p.dst]
                if any(not dominates(idom, b, pr) for pr in self_edges):
                    conservative_ids.add(i)
            continue

        # (R2) exactly one distinct non-self operand
        nonself = {v for v in vals if v != p.dst}
        self_edges = [pr for pr, v in ops if v == p.dst]
        if len(nonself) == 1:
            w = next(iter(nonself))
            safe = all(dominates(idom, b, pr) for pr in self_edges)
            if w != p.dst and safe:
                apply_subst(i, w)
                continue
            conservative_ids.add(i)
        else:
            if any(not dominates(idom, b, pr) for pr in self_edges):
                conservative_ids.add(i)
        # otherwise: genuinely conflicting live-ins -> keep the phi

    # Final rewrite of every remaining use (incl. non-phi instructions).
    for blk in fn.blocks.values():
        for p in blk.phis:
            for op in p.operands:
                op[1] = _resolve(subst, op[1])
        for ins in blk.instrs:
            if ins.op != "const":
                ins.args = [_resolve(subst, a) for a in ins.args]
        if blk.term is not None:
            if blk.term.kind == "br":
                blk.term.args[0] = _resolve(subst, blk.term.args[0])
            elif blk.term.kind == "ret":
                blk.term.args = [_resolve(subst, a) for a in blk.term.args]

    removed = []
    for blk in fn.blocks.values():
        keep = []
        for p in blk.phis:
            if p.dst in subst:
                removed.append(p.dst)
            else:
                keep.append(p)
        blk.phis = keep

    stats.phis_removed = removed
    conservative = {phis[i][1].dst for i in conservative_ids
                    if phis[i][1].dst not in subst}
    stats.conservative_phis = sorted(conservative)

    if split_edges:
        _split_critical_edges(fn, conservative, stats)

    fn.recompute_edges()
    stats.phis_after = sum(len(blk.phis) for blk in fn.blocks.values())
    return stats

# Critical edge splitting
# ---------------------------------------------------------------------------
def _split_critical_edges(fn: Function, conservative_dsts: set, stats: Stats) -> None:
    fn.recompute_edges()
    used_blocks = set(fn.blocks)
    used_vals = fn.all_value_names()
    split_map: dict = {}

    def fresh_block(base: str) -> str:
        name = base
        k = 0
        while name in used_blocks:
            k += 1
            name = f"{base}__{k}"
        used_blocks.add(name)
        return name

    def fresh_val() -> str:
        k = 0
        while f"t{k}" in used_vals:
            k += 1
        name = f"t{k}"
        used_vals.add(name)
        return name

    def get_split(pred: str, target: str) -> str:
        key = (pred, target)
        if key in split_map:
            return split_map[key]
        name = fresh_block(f"{pred}__to__{target}")
        blk = Block(name)
        blk.term = Term("jmp", [target])
        fn.blocks[name] = blk
        t = fn.blocks[pred].term
        if t is not None:
            if t.kind == "jmp":
                if t.args[0] == target:
                    t.args[0] = name
            elif t.kind == "br":
                if t.args[1] == target:
                    t.args[1] = name
                if t.args[2] == target:
                    t.args[2] = name
        split_map[key] = name
        if key not in stats.split_edges:
            stats.split_edges.append(key)
        return name

    for bname, blk in list(fn.blocks.items()):
        for p in blk.phis:
            new_ops = []
            for pred, val in p.operands:
                if pred not in fn.blocks:
                    new_ops.append([pred, val])
                    continue
                critical = (len(fn.succs.get(pred, [])) > 1
                            and len(fn.preds.get(bname, [])) > 1)
                if critical:
                    nb = get_split(pred, bname)
                    if p.dst in conservative_dsts:
                        fv = fresh_val()
                        fn.blocks[nb].instrs.append(Instr(fv, "copy", [val]))
                        stats.copies_inserted.append((nb, fv, val))
                        val = fv
                    pred = nb
                elif (p.dst in conservative_dsts and pred != bname
                      and len(fn.succs.get(pred, [])) == 1):
                    fv = fresh_val()
                    fn.blocks[pred].instrs.append(Instr(fv, "copy", [val]))
                    stats.copies_inserted.append((pred, fv, val))
                    val = fv
                new_ops.append([pred, val])
            p.operands = new_ops

    fn.recompute_edges()


def surviving_phi_critical_edges(fn: Function) -> list:
    """Return any (pred, target) critical edges feeding a surviving phi."""
    fn.recompute_edges()
    bad = []
    for bname, blk in fn.blocks.items():
        for p in blk.phis:
            for pred, _ in p.operands:
                if pred not in fn.blocks:
                    bad.append((pred, bname))
                    continue
                if (len(fn.succs.get(pred, [])) > 1
                        and len(fn.preds.get(bname, [])) > 1):
                    bad.append((pred, bname))
    return bad


# ---------------------------------------------------------------------------
# Reference interpreter

def _eval_val(v, env: dict):
    if v in env:
        return env[v]
    try:
        return int(v)
    except (TypeError, ValueError):
        return UNDEF


def _eval_instr(ins: Instr, env: dict):
    op = ins.op
    if op == "const":
        try:
            return int(ins.args[0])
        except ValueError:
            return UNDEF
    args = [_eval_val(a, env) for a in ins.args]
    if op == "copy":
        return args[0]
    if op == "neg":
        return UNDEF if args[0] is UNDEF else -args[0]
    if any(a is UNDEF for a in args):
        return UNDEF
    a, b = (args + [None, None])[:2]
    try:
        if op == "add":
            return a + b
        if op == "sub":
            return a - b
        if op == "mul":
            return a * b
        if op == "div":
            if b == 0:
                return UNDEF
            q = abs(a) // abs(b)
            return q if (a < 0) == (b < 0) else -q
        if op == "rem":
            if b == 0:
                return UNDEF
            q = abs(a) // abs(b)
            q = q if (a < 0) == (b < 0) else -q
            return a - q * b
        if op == "lt":
            return 1 if a < b else 0
        if op == "le":
            return 1 if a <= b else 0
        if op == "gt":
            return 1 if a > b else 0
        if op == "ge":
            return 1 if a >= b else 0
        if op == "eq":
            return 1 if a == b else 0
        if op == "ne":
            return 1 if a != b else 0
        if op == "and":
            return a & b
        if op == "or":
            return a | b
        if op == "xor":
            return a ^ b
        if op == "shl":
            return a << (b & 31)
        if op == "shr":
            return a >> (b & 31)
    except (TypeError, ValueError):
        return UNDEF
    return UNDEF


def execute(fn: Function, inputs: dict, max_steps: int = 200000) -> tuple:
    """Run a function; returns the tuple of return values.

    Raises ``RuntimeError`` on undefined branch conditions or step overflow so
    the equivalence checker can compare error behaviour as well.
    """
    env = dict(inputs)
    cur = fn.entry
    prev = None
    steps = 0
    while True:
        steps += 1
        if steps > max_steps:
            raise RuntimeError("step limit exceeded")
        blk = fn.blocks[cur]

        # Phi nodes are parallel: read all RHS first, then assign.
        pending = []
        for p in blk.phis:
            val = None
            found = False
            for pr, v in p.operands:
                if pr == prev:
                    val = v
                    found = True
                    break
            if not found:
                if len(p.operands) == 1:
                    val = p.operands[0][1]
                    found = True
            pending.append((p.dst, _eval_val(val, env) if found else UNDEF))
        for d, v in pending:
            env[d] = v

        for ins in blk.instrs:
            env[ins.dst] = _eval_instr(ins, env)

        t = blk.term
        if t is None:
            raise RuntimeError("block without terminator")
        if t.kind == "jmp":
            prev, cur = cur, t.args[0]
        elif t.kind == "br":
            c = _eval_val(t.args[0], env)
            if c is UNDEF:
                raise RuntimeError("undefined branch condition")
            prev, cur = cur, (t.args[1] if c != 0 else t.args[2])
        elif t.kind == "ret":
            return tuple(_eval_val(a, env) for a in t.args)
        else:
            raise RuntimeError(f"bad terminator {t.kind!r}")

def check_equivalence(text: str, input_rows, max_steps: int = 200000):
    """Compare pre-pass and post-pass behaviour on given input rows.

    Returns ``(ok, counterexample)`` where counterexample is either ``None``
    or ``(inputs, pre_result, post_result)``.
    """
    pre = parse(text)
    post = parse(text)
    optimize(post)
    for row in input_rows:
        if isinstance(row, dict):
            inputs = dict(row)
        else:
            inputs = dict(zip(pre.params, row))
        try:
            r_pre, e_pre = execute(pre, inputs, max_steps), None
        except Exception as exc:  # noqa: BLE001
            r_pre, e_pre = None, f"{type(exc).__name__}:{exc}"
        try:
            r_post, e_post = execute(post, inputs, max_steps), None
        except Exception as exc:  # noqa: BLE001
            r_post, e_post = None, f"{type(exc).__name__}:{exc}"
        if e_pre != e_post or r_pre != r_post:
            return False, (inputs, (r_pre, e_pre), (r_post, e_post))
    return True, None


def random_inputs(fn: Function, n: int = 200, lo: int = -3, hi: int = 6,
                  seed: int = 0) -> list:
    rng = random.Random(seed)
    return [tuple(rng.randint(lo, hi) for _ in fn.params) for _ in range(n)]

6. Correctness & complexity

  • R1: every predecessor delivers w; sound everywhere.
  • R2: if block(x) dominates each self predecessor, arriving via a self edge means the block was already entered and x already held w; by induction the value is always w, and the non-self operand is the unique live-in.
  • Irreducible: failing the dominance certificate means the previous value is undefined on some entry path, so the phi is kept and the merge materialised with copies — conservative, never unsound.
  • Termination/cost: substitution is in-place; the worklist is bounded by use-def edges, so the pass is O(V + E) on top of dominator computation. No liveness analysis and no outer fixpoint iteration.
  • Critical split: only edges feeding surviving phis are touched, and each split removes criticality without creating new critical edges.
