Reconstructing per-query bailiwick state from interleaved, out-of-order resolver captures

1. Symptom

A recursive resolver is being flooded Kaminsky-style. The capture is written by a tap that sees all exchanges concurrently, so lines from different queries are interleaved and timestamps are not monotonic. A detector must answer three questions from that single flat file:

  1. Which AUTHORITY / ADDITIONAL RRsets have an owner name that escapes the bailiwick (the query's zone)?
  2. When was each contaminated RRset first seen?
  3. Is the observed txid randomisation weak enough (and the response mismatch rate high enough) that the resolver probably accepted the poison?

The task forbids awk and jq: the whole pipeline must be pure Bash text processing.

2. Root-cause analysis

2.1 The one-pass streamer misattributes records (the real bug)

The intuitive implementation walks the file once, remembers the last query seen, and tests each following RR against that query. Under interleaving this is wrong: an RR belonging to query A is frequently preceded in the file by a query B from a different zone. The zone is then taken from B and perfectly legitimate records are reported as out-of-bailiwick.

Running the deliberately broken naive-detect.sh on the poisoning capture shows the failure immediately — it invents four extra "contaminated" RRsets that are actually in-bailiwick referrals:

$ ./naive-detect.sh capture_poison.log
  com./ns
  example.com./ns      <- FALSE POSITIVE
  good.net./ns         <- FALSE POSITIVE
  ns1.example.com./a   <- FALSE POSITIVE
  ns1.good.net./a      <- FALSE POSITIVE
  ns.evil.net./a

The correct result is exactly two contaminated RRsets. Root cause: state was keyed by position in the stream instead of by query identity. The fix is to make the correlation explicit and two-phase:

  • Pass 1 indexes every Q/H/RR by its stable key (msgid, and txid:sport), ignoring file order.
  • Pass 2 joins RR -> H -> Q by key. An RR is only judged against the zone of the query it actually belongs to. A response that matches no pending query is still checked, but against the zone implied by its own echoed question.

2.2 Out-of-order timestamps

Because the tap is multi-threaded, the first physical occurrence of a record is not its earliest time. "First seen" must be computed as min(ts) over every occurrence, not the first line read. The detector compares ISO-8601 strings, which sort correctly, and keeps the minimum per RRset.

2.3 Why txid entropy is part of the verdict

A bailiwick violation alone is an attempt. Whether it is successful depends on whether the attacker could have guessed the resolver's ephemeral (txid, source-port). We therefore estimate the sample entropy of the resolver's txids and attach a 95% lower confidence bound obtained by a non-parametric bootstrap (200 resamples, 5th percentile). txids are binned by their high byte so that a weak generator (a counter, or a small window) collapses into one or two bins and scores near 0 bits, while a strong 16-bit generator spreads across bins. The verdict requires all of:

  • at least one out-of-bailiwick RRset,
  • on a response that matched a pending query (i.e. it was accepted), and
  • H_lower95 < ENTROPY_LB_MIN (default 4.0 bits), and
  • response mismatch rate >= MISMATCH_MIN (default 0.50).

2.4 Pure-shell maths

awk/jq are banned, and even bc is avoided: log2(n) is computed in fixed point with a 20-round squaring loop (LOG2_MICRO). Modular exponentiation of counts stays inside signed 64-bit range because the mantissa is scaled by 2^30 and renormalised every round.

3. Capture contract

Line-oriented, pipe delimited, one logical DNS message per record:

TS|Q |txid |sport|zone    |qname|qtype
TS|H |msgid|txid |sport|qname|qtype|rcode|an|ns|ar
TS|RR|msgid|section|name  |type |ttl  |rdata
  • TS is ISO-8601 (lexicographically sortable).
  • msgid ties the RRs of one response to its header.
  • A response matches a query iff (txid, sport, qname, qtype) agree.

If your collector already emits dig text, flatten it to this grammar first (one field per line); the detector itself never needs to know about dig's multi-line formatting.

4. The fix

4.1 bailiwick-detect.sh

#!/usr/bin/env bash
# bailiwick-detect.sh -- detect DNS cache-poisoning evidence in interleaved,
# out-of-order dig captures using pure bash text processing (no awk, no jq).
#
#   usage: bailiwick-detect.sh <capture.log>
#   tunables (env): ENTROPY_LB_MIN (bits, default 4.0)
#                   MISMATCH_MIN   (fraction, default 0.50)
#
# Input line grammar (pipe delimited):
#   TS|Q |txid |sport|zone    |qname|qtype
#   TS|H |msgid|txid |sport|qname|qtype|rcode|an|ns|ar
#   TS|RR|msgid|section|name  |type |ttl  |rdata
# TS is ISO-8601 (lexicographically sortable). Records for one exchange share
# msgid; a response matches a query iff (txid,sport,qname,qtype) agree.
set -u
LC_ALL=C

CAP="${1:-}"
if [[ "$CAP" != "--selftest" && ( -z "$CAP" || ! -r "$CAP" ) ]]; then
  echo "usage: $0 <capture.log>" >&2
  echo "       $0 --selftest" >&2
  exit 2
fi
ENTROPY_LB_MIN="${ENTROPY_LB_MIN:-4.0}"
MISMATCH_MIN="${MISMATCH_MIN:-0.50}"
RANDOM="${BOOTSTRAP_SEED:-1}"   # deterministic bootstrap; override to re-seed

# Public suffixes with two labels; extend for your environment.
MULTI_SUFFIXES=" co.uk org.uk ac.uk gov.uk com.au net.au org.au co.jp co.nz com.br "

# --------------------------------------------------------------------------
# Pure-bash fixed point log2: round(log2(n) * 1e6).
# --------------------------------------------------------------------------
LOG2_MICRO() {
  local n=$1
  (( n <= 1 )) && { echo 0; return; }
  local p=0 v=1
  while (( v * 2 <= n )); do v=$(( v * 2 )); p=$(( p + 1 )); done
  local SCALE=$(( 1 << 30 )) TWO=$(( 2 << 30 ))
  local X=$(( n * SCALE / v ))
  local frac=0 k bit
  for (( k = 0; k < 20; k++ )); do
    X=$(( X * X / SCALE ))
    bit=0
    if (( X >= TWO )); then bit=1; X=$(( X / 2 )); fi
    frac=$(( (frac << 1) | bit ))
  done
  echo $(( p * 1000000 + frac * 1000000 / 1048576 ))
}

parse_micro() {  # "4.0"   -> 4000000
  local s="$1" ip fp
  ip="${s%%.*}"; [[ "$ip" == "$s" ]] && fp='' || fp="${s#*.}"
  fp="${fp}000000"; fp="${fp:0:6}"
  printf '%d' $(( ip * 1000000 + 10#$fp ))
}
parse_milli() {  # "0.50"  -> 500
  local s="$1" ip fp
  ip="${s%%.*}"; [[ "$ip" == "$s" ]] && fp='' || fp="${s#*.}"
  fp="${fp}000"; fp="${fp:0:3}"
  printf '%d' $(( ip * 1000 + 10#$fp ))
}
micro_dec() { local m=$1; printf '%d.%06d' $(( m / 1000000 )) $(( m % 1000000 )); }

join_sorted() {  # canonicalise a 'a;b;' set to 'a;b'
  local s="${1%;}" tmp
  tmp=$(printf '%s\n' ${s//;/ } | sort)
  printf '%s' "${tmp//$'\n'/;}"
}

# zone_of qname -> bailiwick apex (last two labels, or last three for a known
# two-label public suffix).
zone_of() {
  local q
  q="${1,,}"; q="${q%.}"
  local -a lab; IFS='.' read -r -a lab <<< "$q"
  local n=${#lab[@]}
  (( n < 2 )) && { printf '%s' "$q"; return; }
  local last2="${lab[n-2]}.${lab[n-1]}"
  if [[ " $MULTI_SUFFIXES " == *" $last2 "* ]] && (( n >= 3 )); then
    printf '%s.%s' "${lab[n-3]}" "$last2"
  else
    printf '%s' "$last2"
  fi
}

in_bailiwick() {
  local owner="${1,,}" zone="${2,,}"
  owner="${owner%.}"; zone="${zone%.}"
  [[ -z "$zone" || "$owner" == "$zone" || "$owner" == *".$zone" ]]
}

if [[ "$CAP" == "--selftest" ]]; then
  rc=0
  chk() { if [[ "$2" == "$3" ]]; then printf 'PASS %s\n' "$1"; else printf 'FAIL %s (want %s got %s)\n' "$1" "$2" "$3"; rc=1; fi; }
  chk 'log2(1)=0'          0       "$(LOG2_MICRO 1)"
  chk 'log2(2)=1.000000'   1000000 "$(LOG2_MICRO 2)"
  chk 'log2(3)=1.584961'   1584961 "$(LOG2_MICRO 3)"
  chk 'log2(48)=5.584961'  5584961 "$(LOG2_MICRO 48)"
  chk 'log2(68)=6.087462'  6087462 "$(LOG2_MICRO 68)"
  chk 'log2(1000)=9.965784' 9965784 "$(LOG2_MICRO 1000)"
  chk 'zone www.example.com'   example.com   "$(zone_of www.example.com)"
  chk 'zone a.b.example.com'   example.com   "$(zone_of a.b.example.com)"
  chk 'zone www.example.co.uk' example.co.uk "$(zone_of www.example.co.uk)"
  chk 'zone example.com'       example.com   "$(zone_of example.com)"
  in_bailiwick ns1.example.com. example.com && chk bailiwick_inner in_scope in_scope || chk bailiwick_inner in_scope out_of_scope
  in_bailiwick com.             example.com && chk bailiwick_parent in_scope out_of_scope || chk bailiwick_parent out_of_scope out_of_scope
  in_bailiwick ns1.example.com.  good.net   && chk bailiwick_sibling in_scope out_of_scope || chk bailiwick_sibling out_of_scope out_of_scope
  exit $rc
fi

# --------------------------------------------------------------------------
# Pass 1: index queries / headers / RRs regardless of file order.
# --------------------------------------------------------------------------
declare -A Q_ZONE=() Q_NAME=() Q_TYPE=()
declare -A H_BY_MSG=()
declare -a H_KEY=() H_QNAME=() H_QTYPE=() H_TS=()
declare -a RR_MSG=() RR_SEC=() RR_NAME=() RR_TYPE=() RR_TS=()
declare -a QT=()
nhead=0 nrr=0

while IFS='|' read -r f_ts f_kind f1 f2 f3 f4 f5 f6 f7 f8 f9; do
  case "$f_kind" in
    Q)
      key="$f1:$f2"
      Q_ZONE[$key]="$f3"; Q_NAME[$key]="$f4"; Q_TYPE[$key]="$f5"
      QT+=("$f1")
      ;;
    H)
      key="$f2:$f3"
      H_BY_MSG["$f1"]=$nhead
      H_KEY[$nhead]="$key"; H_QNAME[$nhead]="$f4"; H_QTYPE[$nhead]="$f5"; H_TS[$nhead]="$f_ts"
      nhead=$(( nhead + 1 ))
      ;;
    RR)
      RR_MSG[$nrr]="$f1"; RR_SEC[$nrr]="$f2"; RR_NAME[$nrr]="$f3"
      RR_TYPE[$nrr]="$f4"; RR_TS[$nrr]="$f_ts"
      nrr=$(( nrr + 1 ))
      ;;
  esac
done < "$CAP"

# --------------------------------------------------------------------------
# Pass 2: for every response decide whether it matches a pending query.
# --------------------------------------------------------------------------
declare -a RESP_MATCHED=()
total_resp=0 matched=0
for (( i = 0; i < nhead; i++ )); do
  total_resp=$(( total_resp + 1 ))
  k="${H_KEY[$i]}"
  if [[ -n "${Q_NAME[$k]:-}" && "${Q_NAME[$k]}" == "${H_QNAME[$i]}" \
        && "${Q_TYPE[$k]}" == "${H_QTYPE[$i]}" ]]; then
    RESP_MATCHED[$i]=1; matched=$(( matched + 1 ))
  else
    RESP_MATCHED[$i]=0
  fi
done

# --------------------------------------------------------------------------
# Pass 3: bailiwick check on AUTHORITY / ADDITIONAL records.
# --------------------------------------------------------------------------
declare -A CONTAM_TS=() CONTAM_SEC=() MATCHED_CONTAM=() FLAGGED_MSG=() FLAGGED_MATCHED=()
for (( i = 0; i < nrr; i++ )); do
  sec="${RR_SEC[$i]}"
  [[ "$sec" == "AUTHORITY" || "$sec" == "ADDITIONAL" ]] || continue
  hi="${H_BY_MSG[${RR_MSG[$i]}]:-}"
  [[ -n "$hi" ]] || continue
  # Prefer the pending query's zone. If the response matches no query, fall
  # back to the zone implied by its echoed question so spoofed answers are
  # still flagged.
  zone="${Q_ZONE[${H_KEY[$hi]}]:-}"
  [[ -n "$zone" ]] || zone="$(zone_of "${H_QNAME[$hi]}")"
  [[ -n "$zone" ]] || continue
  owner="${RR_NAME[$i]}"
  if ! in_bailiwick "$owner" "$zone"; then
    rrset="${owner,,}/${RR_TYPE[$i],,}"
    if [[ -z "${CONTAM_TS[$rrset]:-}" || "${RR_TS[$i]}" < "${CONTAM_TS[$rrset]}" ]]; then
      CONTAM_TS[$rrset]="${RR_TS[$i]}"
    fi
    [[ "${CONTAM_SEC[$rrset]:-}" == *"${sec},"* ]] || CONTAM_SEC[$rrset]="${CONTAM_SEC[$rrset]:-}${sec},"
    mid="${RR_MSG[$i]}"
    [[ "${FLAGGED_MSG[$mid]:-}" == *"${rrset};"* ]] || FLAGGED_MSG[$mid]="${FLAGGED_MSG[$mid]:-}${rrset};"
    if [[ "${RESP_MATCHED[$hi]}" == "1" ]]; then
      MATCHED_CONTAM[$rrset]=1
      FLAGGED_MATCHED[$mid]=1
    fi
  fi
done

mismatch=$(( total_resp - matched ))
rate_milli=0
(( total_resp > 0 )) && rate_milli=$(( mismatch * 1000 / total_resp ))
mat_contam=${#MATCHED_CONTAM[@]}
contam=${#CONTAM_TS[@]}

# --------------------------------------------------------------------------
# Pass 4: sample entropy of observed query txids over high-byte bins, with a
# non-parametric bootstrap 95% lower confidence bound.
# --------------------------------------------------------------------------
declare -a BINS=()
for tx in "${QT[@]:-}"; do
  tx="${tx#0x}"
  [[ "$tx" =~ ^[0-9a-fA-F]+$ ]] || continue
  BINS+=( $(( (16#$tx) >> 8 )) )
done
N=${#BINS[@]}
# Stable order so the seeded bootstrap is independent of capture line order.
for (( i = 1; i < N; i++ )); do
  key="${BINS[$i]}"; j=$(( i - 1 ))
  while (( j >= 0 )) && (( BINS[j] > key )); do BINS[$((j+1))]="${BINS[$j]}"; j=$(( j - 1 )); done
  BINS[$((j+1))]="$key"
done
declare -A CUR=()
for b in "${BINS[@]:-}"; do CUR[$b]=$(( ${CUR[$b]:-0} + 1 )); done
orig_bins=${#CUR[@]}

declare -a LOG2=()
for (( n = 1; n <= N; n++ )); do LOG2[$n]=$(LOG2_MICRO "$n"); done

entropy_micro() {
  local n=$1 sum=0 c
  for c in "${!CUR[@]}"; do sum=$(( sum + CUR[$c] * ${LOG2[${CUR[$c]}]} )); done
  echo $(( (n * ${LOG2[$n]} - sum) / n ))
}

H0=0 H_LB=0
if (( N > 0 )); then
  H0=$(entropy_micro "$N")
  B=200
  declare -a HB=()
  for (( b = 0; b < B; b++ )); do
    CUR=()
    for (( i = 0; i < N; i++ )); do
      bin="${BINS[$(( RANDOM % N ))]}"
      CUR[$bin]=$(( ${CUR[$bin]:-0} + 1 ))
    done
    HB[$b]=$(entropy_micro "$N")
  done
  for (( i = 1; i < B; i++ )); do   # insertion sort ascending
    key="${HB[$i]}"; j=$(( i - 1 ))
    while (( j >= 0 )) && (( HB[j] > key )); do HB[$((j+1))]="${HB[$j]}"; j=$(( j - 1 )); done
    HB[$((j+1))]="$key"
  done
  H_LB="${HB[$(( B * 5 / 100 ))]}"
fi

THRESH_MICRO=$(parse_micro "$ENTROPY_LB_MIN")
MIS_THRESH=$(parse_milli "$MISMATCH_MIN")
weak=0;    (( H_LB < THRESH_MICRO )) && weak=1
highmis=0; (( rate_milli >= MIS_THRESH )) && highmis=1
if (( contam > 0 && mat_contam > 0 && weak == 1 && highmis == 1 )); then
  verdict="LIKELY_SUCCESSFUL_CACHE_POISONING"
else
  verdict="BENIGN_DELEGATION_CHURN"
fi

# --------------------------------------------------------------------------
# Report
# --------------------------------------------------------------------------
printf 'capture            : %s\n' "$CAP"
printf 'queries/responses  : %d / %d  (matched %d, mismatch %d = %d.%d%%)\n' \
  "${#QT[@]}" "$total_resp" "$matched" "$mismatch" $(( rate_milli / 10 )) $(( rate_milli % 10 ))
printf 'contaminated RRsets: %d distinct (%d seen on a matched response)\n' "$contam" "$mat_contam"
echo
echo '== Contaminated RRsets (authority/additional owner escapes query zone) =='
if (( contam == 0 )); then
  echo '  (none)'
else
  while IFS= read -r k; do
    secs="${CONTAM_SEC[$k]%,}"
    tag=''
    [[ "${MATCHED_CONTAM[$k]:-}" == "1" ]] && tag=' [accepted: matched response]'
    printf '  %-24s first-seen=%s sections=%s%s\n' "$k" "${CONTAM_TS[$k]}" "$secs" "$tag"
  done < <(printf '%s\n' "${!CONTAM_TS[@]}" | sort)
fi
echo
echo '== Flagged responses =='
flag_total=${#FLAGGED_MSG[@]}
accepted_flag=${#FLAGGED_MATCHED[@]}
if (( flag_total == 0 )); then
  echo '  (none)'
else
  printf '  total=%d  accepted-on-matched-query=%d  ignored=%d\n' \
    "$flag_total" "$accepted_flag" "$(( flag_total - accepted_flag ))"
  while IFS= read -r m; do
    printf '  ACCEPTED %-10s rrsets=%s\n' "$m" "$(join_sorted "${FLAGGED_MSG[$m]}")"
  done < <(printf '%s\n' "${!FLAGGED_MATCHED[@]}" | sort)
  printf '  all flagged msgids: %s\n' "$(printf '%s ' $(printf '%s\n' "${!FLAGGED_MSG[@]}" | sort))"
fi
echo
echo '== txid entropy (high-byte bins) =='
printf '  N=%d  distinct-bins=%d  H_sample=%s bits  H_lower95=%s bits  threshold=%s bits\n' \
  "$N" "$orig_bins" "$(micro_dec "$H0")" "$(micro_dec "$H_LB")" "$(micro_dec "$THRESH_MICRO")"
echo
echo '== Verdict =='
printf '  %s\n' "$verdict"

4.2 Fixture generator (gen_capture.sh)

#!/usr/bin/env bash
# gen_capture.sh -- build an interleaved, out-of-order dig-style capture.
#
#   usage: gen_capture.sh poison|benign
#
# Line format (pipe delimited; fields vary by record kind):
#   TS|Q |txid |sport|zone          |qname|qtype
#   TS|H |msgid|txid |sport|qname   |qtype|rcode|ancount|nscount|arcount
#   TS|RR|msgid|section|name       |type |ttl  |rdata
#
# Lines are emitted chronologically and then shuffled, so consumers must not
# rely on file order; only the timestamps are meaningful.
set -u
LC_ALL=C
mode="${1:-poison}"

base=1714564800000   # 2024-05-01T12:00:00Z in epoch ms
t=0
TS=""
ts() {
  t=$(( t + 1 + RANDOM % 40 ))
  local total=$(( base + t ))
  local sec=$(( total / 1000 ))
  local msec=$(( total % 1000 ))
  TS=$(TZ=UTC0 printf '%(%Y-%m-%dT%H:%M:%S)T.%03dZ' "$sec" "$msec")
}
rhex()   { printf '%04x' $(( RANDOM % 65536 )); }
rlabel() { printf '%x' $(( RANDOM % 65536 )); }

q()  { printf '%s|Q|%s|%s|%s|%s|%s\n'   "$TS" "$1" "$2" "$3" "$4" "$5"; }
h()  { printf '%s|H|%s|%s|%s|%s|%s|%s|%s|%s|%s\n' "$TS" "$1" "$2" "$3" "$4" "$5" "$6" "$7" "$8" "$9"; }
rr() { printf '%s|RR|%s|%s|%s|%s|%s|%s\n' "$TS" "$1" "$2" "$3" "$4" "$5" "$6"; }

poison() {
  local N=48 i j tx sp qn mid
  for ((i=0; i<N; i++)); do
    tx=$(printf '%04x' $((0x1000 + i)))          # weak, sequential txid
    sp=$(( 40000 + (i * 7) % 20000 ))
    qn="$(rlabel).example.com"
    mid="v$i"

    ts; q  "$tx" "$sp" "example.com" "$qn" "A"
    ts; h  "$mid" "$tx" "$sp" "$qn" "A" "NOERROR" 1 1 1
    ts; rr "$mid" "ANSWER"     "$qn"                "A"  300  "<ip-address>"
    ts; rr "$mid" "AUTHORITY"  "example.com."       "NS" 3600 "ns1.example.com."
    ts; rr "$mid" "ADDITIONAL" "ns1.example.com."   "A"  3600 "<ip-address>"

    # five spoofed responses that miss the real txid ...
    for ((j=0; j<5; j++)); do
      local bad; bad=$(printf '%04x' $((0x8000 + i * 16 + j)))
      mid="sp$i$j"
      ts; h  "$mid" "$bad" "$sp" "$qn" "A" "NOERROR" 0 1 1
      ts; rr "$mid" "AUTHORITY"  "com."           "NS" 3600 "ns.evil.net."
      ts; rr "$mid" "ADDITIONAL" "ns.evil.net."   "A"  3600 "<ip-address>"
    done

    # ... and one that hits it, carrying the poison.
    mid="pp$i"
    ts; h  "$mid" "$tx" "$sp" "$qn" "A" "NOERROR" 0 1 1
    ts; rr "$mid" "AUTHORITY"  "com."           "NS" 3600 "ns.evil.net."
    ts; rr "$mid" "ADDITIONAL" "ns.evil.net."   "A"  3600 "<ip-address>"
  done

  # benign churn from a second zone (in-bailiwick only)
  for ((i=0; i<20; i++)); do
    tx=$(printf '%04x' $((0x2000 + i)))
    sp=$(( 50000 + (i * 11) % 10000 ))
    qn="$(rlabel).good.net"
    mid="g$i"
    ts; q  "$tx" "$sp" "good.net" "$qn" "A"
    ts; h  "$mid" "$tx" "$sp" "$qn" "A" "NOERROR" 1 1 1
    ts; rr "$mid" "ANSWER"     "$qn"             "A"  120  "10.0.0.$((i+1))"
    ts; rr "$mid" "AUTHORITY"  "good.net."       "NS" 3600 "ns1.good.net."
    ts; rr "$mid" "ADDITIONAL" "ns1.good.net."   "A"  3600 "<ip-address>"
  done
}

benign() {
  local N=48 i tx sp qn mid
  for ((i=0; i<N; i++)); do
    tx=$(rhex)                                   # strong 16-bit txid
    sp=$(( 32768 + RANDOM % 28000 ))
    qn="$(rlabel).example.com"
    mid="b$i"
    ts; q  "$tx" "$sp" "example.com" "$qn" "A"
    ts; h  "$mid" "$tx" "$sp" "$qn" "A" "NOERROR" 1 2 1
    ts; rr "$mid" "ANSWER"     "$qn"                "A"  300  "<ip-address>"
    ts; rr "$mid" "AUTHORITY"  "example.com."       "NS" 3600 "ns1.example.com."
    ts; rr "$mid" "AUTHORITY"  "example.com."       "NS" 3600 "ns.provider.net."
    ts; rr "$mid" "ADDITIONAL" "ns1.example.com."   "A"  3600 "<ip-address>"
  done
  # a few late/duplicate responses -- benign churn, all in bailiwick
  for ((i=0; i<3; i++)); do
    tx=$(rhex)
    sp=$(( 32768 + RANDOM % 28000 ))
    mid="late$i"
    ts; h  "$mid" "$tx" "$sp" "stale.example.com" "A" "NOERROR" 0 0 0
  done
}

case "$mode" in
  poison) poison ;;
  benign) benign ;;
  *) echo "usage: $0 poison|benign" >&2; exit 2 ;;
esac

4.3 Deliberately-broken baseline (naive-detect.sh)

The suite runs this one-pass streamer to prove it produces false positives on an interleaved capture (root cause of section 2.1).

#!/usr/bin/env bash
# naive-detect.sh -- WRONG ON PURPOSE. Streams the capture and attributes each
# authority/additional RR to the most recently *seen* query instead of matching
# by (txid,sport). Demonstrates why interleaved logs break a one-pass detector.
set -u
LC_ALL=C
MULTI_SUFFIXES=" co.uk org.uk ac.uk gov.uk com.au net.au org.au co.jp co.nz com.br "
zone_of() {
  local q="${1,,}"; q="${q%.}"; local -a lab; IFS='.' read -r -a lab <<< "$q"
  local n=${#lab[@]}; (( n < 2 )) && { printf '%s' "$q"; return; }
  local last2="${lab[n-2]}.${lab[n-1]}"
  if [[ " $MULTI_SUFFIXES " == *" $last2 "* ]] && (( n >= 3 )); then printf '%s.%s' "${lab[n-3]}" "$last2"; else printf '%s' "$last2"; fi
}
in_bailiwick() {
  local owner="${1,,}" zone="${2,,}"; owner="${owner%.}"; zone="${zone%.}"
  [[ -n "$zone" && ( "$owner" == "$zone" || "$owner" == *".$zone" ) ]]
}
cur_zone=""
declare -A seen=()
while IFS='|' read -r ts kind a b c d e f g; do
  case "$kind" in
    Q) cur_zone="$c" ;;
    RR)
      [[ "$b" == "AUTHORITY" || "$b" == "ADDITIONAL" ]] || continue
      if [[ -n "$cur_zone" ]] && ! in_bailiwick "$c" "$cur_zone"; then
        seen["${c,,}/${d,,}"]=1
      fi
      ;;
  esac
done < "$1"
printf '%s\n' "${!seen[@]}" | sort | sed 's/^/  /'

5.5 Order independence (the whole point)

Reshuffling the same capture must not change a single byte of the decision output (the capture path is ignored in the comparison). This proves the join is by key, not by position:

$ ref=$(./bailiwick-detect.sh capture_poison.log | grep -v '^capture ')

>   shuf capture_poison.log > /tmp/s.log

>     && echo "shuffle $i identical"
> done
shuffle 1 identical
shuffle 2 identical
shuffle 3 identical

The seeded bootstrap uses a sorted bin multiset (RANDOM is seeded from BOOTSTRAP_SEED), so entropy bounds are reproducible and order-independent too.

6. Use, tuning, assumptions

# analyse any capture
./bailiwick-detect.sh /var/log/dns/capture.log

# tighten/loosen the verdict
ENTROPY_LB_MIN=6.0 MISMATCH_MIN=0.30 ./bailiwick-detect.sh capture.log

# reproducible bootstrap with a different seed
BOOTSTRAP_SEED=20240501 ./bailiwick-detect.sh capture.log

Assumptions / extension points:

  • Zone derivation. zone_of takes the last two labels, or the last three for the multi-label suffixes listed in MULTI_SUFFIXES. Extend that list (or feed a real public-suffix list) for production.
  • Bailiwick rule. An owner is in bailiwick when it equals the zone or ends with .zone. NS targets outside the zone are allowed as long as no out-of-zone glue is supplied; we flag owner names, exactly as the task requires ("records escape the query zone").
  • Entropy metric. The confidence bound is a bootstrap percentile of the high-byte-binned sample entropy. It is deliberately a lower bound: if it is below threshold the randomisation is demonstrably weak regardless of the unobserved tail of the distribution.
  • Accepted vs attempted. total flagged responses counts attempts; accepted-on-matched-query is the subset that matched a pending query. Only the latter can poison the cache, which is why the verdict requires mat_contam > 0.
