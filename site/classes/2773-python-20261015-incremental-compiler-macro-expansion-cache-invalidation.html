Diagnosis (root causes)

  1. Stale bindings from direct-import keying. A dependent's import table can stay byte-identical while a transitive provider changes. The key must be a recursive content-addressed fingerprint of the resolved provider (including aliases), not the import text.
  2. Feature flags are hidden inputs. They must be recorded only when actually read, so unread flags don't cause invalidation.
  3. Cycles make per-node recursive fingerprints ill-defined. fp(A)=H(src(A),fp(B)), fp(B)=H(src(B),fp(A)) has no solution, and one member of a cycle can't be invalidated alone. The SCC is the minimal sound invalidation unit; hashing proceeds over the condensation DAG in dependencies-first order.
  4. Dynamic deps need a fixed point. Edits can add expansion edges without touching imports (dead import becomes live on flag flip, alias rebound, provider grows a transitive edge). Fingerprint with the last exact graph → expand → diff observed edges/flags → repeat (≤ |V|+2).
  5. Parallel nondeterminism comes from unsorted hashing, global gensym counters, mutable flag state, and cache races. Fix: canonical sorted serialization, content-derived hygienic names, immutable Snapshot, per-thread in-progress stacks, and SCC-level topological batch scheduling.

The fix

SCC-level Merkle fingerprints over the expansion dependency graph: fp(C) = H(sorted localSig(v) for v in C), with localSig folding in source, span (only if the node emits location-bearing diagnostics), observed flag reads, and (alias, fp(provider)) for external deps. Reuse iff cached.group_fp == fp(v); else re-expand the whole SCC. Cycles use post-expansion placeholders resolved to a fixed point.
