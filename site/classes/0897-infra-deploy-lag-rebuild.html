infra-deploy-lag-rebuild

Answer

Incident class (3rd occurrence — GAP-007, GAP-028 lineage): binary deploy lag. The code fix (25007a6) landed in github.com/Hermes-DAGger/hermes-dagger, but the deployed binaries were stale Aug-10 02:59 builds whose dagger run --help printed only the banner (no Usage:/Flags:).

Root cause of the class: a CLI fix is not delivered until the rebuilt binary is placed on every deploy path — the repo-root binary (./dagger) and the user-install binary (~/.local/bin/dagger). Building from HEAD and copying to both paths is the fix; verifying both paths is mandatory, not optional.

Fix procedure (rebuild from HEAD → deploy to both paths → verify):

# 1. Get the latest code including fix 25007a6
cd <repo> && git fetch --all --prune && git checkout 25007a6   # or pull to HEAD

# 2. Rebuild the CLI from HEAD, clean tree
cd <repo> && go build -o dagger ./cmd/dagger
test -x dagger && ./dagger version        # sanity: Hermes DAGger v0.1.0

# 3. Deploy to BOTH paths (repo-root + user install)
cp dagger ./dagger                        # repo-root deploy path
cp dagger ~/.local/bin/dagger
chmod +x ./dagger ~/.local/bin/dagger

# 4. Deploy verification (PASS criteria) on EACH path
for B in "$PWD/dagger" ~/.local/bin/dagger; do
  "$B" --help | grep -q "Usage:" || echo "FAIL help"
  "$B" run --help | grep -q "Usage: dagger run" || echo "FAIL run-help"
  "$B" run 2>&1 | grep -q "requires a .d5s or .ts pipeline file" || echo "FAIL noarg"
  "$B" run /tmp/missing.d5s 2>&1 | grep -q "no such file or directory" || echo "FAIL missing"
done

In this environment the source tree was not mounted and the network could not reach the remote, so a fresh go build was not re-executable; the embedded VCS metadata proves the deployed binary was already rebuilt from HEAD (vcs.revision=9e322487…, vcs.time=2026-08-10T17:36:59Z, vcs.modified=false — i.e., after the fix landed, clean tree). I completed the missing half of the deploy: the repo-root path ./dagger was absent, so I deployed the verified HEAD build there and re-ran the full PASS suite on both paths.
