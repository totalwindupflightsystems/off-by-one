Answer

DKIM relaxed/simple verifier in pure bash + openssl

Root-cause analysis

A naive DKIM verifier written in shell usually fails on one or more of these exact points, and each produces a wrong OK/FAIL:

  1. Folding is destroyed before hashing. For simple header canonicalization the raw bytes of each header (including folding CRLFs, spaces around the colon, tabs, trailing WSP) must be fed to the hash verbatim. Reading the message with $(...) / read and re-printing it silently strips trailing newlines and normalizes whitespace, so the hash no longer matches.
  2. b= is not emptied correctly. RFC 6376 §3.7 hashes the DKIM-Signature header with the value of b= (and the whitespace around it) deleted, but every other byte of the header preserved, and with no trailing CRLF. If you rebuild the DKIM-Signature from parsed tags you lose the original folding and the signature never verifies. If you blank the wrong span you also fail.
  3. Wrong ordering of the two hash steps. The header hash is h= fields (in h= order, each terminated by CRLF) followed by the DKIM-Signature field itself (b= emptied, no trailing CRLF). Hashing the DKIM-Signature first, or adding a body-hash block, breaks verification.
  4. Header instances are picked top-down. For a repeated name, the first h= occurrence selects the physically last message instance, the second selects the one above it, etc. Scanning from the top is the classic bug.
  5. Body canonicalization ignores the empty-line rules. simple converts the trailing *CRLF sequence to a single CRLF (an empty body becomes CRLF), while relaxed collapses WSP, drops trailing WSP, deletes trailing empty lines and canonicalizes an empty body to the empty string. Consequently the two have different empty-body SHA-256 constants (frcCV1k9... vs 47DEQpj8...).
  6. l= is ignored. With l=N only the first N octets of the canonicalized body are hashed; extra body after that must not invalidate the signature, and l= larger than the body is an error. Byte truncation must be byte-based (not character-based).

The fix

The verifier below addresses all six points. It parses the message into raw header strings (folding preserved), implements both canonicalizations, selects h= instances bottom-up, empties b= by string surgery on the raw header, honours l= with a byte truncation, and uses openssl dgst/openssl pkey only. It emits one deterministic line per DKIM-Signature header.

Saved as ~/dkim/dkimverify.sh:

#!/usr/bin/env bash
#
# dkimverify.sh -- pure bash + openssl DKIM (RFC 6376) verifier.
#
# Usage:
#   dkimverify.sh [options] message.eml
#
# Options:
#   --pubkey FILE   Use FILE as the signer public key.  FILE may be a PEM
#                   public key, a DER public key, or bare base64
#                   SubjectPublicKeyInfo (a DKIM "p=" value).
#   --keydir DIR    Look for DIR/<selector>.<domain>.pem when --pubkey absent.
#   --dns           Fetch the key with dig from <selector>._domainkey.<domain>
#                   (off by default so the tool is deterministic/offline).
#   -h | --help     Show this help.
#
# Output: exactly one deterministic line per DKIM-Signature header, e.g.
#   DKIM OK   n=1 d=example.com s=test c=relaxed/relaxed h=5
#   DKIM FAIL n=1 d=example.com s=test reason: bh= body hash mismatch
#
# Verification logic uses only bash builtins + openssl.  dig is used only
# with --dns.  No mail agent and no Python.

set -u
set -f                       # disable pathname expansion everywhere
LC_ALL=C
export LC_ALL

PROG=${0##*/}
pubkey=
keydir=
use_dns=0
msgfile=

# ---------------------------------------------------------------------------
# Small string helpers
# ---------------------------------------------------------------------------
ltrim() { local v=$1; printf '%s' "${v#"${v%%[![:space:]]*}"}"; }
rtrim() { local v=$1; printf '%s' "${v%"${v##*[![:space:]]}"}"; }

# squeeze_wsp VAR -> collapse runs of SP/HTAB to one SP; result in SQ
squeeze_wsp() {
  local v=$1
  v=${v//$'\t'/ }
  while [[ $v == *"  "* ]]; do v=${v//  / }; done
  SQ=$v
}

# ---------------------------------------------------------------------------
# RFC 6376 section 3.4 canonicalization
# ---------------------------------------------------------------------------

# Relaxed header canonicalization of one field.
# Args: name value   (value is raw text after the first colon, possibly folded)
# Result in CN.
canon_header_relaxed() {
  local name=$1 val=$2
  name=${name,,}
  name=$(ltrim "$name"); name=$(rtrim "$name")
  val=${val//$'\r\n'/}            # unfold, keep following WSP
  squeeze_wsp "$val"; val=$SQ
  val=$(ltrim "$val"); val=$(rtrim "$val")
  CN="$name:$val"
}

# Relaxed canonicalization of a complete raw header ("name:value", folded).
# Result in CN.
canon_raw_relaxed() {
  local raw=$1
  canon_header_relaxed "${raw%%:*}" "${raw#*:}"
}

# ---------------------------------------------------------------------------
# DKIM-Signature b= value removal.
# Deletes the b= tag value and the whitespace surrounding it, preserving every
# other byte (including folding).  Result in SV.
# ---------------------------------------------------------------------------
strip_b_value() {
  local s=$1
  local n=${#s} seg_start=0 semi rest seg out=
  local t tag eqpos tagpart lead core pfx eqpart
  while (( seg_start < n )); do
    rest=${s:seg_start}
    if [[ $rest == *';'* ]]; then
      pfx=${rest%%;*}
      semi=$(( seg_start + ${#pfx} ))
    else
      semi=$n
    fi
    seg=${s:seg_start:semi-seg_start}
    t=$(ltrim "$seg")
    tag=${t%%=*}
    tag=$(rtrim "$tag")
    if [[ $tag == b ]]; then
      eqpos=${#seg}
      if [[ $seg == *=* ]]; then eqpart=${seg%%=*}; eqpos=${#eqpart}; fi
      tagpart=${seg:0:eqpos}
      lead=${tagpart%%[![:space:]]*}
      core=${tagpart#"$lead"}
      core=${core%"${core##*[![:space:]]}"}
      seg="$lead$core="
    fi
    out+=$seg
    if (( semi < n )); then out+=';'; fi
    seg_start=$(( semi + 1 ))
  done
  SV=$out
}

# ---------------------------------------------------------------------------
# Message parsing.  Populates global arrays:
#   raws[]  exact raw header text (name:value, folded, no final CRLF)
#   keys[]  lowercased, WSP-trimmed header name for matching
#   body[]  body lines (CR stripped)
# ---------------------------------------------------------------------------
declare -a raws=() keys=() body=()
nh=0

parse_message() {
  local file=$1 line r nm k
  local state=headers idx=-1
  while IFS= read -r line || [[ -n $line ]]; do
    line=${line%$'\r'}
    if [[ $state == headers ]]; then
      if [[ -z $line ]]; then
        state=body; continue
      fi
      if [[ $line == [[:space:]]* && $idx -ge 0 ]]; then
        raws[$idx]+=$'\r\n'$line
      else
        idx=$((idx+1))
        raws[$idx]=$line
      fi
    else
      body+=("$line")
    fi
  done < "$file"
  nh=${#raws[@]}
  local i
  for ((i=0; i<nh; i++)); do
    r=${raws[i]}
    if [[ $r == *:* ]]; then nm=${r%%:*}; else nm=$r; fi
    k=${nm,,}; k=$(ltrim "$k"); k=$(rtrim "$k")
    keys[i]=$k
  done
}

# ---------------------------------------------------------------------------
# Body canonicalization and l= truncation.  Result file in CBODY.
# Args: mode(relaxed|simple) l(empty|non-negative integer)
# Returns 3 when l= exceeds the canonicalized body length.
# ---------------------------------------------------------------------------
canonicalize_body() {
  local mode=$1 l=$2
  local n=${#body[@]} j last=-1 line
  if [[ $mode == relaxed ]]; then
    for ((j=0; j<n; j++)); do
      squeeze_wsp "${body[j]}"; line=$SQ
      body[j]=$(rtrim "$line")
    done
  fi
  for ((j=n-1; j>=0; j--)); do
    if [[ -n ${body[j]} ]]; then last=$j; break; fi
  done
  : > "$TMP/cbody"
  if (( last < 0 )); then
    [[ $mode == simple ]] && printf '\r\n' > "$TMP/cbody"
  else
    for ((j=0; j<=last; j++)); do printf '%s\r\n' "${body[j]}"; done > "$TMP/cbody"
  fi
  CBODY=$TMP/cbody
  if [[ -n $l ]]; then
    local size
    size=$(wc -c < "$TMP/cbody")
    (( l > size )) && return 3
    if (( l < size )); then
      head -c "$l" "$TMP/cbody" > "$TMP/cbody.trunc" || return 4
      CBODY=$TMP/cbody.trunc
    fi
  fi
  return 0
}

# ---------------------------------------------------------------------------
# Parse the DKIM-Signature value into the global associative array TAGS.
# ---------------------------------------------------------------------------
declare -A TAGS=()
parse_tags() {
  local flat=$1 seg t name value
  local IFS=';'
  local parts
  TAGS=()
  flat=${flat//$'\r\n'/}
  read -ra parts <<< "$flat"
  for seg in "${parts[@]}"; do
    t=$(ltrim "$seg")
    [[ $t != *=* ]] && continue
    name=${t%%=*}; name=$(rtrim "$name")
    value=${t#*=}; value=$(rtrim "$value")
    TAGS[$name]=$value
  done
}

# ---------------------------------------------------------------------------
# Public key resolution.  Result PEM file in PUBKEY.
# Returns 1 (unavailable) or 2 (invalid).
# ---------------------------------------------------------------------------
PUBKEY=
get_pubkey() {
  local d=$1 s=$2 out="$TMP/pub.pem" b64
  if [[ -n $pubkey ]]; then
    if grep -q 'BEGIN .*PUBLIC KEY' "$pubkey" 2>/dev/null; then
      cp "$pubkey" "$out"
    else
      b64=$(tr -d ' \t\r\n' < "$pubkey")
      { printf -- '-----BEGIN PUBLIC KEY-----\n'
        printf '%s\n' "$b64" | fold -w 64
        printf -- '-----END PUBLIC KEY-----\n'; } > "$out"
    fi
  elif [[ -n $keydir && -r "$keydir/$s.$d.pem" ]]; then
    cp "$keydir/$s.$d.pem" "$out"
  elif (( use_dns )); then
    local txt
    txt=$(dig +short +time=5 +tries=1 TXT "$s._domainkey.$d" 2>/dev/null)
    [[ -z $txt ]] && return 1
    txt=$(printf '%s' "$txt" | tr -d '"' | tr -d '\n')
    b64=${txt#*p=}; b64=${b64%%;*}
    b64=$(printf '%s' "$b64" | tr -d ' \t\r\n')
    [[ -z $b64 ]] && return 1
    { printf -- '-----BEGIN PUBLIC KEY-----\n'
      printf '%s\n' "$b64" | fold -w 64
      printf -- '-----END PUBLIC KEY-----\n'; } > "$out"
  else
    return 1
  fi
  PUBKEY=$out
  openssl pkey -pubin -in "$out" -noout >/dev/null 2>&1 || return 2
  return 0
}

# ---------------------------------------------------------------------------
# Verify one DKIM-Signature header (index si, 1-based number n).
# ---------------------------------------------------------------------------
verify_one() {
  local si=$1 n=$2
  local raw=${raws[si]}
  parse_tags "${raw#*:}"

  local d=${TAGS[d]:-} s=${TAGS[s]:-}
  local prefix="n=$n d=${d:-?} s=${s:-?}"

  [[ ${TAGS[v]:-} == 1 ]] || { printf 'DKIM FAIL %s reason: v= unsupported value\n' "$prefix"; return; }

  case ${TAGS[a]:-} in
    rsa-sha256) : ;;
    *) printf 'DKIM FAIL %s reason: a= unsupported algorithm\n' "$prefix"; return ;;
  esac

  local ch=${TAGS[c]:-simple/simple} hc bc
  hc=${ch%%/*}; bc=${ch#*/}
  [[ $ch == */* ]] || bc=simple
  case $hc in simple|relaxed) : ;; *) printf 'DKIM FAIL %s reason: c= header canonicalization unsupported\n' "$prefix"; return ;; esac
  case $bc in simple|relaxed) : ;; *) printf 'DKIM FAIL %s reason: c= body canonicalization unsupported\n' "$prefix"; return ;; esac

  [[ -n $d ]] || { printf 'DKIM FAIL %s reason: d= missing\n' "$prefix"; return; }
  [[ -n $s ]] || { printf 'DKIM FAIL %s reason: s= missing\n' "$prefix"; return; }
  [[ -n ${TAGS[bh]:-} ]] || { printf 'DKIM FAIL %s reason: bh= missing\n' "$prefix"; return; }
  [[ -n ${TAGS[b]:-} ]] || { printf 'DKIM FAIL %s reason: b= missing\n' "$prefix"; return; }
  [[ -n ${TAGS[h]:-} ]] || { printf 'DKIM FAIL %s reason: h= missing\n' "$prefix"; return; }

  # ---- body hash ----
  local l=${TAGS[l]:-}
  if [[ -n $l && ! $l =~ ^[0-9]+$ ]]; then
    printf 'DKIM FAIL %s reason: l= malformed\n' "$prefix"; return
  fi
  if ! canonicalize_body "$bc" "$l"; then
    printf 'DKIM FAIL %s reason: l= exceeds canonicalized body length\n' "$prefix"; return
  fi
  local bh_calc bh_exp
  bh_calc=$(openssl dgst -sha256 -binary < "$CBODY" | openssl base64 -A)
  bh_exp=${TAGS[bh]//[[:space:]]/}
  if [[ $bh_calc != "$bh_exp" ]]; then
    printf 'DKIM FAIL %s reason: bh= body hash mismatch\n' "$prefix"; return
  fi

  # ---- public key ----
  if ! get_pubkey "$d" "$s"; then
    printf 'DKIM FAIL %s reason: key= public key unavailable\n' "$prefix"; return
  fi

  # ---- header hash ----
  local names_str=${TAGS[h]//[[:space:]]/}
  local IFS=':' x
  local -a names=()
  read -ra names <<< "$names_str"
  local got_from=0
  for x in "${names[@]}"; do [[ ${x,,} == from ]] && got_from=1; done
  if (( ! got_from )); then
    printf 'DKIM FAIL %s reason: h= does not include From (under-signed)\n' "$prefix"; return
  fi

  : > "$TMP/hdata"
  local -A seen=()
  local name k cnt j found
  for name in "${names[@]}"; do
    [[ -z $name ]] && continue
    name=${name,,}
    k=${seen[$name]:-0}
    seen[$name]=$((k+1))
    found=-1; cnt=0
    for ((j=nh-1; j>=0; j--)); do
      if [[ ${keys[j]} == "$name" ]]; then
        cnt=$((cnt+1))
        if (( cnt == k+1 )); then found=$j; break; fi
      fi
    done
    if (( found < 0 )); then
      # The task requires rejecting any h= entry with no message instance.
      printf 'DKIM FAIL %s reason: h= references missing header: %s\n' "$prefix" "$name"
      return
    fi
    if [[ $hc == simple ]]; then
      printf '%s\r\n' "${raws[found]}" >> "$TMP/hdata"
    else
      canon_raw_relaxed "${raws[found]}"
      printf '%s\r\n' "$CN" >> "$TMP/hdata"
    fi
  done

  # D-SIG header last, b= value emptied, canonicalized, no trailing CRLF
  strip_b_value "$raw"
  if [[ $hc == simple ]]; then
    printf '%s' "$SV" >> "$TMP/hdata"
  else
    canon_raw_relaxed "$SV"
    printf '%s' "$CN" >> "$TMP/hdata"
  fi

  # ---- signature ----
  local b64sig=${TAGS[b]//[[:space:]]/}
  if ! printf '%s' "$b64sig" | openssl base64 -d -A > "$TMP/sig.bin" 2>/dev/null; then
    printf 'DKIM FAIL %s reason: b= malformed base64\n' "$prefix"; return
  fi
  if ! openssl dgst -sha256 -verify "$PUBKEY" -signature "$TMP/sig.bin" "$TMP/hdata" >/dev/null 2>&1; then
    printf 'DKIM FAIL %s reason: b= signature verification failed\n' "$prefix"; return
  fi

  local hcount=0
  for x in "${names[@]}"; do [[ -n $x ]] && hcount=$((hcount+1)); done
  printf 'DKIM OK %s c=%s/%s h=%d\n' "$prefix" "$hc" "$bc" "$hcount"
}

# ---------------------------------------------------------------------------
main() {
  local msgfile=
  while (($#)); do
    case $1 in
      --pubkey)  pubkey=${2:-}; shift 2 ;;
      --keydir)  keydir=${2:-}; shift 2 ;;
      --dns)     use_dns=1; shift ;;
      -h|--help) sed -n '2,25p' "$0"; return 0 ;;
      --) shift; break ;;
      -*) printf '%s: unknown option: %s\n' "$PROG" "$1" >&2; return 2 ;;
      *)  msgfile=$1; shift ;;
    esac
  done
  [[ -n $msgfile ]] || { printf '%s: missing message file\n' "$PROG" >&2; return 2; }
  [[ -r $msgfile ]] || { printf '%s: cannot read %s\n' "$PROG" "$msgfile" >&2; return 2; }

  TMP=$(mktemp -d) || return 2
  trap 'rm -rf "$TMP"' EXIT

  parse_message "$msgfile"

  local n_sig=0 i
  for ((i=0; i<nh; i++)); do
    if [[ ${keys[i]} == dkim-signature ]]; then
      n_sig=$((n_sig+1))
      verify_one "$i" "$n_sig"
    fi
  done
  (( n_sig == 0 )) && printf 'DKIM NONE reason: no DKIM-Signature header found\n'
  return 0
}

if [[ ${BASH_SOURCE[0]} == "$0" ]]; then
  main "$@"
fi

Key implementation notes:

  • parse_message keeps each header's exact bytes (raws[]) and only strips the trailing CR; body[] is normalized to one CRLF-terminated line per entry.
  • strip_b_value removes only the b= value plus surrounding WSP, preserving folding; the D-SIG is then appended after all h= headers with no final CRLF.
  • Header selection uses a per-name counter and scans nah...0, so the first h= occurrence of a repeated name binds to the bottom-most instance.
  • canonicalize_body uses head -c for l=, so truncation is byte-exact and independent of locale/multibyte characters.

Note on over-signing

RFC 6376 §5.4 permits a signer to list a header in h= more times than it exists ("over-signing"): the missing instance is the null string. The task statement instead requires rejecting any h= entry that has no corresponding message header, so the implementation above fails such signatures with h= references missing header: <name>. If RFC behaviour is desired, replace the if (( found < 0 )); then ... return; fi block with a continue (the removed-header case still fails, later, with b= signature verification failed).
