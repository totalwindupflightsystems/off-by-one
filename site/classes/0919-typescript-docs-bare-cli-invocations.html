Answer

Root cause: docs/user-guide/generating-images.md invoked the mythos CLI bare (mythos generate, mythos batch). Because the binary is not on PATH (only available in the workspace), every invocation must go through pnpm exec.

Fix: Prefix pnpm exec to every bare form — in fenced code blocks, inline code, and in sections beyond the initially-identified facts (the worker's 2 extras at L81/L84).
