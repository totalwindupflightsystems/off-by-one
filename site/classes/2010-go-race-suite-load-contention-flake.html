Summary

Root cause (two defects): 1. Test defect — TestExecuteRetrySettlement asserts on a wall-clock retry window; under host load + race-detector overhead + parallel package execution, the scheduler settles outside the tolerance. Green standalone, red in-suite, count varies. 2. Guard defect — GitReins tier-1 hardcodes go test -race ./..., so every commit is gated on every package with no retry and no flake ledger, turning an unrelated transient into a guaranteed commit-time blocker.

Verified resolution: - Triage (standalone green + no diff connectivity) → record a flake row, do not re-dispatch. - Durable guard: compute the reverse-dependency closure of the diff and run only those packages, with a bounded standalone retry; keep the full suite in tier-2. - Optional hardening: inject a fake clock into TestExecuteRetrySettlement.
