ML-KEM-768 Decapsulation with Constant-Time Implicit Rejection (FIPS 203)

Problem class: python3-ml-kem-decap-implicit-rejection-constant-time Environment: Python 3.12+ (verified here on 3.12 and 3.14) Artifacts: ~/mlkem/mlkem768.py, ~/mlkem/build_kat.py

Root-cause analysis

This is a build-from-scratch problem, so the "root cause" is the set of traps a naive FIPS 203 implementation falls into. They are all real bugs I hit and fixed while bringing the code into conformance:

  1. NTT-domain multiplication is not pointwise. ML-KEM's NTT is the incomplete NTT: it maps Z_q[x]/(x^256+1) into 128 quadratic fields. The product Â ∘ ŝ must use FIPS 203 Algorithm 11 MultiplyNTTs / Algorithm 12 BaseCaseMultiply, i.e. pair-wise h[2i] = a0·b0 + γ_i·a1·b1, h[2i+1] = a0·b1 + a1·b0, with γ_i = 17^(2·BitRev7(i)+1) mod 3329. Multiplying coefficient-by-coefficient (h[k]=a[k]b[k]) produces a valid-looking but wrong key. This was the single failure that broke all known-answer vectors until corrected.

  2. The zeta table must be the literal FIPS table. zetas[i-1] = 17^BitRev7(i) mod 3329 for i = 1..127, and INTT uses i = 127..1 then multiplies by 128^{-1} = 3303. Round-3 Kyber tables are Montgomery-form and would be wrong here. Deriving the table from the definition removes representation ambiguity.

  3. Implicit rejection must return a value, never raise. Per Algorithm 21 the code always decrypts, always re-encrypts, and only then chooses between K' = G(m'‖h) and K̄ = J(z‖c). A raise ValueError on the mismatch path leaks the accept/reject bit through control flow and violates FIPS 203.

  4. The secret-dependent decision must be a mask, not an if. c == c' is converted with hmac.compare_digest into a 0/1 bit and consumed by a branchless byte-mask select _ct_select. (I initially wired the select arguments backwards, which passed the modified vectors and failed the valid ones — a classic implicit-rejection inversion.)

  5. Truncated ciphertexts must be normalised on the public length, then rejected implicitly. Length is public, so brief/long inputs are zero-padded/truncated to 1088 bytes on entry; the re-encryption check then fails and yields J(z‖c_fixed) instead of a crash.

  6. Compress tie rounding. q = 3329 is odd, so Compress_d(x) = ((x·2^d + q//2)//q) mod 2^d is exact round-half-up with no tie ambiguity. Decompress_d(y) = (q·y + 2^(d-1)) >> d. The 1-bit message path therefore gives Decompress_1(1) = 1665.

  7. Bit packing. ByteEncode_d/ByteDecode_d are implemented generically for d ∈ {1,4,10,12} (coefficient i occupies bits [i·d,(i+1)·d) of a little-endian bit string). The message uses d=1; the 12-bit form (called "12-bit message encode/decode" in the prompt) is what serialises t̂/ŝ.

Caveat stated honestly: CPython is not a constant-time execution environment (arbitrary-precision ints, interpreter, allocator). What this code guarantees is the algorithmic discipline — no secret-dependent branch, no secret-dependent table index — plus a statistical harness that would catch a gross accept/reject timing divergence.

Exact fix

Two files. mlkem768.py is the implementation + self-test; build_kat.py regenerates the official NIST ACVP vectors. The on-disk mlkem768.py additionally contains a packed _KAT_GZ_B64 constant (24 KB base64) so it is self-contained offline; it is elided below for readability and the code falls back to mlkem768_kat.json produced by build_kat.py.

mlkem768.py

"""
ML-KEM-768 (FIPS 203) reference implementation in pure Python 3.

Design goals
------------
* Exact FIPS 203 conformance for ML-KEM-768 (k=3, eta1=eta2=2, du=10, dv=4).
* Implicit rejection in KEM.Decaps per FIPS 203 Algorithm 21: when the
  re-encryption does not reproduce the input ciphertext the shared secret is
  J(z || c) (a pseudorandom value), *not* an exception.
* No branch and no table index that depends on a secret value at the Python
  source level.  The only secret-dependent decision (c == c') is turned into a
  byte mask via a constant-time comparison and a branchless select.

NOTE: CPython is not a constant-time execution environment (arbitrary precision
integers, the interpreter, the memory allocator).  The point of this file is to
demonstrate the *algorithmic* constant-time discipline that a real
implementation needs; the timing harness at the bottom is a coarse smoke test,
not a side-channel proof.
"""

from __future__ import annotations

import hashlib
import hmac
import os
import statistics
import time
from typing import List, Sequence, Tuple

# ---------------------------------------------------------------------------
# ML-KEM-768 parameters (FIPS 203, Table 2)
# ---------------------------------------------------------------------------
N = 256              # polynomial degree
Q = 3329             # modulus
K = 3                # module rank
ETA1 = 2             # noise parameter for s, e, y
ETA2 = 2             # noise parameter for e1, e2
DU = 10              # compression parameter for u
DV = 4               # compression parameter for v

EK_BYTES = 384 * K + 32           # 1184
DK_BYTES = 768 * K + 96           # 2400
CT_BYTES = 32 * (DU * K + DV)     # 1088
SS_BYTES = 32


# ---------------------------------------------------------------------------
# Bit helpers
# ---------------------------------------------------------------------------
def _bitrev7(x: int) -> int:
    """Reverse the 7 low bits of x (FIPS 203, Section 4.1)."""
    return int(format(x, "07b")[::-1], 2)


# Exact FIPS 203 NTT twiddle table: zetas[i-1] = 17^BitRev7(i) mod q, i = 1..127.
# This is the canonical table; it is *not* the Montgomery-form table used by
# the round-3 Kyber reference code.  Using the definition removes any ambiguity
# about representation.
ZETAS: Tuple[int, ...] = tuple(pow(17, _bitrev7(i), Q) for i in range(1, 128))

# 128^-1 mod q (FIPS 203, Algorithm 10 step 14).
_INV128 = pow(128, -1, Q)
assert _INV128 == 3303

# Multiplicative constants for MultiplyNTTs (FIPS 203 Algorithm 11):
# BaseCaseMultiply for pair i uses gamma_i = zeta^(2*BitRev7(i)+1).
GAMMAS: Tuple[int, ...] = tuple(pow(17, 2 * _bitrev7(i) + 1, Q) for i in range(128))


# ---------------------------------------------------------------------------
# NTT over Z_q, Algorithm 9 and Algorithm 10 of FIPS 203
# ---------------------------------------------------------------------------
def ntt(f: Sequence[int]) -> List[int]:
    r = list(f)
    i = 0
    length = 128
    while length >= 2:
        start = 0
        while start < N:
            zeta = ZETAS[i]
            i += 1
            for j in range(start, start + length):
                t = zeta * r[j + length] % Q
                r[j + length] = (r[j] - t) % Q
                r[j] = (r[j] + t) % Q
            start += 2 * length
        length //= 2
    return r


def intt(f: Sequence[int]) -> List[int]:
    r = list(f)
    i = 126
    length = 2
    while length <= 128:
        start = 0
        while start < N:
            zeta = ZETAS[i]
            i -= 1
            for j in range(start, start + length):
                t = r[j]
                r[j] = (t + r[j + length]) % Q
                r[j + length] = zeta * ((r[j + length] - t) % Q) % Q
            start += 2 * length
        length *= 2
    return [x * _INV128 % Q for x in r]


def multiply_ntts(f: Sequence[int], g: Sequence[int]) -> List[int]:
    """FIPS 203 Algorithms 11/12: multiply two NTT-domain polynomials."""
    h = [0] * N
    for i in range(128):
        a0, a1 = f[2 * i], f[2 * i + 1]
        b0, b1 = g[2 * i], g[2 * i + 1]
        gamma = GAMMAS[i]
        h[2 * i] = (a0 * b0 + a1 * b1 * gamma) % Q
        h[2 * i + 1] = (a0 * b1 + a1 * b0) % Q
    return h


def _mat_vec(A, v):
    """A is a k x k list of NTT polynomials, v a list of k NTT polynomials."""
    out = []
    for i in range(len(A)):
        acc = [0] * N
        for j in range(len(v)):
            prod = multiply_ntts(A[i][j], v[j])
            acc = [(x + y) % Q for x, y in zip(acc, prod)]
        out.append(acc)
    return out


def _dot(v, w):
    acc = [0] * N
    for a, b in zip(v, w):
        prod = multiply_ntts(a, b)
        acc = [(x + y) % Q for x, y in zip(acc, prod)]
    return acc


# ---------------------------------------------------------------------------
# ByteEncode / ByteDecode, Algorithms 5 and 6 (generic 1/4/10/12 bit variants)
# ---------------------------------------------------------------------------
def byte_encode(coeffs: Sequence[int], d: int) -> bytes:
    acc = 0
    mask = (1 << d) - 1
    for idx, c in enumerate(coeffs):
        acc |= (c & mask) << (idx * d)
    return acc.to_bytes(32 * d, "little")


def byte_decode(data: bytes, d: int) -> List[int]:
    acc = int.from_bytes(data, "little")
    mask = (1 << d) - 1
    return [(acc >> (idx * d)) & mask for idx in range(N)]


# ---------------------------------------------------------------------------
# Compress / Decompress, Equations 4.7 and 4.8 of FIPS 203
#
# FIPS 203 rounds to the nearest integer with ties away from zero.  Because q
# is odd there is never an exact tie for Compress, and +q//2 followed by floor
# division is exactly round-half-up.  Decompress uses +2^(d-1) then a shift.
# ---------------------------------------------------------------------------
def compress(x: int, d: int) -> int:
    return (((x << d) + (Q // 2)) // Q) & ((1 << d) - 1)


def decompress(y: int, d: int) -> int:
    return (Q * y + (1 << (d - 1))) >> d


# ---------------------------------------------------------------------------
# Hash / XOF / PRF primitives (FIPS 203, Section 4.3-4.9)
# ---------------------------------------------------------------------------
def H(s: bytes) -> bytes:
    return hashlib.sha3_256(s).digest()


def J(s: bytes) -> bytes:
    return hashlib.shake_256(s).digest(32)


def G(s: bytes) -> Tuple[bytes, bytes]:
    h = hashlib.sha3_512(s).digest()
    return h[:32], h[32:]


def prf(eta: int, s: bytes, b: int) -> bytes:
    return hashlib.shake_256(s + bytes([b])).digest(64 * eta)


def _xof(rho: bytes, i: int, j: int) -> bytes:
    # An XOF stream is a prefix of a SHAKE128 stream; 840 bytes is enough for
    # rejection sampling with overwhelming probability (see kyber-py note).
    return hashlib.shake_128(rho + bytes([i, j])).digest(840)


# ---------------------------------------------------------------------------
# SampleNTT (Algorithm 7) and SamplePolyCBD (Algorithm 8)
# ---------------------------------------------------------------------------
def sample_ntt(stream: bytes) -> List[int]:
    a: List[int] = []
    i = 0
    while len(a) < N:
        d1 = stream[i] + 256 * (stream[i + 1] % 16)
        d2 = (stream[i + 1] // 16) + 16 * stream[i + 2]
        i += 3
        if d1 < Q:
            a.append(d1)
        if d2 < Q and len(a) < N:
            a.append(d2)
    return a


def sample_poly_cbd(buf: bytes, eta: int) -> List[int]:
    # buf is 64*eta bytes; coefficient i uses 2*eta consecutive bits.
    bits = int.from_bytes(buf, "little")
    out = [0] * N
    for i in range(N):
        a = 0
        b = 0
        base = 2 * i * eta
        for j in range(eta):
            a += (bits >> (base + j)) & 1
            b += (bits >> (base + eta + j)) & 1
        out[i] = a - b
    return out


# ---------------------------------------------------------------------------
# K-PKE, Algorithms 13, 14 and 15
# ---------------------------------------------------------------------------
def _matrix(seed: bytes) -> List[List[List[int]]]:
    """A_hat[i][j] = SampleNTT(seed || j || i)   (FIPS 203 Algorithm 13)."""
    return [
        [sample_ntt(_xof(seed, j, i)) for j in range(K)]
        for i in range(K)
    ]


def _matrix_transpose(seed: bytes) -> List[List[List[int]]]:
    """A_hat^T[i][j] = A[j][i] = SampleNTT(seed || i || j)."""
    return [
        [sample_ntt(_xof(seed, i, j)) for j in range(K)]
        for i in range(K)
    ]


def k_pke_keygen(d: bytes) -> Tuple[bytes, bytes]:
    rho, sigma = G(d + bytes([K]))

    A = _matrix(rho)

    n = 0
    s = []
    e = []
    for _ in range(K):
        s.append(sample_poly_cbd(prf(ETA1, sigma, n), ETA1))
        n += 1
    for _ in range(K):
        e.append(sample_poly_cbd(prf(ETA1, sigma, n), ETA1))
        n += 1

    s_hat = [ntt(p) for p in s]
    e_hat = [ntt(p) for p in e]

    As = _mat_vec(A, s_hat)
    t_hat = [[(e_hat[i][c] + As[i][c]) % Q for c in range(N)] for i in range(K)]

    ek = b"".join(byte_encode(p, 12) for p in t_hat) + rho
    dk = b"".join(byte_encode(p, 12) for p in s_hat)
    return ek, dk


def _k_pke_encrypt_unchecked(ek: bytes, m: bytes, r: bytes) -> bytes:
    t_hat_bytes, rho = ek[:-32], ek[-32:]
    t_hat = [byte_decode(t_hat_bytes[i * 384:(i + 1) * 384], 12) for i in range(K)]

    At = _matrix_transpose(rho)

    n = 0
    y = []
    e1 = []
    for _ in range(K):
        y.append(sample_poly_cbd(prf(ETA1, r, n), ETA1))
        n += 1
    for _ in range(K):
        e1.append(sample_poly_cbd(prf(ETA2, r, n), ETA2))
        n += 1
    e2 = sample_poly_cbd(prf(ETA2, r, n), ETA2)

    y_hat = [ntt(p) for p in y]

    AtY = _mat_vec(At, y_hat)
    u = []
    for i in range(K):
        uu = intt(AtY[i])
        u.append([(uu[c] + e1[i][c]) % Q for c in range(N)])

    vv = intt(_dot(t_hat, y_hat))
    mu = [decompress(b, 1) for b in byte_decode(m, 1)]
    v = [(vv[c] + e2[c] + mu[c]) % Q for c in range(N)]

    c1 = b"".join(byte_encode([compress(x, DU) for x in p], DU) for p in u)
    c2 = byte_encode([compress(x, DV) for x in v], DV)
    return c1 + c2


def k_pke_encrypt(ek: bytes, m: bytes, r: bytes) -> bytes:
    # Encapsulation-key type check and modulus check (FIPS 203, Section 7.2).
    if len(ek) != EK_BYTES:
        raise ValueError("encapsulation key length check failed")
    t_hat_bytes = ek[:-32]
    t_hat = [byte_decode(t_hat_bytes[i * 384:(i + 1) * 384], 12) for i in range(K)]
    if b"".join(byte_encode(p, 12) for p in t_hat) != t_hat_bytes:
        raise ValueError("encapsulation key modulus check failed")
    return _k_pke_encrypt_unchecked(ek, m, r)


def k_pke_decrypt(dk_pke: bytes, c: bytes) -> bytes:
    c1_len = 32 * DU * K
    c1, c2 = c[:c1_len], c[c1_len:]
    u = [
        [decompress(x, DU) for x in byte_decode(c1[i * 32 * DU:(i + 1) * 32 * DU], DU)]
        for i in range(K)
    ]
    v = [decompress(x, DV) for x in byte_decode(c2, DV)]
    s_hat = [byte_decode(dk_pke[i * 384:(i + 1) * 384], 12) for i in range(K)]

    u_hat = [ntt(p) for p in u]
    w = intt(_dot(s_hat, u_hat))
    w = [(v[c] - w[c]) % Q for c in range(N)]
    return byte_encode([compress(x, 1) for x in w], 1)


# ---------------------------------------------------------------------------
# Constant-time helpers
# ---------------------------------------------------------------------------
def _ct_eq(a: bytes, b: bytes) -> int:
    """Return 1 if a == b else 0; comparison itself is constant-time."""
    if len(a) != len(b):
        return 0
    return int(hmac.compare_digest(a, b))


def _ct_select(a: bytes, b: bytes, bit: int) -> bytes:
    """Branchless select: bit == 1 -> a, bit == 0 -> b."""
    mask = (0 - bit) & 0xFF
    return bytes((x & mask) | (y & (~mask & 0xFF)) for x, y in zip(a, b))


# ---------------------------------------------------------------------------
# ML-KEM, Algorithms 16-21
# ---------------------------------------------------------------------------
def keygen_internal(d: bytes, z: bytes) -> Tuple[bytes, bytes]:
    ek_pke, dk_pke = k_pke_keygen(d)
    dk = dk_pke + ek_pke + H(ek_pke) + z
    return ek_pke, dk


def keygen() -> Tuple[bytes, bytes]:
    return keygen_internal(os.urandom(32), os.urandom(32))


def encaps_internal(ek: bytes, m: bytes) -> Tuple[bytes, bytes]:
    Kp, r = G(m + H(ek))
    c = k_pke_encrypt(ek, m, r)
    return Kp, c


def encaps(ek: bytes) -> Tuple[bytes, bytes]:
    return encaps_internal(ek, os.urandom(32))


def _normalize_ciphertext(c: bytes) -> bytes:
    """Public-length normalisation so every Decaps path processes CT_BYTES.

    Length is public, so doing this is not a secret-dependent branch.  A
    short/long ciphertext is zero-padded/truncated and will fail the implicit
    re-encryption check, yielding J(z || c_fixed) exactly like any other
    non-canonical ciphertext.
    """
    return (c + b"\x00" * CT_BYTES)[:CT_BYTES]


def decaps_internal(dk: bytes, c: bytes) -> bytes:
    if len(dk) != DK_BYTES:
        raise ValueError("decapsulation key length check failed")

    c_fixed = _normalize_ciphertext(c)

    dk_pke = dk[:384 * K]
    ek_pke = dk[384 * K:768 * K + 32]
    h = dk[768 * K + 32:768 * K + 64]
    z = dk[768 * K + 64:768 * K + 96]

    # 1. decrypt
    m_prime = k_pke_decrypt(dk_pke, c_fixed)
    # 2. derive (K', r') and the rejection secret
    K_prime, r_prime = G(m_prime + h)
    K_bar = J(z + c_fixed)
    # 3. always re-encrypt, then select in constant time
    c_prime = _k_pke_encrypt_unchecked(ek_pke, m_prime, r_prime)
    # bit == 1 means c == c', i.e. accept K'; otherwise reject to K_bar.
    return _ct_select(K_prime, K_bar, _ct_eq(c_fixed, c_prime))


def decaps(dk: bytes, c: bytes) -> bytes:
    return decaps_internal(dk, c)


# ---------------------------------------------------------------------------
# Convenience: strict FIPS 203 entry points that validate ciphertext length.
# ---------------------------------------------------------------------------
def decaps_strict(dk: bytes, c: bytes) -> bytes:
    if len(c) != CT_BYTES:
        raise ValueError("ciphertext length check failed")
    return decaps_internal(dk, c)


# ---------------------------------------------------------------------------
# Self test: KATs, agreement, timing harness
# ---------------------------------------------------------------------------
def _load_kat():
    """Load the embedded, gzip+base64 packed ACVP KAT vectors.

    If a richer ``mlkem768_kat.json`` sits next to this file it takes
    precedence (produced by ``build_kat.py``).
    """
    import base64
    import gzip
    import json
    import pathlib

    here = pathlib.Path(__file__).with_name("mlkem768_kat.json")
    if here.exists():
        return json.loads(here.read_text())
    blob = globals().get("_KAT_GZ_B64")
    if blob:
        return json.loads(gzip.decompress(base64.b64decode(blob)))
    raise FileNotFoundError(
        "no ACVP vectors available; run `python3 build_kat.py` or restore the "
        "embedded _KAT_GZ_B64 constant"
    )


def run_kat(verbose: bool = True):
    try:
        kat = _load_kat()
    except FileNotFoundError as exc:
        if verbose:
            print(f"  KAT skipped: {exc}")
        return None
    ok = True

    for tc in kat["keygen"]:
        d = bytes.fromhex(tc["d"])
        z = bytes.fromhex(tc["z"])
        ek, dk = keygen_internal(d, z)
        if "ek_sha256" in tc:
            good = (
                hashlib.sha256(ek).hexdigest() == tc["ek_sha256"]
                and hashlib.sha256(dk).hexdigest() == tc["dk_sha256"]
            )
        else:
            good = ek.hex().upper() == tc["ek"] and dk.hex().upper() == tc["dk"]
        ok &= good
        if verbose:
            print(f"  keyGen  tc={tc['tcId']:<4} {'PASS' if good else 'FAIL'}")

    for tc in kat["encaps"]:
        ek = bytes.fromhex(tc["ek"])
        m = bytes.fromhex(tc["m"])
        Kp, c = encaps_internal(ek, m)
        good = c.hex().upper() == tc["c"] and Kp.hex().upper() == tc["k"]
        ok &= good
        if verbose:
            print(f"  encaps  tc={tc['tcId']:<4} {'PASS' if good else 'FAIL'}")

    for tc in kat["decaps"]:
        dk = bytes.fromhex(tc["dk"])
        c = bytes.fromhex(tc["c"])
        K = decaps(dk, c)
        good = K.hex().upper() == tc["k"]
        ok &= good
        if verbose:
            print(
                f"  decaps  tc={tc['tcId']:<4} ({tc.get('reason', '')[:28]:<28}) "
                f"{'PASS' if good else 'FAIL'}"
            )

    return ok


def run_agreement(rounds: int = 32, verbose: bool = True) -> bool:
    """Measure decapsulation agreement for valid / flipped / truncated c."""
    import random

    ek, dk = keygen()
    z = dk[-32:]
    rng = random.Random(0x5EED)

    valid = flipped = truncated = 0
    for _ in range(rounds):
        K, c = encaps(ek)
        if decaps(dk, c) == K:
            valid += 1

        # single bit flip -> implicit rejection must equal J(z || c_fixed)
        cf = bytearray(c)
        pos = rng.randrange(len(cf))
        cf[pos] ^= 1 << rng.randrange(8)
        cf = bytes(cf)
        expected = J(z + _normalize_ciphertext(cf))
        if decaps(dk, cf) == expected:
            flipped += 1

        # truncation -> implicit rejection on zero-padded ciphertext
        ct = c[: rng.randrange(0, len(c))]
        expected_t = J(z + _normalize_ciphertext(ct))
        if decaps(dk, ct) == expected_t:
            truncated += 1

    if verbose:
        print(
            f"  agreement: valid {valid}/{rounds}, "
            f"bit-flipped {flipped}/{rounds}, truncated {truncated}/{rounds}"
        )
    return valid == flipped == truncated == rounds


def _time_call(fn, dk, c):
    t0 = time.perf_counter_ns()
    fn(dk, c)
    return time.perf_counter_ns() - t0


def run_timing_harness(
    iters: int = 60,
    sigma: float = 6.0,
    verbose: bool = True,
    decaps_fn=None,
    label: str = "timing",
) -> bool:
    """Rejection-vs-accept timing variance harness.

    Interleaves accept and reject measurements and fails if the difference of
    means exceeds `sigma` times the standard error of the difference.  With a
    constant-time selection the two paths do identical work and the difference
    stays inside the noise floor.  Feed a deliberately branchy routine via
    ``decaps_fn`` to confirm the harness can actually fail.
    """
    if decaps_fn is None:
        decaps_fn = decaps

    ek, dk = keygen()
    _, c = encaps(ek)

    rej = bytearray(c)
    rej[len(c) // 2] ^= 0x01
    rej = bytes(rej)

    accept_times = []
    reject_times = []
    for i in range(iters):
        # alternate order each iteration to cancel thermal/order bias
        if i % 2 == 0:
            accept_times.append(_time_call(decaps_fn, dk, c))
            reject_times.append(_time_call(decaps_fn, dk, rej))
        else:
            reject_times.append(_time_call(decaps_fn, dk, rej))
            accept_times.append(_time_call(decaps_fn, dk, c))

    ma, mr = statistics.mean(accept_times), statistics.mean(reject_times)
    va, vr = statistics.variance(accept_times), statistics.variance(reject_times)
    se = (va / len(accept_times) + vr / len(reject_times)) ** 0.5
    diff = abs(ma - mr)
    inside = diff <= sigma * se if se > 0 else True

    if verbose:
        print(
            f"  {label}: accept mean {ma:,.0f} ns  reject mean {mr:,.0f} ns  "
            f"|diff| {diff:,.0f} ns  noise(se) {se:,.0f} ns  "
            f"threshold {sigma * se:,.0f} ns  -> {'OK' if inside else 'FAIL'}"
        )
    return inside


def _decaps_synthetic_branchy(dk: bytes, c: bytes) -> bytes:
    """Negative control: identical to decaps but adds work only on reject.

    This is not a correctness bug, it is a deliberately leaky implementation
    used to prove that :func:`run_timing_harness` trips when the two paths
    diverge beyond the noise floor.
    """
    out = decaps(dk, c)
    z = dk[-32:]
    if out == J(z + _normalize_ciphertext(c)):  # branch on the secret result
        acc = 0
        for _ in range(2_000_000):
            acc += 1
    return out


def run_timing_negative_control(iters: int = 60, verbose: bool = True) -> bool:
    """Return True iff the harness correctly *fails* the leaky routine."""
    if verbose:
        print("  negative control (leaky reject path) -- harness must FAIL it:")
    detected = not run_timing_harness(
        iters=iters,
        verbose=verbose,
        decaps_fn=_decaps_synthetic_branchy,
        label="negative",
    )
    if verbose:
        print(f"  negative control detected: {'YES' if detected else 'NO'}")
    return detected


def run_primitive_tests(verbose: bool = True) -> bool:
    """Small, key-free checks of the building blocks."""
    import random

    rng = random.Random(1234567)
    ok = True

    # NTT / inverse NTT round trip
    for _ in range(25):
        f = [rng.randrange(Q) for _ in range(N)]
        ok &= intt(ntt(f)) == f

    # MultiplyNTTs agrees with the inverse of the product in R_q
    a = [rng.randrange(Q) for _ in range(N)]
    b = [rng.randrange(Q) for _ in range(N)]
    prod = intt(multiply_ntts(ntt(a), ntt(b)))
    # schoolbook negacyclic product mod q
    sb = [0] * N
    for i, ai in enumerate(a):
        for j, bj in enumerate(b):
            k = i + j
            if k < N:
                sb[k] = (sb[k] + ai * bj) % Q
            else:
                sb[k - N] = (sb[k - N] - ai * bj) % Q
    ok &= prod == sb

    # Compress tie rounding (q odd -> no exact ties; thresholds are clear)
    ok &= compress(0, 1) == 0
    ok &= compress(832, 1) == 0 and compress(833, 1) == 1
    ok &= compress(2496, 1) == 1 and compress(2497, 1) == 0
    ok &= decompress(0, 1) == 0 and decompress(1, 1) == 1665
    ok &= compress(1664, 1) == 1

    # ByteEncode / ByteDecode round trip for every used width
    for d in (1, 4, 10, 12):
        coeffs = [rng.randrange(1 << d) for _ in range(N)]
        ok &= byte_decode(byte_encode(coeffs, d), d) == coeffs

    if verbose:
        print(f"  primitives (NTT, MultiplyNTTs, Compress, ByteEncode): "
              f"{'PASS' if ok else 'FAIL'}")
    return ok


def run_self_test() -> int:
    print("ML-KEM-768 self test")
    print("Primitive checks:")
    prim_ok = run_primitive_tests()

build_kat.py

#!/usr/bin/env python3
"""Regenerate ``mlkem768_kat.json`` from the official NIST ACVP vectors."""

from __future__ import annotations

import argparse
import hashlib
import json
import pathlib
import urllib.request

BASE = (
    "https://raw.githubusercontent.com/usnistgov/ACVP-Server/master/"
    "gen-val/json-files"
)
FILES = {
    "keygen": f"{BASE}/ML-KEM-keyGen-FIPS203/internalProjection.json",
    "encapdecap": f"{BASE}/ML-KEM-encapDecap-FIPS203/internalProjection.json",
}


def _fetch(url: str) -> dict:
    print(f"  GET {url}")
    with urllib.request.urlopen(url, timeout=120) as resp:
        return json.loads(resp.read())


def _group(groups, function):
    for g in groups:
        if g.get("parameterSet") == "ML-KEM-768" and g.get("function") == function:
            return g
    raise SystemExit(f"ML-KEM-768 group {function!r} not found")


def _keygen_group(groups):
    for g in groups:
        if g.get("parameterSet") == "ML-KEM-768" and "function" not in g:
            return g
    raise SystemExit("ML-KEM-768 keyGen group not found")


def main() -> None:
    ap = argparse.ArgumentParser()
    ap.add_argument("--quick", action="store_true", help="small curated subset")
    ap.add_argument("--out", default=str(pathlib.Path(__file__).with_name("mlkem768_kat.json")))
    args = ap.parse_args()

    kg = _fetch(FILES["keygen"])
    ed = _fetch(FILES["encapdecap"])

    kg_tests = _keygen_group(kg["testGroups"])["tests"]
    enc_tests = _group(ed["testGroups"], "encapsulation")["tests"]
    dec_tests = _group(ed["testGroups"], "decapsulation")["tests"]

    if args.quick:
        kg_tests = [t for t in kg_tests if t["tcId"] in (26,)]
        enc_tests = [t for t in enc_tests if t["tcId"] in (26,)]
        dec_tests = [t for t in dec_tests if t["tcId"] in (86, 88)]

    kat = {
        "keygen": [
            {
                "tcId": t["tcId"],
                "d": t["d"],
                "z": t["z"],
                "ek_sha256": hashlib.sha256(bytes.fromhex(t["ek"])).hexdigest(),
                "dk_sha256": hashlib.sha256(bytes.fromhex(t["dk"])).hexdigest(),
            }
            for t in kg_tests
        ],
        "encaps": [
            {"tcId": t["tcId"], "ek": t["ek"], "m": t["m"], "c": t["c"], "k": t["k"]}
            for t in enc_tests
        ],
        "decaps": [
            {
                "tcId": t["tcId"],
                "reason": t.get("reason", ""),
                "dk": t["dk"],
                "c": t["c"],
                "k": t["k"],
            }
            for t in dec_tests
        ],
    }

    out = pathlib.Path(args.out)
    out.write_text(json.dumps(kat))
    print(
        f"wrote {out} "
        f"(keygen={len(kat['keygen'])}, encaps={len(kat['encaps'])}, "
        f"decaps={len(kat['decaps'])})"
    )


if __name__ == "__main__":
    main()
