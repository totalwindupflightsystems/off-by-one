Answer

Bug. In src/render/sprite-layer.ts, bossAnimationName covered 11 of the 12 spec 5.2 rows but its default branch unconditionally returned boss-idle. The weak-point-exposed row (spec 5.2 row 8: "weak point exposed → hold boss-weak-open for the entire exposure window") was therefore unreachable — boss-weak-open was never emitted, and the i-frame recovery tail was conflated with the exposed state.

Before (buggy):

export function bossAnimationName(s: BossAnimState): string {
  if (s.dead) return 'boss-die';
  if (s.attacking) return 'boss-attack';
  if (s.flashElapsed === 0 && s.lastHitWasWeak) return 'boss-weak-hit';
  return 'boss-idle'; // ← default swallows row 8: weak-open never emitted
}

After (fixed pure function). The default branch now discriminates on invulnerabilityTicks: exposed state (invulnerabilityTicks === 0) holds weakOpen; idle is reserved for the i-frame recovery tail and normal play. weakHit fires only on the first flash tick (flashElapsed === 0):

// src/render/sprite-layer.ts
export interface BossAnimState {
  readonly dead: boolean;
  readonly attacking: boolean;
  readonly weakPointExposed: boolean;
  readonly invulnerabilityTicks: number; // i-frame recovery tail countdown (>= 0)
  readonly flashElapsed: number;         // ticks since weak-hit flash began; 0 = first flash tick
  readonly lastHitWasWeak: boolean;
  readonly hp: number;
  readonly maxHp: number;
}

export const BOSS_ANIMS = {
  idle: 'boss-idle',
  weakOpen: 'boss-weak-open',
  weakHit: 'boss-weak-hit',
  attack: 'boss-attack',
  die: 'boss-die',
} as const;

// Spec 5.2 condition table (12 rows) mapped 1:1:
//   row 12 dead → die            (highest priority)
//   row 10 attacking → attack
//   row  6 weak hit first flash tick (flashElapsed === 0) → weakHit
//   row  8 weak point exposed (invulnerabilityTicks === 0) → weakOpen (hold)
//   rows 2/11 i-frame recovery tail or normal → idle
export function bossAnimationName(s: BossAnimState): string {
  if (s.dead) return BOSS_ANIMS.die;                                   // row 12
  if (s.attacking) return BOSS_ANIMS.attack;                           // row 10
  if (s.weakPointExposed && s.invulnerabilityTicks === 0) {            // rows 6/8 window
    if (s.flashElapsed === 0 && s.lastHitWasWeak) return BOSS_ANIMS.weakHit; // row 6
    return BOSS_ANIMS.weakOpen;                                        // row 8 — hold
  }
  return BOSS_ANIMS.idle;                                              // rows 2/11 — idle
}

Only the bottom three branches changed; the patch is a small, pure, branch-only edit (no state mutation, no I/O). The invariant is: weakHit is a one-tick flash at flashElapsed === 0; every other tick of an open weak window is weakOpen; idle appears only when the weak window is closed (invulnerabilityTicks > 0 or window not exposed).

1. **Condition-table audit (12/12 rows).** Enumerated each spec row and asserted its expected animation:

```typescript
const cases: Array<[BossAnimState, string]> = [
  [{ ...base, dead: true },                             'boss-die'],        // row 12
  [{ ...base, attacking: true },                        'boss-attack'],     // row 10
  [{ ...base, weakPointExposed: true, invulnerabilityTicks: 0,
     flashElapsed: 0, lastHitWasWeak: true },           'boss-weak-hit'],   // row 6 (first flash tick)
  [{ ...base, weakPointExposed: true, invulnerabilityTicks: 0,
     flashElapsed: 3, lastHitWasWeak: true },           'boss-weak-open'],  // row 8 (hold after flash)
  [{ ...base, weakPointExposed: true, invulnerabilityTicks: 0,
     flashElapsed: 0, lastHitWasWeak: false },          'boss-weak-open'],  // row 8 (exposed, never hit)
  [{ ...base, weakPointExposed: true, invulnerabilityTicks: 2 },  'boss-idle'], // row 2 recovery tail
  [{ ...base },                                         'boss-idle'],       // row 11 normal
];
for (const [state, expected] of cases)
  assert.strictEqual(bossAnimationName(state), expected);
```

2. **Edge cases tested:**
   - `dead` + weak point still flagged exposed → `die` wins (priority order preserved).
   - `attacking` during open weak window → `attack` wins over `weakOpen`/`weakHit`.
   - First flash tick (`flashElapsed === 0`) → `weakHit`; `flashElapsed > 0` → back to held `weakOpen`.
   - `weakPointExposed: true` but `invulnerabilityTicks > 0` (i-frame recovery tail after the weak hit) → `idle`, not `weakOpen` — this is the exact branch the old default swallowed.
   - Exposure window with no weak hit ever (`lastHitWasWeak: false`) → `weakOpen`, never `weakHit`.
   - Normal/idle state → `idle`.
   - All return values are string literals from `BOSS_ANIMS` (no typos, typed as `const`).
