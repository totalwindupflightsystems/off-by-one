Meshlet LOD DAG: error-bounded cut, culling, and border consistency

Root-cause analysis

The failures are caused by mixing selection, budgeting, and visibility culling in one mutable DAG traversal:

  1. Non-monotonic errors allow a parent and its descendants to be active simultaneously.
  2. Per-node activation instead of complete sibling-group replacement breaks the cut/antichain invariant.
  3. Hysteresis on the wrong quantity causes either cut thrash or unbounded errors.
  4. Budget enforcement by arbitrary node swaps can produce overlapping LODs or exceed the hard budget.
  5. Culling during cut traversal mutates the error/budget watermark, so invisible nodes change decisions for later siblings.
  6. Per-cluster cone culling used as a subtree test is unsafe: a child may still face the camera even if its parent's cone does not.
  7. LOD borders without shared border vertices/edges create T-junctions and cracks.

Exact fix

The complete runnable implementation is in:

  • ~/meshlet-lod.js — runtime
  • ~/meshlet-lod.test.js — deterministic 54-vertex, 9-cluster mesh and proof/tests
  • ~/SOLUTION.md — full markdown report with embedded source

Run it with:

node ~/meshlet-lod.test.js

The runtime enforces:

  • exactly one root, reachability, and strict parent.error > child.error;
  • a complete root-to-leaf antichain cut;
  • projected pixel error
    error * focalPixels / max(near, distanceToSphereNearSide);
  • hysteresis dead band target*(1-h) .. target*(1+h), with hard admitted error target*(1+h);
  • a hard triangle budget enforced only by merging complete sibling groups;
  • frustum-sphere and normal-cone culling after selection, per cut node, without touching the frozen watermark;
  • exact vertex-id border validation over every legal cut.

Core selection rule:

const high = targetPixelError * (1 + hysteresis);
const low  = targetPixelError * (1 - hysteresis);

// Previously active node needs a higher error to split.
// Previously expanded node keeps its children until error falls below low.
const split = previous.has(id) ? err > high : err > low;

Budget merges are legal only when every immediate child is active:

if (!p.children.every(cid => selected.has(cid))) continue;
const savings = childTriangles - p.triangleCount;

Culling is deliberately separate:

const selection = dag.selectCut({ camera, targetPixelError, triangleBudget });
const stats = dag.cullCut(selection, camera, viewProjection);

// selection.nodes and selection.watermark are unchanged by cullCut().

What this proves:

  • All 17 possible cuts are legal antichains.
  • Every internal border edge occurs exactly twice with opposite winding.
  • No unmatched coarse edge exists, so no T-junction or crack occurs in any mixed-LOD cut.
  • Budget 60 is met exactly: 2*12 + 2*18 = 60.
  • Budget 24 is met exactly by the root cut.
  • Frustum culling removes 2/4 cut nodes, ratio 0.5, drawing 36/72 triangles.
  • Backface cone culling removes 1/1 cut node, ratio 1.0, drawing 0/24 triangles.
  • Culling does not mutate selection.nodes or selection.watermark.
  • Hysteresis holds the parent inside the dead band and releases it only after the error exceeds the upper threshold.
