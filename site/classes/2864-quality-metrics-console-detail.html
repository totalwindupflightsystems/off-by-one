Fix: Tier1Result.summary reports the wrong line for quality failures

Summary

For kind == "quality" failures, Tier1Result.summary fell through to the generic out_lines[-1] fallback. Because the console capture appends the diff-scope block after the metric line, out_lines[-1] is the diff-scope tail (e.g. diff-scope: 3 files changed, ...) rather than the metric line (e.g. quality: line coverage 78.0% < 90.0% threshold). The fix adds a quality-specific branch that extracts the first quality: line, with the old tail behavior retained only as a fallback.

Root-cause analysis

Tier1Result.summary was an if/elif chain keyed on tier kind: - "test" had a dedicated branch that scanned out_lines for the first tests: line. - "quality" had no branch, so it reached the default return out_lines[-1].

The buffer for a failed quality gate is metric-first and diff-scope-last:

quality: line coverage 78.0% < 90.0% threshold                  <- wanted
diff-scope: 3 files changed, 6 insertions(+), 4 deletions(-)    <- out_lines[-1]

Taking the last line therefore selected the diff-scope summary. The test branch worked because it searched for its metric prefix instead of indexing the end of the buffer; the quality tier needed the same treatment.

Exact fix

Add a quality branch before the final fallback:

     def summary(self) -> str:
         if not self.failed:
             return "ok"
         if self.kind == "test":
             for line in self.out_lines:
                 if line.startswith("tests:"):
                     return line.strip()
             return self._tail()
+        if self.kind == "quality":
+            for line in self.out_lines:
+                if line.startswith("quality:"):
+                    return line.strip()
+            return self._tail()
         return self._tail()

Equivalent next(...) form (note the formatting requirement):

        if self.kind == "quality":
            metric = next(
                (line for line in self.out_lines if line.startswith("quality:")),
                self.out_lines[-1] if self.out_lines else "",
            )
            return metric.strip()

Ruff format compliance

The condensed one-liner exceeds the line length; the inline conditional must be wrapped (or replaced by the _tail() helper):

-        metric = next((line for line in self.out_lines if line.startswith("quality:")), self.out_lines[-1] if self.out_lines else "")
+        metric = next(
+            (line for line in self.out_lines if line.startswith("quality:")),
+            self.out_lines[-1] if self.out_lines else "",
+        )
