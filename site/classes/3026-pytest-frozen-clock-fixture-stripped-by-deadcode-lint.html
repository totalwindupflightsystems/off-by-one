Fix: ARG001 lint pass strips pytest fixture parameters and defrosts the quota clock

Symptom

assert datetime.datetime(2026, 10, 28, 7, 47, tzinfo=utc) == datetime.datetime(2026, 10, 23, 12, 0, tzinfo=utc)
    at tests/test_quotas_api.py:460

Expected 2026-10-23 12:00 = frozen instant. Actual 2026-10-28 07:47 = live wall clock. The clock freeze never happens.

Root cause

In pytest a fixture is activated by the presence of its name in the test signature. Side-effect fixtures (frozen_clock doing monkeypatch.setattr) are intentionally never referenced in the body:

def test_window_start(frozen_clock):          # this parameter IS the activation
    assert result_timestamp() == FROZEN_CONSTANT

ARG001 sees an unused argument and the dead-code pass removes it:

def test_window_start():                       # fixture no longer activated
    assert result_timestamp() == FROZEN_CONSTANT

monkeypatch never patches datetime, production reads the live clock, assertion fails. The failure is date-dependent (green while the frozen instant is in the future, red once it's past) and invisible when CI is down because pytest never runs.

Modern Ruff (verified 0.15.22) only reports ARG001; it does not auto-fix it. The strip comes from the project's dead-code codemod/older autofixer. The fix is identical either way.

Exact fix

Preferred: @pytest.mark.usefixtures, drop the parameter

import datetime as dt
import pytest
from production import result_timestamp

FROZEN_CONSTANT = dt.datetime(2026, 10, 23, 12, 0, tzinfo=dt.timezone.utc)

@pytest.mark.usefixtures("frozen_clock")          # fixture still runs, no parameter
def test_window_start_uses_frozen_clock():
    assert result_timestamp() == FROZEN_CONSTANT

Fixture unchanged:

# tests/conftest.py
import datetime as dt
import pytest
import production

FROZEN_INSTANT = dt.datetime(2026, 10, 23, 12, 0, tzinfo=dt.timezone.utc)

@pytest.fixture
def frozen_clock(monkeypatch):
    """Freeze datetime.now() to FROZEN_INSTANT for quota-window math."""
    class FrozenDatetime(dt.datetime):
        @classmethod
        def now(cls, tz=None):
            if tz is not None:
                return FROZEN_INSTANT
            return FROZEN_INSTANT.replace(tzinfo=None)

    monkeypatch.setattr(production.dt, "datetime", FrozenDatetime)

Alternative A: line-scoped noqa

def test_window_start_uses_frozen_clock(frozen_clock):  # noqa: ARG001
    assert result_timestamp() == FROZEN_CONSTANT

Alternative B: scope the ignore to tests

# pyproject.toml (or ruff.toml)
[tool.ruff.lint]
select = ["ARG"]

[tool.ruff.lint.per-file-ignores]
"tests/**" = ["ARG001"]

Do not add _ = frozen_clock or otherwise reference the fixture just to appease the linter. Use usefixtures.

Verification

All steps actually executed on Ruff 0.15.22 / pytest 9.0.2:

# 1. Fixture parameter present -> passes
python3 -m pytest -q
# 1 passed

# 2. Lint flags the parameter
ruff check --select ARG tests/
# tests/test_quotas_api.py:6:41: ARG001 Unused function argument: `frozen_clock`
# Found 1 error.

# 3. Simulate the dead-code pass removing it -> defrost, fail
python3 -m pytest -q
# assert datetime.datetime(2026, 10, 28, 19, 40, 34, tzinfo=utc) == \
#        datetime.datetime(2026, 10, 23, 12, 0, tzinfo=utc)
# FAILED

# 4. Apply @pytest.mark.usefixtures("frozen_clock")
ruff check --select ARG tests/     # All checks passed!
python3 -m pytest -q               # 1 passed

The # noqa and per-file-ignores variants were also verified green.

Extra guard (recommended)

Fail on defrost immediately rather than only after the frozen date passes:

@pytest.mark.usefixtures("frozen_clock")
def test_window_start_uses_frozen_clock():
    assert result_timestamp() == FROZEN_CONSTANT
    # Canary: fails on every wall-clock date if the fixture is ever dropped.
    assert dt.datetime.now(dt.timezone.utc) == FROZEN_CONSTANT

(Use the same module object the fixture patched — read it via production.dt.datetime or a production.now_utc() helper.)

Prevention checklist

  • Use @pytest.mark.usefixtures(...) for side-effect fixtures; keep signatures free of unused parameters.
  • Disable ARG001 under tests/**, or mandate usefixtures there.
  • Add the in-test freeze assertion so defrosting fails deterministically.
  • Treat "CI was down, so it passed" as a red flag: run tests on a schedule and never rely on the host clock.
