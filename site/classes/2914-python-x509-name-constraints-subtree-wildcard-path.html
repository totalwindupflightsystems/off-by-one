RFC 5280 Name Constraints for a Multi-Level Chain

Root-cause analysis

The failures come from treating name constraints as a per-certificate string check instead of path state. A correct validator must:

  1. Intersect permitted subtrees down the path. Each CA extension with permitted subtrees of a name type adds an AND-layer. Multiple subtrees inside one extension are OR’d. A leaf must fall inside every layer. An intermediate can narrow the namespace; a leaf cannot widen it again.
  2. Union excluded subtrees across the path. Any match against an excluded subtree from any CA is fatal, regardless of permitted subtrees.
  3. Distinguish “no permitted subtree of this type” from “deny all.” A DNS-only constraint does not restrict email, IP, or URI. Once a permitted layer exists for a type, every presented name of that type must match it.
  4. Apply the correct namespace rules.
  5. Leading-dot DNS/URI/email constraints are full subtrees and exclude the apex; no-dot constraints are host-only; mailbox constraints are exact.
  6. IP constraints are CIDR networks. /32 and /128 are host-only; shorter prefixes cover ranges.
  7. URI constraints match only the authority host, not path, port, or query.
  8. Treat SAN as authoritative. CN is a DNS fallback only for an end-entity certificate with no SAN at all. A constrained CN must never rescue an out-of-subtree SAN.
  9. Match wildcard SANs literally, label by label. A wildcard is just a left-hand label for subtree membership. It must not be stripped or expanded as a glob. This prevents *.evil.com from escaping .example.com and prevents *.example.com from being accepted by the host-only constraint example.com.
  10. Report the exact failing layer. The verdict should include the offending name, the violated subtree, and the CA certificate that imposed it.

RFC 5280’s DNS prose technically says a no-dot DNS constraint also covers left-added labels. The implementation supports that with rfc5280_dns=True; the default implements the leading-dot/host-only distinction.

"""RFC 5280 name-constraints validation for a certificate chain.

The module is deliberately independent of any web/PKI framework: pass it a
list of ``cryptography.x509.Certificate`` objects (root-first or leaf-first)
and it returns one verdict per certificate.

Default matching rules
----------------------
* DNS/URI: a constraint beginning with ``.`` is a full subtree and does *not*
  include the apex.  A constraint without the dot is host-only.  Set
  ``dns_rfc5280=True`` to use RFC 5280's DNS rule where a no-dot constraint
  also covers names that add labels on the left.
* email: ``<email>`` is one mailbox, ``host`` is all mailboxes at that host,
  ``.domain`` is every mailbox below (but not at) ``domain``.
* IP: constraints are CIDR networks; a /32 or /128 is host-only.
* directoryName: X.500 DN-subtree matching (root-to-leaf RDN prefix).

Permitted subtrees are kept as one layer per CA extension.  A presented name
must match at least one subtree in *every* layer (intersection down the path).
Excluded subtrees from all CA extensions are unioned.  Excluded wins over
permitted.  DNS/URI wildcard SANs are matched literally, label by label, so a
wildcard cannot be used to skip over a subtree boundary.
"""

from __future__ import annotations

import ipaddress
from dataclasses import dataclass, field
from typing import Any, Iterable, Sequence
from urllib.parse import urlsplit

from cryptography import x509
from cryptography.x509.oid import ExtensionOID, NameOID


# ---------------------------------------------------------------------------
# Normalised constraints and presented names
# ---------------------------------------------------------------------------

@dataclass(frozen=True)
class Subtree:
    kind: str                 # dns, ip, email, uri, dn
    value: Any
    raw: str
    full_subtree: bool = False
    source: str = ""


@dataclass(frozen=True)
class PresentedName:
    kind: str
    value: Any
    display: str
    source: str


def _strip_trailing_dot(s: str) -> str:
    return s[:-1] if s.endswith(".") and len(s) > 1 else s


def _norm_dns(value: str, *, full: bool | None = None) -> tuple[str, bool]:
    s = _strip_trailing_dot(value.strip().lower())
    if full is None:
        full = s.startswith(".")
    if s.startswith("."):
        s = s[1:]
    return _strip_trailing_dot(s), bool(full)


def _make_subtree(gn: x509.GeneralName, source: str) -> Subtree | None:
    if isinstance(gn, x509.DNSName):
        base, full = _norm_dns(gn.value)
        return Subtree("dns", base, f"DNS:{gn.value}", full, source)

    if isinstance(gn, x509.RFC822Name):
        s = gn.value.strip()
        if s.startswith("."):
            domain, _ = _norm_dns(s)
            return Subtree("email", (None, domain), f"email:{s}", True, source)
        if "@" in s:
            local, domain = s.rsplit("@", 1)
            domain, _ = _norm_dns(domain)
            return Subtree("email", (local, domain), f"email:{s}", False, source)
        domain, _ = _norm_dns(s)
        return Subtree("email", (None, domain), f"email:{s}", False, source)

    if isinstance(gn, x509.UniformResourceIdentifier):
        # RFC 5280 puts only the host/domain in a URI constraint, but accepting
        # a complete URI here is harmless and helps hand-built fixtures.
        s = gn.value.strip()
        full = s.startswith(".")
        if "://" in s:
            host = urlsplit(s).hostname or ""
            base, _ = _norm_dns(host)
        else:
            base, full = _norm_dns(s, full=full)
        return Subtree("uri", base, f"URI:{s}", full, source)

    if isinstance(gn, x509.IPAddress):
        net = gn.value
        if not isinstance(net, (ipaddress.IPv4Network, ipaddress.IPv6Network)):
            net = ipaddress.ip_network(net, strict=False)
        return Subtree("ip", net, f"IP:{net}", False, source)

    if isinstance(gn, x509.DirectoryName):
        return Subtree("dn", gn.value, f"DN:{gn.value.rfc4514_string()}", False, source)

    # Unsupported GeneralName kinds are ignored here; a production policy may
    # instead reject any critical constraint on such a kind.
    return None


# ---------------------------------------------------------------------------
# Matching primitives
# ---------------------------------------------------------------------------

def _proper_subdomain(name: str, base: str) -> bool:
    """True iff name has at least one extra label to the left of base."""
    n = _strip_trailing_dot(name.lower()).split(".")
    b = _strip_trailing_dot(base.lower()).split(".")
    return len(n) > len(b) and n[-len(b):] == b


def _host_equal(name: str, base: str) -> bool:
    return _strip_trailing_dot(name.lower()) == _strip_trailing_dot(base.lower())


def _dns_matches(host: str, sub: Subtree, *, rfc5280_dns: bool) -> bool:
    host = _strip_trailing_dot(host.lower())
    base = sub.value
    if sub.full_subtree:
        return _proper_subdomain(host, base)
    if rfc5280_dns:
        # RFC 5280: zero or more labels may be prepended to the base.
        return host == base or _proper_subdomain(host, base)
    return _host_equal(host, base)


def _email_matches(addr: str, sub: Subtree) -> bool:
    if "@" not in addr:
        return False
    local, domain = addr.rsplit("@", 1)
    domain, _ = _norm_dns(domain, full=False)
    base_local, base_domain = sub.value
    if base_local is not None:
        return local == base_local and domain == base_domain
    if sub.full_subtree:
        return _proper_subdomain(domain, base_domain)
    return domain == base_domain


def _uri_matches(host: str | None, sub: Subtree, *, rfc5280_dns: bool) -> bool:
    if not host:
        return False
    # URI constraints are DNS-name constraints on the authority host.
    try:
        ipaddress.ip_address(host)
        return False
    except ValueError:
        pass
    return _dns_matches(host, sub, rfc5280_dns=rfc5280_dns)


def _norm_dn_value(value: Any) -> Any:
    if isinstance(value, str):
        return " ".join(value.casefold().split())
    if isinstance(value, bytes):
        return value
    return value


def _rdn_equal(a: x509.RelativeDistinguishedName,
               b: x509.RelativeDistinguishedName) -> bool:
    if len(a) != len(b):
        return False
    aa = sorted((attr.oid.dotted_string, _norm_dn_value(attr.value)) for attr in a)
    bb = sorted((attr.oid.dotted_string, _norm_dn_value(attr.value)) for attr in b)
    return aa == bb


def _dn_within(name: x509.Name, base: x509.Name) -> bool:
    # cryptography keeps RDNs in DER order (root-most first).
    if len(name.rdns) < len(base.rdns):
        return False
    return all(_rdn_equal(n, b) for n, b in zip(name.rdns, base.rdns))


def _matches(pn: PresentedName, sub: Subtree, *, rfc5280_dns: bool) -> bool:
    if pn.kind != sub.kind:
        return False
    if pn.kind == "dns":
        return _dns_matches(pn.value, sub, rfc5280_dns=rfc5280_dns)
    if pn.kind == "email":
        return _email_matches(pn.value, sub)
    if pn.kind == "uri":
        return _uri_matches(pn.value, sub, rfc5280_dns=rfc5280_dns)
    if pn.kind == "ip":
        if pn.value.version != sub.value.version:
            return False
        return pn.value in sub.value
    if pn.kind == "dn":
        return _dn_within(pn.value, sub.value)
    return False


# ---------------------------------------------------------------------------
# Extract names from a certificate
# ---------------------------------------------------------------------------

def _san_values(cert: x509.Certificate) -> tuple[bool, list[tuple[str, Any, str]]]:
    """Return (has_san, [(kind, value, label), ...])."""
    try:
        ext = cert.extensions.get_extension_for_class(x509.SubjectAlternativeName)
    except x509.ExtensionNotFound:
        return False, []

    san = ext.value
    out: list[tuple[str, Any, str]] = []
    for v in san.get_values_for_type(x509.DNSName):
        out.append(("dns", v, f"SAN dNSName:{v}"))
    for v in san.get_values_for_type(x509.RFC822Name):
        out.append(("email", v, f"SAN rfc822Name:{v}"))
    for v in san.get_values_for_type(x509.UniformResourceIdentifier):
        host = urlsplit(v).hostname
        out.append(("uri", host, f"SAN URI:{v}"))
    for v in san.get_values_for_type(x509.IPAddress):
        out.append(("ip", v, f"SAN iPAddress:{v}"))
    for v in san.get_values_for_type(x509.DirectoryName):
        out.append(("dn", v, f"SAN directoryName:{v.rfc4514_string()}"))
    return True, out


def extract_names(cert: x509.Certificate, *,
                  cn_fallback: bool = True) -> list[PresentedName]:
    """Extract the names to which constraints apply.

    SAN is authoritative.  CN is used as a DNS identity only for an end-entity
    certificate when there is no SAN extension at all.  This is the important
    anti-trap rule: a constrained CN must never rescue an out-of-subtree SAN.
    """
    has_san, raw = _san_values(cert)
    names: list[PresentedName] = [
        PresentedName(kind, value, str(value), label) for kind, value, label in raw
    ]

    if cn_fallback and not has_san:
        for attr in cert.subject.get_attributes_for_oid(NameOID.COMMON_NAME):
            if isinstance(attr.value, str):
                names.append(PresentedName(
                    "dns", attr.value, attr.value, f"subject CN fallback:{attr.value}"
                ))
        for attr in cert.subject.get_attributes_for_oid(NameOID.EMAIL_ADDRESS):
            if isinstance(attr.value, str):
                names.append(PresentedName(
                    "email", attr.value, attr.value,
                    f"subject emailAddress fallback:{attr.value}",
                ))

    # directoryName constraints apply to the subject DN independently of SAN.
    if len(cert.subject):
        names.append(PresentedName(
            "dn", cert.subject, cert.subject.rfc4514_string(),
            "subject DN",
        ))
    return names


# ---------------------------------------------------------------------------
# Constraint state
# ---------------------------------------------------------------------------

@dataclass(frozen=True)
class PermittedLayer:
    subtrees: tuple[Subtree, ...]
    source: str


@dataclass
class ConstraintState:
    # kind -> list of AND-layers; each layer is an OR-list of subtrees.
    permitted: dict[str, list[PermittedLayer]] = field(default_factory=dict)
    # kind -> union of excluded subtrees.
    excluded: dict[str, list[Subtree]] = field(default_factory=dict)

    def has_kind(self, kind: str) -> bool:
        return bool(self.permitted.get(kind) or self.excluded.get(kind))

    def add_certificate(self, cert: x509.Certificate, source: str) -> None:
        try:
            ext = cert.extensions.get_extension_for_oid(ExtensionOID.NAME_CONSTRAINTS)
        except x509.ExtensionNotFound:
            return
        nc: x509.NameConstraints = ext.value

        if nc.permitted_subtrees:
            by_kind: dict[str, list[Subtree]] = {}
            for gn in nc.permitted_subtrees:
                sub = _make_subtree(gn, source)
                if sub is not None:
                    by_kind.setdefault(sub.kind, []).append(sub)
            for kind, subtrees in by_kind.items():
                self.permitted.setdefault(kind, []).append(
                    PermittedLayer(tuple(subtrees), source)
                )

        if nc.excluded_subtrees:
            for gn in nc.excluded_subtrees:
                sub = _make_subtree(gn, source)
                if sub is not None:
                    self.excluded.setdefault(sub.kind, []).append(sub)


# ---------------------------------------------------------------------------
# Validation
# ---------------------------------------------------------------------------

def _violation(pn: PresentedName, rule: str, source: str,
               constraints: Iterable[str], reason: str) -> dict[str, Any]:
    return {
        "name": pn.display,
        "name_source": pn.source,
        "kind": pn.kind,
        "rule": rule,                       # permitted / excluded / unusable
        "constraint": list(constraints),
        "constraint_certificate": source,
        "reason": reason,
    }


def _check_name(pn: PresentedName, state: ConstraintState, *,
                rfc5280_dns: bool) -> list[dict[str, Any]]:
    out: list[dict[str, Any]] = []

    # RFC 5280: if URI constraints are in force, a URI whose authority has no
    # DNS host (or has an IP literal) must be rejected, not silently skipped.
    if pn.kind == "uri" and state.has_kind("uri"):
        if not pn.value:
            out.append(_violation(
                pn, "unusable", "URI constraint active", [],
                "URI has no authority host name",
            ))
            return out
        try:
            ipaddress.ip_address(pn.value)
        except ValueError:
            pass
        else:
            out.append(_violation(
                pn, "unusable", "URI constraint active", [],
                "URI authority is an IP address, not a DNS name",
            ))
            return out

    for sub in state.excluded.get(pn.kind, []):
        if _matches(pn, sub, rfc5280_dns=rfc5280_dns):
            out.append(_violation(
                pn, "excluded", sub.source, [sub.raw],
                f"name matches excluded subtree {sub.raw}",
            ))

    for layer in state.permitted.get(pn.kind, []):
        if not any(_matches(pn, s, rfc5280_dns=rfc5280_dns)
                   for s in layer.subtrees):
            out.append(_violation(
                pn, "permitted", layer.source,
                [s.raw for s in layer.subtrees],
                "name is outside every permitted subtree in this layer",
            ))
    return out


@dataclass
class CertVerdict:
    index: int
    subject: str
    is_ca: bool
    allowed: bool
    names: list[str]
    violations: list[dict[str, Any]]


def _is_ca(cert: x509.Certificate) -> bool:
    try:
        bc = cert.extensions.get_extension_for_class(x509.BasicConstraints).value
        return bool(bc.ca)
    except x509.ExtensionNotFound:
        return False


def _root_to_leaf(chain: Sequence[x509.Certificate]) -> list[x509.Certificate]:
    chain = list(chain)
    if len(chain) < 2:
        return chain
    if chain[1].issuer == chain[0].subject:
        return chain
    if chain[0].issuer == chain[1].subject:
        return list(reversed(chain))
    # Fallback: find the cert that is not issued by another member (the root)
    # and walk issuer links.  This also supports unordered input.
    by_subject = {c.subject: c for c in chain}
    start = next((c for c in chain if c.issuer not in by_subject), chain[0])
    ordered = [start]
    used = {start}
    while len(ordered) < len(chain):
        nxt = next(
            (c for c in chain
             if c not in used and c.issuer == ordered[-1].subject),
            None,
        )
        if nxt is None:
            break
        ordered.append(nxt)
        used.add(nxt)
    ordered.extend(c for c in chain if c not in used)
    return ordered


def evaluate_chain(chain: Sequence[x509.Certificate], *,
                   rfc5280_dns: bool = False) -> list[CertVerdict]:
    """Validate every certificate in *chain* against constraints from CAs above it.

    ``chain`` may be root-first or leaf-first.  The return value is in
    root-to-leaf order.  A CA's own name-constraints are added only after that
    CA's names have been checked, because RFC 5280 applies them to subsequent
    certificates.
    """
    ordered = _root_to_leaf(chain)
    state = ConstraintState()
    verdicts: list[CertVerdict] = []
    last = len(ordered) - 1

    for i, cert in enumerate(ordered):
        subject = cert.subject.rfc4514_string()
        is_ca = _is_ca(cert)
        # Self-issued certificates are exempt from constraints on themselves
        # unless they are the final certificate in the path.
        self_issued = cert.subject == cert.issuer
        check_this = not (self_issued and is_ca and i != last)

        # DNS/email CN fallback is an end-entity identity rule, not a CA
        # identity rule (a CA subject is handled by directoryName constraints).
        names = extract_names(cert, cn_fallback=not is_ca)
        violations: list[dict[str, Any]] = []
        if check_this:
            for pn in names:
                violations.extend(_check_name(
                    pn, state, rfc5280_dns=rfc5280_dns
                ))

        verdicts.append(CertVerdict(
            index=i,
            subject=subject,
            is_ca=is_ca,
            allowed=not violations,
            names=[f"{n.kind}:{n.display} ({n.source})" for n in names],
            violations=violations,
        ))

        source = f"cert[{i}] {subject}"
        state.add_certificate(cert, source)

    return verdicts


def chain_allowed(chain: Sequence[x509.Certificate], *,
                  rfc5280_dns: bool = False) -> bool:
    return all(v.allowed for v in evaluate_chain(
        chain, rfc5280_dns=rfc5280_dns
    ))
