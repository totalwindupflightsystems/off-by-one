URL Authority-Differential Rewrite Audit

Problem class: js20261017-csp-url-authority-differential-rewrite-audit

TL;DR

A single URL is parsed independently by a proxy (the security decision maker), a browser-compatible WHATWG parser, and a downstream fetch client. Their canonicalisations of authority/path legitimately differ for the same bytes. An SSRF exists whenever the proxy classifies a destination as public/safe while the component that actually opens the socket resolves it to a private, loopback, link-local, metadata, or otherwise non-public address.

This document provides a complete, dependency-free Node.js auditor that computes the effective (scheme, host, port, path) for every component, resolves hosts offline (numeric IPv4 in every base, IPv6, IDNA/Unicode, trailing root dot, percent-encoded authorities, embedded IPv4 in IPv6), classifies destinations, reports each security-relevant divergence with a minimal reproducer, suppresses false positives for equivalent canonical forms, and audits redirect chains and rewrites. 66/66 unit tests and 30/30 self-contained verifier assertions pass.

Root-cause analysis

URL parsers are not interchangeable. For the same byte string each component runs a different normalisation pipeline; every stage is a place where the host the proxy validated stops being the host the socket connects to.

# Differential Example Proxy sees WHATWG / fetch sees
1 Userinfo split order http://evil.com@<ip-address>/ host evil.com (first segment) host <ip-address> (last segment)
2 Backslash as separator http://<ip-address>\.evil.com/ host <ip-address>\.evil.com host <ip-address>, path /.evil.com/
3 Alternate numeric IPv4 http://2130706433/, http://0x7f.0.0.1/, http://127.1/, http://0177.0.0.1/ a hostname <ip-address>
4 Unicode / IDNA mapping http://①②⑦.0.0.1/, http://ⓛocalhost/, http://127。0。0。1/ non-ASCII literal <ip-address> / localhost
5 IPv4-mapped IPv6 http://[::ffff:<ip-address>]/ opaque literal <ip-address> = loopback
6 Trailing root dot http://localhost./, http://localhost%2e/ localhost. (no deny-list hit) localhost = loopback
7 Percent-encoded host chars http://<ip-address>%2e.evil.com/, http://%31%32%<ip-address>/ literal encoded text re-decoded / split
8 Legacy url.parse http://<ip-address>%2e.evil.com/, http://<ip-address>%00.evil.com/ literal encoded text legacy host <ip-address>
9 Nested encodings http://<ip-address>%252e/ literal one or two decode passes
10 Redirect chains safe host → Location: http://<ip-address>/ only head validated every hop followed

The violated invariant:

The authority used for the policy decision must equal the authority actually connected to, after every applicable decoding / IDNA / numeric-IP / separator normalisation.

A naive auditor also errs in the other direction by flagging equivalent canonical forms. http://example.com, HTTP://Example.COM:80, and http://example.com./ all denote the same endpoint. The rule used here: compare canonical destination keys, not raw strings; only report when the classification (safe vs non-public) or the host identity actually changes.

Fix — the auditor

Save as auditor.js (zero dependencies, Node ≥ 16; verified on Node 22).

'use strict';

/**
 * csp-url-authority-differential-rewrite-audit
 * ------------------------------------------------------------
 * Compares the *effective authority and path* of a URL as seen by
 * three independent components:
 *
 *   1. proxy  - a hand-rolled, deny-list style forward proxy parser
 *               (the policy enforcement point).
 *   2. whatwg - a browser-compatible WHATWG URL parser (`new URL`).
 *   3. fetch  - the downstream client that actually opens the socket
 *               (modern Node == WHATWG, plus offline host resolution).
 *
 * A finding is raised when the components disagree about the
 * destination in a way that is SSRF relevant, i.e. the component
 * that made the security decision (`proxy`) saw a safe host while
 * the component that connects (`fetch`) reaches a private / loopback
 * / link-local / metadata / internal destination.  Canonical
 * equivalences (case, default port, trailing root dot, IDNA, numeric
 * IP spellings) are suppressed so that only real divergences are
 * reported.
 *
 * The auditor performs no network I/O: host resolution is fully
 * deterministic and offline.
 *
 * Zero dependencies. Node >= 16 (developed and verified on v22).
 */

const legacyUrl = require('node:url');
const { URL, domainToASCII } = require('node:url');

/* ------------------------------------------------------------------ *
 * Capability profiles
 * ------------------------------------------------------------------ */

// The proxy is intentionally naive: it recognises a *literal*
// dotted-quad private address and the bare name "localhost", but it
// does not understand alternate numeric IP spellings, IDNA/Unicode
// hosts, percent-encoded hosts, or a trailing root dot.
const PROXY_CAPS = Object.freeze({
  numeric: 'strict',   // only a.b.c.d with 4 dotted decimal octets
  idna: false,
  stripTrailingDot: false,
  decodeDepth: 0,
  ipv4Mapped: false,   // does not unwrap ::ffff:a.b.c.d
});

// WHATWG / modern fetch: full canonicalisation (one decode pass).
const FULL_CAPS = Object.freeze({
  numeric: 'full',
  idna: true,
  stripTrailingDot: true,
  decodeDepth: 1,
  ipv4Mapped: true,
});

// A stack that decodes the authority twice (nested encodings).
const DEEP_CAPS = Object.freeze({ ...FULL_CAPS, decodeDepth: 2 });

/* ------------------------------------------------------------------ *
 * Offline host resolution + destination classification
 * ------------------------------------------------------------------ */

const INTERNAL_KINDS = new Set([
  'loopback',
  'private',
  'linklocal',
  'metadata',
  'unspecified',
  'cgnat',
  'internal-name',
  'reserved',
]);

function classifyIpv4Octets(a, b, c, d) {
  if (a === 127) return { kind: 'loopback', reason: '<ip-address>/8' };
  if (a === 0) return { kind: 'unspecified', reason: '<ip-address>/8' };
  if (a === 10) return { kind: 'private', reason: '<ip-address>/8' };
  if (a === 172 && b >= 16 && b <= 31) return { kind: 'private', reason: '<ip-address>/12' };
  if (a === 192 && b === 168) return { kind: 'private', reason: '<ip-address>/16' };
  if (a === 169 && b === 254) {
    if (c === 169 && d === 254) return { kind: 'metadata', reason: 'cloud metadata <ip-address>' };
    return { kind: 'linklocal', reason: '<ip-address>/16' };
  }
  if (a === 100 && b >= 64 && b <= 127) return { kind: 'cgnat', reason: '<ip-address>/10' };
  if (a === 192 && b === 0 && c === 0) return { kind: 'reserved', reason: '<ip-address>/24' };
  if (a === 192 && b === 0 && c === 2) return { kind: 'documentation', reason: '<ip-address>/24' };
  if (a === 198 && (b === 18 || b === 19)) return { kind: 'benchmark', reason: '<ip-address>/15' };
  if (a === 198 && b === 51 && c === 100) return { kind: 'documentation', reason: '<ip-address>/24' };
  if (a === 203 && b === 0 && c === 113) return { kind: 'documentation', reason: '<ip-address>/24' };
  if (a >= 224 && a <= 239) return { kind: 'multicast', reason: '<ip-address>/4' };
  if (a >= 240) return { kind: 'reserved', reason: '<ip-address>/4' };
  return { kind: 'public', reason: 'public' };
}

// WHATWG-style IPv4 parser: accepts decimal / octal (leading 0) /
// hexadecimal (0x) parts and 1..4 parts.
function parseIpv4Full(input) {
  if (input == null) return null;
  let s = String(input);
  if (s === '') return null;
  let parts = s.split('.');
  if (parts[parts.length - 1] === '') parts = parts.slice(0, -1); // trailing root dot
  if (parts.length === 0 || parts.length > 4) return null;
  const numbers = [];
  for (const raw of parts) {
    if (raw === '') return null;
    let n;
    if (/^0[xX]/.test(raw)) {
      if (raw.length === 2) return null;
      if (!/^0[xX][0-9a-fA-F]+$/.test(raw)) return null;
      n = parseInt(raw.slice(2), 16);
    } else if (raw.length > 1 && raw[0] === '0') {
      if (!/^0[0-7]+$/.test(raw)) return null;
      n = parseInt(raw, 8);
    } else {
      if (!/^[0-9]+$/.test(raw)) return null;
      n = parseInt(raw, 10);
    }
    if (!Number.isFinite(n)) return null;
    numbers.push(n);
  }
  for (let i = 0; i < numbers.length - 1; i++) {
    if (numbers[i] > 255) return null;
  }
  const lastLimit = 256 ** (5 - numbers.length);
  if (numbers[numbers.length - 1] >= lastLimit) return null;
  let value = numbers[numbers.length - 1];
  for (let i = 0; i < numbers.length - 1; i++) {
    value += numbers[i] * 256 ** (3 - i);
  }
  if (value > 0xffffffff) return null;
  return [
    (value >>> 24) & 255,
    (value >>> 16) & 255,
    (value >>> 8) & 255,
    value & 255,
  ];
}

// Strict dotted quad: exactly four decimal octets, no leading zeros,
// each 0..255.  This is what a naive regex based deny-list understands.
function parseIpv4Strict(input) {
  if (input == null) return null;
  const s = String(input);
  if (!/^(0|[1-9][0-9]{0,2})(\.(0|[1-9][0-9]{0,2})){3}$/.test(s)) return null;
  const nums = s.split('.').map(Number);
  if (nums.some((n) => n > 255)) return null;
  return nums;
}

// Independent RFC 4291 IPv6 parser.  Returns 8 x 16-bit groups or null.
function parseIpv6(input) {
  if (input == null) return null;
  let s = String(input).trim().toLowerCase();
  if (s.startsWith('[') && s.endsWith(']')) s = s.slice(1, -1);
  const zone = s.indexOf('%');
  if (zone !== -1) s = s.slice(0, zone);
  if (s === '') return null;

  // Embedded IPv4 tail (e.g. ::ffff:<ip-address>)
  const m = /^(.*:)((?:\d{1,3}\.){3}\d{1,3})$/.exec(s);
  if (m) {
    const v4 = parseIpv4Full(m[2]);
    if (!v4) return null;
    const hi = ((v4[0] << 8) | v4[1]).toString(16);
    const lo = ((v4[2] << 8) | v4[3]).toString(16);
    s = m[1] + hi + ':' + lo;
  }

  const halves = s.split('::');
  if (halves.length > 2) return null;
  const left = halves[0] ? halves[0].split(':') : [];
  const right = halves.length === 2 ? (halves[1] ? halves[1].split(':') : []) : [];
  const ok = (h) => /^[0-9a-f]{1,4}$/.test(h);
  if (![...left, ...right].every(ok)) return null;

  let groups;
  if (halves.length === 2) {
    const fill = 8 - left.length - right.length;
    if (fill < 1) return null;
    groups = [...left, ...new Array(fill).fill('0'), ...right];
  } else {
    if (left.length !== 8) return null;
    groups = left;
  }
  if (groups.length !== 8) return null;
  return groups.map((h) => parseInt(h, 16));
}

function formatIpv6(groups) {
  const hex = groups.map((n) => n.toString(16));
  let bestStart = -1;
  let bestLen = 0;
  let i = 0;
  while (i < 8) {
    if (groups[i] === 0) {
      let j = i;
      while (j < 8 && groups[j] === 0) j++;
      if (j - i > bestLen) {
        bestLen = j - i;
        bestStart = i;
      }
      i = j;
    } else {
      i++;
    }
  }
  if (bestLen < 2) return hex.join(':');
  return hex.slice(0, bestStart).join(':') + '::' + hex.slice(bestStart + bestLen).join(':');
}

function classifyIpv6(groups, options = {}) {
  const ipv4Mapped = options.ipv4Mapped !== false;
  if (groups.every((n) => n === 0)) return { kind: 'unspecified', reason: '::' };
  if (groups.slice(0, 7).every((n) => n === 0) && groups[7] === 1) {
    return { kind: 'loopback', reason: '<ip-address>' };
  }
  // IPv4-mapped ::ffff:a.b.c.d
  if (ipv4Mapped && groups.slice(0, 5).every((n) => n === 0) && groups[5] === 0xffff) {
    const a = (groups[6] >> 8) & 255;
    const b = groups[6] & 255;
    const c = (groups[7] >> 8) & 255;
    const d = groups[7] & 255;
    const v4 = classifyIpv4Octets(a, b, c, d);
    if (v4.kind !== 'public') return { ...v4, reason: `IPv4-mapped ${v4.reason}` };
    return v4;
  }
  // IPv4-compatible ::a.b.c.d (deprecated, but still routed by some stacks)
  if (ipv4Mapped && groups.slice(0, 6).every((n) => n === 0)) {
    const a = (groups[6] >> 8) & 255;
    const b = groups[6] & 255;
    const c = (groups[7] >> 8) & 255;
    const d = groups[7] & 255;
    const v4 = classifyIpv4Octets(a, b, c, d);
    if (v4.kind !== 'public') return { ...v4, reason: `IPv4-compatible ${v4.reason}` };
    return v4;
  }
  if ((groups[0] & 0xffc0) === 0xfe80) return { kind: 'linklocal', reason: 'fe80::/10' };
  if ((groups[0] & 0xfe00) === 0xfc00) return { kind: 'private', reason: 'fc00::/7 (ULA)' };
  if ((groups[0] & 0xffc0) === 0xfec0) return { kind: 'private', reason: 'fec0::/10 (site-local)' };
  if ((groups[0] & 0xff00) === 0xff00) return { kind: 'multicast', reason: 'ff00::/8' };
  if (groups[0] === 0x2001 && groups[1] === 0x0db8) {
    return { kind: 'documentation', reason: '<ip-address>/32' };
  }
  return { kind: 'public', reason: 'public' };
}

function classifyHostname(name) {
  const n = String(name).toLowerCase();
  if (n === '' || n === '.') return { kind: 'none', reason: 'empty' };
  const labels = n.split('.');
  const last = labels[labels.length - 1];
  const last2 = labels.slice(-2).join('.');
  if (n === 'localhost' || last === 'localhost') return { kind: 'loopback', reason: 'localhost' };
  if (last === 'internal' || last2 === 'google.internal' || n === 'metadata' || n === 'instance-data') {
    return { kind: 'metadata', reason: 'cloud metadata / internal name' };
  }
  if (['local', 'home.arpa', 'lan', 'intranet', 'corp', 'private', 'test', 'invalid', 'example'].includes(last)) {
    return { kind: 'internal-name', reason: `special-use TLD .${last}` };
  }
  if (last === 'onion' || last === 'i2p') return { kind: 'reserved', reason: 'special-use TLD' };
  return { kind: 'public', reason: 'public' };
}

function tryDecodePercent(s) {
  if (!s || s.indexOf('%') === -1) return s;
  try {
    return decodeURIComponent(s);
  } catch {
    // Best-effort: decode only well formed escapes.
    return s.replace(/%([0-9a-fA-F]{2})/g, (m, hex) => {
      try {
        return String.fromCharCode(parseInt(hex, 16));
      } catch {
        return m;
      }
    });
  }
}

function safeDomainToASCII(s) {
  try {
    const out = domainToASCII(s);
    return out || null;
  } catch {
    return null;
  }
}

/**
 * Resolve a raw host string into a canonical destination according to
 * the capabilities of the component that produced it.
 *
 * Returns { key, kind, internal, reason, ip }.
 *   key      - canonical equivalence key (used to suppress false positives)
 *   kind     - classification bucket
 *   internal - true when the destination is not publicly routable
 */
function resolveHost(rawHost, caps) {
  const c = { ...FULL_CAPS, ...(caps || {}) };
  if (rawHost == null) return { key: '', kind: 'none', internal: false, reason: 'empty', ip: null };
  let h = String(rawHost).trim();
  let bracket = false;
  if (h.startsWith('[') && h.endsWith(']')) {
    bracket = true;
    h = h.slice(1, -1);
  }

  let work = h;
  const depth = typeof c.decodeDepth === 'number' ? c.decodeDepth : c.decodePercent ? 1 : 0;
  for (let i = 0; i < depth; i++) work = tryDecodePercent(work);
  let ascii = work;
  if (c.idna && !bracket) {
    const a = safeDomainToASCII(work);
    if (a) ascii = a;
  }
  if (c.stripTrailingDot && !bracket) ascii = ascii.replace(/\.+$/, '');
  const lower = ascii.toLowerCase();

  // IPv6 (bracketed or containing a colon)
  if (bracket || lower.includes(':')) {
    const g = parseIpv6(ascii);
    if (g) {
      const cls = classifyIpv6(g, { ipv4Mapped: c.ipv4Mapped !== false });
      const key = formatIpv6(g);
      return { key: `[${key}]`, kind: cls.kind, internal: INTERNAL_KINDS.has(cls.kind), reason: cls.reason, ip: key };
    }
    return { key: `[${lower}]`, kind: 'unknown', internal: false, reason: 'unparsable IPv6', ip: null };
  }

  // IPv4
  if (c.numeric === 'full' || c.numeric === 'strict') {
    const parser = c.numeric === 'full' ? parseIpv4Full : parseIpv4Strict;
    const v4 = parser(ascii);
    if (v4) {
      const cls = classifyIpv4Octets(v4[0], v4[1], v4[2], v4[3]);
      const key = v4.join('.');
      return { key, kind: cls.kind, internal: INTERNAL_KINDS.has(cls.kind), reason: cls.reason, ip: key };
    }
  }

  const cls = classifyHostname(lower);
  return { key: lower, kind: cls.kind, internal: INTERNAL_KINDS.has(cls.kind), reason: cls.reason, ip: null };
}

 * Parsers

function splitUserInfo(authority, firstAt) {
  // `firstAt: true` models the classic buggy gateway that does
  //   const host = authority.split('@')[0];
  // i.e. it treats the FIRST userinfo-looking segment as the host.
  // `firstAt: false` is the standards-correct LAST '@' split.
  const at = firstAt ? authority.indexOf('@') : authority.lastIndexOf('@');
  if (at === -1) return { userinfo: '', hostport: authority };
  if (firstAt) return { userinfo: authority.slice(at + 1), hostport: authority.slice(0, at) };
  return { userinfo: authority.slice(0, at), hostport: authority.slice(at + 1) };
}

function splitHostPort(hostport) {
  let host = hostport;
  let port = '';
  if (hostport.startsWith('[')) {
    const close = hostport.indexOf(']');
    if (close !== -1) {
      host = hostport.slice(0, close + 1);
      const after = hostport.slice(close + 1);
      if (after.startsWith(':')) port = after.slice(1);
    }
  } else {
    const ci = hostport.lastIndexOf(':');
    if (ci !== -1 && hostport.indexOf(':') === ci) {
      host = hostport.slice(0, ci);
      port = hostport.slice(ci + 1);
    }
  }
  return { host, port };
}

/**
 * The policy-enforcement proxy.  A deliberately literal, deny-list
 * oriented parser that mirrors what a large class of hand-written
 * gateways actually do.
 */
function parseProxy(input) {
  const q = {
    firstAt: true,
    backslashIsSeparator: false,
    treatMissingSlashesAsAuthority: true,
    ...(parseProxy.quirks || {}),
  };
  let s = String(input);
  let fragment = '';
  const hi = s.indexOf('#');
  if (hi !== -1) {
    fragment = s.slice(hi);
    s = s.slice(0, hi);
  }
  const sm = /^([A-Za-z][A-Za-z0-9+.-]*):/.exec(s);
  const scheme = sm ? sm[1].toLowerCase() : '';
  let rest = sm ? s.slice(sm[0].length) : s;

  let search = '';
  const qi = rest.indexOf('?');
  if (qi !== -1) {
    search = rest.slice(qi);
    rest = rest.slice(0, qi);
  }

  const isSep = (ch) => ch === '/' || (q.backslashIsSeparator && ch === '\\');

  if (rest.startsWith('//')) {
    rest = rest.slice(2);
  } else if (q.treatMissingSlashesAsAuthority && rest !== '' && !rest.startsWith('/')) {
    // "http:evil.com/path" -> authority starts immediately.
  } else if (rest.startsWith('/')) {
    // no authority
  }

  let end = rest.length;
  for (let i = 0; i < rest.length; i++) {
    if (isSep(rest[i])) {
      end = i;
      break;
    }
  }
  const authority = rest.slice(0, end);
  const path = rest.slice(end);
  const { userinfo, hostport } = splitUserInfo(authority, q.firstAt);
  const { host, port } = splitHostPort(hostport);

  return {
    component: 'proxy',
    ok: true,
    scheme,
    userinfo,
    host,
    port,
    path,
    search,
    fragment,
    rawAuthority: authority,
    href: s + search + fragment,
  };
}

function parseWhatwg(input, base) {
  try {
    const u = base ? new URL(input, base) : new URL(input);
    const userinfo = u.username
      ? u.username + (u.password ? ':' + u.password : '')
      : '';
    return {
      component: 'whatwg',
      ok: true,
      scheme: u.protocol.replace(/:$/, ''),
      userinfo,
      host: u.hostname,
      port: u.port,
      path: u.pathname,
      search: u.search,
      fragment: u.hash,
      rawAuthority: u.host,
      href: u.href,
    };
  } catch (err) {
    return {
      component: 'whatwg',
      ok: false,
      error: err.message,
      scheme: '',
      userinfo: '',
      host: '',
      port: '',
      path: '',
      search: '',
      fragment: '',
      rawAuthority: '',
      href: '',
    };
  }
}

function parseFetch(input, base) {
  const v = parseWhatwg(input, base);
  return { ...v, component: 'fetch' };
}

/**
 * Legacy Node `url.parse` client (pre-WHATWG semantics).  Still ships in
 * Node and is used by a large tail of HTTP libraries, so a proxy that
 * only reasons about WHATWG can be bypassed by clients that use it.
 */
function parseLegacy(input, base) {
  try {
    const resolved = base ? new URL(input, base).href : input;
    const u = legacyUrl.parse(resolved, false, true);
    let host = u.hostname || '';
    if (host.includes(':') && !host.startsWith('[')) host = `[${host}]`;
    return {
      component: 'legacy',
      ok: Boolean(u.hostname),
      scheme: (u.protocol || '').replace(/:$/, ''),
      userinfo: u.auth || '',
      host,
      port: u.port || '',
      path: u.pathname || '/',
      search: u.search || '',
      fragment: u.hash || '',
      rawAuthority: u.host || '',
      href: resolved,
    };
  } catch (err) {
    return { component: 'legacy', ok: false, error: err.message, scheme: '', userinfo: '', host: '', port: '', path: '', search: '', fragment: '', rawAuthority: '', href: '' };
  }
}

function normalizedPath(p) {
  let x = p == null ? '' : String(p);
  const cut = x.search(/[?#]/);
  if (cut !== -1) x = x.slice(0, cut);
  if (x === '') return '/';
  if (!x.startsWith('/')) x = '/' + x;
  x = x.replace(/\\/g, '/');
  x = x.replace(/\/{2,}/g, '/');
  return x;
}

const DEFAULT_PORTS = { http: '80', https: '443', ws: '80', wss: '443', ftp: '21' };

function effectivePort(scheme, port) {
  if (port) return String(port);
  return DEFAULT_PORTS[(scheme || 'http').toLowerCase()] || '';
}

function sameOrigin(a, b) {
  return (
    (a.scheme || 'http') === (b.scheme || 'http') &&
    a.key === b.key &&
    effectivePort(a.scheme, a.port) === effectivePort(b.scheme, b.port)
  );
}

function buildView(parsed, rawInput, caps) {
  const destination = resolveHost(parsed.host, caps);
  const keyDest = resolveHost(parsed.host, FULL_CAPS); // equivalence key
  return {
    ...parsed,
    input: rawInput,
    destination,
    key: keyDest.key,
    pathNorm: normalizedPath(parsed.path),
  };
}

function pushFinding(list, f) {

/**
 * audit(input, opts)
 *
 * opts.proxyQuirks  - override the proxy parser quirks
 * opts.reportPath   - also report non-security path divergence (default true)
 * opts.base         - base URL for relative inputs
 * opts.fetchParser  - 'whatwg' (default) or 'legacy'
 *
 * Returns { input, views, findings, safe, reproducers }
 */
function audit(input, opts = {}) {
  findingSeq = 0;
  parseProxy.quirks = opts.proxyQuirks || null;
  const findings = [];
  const base = opts.base;

  const fetchParser = opts.fetchParser === 'legacy' ? 'legacy' : 'whatwg';
  const proxy = buildView(parseProxy(input), input, PROXY_CAPS);
  const whatwg = buildView(parseWhatwg(input, base), input, FULL_CAPS);
  const fetch =
    fetchParser === 'legacy'
      ? buildView(parseLegacy(input, base), input, FULL_CAPS)
      : buildView(parseFetch(input, base), input, FULL_CAPS);
  const legacy = buildView(parseLegacy(input, base), input, FULL_CAPS);
  const deep = buildView(parseWhatwg(input, base), input, DEEP_CAPS);

  const views = { proxy, whatwg, fetch, legacy, deep };

  // Parser failure on the authoritative side is itself interesting.
  if (!whatwg.ok) {
    pushFinding(findings, {
      type: 'parse-error',
      severity: 'info',
      component: 'whatwg',
      detail: `WHATWG parser rejected input: ${whatwg.error}`,
    });
  }

  // 1. SSRF: proxy's deny-list says safe, but the connecting client
  //    reaches a non-public destination.
  if (fetch.ok && fetch.destination.internal && !proxy.destination.internal) {
    pushFinding(findings, {
      type: 'ssrf',
      severity: 'critical',
      component: 'proxy->fetch',
      detail:
        `proxy believes host ${JSON.stringify(proxy.host)} (${proxy.destination.reason}) ` +
        `but fetch resolves ${JSON.stringify(fetch.host)} -> ${fetch.destination.ip || fetch.key} ` +
        `(${fetch.destination.reason})`,
      expected: fetch.destination,
      observed: proxy.destination,
    });
  }

  // 1b. Browser (WHATWG) divergence, even if fetch somehow differs.
  if (whatwg.ok && whatwg.destination.internal && !proxy.destination.internal) {
    const already = findings.some((f) => f.type === 'ssrf');
    if (!already) {
      pushFinding(findings, {
        type: 'ssrf-browser',
        severity: 'critical',
        component: 'proxy->whatwg',
        detail:
          `proxy believes host ${JSON.stringify(proxy.host)} but WHATWG canonicalises to ` +
          `${JSON.stringify(whatwg.host)} (${whatwg.destination.reason})`,
        expected: whatwg.destination,
        observed: proxy.destination,
      });
    }
  }

  // 1c. Legacy downstream client differential.  This is where nested
  //     encodings (e.g. <ip-address>%2e, %00, %2f) show up: WHATWG rejects
  //     or normalises them away, but a legacy client still connects to
  //     the internal host.
  if (legacy.ok && legacy.destination.internal && !proxy.destination.internal) {
    const alreadyFetch = fetch.ok && fetch.destination.internal;
    if (!alreadyFetch) {
      pushFinding(findings, {
        type: 'legacy-ssrf',
        severity: 'critical',
        component: 'proxy->legacy',
        detail:
          `proxy believes host ${JSON.stringify(proxy.host)} but a legacy downstream parser ` +
          `resolves ${JSON.stringify(legacy.host)} -> ${legacy.destination.ip || legacy.key} ` +
          `(${legacy.destination.reason})`,
        expected: legacy.destination,
        observed: proxy.destination,
      });
    }
  }

  // 1d. Host that only becomes internal after a second percent-decode
  //     pass (application-level nested decoding).
  if (deep.ok && deep.destination.internal && !proxy.destination.internal && !(fetch.ok && fetch.destination.internal)) {
    pushFinding(findings, {
      type: 'nested-encoding-ssrf',
      severity: 'critical',
      component: 'proxy->deep',
      detail:
        `proxy believes host ${JSON.stringify(proxy.host)} but a second decode pass yields ` +
        `${JSON.stringify(deep.host)} (${deep.destination.reason})`,
      expected: deep.destination,
      observed: proxy.destination,
    });
  }

  // Suppress generic authority noise when the proxy's "host" is really
  // the userinfo of a standards-compliant parse (e.g. user:<email>),
  // and the connection stays public.  Genuine SSRF is still reported by
  // the checks above.
  const proxyHostLooksLikeUserinfo =
    fetch.ok &&
    whatwg.ok &&
    proxy.host !== '' &&
    whatwg.userinfo !== '' &&
    whatwg.userinfo.split(/[:,]/).includes(proxy.host);

  // 2. Authority mismatch: different effective host even when both are
  //    public.  This is the classic allow-list bypass / open redirect.
  if (
    fetch.ok &&
    !sameOrigin(proxy, fetch) &&
    !(proxyHostLooksLikeUserinfo && !fetch.destination.internal) &&
    !findings.some((f) => f.type === 'ssrf' || f.type === 'ssrf-browser')
  ) {
    pushFinding(findings, {
      type: 'authority-mismatch',
      severity: fetch.destination.internal
        ? 'critical'
        : proxy.destination.internal
          ? 'medium' // fails closed: proxy blocks, fetch would be public
          : 'high',
      component: 'proxy->fetch',
      detail:
        `effective authority differs: proxy ${JSON.stringify(proxy.host)}:${effectivePort(proxy.scheme, proxy.port)} ` +
        `vs fetch ${JSON.stringify(fetch.host)}:${effectivePort(fetch.scheme, fetch.port)}`,
      expected: { host: fetch.host, port: fetch.port, scheme: fetch.scheme },
      observed: { host: proxy.host, port: proxy.port, scheme: proxy.scheme },
    });
  }

  // 3. Path divergence (routing / cache-key confusion).
  if (opts.reportPath !== false) {
    const pathDiffers = proxy.pathNorm !== fetch.pathNorm;
    if (pathDiffers && (findings.length || /\.\.|%2e|%2f|\\/i.test(proxy.path))) {
      pushFinding(findings, {
        type: 'path-mismatch',
        severity: 'low',
        component: 'proxy->fetch',
        detail:
          `effective path differs: proxy ${JSON.stringify(proxy.pathNorm)} ` +
          `vs fetch ${JSON.stringify(fetch.pathNorm)}`,
      });
    }
  }

  // Attach minimal reproducers to security findings (unless we are
  // already inside the reducer).
  if (opts._noMinimize !== true) {
    const security = findings.filter((f) => SECURITY_TYPES.has(f.type));
    for (const f of security) {
      f.reproducer = minimize(input, { ...opts, _noMinimize: true }, f.type);
    }
  }

  return {
    input,
    views: {
      proxy: pick(proxy),
      whatwg: pick(whatwg),
      fetch: pick(fetch),
      legacy: pick(legacy),
      deep: pick(deep),
    },
    findings,
    safe: findings.every((f) => f.severity !== 'critical' && f.severity !== 'high'),
  };
}

function pick(v) {
  return {
    ok: v.ok,
    scheme: v.scheme,
    host: v.host,
    port: v.port,
    path: v.pathNorm,
    userinfo: v.userinfo,
    destination: v.destination,
  };
}

/* ------------------------------------------------------------------ *
 * Minimal reproducer reduction (delta debugging, bounded)
 * ------------------------------------------------------------------ */

const SECURITY_TYPES = new Set(['ssrf', 'ssrf-browser', 'legacy-ssrf', 'nested-encoding-ssrf']);

function findingSignature(input, opts, type) {
  const r = audit(input, { ...opts, _noMinimize: true });
  const view =
    type === 'legacy-ssrf' ? r.views.legacy : type === 'nested-encoding-ssrf' ? r.views.deep : r.views.fetch;
  if (!view || !view.ok) return null;
  if (!['http', 'https'].includes(view.scheme)) return null;
  const f = r.findings.find((x) => x.type === type);
  if (!f) return null;
  // The signature pins the finding *and* the exact destinations involved,
  // so the reducer can never substitute an unrelated internal host.
  return [
    f.type,
    f.severity,
    f.component,
    view.destination.key,
    view.destination.kind,
    r.views.proxy.destination.key,
  ].join('|');
}

function minimize(input, opts, type) {
  if (typeof input !== 'string') return input;
  const target = findingSignature(input, opts, type);
  if (!target) return input;
  let cur = input;

  // Phase 1: component-wise reduction (fast, produces readable repros).
  const candidates = [
    (s) => s.replace(/[?#].*$/, ''),
    (s) => s.replace(/^([a-zA-Z][a-zA-Z0-9+.-]*:\/\/[^/?#]*)\/.*$/, '$1/'),
    (s) => s.replace(/\/.*$/, '/'),
  ];
  let phase1 = true;
  while (phase1) {
    phase1 = false;
    for (const fn of candidates) {
      const cand = fn(cur);
      if (cand && cand !== cur && findingSignature(cand, opts, type) === target) {
        cur = cand;
        phase1 = true;
        break;
      }
    }
  }

  // Phase 2: bounded character delta-debugging.
  let changed = true;
  let guard = 0;
  while (changed && guard < 4000) {
    changed = false;
    for (let i = 0; i < cur.length; i++) {
      guard += 1;
      const cand = cur.slice(0, i) + cur.slice(i + 1);
      if (cand.length < 8) continue;
      if (findingSignature(cand, opts, type) === target) {
        cur = cand;
        changed = true;
        break;
      }
    }
  }
  return cur;
}

/* ------------------------------------------------------------------ *
 * Redirect chains
 * ------------------------------------------------------------------ */

/**
 * auditChain(urls, opts)
 *
 * `urls` is an ordered list of URLs (the initial request plus every
 * Location target).  Relative locations are resolved against the
 * previous hop using WHATWG rules.  A critical finding on any hop
 * after a proxy-approved first hop is a redirect-based SSRF.
 */
function auditChain(urls, opts = {}) {
  const hops = Array.isArray(urls) ? urls : [urls];
  const perHop = [];
  let base = opts.base;
  let firstApproved = null;
  let offending = null;

  for (let i = 0; i < hops.length; i++) {
    const raw = hops[i];
    let resolved = raw;
    try {
      resolved = new URL(raw, base || undefined).href;
    } catch {
      /* keep raw */
    }
    const r = audit(resolved, { ...opts, base });
    perHop.push({ hop: i, raw, resolved, ...r });
    if (i === 0) {
      // The proxy only inspects the first request in this model.
      firstApproved = !r.views.proxy.destination.internal;
    } else if (firstApproved && r.views.fetch.destination.internal && !offending) {
      // A redirect landed on a non-public destination. Even when that
      // hop's own proxy view is internal, the proxy never re-validated it.
      offending = { index: i, resolved, destination: r.views.fetch.destination };
    }
    base = resolved;
  }

  const findings = [];
  if (offending) {
    findings.push({
      id: 'R1',
      type: 'redirect-ssrf',
      severity: 'critical',
      detail:
        `chain starts at proxy-approved host ${JSON.stringify(perHop[0].views.proxy.host)} ` +
        `and redirects to non-public destination ${JSON.stringify(offending.destination.ip || offending.destination.key)} ` +
        `(${offending.destination.reason}) at hop ${offending.index}`,
      reproducer: offending.resolved,
    });
  }

  return { hops: perHop, findings, safe: findings.length === 0 };
}

/* ------------------------------------------------------------------ *
 * Rewrite auditing
 * ------------------------------------------------------------------ */

/*
 * auditRewrite(input, rewrite, opts)
 *
 * Audits a single rewrite step.  `rewrite` is either a function
 * (string -> string) or an array of [RegExp, replacement] pairs.  It
 * flags when the rewrite changes the effective destination or, worse,
 * turns a safe request into an SSRF.
 */
function auditRewrite(input, rewrite, opts = {}) {
  let output;
  if (typeof rewrite === 'function') {
    output = rewrite(String(input));
  } else if (Array.isArray(rewrite)) {
    output = String(input);
    for (const [pattern, replacement] of rewrite) output = output.replace(pattern, replacement);
  } else {
    throw new TypeError('rewrite must be a function or an array of [pattern, replacement]');
  }
  if (typeof output !== 'string') throw new TypeError('rewrite must return a string');

  const before = audit(input, opts);
  const after = audit(output, opts);
  const findings = [];

  if (after.views.fetch.ok && after.views.fetch.destination.internal && !before.views.proxy.destination.internal) {
    findings.push({
      id: 'W1',
      type: 'rewrite-ssrf',
      severity: 'critical',
      detail:
        `rewrite turned proxy-safe ${JSON.stringify(before.views.proxy.host)} into ` +
        `${JSON.stringify(after.views.fetch.host)} (${after.views.fetch.destination.reason})`,
      reproducer: output,
    });
  } else if (before.views.proxy.destination.key !== after.views.fetch.destination.key) {
    findings.push({
      id: 'W2',
      type: 'rewrite-authority-change',
      severity: 'high',
      detail:
        `rewrite changed effective destination from ${JSON.stringify(before.views.proxy.host)} ` +
        `to ${JSON.stringify(after.views.fetch.host)}`,
      reproducer: output,
    });
  }

  return {
    input,
    output,
    before,
    after,
    findings,
    safe: findings.every((f) => f.severity !== 'critical' && f.severity !== 'high'),
  };
}

/* ------------------------------------------------------------------ *
 * Integration gate
 * ------------------------------------------------------------------ */

function gate(input, opts = {}) {
  const r = audit(input, opts);
  const blocking = r.findings.filter((f) => f.severity === 'critical' || f.severity === 'high');
  return {
    allowed: blocking.length === 0,
    reasons: blocking.map((f) => `${f.type}: ${f.detail}`),
    report: r,
  };
}

Hardening rules the auditor encodes

  1. Never forward an unparsed URL. Validate the canonical host/port using the same parser the downstream client uses.
  2. Re-validate every redirect hop (auditChain).
  3. Resolve and classify, don't string-match. Parse numeric IPv4 in all bases, expand IPv6, IDNA-map, strip the root dot, decode the authority.
  4. Deny by default and re-check the resolved IP at connect time (DNS rebinding).

API summary

  audit,          // audit(url, opts) -> { views, findings, safe }
  auditChain,     // auditChain([url, ...]) -> { hops, findings, safe }
  auditRewrite,   // auditRewrite(url, fn|[[regex, repl]]) -> { before, after, findings, safe }
  gate,           // gate(url, opts) -> { allowed, reasons, report }
  minimize,       // minimize(url, opts, findingType) -> shortest reproducer
  resolveHost,    // resolveHost(host, caps) -> { key, kind, internal, reason, ip }
} = require('./auditor');

audit() options: base, fetchParser: 'whatwg'|'legacy', proxyQuirks, reportPath.

Finding severities:

type severity meaning
ssrf critical proxy-safe host, modern fetch reaches non-public address
ssrf-browser critical proxy-safe host, WHATWG reaches non-public address
legacy-ssrf critical proxy-safe host, legacy downstream parser reaches non-public address
nested-encoding-ssrf critical address only becomes internal after a second decode pass
authority-mismatch critical/high/medium effective authority differs between proxy and fetch
redirect-ssrf critical an approved chain redirects to a non-public address
rewrite-ssrf critical a rewrite turns a safe URL into a non-public destination
path-mismatch low effective path differs (routing / cache-key confusion)
parse-error info WHATWG rejected the input

Known limits

  • Host classification is deterministic and offline; it does not perform DNS. In production re-resolve at connect time and re-apply the classifier to the resolved IP to close DNS-rebinding windows.
  • .example, .test, .invalid are treated as special-use (non-public) names.
  • The proxy model is one common naive implementation (first-@, no backslash splitting, no IDNA, no alternate numeric IPs, no decoding). Use proxyQuirks to model a different gateway; the comparators are unchanged.
