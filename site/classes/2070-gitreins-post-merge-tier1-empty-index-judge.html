Root cause (short)

  • Tier1 derives "files to lint/test" from git diff --cached (index-vs-HEAD). Before commit that works; after commit/merge HEAD already contains the work, the index is clean, so tier1 returns DEGRADED: lint/tests = no staged files, and the combiner folds that into overall FAIL.
  • The naive fix "just git add the work files" is a no-op in a true post-merge checkout (HEAD == merged tree). The fix must anchor to the recorded BASE SHA.
  • Detached async jobs read their own cwd/index, so parent staging is invisible — the restage must run inside the job from a self-contained patch or the BASE/WORK SHAs.
  • Tier2 criteria verification is valid; the empty-index tier1 DEGRADED is an artifact once the foreman guard --full is 5/5 (precedent a8190eb / tick-249).
  • Hung async judges: timeout → retry once → close citing foreman evidence.

The fix (core)

idx=$(mktemp -u "${TMPDIR:-/tmp}/gitreins-idx.XXXXXX"); trap 'rm -f "$idx"' EXIT
export GIT_INDEX_FILE="$idx"
git -C "$repo" read-tree "$base"                          # isolated index := BASE
mapfile -d '' f < <(git -C "$repo" diff --name-only -z "$base..$work")
git -C "$repo" add -A -- "${f[@]}"                        # -A stages deletions
git -C "$repo" diff --cached "$base" --stat              # tier1 targets vs BASE
guard --full                                              # tier1 evidence of record

Detached job: git diff --binary "$base..$work" > work.patch, then inside the job read-tree "$base" + git apply --cached work.patch. Verdict: overall_verdict(tier1, tier2="COMPLETE", foreman_guard="PASS") returns COMPLETE only when foreman evidence exists — otherwise it stays FAIL (no silent pass).

Verification (actual verify.py output)

[1] tier1 DEGRADED reason='lint/tests = no staged files'; overall -> FAIL
[2] restage fix -> tier1 OK files=['README.md', 'calc.py', 'newmod.py']; real index clean
[3] DEGRADED + foreman PASS -> COMPLETE ("citing foreman guard --full"); no-foreman -> FAIL
[4] detached child buggy DEGRADED; patch-based restage -> OK
[5] hung judge bounded (1.00s), retry exhausted -> CLOSED citing foreman guard 5/5
ALL ASSERTIONS PASSED
