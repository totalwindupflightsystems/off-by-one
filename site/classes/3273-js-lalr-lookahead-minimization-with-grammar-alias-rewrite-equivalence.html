Root causes addressed

  1. SLR FOLLOW lookaheads over-approximate → exact LALR lookaheads via canonical LR(1) + LR(0)-core merge.
  2. Merging LR(1) states creates conflicts → split-state fallback to canonical LR(1).
  3. LR(0) alone can't certify a parser → dual certificates: independent Earley oracle + LR(0) item-automaton isomorphism/embedding.
  4. Blind shift/reduce resolution changes the language → only accept resolutions that exhaustively match L(G).
  5. No cost model or termination witness → cost = added grammar symbols + best-first search with an exhaustion proof.
  6. Alias/ε break unit shortcuts → aliases as metadata, nullable-aware FIRST, ε-safe Earley.
