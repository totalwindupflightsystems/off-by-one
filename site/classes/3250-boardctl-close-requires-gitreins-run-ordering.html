What's actually happening

It's a genuine two-gate ordering deadlock:

  1. boardctl TR-251 refuses update --status complete without --evidence-run-id, and the id must resolve to a real .gitreins/history/<date>/<run-id>/ directory. --evidence-artifact also requires a bare 64-hex --evidence-fingerprint, which requires the run id.
  2. gitreins' tier-2 judge grades the row's acceptance_criteria (fed from the board row), and one criterion is the row's own closure — so the first judge run fails until the row is already closed.

The escape hatch: cmd_task_complete calls _persist_result(...) before checking result.passed and exiting 1, so the FAILing run still writes verdict.json and is usable as closure evidence.

The fix (ordering)

gitreins task create/start -> implement -> commit -> push
gitreins task complete <ID>                     # exit 1 OK (closure criterion only)
FINGERPRINT=$(sha256sum <tracked artifact>)
boardctl update <ID> --status complete \
  --commit-hash <product commit> \
  --evidence-run-id <run> --evidence-artifact <path> --evidence-fingerprint <64hex> \
  --completed-at <verdict evaluated_at>
# read back, commit+push (long/background commit; a 180s wrapper kills the hook)
gitreins task complete <ID>                     # now PASS
boardctl update <ID> --evidence-run-id <pass-run> --note 'evidence rebind'
# audit event, commit+push, validate

Verified facts

  • Reproduced the TR-251 refusal, the artifact→fingerprint→run-id flag ordering, and the 64-hex format rejection with boardctl v0.4.0.
  • Confirmed --evidence-fingerprint is stored as evidence[].tree_fp while detail.fingerprint is boardctl's auto-derived row hash.
  • Confirmed the run-directory resolvability is enforced by scripts/board_evidence_check.py --strict / the repo gate (_run_directory_exists), and that the close auto-appends the task_completed event.
  • Found and cited the real instance: CF-418, runs f7708add (FAIL) → 0079055c (PASS), close fb11e92, rebind c2105ee, where detail.evidence[1].tree_fp == sha256(docs/LOOP-CODEX.md)@c490329e.
