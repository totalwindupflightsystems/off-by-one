Verified Solution: Versioned Hybrid Transcript Verifier with Signature-Chain Key Rotation

Problem class: python3-quantum-safe-transcript-key-rotation-20261102 Environment: Python 3 (cryptography for Ed25519; everything else stdlib) Deliverable: hybrid_transcript.py (verifier) + test_hybrid_transcript.py (proof)

1. Root-cause analysis

The task is not a single crash; it is a class of verifier design flaws. A naive "hash the bytes and check one signature" verifier accepts attacks in five distinct ways. Each maps to a concrete invariant that the solution enforces.

# Failure mode Why a naive verifier accepts it Invariant that fixes it
1 Ambiguous transcript fork Two validly signed records for the same (sender, seq) with different bodies each look fine in isolation. A hash chain cannot say "these two are different histories". Keep a bounded window (sender, seq) -> acc. If the same slot yields a different accumulator, raise ForkError. Same accumulator twice is ReplayError.
2 Cross-algorithm / domain confusion If the suite identity is only negotiated out-of-band, a record signed under suite A verifies under suite B. Mix a unique per-suite domain tag into the record body, the chain hash and the KDF; bind the negotiated suite/version into the transcript.
3 Unbounded memory Storing every record to detect replays/forks grows without bound. Anchor on signed, hash-linked checkpoints. Retain only the latest checkpoint, a sliding record window, and a bounded set of seen checkpoint heads.
4 Downgrade "The chosen suite is supported" is weaker than "the chosen suite is the strongest common one". Rotation can also silently switch to a weaker algorithm. Reject version < min_version; reject a chosen suite weaker than the best common suite (unless allow_downgrade); require new_algo == negotiated suite.sig on rotation.
5 Replay / rewind after loss Loss forces resync, and an attacker can replay an old record or an old checkpoint to roll the accepted prefix back. Strictly increasing seq with no gaps; old slots are replay/fork; a checkpoint with seq < current is ReplayError; a checkpoint must link to the last trusted checkpoint hash.

The single root cause is failure to commit to the negotiation context and the accepted history in one authenticated accumulator. The fix is an append-only signature chain whose accumulator is computed from domain || previous_accumulator || canonical(record), verified against a bounded window and hash-linked checkpoints.

2. Exact fix

2.1 Invariants

  • body_i = canonical_json(version, suite, epoch, seq, sender, type, payload, key_id, prev)
  • sig_i = Ed25519(epoch_key, "HT/rec" || domain || body_i)
  • acc_i = SHA256("HT/chain" || domain || acc_{i-1} || body_i)
  • checkpoint = Ed25519(epoch_key, "HT/ckpt" || domain || canonical(version, suite, epoch, seq, acc, prev_checkpoint_hash, key_id))
  • derive_key(domain, suite, ss, transcript_hash, label) = HMAC(domain, "HT/kdf" || label || suite || ss || transcript_hash)
  • Negotiation: chosen suite must be offered; version >= policy.min_version; chosen suite level must equal the strongest level offered for that version.
  • Rotation: the old key signs the transition, the new key countersigns it, and the announced algorithm must equal the negotiated suite's signature algorithm.

2.2 hybrid_transcript.py

#!/usr/bin/env python3
"""hybrid_transcript.py

Reference verifier for a *versioned hybrid transcript* that combines a KEM
handshake with an append-only signature chain, supports signing-key rotation
under packet loss and replay, and validates bounded-memory recovery from
signed checkpoints.

Design goals exercised by the test-suite:

* **Append-only signature chain.**  Every transcript record is signed by the
  server's current epoch key.  The accumulator
  ``acc_i = H("HT/chain" || domain || acc_{i-1} || body_i)`` commits to the
  whole prefix, so a signature at position *i* commits to every earlier byte.

* **Ambiguous-fork rejection.**  Two validly signed records that claim the
  same ``(sender, seq)`` but produce different accumulators, or two
  checkpoints for the same ``(epoch, seq)`` with different accumulators, are
  rejected with :class:`ForkError`.  A hash chain alone cannot express "this
  fork is ambiguous"; the verifier keeps a bounded window of
  ``(sender, seq) -> acc`` to make the two candidates collide.

* **Domain separation.**  The negotiated algorithm suite selects a unique
  domain-separation tag that is mixed into the record body, the chain hash and
  the KDF.  Cross-suite replay therefore cannot verify.

* **Bounded-memory checkpoint recovery.**  The verifier only ever retains the
  latest checkpoint, a bounded window of recent records and a bounded set of
  seen checkpoints.  After packet loss it resynchronises from a signed
  checkpoint that links to the last trusted checkpoint.

* **Downgrade rejection.**  The negotiated version must be >= the policy
  minimum and the chosen suite must be the strongest suite common to the
  client offer, otherwise :class:`DowngradeError` is raised.

The cryptography is a faithful test double: Ed25519 for signatures and a
hash-based KEM.  Swap :func:`kem_keygen`/:func:`kem_encap`/:func:`kem_decap`
for a real hybrid KEM (e.g. X25519 + ML-KEM) without touching the verifier.
"""

from __future__ import annotations

import base64
import hashlib
import hmac
import json
from dataclasses import dataclass, field
from typing import Any, Dict, Iterable, List, Mapping, Optional, Sequence, Tuple

from cryptography.exceptions import InvalidSignature
from cryptography.hazmat.primitives.asymmetric.ed25519 import (
    Ed25519PrivateKey,
    Ed25519PublicKey,

# ---------------------------------------------------------------------------
# Hashing / encoding primitives
# ---------------------------------------------------------------------------

HASH = hashlib.sha256
HASH_LEN = 32

TAG_GENESIS = b"HT/genesis\x00"
TAG_CKPT_GENESIS = b"HT/ckpt-genesis\x00"
TAG_REC = b"HT/rec\x00"
TAG_CHAIN = b"HT/chain\x00"
TAG_SIG = b"HT/sig\x00"
TAG_CKPT = b"HT/ckpt\x00"
TAG_CKPT_HASH = b"HT/ckpt-hash\x00"
TAG_ROTATE = b"HT/rotate\x00"
TAG_KDF = b"HT/kdf\x00"
TAG_FINISHED = b"HT/finished\x00"


def H(*parts: bytes) -> bytes:
    h = HASH()
    for part in parts:
        h.update(part)
    return h.digest()


def _b64e(data: bytes) -> str:
    return base64.b64encode(data).decode("ascii")


def _b64d(text: str) -> bytes:
    return base64.b64decode(text.encode("ascii"))


def _canon(obj: Any) -> bytes:
    """Deterministic JSON encoding used for every signed structure."""
    return json.dumps(obj, sort_keys=True, separators=(",", ":"), ensure_ascii=False).encode("utf-8")


# ---------------------------------------------------------------------------
# Hash-based KEM test double (correctness-preserving; replace with real KEM)
# ---------------------------------------------------------------------------

def kem_keygen(seed: bytes) -> Tuple[bytes, bytes]:
    """Return ``(public_key, secret_key)``."""
    sk = bytes(seed)
    pk = hmac.new(sk, b"HT/kem/pk", HASH).digest()
    return pk, sk


def kem_encap(pk: bytes, seed: bytes) -> Tuple[bytes, bytes]:
    """Return ``(ciphertext, shared_secret)``."""
    ct = bytes(seed)
    ss = hmac.new(pk, b"HT/kem/ss\x00" + ct, HASH).digest()
    return ct, ss


def kem_decap(sk: bytes, ct: bytes) -> bytes:
    pk = hmac.new(sk, b"HT/kem/pk", HASH).digest()
    return hmac.new(pk, b"HT/kem/ss\x00" + ct, HASH).digest()


# ---------------------------------------------------------------------------
# Ed25519 signing keys
# ---------------------------------------------------------------------------

class SigningKey:
    """A named Ed25519 signing key (one epoch)."""

    def __init__(self, key_id: str, seed: bytes) -> None:
        self.key_id = key_id
        self._priv = Ed25519PrivateKey.from_private_bytes(bytes(seed))

    @property
    def public_bytes(self) -> bytes:
        return self._priv.public_key().public_bytes_raw()

    def sign(self, message: bytes) -> bytes:
        return self._priv.sign(message)


def ed_verify(public_bytes: bytes, message: bytes, signature: bytes) -> bool:
    try:
        Ed25519PublicKey.from_public_bytes(bytes(public_bytes)).verify(signature, message)
        return True
    except (InvalidSignature, ValueError):
        return False

# Policy / suites

@dataclass(frozen=True)
class Suite:
    name: str
    version: int
    level: int          # relative strength; used for downgrade checks
    domain: bytes       # domain-separation tag, unique per suite
    kem: str = "TOYKEM-256"
    sig: str = "Ed25519"


@dataclass(frozen=True)
class Policy:
    suites: Mapping[str, Suite]
    trusted_keys: Mapping[str, bytes]   # key_id -> raw Ed25519 public key
    min_version: int = 1
    window_size: int = 16               # max live records retained
    checkpoint_memory: int = 8          # max seen checkpoints retained
    allow_downgrade: bool = False

    def suite(self, name: str) -> Suite:
        try:
            return self.suites[name]
        except KeyError:
            raise DomainSeparationError(f"unknown suite {name!r}") from None


def default_policy(trusted_keys: Mapping[str, bytes]) -> Policy:
    suites = {
        "MLKEM768-X25519": Suite(
            name="MLKEM768-X25519", version=1, level=2,
            domain=b"HT/v1/MLKEM768-X25519",
        ),
        "X25519": Suite(
            name="X25519", version=1, level=1,
            domain=b"HT/v1/X25519",
        ),
        "MLKEM1024-X448": Suite(
            name="MLKEM1024-X448", version=2, level=3,
            domain=b"HT/v2/MLKEM1024-X448",
        ),
    }
    return Policy(suites=suites, trusted_keys=dict(trusted_keys), min_version=1)


# ---------------------------------------------------------------------------
# Canonical encodings for signed structures

@dataclass(frozen=True)
class Record:
    version: int
    suite: str
    epoch: int
    seq: int
    sender: str
    type: str
    payload: bytes
    key_id: str
    prev_hash: bytes
    sig: bytes

    def body(self) -> bytes:
        return _canon({
            "v": self.version,
            "suite": self.suite,
            "epoch": self.epoch,
            "seq": self.seq,
            "sender": self.sender,
            "type": self.type,
            "payload": _b64e(self.payload),
            "key_id": self.key_id,
            "prev": self.prev_hash.hex(),
        })

    def signing_input(self, domain: bytes) -> bytes:
        return TAG_REC + domain + self.body()

    def acc(self, domain: bytes) -> bytes:
        return H(TAG_CHAIN, domain, self.prev_hash, self.body())


@dataclass(frozen=True)
class Checkpoint:
    version: int
    suite: str
    epoch: int
    seq: int
    acc_hash: bytes
    prev_checkpoint_hash: bytes
    key_id: str
    sig: bytes

    def body(self) -> bytes:
        return _canon({
            "v": self.version,
            "suite": self.suite,
            "epoch": self.epoch,
            "seq": self.seq,
            "acc": self.acc_hash.hex(),
            "prev_ckpt": self.prev_checkpoint_hash.hex(),
            "key_id": self.key_id,
        })

    def signing_input(self, domain: bytes) -> bytes:
        return TAG_CKPT + domain + self.body()

    def chain_hash(self, domain: bytes) -> bytes:
        return H(TAG_CKPT_HASH, domain, self.body())


# ---------------------------------------------------------------------------
# KDF with explicit domain separation
# ---------------------------------------------------------------------------

def derive_key(domain: bytes, suite: str, shared_secret: bytes,
               transcript_hash: bytes, label: bytes, length: int = 32) -> bytes:
    material = TAG_KDF + label + b"\x00" + suite.encode("ascii") + b"\x00" + shared_secret + transcript_hash
    return hmac.new(domain, material, HASH).digest()[:length]

# Client hello helper

def make_client_hello(seed: bytes, versions: Sequence[int],
                      suites: Sequence[str], random: bytes = b"\x11" * 32) -> Dict[str, Any]:
    pk, sk = kem_keygen(seed)
    return {
        "versions": list(versions),
        "suites": list(suites),
        "kem_pk": pk.hex(),
        "random": random.hex(),
        "_client_sk": sk,          # kept out of the wire body by the builder
    }


# ---------------------------------------------------------------------------
# Negotiation + downgrade rules
# ---------------------------------------------------------------------------

def negotiate(client_hello: Mapping[str, Any], policy: Policy) -> Tuple[int, str]:
    """Honest server choice: strongest mutually supported suite/version."""
    offered_versions = [v for v in client_hello["versions"] if v >= policy.min_version]
    usable = []
    for name in client_hello["suites"]:
        s = policy.suites.get(name)
        if s is not None and s.version in offered_versions:
            usable.append(s)
    if not usable:
        raise NegotiationError("no mutually supported suite")
    best = max(usable, key=lambda s: (s.version, s.level))
    return best.version, best.name


def check_negotiation(client_hello: Mapping[str, Any], chosen_version: int,
                      chosen_suite: str, policy: Policy) -> Suite:
    if chosen_version < policy.min_version:
        raise DowngradeError(f"version {chosen_version} below minimum {policy.min_version}")
    if chosen_version not in client_hello["versions"]:
        raise NegotiationError("server selected an unoffered version")
    if chosen_suite not in client_hello["suites"]:
        raise NegotiationError("server selected an unoffered suite")
    suite = policy.suite(chosen_suite)
    if suite.version != chosen_version:
        raise NegotiationError("suite/version mismatch")
    if not policy.allow_downgrade:
        usable = [
            policy.suites[n] for n in client_hello["suites"]
            if n in policy.suites and policy.suites[n].version == chosen_version
        ]
        best_level = max(s.level for s in usable)
        if suite.level < best_level:
            raise DowngradeError(
                f"server chose weaker suite {chosen_suite!r} (level {suite.level}) "
                f"when level {best_level} was offered"
            )
    return suite


# ---------------------------------------------------------------------------
# Transcript builder (honest signer)
# ---------------------------------------------------------------------------

class TranscriptBuilder:
    """Builds a valid transcript so the verifier can be exercised."""

    def __init__(self, policy: Policy, client_hello: Mapping[str, Any],
                 version: int, suite_name: str, server_random: bytes = b"\x22" * 32,
                 checkpoint_interval: int = 4) -> None:
        self.policy = policy
        self.client_hello = client_hello
        self.version = version
        self.suite = suite_name
        self.domain = policy.suite(suite_name).domain
        self.checkpoint_interval = checkpoint_interval

        # First server signing key is pinned in the policy under "srv-0".
        self.keys: Dict[str, SigningKey] = {
            "srv-0": SigningKey("srv-0", bytes(range(32)))
        }
        self.epoch = 0
        self.epoch_keys: Dict[int, str] = {0: "srv-0"}

        self.acc = H(TAG_GENESIS, self.domain)
        self.ckpt_hash = H(TAG_CKPT_GENESIS, self.domain)
        self.seq = -1
        self.records: List[Record] = []
        self.checkpoints: List[Checkpoint] = []
        self.events: List[Any] = []          # records + checkpoints, in wire order
        self.shared_secret: Optional[bytes] = None

        self._server_hello(client_hello, server_random)

    # -- internals ---------------------------------------------------------

    def _append(self, rtype: str, payload: Dict[str, Any],
                epoch: Optional[int] = None, key_id: Optional[str] = None,
                auto_checkpoint: bool = True) -> Record:
        if epoch is None:
            epoch = self.epoch
        if key_id is None:
            key_id = self.epoch_keys[epoch]
        self.seq += 1
        body = _canon({
            "v": self.version, "suite": self.suite, "epoch": epoch, "seq": self.seq,
            "sender": "server", "type": rtype, "payload": _b64e(_canon(payload)),
            "key_id": key_id, "prev": self.acc.hex(),
        })
        signing_input = TAG_REC + self.domain + body
        sig = self.keys[key_id].sign(signing_input)
        acc = H(TAG_CHAIN, self.domain, self.acc, body)
        rec = Record(self.version, self.suite, epoch, self.seq, "server", rtype,
                     _canon(payload), key_id, self.acc, sig)
        self.records.append(rec)
        self.events.append(rec)
        self.acc = acc
        if auto_checkpoint and self.checkpoint_interval and \
                self.seq % self.checkpoint_interval == 0:
            self.checkpoint()
        return rec

    def _server_hello(self, client_hello: Mapping[str, Any], server_random: bytes) -> None:
        pk = bytes.fromhex(client_hello["kem_pk"])
        ct, ss = kem_encap(pk, b"\x33" * 32)
        self.shared_secret = ss
        payload = {
            "client_hello": {
                "versions": list(client_hello["versions"]),
                "suites": list(client_hello["suites"]),
                "kem_pk": client_hello["kem_pk"],
                "random": client_hello["random"],
            },
            "chosen_version": self.version,
            "chosen_suite": self.suite,
            "kem_ct": ct.hex(),
            "server_random": server_random.hex(),
        }
        self._append("server_hello", payload)
        # server finished proves possession of the KEM secret and binds the
        # domain-separated key schedule to the handshake transcript.
        ctx = self.acc
        key = derive_key(self.domain, self.suite, ss, ctx, b"server finished")
        vd = hmac.new(key, TAG_FINISHED + self.domain + ctx, HASH).digest()
        self._append("finished", {"verify_data": vd.hex()})

    # -- public API --------------------------------------------------------

    def app_data(self, tag: bytes, blob: bytes = b"") -> Record:
        return self._append("application", {"tag": _b64e(tag), "data": _b64e(blob)})

    def key_update(self, new_key_id: str, seed: bytes,
                   new_algo: str = "Ed25519") -> Record:
        new_key = SigningKey(new_key_id, seed)
        new_epoch = self.epoch + 1
        transition = _canon({
            "v": self.version, "suite": self.suite,
            "old_epoch": self.epoch, "new_epoch": new_epoch,
            "old_key_id": self.epoch_keys[self.epoch], "new_key_id": new_key_id,
            "new_pub": new_key.public_bytes.hex(), "new_algo": new_algo,
            "base_acc": self.acc.hex(),
            "prev_ckpt": self.ckpt_hash.hex(),
        })
        new_sig = new_key.sign(TAG_ROTATE + self.domain + transition)
        payload = {
            "new_epoch": new_epoch,
            "new_key_id": new_key_id,
            "new_pub": new_key.public_bytes.hex(),
            "new_algo": new_algo,
            "new_sig": _b64e(new_sig),
            "transition": transition.hex(),
        }
        rec = self._append("key_update", payload, epoch=self.epoch,
                           key_id=self.epoch_keys[self.epoch],
                           auto_checkpoint=False)
        self.keys[new_key_id] = new_key
        self.epoch = new_epoch
        self.epoch_keys[new_epoch] = new_key_id
        # Emit a checkpoint under the *new* epoch key so recovery can trust it.
        self.checkpoint()
        return rec

    def fork_record(self, rec: Record, payload: Dict[str, Any]) -> Record:
        """Produce an alternative, validly signed record for the same slot."""
        body = _canon({
            "v": rec.version, "suite": rec.suite, "epoch": rec.epoch,
            "seq": rec.seq, "sender": rec.sender, "type": rec.type,
            "payload": _b64e(_canon(payload)), "key_id": rec.key_id,
            "prev": rec.prev_hash.hex(),
        })
        sig = self.keys[rec.key_id].sign(TAG_REC + self.domain + body)
        return Record(rec.version, rec.suite, rec.epoch, rec.seq, rec.sender,
                      rec.type, _canon(payload), rec.key_id, rec.prev_hash, sig)

    def checkpoint(self) -> Checkpoint:
        key_id = self.epoch_keys[self.epoch]
        body = _canon({
            "v": self.version, "suite": self.suite, "epoch": self.epoch,
            "seq": self.seq, "acc": self.acc.hex(),
            "prev_ckpt": self.ckpt_hash.hex(), "key_id": key_id,
        })
        sig = self.keys[key_id].sign(TAG_CKPT + self.domain + body)
        cp = Checkpoint(self.version, self.suite, self.epoch, self.seq, self.acc,
                        self.ckpt_hash, key_id, sig)
        self.checkpoints.append(cp)
        self.events.append(cp)
        self.ckpt_hash = cp.chain_hash(self.domain)
        return cp


# ---------------------------------------------------------------------------
# The verifier
# ---------------------------------------------------------------------------

class TranscriptVerifier:
    def __init__(self, policy: Policy, client_hello: Mapping[str, Any],
                 client_sk: Optional[bytes] = None,
                 window_size: Optional[int] = None,
                 start_checkpoint: Optional[Checkpoint] = None) -> None:
        self.policy = policy
        self.client_hello = client_hello
        self.client_sk = client_sk
        self.window_size = window_size or policy.window_size
        self.memory_high_water = 0

        self.suite: Optional[Suite] = None
        self.version: Optional[int] = None
        self.domain: Optional[bytes] = None

        self.keys: Dict[str, bytes] = dict(policy.trusted_keys)
        self.epoch_keys: Dict[int, str] = {0: "srv-0"}
        self.epoch = 0

        self.acc = b""
        self.seq = -1
        self.shared_secret: Optional[bytes] = None
        self.handshake_acc: Optional[bytes] = None
        self.finished_ok = False

        self.window: Dict[Tuple[str, int], bytes] = {}
        self.seen_checkpoints: Dict[Tuple[int, int], bytes] = {}
        self.last_checkpoint_hash: Optional[bytes] = None
        self.checkpoint: Optional[Checkpoint] = None

        # Bootstrap from an out-of-band trusted checkpoint (bounded-memory
        # recovery): the pinned checkpoint *is* the trust anchor, so it is not
        # re-verified against genesis, but every later checkpoint must link to
        # it and every later record must extend its accumulator.
        if start_checkpoint is not None:
            cp = start_checkpoint
            self._init_domain(cp.version, cp.suite)
            if cp.key_id not in self.keys:
                raise SignatureError(
                    f"cannot recover from checkpoint signed by unpinned key {cp.key_id!r}"
                )
            self.acc = cp.acc_hash
            self.seq = cp.seq
            self.epoch = cp.epoch
            self.epoch_keys[cp.epoch] = cp.key_id
            self.checkpoint = cp
            self.last_checkpoint_hash = cp.chain_hash(self.domain)
            self.seen_checkpoints[(cp.epoch, cp.seq)] = cp.acc_hash

    # -- helpers -----------------------------------------------------------

    def _bump_memory(self) -> None:
        used = len(self.window) + len(self.seen_checkpoints)
        self.memory_high_water = max(self.memory_high_water, used)
        if len(self.window) > self.window_size:
            raise BoundedMemoryError("record window exceeded")

    def _init_domain(self, version: int, suite_name: str) -> None:
        if self.suite is not None:
            if self.suite.name != suite_name:
                raise DomainSeparationError(
                    f"suite changed mid-transcript: {self.suite.name!r} -> {suite_name!r}"
                )
            if self.version != version:
                raise DomainSeparationError("version changed mid-transcript")
            return
        if version < self.policy.min_version:
            raise DowngradeError(f"version {version} below minimum {self.policy.min_version}")
        suite = self.policy.suite(suite_name)
        if suite.version != version:
            raise NegotiationError("suite/version mismatch")
        self.suite = suite
        self.version = version
        self.domain = suite.domain
        self.acc = H(TAG_GENESIS, self.domain)
        self.last_checkpoint_hash = H(TAG_CKPT_GENESIS, self.domain)

    def _check_signature(self, key_id: str, message: bytes, sig: bytes) -> None:
        pub = self.keys.get(key_id)
        if pub is None:
            raise SignatureError(f"unknown key id {key_id!r}")
        if not ed_verify(pub, message, sig):
            raise SignatureError(f"bad signature under key {key_id!r}")

    # -- event entry point -------------------------------------------------

    def feed(self, event: Any) -> None:
        if isinstance(event, Checkpoint):
            self._apply_checkpoint(event)
        elif isinstance(event, Record):
            self._apply_record(event)
        else:
            raise TypeError(f"unsupported event {type(event)!r}")

    # -- records -----------------------------------------------------------

    def _apply_record(self, rec: Record) -> None:
        self._init_domain(rec.version, rec.suite)
        assert self.domain is not None
        if rec.sender != "server":
            raise ChainError("unexpected sender")

        # Sequence handling: strictly increasing, no gaps.  Older positions are
        # either replays or forks.
        if rec.seq <= self.seq:
            key = (rec.sender, rec.seq)
            seen = self.window.get(key)
            if seen is None:
                raise ReplayError(f"stale/replayed record seq={rec.seq}")
            if seen != rec.acc(self.domain):
                raise ForkError(f"fork at seq={rec.seq}: conflicting accumulator")
            raise ReplayError(f"duplicate record seq={rec.seq}")
        if rec.seq != self.seq + 1:
            raise ChainError(
                f"gap before seq={rec.seq} (expected {self.seq + 1}); recover from checkpoint"
            )

        # Epoch / key rotation bookkeeping.
        if rec.epoch > self.epoch:
            if rec.epoch != self.epoch + 1:
                raise ChainError("epoch jump without key_update")
            expected = self.epoch_keys.get(rec.epoch)
            if expected is None or expected != rec.key_id:
                raise SignatureError("record signed with an unannounced epoch key")
        elif rec.epoch != self.epoch:
            raise ChainError("epoch regression")

        # Chain linkage + signature.
        if rec.prev_hash != self.acc:
            raise ForkError("record does not extend the trusted accumulator")
        self._check_signature(rec.key_id, rec.signing_input(self.domain), rec.sig)

        # First record: validate negotiation and KEM, then key schedule.
        if rec.type == "server_hello":
            self._on_server_hello(rec)
        elif rec.type == "key_update":
            self._on_key_update(rec)
        elif rec.type == "finished":
            self._on_finished(rec)

        new_acc = rec.acc(self.domain)

        # Fork detection inside the bounded window.
        key = (rec.sender, rec.seq)
        if key in self.window and self.window[key] != new_acc:
            raise ForkError(f"fork at seq={rec.seq}: conflicting accumulator")
        self.window[key] = new_acc
        self.acc = new_acc
        self.seq = rec.seq
        self.epoch = rec.epoch

        cutoff = self.seq - self.window_size + 1
        for k in [k for k in self.window if k[1] < cutoff]:
            del self.window[k]
        self._bump_memory()

    def _on_server_hello(self, rec: Record) -> None:
        payload = json.loads(rec.payload.decode("utf-8"))
        echoed = payload.get("client_hello", {})
        for field_name in ("versions", "suites", "kem_pk", "random"):
            if echoed.get(field_name) != self.client_hello.get(field_name):
                raise NegotiationError("server did not faithfully echo client_hello")
        suite = check_negotiation(
            self.client_hello, payload["chosen_version"],
            payload["chosen_suite"], self.policy,
        )
        if suite.name != rec.suite:
            raise DomainSeparationError("negotiated suite does not match record domain")
        ct = bytes.fromhex(payload["kem_ct"])
        if self.client_sk is not None:
            ss = kem_decap(self.client_sk, ct)
            if ss != kem_decap(self.client_sk, ct):
                raise ChainError("unstable KEM decapsulation")
            self.shared_secret = ss
        self.handshake_acc = rec.acc(self.domain)

    def _on_key_update(self, rec: Record) -> None:
        assert self.domain is not None
        payload = json.loads(rec.payload.decode("utf-8"))
        new_epoch = payload["new_epoch"]
        if new_epoch != self.epoch + 1:
            raise ChainError("invalid rotation epoch")
        if payload.get("new_algo") != self.suite.sig:
            # Rotating to a different (possibly weaker) algorithm is a
            # negotiated-algorithm downgrade and must be refused.
            raise DowngradeError(
                f"rotation to algorithm {payload.get('new_algo')!r} refused; "
                f"negotiated algorithm is {self.suite.sig!r}"
            )
        transition = bytes.fromhex(payload["transition"])
        expected_transition = _canon({
            "v": rec.version, "suite": rec.suite,
            "old_epoch": self.epoch, "new_epoch": new_epoch,
            "old_key_id": self.epoch_keys[self.epoch],
            "new_key_id": payload["new_key_id"],
            "new_pub": payload["new_pub"],
            "new_algo": payload["new_algo"],
            "base_acc": rec.prev_hash.hex(),
            "prev_ckpt": (self.last_checkpoint_hash or b"").hex(),
        })
        if transition != expected_transition:
            raise ChainError("rotation transition mismatch")
        new_pub = bytes.fromhex(payload["new_pub"])
        if not ed_verify(new_pub, TAG_ROTATE + self.domain + transition,
                         _b64d(payload["new_sig"])):
            raise SignatureError("rotation countersignature invalid")
        # No downgrade via rotation: the new key must not be announced as a
        # weaker algorithm, and the suite cannot change.
        self.keys[payload["new_key_id"]] = new_pub
        self.epoch_keys[new_epoch] = payload["new_key_id"]

    def _on_finished(self, rec: Record) -> None:
        if self.shared_secret is None:
            return  # KEM secret unavailable; structural check only
        assert self.domain is not None
        payload = json.loads(rec.payload.decode("utf-8"))
        ctx = rec.prev_hash
        key = derive_key(self.domain, self.suite.name, self.shared_secret, ctx,
                         b"server finished")
        expected = hmac.new(key, TAG_FINISHED + self.domain + ctx, HASH).digest()
        if not hmac.compare_digest(expected, bytes.fromhex(payload["verify_data"])):
            raise SignatureError("finished verify_data mismatch (key schedule/domain)")
        self.finished_ok = True

    # -- checkpoints -------------------------------------------------------

    def _apply_checkpoint(self, cp: Checkpoint) -> None:
        self._init_domain(cp.version, cp.suite)
        assert self.domain is not None
        if cp.prev_checkpoint_hash != self.last_checkpoint_hash:
            # Could be a stale checkpoint or an ambiguous fork.
            ck = (cp.epoch, cp.seq)
            if ck in self.seen_checkpoints:
                if self.seen_checkpoints[ck] != cp.acc_hash:
                    raise ForkError(f"fork at checkpoint {(cp.epoch, cp.seq)}")
                raise ReplayError("duplicate checkpoint")
            raise ChainError("checkpoint does not link to the trusted checkpoint")
        self._check_signature(cp.key_id, cp.signing_input(self.domain), cp.sig)

        ck = (cp.epoch, cp.seq)
        if ck in self.seen_checkpoints and self.seen_checkpoints[ck] != cp.acc_hash:
            raise ForkError(f"fork at checkpoint {(cp.epoch, cp.seq)}")
        if cp.seq < self.seq:
            raise ReplayError("stale checkpoint would rewind the transcript")
        if cp.seq == self.seq and cp.acc_hash != self.acc:
            raise ForkError("checkpoint conflicts with live accumulator")

        self.acc = cp.acc_hash
        self.seq = cp.seq
        self.epoch = cp.epoch
        self.checkpoint = cp
        self.last_checkpoint_hash = cp.chain_hash(self.domain)
        self.seen_checkpoints[ck] = cp.acc_hash
        self.window.clear()
        while len(self.seen_checkpoints) > self.policy.checkpoint_memory:
            self.seen_checkpoints.pop(next(iter(self.seen_checkpoints)))
        self._bump_memory()

    # -- result ------------------------------------------------------------

    def result(self) -> Dict[str, Any]:
        return {
            "version": self.version,
            "suite": self.suite.name if self.suite else None,
            "domain": self.domain.decode() if self.domain else None,
            "records": self.seq + 1,
            "epoch": self.epoch,
            "finished": self.finished_ok,
            "memory_high_water": self.memory_high_water,
            "window_size": self.window_size,
            "checkpoints": len(self.seen_checkpoints),
        }


def verify_transcript(events: Iterable[Any], policy: Policy,
                      client_hello: Mapping[str, Any],
                      client_sk: Optional[bytes] = None,
                      window_size: Optional[int] = None,
                      start_checkpoint: Optional[Checkpoint] = None) -> Dict[str, Any]:
    verifier = TranscriptVerifier(policy, client_hello, client_sk=client_sk,
                                  window_size=window_size,
                                  start_checkpoint=start_checkpoint)
    for event in events:
        verifier.feed(event)
    return verifier.result()

def demo() -> None:
    client_hello = make_client_hello(b"demo-client", [1], ["MLKEM768-X25519", "X25519"])
    srv = SigningKey("srv-0", bytes(range(32)))
    policy = default_policy({"srv-0": srv.public_bytes})

                                checkpoint_interval=4)
    for i in range(6):
        builder.app_data(b"tag-%d" % i, b"payload-%d" % i)
    builder.key_update("srv-1", b"\x55" * 32)
    for i in range(4):
        builder.app_data(b"post-%d" % i, b"p" * 4)

    print("=" * 68)
    print("1. valid transcript with key rotation")
    res = verify_transcript(builder.events, policy, client_hello,
                            client_sk=client_hello["_client_sk"])
    print("   ACCEPT", res)

    print("2. downgrade attack (hybrid offered, classical chosen)")
    down = TranscriptBuilder(policy, client_hello, 1, "X25519")
    try:
        verify_transcript(down.events, policy, client_hello,
                          client_sk=client_hello["_client_sk"])
    except DowngradeError as exc:
        print("   REJECT DowngradeError:", exc)

    print("3. ambiguous transcript fork (two signed records, same slot)")
    v = TranscriptVerifier(policy, client_hello, client_sk=client_hello["_client_sk"])
    target = builder.records[3]
    for ev in builder.events:
        v.feed(ev)
        if ev is target:
            break
    try:
        v.feed(builder.fork_record(target, {"tag": "Zm9yaw==", "data": ""}))
    except ForkError as exc:
        print("   REJECT ForkError:", exc)

    print("4. replayed record")
    v = TranscriptVerifier(policy, client_hello, client_sk=client_hello["_client_sk"])
    v.feed(builder.records[0])
    try:
        v.feed(builder.records[0])
    except ReplayError as exc:
        print("   REJECT ReplayError:", exc)

    print("5. packet loss + bounded-memory checkpoint recovery")
    loss = TranscriptBuilder(policy, client_hello, 1, "MLKEM768-X25519",
                             checkpoint_interval=4)
    for i in range(10):
        loss.app_data(b"loss-%d" % i, b"z" * 4)
    dropped = {6, 7, 8}          # next surviving event is the checkpoint at seq 8
    stream = [ev for ev in loss.events
              if not (isinstance(ev, Record) and ev.type == "application"
                      and ev.seq in dropped)]
    res = verify_transcript(stream, policy, client_hello,
                            client_sk=client_hello["_client_sk"], window_size=6)
    print("   ACCEPT after loss", {k: res[k] for k in
                                    ("records", "epoch", "memory_high_water",
                                     "window_size")})

    print("6. domain separation (KDF under two suites)")
    ss, th = b"\x01" * 32, b"\x02" * 32
    k1 = derive_key(policy.suites["MLKEM768-X25519"].domain, "MLKEM768-X25519", ss, th, b"l")
    k2 = derive_key(policy.suites["X25519"].domain, "X25519", ss, th, b"l")
    print("   keys differ:", k1 != k2)
    print("=" * 68)

class ForkRejection(unittest.TestCase):
    def test_ambiguous_record_fork_rejected(self):
        policy, ch, b = build()
        v = ht.TranscriptVerifier(policy, ch, client_sk=ch["_client_sk"])
        target = b.records[2]
        for ev in b.events:
            v.feed(ev)
            if ev is target:
                break
        # A second, validly signed record for the same slot but different body.
        fork = b.fork_record(target, {"tag": "Zm9yaw==", "data": "Zm9yaw=="})
        with self.assertRaises(ht.ForkError):
            v.feed(fork)

    def test_ambiguous_checkpoint_fork_rejected(self):
        policy, ch, b = build()
        v = ht.TranscriptVerifier(policy, ch, client_sk=ch["_client_sk"])
        cp = b.checkpoints[0]
        v.feed(cp)
        forged = ht.Checkpoint(
            cp.version, cp.suite, cp.epoch, cp.seq,
            acc_hash=bytes(32),                    # different accumulator
            prev_checkpoint_hash=cp.prev_checkpoint_hash,

        forged = ht.Checkpoint(
            cp.version, cp.suite, cp.epoch, cp.seq, forged.acc_hash,

            b.keys[cp.key_id].sign(ht.TAG_CKPT + b.domain + body),
        )

            v.feed(forged)

3.5 Operational notes

  • The verifier is a pure function over a stream of Record / Checkpoint events; it never stores the whole transcript.
  • Recovery starts from an out-of-band trusted checkpoint via TranscriptVerifier(..., start_checkpoint=cp). The checkpoint's key must be pinned (or delivered under a previously trusted key); a checkpoint signed by an unpinned key is rejected rather than silently trusted.
  • Policy.window_size and Policy.checkpoint_memory bound memory explicitly; exceeding the record window raises BoundedMemoryError.
