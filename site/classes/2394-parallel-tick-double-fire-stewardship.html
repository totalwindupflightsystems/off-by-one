Diagnosis

Double-fire is caused by three compounding defects:

  1. RC-1 — lock keyed on wall-clock, not work. The lane lock releases when the session/wrapper process exits, but detached gitreins/gate/pytest keep running. So outcome=committed, commits=1 is a false completion signal.
  2. RC-2 — the late tick has no sibling branch. 19-34-37 arrives 35 min later with no lease/idempotency check and would blindly dispatch → stacked pytest (AUG-081 class).
  3. RC-3 — stranded closeout unowned. 18-59-16 died after its report but before finalizing board rows; nobody closes them.

Rule: late fire = steward, never dispatch.

Detection (3 corroborating signals)

  • state.db: session_key is the tick id; join messages→sessions for tool calls matching your repo path.
  • scheduler.db: outcome=committed + commits=1 with pending board rows = stranded closeout.
  • ps -eo lstart: live process start times match the sibling's tool-call timestamps exactly.

Exact fix (fold recipe)

  1. Freeze dispatch; capture PRE_TICK_HEAD=$(git rev-parse HEAD).
  2. Close sibling rows: close-row-bytesafe.py --file <BOARD> --key <ROW> --old pending --new closed (dry-run, then apply; never sed the whole board).
  3. Classify verdicts: canonical PASS wins; tier1-contention is informational; tier2-INCOMPLETE is noise.
  4. Append idempotent events via append-event-exists-checked.py.
  5. Set header last_commit to $PRE_TICK_HEAD.
  6. Board-only commit: git add <BOARD> <EVENTS> && git commit --no-verify -m "steward: fold sibling <SIB>" && git push.
  7. No heavy sweeps while sibling judge is live. Doc-only rows may close on a manual criteria grep and fold tier2 later.

Verification (executed)

  • python3 -m py_compile scripts/*.py and bash -n detect-sibling-tick.sh → pass.
  • Byte-safe flip: diff showed only the target row's status changed; re-run printed SKIP.
  • Event append: legacy {"id":null} tolerated; next ids 4,5; duplicate key printed SKIP with no write.
  • Detector exercised against synthetic state.db/scheduler.db; all three signals rendered correctly.

Prevention: a per-lane lease renewed by the detached wrappers, checked before dispatch; completion only after background work drains; outcome=abandoned when a session exits mid-work so the next tick enters steward mode.
