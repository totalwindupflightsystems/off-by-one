PBQP Register Allocation: Exact Spill/Benefit Reduction Solver

Root-cause analysis

A PBQP register allocator fails in practice for five common reasons:

  1. Incorrect domain construction. Each SSA value needs its own domain: [spill, allowed-register-0, allowed-register-1, ...]. Using a global register count, class-local register indices, or letting a precoloured value spill produces wrong feasibility and wrong costs.
  2. Unsafe infinity arithmetic. Conflict edges use an infinite cost for two values on the same physical register. If Inf + finite can wrap, or if Inf is treated as an ordinary large number, forbidden assignments can win.
  3. Reductions without reconstruction. R1/R2 eliminate a variable, but the chosen value depends on the surviving neighbours. Without a reduction stack storing the argmin tables, reconstruction is impossible or wrong.
  4. Invalid branch pruning with negative benefit edges. A partial constant being larger than the incumbent does not prove the branch is worse when future benefit edges are negative. A lower bound must include the remaining edge minima. This exact bug is covered by the regression test below.
  5. Heuristic-only solving cannot prove optimality. The implementation here applies exact reductions to a fixed point, then uses exact branch-and-bound on the irreducible core. Therefore a finite result is a global optimum.

Exact fix

Model the objective as

min  sum_v nodeCost[v][choice_v]
   + sum_{(u,v)} edgeCost[u,v][choice_u][choice_v]

with saturated Inf = 1<<60.

The solver applies:

  • R0: degree-0 node: choose its minimum cost option.
  • RN: a node with a unique finite option is forced; pointwise-dominated options are removed.
  • R1: degree-1 node: fold min_a(nodeCost[a] + edge[a][b]) into the neighbour's node cost and store the argmin table.
  • R2: degree-2 node: fold min_a(nodeCost[a] + edge[a][b] + edge[a][c]) into a new or existing edge between its two neighbours, and store the argmin table.
  • R∞: an all-Inf edge proves infeasibility; an edge with exactly one finite entry forces both endpoints.
  • Branch-and-bound: on an irreducible core, enumerate remaining options with the safe lower bound const + sum_v min(nodeCost[v]) + sum_edges min(edge).

Reconstruction runs the reduction stack backwards. Every R0/RN/forced value is set directly; every R1/R2 value is selected from its stored argmin table using the already-known values of its surviving neighbours.

// Package pbqp implements a partitioned Boolean quadratic problem (PBQP)
// solver and a PBQP-based register allocator.
//
// The solver is exact: it repeatedly applies the R0, RN, R1 and R2
// reductions.  If no reduction applies to the remaining core it performs a
// branch-and-bound search.  Consequently a finite result is a global optimum,
// not merely a heuristic answer.
package pbqp

import (
    "errors"
    "fmt"
)

// Inf is the cost of a forbidden choice.  All real finite costs must be much
// smaller than Inf.  Addition saturates at Inf so that Inf + finite = Inf and
// a forbidden interaction can never accidentally wrap around.
const Inf int64 = 1 << 60

// NegInf is only used to avoid arithmetic underflow if a caller supplies very
// negative finite preferences.  Normal register-allocation instances use only
// non-negative node costs and non-positive benefit edges.
const NegInf int64 = -Inf

// ErrUnsolvable is returned when every assignment contains a forbidden edge.
var ErrUnsolvable = errors.New("pbqp: no finite-cost assignment exists")

func add(a, b int64) int64 {
    if a >= Inf || b >= Inf {
        return Inf
    }
    // Saturating signed addition, with Inf as the positive sentinel.
    if b > 0 && a > Inf-b {
        return Inf
    }
    if b < 0 && a < NegInf-b {
        return NegInf
    }
    s := a + b
    if s >= Inf {
        return Inf
    }
    if s <= NegInf {
        return NegInf
    }
    return s
}

// Edge is a quadratic term.  M has one row per choice of A and one column per
// choice of B.  Costs may be negative (for example coalescing benefits).
type Edge struct {
    A, B int
    M    [][]int64
}

// Problem is a PBQP instance.  Costs[v][choice] is the linear cost of node v.
// The objective is the sum of all node costs and all edge entries selected by
// the assignment.
type Problem struct {
    Costs [][]int64
    Edges []Edge
}

// Validate checks dimensions and rejects self edges.
func (p *Problem) Validate() error {
    for i, c := range p.Costs {
        if len(c) == 0 {
            return fmt.Errorf("node %d has an empty domain", i)
        }
    }
    for k, e := range p.Edges {
        if e.A < 0 || e.A >= len(p.Costs) || e.B < 0 || e.B >= len(p.Costs) {
            return fmt.Errorf("edge %d has an invalid endpoint", k)
        }
        if e.A == e.B {
            return fmt.Errorf("edge %d is a self edge", k)
        }
        if len(e.M) != len(p.Costs[e.A]) {
            return fmt.Errorf("edge %d has %d rows, want %d", k, len(e.M), len(p.Costs[e.A]))
        }
        for r, row := range e.M {
            if len(row) != len(p.Costs[e.B]) {
                return fmt.Errorf("edge %d row %d has %d columns, want %d", k, r, len(row), len(p.Costs[e.B]))
            }
        }
    }
    return nil
}

// Cost evaluates an assignment directly from the original problem.
func (p *Problem) Cost(choice []int) (int64, error) {
    if len(choice) != len(p.Costs) {
        return 0, fmt.Errorf("assignment has %d values, want %d", len(choice), len(p.Costs))
    }
    total := int64(0)
    for v, c := range p.Costs {
        if choice[v] < 0 || choice[v] >= len(c) {
            return 0, fmt.Errorf("choice %d for node %d is out of range", choice[v], v)
        }
        total = add(total, c[choice[v]])
    }
    for _, e := range p.Edges {
        total = add(total, e.M[choice[e.A]][choice[e.B]])
    }
    return total, nil
}

// Solution is an optimal assignment and its objective value.
type Solution struct {
    Choices []int
    Cost    int64
}

// Solve returns a globally optimal assignment.  If the instance is
// infeasible (its minimum cost is Inf) it returns ErrUnsolvable.
func Solve(p *Problem) (Solution, error) {
    if err := p.Validate(); err != nil {
        return Solution{}, err
    }
    s, err := newState(p)
    if err != nil {
        return Solution{}, err
    }
    choices, cost, ok := search(s, nil, 0, Inf)
    if !ok || choices == nil || cost >= Inf {
        return Solution{}, ErrUnsolvable
    }
    // The reconstruction and the reduction arithmetic are independent.  This
    // final check turns an internal inconsistency into an error rather than a
    // silently wrong allocation.
    verified, err := p.Cost(choices)
    if err != nil {
        return Solution{}, err
    }
    if verified != cost {
        return Solution{}, fmt.Errorf("pbqp: internal cost mismatch: solver=%d assignment=%d", cost, verified)
    }
    return Solution{Choices: choices, Cost: cost}, nil
}

// Internal mutable graph

type edge struct {
    a, b int // a < b
    m    [][]int64
}

type state struct {
    costs  [][]int64
    adj    []map[int]*edge
    active []bool
    n      int
}

func cloneMatrix(m [][]int64) [][]int64 {
    out := make([][]int64, len(m))
    for i := range m {
        out[i] = append([]int64(nil), m[i]...)
    }
    return out
}

func transpose(m [][]int64) [][]int64 {
    if len(m) == 0 {
        return nil
    }
    out := make([][]int64, len(m[0]))
    for i := range out {
        out[i] = make([]int64, len(m))
    }
    for i := range m {
        for j := range m[i] {
            out[j][i] = m[i][j]
        }
    }
    return out
}

func newState(p *Problem) (*state, error) {
    s := &state{
        costs:  make([][]int64, len(p.Costs)),
        adj:    make([]map[int]*edge, len(p.Costs)),
        active: make([]bool, len(p.Costs)),
        n:      len(p.Costs),
    }
    for i := range p.Costs {
        s.costs[i] = append([]int64(nil), p.Costs[i]...)
        s.adj[i] = make(map[int]*edge)
        s.active[i] = true
    }
    for _, e := range p.Edges {
        a, b, m := e.A, e.B, e.M
        if a > b {
            a, b, m = b, a, transpose(m)
        }
        if old := s.adj[a][b]; old != nil {
            for i := range old.m {
                for j := range old.m[i] {
                    old.m[i][j] = add(old.m[i][j], m[i][j])
                }
            }
            continue
        }
        ne := &edge{a: a, b: b, m: cloneMatrix(m)}
        s.adj[a][b] = ne
        s.adj[b][a] = ne
    }
    return s, nil
}

func (s *state) clone() *state {
    c := &state{
        costs:  make([][]int64, s.n),
        adj:    make([]map[int]*edge, s.n),
        active: append([]bool(nil), s.active...),
        n:      s.n,
    }
    for i := 0; i < s.n; i++ {
        c.costs[i] = append([]int64(nil), s.costs[i]...)
        c.adj[i] = make(map[int]*edge, len(s.adj[i]))
    }
    for a := 0; a < s.n; a++ {
        for b, e := range s.adj[a] {
            if b <= a {
                continue
            }
            ne := &edge{a: e.a, b: e.b, m: cloneMatrix(e.m)}
            c.adj[a][b] = ne
            c.adj[b][a] = ne
        }
    }
    return c
}

func (s *state) removeEdge(a, b int) {
    delete(s.adj[a], b)
    delete(s.adj[b], a)
}

func (s *state) edgeCost(e *edge, node, val, other, otherVal int) int64 {
    if e.a == node {
        return e.m[val][otherVal]
    }
    return e.m[otherVal][val]
}

func (s *state) addEdgeMatrix(a, b int, delta [][]int64) {
    if a == b {
        return
    }
    if a > b {
        a, b = b, a
        delta = transpose(delta)
    }
    if e := s.adj[a][b]; e != nil {
        for i := range e.m {
            for j := range e.m[i] {
                e.m[i][j] = add(e.m[i][j], delta[i][j])
            }
        }
        return
    }
    ne := &edge{a: a, b: b, m: cloneMatrix(delta)}
    s.adj[a][b] = ne
    s.adj[b][a] = ne
}

func minVector(c []int64) (int, int64) {
    best := 0
    bestCost := c[0]
    for i := 1; i < len(c); i++ {
        if c[i] < bestCost {
            best, bestCost = i, c[i]
        }
    }
    return best, bestCost
}

func minMatrix(m [][]int64) int64 {
    if len(m) == 0 || len(m[0]) == 0 {
        return Inf
    }
    best := m[0][0]
    for i := range m {
        for j := range m[i] {
            if m[i][j] < best {
                best = m[i][j]
            }
        }
    }
    return best
}

// fix assigns v the given value, folds its node cost and incident edge rows
// into its neighbours, and removes it.  The returned value is the added node
// cost (it is not added by fix itself so callers can keep a separate constant).
func (s *state) fix(v, val int) int64 {
    if !s.active[v] {
        return 0
    }
    c := s.costs[v][val]
    for u, e := range s.adj[v] {
        if !s.active[u] {
            continue
        }
        for b := range s.costs[u] {
            s.costs[u][b] = add(s.costs[u][b], s.edgeCost(e, v, val, u, b))
        }
    }
    for u := range s.adj[v] {
        s.removeEdge(v, u)
    }
    s.active[v] = false
    return c
}

// Reduction stack records

type recordKind uint8

const (
    recFixed recordKind = iota
    recR1
    recR2
)

type record struct {
    kind recordKind
    v    int
    val  int
    u, w int
    map1 []int
    map2 [][]int
}

func reconstruct(recs []record, n int) []int {
    choice := make([]int, n)
    for i := range choice {
        choice[i] = -1
    }
    for i := len(recs) - 1; i >= 0; i-- {
        r := recs[i]
        switch r.kind {
        case recFixed:
            choice[r.v] = r.val
        case recR1:
            if r.u < 0 || r.u >= n || choice[r.u] < 0 || choice[r.u] >= len(r.map1) {
                return nil
            }
            choice[r.v] = r.map1[choice[r.u]]
        case recR2:
            if r.u < 0 || r.u >= n || r.w < 0 || r.w >= n ||
                choice[r.u] < 0 || choice[r.w] < 0 ||
                choice[r.u] >= len(r.map2) || choice[r.w] >= len(r.map2[choice[r.u]]) {
                return nil
            }
            choice[r.v] = r.map2[choice[r.u]][choice[r.w]]
        }
    }
    for _, c := range choice {
        if c < 0 {
            return nil
        }
    }
    return choice
}

// R1: eliminate a degree-one node.  For each value of its neighbour we keep
// the best value of the eliminated node.  This is exact variable elimination
// without introducing a new edge.
func (s *state) reduceR1(v int, recs *[]record) {
    var u int
    var e *edge
    for k, ee := range s.adj[v] {
        u, e = k, ee
        break
    }
    mapping := make([]int, len(s.costs[u]))
    for b := range mapping {
        best := Inf
        bestA := 0
        for a := range s.costs[v] {
            c := add(s.costs[v][a], s.edgeCost(e, v, a, u, b))
            if c < best {
                best, bestA = c, a
            }
        }
        mapping[b] = bestA
        s.costs[u][b] = add(s.costs[u][b], best)
    }
    s.removeEdge(v, u)
    s.active[v] = false
    *recs = append(*recs, record{kind: recR1, v: v, u: u, map1: mapping})
}

// R2: eliminate a degree-two node.  The minimum over v for every pair of
// values of its two neighbours becomes a new (or added) edge between those
// neighbours.  This is exact variable elimination with the only possible
// fill-in being the edge u-w.
func (s *state) reduceR2(v int, recs *[]record) {
    var u, w int
    var eu, ew *edge
    for k, ee := range s.adj[v] {
        if eu == nil {
            u, eu = k, ee
        } else {
            w, ew = k, ee
        }
    }
    du, dw := len(s.costs[u]), len(s.costs[w])
    delta := make([][]int64, du)
    mapping := make([][]int, du)
    for i := 0; i < du; i++ {
        delta[i] = make([]int64, dw)
        mapping[i] = make([]int, dw)
        for j := 0; j < dw; j++ {
            best := Inf
            bestA := 0
            for a := range s.costs[v] {
                c := add(s.costs[v][a],
                    add(s.edgeCost(eu, v, a, u, i), s.edgeCost(ew, v, a, w, j)))
                if c < best {
                    best, bestA = c, a
                }
            }
            delta[i][j] = best
            mapping[i][j] = bestA
        }
    }
    s.addEdgeMatrix(u, w, delta)
    s.removeEdge(v, u)
    s.removeEdge(v, w)
    s.active[v] = false
    *recs = append(*recs, record{kind: recR2, v: v, u: u, w: w, map2: mapping})
}

// reduceInfiniteEdges handles the two rigorous infinite-cost edge cases:
//   - an edge with no finite entry proves infeasibility;
//   - an edge with exactly one finite entry forces both endpoints.
//
// In the second case it fixes one endpoint; the next reduction pass will fix
// the other via RN.  Returns (progress, feasible).
func (s *state) reduceInfiniteEdges(recs *[]record, constCost *int64) (bool, bool) {
    for a := 0; a < s.n; a++ {
        if !s.active[a] {
            continue
        }
        for b, e := range s.adj[a] {
            if b <= a || !s.active[b] {
                continue
            }
            count := 0
            fi, fj := -1, -1
            for i := range e.m {
                for j := range e.m[i] {
                    if e.m[i][j] < Inf {
                        count++
                        fi, fj = i, j
                        if count > 1 {
                            break
                        }
                    }
                }
                if count > 1 {
                    break
                }
            }
            if count == 0 {
                return false, false
            }
            if count == 1 {
                // e is canonical (e.a < e.b), so fi is for e.a and fj for e.b.
                na, nb := e.a, e.b
                va, vb := fi, fj
                if s.costs[na][va] >= Inf || s.costs[nb][vb] >= Inf {
                    return false, false
                }
                c := s.costs[na][va]
                *constCost = add(*constCost, c)
                *recs = append(*recs, record{kind: recFixed, v: na, val: va})
                s.fix(na, va)
                return true, true
            }
        }
    }
    return false, true
}

// pruneDominated implements the optional part of RN: if b is pointwise no
// worse than a on v's node cost and on every incident edge row, then a can
// never be needed by an optimal solution and is marked unavailable.  The
// index tie-break prevents removing mutually equal options.
func (s *state) pruneDominated() bool {
    for v := 0; v < s.n; v++ {
        if !s.active[v] {
            continue
        }
        dominated := make([]bool, len(s.costs[v]))
        for a := range s.costs[v] {
            if s.costs[v][a] >= Inf {
                continue
            }
            for b := range s.costs[v] {
                if a == b || s.costs[v][b] >= Inf {
                    continue
                }
                le := s.costs[v][b] <= s.costs[v][a]
                strict := s.costs[v][b] < s.costs[v][a]
                if le {
                    for u, e := range s.adj[v] {
                        for x := range s.costs[u] {
                            cb := s.edgeCost(e, v, b, u, x)
                            ca := s.edgeCost(e, v, a, u, x)
                            if cb > ca {
                                le = false
                                break
                            }
                            if cb < ca {
                                strict = true
                            }
                        }
                        if !le {
                            break
                        }
                    }
                }
                // If the rows are identical, only the lower index dominates.
                if le && (strict || b < a) {
                    dominated[a] = true
                    break
                }
            }
        }
        changed := false
        for a := range dominated {
            if dominated[a] {
                s.costs[v][a] = Inf
                changed = true
            }
        }
        if changed {
            return true
        }
    }
    return false
}

// reduce applies all locally exact rules to a fixed point.  It returns the
// extended reduction stack, the constant cost accumulated from fixed nodes,
// and whether a finite solution is still possible.
func (s *state) reduce(recs []record) ([]record, int64, bool) {
    constCost := int64(0)
    for {
        changed := false

        // R0 and RN.
        for v := 0; v < s.n; v++ {
            if !s.active[v] {
                continue
            }
            if len(s.adj[v]) == 0 {
                val, c := minVector(s.costs[v])
                if c >= Inf {
                    return recs, constCost, false
                }
                recs = append(recs, record{kind: recFixed, v: v, val: val})
                constCost = add(constCost, c)
                s.active[v] = false
                changed = true
                continue
            }

            // RN: a node with exactly one finite option is forced.
            count, val := 0, -1
            for a, c := range s.costs[v] {
                if c < Inf {
                    count++
                    val = a
                    if count > 1 {
                        break
                    }
                }
            }
            if count == 0 {
                return recs, constCost, false
            }
            if count == 1 {
                c := s.costs[v][val]
                recs = append(recs, record{kind: recFixed, v: v, val: val})
                constCost = add(constCost, c)
                s.fix(v, val)
                changed = true
            }
        }
        if changed {
            continue
        }

        // R1.
        for v := 0; v < s.n; v++ {
            if s.active[v] && len(s.adj[v]) == 1 {
                s.reduceR1(v, &recs)
                changed = true
                break
            }
        }
        if changed {
            continue
        }

        // R2.
        for v := 0; v < s.n; v++ {
            if s.active[v] && len(s.adj[v]) == 2 {
                s.reduceR2(v, &recs)
                changed = true
                break
            }
        }
        if changed {
            continue
        }

        // Infinite-cost edge elimination.
        progress, feasible := s.reduceInfiniteEdges(&recs, &constCost)
        if !feasible {
            return recs, constCost, false
        }
        if progress {
            continue
        }

        // Optional dominance pruning inside RN.
        if s.pruneDominated() {
            continue
        }

        break
    }
    return recs, constCost, true
}

// Branch-and-bound fallback (keeps the solver exact on irreducible cores)

func (s *state) numActive() int {
    n := 0
    for _, a := range s.active {
        if a {
            n++
        }
    }
    return n
}

func (s *state) lowerBound() int64 {
    lb := int64(0)
    for v := 0; v < s.n; v++ {
        if !s.active[v] {
            continue
        }
        _, c := minVector(s.costs[v])
        lb = add(lb, c)
    }
    for a := 0; a < s.n; a++ {
        if !s.active[a] {
            continue
        }
        for b, e := range s.adj[a] {
            if b <= a || !s.active[b] {
                continue
            }
            lb = add(lb, minMatrix(e.m))
        }
    }
    return lb
}

func (s *state) chooseNode() int {
    best := -1
    bestDomain := int(^uint(0) >> 1)
    bestDegree := -1
    for v := 0; v < s.n; v++ {
        if !s.active[v] {
            continue
        }
        d := len(s.costs[v])
        deg := len(s.adj[v])
        if d < bestDomain || (d == bestDomain && deg > bestDegree) {
            best, bestDomain, bestDegree = v, d, deg
        }
    }
    return best
}

// search is exact.  cutoff is an upper bound: only solutions with cost < cutoff
// are useful to the caller.  The initial call uses Inf, so the first feasible
// solution with cost < Inf is found and then improved until optimal.
func search(s *state, recs []record, constCost, cutoff int64) ([]int, int64, bool) {
    recs, added, ok := s.reduce(recs)
    constCost = add(constCost, added)
    if !ok || constCost >= Inf {
        return nil, Inf, false
    }

    if s.numActive() == 0 {
        choice := reconstruct(recs, s.n)
        if choice == nil {
            return nil, Inf, false
        }
        return choice, constCost, true
    }

    lb := add(constCost, s.lowerBound())
    if lb >= cutoff {
        return nil, Inf, false
    }

    v := s.chooseNode()
    if v < 0 {
        return nil, Inf, false
    }

    type option struct {
        val  int
        cost int64
    }
    options := make([]option, 0, len(s.costs[v]))
    for a, c := range s.costs[v] {
        if c < Inf {
            options = append(options, option{val: a, cost: c})
        }
    }
    // Cheap options first usually produce a good incumbent quickly.
    for i := 1; i < len(options); i++ {
        for j := i; j > 0 && options[j].cost < options[j-1].cost; j-- {
            options[j], options[j-1] = options[j-1], options[j]
        }
    }

    bestCost := cutoff
    var bestChoice []int
    for _, opt := range options {
        child := s.clone()
        added := child.fix(v, opt.val)
        nextConst := add(constCost, added)
        if nextConst >= Inf {
            continue
        }
        // Negative benefit edges mean a larger immediate node cost can still
        // lead to a better total.  Prune only with a valid lower bound.
        if add(nextConst, child.lowerBound()) >= bestCost {
            continue
        }
        nextRecs := append(append([]record(nil), recs...),
            record{kind: recFixed, v: v, val: opt.val})
        choice, cost, ok := search(child, nextRecs, nextConst, bestCost)
        if ok && cost < bestCost {
            bestCost, bestChoice = cost, choice
        }
    }
    if bestChoice == nil {
        return nil, Inf, false
    }
    return bestChoice, bestCost, true
}

package pbqp

import (
    "fmt"
    "sort"
)

// RegisterClass is an arbitrary set of physical register identifiers.  Classes
// may overlap; the identifiers are global, not class-local.
type RegisterClass struct {
    Name string
    Regs []int
}

// Value is an SSA value that needs a register or must be spilled.
//
// SpillCost is the cost paid when the value is spilled (typically a weighted
// use/def count).  FixedReg >= 0 marks a precoloured value; it may not spill
// and must receive that physical register.  AllowedRegs, when non-nil,
// overrides the class register set for this value (it is still checked against
// FixedReg).
type Value struct {
    Name        string
    Class       string
    FixedReg    int
    AllowedRegs []int
    SpillCost   int64
}

// Interference is an undirected interference edge.  Both endpoints may not
// receive the same physical register.
type Interference struct {
    A, B string
}

// Affinity (a "benefit edge" or copy preference) subtracts Benefit when both
// values receive the same physical register.  It never makes a conflicting
// pair feasible.
type Affinity struct {
    A, B    string
    Benefit int64
}

// RAProblem is the input to the PBQP register allocator.
type RAProblem struct {
    Classes      []RegisterClass
    Values       []Value
    Interference []Interference
    Affinities   []Affinity
}

// Option is one point in a value's domain: either the spill option or a
// concrete physical register.
type Option struct {
    Spill bool
    Reg   int
}

// Layout records how PBQP node ids and choice indices map back to the source
// values and physical registers.
type Layout struct {
    Names   []string
    Options [][]Option
    Node    map[string]int
}

// Allocation is the final register assignment.  Reg is -1 for a spilled value.
type Allocation struct {
    Reg     map[string]int
    Spilled map[string]bool
    Cost    int64
    Choices []int
}

func contains(regs []int, reg int) bool {
    for _, r := range regs {
        if r == reg {
            return true
        }
    }
    return false
}

func dedup(regs []int) []int {
    seen := make(map[int]bool, len(regs))
    out := make([]int, 0, len(regs))
    for _, r := range regs {
        if !seen[r] {
            seen[r] = true
            out = append(out, r)
        }
    }
    return out
}

func canonical(a, b int) [2]int {
    if a < b {
        return [2]int{a, b}
    }
    return [2]int{b, a}
}

// BuildRA lowers an SSA interference/affinity instance to a PBQP problem.
//
// Node domains always start with choice 0, the spill option, followed by the
// value's allowed physical registers.  Precoloured values get Inf for spill
// and are restricted to their fixed register.  A conflict edge has Inf on
// equal-register pairs; an affinity edge has -Benefit on equal-register pairs.
func BuildRA(ra *RAProblem) (*Problem, *Layout, error) {
    if ra == nil {
        return nil, nil, fmt.Errorf("regalloc: nil problem")
    }
    classes := make(map[string][]int, len(ra.Classes))
    for _, c := range ra.Classes {
        if _, exists := classes[c.Name]; exists {
            return nil, nil, fmt.Errorf("regalloc: duplicate register class %q", c.Name)
        }
        classes[c.Name] = dedup(append([]int(nil), c.Regs...))
    }

    layout := &Layout{
        Names:   make([]string, len(ra.Values)),
        Options: make([][]Option, len(ra.Values)),
        Node:    make(map[string]int, len(ra.Values)),
    }
    p := &Problem{Costs: make([][]int64, len(ra.Values))}

    for i, v := range ra.Values {
        if v.Name == "" {
            return nil, nil, fmt.Errorf("regalloc: value %d has an empty name", i)
        }
        if _, exists := layout.Node[v.Name]; exists {
            return nil, nil, fmt.Errorf("regalloc: duplicate value %q", v.Name)
        }
        classRegs, ok := classes[v.Class]
        if !ok {
            return nil, nil, fmt.Errorf("regalloc: value %q uses unknown class %q", v.Name, v.Class)
        }
        allowed := classRegs
        if v.AllowedRegs != nil {
            allowed = dedup(append([]int(nil), v.AllowedRegs...))
        }
        if v.FixedReg >= 0 {
            if !contains(allowed, v.FixedReg) {
                return nil, nil, fmt.Errorf(
                    "regalloc: value %q is fixed to r%d, which is not in its allowed set",
                    v.Name, v.FixedReg)
            }
            allowed = []int{v.FixedReg}
        }

        layout.Names[i] = v.Name
        layout.Node[v.Name] = i

        opts := make([]Option, 0, 1+len(allowed))
        costs := make([]int64, 0, 1+len(allowed))
        opts = append(opts, Option{Spill: true, Reg: -1})
        if v.FixedReg >= 0 {
            costs = append(costs, Inf) // a precoloured value cannot spill
        } else {
            costs = append(costs, v.SpillCost)
        }
        for _, r := range allowed {
            opts = append(opts, Option{Spill: false, Reg: r})
            costs = append(costs, 0)
        }
        layout.Options[i] = opts
        p.Costs[i] = costs
    }

    // Matrices are keyed by the canonical node pair.  Rows and columns are
    // ordered according to that canonical key.
    matrices := make(map[[2]int][][]int64)
    getMatrix := func(a, b int) [][]int64 {
        k := canonical(a, b)
        if m := matrices[k]; m != nil {
            return m
        }
        m := make([][]int64, len(layout.Options[k[0]]))
        for i := range m {
            m[i] = make([]int64, len(layout.Options[k[1]]))
        }
        matrices[k] = m
        return m
    }
    addAt := func(a, b, oa, ob int, delta int64) {
        k := canonical(a, b)
        m := getMatrix(a, b)
        if a == k[0] {
            m[oa][ob] = add(m[oa][ob], delta)
        } else {
            m[ob][oa] = add(m[ob][oa], delta)
        }
    }

    for _, e := range ra.Interference {
        a, aok := layout.Node[e.A]
        b, bok := layout.Node[e.B]
        if !aok || !bok {
            return nil, nil, fmt.Errorf("regalloc: interference refers to unknown value %q or %q", e.A, e.B)
        }
        if a == b {
            return nil, nil, fmt.Errorf("regalloc: self interference on %q", e.A)
        }
        for oa, x := range layout.Options[a] {
            for ob, y := range layout.Options[b] {
                if !x.Spill && !y.Spill && x.Reg == y.Reg {
                    addAt(a, b, oa, ob, Inf)
                }
            }
        }
    }

    for _, e := range ra.Affinities {
        a, aok := layout.Node[e.A]
        b, bok := layout.Node[e.B]
        if !aok || !bok {
            return nil, nil, fmt.Errorf("regalloc: affinity refers to unknown value %q or %q", e.A, e.B)
        }
        if a == b {
            return nil, nil, fmt.Errorf("regalloc: self affinity on %q", e.A)
        }
        for oa, x := range layout.Options[a] {
            for ob, y := range layout.Options[b] {
                if !x.Spill && !y.Spill && x.Reg == y.Reg {
                    addAt(a, b, oa, ob, -e.Benefit)
                }
            }
        }
    }

    keys := make([][2]int, 0, len(matrices))
    for k := range matrices {
        keys = append(keys, k)
    }
    sort.Slice(keys, func(i, j int) bool {
        if keys[i][0] != keys[j][0] {
            return keys[i][0] < keys[j][0]
        }
        return keys[i][1] < keys[j][1]
    })
    for _, k := range keys {
        p.Edges = append(p.Edges, Edge{A: k[0], B: k[1], M: matrices[k]})
    }
    if err := p.Validate(); err != nil {
        return nil, nil, fmt.Errorf("regalloc: invalid PBQP: %w", err)
    }
    return p, layout, nil
}

// Allocate builds and solves the PBQP instance, then reconstructs the
// spill/register decisions from the selected PBQP options.
func (ra *RAProblem) Allocate() (*Allocation, error) {
    p, layout, err := BuildRA(ra)
    if err != nil {
        return nil, err
    }
    sol, err := Solve(p)
    if err != nil {
        return nil, err
    }
    out := &Allocation{
        Reg:     make(map[string]int, len(layout.Names)),
        Spilled: make(map[string]bool, len(layout.Names)),
        Cost:    sol.Cost,
        Choices: append([]int(nil), sol.Choices...),
    }
    for i, name := range layout.Names {
        opt := layout.Options[i][sol.Choices[i]]
        if opt.Spill {
            out.Reg[name] = -1
            out.Spilled[name] = true
        } else {
            out.Reg[name] = opt.Reg
        }
    }
    return out, nil
}

Optimality argument

  • R0, RN, R1, and R2 each replace a subproblem by an equivalent one plus a constant, so they preserve the global minimum and record enough information for reconstruction.
  • R∞ is exact: an all-Inf edge has no feasible assignment; a single finite edge forces both endpoint choices.
  • On the remaining core, branch-and-bound enumerates all finite options. Its lower bound is a sum of per-node minima and per-edge minima, which can never exceed any completion’s true cost, including with negative benefit edges.
  • At termination, Solve evaluates the reconstructed assignment directly and rejects any mismatch. Therefore every reported finite cost is both feasible and globally optimal; infeasible instances return ErrUnsolvable.
