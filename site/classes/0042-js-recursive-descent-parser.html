The parser consists of three classes:

Lexer — Tokenizes input into a stream of tokens (INT, FLOAT, STRING, BOOL, NULL, IDENTIFIER, operators, brackets, etc.). Handles: - Skip whitespace and comments (// line, /* block */) - Read integers (42) and floats (3.14) - Read strings with escape sequences ("hello\nworld", 'single') - Read identifiers and keywords (true, false, null, fooBar) - Two-character operators (==, !=, <=, >=, &&, ||) - Friendly error messages for = (suggest ==) and single &/| (suggest &&/||) - Accurate line:col tracking

ParseError — Error class with line/col in message (Parse error at 1:3: ...)

Parser — Recursive descent with methods for each precedence level:

Level Method Operators Associativity
1 (lowest) parseTernary ?: Right
2 parseLogicalOr \|\| Left
3 parseLogicalAnd && Left
4 parseEquality ==, != Left
5 parseRelational <, >, <=, >= Left
6 parseAdditive +, - Left
7 parseMultiplicative *, /, % Left
8 parseUnary !, - (prefix) Right (nested)
9 (highest) parsePrimary literals, identifiers, (...), [...], {...} —

AST Node Types: - Literal — { type, value, raw, line, col } - Identifier — { type, name, line, col } - BinaryExpression — { type, operator, left, right, line, col } - UnaryExpression — { type, operator, operand, line, col } - LogicalExpression — { type, operator, left, right, line, col } - TernaryExpression — { type, test, consequent, alternate, line, col } - ArrayExpression — { type, elements, line, col } - ObjectExpression — { type, properties, line, col } - Property — { type, key, value, line, col }

Key design decisions: - Ternary is right-associative (a ? b : c ? d : e → a ? b : (c ? d : e)) via parseTernary calling parseExpression for the alternate, which re-enters ternary parsing - All binary operators are left-associative via while loops - Unary operators chain: !!x becomes Unary(!, Unary(!, Identifier(x))) - Arrays and objects support trailing commas

Edge cases verified:
```
Input:  a ? b : c ? d : e     → Ternary(a, b, Ternary(c, d, e))   [right-associative]
Input:  1 + 2 * 3 - 4 / 2     → ((1 + (2*3)) - (4/2))             [precedence correct]
Input:  a < b && c >= d || e == f  → ((a<b) && (c>=d)) || (e==f)  [chained precedence]
Input:  [[1, 2], [3, 4]]       → nested arrays
Input:  {a: 1, b: {c: 2}}      → nested objects
Input:  [1, 2,]                → trailing comma in array
Input:  {a: 1,}                → trailing comma in object
Input:  a = b                  → "Unexpected '=' — did you mean '=='?"
Input:  ""                     → "Parse error at 1:1: Empty input"
```
