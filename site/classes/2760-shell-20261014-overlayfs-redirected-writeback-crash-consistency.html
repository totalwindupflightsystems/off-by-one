Overlayfs Redirected-Writeback Crash Consistency — Recovery Harness

Problem class: shell-20261014-overlayfs-redirected-writeback-crash-consistency Environment / language: bash · Version: 1.0

1. Root-cause analysis

A layered filesystem expands one logical operation into several physical writes on different objects. Those writes can reach stable storage in different orders, while POSIX only tells the application which objects to fsync:

logical op what the application fsyncs
write/overwrite file fsync(file) and fsync(dir)
create / mkdir / unlink / rmdir fsync(parent_dir)
rename fsync(old_parent), fsync(new_parent)

The canonical failure is rename of a lower directory rename("/a","/b"), which makes overlayfs emit:

upper/mkdir            /b
upper/xattr            /b  trusted.overlay.redirect = /a   <- on the moved dir itself
upper/whiteout         /a                                  <- in parent /
upper/dentry           /b                                  <- in parent /
upper/dentry-remove    /a                                  <- in parent /

The application follows POSIX and calls fsync("/"). That covers the whiteout and dentries (they live in /) but not the trusted.overlay.redirect xattr, which lives on /b. If the dentries land and the redirect xattr is lost, /b exists but no longer merges lower /a → lost rename / lost content; if instead the whiteout is lost, /a stays resolvable → stale lower-layer visibility. The copy-up variant is analogous: fsync(parent) alone leaves absent/zero-length upper data plus a missing trusted.overlay.origin, so old bytes reappear.

Why naive checkers are wrong: the correct rename result legitimately contains a whiteout (/a) and a redirect (/b -> /a). A checker that treats those as contradictory rejects valid crash images. The right property is coverage (every acknowledged op's entire physical write set must be fsync-covered) plus reachability (each surviving redirect must resolve to a real lower object). Crash-before-fsync is legal and must not be flagged.

2. The fix — overlay_recover.sh

The harness replays the trace + crash point, computes fsync coverage, reconstructs the merged namespace, audits a concrete crash image, and emits a ddmin-minimal machine-checkable counterexample. Memory is O(physical writes + fsyncs + records); redirect chains are bounded at 64 hops.

2.1 Full harness

#!/usr/bin/env bash
# =============================================================================
# overlay_recover.sh -- crash-consistency recovery harness for an overlayfs-like
# layered filesystem.
#
# It replays a logical operation trace plus a crash point, computes the set of
# physical writes guaranteed durable by the acknowledged fsync() calls,
# reconstructs the merged (lower+upper) namespace, and proves whether that
# namespace is consistent.
#
# Central failure detected: an operation acknowledged by POSIX-style fsync()
# (fsync the file and/or fsync the containing directory) whose *physical
# overlayfs write set* is only partially covered -- in particular the
# `trusted.overlay.redirect` xattr of a renamed directory, which lives on the
# moved directory itself and is NOT covered by fsync() of the parent directory.
#
# Usage:
#   overlay_recover.sh --trace TRACE [--crash N] [--image FILE] [--dump] [--minimize]
#
# Trace DSL (one record per line, '#' comments, blank lines ignored):
#   lower <path> <file|dir>       pre-existing durable lower-layer object
#   create <path> [data]          create/overwrite a file (copy-up if lower)
#   mkdir <path>                  create a directory
#   unlink <path>                 delete a file
#   rmdir <path>                  delete a directory
#   rename <old> <new>            rename a file or directory
#   fsync <path>                  acknowledged fsync() of <path>
#   fsyncall                      acknowledged fsync() of everything prior
#   raw <op> <args...>            inject one physical write (advanced)
#   crash                         crash point; later records are never durable
#
# Exit status: 0 = CONSISTENT, 1 = INCONSISTENT, 2 = usage/parse error.
# =============================================================================

set -u
set -o pipefail

PROG=${0##*/}
VERSION="1.0"

die() { printf '%s: %s\n' "$PROG" "$*" >&2; exit 2; }

parent_of() {
    local p=$1
    case $p in
        */*/*) printf '%s' "${p%/*}" ;;
        /*)    printf '/' ;;
        *)     printf '.' ;;
    esac
}

# ---------------------------------------------------------------------------
# analyze <cleaned-record-file> [crash-limit] [image-file]
#   Reads records until `crash` (or crash-limit). Prints a report.
#   If image-file is given it lists the physical-write IDs (#N from
#   --list-writes) that actually survived the crash; the recovered namespace
#   is built from those and audited against every acknowledged fsync.
#   Returns 0 if CONSISTENT, 1 if INCONSISTENT, 2 on malformed record.
# ---------------------------------------------------------------------------
analyze() {
    local file=$1 crash_limit=${2:-} image_file=${3:-}
    local line cmd sub seq=0
    local -a pw_target=() pw_desc=() pw_owner=() pw_seq=()
    local -a fs_path=() fs_seq=()
    local -A lower_t=() upper_t=()
    local -A op_kind=() op_ack=()
    local -a op_seq=()
    local n_pw=0 n_fs=0 n_op=0 cur_op=-1
    local -A U=() X=()
    local i j o missing total_viol=0

    # emit ONE physical write: target, human description, owner op index (-1=raw)
    emit() {
        pw_target[$n_pw]=$1
        pw_desc[$n_pw]=$2
        pw_owner[$n_pw]=$3
        pw_seq[$n_pw]=$seq
        n_pw=$((n_pw + 1))
    }
    new_op() {
        cur_op=$n_op
        op_kind[$cur_op]=$1
        op_seq[$cur_op]=$seq
        op_ack[$cur_op]=${2:-}
        n_op=$((n_op + 1))
    }

    while IFS= read -r line; do
        line=${line%%#*}
        set -- $line
        [ $# -eq 0 ] && continue
        cmd=${1:-}; shift || true
        seq=$((seq + 1))
        [ -n "$crash_limit" ] && [ "$seq" -gt "$crash_limit" ] && break

        case $cmd in
            crash) break ;;

            lower)
                lower_t[${1:-}]=${2:-file}
                ;;

            create)
                local p=${1:-}; [ -z "$p" ] && return 2
                local par; par=$(parent_of "$p")
                new_op create "$p $par"
                if [ "${lower_t[$p]:-}" = file ]; then
                    emit "$p" "copyup-data:$p" "$cur_op"
                    emit "$p" "xattr:$p:trusted.overlay.origin" "$cur_op"
                else
                    emit "$p" "upper-data:$p" "$cur_op"
                fi
                upper_t[$p]=file
                ;;

            mkdir)
                local p=${1:-}; [ -z "$p" ] && return 2
                local par; par=$(parent_of "$p")
                new_op mkdir "$par"
                emit "$par" "mkdir:$p" "$cur_op"
                upper_t[$p]=dir
                ;;

            unlink|rmdir)
                local p=${1:-}; [ -z "$p" ] && return 2
                local par; par=$(parent_of "$p")
                new_op "$cmd" "$par"
                emit "$par" "whiteout:$p" "$cur_op"
                upper_t[$p]=whiteout
                ;;

            rename)
                local old=${1:-} new=${2:-}; [ -z "$new" ] && return 2
                local po pn; po=$(parent_of "$old"); pn=$(parent_of "$new")
                local lt=${lower_t[$old]:-} ut=${upper_t[$old]:-}
                if [ -n "$ut" ]; then
                    new_op rename "$po $pn"
                    emit "$pn" "dentry:$new" "$cur_op"
                    emit "$po" "dentry-remove:$old" "$cur_op"
                    upper_t[$new]=$ut; upper_t[$old]=whiteout
                elif [ "$lt" = dir ]; then
                    # Renamed lower directory: overlayfs creates the target
                    # directory, marks it with a redirect xattr pointing at the
                    # old lower path, and leaves a whiteout at the old name.
                    # POSIX tells the application to fsync the two parent
                    # directories only -- NOT the moved directory.
                    new_op rename-lower-dir "$po $pn"
                    emit "$pn" "mkdir:$new" "$cur_op"
                    emit "$new" "xattr:$new:trusted.overlay.redirect=$old" "$cur_op"
                    emit "$po" "whiteout:$old" "$cur_op"
                    emit "$pn" "dentry:$new" "$cur_op"
                    emit "$po" "dentry-remove:$old" "$cur_op"
                    upper_t[$new]=dir; upper_t[$old]=whiteout
                elif [ "$lt" = file ]; then
                    new_op rename-lower-file "$po $pn"
                    emit "$new" "copyup-data:$new" "$cur_op"
                    emit "$new" "xattr:$new:trusted.overlay.origin" "$cur_op"
                    emit "$po" "whiteout:$old" "$cur_op"
                    emit "$pn" "dentry:$new" "$cur_op"
                    emit "$po" "dentry-remove:$old" "$cur_op"
                    upper_t[$new]=file; upper_t[$old]=whiteout
                else
                    new_op rename "$po $pn"
                    emit "$pn" "dentry:$new" "$cur_op"
                    emit "$po" "dentry-remove:$old" "$cur_op"
                    upper_t[$new]=dir; upper_t[$old]=whiteout
                fi
                ;;

            fsync)
                local p=${1:-}; [ -z "$p" ] && return 2
                fs_path[$n_fs]=$p; fs_seq[$n_fs]=$seq; n_fs=$((n_fs + 1))
                ;;

            fsyncall)
                fs_path[$n_fs]='*'; fs_seq[$n_fs]=$seq; n_fs=$((n_fs + 1))
                ;;

            raw)
                sub=${1:-}; shift || true
                local p par
                case $sub in
                    write)    p=${1:-}; emit "$p" "raw-data:$p" -1 ;;
                    mkdir)    p=${1:-}; par=$(parent_of "$p"); emit "$par" "raw-mkdir:$p" -1 ;;
                    whiteout) p=${1:-}; par=$(parent_of "$p"); emit "$par" "raw-whiteout:$p" -1 ;;
                    setxattr) p=${1:-}; emit "$p" "raw-xattr:$p:${2:-}=${3:-}" -1 ;;
                    rmxattr)  p=${1:-}; emit "$p" "raw-rmxattr:$p:${2:-}" -1 ;;
                    *) return 2 ;;
                esac
                ;;

            *) return 2 ;;
        esac
    done < "$file"

    local crash_seq=$seq

    # ---- optional crash image: one physical-write ID per line (#N from
    #      --list-writes), naming the writes that reached stable storage.
    local -A in_image=()
    if [ -n "$image_file" ]; then
        while IFS= read -r line; do
            line=${line%%#*}; set -- $line; [ $# -eq 0 ] && continue
            in_image[$1]=1
        done < "$image_file"
    fi

    # ---- coverage: write i is durable iff an acknowledged fsync of its exact
    #      target (or a fsyncall) happened after the write and before the crash.
    local -a covered=() durable=()
    for ((i=0; i<n_pw; i++)); do
        covered[$i]=0
        for ((j=0; j<n_fs; j++)); do
            if [ "${fs_seq[$j]}" -gt "${pw_seq[$i]}" ] && \
               { [ "${fs_path[$j]}" = "${pw_target[$i]}" ] || [ "${fs_path[$j]}" = '*' ]; }; then
                covered[$i]=1; break
            fi
        done
        if [ -n "$image_file" ]; then
            if [ -n "${in_image[$i]:-}" ]; then durable[$i]=1; else durable[$i]=0; fi
        else
            durable[$i]=${covered[$i]}
        fi
    done

    # ---- an op is acknowledged when every POSIX ack target was fsynced after it
    acked() {
        local o=$1 t found=0
        for t in ${op_ack[$o]}; do
            found=0
            for ((j=0; j<n_fs; j++)); do
                if [ "${fs_seq[$j]}" -gt "${op_seq[$o]}" ] && \
                   { [ "${fs_path[$j]}" = "$t" ] || [ "${fs_path[$j]}" = '*' ]; }; then
                    found=1; break
                fi
            done
            [ "$found" -eq 0 ] && return 1
        done
        return 0
    }

    # ---- completeness: every acknowledged op must have ALL its physical writes
    #      covered by an acknowledged fsync.
    local report=""
    for ((o=0; o<n_op; o++)); do
        acked "$o" || continue
        missing=""
        for ((i=0; i<n_pw; i++)); do
            if [ "${pw_owner[$i]}" = "$o" ] && [ "${covered[$i]}" -eq 0 ]; then
                missing+="    - ${pw_desc[$i]}  (write #$i, fsync target '${pw_target[$i]}', seq ${pw_seq[$i]})"$'\n'
            fi
        done
        if [ -n "$missing" ]; then
            total_viol=$((total_viol + 1))
            report+="  [violation $total_viol] acknowledged op #$o '${op_kind[$o]}' has non-durable physical writes:"$'\n'
            report+="$missing"
            report+="    => after the crash this op is half-applied (lost rename / stale lower visibility)."$'\n'
        fi
    done

    # ---- a concrete crash image must contain every fsync-guaranteed write.
    if [ -n "$image_file" ]; then
        for ((i=0; i<n_pw; i++)); do
            if [ "${covered[$i]}" -eq 1 ] && [ "${durable[$i]}" -eq 0 ]; then
                total_viol=$((total_viol + 1))
                report+="  [violation $total_viol] acknowledged fsync guarantees '${pw_desc[$i]}' (write #$i) but it is absent from the crash image."$'\n'
            fi
        done
    fi

    # ---- reconstruct the durable namespace from surviving writes only.
    #      descriptor: kind:path[:name[=value]]
    for ((i=0; i<n_pw; i++)); do
        [ "${durable[$i]}" -eq 0 ] && continue
        local d=${pw_desc[$i]} kind rest path third
        kind=${d%%:*}; rest=${d#*:}; path=${rest%%:*}; third=""
        [ "$rest" != "$path" ] && third=${rest#*:}
        case $kind in
            upper-data|copyup-data|raw-data) U[$path]=file ;;
            mkdir|raw-mkdir)                U[$path]=dir ;;
            whiteout|raw-whiteout)          U[$path]=whiteout ;;
            xattr|raw-xattr)                X["${path}.${third}"]=1 ;;
            raw-rmxattr)                    unset "X[${path}.${third}]" 2>/dev/null || true ;;
            *) : ;;
        esac
    done

    # ---- legality of the reconstructed namespace.
    #      a) a redirect xattr must be on an upper directory;
    #      b) it must resolve, through any chain of redirects, to a lower object.
    for k in "${!X[@]}"; do
        case $k in
            *.trusted.overlay.redirect=*) ;;
            *) continue ;;
        esac
        local path=${k%%.trusted.overlay.redirect=*}
        local val=${k#*.trusted.overlay.redirect=}
        if [ "${U[$path]:-}" != dir ]; then
            total_viol=$((total_viol + 1))
            report+="  [violation $total_viol] redirect xattr on non-directory '$path'."$'\n'
        fi
        local cur=$val hops=0 ok=0 nxt kk
        while [ -n "$cur" ] && [ "$hops" -lt 64 ]; do
            if [ -n "${lower_t[$cur]:-}" ]; then ok=1; break; fi
            nxt=""
            for kk in "${!X[@]}"; do
                case $kk in
                    "$cur".trusted.overlay.redirect=*) nxt=${kk#*.trusted.overlay.redirect=} ;;
                esac
            done
            [ -z "$nxt" ] && break
            cur=$nxt; hops=$((hops + 1))
        done
        if [ "$ok" -eq 0 ]; then
            total_viol=$((total_viol + 1))
            report+="  [violation $total_viol] dangling redirect '$path' -> '$val' (no lower object)."$'\n'
        fi
    done

    if [ "${LIST_WRITES:-0}" -eq 1 ]; then
        printf 'PHYSICAL WRITES:\n'
        for ((i=0; i<n_pw; i++)); do
            printf '  #%d seq=%-3d target=%-8s durable=%d  %s\n' \
                "$i" "${pw_seq[$i]}" "${pw_target[$i]}" "${durable[$i]}" "${pw_desc[$i]}"
        done
        return 0
    fi
    if [ "${DUMP_STATE:-0}" -eq 1 ]; then
        printf 'RECOVERED NAMESPACE:\n'
        local uk
        for uk in $(printf '%s\n' "${!U[@]}" | sort); do printf '  %-14s %s\n' "${U[$uk]}" "$uk"; done
        for uk in $(printf '%s\n' "${!X[@]}" | sort); do printf '  xattr          %s\n' "$uk"; done
    fi
    if [ "$total_viol" -eq 0 ]; then
        printf 'RESULT: CONSISTENT\n'
        return 0
    fi
    printf 'RESULT: INCONSISTENT (%d violation(s))\n' "$total_viol"
    printf '%s' "$report"
    return 1
}

# ---------------------------------------------------------------------------
# minimal_counterexample <records-without-crash-file>
#   ddmin-style delta debugging over the records; prints the smallest record set
#   that still makes analyze() report INCONSISTENT.
# ---------------------------------------------------------------------------
minimal_counterexample() {
    local recfile=$1 tmp
    local -a C=()
    tmp=$(mktemp) || return 1
    mapfile -t C < "$recfile"
    local n=${#C[@]} gran=2 chunk start end i
    while [ "$n" -ge 2 ]; do
        chunk=$(( (n + gran - 1) / gran )); [ "$chunk" -lt 1 ] && chunk=1
        local reduced=0
        start=0
        while [ "$start" -lt "$n" ]; do
            end=$((start + chunk)); [ "$end" -gt "$n" ] && end=$n
            : > "$tmp"
            for ((i=0; i<n; i++)); do
                { [ "$i" -ge "$start" ] && [ "$i" -lt "$end" ]; } && continue
                printf '%s\n' "${C[$i]}" >> "$tmp"
            done
            printf 'crash\n' >> "$tmp"
            if ! analyze "$tmp" >/dev/null 2>&1; then
                local -a NC=()
                for ((i=0; i<n; i++)); do
                    { [ "$i" -ge "$start" ] && [ "$i" -lt "$end" ]; } && continue
                    NC+=("${C[$i]}")
                done
                C=("${NC[@]}"); n=${#C[@]}; reduced=1
                [ "$gran" -gt 2 ] && gran=$((gran - 1))
                break
            fi
            start=$((start + chunk))
        done
        if [ "$reduced" -eq 0 ]; then
            [ "$gran" -ge "$n" ] && break
            gran=$((gran * 2))
        fi
    done
    for ((i=0; i<n; i++)); do printf '%s\n' "${C[$i]}"; done
    rm -f "$tmp"
}
