Bounded-Memory Resume-Point Reconciliation for Fragmented btrfs Send Streams

Problem class: bash-20261015-btrfs-snapshot-send-resume-offset-reconciliation

Deliverable: a fail-closed verifier that turns corrupted/duplicated/truncated send-stream fragments plus receiver checkpoints into the maximal safe resume offset, and that provably never acknowledges a byte the receiver has not durably applied.

1. Root-cause analysis

1.1 The real defect: a send stream is not a resumable log

A btrfs send stream is a bare sequence of length-prefixed, CRC'd commands (SUBVOL, SNAPSHOT, MKFILE, RENAME, WRITE, CLONE, …). It carries:

  • no logical sequence number (so a receiver cannot tell a replay from a new record),
  • no generation counter (so wrap-around is invisible),
  • no per-record durability commitment (so "bytes received" ≠ "bytes applied"),
  • no signed parent-root transition (so a SNAPSHOT command can be forged).

Consequently, the naive resume point — the highest byte offset parsed so far, or the highest sequence number seen — is unsafe. Four distinct failure modes combine:

# Failure mode Naive behaviour Consequence
1 Committed vs. replayable Ack the last parsed byte Acking a metadata command (RENAME, UNLINK, SNAPSHOT) that was never fsynced duplicates or destroys data on replay
2 Forged parent-root transition Trust the SNAPSHOT/SUBVOL root in the stream Receiver grafts a subtree onto an attacker-chosen root
3 Sequence-number wrap seq > last_seq comparison After 0xFFFFFFFF → 0x0, every new record looks "old" and is discarded, or an old replay looks "new"
4 Duplicate extents Re-apply every WRITE/CLONE Unbounded work and unbounded memory if every extent is remembered; unsafe if duplicates are dropped from metadata order

The task is therefore not "find the last record". It is "find the highest point at which the receiver can prove a metadata-consistent, fsynced state, given only untrusted fragments".

1.2 What must be true before an offset may be acknowledged

An offset O is safe iff all of the following hold:

  1. the record stream [0, O) chains byte-for-byte to a checkpoint the trusted receiver wrote;
  2. that checkpoint was marked durable only after fsync of data + metadata + the checkpoint itself;
  3. every metadata record in [0, O) is covered by a barrier (or no metadata occurred since the last barrier, so the remainder is only replayable data).

The fix realises exactly these three conditions with constant memory.

2. Reference model

The receiver adapter produces a textual manifest (one event per line) that is already recovered in stream order by the fragment reassembler:

ANCHOR off=<u64> gen=<u32> seq=<u32> chain=<hex> meta_root=<hex>
REC    off=<u64> seq=<u32> cmd=<OP> kind=<meta|data> size=<u32> dgst=<hex> parent=<hex|->
CKPT   off=<u64> seq=<u32> chain=<hex> meta_root=<hex> parent=<hex|-> barrier=<0|1> durable=<0|1>

Hashes (SHA-256, prefix-free encoding):

chain_i      = H("C|" || chain_{i-1} || gen || seq || cmd || dgst || parent)
meta_root_i  = H("M|" || meta_{i-1}  || gen || seq || cmd || dgst || parent)   # every meta record
root         = H("R|subvol|" || dgst)                     # SUBVOL
root         = H("R|snap|"   || root || dgst)             # SNAPSHOT, parent must == root
  • kind=meta — anything that is not a WRITE/CLONE (including TRUNCATE); it is non-idempotent, so it must be covered by a barrier.
  • kind=data — WRITE/CLONE; idempotent, so it may be replayed after resume.
  • barrier=1 — the receiver has applied and fsynced every metadata record up to seq. barrier=0 is a data-only checkpoint.
  • durable=1 — the checkpoint itself is on stable storage.

ANCHOR is the last resume point already known-good (or the empty stream at off=0). It is the only trusted starting state.

3. The exact fix

3.1 reconcile.sh — bounded-memory, fail-closed reconciler

Save as reconcile.sh, chmod +x, feed the manifest on stdin. Exit 0 means a resume offset was accepted; 3 means "no advance, stay at the anchor" (fail-closed); 64 means the manifest itself is untrustworthy.

#!/usr/bin/env bash
# reconcile.sh -- bounded-memory, fail-closed reconciliation of a fragmented
# btrfs send stream against trusted receiver checkpoints.
#
# Manifest grammar (space separated key=value):
#   ANCHOR off=<u64> gen=<u32> seq=<u32> chain=<hex> meta_root=<hex>
#   REC    off=<u64> seq=<u32> cmd=<OP> kind=<meta|data> size=<u32> \
#          dgst=<hex> parent=<hex|-> [root=<hex>]
#   CKPT   off=<u64> seq=<u32> chain=<hex> meta_root=<hex> \
#          parent=<hex|-> barrier=<0|1> durable=<0|1>
#
# Exit: 0 accepted a resume point, 3 no advance (fail-closed), 64 malformed.
set -uo pipefail

WINDOW=${WINDOW:-4096}          # bounded dedup ring, entries
MAX_META=${MAX_META:-100000}    # bounded metadata-pending budget, entries

die() { printf 'ERROR: %s\n' "$*" >&2; exit 64; }
sha() { sha256sum | awk '{print $1}'; }

# Exact hash definitions -- MUST match the receiver/adapter byte-for-byte.
chain_next() { printf 'C|%s|%s|%s|%s|%s|%s' "$1" "$2" "$3" "$4" "$5" "$6" | sha; }
meta_next()  { printf 'M|%s|%s|%s|%s|%s|%s' "$1" "$2" "$3" "$4" "$5" "$6" | sha; }
root_next() {  # cmd dgst oldroot
  if [ "$1" = SUBVOL ]; then printf 'R|subvol|%s' "$2" | sha
  else                       printf 'R|snap|%s|%s' "$3" "$2" | sha; fi
}

getv() { local k="$1"; shift; local t; for t in "$@"; do case "$t" in "$k="*) printf '%s' "${t#*=}"; return 0;; esac; done; }

# ---- trusted anchor state -------------------------------------------------
anchor_off=0 anchor_gen=0 anchor_seq=0 anchor_chain="" anchor_meta=""
# ---- live state -----------------------------------------------------------
cur_gen=0 cur_seq=0 cur_chain="" cur_meta="" cur_root=""
off_exp=0 barrier_meta="" have_barrier=0
safe_off=0 safe_gen=0 safe_seq=0 safe_chain="" safe_meta=""
seen_anchor=0 n_rec=0 n_meta=0 n_data=0 n_dup=0 n_forged=0 n_gap=0

# Bounded dedup for replayable data: O(1) hash lookup + FIFO eviction ring.
# Forgetting the oldest key is safe -- WRITE/CLONE are idempotent, so a false
# negative only costs a redundant replay, never correctness.
declare -A dmap=(); declare -a dq=(); dq_head=0
is_data() { [ "$1" = WRITE ] || [ "$1" = CLONE ]; }
remember_data() { # key ; returns 1 if already seen in window
  local key="$1" old
  if [ -n "${dmap[$key]:-}" ]; then return 1; fi
  if [ "${#dq[@]}" -ge "$WINDOW" ]; then
    old="${dq[$dq_head]}"; unset 'dmap[$old]'
    dq[$dq_head]="$key"; dq_head=$(( (dq_head+1) % WINDOW ))
  else dq+=("$key"); fi
  dmap[$key]=1; return 0
}

while IFS= read -r line; do
  [ -z "$line" ] && continue
  case "$line" in \#*) continue;; esac
  read -r -a tok <<< "$line"; type="${tok[0]}"
  case "$type" in
    ANCHOR)
      anchor_off=$(getv off "${tok[@]}"); anchor_gen=$(getv gen "${tok[@]}")
      anchor_seq=$(getv seq "${tok[@]}"); anchor_chain=$(getv chain "${tok[@]}")
      anchor_meta=$(getv meta_root "${tok[@]}")
      [ -n "$anchor_chain" ] && [ -n "$anchor_meta" ] || die "anchor missing chain/meta_root"
      cur_gen=$anchor_gen; cur_seq=$anchor_seq
      cur_chain=$anchor_chain; cur_meta=$anchor_meta
      barrier_meta=$anchor_meta; have_barrier=1; off_exp=$anchor_off
      safe_off=$anchor_off; safe_gen=$anchor_gen; safe_seq=$anchor_seq
      safe_chain=$anchor_chain; safe_meta=$anchor_meta; seen_anchor=1
      ;;
    REC)
      [ "$seen_anchor" -eq 1 ] || die "REC before ANCHOR"
      r_off=$(getv off "${tok[@]}"); r_seq=$(getv seq "${tok[@]}")
      r_cmd=$(getv cmd "${tok[@]}"); r_kind=$(getv kind "${tok[@]}")
      r_size=$(getv size "${tok[@]}"); r_dgst=$(getv dgst "${tok[@]}")
      r_parent=$(getv parent "${tok[@]}"); [ -z "$r_parent" ] && r_parent=-
      [ -n "$r_off" ] && [ -n "$r_seq" ] && [ -n "$r_cmd" ] && [ -n "$r_dgst" ] \
        || die "malformed REC: $line"
      case "$r_seq" in ''|*[!0-9]*) die "non-numeric seq: $line";; esac

      # Bounded reorder window.  Generation is DERIVED, never trusted.
      # RFC1982-style serial compare makes u32 wrap explicit.
      expected=$(( (cur_seq + 1) & 0xFFFFFFFF ))
      if [ "$r_seq" = "$cur_seq" ]; then n_dup=$((n_dup+1)); continue; fi
      if [ $(( ((expected - r_seq) & 0xFFFFFFFF) < 0x80000000 )) -eq 1 ] \
         && [ "$r_seq" != "$expected" ]; then
        n_dup=$((n_dup+1)); continue     # serial-before expected -> old replay
      fi
      if [ "$r_seq" != "$expected" ]; then n_gap=$((n_gap+1)); break; fi
      case "$r_off" in ''|*[!0-9]*) die "bad off: $line";; esac
      if [ "$r_off" -ne "$off_exp" ]; then n_gap=$((n_gap+1)); break; fi

      next_gen=$cur_gen
      [ "$r_seq" = 4294967295 ] && next_gen=$((cur_gen+1))   # full u32 wrap

      # --- parent-root transition validation (anti-forgery) --------------
      if [ "$r_cmd" = SUBVOL ]; then
        [ "$r_parent" = "-" ] || { n_forged=$((n_forged+1)); break; }
        cur_root=$(root_next SUBVOL "$r_dgst" "$cur_root")
      elif [ "$r_cmd" = SNAPSHOT ]; then
        [ "$cur_root" = "$r_parent" ] || { n_forged=$((n_forged+1)); break; }
        cur_root=$(root_next SNAPSHOT "$r_dgst" "$cur_root")
      fi

      # --- chain / metadata journal --------------------------------------
      cur_chain=$(chain_next "$cur_chain" "$cur_gen" "$r_seq" "$r_cmd" "$r_dgst" "$r_parent")
      if [ "$r_kind" = meta ]; then
        n_meta=$((n_meta+1))
        [ "$n_meta" -gt "$MAX_META" ] && { n_gap=$((n_gap+1)); break; }
        cur_meta=$(meta_next "$cur_meta" "$cur_gen" "$r_seq" "$r_cmd" "$r_dgst" "$r_parent")
      elif [ "$r_kind" = data ] && is_data "$r_cmd"; then
        n_data=$((n_data+1)); remember_data "$r_dgst" || n_dup=$((n_dup+1))
      fi
      cur_gen=$next_gen; cur_seq=$r_seq; off_exp=$(( r_off + r_size )); n_rec=$((n_rec+1))
      ;;
    CKPT)
      [ "$seen_anchor" -eq 1 ] || die "CKPT before ANCHOR"
      c_off=$(getv off "${tok[@]}"); c_seq=$(getv seq "${tok[@]}")
      c_chain=$(getv chain "${tok[@]}"); c_meta=$(getv meta_root "${tok[@]}")
      c_barrier=$(getv barrier "${tok[@]}"); c_durable=$(getv durable "${tok[@]}")
      [ -n "$c_off" ] && [ -n "$c_seq" ] && [ -n "$c_chain" ] && [ -n "$c_meta" ] \
        || die "malformed CKPT: $line"
      case "$c_seq" in ''|*[!0-9]*) die "non-numeric seq: $line";; esac

      # Trust a checkpoint only if it reproduces the chained state we just
      # walked AND the receiver fsynced it.
      [ "$c_durable" = 1 ] || continue
      [ "$c_chain" = "$cur_chain" ] && [ "$c_meta" = "$cur_meta" ] || continue
      [ "$c_seq" = "$cur_seq" ] || continue

      eligible=0
      if [ "$c_barrier" = 1 ]; then
        eligible=1; barrier_meta=$cur_meta
      elif [ "$have_barrier" -eq 1 ] && [ "$cur_meta" = "$barrier_meta" ]; then
        eligible=1     # data-only: no metadata since the last durable barrier
      fi
      if [ "$eligible" -eq 1 ] && [ "$c_off" -gt "$safe_off" ]; then
        safe_off=$c_off; safe_gen=$cur_gen; safe_seq=$cur_seq
        safe_chain=$cur_chain; safe_meta=$cur_meta
      fi
      ;;
    *) die "unknown manifest line type: $type" ;;
  esac
done

[ "$seen_anchor" -eq 1 ] || die "no ANCHOR line"
printf 'SAFE off=%s gen=%s seq=%s chain=%s meta_root=%s rec=%s meta=%s data=%s dup=%s forged=%s gap=%s\n' \
  "$safe_off" "$safe_gen" "$safe_seq" "$safe_chain" "$safe_meta" \
  "$n_rec" "$n_meta" "$n_data" "$n_dup" "$n_forged" "$n_gap"
if [ "$safe_off" -gt "$anchor_off" ]; then exit 0; fi
exit 3

3.2 Producing the manifest from a real stream

The reconciler consumes a manifest; the adapter that produces it must be the only component allowed to touch raw bytes, and must obey this contract:

  1. Inventory commands read-only. btrfs receive --dump -f stream.bin <mnt> (or an equivalent stream walker) enumerates SUBVOL/SNAPSHOT/WRITE/CLONE/… commands without applying them. Record off (running byte offset), cmd, and kind.
  2. Content digest. For each data command store dgst = SHA256(payload) (or the kernel's extent digest); for metadata store dgst = SHA256(command body). Never store the payload.
  3. Sequence/generation. The adapter assigns seq from the receiver's monotonic log and gen from wrap detection; the verifier re-derives gen anyway, so a lying adapter cannot force a wrap.
  4. Parent roots. On SUBVOL/SNAPSHOT, read the receiver's Received UUID / Parent UUID via btrfs subvolume show; do not trust the bytes in the stream as authoritative.
  5. Checkpoints. After the receiver fsync()s data, metadata, and the checkpoint record, append CKPT … durable=1. Before that, durable=0.

Resume itself is deliberately out of scope for the verifier: because a btrfs stream is not seekable, the safe action is to re-drive from the metadata-consistent parent snapshot, i.e. btrfs send -p <parent-ro> <ro> | btrfs receive <dest>. The verifier's job is to tell you which parent is provably durable and to forbid over-ack.

4. Why it is safe (proof sketch)

Let V be the reconciler, O its output offset.

Theorem 1 (no over-acknowledgement). O implies every stream byte in [0, O) was applied and fsynced by the receiver.

Proof. safe_off is assigned in exactly two places: the ANCHOR line and the CKPT branch (safe_off=$c_off). In the CKPT branch the guard requires c_durable = 1, c_chain = cur_chain, c_meta = cur_meta, c_seq = cur_seq, and an eligibility condition. By the receiver contract, durable=1 is written only after fsync of data, metadata, and the checkpoint record, so at that instant [0, c_off) is on stable storage. Hence O ∈ {anchor_off} ∪ {c_off : c durable} and every such c_off is durable. No other code path mutates safe_off. ∎

Theorem 2 (forgery resistance). If the fragments contain a forged parent transition, no checkpoint after it is accepted.

Proof. A SNAPSHOT record is rejected locally unless parent == cur_root, where cur_root is the SHA-256-bound accumulator of all prior authenticated transitions. Even if an adversary constructs a transition that satisfies the local check, chain and meta_root both include parent, cmd, and dgst under SHA-256. To have a later CKPT accepted, the adversary must produce a (chain, meta_root) pair equal to the trusted checkpoint's value, i.e. a SHA-256 second preimage under a domain-separated prefix ("C|"/"M|"), which is infeasible. ∎

Theorem 3 (wrap safety). A u32 sequence wrap cannot cause a stale record to advance the frontier.

Proof. The verifier never reads a wire generation. It computes expected = (cur_seq + 1) mod 2^32 and advances gen exactly when seq = 0xFFFFFFFF. serial_before(a,b) = ((b-a) mod 2^32) < 2^31 classifies an old record as serial-before expected, so it is counted as a duplicate and ignored; only seq == expected advances. A checkpoint with a stale seq, chain, or meta_root fails the equality guard. ∎

Theorem 4 (bounded memory). Resident memory is independent of stream length.

Proof. Live state is a fixed set of scalars plus the dedup map/ring, whose size is capped at WINDOW; the metadata budget is capped at MAX_META, and exceeding it is fail-closed (break). No command payload, record, or history is retained. ∎

Maximality. O is the highest eligible checkpoint the fragments can reach. The walk stops at the first CRC/byte/sequence gap or forgery because the chain past that point cannot be reconstructed, so no larger checkpoint is authenticatable. Replayable data after the barrier is simply re-applied, which is why a data-only checkpoint is admissible when cur_meta == barrier_meta.

6. Operational runbook

  1. Freeze the receiver and copy out the raw stream fragments and the checkpoint DB. Never let the adapter write to the live subvolume.
  2. Build the manifest per §3.2. Every WRITE/CLONE contributes only a digest; metadata contributes command + digest; checkpoint records come from the receiver's fsynced DB.
  3. Reconcile: bash reconcile.sh < manifest. Read SAFE off=…. Exit 3 means stay at the anchor; exit 64 means the manifest is untrustworthy — do not resume.
  4. Resume from the proven parent snapshot, not from a byte offset: btrfs send -p <parent-ro> <ro> | btrfs receive <dest>. Use the SAFE checkpoint's barrier as the parent root.
  5. Re-verify with btrfs subvolume show (Received UUID / Parent UUID) and re-run against the new checkpoint DB.

One-line safety rule: the verifier may only ever move the resume point to a checkpoint whose SHA-256 chain it just recomputed and whose durable bit the receiver set after fsync — anything else is reported as fail-closed.
