GAP-050 — Silencing PyBoy native boot spam via log_level="ERROR"

Repo: wojons/ai_plays_poke · Fix commit: e92198b · PyBoy: 2.7.0 · Wrapper: src/core/emulator.py

Root cause

PyBoy 2.7.0 does not use the stdlib logging module, so logging.getLogger("PyBoy").setLevel(logging.ERROR) is inert:

  • pyboy/core/mb.py:20 → logger = pyboy.logging.get_logger(__name__) — logger names are pyboy.core.mb, not PyBoy.
  • pyboy/logging/__init__.py:9 → package-wide module global _log_level = WARNING; _log() filters on it and print()s directly (no stdlib handlers).
  • pyboy/pyboy.py:74 → default "log_level": "WARNING".
  • pyboy/pyboy.py:158 → _log_level(log_level) runs inside PyBoy.__init__.

Because the level is a global re-applied on every construction, the only reliable place to set it is the PyBoy(...) call itself — and it must be set on all construction sites, including the reset() re-boot path (which otherwise reverts it to WARNING).

Citation caveat: the historical strings Special Game Boy color command / Unknown SGB packet sent are not present in the 2.7.0 wheel (verified: grep -rni sgb --include=*.py finds only an unrelated comment in cpu.py:128; strings pyboy/core/*.so finds nothing). So no emitter file:line is possible on this version; the fix targets the grep-verifiable constructor mechanism instead.

Exact fix

--- a/src/core/emulator.py
+++ b/src/core/emulator.py
@@ -8,6 +8,10 @@
 from pyboy import PyBoy as _PyBoy
 from pyboy.utils import WindowEvent

+# PyBoy 2.7 uses a package-wide custom logger and resets it from this
+# constructor option on every boot. Keep ERRORs visible while filtering SGB chatter.
+_PYBOY_LOG_LEVEL = "ERROR"
+
@@ -81,7 +85,12 @@ class Emulator:
-        self._pyboy: _PyBoy = _PyBoy(str(rom_path), window="null", sound=False)
+        self._pyboy: _PyBoy = _PyBoy(
+            str(rom_path),
+            window="null",
+            sound=False,
+            log_level=_PYBOY_LOG_LEVEL,
+        )
@@ -321,7 +330,9 @@ class Emulator:
     def reset(self) -> None:
         """Reset the emulator to its initial state."""
         self._pyboy.stop()
-        self._pyboy = _PyBoy(str(self._rom_path), window="null")
+        self._pyboy = _PyBoy(
+            str(self._rom_path), window="null", log_level=_PYBOY_LOG_LEVEL
+        )
         self._running = True

"ERROR" keeps genuine error()/critical() records; only debug/info/warning chatter is filtered. Use "CRITICAL"/"DISABLE" only if errors must also be hidden.

Verification

Regression test tests/test_emulator_pyboy_logging.py patches the wrapper's _PyBoy symbol, models PyBoy's constructor-time application (log_level(kwargs["log_level"])), and asserts both boot paths receive log_level="ERROR" plus that an INFO SGB record is filtered.

# POST-FIX — both pass
PYTHONPATH=/tmp/repo /tmp/venv314/bin/python -m pytest tests/test_emulator_pyboy_logging.py -q
# => 2 passed

# PRE-FIX falsification (restore parent of e92198b, keep test file)

# => 2 failed: KeyError: 'log_level'  (constructor called without the kwarg)

Live boot check (real PyBoy, 30 ticks, output captured):

import io, contextlib
from pathlib import Path
from src.core.emulator import Emulator

buf = io.StringIO()
with contextlib.redirect_stdout(buf), contextlib.redirect_stderr(buf):
    emu = Emulator(Path("pyboy/default_rom.gb"))
    for _ in range(30):
        emu.tick()
    emu.stop()
print("native lines:", len(buf.getvalue().splitlines()))
# => native lines: 0
