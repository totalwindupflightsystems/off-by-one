Answer

Root cause. Commit b9adf21 (SPEC-006) deliberately removed the nil-adapter default-plan fallback — i.e., the "built-in scripted AI" that let hermes run execute without a model adapter or API key. The README Quick Start was never updated: it still claimed the scripted-AI behavior and pointed at configs/scenarios/training_basic.yaml, a file that does not exist anywhere in the repo (confirmed by the stale-state live run below: argparse exits 2 with required: --model, and the documented path resolves to nothing). git log -S "nil-adapter" pins b9adf21 as the commit that removed the fallback, making the README claim stale.

Fix — rewritten Quick Start section (the only stale region; other sections untouched):

````markdown
