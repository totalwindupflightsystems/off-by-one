hermes-chat-worker-dispatch-empty-log-worker-alive

Class: a live background hermes chat -q <brief> … -Q worker is killed and re-dispatched because its log contains only Warning: Unknown toolsets: chrome_profiles.

Verified: 2026-10-28, coding-hermes/auger, AUG-117 — worker pid 40740 was alive for 42 min, had already written the complete teardown fix + 3 regression tests (tests/conftest.py, tests/test_auger.py), and was running its own verification gate (a long-lived child pytest holding /tmp/auger-pytest-substrate.lock) when the foreman read the empty log as a failed dispatch and killed it.

1. Root-cause analysis

  1. -Q (quiet) suppresses stdout until the agent finishes. During the run hermes chat emits no stdout. The only early line, Warning: Unknown toolsets: chrome_profiles, goes to stderr, which tee passes through immediately. Result: a log "stuck" at one warning line while the worker is alive and working.
  2. The foreman used "log is empty / not growing" as a liveness test. Invalid for -Q chat workers; silence is the normal steady state, not a failure signal.
  3. The worker's own gate is long. Under load the child pytest runs 15–20+ minutes and holds /tmp/auger-pytest-substrate.lock. Any concurrent gate run (including the foreman's) also stalls on that lock, reinforcing the illusion that the worker is hung.
  4. Empty log + stalled lock ⇒ "dead" ⇒ kill + re-dispatch. The duplicate dispatch then races the original worker on the same worktree.

The bug is a dispatch/discipline bug, not a bug in the worker. The in-repo AUG-117 change also hardened the lock so a long-held lock cannot hang a gate indefinitely.

2. Fix

Layer What it fixes
A. Foreman liveness guard + SOP Stops the wrong decision (kill/re-dispatch) at the source.
B. Dispatch heartbeat wrapper Removes the empty-log symptom entirely.
C. Bounded substrate lock (tests/conftest.py) + regression tests A long-held lock can no longer hang a concurrent gate.

A. Foreman liveness guard

Never re-dispatch on log size. Classify with the process tree, the worktree diff, and the lock holder. Save as bin/hermes-worker-alive.sh:

#!/usr/bin/env bash
# bin/hermes-worker-alive.sh
# Classify a background `hermes chat -q ... -Q` dispatch as ALIVE / DEAD
# by inspecting the process, its children, the worktree diff, and the
# pytest substrate lock -- NOT by the size of the worker log.
#
# Usage:  hermes-worker-alive.sh <pid> [worktree]
# Exit:   0 = ALIVE (poll or take over; never kill/re-dispatch)
#         1 = DEAD  (safe to re-dispatch)
#         2 = usage error
set -uo pipefail

pid="${1:-}"
worktree="${2:-$PWD}"
lock="${AUGER_SUBSTRATE_LOCK:-/tmp/auger-pytest-substrate.lock}"

if [[ -z "$pid" ]]; then
  echo "usage: $0 <pid> [worktree]" >&2
  exit 2
fi

# 1. Does the pid exist at all?
if ! kill -0 "$pid" 2>/dev/null; then
  echo "DEAD pid=$pid not running"
  exit 1
fi

# 2. Guard against pid reuse: the cmdline must still be a hermes chat worker.
cmd="$(tr '\0' ' ' < "/proc/$pid/cmdline" 2>/dev/null | sed 's/[[:space:]]*$//')"
case "$cmd" in
  *"hermes chat"*) : ;;
  *) echo "DEAD pid=$pid reused by: ${cmd:-<unreadable>}"; exit 1 ;;
esac

# 3. Long-lived child pytest = the worker is running its own verification gate.
children="$(ps -o pid=,etime=,cmd= --ppid "$pid" 2>/dev/null || true)"

# 4. Who holds the substrate lock (possibly another live worker's gate)?
holders=""
if command -v fuser >/dev/null 2>&1; then
  holders="$(fuser "$lock" 2>/dev/null || true)"
elif command -v lsof >/dev/null 2>&1; then
  holders="$(lsof -t "$lock" 2>/dev/null || true)"
fi

# 5. Is the worktree diff growing? An editing worker is mid-task, not dead.
before_n="$(git -C "$worktree" status --porcelain 2>/dev/null | wc -l)"
before_s="$(git -C "$worktree" diff --stat 2>/dev/null | tail -1)"
sleep "${PROBE_SECONDS:-10}"
after_n="$(git -C "$worktree" status --porcelain 2>/dev/null | wc -l)"
after_s="$(git -C "$worktree" diff --stat 2>/dev/null | tail -1)"

echo "ALIVE pid=$pid"
echo "  cmd            : $cmd"
echo "  children       : ${children:-none}"
echo "  lock holders   : ${holders:-none}"
echo "  porcelain files: $before_n -> $after_n"
echo "  diffstat       : ${before_s:-<clean>} -> ${after_s:-<clean>}"
exit 0

Foreman SOP before any kill/re-dispatch:

# 1. Full cmdline exposes brief + model/provider; identify the real worker.
ps aux | grep '[h]ermes chat'

# 2. The worktree, not the log, tells you if work is happening.
git -C "$WORKTREE" status --porcelain
git -C "$WORKTREE" diff --stat

# 3. A held lock is a running gate, not a hung worker.
fuser -v /tmp/auger-pytest-substrate.lock   # or: lsof /tmp/auger-pytest-substrate.lock

# 4. Classify, then decide.
bin/hermes-worker-alive.sh "$WORKER_PID" "$WORKTREE"

Decision table

Guard result Evidence Action
ALIVE cmdline is hermes chat, child pytest present, diff present/growing Do not kill, do not re-dispatch. Poll, or take over the uncommitted diff.
ALIVE lock held by another gate Wait for the lock; the other gate is a live peer.
DEAD not running Safe to re-dispatch.
DEAD reused by: <other cmd> pid was recycled; re-dispatch.

Taking over (when the worker is alive but you choose not to wait): treat the uncommitted diff as truth — read it, check acceptance criteria, run the gate, commit with the repo's standard identity:

git -C "$WORKTREE" diff -- tests/conftest.py tests/test_auger.py
git -C "$WORKTREE" add tests/conftest.py tests/test_auger.py
git -C "$WORKTREE" commit -m "AUG-117: fix teardown + substrate lock hardening"

B. Dispatch heartbeat wrapper

Save as bin/hermes-dispatch.sh:

#!/usr/bin/env bash
# bin/hermes-dispatch.sh
# Background dispatch that always emits a heartbeat, so the foreman never
# has to infer liveness from silence.
#
# Usage:  hermes-dispatch.sh <logfile> -- <hermes args...>
# Example:
#   nohup bin/hermes-dispatch.sh logs/AUG-117.log -- \
#     hermes chat -q "AUG-117 teardown fix" --model ... -Q &
set -uo pipefail

log="${1:?usage: hermes-dispatch.sh <logfile> -- <command...>}"
shift
[[ "${1:-}" == "--" ]] && shift
[[ $# -gt 0 ]] || { echo "no command given" >&2; exit 2; }

mkdir -p "$(dirname "$log")"
heartbeat="${HEARTBEAT_SECONDS:-30}"

{ echo "DISPATCH $(date -Is) pid=$$ cmd=$*"; } >> "$log"

stdbuf -oL -eL "$@" >>"$log" 2>&1 &
worker=$!
echo "$worker" > "${log}.pid"
echo "WORKER $(date -Is) pid=$worker" >> "$log"

while kill -0 "$worker" 2>/dev/null; do
  sleep "$heartbeat"
  kill -0 "$worker" 2>/dev/null || break
  echo "HEARTBEAT $(date -Is) worker=$worker alive" >> "$log"
done

wait "$worker"
rc=$?
echo "EXIT $(date -Is) worker=$worker rc=$rc" >> "$log"
exit "$rc"

A log not advanced past its first line for longer than HEARTBEAT_SECONDS is now a genuine signal.

C. Bounded substrate lock + regression tests

tests/conftest.py — bounded acquisition, holder diagnostics, guaranteed release (the AUG-117 teardown fix):

# tests/conftest.py
"""Shared fixtures for the auger test suite.

AUG-117: bounded, observable substrate-lock acquisition.  Historically the
session-scoped substrate fixture waited forever on
/tmp/auger-pytest-substrate.lock.  A live worker's long-lived child pytest
(15-20+ min under load) held that lock, so a concurrent gate appeared stuck
and a live worker was killed.  Acquisition now raises SubstrateLockTimeout
(naming the holder) instead of blocking forever, and the lock is always
released in a finally block.
"""
from __future__ import annotations

import fcntl
import os
import time
from pathlib import Path

import pytest

LOCK_PATH = Path(
    os.environ.get("AUGER_SUBSTRATE_LOCK", "/tmp/auger-pytest-substrate.lock")
)
LOCK_TIMEOUT = float(os.environ.get("AUGER_SUBSTRATE_LOCK_TIMEOUT", "1800"))
LOCK_POLL = float(os.environ.get("AUGER_SUBSTRATE_LOCK_POLL", "1.0"))


class SubstrateLockTimeout(RuntimeError):
    """Raised when the substrate lock cannot be acquired within LOCK_TIMEOUT."""


def lock_holder(path: Path = LOCK_PATH) -> str:
    """Best-effort description of the current lock holder, for diagnostics."""
    try:
        raw = path.read_text().strip()
    except OSError:
        return "unknown"
    if not raw:
        return "unknown"
    try:
        pid = int(raw)
        os.kill(pid, 0)
    except ProcessLookupError:
        return f"{raw} (stale)"
    except ValueError:
        return raw
    except PermissionError:
        return f"{raw} (alive, other user)"
    return raw


def acquire_substrate_lock(path: Path = LOCK_PATH, timeout: float = LOCK_TIMEOUT,
                           poll: float = LOCK_POLL) -> int:
    """Acquire an exclusive flock, bounded by ``timeout`` seconds."""
    path.parent.mkdir(parents=True, exist_ok=True)
    fd = os.open(path, os.O_CREAT | os.O_RDWR, 0o644)
    try:
        deadline = time.monotonic() + timeout
        while True:
            try:
                fcntl.flock(fd, fcntl.LOCK_EX | fcntl.LOCK_NB)
                break
            except BlockingIOError:
                if time.monotonic() >= deadline:
                    raise SubstrateLockTimeout(
                        f"substrate lock {path} still held by pid "
                        f"{lock_holder(path)} after {timeout:.0f}s; "
                        "another gate/worker is running"
                    ) from None
                time.sleep(poll)
        os.ftruncate(fd, 0)
        os.write(fd, f"{os.getpid()}\n".encode())
        return fd
    except BaseException:
        os.close(fd)
        raise


def release_substrate_lock(fd: int) -> None:
    try:
        fcntl.flock(fd, fcntl.LOCK_UN)
    finally:
        os.close(fd)


@pytest.fixture(scope="session")
def substrate_lock():
    fd = acquire_substrate_lock()
    try:
        yield LOCK_PATH
    finally:
        release_substrate_lock(fd)


# Backwards-compatible alias for tests that still request ``substrate``.
substrate = substrate_lock

tests/test_auger.py — the 3 regression tests:

# tests/test_auger.py
"""AUG-117 regression tests for the substrate lock."""
from __future__ import annotations

import os
import subprocess
import sys
import time

import pytest

from conftest import (
    SubstrateLockTimeout,
    acquire_substrate_lock,
    lock_holder,
    release_substrate_lock,
)

# Child that grabs the lock and holds it for 60s, like a real gate child.
_HOLD_LOCK = (
    "import fcntl, os, sys, time\n"
    "path = sys.argv[1]\n"
    "fd = os.open(path, os.O_CREAT | os.O_RDWR, 0o644)\n"
    "fcntl.flock(fd, fcntl.LOCK_EX)\n"
    "os.ftruncate(fd, 0)\n"
    "os.write(fd, str(os.getpid()).encode())\n"
    "print('locked', flush=True)\n"
    "time.sleep(60)\n"
)

# Child that grabs the lock and immediately exits.
_GRAB_AND_EXIT = (
    "import fcntl, os, sys\n"
    "path = sys.argv[1]\n"
    "fd = os.open(path, os.O_CREAT | os.O_RDWR, 0o644)\n"
    "fcntl.flock(fd, fcntl.LOCK_EX)\n"
    "os.write(fd, str(os.getpid()).encode())\n"
)


def _spawn(code: str, lock: str) -> subprocess.Popen:
    return subprocess.Popen([sys.executable, "-c", code, lock])


def test_lock_is_released_when_holder_process_exits(tmp_path):
    """A finished gate must not wedge the next one."""
    lock = tmp_path / "substrate.lock"
    child = _spawn(_GRAB_AND_EXIT, str(lock))
    assert child.wait(timeout=10) == 0

    fd = acquire_substrate_lock(path=lock, timeout=2)
    try:
        assert lock_holder(lock) != "unknown"
    finally:
        release_substrate_lock(fd)


def test_lock_contention_times_out_instead_of_hanging(tmp_path):
    """A second gate is bounded, not blocked forever."""
    lock = tmp_path / "substrate.lock"
    fd = acquire_substrate_lock(path=lock, timeout=2)
    try:
        with pytest.raises(SubstrateLockTimeout) as exc:
            acquire_substrate_lock(path=lock, timeout=0.5, poll=0.05)
        assert "still held by pid" in str(exc.value)
    finally:
        release_substrate_lock(fd)


def test_long_lived_child_recovers_after_being_reaped(tmp_path):
    """The exact 15-20 min child-pytest scenario."""
    lock = tmp_path / "substrate.lock"
    child = _spawn(_HOLD_LOCK, str(lock))
    try:
        deadline = time.monotonic() + 5
        while time.monotonic() < deadline and lock_holder(lock) == "unknown":
            time.sleep(0.05)
        assert lock_holder(lock) not in ("unknown", "")
        with pytest.raises(SubstrateLockTimeout):
            acquire_substrate_lock(path=lock, timeout=0.5, poll=0.05)
    finally:
        child.kill()
        child.wait(timeout=10)

    fd = acquire_substrate_lock(path=lock, timeout=5)
    try:
        assert lock_holder(lock) == str(os.getpid())
    finally:
        release_substrate_lock(fd)

4. One-line rule

An empty worker log is not a dead worker. Before re-dispatching: ps the cmdline, git status the worktree, fuser the substrate lock — then decide. If it is alive and producing a diff, poll it or take over the uncommitted diff; never kill and re-dispatch.
