The fix is verified and documented. Summary:

Diagnosis

pkg/agent/ai_agent_real_model_test.go gates its live-model subtests only on OPENROUTER_API_KEY presence. With a key set (common on dev machines/CI), the subtests invoked openai/gpt-4o-mini and anthropic/claude-3.5-haiku — models absent from the pkg/harness registry. The adapter rejects them with a non-retryable VALIDATION_ERROR before any I/O, but the agent retry loop retried it anyway (3 × 4s), producing the ~24s hard FAIL on clean checkouts. Three gaps: wrong test gate, no registry lookup exposed to tests, and a retry loop that sleeps on errors that can never succeed.

Solution (/workspace/KM-GAP-047-solution.md, self-contained)

  • Layer A: pkg/harness — expose HasModel(id) + RegisteredModelIDs().
  • Layer B (the fix): gate each subtest on both the key and registry membership; unregistered models → t.Skipf with a reason naming the model and the registered set (so the registry drift becomes visible, not a red build).
  • Layer C: new ai_agent_offline_test.go with a stub adapter so token-tracking asserts run without network/key/registry.
  • Layer D (hardening): ErrModelNotFound becomes non-retryable → the agent fails fast instead of burning 24s, covering any unguarded caller.

Verification (Go 1.26, faithful structural sim at /tmp/km-sim)

  • Before (reproduced): key set, no registry gate → FAIL (16.01s), exact report error string model anthropic/claude-3.5-haiku not found in registry (VALIDATION_ERROR, non-retryable) (24.01s in production with per-attempt overhead).
  • After, full matrix:
  • key unset → SKIP, ok 0.003s
  • key set, model not in registry → SKIP with clear reason, ok 0.007s (was FAIL 16–24s)
  • key set, model registered → subtest runs, token-tracking assert passes (81 tokens)
  • stub suite (token tracking, fail-fast on validation error, transient retry) → PASS, also clean under -race
  • All 5 Go code blocks in the markdown pass gofmt -e syntax validation.

One real follow-up surfaced: gpt-4o-mini and claude-3.5-haiku are simply not registered — provision them or remove them from realModelCases; the new skip text tracks it as visible debt.
