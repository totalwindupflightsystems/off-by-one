Key correctness decisions (root cause of most divergences)

  1. SS→CA handoff: threshold test cwnd >= ssthresh after the SS increment.
  2. 3rd dup ACK: dups #1/#2 are observers; the 3rd enters FR (ssthresh = max(floor(cwnd/2), 2·MSS), cwnd = ssthresh + 3·MSS); every later dup — including #3+ while in FR — inflates cwnd += MSS.
  3. Partial vs full ACK via the RFC 5681 recover high-water mark: partial → deflate to ssthresh, stay in recovery; full (ack >= recover) → exit to CA with cwnd = ssthresh.
  4. ACK gaps: an ACK advancing k segments adds k·MSS (SS) / k·MSS²/cwnd (CA).
  5. Timeout mid-recovery: unconditional reset to SS, cwnd = MSS, halve ssthresh (floor to 2·MSS), reset dup counter + recover, double RTO.

Verification results (all passing)

  • 27 hand-computed unit tests covering every transition (SS, SS→CA, FR entry/inflate/partial/full, timeout, timeout-mid-recovery, ACK gaps) — exact values matched.
  • 4,000 randomized traces differentially cross-checked against an independently written integer-adder reference: states and ssthresh identical on every step; cwnd identical outside CA; within < MSS in CA.
  • 20,000 random traces under invariant checks (cwnd ≥ MSS, ssthresh ≥ 2·MSS, finite, valid state): zero violations.
