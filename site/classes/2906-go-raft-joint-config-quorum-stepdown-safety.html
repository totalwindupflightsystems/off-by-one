Safe Joint-Consensus Commit, Step-Down, and Append Handling

A complete runnable reference implementation and tests are in:

Root cause

The unsafe behavior comes from treating the new configuration as an ordinary latest-value update instead of a two-phase joint-consensus state machine:

  1. Quorum logic used a bare majority. A joint configuration must require a majority of C_old and a majority of C_new. Counting only a C_new majority, or a majority of the union, allows commitIndex to advance while the joint entry is still uncommitted/unapplied on an old majority.
  2. The active configuration switched too early. If C_new becomes active merely because it was appended, or because the joint entry was applied locally, the leader can stop consulting C_old before C_new is committed. Losing all C_old voters must stop commits and leadership—not trigger a campaign under C_new alone.
  3. AppendEntries mutated the log before validating configuration order. A normal Raft conflict truncates the log suffix. A stale C_new-only entry from an older term can therefore delete a newer local joint entry. Configuration conflicts must be rejected before any truncation occurs.
  4. Election, step-down/check-quorum, and leadership transfer did not all use the same joint-aware configuration. They must share the same active configuration and require both old and new majorities until the transition is safely complete.

Exact fix

1. Joint quorum requires both majorities

func (c Config) Quorum(acks map[string]bool) bool {
    if c.Joint {
        return hasMajority(c.Old, acks) && hasMajority(c.New, acks)
    }
    return hasMajority(c.New, acks)
}

2. Gate activation of the final C_new

The joint entry is active as soon as it is in the log. The final C_new is not used for quorum decisions until that final entry is committed. Until then, the preceding joint configuration remains active.

func (r *Replica) ActiveConfig() Config {
    cfg, idx := r.latestConfigAtOrBefore(r.lastIndex())
    if idx == 0 {
        return copyConfig(r.Bootstrap)
    }
    if !cfg.Joint && idx > r.CommitIndex {
        prev, prevIdx := r.latestConfigBefore(idx)
        if prevIdx > 0 && prev.Joint {
            return copyConfig(prev)
        }
    }
    return copyConfig(cfg)
}

This ensures that while the joint entry is unapplied on a majority—and even after it is applied but before final C_new is committed—no decision can use a bare C_new majority.

3. Commit, step-down, campaign, and transfer all use ActiveConfig

func (r *Replica) AdvanceCommit(match map[string]uint64) (uint64, bool) {
    if r.Role != Leader {
        return r.CommitIndex, false
    }
    cfg := r.ActiveConfig()
    for n := r.lastIndex(); n > r.CommitIndex; n-- {
        if r.Log[n].Term != r.CurrentTerm {
            continue // only current-term entries are committed by counting
        }
        acks := make(map[string]bool, len(match)+1)
        acks[r.ID] = true
        for id, m := range match {
            if m >= n {
                acks[id] = true
            }
        }
        if cfg.Quorum(acks) {
            r.CommitIndex = n
            return n, true
        }
    }
    return r.CommitIndex, false
}

func (r *Replica) CheckQuorum(reachable map[string]bool) bool {
    if r.Role != Leader {
        return false
    }
    if !r.ActiveConfig().Quorum(reachable) {
        r.becomeFollower(r.CurrentTerm, "")
        return false
    }
    return true
}

func (r *Replica) Campaign(votes map[string]bool) bool {
    cfg := r.ActiveConfig()
    if !cfg.Contains(r.ID) {
        r.Role = Follower
        return false
    }
    if !cfg.Quorum(votes) {
        r.Role = Candidate
        return false
    }
    r.Role = Leader
    r.LeaderID = r.ID
    return true
}

func (r *Replica) CanTransferTo(target string) bool {
    return r.Role == Leader && r.ActiveConfig().Contains(target)
}

During a joint configuration, Contains requires the transfer target to be in both C_old and C_new, so leadership cannot be transferred to a C_new-only replica.

4. Reject stale configuration entries before truncating the log

AppendEntries builds a candidate log on a copy, validates the complete configuration sequence, and only then assigns it. A stale config entry that would overwrite or truncate a newer config entry is rejected.

candidate := append([]Entry(nil), r.Log...)
for i, in := range req.Entries {
    idx := req.PrevLogIndex + 1 + uint64(i)
    if idx < uint64(len(candidate)) {
        existing := candidate[idx]
        if existing.Term == in.Term {
            if existing.Type != in.Type ||
                (in.Type == EntryConfig && !sameConfig(existing.Cfg, in.Cfg)) {
                return false
            }
            continue
        }

        // Stale C_new at the same index as a newer joint entry.
        if in.Type == EntryConfig && existing.Type == EntryConfig &&
            in.Term < existing.Term {
            return false
        }

        // Stale C_new earlier in the log that would truncate a later, newer
        // joint/config entry.
        if in.Type == EntryConfig {
            for j := idx; j < uint64(len(candidate)); j++ {
                if candidate[j].Type == EntryConfig &&
                    candidate[j].Term > in.Term {
                    return false
                }
            }
        }
        candidate = candidate[:idx]
    }

    in.Index = idx
    candidate = append(candidate, in)
}

if err := validateConfigLog(r.Bootstrap, candidate[1:]); err != nil {
    return false
}
r.Log = candidate

The transition validator permits only:

simple(C_old) -> joint(C_old, C_new) -> simple(C_new)

It rejects naked simple -> simple transitions, nested joint entries, a joint entry whose Old does not match current members, and a final C_new whose members do not match the joint New.

5. Do not append final C_new before joint commit

func (r *Replica) ProposeFinal() error {
    if r.Role != Leader {
        return ErrNotLeader
    }
    cur, idx := r.latestConfigAtOrBefore(r.lastIndex())
    if idx == 0 || !cur.Joint {
        return fmt.Errorf("%w: not in a joint configuration", ErrBadTransition)
    }
    if idx > r.CommitIndex {
        return ErrJointNotCommitted
    }
    return r.appendConfigLocked(Simple(cur.New...))
}
