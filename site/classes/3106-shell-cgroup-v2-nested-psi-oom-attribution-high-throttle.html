Diagnosis

The naive auditor has four independent defects; fixing any one alone still yields wrong answers:

  1. memory.psi does not exist in cgroup v2. PSI is memory.pressure; its total= field is cumulative microseconds. Absolute reads always favor the oldest cgroup, so a window delta is mandatory.
  2. memory.events is hierarchical, memory.events.local is not. A parent accumulates its whole subtree, so reading .events blames the parent. Confirmed in /usr/src/linux-headers-*/include/linux/memcontrol.h (memory_events vs memory_events_local).
  3. memory.current is not blameworthy. Page cache (stat file) and shmem (stat shmem) are reclaimable, so summing raw current crowns the byte-hog rather than the cgroup under pressure.
  4. PSI is also hierarchical (struct psi_group has parent in psi_types.h). Every ancestor of the victim shows a positive delta, so the tool must descend to the deepest node with positive some delta that has no positive-delta descendant.
  5. Ties must be refused with a non-zero exit and an explicit message.

Fix

cgroup-victim-audit.sh walks the tree, snapshots twice, and:

  • parses memory.pressure some/full as microseconds and uses deltas;
  • uses memory.events.local for hard-event attribution;
  • finds the deepest PSI pressure-origin, ranks by some delta, not bytes;
  • reports memory.current - file - shmem as reclaim= in --verbose;
  • exits 3 with ambiguous victim: /A,/B all tie at … usec on a tie.

Supports live sampling (--root, --window) and deterministic offline analysis (--before/--after, --emit-snapshot), plus --mode auto|high|oom, --threshold, --quiet.

Verification

  • test-victim-audit.sh: 12 scripted trees (threaded subtree, delegated subtree, parent-throttled/quiet-children, OOM hierarchical trap, deep nesting, shmem trap, tie, mode selection) → 13 passed, 0 failed.
  • demo-traps.sh reproduces each naive failure: missing memory.psi, parent's hierarchical event vs child's local event, and absolute-total 7000 wrongly blaming /A where the delta correctly names /A/B/C.
  • Tie case verified to print the explicit ambiguity message and exit 3.
