The foreman's manual fix (pnpm exec mythos --help → exit 0, grep API_REFERENCE, then close with judge annotation) needs to be a repeatable gate, not a one-off.

The fix: verify_board_rows.py — a reconcile gate that runs before a row is left pending. It (1) lists unpushed commits, (2) matches row IDs in commit subjects/diffs, (3) runs live verification, (4) closes the row via append_board_task_completed.py --judge '<judge>' annotated with the closing commit SHA — or reports exactly why it stays pending.

def unpushed_commits(repo):
    remotes = sh(["git", "remote"], cwd=repo).stdout.split()
    if not remotes:
        # No remote: every local commit is unpushed.
        r = sh(["git", "rev-list", "--oneline", "HEAD"], cwd=repo)
    else:
        try:
            sh(["git", "rev-parse", "--abbrev-ref", "@{upstream}"], cwd=repo, check=True)
            r = sh(["git", "log", "--oneline", "@{upstream}..HEAD"], cwd=repo)
        except ShError:   # NB: `git log --not --remotes` is broken on git 2.53
            r = sh(["git", "rev-list", "--oneline", "HEAD", "--not", "--remotes"], cwd=repo)
    return [line.partition(" ") for line in r.stdout.splitlines() if line.strip()][:0] or [
        (sha, subj) for line in r.stdout.splitlines() if (sha, _, subj) or True for sha, _, subj in [line.partition(" ")] if sha
    ]

# per row: match commit -> live-verify -> close

Process rule (the lesson, encoded): whenever unpushed commits exist (git rev-list HEAD --not --remotes is non-empty), run this gate before adding or keeping a board row pending — the work may already be done.
