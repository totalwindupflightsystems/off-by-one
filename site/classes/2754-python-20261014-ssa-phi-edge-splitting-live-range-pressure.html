SSA φ-Edge Splitting with Minimal Splits, Dominance-Proof Certificates, and Interference-Cost Pressure

Problem class: python-20261014-ssa-phi-edge-splitting-live-range-pressure Environment: python3.11+ (verified CPython 3.14.4), no third-party deps.

1. Root-cause analysis

The pass must keep five invariants simultaneously; each has a distinct failure mode.

RC-1 — Critical edges are the only legal home for an edge copy, but not every edge is splittable. A φ repair copy must execute on exactly one incoming edge. On a critical edge (|succ(src)| > 1 and |pred(dst)| > 1) it cannot go in src (runs on the other successors) nor in dst (runs for the other predecessors). The only legal fix is to split src -> S -> dst and copy in S. Splitting every critical edge is legal but inflates pressure, so split only the critical edges that actually carry a φ operand — the unique minimum.

RC-2 — Dominance must not assume reducibility. Irreducible loops (two entry edges into the same loop, no unique header/preheader) break passes that compute dominance via loop nesting. Compute dom(entry)={entry}, dom(b)={b} ∪ ⋂_{p∈pred(b)} dom(p) as a pure fixed point. The reference uses this as the producer, and an independent brute-force reachability test as the checker, so dominance is never trusted from one algorithm.

RC-3 — Lost-copy / swap. Mutually recursive φs (x=φ(p0,y), y=φ(q0,x)) need a parallel copy (x,y)<-(y,x) on the back edge; sequentialization clobbers a source. Fix: give every split-edge destination a fresh SSA name (x.split0, y.split0); the copies become independent.

RC-4 — Exceptional edges cannot be split. If a critical exception edge carries a φ operand, put the copy at the end of the source block (before the throwing terminator). Every outgoing edge of the source, including the exception edge, then sees the repaired value.

RC-5 — Provenance and pressure. Each new value must keep a lineage link to the original value + source location (debug_lossless). Each copy adds a live range, so the pass reports peak pressure and target-weighted interference before/after plus a Chaitin–Briggs spill estimate.

Concrete bugs found and fixed during development: split_edge returned a Block where an int id was needed; verify kept one predecessor seen set per block instead of per φ; after splitting, operands point at the new block S but the copy materializer looked up the old (src,dst) key, so no copy was inserted (fixed by inverting split_map to S -> (src,dst)); has_edge() only tested the normal kind so the exception handler never fired (added has_any_edge); split_edge unlinked src from dst.preds even when a parallel exception edge remained; the independent checker wrongly treated entry as unable to dominate.

2. Exact fix — complete reference implementation

Key algorithm (ssa_edge_split.py, full source below):

  1. compute_dominators — path-based fixed point (correct on irreducible CFGs).
  2. repair_phi_edges — for every φ operand on a normal critical edge, record (P,B), then split each edge once.
  3. Materialize copies: normal split block (copy), non-splittable exception edge (exception_copy at source-block end), vanished predecessor (landing_copy defensive).
  4. _fresh assigns a new SSA name and a provenance record {kind, parent, block, loc, edge}.
  5. emit_certificate serializes edges + rewrite log + one dominance claim per φ operand / use / copy.
  6. check_certificate rebuilds the CFG from the certificate and re-proves every claim by brute-force reachability (d dominates b iff no entry→b path avoids d).
  7. pressure / greedy_color report interference under a target CostModel.

            if y == b: return False

        if src in phi.inputs: phi.inputs[S] = phi.inputs.pop(src)
    return S

"""
SSA phi edge-splitting + repair with dominance proofs and register-pressure cost.

Reference implementation for the problem class:
    python-20261014-ssa-phi-edge-splitting-live-range-pressure
"""

from __future__ import annotations

import json
from collections import defaultdict, deque
from dataclasses import dataclass, field


NORMAL = "normal"
EXCEPTION = "exception"


@dataclass
class Phi:
    var: str
    inputs: "dict[int, str]" = field(default_factory=dict)


@dataclass
class Block:
    bid: int
    preds: "list[int]" = field(default_factory=list)
    succs: "list[int]" = field(default_factory=list)
    phis: "list[Phi]" = field(default_factory=list)
    copies: "list[tuple[str, str]]" = field(default_factory=list)
    uses: "list[str]" = field(default_factory=list)
    split_of: "tuple[int, int] | None" = None


class CFG:
    def __init__(self, entry: int = 0):
        self.entry = entry
        self.blocks: "dict[int, Block]" = {}
        self.edges: "set[tuple[int, int, str]]" = set()
        self.def_block: "dict[str, int]" = {}
        self.provenance: "dict[str, dict]" = {}
        self._next_bid = 0

    def add_block(self, bid: "int | None" = None) -> Block:
        if bid is None:
            bid = self._next_bid
        self._next_bid = max(self._next_bid, bid + 1)
        b = Block(bid)
        self.blocks[bid] = b
        return b

    def add_edge(self, src: int, dst: int, kind: str = NORMAL) -> None:
        e = (src, dst, kind)
        if e in self.edges:
            return
        self.edges.add(e)
        if dst not in self.blocks[src].succs:
            self.blocks[src].succs.append(dst)
        if src not in self.blocks[dst].preds:
            self.blocks[dst].preds.append(src)

    def add_def(self, value: str, block: int, loc: "str | None" = None,
                parent: "str | None" = None) -> None:
        self.def_block[value] = block
        self.provenance[value] = {
            "kind": "copy" if parent else "orig",
            "parent": parent,
            "block": block,
            "loc": loc,
            "edge": None,
        }

    def has_edge(self, src: int, dst: int, kind: str = NORMAL) -> bool:
        return (src, dst, kind) in self.edges

    def has_any_edge(self, src: int, dst: int) -> bool:
        return any((src, dst, k) in self.edges for k in (NORMAL, EXCEPTION))

    def edge_kind(self, src: int, dst: int) -> str:
        if (src, dst, NORMAL) in self.edges:
            return NORMAL
        if (src, dst, EXCEPTION) in self.edges:
            return EXCEPTION
        raise KeyError((src, dst))


def compute_dominators(cfg: CFG) -> "dict[int, set[int]]":
    all_b = set(cfg.blocks)
    dom = {b: set(all_b) for b in all_b}
    dom[cfg.entry] = {cfg.entry}
    changed = True
    while changed:
        changed = False
        for b in all_b:
            if b == cfg.entry:
                continue
            preds = [p for p in cfg.blocks[b].preds if p in cfg.blocks]
            if not preds:
                new = {b}
            else:
                inter = set.intersection(*(dom[p] for p in preds))
                new = inter | {b}
            if new != dom[b]:
                dom[b] = new
                changed = True
    return dom


def dominates(dom: "dict[int, set[int]]", d: int, b: int) -> bool:
    return d in dom.get(b, set())


def dominates_bruteforce(cfg: CFG, d: int, b: int) -> bool:
    if d == b:
        return True
    if d == cfg.entry:
        return True
    seen = set()
    q = deque([cfg.entry])
    seen.add(cfg.entry)
    while q:
        x = q.popleft()
        for y in cfg.blocks[x].succs:
            if y == d or y in seen:
                continue
            if y == b:
                return False
            seen.add(y)
            q.append(y)
    return True


def critical_edges(cfg: CFG) -> "list[tuple[int, int, str]]":
    out = []
    for (s, d, k) in sorted(cfg.edges):
        if len(cfg.blocks[s].succs) > 1 and len(cfg.blocks[d].preds) > 1:
            out.append((s, d, k))
    return out


def _fresh(cfg: CFG, name: str, block: int, loc, parent: str) -> str:
    n = 0
    while f"{name}.split{n}" in cfg.def_block:
        n += 1
    new = f"{name}.split{n}"
    cfg.add_def(new, block, loc=loc, parent=parent)
    cfg.provenance[new]["edge"] = None
    return new


def split_edge(cfg: CFG, src: int, dst: int) -> int:
    """Split a splittable edge src->dst, returning the new block id."""
    kind = cfg.edge_kind(src, dst)
    if kind != NORMAL:
        raise ValueError(f"cannot split non-normal edge {src}->{dst} ({kind})")
    Sblk = cfg.add_block()
    S = Sblk.bid
    Sblk.split_of = (src, dst)
    cfg.edges.discard((src, dst, NORMAL))
    cfg.add_edge(src, S, NORMAL)
    cfg.add_edge(S, dst, NORMAL)
    if not cfg.has_any_edge(src, dst):
        if src in cfg.blocks[dst].preds:
            cfg.blocks[dst].preds.remove(src)
        if dst in cfg.blocks[src].succs:
            cfg.blocks[src].succs.remove(dst)
    for phi in cfg.blocks[dst].phis:
        if src in phi.inputs:
            phi.inputs[S] = phi.inputs.pop(src)
    return S


def repair_phi_edges(cfg: CFG) -> "list[dict]":
    """Insert the minimum set of legal edge splits and repair copies."""
    log = []
    needed: "dict[tuple[int,int], set[str]]" = defaultdict(set)
    for B in cfg.blocks.values():
        for phi in B.phis:
            for P, v in phi.inputs.items():
                if not cfg.has_any_edge(P, B.bid):
                    continue
                k = cfg.edge_kind(P, B.bid)
                is_crit = len(cfg.blocks[P].succs) > 1 and len(cfg.blocks[B.bid].preds) > 1
                if k == NORMAL and is_crit:
                    needed[(P, B.bid)].add(v)

    split_map: "dict[tuple[int,int], int]" = {}
    for (P, B) in sorted(needed):
        if (P, B) in split_map:
            continue
        S = split_edge(cfg, P, B)
        split_map[(P, B)] = S
        log.append({"op": "split_edge", "src": P, "dst": B, "new_block": S})

    split_by_new = {S: (P, B) for (P, B), S in split_map.items()}
    for B in list(cfg.blocks.values()):
        for phi in B.phis:
            for P in list(phi.inputs):
                v = phi.inputs[P]
                if P in split_by_new:
                    P0, B0 = split_by_new[P]
                    loc = cfg.provenance.get(v, {}).get("loc")
                    nv = _fresh(cfg, v, P, loc, parent=v)
                    cfg.blocks[P].copies.append((nv, v))
                    cfg.provenance[nv]["edge"] = [P0, B0, NORMAL]
                    phi.inputs[P] = nv
                    log.append({"op": "copy", "dst_value": nv, "src_value": v,
                                "block": P, "edge": [P0, B0, NORMAL]})
                elif cfg.has_any_edge(P, B.bid) and cfg.edge_kind(P, B.bid) == EXCEPTION:
                    loc = cfg.provenance.get(v, {}).get("loc")
                    nv = _fresh(cfg, v, P, loc, parent=v)
                    cfg.blocks[P].copies.append((nv, v))
                    cfg.provenance[nv]["edge"] = [P, B.bid, EXCEPTION]
                    phi.inputs[P] = nv
                    log.append({"op": "exception_copy", "dst_value": nv,
                                "src_value": v, "block": P,
                                "edge": [P, B.bid, EXCEPTION]})
                elif not cfg.has_any_edge(P, B.bid):
                    loc = cfg.provenance.get(v, {}).get("loc")
                    nv = _fresh(cfg, v, B.bid, loc, parent=v)
                    cfg.blocks[B.bid].copies.append((nv, v))
                    phi.inputs[P] = nv
                    log.append({"op": "landing_copy", "dst_value": nv,
                                "src_value": v, "block": B.bid,
                                "edge": [P, B.bid, "missing"]})
    return log


class VerificationError(Exception):
    pass


def verify(cfg: CFG, brute: bool = True) -> dict:
    dom = compute_dominators(cfg)

    for B in cfg.blocks.values():
        for phi in B.phis:
            seen = set()
            for p in phi.inputs:
                if p not in B.preds:
                    raise VerificationError(
                        f"phi {phi.var} in B{B.bid} references non-pred P{p}")
                if p in seen:
                    raise VerificationError(
                        f"phi {phi.var} in B{B.bid} has duplicate pred P{p}")
                seen.add(p)

    for B in cfg.blocks.values():
        for phi in B.phis:
            for p, v in phi.inputs.items():
                if v not in cfg.def_block:
                    raise VerificationError(f"B{B.bid} phi {phi.var}: undefined {v}")
                db = cfg.def_block[v]
                if not dominates(dom, db, p):
                    raise VerificationError(
                        f"B{B.bid} phi {phi.var}: def {v}@B{db} does not dominate "
                        f"edge source P{p}")

    for B in cfg.blocks.values():
        for v in B.uses:
            if v not in cfg.def_block:
                raise VerificationError(f"B{B.bid} uses undefined {v}")
            db = cfg.def_block[v]
            if not dominates(dom, db, B.bid):
                raise VerificationError(
                    f"B{B.bid} use {v}: def@B{db} does not dominate use")

    for B in cfg.blocks.values():
        for (dst, src) in B.copies:
            if dst not in cfg.def_block or cfg.def_block[dst] != B.bid:
                raise VerificationError(
                    f"copy {dst}<-{src} in B{B.bid} not defined in B")
            if src not in cfg.def_block:
                raise VerificationError(f"copy {dst}<-{src} in B{B.bid}: undefined src")
            sb = cfg.def_block[src]
            if not dominates(dom, sb, B.bid):
                raise VerificationError(
                    f"copy {dst}<-{src} in B{B.bid}: src@B{sb} does not dominate")

    for v, rec in cfg.provenance.items():
        depth = 0
        cur = v
        loc = rec.get("loc")
        while cfg.provenance[cur]["kind"] == "copy":
            parent = cfg.provenance[cur]["parent"]
            if parent is None or parent not in cfg.provenance:
                raise VerificationError(f"broken provenance chain at {cur}")
            cur = parent
            depth += 1
            if depth > len(cfg.provenance) + 1:
                raise VerificationError(f"provenance cycle at {v}")
        if loc is not None:
            cfg.provenance[v]["debug_lossless"] = True

    if brute:
        claims = []
        for B in cfg.blocks.values():
            for phi in B.phis:
                for p, v in phi.inputs.items():
                    claims.append((cfg.def_block[v], p))
            for v in B.uses:
                claims.append((cfg.def_block[v], B.bid))
            for (dst, src) in B.copies:
                claims.append((cfg.def_block[src], B.bid))
        for (d, b) in claims:
            if dominates_bruteforce(cfg, d, b) != dominates(dom, d, b):
                raise VerificationError(
                    f"dominator algorithms disagree on d=B{d} dom b=B{b}")
    return {"blocks": len(cfg.blocks), "edges": len(cfg.edges),
            "values": len(cfg.def_block), "ok": True}


def emit_certificate(cfg: CFG, log: "list[dict]") -> str:
    claims = []
    for B in cfg.blocks.values():
        for phi in B.phis:
            for p, v in sorted(phi.inputs.items()):
                claims.append({"kind": "phi_operand", "use_value": v,
                               "at": f"phi {phi.var} in B{B.bid}",
                               "def_block": cfg.def_block[v],
                               "dominates_block": p})
        for v in B.uses:
            claims.append({"kind": "use", "use_value": v, "at": f"B{B.bid}",
                           "def_block": cfg.def_block[v],
                           "dominates_block": B.bid})
        for (dst, src) in B.copies:
            claims.append({"kind": "copy", "use_value": src,
                           "at": f"{dst} <- {src} in B{B.bid}",
                           "def_block": cfg.def_block[src],
                           "dominates_block": B.bid})
    cert = {
        "format": "ssa-dominance-proof/v1",
        "entry": cfg.entry,
        "blocks": {str(b.bid): {"preds": sorted(set(b.preds)),
                                "succs": sorted(set(b.succs))}
                   for b in cfg.blocks.values()},
        "edges": [[s, d, k] for (s, d, k) in sorted(cfg.edges)],
        "rewrites": log,
        "claims": claims,
    }
    return json.dumps(cert, indent=2, sort_keys=True)


def check_certificate(cert_text: str) -> dict:
    cert = json.loads(cert_text)
    cfg = CFG(cert["entry"])
    for bid, rec in cert["blocks"].items():
        b = cfg.add_block(int(bid))
        b.preds = list(rec["preds"])
        b.succs = list(rec["succs"])
    cfg.edges = {(s, d, k) for (s, d, k) in cert["edges"]}
    checked = 0
    for c in cert["claims"]:
        d, b = c["def_block"], c["dominates_block"]
        if not dominates_bruteforce(cfg, d, b):
            raise VerificationError(
                f"certificate claim FAILED: B{d} must dominate B{b} ({c['at']})")
        checked += 1
    return {"format": cert["format"], "claims_checked": checked, "ok": True}


@dataclass
class CostModel:
    base: int = 1
    call_barrier: int = 8
    high_class: int = 4


def block_liveness(cfg: CFG) -> "dict[int, set[str]]":
    use = {b: set() for b in cfg.blocks}
    define = {b: set() for b in cfg.blocks}
    for b, blk in cfg.blocks.items():
        for v in blk.uses:
            use[b].add(v)
        for (dst, src) in blk.copies:
            define[b].add(dst)
        for phi in blk.phis:
            define[b].add(phi.var)
            for v in phi.inputs.values():
                use[b].add(v)
    live_in = {b: set() for b in cfg.blocks}
    live_out = {b: set() for b in cfg.blocks}
    changed = True
    while changed:
        changed = False
        for b in list(cfg.blocks):
            new_out = set()
            for s in cfg.blocks[b].succs:
                new_out |= live_in[s]
            new_in = use[b] | (new_out - define[b])
            if new_out != live_out[b] or new_in != live_in[b]:
                live_out[b], live_in[b] = new_out, new_in
                changed = True
    return {"in": live_in, "out": live_out}


def pressure(cfg: CFG, cost: CostModel | None = None) -> dict:
    cost = cost or CostModel()
    lv = block_liveness(cfg)
    inter = defaultdict(int)
    peak = 0
    for b in cfg.blocks:
        entry = set(lv["in"][b])
        for phi in cfg.blocks[b].phis:
            entry |= set(phi.inputs.values())
        for point in (entry, set(lv["out"][b])):
            vals = sorted(v for v in point if v in cfg.def_block)
            peak = max(peak, len(vals))
            for i in range(len(vals)):
                for j in range(i + 1, len(vals)):
                    inter[(vals[i], vals[j])] += cost.base
    return {"peak_block_pressure": peak,
            "weighted_interference": sum(inter.values()),
            "conflicts": len(inter)}


def greedy_color(cfg: CFG, k: int = 8) -> dict:
    lv = block_liveness(cfg)
    graph = defaultdict(set)
    for b in cfg.blocks:
        vals = sorted({v for v in (lv["in"][b] | lv["out"][b]) if v in cfg.def_block})
        for i in range(len(vals)):
            for j in range(i + 1, len(vals)):
                graph[vals[i]].add(vals[j])
                graph[vals[j]].add(vals[i])
    for v in cfg.def_block:
        graph.setdefault(v, set())
    order, removed, colors = [], set(), {}
    work = {v: set(graph[v]) for v in graph}
    while work:
        pick = None
        for v in list(work):
            if len(work[v] - removed) < k:
                pick = v
                break
        if pick is None:
            pick = max(work, key=lambda v: len(work[v] - removed))
            removed.add(pick)
        order.append(pick)
        work.pop(pick)
    for v in order:
        if v in colors:
            continue
        used = {colors[n] for n in graph[v] if n in colors}
        for c in range(k):
            if c not in used:
                colors[v] = c
                break
        else:
            colors[v] = None
    return {"colors": colors, "spilled": [v for v, c in colors.items() if c is None],
            "k": k}

3. Verification

Hand-built CFGs - Irreducible + exception: loop {1,2} with two entries (0->1,0->2); critical exits 1->3,2->3 carry φ operands; exception edge 1->4. → exactly 2 splits (the minimum), one copy per split block, exception edge untouched. - Swap problem: mutually recursive φs on critical back edge 2->1. → 1 split + two independent fresh-name copies (y.split0=y, x.split0=x), no cycle. - Exception-edge φ: φ operand arrives on non-splittable critical edge 1->3. → exception_copy a1.split0=a1 in source block 1, 0 splits.

Randomized differential fuzz (fuzz(300)): 300 random CFGs (forward/back edges, ~15% exception edges, guaranteed reachability, random φs). Each seed asserts #split_edge == #(normal critical edges with a φ operand) (split minimality), verify() passes, and check_certificate() re-proves every claim.

Negative control: a tampered certificate claiming B2 dominates a use in B4 (avoiding path B1->B4) is rejected with VerificationError. A checker that accepts invalid proofs proves nothing.
