Answer

Root cause. Two boards drifted: tasks.jsonl (canonical) lost the CONC-001/E2E-001/BOARD-V2 rows entirely, while tasks.md (legacy matrix) kept them pending forever. A stand-in PM trusted the matrix text and filed GAP-005 for a defect that migration 014 (UNIQUE index) + 23505→ErrDuplicateEvent + judge PASS 5/5 tick 271 already fixed. Board text is derived state; code is the source of truth.

Step 1 — verify status against CODE, not board text (what the PM should have run):

find migrations/ -maxdepth 1 -name '*014*'                  # migration 014 present
grep -n 'UNIQUE' migrations/014_*.sql                      # UNIQUE index in place
grep -rn 'ErrDuplicateEvent' migrations/ src/              # 23505 -> ErrDuplicateEvent
grep -h 'PASS' ledger/judge-*.log | tail -3                # tick 271: PASS 5/5

Step 2 — scripts/sync-board-from-code.sh: refuses to run unless the fix markers exist in code; then appends canonical JSONL rows with done + evidence, flips legacy matrix cells to DONE, and writes an evidence footnote.

for id in CONC-001 E2E-001 BOARD-V2; do
  grep -Rl "$id" migrations/ >/dev/null || { echo "skip $id: no code trace"; continue; }
  # canonical JSONL: append done row (skip if already done -> idempotent)
  printf '{"id":"%s","status":"done","evidence":"%s","resolved_tick":271}\n' \
         "$id" "$EVIDENCE" >> tasks.jsonl
  # legacy matrix: flip status cell (greedy backtracking targets LAST '| pending |' = status cell)
  sed -E "s/^(\|[[:space:]]*${id}[[:space:]]*\|.*\|)[[:space:]]*pending[[:space:]]*(.*)$/\1 DONE \2/" \
      tasks.md > tasks.md.tmp && mv tasks.md.tmp tasks.md
done

Step 3 — scripts/check-board-consistency.sh (grep-based, mawk-safe: grep -E + POSIX classes only — no \b, no grep -P, no gawk capture-array match). Extracts the pending-ID set from each board, comm -23s them, then cross-checks the union against code so the "rows never marked DONE on either board" failure mode is caught too:

grep -E '"status"[[:space:]]*:[[:space:]]*"pending"' tasks.jsonl \
  | sed -E 's/.*"id"[[:space:]]*:[[:space:]]*"([^"]+)".*/\1/' | sort -u > "$TMP/j"
grep -E '^\|[[:space:]]*[A-Za-z0-9]+-[A-Za-z0-9]+[[:space:]]*\|' tasks.md \
  | grep -Ei '[[:space:]]pending[[:space:]]|open' \
  | sed -E 's/^\|[[:space:]]*([A-Za-z0-9]+-[A-Za-z0-9]+).*/\1/' | sort -u > "$TMP/m"
comm -23 "$TMP/m" "$TMP/j" | while read -r id; do
  find migrations/ -maxdepth 1 -name '*014*' | grep -q . && grep -Rl "$id" migrations/ >/dev/null \
    && echo "SPLIT-BRAIN: $id proven FIXED in code (migration/014 + ErrDuplicateEvent, judge PASS 5/5 tick 271)" && exit 1
done
