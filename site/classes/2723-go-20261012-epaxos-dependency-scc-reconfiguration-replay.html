EPaxos dependency-SCC reconfiguration replay

Root cause

The trace is not the execution history. EPaxos safety is a partial order over dependencies + ballots:

  1. Delivery order ≠ protocol order. Duplicates/reordering let a stale lower-ballot pre_accept/accept overwrite a commit. Precedence must be commit/conf_change > accept > pre_accept, then max ballot, unioning deps tied at (phase, ballot).
  2. Dependencies form a DAG up to SCCs. Mutual dependencies are normal (contention). A plain topological sort deadlocks or picks an arbitrary cycle break → reorders conflicting commands.
  3. Lost conflict edges. Two committed commands on the same key need a fallback order (seq, ballot, replica, slot), added only when no dependency path exists (never fabricate a cycle).
  4. Per-replica slot truncation is not a global cut — the core reconfiguration bug. A snapshot keeping an early local slot may omit a dependency in a later slot on another replica, so the retained set is not closed and the state is unlinearizable.
  5. External deps must be carried in residual, not inferred.
  6. Bounded memory: keep only the committed graph, SCC condensation, retained suffix, and a frontier touching the snapshot.

The three truncation invariants for a prefix S: dependency closure (x∈S ⇒ deps(x)⊆S), SCC atomicity, and configuration-epoch boundary (<e fully included, e wholly or not at all).

The fix

Pipeline: Normalize → BuildGraph → Tarjan(SCC) → ExecutionOrder → Verify, with Verify returning shortest-path/cycle minimal counterexamples and a self-re-verifying recovery plan.

Core selection logic:

// commit/conf_change > accept > pre_accept; within phase, max ballot;
// union deps tied at (phase, ballot).
bestRank := 0
for _, m := range group { if r := kindRank(m.Kind); r > bestRank { bestRank = r } }
// ... pick max ballot among bestRank, union deps of all messages at that (rank,ballot)

Recovery finds the greatest dependency-closed, SCC-complete, config-prefix subset and moves the rest back into the log (less truncation), then re-runs verification with recursion disabled.
