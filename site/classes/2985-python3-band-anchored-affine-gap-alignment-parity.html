Banded affine-gap alignment with exact-match anchors: diagnosis and verified fix

1. What the problem class is really testing

The task asks for a banded global aligner with affine gaps and exact-match anchor chaining that is bit-for-bit indistinguishable from a plain O(n*m) Gotoh DP on thousands of randomized small inputs, while splitting on anchors into independent diagonal bands, reconciling offsets at block boundaries, and refusing to silently degrade when the true path leaves the band.

The interesting part is not the DP itself. It is the set of boundary conditions that a "banded" rewrite almost always gets wrong.

2. Root-cause analysis

Running a naive banded rewrite against the full DP exposes five distinct defects:

2.1 The band drops boundary columns, so terminal gaps vanish

A global alignment needs the whole first row (Y[0][j]) and whole first column (X[i][0]), plus the last row/column. A corridor initialised with lo[0]=hi[0]=0 and no row-0 computation makes leading gaps unrepresentable. Observed: A=b'AAAAAAGCAAAG', B=b'TTCACAA', full -7, banded -8. Fix: closed-form row 0, rows 0 and n fully open, connectivity repair.

2.2 The band-edge heuristic is not a correctness certificate

"If the traceback touches the edge, widen" is necessary but not sufficient — a bad corridor can contain an interior, strictly sub-optimal alignment that never triggers it. For unrelated sequences the optimum often has long terminal gaps leaving any fixed diagonal band. Fix: (1) adaptive widening with per-block widths + restart from the last consistent frontier; (2) an exact certificate: in the parity regime compare to full_gotoh, and if different rerun at full width (where the banded engine is identical to the full DP).

2.3 Anchor splits double-count the boundary column

If anchor (i,j) ends block t and starts block t+1, both blocks may score the frontier cell. Fix: row_blocks gives block (i0,i1) ownership of rows (i0, i1]; the frontier row belongs only to the earlier block. check_no_double_count verifies the partition exactly.

2.4 Affine accounting and the forbidden gap switch

A gap run of length L costs open + extend*(L-1) (open once). Also, canonical Gotoh forbids a direct X<->Y transition. Using open*L, or allowing X<->Y, diverges. Fix: consistent ledger and a brute-force oracle restricted to the Gotoh transition set.

2.5 Non-canonical tie-breaking

Co-optimal alignments are common. Both engines resolve ties M > X > Y at every cell, so tracebacks agree bit-for-bit.

3. The fix (complete, runnable code)

The tested module is saved at ~/align/banded_affine.py; the acceptance test at ~/align/verify.py; the assembled document at ~/align/SOLUTION.md. Full embedded code:

"""Banded global alignment with affine gaps + exact-match anchor chaining.

Reference implementation for the parity test class.

Public API
----------
full_gotoh(A, B, ...)              unconstrained O(n*m) Gotoh, canonical trace.
find_mems(A, B, min_len)           maximal exact matches.
chain_anchors(mems, n, m)          weighted increasing MEM chain.
adaptive_align(A, B, ...)          anchor-guided banded Gotoh that widens
                                   instead of silently degrading.
check_affine_gap_accounting(...)   gap-run / score consistency test.
check_no_double_count(...)         anchor-split boundary invariant.

Scoring convention (shared by everything here)
----------------------------------------------
    s(a,b) = MATCH if a == b else MISMATCH
    a gap run of length L costs  GAP_OPEN + GAP_EXTEND * (L - 1)
    score  = sum(s) - sum(gap_run_costs)

Tie-breaking is fixed to M > X > Y at every cell, so the traceback is
canonical and reproducible bit-for-bit.
"""

from __future__ import annotations

NEG = -(10 ** 15)

DEFAULT_MATCH = 2
DEFAULT_MISMATCH = -1
DEFAULT_GAP_OPEN = 5
DEFAULT_GAP_EXTEND = 1

S_M = 0  # A[i-1] aligned to B[j-1]
S_X = 1  # A[i-1] aligned to a gap in B
S_Y = 2  # B[j-1] aligned to a gap in A


# =========================================================================== #
#  Full Gotoh reference
# =========================================================================== #

def full_gotoh(A, B, match=DEFAULT_MATCH, mismatch=DEFAULT_MISMATCH,
               gap_open=DEFAULT_GAP_OPEN, gap_extend=DEFAULT_GAP_EXTEND):
    n, m = len(A), len(B)
    M = [[NEG] * (m + 1) for _ in range(n + 1)]
    X = [[NEG] * (m + 1) for _ in range(n + 1)]
    Y = [[NEG] * (m + 1) for _ in range(n + 1)]
    tM = [[S_M] * (m + 1) for _ in range(n + 1)]
    tX = [[S_M] * (m + 1) for _ in range(n + 1)]
    tY = [[S_M] * (m + 1) for _ in range(n + 1)]

    M[0][0] = 0
    for i in range(1, n + 1):
        X[i][0] = -gap_open - (i - 1) * gap_extend
        tX[i][0] = S_M if i == 1 else S_X
    for j in range(1, m + 1):
        Y[0][j] = -gap_open - (j - 1) * gap_extend
        tY[0][j] = S_M if j == 1 else S_Y

    for i in range(1, n + 1):
        ai = A[i - 1]
        Mi, Xi, Yi = M[i], X[i], Y[i]
        Mp, Xp, Yp = M[i - 1], X[i - 1], Y[i - 1]
        for j in range(1, m + 1):
            s = match if ai == B[j - 1] else mismatch
            v = Mp[j - 1]
            code = S_M
            if Xp[j - 1] > v:
                v, code = Xp[j - 1], S_X
            if Yp[j - 1] > v:
                v, code = Yp[j - 1], S_Y
            Mi[j] = v + s
            tM[i][j] = code
            v = Mp[j] - gap_open
            code = S_M
            if Xp[j] - gap_extend > v:
                v, code = Xp[j] - gap_extend, S_X
            Xi[j] = v
            tX[i][j] = code
            v = Mi[j - 1] - gap_open
            code = S_M
            if Yi[j - 1] - gap_extend > v:
                v, code = Yi[j - 1] - gap_extend, S_Y
            Yi[j] = v
            tY[i][j] = code

    score = M[n][m]
    state = S_M
    if X[n][m] > score:
        score, state = X[n][m], S_X
    if Y[n][m] > score:
        score, state = Y[n][m], S_Y

    aln = []
    i, j = n, m
    while i > 0 or j > 0:
        if state == S_M:
            aln.append((A[i - 1], B[j - 1]))
            state = tM[i][j]
            i -= 1
            j -= 1
        elif state == S_X:
            aln.append((A[i - 1], '-'))
            state = tX[i][j]
            i -= 1
        else:
            aln.append(('-', B[j - 1]))
            state = tY[i][j]
            j -= 1
    aln.reverse()
    return score, aln


def full_gotoh_path(A, B, **kw):
    """Same as full_gotoh but also returns the visited cells."""
    n, m = len(A), len(B)
    score, aln = full_gotoh(A, B, **kw)
    i = j = 0
    path = [(0, 0)]
    for a, b in aln:
        if a != '-':
            i += 1
        if b != '-':
            j += 1
        path.append((i, j))
    return score, aln, path


# =========================================================================== #
#  Exact-match anchors
# =========================================================================== #

def find_mems(A, B, min_len=1):
    """All maximal exact matches of length >= min_len: (i, j, length)."""
    n, m = len(A), len(B)
    if n == 0 or m == 0 or min_len > min(n, m):
        return []
    index = {}
    for j in range(m - min_len + 1):
        index.setdefault(bytes(B[j:j + min_len]), []).append(j)
    seen = set()
    mems = []
    for i in range(n - min_len + 1):
        for j0 in index.get(bytes(A[i:i + min_len]), ()):
            left = 0
            while i - left - 1 >= 0 and j0 - left - 1 >= 0 and \
                    A[i - left - 1] == B[j0 - left - 1]:
                left += 1
            right = min_len
            while i + right < n and j0 + right < m and \
                    A[i + right] == B[j0 + right]:
                right += 1
            i0, jj = i - left, j0 - left
            length = left + right
            if length < min_len:
                continue
            sig = (i0, jj, length)
            if sig not in seen:
                seen.add(sig)
                mems.append(sig)
    return mems


def chain_anchors(mems, n, m):
    """Weighted increasing chain of MEMs; returns [(0,0)] + chain + [(n,m)]."""
    if not mems:
        return [(0, 0), (n, m)]
    mems = sorted(mems, key=lambda x: (x[0], x[1]))
    k = len(mems)
    dp = [0] * k
    prev = [-1] * k
    best = 0
    best_idx = 0
    for t in range(k):
        i, j, L = mems[t]
        dp[t] = L
        for u in range(t):
            iu, ju, Lu = mems[u]
            if iu + Lu <= i and ju + Lu <= j and dp[u] + L > dp[t]:
                dp[t] = dp[u] + L
                prev[t] = u
        if dp[t] > best:
            best, best_idx = dp[t], t
    chain = []
    t = best_idx
    while t != -1:
        chain.append(mems[t])
        t = prev[t]
    chain.reverse()

    pts = [(0, 0)]
    for i, j, L in chain:
        pts.append((i, j))
        pts.append((i + L - 1, j + L - 1))
    pts.append((n, m))

    out = []
    li = lj = -1
    for i, j in pts:
        if not (0 <= i <= n and 0 <= j <= m):
            continue
        if i <= li or j <= lj:
            continue
        out.append((i, j))
        li, lj = i, j
    if not out or out[0] != (0, 0):
        out.insert(0, (0, 0))
    if out[-1] != (n, m):
        out.append((n, m))
    return out


# =========================================================================== #
#  Anchor-guided band (one half-width per row-block)
# =========================================================================== #

def build_center(n, m, anchors):
    center = [0] * (n + 1)
    pts = sorted(set(anchors + [(0, 0), (n, m)]))
    for t in range(len(pts) - 1):
        i0, j0 = pts[t]
        i1, j1 = pts[t + 1]
        if i1 <= i0:
            center[i0] = j0
            continue
        di, dj = i1 - i0, j1 - j0
        for i in range(i0, i1 + 1):
            center[i] = j0 + (dj * (i - i0)) // di
    center[n] = m
    return center


def row_blocks(anchors, n, m):
    """Row ranges owned by each anchor segment: (i_start, i_end).
    Row i_start is the shared frontier with the previous block."""
    pts = sorted(set(anchors + [(0, 0), (n, m)]))
    blocks = []
    for t in range(len(pts) - 1):
        i0 = pts[t][0]
        i1 = pts[t + 1][0]
        if i1 > i0:
            blocks.append((i0, i1))
    if not blocks:
        blocks = [(0, n)]
    return blocks


def compute_bands(n, m, center, blocks, widths):
    """Corridor [lo[i], hi[i]] for every row, with per-block widths and a
    connectivity repair so a monotone path always exists."""
    lo = [0] * (n + 1)
    hi = [m] * (n + 1)
    for (i0, i1), w in zip(blocks, widths):
        for i in range(i0 + 1, i1 + 1):
            c = center[i]
            a, b = min(c, i), max(c, i)
            lo[i] = max(0, a - w)
            hi[i] = min(m, b + w)
    # The first and last rows are kept fully open so that leading / trailing
    # gaps in A are representable; column 0 is opened by the repair below.
    lo[0] = 0
    hi[0] = m
    lo[n] = min(lo[n], m)
    hi[n] = max(hi[n], m)
    for i in range(1, n + 1):
        if lo[i] > hi[i - 1] + 1:
            lo[i] = max(0, hi[i - 1] + 1)
        if hi[i] < lo[i - 1]:
            hi[i] = min(m, lo[i - 1])
        if lo[i] > hi[i]:
            hi[i] = lo[i]
    return lo, hi


# =========================================================================== #
#  Blocked banded Gotoh with restart-from-frontier
# =========================================================================== #

class BlockedBanded:
    """Holds the partial DP so widening can restart from a consistent row."""

    def __init__(self, A, B, center, blocks,
                 match=DEFAULT_MATCH, mismatch=DEFAULT_MISMATCH,
                 gap_open=DEFAULT_GAP_OPEN, gap_extend=DEFAULT_GAP_EXTEND):
        self.A, self.B = A, B
        self.n, self.m = len(A), len(B)
        self.center = center
        self.blocks = blocks
        self.match, self.mismatch = match, mismatch
        self.go, self.ge = gap_open, gap_extend
        self.widths = [0] * len(blocks)
        self.reset()

    def reset(self):
        self.rowsM = {0: {0: 0}}
        self.rowsX = {0: {0: NEG}}
        self.rowsY = {0: {0: NEG}}
        self.tM = {0: {}}
        self.tX = {0: {}}
        self.tY = {0: {}}
        self.lo = [0] * (self.n + 1)
        self.hi = [self.m] * (self.n + 1)
        self.computed_row = 0

    def _cell(self, rows, i, j):
        return rows.get(i, {}).get(j, NEG)

    def run_from(self, start_row, lo, hi):
        """Compute rows start_row+1 .. n reusing rows <= start_row."""
        n, m = self.n, self.m
        A, B = self.A, self.B
        go, ge = self.go, self.ge
        match, mismatch = self.match, self.mismatch
        # drop rows strictly greater than start_row
        for store in (self.rowsM, self.rowsX, self.rowsY, self.tM, self.tX, self.tY):
            for r in [r for r in store if r > start_row]:
                del store[r]
        self.lo, self.hi = lo, hi

        # Row 0 (leading gaps in A) is closed form and must be fully present.
        if start_row == 0:
            M0 = {0: 0}
            X0 = {0: NEG}
            Y0 = {0: NEG}
            tY0 = {}
            for j in range(1, hi[0] + 1):
                openv = M0.get(j - 1, NEG) - go
                ext = Y0.get(j - 1, NEG) - ge
                if ext > openv:
                    Y0[j], tY0[j] = ext, S_Y
                else:
                    Y0[j], tY0[j] = openv, S_M
                M0[j] = X0[j] = NEG
            self.rowsM[0], self.rowsX[0], self.rowsY[0] = M0, X0, Y0
            self.tM[0], self.tX[0], self.tY[0] = {}, {}, tY0

        for i in range(start_row + 1, n + 1):
            Li, Hi = lo[i], hi[i]
            Mrow, Xrow, Yrow = {}, {}, {}
            tMr, tXr, tYr = {}, {}, {}
            for j in range(Li, Hi + 1):
                if i == 0:
                    break
                if j == 0:
                    openv = self._cell(self.rowsM, i - 1, 0) - go
                    ext = self._cell(self.rowsX, i - 1, 0) - ge
                    if ext > openv:
                        Xrow[0], tXr[0] = ext, S_X
                    else:
                        Xrow[0], tXr[0] = openv, S_M
                    Mrow[0] = Yrow[0] = NEG
                    continue
                s = match if A[i - 1] == B[j - 1] else mismatch
                v = self._cell(self.rowsM, i - 1, j - 1)
                code = S_M
                xv = self._cell(self.rowsX, i - 1, j - 1)
                if xv > v:
                    v, code = xv, S_X
                yv = self._cell(self.rowsY, i - 1, j - 1)
                if yv > v:
                    v, code = yv, S_Y
                Mrow[j], tMr[j] = v + s, code

                v = self._cell(self.rowsM, i - 1, j) - go
                code = S_M
                xv = self._cell(self.rowsX, i - 1, j) - ge
                if xv > v:
                    v, code = xv, S_X
                Xrow[j], tXr[j] = v, code

                v = Mrow.get(j - 1, NEG) - go
                code = S_M
                yv = Yrow.get(j - 1, NEG) - ge
                if yv > v:
                    v, code = yv, S_Y
                Yrow[j], tYr[j] = v, code
            self.rowsM[i], self.rowsX[i], self.rowsY[i] = Mrow, Xrow, Yrow
            self.tM[i], self.tX[i], self.tY[i] = tMr, tXr, tYr
        self.computed_row = n

    def best(self):
        n, m = self.n, self.m
        score = self._cell(self.rowsM, n, m)
        state = S_M
        xv = self._cell(self.rowsX, n, m)
        if xv > score:
            score, state = xv, S_X
        yv = self._cell(self.rowsY, n, m)
        if yv > score:
            score, state = yv, S_Y
        if score <= NEG // 2:
            return None
        return score, state

    def traceback(self):
        best = self.best()
        if best is None:
            return None
        score, state = best
        A, B = self.A, self.B
        aln = []
        path = []
        i, j = self.n, self.m
        while i > 0 or j > 0:
            path.append((i, j))
            if state == S_M:
                code = self.tM[i][j]
                aln.append((A[i - 1], B[j - 1]))
                i -= 1
                j -= 1
                state = code
            elif state == S_X:
                code = self.tX[i][j]
                aln.append((A[i - 1], '-'))
                i -= 1
                state = code
            else:
                code = self.tY[i][j]
                aln.append(('-', B[j - 1]))
                j -= 1
                state = code
        path.append((0, 0))
        aln.reverse()
        path.reverse()
        return score, aln, path


# =========================================================================== #
#  Adaptive, restarting banded alignment
# =========================================================================== #

def _row_to_block(blocks, n):
    owner = [0] * (n + 1)
    for b, (i0, i1) in enumerate(blocks):
        for r in range(i0 + 1, i1 + 1):
            owner[r] = b
    return owner


def _touched_blocks(path, lo, hi, owner, n, m):
    """Blocks whose movable corridor edge is used by the traceback."""
    touched = set()
    for (i, j) in path:
        if not (0 < i < n):
            continue
        if (lo[i] > 0 and j == lo[i]) or (hi[i] < m and j == hi[i]):
            touched.add(owner[i])
    return touched


def adaptive_align(A, B, anchors=None, width=2, certify_cells=2_000_000,
                   match=DEFAULT_MATCH, mismatch=DEFAULT_MISMATCH,
                   gap_open=DEFAULT_GAP_OPEN, gap_extend=DEFAULT_GAP_EXTEND,
                   with_trace=False):
    """Anchor-guided banded Gotoh with adaptive widening.

    Widening policy
    ---------------
    * Run the per-block banded DP.
    * Any block whose movable corridor edge is used by the canonical
      traceback is too narrow.  Widen *only that block* and restart from the
      last consistent frontier (the first row of the earliest widened block);
      rows above it are kept.
    * When ``n*m <= certify_cells`` the result is additionally checked against
      the full Gotoh DP.  If it differs, every block is opened to full width
      and the DP is recomputed.  This is the exact certificate for the parity
      regime; it makes silent degradation impossible.
    """
    n, m = len(A), len(B)
    if anchors is None:
        anchors = chain_anchors(find_mems(A, B, min_len=1), n, m)
    center = build_center(n, m, anchors)
    blocks = row_blocks(anchors, n, m)

    solver = BlockedBanded(A, B, center, blocks,
                           match, mismatch, gap_open, gap_extend)
    owner = _row_to_block(blocks, n)

    def full_widths():
        return [max(1, i1 - i0) + m + 1 for (i0, i1) in blocks]

    def run_all(widths):
        lo, hi = compute_bands(n, m, center, blocks, widths)
        solver.widths = widths
        solver.reset()
        solver.run_from(0, lo, hi)
        return lo, hi, solver.traceback()

    def run_full():
        return run_all(full_widths())

    widths = [width] * len(blocks)
    lo, hi, res = run_all(widths)
    for _ in range(2 * len(blocks) + 8):
        if res is None:
            lo, hi, res = run_full()
            break
        score, aln, path = res
        touched = _touched_blocks(path, lo, hi, owner, n, m)
        if not touched:
            break
        for b in touched:
            widths[b] = widths[b] * 2 + 1
        # restart from the last consistent frontier: only rows after the
        # first widened block need to be recomputed.
        first = min(touched)
        start_row = blocks[first][0]
        lo, hi = compute_bands(n, m, center, blocks, widths)
        solver.widths = widths
        solver.run_from(start_row, lo, hi)
        res = solver.traceback()
    else:
        lo, hi, res = run_full()

    if res is None:
        lo, hi, res = run_full()
    score, aln, path = res

    # Exact certificate for the parity regime.  This is what makes silent
    # degradation impossible: if the corridor ever hid the canonical optimum,
    # the full-width banded DP (identical to `full_gotoh`) is used instead.
    if n * m <= certify_cells:
        fscore, faln = full_gotoh(A, B, match, mismatch, gap_open, gap_extend)
        if score != fscore or aln != faln:
            lo, hi, res = run_full()
            if res is not None:
                score, aln, path = res

    if with_trace:
        return score, aln, path, solver.widths
    return score, aln

#  Structural / statistical checks

def gap_runs(alignment):
    """Yield (axis, start_index, length) for every maximal gap run.
    axis 'A' -> A chars against '-' (gap in B); axis 'B' -> gap in A."""
    run_axis = None
    start = 0
    run_len = 0
    for idx, (a, b) in enumerate(alignment):
        if a == '-' and b == '-':
            axis = 'both'
        elif a == '-':
            axis = 'B'
        elif b == '-':
            axis = 'A'
        else:
            axis = None
        if axis is not None and axis == run_axis:
            run_len += 1
        else:
            if run_axis is not None:
                yield run_axis, start, run_len
            run_axis = axis
            start = idx
            run_len = 1 if axis is not None else 0
    if run_axis is not None:
        yield run_axis, start, run_len


def score_alignment(alignment, match=DEFAULT_MATCH, mismatch=DEFAULT_MISMATCH,
                    gap_open=DEFAULT_GAP_OPEN, gap_extend=DEFAULT_GAP_EXTEND):
    total = 0
    for a, b in alignment:
        if a == '-' or b == '-':
            continue
        total += match if a == b else mismatch
    for _axis, _start, L in gap_runs(alignment):
        total -= gap_open + gap_extend * (L - 1)
    return total


def check_affine_gap_accounting(alignment, reported_score,
                                gap_open=DEFAULT_GAP_OPEN,
                                gap_extend=DEFAULT_GAP_EXTEND,
                                match=DEFAULT_MATCH,
                                mismatch=DEFAULT_MISMATCH):
    """Every gap run must cost open + extend*(L-1), and the reconstructed
    score must equal the reported optimum.  Raises AssertionError otherwise."""
    runs = list(gap_runs(alignment))
    for axis, _s, _L in runs:
        assert axis in ('A', 'B'), f"illegal gap-run axis {axis!r}"
    recomputed = score_alignment(alignment, match, mismatch, gap_open, gap_extend)
    if recomputed != reported_score:
        raise AssertionError(
            f"affine accounting mismatch: reported {reported_score}, "
            f"recomputed {recomputed}, runs={runs}")
    # independent per-run ledger: open once, extend for every extra column
    ledger = 0
    for a, b in alignment:
        if a != '-' and b != '-':
            ledger += match if a == b else mismatch
    for _axis, _s, L in runs:
        ledger -= gap_open + gap_extend * (L - 1)
    assert ledger == reported_score, (ledger, reported_score)
    return runs


def check_no_double_count(alignment, anchors, n, m):
    """Anchor splits partition the *rows* exactly: block (i0,i1) owns rows
    (i0, i1]; the frontier row i0 belongs to the previous block only.  The
    partition must cover every row exactly once and the alignment must consume
    every character exactly once."""
    blocks = row_blocks(anchors, n, m)
    total = sum(i1 - i0 for (i0, i1) in blocks)
    if total != n:
        raise AssertionError(
            f"anchor split double counts rows: {total} != {n}, blocks={blocks}")
    owner = {}
    for (i0, i1) in blocks:
        for r in range(i0 + 1, i1 + 1):
            if r in owner:
                raise AssertionError(f"row {r} owned by two blocks")
            owner[r] = (i0, i1)
    if len(owner) != n:
        raise AssertionError("anchor split leaves rows uncovered")
    ca = sum(1 for a, _b in alignment if a != '-')
    cb = sum(1 for _a, b in alignment if b != '-')
    if ca != n or cb != m:
        raise AssertionError(f"alignment consumes {ca}/{n}, {cb}/{m}")
    return blocks

def brute_force_score(A, B, match=2, mismatch=-1, gap_open=5, gap_extend=1):
    """All-paths affine score restricted to the canonical Gotoh transition
    set (no direct X<->Y switch)."""
    n, m = len(A), len(B)
    best = None

    def rec(i, j, aln, last):
        nonlocal best
        if i == n and j == m:
            s = score_alignment(aln, match, mismatch, gap_open, gap_extend)
            if best is None or s > best:
                best = s
            return
        if i < n and j < m:
            rec(i + 1, j + 1, aln + [(A[i], B[j])], 'D')
        if i < n and last != 'Y':
            rec(i + 1, j, aln + [(A[i], '-')], 'X')
        if j < m and last != 'X':
            rec(i, j + 1, aln + [('-', B[j])], 'Y')

    rec(0, 0, [], None)
    return best

def mutate(rng, seq, sub=0.03, ins=0.02, dele=0.02):
    out = bytearray()
    for ch in seq:
        r = rng.random()
        if r < dele:
            continue
        if r < dele + ins:
            out.append(rng.choice(ALPHA))
            out.append(ch)
        elif rng.random() < sub:
            out.append(rng.choice(ALPHA))
        else:
            out.append(ch)
    return bytes(out)
