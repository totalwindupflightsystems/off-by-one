Tiled Translucent Overflow & Replay: Legal Partition and Tight Peak-Memory Schedule

Problem class: webgpu20261018-translucent-tile-overflow-replay Environment: Node 20+ (verified on Node v22), zero dependencies Artifact: overflow-replay.js — a single runnable, self-testing file

0. Symptom

A WebGPU render graph composites premultiplied-alpha translucent fragments per tile. Each tile attachment can hold only C fragment slots. Primitives straddle tile boundaries, so one draw deposits fragments into several tiles and a tile can overflow. Passes may be reordered asynchronously. The observed failures are: lost/duplicated translucent layers after overflow, output that depends on pass execution order, unbounded (or non-tight) transient storage, and corrupted tiles after device.lost.

1. Root-cause analysis

RC1 — Tile-boundary overflow truncates or re-bases the layer list

A primitive spanning several tiles replicates a fragment into every tile it covers, so per-tile counts n_t can exceed capacity C. If the excess is dropped, or if an overflow buffer is flushed without preserving the original order, layers disappear. Fix: never drop; split each tile's ordered list into ceil(n_t / C) contiguous replay bins and execute all of them.

RC2 — Blend order is not commutative; spilled data must stay premultiplied

The premultiplied source-over operator

over(s, d) = ( s.rgb + d.rgb * (1 - s.a),  s.a + d.a * (1 - s.a) )

is associative but not commutative. Bins may therefore be regrouped (associativity) but never permuted (non-commutativity). Two classic bugs:

  1. the replay path sorts bins by pass/tile id instead of submission order;
  2. overflow fragments are stored as straight alpha and multiplied by alpha again on reload, so rounding breaks exact regrouping.

Fix: premultiply once at fragment creation, tag every fragment with a monotonic seq, sort each tile by seq, and make each bin a contiguous seq range.

RC3 — Asynchronous pass reordering changes the per-tile block order

Independent passes may run in any order. If the replay schedule uses pass id or arrival time as the ordering key, two fragments that land in the same tile can swap. Fix: order is a property of the payload (seq), never of execution. Passes may be reordered freely; within a tile, bins are emitted by chunkIndex. The emitted schedule is a linear extension of the per-tile bin chains.

RC4 — Device loss tears in-flight tile state

If a bin writes directly into the committed accumulator and the device is lost mid-bin, the accumulator is half-blended and replaying the bin double-blends it. Fix: blend each bin into a chunk-local staging value, commit only when the whole bin succeeds, and treat (committed accumulator, lastChunk[tile]) as the checkpoint. On device loss, discard staging and replay the current bin. Because over is associative and the committed prefix is untouched, replay is exact and idempotent.

2. Exact fix

2.1 Invariants

  1. Fragments are premultiplied at creation; reload never re-premultiplies.
  2. Every fragment receives a strictly increasing submission sequence seq.
  3. Per tile, fragments composite strictly in seq order.
  4. Every replay bin is a contiguous seq range holding <= C fragments.
  5. A tile uses the minimum b_t = ceil(n_t / C) bins, with balanced sizes.
  6. A bin is committed atomically; its staging buffer is discarded on failure.

2.2 Algorithm

  • partition(graph, C) — per tile, sort by seq, chunk into b_t = ceil(n_t / C) balanced contiguous bins; returns the legal partition.
  • schedule(partitioned) — round-robins tiles over chunk index, emitting steps (tile, chunkIndex, seqStart..seqEnd, size, running peak). This is a valid topological order of the per-tile chains and demonstrates asynchronous interleaving across tiles.
  • execute(order, tiles) — replays bins with chunk-local staging and throws on any chunkIndex order violation, so the schedule self-checks.
  • executeWithRecovery(order, tiles, failAtStep) — as above, but a simulated device loss discards staging and replays the bin from the last checkpoint.

2.3 Tight peak-memory bound

For a tile with n fragments and capacity C, every legal partition needs at least b = ceil(n / C) bins. With exactly b bins, the largest bin has size at least ceil(n / b). The balanced partition attains exactly ceil(n / b). Hence the per-tile optimum at the minimal bin count is

P_t = ceil( n / ceil(n / C) )

and the global tight peak is P* = max_t P_t. A serial replay that owns one tile at a time realizes P*, and no legal minimum-pass partition can beat it. (More passes than b_t can lower the peak toward 1; P* is the optimum at the minimal replay-pass count that the bounded attachment forces.)

'use strict';
// ============================================================================
// overflow-replay.js
// Tiled translucent render-graph: legal partition + replay schedule.
//
// Model
// -----
//  * Fragments are premultiplied-alpha samples produced by render passes.
//  * Each fragment carries a globally monotonic submission sequence `seq`.
//  * Fragments are grouped per tile and composited with the premultiplied
//    source-over operator. `over` is associative but NOT commutative, so the
//    per-tile sequence is part of correctness and may never be permuted.
//  * Each tile attachment holds at most C fragment slots. A tile with n
//    fragments therefore needs ceil(n / C) contiguous replay chunks (bins).
//  * Bins of one tile form a chain; different tiles are independent and may be
//    reordered / interleaved ("asynchronous pass reordering").
//
// Peel memory is measured as the number of resident fragment slots.
// ============================================================================

// ---------------------------------------------------------------- blend math
function over(src, dst) {
  const inv = 1 - src.a;
  return {
    r: src.r + dst.r * inv,
    g: src.g + dst.g * inv,
    b: src.b + dst.b * inv,
    a: src.a + dst.a * inv,
  };
}
const ZERO = () => ({ r: 0, g: 0, b: 0, a: 0 });
const EPS = 1e-12;
function close(a, b) {
  return Math.abs(a.r - b.r) < EPS && Math.abs(a.g - b.g) < EPS &&
         Math.abs(a.b - b.b) < EPS && Math.abs(a.a - b.a) < EPS;
}

// ---------------------------------------------------------------- determinism
function makeRng(seed) {
  let s = seed >>> 0;
  return () => { s = (s * 1664525 + 1013904223) >>> 0; return s / 4294967296; };
}

// ------------------------------------------------------------ graph building
function buildGraph({ tiles, passes, fragsPerPass, rng, seed = 0x1234 }) {
  const rand = rng || makeRng(seed);
  const frags = [];
  let seq = 0;
  for (let p = 0; p < passes; p++) {
    for (let i = 0; i < fragsPerPass; i++) {
      const tile = Math.floor(rand() * tiles);
      const a = 0.05 + 0.9 * rand();
      const r = rand(), g = rand(), b = rand();
      frags.push({ seq: seq++, pass: p, tile, r: r * a, g: g * a, b: b * a, a });
    }
  }
  return { tiles, passes, frags };
}

// --------------------------------------------- per-tile groups (stable order)
function groupByTile(frags, tiles) {
  const by = Array.from({ length: tiles }, () => []);
  for (const f of frags) by[f.tile].push(f);
  for (const arr of by) arr.sort((x, y) => x.seq - y.seq);
  return by;
}

// --------------------------------------------------- reference (ground truth)
function renderReference(graph) {
  const by = groupByTile(graph.frags, graph.tiles);
  return by.map(list => list.reduce((acc, f) => over(f, acc), ZERO()));
}

// ------------------------------------------------------- partition arithmetic
// Minimum number of contiguous chunks of capacity C that cover n items.
function minChunks(n, C) {
  if (C < 1) throw new Error('capacity must be >= 1');
  return n === 0 ? 0 : Math.ceil(n / C);
}
// Balanced contiguous chunk sizes: minimum count, minimum possible maximum.
function balancedSizes(n, C) {
  const b = minChunks(n, C);
  if (b === 0) return [];
  const base = Math.floor(n / b), rem = n % b;
  const out = new Array(b);
  for (let i = 0; i < b; i++) out[i] = base + (i < rem ? 1 : 0);
  return out;
}
// Tight peak a single tile can achieve with the *minimum* number of chunks.
function tightPeakForTile(n, C) {
  const b = minChunks(n, C);
  return b === 0 ? 0 : Math.ceil(n / b);
}

// -------------------------------------------------------------- partition
function partition(graph, C) {
  const by = groupByTile(graph.frags, graph.tiles);
  const bins = [];
  for (let t = 0; t < graph.tiles; t++) {
    const sizes = balancedSizes(by[t].length, C);
    let off = 0;
    for (let idx = 0; idx < sizes.length; idx++) {
      const s = sizes[idx];
      const chunk = by[t].slice(off, off + s);
      off += s;
      bins.push({
        id: bins.length, tile: t, chunkIndex: idx, size: s,
        seqStart: chunk.length ? chunk[0].seq : -1,
        seqEnd: chunk.length ? chunk[chunk.length - 1].seq : -1,
        passSpan: chunk.length
          ? [Math.min(...chunk.map(f => f.pass)), Math.max(...chunk.map(f => f.pass))]
          : [],
        fragments: chunk,
      });
    }
  }
  return { bins, byTile: by };
}

// --------------------------------------------------------------- scheduling
// Emits a chain-respecting replay order. Round-robin across tiles demonstrates
// that asynchronous pass reordering is legal as long as per-tile chunk order
// (chunkIndex) is monotonic. Memory accounting is one resident bin at a time.
function schedule(partitioned) {
  const byTile = new Map();
  for (const b of partitioned.bins) {
    if (!byTile.has(b.tile)) byTile.set(b.tile, []);
    byTile.get(b.tile).push(b);
  }
  for (const arr of byTile.values()) arr.sort((x, y) => x.chunkIndex - y.chunkIndex);

  const tileIds = [...byTile.keys()].sort((a, b) => a - b);
  const maxLen = tileIds.reduce((m, t) => Math.max(m, byTile.get(t).length), 0);

  const order = [];
  const steps = [];
  let peak = 0;
  for (let k = 0; k < maxLen; k++) {
    for (const t of tileIds) {
      const arr = byTile.get(t);
      if (k >= arr.length) continue;
      const bin = arr[k];
      peak = Math.max(peak, bin.size);
      order.push(bin);
      steps.push({
        step: steps.length, tile: t, chunkIndex: k, size: bin.size,
        seqStart: bin.seqStart, seqEnd: bin.seqEnd,
        resident: bin.size, peak,
      });
    }
  }
  return { order, steps, peak };
}

// --------------------------------------------------------------- execution
// Replays bins into per-tile accumulators. Throws on any order violation.
function execute(order, tiles) {
  const acc = Array.from({ length: tiles }, ZERO);
  const lastChunk = new Array(tiles).fill(-1);
  for (const b of order) {
    if (b.chunkIndex !== lastChunk[b.tile] + 1) {
      throw new Error(`order violation: tile ${b.tile} chunk ${b.chunkIndex} ` +
                      `after ${lastChunk[b.tile]}`);
    }
    // Commit only after the whole chunk is blended (chunk-local staging).
    let tmp = { ...acc[b.tile] };
    for (const f of b.fragments) tmp = over(f, tmp);
    acc[b.tile] = tmp;
    lastChunk[b.tile] = b.chunkIndex;
  }
  return acc;
}

// ------------------------------------------------ device-loss recovery replay
// The committed accumulator + last chunk index form the checkpoint. A device
// loss discards the in-flight chunk's staging buffer only; the chunk is simply
// replayed. Recovery is idempotent because nothing is committed mid-chunk.
function executeWithRecovery(order, tiles, failAtStep) {
  const acc = Array.from({ length: tiles }, ZERO);
  const lastChunk = new Array(tiles).fill(-1);
  let recoveries = 0;
  let step = 0;

  for (const b of order) {
    if (b.chunkIndex !== lastChunk[b.tile] + 1) {
      throw new Error('order violation during recovery');
    }
    let attempt = 0;
    for (;;) {
      let tmp = { ...acc[b.tile] };
      for (const f of b.fragments) tmp = over(f, tmp);
      if (attempt === 0 && step === failAtStep) {
        recoveries++;          // simulated VK_ERROR_DEVICE_LOST / device.lost
        attempt++;
        continue;              // discard staging, reload checkpoint, retry
      }
      acc[b.tile] = tmp;
      lastChunk[b.tile] = b.chunkIndex;
      break;
    }
    step++;
  }
  return { acc, recoveries };
}

// -------------------------------------------------------------- verification
function verifyGraph(graph, C, verbose = false) {
  const ref = renderReference(graph);
  const part = partition(graph, C);
  const sched = schedule(part);
  const got = execute(sched.order, graph.tiles);
  const rec = executeWithRecovery(sched.order, graph.tiles, 0);

  const counts = new Array(graph.tiles).fill(0);
  for (const f of graph.frags) counts[f.tile]++;

  const expectedPeak = counts.reduce((m, n) => Math.max(m, tightPeakForTile(n, C)), 0);
  const expectedPasses = counts.reduce((s, n) => s + minChunks(n, C), 0);

  const checks = {
    outputMatchesReference: ref.every((v, i) => close(v, got[i])),
    recoveryMatchesReference: ref.every((v, i) => close(v, rec.acc[i])),
    recoveryTriggered: rec.recoveries === (sched.order.length > 0 ? 1 : 0),
    peakEqualsTightBound: sched.peak === expectedPeak,
    peakWithinCapacity: sched.peak <= C,
    passesMinimal: sched.order.length === expectedPasses,
    allFragmentsOnce:
      part.bins.reduce((s, b) => s + b.size, 0) === graph.frags.length,
  };
  const ok = Object.values(checks).every(Boolean);
  if (verbose) {
    console.log('  tiles=%d capacity=%d fragments=%d', graph.tiles, C, graph.frags.length);
    console.log('  replay passes=%d  peak=%d  tight-bound=%d',
      sched.order.length, sched.peak, expectedPeak);
    for (const [k, v] of Object.entries(checks)) console.log('   %s %s', v ? 'PASS' : 'FAIL', k);
  }
  return { ok, checks, peak: sched.peak, expectedPeak, passes: sched.order.length, expectedPasses };
}

// ------------------------------------------------------- brute-force tightness
// For small n, enumerate every partition of n into exactly k = ceil(n/C)
// positive parts and confirm the balanced partition attains the minimum max
// part, i.e. no minimum-chunk partition can beat `tightPeakForTile`.
function compositions(n, k, prefix = [], out = []) {
  if (k === 0) { if (n === 0) out.push(prefix.slice()); return out; }
  for (let first = 1; first <= n - (k - 1); first++) {
    prefix.push(first);
    compositions(n - first, k - 1, prefix, out);
    prefix.pop();
  }
  return out;
}
function bruteForceTightness(maxN = 18) {
  for (let C = 1; C <= 6; C++) {
    for (let n = 1; n <= maxN; n++) {
      const k = minChunks(n, C);
      const parts = compositions(n, k);
      const best = Math.min(...parts.map(p => Math.max(...p)));
      if (best !== tightPeakForTile(n, C)) {
        return { ok: false, C, n, best, claim: tightPeakForTile(n, C) };
      }
    }
  }
  return { ok: true };
}

  for (let i = shuffled.frags.length - 1; i > 0; i--) {
    const j = Math.floor(rand() * (i + 1));
    [shuffled.frags[i], shuffled.frags[j]] = [shuffled.frags[j], shuffled.frags[i]];
  }
  const refA = renderReference(graph);
  const refB = renderReference(shuffled);
  const reorderOk = refA.every((v, i) => close(v, refB[i]));
  allOk &&= reorderOk;
  console.log('  submission-order shuffle preserves output: %s', reorderOk ? 'OK' : 'FAIL');

  console.log('\n[2b] blend law: associative but NOT commutative');
  {
    const a = { r: 0.2, g: 0.1, b: 0.3, a: 0.4 };
    const b = { r: 0.5, g: 0.25, b: 0.1, a: 0.7 };
    const c = { r: 0.05, g: 0.4, b: 0.2, a: 0.2 };
    const assoc = close(over(over(a, b), c), over(a, over(b, c)));
    const comm = close(over(a, b), over(b, a));
    allOk &&= assoc && !comm;
    console.log('  (a over b) over c == a over (b over c): %s', assoc ? 'OK' : 'FAIL');
    console.log('  a over b == b over a (must be false): %s', !comm ? 'OK' : 'FAIL');
    // Bin boundaries may regroup but never permute.
    const list = graph.frags.filter(f => f.tile === 0).map(f => f);
    const whole = list.reduce((acc, f) => over(f, acc), ZERO());
    const cut = Math.floor(list.length / 2);
    const grouped = over(
      list.slice(cut).reduce((acc, f) => over(f, acc), ZERO()),
      list.slice(0, cut).reduce((acc, f) => over(f, acc), ZERO()));
    const regroupOk = close(whole, grouped);
    allOk &&= regroupOk;
    console.log('  chunk/regroup across a bin boundary is exact: %s', regroupOk ? 'OK' : 'FAIL');
  }

  // 3. Device-loss recovery at several steps.

  const part = partition(graph, 7);
  const sched = schedule(part);
  const ref = renderReference(graph);
  let recOk = true;
  for (const failAt of [0, 1, Math.floor(sched.order.length / 2), sched.order.length - 1]) {
    const r = executeWithRecovery(sched.order, graph.tiles, failAt);
    const eq = ref.every((v, i) => close(v, r.acc[i]));
    recOk &&= eq && r.recoveries === 1;
    console.log('  ' + pad('failAtStep=' + failAt, 14) + pad('recoveries=' + r.recoveries, 13) +
      'match=' + (eq ? 'OK' : 'FAIL'));
  }
