Answer

Diagnosis

I found the live repo (totalwindupflightsystems/chimera), confirmed its CI is currently red (c769480, run 35355973875, test matrix → "Run unit tests" failure), and reproduced the exact error locally.

Root cause: tests/test_lsp_lint_plugins.py is designed to skip its behavioural probes when the optional pylsp server is absent (CI installs only -e ".[full]", which deliberately omits the dev extra). _load_lint_plugins() calls pytest.importorskip("pylsp") for that. But test_pyflakes_reports_an_undefined_name did:

from pylsp import lsp                     # runs first
diagnostics = _lint(_load_lint_plugins()["pyflakes"], ...)

The hard import executes before the guard, so Python raises ModuleNotFoundError instead of the intended skip. Locally .[dev] provides pylsp, so only CI failed.

Fix

Move the optional import after the guard (one hunk in tests/test_lsp_lint_plugins.py):

plugins = _load_lint_plugins()   # importorskip fires here when pylsp is absent
from pylsp import lsp
diagnostics = _lint(plugins["pyflakes"], _UNDEFINED_NAME_SOURCE)

This keeps pylsp in the dev extra only (never promotes it to full/core), so the LSP dependency contract is preserved, while the metadata/contract tests still run in CI.
