Fixing repeat collapse and chimeric bridging in an error-corrected OLC string-graph assembler

Environment: python3 (3.12+; verified 3.14.4) · zero dependencies Fast run: cd ~/olc && python3 olc_assembler.py && python3 -m unittest -v test_olc

1. Symptom

Naive greedy shortest-common-superstring (SCS) keys only on the longest suffix/prefix match. On a genome with an exact repeat longer than a read, both copies share sequence-identical interior reads, so greedy consumes the repeat once and collapses the two loci. A chimeric read adds a second failure: it has a valid-looking overlap on each half and fuses two unrelated loci.

Reproduced on the toy (repeat R = 21 bp, reads = 16 bp):

=== naive greedy SCS (straw man) ===
  contig length=65  repeat copies=1
  TCGACCTGAAGATTACAGGCCTTAAGCATGCGGTCCAATGCACCTTAAGGTGATTACAGGCCTTA

=== without chimeric screening ===
  len=82  repeat_x2  ...region1...region2...   (false fusion)

Correct answer = two 41 bp contigs, each containing R exactly once.

2. Root-cause analysis

2.1 Greedy SCS is a heuristic, not a layout. It ignores copy number, strand, the overlap error profile, and mate pairs. A repeat interior read is a branch (multiple predecessors/successors). Greedy cannot represent "traverse the branch once per copy".

2.2 Flat transitive reduction is unsound with long repeats. Edge u→w is transitive if a witness v satisfies ov(u,v)+ov(v,w) ≥ |v| and ov(u,w) = ov(u,v)+ov(v,w)-|v| (v fully covered). Deleting it only preserves the layout language if v has a unique placement (indeg(v)=outdeg(v)=1). With an exact repeat longer than a read, no read spans the repeat; every read wholly inside it has ≥2 contexts, so it is never a unique witness — using it can delete a true edge.

2.3 Chimeras are false high-scoring overlaps. The k-mer spanning the breakpoint exists only in that read. Mate distance scoring alone does not reject it (the fusion is linear and both internal pairs stay consistent), so it must be screened.

3. The fix (core pipeline)

overlap discovery (error profile, both strands)
  → chimeric screening (private junction k-mer)
  → string graph + containment removal
  → repeat-safe transitive reduction (unique non-branching witness only)
  → top-2 edge pruning
  → orientation/layout search: score = Σ overlap score + w · mate-pair linkage

3.1 Error-profile overlap scoring

def overlap(a, b, p=OverlapParams()):
    best = None
    for ov in range(max(p.min_overlap,1), min(len(a),len(b))+1):
        mm = sum(x != y for x, y in zip(a[-ov:], b[:ov]))
        if mm > p.max_error_rate * ov:
            continue
        if p.use_loglik:                      # LLR vs 25% random null
            e = max(p.error_rate, 1e-9)
            score = (ov-mm)*math.log((1-e)/0.25) + mm*math.log((e/3)/0.25)
        else:
            score = ov - p.mismatch_penalty * mm
        if best is None or score > best.score or (score == best.score and ov > best.ov):
            best = Overlap(ov, mm, score)
    return best

A long clean overlap now beats a longer error-rich one — greedy SCS cannot do this.

3.2 Repeat-safe transitive reduction (the correctness-critical part)

if (len(witnesses) == 1
        and self.indeg(witnesses[0]) == 1
        and self.outdeg(witnesses[0]) == 1):
    del self.adj[u][w]           # only a UNIQUE placement may delete an edge
    del self.radj[w][u]

Branching repeat vertices are never witnesses; their incident edges are retained.

3.3 Chimeric screening

# for each internal split of a read, the k-mer spanning the split must occur
# in at least one other read; a private junction k-mer marks a chimera.
for pos in range(min_flank, n - min_flank + 1):
    km = s[pos - k//2: pos + k//2 + 1]
    left, right = s[pos-min_flank:pos], s[pos:pos+min_flank]
    if both flanks seen elsewhere and no other read contains km:
        flagged[r.rid] = (pos, km)

3.4 Orientation/layout scoring

Only branch unitigs need a decision: a partial matching of in-edges to out-edges (size >1 ⇒ the repeat is traversed more than once). Coordinate descent maximizes

score(layout) = Σ_over_used_edges overlap_score + w · Σ_pairs linkage

with +w when mates land on one contig at the expected insert distance, -w/2 when they land on one contig at the wrong distance, 0 across contigs. Starting from the overlap-only (collapsing) solution, the mate-pair term forces the repeat to be traversed twice.

The complete ~700-line module (all helper functions, unitig contraction, greedy SCS straw man, demo) is embedded in SOLUTION.md and saved as olc_assembler.py. Key high-level entry point:

def assemble(reads, pairs, params=OverlapParams(), pair_weight=8.0,
             chim_k=7, chim_flank=7):
    flagged = detect_chimeric_reads(reads, k=chim_k, min_flank=chim_flank)
    kept = [r for r in reads if r.rid not in flagged]
    remap = {r.rid: i for i, r in enumerate(kept)}
    kept = [Read(remap[r.rid], r.seq, r.name) for r in kept]
    new_pairs = [Pair(remap[p.a], remap[p.b], p.insert, p.tol)
                 for p in pairs if p.a in remap and p.b in remap]
    g = Graph.build(kept, params)
    g.transitive_reduce()
    g.prune_edges(k_out=2, k_in=2)
    contigs, score, _ = assemble_with_pairs(g, new_pairs, pair_weight=pair_weight)
    seqs = {r.seq for r in kept}
    final, seen = [], set()
    for c in contigs:
        if not any(s in c for s in seqs):       # drop mirror-strand solutions
            continue
        key = min(c, revcomp(c))
        if key not in seen:
            seen.add(key); final.append(c)
    final.sort(key=len, reverse=True)
    return final, g, flagged, score

5. Correctness condition (the asked-for statement)

Removing a transitive edge (u,w) via a witness v (ov(u,v)+ov(v,w) ≥ |v| and ov(u,w) = ov(u,v)+ov(v,w)-|v|) preserves the set of genome-consistent layouts iff v is a unique witness, i.e. indeg(v) = outdeg(v) = 1. If the true genome contains an exact repeat longer than the read length, every read lying wholly inside the repeat has at least two distinct overlap contexts, so it is not a unique witness; reduction must therefore skip such branching reads and resolve the ambiguity using read-pair linkage. If the repeat is shorter than a read, a spanning read makes the witness unique and ordinary transitive reduction is sound.

Practical notes: swap _placements()'s exact search for an approximate mapper on real data; pick the largest odd k with ≥2× genomic k-mer support for chimera screening; seed the all-pairs overlap with a k-mer index for large inputs.
