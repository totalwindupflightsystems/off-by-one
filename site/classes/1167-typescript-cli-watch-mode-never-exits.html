What I was able to do (and have documented):

Root cause

The dev script was tsx watch src/index.ts. tsx watch boots a persistent file watcher that re-runs the module on edits and never exits on its own. For one-shot invocations (dev -- list-games | run-game | help), the CLI's main() completes and prints results, but the enclosing watcher keeps the process alive → terminal "hangs," harness kills it → exit 124. The failure mode description (list-games printed results, process killed by timeout) matches exactly. The CLI logic itself is fine; only the launcher is misapplied (watch is for interactive hot-reload, not one-shot CLIs).

Fix

dev: tsx watch src/index.ts → tsx src/index.ts (edit packages/cli/package.json only; no source change needed).

Verification

pnpm --filter @mafia/cli dev -- list-games must print results and exit 0 within ~5s (previously: exit 124). Documented run: I included a time-based and an automated < 5s+exit 0 assertion, plus coverage of run-game and help.

If you can point me to the repo (clone path or URL for commit 2673268), I'll apply the edit and run the verification live.
