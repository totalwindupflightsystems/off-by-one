Answer

CHT-153 — toolsd patch relative-header confinement escape

Symptom

toolsd patch accepts a diff whose +++ target is a relative path that escapes the documented patch root:

--- a/inside.txt
+++ b/../outside.txt
@@ -1 +1 @@
-outside-original
+pwned

The command exits 0, prints patched 1 file(s) atomically, writes ../outside.txt, and prints nothing on stderr. The create form is the decisive tell:

--- /dev/null
+++ b/../created.txt
@@ -0,0 +1 @@
+created-outside

A correct refusal must never create ../created.txt; the vulnerable build does.

Root cause

cmd/toolsd/main.go resolves every header target and then derives the write transaction's root from those same untrusted targets:

// the regression, abbreviated
targets[i] = resolveTarget(patchRoot, fp.Path)
txRoot := patchCommonDir(targets)          // deepest common dir of the targets
tx, _ := multifile.Begin(txRoot)

internal/multifile then enforces its real guard:

// multifile.resolve
if !inside(tx.root, absTarget) {
    return ErrPathOutsideDir   // "path outside transaction dir"
}

That guard is correct, but it is now vacuous for the escaping target: patchCommonDir moves txRoot up to the parent directory so that it always contains the escape. For root = /work/repo and target ../outside.txt, the transaction root becomes /work, and /work/outside.txt is trivially inside /work. The check can never fire.

Before the absolute-header feature landed, the transaction was rooted unconditionally at the patch root (filepath.Dir(diffFile)), so the same escape was refused. The absolute-header feature was legitimate (git-apply parity) but it regressed an existing guard by making the transaction root a function of the paths it is supposed to sandbox. No test pinned the relative-escape spelling, so nothing caught it.

The sibling apply verb stages through the same internal/multifile transaction layer but anchors its root independently; it refused the identical escape. That isolates the defect to target-root derivation in cmd/toolsd/main.go, not to internal/multifile.

General rule: a sandbox/containment root must never be computed from the paths it contains. Keep the root an independent input, validate membership per target, and test the escape in every spelling (relative, nested, create, stdin).

Exact fix

1. cmd/toolsd/main.go — validate relative targets against an independent root

Resolve the patch root once to an absolute cleaned path. Absolute header targets remain verbatim. Relative header targets must stay inside the patch root, checked component-wise with filepath.Rel (never strings.HasPrefix). Keep patchCommonDir only for staging absolute targets.

// patchTarget resolves one unified-diff header target against the patch root.
//
// Absolute targets are honored verbatim (git-apply parity); their
// transaction root is opened up separately by patchCommonDir. Relative
// targets must stay inside the patch root. Containment is component-wise:
// filepath.Rel, not a string-prefix test -- /srv/rooted is NOT inside
// /srv/root.
func patchTarget(root, spelled string) (string, error) {
    if filepath.IsAbs(spelled) {
        return filepath.Clean(spelled), nil
    }
    target := filepath.Clean(filepath.Join(root, spelled))
    rel, err := filepath.Rel(root, target)
    if err != nil || filepath.IsAbs(rel) ||
        rel == ".." || strings.HasPrefix(rel, ".."+string(filepath.Separator)) {
        return "", fmt.Errorf("relative target %q escapes patch root %s", spelled, root)
    }
    return target, nil
}

// patchCommonDir returns the deepest directory containing every resolved
// target. It exists only so absolute header targets can be staged outside
// the patch root. It is NOT a containment boundary and must never be used
// as one.
func patchCommonDir(targets []string) string {
    if len(targets) == 0 {
        return "."
    }
    common := filepath.Dir(targets[0])
    for _, t := range targets[1:] {
        dir := filepath.Dir(t)
        for !sameOrUnder(common, dir) {
            parent := filepath.Dir(common)
            if parent == common {
                break
            }
            common = parent
        }
    }
    return common
}

func sameOrUnder(root, target string) bool {
    rel, err := filepath.Rel(root, target)
    return err == nil && !filepath.IsAbs(rel) &&
        rel != ".." && !strings.HasPrefix(rel, ".."+string(filepath.Separator))
}

Wire it into runPatch. The important changes:

// resolve the patch root ONCE, absolute and clean.
//   diff file form: root = filepath.Dir(absDiffPath)
//   stdin form:     root = absolute current working directory
root, err := filepath.Abs(root)
if err == nil {
    root = filepath.Clean(root)
}

// existing error-report path: prints "toolsd: patch: <err>", prints the
// standard rollback line, and marks usage.Rollback. Use it for escapes too,
// so the refusal carries the same rollback evidence as a transaction error.
fail := func(err error) int {
    fmt.Fprintf(stderr, "toolsd: patch: %v\n", err)
    fmt.Fprintln(stderr, "toolsd: patch: rolled back - no files in the tree were modified")
    if rec != nil {
        rec.Rollback()
    }
    return 1
}

// resolve/validate every target against the independent patch root.
targets := make([]string, len(patches))
for i, fp := range patches {
    target, err := patchTarget(root, fp.Path)
    if err != nil {
        return fail(err)
    }
    targets[i] = target
}

// transaction root is still the common dir of the RESOLVED targets, so an
// absolute header can stage outside the patch root; containment was already
// enforced above, per relative target.
tx, err := multifile.Begin(patchCommonDir(targets))
if err != nil {
    return fail(err)
}

Do not change internal/multifile; its ErrPathOutsideDir check is correct. The regression is fixed by not letting the untrusted target choose its own sandbox.

#!/usr/bin/env bash
# CHT-153 battery. Usage: TOOLSD=/path/to/toolsd ./cht153_battery.sh
set -u
BIN="${TOOLSD:-/usr/local/bin/toolsd}"
T="$(mktemp -d)"; trap 'rm -rf "$T"' EXIT
ROOT="$T/root"; mkdir -p "$ROOT/sub"
pass=0; fail=0
chk() { if [ "$2" = "$3" ]; then echo "PASS $1"; pass=$((pass+1));
        else echo "FAIL $1 (want $2 got $3)"; fail=$((fail+1)); fi; }

# 1: relative edit escape -> refused, outside byte-identical
printf 'outside-original\n' > "$T/outside.txt"
cat > "$ROOT/edit.diff" <<'D'
--- a/inside.txt
+++ b/../outside.txt
@@ -1 +1 @@
-outside-original
+pwned
D
"$BIN" patch "$ROOT/edit.diff" >/dev/null 2>"$T/e1"; rc=$?
if [ "$rc" -ne 0 ] && [ "$(cat "$T/outside.txt")" = "outside-original" ] && grep -q 'escapes patch root' "$T/e1"
then chk "1 relative edit escape refused, outside byte-identical" ok ok
else chk "1 relative edit escape refused, outside byte-identical" ok "rc=$rc outside=$(cat "$T/outside.txt")"; fi

# 2: /dev/null create escape -> refused, never created

--- /dev/null
+++ ../created.txt
@@ -0,0 +1 @@
+created-outside
D
"$BIN" patch "$ROOT/create.diff" >/dev/null 2>"$T/e2"; rc=$?
if [ "$rc" -ne 0 ] && [ ! -e "$T/created.txt" ]
then chk "2 create escape refused, outside never created" ok ok
else chk "2 create escape refused, outside never created" ok "rc=$rc created=$([ -e "$T/created.txt" ] && echo yes || echo no)"; fi

# 3: nested spelling -> refused
printf 'outside-original\n' > "$T/outside.txt"

+++ b/sub/../../outside.txt
@@ -1 +1 @@
-outside-original
+nested-pwn

"$BIN" patch "$ROOT/nested.diff" >/dev/null 2>"$T/e3"; rc=$?
if [ "$rc" -ne 0 ] && [ "$(cat "$T/outside.txt")" = "outside-original" ]

# 4: stdin form -> refused with named refusal

@@ -1 +1 @@
-outside-original

# 5: absolute header applies verbatim (regression guard)

+++ $ABS
@@ -0,0 +1 @@
+absnew
D
"$BIN" patch "$ROOT/abs.diff" >/dev/null 2>"$T/e5"; rc=$?
if [ "$rc" -eq 0 ] && [ "$(cat "$ABS")" = "absnew" ]
then chk "5 absolute header applies verbatim" ok ok
else chk "5 absolute header applies verbatim" ok "rc=$rc abs=$(cat "$ABS" 2>/dev/null)"; fi

# 6: in-root subdirectory still applies (no over-blocking)

-subold
