go-async-node-promise-swallow

Answer

Root cause. The DAG engine evaluates a node by inlining the node's JS function source and stringifying the result, roughly JSON.stringify((fn)(prev)). When fn is async, the call returns a Promise. JSON.stringify(promise) yields "{}" because a Promise has no enumerable own properties — the resolved value is silently dropped. Worse, rejections are never awaited, so node errors vanish too.

Fix. Wrap every node invocation so the engine awaits the completion value before stringifying:

(async () => JSON.stringify(await ((fn))(prev)))()

The shape is deliberate: the double parens ((fn)) let fn be any function-source expression (arrow, named async function, or a callable expression); await resolves the promise (and flattens nested thenables); JSON.stringify runs after settlement so the engine's completion value is a JSON string; the trailing () invokes the IIFE so the script's top-level completion is the settled promise the engine extracts.

Go engine code (the actual fix):

// rawJSWrap wraps a node fn so the engine awaits its completion value.
// Exact RawJS contract (unit-tested byte-for-byte):
//   (async () => JSON.stringify(await ((fn))(prev)))()
func rawJSWrap(fn, prev string) string {
    return "(async () => JSON.stringify(await ((" + fn + "))(" + prev + ")))()"
}

// evalNode runs one DAG node. prev = prior node's output (JSON string),
// fn = node's raw JS source. The engine evals the wrap and, because the
// top-level script is an async IIFE, its job loop has already settled the
// promise by the time RunString returns; we just extract the value.
func evalNode(vm *goja.Runtime, prev, fn string) (string, error) {
    v, err := vm.RunString(rawJSWrap(fn, prev))
    if err != nil {
        return "", fmt.Errorf("eval: %w", err)
    }
    p, ok := v.Export().(*goja.Promise)
    if !ok { // fully-synchronous fn: completion value is the JSON string
        return v.String(), nil
    }
    switch p.State() {
    case goja.PromiseStateFulfilled:
        return p.Result().String(), nil
    case goja.PromiseStateRejected:
        return "", fmt.Errorf("node fn rejected: %v", p.Result())
    default:
        return "", fmt.Errorf("node fn promise never settled")
    }
}

Unit test asserting the exact RawJS wrap:

func TestRawJSWrapExact(t *testing.T) {
    fn, prev := "async (prev) => ({ v: 42 })", `{"seed":1}`
    want := `(async () => JSON.stringify(await ((async (prev) => ({ v: 42 })))({"seed":1})))()`
    if got := rawJSWrap(fn, prev); got != want {
        t.Fatalf("rawJSWrap mismatch:\n got: %s\nwant: %s", got, want)
    }
}
