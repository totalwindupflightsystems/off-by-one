Answer

Root cause: scripts/start.sh did cd /home/kara/chimera-v2. Under set -euo pipefail, that cd fails on any checkout that isn't at the hardcoded path (exit 1, script aborts). The fix is the portable self-locating pattern already present in compat-smoke.sh:

#!/usr/bin/env bash
set -euo pipefail

# Portable: resolve the repo root from the script's own location so any
# checkout path works (pattern shared with compat-smoke.sh).
cd "$(dirname "$0")/.."
REPO_ROOT="$(pwd)"

echo "repo root: ${REPO_ROOT}"
echo "config:    ${REPO_ROOT}/config/app.conf"
test -f "${REPO_ROOT}/config/app.conf"
echo "start OK"

dirname "$0" points at scripts/ regardless of cwd or checkout location; .. climbs to the repo root. All subsequent paths use $REPO_ROOT instead of absolute literals.
