Offline ZFS scrub/resilver txg boundary audit

Root-cause analysis

The task is not "diff two txg numbers". A naive analyzer fails because ZFS txg arithmetic has three independent boundary semantics that each turn the same timeline into a different verdict:

  1. Scrub end txg is exclusive. A scrub recorded as scrub_end: 100 has covered txgs [scrub_start, 100), i.e. up to and including 99. Txg 100 itself was never scanned. Treating the interval as closed (<= 100) hides exactly one txg of dirt — and that txg is usually the one a resilver is about to rely on. This is why the canonical "scrub ends at 100" fixture must report a gap at 100.
  2. Deferred resilver frees are charged to resilver_start_txg, not to the flush txg. A free that is actually flushed at txg 120 during a resilver that began at txg 100 is accounted at 100. If the analyzer uses the raw flush txg (120) as the dirty point, it reports a coverage hole that does not exist. So the dirty window for a vdev is bounded above by resilver_start_txg, regardless of when the free hit the log.
  3. The uberblock ring holds only 128 entries. Any txg span wider than 128 is no longer fully present on disk, so it is unobservable, not dirty. It must be reported as "wrapped": true and must not be turned into a coverage hole. Flow control here matters: the wrap check must run before the per-txg ring-membership check and before the coverage loop.

A second failure mode is input trust. Event streams are produced by tools and operators, so the analyzer must reject internally inconsistent bounds instead of emitting a plausible-looking verdict: end < start on a scrub, resilver, or attach event, and a needed interval whose txgs are simply absent from the ring (a real discontinuity, as opposed to a legitimate >128 wrap). The diagnostic must name the offending event (file + line + fields), and the process must exit non-zero.

Reconstructed semantics used by the implementation

  • A completed scrub pair (S, E) covers the half-open txg set [S, E-1].
  • A vdev's dirty-before-resilver window is [A, R] inclusive, where A is the attach txg (falling back to the first ring sighting) and R is resilver_start_txg. R is included because deferred frees are charged there (trap 2).
  • uncovered = [A, R] \ union(coverage of all completed scrubs).
  • verdict = "gap" iff uncovered is non-empty; first_uncovered_txg is the first uncovered txg; ranges are the uncovered inclusive ranges.
  • If R - A + 1 > 128, the span is unobservable: wrapped = true, verdict = "covered", first_uncovered_txg = null, ranges = [].
  • Otherwise every txg in [A, R] must be present in the ring or the run aborts with exit code 2.

Output is JSONL, one object per vdev, sorted lexicographically by vdev.

Fix

zfs_scrub_audit.sh (bash 5 + jq + awk, no live zpool). Save it, chmod +x, and run ./zfs_scrub_audit.sh <fixture-dir>.

#!/usr/bin/env bash
#
# zfs_scrub_audit.sh -- offline ZFS scrub/resilver txg boundary auditor.
#
# Reconstructs a pool txg timeline from an offline fixture directory and, for
# every vdev, decides whether the last completed scrub covered every block
# dirtied before that vdev's resilver began.
#
# Usage: zfs_scrub_audit.sh <fixture-dir>
#
#   <fixture-dir>/uberblocks.jsonl  one uberblock-ring dump per line:
#        {"txg":N,"timestamp":...,"guid":...,"ring_index":N,"vdevs":[...]}
#   <fixture-dir>/events.jsonl      timeline events:
#        {"type":"scrub_start","txg":N}
#        {"type":"scrub_end","txg":N}          # end txg is EXCLUSIVE
#        {"type":"resilver_start","txg":N,"vdev":"PATH"}
#        {"type":"resilver_end","txg":N,"vdev":"PATH"}
#        {"type":"vdev_attach","txg":N,"vdev":"PATH",
#         "resilver_start_txg":N,"resilver_end_txg":N}
#
# Output: JSONL sorted by vdev path, one object per vdev:
#   {"vdev":...,"verdict":"covered|gap","first_uncovered_txg":N|null,
#    "ranges":[[start,end],...],"wrapped":bool}
#
# Exit codes:
#   0  audit produced
#   1  usage / IO error
#   2  inconsistent txg bounds (diagnostic names the offending event)
#
set -euo pipefail

# ---------------------------------------------------------------------------
# helpers
# ---------------------------------------------------------------------------
prog=${0##*/}

die() { printf '%s: error: %s\n' "$prog" "$*" >&2; exit 1; }

usage() {
  printf 'usage: %s <fixture-dir>\n' "$prog" >&2
  exit 1
}

# ---------------------------------------------------------------------------
# arguments
# ---------------------------------------------------------------------------
[[ $# -eq 1 ]] || usage
DIR=$1
[[ -d "$DIR" ]] || die "fixture directory not found: $DIR"

UB=$DIR/uberblocks.jsonl
EV=$DIR/events.jsonl
[[ -f "$UB" ]] || die "missing uberblock dump: $UB"
[[ -f "$EV" ]] || die "missing event log: $EV"

command -v jq >/dev/null 2>&1 || die "jq is required"
command -v awk >/dev/null 2>&1 || die "awk is required"

# Ring capacity.  The uberblock ring keeps the most recent 128 entries, so any
# txg span wider than this cannot be fully reconstructed -- it is "wrapped".
RING_CAP=128

# ---------------------------------------------------------------------------
# Normalise events into a TSV stream:
#   line  type  txg  vdev  start_txg  end_txg
# input_line_number gives the physical line in events.jsonl so diagnostics can
# name the offending event precisely.
# ---------------------------------------------------------------------------
EV_TSV=$(
  jq -r -n '
    inputs
    | [ (input_line_number|tostring),
        (.type // ""),
        (.txg // "" | tostring),
        (.vdev // .path // ""),
        ((.start_txg // .resilver_start_txg // "") | tostring),
        ((.end_txg   // .resilver_end_txg   // "") | tostring)
      ] | @tsv' "$EV"
)

# Normalise the uberblock ring.  A vdev tree may be a flat array of paths, an
# object, or nested; we harvest every path/name at any depth.
UB_TSV=$(
  jq -r '
    [ (.txg // -1 | tostring),
      (.ring_index // -1 | tostring),
      ([.. | objects | (.path // .name) | strings] | unique | join(","))
    ] | @tsv' "$UB"
)

# ---------------------------------------------------------------------------
# Timeline reconstruction + boundary audit.
# ---------------------------------------------------------------------------
RESULT=$(
  awk -v EV_TSV="$EV_TSV" -v UB_TSV="$UB_TSV" -v CAP="$RING_CAP" '
  # ---------------- pass over events ----------------
  function ev_err(msg) { err[++nerr] = msg }

  BEGIN {
    FS = "\t"; OFS = "\t"
    nsc = 0; nerr = 0; have_ss = 0
    n = split(EV_TSV, lines, "\n")
    for (li = 1; li <= n; li++) {
      if (lines[li] == "") continue
      m = split(lines[li], f, "\t")
      ln = f[1]; type = f[2]; txg = f[3]; vdev = f[4]; s = f[5]; e = f[6]

      if (type == "scrub_start") {
        # A new scrub_start without an intervening scrub_end means the previous
        # scrub was interrupted/aborted; it never completed, so drop it.
        ss = txg + 0; ss_ln = ln; have_ss = 1
      }
      else if (type == "scrub_end") {
        if (!have_ss) {
          ev_err("events.jsonl:" ln ": scrub_end (txg=" txg ") has no preceding scrub_start")
          continue
        }
        if ((txg + 0) < ss) {
          ev_err("events.jsonl:" ln ": scrub_end txg=" txg " < scrub_start txg=" ss)
          have_ss = 0
          continue
        }
        nsc++
        cstart[nsc] = ss; cend[nsc] = txg + 0
        have_ss = 0
      }
      else if (type == "resilver_start") {
        if (vdev == "") { ev_err("events.jsonl:" ln ": resilver_start missing vdev"); continue }
        rlstart[vdev] = txg + 0; rlstart_ln[vdev] = ln
        if (!(vdev in attach)) { attach[vdev] = txg + 0; attach_ln[vdev] = ln }
      }
      else if (type == "resilver_end") {
        if (vdev == "") { ev_err("events.jsonl:" ln ": resilver_end missing vdev"); continue }
        if ((vdev in rlstart) && (txg + 0) < rlstart[vdev]) {
          ev_err("events.jsonl:" ln ": resilver_end txg=" txg " < resilver_start txg=" rlstart[vdev] " for vdev " vdev)
          continue
        }
        rlend[vdev] = txg + 0
      }
      else if (type == "vdev_attach") {
        if (vdev == "") { ev_err("events.jsonl:" ln ": vdev_attach missing vdev"); continue }
        attach[vdev] = txg + 0; attach_ln[vdev] = ln
        if (s != "") { rlstart[vdev] = s + 0; rlstart_ln[vdev] = ln }
        if (e != "") { rlend[vdev] = e + 0 }
        if (s != "" && e != "" && (e + 0) < (s + 0)) {
          ev_err("events.jsonl:" ln ": vdev_attach resilver_end txg=" e " < resilver_start txg=" s " for vdev " vdev)
        }
      }
      # unknown event types are intentionally ignored
    }
  }

  END {
    # ---------------- pass over the uberblock ring ----------------
    nr = split(UB_TSV, ulines, "\n")
    for (ui = 1; ui <= nr; ui++) {
      if (ulines[ui] == "") continue
      k = split(ulines[ui], uf, "\t")
      utxg = uf[1] + 0
      ring[utxg] = 1
      p = uf[3]
      np = split(p, ap, ",")
      for (pi = 1; pi <= np; pi++) {
        pv = ap[pi]
        if (pv == "") continue
        seen[pv] = 1
        if (!(pv in firstseen) || utxg < firstseen[pv]) firstseen[pv] = utxg
      }
    }

    # ---------------- inconsistent bounds: fail before auditing ----------------
    if (nerr > 0) {
      for (i = 1; i <= nerr; i++) print "ERROR: " err[i] > "/dev/stderr"
      exit 2
    }

    # ---------------- union of vdevs ----------------
    nv = 0
    for (v in seen) if (!(v in vseen)) { vseen[v] = 1; vlist[++nv] = v }
    for (v in rlstart) if (!(v in vseen)) { vseen[v] = 1; vlist[++nv] = v }

    for (vi = 1; vi <= nv; vi++) {
      v = vlist[vi]

      # Lower bound of the dirtied window: attach txg, else first ring sighting.
      if (v in attach) { A = attach[v]; Aln = attach_ln[v] }
      else if (v in firstseen) { A = firstseen[v]; Aln = "" }
      else { A = 0; Aln = "" }

      # Upper bound: resilver start.  No resilver => nothing pre-resilver to
      # audit; report covered.
      if (!(v in rlstart)) {
        printf "%s|covered||false|\n", v
        continue
      }
      R = rlstart[v]; Rln = rlstart_ln[v]
      span = R - A + 1

      if (span < 0) {
        printf "ERROR: vdev %s: attach txg %d > resilver_start txg %d (event events.jsonl:%s)\n", v, A, R, Rln > "/dev/stderr"
        exit 2
      }

      # ---- TRAP 3: ring wrap -------------------------------------------
      # A span wider than the 128-entry ring is unobservable.  Mark wrapped
      # and do NOT report it as a coverage hole.
      if (span > CAP) {
        printf "%s|covered||true|\n", v
        continue
      }

      # ---- ring presence check -----------------------------------------
      # The dirtied interval must be fully represented in the ring, otherwise
      # the timeline cannot be trusted.
      missing = -1
      for (t = A; t <= R; t++) if (!(t in ring)) { missing = t; break }
      if (missing != -1) {
        evref = (Rln != "") ? ("events.jsonl:" Rln " (resilver_start)") : ("vdev " v)
        printf "ERROR: interval [%d,%d] for vdev %s absent from uberblock ring (missing txg %d); offending event %s\n", A, R, v, missing, evref > "/dev/stderr"
        exit 2
      }

      # ---- TRAP 1 + union of completed scrub coverage ------------------
      # A scrub (S,E) covers [S, E-1]: the end txg is exclusive.
      ranges = ""; first = ""; inrun = 0
      for (t = A; t <= R; t++) {
        cov = 0
        for (j = 1; j <= nsc; j++) {
          if (t >= cstart[j] && t <= cend[j] - 1) { cov = 1; break }
        }
        if (!cov) {
          if (!inrun) { rs = t; inrun = 1 }
          re = t
        } else if (inrun) {
          ranges = ranges (ranges == "" ? "" : ",") rs "-" re
          if (first == "") first = rs
          inrun = 0
        }
      }
      if (inrun) {
        ranges = ranges (ranges == "" ? "" : ",") rs "-" re
        if (first == "") first = rs
      }

      if (ranges == "") printf "%s|covered||false|\n", v
      else              printf "%s|gap|%d|false|%s\n", v, first, ranges
    }
  }
  ' </dev/null
) || exit $?

# ---------------------------------------------------------------------------
# Emit JSONL, sorted by vdev path.
# ---------------------------------------------------------------------------
if [[ -n "$RESULT" ]]; then
  while IFS='|' read -r vdev verdict first wrapped ranges; do
    [[ -n "$vdev" ]] || continue
    jq -nc \
      --arg vdev "$vdev" \
      --arg verdict "$verdict" \
      --arg first "$first" \
      --arg wrapped "$wrapped" \
      --arg ranges "$ranges" '
      {
        vdev: $vdev,
        verdict: $verdict,
        first_uncovered_txg: (if $first == "" then null else ($first | tonumber) end),
        ranges: (if $ranges == "" then []
                 else ($ranges | split(",") | map(split("-") | map(tonumber)))
                 end),
        wrapped: ($wrapped == "true")
      }'
  done < <(printf '%s\n' "$RESULT" | sort -t '|' -k1,1)
fi

#!/usr/bin/env bash
# Regenerates every fixture under ./fixtures. Used by verify.sh.
set -euo pipefail
base=$(cd "$(dirname "$0")" && pwd)
root=$base/fixtures
rm -rf "$root"
mkdir -p "$root"

# ring <start> <end> <vdev-csv>  -> prints uberblock jsonl
ring() {
  local s=$1 e=$2 v=$3 i
  for ((i=s; i<=e; i++)); do
    printf '{"txg":%d,"timestamp":%d,"guid":"g0","ring_index":%d,"vdevs":[{"path":"%s"}]}\n' \
      "$i" "$((1700000000+i))" "$((i%128))" "$v"
  done
}

# ---- 1. covered: scrub end (101) is past resilver start (100) ------------
d=$root/covered; mkdir -p "$d"
ring 80 110 "tank/d1" > "$d/uberblocks.jsonl"
cat > "$d/events.jsonl" <<'EOF'
{"type":"vdev_attach","txg":85,"vdev":"tank/d1","resilver_start_txg":100,"resilver_end_txg":130}
{"type":"scrub_start","txg":80}
{"type":"scrub_end","txg":101}
EOF

# ---- 2. end_exclusive: scrub ends AT 100, so txg 100 is a hole -----------

Note on the read/IFS pitfall

The internal awk→bash handoff uses | as the field delimiter, not a tab. read treats tabs as IFS whitespace and collapses runs of them, which loses the empty first_uncovered_txg field and shifts every following column. Using a non-whitespace delimiter keeps empty fields intact. This was caught by the very first run and is why the result stream uses |.
