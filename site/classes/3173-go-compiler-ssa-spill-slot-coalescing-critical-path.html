Answer

Spill-Slot Coalescing Across Loop Back Edges — Diagnosis and Verified Fix

The complete, runnable solution is at ~/spillcoalesce/SOLUTION.md, with sources in the same directory. Everything below is reproducible with go1.26.8 linux/amd64.

Root-cause analysis

The bug is not in the greedy allocator; it is in the interference graph supplied to it.

Interference over machine basic blocks is built from:

  • a clique over LiveIn(b) and LiveOut(b) for each block,
  • within each block, def(v) interfering with every value live immediately after v.

When critical edges are split, the split block sits on the edge — here on the loop back edges inner.crit -> inner.header and outer.crit -> outer.header. If interference is computed from a stale, pre-split view (or a cached pre-split live table), those split blocks are omitted. Consequently:

  1. The defs that exist only on the back-edge critical path get zero interference edges.
  2. The coalescer sees them as free and packs them into the same stack slot as a loop-carried value that is live across the back edge.
  3. On the next iteration the header reads the carried value and instead gets a critical-path temporary — a silent miscompile.

On the supplied nested-loop / register-pressure-cliff function, the unguarded allocator produces 4 unsafe shared-slot violations: v0 merged with v8,v9 on the outer back edge and with v10,v11 on the inner back edge.

Exact fix

Re-establish the lost interference for every critical block C whose successor H is dominated by C (so C -> H is a back edge), and attach a concrete witness to every added edge:

func addCriticalGuards(p *Program, dom []map[int]bool, g *Interference) []Witness {
    var ws []Witness
    for _, b := range p.Blocks {
        if !b.Critical {
            continue
        }
        head := -1
        for _, s := range b.Succs {
            if dom[b.ID][s] { // b->s is a back edge
                head = s
                break
            }
        }
        if head < 0 {
            continue
        }

        var critDefs []ValueID
        for _, op := range b.Ops {
            if op.Def != NoValue {
                critDefs = append(critDefs, op.Def)
            }
        }
        live := make([]ValueID, 0, len(b.LiveIn))
        for v := range b.LiveIn {
            live = append(live, v)
        }
        sort.Slice(live, func(i, j int) bool { return live[i] < live[j] })

        // Core safety edge: carried value vs critical-path definition.
        for _, v := range live {
            for _, w := range critDefs {
                if v == w {
                    continue
                }
                wit := Witness{Kind: "backedge-critical", Tail: b.ID, Head: head, Block: b.ID, A: v, B: w}
                ws = append(ws, wit)
                g.add(v, w, wit)
            }
        }

        // Restore the entry-live clique the pre-split pass never built.
        for i := 0; i < len(live); i++ {
            for j := i + 1; j < len(live); j++ {
                wit := Witness{Kind: "critical-entry-live", Tail: b.ID, Head: head, Block: b.ID, A: live[i], B: live[j]}
                ws = append(ws, wit)
                g.add(live[i], live[j], wit)
            }
        }

        // Genuine intra-block interference: replay backwards from LiveOut.
        // Do NOT add a clique over all defs; sequential defs are non-interfering.
        liveSet := map[ValueID]bool{}
        for v := range b.LiveOut {
            liveSet[v] = true
        }
        for i := len(b.Ops) - 1; i >= 0; i-- {
            op := b.Ops[i]
            if op.Def != NoValue {
                for v := range liveSet {
                    if v == op.Def {
                        continue
                    }
                    wit := Witness{Kind: "critical-def-live", Tail: b.ID, Head: head, Block: b.ID, A: op.Def, B: v}
                    ws = append(ws, wit)
                    g.add(op.Def, v, wit)
                }
                delete(liveSet, op.Def)
            }
            for _, u := range op.Uses {
                liveSet[u] = true
            }
        }
    }
    return ws
}

The coalescer records a Rejection{V, SlotID, Conflict, Witness} for every declined merge, so no rejection is witness-free.
