Multipath QUIC PMTUD Black-Hole Recovery Harness

Deliverable: a self-contained, deterministic shell harness that generates fault-injection traces, streams them through a bounded-memory analyzer, and emits per-path safe datagram limits + retransmission policy. Saved at /workspace/harness/quic_pmtud_harness.sh.

Root-cause analysis

A multipath QUIC sender cannot tell "the path shrank" from "the path is congested" from "the path was never really validated", because all three look like the same thing on the wire: a large flight of packets disappears. Naive recovery loops conflate three independent signals and therefore fail in three ways:

  1. Loss is always treated as congestion. The sender halves cwnd, retransmits at the same size, and the black hole persists forever (classic PMTU black hole). Symptom: repeated loss of one size class, no CE marks, no loss at the 1200-byte floor, and smaller packets still delivered.
  2. ICMP PTB is treated as immortal truth. A PTB generated before a route change or a path migration arrives late (or references an old path generation) and permanently pins the path to an artificially small MTU even though 1400/1500-byte datagrams are provably being delivered after it.
  3. A challenged path is treated as usable. After migrate, the new path has no validated MTU; sending full-size data there turns a migration into a stall. Meanwhile the old path is discarded, so the connection dies.

Two engineering constraints make the obvious fixes (store every packet, replay offline, seed a random prober) unacceptable: the analyzer must run in bounded memory while producing a deterministic recovery trace.

The fix is a small per-path state machine that separates the evidence channels and only commits conservative state:

  • Bucket outcomes by an MTU ladder; a true black hole is a size cliff: delivery=0 at the first bad rung and every larger rung, with a proven delivery below it, loss>=2, zero loss at the 1200 floor, and no ECN CE. If smaller sizes also fail, or CE marks exist, it is congestion.
  • Accept a PTB only for the current path generation and ≥1200 bytes. If a delivery larger than the PTB's advertised MTU occurs after the PTB, the PTB is stale/wrong: revoke it and count a conflict.
  • Treat an un-answered PATH_CHALLENGE with no delivered data in the current generation as stale validation; never shrink the path's MTU on congestion, and keep the last validated path as fallback across migrate.
  • Fold each evidence epoch (closed by migration, an MTU change, or a changed PTB) into a per-path minimum, then reset counters. State is O(paths × rungs); no per-packet storage.

Exact fix

The harness has a deterministic trace generator (gen), a streaming awk analyzer (replay), and an assertion suite (selftest).

#!/usr/bin/env bash
# quic_pmtud_harness.sh
# Fault-injection harness + streaming analyzer for multipath QUIC PMTUD
# black-hole recovery.
#
#   gen <scenario>      emit a deterministic fault-injection trace on stdout
#   replay [file]       analyze a trace (stdin if no file) and emit the
#                       deterministic recovery trace + summary
#   selftest            run all built-in scenarios and assert expected results
#   hash <scenario>     emit the sha256 of the recovery trace for a scenario
#
# Trace grammar (whitespace separated key=value, order independent):
#   t=<sec> path=<id> ev=<event> [size=..] [mtu=..] [gen=..] [ce=..] [ect=..]
#   [from=..] [to=..]
# Events: challenge | challenge_ack | send | delivered | lost | icmp_ptb |
#         migrate | ecn_ce | mtu_change
#
# Memory is O(paths * rungs) and never grows with packet count: no per-packet
# arrays, no random seeds. Output is insertion-ordered, so it is deterministic.
set -uo pipefail

VERSION="5"

AWK_PROG=$(cat <<'AWK'
BEGIN {
  # Conservative MTU ladder (QUIC's 1200 floor up to Ethernet 1500).
  n = split("1200 1252 1280 1300 1360 1400 1420 1440 1452 1460 1472 1500", LAD, " ")
  MAXPATH  = 64
  MINSAMP  = 2      # outcomes needed before a rung is trusted
  GOOD     = 0.80   # a rung method is "good" at/above this delivery ratio
  BAD      = 0.25   # a rung method is "bad" at/below this delivery ratio
  npaths   = 0
}
function rung(sz,   i) {
  if (sz < LAD[1]) return 1
  for (i = n; i >= 1; i--) if (sz >= LAD[i]) return i
  return 1
}
function addpath(p) {
  if (!(p in seen)) {
    if (npaths >= MAXPATH) { capped = 1; return 0 }
    seen[p] = 1; npaths++; order[npaths] = p
  }
  return 1
}
function reset_counters(p,   r) {
  for (r = 1; r <= n; r++) { deliv[r,p] = 0; loss[r,p] = 0; sent[r,p] = 0 }
  ce[p] = 0; ect[p] = 0; maxdeliv[p] = 0; ptb[p] = 0; ptb_t[p] = 0
}

# Classify the *current* epoch of path p. Populates the CL_* globals and the
# epoch-safe estimate CL_safe. Pure function of the current counters.
function classify(p,   r, denom, ratio, firstbad, goodbelow, clean, td, tl, spread, cand, es) {
  td = 0; tl = 0; spread = 0
  for (r = 1; r <= n; r++) { td += deliv[r,p]; tl += loss[r,p]; if (loss[r,p] > 0) spread++ }

  # First rung with a demonstrated size cliff (ratio at/below BAD).
  firstbad = -1
  for (r = 1; r <= n; r++) {
    denom = deliv[r,p] + loss[r,p]
    if (denom >= MINSAMP) {
      ratio = deliv[r,p] / denom
      if (ratio <= BAD && firstbad == -1) firstbad = r
    }
  }
  goodbelow = 0
  for (r = 1; r <= n; r++)
    if (deliv[r,p] > 0 && (firstbad == -1 || r < firstbad)) goodbelow = 1

  # A TRUE black hole: zero delivery at the first bad rung and at every larger
  # rung, a proven delivery below it, no loss at the 1200 floor, and no ECN CE.
  clean = 0
  if (firstbad >= 2 && goodbelow && maxdeliv[p] > 0 && loss[firstbad,p] >= MINSAMP) {
    clean = 1
    if (deliv[firstbad,p] > 0) clean = 0
    for (r = firstbad + 1; r <= n; r++) if (deliv[r,p] > 0) clean = 0
  }
  CL_td = td; CL_tl = tl; CL_spread = spread
  CL_firstbad = firstbad; CL_clean = clean
  CL_r1loss = loss[1,p]
  CL_blackhole = (clean && loss[1,p] == 0 && ce[p] == 0)
  # Stale validation: the path was challenged but never answered and carried
  # no data in the current generation.
  CL_stale = (valid[p] == 0 && ch_sent[p] == 1 && ch_ack[p] == 0 && td == 0)
  # Congestion: CE feedback, loss at the 1200 floor, mixed delivery ratios,
  # or loss spread over many rungs with some delivery still succeeding.
  CL_congested = 0
  if (!CL_blackhole && !CL_stale) {
    if (ce[p] > 0) CL_congested = 1
    if (loss[1,p] > 0) CL_congested = 1
    if (td > 0 && tl > 0 && !clean) CL_congested = 1
    if (spread >= 3 && td > 0) CL_congested = 1
  }

  # Safe datagram limit for this epoch: the largest proven-delivered size,
  # capped by the observed size cliff, then capped by a still-valid ICMP PTB.
  es = 0
  if (CL_blackhole && firstbad >= 2) es = LAD[firstbad - 1]
  if (maxdeliv[p] > 0) { cand = maxdeliv[p]; if (es == 0 || cand < es) es = cand }
  if (ptb[p] > 0)      { if (es == 0 || ptb[p] < es) es = ptb[p] }
  if (es > 0 && es < 1200) es = 1200
  if (es > 1500) es = 1500
  CL_safe = es

  if (CL_stale)           { CL_state = "stale";     CL_policy = "challenge-then-resume" }
  else if (CL_blackhole)  { CL_state = "blackhole"; CL_policy = "downsize-retransmit@" (es > 0 ? es : 1200) }
  else if (CL_congested)  { CL_state = "congestion";CL_policy = "cwnd-limited-retransmit" }
  else if (td > 0 || valid[p] == 1) { CL_state = "healthy"; CL_policy = "normal" }
  else                    { CL_state = "unknown";   CL_policy = "probe" }
}

# Close an epoch: fold its safe limit into the path minimum and start fresh.
function finalize_epoch(p) {
  classify(p)
  if (CL_safe > 0 && (minsafe[p] == 0 || CL_safe < minsafe[p])) minsafe[p] = CL_safe
  epochs[p]++
  reset_counters(p)
}

{
  delete F
  for (i = 1; i <= NF; i++) {
    if ($i ~ /^#/) break
    eq = index($i, "=")
    if (eq > 1) F[substr($i, 1, eq - 1)] = substr($i, eq + 1)
  }
  ev = F["ev"]; if (ev == "") next
  t = F["t"] + 0

  if (ev == "migrate") {
    to = F["to"]; from = F["from"]
    if (to == "") next
    if (!addpath(to)) next
    to_was_valid = (valid[to] == 1)
    from_valid   = (from != "" && valid[from] == 1)
    finalize_epoch(to)                 # close any prior epoch on the target
    gen[to]++; valid[to] = 0; ch_sent[to] = 0; ch_ack[to] = 0
    migrations++
    if (from_valid || to_was_valid) failover_ok = 1
    if (ever_valid && !from_valid && !to_was_valid) conn_broken = 1
    next
  }

  p = F["path"]; if (p == "") next
  if (!addpath(p)) next

  if (ev == "challenge") {
    ch_sent[p] = 1
  } else if (ev == "challenge_ack") {
    ch_ack[p] = 1; valid[p] = 1; ever_valid = 1
    if (t > lastgood[p]) lastgood[p] = t
  } else if (ev == "send") {
    sz = F["size"] + 0; r = rung(sz); sent[r,p]++
  } else if (ev == "delivered") {
    sz = F["size"] + 0; r = rung(sz); deliv[r,p]++
    if (sz > maxdeliv[p]) maxdeliv[p] = sz
    if (t > lastgood[p]) lastgood[p] = t
    # A delivery *after* a PTB that exceeds its advertised limit proves the
    # ICMP message stale/wrong: drop the ceiling and record the conflict.
    if (ptb[p] > 0 && ptb_t[p] > 0 && t > ptb_t[p] && sz > ptb[p]) {
      ptb_conflict[p]++; ptb[p] = 0; ptb_t[p] = 0
    }
    if (F["ce"]  != "") ce[p]  += F["ce"] + 0
    if (F["ect"] != "") ect[p] += F["ect"] + 0
  } else if (ev == "lost") {
    sz = F["size"] + 0; r = rung(sz); loss[r,p]++
  } else if (ev == "icmp_ptb") {
    mtu = F["mtu"] + 0; g = F["gen"] + 0
    if (mtu < 1200) {
      icmp_low[p]++
    } else if (g != gen[p]) {
      stale_icmp[p]++
    } else if (ptb[p] != mtu) {
      finalize_epoch(p)
      ptb[p] = mtu; ptb_t[p] = t
    }
  } else if (ev == "ecn_ce") {
    ce[p] += (F["ce"] + 0 > 0 ? F["ce"] + 0 : 1)
  } else if (ev == "mtu_change") {
    mtu = F["mtu"] + 0
    finalize_epoch(p)
    if (mtu >= 1200) { ptb[p] = mtu; ptb_t[p] = t }
    mtu_changes[p]++
  }
}

END {
  conn_min = 0; usable = 0; validated = 0
  stale_total = 0; conflict_total = 0; icmp_low_total = 0
  for (i = 1; i <= npaths; i++) {
    stale_total += stale_icmp[order[i]]
    conflict_total += ptb_conflict[order[i]]
    icmp_low_total += icmp_low[order[i]]
    p = order[i]
    classify(p)
    st = CL_state; pol = CL_policy
    if (CL_safe > 0 && (minsafe[p] == 0 || CL_safe < minsafe[p])) minsafe[p] = CL_safe
    fsafe = minsafe[p]
    if (fsafe == 0) fsafe = (CL_safe > 0 ? CL_safe : 1200)

    if (valid[p] == 1) validated++
    is_usable = (valid[p] == 1 || CL_td > 0 || maxdeliv[p] > 0)
    if (is_usable) {
      usable++
      if (conn_min == 0 || fsafe < conn_min) conn_min = fsafe
    }

    if (st == "blackhole")      reason = "size-cliff>" LAD[CL_firstbad]
    else if (st == "congestion") reason = (ce[p] > 0 ? "ecn-ce" : (CL_r1loss > 0 ? "loss-at-floor" : "mixed-loss"))
    else if (st == "stale")      reason = "challenge-unacked"
    else if (st == "healthy")    reason = "validated"
    else                         reason = "no-observation"

    printf "RECOVERY path=%s state=%s safe_mtu=%d policy=%s reason=%s deliveries=%d losses=%d ce=%d epochs=%d stale_icmp=%d conflicts=%d\n",
      p, st, fsafe, pol, reason, CL_td, CL_tl, ce[p], epochs[p], stale_icmp[p], ptb_conflict[p]
  }
  if (conn_min == 0) conn_min = 1200
  preserved = (!conn_broken && usable >= 1) ? "yes" : "no"
  failover = (migrations > 0) ? (failover_ok ? "yes" : "no") : "n/a"
  printf "SUMMARY paths=%d validated=%d usable=%d migrations=%d failover=%s preserved=%s safe_connection_mtu=%d stale_icmp=%d ptb_conflicts=%d icmp_low=%d capped=%s\n",
    npaths, validated, usable, migrations, failover, preserved, conn_min, stale_total, conflict_total, icmp_low_total, (capped ? "yes" : "no")
}
AWK
)

gen() {
  case "$1" in
    blackhole)    scenario_blackhole ;;
    congestion)   scenario_congestion ;;
    stale)        scenario_stale ;;
    delayed_icmp) scenario_delayed_icmp ;;
    wrong_icmp)   scenario_wrong_icmp ;;
    combined)     scenario_combined ;;
    unknown)      scenario_unknown ;;
    *) echo "unknown scenario: $1" >&2; return 2 ;;
  esac
}

replay() {
  local file="${1:-}"
  local trace hash
  if [ -n "$file" ]; then
    trace=$(awk "$AWK_PROG" "$file")
  else
    trace=$(awk "$AWK_PROG")
  fi
  [ -n "$trace" ] || trace="(empty)"
  printf '%s\n' "$trace"
  hash=$(printf '%s\n' "$trace" | sha256sum | awk '{print $1}')
  printf 'TRACE_SHA256 %s\n' "$hash"
}

selftest() {
  local tmp fail=0
  tmp=$(mktemp -d)
  trap 'rm -rf "$tmp"' RETURN

  check() {
    local name="$1" expect="$2" out flat
    gen "$name" > "$tmp/$name.trace"
    out=$(replay "$tmp/$name.trace")
    flat=$(printf '%s\n' "$out" | tr '\n' ' ')
    if printf '%s' "$flat" | grep -qE "$expect"; then
      echo "PASS  $name"
    else
      echo "FAIL  $name  (expected: $expect)"
      printf '%s\n' "$out" | sed 's/^/      /'
      fail=1
    fi
  }

  check blackhole    'RECOVERY path=0 state=blackhole safe_mtu=1200 policy=downsize-retransmit@1200'
  check congestion   'RECOVERY path=0 state=congestion safe_mtu=1440 policy=cwnd-limited-retransmit'
  check stale        'RECOVERY path=0 state=healthy.*RECOVERY path=1 state=stale.*challenge-then-resume'
  check stale        'failover=yes preserved=yes'
  check delayed_icmp 'RECOVERY path=0 state=healthy safe_mtu=1500.*stale_icmp=1'
  check wrong_icmp   'RECOVERY path=0 state=healthy safe_mtu=1500.*conflicts=1'
  check combined     'RECOVERY path=0 state=blackhole safe_mtu=1400.*RECOVERY path=1 state=stale'
  check combined     'failover=yes preserved=yes.*safe_connection_mtu=1400'

  # Determinism: the same trace must hash identically across runs.
  local h1 h2
  h1=$(gen combined | replay)
  h2=$(gen combined | replay)
  if [ "$h1" = "$h2" ]; then echo "PASS  determinism"; else echo "FAIL  determinism"; fail=1; fi

  return $fail
}

  $(basename "$0") hash <scenario>    # sha256 of the recovery trace

}

3. Distinguishing the three failure modes

Scenario Decisive evidence Verdict Safe limit / policy
blackhole zero delivery at 1400 and 1500, delivery at 1200, ce=0, no 1200-floor loss blackhole 1200 / downsize-retransmit@1200
congestion loss at 1200 floor + CE marks + mixed ratios congestion 1440 / cwnd-limited-retransmit (MTU not shrunk)
stale challenge on path 1 never acked, zero data in generation stale challenge-then-resume, old path kept as fallback
delayed_icmp PTB gen=1 ≠ path generation 0 stale ICMP (stale_icmp=1) 1500 / normal
wrong_icmp same-gen PTB 1200 but delivery at 1500 after it conflict (conflicts=1) 1500 / normal

4. Determinism and bounded memory

Same input → byte-identical trace and hash (asserted by PASS determinism). On a 200,000-line trace:

200000 /tmp/big.trace
Elapsed: 0:00.55
Maximum resident set size (kbytes): 7740

The analyzer keeps only O(paths × rungs) counters and caps paths at 64 (capped=yes is reported when exceeded); it stores no per-packet state, so RSS does not grow with packet count. shellcheck -S warning is clean.

Notes / assumptions

  • MTU epochs are delimited by migrate, mtu_change, or a changed, fresh PTB; the reported per-path limit is the minimum over epochs (conservative: a limit, once proven, is never silently raised).
  • A PTB below the QUIC 1200 floor is counted (icmp_low) and ignored; a PTB whose generation differs from the path's current generation is counted (stale_icmp) and ignored; a PTB contradicted by a later larger delivery is revoked (ptb_conflicts).
  • The trace grammar is intentionally tiny so a real capture can be normalized into it with one awk line without changing the analyzer.
