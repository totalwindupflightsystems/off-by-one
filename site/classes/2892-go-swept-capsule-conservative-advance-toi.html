go-swept-capsule-conservative-advance-toi — root cause and verified fix

TL;DR

A moving capsule (segment p0→p1, radius r, linear translation + interpolated angular motion) is tested against a static triangle soup. The bug class is discrete sampling: checking the clearance only at the ends of a 1/60 s integration step lets a 10000 u/s capsule move ~166.7 units in one step and jump clean over a 0.01-thick wall.

The fix is conservative advancement with a proven Lipschitz bound on the capsule's clearance g(t) = dist(segment(t), mesh) − r:

V = max(|p0_end − p0_start|, |p1_end − p1_start|)   // Lipschitz constant of g
step = g(t) / V                                      // can never jump a zero

Iterate step until g ≤ 0, then bisect to 1e-9. Because the capsule at t and t+dt are within Hausdorff distance V·dt and distance-to-a-set is 1-Lipschitz, g cannot reach zero before t + g(t)/V; therefore no impact is ever skipped, at any speed. Resting contact is a stream-level classification: a new hit is the same contact (not a new collision) when its time is within 1e-7 of the previous one and the triangle is unchanged.

1. Root cause

Given a motion that spans one integration step, the naive test is

hit = (clearance(t=0) <= 0) || (clearance(t=1) <= 0)

With speed = 10000 u/s, dt = 1/60 s, the displacement is 10000/60 ≈ 166.67 units. A 0.01-thick wall with a 0.05-radius capsule is only "occupied" over a window of width 2r + thickness = 0.11 units. The capsule is inside that window for only 0.11 / 10000 = 1.1e-5 s, roughly 0.00066 of a step. Both endpoints of the step lie outside the window, so the collision is silently dropped — the capsule tunnels through.

Raising the sample rate is not a fix (it only moves the adversarial speed/thickness threshold). What is needed is an advance that is certified not to step over a contact. A second, independent failure is treating a persistent resting contact as a brand-new impact on every frame, which causes repeated impulses and jitter; a stable "same contact" classification is needed.

2. The fix

2.1 Motion and clearance

For t ∈ [0,1] the endpoints move linearly:

p0(t) = p0_start + t·(p0_end − p0_start)
p1(t) = p1_start + t·(p1_end − p1_start)

Linear interpolation of both endpoints is exactly linear translation of the capsule centre plus interpolated angular motion of the capsule axis. The capsule clearance is the exact segment/triangle distance minus r (negative means the capsule volume overlaps the surface):

g(t) = min over triangles T of  dist( segment(p0(t),p1(t)), T )  −  r

The closest points returned by the distance query give the contact normal (cpSeg − cpTri, oriented from the mesh toward the capsule). The exact segment/triangle distance considers the two segment endpoints vs. the triangle, the segment vs. the three triangle edges, and the segment/plane intersection when it lands inside the triangle.

2.2 Lipschitz bound, and why no impact is skipped

Claim: g is Lipschitz with constant V = max(|Δp0|, |Δp1|).

  • The segment at t and the segment at t+dt map to each other by sending a convex combination (1−s)p0 + s p1 to the same combination at t+dt; the displacement is |(1−s)Δp0 + sΔp1|·dt ≤ V·dt. Hence the Hausdorff distance between the two segments is at most V·dt.
  • The capsule is segment ⊕ ball(r); the Minkowski sum with the same ball cannot increase Hausdorff distance, so the capsules are within V·dt too.
  • Distance to a fixed set is 1-Lipschitz, so |g(t+dt) − g(t)| ≤ V·dt.

Consequently, from a state with g(t) > 0, every time τ < g(t)/V satisfies g(t+τ) ≥ g(t) − V·τ > 0. A step of g(t)/V therefore cannot cross a contact, however large V is. The algorithm advances by exactly that amount and stops at the first g ≤ 0; the last safe time and the first contacting time bracket the earliest root, which is then bisected to 1e-9.

2.3 Algorithm

clearance(t), normal(t) via exact segment/triangle queries

TimeOfImpact(a0,b0,a1,b1,r):
    g = clearance(0)
    if g <= 0: return (t=0, already in contact)
    V = max(|a1-a0|, |b1-b0|)
    loop:
        tNew = t + g / V                 # certified safe advance
        if tNew >= 1:
            if clearance(1) > 0: return no hit
            else: bracket = [t, 1]; break
        gNew = clearance(tNew)
        if gNew <= 0: bracket = [t, tNew]; break
        t, g = tNew, gNew
    refine by bisection on clearance sign until interval <= 1e-9

refine keeps g(lo) > 0 and g(hi) ≤ 0; since the advance never skipped a root, the root in the bracket is the earliest impact.

2.4 Stable resting-contact classification

The CLI tracks whether the previous step ended in contact and with which triangle. A hit is classified resting iff its time is within 1e-7 of the start of the current step and the previous step ended in contact with the same triangle. Otherwise it is a new impact. No hit is none. This makes a second contact within 1e-7 of the first the same contact rather than a new collision, so a backstop does not re-resolve a resting capsule every frame.

2.5 CLI contract

Input — one JSON object per line on stdin:

{"id":1,"radius":0.05,
 "p0_start":[-83.33,-0.2,0],"p1_start":[-83.33,0.2,0],
 "p0_end":[83.33,-0.2,0],"p1_end":[83.33,0.2,0]}

Output — one JSON object per line on stdout:

{"id":1,"time_of_impact":0.49967,"normal":[-1,0,0],
 "triangle_id":2,"classification":"impact",
 "verify":{"before":1.66e-5,"after":-1.66e-5,"ok":true}}
  • time_of_impact ∈ [0,1], or -1 when there is no hit.
  • normal points from the mesh toward the capsule.
  • triangle_id is the hit triangle, or -1.
  • classification ∈ {none, impact, resting}.
  • With --verify, the capsule signed clearance is sampled at t ± 1e-7 and ok is true when it is positive before and non-positive after.

package main

import "math"

// Vec3 is a 3-component double precision vector.
type Vec3 struct{ X, Y, Z float64 }

func V(x, y, z float64) Vec3 { return Vec3{x, y, z} }

func (a Vec3) Add(b Vec3) Vec3    { return Vec3{a.X + b.X, a.Y + b.Y, a.Z + b.Z} }
func (a Vec3) Sub(b Vec3) Vec3    { return Vec3{a.X - b.X, a.Y - b.Y, a.Z - b.Z} }
func (a Vec3) Mul(s float64) Vec3 { return Vec3{a.X * s, a.Y * s, a.Z * s} }
func (a Vec3) Dot(b Vec3) float64 {
    return a.X*b.X + a.Y*b.Y + a.Z*b.Z
}
func (a Vec3) Cross(b Vec3) Vec3 {
    return Vec3{
        a.Y*b.Z - a.Z*b.Y,
        a.Z*b.X - a.X*b.Z,
        a.X*b.Y - a.Y*b.X,
    }
}
func (a Vec3) Len2() float64 { return a.Dot(a) }
func (a Vec3) Len() float64  { return math.Sqrt(a.Dot(a)) }
func (a Vec3) Normalize() Vec3 {
    l := a.Len()
    if l < 1e-15 {
        return Vec3{}
    }
    return a.Mul(1 / l)
}

// Lerp linearly interpolates a->b by t in [0,1].
func Lerp(a, b Vec3, t float64) Vec3 { return a.Add(b.Sub(a).Mul(t)) }

func clamp(x, lo, hi float64) float64 {
    if x < lo {
        return lo
    }
    if x > hi {
        return hi
    }
    return x
}

func maxf(a, b float64) float64 {
    if a > b {
        return a
    }
    return b
}

distance.go

package main

import "math"

const epsDist = 1e-15

// closestPointTriangle returns the point on triangle (a,b,c) closest to p.
// Ericson, Real-Time Collision Detection, section 5.1.5.
func closestPointTriangle(p, a, b, c Vec3) Vec3 {
    ab := b.Sub(a)
    ac := c.Sub(a)
    ap := p.Sub(a)
    d1 := ab.Dot(ap)
    d2 := ac.Dot(ap)
    if d1 <= 0 && d2 <= 0 {
        return a
    }

    bp := p.Sub(b)
    d3 := ab.Dot(bp)
    d4 := ac.Dot(bp)
    if d3 >= 0 && d4 <= d3 {
        return b
    }

    vc := d1*d4 - d3*d2
    if vc <= 0 && d1 >= 0 && d3 <= 0 {
        v := d1 / (d1 - d3)
        return a.Add(ab.Mul(v))
    }

    cp := p.Sub(c)
    d5 := ab.Dot(cp)
    d6 := ac.Dot(cp)
    if d6 >= 0 && d5 <= d6 {
        return c
    }

    vb := d5*d2 - d1*d6
    if vb <= 0 && d2 >= 0 && d6 <= 0 {
        w := d2 / (d2 - d6)
        return a.Add(ac.Mul(w))
    }

    va := d3*d6 - d5*d4
    if va <= 0 && (d4-d3) >= 0 && (d5-d6) >= 0 {
        w := (d4 - d3) / ((d4 - d3) + (d5 - d6))
        return b.Add(c.Sub(b).Mul(w))
    }

    denom := va + vb + vc
    if math.Abs(denom) < 1e-30 {
        // Degenerate triangle; fall back to nearest vertex.
        best := a
        if p.Sub(b).Len2() < p.Sub(best).Len2() {
            best = b
        }
        if p.Sub(c).Len2() < p.Sub(best).Len2() {
            best = c
        }
        return best
    }
    v := vb / denom
    w := vc / denom
    return a.Add(ab.Mul(v)).Add(ac.Mul(w))
}

// pointInTriangle tests whether p, assumed to lie in the triangle plane, is
// inside triangle (a,b,c). Uses edge half-space tests with the plane normal.
func pointInTriangle(p, a, b, c Vec3) bool {
    n := b.Sub(a).Cross(c.Sub(a))
    if n.Len2() < 1e-30 {
        return false
    }
    c1 := b.Sub(a).Cross(p.Sub(a)).Dot(n)
    c2 := c.Sub(b).Cross(p.Sub(b)).Dot(n)
    c3 := a.Sub(c).Cross(p.Sub(c)).Dot(n)
    hasNeg := c1 < -epsDist || c2 < -epsDist || c3 < -epsDist
    hasPos := c1 > epsDist || c2 > epsDist || c3 > epsDist
    return !(hasNeg && hasPos)
}

// closestSegSeg returns the closest points on segments [p1,q1] and [p2,q2].
// Ericson, section 5.1.9.
func closestSegSeg(p1, q1, p2, q2 Vec3) (Vec3, Vec3) {
    d1 := q1.Sub(p1)
    d2 := q2.Sub(p2)
    r := p1.Sub(p2)
    a := d1.Dot(d1)
    e := d2.Dot(d2)
    f := d2.Dot(r)
    const eps = 1e-18

    if a <= eps && e <= eps {
        return p1, p2
    }

    var s, t float64
    if a <= eps {
        s = 0
        t = clamp(f/e, 0, 1)
    } else {
        c := d1.Dot(r)
        if e <= eps {
            t = 0
            s = clamp(-c/a, 0, 1)
        } else {
            b := d1.Dot(d2)
            denom := a*e - b*b
            if denom > eps {
                s = clamp((b*f-c*e)/denom, 0, 1)
            } else {
                s = 0
            }
            t = (b*s + f) / e
            if t < 0 {
                t = 0
                s = clamp(-c/a, 0, 1)
            } else if t > 1 {
                t = 1
                s = clamp((b-c)/a, 0, 1)
            }
        }
    }
    return p1.Add(d1.Mul(s)), p2.Add(d2.Mul(t))
}

// TriClosest is the result of a segment/triangle closest-point query.
type TriClosest struct {
    Dist  float64
    CpSeg Vec3
    CpTri Vec3
}

// closestSegmentTriangle computes the exact closest points between segment
// [p0,p1] and triangle (a,b,c). Candidate features are: the two segment
// endpoints against the triangle, the segment against each triangle edge, and
// the segment/plane intersection when it lands inside the triangle.
func closestSegmentTriangle(p0, p1, a, b, c Vec3) TriClosest {
    best := TriClosest{Dist: math.Inf(1)}
    update := func(d float64, cs, ct Vec3) {
        if d < best.Dist {
            best = TriClosest{Dist: d, CpSeg: cs, CpTri: ct}
        }
    }

    // Endpoints against the triangle.
    ct := closestPointTriangle(p0, a, b, c)
    update(p0.Sub(ct).Len(), p0, ct)
    ct = closestPointTriangle(p1, a, b, c)
    update(p1.Sub(ct).Len(), p1, ct)

    // Segment against the three edges.
    edges := [3][2]Vec3{{a, b}, {b, c}, {c, a}}
    for _, e := range edges {
        cs, ce := closestSegSeg(p0, p1, e[0], e[1])
        update(cs.Sub(ce).Len(), cs, ce)
    }

    // Segment/plane intersection interior to the triangle (distance 0).
    n := b.Sub(a).Cross(c.Sub(a))
    if n.Len2() > 1e-30 {
        d0 := p0.Sub(a).Dot(n)
        d1 := p1.Sub(a).Dot(n)
        if d0*d1 < 0 {
            t := d0 / (d0 - d1)
            x := p0.Add(p1.Sub(p0).Mul(t))
            if pointInTriangle(x, a, b, c) {
                return TriClosest{Dist: 0, CpSeg: x, CpTri: x}
            }
        }
    }
    return best
}

mesh.go

package main

import "math"

// Triangle is a single triangle of the static triangle soup.
type Triangle struct {
    A, B, C Vec3
}

func (t Triangle) Normal() Vec3 { return t.B.Sub(t.A).Cross(t.C.Sub(t.A)).Normalize() }

// Mesh is a static triangle soup. For solid (closed) meshes the signed
// distance is well defined; for open soups the unsigned surface distance is
// returned with a positive sign.
type Mesh struct {
    Tris []Triangle
}

// Clearance returns the clearance of a capsule (segment [p0,p1], radius r) to
// the surface: the closest segment/triangle distance minus r. It also returns
// the closest point on the segment, the closest point on the triangle, the
// triangle index, and that triangle's geometric normal. Negative clearance
// means the capsule volume overlaps the surface.
func (m *Mesh) Clearance(p0, p1 Vec3, r float64) (clearance float64, cpSeg, cpTri Vec3, triID int, triNormal Vec3) {
    best := math.Inf(1)
    triID = -1
    for i := range m.Tris {
        t := m.Tris[i]
        res := closestSegmentTriangle(p0, p1, t.A, t.B, t.C)
        if res.Dist < best {
            best = res.Dist
            cpSeg = res.CpSeg
            cpTri = res.CpTri
            triID = i
            triNormal = t.Normal()
        }
    }
    if triID < 0 {
        return math.Inf(1), p0, p0, -1, Vec3{}
    }
    return best - r, cpSeg, cpTri, triID, triNormal
}

// SignedDistancePoint returns the signed distance from p to a closed mesh
// (negative inside). For open soups the result is the unsigned surface
// distance. The sign is obtained by ray-casting parity.
func (m *Mesh) SignedDistancePoint(p Vec3) float64 {
    best := math.Inf(1)
    for i := range m.Tris {
        t := m.Tris[i]
        c := closestPointTriangle(p, t.A, t.B, t.C)
        if d := p.Sub(c).Len(); d < best {
            best = d
        }
    }
    if m.pointInside(p) {
        return -best
    }
    return best
}

// Several non-axis-aligned ray directions are used for the parity test so a
// single ray grazing a shared mesh edge (which would be counted twice) cannot
// flip the result. The majority vote is robust for watertight soups.
var insideDirs = []Vec3{
    V(0.3123, 0.7123, 0.6231).Normalize(),
    V(-0.5231, 0.2341, 0.8191).Normalize(),
    V(0.7777, -0.3333, 0.5311).Normalize(),
}

func (m *Mesh) pointInside(p Vec3) bool {
    votes := 0
    for _, d := range insideDirs {
        count := 0
        for i := range m.Tris {
            if rayIntersectsTriangle(p, d, m.Tris[i]) {
                count++
            }
        }
        if count%2 == 1 {
            votes++
        }
    }
    return votes >= 2
}

// rayIntersectsTriangle is the Moller-Trumbore test (no backface culling).
func rayIntersectsTriangle(orig, dir Vec3, t Triangle) bool {
    e1 := t.B.Sub(t.A)
    e2 := t.C.Sub(t.A)
    pv := dir.Cross(e2)
    det := e1.Dot(pv)
    if math.Abs(det) < 1e-15 {
        return false
    }
    inv := 1 / det
    tv := orig.Sub(t.A)
    u := tv.Dot(pv) * inv
    if u < 0 || u > 1 {
        return false
    }
    qv := tv.Cross(e1)
    v := dir.Dot(qv) * inv
    if v < 0 || u+v > 1 {
        return false
    }
    tt := e2.Dot(qv) * inv
    return tt > 1e-12
}

// BuildThinWall builds a closed box centered at the origin, thin along X.
func BuildThinWall(thickness, halfY, halfZ float64) *Mesh {
    hx := thickness / 2
    hy := halfY
    hz := halfZ
    v000 := V(-hx, -hy, -hz)
    v100 := V(hx, -hy, -hz)
    v110 := V(hx, hy, -hz)
    v010 := V(-hx, hy, -hz)
    v001 := V(-hx, -hy, hz)
    v101 := V(hx, -hy, hz)
    v111 := V(hx, hy, hz)
    v011 := V(-hx, hy, hz)

    var tris []Triangle
    quad := func(a, b, c, d Vec3) {
        tris = append(tris, Triangle{a, b, c}, Triangle{a, c, d})
    }
    quad(v100, v110, v111, v101) // +X
    quad(v000, v001, v011, v010) // -X
    quad(v010, v011, v111, v110) // +Y
    quad(v000, v100, v101, v001) // -Y
    quad(v001, v101, v111, v011) // +Z
    quad(v000, v010, v110, v100) // -Z
    return &Mesh{Tris: tris}
}

ccd.go

package main

// TOIResult is the outcome of a continuous-collision query for one capsule
// motion.
type TOIResult struct {
    Hit          bool
    T            float64 // time of impact in [0,1]
    Normal       Vec3    // unit contact normal, pointing from mesh to capsule
    TriID        int     // triangle hit, -1 if none
    StartContact bool    // capsule was already touching at t=0
}

// Solver performs conservative advancement against a static Mesh.
type Solver struct {
    Mesh *Mesh
    Tol  float64 // time accuracy target (default 1e-9)
}

func (s *Solver) tolerance() float64 {
    if s.Tol > 0 {
        return s.Tol
    }
    return 1e-9
}

// eval samples the capsule clearance at time t.
func (s *Solver) eval(a0, b0, a1, b1 Vec3, r, t float64) (float64, Vec3, Vec3, int, Vec3) {
    return s.Mesh.Clearance(Lerp(a0, a1, t), Lerp(b0, b1, t), r)
}

func contactNormal(cpSeg, cpTri, triNormal, ref Vec3) Vec3 {
    d := cpSeg.Sub(cpTri)
    if d.Len2() > 1e-18 {
        return d.Normalize()
    }
    n := triNormal.Normalize()
    if n.Dot(ref.Sub(cpTri)) < 0 {
        n = n.Mul(-1)
    }
    return n
}

// TimeOfImpact finds the earliest t in [0,1] at which the capsule moving
// linearly from segment [a0,b0] to [a1,b1] first touches the mesh.
//
// The clearance g(t) = dist(segment(t), mesh) - r is Lipschitz with constant
// V = max(|a1-a0|, |b1-b0|): the capsule at t and t+dt are within Hausdorff
// distance V*dt, and distance to a fixed set is 1-Lipschitz. Therefore a step
// of g(t)/V can never jump over a zero of g, so no impact is skipped even for
// displacements of hundreds of units per step.
func (s *Solver) TimeOfImpact(a0, b0, a1, b1 Vec3, r float64) TOIResult {
    d, cpSeg, cpTri, id, tn := s.Mesh.Clearance(a0, b0, r)
    if d <= 0 {
        ref := a0.Add(b0).Mul(0.5)
        return TOIResult{Hit: true, T: 0, Normal: contactNormal(cpSeg, cpTri, tn, ref), TriID: id, StartContact: true}
    }

    v := maxf(a1.Sub(a0).Len(), b1.Sub(b0).Len())
    if v < 1e-15 {
        return TOIResult{}
    }

    t := 0.0
    cur := d
    for iter := 0; iter < 1_000_000; iter++ {
        // Largest safe advance: g cannot reach zero before t + cur/v.
        dt := cur / v
        if dt < 1e-15 {
            dt = 1e-15
        }
        tNew := t + dt
        if tNew >= 1 {
            dEnd, cpS1, cpT1, id1, tn1 := s.eval(a0, b0, a1, b1, r, 1)
            if dEnd > 0 {
                return TOIResult{}
            }
            ref := Lerp(a0, a1, 1).Add(Lerp(b0, b1, 1)).Mul(0.5)
            res := s.refine(a0, b0, a1, b1, r, t, 1, id1, tn1, cpS1, cpT1, ref)
            return res
        }
        dNew, cpS1, cpT1, id1, tn1 := s.eval(a0, b0, a1, b1, r, tNew)
        if dNew <= 0 {
            ref := Lerp(a0, a1, tNew).Add(Lerp(b0, b1, tNew)).Mul(0.5)
            return s.refine(a0, b0, a1, b1, r, t, tNew, id1, tn1, cpS1, cpT1, ref)
        }
        t = tNew
        cur = dNew
    }
    return TOIResult{}
}

// refine bisects the bracket [lo,hi] with g(lo)>0 and g(hi)<=0. Because the
// advancement never skipped a root, the root in this bracket is the earliest.
func (s *Solver) refine(a0, b0, a1, b1 Vec3, r, lo, hi float64, id int, tn, cpS, cpT, ref Vec3) TOIResult {
    tol := s.tolerance()
    for i := 0; i < 200; i++ {
        if hi-lo <= tol {
            break
        }
        mid := 0.5 * (lo + hi)
        d, cs, ct, cid, ctn := s.eval(a0, b0, a1, b1, r, mid)
        if d > 0 {
            lo = mid
        } else {
            hi = mid
            id, tn, cpS, cpT = cid, ctn, cs, ct
        }
    }
    d, cs, ct, cid, ctn := s.eval(a0, b0, a1, b1, r, hi)
    if cid >= 0 {
        id, tn, cpS, cpT = cid, ctn, cs, ct
    }
    _ = d
    return TOIResult{Hit: true, T: hi, Normal: contactNormal(cpS, cpT, tn, ref), TriID: id}
}

// VerifyResult holds the before/after signed-clearance samples used by the
// --verify mode.
type VerifyResult struct {
    Before *float64
    After  float64
    OK     bool
}

// Verify re-checks a reported impact by sampling the capsule signed clearance
// immediately before and after the impact time.
func (s *Solver) Verify(a0, b0, a1, b1 Vec3, r, t float64) VerifyResult {
    const delta = 1e-7
    var before *float64
    if t > delta {
        v := s.evalClearance(a0, b0, a1, b1, r, t-delta)
        before = &v
    }
    ta := t + delta
    if ta > 1 {
        ta = 1
    }
    after := s.evalClearance(a0, b0, a1, b1, r, ta)

    ok := after <= 1e-9
    if before != nil {
        ok = ok && *before >= -1e-9
    } else {
        // Impact at t~=0: the capsule must already be in contact.
        ok = ok && after <= 1e-9
    }
    return VerifyResult{Before: before, After: after, OK: ok}
}

func (s *Solver) evalClearance(a0, b0, a1, b1 Vec3, r, t float64) float64 {
    d, _, _, _, _ := s.eval(a0, b0, a1, b1, r, t)
    return d
}

func vec3From(f [3]float64) Vec3 { return V(f[0], f[1], f[2]) }

func loadMesh(path string) (*Mesh, error) {
    data, err := os.ReadFile(path)
    if err != nil {
        return nil, err
    }
    var mf MeshFile
    if err := json.Unmarshal(data, &mf); err != nil {
        return nil, err
    }
    m := &Mesh{}
    for _, t := range mf.Triangles {
        m.Tris = append(m.Tris, Triangle{vec3From(t[0]), vec3From(t[1]), vec3From(t[2])})
    }
    if len(m.Tris) == 0 {
        return nil, fmt.Errorf("mesh %q has no triangles", path)
    }
    return m, nil
}

            os.Exit(4)
        }

    var in io.Reader = os.Stdin
    if *inPath != "-" {

type streamCtx struct {
    prevContact bool
    prevTri     int
}

func solveState(s *Solver, st StateIn, doVerify bool, restTol float64, ctx *streamCtx) ResultOut {
    a0, b0 := vec3From(st.P0Start), vec3From(st.P1Start)
    a1, b1 := vec3From(st.P0End), vec3From(st.P1End)
    res := s.TimeOfImpact(a0, b0, a1, b1, st.Radius)

    out := ResultOut{ID: st.ID, TimeOfImpact: -1, TriangleID: -1, Classification: "none"}
    if !res.Hit {
        ctx.prevContact = false
        ctx.prevTri = -1
        return out
    }

    out.TimeOfImpact = res.T
    out.TriangleID = res.TriID
    out.Normal = vec3To(res.Normal)

    // A state that starts already in contact with the same triangle as the
    // previous state is a continuation (resting) contact, not a new impact.
    if res.T <= restTol && ctx.prevContact && ctx.prevTri == res.TriID {
        out.Classification = "resting"
    } else {
        out.Classification = "impact"
    }

    // Determine whether the capsule is still in contact at the end of the step
    // (persistent contact), which lets the next state recognise a resting
    // contact even when its reported TOI is numerically ~0.
    atEnd, _, _, endTri, _ := s.eval(a0, b0, a1, b1, st.Radius, 1)
    if atEnd <= restTol {
        ctx.prevContact = true
        ctx.prevTri = endTri
    } else {
        ctx.prevContact = false
        ctx.prevTri = -1
    }

    if doVerify {
        v := s.Verify(a0, b0, a1, b1, st.Radius, res.T)
        vo := &VerifyOut{After: v.After, OK: v.OK}
        if v.Before != nil {
            vo.Before = v.Before
        }
        out.Verify = vo
    }
    return out
}

func trimSpace(b []byte) []byte {
    start := 0
    for start < len(b) && (b[start] == ' ' || b[start] == '\t' || b[start] == '\r' || b[start] == '\n') {
        start++
    }
    end := len(b)
    for end > start && (b[end-1] == ' ' || b[end-1] == '\t' || b[end-1] == '\r' || b[end-1] == '\n') {
        end--
    }
    return b[start:end]
}

4.3 Why tunneling is now impossible

Let g(t) be the exact signed clearance and V = max(|Δp0|, |Δp1|). The Hausdorff argument of §2.2 gives |g(t+dt) − g(t)| ≤ V·dt. From g(t) > 0, for every τ < g(t)/V we have g(t+τ) > 0. The solver advances by at most g(t)/V and re-evaluates, so it can never land beyond the first zero of g. The reported t is then bracketed and bisected to 1e-9. This argument does not depend on the magnitude of V, which is why the 10000 u/s case behaves the same as a slow approach.
