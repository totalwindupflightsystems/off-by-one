Haplotype Threading with a Recombination Budget — Diagnosis and Exact Fix

1. Problem formalisation

We are given: * a variation graph G=(V,E), a DAG that may contain bubbles and convergent paths; * phased sample haplotypes (each sample owns K haplotype paths through G); * read-to-path log-likelihoods L[r][h] (-inf = incompatible); * a per-sample recombination budget B_s.

An assignment sends each read r to a compatible haplotype x_r of its sample. A recombination is a change of haplotype between two consecutive reads of the same sample (reads in genomic order). Choose an assignment that

  1. primary: maximises sum_r L[r][x_r],
  2. secondary: minimises total recombinations,
  3. hard cap: for every sample, recombinations <= B_s,

or report INFEASIBLE. Paths must never be enumerated.

2. Root-cause analysis

Why obvious approaches fail * Enumerate all source-to-sink paths / bubble combinations — up to 2^m paths; exponential. * Greedy per-read assignment — maximises likelihood but ignores switch counting; can violate the budget arbitrarily. * Enumerate K^n assignments — infeasible. * State = product of all samples' current haplotypes — exponential in sample count.

The structure that makes it tractable 1. Objective and constraint are additive over samples → solve each sample independently (no cross-sample state product). 2. For one sample only the previous read's haplotype and the recombination count matter → bounded-state DP f[i][h][c] = best log-likelihood for reads 0..i with read i on h and c recombinations, with f[i][h][c] = L[i][h] + max( f[i-1][h][c], max_{h'!=h} f[i-1][h'][c-1] ). The switch term is O(1) per state via top-two of the previous layer → O(n K B) time. 3. Compact haplotype representation as bubble -> allele; a read is checked in O(|path|). Path count is irrelevant.

Subtle correctness point. The cap is hard and likelihood is primary, so a greedy "maximise likelihood then hope the cap holds" is wrong: the unique max-likelihood assignment may need more switches than B. The solver therefore has two phases: * O(nK) phase: fix each read to its max-likelihood haplotype, compute minimum recombinations R*. If R* <= B, done. * Otherwise B < R* <= n-1, so the cap truly binds and the exact O(nKB) DP runs with B = budget.

3. Exact fix

3.1 Data model (no path enumeration)

node_to_bubble = build_node_to_bubble(bubbles)   # node -> (bubble_id, allele_id)
read_hap_compatible(read_path, hap_def, node_to_bubble)

3.2 Algorithm (single sample)

solve_sample(L[0..n-1][0..K-1], budget B):
    if some read has all L = -inf: return INFEASIBLE
    # phase 1: O(nK)
    best_i = max_h L[i][h];  allowed_i = { h : L[i][h] == best_i }
    R* = min recombinations over x_i in allowed_i
    if R* <= B: return that assignment
    # phase 2: cap binds, B < R* <= n-1
    dp[h][0] = L[0][h]
    for i in 1..n-1:
        (top1,top1h,top2,top2h)[c] = top-two of dp[.][c]
        for each h,c with L[i][h] != -inf:
            best = dp[h][c]                              # stay
            if c >= 1:
                sw = top1[c-1] if top1h[c-1] != h else top2[c-1]
                best = max(best, sw)                     # switch
            ndp[h][c] = best + L[i][h]
        dp = ndp
    pick max likelihood, then min c ascending; reconstruct via parents

3.3 Complexity

O(N K B) time total; O(K B) value memory per sample (O(nKB) with backtracking pointers). Independent of the number of source-to-sink paths.

3.4 Correctness

  • Phase 1 sums per-read maxima = global max likelihood; O(nK) DP over allowed sets gives minimum switches attaining it.
  • Phase 2: (h,c) is a complete state — the future depends on the past only through last haplotype and switch count; the recurrence covers stay/switch, so it is exact for every (h,c). Ascending c gives the min-switch tie-break.
  • Infeasibility: a read with no compatible haplotype, or no reachable state with c <= B.

#!/usr/bin/env python3
"""
Exact solver for: python3-haplotype-threading-recombination-budget

Given
  * a variation graph (DAG, may contain bubbles / convergent paths),
  * phased sample haplotypes,
  * read-to-haplotype log-likelihoods (or per-node scores from which they are
    derived without enumerating source-to-sink paths),
  * a per-sample recombination budget,

assign every read to one compatible haplotype path so that

    primary   : total log-likelihood is maximised,
    secondary : total number of recombination events is minimised,
    hard cap  : per-sample recombinations <= budget,

and report the assignment, or INFEASIBLE when no budget-feasible assignment
exists.

Key facts used
--------------
1. Reads are partitioned by sample, the likelihood is additive over reads and
   the recombination count is additive over samples.  Hence the samples are
   *independent* and each one is solved on its own.  This is what keeps the
   state bounded: no cross-sample product state is ever formed.

2. For one sample the only thing that matters about the past is the haplotype
   of the immediately preceding read and how many recombinations have been
   used.  This yields the bounded-state DP

       f[i][h][c] = best log-likelihood of reads 0..i when read i is on
                    haplotype h and c recombinations have been used.

   with transition
       f[i][h][c] = L[i][h] + max( f[i-1][h][c],                 # stay
                                   max_{h'!=h} f[i-1][h'][c-1] ) # switch
   which is evaluated in O(K) per state using the top-two values of the
   previous layer, giving O(n * K * B) time and O(K * B) memory per sample.

3. Haplotypes are represented only by the allele they choose at each bubble.
   Full source-to-sink paths are never materialised, so an exponentially large
   number of paths causes no blow-up: a read is checked against a haplotype in
   O(|read path|) by consulting the bubble->allele table.

Input JSON schema
-----------------
{
  "samples": [
    {
      "sample_id": "s1",
      "recombination_budget": 1,
      "haplotypes": ["h1", "h2"],
      "reads": [
        {"read_id": "r0", "order": 0,
         "likelihoods": {"h1": -1.2, "h2": -7.0}},     # null/missing = -inf
        ...
      ]
    }, ...
  ]
}

Alternative (graph-derived) schema, mutually exclusive with "likelihoods":
{
  "graph": {
    "nodes": ["s","a","b","t"],
    "edges": [["s","a"],["s","b"],["a","t"],["b","t"]],
    "source": "s", "sink": "t"
  },
  "bubbles": [
    {"id":"B1",
     "alleles": {"0": ["a"], "1": ["b"]}}          # allele-id -> node list
  ],
  "haplotypes": {                                    # global haplotype defs
    "h1": {"B1": "0"}, "h2": {"B1": "1"}
  },
  "node_scores": {"r0": {"s": 0.0, "a": -0.1, "t": -0.2}, ...},
  "samples": [
    {"sample_id":"s1", "recombination_budget":1,
     "haplotypes":["h1","h2"],
     "reads":[{"read_id":"r0","order":0,
               "path":["s","a","t"]}]}
  ]
}
"""

from __future__ import annotations

import argparse
import itertools
import json
import random
import sys
from typing import Dict, List, Optional, Sequence, Tuple

NEG_INF = float("-inf")


# --------------------------------------------------------------------------- #
# Likelihood construction (graph-aware, no path enumeration)
# --------------------------------------------------------------------------- #
def build_node_to_bubble(bubbles: Sequence[dict]) -> Dict[str, Tuple[str, str]]:
    """Return node -> (bubble_id, allele_id) for every bubble node."""
    mapping: Dict[str, Tuple[str, str]] = {}
    for b in bubbles:
        bid = b["id"]
        for allele_id, nodes in b["alleles"].items():
            for node in nodes:
                mapping[node] = (bid, str(allele_id))
    return mapping


def read_hap_compatible(
    read_path: Sequence[str],
    hap_def: Dict[str, str],
    node_to_bubble: Dict[str, Tuple[str, str]],
) -> bool:
    """A read path is compatible with a haplotype iff every bubble node it
    traverses is carried by the allele the haplotype chooses at that bubble."""
    for node in read_path:
        hit = node_to_bubble.get(node)
        if hit is None:
            continue  # non-polymorphic / shared node
        bid, allele_id = hit
        if str(hap_def.get(bid, allele_id)) != allele_id:
            return False
    return True


def derive_likelihoods(data: dict) -> None:
    """In-place: attach 'likelihoods' dicts to every read using node scores.
    Only bubble->allele tables are consulted; haplotype paths are never built."""
    graph = data.get("graph")
    if graph is None:
        return
    bubbles = data.get("bubbles", [])
    hap_defs = data.get("haplotypes", {})
    node_scores = data.get("node_scores", {})
    node_to_bubble = build_node_to_bubble(bubbles)

    for sample in data["samples"]:
        for read in sample["reads"]:
            scores = node_scores.get(read["read_id"], {})
            path = read.get("path", [])
            likes: Dict[str, Optional[float]] = {}
            for hid in sample["haplotypes"]:
                hdef = hap_defs.get(hid, {})
                if read_hap_compatible(path, hdef, node_to_bubble):
                    likes[hid] = float(sum(scores.get(n, 0.0) for n in path))
                else:
                    likes[hid] = None
            read["likelihoods"] = likes


# --------------------------------------------------------------------------- #
# Core DP for a single sample
# --------------------------------------------------------------------------- #
def _top_two(dp: List[List[float]], K: int, B: int):
    """top1[c], top1h[c], top2[c] over the K haplotypes for each cost c."""
    top1 = [NEG_INF] * (B + 1)
    top1h = [-1] * (B + 1)
    top2 = [NEG_INF] * (B + 1)
    top2h = [-1] * (B + 1)
    for c in range(B + 1):
        t1 = NEG_INF
        t1h = -1
        t2 = NEG_INF
        t2h = -1
        for h in range(K):
            v = dp[h][c]
            if v > t1:
                t2, t2h = t1, t1h
                t1, t1h = v, h
            elif v > t2:
                t2, t2h = v, h
        top1[c], top1h[c], top2[c], top2h[c] = t1, t1h, t2, t2h
    return top1, top1h, top2, top2h


def _min_recombinations_unconstrained(
    L: List[List[float]], K: int
) -> Optional[Tuple[int, List[int]]]:
    """Among assignments that put every read on one of its maximum-likelihood
    haplotypes, find one using the fewest recombinations.  O(n K) time/space.

    Returns (min_recombinations, assignment) or None if a read has no
    compatible haplotype.
    """
    n = len(L)
    allowed: List[List[int]] = []
    for row in L:
        if all(v == NEG_INF for v in row):
            return None
        best = max(row)
        allowed.append([h for h in range(K) if row[h] == best])

    INF = float("inf")
    dp = [0.0 if h in allowed[0] else INF for h in range(K)]
    parents = [[None] * K for _ in range(n)]
    for i in range(1, n):
        # two smallest dp values and their argmins
        m1 = INF
        m1h = -1
        m2 = INF
        for h in range(K):
            if dp[h] < m1:
                m2 = m1
                m1 = dp[h]
                m1h = h
            elif dp[h] < m2:
                m2 = dp[h]
        ndp = [INF] * K
        for h in allowed[i]:
            stay = dp[h]
            switch = (m2 if m1h == h else m1) + 1.0
            if stay <= switch:
                ndp[h] = stay
                parents[i][h] = h
            else:
                ndp[h] = switch
                parents[i][h] = m1h
        dp = ndp

    best = min(dp)
    if best == INF:
        return None
    h = dp.index(best)
    assign = [0] * n
    for i in range(n - 1, -1, -1):
        assign[i] = h
        if i > 0:
            h = parents[i][h]
    return int(best), assign


def solve_sample(
    read_ids: Sequence[str],
    likelihood_rows: List[Dict[str, Optional[float]]],
    haplotypes: Sequence[str],
    budget: int,
) -> Optional[dict]:
    """Return an optimal assignment dict for one sample, or None if infeasible.

    The returned dict has keys: recombinations, log_likelihood, assignments.
    """
    n = len(read_ids)
    K = len(haplotypes)
    if n == 0:
        return {"recombinations": 0, "log_likelihood": 0.0, "assignments": []}
    if K == 0:
        return None

    # likelihood matrix, -inf for incompatible
    L: List[List[float]] = []
    for row in likelihood_rows:
        L.append([
            NEG_INF if row.get(h) is None else float(row[h])
            for h in haplotypes
        ])
    if any(all(v == NEG_INF for v in r) for r in L):
        return None  # a read with no compatible haplotype

    budget = int(budget)

    # ---- Fast path: the recombination cap is not binding. -----------------
    # The primary objective ignores the cap, so first maximise each read's
    # likelihood independently, then minimise recombinations among all such
    # assignments.  If that uses <= budget it is the lexicographic optimum.
    unc = _min_recombinations_unconstrained(L, K)
    if unc is not None:
        min_rec, star = unc
        if min_rec <= budget:
            ll = sum(L[i][star[i]] for i in range(n))
            return {
                "recombinations": min_rec,
                "log_likelihood": ll,
                "assignments": [
                    {"read_id": read_ids[i], "haplotype": haplotypes[star[i]]}
                    for i in range(n)
                ],
            }

    # ---- Cap binds: bounded-state budget DP. ------------------------------
    # Now budget < min_rec <= n-1, so B is genuinely bounded by the budget.
    B = budget
    if B < 0:
        return None

    # dp[h][c]
    dp = [[NEG_INF] * (B + 1) for _ in range(K)]
    for h in range(K):
        if L[0][h] != NEG_INF:
            dp[h][0] = L[0][h]

    # parent[i][h][c] = (prev_h, prev_c) ; prev_h == -1 means start
    parents: List[List[List[Optional[Tuple[int, int]]]]] = []
    parents.append([[( -1, -1) if dp[h][c] != NEG_INF else None
                     for c in range(B + 1)] for h in range(K)])

    for i in range(1, n):
        top1, top1h, top2, top2h = _top_two(dp, K, B)
        ndp = [[NEG_INF] * (B + 1) for _ in range(K)]
        par = [[None] * (B + 1) for _ in range(K)]
        for h in range(K):
            lh = L[i][h]
            if lh == NEG_INF:
                continue
            for c in range(B + 1):
                best = NEG_INF
                best_prev: Optional[Tuple[int, int]] = None
                # stay on h
                if dp[h][c] > best:
                    best = dp[h][c]
                    best_prev = (h, c)
                # switch from some h' != h
                if c >= 1:
                    if top1h[c - 1] != h:
                        sw = top1[c - 1]
                        swh = top1h[c - 1]
                    else:
                        sw = top2[c - 1]
                        swh = top2h[c - 1]
                    if sw > best:
                        best = sw
                        best_prev = (swh, c - 1)
                if best != NEG_INF:
                    ndp[h][c] = best + lh
                    par[h][c] = best_prev
        dp = ndp
        parents.append(par)

    # primary = max log-likelihood, secondary = min recombinations
    best_val = NEG_INF
    best_h = -1
    best_c = -1
    for c in range(B + 1):          # ascending c gives the tie-break for free
        for h in range(K):
            v = dp[h][c]
            if v > best_val:
                best_val = v
                best_h = h
                best_c = c
    if best_val == NEG_INF:
        return None

    # reconstruct
    assign_idx = [0] * n
    h, c = best_h, best_c
    for i in range(n - 1, -1, -1):
        assign_idx[i] = h
        prev = parents[i][h][c]
        if prev is None:
            return None  # should not happen
        h, c = prev

    assignments = [
        {"read_id": read_ids[i], "haplotype": haplotypes[assign_idx[i]]}
        for i in range(n)
    ]
    return {
        "recombinations": best_c,
        "log_likelihood": best_val,
        "assignments": assignments,
    }


# --------------------------------------------------------------------------- #
# Whole input
# --------------------------------------------------------------------------- #
def solve(data: dict) -> dict:
    derive_likelihoods(data)

    out_samples = []
    total_ll = 0.0
    total_rec = 0
    for sample in data["samples"]:
        reads = list(sample["reads"])
        reads.sort(key=lambda r: r.get("order", 0))
        read_ids = [r["read_id"] for r in reads]
        rows = [r.get("likelihoods", {}) for r in reads]
        haps = list(sample["haplotypes"])
        budget = int(sample.get("recombination_budget", 0))

        res = solve_sample(read_ids, rows, haps, budget)
        if res is None:
            return {
                "status": "INFEASIBLE",
                "sample_id": sample.get("sample_id"),
                "reason": "no assignment respects compatibility and recombination budget",
            }
        out_samples.append({
            "sample_id": sample.get("sample_id"),
            "recombinations": res["recombinations"],
            "log_likelihood": res["log_likelihood"],
            "assignments": res["assignments"],
        })
        total_ll += res["log_likelihood"]
        total_rec += res["recombinations"]

    return {
        "status": "OPTIMAL",
        "total_log_likelihood": total_ll,
        "total_recombinations": total_rec,
        "samples": out_samples,
    }


# --------------------------------------------------------------------------- #
# Brute force reference (tests only)
# --------------------------------------------------------------------------- #
def brute_sample(
    read_ids: Sequence[str],
    rows: List[Dict[str, Optional[float]]],
    haplotypes: Sequence[str],
    budget: int,
):
    n = len(read_ids)
    K = len(haplotypes)
    best_key = None
    best_assign = None
    for assign in itertools.product(range(K), repeat=n):
        total = 0.0
        ok = True
        for i, hi in enumerate(assign):
            v = rows[i].get(haplotypes[hi])
            if v is None:
                ok = False
                break
            total += float(v)
        if not ok:
            continue
        rec = sum(1 for i in range(1, n) if assign[i] != assign[i - 1])
        if rec > budget:
            continue
        key = (total, -rec)
        if best_key is None or key > best_key:
            best_key = key
            best_assign = assign
    if best_key is None:
        return None
    return {
        "log_likelihood": best_key[0],
        "recombinations": -best_key[1],
        "assignments": [
            {"read_id": read_ids[i], "haplotype": haplotypes[best_assign[i]]}
            for i in range(n)
        ],
    }


# --------------------------------------------------------------------------- #
# Self test
# --------------------------------------------------------------------------- #
def selftest(trials: int = 3000) -> None:
    rng = random.Random(12345)
    for t in range(trials):
        K = rng.randint(1, 4)
        n = rng.randint(0, 7)
        haps = [f"h{j}" for j in range(K)]
        rows = []
        for _ in range(n):
            row = {}
            for h in haps:
                if rng.random() < 0.25:
                    row[h] = None
                else:
                    row[h] = round(rng.uniform(-5, 5), 2)
            rows.append(row)
        budget = rng.randint(0, 3)
        got = solve_sample(list(range(n)), rows, haps, budget)
        exp = brute_sample(list(range(n)), rows, haps, budget)
        if (got is None) != (exp is None):
            raise AssertionError(
                f"feasibility mismatch t={t}\nrows={rows}\nbudget={budget}\n"
                f"got={got}\nexp={exp}"
            )
        if got is not None:
            if (round(got["log_likelihood"], 6) != round(exp["log_likelihood"], 6)
                    or got["recombinations"] != exp["recombinations"]):
                raise AssertionError(
                    f"optimality mismatch t={t}\nrows={rows}\nbudget={budget}\n"
                    f"got={got}\nexp={exp}"
                )
    print(f"selftest OK ({trials} random cases compared against brute force)")

# CLI

def main(argv=None) -> int:
    ap = argparse.ArgumentParser(description=__doc__)

    ap.add_argument("--selftest", action="store_true")
    ap.add_argument("--trials", type=int, default=3000)
    args = ap.parse_args(argv)

    json.dump(result, sys.stdout, indent=2)
    sys.stdout.write("\n")
    return 0 if result["status"] == "OPTIMAL" else 0

5. Summary of the fix

Failure mode Fix
Exponential path/combination enumeration Compact per-bubble allele maps; check reads via node -> (bubble, allele)
Exponential K^n assignment enumeration Bounded-state DP f[i][h][c]
Exponential cross-sample state product Solve each sample independently (additive objective/constraint)
Greedy likelihood ignoring switches DP counts switches on adjacent reads
Wrong handling of the hard budget Two-phase: O(nK) fast path when the cap is not binding, exact O(nKB) DP otherwise
O(n^2) blow-up for large non-binding budgets Phase-1 shortcut keeps work/memory linear
