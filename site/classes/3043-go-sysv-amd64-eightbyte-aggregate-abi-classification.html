SysV AMD64 Aggregate ABI Classification — Diagnosed and Verified

Environment: go1.26.8 linux/amd64, gcc 15.2.0, cgo. Result: checked 240 cases, 0 failures (1344 aggregate arguments), with mutation testing proving the harness is not vacuously green.

The complete, runnable solution is on disk at ~/sysv/ with the full write‑up in ~/sysv/SOLUTION.md (1376 lines, includes the entire main.go and gen/main.go source). Below is the self‑contained solution.

1. Problem statement

Given struct types mixing scalars, floats, fixed arrays and nested aggregates, compute each eightbyte's INTEGER/SSE/SSEUP/MEMORY class using the psABI merge rules, emit the exact parameter assignment (%rdi/%rsi/%rdx/%rcx/%r8/%r9, %xmm0–%xmm7) plus stack offsets, and validate against a cgo C harness dumping real received registers for ≥200 layouts.

2. Root-cause analysis

The classification itself is straightforward; the traps are in producing trustworthy ground truth.

2.1 Bare C array parameters decay to pointers. void f(int8_t a[9]) passes int8_t*, not the aggregate. A naive generated harness produced register dumps unrelated to the type. Fix: only pass arrays inside a struct; the generator wraps any top-level array as struct { T f0; } (same size/alignment, real by-value ABI).

2.2 Padding is indeterminate. Compilers may leave argument padding uninitialized when constructing by-value aggregates, so comparing whole eightbytes produced spurious got 0x17 want 0x00 failures. Fix: compare only bytes occupied by real scalar leaves via a per-byte leaf mask.

2.3 A fixed [2]Class cannot describe >16-byte aggregates. Stack aggregates of 17–32 bytes need 3–4 eightbytes; a [2]Class overflowed. Fix: classes are a slice of length (size+7)/8.

2.4 Unaligned fields demote the whole aggregate to MEMORY. Packed structs placed at unnatural offsets classify MEMORY even at 12 bytes. Check recursively against each field's natural alignment.

2.5 Register exhaustion reverts the whole argument. All-or-nothing: count needed INTEGER and SSE eightbytes (SSEUP does not consume a new %xmm); if intUsed+needInt>6 || sseUsed+needSSE>8, the whole argument goes to the stack and consumes nothing.

2.6 SSEUP semantics. __m128 is [SSE, SSEUP] in one %xmm (low+high), while struct{double;double} is [SSE,SSE] in two %xmm. Normalize orphaned SSEUP to SSE.

2.7 CET / indirect calls. The capture is hand-written asm reached through a per-case direct stub endbr64; jmp sysv_cap_call, with exact __typeof__(aN) prototypes so no default argument promotions occur.

2.8 Stack layout. First outgoing slot is at 8(%rsp); align each to min(align,16), round size to 8.

Classification core (main.go)

func merge(a, b Class) Class {
    if a == b { return a }
    if a == NoClass { return b }
    if b == NoClass { return a }
    if a == Memory || b == Memory { return Memory }
    if a == Integer || b == Integer { return Integer }
    return SSE
}

func mergeAt(cls []Class, i int, c Class) {
    if i >= 0 && i < len(cls) { cls[i] = merge(cls[i], c) }
}

func mergeRange(cls []Class, off, size int, c Class) {
    first, last := off/8, (off+size-1)/8
    for i := first; i <= last; i++ { mergeAt(cls, i, c) }
}

// A single misaligned field anywhere demotes the whole aggregate to MEMORY.
func hasUnaligned(t *T, off int) bool {
    if t.Align > 0 && off%t.Align != 0 { return true }
    switch t.Kind {
    case "struct":
        for _, fl := range t.Fields {
            if hasUnaligned(fl.T, off+fl.Off) { return true }
        }
    case "array":
        for i := 0; i < t.Len; i++ {
            if hasUnaligned(t.Elem, off+i*t.Elem.Size) { return true }
        }
    }
    return false
}

func classifyInto(t *T, off int, cls []Class) {
    switch t.Kind {
    case "i8", "i16", "i32", "i64":
        mergeRange(cls, off, t.Size, Integer)
    case "f32", "f64":
        mergeRange(cls, off, t.Size, SSE)
    case "v128":
        mergeAt(cls, off/8, SSE)
        mergeAt(cls, off/8+1, SSEUP)
    case "struct":
        for _, fl := range t.Fields { classifyInto(fl.T, off+fl.Off, cls) }
    case "array":
        for i := 0; i < t.Len; i++ { classifyInto(t.Elem, off+i*t.Elem.Size, cls) }
    }
}

func classifyType(t *T) ([]Class, bool) {
    nb := (t.Size + 7) / 8
    if nb == 0 { return nil, false }
    if t.Size > 16 || hasUnaligned(t, 0) {
        cls := make([]Class, nb)
        for i := range cls { cls[i] = Memory }
        return cls, true
    }
    cls := make([]Class, nb)
    classifyInto(t, 0, cls)
    if cls[0] == SSEUP { cls[0] = SSE }
    for i := 1; i < len(cls); i++ {
        if cls[i] == SSEUP && cls[i-1] != SSE && cls[i-1] != SSEUP { cls[i] = SSE }
    }
    for _, c := range cls { if c == Memory { return cls, true } }
    return cls, false
}

        switch cls[j] {
        case Integer: a.Regs[j] = intUsed; intUsed++
        case SSE:     a.Regs[j] = sseUsed; lastSSE = sseUsed; sseUsed++
        case SSEUP:   a.Regs[j] = lastSSE; a.Upper[j] = true
        }
    }
}

Ground-truth harness

harness.c (generated) zero-initializes each argument, writes a distinct high-bit-clear byte into every leaf, snapshots source bytes, then calls the asm capture via an exact-prototype stub. The asm records %rdi..%r9, full 16 bytes of %xmm0..%xmm7, and 48 stack qwords:

sysv_cap_call:
  endbr64
  movq %rdi, sysv_cap_regs+0(%rip)
  ...
  movdqu %xmm0, sysv_cap_xmm+0(%rip)
  ...
  movq 8(%rsp), %rax
  movq %rax, sysv_cap_regs+48(%rip)
  ...
  ret

The verifier predicts placement independently, then compares only leaf bytes (leafMask) against the predicted register/stack location, which neutralizes indeterminate padding.

Scope note

The verifier targets the required subset INTEGER/SSE/SSEUP/MEMORY; x87/COMPLEX_X87 (long double) are out of scope and would map to MEMORY. The two real hazards that surfaced only via this harness were C array-parameter decay and indeterminate padding.
