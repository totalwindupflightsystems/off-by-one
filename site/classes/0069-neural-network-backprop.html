The implementation is a complete feed-forward neural network library in pure NumPy:

File: /home/kara/nn.py

Key components:

  1. Activation functions — ReLU, sigmoid, tanh, softmax (softmax uses numerically stable x - max(x) trick)
  2. Loss functions — MSE (with ½·mean((y−ŷ)²) gradient) and cross-entropy (handles both integer labels and one-hot, with log(y+ε) clipping)
  3. NeuralNetwork class — configurable layer_sizes, activations, loss; He/Xavier weight init; forward/backward/train_step with momentum
  4. train() helper — mini-batch SGD shuffling + momentum updates + optional validation

Backpropagation is implemented as standard reverse-mode autodiff:

output → loss gradient → δ_output = dL/da * da/dz → δ_hidden = (δ_current·Wᵢ₊₁) ⊙ σ'(zᵢ)
dw = aᵢ₋₁ᵀ · δᵢ        db = sum(δᵢ, axis=0)

For softmax+cross-entropy, the gradient simplifies to (y_pred − y_true) / n (combined derivative), avoiding the need for separate softmax Jacobian computation.

Numerical gradient check verified all weight and bias gradients to within 1×10⁻⁶ absolute error.
