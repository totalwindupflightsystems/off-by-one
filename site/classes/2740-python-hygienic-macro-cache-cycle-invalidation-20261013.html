Incremental Hygienic Macro Expansion: Content-Addressed Cache Keys, Cycle-Safe Invalidation, and Deterministic Diagnostics

Problem class: python-hygienic-macro-cache-cycle-invalidation-20261013 Environment: Python 3.11 (verified on 3.14.4), stdlib only Deliverable: macro_engine.py (engine) + test_macro_engine.py (29-check suite) + SOLUTION.md (self-contained, full source in appendices)

1. What is being diagnosed

An incremental expander for a hygienic macro language must: resolve nested imports; track source locations; support mutually recursive macros; after a one-file edit recompute exactly the affected expansion subgraph; never serve a stale expansion; produce deterministic diagnostics under parallel builds; and never diverge on cyclic dependencies (macro and import cycles). A naive implementation fails each of these in a characteristic way.

2. Root-cause analysis

RC-1 — Cache key granularity is wrong in both directions

Keying on the use site alone is stale (a changed macro body is part of the input). Keying on the whole file/environment is over-invalidation (editing unrelated macro other discards expansions that only used m). Fix: key each expansion on the macro signature + argument syntax + hygiene/cycle context, and resolve macros per (module, name).

RC-2 — No early cutoff

If a recomputed node always bumps its version, a whitespace edit cascades through identical ASTs and macro signatures. Fix: verified_at/changed_at revisions; on recompute, compare new vs old with a location-free structural freeze; if equal, keep the old changed_at.

RC-3 — Hashing includes source locations

Inserting a blank line changes every hash. Fix: canonicalize AST dropping Loc; locations live only in diagnostics.

RC-4 — No cycle discipline

Recursive macros and cyclic imports diverge. Fix at three layers: active macro-signature stack (expansion), visited BFS (imports), in_progress guard (engine).

RC-5 — Hygiene driven by a global counter

Counters/id() make fresh names differ per run, breaking reproducibility. Fix: derive the hygiene token from the macro signature and rename with a deterministic traversal counter.

RC-6 — Diagnostics ordered by completion

Parallel workers append in race order. Fix: collect per-node diagnostics and sort by the total order (path, line, col, code, message).

3. The exact fix

Two layers: a revision-based demand-driven query engine (mini-Salsa), and expander queries over it.

Query Key Depends on Why
parse ("parse", p) ("content", p) one node per module
local macro ("macro_local", p, name) ("parse", p) per name → unrelated macros don't invalidate each other
resolved macro ("macro", p, name) macro_local over BFS import set nested imports; visited breaks cycles
expansion ("expand", p, node_hash(form), stack) ("macro", p, head), argument/child expansions content-addressed args + cycle context

Engine core — dependency-tracked invalidation with early cutoff:

def get(self, key, compute):
    entry = self.cache.get(key)
    if entry is not None:
        if entry.verified_at == self.revision:
            self._record_dep(key); return entry.value
        stale = False
        for dep in entry.deps:
            if dep in self.inputs:
                if self.input_changed_at(dep) > entry.verified_at:
                    stale = True; break
            else:
                child = self.cache.get(dep)
                if child is None: stale = True; break
                self.get(dep, child.compute)
                if self.cache[dep].changed_at > entry.verified_at:
                    stale = True; break
        if not stale:
            entry.verified_at = self.revision
            self._record_dep(key); return entry.value
    return self._compute(key, compute)

def _compute(self, key, compute):
    self._record_dep(key)
    old = self.cache.get(key)
    frame = [key, [], []]
    self._stack.append(frame)
    try:
        value = compute(self)                      # records deps via get()
    finally:
        self._stack.pop()
    if old is not None and freeze(old.value) == freeze(value):
        changed_at = old.changed_at                # EARLY CUTOFF
    else:
        changed_at = self.revision
    self.cache[key] = Entry(value, tuple(dict.fromkeys(frame[1])), compute,
                            self.revision, changed_at, tuple(frame[2]))
    return value

Import resolution uses BFS with a visited set, so cyclic imports terminate. Hygiene derives its token from the signature: fresh = f"{name}~{md.signature[:8]}#{counter.next()}". Diagnostics are finalized with sorted(set(diags), key=lambda d: d.sort_key()).
