python-test-setup-pytest-systemexit-on-import

Answer

Root cause: RethinkDB fork RT-GAP-009 shipped script-style E2E tests with two defects: 1. SystemExit-on-import — sys.exit(run()) at module level executes when pytest imports the file for collection, raising SystemExit mid-collection (INTERNALERROR> SystemExit: 0). 2. Machine-specific path — sys.path.insert(0, "/home/kara/rethinkdb/drivers/python3") only exists on one machine (ModuleNotFoundError elsewhere).

Fix (4 artifacts):

1. Repo-root conftest.py — driver path resolved via os.path relative to __file__, so pytest can import rethinkdb from any checkout:

import os
import sys

_ROOT = os.path.dirname(os.path.abspath(__file__))
_DRIVER = os.path.join(_ROOT, "drivers", "python3")
if _DRIVER not in sys.path:
    sys.path.insert(0, _DRIVER)

2. test-requirements.txt — one-command deps:

pytest>=7,<10
looseversion>=1.3   # driver fallback for distutils.version.LooseVersion (removed in Py3.12)

3. AGENTS.md — 1-command setup + run modes:

python3 -m pip install -r test-requirements.txt
python3 -m pytest e2e/ -v     # pytest mode
python3 e2e/test_crud.py      # script mode (unchanged)

4. Test file — wrap execution in main() + if __name__ == "__main__" guard, plus an idempotent __file__-relative bootstrap so script mode also works without a hardcoded path (conftest only loads under pytest):

import os, sys
_DRIVER = os.path.join(os.path.dirname(os.path.dirname(os.path.abspath(__file__))),
                       "drivers", "python3")
if _DRIVER not in sys.path:
    sys.path.insert(0, _DRIVER)

import rethinkdb as r

def run(): ...            # returns 0 on success, non-zero failure count
def test_e2e_crud():      # pytest entry point — no sys.exit inside tests
    assert run() == 0
def main():               # script entry point — preserves original sys.exit semantics
    sys.exit(run())
if __name__ == "__main__":
    main()

pytest imports cleanly (guard prevents execution; test_* function is what pytest runs); python3 e2e/test_crud.py behaves exactly as before, including exit-code propagation.
