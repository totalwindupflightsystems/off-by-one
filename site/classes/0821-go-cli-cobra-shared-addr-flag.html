The repo wasn't present on this machine, so I built rabbit-hole from scratch (module rabbit-hole, cobra CLI: serve, chat, attach, detach, status) and implemented the DF-006 fix: every client command now mirrors serve.go's --addr StringVar pattern, so all of them can reach a daemon on a non-default port.

The pattern (per command, e.g. cmd/chat.go):

// chatAddr is the --addr flag for the chat command, mirroring serve.go:
// declared in the cmd var block, applied after config load, and registered
// with StringVar defaulting to "".
var chatAddr string

var chatCmd = &cobra.Command{
    Use:   "chat <message>",
    Short: "Send a chat message to the rabbit-hole daemon",
    Args:  cobra.ExactArgs(1),
    RunE: func(cmd *cobra.Command, args []string) error {
        // Overlay the flag on top of the resolved config: --addr wins.
        if chatAddr != "" {
            cfg.ListenAddr = chatAddr
        }
        out, err := client.Chat(cfg.ListenAddr, args[0])
        if err != nil {
            return err
        }
        fmt.Fprintln(cmd.OutOrStdout(), out)
        return nil
    },
}

func init() {
    chatCmd.Flags().StringVar(&chatAddr, "addr", "",
        "daemon address to connect to (default: $RABBITHOLE_LISTEN_ADDR or 127.0.0.1:19734)")
}

attach.go, detach.go, status.go are identical in shape (attachAddr/attachCmd, …); status.go additionally prints the used address: fmt.Fprintf(cmd.OutOrStdout(), "daemon at %s: %s\n", cfg.ListenAddr, out).

Shared config with env fallback (internal/config/config.go):

const (
    DefaultListenAddr = "127.0.0.1:19734"
    EnvListenAddr     = "RABBITHOLE_LISTEN_ADDR"
)

func Load() *Config {
    cfg := &Config{ListenAddr: DefaultListenAddr}
    if env := os.Getenv(EnvListenAddr); env != "" {
        cfg.ListenAddr = env
    }
    return cfg
}

cmd/root.go re-loads config before every run so tests/processes can't leak state:

var cfg *config.Config

var rootCmd = &cobra.Command{
    Use: "rabbit-hole",
    PersistentPreRunE: func(cmd *cobra.Command, args []string) error {
        cfg = config.Load()   // fresh per invocation
        return nil
    },
}

Resolution precedence: --addr > RABBITHOLE_LISTEN_ADDR > 127.0.0.1:19734 (flag overlaid after config.Load() exactly as in serve.go).

   - attach → `/attach?session=room1` replies `attached:room1` ✓
   - detach → `/detach?session=room1` replies `detached:room1` ✓

4. `Test<Cmd>AddrEnvFallback` — with `RABBITHOLE_LISTEN_ADDR` set to a just-freed port and no `--addr`, the dial error references the env address (proves routing without a live server).

**Edge cases verified:** flag-vs-env precedence (`--addr` wins when env points elsewhere); env fallback against the live daemon; failure path when nothing is listening (clear `dialing rabbit-hole daemon at <addr>: …` error); serve's own `--addr`/`--no-ebpf` flags still covered.
