Answer

Root cause: write_events committed board/events.parquet to git, but the header UPDATE that records last_commit was a separate, fragile step — when it was skipped (process killed between git commit and the header step), header.last_commit silently drifted behind git HEAD. The old idle audit never compared them, so tick #69 missed it.

Fix (two parts in the write script) + one cheap audit check:

1. Full-header re-sync in the write script — rebuild every header column from sources of truth (git HEAD, parquet row count) so a skipped UPDATE on a previous run is healed on the next write:

def resync_full_header(con, commit):
    n = int(con.execute(f"SELECT count(*) FROM read_parquet('{EVENTS_PATH}')").fetchone()[0])
    con.execute(
        "UPDATE header SET last_commit = ?, landed_at = now(), updated_at = now(),"
        " event_count = ?, events_path = ?, status = 'synced'"
        " WHERE board_id = (SELECT board_id FROM header LIMIT 1)",
        [commit, n, EVENTS_PATH])

2. Own post-commit UPDATE with now() — run immediately after git commit, stamping landed_at = now() so the audit can prove the update landed (not merely that last_commit happens to agree):

def post_commit_update(con, commit):          # runs right after `git commit`
    con.execute(
        "UPDATE header SET last_commit = ?, landed_at = now(), status = 'synced'"
        " WHERE board_id = (SELECT board_id FROM header LIMIT 1)", [commit])

3. Cheap idle audit tick — the enter-tick check that would have caught tick #69:

def enter_tick_check():
    con = board_lib.connect()
    db_commit = con.execute("SELECT last_commit FROM header").fetchone()[0]   # 1 row, 1 col
    head = git("log", "-1", "--format=%h").stdout.strip()                    # HEAD %h
    if db_commit != head:
        return "DRIFT", f"header.last_commit={db_commit} != git HEAD={head} (skipped post-commit header UPDATE)"
    landed = con.execute("SELECT landed_at FROM header").fetchone()[0]
    if landed is None or landed.timestamp() < head_commit_epoch():           # now() proof
        return "DRIFT", "post-commit UPDATE did not land"
    return "OK", f"header synced to {head} (landed_at={landed})"

4. Tracked board dir → no -f: in terminal-jail board/ is not gitignored — git check-ignore -q board/events.parquet returns rc=1 (not ignored), so the write script asserts that and uses a plain git add board/events.parquet (never -f).
