Fix: CIGAR Indel Left-Shift and Split-Read Span Reconciliation

Root-cause analysis

The breakage comes from representation bugs that appear when split alignment records are edited or merged:

  1. Ambiguous indel placement in repeats — an indel in a homopolymer/tandem repeat has many equivalent CIGAR spellings. Without canonical left-most placement, records disagree even when the alignment is identical.
  2. Gaps cannot be moved by naive string surgery — shifting a gap changes which read base pairs with which reference base. The safe primitive is a column model ([read_base, ref_base]); move a gap one column left only when the base that becomes a match equals the base being absorbed.
  3. Adjacent I+D pairs — SAM permits them next to each other; they cancel into a single M column. Failing to collapse leaves non-canonical, non-idempotent CIGARs and breaks span arithmetic.
  4. Soft vs. hard clips — S bases are in SEQ; H bases are not. H→S needs the full read; S→H must trim SEQ/QUAL. Mixing them without query-coordinate tracking yields length mismatches and lost bases.
  5. Split-read reconciliation — each record covers a different read slice. Must verify: same full read length, disjoint aligned read intervals, and reference span unchanged by normalization.
  6. Boundary conditions — zero-length ops (0M), indels at the first/last column, and runs past the contig end need explicit guards; otherwise the column builder indexes past the reference or loops forever on P.

Exact fix

The verified fix is cigar_norm.py (pure stdlib, no pysam/samtools). It provides:

  • parse_cigar / format_cigar — strict parser; rejects garbage, keeps zero-length ops for detection, merges/drops later.
  • left_align_ops — column-model left shift of M/I/D runs; N, S, H are hard boundaries; validates contig/reference bounds; supports P.
  • _shift_gaps_left — insertion moves left when read[j-1] == ref[i-1]; deletion moves left when read[i-1] == ref[j-1].
  • _collapse_adjacent — folds adjacent I/D into one M.
  • normalize_cigar / normalize_record — enforces query length vs SEQ, preserves the aligned read subsequence and the reference span; supports --clip-mode soft|hard.
  • reconcile_qname — per-QNAME: recovers the full read from a non-hard-clipped record, converts hard clips when requested, verifies identical full read length, rejects overlapping aligned read intervals, and re-checks reference-span invariance. Returns QnameReconciliation with total span, covered bases, read intervals, and per-record spans.
  • total_reference_span — reports (span, union_bases, full_read_length) for a qname.
  • SAM/FASTA I/O and CLI; errors print cleanly to stderr and exit 2.

Key CLI usage:

python3 cigar_norm.py -r reference.fa < in.sam > out.sam
python3 cigar_norm.py -r reference.fa --clip-mode soft in.sam
python3 cigar_norm.py -r reference.fa --clip-mode hard in.sam
