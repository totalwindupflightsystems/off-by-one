Answer

Bufferbloat harness: HTB + fq_codel vs pfifo_fast over a veth pair

A single self-contained Bash script that builds a two-namespace veth testbed, shapes it to 8 Mbit with a 20 ms base RTT, runs three concurrent TCP flows, and machine-checks:

  • per-flow throughput within 10 % of a fair share,
  • 95th-percentile standing queue below 10 ms while the link is ≥ 80 % utilized,
  • per-flow throughput, RTT percentiles, drops and ECN marks, and max qdisc backlog in a JSON report,
  • the same tree with a pfifo_fast leaf as a contrast run that must demonstrate bufferbloat (otherwise the harness exits non-zero too).

It exits non-zero when any target is missed.

1. Root-cause analysis

1.1 Why a deep FIFO produces bufferbloat

pfifo_fast is the kernel's default qdisc and is little more than a 3-band tail-drop FIFO. Its depth is the interface txqueuelen (1000 packets by default). A TCP sender keeps increasing its congestion window until it sees loss. With a 1000-packet tail-drop buffer and an 8 Mbit bottleneck:

1000 packets x 1500 B = 1.5 MB
1.5 MB x 8 / 8_000_000 = 1.5 s of queuing delay

All flows of the same DSCP land in the same band, so there is no per-flow isolation and no AQM. The queue becomes a standing queue: while the link is saturated it never drains, so the local minimum RTT (the quantity CoDel controls) stays elevated for as long as the load lasts. This is bufferbloat.

1.2 Why an HTB class with an fq_codel leaf fixes it

  • HTB is a classful token-bucket shaper. It is what actually imposes the 8 Mbit bottleneck and gives us a class tree to attach the AQM to.
  • fq_codel = fair queuing + CoDel. It hashes each packet's flow (skb_get_hash, i.e. the 5-tuple plus a per-qdisc random perturbation) into one of flows per-flow queues, serves those queues round-robin using quantum bytes of deficit (DRR), and runs an independent CoDel instance on each. Three bulk TCP flows therefore each receive ≈ 1/3 of the shaped rate and each gets its own delay control loop.
  • CoDel tracks packet sojourn time (not queue length). It tolerates bursts but keeps the local minimum sojourn near target (5 ms). Once the minimum exceeds target for more than interval, it drops/marks to force the senders down. Because the control variable is time in the queue, the steady-state queue is bounded in milliseconds regardless of the link rate.
  • ECN: fq_codel has ecn on by default (the tc-fq_codel(8) man page says so explicitly, unlike codel). When both endpoints negotiate ECN, CoDel sets CE instead of dropping, so tc -s qdisc reports ecn_mark > 0 and drops near zero.

1.3 The tc stacking trap (why netem is on the return path)

netem is a classless, terminal qdisc:

  • it cannot be the parent of an fq_codel leaf, and
  • a class can have exactly one child qdisc, so you cannot hang both netem and fq_codel off the same HTB class.

The usual "apply netem delay and htb/fq_codel on the same interface root" recipe is therefore impossible without an extra device. The harness avoids it by putting:

  • the bottleneck + AQM on the forward path (root 1: htb -> 1:1 -> 1:10 -> 10: fq_codel), and
  • the 20 ms propagation delay on the return path (root 1: netem delay 20ms on the peer).

TCP's RTT is a round trip, so 20 ms of one-way delay on the ACK path produces a 20 ms base RTT while leaving the forward path free for the real qdisc under test. (If you ever need delay and shaping in the same direction, redirect to an IFB device and shape the IFB's egress — noted as an extension in §5.)

1.4 The measurement trap (sparse flows vs the standing queue)

A ping/ICMP flow hashes into a different fq_codel bucket and is served as a sparse ("new") flow, so its RTT stays near the base even while the bulk flows have a queue. Measuring only ping RTT therefore understates the standing queue. The harness measures the standing queue two independent ways and takes the conservative maximum:

  1. Backlog-derived queue delay — sample tc -s qdisc at 10 Hz and convert backlog bytes to time: delay_ms = backlog_bytes * 8 / rate_bps * 1000. Report max qdisc backlog in bytes and packets.
  2. RTT inflation — p95(loaded ping RTT) - p50(idle ping RTT).

This is faithful to CoDel's own definition: it controls packet-sojourn time, which for a saturated link is the standing queue.

1.5 Why the pfifo_fast contrast is a target, not an afterthought

The contrast run uses the same HTB tree and the same 8 Mbit rate, but a pfifo_fast leaf. If its p95 standing queue is not dramatically worse than fq_codel's, the experiment failed to demonstrate anything (e.g. the load was too small or the qdisc was not applied), so the harness treats that as a failed target and exits non-zero. The pass condition is pfifo_p95 >= max(20 ms, 2 x fq_codel_p95).

2. Topology

   bl_cli namespace                         bl_srv namespace
  +--------------------+                  +--------------------+
  |  vc <ip-address>/24   |<=== veth pair ===>|  vs <ip-address>/24   |
  |                    |                  |                    |
  | egress = BOTTLENECK|  forward data -> |                    |
  | root 1: htb 8mbit  |                  | egress = netem     |
  |   1:1              |  <- ACKs (delay) | root 1: netem      |
  |    1:10            |                  |      delay 20ms    |
  |     10: fq_codel   |                  |                    |
  +--------------------+                  +--------------------+
      iperf3 -c (x3)                         iperf3 -s (x3)
      ping under load                        (ACK path)

Direction under test is client → server ("upload"), so the bottleneck is the client egress qdisc. Three one-shot iperf3 -s -1 -p 5201..5203 servers and three concurrent iperf3 -c clients produce three independent TCP flows.

3. Exact tc commands

These are the commands the harness issues (it also logs every command it runs to $WORKDIR/tc_commands.txt, so the report is reproducible).

Forward path — client egress vc: 8 Mbit bottleneck + fq_codel AQM

tc qdisc add dev vc root handle 1: htb default 10
tc class add dev vc parent 1:   classid 1:1  htb rate 8mbit ceil 8mbit quantum 1514
tc class add dev vc parent 1:1  classid 1:10 htb rate 8mbit ceil 8mbit quantum 1514
tc qdisc add dev vc parent 1:10 handle 10: fq_codel \
    limit 10240 flows 1024 quantum 1514 target 5ms interval 100ms \
    ecn memory_limit 32mb drop_batch 64

Return path — server egress vs: 20 ms base RTT

tc qdisc add dev vs root handle 1: netem delay 20ms limit 10000

Contrast run — same tree, FIFO leaf

tc qdisc del dev vc root
tc qdisc add dev vc root handle 1: htb default 10
tc class add dev vc parent 1:   classid 1:1  htb rate 8mbit ceil 8mbit quantum 1514
tc class add dev vc parent 1:1  classid 1:10 htb rate 8mbit ceil 8mbit quantum 1514
tc qdisc add dev vc parent 1:10 handle 10: pfifo_fast

Inspection (what the analyser parses)

tc -s -d qdisc show dev vc     # leaf backlog, dropped, ecn_mark
tc -s   class show dev vc      # per-class backlog fallback

tc parameter notes:

  • target 5ms / interval 100ms are the CoDel defaults and are appropriate here: interval should be on the order of the worst-case RTT (20 ms base, 100 ms is comfortably larger). RFC 8289 (CoDel) / RFC 8290 (fq_codel).
  • quantum 1514 = Ethernet MTU (1500) + L2 header (14). Correct for a veth/MTU-1500 path; change it if the MTU changes.
  • flows 1024 can only be set when the qdisc is created (the hash table is allocated at load time).
  • ecn is already the default; it is written explicitly so the intent is unambiguous and so the report's ecn_mark counter is expected.

4. The harness (drop-in script)

Save as bufferbloat_harness.sh, chmod +x, run as root with iperf3 installed. It creates and tears down its own namespaces; nothing on the host interface is touched.

#!/usr/bin/env bash
# =============================================================================
# bufferbloat_harness.sh
#
# Reproducible bufferbloat / fairness harness built on a veth pair in private
# network namespaces.
#
#   client ns (bl_cli) --- vc ======= vs --- server ns (bl_srv)
#
# Direction under test is client -> server (upload), so the bottleneck qdisc is
# the *egress* qdisc of "vc" in the client namespace:
#
#     root 1: htb  (rate 8 Mbit)
#       +-- 1:1   (aggregate class)
#            +-- 1:10  (service class)
#                 +-- 10: fq_codel   (AQM leaf, ECN enabled)
#              or 10: pfifo_fast     (contrast leaf)
#
# A 20 ms base RTT is created with netem on the *return* path (server egress).
# TCP's RTT is a round trip, so 20 ms of one-way delay on the ACK path yields a
# 20 ms base RTT while leaving the forward path free for the real bottleneck
# qdisc (a qdisc cannot have both netem and HTB/fq_codel stacked in one
# direction without an extra IFB device).
#
# Two runs are executed:
#   fq_codel   - must meet: utilization, flow fairness, p95 standing queue
#   pfifo_fast - contrast; must demonstrate bufferbloat (p95 queue >> target)
#
# A machine-checkable JSON report is written to $REPORT.
# Exit status is 0 only if the fq_codel run passes every target *and* the
# pfifo_fast contrast run demonstrates the expected bufferbloat.
# =============================================================================
set -euo pipefail

# ------------------------------- configuration ------------------------------
NS_S="${NS_S:-bl_srv}"                 # server namespace (ACK sender)
NS_C="${NS_C:-bl_cli}"                 # client namespace (bottleneck egress)
VS="${VS:-vs}"                         # veth end inside server ns
VC="${VC:-vc}"                         # veth end inside client ns (bottleneck)
IP_S="${IP_S:-<ip-address>}"
IP_C="${IP_C:-<ip-address>}"
PREFIX="${PREFIX:-24}"

RATE_STR="${RATE_STR:-8mbit}"          # HTB shaping rate
LINK_RATE_BPS="${LINK_RATE_BPS:-8000000}"
BASE_RTT_MS="${BASE_RTT_MS:-20}"       # netem one-way delay on return path
NUM_FLOWS="${NUM_FLOWS:-3}"
DURATION="${DURATION:-30}"
SAMPLE_INTERVAL="${SAMPLE_INTERVAL:-0.1}"
PORT_BASE="${PORT_BASE:-5201}"

TARGET_UTIL="${TARGET_UTIL:-0.80}"              # >= 80% link utilization
TARGET_FAIRNESS="${TARGET_FAIRNESS:-0.10}"      # each flow within +/-10%
TARGET_QUEUE_P95_MS="${TARGET_QUEUE_P95_MS:-10}" # p95 standing queue < 10 ms
CONTRAST_MIN_MS="${CONTRAST_MIN_MS:-20}"        # pfifo_fast p95 must exceed
CONTRAST_RATIO="${CONTRAST_RATIO:-2.0}"         # ... and beat fq_codel by 2x

LEAF_HANDLE=10
MIN_IPERF_MIN="${MIN_IPERF_MIN:-10}"   # sanity: iperf duration must be >= this

WORKDIR="${WORKDIR:-$(mktemp -d /tmp/bufferbloat.XXXXXX)}"
KEEP_WORKDIR="${KEEP_WORKDIR:-0}"
SKIP_PRIVCHECK="${SKIP_PRIVCHECK:-0}"
REPORT="${REPORT:-$WORKDIR/report.json}"
TC_LOG="$WORKDIR/tc_commands.txt"
RUNNING="$WORKDIR/.running"
mkdir -p "$WORKDIR"

log()  { printf '[%s] %s\n' "$(date +%H:%M:%S)" "$*" >&2; }
die()  { log "ERROR: $*"; exit 1; }

SRV_PIDS=()
CLI_PIDS=()
BG_PIDS=()

# shellcheck disable=SC2329  # invoked indirectly via trap
cleanup() {
  local rc=$?
  trap - EXIT INT TERM
  rm -f "$RUNNING" 2>/dev/null || true
  local p
  for p in "${BG_PIDS[@]:-}" "${CLI_PIDS[@]:-}" "${SRV_PIDS[@]:-}"; do
    [ -n "$p" ] && kill "$p" 2>/dev/null || true
  done
  wait 2>/dev/null || true
  ip netns del "$NS_S" 2>/dev/null || true
  ip netns del "$NS_C" 2>/dev/null || true
  [ "$KEEP_WORKDIR" = 1 ] || rm -rf "$WORKDIR"
  exit "$rc"
}
trap cleanup EXIT INT TERM

# ----------------------------------- checks ----------------------------------
[ "$SKIP_PRIVCHECK" = 1 ] || [ "$(id -u)" -eq 0 ] \
  || die "must run as root (or set SKIP_PRIVCHECK=1 for the mock test harness)"
for c in ip tc iperf3 ping python3; do
  command -v "$c" >/dev/null 2>&1 || die "required tool not found: $c"
done
[ "$DURATION" -ge "$MIN_IPERF_MIN" ] \
  || die "DURATION=$DURATION is too short for stable statistics (>= $MIN_IPERF_MIN)"

if command -v modprobe >/dev/null 2>&1; then
  for m in sch_htb sch_netem sch_fq_codel cls_u32; do
    modprobe "$m" 2>/dev/null || true
  done
fi

# ------------------------------- tc helpers ----------------------------------
tc_s() { printf 'tc %s\n' "$*" >>"$TC_LOG"; ip netns exec "$NS_S" tc "$@"; }
tc_c() { printf 'tc %s\n' "$*" >>"$TC_LOG"; ip netns exec "$NS_C" tc "$@"; }

# ---------------------------------- topology ---------------------------------
setup_topo() {
  ip netns del "$NS_S" 2>/dev/null || true
  ip netns del "$NS_C" 2>/dev/null || true
  ip netns add "$NS_S"
  ip netns add "$NS_C"
  ip link add "$VS" type veth peer name "$VC"
  ip link set "$VS" netns "$NS_S"
  ip link set "$VC" netns "$NS_C"
  ip netns exec "$NS_S" ip addr add "$IP_S/$PREFIX" dev "$VS"
  ip netns exec "$NS_C" ip addr add "$IP_C/$PREFIX" dev "$VC"
  ip netns exec "$NS_S" ip link set lo up
  ip netns exec "$NS_C" ip link set lo up
  ip netns exec "$NS_S" ip link set "$VS" up
  ip netns exec "$NS_C" ip link set "$VC" up
  # pfifo_fast's depth is the interface txqueuelen; keep the classic 1000.
  ip netns exec "$NS_S" ip link set "$VS" txqueuelen 1000
  ip netns exec "$NS_C" ip link set "$VC" txqueuelen 1000
  # ECN is required for fq_codel to mark instead of drop.
  ip netns exec "$NS_S" sysctl -qw net.ipv4.tcp_ecn=1 2>/dev/null || true
  ip netns exec "$NS_C" sysctl -qw net.ipv4.tcp_ecn=1 2>/dev/null || true
}

# 20 ms base RTT: delay the return path only.
apply_netem() {
  tc_s qdisc del dev "$VS" root 2>/dev/null || true
  tc_s qdisc add dev "$VS" root handle 1: netem delay "${BASE_RTT_MS}ms" limit 10000
}

# HTB class tree + fq_codel AQM leaf.
#
# fq_codel grew parameters over time.  Try the modern full set first and fall
# back so the harness also runs on older kernels:
#   limit/flows/target/interval/quantum/ecn : Linux >= 3.5 (original fq_codel)
#   ce_threshold / ce_threshold_*           : Linux >= 4.2 / >= 5.16 (unused)
#   memory_limit                            : Linux >= 4.7
#   drop_batch                              : Linux >= 4.7
# (See the kernel-version notes in the accompanying write-up.)
apply_fq_codel() {
  tc_c qdisc del dev "$VC" root 2>/dev/null || true
  tc_c qdisc add dev "$VC" root handle 1: htb default "$LEAF_HANDLE"
  tc_c class add dev "$VC" parent 1: classid 1:1 htb \
      rate "$RATE_STR" ceil "$RATE_STR" quantum 1514
  tc_c class add dev "$VC" parent 1:1 classid "1:$LEAF_HANDLE" htb \
      rate "$RATE_STR" ceil "$RATE_STR" quantum 1514
  local -a base=(parent "1:$LEAF_HANDLE" handle "$LEAF_HANDLE:" fq_codel)
  local -a common=(limit 10240 flows 1024 quantum 1514 target 5ms interval 100ms ecn)
  if ip netns exec "$NS_C" tc qdisc add dev "$VC" "${base[@]}" \
        "${common[@]}" memory_limit 32mb drop_batch 64 2>/dev/null; then
    printf 'tc qdisc add dev %s parent 1:%s handle %s: fq_codel %s memory_limit 32mb drop_batch 64\n' \
      "$VC" "$LEAF_HANDLE" "$LEAF_HANDLE" "${common[*]}" >>"$TC_LOG"
  elif ip netns exec "$NS_C" tc qdisc add dev "$VC" "${base[@]}" \
        "${common[@]}" memory_limit 32mb 2>/dev/null; then
    printf 'tc qdisc add dev %s parent 1:%s handle %s: fq_codel %s memory_limit 32mb\n' \
      "$VC" "$LEAF_HANDLE" "$LEAF_HANDLE" "${common[*]}" >>"$TC_LOG"
  else
    tc_c qdisc add dev "$VC" "${base[@]}" "${common[@]}"
  fi
}

# Same HTB class tree, but a plain FIFO leaf (this is the "before" picture).
apply_pfifo_fast() {
  tc_c qdisc del dev "$VC" root 2>/dev/null || true
  tc_c qdisc add dev "$VC" root handle 1: htb default "$LEAF_HANDLE"
  tc_c class add dev "$VC" parent 1: classid 1:1 htb \
      rate "$RATE_STR" ceil "$RATE_STR" quantum 1514
  tc_c class add dev "$VC" parent 1:1 classid "1:$LEAF_HANDLE" htb \
      rate "$RATE_STR" ceil "$RATE_STR" quantum 1514
  tc_c qdisc add dev "$VC" parent "1:$LEAF_HANDLE" handle "$LEAF_HANDLE:" pfifo_fast
}

# ---------------------------------- workload ---------------------------------
sample_qdisc() {
  local out="$1"
  : >"$out"
  while [ -e "$RUNNING" ]; do
    printf '#TS %s\n' "$(date +%s.%N)" >>"$out"
    ip netns exec "$NS_C" tc -s qdisc show dev "$VC" >>"$out" 2>/dev/null || true
    sleep "$SAMPLE_INTERVAL"
  done
}

run_ping() {
  local out="$1" count="$2" interval="$3"
  ip netns exec "$NS_C" ping -n -c "$count" -i "$interval" -W 5 "$IP_S" \
    >"$out" 2>&1 || true
}

start_servers() {
  SRV_PIDS=()
  local i port
  for i in $(seq 1 "$NUM_FLOWS"); do
    port=$((PORT_BASE + i - 1))
    ip netns exec "$NS_S" iperf3 -s -1 -p "$port" \
      >"$WORKDIR/srv.$i.log" 2>&1 &
    SRV_PIDS+=("$!")
  done
}

start_clients() {
  CLI_PIDS=()
  local i port
  for i in $(seq 1 "$NUM_FLOWS"); do
    port=$((PORT_BASE + i - 1))
    ip netns exec "$NS_C" iperf3 -c "$IP_S" -p "$port" -t "$DURATION" -J \
      >"$WORKDIR/flow.$i.json" 2>"$WORKDIR/flow.$i.err" &
    CLI_PIDS+=("$!")
  done
}

run_scenario() {
  local mode="$1"
  log "scenario: $mode"
  apply_netem
  case "$mode" in
    fq_codel)   apply_fq_codel ;;
    pfifo_fast) apply_pfifo_fast ;;
    *)          die "unknown scenario $mode" ;;
  esac

  # Baseline RTT with an idle link.
  run_ping "$WORKDIR/ping.idle.$mode" 20 0.1

  touch "$RUNNING"
  sample_qdisc "$WORKDIR/qdisc.$mode" &
  local sampler=$!
  BG_PIDS+=("$sampler")

  start_servers
  sleep 1.0

  run_ping "$WORKDIR/ping.load.$mode" $((DURATION * 10)) 0.1 &
  local pinger=$!
  BG_PIDS+=("$pinger")

  start_clients
  local failed=0 p
  for p in "${CLI_PIDS[@]}"; do
    wait "$p" || failed=1
  done
  [ "$failed" = 0 ] || log "WARN: one or more iperf3 clients exited non-zero"

  rm -f "$RUNNING"
  wait "$sampler" 2>/dev/null || true
  wait "$pinger"  2>/dev/null || true
  for p in "${SRV_PIDS[@]}"; do kill "$p" 2>/dev/null || true; done
  wait 2>/dev/null || true

  # Append the final cumulative counters (dropped / ecn_mark).
  ip netns exec "$NS_C" tc -s qdisc show dev "$VC" >>"$WORKDIR/qdisc.$mode" 2>/dev/null || true
}

# ---------------------------------- analyzer ---------------------------------
cat >"$WORKDIR/analyze.py" <<'PYEOF'
#!/usr/bin/env python3
"""Analyze harness artefacts and emit a machine-checkable JSON report."""
import json
import os
import re
import sys

work = sys.argv[1]
outpath = sys.argv[2]

LINK = float(os.environ["LINK_RATE_BPS"])
NUM = int(os.environ["NUM_FLOWS"])
TARGET_UTIL = float(os.environ["TARGET_UTIL"])
TARGET_FAIR = float(os.environ["TARGET_FAIRNESS"])
TARGET_Q = float(os.environ["TARGET_QUEUE_P95_MS"])
CONTRAST_MIN = float(os.environ["CONTRAST_MIN_MS"])
CONTRAST_RATIO = float(os.environ["CONTRAST_RATIO"])
BASE_RTT_MS = float(os.environ["BASE_RTT_MS"])
LEAF = os.environ["LEAF_HANDLE"]


def percentile(values, p):
    if not values:
        return None
    s = sorted(values)
    if len(s) == 1:
        return s[0]
    k = (len(s) - 1) * (p / 100.0)
    lo = int(k)
    hi = min(lo + 1, len(s) - 1)
    return s[lo] + (s[hi] - s[lo]) * (k - lo)


def summarise(values):
    if not values:
        return {"count": 0}
    return {
        "count": len(values),
        "min": min(values),
        "p50": percentile(values, 50),
        "p95": percentile(values, 95),
        "p99": percentile(values, 99),
        "max": max(values),
        "mean": sum(values) / len(values),
    }


def parse_qdisc(path):
    """Return (samples[(ts,backlog_bytes,backlog_pkts)], dropped, ecn_mark)."""
    samples = []
    dropped = 0
    ecn = 0
    cur_handle = None
    ts = 0.0
    want = LEAF + ":"
    try:
        fh = open(path, "r", errors="replace")
    except FileNotFoundError:
        return samples, dropped, ecn
    with fh:
        for line in fh:
            line = line.strip()
            m = re.match(r"#TS\s+([0-9.]+)", line)
            if m:
                ts = float(m.group(1))
                continue
            m = re.match(r"qdisc\s+\S+\s+(\S+)", line)
            if m:
                cur_handle = m.group(1)
                continue
            if cur_handle != want:
                continue
            m = re.search(r"backlog\s+(\d+)b\s+(\d+)p", line)
            if m:
                samples.append((ts, int(m.group(1)), int(m.group(2))))
                continue
            m = re.search(r"\(dropped\s+(\d+)", line)
            if m:
                dropped = max(dropped, int(m.group(1)))
                continue
            m = re.search(r"ecn_mark\s+(\d+)", line)
            if m:
                ecn = max(ecn, int(m.group(1)))
    return samples, dropped, ecn


def parse_ping(path):
    times = []
    try:
        fh = open(path, "r", errors="replace")
    except FileNotFoundError:
        return times
    with fh:
        for line in fh:
            m = re.search(r"time[=<]\s*([0-9.]+)\s*ms", line)
            if m:
                times.append(float(m.group(1)))
    return times


def parse_iperf(path):
    try:
        with open(path, "r", errors="replace") as fh:
            data = json.load(fh)
    except Exception as exc:  # noqa: BLE001 - report any parse failure
        return None, 0, str(exc)
    end = data.get("end", {})
    sent = end.get("sum_sent") or {}
    recv = end.get("sum_received") or end.get("sum") or {}
    bps = recv.get("bits_per_second")
    if bps is None:
        bps = sent.get("bits_per_second", 0.0)
    return float(bps), int(sent.get("retransmits", 0) or 0), None


def run_result(mode):
    samples, dropped, ecn = parse_qdisc(os.path.join(work, "qdisc.%s" % mode))
    backlog_bytes = [s[1] for s in samples]
    backlog_pkts = [s[2] for s in samples]
    queue_ms = [b * 8.0 / LINK * 1000.0 for b in backlog_bytes]

    idle = parse_ping(os.path.join(work, "ping.idle.%s" % mode))
    loaded = parse_ping(os.path.join(work, "ping.load.%s" % mode))
    base_rtt = percentile(idle, 50) if idle else None
    rtt = summarise(loaded)
    inflation_p95 = None
    if base_rtt is not None and rtt.get("p95") is not None:
        inflation_p95 = max(0.0, rtt["p95"] - base_rtt)

    flows = []
    retrans = 0
    flow_errors = []
    for i in range(1, NUM + 1):
        bps, retr, err = parse_iperf(os.path.join(work, "flow.%d.json" % i))
        if bps is None:
            flow_errors.append("flow%d: %s" % (i, err))
            flows.append(0.0)
        else:
            flows.append(bps)
            retrans += retr

    total = sum(flows)
    utilization = total / LINK if LINK else 0.0
    fair = total / NUM if NUM else 0.0
    devs = [abs(f - fair) / fair for f in flows] if fair else []
    max_dev = max(devs) if devs else None

    q95 = percentile(queue_ms, 95) if queue_ms else 0.0
    q_max = max(queue_ms) if queue_ms else 0.0
    standing_p95 = max([v for v in (q95, inflation_p95) if v is not None] or [0.0])

    failed = []
    if not (utilization >= TARGET_UTIL and utilization <= 1.10):
        failed.append("utilization")
    if max_dev is None or max_dev > TARGET_FAIR:
        failed.append("fairness")
    if standing_p95 >= TARGET_Q:
        failed.append("queue")
    if flow_errors:
        failed.append("flows")
    if not samples:
        failed.append("no_backlog_samples")

5.1 How to run

Exit status:

  • 0 — fq_codel met utilization, fairness, standing-queue and base-RTT targets and the pfifo_fast contrast demonstrated bufferbloat.
  • non-zero — any target missed (or the contrast failed to demonstrate the difference, or a tc/measurement step failed).

Every threshold is overridable, e.g. TARGET_QUEUE_P95_MS=3 TARGET_UTIL=0.9 sudo -E ./bufferbloat_harness.sh.

5.2 Target definitions

Target Check Default
Utilization aggregate_bps / link_rate_bps >= 0.80 TARGET_UTIL=0.80
Fairness every flow within ±10 % of the achieved mean TARGET_FAIRNESS=0.10
Standing queue p95 max(backlog p95, RTT inflation p95) < 10 ms TARGET_QUEUE_P95_MS=10
Base RTT sane idle ping p50 within [0.5, 2.0] x 20 ms BASE_RTT_MS=20
Contrast pfifo_p95 >= max(20 ms, 2 x fq_codel_p95) CONTRAST_MIN_MS=20, CONTRAST_RATIO=2.0

Fair share is computed as the achieved aggregate divided by the number of flows, which is the max-min fair share actually available to the flows; the absolute link-rate share (8 Mbit / 3 ≈ 2.667 Mbit) is also reported. The harness drives the link to saturation (typically ~95–100 % utilization) and evaluates the standing queue over that loaded interval; requiring ≥ 80 % utilization is the "at 80 % link utilization" operating point.

Practical consequences:

  • The script starts with the full modern option set and falls back to memory_limit-only, then to the original 3.5 option set, so it runs from Linux 3.5 through current kernels. The successful command is the one logged in tc_commands.txt.
  • The report records uname().release, so any version-specific difference is attributable.
  • Required kernel config: CONFIG_NET_SCH_FQ_CODEL, CONFIG_NET_SCH_HTB, CONFIG_NET_SCH_NETEM (and CONFIG_NET_CLS_U32 if you extend the tree with u32 filters). The script modprobes these best-effort.
  • interval (100 ms) must be ≥ the worst-case RTT; with the 20 ms base RTT here it is. If you raise the base RTT above ~50 ms, raise interval too.
  • ECN marking (ecn_mark) is only exercised if both endpoints negotiate ECN; the script sets net.ipv4.tcp_ecn=1 in both namespaces. On a kernel where iperf3's TCP does not negotiate ECN, expect dropped > 0, ecn_mark == 0 and the same latency target still applies.

6. Extending to multiple fq_codel leaves

The script uses one shared fq_codel leaf so that fq_codel's own flow hashing — not HTB's class weights — is what produces per-flow fairness and per-flow latency control. To force a literal multi-leaf tree (e.g. per service class, or to pin each flow to its own class), replicate the class + leaf and classify by destination port (clients upload to three distinct server ports):

tc qdisc add dev vc root handle 1: htb default 30
tc class add dev vc parent 1:  classid 1:1  htb rate 8mbit ceil 8mbit quantum 1514
for i in 10 20 30; do
  tc class add dev vc parent 1:1 classid 1:$i htb \
      rate 2666kbit ceil 8mbit quantum 1514
  tc qdisc add dev vc parent 1:$i handle $i: fq_codel \
      limit 10240 flows 1024 quantum 1514 target 5ms interval 100ms \
      ecn memory_limit 32mb drop_batch 64
done
tc filter add dev vc protocol ip parent 1: prio 1 u32 match ip dport 5201 0xffff flowid 1:10
tc filter add dev vc protocol ip parent 1: prio 1 u32 match ip dport 5202 0xffff flowid 1:20
tc filter add dev vc protocol ip parent 1: prio 1 u32 match ip dport 5203 0xffff flowid 1:30

Caveat: once each flow owns a class, per-flow fairness is enforced by HTB's equal rates and the fq_codel flow isolation is no longer what is being tested; also a stray sparse flow (e.g. ping) in the default class will not share the data leaf's queue, so the RTT-based contrast is weaker (the backlog-based standing-queue measurement still catches it).
