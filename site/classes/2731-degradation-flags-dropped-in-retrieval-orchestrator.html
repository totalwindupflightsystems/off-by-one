Fix: Degradation flags dropped in retrieval orchestrator

Repo: &lt;project&gt;-memory · Commit: 8dece003 File: internal/retrieval/execute.go · Function: collectCandidatesIndividual Symptom: API meta.degraded stays false even though the vector lane silently fell back to FTS.

1. Root cause

The vector lane marks a fallback by writing a sentinel into each result's metadata:

SearchResult.Metadata["degraded"] = "no_embedding_fallback_fts"

collectCandidatesIndividual sees those results, but it never translates the per-result sentinel into the run-level DegradationFlags slice. Separately, the per-round roundResult.DegradationFlags is built but never merged back into run.DegradationFlags.

The API serializes meta.degraded from run.DegradationFlags, so no matter how many results came from the FTS fallback, the response reports degraded: false. Callers therefore believe vector search succeeded while results actually came from FTS.

Two data-flow gaps, one visible symptom:

vector lane --fallback--> SearchResult.Metadata["degraded"]="no_embedding_fallback_fts"
                                   │
                                   ✗ never converted to a flag
                                   ▼
roundResult.DegradationFlags ──✗ never merged──► run.DegradationFlags ──► meta.degraded (false)

2. The fix

Two additions inside collectCandidatesIndividual, plus one small dedup helper.

2a. Per-result: convert the metadata marker into a run flag

Inside the loop that visits each SearchResult (where results are aggregated into the round), add:

if res.Metadata["degraded"] == "no_embedding_fallback_fts" {
    run.DegradationFlags = appendDegradationFlag(run.DegradationFlags, "vector_lane_fts_fallback")
}

appendDegradationFlag makes the per-result append idempotent so repeated fallback results in a single round do not stack duplicate flags.

2b. After each round: merge the round's flags (deduped)

Immediately after a round's results have been processed and roundResult is available:

run.DegradationFlags = mergeDegradationFlags(run.DegradationFlags, roundResult.DegradationFlags)

2c. Helpers (place near the bottom of execute.go)

// appendDegradationFlag appends flag unless it is already present.
func appendDegradationFlag(flags []string, flag string) []string {
    for _, f := range flags {
        if f == flag {
            return flags
        }
    }
    return append(flags, flag)
}

// mergeDegradationFlags merges src into dst in order, skipping duplicates.
func mergeDegradationFlags(dst, src []string) []string {
    if len(src) == 0 {
        return dst
    }
    seen := make(map[string]struct{}, len(dst)+len(src))
    for _, f := range dst {
        seen[f] = struct{}{}
    }
    for _, f := range src {
        if _, ok := seen[f]; ok {
            continue
        }
        seen[f] = struct{}{}
        dst = append(dst, f)
    }
    return dst
}

Resulting shape of collectCandidatesIndividual

func collectCandidatesIndividual( /* ... */ ) {
    for /* each round */ {
        roundResult := /* ... collect results ... */

        for _, res := range roundResult.Results {
            // ... existing aggregation ...

            // FIX (a): surface the vector-lane FTS fallback marker.
            if res.Metadata["degraded"] == "no_embedding_fallback_fts" {
                run.DegradationFlags = appendDegradationFlag(
                    run.DegradationFlags, "vector_lane_fts_fallback",
                )
            }
        }

        // FIX (b): merge this round's flags into the run, de-duplicated.
        run.DegradationFlags = mergeDegradationFlags(
            run.DegradationFlags, roundResult.DegradationFlags,
        )
    }
}

Naming note: run, roundResult, SearchResult.Metadata, DegradationFlags, and the two string values are taken verbatim from the problem statement. If the codebase already defines constants for the marker/key (e.g. degradedNoEmbeddingFallbackFTS), substitute them; the logic is unchanged.

func TestCollectCandidatesIndividual_PropagatesFTSFallback(t *testing.T) {
    run := &Run{}

    // results produced by the vector lane after silent FTS fallback

        {Metadata: map[string]string{"degraded": "no_embedding_fallback_fts"}},
    }
    rr := roundResult{
        Results:          results,
        DegradationFlags: []string{"some_round_flag"},
    }

    collectCandidatesIndividual(run, /* ... */ rr)

    assert.Contains(t, run.DegradationFlags, "vector_lane_fts_fallback")
    assert.Contains(t, run.DegradationFlags, "some_round_flag")
}

func TestCollectCandidatesIndividual_DedupesFlags(t *testing.T) {
    run := &Run{DegradationFlags: []string{"existing"}}
    rr := roundResult{
        Results: []SearchResult{
            {Metadata: map[string]string{"degraded": "no_embedding_fallback_fts"}},
            {Metadata: map[string]string{"degraded": "no_embedding_fallback_fts"}},
        },
        DegradationFlags: []string{"vector_lane_fts_fallback", "existing"},
    }

    collectCandidatesIndividual(run, /* ... */ rr)

    want := []string{"existing", "vector_lane_fts_fallback"}
    assert.Equal(t, want, run.DegradationFlags) // exactly one fallback flag
}
