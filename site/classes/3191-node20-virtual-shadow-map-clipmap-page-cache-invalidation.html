Virtual Shadow Map (clipmap) with correct page-cache invalidation

Environment: Node.js 20+ (validated on v22.23.4), CommonJS, zero dependencies. Run: node ~/vsm/verify.js (deterministic, exit 0 on success).

1. Root-cause analysis

The hard part of a virtual shadow map is never the rasterizer — it is the validity model of the page cache. Four defects reproduce the classic symptoms (holes, ghosting, shimmer, stalls, leaks). Each was reproduced, measured, then fixed:

Bug 1 — pages keyed in camera-relative space (shimmer + total cache churn). If a page is identified relative to the current cascade origin, or if the validity hash includes the continuously-changing light basis, then every camera move invalidates every page. Reproduced: cacheMissRate = 1.0, every page re-rasterized every frame. Fix: world-anchored light-space keys u = dot(p,right), v = dot(p,up); only the origin is texel-snapped. Overlapping world regions keep the same key across camera motion.

Bug 2 — invalidating on depth bounds only (ghosting from lateral motion). A conservative min/max depth test catches an occluder moving along the light, but an occluder sliding tangentially inside a page leaves its depth range unchanged while page contents change. Reproduced: maxDepthErr ≈ 3.9 world units on thin grazing occluders. Fix: invalidate on a geometry signature — the set of overlapping occluders by stable id + transform version, plus their projected u/v footprint quantized to the texel grid. Depth min/max and HZB remain as a secondary check.

Bug 3 — never-rendered/empty pages treated as valid. Sampling a not-yet-rasterized page (still Infinity) as lit creates holes; bilinearly blending Infinity with a real texel yields a bogus finite depth (≈1e17). Reproduced maxDepthErr ≈ 1e17, maxShadowErr = 1. Fix: explicit state (valid, requested, staleThisFrame, hzb), HZB-presence test, and fallback to the next coarser resident level.

Bug 4 — unbounded requests / no eviction (stalls + leaks). Fix: prioritized request queue bounded by pageBudget; LRU/priority eviction that never touches a page used this frame; a per-frame audit() asserting map.size == resident and free + resident == poolSize.

Bug 5 — verification aliasing (false "depth error"). Comparing a bilinear cache sample against a nearest 512² reference at a silhouette, with unnormalized world depth, manufactures errors. The cache matches a fresh render exactly; the metric was wrong. Fix: same-side nearest sampling, a two-sided 3×3 silhouette guard, depth normalized by cascade extent, and transient budget-deferred samples reported separately (staleRate).

2. The fix (key code)

// 2.1 World-anchored keys + texel-snapped origin (page identity stable under camera motion)
const u = V.dot(focus, basis.right);
const u0s = Math.floor(u / texel) * texel;          // snap ORIGIN only
const jx  = Math.floor(uPoint / st.pageWorld);      // world-anchored page index
const key = level + ':' + jx + ':' + jy;

// 2.2 Geometry-signature invalidation (the critical fix for lateral motion)
sig += bi + ':' + box.version + ':' +
       ((buMin-uMin)/st.texel).toFixed(2) + ',' + ((buMax-uMin)/st.texel).toFixed(2) + ',' +
       ((bvMin-vMin)/st.texel).toFixed(2) + ',' + ((bvMax-vMin)/st.texel).toFixed(2) + ';';
if (slot.basisHash !== basisHash)          stale = true;
if (!slot.valid || !slot.hzb)              stale = true;   // never rendered
else if (slot.sig !== sig)                 stale = true;   // moved / edited geometry
else if (Math.abs(mn - slot.boundMin) > eps ||
         Math.abs(mx - slot.boundMax) > eps) stale = true;

// 2.3 HZB state + fully-lit fast path
const root = slot.hzb[slot.hzb.length - 1];                // 1x1 min/max root
if (sR <= root.min[0] + bias) return /* whole page lit */;

// 2.4 Budget + LRU/priority eviction + leak audit
requested.sort((a,b) => a.level - b.level || dist2(a) - dist2(b));
for (const s of requested) { if (rendered >= this.pageBudget) break;
  this._renderPage(s, basis, boxes); rendered++; }
// _evict(): skip s.lastUsed === this.frame; prefer old + coarse + invalid
// audit(): map.size === resident && free + resident === poolSize
