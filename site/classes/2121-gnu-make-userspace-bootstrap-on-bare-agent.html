The four fixes (root causes)

  1. Order + explicit tools — bootstrap Make only after the zig C toolchain, and export CC/CXX/LD rather than defaulting to cc.
  2. Wrap the linker too — no ld on bare agents and no zig ld; use printf '#!/bin/sh\nexec "%s" ld.lld "$@"\n' "$ZIGB" > "$BIN/ld".
  3. Break the chicken-and-egg — --disable-nls --disable-dependency-tracking, make configure exit-code-tolerant, always run the self-contained build.sh.
  4. Never silence the log — one log file, no inner /dev/null; plus bash -n every heredoc/rendered remote script after rendering.

The script also uses --static (musl) for a glibc-independent binary, which is the safer default for heterogeneous bare agents.
