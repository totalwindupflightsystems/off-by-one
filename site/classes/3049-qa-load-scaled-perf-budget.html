Answer

I diagnosed the failure, reproduced it, and verified the fix on the real repo (github.com/trouble-agent/trouble, fix commit b17bdd4). The full write-up is at ~/solution.md.

Summary

Root cause: loadfence.MemCap() only read the TROUBLE_TEST_MEMLIMIT env override and the cgroup v2/v1 memory files. The QA chaos-resource leg caps the suite with ulimit -v 3145728 (RLIMIT_AS), which moves no cgroup file, so MemCap() returned -1 ("no ceiling"). Consequently SkipUnderMemCap/CappedN never fired and the load-only Miss fence was blind to cap pressure (which slows producers/GC without moving load_avg). A secondary bug: MemCap returned the first cgroup cap, not the tightest.

Fix (4 parts): 1. New rlimitMemCeiling() per-OS reader for RLIMIT_AS/RLIMIT_DATA (unix; !unix stub returns none), dropping RLIM_INFINITY/>1<<62 sentinels. 2. MemCap() collects cgroup v2 + cgroup v1 + rlimits into namedCeiling and resolves the tightest via tightestCeiling. 3. MissUnderPressure/pressureSkipReason SKIP a missed host-measured verdict when the load fence or a detected memory ceiling explains it, and t.Errorf (FAIL) otherwise. 4. Ledger (TestFsyncCountIsStructural, TestAmortizedThroughput) and sensors (TestRuleEvaluationBudget256Rules) routed through MissUnderPressure; dashboard's existing SkipUnderMemCap now sees the rlimit.

Key new code (full patch is in the doc):

//go:build unix
func rlimitMemCeiling() (int64, string, bool) {
    best, name := int64(-1), ""
    for _, r := range []struct{ resource int; name string }{
        {syscall.RLIMIT_AS, "RLIMIT_AS(ulimit -v)"},
        {syscall.RLIMIT_DATA, "RLIMIT_DATA(ulimit -d)"},
    } {
        var lim syscall.Rlimit
        if err := syscall.Getrlimit(r.resource, &lim); err != nil { continue }
        if lim.Cur > 1<<62 { continue } // RLIM_INFINITY sentinel
        if best < 0 || int64(lim.Cur) < best { best, name = int64(lim.Cur), r.name }
    }
    if best <= 0 { return 0, "", false }
    return best, "rlimit:" + name, true
}

func pressureSkipReason(gate, measured string, load float64) (string, bool) {
    if Oversubscribed(load) { return SkipText(gate, measured, load), true }
    if capBytes, source := MemCap(); capBytes > 0 {
        return fmt.Sprintf("%s SKIP: host under a memory ceiling — %s; ...: %s",
            gate, MemCapText(capBytes, source), measured), true
    }
    return "", false
}

Falsifiability is preserved: TROUBLE_TEST_MEMLIMIT still wins alone, and the no pressure: the verdict fails row asserts an un-pressured miss still FAILs.
