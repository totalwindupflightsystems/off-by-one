What was wrong (root causes)

Failure mode Naive bug Fix
Readers see partial objects writing directly to the final path stage in tmp/, publish with atomic rename(2)
Concurrent producers duplicate/overlapping writes per-digest mkdir producer lock
Stale locks PID-file reclaim has an ABA race serialize all lock-dir mutations with flock on a .guard file; owner = pid boot_id host starttime
Symlink / traversal digest interpolated into path strict ^[0-9a-f]{64}$ + component-by-component symlink checks; objects must be -f and ! -L
GC deletes in-use object check-then-unlink shared flock for readers/writers, exclusive -n for GC, re-check under the lock
Interrupted writes partial visible / garbage unique tmp names + grace-period GC of tmp/
