Answer

Root cause. integration-guide.md instructed readers to run pip install hermes-h3-shim. That distribution was never uploaded to PyPI — the package's canonical distribution name is hermes-h3-shim (confirmed by the wheel built from source: hermes_h3_shim-0.1.0-py3-none-any.whl), but only the GitHub source repo exists. PyPI returns HTTP 404 for it, so every reader hit E404 / No matching distribution found.

Fix (doc-only change to integration-guide.md). Replace the dead PyPI install command with a direct install from the source repository, matching the sdk-python convention of installing from the get-h3 GitHub org:

- pip install hermes-h3-shim
+ pip install git+https://github.com/get-h3/shim

Corrected documentation section (the file's install block now reads):

# Install the H3 harness shim (distribution: hermes-h3-shim; published
# only as source on GitHub, not on PyPI)
pip install git+https://github.com/get-h3/shim

Verification instructions that accompany the doc:

python3 -m venv .venv && source .venv/bin/activate
