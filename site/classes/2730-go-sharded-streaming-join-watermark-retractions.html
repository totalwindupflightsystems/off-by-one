Answer

Streaming Interval Join over Resharded Workers: Exactly-Once Handoff + Minimum Retention

Below is a complete, self-contained Go implementation plus the reasoning. Everything in §4 was actually built and run against go1.26 in ~/solution.

1. Root-cause analysis

The class of bugs here is not "the interval overlap test is wrong." It is that four independent lifecycle facts are conflated:

Symptom Actual root cause
Unbounded memory / OOM State is keyed by event and never dropped. Watermarks exist but no provably-safe eviction cutoff.
Out-of-order gives wrong join Matches are computed at insert time only against currently live opposite events; the operator has no stable notion of "still relevant."
Duplicate results / double counting Event replay after a crash re-runs insert, and re-emits a match that already went out. There is no per-row idempotency key.
Late retraction leaves stale results Matches are derived on the fly and not indexed by endpoint, so retracting one side cannot find the pairs to retract.
Migration omits matches Source quiesces but the target never receives state, or the source keeps emitting while the target starts from scratch.
Migration double-counts Source and target both own the key during an overlap window, or a checkpoint is replayed and re-emits.

The specific poison is the migration crash window between quiesce and ownership commit. A naive handoff:

stop source; copy state; start target

At least one of these is always true across a crash: - If you commit ownership before the copy is durable → omission. - If you commit after, without fencing → double count during the overlap. - If you replay from an older checkpoint → duplicate emission.

And retention fails because the naive rule evict when wm > TS + lateness ignores that a long interval can still be matched by a new event whose Start reaches back by the max interval length, and because active matches must survive until both endpoints can no longer be retracted.

2. Model and assumptions

  • Two streams L and R; equi-join on Key; intervals are inclusive [Start, End]; match iff same Key and Start_a <= End_b && Start_b <= End_a.
  • Each event has a globally unique ID and satisfies Start <= TS <= End and End-Start <= D (MaxIntervalLen).
  • L (AllowedLateness): an insert is accepted iff TS >= globalWM - L. globalWM = min(per-source watermark).
  • A retract references an existing row by ID and is honored iff that row is still retained; it is not subject to the insert lateness bound (otherwise every retraction of an old row would be rejected before it could run).
  • State is fully partitioned by Key. Therefore a reshard is a set of atomic per-key ownership transfers.

3. Exact fix

3.1 Idempotent core join

  • Maintain Live[id], per-id Applied dedup record, Active[matchID], and an inverse index ByEvent[id] -> matchIDs.
  • matchID is deterministic (L:<id>|R:<id>), so replay produces the same identity.
  • Insert emits only for matches not already active.
  • Retract walks ByEvent[id], emits Retract for active pairs, then marks the row retracted. Re-delivery of either action is ignored.

3.2 Minimum retention rule (derived, not guessed)

For a retained event e, a future accepted opposite event b has b.TS >= globalWM - L. Since b.Start >= b.TS - D and b.End >= b.TS:

b.Start >= globalWM - L - D

b cannot overlap e if b.Start > e.End, i.e. if

globalWM - L - D > e.End     ⇔     globalWM > e.End + L + D

So:

Evict event e iff globalWM > e.End + L + D (strict; equality retains).

A retraction for e carries e's original TS <= e.End, so the same cutoff also guarantees no future retraction can touch e. Dedup entries are dropped on the same horizon. A match is GC'd only when both endpoints are evicted, because a surviving endpoint can still be retracted by a late retraction.

This is minimum in the sense that dropping earlier can lose a legitimate overlap or retraction. The bounded-state test below confirms the steady state depends only on L + D, never on history length.

3.3 Ownership handoff & checkpoint protocol

Per key, with a monotonically increasing ownership epoch:

  1. Quiesce + snapshot: source sets Frozen[key], takes a deep copy, writes it durably (store.Put). Events arriving while frozen are buffered.
  2. Install (idempotent): target decodes the checkpoint, sets epoch, and installs. Installing an epoch <= current is a no-op, so duplicate/retried transfers are harmless.
  3. Commit (fence switch): coordinator sets owner = target, epoch++.
  4. Release: source drops local state only if its epoch still matches.

Crash table: - Crash before step 1 completes → no durable snapshot, rerun; nothing moved. - Crash after 1, before 3 → store has the snapshot, source is frozen and buffering; recover by re-Install, then commit. - Crash after 3 → target owns the new epoch; replaying Install is a no-op and the old source's writes are epoch-fenced.

Exactly-once: deterministic matchID + idempotent sink State[MatchID] + epoch fencing. A replayed or stale write with the same (MatchID, Action) is a no-op; a stale write with a different action is rejected by the fence.

package streamjoin

import (
    "bytes"
    "encoding/gob"
    "fmt"
    "math"
)

// Kind is the logical action carried by an event or emitted by the join.
type Kind uint8

const (
    Insert Kind = iota
    Retract
)

func (k Kind) String() string {
    if k == Insert {
        return "insert"
    }
    return "retract"
}

// Event is an interval row from one of the two joined streams.
//
// Invariant: Start <= TS <= End and End-Start <= Config.MaxIntervalLen.
type Event struct {
    ID    string // globally unique logical row id (idempotency key)
    Key   string // equi-join key; state is fully partitioned by Key
    Src   string // "L" or "R"
    Seq   uint64 // per-source monotonic sequence (for observability)
    TS    int64  // event time
    Start int64  // inclusive interval start
    End   int64  // inclusive interval end
    Kind  Kind   // Insert or Retract (retract carries the row's original TS)
}

// Change is a single result mutation the join wants to push downstream.
type Change struct {
    MatchID string
    Key     string
    L       string
    R       string
    Action  Kind
}

// MatchRec is a live (currently inserted) match.
type MatchRec struct {
    Key string
    L   string
    R   string
}

type appliedRec struct {
    Kind Kind
    End  int64 // used to GC the dedup entry at the retention horizon
}

// KeyState is the complete bounded state for a single join key. It is the
// unit of ownership handoff: resharding moves whole keys atomically.
type KeyState struct {
    Live    map[string]Event           // eventID -> retained payload
    Applied map[string]appliedRec      // eventID -> last applied action (dedup)
    Active  map[string]MatchRec        // matchID -> live insert (not yet retracted)
    ByEvent map[string]map[string]bool // eventID -> set of matchIDs it participates in
}

func newKeyState() *KeyState {
    return &KeyState{
        Live:    map[string]Event{},
        Applied: map[string]appliedRec{},
        Active:  map[string]MatchRec{},
        ByEvent: map[string]map[string]bool{},
    }
}

// Clone deep-copies state. A checkpoint must never alias live state.
func (ks *KeyState) Clone() *KeyState {
    var buf bytes.Buffer
    if err := gob.NewEncoder(&buf).Encode(ks); err != nil {
        panic(err)
    }
    out := newKeyState()
    if err := gob.NewDecoder(&buf).Decode(out); err != nil {
        panic(err)
    }
    return out
}

// Config holds the two bounds that make retention finite.
type Config struct {
    // AllowedLateness L: an event is accepted iff TS >= globalWatermark - L.
    AllowedLateness int64
    // MaxIntervalLen D: End-Start <= D for every event.
    MaxIntervalLen int64
}

// Operator is the deterministic single-partition interval join.
// It is idempotent under duplicate delivery and handles arbitrary
// out-of-order inserts/retractions.
type Operator struct {
    cfg     Config
    keys    map[string]*KeyState
    wm      map[string]int64 // per-source watermark
    tooLate int
    deduped int
}

func NewOperator(cfg Config) *Operator {
    if cfg.MaxIntervalLen < 0 {
        panic("MaxIntervalLen must be >= 0")
    }
    if cfg.AllowedLateness < 0 {
        panic("AllowedLateness must be >= 0")
    }
    return &Operator{cfg: cfg, keys: map[string]*KeyState{}, wm: map[string]int64{}}
}

func (o *Operator) state(key string) *KeyState {
    ks := o.keys[key]
    if ks == nil {
        ks = newKeyState()
        o.keys[key] = ks
    }
    return ks
}

// sourceWM returns the per-source watermark; absence means -inf.
func (o *Operator) sourceWM(src string) int64 {
    if w, ok := o.wm[src]; ok {
        return w
    }
    return math.MinInt64
}

// GlobalWM is min over all sources. With fewer than two sources it is -inf
// (no eviction can be justified until both streams report).
func (o *Operator) GlobalWM() int64 {
    if len(o.wm) < 2 {
        return math.MinInt64
    }
    g := int64(math.MaxInt64)
    for _, w := range o.wm {
        if w < g {
            g = w
        }
    }
    return g
}

// PerSourceWM exposes a source watermark.
func (o *Operator) PerSourceWM(src string) int64 { return o.sourceWM(src) }

// TooLate reports events dropped by the lateness bound.
func (o *Operator) TooLate() int { return o.tooLate }

// Deduped reports duplicate deliveries ignored.
func (o *Operator) Deduped() int { return o.deduped }

// StateSize reports (keys, live events, live matches) for boundedness tests.
func (o *Operator) StateSize() (keys, live, matches int) {
    for _, ks := range o.keys {
        keys++
        live += len(ks.Live)
        matches += len(ks.Active)
    }
    return
}

// Apply ingests one event and returns the result mutations it causes.
// It is fully idempotent: applying the same event (or a duplicate insert
// after a retract) yields no changes.
func (o *Operator) Apply(e Event) []Change {
    if e.Src != "L" && e.Src != "R" {
        panic("Src must be L or R")
    }
    if e.End < e.Start {
        e.Start, e.End = e.End, e.Start
    }
    ks := o.state(e.Key)

    // --- duplicate / ordering dedup -------------------------------------
    if prev, ok := ks.Applied[e.ID]; ok {
        if prev.Kind == e.Kind {
            o.deduped++
            return nil
        }
        // A retract may follow an insert. An insert after a retract is a
        // duplicate of the original logical row and must be ignored.
        if e.Kind == Insert {
            o.deduped++
            return nil
        }
        // Insert then retract: fall through and apply the retraction.
    } else if e.Kind == Retract {
        // Retractions do not carry a fresh event time; they are judged by
        // the *retention* of the referenced row, not by the insert lateness
        // bound. Unknown / already-evicted rows are dropped here.
        o.tooLate++
        return nil
    }

    // --- lateness bound (inserts only) ----------------------------------
    if e.Kind == Insert {
        if gw := o.GlobalWM(); gw != math.MinInt64 && e.TS < gw-o.cfg.AllowedLateness {
            o.tooLate++
            return nil
        }
    }

    switch e.Kind {
    case Insert:
        ks.Live[e.ID] = e
        ks.Applied[e.ID] = appliedRec{Kind: Insert, End: e.End}
        return o.matchInsert(ks, e)
    case Retract:
        return o.retract(ks, e)
    }
    return nil
}

// matchInsert emits Insert for every currently-live overlapping opposite
// event, skipping matches already active.
func (o *Operator) matchInsert(ks *KeyState, e Event) []Change {
    other := "R"
    if e.Src == "R" {
        other = "L"
    }
    var out []Change
    for _, x := range ks.Live {
        if x.Src != other || x.Key != e.Key {
            continue
        }
        if !overlap(e, x) {
            continue
        }
        mid, l, r := matchID(e, x)
        if _, exists := ks.Active[mid]; exists {
            continue
        }
        ks.Active[mid] = MatchRec{Key: e.Key, L: l, R: r}
        addByEvent(ks, l, mid)
        addByEvent(ks, r, mid)
        out = append(out, Change{MatchID: mid, Key: e.Key, L: l, R: r, Action: Insert})
    }
    return out
}

// retract removes an event and emits Retract for every active match that
// referenced it, even if the opposite endpoint was already evicted.
func (o *Operator) retract(ks *KeyState, e Event) []Change {
    var out []Change
    for mid := range ks.ByEvent[e.ID] {
        if rec, ok := ks.Active[mid]; ok {
            delete(ks.Active, mid)
            removeByEvent(ks, rec.L, mid)
            removeByEvent(ks, rec.R, mid)
            out = append(out, Change{MatchID: mid, Key: rec.Key, L: rec.L, R: rec.R, Action: Retract})
        }
    }
    delete(ks.Live, e.ID)
    ks.Applied[e.ID] = appliedRec{Kind: Retract, End: e.End}
    return out
}

func addByEvent(ks *KeyState, id, mid string) {
    s := ks.ByEvent[id]
    if s == nil {
        s = map[string]bool{}
        ks.ByEvent[id] = s
    }
    s[mid] = true
}

func removeByEvent(ks *KeyState, id, mid string) {
    if s := ks.ByEvent[id]; s != nil {
        delete(s, mid)
        if len(s) == 0 {
            delete(ks.ByEvent, id)
        }
    }
}

func overlap(a, b Event) bool { return a.Start <= b.End && b.Start <= a.End }

// matchID is deterministic and independent of arrival order.
func matchID(a, b Event) (mid, l, r string) {
    if a.Src == "L" {
        return "L:" + a.ID + "|R:" + b.ID, a.ID, b.ID
    }
    return "L:" + b.ID + "|R:" + a.ID, b.ID, a.ID
}

// AdvanceWM raises a source watermark and evicts everything that can no
// longer participate in a future match or retraction.
//
// Retention rule (minimum):
//   evict event e  when  globalWM > e.End + L + D
//   GC match m     when both endpoints are evicted
//
// Proof: any future accepted event b has TS >= globalWM - L, and since
// Start >= TS - D and End >= TS, we get b.Start >= globalWM - L - D. If
// globalWM > e.End + L + D then b.Start > e.End, so b cannot overlap e.
// A late retraction for e carries e's original TS and is thus rejected by
// the same bound. Therefore e and its dedup entry are dead.
func (o *Operator) AdvanceWM(src string, wm int64) {
    if wm <= o.sourceWM(src) {
        return
    }
    o.wm[src] = wm
    o.evict()
}

func (o *Operator) evict() {
    gw := o.GlobalWM()
    if gw == math.MinInt64 {
        return
    }
    horizon := func(end int64) bool {
        // strict: evict iff gw > end + L + D  <=>  end < gw - L - D
        return end < gw-o.cfg.AllowedLateness-o.cfg.MaxIntervalLen
    }
    for key, ks := range o.keys {
        for id, e := range ks.Live {
            if horizon(e.End) {
                delete(ks.Live, id)
                delete(ks.Applied, id)
            }
        }
        for id, a := range ks.Applied {
            if horizon(a.End) {
                delete(ks.Applied, id)
            }
        }
        // Matches are final once neither endpoint is live.
        for mid, rec := range ks.Active {
            _, lok := ks.Live[rec.L]
            _, rok := ks.Live[rec.R]
            if !lok && !rok {
                delete(ks.Active, mid)
                removeByEvent(ks, rec.L, mid)
                removeByEvent(ks, rec.R, mid)
            }
        }
        if len(ks.Live) == 0 && len(ks.Active) == 0 && len(ks.Applied) == 0 {
            delete(o.keys, key)
        }
    }
}

// SnapshotKey returns a deep copy of one key's state for handoff.
func (o *Operator) SnapshotKey(key string) *KeyState {
    ks := o.keys[key]
    if ks == nil {
        return newKeyState()
    }
    return ks.Clone()
}

// InstallKey overwrites one key's state (idempotent handoff target).
func (o *Operator) InstallKey(key string, ks *KeyState) {
    o.keys[key] = ks.Clone()
}

// InstallWMs seeds watermarks at a new owner (watermarks are global, not
// per-key, and may only move forward).
func (o *Operator) InstallWMs(wm map[string]int64) {
    for s, w := range wm {
        if w > o.sourceWM(s) {
            o.wm[s] = w
        }
    }
    o.evict()
}

// KeyIDs is a debug helper.
func (o *Operator) KeyIDs() []string {
    out := make([]string, 0, len(o.keys))
    for k := range o.keys {
        out = append(out, k)
    }
    return out
}

func (o *Operator) String() string {
    k, l, m := o.StateSize()
    return fmt.Sprintf("op{keys=%d live=%d matches=%d late=%d dup=%d}", k, l, m, o.tooLate, o.deduped)
}

package streamjoin

import (
    "bytes"
    "encoding/gob"
    "fmt"
    "sort"
    "sync"
)

// ---------------------------------------------------------------------------
// Durable checkpoint store
// ---------------------------------------------------------------------------

// Checkpoint is the durable, self-contained handoff unit for one key.
type Checkpoint struct {
    Key   string
    Epoch uint64
    WMs   map[string]int64
    State []byte // gob-encoded KeyState
}

func encodeState(ks *KeyState) []byte {
    var buf bytes.Buffer
    if err := gob.NewEncoder(&buf).Encode(ks); err != nil {
        panic(err)
    }
    return buf.Bytes()
}

func decodeState(b []byte) *KeyState {
    out := newKeyState()
    if err := gob.NewDecoder(bytes.NewReader(b)).Decode(out); err != nil {
        panic(err)
    }
    return out
}

// CheckpointStore models durable storage. It is the source of truth during
// migration: an owner may crash, but a written checkpoint survives.
type CheckpointStore struct {
    mu   sync.Mutex
    data map[string]Checkpoint // key -> latest checkpoint
}

func NewCheckpointStore() *CheckpointStore {
    return &CheckpointStore{data: map[string]Checkpoint{}}
}

func (s *CheckpointStore) Put(cp Checkpoint) {
    s.mu.Lock()
    defer s.mu.Unlock()
    s.data[cp.Key] = cp
}

func (s *CheckpointStore) Get(key string) (Checkpoint, bool) {
    s.mu.Lock()
    defer s.mu.Unlock()
    cp, ok := s.data[key]
    return cp, ok
}

// ---------------------------------------------------------------------------
// Worker
// ---------------------------------------------------------------------------

// Worker owns a set of join keys. Each key has a monotonic ownership epoch.
// Only the highest epoch may emit results (fencing).
type Worker struct {
    ID     string
    Epochs map[string]uint64
    Ops    map[string]*Operator
    Frozen map[string]bool
}

func NewWorker(id string) *Worker {
    return &Worker{ID: id, Epochs: map[string]uint64{}, Ops: map[string]*Operator{}, Frozen: map[string]bool{}}
}

// Freeze stops mutation of key and returns a durably-checkpointed snapshot.
// It is the first phase of handoff (quiesce + snapshot).
func (w *Worker) Freeze(key string, epoch uint64, cfg Config) Checkpoint {
    if w.Ops[key] == nil {
        w.Ops[key] = NewOperator(cfg)
    }
    w.Frozen[key] = true
    ks := w.Ops[key].SnapshotKey(key)
    wms := map[string]int64{}
    for _, s := range []string{"L", "R"} {
        wms[s] = w.Ops[key].PerSourceWM(s)
    }
    return Checkpoint{Key: key, Epoch: epoch, WMs: wms, State: encodeState(ks)}
}

// Install is idempotent: installing an epoch <= the current epoch for a key
// is a no-op (a duplicated or stale transfer cannot corrupt the target).
func (w *Worker) Install(cp Checkpoint, cfg Config) error {
    cur := w.Epochs[cp.Key]
    if cp.Epoch < cur {
        return fmt.Errorf("stale epoch %d < %d for key %s", cp.Epoch, cur, cp.Key)
    }
    op := w.Ops[cp.Key]
    if op == nil {
        op = NewOperator(cfg)
        w.Ops[cp.Key] = op
    }
    // Force current epoch forward before installing so the state and epoch
    // are never observed out of sync.
    w.Epochs[cp.Key] = cp.Epoch
    op.InstallKey(cp.Key, decodeState(cp.State))
    op.InstallWMs(cp.WMs)
    w.Frozen[cp.Key] = false
    return nil
}

// Release drops local state after the coordinator confirms the target ack.
func (w *Worker) Release(key string, epoch uint64) {
    if w.Epochs[key] != epoch {
        return // already superseded; do not delete newer state
    }
    delete(w.Ops, key)
    delete(w.Epochs, key)
    delete(w.Frozen, key)
}

// Apply routes an event into this worker and returns result changes. It is
// fenced: if the key epoch has advanced, the call is rejected.
func (w *Worker) Apply(key string, e Event, cfg Config) ([]Change, bool) {
    if w.Frozen[key] {
        return nil, false // handoff in progress; caller must buffer
    }
    op := w.Ops[key]
    if op == nil {
        op = NewOperator(cfg)
        w.Ops[key] = op
    }
    return op.Apply(e), true
}

func (w *Worker) Operator(key string) *Operator { return w.Ops[key] }

// ---------------------------------------------------------------------------
// Idempotent sink (exactly-once materialization)
// ---------------------------------------------------------------------------

// Sink materializes the result relation keyed by MatchID. Applying the same
// (MatchID, Action) twice is a no-op, so replay after a crash cannot double
// count, and a stale owner cannot flip the state back.
type Sink struct {
    mu      sync.Mutex
    State   map[string]Kind
    Applied int
    Deduped int
    Fenced  int
}

func NewSink() *Sink { return &Sink{State: map[string]Kind{}} }

func (s *Sink) Apply(c Change, epoch uint64, ownerEpoch uint64) {
    s.mu.Lock()
    defer s.mu.Unlock()
    if epoch < ownerEpoch {
        s.Fenced++ // stale owner write, ignore
        return
    }
    if cur, ok := s.State[c.MatchID]; ok && cur == c.Action {
        s.Deduped++
        return
    }
    s.State[c.MatchID] = c.Action
    s.Applied++
}

// Snapshot returns a sorted, comparable view of the materialized relation.
func (s *Sink) Snapshot() []string {
    s.mu.Lock()
    defer s.mu.Unlock()
    out := make([]string, 0, len(s.State))
    for k, v := range s.State {
        out = append(out, k+"="+v.String())
    }
    sort.Strings(out)
    return out
}

// ---------------------------------------------------------------------------
// Cluster: routing + coordinated ownership handoff
// ---------------------------------------------------------------------------

type Cluster struct {
    Cfg     Config
    Store   *CheckpointStore
    Sink    *Sink
    Workers map[string]*Worker
    Owners  map[string]string // key -> workerID
    Epochs  map[string]uint64 // key -> ownership epoch
    WM      map[string]int64  // global per-source watermark (authoritative)
    Buffers map[string][]Event
}

func NewCluster(cfg Config, workerIDs ...string) *Cluster {
    c := &Cluster{
        Cfg:     cfg,
        Store:   NewCheckpointStore(),
        Sink:    NewSink(),
        Workers: map[string]*Worker{},
        Owners:  map[string]string{},
        Epochs:  map[string]uint64{},
        WM:      map[string]int64{},
        Buffers: map[string][]Event{},
    }
    for _, id := range workerIDs {
        c.Workers[id] = NewWorker(id)
    }
    return c
}

func (c *Cluster) ownerOf(key string) string {
    if o, ok := c.Owners[key]; ok {
        return o
    }
    // Murmur-free deterministic assignment; enough for tests.
    ids := make([]string, 0, len(c.Workers))
    for id := range c.Workers {
        ids = append(ids, id)
    }
    sort.Strings(ids)
    h := 0
    for i := 0; i < len(key); i++ {
        h = h*131 + int(key[i])
    }
    o := ids[(h%len(ids)+len(ids))%len(ids)]
    c.Owners[key] = o
    c.Epochs[key] = 0
    return o
}

// Ingest routes an event to the current owner. If the key is frozen for a
// handoff, the event is buffered and flushed after migration completes.
func (c *Cluster) Ingest(e Event) {
    key := e.Key
    owner := c.ownerOf(key)
    w := c.Workers[owner]
    if w.Frozen[key] {
        c.Buffers[key] = append(c.Buffers[key], e)
        return
    }
    op := w.Operator(key)
    if op == nil {
        op = NewOperator(c.Cfg)
        w.Ops[key] = op // ensure registered
    }
    w.Epochs[key] = c.Epochs[key]
    op.InstallWMs(c.WM)
    changes := op.Apply(e)
    c.commit(changes, key)
}

// AdvanceWM advances the authoritative watermark and fans it out.
func (c *Cluster) AdvanceWM(src string, wm int64) {
    if wm <= c.WM[src] {
        return
    }
    c.WM[src] = wm
    for _, w := range c.Workers {
        for key := range w.Ops {
            w.Ops[key].InstallWMs(c.WM)
        }
    }
}

func (c *Cluster) commit(changes []Change, key string) {
    epoch := c.Epochs[key]
    for _, ch := range changes {
        c.Sink.Apply(ch, epoch, epoch)
    }
}

func (c *Cluster) flush(key string) {
    buf := c.Buffers[key]
    delete(c.Buffers, key)
    for _, e := range buf {
        c.Ingest(e)
    }
}

// Migrate performs the full handoff of key to dstEpoch. It is written so the
// coordinator can crash and resume at any step using only the durable store.
//
//  1. src.Freeze + store.Put   (snapshot is durable before anything moves)
//  2. dst.Install             (idempotent; may be retried)
//  3. coordinator commits new owner/epoch (the fence switch)
//  4. src.Release
//
// Crash safety:
//   - crash before (1) finished: no durable snapshot; rerun from last one.
//   - crash after (1), before (3): store still has the snapshot; the key is
//     still owned by src (it is frozen, so writes are buffered); recover by
//     re-running Install, then commit.
//   - crash after (3): dst owns the new epoch; replaying Install is a no-op
//     and src's stale writes are epoch-fenced.
func (c *Cluster) Migrate(key, dst string) (newEpoch uint64) {
    src := c.ownerOf(key)
    if src == dst {
        return c.Epochs[key]
    }
    newEpoch = c.Epochs[key] + 1

    cp := c.Workers[src].Freeze(key, newEpoch, c.Cfg) // (1)
    c.Store.Put(cp)

    c.InstallFromStore(key, dst, c.Cfg) // (2)

    c.Owners[key] = dst // (3) fence switch
    c.Epochs[key] = newEpoch
    c.Workers[src].Release(key, newEpoch) // (4)
    c.flush(key)
    return newEpoch
}

// InstallFromStore is the recovery entry point: it (re)installs the durable
// checkpoint on dst. Idempotent and safe to call any number of times.
func (c *Cluster) InstallFromStore(key, dst string, cfg Config) bool {
    cp, ok := c.Store.Get(key)
    if !ok {
        return false
    }
    if err := c.Workers[dst].Install(cp, cfg); err != nil {
        return false
    }
    return true
}

// SimulateCrashDst throws away a worker's volatile state, modelling a crash
// that loses everything not in the checkpoint store.
func (c *Cluster) SimulateCrashDst(wid string, key string) {
    w := c.Workers[wid]
    delete(w.Ops, key)
    delete(w.Epochs, key)
}

// SimulateCrashSrc models the source crashing mid-handoff: volatile state is
// lost, but its last durable checkpoint (if any) survives in Store.
func (c *Cluster) SimulateCrashSrc(wid string, key string) {
    w := c.Workers[wid]
    delete(w.Ops, key)
    delete(w.Epochs, key)
}

// pickDest returns a live worker id other than the current owner of key.
func pickDest(c *Cluster, key string) string {
    cur := c.ownerOf(key)
    for _, id := range []string{"w0", "w1", "w2"} {
        if id != cur {
            return id
        }
    }
    return cur
}

// migrateWithCrash runs the handoff state machine by hand and injects a crash
// at a chosen point, then recovers using only the durable checkpoint store.
func migrateWithCrash(c *Cluster, key, dst, point string) {
    src := c.ownerOf(key)
    if src == dst {
        dst = pickDest(c, key)
    }
    ep := c.Epochs[key] + 1

    // (1) quiesce + durable snapshot
    cp := c.Workers[src].Freeze(key, ep, c.Cfg)
    c.Store.Put(cp)

    if point == "before-install" {
        c.SimulateCrashDst(dst, key)
    }
    if !c.InstallFromStore(key, dst, c.Cfg) {
        panic("recovery failed: no checkpoint")
    }
    // Retry install to model duplicate transfer delivery: must be idempotent.
    c.InstallFromStore(key, dst, c.Cfg)

    if point == "after-install-before-commit" {
        c.SimulateCrashDst(dst, key)
        if !c.InstallFromStore(key, dst, c.Cfg) {
            panic("recovery failed after target crash")
        }
    }

    // (3) fence switch
    c.Owners[key] = dst
    c.Epochs[key] = ep

    if point == "after-commit-before-release" {
        c.SimulateCrashSrc(src, key)
    } else {
        c.Workers[src].Release(key, ep)
    }
    c.flush(key)
}

func run(c *Cluster, migrating bool, crashPoint string) {
    migrate := func(key string) {
        if !migrating {
            return
        }
        dst := pickDest(c, key)
        if crashPoint == "none" {
            c.Migrate(key, dst)
        } else {
            migrateWithCrash(c, key, dst, crashPoint)
        }
    }
    keys := []string{"u1", "u2", "u3"}
    for round := 0; round < 9; round++ {
        base := int64(round * 100)
        for _, k := range keys {
            c.Ingest(ev(fmt.Sprintf("r-%s-%d", k, round), k, "R", base+20, base, base+40, Insert))
        }
        if round == 3 {
            migrate("u1")
            migrate("u2")
        }
        for _, k := range keys {
            c.Ingest(ev(fmt.Sprintf("l-%s-%d", k, round), k, "L", base+30, base+10, base+50, Insert))
        }
        if round == 3 {
            c.Ingest(ev("r-u1-3", "u1", "R", base+20, base, base+40, Insert))
        }
        if round == 5 {
            c.AdvanceWM("L", base+30)
            c.AdvanceWM("R", base+20)
        }
        if round == 6 {
            c.Ingest(ev("r-u2-2", "u2", "R", 220, 200, 240, Retract))
        }
        if round == 7 {
            migrate("u3")
        }
    }
    migrate("u1")
    c.AdvanceWM("L", 1<<40)
    c.AdvanceWM("R", 1<<40)
}

// The join state must stay bounded across a long out-of-order stream as the
// watermark advances. We prove this by running two histories of very
// different lengths and showing the final retained state is essentially
// identical (steady state depends only on the retention window L+D).
func TestBoundedStateUnderSustainedLoad(t *testing.T) {
    cfg := Config{AllowedLateness: 10, MaxIntervalLen: 50}
    runLen := func(n int) (live, matches int) {
        op := NewOperator(cfg)
        for i := 0; i < n; i++ {
            ts := int64(i)
            op.Apply(ev(fmt.Sprintf("r%d", i), "u1", "R", ts, ts-5, ts+5, Insert))
            op.Apply(ev(evID("l", i), "u1", "L", ts, ts-3, ts+7, Insert))
            op.AdvanceWM("L", ts)
            op.AdvanceWM("R", ts)
        }
        _, live, matches = op.StateSize()
        return
    }
    sLive, sMatch := runLen(10000)
    lLive, lMatch := runLen(40000)
    if lMatch > sMatch*2 || lLive > sLive*2 {
        t.Fatalf("state grows with history: short=(%d,%d) long=(%d,%d)", sLive, sMatch, lLive, lMatch)
    }
    t.Logf("short history=(live=%d matches=%d) long history=(live=%d matches=%d)", sLive, sMatch, lLive, lMatch)
}
