Fix: vfs_graph_related Returns Silent [] for Truly Unknown Paths (GAP-062)

Repo: gethilo/hilo · Fix commit: 661878d5b829c5d1f33693e9771270c10599ab41 Files: hilo-mcp/src/tools/mod.rs, hilo-mcp/tests/mcp_test.rs

1. Symptom

vfs_graph_related answered a non-existent source path with a successful JSON-RPC result containing []:

{"jsonrpc":"2.0","id":41,"result":{"content":[{"type":"text","text":"[]"}]}}

vfs_graph_impact and CLI hilo graph related correctly failed loudly (-32603, '<path>' is not in the graph ...). Since [] is a valid answer for a real node with no edges, unknown and known-empty were indistinguishable.

2. Root-Cause Analysis

The MCP handler re-implemented candidate resolution and then fell back to ensure_parsed + related. GraphDB::ensure_parsed is deliberately lenient — for a missing file it returns Ok(Vec::new()) and never errors — so the fallback produced [] for a path absent from both graph and disk.

Meanwhile GraphDB::related_or_parse already encoded the correct contract used by the CLI and impact: node-existence check → GraphError::Other("'<path>' is not in the graph ...") → JSON-RPC -32603.

3. The Exact Fix

hilo-mcp/src/tools/mod.rs — track whether any candidate resolved; if none did, delegate to the shared JIT contract:

    let mut resolved = false;
    let mut edges = Vec::new();
    for candidate in &candidates {
        if db.file_in_graph(candidate)? {
            resolved = true;
            edges = db.related(candidate, relation, dir)?;
            if !edges.is_empty() {
                break;
            }
        }
    }

    // No candidate is cached: fall through to the shared JIT contract
    // (`GraphDB::related_or_parse`). It parses an on-disk file on the fly and,
    // for a path that is neither cached nor on disk, returns the loud
    // "is not in the graph" GraphError instead of an empty list.
    if !resolved {
        edges = db.related_or_parse(target, relation, dir)?;
    }

This keeps normalization (/, ./, /home/) for cached nodes, preserves valid [] for real in-graph nodes, JIT-parses real on-disk files, and maps truly unknown paths through the existing -32603 path.

Regression tests added in hilo-mcp/tests/mcp_test.rs (isolated-CWD fixture): test_graph_related_unknown_path_is_loud_error, test_graph_related_resolves_nodes_and_keeps_valid_empty_results, test_graph_related_jit_parses_uncached_source_file.
