Robust Aggregation Against Coordinated Model Poisoning in Federated Learning

Problem class: python3-federated-gradient-poisoning-robust-aggregation-20261103 Runtime: Python 3 + NumPy only.

1. Symptom

Plain server aggregation diverges under a 40 % coordinated attack (40 clients, 200 features, norm clipping at 3× median), while the robust aggregate stays near the clean baseline:

aggregate final held-out logistic loss
no attack (FedAvg baseline) 0.2135
FedAvg (nanmean) 4.4230
coordinate median 7.4820
trimmed mean (β=0.3) 7.9707
Multi-Krum, oracle f 0.2556
robust_aggregate (this fix) 0.3886

2. Root-cause analysis

  1. Clipping bounds magnitude, not direction. A coalition pushing one shared direction shifts the mean deterministically; FedAvg has zero breakdown point.
  2. Coordinate-wise robust statistics are fooled by a coordinated vector. -2u + 0.8v is spread across all coordinates, not sparse per coordinate — so median/trimmed mean still diverge.
  3. Multi-Krum needs the right f. Too small → attackers survive; too large → m = n-f-2 shrinks and the nearly identical colluders have the smallest neighbourhood distances and get selected. An accurate budget estimator is mandatory.
  4. Center-based detection is self-defeating. A 40–45 % coalition corrupts the coordinate median, so residuals no longer separate honest from malicious (attacker cosine-to-median is even higher than honest).
  5. One spectral cut underestimates the budget. Colluders often form several tight sub-communities (sign-flippers + directional attackers); a single Fiedler cut peels only one, letting the rest poison the survivors.

3. The exact fix

Pipeline: clip_by_norm → detect_colluders (center-free spectral peeling) → estimate_attack_budget → robust_aggregate (detection-conditioned Multi-Krum with worst-case fallback).

Key properties: - Center-free detection: cosine-similarity graph → normalized Laplacian → Fiedler vector (eigh for n≤512, deflated power iteration above) → split into the denser side (a 45 % bloc is the majority of its own cut) → accept only when separation = mean(intra) − mean(cross) ≥ 0.15 (clean ≈ 0.03, so no false positives) → peel and repeat to recover all sub-communities. - Budget-conditioned aggregation: confirmed coalition → drop and Multi-Krum the survivors; no coalition → Multi-Krum with worst-case f = ⌊0.45n⌋ so a detector miss is covered. - Sparse/non-IID/clip safe: NaN-aware primitives; detection on normalized cosines is invariant to clipping and non-IID scale. - Bounded memory: the held-out stream is consumed in fixed mini-batches with a running mean.

def detect_colluders(G, topk_frac=0.30, sep_threshold=0.15, max_frac=0.45,
                     min_cluster=2, fiedler_iters=400, exact_max=512, seed=0):
    G = np.asarray(G, dtype=float); n, d = G.shape
    Gf = _fill_nan(G)
    Rn = Gf / np.maximum(np.linalg.norm(Gf, axis=1)[:, None], _EPS)
    S = Rn @ Rn.T; np.fill_diagonal(S, 0.0); S = np.nan_to_num(S)
    mu = coordinate_median(G)
    gnorm = np.linalg.norm(Gf, axis=1); mun = max(np.linalg.norm(mu), _EPS)
    cos_mu = (Gf @ mu) / (np.maximum(gnorm, _EPS) * mun)
    resnorm = np.linalg.norm(Gf - mu[None, :], axis=1)

    def _fiedler(block):                       # normalized-Laplacian Fiedler vector
        m = block.shape[0]
        Wb = np.maximum(block, 0.0) + _EPS
        db = Wb.sum(1); dhb = np.sqrt(np.maximum(db, _EPS))
        if m <= exact_max:
            Lb = np.eye(m) - Wb / np.outer(dhb, dhb)
            _, evecs = np.linalg.eigh(Lb); return evecs[:, 1]
        Ab = Wb / np.outer(dhb, dhb); dhat = dhb / np.linalg.norm(dhb)
        rng = np.random.default_rng(seed); vec = rng.standard_normal(m)
        vec -= (vec @ dhat) * dhat; vec /= max(np.linalg.norm(vec), _EPS)
        for _ in range(fiedler_iters):
            vec = Ab @ vec; vec -= (vec @ dhat) * dhat
            nv = np.linalg.norm(vec)
            if nv < _EPS: break
            vec /= nv
        return vec

    cand = np.zeros(n, dtype=bool); remaining = np.arange(n)
    seps = []; ceil = int(max_frac * n) + 1
    while remaining.size >= min_cluster + 1 and cand.sum() < ceil:
        block = S[np.ix_(remaining, remaining)]; f = _fiedler(block)
        a = f >= 0
        if a.sum() == 0 or a.sum() == remaining.size: a = f > 0
        best = None
        for side in (a, ~a):                   # pick the DENSER side, not smaller
            idx = np.where(side)[0]
            if idx.size < min_cluster or idx.size >= remaining.size: continue
            centrality = block[np.ix_(idx, idx)].sum(axis=1)
            if idx.size > ceil:
                idx = idx[np.argsort(centrality)[::-1][:ceil]]
            within = block[np.ix_(idx, idx)].sum() / max(idx.size * (idx.size - 1), 1)
            if best is None or within > best[1]:
                oth = np.setdiff1d(np.arange(remaining.size), idx)
                cross = block[np.ix_(idx, oth)].mean() if oth.size else 0.0
                best = (idx, float(within), float(cross), float(within - cross), oth)
        if best is None: break
        lidx, _, _, sep, loth = best
        if (lidx.size < remaining.size / 2 and sep >= sep_threshold
                and cand.sum() + lidx.size <= ceil):
            cand[remaining[lidx]] = True; seps.append(sep); remaining = remaining[loth]
        else:
            break
    sep = max(seps) if seps else 0.0
    return {"mask": cand, "cosine_to_median": cos_mu, "residual_norm": resnorm,
            "center": mu, "gap": sep, "separation": sep,
            "confident": bool(cand.sum() >= min_cluster and sep >= sep_threshold)}


def estimate_attack_budget(G, **detect_kw):
    det = detect_colluders(G, **detect_kw); mask = det["mask"]; n = G.shape[0]
    f_est = int(mask.sum())
    if f_est:
        resid = _fill_nan(G - det["center"][None, :])
        shared = np.mean(resid[mask], axis=0)
        shared_norm = float(np.linalg.norm(shared))
        per_client = float(np.median(np.linalg.norm(resid[mask], axis=1)))
    else:
        shared = np.zeros(G.shape[1]); shared_norm = per_client = 0.0
    return {"n_clients": n, "n_malicious_est": f_est,
            "malicious_fraction_est": f_est / n, "shared_direction": shared,
            "shared_direction_norm": shared_norm,
            "per_client_injected_norm": per_client,
            "confident": det["confident"], "gap": det["gap"], "detector": det}


def robust_aggregate(G, clip_factor=3.0, detect_kw=None, beta_floor=0.10,
                     beta_cap=0.45, mode="krum", conservative_frac=0.45):
    G = np.asarray(G, dtype=float); n = G.shape[0]
    Gc = clip_by_norm(G, factor=clip_factor)
    budget = estimate_attack_budget(Gc, **(detect_kw or {}))
    f_est = int(budget["n_malicious_est"]); mask = budget["detector"]["mask"]
    detected = bool(budget["confident"] and 0 < f_est < n // 2)
    if detected:                                   # confirmed coalition -> survivors
        kept = ~mask; surv = Gc[kept]
        if mode == "median":   agg = coordinate_median(surv)
        elif mode == "mom":    agg = median_of_means(surv)
        elif mode == "trimmed":
            agg = trimmed_mean(surv, min(beta_cap, max(beta_floor, f_est / n + 0.05)))
        else:
            f_s = min(int(math.floor(0.10 * surv.shape[0])), (surv.shape[0] - 2) // 2)
            agg, _ = multi_krum_indices(surv, f=max(0, f_s))
    else:                                          # no coalition -> worst-case budget
        f_used = int(min(math.floor(conservative_frac * n), (n - 2) // 2))
        agg, kept = multi_krum_indices(Gc, f=f_used)
    beta = min(beta_cap, max(beta_floor, (f_est if detected else 0) / n + 0.05))
    return AggregationResult(agg, f_est, beta, kept, budget, budget["detector"])
