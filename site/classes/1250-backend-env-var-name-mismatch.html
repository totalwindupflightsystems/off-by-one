DOGFOOD-010: Backend Env Var Name Mismatch

Root-Cause Analysis

The backend server and the CLI/README used different environment variable names to resolve the workspace and cache directories:

Layer Uses Looks up
CLI / README MYTHOS_PROJECTS_PATH, MYTHOS_CACHE_PATH mythos-style prefixed vars
Backend (app.config.ts) PROJECTS_PATH, CACHE_DB_PATH undocumented, inline duplicated resolvers

Setting MYTHOS_PROJECTS_PATH=/tmp/ws was therefore ignored by the backend. The backend inlined its own resolver (same duplicate helper with different names) and wrote data to PROJECTS_PATH-defaulted dirs (./projects, unexpectedly).

The CLI had the same duplicated resolver inline instead of being wired through the server.ts helpers, so both sides diverged.

The Fix

1. Add canonical resolvers to backend/app.config.ts

import * as path from "path";

/** Returns the project workspace root.
 *  Precedence: explicit PROJECTS_PATH > CLI MYTHOS_PROJECTS_PATH > ./projects
 */
export function resolveProjectsPath(env = process.env): string {
  if (env.PROJECTS_PATH) return env.PROJECTS_PATH;

  const cli = env.MYTHOS_PROJECTS_PATH;
  if (cli) {
    const p = cli === "/" ? "/" : cli.endsWith("/") ? cli : cli + "/";
    return p.endsWith("projects") || p === "/" ? p : path.join(p, "projects");
  }
  return "./projects";
}

/** Same semantics for the cache/db dir. */
export function resolveCacheDbPath(env = process.env): string {
  if (env.CACHE_DB_PATH) return env.CACHE_DB_PATH;
  const cli = env.MYTHOS_CACHE_PATH;
  if (cli) {
    const p = cli === "/" ? "/" : cli.endsWith("/") ? cli : cli + "/";
    return p.endsWith("cache") || p === "/" ? p : path.join(p, "cache");
  }
  return "./cache";
}

2. Wire server.ts through the shared helpers

Delete the inline duplicated blocks and replace with:

import { resolveProjectsPath, resolveCacheDbPath } from "./app.config";

Now both the HTTP server and any other entrypoint resolve the same canonical precedence:

PROJECTS_PATH > MYTHOS_PROJECTS_PATH (CLI-style: basename === "projects" ? value : value/projects) > ./projects
CACHE_DB_PATH  > MYTHOS_CACHE_PATH  (CLI-style: basename === "cache" ? value : value/cache) > ./cache
