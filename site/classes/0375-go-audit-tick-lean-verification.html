Finding — the audit target does not exist in this environment. The zombie Go project is absent: a full filesystem probe found no go.mod, no project .git, no events.parquet, no E2E fixtures anywhere. A lean-verification tick must therefore block with exit 3 rather than fabricate an 8/8 pass. That is the fix's first and hardest guarantee: never synthesize evidence for a tree that isn't there.

The fix is an idempotent, guarded tick script encoding the exact cadence, so any future tick on a real checkout is deterministic. Delivered at /home/kara/audit-tick/audit-tick.sh:

# Guard 1 — target must exist; never fabricate for a missing tree
if ! find_project; then
  die "audit target absent: no Go project (go.mod) under '$AUDIT_TICK_DIR'. Tick blocked; no evidence fabricated." 3
fi

# 1. build + vet + tests (expect 8/8); build into /dev/null so no artifact lands in the tree
( cd "$PROJECT_ROOT" && go build -o /dev/null ./... ) || ( cd "$PROJECT_ROOT" && go build ./... ) || die "build failed" 6
( cd "$PROJECT_ROOT" && go vet ./... ) || die "vet failed" 6
out="$(cd "$PROJECT_ROOT" && go test -v -count=1 ./... 2>&1)" || die "tests failed rc=$rc" 6

# 2. hilo stats — high/low watermarks of passes + commit delta, persisted to .audit/hilo.json
# 3. govulncheck — binary-or-`go run` fallback; offline → recorded as degraded, tick continues
# 4. CI scan — requires a non-empty .github/workflows, else die 6 (zombie risk)
# 5. remote-commit scan — git fetch origin, drift ahead/behind recorded (0/0 if no origin)

# 6. E2E battery DEFERRED until cadence >= +5; fixtures stay pending on the board
if [[ "$cad" -ge 5 ]]; then log "cadence >= 5 reached — E2E battery unlocked"; fi

# 7. board-only commit — events.parquet ONLY; .audit/ state is invisible to the guard
status="$(git status --porcelain)"
status="$(grep -vE '^\?\? \.audit/' <<<"$status")"           # tick's own state
grep -vqE '^(\?\?| M|M ) events.parquet$' <<<"$status" && die "board-only commit refused" 4
git add -- events.parquet && git commit -q -m "audit(tick): board events parquet @cadence=$cad"

Exit-code contract: 0 ok · 2 usage · 3 target absent (blocked) · 4 board-only guard violation · 5 toolchain missing · 6 tick failed (build/vet/test/vuln/CI). Modes: check (read-only probe) · run (full tick) · commit (re-validated board commit).
