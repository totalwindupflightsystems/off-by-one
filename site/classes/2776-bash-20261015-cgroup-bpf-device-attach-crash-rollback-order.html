Crash-Recovery Auditor for cgroup-v2 BPF Device Attachments

Problem class: bash-20261015-cgroup-bpf-device-attach-crash-rollback-order Language / shell: Bash 5.2+ (verified on GNU bash 5.3.9) Deliverable: a self-contained auditor that replays an operation log with torn writes and arbitrary crash points, reports the only safe replay order, finds leaked / over-permissive device attachments, and emits a minimal repair plan that preserves unrelated descendants.

1. Root-cause analysis

1.1 The inheritance rule that makes ordering matter

A BPF_PROG_TYPE_CGROUP_DEVICE program attached with bpf_prog_attach is inherited by every descendant cgroup that does not itself override it. The effective device policy of a node is therefore a function of the whole ancestor chain, not just the node:

  • if some ancestor (or the node itself) has a program attached with an override flag, the deepest such attachment masks all higher ones;
  • otherwise the node's effective policy is the union/AND of every program attached from the root down to the node.

Two consequences drive the whole bug class:

  1. An operation on an ancestor has descendant-wide blast radius. A single attach /a leaky override affects /a, /a/b, /a/b/c, ... .
  2. A replace is not atomic. At the syscall level it is attach(new) then detach(old). If you detach(old) first, there is a window in which the node is less restricted (attach-then-detach is the only order that never widens access). If the machine dies in that window the node can be left with no restriction at all.

1.2 Durability boundary: COMMIT, not the last log byte

The operation log is journaled as transactions. A transaction is durable iff its COMMIT record is present. A BEGIN without a matching COMMIT — because the process died, because the final block was only partially flushed, or because the last write has no terminating newline — is a torn transaction. Its operations are not authoritative and must never be replayed. But the kernel may already have applied some of them before the crash, so the observed live state can contain the effects of a transaction that will never commit.

1.3 The failure mode

The naive recovery is "read the log, apply the operations in the order they appear, then remove anything that looks wrong." That is wrong in three ways:

  • It replays torn transactions, resurrecting a leaky override that the crash was supposed to discard. Because of inheritance, the leak is not local — it silently relaxes every descendant.
  • It applies detach before attach inside a replace, opening an unrestricted window and, at a crash point, leaving a node with no policy.
  • It removes a leaked program from children instead of from the node where it was directly attached. That is both non-minimal and harmful: it detaches legitimate programs from descendants that merely inherited the leak, while the real attachment (and its descendant-wide effect) survives.

The safe recovery is a two-source reconciliation:

intended durable state = replay(only committed transactions, normalized order) observed live state = what the kernel currently has repair = minimal direct-attachment diff between the two

2. The fix

2.1 The only safe replay order

Order the committed operations by the following partial order (this is the unique order that satisfies all the invariants simultaneously):

phase operation order why
1 mkdir ascending depth (parents first) a child cannot exist before its parent
2 attach (and the attach half of replace) after mkdir, ascending depth policy must be in place before the node is handed out
3 delegate after the policy of its node is installed never hand control to a delegatee before the restricting program is attached
4 detach (and the detach half of replace) after attach, descending depth new-before-old avoids an unrestricted window; deepest-first stops inheritance before an ancestor is torn down
5 rmdir descending depth (children first) a parent cannot be removed while children remain

Applying any other interleaving either creates a transient unrestricted window or lets a child inherit a program it was meant to override.

2.2 Minimal repair rule

For each (node, program) pair:

  • present in observed but absent in intended → detach it at node — the node where it is directly attached. Detaching there is sufficient because inheritance follows the tree, and it is minimal because no descendant's own attachment is touched.
  • absent in observed but present in intended → attach it at node.
  • present in both → leave it alone, even if its descendants differ. Nodes whose direct-attachment set already matches are never touched, which is what preserves unrelated subtrees.

Repairs are emitted attach top-down first, then detach bottom-up, so the same no-gap / no-unrestricted-window invariant holds during repair itself.

2.3 The auditor

Save as cg_bpf_audit.sh and chmod +x it.

#!/usr/bin/env bash
# cg_bpf_audit.sh - crash-recovery auditor for cgroup-v2 BPF device attachments.
#
# Usage:
#   cg_bpf_audit.sh --log OPS.log --state STATE.txt [--progs PROGS.txt]
#
# Exit status:
#   0 = observed state already matches intended state (no repair needed)
#   1 = repair plan emitted (leaks / missing attachments / over-permissive)
#   2 = usage / input error
#
# This tool is intentionally dependency-free (bash + coreutils), so it can run
# in an initramfs / recover shell before systemd has finished coming up.

set -u

LOG=""; STATE=""; PROGS=""
while [ $# -gt 0 ]; do
  case "$1" in
    --log)   LOG="${2:-}";   shift 2 ;;
    --state) STATE="${2:-}"; shift 2 ;;
    --progs) PROGS="${2:-}"; shift 2 ;;
    -h|--help) sed -n '2,16p' "$0"; exit 0 ;;
    *) echo "unknown arg: $1" >&2; exit 2 ;;
  esac
done
[ -n "$LOG" ]   || { echo "missing --log"   >&2; exit 2; }
[ -n "$STATE" ] || { echo "missing --state" >&2; exit 2; }

# ---------------------------------------------------------------------------
# helpers
# ---------------------------------------------------------------------------
depth() { # depth /a/b/c -> 3
  local p="${1#/}" n=0 IFS=/
  set -- $p
  for _ in "$@"; do [ -n "$_" ] && n=$((n+1)); done
  echo "$n"
}
parent_of() { # /a/b/c -> /a/b ; /a -> ""
  local p="$1"
  case "$p" in
    /*/*) echo "${p%/*}" ;;
    *) echo "" ;;
  esac
}
# stable, dependency-free key/value store via parallel arrays
declare -a OPSEQ=() OPTYPE=() OPPATH=() OPARG1=() OPARG2=() OPMODE=()

# ---------------------------------------------------------------------------
# 1. Parse committed transactions.  A transaction is durable iff it has an
#    explicit COMMIT.  Dangling ops (no COMMIT) are TORN and are never replayed.
# ---------------------------------------------------------------------------
declare -a LOGTXN=()   # committed transaction ids, in commit order
declare -a TORN=()     # torn transaction ids
cur=""
declare -a pending_type=() pending_path=() pending_a1=() pending_a2=() pending_mode=()

flush_txn() { # $1=tid  $2=committed(yes/no)
  local tid="$1" ok="$2" i
  if [ "$ok" = yes ]; then
    LOGTXN+=("$tid")
    for ((i=0;i<${#pending_type[@]};i++)); do
      OPSEQ+=("$(( ${#OPSEQ[@]} + 1 ))")
      OPTYPE+=("${pending_type[$i]}"); OPPATH+=("${pending_path[$i]}")
      OPARG1+=("${pending_a1[$i]}");  OPARG2+=("${pending_a2[$i]}")
      OPMODE+=("${pending_mode[$i]}")
    done
  else
    TORN+=("$tid")
  fi
  pending_type=(); pending_path=(); pending_a1=(); pending_a2=(); pending_mode=()
}

if [ -n "$PROGS" ] && [ -r "$PROGS" ]; then
  while read -r p c rest; do
    [ -z "${p:-}" ] && continue
    case "$p" in \#*) continue ;; esac
    printf '%s\t%s\n' "$p" "${c:-restrict}"
  done <"$PROGS" > /tmp/.cg_progs.$$ || true
fi

declare -A PROGCLASS=()
[ -f /tmp/.cg_progs.$$ ] && while IFS=$'\t' read -r p c; do PROGCLASS["$p"]="$c"; done < /tmp/.cg_progs.$$

lineno=0
while IFS= read -r raw || { [ -n "$raw" ] && lastline_torn=1; }; do
  lineno=$((lineno+1))
  line="${raw%%$'\r'}"
  set -- $line
  cmd="${1:-}"; [ -z "$cmd" ] && continue
  case "$cmd" in
    \#*) continue ;;
    PROG)  # PROG <id> <allow_all|restrict>  (program metadata)
      PROGCLASS["${2:-}"]="${3:-restrict}" ;;
    BEGIN)
      if [ -n "$cur" ]; then flush_txn "$cur" no; fi
      cur="${2:-?}" ;;
    COMMIT)
      if [ -n "$cur" ]; then flush_txn "$cur" yes; fi
      cur="" ;;
    mkdir)
      pending_type+=(mkdir); pending_path+=("${2:-}"); pending_a1+=(""); pending_a2+=(""); pending_mode+=("") ;;
    attach)
      pending_type+=(attach); pending_path+=("${2:-}"); pending_a1+=("${3:-}"); pending_a2+=(""); pending_mode+=("${4:-single}") ;;
    detach)
      pending_type+=(detach); pending_path+=("${2:-}"); pending_a1+=("${3:-}"); pending_a2+=(""); pending_mode+=("") ;;
    replace) # replace <path> <old> <new> <mode>
      pending_type+=(attach);  pending_path+=("${2:-}"); pending_a1+=("${4:-}"); pending_a2+=(""); pending_mode+=("${5:-single}")
      pending_type+=(detach);  pending_path+=("${2:-}"); pending_a1+=("${3:-}"); pending_a2+=(""); pending_mode+=("") ;;
    delegate)
      pending_type+=(delegate); pending_path+=("${2:-}"); pending_a1+=("${3:-}"); pending_a2+=(""); pending_mode+=("") ;;
    rmdir)
      pending_type+=(rmdir); pending_path+=("${2:-}"); pending_a1+=(""); pending_a2+=(""); pending_mode+=("") ;;
    *) : ;; # ignore unknown op kinds (forward compat)
  esac
  unset raw
done <"$LOG"
if [ -n "$cur" ]; then flush_txn "$cur" no; fi   # unterminated final transaction

# ---------------------------------------------------------------------------
# 2. Normalise replay order.  Sorting rules:
#      mkdir    : parents before children  (ascending depth)
#      attach   : after mkdir, before delegate, before detach (no gap)
#      delegate : after policy is installed
#      detach   : after attach, descendants before ancestors (descending depth)
#      rmdir    : descendants before ancestors (descending depth)
# ---------------------------------------------------------------------------
declare -a ORDER=()
tmpord=$(mktemp)
for ((i=0;i<${#OPTYPE[@]};i++)); do
  t="${OPTYPE[$i]}"; p="${OPPATH[$i]}"; d=$(depth "$p")
  case "$t" in
    mkdir)    prio=$((100 + d)) ;;
    attach)   prio=$((200 + d)) ;;
    delegate) prio=$((300 + d)) ;;
    detach)   prio=$((400 + (100 - d))) ;;
    rmdir)    prio=$((500 + (100 - d))) ;;
    *)        prio=999 ;;
  esac
  printf '%s\x1f%s\x1f%s\x1f%s\x1f%s\x1f%s\x1f%s\n' \
    "$prio" "${OPSEQ[$i]}" "$t" "$p" "${OPARG1[$i]}" "${OPARG2[$i]}" "${OPMODE[$i]}" >>"$tmpord"
done
while IFS=$'\x1f' read -r _prio _seq t p a1 a2 m; do
  ORDER+=("$t|$p|$a1|$a2|$m")
done < <(sort -s -t$'\x1f' -k1,1n -k2,2n "$tmpord")
rm -f "$tmpord"

# ---------------------------------------------------------------------------
# 3. Replay committed ops into the intended state.
# ---------------------------------------------------------------------------
declare -A NODE=()                 # path -> 1
declare -A INTENDED=()             # "path|prog" -> mode
apply_op() { # type path a1 a2 mode
  local t="$1" p="$2" a1="$3" a2="$4" m="$5"
  case "$t" in
    mkdir) NODE["$p"]=1 ;;
    attach)
      NODE["$p"]=1
      INTENDED["$p|$a1"]="$m" ;;
    detach)
      unset "INTENDED[$p|$a1]" 2>/dev/null || true ;;
    rmdir) unset 'NODE["$p"]' 2>/dev/null || true ;;
    delegate) : ;; # policy is already installed; delegation does not move it
  esac
}
for entry in "${ORDER[@]}"; do
  IFS='|' read -r t p a1 a2 m <<<"$entry"
  apply_op "$t" "$p" "$a1" "$a2" "$m"
done

# ---------------------------------------------------------------------------
# 4. Parse observed live state.
# ---------------------------------------------------------------------------
declare -A OBS=()
if [ -r "$STATE" ]; then
  while read -r p prog m rest; do
    [ -z "${p:-}" ] && continue
    case "$p" in \#*) continue ;; esac
    NODE["$p"]=1
    OBS["$p|$prog"]="${m:-single}"
  done <"$STATE"
fi

# ---------------------------------------------------------------------------
# 5. Effective policy = deepest override node on the path masks ancestors;
#    otherwise the union of direct attachments from root down to node.
# ---------------------------------------------------------------------------
ancestors() { # path -> self, parent, ... root (one per line)
  local p="$1"
  while [ -n "$p" ]; do echo "$p"; p="$(parent_of "$p")"; done
}
effective() { # path -> space-separated "prog:mode" sorted; uses $1 map name
  local path="$1" mapname="$2"
  declare -n M="$mapname"
  local p override="" 
  while read -r p; do
    local k
    for k in "${!M[@]}"; do
      case "$k" in "$p|"*)
        [ "${M[$k]}" = override ] && { override="$p"; break; } ;;
      esac
    done
    [ -n "$override" ] && break
  done < <(ancestors "$path")
  local out=() p2 k
  if [ -n "$override" ]; then
    for k in "${!M[@]}"; do case "$k" in "$override|"*) out+=("${k#*|}");; esac; done
  else
    while read -r p2; do
      for k in "${!M[@]}"; do case "$k" in "$p2|"*) out+=("${k#*|}");; esac; done
    done < <(ancestors "$path")
  fi
  printf '%s\n' "${out[@]:-}" | sed '/^$/d' | sort -u | tr '\n' ' '
}

is_allow_all() { [ "${PROGCLASS[$1]:-restrict}" = allow_all ]; }

# ---------------------------------------------------------------------------
# 6. Emit the report.
# ---------------------------------------------------------------------------
echo "== TORN TRANSACTIONS (discarded, never replayed) =="
if [ ${#TORN[@]} -eq 0 ]; then echo "  (none)"; else for t in "${TORN[@]}"; do echo "  txn $t"; done; fi
[ "${lastline_torn:-0}" = 1 ] && echo "  (log has no terminating newline: last write was torn)"

echo
echo "== SAFE REPLAY ORDER (committed transactions only) =="
n=0
for entry in "${ORDER[@]}"; do
  IFS='|' read -r t p a1 a2 m <<<"$entry"
  n=$((n+1)); printf '  %2d. %-8s %s %s %s\n' "$n" "$t" "$p" "${a1:-}" "${m:-}"
done

echo
echo "== LEAKS / OVER-PERMISSIVE ATTACHMENTS =="
leaks=0; over=0
# direct attachment present in observed but not intended => leaked
for k in "${!OBS[@]}"; do
  if [ -z "${INTENDED[$k]:-}" ]; then
    p="${k%%|*}"; prog="${k#*|}"; leaks=$((leaks+1))
    flag="leak"
    is_allow_all "$prog" && flag="leak/OVER-PERMISSIVE"
    echo "  $p : direct $prog (${OBS[$k]}) -> $flag"
  fi
done
# effective policy weaker than intended => over-permissive
for p in "${!NODE[@]}"; do
  ie=$(effective "$p" INTENDED); oe=$(effective "$p" OBS)
  for pair in $oe; do
    prog="${pair%%:*}"
    case " $ie " in *"$prog "*) ;; *) if is_allow_all "$prog"; then
      echo "  $p : effective policy admits over-permissive $prog from an ancestor/self"; over=$((over+1)); fi ;; esac
  done
  for pair in $ie; do
    prog="${pair%%:*}"
    case " $oe " in *"$prog "*) ;; *) echo "  $p : intended restriction $prog is MISSING in effective policy"; over=$((over+1));; esac
  done
done
[ $((leaks+over)) -eq 0 ] && echo "  (none)"

echo
echo "== MINIMAL REPAIR PLAN (preserves unrelated descendants) =="
# completion scan: attaches top-down, detaches bottom-up
tmpfix=$(mktemp)
for k in "${!INTENDED[@]}"; do
  [ -n "${OBS[$k]:-}" ] && continue
  p="${k%%|*}"; prog="${k#*|}"; d=$(depth "$p")
  printf '%s\t%08d\tattach\t%s\t%s\t%s\n' "$((200+d))" 0 "$p" "$prog" "${INTENDED[$k]}" >>"$tmpfix"
done
for k in "${!OBS[@]}"; do
  [ -n "${INTENDED[$k]:-}" ] && continue
  p="${k%%|*}"; prog="${k#*|}"; d=$(depth "$p")
  printf '%s\t%08d\tdetach\t%s\t%s\t%s\n' "$((400+(100-d)))" 0 "$p" "$prog" "${OBS[$k]}" >>"$tmpfix"
done
repairs=0
while IFS=$'\t' read -r _ _ op p a1 m; do
  repairs=$((repairs+1))
  printf '  %2d. repair: %s %s %s\n' "$repairs" "$op" "$p" "$a1"
done < <(sort -s -t$'\t' -k1,1n "$tmpfix")
rm -f "$tmpfix"
[ "$repairs" -eq 0 ] && echo "  (none - state is consistent)"

rm -f /tmp/.cg_progs.$$ 2>/dev/null || true
echo
if [ $((leaks+over)) -eq 0 ] && [ "$repairs" -eq 0 ]; then
  echo "RESULT: CLEAN (exit 0)"; exit 0
else
  echo "RESULT: REPAIR REQUIRED (exit 1)"; exit 1
fi

2.4 Input formats

Operation log (--log):

PROG r1    restrict
PROG leaky allow_all

BEGIN <tid>
mkdir    <path>
attach   <path> <prog> <single|multi|override>
detach   <path> <prog>
replace  <path> <old> <new> <mode>       # expands to attach(new); detach(old)
delegate <path> <uid>
rmdir    <path>
COMMIT <tid>

A BEGIN with no following COMMIT is torn and is discarded. A log whose last byte is not a newline is flagged as a torn write.

Observed live state (--state): one direct attachment per line, <path> <prog> <mode>.

Optional catalog (--progs) keeps PROG metadata out of the log with the same <id> <restrict|allow_all> lines.

3.3 Nested-override case (deepest-first, descendants preserved)

== MINIMAL REPAIR PLAN (preserves unrelated descendants) ==
   1. repair: detach /demo/a/b leaky2
   2. repair: detach /demo/a leaky

Because /demo/a/b carries its own override, detaching the parent leak would not fix it; the auditor repairs both, deepest first, and still never touches /demo/x or /demo/x/y.

3.4 Crash-before-commit case (replay ≠ observed)

When the crash happens before COMMIT 101 but the kernel already applied the replace, the intended state is the old program and the observed state is the new one. The auditor emits attach r1 then detach r2:

== SAFE REPLAY ORDER (committed transactions only) ==
   1. mkdir    /demo
   2. attach   /demo r1 single

== MINIMAL REPAIR PLAN (preserves unrelated descendants) ==
   1. repair: attach /demo r1
   2. repair: detach /demo r2

3.6 Assumptions and limits

  • single/multi attachments are inherited; an override attachment masks ancestors, deepest wins. Device allow/deny logic is abstracted to restrict vs allow_all, which is exactly the over-permission signal a crash auditor needs.
  • Paths are assumed not to contain |, used as an internal record separator.
  • The tool is read-only: it prints a plan and never mutates the kernel. Apply with bpftool/bpf_prog_detach2 after review, in the printed order (attach before detach, top-down for attach, bottom-up for detach).
  • set -u is on but set -e is deliberately not, so one malformed log line cannot abort a recovery mid-plan.
