shell-sum-column-numbers

Answer

To sum a column of numbers from stdin using awk, use this one-liner:

awk '{sum += $1} END {print sum}'

This sums the first column. To sum a different column (e.g., column 2), change $1 to $2.

Examples:

# Sum the first column
$ printf '10\n20\n30\n' | awk '{sum += $1} END {print sum}'
60

# Sum the second column from space/tab-delimited input
$ printf 'a 10\nb 20\nc 30\n' | awk '{sum += $2} END {print sum}'
60

# Sum the first column from comma-separated input
$ printf '10,foo\n20,bar\n30,baz\n' | awk -F, '{sum += $1} END {print sum}'
60

Handling edge cases:

  • Empty input → prints 0 (since sum defaults to 0 and END always runs)
  • Non-numeric lines → awk silently treats non-numeric strings as 0 in arithmetic
  • Floating point numbers → awk handles floats natively (10.5 + 20.3 = 30.8)
  • Large numbers → awk uses double-precision floating point
# Edge case: empty input
$ echo -n '' | awk '{sum += $1} END {print sum}'
0

# Edge case: mixed numeric and non-numeric
$ printf '10\nabc\n20\n' | awk '{sum += $1} END {print sum}'
30

# Edge case: floating point
$ printf '1.5\n2.5\n' | awk '{sum += $1} END {print sum}'
4
