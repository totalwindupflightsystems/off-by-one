Root cause

The five flow durable-dispatch bounds (max_entries=256, retention=72h, max_attempts=5, lease_timeout=5s, batch_size=100) existed only as compiled constants. Four defects kept them untunable:

  1. No flow.* rows in the registry table, so a host [flow] table was never read.
  2. Trusting Duration.Std(), which returns 0 for both empty and garbage input — and a resolved max_entries=0 is an unbounded queue.
  3. Constants-only construction path: the composition root handed literals to store.New / flow.New, discarding resolved values.
  4. No behaviour test overrode a key, so regressions were invisible.

Exact fix (internal/lifecycle/config.go)

Add one registry row per leaf, mirroring hub.* / server.redis.*, with positive-only validators:

positiveInt = func(raw any) error {
    s := strings.TrimSpace(fmt.Sprint(raw))
    n, err := strconv.Atoi(s)
    if err != nil { return fmt.Errorf("%s: unparsable integer %q: %w", name, s, err) }
    if n <= 0    { return fmt.Errorf("%s: must be > 0, got %d", name, n) }
    *dst = n; return nil
}

positiveDuration = func(raw any) error {           // NOT Duration.Std()
    s := strings.TrimSpace(fmt.Sprint(raw))
    d, err := time.ParseDuration(s)
    if err != nil { return fmt.Errorf("%s: unparsable duration %q: %w", name, s, err) }
    if d <= 0    { return fmt.Errorf("%s: must be > 0, got %s", name, d) }
    *dst = d; return nil
}

Rows added for flow.dispatch.{max_entries,retention,max_attempts,lease_timeout,batch_size} with defaults 256 / 72h / 5 / 5s / 100. Load installs all defaults, overlays only keys the host actually set, and errors on any failed validator — so an absent [flow] table runs the documented posture and a zero/garbage value is refused.

Composition root projects once and shares the value:

func Wire(cfg *lifecycle.Config) *App {
    bounds := cfg.Dispatch          // projected ONCE
    return &App{
        Store: store.New(bounds),   // same value
        Flow:  flow.New(bounds),    // same value
    }
}

Both store.New and flow.New now take lifecycle.DispatchBounds; no literal defaults remain.
