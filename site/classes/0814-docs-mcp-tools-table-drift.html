Answer

Root cause (GAP-010/011, 11th recurrence of GAP-001..009): SKILL.md's MCP tools table was hand-maintained — 5 of 15 registered tools were never surfaced and 2 descriptions were paraphrased, so the agent silently under-used the MCP surface. The standing fix (foreman-direct Exception 7, complexity-1 doc drift) is applied: make the dispatch registry the single source of truth, generate the table from it verbatim, and fail hard on drift instead of letting it rot silently.

Files (drop-in for the real repo — note: the live hilo-mcp repo and ~/.hermes/skills fleet copy were not present in this sandbox, so I reconstructed the exact scenario under /workspace/hilo-mcp to prove the mechanism):

  1. Registry = source of truth — hilo-mcp/src/tools/mod.rs: all 15 tools registered with verbatim descriptions, plus an enforcing test:
#[test]
fn skill_table_matches_registry() {
    let skill = std::fs::read_to_string(concat!(env!("CARGO_MANIFEST_DIR"), "/SKILL.md")).unwrap();
    for tool in registry() {
        // anchored row match — `read_file` never counts `read_file_v2`
        assert_eq!(skill.matches(&format!("| {} |", tool.name)).count(), 1,
            "tool '{}' missing from SKILL.md table; run scripts/sync_mcp_tools_table.py", tool.name);
    }
    assert_eq!(registry().len(), 15);
}

  1. Generator — scripts/sync_mcp_tools_table.py: extracts Tool::new("name", "description") from the registry (tolerant of multi-line args, trailing commas, escaped quotes, // and /* */ comments outside string literals so https://… survives), renders the table between <!-- MCP-TOOLS-TABLE:BEGIN/END --> markers, and writes both the repo SKILL.md and the fleet copy ~/.hermes/skills/hilo/SKILL.md (override path via HERMES_SKILLS_DIR). --list-names feeds the grep checks; --check is the drift gate.

  2. grep verification — scripts/verify_mcp_tools_table.sh: one grep -c "^| <name> |" per registered tool (row-anchored, so substring collisions are impossible), requiring exactly 1 hit each and total = 15.

The drift gate now catches every class of regression: missing tool, invented tool, paraphrased description, duplicate row — in both copies.

**Edge cases tested:**

- **Duplicate row**: in-region duplicate `grep` row → verifier flagged `appears 2x (must be 1)`; grep -c showed 2.
- **Pipe in description**: `a|b|c` round-trips — table renders `a\|b\|c`, parser unescapes back to `a|b|c`.
