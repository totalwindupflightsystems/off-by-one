Deterministic OCI Layer Deduplication with Hardlink, Whiteout, Ownership and Sparse Safety

1. Root-cause analysis

There is no pre-existing repository in this environment; the "problem" is the tool itself. The failure modes a naive implementation hits are structural, and each one is a distinct way of silently changing image semantics:

  1. Layers are a sequence, not a set. A path's final bytes depend on the ordered application of every layer plus whiteouts. Hashing files and hardlinking "equal" content across layers can link a path to a canonical that a later layer whiteouts. Both names then vanish or point at dead content. Deduplication is only safe among paths that survive to the final merged filesystem.
  2. Hardlinks are an inode relationship, not two files. If a is a tar hardlink (link to b), relinking b to a foreign canonical leaves a pointing at the old inode. The group must be treated atomically, so any hardlink anchor is excluded from relinking.
  3. Content equality is not file equality. Mode, uid, gid and mtime are part of what a container sees; hardlinks share all of them. Extended attributes / ACLs (PAX SCHILY.xattr.*, SCHILY.acl.*) are shared too, so relinking two files with different capabilities is a privilege change.
  4. Sparse extents are inode state. A hardlink preserves the canonical's holes but replaces the other path's allocation map. Byte identity alone is insufficient; sparse-bearing layers must be excluded by default.
  5. Tar listings are hostile to naive parsing. GNU tar emits names that can contain spaces, tabs and newlines, plus ->, link to and * xattr markers. Splitting on whitespace silently corrupts paths and metadata.
  6. Whiteouts are regular files. .wh.<name> (delete file) and .wh..wh..opq (opaque dir) must be simulated, never deduplicated.
  7. Path traversal. Members named ../x or /x must never be turned into apply actions that can escape the merged root.
  8. Long scans must be restartable and verifiable. A crash halfway through must not lose work, and cached digests must be checked against the actual layer bytes before being trusted.

2. Exact fix

The fix is ocidedup.sh: a deterministic, restartable planner that never mutates the input archives and emits a JSONL replacement plan.

Design decisions that address the root causes above:

  • Digests without extraction. tar --no-seek -xf ARCHIVE --to-command=... streams every regular member through sha256sum and exports TAR_SIZE/TAR_MODE/TAR_UID/TAR_GID/TAR_MTIME. --no-seek is what makes sparse members stream correctly (tar writes holes as zeros instead of seeking in a pipe); -P preserves unsafe member names verbatim so they can be flagged.
  • Ordered entry graph. tar -P --xattrs --numeric-owner --quoting-style=escape -tvf yields one line per member (dirs, symlinks, hardlinks, devices, fifos, xattr * markers) in archive order. The listing and the callback stream are merged positionally: the n-th regular listing row consumes the n-th callback row. Names are parsed as "everything after the 5th whitespace field" so spaces are safe, and link to / -> suffixes are stripped from the end.
  • Whiteout simulation. The ordered records are replayed; opaque whiteouts delete a subtree, .wh.X deletes dir/X and its subtree, and the last writer wins for every path. Only entries still visible at the end are survivors.
  • Exact identity. Candidates are grouped by sha256 | size | mode | uid | gid | mtime. xattr, hardlink anchor, unsafe path and (by default) sparse layer records are excluded. The canonical is the lowest (layer, seq) survivor, so the plan is deterministic.
  • Restartability. Each layer is cached as state/layer_NNNN.tsv with a header # <archive_sha256> <sparse> and a #END completeness marker. A cache hit requires the digest to match and #END to be present; anything else is rescanned. Writes are temp-file + mv (atomic). A flock guards the workdir.
  • Verification. --verify snapshots the previous cache before the run, re-derives every layer from the archive, and compares header digest and per-record digests against the snapshot. It then validates that every plan hardlink target exists, is a keep, has the same digest/size/mode/uid/gid/ mtime, and that no path appears twice. Tampering or drift exits 2.
  • Sparse detection. PAX GNU.sparse records are found with a streaming grep; old-GNU S typeflags are found with a checksum-validating 512-byte header scan (perl when available). Detection is cached with the layer state.

2.1 ocidedup.sh

Save as ocidedup.sh, chmod +x ocidedup.sh.

#!/usr/bin/env bash
# ocidedup.sh -- deterministic, restartable OCI layer deduplication planner.
#
# Scans ordered OCI image layer tar archives, finds byte-identical regular
# files that can be safely hardlinked in a *merged* root filesystem, and
# emits a replacement plan.  It never mutates the input archives.
#
# Safety model:
#   * whiteouts (.wh.*) and opaque dirs (.wh..wh..opq) are simulated so only
#     paths that survive to the final image are dedup candidates;
#   * hardlink groups are preserved verbatim and never relinked;
#   * content must match by sha256 *and* size;
#   * mode, uid, gid and mtime must match exactly;
#   * files carrying extended attributes / ACLs are never relinked;
#   * sparse-bearing layers are excluded unless --allow-sparse;
#   * unsafe member paths (absolute or containing '..') are never relinked.
#
# The plan is JSON Lines, deterministic (sorted by layer then path), and the
# run is restartable: per-layer scan state is cached and verified against the
# layer's sha256 so an interrupted run resumes without redoing work.
set -u

SCHEMA="ocidedup/1"
PROG="${0##*/}"

WORKDIR=".ocidedup"
PLAN=""
VERIFY=0
RESET=0
ALLOW_SPARSE=0
QUIET=0
LAYERS=()

usage() {
  cat <<EOF
$PROG -- deterministic OCI layer dedup planner (schema $SCHEMA)

Usage:
  $PROG [options] LAYER.tar[.gz|.xz|.zst|.bz2] [LAYER2 ...]

Options:
  --workdir DIR    state directory (default: $WORKDIR)
  --plan FILE      write the JSONL plan here (default: stdout)
  --verify         re-derive digests from archives and check the plan
  --reset          discard cached state before running
  --allow-sparse   permit dedup of layers that contain sparse files
  --quiet          only report errors
  -h, --help       this help

Exit status: 0 ok, 1 usage/IO error, 2 verification failure.
EOF
}

log()  { [ "$QUIET" -eq 1 ] || printf '%s\n' "$*" >&2; }
die()  { printf '%s: error: %s\n' "$PROG" "$*" >&2; exit 1; }
warn() { printf '%s: warning: %s\n' "$PROG" "$*" >&2; }

while [ $# -gt 0 ]; do
  case "$1" in
    --workdir)      [ $# -ge 2 ] || die "--workdir needs a value"; WORKDIR="$2"; shift 2 ;;
    --plan)         [ $# -ge 2 ] || die "--plan needs a value";    PLAN="$2";    shift 2 ;;
    --verify)       VERIFY=1; shift ;;
    --reset)        RESET=1; shift ;;
    --allow-sparse) ALLOW_SPARSE=1; shift ;;
    --quiet)        QUIET=1; shift ;;
    -h|--help)      usage; exit 0 ;;
    --)             shift; while [ $# -gt 0 ]; do LAYERS+=("$1"); shift; done ;;
    -*)             die "unknown option: $1" ;;
    *)              LAYERS+=("$1"); shift ;;
  esac
done

[ "${#LAYERS[@]}" -gt 0 ] || { usage >&2; die "no layer archives given"; }
for f in "${LAYERS[@]}"; do [ -f "$f" ] || die "no such layer file: $f"; done

[ "$RESET" -eq 1 ] && rm -rf "$WORKDIR"
mkdir -p "$WORKDIR/state" || die "cannot create workdir $WORKDIR"
exec 9>"$WORKDIR/lock" || die "cannot open lock file"
flock -n 9 || die "another $PROG instance is running in $WORKDIR"

STATE="$WORKDIR/state"

# ---------------------------------------------------------------------------
# archive helpers
# ---------------------------------------------------------------------------

detect_comp() {
  local m
  m=$(od -An -N6 -tx1 "$1" 2>/dev/null | tr -d ' \n')
  case "$m" in
    1f8b*)        printf '%s' "-z" ;;
    425a68*)      printf '%s' "-j" ;;
    fd377a585a00) printf '%s' "-J" ;;
    28b52ffd*)    printf '%s' "--zstd" ;;
    *)            printf '%s' "" ;;
  esac
}

decompress_cmd_for() {
  case "$1" in
    -z)     printf '%s' "gzip -dc" ;;
    -j)     printf '%s' "bzip2 -dc" ;;
    -J)     printf '%s' "xz -dc" ;;
    --zstd) printf '%s' "zstd -dc" ;;
    *)      printf '%s' "cat" ;;
  esac
}

# 0 if the archive contains sparse members (PAX GNU.sparse records or old GNU
# 'S' typeflag).  Old-GNU detection checksum-validates every 512-byte header.
archive_has_sparse() {
  local archive="$1" comp dcmd
  comp=$(detect_comp "$archive")
  dcmd=$(decompress_cmd_for "$comp")
  if $dcmd "$archive" 2>/dev/null | grep -aqm1 'GNU\.sparse'; then
    return 0
  fi
  if command -v perl >/dev/null 2>&1; then
    $dcmd "$archive" 2>/dev/null | perl -e '
      local $/ = \512;
      while (defined(my $b = <STDIN>)) {
        next unless length($b) == 512;
        next unless substr($b,257,5) eq "ustar";
        my $st = substr($b,148,8); $st =~ s/\0.*//s; $st =~ s/ //g;
        next if $st eq "";
        my $stored = oct("0$st");
        my $c = $b; substr($c,148,8) = "        ";
        my $sum = 0; $sum += ord($_) for split //, $c;
        next unless $sum == $stored;
        exit 0 if substr($b,156,1) eq "S";
      }
      exit 1;
    ' && return 0
  fi
  return 1
}

# ---------------------------------------------------------------------------
# stage 1: scan one layer into ordered normalized records
#
# Output: one header line ('# <archive_sha256> <sparse>'), one record per
# member, then a '#END' marker.
# type: '-' regular, d dir, l symlink, h hardlink, c/b/p/s device/fifo/socket
# ---------------------------------------------------------------------------

scan_layer() {
  local idx="$1" archive="$2" out="$3" sparse="${4:-0}"
  local comp cbf listf errf rc
  comp=$(detect_comp "$archive")
  cbf="$out.cb.$$"; listf="$out.list.$$"; errf="$out.err.$$"

  # 1a. stream every regular member to sha256sum; capture metadata.
  #     --no-seek keeps sparse members streamable (holes arrive as zeros).
  #     -P keeps any unsafe member name verbatim so it can be flagged.
  tar $comp -P --no-seek -xf "$archive" --to-command='
      f=$(sha256sum)
      d=${f%% *}
      printf "%s\t%s\t%s\t%s\t%s\t%s\n" "$d" "$TAR_SIZE" "$TAR_MODE" "$TAR_UID" "$TAR_GID" "$TAR_MTIME"
    ' >"$cbf" 2>"$errf"
  rc=$?
  [ $rc -eq 0 ] || { cat "$errf" >&2; rm -f "$cbf" "$listf" "$errf"; return $rc; }

  # 1b. full ordered listing, including types/links and xattr markers.
  tar $comp -P --xattrs --numeric-owner --quoting-style=escape -tvf "$archive" \
      >"$listf" 2>>"$errf"
  rc=$?
  [ $rc -eq 0 ] || { cat "$errf" >&2; rm -f "$cbf" "$listf" "$errf"; return $rc; }

  # 1c. merge by archive order: consume one callback line per regular entry.
  awk -v layer="$idx" -v sparse="$sparse" -v cbf="$cbf" '
  function after_fields(s, k,   p,c) {
    p=1; c=0
    while (c<k) {
      while (p<=length(s) && substr(s,p,1)==" ") p++
      if (p>length(s)) return ""
      while (p<=length(s) && substr(s,p,1)!=" ") p++
      c++
    }
    while (p<=length(s) && substr(s,p,1)==" ") p++
    return substr(s,p)
  }
  function last_index(s, t,   i,last) {
    last=0; i=index(s,t)
    while (i>0) { last=i; i=index(substr(s,i+1),t); if(i>0) i+=last+length(t)-1 }
    return last
  }
  function norm(p,   n,a,i,out,seg,pre) {
    pre = (substr(p,1,1)=="/") ? 1 : 0
    n=split(p,a,"/"); out=""
    for(i=1;i<=n;i++){
      seg=a[i]
      if(seg==""||seg==".") continue
      if(seg=="..") return "..UNSAFE.."
      out = (out=="" ? seg : out "/" seg)
    }
    if(pre) return "..UNSAFE.."
    return out
  }
  BEGIN { FS="\t"; OFS="\t" }
  FILENAME==cbf { cb[++ncb]=$0; next }
  /^[ ]/ { next }        # xattr continuation lines (defensive)
  {
    line=$0
    split(line, col, /[ \t]+/)
    mode=col[1]
    typ=substr(mode,1,1)
    if (typ=="f") typ="-"
    xattr=(mode ~ /\*$/) ? 1 : 0
    sub(/\*$/,"",mode)
    name=after_fields(line,5)
    link=""
    if (typ=="h") {
      li=last_index(name, " link to ")
      if (li>0) { link=substr(name,li+9); name=substr(name,1,li-1) }
    } else if (typ=="l") {
      li=last_index(name, " -> ")
      if (li>0) { link=substr(name,li+4); name=substr(name,1,li-1) }
    }
    npath=norm(name)
    nlink=(link=="" ? "" : norm(link))
    unsafe=0
    if (npath=="..UNSAFE.." || substr(npath,1,1)=="/") unsafe=1
    if (link!="" && (nlink=="..UNSAFE.." || substr(nlink,1,1)=="/")) unsafe=1
    digest=""; size=""; uid=""; gid=""; mtime=""
    if (typ=="-") {
      split(cb[++ci], m, "\t")
      digest=m[1]; size=m[2]; uid=m[4]; gid=m[5]; mtime=m[6]
    }
    seq=++s
    print layer, seq, typ, npath, nlink, xattr, unsafe, mode, uid, gid, mtime, size, digest, sparse
  }
  ' "$cbf" "$listf" >>"$out"

  rm -f "$cbf" "$listf" "$errf"
  return 0
}

# ---------------------------------------------------------------------------
# stage 2: simulate whiteouts -> survivors
# ---------------------------------------------------------------------------

simulate_whiteouts() {
  cat "$STATE"/layer_*.tsv | awk '
  BEGIN{FS="\t"; OFS="\t"}
  /^#/ { next }
  function basename(p,   i){ i=length(p); while(i>0 && substr(p,i,1)!="/") i--; return substr(p,i+1) }
  function dirname(p,   i){ i=length(p); while(i>0 && substr(p,i,1)!="/") i--; if(i==0) return "."; if(i==1) return "/"; return substr(p,1,i-1) }
  {
    layer=$1; seq=$2; typ=$3; path=$4
    rec[++n]=$0
    key=layer SUBSEP seq
    bn=basename(path); dn=dirname(path)
    if (typ=="-" && bn==".wh..wh..opq") {
      if (dn=="." || dn=="/") { for (q in vis) del[q]=1 }
      else { for (q in vis) if (q==dn || index(q, dn "/")==1) del[q]=1 }
      for (q in del) delete vis[q]
      delete del
      next
    }
    if (typ=="-" && bn ~ /^\.wh\./) {
      nm=bn; sub(/^\.wh\./,"",nm)
      tgt=(dn=="." ? nm : (dn=="/" ? "/" nm : dn "/" nm))
      for (q in vis) if (q==tgt || index(q, tgt "/")==1) del[q]=1
      for (q in del) delete vis[q]
      delete del
      next
    }
    if (typ=="h") anchor[link]=1
    vis[path]=key
  }
  END{
    for(i=1;i<=n;i++){
      split(rec[i],f,"\t")
      path=f[4]; key=f[1] SUBSEP f[2]
      if (vis[path]==key && f[3]=="-") print rec[i]
    }
  }
  ' >"$STATE/survivors.tsv"
}

# ---------------------------------------------------------------------------
# stage 3: deterministic plan
# ---------------------------------------------------------------------------

build_plan() {
  cat "$STATE"/layer_*.tsv >"$WORKDIR/all.tsv"
  awk -v schema="$SCHEMA" -v allow_sparse="$ALLOW_SPARSE" -v allf="$WORKDIR/all.tsv" '
  function jesc(s,   out,i,c){ out=""
    for(i=1;i<=length(s);i++){ c=substr(s,i,1)
      if(c=="\\") out=out "\\\\"
      else if(c=="\"") out=out "\\\""
      else if(c=="\t") out=out "\\t"
      else if(c=="\r") out=out "\\r"
      else if(c=="\n") out=out "\\n"
      else out=out c }
    return out }
  BEGIN{FS="\t"; OFS="\t"}
  FILENAME==allf {                           # all.tsv: collect hardlink anchors
    if ($3=="h" && $5!="") anchor[$5]=1
    next
  }
  {                                         # survivors.tsv
    layer=$1; path=$4; xattr=$6; unsafe=$7; mode=$8
    uid=$9; gid=$10; mtime=$11; size=$12; digest=$13; sparse=$14
    rec[++n]=$0
  }
  END{
    for (i=1;i<=n;i++){                     # choose canonical per identity
      split(rec[i],f,"\t")
      path=f[4]
      if (f[6]==1 || f[7]==1 || anchor[path]==1) continue
      if (f[14]==1 && allow_sparse!=1) continue
      id=f[13] "|" f[12] "|" f[8] "|" f[9] "|" f[10] "|" f[11]
      if (!(id in canon)) canon[id]=path
    }
    for (i=1;i<=n;i++){                     # emit sorted-key + JSON
      split(rec[i],f,"\t")
      layer=f[1]; path=f[4]; xattr=f[6]; unsafe=f[7]
      mode=f[8]; uid=f[9]; gid=f[10]; mtime=f[11]; size=f[12]; digest=f[13]; sparse=f[14]
      action="keep"; reason="canonical"; target=""
      if (unsafe==1) { action="preserve"; reason="unsafe_path" }
      else if (xattr==1) { action="preserve"; reason="xattr_or_acl" }
      else if (anchor[path]==1) { action="preserve"; reason="hardlink_anchor" }
      else if (sparse==1 && allow_sparse!=1) { action="preserve"; reason="sparse_layer" }
      else {
        id=digest "|" size "|" mode "|" uid "|" gid "|" mtime
        if (canon[id]!=path) { action="hardlink"; reason="identical_content_and_metadata"; target=canon[id] }
      }
      json=sprintf("{\"schema\":\"%s\",\"layer\":%d,\"path\":\"%s\",\"type\":\"file\",\"size\":%d,\"mode\":\"%s\",\"uid\":%d,\"gid\":%d,\"mtime\":%d,\"digest\":\"sha256:%s\",\"action\":\"%s\",\"reason\":\"%s\",\"target\":\"%s\"}", \
        schema, layer+0, jesc(path), size+0, jesc(mode), uid+0, gid+0, mtime+0, digest, action, reason, jesc(target))
      printf "%08d\t%s\t%s\n", layer+0, path, json
    }
  }
  ' "$WORKDIR/all.tsv" "$STATE/survivors.tsv" | LC_ALL=C sort -k1,1 -k2,2 | cut -f3-
}

i=0
for archive in "${LAYERS[@]}"; do
  idx=$(printf '%04d' "$i")
  adig=$(sha256sum "$archive" | awk '{print $1}') || die "sha256 failed: $archive"
  statef="$STATE/layer_${idx}.tsv"
  sparse=0
  need_scan=1
  if [ -f "$statef" ] && [ "$(sed -n '1p' "$statef")" = "# $adig 1" ]; then
    sparse=1; need_scan=0
  elif [ -f "$statef" ] && [ "$(sed -n '1p' "$statef")" = "# $adig 0" ]; then
    need_scan=0
  fi
  if [ $need_scan -eq 0 ] && ! tail -n1 "$statef" | grep -q '^#END$'; then
    need_scan=1
  fi
  if [ $need_scan -eq 1 ]; then
    archive_has_sparse "$archive" && sparse=1 || sparse=0
    log "layer $i: scanning $archive (sparse=$sparse)"
    tmp="$statef.tmp.$$"
    body="$WORKDIR/scan_${idx}.body.$$"
    scan_layer "$i" "$archive" "$body" "$sparse" || { rm -f "$tmp" "$body"; die "failed to scan $archive"; }
    {
      printf '# %s %s\n' "$adig" "$sparse"
      cat "$body"
      printf '#END\n'
    } >"$tmp" || { rm -f "$tmp" "$body"; die "cannot build $statef"; }
    rm -f "$body"
    mv -f "$tmp" "$statef" || die "cannot commit $statef"
  else
    log "layer $i: cached ($archive)"
  fi

  printf '%s\t%s\t%s\t%s\n' "$i" "$archive" "$adig" "$sparse" >>"$LAYER_META.tmp"
  i=$((i+1))
done
mv -f "$LAYER_META.tmp" "$LAYER_META"

simulate_whiteouts

emit_all() {
  printf '{"schema":"%s","tool":"%s","kind":"manifest","layers":%d}\n' "$SCHEMA" "$PROG" "${#LAYERS[@]}"
  awk -F'\t' '{printf "{\"schema\":\"%s\",\"kind\":\"layer\",\"index\":%d,\"sha256\":\"%s\",\"sparse\":%s}\n", schema, $1, $3, ($4==1?"true":"false")}' schema="$SCHEMA" "$LAYER_META"
  build_plan
}

# ---------------------------------------------------------------------------
# verification
# ---------------------------------------------------------------------------

if [ "$VERIFY" -eq 1 ]; then
  fail=0
  i=0
  for archive in "${LAYERS[@]}"; do
    idx=$(printf '%04d' "$i")
    if [ -n "$SNAP" ] && [ -f "$SNAP/state/layer_${idx}.tsv" ]; then
      statef="$SNAP/state/layer_${idx}.tsv"
    else
      statef="$STATE/layer_${idx}.tsv"
    fi
    adig=$(sha256sum "$archive" | awk '{print $1}')
    stored=$(sed -n '1s/^# \([0-9a-f]*\) .*/\1/p' "$statef" 2>/dev/null)
    sparse_stored=$(sed -n '1s/^# [0-9a-f]* \([01]\)$/\1/p' "$statef" 2>/dev/null)
    if [ "$adig" != "$stored" ]; then
      warn "layer $i archive digest mismatch (stored=$stored now=$adig)"; fail=1
    fi
    if scan_layer "$i" "$archive" "$WORKDIR/verify_${idx}.body" "$sparse_stored" 2>/dev/null; then
      if diff -q <(grep -v '^#' "$statef") "$WORKDIR/verify_${idx}.body" >/dev/null; then
        log "layer $i: content digests verified"
      else
        warn "layer $i content digest verification FAILED"; fail=1
      fi
    else
      warn "layer $i could not be re-scanned"; fail=1
    fi
    rm -f "$WORKDIR/verify_${idx}.body"
    i=$((i+1))
  done

  build_plan >"$WORKDIR/plan.check.jsonl"
  [ -n "$SNAP" ] || warn "no prior state found; verified only against this run"
  awk '
    /^\{/ {
      if (match($0,/"path":"[^"]*"/)) { p=substr($0,RSTART+8,RLENGTH-9); seen[p]++ }
      if (match($0,/"target":"[^"]*"/)) { t=substr($0,RSTART+10,RLENGTH-11); if(t!="") need[t]=1 }
      if (match($0,/"action":"[^"]*"/)) { a=substr($0,RSTART+10,RLENGTH-11); if(a=="hardlink") links++ }
    }
    END {
      for (t in need) if (!(t in seen)) { print "missing hardlink target: " t > "/dev/stderr"; bad=1 }
      for (p in seen) if (seen[p]>1) { print "duplicate path: " p > "/dev/stderr"; bad=1 }
      printf "plan: %d paths, %d hardlinks\n", length(seen), links > "/dev/stderr"
      exit bad
    }
  ' "$WORKDIR/plan.check.jsonl" || fail=1
  [ $fail -eq 0 ] && log "verification OK" || warn "verification reported problems"
  exit $((fail?2:0))
fi

if [ -n "$PLAN" ]; then
  emit_all >"$PLAN.tmp.$$" && mv -f "$PLAN.tmp.$$" "$PLAN" || die "cannot write plan $PLAN"
  log "plan written to $PLAN"
else
  emit_all
fi

2.4 Plan schema

The plan is JSON Lines, ordered by layer then path:

{"schema":"ocidedup/1","kind":"manifest","layers":4}
{"schema":"ocidedup/1","kind":"layer","index":0,"sha256":"...","sparse":false}
{"schema":"ocidedup/1","layer":0,"path":"etc/config","size":10,"mode":"-rw-r--r--",
 "uid":1000,"gid":1000,"mtime":1700000000,"digest":"sha256:...",
 "action":"keep","reason":"canonical","target":""}
{"schema":"ocidedup/1","layer":1,"path":"opt/copyA","size":10,"mode":"-rw-r--r--",
 "uid":1000,"gid":1000,"mtime":1700000000,"digest":"sha256:...",
 "action":"hardlink","reason":"identical_content_and_metadata","target":"etc/config"}

action is one of keep, hardlink, preserve. reason is one of canonical, identical_content_and_metadata, hardlink_anchor, xattr_or_acl, sparse_layer, unsafe_path. A consumer applies the plan to the merged extracted rootfs with ln -f target path for hardlink entries; nothing else is changed, so whiteouts, hardlink groups, ownership, sparse extents and unsupported metadata are untouched.

What each group proves:

  • Whiteout semantics — data/only-lower is whiteouted in layer 1 and never appears in the plan.
  • Cross-layer dedup — opt/copyA, ok/copyA3 (non-sparse layers) become hardlink entries targeting the layer-0 canonical etc/config; their digest/size/mode/uid/gid/mtime are asserted equal to the target.
  • Hardlink preservation — hard/b is a hardlink anchor and is preserve/hardlink_anchor; no unsafe path is ever used as a target.
  • xattr safety — opt/xattred carries user.demo and is preserve/xattr_or_acl.
  • Sparse safety — layer 2 contains the sparse var/blob; by default every file in that layer is preserve/sparse_layer, including the byte-identical blob/copy. With --allow-sparse, blob/copy instead hardlinks to var/blob, proving the exclusion is the only thing preventing the link.
  • Path traversal — the member crafted as ../escaped is normalized to the sentinel ..UNSAFE.. and emitted as preserve/unsafe_path.
  • Plan integrity — every hardlink target is a keep, and all hardlink peers match on content and every metadata field.
  • Determinism — two independent runs produce byte-identical plans.
  • Restartability — deleting state/layer_0002.tsv after a run causes only layer 2 to be rescanned; all other layers are reported cached, and the rebuilt plan is byte-identical.
  • Verification — --verify returns 0 on intact layers and 2 after a single byte is appended to layers/3.tar, with an explicit archive digest mismatch and per-record digest comparison.

Manual spot checks:

# authoritative content digests
sha256sum layers/0.tar layers/1.tar layers/2.tar layers/3.tar

jq -c 'select(.kind==null) | {path,action,reason,target}' plan.jsonl

Caveats: sparse detection is conservative at the layer granularity by default (--allow-sparse opts in); xattr/ACL detection relies on GNU tar's * marker and therefore also excludes files whose xattrs GNU tar cannot round-trip; the tool emits a plan and deliberately does not extract or apply it. Under an unprivileged user the archive uid/gid in the plan is still the original archive value, so it remains valid for a privileged applier.
