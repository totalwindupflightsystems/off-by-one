Constant-Time, Crash-Safe Threshold Signatures for a Rotating Committee

Problem class: py-20261006-constant-time-threshold-signatures Environment: Python 3.11 (verified on 3.14) · Status: diagnosed, fixed, verified (19/19 tests pass)

1. Root-cause analysis

The requirements collapse into five independent failure modes:

  • RC-1 — Nonce reuse across retries (fatal). Reusing a nonce pair (d_i,e_i) for two different messages lets an attacker recover the secret. For Schnorr with reused nonce R and challenges c1 ≠ c2: z1 = k + c1·x, z2 = k + c2·x ⇒ x = (z1 − z2)/(c1 − c2). Buggy patterns: re-drawing nonces only on success; caching commitments without binding the message; deriving the nonce from the message so a retry silently yields a second nonce.
  • RC-2 — Non-idempotent retries / reordered messages. Replay generating fresh partials, or challenge hashing over an un-canonical commitment order, corrupts aggregation.
  • RC-3 — Partial-round state not durable. Losing the nonce/partial association on crash causes re-derivation or equivocation (a second signature for the same session).
  • RC-4 — Timing/error side channels. Branching on secret bits, early-exit loops, variable-time modular inverse (EEA), and == comparisons leak secrets; rejecting a conflict after secret work turns errors into an oracle.
  • RC-5 — Broken committee rotation. Arbitrary zero-sum share deltas preserve the sum but destroy the Shamir polynomial, so Lagrange interpolation reconstructs the wrong secret. (This bug surfaced during verification.)

2. The exact fix

RC-1 + RC-3 — per-node durable session state machine. Invariant: (epoch, sid) is bound to at most one message digest and a finalized session never emits another partial. The conflict check runs before any secret operation. Nonces are derived deterministically from a per-epoch secret (HMAC(master, epoch)), so a restarted node recomputes identical (d_i,e_i) instead of drawing new ones. State is written atomically (tmp + os.replace) and keys are namespaced p{pid}:{sid}.

def bind_message(self, epoch, sid, digest):
    rec = self.open_session(epoch, sid)
    if rec["finalized"]:
        raise SessionFinalizedError(...)
    hexd = digest.hex()
    if rec["digest"] is None:
        rec["digest"] = hexd          # bind exactly once
    elif not hmac.compare_digest(rec["digest"], hexd):
        raise NonceReuseError(...)    # same nonce, different message -> abort
    return rec

RC-2 — canonical commitment encoding. Sort by participant id before hashing; bind the message digest into both the binding factor and the challenge:

rho_i = H("rho", i, SHA256(m), encode_commitments(commitments))  # sorted
c     = H("chal", R, X, SHA256(m))
z_i   = d_i + rho_i·e_i + c·λ_i·x_i

RC-4 — constant-time discipline. Fixed-iteration Montgomery ladder (both branches do the same number of multiplications), Fermat inverse (a^(q−2), no variable-time EEA), hmac.compare_digest for all comparisons.

def ct_modexp(base, exp, mod, nbits):
    base %= mod
    r0, r1 = 1, base
    for i in range(nbits - 1, -1, -1):      # fixed count, no secret branch cost
        bit = (exp >> i) & 1
        if bit: r0 = (r0*r1) % mod; r1 = (r1*r1) % mod
        else:   r1 = (r0*r1) % mod; r0 = (r0*r0) % mod
    return r0
def ct_inv(a, mod=Q): return ct_modexp(a, mod-2, mod, mod.bit_length())
def ct_eq(a,b):       return hmac.compare_digest(a, b)

RC-5 — structurally-correct refresh. Add g(i) where g has degree t−1 and g(0)=0, keeping the same Shamir secret/public key:

def refresh_shares(shares, threshold):
    coeffs = [0] + [secrets.randbelow(Q) for _ in range(threshold - 1)]
    return {i: (shares[i] + _poly_eval(coeffs, i)) % Q for i in shares}

Honest limitations

  • CPython cannot guarantee constant-time execution (interpreter, GC, bigint internals). Production must route scalar arithmetic through a vetted C library (libsecp256k1, BoringSSL, cryptography).
  • The NonceStore file holds partial signatures and needs OS access controls / encryption at rest.
  • trusted_dealer is setup-only; use VSS/DKG in production.
  • Partial shares must be authenticated before aggregation in an adversarial network.
