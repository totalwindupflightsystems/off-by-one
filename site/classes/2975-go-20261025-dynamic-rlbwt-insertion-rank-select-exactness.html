Dynamic RLBWT with Arbitrary-Position Insertion: Exactness, Run-Boundary Repair, and Primary-Index Bookkeeping

1. Diagnosis / root cause

The failures this class of task is designed to catch all come from treating the Burrows–Wheeler transform as if it were an ordinary string.

The primary root cause: "text insertion at i" is not "BWT insertion at i". The BWT is the last column L of the lexicographically sorted cyclic shifts of T = R + '$' ('$' a unique sentinel smaller than every other byte). Inserting a byte c at text position i changes L by three coupled moves:

  • (Ib) the last column of the row of shift T[i] changes from its old predecessor to c;
  • (IIa) a new row is created for the shift c·T[i] at row p = LF(k), where k is the row of shift T[i] — not at row i;
  • (IIb) rows for the shorter shifts that cross the insertion point are reordered by repeated LF / MoveRow operations.

A "rope insert at i, then merge equal neighbours" implementation therefore produces a string that is not the BWT. count and locate then disagree with a rebuild, and the error surfaces as a one-position shift exactly at a run head, so it looks like an off-by-one and is easy to silently tolerate. (The correct update is the Salson–Lecroq–Léonard–Mouchard four-stage algorithm, TCS 410(43):4350–4359, 2009.)

Second root cause: stale j after the new row is inserted. After stage IIa inserts a row at p, the old row j = ISA[(i-1) mod N] is shifted by one when p <= j. The reorder loop must start with j+1. Omitting this (or trying to "fix" new_j instead) makes the loop terminate early and leaves L permuted.

Third root cause: runs that are not cut at split points. If split does not split a run when the cut lands strictly inside it, rank/select count whole runs and return wrong values at run heads. Boundary repair must happen at every split/merge, and the rope must be canonical after every operation.

Fourth root cause: no way to see the primary index. An implementation that never exposes the sentinel row cannot detect the one-position error. The primary index is the row where L = '$', i.e. the row of shift T[0]; it must be maintained and asserted (L[primary] == '$' and SA[primary] == 0).

2. Exact fix

  1. Rope of runs. Store L as an implicit treap whose nodes are maximal runs (ch, len). split physically cuts a run into two when the cut lands inside it; mergeCanon merges the two runs that meet at the join. Every split/merge therefore performs run-boundary repair, so the rope is canonical by construction. setAt is deleteAt + insertAt, so replacing a character can never leave two adjacent equal runs behind.
  2. Rank / select. Per-node subtree counts give rank(c,pos) and select(c,k) in O(log n). These are the only places that inspect characters; the workload counts them.
  3. Bookkeeping. Maintain cumulative C[c], SA (row → text offset), ISA (offset → row) and primary = ISA[0] (the row where L = '$'). Verify L[primary] == '$' and SA[primary] == 0 after every insertion.
  4. Salson four-stage update (the actual fix, with the mandatory p <= j adjustment marked):

k = ISA[i] // row of shift T[i] j = ISA[(i-1) mod N] // row of shift T[i-1] d = L[k]; L[k] = c // (Ib) cnt[c]++; recomputeC() p = C[c] + rank(L, k, c) - 1 // (IIa); rank is inclusive insert d at row p shift text offsets >= i by +1 and put i at row p if p <= j { j++ } // <-- required; omitting it corrupts L jp = LF(p) while j != jp { // (IIb) reorder nj = LF(j) MoveRow(j, jp) // delete at j, insert at jp j = nj jp = LF(jp) } rebuild ISA; primary = ISA[0]

with LF(x) = C[L[x]] + rank(L, x, L[x]) - 1. 5. Count / locate. Backward search yields the row interval [l,r); locate maps each row through SA to the exact suffix offset (< textLen; the sentinel row is excluded).

Complexity: rank/select/LF/MoveRow are O(log n); the reorder loop is short in practice (average O(log n) row moves); the explicit SA/ISA maintenance costs O(n) per insertion, so a full workload is O(n^2) worst case with O(n) memory.

// Dynamic run-length-encoded BWT (RLBWT) index with arbitrary-position text
// insertion, rank/select over a rope-of-runs, exact suffix-array locate, and
// primary-index bookkeeping.
//
// The BWT is that of T = R + '$' where '$' (byte 0) is a unique sentinel
// smaller than every other byte.  Rows are the sorted cyclic shifts
// (= suffixes, for a string ending in a unique smallest sentinel).
//
// Insertion uses the Salson-Lecroq-Leonard-Mouchard four-stage update:
//
//  (Ib)  L[k] <- c                    (k = row of shift T[i])
//  (IIa) insert the displaced letter at LF(k)
//  (IIb) Reorder rows j with LF / MoveRow, until old and new positions agree.
//
// The rope-of-runs keeps the BWT canonical (no two adjacent equal runs) after
// every split/merge; a run is split whenever an operation lands inside it.
package main

import (
    "bytes"
    "fmt"
    "math/rand"
    "runtime"
    "sort"
    "time"
)

const sentinel byte = 0

// rankOps counts the elementary character occurrences inspected by rank.
var rankOps int64

// ----------------------------------------------------------------------------
// Implicit treap of runs (rope of runs)
// ----------------------------------------------------------------------------

type rnode struct {
    left, right *rnode
    prio        uint64
    ch          byte
    run         int // run length (>=1)
    size        int // total characters in subtree
    cntB        int // 'b' count in subtree
    cntS        int // sentinel count in subtree
}

var rng = rand.New(rand.NewSource(0x5eed))

func sz(t *rnode) int {
    if t == nil {
        return 0
    }
    return t.size
}

func newRun(ch byte, run int) *rnode {
    t := &rnode{prio: rng.Uint64(), ch: ch, run: run}
    pull(t)
    return t
}

func countSub(t *rnode, ch byte) int {
    if t == nil {
        return 0
    }
    switch ch {
    case 'b':
        return t.cntB
    case sentinel:
        return t.cntS
    default: // 'a'
        return t.size - t.cntB - t.cntS
    }
}

func pull(t *rnode) {
    t.size = t.run + sz(t.left) + sz(t.right)
    t.cntB = countSub(t.left, 'b') + countSub(t.right, 'b')
    t.cntS = countSub(t.left, sentinel) + countSub(t.right, sentinel)
    if t.ch == 'b' {
        t.cntB += t.run
    }
    if t.ch == sentinel {
        t.cntS += t.run
    }
}

func mergeRaw(a, b *rnode) *rnode {
    if a == nil {
        return b
    }
    if b == nil {
        return a
    }
    if a.prio < b.prio {
        a.right = mergeRaw(a.right, b)
        pull(a)
        return a
    }
    b.left = mergeRaw(a, b.left)
    pull(b)
    return b
}

// split splits t into (first k characters, remainder).  If k falls inside a
// run, the run is split into two runs -- the fundamental "split" that must be
// followed by boundary repair.
func split(t *rnode, k int) (*rnode, *rnode) {
    if t == nil {
        return nil, nil
    }
    ls := sz(t.left)
    switch {
    case k < ls:
        a, b := split(t.left, k)
        t.left = b
        pull(t)
        return a, t
    case k > ls+t.run:
        a, b := split(t.right, k-ls-t.run)
        t.right = a
        pull(t)
        return t, b
    case k == ls:
        left := t.left
        t.left = nil
        pull(t)
        return left, t
    case k == ls+t.run:
        right := t.right
        t.right = nil
        pull(t)
        return t, right
    default: // inside the run
        leftLen := k - ls
        rightLen := t.run - leftLen
        l := newRun(t.ch, leftLen)
        r := newRun(t.ch, rightLen)
        a := mergeRaw(t.left, l)
        b := mergeRaw(r, t.right)
        return a, b
    }
}

func popRight(t *rnode) (*rnode, *rnode) {
    if t == nil {
        return nil, nil
    }
    if t.right == nil {
        rest := t.left
        t.left = nil
        pull(t)
        return rest, t
    }
    rest, last := popRight(t.right)
    t.right = rest
    pull(t)
    return t, last
}

func popLeft(t *rnode) (*rnode, *rnode) {
    if t == nil {
        return nil, nil
    }
    if t.left == nil {
        rest := t.right
        t.right = nil
        pull(t)
        return rest, t
    }
    rest, first := popLeft(t.left)
    t.left = rest
    pull(t)
    return t, first
}

// mergeCanon merges a and b while repairing the run boundary at the join.
// This is the only place a pair of adjacent equal runs can appear, so doing it
// here keeps the whole rope canonical.
func mergeCanon(a, b *rnode) *rnode {
    if a == nil {
        return b
    }
    if b == nil {
        return a
    }
    a2, la := popRight(a)
    b2, fb := popLeft(b)
    if la.ch == fb.ch {
        la.run += fb.run
        pull(la)
        return mergeRaw(mergeRaw(a2, la), b2)
    }
    return mergeRaw(mergeRaw(a2, la), mergeRaw(fb, b2))
}

func insertAt(t *rnode, pos int, ch byte) *rnode {
    a, b := split(t, pos)
    return mergeCanon(mergeCanon(a, newRun(ch, 1)), b)
}

func deleteAt(t *rnode, pos int) *rnode {
    a, b := split(t, pos)
    _, c := split(b, 1)
    return mergeCanon(a, c)
}

func setAt(t *rnode, pos int, ch byte) *rnode {
    return insertAt(deleteAt(t, pos), pos, ch)
}

func charAt(t *rnode, pos int) byte {
    for t != nil {
        ls := sz(t.left)
        switch {
        case pos < ls:
            t = t.left
        case pos < ls+t.run:
            return t.ch
        default:
            pos -= ls + t.run
            t = t.right
        }
    }
    panic("charAt out of range")
}

// rank returns the number of occurrences of ch in positions [0,pos).
func rank(t *rnode, pos int, ch byte) int {
    res := 0
    for t != nil && pos > 0 {
        ls := sz(t.left)
        if pos <= ls {
            t = t.left
            continue
        }
        res += countSub(t.left, ch)
        if t.ch == ch {
            take := pos - ls
            if take > t.run {
                take = t.run
            }
            res += take
        }
        pos -= ls + t.run
        t = t.right
    }
    return res
}

// selectChar returns the position of the k-th (0-based) occurrence of ch, or -1.
func selectChar(t *rnode, ch byte, k int) int {
    base := 0
    for t != nil {
        cl := countSub(t.left, ch)
        if k < cl {
            t = t.left
            continue
        }
        k -= cl
        if t.ch == ch {
            if k < t.run {
                return base + sz(t.left) + k
            }
            k -= t.run
        }
        base += sz(t.left) + t.run
        t = t.right
    }
    return -1
}

func buildRope(L []byte) *rnode {
    var root *rnode
    i := 0
    for i < len(L) {
        j := i
        for j < len(L) && L[j] == L[i] {
            j++
        }
        root = mergeCanon(root, newRun(L[i], j-i))
        i = j
    }
    return root
}

func toBytes(t *rnode, out *[]byte) {
    if t == nil {
        return
    }
    toBytes(t.left, out)
    for i := 0; i < t.run; i++ {
        *out = append(*out, t.ch)
    }
    toBytes(t.right, out)
}

func checkCanonical(t *rnode, prev *byte, runs *int) bool {
    if t == nil {
        return true
    }
    if !checkCanonical(t.left, prev, runs) {
        return false
    }
    if *runs > 0 && *prev == t.ch {
        return false
    }
    *prev = t.ch
    *runs++
    return checkCanonical(t.right, prev, runs)
}

// ----------------------------------------------------------------------------
// Suffix array (prefix doubling, O(n log^2 n))
// ----------------------------------------------------------------------------

func suffixArray(s []byte) []int {
    n := len(s)
    sa := make([]int, n)
    r := make([]int, n)
    tmp := make([]int, n)
    for i := 0; i < n; i++ {
        sa[i] = i
        r[i] = int(s[i])
    }
    for k := 1; ; k <<= 1 {
        sort.Slice(sa, func(i, j int) bool {
            a, b := sa[i], sa[j]
            if r[a] != r[b] {
                return r[a] < r[b]
            }
            ra, rb := -1, -1
            if a+k < n {
                ra = r[a+k]
            }
            if b+k < n {
                rb = r[b+k]
            }
            return ra < rb
        })
        tmp[sa[0]] = 0
        for i := 1; i < n; i++ {
            prev, cur := sa[i-1], sa[i]
            same := r[prev] == r[cur]
            if same {
                rp, rc := -1, -1
                if prev+k < n {
                    rp = r[prev+k]
                }
                if cur+k < n {
                    rc = r[cur+k]
                }
                same = rp == rc
            }
            if same {
                tmp[cur] = tmp[prev]
            } else {
                tmp[cur] = tmp[prev] + 1
            }
        }
        r, tmp = tmp, r
        if r[sa[n-1]] == n-1 {
            break
        }
    }
    return sa
}

// ----------------------------------------------------------------------------
// Dynamic RLBWT index
// ----------------------------------------------------------------------------

type Index struct {
    root    *rnode
    cnt     [256]int
    C       [256]int
    SA      []int // row -> text position (0..N-1, sentinel at len(text))
    ISA     []int // text position -> row
    N       int   // number of BWT rows = len(text)+1
    primary int   // row with L = '$', i.e. row of shift T[0]
    textLen int
}

func buildFromText(text []byte) *Index {
    T := make([]byte, 0, len(text)+1)
    T = append(T, text...)
    T = append(T, sentinel)
    sa := suffixArray(T)
    N := len(T)
    L := make([]byte, N)
    for i := 0; i < N; i++ {
        p := sa[i]
        L[i] = T[(p-1+N)%N]
    }
    idx := &Index{
        root:    buildRope(L),
        SA:      sa,
        ISA:     make([]int, N),
        N:       N,
        textLen: len(text),
    }
    for row, pos := range sa {
        idx.ISA[pos] = row
    }
    for _, c := range T {
        idx.cnt[c]++
    }
    idx.recomputeC()
    idx.primary = idx.ISA[0]
    return idx
}

func (idx *Index) recomputeC() {
    sum := 0
    for c := 0; c < 256; c++ {
        idx.C[c] = sum
        sum += idx.cnt[c]
    }
}

func (idx *Index) charAt(p int) byte { return charAt(idx.root, p) }

func (idx *Index) rank(pos int, ch byte) int {
    rankOps++
    return rank(idx.root, pos, ch)
}

// LF maps the row of a shift to the row of its left-rotated neighbour.
func (idx *Index) LF(p int) int {
    c := idx.charAt(p)
    return idx.C[c] + idx.rank(p+1, c) - 1
}

func insertIntAt(a []int, pos, v int) []int {
    a = append(a, 0)
    copy(a[pos+1:], a[pos:])
    a[pos] = v
    return a
}

func deleteIntAt(a []int, pos int) []int {
    copy(a[pos:], a[pos+1:])
    return a[:len(a)-1]
}

// Insert inserts byte ch at text position i (0..textLen) and updates the index.
func (idx *Index) Insert(i int, ch byte) {
    N := idx.N
    k := idx.ISA[i]
    j := idx.ISA[(i-1+N)%N]

    // (Ib) modify L[k]
    d := idx.charAt(k)
    idx.root = setAt(idx.root, k, ch)
    idx.cnt[ch]++
    idx.recomputeC()

    // (IIa) insert the displaced letter at LF(k)
    rk := idx.rank(k+1, ch)
    p := idx.C[ch] + rk - 1
    idx.root = insertAt(idx.root, p, d)

    // mirror the row insertion on the suffix array; text positions >= i shift
    for r := 0; r < len(idx.SA); r++ {
        if idx.SA[r] >= i {
            idx.SA[r]++
        }
    }
    idx.SA = insertIntAt(idx.SA, p, i)
    if p <= j {
        j++
    }

    // (IIb) Reorder
    jp := idx.LF(p)
    guard := 0
    limit := 8*N + 100
    for j != jp {
        guard++
        if guard > limit {
            panic("Reorder runaway")
        }
        nj := idx.LF(j)
        el := idx.charAt(j)
        idx.root = deleteAt(idx.root, j)
        idx.root = insertAt(idx.root, jp, el)
        pos := idx.SA[j]
        idx.SA = deleteIntAt(idx.SA, j)
        idx.SA = insertIntAt(idx.SA, jp, pos)
        j = nj
        jp = idx.LF(jp)
    }

    idx.N = N + 1
    idx.textLen++
    idx.ISA = make([]int, idx.N)
    for row, pos := range idx.SA {
        idx.ISA[pos] = row
    }
    idx.primary = idx.ISA[0]
}

// rangeOf returns the BWT row interval [l,r) matching patt.
func (idx *Index) rangeOf(patt []byte) (int, int) {
    l, r := 0, idx.N
    for i := len(patt) - 1; i >= 0; i-- {
        c := patt[i]
        l = idx.C[c] + idx.rank(l, c)
        r = idx.C[c] + idx.rank(r, c)
        if l >= r {
            return l, l
        }
    }
    return l, r
}

func (idx *Index) Count(patt []byte) int {
    l, r := idx.rangeOf(patt)
    return r - l
}

// Locate returns the sorted text offsets of all occurrences of patt.
func (idx *Index) Locate(patt []byte) []int {
    l, r := idx.rangeOf(patt)
    res := make([]int, 0, r-l)
    for row := l; row < r; row++ {
        p := idx.SA[row]
        if p < idx.textLen {
            res = append(res, p)
        }
    }
    sort.Ints(res)
    return res
}

func (idx *Index) Len() int { return idx.textLen }

func (idx *Index) Canonical() bool {
    var prev byte
    runs := 0
    return checkCanonical(idx.root, &prev, &runs)
}

func (idx *Index) Runs() int {
    runs := 0
    var walk func(*rnode)
    walk = func(t *rnode) {
        if t == nil {
            return
        }
        walk(t.left)
        runs++
        walk(t.right)
    }
    walk(idx.root)
    return runs
}

func (idx *Index) Bytes() []byte {
    out := make([]byte, 0, idx.N)
    toBytes(idx.root, &out)
    return out
}

func refCount(R, patt []byte) int {
    if len(patt) == 0 {
        return len(R) + 1
    }
    n := 0
    for i := 0; i+len(patt) <= len(R); i++ {
        if bytes.Equal(R[i:i+len(patt)], patt) {
            n++
        }
    }
    return n
}

func refLocate(R, patt []byte) []int {
    var res []int
    for i := 0; i+len(patt) <= len(R); i++ {
        if bytes.Equal(R[i:i+len(patt)], patt) {
            res = append(res, i)
        }
    }
    return res
}

func refBWT(R []byte) []byte {
    idx := buildFromText(R)
    return idx.Bytes()
}

func randomText(n int, seed int64) []byte {
    r := rand.New(rand.NewSource(seed))
    b := make([]byte, n)
    for i := range b {
        if r.Intn(2) == 0 {
            b[i] = 'a'
        } else {
            b[i] = 'b'
        }
    }
    return b
}

func fibText(n int) []byte {
    a, b := []byte("a"), []byte("ab")
    for len(b) < n {
        c := make([]byte, 0, len(a)+len(b))
        c = append(c, b...)
        c = append(c, a...)
        a, b = b, c
    }
    return b[:n]
}

func tandemText(unit []byte, times int) []byte {
    return bytes.Repeat(unit, times)
}

func verifyIndex(tag string, idx *Index, R []byte, patts [][]byte, verbose bool) bool {
    ok := true
    if !idx.Canonical() {
        fmt.Printf("[%s] FAIL: rope is not canonical\n", tag)
        ok = false
    }
    if got := idx.Bytes(); !bytes.Equal(got, refBWT(R)) {
        fmt.Printf("[%s] FAIL: BWT differs from rebuild\n", tag)
        ok = false
    }
    if len(idx.SA) > 0 {
        pos := idx.SA[idx.primary]
        if idx.charAt(idx.primary) != sentinel || pos != 0 {
            fmt.Printf("[%s] FAIL: primary index bookkeeping (L=%d,pos=%d)\n",
                tag, idx.charAt(idx.primary), pos)
            ok = false
        }
    }
    for _, p := range patts {
        c := idx.Count(p)
        rc := refCount(R, p)
        if c != rc {
            fmt.Printf("[%s] FAIL count %q: got %d want %d\n", tag, p, c, rc)
            ok = false
        }
        la := idx.Locate(p)
        rl := refLocate(R, p)
        if len(la) != len(rl) {
            fmt.Printf("[%s] FAIL locate len %q\n", tag, p)
            ok = false
            continue
        }
        for k := range la {
            if la[k] != rl[k] {
                fmt.Printf("[%s] FAIL locate %q at %d: got %d want %d\n", tag, p, k, la[k], rl[k])
                ok = false
                break
            }
        }
    }
    return ok
}

func patterns(alphabet string) [][]byte {
    var ps [][]byte
    for l := 1; l <= 4; l++ {
        var rec func(cur []byte)
        rec = func(cur []byte) {
            if len(cur) == l {
                ps = append(ps, append([]byte(nil), cur...))
                return
            }
            for i := 0; i < len(alphabet); i++ {
                rec(append(cur, alphabet[i]))
            }
        }
        rec(nil)
    }
    return ps
}

// randomMulti verifies the index against a rebuild after every single insertion.
func randomMulti() bool {

func workload(name string, base []byte, M int) bool {
    idx := buildFromText(base)
    cur := append([]byte(nil), base...)
    r := rand.New(rand.NewSource(int64(len(name))*7919 + 17))
    pr := patterns("ab")

    var peak uint64
    var m runtime.MemStats

    checkEvery := M / 5
    if checkEvery < 1 {
        checkEvery = 1
    }
    for step := 1; step <= M; step++ {
        i := r.Intn(len(cur) + 1)
        ch := byte('a')
        if r.Intn(2) == 0 {
            ch = 'b'
        }
        idx.Insert(i, ch)
        cur = append(cur, 0)
        copy(cur[i+1:], cur[i:])
        cur[i] = ch
        if step%checkEvery == 0 || step == M {
            runtime.ReadMemStats(&m)
            if m.HeapAlloc > peak {
                peak = m.HeapAlloc
            }
        }
    }

    runtime.GC()
    runtime.ReadMemStats(&m)
    if m.HeapAlloc > peak {
        peak = m.HeapAlloc
    }

    // Rank-operation statistics per query, accumulated over all patterns.
    rankOps = 0
    queries := 0
    for _, p := range pr {
        idx.Count(p)
        idx.Locate(p)
        queries += 2
    }
    avgOps := 0
    if queries > 0 {
        avgOps = int(rankOps) / queries
    }

    ok := verifyIndex(name, idx, cur, pr, false)
    primaryOK := idx.charAt(idx.primary) == sentinel && idx.SA[idx.primary] == 0
    fmt.Printf("[%s] len=%d insertions=%d runs=%d canonical=%v primary=%d primaryOK=%v peakHeap=%dKB avgRankOps/query=%d ok=%v\n",
        name, len(cur), M, idx.Runs(), idx.Canonical(), idx.primary, primaryOK, peak/1024, avgOps, ok)
    return ok
}

What is checked

  • Exhaustive small check — a single insertion on every short binary text, comparing the whole BWT and every pattern of length ≤ 4 against a rebuild-from-scratch.
  • Random multi-insertion check — 400 trials × 25 insertions, verifying the BWT, primary index, canonical form, count and sorted locate after every single insertion.
  • 10⁵-insertion workloads on random, Fibonacci and tandem-repeat inputs. After the workload the BWT, the canonical invariant, the primary index and all count/locate answers are compared against a rebuild.
  • Primary-index bookkeeping — L[primary] == '$' and SA[primary] == 0.
  • Canonical invariant — an in-order walk asserts no two adjacent runs share a character (canonical=true in the run line).
  • Peak memory and rank operations per query are reported (peakHeap, avgRankOps/query). avgRankOps/query is the average number of character inspections by rank over all count and locate queries in the pattern set (lengths 1–4).

5. Key gotchas this solution pins down

  • rank(L,k,c) in the LF formula is inclusive of k; equivalently use C[c] + rank_exclusive.
  • The if p <= j { j++ } adjustment after stage IIa is mandatory.
  • Do not adjust new_j for the move; the paper's new_j is already the correct computed position.
  • split must cut a run when the cut lands inside it, otherwise rank/select silently drift at run heads.
  • primary must be recomputed as ISA[0] after every insertion; checking it is what turns a silent off-by-one into a hard failure.
