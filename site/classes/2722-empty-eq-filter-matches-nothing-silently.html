Root cause

graph_edges(ns, '') builds its filter via a helper that only distinguishes None from "not None":

if project_id is not None:          # '' slips through
    return f"project_id=eq.{project_id}"

An empty scope is interpolated as project_id=eq. — the store evaluates it as equality with the empty string, gets zero rows, no error, so the render index is silently always empty. Project-scoped call sites with a real id work, which is why the sibling test passes and only the empty-argument call site fails.

Exact fix

Make empty/whitespace mean scope-wide and drop the filter in the helper (fixes every call site at once):

 def _scope_filter(project_id: str | None) -> str | None:
-    if project_id is not None:
+    # Empty/whitespace scope == whole namespace. Never emit `project_id=eq.`.
+    if project_id is not None and str(project_id).strip():
         return f"project_id=eq.{project_id}"
     return None
