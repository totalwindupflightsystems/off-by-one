Fix: mcp__duckbrain__remember call emitted with empty arguments

Problem class: agent-tool-call-emitted-with-empty-arguments Surface: DuckBrain HTTP API (<ip-address>:3000, x-api-key auth)

1. Symptom

tool_call to 'mcp__duckbrain__remember' is missing required argument(s):
key, domain, attributes, embedding_text. The tool was NOT invoked.

Repeated ~15 times with no state change.

2. Root cause

The payload was built with an empty arguments map. The runtime validates tool arguments locally, before invocation, so the call never reaches the MCP daemon. "No state change" is expected, not a hang.

Two facts from the error text: 1. The named fields are the exact required arguments. 2. "The tool was NOT invoked" is authoritative → failure is at emission, not invocation.

Do not probe or restart the daemon; fix the payload or bypass emission.

3. Diagnosis

Signal Meaning
missing required argument(s): <names> Local pre-invocation validation
The tool was NOT invoked Daemon never saw the request
Identical error repeated, no side effects Payload construction broken

Prove the daemon is independent:

curl -s http://<ip-address>:3000/health

/health may show "status":"degraded" / 503 when the embedding probe times out — the body says it's a health-probe budget, not a write failure. A degraded probe does not prove the write path is broken.

4. The fix

Option A — fix emission: emit the required args ({"key","domain","attributes","embedding_text"}) instead of {}; assert the payload is non-empty before emitting.

Option B — staged HTTP write (verified workaround): bypass deferred-tool emission. Write the script to a file (never inline):

cat > /tmp/duckbrain_write.py <<'PY'
#!/usr/bin/env python3
"""Write one DuckBrain memory over HTTP, then read it back to verify."""
import json, os, pathlib, urllib.parse, urllib.request

BASE = os.environ.get("DUCKBRAIN_URL", "http://<ip-address>:3000")

def load_token(role="foreman"):
    sidecar = pathlib.Path.home() / ".duckbrain" / f"{role}.token"
    if sidecar.is_file():
        return sidecar.read_text().strip()
    env = os.environ.get("DUCKBRAIN_API_KEY")
    if env:
        return env.strip()
    raise SystemExit(f"no DuckBrain token: expected {sidecar}")

def _request(path, *, data=None, method="GET", role="foreman"):
    headers = {"x-api-key": load_token(role)}          # NOT Bearer -> 401
    if data is not None:
        headers["Content-Type"] = "application/json"
    req = urllib.request.Request(BASE + path, data=data, method=method, headers=headers)
    with urllib.request.urlopen(req, timeout=30) as resp:
        return resp.status, json.loads(resp.read().decode() or "{}")

def write_memory(ns, key, text, domain="event", role="foreman"):
    path = "/api/memories?namespace=" + urllib.parse.quote(ns, safe="")   # query param!
    data = json.dumps({"key": key, "domain": domain, "content": text}).encode()  # 'content', not 'embedding_text'
    return _request(path, data=data, method="POST", role=role)

def read_back(ns, key, role="foreman"):
    path = ("/api/memories?namespace=" + urllib.parse.quote(ns, safe="")
            + "&prefix=" + urllib.parse.quote(key, safe=""))
    _, body = _request(path, method="GET", role=role)
    items = body.get("items") or body.get("memories") or []   # envelope differs; no '.count'
    return [m for m in items if m.get("key") == key]

def main():
    ns = os.environ.get("DUCKBRAIN_NS", "foreman")
    key = "/tick/2026-10-26/foreman/duckbrain-empty-args-fix"  # leading slash
    text = "Wrote via HTTP and verified by read-back."
    status, created = write_memory(ns, key, text)
    print(f"POST {status} id={created.get('id')} key={created.get('key')}")
    if status not in (200, 201):
        raise SystemExit(f"write failed: {status} {created}")
    matches = read_back(ns, key)
    if len(matches) != 1 or matches[0].get("id") != created.get("id"):
        raise SystemExit(f"read-back mismatch: {matches!r}")
    print(f"read-back OK: id={matches[0]['id']} key={matches[0]['key']}")
    print("VERIFIED")

if __name__ == "__main__":
    main()

5. Route gotchas

Mistake Correct
{"namespace": ns} in body ?namespace=<ns> query param
{"embedding_text": text} Body field is content (else 400)
Authorization: Bearer <tok> x-api-key: <tok> (else 401)
Token from wrong place ~/.duckbrain/<role>.token
Key without leading / Keep key filesystem-shaped
Inline python3 -c Stage /tmp/*.py

6. Verification

  1. POST /api/memories?namespace=<ns> {"key","domain","content"} → HTTP 201 + id.
  2. Separate GET /api/memories?namespace=<ns>&prefix=<urlencoded-key> → exactly one item, .id and .key match.
  3. Parse under .items (fallback .memories); never require .count.
  4. Record the witness in the board event.

Observed here:

GET /health                                -> 200 healthy (or 503 degraded + probe note)
GET /api/memories (no key)                 -> 401 "API key required"
GET /api/memories (bad x-api-key)          -> 401 "Invalid API key"
GET /api/memories (Authorization: Bearer)  -> 401

7. Anti-patterns

  • Don't restart the daemon, probe MCP, or re-call with {}.
  • Don't treat missing required argument(s) as transient.
  • Don't trust the POST status alone — read back; don't trust /health == degraded as a write failure.

Decision rule: "missing required argument(s)" + "The tool was NOT invoked" ⇒ fix the arguments you emit, or route around emission via the HTTP API and verify by read-back.
