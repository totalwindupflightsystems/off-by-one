FROST t-of-n Threshold Schnorr on secp256k1 (Node 20)

TL;DR

A correct FROST implementation needs three independent guards; omitting any one turns a threshold signer into a key-extraction oracle:

  1. A binding factor rho_i = H(i, msg, B) over a canonical encoding of the full commitment list B, so a last-mover cannot pick nonces after seeing honest commitments and bias the joint nonce.
  2. A known-discrete-log abort: if the aggregate nonce R is the identity element (discrete log 0), abort before any share is released. Otherwise z = c*x and anyone recovers x = z/c.
  3. Aggregation that re-derives rho_i and R_i = D_i + rho_i*E_i from the recorded commitment list and verifies z_i*G == R_i + c*lambda_i*PK_i. Never trust commitments or binding factors sent alongside a share.

The implementation below passes 18 checks, including a demonstration that removing guard (2) leaks the group secret while still producing a signature that verifies.

Root-cause analysis

The problem class is "nonce commitment / abort": a threshold Schnorr signer that is algebraically correct but missing the nonce-safety checks. The individual root causes are:

RC-1 — No known-DL abort on the aggregate nonce (critical)

With R the aggregate nonce and c = H(R, PK, m), the aggregate share is

z = sum_i (d_i + rho_i*e_i + lambda_i*s_i*c)
  = r + c*x          where r = DL(R), x = group secret

If an adversary can force R = O (the identity, so r = 0), then z = c*x and anyone computes x = z * c^-1 mod n. The forged signature even passes ordinary Schnorr verification because z*G = c*PK = R + c*PK. The only safe action is to abort the moment R == O, and to do it inside signShare before z_i is returned, not only at aggregation time.

RC-2 — Binding factor not over a canonical, complete commitment list

The binding factor must be rho_i = H1(i, msg, B) where B is a single deterministic byte encoding of all (id, D_j, E_j) tuples, sorted by id. If B is missing, unordered, or excludes some commitments, the last signer can choose D_i, E_i to make R a point with known discrete log (the "ROS"-style bias). With the binding factor over the canonical list this attack fails because rho_i depends on the attacker's own commitments.

RC-3 — Aggregator trusting commitments supplied with the share

A malicious signer can publish one commitment in round 1 (used to build B) and then hand the aggregator a different commitment or rho_i in round 2. If the aggregator verifies z_i against the attacker-supplied values, it can be tricked into emitting an invalid or biased aggregate. The fix is to ignore any commitment material attached to a share and recompute everything from the recorded list.

RC-4 — Feldman shares not verified

A corrupt dealer can distribute shares that do not lie on the committed polynomial. Every recipient must check s_i*G == sum_k A_k * i^k before using the share.

RC-5 — Non-canonical commitment ordering

Different participants must serialize B identically or their binding factors diverge. Sort by numeric id and use fixed-width big-endian scalars.

'use strict';

/**
 * FROST (Flexible Round-Optimized Schnorr Threshold signatures) for
 * t-of-n signing over secp256k1.
 *
 * Implements:
 *   - Feldman verifiable secret sharing key generation (dealer variant)
 *   - Round 1: per-party hiding + binding nonce commitments (D_i, E_i)
 *   - Round 2: binding-factor weighted signature shares z_i
 *   - Aggregation that re-derives every R_i from the *recorded* commitment
 *     list (so a party cannot be aggregated under a different commitment
 *     than the one that produced its binding factor)
 *   - Hard abort when the aggregate nonce R is the identity element, i.e. a
 *     point with known discrete log 0 (RFC 9591 style known-DL guard)
 *
 * Pure BigInt arithmetic + node:crypto SHA-256. No external dependencies.
 */

const crypto = require('crypto');

// ---------------------------------------------------------------------------
// secp256k1 domain parameters
// ---------------------------------------------------------------------------
const P = 0xfffffffffffffffffffffffffffffffffffffffffffffffffffffffefffffc2fn;
const N = 0xfffffffffffffffffffffffffffffffebaaedce6af48a03bbfd25e8cd0364141n;
const G = {
  x: 0x79be667ef9dcbbac55a06295ce870b07029bfcdb2dce28d959f2815b16f81798n,
  y: 0x483ada7726a3c4655da4fbfc0e1108a8fd17b448a68554199c47d08ffb10d4b8n,
};

// ---------------------------------------------------------------------------
// Field / scalar arithmetic
// ---------------------------------------------------------------------------
function mod(a, m = P) {
  const r = a % m;
  return r >= 0n ? r : r + m;
}

function modPow(base, exp, m = P) {
  base = mod(base, m);
  let result = 1n;
  while (exp > 0n) {
    if (exp & 1n) result = mod(result * base, m);
    base = mod(base * base, m);
    exp >>= 1n;
  }
  return result;
}

function egcd(a, b) {
  let oldR = a, r = b;
  let oldS = 1n, s = 0n;
  let oldT = 0n, t = 1n;
  while (r !== 0n) {
    const q = oldR / r;
    [oldR, r] = [r, oldR - q * r];
    [oldS, s] = [s, oldS - q * s];
    [oldT, t] = [t, oldT - q * t];
  }
  return { g: oldR, x: oldS, y: oldT };
}

function modInv(a, m = P) {
  a = mod(a, m);
  if (a === 0n) throw new Error('division by zero');
  const { g, x } = egcd(a, m);
  if (g !== 1n) throw new Error('element is not invertible');
  return mod(x, m);
}

// ---------------------------------------------------------------------------
// Point arithmetic (Jacobian internally, affine externally, null = identity)
// ---------------------------------------------------------------------------
const JINF = { X: 0n, Y: 1n, Z: 0n };

function toJ(p) {
  return p === null ? JINF : { X: p.x, Y: p.y, Z: 1n };
}

function fromJ(p) {
  if (p.Z === 0n) return null;
  const zInv = modInv(p.Z);
  const zInv2 = mod(zInv * zInv);
  return { x: mod(p.X * zInv2), y: mod(p.Y * zInv2 * zInv) };
}

function jDouble(p) {
  const { X, Y, Z } = p;
  if (Z === 0n || Y === 0n) return JINF;
  const A = mod(X * X);
  const B = mod(Y * Y);
  const C = mod(B * B);
  const D = mod(2n * (mod((X + B) * (X + B)) - A - C)); // 4*X*B
  const E = mod(3n * A); // a = 0
  const F = mod(E * E);
  const X3 = mod(F - 2n * D);
  const Y3 = mod(E * (D - X3) - 8n * C);
  const Z3 = mod(2n * Y * Z);
  return { X: X3, Y: Y3, Z: Z3 };
}

function jAdd(p, q) {
  if (p.Z === 0n) return q;
  if (q.Z === 0n) return p;
  const Z1Z1 = mod(p.Z * p.Z);
  const Z2Z2 = mod(q.Z * q.Z);
  const U1 = mod(p.X * Z2Z2);
  const U2 = mod(q.X * Z1Z1);
  const S1 = mod(p.Y * q.Z * Z2Z2);
  const S2 = mod(q.Y * p.Z * Z1Z1);
  if (U1 === U2) {
    if (S1 !== S2) return JINF; // p == -q
    return jDouble(p);
  }
  const H = mod(U2 - U1);
  const HH = mod(2n * H);
  const I = mod(HH * HH);
  const J = mod(H * I);
  const r = mod(2n * (S2 - S1));
  const V = mod(U1 * I);
  const X3 = mod(r * r - J - 2n * V);
  const Y3 = mod(r * (V - X3) - 2n * S1 * J);
  const Z3 = mod((mod((p.Z + q.Z) * (p.Z + q.Z)) - Z1Z1 - Z2Z2) * H);
  return { X: X3, Y: Y3, Z: Z3 };
}

function pointAdd(p, q) {
  return fromJ(jAdd(toJ(p), toJ(q)));
}

function pointNeg(p) {
  return p === null ? null : { x: p.x, y: mod(-p.y) };
}

function scalarMul(k, p) {
  k = mod(k, N);
  if (k === 0n || p === null) return null;
  let r = JINF;
  let q = toJ(p);
  while (k > 0n) {
    if (k & 1n) r = jAdd(r, q);
    q = jDouble(q);
    k >>= 1n;
  }
  return fromJ(r);
}

function pointEq(p, q) {
  if (p === null || q === null) return p === q;
  return p.x === q.x && p.y === q.y;
}

// ---------------------------------------------------------------------------
// Encoding helpers
// ---------------------------------------------------------------------------
function intToBytes32(x) {
  const b = Buffer.alloc(32);
  let v = x;
  for (let i = 31; i >= 0; i--) {
    b[i] = Number(v & 0xffn);
    v >>= 8n;
  }
  return b;
}

function bytesToScalar(buf) {
  let s = 0n;
  for (const byte of buf) s = (s << 8n) | BigInt(byte);
  return s;
}

function pointToBytes(p) {
  if (p === null) throw new Error('cannot encode the identity point');
  const prefix = (p.y & 1n) === 0n ? 0x02 : 0x03;
  return Buffer.concat([Buffer.from([prefix]), intToBytes32(p.x)]);
}

function pointFromBytes(buf) {
  if (buf.length !== 33) throw new Error('point encoding must be 33 bytes');
  const prefix = buf[0];
  if (prefix !== 0x02 && prefix !== 0x03) throw new Error('invalid point prefix');
  const x = bytesToScalar(buf.subarray(1));
  if (x >= P) throw new Error('x coordinate out of field');
  const y2 = mod(x * x * x + 7n);
  let y = modPow(y2, (P + 1n) / 4n, P);
  if (mod(y * y) !== y2) throw new Error('point is not on secp256k1');
  if ((y & 1n) !== BigInt(prefix & 1)) y = mod(-y);
  return { x, y };
}

// ---------------------------------------------------------------------------
// Random scalars
// ---------------------------------------------------------------------------
function randomScalar() {
  for (;;) {
    const s = bytesToScalar(crypto.randomBytes(32));
    if (s > 0n && s < N) return s;
  }
}

// ---------------------------------------------------------------------------
// Tagged hash (RFC 9591 style: H(context || tag || msg))
// ---------------------------------------------------------------------------
const CONTEXT = Buffer.from('FROST-secp256k1-SHA256-v1', 'utf8');

function sha256(...bufs) {
  const h = crypto.createHash('sha256');
  for (const b of bufs) h.update(b);
  return h.digest();
}

function taggedHash(tag, ...msgs) {
  return sha256(CONTEXT, Buffer.from(tag, 'utf8'), ...msgs);
}

function hashToScalar(tag, ...msgs) {
  return mod(bytesToScalar(taggedHash(tag, ...msgs)), N);
}

// ---------------------------------------------------------------------------
// Feldman VSS key generation
// ---------------------------------------------------------------------------
/**
 * Dealer-based Feldman VSS.
 * @returns {{
 *   n:number, t:number,
 *   groupPublicKey:object,
 *   commitments:object[],
 *   shares:{id:number, secret:bigint, publicShare:object}[],
 *   dealerSecret:bigint
 * }}
 */
function keygen(n, t) {
  if (!Number.isInteger(n) || !Number.isInteger(t)) throw new Error('n and t must be integers');
  if (t < 1 || t > n) throw new Error('require 1 <= t <= n');

  // f(x) = a_0 + a_1 x + ... + a_{t-1} x^{t-1}
  const coeffs = [];
  for (let k = 0; k < t; k++) coeffs.push(randomScalar());

  // A_k = a_k * G  (Feldman commitments)
  const commitments = coeffs.map((a) => scalarMul(a, G));

  const shares = [];
  for (let i = 1; i <= n; i++) {
    // Horner evaluation of f(i)
    let secret = 0n;
    for (let k = t - 1; k >= 0; k--) secret = mod(secret * BigInt(i) + coeffs[k], N);

    // Verify share against commitments:
    //   s_i * G == sum_k A_k * i^k
    const lhs = scalarMul(secret, G);
    let rhs = null;
    let xp = 1n;
    for (let k = 0; k < t; k++) {
      rhs = pointAdd(rhs, scalarMul(xp, commitments[k]));
      xp = mod(xp * BigInt(i), N);
    }
    if (!pointEq(lhs, rhs)) throw new Error(`Feldman share verification failed for party ${i}`);

    shares.push({ id: i, secret, publicShare: lhs });
  }

  return {
    n,
    t,
    groupPublicKey: commitments[0],
    commitments,
    shares,
    dealerSecret: coeffs[0],
  };
}

// ---------------------------------------------------------------------------
// Lagrange coefficients at x = 0
// ---------------------------------------------------------------------------
function lagrangeCoeff(id, ids) {
  let num = 1n;
  let den = 1n;
  for (const j of ids) {
    if (j === id) continue;
    num = mod(num * BigInt(j), N);
    den = mod(den * BigInt(j - id), N);
  }
  return mod(num * modInv(den, N), N);
}

// ---------------------------------------------------------------------------
// Round 1: nonce generation + commitments
// ---------------------------------------------------------------------------
function commit(id) {
  const d = randomScalar();
  const e = randomScalar();
  return { id, d, e, D: scalarMul(d, G), E: scalarMul(e, G) };
}

// ---------------------------------------------------------------------------
// Binding factors and aggregate nonce
// ---------------------------------------------------------------------------
/**
 * Canonical encoding of the commitment list B. Must be identical for every
 * participant and for the aggregator, otherwise binding factors diverge.
 */
function encodeCommitmentList(commitList) {
  const sorted = [...commitList].sort((a, b) => a.id - b.id);
  const parts = [];
  for (const c of sorted) {
    parts.push(intToBytes32(BigInt(c.id)));
    parts.push(pointToBytes(c.D));
    parts.push(pointToBytes(c.E));
  }
  return Buffer.concat(parts);
}

/**
 * rho_i = H1(i, msg, B) mod N.
 * @param {boolean} useBinding if false, the binding factor is 1 (simulates a
 *   buggy implementation that omits the binding factor). Used by the tests.
 */
function bindingFactor(id, msg, commitList, useBinding = true) {
  if (!useBinding) return 1n;
  return hashToScalar('rho', intToBytes32(BigInt(id)), msg, encodeCommitmentList(commitList));
}

/**
 * R = sum_i (D_i + rho_i * E_i).
 * Returns null when the aggregate nonce is the identity element.
 */
function aggregateNonce(commitList, msg, useBinding = true) {
  let R = null;
  for (const c of commitList) {
    const rho = bindingFactor(c.id, msg, commitList, useBinding);
    R = pointAdd(R, pointAdd(c.D, scalarMul(rho, c.E)));
  }
  return R;
}

/**
 * Schnorr challenge c = H2(R, PK, msg) mod N.
 */
function challenge(R, publicKey, msg) {
  return hashToScalar('chal', pointToBytes(R), pointToBytes(publicKey), msg);
}

// ---------------------------------------------------------------------------
// Round 2: signature share
// ---------------------------------------------------------------------------
/**
 * z_i = d_i + rho_i * e_i + lambda_i * s_i * c
 */
function signShare(share, nonce, commitList, msg, publicKey, useBinding = true) {
  const R = aggregateNonce(commitList, msg, useBinding);
  if (R === null) {
    throw new Error('ABORT: aggregate nonce R is the identity element (known discrete log 0)');
  }
  const rho = bindingFactor(nonce.id, msg, commitList, useBinding);
  const c = challenge(R, publicKey, msg);
  const ids = commitList.map((x) => x.id);
  const lambda = lagrangeCoeff(share.id, ids);
  const z = mod(nonce.d + rho * nonce.e + lambda * share.secret * c, N);
  return { id: nonce.id, z };
}

// ---------------------------------------------------------------------------
// Aggregation
// ---------------------------------------------------------------------------
/**
 * Verify one signature share against the *recorded* commitment list.
 *
 * The check z_i*G == (D_i + rho_i*E_i) + c*lambda_i*PK_i is what rejects a
 * party whose published nonce commitment is inconsistent with the binding
 * factor it was aggregated under: D_i, E_i and rho_i are all re-derived from
 * the canonical list, never trusted from the share.
 */
function verifyShare(sigShare, commitList, msg, publicKey, publicShares, useBinding = true) {
  const c = commitList.find((x) => x.id === sigShare.id);
  if (!c) throw new Error(`no commitment published for party ${sigShare.id}`);

  const R = aggregateNonce(commitList, msg, useBinding);
  if (R === null) throw new Error('ABORT: aggregate nonce R is the identity element');

  const rho = bindingFactor(c.id, msg, commitList, useBinding);
  const Ri = pointAdd(c.D, scalarMul(rho, c.E));

  const ids = commitList.map((x) => x.id);
  const lambda = lagrangeCoeff(c.id, ids);
  const chal = challenge(R, publicKey, msg);

  const lhs = scalarMul(sigShare.z, G);
  const rhs = pointAdd(Ri, scalarMul(mod(chal * lambda, N), publicShares[c.id]));
  return pointEq(lhs, rhs);
}

/**
 * Aggregate signature shares into (R, z), verifying each share first.
 */
function aggregate(sigShares, commitList, msg, publicKey, publicShares, useBinding = true) {
  const R = aggregateNonce(commitList, msg, useBinding);
  if (R === null) {
    throw new Error('ABORT: aggregate nonce R is the identity element (known discrete log 0)');
  }

  let z = 0n;
  for (const s of sigShares) {
    if (!verifyShare(s, commitList, msg, publicKey, publicShares, useBinding)) {
      throw new Error(`REJECT: invalid signature share from party ${s.id}`);
    }
    z = mod(z + s.z, N);
  }
  return { R, z };
}

// ---------------------------------------------------------------------------
// Single-party Schnorr (reference / indistinguishability check)
// ---------------------------------------------------------------------------
function schnorrSign(secret, msg, nonceScalar) {
  const k = nonceScalar === undefined ? randomScalar() : nonceScalar;
  const R = scalarMul(k, G);
  const c = challenge(R, scalarMul(secret, G), msg);
  const z = mod(k + c * secret, N);
  return { R, z };
}

function verify(publicKey, msg, signature) {
  const { R, z } = signature;
  if (R === null) return false;
  const c = challenge(R, publicKey, msg);
  const lhs = scalarMul(z, G);
  const rhs = pointAdd(R, scalarMul(c, publicKey));
  return pointEq(lhs, rhs);
}

// ---------------------------------------------------------------------------
// Exports
// ---------------------------------------------------------------------------
module.exports = {
  // parameters
  P, N, G,
  // math / encoding
  mod, modPow, modInv, pointAdd, pointNeg, scalarMul, pointEq,
  intToBytes32, bytesToScalar, pointToBytes, pointFromBytes, randomScalar,
  // frost
  keygen, lagrangeCoeff, commit, bindingFactor, aggregateNonce, challenge,
  signShare, verifyShare, aggregate, encodeCommitmentList,
  // reference schnorr
  schnorrSign, verify,
};

// Canonical challenge for an identity aggregate nonce, used only to show why
// the abort is mandatory. (A real protocol must never reach this point.)
function identityChallenge(publicKey, msg) {
  const digest = require('crypto')
    .createHash('sha256')
    .update(Buffer.from('FROST-secp256k1-SHA256-v1', 'utf8'))
    .update(Buffer.from('chal', 'utf8'))
    .update(Buffer.from([0x00])) // canonical identity marker
    .update(F.pointToBytes(publicKey))
    .update(msg)
    .digest();
  return F.mod(F.bytesToScalar(digest), F.N);
}

// t-1 colluders set D_2 = -D_1 and E_2 = -E_1. Under a correct binding factor
// this does NOT cancel; under a coordinator that omits the binding factor it
// makes R = (D_1+E_1) + (D_2+E_2) = identity (known DL = 0).
function collusionFixture() {
  const n1 = F.commit(1);
  const n2 = {
    id: 2,
    d: F.mod(-n1.d, F.N),
    e: F.mod(-n1.e, F.N),
    D: F.pointNeg(n1.D),
    E: F.pointNeg(n1.E),
  };
  return {
    n1,
    n2,
    commitList: [
      { id: 1, D: n1.D, E: n1.E },
      { id: 2, D: n2.D, E: n2.E },
    ],
  };
}

check('without the guard, R = identity leaks the group secret', () => {
  // Demonstrate *why* the abort is mandatory. We bypass the guard and compute
  // the shares for the identity nonce. The resulting signature verifies, yet
  // anyone can recover x = z / c because z = c*x when R = identity.
  const msg = Buffer.from('leak', 'utf8');
  const g = F.keygen(2, 2);
  const ids = [1, 2];
  const { n1, n2, commitList } = collusionFixture();
  const c = identityChallenge(g.groupPublicKey, msg);

  let z = 0n;
  for (const id of ids) {
    const lam = F.lagrangeCoeff(id, ids);
    const nonce = id === 1 ? n1 : n2;
    // rho = 1 in the vulnerable coordinator; nonce parts cancel by construction.
    z = F.mod(z + nonce.d + nonce.e + lam * g.shares[id - 1].secret * c, F.N);
  }
  const recovered = F.mod(z * F.modInv(c, F.N), F.N);
  assert.strictEqual(recovered, g.dealerSecret);
  // z*G == c*PK, so the forged "signature" passes ordinary verification.
  assert.ok(F.pointEq(F.scalarMul(z, F.G), F.scalarMul(c, g.groupPublicKey)));
  // Sanity: the same nonce cancellation does not work with the binding factor.
  assert.notStrictEqual(F.aggregateNonce(commitList, msg, true), null);
});

  const msg = Buffer.from('binding-defense', 'utf8');
  const { commitList } = collusionFixture();
  const R = F.aggregateNonce(commitList, msg, true);
  assert.notStrictEqual(R, null);

Security notes / hardening for production

  • Reject identity or off-curve commitments at the wire boundary (pointFromBytes already validates curve membership; an identity encoding should be rejected before it enters B).
  • Use a real t-of-n DKG instead of the trusted-dealer Feldman variant if no single party may know the group secret.
  • Constant-time scalar arithmetic is not provided; this is a reference implementation for correctness verification, not a side-channel-hardened library.
  • The challenge H2(R, PK, m) uses compressed point encodings. For BIP-340 x-only compatibility, normalize R to even Y (negate nonces) and encode x-only; the algebraic FROST structure is unchanged.
