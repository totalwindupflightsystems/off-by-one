Answer

Root cause. In the tick that verifies gitreins records, the judge-skipped (doc-only) branch evaluated the grep-able criteria against HEAD, saw them pass, and then continued — skipping the status flip. tasks.yaml kept df-015 at status: pending, so the next tick had to rediscover and close it with gitreins task complete df-015. A judge-skipped record still needs its status flipped; gitreins task complete <id> is the correct closure mechanism and works fine for doc criteria.

The fix (/tmp/gitreins-fix/solution/close_leftover_doc_records.py): the same pass that verifies a judge-skipped record completes it — gitreins task complete <id>, flip status to done in tasks.yaml, then commit tasks.yaml as chore with standard trailers (Signed-off-by:, Verdict:).

def head_grep(pattern, path, workdir):
    # tier2 judge semantics: evaluate the committed tree, not the dirty tree
    proc = subprocess.run(["git", "grep", "-q", "-E", pattern, "HEAD", "--", path],
                          cwd=workdir, capture_output=True, text=True)
    return proc.returncode == 0         # 0=match, 1=no match, >1=error

def doc_criteria_pass(rec, workdir):
    criteria = rec.get("criteria") or []
    if not criteria:
        return False                     # no verifiable criteria → never auto-close
    for crit in criteria:                # accepts "str" or {"grep":..., "path":...}
        pattern = crit if isinstance(crit, str) else (crit.get("grep") or crit.get("pattern"))
        path = "." if isinstance(crit, str) else (crit.get("path") or ".")
        if not pattern or not head_grep(pattern, path, workdir):
            return False
    return True

Closure + chore commit:

def gitreins_complete(task_id, workdir):
    exe = shutil.which("gitreins")
    if exe is None:
        return False, ""                 # fallback: yaml-only closure still proceeds
    proc = subprocess.run([exe, "task", "complete", task_id],
                          cwd=workdir, capture_output=True, text=True)
    if proc.returncode not in (0, 2):    # 2 = already complete / no-op
        return False, ""
    verdict = next((l.split(":", 1)[1].strip() for l in (proc.stdout or "").splitlines()
                    if l.lower().startswith("verdict")), "")
    return True, verdict                 # captures judge verdict (2e0b2217-style)

def commit_tasks_chore(tasks_path, workdir, closed_ids, verdict):
    git add -- tasks.yaml
    git commit -m "chore(tasks): close judge-skipped doc record(s): df-015" \
      -m """Judge-skipped doc-only records were left pending after the
verifying tick. Close them now that grep-able doc criteria are satisfied at HEAD.

Signed-off-by: gitreins-tick <gitreins-tick@localhost>
Verdict: {verdict}"""

Run: python3 close_leftover_doc_records.py [--tasks tasks.yaml] [--dry-run] — exit 0 = closed+committed (or nothing to do), exit 1 = criteria unmet at HEAD.
