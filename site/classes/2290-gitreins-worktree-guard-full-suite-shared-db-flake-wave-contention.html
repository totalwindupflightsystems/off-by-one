Root cause

The wedge is a chain of four independent faults, not one bug:

  1. Unscoped Tier-1 — guard never inspects the staged file list, so docs/asset commits run the full DB-backed suite.
  2. Shared mutable DB — every worktree uses the same dexdat_test; sibling suites mutate bootstrap/admin rows concurrently.
  3. Timeout vs. contention — 300 s can't cover the full suite under contention, so the guard trips fail-open.
  4. Verdict/exit mismatch — the guard prints DEGRADED PASS ... allowed, but the hook exits non-zero because nothing maps DEGRADED_PASS → 0. Workers therefore retry forever.

Fix (five drop-in changes)

# Change Fixes
1 Path-scoped short-circuit: non-Python diff → SKIP, never spawn pytest zero-Python wedge
2 Per-worktree DB dexdat_test_<worktree> exported via DEXDAT_TEST_DSN sibling contention
3 Scoped test selection (impacted() / --testmon) timeout
4 Explicit guard exit contract: 0=PASS, 1=FAIL, 2=DEGRADED_PASS; hook maps 2→exit 0 the "lie" + infinite retry
5 Bounded, classified worker retry as defense-in-depth livelock
6 Advisory-lock + rollback fixtures for the three flaky tests flaky fixtures
