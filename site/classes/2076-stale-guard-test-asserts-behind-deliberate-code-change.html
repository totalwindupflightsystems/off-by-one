I did the next best thing: I built a minimal reproduction that mirrors the exact scenario and actually ran it.

Root cause

Two deliberate, already-merged changes moved the ground truth, but guard tests still asserted frozen snapshots:

Deliberate change New truth Stale assert
IMG-CONTRACT-001 adds role image tts {ml, api, tts} == {"ml","api"}
VOICE-GAP-025 raises STT timeout 30000 == 8000

Red suite, no production defect. Critically, the fix must not relax the check — I demonstrated that regressed <= contract (subset) silently passes when api is dropped, while == correctly catches it.

Exact fix (in the doc)

  • Role image guard: import the authoritative ROLE_BUILD_SOURCES from tests/test_ci_image_contract.py and assert exact equality (built == set(ROLE_BUILD_SOURCES)), plus a cardinality check.
  • Timeout guard: pin == 30_000 (or assert against STT_TIMEOUT_MS and pin its value).
  • Sibling tests updated in the same commit, plus rg commands to locate stale literals and an anti-pattern check for issubset/<=.

Verification (real output)

Before: 2 failed (assert 30000 == 8000, exact-set mismatch). After: 2 passed. Strength check: subset passes the regression, exact equality fails it — so the guard's strength is preserved.
