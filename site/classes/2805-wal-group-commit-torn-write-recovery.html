Crash-Safe WAL with Group Commit, CRC Frames, and Torn-Tail Recovery

Environment: Go 1.26, Linux. Module walgroup.

Problem statement

Implement a write-ahead log where:

  • concurrent writers batch their fsync calls (group commit),
  • every record carries a CRC,
  • the log survives a process kill at any byte offset (torn tail writes),
  • recovery scans frames, detects the first corrupt/short frame, truncates the log to the last fully durable transaction boundary, and reports which committed transactions survive,
  • duplicate LSNs produced by a replayed, partially-applied transaction are handled, and recovery is proven idempotent across repeated crash loops.

Root-cause analysis (why the naive WAL fails)

A straightforward "write bytes, fsync, read them back" log fails in five distinct ways under crash and concurrency pressure.

  1. A crash is not a whole-file event. write(2) and fsync(2) are not atomic with respect to power loss or SIGKILL. A record can be flushed partially: the header may be present while the payload is missing, a length field may be stale, or a page may be reordered. Without a per-record integrity check, recovery cannot distinguish a torn tail from valid data.

  2. No length + no checksum means no framing. If you read a record by trusting an on-disk length that was itself torn, you either allocate unbounded memory or lose byte alignment for every later record. Recovery must stop at the first frame whose checksum or length does not validate and must never trust bytes past it.

  3. No transaction boundary means replaying garbage. If recovery keeps every byte that happens to parse, it will replay the frames of an uncommitted transaction as if they were committed, corrupting application state. It must truncate back to the end of the last COMMIT frame — the last fully durable transaction boundary — and then fsync the truncation so the repair itself is durable.

  4. Per-writer fsync destroys throughput. fsync is the dominant cost. If every writer calls it independently, N concurrent transactions pay N fsyncs. Coalescing all outstanding durability requests into one fsync is the entire point of group commit.

  5. Crash loops are not idempotent. After a crash, a transaction may have been durably committed but only partially applied, or a replay may append records that reuse LSNs. Re-applying committed records must be a no-op. That requires de-duplicating by LSN and tracking an applied-LSN watermark, and requires that nextLSN is advanced only over the kept region.

Design of the fix

Frame format (32-byte header + payload)

offset  size  field
0       4     magic 0x57414C31 ("WAL1")
4       4     payload length N (LE uint32, N <= 1 MiB)
8       8     LSN (LE uint64)
16      8     txid (LE uint64)
24      1     type (BEGIN/DATA/COMMIT/ABORT/CHECKPOINT)
25      3     reserved, zero
28      4     CRC32C over header[0:28] || payload
32      N     payload

The CRC covers the header's own fields and the payload, so a corrupted length, LSN, txid or type is detected too. MaxPayload bounds the allocation a corrupt length can trigger.

Group commit

Writers append into a shared bufio.Writer under a mutex, then call Sync, which posts a request on a channel and waits. A single background committer receives the first request, drains every other queued request non-blocking, and performs exactly one Flush + fsync for the whole batch. This is correct because a writer's append happens-before its channel send, and the committer's flush happens-after the receive; the flush is serialized with appends by the same mutex, so the batch's fsync covers every member's data.

Shutdown is race-free: Sync holds a read lock on lifecycleMu for the whole send/wait, Close takes the write lock, sets closed, stops the committer and then issues a final fsync.

Recovery

Recovery reads from offset 0. For each frame it requires: a full 32-byte header, the magic, a length <= MaxPayload, a full payload, and a matching CRC. On the first failure it stops and records CorruptAt. ValidBytes is the end offset of the last COMMIT frame; Open truncates to ValidBytes and fsyncs. LastLSN is computed only over the kept region so new appends never collide with discarded bytes.

Because frames are append-only and serialized, the committed set of a prefix of the file is exactly the set of transactions whose COMMIT frame lies within that prefix. The exhaustive test below asserts this equality for every cut offset.

Duplicate LSNs and idempotent apply

RecoverResult.CommittedRecords() sorts committed records by LSN and drops duplicate LSNs. The Applier keeps an applied-LSN set, so applying the same committed region any number of times advances state at most once.

// Package walgroup implements a crash-safe, group-committing write-ahead log.
//
// Design goals:
//
//   - Append-only, self-describing frames. Every frame carries a length, an
//     LSN, a transaction id, a type and a CRC32C that covers the header and
//     the payload. A frame is only trusted after its CRC verifies.
//   - Group commit: concurrent writers that want durability register a sync
//     request. A single background committer coalesces all outstanding
//     requests and performs one fsync for the whole batch.
//   - Torn-tail safe: because frames are CRC protected and the file is
//     append-only, recovery scans from the front and stops at the first
//     short/corrupt frame. The file is truncated back to the last fully
//     durable transaction boundary (the end of the last commit frame).
//   - Idempotent recovery: repairing a log and recovering it again yields the
//     same committed set; re-applying committed records is a no-op thanks to
//     an applied-LSN watermark that tolerates duplicate LSNs.
package walgroup

import (
    "bufio"
    "encoding/binary"
    "errors"
    "fmt"
    "hash/crc32"
    "io"
    "os"
    "path/filepath"
    "sync"
    "sync/atomic"
    "time"
)

// On-disk constants.
const (
    // Magic marks the beginning of every frame. Not a valid CRC-protected
    // value on its own; the CRC is the real integrity check.
    Magic uint32 = 0x57414C31 // "WAL1"

    // HeaderSize is the size of a frame header in bytes.
    //
    //  offset size field
    //  0      4    magic
    //  4      4    payload length
    //  8      8    LSN
    //  16     8    transaction id
    //  24     1    record type
    //  25     3    reserved (zero)
    //  28     4    CRC32C over header[0:28] || payload
    HeaderSize = 32

    // MaxPayload bounds a single frame so a corrupt length can never trigger
    // an unbounded allocation during recovery.
    MaxPayload = 1 << 20
)

// RecordType classifies a frame.
type RecordType uint8

const (
    TypeBegin      RecordType = 1
    TypeData       RecordType = 2
    TypeCommit     RecordType = 3
    TypeAbort      RecordType = 4
    TypeCheckpoint RecordType = 5
)

func (t RecordType) String() string {
    switch t {
    case TypeBegin:
        return "BEGIN"
    case TypeData:
        return "DATA"
    case TypeCommit:
        return "COMMIT"
    case TypeAbort:
        return "ABORT"
    case TypeCheckpoint:
        return "CHECKPOINT"
    default:
        return fmt.Sprintf("TYPE(%d)", uint8(t))
    }
}

var (
    crcTable = crc32.MakeTable(crc32.Castagnoli)

    // ErrClosed is returned by operations on a closed WAL.
    ErrClosed = errors.New("walgroup: log is closed")
    // ErrPayloadTooLarge is returned when a payload exceeds MaxPayload.
    ErrPayloadTooLarge = errors.New("walgroup: payload too large")
    // ErrEmptyTxn is returned when a commit has no preceding begin/data.
    ErrEmptyTxn = errors.New("walgroup: transaction has no records")
)

// syncRequest is a single wait for durability.
type syncRequest struct {
    done chan error
}

// WAL is a crash-safe write-ahead log.
type WAL struct {
    path string

    // lifecycleMu guards closed and keeps Sync/Write from racing Close.
    lifecycleMu sync.RWMutex
    closed      bool

    // mu serialises access to the file and buffer.
    mu      sync.Mutex
    f       *os.File
    bw      *bufio.Writer
    nextLSN uint64

    // Group commit machinery.
    commitCh      chan *syncRequest
    stopCh        chan struct{}
    committerDone chan struct{}

    // Stats / testing hooks.
    fsyncs    atomic.Int64
    syncDelay atomic.Int64 // nanoseconds; encourages batching in tests
    syncHook  atomic.Value // func() error
}

// Open opens (creating if needed) the WAL at path, performs recovery and
// truncates any torn tail. The returned WAL is ready for appends.
func Open(path string) (*WAL, error) {
    f, err := os.OpenFile(path, os.O_RDWR|os.O_CREATE, 0o644)
    if err != nil {
        return nil, err
    }

    res, err := scan(f)
    if err != nil {
        f.Close()
        return nil, err
    }

    // Truncate away any uncommitted/torn tail so the on-disk prefix ends on a
    // transaction boundary.
    if err := f.Truncate(res.ValidBytes); err != nil {
        f.Close()
        return nil, err
    }
    if err := f.Sync(); err != nil {
        f.Close()
        return nil, err
    }
    if _, err := f.Seek(0, io.SeekEnd); err != nil {
        f.Close()
        return nil, err
    }

    w := &WAL{
        path:          path,
        f:             f,
        bw:            bufio.NewWriterSize(f, 1<<20),
        nextLSN:       res.LastLSN + 1,
        commitCh:      make(chan *syncRequest, 1024),
        stopCh:        make(chan struct{}),
        committerDone: make(chan struct{}),
    }
    go w.committer()

    // Make the directory entry itself durable so a crash cannot lose the file.
    syncDir(filepath.Dir(path))
    return w, nil
}

// Path returns the file path backing the log.
func (w *WAL) Path() string { return w.path }

// NextLSN returns the LSN that the next written frame will receive.
func (w *WAL) NextLSN() uint64 {
    w.mu.Lock()
    defer w.mu.Unlock()
    return w.nextLSN
}

// FsyncCount reports how many fsync calls have been issued. Used by tests to
// prove that batching actually happens.
func (w *WAL) FsyncCount() int64 { return w.fsyncs.Load() }

// SetSyncDelay makes the committer wait before flushing, which gives
// concurrent writers time to join a batch. It is a test hook.
func (w *WAL) SetSyncDelay(d time.Duration) { w.syncDelay.Store(int64(d)) }

// SetSyncHook replaces the fsync syscall with fn. It is a test hook.
func (w *WAL) SetSyncHook(fn func() error) { w.syncHook.Store(fn) }

// Append writes a frame with the next auto-assigned LSN and returns that LSN.
// It does not make the write durable; call Sync (or Commit) for that.
func (w *WAL) Append(txid uint64, typ RecordType, payload []byte) (uint64, error) {
    w.lifecycleMu.RLock()
    defer w.lifecycleMu.RUnlock()
    if w.closed {
        return 0, ErrClosed
    }
    w.mu.Lock()
    defer w.mu.Unlock()
    return w.appendLocked(txid, w.nextLSN, typ, payload)
}

// AppendAt writes a frame with an explicit LSN. It is intended for replay and
// for exercising duplicate-LSN handling; the WAL watermark is advanced past
// lsn so later auto-assigned LSNs never collide with it.
func (w *WAL) AppendAt(txid, lsn uint64, typ RecordType, payload []byte) error {
    w.lifecycleMu.RLock()
    defer w.lifecycleMu.RUnlock()
    if w.closed {
        return ErrClosed
    }
    w.mu.Lock()
    defer w.mu.Unlock()
    if _, err := w.appendLocked(txid, lsn, typ, payload); err != nil {
        return err
    }
    if lsn >= w.nextLSN {
        w.nextLSN = lsn + 1
    }
    return nil
}

// appendLocked encodes and buffers one frame. Callers must hold w.mu.
func (w *WAL) appendLocked(txid, lsn uint64, typ RecordType, payload []byte) (uint64, error) {
    if len(payload) > MaxPayload {
        return 0, ErrPayloadTooLarge
    }
    var hdr [HeaderSize]byte
    binary.LittleEndian.PutUint32(hdr[0:], Magic)
    binary.LittleEndian.PutUint32(hdr[4:], uint32(len(payload)))
    binary.LittleEndian.PutUint64(hdr[8:], lsn)
    binary.LittleEndian.PutUint64(hdr[16:], txid)
    hdr[24] = byte(typ)

    crc := crc32.Update(0, crcTable, hdr[:28])
    crc = crc32.Update(crc, crcTable, payload)
    binary.LittleEndian.PutUint32(hdr[28:], crc)

    if _, err := w.bw.Write(hdr[:]); err != nil {
        return 0, err
    }
    if len(payload) > 0 {
        if _, err := w.bw.Write(payload); err != nil {
            return 0, err
        }
    }
    w.nextLSN++
    return lsn, nil
}

// Commit appends a COMMIT marker for txid and fsyncs (via group commit). When
// it returns nil the transaction is durable.
func (w *WAL) Commit(txid uint64) (uint64, error) {
    lsn, err := w.Append(txid, TypeCommit, nil)
    if err != nil {
        return 0, err
    }
    if err := w.Sync(); err != nil {
        return 0, err
    }
    return lsn, nil
}

// Abort appends an ABORT marker. It is not required to be durable.
func (w *WAL) Abort(txid uint64) (uint64, error) {
    return w.Append(txid, TypeAbort, nil)
}

// Sync requests durability for everything written before the call. Concurrent
// requests are coalesced into a single fsync by the committer.
func (w *WAL) Sync() error {
    w.lifecycleMu.RLock()
    if w.closed {
        w.lifecycleMu.RUnlock()
        return ErrClosed
    }
    req := &syncRequest{done: make(chan error, 1)}
    w.commitCh <- req
    err := <-req.done
    w.lifecycleMu.RUnlock()
    return err
}

// committer services durability requests in batches.
func (w *WAL) committer() {
    defer close(w.committerDone)
    for {
        select {
        case req := <-w.commitCh:
            w.processBatch(req)
        case <-w.stopCh:
            // Service anything already queued, then exit.
            for {
                select {
                case req := <-w.commitCh:
                    w.processBatch(req)
                default:
                    return
                }
            }
        }
    }
}

// processBatch waits briefly for peers, drains all queued requests and issues
// a single flush+fsync for the batch.
func (w *WAL) processBatch(first *syncRequest) {
    batch := []*syncRequest{first}

    if d := w.syncDelay.Load(); d > 0 {
        time.Sleep(time.Duration(d))
    }
drain:
    for {
        select {
        case req := <-w.commitCh:
            batch = append(batch, req)
        default:
            break drain
        }
    }

    err := w.doFsync()
    for _, req := range batch {
        req.done <- err
    }
}

// doFsync flushes the user-space buffer and calls fsync exactly once.
func (w *WAL) doFsync() error {
    w.mu.Lock()
    defer w.mu.Unlock()

    if err := w.bw.Flush(); err != nil {
        return err
    }
    w.fsyncs.Add(1)
    if fn, ok := w.syncHook.Load().(func() error); ok && fn != nil {
        return fn()
    }
    return w.f.Sync()
}

// Close flushes, fsyncs and releases the log. It is safe to call once.
func (w *WAL) Close() error {
    w.lifecycleMu.Lock()
    if w.closed {
        w.lifecycleMu.Unlock()
        return nil
    }
    w.closed = true
    close(w.stopCh)
    w.lifecycleMu.Unlock()

    <-w.committerDone
    err := w.doFsync()
    if cerr := w.f.Close(); err == nil {
        err = cerr
    }
    return err
}

// syncDir fsyncs a directory so that a newly created file entry is durable.
func syncDir(dir string) {
    if dir == "" {
        dir = "."
    }
    d, err := os.Open(dir)
    if err != nil {
        return
    }
    _ = d.Sync()
    _ = d.Close()
}

package walgroup

import (
    "bufio"
    "encoding/binary"
    "errors"
    "hash/crc32"
    "io"
    "os"
    "sort"
)

// Record is a decoded, CRC-verified frame.
type Record struct {
    LSN      uint64
    TxID     uint64
    Type     RecordType
    Payload  []byte
    Offset   int64 // byte offset of the frame in the file
    FrameLen int   // total frame length (header + payload)
}

// RecoverResult summarises a recovery scan.
type RecoverResult struct {
    // Records contains every CRC-valid frame up to the first bad frame.
    Records []Record
    // Committed is the set of transaction ids that have a COMMIT frame in the
    // kept region.
    Committed map[uint64]bool
    // ValidBytes is the offset of the last fully durable transaction boundary
    // (end of the last commit frame). It is the safe truncation point.
    ValidBytes int64
    // LastLSN is the largest LSN in the kept region.
    LastLSN uint64
    // ScannedBytes is how many bytes were consumed before the scan stopped.
    ScannedBytes int64
    // CorruptAt is the offset of the first bad frame, or -1 if the file ended
    // cleanly on a frame boundary.
    CorruptAt int64
    // Truncated reports whether ValidBytes is smaller than ScannedBytes (i.e.
    // there is a tail that must be discarded).
    Truncated bool
}

// CommittedRecords returns the frames that belong to committed transactions,
// in LSN order, with duplicate LSNs removed. Duplicate LSNs can appear when a
// partially-applied transaction is replayed and re-appends frames that were
// already durably recorded.
func (r *RecoverResult) CommittedRecords() []Record {
    recs := make([]Record, 0, len(r.Records))
    for _, rec := range r.Records {
        if !r.Committed[rec.TxID] {
            continue
        }
        recs = append(recs, rec)
    }
    sort.SliceStable(recs, func(i, j int) bool { return recs[i].LSN < recs[j].LSN })

    seen := make(map[uint64]bool, len(recs))
    out := recs[:0]
    for _, rec := range recs {
        if seen[rec.LSN] {
            continue
        }
        seen[rec.LSN] = true
        out = append(out, rec)
    }
    return out
}

// TxIDs returns the committed transaction ids in ascending order.
func (r *RecoverResult) TxIDs() []uint64 {
    out := make([]uint64, 0, len(r.Committed))
    for id := range r.Committed {
        out = append(out, id)
    }
    sort.Slice(out, func(i, j int) bool { return out[i] < out[j] })
    return out
}

// Recover scans path without modifying it and returns the recovery result.
func Recover(path string) (*RecoverResult, error) {
    f, err := os.Open(path)
    if err != nil {
        return nil, err
    }
    defer f.Close()
    return scan(f)
}

// Repair recovers path and truncates it to the last fully durable transaction
// boundary. It returns the recovery result computed before truncation.
func Repair(path string) (*RecoverResult, error) {
    f, err := os.OpenFile(path, os.O_RDWR, 0o644)
    if err != nil {
        return nil, err
    }
    defer f.Close()

    res, err := scan(f)
    if err != nil {
        return nil, err
    }
    if res.ValidBytes != res.ScannedBytes {
        if err := f.Truncate(res.ValidBytes); err != nil {
            return nil, err
        }
        if err := f.Sync(); err != nil {
            return nil, err
        }
    }
    return res, nil
}

// scan walks a reader from the start and returns the recovery result. It never
// allocates more than MaxPayload for a single frame.
func scan(r io.Reader) (*RecoverResult, error) {
    br := bufio.NewReaderSize(r, 1<<20)
    res := &RecoverResult{Committed: map[uint64]bool{}, CorruptAt: -1}

    var off int64
    for {
        var hdr [HeaderSize]byte
        if _, err := io.ReadFull(br, hdr[:]); err != nil {
            if errors.Is(err, io.EOF) {
                // Clean end on a frame boundary.
                break
            }
            // io.ErrUnexpectedEOF: a partial header was written.
            res.CorruptAt = off
            res.ScannedBytes = off
            break
        }

        if binary.LittleEndian.Uint32(hdr[0:]) != Magic {
            // Garbage or zero padding: stop, the tail is not a valid frame.
            res.CorruptAt = off
            res.ScannedBytes = off
            break
        }

        length := binary.LittleEndian.Uint32(hdr[4:])
        if length > MaxPayload {
            res.CorruptAt = off
            res.ScannedBytes = off
            break
        }

        payload := make([]byte, length)
        if length > 0 {
            if _, err := io.ReadFull(br, payload); err != nil {
                res.CorruptAt = off
                res.ScannedBytes = off
                break
            }
        }

        want := binary.LittleEndian.Uint32(hdr[28:])
        got := crc32.Update(0, crcTable, hdr[:28])
        got = crc32.Update(got, crcTable, payload)
        if got != want {
            res.CorruptAt = off
            res.ScannedBytes = off
            break
        }

        rec := Record{
            LSN:      binary.LittleEndian.Uint64(hdr[8:]),
            TxID:     binary.LittleEndian.Uint64(hdr[16:]),
            Type:     RecordType(hdr[24]),
            Payload:  payload,
            Offset:   off,
            FrameLen: HeaderSize + int(length),
        }
        res.Records = append(res.Records, rec)
        if rec.Type == TypeCommit {
            res.Committed[rec.TxID] = true
            res.ValidBytes = off + int64(rec.FrameLen)
        }
        off += int64(rec.FrameLen)
        res.ScannedBytes = off
    }

    // LastLSN must only reflect the region we keep.
    for _, rec := range res.Records {
        if rec.Offset+int64(rec.FrameLen) <= res.ValidBytes && rec.LSN > res.LastLSN {
            res.LastLSN = rec.LSN
        }
    }
    res.Truncated = res.ValidBytes < res.ScannedBytes
    return res, nil
}

// CommitBoundaries returns the byte offsets of every commit frame end, in
// ascending order. Useful for exhaustive torn-write testing.
func (r *RecoverResult) CommitBoundaries() []int64 {
    var out []int64
    for _, rec := range r.Records {
        if rec.Type == TypeCommit {
            out = append(out, rec.Offset+int64(rec.FrameLen))
        }
    }
    sort.Slice(out, func(i, j int) bool { return out[i] < out[j] })
    return out
}

applier.go

package walgroup

import "sync"

// Applier applies committed records idempotently. It remembers every LSN it
// has applied, so replaying the same committed region (for example after a
// crash loop where the transaction was re-appended with duplicate LSNs) never
// applies a record twice.
type Applier struct {
    mu      sync.Mutex
    applied map[uint64]bool
    state   map[string][]byte
    ops     int64
}

// NewApplier creates an empty applier.
func NewApplier() *Applier {
    return &Applier{
        applied: make(map[uint64]bool),
        state:   make(map[string][]byte),
    }
}

// Apply applies every record that has not been applied yet and returns the
// number of records that actually advanced the state. Records must be sorted
// by LSN. Duplicate LSNs are ignored.
func (a *Applier) Apply(records []Record) int {
    a.mu.Lock()
    defer a.mu.Unlock()

    applied := 0
    for _, rec := range records {
        if a.applied[rec.LSN] {
            continue
        }
        a.applied[rec.LSN] = true
        a.ops++
        switch rec.Type {
        case TypeData, TypeBegin:
            // Payload is interpreted as "key=value"; replace the value.
            key, val := splitKV(rec.Payload)
            if key != "" {
                a.state[key] = []byte(val)
            }
        }
        applied++
    }
    return applied
}

// Get returns the current value for key.
func (a *Applier) Get(key string) ([]byte, bool) {
    a.mu.Lock()
    defer a.mu.Unlock()
    v, ok := a.state[key]
    return v, ok
}

// Snapshot returns a copy of the applied state.
func (a *Applier) Snapshot() map[string]string {
    a.mu.Lock()
    defer a.mu.Unlock()
    out := make(map[string]string, len(a.state))
    for k, v := range a.state {
        out[k] = string(v)
    }
    return out
}

// Ops returns the number of state mutations performed.
func (a *Applier) Ops() int64 {
    a.mu.Lock()
    defer a.mu.Unlock()
    return a.ops
}

func splitKV(b []byte) (string, string) {
    for i := 0; i < len(b); i++ {
        if b[i] == '=' {
            return string(b[:i]), string(b[i+1:])
        }
    }
    return string(b), ""
}

package walgroup

import (
    "fmt"
    "math/rand"
    "os"
    "os/exec"
    "path/filepath"
    "reflect"
    "sort"
    "sync"
    "testing"
    "time"
)

// TestMain lets the same test binary act as a crash victim when invoked by the
// SIGKILL test.
func TestMain(m *testing.M) {
    if os.Getenv("WAL_KILL_HELPER") == "1" {
        runKillHelper()
        return
    }
    os.Exit(m.Run())
}

// runKillHelper hammers commits until it is killed.
func runKillHelper() {
    path := os.Getenv("WAL_PATH")
    w, err := Open(path)
    if err != nil {
        os.Exit(2)
    }
    for i := 0; ; i++ {
        txid := uint64(i + 1)
        if _, err := w.Append(txid, TypeBegin, []byte("op=set")); err != nil {
            os.Exit(3)
        }
        if _, err := w.Append(txid, TypeData, []byte(fmt.Sprintf("k%d=v%d", txid, txid))); err != nil {
            os.Exit(3)
        }
        if _, err := w.Commit(txid); err != nil {
            os.Exit(3)
        }
    }
}

// buildCleanLog writes ntxn committed transactions and returns the raw bytes
// and the recovery result of the intact log.
func buildCleanLog(t *testing.T, path string, ntxn int) ([]byte, *RecoverResult) {
    t.Helper()
    w := mustOpen(t, path)
    for i := 0; i < ntxn; i++ {
        txid := uint64(i + 1)
        if _, err := w.Append(txid, TypeBegin, []byte("begin")); err != nil {
            t.Fatal(err)
        }
        if _, err := w.Append(txid, TypeData, []byte(fmt.Sprintf("k%d=v%d", txid, txid))); err != nil {
            t.Fatal(err)
        }
        if _, err := w.Commit(txid); err != nil {
            t.Fatal(err)
        }
    }
    if err := w.Close(); err != nil {
        t.Fatal(err)
    }
    b, err := os.ReadFile(path)
    if err != nil {
        t.Fatal(err)
    }
    res, err := Recover(path)
    if err != nil {
        t.Fatal(err)
    }
    return b, res
}

func sameIDSet(a map[uint64]bool, b []uint64) bool {
    set := make(map[uint64]bool, len(b))
    for _, id := range b {
        set[id] = true
    }
    return reflect.DeepEqual(a, set)
}

// txCommitEnds maps transaction id -> byte offset just past its commit frame.
func txCommitEnds(res *RecoverResult) map[uint64]int64 {
    m := map[uint64]int64{}
    for _, rec := range res.Records {
        if rec.Type == TypeCommit {
            m[rec.TxID] = rec.Offset + int64(rec.FrameLen)
        }
    }
    return m
}

// TestGroupCommitBatchesFsyncs proves that concurrent writers share fsyncs.
func TestGroupCommitBatchesFsyncs(t *testing.T) {
    dir := t.TempDir()
    path := filepath.Join(dir, "wal.log")
    w := mustOpen(t, path)
    defer w.Close()

    // Give the committer a window so all writers can join one batch.
    w.SetSyncDelay(100 * time.Millisecond)

    const N = 64
    before := w.FsyncCount()
    var start sync.WaitGroup
    start.Add(1)
    var wg sync.WaitGroup
    for i := 0; i < N; i++ {
        wg.Add(1)
        go func(i int) {
            defer wg.Done()
            txid := uint64(i + 1)
            start.Wait()
            if _, err := w.Append(txid, TypeBegin, []byte("b")); err != nil {
                t.Errorf("append: %v", err)
                return
            }
            if _, err := w.Append(txid, TypeData, []byte(fmt.Sprintf("k%d=v", txid))); err != nil {
                t.Errorf("append: %v", err)
                return
            }
            if _, err := w.Commit(txid); err != nil {
                t.Errorf("commit: %v", err)
            }
        }(i)
    }
    start.Done()
    wg.Wait()
    fsyncs := w.FsyncCount() - before
    t.Logf("group commit: %d concurrent transactions needed %d fsync(s)", N, fsyncs)
    if fsyncs < 1 {
        t.Fatalf("expected at least one fsync, got %d", fsyncs)
    }
    if fsyncs >= N {
        t.Fatalf("batching failed: %d fsyncs for %d commits", fsyncs, N)
    }

    // All transactions must be durable and recoverable.
    res, err := Recover(path)
    if err != nil {
        t.Fatal(err)
    }
    if len(res.Committed) != N {
        t.Fatalf("committed = %d, want %d", len(res.Committed), N)
    }
}

// TestTornWriteAtEveryOffset truncates the log at every possible byte offset
// and checks that recovery keeps exactly the transactions whose commit frame
// is fully present, that repair is stable, and that the log remains writable.
func TestTornWriteAtEveryOffset(t *testing.T) {
    dir := t.TempDir()
    src := filepath.Join(dir, "src.log")
    full, fullRes := buildCleanLog(t, src, 8)
    ends := txCommitEnds(fullRes)

    // Precompute expected committed set for each k.
    expected := func(k int) map[uint64]bool {
        set := map[uint64]bool{}
        for txid, end := range ends {
            if end <= int64(k) {
                set[txid] = true
            }
        }
        return set
    }

    for k := 0; k <= len(full); k++ {
        path := filepath.Join(dir, fmt.Sprintf("torn-%d.log", k))
        if err := os.WriteFile(path, full[:k], 0o644); err != nil {
            t.Fatal(err)
        }

        res, err := Recover(path)
        if err != nil {
            t.Fatalf("k=%d Recover: %v", k, err)
        }
        if !reflect.DeepEqual(res.Committed, expected(k)) {
            t.Fatalf("k=%d committed=%v want=%v (validBytes=%d corruptAt=%d)",
                k, res.Committed, expected(k), res.ValidBytes, res.CorruptAt)
        }
        if res.ValidBytes > int64(k) {
            t.Fatalf("k=%d validBytes %d exceeds file size", k, res.ValidBytes)
        }
        // Every surviving commit must have all its frames inside validBytes.
        for txid := range res.Committed {
            if ends[txid] > res.ValidBytes {
                t.Fatalf("k=%d committed tx %d beyond validBytes", k, txid)
            }
        }

        // Repair is idempotent.
        if _, err := Repair(path); err != nil {
            t.Fatalf("k=%d Repair: %v", k, err)
        }
        res2, err := Recover(path)
        if err != nil {
            t.Fatalf("k=%d Recover after repair: %v", k, err)
        }
        if !reflect.DeepEqual(res2.Committed, res.Committed) {
            t.Fatalf("k=%d repair changed committed set: %v -> %v", k, res.Committed, res2.Committed)
        }
        if res2.ValidBytes != res.ValidBytes {
            t.Fatalf("k=%d repair changed validBytes: %d -> %d", k, res.ValidBytes, res2.ValidBytes)
        }

        // The repaired log must still be usable and keep old commits.
        w := mustOpen(t, path)
        txid := uint64(9999)
        if _, err := w.Append(txid, TypeData, []byte("after-repair")); err != nil {
            t.Fatal(err)
        }
        if _, err := w.Commit(txid); err != nil {
            t.Fatal(err)
        }
        if err := w.Close(); err != nil {
            t.Fatal(err)
        }
        res3, err := Recover(path)
        if err != nil {
            t.Fatal(err)
        }
        if !res3.Committed[txid] {
            t.Fatalf("k=%d new commit lost", k)
        }
        for id := range res.Committed {
            if !res3.Committed[id] {
                t.Fatalf("k=%d repair+append lost committed tx %d", k, id)
            }
        }
    }
}

// TestSingleByteCorruption flips one byte at a time and verifies recovery
// stops at the corrupted frame and still truncates to a valid boundary.
func TestSingleByteCorruption(t *testing.T) {
    dir := t.TempDir()
    src := filepath.Join(dir, "src.log")
    full, fullRes := buildCleanLog(t, src, 5)
    ends := txCommitEnds(fullRes)

    for k := 0; k < len(full); k++ {
        path := filepath.Join(dir, fmt.Sprintf("corrupt-%d.log", k))
        b := append([]byte(nil), full...)
        b[k] ^= 0xFF
        if err := os.WriteFile(path, b, 0o644); err != nil {
            t.Fatal(err)
        }
        res, err := Recover(path)
        if err != nil {
            t.Fatalf("k=%d Recover: %v", k, err)
        }
        if res.ValidBytes > int64(k) {
            t.Fatalf("k=%d validBytes %d > corrupt offset", k, res.ValidBytes)
        }
        // Committed set must correspond to commit frames strictly before the
        // first bad frame.
        for txid, end := range ends {
            want := end <= res.ValidBytes
            if res.Committed[txid] != want {
                t.Fatalf("k=%d tx %d committed=%v want=%v", k, txid, res.Committed[txid], want)
            }
        }
    }
}

// TestDuplicateLSNIdempotentApply verifies recovery dedups duplicate LSNs and
// that applying the committed records repeatedly is a no-op.
func TestDuplicateLSNIdempotentApply(t *testing.T) {
    dir := t.TempDir()
    path := filepath.Join(dir, "dup.log")
    w := mustOpen(t, path)

    writeTx := func() {
        t.Helper()
        must := func(err error) {
            if err != nil {
                t.Fatal(err)
            }
        }
        must(w.AppendAt(1, 1, TypeBegin, []byte("k=replay")))
        must(w.AppendAt(1, 2, TypeData, []byte("k=v1")))
        must(w.AppendAt(1, 3, TypeCommit, nil))
    }
    // First application of tx 1.
    writeTx()
    if err := w.Sync(); err != nil {
        t.Fatal(err)
    }
    // Replay of the partially-applied transaction: identical LSNs.
    writeTx()
    if err := w.Sync(); err != nil {
        t.Fatal(err)
    }
    // A distinct later transaction.
    if _, err := w.Append(2, TypeBegin, []byte("j=x")); err != nil {
        t.Fatal(err)
    }
    if _, err := w.Append(2, TypeData, []byte("j=y")); err != nil {
        t.Fatal(err)
    }
    if _, err := w.Commit(2); err != nil {
        t.Fatal(err)
    }
    if err := w.Close(); err != nil {
        t.Fatal(err)
    }

    res, err := Recover(path)
    if err != nil {
        t.Fatal(err)
    }
    recs := res.CommittedRecords()
    // tx1 contributes 3 unique LSNs, tx2 contributes 3 unique LSNs.
    if len(recs) != 6 {
        t.Fatalf("CommittedRecords len = %d, want 6: %+v", len(recs), recs)
    }

    a := NewApplier()
    first := a.Apply(recs)
    if first != 6 {
        t.Fatalf("first apply = %d, want 6", first)
    }
    // Recover + apply again: must change nothing.
    res2, err := Recover(path)
    if err != nil {
        t.Fatal(err)
    }
    second := a.Apply(res2.CommittedRecords())
    if second != 0 {
        t.Fatalf("replay applied %d records, want 0 (not idempotent)", second)
    }
    v, _ := a.Get("k")
    if string(v) != "v1" {
        t.Fatalf("state k = %q, want v1", v)
    }
}

// TestRepeatedCrashLoop is an explicit idempotency check: repair the same torn
// image many times and confirm the result never drifts.
func TestRepeatedCrashLoop(t *testing.T) {
    dir := t.TempDir()
    src := filepath.Join(dir, "src.log")
    full, _ := buildCleanLog(t, src, 6)
    path := filepath.Join(dir, "loop.log")

    // Start from an arbitrary torn point.
    cut := len(full) * 2 / 3
    if err := os.WriteFile(path, full[:cut], 0o644); err != nil {
        t.Fatal(err)
    }

    res, err := Recover(path)
    if err != nil {
        t.Fatal(err)
    }
    first := res.TxIDs()
    firstValid := res.ValidBytes

    for i := 0; i < 20; i++ {
        if _, err := Repair(path); err != nil {
            t.Fatal(err)
        }
        res, err = Recover(path)
        if err != nil {
            t.Fatal(err)
        }
        if !reflect.DeepEqual(res.TxIDs(), first) {
            t.Fatalf("iteration %d committed set drifted: %v -> %v", i, first, res.TxIDs())
        }
        if res.ValidBytes != firstValid {
            t.Fatalf("iteration %d validBytes drifted: %d -> %d", i, firstValid, res.ValidBytes)
        }
    }
}

// TestProcessKillMidCommit repeatedly SIGKILLs a child that is committing, then
// verifies the surviving log is uncorrupted and a contiguous committed prefix.
func TestProcessKillMidCommit(t *testing.T) {
    if testing.Short() {
        t.Skip("short mode")
    }
    dir := t.TempDir()
    rng := rand.New(rand.NewSource(1))

    for iter := 0; iter < 30; iter++ {
        path := filepath.Join(dir, fmt.Sprintf("kill-%d.log", iter))
        _ = os.Remove(path)

        cmd := exec.Command(os.Args[0])
        cmd.Env = append(os.Environ(),
            "WAL_KILL_HELPER=1",
            "WAL_PATH="+path,
        )
        if err := cmd.Start(); err != nil {
            t.Fatalf("start helper: %v", err)
        }
        time.Sleep(time.Duration(2+rng.Intn(25)) * time.Millisecond)
        _ = cmd.Process.Kill()
        _ = cmd.Wait()

        // Under -race the child may be killed before it creates the file; that
        // is a legitimate "crash before any commit" and yields an empty set.
        if _, statErr := os.Stat(path); os.IsNotExist(statErr) {
            continue
        }

        res, err := Recover(path)
        if err != nil {
            t.Fatalf("iter %d Recover: %v", iter, err)
        }
        // Committed txids must be a contiguous prefix 1..M.
        ids := res.TxIDs()
        for i, id := range ids {
            if id != uint64(i+1) {
                t.Fatalf("iter %d committed set not a prefix: %v", iter, ids)
            }
        }
        // Repair then reopen and continue appending.
        if _, err := Repair(path); err != nil {
            t.Fatalf("iter %d Repair: %v", iter, err)
        }
        w, err := Open(path)
        if err != nil {
            t.Fatalf("iter %d Open: %v", iter, err)
        }
        next := uint64(len(ids) + 1)
        if _, err := w.Append(next, TypeData, []byte("x=y")); err != nil {
            t.Fatal(err)
        }
        if _, err := w.Commit(next); err != nil {
            t.Fatal(err)
        }
        if err := w.Close(); err != nil {
            t.Fatal(err)
        }
        res2, err := Recover(path)
        if err != nil {
            t.Fatal(err)
        }
        got := res2.TxIDs()
        sort.Slice(got, func(i, j int) bool { return got[i] < got[j] })
        if len(got) != len(ids)+1 || got[len(got)-1] != next {
            t.Fatalf("iter %d after append got %v, want prefix + %d", iter, got, next)
        }
    }
}

Key invariants checked directly

  • Torn tail: a partial header (io.ErrUnexpectedEOF) and a partial payload both surface as CorruptAt at the frame offset; nothing after it is trusted.
  • Durable boundary: ValidBytes is always the end of a COMMIT frame, so recovery never reports an uncommitted transaction as surviving.
  • No LSN reuse across repairs: Open sets nextLSN = LastLSN(kept) + 1.
  • Group-commit correctness: every Sync returns only after the batch fsync that covers its writer's append.

Notes / trade-offs

  • Recovery stops at the first bad frame rather than scanning past it. This is the safe WAL semantic: a later valid frame beyond a gap cannot be trusted because the bytes in between are unknown. For true torn tails (data written before a successful fsync) this never loses a committed transaction, because fsync would have persisted the whole prefix.
  • CRC32C is used; cryptographic hashes are unnecessary for accidental corruption and would cost throughput.
  • The directory is fsynced on Open so a newly created log file survives a crash immediately after creation.
  • MaxPayload (1 MiB) caps what a corrupt length field can allocate.
