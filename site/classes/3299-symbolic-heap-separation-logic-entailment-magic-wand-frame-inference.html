Symbolic-Heap Separation-Logic Entailment with Magic-Wand Frame Inference

Deliverable: a self-contained Python 3.12 module ~/sl/sheap.py that decides symbolic-heap entailment (emp, x |-> (t…), *, pure =/!=, exists, and -*), performs frame inference, and emits either a witness substitution + frame + proof sketch or a concrete counterexample heap. It uses a union-find congruence closure (no unfolding), one-sided matching, an exact/frame split for sound wand reasoning, and a bounded brute-force oracle for verification. Full write-up: ~/sl/SOLUTION.md. Verification log: ~/sl/VERIFY.log.

Root-cause analysis

The task ("decide A |- B for symbolic heaps with *, points-to and -*, and do frame inference") breaks five naıve implementations. Each is fixed explicitly.

1. Cyclic pure constraints loop under unfolding — the named hazard

Substitution/rewriting solvers loop on x=y ∧ y=z ∧ z=x and blow up on occurs loops. Fix: a union-find congruence closure (Store) with path compression and constant propagation at the root. Equality is decided by canonical representatives; no term is ever rewritten, so cycles terminate immediately. x=y ∧ y=z ∧ z=x ∧ x≠y is found inconsistent ⇒ vacuous entailment, in O(1) per step.

2. Free variables are rigid; only existentials are witnesses

Unifying arbitrary variables proves false entailments (x|->a |- y|->a must fail, since x,y are universally quantified). Fix: one-sided matching (Match) where a flex set contains only right-hand existential variables; rigid representatives must be syntactically identical after congruence closure; an occurs check prevents cyclic bindings.

3. * implies disjoint domains

Distinct cell sources denote distinct locations, and a cell source is never nil. Ignoring this loses valid entailments (x|->nil * y|->x |- x≠y, x|->a |- x≠nil). Fix: add_spatial_neqs injects s≠nil and pairwise sᵢ≠sⱼ; heap_consistent treats duplicate sources / nil sources as an inconsistent (vacuously entailing) antecedent. This was found by differential testing — see V2.

4. Magic-wand currying must split the context

A |- B' * (C -* D) ⇔ A*C |- B'*D is unsound. Counterexample: x|->a |- x|->a * (x|->a -* emp) is false, yet the curried sequent x|->a * x|->a |- x|->a * emp is vacuously true. Fix: the prover distinguishes exact entailment (every antecedent cell consumed) from frame entailment (leftovers allowed). A right wand consumes a chosen subset S as its base and requires the exact sequent S*C |-_E D (_wand_base); the rest serves the other right-hand atoms or the frame.

5. Left-wand elimination must consume its argument

(C-*D)*M |- D needs M |-_E C exactly and consumes M. Keeping M re-introduces contradictory cells. Fix: _elim_wand does an exact sub-search and replaces the consumed atoms by the consequent D. Frame inference is made explicit (frame_infer) rather than conflated with exact entailment.

The exact fix (core code)

The full, tested implementation is ~/sl/sheap.py. The three load-bearing pieces are below.

Union-find + one-sided matcher (fixes root causes 1–3):

class Store:
    __slots__ = ("parent", "rank", "cval", "neq", "_neqset")
    def rep(self, t):
        if isinstance(t, Const): return t
        r = self._find(t); return self.cval.get(r, r)
    def union(self, a, b):
        ra, rb = self.rep(a), self.rep(b)
        if isinstance(ra, Const) and isinstance(rb, Const): return ra == rb
        if isinstance(ra, Const): self.cval[self._find(rb)] = ra; return True
        if isinstance(rb, Const): self.cval[self._find(ra)] = rb; return True
        if ra == rb: return True
        if self.rank[ra] < self.rank[rb]: ra, rb = rb, ra
        self.parent[rb] = ra
        if self.rank[ra] == self.rank[rb]: self.rank[ra] += 1
        if rb in self.cval:
            ca = self.cval.pop(rb)
            if ra in self.cval: return self.cval[ra] == ca
            self.cval[ra] = ca
        return True
    def add_neq(self, a, b):
        if self.equal(a, b): return False
        key = (a, b) if str(a) <= str(b) else (b, a)
        if key not in self._neqset:
            self._neqset.add(key); self.neq.append((a, b))
        return True

class Match:                       # only `flex` (RHS existential) vars instantiable
    def resolve(self, t):
        while isinstance(t, str) and t in self.sub: t = self.sub[t]
        return self.store.rep(t)
    def match(self, pattern, target):
        rp, rt = self.resolve(pattern), self.resolve(target)
        if isinstance(rp, Const): return rp == rt
        if isinstance(rp, str) and rp in self.flex: return self.bind(rp, rt)
        return rp == rt              # rigid variable: must be identical

def add_spatial_neqs(store, pts):    # disjoint domains + allocated != nil
    reps = [store.rep(lhs) for lhs, _ in pts]
    for r in reps:
        if r == NIL: return False
        store.add_neq(r, NIL)
    for i in range(len(reps)):
        for j in range(i + 1, len(reps)):
            if reps[i] == reps[j]: return False
            store.add_neq(reps[i], reps[j])
    return True

Proof search with the exact/frame split (fixes root causes 4–5):

def _search(self, A, B_pts, B_wands, B_pure, m, used, depth, exact):
    if not m.store.consistent() or not heap_consistent(m.store, A.pts):
        return (m.clone(), [], used)              # inconsistent antecedent == vacuous
    add_spatial_neqs(m.store, A.pts)

    if B_pts:                                     # right points-to
        if not right_heap_consistent(m, B_pts): return None
        r = B_pts[0]
        for i, a_pt in enumerate(A.pts):
            if i in used: continue
            m2 = m.clone()
            if self._match_atom(m2, a_pt, r):
                sol = self._search(A, B_pts[1:], B_wands, B_pure, m2, used | {i}, depth+1, exact)
                if sol is not None: return sol
        for wi in range(len(A.wands)):             # modus ponens
            sol = self._elim_wand(A, B_pts, B_wands, B_pure, m, used, wi, depth, exact)
            if sol is not None: return sol
        return None

    if B_wands:                                   # right wand: split the context
        c, d = B_wands[0]; rest = B_wands[1:]
        avail = [i for i in range(len(A.pts)) if i not in used]
        if len(avail) > 14: return None
        candidates = [tuple(avail)] if exact else _all_subsets(avail)
        for S in candidates:
            m2 = self._wand_base(A, S, c, d, m, depth)   # exact: S*C |-_E D
            if m2 is None: continue
            sol = self._search(A, B_pts, rest, B_pure, m2, used | set(S), depth+1, exact)
            if sol is not None: return sol
        return None

    m2 = m.clone()                                # discharge pure goals
    if not entails_pure(m2, B_pure): return None
    if exact and len(used) != len(A.pts): return None
    frame = [A.pts[i] for i in range(len(A.pts)) if i not in used]
    return (m2, frame, used)

Known boundary. Magic-wand entailment is only decidable on fragments. The procedure is sound and complete on the wand-free fragment (verified), and sound but deliberately conservative with wands; incomplete cases are antecedents whose wand is unsatisfiable, deferred to the model finder when the instance is small.
