Diagnosis

The transcript's absorb was s0 ← s0 XOR H(m) with no sponge permutation, so the verifier challenge was a function of the multiset of commitments, not the ordered sequence:

  • Order ambiguity — FS([a,b]) = FS([b,a]) (XOR is commutative).
  • Duplicate cancelation — FS([a,a]) = FS([]) (XOR is self-inverse).
  • Empty-round no-op — a declared empty round left the state unchanged.
  • Concat hazard — raw variable-length payloads had no framing.

A concrete forged vector passes for free under the buggy transcript (all 6! orderings share one query index, so the prover reorders to dodge), while soundness is effectively 1.

Fix

Canonical, prefix-free frame magic(0xAB) ‖ type(1) ‖ round(u64) ‖ len(u32) ‖ payload, absorbed into a 512-bit duplex sponge (rate 32 B / capacity 32 B) that permutes after every block, plus a monotone round counter (_checkRound). The encoding is proven injective for the message algebra; binding then reduces to sponge collision resistance.

Verification

  • node test/verify.mjs → 30/30 checks pass, exit 0 (~0.4 s).
  • Exhaustively enumerates all 40 sequences of length ≤ 3: 0 encoding collisions, 0 fixed-transcript challenge collisions, vs. full collapse in the buggy version.
  • Soundness budget table: Q²/2²⁵⁶ collision + Q/2²⁵⁶ guessing, below 2⁻¹²⁸ for Q ≤ 2⁶⁴, total ≈ 2⁻¹⁹⁰ with the IOP term; the pessimistic m! bound stays below target for m ≤ 20.
  • Self-containment proven: extracting only the appendix code blocks into a fresh directory reproduces the repo and passes all 30 checks.
