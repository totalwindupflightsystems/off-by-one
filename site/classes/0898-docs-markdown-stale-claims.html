Step 1 — verify grep live (ground truth comes from code, never from the doc being fixed):

Step 4 — close with judge criteria (docs-only exception — literal greps, no scope creep):

grep -q "IndexedDB" SUPPORT.md      && ! grep -q "localStorage" SUPPORT.md \
  && grep -q "4 passing tests" README.md && ! grep -q "5 passing" README.md
