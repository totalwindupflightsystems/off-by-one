Exact 2-D EHVI Selection — Diagnosis and Verified Fix

Problem class: multiobjective-ehvi-hypervolume-selection · Env: Python 3.11+ (verified 3.14), NumPy only.

Root-cause analysis

  1. Front orientation / domination direction (the actual bug hit). For a maximization front sorted by x1 ascending, x2 must descend. The naive filter sort x ascending; keep if y > best_y keeps only the top-left point. On [(1,5),(2.5,3.5),(4,2)] it yields HV=5 instead of 13.25. Correct sweep is from the right (x descending) keeping points that raise x2.
  2. Missing terminal slab / empty front. The non-dominated region continues to the right of the last front point down to ref2; omitting it underestimates EHVI. Empty front must return the full quadrant integral.
  3. Naive Monte Carlo. Cannot reach 1e-6 relative error without ~1e10 samples; the spec demands analytic normal-CDF slices.
  4. A lying verifier (second bug hit). Tensor Gauss–Hermite of ∫∫ I(y)φφ converges slowly because I(y) is only piecewise bilinear (kinks at every front coordinate). It reported 1e-3…1e-2 error even when the closed form was exact. Fix: align quadrature partitions to all front/reference breakpoints and use Gauss–Legendre per cell.
  5. Tail cancellation. σ(φ(z) − z·S(z)) cancels for large z; use erfc and an asymptotic series above z=6.
  6. Batch bugs. Computing all k scores once is not sequential greedy — recompute against P ∪ {μ_pick} after each pick. Region exclusion must happen during selection, not as a post-filter.

Exact fix

Math: E[I(Y)] = ∫∫_N P(Y1≥x1)P(Y2≥x2) dx1 dx2. With the front sorted by x1 ascending, N splits into slabs that factorize:

EHVI = Σ_{i=1..n} A(p_{i-1,1}, p_{i,1}) · B(p_{i,2})  +  A(p_{n,1}, ∞) · B(ref2)
A(l,u) = F(u) − F(l),  F(x) = (x−μ)S((x−μ)/σ) − σφ((x−μ)/σ)
B(a)   = σ(φ(z) − z·S(z)),  z=(a−μ)/σ,  S=1−Φ,  p_{0,1}=ref1

from __future__ import annotations
import math
from typing import Hashable, Iterable, Sequence

_SQRT2 = math.sqrt(2.0)
_INV_SQRT_2PI = 1.0 / math.sqrt(2.0 * math.pi)

def norm_pdf(z): return _INV_SQRT_2PI * math.exp(-0.5 * z * z)
def norm_cdf(z): return 0.5 * math.erfc(-z / _SQRT2)
def norm_sf(z):  return 0.5 * math.erfc(z / _SQRT2)      # stable both tails

def _tail_integral(z, sigma):
    """sigma * ∫_z^inf (1-Phi(t)) dt = sigma*(phi(z) - z*S(z))."""
    if z > 6.0:                                          # avoid cancellation
        zz = z * z
        series = (1.0 - 3.0/zz + 15.0/(zz*zz) - 105.0/(zz**3)) / zz
        return sigma * norm_pdf(z) * series
    return sigma * (norm_pdf(z) - z * norm_sf(z))

def _survival_integral(l, u, mu, sigma):
    """∫_l^u (1 - Phi((x-mu)/sigma)) dx; u may be +inf."""
    zl = (l - mu) / sigma
    fl = (l - mu) * norm_sf(zl) - sigma * norm_pdf(zl)
    if math.isinf(u):
        return -fl
    zu = (u - mu) / sigma
    fu = (u - mu) * norm_sf(zu) - sigma * norm_pdf(zu)
    return fu - fl

def nondominated_2d(points):
    """Non-dominated subset, maximization. Sweep x DESCENDING keeping y records."""
    pts = [(float(p[0]), float(p[1])) for p in points]
    pts.sort(key=lambda p: (-p[0], -p[1]))
    nd, best_y = [], -math.inf
    for x, y in pts:
        if y > best_y:
            nd.append((x, y)); best_y = y
    nd.sort(key=lambda p: p[0])
    return nd

def _clean_front(front, ref):
    pts = [(float(p[0]), float(p[1])) for p in front
           if p[0] > ref[0] and p[1] > ref[1]]
    return nondominated_2d(pts) if pts else []

def hypervolume_2d(front, ref):
    nd = _clean_front(front, ref)
    area, prev_x = 0.0, ref[0]
    for x, y in nd:
        area += (x - prev_x) * (y - ref[1]); prev_x = x
    return area

def ehvi_2d_exact(mu, sigma, front, ref):
    mu1, mu2 = float(mu[0]), float(mu[1])
    s1, s2 = float(sigma[0]), float(sigma[1])
    if s1 <= 0 or s2 <= 0: raise ValueError("sigma must be positive")
    ref1, ref2 = float(ref[0]), float(ref[1])
    nd = _clean_front(front, ref)
    if not nd:                                # empty front: full quadrant
        return _survival_integral(ref1, math.inf, mu1, s1) * \
               _tail_integral((ref2 - mu2)/s2, s2)
    total, prev_x = 0.0, ref1
    for x, y in nd:
        total += _survival_integral(prev_x, x, mu1, s1) * _tail_integral((y-mu2)/s2, s2)
        prev_x = x
    total += _survival_integral(prev_x, math.inf, mu1, s1) * \
             _tail_integral((ref2 - mu2)/s2, s2)   # terminal slab
    return total

class Candidate:
    __slots__ = ("mu", "sigma", "region", "index")
    def __init__(self, mu, sigma, region: Hashable, index=None):
        self.mu = (float(mu[0]), float(mu[1]))
        self.sigma = (float(sigma[0]), float(sigma[1]))
        self.region, self.index = region, index

def greedy_batch_ehvi(candidates, k, ref, front=(), return_values=False):
    current, used_regions, used_indices = list(front), set(), set()
    picks, scores = [], []
    for _ in range(k):
        best, best_val = None, -math.inf
        for c in candidates:
            if c.index in used_indices or c.region in used_regions:
                continue
            v = ehvi_2d_exact(c.mu, c.sigma, current, ref)
            if v > best_val: best_val, best = v, c
        if best is None: break
        picks.append(best); scores.append(best_val)
        if best.index is not None: used_indices.add(best.index)
        used_regions.add(best.region)
        current = [p for p in nondominated_2d(list(current)+[best.mu])
                   if p[0] > ref[0] and p[1] > ref[1]]
    return (picks, scores) if return_values else picks
