Reconstructing Committed State from Three Compacted Raft Replicas

Problem class: replicated-log-snapshot-reconcile-20261009 · Go 1.26 Artifact: ~/raftreconcile (module example.com/raftreconcile), full write-up also in ~/raftreconcile/SOLUTION.md.

The reconciler is a deterministic, order-insensitive function of the evidence set. It reconstructs the unique committed prefix and reports irreconcilable histories with stable conflict codes.

1. Root-cause analysis

The four ways this is usually got wrong:

  1. "Take the longest log." The longest log can end in uncommitted entries from a deposed leader. Length is not a commitment proof.
  2. "Take the highest-term log." A follower can carry a high term while missing committed entries present on a majority.
  3. "Trust a snapshot as the state." Overlapping snapshots can come from different branches. A snapshot is only authoritative if it is anchored to the committed prefix (Raft compacts only applied entries), and overlapping snapshot/entry evidence at the same index must agree on term and state hash.
  4. "Apply in arrival order / use a fixed quorum." Under arbitrary reordering the answer must be a pure function of the evidence set, and the quorum certifying an entry is the configuration active at that index, not a fixed global majority.

What makes the state unique. With n = 3, every two majorities (size 2) intersect, so two different values cannot both be quorum-supported at one index. Log Matching + State Machine Safety then force quorum-supported indices to form a contiguous prefix 1..C, and that prefix is exactly the set of entries no future leader can lack.

2. Model and invariants

A replica reports (id, current_term, snapshot, entries, commit_index); snapshot.last_index is compacted/committed, entries is the suffix after it, and each entry may carry a post-apply state_hash. Config entries carry {"voters":[...]} or {"joint":{"old":[...],"new":[...]}}.

Replica commit_index ≤ last log index E_COMMIT_OUT_OF_RANGE
Replica commit_index ≥ snapshot.last_index E_COMMIT_BELOW_SNAPSHOT
Replica entry term ≤ current_term E_TERM_EXCEEDS_CURRENT

3. Algorithm

RECONCILE(replicas):
  sort replicas by id; sort each replica's entries by index      # reordering safety
  validate local invariants
  byIndex[i] = explicit (replica, entry) claims

  check pairwise Log Matching
  record state hashes; flag index disagreements
  flag any index where two values each reach a majority

  anchor = max(snapshot.last_index)                              # committed evidence
  anchorHash = unique state hash at anchor
  cfg = config at anchor (snapshot config, else quorum configs <= anchor; default all ids)

  C = anchor
  for i = anchor+1 ...:
      e, ok, multi = QUORUM(byIndex[i], cfg)
      if multi: report E_DOUBLE_MAJORITY; break
      if not ok: break                                           # first non-contiguous index
      committed[i] = e; C = i
      if e.kind == config:
          cfg, err = TRANSITION(cfg, parse(e.data))              # simple -> joint -> simple
          if err: report E_ILLEGAL_CONFIG_TRANSITION

  for each replica r:
      if r.commit_index > C: report E_UNSUPPORTED_COMMIT
      for i in (anchor, r.commit_index]:
          if r has entry i != committed[i]: report E_COMMIT_CONFLICT
  for each snapshot s:
      if quorum term at s.last_index != s.last_term: report E_SNAPSHOT_TERM_CONFLICT

  sort + dedupe conflicts; status = CONFLICT if any else OK
  return {status, anchor, C, state_hash, config, suffix, conflicts}

QUORUM counts each distinct (term,kind,data) per voter set of cfg; a value wins if it has a majority in every set (both sides of a joint config). The scan can stop at the first gap because above the anchor, quorum at i+1 implies quorum at i by contiguity.

4. Complexity bounds

Phase Time Space
Normalise / validate O(N log N) O(N)
Index table O(N) O(N)
Pairwise Log Matching (R=3) O(N log N) O(N)
Quorum sweep O(N log N) O(N)
Conflict sort/dedupe O(K log K) O(K)

Total O(N log N) time, O(N) space for fixed R; general O(R²N log N) / O(RN+K). All iteration over sets/maps is sorted, so the output is a pure deterministic function of the evidence set.

Correctness sketch. Safety: every emitted entry has a quorum in the active config; any future committed log intersects that quorum and must agree by Log Matching, so emitted entries are never overwritten. Completeness: a committed entry's replication set is a majority, so the observed quorum finds it, or a conflict is reported rather than silent loss. Determinism: replicas sorted by id, entries by index, map keys before use, conflicts by (code,index,replica,detail) and deduped.

func Reconcile(in Input) Report {
    reps := make([]Replica, len(in.Replicas))
    copy(reps, in.Replicas)
    var conflicts []Conflict
    add := func(c Conflict) { conflicts = append(conflicts, c) }
    if len(reps) == 0 {
        return Report{Status: StatusConflict, Log: []Entry{}, Conflicts: []Conflict{{
            Code: "E_NO_REPLICAS", Detail: "no replicas provided"}}}
    }

    // Canonicalise replica and entry order -> reordering safety.
    sort.SliceStable(reps, func(i, j int) bool { return reps[i].ID < reps[j].ID })
    for i := range reps {
        sort.SliceStable(reps[i].Entries, func(a, b int) bool {
            return reps[i].Entries[a].Index < reps[i].Entries[b].Index })
    }
    for _, r := range reps { conflicts = append(conflicts, validateReplica(r)...) }

    byIndex := map[uint64][]repEntry{}
    for _, r := range reps {
        for _, e := range r.Entries { byIndex[e.Index] = append(byIndex[e.Index], repEntry{r.ID, e}) }
    }
    baseVoters := voterSet{}
    for _, r := range reps { baseVoters[r.ID] = true }
    baseCfg := config{old: cloneSet(baseVoters)}

    conflicts = append(conflicts, checkLogMatching(reps)...)

    hashAt := map[uint64]string{}
    for _, r := range reps {
        record := func(idx uint64, h string) {
            if h == "" { return }
            if old, ok := hashAt[idx]; ok && old != h {
                add(Conflict{Code: "E_STATE_HASH_CONFLICT", Index: idx, Replica: r.ID,
                    Detail: fmt.Sprintf("state hash %q conflicts with %q", h, old)})
                return
            }
            hashAt[idx] = h
        }
        if r.Snapshot != nil { record(r.Snapshot.LastIndex, r.Snapshot.StateHash) }
        for _, e := range r.Entries { record(e.Index, e.StateHash) }
    }

    anchor := uint64(0)
    for _, r := range reps { if r.snapLast() > anchor { anchor = r.snapLast() } }
    anchorHash := hashAt[anchor]

    cfg := cloneConfig(baseCfg)
    if anchor > 0 {
        chosen := ""
        for _, r := range reps {
            if r.Snapshot != nil && r.Snapshot.Config != "" && r.Snapshot.LastIndex == anchor {
                if chosen != "" && chosen != r.Snapshot.Config {
                    add(Conflict{Code: "E_CONFIG_CONFLICT", Index: anchor, Detail: "conflicting snapshot configs at anchor"})
                }
                chosen = r.Snapshot.Config
            }
        }
        if chosen != "" {
            if c, err := parseConfig(chosen); err == nil { cfg = c } else {
                add(Conflict{Code: "E_CONFIG_PARSE", Index: anchor, Detail: err.Error()})
            }
        } else {
            for _, i := range sortedIndexesLE(byIndex, anchor) {
                e, ok, _ := quorumEntry(byIndex[i], cfg)
                if !ok || e.Kind != KindConfig { continue }
                nc, err := parseConfig(e.Data)
                if err != nil { add(Conflict{Code: "E_CONFIG_PARSE", Index: i, Detail: err.Error()}); continue }
                nn, cf := transitionConfig(cfg, nc, i)
                if cf != nil { add(*cf) } else { cfg = nn }
            }
        }
    }

    committed := map[uint64]Entry{}
    C := anchor
    for i := anchor + 1; ; i++ {
        e, ok, multi := quorumEntry(byIndex[i], cfg)
        if multi {
            add(Conflict{Code: "E_DOUBLE_MAJORITY", Index: i, Detail: "two distinct values each reach quorum"})
            break
        }
        if !ok { break }
        committed[i] = e
        C = i
        if e.Kind == KindConfig {
            nc, err := parseConfig(e.Data)
            if err != nil { add(Conflict{Code: "E_CONFIG_PARSE", Index: i, Detail: err.Error()}) } else {
                nn, cf := transitionConfig(cfg, nc, i)
                if cf != nil { add(*cf) } else { cfg = nn }
            }
        }
    }

    for _, i := range sortedIndexesLE(byIndex, ^uint64(0)) {
        if _, _, multi := quorumEntry(byIndex[i], baseCfg); multi {
            add(Conflict{Code: "E_DOUBLE_MAJORITY", Index: i, Detail: "two distinct values each reach a majority"})
        }
    }

    for _, r := range reps {
        if r.CommitIndex == 0 { continue }
        if r.CommitIndex > C {
            add(Conflict{Code: "E_UNSUPPORTED_COMMIT", Index: r.CommitIndex, Replica: r.ID,
                Detail: fmt.Sprintf("commit index %d is not backed by an observed quorum", r.CommitIndex)})
            continue
        }
        for i := anchor + 1; i <= r.CommitIndex; i++ {
            re, has := explicitEntry(r, i)
            if !has { continue }
            ce, ok := committed[i]
            if !ok { continue }
            if entryValue(re) != entryValue(ce) {
                add(Conflict{Code: "E_COMMIT_CONFLICT", Index: i, Replica: r.ID,
                    Detail: fmt.Sprintf("locally committed %q but quorum committed %q", entryValue(re).key(), entryValue(ce).key())})
            }
        }
    }

    for _, r := range reps {
        if r.Snapshot == nil || r.Snapshot.LastIndex == 0 { continue }
        i := r.Snapshot.LastIndex
        if claims, ok := byIndex[i]; ok && len(claims) > 0 {
            if qe, qok, _ := quorumEntry(claims, baseCfg); qok && qe.Term != r.Snapshot.LastTerm {
                add(Conflict{Code: "E_SNAPSHOT_TERM_CONFLICT", Index: i, Replica: r.ID,
                    Detail: fmt.Sprintf("snapshot term %d conflicts with quorum term %d", r.Snapshot.LastTerm, qe.Term)})
            }
        }
    }

    logOut := make([]Entry, 0, len(committed))
    for _, e := range committed { logOut = append(logOut, e) }
    sort.Slice(logOut, func(i, j int) bool { return logOut[i].Index < logOut[j].Index })

    sort.Slice(conflicts, func(i, j int) bool {
        a, b := conflicts[i], conflicts[j]
        if a.Code != b.Code { return a.Code < b.Code }
        if a.Index != b.Index { return a.Index < b.Index }
        if a.Replica != b.Replica { return a.Replica < b.Replica }
        return a.Detail < b.Detail
    })
    conflicts = dedupeConflicts(conflicts)

    status := StatusOK
    if len(conflicts) > 0 { status = StatusConflict }
    return Report{Status: status, AnchorIndex: anchor, AnchorHash: anchorHash,
        CommitIndex: C, StateHash: hashAt[C], Config: cfg.String(), Log: logOut, Conflicts: conflicts}
}

Quorum resolution (majority in every voter set, so joint configs require both sides):

func quorumEntry(claims []repEntry, cfg config) (Entry, bool, bool) {
    byKey := map[string]Entry{}
    for _, c := range claims { byKey[entryValue(c.entry).key()] = c.entry }
    keys := make([]string, 0, len(byKey))
    for k := range byKey { keys = append(keys, k) }
    sort.Strings(keys)
    var winners []Entry
    for _, k := range keys { if valueHasQuorum(claims, cfg, k) { winners = append(winners, byKey[k]) } }
    if len(winners) == 0 { return Entry{}, false, false }
    sort.Slice(winners, func(i, j int) bool { return winners[i].Term < winners[j].Term })
    return winners[0], true, len(winners) > 1
}
func valueHasQuorum(claims []repEntry, cfg config, key string) bool {
    for _, vs := range cfg.voterSets() { if !voterQuorum(claims, vs, key) { return false } }
    return true
}
func voterQuorum(claims []repEntry, voters voterSet, key string) bool {
    if len(voters) == 0 { return false }
    count := 0
    for _, c := range claims { if voters[c.replica] && entryValue(c.entry).key() == key { count++ } }
    return count >= len(voters)/2+1
}

7. Notes

  • The reconciler is a pure function of an evidence set, which is the strongest reordering-safety achievable without a live protocol; it intentionally does not model timers or in-flight messages.
  • Snapshots are trusted as committed evidence, but still cross-checked (snapshot term vs quorum term, state-hash agreement at shared indices).
  • Majority-replicated entries are treated as the committed prefix: by Raft's election restriction, any entry held by a majority of observed replicas can never be overwritten, so it belongs to the unique committed log.
  • Membership uses simple/joint voter sets; quorum certification at index i uses the config active just before i.
