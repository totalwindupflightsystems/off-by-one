Delta-state OR-Map with safe causal-context pruning

Problem class: go-delta-crdt-anti-entropy-causal-context-prune-safety Environment: Go 1.26 (verified with go1.26.8) Module: crdt — package crdt/deltacrdt

1. Root-cause analysis

A delta-state OR-Map replicates only deltas (batches of add/remove events). Each add is a unique dot (replica, seq); a remove is itself a dot and carries the add dots it observed (a tombstone record). Two things grow without bound:

  1. Tombstone records (addDot -> removeDot) under each key.
  2. Buffered (pending) deltas kept for anti-entropy DeltaSince.

Both are part of the causal context. Reclaiming them is the crux.

The bug: pruning at the local context

The tempting optimization is: "I observed add dot A:1 (or remove event A:2), so I can drop its tombstone / buffered delta." This is unsound in two independent ways, and both cause permanent divergence:

  • Resurrection. A correct OR-Set suppresses a re-delivered add only while a tombstone exists. If B drops the tombstone for A:1 because its own context covers A:1, a stale retransmission of the add (peer's pending buffer, duplicate link, delayed packet) brings the key back while others have it removed.
  • Stranding a lagging replica. If A compacts its pending buffer because its own context covers A:1, it forgets the only copy of a delta that partitioned replica B still needs, so B can never be repaired after heal.

The root cause is the same: local knowledge is not global knowledge.

Why a plain version vector is not enough

Anti-entropy delivers out of order, so a naive "max sequence seen" vector can advance past a hole and let GC cover a dot that was never delivered. The context must track a contiguous prefix and keep out-of-order observations in a separate gap set. Only the contiguous prefix is trustworthy for GC.

The invariant

Let contig(R) be replica R's contiguous version vector and define the stable frontier

F = pointwise-min { contig(R) : R over all replicas }.

F is a lower bound on what every replica has contiguously observed. A tombstone (addDot, removeDot) may be dropped, and a buffered op retired, iff F covers both dots. Then no replica can still hold the add in a buffer or originate a new event for it, so no future delta can resurrect the removed element.

As defense in depth, the merge also makes the causal context the permanent record of every observed dot: a re-delivered add is ignored even after its tombstone is GC'd.

// Package deltacrdt implements a delta-state Observed-Remove Map (OR-Map)
// with a version-vector causal context and *stable-frontier* tombstone GC.
//
// Model
//
//  Every add  event is a unique dot (replica, seq).
//  Every remove event is itself a dot AND carries the set of add dots it
//  observed and removed (a tombstone record).
//  A Delta is a batch of add/remove events and is the only thing that is
//  replicated; there is no separate "full state" message.
//
// Merge is order independent and idempotent: adds create an entry unless the
// add dot is already tombstoned, and removes install tombstones for the add
// dots they observed. Because a tombstone is the only thing that suppresses a
// re-delivered add, tombstones are the part of the causal context that grows
// without bound and must be reclaimed.
//
// Safety of GC
//
//  A tombstone (addDot -> removeDot) may be dropped only when *every* replica
//  has contiguously observed both addDot and removeDot. At that point:
//    1. no replica can still be holding addDot in its outbound delta buffer
//       (buffers are retired at the same frontier), and
//    2. no replica will ever generate a new event for addDot,
//  so no future delta can carry a resurrection of addDot.
//
// The pointwise minimum of all replicas' contiguous contexts is the *stable
// frontier*. Pruning at or below it is safe; pruning at the local context is
// not, and is the bug this package is written to defeat.
package deltacrdt

import (
    "sort"
    "sync"
)

// Dot is a globally unique event identifier.
type Dot struct {
    Replica string
    Seq     uint64
}

// Less gives a total order over dots (replica name, then sequence).
func (d Dot) Less(o Dot) bool {
    if d.Replica != o.Replica {
        return d.Replica < o.Replica
    }
    return d.Seq < o.Seq
}

// ---------------------------------------------------------------------------
// Causal context
// ---------------------------------------------------------------------------

// VersionVector maps a replica to the highest sequence number that has been
// observed *contiguously* (without gaps) from that replica.
type VersionVector map[string]uint64

// Clone returns an independent copy.
func (v VersionVector) Clone() VersionVector {
    out := make(VersionVector, len(v))
    for k, s := range v {
        out[k] = s
    }
    return out
}

// Covers reports whether dot d is at or below the vector.
func (v VersionVector) Covers(d Dot) bool { return v[d.Replica] >= d.Seq }

// MinFrontier returns the pointwise minimum of the supplied vectors. It is a
// lower bound on what every replica has contiguously observed, i.e. the
// largest region that is safe to garbage collect.
func MinFrontier(vs ...VersionVector) VersionVector {
    out := VersionVector{}
    keys := map[string]struct{}{}
    for _, v := range vs {
        for k := range v {
            keys[k] = struct{}{}
        }
    }
    for k := range keys {
        min := ^uint64(0)
        for _, v := range vs {
            if s := v[k]; s < min {
                min = s
            }
        }
        out[k] = min
    }
    return out
}

// CausalContext is a gap-aware version vector. The contiguous prefix is the
// part that can be trusted for the stable-frontier computation; out-of-order
// observations live in gaps until the prefix catches up to them.
type CausalContext struct {
    vv   VersionVector
    gaps map[Dot]struct{}
}

// NewCausalContext returns an empty context.
func NewCausalContext() *CausalContext {
    return &CausalContext{vv: VersionVector{}, gaps: map[Dot]struct{}{}}
}

// Clone returns an independent copy.
func (c *CausalContext) Clone() *CausalContext {
    out := &CausalContext{vv: c.vv.Clone(), gaps: make(map[Dot]struct{}, len(c.gaps))}
    for d := range c.gaps {
        out.gaps[d] = struct{}{}
    }
    return out
}

// Contiguous returns a copy of the trusted prefix.
func (c *CausalContext) Contiguous() VersionVector { return c.vv.Clone() }

// Observed reports whether d has been seen, contiguously or out of order.
func (c *CausalContext) Observed(d Dot) bool {
    if c.vv[d.Replica] >= d.Seq {
        return true
    }
    _, ok := c.gaps[d]
    return ok
}

// Observe records d. It returns true if d was newly observed.
func (c *CausalContext) Observe(d Dot) bool {
    if c.Observed(d) {
        return false
    }
    if d.Seq == c.vv[d.Replica]+1 {
        c.vv[d.Replica] = d.Seq
        // Absorb any contiguous run of previously out-of-order dots.
        for {
            next := Dot{Replica: d.Replica, Seq: c.vv[d.Replica] + 1}
            if _, ok := c.gaps[next]; !ok {
                break
            }
            delete(c.gaps, next)
            c.vv[d.Replica] = next.Seq
        }
    } else {
        c.gaps[d] = struct{}{}
    }
    return true
}

// Merge folds another context into this one.
func (c *CausalContext) Merge(o *CausalContext) {
    for r, s := range o.vv {
        if s <= c.vv[r] {
            continue
        }
        c.vv[r] = s
        for {
            next := Dot{Replica: r, Seq: c.vv[r] + 1}
            if _, ok := c.gaps[next]; !ok {
                break
            }
            delete(c.gaps, next)
            c.vv[r] = next.Seq
        }
    }
    for d := range o.gaps {
        c.Observe(d)
    }
}

// ---------------------------------------------------------------------------
// Delta and operations
// ---------------------------------------------------------------------------

// AddOp is a single add event.
type AddOp[V any] struct {
    Dot   Dot
    Key   string
    Value V
}

// RemoveOp is a single remove event. Dot identifies the removal itself; Removed
// lists the add dots that were observed and removed.
type RemoveOp struct {
    Dot     Dot
    Key     string
    Removed []Dot
}

// Delta is a batch of operations. It is the unit of replication.
type Delta[V any] struct {
    Adds    []AddOp[V]
    Removes []RemoveOp
}

// Empty reports whether the delta carries no operations.
func (d Delta[V]) Empty() bool { return len(d.Adds) == 0 && len(d.Removes) == 0 }

// Append folds src into dst (test/oracle helper).
func (d *Delta[V]) Append(src Delta[V]) {
    d.Adds = append(d.Adds, src.Adds...)
    d.Removes = append(d.Removes, src.Removes...)
}

// ---------------------------------------------------------------------------
// OR-Map
// ---------------------------------------------------------------------------

// ORMap is one replica of the replicated map.
type ORMap[V any] struct {
    mu      sync.Mutex
    replica string
    seq     uint64

    ctx        *CausalContext
    entries    map[string]map[Dot]V   // live add dots per key
    tombstones map[string]map[Dot]Dot // key -> addDot -> removeDot
    pending    Delta[V]               // ops not yet known stable, for DeltaSince
}

// New creates an empty replica.
func New[V any](replica string) *ORMap[V] {
    return &ORMap[V]{
        replica:    replica,
        ctx:        NewCausalContext(),
        entries:    map[string]map[Dot]V{},
        tombstones: map[string]map[Dot]Dot{},
    }
}

// Replica returns the replica id.
func (m *ORMap[V]) Replica() string { return m.replica }

// Context returns a snapshot copy of the causal context.
func (m *ORMap[V]) Context() *CausalContext {
    m.mu.Lock()
    defer m.mu.Unlock()
    return m.ctx.Clone()
}

// ---------------------------------------------------------------------------
// Local mutation
// ---------------------------------------------------------------------------

// Add appends a new add event locally and returns the minimal delta for it.
func (m *ORMap[V]) Add(key string, value V) Delta[V] {
    m.mu.Lock()
    defer m.mu.Unlock()
    m.seq++
    op := AddOp[V]{Dot: Dot{Replica: m.replica, Seq: m.seq}, Key: key, Value: value}
    m.ctx.Observe(op.Dot)
    if m.entries[key] == nil {
        m.entries[key] = map[Dot]V{}
    }
    m.entries[key][op.Dot] = value
    m.pending.Adds = append(m.pending.Adds, op)
    return Delta[V]{Adds: []AddOp[V]{op}}
}

// Remove tombstones every live add dot for key that this replica has observed.
// It returns an empty delta if the key has no live entries.
func (m *ORMap[V]) Remove(key string) Delta[V] {
    m.mu.Lock()
    defer m.mu.Unlock()
    var live []Dot
    for d := range m.entries[key] {
        if _, removed := m.tombstones[key][d]; !removed {
            live = append(live, d)
        }
    }
    if len(live) == 0 {
        return Delta[V]{}
    }
    sort.Slice(live, func(i, j int) bool { return live[i].Less(live[j]) })

    m.seq++
    rem := RemoveOp{Dot: Dot{Replica: m.replica, Seq: m.seq}, Key: key, Removed: live}
    m.ctx.Observe(rem.Dot)
    if m.tombstones[key] == nil {
        m.tombstones[key] = map[Dot]Dot{}
    }
    for _, d := range live {
        m.tombstones[key][d] = rem.Dot
        delete(m.entries[key], d)
    }
    m.pending.Removes = append(m.pending.Removes, rem)
    return Delta[V]{Removes: []RemoveOp{rem}}
}

// ---------------------------------------------------------------------------
// Merge
// ---------------------------------------------------------------------------

// Apply merges a delta (possibly out of order or duplicated). It is idempotent
// unconditionally: the causal context permanently remembers every observed dot,
// so a re-delivered add is ignored even after its tombstone has been GC'd.
func (m *ORMap[V]) Apply(delta Delta[V]) {
    m.mu.Lock()
    defer m.mu.Unlock()
    for _, a := range delta.Adds {
        if m.ctx.Observed(a.Dot) {
            // Already applied (or dominated by a tombstone) at some earlier
            // point. The causal context remembers the dot forever, so a stale
            // retransmission can never resurrect it, even after GC.
            continue
        }
        m.ctx.Observe(a.Dot)
        m.pending.Adds = append(m.pending.Adds, a)
        if _, removed := m.tombstones[a.Key][a.Dot]; removed {
            continue // the add is dominated by an observed removal
        }
        if m.entries[a.Key] == nil {
            m.entries[a.Key] = map[Dot]V{}
        }
        m.entries[a.Key][a.Dot] = a.Value
    }
    for _, r := range delta.Removes {
        if m.ctx.Observed(r.Dot) {
            continue
        }
        m.ctx.Observe(r.Dot)
        m.pending.Removes = append(m.pending.Removes, r)
        if m.tombstones[r.Key] == nil {
            m.tombstones[r.Key] = map[Dot]Dot{}
        }
        for _, rd := range r.Removed {
            // A referenced add dot is not "observed" here: only the add
            // event itself advances the contiguous context.
            m.tombstones[r.Key][rd] = r.Dot
            delete(m.entries[r.Key], rd)
        }
    }
}

// applyContextFree mirrors a naive OR-Set merge that relies on tombstones alone
// and never consults the causal context to suppress re-delivered dots. It is
// retained only as a test fixture that demonstrates the failure mode that
// stable-frontier GC plus context-aware merge together eliminate.
func applyContextFree[V any](m *ORMap[V], delta Delta[V]) {
    m.mu.Lock()
    defer m.mu.Unlock()
    for _, a := range delta.Adds {
        if m.ctx.Observe(a.Dot) {
            m.pending.Adds = append(m.pending.Adds, a)
        }
        if _, removed := m.tombstones[a.Key][a.Dot]; removed {
            continue
        }
        if m.entries[a.Key] == nil {
            m.entries[a.Key] = map[Dot]V{}
        }
        m.entries[a.Key][a.Dot] = a.Value
    }
    for _, r := range delta.Removes {
        if m.ctx.Observe(r.Dot) {
            m.pending.Removes = append(m.pending.Removes, r)
        }
        if m.tombstones[r.Key] == nil {
            m.tombstones[r.Key] = map[Dot]Dot{}
        }
        for _, rd := range r.Removed {
            m.tombstones[r.Key][rd] = r.Dot
            delete(m.entries[r.Key], rd)
        }
    }
}

// unsafeCompactLocal compacts pending deltas at the *local* context instead of
// the stable frontier. A lagging replica that never received those ops can then
// never be repaired. It is retained only as a demonstration.
func unsafeCompactLocal[V any](m *ORMap[V]) {
    m.mu.Lock()
    defer m.mu.Unlock()
    local := m.ctx.Contiguous()
    keptA := m.pending.Adds[:0]
    for _, a := range m.pending.Adds {
        if !local.Covers(a.Dot) {
            keptA = append(keptA, a)
        }
    }
    m.pending.Adds = keptA
    keptR := m.pending.Removes[:0]
    for _, r := range m.pending.Removes {
        if !local.Covers(r.Dot) {
            keptR = append(keptR, r)
        }
    }
    m.pending.Removes = keptR
}

// DeltaSince returns the ops this replica holds that the remote context has not
// observed. Add ops that are already tombstoned are never forwarded; the
// remove that dominates them carries the necessary information.
func (m *ORMap[V]) DeltaSince(remote *CausalContext) Delta[V] {
    m.mu.Lock()
    defer m.mu.Unlock()
    var out Delta[V]
    for _, a := range m.pending.Adds {
        if remote.Observed(a.Dot) {
            continue
        }
        if _, tomb := m.tombstones[a.Key][a.Dot]; tomb {
            continue
        }
        out.Adds = append(out.Adds, a)
    }
    for _, r := range m.pending.Removes {
        if remote.Observed(r.Dot) {
            continue
        }
        out.Removes = append(out.Removes, r)
    }
    return out
}

// ---------------------------------------------------------------------------
// Stable-frontier GC
// ---------------------------------------------------------------------------

// Prune garbage collects tombstones and buffered deltas at or below frontier.
//
// A tombstone (addDot -> removeDot) is dropped only when frontier covers BOTH
// dots. This is the safe frontier invariant. Dropping a tombstone when the
// add dot is below the frontier guarantees that every replica has contiguously
// observed the add and retired it from its pending buffer, so no future delta
// can re-deliver it and resurrect the key.
func (m *ORMap[V]) Prune(frontier VersionVector) (droppedTombstones, droppedPending int) {
    m.mu.Lock()
    defer m.mu.Unlock()

    for key, ts := range m.tombstones {
        for addDot, removeDot := range ts {
            if frontier.Covers(addDot) && frontier.Covers(removeDot) {
                delete(ts, addDot)
                droppedTombstones++
            }
        }
        if len(ts) == 0 {
            delete(m.tombstones, key)
        }
    }
    // Reclaim fully-removed keys.
    for key, es := range m.entries {
        if len(es) == 0 {
            if _, hasTombs := m.tombstones[key]; !hasTombs {
                delete(m.entries, key)
            }
        }
    }

    keptA := m.pending.Adds[:0]
    for _, a := range m.pending.Adds {
        if frontier.Covers(a.Dot) {
            droppedPending++
            continue
        }
        keptA = append(keptA, a)
    }
    m.pending.Adds = keptA

    keptR := m.pending.Removes[:0]
    for _, r := range m.pending.Removes {
        if frontier.Covers(r.Dot) {
            droppedPending++
            continue
        }
        keptR = append(keptR, r)
    }
    m.pending.Removes = keptR
    return
}

// ---------------------------------------------------------------------------
// Read / introspection
// ---------------------------------------------------------------------------

// Entry is one live add dot.
type Entry[V any] struct {
    Key   string
    Dot   Dot
    Value V
}

// LiveEntries returns all live entries in a canonical order.
func (m *ORMap[V]) LiveEntries() []Entry[V] {
    m.mu.Lock()
    defer m.mu.Unlock()
    var out []Entry[V]
    for key, es := range m.entries {
        for d, v := range es {
            if _, removed := m.tombstones[key][d]; removed {
                continue
            }
            out = append(out, Entry[V]{Key: key, Dot: d, Value: v})
        }
    }
    sort.Slice(out, func(i, j int) bool {
        if out[i].Key != out[j].Key {
            return out[i].Key < out[j].Key
        }
        return out[i].Dot.Less(out[j].Dot)
    })
    return out
}

// Lookup returns the deterministic (max-dot) winning value for key.
func (m *ORMap[V]) Lookup(key string) (V, bool) {
    m.mu.Lock()
    defer m.mu.Unlock()
    var best Dot
    var val V
    found := false
    for d, v := range m.entries[key] {
        if _, removed := m.tombstones[key][d]; removed {
            continue
        }
        if !found || best.Less(d) {
            best, val, found = d, v, true
        }
    }
    return val, found
}

// Keys returns the sorted set of keys with at least one live entry.
func (m *ORMap[V]) Keys() []string {
    m.mu.Lock()
    defer m.mu.Unlock()
    var out []string
    for key, es := range m.entries {
        live := false
        for d := range es {
            if _, removed := m.tombstones[key][d]; !removed {
                live = true
                break
            }
        }
        if live {
            out = append(out, key)
        }
    }
    sort.Strings(out)
    return out
}

// TombstoneCount returns the number of retained tombstone records.
func (m *ORMap[V]) TombstoneCount() int {
    m.mu.Lock()
    defer m.mu.Unlock()
    n := 0
    for _, ts := range m.tombstones {
        n += len(ts)
    }
    return n
}

// PendingCount returns the number of buffered ops awaiting stable GC.
func (m *ORMap[V]) PendingCount() int {
    m.mu.Lock()
    defer m.mu.Unlock()
    return len(m.pending.Adds) + len(m.pending.Removes)
}

// LiveCount returns the number of live add dots.
func (m *ORMap[V]) LiveCount() int {
    m.mu.Lock()
    defer m.mu.Unlock()
    n := 0
    for key, es := range m.entries {
        for d := range es {
            if _, removed := m.tombstones[key][d]; !removed {
                n++
            }
        }
    }
    return n
}

package deltacrdt

// ---------------------------------------------------------------------------
// Basic semantics
// ---------------------------------------------------------------------------

func TestBasicAddRemove(t *testing.T) {
    a := New[string]("A")
    d := a.Add("k", "v1")
    if v, ok := a.Lookup("k"); !ok || v != "v1" {
        t.Fatalf("lookup = %q,%v want v1,true", v, ok)
    }
    r := a.Remove("k")
    if _, ok := a.Lookup("k"); ok {
        t.Fatalf("key still present after remove")
    }
    if d.Empty() || r.Empty() {
        t.Fatalf("expected non-empty deltas")
    }
    // Removing an absent key is a no-op.
    if !a.Remove("k").Empty() {
        t.Fatalf("removing absent key should be empty delta")
    }
}

func TestOutOfOrderAndDuplicate(t *testing.T) {
    a, b := New[string]("A"), New[string]("B")
    d := a.Add("k", "v")
    r := a.Remove("k")

    // Deliver the remove *before* the add, and duplicate both.
    b.Apply(r)
    b.Apply(d)
    b.Apply(d)
    b.Apply(r)

    if _, ok := b.Lookup("k"); ok {
        t.Fatalf("remove-before-add must stay removed")
    }
    if len(b.LiveEntries()) != 0 {
        t.Fatalf("expected no live entries, got %v", b.LiveEntries())
    }
    a.Apply(d)
    a.Apply(r)
    if _, ok := a.Lookup("k"); ok {
        t.Fatalf("A must stay removed")
    }
}

// unsafePruneLocal is the classic bug: drop a tombstone as soon as the local
// context has observed the removed add dot. It ignores the remove event and,
// crucially, ignores every other replica. It exists only to demonstrate the
// failure mode; it must never be used in production.
func unsafePruneLocal[V any](m *ORMap[V]) int {
    m.mu.Lock()
    defer m.mu.Unlock()
    n := 0
    for key, ts := range m.tombstones {
        for addDot := range ts {
            if m.ctx.Observed(addDot) {
                delete(ts, addDot)
                n++
            }
        }
        if len(ts) == 0 {
            delete(m.tombstones, key)
        }
    }
    return n
}

// TestUnsafeLocalPruneResurrects reproduces the classic failure: a context-free
// OR-Set merge relies entirely on tombstones, so garbage collecting a tombstone
// at the local context lets a stale retransmission resurrect the key.
func TestUnsafeLocalPruneResurrects(t *testing.T) {
    a, b := New[string]("A"), New[string]("B")
    d := a.Add("k", "v") // A:1
    applyContextFree(b, d)
    r := a.Remove("k") // A:2 dominates A:1
    applyContextFree(b, r)

    if _, ok := b.Lookup("k"); ok {
        t.Fatalf("B should be removed")
    }
    // The buggy GC drops B's tombstone because B saw A:1.
    if n := unsafePruneLocal(b); n != 1 {
        t.Fatalf("expected to drop 1 tombstone, dropped %d", n)
    }
    // A stale retransmission of the original add now resurrects the key.
    applyContextFree(b, d)
    if _, ok := b.Lookup("k"); !ok {
        t.Fatalf("BUG NOT REPRODUCED: expected resurrection")
    }
    if _, ok := a.Lookup("k"); ok {
        t.Fatalf("A should still be removed")
    }
    t.Logf("unsafe local prune diverged: B=%v A=%v", b.Keys(), a.Keys())
}

func TestStableFrontierPruneIsSafe(t *testing.T) {
    a, b := New[string]("A"), New[string]("B")
    d := a.Add("k", "v")
    b.Apply(d)
    r := a.Remove("k")
    b.Apply(r)

    // Every replica has contiguously observed both A:1 and A:2, so the stable
    // frontier covers them and the tombstone is collectable.
    frontier := MinFrontier(a.Context().Contiguous(), b.Context().Contiguous())
    b.Prune(frontier)
    if b.TombstoneCount() != 0 {
        t.Fatalf("tombstone should be collectable at the stable frontier")
    }
    // With the context-aware merge, replaying the stale add is a no-op.
    b.Apply(d)
    if _, ok := b.Lookup("k"); ok {
        t.Fatalf("context-aware merge resurrected the key after GC")
    }
    // And a remove that arrives before its add also suppresses it.
    c := New[string]("C")
    c.Apply(r)
    c.Apply(d)
    if _, ok := c.Lookup("k"); ok {
        t.Fatalf("remove-before-add resurrected the key")
    }
}

// TestUnsafeLocalCompactionLosesDeltas shows the other half of the bug:
// compacting the pending causal context at the local frontier discards deltas
// that a lagging replica still needs, so it can never be repaired.
func TestUnsafeLocalCompactionLosesDeltas(t *testing.T) {
    a, b := New[string]("A"), New[string]("B")
    a.Add("k", "v") // in flight to B

    // Buggy: A is fully caught up with itself, so a local compaction drops d.
    unsafeCompactLocal(a)
    if got := a.DeltaSince(NewCausalContext()); !got.Empty() {
        t.Fatalf("expected local compaction to lose the delta, got %+v", got)
    }
    if _, ok := b.Lookup("k"); ok {
        t.Fatalf("B unexpectedly has the key")
    }

    // Safe: a fresh producer, whose stable frontier is the minimum of its own
    // context and the lagging replica's, does not cover A:1, so it keeps the
    // delta and can repair the lagging replica.
    a2 := New[string]("A")
    a2.Add("k", "v")
    b2 := New[string]("B")
    frontier := MinFrontier(a2.Context().Contiguous(), b2.Context().Contiguous())
    a2.Prune(frontier)
    got := a2.DeltaSince(b2.Context())
    if len(got.Adds) != 1 {
        t.Fatalf("stable frontier lost a needed delta: %+v", got)
    }
    b2.Apply(got)
    if _, ok := b2.Lookup("k"); !ok {
        t.Fatalf("B should have been repaired")
    }
}

type message struct {
    from, to int
    delta    Delta[string]
}

type simConfig struct {
    n              int
    ops            int
    keys           int
    seed           int64
    partitionEvery int
    prune          bool
}

type simResult struct {
    live   []map[string]map[Dot]string
    expect map[string]map[Dot]string
    tombs  []int
    pend   []int
}

func runSim(cfg simConfig) simResult {
    rng := rand.New(rand.NewSource(cfg.seed))
    reps := make([]*ORMap[string], cfg.n)
    for i := range reps {
        reps[i] = New[string](fmt.Sprintf("R%d", i))
    }
    part := make([]int, cfg.n) // 0 == fully connected
    var queue []message
    var opLog Delta[string]

    connected := func() bool {
        for _, p := range part {
            if p != part[0] {
                return false
            }
        }
        return true
    }

    drain := func() {
        for len(queue) > 0 {
            rng.Shuffle(len(queue), func(i, j int) { queue[i], queue[j] = queue[j], queue[i] })
            var next []message
            moved := false
            for _, m := range queue {
                if part[m.from] == part[m.to] {
                    reps[m.to].Apply(m.delta)
                    moved = true
                } else {
                    next = append(next, m)
                }
            }
            queue = next
            if !moved {
                return
            }
        }
    }

    broadcast := func(from int, d Delta[string]) {
        if d.Empty() {
            return
        }
        for to := 0; to < cfg.n; to++ {
            if to == from {
                continue
            }
            queue = append(queue, message{from, to, d})
            if rng.Intn(6) == 0 { // adversarial duplicate
                queue = append(queue, message{from, to, d})
            }
        }
    }

    syncRound := func() {
        for i := 0; i < cfg.n; i++ {
            for j := 0; j < cfg.n; j++ {
                if i == j {
                    continue
                }
                if d := reps[i].DeltaSince(reps[j].Context()); !d.Empty() {
                    queue = append(queue, message{i, j, d})
                }
            }
        }
    }

    pruneAll := func() {
        if !connected() {
            return
        }
        var vvs []VersionVector
        for _, r := range reps {
            vvs = append(vvs, r.Context().Contiguous())
        }
        f := MinFrontier(vvs...)
        for _, r := range reps {
            r.Prune(f)
        }
    }

    for i := 0; i < cfg.ops; i++ {
        r := rng.Intn(cfg.n)
        key := fmt.Sprintf("k%d", rng.Intn(cfg.keys))
        var d Delta[string]
        if rng.Intn(100) < 55 {
            d = reps[r].Add(key, fmt.Sprintf("v%d", i))
        } else {
            d = reps[r].Remove(key)
        }
        opLog.Append(d)
        broadcast(r, d)

        if i%50 == 0 {
            drain()
        }
        if cfg.partitionEvery > 0 && i > 0 && i%cfg.partitionEvery == 0 {
            for k := range part {
                part[k] = rng.Intn(3)
            }
            drain()
        }
        if i%250 == 0 {
            syncRound()
            drain()
            if cfg.prune {
                pruneAll()
            }
        }
    }

    // Heal and quiesce.
    for k := range part {
        part[k] = 0
    }
    drain()
    for iter := 0; iter < 200; iter++ {
        syncRound()
        drain()
        if cfg.prune {
            pruneAll()
        }
        if allSameContext(reps) && len(queue) == 0 {
            break
        }
    }

    res := simResult{expect: expectedLive(opLog)}
    for _, r := range reps {
        res.live = append(res.live, liveMap(r))
        res.tombs = append(res.tombs, r.TombstoneCount())
        res.pend = append(res.pend, r.PendingCount())
    }
    return res
}

func expectedLive(log Delta[string]) map[string]map[Dot]string {
    removed := map[Dot]bool{}
    for _, r := range log.Removes {
        for _, d := range r.Removed {
            removed[d] = true
        }
    }
    out := map[string]map[Dot]string{}
    for _, a := range log.Adds {
        if removed[a.Dot] {
            continue
        }
        m := out[a.Key]
        if m == nil {
            m = map[Dot]string{}
            out[a.Key] = m
        }
        m[a.Dot] = a.Value
    }
    return out
}

func liveMap(r *ORMap[string]) map[string]map[Dot]string {
    out := map[string]map[Dot]string{}
    for _, e := range r.LiveEntries() {
        m := out[e.Key]
        if m == nil {
            m = map[Dot]string{}
            out[e.Key] = m
        }
        m[e.Dot] = e.Value
    }
    return out
}

func allSameContext(reps []*ORMap[string]) bool {
    base := reps[0].Context().Contiguous()
    for _, r := range reps[1:] {
        if !reflect.DeepEqual(base, r.Context().Contiguous()) {
            return false
        }
    }
    return true
}

// TestConvergenceUnderAdversarialSchedule drives 10k concurrent operations per
// seed through partitions, random reordering and duplicate deliveries, then
// heals and checks every replica equals a delivery-order-independent oracle.
func TestConvergenceUnderAdversarialSchedule(t *testing.T) {
    for _, seed := range []int64{1, 2, 3, 4, 5, 6, 7, 8} {
        res := runSim(simConfig{n: 5, ops: 10000, keys: 64, seed: seed, partitionEvery: 613, prune: true})
        for i := range res.live {
            if !reflect.DeepEqual(res.live[i], res.expect) {
                t.Fatalf("seed %d replica %d diverged from oracle", seed, i)
            }
            if res.tombs[i] != 0 || res.pend[i] != 0 {
                t.Fatalf("seed %d replica %d overhead not reclaimed: tombs=%d pending=%d",
                    seed, i, res.tombs[i], res.pend[i])
            }
        }
    }
}

// TestPruneMatchesNoPrune checks the GC'd run agrees with a run that never GCs.
func TestPruneMatchesNoPrune(t *testing.T) {
    for _, seed := range []int64{11, 12, 13, 14} {
        cfg := simConfig{n: 4, ops: 5000, keys: 48, seed: seed, partitionEvery: 511}
        noPrune := runSim(func() simConfig { c := cfg; c.prune = false; return c }())
        withPrune := runSim(func() simConfig { c := cfg; c.prune = true; return c }())
        for i := range withPrune.live {
            if !reflect.DeepEqual(withPrune.live[i], noPrune.live[i]) {
                t.Fatalf("seed %d replica %d: pruned state differs from unpruned", seed, i)
            }
            if !reflect.DeepEqual(withPrune.live[i], noPrune.expect) {
                t.Fatalf("seed %d replica %d diverged from oracle", seed, i)
            }
        }
    }
}

// TestIdempotentApply verifies that applying the same delta many times is a

// TestGCBoundsMemory shows that stable-frontier GC keeps tombstones bounded

        d := a.Add("hot", fmt.Sprintf("v%d", i))
        b.Apply(d)
        r := a.Remove("hot")
        b.Apply(r)
        // A and B are the whole system; the frontier is their min context.
        f := MinFrontier(a.Context().Contiguous(), b.Context().Contiguous())
        a.Prune(f)
        b.Prune(f)

        t.Fatalf("tombstones not bounded, got %d", n)
    }
    if n := a.PendingCount() + b.PendingCount(); n > 2 {
        t.Fatalf("pending not bounded, got %d", n)
    }
}

The adversarial oracle

The harness is independent of delivery order. It records the generated op log and builds the expected live set directly: live = every add dot that no remove observed. Each replica's live entries must deep-equal this set, catching both resurrection (extra live dot) and lost updates (missing live dot).

Size bound

After the final heal + anti-entropy quiesce, every op dot is below the stable frontier, so TestConvergenceUnderAdversarialSchedule additionally asserts TombstoneCount() == 0 and PendingCount() == 0 on every replica while live entries still equal the oracle — the bounded-overhead property required under the 10k-op adversarial schedule.
