Fix: E0046 on a feature-gated WriteTxn impl that default-feature builds never compile

Class: rust-e0046-trait-impl-missing-under-feature-gate Repo: hermes-rs · broken: a5dcc10 · fixed: 7a349058bba02b202ff702489d434de46eb18416 Trait: WriteTxn (src/persistence/api.rs) · gated impl: TursoBackend (src/persistence/turso_backend.rs:512) Gate command: cargo clippy --workspace --all-targets --all-features -- -D warnings

1. Symptom

Command Result
cargo test --workspace GREEN (exit 0, all targets ok, new regression tests pass)
cargo build --workspace --all-features RED (exit 101) — error[E0046]: not all trait items implemented, missing: append_messages_batch --> src/persistence/turso_backend.rs:512

The same --all-features failure hit the CI lint/build leg on every push.

2. Root cause

WriteTxn has multiple impls; one is compiled only under the opt-in turso feature:

[features]
turso = ["dep:turso", "dep:tokio"]

#[cfg(feature = "turso")]
pub mod turso_backend;

turso is not in the default feature set, so a plain cargo test --workspace never parses/types-checks turso_backend.rs — cfg-stripped modules are removed before name resolution and trait checking. When a new required method append_messages_batch was added to WriteTxn, only SqliteWriteTxn was updated. The missing method on TursoBackend is invisible under default features and only E0046 fires under --all-features.

Key insight: default-feature compilation is not a subset check over gated code paths. Green default + red --all-features is the signature of this class.

Not to be confused with Cargo feature unification (E0599 / serialize_struct not found). That is about a dependency's features leaking across members (resolver = "2"); this is a local impl being cfg-stripped from the compilation unit.

3. Exact fix

3.1 Enumerate impls by source, not compiler output

grep -rn "impl WriteTxn for" src/
grep -rn "cfg(feature" src/persistence/          # which impls can be stripped

src/persistence/stock_sqlite.rs:  impl WriteTxn for SqliteWriteTxn   # already fixed
src/persistence/turso_backend.rs: impl WriteTxn for TursoBackend    # MISSING -> fix

3.2 Implement the method on every impl, including the gated one

// src/persistence/turso_backend.rs (inside impl WriteTxn for TursoBackend)
fn append_messages_batch(&mut self, messages: &[NewMessage]) -> Result<()> {
    if messages.is_empty() {
        return Ok(());
    }
    // One transaction for the whole batch: all rows land or none do.
    let tx = self.conn.transaction()?;
    for message in messages {
        append_message_in_tx(&tx, message)?;
    }
    tx.commit()?;
    Ok(())
}

(If the backend has a native bulk-insert API, delegate to it instead.) Keep api.rs + stock_sqlite.rs as the source of truth and conform the Turso impl.

3.3 Format before pushing

cargo fmt --all && cargo fmt --all -- --check

3.4 Adopt the full-feature gate (prevention)

cargo clippy --workspace --all-targets --all-features -- -D warnings   # guard
cargo build  --workspace --all-features                               # minimum

Wire the guard into CI lint/test legs with --all-features everywhere so gated impls always enter the compilation unit.

4. Verification (in order)

1 cargo clippy --workspace --all-targets --all-features -- -D warnings exit 0 (was 101 + E0046)
2 cargo build --workspace --all-features exit 0
3 cargo test --workspace exit 0, all targets ok, incl. two new regression tests
4 cargo test --workspace --all-features exit 0 (exercises the real Turso impl set)
5 cargo fmt --all -- --check exit 0
6 CI after push 3/3 legs success; pre-fix run shows Format-leg failure

5. Trap to remember

  • Green cargo test --workspace ≠ complete trait addition when an impl is cfg-gated.
  • Green default build + red --all-features build is the signature of this class.
  • Default and --all-features test runs exercise different impl sets — any "the repo builds" criterion must name the feature set.
  • On every trait-method change: grep -rn "impl <Trait> for" src/ cross-checked with grep -rn "cfg(feature" src/. Never rely on the default compiler to report missing gated impls.
