Summary

Root cause (two compounding defects in auger.py):

  1. ns_dir() hardcoded ~/duckbrain/namespaces/<ns>, while the substrate resolves its declaration tree from DUCKBRAIN_NAMESPACES_PATH. init wrote 14 .table.json files into the wrong tree (polluting ~) and the API never saw them.
  2. cmd_init computed the tally (declared: 0/14) and warned, but return 0 ignored it — a wrong-tree install exited green, and the next verb 404'd with Table 'project' not found.

Fix: resolve the root the way the substrate does — --namespaces-path → $DUCKBRAIN_NAMESPACES_PATH → $DUCKBRAIN_DATA_DIR/namespaces → ~/duckbrain/namespaces — and make a 0/N tally raise SystemExit (rc 1) naming both directories.

Verification (all run here): - Offline harness (real cmd_init, real resolver, real writes; only urlopen faked): resolution precedence PASS, init rc≠0 on 0/14 PASS, init rc=0 on 14/14 PASS, --namespaces-path overrides env PASS. - Existing suite: pytest -q → 45 passed, 138 skipped (live tests skip without a substrate).

# auger.py — replace ns_dir
NAMESPACES_PATH_ENV = "DUCKBRAIN_NAMESPACES_PATH"
DATA_DIR_ENV = "DUCKBRAIN_DATA_DIR"
_NAMESPACES_ROOT: str | None = None

def set_namespaces_root(path: str | None) -> None:
    global _NAMESPACES_ROOT
    _NAMESPACES_ROOT = os.path.expanduser(path) if path else None

def namespaces_root() -> str:
    if _NAMESPACES_ROOT:
        return _NAMESPACES_ROOT
    explicit = os.environ.get(NAMESPACES_PATH_ENV)
    if explicit:
        return os.path.expanduser(explicit)
    data_dir = os.environ.get(DATA_DIR_ENV)
    if data_dir:
        return os.path.join(os.path.expanduser(data_dir), "namespaces")
    return os.path.join(os.path.expanduser("~"), "duckbrain", "namespaces")

def ns_dir(ns: str) -> str:
    return os.path.join(namespaces_root(), ns)

# auger.py — cmd_init, fail closed on 0/N (after the missing-table warning)
    if not have:
        raise SystemExit(
            f"init declared 0/{len(COLS)} tables: the API cannot see a single declaration, so the "
            f"substrate is reading a different directory than auger wrote to.\n"
            f"  auger wrote:  {d}\n"
            f"  resolved root: {namespaces_root()} ...\n"
            f"  point auger at the substrate's root, e.g. `--namespaces-path <dir>` or "
            f"`export {NAMESPACES_PATH_ENV}=<dir>`, then rerun init; if the files are already in "
            f"the right place, restart the API so it re-reads them"
        )
