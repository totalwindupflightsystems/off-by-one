BGP Route-Reflector Best-Exit Selection under RPKI Path-Attribute Poisoning — Diagnosis and Verified Fix

0. TL;DR

The failure mode is not a crash: it is a silent mis-selection. A route reflector picks the wrong egress because the origin-validity stamp is folded into the decision process in the wrong place, because a missing stamp is treated as neutral instead of conservative, and because poisoned stamps are detected but never repaired when computing the corrected map. The fix is a single, total, fully specified decision process plus an explicit baseline vs. corrected evaluator distinction and a per-prefix minimal correction search.

This document is self-contained: it states an input contract, gives the complete working Go program and test suite, and shows the verified output. Artifacts also live at /workspace/SOLUTION.md and /workspace/bgp-rr/.

1. Input / output contract

1.1 Snapshot JSON (input)

{
  "local_as": 65000,
  "peers": {
    "<ip-address>": { "asn": 65001, "router_id": "<ip-address>", "ibgp": false }
  },
  "rpki_cache": [
    { "prefix": "<ip-address>/24", "state": "valid" }
  ],
  "paths": [
    {
      "prefix": "<ip-address>/24",
      "peer": "<ip-address>",
      "as_path": [65001, 64496],
      "med": 10,
      "local_pref": 100,
      "origin": "igp",
      "communities": ["65001:1"],
      "origin_stamp": "valid"
    }
  ]
}
  • rpki_cache is the delta embedded in the dump: prefix -> state (valid / notfound / invalid). A prefix absent from the delta is interpreted as notfound.
  • origin_stamp is the validity declared by the announcement; it may be omitted (missing) — the poisoning vector.
  • local_pref omitted/0 means the BGP default 100.

1.2 Report JSON (output)

{
  "best_exit":               [ { "prefix": "...", "peer": "...", "deciding_attribute": "..." } ],
  "poisoned":                [ { "prefix": "...", "peer": "...", "kind": "contradiction|missing-stamp",
                                 "declared": "...", "cache": "..." } ],
  "minimal_corrections":     [ { "prefix": "...", "peer": "..." } ],
  "impactful_single_repairs":[ { "prefix": "...", "peer": "..." } ],
  "baseline_differs_from_corrected": true
}
  • best_exit — chosen egress per prefix for the baseline (as-dumped) map.
  • poisoned — every announcement whose effective stamp disagrees with the cache.
  • minimal_corrections — minimum-cardinality set of (prefix, peer) repairs that transforms the baseline map into the fully corrected map.
  • impactful_single_repairs — repairs that flip the winner on their own. A strict, possibly-empty subset of minimal_corrections (a coordinated 2-repair prefix contributes to the latter but not the former).

2. Root-cause analysis

2.1 Origin validity is a ranking attribute, placed after AS_PATH. The RPKI state must be part of the comparison, not a pre-filter that drops invalid routes — dropping hides that an invalid route was winning on local_pref. The order used (RR process extended per RFC 8097):

  1. highest LOCAL_PREF
  2. shortest AS_PATH
  3. best origin validity — valid (2) > notfound (1) > invalid (0)
  4. lowest MED
  5. lowest origin type — IGP < EGP < INCOMPLETE
  6. lexicographically smallest community set
  7. lowest peer id (deterministic tie-break)

2.2 A missing stamp must be conservative, not neutral. Mapping "missing" → invalid (worst) ensures an unstamped announcement can never outrank a stamped one. This is exactly why a single repair can flip the winner.

2.3 "Poisoned" vs "missing" are different detections. contradiction = stamp present and != cache; missing-stamp = stamp absent. Both are repairable.

2.4 Baseline and corrected are two different evaluators. Baseline = declared stamps (missing → conservative); corrected = cache truth for every path. One evaluator with a fixed peer set (the single seam through which validity resolves) serves baseline, partial repairs, and corrected map with no duplicated logic.

2.5 Minimal corrections are per-prefix independent. A stamp only changes the winner for its own prefix, so the global minimum-cardinality set is the union of per-prefix minima — no global search.

2.6 A single repair is not always sufficient. With cache invalid:

peer MED declared baseline rank
p7 5 valid 2 (wins)
p8 1 notfound 1
p9 0 invalid 0

Baseline wins p7; corrected wins p9. Fixing p7 alone → p8; fixing p8 alone → p7. Only {p7, p8} yields p9. A solver that only looks for single impactful repairs reports nothing for this prefix and misses the fix.

2.7 Determinism. No map-iteration-order ties: communities compared as sorted lists, peer id as final total-order tie-break.

// Command bgprr computes the optimal egress selection for every prefix in a BGP
// route-reflector snapshot, detects RPKI origin-validity poisoning, and derives
// the minimal set of (prefix, peer) corrections whose repair changes the global
// egress map.
//
// Input is a JSON snapshot (see snapshot.json). Output is a JSON report on
// stdout; pass -v for a human readable summary on stderr.
package main

import (
    "encoding/json"
    "flag"
    "fmt"
    "io"
    "os"
    "sort"
    "strings"
)

// ---------------------------------------------------------------------------
// Origin validity model
// ---------------------------------------------------------------------------

// State is the RPKI origin-validation state of an announcement.
type State string

const (
    StateValid    State = "valid"
    StateNotFound State = "notfound"
    StateInvalid  State = "invalid"
)

// ConservativeDefault is the validity state inherited by a path that carries no
// origin-validity stamp at all. It is deliberately the *worst* state so that an
// unknown announcement can never outrank a stamped one; repairing the stamp
// with the RPKI cache truth can therefore flip the winner.
const ConservativeDefault = StateInvalid

// rank orders validity states from best (2) to worst (0).
func (s State) rank() int {
    switch normalizeState(s) {
    case StateValid:
        return 2
    case StateNotFound:
        return 1
    case StateInvalid:
        return 0
    default:
        return -1 // unknown/garbage sorts below invalid
    }
}

func normalizeState(s State) State {
    switch strings.ToLower(strings.TrimSpace(string(s))) {
    case "valid", "v":
        return StateValid
    case "notfound", "not_found", "not-found", "nf", "unknown":
        return StateNotFound
    case "invalid", "inv", "i":
        return StateInvalid
    }
    return s
}

// ---------------------------------------------------------------------------
// Snapshot schema
// ---------------------------------------------------------------------------

// Peer describes an announcing neighbor.
type Peer struct {
    ASN      uint32 `json:"asn"`
    RouterID string `json:"router_id"`
    IBGP     bool   `json:"ibgp"`
}

// CacheEntry is one authoritative origin-validity record from the RPKI delta.
type CacheEntry struct {
    Prefix string `json:"prefix"`
    State  State  `json:"state"`
}

// Path is one competing announcement for a prefix.
type Path struct {
    Prefix      string   `json:"prefix"`
    Peer        string   `json:"peer"`
    ASPath      []uint32 `json:"as_path"`
    MED         uint32   `json:"med"`
    LocalPref   uint32   `json:"local_pref"`
    Origin      string   `json:"origin"`
    Communities []string `json:"communities"`
    // OriginStamp is the validity stamp *declared in the dump*. A nil pointer
    // means the stamp is missing and the conservative default applies.
    OriginStamp *State `json:"origin_stamp"`
}

// Snapshot is the full route-reflector dump.
type Snapshot struct {
    LocalAS   uint32          `json:"local_as"`
    Peers     map[string]Peer `json:"peers"`
    RPKICache []CacheEntry    `json:"rpki_cache"`
    Paths     []Path          `json:"paths"`
}

// ---------------------------------------------------------------------------
// Evaluation context
// ---------------------------------------------------------------------------

// evaluator resolves the effective validity state for a path. It is the single
// seam that lets us evaluate the baseline, the fully corrected map and any
// partial repair with the same comparator.
type evaluator struct {
    cache map[string]State
    // fixed holds the peers whose stamp has been repaired to the cache truth,
    // keyed by "prefix\x00peer".
    fixed map[string]bool
}

func newEvaluator(snap *Snapshot) *evaluator {
    cache := make(map[string]State, len(snap.RPKICache))
    for _, e := range snap.RPKICache {
        cache[e.Prefix] = normalizeState(e.State)
    }
    return &evaluator{cache: cache, fixed: map[string]bool{}}
}

// cacheState returns the authoritative state for a prefix. Prefixes absent from
// the delta are treated as NotFound (the standard "no ROA" outcome).
func (e *evaluator) cacheState(prefix string) State {
    if s, ok := e.cache[prefix]; ok {
        return s
    }
    return StateNotFound
}

// effective returns the validity state used for ranking.
//
//   - baseline:      declared stamp, or ConservativeDefault when missing.
//   - repaired peer: cache truth.
//   - corrected:     cache truth for every path.
func (e *evaluator) effective(p Path) State {
    key := p.Prefix + "\x00" + p.Peer
    if e.fixed[key] {
        return e.cacheState(p.Prefix)
    }
    if p.OriginStamp == nil {
        return ConservativeDefault
    }
    return normalizeState(*p.OriginStamp)
}

// corrected evaluator with every peer "fixed".
func correctedEvaluator(snap *Snapshot) *evaluator {
    e := newEvaluator(snap)
    e.fixed = map[string]bool{}
    for _, p := range snap.Paths {
        e.fixed[p.Prefix+"\x00"+p.Peer] = true
    }
    return e
}

// ---------------------------------------------------------------------------
// BGP best-path selection
// ---------------------------------------------------------------------------

// defaultLocalPref is the BGP default applied when the dump omits the attribute.
const defaultLocalPref = 100

func localPref(p Path) uint32 {
    if p.LocalPref == 0 {
        return defaultLocalPref
    }
    return p.LocalPref
}

func originOrd(o string) int {
    switch strings.ToLower(strings.TrimSpace(o)) {
    case "igp", "i":
        return 0
    case "egp", "e":
        return 1
    case "incomplete", "?":
        return 2
    }
    return 3
}

// communityLess reports whether sorted community list a is preferred over b.
// "Smaller lexicographic list wins"; fewer elements win a prefix tie.
func communityLess(a, b []string) bool {
    as := append([]string(nil), a...)
    bs := append([]string(nil), b...)
    sort.Strings(as)
    sort.Strings(bs)
    n := len(as)
    if len(bs) < n {
        n = len(bs)
    }
    for i := 0; i < n; i++ {
        if as[i] != bs[i] {
            return as[i] < bs[i]
        }
    }
    return len(as) < len(bs)
}

// better reports whether path a strictly beats path b under the standard
// route-reflector decision process extended with RPKI origin validation:
//
//  1. highest LOCAL_PREF
//  2. shortest AS_PATH
//  3. best origin-validity (valid > notfound > invalid)
//  4. lowest MED
//  5. lowest origin type (IGP < EGP < INCOMPLETE)
//  6. lexicographically smallest community set
//  7. lowest peer id (deterministic final tie-break)
func better(a, b Path, e *evaluator) bool {
    if localPref(a) != localPref(b) {
        return localPref(a) > localPref(b)
    }
    if len(a.ASPath) != len(b.ASPath) {
        return len(a.ASPath) < len(b.ASPath)
    }
    if ra, rb := e.effective(a).rank(), e.effective(b).rank(); ra != rb {
        return ra > rb
    }
    if a.MED != b.MED {
        return a.MED < b.MED
    }
    if oa, ob := originOrd(a.Origin), originOrd(b.Origin); oa != ob {
        return oa < ob
    }
    if !equalCommunities(a.Communities, b.Communities) {
        return communityLess(a.Communities, b.Communities)
    }
    return a.Peer < b.Peer
}

func equalCommunities(a, b []string) bool {
    if len(a) != len(b) {
        return false
    }
    as := append([]string(nil), a...)
    bs := append([]string(nil), b...)
    sort.Strings(as)
    sort.Strings(bs)
    for i := range as {
        if as[i] != bs[i] {
            return false
        }
    }
    return true
}

// bestPath returns the winning path for a set of contenders.
func bestPath(paths []Path, e *evaluator) (Path, bool) {
    var best Path
    found := false
    for _, p := range paths {
        if !found || better(p, best, e) {
            best = p
            found = true
        }
    }
    return best, found
}

// decidingAttribute names the first attribute on which winner beats runnerUp.
func decidingAttribute(winner, runnerUp Path, e *evaluator) string {
    if localPref(winner) != localPref(runnerUp) {
        return "local_pref"
    }
    if len(winner.ASPath) != len(runnerUp.ASPath) {
        return "as_path_length"
    }
    if e.effective(winner).rank() != e.effective(runnerUp).rank() {
        return "origin_validity"
    }
    if winner.MED != runnerUp.MED {
        return "med"
    }
    if originOrd(winner.Origin) != originOrd(runnerUp.Origin) {
        return "origin"
    }
    if !equalCommunities(winner.Communities, runnerUp.Communities) {
        return "communities"
    }
    return "peer_id"
}

// ---------------------------------------------------------------------------
// Minimal correction search
// ---------------------------------------------------------------------------

// fixableCandidates lists paths whose effective stamp disagrees with the cache
// truth and which could therefore be repaired. Deterministically ordered.
func fixableCandidates(contenders []Path, e *evaluator) []Path {
    var out []Path
    for _, p := range contenders {
        if e.effective(p) != e.cacheState(p.Prefix) {
            out = append(out, p)
        }
    }
    sort.Slice(out, func(i, j int) bool { return out[i].Peer < out[j].Peer })
    return out
}

// minimalCorrection finds the smallest subset of candidates whose joint repair
// makes the winner equal to target. Returns nil if impossible (should not
// happen, since repairing *all* candidates always reaches the corrected map).
func minimalCorrection(contenders []Path, e *evaluator, target string) []Path {
    cands := fixableCandidates(contenders, e)
    n := len(cands)
    if n == 0 {
        return nil
    }
    // For each candidate subset, simulate and check the resulting winner.
    simulate := func(idxs []int) (string, bool) {
        sim := &evaluator{cache: e.cache, fixed: map[string]bool{}}
        for k := range e.fixed {
            sim.fixed[k] = true
        }
        for _, i := range idxs {
            sim.fixed[cands[i].Prefix+"\x00"+cands[i].Peer] = true
        }
        w, ok := bestPath(contenders, sim)
        return w.Peer, ok
    }
    // Guard against combinatorial explosion; real dumps have only a handful of
    // competing paths per prefix.
    if n > 20 {
        for i := range cands {
            if peer, ok := simulate([]int{i}); ok && peer == target {
                return []Path{cands[i]}
            }
        }
        return nil
    }
    for size := 1; size <= n; size++ {
        var walk func(start int, chosen []int) []Path
        walk = func(start int, chosen []int) []Path {
            if len(chosen) == size {
                if peer, ok := simulate(chosen); ok && peer == target {
                    res := make([]Path, len(chosen))
                    for i, idx := range chosen {
                        res[i] = cands[idx]
                    }
                    return res
                }
                return nil
            }
            for i := start; i <= n-(size-len(chosen)); i++ {
                if got := walk(i+1, append(chosen, i)); got != nil {
                    return got
                }
            }
            return nil
        }
        if got := walk(0, nil); got != nil {
            return got
        }
    }
    return nil
}

// Report assembly

type Exit struct {
    Prefix     string `json:"prefix"`
    Peer       string `json:"peer"`
    LocalPref  uint32 `json:"local_pref"`
    ASPathLen  int    `json:"as_path_len"`
    MED        uint32 `json:"med"`
    Origin     string `json:"origin"`
    Stamp      State  `json:"effective_stamp"`
    CacheState State  `json:"cache_state"`
    Deciding   string `json:"deciding_attribute,omitempty"`
}

type Poison struct {
    Prefix   string `json:"prefix"`
    Peer     string `json:"peer"`
    Kind     string `json:"kind"` // contradiction | missing-stamp
    Declared State  `json:"declared,omitempty"`
    Cache    State  `json:"cache"`
}

type Pair struct {
    Prefix string `json:"prefix"`
    Peer   string `json:"peer"`
}

type Report struct {
    BestExit               []Exit   `json:"best_exit"`
    Poisoned               []Poison `json:"poisoned"`
    MinimalCorrections     []Pair   `json:"minimal_corrections"`
    ImpactfulSingleRepairs []Pair   `json:"impactful_single_repairs"`
    BaselineDiffersTarget  bool     `json:"baseline_differs_from_corrected"`
}

func groupByPrefix(paths []Path) ([]string, map[string][]Path) {
    groups := map[string][]Path{}
    for _, p := range paths {
        groups[p.Prefix] = append(groups[p.Prefix], p)
    }
    prefixes := make([]string, 0, len(groups))
    for k := range groups {
        prefixes = append(prefixes, k)
    }
    sort.Strings(prefixes)
    return prefixes, groups
}

// Analyze produces the full report for a snapshot.
func Analyze(snap *Snapshot) Report {
    base := newEvaluator(snap)
    corr := correctedEvaluator(snap)

    prefixes, groups := groupByPrefix(snap.Paths)

    var rep Report
    for _, prefix := range prefixes {
        contenders := groups[prefix]

        baseBest, ok := bestPath(contenders, base)
        if !ok {
            continue
        }
        corrBest, _ := bestPath(contenders, corr)

        // Chosen exit for the baseline map.
        exit := Exit{
            Prefix:     prefix,
            Peer:       baseBest.Peer,
            LocalPref:  localPref(baseBest),
            ASPathLen:  len(baseBest.ASPath),
            MED:        baseBest.MED,
            Origin:     baseBest.Origin,
            Stamp:      base.effective(baseBest),
            CacheState: base.cacheState(prefix),
        }
        // Runner-up (for the deciding attribute).
        var runnerUp Path
        haveRunner := false
        for _, p := range contenders {
            if p.Peer == baseBest.Peer {
                continue
            }
            if !haveRunner || better(p, runnerUp, base) {
                runnerUp = p
                haveRunner = true
            }
        }
        if haveRunner {
            exit.Deciding = decidingAttribute(baseBest, runnerUp, base)
        }
        rep.BestExit = append(rep.BestExit, exit)

        // Poison / missing-stamp inventory.
        for _, p := range contenders {
            cache := base.cacheState(prefix)
            switch {
            case p.OriginStamp == nil:
                rep.Poisoned = append(rep.Poisoned, Poison{
                    Prefix: prefix, Peer: p.Peer, Kind: "missing-stamp",
                    Cache: cache,
                })
            case normalizeState(*p.OriginStamp) != cache:
                rep.Poisoned = append(rep.Poisoned, Poison{
                    Prefix: prefix, Peer: p.Peer, Kind: "contradiction",
                    Declared: normalizeState(*p.OriginStamp), Cache: cache,
                })
            }
        }

        if baseBest.Peer == corrBest.Peer {
            continue // already consistent: no correction changes this prefix
        }
        rep.BaselineDiffersTarget = true

        // Impactful single repairs: one fix alone flips the winner.
        for _, p := range fixableCandidates(contenders, base) {
            sim := &evaluator{cache: base.cache, fixed: map[string]bool{
                p.Prefix + "\x00" + p.Peer: true,
            }}
            if w, ok := bestPath(contenders, sim); ok && w.Peer == corrBest.Peer {
                rep.ImpactfulSingleRepairs = append(rep.ImpactfulSingleRepairs, Pair{prefix, p.Peer})
            }
        }

        // Minimal correction for this prefix; prefixes are independent, so the
        // union of per-prefix minima is globally minimal by cardinality.
        for _, p := range minimalCorrection(contenders, base, corrBest.Peer) {
            rep.MinimalCorrections = append(rep.MinimalCorrections, Pair{prefix, p.Peer})
        }
    }

    sort.Slice(rep.MinimalCorrections, func(i, j int) bool {
        if rep.MinimalCorrections[i].Prefix != rep.MinimalCorrections[j].Prefix {
            return rep.MinimalCorrections[i].Prefix < rep.MinimalCorrections[j].Prefix
        }
        return rep.MinimalCorrections[i].Peer < rep.MinimalCorrections[j].Peer
    })
    sort.Slice(rep.ImpactfulSingleRepairs, func(i, j int) bool {
        if rep.ImpactfulSingleRepairs[i].Prefix != rep.ImpactfulSingleRepairs[j].Prefix {
            return rep.ImpactfulSingleRepairs[i].Prefix < rep.ImpactfulSingleRepairs[j].Prefix
        }
        return rep.ImpactfulSingleRepairs[i].Peer < rep.ImpactfulSingleRepairs[j].Peer
    })
    return rep
}

func readSnapshot(r io.Reader) (*Snapshot, error) {
    dec := json.NewDecoder(r)
    dec.DisallowUnknownFields()
    var snap Snapshot
    if err := dec.Decode(&snap); err != nil {
        return nil, fmt.Errorf("decode snapshot: %w", err)
    }
    if snap.Paths == nil {
        return nil, fmt.Errorf("snapshot has no paths")
    }
    return &snap, nil
}

func printTable(w io.Writer, rep Report) {
    fmt.Fprintln(w, "prefix                          chosen peer     deciding attr")
    fmt.Fprintln(w, "------------------------------  --------------  ----------------")
    for _, x := range rep.BestExit {
        fmt.Fprintf(w, "%-30s  %-14s  %s\n", x.Prefix, x.Peer, x.Deciding)
    }
    fmt.Fprintln(w)
    fmt.Fprintln(w, "poisoned / missing announcements:")
    if len(rep.Poisoned) == 0 {
        fmt.Fprintln(w, "  (none)")
    }
    for _, p := range rep.Poisoned {
        if p.Kind == "missing-stamp" {
            fmt.Fprintf(w, "  %-30s  %-14s  missing  (cache=%s)\n", p.Prefix, p.Peer, p.Cache)
        } else {
            fmt.Fprintf(w, "  %-30s  %-14s  declared=%s cache=%s\n", p.Prefix, p.Peer, p.Declared, p.Cache)
        }
    }
    fmt.Fprintln(w)
    fmt.Fprintln(w, "minimal corrections that change the global egress map:")
    if len(rep.MinimalCorrections) == 0 {
        fmt.Fprintln(w, "  (none)")
    }
    for _, c := range rep.MinimalCorrections {
        fmt.Fprintf(w, "  %s via %s\n", c.Prefix, c.Peer)
    }
}

func main() {
    inPath := flag.String("in", "-", "snapshot JSON file, or - for stdin")
    verbose := flag.Bool("v", false, "print a human readable summary to stderr")
    flag.Parse()

    var r io.Reader = os.Stdin
    if *inPath != "-" {
        f, err := os.Open(*inPath)
        if err != nil {
            fmt.Fprintln(os.Stderr, "error:", err)
            os.Exit(1)
        }
        defer f.Close()
        r = f
    }

    snap, err := readSnapshot(r)
    if err != nil {
        fmt.Fprintln(os.Stderr, "error:", err)
        os.Exit(1)
    }

    rep := Analyze(snap)

    enc := json.NewEncoder(os.Stdout)
    enc.SetIndent("", "  ")
    if err := enc.Encode(rep); err != nil {
        fmt.Fprintln(os.Stderr, "error:", err)
        os.Exit(1)
    }
    if *verbose {
        printTable(os.Stderr, rep)
    }
}

package main

import (
    "os"
    "sort"
    "testing"
)

func stamp(s State) *State { return &s }

func mustPeer(t *testing.T, snap *Snapshot, prefix, peer string) {
    t.Helper()
    _, groups := groupByPrefix(snap.Paths)
    e := newEvaluator(snap)
    best, ok := bestPath(groups[prefix], e)
    if !ok {
        t.Fatalf("prefix %s: no paths", prefix)
    }
    if best.Peer != peer {
        t.Fatalf("prefix %s: baseline best = %s, want %s", prefix, best.Peer, peer)
    }
}

// TestConservativeDefaultFlipsWinner is the core "missing stamp" case: a path
// with no stamp defaults to invalid (conservative), loses, and a *single*
// repair of that stamp makes it win.
func TestConservativeDefaultFlipsWinner(t *testing.T) {
    snap := &Snapshot{
        RPKICache: []CacheEntry{{Prefix: "<ip-address>/24", State: StateValid}},
        Paths: []Path{
            {Prefix: "<ip-address>/24", Peer: "<ip-address>", ASPath: []uint32{65001, 64496}, MED: 10, LocalPref: 100, Origin: "igp", OriginStamp: stamp(StateValid)},
            {Prefix: "<ip-address>/24", Peer: "<ip-address>", ASPath: []uint32{65002, 64497}, MED: 5, LocalPref: 100, Origin: "igp"},
        },
    }
    rep := Analyze(snap)
    if got := rep.BestExit[0].Peer; got != "<ip-address>" {
        t.Fatalf("baseline winner = %s, want <ip-address> (missing stamp must be conservative)", got)
    }
    wantCorr := []Pair{{"<ip-address>/24", "<ip-address>"}}
    if !equalPairs(rep.MinimalCorrections, wantCorr) {
        t.Fatalf("minimal corrections = %v, want %v", rep.MinimalCorrections, wantCorr)

// TestAttributeOrdering pins the decision process order.
func TestAttributeOrdering(t *testing.T) {
    base := Path{Prefix: "p", Peer: "a", ASPath: []uint32{1, 2}, MED: 7, LocalPref: 100, Origin: "incomplete", OriginStamp: stamp(StateNotFound)}
    cases := []struct {
        name   string
        mutate func(Path) Path
        want   string
    }{
        {"higher local_pref", func(p Path) Path { p.LocalPref = 200; return p }, "local_pref"},
        {"shorter as_path", func(p Path) Path { p.ASPath = []uint32{1}; return p }, "as_path_length"},
        {"better validity", func(p Path) Path { p.OriginStamp = stamp(StateValid); return p }, "origin_validity"},
        {"lower med", func(p Path) Path { p.MED = 3; return p }, "med"},
        {"better origin", func(p Path) Path { p.Origin = "igp"; return p }, "origin"},
    }
    for _, tc := range cases {
        t.Run(tc.name, func(t *testing.T) {
            e := newEvaluator(&Snapshot{})
            // base is the incumbent; the mutated challenger must win.
            challenger := tc.mutate(base)
            challenger.Peer = "b"
            if !better(challenger, base, e) {
                t.Fatalf("challenger did not beat incumbent")
            }
            if got := decidingAttribute(challenger, base, e); got != tc.want {
                t.Fatalf("deciding attribute = %s, want %s", got, tc.want)
            }
        })
    }
}

// TestMinimalityByBruteForce independently re-derives, for every prefix, the
// minimum number of repairs needed to reach the fully corrected winner using a
// separate exhaustive enumeration. It also proves the reported repairs actually
// reproduce the corrected map when applied together.
func TestMinimalityByBruteForce(t *testing.T) {
    f, err := os.Open("snapshot.json")
    if err != nil {
        t.Fatal(err)
    }
    defer f.Close()
    snap, err := readSnapshot(f)
    if err != nil {
        t.Fatal(err)
    }
    rep := Analyze(snap)

    // Count reported corrections per prefix.
    reported := map[string]int{}
    for _, c := range rep.MinimalCorrections {
        reported[c.Prefix]++
    }

    base := newEvaluator(snap)
    corr := correctedEvaluator(snap)
    _, groups := groupByPrefix(snap.Paths)

    for prefix, contenders := range groups {
        target, ok := bestPath(contenders, corr)
        if !ok {
            continue
        }
        var cands []Path
        for _, p := range contenders {
            if base.effective(p) != base.cacheState(prefix) {
                cands = append(cands, p)
            }
        }
        best := -1
        for mask := 0; mask < (1 << len(cands)); mask++ {
            sim := newEvaluator(snap)
            for i, p := range cands {
                if mask&(1<<i) != 0 {
                    sim.fixed[p.Prefix+"\x00"+p.Peer] = true
                }
            }
            w, ok := bestPath(contenders, sim)
            if !ok || w.Peer != target.Peer {
                continue
            }
            bits := 0
            for m := mask; m > 0; m >>= 1 {
                bits += m & 1
            }
            if best == -1 || bits < best {
                best = bits
            }
        }
        if best == -1 {
            best = 0
        }
        if reported[prefix] != best {
            t.Errorf("prefix %s: reported %d corrections, true minimum %d", prefix, reported[prefix], best)
        }
    }

    // Applying every reported correction must reproduce the corrected map.
    apply := newEvaluator(snap)
    for _, c := range rep.MinimalCorrections {
        apply.fixed[c.Prefix+"\x00"+c.Peer] = true
    }
    for prefix, contenders := range groups {
        got, _ := bestPath(contenders, apply)
        want, _ := bestPath(contenders, corr)
        if got.Peer != want.Peer {
            t.Errorf("prefix %s: applying corrections gives %s, corrected map gives %s", prefix, got.Peer, want.Peer)
        }
    }
}

func equalPairs(a, b []Pair) bool {
    if len(a) != len(b) {
        return false
    }
    as := append([]Pair(nil), a...)
    bs := append([]Pair(nil), b...)
    sort.Slice(as, func(i, j int) bool { return as[i].Prefix+as[i].Peer < as[j].Prefix+as[j].Peer })
    sort.Slice(bs, func(i, j int) bool { return bs[i].Prefix+bs[i].Peer < bs[j].Prefix+bs[j].Peer })
    for i := range as {
        if as[i] != bs[i] {
            return false
        }
    }
    return true
}

5.3 Complexity

  • Best-path selection: O(P · A) per prefix — linear.
  • Poison scan: O(paths).
  • Minimal correction: exponential only in the number of conflicting paths per prefix (typically ≤ 4); prefixes are independent, so the global result is exact with no combined blow-up.
