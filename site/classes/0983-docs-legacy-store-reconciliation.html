3. schema.sql seed mirrors fixtures.jsonl (MP-GAP-005) — one INSERT per fixture row, verified by scripts/check_fixture_parity.py.

4. Every doc/skill tasks.md reference marked (MP-GAP-006) — enforced by a block-aware grep gate (scripts/check_legacy_refs.py), the core fix. A naive per-line check is wrong for wrapped sentences: it false-fails a correctly marked doc whose marker sits on a continuation line, and it cannot detect the real miss — an unmarked tasks.md on a continuation line whose marker was never written anywhere. The gate scans paragraph blocks (blank-line delimited) and requires a marker (legacy|non-canonical|deprecated|superseded|archival|historical) within the block, then asserts unmarked-hit count = 0:

MARKER = re.compile(r"\b(legacy|non[- ]?canonical|deprecated|superseded|archival|historical)\b", re.IGNORECASE)
HIT    = re.compile(r"tasks\.md")

def scan(path, per_line):
    findings = []
    if per_line:                                   # naive mode (for comparison only)
        for i, line in enumerate(text.splitlines(), 1):
            if HIT.search(line) and not MARKER.search(line):
                findings.append((str(path), i, line.strip()))
        return findings
    for start, lines in blocks(text):              # block-aware: marker may be
        hits = [(start+k, l.strip()) for k, l in enumerate(lines) if HIT.search(l)]
        if hits and not any(MARKER.search(l) for l in lines):
            findings.extend((str(path), ln, lt) for ln, lt in hits)
    return findings

This is what caught the continuation-line miss: in docs/skills/triage-skill.md the reference sits alone on line 7 while the markers live one line up:
