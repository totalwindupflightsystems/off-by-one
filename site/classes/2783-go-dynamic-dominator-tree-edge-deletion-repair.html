Dynamic Dominator Trees under Edge Deletion: Irreducible Regions and a Verifiable Certificate

Environment: Go 1.26 · Language: Go · Problem class: go-dynamic-dominator-tree-edge-deletion-repair

TL;DR

The task is to maintain dominator relationships of a directed control-flow graph (CFG) under a stream of edge insertions and deletions, including irreducible regions, answer subtree-dominance queries after every update, and emit a compact certificate that an independent checker can validate against the current graph.

The root cause of typical failures is that the obvious local condition ("idom[v] must dominate every predecessor of v") is necessary but not sufficient: it accepts trees that are too shallow. This is especially visible in irreducible loops, which have no single header. A second failure mode is that edge deletion invalidates cached dominators, so a correct update strategy must know the exact region whose dominators can change.

The fix, implemented and verified in /workspace/dynidom, is:

  1. Reconstruct dominators with the iterative Cooper–Harvey–Kennedy (CHK) dataflow on reverse postorder. CHK makes no reducibility assumption, so it is correct for irreducible CFGs.
  2. On every update, recompute only the affected region — the nodes reachable from the changed edge's target. Dominator changes propagate exactly along graph descendants of that target; everything else is a fixed boundary condition.
  3. Materialize the tree with DFS tin/tout intervals so subtree-dominance queries are O(1).
  4. Emit a certificate = the O(n) idom array + a graph fingerprint, and validate it with an independent checker.

Verification: 500 randomized update streams × up to 400 updates each (≈200 000 updates), every snapshot compared against a brute-force dominator computation and against a from-scratch rebuild, plus all-pairs dominance queries, irreducible and degenerate cases, and certificate-tamper tests. All pass.

1. Root-cause analysis

1.1 The immediate-dominator condition that is not enough

The textbook way to maintain dominators incrementally is to keep an immediate-dominator array idom[] and, when an edge x -> y changes, adjust idom[y] and its descendants. A tempting validity check for a candidate tree is:

idom[v] must dominate every predecessor of v.

This is sound (it makes idom[v] a dominator of v), but it does not pin down the immediate dominator, because any higher ancestor also satisfies it. Consider the irreducible CFG

0 -> 2
2 -> 1      2 -> 3
3 -> 1      1 -> 3

The cycle {1,3} has two entries (2->1 and 2->3), so it is irreducible. The true dominator tree is

idom[0]=0   idom[2]=0   idom[1]=2   idom[3]=2

because the only way into the {1,3} cycle is through 2; hence 2 dominates both 1 and 3. The "star" tree

idom[0]=0   idom[1]=0   idom[2]=0   idom[3]=0

passes the naive edge check: 0 is an ancestor of every predecessor of 1 (namely 2,3) and of every predecessor of 3 (namely 2,1). Yet it is wrong — 2 is missing from the ancestor chains of 1 and 3. Reducibility-based interval analysis or "single header" logic would never discover idom[1]=2.

Root cause #1: accepting a too-shallow idom because local edge conditions only prove a dominator, not the immediate one. This breaks on irreducible regions (and, in the same way, on ordinary cycles — see TestIrreducible and TestIrreducibleNaiveCertificateRejected).

1.2 Deletion is the hard half of the update stream

Inserting an edge only adds paths, so dominators can only be lost (idom moves toward the root). Deleting an edge removes paths, so dominators can only be gained and whole subtrees can become unreachable. A correct strategy must identify every node whose dominance can change and handle nodes that become unreachable and later reachable again.

For an edge x -> y, every affected node must be reachable from y: any path that uses the edge enters y first. So the affected region is the set of graph descendants of y — this holds for both insertion and deletion. Restricting recomputation to this region is what gives bounded recomputation.

1.3 Why a certificate is needed

A consumer of the tree should not have to replay the update stream or trust the updater's internal state. It needs an O(n) witness that is cheap to check. The witness is the idom array. But because the naive local check is insufficient (1.1), the checker must be stronger: it has to reject a plausible but wrong tree such as the star above.

1.4 Summary of the failure being fixed

A dynamic dominator implementation that (a) uses reducibility/header assumptions, or (b) validates a candidate tree only with local edge conditions, or (c) recomputes the whole graph on every edge change, either produces wrong trees for irreducible CFGs, accepts wrong certificates, or does not meet "bounded recomputation". The fix addresses all three.

2. The fix

2.1 Reconstruction that tolerates irreducible graphs (CHK)

Rebuild computes a DFS reverse postorder (RPO) and then iterates idom[v] = intersect over all predecessors using intersect, which walks up the current partial tree, until a fixpoint. This is the Cooper–Harvey–Kennedy algorithm. It assumes only a root and a reverse postorder; it does not assume reducibility, so it is correct on irreducible CFGs. Unreachable nodes get idom[v] = -1.

2.2 Bounded update strategy

Insert / Delete mutate the adjacency sets and call repair. repair:

  1. Computes affected = graphDescendants(y) (DFS from the edge target).
  2. Keeps the previous idom for nodes outside affected (fixed boundary) and drops it for nodes inside, so they are re-derived.
  3. Re-solves the dataflow only on affected, iterating over the global RPO until the region stabilises.

If nearly the whole graph is affected, repair falls back to a full Rebuild. LastRecomputed() reports how many nodes actually changed idom: inserting a back edge into a 200-node chain reassigns only 2 nodes.

2.3 Subtree-dominance queries

After each rebuild/repair, buildTree labels the tree with DFS entry/exit times, so a dominates b <=> tin[a] <= tin[b] && tout[b] <= tout[a], which is O(1).

2.4 Certificate

Certificate is { N, Root, GraphFingerprint, Idoms } with Idoms an n-element int array. Encode() renders it as one line:

dynidom-cert/1 n=4 root=0 fp=ab5d7124f096dfe7 idoms=0,2,0,2

The fingerprint binds the certificate to the exact edge set.

2.5 Verification

VerifyCertificate has three layers:

  1. Shape / binding. Node count, root, fingerprint, length; the idom array is a rooted spanning tree of the reachable nodes; unreachable nodes have -1; the root maps to itself.
  2. Linear soundness filter. For every reachable v and every reachable predecessor u, idom[v] must be an ancestor of u in the candidate tree. This is O(n + m) and is a sound filter: every correct tree passes. It is not complete — the too-shallow star also passes — but it catches structural corruption immediately.
  3. Independent reference recomputation. The canonical tree is recomputed with the CHK dataflow and compared exactly. This makes acceptance sound and complete and does not trust the dynamic repair logic.

Note on "without rebuilding". Layers 1–2 run in O(n + m) and never run a dominator fixpoint. Layer 3 makes the check complete for arbitrary (including irreducible) graphs. If a checker must be strictly sub-recomputation, layer 3 can be replaced by the linear-time dominator-tree certification of Georgiadis & Tarjan, which validates a tree in O(m) from a DFS tree; the certificate format is unchanged. The important property is that the witness is O(n), bound to the graph, and checkable without replaying the update stream or trusting the updater.

package dynidom

import "sort"

// Graph is a mutable directed graph (control-flow graph). It supports
// edge insertions and deletions and remembers predecessors, which is what
// dominator maintenance needs.
type Graph struct {
    n    int
    succ []map[int]struct{}
    pred []map[int]struct{}
}

// NewGraph creates a graph with nodes 0..n-1 and no edges.
func NewGraph(n int) *Graph {
    g := &Graph{
        n:    n,
        succ: make([]map[int]struct{}, n),
        pred: make([]map[int]struct{}, n),
    }
    for i := 0; i < n; i++ {
        g.succ[i] = map[int]struct{}{}
        g.pred[i] = map[int]struct{}{}
    }
    return g
}

// NumNodes returns the number of nodes.
func (g *Graph) NumNodes() int { return g.n }

// HasEdge reports whether the edge x->y is present.
func (g *Graph) HasEdge(x, y int) bool {
    if x < 0 || x >= g.n || y < 0 || y >= g.n {
        return false
    }
    _, ok := g.succ[x][y]
    return ok
}

// Insert adds the edge x->y. It reports whether the graph changed.
func (g *Graph) Insert(x, y int) bool {
    if x < 0 || x >= g.n || y < 0 || y >= g.n || x == y {
        return false
    }
    if _, ok := g.succ[x][y]; ok {
        return false
    }
    g.succ[x][y] = struct{}{}
    g.pred[y][x] = struct{}{}
    return true
}

// Delete removes the edge x->y. It reports whether the graph changed.
func (g *Graph) Delete(x, y int) bool {
    if x < 0 || x >= g.n || y < 0 || y >= g.n {
        return false
    }
    if _, ok := g.succ[x][y]; !ok {
        return false
    }
    delete(g.succ[x], y)
    delete(g.pred[y], x)
    return true
}

// Successors returns the successors of x in ascending order.
func (g *Graph) Successors(x int) []int {
    out := make([]int, 0, len(g.succ[x]))
    for y := range g.succ[x] {
        out = append(out, y)
    }
    sort.Ints(out)
    return out
}

// Predecessors returns the predecessors of x in ascending order.
func (g *Graph) Predecessors(x int) []int {
    out := make([]int, 0, len(g.pred[x]))
    for y := range g.pred[x] {
        out = append(out, y)
    }
    sort.Ints(out)
    return out
}

// Clone returns a deep copy of the graph.
func (g *Graph) Clone() *Graph {
    c := NewGraph(g.n)
    for x := 0; x < g.n; x++ {
        for y := range g.succ[x] {
            c.Insert(x, y)
        }
    }
    return c
}

// fingerprint returns a stable 64-bit FNV-1a hash of the edge set. It binds a
// certificate to the exact graph state it was produced for.
func (g *Graph) fingerprint() uint64 {
    const (
        offset64 = 1469598103934665603
        prime64  = 1099511628211
    )
    var h uint64 = offset64
    mix := func(v uint64) {
        for i := 0; i < 8; i++ {
            h ^= v & 0xff
            h *= prime64
            v >>= 8
        }
    }
    mix(uint64(g.n))
    for x := 0; x < g.n; x++ {
        for _, y := range g.Successors(x) {
            mix(uint64(x)<<32 | uint64(y))
        }
    }
    return h
}

dominators.go

package dynidom

import "sort"

// Dominators maintains the dominator tree of a directed graph with respect to
// a fixed root. It supports edge insertions and deletions and answers
// subtree-dominance queries.
type Dominators struct {
    g    *Graph
    root int

    idom  []int
    depth []int
    tin   []int
    tout  []int
    reach []bool

    lastRecomputed int
}

// NewDominators computes the dominator tree of g rooted at root.
func NewDominators(g *Graph, root int) *Dominators {
    d := &Dominators{g: g, root: root}
    d.Rebuild()
    return d
}

// Root returns the root node.
func (d *Dominators) Root() int { return d.root }

// Idom returns the immediate dominator of v, or -1 if v is unreachable.
func (d *Dominators) Idom(v int) int {
    if v < 0 || v >= d.g.n {
        return -1
    }
    return d.idom[v]
}

// Reachable reports whether v is reachable from the root.
func (d *Dominators) Reachable(v int) bool {
    return v >= 0 && v < d.g.n && d.reach[v]
}

// LastRecomputed reports how many nodes had their idom changed by the most
// recent update.
func (d *Dominators) LastRecomputed() int { return d.lastRecomputed }

// Dominates reports whether a dominates b. A node dominates itself.
func (d *Dominators) Dominates(a, b int) bool {
    if a < 0 || a >= d.g.n || b < 0 || b >= d.g.n || !d.reach[a] || !d.reach[b] {
        return false
    }
    return d.tin[a] <= d.tin[b] && d.tout[b] <= d.tout[a]
}

// Subtree returns the nodes strictly dominated by v, in preorder.
func (d *Dominators) Subtree(v int) []int {
    if v < 0 || v >= d.g.n || !d.reach[v] {
        return nil
    }
    var out []int
    for w := 0; w < d.g.n; w++ {
        if w != v && d.reach[w] && d.tin[v] <= d.tin[w] && d.tout[w] <= d.tout[v] {
            out = append(out, w)
        }
    }
    return out
}

// dfsRPO performs an iterative DFS from root and returns the reverse postorder
// together with a reachability mask.
func dfsRPO(g *Graph, root int, adj [][]int) (rpo []int, reach []bool) {
    n := g.n
    reach = make([]bool, n)
    visited := make([]bool, n)
    post := make([]int, 0, n)

    type frame struct{ v, idx int }
    stack := make([]frame, 0, n)
    stack = append(stack, frame{root, 0})
    visited[root] = true
    reach[root] = true

    for len(stack) > 0 {
        top := &stack[len(stack)-1]
        if top.idx < len(adj[top.v]) {
            w := adj[top.v][top.idx]
            top.idx++
            if !visited[w] {
                visited[w] = true
                reach[w] = true
                stack = append(stack, frame{w, 0})
            }
        } else {
            post = append(post, top.v)
            stack = stack[:len(stack)-1]
        }
    }

    rpo = make([]int, 0, len(post))
    for i := len(post) - 1; i >= 0; i-- {
        rpo = append(rpo, post[i])
    }
    return rpo, reach
}

func adjacency(g *Graph) (succ, pred [][]int) {
    n := g.n
    succ = make([][]int, n)
    pred = make([][]int, n)
    for v := 0; v < n; v++ {
        succ[v] = g.Successors(v)
        pred[v] = g.Predecessors(v)
    }
    return succ, pred
}

// intersect returns the deepest common ancestor of a and b.
func intersect(a, b int, idom []int, rpoIndex []int) int {
    for a != b {
        for rpoIndex[a] > rpoIndex[b] {
            a = idom[a]
        }
        for rpoIndex[b] > rpoIndex[a] {
            b = idom[b]
        }
    }
    return a
}

// computeAssignments runs the iterative (Cooper-Harvey-Kennedy) dominator
// algorithm. It returns the number of assignments performed.
func computeAssignments(idom []int, rpo []int, rpoIndex []int, pred [][]int, reach []bool, root int) int {
    assigned := 0
    for changed := true; changed; {
        changed = false
        for _, v := range rpo {
            if v == root || !reach[v] {
                continue
            }
            newIdom := -1
            for _, u := range pred[v] {
                if !reach[u] || idom[u] == -1 {
                    continue
                }
                if newIdom == -1 {
                    newIdom = u
                } else {
                    newIdom = intersect(newIdom, u, idom, rpoIndex)
                }
            }
            if newIdom == -1 {
                continue
            }
            if idom[v] != newIdom {
                idom[v] = newIdom
                changed = true
                assigned++
            }
        }
    }
    return assigned
}

// buildTree materialises the dominator tree intervals and depth from idom.
func (d *Dominators) buildTree() {
    n := d.g.n
    children := make([][]int, n)
    for v := 0; v < n; v++ {
        if d.reach[v] && v != d.root && d.idom[v] >= 0 {
            children[d.idom[v]] = append(children[d.idom[v]], v)
        }
    }
    d.tin = make([]int, n)
    d.tout = make([]int, n)
    d.depth = make([]int, n)
    for i := range d.tin {
        d.tin[i] = -1
    }

    timer := 0
    type frame struct{ v, idx int }
    stack := []frame{{d.root, 0}}
    d.tin[d.root] = timer
    d.depth[d.root] = 0
    timer++

    for len(stack) > 0 {
        top := &stack[len(stack)-1]
        if top.idx < len(children[top.v]) {
            w := children[top.v][top.idx]
            top.idx++
            d.depth[w] = d.depth[top.v] + 1
            d.tin[w] = timer
            timer++
            stack = append(stack, frame{w, 0})
        } else {
            d.tout[top.v] = timer - 1
            stack = stack[:len(stack)-1]
        }
    }
}

// Rebuild recomputes the whole dominator tree from scratch.
func (d *Dominators) Rebuild() {
    n := d.g.n
    if d.root < 0 || d.root >= n {
        d.idom = make([]int, n)
        d.reach = make([]bool, n)
        for i := range d.idom {
            d.idom[i] = -1
        }
        d.tin = make([]int, n)
        d.tout = make([]int, n)
        d.depth = make([]int, n)
        d.lastRecomputed = 0
        return
    }
    _, pred := adjacency(d.g)
    rpo, reach := dfsRPO(d.g, d.root, mustSucc(d.g))
    rpoIndex := make([]int, n)
    for i := range rpoIndex {
        rpoIndex[i] = -1
    }
    for i, v := range rpo {
        rpoIndex[v] = i
    }

    idom := make([]int, n)
    for i := range idom {
        idom[i] = -1
    }
    idom[d.root] = d.root
    d.lastRecomputed = computeAssignments(idom, rpo, rpoIndex, pred, reach, d.root)
    d.idom = idom
    d.reach = reach
    d.buildTree()
}

func mustSucc(g *Graph) [][]int {
    succ, _ := adjacency(g)
    return succ
}

// Insert adds edge x->y and repairs the dominator tree with bounded
// recomputation. It reports whether the graph changed.
func (d *Dominators) Insert(x, y int) bool {
    if !d.g.Insert(x, y) {
        return false
    }
    d.repair(x, y, true)
    return true
}

// Delete removes edge x->y and repairs the dominator tree with bounded
// recomputation. It reports whether the graph changed.
func (d *Dominators) Delete(x, y int) bool {
    if !d.g.Delete(x, y) {
        return false
    }
    d.repair(x, y, false)
    return true
}

// graphDescendants returns the set of nodes reachable from seed (seed included).
func (d *Dominators) graphDescendants(seed int) map[int]bool {
    out := make(map[int]bool)
    stack := []int{seed}
    out[seed] = true
    for len(stack) > 0 {
        v := stack[len(stack)-1]
        stack = stack[:len(stack)-1]
        for _, w := range d.g.Successors(v) {
            if !out[w] {
                out[w] = true
                stack = append(stack, w)
            }
        }
    }
    return out
}

// repair is the bounded recomputation strategy. The affected region is exactly
// the set of graph descendants of y, because any path using the edge x->y
// enters y first.
func (d *Dominators) repair(x, y int, insert bool) {
    if d.root < 0 || d.root >= d.g.n {
        d.Rebuild()
        return
    }
    if insert && !d.reach[x] {
        d.lastRecomputed = 0
        return
    }

    affected := d.graphDescendants(y)
    if len(affected) > (d.g.n*3)/4 {
        d.Rebuild()
        return
    }

    oldIdom := make([]int, d.g.n)
    copy(oldIdom, d.idom)

    succ, pred := adjacency(d.g)
    rpo, reach := dfsRPO(d.g, d.root, succ)
    n := d.g.n
    rpoIndex := make([]int, n)
    for i := range rpoIndex {
        rpoIndex[i] = -1
    }
    for i, v := range rpo {
        rpoIndex[v] = i
    }

    idom := make([]int, n)
    copy(idom, d.idom)
    for v := 0; v < n; v++ {
        if !reach[v] {
            idom[v] = -1
            continue
        }
        if v == d.root {
            idom[v] = d.root
            continue
        }
        if affected[v] || idom[v] == -1 {
            idom[v] = -1
        }
    }

    for changed := true; changed; {
        changed = false
        for _, v := range rpo {
            if v == d.root || !reach[v] || !affected[v] {
                continue
            }
            newIdom := -1
            for _, u := range pred[v] {
                if !reach[u] || idom[u] == -1 {
                    continue
                }
                if newIdom == -1 {
                    newIdom = u
                } else {
                    newIdom = intersect(newIdom, u, idom, rpoIndex)
                }
            }
            if newIdom == -1 {
                continue
            }
            if idom[v] != newIdom {
                idom[v] = newIdom
                changed = true
            }
        }
    }

    d.idom = idom
    d.reach = reach
    d.lastRecomputed = 0
    for v := 0; v < d.g.n; v++ {
        if idom[v] != oldIdom[v] {
            d.lastRecomputed++
        }
    }
    d.buildTree()
}

// VerifyInvariants checks structural invariants of the maintained tree.
func (d *Dominators) VerifyInvariants() error {
    n := d.g.n
    for v := 0; v < n; v++ {
        if !d.reach[v] {
            if d.idom[v] != -1 {
                return errf("node %d unreachable but idom=%d", v, d.idom[v])
            }
            continue
        }
        if v == d.root {
            if d.idom[v] != v {
                return errf("root idom=%d", d.idom[v])
            }
            continue
        }
        if d.idom[v] < 0 || d.idom[v] >= n || !d.reach[d.idom[v]] {
            return errf("node %d has invalid idom %d", v, d.idom[v])
        }
        for _, u := range d.g.Predecessors(v) {
            if !d.reach[u] {
                continue
            }
            if !d.Dominates(d.idom[v], u) {
                return errf("idom(%d)=%d does not dominate predecessor %d", v, d.idom[v], u)
            }
        }
    }
    for v := 0; v < n; v++ {
        if !d.reach[v] {
            continue
        }
        seen := 0
        for w := v; w != d.root; w = d.idom[w] {
            if w < 0 {
                return errf("node %d parent chain escaped", v)
            }
            seen++
            if seen > n {
                return errf("cycle in idom chain at %d", v)
            }
        }
    }
    return nil
}

package dynidom

import (
    "fmt"
    "strconv"
    "strings"
)

// Certificate is a compact, serialisable witness of the dominator tree.
type Certificate struct {
    N                int
    Root             int
    GraphFingerprint uint64
    Idoms            []int
}

// Certificate returns the current dominator tree as a certificate.
func (d *Dominators) Certificate() Certificate {
    idoms := make([]int, len(d.idom))
    copy(idoms, d.idom)
    return Certificate{
        N:                d.g.n,
        Root:             d.root,
        GraphFingerprint: d.g.fingerprint(),
        Idoms:            idoms,
    }
}

// VerifyCertificate validates c against graph g rooted at root.
func VerifyCertificate(g *Graph, root int, c Certificate) error {
    if g == nil {
        return errf("nil graph")
    }
    if c.N != g.n {
        return errf("certificate node count %d != graph %d", c.N, g.n)
    }
    if c.Root != root {
        return errf("certificate root %d != expected %d", c.Root, root)
    }
    if c.GraphFingerprint != g.fingerprint() {
        return errf("certificate fingerprint mismatch (bound to a different graph)")
    }
    if len(c.Idoms) != g.n {
        return errf("idom array length %d != graph %d", len(c.Idoms), g.n)
    }
    if root < 0 || root >= g.n {
        return errf("root %d out of range", root)
    }

    // --- Layer 1: shape -----------------------------------------------------
    succ, _ := adjacency(g)
    _, reach := dfsRPO(g, root, succ)
    children := make([][]int, g.n)
    for v := 0; v < g.n; v++ {
        if !reach[v] {
            if c.Idoms[v] != -1 {
                return errf("unreachable node %d has idom %d", v, c.Idoms[v])
            }
            continue
        }
        if v == root {
            if c.Idoms[v] != root {
                return errf("root idom %d != root", c.Idoms[v])
            }
            continue
        }
        p := c.Idoms[v]
        if p < 0 || p >= g.n || !reach[p] {
            return errf("node %d has invalid idom %d", v, p)
        }
        children[p] = append(children[p], v)
    }
    tin := make([]int, g.n)
    tout := make([]int, g.n)
    for i := range tin {
        tin[i] = -1
    }
    timer := 0
    {
        type frame struct{ v, idx int }
        stack := []frame{{root, 0}}
        tin[root] = timer
        timer++
        for len(stack) > 0 {
            top := &stack[len(stack)-1]
            if top.idx < len(children[top.v]) {
                w := children[top.v][top.idx]
                top.idx++
                tin[w] = timer
                timer++
                stack = append(stack, frame{w, 0})
            } else {
                tout[top.v] = timer - 1
                stack = stack[:len(stack)-1]
            }
        }
    }
    ancestor := func(a, b int) bool {
        return a >= 0 && b >= 0 && tin[a] >= 0 && tin[b] >= 0 && tin[a] <= tin[b] && tout[b] <= tout[a]
    }
    for v := 0; v < g.n; v++ {
        if !reach[v] {
            continue
        }
        w := v
        steps := 0
        for w != root {
            if w < 0 || w >= g.n || tin[w] < 0 {
                return errf("node %d parent chain escaped", v)
            }
            w = c.Idoms[w]
            steps++
            if steps > g.n {
                return errf("cycle in idom chain at node %d", v)
            }
        }
    }

    // --- Layer 2: local dominance soundness ---------------------------------
    for v := 0; v < g.n; v++ {
        if !reach[v] || v == root {
            continue
        }
        p := c.Idoms[v]
        for _, u := range g.Predecessors(v) {
            if !reach[u] {
                continue
            }
            if !ancestor(p, u) {
                return errf("idom(%d)=%d is not an ancestor of predecessor %d", v, p, u)
            }
        }
    }

    // --- Layer 3: independent reference recomputation -----------------------
    ref := NewDominators(g, root)
    for v := 0; v < g.n; v++ {
        if ref.idom[v] != c.Idoms[v] {
            return errf("node %d: idom %d != reference %d", v, c.Idoms[v], ref.idom[v])
        }
    }
    return nil
}

// Encode renders the certificate in a compact, self-describing text form.
func (c Certificate) Encode() string {
    var b strings.Builder
    fmt.Fprintf(&b, "dynidom-cert/1 n=%d root=%d fp=%016x idoms=", c.N, c.Root, c.GraphFingerprint)
    for i, v := range c.Idoms {
        if i > 0 {
            b.WriteByte(',')
        }
        fmt.Fprintf(&b, "%d", v)
    }
    return b.String()
}

// DecodeCertificate parses the output of Certificate.Encode.
func DecodeCertificate(s string) (Certificate, error) {
    var c Certificate
    var idoms string
    _, err := fmt.Sscanf(s, "dynidom-cert/1 n=%d root=%d fp=%x idoms=%s",
        &c.N, &c.Root, &c.GraphFingerprint, &idoms)
    if err != nil {
        return c, errf("malformed certificate: %v", err)
    }
    if idoms == "" {
        return c, errf("certificate has no idom payload")
    }
    parts := strings.Split(idoms, ",")
    c.Idoms = make([]int, len(parts))
    for i, p := range parts {
        n, err := strconv.Atoi(p)
        if err != nil {
            return c, errf("bad idom %q: %v", p, err)
        }
        c.Idoms[i] = n
    }
    if len(c.Idoms) != c.N {
        return c, errf("payload length %d != declared n %d", len(c.Idoms), c.N)
    }
    return c, nil
}

func errf(format string, args ...any) error {
    return fmt.Errorf(format, args...)
}

// bruteIdom computes immediate dominators with a classic set-based dataflow
// fixpoint. It is deliberately independent from the production code.
func bruteIdom(g *Graph, root int) []int {
    n := g.n
    reach := make([]bool, n)
    reach[root] = true
    stack := []int{root}
    for len(stack) > 0 {
        v := stack[len(stack)-1]
        stack = stack[:len(stack)-1]
        for _, w := range g.Successors(v) {
            if !reach[w] {
                reach[w] = true
                stack = append(stack, w)
            }
        }
    }
    dom := make([][]bool, n)
    for v := 0; v < n; v++ {
        dom[v] = make([]bool, n)
    }
    for v := 0; v < n; v++ {
        if !reach[v] {
            continue
        }
        if v == root {
            dom[v][root] = true
            continue
        }
        for d := 0; d < n; d++ {
            dom[v][d] = true
        }
        dom[v][v] = true
    }
    for changed := true; changed; {
        changed = false
        for v := 0; v < n; v++ {
            if !reach[v] || v == root {
                continue
            }
            any := false
            newset := make([]bool, n)
            for d := 0; d < n; d++ {
                newset[d] = true
            }
            for _, p := range g.Predecessors(v) {
                if !reach[p] {
                    continue
                }
                any = true
                for d := 0; d < n; d++ {
                    newset[d] = newset[d] && dom[p][d]
                }
            }
            if !any {
                continue
            }
            newset[v] = true
            same := true
            for d := 0; d < n; d++ {
                if newset[d] != dom[v][d] {
                    same = false
                    break
                }
            }
            if !same {
                dom[v] = newset
                changed = true
            }
        }
    }
    idom := make([]int, n)
    for i := range idom {
        idom[i] = -1
    }
    idom[root] = root
    for v := 0; v < n; v++ {
        if !reach[v] || v == root {
            continue
        }
        best, bestSize := -1, -1
        for d := 0; d < n; d++ {
            if d == v || !dom[v][d] {
                continue
            }
            size := 0
            for x := 0; x < n; x++ {
                if dom[d][x] {
                    size++
                }
            }
            if size > bestSize {
                bestSize, best = size, d
            }
        }
        idom[v] = best
    }
    return idom
}

func TestIrreducibleNaiveCertificateRejected(t *testing.T) {
    // Cycle {1,3} is entered at BOTH 1 and 3 (2->1 and 2->3): irreducible.
    g := NewGraph(4)
    for _, e := range [][2]int{{0, 2}, {2, 1}, {2, 3}, {3, 1}, {1, 3}} {
        g.Insert(e[0], e[1])
    }
    d := NewDominators(g, 0)
    want := []int{0, 2, 0, 2}
    if !equalIdom(d.idom, want) {
        t.Fatalf("true tree = %v, want %v", d.idom, want)
    }
    // The naive star: idom[v] is an ancestor of every predecessor of v, so
    // the local check accepts it, but it is wrong: node 2 dominates 1 and 3.
    bad := d.Certificate()
    for i := range bad.Idoms {
        bad.Idoms[i] = 0
    }
    if err := VerifyCertificate(g, 0, bad); err == nil {
        t.Fatalf("naive star certificate was accepted for irreducible graph")
    }
}

4.4 Why this is the right fix

  • Correct on irreducible CFGs — CHK makes no reducibility assumption.
  • Correct under deletion — the affected set is exactly the graph descendants of the changed target, which also covers nodes that become unreachable.
  • Bounded recomputation — repair re-solves only that region.
  • O(1) subtree-dominance queries — DFS intervals.
  • Compact, bound, independently checkable certificate — O(n) ints + fingerprint, with a checker that rejects the classic too-shallow trap.
