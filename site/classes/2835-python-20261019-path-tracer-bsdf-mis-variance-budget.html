Diagnosis (root cause)

This is a statistical problem, so the failure modes are estimator biases/variance blow-ups, not syntax errors: 1. Measure mismatch — light sampling is in area, BSDF sampling in solid angle. MIS requires the Jacobian p_l(ω) = p_A(y)·r²/cos θ_y. 2. Double counting — NEE and BSDF hits on the light must be combined with weights summing to 1. 3. Bounce-cap bias — a closed glossy scene needs Russian roulette (T ← T/q), not max_depth. 4. Intractable "truth" — uniform-hemisphere sampling of the full path integral is heavy-tailed for a tiny light, so correctness is proven on the direct-lighting integral plus a deterministic quadrature. 5. Invisible fireflies — need full per-sample path recording. 6. Spectral — hero wavelength λ~U[380,780] needs the Δλ bandwidth factor.

The fix

A spectral path tracer with 5 unbiased estimators (light NEE-only, bsdf GGX-only, balance β=1, power β=2, brute uniform hemisphere), Russian roulette, per-pixel variance, a firefly audit that logs (object, strategy, value) paths, and an independent 512² deterministic area quadrature.

Verification highlights (full run, N=2²² direct; N=2¹⁶ multi-bounce)

  • Deterministic quadrature cross-check (monochromatic): light/balance/power match the no-Monte-Carlo reference to < 0.15 % on all three scenes.
  • Equal sample-count agreement @ 5 %: all pass — small_light max rel. err 2.14 %, large_light 0.07 %, grazing 3.53 %; all z ≤ 1.0.
  • Variance budget (direct, mean per-pixel var): power lowest everywhere; brute is 13×–1467× noisier; on large_light MIS also beats the best single strategy by ~8 %.
  • Unbiasedness: every estimator consistent with the 2²² brute reference at all N (|z| < 3); brute shows the expected N^{-1/2} slope.
  • Firefly audit: e.g. BSDF grazing flags weight 2680 vs threshold 103 with path floor[camera] → light[bsdf->light].
  • Answer: the power heuristic (β=2) has the lowest variance on all three stress scenes (small light, large light, near-grazing glossy), both direct and multi-bounce.
