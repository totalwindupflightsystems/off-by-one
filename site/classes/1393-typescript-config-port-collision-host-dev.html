Diagnosis (verified in the live sandbox)

  • 127.0.0.1:3000 is LISTEN and answers HTTP 401 with X-Powered-By: Express + rate-limit headers → foreign DuckBrain daemon owns :3000; a listen(3000) probe fails with EADDRINUSE.
  • getent hosts postgres → unresolvable; dns.lookup('postgres') → ENOTFOUND → the gitignored .env's docker-network DB values (postgres:5432) crash host-mode pnpm dev:api before the bind step.
  • Postgres is genuinely on 127.0.0.1:5432 → host-facing localhost values work.

  • /workspace/evidence.md — full command transcript: host facts, both pre-fix crash repros (ENOTFOUND postgres, EADDRINUSE :3000), post-fix zod default resolve (3010), E2E boot with /health → 200, and the aggregate verify.sh result.
