Online Dynamic MST with Cut-and-Replacement Certificates

1. Root-cause analysis

The problem is fully dynamic MSF under an oblivious/adversarial online sequence of Insert, Delete, and WeightChange. The failure mode of the obvious solutions:

Attempt Why it fails
Recompute Kruskal after every update O(m log m) per update. A deletion of one tree edge invalidates the whole cached MST.
Keep MST, handle insertions with Link-Cut Tree only Insertion is local (find max edge on the path), but deletion of a tree edge e disconnects the forest, and no local information tells you the cheapest replacement.
On tree-edge deletion, scan all non-tree edges Correct but O(m) per deletion. A path graph where every deleted edge is a bridge, or a dense graph, kills it.
Keep "the MST is unique" assumption With tied weights the MST is not unique, so "the" canonical edge set and the swap decision are ill-defined.

The real obstruction is the cut-and-replacement operation: for a tree edge e, with (S, V\S) the two sides of F − e, you must return the minimum-weight edge of the current graph crossing the cut. Doing this without rebuilding the forest is exactly what Holm–de Lichtenberg–Thorup (HDT) solve.

Two secondary root causes that break naive implementations:

  1. Ties. Without a fixed total order, the "canonical" forest oscillates and certificates are not reproducible. Fix: an MST is the unique minimum in the lexicographic order (weight, id), so every comparison is strict.
  2. Weight-change is not local. Lowering a tree edge may make it grow a component; raising it may require a replacement. Treat it as Delete + Insert; a replacement search must run.

Additionally, the classic subtle bug in HDT code is in the replacement scan: when testing whether a candidate edge crosses the cut, you must test the endpoint different from the one currently being visited, not a fixed endpoint. I hit and fixed exactly that bug while verifying.

2. The fix (HDT + LCT + Henzinger–King reduction)

Level decomposition (decremental core). Every edge gets a level ℓ(e) ∈ {0..⌊log₂ n⌋}. F_i is the subforest of tree edges with level ≥ i, G_i the subgraph of all edges with level ≥ i. Invariants:

  • (i) F is a maximum spanning forest w.r.t. levels: a non-tree edge (u,v) has u,v connected in F_{ℓ(u,v)}.
  • (ii) a tree in F_i has ≤ n/2^i vertices.
  • (iii) every cycle has a non-tree edge of maximum weight and minimum level.

Delete of a tree edge e at level i calls Replace(e,i):

  1. Find the two components of F_i − e; let the smaller be S.
  2. Promote all level-i tree edges inside S to i+1 (invariant (ii) guarantees |S| ≤ n/2^{i+1}).
  3. Visit the level-i non-tree edges incident to S in increasing (weight,id) order; a crossing edge is the answer, otherwise promote it. If none, recurse at i−1.

Invariant (iii) makes the highest level with a crossing edge contain the globally lightest replacement, so we can stop there.

Fully dynamic via the Henzinger–King reduction. Because the core is deletions-only, keep A₀…A_L deletions-only structures. On an update with "new global non-tree edge" set D, pick the smallest j with |D ∪ ⋃_{h≤j}(A_h\F_h)| ≤ 2^j, rebuild A_j = F ∪ D ∪ ⋃_{h≤j}(A_h\F_h), and clear A_h for h<j. A global tree deletion removes e from every A_i containing it; the returned local replacements are exactly the candidates, and the lightest one that reconnects F is the global replacement (Lemma 9 of HDT).

Global forest. A Link-Cut Tree maintains F, gives Connected, and PathMax (max by (weight,id)) for insertions.

Complexity: O(log⁴ n) amortized per update for the classic structure. This code uses BFS for the component/heap steps instead of Euler-tour trees (much simpler, same level-promotion amortization); it is comfortably fast in practice (60 000 random ops on n=1000 in ~1.6 s).

lct.go

package main

// Link-Cut Tree maintaining a maximum (by (weight,id)) edge on any path.
type LCT struct {
    n                 int
    ch0, ch1          []int32
    fa                []int32
    rev               []bool
    valW, valID       []int32
    bestW, bestID     []int32
    bestNode          []int32
}

func NewLCT(vertices, maxEdges int) *LCT {
    N := vertices + maxEdges
    l := &LCT{
        n: N,
        ch0: make([]int32, N), ch1: make([]int32, N), fa: make([]int32, N),
        rev: make([]bool, N), valW: make([]int32, N), valID: make([]int32, N),
        bestW: make([]int32, N), bestID: make([]int32, N), bestNode: make([]int32, N),
    }
    for i := 0; i < N; i++ {
        l.ch0[i], l.ch1[i], l.fa[i] = -1, -1, -1
        l.valW[i], l.valID[i] = -1, -1
        l.bestW[i], l.bestID[i] = -1, -1
        l.bestNode[i] = int32(i)
    }
    return l
}

func (l *LCT) SetEdge(node, w, id int) {
    l.valW[node], l.valID[node] = int32(w), int32(id)
    l.bestW[node], l.bestID[node], l.bestNode[node] = int32(w), int32(id), int32(node)
}

func (l *LCT) better(w1, id1, w2, id2 int32) bool {
    if w1 != w2 {
        return w1 > w2
    }
    return id1 > id2
}

func (l *LCT) pushup(x int32) {
    l.bestW[x], l.bestID[x], l.bestNode[x] = l.valW[x], l.valID[x], x
    if c := l.ch0[x]; c != -1 && l.better(l.bestW[c], l.bestID[c], l.bestW[x], l.bestID[x]) {
        l.bestW[x], l.bestID[x], l.bestNode[x] = l.bestW[c], l.bestID[c], c
    }
    if c := l.ch1[x]; c != -1 && l.better(l.bestW[c], l.bestID[c], l.bestW[x], l.bestID[x]) {
        l.bestW[x], l.bestID[x], l.bestNode[x] = l.bestW[c], l.bestID[c], c
    }
}

func (l *LCT) applyRev(x int32) {
    if x == -1 {
        return
    }
    l.ch0[x], l.ch1[x] = l.ch1[x], l.ch0[x]
    l.rev[x] = !l.rev[x]
}

func (l *LCT) pushdown(x int32) {
    if l.rev[x] {
        l.applyRev(l.ch0[x])
        l.applyRev(l.ch1[x])
        l.rev[x] = false
    }
}

func (l *LCT) isRoot(x int32) bool {
    f := l.fa[x]
    return f == -1 || (l.ch0[f] != x && l.ch1[f] != x)
}

func (l *LCT) rotate(x int32) {
    f, g := l.fa[x], l.fa[l.fa[x]]
    if l.ch1[f] == x {
        b := l.ch0[x]
        l.ch0[x], l.ch1[f] = f, b
        if b != -1 {
            l.fa[b] = f
        }
    } else {
        b := l.ch1[x]
        l.ch1[x], l.ch0[f] = f, b
        if b != -1 {
            l.fa[b] = f
        }
    }
    l.fa[f], l.fa[x] = x, g
    if g != -1 {
        if l.ch0[g] == f {
            l.ch0[g] = x
        } else if l.ch1[g] == f {
            l.ch1[g] = x
        }
    }
    l.pushup(f)
    l.pushup(x)
}

func (l *LCT) splay(x int32) {
    var stk []int32
    for y := x; ; y = l.fa[y] {
        stk = append(stk, y)
        if l.isRoot(y) {
            break
        }
    }
    for i := len(stk) - 1; i >= 0; i-- {
        l.pushdown(stk[i])
    }
    for !l.isRoot(x) {
        f, g := l.fa[x], l.fa[l.fa[x]]
        if !l.isRoot(f) {
            if (l.ch0[f] == x) == (l.ch0[g] == f) {
                l.rotate(f)
            } else {
                l.rotate(x)
            }
        }
        l.rotate(x)
    }
}

func (l *LCT) access(x int32) {
    last := int32(-1)
    for y := x; y != -1; y = l.fa[y] {
        l.splay(y)
        l.ch1[y] = last
        l.pushup(y)
        last = y
    }
    l.splay(x)
}

func (l *LCT) makeroot(x int32) { l.access(x); l.applyRev(x) }

func (l *LCT) findroot(x int32) int32 {
    l.access(x)
    for l.ch0[x] != -1 {
        l.pushdown(x)
        x = l.ch0[x]
    }
    l.splay(x)
    return x
}

func (l *LCT) Connected(x, y int32) bool {
    if x == y {
        return true
    }
    l.makeroot(x)
    return l.findroot(y) == x
}

func (l *LCT) Link(x, y int32) { l.makeroot(x); l.fa[x] = y }

func (l *LCT) Cut(x, y int32) {
    l.makeroot(x)
    l.access(y)
    if l.ch0[y] == x && l.ch1[x] == -1 {
        l.ch0[y], l.fa[x] = -1, -1
        l.pushup(y)
    }
}

func (l *LCT) PathMax(x, y int32) int {
    l.makeroot(x)
    l.access(y)
    if l.bestID[y] < 0 {
        return -1
    }
    return int(l.bestID[y])
}

decremental.go

package main

import "sort"

type Graph struct {
    eu, ev, ew []int
    adj        [][]int
    active     []bool
}

func NewGraph(n, maxEdges int) *Graph {
    return &Graph{
        eu: make([]int, maxEdges), ev: make([]int, maxEdges), ew: make([]int, maxEdges),
        adj: make([][]int, n), active: make([]bool, maxEdges),
    }
}

func (g *Graph) AddEdge(id, u, v, w int) {
    g.eu[id], g.ev[id], g.ew[id] = u, v, w
    if u == v {
        return
    }
    g.adj[u] = append(g.adj[u], id)
    g.adj[v] = append(g.adj[v], id)
}

// DecrMSF: deletions-only HDT minimum spanning forest.
type DecrMSF struct {
    g *Graph
    n int

    present, removed, isTree []bool
    level                    []uint8
    edges                    []int

    visA, visB []int32
    seenEdge   []int32
    bfsStamp   int32
    edgeStamp  int32
    queue      []int
}

func NewDecrMSF(n, maxEdges int) *DecrMSF {
    return &DecrMSF{
        n: n,
        present: make([]bool, maxEdges), removed: make([]bool, maxEdges),
        isTree: make([]bool, maxEdges), level: make([]uint8, maxEdges),
        visA: make([]int32, n), visB: make([]int32, n), seenEdge: make([]int32, maxEdges),
    }
}

func (d *DecrMSF) Clear() {
    for _, id := range d.edges {
        d.present[id], d.removed[id], d.isTree[id], d.level[id] = false, false, false, 0
    }
    d.edges = d.edges[:0]
}

func (d *DecrMSF) Init(g *Graph, edgeIDs []int, isF []bool) {
    d.g = g
    d.Clear()
    for _, id := range edgeIDs {
        d.present[id] = true
        d.isTree[id] = isF[id]
        d.edges = append(d.edges, id)
    }
}

func (d *DecrMSF) Contains(id int) bool { return d.present[id] && !d.removed[id] }

func (d *DecrMSF) NonTreeEdges() []int {
    res := make([]int, 0)
    for _, id := range d.edges {
        if d.present[id] && !d.removed[id] && !d.isTree[id] {
            res = append(res, id)
        }
    }
    return res
}

func (d *DecrMSF) Delete(id int) int {
    if !d.Contains(id) {
        return -1
    }
    d.removed[id] = true
    if !d.isTree[id] {
        return -1
    }
    d.isTree[id] = false
    r := d.replace(id, int(d.level[id]))
    if r >= 0 {
        d.isTree[r] = true
    }
    return r
}

func (d *DecrMSF) other(id, x int) int {
    if d.g.eu[id] == x {
        return d.g.ev[id]
    }
    return d.g.eu[id]
}

func (d *DecrMSF) bfs(start, i int, vis []int32) []int {
    d.queue = d.queue[:0]
    d.queue = append(d.queue, start)
    vis[start] = d.bfsStamp
    for head := 0; head < len(d.queue); head++ {
        x := d.queue[head]
        for _, id := range d.g.adj[x] {
            if !d.present[id] || d.removed[id] || !d.isTree[id] || int(d.level[id]) < i {
                continue
            }
            y := d.other(id, x)
            if vis[y] != d.bfsStamp {
                vis[y] = d.bfsStamp
                d.queue = append(d.queue, y)
            }
        }
    }
    res := make([]int, len(d.queue))
    copy(res, d.queue)
    return res
}

func (d *DecrMSF) replace(e, i int) int {
    if i < 0 {
        return -1
    }
    d.bfsStamp++
    us := d.bfs(d.g.eu[e], i, d.visA)
    vs := d.bfs(d.g.ev[e], i, d.visB)
    small, bigVis := us, d.visB
    if len(vs) < len(us) {
        small, bigVis = vs, d.visA
    }
    // (ii): promote level-i tree edges of the smaller side
    for _, x := range small {
        for _, id := range d.g.adj[x] {
            if d.present[id] && !d.removed[id] && d.isTree[id] && int(d.level[id]) == i {
                d.level[id]++
            }
        }
    }
    type cand struct{ id, w int }
    cands := make([]cand, 0)
    d.edgeStamp++
    for _, x := range small {
        for _, id := range d.g.adj[x] {
            if !d.present[id] || d.removed[id] || d.isTree[id] || int(d.level[id]) != i {
                continue
            }
            if d.seenEdge[id] == d.edgeStamp {
                continue
            }
            d.seenEdge[id] = d.edgeStamp
            cands = append(cands, cand{id, d.g.ew[id]})
        }
    }
    sort.Slice(cands, func(a, b int) bool {
        if cands[a].w != cands[b].w {
            return cands[a].w < cands[b].w
        }
        return cands[a].id < cands[b].id
    })
    for _, c := range cands {
        x1, x2 := d.g.eu[c.id], d.g.ev[c.id]
        inBig := (bigVis[x1] == d.bfsStamp) != (bigVis[x2] == d.bfsStamp)
        if inBig { // exactly one endpoint in the far side => crosses the cut
            return c.id
        }
        d.level[c.id]++
    }
    return d.replace(e, i-1)
}

dynamic.go

package main

import (
    "math/bits"
    "sort"
)

type DynamicMSF struct {
    n        int
    maxEdges int
    g        *Graph
    lct      *LCT
    A        []*DecrMSF
    aCount   int
    inF      []bool
    fEdges   []int
    fStale   int
    fSeen    []int32
    fSeenSt  int32
    total    int
    nextEdge int
}

func NewDynamicMSF(n, maxEdges int) *DynamicMSF {
    if maxEdges < 1 {
        maxEdges = 1
    }
    aCount := bits.Len(uint(maxEdges)) + 1
    dm := &DynamicMSF{
        n: n, maxEdges: maxEdges, g: NewGraph(n, maxEdges), lct: NewLCT(n, maxEdges),
        A: make([]*DecrMSF, aCount), aCount: aCount,
        inF: make([]bool, maxEdges), fSeen: make([]int32, maxEdges),
    }
    for i := range dm.A {
        dm.A[i] = NewDecrMSF(n, maxEdges)
    }
    return dm
}

// canonical total order: (weight, id)
func (dm *DynamicMSF) better(a, b int) bool {
    if dm.g.ew[a] != dm.g.ew[b] {
        return dm.g.ew[a] < dm.g.ew[b]
    }
    return a < b
}

func (dm *DynamicMSF) compactF() {
    if dm.fStale*2 <= len(dm.fEdges) {
        return
    }
    out := dm.fEdges[:0]
    for _, id := range dm.fEdges {
        if dm.inF[id] {
            out = append(out, id)
        }
    }
    dm.fEdges, dm.fStale = out, 0
}

func (dm *DynamicMSF) Insert(u, v, w int) int {
    id := dm.nextEdge
    dm.nextEdge++
    dm.g.AddEdge(id, u, v, w)
    dm.g.active[id] = true
    dm.lct.SetEdge(dm.n+id, w, id)

    if !dm.lct.Connected(int32(u), int32(v)) {
        dm.lct.Link(int32(u), int32(dm.n+id))
        dm.lct.Link(int32(dm.n+id), int32(v))
        dm.inF[id] = true
        dm.fEdges = append(dm.fEdges, id)
        dm.total += w
        return id
    }
    f := dm.lct.PathMax(int32(u), int32(v))
    if f >= 0 && dm.better(id, f) {
        dm.lct.Cut(int32(dm.g.eu[f]), int32(dm.n+f))
        dm.lct.Cut(int32(dm.n+f), int32(dm.g.ev[f]))
        dm.lct.Link(int32(u), int32(dm.n+id))
        dm.lct.Link(int32(dm.n+id), int32(v))
        dm.inF[f], dm.fStale, dm.inF[id] = false, dm.fStale+1, true
        dm.fEdges = append(dm.fEdges, id)
        dm.total += w - dm.g.ew[f]
        dm.update([]int{f})
    } else {
        dm.update([]int{id})
    }
    return id
}

func (dm *DynamicMSF) Delete(id int) {
    if id < 0 || id >= dm.nextEdge || !dm.g.active[id] {
        return
    }
    dm.g.active[id] = false
    R := make([]int, 0)
    for _, a := range dm.A {
        if a.Contains(id) {
            if r := a.Delete(id); r >= 0 {
                R = append(R, r)
            }
        }
    }
    if !dm.inF[id] {
        dm.update(R)
        return
    }
    dm.lct.Cut(int32(dm.g.eu[id]), int32(dm.n+id))
    dm.lct.Cut(int32(dm.n+id), int32(dm.g.ev[id]))
    dm.inF[id], dm.fStale = false, dm.fStale+1
    dm.total -= dm.g.ew[id]

    sort.Slice(R, func(i, j int) bool {
        if dm.g.ew[R[i]] != dm.g.ew[R[j]] {
            return dm.g.ew[R[i]] < dm.g.ew[R[j]]
        }
        return R[i] < R[j]
    })
    for _, f := range R {
        if !dm.g.active[f] {
            continue
        }
        if !dm.lct.Connected(int32(dm.g.eu[f]), int32(dm.g.ev[f])) {
            dm.lct.Link(int32(dm.g.eu[f]), int32(dm.n+f))
            dm.lct.Link(int32(dm.n+f), int32(dm.g.ev[f]))
            dm.inF[f] = true
            dm.fEdges = append(dm.fEdges, f)
            dm.total += dm.g.ew[f]
            break
        }
    }
    dm.update(R)
    dm.compactF()
}

func (dm *DynamicMSF) ChangeWeight(id, w int) int {
    u, v := dm.g.eu[id], dm.g.ev[id]
    dm.Delete(id)
    return dm.Insert(u, v, w)
}

func (dm *DynamicMSF) Total() int { return dm.total }

func (dm *DynamicMSF) Forest() []int {
    res := make([]int, 0, len(dm.fEdges))
    for _, id := range dm.fEdges {
        if dm.inF[id] && dm.g.active[id] {
            res = append(res, id)
        }
    }
    sort.Ints(res)
    k := 0
    for i := range res {
        if i == 0 || res[i] != res[i-1] {
            res[k] = res[i]
            k++
        }
    }
    return res[:k]
}

func (dm *DynamicMSF) update(D []int) {
    union := make([]int, 0, len(D))
    seen := make(map[int]bool)
    add := func(id int) {
        if dm.inF[id] || seen[id] {
            return
        }
        seen[id] = true
        union = append(union, id)
    }
    for _, id := range D {
        add(id)
    }
    for j := 0; j < dm.aCount; j++ {
        for _, id := range dm.A[j].NonTreeEdges() {
            add(id)
        }
        if len(union) <= (1 << j) {
            dm.rebuildA(j, union)
            for h := 0; h < j; h++ {
                dm.A[h].Clear()
            }
            return
        }
    }
    j := dm.aCount - 1
    dm.rebuildA(j, union)
    for h := 0; h < j; h++ {
        dm.A[h].Clear()
    }
}

func (dm *DynamicMSF) rebuildA(j int, nontree []int) {
    edges := make([]int, 0, len(dm.fEdges)+len(nontree))
    dm.fSeenSt++
    for _, id := range dm.fEdges {
        if dm.inF[id] && dm.fSeen[id] != dm.fSeenSt {
            dm.fSeen[id] = dm.fSeenSt
            edges = append(edges, id)
        }
    }
    for _, id := range nontree {
        if dm.fSeen[id] != dm.fSeenSt {
            dm.fSeen[id] = dm.fSeenSt
            edges = append(edges, id)
        }
    }
    dm.A[j].Init(dm.g, edges, dm.inF)
}

// Certificate: smaller side of F-id and lightest crossing edge. Read-only.
func (dm *DynamicMSF) Certificate(id int) (side []int, repl int) {
    vis := make([]int32, dm.n)
    collect := func(start int) []int {
        q := []int{start}
        vis[start] = 1
        for h := 0; h < len(q); h++ {
            x := q[h]
            for _, e := range dm.g.adj[x] {
                if e == id || !dm.inF[e] || !dm.g.active[e] {
                    continue
                }
                var y int
                if dm.g.eu[e] == x {
                    y = dm.g.ev[e]
                } else {
                    y = dm.g.eu[e]
                }
                if vis[y] != 1 {
                    vis[y] = 1
                    q = append(q, y)
                }
            }
        }
        return q
    }
    a := collect(dm.g.eu[id])
    sideIsA := len(a) <= dm.n-len(a)
    if sideIsA {
        side = a
    } else {
        for v := 0; v < dm.n; v++ {
            if vis[v] != 1 {
                side = append(side, v)
            }
        }
    }
    repl = -1
    for _, x := range side {
        for _, e := range dm.g.adj[x] {
            if e == id || !dm.g.active[e] {
                continue
            }
            var y int
            if dm.g.eu[e] == x {
                y = dm.g.ev[e]
            } else {
                y = dm.g.eu[e]
            }
            if (vis[y] == 1) != sideIsA {
                if repl == -1 || dm.better(e, repl) {
                    repl = e
                }
            }
        }
    }
    return side, repl
}

package main

import "fmt"

func main() {
    dm := NewDynamicMSF(5, 32)
    dm.Insert(0, 1, 4)
    dm.Insert(1, 2, 1)
    dm.Insert(2, 3, 5)
    e3 := dm.Insert(3, 4, 2)
    dm.Insert(0, 4, 3)
    dm.Insert(1, 3, 6)

    fmt.Println("mst weight:", dm.Total())   // 10
    fmt.Println("mst edges :", dm.Forest())  // [0 1 3 4]

    side, repl := dm.Certificate(e3)
    fmt.Printf("delete %d -> cut side %v, replacement %d (w=%d)\n",
        e3, side, repl, dm.g.ew[repl]) // side [3], replacement edge 2 (w=5)

    dm.Delete(e3)
    fmt.Println("after delete:", dm.Total(), dm.Forest()) // 13 [0 1 2 4]
}

4. Verification

The reference oracle (brute.go) recomputes the MST with Kruskal after every update using the same (weight,id) order, and independently computes the exact cut and minimum crossing edge for certificates. The differential tests assert, after every operation:

  • Total() equals the brute-force MSF weight;
  • Forest() equals the brute-force canonical edge-id set;
  • for every tree edge, Certificate(e) returns a valid cut side and exactly the brute-force minimum crossing edge.

The certificate is verifiable by a third party without rebuilding: given side, the verifier only has to (a) confirm side is one component of F−e, (b) confirm the replacement crosses side/complement, and (c) confirm no cheaper active edge crosses. The returned Forest() is canonical by construction because every comparison uses the total order (weight,id).

Call Meaning

This treats weight change as a versioned delete+insert (new id), which keeps the (weight,id) order well defined; the Forest/Certificate output uses those ids. If a stable external id is required, map the returned id back to the logical edge.
