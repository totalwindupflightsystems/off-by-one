Verified Solution: BWA-style FM-index backward search + adaptive affine-gap banded alignment

Problem class: go-bwap-backward-search-affine-gap-band-pruning Toolchain: Go 1.26 (go1.26.8 linux/amd64)

The module lives at ~/bwa-fmindex and implements an exact FM-index backward search (wavelet-matrix rank + Occ/SA checkpoints), affine-gap Smith-Waterman with a seed-derived adaptive diagonal band, full CIGAR traceback, and a saturating MAPQ.

Root-cause analysis

Naive implementations fail in five concrete ways; all five were encountered and fixed while building this solution.

RC0 — SA prefix-doubling rank tie-break used the wrong offset. Sorting uses (rank[i], rank[i+k]), but the rank-assignment step compared rank[a+1] instead of rank[a+k]. It is correct only while k==1; afterwards the FM-index silently corrupts (Count returns 0 for present patterns, Locate returns unrelated positions).

// before: if a+1 < n { ra = rnk[a+1] }
if a+kk < n { ra = rnk[a+kk] }   // after

RC1 — affine gap-extension state was never stored. e/f were computed and used in H but never written to the reused buffers, so every E[i-1][j]-GapExtend / F[i][j-1]-GapExtend read stale/zero data and gaps longer than 1 were effectively free.

Hcur[j] = best
Ecur[j] = e   // <-- required
Fcur[j] = f   // <-- required

RC2 — first-row buffer leak. The E recurrence was skipped on row 0 (if !first), so Eprev for row 1 was the zero-initialised buffer instead of -inf, making a length-1 gap cost -GapExtend rather than -GapOpen. Fix: always evaluate E (border H[-1][*]=0, E[-1][*]=-inf is already encoded).

RC3 — band pruning can clip the optimum. With no seed the band collapses around diagonal 0; a spurious/repetitive seed picks a wrong diagonal. Fix without widening: use the complete matrix when no seed is found, and after a banded pass detect a traceback that touched a band edge and re-run the exact unbanded matrix. Thus Widen == 0 can never lose the optimum.

RC4 — MAPQ must saturate on repeats. A linear uniqueness term stays high for thousands of hits. Use a multiplicative repeat penalty:

uniq = 1 - second/best;  pen = 1/occ;  mapq = round(60 * uniq * pen)

Key mapper logic:

banded := have
var bandFor align.BandFn
if banded {
    bandFor = func(i int) (int, int) { c := i + d0; return c - half, c + half }
} else {
    bandFor = align.FullBand(m, refLen)   // no seed -> exact
}
best, cigar, refStart, clipped := align.AlignTrace(read, refOf(idx), p.Scoring, bandFor)
if banded && clipped {                    // edge hit -> exact fallback, never widen
    best, cigar, refStart, _ = align.AlignTrace(read, refOf(idx), p.Scoring, align.FullBand(m, refLen))
    res.Fallback = true
    banded = false
}
