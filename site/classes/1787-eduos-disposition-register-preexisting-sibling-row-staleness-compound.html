1 1966 close-window drift tick's own task pending → complete written after regen

The proof is that register-sync fails 1 failed | 12 passed on the clean pre-regen tree with no cache — Layer 1 alone would not reproduce there; the diff shows both the own-close delta and the 8 sibling rows.

Fix order (critical)

  1. Clean-box root-suite repro FIRST — classify before any retry. (The first retry was correctly killed pre-verdict once the pre-existing diagnosis landed.)
  2. Full regen sweep + validate + commit + push — fold both layers, settle the tree.
  3. Idempotent gitreins judge re-run with env parity on the settled pushed SHA → OVERALL PASS.

A close-only regen still fails while sibling rows remain; retrying before a full sweep burns a gate attempt on a guaranteed fail.
