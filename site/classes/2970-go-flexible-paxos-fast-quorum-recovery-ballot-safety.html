Answer

Flexible Paxos: safe independent Q1/Q2 quorums and crash recovery

The complete verified solution is also available at /workspace/SOLUTION.md, with source in /workspace/flexpaxos.

Root-cause analysis

A normal Paxos implementation hard-codes “majority” in two places: it accepts a phase-1 quorum if len(promises) >= N/2+1, and a phase-2 quorum if len(accepted) >= N/2+1. That is wrong for Flexible Paxos.

  • The safety invariant is intersection, not majority: every phase-1 quorum Q1 must intersect every phase-2 quorum Q2. If the quorums are “any subset of the configured sizes”, this is equivalent to |Q1| + |Q2| > N.
  • A fixed majority check is unsound when the configured Q1 or Q2 is smaller than a majority. Example: N=5, Q1=1, Q2=5 is safe (the single Q1 member is in every Q2), but a hard-coded majority would reject the legal Q1.
  • A fixed majority check is also needlessly rejecting when the configured quorum is larger than a majority. Example: N=5, Q1=4, Q2=2 is legal, but a hard-coded Q2 majority check rejects a valid Q2 of two acceptors.
  • Recovery after a proposer crash must not simply reuse its old value. Phase 1 must collect the accepted state from a Q1; because every Q1 intersects the Q2 that may have committed, at least one promise carries the committed value (or a newer accepted value). The proposer must choose the value with the highest accepted ballot among the promises before entering phase 2.
  • Stale/reordered messages are handled by making ballots totally ordered and by including the ballot (and log index) in every reply. An acceptor rejects an accept below its promise; a proposer discards replies for any ballot other than its current attempt. Duplicate phase-1 requests are idempotent.
  • Ballots must never be reused, even across a process crash. BallotGen must be restored from durable state (or from the maximum ballot observed/persisted) before issuing a new ballot. Reusing a ballot with a different value can break safety because two Q2 quorums need not intersect.

The fix is therefore:

  1. Validate N, Q1, Q2 and reject Q1+Q2 <= N in the config loader.
  2. Persist the acceptor’s promised, acceptedBallot, acceptedValue, and recovery ballot.
  3. Count only the configured Q1/Q2 sizes.
  4. On phase 1, recover the highest accepted value from the promises.
  5. Fence all stale traffic with the ballot and never reuse a ballot.

ballot.go

package flexpaxos

import "sync"

// Ballot is a totally ordered Paxos ballot. Round is the primary ordering key;
// ID breaks ties between proposers if a deployment gives each proposer its own
// counter. The harness uses one global generator so Round alone is unique.
type Ballot struct {
    Round uint64
    ID    uint64
}

func (b Ballot) Compare(o Ballot) int {
    if b.Round < o.Round {
        return -1
    }
    if b.Round > o.Round {
        return 1
    }
    if b.ID < o.ID {
        return -1
    }
    if b.ID > o.ID {
        return 1
    }
    return 0
}

func maxBallot(a, b Ballot) Ballot {
    if a.Compare(b) >= 0 {
        return a
    }
    return b
}

// BallotGen issues ballots strictly greater than a supplied floor. A real
// deployment must persist last (or recover it from durable acceptor promises)
// before issuing ballots after a process restart.
type BallotGen struct {
    mu   sync.Mutex
    last uint64
}

// NewBallotGen restores a generator from durable state. Pass the greatest
// ballot known to have been issued before a restart. A fresh cluster may use
// NewBallotGen(0).
func NewBallotGen(last uint64) *BallotGen { return &BallotGen{last: last} }

// Last returns the greatest round issued/observed so far. Persist this value
// before acknowledging a proposal if the same process may restart.
func (g *BallotGen) Last() uint64 {
    g.mu.Lock()
    defer g.mu.Unlock()
    return g.last
}

func (g *BallotGen) Next(after Ballot) Ballot {
    g.mu.Lock()
    defer g.mu.Unlock()
    if after.Round > g.last {
        g.last = after.Round
    }
    g.last++
    return Ballot{Round: g.last, ID: 0}
}

config.go

package flexpaxos

import (
    "bytes"
    "encoding/json"
    "fmt"
    "io"
    "os"
)

// Config describes N acceptors and the sizes of the phase-1 and phase-2
// quorums. Legal configurations satisfy |Q1|+|Q2| > N. That inequality is
// exactly what guarantees every possible Q1 intersects every possible Q2.
type Config struct {
    N  int `json:"n"`
    Q1 int `json:"q1"`
    Q2 int `json:"q2"`
}

func (c Config) Validate() error {
    if c.N <= 0 {
        return fmt.Errorf("bad config: n must be > 0, got %d", c.N)
    }
    if c.Q1 < 1 || c.Q1 > c.N {
        return fmt.Errorf("bad config: q1 must be in [1,%d], got %d", c.N, c.Q1)
    }
    if c.Q2 < 1 || c.Q2 > c.N {
        return fmt.Errorf("bad config: q2 must be in [1,%d], got %d", c.N, c.Q2)
    }
    if c.Q1+c.Q2 <= c.N {
        return fmt.Errorf("unsafe flexible quorum: need q1+q2 > n, got %d+%d <= %d", c.Q1, c.Q2, c.N)
    }
    return nil
}

// LoadConfig reads a strict JSON config and rejects any unsafe quorum
// configuration at the boundary, before a replica can be started.
func LoadConfig(path string) (Config, error) {
    b, err := os.ReadFile(path)
    if err != nil {
        return Config{}, err
    }
    var c Config
    dec := json.NewDecoder(bytes.NewReader(b))
    dec.DisallowUnknownFields()
    if err := dec.Decode(&c); err != nil {
        return Config{}, fmt.Errorf("parse config: %w", err)
    }
    if err := dec.Decode(&struct{}{}); err != io.EOF {
        return Config{}, fmt.Errorf("parse config: trailing data after JSON object")
    }
    if err := c.Validate(); err != nil {
        return Config{}, err
    }
    return c, nil
}

acceptor.go

package flexpaxos

import "sync"

// Value is the replicated value. A separate bool records whether an acceptor
// has ever accepted a value, so the empty string is a legal value.
type Value string

// PrepareReply is the durable information an acceptor returns in phase 1.
type PrepareReply struct {
    From           int
    Ballot         Ballot
    OK             bool
    Promised       Ballot
    AcceptedBallot Ballot
    AcceptedValue  Value
    HasAccepted    bool
}

// AcceptReply confirms a phase-2 write.
type AcceptReply struct {
    From     int
    Ballot   Ballot
    OK       bool
    Promised Ballot
}

// Acceptor is a persistent Flexible Paxos acceptor. promised, acceptedBallot,
// acceptedValue and recoveryBallot are the state that must survive a crash.
// recoveryBallot is the highest ballot for which this acceptor has joined a
// recovery (phase-1) round; it is diagnostic/lease state, while safety comes
// from promised + acceptedBallot/value.
type Acceptor struct {
    ID int

    mu             sync.Mutex
    promised       Ballot
    hasPromised    bool
    acceptedBallot Ballot
    acceptedValue  Value
    hasAccepted    bool
    recoveryBallot Ballot
    hasRecovery    bool
}

func NewAcceptor(id int) *Acceptor { return &Acceptor{ID: id} }

// Prepare promises not to accept any ballot below b and reports the value (if
// any) already accepted by this acceptor. Equal ballots are idempotent, which
// lets a retried prepare be safe under duplicate/reordered messages.
func (a *Acceptor) Prepare(b Ballot) PrepareReply {
    a.mu.Lock()
    defer a.mu.Unlock()

    if a.hasPromised && b.Compare(a.promised) < 0 {
        return PrepareReply{From: a.ID, Ballot: b, OK: false, Promised: a.promised}
    }
    a.promised = maxBallot(a.promised, b)
    a.hasPromised = true
    a.recoveryBallot = maxBallot(a.recoveryBallot, b)
    a.hasRecovery = true
    return PrepareReply{
        From:           a.ID,
        Ballot:         b,
        OK:             true,
        Promised:       a.promised,
        AcceptedBallot: a.acceptedBallot,
        AcceptedValue:  a.acceptedValue,
        HasAccepted:    a.hasAccepted,
    }
}

// Accept accepts b/value only if no higher ballot has been promised. Accepting
// a second, different value at the same ballot is refused (proposer bug or
// Byzantine input); a correct proposer retries with a strictly newer ballot.
func (a *Acceptor) Accept(b Ballot, v Value) AcceptReply {
    a.mu.Lock()
    defer a.mu.Unlock()

    if a.hasPromised && b.Compare(a.promised) < 0 {
        return AcceptReply{From: a.ID, Ballot: b, OK: false, Promised: a.promised}
    }
    if a.hasAccepted && b.Compare(a.acceptedBallot) == 0 && v != a.acceptedValue {
        return AcceptReply{From: a.ID, Ballot: b, OK: false, Promised: a.promised}
    }
    a.promised = maxBallot(a.promised, b)
    a.hasPromised = true
    a.acceptedBallot = b
    a.acceptedValue = v
    a.hasAccepted = true
    return AcceptReply{From: a.ID, Ballot: b, OK: true, Promised: a.promised}
}

// Snapshot is for diagnostics and assertions; it is not used by the protocol.
func (a *Acceptor) Snapshot() (promised Ballot, acceptedBallot Ballot, acceptedValue Value, hasAccepted bool, recovery Ballot) {
    a.mu.Lock()
    defer a.mu.Unlock()
    return a.promised, a.acceptedBallot, a.acceptedValue, a.hasAccepted, a.recoveryBallot
}

proposer.go

package flexpaxos

// MsgType is the wire type used by the deterministic harness.
type MsgType uint8

const (
    MsgPrepare MsgType = iota
    MsgPromise
    MsgAccept
    MsgAccepted
)

// Message is both a request and a response. For MsgPrepare/MsgAccept, From is
// the proposer ID and To is the acceptor ID. For replies it is the reverse.
type Message struct {
    Type           MsgType
    From, To       int
    Index          int
    Ballot         Ballot
    Value          Value
    OK             bool
    Promised       Ballot
    AcceptedBallot Ballot
    AcceptedValue  Value
    HasAccepted    bool
}

type phase uint8

const (
    phaseIdle phase = iota
    phasePreparing
    phaseAccepting
    phaseCommitted
    phaseAborted
)

// Proposer implements the Flexible Paxos proposer. A new attempt always uses a
// strictly larger ballot. Phase 1 waits for Q1 promises, selects the accepted
// value with the highest accepted ballot among those promises (falling back to
// the proposal value), and only then sends phase 2. A commit is declared when
// Q2 distinct acceptors confirm the same ballot.
type Proposer struct {
    ID      int
    Config  Config
    Ballots *BallotGen

    index       int
    initial     Value
    ballot      Ballot
    phase       phase
    promises    map[int]PrepareReply
    accepts     map[int]struct{}
    chosen      Value
    committed   bool
    commitValue Value
    attempts    int
    maxAttempts int
}

func NewProposer(id int, cfg Config, ballots *BallotGen) *Proposer {
    return &Proposer{
        ID:          id,
        Config:      cfg,
        Ballots:     ballots,
        maxAttempts: 16,
    }
}

func (p *Proposer) Committed() (Value, bool) { return p.commitValue, p.committed }
func (p *Proposer) Ballot() Ballot           { return p.ballot }
func (p *Proposer) Phase() phase             { return p.phase }

// Start begins a fresh proposal for one log index.
func (p *Proposer) Start(index int, value Value) []Message {
    p.index = index
    p.initial = value
    p.attempts = 0
    p.committed = false
    p.commitValue = ""
    p.phase = phaseIdle
    return p.newAttempt(Ballot{})
}

func (p *Proposer) newAttempt(after Ballot) []Message {
    if p.attempts >= p.maxAttempts {
        p.phase = phaseAborted
        return nil
    }
    p.attempts++
    p.ballot = p.Ballots.Next(after)
    p.phase = phasePreparing
    p.promises = make(map[int]PrepareReply)
    p.accepts = make(map[int]struct{})
    p.chosen = p.initial
    msgs := make([]Message, 0, p.Config.N)
    for i := 0; i < p.Config.N; i++ {
        msgs = append(msgs, Message{
            Type: MsgPrepare, From: p.ID, To: i, Index: p.index, Ballot: p.ballot,
        })
    }
    return msgs
}

// Handle consumes one reply. Replies from an older ballot or from a previous
// attempt are ignored, so duplicated/reordered/stale traffic cannot corrupt
// the current attempt.
func (p *Proposer) Handle(m Message) []Message {
    if m.Index != p.index || m.Ballot.Compare(p.ballot) != 0 {
        return nil
    }
    switch p.phase {
    case phasePreparing:
        if m.Type != MsgPromise {
            return nil
        }
        if !m.OK {
            if m.Promised.Compare(p.ballot) > 0 {
                return p.newAttempt(maxBallot(p.ballot, m.Promised))
            }
            return nil
        }
        if _, seen := p.promises[m.From]; seen {
            return nil
        }
        p.promises[m.From] = PrepareReply{
            From: m.From, Ballot: m.Ballot, OK: true, Promised: m.Promised,
            AcceptedBallot: m.AcceptedBallot, AcceptedValue: m.AcceptedValue,
            HasAccepted: m.HasAccepted,
        }
        if len(p.promises) < p.Config.Q1 {
            return nil
        }

        // Recovery rule: take the value accepted at the highest ballot in Q1.
        p.chosen = p.initial
        var bestBallot Ballot
        found := false
        for _, r := range p.promises {
            if !r.HasAccepted {
                continue
            }
            if !found || r.AcceptedBallot.Compare(bestBallot) > 0 {
                found = true
                bestBallot = r.AcceptedBallot
                p.chosen = r.AcceptedValue
            }
        }

        p.phase = phaseAccepting
        msgs := make([]Message, 0, p.Config.N)
        for i := 0; i < p.Config.N; i++ {
            msgs = append(msgs, Message{
                Type: MsgAccept, From: p.ID, To: i, Index: p.index,
                Ballot: p.ballot, Value: p.chosen,
            })
        }
        return msgs

    case phaseAccepting:
        if m.Type != MsgAccepted {
            return nil
        }
        if !m.OK {
            if m.Promised.Compare(p.ballot) > 0 {
                return p.newAttempt(maxBallot(p.ballot, m.Promised))
            }
            return nil
        }
        if _, seen := p.accepts[m.From]; seen {
            return nil
        }
        p.accepts[m.From] = struct{}{}
        if len(p.accepts) >= p.Config.Q2 {
            p.committed = true
            p.commitValue = p.chosen
            p.phase = phaseCommitted
        }
    }
    return nil
}

harness.go

package flexpaxos

import "fmt"

// This file is a deterministic, in-process message-reorder harness. It is not
// part of the wire protocol. It schedules every request/reply at a logical
// time chosen from a seeded PRNG, so a seed reproduces an exact interleaving.

type rng64 struct{ state uint64 }

func newRNG(seed uint64) *rng64 {
    if seed == 0 {
        seed = 0x9e3779b97f4a7c15
    }
    return &rng64{state: seed}
}
func (r *rng64) next() uint64 {
    x := r.state
    x ^= x << 13
    x ^= x >> 7
    x ^= x << 17
    r.state = x
    return x
}
func (r *rng64) Intn(n int) int {
    if n <= 0 {
        return 0
    }
    return int(r.next() % uint64(n))
}

type event struct {
    due int64
    seq int64
    msg Message
}

// Harness owns acceptors, proposers, and a logical-time priority queue.
type Harness struct {
    Config    Config
    acceptors []*Acceptor
    proposers map[int]*Proposer
    ballots   *BallotGen
    rng       *rng64
    events    []event
    seq       int64
    clock     int64
    delayMax  int

    committed  map[int]Value
    violations []string
    delivered  int
}

func NewHarness(cfg Config, seed uint64) (*Harness, error) {
    if err := cfg.Validate(); err != nil {
        return nil, err
    }
    h := &Harness{
        Config:    cfg,
        proposers: make(map[int]*Proposer),
        ballots:   NewBallotGen(0),
        rng:       newRNG(seed),
        delayMax:  24,
        committed: make(map[int]Value),
    }
    h.acceptors = make([]*Acceptor, cfg.N)
    for i := range h.acceptors {
        h.acceptors[i] = NewAcceptor(i)
    }
    return h, nil
}

func (h *Harness) Acceptor(id int) *Acceptor { return h.acceptors[id] }

func (h *Harness) AddProposer(id int) *Proposer {
    p := NewProposer(id, h.Config, h.ballots)
    h.proposers[id] = p
    return p
}

func (h *Harness) Start(index int, id int, value Value) {
    p := h.proposers[id]
    if p == nil {
        p = h.AddProposer(id)
    }
    h.enqueueAll(p.Start(index, value))
}

func (h *Harness) Crash(id int) { delete(h.proposers, id) }

func (h *Harness) Pending() bool { return len(h.events) > 0 }

func (h *Harness) enqueueAll(msgs []Message) {
    for _, m := range msgs {
        h.enqueue(m)
    }
}

func (h *Harness) enqueue(m Message) {
    // Strictly positive random delay; a larger delayMax forces deeper reorder.
    due := h.clock + int64(1+h.rng.Intn(h.delayMax+1))
    h.seq++
    h.events = append(h.events, event{due: due, seq: h.seq, msg: m})
}

func (h *Harness) pop() (event, bool) {
    if len(h.events) == 0 {
        return event{}, false
    }
    best := 0
    for i := 1; i < len(h.events); i++ {
        if h.events[i].due < h.events[best].due ||
            (h.events[i].due == h.events[best].due && h.events[i].seq < h.events[best].seq) {
            best = i
        }
    }
    e := h.events[best]
    h.events = append(h.events[:best], h.events[best+1:]...)
    return e, true
}

// Step delivers exactly one network event and schedules any replies.
func (h *Harness) Step() bool {
    e, ok := h.pop()
    if !ok {
        return false
    }
    if e.due > h.clock {
        h.clock = e.due
    }
    h.delivered++
    m := e.msg
    switch m.Type {
    case MsgPrepare:
        r := h.acceptors[m.To].Prepare(m.Ballot)
        h.enqueue(Message{
            Type: MsgPromise, From: m.To, To: m.From, Index: m.Index, Ballot: m.Ballot,
            OK: r.OK, Promised: r.Promised, AcceptedBallot: r.AcceptedBallot,
            AcceptedValue: r.AcceptedValue, HasAccepted: r.HasAccepted,
        })
    case MsgAccept:
        r := h.acceptors[m.To].Accept(m.Ballot, m.Value)
        h.enqueue(Message{
            Type: MsgAccepted, From: m.To, To: m.From, Index: m.Index,
            Ballot: m.Ballot, OK: r.OK, Promised: r.Promised,
        })
    case MsgPromise, MsgAccepted:
        p := h.proposers[m.To]
        if p == nil {
            return true // crashed proposer: its replies are lost
        }
        wasCommitted := p.committed
        replies := p.Handle(m)
        if !wasCommitted && p.committed {
            h.recordCommit(p.index, p.commitValue)
        }
        h.enqueueAll(replies)
    }
    return true
}

func (h *Harness) recordCommit(index int, value Value) {
    if old, ok := h.committed[index]; ok {
        if old != value {
            h.violations = append(h.violations, fmt.Sprintf(
                "divergent commit index=%d old=%q new=%q clock=%d", index, old, value, h.clock))
        }
        return
    }
    h.committed[index] = value
}

// RunUntil delivers events until pred is true (or the queue empties/max steps
// is reached). It returns whether pred became true.
func (h *Harness) RunUntil(maxSteps int, pred func() bool) bool {
    for steps := 0; steps < maxSteps; steps++ {
        if pred() {
            return true
        }
        if !h.Step() {
            return pred()
        }
    }
    return pred()
}

func (h *Harness) Run(maxSteps int) {
    h.RunUntil(maxSteps, func() bool { return false })
}

func (h *Harness) Committed(index int) (Value, bool) {
    v, ok := h.committed[index]
    return v, ok
}

func (h *Harness) Violations() []string { return append([]string(nil), h.violations...) }

func (h *Harness) Check() error {
    if len(h.violations) > 0 {
        return fmt.Errorf("safety violation: %s", h.violations[0])
    }
    return nil
}

// CountAccepted returns how many acceptors durably accepted value at a ballot.
func (h *Harness) CountAccepted(value Value) int {
    n := 0
    for _, a := range h.acceptors {
        _, _, av, ok, _ := a.Snapshot()
        if ok && av == value {
            n++
        }
    }
    return n
}

package flexpaxos

import (
    "fmt"
    "os"
    "path/filepath"
    "testing"
)

func legalConfigs(maxN int) []Config {
    var out []Config
    for n := 2; n <= maxN; n++ {
        for q1 := 1; q1 <= n; q1++ {
            for q2 := 1; q2 <= n; q2++ {
                c := Config{N: n, Q1: q1, Q2: q2}
                if c.Validate() == nil {
                    out = append(out, c)
                }
            }
        }
    }
    return out
}

func TestConfigValidation(t *testing.T) {
    for _, c := range legalConfigs(8) {
        if err := c.Validate(); err != nil {
            t.Fatalf("legal config %+v rejected: %v", c, err)
        }
    }
    for _, c := range []Config{
        {N: 3, Q1: 1, Q2: 2}, // 1+2 <= 3: unsound
        {N: 5, Q1: 2, Q2: 3}, // exactly half: unsound
        {N: 4, Q1: 0, Q2: 4},
        {N: 4, Q1: 5, Q2: 1},
        {N: 0, Q1: 1, Q2: 1},
    } {
        if err := c.Validate(); err == nil {
            t.Fatalf("unsafe config %+v accepted", c)
        }
    }
}

func TestLoadConfigBoundary(t *testing.T) {
    dir := t.TempDir()
    write := func(name, body string) string {
        p := filepath.Join(dir, name)
        if err := os.WriteFile(p, []byte(body), 0o600); err != nil {
            t.Fatal(err)
        }
        return p
    }
    if _, err := LoadConfig(write("ok.json", `{"n":5,"q1":2,"q2":4}`)); err != nil {
        t.Fatalf("legal config rejected: %v", err)
    }
    if _, err := LoadConfig(write("bad.json", `{"n":5,"q1":2,"q2":3}`)); err == nil {
        t.Fatal("unsafe config q1+q2==n was accepted")
    }
    if _, err := LoadConfig(write("unknown.json", `{"n":5,"q1":2,"q2":4,"mode":"fast"}`)); err == nil {
        t.Fatal("unknown field was accepted")
    }
}

// Enumerate all possible quorum subsets for small N and check the loader's
// inequality really is equivalent to every Q1 intersecting every Q2.
func TestEveryLegalQuorumPairIntersects(t *testing.T) {
    for _, c := range legalConfigs(7) {
        for q1 := 0; q1 < (1 << c.N); q1++ {
            if popcount(q1) != c.Q1 {
                continue
            }
            for q2 := 0; q2 < (1 << c.N); q2++ {
                if popcount(q2) != c.Q2 {
                    continue
                }
                if q1&q2 == 0 {
                    t.Fatalf("config %+v has disjoint quorums %07b and %07b", c, q1, q2)
                }
            }
        }
    }
}

func popcount(x int) int {
    n := 0
    for x != 0 {
        n += x & 1
        x >>= 1
    }
    return n
}

// Two (or three) proposers race with different values while every message is
// independently delayed. The invariant checked is the Paxos safety property:
// no two proposers may commit different values at the same log index.
func TestSafetyAllLegalQuorumsUnderReordering(t *testing.T) {
    for _, cfg := range legalConfigs(6) {
        cfg := cfg
        t.Run(fmt.Sprintf("n%d-q1%d-q2%d", cfg.N, cfg.Q1, cfg.Q2), func(t *testing.T) {
            for seed := uint64(0); seed < 40; seed++ {

                if err != nil {

                }
                nProps := 2 + int(seed%2)
                for id := 0; id < nProps; id++ {
                    h.AddProposer(id)
                    h.Start(0, id, Value(fmt.Sprintf("p%d", id)))
                }

                // At one deterministic point, crash a proposer that may have
                // accepted a value but not yet learned that it committed, then
                // start a recovery proposer with a conflicting value.
                crashAt := 20 + int(seed%40)
                crashed := int(seed) % nProps
                didCrash := false
                for step := 0; step < 3000 && h.Pending(); step++ {
                    h.Step()
                    if !didCrash && step == crashAt {
                        h.Crash(crashed)
                        h.AddProposer(1000 + int(seed))
                        h.Start(0, 1000+int(seed), Value(fmt.Sprintf("recovered-%d", seed)))
                        didCrash = true
                    }
                }
                if err := h.Check(); err != nil {
                    t.Fatalf("seed %d: %v", seed, err)
                }
                if _, ok := h.Committed(0); !ok {
                    t.Fatalf("seed %d: no proposer committed (config %+v)", seed, cfg)
                }
            }
        })

// A proposer is crashed immediately after phase 1 sends its accepts. Its value
// can therefore already be chosen by a Q2, but the crashed proposer never
// observed Q2 replies. The recovery proposer must learn that value using only
// Q1 promises and must not commit its own conflicting value.
func TestRecoveryUsesOnlyPhase1Quorum(t *testing.T) {
    for _, cfg := range legalConfigs(6) {
        cfg := cfg
        t.Run(fmt.Sprintf("n%d-q1%d-q2%d", cfg.N, cfg.Q1, cfg.Q2), func(t *testing.T) {
            for seed := uint64(0); seed < 20; seed++ {
                h, err := NewHarness(cfg, seed+1)
                if err != nil {
                    t.Fatal(err)
                }
                h.AddProposer(1)
                h.Start(0, 1, "old")
                ok := h.RunUntil(2000, func() bool {
                    p := h.proposers[1]
                    return p != nil && p.Phase() == phaseAccepting
                })
                if !ok {
                    t.Fatalf("seed %d: old proposer never reached phase 2", seed)
                }

                // Drop all replies to proposer 1, but let its phase-2 requests
                // reach the acceptors. This creates an accepted value whose
                // proposer does not know it may be committed.
                h.Crash(1)
                h.Run(2000)
                if got := h.CountAccepted("old"); got < cfg.Q2 {
                    t.Fatalf("seed %d: only %d acceptors accepted old value, need Q2=%d", seed, got, cfg.Q2)
                }
                if _, ok := h.Committed(0); ok {
                    t.Fatalf("seed %d: crashed proposer observed commit unexpectedly", seed)
                }

                h.AddProposer(2)
                h.Start(0, 2, "new")
                h.Run(3000)
                if err := h.Check(); err != nil {
                    t.Fatalf("seed %d: %v", seed, err)
                }
                got, ok := h.Committed(0)
                if !ok {
                    t.Fatalf("seed %d: recovery proposer did not commit", seed)
                }
                if got != "old" {
                    t.Fatalf("seed %d: recovery committed %q, want recovered value %q", seed, got, "old")
                }
                v, cok := h.proposers[2].Committed()
                if !cok || v != "old" {
                    t.Fatalf("seed %d: recovery proposer state = (%q,%v), want (old,true)", seed, v, cok)
                }
            }
        })
    }
}

func TestStaleAcceptIsRejected(t *testing.T) {
    a := NewAcceptor(0)
    b1 := Ballot{Round: 1}
    b2 := Ballot{Round: 2}

    if r := a.Prepare(b1); !r.OK {
        t.Fatal("first prepare rejected")
    }
    if r := a.Accept(b1, "v1"); !r.OK {
        t.Fatal("first accept rejected")
    }
    if r := a.Prepare(b2); !r.OK {
        t.Fatal("higher prepare rejected")
    }
    if r := a.Accept(b1, "v1"); r.OK {
        t.Fatal("stale accept at lower ballot was accepted")
    } else if r.Promised.Compare(b2) != 0 {
        t.Fatalf("reject did not advertise promised ballot: %+v", r)
    }
    // Equal-ballot duplicate prepare remains idempotent and reports the value.
    if r := a.Prepare(b2); !r.OK || r.HasAccepted != true || r.AcceptedValue != "v1" {
        t.Fatalf("duplicate prepare did not return durable accepted state: %+v", r)
    }
}

The harness records every commit and fails on the first time two different values are committed at index 0.
  • TestRecoveryUsesOnlyPhase1Quorum: crashes a proposer after it has sent phase-2 accepts but before it observes any phase-2 reply, so the value may already be chosen without the proposer knowing. A recovery proposer with a conflicting value must learn the old value from Q1 promises and commit it.

Operational note: in a real process, persist the acceptor state and the BallotGen.last value (or initialize the generator from the maximum ballot found on disk) before acknowledging messages. Leases may optimize the fast path, but a lease must never allow bypassing the ballot promise fence; otherwise an expired/stale leader can violate the same intersection argument.
