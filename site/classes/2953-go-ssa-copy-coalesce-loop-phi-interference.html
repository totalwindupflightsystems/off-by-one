Fixing SSA Copy Coalescing Around Loop-Header Phi Self-Cycles

Problem class: go-ssa-copy-coalesce-loop-phi-interference · Go 1.26 · full source: ~/ssacoalesce/SOLUTION.md (10 files, extracted and rebuilt in a clean dir as the final check).

1. Symptom

A "coalesce every move" allocator produces an assignment that quietly violates interference at loop headers:

-- loop_conflict (K=2) --
   removed copies : 2
   residual moves : 0  (kept: 0)
   spills         : 1
   verify         : FAIL
      ! interference violated: i and s both in r0   <-- self-cycle was merged away

The spill count looks plausible; only the verifier catches it.

2. Root-cause analysis

Interference = must not share a register. Two simultaneously-live values interfere. Coalescing is sound only if no interference edge connects the two equivalence classes being merged. If one does, the merged graph gets a self-cycle — one register would have to hold two live values.

Why loop back edges are the trap. After phi elimination the header phi becomes phi_dest = back_edge_value in the latch. The header value is live across the iteration, and the back-edge value is often defined while the header value is still live (or used afterwards). In the corpus:

bb1 succs=1
  i = phi init@0, s@1     ; header value lives across the iteration
  s = mul i, one          ; back-edge value defined here...
  t = add i, one          ; ...but i is still live here

i and s interfere. Naive coalescing unions them anyway; the edge (i,s) becomes a self-loop that gets dropped, so the allocator colors an under-constrained graph and emits an invalid assignment. Correct behavior: detect the cycle, keep the move, and report it as a residual move.

Two extra bugs the verifier caught: 1. Union-find member bookkeeping — delete(members, rd); delete(members, rs) deletes the just-written list when the new representative equals rd or rs. Member lists go empty, interferesSets misses real edges, and illegal merges succeed. Fix: delete only the non-representative. 2. Shared backtracking state — one used color buffer reused across recursive calls loses neighbor colors when a nested call returns, producing invalid/non-minimal colorings. Fix: allocate used per call.

Supporting correctness: phi operands are used at the end of the predecessor and phi destinations are defined at block entry; and the verifier must check the original edge set against the final per-value location.

3. Exact fix

Pipeline: build interference → conservatively coalesce (reject merges that connect interfering classes) → exactly color the coalesced graph → verify against the original edge set.

The heart is the self-cycle gate (coalesce.go):

// interferesSets: would coalescing classes a and b create a self-cycle?
func interferesSets(g *Interference, members map[Value][]Value, a, b Value) bool {
    for _, x := range members[a] {
        for _, y := range members[b] {
            if g.Has(x, y) {
                return true
            }
        }
    }
    return false
}

func Coalesce(f *Func, g *Interference, naive bool) *CoalesceResult {
    n := f.NumValues()
    uf := NewUF(n)
    members := map[Value][]Value{}
    for i := 0; i < n; i++ {
        members[Value(i)] = []Value{Value(i)}
    }

    res := &CoalesceResult{UF: uf}
    for _, c := range CollectCopies(f) {
        rd := uf.Find(c.Dest)
        rs := uf.Find(c.Src)
        if rd == rs {
            res.Removed = append(res.Removed, c)
            continue
        }
        if !naive && interferesSets(g, members, rd, rs) {
            res.Rejected = append(res.Rejected, RejectedCopy{Copy: c, Reason: "self-cycle: endpoints interfere"})
            continue
        }
        if naive && interferesSets(g, members, rd, rs) {
            res.SelfLoop = true // detect it but merge anyway (buggy)
        }
        nr := uf.Union(rd, rs)
        members[nr] = append(members[rd], members[rs]...)
        if rd != nr { delete(members, rd) }   // <-- keep the representative
        if rs != nr { delete(members, rs) }
        res.Removed = append(res.Removed, c)
    }
    return res
}

Scanning all members of both classes (not just the pair) also rejects cycles that only appear after several coalesces, e.g. the diamond case.

The other pieces: - analysis.go — backward dataflow live_out(B) = ⋃_S (live_in(S) \ phiDefs(S)) ∪ phiUses(S,B), then a bottom-up per-block walk (instructions, then phis) to add interference. A phi dest interferes with everything live across the block entry. - alloc.go — exact minimum-spill branch-and-bound: at each node try each free register, then spilling; prune on spills >= best; local used buffer per call. - verify.go — for every edge (a,b) of the original graph, assert loc[a] != loc[b]; for every removed copy d=s, assert loc[d]==loc[s] (a move from a location to itself ⇒ redundant on every path); for every kept copy, assert it is a genuine move.
