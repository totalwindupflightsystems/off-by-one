Answer

Root cause (U-GAP-018): README.md promised "hot paths become native code" (a runtime-execution claim) while jitSandboxAdapter.Execute was — and is, by design — a hard NOT_IMPLEMENTED stub. The E2E battery (provision.sh) asserts jit echo → 501, so implementing execution to match the README would break the battery. The task offered implement-vs-document; checking the battery's design constraints first forces the DOCS route.

The fix: scope JIT as generation-only (Phase 1) with validation/deployment as planned Phase 2, and lock that scoping with a docs-contract regression test. No execution code changed — the 501 contract is preserved.
