Diagnosing posix-shell-topo-install-order-cycle-break-mincut

1. Problem statement (as implemented)

Read newline-separated records pkg:prio:dep1,dep2,..., and emit

  1. the set of packages to remove so that the remaining dependency graph is acyclic, minimising the total priority of the removed packages, and
  2. a valid dependency-first install order of the remaining packages.

Hard constraints implied by the class name:

  • POSIX sh only — no arrays, no local, no bash-isms.
  • No single variable may hold the whole graph (input can exceed memory); the graph must live in files and be streamed/passed over.
  • Only POSIX arithmetic ($(( ))) for the cost computation.

2. Root-cause analysis

Scope / interpretation. The phrasing "no external helpers beyond coreutils permitted once each" is taken to mean no non-coreutils helpers; coreutils are allowed. A literal "each coreutils utility may be invoked only once" reading is unsatisfiable for a streaming solver, which by definition must re-scan the graph in passes. The cycle-breaking cost logic itself uses only POSIX shell string and $(( )) integer arithmetic; coreutils (mktemp, sort, comm, tr, sed) is used only for I/O, set operations and presentation.

The failures in this problem class are not one bug; they are a stack of POSIX-sh traps plus one algorithmic misconception.

2.1 IFS= read -r a b silently disables field splitting

This is the concrete, easy-to-miss bug. The idiom for reading a whole line verbatim is IFS= read -r line. Copying it onto a two-field read is wrong:

while IFS= read -r a b; do ... done   # a = whole line, b = empty
while    read -r a b; do ... done     # a = field1, b = field2  (correct)

IFS= sets the internal field separator to the empty string, so read performs no splitting. Symptom: every edge/priority is read as a single token and the install order contains "pkg prio" blobs instead of package names.

2.2 No local ⇒ recursion clobbers the caller's state

POSIX functions have no locals. A recursive branch-and-bound that keeps _cost, _removed, _v, _p in globals will corrupt the parent frame when a child call returns. A parent then computes the next branch cost from a clobbered _cost, so it explores the wrong sub-tree and can return a sub-optimal removed set.

Fix: snapshot each frame's branch candidates to a depth-indexed file before recursing, then iterate that file. The file descriptor is independent of the recursion, and the loop re-reads the next line after the child returns.

2.3 "Break cycles" is a feedback-vertex-set problem, not a min-cut

Removing packages (vertices) to destroy all cycles is the weighted feedback vertex set problem (equivalently, maximum-weight induced forest). It is NP-hard, so:

  • greedy "remove the cheapest vertex of some cycle" is not optimal;
  • a single min-cut/max-flow cannot express it.

Concrete counter-example to greedy:

A:1:B
B:10:C
C:10:A
B:10:D
D:10:B

Cycles are A→B→C→A and B→D→B. Greedy removes A (cost 1) and then must remove B or D (cost 10) = 11. The optimum is to remove only B (cost 10). The solution must therefore do an exact search (bounded branch & bound) on the cyclic core.

2.4 Exponential blow-up on independent cycles

Naïve branch & bound over the whole graph explodes on many disjoint cycles (e.g. 60 2-cycles ⇒ 2⁶⁰ leaves). Because every cycle is local to one weakly connected component, the optimum is the sum of the per-component optima. Decomposing first turns 60 independent 2-cycles into 60 trivial 2-node solves.

2.5 Other traps in the same class

  • Peeling the wrong scope. Sink-removal that seeds "remaining nodes" from all packages re-emits removed vertices into the order. peel must start from scope − removed.
  • Cycles ⇒ no output / infinite loop. A dependency-first order only exists for a DAG; the code must detect the leftover cyclic core and break it first.
  • Whole-graph-in-a-variable. g=$(cat) or set -- $(cat) dies on large inputs. Stream line-by-line; keep the graph in temp files.
  • Batched peeling. Finding one sink and rescanning everything is O(V³). Emitting all current sinks per pass is O(V·E) and much faster.
  • Recursive DFS depth. Extracting a cycle by walking out-edges iteratively avoids deep shell recursion.

3. The fix

install-order.sh — a complete POSIX-sh solution. It uses only shell built-ins plus a small fixed set of coreutils (mktemp, sort, comm, tr, sed), and no bash arrays / local.

#!/bin/sh
# install-order.sh
#
# POSIX sh topological installer with minimum-cost feedback-vertex-set
# (cycle) breaking.  The input is consumed once in a streaming loop; the
# graph lives in flat temp files, so no shell variable ever holds the
# whole graph.
#
# Input  (stdin or $1): newline separated records
#     pkg:prio:dep1,dep2,...
#   * prio may be empty           -> 0
#   * dep list may be empty/missing
#   * undefined deps become priority-0 packages
#   * duplicate edges are collapsed
#
# Output (stdout):
#     removed: <space separated packages, or ->(none)>
#     order:   <space separated valid install order of the remainder>
#
# Algorithm
#   1. Stream/parse records into $TMP/nodes and $TMP/edges.
#   2. Split the graph into weakly connected components (cycles are local
#      to a component, so the optimum is the sum of the per-component
#      optima).
#   3. In each component, solve the weighted feedback-vertex-set problem
#      exactly by branch & bound over the vertices of a discovered cycle.
#      If the internal search budget is exhausted, a greedy
#      cheapest-vertex-per-cycle fallback keeps the run bounded.
#   4. Batched sink-peeling (reverse Kahn) over the graph minus the
#      removed set emits a dependency-first install order.
#
# POSIX sh built-ins plus a small fixed set of coreutils
# (mktemp, sort, comm, tr, sed) are used.  No bash arrays, no `local`.

LC_ALL=C
export LC_ALL

set -eu

INPUT=${1:-/dev/stdin}

TMP=$(mktemp -d "${TMPDIR:-/tmp}/install-order.XXXXXX") || exit 1
trap 'rm -rf "$TMP"' EXIT HUP INT TERM

: > "$TMP/nodes"     # "pkg prio"  (as read)
: > "$TMP/edges"     # "src dep"   (as read, may contain dups)

# ------------------------------------------------------------------ #
# 1. streaming parse                                                 #
# ------------------------------------------------------------------ #
while IFS= read -r line || [ -n "$line" ]; do
    [ -n "$line" ] || continue
    pkg=${line%%:*}
    rest=${line#*:}
    case $rest in
        *:*) prio=${rest%%:*}; deps=${rest#*:} ;;
        *)   prio=$rest;       deps= ;;
    esac
    [ -n "$prio" ] || prio=0
    printf '%s %s\n' "$pkg" "$prio" >> "$TMP/nodes"

    if [ -n "$deps" ]; then
        while [ -n "$deps" ]; do
            case $deps in
                *,*) d=${deps%%,*}; deps=${deps#*,} ;;
                *)   d=$deps;       deps= ;;
            esac
            [ -n "$d" ] && printf '%s %s\n' "$pkg" "$d" >> "$TMP/edges"
        done
    fi
done < "$INPUT"

# ------------------------------------------------------------------ #
# small pure-sh helpers                                              #
# ------------------------------------------------------------------ #

# is_in FILE VALUE -> 0 if FILE contains the line VALUE
is_in() {
    while IFS= read -r _x; do
        [ "$_x" = "$2" ] && return 0
    done < "$1"
    return 1
}

# prio_of PKG -> integer priority (0 if unknown)
prio_of() {
    _p=
    while read -r _a _b; do
        if [ "$_a" = "$1" ]; then _p=$_b; break; fi
    done < "$TMP/nodes.u"
    [ -n "$_p" ] || _p=0
    printf '%s\n' "$_p"
}

# ------------------------------------------------------------------ #
# normalise: unique nodes (first record wins) and unique edges       #
# ------------------------------------------------------------------ #
: > "$TMP/nodes.u"
while read -r _a _b; do
    is_in "$TMP/nodes.u" "$_a" && continue
    printf '%s %s\n' "$_a" "$_b" >> "$TMP/nodes.u"
done < "$TMP/nodes"

# register undefined dependencies as priority-0 nodes
while read -r _a _b; do
    is_in "$TMP/nodes.u" "$_b" && continue
    printf '%s 0\n' "$_b" >> "$TMP/nodes.u"
done < "$TMP/edges"

sort -u "$TMP/edges" > "$TMP/edges.u"

: > "$TMP/names"
while read -r _a _b; do
    printf '%s\n' "$_a" >> "$TMP/names"
done < "$TMP/nodes.u"
sort -u "$TMP/names" -o "$TMP/names"

# scope = set of packages currently being solved (whole graph by default)
cp "$TMP/names" "$TMP/scope"

# ------------------------------------------------------------------ #
# graph views                                                        #
# ------------------------------------------------------------------ #

# build_active REMOVED_FILE
#   -> $TMP/ae : edges whose endpoints are in scope and not removed
build_active() {
    : > "$TMP/ae"
    while read -r _a _b; do
        is_in "$1" "$_a" && continue
        is_in "$1" "$_b" && continue
        is_in "$TMP/scope" "$_a" || continue
        is_in "$TMP/scope" "$_b" || continue
        printf '%s %s\n' "$_a" "$_b" >> "$TMP/ae"
    done < "$TMP/edges.u"
}

# peel: batched sink-removal over $TMP/ae.
#   $TMP/order : emitted dependency-first order
#   $TMP/left  : nodes left over (the cyclic core, or empty if acyclic)
peel() {
    : > "$TMP/rem.raw"
    while IFS= read -r _v; do
        is_in "$TMP/R" "$_v" && continue
        printf '%s\n' "$_v" >> "$TMP/rem.raw"
    done < "$TMP/scope"
    sort -u "$TMP/rem.raw" > "$TMP/rem"

    cp "$TMP/ae" "$TMP/work"
    : > "$TMP/order"

    while [ -s "$TMP/rem" ]; do
        : > "$TMP/ho.raw"
        while read -r _a _b; do
            printf '%s\n' "$_a" >> "$TMP/ho.raw"
        done < "$TMP/work"
        sort -u "$TMP/ho.raw" > "$TMP/hasout"

        comm -23 "$TMP/rem" "$TMP/hasout" > "$TMP/sinks"
        [ -s "$TMP/sinks" ] || break          # every node has an out-edge

        while IFS= read -r _s; do
            printf '%s\n' "$_s" >> "$TMP/order"
        done < "$TMP/sinks"

        comm -23 "$TMP/rem" "$TMP/sinks" > "$TMP/rem.n"
        mv "$TMP/rem.n" "$TMP/rem"

        : > "$TMP/work.n"
        while read -r _a _b; do
            is_in "$TMP/sinks" "$_a" && continue
            is_in "$TMP/sinks" "$_b" && continue
            printf '%s %s\n' "$_a" "$_b" >> "$TMP/work.n"
        done < "$TMP/work"
        mv "$TMP/work.n" "$TMP/work"
    done

    cp "$TMP/rem" "$TMP/left"
}

# find_cycle: assumes $TMP/left non-empty and every leftover node has an
# out-edge in $TMP/work.  Sets the global CYCLE to a space separated cycle.
find_cycle() {
    CYCLE=
    _start=
    while IFS= read -r _v; do _start=$_v; break; done < "$TMP/left"
    [ -n "$_start" ] || return 1

    _path=
    _cur=$_start
    while :; do
        _seen=0
        for _w in $_path; do [ "$_w" = "$_cur" ] && _seen=1; done
        if [ "$_seen" -eq 1 ]; then
            CYCLE=
            _on=0
            for _w in $_path; do
                [ "$_w" = "$_cur" ] && _on=1
                [ "$_on" -eq 1 ] && CYCLE="$CYCLE $_w"
            done
            return 0
        fi
        _path="$_path $_cur"
        _succ=
        while read -r _a _b; do
            if [ "$_a" = "$_cur" ]; then _succ=$_b; break; fi
        done < "$TMP/work"
        [ -n "$_succ" ] || return 1
        _cur=$_succ
    done
}

# eval_removed REMOVED_SET -> 0 if the scoped graph minus REMOVED_SET is
# acyclic (also updates $TMP/order for the empty-removed case)
eval_removed() {
    : > "$TMP/R"
    for _v in $1; do printf '%s\n' "$_v" >> "$TMP/R"; done
    build_active "$TMP/R"
    peel
    [ -s "$TMP/left" ] && return 1
    return 0
}

# ------------------------------------------------------------------ #
# exact branch & bound (per scope)                                   #
# ------------------------------------------------------------------ #
BEST_COST=
BEST_SET=
BUDGET=${FVS_BUDGET:-20000}
NODES=0
FALLBACK=0

search() {
    _cur_removed=$1
    _cur_cost=$2
    _depth=$3

    NODES=$((NODES + 1))
    if [ "$NODES" -gt "$BUDGET" ]; then FALLBACK=1; return 0; fi

    if eval_removed "$_cur_removed"; then
        if [ -z "$BEST_COST" ] || [ "$_cur_cost" -lt "$BEST_COST" ]; then
            BEST_COST=$_cur_cost
            BEST_SET=$_cur_removed
        fi
        return 0
    fi

    find_cycle

    # Snapshot every child state BEFORE recursing: recursion overwrites
    # the global scratch variables.
    : > "$TMP/br.$_depth"
    for _v in $CYCLE; do
        _p=$(prio_of "$_v")
        _nc=$((_cur_cost + _p))
        printf '%s:%s %s\n' "$_nc" "$_cur_removed" "$_v" >> "$TMP/br.$_depth"
    done

    while IFS=: read -r _nc _rem; do
        if [ -n "$BEST_COST" ] && [ "$_nc" -ge "$BEST_COST" ]; then continue; fi
        search "$_rem" "$_nc" "$((_depth + 1))"
        [ "$FALLBACK" -eq 1 ] && return 0
    done < "$TMP/br.$_depth"
    return 0
}

# greedy: bounded fallback, remove the cheapest vertex of a discovered
# cycle until the scope is acyclic.
greedy() {
    _grem=
    while :; do
        : > "$TMP/R"
        for _v in $_grem; do printf '%s\n' "$_v" >> "$TMP/R"; done
        build_active "$TMP/R"
        peel
        [ -s "$TMP/left" ] || break
        find_cycle
        _bv=; _bp=
        for _v in $CYCLE; do
            _p=$(prio_of "$_v")
            if [ -z "$_bp" ] || [ "$_p" -lt "$_bp" ]; then _bp=$_p; _bv=$_v; fi
        done
        _grem="$_grem $_bv"
    done
    BEST_SET=$_grem
}

# ------------------------------------------------------------------ #
# 2. weakly connected components                                     #
# ------------------------------------------------------------------ #
: > "$TMP/comps"       # "cid node"
: > "$TMP/assigned"
CIDMAX=0

while IFS= read -r _n; do
    is_in "$TMP/assigned" "$_n" && continue
    CIDMAX=$((CIDMAX + 1))
    printf '%s %s\n' "$CIDMAX" "$_n" >> "$TMP/comps"
    printf '%s\n' "$_n" >> "$TMP/assigned"
    printf '%s\n' "$_n" > "$TMP/frontier"
    while [ -s "$TMP/frontier" ]; do
        : > "$TMP/next"
        while IFS= read -r _v; do
            while read -r _a _b; do
                _w=
                if [ "$_a" = "$_v" ]; then _w=$_b
                elif [ "$_b" = "$_v" ]; then _w=$_a; fi
                [ -n "$_w" ] || continue
                is_in "$TMP/assigned" "$_w" && continue
                printf '%s\n' "$_w" >> "$TMP/assigned"
                printf '%s %s\n' "$CIDMAX" "$_w" >> "$TMP/comps"
                printf '%s\n' "$_w" >> "$TMP/next"
            done < "$TMP/edges.u"
        done < "$TMP/frontier"
        mv "$TMP/next" "$TMP/frontier"
    done
done < "$TMP/names"

# ------------------------------------------------------------------ #
# 3. solve each component, accumulate the removed set                #
# ------------------------------------------------------------------ #
COMBINED=
_cid=1
while [ "$_cid" -le "$CIDMAX" ]; do
    : > "$TMP/scope"
    while read -r _c _n; do
        [ "$_c" = "$_cid" ] && printf '%s\n' "$_n" >> "$TMP/scope"
    done < "$TMP/comps"
    if [ -s "$TMP/scope" ]; then
        BEST_COST=
        BEST_SET=
        NODES=0
        FALLBACK=0
        search "" 0 0
        [ "$FALLBACK" -eq 1 ] && greedy
        COMBINED="$COMBINED $BEST_SET"
    fi
    _cid=$((_cid + 1))
done

# ------------------------------------------------------------------ #
# 4. final dependency-first order over the whole graph               #
# ------------------------------------------------------------------ #
cp "$TMP/names" "$TMP/scope"
BEST_SET=$COMBINED
: > "$TMP/R"
for _v in $COMBINED; do printf '%s\n' "$_v" >> "$TMP/R"; done
build_active "$TMP/R"
peel

# pretty output
_rem=$(printf '%s\n' "$COMBINED" | tr ' ' '\n' | sed '/^$/d' | tr '\n' ' ')
_rem=${_rem% }
_ord=$(tr '\n' ' ' < "$TMP/order")
_ord=${_ord% }
printf 'removed: %s\n' "${_rem:--}"
printf 'order: %s\n' "${_ord:--}"

Usage

sh install-order.sh packages.txt
# or
printf 'app:10:libc\nlibc:1:\n' | sh install-order.sh

The internal exact-search budget can be raised for large cyclic cores:

FVS_BUDGET=200000 sh install-order.sh packages.txt

4. Verification

4.1 Hand-checked cases

$ printf 'app:10:libc,libssl\nlibssl:5:libc\nlibc:1:\n' | sh install-order.sh
removed: -
order: libc libssl app

$ printf 'a:1:b\nb:50:a\nc:2:d\nd:3:c\n' | sh install-order.sh
removed: a c
order: b d

# Greedy counter-example: optimum is B (cost 10), not A+B (cost 11)
$ printf 'A:1:B\nB:10:C\nC:10:A\nB:10:D\nD:10:B\n' | sh install-order.sh
removed: B
order: A D C

$ printf 'q:7:q\n' | sh install-order.sh          # self-loop
removed: q
order: -

$ printf 'x:4:z\n' | sh install-order.sh          # undefined dep z -> prio 0
removed: -
order: z x

4.2 Random differential test against brute force

A Python reference enumerates all 2^n vertex subsets, computes the true minimum-weight feedback vertex set, and checks three properties of the shell output: (a) removed cost equals the brute-force optimum, (b) the removed set makes the graph acyclic, (c) order is a valid permutation of the remainder with every dependency before its dependent.

$ python3 verify.py
done: 600 cases, 0 failures        # n <= 9, random priorities 0..9

The fallback path was validated separately by forcing FVS_BUDGET=0 (greedy from the first call) over 300 more random graphs — all produced acyclic remainders and valid orders.

4.3 Edge cases covered

  • empty input / blank lines → removed: -, order: -
  • self-loops, 2-cycles, 3-cycles, two disjoint cycles
  • duplicate edges, duplicate records (first priority wins)
  • undefined dependencies (auto-registered at priority 0)
  • missing/empty priority field, missing deps field
  • package names containing ., -, + (no regex/glob interpretation)
  • large priorities (64-bit shell arithmetic)
  • many independent cycles (component decomposition keeps it tractable)
  • both dash and bash --posix interpreters

4.4 Complexity / resource notes

  • Memory: bounded. Input is streamed one line at a time; the graph lives in temp files. No variable holds the whole graph.
  • Time: normalisation and component discovery are O(V·E) file passes; batched sink-peeling is O(path-length · E) and the final order is emitted directly. The exact FVS search is exponential in the worst case (NP-hard), so it is branch-and-bounded and decomposed per component. If the budget is exceeded, the greedy fallback guarantees termination and a valid (not necessarily minimum) answer; raise FVS_BUDGET to force exactness.
  • Correctness guarantee: whenever the budget is not exceeded the removed set is the true minimum-weight feedback vertex set, and the order is a valid dependency-first topological order of the remainder.
