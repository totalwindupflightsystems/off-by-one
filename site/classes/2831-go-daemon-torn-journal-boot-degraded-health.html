Fix: torn-journal boot aborts / self-deadlocks instead of reporting degraded health

Problem class: go-daemon-torn-journal-boot-degraded-health Environment: go1.24 linux/amd64, local journal file Observed errors: reverter: journal parse: unexpected EOF; panic: runtime error: invalid memory address or nil pointer dereference (sync.Mutex.Lock on 0x0); health.json never created.

1. Summary

Three defects combined so the daemon could not survive a crash-torn journal:

  1. Store constructor was all-or-nothing. store.Open returned (nil, err) on a torn final line, so the caller had no usable store.
  2. Daemon treated the recoverable fold error as fatal. It exited 1 (or dereferenced the nil store), so health.json was never written.
  3. The degraded render path re-locked a mutex the caller already held, self-deadlocking the one beat that was supposed to report the corruption. A related tick-loop guard also skipped the write when degraded.

The fix makes Open return the initialised store together with the fold error, has the daemon accept the degraded store and retain the error, uses a non-locking field setter inside the already-locked render path, and makes the tick loop publish the degraded beat instead of skipping it.

2. Root-cause analysis

2.1 Constructor discards the initialised store

A torn line (a partial JSON object left by a crash mid-append) is recoverable: every complete record before it is valid. The old code did the opposite of fail-closed — it returned no store at all:

// BEFORE (internal/store/journal.go)
if err := dec.Decode(&r); err != nil {
    return nil, fmt.Errorf("journal parse: %w", err) // caller gets nothing
}

A truncated line decoded with encoding/json yields io.ErrUnexpectedEOF, whose text is exactly unexpected EOF — matching reverter: journal parse: unexpected EOF.

2.2 Daemon aborts boot

// BEFORE (cmd/mischiefd/main.go)
s, err := store.Open(journalPath)
if err != nil {
    log.Fatalf("reverter: %v", err) // os.Exit(1): no health.json ever
}

Even if the caller did not exit, it would then call s.FoldError() on a nil *Store, producing sync.Mutex.Lock on 0x0.

2.3 Degraded render re-locks the held mutex

beat held d.mu, then the degraded branch called a locking setter, which blocked forever on the same mutex:

// BEFORE (internal/daemon/daemon.go)
func (d *Daemon) beat() {
    d.mu.Lock()
    defer d.mu.Unlock()
    d.lastBeat = time.Now()
    if d.foldErr != nil {
        d.setDegraded(d.foldErr) // deadlock: takes d.mu again
    }
    d.writeHealth()
}

Because Run published the first beat synchronously before entering the ticker, the daemon deadlocked on the very first beat and health.json was never created.

2.4 Test-fixture defects that hid the behaviour

  • Fixture written to a guessed filename instead of the store's real journal file (store.JournalName).
  • Health JSON decoded into a reused struct; omitempty fields (e.g. degraded, error) stayed populated from the previous degraded beat, so recovery was never observed.
  • Recovery poll window shorter than the heartbeat interval, so a healthy beat had not happened yet.

3. Exact fix

3.1 internal/store/journal.go — return the store with the error

// JournalName is the canonical on-disk journal filename. Fixtures must use it.
const JournalName = "journal.log"

func Open(path string) (*Store, error) {
    s := &Store{path: path}

    f, err := os.Open(path)
    if err != nil {
        if errors.Is(err, os.ErrNotExist) {
            return s, nil // fresh boot: no journal is fine
        }
        return nil, fmt.Errorf("open journal: %w", err) // truly unusable
    }
    defer f.Close()

    sc := bufio.NewScanner(f)
    sc.Buffer(make([]byte, 0, 64*1024), 4*1024*1024)
    for sc.Scan() {
        dec := json.NewDecoder(bytes.NewReader(sc.Bytes()))
        var r Record
        if err := dec.Decode(&r); err != nil {
            s.foldErr = fmt.Errorf("journal parse: %w", err)
            return s, s.foldErr // initialised store WITH the fold error
        }
        if dec.More() {
            s.foldErr = fmt.Errorf("journal parse: %w", io.ErrUnexpectedEOF)
            return s, s.foldErr
        }
        s.records = append(s.records, r)
    }
    if err := sc.Err(); err != nil {
        s.foldErr = fmt.Errorf("journal read: %w", err)
        return s, s.foldErr
    }
    return s, nil
}

Open returns (nil, err) only when no store can exist. A torn journal is (initialisedStore, err).

3.2 cmd/mischiefd/main.go — fail-closed but accept degraded boot

s, err := store.Open(journalPath)
if s == nil {
    log.Fatalf("reverter: journal open: %v", err) // fatal only if no store
}
if err != nil {
    log.Printf("reverter: %v (booting degraded)", err) // keep the error
}

d := daemon.New(s, healthPath, 250*time.Millisecond) // run degraded

3.3 internal/daemon/daemon.go — non-locking setter + always publish

// New accepts a degraded (non-nil store + error) daemon.
func New(j *store.Store, healthPath string, heartbeat time.Duration) *Daemon {
    d := &Daemon{journal: j, healthPath: healthPath, heartbeat: heartbeat}
    if j != nil {
        d.foldErr = j.FoldError()
    }
    return d
}

// setFoldErrorLocked records the error WITHOUT taking d.mu. The caller
// already holds it; locking again self-deadlocks the degraded beat.
func (d *Daemon) setFoldErrorLocked(err error) { d.foldErr = err }

func (d *Daemon) beat() {
    d.mu.Lock()
    defer d.mu.Unlock()
    d.lastBeat = time.Now()
    d.writeHealthLocked() // degraded state must NOT skip this write
}

func (d *Daemon) writeHealthLocked() {
    h := Health{
        Status:   "ok",
        LastBeat: d.lastBeat.UTC().Format(time.RFC3339Nano),
    }
    if d.foldErr != nil {
        h.Status = "degraded"
        h.Degraded = true
        h.Error = d.foldErr.Error()
    }
    data, err := json.Marshal(h)
    if err != nil {
        return
    }
    tmp := d.healthPath + ".tmp"
    if err := os.WriteFile(tmp, data, 0o644); err != nil {
        return
    }
    _ = os.Rename(tmp, d.healthPath)
}

Run publishes immediately, re-folds each tick so a repaired line clears the degraded state, and never gates the beat on health:

func (d *Daemon) Run(stop <-chan struct{}) {
    d.beat()
    t := time.NewTicker(d.heartbeat)
    defer t.Stop()
    for {
        select {
        case <-stop:
            return
        case <-t.C:
            d.reload() // clears foldErr once the torn line is repaired
            d.beat()
        }
    }
}

// use the REAL filename
jpath := filepath.Join(dir, store.JournalName)

// FRESH struct on every poll
func readHealth(path string) (daemon.Health, error) {
    var h daemon.Health // new zero value each call; no omitempty carryover
    b, err := os.ReadFile(path)
    if err != nil {
        return h, err
    }
    err = json.Unmarshal(b, &h)
    return h, err
}

// poll window STRICTLY GREATER than the heartbeat
h := waitHealth(t, hp, beat*6) // beat = 50ms, window = 300ms
